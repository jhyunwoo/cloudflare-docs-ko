Hyperdrive 구성의 연결 정보와 자격 변경을 할 수 있습니다.

1. 새로운 연결 정보를 가진 새로운 Hyperdrive 윤곽을 창조하고, 새로운 HyperdriveXQ 윤곽을 사용하는 당신의 노동자를 새롭게 합니다.
2. 새로운 연결 정보와 credentials를 가진 기존 Hyperdrive 윤곽을 새롭게 하십시오.

## 새로운 HyperdriveXQ 윤곽을 사용하십시오

새로운 HyperdriveXQ 구성을 작성하여 데이터베이스 자격 증명을 업데이트하면 기존 HyperdriveXQXQ 구성을 변경하지 않고 새로운 HyperdriveXQ 구성으로 작업자를 점차적으로 마이그레이션하고 필요한 경우 이전 구성으로 쉽게 롤 할 수 있습니다.

기존 PostgreSQL 또는 MySQL 데이터베이스에 연결하는 HyperdriveXQ 구성을 만들려면[Wrangler](/workers/wrangler/install-and-update/)CLI 또는[Cloudflare대시보드](https://dash.cloudflare.com/?to=/:account/workers/hyperdrive).

```sh
#wrangler v3.11 이상 필요
npx wrangler hyperdrive create my-updated-hyperdrive --connection-string="<YOUR_CONNECTION_STRING>"
```

위의 명령은 Hyperdrive의 ID를 출력합니다. 이 ID를 설정[Wrangler 구성 파일](/workers/wrangler/configuration/)Workers 프로젝트를 위해:

<WranglerConfig>
  ```jsonc
  {
  	//데이터베이스 드라이버에 필요한 기능
  	"compatibility_flags": [
  		"nodejs_compat"
  	],
  	"compatibility_date": "$today",
  	"hyperdrive": [
  		{
  			"binding": "HYPERDRIVE",
  			"id": "<your-hyperdrive-id-here>"
  		}
  	]
  }
  ```
</WranglerConfig>

당신의 노동자를 새롭게 하기 위하여 새로운 Hyperdrive 윤곽을, 당신의 노동자 또는 사용을 redeploy[gradual 배포](/workers/configuration/versions-and-deployments/gradual-deployments/).

## 기존 HyperdriveXQ 구성 업데이트

기존 Hyperdrive 구성의 구성을 업데이트할 수 있습니다.[wrangler 클립](/workers/wrangler/install-and-update/).

```sh
#wrangler v3.11 이상 필요
npx wrangler hyperdrive update <HYPERDRIVE_CONFIG_ID> --origin-host <YOUR_ORIGIN_HOST> --origin-password <YOUR_ORIGIN_PASSWORD> --origin-user <YOUR_ORIGIN_USERNAME> --database <YOUR_DATABASE> --origin-port <YOUR_ORIGIN_PORT>
```

:::참조
기존 HyperdriveXQXQ 구성의 설정을 변경하지 않고 Hyperdrive의 캐시를 제거하고 기존 데이터베이스 연결 풀을 찢지 않습니다. 새 연결은 새로운 연결 정보를 사용하여 설치됩니다.

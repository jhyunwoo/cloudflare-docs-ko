Hyperdrive는[Cloudflare IP 주소 범위](https://www.cloudflare.com/ips/)데이터베이스에 연결하기. 이 참고 자료에 나열된 IP 주소는 데이터베이스의 방화벽 및 네트워킹 구성에 대한 허용 목록이 있어야 합니다.

다음 네트워킹 구성을 사용하여 Hyperdrive에서 데이터베이스에 연결할 수 있습니다.

1. 공공 인터넷 (모든 IP 주소 범위)에서 인바운드 연결을 허용하는 데이터베이스 구성.
2. 공공 인터넷에서 인바운드 연결을 허용하는 데이터베이스를 구성하고, Hyperdrive에 의해 사용되는 IP 주소 범위는 IP 액세스 제어 목록 (ACL)에서 수신 할 수 있습니다.
3. 개인 네트워크에서 인바운드 연결을 허용하려면 데이터베이스를 구성하고 개인 네트워크의 Cloudflare 터널 인스턴스를 실행하여 Hyperdrive를 활성화하여 Cloudflare 네트워크에서 개인 네트워크에 연결할 수 있습니다. 더 알아보기[터널을 사용하여 개인 데이터베이스에 연결하는 문서](/hyperdrive/configuration/connect-to-private-database/).

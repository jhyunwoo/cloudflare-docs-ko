Hyperdrive는 개인 데이터베이스에 안전하게 연결할 수 있습니다[Cloudflare 관련 제품](/cloudflare-one/networks/connectors/cloudflare-tunnel/)·[Cloudflare 오시는 길](/cloudflare-one/access-controls/policies/).

## 어떻게 작동합니까?

데이터베이스가 개인 네트워크 내에서 격리 될 때 (예 :[가상 개인 클라우드](https://www.cloudflare.com/learning/cloud/what-is-a-virtual-private-cloud)또는 온-프레미스 네트워크), 당신은 당신의 네트워크에서 Cloudflare에 안전한 연결을 가능하게해야합니다.

- [Cloudflare 관련 제품](/cloudflare-one/networks/connectors/cloudflare-tunnel/)안전한 갱도 연결을 설치하기 위하여 사용됩니다.
- [모델 번호: Cloudflare 오시는 길](/cloudflare-one/access-controls/policies/)특정 Hyperdrive 구성이 접근할 수 있도록 터널에 대한 액세스를 제한하는 데 사용됩니다.

Cloudflare Worker의 요청은 Hyperdrive, Cloudflare 액세스 및 Cloudflare 터널을 통해 사용됩니다.`cloudflared`. `cloudflared`데이터베이스가 액세스 할 수있는 개인 네트워크에서 실행해야합니다.

Cloudflare 갱도는 당신의 개인적인 네트워크에서 Cloudflare에 outbound 양방향 연결을 설치할 것입니다. Cloudflare 액세스는 Cloudflare Hyperdrive 구성에 의해서만 접근할 수 있는 갱도.

![원래 데이터베이스에 Cloudflare 노동자의 요청은 Hyperdrive, Cloudflare 액세스 및 Cloudflare 터널을 통해 이동합니다.](~/assets/images/hyperdrive/configuration/hyperdrive-private-database-architecture.png)

## 문제 해결

HyperdriveXQ 구성을 설정할 때 문제가 발생하면 개인 데이터베이스에 터널을 사용하여 이러한 일반적인 솔루션을 고려하십시오.[일반 문제 해결 단계](/hyperdrive/observability/troubleshooting/)Hyperdrive를 위해:

- 데이터베이스가 TLS (SSL)를 사용하도록 구성됩니다. Hyperdrive는 연결하기 위하여 TLS (SSL)를 요구합니다.

다음 제한은 Hyperdrive 구성, 연결 및 구성 요소 데이터베이스로 만든 쿼리에 적용됩니다.

## 구성 제한

이러한 제한은 Hyperdrive 구성을 생성하거나 업데이트할 때 적용됩니다.

| 지원하다                | 무료 다운로드   | 계정 만들기    |
| ------------------- | --------- | --------- |
| 최대 구성 된 데이터베이스      | 계정 당 10   | 계정 당 25   |
| 최대 사용자 이름 길이[^1]    | 63자 (바이트) | 63자 (바이트) |
| 최대 데이터베이스 이름 길이[^1] | 63자 (바이트) | 63자 (바이트) |

[^1]: 이것은 PostgreSQL에 의해 수행 한 제한입니다. 몇몇 데이터베이스 공급자는 더 작은 한계를 강제할지도 모릅니다.

## 연결 제한

이 한계는 Hyperdrive와 당신의 근원 데이타베이스 사이 연결에 적용합니다.

| 지원하다                      | 무료 다운로드 | 계정 만들기   |
| ------------------------- | ------- | -------- |
| 처음 연결 timeout             | 15 초    | 15 초     |
| Idle 연결 timeout           | 10 분    | 10 분     |
| 최대 소스 데이터베이스 연결 (설정당)[^2] | \~20 연결 | \~100 연결 |

Hyperdrive는 Workers에서 동시 클라이언트 연결을 제한하지 않습니다. 그러나, Hyperdrive는 대부분의 호스팅 데이터베이스가 연결 제한이 있기 때문에 원래 데이터베이스에 연결 제한을 제한합니다.

[^2]: Hyperdrive는 분배된 체계입니다, 그래서 클라이언트는 기존하는 수영장에 도달할 수 없습니다. 이 시나리오에서 새로운 풀은 자체 연결 할당으로 설치됩니다. 엄격한 제한 시행에 대한 가용성을 우선 순위, 이는 연결 카운트가 때때로 나열된 한계를 초과 할 수있다.

### 연결 오류

Hyperdrive는 당신의 근원 데이타베이스에 연결을 취득할 수 없는 경우에, 당신은 뒤에 오는 과실의 한을 볼지도 모릅니다:

| 오류 메시지                                                 | 이름 \*                                                                                    |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| `Failed to acquire a connection from the pool.`        | 연결 풀은 연결이 너무 오래 열리기 때문에 배출됩니다. 긴 실행 쿼리 또는 거래는 일반적인 원인입니다.                                |
| `Server connection attempt failed: connection_refused` | 당신의 근원 데이타베이스는 연결 거부입니다. 이것은 방화벽 블록 Hyperdrive, 또는 데이터베이스 공급자의 연결 제한이 초과 될 때 발생할 수 있습니다. |

오류 코드의 전체 목록의 경우, 참조[문제 해결 및 디버그](/hyperdrive/observability/troubleshooting/).

## Query 제한

이 제한은 Hyperdrive를 통해 보내진 쿼리에 적용됩니다.

| 지원하다                 | 무료 다운로드 | 계정 만들기 |
| -------------------- | ------- | ------ |
| 최대 쿼리 (statement) 기간 | 60 초    | 60 초   |
| 최대 캐시된 쿼리 응답 크기      | 50 마일   | 50 마일  |

최대 기간을 초과하는 쿼리는 종료됩니다. Query 응답 더 큰 50 MB는 캐시 되지 않습니다 하지만 여전히 당신의 노동자에 반환.

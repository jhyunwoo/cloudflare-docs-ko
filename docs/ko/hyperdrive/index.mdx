<Description>
  기존의 지역 데이터베이스를 글로벌 분산 데이터베이스로 전환합니다.
</Description>

<Plan type="workers-all" />

Hyperdrive는 기존 데이터베이스에 만들 수 있는 쿼리를 가속화하는 서비스이며, 전 세계의 데이터에 액세스하는 데 더 빠르게 액세스할 수 있습니다.[CloudflareWorkers](/workers/)사용자의 위치 결정.

Hyperdrive는 AWS, Google Cloud, Azure, Neon 및 PlanetScale에서 호스팅되는 사람들을 포함하여 모든 Postgres 또는 MySQL 데이터베이스를 지원합니다. Hyperdrive는 CockroachDB 및 Timescale와 같은 Postgres 호환 데이터베이스를 지원합니다.
새로운 코드를 작성하거나 좋아하는 도구를 교체 할 필요가 없습니다 : Hyperdrive는 기존 코드와 도구를 사용하여 작동합니다.

Hyperdrive의 연결 문자열을 사용하여 Cloudflare WorkersXQ 응용 프로그램을 사용하여 기존의 Postgres 드라이버 및 객체-relational mapping (ORM) 라이브러리:

        ```ts
        import { Client } from "pg";

        export default {
        	async fetch(request, env, ctx): Promise<Response> {
        		//각 요청에 대한 새로운 클라이언트 인스턴스를 만듭니다. Hyperdrive는 유지합니다
        		//데이터베이스 연결 풀에서 새로운 클라이언트를 만드는 것은 빠릅니다.
        		const client = new Client({
        			connectionString: env.HYPERDRIVE.connectionString,
        		});

        		try {
        			//데이터베이스에 연결
        			await client.connect();
        			//SQL 쿼리
        			const result = await client.query("SELECT * FROM pg_tables");

        			return Response.json(result.rows);
        		} catch (e) {
        			return Response.json({ error: e instanceof Error ? e.message : e }, { status: 500 });
        		}
        	},
        } satisfies ExportedHandler<{ HYPERDRIVE: Hyperdrive }>;
        ```

이 예제는 Hyperdrive를 MySQL 인스턴스의 Azure 데이터베이스에 연결하는 방법을 보여줍니다.

## 1. Hyperdrive 액세스 허용

데이터베이스에 연결하는 Hyperdrive를 허용하려면 Hyperdrive가 유효한 자격 증명 및 네트워크 액세스를 보장해야합니다.

<Render file="public-connectivity" product="hyperdrive" />

### Azure 포털

#### 공공 액세스 네트워킹

공용 인터넷 연결을 사용하여 MySQL 인스턴스에 대한 Azure 데이터베이스에 연결하려면:

1. 내 계정[Azure 포털](https://portal.azure.com/), Hyperdrive를 원하는 인스턴스를 선택하여 연결합니다.
2. 지원하다**계정 설정** > **사업영역**> 보증**본문 바로가기**활성화 >**방화벽 규칙**더 보기`0.0.0.0`이름 \***IP 주소 시작**·`255.255.255.255`이름 \***IP 주소**.
3. 제품정보**제품 정보**당신의 변화에 대해
4. 제품정보**제품정보**측바에서 그리고 주의 아래**Server 이름**귀하의 인스턴스.

사용자 이름, 암호, 서버 이름 및 데이터베이스 이름 (과태:`mysql`), 당신은 지금 Hyperdrive 데이타베이스 윤곽을 창조할 수 있습니다.

#### 개인 액세스 네트워킹

MySQL 인스턴스의 개인 Azure 데이터베이스에 연결하려면, 참조[터널을 사용하여 개인 데이터베이스에 연결](/hyperdrive/configuration/connect-to-private-database/).

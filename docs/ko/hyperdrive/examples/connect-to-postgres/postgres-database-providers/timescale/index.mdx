이 예제는 Hyperdrive를 연결하는 방법을 보여줍니다.[타임 스](https://www.timescale.com/)시간 시리즈 데이터베이스. Timescale는 PostgreSQL에 내장되어 강력한 시간 시리즈, 이벤트 및 분석 기능이 포함되어 있습니다.

Timescale에 대해 자세히 알아볼 수 있습니다.[시간표](https://docs.timescale.com/getting-started/latest/services/).

## 1. Hyperdrive 액세스 허용

Hyperdrive를 새로운 사용자를 만들고 데이터베이스 연결 문자열을 fetching하여 기존 시간대 데이터베이스에 연결할 수 있습니다.

### Timescale 대시보드

:::참조

대부분의 서비스와 마찬가지로 Timescale는 데이터베이스 사용자와 관련된 암호를 재설정해야하므로 안전하게 저장되지 않습니다. 암호를 재설정 할 때 기존 클라이언트를 방해하지 않도록해야합니다.

:::

credentials 및 데이터베이스 엔드포인트를 검색하려면[Timescale 콘솔](https://console.cloud.timescale.com/):

1. Hyperdrive를 원하는 서비스 (database)를 선택하여 연결하십시오.
2. 지원하다**연결 정보**.
3. 제출하기**서비스 URL**. 서비스 URL은 Hyperdrive가 연결하는 연결 문자열입니다. 이 문자열에는 데이터베이스 hostname, 포트 번호 및 데이터베이스 이름을 포함합니다.

비밀번호가 저장되지 않은 경우, 선택해야 할 것입니다.**비밀번호를 잊으셨나요?**&#xADF8;리고 새로운 설정**사이트맵**비밀번호 이 암호를 저장, Timescale로 표시 한 번.

아래를 닮은 연결 문자열로 끝납니다.

```txt
postgres://tsdbadmin:YOUR_PASSWORD_HERE@pn79dztyy0.xzhhbfensb.tsdb.cloud.timescale.com:31358/tsdb
```

연결 문자열을 사용하면 이제 Hyperdrive 데이터베이스 구성을 만들 수 있습니다.

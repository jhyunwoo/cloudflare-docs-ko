이 예제는 Hyperdrive를 연결하는 방법을 보여줍니다.[사이트맵](https://www.cockroachlabs.com/)데이터베이스 클러스터. CockroachDB는 강력한 일관성 보증으로 PostgreSQL 호환 분산 SQL 데이터베이스입니다.

## 1. Hyperdrive 액세스 허용

데이터베이스에 연결하는 Hyperdrive를 허용하려면 Hyperdrive가 유효한 사용자 자격 증명 및 네트워크 액세스를 보장해야합니다.

### CockroachDB 콘솔

아래 단계는 당신이 가지고 가정[기존의 CockroachDB 클라우드 계정](https://www.cockroachlabs.com/docs/cockroachcloud/quickstart)그리고 데이터베이스 클러스터 생성.

작성 및 / 또는 데이터베이스 자격 증명을 fetch:

1. 오시는 길[사이트맵 클라우드 콘솔](https://cockroachlabs.cloud/clusters)Hyperdrive를 원하는 클러스터를 선택합니다.
2. 제품정보**SQL 사용자**왼쪽의 사이드바에서 선택**사용자 정의**.
3. 사용자 이름을 입력 (예를 들어, \`hyperdrive-user), 선택**비밀번호**.
4. 사용자 이름과 비밀번호를 임시 위치로 복사합니다.

데이터베이스 연결 세부 사항을 검색하려면:

1. 오시는 길[사이트맵 클라우드 콘솔](https://cockroachlabs.cloud/clusters)Hyperdrive를 원하는 클러스터를 선택합니다.
2. 제품정보**연결하기**오른쪽 상단에.
3. 예를 들어, 생성된 사용자를 선택합니다.`hyperdrive-user`.
4. 데이터베이스를 선택, 예를 들어`defaultdb`.
5. 제품정보**일반 연결 문자열**옵션으로.
6. 아래 텍스트 상자에, 선택**관련 기사**연결 문자열을 복사합니다.

기본적으로 CockroachDB 클라우드는 공용 인터넷에서 연결을 가능하게합니다 (`0.0.0.0/0`). 기존 클러스터에 이러한 설정을 변경하면 Hyperdrive에 대한 공공 인터넷에서 연결을 허용해야합니다.

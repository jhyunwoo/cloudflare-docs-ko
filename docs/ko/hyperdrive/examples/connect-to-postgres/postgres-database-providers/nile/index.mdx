이 예제는 Hyperdrive를 연결하는 방법을 보여줍니다.[이름 \*](https://thenile.dev)PostgreSQL 데이터베이스 인스턴스.

Nile 이다 PostgreSQL re-engineered 용 멀티-텐트 응용 프로그램. Nile의 가상 테넌트 데이터베이스는 Tenant의 데이터 및 embedding에 대한 고립, 배치, 통찰력 및 기타 기능을 제공합니다. 더 알아보기[Nile 문서](https://www.thenile.dev/docs/getting-started/whatisnile)더 알아보기.

## 1. Hyperdrive 액세스 허용

연결 문자열을 사용하여 작업 공간에서 Cloudflare HyperdriveXQ를 연결하거나 기존 세트를 사용하여 CloudflareXQXQXQXQXQ를 연결할 수 있습니다.

### Nile 콘솔

Nile 콘솔에서 연결 문자열을 얻으려면:

1. 로그인[Nile 콘솔](https://console.thenile.dev), 다음 데이터베이스를 선택합니다.
2. 왼쪽 손 메뉴에서 클릭**계정 설정**(가장 큰 아이콘) 다음 선택**관련 링크**.
3. PostgreSQL 로고를 선택하여 연결 문자열을 표시합니다.
4. 새로운 자격 증명을 생성하기 위해 "Generate credentials"를 선택하십시오.
5. 연결 문자열을 복사 ( "psql"부분없이).

다음과 비슷한 연결 문자열을 얻을 것이다:

```txt
    postgres://0191c898-...:4d7d8b45-...@eu-central-1.db.thenile.dev:5432/my_database
```

연결 문자열을 사용하면 이제 Hyperdrive 데이터베이스 구성을 만들 수 있습니다.

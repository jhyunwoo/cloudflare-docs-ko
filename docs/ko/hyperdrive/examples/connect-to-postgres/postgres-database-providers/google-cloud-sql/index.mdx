이 예제는 Hyperdrive를 Google Cloud SQL Postgres 데이터베이스 인스턴스에 연결하는 방법을 보여줍니다.

## 1. Hyperdrive 액세스 허용

데이터베이스에 연결하는 Hyperdrive를 허용하려면 Hyperdrive가 유효한 사용자 자격 증명 및 네트워크 액세스를 보장해야합니다.

<Render file="public-connectivity" product="hyperdrive" />

### 클라우드 콘솔

인스턴스를 만들 때 또는 기존 인스턴스를 편집할 때[Google 클라우드 콘솔](https://console.cloud.google.com/sql/instances):

Hyperdrive를 허용하여 인스턴스에 도달하십시오.

1. 내 계정[클라우드 콘솔](https://console.cloud.google.com/sql/instances), Hyperdrive를 원하는 인스턴스를 선택합니다.
2. 지원하다**연결하기** > **사업영역**> 보증**공공 IP**설정 >**네트워크 추가**및 입력`0.0.0.0/0`.
3. 제품정보**이름 \*** > **제품 정보**당신의 변화에 대해
4. 제품정보**제품정보**측바에서 그리고 주의 아래**IP 주소**귀하의 인스턴스.

Hyperdrive에 대한 사용자를 만들려면:

1. 제품정보**이름 \***&#xC0AC;이드바에서.
2. 제품정보**사용자 계정 추가**> 선택**내장 인증**.
3. 이름 (예를 들면,`hyperdrive-user`) > 선택**제품 정보**비밀번호 생성
4. 선택하기 전에 클립보드에 이 암호를 복사**더 보기**사용자를 만듭니다.

사용자 이름, 암호, 공개 IP 주소 및 (선택 사항) 데이터베이스 이름 (과태:`postgres`), 당신은 지금 Hyperdrive 데이타베이스 윤곽을 창조할 수 있습니다.

### gcloud 클립

더 보기[gcloud 클립](https://cloud.google.com/sdk/docs/install)새로운 사용자를 만들고 Hyperdrive를 활성화하여 데이터베이스에 연결할 수 있습니다.

제품 정보`gcloud sql`새로운 사용자 만들기 (예를 들면,`hyperdrive-user`) 강한 암호로:

```sh
gcloud sql users create hyperdrive-user --instance=YOUR_INSTANCE_NAME --password=SUFFICIENTLY_LONG_PASSWORD
```

다음 명령을 실행하여 활성화[인터넷 접속](https://cloud.google.com/sql/docs/postgres/configure-ip)데이터베이스 인스턴스에:

```sh
#기존의 공인된 네트워크가 있는 경우, comma 분리된 리스트로 이를 제공합니다.
#gcloud CLI는 여기에 제공하는 목록이있는 기존 공인 네트워크를 대체합니다.
gcloud sql instances patch YOUR_INSTANCE_NAME --authorized-networks="0.0.0.0/0"
```

더 알아보기[Google Cloud의 문서](https://cloud.google.com/sql/docs/postgres/create-manage-users)추가 구성 옵션.

이 예제는 Amazon Relational Database Service (Amazon RDS) Postgres 또는 Amazon Aurora 데이터베이스 인스턴스에 HyperdriveXQ를 연결하는 방법을 보여줍니다.

## 1. Hyperdrive 액세스 허용

데이터베이스에 연결하는 Hyperdrive를 허용하려면 Hyperdrive가 유효한 사용자 자격 증명 및 네트워크 액세스를 보장해야합니다.

### AWS 콘솔

AWS 콘솔에서 인스턴스를 생성하거나 수정할 때:

1. 설정하기**DB 클러스터 식별자**사용자 정의하려는 다른 설정.
2. 이름 \***계정 설정** > **Credential 설정**, 주의 아래**사용자 이름**·**마스터 암호**(Aurora 전용).
3. 이름 \***연결성**헤더, 보증**본문 바로가기**설정**이름 \***.
4. 자주 묻는 질문**기존 VPC 보안 그룹**그것은 공공 인터넷 액세스를 허용`0.0.0.0/0`데이터베이스 인스턴스를 포트로 설정하면 (과태:`5432`PostgreSQL 인스턴스의 경우).
5. 제품정보**데이터베이스**.

## 2. 사용자 만들기

데이터베이스가 생성되면 Hyperdrive에 대한 사용자를 만들 필요가 있습니다. 사용할 수 있지만**사용자 이름**초기 데이터베이스 생성 중 구성, 최고의 연습은 덜 권한 사용자를 만들 것입니다.

새로운 사용자를 만들려면 데이터베이스에 로그인하고 사용`CREATE ROLE`명령:

```sh
#데이터베이스에 로그인
psql postgresql://MASTER_USERNAME:MASTER_PASSWORD@ENDPOINT_NAME:PORT/database_name
```

다음 SQL 문 실행:

```sql
-- Create a role for Hyperdrive
CREATE ROLE hyperdrive;

-- Allow Hyperdrive to connect
GRANT CONNECT ON DATABASE postgres TO hyperdrive;

-- Grant database privileges to the hyperdrive role
GRANT ALL PRIVILEGES ON DATABASE postgres to hyperdrive;

-- Create a specific user for Hyperdrive to log in as
CREATE ROLE hyperdrive_user LOGIN PASSWORD 'sufficientlyRandomPassword';

-- Grant this new user the hyperdrive role privileges
GRANT hyperdrive to hyperdrive_user;
```

AWS에 Refer[PostgreSQL의 사용자 역할에 대한 문서](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/Appendix.PostgreSQL.CommonDBATasks.Roles.html)더 많은 정보.

데이터베이스 사용자, 암호, 데이터베이스 엔드포인트(hostname and port) 및 데이터베이스 이름(default:`postgres`), 당신은 지금 HyperdriveXQ를 설치해서 좋습니다.

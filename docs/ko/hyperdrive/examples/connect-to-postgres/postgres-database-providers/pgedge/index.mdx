이 예제는 Hyperdrive를 연결하는 방법을 보여줍니다.[뚱 베어](https://pgedge.com/)Postgres 데이터베이스. pgEdge Cloud는 완전 관리, 완전 분산, 안전한 Postgres의 쉬운 배포를 제공합니다.

## 1. Hyperdrive 액세스 허용

pgEdge가 제공하는 기본 사용자 및 암호로 Hyperdrive를 기존 pgEdge 데이터베이스에 연결할 수 있습니다.

### 모델 번호: 대시보드

pgEdge 대시보드에서 연결 문자열을 검색하려면:

1. 오시는 길[**모델 번호: 대시보드**](https://app.pgedge.com)연결하려는 데이터베이스를 선택합니다.
2. 에 의해**데이터베이스에 연결**섹션, 연결 문자열을 아래 (starting with`postgres://app@...`) 에서**연결 문자열**텍스트 상자.

이 예제는 Hyperdrive를 연결하는 방법을 보여줍니다.[스파베이스](https://supabase.com/)Postgres 데이터베이스.

## 1. Hyperdrive 액세스 허용

Hyperdrive를 프로젝트 생성 중에 설정되는 Postgres 사용자로 기존의 Supabase 데이터베이스에 연결할 수 있습니다.
대안으로, Hyperdrive에 대한 새로운 사용자를 만들기 위해, 이 명령을 실행[SQL 편집기](https://supabase.com/dashboard/project/_/sql/new).

```sql
CREATE ROLE hyperdrive_user LOGIN PASSWORD 'sufficientlyRandomPassword';

-- Here, you are granting it the postgres role. In practice, you want to create a role with lesser privileges.
GRANT postgres to hyperdrive_user;
```

데이터베이스 엔드포인트에서 찾을 수 있습니다.[Database 설정 페이지](https://supabase.com/dashboard/project/_/settings/database).

데이터베이스 사용자, 암호, 데이터베이스 엔드포인트 (hostname 및 포트) 및 데이터베이스 이름 (기본: postgres)를 사용하면 이제 HyperdriveXQ를 설정할 수 있습니다.

:::참조

Hyperdrive에서 Supabase에 연결할 때, 당신은 사용해야 합니다**직접 연결**연결 문자열 오히려 풀 연결 문자열. Hyperdrive는 WorkersXQ에서 최적의 액세스를 보장하기 위해 연결 풀링을 수행합니다.

:::

이 예제는 Hyperdrive를 Fly Postgres 데이터베이스 인스턴스에 연결하는 방법을 보여줍니다.

## 1. Hyperdrive 액세스 허용

Hyperdrive를 기존 Fly 데이터베이스에 연결할 수 있습니다.

1. 공중 IP 주소를 Fly Database 인스턴스에 할당
2. 외부 서비스 구성
3. 설정 배포
4. Hyperdrive에 데이터베이스를 연결하는 데 사용되는 연결 문자열을 가져옵니다.

<Steps>
  1) 다음 명령을 실행[IP 주소 할당](https://fly.io/docs/postgres/connecting/connecting-external/#allocate-an-ip-address).

     ```txt
     fly ips allocate-v6 --app <pg-app-name>
     ```

     :::참조
     Cloudflare는 IPv6를 사용하여 권장하지만 일부 인터넷 서비스 제공 업체는 IPv6를 지원하지 않을 수 있습니다. 이 경우,[IPv4 주소를 할당할 수 있습니다.](https://fly.io/docs/postgres/connecting/connecting-with-flyctl/).
     :::

  2) [외부 서비스 구성](https://fly.io/docs/postgres/connecting/connecting-external/#configure-an-external-service)본문내용 바로가기`fly.toml`파일. 다음 명령을 실행하여 다운로드`fly.toml`파일.

     ```txt
     fly config save --app <pg-app-name>
     ```

     그런 다음`services`·`services.ports`다음 파일의 섹션`toml`스니펫:

     ```toml
     [[services]]
     	internal_port = 5432 # Postgres instance
     	protocol = "tcp"

     [[services.ports]]
     	handlers = ["pg_tls"]
     	port = 5432
     ```

  3) [새로운 구성 배포](https://fly.io/docs/postgres/connecting/connecting-external/#deploy-with-the-new-configuration).

  4) [연결 문자열을 얻기](https://fly.io/docs/postgres/connecting/connecting-external/#adapting-the-connection-string), 의 형태로:

     ```txt
     postgres://{username}:{password}@{public-hostname}:{port}/{database}?options
     ```
</Steps>

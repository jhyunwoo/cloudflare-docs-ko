[프리즈마 ORM](https://www.prisma.io/docs)Node.js 및 TypeScript ORM은 유형 안전 및 개발자 경험에 초점입니다. 이 예제는 Cloudflare HyperdriveXQXQXQ를 통해 PostgreSQL과 Prisma ORM을 사용하는 방법을 설명합니다.

## 자주 묻는 질문

- Cloudflare 계정 Workers 액세스
- PostgreSQL 데이터베이스 (예 :[Prisma 포스터](https://www.prisma.io/postgres))
- ·[당신의 PostgreSQL 데이터베이스에 Hyperdrive 구성](/hyperdrive/get-started/#3-connect-hyperdrive-to-a-database)
- 현재 위치[Worker 프로젝트](/workers/get-started/guide/)

## 2. Prisma ORM 구성

### 2.1. Prisma를 초기화

응용 프로그램에 Prisma를 초기화 :

```sh
npx prisma init
```

이 생성`prisma`폴더와`schema.prisma`파일 및`.env`파일.

### 2.2. 스키마를 정의

데이터베이스 schema를 정의`prisma/schema.prisma`파일 :

```prisma title="prisma/schema.prisma"
generator client {
  provider        = "prisma-client-js"
  previewFeatures = ["driverAdapters"]
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

model User {
  id        Int      @id @default(autoincrement())
  name      String
  email     String   @unique
  createdAt DateTime @default(now())
}
```

### 2.3. 환경 변수 설정

데이터베이스 연결 문자열을 추가`.env`Prisma에 의해 생성 된 파일:

```txt title=".env"
DATABASE_URL="postgres://user:password@host:port/database"
```

helper 스크립트 추가`package.json`:

```json title="package.json"
"scripts": {
  "migrate": "npx prisma migrate dev",
  "generate": "npx prisma generate --no-engine",
  "studio": "npx prisma studio"
}
```

### 2.4. Prisma 클라이언트 생성

드라이버 어댑터 지원 Prisma 클라이언트 생성 :

```sh
npm run generate
```

### 2.5. 이동 실행

생성 및 데이터베이스 schema 적용:

```sh
npm run migrate
```

신속한 경우 마이그레이션의 이름을 제공합니다 (예를 들어,`init`).

## 3. Prisma ORM을 Hyperdrive에 연결하십시오

Prisma ORM을 사용할 때 Hyperdrive 구성을 사용하십시오. 업데이트`src/index.ts`파일 :

```ts title="src/index.ts"
import { PrismaPg } from "@prisma/adapter-pg";
import { PrismaClient } from "@prisma/client";

export interface Env {
	HYPERDRIVE: Hyperdrive;
}

export default {
	async fetch(request, env, ctx): Promise<Response> {
		//Hyperdrive 연결 문자열로 드라이버 어댑터를 사용하여 Prisma 클라이언트 만들기
		const adapter = new PrismaPg({ connectionString: env.HYPERDRIVE.connectionString });
		const prisma = new PrismaClient({ adapter });

		//샘플 쿼리 생성 및 fetch 사용자
		const user = await prisma.user.create({
			data: {
				name: "John Doe",
				email: `john.doe.${Date.now()}@example.com`,
			},
		});

		const allUsers = await prisma.user.findMany();

		return Response.json({
			newUser: user,
			allUsers: allUsers,
		});
	},
} satisfies ExportedHandler<Env>;
```

:::참조

HyperdriveXQ와 Prisma ORM을 사용할 때, 당신은 Hyperdrive 연결 문자열을 제대로 활용하기 위해 드라이버 어댑터를 사용해야합니다. 더 보기`@prisma/adapter-pg`드라이버 어댑터는 Prisma ORM을 사용하여 작업 할 수 있습니다.`pg`드라이버 및 Hyperdrive의 연결 풀링. 이 접근법은 Hyperdrive를 통해 네트워크 수준에서 풀링을 제공하므로 Prisma 별 연결 풀링 확장이 필요 없습니다.

:::

[건조 ORM](https://orm.drizzle.team/)유형 안전에 초점과 경량 TypeScript ORM입니다. 이 예제는 Cloudflare HyperdriveXQXQXQ를 통해 PostgreSQL과 Drizzle ORM을 사용하는 방법을 설명합니다.

## 자주 묻는 질문

- Cloudflare 계정 Workers 액세스
- PostgreSQL 데이터베이스
- ·[당신의 PostgreSQL 데이터베이스에 Hyperdrive 구성](/hyperdrive/get-started/#3-connect-hyperdrive-to-a-database)

## 1. Drizzle 설치

Drizzle ORM과 같은 의존성을 설치하십시오.[노드-postgres](https://node-postgres.com/) (`pg`) 운전사:

```sh
npm i drizzle-orm pg dotenv
npm i -D drizzle-kit tsx @types/pg @types/node
```

필요한 Node.js 호환성 플래그 및 Hyperdrive 바인딩을 추가하십시오`wrangler.jsonc`파일 :

## 2. Drizzle 구성

### 2.1. 스키마 정의

Drizzle ORM으로, 우리는 TypeScript의 스키마를 정의합니다.

<Steps>
  1. 폴더 만들기`/db/`내 계정`/src/`.
  2. 이름 \*`schema.ts`파일.
  3. 내 계정`schema.ts`, 정의`users`아래와 같이 표.

     ```ts title="src/db/schema.ts"
     //src/db/schema.ts의 경우
     import { pgTable, serial, varchar, timestamp } from "drizzle-orm/pg-core";

     export const users = pgTable("users", {
     	id: serial("id").primaryKey(),
     	name: varchar("name", { length: 255 }).notNull(),
     	email: varchar("email", { length: 255 }).notNull().unique(),
     	createdAt: timestamp("created_at").defaultNow(),
     });
     ```
</Steps>

### 2.2. Hyperdrive를 가진 데이타베이스에 Drizzle ORM를 연결하십시오

Drizzle ORM을 사용할 때 데이터베이스의 Hyperdrive 구성을 사용하십시오.

감사합니다.`index.ts`아래에 표시된 것과 같이 파일.

```ts title="src/index.ts"
//프로젝트
import { Client } from "pg";
import { drizzle } from "drizzle-orm/node-postgres";
import { users } from "./db/schema";

export interface Env {
	HYPERDRIVE: Hyperdrive;
}

export default {
	async fetch(request, env, ctx): Promise<Response> {
		//각 요청에 대한 새로운 클라이언트 인스턴스를 만듭니다.
		const client = new Client({
			connectionString: env.HYPERDRIVE.connectionString,
		});

		//데이터베이스에 연결
		await client.connect();

		//node-postgres 연결을 통해 Drizzle 클라이언트 생성
		const db = drizzle(client);

		//모든 사용자를 얻기 위해 샘플 쿼리
		const allUsers = await db.select().from(users);

		return Response.json(allUsers);
	},
} satisfies ExportedHandler<Env>;
```

:::참조
사용 가능[노드-postgres](https://orm.drizzle.team/docs/get-started-postgresql#node-postgres)또는[다운로드](https://orm.drizzle.team/docs/get-started-postgresql#postgresjs)Drizzle ORM을 사용할 때. 둘 다 지원되고 호환이 됩니다.

### 2.3. 이동을 위한 Drizzle-Kit 구성 (선택 사항)

:::참조
데이터베이스에서 테이블을 설정해야하므로 Drizzle ORM은 작업 쿼리를 만들 수 있습니다.

이미 설정한 경우 (예를 들어, 다른 사용자가 데이터베이스에 스키마를 적용한 경우) 또는 Drizzle ORM을 사용하고 스키마는 데이터베이스에 이미 존재하는 것과 일치하는 경우 마이그레이션을 실행할 필요가 없습니다.
주요 특징

Drizzle Kit CLI를 사용하여 스키마를 기반으로 데이터베이스에 SQL 마이그레이션을 생성하고 실행할 수 있습니다. 더 알아보기[Drizzle ORM 문서](https://orm.drizzle.team/docs/get-started/postgresql-new)추가지도.

<Steps>
  1. 이름 \*`.env`프로젝트의 루트 폴더를 파일하고 데이터베이스 연결 문자열을 추가합니다. Drizzle Kit CLI는 이 연결 문자열을 사용하여 마이그레이션을 만들고 적용합니다.

     ```toml title=".env"
     # .env
     # Replace with your direct database connection string
     DATABASE_URL='postgres://user:password@db-host.cloud/database-name'
     ```

  2. 이름 \*`drizzle.config.ts`프로젝트의 루트 폴더에 파일은 Drizzle Kit을 구성하고 다음 내용을 추가합니다.

     ```ts title="drizzle.config.ts"
     //파일 형식
     import "dotenv/config";
     import { defineConfig } from "drizzle-kit";
     export default defineConfig({
     	out: "./drizzle",
     	schema: "./src/db/schema.ts",
     	dialect: "postgresql",
     	dbCredentials: {
     		url: process.env.DATABASE_URL!,
     	},
     });
     ```

  3. 귀하의 스키마 파일에 따라 데이터베이스에 대한 마이그레이션 파일을 생성하고 데이터베이스에 마이그레이션을 적용합니다.

     다음 두 개의 명령을 실행:

     ```bash
     npx drizzle-kit generate
     ```

     ```bash output
     No config path provided, using default 'drizzle.config.ts'
     Reading config file 'drizzle.config.ts'
     1 tables
     users 4 columns 0 indexes 0 fks

     [✓] Your SQL migration file ➜ drizzle/0000_mysterious_queen_noir.sql 🚀
     ```

     ```bash
     npx drizzle-kit migrate
     ```

     ```bash output
     No config path provided, using default 'drizzle.config.ts'
     Reading config file 'drizzle.config.ts'
     Using 'postgres' driver for database querying
     ```
</Steps>

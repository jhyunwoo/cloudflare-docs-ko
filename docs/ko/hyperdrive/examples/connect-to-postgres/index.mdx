Hyperdrive는 PostgreSQL 및 PostgreSQL 호환 데이터베이스를 지원합니다.[인기 드라이버](#supported-drivers)그리고 Object Relational Mapper(ORM) 라이브러리를 사용하여 그 드라이버를 사용합니다.

## Hyperdrive

:::참조

Hyperdrive에 새로운? 더 알아보기[자주 묻는 질문](/hyperdrive/get-started/)첫 번째 Hyperdrive를 설정하는 방법을 배우십시오.

:::

기존 PostgreSQL 데이터베이스에 연결하는 Hyperdrive를 생성하려면[채용정보](/workers/wrangler/install-and-update/)CLI 또는[Cloudflare 대시보드](https://dash.cloudflare.com/?to=/:account/workers/hyperdrive).

wrangler를 사용할 때, placeholder 값을 다음과 같이 대체합니다.`--connection-string`데이터베이스에 대한 연결 문자열:

```sh
#wrangler v3.11 이상 필요
npx wrangler hyperdrive create my-first-hyperdrive --connection-string="postgres://user:password@database.host.example.com:5432/databasenamehere"
```

위의 명령은 Hyperdrive의 ID를 출력합니다.[Wrangler 구성 파일](/workers/wrangler/configuration/)당신의 Workers 프로젝트를 위해:

<Render file="hyperdrive-node-compatibility-requirement" product="hyperdrive" />

이것은 Hyperdrive를 허용하여 기존 데이터베이스 드라이버로 전달할 수 있는 작업자의 동적 연결 문자열을 생성합니다. 더 알아보기[드라이버 예제](#driver-examples)Hyperdrive로 데이터베이스 드라이버를 설정하는 방법을 배우려면.

더 알아보기[예제 문서](/hyperdrive/examples/)몇 가지 인기있는 데이터베이스 제공 업체와 Hyperdrive를 설정하는 방법에 대한 단계별 가이드.

## 지원된 운전사

Hyperdrive는 Workers를 이용합니다[TCP 소켓 지원](/workers/runtime-apis/tcp-sockets/#connect)데이터베이스에 TCP 연결을 지원합니다. 다음 테이블은 지원된 데이터베이스 드라이버와 Hyperdrive와 함께 작동하는 최소 버전을 나열합니다.

| 노드 포스트 -`pg`(추천)                                   | [노드 포스트 -`pg`관련 기사](https://node-postgres.com/)               | `pg@8.13.0`      | `8.11.4`URL 파싱과 버그를 도입하고 작동하지 않습니다.`8.11.5`이 수정. 문의 사항`compatibility_flags = ["nodejs_compat"]`·`compatibility_date = "2024-09-23"`- 참고[Node.js 호환성](/workers/runtime-apis/nodejs). wrangler 요구`3.78.7`또는 나중에. |

## Hyperdrive의 연결을 식별

Hyperdrive에서 Postgres 데이터베이스 서버에 대한 활성 연결을 식별하려면:

- Hyperdrive의 데이터베이스에 연결하면`Cloudflare Hyperdrive`으로`application_name`내 계정`pg_stat_activity`테이블.
- 지원하다`SELECT DISTINCT usename, application_name FROM pg_stat_activity WHERE application_name = 'Cloudflare Hyperdrive'`Hyperdrive가 현재 데이터베이스에 연결 (또는 연결)을 열지 여부를 보여줍니다.

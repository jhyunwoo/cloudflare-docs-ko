Hyperdrive는 Cloudflare QXWorkersXQ에서 기존 데이터베이스에 액세스 할 수 있으며 단일 등록 데이터베이스가 글로벌 배포됩니다.

Cloudflare의 네트워크 내에서 데이터베이스에 연결 풀을 유지함으로써 HyperdriveXQ는 쿼리를 보낼 수 있기 전에 데이터베이스에 7 라운드 스트립을 줄입니다. TCP Handhake (1x), TLS 협상 (3x) 및 데이터베이스 인증 (3x).

Hyperdrive는 데이터베이스에 읽기와 쓰기 쿼리의 차이를 이해하고 가장 일반적인 읽기 쿼리를 캐시하고 성능 향상 및 원산지 데이터베이스에 부하를 줄입니다.

이 가이드는 당신을 통해 지시합니다:

- 당신의 첫번째 Hyperdrive 윤곽을 창조하십시오.
- 구매하기[모델 번호: Cloudflare 작업자](/workers/)그리고 당신의 Hyperdrive 윤곽에 그것을 바인딩하십시오.
- 작업자에서 공공 데이터베이스에 데이터베이스 연결을 설치합니다.

:::참조

Hyperdrive는 현재 PostgreSQL, MySQL 및 많은 호환 데이터베이스와 함께 작동합니다. CockroachDB 및 Materialize (PostgreSQL 호환) 및 PlanetScale가 포함되어 있습니다.

더 알아보기[Hyperdrive 지원 데이터베이스](/hyperdrive/reference/supported-databases-and-features).

:::

## 자주 묻는 질문

시작하기 전에 다음을 완료했습니다.

1. 로그인[Cloudflare 계정](https://dash.cloudflare.com/sign-up/workers-and-pages)이미 없다면.
2. 설치하기[`Node.js`](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm). Node version Manager를 사용하여[사이트맵](https://github.com/nvm-sh/nvm)또는[볼트](https://volta.sh/)허가 문제를 방지하고 Node.js 버전을 변경하십시오.[모델 번호: Wrangler](/workers/wrangler/install-and-update/)Node 버전이 필요합니다.`16.17.0`또는 나중에.
3. publicly access PostgreSQL 또는 MySQL (또는 호환) 데이터베이스가 있습니다.*데이터베이스가 개인 네트워크에 있는지 (VPC와 동일)*, 참조[개인 데이터베이스에 연결](/hyperdrive/configuration/connect-to-private-database/)Cloudflare 터널을 사용하여 HyperdriveQXQ.

## 3. Hyperdrive를 데이터베이스에 연결하십시오

Hyperdrive는 당신의 데이타베이스, 풀링 데이터베이스 연결에 연결하여 작동하며, CloudflareXQ의 네트워크를 통해 데이터베이스 액세스를 가속화합니다.

Hyperdrive를 통해 데이터베이스에 연결할 수 있는 Worker에서만 접근할 수 있는 안전한 연결 문자열을 제공할 것입니다.
이것은 Hyperdrive 연결 문자열을 기존 드라이버 또는 ORM 라이브러리를 사용하여 코드를 크게 변경할 필요가 없습니다.

첫 번째 Hyperdrive 데이터베이스 구성을 만들려면 Workers 프로젝트를 위해 만든 디렉토리로 변경하십시오.

```sh
cd hyperdrive-tutorial
```

당신의 첫번째 HyperdriveXQ를 창조하기 위하여, 당신은 필요로 할 것입니다:

- IP 주소 (또는 호스트 이름) 및 데이터베이스의 포트.
- 데이터베이스 사용자 이름 (예를 들어,`hyperdrive-demo`).
- 사용자 이름과 관련된 비밀번호.
- Hyperdrive를 원하는 데이터베이스의 이름은 연결합니다. 예를 들어,`postgres`또는`mysql`.

Hyperdrive는 데이터베이스 드라이버에 의해 사용되는 일반적인 연결 문자열 형식의 이러한 매개 변수의 조합을 허용:

    ```txt
    postgres://USERNAME:PASSWORD@HOSTNAME_OR_IP_ADDRESS:PORT/database_name

    ```

    ```sh
    npx wrangler hyperdrive create <YOUR_CONFIG_NAME> --connection-string="postgres://user:password@HOSTNAME_OR_IP_ADDRESS:PORT/database_name"
    ```

### 작업자 쓰기

<Tabs>
  <TabItem label="프로젝트">
    데이터베이스를 설정 한 후 작업자 내에서 SQL 쿼리를 실행합니다.

    로그인`hyperdrive-tutorial`노동자와 열려있는`index.ts`파일.

    더 보기`index.ts`파일은 Hyperdrive로 작업자의 상호 작용을 구성하는 곳입니다.

    감사합니다.`index.ts`다음 코드 파일 :

    ```typescript
    //pg 8.13.0 이상 권장
    import { Client } from "pg";

    export interface Env {
    	//Wrangler config 파일의 이름을 'binding'의 값으로 설정하면
    	//정의된 변수 이름과 "HYPERDRIVE"를 대체합니다.
    	HYPERDRIVE: Hyperdrive;
    }

    export default {
    	async fetch(request, env, ctx): Promise<Response> {
    		//각 요청에 새로운 클라이언트를 만듭니다. Hyperdrive는 underlying를 유지합니다
    		//데이터베이스 연결 풀, 그래서 새로운 클라이언트를 만드는 것은 빠릅니다.
    		const sql = new Client({
    			connectionString: env.HYPERDRIVE.connectionString,
    		});

    		try {
    			//데이터베이스에 연결
    			await sql.connect();

    			//샘플 쿼리
    			const results = await sql.query(`SELECT * FROM pg_tables`);

    			//JSON으로 결과를 반환합니다.
    			return Response.json(results.rows);
    		} catch (e) {
    			console.error(e);
    			return Response.json(
    				{ error: e instanceof Error ? e.message : e },
    				{ status: 500 },
    			);
    		}
    	},
    } satisfies ExportedHandler<Env>;
    ```

    요청에 따라 위의 코드는 다음과 같습니다.

    1. Hyperdrive 연결 문자열을 사용하여 데이터베이스에 연결하는 새로운 데이터베이스 클라이언트를 만듭니다.
    2. 자주 묻는 질문`await sql.query()`데이터베이스에서 모든 테이블 (사용자 및 시스템 생성)를 출력 (예를 들어 쿼리).
    3. JSON을 클라이언트로 반환합니다. Hyperdrive는 요청이 종료될 때 클라이언트 연결을 자동으로 청소하고 재사용을 위한 그것의 수영장에서 열리는 underlying 데이타베이스 연결을 유지합니다.
  </TabItem>

  <TabItem label="기본 정보">
    데이터베이스를 설정 한 후 작업자 내에서 SQL 쿼리를 실행합니다.

    ```typescript
    import { createConnection  } from 'mysql2/promise';

    export interface Env {
      //Wrangler config 파일의 이름을 'binding'의 값으로 설정하면
      //정의된 변수 이름과 "HYPERDRIVE"를 대체합니다.

    }

    export default {
     async fetch(request, env, ctx): Promise<Response> {

    		//각 요청에 대한 새로운 연결 만들기. Hyperdrive는 underlying를 유지합니다

    		const connection = await createConnection({
    			host: env.HYPERDRIVE.host,
    			user: env.HYPERDRIVE.user,
    			password: env.HYPERDRIVE.password,
    			database: env.HYPERDRIVE.database,
    			port: env.HYPERDRIVE.port,

    			//다음 라인은 WorkersXQXQ와 mysql2 호환성에 필요합니다.
    			//mysql2는 eval()을 사용하여 행의 결과를 최적화합니다. > 100 열
    			//disableEval 대신 정적 파싱을 사용하려면 mysql2를 구성하십시오.
    			disableEval: true
    		});

    		try{
    			//샘플 쿼리
    			const [results, fields] = await connection.query(
    				'SHOW tables;'
    			);

    			//JSON으로 결과를 반환합니다.
    			return new Response(JSON.stringify({ results, fields }), {
    				headers: {
    					'Content-Type': 'application/json',
    					'Access-Control-Allow-Origin': '*',
    				},
    			});
    		}
    		catch(e){
    			console.error(e);
    			return Response.json(
    				{ error: e instanceof Error ? e.message : e },
    				{ status: 500 },
    			);
    		}

     },
    } satisfies ExportedHandler<Env>;
    ```

### 개발 모드에서 실행 (옵션)

작업자를 로컬로 테스트할 수 있습니다.`wrangler dev`. 이것은 당신의 데이타베이스에 연결하는 동안 당신의 기계에 노동자 부호를 달립니다.

더 보기`localConnectionString`필드는 로컬 및 원격 데이터베이스와 함께 작동하며 로컬에서 작업자 프로젝트에서 데이터베이스에 직접 연결할 수 있습니다. 필요한 경우 SSL/TLS 모드를 지정해야 합니다 (`sslmode=require`Postgres에 대해`sslMode=REQUIRED`MySQL의 경우).

로컬 개발 중에 데이터베이스에 연결하려면 구성`localConnectionString`내 계정`wrangler.jsonc`:

```jsonc
{
	"hyperdrive": [
		{
			"binding": "HYPERDRIVE",
			"id": "your-hyperdrive-id",
			"localConnectionString": "postgres://user:password@your-database-host:5432/database",
		},
	],
}
```

또는 환경 변수를 설정:

```sh
export CLOUDFLARE_HYPERDRIVE_LOCAL_CONNECTION_STRING_HYPERDRIVE="postgres://user:password@your-database-host:5432/database"
```

다음 로컬 개발 시작:

```sh
npx wrangler dev
```

:::참조

사용 방법`wrangler dev`이름 \*`localConnectionString`또는`CLOUDFLARE_HYPERDRIVE_LOCAL_CONNECTION_STRING_HYPERDRIVE`, Hyperdrive 캐싱은 국부적으로 효력을 가지고 있지 않습니다.

대안으로, 당신은 실행할 수 있습니다`wrangler dev --remote`배치 된 Hyperdrive 구성에 대한 테스트가 활성화되었지만 로컬 대신 Cloudflare의 네트워크에서 전체 작업기를 실행합니다.

더 알아보기[Hyperdrive](/hyperdrive/configuration/local-development/).

:::

## 6. 작업자를 배포

이제 Worker를 배포하여 인터넷에 접근할 수 있습니다. 노동자를 배포하려면, 실행:

```sh
npx wrangler deploy
#산출: https://hyperdrive-tutorial.<YOUR_SUBDOMAIN>.workers.dev
```

새로 생성 된 프로젝트에 대한 URL을 방문하여 라이브 데이터베이스를 쿼리 할 수 있습니다.

예를 들어, 새로운 노동자의 URL이 있다면`hyperdrive-tutorial.<YOUR_SUBDOMAIN>.workers.dev`, 접속`https://hyperdrive-tutorial.<YOUR_SUBDOMAIN>.workers.dev/`데이터베이스를 직접 쿼리하는 작업자에게 요청을 보낼 것입니다.

이 튜토리얼을 완료하면 Hyperdrive 구성을 생성하고, 작업자는 데이터베이스에 액세스하고 글로벌 프로젝트를 배포했습니다.

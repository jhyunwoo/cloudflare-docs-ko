## 지원된 데이터베이스 공급자

Hyperdrive는 AWS, Azure 및 GCP를 포함한 다양한 공급자가 제공하는 관리형 Postgres 및 MySQL 데이터베이스를 지원합니다. 더 알아보기[이름 \*](/hyperdrive/examples/connect-to-postgres/)다양한 데이터베이스 공급자에 연결하는 방법을 참조하십시오.

Hyperdrive 또한 Postgres 또는 MySQL 프로토콜과 호환되는 데이터베이스를 지원합니다. 다음은 Postgres 또는 MySQL 호환 데이터베이스 제공 업체의 비 배출 목록입니다.

## 지원된 TLS (SSL) 형태

Hyperdrive는 뒤에 오는 것을 지원합니다[PostgreSQL의 TLS (SSL)](https://www.postgresql.org/docs/current/libpq-ssl.html)연결 모드 당신의 기원 데이터베이스에 연결:

| 주요 특징         | 지원되는              | 이름 \*                                                                    |
| ------------- | ----------------- | ------------------------------------------------------------------------ |
| `none`        | 이름 \*             | Hyperdrive는 insecure 일반 텍스트 연결을 지원하지 않습니다.                               |
| `prefer`      | 없음 (사용)`require`) | Hyperdrive는 항상 TLS를 사용합니다.                                               |
| `require`     | 그렇습니다 (과태)        | TLS는 필수이며, 서버 인증서는 WebPKI에 따라 검증됩니다.                                     |
| `verify-ca`   | 이름 \*             | 서버의 TLS 인증서는 클라이언트의 루트 CA에 의해 서명됩니다. 이 서버는 클라이언트의 신뢰를 인증합니다.             |
| `verify-full` | 이름 \*             | 본문 바로가기`verify-ca`, 또한 데이터베이스 호스트 이름은 인증서에 존재하는 제목 대체 이름 (SAN)과 일치해야합니다. |

더 알아보기[SSL/TLS 인증서](/hyperdrive/configuration/tls-ssl-certificates-for-hyperdrive/)구성하는 방법`verify-ca`또는`verify-full`Hyperdrive를 위한 TLS (SSL) 형태.
:::참조

Hyperdrive 지원`verify-ca`·`verify-full`MySQL은 사용할 수 없습니다 (beta).

:::

## PostgreSQL 인증 모드 지원

Hyperdrive는 뒤에 오는 것을 지원합니다[인증 모드](https://www.postgresql.org/docs/current/auth-methods.html)PostgreSQL 데이터베이스에 연결하기:

- 비밀번호 인증`md5`)
- 비밀번호 인증`password`) (clear 원본 암호)
- SASL 인증`SCRAM-SHA-256`)

## 지원되지 않은 PostgreSQL 기능:

Hyperdrive는 다음과 같은 PostgreSQL 기능을 지원하지 않습니다.

- SQL-level 관리와 같은 준비된 진술`PREPARE`, `DISCARD`, `DEALLOCATE`, 또는`EXECUTE`.
- 자문 잠금 (advisory locks)[PostgreSQL 문서](https://www.postgresql.org/docs/current/explicit-locking.html#ADVISORY-LOCKS)).
- `LISTEN`·`NOTIFY`.
- `PREPARE`·`DEALLOCATE`.
- 다른 곳에서 지원되지 않은 영구적 인 상태에 대한 수정.

## 지원되는 MySQL 특징:

Hyperdrive는 다음과 같은 MySQL 기능을 지원하지 않습니다.

- 쿼리의 Non-UTF8 문자
- `USE`이름 \*
- 다중 상태 쿼리
- SQL (using)을 통해 계산 된 성명 쿼리`PREPARE`·`EXECUTE`성명) 및[Protocol-level 준비된 문](https://sidorares.github.io/node-mysql2/docs/documentation/prepared-statements).
- `COM_INIT_DB`이름 \*
- [인증 플러그인](https://dev.mysql.com/doc/refman/8.4/en/authentication-plugins.html)다른 것 보다는`caching_sha2_password`또는`mysql_native_password`

Hyperdrive 팀은 Hyperdrive없이 두 번째를 설정하는 것이 좋습니다.

Hyperdrive에 대한 가장 일반적으로 묻는 질문에 대한 답변을 찾을 수 있습니다.

## 연결성

### Hyperdrive는 특정 IP 주소를 사용하여 데이터베이스에 연결합니까?

Hyperdrive는 데이터베이스에 연결[Cloudflare의 IP 주소 범위](https://www.cloudflare.com/ips/). 이들은 모든 Hyperdrive 윤곽 및 다른 Cloudflare 제품에 의해 공유됩니다.

데이터베이스 방화벽에서 제한을 구성하려면 데이터베이스에 액세스할 수 있는 IP 주소를 제한할 수 있습니다.

### Hyperdrive 지원은 D1 데이터베이스에 연결합니까?

Hyperdrive는 지원하지 않습니다[모델 번호: D1](/d1)D1는 디자인에 의하여 Workers에서 빠른 연결을 제공합니다.

Hyperdrive는 PostgreSQL과 같은 기존의 지역 SQL 데이터베이스에 대한 연결을 가속화하도록 설계되었습니다. 이 데이터베이스는 일반적으로 TCP/IP를 통해 통신하는 데이터베이스 드라이버를 사용하여 액세스됩니다.
D1와는 달리, 전통적인 SQL 데이타베이스에 안전한 데이타베이스 연결을 만드는
클라이언트 (당신의 노동자)와 데이터베이스 서버 간의 여러 라운드 여행을 포함합니다.
이름 \*[Hyperdrive는 어떻게 작동합니까?](/hyperdrive/concepts/how-hyperdrive-works/)왜 둥근 여행이 필요한지에 대한 자세한 내용은
그리고 Hyperdrive는 어떻게 이것을 해결합니다.

D1는 데이터베이스 연결을 만들 수있는 둥근 여행이 필요하지 않습니다. D1는 HyperdriveXQ가 기본적으로 Workers에서 접근을 위해 실행되도록 설계되었습니다.

### Hyperdrive로 배치를 사용해야합니까?

예, 노동자가 요청당 여러 쿼리를 만들 경우.[회사연혁](/workers/configuration/placement/)데이터베이스 근처에 작업자를 실행하여 20-30ms에서 1-3ms로 단축합니다. Hyperdrive는 연결 풀 및 체제를 취급합니다. 배치는 쿼리 실행을 위한 네트워크 거리를 감소시킵니다.

제품 정보`placement.region`데이터베이스가 AWS, GCP 또는 Azure에서 실행되는 경우. 제품 정보`placement.host`데이터베이스는 다른 곳에서 호스팅됩니다.

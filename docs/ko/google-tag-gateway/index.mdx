Google tag gateway for advertisers를 사용하면 Cloudflare를 CDN으로 사용하는 웹사이트 소유자가 몇 번의 클릭만으로 광고 측정 도구를 최대한 활용할 수 있습니다. 이 기능을 사용하면 자체 도메인으로 Google 스크립트를 배포할 수 있어 데이터 프라이버시를 강화하고 측정 신호 복구를 개선할 수 있습니다. 태그를 Google 도메인에서 요청하는 일반적인 구성과 달리, Google tag gateway for advertisers는 사용자의 도메인에서 태그를 로드하고 측정 이벤트를 사용자 도메인으로 전송한 뒤, 거기서 Google로 전달합니다.

왜 이 기능을 만들었고 어떻게 동작하는지에 대해서는 [블로그 글](https://blog.cloudflare.com/google-tag-gateway-for-advertisers/)에서 자세히 알아보세요.

## 가격

Google tag gateway for advertisers는 무료로 사용할 수 있습니다. 이 게이트웨이를 통해 라우팅되는 요청은 [CDN](/cache/), [WAF](/waf/), [Bot Management](/bots/) 같은 다른 Cloudflare 제품의 사용량이나 과금에 포함되지 않습니다.

## 시작하기

사이트 소유자는 두 가지 방법 중 하나로 이 기능을 활성화할 수 있습니다. Google tag 콘솔을 통해서, 또는 [Cloudflare 대시보드](https://dash.cloudflare.com/?to=/:account/tag-management/google-tag-gateway)를 통해서입니다.

### Google Tag Manager에서 구성

Google tag gateway for advertisers를 설정하는 가장 빠른 방법은 Google Tag Manager에서 구성하는 것입니다. [Google 도움말 센터의 단계](https://support.google.com/analytics/answer/16061641)를 따라 하세요.

### Cloudflare 대시보드에서 구성

:::note
Cloudflare 대시보드 사용자에게는 다음 [계정 역할](/fundamentals/manage-members/roles/#account-scoped-roles) 중 하나가 있어야 합니다: Super Administrator, Administrator 또는 Zaraz Admin. Domain Scoped Roles를 사용하는 경우 [도메인 역할](/fundamentals/manage-members/roles/#domain-scoped-roles)은 Domain Administrator여야 합니다.
:::

1. Cloudflare 대시보드에서 **Google Tag Gateway** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/tag-management/google-tag-gateway" />

2. 도메인을 선택합니다.
4. **Turn on and configure Google tag gateway** 토글을 활성화합니다.

![Google tag gateway for advertisers configuration](~/assets/images/google-tag-gateway/google-tag-configuration.png)

5. Google 태그 ID와, Google 태그용으로 예약할 웹사이트 경로를 추가합니다.
[Google tag ID](https://support.google.com/analytics/answer/9539598?hl=en)는 Google Tag Experience 대시보드에서 찾을 수 있습니다. 측정 경로는 Google Tag Manager와 이후의 모든 측정 요청을 로드할 사이트 내 미사용 경로입니다.

![Add to ID and path](~/assets/images/google-tag-gateway/google-tag-id-path.png)

6. **Save**를 클릭하면 Google tag gateway for advertisers가 해당 zone에서 활성화됩니다. 웹사이트에 이미 GTM 스크립트가 있다면 이 퍼스트파티 태그가 기존 스크립트를 덮어씁니다.

Cloudflare 계정에 인증하고 GTM을 퍼스트파티 모드로 구성하면, 이제 Google Tags는 `https://your-domain/measurement-path/...`를 사용해 로드되고 이후 측정 요청은 Cloudflare가 처리합니다.

이 튜토리얼은 Internet-of-things(IoT) 장치와 모바일 애플리케이션이 [API Shield](/api-shield/)와 함께 클라이언트 인증서를 사용하도록 구성하는 방법을 보여줍니다.

## 시나리오 세부 정보

이 안내에서는 온도 측정값을 수집하는 장치가 Cloudflare로 보호되는 API에 POST 요청을 보내 해당 값을 전송하는 예를 사용합니다. iOS용 Swift로 작성된 모바일 애플리케이션은 이 측정값을 가져와 표시합니다.

예제를 단순하게 유지하기 위해 API는 Cloudflare Worker로 구현되어 있습니다([jamstack 앱 빌드용 To-Do List 튜토리얼](/workers/tutorials/build-a-jamstack-app/)의 코드를 차용).

온도값은 소스 IP 주소를 키로 사용해 [Workers KV](/kv/concepts/how-kv-works/)에 저장되지만, 지문과 같은 [클라이언트 인증서의 값](/cloudflare-one/access-controls/service-credentials/mutual-tls-authentication/)도 쉽게 사용할 수 있습니다.

아래 예시 API 코드는 POST가 수행될 때 온도와 타임스탬프를 KV에 저장하고, GET이 수행될 때 가장 최근의 온도 다섯 개를 반환합니다.

```js
const defaultData = { temperatures: [] };

const getCache = (key) => TEMPERATURES.get(key);
const setCache = (key, data) => TEMPERATURES.put(key, data);

async function addTemperature(request) {
	// 이 클라이언트에 대해 이전에 기록된 온도값을 가져옵니다.
	const ip = request.headers.get("CF-Connecting-IP");
	const cacheKey = `data-${ip}`;
	let data;
	const cache = await getCache(cacheKey);
	if (!cache) {
		await setCache(cacheKey, JSON.stringify(defaultData));
		data = defaultData;
	} else {
		data = JSON.parse(cache);
	}

	// 제출된 측정값(온도와 타임스탬프가 모두 있다고 가정)을 기존 기록에 추가합니다.
	try {
		const body = await request.text();
		const val = JSON.parse(body);

		if (val.temperature && val.time) {
			data.temperatures.push(val);
			await setCache(cacheKey, JSON.stringify(data));
			return new Response("", { status: 201 });
		} else {
			return new Response(
				"Unable to parse temperature and/or timestamp from JSON POST body",
				{ status: 400 },
			);
		}
	} catch (err) {
		return new Response(err, { status: 500 });
	}
}

function compareTimestamps(a, b) {
	return -1 * (Date.parse(a.time) - Date.parse(b.time));
}

// 가장 최근의 온도 측정값 5개를 반환합니다.
async function getTemperatures(request) {
	const ip = request.headers.get("CF-Connecting-IP");
	const cacheKey = `data-${ip}`;

	const cache = await getCache(cacheKey);
	if (!cache) {
		return new Response(JSON.stringify(defaultData), {
			status: 200,
			headers: { "content-type": "application/json" },
		});
	} else {
		data = JSON.parse(cache);
		const retval = JSON.stringify(
			data.temperatures.sort(compareTimestamps).splice(0, 5),
		);
		return new Response(retval, {
			status: 200,
			headers: { "content-type": "application/json" },
		});
	}
}

export default {
	async fetch(request, env, ctx) {
		return request.method === "POST"
			? addTemperature(request)
			: getTemperatures(request);
	},
};
```

## 1. API 검증

### API에 샘플 데이터 POST

mTLS 인증을 추가하기 전에 API를 검증하려면 임의의 온도 측정값을 POST합니다.

```sh
$ TEMPERATURE=$(echo $((361 + RANDOM %11)) | awk '{printf("%.2f",$1/10.0)}')
$ TIMESTAMP=$(date -u +"%Y-%m-%dT%H:%M:%SZ")

$ echo -e "$TEMPERATURE\n$TIMESTAMP"
36.70
2020-09-28T02:54:56Z

$ curl --verbose --header "Content-Type: application/json" --data '{"temperature":'''$TEMPERATURE''', "time": "'''$TIMESTAMP'''"}' https://shield.upinatoms.com/temps 2>&1 | grep "< HTTP/2"
< HTTP/2 201

```

### API에서 샘플 데이터 GET

`temps` 엔드포인트에 대한 GET 요청은 가장 최근 측정값을 반환하며, 위 예시에서 제출한 값도 포함됩니다.

```sh
$ curl --silent https://shield.upinatoms.com/temps | jq .
[
  {
    "temperature": 36.3,
    "time": "2020-09-28T02:57:49Z"
  },
  {
    "temperature": 36.7,
    "time": "2020-09-28T02:54:56Z"
  },
  {
    "temperature": 36.2,
    "time": "2020-09-28T02:33:08Z"
  }
]
```

## 2. Cloudflare 발급 인증서 만들기

API 또는 웹 애플리케이션을 API Shield로 보호하려면 먼저 Cloudflare가 발급한 클라이언트 인증서를 만들어야 합니다.

[Cloudflare 대시보드에서 클라이언트 인증서를 생성](/ssl/client-certificates/create-a-client-certificate/)할 수 있습니다.

하지만 대규모로 작업하는 대부분의 개발자는 API를 통해 자체 개인 키와 인증서 서명 요청(CSR)을 생성하므로, 이 예제에서는 Cloudflare API를 사용해 클라이언트 인증서를 생성합니다.

iOS 애플리케이션과 IoT 장치용 bootstrap 인증서를 만들기 위해, 이 예제에서는 [Cloudflare의 공개 키 인프라 툴킷 CFSSL](https://github.com/cloudflare/cfssl)을 사용합니다.

## 3. 모바일 앱에 클라이언트 인증서 삽입

IoT 장치가 제출한 온도 데이터를 모바일 앱이 안전하게 요청하도록 구성하려면, 모바일 앱에 클라이언트 인증서를 삽입합니다.

단순화를 위해 이 예제에서는 애플리케이션 번들에 PKCS#12 형식 파일로 된 “bootstrap” 인증서와 키를 삽입합니다.

```sh
$ openssl pkcs12 -export -out bootstrap-cert.pfx -inkey ios-key.pem -in ios.pem
Enter Export Password:
Verifying - Enter Export Password:
```

실제 배포 환경에서는 bootstrap 인증서를 사용자 자격 증명과 함께 사용하여, 고유한 사용자 인증서를 반환할 수 있는 API 엔드포인트에 인증할 때만 사용해야 합니다. 기업 사용자는 모바일 장치 관리(MDM)를 사용해 인증서를 배포하는 것이 좋습니다.

### Android 앱에 클라이언트 인증서 삽입

다음은 Android 앱에서 클라이언트 인증서를 사용하여 HTTP 호출을 수행하는 예입니다. 인터넷 연결을 허용하려면 `AndroidManifest.xml`에 다음 권한을 추가해야 합니다.

```xml
<uses-permission android:name="android.permission.INTERNET" />
```

이 예제에서는 설명을 위해 인증서를 `app/src/main/res/raw/cert.pem`에, 개인 키를 `app/src/main/res/raw/key.pem`에 저장합니다. 이러한 파일은 다른 안전한 방식으로 저장할 수도 있습니다.

다음 예제는 `OkHttpClient`를 사용하지만, `HttpURLConnection`과 같은 다른 클라이언트도 유사한 방식으로 사용할 수 있습니다. 핵심은 `SSLSocketFactory`를 사용하는 것입니다.

```java
private OkHttpClient setUpClient() {
    try {
        final String SECRET = "secret"; // 이 문자열도 더 안전한 위치에 저장할 수 있습니다.
        CertificateFactory certificateFactory = CertificateFactory.getInstance("X.509");

        // 개인 키 가져오기
        InputStream privateKeyInputStream = getResources().openRawResource(R.raw.key);
        byte[] privateKeyByteArray = new byte[privateKeyInputStream.available()];
        privateKeyInputStream.read(privateKeyByteArray);

        String privateKeyContent = new String(privateKeyByteArray, Charset.defaultCharset())
                .replace("-----BEGIN PRIVATE KEY-----", "")
                .replaceAll(System.lineSeparator(), "")
                .replace("-----END PRIVATE KEY-----", "");

        byte[] rawPrivateKeyByteArray = Base64.getDecoder().decode(privateKeyContent);
        KeyFactory keyFactory = KeyFactory.getInstance("RSA");
        PKCS8EncodedKeySpec keySpec = new PKCS8EncodedKeySpec(rawPrivateKeyByteArray);

        // 인증서 가져오기
        InputStream certificateInputStream = getResources().openRawResource(R.raw.cert);
        Certificate certificate = certificateFactory.generateCertificate(certificateInputStream);

        // KeyStore 설정
        KeyStore keyStore = KeyStore.getInstance(KeyStore.getDefaultType());
        keyStore.load(null, SECRET.toCharArray());
        keyStore.setKeyEntry("client", keyFactory.generatePrivate(keySpec), SECRET.toCharArray(), new Certificate[]{certificate});
        certificateInputStream.close();

        // Trust Manager 설정
        TrustManagerFactory trustManagerFactory = TrustManagerFactory.getInstance(TrustManagerFactory.getDefaultAlgorithm());
        trustManagerFactory.init((KeyStore) null);
        TrustManager[] trustManagers = trustManagerFactory.getTrustManagers();

        // Key Manager 설정
        KeyManagerFactory keyManagerFactory = KeyManagerFactory.getInstance(KeyManagerFactory.getDefaultAlgorithm());
        keyManagerFactory.init(keyStore, SECRET.toCharArray());
        KeyManager[] keyManagers = keyManagerFactory.getKeyManagers();

        // SSL Socket Factory 획득
        SSLContext sslContext = SSLContext.getInstance("TLS");
        sslContext.init(keyManagers, trustManagers, new SecureRandom());
        SSLSocketFactory sslSocketFactory = sslContext.getSocketFactory();

        // 마지막으로, HTTP 호출에 사용될 클라이언트를 반환합니다.
        OkHttpClient client = new OkHttpClient.Builder()
                .sslSocketFactory(sslSocketFactory, (X509TrustManager) trustManagers[0])
                .build();

        return client;

    } catch (CertificateException | IOException | NoSuchAlgorithmException | KeyStoreException | UnrecoverableKeyException | KeyManagementException | InvalidKeySpecException e) {
        e.printStackTrace();
        return null;
    }
}
```

위 함수는 클라이언트 인증서가 내장된 `OkHttpClient`를 반환합니다. 이제 이 클라이언트를 사용해 mTLS로 보호된 API 엔드포인트에 HTTP 요청을 보낼 수 있습니다.

## 4. IoT 장치에 클라이언트 인증서 삽입

IoT 장치가 API 엔드포인트와 안전하게 통신하도록 준비하려면, 장치에 인증서를 삽입하고 POST 요청을 만들 때 해당 인증서를 사용하도록 장치를 구성합니다.

이 예제에서는 인증서와 개인 키가 `/etc/ssl/private/sensor-key.pem` 및 `/etc/ssl/certs/sensor.pem`에 안전하게 복사되어 있다고 가정합니다.

샘플 스크립트는 이 파일들을 가리키도록 수정됩니다.

```python
import requests
import json
from datetime import datetime

def readSensor():

    # 온도 센서에서 값을 읽어 temp_measurement에 저장합니다.

    dateTimeObj = datetime.now()
    timestampStr = dateTimeObj.strftime('%Y-%m-%dT%H:%M:%SZ')

    measurement = {'temperature':str(temp_measurement),'time':timestampStr}
    return measurement

def main():

    print("Cloudflare API Shield [IoT device demonstration]")

    temperature = readSensor()
    payload = json.dumps(temperature)

    url = 'https://shield.upinatoms.com/temps'
    json_headers = {'Content-Type': 'application/json'}
    cert_file = ('/etc/ssl/certs/sensor.pem', '/etc/ssl/private/sensor-key.pem')

    r = requests.post(url, headers = json_headers, data = payload, cert = cert_file)

    print("Request body: ", r.request.body)
    print("Response status code: %d" % r.status_code)
```

스크립트가 `https://shield.upinatoms.com/temps`에 연결을 시도하면 Cloudflare는 클라이언트 인증서 전송을 요구하고, 스크립트는 `/etc/ssl/certs/sensor.pem`의 내용을 전송합니다. 그런 다음 SSL/TLS 핸드셰이크를 완료하기 위해 스크립트는 `/etc/ssl/private/sensor-key.pem`을 소유하고 있음을 증명합니다.

클라이언트 인증서가 없으면 Cloudflare는 요청을 거부합니다.

```txt
Cloudflare API Shield [IoT device demonstration]
Request body:  {"temperature": "36.5", "time": "2020-09-28T15:52:19Z"}
Response status code: 403
```

IoT 장치가 유효한 클라이언트 인증서를 제시하면 POST 요청이 성공하고 온도 측정값이 기록됩니다.

```txt
Cloudflare API Shield [IoT device demonstration]
Request body:  {"temperature": "36.5", "time": "2020-09-28T15:56:45Z"}
Response status code: 201
```

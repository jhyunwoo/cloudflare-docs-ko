Cloudflare에서 [클라이언트 인증서를 생성](/ssl/client-certificates/)한 후에는 생성된 인증서들을 구분하기가 어려울 수 있습니다.

## 원인

Cloudflare에서 개인 키와 CSR을 생성하는 옵션은 더 단순한 사용 사례를 위한 것이며, 인증서는 단순히 `"CN=Cloudflare, C=US"`로 생성됩니다.

## 해결 방법

고객별로 조직 단위로 클라이언트 인증서를 구분해야 한다면 자체 개인 키와 CSR을 생성할 수 있습니다. 개인 키와 CSR을 생성할 때 인증서 요청에 포함될 정보를 직접 입력할 수 있습니다.

예를 들어 OpenSSL이 설치된 상태에서 다음 명령을 실행하면:

```sh
openssl req -new -newkey rsa:2048 -nodes -keyout client1.key -out client1.csr
```

다음 값을 지정할 수 있습니다.

```
Country Name (2 letter code) []:
State or Province Name (full name) []:
Locality Name (eg, city) []:
Organization Name (eg, company) []:
Organizational Unit Name (eg, section) []:
Common Name (eg, fully qualified host name) []:
Email Address []:
```

보통 `Country Name`과 `Organization Name`만 추가해도 충분하지만, 필요에 따라 원하는 만큼 많은 정보를 제공할 수 있습니다.

추가 정보는 **Certificate Subject**에 포함되므로 어떤 인증서가 어떤 고객에 속하는지 쉽게 식별할 수 있습니다. 이렇게 하면 필요할 때 특정 인증서를 더 쉽게 폐기할 수도 있습니다.

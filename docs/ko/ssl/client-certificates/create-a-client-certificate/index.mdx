Cloudflare 대시보드에서 클라이언트 인증서를 만들려면:

1. Cloudflare 대시보드에서 **Client Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/client-certificates" />

2. **Create Certificate**를 선택하고 필요한 필드를 입력합니다. 다음 옵션 중 하나를 선택할 수 있습니다.

  - Cloudflare에서 개인 키와 인증서 서명 요청(CSR)을 생성합니다.
  - 자체 개인 키와 CSR을 사용합니다. 이 옵션을 사용하면 [클라이언트 인증서 라벨 지정](/ssl/client-certificates/label-client-certificate/)도 가능합니다.

    <Details header="OpenSSL 명령 예시">

    자체 CSR을 생성하여 사용하려면 다음과 같은 명령을 실행할 수 있습니다.

    ```sh
    openssl req -new -newkey rsa:2048 -nodes -keyout client1.key -out client1.csr -subj '/C=GB/ST=London/L=London/O=Organization/CN=CommonName'
    ```

    </Details>

:::note
대시보드에서 생성한 클라이언트 인증서는 [Cloudflare 관리형 CA](/ssl/client-certificates/#how-it-works)에서 발급됩니다. 다른 CA가 발급한 인증서를 사용해야 한다면 대신 API를 통해 [자체 CA를 가져와 사용](/ssl/client-certificates/byo-ca/)하세요.
:::

3. **Certificate Validity** 값을 선택하고 **Create**를 선택합니다.
4. 인증서와 개인 키는 이후 다시 표시되지 않으므로 반드시 복사해 두세요.
5. **OK**를 선택하여 확인합니다.

## 다음 단계

클라이언트 인증서를 만든 후에는 해당 인증서가 클라이언트 장치에 설치되어 있는지 확인하고, 인증서가 필요한 각 호스트 이름에 대해 [mTLS를 활성화](/ssl/client-certificates/enable-mtls/)하세요.

자세한 배경은 [Cloudflare에서의 mTLS 학습 경로](/learning-paths/mtls/concepts/)를 참고하세요.

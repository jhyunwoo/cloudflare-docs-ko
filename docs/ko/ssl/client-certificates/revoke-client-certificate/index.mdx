기본 [Cloudflare 관리형 CA](/ssl/client-certificates/)로 이전에 생성한 클라이언트 인증서를 폐기할 수 있습니다.

기본 Cloudflare 관리형 CA로 생성한 클라이언트 인증서를 영구적으로 삭제하는 것은 불가능합니다. 폐기된 이후에도 이러한 클라이언트 인증서는 [**Client Certificates**](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/client-certificates) 페이지에 계속 표시되며, 언제든 복원할 수 있습니다.

## 단계

1. Cloudflare 대시보드에서 **Client Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/client-certificates" />

2. 폐기하려는 인증서를 선택합니다.
3. **Revoke**를 선택하고 작업을 확인합니다.

:::caution[중요]


인증서를 폐기한 후에는 폐기된 인증서가 포함된 모든 요청을 차단하도록, 클라이언트 인증서의 존재 여부를 확인하는 모든 mTLS 규칙을 업데이트해야 합니다.

자세한 내용은 [폐기된 인증서 확인](/api-shield/security/mtls/configure/#check-for-revoked-certificates)을 참고하세요.


:::

Cloudflare가 도메인에 대해 [authoritative DNS](/dns/zone-setups/full-setup/)를 제공하는 경우, 표준 Universal 인증서마다 백업 [Universal SSL certificate](/ssl/edge-certificates/universal-ssl/)도 함께 발급합니다.

이 백업 인증서는 다른 개인 키로 래핑되며, 도메인의 기본 Universal SSL 인증서와는 다른 Certificate Authority에서 발급됩니다. 사용되는 기관은 Google Trust Services, Let's Encrypt, Sectigo 또는 SSL.com 중 하나입니다.

이 백업 인증서는 일반적으로 배포되지 않지만, 인증서 폐기 또는 키 손상 문제가 발생하면 Cloudflare가 자동으로 배포합니다.

자세한 내용은 [소개 블로그 게시물](https://blog.cloudflare.com/introducing-backup-certificates/)을 참고하세요.

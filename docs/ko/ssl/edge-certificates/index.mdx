아래 정보는 일반적인 사용 사례에 맞춰 어떤 엣지 인증서를 선택해야 하는지 판단하는 데 도움이 됩니다. 더 많은 옵션은 이 섹션의 다른 페이지를 참고하세요.

SSL/TLS 인증서가 무엇인지 익숙하지 않다면 [개념](/ssl/concepts/)을 먼저 참고하세요.

:::note
Cloudflare 대시보드에 apex 호스트명만 나열된 와일드카드 인증서가 표시되고 와일드카드 기호 `*`가 보이지 않는 경우가 있습니다.

이 동작은 다음 조건이 모두 참일 때 발생합니다.

* 영역이 [하위 도메인 설정](/dns/zone-setups/subdomain-setup/)에 있습니다.
* 인증서의 subject 또는 SAN이 영역 상위 도메인에 대한 와일드카드입니다.
:::

## 사용 사례

### 발급과 갱신 단순화

인증서 발급과 갱신은 기술 팀의 시간을 많이 소모할 수 있습니다. Cloudflare [Universal SSL](/ssl/edge-certificates/universal-ssl/) 또는 [고급 인증서](/ssl/edge-certificates/advanced-certificate-manager/)를 활용해 이 과정을 단순화하세요.

고급 인증서는 Universal SSL보다 더 많은 사용자 지정 옵션을 제공합니다.

[커스텀 인증서](/ssl/edge-certificates/custom-certificates/)를 사용하면 인증 기관(CA)이나 인증서의 <GlossaryTooltip term="validation level" link="/ssl/concepts/#validation-level">검증 수준</GlossaryTooltip>을 완전히 제어할 수 있지만, 발급과 갱신은 직접 처리해야 합니다.

### Cipher suite 요구 사항 충족

SSL/TLS 암호화에 사용되는 알고리즘은 보안 수준 측면에서 차이가 있을 수 있습니다.

[Cipher suite 사용자 지정](/ssl/edge-certificates/additional-options/cipher-suites/customize-cipher-suites/)을 사용하면 도메인 및 특정 호스트명에서 어떤 cipher를 사용할지 제어할 수 있습니다. 이를 통해 레거시 장치에서도 접근 가능한 가용성이 높은 마케팅 웹사이트(`www.example.com`)와 [표준 준수](/ssl/edge-certificates/additional-options/cipher-suites/compliance-status/)가 필요한 보안 수준이 높은 서비스 또는 애플리케이션(`shop.example.com`) 사이의 균형을 맞출 수 있습니다.

Cipher suite 사용자 지정은 특정 호스트명 연결에 사용되는 모든 엣지 인증서에 적용됩니다. 하지만 [커스텀 cipher suite 및 기타 기능](/ssl/edge-certificates/advanced-certificate-manager/#advanced-certificate-manager)을 활성화하려면 [Advanced Certificate Manager 애드온을 구매](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/acm/)해야 합니다.

이미 Advanced Certificate Manager를 사용 중이라면 API를 통해 커스텀 cipher suite를 설정하세요. 자세한 내용은 [Cipher suite 사용자 지정](/ssl/edge-certificates/additional-options/cipher-suites/customize-cipher-suites/)을 참고하세요.

### Domain control validation(DCV) 자동화

Cloudflare를 사용하면서 DNS는 외부에서 관리하려는 경우([partial setup](/dns/zone-setups/partial-setup/)), SSL/TLS 인증서를 발급하기 전에 도메인 제어 권한을 증명하기 위해 [domain control validation (DCV)](/ssl/edge-certificates/changing-dcv-method/)를 수행해야 할 수 있습니다.

이 과정을 더 쉽게 만들고 인증서 갱신 시 DCV를 자동화하려면 [고급 인증서](/ssl/edge-certificates/advanced-certificate-manager/)를 사용하고 [delegated DCV](/ssl/edge-certificates/changing-dcv-method/methods/delegated-dcv/)를 설정하세요.

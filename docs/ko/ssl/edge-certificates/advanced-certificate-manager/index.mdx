고급 인증서를 주문하려면 Advanced Certificate Manager 애드온을 구매해야 하며, 이 구독에는 다른 기능도 포함됩니다.

## Advanced Certificate Manager

Advanced Certificate Manager를 사용하면 다음이 가능합니다.

- 다음과 같은 고급 인증서 주문:
  - 영역 apex와 최대 50개의 호스트를 커버 호스트명으로 포함
  - 한 단계보다 더 깊은 하위 도메인까지 포함
  - 원하는 Certificate Authority(CA)에서 발급
  - 원하는 검증 방법 사용
  - 원하는 유효 기간 선택
- [delegated DCV](/ssl/edge-certificates/changing-dcv-method/methods/delegated-dcv/)를 사용하여 partial zone의 <GlossaryTooltip term="domain control validation (DCV)">DCV process</GlossaryTooltip>를 Cloudflare에 위임
- [Total TLS](/ssl/edge-certificates/additional-options/total-tls/)를 활성화해 프록시된 호스트명을 자동 보호
- 원본 인증용 [custom trust store](/ssl/origin-configuration/custom-origin-trust-store/) 선택
- [cipher suites](/ssl/edge-certificates/additional-options/cipher-suites/customize-cipher-suites/)와 [호스트명별 minimum TLS version](/ssl/edge-certificates/additional-options/minimum-tls/#per-hostname) 제어

:::note

Enterprise 고객은 Advanced Certificate Manager 구독을 구매해 영역당 최대 100개의 <GlossaryTooltip term="edge certificate">edge certificates</GlossaryTooltip>를 추가할 수도 있습니다.

:::

## 제한 사항

고급 인증서는 [Cloudflare Pages](/pages/)나 [R2](/r2/)에서 [certificate prioritization](/ssl/reference/certificate-and-hostname-priority/) 때문에 사용되지 않습니다. Pages와 R2 커스텀 도메인은 모두 Cloudflare for SaaS 인증서를 사용합니다.

고급 인증서는 [Domain Validated (DV)](/ssl/concepts/#validation-level) 인증서입니다. 조직에서 Organization Validated(OV) 또는 Extended Validation(EV) 인증서가 필요하다면 [Custom certificates](/ssl/edge-certificates/custom-certificates/)를 참고하세요. <br/>

고급 인증서는 여러 서로 다른 도메인을 포괄하지 않습니다. 멀티 도메인 인증서(MDC)가 필요하다면 [Cloudflare for SaaS](/cloudflare-for-platforms/cloudflare-for-saas/) 제품을 고려하세요. 추가 지침은 [Leveraging Cloudflare for your SaaS applications](/reference-architecture/design-guides/leveraging-cloudflare-for-your-saas-applications/)에서 확인할 수 있습니다.

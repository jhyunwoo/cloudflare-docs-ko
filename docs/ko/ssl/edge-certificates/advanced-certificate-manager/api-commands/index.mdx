고급 인증서를 관리하려면 다음 API 명령을 사용하세요. Cloudflare API를 처음 사용한다면 [API documentation](/fundamentals/api/)를 먼저 참고하세요.



| Command                                                                                                                                                 | Method   | Endpoint                                             | Additional notes                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| [고급 인증서 주문](/api/resources/ssl/subresources/certificate_packs/methods/create/)                                     | `POST`   | `zones/<<ZONE_ID>>/ssl/certificate_packs/order`      |                                                                                             |
| [인증서 검증 재시작](/api/resources/ssl/subresources/certificate_packs/methods/edit/)                | `PATCH`  | `zones/<<ZONE_ID>>/ssl/certificate_packs/<<ID>>`     | `validation_timed_out` 상태의 Certificate Pack에 사용합니다.                                                                                             |
| [인증서 팩 삭제](/api/resources/ssl/subresources/certificate_packs/methods/delete/)                                       | `DELETE` | `zones/<<ZONE_ID>>/ssl/certificate_packs/<<ID>>`     |                                                                                             |
| [영역의 인증서 팩 목록 보기](/api/resources/ssl/subresources/certificate_packs/methods/list/)                                                            | `GET`    | `zones/<<ZONE_ID>>/ssl/certificate_packs?status=all` | 이 API 호출은 도메인에 대한 모든 인증서 팩(Universal, Custom, Advanced)을 반환합니다. |
| Cipher Suite 설정 조회: URI 경로에서 설정 이름을 `ciphers`로 지정한 [Get zone setting](/api/resources/zones/subresources/settings/methods/get/)     | `GET`    | `zones/<<ZONE_ID>>/settings/ciphers`                 |                                                                                             |
| Cipher Suite 설정 변경: URI 경로에서 설정 이름을 `ciphers`로 지정한 [Edit zone setting](/api/resources/zones/subresources/settings/methods/edit/) | `PATCH`  | `zones/<<ZONE_ID>>/settings/ciphers`                 | 기본 설정으로 되돌리려면 `value` 파라미터에 빈 배열을 전송합니다.                   |

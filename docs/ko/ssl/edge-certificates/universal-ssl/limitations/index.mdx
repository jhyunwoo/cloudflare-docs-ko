Universal SSL 인증서에는 몇 가지 제한 사항이 있습니다.

## 프록시 상태

Cloudflare는 DNS 레코드의 [proxy status](/dns/proxy-status/)가 **Proxied**로 설정된 경우에만 해당 레코드에 대해 SSL/TLS 인증서를 제공할 수 있습니다. 그렇지 않으면 레코드가 가리키는 오리진 서버가 SSL/TLS 연결을 직접 지원해야 합니다.

## 호스트 이름 범위

### 전체 설정

Universal SSL 인증서는 `example.com`, `www.example.com` 같은 루트 도메인 또는 1단계 서브도메인만 지원합니다. `dev.www.example.com` 또는 `app3.dev.www.example.com` 같은 2단계, 3단계, 4단계 서브도메인에 SSL을 사용하려면 다음 중 하나를 수행할 수 있습니다.

* [Advanced Certificate Manager](/ssl/edge-certificates/advanced-certificate-manager/)를 구매하여 고급 인증서를 주문합니다.
* Business 또는 Enterprise 플랜으로 업그레이드하여 [사용자 지정 인증서](/ssl/edge-certificates/custom-certificates/)를 업로드합니다.

### CNAME 설정

[CNAME setup zone](/dns/zone-setups/partial-setup/)에서는 각 서브도메인(레벨과 무관)이 자체 Universal SSL 인증서를 가지며 추가 기능이나 구매가 필요하지 않습니다. 서브도메인이 Cloudflare로 프록시되는 한 Universal 인증서가 [발급됩니다](/ssl/edge-certificates/universal-ssl/enable-universal-ssl/#partial-dns-setup).

## 인증 기관

Universal SSL 인증서에 사용되는 <GlossaryTooltip term="Certificate Authority (CA)">인증 기관(CA)</GlossaryTooltip>은 Cloudflare가 선택합니다.

Cloudflare는 사전 통지 없이 [인증 기관](/ssl/reference/certificate-authorities/)을 변경할 수 있으며, 변경이 발생해도 별도의 알림을 보내지 않습니다.

발급 인증 기관을 직접 선택하려면 [고급 인증서 주문](/ssl/edge-certificates/advanced-certificate-manager/)이 필요합니다.


## 유효 기간

Universal 인증서는 유효 기간을 Cloudflare가 제어합니다. 자세한 내용은 [유효 기간 및 갱신](/ssl/reference/certificate-validity-periods/#universal-ssl)을 참고하세요.

## TLS 설정

[암호군 사용자 지정](/ssl/edge-certificates/additional-options/cipher-suites/customize-cipher-suites/)은 [Advanced Certificate Manager](/ssl/edge-certificates/advanced-certificate-manager/) 또는 [Cloudflare for SaaS](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/)에서만 사용할 수 있습니다.

[최소 TLS 버전](/ssl/edge-certificates/additional-options/minimum-tls/)은 영역 수준에서 설정할 수 있지만, 호스트 이름별 설정을 하려면 [Advanced Certificate Manager](/ssl/edge-certificates/advanced-certificate-manager/)가 필요합니다.

## 위임된 DCV

위임된 DCV는 [부분 DNS 설정](/dns/zone-setups/partial-setup/)을 사용하는 영역이 DCV 프로세스를 Cloudflare에 위임할 수 있도록 합니다. 그러나 DCV 위임은 Universal SSL 인증서에서는 동작하지 않으며 [고급 인증서](/ssl/edge-certificates/advanced-certificate-manager/)를 사용해야 합니다.

## Spectrum

Universal SSL은 [Cloudflare Spectrum](/spectrum/)과 호환되지 않습니다. Spectrum을 사용하려면 [고급 인증서](/ssl/edge-certificates/advanced-certificate-manager/) 또는 [사용자 지정 인증서](/ssl/edge-certificates/custom-certificates/)를 사용하세요.

## 로드 밸런싱

내부 제한으로 인해 Universal SSL 인증서는 기본적으로 [load balancing hostnames](/load-balancing/load-balancers/dns-records/)를 포함하지 않습니다. 이 동작은 향후 수정될 예정입니다.

## 브라우저 지원

브라우저 지원에 대한 자세한 내용은 [Browser compatibility](/ssl/reference/browser-compatibility/)를 참고하세요.

## SSL invalid brand check

일부 도메인은 상표가 있는 도메인과 충돌하는 단어를 포함하면 Universal SSL 대상이 되지 못할 수 있습니다.

이 문제를 해결하려면 다음을 수행할 수 있습니다.

* [고급 인증서](/ssl/edge-certificates/advanced-certificate-manager/)를 구매합니다.
* 직접 [사용자 지정 인증서](/ssl/edge-certificates/custom-certificates/uploading/)를 업로드합니다.

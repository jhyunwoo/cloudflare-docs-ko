<GlossaryDefinition term="Universal SSL certificate" />

Universal 인증서는 [도메인 검증(DV)](/ssl/concepts/#validation-level) 방식입니다. 설정 세부 사항은 [Universal SSL 활성화](/ssl/edge-certificates/universal-ssl/enable-universal-ssl/)를 참고하세요.

:::note

웹사이트나 애플리케이션이 트래픽을 Cloudflare로 이전하기 전에 SSL 인증서를 필요로 하거나, [암호군을 사용자 지정](/ssl/edge-certificates/additional-options/cipher-suites/customize-cipher-suites/)해야 한다면 [Advanced](/ssl/edge-certificates/advanced-certificate-manager/) 또는 [Custom](/ssl/edge-certificates/custom-certificates/) 인증서를 참고하세요.

:::

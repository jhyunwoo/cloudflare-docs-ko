일부 고객은 자체 SSL 인증서를 관리하거나 특정 인증 기관에 의존해야 할 수 있습니다.

도메인의 Universal SSL 인증서를 비활성화하면 Cloudflare는 해당 인증서를 네트워크에서 제거하며 추가 Universal SSL 인증서를 주문하거나 갱신하지 않습니다.

Universal SSL을 비활성화해도 Cloudflare 네트워크에서 이미 진행 중인 TLS 연결은 중단되지 않으며, 이 연결은 처음 수립될 때 사용한 Universal SSL 인증서에 따라 계속 서비스됩니다. 결국 이러한 연결은 자연스럽게 종료됩니다.

새 TLS 연결은 [사용자 지정](/ssl/edge-certificates/custom-certificates/) 또는 [고급](/ssl/edge-certificates/advanced-certificate-manager/) 인증서처럼 다른 유효한 인증서가 이미 활성 상태라면 정상적으로 성공해야 합니다. 새 TLS 연결은 [인증서 및 호스트 이름 우선순위](/ssl/reference/certificate-and-hostname-priority/)에 따라 가장 우선순위가 높은 인증서를 사용합니다. 비활성화 전에 유효한 인증서가 활성 상태가 아니라면 TLS 연결은 실패합니다. 자세한 내용은 아래 [잠재적 오류](#잠재적-오류)를 참고하세요.

## 잠재적 오류

도메인에서 오류가 발생하지 않도록 Universal SSL을 비활성화하기 전에 [사용자 지정 인증서 업로드](/ssl/edge-certificates/custom-certificates/)를 하거나 [Advanced Certificate Manager](/ssl/edge-certificates/advanced-certificate-manager/)를 구매하세요.

Universal SSL을 비활성화하면 다음 시나리오에서 오류가 발생할 수 있습니다.

- **활성화된 기능**:

  - [HTTP Strict Transport Security (HSTS)](/ssl/edge-certificates/additional-options/http-strict-transport-security/)
  - [Always Use HTTPS](/ssl/edge-certificates/additional-options/always-use-https/)
  - [Opportunistic Encryption](/ssl/edge-certificates/additional-options/opportunistic-encryption/)

- **기타 설정**:

  - 트래픽을 HTTPS로 리디렉션하는 [Page Rules](/rules/page-rules/)
  - 오리진 웹 서버에서의 HTTP to HTTPS 리디렉션

## Universal SSL 인증서 비활성화

Universal SSL/TLS를 비활성화하기 전에 도메인을 보호할 [사용자 지정 인증서](/ssl/edge-certificates/custom-certificates/)를 업로드했거나 [Advanced Certificate Manager](/ssl/edge-certificates/advanced-certificate-manager/)를 구매했는지 확인하세요.

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 Universal SSL을 비활성화하려면:

1. Cloudflare 대시보드에서 **Edge Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/edge-certificates" />

2. **Disable Universal SSL**에서 **Disable Universal SSL**을 선택합니다.
3. **Acknowledgement**의 경고를 읽습니다.
4. **I Understand**를 선택한 뒤 **Confirm**을 선택합니다.

</TabItem> <TabItem label="API">

Cloudflare API로 Universal SSL을 비활성화하려면 [`PATCH`](/api/resources/ssl/subresources/universal/subresources/settings/methods/edit/) 요청을 보내고 `"enabled": false` 파라미터를 포함하세요.

</TabItem> </Tabs>

## Universal SSL 다시 활성화

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 Universal SSL을 다시 활성화하려면:

1. Cloudflare 대시보드에서 **Edge Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/edge-certificates" />

2. **Disable Universal SSL**에서 **Enable Universal SSL**을 선택합니다.

</TabItem> <TabItem label="API">

Cloudflare API로 Universal SSL을 다시 활성화하려면 [`PATCH`](/api/resources/ssl/subresources/universal/subresources/settings/methods/edit/) 요청을 보내고 `"enabled": true` 파라미터를 포함하세요.

</TabItem> </Tabs>

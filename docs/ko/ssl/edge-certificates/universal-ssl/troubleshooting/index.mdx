## 시간 초과 상태 해결

인증서 발급이 시간 초과되면 Cloudflare는 발급 체인의 어느 단계에서 시간 초과가 발생했는지(Initializing, Validation, Issuance, Deployment, Deletion)를 알려줍니다.

시간 초과 문제를 해결하려면 다음 옵션 중 하나 이상을 시도해 보세요.

* 관련 DNS 레코드의 **Proxy status**를 **DNS only**(회색 구름)로 변경하고 최소 1분 이상 기다립니다. 그런 다음 **Proxy status**를 다시 **Proxied**(주황색 구름)로 변경합니다.
* [Universal SSL 비활성화](/ssl/edge-certificates/universal-ssl/disable-universal-ssl/) 후 최소 1분 이상 기다립니다. 그다음 Universal SSL을 다시 활성화합니다.
* 현재와 동일한 [DCV 방법](/ssl/edge-certificates/changing-dcv-method/)을 사용해 [validation endpoint](/api/resources/ssl/subresources/verification/methods/edit/)에 PATCH 요청을 보냅니다(API 전용). 요청 시 `--data` 필드가 비어 있지 않은지 확인하세요.
* 도메인 제어 유효성 검사(DCV)를 검토합니다. DCV 방법을 변경하면 인증서 발급이 다시 시작됩니다.

## 인증서 삭제

Cloudflare 대시보드에 더 이상 표시하지 않으려는 인증서는 [API 사용](/api/resources/ssl/subresources/certificate_packs/methods/delete/)으로 삭제할 수 있습니다.

## 기타 문제

추가적인 문제 해결이 필요하면 [SSL 오류 문제 해결](/ssl/troubleshooting/)을 참고하세요.

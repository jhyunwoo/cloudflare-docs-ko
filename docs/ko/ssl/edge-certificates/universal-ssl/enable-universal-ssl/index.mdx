### 다운타임 최소화

웹사이트나 애플리케이션이 이미 운영 중이며 Universal 인증서가 발급되는 동안 노출되지 않으면 안 되는 경우, 다음을 고려하세요.

- 트래픽을 Cloudflare로 프록시하기 전에 [Advanced certificate](/ssl/edge-certificates/advanced-certificate-manager/)를 주문합니다.
- 이전 전에 [사용자 지정 인증서](/ssl/edge-certificates/custom-certificates/)를 업로드하고, [Universal certificate가 활성화된 뒤](#인증서가-활성-상태인지-확인) 삭제합니다.
- [인증서가 활성화될 때까지](#인증서가-활성-상태인지-확인) DNS 레코드를 [**unproxied**](/dns/proxy-status/) 상태로 유지합니다.

:::note
도메인이 **부분 설정**을 사용 중이라면 권한 있는 DNS에 [도메인 제어 유효성 검사(DCV) 레코드](/ssl/edge-certificates/changing-dcv-method/)를 추가해야 합니다.
:::

## 부분 DNS 설정

권한 있는 네임서버를 Cloudflare가 운영하지 않는 [부분 도메인](/dns/zone-setups/partial-setup/)의 경우 Universal SSL은 다음과 같이 처리됩니다.

- DNS 레코드가 [Cloudflare를 통해 프록시](/dns/zone-setups/partial-setup/setup/#3-add-dns-records)되면 발급됩니다.
- 검증은:
  - 권한 있는 DNS에 [도메인 제어 유효성 검사(DCV)](/ssl/edge-certificates/changing-dcv-method/) 레코드를 추가하면 즉시 수행됩니다.
  - DCV 레코드를 **추가하지 않으면**, 트래픽이 프록시된 뒤 짧은 다운타임 이후에 수행됩니다.

[Advanced certificate](/ssl/edge-certificates/advanced-certificate-manager/)를 사용해 여러 서브도메인을 함께 보호하고 검증하지 않는 한, 새 서브도메인이 추가될 때마다 해당 서브도메인을 프록시하고 검증해야 합니다.

## 인증서가 활성 상태인지 확인

Universal SSL을 활성화한 뒤에는 [**Edge Certificates**](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/edge-certificates) 페이지 또는 [GET 요청](/api/resources/ssl/subresources/certificate_packs/methods/list/)을 통한 API에서 [활성화 상태](/ssl/reference/certificate-statuses/)를 확인할 수 있습니다.

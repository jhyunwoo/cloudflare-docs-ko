인증서 스테이징 환경을 사용하면 새 사용자 지정(modern) 인증서를 프로덕션 환경에 배포하기 전에 테스트할 수 있습니다. 이 과정은 다음과 같은 상황에서 **사고가 발생하기 전에** 잠재적인 인증서 문제를 해결하는 데 도움이 됩니다.

* 새 사용자 지정 인증서를 업로드할 때 실수한 경우
* 인증서 순서를 잘못 이해한 경우
* 클라이언트가 이전 사용자 지정 인증서를 이미 pinning 하고 있어 TLS 종료 오류가 발생하는 경우

## 스테이징 환경 사용

### 1. 인증서 업로드

스테이징 환경에 사용자 지정(modern) 인증서를 업로드하려면:

1. Cloudflare 대시보드에서 **Staging Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/staging-certificates" />

2. **Upload Custom Staging Certificate**를 선택합니다.
3. 사용자 지정(modern) 인증서를 업로드합니다([자세한 지침](/ssl/edge-certificates/custom-certificates/uploading/)).
4. 인증서는 대시보드에 **Staging Deployment** 상태로 표시됩니다. 페이지를 새로 고치면 상태가 **Staging Active**로 바뀌어야 합니다.

### 2. 인증서 테스트

[**Staging Certificates**](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/staging-certificates) 페이지에 나열된 IP 주소로 `curl` 요청을 보내 사용자 지정(modern) 인증서를 테스트하세요.

```txt
curl --resolve <HOSTNAME>:<PORT>:<STAGING_IP> https://<HOSTNAME> -iv
```

다음 사항을 확인해야 합니다.

* TLS 종료가 성공하는지
* 에지에서 올바른 인증서가 제공되는지
* 어떤 클라이언트가 이전 인증서를 pinning 하고 있는지

### 3. 인증서를 프로덕션으로 배포

문제가 없다면 사용자 지정(modern) 인증서를 프로덕션 환경으로 배포하세요.

1. Cloudflare 대시보드에서 **Staging Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/staging-certificates" />

2. 사용자 지정 인증서를 선택합니다.
3. **Push to Production**을 선택합니다.

인증서에 문제가 있었다면 스테이징 환경에 그대로 두거나 인증서 자체에서 **Deactivate**를 선택할 수 있습니다.

### 4. (선택 사항) 인증서를 다시 스테이징으로 되돌리기

사용자 지정(modern) 인증서를 프로덕션에 배포한 뒤 문제가 발생하면, 해당 인증서를 비활성화하여 에지에서 삭제한 다음 추가 테스트를 위해 인증서를 스테이징 환경으로 되돌릴 수 있습니다.

1. Cloudflare 대시보드에서 **Edge Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/edge-certificates" />

2. 사용자 지정 인증서를 선택합니다.
3. **Deactivate**를 선택합니다.
4. **Push to Staging**을 선택합니다.

## 제한 사항

### 접근 권한

현재 스테이징 환경은 오픈 베타에 참여 중인 Enterprise 고객만 사용할 수 있습니다. 베타 접근 권한이 필요하면 계정 팀에 문의하세요.

### 기능

현재 스테이징 환경은 기능이 제한적입니다.

* 사용자 지정(modern) 인증서만 지원
* 대시보드를 통해서만 접근 가능

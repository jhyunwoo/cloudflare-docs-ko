[Universal SSL](/ssl/edge-certificates/universal-ssl/) 또는 [advanced certificates](/ssl/edge-certificates/advanced-certificate-manager/)와 달리, Cloudflare는 사용자 지정 인증서의 발급과 갱신을 관리하지 않습니다.
사용자 지정 인증서를 사용할 때는 다음 작업을 사용자가 고려하고 직접 수행해야 합니다.

- [인증서 업로드](/ssl/edge-certificates/custom-certificates/uploading/#upload-a-custom-certificate)
- [인증서 업데이트](/ssl/edge-certificates/custom-certificates/uploading/#update-an-existing-custom-certificate)
- [다운타임 방지를 위한 인증서 만료일 확인](/ssl/edge-certificates/custom-certificates/renewing/)

:::note

사용자 지정 인증서가 모든 1단계 호스트 이름을 포괄하지 못한다면 [Universal SSL certificate](/ssl/edge-certificates/universal-ssl/)를 활성화하여 이를 보완할 수 있습니다.

사용자 지정 인증서가 [Cloudflare가 파트너십을 맺은 인증 기관](/ssl/reference/certificate-authorities/)에서 발급된 것이라면, 자동 발급 및 갱신의 이점을 얻기 위해 Cloudflare 관리형 인증서로 전환하는 것도 고려해 보세요.

:::

## 인증서 팩

<Render file="custom-cert-ciphers" product="ssl" />

각 팩은 사용자 지정 인증서 할당량에서 SSL 인증서 1개로만 계산됩니다.

:::note

팩에 보조 인증서가 존재하는 경우 기본 인증서는 삭제할 수 없습니다.

:::

## 관련 기능

### 인증서 서명 요청(CSR)

사용자 지정 인증서 프로세스의 일부로 Cloudflare를 사용해 [Certificate Signing Request (CSR)](/ssl/edge-certificates/additional-options/certificate-signing-requests/)를 생성할 수 있습니다. 이 옵션을 사용하면 Cloudflare가 CSR과 연결된 개인 키를 안전하게 생성하고 저장합니다.

### Geo Key Manager(개인 키 제한)

기본적으로 Cloudflare는 개인 키를 암호화하여 모든 Cloudflare 데이터 센터에 안전하게 배포하고, 각 위치에서 로컬 SSL/TLS 종료에 사용할 수 있게 합니다. 개인 키를 사용할 수 있는 위치를 제한하려면 [Geo Key Manager](/ssl/edge-certificates/geokey-manager/)를 사용하세요.

### Keyless SSL

사용자 지정 인증서를 업로드하되 개인 키는 자체 인프라에 유지하고 싶다면 [Keyless SSL](/ssl/keyless-ssl/) 사용을 고려하세요.

비밀번호로 보호된 키 파일이 있는 사용자 지정 인증서는 업로드할 수 없습니다.

비밀번호 제거 과정은 운영 체제에 따라 다릅니다. 다음 예시는 `example.com.key`에서 비밀번호를 제거합니다.

<Details header="Linux">

1. 명령 콘솔을 엽니다.

2. `example.com.key` 파일이 있는 디렉터리로 이동합니다.

3. 원본 키를 복사합니다.

   ```sh
   cp example.com.key temp.key
   ```

4. 다음 명령을 실행합니다(ECDSA 인증서를 사용하는 경우 `rsa`를 `ec`로 바꾸세요).

   ```sh
   openssl rsa -in temp.key -out example.com.key
   ```

5. 콘솔 창에서 메시지가 표시되면 원래 키 비밀번호를 입력합니다.

6. [파일 내용을](/ssl/edge-certificates/custom-certificates/uploading/#upload-a-custom-certificate) Cloudflare에 업로드합니다.

</Details>

<Details header="Windows">

1. [https://indy.fulgan.com/SSL/](https://indy.fulgan.com/SSL/)로 이동하여 x86 또는 x86_64 운영 체제용 최신 OpenSSL 버전을 다운로드합니다.

2. `.zip` 파일을 열고 압축을 풉니다.

3. **openssl.exe**를 선택합니다.

4. 표시되는 명령 창에서 다음을 실행합니다.

   ```sh
   rsa -in C:\Path\To\example.com.key -out key.pem
   ```

5. **openssl.exe** 명령 창에 메시지가 표시되면 원래 키 비밀번호를 입력합니다.

6. `key.pem` 파일 내용을 [업로드](/ssl/edge-certificates/custom-certificates/uploading/#upload-a-custom-certificate)합니다.

</Details>

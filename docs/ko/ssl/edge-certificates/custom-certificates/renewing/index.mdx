## 사용자 지정 인증서 갱신

Cloudflare는 업로드된 인증서를 갱신할 수 없으므로, 만료 전에 만료 예정인 사용자 지정 인증서를 교체하거나 [업데이트](/ssl/edge-certificates/custom-certificates/uploading/#update-an-existing-custom-certificate)해야 합니다. 그렇지 않으면 방문자가 연결하지 못할 수 있습니다.

Cloudflare는 사용자 지정 인증서 만료 30일 전과 14일 전에 자동으로 이메일 알림을 보냅니다. 이 이메일은 SSL/TLS, Administrator, 또는 Super Administrator [roles](/fundamentals/manage-members/roles/)를 가진 사용자에게 전송됩니다.

:::note

사용자 지정 인증서를 갱신할 때는 [이전에 생성한 CSR](/ssl/edge-certificates/additional-options/certificate-signing-requests/)을 재사용할 수 있습니다.

Enterprise 플랜을 사용 중이며 사용자 지정(modern) 인증서를 갱신하려는 경우 [Staging environment (Beta)](/ssl/edge-certificates/staging-environment/) 접근 권한 요청도 고려해 보세요.
:::

## 만료된 인증서

만료 예정인 사용자 지정 인증서의 <GlossaryTooltip term="Subject Alternative Names (SANs)">SAN</GlossaryTooltip> 중 일부 또는 전부를 포괄하는 유효한 대체 인증서가 이미 준비되어 있다면, Cloudflare는 만료 24시간 전 이내에 만료 예정 인증서를 제거합니다. 이 전환으로 인한 다운타임은 예상되지 않습니다.

유효한 대체 인증서가 없다면, Cloudflare는 사용자 지정 인증서가 만료된 뒤 이를 제거합니다.

영향을 받는 도메인과 서브도메인은 만료된 인증서의 호스트 이름을 포괄하는 다른 활성 인증서가 있으면 그 인증서로 대체됩니다.

:::caution

[인증서 팩](/ssl/edge-certificates/custom-certificates/#certificate-packs)에 포함된 모든 인증서는 하나의 객체로 취급됩니다.
인증서 팩의 만료일은 팩 안의 인증서들 중 가장 이른 `Not After` 날짜와 같습니다.

예를 들어 ECDSA와 RSA 인증서로 구성된 사용자 지정 인증서가 있다면, 그중 하나가 만료될 경우 전체 팩이 제거됩니다.
:::

## 다른 인증서 유형으로 마이그레이션

더 이상 사용자 지정 인증서를 사용하고 싶지 않지만 웹사이트나 애플리케이션은 계속 SSL/TLS로 보호하고 싶다면 다음을 수행할 수 있습니다.

1. Cloudflare 대시보드에서 **Edge Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/edge-certificates" />

2. 동일한 호스트 이름을 포괄하는 활성 [universal](/ssl/edge-certificates/universal-ssl/) 또는 [advanced](/ssl/edge-certificates/advanced-certificate-manager/) 인증서가 이미 있는지 확인합니다.
3. 사용자 지정 인증서를 삭제합니다.

## 누가 CAA 레코드를 만들어야 하나요?

다음 조건이 모두 참이라면 Cloudflare에서 [CAA 레코드를 생성](#create-caa-records)해야 합니다.

- Cloudflare가 프로비저닝한 것이 아닌, 직접 업로드한 커스텀 원본 서버 인증서를 사용하고 있습니다.
- 해당 인증서는 자체 서명된 것이 아니라 CA에서 발급되었습니다.
- 도메인이 [full setup](/dns/zone-setups/full-setup/)에 있으며([CNAME setup](/dns/zone-setups/partial-setup/) 아님).
- 새 [Custom Hostname](/cloudflare-for-platforms/cloudflare-for-saas/start/getting-started/)을 추가할 때 고객이 기존 CAA 레코드를 가지고 있습니다. 이 경우 고객에게 기존 CAA 레코드를 제거하거나 누락된 CAA 레코드를 추가하도록 요청하세요.

## CAA 레코드 생성

도메인에서 사용할 각 Certificate Authority(CA)에 대해 CAA 레코드를 생성하세요.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

대시보드에서 CAA 레코드를 추가하려면,

1. Cloudflare 대시보드에서 **DNS Records** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/dns/records" />

2. **Add record**를 선택합니다.
3. **Type**에서 **CAA**를 선택합니다.
4. **Name**에 도메인을 입력합니다.
5. 레코드와 연결할 동작을 지정하는 **Tag**를 선택합니다.
6. **CA domain name**에 CA 이름을 입력합니다.
7. **Save**를 선택합니다.
8. 도메인과 연관된 각 CA에 대해 반복합니다.

</TabItem> <TabItem label="API">

API로 CAA 레코드를 생성하려면 이 [POST endpoint](/api/resources/dns/subresources/records/methods/create/)를 사용하세요.

</TabItem> </Tabs>

모든 레코드 생성을 마치면 DNS Records 패널 아래에 표시되는 레코드 목록에서 검토할 수 있습니다.

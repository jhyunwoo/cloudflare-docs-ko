## DCV 상태 확인

인증서의 [DCV 상태](/ssl/reference/certificate-statuses/)를 확인하려면 [**Edge Certificates**](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/edge-certificates) 페이지에서 인증서 상태를 모니터링하거나 [Verification Status endpoint](/api/resources/ssl/subresources/verification/methods/get/)를 사용하세요.

상태가 `active`이면 인증서가 Cloudflare의 글로벌 네트워크에 배포되었으며 HTTP 트래픽이 Cloudflare로 프록시되는 즉시 제공된다는 의미입니다.

[^1]: Cloudflare가 권한 있는 DNS 제공자라는 의미입니다.

[^2]: Cloudflare가 아닌 다른 DNS 제공자가 권한 있는 DNS를 유지 관리한다는 의미입니다.

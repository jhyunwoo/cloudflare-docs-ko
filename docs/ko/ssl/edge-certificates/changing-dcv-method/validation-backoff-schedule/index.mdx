인증 기관(CA)이 도메인에 대한 인증서를 발급하기 전에 도메인 제어 유효성 검사(DCV)가 먼저 완료되어야 합니다. 발급 또는 갱신 중 DCV가 실패하면 Cloudflare는 일정에 따라 자동으로 재시도합니다.

[위임된 DCV](/ssl/edge-certificates/changing-dcv-method/methods/delegated-dcv/)를 사용하거나 [Cloudflare가 사용자를 대신해 자동으로 DCV를 수행](/ssl/edge-certificates/changing-dcv-method/)하는 경우, 이 페이지는 참고용 정보입니다. DCV를 수동으로 수행해야 한다면 검증 일정에 대한 다음 섹션을 참고하고 DCV 토큰에는 [고정된 유효 기간](#dcv-토큰-유효-기간)이 있다는 점을 기억하세요.

:::note

현재 사용 중인 [방법](/ssl/edge-certificates/changing-dcv-method/methods/)과 동일한 `validation_method`를 지정해 [Edit SSL Certificate Pack Validation Method endpoint](/api/resources/ssl/subresources/verification/methods/edit/)를 사용하면 즉시 재검사를 요청할 수도 있습니다.
:::

## DCV 토큰 유효 기간

DCV 프로세스는 발급 CA가 생성한 토큰에 의존합니다. 이 토큰의 유효 기간은 각 CA가 정의합니다.

- Google Trust Services - 14일
- Let's Encrypt - 7일
- SSL.com - 14일

이 기간이 지나면 DCV 토큰은 [CA/B Baseline Requirements](https://cabforum.org/baseline-requirements-documents/)에 따라 만료되며, 새롭고 유효한 토큰을 다시 배치해야 합니다.

## 연속 검사 함수

Cloudflare는 월말로 갈수록 검사 간격이 지나치게 커지는 것을 방지하기 위해 검사 백오프를 최대 4시간으로 제한합니다.

```txt
now() + min((floor(60 * pow(1.05, retry_attempt)) * INTERVAL '1 second'), INTERVAL '4 hours')
```

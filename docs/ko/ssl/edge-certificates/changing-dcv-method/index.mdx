:::note

DCV 프로세스에 포함되는 단계와 관련 당사자에 대해 더 알아보려면 [도메인 제어 유효성 검사 흐름](/ssl/edge-certificates/changing-dcv-method/dcv-flow/)을 참고하세요.

:::

[사용자 지정 인증서](/ssl/edge-certificates/custom-certificates/)의 경우, 인증서를 CA에 요청할 때 DCV는 항상 사용자가 직접 처리합니다.

Cloudflare를 통해 발급되는 인증서는 이 과정이 자동으로 수행될 수도 있고, 다음 섹션에서 설명하는 것처럼 사용자가 조치를 취해야 할 수도 있습니다.

---

## 전체 DNS 설정 - 조치 불필요

도메인이 [**전체 설정**](/dns/zone-setups/full-setup/) 상태라면, 즉 Cloudflare가 권한 있는 네임서버를 운영하고 있다면, Cloudflare가 TXT 레코드를 사용해 사용자를 대신하여 자동으로 DCV를 처리합니다. 자세한 내용은 [Universal SSL 활성화](/ssl/edge-certificates/universal-ssl/enable-universal-ssl/#full-dns-setup)를 참고하세요.

---

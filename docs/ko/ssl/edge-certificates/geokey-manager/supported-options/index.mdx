## 유효한 국가

Geo Key Manager v2를 가진 고객을 위해, 당신은 사용할 수 있습니다`policy`매개 변수는 개별 국가뿐만 아니라 지정합니다. Cloudflare는 지속적으로 지원되는 국가의 수를 확장하고 있습니다. 국가를 나타내려면, 두 개의 터미널 (ISO 3166) 국가 코드를 지정하십시오.

지원 국가의 예는 일본, 캐나다, 인도, 호주입니다.

***

## 가장 높은 보안 데이터 센터

Geo Key Manager v1 및 v2 모두 고객을 위해, 당신은 사용할 수 있습니다`geo_restrictions`매개변수는 Cloudflare의 가장 높은 보안 데이터 센터를 선택합니다.

다음과 같은 측면은 우리의 가장 높은 보안 데이터 센터에 독특하지만, 모든 데이터 센터의 기본 보안 요구 사항은 또한 상세[우리의 블로그](https://blog.cloudflare.com/introducing-cloudflare-geo-key-manager/).

### Pre-scheduled 및 생체 측정 제어 시설 액세스

시설에 액세스 할 수있는 'Cloudflare' 직원은 이전에 액세스 권한을 부여하기 전에 방문을 예정해야합니다.

시설 입구에 대한 액세스는 할당 된 액세스 코드와 결합 된 생체 인식 핸드 리더의 사용을 통해 제어됩니다.

### biometric 독자를 가진 개인 감금소

모든 장비는 biometrics를 통해 통제되는 육체적인 접근을 가진 개인 감금소에 있고 감사 기록에서 기록했습니다.
Entrants는 감금소에 접근하기 전에 5개의 별도의 독자를 통과해야 합니다.

### 외부 보안 제어 및 모니터링

ingress/egress의 모든 포인트는 과거의 검토를 위해 허가한 사용자와 접근 사건을 가진 침입 탐지 체계 (IDS)에 의해 감시됩니다.

### 내부 보안 제어 및 모니터링

ingress/egress의 내부 포인트는 액세스 제어 서브 시스템에 의해 제어되며, mantrap을 통해 경로를 입력합니다. 모든 영역은 모니터 및 닫히는 회로 텔레비전, 데이터는 최소 30 일 동안 유지.

외부 벽은 완벽한이고 강화된 콘크리트, Kevlar 탄알 널, 증기 장벽, 또는 탄알 증거 정면 문과 같은 추가 안전 측정을 통합할지도 모릅니다.

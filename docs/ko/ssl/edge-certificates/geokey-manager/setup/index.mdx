## 지오 키 관리자 v2<InlineBadge preset="beta" />

:::참조

Geo Key Manager v2는 Cloudflare API를 통해만 사용할 수 있습니다.

:::

Geo Key Manager v2는 키가 저장되는 지리적 경계를 선택할 때 고객 유연성을 제공합니다.

사용 방법`policy`필드, 고객은 개인 키가 저장되어야하는 국가 또는 지역의 허용 및 블록 목록을 포함하는 정책을 정의 할 수 있습니다.

API로 Geo Key Manager v2를 사용하려면 일반적으로 단계에 따라[사용자 정의 인증서 업로드](/ssl/edge-certificates/custom-certificates/uploading/#upload-a-custom-certificate).

전송할 때[`POST`](/api/resources/custom_certificates/methods/create/)요청, 포함`policy`개인 키가 저장되어야하는 국가 또는 지역의 허용 및 블록 목록을 포함하는 정책을 정의하는 매개 변수.

:::참조

당신은 또한 접근해야`geo_restrictions`매개 변수, 이는 상호적으로 독점적으로`policy`모수는의 부분입니다[지오 키 관리자 v1](#geo-key-manager-v1).

:::

### 이름 \*

<Example>
  E.U.와 미국의 개인 키를 저장합니다.

  <APIRequest
    path="/zones/{zone_id}/custom_certificates"
    method="POST"
    json={{
  	certificate: "certificate",
  	private_key: "<PRIVATE_KEY>",
  	policy: "(country: US) and (region: EU)",
  	type: "sni_custom",
  }}
  />
</Example>

<Example>
  E.U.의 개인 키를 저장하지만, 프랑스에서

  <APIRequest
    path="/zones/{zone_id}/custom_certificates"
    method="POST"
    json={{
  	certificate: "certificate",
  	private_key: "<PRIVATE_KEY>",
  	policy: "(region: EU) and (not country: FR)",
  	type: "sni_custom",
  }}
  />
</Example>

:::참조

더 많은 정보를 원하시면`policy`분야, 참조[지원 옵션](/ssl/edge-certificates/geokey-manager/supported-options/).

:::

## 지오 키 관리자 v1

<Render file="geokey-manager-v1" product="ssl" />

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    대시보드에서 Geo Key Manager를 사용하려면:

    1. 단계에 따라[사용자 정의 인증서 업로드](/ssl/edge-certificates/custom-certificates/uploading/#upload-a-custom-certificate).
    2. 제품 정보**개인 키 제한**, 다음 옵션 중 하나를 선택:
       - **모든 Cloudflare 데이터 센터에 분산 (optimal performance)**
       - **미국 데이터 센터에만 분산**
       - **E.U. 데이터 센터에만 분산**
       - **가장 높은 보안 데이터 센터에만 분산** ([더 많은 정보](/ssl/edge-certificates/geokey-manager/supported-options/#highest-security-data-centers))
    3. 제품정보**사용자 정의 인증서**.
  </TabItem>

  <TabItem label="사이트맵">
    API로 Geo Key Manager를 사용하려면 일반적으로 단계를 따르십시오.[사용자 정의 인증서 업로드](/ssl/edge-certificates/custom-certificates/uploading/#upload-a-custom-certificate).

    전송할 때[`POST`](/api/resources/custom_certificates/methods/create/)요청, 포함`geo_restrictions`매개변수는 뒤에 오는 선택권의 하나에 놓습니다:

    - `us`
    - `eu`
    - `highest_security`([더 많은 정보](/ssl/edge-certificates/geokey-manager/supported-options/#highest-security-data-centers))
  </TabItem>
</Tabs>

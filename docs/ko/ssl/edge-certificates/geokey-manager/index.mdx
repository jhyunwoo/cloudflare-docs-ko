  TLS 인증서에 사용되는 개인 키가 저장되고 관리되는 것을 제한합니다.
</Description>

Geo Key Manager는 고객이 다른 지리적 위치에 자신의 도메인에 대한 암호화 키를 저장하고 관리 할 수 있으므로 준수 규정을 준수하고 데이터를 안전하게 유지할 수 있습니다.

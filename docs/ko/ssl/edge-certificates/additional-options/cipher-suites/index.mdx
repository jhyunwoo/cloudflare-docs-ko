이 섹션은 방문자의 브라우저와 같은 클라이언트와 Cloudflare 네트워크 사이의 연결에서 사용되는 cipher suite를 다룹니다. Cloudflare와 원본 서버 사이에서 사용되는 cipher suite에 대해서는 [Origin server > Cipher suites](/ssl/origin-configuration/cipher-suites/)를 참고하세요.

:::note

Cloudflare는 SSL/TLS 구성에 대한 [공개 저장소](https://github.com/cloudflare/sslconfig)를 GitHub에서 유지하고 있으며, 커밋 기록에서 변경 사항을 확인할 수 있습니다.

[RC4 cipher suites](https://blog.cloudflare.com/end-of-the-road-for-rc4/)와 [SSLv3](https://blog.cloudflare.com/sslv3-support-disabled-by-default-due-to-vulnerability/)는 더 이상 지원되지 않습니다.
:::

## Cipher suites와 엣지 인증서

기본값으로 사용되는 cipher suite는 모든 Cloudflare 도메인/영역에서 보안과 호환성의 균형을 맞추도록 설계되어 있지만, Qualys SSL Labs 테스트 같은 서드파티 도구에서는 일부가 약한 것으로 간주될 수 있습니다.

기본 옵션([Legacy](/ssl/edge-certificates/additional-options/cipher-suites/recommendations/))이 비즈니스 요구 사항을 충족하지 못한다면, [Advanced Certificate Manager 애드온을 구매](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/acm/)하여 [더 안전한 cipher suite를 지정](/ssl/edge-certificates/additional-options/cipher-suites/customize-cipher-suites/)할 수 있습니다.

커스텀 cipher suite는 호스트명 수준 설정입니다. 한 번 지정되면 [인증서 유형](/ssl/edge-certificates/)(universal, advanced, custom)과 관계없이 해당 호스트명 연결에 사용되는 모든 엣지 인증서에 적용됩니다.

## 관련 SSL/TLS 설정

별도로 구성되지만 cipher suite는 다른 SSL/TLS 설정과 상호작용합니다.

### Minimum TLS Version

클라이언트가 웹사이트나 애플리케이션에 연결할 때 필요한 [최소 TLS 버전](/ssl/edge-certificates/additional-options/minimum-tls/)을 지정할 수 있습니다.

예를 들어 최소 버전으로 TLS 1.1을 선택하면 TLS 1.0을 사용하는 방문자는 거부되고 TLS 1.1, 1.2, 1.3(활성화된 경우)을 사용하는 방문자는 허용됩니다.

각 cipher suite는 자신이 지원하는 최소 프로토콜과 연결됩니다. 즉, cipher suite에서 [더 높은 보안 수준](/ssl/edge-certificates/additional-options/cipher-suites/recommendations/)을 사용하여 TLS 1.0 지원을 중단한다면, 최소 TLS 버전도 그에 맞게 조정해야 합니다.

[Compliance standards](/ssl/edge-certificates/additional-options/cipher-suites/compliance-status/) 때문에 웹사이트 또는 애플리케이션 연결에 허용되는 최소 TLS 버전을 올려야 할 수도 있습니다.

### TLS 1.3

<Render file="tls-13-cipher-limitations" product="ssl" />

Cloudflare는 TLS 1.3 cipher suite에 대해 다음 이름을 반환할 수 있습니다. 아래는 [RFC 8446](https://www.rfc-editor.org/rfc/rfc8446.html) 이름과의 대응입니다.

| Cloudflare                      | RFC 8446                       |
| ------------------------------- | ------------------------------ |
| `AEAD-AES128-GCM-SHA256`        | `TLS_AES_128_GCM_SHA256`       |
| `AEAD-AES256-GCM-SHA384`        | `TLS_AES_256_GCM_SHA384`       |
| `AEAD-CHACHA20-POLY1305-SHA256` | `TLS_CHACHA20_POLY1305_SHA256` |

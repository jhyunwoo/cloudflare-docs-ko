대시보드에서 cipher suite를 구성할 때는 세 가지 선택 모드를 사용할 수 있습니다.

- **By security level**: 미리 정의된 [Cloudflare 권장안](/ssl/edge-certificates/additional-options/cipher-suites/recommendations/) 중에서 선택합니다(Modern[^1], Compatible, Legacy).
- **By compliance standard**: [산업 표준](/ssl/edge-certificates/additional-options/cipher-suites/compliance-status/)에 따라 묶인 cipher suite를 선택합니다(PCI DSS 또는 FIPS-140-2).
- **Custom**: 지원할 cipher suite를 개별적으로 선택합니다.

어떤 모드를 사용하든 다음 구성 조건을 유념해야 합니다. **security level** 또는 **compliance standard** 모드를 사용할 때 일부 동작은 차단될 수 있으며, 그 이유는 이 조건을 기준으로 설명됩니다.

<Details header="Configuration conditions">
	* Cipher suite는 다른 [SSL/TLS settings](/ssl/edge-certificates/additional-options/cipher-suites/#related-ssltls-settings)과 함께 사용됩니다.
	* 특정 TLS 1.3 cipher는 개별 지정할 수 없습니다. 대신 영역 전체에 대해 [TLS
	1.3](/ssl/edge-certificates/additional-options/tls-13/#enable-tls-13)를 활성화하면 Cloudflare가 적용 가능한 모든 [TLS 1.3 cipher
	suites](/ssl/edge-certificates/additional-options/cipher-suites/supported-cipher-suites/)를 사용합니다.
	* 각 cipher suite는 특정 알고리즘(RSA 또는 ECDSA)도 지원하므로, cipher를 선택할 때 엣지 인증서에서 사용 중인 알고리즘을 고려해야 합니다. 이 정보는 [**Edge
	Certificates**](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/edge-certificates) 페이지에 나열된 각 인증서 아래에서 확인할 수 있습니다.
	* [Cloudflare Pages](/pages/) 호스트명에 대해서는 minimum TLS version 또는 cipher suites를 구성할 수 없습니다.
</Details>

## 단계

1. Cloudflare 대시보드에서 **Edge Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/edge-certificates" />

2. **Cipher suites** 설정에서 **Configure**를 선택합니다.
3. cipher suite 선택 모드를 고른 뒤 **Next**를 선택합니다.
4. 미리 정의된 cipher suite 집합을 선택하거나, **Custom**을 선택했다면 허용할 cipher suite를 직접 지정합니다. 이 선택이 Minimum TLS version, TLS 1.3, 인증서 알고리즘(ECDSA 또는 RSA)과 어떻게 상호작용하는지 이해하고 진행하세요.
5. **Save**를 선택해 저장합니다.

:::note[Modern 또는 PCI DSS]
[TLS 1.3](/ssl/edge-certificates/additional-options/cipher-suites/#tls-13)와 함께 사용할 때 Modern은 PCI DSS와 동일합니다.
:::

[^1]: TLS 1.3과 함께 사용할 때 Modern은 PCI DSS와 같습니다.

[Advanced Certificate Manager](/ssl/edge-certificates/advanced-certificate-manager/) 구독이 있으면 Cloudflare와 방문자 브라우저 같은 클라이언트 사이의 연결을 특정 [cipher suites](/ssl/edge-certificates/additional-options/cipher-suites/)로 제한할 수 있습니다.

이 기능은 특정 [권장 사항](/ssl/edge-certificates/additional-options/cipher-suites/recommendations/)을 따르거나, [약한 cipher suite를 비활성화](/ssl/edge-certificates/additional-options/cipher-suites/troubleshooting/#ssl-labs-weak-ciphers-report)하거나, [산업 표준](/ssl/edge-certificates/additional-options/cipher-suites/compliance-status/)을 준수해야 할 때 유용합니다.

Cipher suite를 사용자 지정해도 SSL/TLS 보호에는 다운타임이 발생하지 않습니다.

:::note[Cloudflare for SaaS]
SaaS 공급자로서 [custom hostnames](/cloudflare-for-platforms/cloudflare-for-saas/domain-support/) 연결의 cipher suite를 제한하려는 경우 [Cloudflare for SaaS](/cloudflare-for-platforms/cloudflare-for-saas/) 구독으로 구성할 수 있습니다. 대신 [TLS management](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/enforce-mtls/#cipher-suites)를 참고하세요.
:::

## 동작 방식

커스텀 cipher suite는 호스트명 수준 설정이며, 이는 다음을 의미합니다.

* 영역의 cipher suite를 사용자 지정하면 그 영역의 모든 호스트명에 영향을 미칩니다. Cloudflare zone이 무엇인지 익숙하지 않다면 [Fundamentals](/fundamentals/concepts/accounts-and-zones/#zones)를 참고하세요.
* 이 구성은 [인증서 유형](/ssl/edge-certificates/)(universal, advanced, custom)과 관계없이 해당 호스트명에 연결하는 데 사용되는 모든 엣지 인증서에 적용됩니다.
* 호스트명별 cipher suite 사용자 지정을 사용하려면 해당 호스트명이 인증서에 명시되어 있어야 합니다.

## 범위

현재 가능한 옵션은 다음과 같습니다.

- 영역에 대한 커스텀 cipher suite 설정: [API](/ssl/edge-certificates/additional-options/cipher-suites/customize-cipher-suites/api/) 또는 [대시보드](/ssl/edge-certificates/additional-options/cipher-suites/customize-cipher-suites/dashboard/) 사용
- 호스트명별 커스텀 cipher suite 설정: [API](/api/resources/hostnames/subresources/settings/subresources/tls/methods/update/)에서만 가능. 자세한 내용은 [가이드](/ssl/edge-certificates/additional-options/cipher-suites/customize-cipher-suites/api/) 참고

## 설정 우선순위와 cipher 순서

Cloudflare는 어떤 설정을 적용할지 결정하기 위해 [hostname priority logic](/ssl/reference/certificate-and-hostname-priority/)을 사용합니다.

ECDSA cipher suite는 RSA보다 우선되며, Cloudflare는 지정된 cipher suite의 순서를 그대로 유지합니다. 즉 ECDSA와 RSA를 함께 사용하는 경우, Cloudflare는 먼저 ECDSA cipher를 설정된 순서대로 제시하고, 이어서 RSA cipher를 역시 설정된 순서대로 제시합니다.

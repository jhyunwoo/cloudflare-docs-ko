## 시작하기 전에

다음 사항을 참고하세요.

- Cipher suite를 업데이트하면 인증서가 다시 배포됩니다.
- Cipher suite는 다른 [SSL/TLS settings](/ssl/edge-certificates/additional-options/cipher-suites/#related-ssltls-settings)과 함께 사용됩니다.
- 특정 TLS 1.3 cipher는 직접 지정할 수 없습니다. 대신 영역 전체에서 [TLS 1.3](/ssl/edge-certificates/additional-options/tls-13/#enable-tls-13)을 활성화하면 Cloudflare가 적용 가능한 모든 [TLS 1.3 cipher suites](/ssl/edge-certificates/additional-options/cipher-suites/supported-cipher-suites/)를 사용합니다.
- 각 cipher suite는 특정 알고리즘(RSA 또는 ECDSA)도 지원하므로, cipher를 선택할 때 엣지 인증서에서 사용 중인 알고리즘을 고려해야 합니다. 이 정보는 [**Edge Certificates**](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/edge-certificates) 페이지의 각 인증서 아래에서 확인할 수 있습니다.
- [Cloudflare Pages](/pages/) 호스트명에 대해서는 minimum TLS version 또는 cipher suites를 구성할 수 없습니다.
- Windows를 사용하는 경우 `curl` 문법을 조정해야 할 수 있습니다. 자세한 내용은 [Windows에서 API 호출하기](/fundamentals/api/how-to/make-api-calls/#making-api-calls-on-windows)를 참고하세요.

:::caution
호스트명별 cipher suite 사용자 지정을 설정할 때는 해당 호스트명이 인증서에 명시되어 있어야 합니다(와일드카드로 포괄되는 형태가 아니어야 함). 와일드카드 인증서에 호스트명별 구성을 적용하면 그 구성은 모든 호스트명에 적용됩니다.
:::

## 단계 및 API 예시

1. 지정하려는 cipher suite와 비활성화할 cipher suite(선택 목록에 포함되지 않을 항목)를 결정합니다.

   아래에는 [보안 수준별](/ssl/edge-certificates/additional-options/cipher-suites/recommendations/) 및 [준수 표준별](/ssl/edge-certificates/additional-options/cipher-suites/compliance-status/) 권장 cipher 예시가 있지만, 지원되는 전체 [목록](/ssl/edge-certificates/additional-options/cipher-suites/supported-cipher-suites/)을 참고해 직접 선택을 구성할 수도 있습니다.

2. Cloudflare 대시보드에 로그인한 뒤 [**My Profile** > **API Tokens**](https://dash.cloudflare.com/?to=/:account/profile/api-tokens/)에서 Global API Key를 확인합니다.
3. cipher suite를 지정하려는 도메인의 [Overview page](https://dash.cloudflare.com/?to=/:account/:zone/)에서 Zone ID를 확인합니다.
4. [Edit zone setting](/api/resources/zones/subresources/settings/methods/edit/) 또는 [Edit TLS setting for hostname](/api/resources/hostnames/subresources/settings/subresources/tls/methods/update/) 엔드포인트 중 하나로 API 호출을 수행하고 URL에 `ciphers`를 지정합니다. 선택한 cipher suite 배열을 `value` 필드에 나열합니다.

<Tabs> <TabItem label="modern">

<APIRequest
	path="/zones/{zone_id}/settings/{setting_id}"
	method="PATCH"
	json={{
		value: [
			"ECDHE-ECDSA-AES128-GCM-SHA256",
			"ECDHE-ECDSA-CHACHA20-POLY1305",
			"ECDHE-RSA-AES128-GCM-SHA256",
			"ECDHE-RSA-CHACHA20-POLY1305",
			"ECDHE-ECDSA-AES256-GCM-SHA384",
			"ECDHE-RSA-AES256-GCM-SHA384",
		],
	}}
	parameters={{
		setting_id: "ciphers",
	}}
/>

### 기본값으로 재설정

<Tabs> <TabItem label="zone">

영역 수준에서 기본 cipher suite로 재설정하려면 URL에서 설정 이름을 `ciphers`로 지정한 [Edit zone setting](/api/resources/zones/subresources/settings/methods/edit/) 엔드포인트를 사용하고, `value` 필드에 빈 배열을 전송합니다.

<APIRequest
	path="/zones/{zone_id}/settings/{setting_id}"
	method="PATCH"
	json={{
		value: [],
	}}
	parameters={{
		setting_id: "ciphers",
	}}
/>

</TabItem> <TabItem label="per-hostname">

특정 호스트명 설정의 경우 [Delete TLS setting for hostname](/api/resources/hostnames/subresources/settings/subresources/tls/methods/delete/) 엔드포인트를 사용합니다.

<APIRequest
	path="/zones/{zone_id}/hostnames/settings/{setting_id}/{hostname}"
	method="DELETE"
	parameters={{
		setting_id: "ciphers",
	}}
/>

</TabItem> </Tabs>

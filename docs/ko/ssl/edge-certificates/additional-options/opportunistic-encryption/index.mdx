Opportunistic Encryption은 브라우저가 HTTP URI에 암호화된 TLS 채널을 통해 접근할 수 있게 합니다. HTTPS를 대체하는 기능은 아니지만, 그 외에는 취약할 수 있는 요청에 추가 보안을 제공합니다.

강력한 암호화와 인증이 모두 필요한 경우에는 HTTPS를 사용하세요. HTTP Opportunistic Encryption은 HTTP/2 같은 다른 프로토콜에 TLS를 사용할 수 있도록 하는 방법을 제공합니다. 다만 대부분의 브라우저 주소창에 보이는 초록색 자물쇠와 같은 HTTPS 수준의 보안 표시를 제공하지는 않습니다.

## Opportunistic Encryption 활성화

원본 웹 서버를 Opportunistic Encryption 지원용으로 별도 구성할 필요는 없습니다. Cloudflare 대시보드에서 설정만 변경하면 됩니다.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

대시보드에서 Opportunistic Encryption을 활성화하려면:

1. Cloudflare 대시보드에서 **Edge Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/edge-certificates" />

2. **Opportunistic Encryption** 토글을 **On**으로 전환합니다.

</TabItem> <TabItem label="API">

API로 Opportunistic Encryption 설정을 조정하려면 URI 경로에서 설정 이름을 `opportunistic_encryption`으로 지정하고, `value` 파라미터에 원하는 값(`"on"` 또는 `"off"`)을 넣은 [`PATCH`](/api/resources/zones/subresources/settings/methods/edit/) 요청을 보냅니다.

</TabItem> </Tabs>

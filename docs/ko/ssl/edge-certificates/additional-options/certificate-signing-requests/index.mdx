## CSR 유형

생성할 수 있는 CSR은 두 가지입니다.

- **Zone-level**: 현재 영역과 연결된 인증서를 서명하는 용도로만 사용됩니다.
- **Account-level**: 여러 도메인에 걸쳐 인증서를 발급하는 조직을 위한 것입니다.

## CSR 생성 및 사용

CSR을 생성하려면:

1. Cloudflare 대시보드에서 **Edge Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/edge-certificates" />

2. **Certificate Signing Request (CSR)**에서 **Generate**를 선택합니다.
3. **Scope**를 선택합니다([일부 고객](#csr-유형)만 **Account**를 선택할 수 있음).
4. 양식에 필요한 정보를 입력하고 **Create**를 선택합니다.

CSR을 사용하려면:

1. [**Edge Certificates**](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/edge-certificates) 페이지에서 방금 생성한 CSR 레코드를 **Certificate Signing Request (CSR)** 아래에서 선택합니다.
2. **Certificate Signing Request** 값은 복사하거나 **Click to copy**를 선택합니다.
3. 선택한 Certificate Authority(CA)에서 CSR을 사용해 인증서를 발급받습니다.
4. 인증서를 Cloudflare에 [커스텀 인증서로 업로드](/ssl/edge-certificates/custom-certificates/uploading/)할 때 **Encoding mode**를 **Certificate Signing Request (CSR)**로 선택하고 해당 값을 입력합니다.

   :::note
   특정 영역 또는 계정에 연결된 CSR을 생성하기 전에는 **Encoding Mode** 조정 옵션이 표시되지 않습니다.
   :::

## 인증서 갱신

[커스텀 인증서 갱신](/ssl/edge-certificates/custom-certificates/renewing/) 시에는 이전에 생성한 CSR을 다시 사용해야 합니다.

같은 인증서에 다른 CSR을 사용하는 것은 불가능합니다. 이런 경우 해당 인증서를 새 인증서로 업로드하면서 새 CSR을 선택해야 합니다.

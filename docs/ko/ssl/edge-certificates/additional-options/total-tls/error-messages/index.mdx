[`ERR_SSL_VERSION_OR_CIPHER_MISMATCH`](/ssl/troubleshooting/version-cipher-mismatch/) 오류를 피할 수 있도록 Cloudflare는 TLS 인증서로 보호되지 않는 프록시 DNS 레코드에 대해 `This hostname is not covered by a certificate`라는 오류 메시지를 자동으로 표시합니다.

## 보류 중인 도메인

최근에 [도메인을 추가](/fundamentals/manage-domains/add-site/)했고 영역이 [pending state](/dns/zone-setups/reference/domain-status/)에 있다면, 이 경고는 대부분 무시해도 됩니다.

대부분의 도메인이 **Active**가 되면 Cloudflare가 Universal SSL 인증서를 자동 발급하고, SSL/TLS 적용 범위가 생기면서 경고 메시지도 사라집니다.

:::note

인증서 적용 범위와 발급 시점에는 몇 가지 세부 사항이 있으므로, 도메인이 자동으로 SSL/TLS 보호를 받는지 확인하려면 [Enable Universal SSL certificates](/ssl/edge-certificates/universal-ssl/enable-universal-ssl/)를 검토하세요.

:::

## 활성 도메인

영역이 이미 Cloudflare에서 활성 상태라면, 이 경고는 현재 SSL/TLS 인증서 범위에 포함되지 않는 하위 도메인을 나타냅니다.

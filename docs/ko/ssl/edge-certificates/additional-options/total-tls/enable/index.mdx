프록시된 호스트명에 대해 개별 인증서를 발급하는 [Total TLS](/ssl/edge-certificates/additional-options/total-tls/)를 활성화하려면 다음 지침을 따르세요.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

대시보드에서 Total TLS를 활성화하려면:

1. Cloudflare 대시보드에서 **Edge Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/edge-certificates" />

2. **Total TLS** 토글을 **On**으로 전환하고, 원한다면 발급 **Certificate Authority**를 선택합니다.

</TabItem> <TabItem label="API">

API로 Total TLS를 활성화하려면 `enabled` 파라미터를 원하는 값(`true` 또는 `false`)으로 설정한 [`PATCH`](/api/resources/acm/subresources/total_tls/methods/create/) 요청을 보냅니다.

`certificate_authority` 파라미터에 값을 추가해 원하는 인증 기관을 지정할 수도 있습니다.

</TabItem> </Tabs>

TLS 1.3은 보안과 성능을 향상시키기 위해 지원 가능한 경우 최신 버전의 TLS 프로토콜을 활성화합니다.

## TLS 1.3이란?

TLS 1.3은 [TLS 프로토콜](/ssl/reference/protocols/)의 가장 최신이자 가장 빠르고 안전한 버전입니다.

TLS 1.3 기능을 켜면, 클라이언트가 지원하는 경우 웹사이트로 오가는 트래픽은 TLS 1.3 프로토콜로 제공됩니다. TLS 1.3은 이전 버전보다 지연 시간이 더 낮고 여러 새로운 기능을 포함하며, 현재 주요 브라우저의 최신 버전에서 모두 지원됩니다.

## TLS 1.3 활성화

TLS 1.3은 Cloudflare 대시보드 또는 API를 통해 활성화할 수 있습니다.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

대시보드에서 TLS 1.3을 활성화하려면:

1. Cloudflare 대시보드에서 **Edge Certificates** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls/edge-certificates" />

2. **TLS 1.3** 토글을 **On**으로 전환합니다.

</TabItem> <TabItem label="API">

API로 TLS 1.3 설정을 조정하려면 URI 경로에서 설정 이름을 `tls_1_3`으로 지정하고, `value` 파라미터에 원하는 값(`"on"`, `"zrt"`, `"off"`)을 설정한 [`PATCH`](/api/resources/zones/subresources/settings/methods/edit/) 요청을 보냅니다. `zrt`는 [Zero Round Trip Time Resumption (0-RTT)](https://blog.cloudflare.com/introducing-0-rtt/)을 뜻합니다.

</TabItem> </Tabs>

### 문제 해결

TLS 1.3 구현은 비교적 새롭기 때문에 일부 실패가 발생할 수 있습니다. 오류가 발생하면 다음 정보를 포함해 Cloudflare Support 티켓을 제출하세요.

- 문제를 재현하는 단계(가능한 경우)
- 클라이언트 빌드 버전
- 클라이언트 진단 정보
- 패킷 캡처

Chrome 사용자는 Google에 [net-internals trace](https://dev.chromium.org/for-testers/providing-network-details)를 제출해야 합니다. Firefox 사용자는 [Mozilla에 버그를 보고](https://bugzilla.mozilla.org/home)해야 합니다.

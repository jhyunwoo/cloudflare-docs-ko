Always Use HTTPS는 애플리케이션의 모든 하위 도메인과 호스트에 대해 방문자의 모든 요청을 `http`에서 `https`로 리디렉션합니다.

:::note

이 과정은 인증서 검증에 영향을 주지 않습니다. [HTTP DCV](/ssl/edge-certificates/changing-dcv-method/methods/)를 사용하는 경우에도 Always Use HTTPS를 활성화할 수 있습니다.
:::

Cloudflare는 원본 웹 서버에서 리디렉션을 수행하지 말 것을 권장합니다. 이 경우 [리디렉션 루프 오류](/ssl/troubleshooting/too-many-redirects/)가 발생할 수 있습니다.

## 모든 방문자 트래픽 암호화

애플리케이션의 모든 하위 도메인과 호스트에 대해 트래픽을 리디렉션하려면 **Always Use HTTPS**를 활성화하면 됩니다.

:::note

애플리케이션의 일부만 HTTPS 트래픽을 지원할 수 있다면 **Always Use HTTPS**를 활성화하지 말고, [single redirect](/rules/url-forwarding/single-redirects/)를 사용해 HTTPS로의 리디렉션을 선택적으로 수행하세요. 예시는 [관리자 영역 요청을 HTTPS로 리디렉션](/rules/url-forwarding/examples/redirect-admin-https/)을 참고하세요.
:::

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

대시보드에서 **Always Use HTTPS**를 활성화하려면:

1. Cloudflare 대시보드에서 **SSL/TLS Overview** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls" />

2. [SSL/TLS 암호화 모드](/ssl/origin-configuration/ssl-modes/off/)가 **Off**로 설정되어 있지 않은지 확인합니다. 암호화 모드를 **Off**로 설정하면 Cloudflare 대시보드에서 **Always Use HTTPS** 옵션이 보이지 않습니다.
3. [**Edge Certificates**](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/edge-certificates) 페이지로 이동합니다.
4. **Always Use HTTPS**를 켭니다.

</TabItem> <TabItem label="API">

API로 **Always Use HTTPS**를 활성화 또는 비활성화하려면:

1. [SSL/TLS 암호화 모드](/ssl/origin-configuration/ssl-modes/off/)가 **Off가 아닌지** 확인합니다.
2. URI 경로에서 설정 이름을 `always_use_https`로 지정하고 `value` 파라미터를 원하는 값(`"on"` 또는 `"off"`)으로 설정한 [`PATCH`](/api/resources/zones/subresources/settings/methods/edit/) 요청을 보냅니다.

</TabItem> </Tabs>

## 제한 사항

HTTPS 강제 적용은 [혼합 콘텐츠](/ssl/troubleshooting/mixed-content-errors/) 문제를 해결하지 않습니다. 브라우저는 요청을 보내기 전에 포함된 리소스의 프로토콜을 확인하기 때문입니다. HTTPS로 강제하는 페이지에서는 상대 링크 또는 HTTPS 링크만 사용해야 합니다. Cloudflare는 [Automatic HTTPS Rewrites](/ssl/edge-certificates/additional-options/automatic-https-rewrites/) 기능을 사용해 일부 혼합 콘텐츠 링크를 자동으로 해결할 수 있습니다.

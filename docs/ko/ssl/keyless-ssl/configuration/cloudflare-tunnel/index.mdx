## 2. Tunnel 생성

그다음 Cloudflare Tunnel을 생성합니다.

<Render file="keyless-tunnel-setup" product="ssl" /> <br />

이 단계에서는 **Connect a network** 옵션을 선택하고 키 서버의 사설 IP 주소를 사용해야 합니다.

Tunnel을 생성한 뒤에는 Cloudflare API를 사용해 [List tunnel routes](/api/resources/zero_trust/subresources/networks/subresources/routes/methods/list/)를 호출하고, 이후 단계에 사용할 다음 값을 저장하세요.

- `"virtual_network_id"`
- `"network"`

## 3. Keyless SSL 인증서 업로드

<Render file="keyless-upload-preamble" product="ssl" />

API로 Keyless 인증서를 업로드하려면 `"tunnel"` 객체를 포함한 [`POST`](/api/resources/keyless_certificates/methods/create/) 요청을 보내세요.

```json
"tunnel": {
  "vnet_id": "<VIRTUAL_NETWORK_ID>",
  "private_ip": "<NETWORK>"
}
```

:::note

Tunnel route API에서 `network` 값을 받을 때는 `10.0.0.1/32`처럼 서브넷 마스크가 포함됩니다. 서브넷 마스크를 제거하고 IP 주소(`10.0.0.1`)만 사용하세요.

:::

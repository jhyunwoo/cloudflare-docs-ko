Keyless Delegation은 위임 자격 증명 표준([RFC 9345](https://www.rfc-editor.org/rfc/rfc9345.html))에 대한 Cloudflare의 구현입니다. 위임 자격 증명 사용을 허용하는 특수 확장이 포함된 인증서를 Keyless에 사용하도록 업로드하면, Cloudflare는 자동으로 위임 자격 증명을 생성하고 이 기능을 지원하는 클라이언트에 대해 엣지에서 이를 사용합니다. 핸드셰이크는 Keyless 서버까지 다시 왕복하면서 발생하는 추가 지연 없이 완료되며, [알고리즘 선택 유연성 측면에서도 추가 이점](https://blog.cloudflare.com/keyless-delegation/)이 있습니다.

내부적으로는 주기적으로 위임 자격 증명을 생성하고, Keyless 사용 시 서버가 보내는 Certificate Verify 메시지에 서명하는 것과 동일한 메커니즘을 통해 Keyless로 서명합니다. 이러한 자격 증명은 수명이 짧기 때문에 Keyless를 비활성화하면 생성된 자격 증명은 24시간 이내에 무효가 됩니다. 지원하는 클라이언트는 자격 증명을 검증하고, 서버는 생성한 키를 사용해 TLS 핸드셰이크 응답에 서명할 수 있으므로 왕복이 필요하지 않습니다.

보안상의 이유로 인증서에는 위임 자격 증명 사용을 위한 특별 식별자가 포함되어야 합니다. 이는 NULL 내용을 가진 선택적 X509 확장과 OID `1.3.6.1.4.1.44363.44` 형태를 가집니다. 사용하는 CA가 위임 자격 증명을 지원하려면 코드 변경이 필요할 수 있습니다.

현재 위임 자격 증명을 지원하는 클라이언트는 매우 적고, 이 확장이 포함된 인증서를 발급하는 인증 기관도 소수에 불과합니다. Cloudflare는 DigiCert에서 성공적으로 사용한 경험이 있습니다. Firefox 77 이상은 위임 자격 증명을 지원합니다.

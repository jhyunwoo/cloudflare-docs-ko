Cloudflare의 Keyless SSL 기술은 수직 및 수평 확장, 그리고 가능할 때마다 ECDSA 같은 사전 계산 기법을 사용해 어떤 규모의 워크로드도 수용할 수 있도록 설계되었습니다. 키 서버 아키텍처 설계의 목표는 지연 시간을 최소화하면서 초당 서명 작업 수를 최대화하는 것입니다.

각 키 서버는 워커 풀 모델을 사용합니다. 들어오는 클라이언트 연결은 자체 reader/writer 고루틴 쌍이 처리하고, 암호화 작업은 전역 풀에서 가져온 별도의 워커 고루틴에서 수행됩니다.

필요한 경우 여러 키 서버를 배포하고 원하는 인그레스 로드 밸런싱 구성으로 이들 사이에 분산할 수 있습니다. 완전한 고가용성을 위해서는 예상 워크로드의 두 배를 처리할 수 있을 만큼 충분한 키 서버를 배포해야 합니다.

***

## 키 유형

키 서버는 ECDSA와 RSA 키를 모두 지원하지만, RSA 서명은 [계산 비용이 한 자릿수 이상 더 크기](https://blog.cloudflare.com/ecdsa-the-digital-signature-algorithm-of-a-better-internet/) 때문에 배포 시 필요한 키 서버 수를 계획할 때 사용 키 유형을 고려해야 합니다.

ECDSA 서명은 두 단계로 나눌 수 있습니다. 첫 번째 단계인 난수 값 생성(나중에 개인 키 및 서명할 메시지와 함께 사용됨)이 계산 비용의 대부분을 차지하므로, Cloudflare는 이러한 난수 값을 미리 생성해 지연 시간을 크게 줄입니다. ECDSA 서명 요청은 RSA 서명 요청과 별도의 워커 풀로 계산적으로 분리되어 가능한 한 빠르게 처리됩니다.

추가 세부 사항은 [gokeyless 서버 README 파일](https://github.com/cloudflare/gokeyless#readme)에서 확인할 수 있습니다.

***

## 벤치마크

Cloudflare는 당시 최신 세대의 컴퓨팅 최적화 EC2 인스턴스([c5.xlarge](https://aws.amazon.com/ec2/instance-types/c5/))에서 [Cloudflare의 gokeyless bench 도구](https://github.com/cloudflare/gokeyless/tree/master/cmd/bench)를 사용해 벤치마크를 수행했습니다. 이 인스턴스는 3.0 GHz Intel Xeon 프로세서 기반의 4개 vCPU를 갖고 있습니다.

```txt
c5$ cat /proc/cpuinfo|grep "model name"
model name	: Intel(R) Xeon(R) Platinum 8124M CPU @ 3.00GHz
model name	: Intel(R) Xeon(R) Platinum 8124M CPU @ 3.00GHz
model name	: Intel(R) Xeon(R) Platinum 8124M CPU @ 3.00GHz
model name	: Intel(R) Xeon(R) Platinum 8124M CPU @ 3.00GHz
```

기본적으로 bench는 코어당 하나의 워커 고루틴(4개)과 총 코어 수와 동일한 최대 운영체제 스레드 수(이 경우 `GOMAXPROCS=4`)로 실행됩니다. 예상대로, 그리고 위에서 설명했듯 ECDSA 서명 성능은 RSA보다 훨씬 뛰어납니다. [결과](#results)는 이 c5.xl 머신의 각 코어가 초당 10,000건이 넘는 ECDSA 서명 작업과 약 200건의 RSA 서명 작업을 수행할 수 있음을 보여줍니다.

배포를 계획할 때는 특정 키 서버를 사용해 초당 종료할 것으로 예상되는 최대 신규 TLS 연결 수를 산정하고 그에 맞게 확장하세요. 완전한 고가용성을 위해서는 keyless를 실행하는 각 데이터 센터가 예상하는 전체 워크로드를 처리할 수 있어야 합니다.

### 결과

#### ECDSA

```txt
c5$ bench -ski $ECDSA_SKI -op ECDSA-SHA256 -bandwidth -duration 60s
Total operations completed: 2661570
Average operation duration: 22.543µs
```

#### RSA

```txt
c5$ bench -ski $RSA_SKI -op RSA-SHA256 -bandwidth -duration 60s
Total operations completed: 46560
Average operation duration: 1.288659ms.
```

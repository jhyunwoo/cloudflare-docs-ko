Cloudflare Keyless SSL 서버는 의존성이 거의 없는 단일 바이너리로 실행되며, 견고하고 안정적으로 동작하도록 설계되었습니다. 하지만 키 서버와 Cloudflare 사이의 네트워크는 그렇지 않을 수 있으며, 이 경우 새 TLS 연결이 차단될 수 있습니다.

이 때문에 로드 밸런서 뒤에서 고가용성 구성으로 최소 두 대의 키 서버를 운영할 것을 강력히 권장합니다. 기본값인 TCP 포트 `2407`에서 각 키 서버에 대한 헬스 체크를 설정하고, 필요에 따라 장애 조치를 수행하거나 활성(정상) 키 서버 간에 라운드 로빈으로 분산하세요.

네트워크 가용성과 성능 측면에서는, Cloudflare 글로벌 네트워크가 BGP를 통해 가장 가까운 키 서버로 라우팅할 수 있도록 키 서버의 IP 주소를 여러 데이터 센터에서 광고하는 것(anycast 구성)을 권장합니다. anycast 라우팅을 사용하면 유지 관리를 위해 데이터 센터 하나를 오프라인으로 전환해도 안전합니다.

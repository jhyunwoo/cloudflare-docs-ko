## Cloudflare Keyless SSL 키 서버("key server")

키 서버는 자체 인프라에서 실행하는 데몬입니다. 키 서버는 기본적으로 TCP 포트 `2407`에서 Cloudflare의 키리스 클라이언트로부터 들어오는 요청을 수신하므로, 방화벽과 기타 접근 제어 목록이 [Cloudflare의 IP 범위](https://www.cloudflare.com/ips/)에서 오는 이러한 요청을 허용하도록 해야 합니다.

키 서버는 TLS 핸드셰이크 과정에서 Cloudflare가 접속하며, 새 TLS 연결을 종료하려면 온라인 상태여야 합니다. 기존 세션은 키 서버에 다시 연락하지 않고도 만료되지 않은 TLS 세션 티켓을 사용해 재개할 수 있습니다.

## Cloudflare Keyless SSL 클라이언트("keyless client")

키리스 클라이언트는 Cloudflare 인프라에서 실행되는 프로세스입니다. 키리스 클라이언트는 새 TLS 세션을 설정하는 데 필요한 도움을 받기 위해 TCP 포트 `2407`을 통해 키 서버로 아웃바운드 요청을 보냅니다.

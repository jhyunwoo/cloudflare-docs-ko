Cloudflare Keyless SSL을 사용하는 동안에는 주기적으로 키 서버를 업데이트해야 할 수 있습니다.

키 서버를 업그레이드하려면 다음을 수행하세요.

1. `/etc/keyless`의 내용을 백업합니다.
2. `apt-get update` 또는 `yum update`와 같이 OS 패키지 목록을 업데이트합니다.
3. gokeyless 서버를 업그레이드합니다.
4. Debian/Ubuntu: `apt-get upgrade gokeyless`
5. RHEL/CentOS: `yum install gokeyless`
6. keyless 인스턴스를 다시 시작합니다.
7. systemd: `service gokeyless restart`
8. upstart/sysvinit: `/etc/init.d/gokeyless restart`
9. HTTPS 연결이 예상대로 동작하는지 확인합니다.

:::caution


[고가용성 구성](/ssl/keyless-ssl/reference/high-availability/)을 사용 중이라면, 정상 동작하는 키 서버가 없으면 새 TLS 연결이 Cloudflare 글로벌 네트워크에서 종료되지 못하므로 서버를 한 번에 하나씩 업그레이드하세요.


:::

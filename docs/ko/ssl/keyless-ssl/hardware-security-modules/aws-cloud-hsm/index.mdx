## 시작하기 전에

다음을 준비했는지 확인하세요.

- [AWS CloudHSM 클러스터](https://docs.aws.amazon.com/cloudhsm/latest/userguide/getting-started.html)를 프로비저닝했는지
- [PKCS#11용 적절한 소프트웨어 라이브러리](https://docs.aws.amazon.com/cloudhsm/latest/userguide/pkcs11-library-install.html)를 설치했는지

## 1. 공개 키와 개인 키를 HSM으로 가져오기

공개 키를 가져오기 전에 CA가 제공한 인증서에서 공개 키를 추출합니다. 개인 키 내용을 `privkey.pem`에 넣은 뒤, 아래 명령을 실행해 `pubkey.pm`을 생성합니다(`certificate.pem`은 실제 인증서 파일명으로 바꾸세요).

```txt
keyserver$ openssl x509 -pubkey -noout -in certificate.pem > pubkey.pem
```

이전에 만든 [crypto user](https://docs.aws.amazon.com/cloudhsm/latest/userguide/hsm-users.html#crypto-user)(CU) 계정으로 CloudHSM에 로그인하고, 개인 키를 가져오는 데 사용할 key encryption key를 생성합니다.

```txt
keyserver$ /opt/cloudhsm/bin/key_mgmt_util
Command: loginHSM -u CU -s patrick -p donahue
Command: genSymKey -t 31 -s 16 -sess -l import-wrapping-key
...
Symmetric Key Created.  Key Handle: 658
...
```

위에서 반환된 키 핸들을 참조해 개인 키와 공개 키를 가져온 다음 HSM에서 로그아웃합니다.

```txt
Command: importPrivateKey -f privkey.pem -l mykey -id 1 -w 658
...
Cfm3WrapHostKey returned: 0x00 : HSM Return: SUCCESS
Cfm3CreateUnwrapTemplate returned: 0x00 : HSM Return: SUCCESS
Cfm3UnWrapKey returned: 0x00 : HSM Return: SUCCESS
...
Private Key Unwrapped.  Key Handle: 658


Command: importPubKey -f pubkey.pem -l mykey -id 1
Cfm3CreatePublicKey returned: 0x00 : HSM Return: SUCCESS
...
Public Key Handle: 941


Command: logoutHSM
Command: exit
```

## 2. gokeyless 구성 파일 수정 및 서비스 재시작

키를 배치했으므로 이제 키 서버가 시작 시 읽을 구성 파일을 수정해야 합니다. `object=mykey`와 `pin-value=username:password` 값을 실제로 지정한 키 레이블과 생성한 CU 사용자에 맞게 변경하세요.

`/etc/keyless/gokeyless.yaml`을 열고, 다음 바로 아래에

```yaml
private_key_stores:
  - dir: /etc/keyless/keys
```

다음을 추가합니다.

```yaml
- uri: pkcs11:token=cavium;object=mykey?module-path=/opt/cloudhsm/lib/libcloudhsm_pkcs11_standard.so&pin-value=patrick:donahue&max-sessions=1
```

구성 파일을 저장한 뒤 `gokeyless`를 다시 시작하고 정상적으로 시작되었는지 확인합니다.

```sh
sudo systemctl restart gokeyless.service
sudo systemctl status gokeyless.service -l
```

:::caution[중요]

SoftHSMv2는 개인 키를 디스크에 직접 저장하는 것보다 더 안전하다고 간주해서는 안 됩니다. 아래 예시에서는 이 설치를 안전하게 보호하려는 시도를 하지 않으며, 단순히 시연 목적만을 위해 제공합니다.

:::

---

## 1. SoftHSMv2 설치 및 구성

먼저 SoftHSMv2를 설치하고 기본 위치인 `/var/lib/softhsm/tokens`에 토큰을 저장하도록 구성합니다. 또한 `keyless` 사용자가 이 디렉터리에 접근할 수 있도록 `softhsm` 그룹에 이 디렉터리 권한을 부여해야 합니다.

```bash
sudo apt-get install -y softhsm2 opensc

#...

cat <<EOF | sudo tee /etc/softhsm/softhsm2.conf
directories.tokendir = /var/lib/softhsm/tokens
objectstore.backend = file
log.level = DEBUG
slots.removable = false
EOF

sudo mkdir /var/lib/softhsm/tokens
sudo chown root:softhsm $_
sudo chmod 0770 /var/lib/softhsm/tokens
sudo usermod -G softhsm keyless
sudo usermod -G softhsm $(whoami)

echo 'export SOFTHSM2_CONF=/etc/softhsm/softhsm2.conf' | tee -a ~/.profile
source ~/.profile
```

## 2. 토큰과 개인 키 생성, CSR 생성

다음으로 슬롯 0에 `test-token`이라는 토큰을 생성하고 PIN `1234`로 보호합니다. 이 슬롯에는 `keyless-softhsm.example.com`용 SSL 인증서 RSA 키를 저장합니다.

```sh
sudo -u keyless softhsm2-util --init-token --slot 0 --label test-token --pin 1234 --so-pin 4321
```

```sh output
The token has been initialized.
```

cfssl을 사용해 [개인 키와 인증서 서명 요청(CSR)](https://github.com/cloudflare/cfssl)을 생성합니다. CSR은 인증 기관(CA)에 보내 서명을 받습니다.

```bash
cat <<EOF | tee csr.json
{
    "hosts": [
        "keyless-softhsm.example.com"
    ],
    "CN": "keyless-softhsm.example.com",
    "key": {
        "algo": "rsa",
        "size": 2048
    },
    "names": [{
        "C": "US",
        "L": "San Francisco",
        "O": "TLS Fun",
        "OU": "Technical Operations",
        "ST": "California"
    }]
}
EOF

cfssl genkey csr.json | cfssljson -bare certificate
```

```sh output
2018/08/12 00:52:22 [INFO] generate received request
2018/08/12 00:52:22 [INFO] received CSR
2018/08/12 00:52:22 [INFO] generating key: rsa-2048
2018/08/12 00:52:22 [INFO] encoded CSR
```

## 3. 키 변환 및 가져오기

이제 키를 생성했으므로 우리가 만든 슬롯으로 로드할 차례입니다. 먼저 PKCS#1 형식에서 PKCS#8 형식으로 변환해야 합니다. 가져오는 동안에는 토큰 초기화 시 사용한 토큰과 PIN을 지정하고, 키에 고유한 16진 ID와 레이블을 부여합니다.

```sh
openssl pkcs8 -topk8 -inform PEM -outform PEM -nocrypt -in certificate-key.pem -out certificate-key.p8
sudo chown keyless certificate-key.p8

sudo -u keyless softhsm2-util --pin 1234 --import ./certificate-key.p8 --token test-token --id a000 --label rsa-privkey
```

```sh output
Found slot 915669571 with matching token label.
The key pair has been imported.
```

가져오기 후에는 `pkcs11-tool`로 객체가 토큰에 정상적으로 저장되었는지 확인합니다.

```bash
sudo -u keyless pkcs11-tool --module /usr/lib/softhsm/libsofthsm2.so -l -p 1234 --token test-token --list-objects
```

```sh output
Public Key Object; RSA 2048 bits
  label:      rsa-privkey
  ID:         a000
  Usage:      verify
Private Key Object; RSA
  label:      rsa-privkey
  ID:         a000
  Usage:      sign
```

## 4. gokeyless 구성 파일 수정 및 서비스 재시작

키가 준비되었으므로 이제 키 서버가 시작할 때 읽을 구성 파일을 작성할 차례입니다. `id`는 `softhsm2-util` import 명령에 제공한 16진 ID를 의미합니다. 여기서는 `a000`을 사용했으므로 `%a0%00`으로 인코딩됩니다. `module-path`는 사용하는 Linux 배포판에 따라 조금씩 다르며, Debian에서는 `/usr/lib/softhsm/libsofthsm2.so`여야 합니다.

`/etc/keyless/gokeyless.yaml`을 열고, 다음 바로 아래에

```yaml
private_key_stores:
  - dir: /etc/keyless/keys
```

다음을 추가합니다.

```yaml
- uri: pkcs11:token=test-token;id=%a0%00?module-path=/usr/lib/softhsm/libsofthsm2.so&pin-value=1234&max-sessions=1
```

구성 파일을 저장한 뒤 `gokeyless`를 다시 시작하고 정상적으로 시작되었는지 확인합니다.

```sh
sudo systemctl restart gokeyless.service
sudo systemctl status gokeyless.service -l
```

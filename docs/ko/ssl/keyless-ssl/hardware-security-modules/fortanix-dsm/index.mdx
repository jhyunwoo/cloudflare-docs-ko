Cloudflare Keyless SSL은 FIPS 140-2 Level 3 인증 구현인 [Fortanix Data Security Manager (DSM)](https://www.fortanix.com/platform/data-security-manager)와 함께 사용할 수 있습니다.

[Data Security Manager Enterprise Tier](https://www.fortanix.com/start-your-free-trial)를 사용해야 하며, 그룹과 해당 그룹에 할당된 애플리케이션을 설정해야 합니다.

자세한 안내는 [Fortanix 문서](https://support.fortanix.com/docs/fortanix-data-security-manager-with-cloudflare-integration#50-configure-fortanix-dsm)의 튜토리얼을 따르세요. 이 가이드는 Keyless SSL의 [Public DNS](/ssl/keyless-ssl/configuration/public-dns/) 옵션을 기준으로 하며, Ubuntu 22.04.3 LTS가 실행되는 Azure 배포 가상 머신(VM)에서 테스트되었습니다.

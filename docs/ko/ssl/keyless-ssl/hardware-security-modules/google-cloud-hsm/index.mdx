이 튜토리얼은 FIPS 140-2 Level 3 인증 구현인 [Google Cloud HSM](https://cloud.google.com/kms/docs/hsm)을 사용합니다.

---

## 시작하기 전에

다음이 준비되어 있는지 확인하세요.

- [Google Cloud project](https://cloud.google.com/kms/docs/quickstart#before-you-begin)를 설정했는지

---

## 1. 키 링 생성

Google Cloud HSM을 설정하려면 [key ring을 생성](https://cloud.google.com/kms/docs/hsm#kms-create-key-hsm-web)하고 위치를 지정합니다.

:::note[참고:]

[특정 위치](https://cloud.google.com/kms/docs/locations#hsm-regions)에서만 Google Cloud HSM을 지원합니다.

:::

## 3. 개인 키 가져오기

key ring과 키를 생성한 뒤 [개인 키를 가져옵니다](https://cloud.google.com/kms/docs/importing-a-key).

:::note[참고:]

키를 PEM 형식에서 DER 형식으로 [변환](https://cloud.google.com/kms/docs/formatting-keys-for-import#formatting_asymmetric_keys)해야 합니다.

:::

---

## 4. gokeyless 구성 파일 수정 및 서비스 재시작

키를 가져온 뒤 UI에서 **Resource name**을 복사합니다. 그런 다음 이 값을 `gokeyless` YAML 파일의 `private_key_stores` 아래에 추가합니다.

구성 파일을 저장한 뒤 `gokeyless`를 다시 시작하고 정상적으로 시작되었는지 확인합니다.

```sh
sudo systemctl restart gokeyless.service
sudo systemctl status gokeyless.service -l
```

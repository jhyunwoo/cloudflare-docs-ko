Cloudflare SSL/TLS 인증서 상품과 Cloudflare가 협력하는 CA에 대해 자주 묻는 질문은 이 페이지를 참고하세요.

---

## 일반

### Cloudflare는 RSA와 ECDSA 인증서를 모두 발급하나요?

예. Cloudflare는 RSA와 ECDSA 인증서를 모두 발급할 수 있습니다.

### Cloudflare SSL 인증서는 공유되나요?

아니요. Cloudflare SSL/TLS 인증서는 도메인 간에도, 고객 간에도 공유되지 않습니다.

### Cloudflare 인증서가 여러 개 있으면 어떤 것이 사용되나요?

Cloudflare 인증서는 호스트명 구체성, 영역 구체성, 인증서 유형의 조합에 따라 우선순위가 정해집니다. 자세한 내용은 [Certificate and hostname priority](/ssl/reference/certificate-and-hostname-priority/)를 참고하세요.

### 내 웹사이트에 SSL 인증서가 설치되어 있는데 왜 Cloudflare 인증서가 보이나요?

Cloudflare는 악성 트래픽을 캐시하고 필터링하기 위해 트래픽을 복호화해야 합니다. Cloudflare는 도메인의 [encryption mode](/ssl/origin-configuration/ssl-modes/)에 따라 트래픽을 다시 암호화하거나 origin web server로 평문 트래픽을 보냅니다.

## Certificate authorities (CAs)

### Cloudflare는 어떤 certificate authority를 사용하나요?

Cloudflare는 Let's Encrypt, Google Trust Services, SSL.com, Sectigo를 사용합니다. 제품별 사용 가능한 CA와 알고리즘의 전체 목록은 [certificate authorities reference page](/ssl/reference/certificate-authorities/)에서 확인할 수 있습니다.

Sectigo는 [backup certificates](/ssl/edge-certificates/backup-certificates/)에만 사용됩니다.

### 알아야 할 CA 제한 사항이 있나요?

파이프라인에 있는 각 CA의 제한 사항 목록은 [certificate authorities reference page](/ssl/reference/certificate-authorities/)를 참고하세요. 그곳에서 장치 및 브라우저 호환성 정보도 확인할 수 있습니다.

### Cloudflare가 협력하는 CA를 사용하고 싶지 않습니다. 어떻게 해야 하나요?

Business 또는 Enterprise 요금제를 사용 중이라면 원하는 CA의 [인증서를 업로드](/ssl/edge-certificates/custom-certificates/uploading/#upload-a-custom-certificate)할 수 있습니다.

### 신뢰 저장소에 Cloudflare가 사용하는 CA가 없습니다. 어떻게 해야 하나요?

Cloudflare가 관리형 인증서에 사용하는 모든 CA를 포함하는 [CFSSL trust store](https://github.com/cloudflare/cfssl_trust)를 사용할 수 있습니다.

## CAA 레코드

### CAA란 무엇이며 어떻게 생성할 수 있나요?

자세한 내용은 [CAA 레코드 추가](/ssl/edge-certificates/caa-records/)를 참고하세요.

### Cloudflare는 CAA 레코드를 어떻게 평가하나요?

CAA 레코드는 Cloudflare가 아니라 CA가 평가합니다. 자세한 내용은 [RFC 8659](https://www.rfc-editor.org/rfc/rfc8659.html#name-relevant-resource-record-se)를 참고하세요.

특정 CA 하나 이상을 지정하는 CAA 레코드를 설정해도 Cloudflare가 도메인에 universal 또는 advanced certificate를 발급할 때 어떤 CA를 사용하는지는 영향을 받지 않습니다. 원한다면 [advanced certificate를 주문](/ssl/edge-certificates/advanced-certificate-manager/manage-certificates/)할 때 Cloudflare 인증서와 연관된 CA를 지정할 수 있습니다.

### CAA 레코드를 설정할 때 어떤 위험이 있나요?

대규모 조직에 속해 있거나 여러 담당자가 SSL 인증서 획득을 맡고 있는 조직이라면 조직에 적용되는 모든 CA에서 발급을 허용하는 [CAA 레코드를 포함](/ssl/edge-certificates/caa-records/)하세요. 그렇지 않으면 조직의 다른 부분에서 SSL 발급이 의도치 않게 차단될 수 있습니다.

### Cloudflare CA에서 발급을 허용하려면 어떤 CAA 레코드가 필요한가요?

모든 Cloudflare CA와 연결된 CAA 레코드는 [certificate authorities reference page](/ssl/reference/certificate-authorities/#caa-records)에서 찾을 수 있습니다. Cloudflare를 DNS 공급자로 사용하는 경우 CAA 레코드는 Cloudflare가 대신 추가합니다.

## Universal SSL

### Universal SSL을 사용 중인데 다른 CA를 사용하고 싶습니다. 어떻게 해야 하나요?

CA를 지정하려면 [Advanced Certificate Manager](/ssl/edge-certificates/advanced-certificate-manager/)를 구매해야 합니다. Advanced Certificate Manager를 사용하면 advanced certificate 주문 시 certificate authority를 선택하거나 [Total TLS](/ssl/edge-certificates/additional-options/total-tls/)를 사용할 때 기본 CA를 선택할 수 있습니다.

Business 또는 Enterprise 요금제를 사용 중이라면 원하는 CA의 [인증서를 업로드](/ssl/edge-certificates/custom-certificates/uploading/#upload-a-custom-certificate)할 수 있습니다. 이 경우 인증서 발급과 갱신은 사용자가 직접 관리해야 합니다.

### Cloudflare는 Universal certificate에 대해 RSA와 ECDSA 인증서를 모두 발급하나요?

무료 영역의 Universal certificate에는 ECDSA 인증서만 발급됩니다. 유료 영역에는 RSA와 ECDSA 인증서가 모두 발급됩니다.

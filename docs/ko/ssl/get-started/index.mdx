## Edge certificate 선택

[개념 페이지](/ssl/concepts/#ssltls-certificate)에서 설명한 것처럼 edge certificate는 Cloudflare가 방문자에게 제시하는 SSL/TLS 인증서입니다.

Cloudflare는 애플리케이션의 edge certificate에 대해 다양한 옵션을 제공합니다.

- [**Universal certificates**](/ssl/edge-certificates/universal-ssl/): <GlossaryDefinition term="Universal SSL certificate" />
- [**Advanced certificates**](/ssl/edge-certificates/advanced-certificate-manager/): <Render file="acm-definition" product="ssl" />
- [**Custom certificates**](/ssl/edge-certificates/custom-certificates/): <Render file="custom-certificates-definition" product="ssl" />
- [**Keyless certificates**](/ssl/keyless-ssl/) (Enterprise only): <Render file="keyless-ssl-definition" product="ssl" />

서로 다른 인증서 유형이 일반적인 사용 사례에 어떻게 대응하는지에 대한 자세한 내용은 [Edge certificates](/ssl/edge-certificates/)를 참고하세요.

:::note[SaaS 제공업체용]

<Render file="ssl-for-saas-definition" product="cloudflare-for-platforms" />

자세한 내용은 [Cloudflare for SaaS (managed hostnames)](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/)를 참고하세요.

:::

## Encryption mode 선택

edge certificate를 선택한 후에는 [encryption mode를 선택](/ssl/origin-configuration/ssl-modes/)하세요.

Encryption mode는 (a) 방문자와 Cloudflare 사이, (b) Cloudflare와 origin server 사이 연결을 Cloudflare가 어떻게 암호화할지 지정합니다. 이 두 단계 프로세스에 대한 더 많은 배경은 [개념 페이지](/ssl/concepts/#ssltls-certificate)를 참고하세요.

일부 encryption mode에서는 origin server에서 관리하는 유효한 [origin certificate](/ssl/concepts/#origin-certificate)가 필요하다는 점에 유의하세요. 각 encryption mode 설정 페이지에는 이 요구 사항과 다른 요구 사항이 나열되어 있으며, [origin server와 함께 사용할 다른 Cloudflare 옵션](/ssl/origin-configuration/)도 함께 검토할 수 있습니다. 예를 들어 [Origin CA certificates](/ssl/origin-configuration/origin-ca/)가 있습니다.

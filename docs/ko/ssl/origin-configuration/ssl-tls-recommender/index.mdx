SSL/TLS Recommender는 애플리케이션에 가장 적합한 [Encryption mode](/ssl/origin-configuration/ssl-modes/)를 선택하는 데 도움을 줍니다.

:::caution

Cloudflare는 SSL/TLS Recommender를 [Automatic SSL/TLS](/ssl/origin-configuration/ssl-modes/#automatic-ssltls-default)로 대체하며 사용 중단하고 있습니다.

:::

## Common tasks

### SSL/TLS recommendations 활성화

<Render file="ssl-recommender-prereqs" product="ssl" />

그 다음 SSL/TLS recommender를 활성화할 수 있습니다.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

대시보드에서 SSL/TLS recommendations를 활성화하려면:

1. Cloudflare 대시보드에서 **SSL/TLS Overview** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/ssl-tls" />

2. **SSL/TLS Recommender** 토글을 **On**으로 전환합니다.

</TabItem> <TabItem label="API">

API로 SSL/TLS Recommender 등록 상태를 변경하려면 [`PATCH`](/api/resources/ssl/subresources/recommendations/methods/get/) 요청을 보내고 `enabled` 파라미터를 원하는 값(`true` 또는 `false`)으로 설정합니다.

</TabItem> </Tabs>

### 새 스캔 수동 실행

활성화하면 recommender는 일반적으로 이틀마다 주기적으로 향후 스캔을 실행하며, 새로운 권장 사항이 있으면 알림을 보냅니다.

새 스캔을 수동으로 다시 실행하려면 SSL/TLS recommendations를 비활성화한 뒤 다시 [활성화](#enable-ssltls-recommendations)하세요.

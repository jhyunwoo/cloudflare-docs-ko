기본적으로 Cloudflare 글로벌 네트워크는 [공개적으로 신뢰되는 certificate authorities 목록](https://github.com/cloudflare/cfssl_trust)을 유지합니다. 즉, [Full (strict) encryption mode](/ssl/origin-configuration/ssl-modes/full-strict/)를 사용할 때 Cloudflare는 이 trust store에 포함된 CA가 발급한 오리진 서버 인증서만 신뢰합니다.

<Render file="custom-origin-trust-store-definition" product="ssl" /> <br />

CA가 Custom Origin Trust Store에 업로드되면 Cloudflare는 기본 공개 신뢰 CA를 모두 무시하고, 업로드된 CA만 사용해 오리진 서버 연결을 인증합니다.

## Availability

Custom Origin Trust Store에 접근하려면 zone에서 [Advanced Certificate Manager](/ssl/edge-certificates/advanced-certificate-manager/)가 활성화되어 있어야 합니다.

## 사용 방법

대시보드에서 origin trust store를 관리하려면 [**Origin Server**](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/origin) 페이지로 이동해 **Custom Origin Trust Store** 카드를 사용하세요.

API로 origin trust store를 관리하려면 [API commands](#api-commands)를 참고하세요.

## Limitations

[Full (strict) encryption mode](/ssl/origin-configuration/ssl-modes/full-strict/)가 활성화된 상태에서 업로드한 CA가 만료되고 trust store 안에 대체 가능한 유효한 CA가 없다면, Cloudflare는 오리진 서버 연결을 올바르게 인증할 수 없습니다.

## API commands

#### List Custom Origin Trust Store Details

  - API documentation: [List Custom Origin Trust Store Details](/api/resources/acm/subresources/custom_trust_store/methods/list/)
  - Method: `GET`
  - Endpoint: `/zones/$ZONE_ID/acm/custom_trust_store`

#### Custom Origin Trust Store Details

  - API documentation: [Custom Origin Trust Store Details](/api/resources/acm/subresources/custom_trust_store/methods/get/)
  - Method: `GET`
  - Endpoint: `/zones/$ZONE_ID/acm/custom_trust_store/$CUSTOM_ORIGIN_TRUST_STORE_ID`
    :::note
    `$CUSTOM_ORIGIN_TRUST_STORE_ID`는 [List command](#list-custom-origin-trust-store-details)로 확인할 수 있습니다.
    :::

#### Upload Custom Origin Trust Store

  - API documentation: [Upload Custom Origin Trust Store](/api/resources/acm/subresources/custom_trust_store/methods/create/)
  - Method: `POST`
  - Endpoint: `/zones/$ZONE_ID/acm/custom_trust_store`

#### Delete Custom Origin Trust Store

  - API documentation: [Delete Custom Origin Trust Store](/api/resources/acm/subresources/custom_trust_store/methods/delete/)
  - Method: `DELETE`
  - Endpoint: `/zones/$ZONE_ID/acm/custom_trust_store/$CUSTOM_ORIGIN_TRUST_STORE_ID`
    :::note
    `$CUSTOM_ORIGIN_TRUST_STORE_ID`는 [List command](#list-custom-origin-trust-store-details)로 확인할 수 있습니다.
    :::

hostname별로 Authenticated Origin Pulls를 활성화하면, 지정된 hostname으로 가는 모든 프록시 트래픽이 오리진 웹 서버에서 인증됩니다. Private PKI의 클라이언트 인증서를 사용해 Cloudflare에서 오는 연결을 인증할 수 있습니다.

## Before you begin

:::caution[Warning]

:::

## 1. Upload custom certificate

[Upload A Hostname Client Certificate](/api/resources/origin_tls_client_auth/subresources/hostname_certificates/methods/create/) endpoint를 사용해 커스텀 인증서를 업로드합니다.

:::note

[leaf certificate](/ssl/concepts/#chain-of-trust)를 업로드해야 합니다. 루트 CA를 업로드하면 API는 `missing leaf certificate` 오류를 반환합니다.
:::

<Render file="aop-per-hostname-upload-cert" product="ssl" />

API 응답에서 인증서 `id`를 저장해 두세요. 4단계에서 필요합니다.

## 3. Enable Authenticated Origin Pulls for the hostname

Cloudflare API에 [`PUT`](/api/resources/origin_tls_client_auth/subresources/hostnames/methods/update/) 요청을 보내 특정 hostname에 대해 Authenticated Origin Pulls를 활성화합니다.

2단계에서 오리진에 로깅을 설정했다면, 테스트를 수행하여 Authenticated Origin Pulls가 정상적으로 동작하는지 확인하세요.

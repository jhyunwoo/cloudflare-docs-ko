Authenticated Origin Pulls(AOP)는 오리진 서버로 향하는 요청이 Cloudflare 네트워크에서 온 것인지 확인하도록 도와주며, [Full](/ssl/origin-configuration/ssl-modes/full/) 또는 [Full (strict)](/ssl/origin-configuration/ssl-modes/full-strict/) 암호화 모드 위에 추가적인 보안 계층을 제공합니다.

이 인증은 특히 [Cloudflare Web Application Firewall (WAF)](/waf/)와 함께 사용할 때 중요합니다. WAF와 함께 사용하면 오리진에서 응답을 반환하기 전에 **모든 트래픽**이 평가되도록 할 수 있습니다.

## Aspects to consider

Cloudflare는 [zone-level authenticated origin pulls를 구성](/ssl/origin-configuration/authenticated-origin-pull/set-up/zone-level/)할 수 있도록 인증서를 제공하지만, 이 인증서는 계정 전용이 아니며 요청이 Cloudflare 네트워크에서 왔다는 것만 보장합니다. 더 엄격한 보안이 필요하다면 [오리진에 대한 추가 보안 조치](/fundamentals/security/protect-your-origin-server/)를 고려하고, Authenticated Origin Pulls를 설정할 때 자체 인증서를 업로드해야 합니다.

커스텀 인증서는 [zone-level](/ssl/origin-configuration/authenticated-origin-pull/set-up/zone-level/)과 [per-hostname](/ssl/origin-configuration/authenticated-origin-pull/set-up/per-hostname/) authenticated origin pulls 모두에서 사용할 수 있으며, 도메인이 [FIPS](https://en.wikipedia.org/wiki/Federal_Information_Processing_Standards)를 준수해야 하는 경우 필수입니다.

## Limitations

Authenticated Origin Pulls는 [SSL/TLS encryption mode](/ssl/origin-configuration/ssl-modes/)가 **Off** 또는 **Flexible**로 설정된 경우 적용되지 않습니다.

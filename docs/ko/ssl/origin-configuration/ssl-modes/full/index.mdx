암호화 모드를 **Full**로 설정하면 Cloudflare는 방문자와 Cloudflare 사이의 HTTPS 연결을 허용하고, 오리진과의 연결은 방문자가 요청한 scheme에 따라 수행합니다. 즉 방문자가 `http`를 사용하면 Cloudflare도 오리진에 평문 HTTP로 연결하고, `https`를 사용하면 HTTPS로 연결합니다.

## 사용 시점

오리진이 SSL 인증서를 지원할 수는 있지만 여러 이유로 유효하고 공개적으로 신뢰되는 인증서를 사용할 수 없을 때 **Full** 모드를 선택하세요.

:::note

**Full** 암호화 외에도 [Authenticated Origin Pulls](/ssl/origin-configuration/authenticated-origin-pull/)를 설정해 모든 오리진 요청이 응답 전에 평가되도록 할 수 있습니다.

:::

## Required setup

### Prerequisites

**Full** 모드를 활성화하기 전에 오리진이 포트 443에서 HTTPS 연결을 허용하고, 인증서(self-signed, [Cloudflare Origin CA](/ssl/origin-configuration/origin-ca/), 또는 Certificate Authority에서 구매한 인증서)를 제공하는지 확인하세요. 그렇지 않으면 방문자가 [525 error](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-525/)를 볼 수 있습니다.

## Limitations

오리진이 제시하는 인증서는 **어떤 방식으로도 검증되지 않습니다**. 만료되었거나 self-signed일 수 있고, 요청한 hostname에 대한 CN/SAN 항목이 일치하지 않아도 됩니다.

[**Full (strict)**](/ssl/origin-configuration/ssl-modes/full-strict/)를 사용하지 않으면, 악의적인 제3자가 연결을 탈취하고 자체 인증서를 제시할 가능성이 기술적으로 존재합니다.

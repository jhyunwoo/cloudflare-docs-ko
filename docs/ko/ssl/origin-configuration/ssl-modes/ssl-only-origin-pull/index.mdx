암호화 모드를 **Strict (SSL-Only Origin Pull)**로 설정하면, 방문자가 요청한 scheme과 관계없이 오리진과의 연결은 항상 SSL/TLS를 사용합니다.

오리진이 제시하는 인증서는 [Full (strict) mode](/ssl/origin-configuration/ssl-modes/full-strict/)와 동일한 방식으로 검증됩니다.

## 사용 시점

가능한 가장 안전한 오리진 구성이 필요하고, Enterprise 고객이며, [**Full (strict)** mode](/ssl/origin-configuration/ssl-modes/full-strict/) 요구 사항을 충족할 때 사용합니다.

## Required setup

설정은 일반적으로 [**Full (strict)** mode](/ssl/origin-configuration/ssl-modes/full-strict/)와 같지만, 암호화 모드로 **Strict (SSL-Only Origin Pull)**를 선택합니다.

:::note

**Strict (SSL-Only Origin Pull)** 암호화 외에도 [Authenticated Origin Pulls](/ssl/origin-configuration/authenticated-origin-pull/)를 설정해 모든 오리진 요청이 응답 전에 평가되도록 할 수 있습니다.

:::

Cloudflare에 추가된 도메인은 SSL 인증서를 받아 HTTPS로 트래픽을 제공할 수 있습니다. 하지만 일부 고객은 Cloudflare 사용을 시작한 뒤 HTTPS 트래픽을 처음 제공할 때 콘텐츠 누락이나 페이지 렌더링 문제를 발견합니다.

보통 이 문제는 HTTPS로 제공되는 웹 페이지에서 HTTP 리소스를 요청하기 때문에 발생합니다. 예를 들어 브라우저에 `https://example.com`을 입력했는데, 페이지의 HTML에 `<img src="http://example.com/resource.jpg">`처럼 HTTP로 이미지를 참조하는 경우입니다.

일반적으로 웹사이트가 모든 리소스를 HTTPS로 안전하게 로드하면 방문자는 브라우저 주소 표시줄에서 자물쇠 아이콘을 보게 됩니다.

이는 사이트가 정상적인 SSL 인증서를 가지고 있고, 사이트가 로드하는 모든 리소스가 HTTPS로 로드된다는 뜻입니다. 초록색 자물쇠는 방문자에게 연결이 안전하다는 신호를 제공합니다. [mixed content 발생 증상](#symptoms-of-mixed-content-occurrence) 중 하나는 초록색 자물쇠 대신 다른 아이콘이 표시되는 것입니다.

***

## Mixed content 발생 증상

대부분의 최신 브라우저는 보안 HTTPS 페이지에서 HTTP 요청을 차단합니다. 차단되는 콘텐츠에는 이미지, JavaScript, CSS 또는 페이지의 모양과 동작에 영향을 주는 기타 콘텐츠가 포함될 수 있습니다.

### 브라우저 표시 방식

각 웹 브라우저는 웹사이트의 mixed content에 대해 서로 다른 방식으로 방문자에게 경고할 수 있으며, 예를 들면 다음과 같습니다.

* URL 바 옆의 노란색 삼각형 또는 정보 아이콘
* "secure content"를 언급하는 메시지

### **콘솔 로그**

Mixed content warning의 경우 웹 브라우저는 리소스를 로드하지만 사용자는 URL에서 자물쇠 아이콘을 볼 수 없습니다. 경고 메시지는 브라우저의 디버그 도구에 표시됩니다.

![Screenshot of mixed content warnings displayed in a browser console.](~/assets/images/support/hc-import-mixed_content_warning.png)

Mixed content error의 경우 브라우저는 보안되지 않은 연결을 통해 리소스를 로드하지 않습니다.

![Screenshot of mixed content errors displayed in a browser console.](~/assets/images/support/hc-import-mixed_content_error.png)

이러한 문제를 찾기 위해 브라우저 디버그 도구를 사용하는 방법은 [Chrome](https://developers.google.com/web/fundamentals/security/prevent-mixed-content/fixing-mixed-content) 및 [Firefox](https://developer.mozilla.org/en-US/docs/Web/Security/Mixed_content) 문서에서 확인할 수 있습니다. 또는 페이지 소스를 보고 다른 리소스 경로에 대한 *http\://* 참조를 직접 찾을 수도 있습니다.

## 해결 방법

### 일반적인 조언

Mixed content 오류를 해결하는 방법은 두 가지입니다.

1. HTML 소스에서 HTTP 또는 HTTPS 프로토콜을 명시하지 않고 모든 리소스를 로드합니다.
   예를 들어 `http://domain.com/path/to.file` 대신 `/domain.com/path/to.file`을 사용합니다.
2. 사용하는 Content Management System에 따라 HTTP 리소스를 HTTPS로 자동 재작성하는 플러그인이 있는지 확인합니다. Cloudflare는 [Automatic HTTPS Rewrites](/ssl/edge-certificates/additional-options/automatic-https-rewrites)를 통해 이러한 서비스를 제공합니다.

### WordPress 사용자

Cloudflare는 WordPress 사용자에게 [Cloudflare WordPress plugin](https://wordpress.org/plugins/cloudflare/)을 설치하고, 플러그인 내에서 *Automatic HTTPS rewrites* 옵션을 활성화할 것을 권장합니다.

아래에 나열된 것처럼 Cloudflare가 배포한 post-quantum [hybrid key agreements](/ssl/post-quantum-cryptography/#hybrid-key-agreement)는 여러 소프트웨어에서 지원됩니다. 목록을 최신 상태로 유지하기 위한 [기여](/style-guide/contributions/)는 언제나 환영합니다.

:::caution
아래 목록은 참고용일 뿐입니다. 제3자 소프트웨어에 대한 책임은 각 유지 관리 주체에게 있습니다. 사용은 스스로의 판단에 따라 진행하세요.
:::

## X25519MLKEM768
- [Firefox 132+](https://www.mozilla.org/firefox/) (Desktop) 및 Firefox 145+ (Android)의 기본값
    - QUIC/HTTP3의 경우 Firefox 135+ (Desktop) 사용
- [Chrome 131+](https://www.google.com/chrome/)의 기본값
- [Safari 26+](https://www.apple.com/safari/)의 기본값
    - iOS 26, macOS Tahoe 26 및 기타 [Apple operating systems](https://support.apple.com/122756)에서 시스템 전역 지원
- [Edge 131+](https://microsoft.com/edge/)의 기본값
- 최신 [Opera](https://opera.com) 및 [Brave](https://brave.com)의 기본값
- [Tor Browser 15.0+](https://www.torproject.org/)의 기본값
- Cloudflare의 [Go 포크](https://github.com/cloudflare/go)
- [Go 1.24+](https://go.dev/doc/go1.24#cryptotlspkgcryptotls)의 기본값
- [OpenSSL 3.5.0+](https://www.openssl.org/)의 기본값
- [Node 24.5.0+](https://nodejs.org/) 및 22.20.0+의 기본값([backported](https://nodejs.org/en/blog/release/v22.20.0#openssl-updated-to-352))
- [BoringSSL](https://boringssl.googlesource.com/boringssl/)
- [GnuTLS](https://www.gnutls.org)
    - leancrypto 1.2.0+로 컴파일된 3.8.9+
    - liboqs 0.11.0+로 컴파일된 3.8.8-3.8.9
- [rustls 0.23.22+](https://crates.io/crates/rustls)
- [rpxy 0.9.4+](https://github.com/junkurihara/rust-rpxy)의 기본값
- OpenSSL 3.5+로 컴파일된 [NGINX](https://github.com/nginx/nginx)의 기본값([instructions](https://github.com/nginx/nginx/issues/288))
- [Open Quantum Safe](https://openquantumsafe.org/)
    - C 라이브러리: liboqs 0.10.0+
    - OpenSSL provider: oqs-provider 0.7.0+
- [Zig 0.14.0+](https://ziglang.org/) (client)
- [Caddy HTTP server 2.10.0+](https://caddyserver.com/)의 기본값
- [Traefik](https://traefik.io/traefik/)
    - 3.4.2+, 2.11.26+의 기본값([commit](https://github.com/traefik/traefik/commit/cd16321dd9c25bb47a2e9417b2a4a75959be63d0))
    - [3.5.0-rc.1+](https://github.com/traefik/traefik/releases/tag/v3.5.0-rc1)에서는 `curvePreferences`로 설정 가능
- [Botan C++ library 3.7.0+](https://botan.randombit.net/)

## X25519Kyber768Draft00

- Desktop의 [Chrome 124-130](https://www.google.com/chrome/) 기본값
    - 더 오래된 Chrome 또는 모바일에서는 `chrome://flags`에서 _TLS 1.3 hybridized Kyber support_ (`enable-tls13-kyber`)를 켜세요.
- [Edge 124-130](https://microsoft.com/edge/)의 기본값
- `about:config`에서 `security.tls.enable_kyber`를 켠 경우 [Firefox 124-131](https://www.mozilla.org/firefox)
    - QUIC/HTTP3의 경우 `network.http.http3.enable_kyber`가 설정된 Firefox 128+ 사용
- Cloudflare의 [Go 포크](https://github.com/cloudflare/go)
- [Go 1.23](https://github.com/golang/go/issues/67061)의 기본값
- [BoringSSL](https://boringssl.googlesource.com/boringssl/)
- [GnuTLS](https://www.gnutls.org)
    - liboqs 0.11.0+로 컴파일된 3.8.8-3.8.9
    - liboqs 0.10.1+로 컴파일된 3.8.7
- Cloudflare의 [QUIC-go 포크](https://github.com/cloudflare/qtls-pq)
- Goutam Tamvada의 [Firefox 포크](https://github.com/xvzcf/firefox-pq-demos)
- [Open Quantum Safe](https://openquantumsafe.org/)
    - C 라이브러리: liboqs 0.5.0+
    - OpenSSL provider: oqs-provider 0.5.0-0.8.0
- [Zig 0.11.0-0.13.0](https://ziglang.org/) (client)
- [BoringSSL로 컴파일된](https://mailman.nginx.org/pipermail/nginx/2023-August/NOISOYU3QTB2DGIYUBGF7CAMQHDI2QLT.html) [nginx](https://www.nginx.org/) ([guide](https://blog.centminmod.com/2023/10/03/2860/how-to-enable-cloudflare-post-quantum-x25519kyber768-key-exchange-support-in-centmin-mod-nginx/))
- [Botan C++ library 3.2.0+](https://botan.randombit.net/) ([instructions](https://github.com/randombit/botan/discussions/3747))

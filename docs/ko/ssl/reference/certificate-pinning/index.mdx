Cloudflare는 Universal, Advanced, 또는 Custom Hostname 인증서에 대해 HTTP public key pinning(HPKP)[^1]을 지원하지 않습니다.

이는 Cloudflare가 도메인에 프로비저닝된 edge certificate를 정기적으로 변경하기 때문이며, HPKP가 활성화되어 있으면 도메인이 오프라인이 되기 때문입니다. 또한 [업계 전문가](https://scotthelme.co.uk/im-giving-up-on-hpkp/)들은 HPKP 사용을 권장하지 않습니다.

HPKP가 해결하려는 문제인 인증서 오발급 방지에는 [Certificate Transparency Monitoring](/ssl/edge-certificates/additional-options/certificate-transparency-monitoring/)을 사용하는 것이 더 나은 해결책입니다. 또한 [현대적인 certificate pinning 대안](https://blog.cloudflare.com/why-certificate-pinning-is-outdated/)에 대한 Cloudflare 블로그 글도 참고하세요.

인증서를 pinning할 때 다운타임을 피하려면 [custom certificates](/ssl/edge-certificates/custom-certificates/)를 사용하고 [**user-defined** bundle method](/ssl/edge-certificates/custom-certificates/bundling-methodologies/#user-defined)를 선택하세요. 이렇게 하면 갱신 후 어떤 CA, intermediate, certificate가 사용될지 제어할 수 있습니다.

[^1]: Key pinning은 호스트가 브라우저에 일정 기간 동안 특정 공개 키만 허용하도록 지시하는 방식입니다.

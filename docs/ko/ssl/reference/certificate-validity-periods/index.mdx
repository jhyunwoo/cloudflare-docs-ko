Cloudflare가 관리하는 인증서의 경우, 갱신 시도는 자동 갱신 기간이 시작될 때부터 시작되어 만료 24시간 전까지 계속됩니다. 자동 갱신 기간은 아래 섹션에서 설명한 것처럼 인증서 유효 기간에 따라 달라집니다.

인증서 갱신에 실패했더라도 해당 호스트명에 대해 다른 유효한 인증서가 존재하면, Cloudflare는 만료 24시간 이내에 그 유효한 인증서를 배포합니다.

### Advanced certificates

[advanced certificate](/ssl/edge-certificates/advanced-certificate-manager/manage-certificates/)를 주문할 때 서로 다른 인증서 유효 기간을 선택할 수 있습니다. 각 유효 기간에는 해당하는 자동 갱신 기간이 있으며, 이 시점부터 [갱신 시도](/ssl/reference/certificate-validity-periods/)가 시작됩니다.

| Certificate validity period | Auto renewal period | Notes                                                                                                                                                                              |
| --------------------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 year                      | 30 days             | [SSL.com](/ssl/reference/certificate-authorities/#sslcom)을 사용하는 [advanced certificates](/ssl/edge-certificates/advanced-certificate-manager/)의 Enterprise 고객으로 제한됨 |
| 3 months                    | 30 days             |                                                                                                                                                                                    |
| 1 month                     | 7 days              | [Let's Encrypt](/ssl/reference/certificate-authorities/#lets-encrypt)에서는 지원되지 않음                                                                                         |
| 2 weeks                     | 3 days              | [Let's Encrypt](/ssl/reference/certificate-authorities/#lets-encrypt)에서는 지원되지 않음                                                                                         |

:::note

API 호출에서 사용되는 `validity_days` 파라미터의 자세한 내용은 [Order Advanced Certificate Pack](/api/resources/ssl/subresources/certificate_packs/methods/create/)을 참고하세요.

:::

## 더 짧은 유효 기간의 장점

Cloudflare가 유효 기간이 3개월 이하인 인증서만 발급하는 이유는 두 가지입니다.

첫째, 수명이 짧은 인증서는 키 유출과 잘못된 발급으로 인한 피해를 제한합니다. 손상된 키 자료는 더 짧은 기간 동안만 유효합니다.

둘째, 짧은 인증서는 자동화를 장려합니다. 어떤 작업을 자주 해야 할수록 자동화하고 싶어질 가능성이 커집니다. 자동화는 또한 프로덕션에서 인증서를 만료시키거나 키 자료에 대한 접근 권한을 사람에게 부여하는 일을 줄여 줍니다.

더 짧은 유효 기간의 장점에 대한 자세한 내용은 [Advanced Certificate Manager를 소개하는 블로그 글](https://blog.cloudflare.com/advanced-certificate-manager/)을 참고하세요.

Cloudflare는 다음 TLS 프로토콜을 지원합니다.

* TLS 1.0
* TLS 1.1
* TLS 1.2
* TLS 1.3

TLS 1.0은 인증서 기반 암호화를 사용하는 모든 고객에게 Cloudflare가 [기본값으로 설정하는 버전](/ssl/edge-certificates/additional-options/minimum-tls/)입니다.

클라이언트와 Cloudflare 네트워크 사이에서 지원되는 cipher suite 정보는 [Cipher suites](/ssl/edge-certificates/additional-options/cipher-suites/)를 참고하세요.

## TLS 버전 이해하기

더 높은 TLS 버전은 더 강한 암호화 표준을 의미합니다. TLS 1.2에는 이전 버전에서 발견된 알려진 취약점에 대한 수정 사항이 포함됩니다.

2018년 6월부터 TLS 1.2는 Payment Card Industry(PCI) Security Standards Council이 요구하는 버전입니다. Cloudflare는 PCI 요구 사항을 준수하기 위해 TLS 1.2로 마이그레이션할 것을 권장합니다.

추가적인 보안 및 성능 향상을 제공하는 [TLS 1.3](/ssl/edge-certificates/additional-options/tls-13/)은 2018년 5월 Internet Engineering Task Force(IETF)에서 승인되었습니다.

:::note[PayPal의 TLS 1.2 요구 사항]

Cloudflare를 사용한다고 해서 PayPal의 TLS 1.2 요구 사항에 영향이 있지는 않습니다. 다만 PayPal IPN(Instant Payment Notification)은 [TLS version 1.3](/ssl/edge-certificates/additional-options/tls-13/)을 지원하지 않을 수 있습니다. Cloudflare를 통해 프록시된 트래픽에서 PayPal IPN 문제가 발생한다면 [Minimum TLS version](/ssl/edge-certificates/additional-options/minimum-tls/)을 1.2로 설정해 보세요.

:::

## 사용할 버전 결정

TLS 1.3은 널리 채택되었습니다. 일반적으로 Cloudflare는 최고의 보안을 제공하는 TLS 1.3 설정을 권장합니다.

하지만 모든 브라우저 버전이 TLS 1.2 이상을 지원하는 것은 아닙니다. 비즈니스 상황에 따라 더 강한 암호화 표준 사용에 다음과 같은 제한이 있을 수 있습니다.

* 폭넓은 사용자층을 가진 사이트, 특히 비거래성 사이트에는 TLS 1.0 또는 1.1 사용을 고려하세요. 이렇게 하면 일부 클라이언트가 사이트에 안전하게 연결하지 못할 가능성을 최소화할 수 있습니다.

* 사용자층이 좁고 내부 애플리케이션이나 비즈니스 및 생산성 애플리케이션을 운영하는 사이트에는 Cloudflare가 TLS 1.2를 권장합니다. 이러한 사이트는 이미 더 엄격한 보안 요구 사항을 가지고 있거나 [PCI compliance](/ssl/edge-certificates/additional-options/cipher-suites/compliance-status/) 대상일 수 있습니다. 또한 사용자가 TLS 1.2를 준수하는 브라우저로 업그레이드하도록 해야 합니다.

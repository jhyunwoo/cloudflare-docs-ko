[Universal SSL](/ssl/edge-certificates/universal-ssl/)을 통해 Cloudflare는 무료 SSL/TLS 보호를 제공한 최초의 인터넷 성능 및 보안 회사입니다.
Cloudflare SSL/TLS는 또한 암호화 요구 사항과 인증서 관리 요구 사항을 충족하기 위한 다양한 기능을 제공합니다. 자세한 내용은 [시작하기](/ssl/get-started/)를 참고하세요.

***

## 기능

<Feature header="Total TLS" href="/ssl/edge-certificates/additional-options/total-tls/">
Universal SSL이 제공하는 보호를 확장하여, 보유한 모든 하위 도메인 수준에 대해 인증서를 자동으로 발급할 수 있는 간편한 방법입니다.
</Feature>

<Feature header="Delegated DCV" href="/ssl/edge-certificates/changing-dcv-method/methods/delegated-dcv/">
권한 DNS에 다른 공급자를 사용하더라도 domain control validation(DCV)을 Cloudflare에 위임하여 수동 개입의 필요성을 줄일 수 있습니다.
</Feature>

<Feature header="사용자 지정 TLS 설정" href="/ssl/edge-certificates/additional-options/minimum-tls/">
Cloudflare는 방문자가 웹사이트나 애플리케이션에 연결할 때 사용해야 하는 최소 TLS 버전을 지정하고, 보안 요구 사항에 맞게 [cipher suites를 제한](/ssl/edge-certificates/additional-options/cipher-suites/customize-cipher-suites/)할 수 있도록 지원합니다.
</Feature>

<br />

여러 Cloudflare 요금제에 따른 SSL/TLS 기능 전체 목록과 제공 여부는 [기능 및 사용 가능 여부](/ssl/reference/all-features/)를 참고하세요.

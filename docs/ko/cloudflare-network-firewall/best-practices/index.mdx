기본적으로 Cloudflare 네트워크 방화벽(이전 Magic Firewall)은 Cloudflare의 핵심 DDoS 완화를 통해 통과한 모든 진입 트래픽을 허용합니다. 공격을 완화하고 공격의 표면과 누설을 최소화하기 위해, 우리는 다음 지침을 사용하여 Cloudflare 네트워크 방화벽 규칙을 구현하는 것이 좋습니다.

가장 좋은 방법은 네트워크 방화벽의 현재 진입 둘레 방화벽 규칙을 복제하는 것입니다. 현재 둘레 방화벽 규칙을 수출할 수없는 경우 Cloudflare 네트워크 방화벽 규칙에 규칙을 번역하는 데 도움이되는 구현 관리자에 문의하십시오.

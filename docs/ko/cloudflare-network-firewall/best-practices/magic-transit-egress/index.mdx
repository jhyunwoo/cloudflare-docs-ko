에 대한 제안[미니멀 규칙](/cloudflare-network-firewall/best-practices/minimal-ruleset/)·[확장 규칙](/cloudflare-network-firewall/best-practices/extended-ruleset/)ingress 트래픽에 대한 권장 사항입니다.

Magic Transit egress 트래픽의 경우 다음 정보를 고려하십시오.

- Cloudflare Network Firewall (이전 Magic Firewall) 규칙은 Cloudflare를 통해 Magic Transit ingress 및 egress 트래픽 모두에 적용됩니다.
- 네트워크 방화벽은 Magic Transit egress 트래픽에 대해 유망하지 않습니다.
- Network Firewall은 DDoS 완화 후 두 방향에서 현명하지 않습니다.
- 네트워크 방화벽이 있는 경우 "기본 드롭" 공격 트래픽에 대한 캐치 룰, 당신은 당신의 Magic Transit 접두사에서 소스를 허용하는 이전 규칙을 추가해야합니다 목적지로 목적지**이름 \***&#xC544;웃바운드 egress 트래픽을 허용한다.

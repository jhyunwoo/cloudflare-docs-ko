Cloudflare 네트워크 방화벽 (이전 Magic Firewall)은<GlossaryTooltip term="firewall-as-a-service">방화벽 서비스(FWaaS)</GlossaryTooltip>Cloudflare 글로벌 네트워크에서 전달하여 사무실 네트워크 및 클라우드 인프라를 고급적이고 확장 가능한 보호로 보호합니다. Cloudflare Network Firewall을 사용하면 다양한 표준에 필터 규칙을 적용 할 수 있습니다.<GlossaryTooltip term="data packet">제품정보</GlossaryTooltip>길이, 네트워크에 도달하기 전에 원치 않는 트래픽을 필터링합니다.

Cloudflare Network Firewall은 Wireshark 문법 구문을 사용하며, 네트워크 세계에 공통된 도메인별 언어(DSL)과 다른 제품에 사용되는 동일한 구문을 사용합니다. 이 구문을 사용하면 네트워크에서 트래픽을 정확하게 허용하거나 거부 할 수있는 강력한 규칙을 쉽게 만들 수 있습니다.

Cloudflare Network Firewall은 구매시 사용할 수 있습니다.[매직 트레인](/magic-transit/)또는[Cloudflare 대만](/cloudflare-wan/).

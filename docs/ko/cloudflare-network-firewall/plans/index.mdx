당신이라면[매직 트레인](/magic-transit/)또는[Cloudflare 대만](/cloudflare-wan/)사용자는 Cloudflare Network Firewall (이전 Magic Firewall) 기능의 표준 목록으로 자동으로 제공됩니다. 구매에 사용할 수있는 추가 기능을 위해 아래 고급 기능 목록을 참조하십시오.

## 표준 기능

- 프로토콜 기반의 필터링 규칙, 포트, IP 주소,<GlossaryTooltip term="data packet">제품정보</GlossaryTooltip>길이 및<GlossaryTooltip term="bit field matching">비트 필드 일치</GlossaryTooltip>.
- 규칙의 빠른 전파는 분 미만으로 변경됩니다.
- 단일 대시보드 관리<GlossaryTooltip term="firewall">계정 관리</GlossaryTooltip>및 네트워크 구성.
- 자동화된 배포 및 관리를위한 풀그릴 API — 인프라 코드 플랫폼과 호환[옵션 정보](/terraform/).
- 대시보드의 규칙 당 교통 분석 및 사용[그래프QL API](/analytics/graphql-api/).
- 통합과[Cloudflare WAN 네트워크 A 서비스](/cloudflare-wan/).
- 포함 된 DDoS 보호[매직 트레인](/magic-transit/).

## 고급 기능

모든 표준 기능은 다음과 같은 고급 기능의 구매에 포함되어 있습니다.

- Customizable IP 명부.
- 관리 위협 인텔리전스 IP 목록 (Anonymizer, Botnet, Malware, Open Proxies, VPNs).
- 국가별로 사용자 위치를 기반으로 Geoblocking.
- 블록 또는 Autonomous System Number(ASN)을 기반으로 패킷을 허용한다.
- 네트워크 문제 해결에 대한 수요에 패킷 캡처.
- [프로토콜 검증 규칙](/cloudflare-network-firewall/about/protocol-validation-rules/)트래픽 유효성을 검사하고 긍정적 인 보안 모델을 시행합니다.
- [보안 웹 게이트웨이](/cloudflare-one/traffic-policies/)아웃바운드 인터넷 트래픽 필터링 (network 및 HTTP 정책). Secure Web Gateway는 모든 TCP 및 UDP 포트를 지원하며, RFC 1918 주소 공간의 트래픽을 지원합니다. Gateway는 기본 Cloudflare IP 또는 할당 된 을 통해 egress에 BYOIP 트래픽을 프록시합니다.[전용 egress IP](/cloudflare-one/traffic-policies/egress-policies/dedicated-egress-ips/).
- 침입 검출 시스템 (IDS).

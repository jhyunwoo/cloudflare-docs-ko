[IP 목록](/waf/tools/lists/custom-lists/#ip-lists)Cloudflare의 사용자 정의 목록의 일부입니다. 사용자 지정 목록에는 동일한 유형의 하나 이상의 항목이 포함되어 있습니다 - IP 주소, 호스트 이름 또는 ASNs - 규칙 표현에서 참고 자료 할 수 있습니다.

IP 목록은 계정 수준에 정의되어 있으며 상대방과 일치하기 위해 사용될 수 있습니다.`ip.src`·`ip.dst`사이트 맵 현재 Cloudflare Network Firewall (이전 Magic Firewall)은 이러한 목록에서 IPv4 주소를 지원하며 IPv6가 아닙니다.

이 기능을 사용하려면:

## 1. 만들기[새로운 IP 목록](/api/resources/rules/subresources/lists/methods/create/).

예를 들면:

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/rules/lists \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>" \
--header "Content-Type: application/json" \
--data '{
  "name": "iplist",
  "description": "This contains IPs that should be allowed.",
  "kind": "ip"
}'
```

## 2. 리스트에 IP 추가

다음 것,[비밀번호](/api/resources/rules/subresources/lists/subresources/items/methods/create/). 이것은 현재 명부에 성분을 추가할 것입니다.

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/rules/lists/{list_id}/items \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>" \
--header "Content-Type: application/json" \
--data '[
  {"ip":"10.0.0.1"},
  {"ip":"10.10.0.0/24"}
]'
```

## 3. 규칙에 목록 사용

마지막으로, 네트워크 방화벽 규칙은 기존의 규칙으로 목록을 참조:

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/rulesets/{ruleset_id}/rules \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "action": "skip",
  "action_parameters": {
    "ruleset": "current"
  },
  "expression": "ip.src in $iplist",
  "description": "Allowed IPs from iplist",
  "enabled": true
}'
```

## 관리 목록

요금 제한 정책 (베타) 특정 위치에 대한 네트워크에 들어오는 트래픽을 관리 할 수 있습니다.

이 가이드는 수신 패킷 일치를 할 때 정책을 만드는 방법을 가르치고, 당신의 비율이 특정 값을 초과하는 경우 (서버 또는 비트에서).

:::참조
Cloudflare를 위해 고급 네트워크 방화벽 고객, 제한 속도 (beta)는 계정 팀을 통해 요청할 수 있습니다.
주요 특징

## 정책 추가

정책을 추가하려면:

1. Cloudflare 대시보드에서[방화벽 정책](https://dash.cloudflare.com/?to=/:account/network-security/magic_firewall)사이트 맵
2. 선택하기**비율 제한**탭, 다음 선택**정책 추가**.
3. 귀하의 새로운 정책에 대한 정보를 작성:
   - 선택하기**제품정보**: 순간에, 당신은 단지 선택할 수 있습니다[colo 이름](https://developers.cloudflare.com/ruleset-engine/rules-language/fields/cloudflare-network-firewall/).
   - 선택하기**회사연혁**: 선택**이름 \***&#xB610;는**로그인**.
   - 선택하기**제품정보**.
4. 당신이 할 때, 선택**자주 묻는 질문**.

## 기존 정책 편집

정책 편집:

1. Cloudflare 대시보드에서[방화벽 정책](https://dash.cloudflare.com/?to=/:account/network-security/magic_firewall)사이트 맵
2. 선택하기**비율 제한**탭.
3. 목록에서 편집하고 선택하려는 정책을 찾습니다**제품정보**.
4. 변경 사항 및 선택 사항**편집 정책**.

## 기존 정책 삭제

기존 정책을 삭제하려면:

1. Cloudflare 대시보드에서[방화벽 정책](https://dash.cloudflare.com/?to=/:account/network-security/magic_firewall)사이트 맵
2. 선택하기**비율 제한**탭.
3. 목록에서 삭제하려는 정책을 찾습니다.
4. 세 개의 도트를 삭제, 다음 선택**기타 제품**.

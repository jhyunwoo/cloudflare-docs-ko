Cloudflare의 침입 검출 시스템 (IDS)은 Cloudflare Advanced Network Firewall (이전 Magic Firewall) 기능으로 트래픽의 다양한 알려진 위협 서명을 모니터링 할 수 있습니다. IDS는 방화벽의 보안 범위를 확장하여 더 넓은 위협 데이터베이스에 대한 트래픽을 분석하고 랜섬웨어, 데이터 여과 및 네트워크 스캔과 같은 다양한 정교한 공격을 감지합니다. 서명 또는 네트워크 트래픽에 기반한 네트워크 스캔.

Cloudflare의 글로벌 anycast 네트워크로, 당신은 얻을:

- Cloudflare의 전체 글로벌 네트워크 용량은 이제 IDS의 용량입니다.
- 중복 및 실패로 내장. 모든 서버는 Cloudflare의 IDS 소프트웨어를 실행하고 트래픽은 소스에 가장 가까운 네트워크 위치에 자동으로 끌어 들입니다.
- Cloudflare의 IDS 기능 향상을 위한 지속적인 배치.

더 알아보기[IDS 사용](/cloudflare-network-firewall/how-to/enable-ids/)IDS를 활성화하고 새로운 규칙 만들기에 대한 자세한 내용은. IDS가 활성화되면 트래픽이 악의적인 트래픽을 찾을 수 있습니다. 검출은 대시보드에서 구성할 수 있는 대상에 기록됩니다. 더 알아보기[IDS로 Logpush 사용](/cloudflare-network-firewall/how-to/use-logpush-with-ids/)탐지를받을 대상을 구성하는 방법에 대한 지침. 또한 분석 된 모든 트래픽은 통해 액세스 할 수 있습니다.[네트워크 분석](/analytics/network-analytics/). 참고[GraphQL 분석](/cloudflare-network-firewall/tutorials/graphql-analytics/)분석 데이터를 쿼리합니다.

아래 내용을 검토하여 Cloudflare Network Firewall (이전 Magic Firewall)과 관련된 개념에 대해 자세히 알아보십시오.

:::카ution\[중요]

Cloudflare 네트워크 방화벽을 사용하여 프록시 트래픽 (예를 들어, CDN 및 Spectrum)을 다른 Cloudflare 서비스를 따라 다음의 인식이됩니다.

- 소스 IP 주소를 기반으로 트래픽을 차단하는 방화벽 규칙은 Cloudflare가 들어오는 TCP 연결을 종료 한 후 평가되지 않기 때문에 의도하지 않을 수 있습니다.
- 당신은 허용해야[Cloudflare IP 주소](https://www.cloudflare.com/ips/).
- Cloudflare 네트워크 방화벽을 사용할 때 파편<GlossaryTooltip term="data packet">제품정보</GlossaryTooltip>검사되기 전에 완전한 소포로 reassembled. 결과적으로 파편의 방화벽 규칙을 만들 수 없습니다.

:::

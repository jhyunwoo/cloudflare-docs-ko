Cloudflare 네트워크 방화벽(이전 Magic Firewall) 지원[세션 시작 프로토콜 (SIP)](https://datatracker.ietf.org/doc/html/rfc2543)트래픽 유효성을 검사하고 긍정적 인 보안 모델을 시행합니다.

당신은 사용할 수 있습니다`sip`패킷이 유효한 SIP Layer 7 (L7) 프로토콜인지 결정하는 규칙을 만들 때 필드. 더 알아보기[Cloudflare 네트워크 방화벽 필드](/cloudflare-network-firewall/reference/network-firewall-fields/), 특히`sip`필드, 이 항목에 대한 자세한 내용은.

추가 프로토콜을 지원하는 Cloudflare Network Firewall이 필요한 경우 계정 관리자에게 문의하십시오.

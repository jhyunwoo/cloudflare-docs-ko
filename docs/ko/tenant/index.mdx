Cloudflare Tenant API는 채널 및 얼라이언스 파트너가 고객에게 Cloudflare 계정 및 서비스를 설정하고 관리하기 위해 프로비저닝 메커니즘입니다.

이 API는 클라이언트 v4 API 라이브러리에 내장되어 간소화된 온보드 및 설정 경험을 제공합니다.

## 관련 자료

Tenant API로 다이빙하면 다음 리소스를 활용하십시오.

- [Tenant 구조](/tenant/structure/)Tenant API 뒤에 몇 가지 기본 아이디어를 설명하고 어떻게 작동.
- [시작하기](/tenant/get-started/)고객 계정을 업 및 실행할 수있는 가장 빠른 경로를 제공합니다.
- [이름 \*](/tenant/how-to/)특정 작업에 대한 단계별 지침을 제공합니다.
- [관련 항목](/tenant/reference/)Tenant API에 대한 자세한 정보를 포함, 사용 가능한 영역 및 계정 수준의 구독 목록을 포함하여.

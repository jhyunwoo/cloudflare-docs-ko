## Step 2 - Grant 사용자 액세스

이제 계정을 만들었으므로 Cloudflare에 직접 액세스하거나 상호 작용하는 인터페이스를 구축해야합니다.

첫 번째 방법은 고객에게 Cloudflare의 모든 측면에 대한 제어를 제공합니다. 후자는 고객의 CloudflareXQ 경험을 대시보드XQ로 제어하고 이미 익숙해질 수 있습니다.

### 옵션 1 - Cloudflare에 직접 액세스

계정에 사용자 액세스를 부여 할 때 Cloudflare는 사용자에게 초대를 보내하므로 계정에 액세스 할 수 있습니다. 이미 CloudflareXQ 사용자가없는 경우 CloudflareXQ는 하나의 생성 과정을 통해 수행됩니다. 생성되면 계정과 이미 생성된 모든 영역에 액세스할 수 있습니다.

#### 대시보드

고객이 개별 계정에 액세스 할 것을 원한다면, 당신은 같은 것입니다[teammate 소개](/fundamentals/manage-members/manage/#add-account-members)계정 관리

#### API 사용

API를 사용하여 QXQX0002XQQ 대시보드에 액세스 할 수도 있습니다.

```bash title="Request"
curl 'https://api.cloudflare.com/client/v4/accounts/<CUSTOMER_ACCOUNT_ID>/members' \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>" \
--header "Content-Type: application/json" \
--data '{
  "email": "<CUSTOMER_EMAIL>",
  "roles": ["<USER_ROLE>"]
}'
```

대부분의 경우, 새로운 사용자를 역할로 만들려면`Administrator`항상 ID가`05784afa30c1afe1440e79d9351c7430`.

고객이 엔터프라이즈 플랜에 있다면, 사용자 역할의 광범위한 설정에 액세스해야 합니다. 유효한 역할의 전체 목록을 얻으려면, 보내[`GET`](/api/resources/accounts/subresources/roles/methods/list/)API에 요청.

### 옵션 2 - 인터페이스를 통해 액세스

고객이 CloudflareXQ를 사용하거나 고객이 기존 대시보드XQ를 사용하려는 경우 이미 알고있는 사용자의 QXQXQXQXQ를 사용하여이 경험을 구축 할 수 있습니다.

이것은 당신이 당신의 고객을 대신에 CloudflareXQ에 API 전화를 만드는 것을 의미합니다. 관련 기사[가격 제한](/fundamentals/api/reference/limits/)우리의 API에 의하여, Cloudflare는 당신이 당신의 고객의 각각을 위한 계정 그리고 사용자를 창조하는 것을 추천합니다. 고객의 변화`A`자주 묻는 질문`A`고객의 변화`B`자주 묻는 질문`B`.

:::참조

이 기능은 기본적으로 활성화되지 않습니다. 이 기능을 필요로 하는 경우에, 접촉[Cloudflare 지원](/support/contacting-cloudflare-support/).

:::

인터페이스를 통해 액세스 권한을 부여하려면, 당신은 서비스 사용자를 만들 필요가있다, 어느 하나는 그들과 대시보드XQ에 로그인합니다. 이 메소드를 사용할 계획이라면 Cloudflare는 API 키가 API 호출을 만드는 데 사용할 수 있습니다.

```bash title="Request"
curl "https://api.cloudflare.com/client/v4/users" \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>" \
--header "Content-Type: application/json" \
--data '{
  "email": "<ID@example.com>"
}'
```

## 3 단계 - 영역 만들기

이제 고객 계정과 고객 사용자 (또는 서비스 사용자)가 있고, 당신은 영역을 만들 필요가있다.

이렇게하려면[`POST`](/api/resources/zones/methods/create/)요청하기`/zones`endpoint (고객 계정 ID 포함)[단계 1](#step-1---create-an-account)).

```bash title="Request"
curl "https://api.cloudflare.com/client/v4/zones" \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>" \
--header "Content-Type: application/json" \
--data '{
  "name": "example.com",
  "account": {
    "id": "<CUSTOMER_ACCOUNT_ID>"
  }
}'
```

시간 :[계정의 제공 서비스](/tenant/how-to/manage-subscriptions/), 각 API 호출과 특정 값을 특정 서비스를 지정할 필요가 있습니다.

현재 파트너 프로그램에 따라 사용할 수 있는 구독은 다릅니다 ([기업 파트너 프로그램](https://www.cloudflare.com/cloudflare-partners-self-serve-program-closed-beta/)또는[엔터프라이즈 리셀러 및 MSP 프로그램](https://portal.cloudflarepartners.com)).

다음과 같은 값은 샘플이며 소진되지 않습니다. 당신이 사용할 수있는 구독 값의 전체 목록의 경우, API 호출을[지역 구독](/api/resources/zones/subresources/rate_plans/methods/get/)또는[계정 구독](/api/resources/accounts/subresources/subscriptions/methods/get/)끝점.

## 지역 계획

창조하거나 업데이트 할 때[지역 계획](/api/resources/zones/subresources/subscriptions/methods/get/), 파트너는 다음 값 중 하나를 사용할 수 있습니다`id`이름 \*`rate_plan`필드 (zone-level 계획 구독을 제어).

| 파트너 프로그램        | 이용 약관                                                           |
| --------------- | --------------------------------------------------------------- |
| 기업 및 셀프 서비스 리셀러 | `PARTNERS_FREE`, `PARTNERS_PRO`, `PARTNERS_BIZ`, `PARTNERS_ENT` |
| 기업 파트너          | `CF_FREE`, `CF_PRO_20_20`, `CF_BIZ`                             |
| MSP 파트너         | `msp_biz`                                                       |

## 새로운 구독 받기

리셀러 플랜이 특정 구독에 액세스하지 않으면 API 호출을 만들 때 다음 오류를 받게됩니다.

```json
"errors": [
        {
            "code": 1225,
            "message": "Your account does not have access to this product. Contact billing@cloudflare.com for assistance."
        }
]
```

프로그램을 변경하거나 - 일부 경우에 - 당신의 리셀러 계획에 추가 특정 가입을 얻을, 접촉`partners@cloudflare.com`. 기관 파트너는 접촉해야 합니다[모델 번호: agency@cloudflare.com](mailto:agency@cloudflare.com)

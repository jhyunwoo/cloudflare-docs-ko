## 계정 보기

Tenant API로 계정을 만들 때 Cloudflare 사용자는 생성, 지속적인 관리 및 최종 삭제에서 계정을 소유합니다.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    대시보드XQ를 사용하여 열거된 모든 계정 보기:

    1. 로그인[Cloudflare 대시보드](https://dash.cloudflare.com).
    2. 오시는 길**회사 소개** > **관리 계정**.
  </TabItem>

  <TabItem label="사이트맵">
    API를 사용하여 tenant에 의해 소유 된 모든 계정을 가져오려면,[`GET`](/api/resources/accounts/methods/list/)요청하기`/accounts`끝점.

## 업데이트 계정

계정을 업데이트하려면[`PUT`](/api/resources/accounts/methods/update/)요청하기`/accounts/{account_id}`끝점.

## 계정 삭제

생성된 계정을 삭제하려면`DELETE`요청하기`/accounts/{account_id}`끝점.

계정 삭제는 영구적이며 계정의 밑에 모든 영역 또는 다른 리소스를 삭제합니다.

```bash title="Request"
curl --request DELETE \
https://api.cloudflare.com/client/v4/accounts/{account_id} \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>"
```

성공적인 요청은 작동을 확인하기 위해 ID를 반환합니다.

```json title="Response"
{
	"result": {
		"id": "1b16db169c9cb7853009857198fae1b9"
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

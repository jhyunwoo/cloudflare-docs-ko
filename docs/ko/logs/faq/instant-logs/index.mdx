[자주 묻는 질문](/logs/faq/)

### 웹소켓에 연결하려고 시도 할 때 HTTP 301을 얻는다. 무엇을 할 수 있습니까?

자주 묻는 질문`wss://`WebSocket에 연결할 때 프로토콜.

### 나는 HTTP 429을 얻고있다. 무엇을 할 수 있습니까?

연결 요청은 제한됩니다. 몇 분 동안 다시 요청을 시도하십시오.

### 왜 데이터를받지 않습니까?

먼저 필터가 정의된 경우 이중 검사. 당신이 할 경우, 그것은 너무 엄격한 될 수있다 (또는 잘못된) 모든 데이터를 삭제.

필터에 자신감이있는 경우 세션을 만들 때 사용되는 샘플 속도를 확인하십시오. 예를 들어, 100의 샘플은 각 100의 요청에 대해 하나의 로그를 받게됩니다.

마지막으로, 목적지가 Cloudflare (또한 오렌지 클라우드로 알려져 있음)를 통해 예상됩니다. Cloudflare의 글로벌 네트워크를 통해 갈 수없는 경우 요청을 로그 할 수 없습니다.

### 나는 오류가 내 데이터를 fetching. 어떻게 해결할 수 있습니까?

올바른 권한이 있는지 확인하십시오. Super Administrator, Administrator, Log Share 또는 Log Share Reader 권한이 필요합니다.

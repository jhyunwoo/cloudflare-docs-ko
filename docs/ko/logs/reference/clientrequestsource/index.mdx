가능한 값`ClientRequestSource`필드는 다음과 같습니다 :

| 제품정보 | 회사 소개                  | 이름 \*                                                                             |
| ---- | ---------------------- | --------------------------------------------------------------------------------- |
| `0`  | 이름 \*                  | 하지 않습니다.                                                                          |
| `1`  | 아이볼                    | 최종 사용자의 요청. 요청을 계산하려는 경우 Cloudflare Edge, 쿼리를 필터링해야합니다`requestSource=eyeball`.    |
| `2`  | 사이트맵                   | Cloudflare의 퍼지 시스템에 의해 한 요청.                                                      |
| `3`  | 항상온라인                  | Cloudflare의 항상 온라인 크롤러에 의해 한 요청.                                                  |
| `4`  | 건강검진                   | Cloudflare의 건강 검사 체계에 의해 한 요구.                                                    |
| `5`  | 연락처                    | 가장자리 노동자에게서 한 fetch 요구.                                                           |
| `6`  | 연락처                    | Edge Worker에서 만든 캐시 API 호출.                                                       |
| `7`  | EdgeWorkerKV의 특징       | 가장자리 노동자에게서 한 KV 외침.                                                              |
| `8`  | 이미지예약                  | Cloudflare의 이미지 반응 제품에 의해 한 요청.                                                   |
| `9`  | 오렌지ToOrange            | 다른 오렌지 클라우드 영역에서 오는 요청.                                                           |
| `10` | 네트워크                   | Cloudflare의 요청[SSL 검출 시스템](https://blog.cloudflare.com/ssl-tls-recommender/).     |
| `11` | 초기 HintsCache          | 이름 \*[상세 정보 Hint 요청](https://blog.cloudflare.com/early-hints/).                   |
| `12` | inBrowserChallenge의 장점 | Cloudflare 보안 제품 (Challenges, JavaScript 탐지)에 기인한 최종 사용자 요구. 이 요청은 원래에 도달하지 않습니다. |

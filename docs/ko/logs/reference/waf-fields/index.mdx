Web Application Firewall (WAF)는 Cloudflare가 관리하여 악성 콘텐츠를 포함하는 요청을 차단하는 규칙을 포함합니다.

## WAF 활동

| 제품정보                                       | - 연혁  | 이름 \*                       |
| ------------------------------------------ | ----- | --------------------------- |
| <span style="font-weight: 400;">`0`</span> | 이름 \* | 다른 작업을 수행하지 마십시오.           |
| <span style="font-weight: 400;">`1`</span> | 지원하다  | WAF 규칙을 우회하십시오.             |
| <span style="font-weight: 400;">`2`</span> | 팟캐스트  | HTTP 403 응답 블록.             |
| <span style="font-weight: 400;">`3`</span> | 도전가능  | 관리적인 도전을 발행합니다.             |
| <span style="font-weight: 400;">`4`</span> | 도전 드롭 | 사용되지 않음                     |
| <span style="font-weight: 400;">`5`</span> | 로그인   | 이벤트를 로깅하지 않고 다른 작업을 수행하십시오. |

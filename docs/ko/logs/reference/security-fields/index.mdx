보안 필드는 특정 유형의 콘텐츠를 포함하는 요청을 차단하는 규칙을 포함합니다.

## 비밀번호

| 제품정보                                   | - 연혁  | 이름 \*                                                               |
| -------------------------------------- | ----- | ------------------------------------------------------------------- |
| `unknown`                              | 이름 \* | 다른 작업을 수행하지 마십시오.                                                   |
| `allow`                                | 지원하다  | 모든 후속 규칙을 우회합니다.                                                    |
| `block`                                | 팟캐스트  | 403, 429 또는 기타 4XX 상태 코드의 HTTP 상태 코드와 블록.                           |
| `challenge`                            | 도전 드롭 | 상호 작용하는 도전.                                                         |
| `jschallenge`                          | 도전 드롭 | 비동기적인 도전을 발행합니다.                                                    |
| `log`                                  | 로그인   | 이벤트를 로깅하지 않고 다른 작업을 수행하십시오.                                         |
| `connectionClose`                      | 이름 \* | 연결 닫기                                                               |
| `challengeSolved`                      | 지원하다  | 한 번 대화 형 도전 해결.                                                     |
| `challengeBypassed`                    | 지원하다  | 대화 형 도전은 이전에 대화 형 도전을 통과했기 때문에 다시 발급되지 않습니다.`cf_clearance`쿠키가 있습니다. |
| `jschallengeSolved`                    | 지원하다  | 해결되지 않은 한 번 비동기적인 도전을 허용하십시오.                                       |
| `jschallengeBypassed`                  | 지원하다  | 방문자가 이전에 비동기 또는 대화 형 도전을 통과했기 때문에 비동기적인 도전이 발행되지 않았습니다.             |
| `bypass`                               | 지원하다  | 이후 방화벽 규칙을 우회합니다.                                                   |
| `managedChallenge`                     | 도전 드롭 | 문제 관리 도전.                                                           |
| `managedChallengeNonInteractiveSolved` | 지원하다  | 관리된 도전이 비동기적인 인터랙티브 페이지를 통해 해결됩니다.                                  |
| `managedChallengeInteractiveSolved`    | 지원하다  | 한 번 관리 된 도전은 대화 형 상호 작용 페이지를 통해 해결됩니다.                              |
| `managedChallengeBypassed`             | 지원하다  | 방문자가 이전 도전에서 정리했기 때문에 도전이 발표되지 않았습니다.                               |

## 보안 소스

| 제품정보              | 이름 \*                                            |
| ----------------- | ------------------------------------------------ |
| `unknown`         | 이벤트가 새로운 소스에서 수신되었지만 로깅 시스템은 업데이트되지 않았습니다.       |
| `asn`             | 자율주행 시스템 번호에 따라 허용 또는 블록.                        |
| `country`         | 국가를 기준으로 허용 또는 블록.                               |
| `ip`              | IP 주소에 근거를 둔 허용 또는 구획.                           |
| `ipRange`         | IP 주소 범위에 따라 허용 또는 차단.                           |
| `securityLevel`   | requester의 보안 수준에 따라 허용 또는 블록.                   |
| `zoneLockdown`    | 특정 영역에 대한 모든 접근을 제한합니다.                          |
| `waf`             | WAF 제품 설정에 따라 허용 또는 블록. 이것은 WAF / 관리 규칙 시스템입니다.  |
| `firewallRules`   | 영역의 방화벽 규칙 구성(deprecated)에 따라 허용하거나 차단할 수 있습니다.  |
| `uaBlock`         | Cloudflare 사용자 에이전트 차단 제품 설정에 따라 또는 블록 허용.       |
| `rateLimit`       | Cloudflare에 의해 설정 여부, 제한 규칙에 따라 또는 블록 허용.        |
| `bic`             | Browser Integrity Check 제품 설정에 따라 허용 또는 블록.      |
| `hot`             | Hotlink Protection 제품 설정에 따라 허용 또는 블록.           |
| `l7ddos`          | L7 DDoS 제품 설정에 따라 허용 또는 차단.                      |
| `validation`      | 잘못된 요청에 따라 허용하거나 블록 (사용자 정의 할 수 없습니다.)           |
| `botFight`        | Bot Fight Mode (classic) 제품 설정에 따라 허용 또는 블록.     |
| `botManagement`   | Bot Management 제품 설정에 따라 허용 또는 블록.               |
| `dlp`             | Data Loss Prevention 제품 설정에 따라 허용하거나 차단할 수 있습니다. |
| `firewallManaged` | WAF 관리 규칙의 설정에 따라 허용하거나 블록.                      |
| `firewallCustom`  | WAF 사용자 정의 규칙에 따라 또는 블록 허용.                      |

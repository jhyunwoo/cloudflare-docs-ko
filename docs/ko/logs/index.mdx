<Description>
  제품에 의해 생성 된 메타 데이터를 포함하는 상세한 로그.
</Description>

이 로그는 디버깅에 도움이되며 구성 조정을 식별하고 분석 생성에 특히 애플리케이션 서버와 같은 다른 소스에서 로그와 결합 할 때 특히 유용합니다. 데이터 Cloudflare 수집 유형에 대한 정보는 참조[Cloudflare의 분석 유형](/analytics/types-of-analytics/).

***

## 주요 특징

<Feature header="다운로드" href="/logs/logpush/">
  Cloudflare 대시보드 또는 API를 통해 구성 할 수있는 Logpush를 사용하여 클라우드 서비스 제공 업체에 요청 또는 이벤트 로그를 푸시하십시오.
</Feature>

<Feature header="즉시 로그인" href="/logs/instant-logs/">
  Cloudflare 대시보드 또는 CLI에서 즉시 HTTP 요청 로그를보십시오.
</Feature>

<Feature header="Logpull (특성)" href="/logs/logpull/">
  Cloudflare를 사용하여 HTTP를 통해 요청 로그 Logpull, 로그 검색을 위해 설계된 REST API.
</Feature>

Edge Log Delivery는 고객이 Cloudflare의 가장자리에서 직접 로그를 보낼 수 있습니다. 30 초와 5 분 사이에 로그 배치에 대한 최대 간격을 구성 할 수 있습니다. 그러나 로그 배치의 최소 간격을 지정할 수 없습니다. 로그 파일이 최대 지정보다 짧은 간격으로 전송될 수 있음을 의미합니다. Logpush에 비해 Edge Log Delivery는 더 낮은 대기 시간, 더 자주, 더 작은 배치로 로그를 보냅니다.

Edge Log Delivery는 HTTP 요청 로그에만 사용할 수 있습니다. 더 알아보기[API 구성](/logs/logpush/logpush-job/api-configuration/#kind)Edge Log Delivery를 사용하는 작업을 구성하는 방법에 대한 단계에 대한 페이지.

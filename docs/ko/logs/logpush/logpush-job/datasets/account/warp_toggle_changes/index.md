아래 설명은 필드를 사용할 수 있습니다.`warp_toggle_changes`.

## 계정 ID

유형:`string`

Cloudflare 계정 ID 때 toggle 일어난다.

## 계정 이름

유형:`string`

toggle가 일어났을 때 계정 이름.

## 장치ID

유형:`string`

물리적 장치 ID.

## 장치등록ID

유형:`string`

장치 등록 ID.

## 이름 \*

유형:`string`

장치 hostname.

## 직렬Number

유형:`string`

장치 일련 번호.

## 스크린 샷

유형:`int or string`

이벤트가 혼잡되었습니다.

## 댓글 RSS

유형:`bool`

장치가 toggled 또는 아닙니다인지 나타냅니다.

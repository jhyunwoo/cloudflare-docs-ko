## 데이터셋

아래 데이터 세트는 로그 범주에 의해 사용할 수있는 필드를 설명합니다.

- [Zone-scoped 데이터 세트](/logs/logpush/logpush-job/datasets/zone/)
- [account-scoped 데이터 세트](/logs/logpush/logpush-job/datasets/account/)

## 사이트맵

필드의 목록은 다음 엔드포인트를 사용하여 API에서 직접 액세스 할 수 있습니다.

- Zone-scoped datasets를 위해:`https://api.cloudflare.com/client/v4/zones/{zone_id}/logpush/datasets/<DATASET>/fields`

- account-scoped datasets를 위해:`https://api.cloudflare.com/client/v4/accounts/{account_id}/logpush/datasets/<DATASET>/fields`

더 보기`<DATASET>`인수는 로그 범주를 나타냅니다. 예를 들어,`http_requests`, `spectrum_events`, `firewall_events`, `nel_reports`, 또는`dns_logs`.

## 적용분야

- Logpush dataset 필드의 가용성은 구독 계획에 따라 다릅니다.
- Zone-scoped HTTP 요청은 Logpush 및 Logpull 모두에서 사용할 수 있습니다.
- [회사 소개](/logs/logpush/logpush-job/custom-fields/)HTTP 요청은 Logpush에서만 사용할 수 있습니다.
- 다른 모든 데이터 세트는 Logpush를 통해서만 유효합니다.

## 공지사항

기존의 일자리를 막는 데 사용할 수 있습니다. 그들은 결국 완전히 제거하면 빈 값이 될 수 있습니다. 고객은 그들이 그들을 사용 하는 경우 deprecated 필드에서 멀리 마이그레이션 하는 것이 좋습니다.

## Recommend

로그인 필드**ClientIP클래스**, Cloudflare는 사용을 추천합니다[봇 태그](/bots/concepts/bot-tags/)IP를 분류합니다.

## 관련 자료

Cloudflare Zero Trust에서 사용할 수있는 로그에 대한 자세한 내용은 참조[Zero Trust 로그](/cloudflare-one/insights/logs/).

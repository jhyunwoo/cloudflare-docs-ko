모델 번호: Cloudflare Logpush는 서비스 제공 업체의 제한된 세트로 로그를 밀어 지원합니다. 그러나 API를 통해 Logpush를 구성할 수 있습니다.

## Cloudflare 대시보드를 통해 관리

더 알아보기[자주 묻는 질문](/logs/logpush/logpush-job/enable-destinations/)Cloudflare 대시보드를 통해 Logpush로 사용할 수 있는 서비스의 목록을 위해. 다른 서비스에 관심이 있습니까? 이태리[연구분야](https://docs.google.com/forms/d/e/1FAIpQLScwOSabROywVajpMX2ZYCVl3saYs11cP4NIC8QR-wmOAnxOtA/viewform).

## API를 통해 관리

Cloudflare Logpush API는 생성, 검색, 업데이트 및 삭제 작업을 통해 작업을 구성하고 관리 할 수 있습니다 (CRUD).

Logpush로, 메타 데이터 Cloudflare의 로그를 업로드 할 수있는 작업을 만들 수 있습니다. 도메인 당 dataset 당 설정할 수 있는 기본 번호는 4이지만 플랜 및 구독에 따라 더 많은 작업을 설정할 수 있습니다.

<Render file="enable-read-permissions" product="logs" />

<br />

시작하기에:

1. 저장 공급자 및 보조금을 설정 Cloudflare 액세스. 저장 공급자는 당신의 Cloudflare API 자격 및 다른 정보를 포함하여 요구할지도 모릅니다:
   - 이메일 주소
   - Cloudflare API 열쇠
   - 지역 ID
   - 귀하의 클라우드 서비스 제공 업체에 대한 목적지 액세스 정보

2. Logpush 작업을 구성합니다. Logpush 작업을 구성하는 방법에 대한 자세한 내용은 참조[API 구성](/logs/logpush/logpush-job/api-configuration/).

## Blob Storage 컨테이너에 액세스하고 얻을

Cloudflare는 Blob 저장 용기에 액세스 할 수있는 공유 액세스 서명 (SAS) 토큰을 사용합니다. 당신은 제공해야합니다`Write`SAS 토큰 만료에 대해 걱정할 필요가 없습니다.

<Render file="enable-read-permissions" product="logs" />

<br />

Logpush를 Azure로 활성화하려면:

1. Blob Storage 컨테이너를 만듭니다. 더 알아보기[Azure의 지시](https://docs.microsoft.com/en-us/azure/storage/blobs/storage-quickstart-blobs-portal).

2. 이름 \*[공유 액세스 서명 (SAS)](https://learn.microsoft.com/en-us/azure/storage/common/storage-sas-overview)blob 저장 용기에 대한 보안 및 제한. 제품 정보[스토리지 Explorer](https://learn.microsoft.com/en-us/azure/storage/storage-explorer/vs-azure-tools-storage-manage-with-storage-explorer)컨테이너로 이동하고 서명을 만들려면 오른쪽 클릭. 적어도 5 년 동안 만료되는 서명을 설정하고 쓰기 권한을 제공합니다.

3. Logpush API 또는 UI에 의해 신속한 경우 SAS URL을 제공합니다.

:::주\[주]

Logpush는 SAS 토큰이 만료되는 경우 로그를 밀어 중지합니다. 이는 적어도 5 년의 만료 기간이 필요합니다. SAS 토큰의 갱신은 API를 통해 수행해야하며 업데이트`destination_conf`Logpush 작업의 매개 변수.

:::

## Azure 목적지 문제 해결

### loginResourceTypes 오류

Azure 대상을 구성할 때 SAS (Shared Access Signature) 토큰은 blob 컨테이너로 작성할 수 있습니다. 서비스는 Blob 전용이어야합니다 (`ss=b`), 자원 유형은 Object-only이어야한다 (`srt=o`).

SAS 토큰이 다른 설정을 사용하는 경우 다음 오류를 받게됩니다.

```
signedResourceTypes must be Object only (srt=o)
```

이 오류를 해결하기 위해 SAS 토큰을 재생[스토리지 Explorer](https://learn.microsoft.com/en-us/azure/storage/storage-explorer/vs-azure-tools-storage-manage-with-storage-explorer)올바른 권한으로:

- 서비스: Blob 전용 (`ss=b`)
- 리소스 유형: Object-only (`srt=o`)
- 권한: 쓰기 전용
- 만료: 5년 이상

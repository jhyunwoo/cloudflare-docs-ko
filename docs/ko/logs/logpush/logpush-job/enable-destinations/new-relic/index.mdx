## Cloudflare 대시보드를 통해 관리

4. 내 계정**자주 묻는 질문**, 선택**새로운 Relic**.

5. 이름 \***새로운 Relic 로그 Endpoint**:

새로운 Relic 계정에서 설정 한 것을 일치시키는 지역을 사용합니다. 더 보기**라이센스 키**필드는 New Relic 대시보드에서 찾을 수 있습니다. 그것은 뒤에 의해 retrieved 할 수 있습니다[이 단계](https://docs.newrelic.com/docs/apis/intro-apis/new-relic-api-keys/#manage-license-key).

목적지 정보를 입력할 때, 선택**계속하기**.

6. Dataset을 선택하여 저장 서비스로 밀어줍니다.

7. 다음 단계에서, 당신은 당신의 logpush 작업을 구성해야:
   - 이름 \***이름 \***.
   - 이름 \***로그인**, 당신은 이벤트를 선택하고 / 또는 로그에서 제거 할 수 있습니다. 더 알아보기[필터링](/logs/logpush/logpush-job/filters/)더 많은 정보. 모든 datasets에는 이 선택권이 있습니다.
   - 내 계정**다음 필드를 보내십시오**, 당신은 당신의 저장 목적지에 모든 로그를 밀어 또는 선택적으로 당신이 밀어하려는 로그를 선택할 수 있습니다.

8. 내 계정**고급 옵션**, 당신은 할 수 있습니다:
   - 로그인의 타임스탬프 필드의 형식을 선택하십시오 (`RFC3339`(과태)`Unix`, 또는`UnixNano`).
   - 선택하기[샘플링 비율](/logs/logpush/logpush-job/api-configuration/#sampling-rate)로그인 또는 로그의 무작위 샘플 비율을 밀어.
   - 사용 가능한 적색`CVE-2021-44228`. 이 선택권은 각 발생을 대체할 것입니다`${`이름 \*`x{`.

9. 제품정보**제출하기**일단 당신이 당신의 logpush 일을 구성하고 있습니다.

## API를 통해 관리

<Render file="enable-read-permissions" product="logs" />

### 1. 작업 만들기

일을 만들려면,`POST`다음 필드에 Logpush 작업 엔드 포인트에 요청:

- **이름 \***(optional) - 도메인 이름을 작업 이름으로 사용하십시오.

- **output 옵션**(선택 사항) - 필드, 샘플 속도 및 타임스탬프 형식을 구성하려면, 참조[로그 출력 옵션](/logs/logpush/logpush-job/log-output-options/).

  :::주\[주]

  Cloudflare 로그를 조회하려면, 새로운 Relic는 UNIX 타임스탬프로 보내도록 필드를 요구합니다.

  :::

- **대상 conf**- 엔드포인트 URL, 라이센스 키 및 문자열 형식으로 구성된 로그 대상.
  - `<NR_ENDPOINT_URL>`: 새로운 Relic HTTP 로그 입구 endpoint, 이는`https://log-api.newrelic.com/log/v1`미국 또는`https://log-api.eu.newrelic.com/log/v1`유럽 연합 (EU)의 경우, 새로운 Relic 계정에 설정 된 지역에 따라.
  - `<NR_LICENSE_KEY>`: 이 키는 New Relic 대시보드에서 찾을 수 있으며 다음과 같이 검색 할 수 있습니다.[이 단계](https://docs.newrelic.com/docs/apis/intro-apis/new-relic-api-keys/#manage-license-key).
  - `format`: 형식은`cloudflare`.

    미국:`"https://log-api.newrelic.com/log/v1?Api-Key=<NR_LICENSE_KEY>&format=cloudflare"`

    EU:`"https://log-api.eu.newrelic.com/log/v1?Api-Key=<NR_LICENSE_KEY>&format=cloudflare"`

- **최대 upload records**(선택 사항) - 일괄 처리 당 로그 라인의 최대 번호. 1,000개 이상의 라인이 있어야 합니다. 배치 당 최소 로그 라인을 지정하는 방법이 없습니다. 로그 파일이 지정된 것보다 많은 몇 줄을 포함 할 수 있음을 의미합니다.

- **최대 upload bytes**(옵션) - 로그의 배치의 최대 압축 파일 크기. 최소 5MB 이상이어야 합니다. 최소 파일 크기를 설정하는 방법이 없습니다. 이것은 로그 파일이 일괄 크기보다 훨씬 작을 수 있음을 의미합니다. 절대로, 이 매개 변수를 5,000,000로 설정하는 것이 좋습니다.

- **데이터셋**- 수신하려는 로그의 범주. 더 알아보기[데이터셋](/logs/logpush/logpush-job/datasets/)지원된 datasets의 전체 목록을 위해.

cURL을 사용한 예시 요청:

<APIRequest
  path="/zones/{zone_id}/logpush/jobs"
  method="POST"
  json={{
  	name: "<DOMAIN_NAME>",
  	output_options: {
  		field_names: [
  			"ClientIP",
  			"ClientRequestHost",
  			"ClientRequestMethod",
  			"ClientRequestURI",
  			"EdgeEndTimestamp",
  			"EdgeResponseBytes",
  			"EdgeResponseStatus",
  			"EdgeStartTimestamp",
  			"RayID",
  		],
  		timestamp_format: "unix",
  	},
  	destination_conf:
  		"https://log-api.newrelic.com/log/v1?Api-Key=<NR_LICENSE_KEY>&format=cloudflare",
  	max_upload_bytes: 5000000,
  	dataset: "http_requests",
  	enabled: true,
  }}
/>

### 2. 직업 (업데이트)

일을 할 수 있도록,`PUT`Logpush 작업 엔드 포인트에 요청. URL에서 이전 단계에서 반환된 작업 ID를 사용하고 전송합니다.`{"enabled": true}`요청 몸에서.

cURL을 사용한 예시 요청:

<APIRequest
  path="/zones/{zone_id}/logpush/jobs/{job_id}"
  method="PUT"
  json={{
  	enabled: true,
  }}
/>

응답:

```json
{
  "errors": [],
  "messages": [],
  "result": {
    "dataset": "http_requests",
    "destination_conf": "https://log-api.newrelic.com/log/v1?Api-Key=<NR_LICENSE_KEY>&format=cloudflare",
    "enabled": true,
    "error_message": null,
     "id": <JOB_ID>,
     "kind": "",
     "last_complete": "null",
     "last_error": null,
     "output_options": {
       "field_names": ["ClientIP", "ClientRequestHost", "ClientRequestMethod", "ClientRequestURI", "EdgeEndTimestamp","EdgeResponseBytes", "EdgeResponseStatus", "EdgeStartTimestamp", "RayID"],
       "timestamp_format": "unix"
     },
     "max_upload_bytes": 5000000,
     "name": "<DOMAIN_NAME>"
  },
  "success": true
}
```

Cloudflare 네트워크 로그를 사용하여 Cloudflare 메트릭을 분석하고 시각화하려면, 단계에 따라[새로운 Relic Analytics 통합 페이지](/analytics/analytics-integrations/new-relic/).

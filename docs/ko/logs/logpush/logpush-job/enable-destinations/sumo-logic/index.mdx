## Hosted Collector 구성

Cloudflare는 주인 수집가에 로그를 보낼 수 있습니다**HTTP 로그 및 미터**소스로. 수집가를 설정하면 로그인할 수 있는 HTTP Source Address(A unique URL)을 제공합니다.

<Render file="enable-read-permissions" product="logs" />

<br />

Sumo Logic에 Logpush를 활성화하려면:

1. Hosted Collector를 구성합니다. 더 알아보기[Sumo Logic의 지시](https://help.sumologic.com/docs/send-data/hosted-collectors/configure-hosted-collector/).

2. HTTP 로그 및 미터 소스 구성. 더 알아보기[Sumo Logic의 지시](https://help.sumologic.com/docs/send-data/hosted-collectors/http-source/). 마지막 단계는 HTTP 소스 주소 (URL)를 얻는 방법을 나타냅니다.

3. Logpush API 또는 UI에 의해 신속한 경우 HTTP 소스 주소 (URL)를 제공합니다.

:::주\[주]

- Logpush는 HTTP 소스 주소 (URL)를 재생하면 작업을 중지합니다. 더 알아보기[Sumo Logic의 HTTP 소스에 대한 새로운 URL 생성](https://help.sumologic.com/docs/send-data/hosted-collectors/http-source/generate-new-url/). 새 URL을 사용하려면 새로운 소유권 도전을 얻을 것이고 당신의 일에 대한 목적지를 업데이트해야합니다.

- Sumo Logic은 귀하의 로그 ingestion에 throttling 및 캡을 부과 할 수 있습니다.**공급 능력**. 참고[ingestion 관리](https://help.sumologic.com/docs/manage/ingestion-volume/log-ingestion/).

- Cloudflare 로그를 분석하고 시각화하려면 Sumo Logic의 Cloudflare 앱을 사용하세요. 자세한 단계는 Sumo Logic 문서의 [Cloudflare 앱 설치](https://help.sumologic.com/docs/integrations/saas-cloud/cloudflare/#installing-the-cloudflare-app) 및 [Cloudflare 대시보드 보기](https://help.sumologic.com/docs/integrations/saas-cloud/cloudflare/#viewing-the-cloudflare-dashboards)를 참고하세요.
  :::

## HTTP 수신기 프로토콜

Cloudflare 로그를 QRadar로 보내려면[HTTP endpoints에 Logpush 작업](/logs/logpush/logpush-job/enable-destinations/http/)API를 통해. 아래에서 Cloudflare 방화벽 이벤트 및 Cloudflare HTTP 이벤트를 QRadar로 보내려면 두 개의 컬 예제를 찾을 수 있습니다.

Cloudflare는 IP 주소, 포트의 접근성을 확인하고 HTTP 수신 로그 소스의 인증서를 검증합니다. 모든 매개 변수가 유효하다면, Logpush는 생성되고, HTTP 수신기 로그 소스에 이벤트를 보낼 시작합니다.

## 아마존 AWS S3 나머지 API

Amazon S3 REST API 프로토콜을 사용할 때 IBM QRadar는 Cloudflare를 수집합니다. 아마존 S3 버킷에서 이벤트 로그. 이 옵션을 사용하려면:

1. 이름 \*[아마존 S3 물통](https://docs.aws.amazon.com/AmazonS3/latest/userguide/creating-bucket.html)Cloudflare 로그 저장. 양동이 이름과 AWS 액세스 키 ID 및 비밀 액세스 키의 메모를 버킷에 쓸 수있는 충분한 권한으로 만드십시오.
2. [Amazon S3에 Logpush를 사용](/logs/logpush/logpush-job/enable-destinations/aws-s3/).
3. AWS 관리 콘솔에서 Amazon S3 서비스에 이동하십시오. Cloudflare를 허용하는 버킷 엔드 포인트를 생성하여 S3 버킷에 직접 로그를 보냅니다.
4. 자주 묻는 질문[통합 Cloudflare Amazon AWS S3 REST API 프로토콜을 이용하여 QRadar로 로그인](https://www.ibm.com/docs/en/dsm?topic=configuration-cloudflare-logs).
5. Cloudflare에서 일부 로그를 생성하여 구성을 테스트하고 S3 버킷에 전달되고 QRadar로 전달되는 것을 보장합니다.

모델 번호: Cloudflare Logpush는 R2에 직접 밀어 로그를 지원합니다. 자동 설정 (Cloudflare는 당신을 위해 R2 물통을 만듭니다)를 통해 이렇게 할 수 있습니다, 또는 당신은 당신의 자신의 R2 물통을 주문 설정으로 만들 수 있습니다. 자동 설정은 물통을 설정하거나 테스트 목적으로 이상적입니다. 대신 구성에 전체 제어가 필요한 경우 사용자 정의 설정을 사용합니다.

:::

## 주문 설정

모델 번호: Cloudflare Logpush는 R2 Cloudflare 대시보드 또는 API를 통해 R2에 직접 밀어 로그를 지원합니다.

시작하기 전에:

- R2 물통을 만들고 R2 API 토큰을 설치하십시오.
  1. R2 UI로 이동 >**버킷 만들기**.

  2. 제품정보**R2 API 관리 토큰 토큰**.

  3. 제품정보**API 토큰 만들기**.

  4. 이름 \***제출**, 선택**제품정보**토큰에 대한 권한.

  5. 비밀 액세스 키 및 액세스 키 ID 복사. Logpush 작업을 설정할 때 이러한 작업을해야합니다.

- 다음 권한이 있는지 확인하십시오:
  - R2 쓰기, Logshare 편집.

### API를 통해 관리

일을 만들려면,`POST`다음 필드에 Logpush 작업 엔드 포인트에 요청:

- **이름 \***(optional) - 도메인 이름을 작업 이름으로 사용하십시오.
- **대상 conf**- 버킷 경로, 계정 ID, R2 액세스 키 ID 및 R2 비밀 액세스 키로 구성된 로그 대상.

:::주\[주]

우리는 추가 추천합니다`{DATE}`매개 변수`destination_conf`로그인을 일일 폴더로 분리하십시오.
주요 특징

```bash
r2://<BUCKET_PATH>/{DATE}?account-id=<ACCOUNT_ID>&access-key-id=<R2_ACCESS_KEY_ID>&secret-access-key=<R2_SECRET_ACCESS_KEY>
```

- **데이터셋**- 수신하려는 로그의 범주. 더 알아보기[데이터셋](/logs/logpush/logpush-job/datasets/)지원된 datasets의 전체 목록을 위해.
- **output 옵션**(선택 사항) - 필드, 샘플 속도 및 타임스탬프 형식을 구성하려면, 참조[API 구성 옵션](/logs/logpush/logpush-job/api-configuration/#options).

## R2에서 로그 다운로드

로그가 R2에 저장되면 다양한 방법을 사용하여 다운로드 할 수 있습니다.

### 모델 번호: 대시보드

1. Cloudflare 대시보드에서, 갑니다**모델 번호: R2**사이트 맵

   <DashButton url="/?to=/:account/r2/overview" />

2. 당신의 물통을 선택하십시오.

3. 버킷의 페이지에서 원하는 로그 파일을 찾습니다.

4. 자주 묻는 질&#xBB38;**...**&#xD30C;일 옆에 아이콘을 다운로드합니다.

![파일 목록](~/assets/images/logs/logs-r2.png)

### AWS 클립

Cloudflare R2는 S3-compatible, 그래서 당신은 그것을 상호 작용하는 AWS CLI를 사용할 수 있습니다.

- R2 자격 증명을 가진 AWS CLI를 구성하십시오.
- 사용 방법`aws s3 cp`로그 파일을 다운로드하려면 명령:

```bash
aws s3 cp s3://<BUCKET-NAME>/<PATH-TO-LOG-FILE> <LOCAL-DESTINATION>
```

기타 제품`<bucket-name>`, `<path-to-log-file>`·`<local-destination>`당신의 특정한 세부사항으로.

파일 다운로드는 gzipped 그래서 그들은 텍스트 편집기에서 열 수 전에 decompressed해야합니다.

## API를 통해 관리

SentinelOne Logpush 작업을 설정하려면:

1. 적절한 엔드포인트 URL 및 인증 매개 변수로 작업을 만듭니다.
2. 로그를 푸는 작업을 활성화합니다.

:::참조
AWS S3, GCS, 또는 Azure를 위한 Logpush 작업을 구성하는 것은 SentinelOne에 Logpush를 구성할 때 소유권이 없습니다.

### 1. 작업 만들기

일을 만들려면,`POST`다음 필드에 Logpush 작업 엔드 포인트에 요청:

- **이름 \***(optional) - 도메인 이름을 작업 이름으로 사용하십시오.
- **대상 conf**- 엔드포인트 URL, 소스 유형, 아래에 문자열 형식의 권한 헤더로 구성된 로그 대상.
  - **SENTINELONE ENDPOINT URL에 대하여**: 포트가있는 SentinelOne Raw HTTP Event Collector URL. 예를 들면:`sentinelone://ingest.us1.sentinelone.net/services/collector/raw`. Cloudflare는 SentinelOne 엔드포인트를 기대합니다.`/services/collector/raw`Logpush 작업을 설정하고 설정하는 동안.
  - **센트린원 AUTH TOKEN**: URL 인코딩 된 SentinelOne 인증 토큰. 예를 들면:`Bearer 0e6d94e8c-5792-4ad1-be3c-29bcaee0197d`.
  - **사이트맵**: SentinelOne 소스 유형. 예를 들면:`marketplace-cloudflare-latest`.

```bash
"https://<SENTINELONE_ENDPOINT_URL>?sourcetype=<SOURCE_TYPE>&header_Authorization=<SENTINELONE_AUTH_TOKEN>"
```

- **데이터셋**- 수신하려는 로그의 범주. 더 알아보기[데이터셋](/logs/logpush/logpush-job/datasets/)지원된 datasets의 전체 목록을 위해.

- **output 옵션**(선택 사항) - 필드, 샘플 속도 및 타임스탬프 형식을 구성하려면, 참조[로그 출력 옵션](/logs/logpush/logpush-job/log-output-options/). 타임스탬프를 위해, Cloudflare는 사용을 추천합니다`timestamps=rfc3339`.

cURL을 사용한 예시 요청:

### 2. 직업 (업데이트)

일을 할 수 있도록,`PUT`Logpush 작업 엔드 포인트에 요청. URL에서 이전 단계에서 반환된 작업 ID를 사용하여 전송`{"enabled": true}`요청 몸에서.

cURL을 사용한 예시 요청:

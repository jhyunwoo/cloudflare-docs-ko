5. 다음 목적지 세부 정보 입력 또는 선택:
   - **제품정보**- GCS 버킷 이름
   - **오시는 길**- 저장 용기 안에 물통 위치
   - **로그인을 일일 폴더로 구성**(추천)
   - 제품 정보**Grant Cloudflare 파일 업로드**, 당신의 물통이 Cloudflare의 IAM를 사용자로 추가한 것을 확인합니다[Storage Object 관리자 역할](https://cloud.google.com/storage/docs/access-control/iam-roles).

목적지 정보를 입력할 때, 선택**계속하기**.

6. 소유권을 증명하려면 Cloudflare는 지정된 목적지에 파일을 보낼 것입니다. 토큰을 찾으려면**기타**단추에서**모델 번호: 개요**소유권 도전 파일의 탭, 다음 Cloudflare 대시보드에 붙여넣기하여 버킷에 대한 액세스를 확인합니다. 이름 \***소유권 토큰**선택하기**계속하기**.

7. Dataset을 선택하여 저장 서비스로 밀어줍니다.

8. 다음 단계에서, 당신은 당신의 logpush 작업을 구성해야:
   - 이름 \***이름 \***.
   - 이름 \***로그인**, 당신은 이벤트를 선택하고 / 또는 로그에서 제거 할 수 있습니다. 더 알아보기[필터링](/logs/logpush/logpush-job/filters/)더 많은 정보. 모든 datasets에는 이 선택권이 있습니다.
   - 내 계정**다음 필드를 보내십시오**, 당신은 당신의 저장 목적지에 모든 로그를 밀어 또는 선택적으로 당신이 밀어하려는 로그를 선택할 수 있습니다.

9. 내 계정**고급 옵션**, 당신은 할 수 있습니다:
   - 로그인의 타임스탬프 필드의 형식을 선택하십시오 (`RFC3339`(과태)`Unix`, 또는`UnixNano`).
   - 선택하기[샘플링 비율](/logs/logpush/logpush-job/api-configuration/#sampling-rate)로그인 또는 로그의 무작위 샘플 비율을 밀어.
   - 사용 가능한 적색`CVE-2021-44228`. 이 선택권은 각 발생을 대체할 것입니다`${`이름 \*`x{`.

10. 제품정보**제출하기**일단 당신이 당신의 logpush 일을 구성하고 있습니다.

## GCS 버킷에 액세스하고

Cloudflare는 Google Cloud Identity 및 Access Management (IAM)을 사용하여 버킷에 액세스 할 수 있습니다. Cloudflare IAM 서비스 계정은 버킷에 대한 관리자 권한이 필요합니다.

<Render file="enable-read-permissions" product="logs" />

<br />

GCS에 Logpush를 활성화하려면:

1. GCS 버킷을 만듭니다. 더 알아보기[GCS의 지침](https://cloud.google.com/storage/docs/creating-buckets#storage-create-bucket-console).

2. 내 계정**제품 정보** > **이름 \*** > **제품정보** > **제출**, 회원 추가`logpush@cloudflare-data.iam.gserviceaccount.com`이름 \*`Storage Object Admin`이름 \*

다운로드 후 Cloudflare 로그 데이터, 당신은 다른 도구를 사용하여 파삭하고 로그 분석 할 수 있습니다.

JSON 로그 데이터를 파기하는 데 사용되는 그 도구 중 하나는`jq`.

더 알아보기[다운로드 jq](https://jqlang.github.io/jq/download/)더 많은 정보를 얻기 및 설치`jq`.

:::주\[주]

`jq`JSON 데이터를 파싱하고 분석의 특정 유형을 수행합니다. 더 자세한 분석을 수행하려면 전체 권장 데이터 분석 시스템을 고려하십시오.*스낵 바*.

:::

## 관련기관

IP 주소, URI 또는 참조와 같은 로그에 나타나는 필드를 집계하려면 몇 가지를 사용할 수 있습니다.`jq`명령. 이것은 트래픽의 패턴을 식별하는 데 유용합니다; 예를 들어, 가장 인기있는 페이지를 식별하거나 공격을 차단하기 위해.

아래 예제는 필드 이름에 일치하고 각 필드 인스턴스의 카운트를 제공, 카운트에 의해 ascending 순서에 정렬.

```bash
jq -r .ClientRequestURI logs.json | sort -n | uniq -c | sort -n | tail
```

```bash output
2 /nginx-logo.png
2 /poweredby.png
2 /testagain
3 /favicon.ico
3 /testing
3 /testing123
6 /test
7 /testing1234
10 /cdn-cgi/nexp/dok3v=1613a3a185/cloudflare/rocket.js
54 /
```

```bash
jq -r .ClientRequestUserAgent logs.json | sort -n | uniq -c | sort -n | tail
```

```bash output
1 python-requests/2.9.1
2 Mozilla/5.0 (Macintosh; Intel Mac OS X 10_7_5) AppleWebKit/537.17 (KHTML, like Gecko) Chrome/24.0.1312.56 Safari/537.17
4 Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/48.0.2564.116 Safari/537.36
5 curl/7.47.2-DEV
36 Mozilla/5.0 (X11; Linux x86_64; rv:44.0) Gecko/20100101 Firefox/44.0
51 curl/7.46.0-DEV
```

```bash
jq -r .ClientRequestReferer logs.json | sort -n | uniq -c | sort -n | tail
```

```bash output
2 http://example.com/testagain
3 http://example.com/testing
5 http://example.com/
5 http://example.com/testing123
7 http://example.com/testing1234
77 null
```

## 필터 분야

또 다른 일반적인 사용 케이스는 특정 필드 값에 대한 데이터를 필터링하고 그 후에 집계를 포함한다. 자주 묻는 질문*어떤 URL은 대부분의 502 오류를 보았다?*&#xC608;를 들면:

```bash
jq 'select(.OriginResponseStatus == 502) | .ClientRequestURI' logs.json | sort -n | uniq -c | sort -n | tail
```

```bash output
1 "/favicon.ico"
1 "/testing"
3 "/testing123"
6 "/test"
6 "/testing1234"
18 "/"
```

Cloudflare WAF에 의해 차단되는 최고 IP 주소를 알아내기 위하여는, 뒤에 오는 조회를 사용하십시오:

```bash
jq -r 'select(.SecurityAction == "block") | .ClientIP' logs.json | sort -n | uniq -c | sort -n
```

```bash output
1 127.0.0.1
```

## 캐시 된 요청 표시

캐시 비율을 검색하려면 다음 쿼리를 시도하십시오.

```bash
jq -r '.CacheCacheStatus' logs.json | sort -n | uniq -c | sort -n
```

```bash output
3 hit
3 null
3 stale
4 expired
6 miss
81 unknown
```

## TLS 버전보기

TLS 버전이 방문자가 사용 중인지 알아보세요. 예를 들어, 1.2 이상인 TLS 버전을 비활성화할 수 있다면 다음 쿼리를 사용하십시오.

```bash
jq -r '.ClientSSLProtocol' logs.json | sort -n | uniq -c | sort -n
```

```bash output
42 none
58 TLSv1.2
```

아래는 토큰 및 역할에 대한 사용 가능한 권한의 설명입니다. API 토큰을 만드는 방법에 대한 정보는 참조[API 토큰 만들기](/fundamentals/api/get-started/create-token/).

## 토큰 토큰

- **로그: 읽기**- Logpull 또는 Instant Logs를 사용하여 로그에 액세스 할 수 있습니다.

- **로그: 쓰기**- Grants는 Logpull 및 Logpush에 액세스하고 즉시 로그인에 대한 액세스를 읽습니다. 모든 Logpush API 작업이 필요합니다.**로그: 쓰기**Logpush 작업이 민감한 정보를 포함했기 때문에 허가.

:::주\[주]

- **Zone-scoped 데이터 세트**요구 사항**Zone-scoped 토큰**.
- **account-scoped 데이터 세트**요구 사항**account-scoped 토큰**.

권한은 해당 API 엔드포인트에 대한 액세스를 보장하기 위해 적절한 수준 (zone 또는 계정)에서 명시적으로 구성해야합니다.

:::

## 제품정보

**슈퍼 관리자**, **관리자**그리고**로그인**Logpull, Logpush 및 Instant Logs에 대한 전체 액세스가 있습니다.

오직 역할**로그인**작업 구성이 민감한 정보를 포함 할 수 있기 때문에 권한이 읽고 구성 할 수 있습니다.

더 보기**Administrator 읽기 전용**·**로그 공유 Reader**역할은 Instant Logs 및 Logpull에 액세스 할 수 있습니다. 이 역할은 Logpush 작업의 구성을 볼 수있는 권한이 없습니다.

### Zero Trust 데이터 세트

Zero Trust 데이터셋(Access, Gateway, DEX) 사용자를 위한 Logpush 작업을 보시려면`Logs Edit`·`Zero Trust: PII Read`이름 \*

오류가 발생하면`reading job for product '<product>' is not allowed (1004)`, 이것은 API 토큰이 필요한 권한이 없다는 것을 나타냅니다. 토큰 또는 사용자 계정이 위의 두 권한이 있습니다.

자세한 내용은 참조[Zero Trust Datasets를 위한 Logpush 권한 갱신](https://developers.cloudflare.com/changelog/2025-11-05-logpush-permissions-update/).

### 할당하거나 역할 제거

계정의 구성원 목록을 확인하거나 역할과 권한을 관리하십시오.

1. 탐색하기[Cloudflare 대시보드](https://dash.cloudflare.com/login)계정 선택
2. 계정에서 홈으로 이동**계정 관리** > **이름 \***.
3. 회원의 이메일 주소를 입력하여 계정을 추가하고, 선택**뚱 베어**.
4. 대안으로, 아래로 스크롤**이름 \***&#xCE74;드는 자신의 상태와 역할로 회원 목록을 찾을 수 있습니다.

더 많은 정보를 원하시면, 참조[Cloudflare 계정 내에서 역할 관리](/fundamentals/manage-members/).

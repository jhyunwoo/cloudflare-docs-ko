## 이름 \*

Logpull API에서 지원하는 세 가지 엔드 포인트는 다음과 같습니다.

- `GET /logs/received`- 지정된 매개 변수에 따라 HTTP 요청 로그 데이터를 반환
- `GET /logs/received/fields`- 모든 사용 가능한 로그 필드의 목록을 반환
- `GET /logs/rayids/{ray_id}`- HTTP 요청 로그 데이터 일치 반환`{ray_id}`

## 필수 인증 헤더

다음 헤더는 모든 엔드포인트 통화에 필요합니다.

- `X-Auth-Email`- 도메인과 관련된 Cloudflare 계정 이메일 주소
- `X-Auth-Key`- Cloudflare API 열쇠

대신, Logs와 API 토큰은 인증에 사용할 수 있습니다.

- `Authorization: Bearer <API_TOKEN>`

## 매개 변수

API는 GET 요청 쿼리 문자열에서 endpoint 매개 변수를 기대합니다. 다음은 예 형식입니다:

`logs/received`

```bash
https://api.cloudflare.com/client/v4/zones/{zone_id}/logs/received?start=<unix|rfc3339>&end=<unix|rfc3339>[&count=<int>][&sample=<float>][&fields=<FIELDS>][&timestamps=<string>][&CVE-2021-44228=<boolean>]
```

`logs/rayids/{ray_id}`

```bash
https://api.cloudflare.com/client/v4/zones/{zone_id}/logs/rayids/{ray_id}?[&fields=<FIELDS>][&timestamps=<string>]
```

## cURL을 사용하여 API 요청

`logs/received`

```bash
curl "https://api.cloudflare.com/client/v4/zones/{zone_id}/logs/received?start=2017-07-18T22:00:00Z&end=2017-07-18T22:01:00Z&count=1&fields=ClientIP,ClientRequestHost,ClientRequestMethod,ClientRequestURI,EdgeEndTimestamp,EdgeResponseBytes,EdgeResponseStatus,EdgeStartTimestamp,RayID" \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>"
```

`logs/rayids/{ray_id}`

```bash
curl "https://api.cloudflare.com/client/v4/zones/{zone_id}/logs/rayids/{ray_id}}?timestamps=rfc3339" \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>"
```

:::주\[주]

IATA 코드는 일부로 반환**레이디**요청에 포함 할 필요가 없습니다. 예를 들어, 당신이 가지고있는 경우**레이디**등`49ddb3e70e665831-DFW`, 만 포함`49ddb3e70e665831`당신의 요구에.

:::

## 제품정보

지정되지 않음**주요연혁**매개변수, API는 로그 필드의 한정된 세트를 반환합니다. 이 기본 필드 설정은 언제든지 변경할 수 있습니다. 모든 사용 가능한 필드의 목록은:

`https://api.cloudflare.com/client/v4/zones/{zone_id}/logs/received/fields`

어떤 필드가 지정되지 않는 경우, 응답의 필드의 순서는 지정되지 않습니다.

bash subshell 사용`jq`, 당신은 수동으로 복사하고 요청으로 필드를 붙여 넣지 않고 모든 가능한 필드로 로그를 다운로드 할 수 있습니다. 예를 들면:

```bash
FIELDS=$(curl https://api.cloudflare.com/client/v4/zones/{zone_id}/logs/received/fields \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>" \
| jq '. | to_entries[] | .key' -r | paste -sd "," -)

curl "https://api.cloudflare.com/client/v4/zones/{zone_id}/logs/received?start=2017-07-18T22:00:00Z&end=2017-07-18T22:01:00Z&count=1&fields=$FIELDS" \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>"
```

더 알아보기[다운로드 jq](https://jqlang.github.io/jq/download/)더 많은 정보를 얻기 및 설치`jq`.

더 알아보기[HTTP 요청 필드](/logs/logpush/logpush-job/datasets/zone/http_requests)현재 사용 가능한 필드에 대한.

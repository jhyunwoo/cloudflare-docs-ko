## 일일 데이터 볼륨 평가

일 당 지역 데이터의 양을 추정하기 위해 (로그 라인의 수와 바이트의 양), 1 시간 동안 데이터의 1 % 또는 10 % 샘플을 요청하십시오 (당신의 볼륨이 낮은 경우 10 %를 사용하십시오). 주의사항`start=2018-12-15T00:00:00Z`·`end=2018-12-15T01:00:00Z`1시간의 기간과`sample=0.1`.

```bash
curl "https://api.cloudflare.com/client/v4/zones/{zone_id}/logs/received?start=2018-12-15T00:00:00Z&end=2018-12-15T01:00:00Z&sample=0.1" \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>" \
> sample.log
```

```bash
wc -l sample.log
```

```bash output
83 sample.log
```

```bash
ls -lh sample.log
```

```bash output
-rw-r--r-- 1 mik mik 25K Dec 17 15:49 sample.log
```

이 정보에 근거하여, 메시지/일의 대략적인 수는 19,920 (83 × 10 × 24)이고, 바이트 크기는 6MB (25K × 10 × 24)입니다. 크기 견적은 기본 응답 필드 설정에 근거합니다. 응답 필드 설정 변경 (refer to[제품정보](/logs/logpull/requesting-logs/#fields))는 응답 크기를 바꿀 것입니다.

매일 교통의 좋은 견적을 얻으려면, 그것은 당신의 시간당 샘플에서 적어도 30 로그 라인을 얻는 것이 가장 좋습니다. 응답 크기가 너무 작으면 (또는 너무 크다), 샘플 값 조정, 시간 범위가 아닌.

## 압축

응답은 기본적으로 압축됩니다 (gzip).`cURL`투명하게 응답합니다.

`--header "Accept-Encoding: gzip"`

그 경우에, 산출은 gzipped 남아 있습니다. 압축된 자료는 그것의 uncompressed 크기의 대략 5-10%입니다. 이것은 1GB 압축 응답이 50-100MB로 압축된다는 것을 의미합니다.

## 서비스 기대

### 성공적인 요청

응답 또는 timeout 제한이 초과되거나 응답을 fetching 어떤 문제든지 있는 경우에,`200`상태는 반환되며 응답은 비 JSON 텍스트 라인 “Error Streaming data”로 종료됩니다. 응답이 흐르기 때문에, 시간이 앞서 오류를 식별하는 방법이 없습니다. 응답은 "Error Streaming data" 텍스트 라인에 끝나지 않는 경우 성공합니다.

주어진 영역 및 시간 범위에 대한 성공적인 응답을 받으면 다음은 모든 후속 요청에 대한 사실입니다.

- 반환된 기록의 수와 내용은 동일합니다.
- 반환된 기록의 순서는 다를 수 있습니다 (그리고 가능성이있다).

### 응답 분야

결론에 대하여**주요연혁**모수:

- 필드는 요청 URL에 명시적으로 포함될 때, 필드는 변경되지 않습니다.
- URL에 지정하지 않으면 기본 필드가 반환됩니다.
- 기본 필드는 언제든지 변경할 수 있습니다.

### 제한 사항

다음 사용 제한이 적용됩니다:

- **비율 제한:**&#xC774; 제한 결과를 초과`429`오류 응답:
  - 지역 당 15의 요구/min.
  - 사용자 당 180 요청/분 (이메일 주소).
- **시간 범위:**&#xAC00;장 큰 차이**시작하기**·**이름 \***&#xBAA8;수는 1 시간일 수 있습니다.
- **응답 크기:**&#xCD5C;대 응답 크기는 요청에 따라 10GiB이며, 약 55개의 필드가 선택될 때 약 15M 레코드와 동일합니다. (더 적은 필드가 기록 크기가 작을 때 더 많은 레코드가 검색될 수 있습니다).
- **운동:**&#xC751;답은 10 분 후에 종결된 연결으로 실패할 것입니다.
- **스트림 타임 아웃:**&#xC694;청은 종료됩니다.`408`연결이 30s를 위한 idle인 경우에 과실 응답. 이 타임 아웃은 일반적으로 요청이 아마 너무 소진된다는 것을 의미합니다 (자신한 타임 아웃 (> 12/hr)은 1hr 동안 상태 코드 429로 차단 된 후속 쿼리에서 발생합니다).
  - 더 적은 수의 필드를 사용하여 레코드를 요청합니다.
  - 더 작은 시도**시작하기**·**이름 \***&#xBAA8;수.

기본적으로 HTTP 요청 로그가 유지되지 않습니다. Logpull API를 처음 사용할 때 보존할 필요가 있습니다. 언제든지 유지를 해제 할 수 있습니다. 보존이 중단된 후, 이전에 저장된 로그는 보존 기간이 만료될 때까지 사용할 수 있음(refer to[자료 보유 기간](/logs/logpull/understanding-the-basics/#data-retention-period)).

## 이름 \*

로그 유지 관리를위한 두 가지 엔드 포인트가 있습니다 :

- `GET /logs/control/retention/flag`- 보존의 현재 상태를 반환
- `POST /logs/control/retention/flag`- 턴 유지 또는 해제

:::주\[주]

아래 리눅스 예제에서 우리는 옵션 사용[사이트맵](/logs/logpush/parsing-json-log-data/)응답 데이터를 파싱하는 데 도움이되는 도구.

제품정보`POST`전화, 당신은 영역-scoped가 있어야`edit`Super Administrator, Administrator, Log Share와 같은 권한. 더 알아보기[API 호출](/fundamentals/api/how-to/make-api-calls/)더 많은 정보.

:::

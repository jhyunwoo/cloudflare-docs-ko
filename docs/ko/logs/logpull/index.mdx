모델 번호: Cloudflare Logpull은 HTTP를 통해 요청 로그에 대한 REST API입니다. 이 로그는 Cloudflare 네트워크를 통해 연결 클라이언트와 관련된 데이터를 포함하고, 원래 웹 서버의 응답. 이 데이터는 원래 서버에서 기존 로그를 풍부하게하는 데 유용합니다. Logpull는 기업 계획에 고객에게 제공됩니다.

:::카트로션

Logpull은 레거시 기능으로 간주됩니다.[다운로드](/logs/logpush/)또는[로그 엔진](/logs/r2-log-retrieval/)더 나은 성능과 기능을 위해 대신.

:::

### 계정 관리

Logpull은 고객 Metadata Boundary (CMB)가 미국 지역에서 설정될 때 사용할 수 없습니다. 특히 CMB가 EU 전용 설정에 제한될 때 작동하지 않습니다. 자세한 내용은 참조[Cloudflare 자료 현지화](/data-localization/)문서.

Sandbox SDK 가격은 밑으로 결정됩니다.[회사 소개](/containers/)에 내장 된 플랫폼.

## 컨테이너 가격

더 알아보기[컨테이너 가격](/containers/pricing/)완전한 세부사항을 위해:

- vCPU, 메모리 및 디스크 사용률
- 네트워크 egress 가격
- Instance 유형과 비용

## 관련 가격

Sandbox를 사용하면 청구됩니다.

- [Workers](/workers/platform/pricing/)- 샌드박스에 수신 요청 처리
- [Durable Objects](/durable-objects/platform/pricing/)- 각 sandbox 인스턴스 전원
- [Workers 로그](/workers/observability/logs/workers-logs/#pricing)- 선택적 관측성 (사용 가능한 경우)

명령을 실행하고 sandbox의 격리 된 컨테이너 환경에서 배경 프로세스를 관리합니다.

## 제품 설명

### `exec()`

명령을 실행하고 완전한 결과를 반환합니다.

```ts
const result = await sandbox.exec(command: string, options?: ExecOptions): Promise<ExecuteResponse>
```

**매개 변수**:

- `command`- 실행할 명령(변수 포함)
- `options`(선택):
  - `stream`- Enable Streaming 콜백 (과태:`false`)
  - `onOutput`- 실시간 출력을 위한 Callback:`(stream: 'stdout' | 'stderr', data: string) => void`
  - `timeout`- milliseconds의 최대 실행 시간
  - `env`- 이 명령의 환경 변수:`Record<string, string | undefined>`
  - `cwd`- 이 명령의 작업 디렉토리
  - `stdin`- 명령의 표준 입력으로 전달하는 데이터 (쉘 주입 위험없이 임의 입력 가능)

**기타 제품**: `Promise<ExecuteResponse>`이름 \*`success`, `stdout`, `stderr`, `exitCode`

<TypeScriptExample>
  ```
  const result = await sandbox.exec('npm run build');

  if (result.success) {
    console.log('Build output:', result.stdout);
  } else {
    console.error('Build failed:', result.stderr);
  }

  // With streaming
  await sandbox.exec('npm install', {
    stream: true,
    onOutput: (stream, data) => console.log(`[${stream}] ${data}`)
  });

  // With environment variables (undefined values are skipped)
  await sandbox.exec('node app.js', {
    env: {
      NODE_ENV: 'production',
      PORT: '3000',
      DEBUG_MODE: undefined // Skipped, uses container default or unset
    }
  });

  // Pass input via stdin (no shell injection risks)
  const result = await sandbox.exec('cat', {
    stdin: 'Hello, world!'
  });
  console.log(result.stdout); // "Hello, world!"

  // Process user input safely
  const userInput = 'user@example.com\nsecret123';
  await sandbox.exec('python process_login.py', {
    stdin: userInput
  });
  ```
</TypeScriptExample>

:::노트\[시간 동작]
명령을 실행하면 SDK는 콜러 측에 오류를 제기하고 연결을 닫습니다. 아래 공정**계속하기**콘테이너 안쪽에. Timed-out 프로세스를 중지하려면 세션을 삭제하십시오.[`deleteSession()`](/sandbox/api/sessions/#deletesession)또는 sandbox를 파괴[`destroy()`](/sandbox/api/lifecycle/#destroy).

운동 전진: per-command`timeout`에 의해`exec()`> 세션 레벨`commandTimeoutMs`에 의해[`createSession()`](/sandbox/api/sessions/#createsession)> 글로벌[`COMMAND_TIMEOUT_MS`](/sandbox/configuration/environment-variables/#command_timeout_ms)환경 변수. 설정이 없다면, 명령은 타임아웃 없이 실행됩니다.
주요 특징

### `execStream()`

명령을 실행하고 실시간 처리를 위한 Server-Sent Events 스트림을 반환합니다.

```ts
const stream = await sandbox.execStream(command: string, options?: ExecOptions): Promise<ReadableStream>
```

**매개 변수**:

- `command`- 실행할 명령
- `options`- 동일`exec()`(포함)`stdin`지원)

**기타 제품**: `Promise<ReadableStream>`관련 제품`ExecEvent`물체 (`start`, `stdout`, `stderr`, `complete`, `error`)

<TypeScriptExample>
  ```
  import { parseSSEStream, type ExecEvent } from '@cloudflare/sandbox';

  const stream = await sandbox.execStream('npm run build');

  for await (const event of parseSSEStream<ExecEvent>(stream)) {
    switch (event.type) {
      case 'stdout':
        console.log('Output:', event.data);
        break;
      case 'complete':
        console.log('Exit code:', event.exitCode);
        break;
      case 'error':
        console.error('Failed:', event.error);
        break;
    }
  }

  // Stream with stdin input
  const inputStream = await sandbox.execStream('python -c "import sys; print(sys.stdin.read())"', {
    stdin: 'Data from Workers!'
  });

  for await (const event of parseSSEStream<ExecEvent>(inputStream)) {
    if (event.type === 'stdout') {
      console.log('Python received:', event.data);
    }
  }
  ```
</TypeScriptExample>

### `startProcess()`

긴 실행 배경 프로세스를 시작합니다.

```ts
const process = await sandbox.startProcess(command: string, options?: ProcessOptions): Promise<Process>
```

**매개 변수**:

- `command`- 배경 프로세스로 시작하는 명령
- `options`(선택):
  - `cwd`- 작업 디렉토리
  - `env`- 환경 변수:`Record<string, string | undefined>`
  - `stdin`- 명령의 표준 입력에 전달하는 데이터
  - `timeout`- milliseconds의 최대 실행 시간
  - `processId`- 주문 공정 ID
  - `encoding`- 출력 인코딩 (과태:`'utf8'`)
  - `autoCleanup`- 샌드박스 수면에서 공정을 청소하는 것

**기타 제품**: `Promise<Process>`객체와:

- `id`- 고유 프로세스 식별자
- `pid`- 시스템 공정 ID
- `command`- 실행중인 명령
- `status`- 현재 상태 (`'running'`, `'exited'`, 등)
- `kill()`- 프로세스 중지
- `getStatus()`- 현재 상태 얻기
- `getLogs()`- 축적된 로그 받기
- `waitForPort()`- 포트를 듣는 과정
- `waitForLog()`- 공정 출력의 패턴을 기다립니다
- `waitForExit()`- 종료 및 반환 종료 코드 프로세스를 기다립니다

<TypeScriptExample>
  ```
  const server = await sandbox.startProcess('python -m http.server 8000');
  console.log('Started with PID:', server.pid);

  // With custom environment
  const app = await sandbox.startProcess('node app.js', {
    cwd: '/workspace/my-app',
    env: { NODE_ENV: 'production', PORT: '3000' }
  });

  // Start process with stdin input (useful for interactive applications)
  const interactive = await sandbox.startProcess('python interactive_app.py', {
    stdin: 'initial_config\nstart_mode\n'
  });
  ```
</TypeScriptExample>

### `listProcesses()`

모든 실행 프로세스를 나열합니다.

```ts
const processes = await sandbox.listProcesses(): Promise<ProcessInfo[]>
```

<TypeScriptExample>
  ```
  const processes = await sandbox.listProcesses();

  for (const proc of processes) {
    console.log(`${proc.id}: ${proc.command} (PID ${proc.pid})`);
  }
  ```
</TypeScriptExample>

### `killProcess()`

특정 프로세스를 정의하고 자녀 프로세스의 모든.

```ts
await sandbox.killProcess(processId: string, signal?: string): Promise<void>
```

**매개 변수**:

- `processId`- 프로세스 ID (from)`startProcess()`또는`listProcesses()`)
- `signal`- 전송 신호 (과태:`"SIGTERM"`)

전체 프로세스 그룹에 신호를 보내, 주요 프로세스와 모든 아이 프로세스를 모두 보장은 종료됩니다. 이것은 부모가 사망 한 후 계속 실행되는 과정을 막습니다.

<TypeScriptExample>
  ```
  const server = await sandbox.startProcess('python -m http.server 8000');
  await sandbox.killProcess(server.id);

  // Example with a process that spawns children
  const script = await sandbox.startProcess('bash -c "sleep 10 & sleep 10 & wait"');
  // killProcess terminates both sleep commands and the bash process
  await sandbox.killProcess(script.id);
  ```
</TypeScriptExample>

### `killAllProcesses()`

모든 실행 프로세스를 종료합니다.

```ts
await sandbox.killAllProcesses(): Promise<void>
```

<TypeScriptExample>

</TypeScriptExample>

### `streamProcessLogs()`

실시간 실행 프로세스에서 스트림 로그.

```ts
const stream = await sandbox.streamProcessLogs(processId: string): Promise<ReadableStream>
```

**매개 변수**:

- `processId`- 공정 ID

**기타 제품**: `Promise<ReadableStream>`관련 제품`LogEvent`기타 제품

<TypeScriptExample>
  ```
  import { parseSSEStream, type LogEvent } from '@cloudflare/sandbox';

  const server = await sandbox.startProcess('node server.js');
  const logStream = await sandbox.streamProcessLogs(server.id);

  for await (const log of parseSSEStream<LogEvent>(logStream)) {
    console.log(`[${log.timestamp}] ${log.data}`);

    if (log.data.includes('Server started')) break;
  }
  ```
</TypeScriptExample>

### `getProcessLogs()`

프로세스에서 축적된 로그를 가져옵니다.

```ts
const logs = await sandbox.getProcessLogs(processId: string): Promise<string>
```

**매개 변수**:

- `processId`- 공정 ID

**기타 제품**: `Promise<string>`모든 축적된 출력

<TypeScriptExample>
  ```
  const server = await sandbox.startProcess('node server.js');
  await new Promise(resolve => setTimeout(resolve, 5000));

  const logs = await sandbox.getProcessLogs(server.id);
  console.log('Server logs:', logs);
  ```
</TypeScriptExample>

## 표준 입력 (stdin)

모든 명령 실행 방법 데이터 전달 명령의 표준 입력을 통해`stdin`옵션. 쉘 주입 위험없이 사용자 입력의 안전한 처리가 가능합니다.

### 어떻게 stdin 작품

당신이 제공 할 때`stdin`옵션 :

1. 입력 데이터는 컨테이너 내부의 임시 파일에 기록됩니다.
2. 명령은 표준 입력 스트림을 통해이 데이터를받습니다.
3. 임시 파일은 실행 후 자동으로 청소됩니다.

이 접근은 명령에서 사용자 데이터를 직접 삽입 할 때 발생할 수있는 쉘 주입 공격을 방지합니다.

<TypeScriptExample>
  ```
  // Safe: User input goes through stdin, not shell parsing
  const userInput = 'user@domain.com; rm -rf /';
  const result = await sandbox.exec('python validate_email.py', {
    stdin: userInput
  });

  // Instead of unsafe: `python validate_email.py "${userInput}"`
  // which could execute the embedded `rm -rf /` command
  ```
</TypeScriptExample>

### 일반적인 본

**처리 형태 자료:**

<TypeScriptExample>
  ```
  const formData = JSON.stringify({
    username: 'john_doe',
    email: 'john@example.com'
  });

  const result = await sandbox.exec('python process_form.py', {
    stdin: formData
  });
  ```
</TypeScriptExample>

**상호 작용하는 명령 선 공구:**

<TypeScriptExample>
  ```
  // Simulate user responses to prompts
  const responses = 'yes\nmy-app\n1.0.0\n';
  const result = await sandbox.exec('npm init', {
    stdin: responses
  });
  ```
</TypeScriptExample>

**데이터 변환:**

<TypeScriptExample>
  ```
  const csvData = 'name,age,city\nJohn,30,NYC\nJane,25,LA';
  const result = await sandbox.exec('python csv_processor.py', {
    stdin: csvData
  });

  console.log('Processed data:', result.stdout);
  ```
</TypeScriptExample>

## 프로세스 readiness 방법

더 보기`Process`반환된 객체`startProcess()`진행하기 전에 프로세스를 기다릴 수있는 방법을 포함합니다.

### `process.waitForPort()`

포트를 듣는 과정을 기다립니다.

```ts
await process.waitForPort(port: number, options?: WaitForPortOptions): Promise<void>
```

**매개 변수**:

- `port`- 확인 포트 번호
- `options`(선택):
  - `mode`- 체크 형태:`'http'`(과태) 또는`'tcp'`
  - `timeout`- 최대 대기 시간 milliseconds
  - `interval`- 밀리 초 (과태:`100`)
  - `path`- HTTP 경로 확인 (과태:`'/'`, HTTP 모드만)
  - `status`- 예상된 HTTP 상태 범위 (과태:`{ min: 200, max: 399 }`, HTTP 모드만)

**HTTP 모드**(과태) HTTP GET 요청을 만들고 응답 상태를 확인합니다 :

<TypeScriptExample>
  ```
  const server = await sandbox.startProcess('node server.js');

  // Wait for server to be ready (HTTP mode)
  await server.waitForPort(3000);

  // Check specific endpoint and status
  await server.waitForPort(8080, {
    path: '/health',
    status: { min: 200, max: 299 },
    timeout: 30000
  });
  ```
</TypeScriptExample>

**TCP 모드**포트가 연결을 허용하는 경우 체크:

<TypeScriptExample>
  ```
  const db = await sandbox.startProcess('redis-server');

  // Wait for database to accept connections
  await db.waitForPort(6379, {
    mode: 'tcp',
    timeout: 10000
  });
  ```
</TypeScriptExample>

**한국어**:

- `ProcessReadyTimeoutError`- 포트가 타임아웃 내에서 준비되지 않는 경우
- `ProcessExitedBeforeReadyError`- 준비하기 전에 프로세스 종료

### `process.waitForLog()`

공정 출력에 나타나는 패턴을 기다립니다.

```ts
const result = await process.waitForLog(pattern: string | RegExp, timeout?: number): Promise<WaitForLogResult>
```

**매개 변수**:

- `pattern`- stdout/stderr에서 일치하기 위하여 String 또는 RegExp
- `timeout`- milliseconds (선택)에 있는 최대 대기 시간

**기타 제품**: `Promise<WaitForLogResult>`이름:

- `line`- 산출의 일치 선
- `matches`- 캡처 그룹의 배열 (Re RegExp 패턴 용)

<TypeScriptExample>
  ```
  const server = await sandbox.startProcess('node server.js');

  // Wait for string pattern
  const result = await server.waitForLog('Server listening');
  console.log('Ready:', result.line);

  // Wait for RegExp with capture groups
  const result = await server.waitForLog(/Server listening on port (\d+)/);
  console.log('Port:', result.matches[1]); // Extracted port number

  // With timeout
  await server.waitForLog('Ready', 30000);
  ```
</TypeScriptExample>

**한국어**:

- `ProcessReadyTimeoutError`- 패턴이 타임 아웃 내에서 찾을 수없는 경우
- `ProcessExitedBeforeReadyError`- 패턴 전의 프로세스 종료가 나타나면

### `process.waitForExit()`

종료 코드를 종료하고 반환하는 프로세스를 기다립니다.

```ts
const result = await process.waitForExit(timeout?: number): Promise<WaitForExitResult>
```

**매개 변수**:

- `timeout`- milliseconds (선택)에 있는 최대 대기 시간

**기타 제품**: `Promise<WaitForExitResult>`이름:

- `exitCode`- 공정 종료 코드

<TypeScriptExample>
  ```
  const build = await sandbox.startProcess('npm run build');

  // Wait for build to complete
  const result = await build.waitForExit();
  console.log('Build finished with exit code:', result.exitCode);

  // With timeout
  const result = await build.waitForExit(60000); // 60 second timeout
  ```
</TypeScriptExample>

**한국어**:

- `ProcessReadyTimeoutError`- 가공이 종료되지 않는 경우

Python, JavaScript, TypeScriptXQ 코드를 실행하여 데이터 시각화, 테이블 및 풍부한 출력 형식을 지원합니다. Contexts는 실행을 통해 state (variables, imports, function)를 유지합니다.

## 제품 설명

### `createCodeContext()`

실행 코드를 위한 persistent 실행 context를 만듭니다.

```ts
const context = await sandbox.createCodeContext(options?: CreateContextOptions): Promise<CodeContext>
```

**매개 변수**:

- `options`(선택):
  - `language` - `"python" | "javascript" | "typescript"`(과태:`"python"`)
  - `cwd`- 작업 디렉토리 (기본값:`"/workspace"`)
  - `envVars`- 환경변수
  - `timeout`- 밀리 초 (과태: 30000)에서 타임 아웃 요청

**기타 제품**: `Promise<CodeContext>`이름 \*`id`, `language`, `cwd`, `createdAt`, `lastUsed`

<TypeScriptExample>
  ```
  const ctx = await sandbox.createCodeContext({
    language: 'python',
    envVars: { API_KEY: env.API_KEY }
  });
  ```
</TypeScriptExample>

### `runCode()`

컨텍스트에서 코드를 실행하고 완전한 결과를 반환합니다.

```ts
const result = await sandbox.runCode(code: string, options?: RunCodeOptions): Promise<ExecutionResult>
```

**매개 변수**:

- `code`- 실행할 코드(required)
- `options`(선택):
  - `context`- Context에서 실행 (recommended - 아래 참조)
  - `language` - `"python" | "javascript" | "typescript"`(과태:`"python"`)
  - `timeout`- 밀리 초 (기본값 : 60000)의 실행 시간
  - `onStdout`, `onStderr`, `onResult`, `onError`- 스트리밍 콜백

**기타 제품**: `Promise<ExecutionResult>`이름:

- `code`- 실행된 코드
- `logs` - `stdout`·`stderr`지원하다
- `results`- 풍부한 출력의 배열 (see)[부유한 산출 체재](#rich-output-formats))
- `error`- 어떤 경우 실행 오류
- `executionCount`- 실행 카운터

**권장 사용 - 명시된 컨텍스트 생성**:

<TypeScriptExample>
  ```
  const ctx = await sandbox.createCodeContext({ language: 'python' });

  await sandbox.runCode('import math; radius = 5', { context: ctx });
  const result = await sandbox.runCode('math.pi * radius ** 2', { context: ctx });

  console.log(result.results[0].text); // "78.53981633974483"
  ```
</TypeScriptExample>

:::note\[기본설정]
없음`context`제공된다, 기본 컨텍스트는 자동으로 생성 / 지정된 사용`language`. 빠른 테스트를 위해 편리한 동안,**명시적으로 context를 생성하는 것이 좋습니다.**&#xC608;측 가능한 상태를 유지하기위한 생산 사용.

<TypeScriptExample>
  ```
  const result = await sandbox.runCode(`
  data = [1, 2, 3, 4, 5]
  print(f"Sum: {sum(data)}")
  sum(data)
  `, { language: 'python' });

  console.log(result.logs.stdout); // ["Sum: 15"]
  console.log(result.results[0].text); // "15"
  ```
</TypeScriptExample>

:::

**오류 처리**:

<TypeScriptExample>
  ```
  const result = await sandbox.runCode('x = 1 / 0', { language: 'python' });

  if (result.error) {
    console.error(result.error.name);      // "ZeroDivisionError"
    console.error(result.error.value);     // "division by zero"
    console.error(result.error.traceback); // Stack trace array
  }
  ```
</TypeScriptExample>

**JavaScript 및 TypeScript 특징**:

JavaScript 및 TypeScript 코드 실행은 최고 수준의 지원`await`그리고 동일한 컨텍스트 내에서 실행할 수 있는 persistent 변수.

<TypeScriptExample>
  ```
  const ctx = await sandbox.createCodeContext({ language: 'javascript' });

  // Execution 1: Fetch data with top-level await
  await sandbox.runCode(`
  const response = await fetch('https://api.example.com/data');
  const data = await response.json();
  `, { context: ctx });

  // Execution 2: Use the data from previous execution
  const result = await sandbox.runCode('console.log(data)', { context: ctx });
  console.log(result.logs.stdout); // Data persists across executions
  ```
</TypeScriptExample>

변수 선언`const`, `let`, 또는`var`실행에 걸쳐 지속되며 다중 단계 워크플로우를 가능하게 합니다.

<TypeScriptExample>
  ```
  const ctx = await sandbox.createCodeContext({ language: 'javascript' });

  await sandbox.runCode('const x = 10', { context: ctx });
  await sandbox.runCode('let y = 20', { context: ctx });
  const result = await sandbox.runCode('x + y', { context: ctx });

  console.log(result.results[0].text); // "30"
  ```
</TypeScriptExample>

### `listCodeContexts()`

모든 활성 코드 실행 컨텍스트 목록.

```ts
const contexts = await sandbox.listCodeContexts(): Promise<CodeContext[]>
```

<TypeScriptExample>
  ```
  const contexts = await sandbox.listCodeContexts();
  console.log(`Found ${contexts.length} contexts`);
  ```
</TypeScriptExample>

### `deleteCodeContext()`

코드 실행 컨텍스트를 삭제하고 리소스를 무료로.

```ts
await sandbox.deleteCodeContext(contextId: string): Promise<void>
```

<TypeScriptExample>
  ```
  const ctx = await sandbox.createCodeContext({ language: 'python' });
  await sandbox.runCode('print("Hello")', { context: ctx });
  await sandbox.deleteCodeContext(ctx.id);
  ```
</TypeScriptExample>

## 부유한 산출 체재

결과:`text`, `html`, `png`, `jpeg`, `svg`, `latex`, `markdown`, `json`, `chart`, `data`

**차트 (matplotlib)**:

<TypeScriptExample>
  ```
  const result = await sandbox.runCode(`
  import matplotlib.pyplot as plt
  import numpy as np

  x = np.linspace(0, 10, 100)
  plt.plot(x, np.sin(x))
  plt.show()
  `, { language: 'python' });

  if (result.results[0]?.png) {
    const imageBuffer = Buffer.from(result.results[0].png, 'base64');
    return new Response(imageBuffer, {
      headers: { 'Content-Type': 'image/png' }
    });
  }
  ```
</TypeScriptExample>

**테이블 (평)**:

<TypeScriptExample>
  ```
  const result = await sandbox.runCode(`
  import pandas as pd
  df = pd.DataFrame({'Name': ['Alice', 'Bob'], 'Age': [25, 30]})
  df
  `, { language: 'python' });

  if (result.results[0]?.html) {
    return new Response(result.results[0].html, {
      headers: { 'Content-Type': 'text/html' }
    });
  }
  ```
</TypeScriptExample>

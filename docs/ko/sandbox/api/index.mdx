Sandbox SDK는 격리된 샌드박스에서 파일, 실행 프로세스 및 exposing 서비스를 관리하는 실행 코드를 위한 종합적인 API를 제공합니다.

<CardGrid>
  <LinkTitleCard title="생활주기" href="/sandbox/api/lifecycle/" icon="rocket">
    sandbox 컨테이너를 만들고 관리합니다. sandbox 인스턴스를 가져옵니다, 구성
    옵션 및 정리 리소스.
  </LinkTitleCard>

  <LinkTitleCard title="이름 *" href="/sandbox/api/commands/" icon="seti:shell">
    명령과 스트림 출력을 실행합니다. 스크립트를 실행, 배경 프로세스를 관리,
    캡처 실행 결과.
  </LinkTitleCard>

  <LinkTitleCard title="파일 형식" href="/sandbox/api/files/" icon="document">
    모래 상자 파일 시스템에서 파일을 읽고, 쓰기 및 관리합니다. 디렉토리
    운영 및 파일 메타데이터.
  </LinkTitleCard>

  <LinkTitleCard title="파일 watching" href="/sandbox/api/file-watching/" icon="seti:eye">
    native inotify를 사용하여 실시간 파일 시스템 변경을 모니터링합니다. 회사연혁
    도구, 핫로드 시스템 및 응답 파일 처리.
  </LinkTitleCard>

  <LinkTitleCard title="코드 Interpreter" href="/sandbox/api/interpreter/" icon="laptop">
    도표, 테이블을 포함하여 부유한 산출을 가진 Python 및 JavaScript 코드를 실행하십시오,
    및 포맷 된 데이터.
  </LinkTitleCard>

  <LinkTitleCard title="항구 항구" href="/sandbox/api/ports/" icon="download">
    미리보기 URL을 통해 sandbox에서 실행되는 노출 서비스. 웹 서버 액세스
    인터넷에서 API.
  </LinkTitleCard>

  <LinkTitleCard title="제품 정보" href="/sandbox/api/storage/" icon="database">
    S3-compatible Buckets(R2, S3, GCS)를 persistent를 위한 로컬 파일시스템으로 마운트
    sandbox lifecycles의 데이터 저장.
  </LinkTitleCard>

  <LinkTitleCard title="지원하다" href="/sandbox/api/backups/" icon="clock">
    감독의 포인트 인 타임 스냅 샷을 만들고 그들과 복원
    copy-on-write 오버레이. R2에서 백업 저장.
  </LinkTitleCard>

  <LinkTitleCard title="교육과정" href="/sandbox/api/sessions/" icon="seti:plan">
    sandbox 내에서 격리된 실행 상황 생성. 각 세션은 유지
    자신의 쉘 상태, 환경 변수 및 작업 디렉토리.
  </LinkTitleCard>

  <LinkTitleCard title="이름 *" href="/sandbox/api/terminal/" icon="terminal">
    브라우저 기반 터미널 UI를 WebSocket을 통해 sandbox 쉘에 연결하여
    xterm.js SandboxAddon for automatic reconnection and resize 처리.
  </LinkTitleCard>
</CardGrid>

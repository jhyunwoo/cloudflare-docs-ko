sandbox 내에서 격리된 실행 상황 생성. 각 세션은 자체 쉘 상태, 환경 변수 및 작업 디렉토리를 유지합니다. 이름 \*[세션 관리 개념](/sandbox/concepts/sessions/)상세 정보

:::참조
모든 sandbox는 쉘 상태를 자동으로 유지하는 기본 세션이 있습니다. 다른 환경이나 병렬 워크플로우를 위해 격리된 쉘 컨텍스트가 필요할 때 추가 세션을 만듭니다. sandbox-level 작업에 대해 컨테이너를 생성하거나 전체 sandbox 파괴, 참조[라이프사이클 API](/sandbox/api/lifecycle/).
:::

## 제품 설명

### `createSession()`

새로운 고립된 실행 세션을 만듭니다.

```ts
const session = await sandbox.createSession(options?: SessionOptions): Promise<ExecutionSession>
```

**매개 변수**:

- `options`(선택):
  - `id`- 맞춤 세션 ID (제공되지 않은 경우 자동 생성)
  - `env`- 이 세션의 환경 변수:`Record<string, string | undefined>`
  - `cwd`- 작업 디렉토리 (기본값:`"/workspace"`)
  - `commandTimeoutMs`- 이 세션의 모든 명령이 타이밍되기 전에 실행할 수 있는 milliseconds의 최대 시간. 개인 명령은이를 무시할 수 있습니다.`timeout`옵션 정보`exec()`.

**기타 제품**: `Promise<ExecutionSession>`모든 sandbox 방법이 세션에 바인딩

<TypeScriptExample>
  ```ts
  //다중 절연 환경
  const prodSession = await sandbox.createSession({
    id: 'prod',
    env: { NODE_ENV: 'production', API_URL: 'https://api.example.com' },
    cwd: '/workspace/prod'
  });

  const testSession = await sandbox.createSession({
    id: 'test',
    env: {
      NODE_ENV: 'test',
      API_URL: 'http://localhost:3000',
      DEBUG_MODE: undefined //이 세션에서 설정하지 않는 Skipped
    },
    cwd: '/workspace/test'
  });

  //병렬에서 실행
  const [prodResult, testResult] = await Promise.all([
    prodSession.exec('npm run build'),
    testSession.exec('npm run build')
  ]);

  //기본 명령 timeout과 세션
  const session = await sandbox.createSession({
    commandTimeoutMs: 5000 //모든 명령을 위한 5s timeout
  });

  await session.exec('sleep 10'); //5s 후에 밖으로 시간

  //Per-command timeout overrides 세션 레벨 타임 아웃
  await session.exec('sleep 10', { timeout: 3000 }); //3s 후에 밖으로 시간
  ```
</TypeScriptExample>

### `getSession()`

ID로 기존 세션을 검색합니다.

```ts
const session = await sandbox.getSession(sessionId: string): Promise<ExecutionSession>
```

**매개 변수**:

- `sessionId`- 기존 세션 ID

**기타 제품**: `Promise<ExecutionSession>`지정된 세션에 바인딩

<TypeScriptExample>
  ```ts
  //첫 번째 요청 - 세션 생성
  const session = await sandbox.createSession({ id: 'user-123' });
  await session.exec('git clone https://github.com/user/repo.git');
  await session.exec('cd repo && npm install');

  //두 번째 요청 - 세션을 재개 (환경 및 cwd 보존)
  const session = await sandbox.getSession('user-123');
  const result = await session.exec('cd repo && npm run build');
  ```
</TypeScriptExample>

### `deleteSession()`

세션을 삭제하고 리소스를 정리합니다.

```ts
const result = await sandbox.deleteSession(sessionId: string): Promise<SessionDeleteResult>
```

**매개 변수**:

- `sessionId`- 삭제할 세션의 ID (할 수 없습니다`"default"`)

**기타 제품**: `Promise<SessionDeleteResult>`포함 :

- `success`- 삭제가 성공 여부
- `sessionId`- 삭제된 세션 ID
- `timestamp`- 삭제 타임스탬프

<TypeScriptExample>
  ```ts
  //특정 작업을 위한 임시 세션 만들기
  const tempSession = await sandbox.createSession({ id: 'temp-task' });

  try {
    await tempSession.exec('npm run heavy-task');
  } finally {
    //수행 할 때 세션을 청소
    await sandbox.deleteSession('temp-task');
  }

  ```
</TypeScriptExample>

:::카트로션
세션을 즉시 종료 모든 실행 명령. 기본 세션은 삭제할 수 없습니다.
주요 특징

### `setEnvVars()`

sandbox의 환경 변수 설정.

```ts
await sandbox.setEnvVars(envVars: Record<string, string | undefined>): Promise<void>
```

**매개 변수**:

- `envVars`- 환경 변수의 Key-value 쌍을 설정하거나 unset
  - `string`value: 환경 변수 설정
  - `undefined`또는`null`값: 환경 변수를 설정하지 않음

:::카트로션
이름 \*`setEnvVars()` **이전 다음**환경 변수를 보장하기 위해 다른 sandbox 작업은 시작에서 사용할 수 있습니다.
주요 특징

<TypeScriptExample>
  ```ts
  const sandbox = getSandbox(env.Sandbox, 'user-123');

  //환경 변수 설정 첫째
  await sandbox.setEnvVars({
    API_KEY: env.OPENAI_API_KEY,
    DATABASE_URL: env.DATABASE_URL,
    NODE_ENV: 'production',
    OLD_TOKEN: undefined //이전에 설정한 경우 OLD TOKEN 설정
  });

  //이제 명령은 이러한 변수에 접근할 수 있습니다.
  await sandbox.exec('python script.py');
  ```
</TypeScriptExample>

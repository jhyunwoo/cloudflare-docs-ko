이 가이드는 sandbox, 핸들 출력 및 오류를 효과적으로 실행하는 방법을 보여줍니다.

## 올바른 방법을 선택하십시오.

SDK는 실행 명령에 대한 여러 가지 접근 방식을 제공합니다.

- **`exec()`**- 명령을 실행하고 완전한 결과를 기다립니다. 빌드, 설치 및 스크립트와 같은 한 번의 명령에 가장 적합합니다.
- **`execStream()`**- 실시간 스트림 출력. 즉각적인 피드백이 필요한 긴 실행 명령에 가장 적합합니다.
- **`startProcess()`**- 배경 프로세스를 시작합니다. 웹 서버, 데이터베이스 및 실행을 유지하는 데 필요한 서비스.

:::참조
제품 정보**웹 서버, 데이터베이스, 또는 실행해야 하는 서비스**, 사용`startProcess()`대신. 이름 \*[배경 프로세스 가이드](/sandbox/guides/background-processes/).
:::

## 기본 명령 실행

제품 정보`exec()`간단한 명령을 위해 신속하게 완료:

<TypeScriptExample>
  ```
  import { getSandbox } from '@cloudflare/sandbox';

  const sandbox = getSandbox(env.Sandbox, 'my-sandbox');

  // Execute a single command
  const result = await sandbox.exec('python --version');

  console.log(result.stdout);   // "Python 3.11.0"
  console.log(result.exitCode); // 0
  console.log(result.success);  // true
  ```
</TypeScriptExample>

## 안전한 인수

사용자 입력 또는 동적 값을 전달할 때, 삽입 공격을 방지하기 위해 문자열 교환을 방지:

<TypeScriptExample>
  ```
  // Unsafe - vulnerable to injection
  const filename = userInput;
  await sandbox.exec(`cat ${filename}`);

  // Safe - use proper escaping or validation
  const safeFilename = filename.replace(/[^a-zA-Z0-9_.-]/g, '');
  await sandbox.exec(`cat ${safeFilename}`);

  // Better - write to file and execute
  await sandbox.writeFile('/tmp/input.txt', userInput);
  await sandbox.exec('python process.py /tmp/input.txt');
  ```
</TypeScriptExample>

## 핸들 오류

명령은 두 가지 방법으로 실패 할 수 있습니다 :

1. **비소 출구 코드**- 명령 랜하지만 실패 (result.success === false)
2. **실행 오류**- 명령은 시작할 수 없습니다 (예를 들면 예외)

<TypeScriptExample>
  ```
  try {
    const result = await sandbox.exec('python analyze.py');

    if (!result.success) {
      // Command failed (non-zero exit code)
      console.error('Analysis failed:', result.stderr);
      console.log('Exit code:', result.exitCode);

      // Handle specific exit codes
      if (result.exitCode === 1) {
        throw new Error('Invalid input data');
      } else if (result.exitCode === 2) {
        throw new Error('Missing dependencies');
      }
    }

    // Success - process output
    return JSON.parse(result.stdout);

  } catch (error) {
    // Execution error (couldn't start command)
    console.error('Execution failed:', error.message);
    throw error;
  }
  ```
</TypeScriptExample>

## 쉘 명령 실행

Sandbox는 파이프, 리디렉션, 체인링과 같은 쉘 기능을 지원합니다.

<TypeScriptExample>
  ```
  // Pipes and filters
  const result = await sandbox.exec('ls -la | grep ".py" | wc -l');
  console.log('Python files:', result.stdout.trim());

  // Output redirection
  await sandbox.exec('python generate.py > output.txt 2> errors.txt');

  // Multiple commands
  await sandbox.exec('cd /workspace && npm install && npm test');
  ```
</TypeScriptExample>

## Python 스크립트 실행

<TypeScriptExample>
  ```
  // Run inline Python
  const result = await sandbox.exec('python -c "print(sum([1, 2, 3, 4, 5]))"');
  console.log('Sum:', result.stdout.trim()); // "15"

  // Run a script file
  await sandbox.writeFile('/workspace/analyze.py', `
  import sys
  print(f"Argument: {sys.argv[1]}")
  `);

  await sandbox.exec('python /workspace/analyze.py data.csv');
  ```
</TypeScriptExample>

## 시간 아웃

긴 실행을 방지하기 위해 명령의 최대 실행 시간을 설정하여 무한하게 차단합니다.

### Per-command 타이머

패스워드`timeout`단일 명령에 대한 타임아웃을 설정하는 옵션:

<TypeScriptExample>
  ```
  const result = await sandbox.exec('npm run build', {
    timeout: 30000 // 30 seconds
  });
  ```
</TypeScriptExample>

### 세션 레벨 타임아웃

세션에서 모든 명령에 대한 기본 시간 설정`commandTimeoutMs`:

<TypeScriptExample>
  ```
  const session = await sandbox.createSession({
    commandTimeoutMs: 10000 // 10s default for all commands
  });

  await session.exec('npm install');    // Times out after 10s
  await session.exec('npm run build');  // Times out after 10s

  // Per-command timeout overrides the session default
  await session.exec('npm test', { timeout: 60000 }); // 60s for this command
  ```
</TypeScriptExample>

### 글로벌 타임아웃

설정하기`COMMAND_TIMEOUT_MS` [환경 변수](/sandbox/configuration/environment-variables/#command_timeout_ms)글로벌 디폴트 타임 아웃 정의`exec()`모든 세션에서 호출.

### 타임아웃

여러 번의 타임아웃이 구성될 때, 가장 특정한 값은 이깁니다:

1. **회사 소개** `timeout`에 의해`exec()`(최고의 우선 순위)
2. **세션 레벨** `commandTimeoutMs`에 의해`createSession()`
3. **주요사업** `COMMAND_TIMEOUT_MS`환경 변수 (낮은 우선)

설정이 없다면, 명령은 타임아웃 없이 실행됩니다.

### Timeout은 프로세스를 죽이지 않습니다.

:::카트로션
명령을 실행하면 SDK는 오류를 발생시키고 연결을 닫습니다. 아래 공정**계속하기**콘테이너 안쪽에. Timed-out 프로세스를 중지하려면 세션을 삭제하십시오.[`deleteSession()`](/sandbox/api/sessions/#deletesession)또는 sandbox를 파괴[`destroy()`](/sandbox/api/lifecycle/#destroy).
:::

## 좋은 관행

- **본문 바로가기**- 항상 확인`result.success`·`result.exitCode`
- **유효한 입력**- 주입을 방지하기 위해 사용자 입력을 Escape 또는 validate
- **고객지원**- 긴 가동을 위해, 사용`execStream()`실시간 피드백
- **배경 프로세스**- 실행을 유지해야하는 서비스 (웹 서버, 데이터베이스), 사용[배경 프로세스 가이드](/sandbox/guides/background-processes/)이름 \*
- **핸들 오류**- 오류 상세에 대한 stderr 확인

## 문제 해결

### 찾을 수 없음

명령은 컨테이너에 존재합니다.

<TypeScriptExample>
  ```
  const check = await sandbox.exec('which python3');
  if (!check.success) {
    console.error('python3 not found');
  }
  ```
</TypeScriptExample>

### 작업 디렉토리 문제

절대 경로 또는 변경 디렉토리를 사용하십시오:

<TypeScriptExample>
  ```
  // Use absolute path
  await sandbox.exec('python /workspace/my-app/script.py');

  // Or change directory
  await sandbox.exec('cd /workspace/my-app && python script.py');
  ```
</TypeScriptExample>

이 가이드는 샌드박스에서 실행되는 WebSocket 서버와 어떻게 작동하나요?

## 당신의 접근

**미리보기 URL을 통해 노출**- 외부 클라이언트를 위한 공개 URL을 연결하십시오. 대중적인 채팅방, 멀티플레이어 게임, 또는 실시간 dashboards를 위한 베스트.

**wsConnect()와 연결**- 당신의 노동자는 WebSocket 연결을 설치합니다. 사용자 정의 라우팅 논리, 인증 게이트 또는 작업자가 샌드박스 서비스에서 실시간 데이터를 필요로 할 때 가장 좋습니다.

## WebSocket echo 서버 연결

**echo 서버 만들기:**

```typescript title="echo-server.ts"
Bun.serve({
	port: 8080,
	hostname: "0.0.0.0",
	fetch(req, server) {
		if (server.upgrade(req)) {
			return;
		}
		return new Response("WebSocket echo server");
	},
	websocket: {
		message(ws, message) {
			ws.send(`Echo: ${message}`);
		},
		open(ws) {
			console.log("Client connected");
		},
		close(ws) {
			console.log("Client disconnected");
		},
	},
});

console.log("WebSocket server listening on port 8080");
```

**Dockerfile을 확장하십시오:**

```dockerfile title="Dockerfile"
FROM docker.io/cloudflare/sandbox:0.3.3

# Copy echo server into the container
COPY echo-server.ts /workspace/echo-server.ts

# Create custom startup script
COPY startup.sh /container-server/startup.sh
RUN chmod +x /container-server/startup.sh
```

**시작 스크립트 만들기:**

```bash title="startup.sh"
#!/bin/bash
#배경에서 WebSocket 서버 시작
bun /workspace/echo-server.ts &
#SDK의 제어 평면을 시작 ( SDK를 위해 작동)
exec bun dist/index.js
```

**당신의 노동자에게서 연결:**

<TypeScriptExample>
  ```ts
  import { getSandbox } from '@cloudflare/sandbox';

  export { Sandbox } from "@cloudflare/sandbox";

  export default {
    async fetch(request: Request, env: Env): Promise<Response> {
      if (request.headers.get('Upgrade')?.toLowerCase() === 'websocket') {
        const sandbox = getSandbox(env.Sandbox, 'echo-service');
        return await sandbox.wsConnect(request, 8080);
      }

      return new Response('WebSocket endpoint');

  }
  };

  ```
</TypeScriptExample>

**클라이언트는 연결합니다:**

```javascript
const ws = new WebSocket('wss://your-worker.com');
ws.onmessage = (event) => console.log(event.data);
ws.send('Hello!'); //수신: "Echo: 안녕하세요!"
```

## 미리보기 URL을 통해 WebSocket 서비스를 노출

WebSocket 서버의 공개 URL을 가져옵니다:

<TypeScriptExample>
  ```ts
  import { getSandbox, proxyToSandbox } from '@cloudflare/sandbox';

  export { Sandbox } from '@cloudflare/sandbox';

  export default {
    async fetch(request: Request, env: Env): Promise<Response> {
      //proxyToSandbox를 통해 자동 루트 모든 요청
      const proxyResponse = await proxyToSandbox(request, env);
      if (proxyResponse) return proxyResponse;

      //요청에서 hostname 추출
      const { hostname } = new URL(request.url);
      const sandbox = getSandbox(env.Sandbox, 'echo-service');

      //미리보기 URL을 얻기 위해 포트를 노출
      const { url } = await sandbox.exposePort(8080, { hostname });

      //클라이언트로 URL을 반환
      if (request.url.includes('/ws-url')) {
        return Response.json({ url: url.replace('https', 'wss') });
      }

      return new Response('Not found', { status: 404 });

  }
  };

  ```
</TypeScriptExample>

**클라이언트는 URL을 미리 연결:**

```javascript
//미리보기 URL을 가져옵니다
const response = await fetch('https://your-worker.com/ws-url');
const { url } = await response.json();

//연결하기
const ws = new WebSocket(url);
ws.onmessage = (event) => console.log(event.data);
ws.send('Hello!'); //수신: "Echo: 안녕하세요!"
```

## Worker에서 실시간 데이터를 얻을 수 있습니다.

당신의 노동자는 웹소켓 서비스에 연결하여 실시간 데이터를 얻을 수 있습니다. 수신 요청이 WebSocket이 아닌 경우에도:

<TypeScriptExample>
  ```ts
  import { getSandbox } from '@cloudflare/sandbox';

  export { Sandbox } from '@cloudflare/sandbox';

  let initialized = false;

  export default {
    async fetch(request: Request, env: Env): Promise<Response> {

       //sandbox 인스턴스를 가져옵니다
      const sandbox = getSandbox(env.Sandbox, 'data-processor');


      //WebSocket 업그레이드
      const upgrade = request.headers.get('Upgrade')?.toLowerCase();

      if (upgrade === 'websocket') {
        //첫 번째 연결에 서버를 초기화
        if (!initialized) {
          await sandbox.writeFile(
            '/workspace/server.js',
            `Bun.serve({
              port: 8080,
              fetch(req, server) {
                server.upgrade(req);
              },
              websocket: {
                message(ws, msg) {
                  ws.send(\`Echo: \${msg}\`);
                }
              }
            });`
          );
          await sandbox.startProcess(
            'bun /workspace/server.js'
          );
          initialized = true;
        }
        //WebSocket 서버 연결
        return await sandbox.wsConnect(request, 8080);
      }

      return new Response('Processed real-time data');

  }
  };

  ```
</TypeScriptExample>

이 패턴은 sandbox 서비스에서 스트리밍 데이터를 필요로하지만 클라이언트에게 HTTP 응답을 반환 할 때 유용합니다.

## 문제 해결

### 업그레이드 실패

Verify 요청은 WebSocket 헤더가 있습니다.

<TypeScriptExample>
  ```ts
  console.log(request.headers.get('Upgrade'));    //'웹소켓'
  console.log(request.headers.get('Connection')); //'업그레이드'
  ```
</TypeScriptExample>

### 지역 개발

Dockerfile에 대한 포트 노출`wrangler dev`:

```dockerfile title="Dockerfile"
FROM docker.io/cloudflare/sandbox:0.3.3

COPY echo-server.ts /workspace/echo-server.ts
COPY startup.sh /container-server/startup.sh
RUN chmod +x /container-server/startup.sh

# Required for local development
EXPOSE 8080
```

:::참조
Dockerfile의 포트 노출은 로컬 개발에만 필요합니다. 생산에서, 모든 항구는 자동적으로 접근 가능합니다.

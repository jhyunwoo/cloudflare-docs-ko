**완료 시간:**&#x31;5 분

## 당신이 구축 할 것

Cloudflare 자연 언어 프롬프트를 수용하는 노동자는 Python 코드 실행이 필요한 경우 결정하기 위해 GPT-OSS를 사용하여 격리 된 샌드 박스에 코드를 실행하고 AI 전원 설명으로 결과를 반환합니다.

## 2. 구현 검토

템플릿은 최신 모범 사례를 사용하여 완벽한 구현을 포함합니다. 중요한 성분을 검사하자:

```typescript
//프로젝트
import { getSandbox } from "@cloudflare/sandbox";
import { generateText, stepCountIs, tool } from "ai";
import { createWorkersAI } from "workers-ai-provider";
import { z } from "zod";

const MODEL = "@cf/openai/gpt-oss-120b" as const;

async function handleAIRequest(input: string, env: Env): Promise<string> {
	const workersai = createWorkersAI({ binding: env.AI });

	const result = await generateText({
		model: workersai(MODEL),
		messages: [{ role: "user", content: input }],
		tools: {
			execute_python: tool({
				description: "Execute Python code and return the output",
				inputSchema: z.object({
					code: z.string().describe("The Python code to execute"),
				}),
				execute: async ({ code }) => {
					return executePythonCode(env, code);
				},
			}),
		},
		stopWhen: stepCountIs(5),
	});

	return result.text || "No response generated";
}
```

**직접 REST API 호출에 대한 주요 개선:**

- **공식 패키지**: 용도`workers-ai-provider`수동 API 호출 대신
- **Vercel AI SDK를**: 레버리지`generateText()`·`tool()`깨끗한 기능 호출
- **API 키 없음**: 환경 변수 대신 기본 AI 바인딩을 사용합니다.
- **유형 안전**: 적절한 타이핑과 TypeScript 지원

## 어떻게 작동합니까?

1. **사용자 입력**: 자연적인 언어를 즉시 보내십시오`/run`끝점
2. **AI 결정**: GPT-OSS는 프롬프트를 받는다.`execute_python`사용 가능
3. **스마트 실행**: 모델은 Python 코드 실행이 필요한지 결정합니다.
4. **Sandbox 고립**: 고립 된 Cloudflare에서 코드 실행 Sandbox 컨테이너
5. **AI 설명**: 결과가 최종 출력에 대한 AI의 응답으로 다시 통합됩니다.

## 당신이 내장 된

정교한 코드 해석기를 배포했습니다.

- **지적인 응답**: 코드 실행 결과와 AI reasoning

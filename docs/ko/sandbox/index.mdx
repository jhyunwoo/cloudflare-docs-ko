<Description>
  보안, 고립된 코드 실행 환경 구축
</Description>

<Plan type="workers-paid" />

Sandbox SDK를 사용하면 격리된 환경에서 신뢰할 수 없는 코드를 안전하게 실행할 수 있습니다. 관련 제품[회사 소개](/containers/), Sandbox SDK는 실행 명령, 파일 관리, 실행 배경 프로세스 및 만료 서비스 - 모두에 대한 간단한 API를 제공합니다[모델 번호: Workers](/workers/)신청.

Sandboxes는 코드, 상호 작용하는 발달 환경, 자료 분석 플랫폼, CI/CD 체계 및 가장자리에 안전한 부호 실행을 필요로 하는 어떤 신청든지를 실행할 필요가 있는 AI 대리인을 건축하기에 대하 이상적입니다. 각 샌드박스는 완전한 Linux 환경에서 자체 격리된 컨테이너에서 성능 유지하면서 강력한 보안 경계를 제공합니다.

Sandbox를 사용하면 Python 스크립트를 실행하고 Node.js 응용 프로그램을 실행하고 데이터를 분석하고 코드를 컴파일하고 복잡한 계산을 수행 할 수 있습니다. 간단한 QXQX0002XQ API 및 관리 할 인프라가 없습니다.

<Tabs>
  <TabItem label="명령 실행">
    ```typescript
    import { getSandbox } from '@cloudflare/sandbox';

    export { Sandbox } from '@cloudflare/sandbox';

    export default {
    	async fetch(request: Request, env: Env): Promise<Response> {
    		const sandbox = getSandbox(env.Sandbox, 'user-123');

    		//명령을 실행하고 결과를 얻을
    		const result = await sandbox.exec('python --version');

    		return Response.json({
    			output: result.stdout,
    			exitCode: result.exitCode,
    			success: result.success
    		});
    	}
    };
    ```
  </TabItem>

  <TabItem label="코드 Interpreter">
    ```typescript
    import { getSandbox } from '@cloudflare/sandbox';

    export { Sandbox } from '@cloudflare/sandbox';

    export default {
    	async fetch(request: Request, env: Env): Promise<Response> {
    		const sandbox = getSandbox(env.Sandbox, 'user-123');

    		//Python 실행 컨텍스트 만들기
    		const ctx = await sandbox.createCodeContext({ language: 'python' });

    		//자동 결과 캡처와 Python 코드를 실행
    		const result = await sandbox.runCode(`
    import pandas as pd
    data = {'product': ['A', 'B', 'C'], 'sales': [100, 200, 150]}
    df = pd.DataFrame(data)
    df['sales'].sum()  # Last expression is automatically returned
    	`, { context: ctx });

    			return Response.json({
    				result: result.results?.[0]?.text,
    				logs: result.logs
    			});
    		}
    	};
    ```
  </TabItem>

  <TabItem label="파일 작업">
    ```typescript
    import { getSandbox } from '@cloudflare/sandbox';

    export { Sandbox } from '@cloudflare/sandbox';

    export default {
    	async fetch(request: Request, env: Env): Promise<Response> {
    		const sandbox = getSandbox(env.Sandbox, 'user-123');

    		//프로젝트 구조 만들기
    		await sandbox.mkdir('/workspace/project/src', { recursive: true });

    		//파일 형식
    		await sandbox.writeFile(
    			'/workspace/project/package.json',
    			JSON.stringify({ name: 'my-app', version: '1.0.0' })
    		);

    		//파일 읽기
    		const content = await sandbox.readFile('/workspace/project/package.json');

    		return Response.json({ content });
    	}
    };
    ```
  </TabItem>

  <TabItem label="파일 watching">
    ```typescript
    import { getSandbox } from '@cloudflare/sandbox';

    export { Sandbox } from '@cloudflare/sandbox';

    export default {
    	async fetch(request: Request, env: Env): Promise<Response> {
    		const sandbox = getSandbox(env.Sandbox, 'user-123');

    		//실시간 파일 변경
    		const watcher = await sandbox.watch('/workspace/src', {
    			include: ['*.js', '*.ts'],
    			onEvent: (event) => {
    				console.log(`${event.type}: ${event.path}`);
    				if (event.type === 'modify') {
    					//방아쇠 rebuild 또는 뜨거운 reload
    					console.log('Code changed, recompiling...');
    				}
    			},
    			onError: (error) => {
    				console.error('Watch error:', error);
    			}
    		});

    		//할 때 보
    		setTimeout(() => watcher.stop(), 60000);

    		return Response.json({ message: 'File watcher started' });
    	}
    };
    ```
  </TabItem>

  <TabItem label="터미널 액세스">
    ```typescript
    import { getSandbox } from '@cloudflare/sandbox';

    export { Sandbox } from '@cloudflare/sandbox';

    export default {
    	async fetch(request: Request, env: Env): Promise<Response> {
    		const url = new URL(request.url);

    		//터미널 WebSocket 연결
    		if (url.pathname === '/ws/terminal') {
    			const sandbox = getSandbox(env.Sandbox, 'user-123');
    			return sandbox.terminal(request, { cols: 80, rows: 24 });
    		}

    		return Response.json({ message: 'Terminal endpoint' });
    	}
    };
    ```

    WebSocket을 통해 sandbox shells에 직접 브라우저 터미널을 연결하십시오. 더 알아보기:[브라우저 터미널](/sandbox/guides/browser-terminals/).
  </TabItem>

  <TabItem label="WebSocket 연결">
    ```typescript
    import { getSandbox } from '@cloudflare/sandbox';

    export { Sandbox } from '@cloudflare/sandbox';

    export default {
    	async fetch(request: Request, env: Env): Promise<Response> {
    		//Sandbox의 WebSocket 서비스에 연결
    		if (request.headers.get('Upgrade')?.toLowerCase() === 'websocket') {
    			const sandbox = getSandbox(env.Sandbox, 'user-123');
    			return await sandbox.wsConnect(request, 8080);
    		}

    		return Response.json({ message: 'WebSocket endpoint' });
    	}
    };
    ```

    sandboxes에서 실행되는 WebSocket 서버에 연결하십시오. 더 알아보기:[WebSocket 연결](/sandbox/guides/websocket-connections/).

## 사용 사례

Sandbox를 가진 강력한 신청을 건설하십시오:

### AI 코드 실행

큰 언어 모델에 의해 생성 된 코드를 안전하고 신뢰할 수 있습니다. Native 통합[Workers AI](/workers-ai/)GPT-OSS 같은 모델은 샌드박스 실행으로 호출할 수 있습니다. AI 에이전트, 코드 조수 및 비신뢰 코드를 실행할 필요가있는 자율 시스템.

### 데이터 분석 및 노트북

pandas, NumPy 및 Matplotlib와 상호 작용하는 데이터 분석 환경을 만듭니다. 자동 풍부한 출력 포맷으로 차트, 테이블 및 시각화를 생성합니다.

### Interactive 개발 환경

클라우드 IDE, 코딩 놀이터 및 전체 Linux 환경 및 미리보기 URL과 협업 개발 도구 구축.

### CI/CD 및 빌드 시스템

테스트, 컴파일 코드를 실행하고, 병렬 실행 및 스트리밍 로그와 격리된 환경에서 빌드 파이프라인을 실행합니다.

## 콘테이너 고립

각 sandbox는 완전한 고립을 제공하는 분리되는 VM에서 실행합니다:

- **파일시스템 고립**- Sandboxes는 다른 sandboxes의 파일을 접근할 수 없습니다
- **공정 고립**- 하나의 샌드박스에서 프로세스를 볼 수 없거나 다른 사람들에게 영향을 줄 수 없습니다.
- **네트워크 고립**- 샌드박스에는 별도의 네트워크 스택이 있습니다.
- **자원 제한**- CPU, 메모리 및 디스크 quotas는 sandbox 당 시행됩니다.

underlying container 플랫폼에 대한 완벽한 보안 세부 사항, 참조[컨테이너 건축](/containers/platform-details/architecture/).

## sandbox 안에

단일 샌드박스의 모든 코드 리소스:

- **파일시스템**- 모든 프로세스는 동일한 파일을 참조하십시오.
- **회사연혁**- 모든 세션은 모든 프로세스를 볼 수 있습니다.
- **회사연혁**- 프로세스는 localhost를 통해 통신 할 수 있습니다.

완전한 고립을 위해, 사용자 당 분리되는 sandboxes를 사용하십시오:

```typescript
//좋은 - 분리되는 sandbox에 있는 각 사용자
const userSandbox = getSandbox(env.Sandbox, `user-${userId}`);

//나쁜 - 사용자 공유 한 sandbox
const shared = getSandbox(env.Sandbox, 'shared');
//사용자는 서로의 파일을 읽을 수 있습니다!
```

## 입력 유효성

### 명령 주입

항상 명령에서 사용하기 전에 사용자 입력을 검증:

```typescript
//Dangerous - 명령에서 직접 입력
const filename = userInput;
await sandbox.exec(`cat ${filename}`);
//사용자는 입력 할 수 있습니다: "file.txt; rm -rf /"

//Safe - 유효한 입력
const filename = userInput.replace(/[^a-zA-Z0-9._-]/g, '');
await sandbox.exec(`cat ${filename}`);

//Better - 파일 사용 API
await sandbox.writeFile('/tmp/input', userInput);
await sandbox.exec('cat /tmp/input');
```

## 인증현황

### Sandbox 액세스

Sandbox ID는 기본 액세스 제어를 제공하지만 암호화되지 않습니다. Application-level 인증 추가:

```typescript
export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const userId = await authenticate(request);
    if (!userId) {
      return new Response('Unauthorized', { status: 401 });
    }

    //사용자는 sandbox에서만 접근할 수 있습니다
    const sandbox = getSandbox(env.Sandbox, userId);
    return Response.json({ authorized: true });
  }
};
```

### 미리보기 URL

미리보기 URL은 무작위로 생성된 토큰을 포함합니다. URL을 가진 사람은 서비스에 접근할 수 있습니다.

접근을 취소하려면 포트를 비교하십시오.

```typescript
await sandbox.unexposePort(8080);
```

```python
from flask import Flask, request, abort
import os

app = Flask(__name__)

def check_auth():
    token = request.headers.get('Authorization')
    if token != f"Bearer {os.environ['AUTH_TOKEN']}":
        abort(401)

@app.route('/api/data')
def get_data():
    check_auth()
    return {'data': 'protected'}
```

## 비밀 관리

환경 변수를 사용, hardcoded 비밀:

```typescript
//나쁜 - 파일에 하드 코딩
await sandbox.writeFile('/workspace/config.js', `
  const API_KEY = 'sk_live_abc123';
`);

//Good - 환경 변수 사용
await sandbox.startProcess('node app.js', {
  env: {
    API_KEY: env.API_KEY,  //Worker 환경 바인딩에서
  }
});
```

임시 민감한 자료를 청소하십시오:

```typescript
try {
  await sandbox.writeFile('/tmp/sensitive.txt', secretData);
  await sandbox.exec('python process.py /tmp/sensitive.txt');
} finally {
  await sandbox.deleteFile('/tmp/sensitive.txt');
}
```

## 좋은 관행

**격리를 위한 분리되는 sandboxes를 사용하십시오**:

```typescript
const sandbox = getSandbox(env.Sandbox, `user-${userId}`);
```

**모든 입력을 검증**:

```typescript
const safe = input.replace(/[^a-zA-Z0-9._-]/g, '');
await sandbox.exec(`command ${safe}`);
```

**secrets를 위한 환경변수를 사용하십시오**:

```typescript
await sandbox.startProcess('node app.js', {
  env: { API_KEY: env.API_KEY }
});
```

**깨끗한 임시 자원**:

```typescript
try {
  const sandbox = getSandbox(env.Sandbox, sessionId);
  await sandbox.exec('npm test');
} finally {
  await sandbox.destroy();
}
```

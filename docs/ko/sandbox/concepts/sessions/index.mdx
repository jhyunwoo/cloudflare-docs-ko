세션은 sandbox 내에서 bash 쉘 실행 컨텍스트입니다. 같은 컨테이너에 터미널 탭 또는 팬과 같은 생각.

- **샌드박스**= 컴퓨터 (컨테이너)
- **회사연혁**그 컴퓨터에서 터미널 쉘 세션 =

## 기본 세션

모든 sandbox는 컨테이너가 활성화되는 동안 명령 사이의 쉘 상태를 유지하는 기본 세션이 있습니다.

```typescript
const sandbox = getSandbox(env.Sandbox, 'my-sandbox');

//이 명령은 기본 세션에서 실행됩니다.
await sandbox.exec("cd /app");
await sandbox.exec("pwd");  //산출: /app

await sandbox.exec("export MY_VAR=hello");
await sandbox.exec("echo $MY_VAR");  //산출: 안녕
```

작업 디렉토리, 환경 변수 및 수출 된 변수는 명령 사이에 수행됩니다. 이 상태는 inactivity로 인해 컨테이너가 재시작하면 재설정됩니다.

### 자동 세션 생성

컨테이너는 첫 번째 사용에 세션을 자동으로 생성합니다. reference가 아닌 세션 ID인 경우, 컨테이너는 기본 설정으로 만듭니다.

```typescript
//이 세션은 아직 존재하지 않습니다.
const result = await sandbox.exec('echo hello', { sessionId: 'new-session' });
//컨테이너는 기본적으로 'new-session'를 자동으로 생성합니다.
//- cwd: '/workspace'
//- env: {} (empty)
```

이 행동은 세션을 삭제한 후 특히 관련이 있습니다.

```typescript
//세션 생성 및 구성
const session = await sandbox.createSession({
  id: 'temp',
  env: { MY_VAR: 'value' }
});

//세션 삭제
await sandbox.deleteSession('temp');

//동일한 세션 ID를 사용하여 다시 작동 - 기본값으로 자동 생성
const result = await sandbox.exec('echo $MY_VAR', { sessionId: 'temp' });
//출력 : (empty) - MY VAR는 신선하게 만들어진 세션에서 설정되지 않습니다.
```

이 자동 계산은 "break" 명령이 아닌 실행 세션을 참조하여 할 수 없습니다. 그러나, 사용자 정의 구성 (환경 변수, 작업 디렉토리) deletion 후 손실됩니다.

## 세션 만들기

격리된 포탄 상황에 대한 추가 세션 만들기:

```typescript
const buildSession = await sandbox.createSession({
  id: "build",
  env: { NODE_ENV: "production" },
  cwd: "/build"
});

const testSession = await sandbox.createSession({
  id: "test",
  env: { NODE_ENV: "test" },
  cwd: "/test"
});

//다른 쉘 컨텍스트
await buildSession.exec("npm run build");
await testSession.exec("npm test");
```

세션에서 모든 명령에 대한 기본 명령 타임아웃을 설정할 수 있습니다.

```typescript
const session = await sandbox.createSession({
  id: "ci",
  commandTimeoutMs: 30000 //모든 명령을 위한 30s timeout
});

await session.exec("npm test"); //아직도 달리는 경우에 30s 후에 밖으로 시간
```

개별 명령은 세션 타임아웃을 중복할 수 있습니다.`timeout`옵션 정보`exec()`. 자세한 내용은, 참조[세션 API](/sandbox/api/sessions/)그리고[명령 가이드 실행](/sandbox/guides/execute-commands/#timeouts).

## 세션 당 격리 된 것

각 세션은 다음과 같습니다:

**Shell 환경**:

```typescript
await session1.exec("export MY_VAR=hello");
await session2.exec("echo $MY_VAR");  //빈 - 다른 포탄
```

**작업 디렉토리**:

```typescript
await session1.exec("cd /workspace/project1");
await session2.exec("pwd");  //다른 작업 디렉토리
```

**환경 변수**(를 통해 설정`createSession`옵션):

```typescript
const session1 = await sandbox.createSession({
  env: { API_KEY: 'key-1' }
});
const session2 = await sandbox.createSession({
  env: { API_KEY: 'key-2' }
});
```

## 공유하기

sandbox 공유의 모든 세션 :

**파일시스템**:

```typescript
await session1.writeFile('/workspace/file.txt', 'data');
await session2.readFile('/workspace/file.txt');  //그것을 읽을 수 있습니다
```

**회사연혁**:

```typescript
await session1.startProcess('node server.js');
await session2.listProcesses();  //서버 보기
```

## 세션을 사용할 때

**세션을 사용할 때**:

- 다른 작업을 위한 고립된 포탄 국가가 필요합니다
- 다른 환경을 가진 평행한 가동을 달리기
- App runtime에서 별도의 AI 에이전트 자격

**예제 - 별도의 dev 및 runtime 환경**:

```typescript
//단계 1: AI 대리인은 부호를 (API 열쇠에) 씁니다
const devSession = await sandbox.createSession({
  id: "dev",
  env: { ANTHROPIC_API_KEY: env.ANTHROPIC_API_KEY }
});
await devSession.exec('ai-tool "build a web server"');

//단계 2: 코드를 실행 (API 키 없이)
const appSession = await sandbox.createSession({
  id: "app",
  env: { PORT: "3000" }
});
await appSession.exec("node server.js");
```

**별도의 샌드박스 사용**:

- 당신은 완전한 고립을 필요로 (신뢰한 부호)
- 다른 사용자는 완전히 분리된 환경을 요구합니다
- 자주하는 질문

## 좋은 관행

### 세션 정리

**임시 세션 청소**sandbox 실행을 유지하면서 무료 리소스 :

```typescript
try {
  const session = await sandbox.createSession({ id: 'temp' });
  await session.exec('command');
} finally {
  await sandbox.deleteSession('temp');
}
```

**기본 세션은 삭제할 수 없습니다.**:

```typescript
//이 오류 발생
await sandbox.deleteSession('default');
//오류: 기본 세션을 삭제할 수 없습니다. 대신 sandbox.destroy ()를 사용하십시오.
```

### 파일시스템 고립

**세션 공유 파일시스템**- 파일 작업은 모든 세션에 영향을줍니다.

```typescript
//나쁜 - 모든 세션에 영향을줍니다.
await session.exec('rm -rf /workspace/*');

//신뢰할 수없는 코드 고립을 위해 별도의 샌드 박스를 사용하십시오.
const userSandbox = getSandbox(env.Sandbox, userId);
```

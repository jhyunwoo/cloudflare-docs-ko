## 설치하기

### 한국어

Homebrew 패키지 관리자를 통해 설치.

```sh
brew install pulumi/tap/pulumi
```

### 리눅스

설치 스크립트를 사용합니다.

```sh
curl -fsSL https://get.pulumi.com | sh
```

### 윈도우

1. 최신 설치 프로그램을 다운로드[펄프](https://github.com/pulumi/pulumi-winget/releases/latest)
2. 더블 클릭 MSI 파일과 마법사를 완료.

## 연락처

설치를 확인하려면 터미널에서 다음을 실행하십시오.

```sh
pulumi version
```

:::주\[주]

업그레이드 및 설치 대안을 위해, 참조[Pulumi 설치](https://www.pulumi.com/docs/install/).

:::

시작하기 전에, 확인[Pulumi 설치](/pulumi/installing/).

1. [사이트 추가](/pulumi/tutorial/add-site/)

   - Pulumi IaC를 가진 Cloudflare의 밑에 당신의 기존하는 위치를 가져옵니다.
   - 회사연혁`pulumi new`, `up`·`destroy`.
   - Cloudflare 리소스 정의 : 영역 및 DNS 레코드.

2. [비밀 관리](/pulumi/tutorial/manage-secrets/)

   - Pulumi ESC와 Wrangler를 안전하게 개발하십시오.
   - ESC CLI 및 Wrangler CLI에 대한 소개.
   - Cloudflare 자격, 노동자 비밀 관리, 및`.dev.vars`.

3. [작업자 배치](/pulumi/tutorial/hello-world/)

   - 펄프를 가진 Cloudflare Workers 신청을 배치하는 짧은 소개.
   - 회사연혁`pulumi new`, `up`·`destroy`.
   - Cloudflare 리소스 정의 : 노동자 스크립트, 노동자 경로 및 DNS 레코드.

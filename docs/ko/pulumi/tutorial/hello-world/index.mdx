이 튜토리얼에서는 Cloudflare Workers 및 Pulumi 인프라를 사용하여 Hello World 애플리케이션을 배포하는 단계별 지침을 따르고 리소스 관리 수명주기와 자신을 익숙하게합니다. 특히, 당신은 모든 리소스를 청소하기 전에 응용 프로그램에 액세스하기 위해 노동자, 경로 및 DNS 레코드를 만들 것입니다.

:::참조
Pulumi Cloud 및 Cloudflare 모두 무료 계층 제공 자격을 갖춘 리소스를 제공 할 것입니다.
주요 특징

## 시작하기 전에

당신은 있다:

- Cloudflare 계정 및 API 토큰은이 튜토리얼에서 리소스를 편집 할 권한을 가지고 있습니다. 필요한 경우, 가입[Cloudflare 계정](https://www.cloudflare.com/sign-up)계속하기 토큰은 다음과 같습니다:
  - `Account-Workers Scripts-Edit`(주)
  - `Zone-Workers Route-Edit`(주)
  - `Zone-DNS-Edit`(주)
- Pulumi Cloud 계정. 로그인할 수 있습니다.[항상 자유로운 개인적인 층](https://app.pulumi.com/signup).
- 더 보기[Pulumi 클립](/pulumi/installing/)당신의 기계에 설치됩니다.
- ·[Pulumi 지원되는 프로그램 언어](https://github.com/pulumi/pulumi?tab=readme-ov-file#languages)구성. (TypeScript, JavaScript, Python, Go, .NET, Java 또는 YAML 사용)
- Cloudflare 관리 도메인. 더 보기[사이트 튜토리얼 추가](/pulumi/tutorial/add-site/)Cloudflare에서 기존 도메인을 가져 오기.

## 1. 당신의 프로젝트를 초기화

Pulumi 프로젝트는 생성하려는 인프라를 설명하는 전용 폴더의 파일 모음입니다. Pulumi 프로젝트 폴더는 필수로 식별됩니다.`Pulumi.yaml`파일. Pulumi CLI를 사용하여 새로운 프로젝트를 만들고 구성합니다.

### a. 디렉토리 만들기

이 튜토리얼의 새로운 빈 디렉토리를 사용합니다.

```sh
mkdir serverless-cloudflare
cd serverless-cloudflare
```

### b. Pulumi Cloud에 로그인

[Pulumi 클라우드](https://www.pulumi.com/product/pulumi-cloud/)보안 및 확장 가능한 플랫폼을 제공하는 호스팅 서비스입니다. Pulumi 백엔드 구성을 저장할 수 있습니다.

프롬프트에서 브라우저를 통해 Pulumi Cloud 계정으로 로그인하십시오. 대안으로, 당신은 제공 할 수 있습니다[Pulumi Cloud 액세스 토큰](https://www.pulumi.com/docs/pulumi-cloud/access-management/access-tokens/).

```sh
pulumi login
```

### d. 스택 만들기

펄프[사이트맵](https://www.pulumi.com/docs/concepts/stack/)Pulumi 프로그램의 인스턴스입니다. 스택은 독립적으로 구성되며 다른 환경 (개발, 시효, 생산) 또는 기능 지점을 나타냅니다. 이 튜토리얼의 경우, 당신은 사용할 것이다`dev`스택.

즉시 당신의`dev`스택, 실행:

### e. 앱 설정 저장

이 단계에서 당신은 Pulumi에서 응용 프로그램 설정을 저장합니다.[ESC 환경](https://www.pulumi.com/docs/esc/environments/)구성과 비밀을 포함하는 YAML 파일. Pulumi 프로그램을 포함한 여러 가지 방법으로 액세스 할 수 있습니다. 모든 ESC 환경은 Pulumi Cloud 계정에 안전하게 의존하며 Pulumi CLI를 통해 완전히 관리 할 수 있습니다. 이 튜토리얼의 경우 다음 값을 저장합니다.

- 당신의 Cloudflare[계정 ID](/fundamentals/account/find-account-and-zone-ids/).
- 유효한 Cloudflare API[계정 관리](/fundamentals/api/get-started/create-token/).
- 도메인. 예를 들어,`example.com`.

```sh
#새 ESC 환경을 이름 지정하기
E=hello-world/dev-env

#새로운 ESC 환경을 초기화
pulumi config env init --env $E --yes
```

```sh output
Creating environment hello-world/dev-env for stack dev...
```

```sh
#Cloudflare 계정 ID로 abc123을 교체하십시오
pulumi env set $E --plaintext pulumiConfig.accountId abc123

#Cloudflare API 토큰으로 API TOKEN 교체
pulumi env set $E --secret pulumiConfig.cloudflare:apiToken API_TOKEN

#example.com을 도메인으로 바꾸기
pulumi env set $E --plaintext pulumiConfig.domain example.com
```

    		conf := config.New(ctx, "")

    		domain := conf.Get("domain")

    		export default {

    		  },

    			Module:    pulumi.Bool(true), // ES6 module
    		})
    		if err != nil {
    			return err
    		}

    		return nil
    	})
    }

### b. 노선 추가

지금 추가[모델 번호: Workers 노선 정보](https://www.pulumi.com/registry/packages/cloudflare/api-docs/workersroute/)당신의 Pulumi 프로그램에 그래서 Workers 스크립트는 엔드포인트가 있고 활성화 될 수 있습니다. 제대로 루트를 구성하려면 도메인의 영역 ID를 볼 수 있습니다.

다음 코드를 추가 snippet 당신의 Entrypoint 파일**후에**Worker 스크립트 리소스:

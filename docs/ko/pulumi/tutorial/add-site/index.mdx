이 튜토리얼에서는 Cloudflare를 사용하여 Cloudflare에 기존의 사이트를 가져 오는 단계별 지침을 따라 리소스 관리 수명주기에 익숙하게합니다. 특히 새로 추가 된 사이트를 해결하기 위해 Zone 및 DNS 레코드를 만들 것입니다. 이 튜토리얼은 IaC 원칙을 채택하여 단계가 나열된 단계를 완료합니다.[사이트 자습서](/fundamentals/manage-domains/add-site/).

:::참조
Pulumi Cloud 및 Cloudflare 모두 무료 계층 제공 자격을 갖춘 리소스를 제공 할 것입니다.
주요 특징

## 시작하기 전에

당신은 있다:

- Cloudflare 계정 및 API 토큰은이 튜토리얼에서 리소스를 편집 할 권한을 가지고 있습니다. 필요한 경우, 가입[Cloudflare 계정](https://www.cloudflare.com/sign-up)계속하기 토큰이 있어야 합니다:
  - `Zone-Zone-Edit`(주)
  - `Zone-DNS-Edit`(주)
  - `include-All zones from an account-<your account>`지역 자원
- Pulumi Cloud 계정. 로그인할 수 있습니다.[항상 자유로운 개인적인 층](https://app.pulumi.com/signup).
- 더 보기[Pulumi 클립](/pulumi/installing/)당신의 기계에 설치됩니다.
- ·[Pulumi 지원되는 프로그램 언어](https://github.com/pulumi/pulumi?tab=readme-ov-file#languages)설정한다. (TypeScript, JavaScript, Python, Go, .NET, Java 또는 YAML 사용)
- 도메인 이름. 사용 가능`example.com`튜토리얼을 완료합니다.

## 1. 당신의 프로젝트를 초기화

Pulumi 프로젝트는 생성하려는 인프라를 설명하는 전용 폴더의 파일 모음입니다. Pulumi 프로젝트 폴더는 필수로 식별됩니다.`Pulumi.yaml`파일. Pulumi CLI를 사용하여 새로운 프로젝트를 만들고 구성합니다.

### a. 디렉토리 만들기

이 튜토리얼의 새로운 빈 디렉토리를 사용합니다.

```sh
mkdir addsite-cloudflare
cd addsite-cloudflare
```

### b. Pulumi Cloud에 로그인

[Pulumi 클라우드](https://www.pulumi.com/product/pulumi-cloud/)보안 및 확장 가능한 플랫폼을 제공하는 호스팅 서비스입니다. Pulumi 백엔드 구성을 저장할 수 있습니다.

프롬프트에서 브라우저를 통해 Pulumi Cloud 계정으로 로그인하십시오. 대안으로, 당신은 제공 할 수 있습니다[Pulumi Cloud 액세스 토큰](https://www.pulumi.com/docs/pulumi-cloud/access-management/access-tokens/).

```sh
pulumi login
```

### d. 스택 만들기

펄프[사이트맵](https://www.pulumi.com/docs/concepts/stack/)Pulumi 프로그램의 인스턴스입니다. 스택은 독립적으로 구성되며 다른 환경 (개발, 시효, 생산) 또는 기능 지점을 나타냅니다. 이 튜토리얼의 경우, 당신은 사용할 것이다`dev`스택.

즉시 당신의`dev`스택, 실행:

```sh
pulumi up --yes
#스택의 몇 초를 즉시 기다립니다.
```

이 시점에서 모든 리소스를 정의하지 않았으므로 빈 스택이 있습니다.

### e. 설정 저장

이 단계에서는 Pulumi에서 설정을 저장합니다.[ESC 환경](https://www.pulumi.com/docs/esc/environments/)구성과 비밀을 포함하는 YAML 파일. Pulumi 프로그램을 포함한 여러 가지 방법으로 액세스 할 수 있습니다. 모든 ESC 환경은 Pulumi Cloud 계정에 안전하게 의존하며 Pulumi CLI를 통해 완전히 관리 할 수 있습니다. 이 튜토리얼의 경우 다음 값을 저장합니다.

- 당신의 Cloudflare[계정 ID](/fundamentals/account/find-account-and-zone-ids/).
- 유효한 Cloudflare API[계정 관리](/fundamentals/api/get-started/create-token/).
- 도메인. 예를 들어,`example.com`.

```sh
#ESC 환경 이름 정의
E=cloudflare/my-dev-env

#새로운 Pulumi ESC 환경 만들기
pulumi config env init --env $E --yes
```

```sh output
Creating environment cloudflare/my-dev-env for stack dev...
```

```sh
#Cloudflare로 abc123을 대체하십시오 계정 ID
pulumi env set $E --plaintext pulumiConfig.accountId abc123

#Cloudflare API 토큰을 사용하여 API TOKEN을 대체하십시오
pulumi env set $E --secret  pulumiConfig.cloudflare:apiToken API_TOKEN

#등록 된 도메인에 example.com을 바꾸거나, 그대로 남겨두십시오.
pulumi env set $E --plaintext pulumiConfig.domain example.com
```

## 2. 코드에 Cloudflare 리소스 정의

Cloudflare 패키지를 설치하면 이제 정의 할 수 있습니다.[지원되는 Cloudflare 자원](https://www.pulumi.com/registry/packages/cloudflare/)당신의 Pulumi 프로그램에. 다음 영역과 DNS 레코드를 정의할 수 있습니다.

### a. 지역 추가

도메인 또는 사이트, Cloudflare의 영역으로 알려져 있습니다. 푸미에서,[지역 자원](https://www.pulumi.com/registry/packages/cloudflare/api-docs/zone/)Cloudflare 영역을 나타냅니다.

다음으로 엔트리포인트 파일의 내용을 대체합니다:

<Tabs>
  <TabItem label="모델 번호: JavaScript" icon="seti:javascript">
    **파일 이름:`index.js`**

    ```js
    "use strict";
    const pulumi = require("@pulumi/pulumi");
    const cloudflare = require("@pulumi/cloudflare");

    const config = new pulumi.Config();
    const accountId = config.require("accountId");
    const domain = config.require("domain");

    //Cloudflare 리소스 만들기 (Zone)
    const zone = new cloudflare.Zone("my-zone", {
    	zone: domain,
    	accountId: accountId,
    	plan: "free",
    	jumpStart: true,
    });

    exports.zoneId = zone.id;
    exports.nameservers = zone.nameServers;
    exports.status = zone.status;
    ```
  </TabItem>

  <TabItem label="모델 번호: TypeScript" icon="seti:typescript">

  <TabItem label="기타">
    **파일 이름:`main.go`**

    ```go
    package main

    import (
        "github.com/pulumi/pulumi/sdk/v3/go/pulumi"
        cloudflare "github.com/pulumi/pulumi-cloudflare/sdk/v3/go/cloudflare"
    )

    func main() {
        pulumi.Run(func(ctx *pulumi.Context) error {
            domain, _ := ctx.GetConfig("domain")

            // Create a Cloudflare resource (Zone)
            zone, err := cloudflare.NewZone(ctx, "my-zone", &cloudflare.ZoneArgs{
                Zone:      pulumi.String(domain),
                Plan:      pulumi.String("free"),
                JumpStart: pulumi.Bool(true),
            })
            if err != nil {
                return err
            }

            ctx.Export("zoneId", zone.ID())
            ctx.Export("nameservers", zone.NameServers)
            ctx.Export("status", zone.Status)
            return nil
        })
    }
    ```

이 프로세스는 Cloudflare 당신의 권위있는 DNS 공급자, 당신의 DNS 쿼리 및 웹 트래픽을 허용하고 Cloudflare 네트워크에 의해 보호.

[더 알아보기](/dns/zone-setups/reference/domain-status/)
:::

:::참조
귀하의 사이트`example.com`, 앞으로 건너뛰기[사이트 맵](#5-test-your-site).
:::

### a. 네임서버 취득

Cloudflare에 도메인을 추가하면 도메인은 두 개의 할당 된 권한 네임 서버를 받게됩니다.

할당 된 검색`nameservers`, 실행:

```sh
pulumi stack output
```

### b. 레지스트라 업데이트

도메인에 대한 Cloudflare 서비스를 활성화하려면 레지스트라에서 네임 서버를 업데이트하십시오. 지침은 레지스트라 별입니다. 아래 지도를 찾을 수 있습니다.[이 통합된 공통 등록 목록](/dns/zone-setups/full-setup/setup/#update-your-registrar).

:::카트로션
레지스트라는 네임서버 변경을 처리하기 위해 최대 24시간 걸립니다.
주요 특징

### c. 도메인 상태를 확인

성공적으로 등록되면 도메인`status`변경 사항`active`.

```sh
pulumi stack output
```

## 5. 당신의 위치를 시험하십시오

당신은 두 번 실행됩니다`nslookup`Cloudflare- 할당된 네임서버에 대한 명령.

사이트 테스트, 실행:

```sh
DOMAIN=$(pulumi config get domain)
NS1=$(pulumi stack output nameservers | jq '.[0]' -r)
NS2=$(pulumi stack output nameservers | jq '.[1]' -r)
nslookup $DOMAIN $NS1
nslookup $DOMAIN $NS2
```

.NET의 사용을 위해`Nameservers`산출으로.

응답을 확인하면 IP 주소(es) 귀하의 사이트에.

:::참조
사용할 경우 유효한 응답을받지 않습니다.`example.com`당신의 위치.

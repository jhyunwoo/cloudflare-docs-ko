<Description>
  다양한 프로그래밍 언어로 Cloudflare 리소스를 만들고, 배포하고 관리합니다.
</Description>

Cloudflare를 사용하여 인프라를 코드로 관리하고 관리[펄프](https://www.pulumi.com/). 와 함께[Pulumi Cloudflare 포장](https://www.pulumi.com/registry/packages/cloudflare/)표준 프로그래밍 언어 (TypeScript, JavaScript, Python, Python, .NET, Java, Go, YAML)를 사용하여 Cloudflare 리소스를 빌드, 배포 및 관리 할 수 있습니다. 코드에 대한 원하는 상태를 정의하고 루프, 기능, 클래스 및 패키지 관리와 같은 언어 기능을 활용할 수 있습니다.

***

## 주요 특징

<Feature header="회사연혁" href="https://www.pulumi.com/blog/pulumi-hearts-opensource/" cta="View open source commitment">
  [펄프](https://github.com/pulumi/pulumi)오픈 소스이며 Apache 2.0 라이선스를 사용합니다.
</Feature>

<Feature header="여러 언어 및 SDK" href="https://www.pulumi.com/docs/languages-sdks/">
  TypeScript, JavaScript, Python, Go, .Net, Java, 또는 YAML를 사용하여 Pulumi 프로그램을 작성합니다. 각 언어는 다른 언어와 지원할 수 있습니다[펄프](https://www.pulumi.com/registry/).
</Feature>

***

모델 번호: Cloudflare 터널은 다른 Cloudflare 제품과 통합하여 연결, 보안 및 응용 분야에 대한 가용성을 확장합니다.

## 모델 번호: Cloudflare 1 (개인 네트워킹)

공개 응용 프로그램, Cloudflare 터널은 연결 층입니다.[모델 번호: Cloudflare 한국어](/cloudflare-one/)— Cloudflare의 SASE 플랫폼. 같은 포스트 퀀텀 암호화 터널은 공공 응용 프로그램을 제공 할 수도 있습니다 전용 트래픽과 결합 할 때[WARP 클라이언트](/cloudflare-one/team-and-resources/devices/warp/):

- **회사 소개**- 내부 웹 앱, SSH 서버, RDP 호스트 및 공개적으로 도달 할 수없는 사용자를 인증하는 다른 서비스.
- **개인 네트워크**- IP 범위 (RFC 1918, 사용자 정의 CIDR) 터널을 통해 현장 VPN 교체. WARP-enrolled 장치에서 사용자는 개인 네트워크에 있는 경우에 개인 IP를 도달합니다.
- **네트워크 트래픽 필터링**- DNS, HTTP 및 네트워크 수준 정책을 적용[Cloudflare 게이트웨이](/cloudflare-one/traffic-policies/)터널을 통해 흐르는 모든 교통.

CloudflareXQ 터널을 사용하는 경우 Zero Trust 네트워크 액세스, VPN 교체 또는 개인 네트워크 연결, 참조[모델 번호: Cloudflare One Tunnel 문서](/cloudflare-one/networks/connectors/cloudflare-tunnel/)설정 및 구성에 대한.

**관련 :** [개인 네트워크](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/) | [SSH 가이드](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/) | [RDP 가이드](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/rdp/) | [VPN 설정](/learning-paths/replace-vpn/get-started/)

## 모델 번호: WorkersVPC

[모델 번호: WorkersVPC](/workers-vpc/)Cloudflare QXWorkers를 사용하여 데이터베이스, 내부 API 및 기타 서비스와 같은 개인 리소스에 액세스 할 수 있습니다. 모델 번호: Cloudflare 터널은 연결 레이어로 제공되며, 개인 네트워크에서 CloudflareXQ로 포스트 퀀텀 암호화 아웃바운드 연결을 설정합니다.

**시작하기:** [터널 만들기](/tunnel/setup/)다음을 따르십시오.[Workers VPC 가이드](/workers-vpc/get-started/)VPC 서비스 구성

**관련 :** [개인 API에 연결](/workers-vpc/examples/private-api/) | [S3 버킷에 연결](/workers-vpc/examples/private-s3-bucket/)

## 적재 Balancing

[Cloudflare 부하 균형](/load-balancing/)건강 검사, 스티어링 알고리즘 및 실패 논리를 사용하여 여러 가지 원산지의 트래픽을 배포합니다. 터널과 결합된, 당신은 공중으로 routable IP 주소 없이 근원에 균형 소통량을 적재할 수 있습니다.

각 터널은 하위 도메인을 할당합니다 (`<UUID>.cfargotunnel.com`). Load Balancer Pool의 엔드포인트로 호스트 헤더로 Application hostname로 추가합니다.

**시작하기:**&#xB354; 알아보기[Load Balancing 설정](/tunnel/routing/#load-balancing)단계별 지침.

**관련 :** [터널 복제](/tunnel/configuration/#replicas-and-high-availability) | [짐 균형을 잡는 참고 자료 건축](/reference-architecture/architectures/load-balancing/)

## 모델 번호: Cloudflare 오시는 길

[모델 번호: Cloudflare 오시는 길](/cloudflare-one/access-controls/)애플리케이션에 모든 요청을 인증하는 identity-aware proxy를 제공합니다. Tunnel과 결합된 Access는 내부 웹 애플리케이션을 인터넷에 게시할 수 있으며 공인된 사용자만 도달할 수 있습니다. 구성할 수 있습니다.[오시는 길](/cloudflare-one/access-controls/policies/)사용자 정체성, 소스 IP 범위, 기계에 기계 인증 서비스 토큰을 기반으로합니다.

**시작하기:** [자체 호스팅 응용 프로그램 게시](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/).

**관련 :** [Identity 공급자](/cloudflare-one/integrations/identity-providers/) | [유효한 접근 JWTs](/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/validating-json/)

## 스펙트럼

[Cloudflare 스펙트럼](/spectrum/)DDoS 차단 및 트래픽 가속을 비-HTTP 프로토콜로 확장합니다. DNS CNAME 레코드 또는 Load Balancer를 사용하여 터널을 통해 연결된 Origin에 Spectrum 애플리케이션 트래픽을 경로를 지정할 수 있습니다.

Tunnel과의 Spectrum 통합은 HTTP 및 HTTPS 애플리케이션에서만 지원됩니다. 제한의 전체 목록의 경우, 참조[Spectrum의 문서](/spectrum/reference/limitations/).

Cloudflare 터널 및 5 분 미만의 첫 번째 응용 프로그램을 게시합니다.

## 자주 묻는 질문

- ·[Cloudflare 계정](https://dash.cloudflare.com/sign-up)
- ·[Cloudflare에 도메인](/fundamentals/manage-domains/add-site/)(출판 신청 필요)
- 서버 또는 VM 인터넷 액세스를 설치하면 설치됩니다.`cloudflared`

:::가격
서버가 제한 방화벽 뒤에 있다면, 포트에 CloudflareXQ에 도달 할 수 있습니다.`7844`계속하기. 더 알아보기[연결 오류](/tunnel/troubleshooting/#connection-errors).
:::

## 터널 만들기

새로운 CloudflareXQ 갱도를 창조하기 위하여:

    7. 터널이 연결되면, 선택**계속하기**.

## 신청하기

인터넷에서 액세스 할 수있는 응용 프로그램을 만들기 위해, 당신의 터널에 게시 된 응용 프로그램을 추가합니다. 터널 경로는 공공 hostname을 로컬 서비스로 맵니다.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    1. 내 계정[Cloudflare 대시보드](https://dash.cloudflare.com/), 이동**사업영역** > **연락처**터널을 선택하십시오.<DashButton url="/?to=/:account/tunnels" />

    2. 이름 \***오시는 길**, 선택**경로 추가**.

    3. 제품정보**자주 묻는 질문**.

    4. 이름 \***이름 \***, 하위 도메인을 입력하고 드롭다운 메뉴에서 도메인을 선택합니다.

    5. 제품 정보**서비스 URL**, 당신의 신청의 국부적으로 주소 및 항구를 입력하십시오.

       예를 들어, 웹 서버가 같은 기계에서 실행하면`cloudflared`:

       - 포트에 HTTP`80`: `http://localhost:80`
       - 포트에 HTTPS`443`: `https://localhost:443`

       웹 서버가 다른 기계에서 실행되는 경우:`http://192.0.2.1:80`

    6. 제품정보**경로 추가**.
  </TabItem>

  <TabItem label="사이트맵">
    1. 터널의 진입 규칙을 구성:

       <APIRequest
         path="/accounts/{account_id}/cfd_tunnel/{tunnel_id}/configurations"
         method="PUT"
         json={{
          config: {
          	ingress: [
          		{
          			hostname: "app.example.com",
          			service: "http://localhost:80",
          			originRequest: {},
          		},
          		{
          			service: "http_status:404",
          		},
          	],
          },
       }}
       />

       당신의 진입 규칙은 끝에서 catch-all 규칙을 포함해야합니다. 이 예제에서,`cloudflared`요청이 호스트 이름과 일치하지 않을 때 404 상태 코드에 응답합니다.

    2. 응용 프로그램에 대한 DNS 레코드 생성 :

       <APIRequest
         path="/zones/{zone_id}/dns_records"
         method="POST"
         json={{
          type: "CNAME",
          proxied: true,
          name: "app.example.com",
          content: "<TUNNEL_ID>.cfargotunnel.com",
       }}
       />

    3. 설치하기`cloudflared`서버에서 터널을 실행`token`제품정보[터널 만들기](/tunnel/setup/#create-a-tunnel):

       <Render file="tunnel/install-and-run-tunnel" product="cloudflare-one" />
  </TabItem>
</Tabs>

응용 프로그램은 현재 구성 된 호스트 이름에 살고 있습니다. Cloudflare는 자동적으로 CDN 캐싱, WAF 및 DDoS 보호를 적용하는 그것의 네트워크를 통해 교통을 프록시.

비-HTTP 서비스 (SSH, TCP, RDP) 필요`cloudflared`클라이언트 측에. 더 알아보기[의정서 참고 자료](/tunnel/routing/#supported-protocols)상세 정보

## 빠른 터널 (개발)

로컬 개발을 위해 Cloudflare 계정없이 로컬 호스트를 즉시 노출 할 수 있습니다.

```sh
cloudflared tunnel --url http://localhost:8080
```

이 랜덤 생성`trycloudflare.com`프록시 트래픽을 로컬 서버로 설정합니다. 빠른 터널은 테스트에만 사용됩니다. 200 동시 요청 제한이 있으며 Server-Sent Events (SSE)를 지원하지 않습니다.

생산 사용을 위해,[터널 만들기](#create-a-tunnel)대신.

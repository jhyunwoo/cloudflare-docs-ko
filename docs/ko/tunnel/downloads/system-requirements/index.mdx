`cloudflared`라즈베리 파이 또는 데이터 센터 서버에서 실행하는 경량입니다. Tunnel throughput은 시스템 소프트웨어로 구성된 포트 수에 의해 주로 제한되며 하드웨어가 아닙니다.

## Baseline 권장 사항

시작하기`cloudflared` [회사 소개](/tunnel/configuration/#replicas-and-high-availability)최소 4 GB RAM 및 4 CPU 코어가있는 위치 당 두 개의 전용 호스트. 주인 당 50,000의 항구를 할당하십시오.

## 용량 계산기

배치에 대한 터널 용량 요구 사항을 추정하려면:

1. 사용 방법[메트릭 엔드포인트](/tunnel/monitoring/#cloudflared-metrics)측정하기`cloudflared_tcp_total_sessions`·`cloudflared_udp_total_sessions`.
2. 평균 Compute**초당 TCP 요청**으로 dividing`cloudflared_tcp_total_sessions`로 총 시간.
3. 평균 Compute**초당 비 DNS UDP 요청**으로 dividing`cloudflared_udp_total_sessions`로 총 시간.
4. 이름 \***초당 TCP 요청**·**초당 비 DNS UDP 요청**아래 계산기로. (당신은 떠날 수 있습니다**초당 개인 DNS 요청**이름 \*`0`터널을 사용하지 않는 경우[개인 네트워크 접근](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-availability/system-requirements/).)

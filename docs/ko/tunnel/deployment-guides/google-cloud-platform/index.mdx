이 가이드는 CloudflareXQ에 Google Cloud Platform (GCP) 가상 머신을 연결하는 방법을 다룹니다.`cloudflared`Cloudflare 터널을 통해 웹 응용 프로그램을 게시합니다.

### 자주 묻는 질문

- [Google Cloud 프로젝트](https://cloud.google.com/resource-manager/docs/creating-managing-projects#creating_a_project)
- [CloudflareXQ에 지역](/fundamentals/manage-domains/add-site/)

## 2. 터널 만들기

1. 내 계정[Cloudflare 대시보드](https://dash.cloudflare.com/), 이동**사업영역** > **연락처**.
2. 제품정보**터널 만들기**이름을 입력합니다 (예를 들어,`gcp-tunnel`).
3. 제품정보**터널 만들기**.
4. 이름 \***설치 환경**, 선택**데비안 64 비트**.
5. SSH를 VM에 연결하고 대시보드XQ에 표시된 설치 명령을 실행합니다.
6. 터널이 연결되면, 선택**계속하기**.

## 3. 신청 게시

1. 이름 \***오시는 길**, 선택**경로 추가** > **자주 묻는 질문**.
2. hostname(예를 들어,`hellocloudflare.<your-domain>.com`).
3. 이름 \***제품정보**, 입력`http://localhost:80`.
4. 제품정보**경로 추가**.

테스트하려면 브라우저를 열고 설정된 호스트 이름으로 이동합니다.

선택적으로 추가할 수 있습니다.[모델 번호: Cloudflare 오시는 길](/tunnel/integrations/#cloudflare-access)서비스에 도달 할 수있는 제어.

:::note\[개인 네트워크 접속을 찾고?]
WARP 클라이언트를 사용하여 개인 IP를 통해 VM에 연결하려면, 참조[모델 번호: Cloudflare One Tunnel 문서](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/).
:::

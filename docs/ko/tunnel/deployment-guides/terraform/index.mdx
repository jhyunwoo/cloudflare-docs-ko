- 웹 서버를 실행하는 GCP 가상 머신

- (선택) Cloudflare 연결 할 수있는 정의 접근 정책

더 알아보기[Terraform 설치 가이드](https://developer.hashicorp.com/terraform/tutorials/aws-get-started/install-cli)당신의 운영 체계를 위해.

## 2. gcloud CLI 설치

1. [gcloud CLI 설치](https://cloud.google.com/sdk/docs/install)Terraform은 GCP 계정과 상호 작용할 수 있습니다.

2. CLI를 실행하여 인증:

   ```sh
   gcloud auth application-default login
   ```

| 제품정보  | 제품 정보         | 제출   |

| 계좌정보  | Cloudflare 갱도 | 제품정보 |
| 계좌정보  | 액세스 : 앱 및 정책  | 제품정보 |

## 6. 배포 Terraform

<Render file="terraform/deploy-terraform" product="cloudflare-one" />

GCP 인스턴스와 터널에 대한 몇 분이 걸릴 수 있습니다. 새로운 터널을 볼 수 있습니다.[Cloudflare 대시보드](https://dash.cloudflare.com/)이름 \***사업영역** > **연락처**.

## 7. 연결을 시험하십시오

1. 내 계정[Cloudflare 대시보드](https://dash.cloudflare.com/), 이동**사업영역** > **연락처**터널을 확인**지원하다**.

2. (선택) 접근을 설정하면 이동**보안 보안** > **오시는 길** > **이름 \***&#x43;loudflareXQ 이메일은 액세스 정책에 의해 허용됩니다.

3. 모든 장치에서 브라우저를 열고 이동`http_app.<CLOUDFLARE_ZONE>`(예:`http_app.example.com`).

   액세스를 구성하면 액세스 로그인 페이지를 볼 수 있습니다. CloudflareXQ 메일로 로그인하십시오.

4. HTTPBin 홈페이지를 보시려면 터널이 제대로 routing 트래픽인지 확인하십시오.

### 자주 묻는 질문

- [웹 사이트 추가 Cloudflare](/fundamentals/manage-domains/add-site/)

## 2. 터널 만들기

1. 내 계정[Cloudflare 대시보드](https://dash.cloudflare.com/), 이동**사업영역** > **연락처**.
2. 제품정보**터널 만들기**이름을 입력합니다 (예를 들어,`azure-tunnel`).
3. 제품정보**터널 만들기**.
4. 이름 \***설치 환경**, 선택**데비안 64 비트**.
5. 설치 명령을 복사하고 Azure VM에서 실행하십시오.
6. 터널이 연결되면, 선택**계속하기**.

## 3. 신청 게시

1. 이름 \***오시는 길**, 선택**경로 추가** > **자주 묻는 질문**.
2. hostname(예를 들어,`hellocloudflare.<your-domain>.com`).
3. 이름 \***제품정보**, 입력`http://localhost:80`.
4. 제품정보**경로 추가**.

테스트하려면 브라우저를 열고 설정된 호스트 이름으로 이동합니다. 당신은 볼 수**안녕하세요 Cloudflare!**&#xC2DC;험 페이지.

:::note\[개인 네트워크 접속을 찾고?]
WARP 클라이언트를 사용하여 개인 IP를 통해 Azure VM에 연결하려면, 참조[모델 번호: Cloudflare One Tunnel 문서](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/).
:::

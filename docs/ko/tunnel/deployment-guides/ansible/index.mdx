Ansible은 인프라의 규모 관리를 가능하게 하는 소프트웨어 도구입니다. Ansible은 Agentless입니다 - 모든 함수는 대상에 SSH와 PythonXQ가 설치되어있는 기능입니다.

Cloudflare 터널 설정 프로세스를 간소화하기 위해 Terraform과 함께 사용할 수 있습니다. 이 가이드에서 Terraform을 사용하여 Google Cloud에서 SSH 서버를 배포하고 생성합니다.[로컬 관리 터널](/tunnel/advanced/local-management/create-local-tunnel/)서버는 인터넷에서 사용할 수 있습니다. Terraform은 자동으로 Ansible playbook을 실행하고 구성합니다.`cloudflared`서버에서.

모델 번호: Cloudflare 터널은 아웃바운드 전용을 통해 CloudflareXQ에 인프라를 연결합니다.[게시물-퀀텀 암호화](/ssl/post-quantum-cryptography/)연결. 공공 IP를 폭발하는 대신 가벼운 데몬을 설치`cloudflared`서버에서. 그것은 CloudflareXQ의 세계적인 네트워크에 지속적인 갱도를 창조합니다, 그래서 당신의 근원에 모든 소통량은 CloudflareXQ를 통해 흐릅니다 — CDN 캐싱, WAF, Bot 관리 및 DDoS 보호가 자동적으로 적용됩니다.

inbound 포트가 없습니다. 공공 IP 없음. 공격 표면 없음.

## 어떻게 작동합니까?

1. 설치하기`cloudflared`서버 또는 네트워크에.
2. `cloudflared`CloudflareXQ에 아웃바운드, 포스트-퀀텀 암호화 연결 설정 - 인바운드 포트 또는 방화벽 변경 없음.
3. 지역 서비스에 대한 공공 호스트 이름 (예를 들어,`app.example.com`으로`http://localhost:8080`).
4. 트래픽은 Cloudflare의 네트워크를 통해 전체 CDN 및 보안 적용.

각 갱도는 붙박이 중복을 위한 2개의 Cloudflare 자료 센터에 4개의 오래 살아 있는 연결을 유지합니다. 여러 번 실행할 수 있습니다.`cloudflared` [회사 소개](/tunnel/configuration/#replicas-and-high-availability)추가 높은 가용성.

![HTTP 요청이 Cloudflare 터널과 연결된 원산지에 도달하는 방법](~/assets/images/cloudflare-one/connections/connect-apps/handshake.jpg)

## 사용 사례

- **Secure Origin 연결**— 공개 IP를 삭제합니다. 모든 트래픽은 CDN, WAFXQ 및 DDoS 보호가 적용된 Cloudflare를 통해 흐릅니다.
- **공공 ingress 여정**— 로컬 서비스에 public hostnames를 맵핑하여 인터넷에 내부 애플리케이션을 게시합니다. HTTP, HTTPS, TCP, SSH, RDP 및 지원[더 보기](/tunnel/routing/#supported-protocols).
- **모델 번호: WorkersVPC**— 사용[CloudflareWorkers](/workers-vpc/)개인 데이터베이스, API 및 터널을 통해 서비스에 안전하게 액세스합니다.
- **적재 Balancing**— 터널을 Origin endpoints로 사용[Cloudflare 로드밸런서](/load-balancing/)높은 가용성과 지적인 교통 조타를 위한 수영장.

:::note\[Zero Trust 및 개인 네트워킹을 찾고?]
VPN 교체, 개인 네트워크 액세스 및 네트워크 트래픽 필터링을 위해, 참조[모델 번호: Cloudflare One Tunnel 문서](/cloudflare-one/networks/connectors/cloudflare-tunnel/).
:::

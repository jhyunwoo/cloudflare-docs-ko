이 페이지는 가장 일반적인 구성 옵션을 커버`cloudflared`높은 가용성, 방화벽 규칙 및 실행 매개 변수를 포함한 터널.

## Replicas 및 높은 가용성

터널을 실행할 때,`cloudflared`4개의 아웃바운드만 설치[게시물-퀀텀 암호화](/ssl/post-quantum-cryptography/)적어도 2개의 명백한 Cloudflare 자료 센터에 연결. 어떤 연결, 서버 또는 데이터 센터가 오프라인으로 진행되는 경우, 리소스는 사용할 수 있습니다.

복제는 추가`cloudflared`같은 터널에 점이 있는 경우. 각 복제는 4개의 새로운 연결을 창조하고, 당신의 근원에 추가 진입 점을 제공하. 터널당 최대 25개의 복제(100개의 연결)을 실행할 수 있습니다. 지리적으로 가까운 복제에 대한 교통 경로.

## 방화벽 규칙

## 실행 매개 변수

이 플래그는`cloudflared tunnel run`명령. 터널이 운영 체제에서 실행되는 방법을 제어합니다.

가장 일반적으로 사용되는 매개 변수:

| 제품 설명                                                     | 기본 정보             | 이름 \*                                            |
| --------------------------------------------------------- | ----------------- | ------------------------------------------------ |
| [`--loglevel`](/tunnel/advanced/run-parameters/#loglevel) | `info`            | 로그 동사성:`debug`, `info`, `warn`, `error`, `fatal` |
| [`--logfile`](/tunnel/advanced/run-parameters/#logfile)   | 사이트맵              | 로그 출력을 쓰는 경로                                     |
| [`--metrics`](/tunnel/advanced/run-parameters/#metrics)   | `127.0.0.1:2024x` | Prometheus 메트릭 엔드포인트 주소                          |
| [`--protocol`](/tunnel/advanced/run-parameters/#protocol) | `auto`            | 연결 의정서:`auto`, `quic`, `http2`                   |
| [`--region`](/tunnel/advanced/run-parameters/#region)     | 글로벌               | 미국 전용 데이터 센터를 통해 노선`us`                          |
| [`--token`](/tunnel/advanced/run-parameters/#token)       | —                 | 터널 토큰 (remotely-managed Tunnels)                 |

다음 예제는 구성 플래그와 터널을 수동으로 실행하는 방법을 보여줍니다 :

```sh
cloudflared tunnel --loglevel info --logfile /var/log/cloudflared/cloudflared.log run --token <TOKEN VALUE>
```

터널 서비스에 추가하는 방법에 대한 실행 매개 변수 및 지침의 전체 목록을 보려면, 참조[실행 매개 변수](/tunnel/advanced/run-parameters/).

## 근원 모수

Origin 설정 매개 변수 제어 방법`cloudflared`프록시 트래픽을 Origin 서버에.

가장 일반적으로 사용되는 매개 변수:

| 제품 설명                                                                      | 기본 정보   | 이름 \*                    |
| -------------------------------------------------------------------------- | ------- | ------------------------ |
| [`originServerName`](/tunnel/advanced/origin-parameters/#originservername) | `""`    | Origin 인증서에서 예상되는 호스트 이름 |
| [`noTLSVerify`](/tunnel/advanced/origin-parameters/#notlsverify)           | `false` | TLS 인증                   |
| [`httpHostHeader`](/tunnel/advanced/origin-parameters/#httphostheader)     | `""`    | HTTP 보안 호스트 헤더           |
| [`connectTimeout`](/tunnel/advanced/origin-parameters/#connecttimeout)     | `30s`   | TCP 연결 시간                |

원산지 매개 변수 및 설정 지침의 전체 목록은 참조[근원 모수](/tunnel/advanced/origin-parameters/).

환경이 읽기 전용일 때, 이 환경에 배치 된 버전은 영구적으로 읽기 전용이됩니다. 이 구성은 실수로 인한 민감한 환경을 보호합니다.

**버전 Zero**이 규칙에 예외이며 항상 편집 할 수 있습니다.

<Render file="production-read-only-default" product="version-management" />

<br />

비슷한 이유로 일부 조직은 만들 수 있습니다.**사이트맵**읽기 전용 환경. 그렇지 않으면 계정의 다른 회원은 버전으로 변경할 수 있습니다.**사이트맵** *후에*귀하의 조직은 이전의 검증 테스트를 수행했습니다.**제품정보**. 읽기 전용 없이**사이트맵**환경은, 이 변화로 풀어질 수 있었습니다**제품정보**테스트하지 않고 라이브 트래픽에 문제가 발생할 수 있습니다.

환경의 읽기 전용 상태를 변경하려면[환경 편집](/version-management/how-to/environments/#edit-environment).

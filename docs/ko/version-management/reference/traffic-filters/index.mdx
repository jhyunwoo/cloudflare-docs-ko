당신은[환경 만들기](/version-management/how-to/environments/#create-environment), 해당 환경에 대한 트래픽 필터를 지정합니다. 이 필터는 환경에 도달하는 모든 트래픽을 보장하고, 확장, 환경의 버전과 관련된 구성 변경은 의도적이다.

특정 환경에 트래픽을 보내려면 필터에 명시된 패턴과 일치하는 영역에 요청을 보냅니다. 이들은 같은 특성일 수 있었습니다**가장자리 서버 IP**, **아사쿠사**, **이름 \***, 또는**사용자 에이전트**.

요청이 환경에 도달하기 위해, 검토[미터](/version-management/how-to/versions/#view-metrics)당신의 환경에 관련. 이 미터는 또한 당신이 기대하는 방법에 있는 당신의 윤곽 변화가 영향을 미치는 소통량을 평가하는 것을 도울 것입니다.

버전의 차이를 빠르게 볼 수 있습니다. 구성이 앞에 정확합니다.[버전 홍보](/version-management/how-to/environments/#change-environment-version)새로운 환경에.

일반적인 사용 사례는 노화 및 생산의 버전과 비교하여 생산에 시효 버전을 홍보하기 전에 변화를 확인합니다.

버전 비교:

1. Cloudflare 대시보드XQ에 로그인하십시오.

   <DashButton url="/?to=/:account/home" />

2. 계정과 영역을 선택하십시오.

3. 오시는 길**버전 관리** > **비교하기**.

4. 두 가지 다른 버전을 선택하십시오.

5. 제품정보**더 보기**.

몇 초 후에, 페이지는 per-product 기초에 비교하여 자동적으로 업데이트할 것입니다. 더 낮은 수의 버전은 항상 왼쪽에 표시되며 상단은 사용자가 올바른 버전을 비교할 수 있도록 할당 된 환경을 보여줍니다.

![버전간의 변경 사항 보기](~/assets/images/version-management/compare-versions.png)

변경은 새로운 추가 및 제거를 위해 강조됩니다. 비교를 기반으로하면 더 많은 변경이 필요한 경우 또는 새로운 버전이 밖으로 구출 될 준비가 결정할 수 있습니다.

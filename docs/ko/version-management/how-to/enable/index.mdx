## 버전 관리

:::카트로션

Zone Versioning을 비활성화 할 때 모든 영역 구성은 당신에 반대합니다.**버전 Zero**.

생산 환경을 삭제할 때, 모든 트래픽은 버전 0에 기본적으로 표시됩니다. 환경 삭제의 작업은 어떤 버전 구성에 영향을 미치지 않습니다.

:::

지역 버전 비활성화:

1. 견적 요청**버전 Zero**당신의 지역을 위한 정확한 윤곽이 있습니다:
   1. 사용 방법[비교 기능](/version-management/how-to/compare-versions/)현재의 차이를 볼 수 있습니다.**제품정보**버전 및**버전 Zero**.

   2. 차이점이 있는 경우, 변경 사항**버전 Zero**그래서 그것은 당신의 현재 일치**제품정보**버전.

   3. [지원하다](/version-management/how-to/environments/#promote-a-version) **버전 Zero**내 계정**제품정보**환경.

   4. 새 소식**제품정보**예상대로 환경 기능.

2. 이름 \*`GET`요청하기`/zones/{zone_id}/environments`끝점.

   ```bash
   curl "https://api.cloudflare.com/client/v4/zones/{zone_id}/environments" \
   --header "X-Auth-Email: <EMAIL>" \
   --header "X-Auth-Key: <API_KEY>"
   ```

   응답에서 다음 값을 저장하십시오.

   - 환경`ref`모든 규칙

3. 사용 방법`ref`그 환경의, 보냅니다`DELETE`요청하기`/zones/{zone_id}/environments/{ref}`각 환경을 위한 endpoint.

   ```bash
   curl --request DELETE \
   "https://api.cloudflare.com/client/v4/zones/{zone_id}/environments/{ref}" \
   --header "X-Auth-Email: <EMAIL>" \
   --header "X-Auth-Key: <API_KEY>"
   ```

4. 그런 다음`GET`모든 HTTP 응용 프로그램을 찾을 수 요청 (또는 귀하의 영역의 버전).

   ```bash
   curl "https://api.cloudflare.com/client/v4/zones/{zone_id}/http_applications" \
   --header "X-Auth-Email: <EMAIL>" \
   --header "X-Auth-Key: <API_KEY>"
   ```

   구매하기`id`각 HTTP 응용 프로그램의.

5. 사용 방법`id`HTTP 애플리케이션의 전송`DELETE`모든 신청에 대한 요청.

   ```bash
   curl --request DELETE \
   "https://api.cloudflare.com/client/v4/zones/{zone_id}/http_applications/{http_application_id}" \
   --header "X-Auth-Email: <EMAIL>" \
   --header "X-Auth-Key: <API_KEY>"
   ```

이 모든 단계가 완료되면 Zone Versioning은 원래 착륙 페이지로 돌아갑니다.

## 기타 제품

당신의 지역에 새로운 변화를 위해,[새 버전 만들기](/version-management/how-to/versions/#create-version)그리고 이 과정을 반복하십시오.

## 특정 버전 삭제

버전 관리에서 생성 된 버전은 immutable이며 변경 사항을 추적하고 필요한 경우 다시 롤링 할 수 있도록 삭제 될 수 없습니다.

당신은 할 수 있습니다, 그러나, 새로운 버전을 만들고 이전 버전에서 구성을 복제, 당신의 원하는 환경에 홍보하기 전에 필요한 변경을 만들기. 이 솔루션은 효과적으로 "delete" 오래된 버전을 사용하여 더 이상 사용하지 않습니다.

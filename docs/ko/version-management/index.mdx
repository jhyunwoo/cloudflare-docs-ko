## 이름 \*

버전 관리를 사용해서:

- 실제 트래픽에 영향을 미치는 위험 없이 변경할 수 있는 독립적인 버전 만들기.
- 안전한 배치는 생산에 배포하기 전에 환경의 변화에 변화합니다.
- 문제가 발생할 때 신속하게 배치 된 변경을 롤.

## 적용분야

<FeatureTable id="account.version_management" />

접속하기[지원하다](/version-management/how-to/enable/)Cloudflare 대시보드에 있는 지역 Versioning.

## 제품 정보

버전 관리를 사용하려면 다음을 모두 true이어야합니다.

- 당신의 지역은 기업 계획에 있습니다.
- 당신의 지역은[이름 \*](/dns/zone-setups/reference/domain-status/)국가.
- 당신의 지역 용도[WAF 관리 규칙](/waf/managed-rules/).
- 당신의 지역은 사용할 수 있습니다[주문 규칙](/waf/custom-rules/)방화벽 규칙 대신 (deprecated).
- 계정은[새로운 WAF](https://blog.cloudflare.com/new-cloudflare-waf/)(아니면 계정 팀에 문의하십시오).
- 사용자 계정은 관리자 또는 관리자가 있어야 합니다.[이름 \*](/fundamentals/manage-members/roles/). **지역 버전**역할은 새로운 버전을 만들 수 없습니다.
- 사용자 계정은 API Key 프로비저닝이 있어야 합니다 (if not,[API 키 보기](/fundamentals/api/get-started/keys/#view-your-global-api-key)).
- 사용자 계정은 API 액세스가 활성화되어야 합니다. 더 알아보기[API 접근 제한](/fundamentals/api/how-to/control-api-access/)더 많은 정보.
- 버전을 관리하려면 대시보드를 사용해야합니다.

이메일 보안이 감지되면<GlossaryTooltip term="phishing">피싱</GlossaryTooltip>이메일, 검출의 메타데이터는 Falcon LogScale에 직접 전송할 수 있습니다. 이 튜토리얼에서는 Falcon LogScale 계정이 필요합니다. LogScale 계정에서 새로운 Ingest Token을 만들 수도 있습니다. Ingest Tokens는 저장소를 식별하고 저장소에 데이터 섭취를 구성하는 데 사용됩니다. 더 알아보기[비밀번호 찾기](https://library.humio.com/falcon-logscale-cloud/ingesting-data-tokens.html)더 많은 정보.

Ingest 토큰을 만들기 후에:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**이메일 설정** > **도메인 및 루팅** > **웹훅**.
4. 제품정보**새로운 Webhook**.
5. 내 계정**앱 유형**, 선택**사이트맵**.
6. 제품 정보*카테고리*드롭다운에서 Ingest Token을**Auth 부호**이름 \*
7. 내 계정**제품정보**, URL을 붙여`https://cloud.community.humio.com/api/v1/ingest/hec/raw`.
8. 제품정보**웹훅 게시**.

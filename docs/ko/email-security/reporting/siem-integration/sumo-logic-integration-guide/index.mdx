이메일 보안이 감지되면<GlossaryTooltip term="phishing">피싱</GlossaryTooltip>이메일, 검출의 메타데이터는 Sumo Logic의 인스턴스로 직접 전송할 수 있습니다. 이 문서는 Sumo Logic을 사용하여 이메일 보안을 통합해야합니다.

![이메일 보안이 피싱 이메일을 감지하고 Sumo Logic에 전송할 때 발생하는 다이어그램.](~/assets/images/email-security/siem-integration/sumo-logic/opening-sumo-logic.png)

## 1. Sumologic 수집가 구성

1. 로그인[스모 로직](https://service.sumologic.com/ui/)관리자 계정으로

2. 오시는 길**Data 관리** > **제품정보**수집가 설정 창을 엽니다.

3. 제품정보**관련 제품**.

   ![수집가 추가.](~/assets/images/email-security/siem-integration/sumo-logic/step3-collector.png)

4. 내 계정**선택 수집가 유형**, 선택**Hosted 수집**.

   ![Hosted Collector를 선택하십시오.](~/assets/images/email-security/siem-integration/sumo-logic/step4-hosted.png)

5. 내 계정**Hosted 수집가 추가**, 다음 설정을 입력:

   - **이름 \***: `Email security Collector`
   - **이름 \***: `Email security Security Collectors`
   - **(주)**: 안티-피싱

   ![수집자를 구성하려면 위의 설정을 입력합니다.](~/assets/images/email-security/siem-integration/sumo-logic/step5-hosted-collector.png)

6. 제품정보**제품 정보** > **이름 \***&#xC0C8;로운 수집가의 추가를 확인합니다.

7. 내 계정**클라우드 API**, 선택**HTTP 로그 및 미터**데이터 소스의 구성을 시작합니다.

   ![HTTP 로그 및 미터 선택.](~/assets/images/email-security/siem-integration/sumo-logic/step7-http-logs.png)

8. 본문 바로가기**이름 \***·**이름 \***, 그리고 선택**제품 정보**.

   ![이름과 설명을 입력합니다.](~/assets/images/email-security/siem-integration/sumo-logic/step8-name.png)

9. 시스템은 HTTP 엔드포인트로 대화 상자가 표시됩니다. 저장하면 나중에 이메일 보안을 구성해야합니다.

   ![나중에 사용하려면 엔드포인트를 참고하십시오.](~/assets/images/email-security/siem-integration/sumo-logic/step9-endpoint.png)

## 2. 이메일 보안 구성

다음 단계는 Sumologic HTTP Collector에 이메일 탐지 이벤트를 밀어 이메일 보안을 구성하는 것입니다.

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**이메일 설정** > **웹훅**, 그리고 선택**새로운 Webhook**.
3. Webhooks 페이지를 추가하려면 다음 설정을 입력하십시오.
   - **앱 유형**: 선택**사이트맵** > **스플리크**. 에서**Auth 코드**, 입력`Sumologic`.
   - **제품정보**: 이전 섹션에서 저장된 HTTP 엔드포인트를 입력하십시오.
   - 제품정보<GlossaryTooltip term="disposition">관련 기사</GlossaryTooltip> (`MALICIOUS`, `SUSPICIOUS`, `SPOOF`, `SPAM`, `BULK`) 당신이 webhook에 보낼 것을 원하는 경우에 선택. 이름 \*`SPAM`·`BULK`dispositions는 사건의 높은 수를 생성합니다.
4. 제품정보**웹훅 게시**.

Sumo Logic 통합은 이제 모든 Webhooks 패널에서 표시됩니다.

![Sumo Logic webhook은 모든 Webhooks 패널에 표시됩니다.](~/assets/images/email-security/siem-integration/sumo-logic/all-webhooks.png)

이메일 보안의 인프라를 통해 완전히 propagate를 구성하는 데 약 10 분이 소요되며, 검색에 나타나기 위해 이벤트를 시작합니다. 구성이 propagated되면 이벤트는 Sumo Logic의 인스턴스에 나타납니다.

로그를 보기 위해, 이메일 보안 수집가에 마우스를 hover, 선택**로그인 검색**.

![Sumo Logic에서 로그 보기.](~/assets/images/email-security/siem-integration/sumo-logic/open-log.png)

이벤트가 시작되면, 선&#xD0DD;**- 한국어** > **비밀번호**검색 기준에 대한 검색 결과 (예를 들어,`_collector="Email security Collector"`).

![이벤트 검색](~/assets/images/email-security/siem-integration/sumo-logic/search-events.png)

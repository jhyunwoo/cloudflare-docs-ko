## 2. HTTP Event Collector 테스트

HTTP Event Collector를 테스트하려면 다음 cURL 명령을 사용하여 Splunk로 이벤트를 수동으로 주입할 수 있습니다.

```bash
curl https://{host}:8088/services/collector/event \
--header "Authorization: Splunk <YOUR_TOKEN>" \
--data '{
    "sourcetype": "<YOUR_SOURCE_TYPE>",
    "event": "Hello, World!"
    }'
```

### 자주 묻는 질문

Splunk에 요청을 만들 때, URL 및 포트 번호는 Splunk 설정의 유형에 따라 변경합니다.

- **Splunk Cloud Platform 무료 평가판**: `<protocol>://http-inputs-<host>.splunkcloud.com:8088/<endpoint>`
- **Splunk 클라우드 플랫폼**: `<protocol>://http-inputs-<host>.splunkcloud.com:443/<endpoint>`
- **Splunk 기업**: `<protocol>://<host>:8088/<endpoint>`

더 알아보기[Splunk 문서](https://docs.splunk.com/Documentation/Splunk/8.2.2/Data/UsetheHTTPEventCollector)더 많은 정보.

인스턴스가 온프레미스인 경우 적절한 호스트명을 지정하고 방화벽이 구성된 포트를 인스턴스로 지정할 수 있도록 합니다. 연결은이에서 오는 것입니다[Egress IP 주소](/email-security/deployment/inline/reference/egress-ips/), 액세스 제어 목록에 필요한 경우 (ACLs)

:::참조
예를 들어 유효한 SSL 인증서가 있는지 확인하십시오. 인증서는 만료 될 수 없으며 자체 서명 된 인증서가 될 수 없습니다.
주요 특징

모든 요구 사항이 충족되면 cURL 명령으로 다음 응답을 받게됩니다.

{"text":"Success","code":0}

## 3. 이메일 보안 구성

다음 단계는 Splunk HTTP Event Collector에 이메일 탐지 이벤트를 밀어 이메일 보안을 구성하는 것입니다.

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**이메일 설정** > **웹훅**, 그리고 선택**새로운 Webhook**.
3. Webhooks 페이지를 추가하려면 다음 설정을 입력하십시오.
   - **앱 유형**: 선택**사이트맵** > **스플리크**, 그리고 이전 단계의 메모를 했다 auth 코드를 입력.
   - **제품정보**: Splunk 인스턴스의 대상 URI를 입력합니다. 그것은 일반적으로 있다`https://<host>:8088/services/collector`파일 형식. 더 알아보기[자주 묻는 질문](#request-formats)Splunk 구독이 URI에 영향을 미치는 방법에 대해 자세히 알아보십시오.
   - 제품정보<GlossaryTooltip term="disposition">관련 기사</GlossaryTooltip> (`MALICIOUS`, `SUSPICIOUS`, `SPOOF`, `SPAM`, `BULK`) 당신이 webhook에 보낼 것을 원하는 경우에 선택. 이름 \*`SPAM`·`BULK`dispositions는 사건의 높은 수를 생성합니다.
4. 제품정보**웹훅 게시**.

Splunk 통합은 이제 모든 Webhooks 패널에서 표시됩니다.

![모든 Webhooks 섹션은 Splunk webhook을 보여줍니다.](~/assets/images/email-security/siem-integration/splunk/splunk-webhook-integrations.png)

그것은 약 10 분 정도 걸릴 것입니다 또는 그래서 완전히 이메일 보안 (이전 지역 1)의 인프라를 통해 propagate에 대한 구성, 그리고 당신의 검색에 나타나는 이벤트. 구성이 propagated되면, 이벤트는 Splunk의 인스턴스에 나타납니다.

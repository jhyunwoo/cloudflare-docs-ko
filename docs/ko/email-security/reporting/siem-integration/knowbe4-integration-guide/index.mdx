이메일 보안이 감지되면<GlossaryTooltip term="phishing">피싱</GlossaryTooltip>이메일, 검출의 메타데이터는 KnowBe4에 직접 전송할 수 있습니다. 이 튜토리얼에서는 SecurityCoach add-on을 사용하여 KnowBe4 계정이 필요합니다. 이메일 보안에서 사용할 조직 키를 만들 수도 있습니다. 이 조직 키는 이메일 보안을 사용하여 KnowBe4를 통합 할 수 있습니다. 더 알아보기[KnowBe4 문서](https://support.knowbe4.com/hc/articles/13129840202643)이 주제에 대한 자세한 내용은.

조직 키 생성 및 이메일 보안 승인 후:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**이메일 설정** > **도메인 및 루팅** > **웹훅**.
4. 제품정보**새로운 Webhook**.
5. 내 계정**앱 유형**, 선택**사이트맵**.
6. 제품 정보*알고있다Be4*드롭다운에서 조직 키를 붙여넣기**Auth 부호**이름 \*
7. 내 계정**제품정보**, 귀하의 조직에 맞는 URL을 붙여. KnowBe4는 다른 지역을 위한 다른 URL이 있습니다:
   | KnowBe4 인스턴스 | 사이트 맵                                          |
   | ------------ | ---------------------------------------------- |
   | 대한민국         | `https://area1.vendor.training.knowbe4.com/v1` |
   | 유럽 연합 (EU)   | `https://area1.vendor.eu.knowbe4.com/v1`       |
   | 한국어          | `https://area1.vendor.ca.knowbe4.com/v1`       |
   | 대한민국         | `https://area1.vendor.uk.knowbe4.com/v1`       |
   | 한국어          | `https://area1.vendor.da.knowbe4.com/v1`       |
8. 제품정보*관련 상품*드롭다운 메뉴에서**맛있는 스타일**, **Suspicious 스타일**·**Spoof 작풍**.
9. 제품정보**웹훅 게시**.

귀하의 계정의 개요에 액세스하려면, 처리 된 이메일의 총 번호, 다른 유형의 정보 중 스레드의 고장 :

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/users/login).
2. 귀하의 계정에 대한 정보를 검토하는 홈 섹션에서 확인:

| 제품정보                     | 이름 \*                                                                                                                          |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| **시스템 통계**               | <ul><li>지역 1의 서비스 상태</li> <li>지역 1의 서비스 및 가동 시간</li> <li>처리 된 이메일 및 공격의 수</li></ul>                                            |
| **탐지 통계**                | 총 수의 검출에 관한 통계 및 처리 된 이메일.                                                                                                     |
| **관련 기사**                | 사용자의 메일 박스에서 삭제 된 메시지의 배포를 표시합니다.                                                                                              |
| **Phish Submissions 통계** | 사용자 및 보안 운영 센터 (SOC)에 의해 제출 된 phish 이메일의 수에 관한 통계                                                                              |
| **위협 근원**                | 당신의 조직에 대한 최고 지리적 위협.                                                                                                          |
| **Org 스포프**              | envelopes의 이름은 헤더와 spoofed 도메인과 다릅니다.                                                                                          |
| **도메인 Proximity**        | 당신의 자신과 비슷한 도메인 목록.                                                                                                            |
| **맛있는 목 유형**             | 악성 위협 유형의 고장.                                                                                                                  |
| **이메일 링크 고립**            | 자주 묻는 질문[이메일 링크 고립](/email-security/email-configuration/email-policies/link-actions/#email-link-isolation).                    |
| **BEC 대상**               | 어떤 이메일 주소는 상단 대상에[비즈니스 이메일 Compromise 기능](/email-security/email-configuration/enhanced-detections/business-email-compromise/). |

이메일 보안에 의해 처리 된 이메일에 대한 검색 할 수 있습니다 (이전 지역 1), 그들은 표시되어 있는지 여부<GlossaryTooltip term="disposition" link="/email-security/reference/dispositions-and-attributes/">탐지 disposition</GlossaryTooltip>또는 아니.

이메일 검색을위한 두 가지 방법이 있습니다 :

- **연락처**: 검색 조건을 입력 할 수있는 필드로 당신을 선물합니다.
- **Freeform 검색**: 자신의 검색 쿼리를 구성 할 수있는 하나의 검색 필드가 있습니다.`My great products`.

## 검색 조건

Freeform Search에서 공간에 의해 분리되는 값이나 조합을 검색할 수 있습니다. 여러 검색 조건을 가진 공간은 연산자를 사용하는 것과 같습니다.`AND`.

3개 미만의 문자 길이 및 일반 영어 단어는 검색 값에 대한 중요성을 제공하지 않습니다.`and`, `the`, `then`, `their`무시.

더 정확한 일치를 위해, 지명한 분야를 안으로 사용하십시오**연락처**필드가 값을 포함해야한다는 것을 나타냅니다. 예를 들어, 전송된 메시지만 찾습니다.`demo@example.com`, 입력`demo@example.com`내 계정**에서 (EXACT)**. `EXACT`필드 descriptor에서 용어는 값이 메시지에 어떻게 나타나는지 일치합니다.

2. 선택하기**이름 \***&#xBC14;.
3. 다음 필드 중 하나 이상의 채우기. 채우는 다수 분야는 추가의 동등물입니다`AND`뒤에 오는 기간 사이 통신수:
   - **제품 정보**: 사용 가능한 필드의 조건을 검색합니다. 여러 수신자에 맞는 메시지를 검색하려면이 필드를 사용하십시오. 하나의 값만 지정할 수 있습니다.**이름 \***·**으로**사이트 맵
   - **(예)**: sender의 정확한 이메일 주소 검색.

## Freeform 검색

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 선택하기**검색 바** > **Freeform 검색**.
3. 검색 쿼리 작성 — 예를 들어,`My great products`. 시스템은 쿼리에 맞는 모든 이메일을 반환합니다.

## 검색 팁

### 모수 필터링

특정 값에 대한 검색[유효한 모수](/email-security/reporting/search/available-parameters/), 당신의 검색을 형식으로:

```txt
<<FIELD_NAME>>:<<VALUE>>
```

예를 들어, 검색할 수 있습니다.`final_disposition:MALICIOUS`. 우리의 참고 자료 물자에 가득 차있는 명부를 위한 참조하십시오[관련 기사](/email-security/reference/dispositions-and-attributes/).

### `message_id`

일반 쿼리의 경우, 공백은 다른 값으로 검색 조건을 분할합니다. 예를 들어,`billing statement`모두 포함 된 모든 메시지를 찾습니다`billing`·`statement`.

그러나 공간, 인용 및 기타 문자는 때때로 일부입니다.`message_id`모수. 이 값을 확인하려면 메시지 ID에 필터링의 일부로 포함, 당신은 prefix해야합니다`message_id`가치와`message_id`.

예를 들어, 다음 쿼리는 모든 메시지를 찾을 수 있습니다.`billing`·`statement`그리고 있다`message_id`이름 \*`<Amazon aws Support@email.amazonses.com>`.

```txt
billing statement message_id:<Amazon aws Support@email.amazonses.com>
```

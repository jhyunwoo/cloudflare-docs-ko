## 데이터 보유

이메일 보안 Horizon Enterprise 고객을 위해 검색은 12 개월의 기간 동안 인덱스되며 12 개월 동안 회전 할 수 있습니다.

이메일 보안 Horizon Advantage 고객에 대한 검색은 3 개월 동안 인덱스되며 3 개월 동안 회전합니다.

## 데이터의 범위 유지

감지되지 않은 메시지의 경우, 메시지 자체의 몸은 유지되지 않습니다. 보낸 사람, 수신자, 제목, message id 및 배달 로그와 같은 메타 데이터 만 유지됩니다. 미리보기 이미지로 메시지를 볼 수도 있습니다.

검색을 위해, 전체 메시지가 유지됩니다, 첨부 파일을 포함, 위에 설명 된 메타 데이터 이외에. 첨부 파일을 포함한 원시 메시지는 다운로드 할 수 있습니다`.eml`파일.

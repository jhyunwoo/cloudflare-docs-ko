계정에서 수행 된 작업을 검토하려면 이메일 보안 로그를 사용할 수 있습니다.

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**사용자 및 활동** > **감사 로그**.
4. 로그를 검토합니다. 드롭다운 메뉴에서 로그 유형으로 필터링 할 수 있습니다.

## 로그 미리보기

미리보기 로그 중 하나를 사용하여 이메일 보안이 포스트 배달 retractions를 처리하는 방법을 미리 볼 수 있습니다. 감사 로그 미리보기, 이메일 보안은 Post Delivery Response (PDR) 또는 Phish Submissions Response (PSR)로 철회 된 이메일이 표시됩니다.

더 알아보기**새로운 위협을 위한 포스트 납품 retractions**제품 정보[사이트맵](/email-security/deployment/api/setup/gsuite-bcc-setup/add-retraction/#post-delivery-retractions-for-new-threats)또는[사무실 365](/email-security/email-configuration/retract-settings/office365-retraction/#post-delivery-retractions-for-new-threats)이 기능에 대해 더 알아보기.

미리보기 로그를 검토하려면:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**사용자 및 활동** > **감사 로그**.
4. 드롭다운에서, 중 하나를 선택**다운로드**로그아웃 이것은 포스트 배달 응답 또는 Phish Submission 응답으로 철회 된 것을 보여줄 것입니다.

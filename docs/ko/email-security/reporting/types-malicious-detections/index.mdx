계정에서 만든 악의적인 탐지의 수와 유형을 검토하려면:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/users/login).
2. 선택하기**이름 \***&#xD0ED;.
3. 더 보기**모델 번호: 개요**섹션은 처리 된 이메일의 총 번호와 그래프뿐만 아니라 다른 위협 카테고리와 관련있는 많은 사람들을 보여줍니다. Malicious 또는 Spam과 같은. 더 알아보기[위치 및 속성](/email-security/reference/dispositions-and-attributes/)더 많은 정보. 제품정보**더 보기**.
4. 당신은 열 것이다**제품정보**사이트 맵 이 페이지는 다양한 종류의 위협에 대한 정보를 차단합니다. 당신은 접근해야:

| 제품정보      | 이름 \*                                                                                                          |
| --------- | -------------------------------------------------------------------------------------------------------------- |
| **첨부파일**  | <ul><li>악의적 인 이메일이 첨부 된 몇 가지가 있습니다.</li> <li>이 중 가장 악의적인 파일 중 하나는 (예를 들어, PDF 파일).</li></ul>                   |
| **회사 소개** | <ul><li>Total Number of malicious senders, 뿐만 아니라 그래프는 그들이 달 내내 배포되는 방법을 보여주는.</li> <li>최고 악의적인 도메인.</li></ul> |
| **제품정보**  | 상단 이메일 대상[BEC 특징](/email-security/email-configuration/enhanced-detections/business-email-compromise/).         |
| **새 도메인** | <ul><li>지난 달에 등록된 악성 도메인의 총 수.</li> <li>가장 일반적인 최상위 악의 도메인.</li></ul>                                          |
| **관련 기사** | <ul><li>월간 악성 링크 및 배포의 총 수.</li> <li>Top 위협 유형 (예 : credential 수확기).</li></ul>                                 |
| **위협 유형** | 가장 악한 위협 유형, 그리고 그들의 비율은 받는 위협의 총계에 상대적으로.                                                                     |
| **위협 근원** | 세계를 대표하는 그래프는 최고의 위협 기원입니다.                                                                                    |

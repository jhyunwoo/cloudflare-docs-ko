## blocked sender 추가

새로운 블록 패턴을 만들려면 :

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 이름 \***이메일 설정**, 이동**블록 목록** > **블록 체인**.

4. 제품정&#xBCF4;**+ 새로운 Sender**.

5. 패턴 정보를 입력:
   - **회사 소개**: 다음 유형의 패턴 중 하나를 입력 :
     - **이메일 주소**: 유효한 이메일이어야 합니다.
     - **IP 주소**: IPv4만 가능합니다. IPv6 및 CIDR는 유효하지 않은 항목입니다.
     - **일반 표현**: 필수[유효한 Java 표현](https://www.freeformatter.com/java-regex-tester.html). 정규 표현은 sender 이메일 주소와 관련된 필드와 일치합니다 (`envelope from`, `header from`, `reply-to`), IP 주소 시작, 이메일 서버 이름.

   - **지원하다**: blocked sender 패턴에 대한 추가 노트를 제공합니다.

6. 제품정보**제품 정보**.

### CSV 업로드

여러 허용 패턴의 CSV 파일을 업로드 할 수 있습니다. CSV 파일은 150KB보다 작아야하며 필요한 모든 값의 헤더 행을 시작하며 추가 필드가 없습니다.

예 파일은 다음과 같습니다.

```txt
Blocked_Sender, Notes
john.smith@email.com, John Smith
melanie.turner@email.com, Melanie Turner
```

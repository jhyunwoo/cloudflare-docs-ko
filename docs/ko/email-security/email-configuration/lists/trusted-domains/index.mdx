**신뢰할 수 있는 도메인**이메일 보안 (이전 지역 1) 탐지에서 면제되어야하는 도메인을 식별 할 수 있습니다.

## 기본 동작

메시지가 특정 도메인에서 수신자에게 올 때, 이메일 보안 트리거[제품정보](/email-security/reference/dispositions-and-attributes/)기본적으로:

- **Proximity 도메인**: 기존 도메인에 유사한 맞춤법과 도메인. 트리거 할 것`SPOOF`탐지.
- **최근 도메인**: 최근에 만들어진 도메인 (exact Definition set in[관련 검색](/email-security/email-configuration/enhanced-detections/added-detections/)). 트리거 할 것`MALICIOUS`또는`SUSPICIOUS`탐지.

그러나 때때로 그 도메인은 합법적입니다. 예를 들어, 귀하의 회사는 도메인 스쿼터를 전투하기 위해 몇 가지 유사 도메인을 등록 할 수 있습니다.

이 감지에서 특정 도메인을 면제하려면 신뢰할 수있는 도메인을 추가 할 수 있습니다.

## 신뢰할 수있는 도메인 추가

신뢰할 수있는 도메인을 추가하려면:

1. 로그인하기[이메일 보안 (이전 지역 1) 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 이름 \***이메일 설정**, 이동**자주 묻는 질문** > **신뢰할 수 있는 도메인**.

4. 제품정&#xBCF4;**+ 도메인 추가**.

5. 정확한 흐름은 당신이 당신의 선택에 따라 달라집니다**패턴 유형**:
   - **이름 \***: 특정 도메인을 지정하고 트리거를 조정할 수 있습니다.*Proximity 도메인*·*최근 도메인*.
   - **Regex 만들기**: 도메인 이름, 최상위 도메인 (TLD) 및 하위 도메인에 대한 Regex 규칙을 생성하고 트리거를 조정 할 수 있습니다.*Proximity 도메인*·*최근 도메인*.

6. 제품정보**제품 정보**.

### CSV 업로드

또한 여러 허용 패턴의 CSV 파일을 업로드 할 수 있으므로 파일이 150 KB보다 작으므로 필요한 모든 값의 헤더 행을 시작하며 추가 필드가 없습니다.

예 파일은 다음과 같습니다.

```txt
Domain, Notes, Proximity, Recent
mydomain.com, First Person, true, true
testdomain.com, New Hire, false, true
```

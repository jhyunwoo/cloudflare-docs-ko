설정할 때**관련 상품**, 이메일 보안 이메일 보안은 정상적인 탐지 스캐닝에서 특정 패턴과 일치하는 메시지를 면제합니다.

## 허용된 패턴 추가

새로운 허용 패턴을 만들려면 :

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 이름 \***이메일 설정**, 이동**자주 묻는 질문** > **허용된 본**.

4. 제품정&#xBCF4;**+ 새로운 패턴**.

5. 패턴 정보를 입력:
   - **허용된 본**: 다음 유형의 패턴 중 하나를 입력 :
     - **이메일 주소**: 유효한 이메일이어야 합니다.
     - **IP 주소**: IPv4만 가능합니다. IPv6 및 CIDR는 유효하지 않은 항목입니다.
     - **일반 표현**: 필수[유효한 Java 표현](https://www.freeformatter.com/java-regex-tester.html).

   - **관련 제품**: 다음 유형 중 하나 이상의 선택 :
     - **신뢰할 수있는 Sender**: 메시지는 모두 우회합니다.[제품정보](/email-security/reference/dispositions-and-attributes/)이메일 보안에 따른 링크 일반적으로,에만 적용<GlossaryTooltip term="phishing">피싱</GlossaryTooltip>KnowBe4와 같은 공급 업체의 시뮬레이션.
     - **자주 묻는 질문**: 모든 이메일 보안에서 메시지 면제[제품정보](/email-security/reference/dispositions-and-attributes/)이 패턴 (이메일 주소 또는 정규식 만 해당) 일치하는 수를 위해 예정. 일반적으로 보안에 대한 사용자 보고서에 대한 메일 박스 제출에만 적용됩니다.
     - **수락가능한 Sender**: 메시지가 면제됩니다.`SPAM`, `SPOOF`·`BULK` [관련 기사](/email-security/reference/dispositions-and-attributes/#available-values)(하지만)`MALICIOUS`또는`SUSPICIOUS`). 마케팅 이메일 또는 내부 도구와 같은 조직을 대신하여 메일을 보내는 외부 도메인 및 소스에 대해 일반적으로 사용됩니다.

   - **지원하다**: 허용된 패턴에 대한 추가 노트를 제공합니다.

6. 당신이 선택한 경우*신뢰할 수있는 Sender*또는*수락가능한 Sender*이전 단계에서는 sender를 확인할 수 있습니다. 언제까지**비밀번호**옵션이 선택되어 DMARC 또는 SPF 또는 DKIM에 의해 전달 인증을 정렬하면 목록 항목 만 영광됩니다.

7. 제품정보**제품 정보**.

### CSV 업로드

여러 허용 패턴의 CSV 파일을 업로드 할 수 있습니다. CSV 파일은 150KB보다 작아야하며 필요한 모든 값의 헤더 행을 시작하며 추가 필드가 없습니다.

예 파일은 다음과 같습니다.

```txt
Pattern, Notes, Verify Email, Trusted Sender,
Exempt Recipient, Acceptable Sender
whale@notaphish.com, not a phish, true, true, false, true
```

메시지가 특정할 때<GlossaryTooltip term="disposition" link="/email-security/reference/dispositions-and-attributes/">관련 제품</GlossaryTooltip>이메일 보안 (이전 지역 1)에서 각 메시지의 주제와 신체에 추가 정보를 추가 할 수 있습니다.

이 정보는 직원에게 추가적인 컨텍스트를 제공합니다. 이 정보는 더 많은 허용 이메일 정책이 있는 경우 더 나은 결정을 내릴 수 있습니다.

- **제목 접두사**: 메시지를 분류하는 수신자에게 말할 수 있습니다. 주제 접두사 항상 마지막 상태[관련 제품](/email-security/reference/dispositions-and-attributes/)메시지의.
- **몸 prefixes**: 메시지가 특정 카테고리에 추가된 이유에 대해 더 많은 컨텍스트를 제공합니다. Body prefixes는 트리거 된 모든 탐지를 포함합니다. 이 정보는에 달려 있습니다[가능한 접두사](#update-text-add-ons).

예를 들어, 이메일은 분해가 있을 수 있습니다.`EXTERNAL MALICIOUS`주제 및`EXTERNAL MALICIOUS SUSPICIOUS UCE`몸에.

:::참조

Text add-ons는 고객에게만 적용 가능합니다.[inline 설정](/email-security/deployment/inline/).

:::

## 업데이트 텍스트 애드온

메시지의 주제 또는 신체에 새 추가를 업데이트하거나 추가하려면:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 이름 \***이메일 설정**, 이동**이메일 정책** > **텍스트 추가 Ons**.

4. 제품정보**제품정보**.

5. 각각**관련 제품**, prefixes가 있는지 선택**이름 \***&#xADF8;리고 당신이 갱신하고 싶은지**주문 상표**.

6. 원하는 경우도 사용할 수 있습니다.**제목 접두사**또는**몸 접두사**렌더링 된 분해 후 텍스트를 추가하려면 :
   - **제목 접두사**: 동적 값 포함`%LABELS`disposition를 나열하고 추가 텍스트를 포함 할 수 있습니다.
   - **몸 접두사**: 동적 값 포함`%LABELS`그 목록은 분해 및`%REASONS`그것은 할당 된 분해 뒤에 이유를 나열합니다. 추가, HTML 형식 텍스트를 포함 할 수 있습니다.

7. 제품정보**텍스트 추가 기능**.

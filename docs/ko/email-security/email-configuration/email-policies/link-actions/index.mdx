## 분쟁 해결

이메일에 대한 작업 만들기<GlossaryTooltip term="disposition" link="/email-security/reference/dispositions-and-attributes/">관련 기사</GlossaryTooltip>. `URL defang`선택된 유형의 이메일에 있는 모든 URL이 링크를 따를 수 없다는 것을 의미한다. 예를 들어,`https://www.example.com`으로`https[:]//www[.]example[.]com`.

업데이트 또는 새로운 분해 작업을 만들려면 :

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

4. 내 계정**분쟁 해결**제품정보**제품정보**.
5. 각 분해를 위해와 같은`MALICIOUS`, `SPAM`·`BULK`, 수행 할 작업을 선택합니다.

## 이메일 링크 고립

Email Link Isolation rewrites link that could be exploited, alerts users when there is uncertainty around the website they are visiting, and protects against malware and vulnerabilities through[Cloudflare 브라우저 고립](/cloudflare-one/remote-browser-isolation/).

Email Link Isolation을 활성화할 때, 서비스는 이메일에 링크를 다시 작성하고 모든 페이지 내용이 원격 서버에 fetched 및 렌더링되는 브라우저 탭에서 열 수 있습니다. 이 기능이 활성화되면 웹 페이지 또는 이메일 링크가 서버 수준에서 격리되고 클라이언트 네트워크에 영향을 미칩니다.

Suspicious 하이퍼 링크는 Cloudflare의 보안 팀에 의해 유지되는 동적인 고립 명부에 의해 체계 결정되고, 방아쇠를 칩니다.

### 이전 분해 작업

이메일 링크 고립을 활성화할 때, Cloudflare는 더 이상 계정으로 가지고 갑니다[URL 작업](#disposition-actions)에 따라[이메일의 처분](/email-security/reference/dispositions-and-attributes/). URL 작업은, 오히려, 링크의 속성을 기반으로.

Link rewriting는 모든 이메일 분해에 적용합니다. 장애를 위해 설정된 작업이 있는 경우, 이메일 링크 고립을 활성화할 때 경고를 볼 수 있습니다. 이메일 Link Isolation의 rewriting이 전 세계적으로 적용된다는 것을 나타냅니다.

### Enable Email Link 고립

:::caution\[이메일 링크 고립 및 Microsoft O365]
Microsoft Office 365를 사용하는 경우 URL을 허용해야 합니다.`https://linkdefender.cloudflare.com`이메일 Link Isolation을 활성화하기 전에. 더 알아보기[Microsoft의 문서](https://learn.microsoft.com/en-us/microsoft-365/security/office-365-security/tenant-allow-block-list-urls-configure)URL을 허용하는 방법을 배울 수 있습니다.
주요 특징

이메일 Link Isolation을 활성화하려면[inline 배포](/email-security/deployment/inline/)이메일 보안 설정. Email Link Isolation는 이메일 보안을 통해 배포되지 않습니다.[저널링 또는 BCC](/email-security/deployment/api/setup/)설정.

Email Link Isolation는 URL rewrite를 하는 다른 보안 응용 프로그램이 없을 때만 사용될 수 있습니다. 두 배 연결은 지원되지 않습니다.

이메일 Link Isolation를 활성화하려면:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 이름 \***이메일 설정**, 이동**이메일 정책** > **링크 작업**.
4. 제품정보**이메일 링크 고립**그리고 그것을 활성화.

이메일 Link Isolation이 활성화되었습니다.

:::참조

Email Link Isolation는 고급 구성 옵션이 없습니다. 격리 된 브라우저 세션에서 할 수있는 것보다 더 미세한 제어가 필요하면 Cloudflare Zero Trust 계정을 가지고 변경 사항을 만드십시오.[브라우저 고립](/cloudflare-one/remote-browser-isolation/).
:::

## URL rewrite 무시 패턴

특정 패턴 일치 URL에 다시 쓰기를 무시하는이 옵션을 사용합니다. 이 기능은 내부 법인 서비스가 결코 그들을 위해 rewritten 링크가없는 것을 보장 할 수 있습니다.

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 이름 \***이메일 설정**, 이동**이메일 정책** > **링크 작업**.
4. 제품정보**URL Rewrite Ignore 패턴**.
5. 새로운 URL 패턴을 추가**URL 패턴**선택하기**패턴 추가**.

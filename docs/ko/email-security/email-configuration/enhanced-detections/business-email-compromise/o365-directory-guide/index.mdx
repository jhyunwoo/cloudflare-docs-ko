이메일 보안 (이전 지역 1)은 Office 365와 통합하여 사용자 및 그룹 정보를 검색할 수 있습니다. 기업 이메일 Compromise 구성을 시행하기 위해 사용될 수 있습니다.

## 1. Office 365로 이메일 보안을 권한 부여

이메일 보안을 인증해야 합니다.[사무실 365 임계](https://learn.microsoft.com/en-us/microsoft-365/solutions/tenant-management-overview)디렉토리 세부 정보를 검색합니다. 저자에 사용된 계정은 요구합니다**Privileged 인증 관리자**·**Privileged 역할 관리자**역할.

### 승인은 어떻게 작동합니까?

인증 프로세스는 기능에 필요한 최소한의 적용 가능한 권한을 가진 Azure 환경에 이메일 보안 액세스를 부여합니다. 이메일 보안 등록자가 관리자 계정에 연결되지 않는 엔터프라이즈 응용 프로그램입니다. Azure Active Directory 관리자 센터에서 Enterprise Application 섹션에서 응용 프로그램에 부여 된 권한을 검토 할 수 있습니다.

Office 365 콘솔에서 사용자 역할을 할당할 때 이러한 역할을 찾을 수 있습니다.**사용자 권한** > **역할 구성** > **Identity 관리자 역할**.

![이메일 보안에 대한 권한 목록](~/assets/images/email-security/bec/o365/permissions.png)

1. 로그인하기[이메일 보안 (이전 지역 1) 대시보드](https://horizon.area1security.com/), 그리고 선택**계정 설정**(장치 아이콘).

2. 오시는 길**주요연혁**, 그리고 선택**연락처**인증 프로세스를 시작합니다.

   ![이메일 보안의 대시보드에서 디렉터리로 이동하고, 권한 프로세스를 시작하기 위해 디렉토리를 추가하십시오.](~/assets/images/email-security/bec/o365/step2-directories.png)

3. Add Directory 구성 패널에서 다음 세부 사항을 입력하십시오.

   - **연락처**: 드롭다운 메뉴를 열고 선택**사무실 365**.
   - **연락처**: 디렉토리를 나타내는 문자열을 입력합니다. 이 값은 Business Email Compromise List 구성 섹션에서 참고 자료d입니다. 예를 들어,`Office 365`.
   - **Sync 빈도**: p참고 자료에 값을 업데이트하십시오.

   제품정보**이름 \***&#xB2F9;신이 할 때.

   ![구성 패널에 적합한 세부 사항 추가](~/assets/images/email-security/bec/o365/step3-directory-config-panel.png)

4. 이메일 보안 대시보드는 Microsoft 로그인 페이지로 이동합니다. 인증 프로세스를 시작하려면 적절한 계정을 선택하거나 입력하십시오.

   <div class="large-img">
     ![적합한 Microsoft 계정 선택](~/assets/images/email-security/bec/o365/step4-login.png)
   </div>

5. 인증되면 시스템이 요청된 권한 목록을 가진 대화 상자를 표시합니다. 제품정보**이름 \***&#xBCC0;경을 승인합니다.

   <div class="medium-img">
     ![자주 묻는 질문](~/assets/images/email-security/bec/o365/step5-permissions.png)
   </div>

6. 저자화에, 당신은 자동으로 추가 디렉토리 구성 패널에 다시 리디렉션됩니다. 제품정보**제품 정보**인증 프로세스를 완료하기 위해.

   ![인증 프로세스를 완료하기 위해 Save를 선택하십시오.](~/assets/images/email-security/bec/o365/step6-save.png)

7. 새로 구성 된 디렉토리가 구성 된 디렉토리 테이블에 나타납니다.

   ![디렉토리는 구성 된 디렉토리 테이블에 표시됩니다.](~/assets/images/email-security/bec/o365/step7-directories.png)

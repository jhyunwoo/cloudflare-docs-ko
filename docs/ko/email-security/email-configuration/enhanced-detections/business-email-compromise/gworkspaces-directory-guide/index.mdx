이메일 보안은 Google과 통합하여 사용자 및 그룹 정보를 검색할 수 있습니다. 기업 이메일 Compromise 구성을 시행하기 위해 사용될 수 있습니다.

## 1. 이메일 보안 디렉토리 통합을 위해 Google의 서비스 계정 만들기

메일 보안을 승인하면 Google Tenant로 연결하여 디렉토리 세부 정보를 검색할 수 있습니다. Cloudflare는 당신이 이 목적을 위한 서비스 계정을 창조하는 것을 추천합니다. 이 계정은 다음과 같은 특전이 필요합니다.

- 도메인에 그룹 가입을 보기.
- 도메인에서 조직 단위를 볼 수 있습니다.
- 도메인에서 그룹 보기.
- 귀하의 도메인에서 사용자에 대한 정보.

서비스 계정 만들기 당신이 이미 한 경우, 당신은이 단계를 건너 뛸 수 있습니다.

1. 오시는 길[Google 관리자 콘솔](https://admin.google.com/)·**계좌정보** > **관리자 역할**.

   ![Google 계정에서 관리자 콘솔에 액세스](~/assets/images/email-security/bec/gmail/step1-access-gadmin.png)

2. 제품정보**새로운 역할 만들기**, 그리고 그것에게 descriptive 이름 및 묘사를 줍니다. 완료되면, 선택**계속하기**.

3. 내 계정**Admin 콘솔 특전**, 다음 특전을 선택하십시오:

   - *조직 단위 > ...에서*
   - *사용자 > ...에서*
   - *디렉토리 설정 > 설정 >Google 지원 설정*
   - *디렉토리 동기화 > Directory 동기화 설정 관리 > 읽기 Directory 동기화 설정*

   ![여기에 언급 한 권한만 선택하십시오.](~/assets/images/email-security/bec/gmail/step3-console-privileges.png)

4. Admin 콘솔 특전을 지정할 때 해당 Admin API 특전을 부여합니다. 어떤 경우, 다음의 특전을 선택해야 합니다.**Admin API 권한**:

   - *조직 단위 > ...에서*
   - *사용자 > ...에서*
   - *그룹 > ...에서*

   ![여기에 언급 한 권한만 선택하십시오.](~/assets/images/email-security/bec/gmail/step4-api-privileges.png)

5. 제품정보**계속하기**.

6. 자주 묻는 질문**역할 만들기**.

## 2. Google과의 디렉토리 액세스에 대한 이메일 보안 승인

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/), 그리고 선택**계정 설정**(장치 아이콘).

2. 오시는 길**주요연혁**, 그리고 선택**연락처**인증 프로세스를 시작합니다.

   ![이메일 보안의 대시보드에서 디렉터리로 이동하고, 권한 프로세스를 시작하기 위해 디렉토리를 추가하십시오.](~/assets/images/email-security/bec/gmail/step2-directories.png)

3. Add Directory 구성 패널에서 다음 세부 사항을 입력하십시오.

   - **연락처**: 드롭다운 메뉴를 열고 선택**구글 +**.
   - **연락처**: 디렉토리를 나타내는 문자열을 입력합니다. 이 값은 Business Email Compromise List 구성 섹션에서 참고 자료d입니다. 예를 들어,`Gmail`.
   - **Sync 빈도**: p참고 자료에 값을 업데이트하십시오.

   제품정보**이름 \***&#xB2F9;신이 할 때.

4. 이메일 보안 대시보드는 Google 로그인 페이지로 이동합니다. 인증 프로세스를 시작하려면 적절한 계정을 선택하거나 입력하십시오.

5. 인증되면 시스템이 필요한 권한 목록을 가진 대화 상자를 표시합니다. 모든 체크 박스를 확인하고 선택**계속하기**변경을 승인합니다.

   ![Google의 모든 설정을 선택](~/assets/images/email-security/bec/gmail/step5-authorize-google.png)

6. 저자화에, 당신은 자동으로 추가 디렉토리 구성 패널에 다시 리디렉션됩니다. 제품정보**제품 정보**인증 프로세스를 완료하기 위해.

   ![인증 프로세스를 완료하기 위해 Save를 선택하십시오.](~/assets/images/email-security/bec/gmail/step6-save.png)

7. 새로 구성 된 디렉토리가 구성 된 디렉토리 테이블에 나타납니다.

   ![디렉토리는 구성 된 디렉토리 테이블에 표시됩니다.](~/assets/images/email-security/bec/gmail/step7-directories.png)

이름 \***관련 검색**, 당신은 이메일을 분석의 시간에 적용되는 각종 윤곽을 처리할 수 있습니다.

이러한 설정은 신뢰할 수있는 비즈니스 파트너에게 특히 적용됩니다. 조직은 (벤더, 외부 제공 업체 및 더 많은) 비즈니스를 할 수 있습니다.

## Access 추가 탐지

접속하다**관련 검색**그리고 잠재적으로 설정을 조정:

1. 로그인하기[이메일 보안 (이전 지역 1) 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 이름 \***이메일 설정**, 이동**향상된 탐지** > **관련 검색**.

이 전망에서, 당신은 조정할 수 있습니다[다양한 구성](#available-configurations).

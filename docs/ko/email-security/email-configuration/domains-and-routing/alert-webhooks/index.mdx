  </GlossaryTooltip>

## alert webhook 만들기

이메일 보안에 경고 webhook를 만들려면:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**이메일 설정** > **도메인 및 루팅** > **웹훅**.
4. 제품정보**새로운 Webhook**.
5. 자주 묻는 질문**앱 유형**.
6. 이름 \***제품정보**.
7. 제품정보**웹훅 게시**.

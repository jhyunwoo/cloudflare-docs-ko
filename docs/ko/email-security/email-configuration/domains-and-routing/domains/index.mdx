Cloudflare가 도메인에 들어오는 이메일을 수신하고 평가합니다.

## 도메인 만들기

이메일 보안의 새로운 도메인 만들기:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 오시는 길**이메일 설정** > **도메인 및 루팅** > **이름 \***.

4. 제품정보**새로운 도메인**.

5. 다음 정보를 입력하십시오:
   - **이름 \***: 이메일 트래픽을 수신하는 도메인 이름.
   - **으로 구성**: 선택**MX 기록**또는 번호 지정**뚱 베어**(이메일 아키텍처에 따라).
   - **관련 제품**: 이메일 공급자의 호스트명을 입력합니다.
   - **IP 제한**(선택 사항): 우편 서버의 IP 주소로 들어오는 트래픽을 제한합니다.
   - **상행 TLS**(비-MX 도메인에서만 사용 가능): 들어오는 트래픽에 TLS를 적용합니다.
   - **아웃바운드 TLS**: 선택**TLS를 통한 모든 메시지 전달**(추천) 또는**모든 메시지를 전달 opportunistic TLS**.
   - **Quarantine 정책**: 선택<GlossaryTooltip term="disposition" link="/email-security/reference/dispositions-and-attributes/">관련 기사</GlossaryTooltip>당신은 보낼[관리 quarantine](/email-security/email-configuration/admin-quarantine/).

6. 제품정보**도메인 게시**.

***

## 도메인 편집

기존 도메인을 편집하려면:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**이메일 설정** > **도메인 및 루팅** > **이름 \***.
4. 특정 도메인에서, 선&#xD0DD;**...** > **제품정보**.
5. 자주 묻는 질문
6. 제품정보**업데이트 도메인**.

***

도메인 삭제:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**이메일 설정** > **도메인 및 루팅** > **이름 \***.
4. 특정 도메인에서, 선&#xD0DD;**...** > **이름 \***.

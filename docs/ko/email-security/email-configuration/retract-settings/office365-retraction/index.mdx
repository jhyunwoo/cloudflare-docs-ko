이 튜토리얼에서 Microsoft Office 365에 대한 이메일 retraction을 설정하는 방법을 배울 수 있습니다.

## 1. Retraction를 위한 Office 365를 가진 이메일 보안 승인

메시지를 위해 retraction 성공적으로 실행, 이메일 보안은 Office 365 Graph API 아키텍처로 API 호출을 할 수있는 권한이 있어야합니다. 이메일 보안을 승인하는 데 사용되는 계정은**Privileged 역할 관리자**역할.

Office 365 콘솔에서 사용자 역할을 할당할 때 이러한 역할을 찾을 수 있습니다.**사용자 권한** > **역할 구성** > **Identity 관리자 역할**.

### 승인은 어떻게 작동합니까?

인증 프로세스는 기능에 필요한 최소한의 적용 가능한 권한을 가진 Azure 환경에 이메일 보안 액세스를 부여합니다. 이메일 보안 등록 (이메일 보안 동기화)가 관리자 계정에 연결되지 않는 엔터프라이즈 응용 프로그램입니다. Azure Active Directory 관리자 센터에서 Enterprise Application 섹션에서 응용 프로그램에 부여 된 권한을 검토 할 수 있습니다.

![이메일 보안에 대한 권한은 Office 365에 액세스해야 합니다.](~/assets/images/email-security/email-retraction/o365/area1-synchronator.png)

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/), 그리고 선택**계정 설정**(장치 아이콘).

2. 오시는 길**이메일 설정** > **RETRACT 설정**.

   ![이메일 보안에서 retract 설정 접근](~/assets/images/email-security/email-retraction/o365/step2-retract-settings.png)

:::참조
Retract 설정 옵션을 볼 수없는 경우,[연락처 고객 지원](/support/contacting-cloudflare-support/)기능 설정
주요 특징

1. Office 365의 Graph API를 통해 회선을 실행하려면 이메일 보안을 승인해야합니다. 정통에 사용할 계정이 있는지 확인합니다. 제품정보**이름 \***&#xD504;로세스를 시작합니다.

   ![Office 365에 액세스하기 위해 이메일 보안을 승인하는 과정을 시작하기 위해 Authorize](~/assets/images/email-security/email-retraction/o365/step3-authorize-o365.png)

2. 이메일 보안 대시보드는 Microsoft 로그인 페이지로 이동합니다. 인증 프로세스를 시작하려면 적절한 계정을 선택하거나 입력하십시오.

   ![계정을 선택하거나 새 계정을 입력하여 이메일 보안을 승인하십시오.](~/assets/images/email-security/email-retraction/o365/step4-authorize-login.png)

3. 인증되면 시스템이 요청된 권한 목록을 가진 대화 상자를 표시합니다. 제품정보**이름 \***&#xBCC0;경을 승인합니다.

   ![Office 365에서 이메일 보안을 승인할 수 있습니다.](~/assets/images/email-security/email-retraction/o365/step5-authorize.png)

4. 인증에, 당신은 이메일 보안 대시보드에 자동으로 리디렉션됩니다, 인증이 성공적으로 완료 된 알림. 제품정보**뚱 베어**공지사항

   ![성공 알림을 해소하기 위해 Dismiss을 선택하십시오.](~/assets/images/email-security/email-retraction/o365/step6-dismiss.png)

## 하드 삭제 된 메시지를 복구

Office 365는 하드 삭제 된 이메일 메시지를 복구하기위한 두 가지 방법이 있습니다 :

- **[전자Discovery](https://learn.microsoft.com/en-us/purview/ediscovery?view=o365-worldwide)**
- **[Exchange 관리자 센터](https://learn.microsoft.com/en-us/exchange/recipients-in-exchange-online/manage-user-mailboxes/recover-deleted-messages)**

Microsoft의 문서에 대한 자세한 내용은 삭제 된 이메일 메시지를 복구하기 위해이 도구를 사용하는 방법에 대해 자세히 알아보십시오.

Admin Quarantine은 수신된 메시지를 자동적으로 막을 수 있도록 합니다.<GlossaryTooltip term="disposition" link="/email-security/reference/dispositions-and-attributes/">관련 제품</GlossaryTooltip>이메일 보안에 의해 할당.

Admin Quarantine에 보내진 메시지는 당신에 의해 결정됩니다[도메인 설정](/email-security/email-configuration/domains-and-routing/domains/).

## Quarantine 이메일 disposition

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 제품정보**이메일 설정** > **이름 \***.

4. 관리 quarantine을 구성하고 싶은 도메인에 3개의 점을 선정하고, 선택합니다**제품정보**.

5. 내 계정**Quarantine 정책**해당 도메인에 대한 quarantine을 활성화 할 수있는 위치를 선택하십시오.

6. 제품정보**업데이트 도메인**.

:::주\[주]

disposition에 의한 Quarantine은 도메인 당 수동으로 구성해야합니다.

당신은 볼 수 잠재적으로 전송 된 이메일**관리자 Quarantine**:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 오시는 길**이름 \*** > **관리자 Quarantine**.

3. 자주 묻는 질문

## 출시 quarantined 이메일

이름 \***관리자 Quarantine**, 당신은 또한 하나 이상의 메시지를 선택하여 quarantined 이메일을 해제 할 수 있습니다 :

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 오시는 길**이름 \*** > **관리자 Quarantine**.

3. 출시하려는 이메일 찾기.

4. 제품정&#xBCF4;**...** > **제품정보**.

   ![quarantine에서 이메일을 제거하는 방출을 선택하십시오.](~/assets/images/email-security/admin-quarantine/release-emails.png)

5. 제품정보**제품정보**선택한 이메일이 공개되도록 확인하려면.

6. (선택) 각 메시지 옆에 박스를 선택하여 여러 메시지도 해제할 수 있습니다.

:::참조
quarantine에서 발표 된 후, 이메일 보안은 원래 이메일 메시지를 목적지로 전달합니다. 이 이메일은 원본 발송인에서 이메일 inboxes에 도착합니다, 이메일 안전.

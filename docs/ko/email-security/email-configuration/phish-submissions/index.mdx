귀하의 지속적인 이메일 보안 자세, 관리자 및 보안 분석가의 일부가 놓칠 필요<GlossaryTooltip term="phishing">뚱 베어</GlossaryTooltip>표본에[이메일 보안 (이전 지역 1) 서비스 주소](https://horizon.area1security.com/support/service-addresses/)그래서 Cloudflare는 그(것)들을 가공하고 필요한 활동을 가지고 갈 수 있습니다.

때때로 phish는 이메일 보안이 감지하기 위해 몇 가지 기술을 사용합니다. 이 웹을 호출하여 캠페인, 기계 학습, 사용자 정의 서명을 식별 할 수 있습니다. 이메일 보안을 위해 phish가 놓친 이유를 확인하기 위해, 우리는 우리의 모듈을 통해 원래 샘플을 실행하고 왜 우리 모듈의 일부가 악의적으로 높이는 충분한 샘플을 점수하지 않았다는 것을 확인합니다.

Cloudflare에 놓인 phish 표본을 제출하는 것은 지속적인 보호를 위한 기공 중요성 그리고 필요의 입니다. 놓인 phish 샘플을 제출하면 Cloudflare는 기계 학습 (ML) 모델을 개선하고 새로운 공격 벡터를 전동적으로 경고합니다.

## phish 제출 방법

phish 샘플을 제출하는 두 가지 방법이 있습니다.

- **사용자 제출**: 최종 사용자에 의해 직접 제출하고 phish 제출 버튼을 사용하여 사용됩니다.<br />user-submitted phish에 대해 자세히 알아 보려면 다음 문서를 참조하십시오.<DirectoryListing />

- **팀 제출**: IT 관리자 또는 보안 팀이 이메일 보안을 제출할 때 사용해야 합니다. EML 형식으로 첨부 파일로 원본 phish 샘플을 제출하십시오.[팀 제출 주소](https://horizon.area1security.com/support/service-addresses/). 예를 들어, 이메일이 spoof로 표시되어야한다고 생각합니다.`SPOOF`팀 제출에 나열된 주소.<br />이 주소에 제출 된 Phish 샘플은 고객의 이메일 보안 팀의 제출으로 간주됩니다. 이것은 유사한 표본의 기회를 미래에 악의로 검출합니다.

팀 주소에 phish 샘플을 제출 한 후, 당신은에서 업데이트를 받게됩니다`status@submission.area1reports.com`조사 및 예측에 대해. 피드백은 우리의 위협 연구 팀에 의해 고객에게 직접 제공되며, 지원 채널을 우회하여 프로세스를 폭발시킵니다.

## phish 제출 후 어떤 일이 발생합니다.

사용자가 phish 샘플을 제출 한 후, 이메일 보안은 학습을위한 기계 학습 (ML) 큐에 직접 샘플을 추가합니다. 몇몇 표본은 직접 개조될 것입니다`MALICIOUS`기계 학습을 통해서 가고 나머지는 우리의 ML 단위에 의해 더 가공될 것입니다.

### Phish 제출 피드백

이메일 보안 대시보드에 제출 된 phish 샘플을 검색하려면 다음 키워드를 사용하십시오.

- `phish_submission`
- `user_malicious_submission`
- `team_malicious_submission`

에 의해**이름 \***&#xC5F4;은 발견 된 메시지에 대한 피드백을 볼 수 있습니다. ML 모듈이 학습하고 phish로 감지하면**이름 \***&#xC5F4;은 그것에 관하여 세부사항을 보여줍니다. 이 열에 대한 정보는 다음과 같습니다.`phish submission`.

이메일 보안을 처리할 수 없는 사용자에게 반복적으로 전송되는 피싱 이메일이 있는 경우,[연락처](/support/contacting-cloudflare-support/)문제 phish 제출 샘플의 세부 사항 (샘플의 ID 또는 메시지 ID).

### Phish 제출 응답 (베타)

Phish Submission Response (PSR)는 보호의 추가 층입니다. PSR을 활성화하면 이메일 보안이 자동으로 분석 후 이메일 보안에 의해 악화되는 사용자에 의해보고 된 메시지가 표시됩니다. 이 기능은 사용자를 이메일 보안의 신경 네트워크로 추가하여 기계 학습 마진 점수를 사용합니다.

PSR을 활성화하려면:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 내 계정**이메일 설정**, 이동**Retract 설정** > **자동 철회**.
4. 이름 \***Phish 제출 응답 (베타)**.

:::참조

PSR은 제출된 phish 샘플만을 사용합니다.[사용자 제출 주소](https://horizon.area1security.com/support/service-addresses/). 참고[Retract 설정](/email-security/email-configuration/retract-settings/)수동 및 자동 retraction에 대해 자세히 알아보세요.

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 선택하기**이름 \***&#xBC14;.
3. 거짓 긍정적으로 보고하고 싶은 메시지 하나 이상의 검색**false 긍정적으로 보고**.

제출 메시지의 흐름에 따라 Microsoft는 더 이상 Microsoft Report Message 버튼을 위한 메일 흐름 규칙을 존중합니다. 따라서, 이메일 보안은 더 이상이 도구와 호환되지 않습니다.

무슨 일이 일어나고 있는지, 관리자로 Microsoft 계정에 로그인하고,[Microsoft에서 통신을 검토](https://admin.microsoft.com/AdminPortal/Home?ref=MessageCenter/:/messages/MC690173).

피시 샘플을 제출하거나 이메일 보안을 놓칠 필요가 있다면, 우리는 사용하는 것이 좋습니다.[Office 365를 위한 PhishNet](/email-security/email-configuration/phish-submissions/phishnet-o365/)대신 통합 앱.

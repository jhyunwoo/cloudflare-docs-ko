PhishNet은 사용자가 이메일 보안 (이전 지역 1)에 직접 제출하는 데 도움이되는 추가 버튼입니다.<GlossaryTooltip term="phishing">뚱 베어</GlossaryTooltip>지역 1의 탐지에 의해 놓인 표본. PhishNet은 이전 프로세스를 피합니다. 사용자는 이메일 관리자에게 phish를보고해야하며 수동으로 다운로드하고 이메일 보안에 샘플을 전달해야합니다.

## 자주 묻는 질문

PhishNet을 Google Workspace로 설정하려면 Google Workspace 계정에 대한 관리자 액세스가 필요합니다.

## Google Workspace에 PhishNet 설정

1. 로그인[Google Workspace 마켓 플레이스 앱](https://workspace.google.com/marketplace/app/cloudflare_phishnet/11369379045)이 직접 링크 및 관리자 계정 사용.

2. 제품정보**관리자 설치**Cloudflare PhishNet 설치. 경고를 읽고, 선택**계속하기**.

   <div class="large-img">
     ![Cloudflare PhishNet 설치하기 시작하려면 관리자 설치를 선택하십시오.](~/assets/images/email-security/phish-submissions/phishnet-gworkspace/step1-phishnet-install.png)
   </div>

3. 열린 창에서 Cloudflare PhishNet을 설치하는 사이에 선택하십시오.**당신의 조직에 모두**또는**특정 그룹 또는 조직 단위**. 이 마지막 옵션을 선택하면 PhishNet을 설치하려는 사용자가 선택할 수 있습니다.

   <div class="medium-img">
     ![PhishNet을 설치하려는 사용자에게 선택](~/assets/images/email-security/phish-submissions/phishnet-gworkspace/step3-select-users.png)

4. PhishNet을 설치하려는 그룹을 선택하면 Google의 서비스 약관에 동의하고 선택**제품 정보**.

5. Google Workspace는 Cloudflare PhishNet이 설치되었습니다. 제품정보**이름 \***&#xACC4;속.

   <div class="medium-img">
     ![모든 것이 잘되면 Done을 선택해야합니다.](~/assets/images/email-security/phish-submissions/phishnet-gworkspace/step5-done.png)
   </div>

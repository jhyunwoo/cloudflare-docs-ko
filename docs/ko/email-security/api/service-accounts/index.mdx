·**서비스 계정**관리자가 단일 사용자 이름과 암호 조합에서 API 자격 증명을 생성하고 유지하도록 합니다. 또한 다른 사용 사례에 대한 추가 API 액세스를 생성하고 제어 할 수 있습니다.

연결할 때[이메일 보안 (이전 지역 1) API](/email-security/api/)·**공공 키**용도*이름 \**&#xADF8;리고**개인 키**제품정보*비밀번호*.

## 서비스 계정 만들기

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**서비스 계정**.
4. 제품정보**서비스 계정 추가**.
5. 추가하기**이름 \***.
6. 제품정보**서비스 계정 만들기**.
7. 계정을 볼 수 있습니다.**개인 키**팝업 메시지 ( 다시 표시되지 않을 것) 및**공공 키**서비스 계정의 목록에서. 안전한 위치에 값과 저장을 모두 복사해야 합니다.

***

## 개인 키를 회전

개인 키를 잃거나 보안상의 이유로 회전해야하는 경우 새로운 개인 키를 생성 할 수 있습니다.

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**서비스 계정**.
4. 특정 계정에, 선&#xD0DD;**...** > **키를 새로 고침**.

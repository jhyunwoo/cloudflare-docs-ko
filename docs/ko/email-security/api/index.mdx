이메일 보안은 Application Programming Interfaces (APIs)를 제공합니다.<GlossaryTooltip term="phishing">피싱</GlossaryTooltip>캠페인 규칙. 이 APIs는 aid 둘 다 연구와 네트워크 보안 가장자리 장치를 사용하여 막는 지시자의 세트를 제공합니다.

모든 API 요청은 정상적인 HTTP 요청을 사용하여 시작된다 (`GET`/`POST`/`DELETE`) 및 응답은 JSON에 반환됩니다. APIs 인증은 HTTP Basic Authentication을 HTTPS에 사용합니다.

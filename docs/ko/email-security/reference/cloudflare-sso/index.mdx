이메일 보안 대시보드에 로그인하려면 Cloudflare 계정을 단일 서명에 (SSO) 인증 제도로 사용할 수 있습니다.

1. 로그인하기[이메일 보안 (이전 지역 1) 대시보드](https://horizon.area1security.com/).
2. 제품정보**Cloudflare로 로그인**. 로그인하려면 Cloudflare 계정으로 리디렉션됩니다.
3. 제품정보**지원하다**Cloudflare 계정으로 변경하려면 이메일 보안을 허용하십시오. 이메일 보안 대시보드로 리디렉션됩니다.
4. 로그인하려면 이메일 보안의 이메일 주소를 입력하십시오.

Cloudflare 계정을 단일 서명에 인증 제도로 사용하여 이메일 보안에 로그인할 수 있습니다. 이메일 보안 대시보드에 액세스 할 수있는 다음 시간, 그냥 선택**Cloudflare로 로그인**로그인

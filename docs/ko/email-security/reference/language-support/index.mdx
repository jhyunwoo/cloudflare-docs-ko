## 이메일 평가

이메일 보안에 의해 사용되는 스캔 서비스 및 verdict 엔진은 언어 agnostic입니다. 우리는 더블 바이트 문자 세트 (DBCS) 및 UTF-8, UTF-16 및 UTF-32 인코딩에 대한 지원을 제공합니다.

## 모델 번호: 대시보드

이메일 보안 이메일 대시보드는 여러 언어로 현지화됩니다. 언어 설정을 업데이트하려면:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 페이지 하단에서 언어 아이콘을 선택하십시오.

   <div class="medium-img">
     ![대시보드를 영어와 일본어로 변환하려면 언어 아이콘을 선택하십시오.](~/assets/images/email-security/language-switcher.png)
   </div>

3. 원하는 언어를 선택하십시오.

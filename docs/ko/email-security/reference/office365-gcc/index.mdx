Microsoft 365 Government Community Cloud (GCC)는 미국 정부의 요구 사항을 충족하도록 설계되었습니다. GCC 낮은 GCC 높은는 GCC의 2개의 층, 다른 안전 및 수락 필요조건으로 각각입니다.

GCC 소개 Low는 미국 정부 기관에 의해 민감한 데이터 처리, 그리고 더 적은 엄격한 준수 요구 사항이 있습니다.

이메일 보안 지원 GCC 낮은 환경.

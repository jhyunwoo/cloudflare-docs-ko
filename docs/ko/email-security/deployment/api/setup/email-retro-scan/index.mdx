이메일 Retro 검사는 사무실 365 (O365)의 오래된 메시지의 14 일까지 검사하고 당신의 현재 이메일 안전 해결책이 어떤 위협든지 놓은지 검사합니다. 계정 관리자에게 이 기능을 활성화하십시오.

## 위협 검사

Office 365 inbox에서 위협을 스캔하려면:

1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com/login), 귀하의 계정과 도메인을 선택합니다.
2. 오시는 길**이메일 보안** > **Retro 검사**.
3. 제품정보**Generate 보고서**.
4. Cloudflare는 O365 메시지에 접근하기 위하여 허가를 필요로 합니다. 제품정보**Microsoft 인증**Cloudflare가 필요한 권한을 부여합니다.
5. Cloudflare 대시보드로 다시, 선택**Grant 메일 액세스**. 그런 다음 계정을 선택하고 Cloudflare가 필요한 권한을 부여합니다.
6. 제품정보**Grant 디렉토리 동기화**.
7. 계정을 선택하고 Cloudflare가 필요한 권한을 부여합니다.
8. 제품정보**계속하기**.
9. 내 계정**자주 묻는 질문**, 검사하는 1개 또는 더 많은 도메인을 선택합니다.
10. 이름 \***검사 날짜 범위**, 날짜 범위를 선택하여 드롭다운 메뉴에서 스캔을 수행합니다.
11. 현재 이메일 보안 시스템을 선택하십시오.**현재 이메일 보안 시스템**.
12. 제품정보**계속하기**.
13. 제품정보**이름 \***. Cloudflare는 선택한 도메인에 대한 모든 이메일을 분석하는 작업을 시작합니다. 이것은 선택한 inbox 및 도메인의 크기에 따라 시간이 걸릴 수 있습니다. 스캔을 완료 할 필요가 없습니다. Cloudflare는 스캔이 완료되면 이메일 알림을 보내드립니다. 대기 중, 선택**공지사항**검사 끝 때.

## Analyze 결과

1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com/login), 귀하의 계정과 도메인을 선택합니다.
2. 오시는 길**이메일 보안** > **Retro 검사**.
3. 제품정보**검사 보고서**. 이 탭은 스캔 된 이메일의 총 수를 보여줍니다, 고장[위협 유형](/email-security/reference/dispositions-and-attributes/)선택된 도메인 내에서 발견,[top 대상 직원](/email-security/email-configuration/enhanced-detections/business-email-compromise/), 위협이 시작되는 가장 일반적인 장소.
4. 위협 보고서의 오프라인 사본을 만들려면, 선택**다운로드 Report**.
5. 제품정보**검색 결과**Retro 검사에 의해 발견된 이메일을 검열하기 위하여. 위협 유형으로 이메일을 필터링 할 수 있습니다 (예, 악의).

Gmail에 대한 이메일 보안 설정 (이전 지역 1):

1. 로그인하기[이메일 보안 (이전 지역 1) 대시보드](https://horizon.area1security.com/).
2. BCC 주소를 찾을 수 있는 질문 표시를 선택합니다.
3. 귀하의 주소를 발견하면, 선택**계정 설정**( 기어 아이콘), 다음 선택**새로운 도메인**.
4. 도메인 추가에 필요한 정보를 입력:

- **이름 \***: Google에서 BCC를 설정하려면 도메인을 입력하십시오.
- **으로 구성**: 홉 선택, 입력`2`.
- **관련 제품**: 입력`google.com`.
- **아웃바운드 TLS**: 선택**TLS를 통한 모든 메시지 전달**.
- **Quarantine 정책**: 정책이 선택되지 않습니다.

5. 제품정보**도메인 게시**.

## 다음 단계

이제 당신은 당신의 BCC 주소를 발견하고 도메인을 추가, 계속[BCC 규칙 추가](/email-security/deployment/api/setup/gsuite-bcc-setup/bcc-rules-to-area1/)이메일 보안에 BCC 규칙을 추가합니다.

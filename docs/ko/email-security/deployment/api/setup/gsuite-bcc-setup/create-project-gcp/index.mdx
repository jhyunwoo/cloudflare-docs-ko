1. 로그인하기[Google 클라우드 콘솔](https://console.cloud.google.com/welcome/new). 대시보드에서, 선택**CREATE 또는 SELECT 프로젝트**.
2. 새로운 프로젝트에 대한 세부 사항 제공, 선택**제품정보**새로운 프로젝트를 시작합니다.
3. 새로운 프로젝트가 생성되면 Google Cloud Platform 콘솔은 프로젝트 콘솔에 자동으로 리디렉션됩니다. 프로젝트 선택기를 사용하여 생성 된 프로젝트에 변경할 수 있습니다.
4. 내 계정**시작하기**, 선택**API를 탐색하고 활성화**> 선택**API 및 서비스**.
5. 검색 바에 대한 검색`Admin SDK API`. 선택**관리자 SDK API**, 다음 선택**제품정보**.
6. 사이드바로 돌아가기, 선택**관련 기사**, Gmail API 검색. 제품정보**Gmail API를**, 다음 선택**제품정보**.

1. 내 계정[Google 관리자 콘솔](https://admin.google.com/), 이&#xB3D9;**\* 이름** > **앱 다운로드** > **Google 작업 공간** > **사이트맵** > **견적 요청**.
2. 오시는 길**콘텐츠 준수**> 선택**제품정보**.
3. 추가하기**콘텐츠 준수**필터 및 이름`Email security (Area 1) - BCC`.
4. 내 계정**이메일 메시지**, 선택**인바운드**.
5. 이메일 보안 (이전 지역 1) BCC를 통해 이메일을 보내려면 수신자를 선택하십시오. 이름 \***각 메시지에서 검색 할 콘텐츠를 설명하는 표현 추가**:
   - 제품정보**다음의 메시지가 있다면**.
   - 제품정보**더 보기**표현을 구성합니다.
     - 제품정보**고급 콘텐츠 일치**.
     - 내 계정**제품정보**, 선택**헤더 + 이름 \***.
     - 내 계정**일치 유형**, 선택**경기 regex**.
     - 내 계정**계정 관리**이름 \*`.*`. 당신은 regex를 필요에 따라 주문을 받아서 만들 수 있고 admin 페이지 또는 같은 위치에 시험하십시오[레퍼런스](https://regexr.com/).
     - 제품정보**제품 정보**.
6. 내 계정**위의 표현이 일치하면 다음과 같습니다.**:
   - 제품정보**본문 바로가기**.
     - 견적 요청**옷 입은** > **자주 묻는 질문**선택되지 않습니다, 그 이메일이 의도되지 않은 결과로 떨어질 수 있도록. 나중에 이 옵션을 선택하면 됩니다.
     - 오시는 길**자주 묻는 질문**, 선택**더 많은 수상자** > **사이트맵**> 선택**지원하다**.
       - 이름 \***옷 입은**, 선택**자주 묻는 질문** > **자주 묻는 질문**> 수신자의 이메일 입력
       - 이름 \***스팸 및 배송 옵션**, 선택**이 수신자에서 Suppress 반송**.
       - 이름 \***기타 제품**, 선택**X-Gm-Spam 및 X-Gm-Phishy 헤더 추가**.
       - 제품정보**제품 정보**.
7. 내 계정**계정 유형에 영향을 미치는**, 선택**이름 \***·**회사 소개**.
8. 제품정보**제품 정보**.

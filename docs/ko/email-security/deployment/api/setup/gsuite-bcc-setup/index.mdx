Gmail을 사용하여 고객, BCC를 통해 이메일 보안 설정은 빠르고 쉽습니다. 당신이해야 할 모든 것은 BCC를 통해 이메일 보안에 이메일 보내기 위해 콘텐츠 준수 필터를 만듭니다. 다음 이메일 흐름이 어떻게 작동 하는지 보여줍니다:

![이메일 보안을 가진 Gmail에 대한 phishing 평가 위험을 설정할 때 이메일 흐름.](~/assets/images/email-security/deployment/api-setup/gmail/gmail-bcc-flow.png)

이메일 보안을 설정하려면:

1. [BCC 주소 찾기 및 도메인 추가](/email-security/deployment/api/setup/gsuite-bcc-setup/add-domain/).
2. [BCC 규칙 추가](/email-security/deployment/api/setup/gsuite-bcc-setup/bcc-rules-to-area1/).
3. [Google Cloud Console에서 프로젝트 생성](/email-security/deployment/api/setup/gsuite-bcc-setup/create-project-gcp/).
4. [서비스 계정 만들기](/email-security/deployment/api/setup/gsuite-bcc-setup/create-service-account/).
5. [retraction 추가](/email-security/deployment/api/setup/gsuite-bcc-setup/add-retraction/).

1. 에 의해[Google 클라우드 콘솔](https://console.cloud.google.com/welcome/new), 선택**회사 소개**.

2. 제품정보**회사 소개** > **서비스 계정**.

3. 서비스 계정을 만들려면 세부 사항 작성 :
   - **서비스 계정 이름**: 입력`Message Retraction Service Account`.
   - **서비스 계정 ID**: 입력`message-retraction-service-acc`.
   - **서비스 계정 설명**: 입력`Email security Message Retraction`.
   - 제품정보**결제 및 결제**.

4. 내 계정**이 서비스 계정이 프로젝트에 접근**, 선택**역할 선택**> 선택**이름 \***. 선택**제품정보**, 다음**이름 \***.

5. 바로가기**회사 소개**, 아래 서비스 계정을 선택**서비스 계정**. 에서**이름 \***, 주의 사항**고유 ID**.

6. 제품정보**고급 설정** > **GOOGLE WORKSPACE ADMIN 관제사를 전망하십시오**, 그 후에 당신의 암호를 입력하십시오.

7. 사이드바에서, 선택**보안 보안** > **액세스 및 데이터 제어** > **API 제어**> 선택**맨션 DOMAIN WIDE DELEGATION**.

8. 제품정보**새소식**· 새로운 클라이언트 ID 추가:
   - **고객 ID**: 입력**고유 ID**당신은 주의했다.

   - **OAuth 범위**: 다음 URL을 입력하십시오:

     ```txt
     https://www.googleapis.com/auth/admin.directory.user.readonly, https://www.googleapis.com/auth/admin.directory.group.readonly, https://www.googleapis.com/auth/admin.directory.user.alias.readonly, https://www.googleapis.com/auth/gmail.labels, https://mail.google.com/
     ```

   - 제품정보**회사연혁**.

9. 사이드바로 돌아가기 >**서비스 계정**.

10. 3 점 선택 >**키 관리** > **ADD 키** > **새 키 만들기**> 선택**JSON 파일**> 선택**제품정보**. 이 다운로드`.json`나중에 사용하는 파일.

## 다음 단계

서비스 계정을 만들었을 때, 진행[retractions 추가](/email-security/deployment/api/setup/gsuite-bcc-setup/add-retraction/)당신의 이메일.

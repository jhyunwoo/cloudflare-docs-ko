## 새로운 위협을 위한 포스트 납품 retractions

이메일 보안 (이전 지역 1)은 지속적으로 피싱 캠페인에 대한 새로운 정보를 수집합니다. 사용자는 이메일 보안에 의해 스캔되었지만, 스캔 당시부터 처음에 철회되지 않았는지, 이러한 이메일 메시지는 위협으로 식별되지 않았습니다. 위험을 완화하려면 이메일 보안은 지식 Cloudflare를 기반으로 한 고정 시간 간격에서 이메일 메시지를 다시 평가하는 도구가 초기 배달 이후 취득 할 수 있습니다. 이 새로운 위협 지식에 맞는 모든 이메일 메시지가 철회됩니다.

두 가지 옵션을 사용할 수 있습니다:

- **포스트 납품 응답**: 이메일 보안은 이미 Cloudflare로 알려진 피싱 사이트 또는 캠페인에 대한 검색에 고정 시간 간격으로 사용자의 inboxes에 전달 된 이메일을 다시 평가하는 계속됩니다. 이 새로운 표준을 준수하는 이메일 메시지가 발견되면 이메일 보안이 거부됩니다.
- **Phish 제출 응답**: 이메일 보안은 이미 사용자가 피싱으로보고 된 이메일을 추적하고 이메일 보안에 의해 악의적 인 것으로 나타났습니다. Retraction는 당신의 윤곽에 따라 일어날 것입니다.

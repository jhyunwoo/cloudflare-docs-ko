## 사용자 역할

이메일 보안은 retraction 및 디렉토리 통합 목적으로 두 가지 역할을합니다.

- **Privileged 인증 관리자**: 이 역할의 사용자는 현재 인증 방법 정보를 볼 수 있으며, 글로벌 관리자를 포함한 모든 사용자의 비 패스워드 자격 증명을 설정하거나 재설정 할 수 있습니다. Privileged 인증 관리자는 기존 Non-password credentials (MFA 또는 FIDO와 같은)에 대한 재등록을 강제 할 수 있으며 수정`remember MFA on the device`모든 사용자의 다음 로그인에 MFA에 대한 메시지 프롬프트.
- **Privileged 역할 관리자**: 이 역할의 사용자는 Azure Active Directory의 역할 할당을 관리 할 수 있으며 Privileged Identity Management 내에서도 관리할 수 있습니다. 또한이 역할은 Privileged Identity Management의 모든 측면을 관리 할 수 있습니다.

Directory 통합은 위에서 언급 한 두 역할 모두의 사용을 요구합니다. 이메일 retraction는 단지 요구합니다**Privileged 역할 관리자**. 필요한 역할의 회원과 함께 모든 Azure 관리자는 이러한 허가를 수행 할 수 있습니다. 인증 프로세스는 Azure 환경에 이메일 보안 대시보드 액세스를 부여합니다. 이 액세스는 기능에 필요한 최소한의 적용 가능한 권한으로 수행됩니다.[아래 표](#azure-applications).

이메일 보안 등록자가 관리자 계정에 연결되지 않는 엔터프라이즈 응용 프로그램입니다. Azure Active Directory 관리자 센터에서 엔터프라이즈 애플리케이션 섹션에서 각 응용 프로그램에 부여 된 권한을 검토 할 수 있습니다. 더 알아보기[Application 관리 문서](https://learn.microsoft.com/en-us/azure/active-directory/manage-apps/)더 많은 정보.

## Microsoft Graph API 설정

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 내 계정**이메일 설정** > **도메인 및 루팅** > **이름 \***, 선택**새로운 도메인**.

4. 내 계정**이름 \***, onboard로 원하는 도메인을 입력하십시오.

5. 내 계정**메일 액세스**, 선택**접근성 준수**.

   <div class="medium-img">
     ![이메일 보안에 대한 올바른 권한을 부여하는 권한](~/assets/images/email-security/deployment/api-setup/ms-graph/step5.png)
   </div>

6. 새 탭에서 열리고 싶은 Office 365 계정을 선택하거나 자격 증명을 입력합니다.

7. 허가를 읽고, 선택**이름 \***&#xACC4;속. 이메일 보안 대시보드로 다시 이동합니다.

8. 내 계정**연락처**, 선택**접근성 준수**.

9. 새 탭에서 열리고 싶은 Office 365 계정을 선택하거나 자격 증명을 입력합니다.

10. 허가를 읽고, 선택**이름 \***&#xACC4;속. 이메일 보안 대시보드로 다시 이동합니다.

11. 내 계정**보호 범위**, 이메일 보안이 inbox 또는 모든 폴더 만 스캔해야하는 경우 선택. 모든 폴더를 스캔하는 것은 이메일이 자동으로 다른 폴더로 변환되는 상황을 위해 유용합니다.
    1. **Inbox 전용 보호**: 이메일 보안은 사용자의 inbox 만 스캔합니다.
    2. **모든 폴더를 보호**: 이메일 보안은 모든 비숨겨진 이메일 폴더를 스캔합니다.

12. 이제 두 가지 유형의 승인이 완료되었습니다.**도메인 게시**.

귀하의 허가 된 도메인이 표시됩니다.**이메일 설정** > **도메인 및 루팅** > **이름 \***, Office 365 및 이메일 보안 사이 디렉토리 동기화의 진행에 대한 메시지.

![이제 두 권한이 완료되어 Publish 도메인을 선택하십시오.](~/assets/images/email-security/deployment/api-setup/ms-graph/domain-sync-state.png)

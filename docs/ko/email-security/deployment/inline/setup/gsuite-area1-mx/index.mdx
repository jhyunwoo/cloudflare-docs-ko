## 2. Quarantine 악성 탐지

이 옵션 단계는 악성 메시지에 노출 된 사용자를 방지하는 것이 좋습니다.

메시지가 악성로 식별되면 이메일 보안이 X-header를 삽입합니다.`X-Area1Security-Disposition`해당 메시지<GlossaryTooltip term="disposition">관련 제품</GlossaryTooltip>. 값에 따라`X-Area1Security-Disposition`, 콘텐츠 준수 필터는 관리 quarantine에 악성 검출을 보낼 수 있습니다. 이 섹션은 다음을 수행해야합니다:

- 이메일 보안을 만들기 Malicious quarantine.
- 콘텐츠 준수 필터를 작성하여 악성 메시지를 quarantine에 보냅니다.

## 3. 이메일 보안에 도메인 추가

이메일 루프 오류를 방지하려면 이메일 보안 대시보드에 도메인을 추가하십시오.

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/home).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 내 계정**이메일 설정** > **이름 \***, 선택**새로운 도메인**.
4. 다음 설정을 입력하십시오:
   1. **이름 \***: 보안을 보호하기 위해 도메인을 입력합니다.
   2. **설정하기**: 선택**MX 기록**.
   3. **관련 제품**: 추가`google.com`.
   4. **Quarantine 정책**: 선택**인기있는**·**스낵 바**.
5. 제품정보**웹 사이트**.

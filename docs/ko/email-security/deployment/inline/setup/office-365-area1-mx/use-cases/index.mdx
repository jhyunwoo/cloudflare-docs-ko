우리의 사용 사례 튜토리얼을 따르기 전에, 가장 좋은 관행과 관련된 가이드를 읽으십시오. 이메일 보안 대시보드를 준비하고 태그와 같은 옵션을 활성화하는 방법을 보여줍니다.[연락처](/email-security/email-configuration/email-policies/link-actions/)또한,[이메일 링크 고립](/email-security/email-configuration/email-policies/link-actions/#email-link-isolation)Office 365를 설정하기 전에 .

1. 로그인하기[이메일 보안 (이전 지역 1) 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 오시는 길**이메일 설정** > **이메일 정책** > **링크 작업**.

4. 다음이 이점 또는 기업 고객 인 경우에 따라 달라집니다.
   1. 당신이라면**제품 정보**고객:

      1. 내 계정**분쟁 해결**, 선택**제품정보**.
      2. 내 계정`SUSPICIOUS`분해 드롭다운 메뉴, 행동을 변경`URL Defang`.

      <div class="large-img">
        ![Defang 의심스러운 이메일](~/assets/email-security/static/flexible-partial-images/o365-area1-mx/defang-suspicious.png)
      </div>

      3. 제품정보**Disposition 동작 저장**.

   2. 당신이라면**회사 소개**고객:

      1. 이름 \***이메일 링크 고립**.

      <div class="large-img">
        ![Enable Email Link 고립](~/assets/email-security/static/flexible-partial-images/o365-area1-mx/step4-enterprise-advantage-customer.png)
      </div>

5. 이름 \***이메일 정책**, 선택**텍스트 추가 기능**.

6. 제품정보**제품정보**.

7. 아래의 옵션 사용**Prefix에 추가하기**:

   - **인기있는**- 지원
   - **인기 있는**- 지원
   - **스낵 바**- 지원
   - **제품특징**- 지원
   - **뚱 베어**- 지원
   - **회사 외곽**- 옵션.
   - **암호화된 콘텐츠**- 옵션.
   - **제목 접두사**- 원하는 형식.

   <div class="large-img">
     ![단계 9에 언급 된 모든 옵션을 활성화](~/assets/images/email-security/deployment/inline-setup/o365-area1-mx/prefix-subject.png)
   </div>

8. 같은 창에서 스크롤하고 아래 옵션을 활성화**본문 바로가기**:

   - **인기있는**- 지원
   - **인기 있는**- 지원
   - **스낵 바**- 장애인
   - **제품특징**- 장애인
   - **뚱 베어**- 지원
   - **회사 외곽**- 옵션.
   - **몸 접두사**- 원하는 형식. 기본 설정을 사용할 수 있습니다. body prefix는 포맷을위한 HTML 태그를 지원합니다.

   <div class="large-img">
     ![단계 7에 언급 된 모든 옵션을 활성화](~/assets/images/email-security/deployment/inline-setup/o365-area1-mx/prefix-subject-enterprise.png)
   </div>

9. 제품정보**텍스트 추가 기능**.

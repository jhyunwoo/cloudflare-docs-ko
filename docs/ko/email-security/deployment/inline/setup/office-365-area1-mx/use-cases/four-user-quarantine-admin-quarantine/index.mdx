## 스팸 방지 정책

스팸 방지 정책을 구성하려면:

1. 자주 묻는 질문[Microsoft 365 수비수 콘솔](https://security.microsoft.com/)

2. 오시는 길**이메일 & 협력** > **정책 및 규칙**.

3. 제품정보**위협 정책**.

4. 이름 \***회사연혁**, 선택**안티 스팸**.

5. 선택하기**Anti-spam inbound 정책 (기본값)**&#xD14D;스트 (Checkbox 없음).

6. 내 계정**관련 기사**섹션, 스크롤 다운 및 선택**편집 작업**.

   <div class="large-img">
     ![행동으로 이동하고 편집 작업을 찾습니다.](~/assets/email-security/static/flexible-partial-images/o365-area1-mx/step6-edit-actions.png)
   </div>

7. 다음 조건과 행동을 설정하십시오 (당신은 스크롤하거나 찾을 필요가있을 수 있습니다) :

   - **스낵 바**: *Quarantine 메시지*.
     - **선택 quarantine 정책**: *사용자NotifyUserRelease*.
   - **높은 신뢰 스팸**: *Quarantine 메시지*.
     - **선택 quarantine 정책**: *사용자NotifyAdmin관련*.
   - **한국어**: *Quarantine 메시지*.
     - **선택 quarantine 정책**: *사용자NotifyAdmin관련*.
   - **높은 신뢰 phishing**: *Quarantine 메시지*.
     - **선택 quarantine 정책**: *사용자NotifyAdmin관련*.
   - **이 많은 일 동안 quarantine에 있는 스팸을 유지합니다**: 기본값은 15일입니다. 이메일 보안은 15-30 일을 권장합니다.

   <div class="large-img">
     ![위의 단계에서 스팸 작업을 선택하십시오.](~/assets/email-security/static/flexible-partial-images/o365-area1-mx/step7-quarantine-message-case4.png)
   </div>

8. 제품정보**제품 정보**.

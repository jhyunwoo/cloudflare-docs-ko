이메일 보안을 설정할 때 (이전 지역 1) 사용[inline 배포](/email-security/deployment/inline/), 당신은 이메일 보안의 egress IP 주소에서 메시지를 수신하는 기존 이메일 제공 업체를 알려야합니다.

참고 자료를 위한 이 페이지에 어떤 IP subnet 가면 범위든지에 Refer.

:::caution\[O365에 대한 추가 정보]

Office 365는 IPv6 주소와 다음과 같은 IPv4 서브넷 마스크 범위를 지원하지 않습니다.

- `104.30.32.0/19`
- `134.195.26.0/23`

Office 365를 사용한다면, 깨어난 것을 사용해야 합니다.`/24`subnet 가면 IP 주소. 더 알아보기[사무실 365`/24`이름 \*](#office-365-24-addresses)지원되는 IPv4 주소 목록.

:::

## 대한민국

미국에서 고객을 위해 다음 IP 주소를 입력하십시오.

### IPv4 지원

```txt
52.11.209.211
52.89.255.11
52.0.67.109
54.173.50.115
104.30.32.0/19
158.51.64.0/26
158.51.65.0/26
134.195.26.0/23
```

### IPv6를

```txt
2405:8100:c400::/38
```

## 유럽 연합 (EU)

유럽의 고객을 위해, 우리의 모든 IP 주소를 추가하십시오. 또한 유럽 데이터 센터의 다음 IP 주소를 추가해야합니다.

```txt
52.58.35.43
35.157.195.63
```

## 주요 특징

인도의 고객을 위해, 우리의 모든 IP 주소를 추가하십시오.

## 호주 / 뉴질랜드

호주와 뉴질랜드에 있는 고객을 위해, 우리의 미국 IP 주소를 전부 추가하십시오.

언제 이메일 보안 (이전 지역 1)은 예외<GlossaryTooltip term="phishing">피싱</GlossaryTooltip>위협 또는 이메일 서비스 불규칙성 행동 (파트너 또는 공급업체, 와이어 사기 전술상에서 전자 메일 서버 제공), 우리는 우리의 고객에게 도달하려고합니다.

구성 할 수있는 4 가지 유형의 접촉이 있습니다. 각 우선 유형 :

- **SOC 연락처**: P1 우선순위
- **삼키 정액**: P2 우선순위
- **In-Depth 항문**: P3 우선 순위.
- **회사연혁**: P4 우선 순위.

이메일 보안은 P1 수준 접촉에 도달하여 시작됩니다. 그들이 응답하지 않는 경우, 우리는 다음 우리가이 그룹 중 하나에서 응답을받을 때까지 다른 연락처에 도달하려고합니다.

옵트인 프로세스를 통해 이러한 특별 알림을 활성화할 수 있습니다:

1. 로그인하기[이메일 보안 (이전 지역 1) 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**이름 \*** > **Escalation 연락처**.
4. 제품정보**연락처**.
5. 양식을 작성합니다.
6. 제품정보**제품 정보**.

:::참조

자주 묻는 질문**긴 수명**, 접촉은 텍스트 및 / 또는 이메일 메시지를 보낼 것입니다. 구독을 확인하려면 링크를 선택해야합니다.

:::

이메일 보안을 설정하면[회사연혁](/email-security/partners/), 그 파트너의 계정은**이름 \***&#xACC4;정으로**이름 \***&#xACC4;정.

각 아이 계정은 부모의 계정으로 허용된 액세스 수준을 설정할 수 있습니다. 부모 계정에서 문제 해결 지원을 받으면이 설정을 업데이트 할 수 있습니다.

부모 권한을 업데이트하려면:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 오시는 길**대표 계정**.

4. 권한 수준을 선택하십시오:
   - **외부 계정 접근**: 부모 계정의 모든 액세스 차단 (이메일 보안 포함).
   - **외부 계정 보기만 허용**(과태): 부모가 설정 등 고객의 포털을 볼 수 있도록 허용합니다.
   - **외부 계정 Super Admin 액세스 허용**: 부모를 대신하여 고객 계정을 관리할 수 있습니다. 이 옵션을 선택함으로써 고객은 계정의 외부 관리에 대한 acknowledging 동의입니다.

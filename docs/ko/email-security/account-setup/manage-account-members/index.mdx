## 사용자 정의

사용자의 설정을 편집하려면:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**사용자 및 활동**.
4. 특정 사용자에, 선&#xD0DD;**...** > **제품정보**.
5. 필요한 정보를 업데이트하십시오.
6. 제품정보**사용자 정의**.

## 2단계 인증 재설정

사용자의 2단계 인증 (2FA)를 재설정하려면:

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).
2. 오시는 길**계정 설정**(장치 아이콘).
3. 오시는 길**사용자 및 활동**.
4. 특정 사용자에, 선&#xD0DD;**...** > **재설정 2FA**.

아래는 성공적으로 정체 공급자를 설정하는 일반적인 가이드입니다.<GlossaryTooltip term="SAML">사이트맵</GlossaryTooltip>. 이러한 옵션은 IDP(idP)에 따라 변경할 수 있습니다. 그러나 아래 또는 그와 동등한 옵션을 설정해야합니다.

## 1. ID 공급자 SAML 설치

1. SAML 공급자에 로그인하고 설정 섹션에 액세스하십시오.

2. IDP 공급자를 구성하려면 다음 값을 입력하십시오.
   |                              |                                                    |
   | ---------------------------- | -------------------------------------------------- |
   | **URL에 단일 기호**               | `https://horizon.area1security.com/api/users/saml` |
   | **Audience URI(SP 엔티티티 ID)** | `https://horizon.area1security.com`                |
   | **이름 ID 체재**                 | *이메일 주소*                                           |
   | **사용자 이름**                   | *이름 \**                                            |
   | **관련 기사**                    | *이름 \**                                            |
   | **Assertion 서명**             | *이름 \**                                            |
   | **서명 알고리즘**                  | *사이트맵*- 샤1                                         |
   | **Digest 알고리즘**              | *사이트맵*                                             |

3. 내 계정**법적 고지**, 응용 프로그램을 추가 사용자. 여기에 추가 이메일은 이메일 보안 대시보드에 이미 이메일을 일치해야합니다.

4. 설정 완료 후 IDP 메타데이터 파일을 다운로드하십시오. 복사 및 붙여넣기**메타데이터 XML**이메일 보안의 대시보드의 SSO 단면도에 있는 분야. 더 알아보기**단계 4**자세한 내용은 아래 가이드에서.

## 2. 이메일 보안 SAML 설정

SSO 공급자에 설정 한 후, 이메일 보안 대시보드로 로그인하여 설정을 완료하십시오.

1. 로그인하기[이메일 보안 (이전 지역 1) 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 내 계정**사용자 및 활동** > **사용자 및 권한**모든 권한 관리자의 이메일 주소를 추가합니다.

   ![공인 관리자를 채우기](~/assets/images/email-security/sso/generic/step3-users-actions.png)

4. 오시는 길**사이트맵**, 그리고 활성화**단일 로그인**.

   ![SSO 사용](~/assets/images/email-security/sso/generic/step4-sso.png)

5. 내 계정**SSO 강화**, 당신의 특정한 필요에 따라 조정의 한을 선택합니다:<Render file="sso-enforcement" product="email-security" />

6. 내 계정**SAML SSO 도메인**SSO 공급자에게 점이 있는 도메인을 입력하십시오.

7. 내 계정**메타데이터 XML**SAML XML 메타데이터 설정을 공급합니다. 이러한 설정(그리고 정확한 텍스트 설명)은 SSO 공급자에 따라 다른 위치에 있습니다.

8. 제품정보**업데이트 설정**설정 저장.

## 문제 해결

SAML 공급자를 이메일 보안에 연결해야 하는 경우 다음을 확인하십시오:

- SAML 공급자에서 구성한 사용자는 이메일 보안 대시보드에 존재합니다.
- 속성으로 이메일 주소를 사용하고 있습니다 (단계 2에서 참조)**이름 ID 체재**·**사용자 이름**).
- SHA-1 알고리즘을 사용합니다.
- 암호화는 2048 비트로 설정됩니다.

그렇지 않으면 Chrome 브라우저 디버그 로그를 활성화합니다. 그런 다음 SSO가 시작될 때 활동을 기록하고 접촉[Cloudflare 지원](/support/contacting-cloudflare-support/).

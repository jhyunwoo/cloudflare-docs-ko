## SAML 구성 옵션

- **Identity Provider(IDP 개시) SAML**: IDP-initiated configurations (Ookta 또는 OneLogin과 같은)는 IDP가 성공적으로 사용자를 인증하기 위해 이메일 보안 인프라에 액세스 할 수 있도록 요구합니다. 대부분의 기본 수준에서 사용자는 IDP에서 응용 프로그램을 선택합니다. 그런 다음 IDP는 이메일 보안 대시보드에 로그인하여 사용자 요청에 대한 정체 정보를 제공하기 위해 SAML assertion을 사용하여 이메일 보안과 통신합니다.
- **서비스 제공자 Initiated (SP 개시) SAML**: SP-initiated 구성은 가장 일반적인 SAML 인증 메커니즘입니다. IDP에 비해 주요 차이점은 서비스 제공 업체 (이메일 보안과 같은) 사용자가 인증하기 위해 IDP에 직접 연결이 필요하지 않습니다. 사용자의 브라우저는 SAML 교환 기능을 제공하지만 서비스 제공 업체 및 IDP는 서로 직접 통신하지 않습니다.

이메일 보안 (이전 지역 1)는 이 시점에서 IDP-initiated SAML 설정을 지원합니다.

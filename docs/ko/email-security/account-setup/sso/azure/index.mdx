이 튜토리얼은 Azure Active Directory 내 비 갤러리 엔터프라이즈 응용 프로그램을 구성하기위한 단계를 통해 수행됩니다.<GlossaryTooltip term="SAML">사이트맵</GlossaryTooltip>이메일 보안과 SSO 연결 (이전 지역 1).

## 1. Azure Active Directory 구성

1. [Azure 포털에 로그인](https://portal.azure.com/)관련 기사**Enterprise 응용**.

2. 제품정보**새로운 신청**.

   ![새 신청서 작성](~/assets/images/email-security/sso/azure/step2-new-app.png)

3. 제품정보**자주 묻는 질문**.

   ![자주 묻는 질문](~/assets/images/email-security/sso/azure/step3-create-your-own-app.png)

4. 앱의 descriptive 이름을 입력하고 선택**갤러리에서 찾을 수없는 다른 응용 프로그램을 통합 (Non-gallery)** > **이름 \***.

   ![당신의 응용 프로그램 descriptive 이름](~/assets/images/email-security/sso/azure/step4-name.png)

5. 신청하기**모델 번호: 개요**페이지를 열고, 선택**2. 단일 기호 설정**.

   ![앱 유형으로 단일 사인온을 선택하십시오.](~/assets/images/email-security/sso/azure/step5-sso.png)

6. 제품정보**사이트맵**단일 로그인 방법.

   ![SAML을 Sign-on 방법으로 선택](~/assets/images/email-security/sso/azure/step6-saml.png)

7. 연필 아이콘을 선택하여 편집**기본 SAML 구성**.

   ![Basic SAML Configuration을 편집하려면 연필 아이콘을 선택하십시오.](~/assets/images/email-security/sso/azure/step7-basic-saml.png)

8. 다음 설정 입력:

   |                                   |                                                    |
   | --------------------------------- | -------------------------------------------------- |
   | **ID (필수)**                       | `https://horizon.area1security.com`                |
   | **응답 URL (Assertion 소비자 봉사 URL)** | `https://horizon.area1security.com/api/users/saml` |
   | **로그인 URL**                       | 자주 묻는 질문                                           |
   | **릴레이 상태**                        | 자주 묻는 질문                                           |
   | **로그아웃 URL**                      | 자주 묻는 질문                                           |

9. 제품정보**제품 정보**교차 버튼**기본 SAML 구성**.

10. 연필 아이콘을 선택하여 편집**SAML 인증서**그리고 다음 변경 사항:

    - **결제 옵션**: 선택*SAML 응답*드롭다운 메뉴에서.
    - **Algorithm 소개**: 선택*사이트맵*드롭다운 메뉴에서.

    ![메뉴에서 표시 SAML 응답 및 SHA-1 선택](~/assets/images/email-security/sso/azure/step10-saml-signing-certificate.png)

11. 제품정보**제품 정보**교차 버튼**SAML 인증서**.

12. 아직도 에**SAML 인증서**섹션, 찾기**웹 사이트**선택하기**다운로드**. 당신은 이메일 안전 대시보드에 있는 SSO 윤곽을 위한 이 정보를 필요로 할 것입니다.

    ![Metadata XML 정보 다운로드](~/assets/images/email-security/sso/azure/step12-download.png)

Azure 구성이 완료되었습니다. 그것은 이것과 유사해야합니다 :

![Azure 구성은 이것과 유사해야 합니다.](~/assets/images/email-security/sso/azure/config-finished.png)

:::참조

이제 애플리케이션 구성이 완료되고 업데이트됩니다.**사용자 할당**·**신청 재산**공인 인력이 앱 카탈로그에서 새로운 응용 프로그램에 액세스 할 수 있도록해야합니다. 또한, 응용 로고 이미지 파일 또는 개인 정보 보호 정책 URL을 업데이트 할 수 있습니다.

## 2. Azure에 연결하는 이메일 보안 구성

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 내 계정**사용자 및 활동** > **사용자 및 권한**모든 권한 관리자의 이메일 주소를 추가합니다.

   ![공인 관리자를 채우기](~/assets/images/email-security/sso/generic/step3-users-actions.png)

4. 오시는 길**SSO 설정**, 그리고 활성화**단일 로그인**.

   ![SSO 사용](~/assets/images/email-security/sso/generic/step4-sso.png)

5. 내 계정**SSO 강화**, 당신의 특정한 필요에 따라 조정의 한을 선택하십시오:<Render file="sso-enforcement" product="email-security" />

6. 제품 정보**SAML SSO 도메인**, 입력`login.microsoftonline.com`.

7. 내 계정**메타데이터 XML**이전 단계에서 다운로드 한 XML 메타 데이터를 붙여 넣기 11. 모든 텍스트를 복사 할 텍스트 편집기로 다운로드 된 파일을 열 수 있습니다. 검색 결과를 찾을 수 없음 한국어 사전에 복사된 텍스트는 다음과 같습니다:

   ```txt
   <?xml version="1.0" encoding="utf-8"?><EntityDescriptor ID="_<YOUR_DESCRIPTOR_ID>" entityID="https://<YOUR_ENTITY_ID> " xmlns="urn:oasis:names:tc:SAML:2.0:metadata">...
   ```

8. 제품정보**업데이트 설정**설정 저장.

## 3. SSO 윤곽을 시험하십시오

Azure 및 이메일 보안 설정을 완료 한 후 SSO 액세스를 테스트 할 수 있습니다.
이 예에서 이메일 보안의 로고가 업데이트되었습니다.

:::참조
새로운 Azure AD 응용 프로그램의 사용자 할당 및 응용 속성이 업데이트되었는지 확인하여 공인 된 직원은 Office 365 / Azure 앱 카탈로그 페이지에서 새로운 응용 프로그램에 액세스 할 수 있습니다. 신청 로고 및 개인 정보 보호 정책 URL은 필요에 따라 업데이트 될 수 있습니다.
주요 특징

1. 로그인[Office 365 포털](https://portal.office.com).

2. 제품정보**모든 앱**.

3. 오시는 길**계정 설정** > **사이트맵**.

4. 이메일 보안 Horizon 애플리케이션을 찾습니다 (또는 귀하가 응용 프로그램을 준 한 이름), 이메일 보안으로 SSO 로그인을 시작하려면 선택하십시오.

5. 모든 것을 올바르게 구성하면 이메일 보안 포털에 로그인하고 대시보드로 리디렉션해야합니다.

## 문제 해결

Azure 계정을 이메일 보안에 연결해야 하는 경우 다음을 확인하십시오:

- 사용자는 이메일 보안 대시보드에 존재합니다.
- 더 보기**인증현황**·**응답 URL**Azure AD에서 올바른 (refer to**기본 SAML 구성**단계 7의[Azure Active Directory 구성](#1-azure-active-directory-configuration)).
- **SAML 응답**·**사이트맵**Azure AD에서 선택 (refer to**SAML 인증서**단계 9 의[Azure Active Directory 구성](#1-azure-active-directory-configuration)).
- SAML SSO 도메인은 이메일 보안 대시보드 (refer to step 6 in[Azure에 연결하는 이메일 보안 구성](#2-configure-email-security-to-connect-to-azure)).
- name ID 식별자는 설정**이메일 주소**.

그렇지 않으면 Chrome 브라우저 디버그 로그를 활성화합니다. 그런 다음 SSO가 시작될 때 활동을 기록하고 접촉[Cloudflare 지원](/support/contacting-cloudflare-support/).

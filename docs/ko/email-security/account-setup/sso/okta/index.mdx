이 튜토리얼에서는 이메일 보안 (이전 지역 1) 계정을 Okta에 연결하는 방법을 배울 것입니다. 단일 사인온 (SSO)이 올바르게 구성되면 공인 된 직원은 익숙한 사용자 이름과 암호를 사용하여 이메일 보안 대시보드에 연결할 수 있습니다.

## 1. Okta의 이메일 보안 앱 만들기

Okta의 이메일 보안 앱을 수동으로 만들 필요가 있습니다.

1. 로 로그인 Okta로 관리자.

2. 관리자 콘솔에서 이동**이름 \*** > **이름 \***.

   ![Okta Admin 콘솔에서 응용 프로그램으로 이동](~/assets/images/email-security/sso/okta/step2-applications.png)

3. 제품정보**App 통합 만들기** > **삼성 2.0**, 그리고 선택**이름 \***.

   ![SAML 2.0을 새로운 앱 통합 유형으로 선택하십시오.](~/assets/images/email-security/sso/okta/step3-saml.png)

4. 앱의 descriptive 이름을 입력해 주세요.`Email security`, 그리고 선택**이름 \***.

5. 다음 설정을 입력하십시오.**SAML 설정**:

   |                              |                                                                   |
   | ---------------------------- | ----------------------------------------------------------------- |
   | **URL에 단 하나 노래**             | `https://horizon.area1security.com/api/users/saml`                |
   | **Audience URI(SP 엔티티티 ID)** | `https://horizon.area1security.com/api/users/saml`                |
   | **이름 ID 체재**                 | 제품정보*이메일주소*드롭다운 메뉴에서.                                             |
   | **사용자 이름**                   | 제품정보*이름 \**&#xB4DC;롭다운 메뉴에서.                                      |
   | **관련 기사**                    | *이름 \**                                                           |
   | **Assertion 서명**             | *이름 \**                                                           |
   | **서명 알고리즘**                  | *사이트맵*                                                            |
   | **Digest 알고리즘**              | *사이트맵*                                                            |
   | **(선택 사항)**                  |                                                                   |
   | **이름 \***                    | 사용자의 이메일 주소를 입력하십시오. 이메일 보안 (이전 지역 1) 대시보드에 이미 추가된 사용자를 일치해야 합니다. |
   | **이름 형식**                    | 제품정보*제품정보*드롭다운 메뉴에서.                                              |
   | **제품정보**                     | 제품정보`user.email`드롭다운 메뉴에서.                                        |

   ![SAML 설정에서 올바른 설정을 입력](~/assets/images/email-security/sso/okta/step5-saml-settings.png)

6. 제품정보**이름 \***.

7. 이름 \***고객 또는 파트너입니까?**, 선택**내부 앱을 추가하는 Okta 고객입니다.**.

8. 내 계정**앱 유형**, 선택**이것은 우리가 만든 내부 응용 프로그램입니다**.

9. 제품정보**제품 정보**.

10. Okta는 방금 만든 앱을 표시해야합니다. 그렇지 않다면**이름 \*** > **이름 \***, 그것을 선택합니다.

11. 내 계정**이름 \***&#xD0ED;, 이동**SAML 설정 지침 보기**SAML 공급자 정보를 검색하려면

    ![보기 SAML 설정 지침 버튼 찾기](~/assets/images/email-security/sso/okta/step11-saml-instructions.png)

12. 복사 및 링크 저장**ID 공급자 단일 로그인 URL**. 나중에 이메일 보안 대시보드에서 사용해야합니다.

    ![이메일 보안 대시보드에서 나중에 사용하는 SSO URL 복사 및 저장](~/assets/images/email-security/sso/okta/step12-sso-url.png)

13. 기타 제품**옵션 정보**. 모든 XML 데이터를 복사하고 저장할 텍스트 상자를 확대해야 할 수도 있습니다. 이메일 보안 대시보드에서 구성을 완료하려면이 정보가 필요합니다. metadata의 시작은 다음과 같습니다.

    ```txt
    <?xml version="1.0" encoding="utf-8"?><EntityDescriptor ID="_<YOUR_DESCRIPTOR_ID>" entityID="https://<YOUR_ENTITY_ID> " xmlns="urn:oasis:names:tc:SAML:2.0:metadata">...
    ```

    ![이메일 보안 대시보드에서 나중에 사용하기 위해 XML 메타 데이터를 복사하고 저장하십시오](~/assets/images/email-security/sso/okta/step13-optional.png)

## 2. Okta에 연결하는 이메일 보안 구성

1. 로그인하기[이메일 보안 대시보드](https://horizon.area1security.com/).

2. 오시는 길**계정 설정**(장치 아이콘).

3. 내 계정**사용자 및 활동** > **사용자 및 권한**모든 권한 관리자의 이메일 주소를 추가합니다.

   ![공인 관리자를 채우기](~/assets/images/email-security/sso/generic/step3-users-actions.png)

4. 오시는 길**SSO 설정**설정하기**단일 로그인**스위치.

   ![SSO 사용](~/assets/images/email-security/sso/generic/step4-sso.png)

5. 내 계정**SSO 강화**, 당신의 특정한 필요에 따라 조정의 한을 선택하십시오:<Render file="sso-enforcement" product="email-security" />

6. 내 계정**SAML SSO 도메인**단계 13에서 저장된 도메인을 입력하십시오. 예를 들어,`area1security-examplecorp.okta.com`.

7. 내 계정**메타데이터 XML**단계 14에서 저장된 XML 메타 데이터를 붙여 넣으십시오.

8. 제품정보**업데이트 설정**설정 저장.

고객 포털 세션에서 로그아웃. Okta 계정은 이제 이메일 보안 타일을 표시해야합니다 (이전 지역 1).

## 추가 세부 정보

<div id="new-users-per-minute"></div>

### 분당 신규 사용자

`new users per minute`를 구성할 때 이 값은 **매분 추가되는 사용자 수**가 아닙니다.

대신 이것은 매분 허용되는 사용자 수의 임계값이며(`total active users` 이하), 사용자가 꼭 필요할 때만 대기되도록 예상 피크 트래픽의 100%로 설정해야 합니다.

<div id="session-duration"></div>

### 세션 지속 시간

세션 지속 시간은 두 가지 방식으로 사용자 경험을 개선합니다.

첫째, 방문자가 같은 작업을 위해 대기실을 두 번 통과하지 않도록 막아 줍니다. 예를 들어 방문자가 `example.com`에서 구매를 하려고 할 수 있습니다. `example.com`에는 트래픽이 많기 때문에 방문자는 온라인 스토어에 들어가기 전에 대기실에서 기다립니다. 시간이 지나 대기실을 벗어나 온라인 스토어에 들어가고, 구매를 완료한 뒤 사이트를 떠납니다.

하지만 주문에 메모를 추가하는 것을 잊었거나 영수증을 요청해야 할 수도 있습니다. [세션 쿠키](/waiting-room/reference/waiting-room-cookie/)가 아직 유효하다면(`session duration`으로 지정한 시간 동안), 사용자는 다시 대기열에 서지 않고 애플리케이션에 재진입할 수 있습니다.

둘째, 세션 지속 시간은 대기실이 애플리케이션으로부터의 동적 유출량을 만들 수 있게 해 줍니다(동적 유입량에 더해). 사용자의 세션 쿠키는 일정 시간 동안 활동이 없으면 만료되므로, 자리가 생기는 즉시 새로운 슬롯을 열 수 있고 예상 대기 시간도 더 낮고 더 정확해집니다.

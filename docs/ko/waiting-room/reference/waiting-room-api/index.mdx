Cloudflare Waiting Room은 트래픽이 많은 웹 페이지에 접근하려는 방문자를 가상 대기실로 리디렉션합니다.

[Cloudflare Waiting Room API](/api/resources/waiting_rooms/methods/list/)는 대기실을 프로그래밍 방식으로 관리할 수 있는 인터페이스를 제공합니다.

## 요청 URL 형식

[Cloudflare Waiting Room API](/api/resources/waiting_rooms/methods/list/) 작업을 호출하려면 엔드포인트를 Cloudflare API 기본 URL 뒤에 붙입니다.

```shell
https://api.cloudflare.com/client/v4
```

인증 방법은 Cloudflare API 문서의 [Getting Started: Requests](/fundamentals/api/)를 참고하세요.

엔드포인트와 페이지네이션에 대한 도움말은 [Getting Started: Endpoints](/fundamentals/api/)를 참고하세요.

## 대기실 관리

| 작업 | Method + URL stub | 참고 |
| --- | --- | --- |
| [대기실 목록 조회](/api/resources/waiting_rooms/methods/list/) | `GET zones/{:zone_identifier}/waiting_rooms` | zone의 모든 대기실을 나열합니다. |
| [대기실 생성](/api/resources/waiting_rooms/methods/create/) | `POST zones/{:zone_identifier}/waiting_rooms` | 대기실을 만듭니다. |
| [대기실 상세 정보](/api/resources/waiting_rooms/methods/get/) | `GET zones/{:zone_identifier}/waiting_rooms/{:identifier}` | 대기실 하나를 가져옵니다. |
| [대기실 업데이트](/api/resources/waiting_rooms/methods/update/) | `PUT zones/{:zone_identifier}/waiting_rooms/{:identifier}` | 대기실을 업데이트합니다. |
| [대기실 삭제](/api/resources/waiting_rooms/methods/delete/) | `DELETE zones/{:zone_identifier}/waiting_rooms/{:identifier}` | 대기실을 삭제합니다. |
| [대기실 패치](/api/resources/waiting_rooms/methods/edit/) | `PATCH zones/{:zone_identifier}/waiting_rooms/{:identifier}` | 구성된 대기실을 부분 수정합니다. |

## 대기실의 현재 상태 가져오기

| 작업 | Method + URL stub | 참고 |
| --- | --- | --- |
| [대기실의 현재 상태 가져오기](/api/resources/waiting_rooms/subresources/statuses/methods/get/) | `GET zones/{:zone_identifier}/waiting_rooms/{:identifier}/status` | <ul><li>대기열이 활성화되어 있으면(클라이언트가 대기실로 들어가면) <code>queueing</code>을 반환합니다.</li><li>대기열이 활성화되어 있지 않거나 대기실이 일시 중지되었으면 <code>not\_queueing</code>을 반환합니다.</li></ul> |

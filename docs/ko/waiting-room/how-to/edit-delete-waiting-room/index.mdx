대기실은 [Waiting Room 대시보드](/waiting-room/how-to/waiting-room-dashboard/) 또는 [API](/waiting-room/reference/waiting-room-api/)를 사용해 관리할 수 있습니다.

:::note
활성 대기실 업데이트에 대한 자세한 내용은 [모범 사례](/waiting-room/reference/best-practices/)를 참고하세요.
:::

## 대시보드 사용

### 대기실 수정

1. 애플리케이션에서 **Traffic** > **Waiting Room**으로 이동합니다.
2. 레코드에서 **Edit**를 선택합니다.
3. **Settings**를 선택합니다.
4. 설정을 수정합니다. 각 설정 설명은 [구성 설정](/waiting-room/reference/configuration-settings/)을 참고하세요.
5. **Next**를 선택합니다. [사용자 지정 템플릿](/waiting-room/how-to/customize-waiting-room/)에 접근할 수 있다면 템플릿도 조정할 수 있습니다.
6. **Review** 단계에 도달하면 **Save**를 선택합니다.

### 대기실 삭제

1. 애플리케이션에서 **Traffic** > **Waiting Room**으로 이동합니다.
2. 레코드에서 **Delete**를 선택합니다.
3. 다시 **Delete**를 선택합니다.

## API 사용

### 대기실 수정

구성된 대기실을 [교체](/api/resources/waiting_rooms/methods/update/)하려면 다음 엔드포인트를 Cloudflare API 기본 URL 뒤에 붙입니다.

<APIRequest
  path="/zones/{zone_id}/waiting_rooms/{waiting_room_id}"
  method="PUT"
  json={{
    name: "webshop-waiting-room",
    host: "example.com",
    new_users_per_minute: 200,
    total_active_users: 300
  }}
/>

구성된 대기실을 [업데이트](/api/resources/waiting_rooms/methods/edit/)하려면 다음 엔드포인트를 Cloudflare API 기본 URL 뒤에 붙입니다.

<APIRequest
  path="/zones/{zone_id}/waiting_rooms/{waiting_room_id}"
  method="PATCH"
  json={{
    name: "webshop-waiting-room",
    host: "example.com",
    new_users_per_minute: 200,
    total_active_users: 300
  }}
/>

PATCH 요청 payload에는 업데이트하려는 필드만 포함하면 됩니다.

### 대기실 삭제

[Waiting Room API](/api/resources/waiting_rooms/methods/delete/)에서 다음 엔드포인트를 Cloudflare API 기본 URL 뒤에 붙여 대기실을 삭제합니다.

<APIRequest
  path="/zones/{zone_id}/waiting_rooms/{waiting_room_id}"
  method="DELETE"
/>

대기실은 대시보드 또는 API를 통해 사용자 지정할 수 있습니다.

## 대시보드에서 대기실 사용자 지정

대기실의 모양을 디자인하고 미리 보려면 **Create waiting room** 페이지에서 **Customization** 탭을 선택하세요.

Cloudflare는 대기실 모양을 사용자 지정할 수 있는 다음 옵션을 제공합니다.

* [기본 대기실](#default-waiting-room): 방문자에게 예상 대기 시간을 표시하는 브랜드 없는 기본 대기실입니다.
  * 기본 대기실 페이지의 언어를 선택할 수 있습니다. 지원 언어는 영어, 아랍어, 독일어, 스페인어, 프랑스어, 인도네시아어, 이탈리아어, 일본어, 한국어, 네덜란드어, 폴란드어, 포르투갈어(브라질), 터키어, 중국어(간체/번체)입니다.
* [커스텀 대기실](#custom-waiting-room): 템플릿 텍스트를 수정하거나 직접 HTML 코드를 만들 수 있습니다.
  * HTML과 CSS 내용을 모두 사용자 지정할 수 있으며, 글꼴, 색상, 정적 이미지, 추가 언어 등을 포함할 수 있습니다.
  * 대시보드에서 직접 내용을 편집하거나 관련 파일을 가져올 수 있습니다.
* [JSON 친화적 대기실 응답 반환](/waiting-room/how-to/json-response/): 사용자의 대기실 상태를 담은 JSON 응답도 함께 활성화하는 토글입니다.

<div id="default-waiting-room"></div>

### 기본 대기실

브랜드 없는 기본 대기실을 선택하려면 다음과 같이 하세요.

1. 대기실을 선택합니다.
2. **Customization** 단계로 이동합니다.
3. **Default waiting room**을 선택합니다.
4. 대기실 기본 페이지의 언어를 선택합니다.

<div id="custom-waiting-room"></div>

### 커스텀 대기실

:::note
일부 고객만 대기실을 사용자 지정할 수 있습니다. 자세한 내용은 [요금제](/waiting-room/plans/) 페이지를 참고하세요.
:::

대기실을 사용자 지정하려면 다음과 같이 하세요.

1. 대기실을 선택합니다.
2. **Customization** 단계로 이동합니다.
3. **Custom waiting room**을 선택합니다.

텍스트 상자에서 HTML 코드를 직접 편집할 수 있습니다.

* **Download default template**를 선택하면 기본 템플릿 내용이 들어 있는 HTML 파일을 컴퓨터로 다운로드합니다.
* **Download**를 선택하면 현재 텍스트 상자 내용이 들어 있는 HTML 파일을 컴퓨터로 다운로드합니다.
* **Copy**를 선택하면 텍스트 상자의 내용을 클립보드에 복사한 뒤 원하는 편집기에 붙여넣을 수 있습니다.

템플릿 텍스트에는 [대기 시간 표시 코드](#display-wait-time)가 포함되어 있습니다. 방문자에게 예상 대기 시간을 표시하려면 이 내용을 삭제하지 마세요.

#### HTML 파일 업로드

1. **Import**를 선택해 컴퓨터에서 HTML 파일을 업로드합니다.
2. 대화 상자에서 파일을 선택하고 **Open**을 선택합니다. HTML 파일 크기 제한은 1,048,576바이트(1MB)입니다.

이후 텍스트 상자에서 추가 편집을 진행하세요. 대기실 페이지에 예상 대기 시간을 표시하려면 [대기 시간 표시 코드](#display-wait-time)를 포함하거나, [사용 가능한 변수](#available-variables)를 이용해 완전히 새로운 커스텀 페이지를 만들 수 있습니다.

<div id="display-wait-time"></div>

#### 대기 시간 표시

템플릿 HTML 코드의 `<main>` 섹션에 있는 다음 내용은 대기 시간을 표시합니다.

```html
<h2 id="time-remaining">
  <noscript>
    {{#waitTimeKnown}}Your estimated wait time is {{waitTimeFormatted}}...{{/waitTimeKnown}}
    {{^waitTimeKnown}}{{#queueIsFull}}The estimated wait time is greater than a day. You will
    automatically be placed in the queue once space is available.{{/queueIsFull}}
    {{^queueIsFull}}Your estimated wait time is unavailable.{{/queueIsFull}}{{/waitTimeKnown}}
  </noscript>
</h2>
```

`<body>` 섹션에서 `<main>` 뒤에 있는 다음 스크립트는 대기 시간을 가져옵니다.

```html
<script type="text/javascript">
  var remainingEl = document.getElementById('time-remaining');
  var waitTime = {{waitTime}};
  var waitTimeKnown = {{waitTimeKnown}};

  var remainingString = 'Your estimated wait time is ';

  if (!waitTimeKnown) {
    remainingString += 'unavailable.'
  } else {
    if (waitTime === 1) {
      remainingString += waitTime + ' minute...';
    } else {
      remainingString += waitTime + ' minutes...';
    }
  }

  remainingEl.innerText = remainingString;
</script>
```

#### Turnstile 변수

사용자 지정 대기실에서 Turnstile을 사용하려면 `turnstile` 변수가 추가되어 있는지 확인해야 합니다. 기본 대기열 페이지 템플릿과 새로 생성한 커스텀 템플릿에는 이미 이 변수가 포함되어 있습니다. 기존 커스텀 HTML 템플릿에서 Turnstile 통합을 활성화하려면 템플릿 어딘가에 `{{{turnstile}}}`를 추가해 Waiting Room이 위젯을 배치할 위치를 알 수 있도록 해야 합니다. Waiting Room은 Mustache 템플릿을 사용하므로, 템플릿 안에 raw HTML을 escape 없이 포함하려면 중괄호 두 개가 아니라 세 개를 사용해야 합니다.

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Waiting Room</title>
  </head>
  <body>
    <h1>You are currently in the queue.</h1>
    {{#waitTimeKnown}}
      <h2>Your estimated wait time is {{waitTimeFormatted}}.</h2>
    {{/waitTimeKnown}}
    {{^waitTimeKnown}}
      <h2>Your estimated wait time is unknown.</h2>
    {{/waitTimeKnown}}
    {{#turnstile}}
      <!-- for a managed (and potentially interactive) challenge, you may want to instruct the user to complete the challenge -->
      <p>Please complete this challenge so we know you're a human:</p>
      {{{turnstile}}} <!-- include the turnstile widget -->
    {{/turnstile}}
  </body>
</html>
```

Infinite Queue를 사용할 때는, 특히 managed challenge처럼 사용자 상호작용이 있을 수 있는 경우, 사용자가 challenge를 완료하기 전까지는 대기열에 들어가지 않는다는 점을 안내하는 것이 좋습니다.

<div id="available-variables"></div>

#### 사용 가능한 변수

커스텀 HTML로 대기실을 만들면 응답을 사용자 지정하기 위한 여러 변수에 접근할 수 있습니다. 전체 변수 목록은 [Cloudflare API 문서](/api/resources/waiting_rooms/methods/create/)의 `json_response_enabled` 파라미터를 참고하세요.

#### 다국어 지원

사용자 지정 가능한 대기실은 UTF-8 문자 집합이 지원하는 모든 언어 텍스트를 표시할 수 있습니다. 예상 대기 시간을 표시하려면 사용자 언어와 무관하게 `waitTime`, `waitTimeHours` 같은 숫자 변수를 대기실 템플릿 안에서 사용할 수 있습니다. 다만 현재 시점에는 다음 변수만 영어로 제공됩니다: `waitTimeFormatted`, `timeUntilEventStartFormatted`, `timeUntilEventEndFormatted`.

경로나 서브도메인에 따라 서로 다른 언어를 표시하고 싶다면 커스텀 HTML에 JavaScript 코드를 추가할 수 있습니다. 아래에는 시작점으로 활용할 수 있는 예시 템플릿이 있습니다.

* 경로(path)에 따라 다른 언어를 표시하려면 이 [template](/waiting-room/static/index.path.html.txt)을 다운로드하세요. 이 템플릿은 경로에 `en`이 포함되면 영어(또는 기본값), `jp`가 포함되면 일본어, `fr`이 포함되면 프랑스어, `es`가 포함되면 스페인어를 표시합니다.

* 서브도메인에 따라 다른 언어를 표시하려면 이 [template](/waiting-room/static/index.subdomain.html.txt)을 다운로드하세요. 이 템플릿은 기본값 또는 서브도메인에 `en`이 포함되면 영어, `jp`가 포함되면 일본어, `fr`이 포함되면 프랑스어, `es`가 포함되면 스페인어를 표시합니다.

이 두 템플릿 중 하나를 내려받은 뒤 원하는 방식으로 자유롭게 수정하세요. 사용자의 사이트 언어 선택 구조에 맞게 path 또는 subdomain 로직을 업데이트하면 됩니다. 각 locale의 `translations` 객체에 번역을 추가해 다른 언어도 포함할 수 있습니다.

#### 리소스 호스팅

이미지나 기타 리소스를 사용자 지정 대기실에서 사용하는 경우, **반드시** 대기실이 적용되는 host명 위에 해당 자산을 호스팅하지 마세요. 그렇지 않으면 이 자산에 대한 요청이 대기실을 통과하지 못합니다.

### 대기실 미리 보기

대기실의 모양을 미리 보려면 다음과 같이 하세요.

1. 애플리케이션에서 **Traffic** > **Waiting Room**으로 이동합니다.
2. [대기실을 새로 만들거나](/waiting-room/how-to/create-waiting-room/) [기존 대기실을 편집](/waiting-room/how-to/edit-delete-waiting-room/)합니다.
3. **Review** 단계로 이동합니다.
4. **Preview waiting room**을 선택합니다.

* **Queueing**을 선택하면 대시보드에서 대기실이 활성화되어 있고 **Queue-all**이 비활성화된 상태의 모습을 볼 수 있습니다.
* **Queue-All**을 선택하면 대시보드에서 대기실이 활성화되어 있고 **Queue-all**도 활성화된 상태의 모습을 볼 수 있습니다. **Queue-all**이 활성화되면 예상 대기 시간은 표시되지 않습니다.

### 문제 해결

대기실을 미리 볼 때 예상치 못한 동작이 보이면 커스텀 코드의 문법이 올바른지 확인하세요. 흔한 실수로는 태그를 해당 닫는 태그(태그 이름 앞에 `/`가 붙은 형태)로 제대로 닫지 않는 경우가 있습니다.

## API를 통한 대기실 사용자 지정

Waiting Room API를 사용하면 방문자가 가상 대기실에 배치되었을 때 제공되는 웹 페이지를 사용자 지정할 수 있습니다.

다음 `PATCH` 요청에서 `custom_page_html` 필드는 [사용자 지정된 대기실](/waiting-room/how-to/customize-waiting-room/)의 HTML 코드를 담고 있습니다.

<APIRequest
  path="/zones/{zone_id}/waiting_rooms/{waiting_room_id}"
  method="PATCH"
  json={{
    name: "webshop-waiting-room",
    host: "example.com",
    new_users_per_minute: 200,
    total_active_users: 300,
    custom_page_html: "<p>Include custom HTML here</p>"
  }}
/>

응답:

```json
{
  "success": true,
  "errors": [],
  "messages": [],
  "result": [
    {
      "id": "1111111111111111111111",
      "name": "webshop-waiting-room",
      "description": "Waiting room for webshop",
      "host": "example.com",
      "path": "/shop",
      "suspended": false,
      "queue_all": false,
      "new_users_per_minute": 200,
      "total_active_users": 300,
      "session_duration": 1,
      "disable_session_renewal": false,
      "json_response_enabled": false,
      "queueing_method": "FIFO",
      "cookie_attributes": {
        "samesite": "auto",
        "secure": "auto"
      },
      "custom_page_html": "<p>Include custom HTML here</p>",
      "created_on": "2014-01-01T05:20:00.12345Z",
      "modified_on": "2014-01-01T05:20:00.12345Z"
    }
  ]
}
```

### 사용자 지정 대기실 HTML 코드 미리 보기

API 요청으로 사용자 지정 HTML을 설정하기 전에, preview 엔드포인트에 업로드해 커스텀 HTML을 미리 확인할 수 있습니다.

```txt
POST https://api.cloudflare.com/client/v4/zones/{zone_id}/waiting_rooms/preview
```

요청 본문에는 `custom_html` 필드에 커스텀 HTML 내용을 포함하세요.

```json
{
  "custom_html": "<p>Include custom HTML here</p>"
}
```

preview 엔드포인트에는 `custom_html` 필드로 HTML을 전달하지만, 실제로 Waiting Room을 구성할 때는 API에서 `custom_page_html` 필드로 HTML을 전달한다는 점에 유의하세요.

예시 요청:

<APIRequest
  path="/zones/{zone_id}/waiting_rooms/preview"
  method="POST"
  json={{
    custom_html: "<p>Include custom HTML here</p>"
  }}
/>

preview 엔드포인트는 응답 본문에 임시 URL을 반환하며, 이 링크로 커스텀 페이지를 미리 볼 수 있습니다.

```json
{
  "result": {
    "preview_url": "https://waitingrooms.dev/preview/111111111111"
  },
  "success": true,
  "errors": [],
  "messages": []
}
```

Cloudflare 계정이 없어도 preview 링크에 접근할 수 있으므로 여러 기기에서 대기실 웹페이지를 검증할 수 있습니다.

### 기본 또는 현재 대기실 웹 페이지 미리 보기

[preview URL 생성](/api/resources/waiting_rooms/subresources/page/methods/preview/) 후 다음 엔드포인트를 사용하면 현재 대기실에 구성된 웹 페이지 또는 커스텀 페이지가 없을 경우 기본 페이지를 미리 볼 수 있는 링크를 생성할 수 있습니다.

```txt
GET https://waitingrooms.dev/preview/{preview_id}
```

응답의 링크는 [mustache](https://mustache.github.io)로 렌더링된 `custom_page_html` 필드 내용을 표시합니다.

모든 트래픽이 강제로 대기되는 상황을 미리 보려면 선택적 `force_queue` 쿼리 파라미터를 사용하세요.

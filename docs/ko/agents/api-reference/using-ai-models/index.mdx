## AI 모델 호출

HTTP 요청을 사용하여 에이전트 내에서 어떤 방법으로 모델을 호출 할 수 있습니다.[`onRequest`](/agents/api-reference/agents-api/)핸들러, 때[자주 묻는 질문](/agents/api-reference/schedule-tasks/)실행할 때 WebSocket 메시지 처리[`onMessage`](/agents/api-reference/websockets/)핸들러 또는 자신의 방법 중 하나에서.

에이전트는 자신의 AI 모델을 호출 할 수 있습니다 — 자율적으로 — 그리고 충분히에 응답하는 분 (또는 더 긴)을 처리 할 수 있습니다. 클라이언트가 중류를 차단하면 에이전트가 실행을 유지하고 재연결 할 때 클라이언트를 잡을 수 있습니다.

### WebSockets에서 스트리밍{/* long-running-model-requests */}

현대 reasoning 모형은 둘 다 응답을 생성하기 위하여 몇몇 시간을 가지고 갈 수 있습니&#xB2E4;*·*&#xD074;라이언트에 응답을 돌려줍니다. 전체 응답을 버퍼의 대신, 당신은 그것을 뒤로 돌릴 수 있습니다[웹소켓](/agents/api-reference/websockets/).

<TypeScriptExample filename="src/index.ts">
  ```ts
  import { Agent } from "agents";
  import { streamText } from "ai";
  import { createWorkersAI } from "workers-ai-provider";

  interface Env {
  	AI: Ai;
  }

  export class MyAgent extends Agent<Env> {
  	async onConnect(connection: Connection, ctx: ConnectionContext) {
  		//
  	}

  	async onMessage(connection: Connection, message: WSMessage) {
  		let msg = JSON.parse(message);
  		await this.queryReasoningModel(connection, msg.prompt);
  	}

  	async queryReasoningModel(connection: Connection, userPrompt: string) {
  		try {
  			const workersai = createWorkersAI({ binding: this.env.AI });
  			const result = streamText({
  				model: workersai("@cf/zai-org/glm-4.7-flash"),
  				prompt: userPrompt,
  			});

  			for await (const chunk of result.textStream) {
  				if (chunk) {
  					connection.send(JSON.stringify({ type: "chunk", content: chunk }));
  				}
  			}

  			connection.send(JSON.stringify({ type: "done" }));
  		} catch (error) {
  			connection.send(JSON.stringify({ type: "error", error: error }));
  		}
  	}
  }
  ```
</TypeScriptExample>

당신은 또한 persist AI 모형 응답 뒤로 할 수 있습니다[에이전트 상태](/agents/api-reference/store-and-sync-state/)이름 \*`this.setState`. 사용자가 분리되면 메시지 기록을 다시 읽고 사용자가 다시 연결하면 전송합니다.

## \`Workers AI\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`

사용 가능[\`Workers AI\`에서 사용할 수있는 모델 중 하나](/workers-ai/models/)당신의 대리인 안에[바인딩 설정](/workers-ai/configuration/bindings/). API 키가 필요하지 않습니다.

\`Workers AI\`는 설정하여 스트리밍 응답을 지원합니다.`stream: true`. 더 큰 모형 또는 reasoning 모형을 위해 완충기와 지연 응답을 피하기 위하여 스트리밍을 사용하십시오.

<TypeScriptExample filename="src/index.ts">
  ```ts
  import { Agent } from "agents";

  interface Env {
  	AI: Ai;
  }

  export class MyAgent extends Agent<Env> {
  	async onRequest(request: Request) {
  		const stream = await this.env.AI.run(
  			"@cf/deepseek-ai/deepseek-r1-distill-qwen-32b",
  			{
  				prompt: "Build me a Cloudflare Worker that returns JSON.",
  				stream: true,
  			},
  		);

  		return new Response(stream, {
  			headers: { "content-type": "text/event-stream" },
  		});
  	}
  }
  ```
</TypeScriptExample>

### 모형 routing

사용 가능[AI 게이트웨이](/ai-gateway/)직접 에이전트에서 지정하여[`gateway`제품 설명](/ai-gateway/usage/providers/workersai/)AI 바인딩을 호출 할 때. 모델 라우팅은 가용성, 속도 제한, 비용 예산을 기반으로 제공 업체 전반에 걸쳐 요청을 추적 할 수 있습니다.

<TypeScriptExample filename="src/index.ts">
  ```ts
  import { Agent } from "agents";

  interface Env {
  	AI: Ai;
  }

  export class MyAgent extends Agent<Env> {
  	async onRequest(request: Request) {
  		const response = await this.env.AI.run(
  			"@cf/deepseek-ai/deepseek-r1-distill-qwen-32b",
  			{
  				prompt: "Build me a Cloudflare Worker that returns JSON.",
  			},
  			{
  				gateway: {
  					id: "{gateway_id}",
  					skipCache: false,
  					cacheTtl: 3360,
  				},
  			},
  		);

  		return Response.json(response);
  	}
  }
  ```
</TypeScriptExample>

더 보기`ai`Wrangler 설정에서 바인딩은 \`Workers AI\`와 AI Gateway를 통해 공유됩니다.

<WranglerConfig>
  ```jsonc
  {
  	"ai": {
  		"binding": "AI",
  	},
  }
  ```
</WranglerConfig>

자주 묻는 질문[AI Gateway 문서](/ai-gateway/)게이트웨이를 구성하고 게이트웨이 ID를 검색하는 방법을 배울 수 있습니다.

## AI SDK 지원

더 보기[AI SDK 지원](https://sdk.vercel.ai/docs/introduction)텍스트 생성, 도구 호출, 구조화된 응답 등을 위한 통합 API를 제공합니다. 'Workers' AI'를 통해 AI SDK 어댑터를 가지고 있는 모든 공급자와 함께 작동합니다.[`workers-ai-provider`](https://www.npmjs.com/package/workers-ai-provider).

<PackageManagers pkg="ai workers-ai-provider" />

<TypeScriptExample filename="src/index.ts">
  ```ts
  import { Agent } from "agents";
  import { generateText } from "ai";
  import { createWorkersAI } from "workers-ai-provider";

  interface Env {
  	AI: Ai;
  }

  export class MyAgent extends Agent<Env> {
  	async onRequest(request: Request): Promise<Response> {
  		const workersai = createWorkersAI({ binding: this.env.AI });
  		const { text } = await generateText({
  			model: workersai("@cf/zai-org/glm-4.7-flash"),
  			prompt: "Build me an AI agent on Cloudflare Workers",
  		});

  		return Response.json({ modelResponse: text });
  	}
  }
  ```
</TypeScriptExample>

OpenAI, Anthropic 또는 기타 AI SDK 호환 어댑터를 사용하여 공급자를 교환 할 수 있습니다.

## OpenAI 호환 엔드포인트

에이전트는 OpenAI API를 지원하는 모든 서비스에서 모델을 호출할 수 있습니다. 예를 들어, OpenAI SDK를 사용하여 호출할 수 있습니다.[Google의 Gemini 모델](https://ai.google.dev/gemini-api/docs/openai#node.js)당신의 대리인에서 직접.

Agents는 Server-Sent Events (SSE)를 사용하여 HTTP에 대한 응답을 스트림 할 수 있습니다.`onRequest`핸들러 또는 네이티브를 사용하여[웹소켓 API](/agents/api-reference/websockets/)클라이언트로 다시 스트림 응답.

<TypeScriptExample filename="src/index.ts">
  ```ts
  import { Agent } from "agents";
  import { OpenAI } from "openai";

  export class MyAgent extends Agent {
  	async onRequest(request: Request): Promise<Response> {
  		const client = new OpenAI({
  			apiKey: this.env.GEMINI_API_KEY,
  			baseURL: "https://generativelanguage.googleapis.com/v1beta/openai/",
  		});

  		let { readable, writable } = new TransformStream();
  		let writer = writable.getWriter();
  		const textEncoder = new TextEncoder();

  		this.ctx.waitUntil(
  			(async () => {
  				const stream = await client.chat.completions.create({
  					model: "gemini-2.0-flash",
  					messages: [
  						{ role: "user", content: "Write me a Cloudflare Worker." },
  					],
  					stream: true,
  				});

  				for await (const part of stream) {
  					writer.write(
  						textEncoder.encode(part.choices[0]?.delta?.content || ""),
  					);
  				}
  				writer.close();
  			})(),
  		);

  		return new Response(readable);
  	}
  }
  ```
</TypeScriptExample>

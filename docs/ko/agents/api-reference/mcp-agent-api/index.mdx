Cloudflare에서 MCP Server를 구축하면 확장됩니다.[`McpAgent`한국어](https://github.com/cloudflare/agents/blob/main/packages/agents/src/mcp.ts), Agents SDK에서:

<TypeScriptExample>
  ```ts title="src/index.ts"
  import { McpAgent } from "agents/mcp";
  import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
  import { z } from "zod";

  export class MyMCP extends McpAgent {
  	server = new McpServer({ name: "Demo", version: "1.0.0" });

  	async init() {
  		this.server.tool(
  			"add",
  			{ a: z.number(), b: z.number() },
  			async ({ a, b }) => ({
  				content: [{ type: "text", text: String(a + b) }],
  			}),
  		);
  	}
  }
  ```
</TypeScriptExample>

MCP 서버의 각 인스턴스가 자체의 튼튼한 상태가 있음을 의미합니다.[튼튼한 목표](/durable-objects/), 그 자신과[SQL 데이터베이스](/agents/api-reference/store-and-sync-state).

MCP 서버는 반드시 대리인이어야 합니다. MCP 서버를 구축할 수 있습니다.[회사 소개](/agents/model-context-protocol/tools)MCP 서버로`@modelcontextprotocol/sdk`패키지.

그러나 MCP 서버를 원하는 경우:

- 이전 도구 호출을 기억하고, 제공된 응답
- MCP 클라이언트에게 게임을 제공, 게임 보드의 상태를 기억, 이전 이동, 및 점수
- 이전 외부 API 호출의 상태를 캐시하므로 이후 도구 호출은 재사용 할 수 있습니다.
- 에이전트가 할 수있는 것은 아무것도 할 수 있지만 MCP 클라이언트가 그것을 통신 할 수 있습니다

아래 API를 사용할 수 있습니다.

## API 개요

| 재산/Method                       | 이름 \*                   |
| ------------------------------- | ----------------------- |
| `state`                         | 현재 상태 객체(persisted)     |
| `initialState`                  | 인스턴스가 시작될 때 기본값 상태      |
| `setState(state)`               | 업데이트 및 지속 상태            |
| `onStateChanged(state)`         | 국가 변경 시                 |
| `sql`                           | 임베디드 데이터베이스에서 SQL 쿼리 실행 |
| `server`                        | 더 보기`McpServer`도구 등록    |
| `props`                         | OAuth 인증의 사용자 정체성과 토큰   |
| `elicitInput(options, context)` | 사용자의 구조 입력              |
| `McpAgent.serve(path, options)` | Worker 핸들러를 만드는 정체되는 방법 |

## McpAgent.serve()로 배포

더 보기`McpAgent.serve()`정적 방법은 MCP 서버에 요청하는 Worker 핸들러를 만듭니다.

<TypeScriptExample>
  ```ts
  import { McpAgent } from "agents/mcp";
  import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
  import { z } from "zod";

  export class MyMCP extends McpAgent {
  	server = new McpServer({ name: "my-server", version: "1.0.0" });

  	async init() {
  		this.server.tool("square", { n: z.number() }, async ({ n }) => ({
  			content: [{ type: "text", text: String(n * n) }],
  		}));
  	}
  }

  //Worker 핸들러 수출
  export default MyMCP.serve("/mcp");
  ```
</TypeScriptExample>

이것은 MCP 서버를 배포하는 가장 간단한 방법입니다 — 약 15 코드의 줄. 더 보기`serve()`메소드는 Streamable HTTP 전송을 자동으로 처리합니다.

### OAuth 인증

사용시[OAuth 공급자 도서관](https://github.com/cloudflare/workers-oauth-provider)MCP 서버에 전달`apiHandlers`:

<TypeScriptExample>
  ```ts
  import { OAuthProvider } from "@cloudflare/workers-oauth-provider";

  export default new OAuthProvider({
  	apiHandlers: { "/mcp": MyMCP.serve("/mcp") },
  	authorizeEndpoint: "/authorize",
  	tokenEndpoint: "/token",
  	clientRegistrationEndpoint: "/register",
  	defaultHandler: AuthHandler,
  });
  ```
</TypeScriptExample>

## 데이터 관할권

GDPR 및 데이터 residency 준수를 위해 MCP 서버 인스턴스가 특정 지역에서 실행되도록 관할권을 지정하십시오.

<TypeScriptExample>
  ```ts
  //GDPR 준수 EU 관할
  export default MyMCP.serve("/mcp", { jurisdiction: "eu" });
  ```
</TypeScriptExample>

OAuth로:

<TypeScriptExample>
  ```ts
  export default new OAuthProvider({
  	apiHandlers: {
  		"/mcp": MyMCP.serve("/mcp", { jurisdiction: "eu" }),
  	},
  	//... 다른 OAuth 구성
  });
  ```
</TypeScriptExample>

지정할 때`jurisdiction: "eu"`:

- 모든 MCP 세션 데이터는 EU 내에서 유지
- 귀하의 도구에 의해 처리 된 사용자 데이터는 EU에 남아
- 튼튼한 개체에 저장된 상태는 EU에 있습니다

사용 가능한 관할 구역`"eu"`(유럽 연합) 및`"fedramp"`(FedRAMP 준수 위치). 더 알아보기[Durable Objects 데이터 위치](/durable-objects/reference/data-location/)더 많은 옵션.

## Hibernation 지원

`McpAgent`인스턴스 자동 지원[웹소켓 Hibernation](/durable-objects/best-practices/websockets/#websocket-hibernation-api)MCP 서버가 해당 상태를 보존하면서 비활성 기간 동안 잠을 수 있도록 합니다. 이 에이전트는 적극적으로 요청 처리, 풀 컨텍스트 및 대화 기록을 유지하면서 비용을 최적화 할 때만 계산 리소스를 사용합니다.

Hibernation는 기본적으로 활성화되며 추가 구성이 필요하지 않습니다.

## 인증 및 인증

McpAgent 클래스는 완벽하게 통합되어 있습니다.[OAuth 공급자 도서관](https://github.com/cloudflare/workers-oauth-provider)제품 정보[인증 및 인증](/agents/model-context-protocol/authorization/).

사용자가 MCP 서버로 인증되면, ID 정보와 토큰을 통해 사용할 수 있습니다.`props`매개 변수, 당신을 허용:

- 사용자별 데이터
- 작업 수행하기 전에 사용자 권한 확인
- 사용자 속성에 따라 응답을 사용자 정의
- 인증 토큰을 사용하여 사용자를 대신하여 외부 서비스에 요청하기

## 국가 동기화 API

더 보기`McpAgent`클래스는 전체 액세스[에이전트 상태 API](/agents/api-reference/store-and-sync-state/):

- [`state`](/agents/api-reference/store-and-sync-state/)— 현재 지속된 상태
- [`initialState`](/agents/api-reference/store-and-sync-state/#set-the-initial-state-for-an-agent)— 인스턴스가 시작될 때 기본 상태
- [`setState`](/agents/api-reference/store-and-sync-state/)— 업데이트 및 지속 상태
- [`onStateChanged`](/agents/api-reference/store-and-sync-state/#synchronizing-state)— React 상태 변경
- [`sql`](/agents/api-reference/agents-api/#sql-api)- 임베디드 데이터베이스에서 SQL 쿼리 실행

:::노트\[ 세션 종료 후 재시작]
현재 각 클라이언트 세션은 인스턴스에 의해 백업됩니다.`McpAgent`수업. 이것은 당신을 위해 자동적으로 취급됩니다, 에서 보이는 것과 같이[자주 묻는 질문](/agents/guides/remote-mcp-server). 동일한 클라이언트가 재연결될 때, 그들은 새로운 회의를 시작하고, 국가는 재시동할 것입니다.
주요 특징

예를 들어, 다음과 같은 코드는 MCP 서버를 구현하여 카운터 값을 기억하고 카운터를 업데이트합니다.`add`도구는 호출 :

<TypeScriptExample>
  ```ts title="src/index.ts"
  import { McpAgent } from "agents/mcp";
  import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
  import { z } from "zod";

  type State = { counter: number };

  export class MyMCP extends McpAgent<Env, State, {}> {
  	server = new McpServer({
  		name: "Demo",
  		version: "1.0.0",
  	});

  	initialState: State = {
  		counter: 1,
  	};

  	async init() {
  		this.server.resource(`counter`, `mcp://resource/counter`, (uri) => {
  			return {
  				contents: [{ uri: uri.href, text: String(this.state.counter) }],
  			};
  		});

  		this.server.tool(
  			"add",
  			"Add to the counter, stored in the MCP",
  			{ a: z.number() },
  			async ({ a }) => {
  				this.setState({ ...this.state, counter: this.state.counter + a });

  				return {
  					content: [
  						{
  							type: "text",
  							text: String(`Added ${a}, total is now ${this.state.counter}`),
  						},
  					],
  				};
  			},
  		);
  	}

  	onStateChanged(state: State) {
  		console.log({ stateUpdate: state });
  	}
  }
  ```
</TypeScriptExample>

## Elicitation (인형 루프)

MCP 서버는 도구 실행 중에 추가 사용자 입력을 요청할 수 있습니다.**한국어**. MCP 클라이언트 (클래드 데스크톱과 같은) JSON Schema를 기반으로 한 양식을 렌더링하고 사용자의 응답을 반환합니다.

### elicitation을 사용할 때

- 원래 도구 호출의 일부가 아닌 구조 입력
- 진행하기 전에 high-stake 작업 확인
- 추가 컨텍스트 또는 p참고 자료s mid-execution

### `elicitInput(options, context)`

도구 실행 중에 사용자의 구조 입력을 요청합니다.

**모수:**

| 제품 설명                      | 제품정보    | 이름 \*                         |
| -------------------------- | ------- | ----------------------------- |
| `options.message`          | 이름 \*   | 입력이 필요한지 설명하는 메시지             |
| `options.requestedSchema`  | JSON 슈마 | 예상 입력 구조를 정의하는 Schema         |
| `context.relatedRequestId` | 이름 \*   | 더 보기`extra.requestId`도구 핸들러에서 |

**반환:** `Promise<{ action: "accept" | "decline", content?: object }>`

<TypeScriptExample>
  ```ts
  import { McpAgent } from "agents/mcp";
  import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
  import { z } from "zod";

  type State = { counter: number };

  export class CounterMCP extends McpAgent<Env, State, {}> {
  	server = new McpServer({
  		name: "counter-server",
  		version: "1.0.0",
  	});

  	initialState: State = { counter: 0 };

  	async init() {
  		this.server.tool(
  			"increase-counter",
  			"Increase the counter by a user-specified amount",
  			{ confirm: z.boolean().describe("Do you want to increase the counter?") },
  			async ({ confirm }, extra) => {
  				if (!confirm) {
  					return { content: [{ type: "text", text: "Cancelled." }] };
  				}

  				//사용자에서 추가 입력 요청
  				const userInput = await this.server.server.elicitInput(
  					{
  						message: "By how much do you want to increase the counter?",
  						requestedSchema: {
  							type: "object",
  							properties: {
  								amount: {
  									type: "number",
  									title: "Amount",
  									description: "The amount to increase the counter by",
  								},
  							},
  							required: ["amount"],
  						},
  					},
  					{ relatedRequestId: extra.requestId },
  				);

  				//자주 묻는 질문
  				if (userInput.action !== "accept" || !userInput.content) {
  					return { content: [{ type: "text", text: "Cancelled." }] };
  				}

  				//입력을 사용하십시오
  				const amount = Number(userInput.content.amount);
  				this.setState({
  					...this.state,
  					counter: this.state.counter + amount,
  				});

  				return {
  					content: [
  						{
  							type: "text",
  							text: `Counter increased by ${amount}, now at ${this.state.counter}`,
  						},
  					],
  				};
  			},
  		);
  	}
  }
  ```
</TypeScriptExample>

### 형식의 JSON Schema

더 보기`requestedSchema`사용자에 표시된 형태 구조를 정의합니다:

```ts
const schema = {
	type: "object",
	properties: {
		//텍스트 입력
		name: {
			type: "string",
			title: "Name",
			description: "Enter your name",
		},
		//번호 입력
		amount: {
			type: "number",
			title: "Amount",
			minimum: 1,
			maximum: 100,
		},
		//Boolean (체크 박스)
		confirm: {
			type: "boolean",
			title: "I confirm this action",
		},
		//Enum (떨림)
		priority: {
			type: "string",
			enum: ["low", "medium", "high"],
			title: "Priority",
		},
	},
	required: ["name", "amount"],
};
```

### 처리 응답

<TypeScriptExample>
  ```ts
  const result = await this.server.server.elicitInput(
  	{ message: "Confirm action", requestedSchema: schema },
  	{ relatedRequestId: extra.requestId },
  );

  switch (result.action) {
  	case "accept":
  		//사용자가 양식을 제출
  		const { name, amount } = result.content as { name: string; amount: number };
  		//입력을 처리 ...
  		break;

  	case "decline":
  		//사용자 취소
  		return { content: [{ type: "text", text: "Operation cancelled." }] };
  }
  ```
</TypeScriptExample>

:::note\[MCP 클라이언트 지원]
Elicitation은 MCP 클라이언트 지원을 요구합니다. 모든 MCP 클라이언트는 elicitation 기능을 실행하지 않습니다. 호환성에 대한 클라이언트 문서 확인.
주요 특징

작업 흐름 기반 승인을 포함한 더 많은 인간 루프 패턴을 위해, 참조[인간에서 루프 패턴](/agents/guides/human-in-the-loop/).

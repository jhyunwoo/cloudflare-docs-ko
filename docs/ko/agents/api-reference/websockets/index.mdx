에이전트는 실시간 WebSocket 연결을 지원, 양방향 통신. 이 페이지는 서버 측 WebSocket 취급을 포함합니다. 클라이언트 측 연결을 위해, 참조하십시오[클라이언트 SDK](/agents/api-reference/client-sdk/).

## Lifecycle 걸이

대리인에는 다른 점에 불이 있는 몇몇 lifecycle 걸이가 있습니다:

| 기타 제품                                         | 호출시                           |
| --------------------------------------------- | ----------------------------- |
| `onStart(props?)`                             | 에이전트가 처음 시작되면 (모든 연결을 위해)     |
| `onRequest(request)`                          | HTTP 요청이 수신되면 (non-WebSocket) |
| `onConnect(connection, ctx)`                  | 새로운 WebSocket 연결이 설치되면        |
| `onMessage(connection, message)`              | WebSocket 메시지가 수신되면           |
| `onClose(connection, code, reason, wasClean)` | WebSocket 연결이 닫을 때            |
| `onError(connection, error)`                  | WebSocket 오류가 발생하면            |

### `onStart`

`onStart()`대리인이 처음 시작될 때 한 번 호출됩니다, 어떤 연결든지 설치하기 전에:

<TypeScriptExample>
  ```ts
  export class MyAgent extends Agent {
  	async onStart() {
  		//자원 초기화
  		console.log(`Agent ${this.name} starting...`);

  		//로드 데이터 저장
  		const savedData = this.sql`SELECT * FROM cache`;
  		for (const row of savedData) {
  			//persistent 저장에서 in-memory 국가를 재건
  		}
  	}

  	onConnect(connection: Connection) {
  		//시간 연결이 도착하면 onStart가 완료되었습니다.
  	}
  }
  ```
</TypeScriptExample>

## 관련 링크

수정하기`onConnect`·`onMessage`WebSocket 연결을 수락하는 에이전트의 방법 :

<TypeScriptExample>
  ```ts
  import { Agent, Connection, ConnectionContext, WSMessage } from "agents";

  export class ChatAgent extends Agent {
  	async onConnect(connection: Connection, ctx: ConnectionContext) {
  		//연결은 자동으로 허용됩니다.
  		//auth, headers, 쿠키에 대한 원래 요청 접근
  		const url = new URL(ctx.request.url);
  		const token = url.searchParams.get("token");

  		if (!token) {
  			connection.close(4001, "Unauthorized");
  			return;
  		}

  		//이 연결에 대한 사용자 정보
  		connection.setState({ authenticated: true });
  	}

  	async onMessage(connection: Connection, message: WSMessage) {
  		if (typeof message === "string") {
  			//본문내용 바로가기
  			const data = JSON.parse(message);
  			connection.send(JSON.stringify({ received: data }));
  		}
  	}
  }
  ```
</TypeScriptExample>

## 연결 객체

각 연결된 클라이언트는 독특합니다`Connection`객체:

| 재산/Method               | 제품정보     | 이름 \*                |
| ----------------------- | -------- | -------------------- |
| `id`                    | `string` | 이 연결에 대한 고유 식별자      |
| `state`                 | `State`  | Per-connection 상태 객체 |
| `setState(state)`       | `void`   | 연결 상태 업데이트           |
| `send(message)`         | `void`   | 메시지 보내기              |
| `close(code?, reason?)` | `void`   | 연결 닫기                |

### Per 연결 상태

각 연결에 특정한 저장 자료 (사용자 정보, p참고 자료, 등):

<TypeScriptExample>
  ```ts
  interface ConnectionState {
  	userId: string;
  	role: "admin" | "user";
  	joinedAt: number;
  }

  export class ChatAgent extends Agent {
  	async onConnect(
  		connection: Connection<ConnectionState>,
  		ctx: ConnectionContext,
  	) {
  		const userId = new URL(ctx.request.url).searchParams.get("userId");

  		connection.setState({
  			userId: userId || "anonymous",
  			role: "user",
  			joinedAt: Date.now(),
  		});
  	}

  	async onMessage(connection: Connection<ConnectionState>, message: WSMessage) {
  		//액세스 연결 별 상태
  		console.log(`Message from ${connection.state.userId}`);
  	}
  }
  ```
</TypeScriptExample>

## 모든 고객에게 방송

제품 정보`this.broadcast()`모든 연결된 클라이언트에게 메시지를 보내려면:

<TypeScriptExample>
  ```ts
  export class ChatAgent extends Agent {
  	async onMessage(connection: Connection, message: WSMessage) {
  		//모든 연결 클라이언트에 방송
  		this.broadcast(
  			JSON.stringify({
  				from: connection.id,
  				message: message,
  				timestamp: Date.now(),
  			}),
  		);
  	}

  	//어떤 방법에서 방송
  	async notifyAll(event: string, data: unknown) {
  		this.broadcast(JSON.stringify({ event, data }));
  	}
  }
  ```
</TypeScriptExample>

### Excluding 연결

방송에서 제외되는 연결 ID의 배열을 통과:

<TypeScriptExample>
  ```ts
  //sender를 제외한 모든 사람에게 방송
  this.broadcast(
  	JSON.stringify({ type: "user-typing", userId: "123" }),
  	[connection.id], //시작자에게 보내지 마십시오.
  );
  ```
</TypeScriptExample>

## 연결 태그

쉽게 필터링을위한 태그 연결. 관련 제품`getConnectionTags()`연결이 설치된 경우 태그를 할당하려면:

<TypeScriptExample>
  ```ts
  export class ChatAgent extends Agent {
  	getConnectionTags(connection: Connection, ctx: ConnectionContext): string[] {
  		const url = new URL(ctx.request.url);
  		const role = url.searchParams.get("role");

  		const tags: string[] = [];
  		if (role === "admin") tags.push("admin");
  		if (role === "moderator") tags.push("moderator");

  		return tags; //9개까지 꼬리표, 각각 최대 256개의 숯
  	}

  	//나중에, admins에서만 방송
  	notifyAdmins(message: string) {
  		for (const conn of this.getConnections("admin")) {
  			conn.send(message);
  		}
  	}
  }
  ```
</TypeScriptExample>

### 연결 관리 방법

| 제품 설명               | 주요특징                                      | 이름 \*            |
| ------------------- | ----------------------------------------- | ---------------- |
| `getConnections`    | `(tag?: string) => Iterable<Connection>`  | 태그로 선택된 모든 연결 얻기 |
| `getConnection`     | `(id: string) => Connection \| undefined` | ID로 연결하기         |
| `getConnectionTags` | `(connection, ctx) => string[]`           | 태그 연결            |
| `broadcast`         | `(message, without?: string[]) => void`   | 모든 연결            |

## 이진 데이터 처리

메시지는 문자열 또는 바이너리가 될 수 있습니다 (`ArrayBuffer` / `ArrayBufferView`):

<TypeScriptExample>
  ```ts
  export class FileAgent extends Agent {
  	async onMessage(connection: Connection, message: WSMessage) {
  		if (message instanceof ArrayBuffer) {
  			//핸들 바이너리 업로드
  			const bytes = new Uint8Array(message);
  			await this.processFile(bytes);
  			connection.send(
  				JSON.stringify({ status: "received", size: bytes.length }),
  			);
  		} else if (typeof message === "string") {
  			//핸들 텍스트 명령
  			const command = JSON.parse(message);
  			//· ...
  		}
  	}
  }
  ```
</TypeScriptExample>

:::참조
에이전트는 JSON 텍스트 프레임 (identity, state, MCP 서버)을 각 연결에 자동으로 보냅니다. 클라이언트가 바이너리 데이터를 처리하고 이러한 프레임을 처리 할 수없는 경우, 사용[`shouldSendProtocolMessages`](/agents/api-reference/protocol-messages/)그들을 억제하기 위해.

## 오류 및 닫기 처리

연결 오류 및 차단 처리 :

<TypeScriptExample>
  ```ts
  export class ChatAgent extends Agent {
  	async onError(connection: Connection, error: unknown) {
  		console.error(`Connection ${connection.id} error:`, error);
  		//이 연결에 대한 모든 리소스를 정리
  	}

  	async onClose(
  		connection: Connection,
  		code: number,
  		reason: string,
  		wasClean: boolean,
  	) {
  		console.log(`Connection ${connection.id} closed: ${code} ${reason}`);

  		//다른 클라이언트
  		this.broadcast(
  			JSON.stringify({
  				event: "user-left",
  				userId: connection.state?.userId,
  			}),
  		);
  	}
  }
  ```
</TypeScriptExample>

## 이름 \*

| 제품정보              | 이름 \*             |
| ----------------- | ----------------- |
| `string`          | 텍스트 메시지 (일반 JSON) |
| `ArrayBuffer`     | Binary 데이터        |
| `ArrayBufferView` | 바이너리 데이터의 종류      |

## 채용 정보

에이전트 지원 hibernation - 그들은 필요할 때 불편하고 깨질 때 잠을 수 있습니다. WebSocket 연결을 유지하면서 리소스를 저장합니다.

### 훈훈훈증

Hibernation는 기본적으로 활성화됩니다. 비활성화:

<TypeScriptExample>
  ```ts
  export class AlwaysOnAgent extends Agent {
  	static options = { hibernate: false };
  }
  ```
</TypeScriptExample>

### 어떻게 hibernation 작품

1. 에이전트는 활성, 처리 연결
2. 메시지가없는 inactivity의 기간 후에, 대리인 hibernates (잠자는)
3. WebSocket 연결이 열려 있음(Cloudflare\`)
4. 메시지가 도착하면 에이전트가 일어나
5. `onMessage`정상적인 호출

### hibernation의 어떤 persists

| 관심상품                    | 지속되지 않음       |
| ----------------------- | ------------- |
| `this.state`(시약국)       | In-memory 변수  |
| `connection.state`      | 타이머/intervals |
| SQLite 데이터 (`this.sql`) | 비행의 약속        |
| 연결 metadata             | 지역 캐시         |

중요한 데이터 저장`this.state`또는 SQLite, 클래스 속성에:

<TypeScriptExample>
  ```ts
  export class MyAgent extends Agent<Env, { counter: number }> {
  	initialState = { counter: 0 };

  	//이 작업을 수행하지 마십시오 - hibernation에 손실
  	private localCounter = 0;

  	onMessage(connection: Connection, message: WSMessage) {
  		//수련을 통해
  		this.setState({ counter: this.state.counter + 1 });

  		//hibernation 후 분실
  		this.localCounter++;
  	}
  }
  ```
</TypeScriptExample>

## 일반적인 본

### 사전 추적

per-connection state를 사용하는 온라인 추적. 연결 상태는 사용자가 차단할 때 자동으로 청소됩니다:

<TypeScriptExample>
  ```ts
  type UserState = {
  	name: string;
  	joinedAt: number;
  	lastSeen: number;
  };

  export class PresenceAgent extends Agent {
  	onConnect(connection: Connection<UserState>, ctx: ConnectionContext) {
  		const url = new URL(ctx.request.url);
  		const name = url.searchParams.get("name") || "Anonymous";

  		connection.setState({
  			name,
  			joinedAt: Date.now(),
  			lastSeen: Date.now(),
  		});

  		//새로운 사용자에 현재 존재를 전송
  		connection.send(
  			JSON.stringify({
  				type: "presence",
  				users: this.getPresence(),
  			}),
  		);

  		//누군가가 가입한 다른 사람
  		this.broadcastPresence();
  	}

  	onClose(connection: Connection) {
  		//수동 정리 필요 없음 - 연결 상태는 자동적으로 사라집니다
  		this.broadcastPresence();
  	}

  	onMessage(connection: Connection<UserState>, message: WSMessage) {
  		if (message === "ping") {
  			connection.setState((prev) => ({
  				...prev!,
  				lastSeen: Date.now(),
  			}));
  			connection.send("pong");
  		}
  	}

  	private getPresence() {
  		const users: Record<string, { name: string; lastSeen: number }> = {};
  		for (const conn of this.getConnections<UserState>()) {
  			if (conn.state) {
  				users[conn.id] = {
  					name: conn.state.name,
  					lastSeen: conn.state.lastSeen,
  				};
  			}
  		}
  		return users;
  	}

  	private broadcastPresence() {
  		this.broadcast(
  			JSON.stringify({
  				type: "presence",
  				users: this.getPresence(),
  			}),
  		);
  	}
  }
  ```
</TypeScriptExample>

### 채팅 룸

<TypeScriptExample>
  ```ts
  type Message = {
  	type: "message" | "join" | "leave";
  	user: string;
  	text?: string;
  	timestamp: number;
  };

  export class ChatRoom extends Agent {
  	onConnect(connection: Connection, ctx: ConnectionContext) {
  		const url = new URL(ctx.request.url);
  		const username = url.searchParams.get("username") || "Anonymous";

  		connection.setState({ username });

  		//다른 사람
  		this.broadcast(
  			JSON.stringify({
  				type: "join",
  				user: username,
  				timestamp: Date.now(),
  			} satisfies Message),
  			[connection.id], //회원가입을 하지 마세요.
  		);
  	}

  	onMessage(connection: Connection, message: WSMessage) {
  		if (typeof message !== "string") return;

  		const { username } = connection.state as { username: string };

  		this.broadcast(
  			JSON.stringify({
  				type: "message",
  				user: username,
  				text: message,
  				timestamp: Date.now(),
  			} satisfies Message),
  		);
  	}

  	onClose(connection: Connection) {
  		const { username } = (connection.state as { username: string }) || {};
  		if (username) {
  			this.broadcast(
  				JSON.stringify({
  					type: "leave",
  					user: username,
  					timestamp: Date.now(),
  				} satisfies Message),
  			);
  		}
  	}
  }
  ```
</TypeScriptExample>

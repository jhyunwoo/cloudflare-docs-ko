Cloudflare는 고객의 OAuth를 사용하여 연결할 수있는 관리 된 원격 MCP 서버 카탈로그를 실행[이름 \*](https://modelcontextprotocol.io/quickstart/user), [윈드 서핑](https://docs.windsurf.com/windsurf/cascade/mcp), 우리의 자신[AI 놀이터](https://playground.ai.cloudflare.com/)또는 어떤[MCP를 지원하는 SDK](https://github.com/cloudflare/agents/tree/main/packages/agents/src/mcp).

이 MCP 서버는 귀하의 계정, 프로세스 정보에서 구성을 읽을 수 있도록 MCP 클라이언트를 허용하고 데이터를 기반으로 제안을 만들고, 그 제안 된 변경 사항을 만들 수 있습니다. 이러한 모든 작업은 애플리케이션 개발, 보안 및 성능을 포함하여 'Cloudflare'의 많은 서비스를 통해 발생할 수 있습니다. 그들은 모두 지원`streamable-http`수송 via`/mcp`그리고`sse`수송 (deprecated) 통해`/sse`.

## Cloudflare API MCP 서버

더 보기[Cloudflare API MCP 서버](https://github.com/cloudflare/mcp)전체 액세스[Cloudflare API](/api/)— 이상 2,500 DNS의 엔드 포인트, Workers,R2,Zero Trust,그리고 모든 다른 제품 —을 통해 단지 두 도구:`search()`·`execute()`.

그것은 사용[비밀번호](/agents/api-reference/codemode/), 모델이 OpenAPI spec의 typed 표현에 대해 JavaScript를 작성하는 기법과 'Cloudflare\` API 클라이언트, 오히려 각 엔드포인트에 대한 개별 도구 정의를로드하는 것보다. 생성된 코드는 격리된 내부에서 실행됩니다.[동적인 노동자](/workers/runtime-apis/bindings/worker-loader/)샌드박스.

이 접근법은 많은 API 엔드포인트가 존재하는지에 관계없이 약 1,000개의 토큰을 사용합니다. 기본 도구로 모든 엔드포인트를 노출하는 동등한 MCP 서버는 1 백만 개 이상의 토큰을 소비합니다. - 대부분의 기초 모델의 전체 컨텍스트 창보다 더 많은.

| 계정 관리                  | 회사 소개 | 토큰 비용       |
| ---------------------- | ----- | ----------- |
| MCP (전체 스키마)           | 2,594 | \~1,170,000 |
| 기본 MCP (필요한 params 전용) | 2,594 | \~244,000   |
| 비밀번호                   | 2     | \~1,000     |

### Cloudflare API MCP 서버 연결

MCP 클라이언트에 다음 구성을 추가:

```json
{
	"mcpServers": {
		"cloudflare-api": {
			"url": "https://mcp.cloudflare.com/mcp"
		}
	}
}
```

연결할 때, OAuth를 통해 승인하고 에이전트에게 권한을 부여하기 위해 Cloudflare로 리디렉션됩니다.

CI/CD 또는 자동화를 위해, 당신은 창조할 수 있습니다[Cloudflare API 토큰](https://dash.cloudflare.com/profile/api-tokens)필요한 권한과 곰기 토큰으로 전달`Authorization`헤더. 사용자 토큰과 계정 토큰 모두 지원됩니다.

더 많은 정보를 원하시면, 참조[Cloudflare MCP 저장소](https://github.com/cloudflare/mcp).

### 에이전트 및 IDE 플러그인을 통해 설치

당신은 설치할 수 있습니다[Cloudflare Skills 플러그인](https://github.com/cloudflare/skills), Cloudflare MCP 서버가 Cloudflare에 구축을 위한 컨텍스트 기술 및 슬래시 명령을 따라 묶습니다. 플러그인은 Claude Code, OpenCode, OpenAI Codex 및 Pi를 포함한 에이전트 스킬 표준을 지원하는 에이전트와 함께 작동합니다.

#### Claude 코드

설치하기[플러그인 마켓](https://code.claude.com/docs/en/discover-plugins#add-from-github):

```txt
/plugin marketplace add cloudflare/skills
```

#### 커서

설치하기**Cursor 마켓**, 또는 수동으로 추가**계정 설정** > **이름 \*** > **추가 규칙** > **원격 규칙 (Github)**&#xC774;름 \*`cloudflare/skills`.

#### npx 기술

설치하기[`npx skills`](https://skills.sh)클립:

```sh
npx skills add https://github.com/cloudflare/skills
```

#### Clone 또는 사본

외계인[클라우드 플레어/스킬](https://github.com/cloudflare/skills)저장소 및 기술 폴더를 에이전트에 적합한 디렉토리에 복사:

| 이름 \*     | 기술 디렉토리                      | 사이트맵                                                                                        |
| --------- | ---------------------------- | ------------------------------------------------------------------------------------------- |
| Claude 코드 | `~/.claude/skills/`          | [Claude 코드 기술](https://code.claude.com/docs/en/skills)                                      |
| 커서        | `~/.cursor/skills/`          | [커서 기술](https://cursor.com/docs/context/skills)                                             |
| 오픈코드      | `~/.config/opencode/skills/` | [OpenCode 기술](https://opencode.ai/docs/skills/)                                             |
| OpenAI 코드 | `~/.codex/skills/`           | [OpenAI Codex 기술](https://developers.openai.com/codex/skills/)                              |
| 뚱 베어      | `~/.pi/agent/skills/`        | [Pi 코딩 에이전트 기술](https://github.com/badlogic/pi-mono/tree/main/packages/coding-agent#skills) |

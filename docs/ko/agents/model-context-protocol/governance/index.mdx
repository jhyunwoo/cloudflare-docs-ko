Model Context Protocol (MCP)는 대형 언어 모델(LLMs)을 사용하여 고유 데이터 및 내부 도구와 상호 작용할 수 있습니다. 그러나 MCP 채택으로 인해 조직은 "Shadow MCP"의 보안 위험에 직면하고 있으며 직원은 민감한 내부 자원에 대한 로컬 MCP 서버를 관리하지 못했습니다. MCP 거버넌스는 관리자가 MCP 서버가 조직에서 사용되어 어떤 조건에서도 사용할 수 있다는 것을 의미합니다.

## MCP 서버 포털

Cloudflare Access는 MCP를 위한 중앙 집중된 관리 계층을 제공하여 사용자와 MCP 서버 사이의 모든 상호 작용을 평가합니다.

더 보기[MCP 서버 포털](/cloudflare-one/access-controls/ai-controls/mcp-portals/)관리의 허브로서 봉사합니다. 이 포털에서 관리자는 타사 및 내부 MCP 서버를 모두 관리하고 정책을 정의 할 수 있습니다.

- **이름 \***: 어떤 사용자 또는 그룹은 특정 MCP 서버에 액세스 권한을 부여합니다.
- **\* 이름**: 보안 자세(예를 들면, 장치 건강 또는 위치)는 접근을 위해 필요합니다.
- **관련 상품**: MCP 서버 내의 특정 도구는 사용할 수 있습니다.

Cloudflare Access logs MCP 서버 요청 및 도구 실행은 포털을 통해 이루어집니다. 관리자는 조직 전체에 MCP 사용으로 가시성을 제공합니다.

## 원격 MCP 서버

현대 보안 자세를 유지하기 위해, Cloudflare는 사용을 권장합니다[원격 MCP 서버](/agents/guides/remote-mcp-server/)현지 임명에. MCP 서버를 로컬로 실행하여 unmanaged와 유사한 위험을 소개합니다.[그림자 IT](https://www.cloudflare.com/learning/access-management/what-is-shadow-it/), 데이터 흐름을 감사하거나 서버 코드의 무결성을 확인합니다. Remote MCP 서버는 관리자가 어떤 서버가 사용되었는지 파악할 수 있는 능력과 함께 관리자에게 가시성을 부여합니다.

당신은 할 수[원격 MCP 서버를 구축](/agents/guides/remote-mcp-server/)Cloudflare에서 직접 작업자. 둘 다[MCP 서버 포털](#mcp-server-portals)그리고 원격 MCP 서버는 Cloudflare의 네트워크에서 실행되며, 같은 인프라에서 요청은 대기시간을 최소화하고 성능을 극대화합니다.

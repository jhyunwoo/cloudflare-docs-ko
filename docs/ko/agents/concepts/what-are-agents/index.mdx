에이전트는 도구 사용과 프로세스 흐름에 대해 의사결정을 내리며 자율적으로 작업을 실행할 수 있는 AI 시스템입니다. 미리 정의된 경로를 따르는 전통적인 자동화와 달리, 에이전트는 문맥과 중간 결과에 따라 동적으로 접근 방식을 바꿀 수 있습니다. 에이전트는 또한 단순히 인간의 입력을 보강하는 co-pilot(전통적인 채팅 애플리케이션 등)과도 다릅니다. 에이전트는 입력을 보조하는 데 그치지 않고 작업 자체를 끝까지 자동화할 수 있습니다.

- **Agents** → 비선형적, 비결정적(실행할 때마다 달라질 수 있음)
- **Workflows** → 선형적, 결정적인 실행 경로
- **Co-pilots** → 인간 개입이 필요한 보조형 AI 지원

## 예시: 휴가 예약하기

에이전트를 처음 다루거나 상호작용해 본다면, 이 예시는 휴가 예약 같은 문맥에서 에이전트가 어떻게 동작하는지 보여 줍니다.

휴가를 예약하려 한다고 상상해 보세요. 항공편을 조사하고, 호텔을 찾고, 식당 리뷰를 확인하고, 예산을 추적해야 합니다.

### 전통적인 workflow 자동화

전통적인 자동화 시스템은 미리 정해진 순서를 따릅니다.

- 특정 입력을 받습니다(날짜, 위치, 예산)
- 정해진 순서로 사전 정의된 API endpoints를 호출합니다
- 하드코딩된 기준에 따라 결과를 반환합니다
- 예상치 못한 상황이 발생해도 적응할 수 없습니다

![Traditional workflow automation diagram](~/assets/images/agents/workflow-automation.svg)

### AI Co-pilot

co-pilot는 다음과 같은 지능형 보조자 역할을 합니다.

- 선호도에 기반해 호텔과 일정 추천을 제공합니다
- 자연어 질의를 이해하고 응답할 수 있습니다
- 안내와 제안을 제공합니다
- 실제 실행을 위해서는 인간의 의사결정과 행동이 필요합니다

![A co-pilot diagram](~/assets/images/agents/co-pilot.svg)

### Agent

에이전트는 AI의 판단 능력과 관련 도구 호출 능력을 결합해 실제 작업을 수행합니다. 에이전트의 출력이 비결정적인 이유는 다음과 같습니다.

- 실시간 가용성과 가격 변화
- 제약 조건의 동적 우선순위 조정
- 실패에서 복구할 수 있는 능력
- 중간 결과에 따른 적응형 의사결정

![An agent diagram](~/assets/images/agents/agent-workflow.svg)

에이전트는 여행사 직원처럼 동적으로 일정을 구성하고 실제 예약까지 수행할 수 있습니다.

## Agent 시스템의 구성 요소

Agent 시스템은 일반적으로 세 가지 핵심 요소를 가집니다.

- **Decision Engine**: 보통 행동 단계를 결정하는 LLM(Large Language Model)
- **Tool Integration**: 에이전트가 활용할 수 있는 API, 함수, 서비스. 흔히 [MCP](/agents/model-context-protocol/)를 통해 연결됩니다
- **Memory System**: 문맥을 유지하고 작업 진행 상황을 추적합니다

### 에이전트는 어떻게 동작하나요?

에이전트는 다음의 연속 루프 안에서 동작합니다.

1. 현재 상태나 작업을 **관찰**합니다
2. AI를 사용해 추론하며 어떤 행동을 취할지 **계획**합니다
3. 사용 가능한 도구를 이용해 그 행동을 **실행**합니다
4. 결과로부터 **학습**합니다(메모리에 결과를 저장하고, 작업 진행 상황을 업데이트하고, 다음 반복을 준비)

## Cloudflare에서 Agents 빌드하기

Cloudflare Agents SDK는 프로덕션 에이전트를 구축하기 위한 인프라를 제공합니다.

- **Persistent state** — 각 에이전트 인스턴스는 문맥과 메모리를 저장하기 위한 자체 SQLite database를 가집니다
- **Real-time sync** — 상태 변화는 WebSockets를 통해 연결된 모든 클라이언트에 자동으로 브로드캐스트됩니다
- **Hibernation** — 에이전트는 유휴 상태일 때 잠들고 요청이 오면 다시 깨어나므로, 사용한 만큼만 비용을 지불합니다
- **Global edge deployment** — 에이전트는 Cloudflare 네트워크에서 사용자 가까이에서 실행됩니다
- **Built-in capabilities** — 스케줄링, task queues, workflows, email handling 등

문맥을 기억하고 결정을 내릴 수 있는 agents를 만들기 시작해 보세요. 이 가이드는 첫 번째 agent를 만들고, agents가 어떻게 동작하는지 이해하도록 도와줍니다.

Agents는 대화 간 상태를 유지하고 workflows를 실행할 수 있습니다. 고객 지원 자동화, 개인 비서, 대화형 경험 구축에 활용할 수 있습니다.

## 무엇을 배우게 되나요?

agents로 작업하려면 몇 가지 핵심 개념을 이해해야 합니다.

- **State management**: agents가 상호작용 간에 정보를 어떻게 기억하는지
- **Decision making**: agents가 요청을 분석하고 행동을 선택하는 방식
- **Tool integration**: agents가 외부 API와 데이터 소스에 접근하는 방식
- **Conversation flow**: agents가 문맥과 개성을 유지하는 방식

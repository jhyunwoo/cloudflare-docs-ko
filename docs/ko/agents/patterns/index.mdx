이 페이지는 [효과적인 에이전트 구축을 위한 Anthropic의 패턴](https://www.anthropic.com/research/building-effective-agents)을 바탕으로, AI agents 구현에 사용되는 일반적인 패턴을 나열하고 정의합니다.

코드 샘플은 [AI SDK](https://sdk.vercel.ai/docs/foundations/agents)를 사용하며, [Durable Objects](/durable-objects/) 위에서 실행됩니다.

오늘날 대부분의 AI 애플리케이션은 상태 비저장입니다. 즉, 요청을 처리하고 응답을 반환하며 모든 것을 잊어버립니다. 실제 에이전트에는 더 많은 것이 필요합니다. 대화 내용을 기억하고, 일정에 따라 조치를 취하고, 도구를 호출하고, 다른 에이전트와 협력하고, 사용자와 실시간으로 연결을 유지해야 합니다. Agents SDK는 이 모든 것을 TypeScript 클래스로 제공합니다.

각 에이전트는 다음에서 실행됩니다.[내구성 있는 개체](/durable-objects/)— 자체 SQL 데이터베이스, WebSocket 연결 및 예약 기능을 갖춘 상태 저장 마이크로 서버입니다. 한 번 배포하면 Cloudflare 글로벌 네트워크에서 에이전트를 실행하여 수천만 개의 인스턴스로 확장됩니다. 관리할 인프라도 없고, 재구성할 세션도 없고, 외부화할 상태도 없습니다.

### 시작하기

실행 중인 에이전트에 대한 세 가지 명령입니다. API 키가 필요하지 않습니다. 스타터는[Workers AI](/workers-ai/)기본적으로.

```sh
npx create-cloudflare@latest --template cloudflare/agents-starter
cd agents-starter && npm install
npm run dev
```

스타터에는 스트리밍 AI 채팅, 서버측 및 클라이언트측 도구, 인간 개입형 승인, 작업 일정 관리 등이 포함되어 있어 구축하거나 분리할 수 있습니다. 교환도 가능해요[OpenAI, Anthropic, Google Gemini 또는 기타 제공업체](/agents/api-reference/using-ai-models/).

### 상담원이 할 수 있는 일

- **모든 것을 기억하세요**— 모든 에이전트에는 기본 제공되는[SQL 데이터베이스](/agents/api-reference/store-and-sync-state/)연결된 클라이언트와 실시간으로 동기화되는 키-값 상태입니다. 상태는 다시 시작, 배포 및 최대 절전 모드에서 유지됩니다.
- **AI 채팅 구축** — [`AIChatAgent`](/agents/api-reference/chat-agents/)자동 메시지 지속성, 재개 가능한 스트림 및 도구 지원을 통해 스트리밍 AI 채팅을 제공합니다. 와 페어링하세요.[`useAgentChat`](/agents/api-reference/chat-agents/)React 후크를 사용하여 몇 분 만에 채팅 UI를 구축할 수 있습니다.
- **어떤 모델로든 생각해 보세요**— 전화[모든 AI 모델](/agents/api-reference/using-ai-models/)— Workers AI, OpenAI, Anthropic, Gemini — 및 스트리밍 응답[웹소켓](/agents/api-reference/websockets/)또는[서버에서 보낸 이벤트](/agents/api-reference/http-sse/). 즉시 작업에 응답하는 데 몇 분이 걸리는 장기 실행 추론 모델입니다.
- **도구 사용 및 제공**— 서버측 도구, 브라우저에서 실행되는 클라이언트측 도구를 정의하고[인간 참여형](/agents/concepts/human-in-the-loop/)승인 흐름. 다음을 통해 에이전트의 도구를 다른 에이전트 및 LLM에 노출하세요.[MCP](/agents/api-reference/mcp-agent-api/).
- **스스로 행동하라** — [작업 예약](/agents/api-reference/schedule-tasks/)지연 시, 특정 시간 또는 크론 시. 에이전트는 사용자가 없어도 스스로 깨어나 작업을 수행하고 다시 절전 모드로 전환할 수 있습니다.
- **웹 탐색**— 스핀업[헤드리스 브라우저](/agents/api-reference/browse-the-web/)스크랩하고, 스크린샷을 찍고, 웹페이지와 상호작용합니다.
- **작업 조율**— 다단계 실행[워크플로](/agents/api-reference/run-workflows/)자동 재시도를 사용하거나 여러 에이전트 간에 조정합니다.
- **React 이벤트까지**— 핸들[인바운드 이메일](/agents/api-reference/email/), HTTP 요청, WebSocket 메시지 및 상태 변경 - 모두 동일한 클래스에서 발생합니다.

### 작동 원리

에이전트는 TypeScript 클래스입니다. 표시된 메소드`@callable()`클라이언트가 WebSocket을 통해 직접 호출할 수 있는 형식화된 RPC가 됩니다.

<TypeScriptExample>
  ```ts
  import { Agent, callable } from "agents";

  export class CounterAgent extends Agent<Env, { count: number }> {
  	initialState = { count: 0 };

  	@callable()
  	increment() {
  		this.setState({ count: this.state.count + 1 });
  		return this.state.count;
  	}
  }
  ```
</TypeScriptExample>

```tsx
import { useAgent } from "agents/react";

function Counter() {
	const [count, setCount] = useState(0);
	const agent = useAgent({
		agent: "CounterAgent",
		onStateUpdate: (state) => setCount(state.count),
	});

	return <button onClick={() => agent.stub.increment()}>{count}</button>;
}
```

AI 채팅의 경우 확장`AIChatAgent`대신. 메시지는 자동으로 유지되고 연결이 끊어지면 스트림이 다시 시작되며 React 후크가 UI를 처리합니다.

<TypeScriptExample>
  ```ts
  import { AIChatAgent } from "@cloudflare/ai-chat";
  import { createWorkersAI } from "workers-ai-provider";
  import { streamText, convertToModelMessages } from "ai";

  export class ChatAgent extends AIChatAgent {
  	async onChatMessage() {
  		const workersai = createWorkersAI({ binding: this.env.AI });
  		const result = streamText({
  			model: workersai("@cf/zai-org/glm-4.7-flash"),
  			messages: await convertToModelMessages(this.messages),
  		});
  		return result.toUIMessageStreamResponse();
  	}
  }
  ```
</TypeScriptExample>

다음을 참조하세요.[빠른 시작](/agents/getting-started/quick-start/)전체 연습을 보려면[채팅 상담원 가이드](/agents/api-reference/chat-agents/)전체 채팅 API의 경우 또는[에이전트 API 참고 자료](/agents/api-reference/agents-api/)완전한 SDK를 위해.

[x402](https://www.x402.org/)는 HTTP 402(Payment Required)를 중심으로 만들어진 개방형 결제 표준입니다. 서비스는 결제 지침이 담긴 402 응답을 반환하고, 클라이언트는 account, session, API 키 없이 프로그램적으로 결제합니다.

Agents SDK는 x402 결제 요구 사항을 추가하는 `tool`의 drop-in replacement인 `paidTool`을 제공합니다. 클라이언트는 tool call마다 결제하고, 하나의 server 안에서 무료 도구와 유료 도구를 섞어 쓸 수 있습니다.

## Setup

`McpServer`를 `withX402`로 감싸고, 과금하려는 tools에는 `paidTool`을 사용하세요.

```ts
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { McpAgent } from "agents/mcp";
import { withX402, type X402Config } from "agents/x402";
import { z } from "zod";

const X402_CONFIG: X402Config = {
	network: "base",
	recipient: "0xYourWalletAddress",
	facilitator: { url: "https://x402.org/facilitator" }, // Payment facilitator URL
	// To learn more about facilitators: https://docs.x402.org/core-concepts/facilitator
};

export class PaidMCP extends McpAgent<Env> {
	server = withX402(
		new McpServer({ name: "PaidMCP", version: "1.0.0" }),
		X402_CONFIG,
	);

	async init() {
		// Paid tool — $0.01 per call
		this.server.paidTool(
			"square",
			"Squares a number",
			0.01, // USD
			{ number: z.number() },
			{},
			async ({ number }) => {
				return { content: [{ type: "text", text: String(number ** 2) }] };
			},
		);

		// Free tool
		this.server.tool(
			"echo",
			"Echo a message",
			{ message: z.string() },
			async ({ message }) => {
				return { content: [{ type: "text", text: message }] };
			},
		);
	}
}
```

## Configuration

| Field         | Description                                                  |
| ------------- | ------------------------------------------------------------ |
| `network`     | 프로덕션은 `base`, 테스트는 `base-sepolia`                  |
| `recipient`   | 결제를 받을 wallet address                                   |
| `facilitator` | Payment facilitator URL(`https://x402.org/facilitator` 사용) |

## paidTool signature

```ts
this.server.paidTool(
	name, // Tool name
	description, // Tool description
	price, // Price in USD (e.g., 0.01)
	inputSchema, // Zod schema for inputs
	annotations, // MCP annotations
	handler, // Async function that executes the tool
);
```

클라이언트가 결제 없이 유료 도구를 호출하면, server는 payment requirements와 함께 402를 반환합니다. 클라이언트는 x402로 결제하고, 결제 증빙을 첨부해 재시도한 뒤, 결과를 받습니다.

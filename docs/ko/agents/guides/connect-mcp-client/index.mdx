당신의 대리인은 외부에 연결할 수 있습니다[모형 Context 의정서 (MCP)](https://modelcontextprotocol.io)서버는 도구에 액세스하고 에이전트의 기능을 확장합니다. 이 튜토리얼에서는 MCP 서버에 연결하고 도구 중 하나를 사용합니다.

## 당신이 구축 할 것

endpoints를 가진 대리인:

- MCP 서버에 연결
- 연결된 서버에서 사용 가능한 도구 목록
- 연결 상태 얻기

## 자주 묻는 질문

MCP 서버 (또는이 튜토리얼에서 공개 예제를 사용합니다).

## 1. 기본 에이전트 만들기

<Steps>
  1. 새로운 Agent 프로젝트 만들기`hello-world`템플릿:

     <PackageManagers type="create" pkg="cloudflare@latest" args={"my-mcp-client --template=cloudflare/ai/demos/hello-world"} />

  2. 프로젝트 디렉토리로 이동:

     ```sh
     cd my-mcp-client
     ```

     당신의 대리인은 준비되어 있습니다! 템플릿에는 최소 에이전트가 포함되어 있습니다.`src/index.ts`:

     <TypeScriptExample>
       ```ts title="src/index.ts"
       import { Agent, routeAgentRequest } from "agents";

       type Env = {
       	HelloAgent: DurableObjectNamespace<HelloAgent>;
       };

       export class HelloAgent extends Agent<Env> {
       	async onRequest(request: Request): Promise<Response> {
       		return new Response("Hello, Agent!", { status: 200 });
       	}
       }

       export default {
       	async fetch(request: Request, env: Env) {
       		return (
       			(await routeAgentRequest(request, env, { cors: true })) ||
       			new Response("Not found", { status: 404 })
       		);
       	},
       } satisfies ExportedHandler<Env>;
       ```
     </TypeScriptExample>
</Steps>

## 2. MCP 연결 endpoint 추가

<Steps>
  1. MCP 서버에 연결하는 엔드포인트를 추가합니다. 에이전트 클래스를 업데이트`src/index.ts`:

     <TypeScriptExample>
       ```ts title="src/index.ts"
       export class HelloAgent extends Agent<Env> {
       	async onRequest(request: Request): Promise<Response> {
       		const url = new URL(request.url);

       		//MCP 서버에 연결
       		if (url.pathname.endsWith("add-mcp") && request.method === "POST") {
       			const { serverUrl, name } = (await request.json()) as {
       				serverUrl: string;
       				name: string;
       			};

       			const { id, authUrl } = await this.addMcpServer(name, serverUrl);

       			if (authUrl) {
       				//OAuth 필수 - 반환 auth URL
       				return new Response(
       					JSON.stringify({ serverId: id, authUrl }),
       					{ headers: { "Content-Type": "application/json" } },
       				);
       			}

       			return new Response(
       				JSON.stringify({ serverId: id, status: "connected" }),
       				{ headers: { "Content-Type": "application/json" } },
       			);
       		}

       		return new Response("Not found", { status: 404 });
       	}
       }
       ```
     </TypeScriptExample>
</Steps>

더 보기`addMcpServer()`방법은 MCP 서버에 연결됩니다. 서버가 OAuth 인증이 필요한 경우, 반환`authUrl`그 사용자는 완전한 허가를 방문해야 합니다.

## 3. 연결을 시험하십시오

<Steps>
  1. 개발 서버 시작:

     ```sh
     npm start
     ```

  2. 새로운 터미널에서 MCP 서버에 연결하십시오 (공유 사례 사용):

     ```sh
     curl -X POST http://localhost:8788/agents/hello-agent/default/add-mcp \
     	-H "Content-Type: application/json" \
     	-d '{
     		"serverUrl": "https://docs.mcp.cloudflare.com/mcp",
     		"name": "Example Server"
     	}'
     ```

     서버 ID와 응답을 보아야 합니다:

     ```json
     {
     	"serverId": "example-server-id",
     	"status": "connected"
     }
     ```
</Steps>

## 4. 목록 유효한 공구

<Steps>
  1. 연결된 서버에서 어떤 도구가 사용할 수있는 엔드포인트를 추가하십시오.

     <TypeScriptExample>
       ```ts title="src/index.ts"
       export class HelloAgent extends Agent<Env> {
       	async onRequest(request: Request): Promise<Response> {
       		const url = new URL(request.url);

       		//... 이전 add-mcp 엔드 포인트 ...

       		//MCP 국가 목록 (서버, 도구 등)
       		if (url.pathname.endsWith("mcp-state") && request.method === "GET") {
       			const mcpState = this.getMcpServers();

       			return Response.json(mcpState);
       		}

       		return new Response("Not found", { status: 404 });
       	}
       }
       ```
     </TypeScriptExample>

  2. 테스트:

     ```sh
     curl http://localhost:8788/agents/hello-agent/default/mcp-state
     ```

     연결된 모든 서버, 연결 상태 및 사용 가능한 도구를 볼 수 있습니다:

     ```json
     {
     	"servers": {
     		"example-server-id": {
     			"name": "Example Server",
     			"state": "ready",
     			"server_url": "https://docs.mcp.cloudflare.com/mcp",
     			...
     		}
     	},
     	"tools": [
     		{
     			"name": "add",
     			"description": "Add two numbers",
     			"serverId": "example-server-id",
     			...
     		}
     	]
     }
     ```
</Steps>

## 제품정보

할 수있는 에이전트를 만들었습니다 :

- 동적인 외부 MCP 서버에 연결
- OAuth 인증이 필요한 경우
- 연결된 서버에서 모든 사용 가능한 도구 목록
- 감시 연결 상태

에이전트의 연결 persist[SQL 저장](/agents/api-reference/store-and-sync-state/), 그래서 그들은 요청에 따라 활성화 남아.

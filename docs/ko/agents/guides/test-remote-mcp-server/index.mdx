리모트, 허가한 연결은의 진화 부분입니다[모형 Context 의정서 (MCP) 명세](https://spec.modelcontextprotocol.io/specification/draft/basic/authorization/). 모든 MCP 클라이언트 지원 먼 연결 없음.

이 가이드는 원격 연결을 지원하는 MCP 클라이언트와 원격 MCP 서버를 사용하여 시작하는 방법에 대한 옵션을 보여줍니다. 아직 생성되지 않은 경우 원격 MCP 서버를 배포하면,[원격 MCP Server 구축](/agents/guides/remote-mcp-server/)첫 번째 가이드.

## 모형 Context 의정서 (MCP) inspector

더 보기[`@modelcontextprotocol/inspector`제품 설명](https://github.com/modelcontextprotocol/inspector)MCP 서버의 시각적 테스트 도구입니다.

1. 터미널을 열고 다음 명령을 실행:

   ```sh
   npx @modelcontextprotocol/inspector
   ```

   ```sh output
   🚀 MCP Inspector is up and running at:
   	http://localhost:5173/?MCP_PROXY_AUTH_TOKEN=46ab..cd3

   🌐 Opening browser...
   ```

   MCP Inspector는 웹 브라우저에서 시작됩니다. 브라우저를 열고`http://localhost:<PORT>`. MCP Inspector가 실행되는 로컬 포트에 대한 명령 출력을 확인합니다. 이 예제에서 MCP Inspector는 포트에 제공됩니다.`5173`.

2. MCP 검사기에서 MCP 서버의 URL을 입력하십시오 (예를 들어,`http://localhost:8788/mcp`). 제품정보**연결하기**.

   로컬 머신이나 원격 MCP 서버에서 실행되는 MCP 서버에 연결할 수 있습니다.

3. 서버가 인증이 필요하면 연결이 실패합니다. 인증:
   1. MCP 검사기에서, 선택**Auth 설정 열기**.
   2. 제품정보**빠른 OAuth 흐름**.
   3. OAuth 공급자로 인증되면 MCP Inspector로 다시 리디렉션됩니다. 제품정보**연결하기**.

당신은 볼 수**회사연혁**MCP 서버가 노출되는 도구를 나열합니다.

## 원격 MCP 서버에서 Cloudflare\`WorkersAI\` 놀이터에 연결

자주 묻는 질문[\`Workers AI\` 놀이터](https://playground.ai.cloudflare.com/), MCP 서버 URL을 입력하고, "연결"을 클릭합니다. 일단 인증 (필요한 경우), 당신은 나열된 도구를 볼 수 있으며 채팅에서 AI 모델에 사용할 수 있습니다.

## 로컬 프록시를 통해 원격 MCP 서버에 Claude Desktop 연결

당신은 사용할 수 있습니다[`mcp-remote`지역 프록시](https://www.npmjs.com/package/mcp-remote)Claude 데스크톱을 원격 MCP 서버에 연결하십시오. 원격 MCP 서버와의 상호 작용을 테스트하면 실제 MCP 클라이언트와 같습니다.

1. Claude 데스크톱을 열고 Settings -> Developer -> Edit Config으로 이동하십시오. 이 MCP 서버 Claude가 액세스 할 수있는 구성 파일을 엽니 다.
2. 이 같은 구성으로 콘텐츠를 대체:

```json
{
	"mcpServers": {
		"my-server": {
			"command": "npx",
			"args": ["mcp-remote", "http://my-mcp-server.my-account.workers.dev/mcp"]
		}
	}
}
```

3. 파일을 저장하고 Claude Desktop (command/ctrl + R)를 다시 시작합니다. Claude가 다시 시작될 때, 브라우저 창은 OAuth 로그인 페이지를 보여주게 됩니다. MCP 서버에 Claude 액세스를 부여하는 권한 흐름을 완료하십시오.

일단 인증되면 Claude의 인터페이스의 하단 오른쪽 코너에서 도구 아이콘을 클릭하여 도구를 볼 수 있습니다.

## 원격 MCP 서버를 Cursor에 연결

연결하기[커서](https://cursor.com/docs/context/mcp)프로젝트 편집을 통해 원격 MCP 서버로`.cursor/mcp.json`파일 또는 글로벌`~/.cursor/mcp.json`파일 및 다음 구성 추가:

```json
{
	"mcpServers": {
		"my-server": {
			"url": "http://my-mcp-server.my-account.workers.dev/mcp"
		}
	}
}
```

## Windsurf에 원격 MCP 서버 연결

원격 MCP 서버를 연결할 수 있습니다.[윈드 서핑](https://docs.windsurf.com)으로 편집[`mcp_config.json`이름 \*](https://docs.windsurf.com/windsurf/cascade/mcp), 다음 구성을 추가:

```json
{
	"mcpServers": {
		"my-server": {
			"serverUrl": "http://my-mcp-server.my-account.workers.dev/mcp"
		}
	}
}
```

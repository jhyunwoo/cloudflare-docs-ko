:::caution[지원 중단 안내]
Classic Schema validation은 지원이 중단되었습니다.

새로운 스키마는 모두 [Schema validation 2.0](/api-shield/security/schema-validation/)에 업로드하세요.
:::

제공한 <GlossaryTooltip term="API schema">API schema</GlossaryTooltip>에 따라 요청을 검증하는 [API Schema validation](/api-shield/security/schema-validation/)을 구성하려면 **API Shield** 인터페이스를 사용하세요.

API에 대해 Schema validation을 구성하려면 먼저 [사양](/api-shield/security/schema-validation/#specifications)에 맞는 API Schema 파일을 준비해야 합니다.

이미 Schema validation 2.0을 사용 중이라면 기존 설정은 변경할 수 있지만, 새로운 Classic Schema validation 스키마는 추가할 수 없습니다.

:::note

이 기능은 Enterprise 요금제 고객에게만 제공됩니다. 접근 권한이 필요하면 Cloudflare Customer Success Manager에게 문의하세요.
:::

## Schema validation을 포함한 API Shield 만들기

Cloudflare dashboard에서 Schema validation을 구성하려면 다음 단계를 따르세요.

1. [Cloudflare dashboard](https://dash.cloudflare.com)에 로그인한 뒤 계정과 도메인을 선택합니다.
2. **Security** > **API Shield**를 선택합니다.
3. **Schema validation**으로 이동한 뒤 **Add schema**를 선택합니다.
4. 정책 이름을 설명적으로 입력하고, 필요하면 Schema validation을 트리거할 식을 편집합니다. 예를 들어 API가 `http://api.example.com/v1`에서 제공된다면 *Hostname* 필드가 `api.example.com`과 같은지 확인하고, *URI Path* 필드가 정규식 `^/v1`과 일치하는지 확인하도록 설정합니다.
:::caution[Important]

호스트명을 검증하려면, 스키마 파일에 호스트명 값이 들어 있더라도 규칙에 *Hostname* 필드를 명시적으로 포함해야 합니다. 스키마 파일에 있는 호스트명 값은 무시됩니다.
:::
5. **Next**를 선택합니다.
6. 스키마 파일을 업로드합니다.
7. **Save**를 선택해 스키마 파일의 내용을 검증하고 Schema validation 규칙을 배포합니다. 검증 오류가 발생하면 [지원되는 파일 형식](/api-shield/security/schema-validation/#specifications) 중 하나를 사용했는지, 그리고 각 엔드포인트와 메서드 쌍에 고유한 operation ID가 있는지 확인하세요.

API Shield 규칙을 배포하면 Cloudflare가 모든 <GlossaryTooltip term="API endpoint">API endpoints</GlossaryTooltip>를 보호 수준과 비정상 요청 및 비보호 요청에 대해 수행될 동작별로 정리해 요약해서 보여줍니다.

1. **Endpoint action** 드롭다운에서 보호된 엔드포인트를 대상으로 하면서 Schema validation에 실패한 모든 요청에 적용할 동작을 선택합니다.
2. **Fallthrough action** 드롭다운에서 비보호 엔드포인트를 대상으로 하는 모든 요청에 적용할 동작을 선택합니다.
3. 필요하다면 **Save new endpoints to [endpoint management](/api-shield/management-and-monitoring/)**를 선택해 Schema를 저장하는 동시에 Endpoint Management에도 엔드포인트를 저장할 수 있습니다. Schema를 초안으로 저장하든 게시하든 관계없이 엔드포인트는 저장됩니다.
4. **Done**을 선택합니다.

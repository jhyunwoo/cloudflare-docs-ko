## API 보안이 왜 중요할까요?

API는 [인기 있는 웹 서비스의 중추](/api-shield/security/api-discovery/)로 자리 잡았으며, 인터넷을 더 쉽게 접근하고 더 유용하게 만드는 데 도움을 주고 있습니다.

하지만 API가 더 널리 사용될수록 그에 따른 문제도 함께 늘어나고 있습니다.

- 많은 기업은 [수천 개의 API](/api-shield/security/api-discovery/)를 보유하고 있으며, 그중에는 자신들도 존재를 모르는 API가 포함되어 있습니다.
- 많은 사용자를 지원하기 위해 많은 API가 부정 보안 모델에 의해 보호되며, 이로 인해 credential stuffing 공격과 자동 스캐닝 도구에 취약해집니다.
- 엔드포인트와 사용자가 너무 많기 때문에 [특정 엔드포인트](/api-shield/security/volumetric-abuse-detection/)를 겨냥한 무차별 대입 공격을 인식하기가 어렵습니다.
- 더 정교한 공격은 인식하기가 더욱 어렵습니다. 개발 팀조차 일반적이거나 흔하지 않은 [사용 패턴](/api-shield/security/sequence-analytics/)을 잘 모르는 경우가 많기 때문입니다.

API Shield를 설정하려면 [시작하기](/api-shield/get-started/) 가이드를 참고하세요.

## 제공 대상

Cloudflare API Security 제품은 Enterprise 고객만 사용할 수 있지만, 누구나 Cloudflare가 관리하는 인증 기관을 사용하는 [Mutual TLS](/api-shield/security/mtls/)를 설정할 수 있습니다.

전체 API Shield 보안 제품군은 Enterprise 전용 유료 애드온으로 제공되지만, 모든 고객은 [Endpoint Management](/api-shield/management-and-monitoring/)와 [Schema validation](/api-shield/security/schema-validation/) 기능을 사용할 수 있습니다.

:::note
현재 API Shield는 JDCloud 고객에게는 동작하지 않습니다.
:::

[JSON Web Token (JWT)](/api-shield/security/jwt-validation/)에서 Cloudflare가 검증한 claims를 사용해 [Transform Rules](/rules/transform/)를 만들면, JWT의 정보를 헤더를 통해 origin으로 전달할 수 있습니다.

claims는 `http.request.jwt.claims` firewall fields를 통해 사용할 수 있습니다.

예를 들어 다음 식은 `TOKEN_CONFIGURATION_ID` token configuration으로 처리된 토큰에서 user claim을 추출합니다.

```txt
lookup_json_string(http.request.jwt.claims["<TOKEN_CONFIGURATION_ID>"][0], "claim_name")
```

token configuration 생성에 대한 자세한 내용은 [Configure JWT validation](/api-shield/security/jwt-validation/api/)을 참고하세요.

## Transform Rule 만들기

예를 들어 `x-send-jwt-claim-user` 요청 헤더를 origin으로 보내려면 다음과 같이 Transform Rule을 만들어야 합니다.

<Steps>
1. In the Cloudflare dashboard, go to the **Rules overview** page.

    <DashButton url="/?to=/:account/:zone/rules/overview" />
2. Select **Create rule** > **Request Header Transform Rules**.
3. Enter a rule name and a filter expression, if applicable.
4. Choose **Set dynamic**.
5. Set the header name to `x-send-jwt-claim-user`.
6. Set the value to:
    ```txt wrap
    lookup_json_string(http.request.jwt.claims["<TOKEN_CONFIGURATION_ID>"][0], "claim_name")
    ```
    `<TOKEN_CONFIGURATION_ID>`는 JWT validation에서 찾을 수 있는 token configuration ID이고, `claim_name`은 헤더에 추가하려는 JWT claim입니다.
</Steps>

GraphQL은 API를 위한 쿼리 언어입니다. Cloudflare는 RESTful API를 보호하는 것 외에도 GraphQL API를 보호할 수 있습니다.

GraphQL malicious query protection은 origin에 과부하를 주고 서비스 거부를 초래할 수 있는 쿼리를 찾기 위해 GraphQL 트래픽을 검사합니다. 들어오는 GraphQL 쿼리의 깊이와 크기를 제한하는 규칙을 만들어 의심스럽게 크거나 복잡한 쿼리를 차단할 수 있습니다.

## 제공 대상

GraphQL malicious query protection은 모든 API Shield 고객에게 제공됩니다. API Shield를 구매하지 않은 Enterprise 고객은 Cloudflare dashboard에서 [API Shield as a non-contract service](https://dash.cloudflare.com/?to=/:account/:zone/security/api-shield)를 미리 보거나 계정 팀에 문의할 수 있습니다.

## 제한 사항

초기 릴리스는 20 KB보다 작은 GraphQL `POST` 본문 파싱으로 제한됩니다. 이 제한은 향후 릴리스에서 해제될 예정입니다. 또한 현재는 `application/json` 또는 `application/graphql` `content-types`를 가지며 fragments나 multiple operations를 포함하지 않는 `POST` 요청만 검사합니다. 파싱과 규칙은 `/graphql`로 끝나는 경로로 제한됩니다.

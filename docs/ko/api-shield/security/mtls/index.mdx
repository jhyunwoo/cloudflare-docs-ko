지원 범위에는 JSON 대신 protocol buffers 같은 바이너리 형식을 사용하는 [gRPC](https://grpc.io/docs/what-is-grpc/introduction/)-based APIs도 포함됩니다.

## 설정

dashboard를 사용해 하나 이상의 host에 대해 mTLS를 설정하려면 [Configure mTLS](/api-shield/security/mtls/configure/)를 참고하세요.

## 제공 대상

모든 Cloudflare 요금제에서 Cloudflare가 관리하는 certificate authority(CA)를 사용해 mTLS를 설정할 수 있습니다. Enterprise 고객은 [최대 5개의 비 Cloudflare CA를 업로드](/ssl/client-certificates/byo-ca/)할 수 있습니다. 더 높은 한도가 필요하면 계정 팀에 문의하세요.

## 제한 사항

Yubikey를 사용할 때는 Yubikey의 PKCS#11 라이브러리 문제 때문에 브라우저가 키 잠금 해제를 요구할 수 있습니다.

<GlossaryTooltip term="API endpoint">endpoints</GlossaryTooltip>를 저장하면 API Shield는 API 카탈로그 역할도 수행합니다. API Shield는 API에 대해 알고 있는 정보를 바탕으로 상호작용형 문서 포털을 만들 수 있으며, 새 OpenAPI schema 파일을 업로드해 즉석에서 문서 포털을 만들 수도 있습니다.

개발자 포털을 만들려면 다음 단계를 따르세요.

<Tabs syncKey="dashNewNav">
  <TabItem label="New dashboard" icon="rocket">
    <Steps>
      1. In the Cloudflare dashboard, go to the **Security Settings** page.

          <DashButton url="/?to=/:account/:zone/security/settings" />
      2. Filter by **API abuse**.
      3. On **Create a developer portal**, select **Create site**.
      4. Upload an OpenAPI v3.0 schema file or choose to select an existing schema from API Shield.
          :::note
          업로드할 스키마가 없고 기존 스키마 중 선택할 수도 없다면 Endpoint Management schema를 export하세요. 최상의 결과를 위해 learned parameters를 포함하세요.

          기존 스키마를 선택할 때는 Schema validation 2.0에 업로드된 <GlossaryTooltip term="API schema">API schemas</GlossaryTooltip>만 사용할 수 있습니다.
          :::
      5. Select **Download project files** to save a local copy of the files that will be uploaded to Cloudflare Pages. Downloading the project files can be helpful if you wish to modify the project in any way and then upload the new version manually to Pages.
      6. Select **Create pages project** to begin project creation. A new Pages project will be automatically created and your API schema will be automatically uploaded to the project along with other supporting static content.
      7. Select **Deploy site**.
    </Steps>

  </TabItem>
  <TabItem label="Old dashboard">
    <Steps>
      1. Log in to the [Cloudflare dashboard](https://dash.cloudflare.com/), and select your account and domain.
      2. Go to **Security** > **API Shield** > **Settings**.
      3. Under **Create a developer portal**, select **Create site**.
      4. Upload an OpenAPI v3.0 schema file or choose to select an existing schema from API Shield.
          :::note
          업로드할 스키마가 없고 기존 스키마 중 선택할 수도 없다면 Endpoint Management schema를 export하세요. 최상의 결과를 위해 learned parameters를 포함하세요.

          기존 스키마를 선택할 때는 Schema validation 2.0에 업로드된 <GlossaryTooltip term="API schema">API schemas</GlossaryTooltip>만 사용할 수 있습니다.
          :::
      5. Select **Download project files** to save a local copy of the files that will be uploaded to Cloudflare Pages. Downloading the project files can be helpful if you wish to modify the project in any way and then upload the new version manually to Pages.
      6. Select **Create pages project** to begin project creation. A new Pages project will be automatically created and your API schema will be automatically uploaded to the project along with other supporting static content.
      7. Select **Deploy site**.
    </Steps>

  </TabItem>
</Tabs>

### 사용자 지정 도메인

`pages.dev` 도메인 대신 vanity domain을 만들려면 [Pages custom domain documentation](/pages/configuration/custom-domains/)를 참고하세요.

## 제공 대상

개발자 포털 빌드 기능은 모든 API Shield 구독자에게 제공됩니다. 이 기능은 결과 포털을 호스팅하기 위해 Cloudflare Pages를 사용합니다. 현재 구독 요금제의 제한 사항은 [Pages](/pages/)를 참고하세요.

## 제한 사항

이 기능은 현재 [Redocly](https://redocly.com/)의 오픈 소스 [Redoc](https://github.com/Redocly/redoc) 프로젝트를 사용합니다. 사용자 지정 테마와 브랜딩 옵션이 필요하다면 [Redoc GitHub repository](https://github.com/Redocly/redoc)를 참고하세요.

결과 페이지를 수정하려면 Pages 프로젝트를 만들기 전에 project files를 다운로드하세요. 그런 다음 변경한 파일을 사용해 브랜딩 가이드라인에 맞는 새 Pages 프로젝트를 만들 수 있습니다.

Cloudflare는 트래픽 검사를 통해 schema parameters를 학습합니다. Endpoint Management에 저장된 모든 엔드포인트에 대해, 학습된 schema를 호스트명 기준 OpenAPI `v3.0.0` 형식으로 export할 수 있습니다.

학습된 schema로 API를 보호하려면 [Schema validation](/api-shield/security/schema-validation/#add-validation-by-applying-a-learned-schema-to-an-entire-hostname)을 참고하세요.

## 스키마 내보내기

{/* prettier-ignore-start */}

<Tabs syncKey="dashNewNav">
  <TabItem label="New dashboard" icon="rocket">
    <Steps>
      1. In the Cloudflare dashboard, go to the **Web Assets** page.

          <DashButton url="/?to=/:account/:zone/security/web-assets" />
      2. Go to the **Endpoints** tab.
      3. Select **Export schema** and choose a hostname to export.
      4. Select whether to include learned parameters and rate limit recommendations
      5. Select **Export schema** and choose a location to save the file.
    </Steps>
  </TabItem>
  <TabItem label="Old dashboard">
    <Steps>
      1. Log in to the [Cloudflare dashboard](https://dash.cloudflare.com/), and select your account and domain.
      2. Select **Security** > **API Shield** > **Endpoint Management**.
      4. Select **Export schema** and choose a hostname to export.
      5. Select whether to include [learned parameters](/api-shield/management-and-monitoring/#learned-schemas-will-always-include) and [rate limit recommendations](/api-shield/security/volumetric-abuse-detection/)
      6. Select **Export schema** and choose a location to save the file.
    </Steps>
  </TabItem>
</Tabs>

:::note
schema는 OpenAPI `v3.0.0` 형식의 JSON 파일로 저장됩니다.
:::

<div id="learned-schemas-will-always-include"></div>

학습된 스키마에는 항상 다음이 포함됩니다.

- servers 섹션의 나열된 호스트명
- 호스트, 메서드, 경로 기준의 모든 엔드포인트

충분한 트래픽을 받는 엔드포인트의 경우, 학습된 스키마에는 다음도 포함됩니다.

- 감지된 path variables와 형식
- 감지된 query parameters와 형식
- `application/json` 콘텐츠 타입에 대해 감지된 `POST`, `PUT`, `PATCH` 본문 변수 이름과 형식

학습된 스키마에는 선택적으로 다음도 포함될 수 있습니다.

- API Shield의 rate limit 임계값 권장치

## 제한 사항

Schema learning이 시작되려면 엔드포인트가 최소 24시간 이상 추가되어 있어야 합니다. Schema learning은 엔드포인트에 대한 최근 72시간의 트래픽을 지속적으로 검사하는 과정입니다.

Schema learning은 `2xx` 응답 코드를 가진 요청만 학습합니다.

Schema learning은 트래픽 양이 많을수록 가장 잘 동작합니다. 최근 72시간 동안 요청 수가 10,000 미만인 엔드포인트는 신뢰도가 낮은 learned schema가 보일 수 있습니다.

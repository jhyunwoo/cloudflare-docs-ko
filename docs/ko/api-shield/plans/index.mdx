API Shield를 구독하지 않은 Free, Pro, Business, Enterprise 고객은 [Endpoint Management](/api-shield/management-and-monitoring/)와 [Schema validation](/api-shield/security/schema-validation/)을 사용할 수 있지만, 그 외 [API Shield](/api-shield/) 기능은 사용할 수 없습니다.

API Shield를 구독하려면 Enterprise 요금제로 업그레이드한 뒤 계정 팀에 문의하세요.

엔드포인트 한도는 Endpoint Management와 Schema validation에 적용됩니다. zone 요금제별 한도는 아래 표를 참고하세요.

| 요금제 유형 | 저장된 엔드포인트 | 업로드된 스키마 | 업로드된 스키마 총 크기 | 규칙 동작 |
| --- | --- | --- | --- | --- |
| **Free** | 100 | 5 | 200 kB | `Block`만 |
| **Pro** | 250 | 5 | 500 kB | `Block`만 |
| **Business** | 500 | 10 | 2 MB | `Block`만 |
| **Enterprise without API Shield** | 500 | 10 | 5 MB | `Log` 또는 `Block` |
| **Enterprise with API Shield** | 10,000 | 10+ | 10+ MB | `Log` 또는 `Block` |

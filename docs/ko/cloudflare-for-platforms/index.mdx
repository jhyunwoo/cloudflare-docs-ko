<Description>
  고객이 코드를 배포 할 수있는 플랫폼을 구축, 각 자신의 하위 도메인 또는 사용자 정의 도메인.
</Description>

플랫폼에 대한 Cloudflare는 큰 플랫폼과 작은에 의해 사용됩니다:

- 특정 도메인에 맞게 응용 프로그램 개발 플랫폼, 전자 상거래 storefront 또는 모바일 앱과 같은
- Power AI 코딩 플랫폼은 누구나 소프트웨어 구축 및 배포
- 제품 행동을 사용자 정의하여 짧은 코드 스니펫을 작성
- 모든 고객 자신의 고립 된 데이터베이스를 제공
- 자신의 하위 도메인으로 각 고객을 제공

***

## 자신의 플랫폼을 배포

몇 분에서 실행되는 작업 플랫폼을 가져옵니다. 건물에 따라 템플릿을 선택하십시오.

### 플랫폼 스타터 키트

[![Cloudflare에 배포](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/cloudflare/templates/tree/main/worker-publisher-template)

사용자가 스케일에 코드를 배포 할 수있는 플랫폼의 예. 각 스니펫은 자체 격리 된 노동자가됩니다.`example.com/{app-name}`. 이 시동기 장비를 자동적으로 구성합니다 당신을 위해 취급되는 여정을 가진 플랫폼을 위한 Workers.

### AI vibe 코딩 플랫폼

[![Cloudflare에 배포](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/cloudflare/vibesdk)

회사연혁[AI vibe 코딩 플랫폼](/reference-architecture/diagrams/ai/ai-vibe-coding-platform/)사용자가 원하는 것을 설명하고 AI 생성하고 작업 응용 프로그램을 배포합니다. 최고의: AI-powered app builders, 코드 생성 도구, 또는 내부 플랫폼은 팀에 응용 프로그램 및 프로토 타입을 구축 할 수 있습니다.

[사이트맵](https://github.com/cloudflare/vibesdk)처리 AI 코드 생성, 보안 샌드 박스에서 코드 실행, 라이브 미리보기, 과 배치 규모.

## 주요 특징

- **고립과 multitenancy**— 고객의 각은 자신의 노동자에 코드 실행,[안전하고 고립 된 sandbox](/cloudflare-for-platforms/workers-for-platforms/reference/worker-isolation/).
- **풀그릴 여정, 진입, egress 및 한계**— 고객의 코드를 발송하는 코드를 작성하고 제어할 수 있습니다.[관련 기사](/cloudflare-for-platforms/workers-for-platforms/configuration/dynamic-dispatch/), [뚱 베어](/cloudflare-for-platforms/workers-for-platforms/configuration/outbound-workers/), 및 세트[고객 제한](/cloudflare-for-platforms/workers-for-platforms/configuration/custom-limits/).
- **데이터베이스 및 저장**— 제공 할 수 있습니다[데이터베이스, 객체 저장 및 기타](/cloudflare-for-platforms/workers-for-platforms/configuration/bindings/)APIs로 고객에게는 API 토큰, 열쇠, 또는 외부 의존도 없이 직접 전화할 수 있습니다.
- **사용자 정의 도메인 및 하위 도메인**- 너[API 호출](/cloudflare-for-platforms/cloudflare-for-saas/domain-support/)사용자 정의 하위 도메인을 만들거나 사용자 정의 도메인을 구성하십시오.

이러한 구성 요소가 함께 작동하는 방법을 배우려면, 참조[플랫폼을위한 Workers는 어떻게 작동합니까?](/cloudflare-for-platforms/workers-for-platforms/how-workers-for-platforms-works/).

당신의 근원 서버에 전달할 때, Cloudflare는 뒤에 따라 요구 모수를 놓을 것입니다:

## 호스트 헤더

Cloudflare는 기본적으로 주인 우두머리를 바꾸지 않으며 클라이언트에 의해 보내진 것과 같이 정확하게 전달할 것입니다. 호스트 헤더의 값을 변경하려면 utilise 할 수 있습니다.[사이트 맵](/workers/configuration/workers-with-page-rules/)또는[모델 번호: Workers](/workers/)자주 묻는 질문[인증서 관리](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/).

## 사이트맵

TLS 연결을 원래 서버로 설정할 때, 요청이 설정된 폴백 호스트로 전송되는 경우, CloudflareXQ에 의해 전송된 SNI의 값은 클라이언트 (즉, 사용자 지정 호스트 이름)에 의해 보낸 호스트 헤더의 값과 일치합니다.

그러나 요청이 Custom Origin에 전달되는 경우 SNI의 값은 Custom Origin의 것입니다.

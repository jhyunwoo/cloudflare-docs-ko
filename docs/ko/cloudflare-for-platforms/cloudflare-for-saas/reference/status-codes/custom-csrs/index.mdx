## 성공 코드

| 끝점                                                  | 제품 설명  | HTTP 상태 코드 |
| --------------------------------------------------- | ------ | ---------- |
| `/api/v4/zones/:zone_id/custom_csrs`                | 사이트맵   | 201 작성     |
| `/api/v4/zones/:zone_id/custom_csrs`                | 이름 \*  | 200 OK     |
| `/api/v4/zones/:zone_id/custom_csrs/:custom_csr_id` | 이름 \*  | 200 OK     |
| `/api/v4/zones/:zone_id/custom_csrs/:custom_csr_id` | 계정 만들기 | 200 OK     |

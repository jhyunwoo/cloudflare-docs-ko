당신이 수행 할 때[사이트맵](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/issue-and-validate/validate-certificates/txt/)도메인 관리 검증, 당신은 당신의 고객과이 토큰을 공유해야합니다.

그러나, 이러한 토큰은 선택한 인증서 기관에 따라 특정 시간 후에 만료됩니다.

| 인증 기관            | 토큰 유효성 |
| ---------------- | ------ |
| 암호화하자            | 7 일    |
| Google Trust 서비스 | 14 일   |
| 사이트맵             | 14 일   |

Cloudflare는 글로벌 분산 데이터 센터의 서버에서 웹 사이트의 콘텐츠의 사본을 저장하여 고객 웹 사이트를 빠르게 만듭니다. 콘텐츠는 정적 또는 동적 일 수 있습니다 : 정적 콘텐츠는 "cacheable"또는 캐싱에 대한 자격이, 동적 콘텐츠는 "uncacheable"또는 캐싱에 대한 불가. 콘텐츠의 캐시 된 사본은 물리적으로 사용자에게 더 가까이 저장되며 신속하게 최적화되어 평판이 필요하지 않습니다.

SaaS 공급자로서, 캐싱은 사용자 정의 도메인의 대기 시간을 줄일 수 있습니다. 더 많은 정보를 원하시면, 참조[캐시](/cache/). 캐싱을 활성화하고 싶다면, 리뷰[Cache 시작하기](/cache/get-started/).

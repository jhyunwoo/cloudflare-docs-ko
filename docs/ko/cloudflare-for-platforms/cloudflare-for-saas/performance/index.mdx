SaaS를 위한 Cloudflare는 고객에게 최고의 성능을 제공합니다.

- [SaaS를 위한 Argo Smart Routing](/cloudflare-for-platforms/cloudflare-for-saas/performance/argo-for-saas/)가장 빠른 경로를 계산하여 목적지로 여행할 수 있습니다.
- [SaaS를 위한 조기 힌트](/cloudflare-for-platforms/cloudflare-for-saas/performance/early-hints-for-saas/)브라우저를 허용하여 개별 사용자 정의 호스트 이름에 대한 빠른 로딩 속도를 제공하여 소스 서버가 전체 응답을 컴파일하는 동안 응답을로드합니다.
- [SaaS를 위한 캐시](/cloudflare-for-platforms/cloudflare-for-saas/performance/cache-for-saas/)고객 웹 사이트를 더 빠르게 만들어 글로벌 분산 데이터 센터의 서버에 웹 사이트의 콘텐츠의 사본을 저장합니다.
- SaaS에 대한 Cloudflare를 사용함으로써 고객은 Cloudflare의 광대한 이점을 자동적으로 상속합니다[anycast 네트워크](https://www.cloudflare.com/network/).

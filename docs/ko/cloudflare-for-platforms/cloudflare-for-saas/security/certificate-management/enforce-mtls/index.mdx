[상호 TLS (mTLS)](https://www.cloudflare.com/learning/access-management/what-is-mutual-tls/)서버 및 클라이언트의 인증서를 검증하여 응용 프로그램에 대한 추가 레이어를 추가합니다. SaaS 응용 프로그램을 구축 할 때, 지불 처리, 데이터베이스 업데이트 등과 관련된 민감한 엔드포인트를 보호하기 위해 mTLS를 시행 할 수 있습니다.

[최소 TLS 버전](#minimum-tls-version)선택한 TLS 프로토콜 버전 또는 더 새로운 것을 지원하는 방문자의 HTTPS 연결을 허용. Cloudflare는 지불 카드 기업 (PCI) 안전 표준위원회에 따르기 위하여 TLS 1.2를 추천합니다. SaaS 공급자로, 당신은 당신의 지역을 위한 최소한도 TLS 버전을 전체적으로 통제할 수 있고, 또한 개인적인 주문 hostnames를 위해.

[Cipher 스위트](#cipher-suites)보안 설정을 협상하는 데 사용되는 ciphers의 조합[SSL/TLS 핸즈](https://www.cloudflare.com/learning/ssl/what-happens-in-a-tls-handshake/). SaaS 공급자로, API를 통해 개별 사용자 정의 hostnames에 전체 및 cipher suites로 영역에서 cipher suites에 대한 구성을 지정할 수 있습니다.

:::카트로션
당신은[custom hostname 인증서 발급](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/issue-and-validate/)wildcards 활성화, 어떤 cipher suites 또는 hostname에 적용되는 최소 TLS 설정은 직접 hostname에만 적용됩니다.

그러나 모든 와일드카드 호스트 이름의 최소 TLS 설정을 업데이트하려면 최소 TLS 버전을 변경할 수 있습니다.[지역 수준](/ssl/edge-certificates/additional-options/minimum-tls/).
:::

## 사용 가능한 mTLS

당신은[사용자 정의 hostname 추가](/cloudflare-for-platforms/cloudflare-for-saas/start/getting-started/)Cloudflare 액세스를 사용하여 mTLS를 활성화 할 수 있습니다. 오시는 길[Cloudflare Zero Trust](https://one.dash.cloudflare.com/)·[mTLS 인증 추가](/cloudflare-one/access-controls/service-credentials/mutual-tls-authentication/)몇 번의 클릭으로

:::참조
현재 사용자 지정 호스트 이름에 mTLS 정책을 추가할 수 없습니다.[모델 번호: API Shield](/api-shield/security/mtls/).

또한 특정 사용자 정의 호스트 이름에 mTLS를 시행해야합니다. CNAME 대상에 설정할 수 없습니다.
주요 특징

## 최소 TLS 버전

:::참조
TLS 1.3은 가장 최근의 안전한 버전이지만, 이전 장치에서 지원되지 않습니다. Cloudflare의 권장 사항 참조[어떤 버전을 사용 하는지 결정](/ssl/reference/protocols/#decide-which-version-to-use).
:::

### 관련 상품

최소 TLS 버전은 모두 존재[지역 수준 조정](/ssl/edge-certificates/additional-options/minimum-tls/)(에)[**Edge 인증서**](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/edge-certificates)내 계정**최소 TLS 버전**) 그리고 주문 hostname 조정으로. 이 의미는:

- API를 통해 생성된 사용자 지정 호스트명은 명시적으로 값을 정의할 수 없습니다.`min_tls_version`. 이 경우, 어떤 값이 영역의 최소 TLS 버전으로 정의됩니다. 주어진 사용자 정의 호스트 이름이 특정 최소 TLS 버전 세트를 가지고 있는지 확인하려면 다음 API 호출을 사용하십시오.

- 대시보드를 통해 사용자 정의 호스트 이름 변경을 할 때마다 최소 TLS 버전이 적용됩니다. 위의 총알에 설명된 시나리오가 있다면 대시보드 변경은 해당 영역 수준의 구성을 무시합니다.

- wildcards 활성화를 가진 사용자 정의 hostnames를 위해, 당신이 창조하는 직접 주문 hostname (예를 들면,`saas-customer.test`)는 hostname-specific 설정을 사용할 것이며, 다른 사람 (`sub1.saas-customer.test`, `sub2.saas-customer.test`, etc)는 지역 수준 조정에 과태 할 것입니다.

보안 및 규제상의 이유로 특정 cipher 스위트에서 연결을 허용 할 수 있습니다. Cloudflare는 우리의 참고 자료의 추천한 가치 및 가득 차있는 cipher 스위트 QXQXQ를 제공합니다[Cipher Suite 문서](/ssl/edge-certificates/additional-options/cipher-suites/#resources).

<Details header="지역을 위한 제한 cipher 스위트">

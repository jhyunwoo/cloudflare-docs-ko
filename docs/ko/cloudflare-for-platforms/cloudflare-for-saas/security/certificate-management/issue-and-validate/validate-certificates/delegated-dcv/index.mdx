DCV는 DCV 프로세스를 Cloudflare에 delegate 할 수 있습니다.

전압: DCV 위임은 Cloudflare를 자동 갱신하는 모든 미래 증명서 순서에 Cloudflare를 허용하는 그들의 권위있는 DNS에 1 시간 기록, 그래서 갱신의 시간에 수동 개입이 없습니다.

***

## 설치하기

위임된 DCV를 설치하기 위하여:

1. 추가하기[주문 hostname](/cloudflare-for-platforms/cloudflare-for-saas/domain-support/create-custom-hostnames/)당신의 지역을 위해, 선택`TXT`으로**인증서 검증 방법**.
2. 에 의해[**사용자 이름**](https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/custom-hostnames)사이트 맵**사용자 정의 호스트 이름에 대한 DCV 위임**.
3. hostname 값을 복사합니다.
4. 각 호스트 이름의 경우 도메인 소유자는 배치해야합니다.`CNAME`자신의 권한 DNS에 기록. 이 예에서 SaaS 영역은`example.com`.
   ```txt
   _acme-challenge.example.com CNAME example.com.<COPIED_HOSTNAME>.
   ```

이 완료되면 Cloudflare는 두 TXT DCV 레코드를 배치합니다.`example.com`그리고 하나`*.example.com`- 에`example.com.<COPIED_HOSTNAME>`이름. CNAME 레코드는 Cloudflare를 허용하기 위해 위치에 머물 필요가 갱신에 대한 기록을 계속.

원하는 경우, 당신은 또한 수동으로 DCV 토큰을 꺼내 고객에게 공유 할 수 있습니다.

## 이동 도메인

당신은[다른 계정에 SaaS 영역을 이동](/fundamentals/manage-domains/move-domain/), 당신은 업데이트해야합니다`CNAME`새로운 hostname 값으로 기록합니다.

### 가동 시간

다운타임을 최소화하려면 다음 방법 중 하나를 살펴보고 고객을 내장하기 전에 인증서를 배포하십시오.

- [위임된 DCV](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/issue-and-validate/validate-certificates/delegated-dcv/): Cloudflare를 자동 갱신하기 위하여 Cloudflare를 허용하는 당신의 권위있는 DNS에 1 시간 기록.
- [TXT 검증](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/issue-and-validate/validate-certificates/txt/): 고객 추가`TXT`자신의 권한 DNS에 기록.
- [수동 HTTP 검증](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/issue-and-validate/validate-certificates/http/#http-manual): 추가`TXT`당신의 근원에 기록.

### 고객 노력

simplicity와 당신의 고객은 다운타임의 몇 분을 처리할 수 있는 경우에, 당신은 CloudflareQ에 의존할 수 있습니다[자동 HTTP 검증](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/issue-and-validate/validate-certificates/http/#http-automatic).

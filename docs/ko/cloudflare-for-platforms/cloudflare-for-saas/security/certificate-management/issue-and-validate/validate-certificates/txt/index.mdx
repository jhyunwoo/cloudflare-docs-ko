## 이용 시

일반적으로 사용할 수 없을 때 TXT 기반 DCV를 사용해야합니다.[HTTP 유효성](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/issue-and-validate/validate-certificates/http/)또는[위임된 DCV](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/issue-and-validate/validate-certificates/delegated-dcv/).

### Non-wildcard 사용자 정의 호스트 이름

사용자 정의 호스트 이름이 와일드 카드를 포함하지 않는 경우, Cloudflare는 항상 자동으로 DCV를 완료하려고합니다[HTTP 유효성](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/issue-and-validate/validate-certificates/http/#http-automatic)선택한 경우에도**사이트맵**당신의 검증 방법.

이 HTTP 유효성 검사는 당신의 고객 때문에 당신의 주문 hostname에 점유하고 그들에는 아무 것도 없는 성공해야 합니다[CAA 기록](/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/issue-and-validate/validate-certificates/troubleshooting/#certificate-authority-authorization-caa-records)선택한 인증 기관 차단.

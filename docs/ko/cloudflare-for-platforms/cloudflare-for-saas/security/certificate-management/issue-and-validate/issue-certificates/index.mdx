## 인증서 당국

API를 통해 사용자 정의 hostname을 만들면, 당신은 떠날 수 있습니다`certificate_authority`매개 변수는 "기본 CA"로 설정한다. 이 옵션으로 Cloudflare는 CA에서 인증서를 발급하는 데 도움이되는 인증서를 요청하기 전에 CAA 레코드를 확인합니다.

더 알아보기[이 인증서 당국 참고 자료 페이지](/ssl/reference/certificate-authorities/)Cloudflare는 SSL/TLS 인증서를 발급하는 데 사용됩니다.

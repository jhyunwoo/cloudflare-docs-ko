## 사용 사례

이 상황은 일반적으로 고객이 확장 된 검증 (EV) 인증서 ( "녹색 바")을 사용하거나 정보 보안 정책이 개인 키 생성에서 세 번째 당사자를 금지 할 때 발생합니다.

## 제한 사항

사용자 정의 인증서를 사용하는 경우 전체 인증서 수명주기 (니셜 업로드, 갱신, 후속 업로드)에 대해 책임집니다.

Cloudflare는 또한 이 유형의 공개적으로 믿을 수 있는 증명서를 받아들입니다:

- `SHA256WithRSA`
- `SHA1WithRSA`
- `ECDSAWithSHA256`

다른 유형의 인증서 또는 자기 서명 된 인증서를 업로드하려고하면 거절됩니다.

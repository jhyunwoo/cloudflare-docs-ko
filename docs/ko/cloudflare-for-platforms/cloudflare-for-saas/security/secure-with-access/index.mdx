Cloudflare Access는 가시성과 제어를 제공합니다.[사용자 정의 hostnames](/cloudflare-for-platforms/cloudflare-for-saas/domain-support/). ID, 장치 자세 및 기타에 따라 사용자를 허용하거나 차단할 수 있습니다.[액세스 규칙](/cloudflare-one/access-controls/policies/).

## 자주 묻는 질문

- 당신은 활성 사용자 정의 호스트 이름이 있어야합니다. 설정 지침을 위해, 참조[SaaS를 위한 Cloudflare 구성](/cloudflare-for-platforms/cloudflare-for-saas/start/getting-started/).
- SaaS 공급자 계정에서 Cloudflare Zero TrustXQ 플랜이 있어야 합니다. 더 알아보기[Zero Trust](/cloudflare-one/setup/).
- Cloudflare 또는 별도 Cloudflare 계정으로 외부 관리되는 경우 사용자 지정 호스트 이름에만 액세스 할 수 있습니다. 사용자 지정 호스트 이름 영역이 SaaS 영역과 같은 계정에 있다면 액세스 응용 프로그램은 적용되지 않습니다.

## 설치하기

1. SaaS 공급자 계정에서, 선택[Zero Trust](https://one.dash.cloudflare.com).
2. 오시는 길**오시는 길** > **이름 \***.
3. 제품정보**앱 추가**그리고, 신청의 유형을 위해, 선택**셀프 호스팅**.
4. 액세스 응용 프로그램에 대한 이름을 입력하고,**세션 기간**, 얼마나 자주 사용자의 선택[앱 토큰](/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/application-token/)유효기간
5. 제품정보**공공 hostname 추가**.
6. 제품 정보**입력 방법**, 선택*제품 정보*.
7. 내 계정**이름 \***, 당신의 주문 hostname를 입력하십시오 (예를 들면,`mycustomhostname.com`).
8. 자주 묻는 질문[자체 호스팅 응용 프로그램 생성 단계](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/)앱을 게시합니다.

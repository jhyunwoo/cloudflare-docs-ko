2개의 일반적인 목적을 위한 주문 이름 분석을 이용할 수 있습니다: 당신의 고객이 당신의 제품을 이용하고 당신의 고객을 가진 CloudflareXQ에 의해 제공된 이익을 공유하는 방법을 탐구하십시오.

이 분석은**사이트 Analytics**, **봇 분석**, **Cache 분석**, **보안 이벤트**·[다른 datasets](/analytics/graphql-api/features/data-sets/)이름 \*`clientRequestHTTPHost`이름 \*

:::참조

SaaS 응용 프로그램에 대한 Cloudflare의 계획은 사용자 정의 호스트 이름에 사용할 수있는 분석을 결정합니다.

:::

## 고객 사용법

사용자 정의 호스트 이름 분석을 사용하여 청구 및 인프라 결정과 조직을 돕기 위해 다음과 같은 질문에 답변 :

- "많은 총 요청이 귀하의 서비스로 얻는 방법?"
- "다른 것보다 더 많은 데이터를 전송하는 고객입니까?"
- "많은 글로벌 고객이 가지고 있으며 어디에서 배포합니까?"

고객이 다른 데이터보다 더 많은 데이터를 사용하는 경우 청구서를 늘릴 수 있습니다. 특정 지리적 영역에서 요청이 증가하면 해당 지역의 Origin 서버를 늘릴 수 있습니다.

사용자 정의 hostname 분석에 액세스하려면[대시보드를 사용하십시오](/analytics/faq/about-analytics/)그리고 필터로`Host`분야 또는[GraphQL API 사용](/analytics/graphql-api/)그리고 필터로`clientRequestHTTPHost`이름 \* 자세한 내용은 우리의 튜토리얼을 참조하십시오.[GraphQL로 hostname에 의한 HTTP 이벤트 조회](/analytics/graphql-api/tutorials/end-customer-analytics/).

## 고객에게 Cloudflare 데이터를 공유

사용자 정의 호스트 이름 분석으로, 당신은 또한 데이터를 포함하여 고객의 사이트 정보를 공유 할 수 있습니다:

- 얼마나 많은 페이지보기 그들의 사이트 수신.
- 사이트가 봇 트래픽의 큰 비율을 가지고 있는지 여부.
- 사이트가 빠른 방법.

사용자 정의 대시보드s를 구축하여 이 정보를 공유하여 개별 사용자 정의 호스트 이름 지정`clientRequestHTTPHost`주요연혁[모든 dataset](/analytics/graphql-api/features/data-sets/)이 필드를 포함합니다.

## 다운로드

[다운로드](/logs/logpush/)클라우드 스토리지 대상 또는 SIEM에 Cloudflare 제품에서 메타 데이터를 보냅니다.

사용 방법[제품정보](/logs/logpush/logpush-job/filters/)필터 기준에 따라 설정된 샘플 속도(또는 로그 altogether 포함)를 보낼 수 있습니다. 이 유연성은 사용자의 로그 볼륨을 크게 증가하지 않고 사용자 정의 호스트 이름에 대한 선택 로그를 유지할 수 있습니다.

필터링 가능[모든 Cloudflare 데이터 세트](/logs/logpush/logpush-job/datasets/zone/).

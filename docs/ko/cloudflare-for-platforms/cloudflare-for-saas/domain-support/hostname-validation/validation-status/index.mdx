당신은[사용자 정의 hostname을 유효](/cloudflare-for-platforms/cloudflare-for-saas/domain-support/hostname-validation/), 그 hostname는 몇몇 다른 상태에서 일 수 있습니다.

| 주요연혁        | 이름 \*                                                                                                                                                                                                               |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 관련 기사       | 사용자 정의 호스트 이름은 호스트 이름 유효성 검사입니다.                                                                                                                                                                                    |
| 지원하다        | Custom hostname은 hostname validation을 완료하고 유효하다.                                                                                                                                                                    |
| Active 재 배포 | 고객 호스트명은 유효하며 변경이 처리되었습니다.                                                                                                                                                                                          |
| 관련 기사       | 사용자 정의 호스트 이름은이 시간에 Cloudflare에 추가 할 수 없습니다. 사용자 정의 hostname은 이전에 CloudflareXQ와 관련이있었으며 남용을 위해 자랐습니다.<br /><br />Enterprise 고객이라면 고객 성공 관리자에 문의하십시오. 기타, 이메일`abusereply@cloudflare.com`웹 속성의 이름과이 웹 속성과 협회의 상세한 설명. |
| 지원하다        | Custom hostname은 유효하지 않습니다.**관련 기사**전체를 위해[유효성 검사](/cloudflare-for-platforms/cloudflare-for-saas/domain-support/hostname-validation/backoff-schedule/)또는 더 이상 떨어지는 기원에 포인트가 없습니다.                                   |
| 파일 형식       | Custom hostname은 영역에서 삭제되었습니다. 상태일 때 Occurs**지원하다**7일 이상.                                                                                                                                                           |

## 빠른 검증

custom hostname validation check를 다시 실행하려면, 선택**지원하다**대시보드에 또는 보냅니다`PATCH`요청하기[사용자 정의 호스트 이름 endpoint](/api/resources/custom_hostnames/methods/edit/). API를 사용하는 경우, 확인`--data`필드 포함`ssl`같은 객체`method`·`type`원래 요청으로.

호스트명이 있는 경우**지원하다**또는**파일 형식**상태, 새로 고침은 사용자 정의 hostname을 다시 설정합니다.**Pending 검증**.

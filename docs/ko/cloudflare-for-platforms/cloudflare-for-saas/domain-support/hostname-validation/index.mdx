Cloudflare는 사용자 정의 호스트 이름을 통해 프록시 트래픽을 할 수 있으므로 호스트 이름의 고객의 소유권을 확인해야합니다.

:::참조
custom hostname이 Cloudflare에 이미 있다면,[사전 검증 방법](/cloudflare-for-platforms/cloudflare-for-saas/domain-support/hostname-validation/pre-validation/)SaaS 영역의 트래픽을 이동하지 않습니다. 한 번만 일어날 것[DNS 대상](/cloudflare-for-platforms/cloudflare-for-saas/start/getting-started/#3-have-customer-create-cname-record)사용자 정의 호스트 이름의 변경은 SaaS 영역으로 전환합니다.
주요 특징

## 옵션 정보

다운타임을 최소화하는 것이 더 중요합니다.[사전 검증 방법](/cloudflare-for-platforms/cloudflare-for-saas/domain-support/hostname-validation/pre-validation/).

고객에 대한 사용의 용이가 더 중요합니다, 우리의 리뷰[실시간 검증 방법](/cloudflare-for-platforms/cloudflare-for-saas/domain-support/hostname-validation/realtime-validation/).

## 제한 사항

다른 CDN을 사용하는 사용자 정의 호스트 이름은 SaaS의 Cloudflare와 호환되지 않습니다. Cloudflare는 다른 CDN의 사용이 DNS 레코드를 손상하면 호스트 이름의 고객 소유권을 검증 할 수 있어야합니다. 호스트 이름 유효성은 실패합니다.

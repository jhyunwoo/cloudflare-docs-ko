당신은[사용자 정의 hostname을 유효](/cloudflare-for-platforms/cloudflare-for-saas/domain-support/hostname-validation/), 다음과 같은 오류 코드를 만날 수 있습니다.

| 오류 수정                                                                                       | 이름 \*                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Zone은 fallback 근원 세트가 없습니다.                                                                 | Fallback은 활동하지 않습니다.                                                                                                                                                   |
| Fallback 근원은 상태에 있습니다`initializing`, `pending_deployment`, `pending_deletion`, 또는`deleted`. | Fallback은 활동하지 않습니다.                                                                                                                                                   |
| 사용자 지정 hostname 하지 않습니다`CNAME`이 지역에.                                                        | 지역은 없습니다[apex 프록시 제목](/cloudflare-for-platforms/cloudflare-for-saas/start/advanced-settings/apex-proxying/)그리고 사용자 정의 hostname은 CNAME이 영역에 있지 않습니다.                    |
| 아무도`A`또는`AAAA`이 계정과 사전 생성 된 소유권 검증 토큰이 소유되지 않았습니다.                                          | 계정이 있습니다[apex 프록시 활성화](/cloudflare-for-platforms/cloudflare-for-saas/start/advanced-settings/apex-proxying/)그러나 사용자 정의 hostname은 hostname validation check를 실패`A`이름 \* |
| 이 계정과 사전 생성 된 소유권 검증 토큰은 찾을 수 없습니다.                                                         | 호스트명은 하지 않습니다.`CNAME`지역 또는 지역 없음`A`/`AAAA`지역별 IP를 기록합니다.                                                                                                               |

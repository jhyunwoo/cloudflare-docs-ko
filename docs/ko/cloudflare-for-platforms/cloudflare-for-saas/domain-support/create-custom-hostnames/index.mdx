## 64자 이상 호스트명

일반 이름(CN) 제한은 64자 제한(64자 제한)[RFC 5280년](https://www.rfc-editor.org/rfc/rfc5280.html)). 이 길이를 초과하는 호스트 이름이 있다면, 설정할 수 있습니다.`cloudflare_branding`으로`true`사용자 정의 호스트명을 만들 때[API를 통해](/api/resources/custom_hostnames/methods/create/).

```txt

"ssl": {
    "cloudflare_branding": true
  }

```

Cloudflare 브랜딩은`sni.cloudflaressl.com`인증서 Common Name (CN)로 추가되며 긴 hostname은 Title Alternative Name (SAN)의 일부로 포함됩니다.

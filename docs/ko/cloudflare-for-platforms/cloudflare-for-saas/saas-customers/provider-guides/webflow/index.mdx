## 이름 \*

O2O의 장점은 Cloudflare 영역의 서비스 및 설정을 적용하는 것이 포함됩니다. WAF, Bot 관리, 대기실 등 Webflow 환경에 대한 트래픽이 지속됩니다.

## 어떻게 작동합니까?

O2O가 다른 Cloudflare 설정보다 더 자세한 내용은 참조[O2O는 어떻게 작동합니까?](/cloudflare-for-platforms/cloudflare-for-saas/saas-customers/how-it-works/).

## 이름 \*

Webflow 고객은 Cloudflare 지역 계획에 O2O를 활성화 할 수 있습니다.

Cloudflare Zone 내의 특정 호스트 이름을 위해 O2O를 활성화하려면[지원하다](/dns/manage-dns-records/how-to/create-dns-records/#create-dns-records)견적 요청`CNAME`Webflow 사이트 이름과 함께 DNS 기록. Webflow의 도메인 추가 설정은 다른 유효성 검사 단계를 통해 수행됩니다.

| 제품정보    | 이름 \*           | 제품정보              | 프록시 상태 |
| ------- | --------------- | ----------------- | ------ |
| `CNAME` | `<YOUR_DOMAIN>` | `cdn.webflow.com` | 견적 요청  |

### DNS CAA 레코드

Webflow는 Let’s Encrypt 및 Google Trust Services를 사용하여 판매자 도메인에 SSL/TLS 인증서를 발급합니다. DNS CAA 레코드를 추가하면 선택해야 합니다.**암호화하자**또는**Google Trust 서비스**인증 기관 (CA) 또는 HTTPS 연결이 실패 할 수 있습니다.

더 자세한 내용은 참조[CAA 기록](/ssl/edge-certificates/caa-records/#caa-records-added-by-cloudflare).

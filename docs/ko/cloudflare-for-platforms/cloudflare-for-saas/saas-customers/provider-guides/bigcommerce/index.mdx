## 어떻게 작동합니까?

O2O가 다른 Cloudflare 설정보다 더 자세한 내용은 참조[O2O는 어떻게 작동합니까?](/cloudflare-for-platforms/cloudflare-for-saas/saas-customers/how-it-works/).

## 이름 \*

BigCommerce 고객은 Cloudflare 지역 계획에 O2O를 활성화 할 수 있습니다.

계정에서 O2O를 활성화하려면[지원하다](/dns/manage-dns-records/how-to/create-dns-records/#create-dns-records)한국어`CNAME`DNS 레코드.

| 제품정보    | 이름 \*             | 제품정보                      | 프록시 상태 |
| ------- | ----------------- | ------------------------- | ------ |
| `CNAME` | `<YOUR_HOSTNAME>` | `shops.mybigcommerce.com` | 견적 요청  |

:::참조

BigCommerce 설정에 대한 자세한 내용은 참조[고객지원](https://support.bigcommerce.com/s/article/Cloudflare-for-Performance-and-Security?language=en_US#orange-to-orange).

도메인을 활성화할 수 없는 경우[DNS 레코드](/dns/proxy-status/), 당신의 계정 팀에 도달.

:::

## 어떻게 작동합니까?

O2O가 활성화되면 트래픽 경로에 대한 자세한 내용은 참조[O2O는 어떻게 작동합니까?](/cloudflare-for-platforms/cloudflare-for-saas/saas-customers/how-it-works/).

## 이름 \*

Kinsta 고객은 어떤 Cloudflare 지역 계획에 O2O를 활성화 할 수 있습니다.

Cloudflare 영역 내에서 특정 호스트 이름을 위해 O2O를 활성화하려면[지원하다](/dns/manage-dns-records/how-to/create-dns-records/#create-dns-records)견적 요청`CNAME`Kinsta 사이트 이름과 함께 DNS 레코드. Kinsta의 도메인 추가 설정은 다른 유효성 검사 단계를 통해 이동합니다.

| 제품정보    | 이름 \*             | 제품정보                            | 프록시 상태 |
| ------- | ----------------- | ------------------------------- | ------ |
| `CNAME` | `<YOUR_HOSTNAME>` | `sitename.hosting.kinsta.cloud` | 견적 요청  |

### Cloudflare 관리 인증서

Cloudflare 관리 인증서를 활성화하려고 시도 할 때 SSL 오류가 발생하면 확인`CAA`명령으로 도메인 이름에 기록`dig +short example.com CAA`.

당신이해야 할 경우`CAA`기록, SSL 인증서를 발급받을 수 있는지 확인[Cloudflare에 의해 지원되는 증명서 권위](/ssl/reference/certificate-authorities/).

## 어떻게 작동합니까?

O2O가 다른 Cloudflare 설정보다 더 자세한 내용은 참조[O2O는 어떻게 작동합니까?](/cloudflare-for-platforms/cloudflare-for-saas/saas-customers/how-it-works/).

## 이름 \*

WP 엔진 고객은 어떤 Cloudflare 지역 계획든지에 O2O를 활성화할 수 있습니다.

Cloudflare 영역 내에서 특정 호스트 이름을 위해 O2O를 활성화하려면[지원하다](/dns/manage-dns-records/how-to/create-dns-records/#create-dns-records)견적 요청`CNAME`뒤에 오는 WP 엔진 CNAMEs의 한 표적을 가진 DNS 기록. 어떤 WP 엔진 CNAME는 당신의 현재에 달려 있을 것입니다[WP 엔진 네트워크 유형](https://wpengine.com/support/network/).

| 제품정보    | 이름 \*             | 제품정보                                                                           | 프록시 상태 |
| ------- | ----------------- | ------------------------------------------------------------------------------ | ------ |
| `CNAME` | `<YOUR_HOSTNAME>` | `wp.wpewaf.com`(Global Edge 보안)<br />또는<br />`wp.wpenginepowered.com`(고급 네트워크) | 견적 요청  |

:::참조

WP Engine 설정에 대한 질문, 참조[고객지원](https://wpengine.com/support/wordpress-best-practice-configuring-dns-for-wp-engine/#Point_DNS_Using_CNAME_Flattening).

도메인을 활성화할 수 없는 경우[DNS 레코드](/dns/proxy-status/), 당신의 계정 팀에 도달.

:::

### SSL 오류 해결

SSL 오류가 발생하면 확인`CAA`이름 \*

당신이해야 할 경우`CAA`기록, SSL 인증서를 발급받을 수 있는지 확인`letsencrypt.org`.

더 자세한 내용은 참조[CAA 레코드 추가](/ssl/edge-certificates/caa-records/).

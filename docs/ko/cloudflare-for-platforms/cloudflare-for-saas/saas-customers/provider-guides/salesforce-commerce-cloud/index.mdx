## 어떻게 작동합니까?

O2O가 활성화되면 트래픽 경로에 대한 자세한 내용은 참조[O2O는 어떻게 작동합니까?](/cloudflare-for-platforms/cloudflare-for-saas/saas-customers/how-it-works/).

## 이름 \*

O2O를 활성화하려면 다음을 요구합니다.

1. SFCC 프록시 영역으로 SFCC 환경을 구성해야 합니다. 현재 "SFCC Legacy Zone"이 있다면 O2O를 활성화 할 수 없습니다.
   - SFCC 구성의 다른 유형에 대한 자세한 내용은 참조[SFCC 프록시 영역에서 Salesforce FAQ](https://help.salesforce.com/s/articleView?id=cc.b2c_ecdn_proxy_zone_faq.htm\&type=5).
   - SFCC Proxy Zone에 SFCC 환경을 마이그레이션하는 방법에 대한 지침은 참조[SFCC Legacy Zone to SFCC 프록시 영역 마이그레이션 가이드](https://help.salesforce.com/s/articleView?id=cc.b2c_migrate_legacy_zone_to_proxy_zone.htm\&type=5).
2. 엔터프라이즈 플랜의 Cloudflare 영역.

위의 요구 사항을 충족하면 O2O는 호스트 이름 당 활성화 할 수 있습니다. Cloudflare 영역 내에서 특정 호스트 이름을 위해 O2O를 활성화하려면[지원하다](/dns/manage-dns-records/how-to/create-dns-records/#create-dns-records)SFCC 비즈니스 관리자가 제공하는 CNAME의 대상을 가진 Proxied CNAME DNS 레코드, 이는 SFCC 고객에 의해 사용되는 대시보드이다.

SFCC Business Manager가 제공하는 CNAME은`commcloud.prod-abcd-example-com.cc-ecdn.net`그리고 3개의 명백한 부속을 포함합니다. SFCC에 각 hostname 라우팅 트래픽을 위해 SFCC 환경에 맞는 예를 들어 CNAME의 각 부분을 업데이트해야합니다.

1. **환경 정책**: `prod`본문 바로가기`prod`또는`dev`또는`stg`.
2. **뚱 베어**: `abcd`SFCC에 의해 할당된 Realm ID로 변경되어야 합니다.
3. **도메인 이름**: `example-com`도메인 이름을 hyphenated 형식으로 변경해야합니다.

| 제품정보    | 이름 \*             | 제품정보                                          | 프록시 상태 |
| ------- | ----------------- | --------------------------------------------- | ------ |
| `CNAME` | `<YOUR_HOSTNAME>` | `commcloud.prod-abcd-example-com.cc-ecdn.net` | 견적 요청  |

O2O를 위해 제대로 구성하려면 SFCC CNAME을 대상으로 적절한 DNS 레코드를 확인하십시오.**기타 제품**. SFCC CNAME을 직접 타겟팅하여 Cloudflare 영역에서 다른 Proxied DNS 레코드를 타겟팅하여 SFCC CNAME을 타겟팅하지 마십시오.

### Cloudflare 관리 인증서

Cloudflare 관리 인증서를 활성화하려고 시도 할 때 SSL 오류가 발생하면 확인`CAA`명령으로 도메인 이름에 기록`dig +short example.com CAA`.

당신이해야 할 경우`CAA`기록, SSL 인증서를 발급받을 수 있는지 확인[Cloudflare에 의해 지원되는 증명서 권위](/ssl/reference/certificate-authorities/).

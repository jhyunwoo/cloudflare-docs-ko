## 어떻게 작동합니까?

O2O가 다른 Cloudflare 설정보다 더 자세한 내용은 참조[O2O는 어떻게 작동합니까?](/cloudflare-for-platforms/cloudflare-for-saas/saas-customers/how-it-works/).

## 이름 \*

O2O는 호스트 이름에 의해 활성화되므로 Cloudflare 영역 내에서 특정 호스트 이름에 O2O를 활성화하십시오.[지원하다](/dns/manage-dns-records/how-to/create-dns-records/#create-dns-records)견적 요청`CNAME`해당 HubSpot CNAME의 대상과 DNS 레코드. 어떤 HubSpot CNAME 대상은 현재에 따라 달라집니다.[HubSpot 프록시 설정](https://developers.hubspot.com/docs/cms/developer-reference/reverse-proxy-support#configure-the-proxy).

| 제품정보    | 이름 \*             | 제품정보                                   | 프록시 상태 |
| ------- | ----------------- | -------------------------------------- | ------ |
| `CNAME` | `<YOUR_HOSTNAME>` | `<HUBID>.sites-proxy.hscoscdn<##>.net` | 견적 요청  |

:::참조

HubSpot 설정에 대한 질문은 참조[HubSpot의 역 프록시 지원 가이드](https://developers.hubspot.com/docs/cms/developer-reference/reverse-proxy-support).

:::

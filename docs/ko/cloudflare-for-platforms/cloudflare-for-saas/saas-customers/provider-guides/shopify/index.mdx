## 이름 \*

O2O 라우팅은 Cloudflare 영역에 특히 Shopify 트래픽을 사용자 정의 할 수 있습니다.

## 어떻게 작동합니까?

O2O가 다른 Cloudflare 설정보다 더 자세한 내용은 참조[O2O는 어떻게 작동합니까?](/cloudflare-for-platforms/cloudflare-for-saas/saas-customers/how-it-works/).

당신은[Shopify 웹 사이트에 O2O 라우팅 설정](#enable), Cloudflare는 이 SaaS 공급자를 위한 특정한 윤곽을 가능하게 합니다. 현재 다음을 포함합니다:

- Workers 및 스니펫은 비활성화됩니다.`/checkout`URI 경로.

## 이름 \*

Cloudflare 영역에 O2O를 활성화 할 수 있습니다.

계정에서 O2O를 활성화하려면[지원하다](/dns/manage-dns-records/how-to/create-dns-records/#create-dns-records)한국어`CNAME`DNS 레코드.

| 제품정보    | 이름 \*                | 제품정보                  | 프록시 상태 |
| ------- | -------------------- | --------------------- | ------ |
| `CNAME` | `<YOUR_SHOP_DOMAIN>` | `shops.myshopify.com` | 견적 요청  |

새로운 DNS 레코드를 저장하면 Cloudflare 대시보드는 CNAME 레코드 값 옆에 Shopify 아이콘을 표시합니다. 예를 들면:

![Cloudflare 대시보드는 특정 Shopify 아이콘을 Shopify에 대한 CNAME DNS 항목을 보여주는](~/assets/images/cloudflare-for-platforms/provider-guides/shopify-dns-entry.png)

:::caution\[ 항상 HTTPS를 사용하지 않는]

사용 안함[항상 HTTPS 사용](/ssl/edge-certificates/additional-options/always-use-https/)Shopify와 O2O 시나리오에서 설정.

이 설정은 모든 요청에 대한 리디렉션을 강제합니다.`/.well-known/acme-challenge/`HTTP-01 도메인 검증에 사용되는 경로. 이것은 자동으로 제공하거나 SSL 인증서를 갱신하여 도메인에 대한 암호화를 방지합니다.

대신, 생성[관련 규칙](/rules/url-forwarding/single-redirects/create-dashboard/)위에서 언급 한 검증 경로를 제외하고 HTTPS를 시행하기 위해.

:::

Shopify 설정에 대한 질문, 참조[고객지원](https://help.shopify.com/en/manual/domains/add-a-domain/connecting-domains/connect-domain-manual).

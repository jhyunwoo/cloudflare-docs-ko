SaaS 공급자로서, SaaS를 위한 Cloudflare를 구성하고 관리할 수 있습니다.[API를 통해](/api/)오히려[Cloudflare 대시보드](https://dash.cloudflare.com/). 아래는 생성, 편집 및 사용자 정의 hostname을 삭제하는 관련 API 호출, 뿐만 아니라 모니터링, 업데이트, 및 삭제 fallback 기원. 더 자세한 내용은 찾을 수 있습니다[Cloudflare API 문서](/api/).

***

## 사용자 이름

| 끝점                                                                   | 지원하다                                                                                 |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| [사용자 정의 hostnames 목록](/api/resources/custom_hostnames/methods/list/) | 사용 방법`page`추가 페이지를 당기는 매개 변수. 추가하기`hostname`특정 호스트명을 검색하는 매개 변수.                     |
| [사용자 정의 hostname](/api/resources/custom_hostnames/methods/create/)   | 내 계정`validation_records`응답의 개체, 사용`txt_name`·`txt_record`사용자 정의 hostname을 유효성 검사합니다. |
| [Custom hostname 세부사항](/api/resources/custom_hostnames/methods/get/) |                                                                                      |
| [사용자 정의 hostname](/api/resources/custom_hostnames/methods/edit/)     | 전송할 때`ssl`기존의 값과 일치하는 객체는 hostname이 도메인 제어 유효성(DCV)을 재시작해야 합니다.                      |
| [사용자 정의 hostname](/api/resources/custom_hostnames/methods/delete/)   | 또한 관련 SSL/TLS 인증서를 삭제합니다.                                                            |

## 가을의 기원

API는 다음과 같은 엔드포인트를 포함합니다.[관련 상품](/cloudflare-for-platforms/cloudflare-for-saas/start/getting-started/#1-create-fallback-origin)주문 hostname의:

- [지금 구매](/api/resources/custom_hostnames/subresources/fallback_origin/methods/get/)
- [업데이트 fallback 기원](/api/resources/custom_hostnames/subresources/fallback_origin/methods/update/)
- [fallback 근원을 제거하십시오](/api/resources/custom_hostnames/subresources/fallback_origin/methods/delete/)

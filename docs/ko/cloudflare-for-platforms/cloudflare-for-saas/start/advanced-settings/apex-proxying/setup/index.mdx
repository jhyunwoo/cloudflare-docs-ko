### 3. 고객은 DNS 기록을 창조합니다

사용자 정의 호스트 이름 설정을 완료하려면 고객은 A 또는 CNAME 레코드 중 하나를 설정할 수 있습니다.

:::참조

CNAME 레코드를 사용할 수 있도록 고객을 원하면 완료해야합니다.[정상적인 설정 과정](/cloudflare-for-platforms/cloudflare-for-saas/start/getting-started/)또한.

:::

#### 이름 \*

고객이 자신의 권위 있는 DNS 공급자에 기록하는 경우, 그들은 당신의 계정에 할당된 IP 접두사에 그들의 hostname을 지적해야 합니다. 당신은 또한 그들이 apex 프록시에 사용하려는 특정 IP로 포인트를해야합니다 - 당신은 정적 IP 또는 BYOIP가 있는 경우, 귀하의 계정과 관련된 IP의 모든 고객 포인트, 유효성 검사가 실행됩니다.

<Render file="get-started-check-statuses" product="cloudflare-for-platforms" />

고객의 기록은 다음과 같습니다.

```txt
example.com.  60  IN  A   192.0.2.1
```

#### CNAME 기록

고객이 선호하는 DNS에서 CNAME 레코드를 사용한다면 호스트명을 호스트명에 할당해야 합니다.[CNAME 대상](/cloudflare-for-platforms/cloudflare-for-saas/start/getting-started/#2-optional-create-cname-target) [^1].

<Render file="get-started-check-statuses" product="cloudflare-for-platforms" />

고객의 CNAME 레코드는 다음과 같습니다.

```txt
mystore.com CNAME customers.saasprovider.com
```

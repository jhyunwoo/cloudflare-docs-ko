## 이름 \*

SaaS를 위한 일반 Cloudflare[설치하기](/cloudflare-for-platforms/cloudflare-for-saas/start/getting-started/), 당신의 고객 노선 교통은 당신의 hostname에 창조해서`CNAME`CNAME 대상에 대한 기록 지적.

그러나 대부분의 DNS 공급자는 허용하지 않습니다.`CNAME`영역의 루트에 기록[^1]. 이것은 고객이 vanity 도메인으로 하위 도메인을 사용해야한다는 것을 의미합니다 (`shop.example.com`) 대신 자신의 도메인 apex (`example.com`).

이 제한은 apex 프록시에 적용되지 않습니다. Cloudflare는 IP 접두사 세트를 할당합니다 - 관련 비용, 당신의 계정에 도달 - 계정에 (또는 당신이 가지고 있는 경우에 당신의 자신의 사용[BYOIP의 특징](/byoip/)). 이것은 고객이 표준을 만들 수 있다는 것을 의미합니다`A`도메인 apex를 지원할 수 있는 도메인에 트래픽을 경로를 기록합니다.

[^1]: Cloudflare는 이 기능을 통해 제공합니다[CNAME 평탄화](/dns/cname-flattening/).

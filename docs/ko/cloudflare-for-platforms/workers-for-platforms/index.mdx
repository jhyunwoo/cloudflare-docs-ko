  신뢰할 수없는 코드를 실행하는 다중 계층 플랫폼을 구축, 격리 샌드 박스.
</Description>

플랫폼에 대한 Workers는 고객에게 서면 신뢰할 수없는 코드를 실행하거나 AI에 의해, 안전한 호스팅 샌드 박스에서. 각 고객은 자신의 노동자, 안전 및 고립 된 환경에서 코드를 실행합니다.

## 플랫폼에 대한 Workers를 사용할 때

당신이 필요로 할 때 플랫폼에 Workers를 사용하십시오:

- **스케일에서 신뢰할 수없는 코드를 실행**- 고객에 의해 작성된 코드를 실행하거나 안전한 샌드박스에서 AI에 의해 생성 된, 응용 프로그램의 무제한 번호를 배포 할 수있는 능력.
- **멀티텐트 플랫폼 구축**- 각 고객에게 10ants 사이 완전한 별거를 가진 자신의 고립된 compute 환경을 주십시오.
- **고객에게 Cloudflare의 개발자 플랫폼을 확장하십시오**- 사용[관련 제품](/cloudflare-for-platforms/workers-for-platforms/configuration/bindings/)KV 상점, D1 데이터베이스, R2Q 저장 및 더 많은 것에 각 고객 접근을 주기 위하여. 고객이 플랫폼을 통해 관리되는 동일한 강력한 도구를 얻습니다.
- **각 응용 프로그램을 자신의 도메인**- 도메인의 하위 도메인 아래에 호스트 응용 프로그램 (예를 들어,`customer-name.myplatform.com`) 또는 통합[사용자 정의 hostnames](/cloudflare-for-platforms/cloudflare-for-saas/domain-support/)고객에게 자신의 도메인을 사용할 수 있도록합니다.

## 주요 특징

플랫폼용 Workers는 고객의 코드를 관리하고 제어하는 도구를 제공합니다:

- **[주문 제한](/cloudflare-for-platforms/workers-for-platforms/configuration/custom-limits/)**- CPU 시간과 subrequests에 per-customer 한계를 설정합니다.
- **[옵션 정보](/cloudflare-for-platforms/workers-for-platforms/configuration/observability/)**- 네임스페이스에서 모든 사용자 WorkersXQ의 로그와 메트릭스를 수집합니다. Datadog, Splunk 및 Grafana와 같은 타사 플랫폼에 수출.
- **[이름 \*](/cloudflare-for-platforms/workers-for-platforms/configuration/tags/)**- 고객 ID, 플랜 유형 또는 환경과 같은 맞춤 태그로 사용자 Workers를 구성, 검색 및 필터링합니다.

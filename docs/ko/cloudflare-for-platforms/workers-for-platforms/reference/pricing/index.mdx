플랫폼 유료 계획을위한 Workers는**월간 $ 25**. 플랫폼을 위한 Workers는 구매될 수 있습니다[Cloudflare dashboard](https://dash.cloudflare.com/?to=/:account/workers-for-platforms).

플랫폼을위한 Workers는 다음과 같은 사용 할당 및 초과 가격과 함께 제공됩니다.

|   | 제품정보<sup>1</sup> <sup>2</sup>              | 이름 \* | CPU 시간<sup>2</sup>                                                                                                                                                                                                                                     | 스크립트                                  |
| - | ------------------------------------------ | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------- |
|   | 달 당 포함되는 20백만개의 요구<br /><br />+$0.30 추가 백만 | 제한 없음 | 달 당 포함되는 60백만개의 CPU milliseconds<br /><br />추가 백만 CPU milliseconds 당 +$0.02<br /><br />직업 당 CPU 시간의 최대 30 초<br />CPU 시간의 최대 15 분 당[Cron 방아쇠](/workers/configuration/cron-triggers/)또는[Queue 소비자](/queues/configuration/javascript-apis/#consumer)관련 기사 | 1000 스크립트<br /> <br />+$0.02 추가 스크립트당 |

<sup>1</sup>직장인에게 Inbound 요청. Cloudflare는 청구하지 않습니다[구독하기](/workers/platform/limits/#subrequests)당신은 당신의 노동자에게서 합니다.<br /> <sup>2</sup>플랫폼에 대한 Workers는 체인에 대한 1 요청만을 청구합니다.[회사 소개](/cloudflare-for-platforms/workers-for-platforms/how-workers-for-platforms-works/#dynamic-dispatch-worker) -> [사용자 작업자](/cloudflare-for-platforms/workers-for-platforms/how-workers-for-platforms-works/#user-workers) -> [아웃바운드 Worker](/cloudflare-for-platforms/workers-for-platforms/configuration/outbound-workers/). CPU 시간은 이 Workers의 맞은편에 위탁됩니다.

## 예 가격:

플랫폼 프로젝트를 위한 Workers는 달 당 100백만개의 요청을 봉사하고, 요구 당 CPU 시간의 평균 10 milliseconds (ms)를 사용하고 1200의 스크립트를 이용하고 다음과 같이 예상된 비용이 있을 것입니다:

|            | 월간 비용  | 제품 정보                                                                                |
| ---------- | ------ | ------------------------------------------------------------------------------------ |
| **이름 \***  | $25.00 |                                                                                      |
| **제품정보**   | $24.00 | (100,000,000 요청 - 20,000,000 포함 요청) / 1,000,000 \* $ 0.30                            |
| **CPU 시간** | $18.80 | (요청 당 CPU 시간의 (10 ms \* 100,000,000 요청) - 60,000,000 포함 CPU ms) / 1,000,000 \* $0.02 |
| **스크립트**   | $4.00  | (1200 스크립트 - 1000 포함 스크립트) \* $0.02                                                  |
| **전체보기**   | $71.80 |                                                                                      |

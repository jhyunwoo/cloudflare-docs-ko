## 스크립트 제한

Cloudflare는 플랫폼 고객을 위한 WorkersXQ를 위한 무제한 스크립트를 제공합니다.

## `cf`기타 제품

더 보기[`cf`기타 제품](/workers/runtime-apis/request/#the-cf-property-requestinitcfproperties)요청의 Cloudflare-specific 속성이 포함되어 있습니다. 이 필드는 접근할 수 없습니다.[사용자 Workers](/cloudflare-for-platforms/workers-for-platforms/how-workers-for-platforms-works/#user-workers)이 객체의 일부 필드가 민감하기 때문에 기본적으로 Cloudflare 기능을 조작하는 데 사용할 수 있습니다 (예를 들어,`cacheKey`, `resolveOverride`, `scrapeShield`.)

오시는 길`cf`객체, 당신은 활성화해야합니다[신뢰할 수있는 모드](/cloudflare-for-platforms/workers-for-platforms/reference/worker-isolation/#trusted-mode)namespace에 대해 namespace에서 모든 Worker 코드를 제어하는 경우만 활성화합니다.

## 튼튼한 Object namespace 제한

플랫폼에 대한 Workers는 내구성 오브젝트 네임스페이스의 수에 제한이 없습니다.

## 캐시 API

고립을 위해,`caches.default`namespaced 스크립트가 비활성화됩니다. 캐시에 대한 자세한 내용을 보려면, 참조[캐시가 어떻게 작동합니까?](/workers/reference/how-the-cache-works/).

## 이름 \*

스크립트당 최대 8개의 태그를 설정할 수 있습니다. 특별한 문자를 피하십시오`,`·`&`태그를 남길 때.

## Gradual 배포

[Gradual 배포](/workers/configuration/versions-and-deployments/gradual-deployments/)아직 사용자 Workers를 위해 지원되지 않습니다. 사용자 WorkersXQ로 만든 변경은 트래픽의 100%에 할당된 새로운 버전을 만듭니다.

시험의 변화[동적인 파견 노동자](/cloudflare-for-platforms/workers-for-platforms/how-workers-for-platforms-works/#dynamic-dispatch-worker)로컬로 동적 파견 노동자를 실행하지만 Workers에 연결하여 Cloudflare.

:::참조
생산에 배포하기 전에 안전한 변화를 테스트하기 위해 staging namespace를 사용하여 고려하십시오.
주요 특징

이것은 도움이 될 때:

- **시험 여정 변화**업데이트가 배포된 사용자 Workers
- **새로운 미들웨어 추가**인증, 제한, 또는 동적 파견 노동자에 로그인
- **문제 해결**배포된 사용자 Workers

### 원격 파견 네임스페이스를 사용하는 방법

동적 파견 노동자의 Wrangler 파일에서 구성[비밀번호](/workers/wrangler/configuration/#dispatch-namespace-bindings-workers-for-platforms)원격 네임스페이스에 연결하기[`remote = true`](/workers/development-testing/#remote-bindings):

<WranglerConfig>
  ```jsonc title="wrangler.jsonc"
  {
    "dispatch_namespaces": [
      {
        "binding": "DISPATCH_NAMESPACE",
        "namespace": "production",
        "remote": true
  		}
    ]
  }
  ```
</WranglerConfig>

이것은 로컬에서 원격으로 연결되는 파견 노동자를 말합니다.`production`네임스페이스 당신이 실행할 때`wrangler dev`, 당신의 Dispatch Worker는 그 네임스페이스에 배포된 User WorkersXQ에 요청을 전달합니다.

로컬 개발 중에 원격 바인딩에 대한 자세한 내용은 참조[원격 바인딩 문서](/workers/development-testing/#remote-bindings).

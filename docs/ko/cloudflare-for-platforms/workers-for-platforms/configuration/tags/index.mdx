사용 태그를 구성, 검색, 필터 사용자 Workers 스케일. 꼬리표 Workers는 고객 ID, 계획 유형, 프로젝트 ID, 또는 환경에 기초를 두었습니다. 당신은 사용자 Workers를 태그 한 후, 당신은 특정 고객을위한 모든 WorkersXQ를 삭제 같은 대량 작업을 수행 할 수 있습니다.

:::참조

스크립트당 최대 8개의 태그를 설정할 수 있습니다. 특별한 문자를 피하십시오`,`·`&`태그를 남길 때.

:::

## dashboard를 통해 태그 추가

1. 오시는 길**플랫폼을위한 Workers**Cloudflare dashboard에서 네임스페이스를 선택하세요.
2. 목록에서 사용자 작업자를 선택합니다.
3. 오시는 길**계정 설정** > **이름 \***.
4. 태그 추가 (예를 들어,`customer-123`, `pro-plan`, `production`).
5. 제품정보**제품 정보**.

Workers를 태그로 검색하고 필터링 할 수 있습니다.

## 태그 API reference

완전한 API 문서의 경우, 참조[플랫폼 API를 위한 Workers](/api/resources/workers_for_platforms/subresources/dispatch/subresources/namespaces/subresources/scripts/subresources/tags/).

### 스크립트 태그

Worker 스크립트에 대한 모든 태그를 Fetch합니다.

<APIRequest method="GET" path="/accounts/{account_id}/workers/dispatch/namespaces/{dispatch_namespace}/scripts/{script_name}/tags" />

### 설정 스크립트 태그

Worker 스크립트에서 모든 태그를 대체합니다. 요청이 제거되지 않은 기존 태그.

<APIRequest method="PUT" path="/accounts/{account_id}/workers/dispatch/namespaces/{dispatch_namespace}/scripts/{script_name}/tags" />

### 단일 태그 추가

기존 태그에 영향을 미치지 않고 Worker 스크립트에 하나의 태그를 추가합니다.

<APIRequest method="PUT" path="/accounts/{account_id}/workers/dispatch/namespaces/{dispatch_namespace}/scripts/{script_name}/tags/{tag}" />

### 단일 태그 삭제

Worker 스크립트에서 하나의 태그를 제거하십시오.

<APIRequest method="DELETE" path="/accounts/{account_id}/workers/dispatch/namespaces/{dispatch_namespace}/scripts/{script_name}/tags/{tag}" />

### 태그로 Workers 필터

태그 필터와 일치하는 모든 Workers를 나열합니다. 제품 정보`tag:yes`기타 제품`tag:no`다음을 제외합니다.

<APIRequest method="GET" path="/accounts/{account_id}/workers/dispatch/namespaces/{dispatch_namespace}/scripts" parameters={{ tags: "production:yes" }} />

### 태그로 Workers 삭제

태그 필터와 일치하는 Workers를 삭제합니다. 클라이언트가 플랫폼을 떠난 때 대량 삭제 WorkersXQ에 이것을 사용하십시오.

<APIRequest method="DELETE" path="/accounts/{account_id}/workers/dispatch/namespaces/{dispatch_namespace}/scripts" parameters={{ tags: "customer-123:yes" }} />

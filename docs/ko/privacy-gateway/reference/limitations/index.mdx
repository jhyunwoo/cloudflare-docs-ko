최종 사용자는 Cloudflare가 웹 사이트 및 서비스가 개인 정보 보호 게이트웨이를 통해 전달되는 요청에서 사용자 데이터를 식별하지 못하도록 할 수 없다는 것을 인식해야합니다. 이름, 이메일 주소 및 전화번호와 같은 정보를 포함합니다.

시간 :[개인정보처리방침](/privacy-gateway/get-started/), Cloudflare 제품의 대다수는 당신의 신청과 호환이 됩니다.

그러나 다음 제품은 호환되지 않습니다 :

- [API Shield](/api-shield/): [Schema 검증](/api-shield/security/schema-validation/)·[API 검색](/api-shield/security/api-discovery/)Cloudflare는 요청 URL을 볼 수 없습니다.
- [캐시](/cache/): 애플리케이션 콘텐츠의 캐싱은 클라이언트와 게이트웨이가 암호화되기 때문에 더 이상 가능하지 않습니다.
- [WAF](/waf/): Cloudflare가 요청 또는 응답 내용을 볼 수 없기 때문에 요청 내용에 근거를 둔 규칙은 지원되지 않습니다.

개인 정보 보호 게이트웨이는 Cloudflare의 글로벌 네트워크에 배포된 관리 게이트웨이 서비스로 Oblivious HTTP IETF 표준을 구현하여 애플리케이션 백엔드에 연결할 때 클라이언트 프라이버시를 개선합니다.

OHTTP는 클라이언트와 서버 사이에 릴레이라고 불리는 신뢰할 수있는 타사 (Cloudflare)를 소개합니다. 릴레이의 목적은 클라이언트에서 서버로 요청을 전달하고, 서버에서 클라이언트로 응답을 전달하는 것 같다. 이 메시지는 클라이언트와 서버간에 암호화됩니다. 릴레이는 클라이언트가 상호 작용하는 서버보다 애플리케이션 데이터의 아무것도 배울 수 있습니다.

개인 정보 보호 정책[Cloudflare의 개인정보 처리방침](https://www.cloudflare.com/privacypolicy/).

## Cloudflare 참조

Cloudflare는 개인 정보 보호 게이트웨이 서비스를 통해 암호화 된 응용 프로그램 HTTP 요청의 내용을 볼 수 없습니다. 클라이언트가 먼저 Cloudflare의 글로벌 네트워크 인 Cloudflare에서 운영되는 OHTTP 릴레이 서버에 연결하기 때문에 다음 정보를 볼 수 있습니다. 연결 장치의 IP 주소, 응용 프로그램 서비스는 DNS 이름 및 IP 주소를 포함하여 사용되며, 로그 유형, 브라우저 설정, 브라우저 설정, 브라우저 설정, 브라우저 설정 및 브라우저 설정 등의 메타 데이터와 관련된 메타 데이터가 표시됩니다.

## Cloudflare 상점

Cloudflare는 가장 최근의 분기와 한 달 (약 124 일)에 대한 개인 정보 보호 게이트웨이 로그 정보를 유지합니다.

## Privacy Gateway 고객 정보

- 요청의 응용 내용.
- Cloudflare 프라이버시 게이트웨이 서버의 IP 주소 및 관련 메타데이터가 요청되었습니다.

Privacy Gateway는 이제 GraphQL API를 통해 향상된 모니터링을 지원하며 게이트웨이 트래픽 및 성능에 대한 자세한 통찰력을 제공합니다. 이 미터에 액세스하려면 다음을 수행하십시오.

- Cloudflare가 oblivious Relay Party로 동작하는 릴레이 게이트웨이 프록시 구현
- Analytics로 API 토큰을 읽습니다.
  우리는 두 개의 GraphQL 노드를 제공합니다.`ohttpMetricsAdaptive`·`ohttpMetricsAdaptiveGroups`. 첫 번째 노드는 포괄적 인 요청 데이터를 제공합니다. 두 번째는 그룹화 된 분석을 용이하게합니다.

## ohttpMetrics 적응

더 보기`ohttpMetricsAdaptive`노드는 적응 샘플링과 개별 OHTTP 요청으로 상세 통찰력을 위해 설계되었습니다. 이 노드는 서버와 클라이언트 설정에서 성능과 부하를 이해하는 데 도움이 될 수 있습니다.

### 키 Arguments

- `filter`\*필수
  - 필터를 적용하여 데이터를 축소합니다.`accountTag`필수 필터입니다.
- `limit`옵션 정보
  - 반환에 기록의 최대 수를 지정합니다.
- `orderBy`옵션 정보
  - 다양한 크기와 메트릭스 옵션으로 데이터를 정렬하는 방법을 선택하십시오.

### 사용 가능한 필드

- `bytesToClient`옵션 정보
  - 클라이언트로 반환된 바이트 수.
- `bytesToGateway`옵션 정보
  - 클라이언트에서 받는 총 바이트.
- `colo`문자열 선택
  - 요청을 제공하는 Cloudflare 데이터 센터의 공항 코드.
- `datetime`옵션 정보
  - 이벤트가 기록되었을 때 날짜와 시간.
- `gatewayStatusCode`옵션 정보
  - 게이트웨이에 의해 반환된 상태 코드.
- `relayStatusCode`옵션 정보
  - 릴레이에 의해 반환된 상태 부호.

이 노드는 트래픽의 알갱이보기에 유용합니다. 패턴, 성능 문제, 또는 데이터 흐름에 영향을 줄 수 있습니다.

## ohttpMetricsAdaptive그룹

더 보기`ohttpMetricsAdaptiveGroups`노드는 OHTTP 요청 메트릭스의 집계 분석이 가능하도록 합니다. 이 노드는 트래픽 및 운영의 다른 차원에서 트렌드 및 패턴을 식별하는 데 특히 유용합니다.

### 키 Arguments

- `filter`\*필수
  - 필터를 적용하여 데이터를 축소합니다.`accountTag`필수 필터입니다.
- `limit`옵션 정보
  - 반환에 기록의 최대 수를 지정합니다.
- `orderBy`옵션 정보
  - 다양한 크기와 메트릭스 옵션으로 데이터를 정렬하는 방법을 선택하십시오.

### 사용 가능한 필드

- `count`옵션 정보
  - 기준을 충족하는 레코드 수.
- `dimensions`옵션 정보
  - 귀하의 데이터에 대한 그룹 차원을 지정합니다.
- `sum`옵션 정보
  - 차원 당 각종 미터를 위한 총계.

**크기 (mm)**

데이터의 더 세분화 된보기를 얻기 위해 다양한 크기로 메트릭을 그룹 할 수 있습니다.

- `colo`문자열 선택
  - Cloudflare 데이터 센터의 공항 코드.
- `date`선택 사항
  - OHTTP 요청 메트릭의 날짜.
- `datetimeFifteenMinutes`옵션 정보
  - 타임즈탬프는 15 분에 truncated.
- `datetimeFiveMinutes`옵션 정보
  - 타임스탬프는 5 분에 truncated.
- `datetimeHour`옵션 정보
  - 타임스탬프는 시간에 truncated.
- `datetimeMinute`옵션 정보
  - 타임즈탬프는 분에 truncated.
- `endpoint`문자열 선택
  - 앱이 생성된 트래픽입니다.
- `gatewayStatusCode`옵션 정보
  - 게이트웨이에 의해 반환된 상태 코드.
- `relayStatusCode`옵션 정보
  - 릴레이에 의해 반환된 상태 부호.

**스태프**

Sum 필드는 선택한 시간 동안 다양한 미터의 누적보기를 제공합니다.

- `bytesToClient`옵션 정보
  - 클라이언트에게 게이트웨이에서 보낸 총 바이트.
- `bytesToGateway`옵션 정보
  - 클라이언트에서 게이트웨이에 총 바이트.
- `clientRequestErrors`옵션 정보
  - 클라이언트 요청 오류의 총 수.
- `gatewayResponseErrors`옵션 정보
  - 게이트웨이 응답 오류의 총 수.

ohttpMetricsAdaptiveGroups 노드를 활용하면, 포괄적인 통합 통찰력을 얻고, 성능과 사용자 경험을 최적화하는 데 도움을 줍니다.

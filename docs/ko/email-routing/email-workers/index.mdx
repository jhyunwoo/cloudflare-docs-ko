이메일 Workers를 사용하면 Cloudflare QXWorkersXQ의 힘을 활용하여 이메일을 처리하고 복잡한 규칙을 만듭니다. 이 규칙은 당신이 이메일을받을 때 무슨 일이 일어나는지 결정합니다.

이메일 Workers를 가진 당신의 자신의 규칙을 창조하는 것은 당신이 원하기 때문에 쉽습니다 복잡합니다. 대중적인 사용 케이스를 위한 코드로 미리 대중화되는 시동기 템플렛의 한을 사용하여 시작할 수 있습니다. 이 템플릿은 Blocklist, Allowlist, 또는 Slack에 알림을 보낼 수 있습니다.

당신이 선호하는 경우에, 당신은 템플릿을 건너골 사용자 정의 코드를 사용합니다. 예를 들어, 특정 주소에서 메시지를 수신하는 논리를 만들 수 있으며, 확인된 이메일 주소 중 하나 또는 더 많은 것을 전달하며 Slack에 경고합니다.

다음은 수당 이메일 노동자의 예입니다.

```js
export default {
	async email(message, env, ctx) {
		const allowList = ["friend@example.com", "coworker@example.com"];
		if (allowList.indexOf(message.from) == -1) {
			message.setReject("Address not allowed");
		} else {
			await message.forward("inbox@corp");
		}
	},
};
```

## 이메일 Workers를 사용하는 방법

이메일 Workers에 이메일 Routing을 사용하려면 다음과 같은 세 가지 단계가 있습니다.

1. 이메일 작업자 만들기.
2. 이메일 Worker에 논리를 추가 (이메일 주소가 허용하거나 이메일을 보내거나 차단).
3. 이메일 노동자를 경로로 바인딩합니다. 이 이메일 주소는 노동자에게 이메일을 전달합니다.

경로, 또는 이메일 주소, Worker는 이메일 작업자에게 이메일을 전달합니다. 노동자의 논리는 다음 이메일이 최종 목적지로 전달되었거나 떨어질 경우 결정합니다. 그리고 더 많은 행동이 적용됩니다.

예를 들어, Allowlist Email Worker를 작성하고 바인딩하는 것을 말합니다.`hello@my-company.com`경로. 이 루트는 세계와 공유하는 이메일 주소가 될 것입니다, 당신의 수당에 이메일 주소는 목적지 주소로 전달됩니다. 다른 모든 이메일은 떨어질 것입니다.

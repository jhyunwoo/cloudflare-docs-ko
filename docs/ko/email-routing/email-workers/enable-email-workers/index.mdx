이 단계를 따르고 첫 번째 이메일 노동자를 추가하십시오. Cloudflare WorkersXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQ[무료 가격 계획](/workers/platform/pricing/).

1. Cloudflare 대시보드에서, 가십시오**이메일 Routing**사이트 맵

   <DashButton url="/?to=/:account/:zone/email/routing" />

2. 제품정보**시작하기**.

3. 내 계정**주문 주소**, 사용하려는 사용자 정의 이메일 주소를 입력하십시오 (예를 들어,`my-new-email`).

4. 내 계정**여행 정보**, 이메일 주소를 선택하거나 이메일을 원하는 이메일 노동자를 선택 — 예를 들어,`your-name@gmail.com`. 당신은 이미 확인 된 목적지 주소를 선택할 수 있습니다. 새로운 목적지 주소를 추가하려면, 참조[대상 주소](#destination-addresses).

5. 제품정보**생성 및 계속**.

6. 목적지 주소를 확인하고 선택**계속하기**.

7. DNS 레코드 구성 및 선택**기록 추가 및 활성화**.

이메일 노동자를 성공적으로 만들었습니다. 이메일 노동자의 카드에서, 선택**오시는 길**확장하고 Worker와 관련된 루트를 확인합니다.

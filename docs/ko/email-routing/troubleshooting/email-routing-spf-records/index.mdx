여러[sender 정책 프레임 워크 (SPF) 레코드](https://www.cloudflare.com/learning/dns/dns-records/dns-spf-record/)귀하의 계정은 허용되지 않으며 제대로 작업에서 이메일 루팅을 방지합니다. 계정이 여러 SPF 레코드를 가지고 있다면이 단계를 따르십시오.

1. Cloudflare 대시보드에서, 갑니다**이메일 Routing**사이트 맵 이메일 Routing 당신은 여러 SPF 레코드가 있다는 것을 경고합니다.

   <DashButton url="/?to=/:account/:zone/email/routing" />

2. 이름 \***DNS 레코드 보기**, 선택**수정 기록**.

3. 잘못된 SPF 레코드를 삭제합니다.

SPF 레코드를 올바르게 구성해야 합니다. SPF 레코드가 삭제되지 않은 경우:

1. Cloudflare 대시보드에서, 가십시오**이메일 Routing**사이트 맵 이메일 Routing 당신은 여러 SPF 레코드가 있다는 것을 경고합니다.

   <DashButton url="/?to=/:account/:zone/email/routing" />

2. 이름 \***DNS 레코드 보기**, 선택**수정 기록**.

3. 모든 SPF 레코드 삭제.

4. 제품정보**기록 추가 및 활성화**.

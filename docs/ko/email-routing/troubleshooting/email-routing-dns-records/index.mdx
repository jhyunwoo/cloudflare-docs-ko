1. Cloudflare 대시보드에서, 갑니다**이메일 Routing**사이트 맵

   <DashButton url="/?to=/:account/:zone/email/routing" />

2. 오시는 길**계정 설정**. 이메일 Routing은 DNS 레코드의 상태를 보여줄 것입니다.`Missing`.

3. 제품정보**이메일 Routing**.

4. 다음 페이지는 어떤 종류의 행동이 필요합니다. 예를 들어, DNS 레코드가 누락된 경우, 선택**기록 추가 및 활성화**.

SPF 레코드에 문제가 있다면, 참조[문제 해결 SPF 레코드](/email-routing/troubleshooting/email-routing-spf-records/).

:::주\[주]
이메일 루팅을 사용하지 않고 삭제할 수 없는 영역에서 이메일 루팅 DNS 레코드를 알 수 있습니다.[이메일 Routing API 호출 가능](/api/resources/email_routing/subresources/dns/methods/delete/). DKIM TXT 레코드와 같은 예기치 않은 레코드를 제거 할 것입니다`cf2024-1._domainkey.<hostname>`.
:::

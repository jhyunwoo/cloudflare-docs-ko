이메일 Routing[지역 수준](/fundamentals/concepts/accounts-and-zones/#zones)이름 \* 영역은 최상위 도메인 (지역 이름과 동일)을 가지고 있으며 하위 도메인 (DN 기능에 따라 관리 됨)을 가질 수 있습니다. 예를 들어, 당신은 할 수 있습니다`example.com`지역, 그리고 그 후에`mail.example.com`·`corp.example.com`아래 하위 도메인.

계정의 모든 영역의 하위 도메인으로 이메일 Routing을 사용할 수 있습니다. 새 하위 도메인에 이메일 Routing 기능을 추가하려면 다음 단계를 따르십시오.

1. Cloudflare 대시보드에서, 갑니다**이메일 Routing**사이트 맵

   <DashButton url="/?to=/:account/:zone/email/routing" />

2. 오시는 길**계정 설정**, 그리고 선택**하위 도메인 추가**.

하위 도메인이 추가되고 DNS 레코드가 구성되면 볼 수 있습니다.**계정 설정**아래 목록**하위 도메인**이름 \*

지금 당신은 갈 수 있습니다**이름 \*** > **이메일 Routing** > **여정 규칙**그리고 새로운 사용자 정의 주소를 만들려면 영역 또는 다른 구성 하위 도메인의 상단 도메인을 사용하여 옵션을 보여줍니다.

DNS 레코드의 상태를 확인할 수 있습니다.**계정 설정**이메일 Routing의 단면도. 이 섹션은 또한 DNS 레코드를 가질 수있는 잠재적 인 문제를 해결 할 수 있습니다.

## 이메일 DNS 기록

계정의 DNS 레코드의 상태를 확인**이메일 DNS 기록**카드:

- **DNS 레코드 구성**- DNS 레코드가 제대로 구성됩니다.
- **이메일 DNS 기록 misconfigured**- 계정 DNS 레코드에 문제가 있습니다. 제품정보**이메일 Routing**으로[문제 해결 문제](/email-routing/troubleshooting/).

### 시작 disabling

성공적으로 이메일 루팅을 구성할 때 DNS 레코드가 잠겨지고 대시보드가 표시됩니다.**시작 disabling**이메일 DNS 레코드 카드의 버튼. 이 잠긴 상태는 Cloudflare에 의해 추천된 조정입니다. DNS 레코드가 이메일 Routing을 위해 필요한 것을 의미한다. 작업이 잠겨 있으며 도메인에서 이메일 Routing을 비활성화하면 변경 될 수 있습니다.

이메일 Routing을 삭제하거나 다른 공급자로 마이그레이션해야하는 경우, 선택**시작 disabling**. 참고[이메일 Routing](/email-routing/setup/disable-email-routing/)더 많은 정보.

### Lock DNS 레코드

영역 구성에 따라 DNS 레코드가 잠금 해제 될 수 있습니다. DNS 레코드를 잠금 해제 한 경우도 마찬가지입니다. 제품정보**Lock DNS 레코드**DNS 레코드를 잠그고 실수로 변경되거나 삭제 된 상태로 보호합니다.

## DNS 레코드 보기

제품정보**DNS 레코드 보기**자주 묻는 질문`MX`그리고 sender 정책 프레임 워크 (SPF) 레코드 이메일 Routing 사용.

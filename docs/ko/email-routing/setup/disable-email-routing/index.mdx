이메일 Routing은 서비스를 비활성화하기위한 두 가지 옵션을 제공합니다 :

- **삭제 및 비활성화**: 이 옵션은 즉시 이메일 루팅을 비활성화하고 제거`MX`이름 \* 귀하의 맞춤 이메일 주소는 작동 중지 및 이메일은 최종 목적지로 갈 수 없습니다.
- **DNS 기록을 열고 유지**: (고급) 이 옵션은 다른 공급자에게 마이그레이션 할 계획이라면 좋습니다. 그것은 당신이 새로운 추가 할 수 있습니다`MX`서비스를 비활성화하기 전에 기록. 이메일 Routing은 당신이 당신의 변경할 때 작동을 중지할 것입니다`MX`이름 \*

## 삭제 및 비활성화 이메일 Routing

1. Cloudflare 대시보드에서, 가십시오**이메일 Routing**사이트 맵

   <DashButton url="/?to=/:account/:zone/email/routing" />

2. 제품정보**계정 설정**.

3. 제품정보**시작 disabling** > **삭제 및 비활성화**. 이메일 Routing은 삭제될 계정과 관련된 레코드 목록을 보여줍니다.

4. 제품정보**삭제된 기록**.

이메일 Routing은 이제 귀하의 계정을 비활성화하고 이메일을 전달하는 것입니다. 다시 서비스를 활성화하려면, 선택**이메일 Routing**그리고 마법사를 따르십시오.

## DNS 기록을 열고 유지

1. Cloudflare 대시보드에서, 가십시오**이메일 Routing**사이트 맵

   <DashButton url="/?to=/:account/:zone/email/routing" />

2. 제품정보**계정 설정**.

3. 제품정보**시작 disabling** > **기록 및 계속**.

4. 제품정보**DNS에 기록**.

이제 DNS 레코드를 편집 할 수있는 옵션이 다른 공급자에게 서비스를 마이그레이션 할 수 있습니다.

:::카트로션

DNS 레코드를 변경하면 이메일 Routing 중지 작업을 할 수 있습니다. 당신이 당신의 마음을 변경하고 당신의 계정과 함께 이메일 Routing 작업을 유지하려면, 선택**Lock DNS 레코드**.
:::

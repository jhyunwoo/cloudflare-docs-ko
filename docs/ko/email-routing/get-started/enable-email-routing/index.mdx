:::카ution\[중요]
이메일 Routing 추가`MX`서비스에 대한 귀하의 영역의 DNS 설정에 기록. 당신은 할 수[이러한 변화`MX`이름 \*](/email-routing/setup/email-routing-dns-records/)언제든지. 그러나, 구성하는 방법에 따라, 이메일 Routing 작업을 중지 할 수 있습니다.
주요 특징

1. Cloudflare 대시보드에서, 가십시오**이메일 Routing**사이트 맵

   <DashButton url="/?to=/:account/:zone/email/routing" />

2. 영역에 추가 될 레코드를 검토합니다.

3. 제품정보**기록 추가 및 활성화**.

4. 오시는 길**여정 규칙**.

5. 제품 정보**주문 주소**, 선택**자주 묻는 질문**.

6. 사용하려는 사용자 지정 이메일 주소를 입력하십시오 (예를 들어,`my-new-email@example.com`).

7. 내 계정**대상 주소**, 귀하의 이메일이 전달되도록 원하는 전체 이메일 주소를 입력하십시오 — 예를 들어,`your-name@example.com`.

   :::주\[주]

   같은 사용자 정의 이메일 주소 (rule)에 연결된 여러 목적지 주소를 가지고 있다면, 이메일 Routing은 가장 최근 규칙 만 처리됩니다. 이를 피하기 위해 같은 사용자 정의 주소에 여러 목적지 주소를 연결하지 마십시오.

   이메일 전달의 현재 구현은 사용자 지정 주소 당 단일 대상 주소를 지원합니다. 여러 목적지에 사용자 지정 주소를 전달하려면 Workers 스크립트를 작성해야 합니다. Workers 스크립트에 사용되는 모든 대상은 이미 검증되어야 합니다.

   :::

8. 제품정보**제품 정보**.

9. Cloudflare는 인증 이메일을 보내드립니다.**관광 명소**이름 \* 진행하기 전에 이메일 주소를 확인해야 합니다.

10. 인증 이메일 Cloudflare에서, 선택**연락처** > **이메일 Routing**이메일 Routing을 활성화합니다.

11. 당신의 목적지 주소는 지금 표시해야 합니다**견적 요청**, 밑에**주요연혁**. 선택**계속하기**.

12. Cloudflare는 관련된 추가해야 합니다`MX`·`TXT`이메일 Routing에 대한 DNS 레코드에 기록. 이 단계는 자동이며 이메일 루팅을 구성하는 첫 번째 시간이 필요합니다. 영역에서 설정된 적절한 레코드를 보장하는 것은 의미입니다. 제품정보**기록 및 끝 추가**.

이메일 Routing이 활성화되었습니다. 계정에 다른 사용자 지정 주소를 추가할 수 있습니다.

:::참조
이메일 Routing이 구성되고 실행되면 다른 이메일 서비스가 구성되는 도메인에서 활성화 될 수 없습니다. 다른 경우`MX`이미 DNS에서 구성 된 레코드, Cloudflare는 삭제하려는 경우 당신을 요청합니다. 당신은 기존을 삭제하지 않는 경우`MX`기록, 이메일 Routing 활성화되지 않습니다.

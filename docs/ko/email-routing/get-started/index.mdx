이메일 Routing을 활성화하려면 대상 주소 또는 이메일 Worker에 연결된 맞춤 이메일 주소를 생성하십시오. 이 양식**이메일 규칙**. Cloudflare 대시보드XQ에서 또는 분리할 수 있는 규칙을 사용할 수 있습니다. 더 알아보기[이메일 Routing](/email-routing/get-started/enable-email-routing)더 많은 정보.

이메일 Routing 작업과 같은 사용자 정의 주소만 전달합니다. 사용자 지정 주소로 전송된 이메일은 이메일 주소로 전달됩니다. Cloudflare는 아웃바운드 이메일을 처리하지 않으며 SMTP 서버가 없습니다.

이메일 Routing에 액세스하는 첫 번째 시간, 당신은 이메일 규칙을 만드는 과정을 통해 마법사를 인도 할 것입니다. 마법사를 건너서 규칙을 수동으로 추가할 수 있습니다.

다른 서비스에 이메일 Routing 또는 offboard를 일시 중지해야하는 경우, 참조[이메일 Routing](/email-routing/setup/disable-email-routing/).

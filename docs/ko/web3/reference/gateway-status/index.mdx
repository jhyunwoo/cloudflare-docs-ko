게이트웨이를 [생성](/web3/how-to/manage-gateways/#create-a-gateway)하면 여러 상태 중 하나를 가질 수 있습니다.

| Status | Definition |
| --- | --- |
| **Active** | 게이트웨이에 대한 DNS 레코드가 생성되었고 정상적으로 동작하고 있습니다. |
| **Pending** | Web3 gateway가 **Active** 상태가 되는 과정에 있습니다. |
| **Deleting** | Web3 gateway가 삭제되는 중입니다. |
| **Error** | 게이트웨이에 대한 DNS 레코드가 잘못 구성되었거나 존재하지 않습니다. 해결하려면 [게이트웨이 새로고침](/web3/how-to/manage-gateways/#refresh-a-gateway)을 시도하세요. |

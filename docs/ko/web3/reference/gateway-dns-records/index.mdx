게이트웨이를 [생성](/web3/how-to/manage-gateways/#create-a-gateway)하면, 게이트웨이가 트래픽을 적절히 수신하고 라우팅할 수 있도록 Cloudflare가 Cloudflare DNS에 레코드를 자동으로 생성하고 추가합니다.

* **Ethereum gateways**: 호스트명을 `ethereum.cloudflare.com`으로 가리키는 [프록시된](/dns/proxy-status/) `CNAME` 레코드를 생성합니다.
* **IPFS gateways**: 호스트명을 `ipfs.cloudflare.com`으로 가리키는 [프록시된](/dns/proxy-status/) `CNAME` 레코드와, [DNSLink](/web3/ipfs-gateway/concepts/dnslink/#how-is-it-used-with-cloudflare)에 지정된 값을 담은 `TXT` 레코드를 생성합니다.

이 레코드는 Cloudflare DNS 내부에서 직접 편집할 수 없습니다. 변경하려면 게이트웨이 [구성 자체를 수정](/web3/how-to/manage-gateways/#edit-a-gateway)해야 합니다.

## 기존 DNS 레코드

기존 DNS 레코드가 이미 있는 호스트명으로 게이트웨이를 [생성](/web3/how-to/manage-gateways/#create-a-gateway)하면, Cloudflare는 Web3 gateway에 적용되도록 기존 레코드를 자동으로 덮어씁니다.

*DNSLink* record 없이 Universal Path gateway를 설정하면, 사용자가 IPFS network에 호스팅된 어떤 콘텐츠든 접근할 수 있는 unrestricted gateway를 만들게 됩니다.

이는 게이트웨이를 특정 콘텐츠 조각(특정 Content Identifier(CID) 또는 Interplanetary Name Service(IPNS) 호스트명)으로 제한하는 [restricted gateway](/web3/ipfs-gateway/concepts/dnslink/)와 다릅니다.

## Cloudflare에서는 어떻게 사용되나요?

[일반 게이트웨이를 생성](/web3/how-to/manage-gateways/)하듯이 Universal Path gateway를 추가할 수 있습니다.

대부분의 경우 [gateway blocklist](/web3/how-to/manage-gateways/#update-blocklist)에 항목을 추가해 Universal Path gateway를 통해 특정 콘텐츠에 접근하는 것을 차단하고 싶을 것입니다. 하나 이상의 다음 항목에 대해 차단할 수 있습니다.

* CID (`QmPZ9gcCEpqKTo6aq61g2nXGUhM4iCL3ewB6LDXZCtioEB`)
* IPFS 콘텐츠 (`/ipfs/QmYwAPJzv5CZsnA625s3Xf2nemtYgPpHdWEz79ojWnPbdG/readme`)
* IPNS 콘텐츠 경로 (`/ipns/example.com`)

:::note


이 기능은 특정 요금제에서만 사용할 수 있습니다. 자세한 내용은 [Limits](/web3/reference/limits/)를 참고하세요.


:::

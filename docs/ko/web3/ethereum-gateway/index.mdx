Cloudflare의 Ethereum Gateway는 컴퓨터에 어떤 소프트웨어도 설치하지 않고 [Ethereum network](/web3/ethereum-gateway/concepts/ethereum/)에 읽기 및 쓰기 접근을 제공합니다.

특히 사용자는 네트워크의 기존 노드들이 합의한 모든 정보를 읽을 수 있습니다. 또한 자신의 트랜잭션과 스마트 계약을 작성하여 이 노드들이 분산 방식으로 저장하도록 할 수 있습니다. 네트워크의 다른 누구나 이 트랜잭션을 볼 수 있으며, 심지어 자신의 Ethereum 화폐를 사용해 사용자의 스마트 계약을 실행할 수도 있습니다.

이러한 상호작용은 공식 [Ethereum JSON-RPC API](https://github.com/ethereum/execution-apis)를 통해 이루어지며, [Cloudflare가 지원하는 API methods](/web3/ethereum-gateway/reference/supported-api-methods/)를 사용합니다.

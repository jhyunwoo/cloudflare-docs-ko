Ethereum network는 사용자가 스마트 계약을 분산 방식으로 작성하고 계산할 수 있게 해 주는 분산 합의 플랫폼입니다. 스마트 계약은 본질적으로 네트워크의 고유 주소에 존재하는 튜링 완전 프로그램입니다. 스마트 계약이 트랜잭션의 일부로 실행되면, 그 결과와 현재 계약 상태는 전체 노드 네트워크가 합의한 검증 가능한 합의 상태에 저장됩니다.

## 스마트 계약

사용자가 원하는 입력값으로 스마트 계약을 실행하려면 자신의 명령과 함께 ETH라는 화폐를 제공합니다. 이 화폐는 트랜잭션을 분산 합의에 추가하는 데 기여하는 특정 노드 집합에 할당됩니다.

스마트 계약이 네트워크 내 다른 개인에게 금액을 이동시키는 내용을 포함한다면, 이 또한 합의에 기록됩니다. 따라서 이 합의는 네트워크의 현재 상태와 각 개인이 얼마나 많은 Ethereum 화폐를 소유하고 있는지를 함께 나타냅니다.

## 주소 지정

네트워크의 모든 트랜잭션은 전체 합의를 구성하는 '블록'에 저장됩니다. 간단히 말해, 합의는 Ethereum 플랫폼의 전체 역사 속 모든 트랜잭션을 나타내는, 증가하는 고유 식별자를 가진 단일 블록 시퀀스입니다.

각 블록에는 블록을 조회하고 조사하는 데 사용할 수 있는 고유 hash 식별자(예: `0xd4e56740f876aef8c010b86a40d5f56745a118d0906a34e69aec8c0db1cb8fa3q` 같은 긴 hexadecimal 문자열)도 있습니다. 블록 안의 각 트랜잭션 역시 개별 트랜잭션을 조회하는 데 사용할 수 있는 고유 hash 식별자를 가집니다. 새로운 트랜잭션이 블록의 일부로 합의에 업로드되면 이 변경은 네트워크 전체로 전파되며, 누구나 어떤 트랜잭션이 일어났는지 읽을 수 있습니다. 이로써 네트워크의 전체 상태는 책임성을 갖게 됩니다.

## 콘텐츠 읽기와 쓰기

콘텐츠를 읽으려면 사용자는 동작 중인 Ethereum node와 상호작용해야 합니다. 이러한 노드는 사용자의 컴퓨터에서 데몬 형태로 로컬 실행할 수 있습니다(예: [https://github.com/ethereum/go-ethereum/](https://github.com/ethereum/go-ethereum/)). 사용자가 이런 node에 접근하면 공식 JSONRPC API를 사용해 네트워크에 쿼리를 보내고 합의의 특정 측면을 파악할 수 있습니다.

콘텐츠 쓰기도 마찬가지로 간단하며 [단일 JSON 명령](https://github.com/ethereum/wiki/wiki/JSON-RPC#eth_sendrawtransaction)으로 수행할 수 있습니다. 다만 트랜잭션을 쓰려면 일정량의 화폐와, 그 화폐를 보유한 [Ethereum wallet](https://www.ethereum.org/use/#_3-what-is-a-wallet-and-which-one-should-i-use)의 secret key를 함께 제공해야 합니다. 이것이 가능하다면 쓰기 트랜잭션은 더 넓은 네트워크로 전송되고 합의에 추가됩니다.

## 웹사이트를 게이트웨이에 연결하기

사용자의 커스텀 도메인 이름으로 Ethereum network에 접근하고 싶다면 [새 Ethereum Gateway를 생성](/web3/how-to/manage-gateways/#create-a-gateway)하면 됩니다.

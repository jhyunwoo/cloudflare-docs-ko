Cloudflare의 Ethereum Gateway는 처음 출시될 때 Rinkeby testnet을 지원했지만, Rinkeby는 [The Merge](https://ethereum.org/en/upgrades/merge/)를 거치지 않았고 그 결과 mainnet용 신뢰할 수 있는 staging 환경이 더 이상 되지 못합니다.

Cloudflare는 2023년 1월 30일에 Rinkeby 지원을 종료합니다.

## 마이그레이션

Web3 개발이나 디버깅에서 문제를 피하려면 Ethereum Gateway에서 완전히 지원되는 [Sepolia testnet](/web3/ethereum-gateway/reference/supported-networks/)으로 전환해야 합니다.

마이그레이션하려면 Ethereum network에 [읽기 또는 쓰기](/web3/how-to/use-ethereum-gateway/)를 수행할 때 사용하는 endpoint를 업데이트해야 합니다.

예를 들어 이전에는 아래 endpoint를 사용해 Ethereum Gateway와 상호작용했을 수 있습니다.

```bash title="기존 curl" {1}
curl https://web3-trial.cloudflare-eth.com/v1/rinkeby \
--header 'Content-Type: application/json' \
--data '{
  "jsonrpc": "2.0",
  "method": "eth_getBlockByNumber",
  "params": ["0x2244", true],
  "id": 1
}'
```

```js title="기존 JS Fetch API" {2}
await fetch(
  new Request('https://web3-trial.cloudflare-eth.com/v1/rinkeby', {
    method: 'POST',
    body: JSON.stringify({
      jsonrpc: '2.0',
      method: 'eth_getBlockByNumber',
      params: ['0x2244', true],
      id: 1,
    }),
    headers: {
      'Content-Type': 'application/json',
    },
  })
).then(resp => {
  return resp.json();
});
```

Rinkeby에서 벗어나려면 endpoint 끝부분을 다른 testnet으로 바꾸세요.

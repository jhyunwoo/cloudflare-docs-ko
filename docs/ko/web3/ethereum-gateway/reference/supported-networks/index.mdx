현재 Cloudflare Ethereum gateway는 다음 네트워크와의 [상호작용](/web3/how-to/use-ethereum-gateway/)을 지원합니다.

| Network | Usage |
| --- | --- |
| [Ethereum Mainnet](https://ethereum.org/en/enterprise/) | 게이트웨이 또는 Cloudflare public gateway(`cloudflare-eth.com`)에 대한 호출 끝에 `/v1/mainnet`을 붙입니다. |
| [Sepolia Testnet](https://sepolia.dev/) | 게이트웨이 호출 끝에 `/v1/sepolia`를 붙입니다. |

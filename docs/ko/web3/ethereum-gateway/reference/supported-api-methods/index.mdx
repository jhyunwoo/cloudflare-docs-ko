## Trace methods

EVM trace는 Ethereum 블록체인에서 스마트 계약의 실행을 추적하는 방법입니다. 스마트 계약이 실행될 때 Ethereum Virtual Machine(EVM)이 수행한 모든 단계를 기록합니다. 여기에는 실행된 구체적인 연산, 사용된 gas 비용, 그 결과 블록체인에 발생한 변경 등이 포함됩니다. trace module은 개발자가 이러한 trace에 접근하고 분석할 수 있도록 해 주는 도구로, 스마트 계약을 디버깅하고 테스트하며 모니터링하는 데 유용합니다. 이를 통해 오류를 찾아 수정하고, 성능을 최적화하며, 스마트 계약이 블록체인과 어떻게 상호작용하는지에 대한 통찰을 얻을 수 있습니다.

### trace_filter

`trace_filter` method는 한 번의 요청으로 여러 트랜잭션의 trace를 가져옵니다. 이 method는 Ethereum 블록체인의 특정 주소를 디버깅하고 모니터링하는 데 특히 유용합니다.

#### 요청 파라미터

- `fromBlock`: `Quantity` 또는 `Tag` - (optional) trace 수집을 시작할 블록 번호입니다.
- `toBlock`: `Quantity` 또는 `Tag` - (optional) trace 수집을 중지할 블록 번호입니다.
- `fromAddress`: `Array` - (optional) trace 수집을 시작할 주소 배열입니다.
- `toAddress`: `Address` - (optional) trace 수집을 중지할 주소 배열입니다.
- `after`: `Quantity` - (optional) offset trace 번호입니다.
- `count`: `Quantity` - (optional) 반환할 trace 수입니다.

#### 반환값

이 method는 주어진 필터에 일치하는 trace의 `Array`를 반환합니다.

#### 예시

```sh title="trace_filter Request" {1}
curl https://web3-trial.cloudflare-eth.com/v1/mainnet \
-X POST \
-H 'Content-Type: application/json' \
--data '{
    "jsonrpc":"2.0",
    "method":"trace_filter",
    "params":[
        {
            "count": 200,
            "fromBlock": "0xccb943",
            "toBlock": "0xccbc62",
            "fromAddress": [
                "0xEdC763b3e418cD14767b3Be02b667619a6374076"
            ]
        }
    ],
    "id":1
    }'
```

### 제한 사항

`trace_filter` method에는 노드가 과부하되지 않도록 몇 가지 제한이 있습니다.

- `trace_filter` method의 블록 범위는 800블록으로 제한됩니다.
- trace `count`는 200으로 제한됩니다.

새 게이트웨이를 [생성](/web3/how-to/manage-gateways/#create-a-gateway)하려면 먼저 하나 이상의 게이트웨이를 구독해야 합니다.

## 새 구독 만들기

Web3 게이트웨이를 구독하려면(아직 구독하지 않았다면) 다음과 같이 하세요.

1. Cloudflare 대시보드에서 **Web3** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/web3" />

2. **Subscribe to Web3 Gateways**를 클릭합니다.
3. 구독하려는 게이트웨이를 선택합니다.
4. **Proceed to Payment Details**를 클릭합니다.
5. 결제 정보를 입력하고(아직 계정에 등록하지 않았다면) 구매를 완료합니다.

<Render file="non-contract-enablement" product="fundamentals" />

## 기존 구독 관리

기존 구독을 업데이트하거나 추가 게이트웨이를 구독하려면 다음과 같이 하세요.

1. Cloudflare 대시보드에서 **Web3** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/web3" />

2. **Manage Subscriptions**를 클릭합니다.
3. 기존 게이트웨이 구독을 업데이트하려면 **Change**를 클릭합니다. 새 게이트웨이에 대한 접근을 구매하려면 **Subscribe**를 클릭합니다.

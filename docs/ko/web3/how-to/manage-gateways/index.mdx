## 게이트웨이 수정

게이트웨이를 [생성](/web3/how-to/manage-gateways/#create-a-gateway)한 후에는 **Gateway Description**만 수정할 수 있으며, **IPFS** 게이트웨이인 경우 [DNSLink](/web3/ipfs-gateway/concepts/dnslink/) 필드 값도 수정할 수 있습니다.

다른 필드를 수정해야 한다면 게이트웨이를 [삭제](#delete-a-gateway)한 뒤 새로 생성하세요.

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드를 사용해 게이트웨이를 수정하려면 다음과 같이 하세요.

1. Cloudflare 대시보드에서 **Web3** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/web3" />

2. 특정 게이트웨이에서 **Edit**를 클릭합니다.
3. **Gateway Description**과, **IPFS** 게이트웨이를 수정하는 경우 [DNSLink](/web3/ipfs-gateway/concepts/dnslink/) 값을 업데이트합니다.
4. **Reapply**를 클릭합니다.

</TabItem> <TabItem label="API">

게이트웨이의 특정 설정을 수정하려면 [`PATCH`](/api/resources/web3/subresources/hostnames/methods/edit/) 요청을 사용하세요.

</TabItem> </Tabs>

## 게이트웨이 새로고침

게이트웨이가 **Error** [status](/web3/reference/gateway-status/)에 멈춰 있다면, 해당 호스트명의 DNS 레코드를 다시 생성하려고 시도하는 새로고침을 해 보는 것이 좋습니다.

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드를 사용해 게이트웨이를 새로고침하려면 다음과 같이 하세요.

1. Cloudflare 대시보드에서 **Web3** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/web3" />

2. 게이트웨이에서 드롭다운을 클릭한 다음 **Refresh**를 선택합니다.

</TabItem> <TabItem label="API">

API를 사용해 게이트웨이를 새로고침하려면 빈 요청 본문과 함께 [`PATCH`](/api/resources/web3/subresources/hostnames/methods/edit/) 요청을 보냅니다.

</TabItem> </Tabs>

## 블록리스트 업데이트

[IPFS Universal Path gateway](/web3/ipfs-gateway/concepts/universal-gateway/)를 설정하는 경우, 게이트웨이 블록리스트에 항목을 추가해 특정 콘텐츠에 대한 접근을 차단할 수 있습니다.

다음 중 하나 이상에 대한 접근을 차단할 수 있습니다.

- CID (`QmPZ9gcCEpqKTo6aq61g2nXGUhM4iCL3ewB6LDXZCtioEB`)
- IPFS 콘텐츠 경로 (`/ipfs/QmYwAPJzv5CZsnA625s3Xf2nemtYgPpHdWEz79ojWnPbdG/readme`)
- IPNS 콘텐츠 경로 (`/ipns/example.com`)

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드를 사용해 블록리스트에 항목을 추가하려면 다음과 같이 하세요.

1. Cloudflare 대시보드에서 **Web3** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/web3" />

2. 특정 게이트웨이에서 드롭다운을 클릭한 다음 **Blocklist**를 선택합니다.
3. **Add entry**를 클릭합니다.
4. 다음 정보를 입력합니다.
   - **Blocklist entry type**: **CID** 또는 **Content path**를 선택합니다.
   - **Blocklist entry content**: 차단할 CID 또는 콘텐츠 경로를 추가합니다. 즉 CID의 경우 유효한 CIDv0 또는 CIDv1 문자열이어야 하고, 콘텐츠 경로의 경우 `/ipfs/` 또는 `/ipns/`로 시작해야 합니다.
   - **Blocklist entry description**: 블록리스트 항목을 식별하기 쉽도록 설명을 추가합니다.

5. **Add**를 클릭합니다.

</TabItem> <TabItem label="API">

API를 사용해 블록리스트 항목을 추가하려면 [`POST`](/api/resources/web3/subresources/hostnames/subresources/ipfs_universal_paths/subresources/content_lists/subresources/entries/methods/create/) 요청을 보냅니다.

</TabItem> </Tabs>

## 게이트웨이 삭제

게이트웨이를 삭제하면 Cloudflare는 연결된 모든 호스트명 DNS 레코드를 자동으로 제거합니다. 이 작업은 트래픽에 영향을 미치며 되돌릴 수 없습니다.

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드를 사용해 게이트웨이를 삭제하려면 다음과 같이 하세요.

1. Cloudflare 대시보드에서 **Web3** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/web3" />

2. 특정 게이트웨이에서 드롭다운을 클릭한 다음 **Remove**를 선택합니다.
3. **Delete hostname**를 클릭합니다.

</TabItem> <TabItem label="API">

API를 사용해 게이트웨이를 삭제하려면 [`DELETE`](/api/resources/web3/subresources/hostnames/methods/delete/) 요청을 보냅니다.

</TabItem> </Tabs>

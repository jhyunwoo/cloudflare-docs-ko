다음 섹션은 Network Analytics 메인 대시보드의 각 부분을 안내합니다.

## 사용 가능한 탭

**All traffic** 탭은 레이어 3/4 트래픽, DNS 트래픽, DDoS 공격에 대한 전체 정보를 표시합니다. 대시보드에는 서로 다른 완화 시스템에 대한 구체적인 정보(및 전용 필터)를 제공하는 추가 탭도 있습니다.

다음 표는 각 탭에 표시되는 내용을 요약합니다.

| 탭 이름 | Magic Transit 사용자용 | Spectrum 사용자용 |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **All traffic** | DDoS 관리 규칙, Advanced TCP Protection, Advanced DNS Protection, Cloudflare Network Firewall에 의해 차단된 트래픽과 원본 서버로 전달된 트래픽 | DDoS 관리 규칙에 의해 차단되거나 통과된 트래픽 |
| **DDoS managed <br/>rules** | [DDoS managed rules](/ddos-protection/managed-rulesets/)에 의해 차단되거나 통과된 트래픽 | [DDoS managed rules](/ddos-protection/managed-rulesets/)에 의해 차단되거나 통과된 트래픽 |
| **TCP <br/>Protection** | [Advanced TCP Protection](/ddos-protection/advanced-ddos-systems/overview/advanced-tcp-protection/) 시스템에 의해 차단되거나 통과된 트래픽. DDoS 관리 규칙에 의해 차단된 트래픽은 포함하지 않음 | N/A |
| **DNS <br/>Protection** | [Advanced DNS Protection](/ddos-protection/advanced-ddos-systems/overview/advanced-dns-protection/) 시스템에 의해 차단되거나 통과된 트래픽. DDoS 관리 규칙에 의해 차단된 트래픽은 포함하지 않음 | N/A |
| **Cloudflare Network Firewall** | [Cloudflare Network Firewall](/cloudflare-network-firewall/)에 의해 차단된 트래픽과 원본 서버로 전달된 트래픽. DDoS 관리 규칙, Advanced TCP Protection, Advanced DNS Protection에 의해 차단된 트래픽은 포함하지 않음 | N/A |

이 탭들을 사용하면 각 완화 시스템이 어떤 결정을 내렸는지, 그리고 공격 완화를 위해 어떤 규칙이 적용되고 있는지 더 잘 이해할 수 있습니다.

:::note

Network Analytics에는 다음과 같은 기타 트래픽은 표시되지 않습니다.

- Spectrum에 의해 차단된 트래픽
- WAF/CDN 서비스에 의해 차단된 트래픽
- 캐시 또는 Workers에서 제공된 트래픽
  :::

## 상위 메트릭

Network Analytics 페이지의 측면 패널은 기간 드롭다운에서 선택한 기간 동안의 활동 요약을 제공합니다.

![Available high-level metrics in the Network Analytics dashboard](~/assets/images/analytics/network-analytics/high-level-metrics.png)

_참고: 이 이미지의 라벨은 이전 제품명을 반영할 수 있습니다._

사이드바에서 메트릭 중 하나를 선택하면 대시보드에 표시되는 데이터의 기본 단위(패킷 또는 비트/바이트)가 정해집니다.

## Executive summary

![Executive summary card in the Network Analytics dashboard.](~/assets/images/analytics/network-analytics/executive-summary-card.png)

Executive summary는 네트워크를 겨냥한 DDoS 공격의 핵심 인사이트와 추세를 제공합니다. 여기에는 공격 수, 전체 트래픽 대비 완화된 공격 트래픽 비율, 최대 공격 속도, 완화된 총 공격 바이트, 상위 출처, 공격 예상 지속 시간이 포함됩니다.

이 인사이트는 선택한 기간과 **Packets** 또는 **Bytes** [메트릭](#상위-메트릭) 선택기에 따라 적응적으로 변화합니다. 또한 선택한 기간 대비 증감을 퍼센트 변화와 지시 화살표로 시각화한 추세 정보도 함께 표시됩니다.

Executive summary 상단에는 최근 및 진행 중인 공격을 알려 주는 한 줄 요약도 제공됩니다.

### 총 공격 수

총 공격 수는 [Network-layer DDoS Attack Protection managed ruleset](/ddos-protection/managed-rulesets/network/)에서 발급한 완화 조치의 고유 공격 ID를 기준으로 계산됩니다.

완화 시스템이 하나의 공격에 대해 여러 완화 규칙(따라서 여러 공격 ID)을 생성할 수 있으므로, 실제 공격 수보다 높아 보이는 경우가 있을 수 있습니다.

최근 완화된 DDoS 공격의 메타데이터를 가져오려면 [`dosdAttackAnalyticsGroups`](/analytics/graphql-api/migration-guides/network-analytics-v2/node-reference/#dosdattackanalyticsgroups) GraphQL 노드를 쿼리하세요.

:::note[공격 속도 관련 참고]

Executive summary의 공격 속도는 시간대별 그래프에 표시된 값보다 낮아 보일 수 있습니다. 이 값은 고유 공격 이벤트의 최대 속도만을 기준으로 하고, Network-layer DDoS Attack Protection managed ruleset에서만 계산되기 때문입니다. 그러나 실제로는 여러 공격과 완화 시스템이 하나의 공격 차단에 함께 기여할 수 있어 표시된 값보다 더 큰 속도가 나올 수 있습니다.

또한 시간대별 그래프에서 확대/축소할 때 샘플링과 adaptive bit rate(ABR)에 따라 공격 속도가 달라질 수 있습니다. 자세한 내용은 [개념](/analytics/network-analytics/understand/concepts/)을 참고하세요.
:::

## 필터

메인 대시보드 카드에서 표시되는 데이터에 필터를 적용할 수 있습니다.

다음 매개변수로 필터링할 수 있습니다.

- Cloudflare가 수행한 완화 작업
- 작업을 수행한 완화 시스템
- 출발지 IP, 포트, ASN, 터널
- [Direction](#트래픽-방향)
- 목적지 IP, 포트, IP 범위(프로비저닝된 프리픽스의 설명 또는 CIDR), 터널
- 트래픽이 관측된 출발지 Cloudflare 데이터 센터 및 해당 데이터 센터 국가
- 패킷 크기
- TCP 플래그
- TTL

현재 IP Range 필터는 /24 IPv4 범위와 /64 IPv6 범위만 지원한다는 제한이 있습니다.

### 트래픽 방향

특정 고객 네트워크 관점에서 **Direction** 필터의 사용 가능한 값은 다음 의미를 가집니다.

- **Ingress**: 공용 인터넷에서 Cloudflare 네트워크를 통해 고객 네트워크로 유입되는 트래픽(예: [Magic Transit](/magic-transit/) 경유)
- **Egress**: Cloudflare 네트워크를 통해 고객 네트워크를 떠나 공용 인터넷으로 향하는 아웃바운드 트래픽(예: [egress 옵션이 배포된 Magic Transit](/magic-transit/reference/egress/) 경유)
- **Lateral**: 고객 네트워크 내부에 머물며 Cloudflare 네트워크를 통해 라우팅된 트래픽(예: [Cloudflare WAN](/cloudflare-wan/)을 통해 라우팅되는 고객 지사 또는 데이터 센터 간 트래픽)

## Packets summary 또는 Bits summary

주어진 차원의 값에 따라 선택한 시간 범위의 트래픽(비트 또는 패킷 기준)을 플롯으로 표시합니다. 기본적으로 Network Analytics는 **Action** 기준으로 분해된 데이터를 표시합니다.

### 사용 가능한 차원

다음 차원 중 하나를 선택할 수 있습니다.

- Action
- Destination IP
- Destination IP range
- Destination port
- Destination tunnels
- Mitigation system
- Source ASN
- Data center country
- Source data center
- Source IP
- Source port
- Source tunnels
- Packet size
- Protocol
- TCP flag

## Mitigation system distribution

**Mitigation System Distribution** 카드는 각 완화 시스템이 완화한 트래픽 양(패킷 또는 비트 기준)을 표시합니다.

## Packet sample log

Network Analytics의 **Packet sample log**는 현재 선택된 시간 범위에서 허용된 패킷과 차단된 패킷을 포함해 최대 100개의 로그 이벤트를 표시하며, 시간 범위 보기당 페이지별 10개 결과로 페이지네이션됩니다([GraphQL Analytics API](/analytics/graphql-api/)에는 이 제한이 없습니다).

각 행을 확장하면 전체 패킷 헤더와 메타데이터를 포함한 이벤트 세부 정보를 확인할 수 있습니다.

## Data center country/Source data center

표시된 트래픽이 수집된 상위 출발지 [Cloudflare 데이터 센터](https://www.cloudflare.com/en-gb/network/)를 표시합니다. 같은 카드에서 이들 상위 출발지 데이터 센터와 연관된 국가도 표시할 수 있습니다.

**Data center country**와 **Source data center** 정보 사이를 전환하려면 카드의 드롭다운을 사용하세요.

## Top insights

**Top insights**의 각 패널은 각 차원에서 상위 항목을 표시합니다. 특정 값으로 필터링하거나 표시 데이터에서 값을 제외하려면 값 통계 위에 마우스를 올리고 **Filter** 또는 **Exclude**를 선택하세요.

각 차원에 대해 표시할 항목 수를 정하려면 보기와 연결된 드롭다운 목록을 열고 원하는 수를 선택합니다.

## TCP flag

**TCP Flag** 패널은 현재 대시보드에 표시된 모든 트래픽에 대해 설정된 TCP 플래그를 보여 줍니다. 여기에는 허용된 트래픽과 완화된 트래픽이 모두 포함됩니다.

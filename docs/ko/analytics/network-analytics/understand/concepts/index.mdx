## Adaptive Bit Rate 샘플링

Adaptive Bit Rate(ABR) 샘플링을 사용하면, ABR을 지원하는 모든 분석 쿼리는 해당 쿼리에 맞는 해상도로 계산됩니다. 쿼리 크기에 따라 ABR 메커니즘은 가장 적절한 샘플링 비율을 선택하고 각 [Network Analytics node](/analytics/graphql-api/migration-guides/network-analytics-v2/node-reference/) 뒤에 캡슐화된 샘플 테이블 중 하나에서 응답을 가져옵니다. 과거 데이터에 대해서도 카디널리티와 정확성이 유지됩니다.

Adaptive Bit Rate 샘플링에 대한 배경 정보는 [Explaining Cloudflare's ABR Analytics](https://blog.cloudflare.com/explaining-cloudflares-abr-analytics/) 블로그 게시물을 참고하세요.

## Edge Sample Enrichment

Network Analytics는 샘플 비율과 Edge Sample Enrichment 덕분에 정확한 데이터를 제공할 수 있습니다.

샘플 비율은 완화 서비스에 따라 달라집니다. 예를 들어:

- `dosd`의 샘플 비율은 패킷 양에 따라 1/100에서 1/10,000 패킷 사이에서 동적으로 변합니다.
- Network Firewall 이벤트의 샘플 비율은 패킷 수에 따라 1/100에서 1/1,000,000 패킷 사이에서 동적으로 변합니다.
- `flowtrackd`의 샘플 비율은 1/10,000 패킷입니다.

NA는 Edge Sample Enrichment에 의존하는 데이터 로깅 파이프라인을 사용합니다. 패킷 샘플 강화와 상호 참조를 글로벌 데이터 센터에 위임함으로써, 데이터 파이프라인의 복원력과 혼잡 내성이 향상됩니다. 이 방법을 사용하면 강화된 패킷 샘플이 도착하는 즉시 Cloudflare의 핵심 데이터 센터에 저장됩니다.

## 적절한 탭 선택

레이어 3/4 트래픽과 DDoS 공격을 폭넓게 분석하려면 **All traffic** 탭을 사용하세요.

특정 완화 시스템에 집중하려면 [다른 사용 가능한 탭](/analytics/network-analytics/understand/main-dashboard/#available-tabs) 중 하나를 선택하세요. 대시보드에 표시되는 탭은 사용 중인 Cloudflare 서비스에 따라 달라집니다.

## 상위 메트릭 선택

데이터 보기를 전환하려면 **Total packets** 또는 **Total bytes** 측면 패널을 선택합니다.

![Network Analytics side panels allowing you to use packets or bits/bytes as the base unit for the dashboard.](~/assets/images/analytics/network-analytics/high-level-metrics.png)

_참고: 이 이미지의 라벨은 이전 제품명을 반영할 수 있습니다._

선택한 메트릭은 대시보드 여러 분석 패널에서 사용하는 기본 단위(패킷 또는 비트/바이트)를 결정합니다.

## 차원 선택

**Packets summary** 또는 **Bits summary** 아래에서 [사용 가능한 차원](/analytics/network-analytics/understand/main-dashboard/#available-dimensions) 중 하나를 선택해 해당 차원으로 데이터를 봅니다. 기본 차원은 **Action**입니다.

## 필터 적용

여러 필터와 제외 규칙을 적용하여 Network Analytics에 표시되는 데이터 범위를 조정할 수 있습니다.
필터는 대시보드에 표시되는 모든 데이터에 영향을 줍니다.

Network Analytics 데이터를 필터링하는 방법은 두 가지입니다. **Add filter**를 선택하거나 stat 필터 중 하나를 선택하면 됩니다.

### Add filter 선택

**Add filter**를 선택하면 **New filter** 팝오버가 열립니다. 필드, 연산자, 값을 지정해 필터 식을 완성합니다. 보기 갱신을 위해 **Apply**를 선택하세요.

:::note[필터링 관련 참고]

필터를 적용할 때 다음 지침을 확인하세요.

- 와일드카드는 지원되지 않습니다.
- 값은 따옴표로 감쌀 필요가 없습니다.
- ASN 번호를 지정할 때는 `AS` 접두사를 제외하세요. 예를 들어 `AS1423` 대신 `1423`을 입력합니다.
  :::

### stat 필터 선택

Network Analytics 통계 항목 중 하나와 연결된 데이터 유형을 기준으로 필터링하려면, 통계 위에 마우스를 올렸을 때 나타나는 **Filter** 및 **Exclude** 버튼을 사용하세요.

## 적용한 필터로 Network Firewall 규칙 생성

:::note

이 기능은 Magic Transit 및 Cloudflare WAN(이전 Magic WAN) 사용자만 사용할 수 있습니다.
:::

**Create Network Firewall rule**을 선택하면 Network Analytics에서 선택한 필터와 일치하는 모든 트래픽을 차단하는 [Network Firewall](/cloudflare-network-firewall/) 규칙을 생성할 수 있습니다.

일부 필터는 새 Network Firewall 규칙 정의에 추가되지 않을 수 있습니다. 그러나 이후 Network Firewall에서 규칙을 추가로 구성할 수 있습니다.

## IP 프리픽스 이벤트 표시

**Show annotations** 토글을 활성화해 **Network Analytics** 보기에서 광고됨/철회됨 IP 프리픽스 이벤트에 대한 주석을 표시하거나 숨길 수 있습니다. 각 주석을 선택하면 더 자세한 내용을 확인할 수 있습니다.

![Network Analytics chart displaying IP prefix-related annotations.](~/assets/images/analytics/network-analytics/view-annotations.png)

## 기록되거나 모니터링된 트래픽 보기

[Network DDoS managed rules](/ddos-protection/managed-rulesets/network/)와 [Advanced DDoS Protection systems](/ddos-protection/advanced-ddos-systems/overview/)는 트래픽을 삭제하지 않는 `log` 또는 `monitoring` 모드를 제공합니다. 이러한 `log` 및 `monitoring` 모드 이벤트는 **Verdict** 및 **Outcome**/**Action** 필드를 기반으로 합니다.

이러한 트래픽 이벤트를 필터링하려면 다음 단계를 따르세요.

1. Cloudflare 대시보드에서 **Network Analytics** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/networking-insights/analytics/network-analytics/transport-analytics" />

2. **DDoS managed rules** 탭으로 이동합니다.
3. **Add filter**를 선택합니다.
   - `Verdict equals drop`으로 설정합니다.
   - `Action equals pass`로 설정합니다.
4. **Apply**를 선택합니다.

`verdict`를 `drop`, `outcome`을 `pass`로 설정하면 감지로 표시되었지만(즉 verdict가 `drop`) 실제로는 삭제되지 않은(예: outcome이 `pass`) 트래픽을 필터링하게 됩니다.

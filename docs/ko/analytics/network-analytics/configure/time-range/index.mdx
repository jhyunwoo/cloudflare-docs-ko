## 기간 드롭다운 사용

기간 드롭다운을 사용해 Network Analytics가 데이터를 표시하는 시간 범위를 변경합니다. 기간을 선택하면 전체 보기가 그 선택을 반영하도록 업데이트됩니다.

Network Analytics 대시보드에서 조회할 수 있는 과거 데이터 범위는 112일입니다.

*Previous 30 minutes*를 선택하면 **Network Analytics** 카드에 지난 30분 데이터가 표시되고 20초마다 갱신됩니다. 보기가 계속 자동 업데이트되고 있음을 알리기 위해 통계 드롭다운 옆에 *Live* 알림이 표시됩니다.

![Timeframe drop-down with Previous 30 minutes selected.](~/assets/images/analytics/network-analytics/timeframe-selector.png)

## 차트 확대

특정 기간을 확대하려면 **Packets summary**(또는 **Bits summary**) 차트에서 드래그하여 영역을 지정합니다. 축소하려면 시간 범위 선택기에서 **X**를 선택합니다.

![User zooming in a given period in the Network Analytics traffic chart.](/images/analytics/network-analytics/chart-zoom-in.gif)

확대하면 유효 해상도는 올라가고 축소하면 내려갑니다. 이는 [Adaptive Bit Rate](/analytics/network-analytics/understand/concepts/#adaptive-bit-rate-sampling) 때문입니다. 즉, 몇 초 동안만 지속된 큰 패킷 급증도 24시간 이상의 데이터를 표시하는 차트에서 분석하면 덜 두드러져 보일 수 있습니다.

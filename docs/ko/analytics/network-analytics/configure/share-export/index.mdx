## Network Analytics 필터 공유

Network Analytics에서 필터를 추가하고 시간 범위를 지정하면 URL이 해당 매개변수를 반영하도록 변경됩니다.

데이터 보기 상태를 공유하려면 URL을 복사해 다른 사용자에게 보내면 동일한 보기로 작업할 수 있습니다.

## 샘플 로그 데이터 내보내기

한 번에 **Packet sample log**에서 최대 100개의 원시 이벤트를 내보낼 수 있습니다. 이 옵션은 Cloudflare 데이터를 별도의 시스템이나 데이터베이스에 저장된 데이터와 결합해 분석해야 할 때 유용합니다. 예를 들어 <GlossaryTooltip term="SIEM">SIEM 시스템</GlossaryTooltip>이 있습니다.

로그 데이터를 내보내려면 다음을 따르세요.

1. **Export**를 선택합니다.
2. 내보낸 데이터를 렌더링할 형식으로 CSV 또는 JSON을 선택합니다. 다운로드되는 파일 이름은 선택한 시간 범위를 반영하며 다음 패턴을 사용합니다.

```txt
network-analytics-attacks-<START_TIME>-<END_TIME>.json
```

## Network Analytics 보고서 내보내기

Network Analytics에서 스냅샷 보고서를 인쇄하거나 다운로드하려면 **Print report**를 선택하세요. 웹 브라우저의 인쇄 인터페이스에 인쇄 또는 PDF 저장 옵션이 표시됩니다.

Cloudflare Network Analytics(버전 2)는 네트워크 및 전송 계층 트래픽 패턴과 DDoS 공격에 대해 거의 실시간에 가까운 가시성을 제공합니다. Network Analytics는 패킷 및 비트 수준 데이터를 시각화하며, 이는 GraphQL Analytics API의 Network Analytics 데이터세트에서 제공되는 데이터와 동일합니다.

<Render file="network-analytics-requirements" product="analytics" />

Network Analytics에 대한 기술적 심화 내용은 [블로그 게시물](https://blog.cloudflare.com/building-network-analytics-v2/)을 참고하세요.

## 참고 사항

* Network Analytics 로그는 Magic Transit 고객 프리픽스/임대 IP 주소 또는 Spectrum 애플리케이션의 IP 트래픽을 가리킵니다. 이 로그는 Cloudflare 계정의 [zones](/fundamentals/concepts/accounts-and-zones/#zones)와 직접 연결되어 있지 않습니다.

* Network Analytics의 데이터 보존 기간은 16주입니다. 또한 8주보다 오래된 데이터는 좁은 시간 범위를 사용할 때 해상도가 낮을 수 있습니다.

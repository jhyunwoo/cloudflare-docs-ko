## Network Analytics 대시보드 보기

1. Cloudflare 대시보드에서 **Network Analytics** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/networking-insights/analytics/network-analytics/transport-analytics" />

2. Magic Transit 또는 Spectrum에 접근 권한이 있는 계정을 선택합니다.
3. 표시되는 데이터를 구성합니다. [시간 범위를 조정](/analytics/network-analytics/configure/time-range/)하고, [주요 메트릭을 선택](/analytics/network-analytics/configure/displayed-data/#select-high-level-metric)하며(총 패킷 또는 총 바이트), [필터를 적용](/analytics/network-analytics/configure/displayed-data/#apply-filters)하는 등의 작업을 할 수 있습니다.

## API로 Network Analytics 데이터 가져오기

사용 가능한 [Network Analytics nodes](/analytics/graphql-api/migration-guides/network-analytics-v2/node-reference/)를 이용해 [GraphQL Analytics API](/analytics/graphql-api/)로 데이터를 쿼리하세요.

## Network Analytics 로그를 서드파티 서비스로 보내기

스토리지 서비스, <GlossaryTooltip term="SIEM">SIEM 솔루션</GlossaryTooltip>, 또는 로그 관리 공급자로 Network analytics 로그를 보내는 [Logpush 작업](/logs/logpush/logpush-job/enable-destinations/)을 생성하세요.

## 제한 사항

`Analytics` 역할을 가진 사용자는 ID에 대한 가시성은 있지만 Network Analytics 대시보드에서 다음 항목은 볼 수 없습니다.

- 터널 이름
- 프리픽스 이름
- [Cloudflare Network Firewall](/cloudflare-network-firewall/) 규칙
- [DDoS managed rulesets](/ddos-protection/managed-rulesets/)
- Override 이름

다음 제한 사항이 Workers Analytics Engine에 적용됩니다.

* Analytics Engine은 `writeDataPoint` 호출당 최대 blob 20개, double 20개, index 1개를 허용합니다.
* 요청 내 모든 blob의 총 크기는 **16 KB**를 초과할 수 없습니다. blobs 필드의 16 KB 제한은 `writeDataPoints()`로 하나의 요청에 여러 데이터 포인트를 포함하더라도 **각 개별 데이터 포인트**마다 적용됩니다.
* 각 index는 96바이트를 넘을 수 없습니다.
* Worker 한 번의 호출(클라이언트 HTTP 요청)당 최대 250개의 데이터 포인트를 기록할 수 있습니다. `writeDataPoint`를 한 번 호출할 때마다 이 제한에 포함됩니다.

## 데이터 보존 기간

Workers Analytics Engine에 기록된 데이터는 3개월 동안 저장됩니다.

더 긴 보존 기간이 필요하다면 [Cloudflare Developers Discord](https://discord.cloudflare.com/)의 `#analytics-engine` 채널에 참여해 어떤 것을 만들고 있는지 알려주세요.

## bin <Badge text="New" variant="tip" size="small" />

사용법:

```sql
bin(<expression>)
```

`bin`은 인수의 이진 표현을 담은 문자열을 반환합니다.

예시:

```sql
-- 1의 이진 표현 구하기
bin(1)
-- 문자열의 이진 표현 구하기
bin('abc')
```

## hex <Badge text="New" variant="tip" size="small" />

사용법:

```sql
hex(<expression>)
```

`hex`는 인수의 16진수 표현을 담은 문자열을 반환합니다.

예시:

```sql
-- 1의 16진수 표현 구하기
hex(1)
-- 문자열의 16진수 표현 구하기
hex('abc')
```

## 산술 연산자

| Operator | Description |
| -------- | ----------- |
| `+`      | 덧셈        |
| `-`      | 뺄셈        |
| `*`      | 곱셈        |
| `/`      | 나눗셈      |
| `%`      | 나머지      |

## 비교 연산자

| Operator     | Description                                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------------- |
| `=`          | 같음                                                                                                          |
| `<`          | 작음                                                                                                          |
| `>`          | 큼                                                                                                            |
| `<=`         | 작거나 같음                                                                                                   |
| `>=`         | 크거나 같음                                                                                                   |
| `<>` or `!=` | 같지 않음                                                                                                     |
| `IN`         | 앞선 식의 값이 목록 안에 있으면 참<br/>`column IN ('a', 'list', 'of', 'values')`                             |
| `NOT IN`     | 앞선 식의 값이 목록 안에 없으면 참<br/>`column NOT IN ('a', 'list', 'of', 'values')`                         |

포함 범위 검사에는 `BETWEEN` 연산자도 지원합니다. `a [NOT] BETWEEN b AND c` 형식으로 사용합니다.

### 패턴 매칭 연산자 <Badge text="New" variant="tip" size="small" />

| Operator    | Description                                                                                             |
| ----------- | ------------------------------------------------------------------------------------------------------- |
| `LIKE`      | 문자열이 패턴과 일치하면 참(대소문자 구분)<br/>`column LIKE 'pattern%'`                                 |
| `NOT LIKE`  | 문자열이 패턴과 일치하지 않으면 참(대소문자 구분)<br/>`column NOT LIKE 'pattern%'`                      |
| `ILIKE`     | 문자열이 패턴과 일치하면 참(대소문자 미구분)<br/>`column ILIKE 'pattern%'`                              |
| `NOT ILIKE` | 문자열이 패턴과 일치하지 않으면 참(대소문자 미구분)<br/>`column NOT ILIKE 'pattern%'`                   |

패턴 매칭은 두 가지 와일드카드 문자를 지원합니다.

- `%`는 0개 이상의 임의 문자 시퀀스와 일치합니다.
- `_`는 임의의 단일 문자와 일치합니다.

예시:

```sql
-- "error"로 시작하는 문자열 매칭
WHERE blob1 LIKE 'error%'

-- ".jpg"로 끝나는 문자열 매칭(대소문자 미구분)
WHERE blob2 ILIKE '%.jpg'

-- 어디에든 "test"를 포함하는 문자열 매칭
WHERE blob3 LIKE '%test%'

-- "log"로 시작하는 정확히 5글자 문자열 매칭
WHERE blob4 LIKE 'log__'

-- "debug"를 포함하는 문자열 제외(대소문자 미구분)
WHERE blob5 NOT ILIKE '%debug%'
```

## 불리언 연산자

| Operator | Description                                      |
| -------- | ------------------------------------------------ |
| `AND`    | 불리언 "AND"(양쪽이 모두 참일 때 참)             |
| `OR`     | 불리언 "OR"(한쪽 또는 양쪽이 모두 참일 때 참)    |
| `NOT`    | 불리언 "NOT"(뒤따르는 식이 거짓일 때 참, 그 반대도 마찬가지) |

## 단항 연산자

| Operator | Description                         |
| -------- | ----------------------------------- |
| `-`      | 부호 반전 연산자(예: `-42`)         |

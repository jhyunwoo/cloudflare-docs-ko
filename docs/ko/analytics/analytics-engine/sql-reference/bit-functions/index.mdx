## bitAnd <Badge text="New" variant="tip" size="small" />

사용법:

```sql
bitAnd(a, b)
```

`bitAnd`는 식 `a`와 `b`의 비트 단위 AND 결과를 반환합니다.

예시:

```sql
-- 0b1 & 0b11 수행
bitAnd(1, 3)
-- double1의 정수값에서 최하위 비트 추출
bitAnd(toUInt8(double1), 1)
```

## bitCount <Badge text="New" variant="tip" size="small" />

사용법:

```sql
bitCount(a)
```

`bitCount`는 `a`의 이진 표현에서 1로 설정된 비트 수를 반환합니다.

예시:

```sql
-- 부동소수점 `double1`의 이진 표현에서 1 비트 수 구하기
bitCount(double1)
-- 정수로 해석한 `double1`의 이진 표현에서 1 비트 수 구하기
bitCount(toUInt32(double1))
-- 1 비트가 최소 5개인 행 선택
SELECT * WHERE bitCount(double1) > 5
```

## bitHammingDistance <Badge text="New" variant="tip" size="small" />

사용법:

```sql
bitHammingDistance(x, y)
```

`bitHammingDistance`는 `x`와 `y` 사이에서 서로 다른 비트 수를 반환합니다.

예시:

```sql
-- 0 반환
bitHammingDistance(1, 1)
-- 2 반환
bitHammingDistance(3, 0)
```

## bitNot <Badge text="New" variant="tip" size="small" />

사용법:

```sql
bitNot(a)
```

`bitNot`는 `a`의 모든 비트를 뒤집은 값을 반환합니다.

예시:

```sql
bitNot(1)
```

## bitOr <Badge text="New" variant="tip" size="small" />

사용법:

```sql
bitOr(a, b)
```

`bitOr`는 `a`와 `b`의 포괄적 비트 OR 결과를 반환합니다.

예시:

```sql
-- 3 반환
bitOr(1, 2)
```

## bitRotateLeft <Badge text="New" variant="tip" size="small" />

사용법:

```sql
bitRotateLeft(a, n)
```

`bitRotateLeft`는 `a`의 모든 비트를 왼쪽으로 `n`비트 회전시킵니다.

예시:

```sql
-- 2 반환
bitRotateLeft(1, 1)
-- 1 반환
bitRotateLeft(128, 1)
```

## bitRotateRight <Badge text="New" variant="tip" size="small" />

사용법:

```sql
bitRotateRight(a, n)
```

`bitRotateRight`는 `a`의 모든 비트를 오른쪽으로 `n`비트 회전시킵니다.

예시:

```sql
-- 128 반환
bitRotateRight(1, 1)
-- 3 반환
bitRotateRight(12, 2)
```


`bitShiftLeft`는 `a`의 모든 비트를 왼쪽으로 `n`비트 시프트합니다.

`bitShiftRight`는 `a`의 모든 비트를 오른쪽으로 `n`비트 시프트합니다.

## bitTest <Badge text="New" variant="tip" size="small" />

사용법:

```sql
bitTest(a, n)
```

`bitTest`는 숫자 `a`에서 `n`번째 비트의 값을 반환합니다.

예시:

```sql
-- 1 반환
bitTest(3, 1)
-- 0 반환
bitTest(2, 1)
-- 특정 비트가 1인 행 선택
SELECT * WHERE bitTest(double1, 2)
```

## bitXor <Badge text="New" variant="tip" size="small" />

사용법:

```sql
bitXor(a, b)
```

`bitXor`는 `a`와 `b`의 비트 단위 배타적 OR 결과를 반환합니다.

예시:

```sql
-- 3 반환
bitXor(1, 2)
-- 0 반환
bitXor(3, 3)
```

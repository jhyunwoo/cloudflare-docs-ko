## formatDateTime

사용법:

```sql
formatDateTime(<datetime expression>, <format string>[, <timezone string>])
```

`formatDateTime`은 제공된 형식 문자열에 따라 datetime을 문자열로 출력합니다. 지원되는 형식 옵션 목록은 [ClickHouse 문서](https://clickhouse.com/docs/en/sql-reference/functions/date-time-functions/#formatdatetime)를 참고하세요.

예시:

```sql
-- 현재 YYYY-MM-DD를 UTC로 출력
formatDateTime(now(), '%Y-%m-%d')

-- datetime의 타임존 기준으로 YYYY-MM-DD 출력
formatDateTime(<a datetime with a timezone>, '%Y-%m-%d')
formatDateTime(toDateTime('2022-12-01 16:17:00', 'America/New_York'), '%Y-%m-%d')

-- UTC 기준으로 YYYY-MM-DD 출력
formatDateTime(<a datetime with a timezone>, '%Y-%m-%d', 'Etc/UTC')
formatDateTime(toDateTime('2022-12-01 16:17:00', 'America/New_York'), '%Y-%m-%d', 'Etc/UTC')
```

## toDateTime

사용법:

```sql
toDateTime(<expression>[, 'timezone string'])
```

`toDateTime`은 식을 datetime으로 변환합니다. 이 함수는 ISO 8601 스타일 타임존을 지원하지 않으므로, UTC가 아닌 시간이라면 두 번째 선택 인수로 타임존을 제공해야 합니다.

예시:

```sql
-- double1에 초 단위 unix timestamp가 들어 있음
toDateTime(double1)

-- blob1에 'YYYY-MM-DD hh:mm:ss' 형식의 datetime이 들어 있음
toDateTime(blob1)

-- 리터럴 값:
toDateTime(355924804) -- unix timestamp
toDateTime('355924804') -- unix timestamp를 담은 문자열
toDateTime('1981-04-12 12:00:04') -- 'YYYY-MM-DD hh:mm:ss' 형식의 datetime 문자열

-- New York 시간 기준으로 날짜 해석
toDateTime('2022-12-01 16:17:00', 'America/New_York')
```

## toDayOfWeek <Badge text="New" variant="tip" size="small" />

사용법:

```sql
toDayOfWeek(<datetime>)
```

`toDayOfWeek`는 datetime을 받아 요일을 숫자로 반환합니다.

월요일은 `1`, 화요일은 `2` 식으로 반환합니다.

예시:

```sql
-- 2025년 10월 27일 월요일에 대해 숫자 1 반환
toDayOfWeek(toDateTime('2025-10-27 00:00:00'))

-- 2025년 10월 28일 화요일에 대해 숫자 2 반환
toDayOfWeek(toDateTime('2025-10-28 00:00:00'))

-- 2025년 11월 2일 일요일에 대해 숫자 7 반환
toDayOfWeek(toDateTime('2025-11-02 00:00:00'))
```

## toStartOfInterval

사용법:

```sql
toStartOfInterval(<datetime>, INTERVAL '<n>' <unit>[, <timezone string>])
```

`toStartOfInterval`은 datetime을 지정한 간격의 가장 가까운 시작 시점으로 내림합니다. 균등한 시간 구간으로 데이터를 그룹화할 때 유용합니다.

예시:

```sql
-- 현재 시간을 가장 가까운 15분 단위 시작 시점으로 내림
toStartOfInterval(now(), INTERVAL '15' MINUTE)

-- timestamp를 해당 날짜의 시작 시점으로 내림
toStartOfInterval(timestamp, INTERVAL '1' DAY)

-- 각 시간 구간에 기록된 데이터 포인트 수 집계
SELECT
  toStartOfInterval(timestamp, INTERVAL '1' HOUR) AS hour,
  sum(_sample_interval) AS count
FROM your_dataset
GROUP BY hour
ORDER BY hour ASC
```

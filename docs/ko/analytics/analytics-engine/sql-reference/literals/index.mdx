다음 리터럴이 지원됩니다.

| Type          | Syntax                                                                                                   |
| ------------- | -------------------------------------------------------------------------------------------------------- |
| integer       | `42`, `-42`                                                                                              |
| double        | `4.2`, `-4.2`                                                                                            |
| string        | `'so long and thanks for all the fish'`                                                                  |
| boolean       | `true` 또는 `false`                                                                                      |
| time interval | `INTERVAL '42' DAY`<br/>`YEAR`, `MONTH`, `DAY`, `HOUR`, `MINUTE`, `SECOND` 간격이 지원됩니다.         |

## if

사용법:

```sql
if(<condition>, <true_expression>, <false_expression>)
```

`<condition>`이 참으로 평가되면 `<true_expression>`을 반환하고, 그렇지 않으면 `<false_expression>`을 반환합니다.

예시:

```sql
if(temp > 20, 'It is warm', 'Bring a jumper')
```

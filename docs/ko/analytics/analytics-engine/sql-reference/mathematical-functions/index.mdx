## intDiv

사용법:

```sql
intDiv(a, b)
```

`a`를 `b`로 나눈 뒤 결과를 가장 가까운 정수 아래 방향으로 내림합니다.

## log <Badge text="New" variant="tip" size="small" />

사용법:

```sql
log(<expression>)
```

`log`는 주어진 숫자의 자연로그를 반환합니다. 별칭 `ln`도 사용할 수 있습니다.

예시:

```sql
-- double1 열의 자연로그 구하기
log(double1)
```

## pow <Badge text="New" variant="tip" size="small" />

사용법:

```sql
pow(<expression>, <expression>)
```

`pow`는 첫 번째 인수를 두 번째 인수의 거듭제곱으로 계산한 값을 반환합니다.

예시:

```sql
-- double1 열의 제곱 구하기
pow(double1, 2)
```

## round <Badge text="New" variant="tip" size="small" />

사용법:

```sql
round(<expression>[, n])
```

`round`는 숫자를 가장 가까운 정수 또는 두 번째 인수로 지정한 소수점 자릿수로 반올림한 값을 반환합니다.

예시:

```sql
-- 5.5를 6으로 반올림
round(5.5)
-- 3.14를 3.1로 반올림
round(3.14, 1)
```

## floor <Badge text="New" variant="tip" size="small" />

사용법:

```sql
floor(<expression>[, n])
```

`floor`는 숫자를 정수로 내림하거나, 두 번째 인수로 지정한 소수점 자릿수까지 내림한 값을 반환합니다.

예시:

```sql
-- 5.5를 5로 내림
floor(5.5)
-- 3.14를 3.1로 내림
floor(3.14, 1)
```

## ceil <Badge text="New" variant="tip" size="small" />

사용법:

```sql
ceil(<expression>[, n])
```

`ceil`은 숫자를 정수로 올림하거나, 두 번째 인수로 지정한 소수점 자릿수까지 올림한 값을 반환합니다.

예시:

```sql
-- 5.5를 6으로 올림
ceil(5.5)
-- 3.14를 3.2로 올림
ceil(3.14, 1)
```

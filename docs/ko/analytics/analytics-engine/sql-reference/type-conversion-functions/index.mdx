## toUInt8 <Badge text="New" variant="tip" size="small" />

사용법:

```sql
toUInt8(<expression>)
```

숫자 식 또는 10진수 문자열로 평가되는 식을 부호 없는 8비트 정수로 변환합니다.

음수에 대한 동작은 정의되어 있지 않습니다.

## toUInt32

사용법:

```sql
toUInt32(<expression>)
```

숫자 식 또는 10진수 문자열로 평가되는 식을 부호 없는 32비트 정수로 변환합니다.

음수에 대한 동작은 정의되어 있지 않습니다.

Workers Analytics Engine은 Workers에서 데이터 포인트를 기록하는 [내장 API](/analytics/analytics-engine/get-started/)와, 해당 데이터를 조회하는 [SQL API](/analytics/analytics-engine/sql-api/)를 통해 대규모 무제한 카디널리티 분석을 제공합니다.

Workers Analytics Engine으로 다음을 할 수 있습니다.

* 자체 고객에게 맞춤형 분석을 제공
* 사용량 기반 과금 시스템 구축
* 고객별 또는 사용자별 서비스 상태 파악
* 자주 호출되는 코드 경로에 계측을 추가하면서도 성능 저하나 외부 분석 시스템의 이벤트 과부하를 방지

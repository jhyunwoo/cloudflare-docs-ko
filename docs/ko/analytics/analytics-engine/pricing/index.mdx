Workers Analytics Engine은 기록된 데이터 포인트와 읽기 쿼리 두 가지 기준으로 과금됩니다.

| Plan             | 기록된 데이터 포인트                                               | 읽기 쿼리                                                   |
| ---------------- | ------------------------------------------------------------------ | ----------------------------------------------------------- |
| **Workers Paid** | 월 1,000만 개 포함 <br /> (초과 100만 개당 +$0.25)                | 월 100만 개 포함 (초과 100만 개당 +$1.00)                   |
| **Workers Free** | 일 100,000개 포함                                                  | 일 10,000개 포함                                            |

:::note[요금 적용 시점]

현재는 Workers Analytics Engine 사용에 대해 과금되지 않습니다. 여기의 요금 정보는 향후 몇 달 안에 Cloudflare가 사용량 과금을 시작할 때 비용을 예측할 수 있도록 미리 제공되는 정보입니다.

Enterprise 고객이라면 Workers Analytics Engine 요금 및 청구 정보에 대해 계정 팀에 문의하세요.
:::

### 기록된 데이터 포인트

Worker에서 [`writeDataPoint()`](/analytics/analytics-engine/get-started/#2-write-data-points-from-your-worker)를 호출할 때마다 기록된 데이터 포인트 1개로 계산됩니다.

기록된 각 데이터 포인트의 비용은 동일합니다. 차원이나 카디널리티를 더해도 추가 비용이 없고, 하나의 데이터 포인트에 더 많은 데이터를 기록해도 추가 비용이 없습니다.

### 읽기 쿼리

Workers Analytics Engine의 [SQL API](/analytics/analytics-engine/sql-api/)에 POST 요청을 보낼 때마다 읽기 쿼리 1개로 계산됩니다.

각 읽기 쿼리의 비용은 동일합니다. 쿼리가 더 복잡하다고 추가 비용이 발생하지 않으며, 몇 개의 행만 읽든 많은 행을 읽든 추가 비용은 없습니다.

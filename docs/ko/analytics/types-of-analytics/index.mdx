Cloudflare Analytics는 Cloudflare 네트워크에서 생성되는 모든 메타데이터를 아우르는 종합 제품입니다. 이러한 인사이트는 Cloudflare 대시보드를 통해 확인할 수 있습니다. 대시보드의 위치에 따라 수집된 메타데이터의 서로 다른 측면이 표시됩니다.

## 계정 수준 분석

### 계정 분석(Account Analytics) (beta)

Cloudflare 대시보드에 로그인한 뒤 **Analytics & Logs** 아래에서 사용할 수 있는 Account Analytics (beta)는 Cloudflare 계정에 속한 [모든 도메인의 트래픽 개요](/analytics/account-and-zone-analytics/account-analytics/)를 보여 줍니다. 여기에는 국가별 요청 및 대역폭, 보안, 캐시, 오류 관련 정보 등이 포함됩니다. Account Analytics에 접근하려면 [Cloudflare 대시보드에 로그인](https://dash.cloudflare.com/login)하고, 해당 계정을 선택한 다음 **Analytics & Logs** > **Account Analytics**로 이동하세요.

### Network Analytics

Network Analytics는 [네트워크 및 전송 계층 트래픽 패턴과 DDoS 공격에 대한 가시성](/analytics/network-analytics/)을 제공합니다.

Network Analytics 대시보드는 [Spectrum](/spectrum/), [Magic Transit](/magic-transit/), 또는 [Bring Your Own IP (BYOIP)](/byoip/)를 사용하는 Enterprise 도메인 플랜 고객에게만 제공됩니다.

### Web Analytics

Web Analytics(이전 명칭 Browser Insights)는 [웹사이트를 위한 무료 프라이버시 중심 분석](/web-analytics/)을 제공합니다. Web Analytics는 방문자의 개인 데이터를 수집하지 않으며, 방문자가 실제로 경험한 웹 페이지 성능을 자세히 파악할 수 있게 해줍니다.

### Carbon Impact Report

Carbon Impact Report는 사용량 기준으로 Cloudflare 서비스를 사용할 때 인터넷 평균과 비교한 [탄소 절감 보고서](https://blog.cloudflare.com/understand-and-reduce-your-carbon-impact-with-cloudflare/)를 제공합니다.

Cloudflare는 100% 재생 가능 에너지원 사용에 전념할 뿐 아니라, 2010년부터 네트워크 운영으로 인해 [배출된 모든 온실가스를 제거](https://blog.cloudflare.com/cloudflare-committed-to-building-a-greener-internet/)하는 데에도 힘쓰고 있습니다.

## 특정 자산과 관련된 분석

Cloudflare를 통해 프록시되는 각 도메인에 대해 집계된 트래픽, 보안, 성능 메트릭에 접근할 수 있습니다. 이러한 분석에 접근하려면 [Cloudflare 대시보드에 로그인](https://dash.cloudflare.com/login)하고 계정과 도메인을 선택한 다음 **Analytics & Logs** 섹션으로 이동하세요.

**Analytics & Logs** 섹션에서 제공되는 데이터는 다음과 같습니다.

* **HTTP Traffic** - 요청, 데이터 전송, 페이지 뷰, 방문, API 요청.
* **Security** - 총 위협 수, 상위 크롤러/봇, 속도 제한, 차단된 총 위협 수.
* **Performance** - 원본 성능, 절약된 대역폭.
* **Edge Reachability** - Enterprise 고객을 위한 [Last mile insights](/network-error-logging/).
* **Workers** - 영역별 Workers 및 계정별 Workers KV와 관련된 [상세 정보](/workers/observability/metrics-and-analytics/).
* **Logs** - Enterprise 고객을 위한 Cloudflare 제품 생성 메타데이터의 [상세 로그](/logs/).
* **Instant logs** - 도메인에 대한 [실시간 트래픽 스트림](/logs/instant-logs/). Enterprise 고객은 Cloudflare 대시보드 또는 명령줄 인터페이스(CLI)에서 이 라이브 스트림에 접근할 수 있습니다.

## 제품별 분석

자산에 제공되는 분석 외에도 특정 제품과 관련된 분석에 접근할 수 있습니다.

* [Bot Analytics](/bots/bot-analytics/) - 알려진 봇, 자동화 가능성이 높은 트래픽, 사람일 가능성이 높은 트래픽 등에 해당하는 요청을 보여 줍니다.
* [Cache Analytics](/cache/performance-review/cache-analytics/) - 리소스가 캐시에 없거나, 만료되었거나, 캐싱 대상이 아닌지 판단하는 데 도움이 되는 인사이트를 제공합니다.
* [DNS Analytics](/dns/additional-options/analytics/) - 영역에 대한 DNS 쿼리 인사이트를 제공합니다.
* [Load Balancing Analytics](/load-balancing/reference/load-balancing-analytics/) - 로드 밸런서 스티어링 결정과 관련된 트래픽 인사이트를 얻는 데 도움이 되는 메트릭을 제공합니다.
* [Security Events](/waf/analytics/security-events/) - Cloudflare WAF와 HTTP DDoS 보호 시스템이 탐지한 공격 및 완화 메트릭을 강조합니다.
* [Security Analytics](/waf/analytics/security-analytics/) - WAF와 DDoS 보호 시스템 같은 보안 조치의 영향을 받지 않은 요청을 포함해 모든 수신 HTTP 요청에 대한 정보를 표시합니다.

## GraphQL API

Cloudflare 대시보드에서 제공되는 분석 및 로그 정보를 시각화하는 방식을 더 세밀하게 제어하고 싶다면 [GraphQL Analytics API](/analytics/graphql-api/)를 사용해 맞춤형 뷰를 구축하세요. 이 API는 기존 Zone Analytics API를 대체하고 기능을 확장합니다.

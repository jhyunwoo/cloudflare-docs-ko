이 튜토리얼은 [New Relic One Cloudflare Quickstart](https://newrelic.com/instant-observability/cloudflare/fc2bb0ac-6622-43c6-8c1f-6a4c26ab5434)를 사용해 Cloudflare 메트릭을 분석하는 방법을 설명합니다.

## 사전 요구 사항

Cloudflare 로그 데이터를 New Relic으로 보내기 전에 다음을 확인하세요.

- Cloudflare Logs가 활성화된 Cloudflare Enterprise 계정이 있어야 합니다.
- New Relic 계정이 있어야 합니다.
- [Logpush to New Relic](/logs/logpush/logpush-job/enable-destinations/new-relic/)을 구성해야 합니다.

## 작업 1 - Cloudflare Network Logs quickstart 설치

1. New Relic에 로그인합니다.
2. Instant Observability 버튼(오른쪽 상단)을 클릭합니다.
3. **Cloudflare Network Logs**를 검색합니다.

![Cloudflare Network Logs install screen](~/assets/images/fundamentals/new-relic/screenshots/cloudflare-network-logs.png)

4. **Install this quickstart**를 클릭합니다.
5. 안내에 따라 배포를 진행합니다.

## 작업 2 - Cloudflare 대시보드 보기

New Relic 대시보드 페이지에서 대시보드를 볼 수 있습니다. 대시보드에는 다음 정보가 포함됩니다.

### 개요

Cloudflare 네트워크 위의 웹사이트 및 애플리케이션에서 가장 중요한 메트릭을 빠르게 파악할 수 있습니다.

![Cloudflare Network Logs install screen](~/assets/images/fundamentals/new-relic/dashboard/dash-1.png)

### 보안

웹 애플리케이션 방화벽(WAF)이 조치를 취한 위협 수, 시간 경과에 따른 위협, 상위 위협 국가 등을 포함해 웹사이트와 애플리케이션에 대한 위협 인사이트를 제공합니다.

![Cloudflare Network security metrics screen](~/assets/images/fundamentals/new-relic/dashboard/dash-2.png)

### 성능

성능 문제와 캐시 구성 오류를 식별하고 해결합니다. 메트릭에는 총 요청 수, 총 요청 대비 캐시된 요청 수, 총 요청 대비 원본 요청 수가 포함됩니다.

![Cloudflare Network Logs performance metrics screen](~/assets/images/fundamentals/new-relic/dashboard/dash-3.png)

### 신뢰성

웹사이트와 애플리케이션의 가용성에 대한 인사이트를 제공합니다. 메트릭에는 시간 경과에 따른 엣지 응답 상태, 시간 경과에 따른 `3xx`/`4xx`/`5xx` 오류 비율 등이 포함됩니다.

![Cloudflare Network Logs reliability metrics screen](~/assets/images/fundamentals/new-relic/dashboard/dash-4.png)

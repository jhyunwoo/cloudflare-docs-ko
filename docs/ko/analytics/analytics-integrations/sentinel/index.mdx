Cloudflare는 Cloudflare 데이터를 더 쉽게, 그리고 중앙 집중식 공간에서 분석할 수 있도록 Microsoft Sentinel과 통합을 제공합니다. 현재 이 커넥터는 두 가지 버전으로 제공됩니다. 설정이 더 쉽고 비용 관리가 용이하며 [Sentinel Data Lake](https://learn.microsoft.com/en-us/azure/sentinel/datalake/sentinel-lake-overview)와 통합되는 최신 Codeless Connector 통합 사용을 권장합니다.

**[Sentinel CCF Solution](https://marketplace.microsoft.com/en-us/product/azure-application/cloudflare.azure-sentinel-solution-cloudflare-ccf?tab=Overview)** (권장): Codeless Connector Framework(CCF)는 파트너, 고급 사용자, 개발자가 Microsoft Sentinel로 데이터를 수집하는 사용자 지정 커넥터를 만들 수 있게 해줍니다.

**[Sentinel Function Based Connector](https://azuremarketplace.microsoft.com/en-us/marketplace/apps/cloudflare.cloudflare_sentinel?tab=Overview)**: Microsoft Sentinel용 Cloudflare 커넥터는 [Azure Functions](https://azure.microsoft.com/en-us/products/functions)를 사용해 Cloudflare Logpush 서비스의 보안 로그를 처리하고 이를 SIEM 플랫폼으로 직접 수집합니다.

이 가이드는 Azure Blob Storage를 사용해 Microsoft Sentinel의 새로운 CCF 커넥터와 Cloudflare 로그를 통합하는 명확한 단계별 지침을 제공합니다. 이 단계를 따르면 Microsoft Sentinel 내에서 Cloudflare 로그를 안전하게 수집, 저장, 분석하여 조직의 보안 모니터링 및 사고 대응 역량을 강화할 수 있습니다.

## 1단계: 사전 요구 사항

- 리소스를 생성하고 관리할 수 있는 권한이 있는 Azure Subscription(Contributor/Owner 역할 권장)
- Azure 환경에 이미 설정된 Microsoft Sentinel Workspace
- Cloudflare 로그 저장용 Blob 컨테이너가 있는 Azure Storage Account
- 내보낼 로그가 있는 도메인에 접근할 수 있고 Logpush 작업을 구성할 권한이 있는 Cloudflare 계정

## 2단계: Logpush 작업 설정

1. [Cloudflare dashboard](https://dash.cloudflare.com/)에 로그인하고 계정과 도메인을 선택합니다.
2. **Analytics** > **Logs**로 이동한 뒤 **Logpush**를 선택합니다.
3. **Create Logpush Job**을 선택합니다. 내보낼 로그 유형(예: **HTTP requests**)을 선택합니다.
4. 대상에서 **Azure Blob Storage**를 선택합니다.
5. Azure Blob Storage 세부 정보를 입력합니다.
   - SAS Token(공유 액세스 서명)

   Azure Portal에서 SAS 토큰을 생성하려면 먼저 저장소 계정으로 이동합니다. **Data Storage** 섹션 아래에서 **Containers**를 선택하고 해당 컨테이너를 선택합니다. 설정에서 **Shared access signature**를 찾아 선택한 뒤 `write`, `create`와 같은 필요한 권한과 토큰 시작/만료 날짜를 지정합니다. 설정이 끝나면 SAS 토큰을 생성합니다.

6. Logpush 작업을 저장하고 활성화합니다.

전체 세부 사항은 [Cloudflare Logpush to Azure documentation](/logs/logpush/logpush-job/enable-destinations/azure/)를 참고하세요.

## 3단계: Azure 구성 및 Microsoft Sentinel에서 데이터 커넥터 배포

1. Azure Portal에 로그인하고 **Microsoft Sentinel** workspace로 이동합니다.
2. 탐색 모음에서 **Content Hub**를 선택하고 **Cloudflare**를 검색합니다.
3. 결과에서 **Cloudflare** 솔루션을 선택합니다.
4. 오른쪽 패널에서 **Install**을 선택합니다.
5. **Sentinel workspace**에서 **Data connectors**로 이동합니다.
6. **Cloudflare connector**를 검색합니다(**Cloudflare (using Azure Blob Storage)**로 표시될 수 있음).
7. 구성을 위해 커넥터를 선택합니다.

![Azure portal](~/assets/images/analytics/azure-portal.png)

## 4단계: 필수 필드 입력

Cloudflare 데이터 커넥터를 구성할 때 다음 정보를 제공해야 합니다.

- Blob 컨테이너 URL

컨테이너 URL을 확인하려면 Azure Portal에서 저장소 계정으로 이동하세요. **Data Storage** 아래에서 **Containers**를 선택한 뒤 Cloudflare에서 로그를 수신하는 해당 컨테이너를 선택합니다. 컨테이너 속성 섹션에 URL 링크가 표시됩니다.

- 저장소 계정의 리소스 그룹 이름
- 저장소 계정 위치
- Subscription ID
- Event grid topic name(재구성하는 경우에만 필요하며 초기 설정에는 불필요)

모든 정보를 입력한 뒤 **Connect**를 선택합니다.

원활한 로그 수집을 위해 모든 필드를 정확히 입력했는지 확인하세요.

![Configuration fields](~/assets/images/analytics/configuration.png)

## 5단계: 배포 완료

1. **Apply changes** 또는 **Connect**를 선택해 커넥터 설정을 완료합니다.
2. Sentinel의 Data connectors 페이지에서 Cloudflare 커넥터 상태가 **Connected**인지 확인합니다.
3. **Log Analytics** > **Logs** 아래 Sentinel workspace에 Cloudflare 로그가 나타나는지 확인합니다.
4. 로그가 보이지 않으면 Blob Storage 권한, Cloudflare Logpush 구성, Sentinel 커넥터 설정을 검토합니다.

![Data connectors](~/assets/images/analytics/data-connectors.png)

위 단계를 따르면 Azure Blob Storage를 사용해 Cloudflare 로그를 Microsoft Sentinel과 성공적으로 통합한 것입니다. 이 통합은 Cloudflare로 보호되는 환경에 대해 고급 보안 분석 및 사고 대응 기능을 제공합니다. 문제가 발생하면 각 구성 단계를 다시 검토하고 권한을 확인하며 Microsoft 공식 문서를 참고하세요.

![Cloudflare traffic overview](~/assets/images/analytics/traffic-overview.png)

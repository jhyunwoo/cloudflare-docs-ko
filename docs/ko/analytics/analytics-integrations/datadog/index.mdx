이 튜토리얼은 [Datadog용 Cloudflare Integration 타일](https://docs.datadoghq.com/integrations/cloudflare/)을 사용해 Cloudflare 메트릭을 분석하는 방법을 설명합니다.

## 개요

Datadog에서 Cloudflare 대시보드를 보기 전에, 이 통합의 특징은 다음과 같습니다.

- 모든 Cloudflare 고객 플랜(Free, Pro, Business, Enterprise)에서 사용 가능
- Cloudflare Analytics API 기반
- Cloudflare 웹 트래픽 및 DNS 메트릭만 제공
- Cloudflare Logs에 저장된 요청 로그 데이터는 포함하지 않음

## 작업 1 - Cloudflare 앱 설치

Datadog용 Cloudflare 앱을 설치하려면 다음 단계를 따르세요.

1. **Datadog**에 로그인합니다.

2. **Integrations** 탭을 클릭합니다.

3. **search box**에 _Cloudflare_ 를 입력하기 시작합니다. 검색 상자 아래에 앱 타일이 표시됩니다.
   ![Searching for Cloudflare App in the Datadog Integrations tab](~/assets/images/fundamentals/datadog/screenshots/datadog-integrations.png)

4. 설치를 시작하려면 **Cloudflare** 타일을 클릭합니다.

5. 다음으로 **Configuration**을 클릭한 뒤 아래 항목을 완료합니다.

   - **Account name**: (선택 사항) 임의의 값을 사용할 수 있습니다. Cloudflare에서 가져오는 사이트 데이터에는 영향을 주지 않습니다.

   - **Email**: 이 값은 계정을 안전하게 유지하는 데 도움을 줍니다. 분석 전용 Cloudflare 사용자를 만들고 읽기 전용 [_Analytics_ 역할](/fundamentals/manage-members/roles/)을 부여하는 것을 권장합니다. _Analytics_ 역할은 Enterprise 고객에게만 제공됩니다.

   - **API Key**: Cloudflare Global API 키를 입력합니다. 자세한 내용은 [API Keys](/fundamentals/api/get-started/keys/)를 참고하세요.

6. **Install Integration**을 클릭합니다.
   ![Configuring and installing the Datadog integration](~/assets/images/fundamentals/datadog/screenshots/cloudflare-tile-datadog-fill-details.png)

이제 Datadog용 Cloudflare 앱이 설치되었으며 대시보드를 볼 수 있습니다.

## 작업 2 - 대시보드 보기

기본적으로 대시보드는 Cloudflare 계정의 모든 사이트에 대한 메트릭을 표시합니다. 특정 도메인의 메트릭을 보려면 대시보드 필터를 사용하세요.

대시보드는 다음 메트릭을 표시합니다.

- **위협** (유형별 위협, 국가별 위협)
- **요청** (총 요청, 캐시된 요청, 캐시되지 않은 요청, 요청 수 기준 상위 국가, IP 클래스별 요청, 상위 콘텐츠 유형)
- **대역폭** (총 대역폭, 암호화/비암호화 트래픽, 캐시된 대역폭, 캐시되지 않은 대역폭)
- **캐싱** (캐시 적중률, 시간 경과에 따른 요청 캐싱 비율)
- **HTTP 응답 상태 오류**
- **페이지 뷰**
- **검색 엔진 봇 트래픽**
- **DNS** (DNS 쿼리, 응답 시간, 상위 호스트명, 유형별 쿼리, 오래된 쿼리와 캐시되지 않은 쿼리 비교)

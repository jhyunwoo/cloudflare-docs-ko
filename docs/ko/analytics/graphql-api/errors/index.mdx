GraphQL Analytics API는 HTTPS 요청과 JSON 응답을 기반으로 하는 RESTful API이며, 익숙한 HTTP 상태 코드(예: `404`, `500`, `504`)를 반환합니다. 하지만 일반적인 REST 방식과 달리 [GraphQL 사양](https://graphql.github.io/graphql-spec/June2018/#sec-Errors)에 따라 `200` 응답 안에도 오류가 포함될 수 있습니다.

모든 응답에는 `errors` 배열이 포함됩니다. 오류가 없으면 `null`이며, 오류가 발생하면 하나 이상의 오류 객체를 포함합니다. null이 아닌 오류 객체에는 다음 필드가 들어 있습니다.

* `message`: 오류를 설명하는 문자열입니다.
* `path`: 루트부터 시작하는 오류 관련 노드입니다. 경로 배열에 포함된 숫자(`0`, `1` 등)는 오류가 적용되는 zone을 나타냅니다. `0`은 목록의 첫 번째 zone(또는 하나만 조회할 경우 그 zone)을 의미합니다.
* `timestamp`: 오류가 발생한 UTC 날짜/시간입니다.

## 예시

```json
{
  "data": null,
  "errors": [
    {
      "message": "cannot request data older than 2678400s",
      "path": ["viewer", "zones", "0", "firewallEventsAdaptiveGroups"],
      "extensions": {
        "timestamp": "2019-12-09T21:27:19.195060142Z"
      }
    }
  ]
}
```

## 일반적인 오류 유형

### 서비스 사용 불가

샘플 오류 메시지:

* `unable to execute query, please try again later` (HTTP `503`)
* `too many queries in progress, please try again later` (HTTP `503`)

이 메시지는 일시적인 서버 측 문제를 나타냅니다. 첫 번째 메시지는 일반적으로 업스트림 데이터베이스에 연결할 수 없거나 오류를 반환했음을 의미합니다. 두 번째 메시지는 서버가 동시에 처리할 수 있는 최대 쿼리 수에 도달했음을 의미합니다.

잠시 후 요청을 다시 시도하세요. 오류가 계속되면 진행 중인 장애가 있는지 [Cloudflare 상태 페이지](https://www.cloudflarestatus.com/)를 확인하세요.

### 데이터세트 접근 제한 초과

샘플 오류 메시지:

* `cannot request data older than...` (HTTP `400`)
* `number of fields can't be more than...` (HTTP `400`)
* `limit must be positive number and not greater than...` (HTTP `400`)
* `query time range is too large...` (HTTP `400`)

이 메시지는 현재 [요금제](https://www.cloudflare.com/plans/)에서 해당 데이터세트에 허용된 범위를 쿼리가 초과했음을 의미하며, 상위 요금제로 업그레이드를 고려해야 할 수 있습니다. 자세한 내용은 [노드 제한](/analytics/graphql-api/limits/#node-limits-and-availability)을 참고하세요.

### 파싱 문제

샘플 오류 메시지:

* `error parsing args...` (HTTP `400`)
* `scalar fields must have no selections` (HTTP `400`)
* `object field must have selections` (HTTP `400`)
* `unknown field...` (HTTP `400`)
* `query contains error, please review it and retry` (HTTP `400`)

이 메시지는 쿼리 형식이 잘못되어 처리할 수 없음을 의미합니다. [GraphQL 스키마](/analytics/graphql-api/getting-started/explore-graphql-schema/)와 쿼리 구문을 대조해 잘못된 필드나 구조를 수정하세요.

### 속도 제한 초과

샘플 오류 메시지:

* `rate limiter budget depleted, try again after 5 minutes` (HTTP `429`)
* `in combination, your request queries too many nodes, zones and accounts` (HTTP `429`)
* `query consumed excessive resources, please try running smaller queries which consume fewer resources` (HTTP `429`)

이 메시지는 쿼리가 속도 또는 리소스 제한을 초과했음을 의미합니다. 쿼리 복잡도, 요청당 zone 또는 account 수를 줄이거나 잠시 기다린 뒤 다시 시도하세요. 속도 제한에 대한 자세한 내용은 [제한](/analytics/graphql-api/limits/) 섹션을 참고하세요.

### 인증 및 권한 부여 오류

샘플 오류 메시지:

* `Unauthorized` (HTTP `401`)
* `not authorized for that account` (HTTP `403`)
* `zones [...] are not authorized` (HTTP `403`)
* `does not have access to the path...` (HTTP `403`)

`Unauthorized` 응답은 API token 또는 bearer token이 없거나, 만료되었거나, 유효하지 않음을 의미합니다. `Authorization` 헤더에 유효한 토큰을 전달하고 있는지 확인하세요.

`403` 응답은 요청한 account 또는 zone에 대해 해당 토큰에 필요한 권한이 없음을 의미합니다. 관련 리소스에 대해 토큰에 **Analytics: Read** 권한이 있는지 확인하세요. 자세한 내용은 [Tokens](/fundamentals/api/get-started/create-token/)를 참고하세요.

### 내부 서버 오류

샘플 오류 메시지:

* `Internal server error` (HTTP `500`)

이 오류는 예기치 않은 실패를 나타내는 일반적인 오류입니다. 계속 발생하면 HTTP 응답의 `Ray-ID` 헤더를 포함해 전체 요청과 응답을 함께 첨부하여 [Cloudflare Support](https://support.cloudflare.com/)에 문의하세요.

import { DashButton } from "~/components";

[Chrome DevTools](https://developer.chrome.com/docs/devtools)를 사용하면 Cloudflare Dashboard의 analytics 뒤에서 실행되는 쿼리를 캡처할 수 있습니다. 이 예제에서는 Network Analytics 데이터셋에 초점을 맞추지만, 같은 과정을 대시보드의 다른 analytics에도 적용할 수 있습니다.

1. Cloudflare 대시보드에서 **Network Analytics** 페이지 또는 GraphQL 쿼리를 확인하려는 다른 analytics 대시보드로 이동합니다.

   <DashButton url="/?to=/:account/networking-insights/analytics/network-analytics/transport-analytics" />

![Analytics tab](~/assets/images/analytics/analytics-tab.png)

2. [Chrome Developer Tools](https://developer.chrome.com/docs/devtools)를 열고 **Inspect**를 선택합니다.

![Chrome developer tools](~/assets/images/analytics/chrome-developer-tools.png)

3. Developer Tools 패널에서 **Network** 탭을 선택합니다.
4. 필터 바에 `graphql`을 입력해 GraphQL 요청만 보이도록 필터링합니다. 요청이 나타나지 않으면 페이지를 새로고침해 보세요. 페이지가 다시 로드되면 여러 네트워크 요청이 **Network** 탭에 채워집니다. 이름에 `graphql`이 포함된 요청을 찾으세요.

![Type graphql in the search field](~/assets/images/analytics/search-field.png)

5. GraphQL 요청 중 하나를 선택해 세부 정보를 열고 **Payload** 탭으로 이동합니다. 거기에서 GraphQL 쿼리를 확인할 수 있습니다. 쿼리 줄을 선택한 다음 **Copy value**를 눌러 쿼리를 캡처하세요.

![Copy query value](~/assets/images/analytics/copy-value.png)

6. 새 쿼리를 캡처하려면 **Network analytics** 대시보드의 필터를 조정하면 되고, 그러면 GraphQL 요청 목록에 새 쿼리가 나타납니다.

![Create a new query](~/assets/images/analytics/new-query.png)

이제 이 쿼리를 API 호출의 기반으로 사용할 수 있습니다. 자세한 내용은 [Get started](/analytics/graphql-api/getting-started/) 섹션을 참조하세요.

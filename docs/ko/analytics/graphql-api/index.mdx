GraphQL Analytics API는 Cloudflare 네트워크를 통과하는 HTTP 요청에 관한 데이터와 Firewall, Load Balancing 같은 특정 제품의 데이터를 제공합니다. Network Analytics 사용자는 패킷 수준 데이터에도 접근할 수 있습니다. GraphQL Analytics API를 사용하면 관심 있는 특정 데이터세트와 메트릭을 선택하고, 다양한 차원으로 데이터를 필터링하고 집계하며, 결과를 다른 애플리케이션과 통합할 수 있습니다.

이 API의 기반은 Facebook이 만들고 오픈 소스로 공개한 [GraphQL 프레임워크](https://graphql.org/)입니다. GraphQL에는 활발한 개발자 커뮤니티와 강력한 쿼리 실행 클라이언트가 있어 시작하기 쉽습니다. GraphQL은 특히 시각화 구축에 유용하며 Cloudflare 대시보드의 분석 기능도 이를 기반으로 동작합니다.

GraphQL은 스키마를 사용해 비즈니스 도메인을 그래프로 모델링합니다. 스키마에는 서로 다른 유형의 노드와 그 연결(에지)에 대한 논리적 정의가 들어 있습니다. 이 노드들이 분석에 사용하는 데이터세트입니다. GraphQL에서는 SQL과 비슷하게 쿼리를 작성합니다. 데이터세트(테이블), 가져올 메트릭(예: requests, bytes), 그리고 필터링하거나 그룹화할 차원(예: 기간)을 지정합니다.

GraphQL은 전통적인 API와 다르게 단일 엔드포인트만 제공합니다.

```txt
https://api.cloudflare.com/client/v4/graphql
```

이 엔드포인트로 보내는 `POST` 요청의 payload에 쿼리 매개변수를 JSON 객체로 전달합니다.

`curl`을 사용해 GraphQL Analytics API에 요청을 보낼 수 있습니다. 또는 GraphQL 클라이언트를 사용해 쿼리를 구성하고 GraphQL Analytics API로 요청을 전달할 수도 있습니다.

## 클라이언트

예제 GraphQL 쿼리에는 [GraphiQL](https://github.com/skevy/graphiql-app)을 사용합니다. 이 외에도 [Altair](https://altairgraphql.dev), [Insomnia](https://insomnia.rest) 등 온라인에서 찾을 수 있는 인기 있는 오픈 소스 클라이언트가 많이 있습니다.

## 제한 사항

GraphQL API의 목적은 다양한 Cloudflare 제품에 대한 집계 분석을 제공하는 것입니다. 이러한 데이터세트는 Cloudflare가 과금 목적으로 사용하는 사용량 측정 기준으로 사용해서는 안 됩니다. 과금 대상 트래픽은 [DDoS 트래픽 같은 항목을 제외](https://blog.cloudflare.com/unmetered-mitigation)하지만, GraphQL은 전체 소비량/사용량을 측정하므로 측정 가능한 모든 트래픽을 포함합니다.

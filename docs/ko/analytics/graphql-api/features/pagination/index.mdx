페이지네이션은 쿼리 결과를 더 작은 조각으로 나누는 작업으로, `limit`, `orderBy`, 필터링 매개변수를 사용해 수행할 수 있습니다. GraphQL Analytics API는 페이지네이션용 커서를 지원하지 않습니다.

* `limit` (integer)는 반환할 레코드 수를 정의합니다.
* `orderBy` (string)는 데이터 정렬 순서를 정의합니다.

## 커서 없이 페이지 조회

다음 예시는 `date`와 `clientCountryName` 조합이 고유하다고 가정합니다.

### 쿼리의 처음 *n*개 결과 가져오기

결과를 제한하려면 `limit` 매개변수에 정수를 추가합니다. 예를 들어 처음 두 개 레코드를 조회합니다.

```javascript

firewallEventsAdaptive (limit: 2, orderBy: [datetime_ASC, clientCountryName_ASC]) {
    datetime
    clientCountryName
}
```

:::note[Note]

날짜만 기준으로 정렬 순서를 지정하면 날짜와 국가를 함께 지정하는 경우보다 덜 구체적인 결과가 반환됩니다.

:::

**응답**

```javascript

{
  "firewallEventsAdaptive" : [
    {
      "datetime": "2018-11-12T00:00:00Z",
      "clientCountryName": "UM"
    },
    {
      "datetime": "2018-11-12T00:00:00Z",
      "clientCountryName": "US"
    }
  ]
}
```

### 필터를 사용해 다음 페이지 조회

다음 *n*개 결과를 가져오려면, 이전 쿼리의 마지막 결과를 제외하는 필터를 지정합니다. 앞선 예시에서는 `clientCountryName` 필드에 greater-than 연산자(`_gt`)를, `datetime` 필드에 greater-or-equal 연산자(`_geq`)를 추가하면 됩니다. 이때 정렬 순서를 구체적으로 지정하는 것이 중요합니다. 더 세분화된 정렬 순서를 사용하면 결과를 놓칠 가능성이 줄어듭니다.

```javascript

firewallEventsAdaptive (limit: 2, orderBy: [datetime_ASC, clientCountryName_ASC], filter: {datetime_geq: "2018-11-12T00:00:00Z", clientCountryName_gt: "US"}) {
    datetime
    clientCountryName
}
```

**응답**

```javascript

{
  "firewallEventsAdaptive" : [
    {
      "datetime": "2018-11-12T00:00:00Z",
      "clientCountryName": "UY"
    },
    {
      "datetime": "2018-11-12T00:00:00Z",
      "clientCountryName": "UZ"
    }
  ]
}
```

### 이전 페이지 조회

이전 *n*개 결과를 가져오려면 필터와 정렬 순서를 반대로 설정합니다.

```javascript

firewallEventsAdaptive (limit: 2, orderBy: [datetime_DESC, clientCountryName_DESC, filter: {datetime_leq: "2018-11-12T00:00:00Z", clientCountryName_lt: "UY"}]) {
  datetime
  clientCountryName
}
```

**응답**

```javascript

{
  "firewallEventsAdaptive" : [
    {
      "datetime": "2018-11-12T00:00:00Z",
      "clientCountryName": "US"
    },
    {
      "datetime": "2018-11-12T00:00:00Z",
      "clientCountryName": "UM"
    }
  ]
}
```

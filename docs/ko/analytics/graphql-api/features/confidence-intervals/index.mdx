신뢰 구간은 샘플링된 데이터세트 결과의 정확성을 평가하고 불확실성을 정량화하는 데 도움이 됩니다. 적응형 데이터세트에서 `sum` 또는 `count` 필드를 조회할 때 신뢰 구간을 요청해 추정치 주변의 가능한 범위를 파악할 수 있습니다. 예를 들어 신뢰 수준을 `0.95`로 지정하면 추정치와 함께 실제 값이 95% 확률로 포함될 것으로 예상되는 범위를 반환합니다.

## 사용 가능 범위

- **지원 데이터세트**: Adaptive(샘플링) 데이터세트만 지원합니다.
- **지원 필드**: 모든 `sum` 및 `count` 필드.
- **사용 방법**: 신뢰 `level`은 0과 1 사이의 소수로 제공해야 합니다(예: `0.90`, `0.95`, `0.99`).
- **기본값**: 신뢰 수준을 지정하지 않으면 구간이 반환되지 않습니다.

## 사용 예시

다음 예시는 신뢰 구간을 조회하고 응답을 해석하는 방법을 보여줍니다.

### 요청

신뢰 구간을 요청하려면 쿼리에서 `confidence(level: X)` 인수를 사용하세요.

```graphql graphql-api-explorer title="A GraphQL query"
query SingleDatasetWithConfidence($zoneTag: string, $start: Time, $end: Time) {
  viewer {
    zones(filter: {zoneTag: $zoneTag}) {
      firewallEventsAdaptiveGroups(
        filter: {datetime_gt: $start, datetime_lt: $end}
        limit: 1000
      ) {
        count
        avg {
          sampleInterval
        }
        confidence(level: 0.95) {
          count {
            estimate
            lower
            upper
            sampleSize
          }
        }
      }
    }
  }
}
```

### 응답

응답에는 다음 값이 포함됩니다.

- `estimate`: 샘플링된 데이터를 기반으로 한 추정값입니다.
- `lower`: 신뢰 구간의 하한입니다.
- `sampleSize`: 추정값 계산에 사용된 샘플 데이터 포인트 수입니다.
- `upper`: 신뢰 구간의 상한입니다.

이 예시에서 응답은 40,054개의 샘플을 기반으로 이벤트 수를 42,939로 추정하며, 실제 값이 42,673에서 43,204 사이에 있을 확률이 95%라는 뜻입니다.


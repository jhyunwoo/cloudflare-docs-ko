`orderBy` 인수를 사용해 쿼리 결과 요소의 순서를 지정할 수 있습니다. 기본적으로 결과는 데이터세트(테이블)의 기본 키로 정렬됩니다. 다른 필드를 기준으로 정렬하더라도 기본 키 역시 정렬 키에 포함되므로, 페이지네이션 시 결과 일관성이 유지됩니다.

집계 데이터세트의 기본 정렬 순서는 집계 데이터가 그룹화된 필드 기준입니다. 다른 순서를 지정하면 집계 그룹이 지정한 정렬 순서 뒤에 추가됩니다.

:::note[Note]

중첩 구조 내부 정렬은 지원되지 않습니다.
:::

## 예시

### 원시 데이터 정렬

```graphql
firewallEventsAdaptive (orderBy: [clientCountryName_ASC]) {
    clientCountryName
}
```

### 여러 필드를 사용한 원시 데이터 정렬

```graphql
firewallEventsAdaptive (orderBy: [clientCountryName_ASC, datetime_DESC]) {
    clientCountryName
    datetime
}
```

### 집계 함수 기준 그룹 정렬

```graphql
httpRequests1hGroups (orderBy: [sum_bytes_DESC]){
    sum {
        bytes
        requests
    }
    dimensions {
        datetime
    }
}
```

Cloudflare GraphQL API는 동적 스키마를 가지며 zone 및 account 범위 전반에 걸쳐 70개가 넘는 데이터세트를 제공합니다. Cloudflare는 이 목록을 지속적으로 확장하고, 기존 데이터세트는 더 강력한 대안으로 교체합니다.

이러한 스키마 문제를 다루기 위해 GraphQL은 [introspection][1] 메커니즘을 제공합니다. 이는 GraphQL 사양의 일부이며, 데이터세트와 필드의 그래프를 탐색할 수 있게 해줍니다.

introspection 결과는 사용 가능한 **모든** 노드와 필드, 그 설명, 그리고 지원 중단 상태에 대한 개요를 제공합니다.

GraphQL에는 `query`, `subscription`, `mutation` 연산이 있지만, Cloudflare GraphQL API는 `query` 연산만 지원합니다.

## 설명과 Beta 모드

주어진 노드나 필드가 노출하는 데이터에 대한 세부 설명에는 Beta 모드 여부도 포함됩니다. Beta 노드(또는 필드)는 테스트와 탐색용이며, 일반적으로 더 높은 요금제의 고객에게 제공됩니다. Beta 데이터 노드는 사전 공지 없이 변경되거나 제거될 수 있으므로 이에 의존하지 마세요.

## 지원 중단

introspection은 지원 중단 상태에 대한 정보도 제공합니다. Cloudflare는 이를 대체 계획에 대한 알림으로 사용합니다. 종료 날짜가 제공된 경우, 서비스 중단을 피하려면 그 날짜 전에 대체 노드로 마이그레이션하세요.

## 가용성

일부 노드는 일부 사용자에게만 조회 가능할 수 있습니다. 특정 노드의 가용성과 사용자별 제한에 대한 자세한 내용은 [settings][2] 노드를 참고하세요.

## 문서 탐색

스키마를 introspection하는 가장 편리한 방법은 GraphQL 클라이언트(GraphiQL, Altair 등)에 보통 포함된 문서 [explorer][3]를 사용하는 것입니다.

또는 필요한 지시자와 함께 `__schema` 노드를 사용해 수동으로 수행할 수도 있습니다.

```graphql graphql-api-explorer title="A typical introspection query"
{
	__schema {
		queryType {
			name
		}
		mutationType {
			name
		}
		subscriptionType {
			name
		}
		types {
			...FullType
		}
		directives {
			name
			description
			locations
			args {
				...InputValue
			}
		}
	}
}
fragment TypeRef on __Type {
	kind
	name
	ofType {
		kind
		name
		ofType {
			kind
			name
			ofType {
				kind
				name
				ofType {
					kind
					name
					ofType {
						kind
						name
						ofType {
							kind
							name
							ofType {
								kind
								name
							}
						}
					}
				}
			}
		}
	}
}
fragment InputValue on __InputValue {
	name
	description
	type {
		...TypeRef
	}
	defaultValue
}
fragment FullType on __Type {
	kind
	name
	description
	fields(includeDeprecated: true) {
		name
		description
		args {
			...InputValue
		}
		type {
			...TypeRef
		}
		isDeprecated
		deprecationReason
	}
	inputFields {
		...InputValue
	}
	interfaces {
		...TypeRef
	}
	enumValues(includeDeprecated: true) {
		name
		description
		isDeprecated
		deprecationReason
	}
	possibleTypes {
		...TypeRef
	}
}
```

`curl`로 GraphQL 요청을 보내는 방법에 대한 자세한 내용은 [Execute a GraphQL query with curl][4]를 참고하세요.

Cloudflare Analytics는 일반 데이터세트와 제품별 데이터세트를 모두 포함한 다양한 데이터세트를 제공합니다. 데이터세트는 반환하는 데이터 유형을 명확히 나타내는 일관된 명명 규칙을 사용합니다.

* **도메인** - 각 데이터세트는 설명하는 필드 이름을 따라 명명되며, 관련 노드 집합과 연결됩니다. 제품별 데이터 노드는 예를 들어 `loadBalancingRequests*` 노드처럼 관련 제품 이름을 포함합니다.

* **적응형 샘플링** - 적응형 샘플링으로 획득한 데이터를 나타내는 노드는 `Adaptive` 접미사를 포함합니다. 자세한 내용은 [sampling][1]을 참고하세요.

* **집계 데이터** - 집계 데이터를 나타내는 노드는 `Groups` 접미사를 포함합니다. 예를 들어 `loadBalancingRequestsAdaptiveGroups` 노드는 Load Balancing 요청의 집계 데이터를 나타냅니다. 집계 데이터는 `...Group` 객체 배열로 반환됩니다. 참고로 현재 이 명명 규칙에서 제외된 노드가 하나 있으며, 바로 `workersInvocationsAdaptive`(beta)입니다.

* **원시 데이터** - `loadBalancingRequestsAdaptive` 같은 원시 데이터 노드는 집계되지 않으므로 `Groups` 접미사를 포함하지 않습니다. 원시 데이터는 관련 데이터 타입의 객체를 담은 배열로 반환됩니다. 예를 들어 `loadBalancingRequestsAdaptive`에 대한 쿼리는 다양한 `LoadBalancingRequest` 객체를 반환합니다.

데이터세트의 가용성, beta, 지원 종료 상태에 대한 자세한 내용은 GraphQL [discovery][2] 기능을 참고하세요.

## 데이터세트 다루기

### 집계 필드

이 예시는 Groups의 구조를 보여줍니다.

```graphql
type WhateverGroup {
    count # 하위 필드가 없으며, 단순히 그룹 크기입니다. 롤업 테이블에서는 사용할 수 없습니다.
    sum {
        # 합계를 지원하는 필드(숫자, 숫자 맵)
    }
    avg {
        # 평균을 지원하는 필드(숫자)
    }
    uniq {
        # 고유값 계산을 지원하는 필드(숫자, 문자열, enum, IP, 날짜 등)
    }
}
```

고유값은 차원으로는 제공되지 않지만, 다음 예시처럼 조회할 수 있습니다.

```graphql
{
  # 각 분(minute)별 바이트 수와 고유 IP 수를 가져옵니다.
  httpRequests1mGroups {
    sum {
      bytes
    }
    uniq {
      uniques # 고유 IP
    }
    dimensions {
      datetimeMinute
    }
  }

  # 각 시간(hour)별 이벤트 수를 셉니다.
  firewallEventsAdaptiveGroups {
    count
    dimensions {
      datetimeHour
    }
  }
}
```

### 스키마 타입 정의

노출되는 모든 테이블에는 GraphQL 타입 정의가 있습니다. 타입 정의는 다음 규칙을 따릅니다.

* 일반 필드는 자기 자신을 나타냅니다.
* 중첩 필드를 포함한 모든 필드는 타입을 가지며, 해당 타입의 목록을 나타냅니다.
* `enum` 타입은 열거형 필드를 나타냅니다.

다음은 `ContentTypeMapElem` 타입 정의의 예시입니다.

```graphql
type ContentTypeMapElem {
    edgeResponseContentType: UInt32!
    requests: UInt64!
    bytes: UInt64!
}

# httpRequestsGroup 배열은 httpRequests1hGroups 또는
# httpRequests1mGroups 쿼리의 결과입니다.
type httpRequestsGroup {
    date: Date!
    timeslot: DateTime!
    requests: UInt64!
    contentTypeMap: [ContentTypeMapElem!]!
    # ... other fields
}

enum TrustedClientCategory {
    UNKNOWN
    REAL_BROWSER
    HONEST_BOT
}

# Request 배열은 httpRequests 쿼리의 결과입니다.
type Request {
    trustedClientCategory: TrustedClientCategory!
    # ... other fields
}
```

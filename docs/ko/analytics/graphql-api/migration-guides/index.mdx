## GraphQL 마이그레이션

현재 더 이상 사용되지 않는 `httpRequests1mByColoGroups` 또는 `httpRequests1dByColoGroups` GraphQL API 노드를 사용 중이라면, [HTTP Requests by Colo Groups에서 HTTP Requests by Adaptive Groups로](/analytics/graphql-api/migration-guides/graphql-api-analytics/) 가이드가 쿼리를 `httpRequestsAdaptiveGroups` 노드를 사용하도록 마이그레이션하는 데 도움이 됩니다.

## Zone Analytics 마이그레이션

현재 Zone Analytics API를 사용 중이라면, 다음 가이드가 쿼리를 새 GraphQL Analytics API로 마이그레이션하는 데 도움이 됩니다.

* [Zone Analytics에서 GraphQL Analytics로](/analytics/graphql-api/migration-guides/zone-analytics/)
* [Zone Analytics Colos Endpoint에서 GraphQL Analytics로](/analytics/graphql-api/migration-guides/zone-analytics-colos/)

## Network Analytics 마이그레이션

현재 Network Analytics v1(NAv1) GraphQL 노드를 사용 중이라면, [Network Analytics v1에서 Network Analytics v2로](/analytics/graphql-api/migration-guides/network-analytics-v2/) 가이드가 쿼리를 새로운 Network Analytics v2로 마이그레이션하는 데 도움이 됩니다.

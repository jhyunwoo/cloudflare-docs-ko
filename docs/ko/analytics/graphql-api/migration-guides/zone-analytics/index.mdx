Zone Analytics API를 사용하면 zone별 요청 데이터를 가져올 수 있습니다. 요청 기간을 지정하는 선택적 `since` 및 `until` 매개변수와, 완전히 집계된 데이터가 있는 기간을 찾기 위해 시간 범위를 뒤로 이동할지 여부를 나타내는 `continuous` 매개변수를 제공합니다.

예를 들어 2분 기간의 데이터를 가져오는 curl 호출 예시는 다음과 같습니다.

```bash
curl "https://api.cloudflare.com/client/v4/zones/<ZONE_ID>/analytics/dashboard?since=2019-09-08T20:00:00Z&until=2019-09-08T20:02:00Z&continuous=false" \
--header "Authorization: Bearer <API_TOKEN>" --silent | jq .
```

응답에서 볼 수 있듯이 Zone Analytics는 많은 차원에 걸친 메트릭을 반환하며, 어떤 데이터를 받을지 직접 제어할 수는 없습니다. 반면 GraphQL Analytics에서는 필요한 데이터만 요청할 수 있습니다. 하지만 Zone Analytics와 정확히 같은 메트릭과 차원을 얻고 싶다면 다음과 같이 쿼리하면 됩니다.

```graphql graphql-api-explorer
query ZoneAnalyticsMigrationSample($zoneTag: string, $start: Time, $end: Time) {
	viewer {
		zones(filter: { zoneTag: $zoneTag }) {
			httpRequests1mGroups(
				orderBy: [datetimeFiveMinutes_ASC]
				limit: 100
				filter: { datetime_geq: $start, datetime_lt: $end }
			) {
				dimensions {
					datetimeFiveMinutes
				}
				sum {
					browserMap {
						pageViews
						uaBrowserFamily
					}
					bytes
					cachedBytes
					cachedRequests
					contentTypeMap {
						bytes
						requests
						edgeResponseContentTypeName
					}
					clientSSLMap {
						requests
						clientSSLProtocol
					}
					countryMap {
						bytes
						requests
						threats
						clientCountryName
					}
					encryptedBytes
					encryptedRequests
					ipClassMap {
						requests
						ipType
					}
					pageViews
					requests
					responseStatusMap {
						requests
						edgeResponseStatus
					}
					threats
					threatPathingMap {
						requests
						threatPathingName
					}
				}
				uniq {
					uniques
				}
			}
		}
	}
}
```

[Filtering](/analytics/graphql-api/features/filtering/)에서 설명하듯이, 이제는 데이터셋 필터를 사용해 요청 기간을 지정할 수 있습니다. GraphQL Analytics는 데이터가 제공되는 즉시 제공하도록 설계되었으므로 더 이상 `continuous` 매개변수가 필요하지 않습니다.

또한 특정 기간의 총합만 필요하고 시간대별 세부 분해가 필요 없다면, `dimensions` 아래의 `datetimeFiveMinutes` 필드를 제거하면 됩니다.

## 주요 노드

주요 노드는 Spectrum 고객과 Magic Transit 고객을 위해 트래픽과 공격에 대한 심층적인 패킷 수준 정보를 제공합니다.

Cloudflare 엣지에서 관측되는 트래픽과 공격을 높은 수준에서 조회하려면 주요 노드를 사용하세요.

| 제품 | 주요 노드 |
| ------------- | -------------------------------------------- |
| Spectrum | `spectrumNetworkAnalyticsAdaptiveGroups` |
| Magic Transit | `magicTransitNetworkAnalyticsAdaptiveGroups` |

공격의 더 구체적인 세부 정보를 조회하려면 [공격 노드](#공격-노드)를 사용하세요.

각 행은 하나의 패킷 샘플을 나타냅니다. 주요 노드의 샘플 비율은 1/10,000 packets입니다.

겹치는 IP 주소에 대해 Magic Transit과 Spectrum을 함께 사용 중이라면 Magic Transit 노드만 사용하면 됩니다.

## 공격 노드

### `dosdAttackAnalyticsGroups`

이 노드는 Cloudflare의 주요 DDoS 보호 시스템인 서비스 거부 데몬(`dosd`)이 감지하고 완화한 DDoS 공격에 대한 정보를 제공합니다. 이 노드는 다음과 같은 공격 메타데이터를 포함합니다.

- `startDatetime`
- `endDatetime`
- `attackType`
- `sourceIp`

각 행은 하나의 공격 이벤트를 나타냅니다. 각 공격은 고유한 ID를 가집니다.

샘플 비율은 패킷 볼륨에 따라 동적으로 결정되며 1/100에서 1/10,000 packets 사이입니다.

:::note[공격 완화 조정]

완화 민감도와 동작을 조정하거나, 완화 동작에서 트래픽을 제외하거나 포함하는 표현식 필터를 정의하려면 [Network-layer DDoS Attack Protection managed ruleset](/ddos-protection/managed-rulesets/network/)을 사용자 지정하세요.

:::

### `dosdNetworkAnalyticsAdaptiveGroups`

이 노드는 `dosdAttackAnalyticsGroups` 노드의 정보를 보완합니다. `dosd`에 의해 완화된 DDoS 공격 패킷에 대한 심층적인 패킷 수준 정보를 제공하며, 다음과 같은 필드를 포함합니다.

- `ipProtocol`
- `ipv4Checksum`
- `ipv4Options`
- `tcpSequenceNumber`
- `tcpChecksum`
- `icmpCode`
- `ruleId`
- `ruleName`
- `attackVector`

각 행은 하나의 패킷 샘플을 나타냅니다. 샘플 비율은 1/10,000 packets입니다.

### `advancedTcpProtectionNetworkAnalyticsAdaptiveGroups`

이 노드는 Magic Transit 고객에게만 제공됩니다. Cloudflare의 [Advanced TCP Protection](/ddos-protection/advanced-ddos-systems/overview/advanced-tcp-protection/) 시스템이 완화한 비정상 상태 TCP DDoS 공격에 대한 메타데이터를 제공합니다.

Advanced TCP Protection은 공격 ID, 규칙 ID, 규칙 집합 ID와 같은 ID 필드를 사용하지 않습니다.

샘플 비율은 1/1,000 packets입니다.

### `advancedDnsProtectionNetworkAnalyticsAdaptiveGroups`

이 노드는 Magic Transit 고객에게만 제공됩니다. Cloudflare의 [Advanced DNS Protection](/ddos-protection/advanced-ddos-systems/overview/advanced-dns-protection/) 시스템이 완화한 DNS 기반 DDoS 공격에 대한 메타데이터를 제공합니다.

샘플에는 다음 DNS 헤더 필드에 대한 정보가 포함됩니다.

- `dnsQueryName`
- `dnsQueryType`

Advanced DNS Protection은 공격 ID, 규칙 ID, 규칙 집합 ID와 같은 ID 필드를 사용하지 않습니다.

샘플 비율은 1/1,000 packets입니다.

### `magicFirewallNetworkAnalyticsAdaptiveGroups`

이 노드는 Magic Transit 고객에게만 제공됩니다. 고객이 구성한 [Cloudflare Network Firewall](/cloudflare-network-firewall/) 규칙과 일치한 패킷에 대한 정보를 제공합니다.

각 행은 Cloudflare Network Firewall 규칙과 일치하는 하나의 패킷 샘플을 나타냅니다.

Cloudflare Network Firewall은 공격 ID를 사용하지 않고, 규칙 ID와 규칙 집합 ID만 사용합니다.

샘플 비율은 패킷 볼륨에 따라 동적으로 결정되며 1/100에서 1/1,000,000 packets 사이입니다.

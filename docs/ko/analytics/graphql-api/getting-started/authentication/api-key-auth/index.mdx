API key는 각 Cloudflare 사용자에게 고유하며 인증에만 사용됩니다. API key 자체는 account나 zone에 대한 접근 권한을 부여하지 않습니다. GraphQL Analytics API가 쿼리를 인증하도록 하려면 Cloudflare Global API Key를 가져오세요.

[Cloudflare 대시보드에서 API Key를 가져오는 방법](/fundamentals/api/get-started/keys/)을 확인하세요.

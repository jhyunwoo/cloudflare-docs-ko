Cloudflare는 Cloudflare API와 상호작용할 때 API token을 기본 인증 방식으로 사용할 것을 권장합니다. 이 문서에서는 GraphQL Analytics API 인증을 위한 API token을 만드는 과정을 안내합니다.

API token과 전체 지원 옵션에 대한 자세한 내용은 [Creating API tokens](/fundamentals/api/get-started/create-token/)를 참고하세요.

GraphQL Analytics API 인증용 API token을 만들려면 다음 흐름을 사용하세요.

- [Create API Token 페이지 열기](#access-the-create-api-token-page)
- [사용자 지정 API token 구성](#configure-a-custom-api-token)
- [API token 검토 및 생성](#review-and-create-your-api-token)
- [API token 복사 및 테스트](#copy-and-test-your-api-token)

## Create API Token 페이지 열기

1. Cloudflare 대시보드에서 **Account API tokens** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/api-tokens" />

2. **Create Token**을 선택합니다.

![API Tokens tab](~/assets/images/analytics/user-profile-api-tokens-tab.png)

**Create API Token** 페이지가 표시됩니다.

![Clicking Get started in the Create API Token page](~/assets/images/analytics/create-api-token-page-display.png)

이 안내의 다음 섹션에서는 GraphQL Analytics API 접근용 사용자 지정 token을 구성하는 방법을 보여줍니다.

## 사용자 지정 API token 구성

사용자 지정 token을 구성하려면 다음 단계를 따르세요.

1. **Create API Token** 페이지의 **Custom token** 섹션에서 **Get started**를 선택합니다.

![Clicking Get started in the Create API Token page](~/assets/images/analytics/create-api-token-get-started.png)

**Create Custom Token** 페이지가 표시됩니다.

![Create Custom Token page](~/assets/images/analytics/create-custom-api-token.png)

2. **Token name** 입력 필드에 token을 설명하는 이름을 입력합니다.

3. GraphQL Analytics API 접근을 구성하려면 **Permissions** 드롭다운 목록을 사용합니다.

4. GraphQL Analytics API 권한을 설정하려면 첫 번째 드롭다운에서 _Account_, 두 번째 드롭다운에서 _Account Analytics_, 세 번째 드롭다운에서 _Read_를 선택합니다.

이 예시에서는 Analytics API에 대한 읽기 접근을 위한 account 수준 권한을 범위로 지정합니다.

![Permissions configuration page](~/assets/images/analytics/create-custom-token-permissions.png)

5. token이 접근을 허용할 특정 zone을 구성하려면 **Zone Resources** 드롭다운 목록을 사용합니다. 이 예시에서는 token이 모든 zone에 접근하도록 설정되어 있습니다.

![Resources configuration page](~/assets/images/analytics/create-custom-token-zone-resources.png)

6. API token을 특정 IP 주소로 제한하려면 **Client IP Address Filtering** 컨트롤을 사용합니다.

![IP Address Filtering configuration page](~/assets/images/analytics/create-custom-token-ip-address-filtering.png)

7. token의 유효 기간을 정의하려면 **TTL**(time-to-live) 시작/종료 날짜를 선택합니다.

![TTL configuration page](~/assets/images/analytics/create-custom-token-ttl.png)

8. **Continue to summary**를 선택합니다.

다음 섹션에서는 API token을 검토하고 테스트하는 방법을 설명합니다.

## API token 검토 및 생성

**Continue to summary**를 선택하면 **API Token Summary** 페이지가 표시됩니다.

API Token을 만들기 전에 원하는 권한과 리소스로 범위가 올바르게 설정되었는지 **API Token Summary**에서 확인하세요.

![API Token Summary page](~/assets/images/analytics/api-token-summary.png)

API token 구성이 올바른지 확인했으면 **Create Token**을 선택하세요.

## API token 복사 및 테스트

새 token을 만들면 token과 사용자 지정 `curl` 명령이 포함된 확인 페이지가 표시됩니다.

![Page displaying your API token and the curl command to test your token](~/assets/images/fundamentals/api/token-complete.png)

기기의 클립보드로 token을 복사하려면 **Copy** 버튼을 선택하세요.

:::caution[Warning]

token은 확인 페이지에만 표시되므로, token을 복사해 안전하게 보관하세요. 이 token을 가진 사람은 누구나 데이터를 조회할 수 있습니다.

token을 잃어버려도 모든 권한을 다시 구성할 필요 없이 [API Tokens 페이지에서 재생성](/fundamentals/api/get-started/create-token/)할 수 있습니다.

:::

token을 테스트하려면 `curl` 명령을 복사해 터미널에 붙여 넣으세요.

작업이 끝나면 **View all API tokens**를 선택하세요.

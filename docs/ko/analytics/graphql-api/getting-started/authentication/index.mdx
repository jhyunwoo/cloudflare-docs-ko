Cloudflare는 zone별로 서비스 구성을 분리합니다. 여러 계정에 많은 zone이 있을 때는, 현재 작업에 필요한 account 및 zone 리소스에만 GraphQL Analytics API 접근을 제한하는 것이 중요합니다.

GraphQL Analytics 데이터에 대한 접근을 보호하려면 Cloudflare API key 또는 token으로 API 요청을 인증하세요.

다음 표는 Cloudflare API key와 token의 차이를 설명합니다.

<table>
  <thead>
      <tr>
          <th>인증 방식</th>
          <th>설명</th>
      </tr>
  </thead>
  <tbody>
      <tr>
        <td><a href='/fundamentals/api/get-started/create-token/'>API Tokens</a></td>
        <td>Cloudflare는 Cloudflare API와 상호작용하는 기본 방법으로 API Token 사용을 권장합니다. token 범위를 구성해 account 및 zone 리소스 접근을 제한할 수 있으며, token이 접근을 허용하는 Cloudflare API도 정의할 수 있습니다.</td>
      </tr>
      <tr>
        <td><a href='/fundamentals/api/get-started/keys/'>API Keys</a></td>
        <td><p>각 Cloudflare 사용자에게 고유하며 인증에만 사용됩니다. API key는 account나 zone에 대한 접근 권한을 부여하지 않습니다.</p>
        <p>인증에는 Global API Key를 사용하세요.</p></td>
      </tr>
  </tbody>
</table>

GraphQL Analytics API token 생성 및 구성 방법은 [Analytics API token 구성](/analytics/graphql-api/getting-started/authentication/api-token-auth/)을 참고하세요.

API key를 찾고 가져오는 방법과 GraphiQL에서 인증용 HTTP 헤더를 편집하는 방법은 [Cloudflare API key로 인증하기](/analytics/graphql-api/getting-started/authentication/api-key-auth/)를 참고하세요.

1. [GraphiQL](https://www.gatsbyjs.com/docs/how-to/querying-data/running-queries-with-graphiql/)을 실행합니다.

2. **Edit HTTP Headers**를 선택합니다.
   ![Clicking Edit HTTP Headers](~/assets/images/analytics/GraphiQL-edit-http-headers.png)
   **Edit HTTP Headers** 창이 나타납니다.
   ![Editing HTTP Headers Window](~/assets/images/analytics/GraphiQL-edit-http-headers-window.png)

3. 인증을 구성하려면 **Add Header**를 선택합니다. Cloudflare Analytics API token 인증(권장) 또는 Cloudflare API key 인증을 사용할 수 있습니다.
   * **Token authentication**:

     **Header Name** 필드에 **Authorization**을 입력하고, **Header value** 필드에 `Bearer {your-analytics-token}`을 입력한 뒤 **Save**를 선택합니다.

     ![Editing HTTP Headers](~/assets/images/analytics/GraphiQL-edit-http-headers-token.png)

   * **Key authentication**:

     **Header name** 필드에 `X-AUTH-EMAIL`을 입력하고, **Header value** 필드에 Cloudflare에 등록한 이메일 주소를 입력한 뒤 **Save**를 선택합니다.<br/>

     두 번째 헤더를 추가하려면 **Add Header**를 선택하세요. **Header Name** 필드에 `X-AUTH-KEY`를 입력하고, **Header value** 필드에 Global API Key를 붙여 넣은 뒤 **Save**를 선택합니다.<br/>

4. GraphiQL에서 **Edit HTTP Headers** 창 바깥 아무 곳이나 클릭해 창을 닫고 메인 화면으로 돌아갑니다.

5. **GraphQL Endpoint** 필드에 `https://api.cloudflare.com/client/v4/graphql`을 입력합니다.
   ![Editing GraphQL Endpoint](~/assets/images/analytics/GraphiQL-response-pane.png)

:::note[Note]


정보를 올바르게 입력하면 오른쪽 응답 창은 비어 있습니다. 헤더 자격 증명에 문제가 있으면 오류가 표시됩니다.


:::

이제 인증 구성이 끝났으므로 GraphiQL에서 쿼리를 실행할 준비가 되었습니다.

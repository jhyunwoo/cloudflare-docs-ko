다음 문서를 통해 Cloudflare GraphQL API를 시작할 수 있습니다.

* [인증][1] - Cloudflare API에 성공적으로 접근할 수 있도록 옵션과 필요한 단계를 안내합니다.
* [쿼리 기초][2] - GraphQL API 탐색을 시작할 수 있도록 간단한 쿼리 예시를 제공합니다.
* [GraphQL 스키마 introspection][3] - GraphQL 클라이언트로 스키마를 탐색하는 방법을 설명합니다.
* [GraphQL 클라이언트에서 쿼리 만들기][4] - GraphQL 클라이언트에서 Cloudflare GraphQL API 대상 쿼리를 구성하고 실행하는 방법을 설명합니다.
* [curl로 GraphQL API 조회하기][5] - 명령줄에서 Cloudflare GraphQL API에 대해 쿼리를 실행하는 과정을 안내합니다.

직접 GraphQL Analytics 대시보드를 만들거나 Firewall, Workers 이벤트 같은 특정 정보를 조회하는 예시는 [Tutorials][6]를 참고하세요.

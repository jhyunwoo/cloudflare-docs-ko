많은 GraphQL 클라이언트는 [introspection][1]을 처리해 GraphQL 스키마 탐색을 지원합니다. 이 페이지에서는 GraphiQL과 Altair 클라이언트를 다룹니다.

[GraphiQL][2]과 [Altair][3]는 쿼리를 작성하고 실행하며 결과를 살펴볼 수 있는 도구를 제공하는 오픈 소스 GraphQL 클라이언트입니다. 추가로 GraphQL 스키마도 탐색할 수 있습니다.

## 사전 준비

시작하기 전에 API 엔드포인트와 HTTP 헤더를 [구성][4]하는 것을 잊지 마세요.

아래 스크린샷은 GraphiQL 기준이지만, Altair도 동일한 기능을 제공하므로 같은 방식으로 스키마를 탐색할 수 있습니다.

## Documentation Explorer 열기

GraphiQL Documentation Explorer를 열려면 응답 창 헤더의 **Docs** 링크를 선택하세요.

![Clicking GraphiQL Docs link to open Documentation Explorer][5]

**Documentation Explorer**가 열리고 사용 가능한 객체 목록이 표시됩니다.

![GraphiQL Doc Explorer pane][6]

**Documentation Explorer**의 객체는 다음 구문을 사용합니다.

```txt
  object-name: object-type-definition
```

## 객체의 타입 정의 찾기

**Documentation Explorer** 창을 처음 열면 `mutation`과 `query` 루트 타입이 표시됩니다.

![Documentation Explorer displaying mutation and query nodes][7]

이 예시에서 `query`는 루트 이름이고 `Query`는 타입 정의입니다.

## 타입 정의에서 사용 가능한 필드 찾기

노드의 **type definition**을 클릭하면 해당 노드가 제공하는 필드를 볼 수 있습니다. **Documentation Explorer**는 노드 설명도 함께 보여줍니다.

예를 들어 **Query** 타입 정의를 선택하면 `Query`가 제공하는 필드가 표시됩니다. 이 예시에서는 `cost`와 `viewer` 필드가 나옵니다.

![Documentation Explorer displaying cost and viewer fields][8]

스키마를 탐색하려면 객체와 정의의 이름을 선택하세요. 헤더의 검색 입력창(돋보기 아이콘)과 breadcrumb 링크를 사용할 수도 있습니다.

## 필드와 연결된 인수 찾기

`viewer` 필드의 타입 정의(금색 텍스트)를 클릭하면 하위 필드가 표시됩니다. `viewer` 필드는 `accounts` 또는 `zones` 데이터를 조회할 수 있는 하위 필드를 제공합니다.

![Displaying viewer fields][9]

`accounts`와 `zones` 노드는 조회할 데이터세트를 지정하는 인수를 받습니다.

예를 들어 `zones`는 `ZoneFilter_InputObject` 타입 필터를 인수로 받을 수 있습니다. 필터에 사용할 수 있는 필드를 보려면 **ZoneFilter_InputObject**를 선택하세요.

## zone에서 사용 가능한 데이터세트 찾기

조회 가능한 데이터세트 목록을 보려면 **zone** 타입 정의(금색 텍스트)를 선택하세요.

![Clicking zone type definition][10]

**Fields** 섹션에 데이터세트 목록이 표시되며, 각 항목에는 유효한 인수 목록과 간단한 설명이 함께 나옵니다. 느낌표(`!`)로 끝나는 인수는 필수입니다.

![Fields section displaying datasets available][11]

검색 입력창(돋보기 아이콘)을 사용해 특정 데이터세트를 찾을 수 있습니다.

![Searching a dataset in the Documentation Explorer][12]

데이터세트를 선택하려면 이름을 선택하세요.

그러면 해당 데이터세트의 정의가 표시됩니다. 이 예시에는 `firewallEventsAdaptive` 데이터세트가 나옵니다.

![Example of a dataset definition][13]

## 데이터세트에서 사용 가능한 필드 찾기

특정 데이터세트에서 사용 가능한 필드를 보려면 해당 타입 정의(금색 텍스트)를 선택하세요.

예를 들어 `firewallEventsAdaptive` 데이터세트에 사용할 수 있는 필드를 보려면 **ZoneFirewallEventsAdaptive** 타입 정의를 선택합니다.

![Clicking type definition to visualize fields available for a dataset][14]

그러면 필드 목록이 표시됩니다.

![Displaying available fields for a dataset][15]

많은 클라이언트는 GraphQL의 [의미 체계][1]를 이해하고 Cloudflare GraphQL API의 가능성을 탐색하는 데 도움이 필요할 수 있습니다.

이 페이지에서는 [GraphiQL 클라이언트][2]를 사용해 GraphQL 쿼리를 작성하고 실행하는 방법을 설명합니다.

## 사전 준비

클라이언트 [구성][3] 방법에 대한 모든 세부 사항은 여기에서 확인할 수 있습니다.

## 쿼리 설정 및 데이터세트 선택

GraphiQL의 편집 창을 클릭하고 다음 기본 쿼리를 추가한 뒤 `zone-id`를 Cloudflare zone ID로 바꾸세요.

![Adding a base query in the GraphiQL pane][4]

:::note[Note]

zone tag를 찾으려면 Cloudflare 계정에 로그인한 뒤 tag를 확인하려는 사이트를 선택하세요. Cloudflare 대시보드 **Overview** 페이지의 오른쪽 사이드바에서 **API** 섹션까지 스크롤하면 zone tag와 account tag가 표시됩니다.

:::

쿼리 작성을 돕기 위해 GraphiQL 클라이언트는 단어 자동 완성을 제공합니다. 이 예시에서는 `zones` 아래 줄에 커서를 놓고 값을 입력해 기능을 활성화합니다. 예를 들어 `firewall`을 입력하면 방화벽 정보를 반환하는 데이터세트 팝업 메뉴가 표시됩니다.

![GraphiQL word completion assistant to query building][5]

목록 하단 텍스트에는 해당 노드가 반환하는 데이터에 대한 짧은 설명이 표시됩니다.

조회하려는 데이터세트를 선택해 삽입하세요. 목록 항목을 클릭하거나 화살표 키로 이동한 뒤 `Return` 키를 누르면 됩니다.

## 필수 매개변수 제공

필드 위에 마우스를 올리면 데이터세트를 설명하는 툴팁이 표시됩니다. 이 예시에서 `firewallEventsAdaptive` 노드 위에 마우스를 올리면 다음 설명이 나타납니다.

![Hovering the mouse over a field to display its description][6]

필수 매개변수를 포함한 데이터세트 정보를 보려면 데이터세트 이름(파란 텍스트)을 선택하세요. 그러면 **Documentation Explorer**가 열리고 데이터세트 세부 정보가 표시됩니다.

![Documentation Explorer window displaying dataset details][7]

타입 정의(금색 텍스트) 뒤의 느낌표(`!`)가 보여주듯, `filter`와 `limit` 인수는 필수입니다. 이 예시에서 `orderBy` 인수는 필수는 아니지만, 사용할 경우 `ZoneFirewallEventsAdaptiveOrderBy` 타입 값을 요구합니다.

지원되는 필터 필드 목록을 보려면 Documentation Explorer에서 필터 타입 정의(금색 텍스트)를 선택하세요. 이 예시에서는 타입이 `ZoneFirewallEventsAdaptiveFilter_InputObject`입니다.

![Browsing GraphiQL filter fields][8]

다음 예시 쿼리는 `firewallEventsAdaptive`에 필요한 `filter`와 `limit` 인수(및 다른 GraphQL 노드에도 동일한 형태)를 보여줍니다.

![Example of GraphiQL query arguments][9]

## 쿼리에서 사용할 필드 정의

쿼리에서 사용할 수 있는 필드를 탐색하려면 쿼리 안의 데이터세트 이름 위에 커서를 올리고, 표시되는 툴팁에서 데이터 타입 정의(금색 텍스트)를 선택하세요.

![Hovering the mouse over a dataset to display available fields][10]

**Documentation Explorer**가 열리고 필드 목록이 표시됩니다.

![Documentation Explorer window displaying list of fields][11]

읽고 싶은 데이터 필드를 추가하려면 매개변수 닫는 괄호 뒤에 여는 중괄호(`{`)를 입력한 다음, 가져오려는 필드 이름을 입력하기 시작하세요. 단어 자동 완성을 사용해 필드를 선택할 수 있습니다.

이 예시 쿼리는 `action`, `datetime`, `clientRequestHTTPHost`, `userAgent` 필드를 반환합니다.

![Example query with return fields][12]

조회하려는 필드를 모두 입력한 후 **Play** 버튼을 선택해 쿼리를 제출하세요. 응답 창에는 설정된 GraphQL API 엔드포인트에서 가져온 데이터가 표시됩니다.

![GraphiQL response pane][13]

## 변수 치환

GraphiQL 클라이언트에서는 값 자리표시자를 사용하고, payload의 `variables` 부분으로 값을 전달할 수 있습니다.

자리표시자 이름은 `$` 문자로 시작해야 하며, 쿼리 안에서 사용할 때 따옴표로 감쌀 필요가 없습니다.

자리표시자 값은 JSON 형식으로 제공해야 하며, 이때 키 이름에는 `$` 문자를 붙이지 않습니다. 예를 들어 `$zoneTag` 자리표시자에 대해서는 GraphQL API가 제공된 variables 객체의 `zoneTag` 필드에서 값을 읽습니다.

자리표시자 값을 제공하려면 **Query Variables** 창을 선택하고 변수를 정의하는 JSON 객체를 수정하세요.

이 예시 쿼리는 zone ID를 나타내기 위해 `zoneTag` 쿼리 변수를 사용합니다.

일반 `curl`로 쿼리를 보내면 결과를 자유롭게 가공하고 필요하다면 후처리를 적용할 수 있습니다. 예를 들어 GraphQL API에서 받은 결과를 CSV 형식으로 변환할 수 있습니다.

자동 완성, 스키마 탐색 등 더 많은 기능이 필요하다면 GraphQL [clients](/analytics/graphql-api/getting-started/compose-graphql-query/)를 살펴보세요.

GraphQL API는 `"query"`와 `"variables"`라는 두 가지 핵심 필드를 가진 JSON을 기대합니다.

쿼리는 줄바꿈 문자를 제거해 한 줄 문자열로 보내야 하며, `variables`는 쿼리에서 사용한 모든 placeholder 값이 들어 있는 객체여야 합니다.

```json title="A payload structure for GraphQL API"
{
  "query": "{viewer { ... }}",
  "variables": {}
}
```

그래도 사람이 읽기 쉬운 쿼리를 사용할 수는 있습니다. 아래 예시에서는 `echo`와 `tr`을 함께 사용해 `curl`에 맞는 payload를 만드는 방법을 보여줍니다.

```bash title="Example bash script that uses curl to query Analytics API"
echo '{ "query":
  "{
    viewer {
      zones(filter: { zoneTag: $zoneTag }) {
        firewallEventsAdaptive(
          filter: $filter
          limit: 10
          orderBy: [datetime_DESC]
        ) {
          action
          clientAsn
          clientCountryName
          clientIP
          clientRequestPath
          clientRequestQuery
          datetime
          source
          userAgent
        }
      }
    }
  }",
  "variables": {
    "zoneTag": "<zone-tag>",
    "filter": {
      "datetime_geq": "2022-07-24T11:00:00Z",
      "datetime_leq": "2022-07-24T12:00:00Z"
    }
  }
}' | tr -d '\n' | curl --silent \
https://api.cloudflare.com/client/v4/graphql \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data @-
```

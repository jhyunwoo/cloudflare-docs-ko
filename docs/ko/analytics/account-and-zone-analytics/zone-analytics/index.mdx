Cloudflare zone analytics는 Cloudflare Analytics 제품군의 주요 구성 요소입니다. 이 앱은 웹사이트 또는 도메인 수준에서 수집된 다양한 메트릭에 접근할 수 있게 해줍니다.

:::note

Cloudflare의 전체 분석 제품군에 대한 일반 정보는 [Cloudflare Analytics](/analytics/faq/about-analytics/)를 읽어보세요.
Cloudflare가 수집하고 처리하는 데이터의 특성도 함께 이해할 수 있습니다.
:::

---

## 웹사이트 분석 보기

웹사이트 메트릭을 보려면 Cloudflare 대시보드에서 **Analytics & Logs** 페이지로 이동하세요.

<DashButton url="/?to=/:account/:zone/analytics/traffic" />

로드가 완료되면 **Traffic**, **Security**, **Performance**, **DNS**, **Workers**, **Logs**(Enterprise 도메인 전용) 탭을 확인할 수 있습니다. 사용 가능한 다양한 메트릭을 이해하려면 아래의 _웹사이트 메트릭 검토_를 참고하세요.

## 웹사이트 메트릭 검토

이 섹션에서는 각 Analytics 앱 탭에서 제공되는 메트릭을 설명합니다. 계속하기 전에, 각 탭에는 다음이 포함될 수 있습니다.

- 기본 메트릭을 더 세분화하는 하나 이상의 패널
- 특정 기간의 메트릭으로 필터링하기 위한 드롭다운(패널 오른쪽 상단). 선택 가능한 기간은 도메인에 연결된 Cloudflare 플랜에 따라 달라질 수 있습니다.

<Render file="case-sensitivity-note" product="analytics" />

아래는 각 Analytics 앱 탭의 요약입니다.

### HTTP 트래픽

#### Free 플랜

이 메트릭에는 정상 사용자 요청뿐 아니라 크롤러와 위협도 포함됩니다. HTTP Traffic 탭에는 다음 패널이 있습니다.

- **Web Traffic** - _Requests_, _Bandwidth_, _Unique Visitors_ 메트릭을 표시합니다. Cloudflare Workers를 사용하는 경우 하위 요청 데이터는 zone Traffic Analytics에 표시되지 않습니다. 대신 **Overview** 섹션의 **Workers & Pages** 탭 아래에서 하위 요청 분석을 확인할 수 있습니다. 자세한 내용은 [Worker Analytics](/analytics/account-and-zone-analytics/analytics-with-workers/#worker-analytics)를 참고하세요.
- **Web Traffic Requests by Country** - 국가별 요청 수를 세분화하는 대화형 지도입니다. 이 패널에는 가장 많은 요청을 보낸 국가를 표시하는 **Top Traffic Countries / Regions** 데이터 테이블도 포함됩니다(데이터가 존재할 경우 최대 5개).

#### Pro, Business, 또는 Enterprise 플랜

:::note

프라이버시 중심 HTTP Traffic Analytics는 Pro, Business, Enterprise 플랜에서 사용할 수 있습니다.
:::

분석은 제3자 스크립트나 트래커 없이 Cloudflare 엣지 로그를 기반으로 합니다. HTTP Traffic 탭에는 다음 메트릭이 있습니다.

- **Requests** - HTTP 요청입니다. 일반적인 페이지 뷰에는 많은 요청이 필요합니다. Cloudflare Workers를 사용하는 경우 하위 요청 데이터는 zone HTTP Traffic Analytics에 표시되지 않습니다. 대신 **Overview** 섹션의 **Workers & Pages** 탭 아래에서 하위 요청 분석을 확인할 수 있습니다. 자세한 내용은 [Worker Analytics](/analytics/account-and-zone-analytics/analytics-with-workers/#worker-analytics)를 참고하세요.
- **Data Transfer** - 응답에서 전송된 총 HTTP 데이터입니다.
- <a id="page-views" /> **Page views** - 페이지 뷰는 콘텐츠 유형이 HTML인 성공적인 HTTP 응답으로 정의됩니다.
- **Visits** - 방문은 다른 웹사이트 또는 직접 링크에서 시작된 [page view](#page-views)로 정의됩니다. Cloudflare는 HTTP referer가 호스트명과 일치하지 않는 경우를 확인합니다. 하나의 방문에는 여러 페이지 뷰가 포함될 수 있습니다.
- **API Requests** - API 데이터를 위한 HTTP 요청입니다.

더 자세한 메트릭을 보려면 **Add filter**를 선택하세요. 또한 각 메트릭을 다음 기준으로 필터링할 수 있습니다.

- 캐시 상태
- 데이터 센터
- 소스 ASN
- 국가
- 소스 디바이스 유형
- 소스 IP
- 참조 호스트
- 호스트
- HTTP 메서드
- HTTP 버전
- 경로
- 쿼리 문자열
- 콘텐츠 유형
- 엣지 상태 코드
- 원본 상태 코드
- 보안 작업
- 보안 소스
- 소스 브라우저
- 소스 운영체제
- 소스 user agent
- X-Requested-With 헤더

또한 다음 필터는 Enterprise [Bot Management](/bots/get-started/bot-management/) 고객만 사용할 수 있습니다.

- Source JA4 fingerprint
- Source JA3 fingerprint

기간을 변경하려면 그래프 위 오른쪽의 드롭다운 메뉴를 사용하세요. 그래프에서 드래그하여 확대할 수도 있습니다.

### 보안

이 탭에서는 기존 데이터와 고객 플랜에 따라 차트의 수와 유형이 달라질 수 있습니다. 이 탭의 대부분 메트릭은 Cloudflare Firewall 앱에서 제공됩니다. 사용 가능한 패널은 다음과 같습니다.

- **Threats** - 사이트에 대한 위협을 보여 주는 데이터 요약과 영역 차트를 표시합니다.
- **Threats by Country** - 위협이 발생한 국가를 강조하는 대화형 지도입니다. 또한 **Top Threat Countries / Regions** 및 **Top Crawlers / Bots** 통계 데이터 테이블도 포함됩니다.
- **Rate Limiting** (추가 서비스) - 속도 제한 기준으로 일치 및 차단된 요청을 강조하는 선형 차트를 제공합니다. 자세한 내용은 [Rate Limiting Analytics](/waf/reference/legacy/old-rate-limiting/#analytics)를 참고하세요.
- **Overview** - **Total Threats Stopped**, **Traffic Served Over SSL**, **Types of Threats Mitigated**에 대한 원형 차트 세트를 표시합니다. 사용 가능한 경우 확장 가능한 **Details** 링크에 수치 데이터 표가 표시됩니다.

### 성능

이 탭 아래 집계되는 메트릭은 여러 Cloudflare 서비스에 걸쳐 있습니다. 사용 가능한 패널은 다음과 같습니다.

- **Origin Performance (Argo)** (추가 서비스) - 지난 48시간 동안 Cloudflare 엣지 네트워크와 원본 서버 간 응답 시간 관련 메트릭을 표시합니다. 추가 세부 내용은 [Argo Analytics](/argo-smart-routing/analytics/)를 참고하세요.
- **Overview** - **Client HTTP Version Used**, **Bandwidth Saved**, **Content Type Breakdown**에 대한 원형 차트 세트를 표시합니다. 사용 가능한 경우 확장 가능한 **Details** 링크에 수치 데이터 표가 표시됩니다.

### Workers

이 패널은 Cloudflare Workers용 메트릭을 제공합니다. 자세한 내용은 [Workers와 함께 사용하는 Cloudflare 분석](/analytics/account-and-zone-analytics/analytics-with-workers/)을 읽어보세요.

### 로그

Logs 탭은 메트릭 기능이 아닙니다. 대신 Enterprise 플랜 고객은 [Cloudflare Logs Logpush](/logs/logpush/) 서비스를 활성화할 수 있습니다. Logpush를 사용하면 원하는 분석 도구로 데이터를 다운로드하고 분석할 수 있습니다.

Cloudflare는 차단하거나 챌린지한 위협을 분류합니다. 사이트 트래픽을 더 잘 이해할 수 있도록 분석 페이지의 'Type of Threats Mitigated' 메트릭은 다음 범주에 의해 차단되거나 챌린지된 위협을 측정합니다.

## Bad browser

요청 출처가 정상이 아니거나 요청 자체가 악의적이었습니다. 사용자는 브라우저에서 [1010 오류 페이지](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1010/)를 보게 됩니다.

Cloudflare의 [Browser Integrity Check](/waf/tools/browser-integrity-check/)는 일반적으로 스패머가 악용하는 공통 HTTP 헤더를 검사하고 페이지 접근을 거부합니다. 또한 user agent가 없거나 비표준 user agent를 사용하는 방문자(봇, 크롤러, 방문자에게 흔함)에게 챌린지를 표시합니다.

## Blocked hotlink

[Hotlink Protection](/waf/tools/scrape-shield/hotlink-protection/)은 다른 사이트가 원본 서버에 호스팅된 이미지에 링크하는 페이지를 만들어 대역폭을 사용하는 일을 방지합니다. 이 기능은 Cloudflare 고객이 켜거나 끌 수 있습니다.

## Human challenged

방문자에게 대화형 챌린지 페이지가 표시되었지만 통과하지 못했습니다.

_참고: 대화형 챌린지 페이지는 사람만 해독할 수 있는 읽기 어려운 단어나 숫자 집합입니다. 잘못 입력하거나 제때 응답하지 않으면 요청이 차단됩니다._

## Browser challenge

봇이 JavaScript 챌린지에 잘못된 답을 제공했습니다(대부분의 경우 이런 일은 드뭅니다. 일반적으로 봇은 챌린지에 전혀 응답하지 않으므로 "실패한" JavaScript 챌린지는 로그에 기록되지 않습니다).

_참고: JavaScript 챌린지 동안 Cloudflare가 정당한 인간 방문자인지 확인하기 위해 일련의 수학적 챌린지를 수행하는 약 5초간의 중간 페이지가 표시됩니다._

## Bad IP

위협 점수를 기준으로 Cloudflare가 신뢰하지 않는 IP 주소에서 들어온 요청입니다.

이전에는 위협 점수가 방문자 IP 평판을 분류하는 `0`(위험 없음)부터 `100`(고위험)까지의 값이었습니다. 현재는 위협 점수가 항상 `0`입니다.

## Country block

WAF에 설정된 [사용자 구성](/waf/tools/ip-access-rules/)에 따라 차단된 국가에서 온 요청입니다.

## IP block (user)

WAF에 설정된 [사용자 구성](/waf/tools/ip-access-rules/)에 따라 특정 IP 주소에서 차단된 요청입니다.

## IP range block (/16)

WAF에 설정된 [사용자 구성](/waf/tools/ip-access-rules/)에 따라 차단된 /16 IP 범위입니다.

## IP range block (/24)

WAF에 설정된 [사용자 구성](/waf/tools/ip-access-rules/)에 따라 차단된 /24 IP 범위입니다.

## New Challenge (user)

**Security** > **WAF**에 구성된 WAF 관리 규칙 또는 사용자 지정 규칙에서 방문자 IP에 대해 설정된 사용자 구성에 기반한 [Challenge](/cloudflare-challenges/)입니다.

## Challenge error

챌린지를 통과하지 못한 봇이 수행한 요청입니다.

_참고: 대화형 챌린지 페이지는 사람만 해독할 수 있는 읽기 어려운 단어나 숫자 집합입니다. 잘못 입력하거나 제때 응답하지 않으면 요청이 차단됩니다._

## Bot Request

봇에서 들어온 요청입니다.

## Unclassified

분류되지 않은 위협은 Browser Integrity Challenge(Bad Browser)와 관련되지 않은 여러 자동 차단을 포함합니다. 이러한 위협은 보통 Hotlink Protection 및 요청의 콘텐츠가 아니라 요청 구성 자체를 기반으로 Cloudflare 글로벌 네트워크에서 발생하는 다른 동작과 관련이 있습니다.

Unclassified는 Hotlink Protection과 관련된 일반적인 위협뿐 아니라, 서버에 도달하기 전에 Cloudflare 글로벌 네트워크에서 차단되는 특정 요청을 함께 묶는 여러 조건을 의미합니다.

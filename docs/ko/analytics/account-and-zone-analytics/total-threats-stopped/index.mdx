title: 차단된 총 위협 수
---

Total Threats Stopped는 사이트를 겨냥한 'suspicious' 및 'bad' 요청 수를 측정합니다. 요청은 Cloudflare 네트워크에 진입할 때 다음과 같이 분류됩니다.

- **Legitimate:** 요청이 사이트로 직접 전달되었습니다.
- **Suspicious:** 요청에 [Cloudflare challenge](/cloudflare-challenges/)가 적용되었습니다.
- **Bad:** Browser Integrity Check 또는 WAF 규칙, IP Access 규칙 같은 사용자 구성 설정으로 인해 요청이 차단되었습니다.

위협 분석 외에도 웹사이트로 향하는 검색 엔진 크롤러를 모니터링할 수 있습니다. 대부분의 웹사이트에서 위협과 크롤러는 트래픽의 20%~50%를 차지합니다.

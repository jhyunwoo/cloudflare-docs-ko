:::note

데이터 센터별 상태 코드 분석은 [Enterprise 서비스 수준](https://www.cloudflare.com/plans/enterprise/contact/)에서만 사용할 수 있습니다.
:::

Cloudflare 대시보드의 **Analytics** 앱에 있는 상태 코드 메트릭은 웹사이트에서 발생하는 오류가 데이터 센터별로 어떻게 분포하는지 고객이 더 깊이 이해할 수 있게 해줍니다. 데이터 센터 시설은 Cloudflare가 엣지 네트워크를 구성하는 서버를 운영하는 장소입니다([현재 위치](https://www.cloudflare.com/network/)).

응답이 Cloudflare 엣지를 통과할 때 나타나는 HTTP 상태 코드는 분석에 표시됩니다.

`Origin Status Code`는 원본에서 발생하는 문제를 조사하는 데 도움이 됩니다. 원본이 `5xx` 오류를 반환하면 Cloudflare 엣지는 이 오류를 최종 사용자에게 전달합니다. `Edge Status Code`와 `Origin Status Code`를 비교하면 문제가 원본에서 발생하는지 Cloudflare 엣지에서 발생하는지 판단하는 데 도움이 됩니다.

Cloudflare 엣지 서버에서 발생하는 오류(단순히 `Cloudflare`만 표시되는 빈 `502`, `503`, `504` 오류 페이지)는 오류 분석에 포함되지 않습니다.

범례에서 하나 이상의 특정 오류를 선택해 해당 오류를 필터링할 수 있습니다. 특정 오류를 제외하면 더 이상 그래프에 표시되지 않습니다.

:::note

사용자는 보고되지 않는 `100x` 오류를 볼 수도 있습니다. 이러한 오류는 `403` 또는 `409`(edge) 오류로 표시됩니다.
:::

## 일반적인 엣지 상태 코드

- `400` - Cloudflare Edge에서 가로채어진 잘못된 요청(예: 누락되었거나 잘못된 HTTP 헤더)
- `403` - 보안 기능(예: Web Application Firewall, Browser Integrity Check, [Cloudflare challenges](/cloudflare-challenges/), 대부분의 1xxx 오류 코드)
- `409` - 일반적으로 1000 또는 1001 오류 코드 형태의 DNS 오류
- `413` - 업로드 파일 크기가 허용 최대 크기를 초과함(대시보드의 **Network** > **Maximum Upload Size**에서 설정)
- `444` - Nginx에서 서버가 클라이언트에 어떤 정보도 반환하지 않고 연결을 닫았음을 나타내기 위해 사용됩니다. 이 오류 코드는 Nginx 내부용이며 클라이언트에 반환되지 **않습니다**.
- `499` - 서버가 요청을 처리하는 동안 클라이언트가 연결을 종료하여 서버가 상태 코드를 돌려줄 수 없을 때 Nginx에서 사용됩니다.

자세한 내용은 [4xx Client Error](/support/troubleshooting/http-status-codes/4xx-client-error/)를 참고하세요.

***

## 일반적인 원본 상태 코드

- `400` - 애플리케이션이 보낸 잘못되었거나 지원되지 않는 구문 때문에 원본이 요청을 거부함
- `404` - 원본이 특정 요청에 대해 404 응답을 발생시킨 경우에만 해당
- `4xx`
- `50x`

자세한 내용은 [4xx Client Error](/support/troubleshooting/http-status-codes/4xx-client-error/) 및 [Troubleshooting Cloudflare 5XX errors](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/)를 참고하세요.

***

## 52x 오류

- `520` - 원본 서버가 예기치 않은 내용을 반환하거나, 엣지가 허용하지 않거나 해석할 수 없는 내용(예: 프로토콜 위반 또는 빈 응답)을 반환할 때 사용하는 사실상의 "포괄" 응답입니다.
- `522` - 엣지가 원본 서버와 TCP 연결을 설정할 수 없었습니다.
- `523` - 원본 서버에 도달할 수 없습니다(예: 원본 IP가 변경되었지만 DNS가 업데이트되지 않았거나, 엣지와 원본 사이의 네트워크 문제).
- `524` - 엣지가 TCP 연결은 설정했지만, 원본이 연결 시간 초과 전에 HTTP 응답을 반환하지 않았습니다.
- `525` - Cloudflare와 원본 웹 서버 간 SSL 핸드셰이크가 실패했음을 나타냅니다. 네트워크 문제 또는 원본의 인증서 문제 때문일 수 있습니다.
- `526` - 원본에 구성된 인증서가 유효하지 않습니다.

자세한 내용은 [Troubleshooting Cloudflare 5XX errors](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/)를 참고하세요.

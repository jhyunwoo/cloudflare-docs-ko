Cloudflare 계정 분석을 사용하면 특정 Cloudflare 계정 아래의 모든 사이트에서 집계된 다양한 메트릭에 접근할 수 있습니다.

:::note

Cloudflare의 전체 분석 제품군에 대한 일반 정보는 [About Cloudflare Analytics](/analytics/faq/about-analytics/)를 참고하세요.
:::

## 계정 분석 보기

사이트 메트릭을 보려면 Cloudflare 대시보드에서 **Account Analytics** 페이지로 이동하세요.

   <DashButton url="/?to=/:account/analytics" />

페이지가 로드되면 Account Analytics 앱에 계정용 집계 메트릭이 카테고리별 차트 모음으로 표시됩니다. 사용 가능한 다양한 메트릭을 이해하려면 아래의 *계정 메트릭 검토*를 참고하세요.

***

## 계정 메트릭 검토

이 섹션에서는 각 범주 아래의 집계 메트릭을 설명합니다. 메트릭을 검토하기 전에, 일부 패널에서 사용되는 몇 가지 개념을 정의하겠습니다.

* *비율(Rate)* - 특정 데이터 범주의 양과 전체 양의 비율을 나타냅니다.
* *대역폭(Bandwidth)* - Cloudflare 엣지 네트워크에서 요청한 클라이언트로 전송된 바이트 수를 의미합니다.

또한 다음 사항도 참고하세요.

* 특정 기간의 메트릭으로 필터링하려면 오른쪽 상단의 드롭다운을 사용합니다.
* 대부분의 메트릭은 기본 데이터를 서로 다른 측면으로 나타내는 패널로 그룹화됩니다.

### 메트릭 요약

아래는 제공되는 메트릭을 구성하는 주요 요소에 대한 간단한 설명입니다.

#### HTTP 트래픽

이 차트는 HTTP 트래픽 데이터를 집계하며 다음을 포함합니다.

![Chart showing last week's data for HTTP traffic](~/assets/images/support/hc-dash-account-analytics-map.png)

* *Requests*, *Bandwidth*, *Page views*, *Visitors* (*Unique IPs*)에 대한 스파크라인
* 국가별 요청 수를 세분화하는 대화형 지도
* 국가별 총 요청 수를 기준으로 정렬된 수치 데이터와 스파크라인 데이터를 결합한 표

#### 보안

![Panel displaying lines highlighting encryption metrics: requests, requests rate, bandwidth, and bandwidth rate](~/assets/images/support/hc-dash-account-analytics_security_panel.png)

이 패널에는 *requests*, *requests rate*, *bandwidth*, *bandwidth rate* 등 다양한 암호화 메트릭을 강조하는 스파크라인이 포함됩니다. 또한 이전 기간과 비교한 변화율도 함께 표시됩니다.

#### 캐시

![Panel displaying lines for caching metrics: requests, requests rate, bandwidth, and bandwidth rate](~/assets/images/support/hc-dash-account-analytics_cache_card.png)

이 패널에는 *requests*, *requests rate*, *bandwidth*, *bandwidth rate* 등 다양한 캐싱 메트릭에 대한 스파크라인이 포함됩니다. 또한 이전의 동일 기간과 비교한 변화율도 함께 표시됩니다. 예를 들어 기간으로 *지난주(Last week)*를 선택한 경우, 이전 기간은 그 전 *주*를 의미합니다.

#### 오류

![Panel displaying lines for 4xx and 5xx error rates](~/assets/images/support/hc-account-analytics_errors_card.png)

이 패널은 각각 4xx 및 5xx 오류율에 대한 스파크라인을 표시합니다. 자세한 내용은 [HTTP 상태 코드](/support/troubleshooting/http-status-codes/)를 참고하세요.

#### 네트워크

![Statistics showing the percentage of requests that use a specific version of HTTP](~/assets/images/support/hc-dash-account-analytics_network_card.png)

#### 사용된 클라이언트 HTTP 버전

이 통계는 특정 HTTP 버전을 사용하는 요청의 비율을 보여줍니다.

#### SSL을 통해 제공된 트래픽

이 통계는 특정 SSL 또는 TLS 버전을 사용해 암호화된 트래픽의 비율을 보여줍니다.

#### 콘텐츠 유형 분포

이 통계는 리소스 콘텐츠 유형에 따른 요청 수를 보여줍니다.

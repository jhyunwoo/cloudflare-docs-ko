[Cloudflare China Network](https://www.cloudflare.com/application-services/products/china-network/)는 중국 본토에 위치한 데이터 센터에서 운영되며, Cloudflare의 파트너인 JD Cloud가 운영하는 일부 Cloudflare 성능 및 보안 제품 패키지입니다.

이 데이터 센터들은 중국 내 주요 인구 밀집 지역 대부분을 포괄합니다. Cloudflare의 기술 리더십과 JD Cloud의 현지 운영 전문성을 결합한 Cloudflare China Network는 중국 내에서 안전하고 신뢰할 수 있으며 빠른 콘텐츠 전송에 대한 요구를 충족하도록 설계되었습니다. 세계 다른 지역에서 Cloudflare를 사용할 때와 동일한 구성과 동일한 대시보드 경험을 사용할 수 있습니다.

## 주요 기능

Cloudflare China Network는 다음을 제공합니다.

- [WAF](/waf/), [DDoS](/ddos-protection/), [Bot Management](/bots/)와 같은 성능 향상 및 보안 서비스를 하나의 솔루션으로 제공합니다.
- 네트워크 트래픽과 보안 상태를 통합된 방식으로 관리할 수 있습니다. 모든 구성을 동일한 대시보드에서 관리할 수 있습니다.
- Cloudflare 글로벌 네트워크와 동일한 고객 지원 기능을 제공합니다. 프리미엄 서비스와 현지 언어 지원을 이용할 수도 있습니다.
- [중국 내 권한 DNS 및 중국 내 네임서버](/china-network/concepts/china-dns/)를 통해 Time to First Byte(TTFB) 성능을 개선합니다.
- [Global Acceleration](/china-network/concepts/global-acceleration/)은 글로벌 자산의 중국 내 배포를 단순화하도록 설계된 연결성과 성능 기능 제품군입니다.

## 제공 여부

Cloudflare China Network는 [Enterprise 요금제](https://www.cloudflare.com/plans/enterprise/) 고객을 위한 별도 구독 형태로 제공됩니다.

## 중요 참고 사항

- 모든 Cloudflare 제품이 Cloudflare China Network에서 제공되는 것은 아닙니다. 자세한 내용은 [사용 가능한 제품 및 기능](/china-network/reference/available-products/)을 참고하세요.
- 중국 본토에서 운영되는 모든 인터넷 주체는 IPv6 지원이 의무입니다. Cloudflare China Network 기능은 이 요구 사항을 충족하기 위해 도메인에 IPv6를 자동으로 활성화합니다.
- 중국 본토 내부의 모든 콘텐츠는 현지 당국의 모니터링 대상이며 현지 규정을 준수해야 합니다.
- Cloudflare에 온보딩하려는 각 apex 도메인마다 유효한 [ICP(Internet Content Provider) 등록 또는 라이선스](/china-network/concepts/icp/)가 있어야 합니다.

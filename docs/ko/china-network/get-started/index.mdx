## 1. 필요한 서비스를 계약하고 추가 약관에 동의하기

<Steps>

1. Cloudflare Enterprise 요금제를 사용 중인지 확인합니다. 아직 Enterprise 요금제가 없다면 업그레이드해야 합니다.
2. Enterprise 요금제에 Cloudflare China Network 패키지(별도 구독)를 추가합니다.
3. [China Service 추가 약관](https://www.cloudflare.com/supplemental-terms/#china-service)에 동의합니다.

</Steps>

이 단계에 대한 자세한 내용은 영업팀에 문의하세요.

## 2. ICP를 취득하고 도메인 콘텐츠 심사 받기

<Steps>

1. 온보딩하려는 모든 apex 도메인에 대해 [Internet Content Provider 등록 또는 라이선스](/china-network/concepts/icp/#obtain-an-icp-number)를 취득합니다.

2. 온보딩할 Zone에 대해 유효한 ICP 등록 또는 라이선스를 제시합니다.

3. 웹사이트가 [페이지 푸터에 ICP 번호를 표시](/china-network/concepts/icp/#display-your-icp-number)하도록 합니다.

4. JD Cloud가 도메인 콘텐츠를 검토할 수 있도록 필요한 정보를 준비합니다. 파트너인 JD Cloud는 China Network를 활성화하기 전에 자사 네트워크에 올라가는 모든 도메인의 콘텐츠를 검토하고 심사해야 합니다. 다음 정보를 제공해야 합니다.
   - 고객 및 회사명
   - 도메인 이름
   - ICP 라이선스/등록 번호
   - 각 도메인 콘텐츠에 대한 일반 설명(예: 마케팅 웹사이트)
   - 서명된 Self Attestation letter(영업팀 제공)

</Steps>

## 3. 도메인을 Cloudflare China Network에 온보딩하기

콘텐츠 심사가 완료되면 [도메인을 Cloudflare에 추가](/fundamentals/manage-domains/add-site/)하세요.

Zone을 처음 활성화하는 경우 China Network에 완전히 온보딩되기까지 약 24~48시간이 걸립니다. 이후에는 Cloudflare 대시보드 안에서 China Network를 활성화하거나 비활성화할 수 있습니다.

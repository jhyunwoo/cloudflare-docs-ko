## 중국 데이터 센터

최신 정보는 [Cloudflare China Network](https://www.cloudflare.com/china-network/) 페이지를 참고하세요.

### 네트워크 IP 주소

Cloudflare는 고객 오리진 네트워크에 연결해 자산을 가져올 때 사용하는 JD Cloud 데이터 센터의 IP 주소 목록을 게시합니다. 이 주소는 DNS 확인 과정에서 웹사이트 방문자에게 반환되는 IP 주소와는 다릅니다.

Cloudflare API를 통해 JD Cloud 데이터 센터 IP 주소 목록을 얻을 수 있습니다. `networks=jdcloud` 쿼리 문자열 매개변수와 함께 [Cloudflare/JD Cloud IP Details](/api/resources/ips/methods/list/) 작업을 사용하세요.

<APIRequest
	path="/ips"
	method="GET"
	parameters={{
		networks: "jdcloud",
	}}
/>

```json output {9-11}
{
	"result": {
		"ipv4_cidrs": [
			// (...)
		],
		"ipv6_cidrs": [
			// (...)
		],
		"jdcloud_cidrs": [
			// (...)
		],
		"etag": "<ETAG>"
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

`jdcloud_cidrs` 배열에는 JD Cloud 데이터 센터의 IP 주소가 나열됩니다.

Cloudflare는 새로운 IP 주소에서 오리진 서버로 연결하기 최소 30일 전에 이 목록에 새 IP 주소를 추가합니다. JD Cloud 기반 China Network를 사용 중이라면 최소 30일에 한 번은 방화벽을 업데이트해 IP 주소 변경 사항을 반영해야 합니다.

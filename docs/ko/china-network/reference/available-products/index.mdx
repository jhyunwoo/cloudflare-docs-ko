다음 제품과 기능은 JD Cloud가 운영하는 Cloudflare China Network에서 사용할 수 있습니다.

## 애플리케이션 서비스

| 제품/기능 | 설명 |
| --- | --- |
| [Authoritative DNS](/china-network/concepts/china-dns/) | 중국 본토 내부에서의 Authoritative DNS 확인. |
| [CDN/Cache](/cache/) | 핵심 캐시 기능. 정적 캐시만 지원합니다. Cache Reserve 또는 Tiered Cache는 지원하지 않습니다. |
| [Image Transformations](/images/) | 도메인 레이아웃에 맞게 엣지에서 이미지 형식을 최적화합니다. |
| [DDoS Protection](/ddos-protection/) | HTTP flood 공격, WordPress Pingback 공격, HULK 공격, LOIC 공격과 같은 DDoS 공격에 대한 Layer 7(애플리케이션 계층) 보호 기능입니다. |
| [Managed rules](/waf/managed-rules/) | 사전 구성된 OWASP ruleset과 Cloudflare managed ruleset입니다. |
| [Custom rules](/waf/custom-rules/) | 사용자 지정 WAF 규칙입니다. 업로드된 콘텐츠 스캔과 managed challenge를 지원합니다. |
| [Rate limiting rules](/waf/rate-limiting-rules/) | 표현식과 일치하는 들어오는 요청에 대한 속도 제한과, 제한에 도달했을 때 수행할 작업을 정의합니다. |
| [Content scanning](/waf/detections/malicious-uploads/) | 업로드된 파일과 같은 콘텐츠 객체를 탐지하고, 멀웨어와 같은 악성 시그니처를 스캔하려고 시도합니다. |
| [Page Shield](/page-shield/) | 스크립트와 같은 로드된 리소스를 추적하고 새로운 리소스나 악성 스크립트를 감지할 때 경고를 제공하여 외부 스크립트 관리를 단순화합니다. |
| [Bot Management](/bots/)[^1] | 도메인에 대한 봇 식별 및 보호 기능을 제공합니다. 일부 Machine Learning(ML) 모델만 지원합니다. |
| [Argo Smart Routing](/argo-smart-routing/) | Layer 7(애플리케이션 계층) 트래픽을 더 효율적으로 오리진으로 스마트 라우팅합니다. |
| [Rules](/rules/)[^2] | 요청과 응답을 조정하고, Cloudflare 설정을 구성하며, 일치하는 요청에 대해 특정 작업을 실행합니다. |
| [Load Balancing](/load-balancing/additional-options/load-balancing-china/) | 애플리케이션 성능과 가용성을 극대화합니다. |

## 개발자 서비스

| 제품/기능 | 설명 |
| --- | --- |
| [Workers](/workers/) | Cloudflare 글로벌 네트워크에서 실행되는 서버리스 실행 환경입니다. |
| [Workers KV](/kv/) | 구성 데이터, 서비스 라우팅 메타데이터, 개인화(A/B 테스트)에 사용됩니다. |
| [R2](/r2/)[^3] | 모든 데이터를 위한 객체 스토리지입니다. |
| [Assets](/workers/static-assets/) | Worker의 일부로 정적 자산(HTML, CSS, 이미지 및 기타 파일)을 업로드하면 Cloudflare가 웹 브라우저에 대한 캐싱과 제공을 처리합니다. |
| [Environment variables](/workers/configuration/environment-variables/) | 텍스트 문자열 또는 JSON 값을 Worker에 연결합니다. |
| [Images](/images/transform-images/bindings/)[^4] | 이미지를 저장, 변환, 최적화하고 대규모로 전달합니다. |
| [mTLS](/workers/runtime-apis/bindings/mtls/) | [mTLS](https://www.cloudflare.com/learning/access-management/what-is-mutual-tls/)를 통해 백엔드 서버에 안전하게 연결합니다. |
| [Rate Limiting](/workers/runtime-apis/bindings/rate-limit/) | Worker 안에서 속도 제한을 정의하고 그 주변 로직을 작성합니다. |
| [Secrets](/workers/configuration/secrets/) | 암호화된 텍스트 값을 Worker에 연결합니다. |
| [Service bindings](/workers/runtime-apis/bindings/service-bindings/) | 공개 URL을 거치지 않고 하나의 Worker가 다른 Worker를 호출할 수 있게 합니다. |
| [Tail Workers](/workers/observability/logs/tail-workers/) | 다른 Workers의 실행에 대한 정보를 수신합니다. |
| [Version metadata](/workers/runtime-apis/bindings/version-metadata/) | Workers 런타임 내부에서 버전에 연결된 메타데이터에 접근합니다. |
| [Workers for Platforms](/cloudflare-for-platforms/workers-for-platforms/) | 사용자 대신 사용자 지정 코드를 배포하거나, 사용자가 직접 자신의 코드를 플랫폼에 배포할 수 있도록 하면서 인프라를 관리합니다. |

[^1]: [Turnstile](/turnstile/)은 중국 본토에서 사용할 수 없습니다.

[^2]: [Origin Rules](/rules/origin-rules/)는 원래 Zone(방문자가 접근하는 Zone)과 대상 Zone 모두에서 China Network가 활성화되어 있어야 합니다. 그렇지 않으면 방문자에게 [1016 오류](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1016/)와 함께 [HTTP 530 상태 코드](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-530/)가 반환됩니다.

[^3]: R2 버킷은 중국 본토 내에서 생성할 수 없고 [사용자 지정 도메인](/r2/buckets/public-buckets/#add-your-domain-to-cloudflare)도 중국 본토에서는 지원되지 않습니다. 다만 R2는 [Global Acceleration](/china-network/concepts/global-acceleration/)을 통해 중국 본토까지 확장할 수 있습니다.

[^4]: Image Resizing은 [Workers 내부](/images/transform-images/transform-via-workers/)에서는 동작하지만, [URL 형식](/images/transform-images/transform-via-url/)을 통해서는 사용하지 못할 수 있습니다.

## 네트워크 서비스

| --- | --- |

| [WebSockets](/workers/runtime-apis/websockets/) | Cloudflare Workers 서버리스 함수와의 실시간 통신을 지원합니다. |

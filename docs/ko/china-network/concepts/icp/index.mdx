Internet Content Provider(ICP)는 2000년 9월 공포된 중화인민공화국 전신조례(中华人民共和国电信条例)에 의해 도입된 라이선스 제도입니다.

ICP 제도에 따르면, 중국 내에서 운영되는 자체 도메인 이름을 가진 모든 웹사이트는 서버가 중국 본토에 있든, CDN을 통해 중국 방문자에게 제공되든 관계없이 라이선스를 취득해야 합니다. 라이선스는 성(省) 단위로 발급됩니다. [MIIT(중화인민공화국 공업정보화부) 웹사이트](https://beian.miit.gov.cn/#/Integrated/recordQuery)에서 도메인에 이미 ICP 번호가 있는지 확인할 수 있습니다. 이 사이트는 중국어로만 제공됩니다.

중국 본토의 모든 공개 웹사이트는 [웹사이트 홈 페이지에 ICP 번호를 표시](#display-your-icp-number)해야 합니다. 동일한 apex 도메인을 사용하는 웹사이트는 같은 ICP 번호를 공유할 수 있습니다. 중국 기반 호스팅 제공업체는 ICP 번호가 없는 웹사이트를 종종 사전 통지 없이 중단하라는 지침을 받습니다.

## ICP 유형

중국 본토에서 웹 서비스를 호스팅하려면 법적으로 **ICP 등록(ICP filing)** 또는 **ICP 라이선스(ICP license)**를 취득해야 합니다.

중국 고객에게 제공하는 웹사이트 유형에 따라 취득해야 하는 ICP 유형이 달라집니다.

|                    | ICP 등록                                                                                                                                                                                                    | ICP 라이선스                                                                                                                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 정의         | 중국어로 “Bei’An”이라고 하는 ICP 등록은 ICP 등록의 첫 단계입니다. ICP 등록이 있으면 중국 본토의 서버 또는 CDN에서 정보 제공 목적의 웹사이트를 호스팅할 수 있습니다. | 중국어로 “ICP Zheng”이라고 하는 ICP 라이선스는 상품 및 서비스를 판매하는 온라인 플랫폼이나 제3자 판매자가 중국 본토 내 호스팅 서버 또는 CDN에 웹사이트를 배포할 수 있게 합니다. |
| 웹사이트 목적    | 비상업적, 비거래적 목적                                                                                                                                                                | 상업적, 거래적 목적                                                                                                                                                               |
| 자격 요건        | 대표 사무소<br/>외국인 단독 투자 기업<br/>합작 회사<br/>현지 회사<br/>개인(개인 웹사이트)                                                                              | 합작 회사(외국 기업 지분 50% 미만)<br/>현지 회사                                                                                                                       |
| 예시 형식     | Beijing ICP preparation XXXXXXXX number                                                                                                                                                                       | Beijing ICP license XXXXXXXX number                                                                                                                                                                  |
| 기타 요구 사항 | 해당 없음                                                                                                                                                                                                           | ICP 라이선스를 취득하려는 회사는 먼저 ICP 등록을 완료해야 합니다.                                                                                                                         |
| 소요 기간           | 1~2개월                                                                                                                                                                                                    | 2~3개월                                                                                                                                                                                           |

마케팅 관련 웹사이트를 호스팅하려는 경우에는 ICP 등록만 있으면 됩니다.

## ICP 번호 취득

Cloudflare는 호스팅 또는 클라우드 서비스 제공업체를 통해 ICP 라이선스를 신청할 것을 권장합니다. 제공업체가 귀하를 대신해 ICP 번호를 등록할 수 있도록 필요한 문서를 제공해야 합니다.

| 개인의 경우                                                                                                                             | 상업용 회사의 경우                                                 |
| ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| – ICP 신청서<br/>– 신분증 사본<br/>– 웹사이트 정보 확인용 양식<br/>– 도메인 인증서 사본 | – 사업자 등록증 사본<br/>– 조직 코드 증명서 |

필수 서류를 모두 제출한 후 ICP 취득에는 웹사이트 유형과 회사가 등록된 성에 따라 4주에서 8주가 걸릴 수 있습니다. MIIT 등록 자체에는 비용이 없지만, 제공업체가 수수료를 청구할 수 있습니다.

ICP 번호와 인증서를 받은 후에는 이를 웹사이트 홈 페이지에 추가하세요.

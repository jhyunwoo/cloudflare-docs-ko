## 사전 준비 사항

로드 밸런서를 [China Network](/china-network/)에 배포할 수 있도록 하려면, 해당 zone이 다음 두 가지 조건을 충족해야 합니다.

1. 해당 zone에 유효한 [ICP 라이선스](/china-network/concepts/icp/)가 있어야 합니다.
2. 해당 zone이 China Network 접근 권한과 함께 프로비저닝되어 있어야 합니다.

이 두 조건이 충족되면 새로 생성하는 모든 로드 밸런서가 자동으로 China Network에 배포됩니다. 풀의 헬스 체크 리전을 선택할 때, 이제 대시보드와 API 모두에서 `China`를 선택할 수 있습니다.

다음 엔드포인트로 `POST` 요청을 보내 로드 밸런서를 생성할 수도 있습니다. API로 China Network에 배포하려면 API 호출의 `networks` 배열에 `cloudflare`와 함께 `jdcloud` 값도 포함되어야 합니다. 필수 필드와 형식에 대한 자세한 내용은 [Cloudflare API 문서](/api/resources/load_balancers/methods/create/)를 참고하세요.

```bash
https://api.cloudflare.com/client/v4/zones/{zone_id}/load_balancers
```

## 제한 사항

현재 China Network에 배포된 로드 밸런서에는 다음과 같은 제한이 있습니다.

- 쿠키 기반 session affinity만 지원됩니다.
- private network off-ramp(Tunnel, GRE, IPsec)은 지원되지 않습니다.
- China Network에서는 Private Network Load Balancing을 사용할 수 없습니다.

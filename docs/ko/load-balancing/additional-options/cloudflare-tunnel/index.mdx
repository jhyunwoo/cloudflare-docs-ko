Cloudflare Tunnel(이전 명칭 Argo Tunnel)은 인프라 내부에서 실행되는 안전한 아웃바운드 연결을 구성하여 애플리케이션과 머신을 Cloudflare에 연결합니다.

Cloudflare Tunnel과 public hostname으로 Load Balancing을 사용하는 방법에 대한 자세한 내용은 [로드 밸런서를 사용해 터널 트래픽 라우팅](/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/public-load-balancers/)을 참고하세요. 대신 private IP를 사용하려면 [Tunnel로 private IP 설정](/load-balancing/private-network/warp-to-tunnel/)을 참고하세요.

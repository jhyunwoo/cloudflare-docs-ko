특정 HTTP 요청에 로드 밸런서가 어떻게 응답할지 사용자 지정하려면 **동작**을 추가하세요.

각 Load Balancing 규칙에는 하나 이상의 동작이 포함됩니다.

## 지원되는 동작

이 표에는 Load Balancing 규칙에서 사용할 수 있는 동작이 나와 있습니다. 단계별 안내는 [Load Balancing 규칙 만들기](/load-balancing/additional-options/load-balancing-rules/create-rules/)를 참고하세요.

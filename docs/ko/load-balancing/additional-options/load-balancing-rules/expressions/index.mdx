[Load Balancing 규칙](/load-balancing/additional-options/load-balancing-rules/)은 두 종류의 표현식을 사용합니다.

* [단순 표현식](#simple-expressions)은 HTTP 요청의 값을 표현식에 정의된 값과 비교합니다. 단순 표현식은 **비교 연산자**(예: *equals*, *less than*)가 있다는 점으로 식별됩니다.

* [복합 표현식](#compound-expressions)은 두 개 이상의 단순 표현식을 하나의 표현식으로 결합합니다. 복합 표현식에는 **논리 연산자**(예: *and*, *or*)가 포함됩니다. 복합 표현식을 사용하면 매우 높은 정확도와 정밀도로 특정 사용 사례에 맞는 규칙을 만들 수 있습니다.

***

<div id="simple-expressions"></div>

## 단순 표현식

단순 표현식은 세 가지 요소로 구성됩니다.

1. HTTP 요청의 속성을 나타내는 **필드**
2. Cloudflare가 실제 요청 값과 비교하는 해당 필드의 대표 **값**
3. 표현식에 정의된 값이 요청의 실제 값과 어떤 관계여야 `true`를 반환하는지 지정하는 **비교 연산자**

비교 연산자가 `true`를 반환하면 요청은 해당 표현식과 일치합니다.

다음 예시 표현식은 요청 URI 경로에 `/content`가 포함될 때 true를 반환합니다.

```sql
(http.request.uri.path contains "/content")
```

일반적으로 단순 표현식은 다음 패턴을 사용합니다.

```sql
<field> <operator> <value>
```

자세한 내용은 [지원되는 필드와 연산자](/load-balancing/additional-options/load-balancing-rules/reference/)를 참고하세요.

## 복합 표현식

복합 표현식은 **논리 연산자**(예: *and*, *or*)를 사용해 둘 이상의 표현식을 결합합니다. 복합 표현식을 사용하면 하나의 표현식 안에서 복잡한 구문을 만들 수 있습니다.

아래 예시 표현식은 HTTP 요청 URI 경로에 `/content`가 포함되고 쿼리 문자열에 `webserver`가 포함될 때 true를 반환합니다.

```sql
(http.request.uri.path contains "/content")
and (http.request.uri.query contains "webserver")
```

일반적으로 복합 표현식은 다음 패턴을 사용합니다.

```sql
<expression> <logical operator> <expression>
```

복합 표현식은 또 다른 논리 연산자의 피연산자가 될 수 있습니다. 이를 통해 여러 연산자를 사용해 개별 표현식 다수로부터 하나의 복합 표현식을 구성할 수 있습니다.

자세한 내용은 [지원되는 필드와 연산자](/load-balancing/additional-options/load-balancing-rules/reference/)를 참고하세요.

## 표현식 사용하기

Expression Builder의 시각적 인터페이스를 사용하면 필드 이름과 문법을 신경 쓰지 않고 표현식을 만들 수 있습니다.

반면 Expression Editor는 텍스트 전용이지만, Builder에서 제공되지 않는 고급 기능을 지원합니다.

<div id="expression-builder"></div>

### Expression Builder

복합 표현식은 Expression Builder의 시각적 인터페이스에서 볼 때 더 쉽게 훑어볼 수 있으며, Expression Preview는 더 고급 표현식 작성법을 익히는 데 좋은 참고 자료가 됩니다.

다음 Expression Builder 스크린샷은 앞서 설명한 예시 복합 표현식을 보여줍니다. 복합 표현식은 Expression Builder의 시각적 인터페이스에 표시될 때 더 쉽게 훑어볼 수 있습니다.

![Expression Builder에 표시된 예시 규칙 구성](~/assets/images/load-balancing/rules-builder-1.png)

**Expression Preview**에는 텍스트 형태의 표현식이 표시됩니다.

```sql
(http.request.uri.path contains "/content")
and (http.request.uri.query contains "webserver")
```

단계별 안내는 [Load Balancing 규칙 만들기](/load-balancing/additional-options/load-balancing-rules/create-rules/)를 참고하세요.

<div id="expression-editor"></div>

### Expression Editor

Expression Editor는 Load Balancing 표현식을 만드는 텍스트 전용 인터페이스입니다. Expression Builder의 시각적 단순함은 없지만, 괄호 같은 grouping symbol 지원과 같은 고급 기능을 제공합니다.

**Traffic** 앱에서 Expression Editor에 접근하려면 **Create Custom Rule** 대화상자에서 **Edit expression**을 클릭하세요.

Builder로 돌아가려면 **Use expression builder**를 클릭하세요.

### Rules lists

Load Balancing Custom Rules는 IP list 연산자를 지원하지 않습니다.

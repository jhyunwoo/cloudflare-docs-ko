## 사용자 지정 규칙의 작동 방식

[WAF 사용자 지정 규칙](/waf/custom-rules/)과 마찬가지로 각 Load Balancing 사용자 지정 규칙은 [표현식](/load-balancing/additional-options/load-balancing-rules/expressions/)과 [동작](/load-balancing/additional-options/load-balancing-rules/actions/)이라는 두 요소의 조합으로 이루어집니다. 표현식은 어떤 HTTP 요청이 동작을 트리거할지 기준을 정의합니다. 동작은 Cloudflare가 해당 요청을 어떻게 처리할지 알려줍니다.

로드 밸런서를 생성하거나 편집할 때 **Load Balancing**에서 [Load Balancing 규칙을 생성](/load-balancing/additional-options/load-balancing-rules/create-rules/)할 수 있습니다.

Load Balancing 규칙용 표현식을 만들 때는 정의와 사용법을 위해 [지원되는 필드와 연산자](/load-balancing/additional-options/load-balancing-rules/reference/)를 참고하세요.

## 사용 가능 여부

기본적으로 Enterprise가 아닌 고객은 **로드 밸런서 호스트 이름당** **하나의** Load Balancing 규칙을 사용할 수 있습니다. 더 많은 규칙이 필요하면 [Enterprise](https://www.cloudflare.com/enterprise/)로 업그레이드하세요.

## 제한 사항

현재 [Cloudflare Spectrum](/spectrum/about/load-balancer/)에서는 Load Balancing 규칙을 사용할 수 없습니다.

사용자 지정 Load Balancing 규칙은 [Geo Steering](/load-balancing/understand-basics/traffic-steering/steering-policies/geo-steering/)과 호환되지 않습니다. 따라서 Geo Steering이 적용된 로드 밸런서에 사용자 지정 규칙을 적용하면 예상대로 동작하지 않습니다.

[간단한 로드 밸런서 만들기](/load-balancing/load-balancers/create-load-balancer/)를 넘어, 로드 밸런서가 트래픽을 라우팅하는 방식을 더 세밀하게 사용자 지정하거나 다른 Cloudflare 제품과 통합하고 싶을 수 있습니다.

## 로드 밸런서 동작 사용자 지정

* [사용자 지정 규칙 만들기](/load-balancing/additional-options/load-balancing-rules/)를 통해 각 요청의 특성에 따라 트래픽 라우팅
* [Load Shedding 설정](/load-balancing/additional-options/load-shedding/)으로 위험 상태의 엔드포인트가 장애 조치 단계에 들어가지 않도록 보호
* [계획된 유지 관리](/load-balancing/additional-options/planned-maintenance/)를 위해 엔드포인트를 순환 대상에서 제외

## 다른 Cloudflare 제품과 통합

* [Cloudflare Spectrum](/load-balancing/additional-options/spectrum/)으로 TCP 또는 UDP 애플리케이션에 Load Balancing 적용
* [Cloudflare Tunnel](/load-balancing/additional-options/cloudflare-tunnel/)로 엔드포인트 접근을 한층 더 안전하게 보호

## 서드파티와 통합

* [헬스 모니터 알림을 PagerDuty로 전송](/load-balancing/additional-options/pagerduty-integration/)하여 가시성 향상

IP 확인에 사용되는 DNS 레코드인 `A`, `AAAA`, `CNAME` 레코드 사이의 로드 밸런싱 외에도, Enterprise 고객은 **MX** 및 **SRV** 레코드 사이에서도 로드 밸런싱을 할 수 있습니다.

## MX 레코드

여러 메일 서버 사이에서 로드 밸런싱하려면 다음을 수행하세요.

1. 메일 서버에 필요한 [DNS 레코드](/dns/manage-dns-records/how-to/email-records/#send-and-receive-email)가 준비되어 있는지 확인합니다.
2. **Type**을 *SMTP*로 지정한 [모니터](/load-balancing/monitors/create-monitor/)를 [생성](/load-balancing/monitors/create-monitor/)합니다.
3. 메일 서버로 [풀](/load-balancing/pools/create-pool/)을 만들고 방금 생성한 모니터를 연결합니다.
4. 새로 만든 풀을 포함하는 [로드 밸런서](/load-balancing/load-balancers/create-load-balancer/)를 생성합니다. SMTP 트래픽을 전달하므로 로드 밸런서는 [unproxied(DNS-only)](/load-balancing/understand-basics/proxy-modes/#dns-only-load-balancing)여야 합니다.

## SRV 레코드

다른 여러 DNS 레코드보다 훨씬 더 많은 정보를 담고 있는 **SRV** 레코드 사이에서 로드 밸런싱하려면 다음을 수행하세요.

1. [SRV 레코드를 생성](/dns/manage-dns-records/how-to/create-dns-records/#create-dns-records)합니다.
2. **Type**을 *UDP-ICMP* 또는 *TCP*로 지정한 [모니터](/load-balancing/monitors/create-monitor/)를 생성합니다.
3. 다양한 SRV 레코드로 [풀](/load-balancing/pools/create-pool/)을 만들고 방금 생성한 모니터를 연결합니다.
4. 새로 만든 풀을 포함하는 [로드 밸런서](/load-balancing/load-balancers/create-load-balancer/)를 생성합니다. 이 로드 밸런서는 [unproxied(DNS-only)](/load-balancing/understand-basics/proxy-modes/#dns-only-load-balancing)여야 합니다.

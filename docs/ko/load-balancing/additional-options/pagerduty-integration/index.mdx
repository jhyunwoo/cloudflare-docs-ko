Cloudflare 헬스 모니터 알림을 PagerDuty와 통합하려면 PagerDuty의 [Email Integration Guide](https://www.pagerduty.com/docs/guides/email-integration-guide/)에 설명된 단계를 따르세요. PagerDuty 계정이 없다면 먼저 계정을 설정해야 합니다.

PagerDuty는 해당 주소로 전송된 이메일을 바탕으로 incident를 생성하는 이메일 주소를 만들어 줍니다. 그 이메일 주소를 찾는 방법은 [PagerDuty 문서](https://www.pagerduty.com/docs/guides/email-integration-guide/)를 참고하세요.

Notifier 객체를 생성할 때 이메일이 PagerDuty 통합 이메일로 전송되도록 구성하세요. 그러면 풀이나 엔드포인트가 다운될 때마다 이를 기록하는 Incident가 생성됩니다.

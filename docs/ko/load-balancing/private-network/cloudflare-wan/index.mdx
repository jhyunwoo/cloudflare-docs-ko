[Cloudflare WAN](/cloudflare-wan/)(이전 Magic WAN)을 온램프이자 오프램프로 사용해 프라이빗 또는 내부 서비스에 안전하게 연결하는 Private Network Load Balancing 솔루션을 어떻게 구성하는지 아래 단계에서 살펴보세요.

Cloudflare WAN으로 Private Network Load Balancing(PNLB)을 사용하기 위한 전제 조건 중 하나는 계정에 Cloudflare WAN이 설정되어 있고 온보딩이 완료되어 있어야 한다는 점입니다. Cloudflare One Appliance를 사용하거나, IPsec 또는 GRE 터널을 통해 자체 하드웨어로 연결할 수 있습니다. 자세한 내용이나 시작 방법은 [Cloudflare WAN documentation](/cloudflare-wan/get-started/)를 참고하세요.

## 1. Load Balancer Pool 생성

Load Balancer Pool은 엔드포인트의 논리적 그룹입니다. 일반적으로는 물리적 데이터센터나 지리적 리전 기준으로 구성됩니다. 풀 안의 엔드포인트는 최종적으로 트래픽이 전달되는 대상입니다.

:::note
Cloudflare WAN을 통해 접근하는 엔드포인트는 기본 VNET에서 접근 가능해야 하며, 해당 VNET에 할당되어 있어야 합니다.
:::

:::caution
IP 목적지 주소도 Cloudflare WAN 구성에서 라우팅 가능해야 합니다. 해당 주소가 구성에서 사용 가능한지 확인하려면 Cloudflare 계정 팀에 문의하세요.
:::

풀은 Cloudflare 대시보드 또는 API를 통해 만들 수 있습니다. 자세한 내용은 [Create a pool](/load-balancing/pools/create-pool/#create-a-pool) 문서를 참고하세요.

## 2. 프라이빗 IP로 Account Load Balancer 생성

1. 계정 수준의 **Load Balancing**으로 이동하여 **Create a Load Balancer**를 선택합니다.
2. **Private Load Balancer**를 선택합니다.
3. 다음 단계에서 이 로드 밸런서를 다음 둘 중 하나와 연결할 수 있습니다.
 - Cloudflare 범위의 CGNAT IP
 - 사용자 지정 [RFC1918 address](https://datatracker.ietf.org/doc/html/rfc1918)
4. 로드 밸런서를 식별할 수 있는 설명적인 이름을 추가합니다.
5. 설정을 계속 진행합니다.

IP 주소를 선택하고 설정을 완료하면 Load Balancing 대시보드로 리디렉션됩니다. 검색창을 사용하거나 **Private** 로드 밸런서로 필터링해 로드 밸런서를 찾을 수 있습니다. 이후 단계에서 필요하므로 할당된 IP 주소를 반드시 기록해 두세요.

:::note
로드 밸런서에서 나가는 트래픽은 Cloudflare의 IP 주소 중 하나에서 시작하는 것처럼 보입니다. 정상적인 트래픽 흐름을 위해서는 이 IP 주소들을 허용 목록에 추가해야 합니다. 반환 트래픽이 퍼블릭 인터넷이 아니라 IPsec/GRE 터널로 돌아가도록 라우팅이 올바르게 구성되어 있는지 확인하세요. Cloudflare 프라이빗 IP 주소로 생성된 Private Load Balancer는 CGNAT 범위 `100.112.0.0`의 기본 주소를 받습니다. 이 IP 주소는 구성 가능합니다. 자세한 내용은 [Cloudflare source IP range](/cloudflare-wan/configuration/manually/how-to/configure-cloudflare-source-ips/)를 참고하세요.
:::

## 3. FQDN override(선택 사항)

로드 밸런서와 그 엔드포인트를 호스트명을 통해 사용자에게 투명하게 제공하고 싶다면, 내부 DNS 시스템에 DNS 레코드를 만들거나 Cloudflare에 override를 생성해 해당 호스트명을 Load Balancer의 IP 주소에 매핑할 수 있습니다. 이렇게 하면 해당 호스트명으로 향하는 트래픽이 올바른 IP로 해석됩니다.

override를 만들려면 다음 단계를 따르세요.

1. **Gateway**에서 **Firewall policies**를 선택합니다.
2. **DNS** 탭에서 다음과 같은 override를 생성합니다.
   - **Selector**는 `Host`
   - **Operator**는 `is`
   - **Value**는 로드 밸런서와 연결하려는 호스트명
3. **Action**을 _Override_로 설정하고, **Override Hostname**에 Private Load Balancer의 IP 주소를 입력합니다.

이제 해당 호스트명에 대한 요청은 프라이빗 로드 밸런서로 해석됩니다.

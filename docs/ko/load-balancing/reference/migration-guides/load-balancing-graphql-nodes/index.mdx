2021년 9월 30일 이후 Cloudflare는 Load Balancing GraphQL 스키마에 다음 변경 사항을 적용합니다.

* 사용 중단되는 노드:
  * `loadBalancingRequestsGroups`는 `loadBalancingRequestsAdaptiveGroups`로 대체되며 사용 중단됩니다.
  * `loadBalancingRequests`는 `loadBalancingRequestsAdaptive`로 대체되며 사용 중단됩니다.
* `date` 필드가 사용 중단됩니다(기존 `datetime` 필드로 대체).
* `sampleInterval` 필드가 추가됩니다.

## 예제 쿼리

다음 예제는 다음 내용을 보여 줍니다.

* `loadBalancingRequestsGroups`를 `loadBalancingRequestsAdaptiveGroups`로 교체합니다.
* `date`를 `datetime`으로 교체합니다.
* 새 `sampleInterval` 필드를 사용합니다.

```json
query {
  viewer {
    zones(filter: { zoneTag: "your Zone ID" }) {
      loadBalancingRequestsAdaptiveGroups(
        filter: {
          datetime_gt: "2021-06-12T04:00:00Z",
          datetime_lt: "2021-06-13T06:00:00Z"
        }
      ) {
        dimensions {
          datetime
          coloCode
          ...
        }
        avg {
          sampleInterval
        }
      }
    }
  }
}
```

Cloudflare의 Load Balancing Regions API는 다음과 같은 여러 용도로 사용할 수 있습니다.

- 특정 Cloudflare Load Balancer 지역에 어떤 국가/지역(미국과 캐나다의 경우 주/도)이 포함되는지 식별합니다.
- 특정 국가/지역(미국과 캐나다의 경우 주/도)에 대해 어떤 Cloudflare Load Balancer 지역이 적용되는지 식별합니다.

Region API는 국가/지역에 대해 2자리 [ISO-3166-1 alpha-2 코드](https://www.iso.org/iso-3166-country-codes.html)를 사용하며, 미국과 캐나다의 경우 주/도에 대해 ISO-3166-2 subdivision 코드를 사용합니다. 이러한 subdivision은 미국과 캐나다에만 제공됩니다.

Region API에는 두 가지 주요 선택적 파라미터가 있습니다.

- country_code는 ISO 3166-1 기준의 2자리 alpha-2 국가 코드 문자열입니다. 예: /load_balancers/regions?country_code=US
- subdivision_code는 미국과 캐나다에 대해 ISO 3166-2 기준의 2자리 subdivision 코드 문자열입니다. 예: /load_balancers/regions?subdivision_code=CA

Region Mapping API 사용에 대한 추가 세부 정보와 예시는 [Cloudflare API 문서](/api/resources/load_balancers/subresources/regions/methods/list/)를 참고하세요.

**풀에 모니터 연결**

모니터를 생성한 후에는 이를 풀에 연결해야 합니다.

1. **Load Balancing**으로 이동합니다.

2. **Pools** 탭을 선택합니다.

3. 특정 풀에서 **Edit**를 선택합니다.

4. 다음 정보를 업데이트합니다.
   - **Monitor**: 사용할 모니터를 선택합니다.
   - **Health Monitor Regions:** Cloudflare가 헬스 모니터 요청을 보내야 하는 지리적 리전을 지정합니다. [모니터가 풀 상태를 확인하는 방식](/load-balancing/monitors/#health-monitor-regions) 때문에 여러 리전을 선택하면 서버 부하가 증가할 수 있습니다.
   - **Notification E-mail:** 알림을 받을 이메일 주소를 포함합니다(개인 주소, 메일링 리스트 주소, PagerDuty 주소).

5. **Save**를 선택합니다. 첫 번째 검사 결과가 나올 때까지 헬스 모니터 상태는 _unknown_으로 표시됩니다.

## 모니터 수정

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 모니터를 수정하려면 다음과 같이 하세요.

1. **Load Balancing**으로 이동합니다.
2. **Monitors**를 선택합니다.
3. 특정 모니터에서 **Edit**를 선택합니다.
4. 필요한 대로 설정을 수정합니다.
5. **Save**를 선택합니다.

</TabItem> <TabItem label="API">

API로 모니터를 수정할 때는 얼마나 많이 수정하려는지에 따라 요청 유형이 달라집니다.

전체 구성을 다시 제출하지 않고 특정 설정만 업데이트하려면 [PATCH](/api/resources/load_balancers/subresources/monitors/methods/edit/) 요청을 사용하세요. 더 큰 변경에는 [PUT](/api/resources/load_balancers/subresources/monitors/methods/update/) 요청을 사용하세요.

</TabItem> </Tabs>

## 모니터 삭제

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 모니터를 삭제하려면 다음과 같이 하세요.

1. **Load Balancing**으로 이동합니다.
2. **Monitors** 탭을 선택합니다.
3. 특정 모니터에서 **Delete**를 선택합니다.

</TabItem> <TabItem label="API">

API를 사용해 모니터를 삭제하려면 [DELETE](/api/resources/load_balancers/subresources/monitors/methods/delete/) 요청을 보내세요.

</TabItem> </Tabs>

로드 밸런서로 요청이 들어오면, 다음 세 가지 요소에 따라 트래픽이 풀과 엔드포인트에 분산됩니다.

1. [Pool and endpoint health](/load-balancing/understand-basics/health-details/): 트래픽 결정은 어떤 풀과 엔드포인트가 사용 가능하고 트래픽을 받아야 하는지에서 시작됩니다.
2. [Global traffic steering](/load-balancing/understand-basics/traffic-steering/steering-policies/): [load balancer](/load-balancing/load-balancers/)에 설정하는 정책으로, 연결되어 있고 사용 가능한 풀로 트래픽을 라우팅합니다.
3. [Local traffic steering](/load-balancing/understand-basics/traffic-steering/origin-level-steering/): 각 [pool](/load-balancing/pools/)에 설정하는 정책으로, 풀 내부의 사용 가능한 엔드포인트로 트래픽을 라우팅합니다.

풀이나 엔드포인트가 비정상이 되면, 로드 밸런서와 풀은 동일한 정책에 따라 트래픽을 재분산합니다.

**Proximity steering**은 방문자 또는 내부 서비스를 가장 가까운 물리적 데이터 센터로 라우팅합니다.

로드 밸런서에서 proximity steering을 사용하려면 먼저 각 풀에 GPS 좌표를 추가해야 합니다.

## Proximity steering을 추가해야 하는 경우

* 새 풀의 경우, 풀을 만들 때 GPS 좌표를 추가합니다.
* 기존 풀의 경우, [풀을 관리](/load-balancing/pools/create-pool/#edit-a-pool)할 때 또는 [로드 밸런서를 생성](/load-balancing/load-balancers/create-load-balancer/)하는 과정의 **Add Traffic steering** 단계에서 GPS 좌표를 추가합니다.

## Proximity steering 추가 방법

풀을 생성하거나 편집할 때 좌표를 추가하려면:

1. *Configure coordinates for Proximity Steering* 드롭다운을 클릭합니다.
2. 위도와 경도를 입력하거나 지도에서 마커를 드래그합니다.
3. **Save**를 선택합니다.

:::caution[경고]

정확한 proximity steering을 위해서는 동일한 로드 밸런서 안의 모든 풀에 GPS 좌표를 추가하세요.

:::

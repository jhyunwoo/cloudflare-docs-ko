## EDNS Client Subnet (ECS) 지원

<GlossaryTooltip term="EDNS Client Subnet (ECS)"> EDNS Client Subnet (ECS) </GlossaryTooltip> 지원은 고객이 gray-cloud DNS 해석 중 위치 기반 스티어링을 더 세밀하게 제어할 수 있게 해 주며, 근접 또는 Geo(국가) 스티어링에 사용할 수 있습니다.

고객은 `prefer_ecs`와 `mode` 속성을 포함하는 `location_strategy` 파라미터를 사용해 로드 밸런서를 구성할 수 있습니다.

`prefer_ecs`는 ECS 지리적 위치를 권위 있는 위치로 우선할지 여부를 결정합니다.

| 유형 | 설명 |
| ---- | ---- |
| `"always"` | 항상 ECS를 우선합니다. |
| `"never"` | ECS를 우선하지 않습니다. |
| `"proximity"` | `steering_policy="proximity"`일 때만 ECS를 우선합니다. |
| `"geo"` | `steering_policy="geo"`일 때만 ECS를 우선하며, 국가 수준 스티어링만 지원합니다. |

`mode`는 ECS가 우선되지 않거나, 요청에 존재하지 않거나, 지리적 위치 조회에 실패했을 때 어떤 위치를 권위 있는 위치로 사용할지 결정합니다.

| 유형 | 설명 |
| ---- | ---- |
| `"pop"` | Cloudflare PoP 위치를 사용합니다. |
| `"resolver_ip"` | DNS 리졸버의 지리적 위치 데이터를 사용합니다. 지리적 위치 조회에 실패하면 Cloudflare PoP 위치를 사용합니다. |

:::note

ECS 지원은 DNS-only 로드 밸런서에 적용됩니다.

:::

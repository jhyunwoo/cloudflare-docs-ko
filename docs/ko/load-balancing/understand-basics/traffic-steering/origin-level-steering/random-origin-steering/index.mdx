**Random steering**은 [엔드포인트 가중치](/load-balancing/understand-basics/traffic-steering/origin-level-steering/#weights)만을 기준으로 요청을 엔드포인트에 보냅니다. 트래픽을 더 정확하게 분산하지만, 같은 IP에서 온 요청이 서로 다른 엔드포인트에 도달할 수 있습니다.

적응형 라우팅은 활성 상태 모니터링 요청 사이의 간격처럼 동적인 조건에 대응해 요청이 풀과 엔드포인트로 라우팅되는 방식을 수정하는 기능을 제어합니다. <Render file="zero-downtime-failover-retry-on-error" product="fundamentals" />

## 풀 간 장애 조치

같은 풀 안에 정상 엔드포인트가 없을 때, 풀 간 장애 조치는 트래픽 스티어링과 엔드포인트 스티어링에서 정의한 장애 조치 순서에 따라 대체 풀의 정상 엔드포인트로 요청을 보내는 무중단 장애 조치를 확장합니다.

### 풀 간 장애 조치 활성화

1. Cloudflare 대시보드에서 **Load Balancing** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/load-balancing" />

2. **Load Balancers**로 이동한 다음 **Edit**를 선택합니다.
3. **Adaptive Routing**에서 **Failover across pools**를 활성화합니다.

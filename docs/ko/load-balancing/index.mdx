Cloudflare Load Balancing은 <GlossaryTooltip term="endpoint" link="/glossary/?term=endpoint">엔드포인트</GlossaryTooltip> 전반에 트래픽을 분산하여 엔드포인트 부담과 지연 시간을 줄이고 최종 사용자 경험을 개선합니다.

## 기능

<Feature header="로드 밸런싱과 장애 조치" href="/load-balancing/load-balancers/">

정상적인 엔드포인트 전반에 트래픽을 고르게 분산하고, 엔드포인트가 비정상이거나 응답하지 않을 때 자동으로 장애 조치를 수행합니다.


</Feature>

<Feature header="능동 모니터링" href="/load-balancing/monitors/">

구성 가능한 간격과 여러 데이터 센터에서 엔드포인트를 모니터링하여 특정 상태 코드, 응답 텍스트, 타임아웃을 확인합니다.


</Feature>

<Feature header="지능형 라우팅" href="/load-balancing/understand-basics/traffic-steering/">

엔드포인트 지연 시간, 방문자의 지리적 지역, 심지어 방문자의 GPS 좌표를 기준으로 요청을 분산할지 선택할 수 있습니다.


</Feature>

<Feature header="사용자 지정 규칙" href="/load-balancing/additional-options/load-balancing-rules/">

개별 요청의 특성에 따라 로드 밸런서 동작을 사용자 지정합니다.


</Feature>

<Feature header="분석" href="/load-balancing/reference/load-balancing-analytics/">

종합 분석을 검토하여 트래픽 흐름을 평가하고, 엔드포인트 상태를 점검하며, 시간에 따른 풀과 풀 상태 변화를 확인할 수 있습니다.


</Feature>

## 관련 제품

<RelatedProduct header="Standalone Health Checks" href="/health-checks/" product="health-checks">

</RelatedProduct>

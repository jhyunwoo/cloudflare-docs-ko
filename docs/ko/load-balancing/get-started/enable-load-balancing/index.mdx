Load balancing은 계정용 추가 기능이므로 계정에 [billing profile](/billing/create-billing-profile/)이 필요합니다.

[Load Balancing](https://dash.cloudflare.com/?to=/:account/:zone/traffic/load-balancing/)을 활성화하려면 다음 단계를 따르세요.

1. Cloudflare 대시보드에서 **Load Balancing** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/load-balancing" />

2. **Status** 열에서 **Enable Load Balancing**을 선택합니다.
3. 요금제 옵션을 선택하고 결제를 확인합니다.

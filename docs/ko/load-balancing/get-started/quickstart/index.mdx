## 시작하기 전에

다음 사항을 확인하세요.

- 물리 장비 또는 클라우드 기반의 여러 <GlossaryTooltip term="endpoint">엔드포인트</GlossaryTooltip>(오리진 서버, 사설 또는 공용 IP 주소, 가상 IP 주소(VIP) 등)에 접근할 수 있어야 합니다.
- 모든 유형의 계정에서 [추가 기능](/load-balancing/get-started/enable-load-balancing/)으로 제공되는 Load Balancing을 사용할 수 있어야 합니다.
- 테스트 및 운영 호스트명이 [SSL/TLS 인증서](/load-balancing/load-balancers/dns-records/#ssltls-coverage) 범위 안에 있어야 합니다.

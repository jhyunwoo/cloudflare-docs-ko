## 2025-04-15

**오렌지 클라우드 오리진 해석 지원 도입**

새로 생성되는 Cloudflare Load Balancers는 오리진이 동일한 계정과 zone에 속해 있는 경우 오렌지 클라우드 오리진 주소를 해석합니다. 기존 Load Balancers는 계속 현재 해석 방식을 사용합니다. 소유권 검증에 실패하면 새 시스템은 기존 동작으로 폴백하고, 일반적으로 anycast 주소로 해석되는 회색 클라우드(DNS-only) 조회를 기본값으로 사용합니다.

## 2025-03-13

**Load Balancing 분석 업데이트**

인프라 개선에 따라 일부 고객의 분석에서 Load Balancing 요청률이 감소할 수 있습니다. 이 감소는 수신된 HTTP 요청 감소를 의미하지 않습니다.

## 2025-02-20

**Load Balancing API 응답에 zone 이름 추가**

이제 Load Balancing API 응답에 `zone_name` 속성이 포함되어 응답 데이터 안에서 zone 이름을 제공합니다.

## 2025-02-10

**Cloudflare Tunnel 일관성 수정**

Cloudflare Load Balancers 내부에서 Cloudflare Tunnel 처리 일관성을 개선하는 수정이 적용되었습니다. 특히 터널이 포함된 경우 더 안정적이고 예측 가능한 라우팅을 보장합니다.

## 2025-01-24

**Cloudflare Tunnel Steering 업데이트**

동일한 zone에서 Cloudflare Tunnels를 백엔드로 사용하는 프록시 도메인의 해석 방식이 변경되었습니다. 이 변경으로 Cloudflare Load Balancers를 통해 오렌지 클라우드 레코드가 Cloudflare Tunnels로 steer되는 방식이 수정되었습니다.

## 2025-01-16

**풀 상태 모니터링 업데이트**

풀 상태를 평가하기 위해 프록시된 오리진을 해석하고 모니터링하는 방식이 변경되었습니다. 분석 결과 고객 구성이나 운영에는 영향이 없는 것으로 나타났습니다. 예상치 못한 동작이 보이면 고객 지원팀에 문의하세요.

## 2024-12-20

**China Network에서의 Load Balancing**

이제 로드 밸런서를 [China Network](/china-network/)에 배포하도록 활성화할 수 있습니다. 자세한 내용은 [문서](/load-balancing/additional-options/load-balancing-china/)를 참고하세요.

## 풀 수정

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 풀을 수정하려면 다음과 같이 하세요.

1. **Load Balancing**으로 이동합니다.
2. **Pools** 탭을 선택합니다.
3. 특정 풀에서 **Edit**를 선택합니다.
4. 필요한 대로 설정을 수정합니다.
5. **Save**를 선택합니다.

</TabItem> <TabItem label="API">

API로 풀을 수정할 때는 얼마나 많이 수정하려는지에 따라 요청 유형이 달라집니다.

전체 구성을 다시 제출하지 않고 특정 설정만 업데이트하려면 [PATCH](/api/resources/load_balancers/subresources/pools/methods/edit/) 요청을 사용하세요. 더 광범위한 변경에는 [PUT](/api/resources/load_balancers/subresources/pools/methods/update/) 요청을 사용하세요.

</TabItem> </Tabs>

---

## 풀 삭제

로드 밸런서에서 사용 중인 풀은 삭제할 수 없습니다. 여기에는 [geo steering regions](/load-balancing/understand-basics/traffic-steering/steering-policies/geo-steering/#region-steering) 풀과 [fallback pools](/load-balancing/understand-basics/health-details/#fallback-pools)도 포함됩니다.

풀을 삭제하려 할 때 오류가 발생하면, 오류에 표시된 호스트명을 확인하고 [해당 로드 밸런서를 수정](/load-balancing/load-balancers/create-load-balancer/)하여 풀에 대한 참조를 모두 제거했는지 확인하세요.

:::note

풀이 geo steering에 의해 참조되고 있는 경우, **Traffic Steering** 방법을 다른 것으로 바꾸어도 해당 구성은 자동으로 제거되지 않습니다. 확실히 제거하려면 **Geo Steering**을 선택하고, 풀을 제거한 뒤, 그다음 필요한 다른 변경 사항을 적용하고 저장하세요.
:::

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 풀을 삭제하려면 다음과 같이 하세요.

1. **Load Balancing**으로 이동합니다.
2. **Pools** 탭을 선택합니다.
3. 특정 풀에서 **Delete**를 선택합니다.

</TabItem> <TabItem label="API">

API를 사용해 풀을 삭제하려면 [DELETE](/api/resources/load_balancers/subresources/pools/methods/delete/) 요청을 보내세요.

</TabItem> </Tabs>

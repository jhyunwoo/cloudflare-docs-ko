### 다른 사이트와 로드 밸런서 공유

계정 내 다른 사이트와 로드 밸런서를 공유하려면 [canonical name(`CNAME`) 레코드](/dns/manage-dns-records/how-to/create-dns-records/)를 생성하면 됩니다. 이렇게 하면 여러 다른 도메인에서 동일한 구성을 공유할 수 있으므로 사이트마다 새 로드 밸런서를 만들 필요가 없습니다.

도메인별로 별도의 로드 밸런서를 구성하면서 모니터와 풀을 재사용할 수도 있습니다. 예를 들어 `example.co.uk` 서버의 페일오버 우선순위가 `example.com` 또는 `example.com.au`와 다를 때 특히 유용합니다.

:::note

사이트 간 로드 밸런서 공유는 대상 zone이 [full DNS setup](/dns/zone-setups/full-setup/)인 경우에만 지원됩니다. 대상 zone이 `CNAME` setup인 경우에는 지원되지 않습니다.

:::

## 로드 밸런서 수정

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 로드 밸런서를 수정하려면 다음과 같이 하세요.

1. **Load Balancing**으로 이동합니다.
2. 특정 로드 밸런서에서 **Edit**를 선택합니다.
3. [생성 워크플로우](#create-a-load-balancer)를 따라가면서 필요한 설정을 수정합니다.
4. **Review** 단계에서 **Save**를 선택합니다.

</TabItem> <TabItem label="API">

API로 로드 밸런서를 수정할 때는 얼마나 많이 바꾸려는지에 따라 요청 유형이 달라집니다.

전체 구성을 다시 제출하지 않고 특정 설정만 업데이트하려면 [PATCH](/api/resources/load_balancers/methods/edit/) 요청을 사용하세요. 더 광범위한 변경에는 [PUT](/api/resources/load_balancers/methods/update/) 요청을 사용하세요.

</TabItem> </Tabs>

---

## 로드 밸런서 삭제

로드 밸런서를 삭제하거나 비활성화하면, 요청에 대한 엔드포인트 응답은 [기존 DNS 레코드](/load-balancing/load-balancers/dns-records/#disabling-a-load-balancer)에 따라 달라집니다.

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 로드 밸런서를 삭제하려면 다음과 같이 하세요.

1. **Load Balancing**으로 이동합니다.
2. 특정 로드 밸런서에서 **Delete**를 클릭합니다.

</TabItem> <TabItem label="API">

API로 로드 밸런서를 삭제하려면 [DELETE](/api/resources/load_balancers/methods/delete/) 요청을 보내세요.

</TabItem> </Tabs>

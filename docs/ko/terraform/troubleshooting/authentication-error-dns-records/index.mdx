Terraform을 사용하여 DNS 레코드를 만들 때 API는 다음 오류를 반환합니다.

`Error: failed to create DNS record: HTTP status 403: Authentication error (10000)`

이것은 코드 구문에 오류에 의해 발생, 당신이 인덱스를 사용하지 않는 경우`[0]`지역을 위해. 아래 예제와 더 상세한 스레드를 찾아보세요.[프로젝트](https://github.com/cloudflare/terraform-provider-cloudflare/issues/913).

이 대신:

```txt
zone_id = data.cloudflare_zones.example_com.id
```

사용 :

```txt "zones[0]"
zone_id = data.cloudflare_zones.example_com.zones[0].id`
```

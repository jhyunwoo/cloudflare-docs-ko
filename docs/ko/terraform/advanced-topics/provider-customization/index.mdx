Terraform은 공급자로 알려진 모듈을 통해 CloudflareXQ와 같은 클라우드 및 글로벌 네트워크 제공 업체 API와 통신합니다. 이 공급자는[자동 설치](/terraform/tutorial/initialize-terraform/#2-initialize-terraform-and-the-cloudflare-provider)실행할 때`terraform init`디렉토리에`.tf`공급자를 포함하는 파일.

일반적으로 공급자에게만 필요한 매개 변수는 인증해야 합니다. 그러나, 당신은 당신의 필요에 공급자를 주문을 받아서 만들 수 있습니다. 뒤에 오는 단면도는 몇몇을 포함합니다[옵션 설정](https://www.terraform.io/docs/providers/cloudflare/#argument-reference)Cloudflare Terraform 공급자에게 전달할 수 있습니다.

## 기본 Cloudflare 공급자 조정

:::참조

아래 예제에서 빌드[모델 번호: Cloudflare Terraform 튜토리얼](/terraform/tutorial/).
:::

구성 매개 변수를 사용하여 Cloudflare Terraform 공급자를 사용자 정의 할 수 있습니다.`.tf`구성 파일 또는 환경 변수를 통해. 환경 변수를 사용하여 CI/CD 시스템에서 Terraform을 실행할 때 감각을 만들거나 변경이 일시적이거나 구성 역사에서 지속될 필요가 없습니다.

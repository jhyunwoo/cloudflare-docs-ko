## 1. 인증 환경 변수 사용

버전 컨트롤에 커밋하기 전에 Terraform 파일에서 자격 증명을 제거하십시오. Cloudflare 공급자 v5는 환경변수를 자동적으로 읽습니다.
업데이트`main.tf`hardcoded API 토큰을 제거하는 파일 :

```hcl
terraform {
  required_providers {
    cloudflare = {
      source  = "cloudflare/cloudflare"
      version = "~> 5"
    }
  }
}

provider "cloudflare" {
  # API token will be read from CLOUDFLARE_API_TOKEN environment variable
}

variable "zone_id" {
  description = "Cloudflare Zone ID"
  type        = string
  sensitive   = true
}

variable "account_id" {
  description = "Cloudflare Account ID"
  type        = string
  sensitive   = true
}

variable "domain" {
  description = "Domain name"
  type        = string
  default     = "example.com"
}

resource "cloudflare_dns_record" "www" {
  zone_id = var.zone_id
  name    = "www"
  content = "203.0.113.10"
  type    = "A"
  ttl     = 1
  proxied = true
  comment = "Domain verification record"
}
```

:::참조
당신은 여전히 파일에 빈 공급자 정의를 포함해야합니다, 그래서 Terraform은 Cloudflare 플러그인을 설치 알고. 고급 옵션에 대한 자세한 내용은 Cloudflare 공급자를 사용자 정의 할 수 있습니다, 참조[공급자 주문](/terraform/advanced-topics/provider-customization/).
:::

업데이트`terraform.tfvars`파일 :

```hcl
zone_id    = "your-zone-id-here"
account_id = "your-account-id-here"
domain     = "your-domain.com"
```

API 토큰은 환경 변수로 설정됩니다:

```sh
export CLOUDFLARE_API_TOKEN="your-api-token-here"
```

인증 작업을 검증:

```sh
terraform plan
```

Terraform이 기존 리소스로 새로운 변수 기반 구성을 비교하여 변경할 수 있습니다. 이것은 hardcoded 값에서 변수로 마이그레이션 할 때 정상입니다:

```sh output
#cloudflare dns record.www가 업데이트됩니다
~ resource "cloudflare_dns_record" "www" {
    ~ name     = "www.your-domain.com" -> "www"
    ~ zone_id  = (sensitive value)
    #(다른 속성은 변경 사항을 표시 할 수 있습니다)
}

Plan: 0 to add, 1 to change, 0 to destroy.
```

## 2. GitHub의 스토어 구성

이름 \*`.gitignore`이 내용의 파일 :

```text
.terraform/
*.tfstate*
.terraform.lock.hcl
terraform.tfvars
```

Git를 초기화하고 구성을 커밋:

```sh
git init
git add main.tf .gitignore
git commit -m "Step 2 - Initial Terraform v5 configuration"
```

GitHub 저장소 만들기 (웹 인터페이스 또는 GitHub CLI를 통해) 및 푸시:

```sh
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/cf-config.git
git push -u origin main
```

Terraform 구성은 이제 버전 제어 및 팀 협업을 준비합니다. 민감한 데이터 (API 토큰, Zone ID)는 보안을 유지하고 코드를 분리합니다.

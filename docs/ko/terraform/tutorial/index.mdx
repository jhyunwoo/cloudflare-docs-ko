시작하기 전에[Terraform 설치](/terraform/installing/). 각 튜토리얼은 이전의 빌드, 그래서 아래의 순서에서 튜토리얼을 완료해야합니다.

:::참조
v4에서 업그레이드하는 경우, 리뷰[본문 바로가기](https://github.com/cloudflare/terraform-provider-cloudflare/blob/main/docs/guides/version-5-upgrade.md)끊는 변화를 위해.
주요 특징

## [1 – Terraform의 초기화](/terraform/tutorial/initialize-terraform/)

- 짧은 소개.
- 회사연혁`terraform init`, `plan`, `apply`·`show`.
- 관련 자료:[`cloudflare_dns_record`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/dns_record)(DNS 기록).

## [2 – 역사를 추적](/terraform/tutorial/track-history/)

- 소스 컨트롤에 Cloudflare 구성 저장.

## [3 – HTTPS 설정 구성](/terraform/tutorial/configure-https-settings/)

- 영역 설정 수정.
- 관련 자료:[`cloudflare_zone_setting`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zone_setting).

## [4 – 성능과 신뢰성 향상](/terraform/tutorial/use-load-balancing/)

- 로드 밸런싱 규칙 추가.
- 태그 :
  - [`cloudflare_load_balancer`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/load_balancer)
  - [`cloudflare_load_balancer_pool`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/load_balancer_pool)
  - [`cloudflare_load_balancer_monitor`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/load_balancer_monitor)

## [5 – 페이지 규칙과 예외 추가](/terraform/tutorial/add-page-rules/)

- 페이지 규칙을 추가하십시오.
- 관련 자료:[`cloudflare_page_rule`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/page_rule).
- 특정 URL의 보안 수준을 증가:`/expensive-db-call`.
- 리디렉션 추가 (URL forward) 와 함께`301`상태 코드에서`/old-location.php`으로`/expensive-db-call`.

## [6 - Revert 구성](/terraform/tutorial/revert-configuration/)

- 리뷰 변경 내역.
- 롤백 변경.

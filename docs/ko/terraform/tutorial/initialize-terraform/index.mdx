이 튜토리얼은 Terraform과 시작하기에 대한 방법을 보여줍니다. 당신은 단지 당신의 도메인에 가입 (`example.com`) Cloudflare에 Terraform에서 모든 것을 관리하고 지금 당신은 DNS 기록 지적을 창조할 것입니다`www.example.com`웹 서버로`203.0.113.10`.

시작하기 전에, 당신은 가지고:

- [설치 Terraform](/terraform/installing/)
- [API 토큰 생성](/fundamentals/api/get-started/create-token/)이 튜토리얼에 대한 리소스를 편집 할 수있는 권한

## 1. 구성 만들기

파일 생성`main.tf`, 당신의 자신의 가치를 채우기[API 토큰](/fundamentals/api/get-started/create-token/), [지역 ID](/fundamentals/account/find-account-and-zone-ids/), [계정 ID](/fundamentals/account/find-account-and-zone-ids/)·[이름 \*](/fundamentals/manage-domains/add-site/):

```bash
terraform {
  required_providers {
    cloudflare = {
      source  = "cloudflare/cloudflare"
      version = "~> 5"
    }
  }
}

provider "cloudflare" {
  api_token = "<YOUR_API_TOKEN>"
}

variable "zone_id" {
  default = "<YOUR_ZONE_ID>"
}

variable "account_id" {
  default = "<YOUR_ACCOUNT_ID>"
}

variable "domain" {
  default = "<YOUR_DOMAIN>"
}

resource "cloudflare_dns_record" "www" {
  zone_id = "<YOUR_ZONE_ID>"
  name    = "www"
  content = "203.0.113.10"
  type    = "A"
  ttl     = 1
  proxied = true
  comment = "Domain verification record"
}
```

:::카트로션

사고로 Cloudflare 자격 증명을 만료하려면 버전 제어 시스템에이 파일을 저장하지 마십시오. 더 보기[다음 튜토리얼](/terraform/tutorial/track-history/)API 토큰을 전달하기위한 모범 사례를 다룹니다.

## 2. 초기화 및 계획

Cloudflare 공급자를 다운로드하는 Terraform를 초기화하십시오:

```sh
terraform init
```

작성된 내용을 검토:

```sh
terraform plan
```

Terraform은 하나의 바이너리 파일로 발송합니다. 아래 예제는 인기있는 운영 체제에 대한 설치 정보를 포함한다.

Terraform 설치에 대한 공식 지침은 참조[Terraform 설치](https://developer.hashicorp.com/terraform/tutorials/certification-associate-tutorials/install-cli).

:::카트로션

Terraform은 Terraform과 QXQX0001XQ Dashboard 또는 API를 통해 구성 변경 사항을 만들 때 깨질 수있는 구성 상태를 유지합니다.

이 상태를 피하기 위해 Terraform 리소스를 Terraform에서만 관리하십시오. 더 자세한 내용은, 참조[좋은 관행](/terraform/advanced-topics/best-practices/).

:::

## 한국어

macOS의 Terraform을 설치하는 가장 쉬운 방법은 Homebrew와 같습니다.

```sh
brew tap hashicorp/tap
brew install hashicorp/tap/terraform
```

## 리눅스

당신은 설치할 수 있습니다`terraform`배포의 패키지 관리자를 통해 바이너리. 예를 들면:

```sh
sudo apt install terraform
```

대안으로, 당신은 특정 버전을 직접 fetch하고 당신의 바이너리를 배치 할 수`PATH`:

```sh
wget -q https://releases.hashicorp.com/terraform/1.4.5/terraform_1.4.5_linux_amd64.zip

unzip terraform_1.4.5_linux_amd64.zip
```

```sh output
Archive:  terraform_1.4.5_linux_amd64.zip
  inflating: terraform
```

```sh
sudo mv terraform /usr/local/bin/terraform

terraform version
```

```sh output
Terraform v1.4.5
```

## 영역에 사용자 정의 규칙을 추가

다음 예제는 영역 항목 점 규칙에 정의 규칙을 구성`http_request_firewall_custom`ID를 가진 지역을 위한 단계`<ZONE_ID>`. 규칙은 비표준 HTTP (S) 포트에 모든 트래픽을 차단합니다:

<Render file="v4-code-snippets" product="terraform" />

```tf
resource "cloudflare_ruleset" "zone_custom_firewall" {
  zone_id     = "<ZONE_ID>"
  name        = "Phase entry point ruleset for custom rules in my zone"
  description = ""
  kind        = "zone"
  phase       = "http_request_firewall_custom"

  rules {
    ref         = "block_non_default_ports"
    description = "Block ports other than 80 and 443"
    expression  = "(not cf.edge.server_port in {80 443})"
    action      = "block"
  }
}
```

## 사용자 정의 규칙 작성 및 배포

:::참조
모든 고객은 사용자 정의 규칙을 만들 수 있습니다[지역 수준](/waf/custom-rules/custom-rulesets/).<br />주문 규칙[계정 수준](/waf/account/custom-rulesets/)유료 애드온과 엔터프라이즈 플랜이 필요합니다.
주요 특징

다음 예제는[주문 규칙](/ruleset-engine/custom-rulesets/)ID로 계정에서`<ACCOUNT_ID>`단일 사용자 정의 규칙을 포함. 이 사용자 정의 규칙은 다음 분리를 사용하여 배치됩니다.`cloudflare_ruleset`Terraform 자원. 사용자 정의 규칙을 배포하지 않으면 실행되지 않습니다.

다음 구성은 단일 규칙과 사용자 정의 규칙을 만듭니다.

<Render file="v4-code-snippets" product="terraform" />

```tf
resource "cloudflare_ruleset" "account_firewall_custom_ruleset" {
  account_id  = "<ACCOUNT_ID>"
  name        = "Custom ruleset blocking traffic in non-standard HTTP(S) ports"
  description = ""
  kind        = "custom"
  phase       = "http_request_firewall_custom"

  rules {
    ref         = "block_non_default_ports"
    description = "Block ports other than 80 and 443"
    expression  = "(not cf.edge.server_port in {80 443})"
    action      = "block"
  }
}
```

<Render file="add-new-rule" product="terraform" params={{ ruleType: "custom rule in the custom ruleset" }} />

<br />

다음 구성은 계정 수준에서 사용자 정의 규칙을 배치합니다. 그것은에 의존성을 정의`account_firewall_custom_ruleset`리소스 및 생성 된 사용자 정의 규칙의 ID를 사용합니다.`action_parameters`:

<Render file="v4-code-snippets" product="terraform" />

```tf
resource "cloudflare_ruleset" "account_firewall_custom_entrypoint" {
  account_id  = "<ACCOUNT_ID>"
  name        = "Account-level entry point ruleset for the http_request_firewall_custom phase deploying a custom ruleset"
  description = ""
  kind        = "root"
  phase       = "http_request_firewall_custom"

  depends_on = [cloudflare_ruleset.account_firewall_custom_ruleset]

  rules {
    ref         = "deploy_custom_ruleset_example_com"
    description = "Deploy custom ruleset for example.com"
    expression  = "(cf.zone.name eq \"example.com\") and (cf.zone.plan eq \"ENT\")"
    action      = "execute"
    action_parameters {
      id = cloudflare_ruleset.account_firewall_custom_ruleset.id
    }
  }
}
```

구성 및 배포에 대한 자세한 내용은 사용자 정의 규칙을 참조하시기 바랍니다[주문 규칙 작업](/ruleset-engine/custom-rulesets/)Ruleset Engine 문서에서.

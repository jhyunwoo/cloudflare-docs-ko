전 세계에 분산된 데이터 센터를 통해 Cloudflare는 최종 사용자에게 매우 가까운 곳에서 콘텐츠를 캐시합니다. 하지만 어떤 콘텐츠가 캐시에 없으면 Cloudflare 데이터 센터는 캐시 가능한 콘텐츠를 받기 위해 origin 서버에 연결해야 합니다. Tiered cache는 Cloudflare 데이터 센터를 lower-tier와 upper-tier의 계층 구조로 나누어 동작하며, upper-tier만 origin에 콘텐츠를 요청할 수 있습니다.

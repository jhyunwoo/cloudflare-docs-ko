## 데이터 삭제

Cache Reserve에 저장된 모든 데이터를 제거할 수 있습니다. 대부분의 경우 삭제가 완료되기까지 약 24시간이 걸립니다.

1. Smart Shield 구성에서 Cache Reserve 옆의 점 세 개를 선택합니다.
2. **View details**를 선택해 Cache Reserve 사이드바를 엽니다.
3. Cache Reserve를 일시 중지했는지 확인합니다.
4. **Delete data**를 선택한 다음 **Save**를 선택합니다.
5. 확인 대화상자에서 다시 **Delete**를 선택합니다.

:::note
대신 캐시를 purge하려면 [cache 구성](/cache/how-to/purge-cache/)을 참고하세요.
:::

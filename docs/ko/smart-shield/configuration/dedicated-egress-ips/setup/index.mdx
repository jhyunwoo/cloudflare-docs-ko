[Edit Zone Settings API endpoint](/api/resources/zones/subresources/settings/methods/edit/)를 사용해 Dedicated CDN Egress IPs(이전 명칭 Aegis)를 설정할 수 있습니다. Cloudflare API 작동 방식이 익숙하지 않다면 [Fundamentals](/fundamentals/api/)를 참고하세요.

:::note[Enterprise 전용]
Dedicated CDN Egress IPs(DCEI)는 현재 Enterprise 고객에게 제공됩니다. 접근 권한을 요청하려면 담당 account 팀에 문의하세요.
:::

## 요구 사항

- Dedicated CDN Egress IPs(DCEI) zone 설정은 임대 IP를 소유한 Cloudflare account 또는 [BYOIP prefix](/byoip/)가 위임된 account에서만 사용할 수 있습니다. 이 기준을 충족하지 않는 zone에 Dedicated CDN Egress IP를 사용하려면 담당 account 팀에 문의하세요.
- <Render file="dcei-pool-requirements" product="smart-shield" />

:::caution
이 풀을 zone에 연결하기 전에 반드시 인프라에서 해당 풀의 IP 주소를 allowlist에 추가해야 합니다. 이 단계를 건너뛰면 트래픽이 origin에 도달하지 못해 오류가 발생합니다.
:::

## zone에서 DCEI 켜기

1. 담당 account 팀에 연락하여 전용 egress pool의 ID를 받습니다.
2. [Edit Zone Setting](/api/resources/zones/subresources/settings/methods/edit/) endpoint에 `PATCH` 요청을 보냅니다.

- URL에서 setting ID로 `aegis`를 지정합니다.
- 요청 본문에서 `enabled`를 `true`로 설정하고, 이전 단계에서 받은 ID를 `pool_id` 값으로 사용합니다.

<APIRequest
	path="/zones/{zone_id}/settings/{setting_id}"
	method="PATCH"
	json={{
		id: "aegis",
		value: {
			enabled: true,
			pool_id: "<EGRESS_POOL_ID>",
		},
	}}
	parameters={{
		setting_id: "aegis",
	}}
/>

## zone의 DCEI 상태 확인

<APIRequest
	path="/zones/{zone_id}/settings/{setting_id}"
	method="GET"
	parameters={{
		setting_id: "aegis",
	}}
/>

## zone에서 DCEI 끄기

<APIRequest
	path="/zones/{zone_id}/settings/{setting_id}"
	method="PATCH"
	json={{
		id: "aegis",
		value: {
			enabled: false,
		},
	}}
	parameters={{
		setting_id: "aegis",
	}}
/>

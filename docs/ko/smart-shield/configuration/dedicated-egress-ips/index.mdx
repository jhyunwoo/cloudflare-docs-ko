Enterprise 고객은 layer 7 [WAF](/waf/) 및 <GlossaryTooltip term="content delivery network (CDN)">CDN</GlossaryTooltip> 서비스, 그리고 [Spectrum](/spectrum/)에 대해 전용 egress[^1] IP를 활용할 수 있습니다. egress IP는 귀하의 account 전용으로 예약되므로, 소수의 IP 주소 목록에서 오는 트래픽만 허용해 origin 보안을 강화할 수 있습니다.

:::note
Dedicated CDN Egress IPs와 함께 Smart Shield Advanced를 사용하고 싶다면 담당 account 팀에 문의하세요.
:::

Dedicated CDN Egress IPs는 이전에 Cloudflare Aegis로 알려졌습니다([출시 블로그 게시물](https://blog.cloudflare.com/cloudflare-aegis/)).

## 이점

Dedicated CDN Egress IPs를 사용하면 다음이 가능합니다.

* 네트워크 방화벽을 잠가 전용 IP에서 오는 트래픽만 허용할 수 있습니다.
* [Cloudflare Access 및 CNI](/smart-shield/configuration/dedicated-egress-ips/other-products/#access-and-cni)를 사용해 서버에 소프트웨어를 설치하거나 코드를 수정하지 않고도 애플리케이션을 보호할 수 있습니다.
* 허가된 [Workers](/smart-shield/configuration/dedicated-egress-ips/other-products/#workers)만 origin 서비스에 접근하도록 보장할 수 있습니다.

## 범위

Dedicated CDN Egress IP는 단일 또는 여러 Cloudflare zone에, 그리고 서로 다른 Cloudflare account 전반에 걸쳐 할당할 수 있습니다.

Dedicated CDN Egress IP는 [CNI를 통한 BGP advertisement](/network-interconnect/)에 포함됩니다.

[회전성](/turnstile/)'Cloudflare'의 CAPTCHA-alternative 솔루션입니다. 웹 사이트 또는 응용 프로그램에 위젯으로 Turnstile을 삽입 할 수 있습니다. 방문자의 브라우저의 배경에서 클라이언트 측 도전을 직접 실행합니다.

Turnstile는 챌린지 Pages와 다른 점은 요청을 일시 중지하거나 사용자의 경험을 중단하지 않습니다. 위젯이 웹 페이지에 내장되어 있기 때문에 HTML의 특정 부분에만 실행되므로 방문자는 대상 URL에 도착하고 Turnstile 위젯을 만날 때 페이지를 볼 수 있습니다. 전체 웹 사이트에 액세스하여 방문자를 차단하는 대신, Turnstile 위젯은 로그인을 완료하거나 양식을 등록, 위젯이 해결 될 때까지 방문자를 방지합니다.

대부분의 경우 방문자에서 더 이상 필요하지 않습니다. 그러나 필요한 경우, Turnstile은 방문자가 진행을 클릭해야하는 간단한 체크 박스를 표시 할 수 있습니다.

챌린지 패스가 끝난 후, Turnstile는 통관 토큰을 통해 검증되어야 합니다.[Siteverify API를](/turnstile/get-started/server-side-validation/)로그인, 가입, 또는 다른 양식 제출과 같은 민감한 작업을 완료하기 전에.

## Widget 유형

웹 사이트 또는 응용 프로그램에 구현 할 수있는 위젯의 세 가지 유형이 있지만, 그 뒤에 도전 논리는 동일합니다.

- **관리 (추천)**: Managed Challenge Page와 유사한 기능. 그것은 방문자의 브라우저에서 수집 된 신호를 기반으로 한 도전을 선택하고 잠재적으로 자동화 된 트래픽을 감지하면 상호 작용을 나타냅니다.

- **비동기**: 위젯은 표시되지만 방문자는 정체성을 확인하기 위해 상호 작용할 필요가 없습니다.

- **옵션 정보**: 위젯은 방문자에 완전히 보이지 않지만 여전히 배경에서 실행됩니다.

## - 연혁

'Cloudflare' 대시보드를 통해 웹 사이트 또는 응용 프로그램에 대한 위젯을 만들면 사이트키를 받게됩니다.

사이트키는 사용[고객 측 렌더링](/turnstile/get-started/client-side-rendering/#implicitly-render-the-turnstile-widget)그것을 추가하여`<div>`콘테이너 placeholder. 그런 다음`<div>`사이트 페이지 또는 양식에 위젯을 추가하려는 코드 snippet.

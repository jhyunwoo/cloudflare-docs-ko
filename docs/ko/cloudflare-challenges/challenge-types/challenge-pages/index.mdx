인터랙티브 챌린지 페이지는 방문자와 웹 사이트 또는 애플리케이션 사이의 게이트 역할을 합니다.

챌린지 페이지는 요청을 들고 자동화된 신호를 위한 브라우저 환경을 평가하고, 챌린지 URL을 통해 방문자를 방해합니다. 방문자는 도전을 통과하지 않고 목적지에 도달 할 수 없습니다. 브라우저 환경에 의해 표시된 신호에 근거한 방문자는 상자 검사와 같은 상호 작용을 실행하거나 더 probing를 위한 단추를 선정하는 것을 요구될지도 모릅니다.

챌린지 페이지의 상호작용과 가시성의 수준은 웹 사이트 또는 응용 프로그램에 대한 WAF 규칙을 만들 때 선택한 행동에 따라 달라집니다.

## 관련 기사

다음 도전 유형은 도전 페이지의 'WAF\` 규칙을 만들 때 사용할 수있는 작업입니다.

### 비동기 도전

비 인터랙티브 챌린지와 함께 ‘Cloudflare’는 ‘JavaScript’를 통해 브라우저 신호를 통해 제한된 정보로 자동화되어 있는지 여부를 결정합니다. 그런 다음, 브라우저에서 처리 된 JavaScript를 제외하고 방문자의 상호 작용이 필요하지 않은 도전 페이지를 소개합니다.

방문자는 브라우저가 "JavaScript"를 처리 할 때까지 기다릴 필요가, 일반적으로 5 초 미만.

방문자가 도전을 통과하면, 원래 요청은 목적지 URL로 계속됩니다. 도전이 실패하거나 완료 할 수없는 경우, 방문자는 다른 Interstitial Challenge Page로 표시됩니다.

### 관리 도전

Managed Challenges는 "Cloudflare"가 역동적으로 브라우저에 의해 표시된 신호에서 요청의 특성에 따라 방문자에게 제공하는 적절한 유형의 도전을 선택합니다. 이 도움말[자동차 경주](https://www.cloudflare.com/learning/bots/how-captchas-work/)또한 인간 시간의 일생을 감소시키고 인터넷을 통해 CAPTCHA를 해결했습니다.

대부분의 인간 방문자는 자동적으로 확인되고 도전 페이지는 표시할 것입니다**감사합니다.**. 그러나, Cloudflare가 방문자의 브라우저에서 non-human 속성을 감지하면 해결하기 위해 도전과 상호 작용할 수 있습니다.

다른 유형의 도전을 사용하는 특정 호환성 문제 또는 다른 이유가 없습니다. "Cloudflare"는 사용자 정의 규칙에 대한 관리 된 도전을 사용하는 것이 좋습니다.

### 대화 도전

Interactive Challenge Pages는 웹 사이트 또는 응용 프로그램에 가장 높은 보안을 제공하므로 Interstitial Challenge Page와 상호 작용할 수 있기 때문에 대화 형 챌린지와 방문자가 해결 할 수 있도록합니다.

'Cloudflare'가 왜 'Cloudflare'가 Interactive Challenge를 사용하는 것이 좋습니다, 관리 된 도전에, 우리의 참조[블로그 게시물](https://blog.cloudflare.com/end-cloudflare-captcha/).

## 호환성 제한

Challenge Pages는 사용자가 렌더링하고 해결하기 위해 전체 HTML 페이지를 반환하여 요청 흐름을 중단합니다. 이 메커니즘은 브라우저가 AJAX 또는 XHR (fetch) 요청과 같은 비 HTML 응답을 기대할 때 실패합니다.

API 호출을 보장하기 위해 단일 페이지 응용 프로그램 (SPAs) 또는 API 통합을 파괴하지 않고 보호됩니다. Cloudflare는 Turnstile Pre-clearance를 사용하는 것이 좋습니다.

Pre-clearance를 활성화함으로써, Turnstile 위젯은 persistent 정리 쿠키를 문제한다 (`cf_clearance`) 초기 HTML 페이지에서 성공적인 인간 검증에. 이 쿠키는 ‘WAF’ 규칙에 의해 보안된 민감한 API 엔드포인트와 상호 작용할 수 있는 방문자를 미리 명확하게 하고, 중단된 챌린지 페이지 응답을 강제하지 않고 granular 보안을 배포할 수 있습니다.

구현 세부 사항, 참조[Turnstile를 위한 Pre-clearance에 지도](/cloudflare-challenges/concepts/clearance/#pre-clearance-support-in-turnstile).

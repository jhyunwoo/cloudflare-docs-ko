## Favicon 사용자 정의

Cloudflare 도전은 웹 사이트의 favicon을 사용`GET /favicon.ico`챌린지 페이지에 표시한다.

아래 HTML 스니펫을 사용하여 favicon을 사용자 정의 할 수 있습니다.

```html title="HTML element"
<link rel="shortcut icon" href="<FAVICON_LINK>" />
```

## 사용자 정의 콘텐츠 보안 정책 (CSP) 및 오류 페이지

Cloudflare-served ChallengePages는 보안을 극대화하고 도전 메커니즘 기능을 올바르게 보장합니다. 이 때문에 자체 콘텐츠 보안 정책 (CSP) 또는 Referer-Policy를 사용하여 설정할 수 없습니다.`<meta>`챌린지 Pages에 태그 또는 변형 규칙. Origin 헤더는 챌린지 페이지 컨텍스트 내에서 수정할 수 있지만, 문제가 발생할 수 있습니다.

사용자 정의 CSP 헤더를 추가하는 것과 같은 웹 사이트에서 전 세계적으로 HTTP 응답 헤더를 수정하기 위해 구성된 활성 Transform 규칙이 있다면,이 규칙은 실패하는 도전 페이지를 방해합니다.

이 충돌을 방지하기 위해 Transform Rule expression을 명시적으로 챌린지 페이지 오류 유형을 제외해야 합니다. Transform 규칙 표현을 다음과 같은 논리 제외로 수정하십시오.

```txt wrap
not cf.response.error_type in {"managed_challenge" "iuam" "legacy_challenge" "country_challenge"}
```

이 exclusion은 사용자 정의 헤더 수정 논리가 당신의 기원에 대한 트래픽에 적용된다는 것을 보증하며, 충돌 응답 헤더에 영향을받지 않고 기능하는 'Cloudflare'의 도전 플랫폼을 허용한다.

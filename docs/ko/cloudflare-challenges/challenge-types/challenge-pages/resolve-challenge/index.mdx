방문자가 도전에 직면하면, Cloudflare 직원들은 그 도전을 제거 할 수 없습니다. 웹 사이트 소유자는 "Cloudflare"설정을 구성하여 챌린지가 발표될 수 있습니다.

'Cloudflare' 도전 페이지를 관찰 할 때, 방문자는 할 수:

- 성공적인 웹 사이트를 방문하기 위해 도전을 전달합니다.
- 웹 사이트 소유자를 요청하여 IP 주소를 허용하십시오.
- 악성 프로그램에 대한 컴퓨터 검사 (그것은 감염 될 수있다).
- 챌린지 리소스에 대한 액세스를 차단하지 않도록 안티 바이러스 또는 방화벽 서비스를 확인하십시오 (예 : 이미지).

:::참조
방문자는 브라우저에서 JavaScript와 쿠키를 활성화하여 어떤 유형의 도전을 전달할 수 있습니다.

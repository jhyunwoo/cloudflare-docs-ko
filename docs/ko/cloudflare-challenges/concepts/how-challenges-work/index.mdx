도전은 'Cloudflare' 제품 또는 기능에 따라 세 가지 주요 방법으로 발급 될 수 있습니다. 각 방법은 원활한 방문자 경험으로 보안을 균형으로 설계되었습니다.

| 제품정보                                                                                                                         | 도전형(s)                                                                             |
| ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| [‘WAF’](/waf/) ([주문 규칙](/waf/custom-rules/), [비율 제한 규칙](/waf/rate-limiting-rules/), [IP 접근 규칙](/waf/tools/ip-access-rules/)) | [Interstitial 도전 페이지](/cloudflare-challenges/challenge-types/challenge-pages/)     |
| [Bot 관리](/bots/get-started/bot-management/)                                                                                  | [JavaScript 탐지](/bots/additional-configurations/javascript-detections/)            |
| [Bot 전투 모드](/bots/get-started/bot-fight-mode/), [슈퍼 Bot 전투 모드](/bots/get-started/super-bot-fight-mode/)                      | [Interstitial 도전 페이지](/cloudflare-challenges/challenge-types/challenge-pages/)     |
| [회전성](/turnstile/)                                                                                                           | 내장 위젯                                                                              |
| [HTTP DDoS 공격 보호](/ddos-protection/managed-rulesets/http/)                                                                   | 모든 도전                                                                              |
| [공격 모드](/fundamentals/reference/under-attack-mode/)                                                                          | [관리 도전](/cloudflare-challenges/challenge-types/challenge-pages/#managed-challenge) |

챌린지 Pages와 Turnstile는 웹 사이트 또는 응용 프로그램의 방문자에게 도전을 발행하기 위해 동일한 하향 메커니즘에 의존합니다.

JavaScript Detections는 Cloudflare의 Enterprise Bot Management를 지원합니다. 클라이언트 측 탐지에 아직도 의존하는 동안, JavaScript는 챌린지 Pages 또는 Turnstile 보다는 더 많은 실행 도전 논리를 사용하여 기능을 탐지합니다.

***

## 유효한 도전

다른 도전 유형에 대한 자세한 내용은 다음 페이지를 참조하십시오 :

- [Interstitial 도전페이지](/cloudflare-challenges/challenge-types/challenge-pages/)
- [회전성](/cloudflare-challenges/challenge-types/turnstile/)
- [JavaScript 탐지](/cloudflare-challenges/challenge-types/javascript-detections/)

***

## 제한 사항

Cloudflare 도전은 다음을 지원할 수 없습니다.

- [브라우저 확장](/cloudflare-challenges/reference/supported-browsers/#browser-extensions)브라우저의 수정`User-Agent`값 또는 웹 API와 같은`Canvas`·`WebGL`.
- 도메인이 다른 도메인에 대해 요청한 문제 페이지를 제공합니다.
- 챌린지 Pages는 cross-origin iframe에 임할 수 없습니다.
- 관리 된 도전의 해결 요청이 원래 IP보다 다른 IP에서 온다 클라이언트 소프트웨어는 도전 요청이 발행되었습니다. 예를 들어, 하나의 IP에서 도전을 받고 다른 IP를 사용하여 해결하면 해결이 유효하지 않으며 도전 루프가 발생할 수 있습니다.

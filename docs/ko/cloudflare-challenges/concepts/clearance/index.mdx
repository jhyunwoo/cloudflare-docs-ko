## `cf_clearance`제품 정보

·`cf_clearance`쿠키는 'Cloudflare'로 증명합니다. 방문자는 검증 된 인간이며 그들에게 발표 된 도전을 통과했습니다.

더 보기`cf_clearance`쿠키는 특정 방문자와 장치에 안전하게 연결됩니다. 이 바인딩은 다른 기계에서 쉽게 전송 및 재사용되는 쿠키를 방지하기 위해 설계된 보안 기능입니다.

보안의 추가 레이어로서, Cloudflare는 고객이 추천한다.[제한 규칙을 추가](/waf/rate-limiting-rules/)에 따라`cf_clearance`쿠키 값. 단일, 유효한 쿠키가 단일 기계에 의해 학대 할 수 없다는 것을 보장한다.

방문자가 대화 형 도전 (최고의 보안 수준)을 통과하면`cf_clearance`쿠키는 원산지를 나타냅니다. 방문자가 웹 사이트에 다른 도전을 우회할 수 있습니다. 비 인터랙티브 챌린지, 관리 챌린지 또는 쿠키가 유효합니다.

방문자가받을 경우`cf_clearance`'WAF' 규칙을 사용하여 페이지에 쿠키를 관리하거나 비동기적 인 도전 (낮은 보안 수준)을 사용하여 다른 페이지에 더 높은 보안 정리 수준 도전이 다시 도전을 해결하는 것입니다.

이름 \*`cf_clearance`더 낮은 보안 정리 수준에서 방문자에게 발행 된 쿠키는 새로운로 대체됩니다.`cf_clearance`더 높은 보안 정리 수준에서 쿠키.

## Turnstile의 사전적 지원

Pre-clearance에서[회전성](/turnstile/)웹 사이트를 통해 사용자 경험을 간소화 할 수 있습니다.`cf_clearance`사이트 맵 더 보기`cf_clearance`쿠키는 방문자가 고객의 보안 정리 수준에 따라 WAF Challenges downstream을 우회할 수 있도록 합니다. 보안을 유지하면서 신뢰할 수있는 방문자에게 특히 유용 할 수 있습니다.

기본적으로, Turnstile는 위젯을 통해 도전을 해결할 때 방문자에게 한 번의 사용 토큰을 발행합니다. 토큰은 Siteverify API에 의해 검증되어야하는 웹 사이트의 백엔드로 이동합니다.

주요 특징

| 공지사항         | `cf_clearance`쿠키 (과태)               |
| Turnstile 위젯 | 토큰 (기본)<br /> `cf_clearance`쿠키 (옵션) |

Turnstile에 대한 pre-clearance 지원을 할 때,`cf_clearance`쿠키는 기본 Turnstile 토큰 외에 방문자에게 발행됩니다.

'Cloudflare' Challenges를 통합 할 수 있습니다. Turnstile을 사용하여 문제 해결`cf_clearance`당신의 방문자에 사전 명확성으로 쿠키. pre-clearance 수준은 위젯 생성 또는 위젯 수정을 사용하여 Turnstile API's 정리 level. 구성의 가능한 값은:

- `interactive`
- `managed`
- `jschallenge`
- `no_clearance`

모든 위젯은 pre-clearance 모드 설정`false`보안은 설정`no_clearance`기본적으로.

모든 사전 구성 호스트 이름없이 위젯을 활성화 할 수있는 엔터프라이즈 고객을 위해, 'Cloudflare'는 최소한 하나의 호스트 이름이 지정되어있는 위젯에 사전 투명 쿠키를 발급하고 'Turnstile'과 통합하려는 영역과 동일합니다.

더 알아보기[블로그 게시물](https://blog.cloudflare.com/integrating-turnstile-with-the-cloudflare-waf-to-challenge-fetch-requests)WAF로 사전 클리어런스가 작동하는 방법에 대한 자세한 내용은.

### Pre-clearance 수준 옵션

**이름 \***(높은)`interactive`

Non-Interactive Challenge, Managed Challenge 또는 Interactive Challenge Firewall Rules에 의해 도전하지 않는 통근 쿠키를 사용하여 사용자를 허용하십시오.

**지원하다**(중간)`managed`

Non-Interactive Challenge 또는 Managed Challenge Firewall Rules에 의해 도전하지 않는 통관 쿠키로 사용자를 허용하십시오.

**비동기**(낮은)`jschallenge`

Non-Interactive Challenge Firewall Rules에 의해 도전하지 않는 정리 쿠키를 사용하여 사용자를 허용합니다.

### 편의 용품

Turnstile 위젯에 의해 생성 된 정리 쿠키는 Zone-level Challenge Passage 값에 의해 지정된 시간에 유효합니다. Challenge Passage 설정을 구성하려면, 참조[도전 통행](/cloudflare-challenges/challenge-types/challenge-pages/challenge-passage/).

### 설치하기

pre-clearance를 활성화하려면 Turnstile 위젯의 호스트 이름을 WAF 규칙과 함께 영역을 일치해야합니다. Cloudflare\`\`대시보드에서 Turnstile 설정 중, 등록 영역의 목록에 액세스 할 수 있습니다. 이 목록에서 적절한 hostname을 선택합니다.

prerequisite는 제대로 기능에 pre-clearance를 위해 중요합니다. 제대로 설정된 경우, 성공적으로 Turnstile을 해결하는 방문자는 고객에 의해 설정된 보안 정리 수준으로 쿠키를 받게 됩니다. 같은 영역에서 WAF 도전에 참여할 때, 구성 정리 수준과 아래에서 추가적인 도전을 우회할 것입니다.

hostnames 관리에 대한 자세한 내용은, 참조[Hostname 관리 문서](/turnstile/additional-configuration/hostname-management/).

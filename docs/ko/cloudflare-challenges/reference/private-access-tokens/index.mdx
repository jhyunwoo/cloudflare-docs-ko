사용자가 챌린지 페이지로 발표될 때, Cloudflare는 Private Access Token (PAT)의 결과를 사용하여 인간의 결과를 증명하기 위해 챌린지를 결정합니다. 사용자가 토큰을 선물하면 더 쉽게 도전을 해결할 수 있습니다.

일부 도전은 적절하게 복잡하거나 상호 작용을 요구하지만, 대부분의 도전은 사용자에게 보이지 않습니다.

챌린지 페이지는 유효한 PAT 또는 아닙니다. PAT는 자동으로 도전을 해결하지 않습니다. 그것은 발행 된에서 특정 도전을 방지합니다.

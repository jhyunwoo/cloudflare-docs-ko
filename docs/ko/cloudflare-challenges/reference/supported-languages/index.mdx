## Multi-language 지원

'Cloudflare' 도전은 여러 언어를 감지하고 현지화 된 도전 경험을 표시합니다.`navigator.language`가치. 더 보기[Navigator.language 읽기 전용 속성](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/language)사용자의 선호 언어를 나타내는 문자열을 반환, 보통 브라우저 사용자 인터페이스의 언어.

'Pages'에 대한 언어 지원은 아래 표 참조.

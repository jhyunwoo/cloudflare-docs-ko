### 브라우저 지원

도전은 Microsoft Internet Explorer에서 지원되지 않습니다. Internet Explorer를 사용하는 경우, 다른 현대 웹 브라우저 (Chrome, Safari, Firefox)를 사용해보십시오. 현대 웹 브라우저를 사용하는 경우 최신 버전을 사용해야합니다.

### Referer 헤더

방문자의 HTTP 요청은 참조 헤더가 웹 사이트로 설정되어 있습니다. 그들이 직면하고 도전 페이지를 해결 할 때, 참조자의 요청은 기원으로 보내지고, 요청에 응답은 사용자에게 제공됩니다. 응답 페이지의 JavaScript는 값을 읽을 수 있습니다.`document.referer`, 그러나 그것은 정확하지 않을 것입니다.

예를 들어, 주어진 웹 사이트에서 오는 방문자가 도전합니다.[WAF 규칙](/waf/custom-rules/)interstitial Challenge Page는 도메인에 의해 제공됩니다. 방문자가 웹 사이트의 홈 페이지를로드하면,`document.referer`값은 도메인이 아닌 웹 사이트입니다.

이 도구는 Google Analytics와 같은 도구에 영향을 미칩니다. 즉, 방문자가 보낸 이전 웹 사이트를 대체하기 때문입니다.

기존의 Google Tag Manager Javascript와 같은 추적 스크립트를 추가할 수 있습니다.[공지사항](/rules/custom-errors/)초기 요청에 정확한 참조 헤더를 캡처합니다.

```js title="Example JavaScript"
<script>
    (function () {
      const gaIds = {
        "<YOUR_DOMAIN>": "<GA_TRACKING_ID>",
      };

      const gaId = gaIds[window.location.hostname];

      if (gaId) {
        const src = "https://www.googletagmanager.com/gtag/js?id=";

        const gaScript = document.createElement("script");
        gaScript.src = src.concat(gaId);
        document.body.appendChild(gaScript);

        window.dataLayer = window.dataLayer || [];
        function gtag() {
          dataLayer.push(arguments);
        }
        gtag("js", new Date());
        gtag("config", gaId);
      } else {
        console.warn(
          "Google Analytics ID not found for host:",
          window.location.hostname,
        );
      }
    })();
  </script>
</body>

```

### Cross-origin 리소스 공유 (CORS) preflight 요청

Cross-origin 리소스 공유 (CORS) preflight 요청 또는`OPTIONS`, 쿠키를 포함하는 사용자 자격 증명을 제외. 결과적으로,`cf_clearance`쿠키는 요청으로 보내지 않을 것이며, 챌린지 페이지(Non-interactive, Managed, 또는 Interactive Challenge)를 우회하지 못하게 합니다.

### 'Cloudflare'-protected 사이트에 도전

Cloudflare는 웹 사이트 방문자에게 봇 공격 및 DDoS 시도와 같은 악의적 인 활동을 보호하기 위해 도전합니다. 법적인 인간 방문자가 예기치 않게 도전하는 경우, 일반적으로 보안 기능에서 줄기는 요청을 기인합니다.

| 이름 \*                         | 이름 \*                                            |
| ----------------------------- | ------------------------------------------------ |
| 높은 위협 점수                      | 높은 점수 트리거 도전과 IP 주소.                             |
| IP 명성                         | IP가 의심스러운 활동의 역사를 가지고 있다면, 그것은 끌 수 있습니다.         |
| Bot 탐지                        | 자동화된 교통 닮은 로봇은 Cloudflare에 의해 필터링됩니다.            |
| 웹 응용 프로그램 방화벽 (WAF) 사용자 정의 규칙 | 사이트 소유자는 특정 지역 또는 사용자 에이전트를 대상으로 규칙을 설정할 수 있습니다. |
| 브라우저 Integrity Check          | Cloudflare는 브라우저가 특정 표준을 준수합니다.                  |
| 도전 통행                         | Privacy Pass와 같은 기술은 반복된 도전의 빈도를 감소시킵니다.         |

반복된 도전을 피하기 위해, 방문자는 그들의 환경을 방아쇠 안전 체크를 지키는 뒤에 오는 단계를 가지고 갈 수 있습니다:

- 웹 브라우저가 최신의 안정 버전으로 업데이트됩니다.
- 광고 차단제 또는 개인 정보 보호 도구와 같은 Temporarily 비활성화 브라우저 확장, 표준 브라우저 헤더 또는 필요한 도전 스크립트를 차단할 수 있습니다.
- IP 주소가 가난한 평판이 있다면 (공유된 VPN 또는 법인 프록시로 보았음), 다른 신뢰할 수있는 네트워크 연결으로 전환하십시오.

### mitigation 작업에서 Allowlist 트래픽

예방해야 하는 경우**제품정보**또&#xB294;**- 연혁**지정된 검색 엔진 크롤러, 모니터링 서비스, 또는 내부 API와 같은 특정 요청에 적용되는 작업은 exclusion을 구성해야 합니다.[WAF 사용자 정의 규칙](/waf/custom-rules/).

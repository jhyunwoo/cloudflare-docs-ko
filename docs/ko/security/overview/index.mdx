보안 개요는 도메인의 보안 상태를 한눈에 보여 주며, 주의가 필요할 수 있는 보안 조치 항목을 빠르게 식별할 수 있게 해줍니다.

새 보안 대시보드에서 보안 개요에 접근하려면 **Overview** 페이지로 이동하세요.

[**Overview**로 이동](https://dash.cloudflare.com/?to=/:account/:zone/security/overview)

보안 개요 페이지에는 다음이 표시됩니다.

- 보안 조치 항목
- 탐지 도구
- 트래픽 개요

## 보안 조치 항목

**보안 조치 항목**에는 잘못된 구성, 노출된 인프라, 의심스러운 활동과 관련된 인사이트와 권장 사항이 표시됩니다.

- **조치 항목 유형**:
  - 의심스러운 활동
  - 보안 인사이트
- **심각도**: 조치 항목은 가장 높은 심각도 순으로 정렬되며, 중요한 항목이 먼저 표시되고 그다음으로 보통, 낮음 순서로 표시됩니다.
- **필터**: 조치 항목은 심각도, 인사이트 유형, 보안 카테고리별로 필터링할 수 있습니다.
  - 심각도:
    - 낮음
    - 보통
    - 중요
  - 인사이트 유형:
    - 의심스러운 활동
    - 노출된 인프라
    - 안전하지 않은 구성
    - 구성 제안
    - 규정 준수 위반
    - 이메일 보안
    - 취약한 인증
  - 보안 카테고리:
    - 웹 애플리케이션 익스플로잇
    - AI 익스플로잇
    - DDoS 공격
    - 봇 트래픽
    - API 남용
    - 클라이언트 측 남용
    - 사기
- **검토**: 보안 조치 항목을 검토하여 문제를 해결하기 위한 더 자세한 정보와 권장 작업을 확인할 수 있습니다.
- **보관**: 메인 목록에 표시하고 싶지 않은 보안 조치 항목은 보관할 수 있습니다.
- **더 보기**: 보안 조치 항목 전체 목록을 볼 수 있습니다.

## 탐지 도구

사용 가능한 탐지 도구와, 현재 어떤 서비스가 위협으로부터 도메인을 보호하기 위해 실행 중인지 검토하세요.

## 트래픽 개요

지난 30일 동안의 도메인 트래픽 패턴과 주요 특징을 확인하세요.

Cloudflare 대시보드에는 다음이 표시됩니다.

- **월간 요청 수**: 월간 요청 수와 Cloudflare가 완화한 트래픽을 확인합니다.
- **동종 업계와의 비교**: Enterprise 플랜에서는 Cloudflare의 보호를 받는 같은 업계의 다른 조직과 비교했을 때 보안 상태가 어떤지 파악할 수 있습니다.

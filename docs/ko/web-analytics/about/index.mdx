Web Analytics는 Adaptive Bit Rate(ABR)를 지원합니다. Cloudflare 서버는 데이터 크기, 날짜 범위, 네트워크 연결 및 기타 요소에 따라 각 차트나 표에 가장 적합한 해상도를 선택합니다. 자세한 내용은 [Explaining Cloudflare's ABR Analytics](https://blog.cloudflare.com/explaining-cloudflares-abr-analytics/)를 참고하세요.

Web Analytics에 표시되는 데이터는 실제 사용자 모니터링(RUM) 데이터입니다. 자세한 내용은 [Real User Monitoring](https://en.wikipedia.org/wiki/Real_user_monitoring)을 참고하세요.

Cloudflare Web Analytics는 방문자의 개인정보를 수집하거나 사용하지 않습니다.

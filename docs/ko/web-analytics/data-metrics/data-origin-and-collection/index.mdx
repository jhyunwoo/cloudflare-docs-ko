Web Analytics는 페이지 로드 성능 지표를 수집하기 위해 `performance.getEntriesByType('navigation')` 객체를 사용합니다. Navigation Timing Level 2가 지원되지 않으면 [`performance.timing` (Level 1)](https://developer.mozilla.org/en-US/docs/Web/API/Performance/timing)을 사용합니다.

웹 페이지 로드 시 타이밍 이벤트가 어떤 순서로 발생하는지 시각적으로 보려면 [W3C Processing Model](https://www.w3.org/TR/navigation-timing-2/#processing-model)을 참고하세요.

## 데이터 수집 및 보고

Web Analytics는 고객이 웹사이트 성능을 확인할 수 있도록 최소한의 정보, 즉 타이밍 지표만 수집합니다. Cloudflare는 고객의 인터넷 자산 전반에 걸쳐 개별 최종 사용자를 추적하지 않습니다.

Web Analytics 성능 beacon은 `https://static.cloudflareinsights.com/beacon.min.js`에서 로드됩니다. 이 스크립트를 로드하려면 <GlossaryTooltip term="content security policy (CSP)" link="https://developer.mozilla.org/en-US/docs/Web/HTTP/CSP">Content Security Policy (CSP)</GlossaryTooltip> 설정을 업데이트해야 할 수 있습니다.

beacon 데이터는 Cloudflare를 통해 프록시되는 사이트의 경우 `https://<yourdomainname>/cdn-cgi/rum`으로, Cloudflare를 통해 프록시되지 않는 사이트의 경우 `https://cloudflareinsights.com/cdn-cgi/rum`으로 전송됩니다. Core Web Vitals 지표는 페이지 load event가 발생한 뒤 `visibilityState`가 처음 hidden 상태가 될 때 보고됩니다.

Page load time 요약은 웹 페이지를 로드하는 데 걸리는 시간을 영역별로 나누어 보여 줍니다. Page load time에 접근하려면 다음과 같이 하세요.

1. 계정 홈 페이지에서 [Web Analytics](https://dash.cloudflare.com/?to=/:account/web-analytics)로 이동한 뒤 웹사이트를 선택합니다.
2. **Page load time**을 선택합니다.

## 구성 요소

아래는 확인할 수 있는 모든 구성 요소 목록입니다.

### Page load

페이지를 로드하는 데 필요한 전체 시간입니다. page load time은 Web Analytics에 표시되는 다른 타이밍들의 합과 일치하지 않는다는 점에 유의하세요. 이는 pre-DNS lookup 타이밍이나 타이밍 지표 사이의 귀속되지 않은 간격처럼, 표시되지 않는 시간도 page load time에 포함되기 때문입니다.

### DNS (`domainLookupEnd` - `domainLookupStart`)

DNS 조회에 걸리는 시간입니다. 연결을 재사용했거나 콘텐츠가 로컬 캐시(메모리 또는 디스크)에 저장되어 있는 경우 0으로 표시될 수 있습니다.

### TCP (`connectEnd` - `connectStart`)

서버와 TCP 연결을 수립하는 데 걸리는 시간입니다. HTTPS를 사용하는 경우 이 과정에는 TLS 협상 시간도 포함됩니다.

### Request (`responseStart` - `requestStart`)

HTTP 요청을 보낸 시점부터 응답의 첫 바이트를 받은 시점까지 경과한 시간입니다.

### Response (`responseEnd` - `responseStart`)

응답의 첫 바이트부터 마지막 바이트까지를 받은 데 걸린 시간입니다. 리소스 다운로드 시간이라고 생각하면 됩니다.

### Processing (`domComplete` - `domInteractive`)

페이지 렌더링에 걸린 시간입니다. 이미지, 스크립트, 스타일시트를 포함해 페이지 렌더링을 막는 모든 리소스 로딩 시간이 포함됩니다. 이 숫자가 크다면 문서 구조, 리소스 크기를 최적화하거나 Cloudflare Speed 앱의 설정을 구성하세요. 이 문서 처리 과정은 `domInteractive`, `domContentLoadedEventStart`, `domContentLoadedEventEnd`, `domComplete`로 더 세부적으로 살펴볼 수 있습니다.

### Load Event (`loadEventEnd` - `loadEventStart`)

문서와 그 리소스의 로딩이 끝났을 때 브라우저가 발생시키는 이벤트입니다. load event 지속 시간은 load event에 추가 함수나 로직이 있는 경우 유용한 지표가 될 수 있습니다.

## Paint Timings에 대해 수집되는 데이터

Web Analytics가 동작하려면 Cloudflare는 여러 종류의 데이터 포인트를 수집합니다. 다음은 Paint Timings를 위해 추가로 수집되는 데이터입니다.

### First Paint

탐색이 시작된 시점부터 브라우저가 화면에 첫 픽셀을 렌더링할 때까지의 시간입니다.

### First Contentful Paint

브라우저가 DOM에서 첫 번째 콘텐츠 조각을 렌더링하는 시점의 시간입니다.

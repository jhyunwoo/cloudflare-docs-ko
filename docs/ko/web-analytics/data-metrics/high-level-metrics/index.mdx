웹 분석의 핵심 지표를 이해하는 것은 웹사이트 성능과 사용자 경험을 최적화하는 데 매우 중요합니다. Cloudflare Web Analytics가 추적하는 상위 수준 지표는 다음과 같습니다.

* **Visits** - 다른 웹사이트 또는 직접 링크에서 시작된 페이지 조회입니다. Cloudflare는 HTTP referer가 호스트명과 일치하지 않는 경우를 기준으로 확인합니다. 한 번의 visit에는 여러 page view가 포함될 수 있습니다.
* **Page views** - content-type이 HTML인 성공적인 HTTP 응답입니다.
* **Page load time** - 페이지를 로드하는 데 필요한 전체 시간입니다.
* **[Core Web Vitals](https://www.cloudflare.com/learning/performance/what-are-core-web-vitals/)** - 사용자 경험을 보다 완전하게 포착하도록 Google이 설계한 상위 수준 지표입니다.

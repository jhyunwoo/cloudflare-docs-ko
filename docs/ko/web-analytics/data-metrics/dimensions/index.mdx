차원(Dimensions)은 다양한 유형의 지표나 데이터를 설명하는 데 사용되는 레이블입니다. 예를 들어 **Referer**는 외부 링크를 통해 페이지로 유입된 방문 데이터를 의미하고, **Browser**는 어떤 브라우저가 웹사이트에 접근했는지를 보여 줍니다.

아래에는 Web Analytics를 필터링하는 데 사용할 수 있는 다양한 차원 목록이 있습니다.

- **Country**: 방문자의 국가입니다.
- **Host**: 사이트 URL의 도메인입니다.
- **Path**: 사이트 내부에서 특정 페이지 방문을 유도한 링크입니다.
- **Referer**: 특정 페이지 방문을 유도한 외부 링크입니다. 대시보드에서는 `referer host` 데이터를 볼 수 있습니다. 추가로 GraphQL API를 사용하면 `referer path` 데이터에도 접근할 수 있습니다.
- **Device type**: 방문자가 페이지에 접근하는 데 사용하는 기기 종류입니다(예: 데스크톱, 모바일, 태블릿).
- **Browser**: 방문자가 웹사이트에 접근할 때 사용하는 웹 브라우저입니다(예: Chrome, Safari).
- **Operating system**: 방문자가 페이지에 접근할 때 사용하는 운영 체제입니다.
- **Site**: 웹사이트의 도메인 이름입니다. 데이터의 상위 수준 분류에 사용됩니다. 예를 들어 특정 zone이나 회색 구름(gray-clouded) 웹사이트 기준으로 사용할 수 있습니다.
- **Exclude Bots**: 데이터셋에서 봇 트래픽을 제외합니다. 이 차원을 `Yes`로 설정하면 결과 데이터셋은 실제 사용자 트래픽에 더 가까워집니다.

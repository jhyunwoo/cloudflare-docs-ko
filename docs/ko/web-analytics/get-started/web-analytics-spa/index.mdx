Cloudflare Web Analytics는 History API의 `pushState` 함수를 재정의하고 `onpopstate` 이벤트를 감지하여 Single Page Application(SPA)에서의 사용자 상호작용을 자동으로 추적할 수 있습니다. 다만 hash 기반 라우터는 지원되지 않습니다.

## SPA 측정 비활성화

SPA에 대한 자동 추적을 비활성화하려면 아래 예시처럼 script tag의 data attribute에 `spa` 옵션을 `false` 값으로 추가하면 됩니다.

```html
<script
  defer
  src="https://static.cloudflareinsights.com/beacon.min.js"
  data-cf-beacon=' {"token": "42e216b9090ru59384ygu891dce9eecde", "spa": false} '
></script>
```

### Google Tag Manager (GTM)

Google Tag Manager(GTM)를 사용 중이라면 script URL의 query string을 통해 spa 옵션을 전달하여 SPA 추적을 비활성화할 수 있습니다.

```html
<script
  defer
  src="https://static.cloudflareinsights.com/beacon.min.js?token=42e216b9090ru59384ygu891dce9eecde&spa=false"
></script>
```

**Rules**를 사용하면 특정 웹사이트 또는 경로에 대해 Web Analytics를 추적할지 여부를 구성할 수 있습니다. 기본적으로 Web Analytics는 모든 페이지에 JavaScript(JS) 스니펫을 삽입하는 단일 zone 규칙을 자동으로 생성합니다.

규칙은 Cloudflare를 통해 프록시되는 사이트에서만 사용할 수 있습니다. 자세한 내용은 [Limits](/web-analytics/limits/)를 참고하세요.

1. Cloudflare 대시보드에서 **Web Analytics** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/web-analytics" />

2. 구성하려는 사이트를 찾아 **Manage site**를 선택합니다.
3. **Advanced options** > **Add rule**을 선택합니다.
4. **Action**을 선택하고 규칙을 추가하려는 호스트명과 경로를 입력합니다.
5. 추가 규칙을 더 만들고 싶다면 **Add rule**을 선택합니다. 그렇지 않으면 **Update**를 선택해 규칙을 저장합니다.

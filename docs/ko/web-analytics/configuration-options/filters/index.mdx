Web Analytics에 표시되는 데이터를 필터링하려면 다음과 같이 하세요.

1. Cloudflare 대시보드에서 **Web Analytics** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/web-analytics" />

2. 확인하려는 웹사이트를 선택합니다.
3. **Add filter**를 선택합니다.
4. **New filter** 상자에서 드롭다운을 사용해 기준을 선택합니다. 사용 가능한 필터 목록과 설명은 [Dimensions](/web-analytics/data-metrics/dimensions/) 페이지를 참고하세요.
5. **Apply**를 선택합니다.

### 추가 팁

- 기본적으로 Web Analytics는 최근 24시간 데이터를 보여 줍니다. 그래프 위의 드롭다운 메뉴를 사용해 시간 범위를 조정하세요.
- 그래프 위에서 커서를 선택한 뒤 드래그하면 사용자 지정 기간을 선택할 수 있습니다.
- 그래프 아래로 스크롤하면 국가별 상위 방문이나 기기 유형별 방문 같은 상세 분류를 확인할 수 있습니다.

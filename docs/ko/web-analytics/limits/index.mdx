Cloudflare는 웹 analytics를 추적할 수 있는 사이트 수와 각 요금제 유형에서 허용되는 규칙 수를 제한합니다. 자세한 내용은 아래 표를 참고하세요.

## 사이트 제한

Cloudflare는 Cloudflare를 통해 프록시되지 않은 사이트에 대해 추적 가능한 웹 analytics 사이트 수를 제한합니다.

| Site type | Limit |
| --- | --- |
| Cloudflare를 통해 프록시되지 않음 | 10 |
| Cloudflare를 통해 프록시됨 | 제한 없음 |

## 규칙 제한

Cloudflare는 요금제 유형에 따라 보유할 수 있는 Web Analytics 규칙 수를 제한합니다. 제한 수가 0인 요금제에서는 Web Analytics가 모든 하위 도메인에 JS snippet을 삽입합니다.

규칙은 Cloudflare를 통해 프록시되는 사이트에서만 사용할 수 있습니다.

| Plan type | Rules limit |
| --- | --- |
| Free | 0 |
| Pro | 5 |
| Business | 20 |
| Enterprise | 100 |

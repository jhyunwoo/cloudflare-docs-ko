<Description>

사용자 개인정보를 침해하지 않으면서도 웹사이트에 필요한 핵심 웹 분석 데이터를 얻으세요.
</Description>

<Plan type="all" />

Cloudflare Web Analytics는 사이트 방문자가 실제로 경험한 웹 페이지 성능을 이해하는 데 도움을 줍니다.

***

## 기능

<Feature header="필터" href="/web-analytics/configuration-options/filters/">

필터를 사용해 Web Analytics에 표시되는 데이터를 더 정교하게 다듬을 수 있습니다.


</Feature>

<Feature header="규칙" href="/web-analytics/configuration-options/rules">

규칙을 사용해 특정 웹사이트 또는 경로에 대해 Web Analytics 추적 방식을 구성할 수 있습니다.


</Feature>

<Feature header="차원" href="/web-analytics/data-metrics/dimensions">

차원을 사용해 다양한 지표나 데이터 유형을 효과적으로 분류하고 정리할 수 있습니다.


</Feature>

***

## 관련 제품

<RelatedProduct header="Analytics" href="/analytics/" product="analytics">
Cloudflare는 자사 제품이 수집한 메타데이터를 Cloudflare 대시보드에서 시각화해 보여 줍니다.
</RelatedProduct>

<RelatedProduct header="Speed" href="/speed/" product="speed">
Speed를 사용하면 웹사이트 성능을 평가하고 웹사이트 성능 향상에 도움이 되는 Cloudflare 제품 추천을 받을 수 있습니다.


</RelatedProduct>

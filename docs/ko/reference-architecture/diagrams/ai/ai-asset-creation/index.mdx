text-to-image 모델과 텍스트 생성 모델을 결합하여 입력 프롬프트를 기반으로 시각적 콘텐츠를 생성 할 수있는 강력한 AI 시스템을 이끌 수 있습니다. 이 통합은 텍스트 세대 모델이 입력 텍스트를 기반으로 텍스트 이미지 모델에 대한 프롬프트를 생성하는 공동 프레임 워크를 통해 달성 할 수 있습니다.

프로세스가 작동 할 수있는 방법 :

- 입력 텍스트 처리 : 입력 텍스트는 간단한 문장에서 여러 단락까지 할 수있는 시스템에 제공됩니다. 이 텍스트는 시각적 콘텐츠를 생성하기위한 기초 역할을합니다.

- Prompt Generation: 텍스트 세대 모델은 입력 텍스트를 기반으로 프롬프트를 생성합니다. 이 프롬프트는 입력 텍스트와 관련된 이미지 생성에 텍스트 투 이미지 모델을 안내하도록 특별히 제작되었습니다. 프롬프트는 이미지 생성 프로세스를 안내하기 위해 설명, 키워드 또는 기타 큐를 포함 할 수 있습니다.

- Content Moderation: Text-classification 모델은 생성된 자산이 콘텐츠 정책을 준수하도록 채택될 수 있습니다.

- Text-to-Image Model: text-to-image 모델은 텍스트 생성 모델에 의해 입력되고 해당 이미지를 생성합니다. text-to-image model은 본문에 의해 전달되는 본질과 컨텍스트를 캡처하는 것을 목표로 시각적 표현으로 텍스트 설명을 번역하는 것을 배웁니다.

AI 모델의 이러한 구성의 예제는 마케팅, 출판, 발표 등을 위해 시각 자산을 생성 할 수 있습니다.

## 자산 생성

![Figure 1: 콘텐츠 기반 자산 생성](~/assets/images/reference-architecture/ai-asset-generation-diagrams/ai-asset-generation.svg "Figure 1: Content-based asset generation")

1. **고객 업로드**: API 엔드포인트로 POST 요청을 보냅니다.
2. **Prompt 생성**: 나중에 단계 텍스트로 이미지 모델에 대한 신속한 생성[모델 번호: Workers AI](/workers-ai/) [텍스트 생성 모델](/workers-ai/models/)입력으로 내용으로.
3. **안전 검사**: 안전 지침 준수 확인[모델 번호: Workers AI](/workers-ai/) [텍스트 분류 모델](/workers-ai/models/)입력으로 이전 생성 된 프롬프트.
4. **이미지 생성**: 호출하여 이미지 생성[모델 번호: Workers AI](/workers-ai/) [텍스트 이미지 모델](/workers-ai/models/)이전 생성 된 프롬프트.

## 제품정보

자동 음성 인식 (ASR) 모델은 자막 및 번역의 생성을 가능하게하여 비디오 콘텐츠의 접근성을 혁명화했습니다. 이 모델은 고급 알고리즘을 사용하여 높은 정확도로 텍스트로 단어를 발음합니다. ASR 기술을 비디오 플랫폼으로 통합함으로써 콘텐츠 제작자, 출판사 및 유통업체는 청각 장애 또는 다른 언어로 콘텐츠를 소비하는 것을 선호하는 사람들을 포함하여 더 넓은 청중에 도달 할 수 있습니다.

이 과정은 비디오 소스에서 오디오를 캡처 한 다음 ASR 모델로 퓨즈됩니다. 이 모델은 오디오 파형을 분석하고 텍스트 표현으로 변환하고 자막 형태로 말한 콘텐츠를 캡처합니다. 또한, 언어 번역을위한 ASR 모델을 사용할 수 있으며 다국어 자막의 생성을 가능하게합니다. 자막이 생성되면 비디오와 함께 표시 할 수 있으며, 음성 콘텐츠의 동기화 된 텍스트 표현을 제공 할 수 있습니다.

## 자동 캡션

![그림 1 : 업로드에 자동 캡션](~/assets/images/reference-architecture/ai-auto-caption-architecture-diagrams/ai-auto-caption-architecture-diagram.svg "Figure 1:  Automatic captioning on upload")

1. **고객 업로드**: API endpoint에 비디오 및 오디오 모두 POST 요청을 보냅니다.
2. **오디오 transcription**: 호출하여 타임스탬프 된 transcriptions 생성[모델 번호: Workers AI](/workers-ai/) [자동 음성 인식 (ARS) 모델](/workers-ai/models/)입력으로 오디오. 제품 정보[모델 번호: Workers](/workers/)출력을 지원된 자막 형식으로 변환합니다.
3. **회사 소개**: 자막 파일 저장(s) 에[모델 번호: R2](/r2/).
4. **회사 소개**: 동영상 파일을 저장[모델 번호: R2](/r2/).
5. **고객 요청**: 비디오 및 자막에 대한 요청을 보내십시오. 글로벌[캐시](/cache/)성능 향상.
6. **공급 업체**: Fetch 파일(s)에서[모델 번호: R2](/r2/)캐시에`MISS`이름 \*[공공 버킷](/r2/buckets/public-buckets/).

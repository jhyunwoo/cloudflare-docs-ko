## 제품정보

가상 데스크톱 인프라 (VDI)는 오래된, 비용으로, 그리고 가난한 사용자 경험, 높은 업 프론트 투자, 지속적인 운영 비용 및 세부 사항에 대해 읽을 수있는 많은 다른 사람[이름 \*](https://blog.cloudflare.com/decommissioning-virtual-desktop/). 우리는 이러한 접근 방식에 대한 지속적인 신뢰로 인해 많은 조직의 얼굴을 인식하고 공감합니다. 이 참고 자료 아키텍처는 Cloudflare의 Zero Trust 솔루션이 조직이 가상 데스크탑 인프라 (VDI)를 확보하고 대부분의 경우를 완전히 해제하는 방법을 설명합니다. 많은 조직은 비싸고 가난한 VDI를 사용하여 보안 웹 브라우저를 원격 사용자에게 제공합니다. 이 경우 Cloudflare는 웹 기반 응용 프로그램 또는 SaaS 응용 프로그램에 대한 VDI의 사용을 완전히 해제 할 수 있습니다.

다른 경우, 전체 가상 데스크톱은 레거시 앱에 필요한 수 있습니다, 아직 조직은 여전히 자신의 VDI에 원격 액세스를 확보하거나 가상 데스크톱을 확보하는 데 도움이 필요하면 사용자가 그들과 상호 작용합니다. 이 문서는 참고 자료를 제공하고 Cloudflare의 Zero Trust 서비스를 사용하고 2개의 주요 단면도로 분할됩니다.

- 웹 기반 응용 프로그램에 대한 보안 원격 액세스를 위해 VDI를 replacing. 웹 브라우저를 사용하려면 전체 blown 데스크탑 환경을 액세스하는 것은 사용자를위한 최고의 경험이 아닙니다. Cloudflare는 웹 신청에 먼 접근에 광대한 개선을 제안하고 더 중대한 안전에 이렇게 할 수 있습니다.
- VDI 데스크탑을...
  - 무단 액세스.
  - 위험한 공공 인터넷 목적지에서.

### 이 문서는 누구입니까?

이 참고 자료 아키텍처는 Cloudflare를 사용하여 가상 데스크탑 인프라를 교체하거나 안전하게 찾고있는 IT 또는 보안 전문가를 위해 설계되었습니다. Cloudflare의 더 강한 기본 이해를 구축하려면 다음 리소스를 권장합니다.

- [VDI 블로그 게시물을 제출](https://blog.cloudflare.com/decommissioning-virtual-desktop/)
- [VDI용 PAC 파일로 Cloudflare의 Secure Web Gateway 활용](/learning-paths/secure-internet-traffic/configure-device-agent/pac-files/#use-cases)

## VDI를 대체

오늘날의 IT 풍경, 대부분의 응용 프로그램 및 서비스는 웹 브라우저를 통해 액세스하고 종종 SaaS 공급자에 의해 전달됩니다. 이 경우 VDI는 오버킬과 믿을 수 없을 정도로 비싸며, 보안 브라우저를 원격 사용자에게 제공합니다. 대신, 많은 조직은 대체로 전환됩니다.[원격 브라우저 고립](https://www.cloudflare.com/zero-trust/products/browser-isolation/)(RBI) 서비스. 이 서비스는 더 낮은 비용 및 오버 헤드, 더 나은 사용자 경험을 제공하고 가장 중요한 것은 강력한 보안 및 로깅 기능을 제공합니다.

![그림 1 : 원격 브라우저 고립은 민감한 회사 응용 프로그램에 액세스하기위한 안전하고 제어 된 브라우저 환경을 제공 할 수 있습니다.](~/assets/images/reference-architecture/zero-trust-and-virtual-desktop-infrastructure/figure1.svg "Figure 1: Remote browser isolation can provide a secure, controlled browser environment for accessing sensitive company applications.")

위의 다이어그램은 사용자 트래픽이 로컬 브라우저에서 Cloudflare의 원격 브라우저로 이동하고 보안 터널을 통해 인프라에서 호스팅되는 애플리케이션을 보여줍니다. 아래 그림 2는 사용자가 브라우저에서 원격 브라우저 고립을 사용하여 응용 프로그램에 액세스 할 수있는 방법을 보여줍니다 또는 트래픽에 대한 더 큰 개인 정보 보호 및 보안을 필요로하는 경우 장치 에이전트를 사용하여 장치에서 Cloudflare로 터널을 만듭니다. 두 방법 모두 내부 및 외부 리소스에 안전한 액세스를 제공합니다.

![그림 2: 2개의 다른 교통 교류 선택권: 장치 대리인을 사용하여 clientless RBI & RBI.](~/assets/images/reference-architecture/zero-trust-and-virtual-desktop-infrastructure/figure2.svg "Figure 2: Two different traffic flow options: clientless RBI & RBI using the device agent.")

## VDI 선택

### Zero Trust 정책을 사용하여 VDI에 접근

VDI를 대체 할 때 옵션이 아니며 완전히 가상화 된 데스크톱은 레거시 응용 프로그램에 필요합니다. Cloudflare의[SASE 플랫폼](https://www.cloudflare.com/zero-trust/)ID 기반 Zero Trust 정책을 사용하여 이러한 환경을 보호하고 장치 자체의 인터넷 경계 트래픽을 확보 할 수 있습니다.

![그림 3: Cloudflare 사용하기 VDI를 보안하기 위해 ZTNA를 액세스하십시오.](~/assets/images/reference-architecture/zero-trust-and-virtual-desktop-infrastructure/figure3.svg "Figure 3: Using Cloudflare Access ZTNA to secure VDI.")

위의 다이어그램은 VDI 인프라에 원격 사용자를 인증하기위한 모범 사례를 사용하여 일반 Zero Trust 배포를 표시합니다.

1. 사용자는 장치 대리인을 사용하여 안전한 갱도에 Cloudflare의 네트워크에 트래픽을 보냅니다.
2. VDI 리소스에 대한 트래픽은 장치 자세, 정체성 및 트래픽 컨텍스트 또는 유형을 포함하여 모든 상태 접근 기준의 조합을 평가하는 ZTNA 정책을 도달합니다.
3. ZTNA 정책을 통과하는 트래픽은 사용자가 VDI와 일반적으로 상호 작용할 수있는 VDI 리소스에 도달 할 수 있습니다.

이 모델은 다음과 같은 옵션에서 혜택을 누릴 수 있습니다. VDI 호스트의 트래픽을 필터링하는 방법 (아래에 참조).

### 보안 웹 게이트웨이 정책을 사용하여 VDI에서 트래픽을 처리

Cloudflare의 SASE 플랫폼은 내부 서비스로 VPN 및 bolstering 정책을 대체 할 수 있습니다. 인터넷에서 높은 위험 사이트에 액세스하여 사용자를 보호하기 위해 중요합니다. Cloudflare의 Secure Web Gateway의 정책은 DNS 요청을 필터링하거나 개방형 인터넷을 통해 네트워크와 HTTP 트래픽을 검사하는 정교한 전체 전달 프록시가 될 수 있습니다.

![그림 4 : Cloudflare의 Secure Web Gateway를 사용하여 VDI에서 오는 트래픽을 필터링하고 보호하십시오.](~/assets/images/reference-architecture/zero-trust-and-virtual-desktop-infrastructure/figure4.svg "Figure 4: Using Cloudflare's Secure Web Gateway to filter and protect traffic coming from VDI.")

1. **DNS 구성**(IP, DoH, DoT) 또는**PAC 파일**제품 정보**가상 데스크톱 인프라(VDI) 환경**인프라 내에서 직접 구성할 수 있습니다. VDI 호스트

   a. DNS 구성은 PAC 파일이 모든 게이트웨이 정책 유형 (DNS, Network 및 HTTP)을 허용하면서 DNS 정책을 시행 할 수 있습니다.

2. 트래픽은 DNS, 네트워크 또는 HTTP 정책에 의해 필터링되는 보안 웹 게이트웨이에 VDI에서 전송됩니다.

3. 트래픽은 게이트웨이 정책을 통해 허용된 인터넷으로 전송됩니다.

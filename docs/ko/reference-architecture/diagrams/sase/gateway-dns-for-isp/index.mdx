## 제품정보

인터넷 서비스 제공 업체는 지속적으로 비즈니스를 확장하기 위해 새로운 수익 기회를 탐험하고, 많은 사람들이 지금 보안을 통해 가치 추가 서비스로 연결 제안. 기존의 보안을 통합하여 보안을 통합하여 보안을 실현하는 데 필요한 레거시 솔루션에 대한 신뢰로 인해 상당한 어려움을 겪었습니다. 이것은 배치하고 관리하고 확장성과 가용성을 가진 포스트 배치 투쟁을 소개합니다.

오늘 이러한 제한은 클라우드 기반 솔루션을 통해 해결 될 수 있습니다.[Cloudflare 게이트웨이](/cloudflare-one/traffic-policies/), 우리의 안전한 웹 출입구 서비스. 모델 번호: Cloudflare Gateway의 DNS 필터링 기능은 서비스 제공 업체가 주거 및 모바일 가입자 또는 B2B 클라이언트에 대한 부가 서비스로 향상된 보안을 제공 할 수 있습니다. Cloudflare에 의해 역행된 정책을 쉽게 창조하십시오[광범위한 위협 인텔리전스](https://www.cloudflare.com/en-gb/security/), 서비스 제공자는 효과적으로 잠재적으로 접근에서 그들의 고객을 보호할 수 있습니다[유해 도메인](/cloudflare-one/traffic-policies/domain-categories/#security-categories).

또한, Cloudflare Gateway는 가용성, 성능 및 확장성에 대한 우려를 제거하여 내장되어 있습니다.[Cloudflare의 1.1.1.1 공개 DNS 해결자](/1.1.1.1/), 중 하나[빠른 속도](https://www.dnsperf.com/#!dns-providers)세계에서 가장 널리 사용되는 DNS 해커.

또한, 이 솔루션은 B2B 클라이언트에 대한 보호자 제어 또는 맞춤 필터링 프로파일과 같은 보안을 넘어 추가 서비스를 개발하기위한 기회를 열어.

## 제품정보

Cloudflare를 가진 서비스 제공자의 끝 고객에게 DNS 보안 제공은 straightforward입니다. 서비스 제공 업체는 Cloudflare 테넌트에 공개 DNS 요청을 간단히 전달하고 Cloudflare는 구성 된 DNS 필터링 정책에 따라 DNS 쿼리를 필터링합니다.

![Figure 1: 서비스 제공 업체 구독자는 DNS 쿼리를 서비스 제공 업체 DNS 서버에 보냅니다. DNS 필터링 정책을 적용하려면 Cloudflare Gateway로 전달됩니다.](~/assets/images/reference-architecture/gateway-dns-for-isp/gateway-dns-for-isp-image-01.svg)

모델 번호: Cloudflare 모든 Cloudflare 서비스와 같은 게이트웨이, 활용[anycast 기술](https://www.cloudflare.com/learning/cdn/glossary/anycast-network/), 모든 서비스 공급자 DNS 쿼리가 존재의 가장 가까운 Cloudflare 점에 지시된다는 것을 지키.

다른 고객으로부터의 서비스 제공 업체로부터 시작된 쿼리를 구별하기 위해, 관리자는 구성[이름 \*](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/)그들의 Cloudflare 테넌트 대시보드에서. DNS 위치가 생성되면 게이트웨이는 해당 위치에 IPv4/IPv6 주소와 DoT/DoH 호스트명을 할당합니다. 이 할당 된 IP 주소 및 호스트 이름은 서비스 제공 업체가 DNS 쿼리를 해결하는 데 사용됩니다. 차례로 서비스 제공 업체는 DNS 서버의 공개 IP 주소와 위치 객체를 구성하고, Cloudflare를 사용하여 해당 위치로 쿼리를 정확하게 준수합니다.

:::\[위치]
안정적인 소스 IPv4 주소가 on-premises DNS 서버로 할당될 수 없는 경우, 서비스 제공업체는 해당 대상 위치 엔드포인트를 대신 사용할 수 있습니다. 각 위치는 구분됩니다.[사이트맵](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#dns-over-tls-dot)·[사이트맵](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#dns-over-https-doh)호스트 이름뿐만 아니라 독특한[대상 IPv6 주소](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#ipv4ipv6-address). 게다가, Cloudflare는 독특하게 제공할 수 있습니다[대상 IPv4 주소 요청](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#dns-resolver-ip).
:::

DNS 필터링은 서비스 제공업체가 설정한 DNS 정책을 통해 해당 도메인에 연결된 도메인을 감지하는 것입니다.[보안 위험](/cloudflare-one/traffic-policies/domain-categories/#security-categories). Cloudflare 지속적으로 위험한 도메인의 목록을 업데이트[강력한 위협 인텔리전스](https://www.cloudflare.com/en-gb/security/). DNS 쿼리가 떠난 도메인을 일치할 때, DNS 정책에서 지정된 해당 동작이 실행됩니다. 이 작업은 '[제품정보](/cloudflare-one/traffic-policies/dns-policies/#block)Gateway가 응답하는 곳`0.0.0.0`IPv4 쿼리 또는`::`IPv6 쿼리를 위해, 또는 표시[Cloudflare에 의해 호스팅되는 주문 구획 페이지](/cloudflare-one/reusable-components/custom-pages/gateway-block-page/). 대안으로,`[Override](/cloudflare-one/traffic-policies/dns-policies/#override)`활동 또는[블록 페이지 URL 리디렉션](/cloudflare-one/reusable-components/custom-pages/gateway-block-page/#redirect-to-a-block-page)서비스 제공자가 호스팅 한 블록 페이지로 DNS 쿼리를 리디렉션 할 수 있습니다.

![Figure 2: DNS 정책은 악의적인 도메인에 navigating에서 사용자를 방지하기 위해. 동작은 서비스 제공 업체가 호스팅 한 블록 페이지로 DNS 쿼리를 무시하고 리디렉션하는 것입니다.](~/assets/images/reference-architecture/gateway-dns-for-isp/gateway-dns-for-isp-image-02.svg)

도메인을 허용하거나 차단할 수 있는 더 정확한 제어를 달성하기 위해 서비스 제공업체는 추가 허용된 도메인과 Blocked Domains 정책을 구성할 수 있습니다. 이 정책 설정[낮은 precedence](/cloudflare-one/traffic-policies/order-of-enforcement/#order-of-precedence)보안 위험 정책보다 서비스 제공 업체는 특정 도메인에 대한 보안 위험 정책을 무시할 수 있습니다.

허용 및 차단 된 도메인의 관리를 간소화하기 위해, 사용[이름 \*](/cloudflare-one/reusable-components/lists/). 목록은 대시보드를 통해 또는 쉽게 새롭게 합니다[API를](/api/resources/zero_trust/subresources/gateway/subresources/lists/methods/update/), 정책 조정을 더 능률 만들기.

![그림 3: DNS 정책은 우선순위에 따라 적용됩니다. 이 예에서 'Allow List Policy' 및 'Block List Policy'는 'Security List' 정책 이전에 간주됩니다.](~/assets/images/reference-architecture/gateway-dns-for-isp/gateway-dns-for-isp-image-03.svg)

또한, Cloudflare에 전달되는 모든 DNS 쿼리 Gateway는 로그인하여 외부 시스템에 수출할 수 있습니다.[다운로드](/cloudflare-one/insights/logs/logpush/).

## DNS 필터링 기능을 기반으로 하는 추가 오퍼링

서비스 제공자는 Cloudflare를 사용하여 그들의 제안을 강화할 수 있습니다 Gateway DNS 정책은 기본 DNS 보안 서비스에 따라 부가가치 서비스를 제공합니다. 동일한 솔루션을 사용하여 서비스 제공업체는 맞춤형 콘텐츠 범주 필터링 서비스를 개발할 수 있습니다. 이 서비스는 Cloudflare의 붙박이를 사용하여 쉽게 건설될 수 있습니다[관련 분류](/cloudflare-one/traffic-policies/domain-categories/#content-categories)·[신청 유형](/cloudflare-one/traffic-policies/application-app-types/), 뿐 아니라 서비스 공급자의 자신의 관례 허용 및 구획 명부.

몇몇 잠재적인 신청은 다음을 포함합니다:

- **학부모 관리 서비스**: 이 서비스는 성인 테마, 아동 학대, 폭력 및 아이들을위한 안전한 온라인 환경을 보장하기 위해 질문 가능한 콘텐츠를 차단 할 수 있습니다.
- **교육 서비스**: 학교 및 교육기구를 위해 설계된이 서비스는 CIPA, 도박, 엔터테인먼트와 같은 추가 범주를 차단하여 부모의 통제를 연장 할 수 있으며 집중 학습 분위기를 홍보합니다.
- **기업 서비스**: 이 오퍼링은 엔터테인먼트, 소셜 네트워킹, 도박, 쇼핑 및 경매, 사회 및 라이프 스타일 및 스포츠와 같은 범주를 포함한 비작업 관련 도메인에 쉽게 액세스 할 수 있습니다.

핵심 DNS 보안 제공에서 이러한 추가 서비스를 차별화하려면 서비스 제공 업체는 추가 DNS 위치를 만들 것입니다. 각 서비스. Cloudflare는 서비스 공급자가 위치의 유일한 식별자 중 하나에게 보낼 경우에 이 서비스를 위한 DNS 쿼리를 구별할 수 있을 것입니다. 각 위치에는 독특한[사이트맵](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#dns-over-https-doh)·[사이트맵](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#dns-over-tls-dot)호스트 이름과 독특한[대상 IPv6 주소](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#ipv4ipv6-address). Cloudflare는 또한 제공 할 수 있습니다[전용 대상 IPv4 주소](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#dns-resolver-ip)위치.

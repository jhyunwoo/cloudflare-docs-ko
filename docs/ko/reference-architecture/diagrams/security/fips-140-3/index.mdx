## 제품정보

이 문서는 Cloudflare의 응용 프로그램을 사용하여 연방 정보 처리 표준 (FIPS) 140 레벨 3 준수를 달성하기위한 참고 자료 아키텍처를 설명합니다. FIPS 140은 컴퓨터 및 통신 시스템에 민감한 정보를 보호하는 암호화 모듈의 보안 요구 사항을 지정하는 미국 정부 표준입니다.

FIPS 140은 4개의 보안 수준을 정의하며, 레벨 3은 비 Military 애플리케이션에 가장 엄격한 역할을 합니다. 그것은 암호화 키 및 중요한 보안 매개 변수에 대한 무단 액세스를 방지하기 위해 물리적 인 탬퍼 저항. 강력한 인클로저, 탬퍼 분명한 인클로저, 정체성 인증과 같은 측정이 포함되어 있습니다.

Achieving FIPS 140 준수, 특히 3 수준은 민감한 데이터를 처리하는 조직에 중요합니다, 특히 다음과 같은 규제 산업 :

- **주요사업**: 민감한 정부 정보를 처리하는 연방 기관 및 계약자.
- **의료보험**: HIPAA의 보호된 건강 정보(PHI) 취급
- **재무정보**서비스: 금융 거래 및 고객 데이터를 다루는 기관.
- **- 연혁**: 엄격한 보안 대책을 요구하는 방어 프로젝트에 대한 계약자.

FIPS 140 준수는 데이터 보안에 대한 강한 약속을 입증하고 고객과 파트너와의 신뢰를 구축하고 규제 요구 사항에 대한 준수를 보장합니다. 이 참고 자료 아키텍처는 Cloudflare의 강력한 보안 기능을 활용하기 위해 포괄적 인 가이드를 제공합니다.

## FIPS 140-3 수준

조직은 FIPS 140-3 표준을 사용하여 하드웨어가 특정 보안 요구 사항을 충족하도록합니다. FIPS 인증 표준은 4 증가, 보안의 품질 수준을 정의합니다.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="레벨 1">
    생산 등급 장비 및 외부 테스트 알고리즘을 요구합니다.
  </TabItem>

  <TabItem label="레벨 2">
    물리적 탐퍼 증거 및 역할 기반 인증에 대한 요구 사항 추가.
  </TabItem>

  <TabItem label="레벨 3">
    신체적 타당성 및 정체성 인증에 대한 요구 사항을 추가합니다. 어떤 중요한 보안 매개 변수가 입력하고 모듈을 떠날 때 인터페이스 사이에 물리적 또는 논리 분리가 있어야합니다. 개인 키는 암호화 된 형태로만 입력하거나 떠날 수 있습니다. 레벨 3은 또한 모듈을 사용하여 아웃 범위 전압 또는 온도 (환경 실패 보호, 또는 EFP)를 감지하고 반응하거나 대체로 환경 고장 테스트 (EFT)를 수행해야합니다.
  </TabItem>

  <TabItem label="레벨 4">
    이 수준은 물리적 보안 요구 사항 더 엄격한, 환경 공격의 다양한 형태를 감지하는 경우 장치의 내용을 지우는 능력이 필요합니다. 결함 주입에 대하여 EFP와 보호는 뿐 아니라 다 요인 입증입니다.
  </TabItem>
</Tabs>

## 핵심 부품

- **Cloudflare 열쇠가 없는 SSL**: Cloudflare의 SSL/TLS 보호를 사용하여 조직이 자신의 인프라에 안전하게 저장되는 개인 키를 유지하면서 조직이 Cloudflare의 SSL/TLS 보호를 사용할 수 있는 서비스로, 개인 키가 통제하에 남아 있으며, Cloudflare의 DDoS 보호 및 성능 최적화 기능에서 여전히 혜택을 누리고 있습니다.
- **Cloudflare 갱도**: Cloudflare의 글로벌 네트워크와 개인 인프라 호스팅 CloudHSM 간의 안전한 암호화 연결 제공, 전송 데이터 보호.
- **하드웨어 보안 모듈**: 암호화 키를 안전하게 관리하는 FIPS 140-2 Level 3 호환 HSM. Cloudflare는 AWS CloudHSM, Azure Key Vault 및 Google Cloud KMS를 포함한 HSM의 편리한 기능을 지원합니다.

<Steps>
  1. **사용자 / 클라이언트**: Cloudflare에 의해 보호되는 도메인에 HTTPS 요청을 시작합니다. Server Name Indication (SNI) extension in the request specifies the domain name like, 예를 들어,`keyless.example.com`. 그 도메인은 선언 된 인증서로 맵핑됩니다.[열쇠가 없는](/ssl/keyless-ssl/)즉, 대중은 Cloudflare에 수입되고, 그러나 열쇠가 없는 청취자는 또한, 후에 중요한 가동을 위해 선언됩니다.
  2. **Cloudflare 보안 터널 구축**: Cloudflare[회사 소개](/cloudflare-one/networks/connectors/cloudflare-tunnel/)구성 요소는 Cloudflare의 글로벌 네트워크와 안전하고 신뢰할 수있는 연결을 설정하는 데 사용됩니다. 교통만 우회하는 것은 둘레를 떠난다. 트래픽은 방화벽에 의해 좁힐 수 있다. 보안 연결은 중요한 작업을 위해 보안 오버레이로 사용됩니다.
  3. **키 작업**: Cloudflare[사이트맵](/ssl/)keyless 작업이 필요한 것을 감지하고 개인 인프라에 설치된 keyless 모듈을 통해 모든 키 작업을 보냅니다. 모든 트래픽은 이전에 보안 터널을 통해 흐르는 것입니다.
  4. **Keyless 단위**: 한국어[keyless 단위](/ssl/keyless-ssl/configuration/cloudflare-tunnel/#install)암호화 작업을위한 하드웨어 보안 모듈 (HSM)에 키 작업을 전달하는 책임입니다. 열쇠가 없는 단위는 Cloudflare와 HSM 사이에서 프록시 역할을 하는 소프트웨어 성분입니다, HSM를 결코 나타낸다는 것을 보증합니다.
  5. **PKCS11를 통한 주요 운영**: HSM은 HSM 내에서 안전하게 저장된 개인 키로 암호화 작업을 수행합니다. HSM은 암호화 키를 안전하게 관리하고 암호화 작업을 수행하고 민감한 데이터에 대한 높은 수준의 보안을 보장합니다.
</Steps>

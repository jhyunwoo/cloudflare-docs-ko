## 제품정보

Data at rest는 로컬 하드 드라이브, 온프레미스 서버 또는 클라우드 스토리지와 같은 고정 위치에서 저장되는 데이터를 나타냅니다. 오늘날 많은 기업들은 구조화된 형태로 많은 비즈니스 데이터를 저장하는 SaaS 플랫폼을 사용하고 있습니다. (예: 문서, 이미지, 스프레드시트와 같은 파일). 암호화 및 신뢰할 수있는 백업과 같은 데이터의 실제 저장 보안은 일반적으로 통제에서 요약됩니다. SaaS 애플리케이션은 사용자 계정을 관리할 수 있으며, 데이터에 액세스할 수 있는 데이터를 정의하고 데이터에 액세스할 수 있는 기능을 제공합니다.

Cloudflare는 주로 우리의 네트워크를 통해 여행하기 때문에 transit에 있는 자료를, 우리 또한 당신의 SaaS 신청에 연결하고 우리의 DLP 단면도를 사용하여 적절한 안전하골 그 때 행동을 가지고 가는 당신을 위한 권고를 제공하.

## Cloudflare CASB를 가진 보호 자료

Cloudflare의 API 구동[Cloud Access 보안 브로커](/cloudflare-one/integrations/cloud-and-saas/)(CASB)는 SaaS API를 통합하고 나머지 (documents, spreadsheets 등)에서 압축되지 않은 데이터를 모두 발견하고 응용 프로그램 및 사용자 계정의 일반적인 구성을 테스트하여 데이터 액세스 제어가 올바르게 구성되도록합니다.

[DLP 프로필](/cloudflare-one/cloud-and-saas-findings/casb-dlp/)SaaS 애플리케이션에 저장된 파일이 민감한 데이터를 포함합니다. 해당 이용 후기에 달린 코멘트가 없습니다.

Cloudflare CASB가 Cloudflare와 결합될 때[보안 웹 게이트웨이](/cloudflare-one/traffic-policies/)SaaS 응용 프로그램에서 모든 트래픽을 검사하는 서비스, 고객은 SaaS 응용 프로그램에 대한 나머지 데이터와 데이터에 대한 포괄적 인 가시성을 달성 할 수 있습니다.

## 데이터에 대한 사용자 접근

1. Cloudflare는 SaaS 애플리케이션에 액세스하려고 시도하고 관리 또는 관리되지 않은 엔드포인트에서 요청을 시작 여부.
   1. 관리된 엔드포인트를 위해, 우리는 우리의 배포를 추천합니다[공급 업체](/cloudflare-one/team-and-resources/devices/warp/)최종 사용자의 장치와 리소스 사이의 모든 트래픽의 가시성과 제어를 극대화합니다.
   2. unmanaged endpoints를 위해, 우리는 가지고 있습니다[고객 없는 솔루션](/reference-architecture/diagrams/sase/sase-clientless-access-private-dns/)데이터가 사용자에 접근할 수 있도록 항상 가시성을 확보하고 검사합니다.

2. Cloudflare의[Zero Trust 네트워크 접근](/cloudflare-one/access-controls/policies/)(ZTNA) 서비스는 직접 통합할 수 있습니다[SaaS 응용](/cloudflare-one/access-controls/applications/http-apps/saas-apps/)표준 프로토콜(e.g. SAML 또는 OIDC)를 사용하여 사용자 액세스의 초기 시행점이 되었습니다. 오시는 길[회사 소개](/cloudflare-one/integrations/identity-providers/)(IdP)의 선택과 사용자 및 장치에 대한 추가 보안 신호를 사용하여 정책 결정을 내립니다.

3. 사용중인 Securing 데이터에 포함 된 확장으로 Cloudflare[원격 브라우저 고립](/cloudflare-one/remote-browser-isolation/)(RBI)는 또한 함께 사용될 수 있습니다[전용 egress IP](/cloudflare-one/traffic-policies/egress-policies/dedicated-egress-ips/), 심지어 원격 clientless 사용자의 트래픽은 예측 가능한 일관된 IP 주소에서 요청한 SaaS 응용 프로그램에 도착 할 수 있습니다.

## 나머지 데이터 발견 및 보호

4. Transit, Cloudflare Data Loss Prevention (DLP)의 Securing 데이터에 포함 된 것은 민감한 데이터를 포함하는 SaaS 응용 프로그램에 의존하는 파일을 검색하는 데 사용할 수 있습니다. CASB는 모든 공유 및 / 또는 공개적으로 DLP 프로파일과 관련된 민감한 텍스트에 대한 SaaS 응용 프로그램에서 파일을 스캔하고 권장되는 작업을 경고합니다.

5. 위에서 언급 한 전용 egress IP 옵션을 보완하려면 SaaS 제공 업체는 특정 IP 주소에서 액세스 할 때 조직의 리소스에 대한 액세스를 제한 할 수 있습니다.

6. Cloudflare CASB와 타사 SaaS 애플리케이션을 통합할 때, CASB는 구성, 사용자, 파일 및 기타 SaaS 'objects'의 관련 메타 데이터를 분석하는 일상적인 API 호출을 만듭니다. 보안 문제 또는 'Findings'는 메타데이터가 통합된 SaaS 애플리케이션 내에서 어떤 insecure 또는 잠재적으로 위험한 구성이 존재하는지 여부를 기준으로 감지됩니다. 이 응용 프로그램 구성, 노출 및 / 또는 민감한 데이터를 포함 할 수 있으며, 사용자가 빈번한 보안 계정.

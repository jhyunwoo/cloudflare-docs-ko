## 제품정보

transit의 데이터는 일반적으로 네트워크에 여행 할 때 의미. 인터넷은 수천 개의 네트워크로 구성되어 있기 때문에 데이터가 서버와 뒤로 이동하므로 보안을 보장하는 것이 중요합니다. 이 일, transit에서 데이터를 생성하는 가장 일반적인 활동은 관련 :

- 온라인 검색 및 업로드/다운로드 데이터 to/from 클라우드 응용 프로그램
- 텍스트, 사진 및 이메일 보내기
- APIs를 통해 데이터 활용 및 분석

transit에 있는 자료는 수시로 변속 도중 방해 또는 탬퍼ing에 취약하게 고려됩니다, 그래서 그것은 암호화 기술을 통해서 그것을 보호하는 것이 중요합니다[견적 요청](https://cloudflare-quic.com/), 수송 층 안전 (TLS) 또는 안전한 소켓 층 (SSL). 이 데이터는 기밀 유지하고 여행 중에 무단 액세스로부터 보호하는 데 도움이됩니다. 데이터 검사의 다른 방법이 있습니다. 네트워크 경계를 통과하면 데이터가 계속 여행하거나 그렇지 않으면 데이터 손실 방지 (DLP) 기술은 네트워크 트래픽의 내용을 검사하고 위험 목적지로 이동하여 민감한 데이터를 차단하는 데 사용될 수 있습니다. 이 문서는 Cloudflare 방법을 설명합니다.

## Securing 네트워크 연결

Cloudflare는 클라우드 네트워크 보안 서비스의 선두 업체 중 하나입니다. 두 가지 주요 사용 사례 Cloudflare는 네트워크 트래픽을 확보하는 데 사용됩니다.

- SSL/TLS를 사용하여 공공 웹 사이트 및 API에 보안 연결을 제공
- 클라우드 또는 온프레미스에서 호스팅되는 개인 네트워크 및 응용 프로그램에 보안 터널 만들기

Cloudflare의[SSL 서비스](/ssl/)웹 사이트의 수백만에 의해 사용되며 DNS 항목에 변경하여 쉽게 구현되므로 공공 웹 사이트 및 API에 대한 모든 연결이 Cloudflare의 가장자리 네트워크에 종료됩니다. Cloudflare에서 대상 웹 사이트 또는 API로 연결은 동일한 SSL 기술을 사용하여 보안 할 수 있습니다. 가장 강한 보안을 보장하기 위해, Cloudflare 용도[포스트 퀀텀 암호화](https://blog.cloudflare.com/post-quantum-to-origins).

![그림 1 : 사용자 장치에서 데이터를 수집, 웹 사이트 / API에 모든 방법](~/assets/images/reference-architecture/securing-data-in-transit/securing-data-in-transit-fig1.svg "Figure 1: Securing data from the user device, all the way to the website/API")

1. TLS/SSL에 의해 보안되는 사용자 브라우저와 Cloudflare 사이 연결
2. Cloudflare에서 TLS/SSL에 의해 보호되는 목적지 서버에 연결

개인 자원, 일반적으로 자체는 직접 공용 인터넷 연결없이 개인 네트워크에 응용 프로그램을 호스팅, transit에서 데이터를 확보하는 다른 방법을 필요로한다. 터널이 개인 네트워크에서 Cloudflare로 만들 수 있는 다양한 방법이 있습니다.[SASE 참고 자료 건축](/reference-architecture/architectures/sase/), 하지만 다음 다이어그램은 좋은 일을 요약 방법.

![그림 2 : Cloudflare에 연결 및 라우팅 트래픽의 다양한 방법](~/assets/images/reference-architecture/cloudflare-one-reference-architecture-images/cf1-ref-arch-14.svg "Figure 2: Various methods of connecting and routing traffic to Cloudflare to secure private traffic.")

*참고: 이 이미지의 라벨은 이전 제품 이름을 반영할 수 있습니다.*

개인 응용 프로그램 및 네트워크가 Cloudflare에 연결되면, 장치가 사용자 장치에서 데이터와 같은 장치 에이전트를 통해 안전하게 연결 될 수 있습니다, 네트워크에서 응용 프로그램에 이르기까지 모든 방법은 보안 될 수 있습니다.

장치에서 트래픽이 호스트 응용 프로그램에 따라 모든 흐름 Cloudflare를 통해, 트래픽을 검사하고 데이터의 내용에 따라 더 보안을 적용 할 수 있습니다.

## Cloudflare DLP와 트래픽 검사

일반적인 도전은 데이터가 민감하고 정책 개입을 요구합니다. 데이터 손실 방지 서비스는 트래픽의 조각의 내용을 검사하는 데 사용되며, 정책에 metadata를 제공합니다.

예를 들어, 사용자가 SaaS 애플리케이션에 파일을 업로드하려고 시도하고 트래픽 경로는 항상 Cloudflare 네트워크를 통해 이동하도록 구성되었습니다.[모델 번호: Cloudflare DLP](/cloudflare-one/data-loss-prevention/)Gateway 정책에 할당된 DLP 프로파일을 사용하여 파일을 검사합니다. DLP 프로필 일치 후 게이트웨이 정책은 허용하거나 트래픽을 차단하고 활동은 로그에 기록됩니다. DLP 프로파일은 검색하려는 데이터 패턴을 정의하는 일반 표현 (일컬어 탐지 항목)의 모음입니다. Cloudflare DLP는 제공합니다[사전 정의 프로파일](/cloudflare-one/data-loss-prevention/dlp-profiles/#configure-a-predefined-profile)일반적인 탐지를 위해, 또는 당신은 건설할 수 있습니다[사용자 정의 프로파일](/cloudflare-one/data-loss-prevention/dlp-profiles/#build-a-custom-profile)데이터에 대한 특정, 심지어 레버리지 할 수있는 능력[Exact 데이터 일치](/cloudflare-one/data-loss-prevention/detection-entries/#exact-data-match)(EDM).

DLP 프로필은 다른 정책 속성과 조화하여 특정 트래픽을 식별하는 데 사용됩니다. 민감한 데이터가 승인 된 Cloud 기반 스토리지 서비스에 업로드 될 때 정책 만주의.

![그림 3 : Cloudflare 정책의 예는 승인 된 클라우드 저장소에 업로드 된 기밀 데이터를 차단합니다.](~/assets/images/reference-architecture/cloudflare-one-reference-architecture-images/cf1-ref-arch-29.svg "Figure 3: Example of a Cloudflare policy blocking confidential data uploaded to approved cloud storage.")

다음 다이어그램은 Cloudflare가 DLP 기반 정책에 따라 요청 및 시행 권한을 검사하는 방법을 일반적인 흐름을 보여줍니다.

![그림 4: Cloudflare DLP에 의해 차단되는 민감한 자료의 업로드](~/assets/images/reference-architecture/securing-data-in-transit/securing-data-in-transit-fig4.svg "Figure 4: Upload of file containing sensitive data blocked by Cloudflare DLP")

1. 사용자들은 SaaS 애플리케이션에 파일을 업로드하려고 합니다. (우리가 만든 Cloudflare에 안전한 터널을 통해[공급 업체](/cloudflare-one/team-and-resources/devices/warp/download-warp/)). [고객 지원](/cloudflare-one/networks/resolvers-and-proxies/)옵션도 지원됩니다.
2. Cloudflare의[보안 웹 게이트웨이](/cloudflare-one/traffic-policies/)(SWG)는 먼저 요청된 SaaS 응용 프로그램을 사용하도록 허용되고, 그 후에 파일의 페이로드를 scrutinize[악성 코드](/cloudflare-one/traffic-policies/http-policies/antivirus-scanning/)·[민감한 데이터](/cloudflare-one/data-loss-prevention/).
3. DLP 프로파일은 미국 사회 보안 번호 (SSN)와 같은 국가 식별자를 포함합니다.
4. Gateway 정책은 다음과 같습니다.[블록 작업](/cloudflare-one/traffic-policies/http-policies/#block), 그래서 시도는[이름 \*](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/#log-the-payload-of-matched-rules)·[블록 페이지](/cloudflare-one/reusable-components/custom-pages/gateway-block-page/)최종 사용자의 웹 브라우저로 반환됩니다.

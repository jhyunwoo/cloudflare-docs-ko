## 제품정보

Data in use는 애플리케이션, 시스템, 또는 사용자가 상호작용, 가공, 조작하는 데이터와 상호작용하고 있습니다. 조직의 데이터 보호에 대한 사용은 접근을 유지하고 그 의무를 충족해야하는 응용 프로그램 및 사용자에 의해 사용 될 수 있지만 여전히 무단 액세스 또는 타당성에 대한 보호.

오늘날, 조작상 데이터와 사용자의 상호 작용의 대다수는 오늘날 이메일 클라이언트, 워드 프로세서 및 스프레드 시트와 같은 전체 클라이언트 응용 프로그램을 가능하게 현대 인터넷 브라우저 내부에 배치됩니다. 최종 사용자에게 제공 할 수 있습니다. 이 소프트웨어는 장치에 설치되어야하며, 또한 복사 및 붙여넣기와 같은 사용자 상호 작용을 만들고 민감한 데이터를 다운로드하고 상대적으로 쉽습니다. 이러한 상호 작용은 직원과 계약자가 매일 중요하고 민감한 데이터와 함께 일하는 조직에 대한 지속적 위험을 감당할 수 있습니다.

보안 데이터에 대한 하나의 방법은 브라우저에서 더 큰 제어를 활용하고 직원은 애플리케이션 및 데이터에 액세스하는 방법을 사용합니다. Cloudflare는 우리의 대규모 세계적인 가장자리 네트워크의 정상에 우두머리 브라우저 해결책을 건축해서 이것을 접근했습니다,[원격 브라우저 고립](/cloudflare-one/remote-browser-isolation/)(RBI). 사용자가 액세스하려고 할 때, 예를 들어, 개인적으로 호스팅 된 리소스, 또는 공공 인터넷에 리소스, 대신 다른 금고가없는 사용자의 브라우저에 직접 제공, Cloudflare 먼저 Cloudflare 글로벌 네트워크에 호스팅 샌드 박스 환경에 리소스를 렌더링. 그런 다음, 최종 사용자에 대한 허용 차이없이, 작은 자바 스크립트 클라이언트는 로컬 브라우저에서 안전하고 안전하게 검색하고 새로로드 된 웹 콘텐츠를 렌더링, Cloudflare에 고유의 특허 기술, 네트워크 Vector Rendering (NVR)라고합니다.

## Cloudflare RBI와 사용에 있는 보호 자료

Cloudflare RBI는 효과적으로 웹 내용 사이에서 보이지 않는 “gap”를 창조합니다 사용자 접근 및 그들의 장치, 장치 보호하고 네트워크는 악용과 공격에서 연결됩니다. 안전한 웹 게이트웨이, 바이러스 백신 소프트웨어, 또는 알려진 위협 패턴 또는 서명에 의존하는 방화벽과는 달리 RBI는 진정한 제로 신뢰 메커니즘입니다. 원격으로 로드 된 RBI 인스턴스 내에서 만든 모든 요청이 Cloudflare Secure Web Gateway를 통해 이동, 데이터에 액세스 정책을 시행하고 또한 교통 자체를 검사 할 수 있습니다 transit 정책.

또한, 조직은 다운로드 / 업로드, 복사 및 붙여넣기 및 인쇄 데이터를 차단 같은 사용 액세스 제어에 특정 데이터를 강제 할 수 있습니다.

RBI와 함께 사용되는 일반적인 정책:

- 내용 범주 -[소셜 네트워크](/cloudflare-one/traffic-policies/domain-categories/)(e.g. Facebook): 대중적인 소셜 미디어 플랫폼 수집하는 데이터의 큰 볼륨을 주기적으로, 이 앱은 매력적 표적이고 그러나 악의적인 entities를 위한 다른 공격 벡터입니다. RBI는 이 응용 프로그램에 붙여진 DLP 프로파일과 일치하면 데이터가 어떤 데이터를 제한 할 수 있습니다.
- 신청 -[인공지능](/cloudflare-one/traffic-policies/application-app-types/)(e.g. ChatGPT) : Generative AI 도구는 직원 생산성을 높일 수 있지만, 이를 사용하는 것에 대한 이해와 유전적 AI 진화의 이 단계에서 불완전한 것. 다시, DLP 프로파일은 여기에 공개 AI 도구로 민감한 데이터의 복사 및 붙여넣기 방지하기 위해 적용 될 수있다.
- 신청 -[SaaS 서비스](/cloudflare-one/traffic-policies/application-app-types/)(예: Salesforce, Zendesk 등): 이 응용 프로그램은 종종 높은 기밀 데이터를 포함 할 수 있습니다. RBI는 계약자 또는 파트너와 같은 일부 액세스가 필요한 위험한 사용자에 대한 액세스를 잠글 수 있습니다. 인쇄를 방지하거나 모든 키보드 입력을 방지하는 것과 같은 제어는 RBI가 사용자와 데이터 사이의 유리의 팬이라면 응용 프로그램의 읽기 전용보기를보고 타사 사용자 만보고 할 수 있습니다.

다음 다이어그램은 ChatGPT와 같은 사용자, RBI 및 웹 사이트 간의 전형적인 상호 작용을 시각화합니다.

![그림 1: Cloudflare RBI에 의해 막힌 원본 사본/약.](~/assets/images/reference-architecture/securing-data-in-use/securing-data-in-use-fig1.svg "Figure 1: Text copy/paste blocked by Cloudflare RBI.")

1. 사용자는 ChatGPT에 로그인하려고 시도하고 사용자는 사용자가 실행되기 때문에 Cloudflare를 통해 요청이 진행됩니다.[공급 업체](/cloudflare-one/team-and-resources/devices/warp/download-warp/)최종 사용자의 장치와 리소스 사이의 모든 트래픽의 가시성과 제어를 극대화합니다.[고객 지원](/cloudflare-one/networks/resolvers-and-proxies/)옵션도 지원됩니다.
2. Cloudflare의[보안 웹 게이트웨이](/cloudflare-one/traffic-policies/)(SWG)는 먼저 ChatGPT에 접속할 수 있음을 확인합니다.
3. Cloudflare의 특허받은 네트워크 Vector Rendering (NVR) 프로세스는 우리의 가장자리 네트워크에 머리없는 브라우저로 시작하고 SKIA draw 명령을 작성하는 웹 응용 프로그램을 래스터화합니다.
4. NVR는 그 draw 명령을 가로 질러 > 토큰화 > 압축 > 암호화 > 로컬 웹 브라우저에 보냅니다.
5. 이 요청은 격리되어 있기 때문에, 정책은 또한 사용자를 방지합니다.[복사 및 붙여넣기](/cloudflare-one/remote-browser-isolation/isolation-policies/#copy-from-remote-to-client)로컬 머신에서 ChatGPT에 민감한 콘텐츠. 기타 제품[정책 설정](/cloudflare-one/remote-browser-isolation/isolation-policies/#policy-settings)‘Disable printing’와 같은, ‘Disable upload / download’, 그리고 더 많은 것은 유효합니다.

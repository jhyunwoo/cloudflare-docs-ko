## 제품정보

Serverless APIs는 전통적인 서버 인프라를 관리하지 않고 확장 가능한 신뢰할 수있는 응용 프로그램 인터페이스 (APIs)를 구축하고 배포하는 현대적인 접근 방식을 나타냅니다. 이 API는 사용자 또는 다른 시스템에서 수신 요청을 처리하도록 설계되었으며 필요한 논리 또는 작업을 수행하고 개발자가 서버에서 제공하거나 관리 할 필요없는 응답을 반환합니다.

Serverless APIs의 핵심은 서버가 없는 컴퓨팅의 개념이며, 개발자는 서버 프로비저닝, 스케일링, 유지 보수와 관련하여 비즈니스 로직을 구현하기 위해 작성 코드를 작성하는 데 초점을 맞추고 있습니다. API 기반 애플리케이션을 위한 더 큰 agility 및 더 빠른 Time-to-market을 허용합니다.

Developers는 API 엔드포인트와 해당 로직 또는 기능 또는 microservices를 사용하여 기능을 정의합니다. 그런 다음 serverless 플랫폼에 배포됩니다. 플랫폼은 수신 요청에 응답에서 이러한 함수의 실행을 처리합니다.

또한 Serverless APIs는 인증 및 인증 서비스, 데이터베이스 및 이벤트 구동 아키텍처와 같은 다른 클라우드 서비스와 원활하게 통합되어 개발자가 최소한의 작동 오버 헤드와 복잡한 확장 가능한 확장 가능한 응용 프로그램을 구축 할 수 있도록합니다.

대부분의 클라우드 서버리스 구현에는 코드가 실행되는 단일 영역이 있습니다. 이것은 어떤 요청을 의미, 세계 어디서나에서, 인터넷을 가로 질러이 단일 위치로 얻을 수 있어야합니다. API 요청에 대한 모든 응답은 동일한 인터넷 경로로 다시 전송해야합니다.

![그림 1 : 전통 단일 종교 건축](~/assets/images/reference-architecture/serverless-global-apis/single-region.png "Figure 1:  Traditional single-region architecture")

Cloudflare는 다른, 세계적인 첫번째 접근을 따릅니다. Globally-deployed Architectures는 전 세계의 다른 부분에서 API에 액세스하는 사용자들에게 낮은 대기시간과 높은 가용성을 가능하게 합니다. 성능 이득을 실현하기 위해, 뿐만 아니라 compute는 배포되어야하지만, 이상적으로 데이터뿐만 아니라. 캐싱 및 글로벌 복제와 같은 다른 솔루션은 이를 가능하게 할 수 있습니다.

![그림 2: 지구 지구](~/assets/images/reference-architecture/serverless-global-apis/region-earth.png "Figure 2:  Region Earth")

전반적으로 Serverless Globally-deployed APIs는 현대 애플리케이션 및 서비스를 구축하는 데 비용 효율적인 확장성 및 가성적 접근을 제공하여 조직이 인프라 관리의 복잡성을 확보하지 않고 사용자에게 가치를 제공 할 수 있습니다.

## Serverless 글로벌 API

![그림 3 : Serverless 글로벌 API](~/assets/images/reference-architecture/serverless-global-apis/serverless-global-apis.svg "Figure 3: Serverless global APIs")

이것은 Cloudflare에 serverless API의 건축술이고 다른 compute와 자료 제품이 서로 상호 작용할 수 있는 방법을 설명하는 것을 목표로 합니다.

1. **고객 요청**: API endpoint에 요청을 보냅니다.
2. **API Shield/로이터**: 사용방법[모델 번호: Workers](/workers/), 유효성 검사 및 필요한 경우 인증 논리 수행. 그런 다음 (전적으로 변환 및 / 또는 enriched) API 호출을 개별화합니다.[모델 번호: Workers](/workers)이름 \*[서비스 바인딩](/workers/runtime-apis/bindings/service-bindings/). 이것은 우려의 별거를 허용합니다.
3. **Read-heavy 데이터**: 읽기[모델 번호: KV](/kv/)read-heavy, 비 역학 데이터를 제공합니다. 이것은 구성 자료 또는 제품 정보를 포함할 수 있었습니다. 자주 묻는 질문[제한 사항](/kv/platform/limits/)자주 묻는 질문
4. **관련 자료**: 문의[모델 번호: D1](/d1/)관계 자료 처리. 이것은 사용자 데이터, 제품 데이터 또는 기타 데이터를 포함 할 수 있습니다.
5. **외부 자료**: Query 외부 데이터베이스 사용[모델 번호: Hyperdrive](/hyperdrive/). 적용 가능한 성능 향상을 위한 활용 이 데이터 마이그레이션이 구현 범위 내에서 특히 도움이 될 수 있습니다.

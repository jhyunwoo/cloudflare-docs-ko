## 제품정보

Object Storage는 기존의 파일 시스템과 같은 계층 구조보다 오히려 객체로 데이터를 저장하는 현대적인 데이터 저장 접근 방식이며, 객체 저장을 고도로 확장하고 다양한 애플리케이션과 환경에 걸쳐 데이터의 광대한 양을 관리할 수 있습니다.

Astentimes 조직은 여러 클라우드 공급자를 활용하여 다양한 플랫폼에서 워크로드를 배포하고, 공급 업체 잠금에서 관련된 위험을 완화하고 탄력을 강화하고 성능과 비용을 최적화합니다. 그러나 여러 클라우드의 데이터 관리는 데이터 이동성 및 상호 운용성, 특히 클라우드 공급자 또는 온프레미스 환경 간의 데이터를 전송하는 데 사용될 때 문제들을 소개합니다.

Egress 수수료는 클라우드 공급자의 네트워크로 전송될 때, 다른 클라우드 공급자, 온프레미스 인프라 또는 외부 서비스로 전송됩니다. 이러한 수수료는 데이터 전송의 양과 같은 요인에 따라 달라질 수 있으며, 데이터의 대상, 네트워크 대역폭 활용.

[모델 번호: R2](/r2/)일반적인 클라우드 스토리지 서비스와 관련된 비용의 egress 대역폭 수수료를 충전하지 않고 엔티티싱 가치 제안. AI 모델 교육, 쿼리 엔진 및 기타 데이터 과학 도구와 같은 compute-intensive workloads를 실행 할 때 특히 멀티 클라우드 환경의 상황에 매우 유용합니다.

## R2 멀티 클라우드 설정

![그림 1: R2 멀티 클라우드 설정](~/assets/images/reference-architecture/r2-multi-cloud/r2-multi-cloud.svg "Figure 1: R2-multi-cloud setup")

1. **노동자와 R2 상호 작용**: R2의 사용[모델 번호: Workers](/r2/api/workers/workers-api-reference/)작업자에서 R2와 상호 작용합니다. 대안으로, 개량한 휴대성을 위해, 사용 R2's[사이트맵](/r2/api/s3/)작업자에서. R2 egress 수수료는 없습니다.
2. **외부 서비스 및 R2 상호 작용**: R2의 사용[사이트맵](/r2/api/s3/)외부 서비스에서 R2와 상호 작용합니다. R2 egress 수수료는 없습니다.

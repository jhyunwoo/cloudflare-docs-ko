## 제품정보

오늘날의 급속하게 진화하는 디지털 풍경에서 조직은 점점 클라우드 마이그레이션을 구현하여 환경을 현대화하고 생산성을 향상시킵니다. Microsoft는 클라우드 애플리케이션 및 서비스의 선도적 인 공급자로서 하이브리드 작업을 지원하는 솔루션의 포괄적 인 제품군을 제공합니다. 그러나 클라우드로 이동하면 조직의 자원의 보안과 무결성을 보장하기 위해 해결해야 할 새로운 도전과 위험이 있습니다.

하이브리드 및 멀티 클라우드 환경에 대한 조직으로, 그들은 종종 서비스 (SaaS), 자체 호스팅 및 비 웹 응용 프로그램으로 소프트웨어의 조합을 관리의 복잡성을 직면. 이 신생 생태계는 이러한 자원에 대한 보안 및 제어의 과정을 보완 할 수 있습니다. 또한 레거시, 종종 온프레미스, Virtual Private Network (VPN) 솔루션에 의존하여 사용자가 애플리케이션에 안전하게 연결할 수 있는 보안 격차 및 직원 생산성을 도입할 수 있습니다.
이러한 도전을 극복하고 더 큰 보안 결과를 달성하려면 조직은 클라우드 보안 및 성능 솔루션의 선두 업체 인 Cloudflare와 파트너 관계를 맺을 수 있습니다. Cloudflare는 Microsoft의 클라우드 생태계와 원활한 통합을 제공하며 보안 격차를 제거하고 성능을 향상시키고 하이브리드 작업 환경에서 신뢰성을 보장합니다.

이 참고 자료 건축 도표에서는, 우리는 Cloudflare의 안전한 접근 서비스 가장자리 (SASE) 플랫폼과 마이크로소프트의 구름 신청 및 서비스의 조합이 당신에게 Zero Trust 안전 자세를 달성하고 잡종 일을 위한 포괄적인 안전을 제공하는 동안 구름 현대화와 생산력을 가속하는 방법을 탐구할 것입니다. Cloudflare의 보안 네트워크 액세스, 위험 사용자 격리 및 응용 프로그램 및 데이터 가시성을 활용하여 조직은 통합 인터페이스를 통해 관리하고 위치와 관계없이 모든 리소스에 안전하게 액세스 할 수 있습니다.

## Microsoft Cloudflare의 통합

Cloudflare의[Zero Trust 네트워크 접근](https://www.cloudflare.com/zero-trust/products/access/)(ZTNA)는 전통적인 VPN에 빠르고 안전한 대안을 제공합니다. On-premises VPN 인프라를 대체하고 온프레미스 네트워크, 공공 클라우드 또는 소프트웨어로 서비스(SaaS)로 호스팅되는지 여부에 관계없이 모든 애플리케이션을 보호합니다. Microsoft Intune 및 Microsoft Entra ID (이전 Azure Active Directory)와 통합함으로써 Cloudflare의 ZTNA 서비스는 기본 밀도, Zero Trust 규칙을 시행하고 사용자 ID 및 장치 자세를 기반으로 내부 리소스에 대한 조건 액세스를 제공합니다.

마이크로소프트와 Cloudflare는 뒤에 오는 방법에 통합될 수 있습니다.

- Microsoft 사용[엔트라 ID](https://learn.microsoft.com/en-us/entra/fundamentals/whatis)모든 Cloudflare 보호 리소스에 대한 인증
- Microsoft 활용[언어 선택](https://learn.microsoft.com/en-us/mem/intune/fundamentals/what-is-intune)Cloudflare 정책에 있는 장치 자세는, 믿을 수 있는 장치만 보호한 자원에 접근합니다
- Cloudflare 사용하기[캐스 번호:](/cloudflare-one/integrations/cloud-and-saas/)당신의 선택[마이크로 소프트 365](https://www.microsoft.com/en-us/microsoft-365/what-is-microsoft-365)incorrectly 설정된 계정 및 민감한 데이터를 포함하는 공유 파일에 대한 보안 검색에 대한 경고
- Cloudflare의 사용[보안 웹 게이트웨이](/cloudflare-one/traffic-policies/)Outlook, OneDrive 및 Teams와 같은 Microsoft SaaS 응용 프로그램에 대한 액세스를 제어
- Cloudflare의 사용[이메일 보안](/email-security/)피싱 공격 및 비즈니스 이메일 손상에서 이메일의 보호를 증가 서비스.

### Cloudflare를 가진 Microsoft Entra ID

Entra ID와 Cloudflare의 통합은 Cloudflare 보호 응용 프로그램에 대한 Entra에서 인증을 위해 엔트라의 식별자를 활용할 수 있습니다. 그룹은 SCIM을 통해 Entra ID의 그룹 회원 관리에 의해 관리 및 요약 액세스 제어를 단순화하여 액세스 정책에 사용될 수 있습니다.

- Entra ID는 관리자가 조건 액세스 정책을 사용하여 응용 프로그램 및 사용자에 대한 정책을 만들고 시행 할 수 있습니다.
- 사용자의 위험 수준, Sign-in 위험 수준, 장치 플랫폼, 위치, 클라이언트 앱 등과 같은 애플리케이션에 사용자 액세스를 제어하는 다양한 매개 변수를 제공합니다.
- 보안 팀은 Entra ID에서 보안 제어를 정의하고 네트워크 레이어에서 시행 할 수 있습니다. Cloudflare의 ZTNA 서비스와 함께 모든 요청을 위해.

### Cloudflare를 가진 Microsoft Intune

Cloudflare는 장치 자세에 관하여 정보를 포함하는 접근 정책을 시행할 수 있습니다. Intune는 Cloudflare로 통합될 수 있습니다 그래서 Intune에 관하여 정보 관리하고 보호한 장치는 Cloudflare에 접근 제한을 시행하기 위하여 이용될 수 있습니다.

- 연결되는 장치로[이름 \*](/cloudflare-one/team-and-resources/devices/warp/), Cloudflare의 ZTNA 서비스는 사용자의 장치 자세 및 준수 상태에 대한 Intune에 의해 제공된 향상된 원격 측정 및 컨텍스트를 활용할 수 있습니다.
- Intune는 보안 상태 및 사용자 장치의 구성에 대한 자세한 정보를 제공하며 더 많은 정보를 제공합니다 액세스 제어 결정.
- 이 통합을 통해 관리자는 중요한 네트워크 및 응용 프로그램에만 적합하고 안전한 장치를 부여할 수 있습니다.

### Microsoft 365를 위한 Cloudflare CASB

수많은 SaaS 애플리케이션을 채택하여 일관된 보안, 가시성 및 성능 유지가 더욱 어렵습니다. 각 응용 프로그램을 통해 독특한 구성 및 보안 요구 사항, IT 팀은 다양한 풍경을 통해 민감한 데이터를 유지하고 보호하는 데 어려움을 직면.

Cloudflare CASB (Cloud Access Security Broker)는 Microsoft 365 및 기타 인기있는 SaaS 응용 프로그램에 대한 광범위한 가시성을 제공함으로써 이러한 문제를 해결합니다. 이 가시성은 조직이 신속하게 구성, 노출된 파일, 사용자 액세스 및 타사 액세스를 식별하고 보안 및 준수 SaaS 환경을 보장합니다.

당사의 CASB 솔루션에 대해 자세히 알아보기[데이터 보호](/reference-architecture/diagrams/security/securing-data-at-rest/).

### Cloudflare의 Microsoft SaaS 응용 프로그램에 대한 향상된 보안을위한 보안 웹 게이트웨이

Cloudflare의 보안 웹 게이트웨이 (SWG)는 조직이 다음 방법에서 Microsoft 365에 안전하고 안전하게 액세스 할 수 있도록 도와줍니다.

1. 교통 검사 및 필터링 : Cloudflare의 SWG는 Microsoft 365에 트래픽을 포함하여 인터넷에 대한 모든 사용자 및 장치 트래픽을 탐지합니다. 조직은 보안 정책, 콘텐츠 필터링 및 위협 방지 조치를 적용하여 합법적이고 공인 트래픽은 Microsoft 365 서비스에 도달합니다.
   위에서 본 것처럼, 정책은 Microsoft 365 및 Azure 플랫폼의 일부에 액세스 할 수 있도록 관리 할 수 있도록 설계되었습니다.
2. DLP 프로파일 데이터 보호 : 트래픽은 장치 자세 및 정체 정보에 근거하여 검사되지 않지만 DLP 엔진은 요청의 내용을 확인하고 허용 / 블록 다운로드 / Microsoft 365 및 Azure에서 기밀 정보의 업로드를 검토 할 수 있습니다.
3. Enforce Cloudflare Gateway: Microsoft 365는 IP 주소의 특정 범위에서만 사용자 트래픽을 수용 할 수 있습니다. Cloudflare는 SWG를 떠나는 모든 트래픽에 첨부된 IP 주소를 정의하고 연관시킬 수 있습니다. 이 조직은 Cloudflare SWG에 의해 지정 된 IP 주소 범위에서 오는 트래픽을 수용 할 수 있다는 것을 의미하며 모든 트래픽이 검사되고 Microsoft 365에 도달하기 전에 Cloudflare의 보안 정책에 의해 승인되었습니다.

Cloudflare SWG를 Microsoft 365 액세스에 대한 보안 게이트웨이로 레버리지함으로써 조직은 고급 위협 보호, 과립 액세스 제어, 교통 검사 및 중앙화 된 가시성에서 혜택을 누릴 수 있으며 사용자가 안전하고 안전한 환경을 보장하며 위험과 유지 준수를 보장합니다.

### Cloudflare의 이메일 보안 향상 이메일 보호

Phishing은 금융 손실과 브랜드 손상으로 이어지는 breaches의 90 %의 뿌리 원인입니다. Cloudflare의 이메일 보안 솔루션은 Microsoft 365 tenant로가는 모든 이메일 앞에 앉아 스팸, 대량, 악성 및 spoof 콘텐츠를 필터링합니다. 솔루션은 Microsoft를 활용할 수 있습니다.[quarantine 행동 규칙](/email-security/deployment/inline/setup/office-365-area1-mx/use-cases/four-user-quarantine-admin-quarantine/), 다른 이메일 탐지가 처리되는 방법을 미세 조정 할 수 있습니다.

![그림 3: 클라우드 이메일 보안은 모든 Microsoft 365 inboxes를 보호합니다.](~/assets/images/reference-architecture/cloudflare-sase-with-microsoft/cloudflare-sase-with-microsoft-fig3.svg "Figure 3: Cloud email security protects all Microsoft 365 inboxes.")

클라우드 이메일 보안을 구성할 수 있습니다.[API를 통해 Microsoft 365 inboxes](/email-security/deployment/api/), 기존 DNS 레코드로 변경할 필요가 피.

## 제품정보

Cloudflare와 Microsoft 통합을 활용하면 조직은 전통적인 네트워크 보안 모델의 한계를 넘어서는 Zero Trust 보안 태세를 구축할 수 있습니다. Cloudflare의 Zero Trust Network Access(ZTNA)를 통해 조직은 자체 호스팅 VPN을 대체하고 사용자 신원과 장치 posture에 기반한 조건부 액세스를 적용할 수 있습니다. Microsoft Entra ID와의 통합은 인증과 액세스 제어를 제공하고, Microsoft Intune은 장치 posture 정보를 제공합니다. 또한 Cloudflare의 CASB는 Microsoft 365 구성의 보안 상태에 대한 가시성을 제공하고, Secure Web Gateway는 Microsoft 365로 향하는 트래픽을 검사 및 필터링하며, Email Security는 피싱 공격을 방어해 안전하고 규정을 준수하는 환경을 보장합니다. 이러한 접근 방식은 애플리케이션에 더 빠르고 안전하게 액세스할 수 있도록 하며, 신원과 장치 posture를 기준으로 사용자 액세스를 세밀하게 제어할 수 있게 해 줍니다.

## 한국어

이 참고 자료 아키텍처는 Cloudflare 및 CrowdStrike 솔루션이 통합된 보안 생태계를 구축하여 네트워크 액세스, 위협 인텔리전스 공유 및 자동화된 구제 워크플로우와 엔드포인트 보호를 결합합니다. 조직은 위험 기반 액세스 정책을 구현하기 위해이 통합을 활용할 수 있으며 위협 감지 및 두 플랫폼의 관현악 보안 응답을 향상시킵니다.

## 제품정보

오늘날의 사이버 보안 풍경은 복잡한 과제로 조직을 제시합니다. 원격 작업, 클라우드 마이그레이션 및 정교한 위협에 의해 생성 된 확장 공격 표면은 엔드포인트 보호, 네트워크 보안 및 정체성 관리에 대한 공동 접근 방식을 요구합니다.

모델 번호: Cloudflare One and CrowdStrike Falcon®는 이러한 도전에 강력한 통합 솔루션을 제공합니다. Cloudflare의 보안 네트워크 및 Zero 신뢰 기능을 갖춘 CrowdStrike의 업계 최고의 보안 플랫폼을 결합함으로써 조직은 자동화 및 정책 일관성을 통해 관리하면서 장치 및 네트워크 트래픽을 모두 안전하게 보호할 수 있습니다.

### 왜 Cloudflare와 CrowdStrike를 통합합니까?

**Context-aware 제로 신뢰:**&#x49;dentity는 더 이상 신뢰를 위해 충분하지 않습니다. Cloudflare 액세스는 실시간 Falcon Zero Trust 평가 (ZTA)는 동적, 위험 기반 정책을 시행하기 위해 점수를 매깁니다. 이것은 건강하고 준수로 검증된 기기만이 민감한 리소스에 접근할 수 있도록 사용자 자격 증명이 유효한 경우에도 손상된 엔드포인트를 효과적으로 차단합니다.

**가시성 및 장시간 탐지 및 응답 (XDR):**&#xB124;트워크 및 엔드포인트 데이터는 종종 분리된 사일로에 의존합니다. 이 통합 스트림 Cloudflare의 풍부한 네트워크 로그 (Cloudflare 게이트웨이, Cloudflare 웹 응용 프로그램 방화벽 (WAF) 및 Cloudflare 이메일 보안 서비스) CrowdStrike Falcon® Next-Gen SIEM에 직접. 이 통합된 전망은 공격 사슬의 완전한 그림을 제공하는 특정 엔드포인트 프로세스를 사용하여 네트워크 블록을 correlate 할 수 있습니다.

**자동화된 치료:**&#x43;loudflare 및 CrowdStrike의 연결 강제 포인트로 보안 팀은 수동 반응에서 자동화된 보호로 이동할 수 있습니다. endpoint에 감지 된 위협은 네트워크 가장자리 (과 vice versa)에서 즉각적인 블록을 트리거 할 수 있으며, 위험 감소 및 작동 오버 헤드가 증가하지 않고 응답 시간 (MTTR)을 의미합니다.

### 핵심 통합점

Cloudflare와 CrowdStrike의 통합은 장치 보안 자세가 직접 액세스 결정에 영향을 미치는 강력한 보안 생태계를 만듭니다. 사용자가 응용 프로그램에 액세스하려고 할 때, Cloudflare CrowdStrike Falcon® 에이전트의 보안 평가, 지원 제공 업체의 사용자 정체성 및 추가 컨텍스트 정보를 확인하여 요청을 확인합니다. 모든 정책 요구 사항이 충족 될 때만 액세스가 부여되며 보안 장치만 민감한 리소스에 도달 할 수 있습니다.

이 지속적인 검증 과정은 플랫폼 간의 양방향 데이터 공유에 의해 강화됩니다.

1. **장치 자세 평가:**&#x43;rowdStrike의 실시간 Zero Trust 평가 (ZTA) 원격 측정은 Cloudflare Zero Trust 액세스 결정에 대해 알려줍니다.
2. **통합 보안 로깅:**&#x43;loudflare는 CrowdStrike의 Falcon Next-Gen SIEM에 보안 원격 측정을 전달합니다.
3. **이메일 보안 정보:**&#x43;loudflare 이메일 보안 경고는 CrowdStrike의 로깅 및 분석 도구로 공급합니다.
4. **자동화된 치료 작업 흐름:**&#x43;rowdStrike Falcon Fusion SOAR를 통해 관현악 된 두 플랫폼에서 자동화 된 응답을 조정하는 보안 이벤트 트리거.

## 통합 아키텍처 개요

Cloudflare와 CrowdStrike의 통합은 양방향 인텔리전스 교환에 중점을 둔 종합 보안 아키텍처를 수립합니다. 이 생태계는 Zero 신뢰 네트워크 액세스 및 자동화 된 응답으로 장치 엔드포인트 보안을 연결합니다.

건축은 뒤에 오는 열쇠 교류에 의해 정의됩니다:

- **Zero 신뢰 접근 제한:**
  - 사용자의 엔드포인트는 Cloudflare WARP 클라이언트와 CrowdStrike Falcon 대리인을 모두 실행합니다.
  - CrowdStrike Falcon Device Posture 및 ZTA 점수는 서비스 API를 통해 Cloudflare와 공유됩니다.
  - Cloudflare는 Cloudflare에 있는 긴요한 요인으로 이 순간 장치 건강 정보를 이용합니다 액세스 결정, 공공 및 민간 응용 프로그램에 대한 제로 신뢰 정책을 적용.
- **통합된 보안 telemetry:**
  - Cloudflare는 CrowdStrike Falcon NextGen SIEM에 네트워크 및 보안 로그 (Logpush를 통해)를 중앙 집중식 상관 관계, 분석 및 위협 탐지를 보냅니다.
- **자동화된 치료:**
  - CrowdStrike 플랫폼에서 보안 이벤트 및 위협 감지는 자동화된 보조 및 응답 워크플로우를 자동화하고 Falcon Fusion SOAR (보안 오케스트라션, 자동화 및 응답)을 통해 오케스트라를 통해 올랐습니다. API 자동화를 활용하면 두 플랫폼에서 양방향 조치를 취합니다.

이 통합된 접근은 다양한 애플리케이션 유형에 안전한 접근을 가능하게 합니다:

- 인터넷 애플리케이션 (SaaS, 웹 앱)
- Self-hosted 응용 프로그램 (내부, 데이터 센터)
- SaaS 애플리케이션( identity proxy를 통해 보호)

### 핵심 사용 사례

Cloudflare와 CrowdStrike의 통합은 중요한 보안 문제를 해결하는 6 가지 사용 사례를 제공합니다.

#### 1. [Zero trust access with device posture 및 사용자 위험 점수](#use-case-detail-zero-trust-with-user-and-device-risk-posture)

**도전:**&#xD558;이브리드 인력으로, 사용자는 기존 방화벽 제어를 우회하여 기업 둘레 밖에 개인 또는 감염된 장치에서 민감한 응용 프로그램을 액세스합니다.

**해결책:**&#x43;loudflare 액세스 정책에 직접 CrowdStrike Falcon ZTA 점수를 통합하여 실시간 조건 액세스를 시행합니다.

#### 2. [통합 위협 사냥](#use-case-detail-unified-threat-hunting)

**도전:**&#x53;ecurity Analysts는 별도의 사일로 데이터가 남아 있기 때문에 특정 엔드포인트 행동으로 네트워크 경고 (예 : 차단 된 악의적 인 도메인)를 correlate로 투쟁합니다.

**해결책:**&#xC2A4;트림 Cloudflare Gateway, WAF 및 중앙 분석을위한 CrowdStrike Falcon Next-Gen SIEM에 Logpush를 통해 이메일 보안 로그.

#### 3. [자동화된 가장자리 치료](#use-case-detail-automated-edge-remediation)

**도전:**&#xC218;동 사건 응답은 자동화된 공격을 멈추기 위하여 너무 느립니다. analyst가 경고를 볼 때, adversary는 이미 나중에 이동하거나 exfiltrated 자료가있을 수 있습니다.

**해결책:**&#xB808;버리지 CrowdStrike Falcon Fusion SOAR는 Cloudflare 내에서, 검출된 위협을 기반으로 합니다.

#### 4. [Compromised 사용자 수명주기: 탐지 및 응답](#use-case-detail-compromised-user-lifecycle--detection-and-response)

**도전:**&#xC0AC;용자의 노트북은 악성 코드로 감염됩니다. 엔드포인트 탐지 및 응답 (EDR) 도구는 감지 할 수 있지만, 사용자는 여전히 SaaS 앱과 민감한 데이터를 액세스 할 수 있도록 유효한 세션 토큰이 있습니다.

**해결책:**&#x65;ndpoint 탐지가 즉시 네트워크 액세스 및 트리거 조사를 취소하는 닫히는 루프 응답.

#### 5. [Insider 위협 및 데이터 보호](#use-case-detail-insider-threat-and-data-protection)

**도전:**&#xCD9C;발 직원은 개인 클라우드 스토리지 사이트에 독점 소스 코드를 업로드하려고합니다. 트래픽은 암호화되고 장치는 "건강"이며 표준 체크를 우회합니다.

**해결책:**&#x43;loudflare 데이터 손실 방지 (DLP) CrowdStrike 행동 분석을 사용하여 데이터 도난을 감지하고 차단합니다.

#### 6. [Proactive 애플리케이션 방어](#use-case-detail-proactive-application-defense)

**도전:**&#x41;ttackers는 자동화된 botnets를 사용하여 취약점을 스캔합니다. WAFs 블록 알려진 시그니처, 하지만 낮은 및 슬로우 공격은 일반 필터를 통해 슬립 할 수 있습니다.

**해결책:**&#xC6F9; 자산에 면역 체계를 창조하는 애플리케이션 보안을 알리는 endpoint 데이터를 사용합니다.

## 사용 케이스 세부 사항 : 사용자 및 장치 위험 자세로 Zero 신뢰

이 사용 사례는 통합이 기업 리소스에 액세스하여 손상되거나 관리되지 않는 장치를 방지하는 방법을 보여줍니다.

### 단계 1: 장치 및 사용자 위험 평가

CrowdStrike Falcon 에이전트는 OS 건강, 패치 레벨 및 위협 활동을 기반으로 ZTA 점수 (1-100)를 계산하는 엔드 포인트를 지속적으로 모니터링합니다. 병렬에서 Cloudflare는 사용자 및 법인 행동 분석 (UEBA)을 기반으로 사용자 위험 점수를 지속적으로 업데이트합니다.

### 단계 2: 정책 평가

사용자 요청이 응용 프로그램에 액세스 할 때, Cloudflare 액세스는 요청을 가로 질러 장치의 현재 ZTA 점수에 CrowdStrike API를 쿼리합니다.

### 단계 3: 접근 강제

Cloudflare는 ZTA 점수가 0 신뢰 정책에서 정의 된 최소 임계값을 충족하는 경우에만 연결 권한을 부여합니다. 그렇지 않으면 사용자는 Cloudflare Access Block Page로 표시되며 일반적으로 장치를 재조정합니다.

## 사용 케이스 세부 사항: Unified 위협 사냥

이 사용 케이스는 네트워크 트래픽과 엔드포인트 활동 사이에 포괄적인 가시성을 제공에 초점을 맞추고 있습니다.

### 단계 1: 자료 섭취

모델 번호: Cloudflare Logpush 필터와 HTTP 요청, DNS 쿼리 및 방화벽 이벤트를 Falcon Next-Gen SIEM 데이터 섭취 API로 전달합니다.

### 단계 2: 상관

Falcon Next-Gen SIEM은 endpoint telemetry와 함께이 데이터를 색인하여 단일 데이터 세트를 쿼리 할 수 있습니다.

### 단계 3: 조사

endpoint alert는 Cloudflare를 통해 만든 모든 네트워크 요청을 볼 수 즉시 피벗을 수 있으며 감염된 피싱 사이트 또는 C2 서버를 식별합니다.

## 케이스 세부 사항: 자동화된 가장자리 요법

이 사용 사례는 CrowdStrike Falcon Fusion SOAR을 구현하는 방법을 설명합니다. MTTR을 빠르게 진화하는 위협으로 줄일 수 있습니다.

### 단계 1: 위협 탐지

CrowdStrike Falcon은 악성 IP 주소와 같은 타협 (IOC)의 특정 지표를 여러 엔드포인트 공격합니다.

### 단계 2: 관현

Falcon Fusion SOAR 워크플로우는 검출에 의해 트리거됩니다.

### 3 단계 : 가장자리 완화

Falcon Fusion SOAR는 대응 플레이북을 자동화합니다. 엔드포인트를 격리하고(네트워크 격리), 사용자를 Cloudflare의 사용자 지정 목록에 추가하여 Falcon Next-Gen SIEM에서 더 깊은 사후 분석을 할 수 있도록 로그에 태그를 남기며, 해당 사용자 지정 목록에 연결된 추가 정책도 함께 적용합니다.

![위협 감지에서 자동화된 가장자리 제거 워크플로우](~/assets/images/reference-architecture/cloudflare-sase-with-crowdstrike/UseCase03.svg "Figure 4: Automated edge remediation")

## 사용 케이스 세부 사항: 사용자 수명주기 준수 — 탐지 및 응답

결합 통합 기둥이 활성 엔드 포인트 타협을 포함 하 여 레버리지 하는 방법을 사용 하 여 측면 운동을 방지.

### 단계 1: 탐지와 신호 공유

Falcon 대리인은 멀웨어 실행을 검출합니다. 기기의 ZTA 점수를 "Critical"로 즉시 삭제하고 SIEM에 경고를 보냅니다.

### 단계 2: 즉시 접근 revocation

모델 번호: Cloudflare 액세스, 다음 요청에 ZTA 점수를 확인, Salesforce, 이메일 또는 내부 도구에 액세스하여 사용자를 차단, 효과적으로 네트워크에서 장치를 quarantining.

### 3 단계 : 투자 및 중급

Falcon Fusion SOAR는 응답 playbook을 자동화합니다: 그것은 endpoint (network containment)를 고립시키고 사용자를 Cloudflare에서 주문 명부에 추가하고, 효과적으로 Falcon Next-Gen SIEM에 있는 더 깊은 retrospective 분석을 위한 로그에서 그(것)들을 끌어서 주문 명부에 붙어 있는 추가 정책을 토론합니다.

![감지, 액세스 재발행 및 재약을 보여주는 사용자 수명주기](~/assets/images/reference-architecture/cloudflare-sase-with-crowdstrike/UseCase04.svg "Figure 5: Compromised user lifecycle - detection and response")

## 케이스 세부 사항 사용 : Insider 위협 및 데이터 보호

이 사용 사례는 무결한 접근법이 방지하고 신뢰할 수있는 내부자 행위자에 의해 데이터 여과에 응답하는 방법을 보여줍니다.

### 단계 1: DLP 감시

Cloudflare DLP 스캔 업로드 트래픽. 소스 코드 마커를 감지하고 Logpush를 통해 Falcon Next-Gen SIEM에 이벤트를 기록하며 특정 요청을 즉시 차단합니다.

### 단계 2: 위험 득점 및 상관

Falcon Next-Gen SIEM은 엔드 포인트 활동 (예 : 최근 USB 사용 또는 대형 파일 사본)이 DLP 이벤트를 상관합니다. 이 행동은 "High Risk"사용자 태그를 트리거합니다.

### 단계 3: 적응 통제

Falcon Fusion SOAR은 Cloudflare Zero Trust 정책을 업데이트하여 "step-up authentication" 또는 Remote browser isolation (RBI)이 특정 사용자를 위해 HR 또는 보안에 의해 명확하게 될 때까지 더 많은 데이터 움직임을 방지합니다.

![내부 위협 및 데이터 보호 작업 흐름 DLP 모니터링 및 적응 제어](~/assets/images/reference-architecture/cloudflare-sase-with-crowdstrike/UseCase05.svg "Figure 6: Insider threat and data protection")

## 사용 케이스 세부 사항: Proactive application Defense

이 사용 사례는 botnets 및 Zero-day 악용에 대한 공공 애플리케이션을 방어하는 통합 솔루션의 힘을 탐구합니다.

### 단계 1: 공격 ID

Cloudflare WAF는 특정한 subnet에서 SQL 주입 시도의 시리즈를 막습니다. 이 로그는 Falcon Next-Gen SIEM로 전송됩니다.

### 2단계: Cross-domain 분석

CrowdStrike Threat Intelligence는 로그 데이터를 풍부하고 알려진 타겟 랜섬웨어 그룹의 일부로 하위넷을 식별합니다.

### 단계 3: 방어 tuning

Falcon Fusion SOAR는 Cloudflare WAF 규칙을 업데이트하기 위해 워크플로우를 트리거합니다: 그것은 그 지역에 대한 "Bot Fight Mode" 감도를 증가시키고 공격과 관련된 전체 자율 시스템 번호 (ASN)에 대한 적극적인 블록 규칙을 생성, 주요 공격 전에 응용 프로그램을 경화 시작.

![공격 식별에서 공격적인 애플리케이션 방어 워크플로우](~/assets/images/reference-architecture/cloudflare-sase-with-crowdstrike/UseCase06.svg "Figure 7: Proactive application defense")

## 구현 구성

Cloudflare와 CrowdStrike와의 통합은 각 플랫폼에서 여러 주요 구성 요소를 활용하여 공동 보안 생태계를 만듭니다.

### Cloudflare 성분

1. **Zero Trust 네트워크 액세스 (ZTNA)**: ID, 장치 자세 및 기타 상황에 따라 애플리케이션에 대한 액세스 제어
   - Application 액세스 정책
   - Private Network 액세스
   - 서비스 토큰 인증
   - Device posture 인증
2. **보안 웹 게이트웨이 (SWG)**: 검사 및 필터 Internet-bound 트래픽
   - URL 필터링
   - Malware 보호
   - 관련 분류
   - 파일 형식 제어
3. **데이터 손실 방지 (DLP)**: 무단 전재 방지
   - 내장 데이터 프로파일 (PII, 금융 데이터, 비밀)
   - 사용자 정의 데이터 패턴
   - Exact 데이터 매칭
   - Context 인식
4. **원격 브라우저 고립 (RBI)**: 안전한 클라우드 환경에서 웹 콘텐츠를 실행
   - 파일 업로드/download 컨트롤
   - 클립보드 제한
   - 키보드 입력 컨트롤
   - Visual 프레젠테이션
5. **이메일 보안**: 이메일 기반 위협 방지
   - Phishing 보호
   - 맛있는 스캔 첨부 파일
   - 이메일 손상 검출
   - 링크 고립
6. **API 구동 클라우드 액세스 보안 브로커 (CASB)**: 모니터 SaaS 사용 및 보안
   - SaaS 자세 관리
   - Permission 모니터링
   - Data 보안 검사
   - 공공 공유 탐지
7. **웹 응용 프로그램 방화벽 (WAF)**
   - 기계 학습 (ML) 검출 및 차단
   - 주문 규칙 생성
   - 관리된 규칙 세트
   - 비율 제한

### CrowdStrike 부품

1. **Falcon 엔드포인트 에이전트**: 포괄적인 endpoint 보호 제공
   - Behavior 모니터링
   - Malware 예방
   - 장치 보안 자세 평가
   - Vulnerability 관리
2. **Zero Trust 평가 (ZTA)**: 실시간 디바이스 보안
   - OS 보안 평가
   - Sensor 상태 모니터링
   - 전체 장치 건강 scoring
   - 지속적인 평가
3. **Falcon 차세대 SIEM**: 보안 모니터링 및 분석
   - 로그인, 상관 관계, 실시간 검색
   - 위협 탐지 규칙 및 경고 트리거
   - customizable 대시보드s를 가진 안전 시각화
   - Alert 관리 및 장기 데이터 저장
4. **Falcon 통찰력 XDR**: 장시간 검출 및 응답 기능 제공
   - Cross-domain 탐지
   - 자동화된 조사
   - 위협 사냥
   - 관련기관
5. **팔콘 융해 SOAR:**&#x43;loudflare 및 CrowdStrike 플랫폼에서 복잡한 보안 워크플로우를 자동화합니다.
   - 보안 관현
   - Playbook 실행
   - 자동화된 봉제 및 enrichment
   - 양방향 작용

## 제품정보

Cloudflare와 CrowdStrike 간의 통합은 엔드포인트 보안, 제로 신뢰 네트워크 액세스 및 애플리케이션 보호와 결합하는 종합 보안 솔루션을 제공합니다. 두 플랫폼의 강점을 활용하여 조직은 보안 자세로 더 나은 가시성을 달성할 수 있으며 위협에 대한 자동 응답을 확보하고 응용 프로그램과 데이터를 효과적으로 보호합니다.

이 참고 자료 건축술은 이 해결책이 0개의 신뢰 채택, 신청 보호 및 자료 안전을 포함하여 중요한 안전 문제를 해결하기 위하여 함께 작동하는 방법을 설명합니다. 이 통합 접근 방식을 구현함으로써 조직은 보안 팀의 운영 부담을 줄이면서 보안 자세를 향상시킬 수 있습니다.

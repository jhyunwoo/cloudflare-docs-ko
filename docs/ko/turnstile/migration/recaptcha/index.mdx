오늘 reCAPTCHA를 사용하는 경우 Cloudflare Turnstile에 원활하게 전환할 수 있습니다.

마이그레이션을 완료하려면, 당신은 얻을해야합니다[사이트키와 비밀 키](/turnstile/get-started/#get-a-sitekey-and-secret-key).

:::참조

Turnstile 마이그레이션은 현재 reCAPTCHA v2와 호환됩니다.
주요 특징

## Client-side 통합

<Steps>
  1. HTML에서 Turnstile 스크립트 스니펫을 삽입하여 클라이언트 측 통합 업데이트`<head>`이름 \*

     ```html title="Turnstile script snippet"
     <script src="https://challenges.cloudflare.com/turnstile/v0/api.js?compat=recaptcha" async defer></script>
     ```

     :::참조

     더 보기`?compat=recaptcha`호환성 형태에 있는 Turnstile를 달립니다,
     다음 기능을 활성화:

     - reCAPTCHA를 위한 implicit 연출
     - `g-recaptcha-response`형식의 입력 이름
     - Turnstile API를 등록`grecaptcha`
       :::

  2. 자주 묻는 질문`grecaptcha.render()`Turnstile 사이트키를 사용하여 사이트키를 호출하고 교체합니다.

     :::참조

     Turnstile 지원:

     - 이름 \*`render()`이름 \*
     - reCAPTCHA v2 보이지 않는 모드`execute()`이름 \*
       주요 특징
</Steps>

## Server-side 통합

Siteverify URL을 대체하여 서버 측 통합을 업데이트합니다.

기타 제품`https://www.google.com/recaptcha/api/siteverify`다음으로:

```txt
https://challenges.cloudflare.com/turnstile/v0/siteverify
```

:::카트로션\[ReCAPTCHA의 Siteverify를 거부]

reCAPTCHA 지원`GET`쿼리 매개 변수를 사용하여 요청`GET /siteverify?response=<response>&secret=<secret>`.

Turnstile의 Siteverify 엔드포인트는*아니다.*&#xC774;것을 지원하고만 받아들입니다`POST`FormData 또는 JSON 몸과의 요청.

더 알아보기[서버 측 검증](/turnstile/get-started/server-side-validation/)더 많은 정보.

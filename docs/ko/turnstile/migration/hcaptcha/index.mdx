오늘 hCaptcha를 사용하는 경우 Cloudflare Turnstile에 완벽하게 전환하여 업그레이드 프로세스를 지원하기 위해 아래 단계별 가이드를 따르십시오.

마이그레이션을 완료하려면, 당신은 얻을해야합니다[사이트키와 비밀 키](/turnstile/get-started/#get-a-sitekey-and-secret-key).

## Client-side 통합

<Steps>
  1. HTML에서 Turnstile 스크립트 스니펫을 삽입하여 클라이언트 측 통합 업데이트`<head>`성분:

     ```html title="Turnstile script snippet"
     <script src="https://challenges.cloudflare.com/turnstile/v0/api.js" async defer></script>
     ```
  2. 자주 묻는 질문`hcaptcha.render()`Turnstile 사이트키와 API를 사용하여 사이트키를 호출하고 교체합니다.

     ```js title="Render"
     //이전 다음
     hcaptcha.render(element, {
         sitekey: "00000000-0000-0000-0000-000000000000"
     })
     //후에
     turnstile.render(element, {
         sitekey: "1x00000000000000000000AA"
     })
     ```
</Steps>

:::참조

Turnstile 지원:

- 이름 \*`render()`이름 \*
- hCaptcha 보이지 않는 모드`execute()`이름 \*
  주요 특징

## Server-side 통합

<Steps>
  1. Siteverify URL을 대체하여 서버 측 통합을 업데이트합니다.

     교체:`https://hcaptcha.com/siteverify`다음으로:

     ```txt
     https://challenges.cloudflare.com/turnstile/v0/siteverify
     ```
  2. 수정하기`h-captcha-response`다음을 가진 입력 이름:

     ```txt
     cf-turnstile-response
     ```
</Steps>

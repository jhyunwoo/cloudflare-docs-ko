이 튜토리얼은 Turnstile를 실행하는 방법을 설명합니다. 들어오는 요청에 따라 헤더 또는 특정 IP 주소의 사전 공유 비밀과 같은.

## 제품정보

Turnstile 도전을 로드하거나 실행할 수 없는 자동화와 같은 설정이 있을 수 있습니다. 사용 방법[`HTMLRewriter`](/workers/runtime-apis/html-rewriter/),이 튜토리얼은 조건으로 처리하는 방법을 설명합니다[클라이언트 측 위젯](/turnstile/get-started/client-side-rendering/)·[Siteverify API를](/turnstile/get-started/server-side-validation/)특정 기준이 충족되면.

:::참조
이 튜토리얼은 특정 표준이 충족 될 때 Turnstile 클라이언트 측면 요소를 제거하지만, 대신 조건으로 삽입 할 수 있습니다.
주요 특징

:::카트로션
Turnstile가 충족되지 않을 때 Siteverify API로 토큰을 검증하는 것이 중요합니다.

이 웹 사이트는 애플 리케이션에 전념. 우리는 정품 앱과 게임을 제공 할 목적으로이 사이트를 만들었습니다. 4AppsApk 최고의 안드로이드 애플 리케이션을위한 APK 파일 다운로드 서비스, 계략.
주요 특징

## - 연혁

이 튜토리얼은 기존의 수정[Turnstile 데모](https://github.com/cloudflare/turnstile-demo-workers/blob/main/src/)상태 제거`script`및 위젯 컨테이너 요소.

```diff title="src/index.mjs" lang="js"
export default {
  async fetch(request) {
    // ...

+    if (request.headers.get("x-bypass-turnstile") === "VerySecretValue") {
+      class RemoveHandler {
+        element(element) {
+          element.remove();
+        }
+      }
+
+      return new HTMLRewriter()
+        // Remove the script tag
+        .on(
+          'script[src="https://challenges.cloudflare.com/turnstile/v0/api.js"]',
+          new RemoveHandler(),
+        )
+       // Remove the container used in implicit rendering
+				.on(
+					'.cf-turnstile',
+					new RemoveHandler(),
+				)
+       // Remove the container used in explicit rendering
+				.on(
+					'#myWidget',
+					new RemoveHandler(),
+				)
+        .transform(body);
+    }

    return new Response(body, {
      headers: {
        "Content-Type": "text/html",
      },
    });
  },
};
```

## Server-side 통합

우리는 동일한 논리가 우리가 클라이언트 측 성분을 제거하기 위하여 이용된 경우에 우리의 검증에서 일찍 종료할 것입니다.

:::카트로션
동일한 논리는 클라이언트 측과 서버 측 둘 다에서 사용되어야 합니다.
주요 특징

```diff lang="js" title="src/index.mjs"
async function handlePost(request) {
+  if (request.headers.get("x-bypass-turnstile") === "VerySecretValue") {
+    return new Response('Turnstile not enforced on this request')
+  }
	// Proceed with validation as normal!
	const body = await request.formData();
  // Turnstile injects a token in "cf-turnstile-response".
  const token = body.get('cf-turnstile-response');
  const ip = request.headers.get('CF-Connecting-IP');
  // ...
}
```

이러한 변경으로 Turnstile는 헤더와 요청에 따라 시행되지 않습니다.`x-bypass-turnstile: VerySecretValue`이름 \*

## 데모

실행 후`npm run dev`프로젝트 폴더에서 다음 명령을 실행하여 변경 사항을 테스트 할 수 있습니다.

```sh
curl -X POST http://localhost:8787/handler -H "x-bypass-turnstile: VerySecretValue"
```

```txt output
Turnstile not enforced on this request
```

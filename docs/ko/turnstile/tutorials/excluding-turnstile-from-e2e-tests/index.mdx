이 튜토리얼은 Turnstile의 전용 테스트 키를 사용하여 최종 테스트 (E2E) 테스트에서 Turnstile를 처리하는 방법을 설명합니다.

## 제품정보

E2E 테스트를 실행하면 Turnstile 검증 프로세스를 우회하거나 단순화 할 수 있습니다. Cloudflare는 항상 검증을 통과하는 공식 테스트 자격 증명을 제공하며 테스트 환경에 적합합니다.

- 시험 sitekey:`1x00000000000000000000AA`
- 시험 비밀 열쇠:`1x0000000000000000000000000000000AA`

자세한 내용은 참조[시험 문서](/turnstile/troubleshooting/testing/).

:::카트로션

생산에 있는 시험 credentials를 사용하지 마십시오. 항상 보증:

- 시험 자격은 시험 환경에서만 사용됩니다.
- 생산 자격은 제대로 보호됩니다.
- 배포 프로세스는 테스트 자격 증명을 도달 생산에서 방지합니다.
  주요 특징

## - 연혁

test-environment detection를 구현하는 열쇠는 테스트 요청 서버 측을 식별합니다. 간단한 접근법은 다음과 같습니다.

```typescript
//IP 주소 또는 헤더를 사용하여 테스트 환경을 감지
function isTestEnvironment(request) {
  const testIPs = ['127.0.0.1', '::1'];
  const isTestIP = testIPs.includes(request.ip);
  const hasTestHeader = request.headers['x-test-environment'] === 'secret-token';

  return isTestIP || hasTestHeader;
}

//환경에 근거한 적합한 자격 증명을 사용하십시오.
function getTurnstileCredentials(request) {
  if (isTestEnvironment(request)) {
    return {
      sitekey: '1x00000000000000000000AA',
      secretKey: '1x0000000000000000000000000000000AA'
    };
  }

  return {
    sitekey: process.env.TURNSTILE_SITE_KEY,
    secretKey: process.env.TURNSTILE_SECRET_KEY
  };
}
```

## Server-side 통합

페이지를 렌더링 할 때, 환경에 따라 적절한 Sitekey를 주입 :

```typescript
app.get('/your-form', (req, res) => {
  const { sitekey } = getTurnstileCredentials(req);
  res.render('form', { sitekey });
});
```

## Client-side 통합

템플릿을 사용할 수 있습니다. injected sitekey:

```html
<div class="turnstile" data-sitekey="<%= sitekey %>"></div>
```

## 좋은 관행

1. **환경 검출**
   - 테스트 환경(IP, 헤더 등)을 식별하는 여러 요인을 사용합니다.
   - 테스트 환경 식별자는 공개 웹에서 테스트해야하는 경우 안전합니다.

2. **Credential 관리**
   - 저장 생산 credentials 안전하게 (예를 들면, 환경변수에서).
   - credentials를 버전 제어에 투입하지 마십시오.
   - 각 환경을 위한 다른 자격 증명을 사용하십시오.

3. **배포 안전**
   - 생산에 있는 시험 credentials를 방지하기 위하여 체크를 추가하십시오.
   - CI/CD 파이프라인에서 자격 검증을 포함하십시오.
   - 사고 시험 credential 사용법을 위한 감시자.

## 시험 고려사항

- 시험 자격은 항상 검증을 통과합니다.
- 자동화된 테스트 환경에 적합합니다.
- 그들은 테스트 중에 제한을 피하는 데 도움이됩니다.
- 그들은 더 예측할 수 있고 더 빨리 시험합니다.

## 예제 테스트 설정

Cypress 또는 유사한 E2E 테스트 기구를 위해:

```typescript
//모든 테스트 요청에 대한 테스트 헤더 설정
beforeEach(() => {
  cy.intercept('*', (req) => {
    req.headers['x-test-environment'] = 'secret-token';
  });
});

//테스트는 일반적으로 양식과 상호 작용할 수 있습니다.
it('submits form successfully', () => {
  cy.visit('/your-form');
  cy.get('form').submit();
  //Turnstile는 자동으로 검증을 통과합니다
});
```

## 이름 \*

Turnstile의 테스트 자격 및 적절한 환경 감지를 사용하여 생산 보안을 유지하면서 신뢰할 수있는 E2E 테스트를 만들 수 있습니다. 항상 테스트 자격 증명을 생산에서 분리하고 배포 프로세스에서 적절한 보호를 구현합니다.

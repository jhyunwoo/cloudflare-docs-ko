## Turnstile는 어떻게 작동합니까?

![Turnstile 개요](~/assets/images/turnstile/turnstile-overview.png)

Turnstile는 개별 방문자 또는 브라우저에 도전해줍니다. 첫째, 우리는 방문자 또는 브라우저 환경에 대한 신호를 수집하는 작은 비동기 JavaScript 도전의 시리즈를 실행합니다.

이러한 과제에는 웹 API를 위한 증거-of-work, proof-of-space, probing 및 브라우저-quirk 및 인간 행동을 감지하기위한 다양한 과제가 있습니다. 결과적으로, 우리는 특정 요청에 도전의 어려움을 초래하고 사용자에게 시각적 또는 상호 작용 퍼즐을 보여주기 위해 노력할 수 있습니다.

:::참조
Turnstile의 데이터 개인 정보 보호 관행에 대한 자세한 정보는 참조[Turnstile 개인 정보 취급 방침](https://www.cloudflare.com/turnstile-privacy-policy/).
:::

### Widget 유형

사이트맵[위젯 유형](/turnstile/concepts/widget/)다음:

- **비동기**: 방문자는 위젯과 상호 작용할 필요가 없습니다.
- **지원하다**: 방문자는 의심스러운 봇 인 경우 대화 형 체크 박스로 표시됩니다.
- **옵션 정보**: 위젯은 방문자에서 완전히 숨겨진.

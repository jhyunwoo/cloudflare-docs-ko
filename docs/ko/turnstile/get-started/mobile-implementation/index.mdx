Turnstile는 모바일 브라우저를 통해 웹 사이트에 액세스하는 모바일 장치를 포함하는 표준 브라우저 환경에서 실행하도록 설계되었습니다.

네이티브 모바일 애플리케이션의 경우 Turnstile는 Turnstile 위젯을 포함하는 웹 콘텐츠를 렌더링하는 WebViews를 사용하여 통합 할 수 있습니다.

***

## WebView 통합

WebViews는 웹 콘텐츠를 표시하는 네이티브 모바일 응용 프로그램을 허용하는 구성 요소입니다. 기본 응용 프로그램 내에서 브라우저 엔진을 포함, 웹 페이지를 표시 할 수 있도록, 양식, JavaScript-powered content like Turnstile 위젯.

### 제품 정보

Turnstile는 WebView에서 제대로 작동하려면 다음 요구 사항을 충족해야합니다.

#### JavaScript 지원

- JavaScript 실행을 활성화해야합니다.
- DOM 저장 API는 유효해야 합니다.
- 표준 웹 API는 접근할 수 있어야 합니다.

#### 네트워크 접속

- 오시는 길`challenges.cloudflare.com`
- HTTP 및 HTTPS 연결 모두 지원.
- 연결하기`about:blank`·`about:srcdoc`

#### 환경 일관성

- 세션 전반에 걸쳐 일관된 사용자 에이전트
- 안정된 장치 및 브라우저 특성
- 핵심 브라우저 행동에 대한 수정

### 플랫폼별 구현

#### Android 웹뷰

```java wrap 
WebView webView = findViewById(R.id.webview);
WebSettings webSettings = webView.getSettings();

// Required: Enable JavaScript
webSettings.setJavaScriptEnabled(true);

// Required: Enable DOM storage
webSettings.setDomStorageEnabled(true);

// Recommended: Enable other web features
webSettings.setLoadWithOverviewMode(true);
webSettings.setUseWideViewPort(true);
webSettings.setAllowFileAccess(true);
webSettings.setAllowContentAccess(true);

// Load your web content with Turnstile
webView.loadUrl("https://yoursite.com/protected-form");
```

#### iOS WKWebView (스위트)

```swift wrap
import WebKit

class ViewController: UIViewController {
    @IBOutlet weak var webView: WKWebView!
    
    override func viewDidLoad() {
        super.viewDidLoad()
        
        // Configure WebView
        let configuration = WKWebViewConfiguration()
        configuration.preferences.javaScriptEnabled = true
        
        // Load your web content with Turnstile
        if let url = URL(string: "https://yoursite.com/protected-form") {
            webView.load(URLRequest(url: url))
        }
    }
}
```

#### React Native 웹뷰

```js wrap
import { WebView } from 'react-native-webview';

export default function App() {
  return (
    <WebView
      source={{ uri: 'https://yoursite.com/protected-form' }}
      javaScriptEnabled={true}
      domStorageEnabled={true}
      allowsInlineMediaPlayback={true}
      mediaPlaybackRequiresUserAction={false}
    />
  );
}
```

#### 웹 사이트 맵

```dart wrap
import 'package:flutter_inappwebview/flutter_inappwebview.dart';

class WebViewScreen extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return InAppWebView(
      initialUrlRequest: URLRequest(
        url: Uri.parse('https://yoursite.com/protected-form')
      ),
      initialOptions: InAppWebViewGroupOptions(
        crossPlatform: InAppWebViewOptions(
          javaScriptEnabled: true,
          useShouldOverrideUrlLoading: false,
        ),
        android: AndroidInAppWebViewOptions(
          domStorageEnabled: true,
        ),
        ios: IOSInAppWebViewOptions(
          allowsInlineMediaPlayback: true,
        ),
      ),
    );
  }
}
```

## 일반적인 구현 문제

### 사용자 에이전트 일관성

세션 중에 사용자 에이전트를 변경하는 것은 Turnstile의 문제로 인해 시스템이 일관된 브라우저 특성에 의존하여 방문자의 정체성을 검증합니다. 사용자 에이전트가 중간 세션을 변경할 때 Turnstile는 잠재적 인 보안 위험으로 이것을 치료하고 도전을 거부합니다.

```java wrap
// Android - Set consistent User Agent
webSettings.setUserAgentString(webSettings.getUserAgentString());
```

```swift wrap
// iOS - Maintain default User Agent
webView.customUserAgent = webView.value(forKey: "userAgent") as? String
```

### 콘텐츠 보안 정책 (CSP)

사이트맵[콘텐츠 보안 정책](/turnstile/reference/content-security-policy/)설정은 필요한 스크립트를로드하고 필요한 네트워크 연결을 만들기에서 Turnstile를 방지 할 수 있습니다. CSP 헤더 또는 메타 태그가 Turnstile가 제대로 작동해야 하는 도메인 및 리소스에 액세스할 때 발생합니다.

```html wrap
<meta http-equiv="Content-Security-Policy" content="
  default-src 'self'; 
  script-src 'self' challenges.cloudflare.com 'unsafe-inline'; 
  connect-src 'self' challenges.cloudflare.com;
  frame-src 'self' challenges.cloudflare.com;
">
```

### 도메인 구성

WebView 보안 제한은 Turnstile가 적절한 작동에 필요한 도메인에 액세스 할 수 있습니다. 일부 WebViews는 특정 도메인을 허용하거나 특정 유형의 연결을 차단하도록 구성되며 Turnstile의 문제를로드하고 Cloudflare의 서버와 통신 할 수 있습니다.

이 문제를 해결하려면 WebView의 허용 된 기원을 구성하려면 Turnstile가 필요한 모든 도메인을 포함:

- `challenges.cloudflare.com`
- `about:blank`
- `about:srcdoc`
- 당신의 자신의 도메인(s)

정확한 구성 방법은 플랫폼에 따라 다르지만 원칙은 명시적으로 이러한 도메인에 대한 네트워크 액세스를 허용하는 것입니다.

### 쿠키 및 저장 문제

세션간에 지속되지 않는 쿠키 및 로컬 저장소는 Turnstile가 이러한 메커니즘에 의존하고 방문자 행동을 추적하기 위해 실패하기 때문에 발생할 수 있습니다. WebView 저장 설정이 너무 제한되거나 앱이 세션 사이에 저장을 취소 할 때 일반적으로 발생합니다. WebView가 쿠키와 로컬 저장소를 제대로 처리하도록 구성되도록 합니다.

```java wrap
// Android - Enable cookies
CookieManager.getInstance().setAcceptCookie(true);
CookieManager.getInstance().setAcceptThirdPartyCookies(webView, true);
```

```swift wrap
// iOS - Configure cookie storage
webView.configuration.websiteDataStore = WKWebsiteDataStore.default()
```

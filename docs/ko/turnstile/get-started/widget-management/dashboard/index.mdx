Cloudflare 대시보드는 위젯 제작 및 관리를위한 사용자 친화적 인 인터페이스를 제공합니다.

## 위젯 만들기

<Steps>
  1. Cloudflare 대시보드에서**사이트맵**사이트 맵

     <DashButton url="/?to=/:account/turnstile" />
  2. 제품정보**위젯 추가**.
  3. 필요한 정보를 입력:
     - **Widget 이름**: 당신의 위젯에 대한 설명 이름.
     - **Hostname 관리**: 위젯이 사용될 도메인.
     - **Widget 모드**: Managed, Non-Interactive 또는 Invisible에서 선택하십시오.
  4. (선택 사항) 구성**Pre-clearance 지원**단일 페이지 애플리케이션
  5. 제품정보**이름 \***&#xC704;젯을 저장합니다.
  6. 사이트키와 비밀 키를 복사하고 비밀 키를 안전하게 저장합니다.
</Steps>

## 기존 위젯 관리

Cloudflare 대시보드에 대한 위젯 세부 정보를 볼 수 있습니다. 기존 위젯을 선택하여 분석, 설정 및 성능 통계.

위젯 구성을 업데이트하려면 기존 위젯에 이동하고 선택**계정 설정**. 선택**제품 정보**당신의 변화를 적용.

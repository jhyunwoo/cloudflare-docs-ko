이 가이드는 Turnstile 위젯을 설정하여 원활한 사용자 경험을 유지하면서 봇에서 웹 사이트를 보호합니다.

## 자주 묻는 질문

시작하기 전에 다음을해야합니다.

- [Cloudflare 계정](/fundamentals/account/create-account/)
- 웹 사이트 또는 웹 응용 프로그램 보호
- HTML과 선호하는 서버 측 언어의 기본 지식

***

## 회사연혁

Turnstile 위젯은 봇 보호 구현의 기초입니다.

<Render file="widget-components" product="turnstile" />

:::주\[중요]
당신의 위젯을 만들고 관리하는 방법의 관계 없이, 당신은 아직도 필요로 할 것입니다[위젯을 포함](/turnstile/get-started/client-side-rendering/)웹 페이지 및[토큰 유효성](/turnstile/get-started/server-side-validation/)서버에서.
주요 특징

Turnstile는 함께 일하는 2개의 필수 성분을 포함합니다:

1. 클라이언트 측:[위젯을 Embed](/turnstile/get-started/client-side-rendering/)

   Turnstile 위젯을 웹 페이지에 추가하여 방문자를 도전하고 검증 토큰을 생성합니다.

2. 서버 측:[토큰 유효성](/turnstile/get-started/server-side-validation/)

   Siteverify API를 사용하여 서버에서 토큰을 검증하고 인증되지 않았습니다.

Turnstile는 독립적인 서비스이기 위하여 디자인됩니다. Cloudflare 네트워크를 통해 proxied 여부에 관계없이 모든 웹 사이트에 Turnstile를 사용할 수 있습니다. 이것은 멀티 클라우드 환경, 온프레미스 인프라, 또는 다른 CDN을 사용하여 현장의 유연한 배포를 허용합니다. 클라이언트 측 위젯과 서버 측 유효성 검사 단계는 완전하게 각자 달성됩니다.

더 알아보기[- 연혁](#implementation)아래에서 Turnstile를 웹 사이트에 구현하는 방법에 대한 지침.

## 추가 구현 옵션

### 모바일 구성

모바일 애플리케이션 및 WebView 구현에 대한 특별한 고려사항이 필요합니다.

더 알아보기[모바일 구현](/turnstile/get-started/mobile-implementation/)모바일 애플리케이션 통합에 대한 자세한 정보

### 다른 CAPTCHA에서 마이그레이션

현재 reCAPTCHA, hCaptcha 또는 다른 CAPTCHA 서비스를 사용하는 경우 Turnstile는 드롭 인 교체가 될 수 있습니다. 오늘 기존 스크립트를 배포한 스크립트를 복사하고 붙여넣을 수 있습니다.

더 알아보기[관련 기사](/turnstile/migration/)다른 CAPTCHA 서비스에서 단계별 마이그레이션 안내.

## 좋은 관행

### 보안 보안

- 비밀 키를 보호합니다. 클라이언트 측 부호에 있는 비밀 열쇠를 결코 노출하지 마십시오.
- 당신의 열쇠를 정기적으로 자전하십시오. API 또는 대시보드를 사용하여 비밀 키를 주기적으로 회전하십시오.
- 호스트명을 제한합니다. 제어할 도메인에 위젯만 허용한다.
- 사용법을 감시하십시오. 특정 패턴을 감지하는 분석.

### 영업 시간

- descriptive 이름 사용. "Login Form" 또는 "Contact Page"와 같은 목적에 따라 이름 위젯.
- 환경 분리. 개발, staging 및 생산을위한 다른 위젯을 사용합니다.
- 어떤 위젯이 어떤 위치에 사용되는지 추적하십시오.
- Terraform을 사용할 때 버전 제어에서 위젯 구성을 저장합니다.

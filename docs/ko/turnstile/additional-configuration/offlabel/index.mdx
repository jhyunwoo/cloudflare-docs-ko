Offlabel는 Cloudflare 브랜딩 및 Turnstile 위젯에서 로고를 제거하는 엔터프라이즈 전용 기능입니다. 활성화될 때, 위젯 디스플레이는 어떤 시각 참고 자료s 없이 Cloudflare, 당신의 상표 정체성에 이음새가 없는 통합을 허용하.

Offlabel이 활성화되면:

- Cloudflare 로고 및 색상 계획은 모든 위젯 국가에서 제거됩니다.
- 위젯은 동일한 기능, 행동 및 WCAG 2.2 AAA 접근성 준수를 유지합니다.
- 모든 보안 기능은 변경되지 않습니다.

위젯은 웹 사이트의 디자인과 완벽하게 통합 된 깨끗한 외관으로 표시됩니다.

***

## - 연혁

### 사용 설명서

계정 팀이 Offlabel 제목을 활성화하면 Cloudflare API를 사용하여 특정 위젯을 활성화 할 수 있습니다.

```bash title="cURL command" wrap
curl -X PUT "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/challenges/widgets/$WIDGET_ID" \
-H "Authorization: Bearer $API_TOKEN" \
-H "Content-Type: application/json" \
-d '{
    "offlabel": true
}'
```

### Offlabel로 새로운 위젯 만들기

새로운 위젯을 만들 때 Offlabel을 활성화 할 수 있습니다.

```bash title="cURL command" wrap
curl -X POST "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/challenges/widgets" \
-H "Authorization: Bearer $API_TOKEN" \
-H "Content-Type: application/json" \
-d '{
    "name": "Branded Widget",
    "domains": ["example.com"],
    "mode": "managed",
    "offlabel": true
}'
```

### 회사연혁

Offlabel가 위젯 구성을 확인하여 활성화됩니다.

```bash title="cURL command" wrap
curl -X GET "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/challenges/widgets/$WIDGET_ID" \
-H "Authorization: Bearer $API_TOKEN"
```

응답은 포함될 것입니다`"offlabel": true`기능이 활성화되면.

### Cloudflare의 Turnstile 개인 정보 보호 정책 링크

offlabel을 활성화하는 조건으로 참고 자료 Cloudflare의[Turnstile 개인 정보 취급 방침](https://www.cloudflare.com/turnstile-privacy-policy/)두 가지 방법으로:

1. 개인 정보 보호 정책에 연결.
2. Cloudflare의 개인 정보 보호 정책에 대한 링크를 표시하는 위젯을 구성[JavaScript 렌더링 매개 변수](/turnstile/get-started/client-side-rendering/widget-configurations/#complete-configuration-reference).

***

## 적용분야

Offlabel는 Enterprise Turnstile add-on 또는 Standalone Enterprise Turnstile 고객에게 독점적으로 사용할 수 있습니다.

Offlabel 기능에 액세스하려면 계정 팀에 문의하십시오.

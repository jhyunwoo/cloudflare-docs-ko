[사전 명확성](/cloudflare-challenges/concepts/clearance/#pre-clearance-support-in-turnstile)Turnstile를 사용하면 Cloudflare-protected 도메인에서 사용할 수 있는 정리 쿠키를 발급할 수 있습니다. 이 기능은 적당한 기능을 위한 특정한 hostname 윤곽을 요구합니다.

## 자주 묻는 질문

제대로 작동하려면 다음을해야합니다.

1. 등록된 Cloudflare 지역을 사용하십시오.

   호스트 이름은 Cloudflare 계정에 등록된 영역이어야 합니다. 대시보드를 통해 위젯을 구성하면 기존 영역에서 선택할 수 있습니다.

2. 지정된 Cloudflare 영역을 선택하여 WAF 규칙을 미리 명확하게 설정하십시오.

   선택한 영역은 WAF 규칙을 포함해야합니다.

   예를 들어, 만약`example.com`·`app.example.com`등록 된 영역으로 Turnstile 문제가 사전에 명확하게해야`app.example.com`, 당신은 선택해야합니다`app.example.com`.

## 인증 및 인증

회사 소개`cf_clearance`위젯의 구성 호스트 이름과 일치하는 도메인에서만 허용되며 Cloudflare 계정의 영역으로 등록되며 Cloudflare의 보안 설정을 통해 활성화된 문제가 있습니다.

우선순위가 설정된 경우, 통관 쿠키는 추가적인 도전 요청으로 무효화될 수 있습니다.

Ephemeral ID는 전통적인 IP 근거한 방법 저쪽에 bot 탐지와 남용 예방을 강화하는 장치 지문 기능을 제공합니다. Ephemeral IDs는 Turnstile가 쿠키 또는 클라이언트 측 저장에 의존하지 않고 특정 클라이언트 장치에 방문자 행동을 링크를 생성하는 고유하고 짧은 라이브 식별자입니다. 다양한 상호 작용을 통해 행동의 패턴을 식별하는 데 도움이되는 임시 장치 지문입니다. Ephemeral ID는 공격자가 IP 주소를 변경할 때에도 인식하는 고급 탐지 방법입니다.

## 회사연혁

Ephemeral IDs는 여러 상호 작용을 통해 행동의 패턴을 찾는 독특한 식별자를 만드는 고급 분석 기술을 사용합니다. 이 식별자는 Turnstile 위젯과 각 방문자 상호 작용을 위해 역동적으로 생성됩니다.

쿠키 또는 로컬 저장소가 없습니다.

Ephemeral ID는 Cloudflare 계정에 적용되며 계정에서 공유할 수 없습니다. ID는 짧은 수명이 있으며 며칠 내에 만료됩니다. 그들은 개별 사용자를 식별 할 수 없습니다

Ephemeral ID는 네트워크 주소가 아닌 개별 고객에게 행동을 연결하는 IP 기반 방법보다 더 정확한 학대 탐지를 제공합니다. 이것은 특히 심각한 공격에 대한 효과적인 나쁜 배우는 피임 방지와 같은 피임 피임과 가짜 계정 생성 공격을 시도.

더 알아보기[블로그 게시물](https://blog.cloudflare.com/turnstile-ephemeral-ids-for-fraud-detection/)더 많은 정보.

## - 연혁

### Ephemeral ID 사용

1. Cloudflare 계정 팀에 문의하여 계정에 대한 Ephemeral ID 제목을 활성화하십시오. 이 기능은 Enterprise-level 액세스가 필요하며 자체 활성화 할 수 없습니다.
2. 제목이 활성화되면 Cloudflare API를 사용하여 특정 위젯에 대한 Ephemeral ID를 활성화합니다.

   ```bash title="cURL command" wrap
   curl -X PUT "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/challenges/widgets/$WIDGET_ID" \
     -H "Authorization: Bearer $API_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{
       "ephemeral_id": true
     }'
   ```
3. Ephemeral ID는 위젯 구성을 확인하여 활성화됩니다.

   ```bash title="cURL command" wrap
   curl -X GET "https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/challenges/widgets/$WIDGET_ID" \
     -H "Authorization: Bearer $API_TOKEN"
   ```

### 액세스 Ephemeral ID

활성화되면, Ephemeral ID는 Siteverify API 응답에 포함되어 있습니다.

```json title="Siteverify API response" wrap
{
  "success": true,
  "challenge_ts": "2022-02-28T15:14:30.096Z",
  "hostname": "example.com",
  "error-codes": [],
  "action": "login",
  "cdata": "sessionid-123456789",
  "metadata": {
    "ephemeral_id": "x:9f78e0ed210960d7693b167e"
  }
}
```

## 적용분야

Ephemeral ID는 기업 Turnstile add-on 또는 독립 기업 Turnstile 고객을 가진 기업 Bot 관리 고객에게 유효합니다. Ephemeral IDs에 액세스하려면 계정 팀에 문의하십시오.

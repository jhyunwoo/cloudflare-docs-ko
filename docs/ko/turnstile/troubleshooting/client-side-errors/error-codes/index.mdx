오류 코드가 표시되면`***`, 나머지 숫자가 무시 될 수 있음을 의미하고 내부 사용을 위해.
주요 특징

| 오류 코드    | 이름 \*        | 관련 기사 | 문제 해결                                                                   |
| -------- | ------------ | ----- | ----------------------------------------------------------------------- |
| `110100` | 사이트 맵        | 이름 \* | 사이트 키 확인[사이트맵](https://dash.cloudflare.com/).                           |
| `110110` | 사이트 맵        | 이름 \* | 사이트 키 맞춤법 및 대시보드 구성을 확인하십시오.                                            |
| `110200` | 도메인 인증       | 이름 \* | Hostname Management의 현재 도메인 추가.                                         |
| `110600` | 도전 시간        | 이름 \* | 방문자의 시계는 잘못 될 수 있습니다, 또는 도전 너무 오래했다.                                    |
| `110620` | 작업 시간        | 이름 \* | 방문자는 시간에 위젯과 상호 작용하지 않았다. 재설정`turnstile.reset()`.                       |
| `200100` | 시계 또는 캐시 문제  | 이름 \* | 방문자의 시계는 잘못되거나 도전은 중간에 의해 캐시되었습니다.                                      |
| `200500` | Iframe 로드 오류 | 이름 \* | Turnstile iframe을로드 할 수 없습니다. 자주 묻는 질문`challenges.cloudflare.com`차단됩니다. |
| `300*`   | 일반적인 도전 실패   | 이름 \* | Bot 행동 감지. 더 알아보기[문제 해결](#troubleshooting).                             |
| `400020` | 사이트 맵        | 이름 \* | 사이트 키 확인[사이트맵](https://dash.cloudflare.com/).                           |
| `400070` | 사이트 키 비활성화   | 이름 \* | 사이트 키가 비활성화됩니다. 자주 묻는 질문[사이트맵](https://dash.cloudflare.com/).           |
| `600*`   | 일반적인 도전 실패   | 이름 \* | Bot 행동 감지. 더 알아보기[문제 해결](#troubleshooting).                             |

***

:::caution\[이러 코드`401`]

Turnstile는 때때로 생성할지도 모릅니다`401`보안 검사 중에 브라우저 콘솔에서 무단 오류. 이것은 일반적으로 귀하의 구현에 문제가 없습니다. 이 오류는 종종 위젯 시도가 요청할 때 발생합니다.[개인 액세스 토큰](/cloudflare-challenges/reference/private-access-tokens/)기기나 브라우저가 아직 지원되지 않습니다.

일반적으로 안전하게 무시할 수 있습니다.`401`오류는 Turnstile의 챌린지 플랫폼 워크플로우의 예상 부분입니다. 위젯이 성공적으로 해결되고 토큰을 수신하는 경우, 작업이 필요하지 않습니다.

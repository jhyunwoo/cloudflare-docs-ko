당신은 회전 할 수 있습니다<GlossaryTooltip term="secret key">비밀 키</GlossaryTooltip>다음 단계를 사용하여:

<Steps>
  1. Cloudflare 대시보드에서**사이트맵**사이트 맵

     <DashButton url="/?to=/:account/turnstile" />
  2. [새로운 Turnstile 위젯 만들기](/turnstile/get-started/).
  3. 위젯 개요에서, 선택**계정 설정** > **회전 비밀 키**.
  4. 웹 사이트를 구성하여 새로운 비밀 키를 사용합니다.
</Steps>

회전은 2 시간 동안 발생합니다. 이 시간 동안, 오래된 비밀 열쇠와 새로운 비밀 열쇠는 유효합니다. 웹 사이트를 통해 어떤 문제를 피하면서 비밀 키를 교환 할 수 있습니다.

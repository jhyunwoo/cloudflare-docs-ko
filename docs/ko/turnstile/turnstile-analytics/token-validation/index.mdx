방문자가 성공적으로 Turnstile 도전을 완료 한 후, 토큰은 Siteverify API를 통해 생성되고 검증됩니다. 토큰 검증 데이터는 보안 자세로 중요한 통찰력을 제공합니다.

예를 들어, 분석의 토큰 검증 값은 다음과 같습니다.

![Token validation 예제 값](~/assets/images/turnstile/token-validation.png "Token validation example")

## 미터

- **Siteverify 요청**: 주어진 시간대에 Siteverify API로 만든 총 요청 수.
- **유효한 토큰**: Siteverify 요청 수`success:true`응답.
- **잘못된 토큰**: Siteverify 요청 수`success:false`응답.

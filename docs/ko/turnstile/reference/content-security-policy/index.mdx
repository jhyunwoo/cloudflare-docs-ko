HTTP Content-Security-Policy 응답 헤더는 웹 사이트 관리자가 리소스를 제어 할 수있게 해주는 사용자 에이전트는 주어진 페이지를로드 할 수 있습니다.

논스 기반 접근 방식을 사용하여 권장[사이트맵](https://w3c.github.io/webappsec-csp/#framework-directive-source-list). 당신의 nonce를 포함하는 것을 확인하십시오`api.js`스크립트 태그와 우리는 나머지를 처리한다. Cloudflare Turnstile는에 작동합니다**엄격한 역학**.

또는 CSP 헤더에 다음 값을 추가하십시오.

- **스크립트-src**: `https://challenges.cloudflare.com`
- **프레임 src**: `https://challenges.cloudflare.com`

CSP를 검증하는 것이 좋습니다.[Google의 CSP 증발기](https://csp-evaluator.withgoogle.com/).

:::참조

메타 태그를 통해 CSP 및/또는 Referer-Policy를 설정할 수 없습니다.[Transform 규칙](/rules/transform/)관련 기사

## Pre-clearance 지원

자주 묻는 질문[사전 클리어런스 모드에서 Turnstile](/cloudflare-challenges/concepts/clearance/#pre-clearance-support-in-turnstile), Turnstile 세트`cf_clearance`특별한 Endpoint에 fetch 요청을 수행함으로써 쿠키[`/cdn-cgi/`](/fundamentals/reference/cdn-cgi-endpoint/)당신의 도메인.

이 요청을 위해, 당신의`connect-src`지시어는`'self'`.

Turnstile 지원`auto`(과태) 방문자의 브라우저 언어를 사용하는 경우 지원됩니다. 위젯의 언어를 명시적으로 설정할 수 있습니다.[client-side 구성 속성](/turnstile/get-started/client-side-rendering/#configurations)아래 테이블에 나열된 것:

:::참조
아래 나열되지 않은 언어에 Turnstile 지원을 요청하려면 작성할 수 있습니다.[이 양식](https://forms.gle/L8njBeRFCsZAjJ2f7).

번역 오류에 대한 피드백을 제출할 수 있습니다.[이 양식](https://forms.gle/Cdz4YTRoagGpVwd7A).
:::

CNAME flattening은 CNAME 해석 속도를 높이고, <GlossaryTooltip term="zone apex" link="/dns/concepts/#zone-apex">zone apex</GlossaryTooltip>(`example.com`)에서 [CNAME 레코드](/dns/manage-dns-records/reference/dns-record-types/#cname)를 사용할 수 있게 해줍니다.

:::note
이 기능 덕분에 Cloudflare Pages 사이트에서 [루트 사용자 지정 도메인](/pages/configuration/custom-domains/)을 사용할 수도 있습니다.
:::

## 작동 방식

CNAME flattening을 사용하면 Cloudflare는 CNAME이 가리키는 IP 주소를 찾습니다. 이 과정에는 한 번의 조회만 필요할 수도 있고(CNAME이 다른 CNAME을 가리키는 경우) 여러 번의 조회가 필요할 수도 있습니다. 그런 다음 Cloudflare는 CNAME 레코드 대신 최종 IP 주소를 반환하여 DNS 쿼리가 더 빠르게 해석되도록 돕습니다.

CNAME flattening 과정의 자세한 단계는 [CNAME flattening diagram](/dns/cname-flattening/cname-flattening-diagram/)을 검토하고 [Cloudflare 블로그 글](https://blog.cloudflare.com/introducing-cname-flattening-rfc-compliant-cnames-at-a-domains-root/)을 참고하세요.

:::note
[Internal DNS](/dns/internal-dns/)에서의 CNAME flattening에 대한 정보는 [internal DNS records](/dns/internal-dns/internal-zones/internal-dns-records/)를 참고하세요.
:::

## 알아둘 점

- 일부 경우에는 CNAME flattening이 기본적으로 적용됩니다. 자세한 내용은 [Setup](/dns/cname-flattening/set-up-cname-flattening/)을 참고하세요.
- 다른 Cloudflare 계정으로의 CNAME은 허용되지 않으며 [Error 1014: CNAME Cross-User Banned](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1014/)가 발생합니다.

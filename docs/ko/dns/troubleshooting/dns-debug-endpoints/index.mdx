다음 디버그 엔드포인트는 `dig` 또는 다른 DNS 쿼리 도구를 통해 사용할 수 있습니다.

:::note
모든 명령에서 `alex.ns.cloudflare.com`을 Cloudflare가 할당한 네임서버로 바꿔 사용할 수 있습니다.
:::

```sh
dig @alex.ns.cloudflare.com chaos txt myip.cloudflare +short
```

이 명령은 Cloudflare가 이 DNS 쿼리를 받은 공개 IP 주소, 즉 사용자의 IP 주소를 알려줍니다. 자신의 IP를 알아야 할 때 디버깅에 유용합니다.

---

```sh
dig @alex.ns.cloudflare.com chaos txt id.server +short
```

이 명령은 이 명령을 실행한 위치에서 보낸 DNS 쿼리가 어느 Cloudflare 데이터 센터에 연결되는지 알려줍니다.

---

```sh
dig @alex.ns.cloudflare.com chaos txt version.bind +short
```

이 명령은 현재 연결된 데이터 센터에서 실행 중인 Cloudflare authoritative DNS 소프트웨어의 버전을 알려줍니다. 일반적으로는 모든 데이터 센터가 같은 버전을 사용하지만, 점진적 배포를 수행하기 때문에 기술적으로는 데이터 센터마다 다른 버전이 존재할 수 있습니다.

---

```sh
dig @alex.ns.cloudflare.com txt whoami.cloudflare.net +short
```

이 명령은 사용자의 공개 IP(위 첫 번째 명령과 동일), ASN, 그리고 해당 국가 코드를 반환하며, 모두 이 쿼리를 보내는 위치를 나타냅니다.

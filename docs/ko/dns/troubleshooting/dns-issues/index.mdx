Safari나 Chrome과 같은 웹 브라우저에서는 다음과 같은 DNS 오류가 흔히 관찰됩니다.

* `This site can’t be reached`
* `This webpage is not available`
* `err_name_not_resolved`
* `Can't find the server`
* [`Error 1001 DNS resolution error`](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1001/)

## 일반적인 원인과 해결 방법

아래는 DNS 해석 오류의 가장 일반적인 원인과 제안되는 해결 방법입니다.

### 도메인 또는 서브도메인 오타

요청 URL의 도메인 또는 서브도메인이 올바르게 입력되었는지 확인하세요.

### DNS 레코드 누락

Cloudflare 대시보드의 **DNS** 앱에 필요한 DNS 레코드가 있는지 확인하세요. 여기에는 다음 레코드가 포함됩니다.

* [zone apex](/dns/manage-dns-records/how-to/create-zone-apex/)(예: `example.com`) 레코드
* 기존 [subdomain](/dns/manage-dns-records/how-to/create-subdomain/)(`www.example.com`, `blog.example.com`) 레코드

:::note

[CNAME setup(partial)](/dns/zone-setups/partial-setup)가 있다면 DNS 레코드가 authoritative nameserver에도 존재하는지 확인하세요.
:::

### 도메인을 Cloudflare에 추가하기 전에 DNSSEC를 비활성화하지 않음

도메인을 Cloudflare에 추가하기 전에 도메인 제공업체에서 [DNSSEC를 비활성화](/dns/dnssec/#disable-dnssec)하지 않으면 DNS 해석 실패가 발생합니다.

### 네임서버가 더 이상 Cloudflare를 가리키지 않음

Cloudflare 대시보드의 **DNS** 앱을 통해 DNS 레코드를 관리하는데 도메인이 Cloudflare 네임서버를 더 이상 가리키지 않으면 DNS 해석이 동작하지 않습니다.

이는 도메인 등록기관이 도메인의 네임서버를 기본 네임서버로 변경하는 경우 발생할 수 있습니다. 이것이 문제인지 확인하려면 [도메인이 Cloudflare 네임서버를 사용하는지 확인](/dns/zone-setups/full-setup/setup/#verify-changes)하세요.

### 해석되지 않는 IP 주소

드물게는 URL을 요청한 클라이언트의 DNS resolver가 DNS 레코드를 유효한 IP 주소로 해석하지 못할 수 있습니다.

잠시 기다린 뒤 페이지를 다시 로드해 문제가 사라지는지 확인하세요. 이 문제는 Cloudflare와 직접적인 관련은 없지만, [Cloudflare DNS resolver](/1.1.1.1/setup/)를 사용하면 도움이 될 수 있습니다. 현재 DNS resolver에 대한 추가 지원은 호스팅 제공업체에 문의하세요.

## 배경

`DNS_PROBE_FINISHED`는 리소스에 대한 DNS 요청이 시간 초과되었음을 의미하고, `NXDOMAIN`은 존재하지 않는 도메인을 뜻합니다. 이 메시지들이 함께 나타난다는 것은 특정 리소스에 대한 DNS 쿼리가 연결된 도메인을 찾지 못했다는 의미입니다.

방문자가 네트워크 문제나 로컬 DNS 문제 때문에 이 오류 또는 Safari, Edge, Firefox의 유사한 메시지를 만나는 경우도 있지만, Cloudflare의 DNS 레코드 문제를 가리킬 수도 있습니다.

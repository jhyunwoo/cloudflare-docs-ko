Cloudflare DNS Firewall은 모든 DNS 쿼리를 Cloudflare의 글로벌 네트워크를 통해 사용자의 네임서버로 프록시합니다. 이를 통해 업스트림 네임서버를 DDoS 공격으로부터 보호하고, DNS 응답을 캐시해 부하를 줄입니다.

![DNS Firewall이 제공하는 보호를 보여 주는 다이어그램입니다. 자세한 내용은 아래를 참고하세요.](~/assets/images/dns/dns-firewall-overview.png)

DNS Firewall은 전체 authoritative nameserver를 가속하고 보호해야 하는 고객을 위한 제품입니다. 개별 Zone을 가속하고 보호해야 한다면 Cloudflare DNS [Setups](/dns/zone-setups/)를 참고하세요.

***

## DNS Firewall 작동 방식

도메인에 대한 DNS 쿼리가 발생하면 다음과 같이 처리됩니다.

1. 쿼리는 웹사이트 방문자와 가장 가까운 Cloudflare 데이터 센터로 전달됩니다. 이 위치는 DNS resolver의 위치를 기준으로 결정됩니다.
2. Cloudflare는 캐시에서 DNS 응답을 반환하려고 시도합니다.
3. 캐시에 응답이 없으면 Cloudflare가 업스트림 authoritative nameserver에 질의합니다.
4. 네임서버로부터 응답을 반환한 후, Cloudflare는 후속 DNS 쿼리를 위해 해당 응답을 일시적으로 캐시합니다.

***

## 이점

DNS Firewall은 조직이 authoritative nameserver를 완전히 제어할 수 있도록 하면서 다음과 같은 이점을 제공합니다.

* DDoS 완화
* 고가용성
* 글로벌 분산
* 향상된 성능
* 대역폭 절감
* [데이터 센터별 속도 제한](/dns/dns-firewall/setup/#additional-options)
* 최소 및 최대 캐시 TTL 지정
* DNS [ANY](https://datatracker.ietf.org/doc/html/rfc8482) 쿼리 타입 차단

[랜덤 프리픽스 공격](/dns/dns-firewall/random-prefix-attacks/about/)의 자동 완화를 활성화하려면 다음 단계를 따르세요.

1. [DNS Firewall](/dns/dns-firewall/setup/)을 설정합니다.
2. DNS Firewall 클러스터를 업데이트하기 위해 [`PATCH` 요청](/api/resources/dns_firewall/methods/edit/)을 보냅니다.

   <APIRequest
   	path="/accounts/{account_id}/dns_firewall/{dns_firewall_id}"
   	method="PATCH"
   	json={{
      "attack_mitigation": {
        "enabled": true,
        "only_when_upstream_unhealthy": true,
      }
   	}}
   />

API에서 `200` 성공 응답을 받으면, 랜덤 프리픽스 공격의 일부로 식별된 쿼리는 `REFUSED` 응답을 받게 됩니다.

:::note


API 호출에서 별도로 지정하지 않으면 Cloudflare는 `"only_when_upstream_unhealthy"` 매개변수를 자동으로 true로 설정합니다. 이는 업스트림이 응답하지 않는다고 감지될 때(공격 결과일 수 있음)만 Cloudflare가 공격을 완화한다는 의미입니다. 이 설정도 위 예시와 유사한 요청을 사용해 API로 변경할 수 있습니다.


:::

Cloudflare DNS를 권한 DNS 공급자로 사용하려면, [기본(primary, full)](/dns/zone-setups/full-setup/)이든 [보조](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/) 설정이든 관계없이, 도메인 네임서버가 Cloudflare 계정에서 받은 네임서버를 가리켜야 합니다. 네임서버 업데이트는 Cloudflare에서 도메인을 활성화하고 대부분의 [애플리케이션 서비스](/fundamentals/concepts/how-cloudflare-works/)를 사용하기 위해 필요합니다.

## 구체적인 절차

Cloudflare는 [네임서버를 제공](/dns/nameservers/#authoritative-nameservers-offering)하거나 자체 [사용자 지정 네임서버](/dns/nameservers/custom-nameservers/)를 만들 수 있도록 해주지만, 도메인에 대해 Cloudflare를 권한 DNS 공급자로 만드는 마지막 단계는 Cloudflare 밖에서 수행해야 할 수도 있습니다. [Cloudflare Registrar](/registrar/)를 사용하지 않는다면 아래 섹션 중 자신의 상황에 맞는 항목을 참고하세요.

:::note[Custom or advanced nameservers]
[사용자 지정 네임서버](/dns/nameservers/custom-nameservers/) 또는 [고급 네임서버](/dns/foundation-dns/setup/)와 함께 Cloudflare Registrar를 사용하는 경우, 네임서버를 알맞게 업데이트하려면 [지원팀에 문의](/support/contacting-cloudflare-support/)해야 합니다.
:::

### 도메인이 다른 등록기관을 사용하는 경우

도메인을 Cloudflare Registrar가 아닌 다른 [등록기관](https://www.cloudflare.com/learning/dns/glossary/what-is-a-domain-name-registrar/)에서 구매했고, [위임된 상태](#your-domain-is-delegated)가 아니라면 등록기관에서 네임서버를 업데이트해야 합니다.

등록기관이 누구인지 모를 경우 [ICANN Lookup](https://lookup.icann.org/) 같은 Whois 검색을 사용할 수 있습니다. Whois 검색 결과에 나온 등록기관이 직접 تعامل한 서비스가 아니라면, [리셀러를 통해 도메인을 구매했을 수 있습니다](#you-have-acquired-your-domain-from-a-reseller).

### 리셀러를 통해 도메인을 구매한 경우

웹사이트 빌더([Squarespace](https://support.squarespace.com/hc/articles/115003671428-Who-s-my-domain-provider) 등)와 같은 일부 서비스는 등록기관이 아니라 [리셀러](https://www.icann.org/resources/pages/reseller-2013-05-03-en) 역할을 하며, 해당 플랫폼에서 직접 도메인을 구매할 수 있게 합니다.

이 경우 등록기관이 아니라 리셀러 플랫폼에서 네임서버를 업데이트해야 할 수 있습니다.

:::note

Squarespace 플랫폼에서 네임서버를 업데이트하는 방법은 [Squarespace 문서](https://support.squarespace.com/hc/articles/4404183898125-Nameservers-and-DNSSEC-for-Squarespace-managed-domains#toc-open-the-domain-s-advanced-settings)를 참고하세요.
:::

### 도메인이 위임된 경우

하위 도메인 `shop.example.com`을 [자식 도메인](/dns/zone-setups/subdomain-setup/)으로 온보딩하는 경우, 부모 도메인(`example.com`)이 자식 도메인에 권한을 위임해야 합니다.

위임이란 `shop.example.com`에 대해 부모 영역(`example.com`)의 DNS 레코드 관리 안에서 전용 `NS` 레코드가 설정되어 있다는 뜻입니다.

그렇다면 Cloudflare에서 영역을 설정하거나 다른 [네임서버](/dns/nameservers/) 집합을 선택할 때는 등록기관이 아니라 부모 도메인 안의 `NS` 레코드를 업데이트해야 합니다.

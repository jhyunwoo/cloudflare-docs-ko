[DNS 동작 방식](https://www.cloudflare.com/learning/dns/what-is-dns/)에서 설명하듯이, 사용자가 웹 브라우저에 주소(`www.example.com`)를 입력하는 순간 DNS 쿼리 해석이 시작됩니다. 이 DNS 해석 과정에는 여러 컴퓨터(또는 서버)가 관여합니다.

Cloudflare DNS 맥락에서 네임서버는 권한(authoritative) 네임서버를 의미하며, 이는 DNS 쿼리 해석의 마지막 단계입니다. 네임서버가 `example.com`에 대해 권한이 있다는 것은, 사용자가 `example.com`에 접근하려 할 때 DNS 리졸버가 해당 네임서버의 응답을 신뢰한다는 뜻입니다.

## 권한 네임서버 제공 방식

Cloudflare에서는 요금제에 따라 Cloudflare 브랜드 네임서버를 사용할 수도 있고, 자체 사용자 지정 네임서버를 구성할 수도 있습니다. Cloudflare 브랜드 네임서버 이름은 자동으로 할당되며 변경할 수 없습니다.

어떤 유형을 선택하든, 이 네임서버들이 도메인에 대해 권한을 가지려면 [도메인 네임서버를 업데이트](/dns/nameservers/update-nameservers/)해야 합니다. 네임서버 업데이트는 Cloudflare에서 도메인을 활성화하고 대부분의 [애플리케이션 서비스](/fundamentals/concepts/how-cloudflare-works/)를 사용하기 위해 필요합니다.

### 표준 네임서버

계정에 특정 [DNS 영역 기본값](/dns/additional-options/dns-zone-defaults/) 구성이 없는 한, [기본(primary, full)](/dns/zone-setups/full-setup/) 또는 [보조(secondary)](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/) DNS 설정으로 도메인을 추가하면 Cloudflare가 자동으로 영역에 두 개의 표준 네임서버를 할당합니다.

표준 네임서버는 `ns.cloudflare.com`에서 호스팅되며 `<proper_name>.ns.cloudflare.com` 형식을 따릅니다.

이 네임서버 이름의 배경은 [블로그 글](https://blog.cloudflare.com/whats-the-story-behind-the-names-of-cloudflares-name-servers/)을 참고하세요.

### 고급 네임서버

[Foundation DNS](/dns/foundation-dns/)를 사용하는 Enterprise 계정은 고급 네임서버에 접근할 수 있습니다.

[고급 네임서버](/dns/foundation-dns/advanced-nameservers/)는 `foundationdns.com`, `foundationdns.net`, `foundationdns.org`에서 호스팅됩니다.

고급 네임서버를 사용하는 각 영역에는 `<color>.foundationdns.com`, `<color>.foundationdns.net`, `<color>.foundationdns.org` 형태의 세 개 네임서버 이름 집합이 할당됩니다.

### 사용자 지정 네임서버

[사용자 지정 네임서버](/dns/nameservers/custom-nameservers/)를 사용하면 네임서버가 자체 도메인(또는 도메인들)에서 호스팅되므로 Cloudflare 브랜드를 사용하지 않게 됩니다.

네임서버에 대해 완전한 도메인 이름(`ns1.mydomain.com`)을 제공하면, Cloudflare가 각 사용자 지정 네임서버에 IPv4 하나와 IPv6 하나를 할당합니다.

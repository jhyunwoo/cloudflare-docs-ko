사용자 지정(또는 vanity) 네임서버를 사용하면 Cloudflare 브랜드 네임서버를 사용하지 않고도 도메인이 Cloudflare DNS를 사용할 수 있습니다. 예를 들어 `example.com`의 네임서버로 `ns1.example.com`과 `ns2.example.com`을 구성할 수 있습니다.

사용자 지정 네임서버를 사용하려면 영역이 Cloudflare를 기본([Full setup](/dns/zone-setups/full-setup/)) 또는 [보조](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/) DNS 공급자로 사용해야 합니다.

## 제공 여부

- 영역 사용자 지정 네임서버는 Business 또는 Enterprise 요금제의 영역에서 사용할 수 있습니다. API 또는 대시보드를 통해 구성할 수 있습니다.
- 계정 사용자 지정 네임서버는 Business([Cloudflare Support에 문의](/support/contacting-cloudflare-support/) 후) 또는 Enterprise 고객에게 제공됩니다. 한 번 구성하면 계정의 모든 영역에서, 해당 영역의 요금제와 관계없이 사용할 수 있습니다. API 또는 대시보드로 구성할 수 있습니다.
- 테넌트 사용자 지정 네임서버는 테넌트 소유자가 생성한 경우, 해당 테넌트에 속한 어떤 계정의 영역에서도 사용할 수 있습니다. API 전용입니다.

## 제한 사항

사용자 지정 네임서버는 여러 세트(`ns_set`)로 구성됩니다. 각 네임서버 세트에는 최소 두 개, 최대 다섯 개의 사용자 지정 네임서버 이름이 있어야 합니다.

<Description>

Cloudflare의 글로벌 네트워크를 활용해 도메인에 탁월한 성능과 안정성을 제공하세요.
</Description>

<Plan type="all" />

Cloudflare DNS는 빠르고, 복원력이 뛰어나며, 관리가 쉬운 권한 DNS 서비스입니다. 도메인에 뛰어난 성능과 안정성을 제공하는 동시에 [DDoS 공격](https://www.cloudflare.com/learning/ddos/what-is-a-ddos-attack/)과 [경로 유출 및 하이재킹](https://www.cloudflare.com/learning/security/glossary/bgp-hijacking/)으로부터 비즈니스를 보호합니다. 어디서부터 시작해야 할지 알고 싶다면 [시작하기](/dns/get-started/)를 참고하세요.

Enterprise 고객은 [Internal DNS (Beta)](/dns/internal-dns/)를 통해 사설 네트워크에도 Cloudflare DNS를 사용할 수 있습니다.

***

## 기능

<Feature header="DNS 레코드" href="/dns/manage-dns-records/how-to/create-dns-records/">
DNS 레코드는 도메인에서 리소스를 사용할 수 있게 하며, 이메일과 같은 서비스를 구성할 수 있도록 해줍니다.
</Feature>

<Feature header="DNSSEC" href="/dns/dnssec/">
DNS Security Extensions(DNSSEC)는 DNS 레코드에 암호화 서명을 추가하여, 다른 누군가가 도메인으로 향하는 트래픽을 리디렉션하지 못하도록 합니다.

Cloudflare는 [Multi-signer DNSSEC](/dns/dnssec/multi-signer-dnssec/)도 지원합니다.
</Feature>

<Feature header="CNAME flattening" href="/dns/cname-flattening/">
CNAME flattening은 더 나은 성능을 제공하고 apex 도메인(`example.com`)에서 CNAME 레코드를 사용할 수 있게 해줍니다. 유료 계정은 도메인의 모든 CNAME 레코드를 flatten하도록 선택할 수 있습니다.
</Feature>

<br />

기능 전체 목록과 Cloudflare 요금제별 제공 여부는 [DNS 기능 및 제공 여부](/dns/reference/all-features/)를 참고하세요.

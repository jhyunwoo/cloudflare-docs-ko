Cloudflare DNS는 몇 가지 서로 다른 [설정 옵션](/dns/zone-setups/)을 제공합니다. 기본 설정(전체)은 가장 일반적인 방식이며 Free 또는 Pro 요금제에서 사용할 수 있는 유일한 옵션입니다.

기본 설정에서는 Cloudflare가 기본 authoritative DNS 공급자가 됩니다. 즉, 방문자가 웹사이트나 애플리케이션에 접근하려고 하면 DNS 리졸버는 Cloudflare에 있는 [DNS 레코드](/dns/manage-dns-records/)를 기준으로 조회합니다.

이 방식이 제대로 동작하려면 Cloudflare뿐 아니라 등록기관, 그리고 이전 DNS 공급자(기존에 사용 중이었다면)와 관련된 몇 가지 단계를 거쳐야 합니다. 자세한 절차는 [기본 영역 설정](/dns/zone-setups/full-setup/setup/)을 참고하세요.

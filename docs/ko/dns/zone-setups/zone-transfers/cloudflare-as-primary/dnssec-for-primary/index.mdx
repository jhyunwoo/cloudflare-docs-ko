[나가는 zone transfer](/dns/zone-setups/zone-transfers/cloudflare-as-primary/)를 사용하면 Cloudflare를 primary DNS 제공자로 유지하면서, 더 높은 가용성과 장애 허용성을 위해 하나 이상의 secondary 제공자를 사용할 수 있습니다.

나가는 zone transfer에서 DNSSEC를 사용하려면 [multi-signer DNSSEC](/dns/dnssec/multi-signer-dnssec/)를 구성해야 합니다. [Cloudflare as primary](/dns/zone-setups/zone-transfers/cloudflare-as-primary/setup/)를 설정한 뒤, 아래 단계에 따라 DNSSEC를 활성화하세요.

## 시작하기 전에

다음 사항에 유의하세요.

- 이 절차를 사용하려면 다른 DNS 제공자도 multi-signer DNSSEC를 지원해야 합니다.
- 일부 단계는 대시보드에서도 수행할 수 있지만, 현재 전체 과정은 API를 통해서만 완료할 수 있습니다.
- [**DNS Settings**](https://dash.cloudflare.com/?to=/:account/:zone/dns/settings)에서 **DNSSEC**와 **Multi-signer DNSSEC**를 활성화하더라도 아래 첫 단계만 대체됩니다. 설정을 완료하려면 나머지 튜토리얼 단계도 따라야 합니다.

## 단계

1. [Edit DNSSEC Status endpoint](/api/resources/dns/subresources/dnssec/methods/edit/)를 사용하여 zone의 DNSSEC를 활성화하고 multi-signer DNSSEC를 켭니다. 아래 예시처럼 `status`를 `active`로, `dnssec_multi_signer`를 `true`로 설정하면 됩니다.

<APIRequest
	path="/zones/{zone_id}/dnssec"
	method="PATCH"
	json={{
		status: "active",
		dnssec_multi_signer: true,
	}}
/>

2. zone에 DNSKEY 레코드를 생성하여 외부 제공자의 ZSK를 Cloudflare에 추가합니다.

```bash
curl 'https://api.cloudflare.com/client/v4/zones/{zone_id}/dns_records' \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>" \
--header "Content-Type: application/json" \
--data '{
  "type": "DNSKEY",
  "name": "<ZONE_NAME>",
  "data": {
    "flags": 256,
    "protocol": 3,
    "algorithm": 13,
    "public_key": "<PUBLIC_KEY>"
  },
  "ttl": 3600
}'
```

3. DNSKEY 레코드가 Cloudflare에서 secondary 제공자로 전송된 후, Cloudflare의 ZSK를 가져와 DNSKEY 레코드에 수동으로 추가합니다.

   현재 ZSK는 자동으로 전송되지 않습니다. API를 사용하거나 할당된 Cloudflare 네임서버 중 하나에 쿼리해서 가져올 수 있습니다.

<Example>

API 예시:

```bash
curl 'https://api.cloudflare.com/client/v4/zones/{zone_id}/dnssec/zsk' \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>"
```

명령줄 쿼리 예시:

```sh
$ dig <ZONE_NAME> dnskey @<CLOUDFLARE_NAMESERVER> +noall +answer | grep 256
```

</Example>

4. 등록기관에 DS 레코드를 추가합니다. 제공자마다 하나씩 추가해야 합니다. Cloudflare DS 레코드는 [**DNS Settings**](https://dash.cloudflare.com/?to=/:account/:zone/dns/settings) 페이지의 **DS Record** 아래에서 확인할 수 있습니다.

등록기관의 네임서버 설정에는 multi-signer DNSSEC 구성에 사용할 모든 제공자의 네임서버가 포함되어 있어야 합니다.

나가는 zone transfer를 사용하면 Cloudflare를 primary DNS 제공자로 사용하고 하나 이상의 peer DNS 서버를 secondary DNS 제공자로 구성할 수 있습니다.

Cloudflare DNS에서 [레코드를 수정](/dns/manage-dns-records/how-to/create-dns-records/)하면 해당 DNS 레코드는 [AXFR](https://datatracker.ietf.org/doc/html/rfc5936) 또는 [IXFR](https://datatracker.ietf.org/doc/html/rfc1995)를 사용하는 zone transfer를 통해 Cloudflare에서 secondary 제공자로 전송됩니다.

![다중 제공자 설정에서 Cloudflare를 primary 제공자로 사용하면 Cloudflare가 secondary DNS 제공자로 주기적으로 레코드를 전송합니다.](~/assets/images/dns/cloudflare-as-primary.png)

## 방법

* [나가는 zone transfer 설정](/dns/zone-setups/zone-transfers/cloudflare-as-primary/setup/)

## 제공 여부

나가는 zone transfer는 현재 Cloudflare를 [authoritative DNS 제공자](/dns/zone-setups/full-setup/)로 사용하는 Enterprise 고객에게 제공됩니다. 활성화와 가격에 대한 자세한 내용은 계정 팀에 문의하세요.

## 참고 사항

[Cloudflare Load Balancing](/load-balancing/)을 사용하는 경우 프록시된 Load Balancer DNS 레코드만 전송됩니다.

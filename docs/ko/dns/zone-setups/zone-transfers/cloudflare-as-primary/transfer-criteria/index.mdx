아래 섹션에서 DNS 레코드 유형과 프록시 상태에 따라 예상되는 동작을 확인하세요.


## 프록시된 레코드

zone의 각 [프록시된 DNS 레코드](/dns/proxy-status/)에 대해 Cloudflare는 `A` 레코드 2개와 `AAAA` 레코드 2개를 전송합니다.

이 레코드는 트래픽을 프록시하는 데 사용되는 [Cloudflare IP 주소](https://www.cloudflare.com/ips/)에 해당합니다.

## DNS-only CNAME 레코드

[DNS 레코드 유형](/dns/manage-dns-records/reference/dns-record-types/#cname)에서 설명한 것처럼 Cloudflare는 [CNAME flattening](/dns/cname-flattening/)이라는 과정을 사용하여 CNAME 대상 대신 최종 IP 주소를 반환합니다. CNAME flattening은 성능을 향상시키며 zone apex에 CNAME 레코드를 설정할 수 있게 해줍니다.

[설정](/dns/cname-flattening/set-up-cname-flattening/)에 따라, DNS-only CNAME 레코드와 함께 나가는 zone transfer를 사용할 때 다음 동작을 기대할 수 있습니다.

- zone apex의 DNS-only CNAME 레코드는 Cloudflare가 항상 flatten된 IP 주소를 전송합니다.
- 서브도메인의 DNS-only CNAME 레코드는 [**모든 CNAME 레코드에 대해 CNAME flattening**](/dns/cname-flattening/set-up-cname-flattening/#for-all-cname-records) 설정이 활성화된 경우에만 Cloudflare가 flatten된 IP 주소를 전송합니다.

:::note[레코드별 CNAME flattening]

[레코드별 CNAME flattening](/dns/cname-flattening/set-up-cname-flattening/#per-record)을 사용하는 레코드(즉, **모든 CNAME 레코드에 대해 CNAME flattening**이 비활성화된 경우)는 Cloudflare가 flatten된 IP 주소가 아니라 CNAME 자체를 전송합니다.

:::

## 전송되지 않는 레코드

Cloudflare를 primary로 사용할 때 다음 레코드는 전송되지 않습니다.

- [CAA 레코드](/ssl/edge-certificates/caa-records/)
- TLS 인증서 검증에 사용되는 TXT 레코드
- DNS-only [Load Balancing](/load-balancing/load-balancers/dns-records/) 레코드

:::note
프록시된 Load Balancing 레코드는 [프록시된 레코드](#프록시된-레코드)에서 설명한 방식으로 전송됩니다.
:::

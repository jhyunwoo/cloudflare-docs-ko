[나가는 zone transfer](/dns/zone-setups/zone-transfers/cloudflare-as-primary/)를 사용하면 Cloudflare를 primary DNS 제공자로 유지하면서, 더 높은 가용성과 장애 허용성을 위해 하나 이상의 secondary 제공자를 사용할 수 있습니다.

## 시작하기 전에

계정 팀이 해당 zone에서 나가는 zone transfer를 활성화했는지 확인하세요.

레코드 유형별 [예상 동작](/dns/zone-setups/zone-transfers/cloudflare-as-primary/transfer-criteria/)을 검토하고, 모든 레코드가 원하는 **Proxy status**를 갖고 있는지 [기존 DNS 레코드](/dns/manage-dns-records/how-to/create-dns-records/)를 확인하세요.

API를 사용하는 경우 [Zone ID와 Account ID 찾기](/fundamentals/account/find-account-and-zone-ids/)도 미리 해 두면 좋습니다.

## 2. Peer DNS 서버 만들기(선택 사항)

다음이 필요한 경우에만 peer DNS 서버를 만들면 됩니다.

- secondary 네임서버가 Cloudflare DNS 레코드 변경에 대한 **NOTIFY**를 받아야 하는 경우
- zone transfer 요청과 **NOTIFY**에 서명할 **TSIG**가 필요한 경우

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 peer를 만들려면:

1. Cloudflare 대시보드에서 계정 **Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/configurations" />

2. **DNS Settings**로 이동합니다.
3. **DNS Zone Transfers** 아래의 **Peer DNS servers**에서 **Create**를 선택합니다.
4. 다음 정보를 입력합니다. 특히 아래 항목에 주의하세요.
   - **IP**: 설정되어 있으면 Cloudflare가 NOTIFY 요청을 보내는 위치를 지정합니다.
   - **Port**: NOTIFY IP에 사용할 IP 포트를 지정합니다.
   - **Enable incremental (IXFR) zone transfers**: Cloudflare를 primary DNS 제공자로 사용하는 경우에는 적용되지 않습니다(Cloudflare zone은 항상 IXFR 요청을 수락합니다).
   - **Link an existing TSIG**: 원한다면 [앞서 만든](#1-tsig-만들기선택-사항) TSIG를 연결합니다.
5. **Create**를 선택합니다.

</TabItem> <TabItem label="API">

API로 peer DNS 서버를 만들려면 [POST](/api/resources/dns/subresources/zone_transfers/subresources/peers/methods/create/) 요청을 보냅니다.

</TabItem> </Tabs>

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 primary zone을 peer에 연결하려면:

1. Cloudflare 대시보드에서 **DNS Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/dns/settings" />

2. **DNS Zone Transfers**에서 **Manage linked peers**를 선택합니다.
3. peer를 선택합니다.
4. **Save**를 선택합니다.

</TabItem> <TabItem label="API">

API로 primary zone을 peer에 연결하려면 [이전에 만든](#2-peer-dns-서버-만들기선택-사항) peer의 ID를 사용해 [POST](/api/resources/dns/subresources/zone_transfers/subresources/incoming/methods/create/) 요청을 보냅니다.

</TabItem> </Tabs>

:::caution[여러 peer와 TSIG]
zone에 둘 이상의 peer를 연결하고 그중 하나 이상에 TSIG가 구성되어 있다면, 모든 peer도 동일한 TSIG를 사용해야 합니다.
:::

## 4. Secondary DNS 제공자 업데이트

secondary DNS 제공자는 [이 IP](/dns/zone-setups/zone-transfers/access-control-lists/cloudflare-ip-addresses/#transfer-ip)의 53번 포트로, 그리고 [peer 구성](#2-peer-dns-서버-만들기선택-사항)에 지정된 IP 주소에서 zone transfer 요청(AXFR 또는 IXFR)을 보내야 합니다.

또한 Cloudflare IP 범위에서 오는 NOTIFY 메시지가 차단되지 않도록 [Access Control Lists(ACL)](/dns/zone-setups/zone-transfers/access-control-lists/cloudflare-ip-addresses/#allow-range)도 업데이트되어 있어야 합니다.

## 5. Cloudflare 안에 secondary 네임서버 추가

secondary DNS 제공자에게서 받은 정보를 사용해, zone apex에 secondary 네임서버를 나열하는 [NS 레코드](/dns/manage-dns-records/how-to/create-dns-records/#create-dns-records)를 생성합니다.

기본적으로 Cloudflare는 zone apex에 추가된 NS 레코드를 무시합니다. 이 동작을 바꾸려면 [multi-provider DNS](/dns/nameservers/nameserver-options/#multi-provider-dns)를 활성화하세요.

:::note
계정 [zone defaults](/dns/additional-options/dns-zone-defaults/)에서 이미 **Multi-provider DNS**가 활성화되도록 정의되어 있다면, 이 단계가 필요하지 않을 수도 있습니다.
:::

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">


1. Cloudflare 대시보드에서 **DNS Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/dns/settings" />

2. **Multi-provider DNS**를 활성화합니다.

</TabItem> <TabItem label="API">

zone ID와 인증 정보를 자리표시자에 맞게 바꾼 뒤 다음 `PATCH` 요청을 보냅니다.

<APIRequest
	path="/zones/{zone_id}/dns_settings"
	method="PATCH"
	json={{
		multi_provider: true,
	}}
/>

</TabItem> </Tabs>

:::note
Cloudflare를 유일한 authoritative DNS 제공자로 유지하려면 multi-provider DNS를 활성화하지 마세요. 이렇게 하면 secondary DNS는 숨겨진 상태로 Cloudflare primary와 동기화되어, 재해 복구 상황을 위한 백업 옵션으로 유지됩니다.
:::

## 6. 나가는 zone transfer 활성화

나가는 zone transfer를 활성화하면 secondary DNS 제공자에게 DNS NOTIFY 메시지가 전송됩니다.

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

1. Cloudflare 대시보드에서 **DNS Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/dns/settings" />

2. **Outgoing Zone Transfers**의 토글을 **On**으로 바꿉니다.

</TabItem> <TabItem label="API">

API로 나가는 zone transfer를 활성화하려면 [POST](/api/resources/dns/subresources/zone_transfers/subresources/outgoing/methods/enable/) 요청을 보냅니다.

</TabItem> </Tabs>

가용성과 장애 허용성을 높이기 위해, 한 제공자가 사용할 수 없게 되는 상황에 대비하여 Cloudflare와 함께 하나 이상의 DNS 제공자를 사용할 수 있습니다([peer DNS server](#peer-dns-server)라고 함). 그러면 각 제공자는 authoritative([AXFR](https://datatracker.ietf.org/doc/html/rfc5936)) 또는 incremental([IXFR](https://datatracker.ietf.org/doc/html/rfc1995)) zone transfer를 사용하여 서로 DNS 레코드를 전송합니다.

AXFR을 사용할 경우 레코드 하나만 변경되더라도 전체 zone이 primary 제공자에서 secondary 제공자로 전송됩니다. IXFR을 사용할 경우에는 변경 사항만 전송됩니다. Cloudflare는 두 프로토콜을 모두 지원합니다.

zone transfer에는 두 가지 구성 옵션이 있습니다.

- [Cloudflare as Primary](/dns/zone-setups/zone-transfers/cloudflare-as-primary/): Cloudflare가 기본 DNS 제공자이며 secondary DNS 제공자로 나가는 zone transfer를 수행합니다.
- [Cloudflare as Secondary](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/): Cloudflare가 secondary DNS 제공자이며 primary DNS 제공자로부터 들어오는 zone transfer를 시작합니다.

## Peer DNS 서버

Peer DNS 서버는 primary 및 secondary 외부 DNS 서버로 사용할 수 있습니다. 동일한 peer를 여러 primary zone과 secondary zone에 연결할 수 있습니다. 각 peer는 하나의 Transaction Signature(TSIG)에만 연결될 수 있습니다.

<Render file="linked-peers-limit" product="dns" />

peer는 [API](/api/resources/dns/subresources/zone_transfers/subresources/peers/methods/list/) 또는 대시보드를 통해 관리할 수 있습니다.

1. Cloudflare 대시보드에서 계정 **Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/configurations" />

2. **DNS Settings** > **DNS Zone Transfers**로 이동합니다.

peer의 사용 방식에 따라 각 필드의 의미가 달라집니다.

| Field        | Cloudflare as Primary (Outgoing)                            | Cloudflare as Secondary (Incoming)                       |
| ------------ | ----------------------------------------------------------- | -------------------------------------------------------- |
| Name         | 사람이 읽을 수 있는 peer 이름                               | 사람이 읽을 수 있는 peer 이름                            |
| IP           | 설정되어 있으면 Cloudflare가 NOTIFY를 보내는 대상          | Cloudflare가 AXFR/IXFR 전송 요청을 보내는 대상          |
| Port         | NOTIFY IP용 IP 포트                                         | 전송 IP용 IP 포트                                        |
| TSIG ID      | 연결된 TSIG 객체                                            | 연결된 TSIG 객체                                         |
| IXFR enabled | Cloudflare는 나가는 zone transfer에 대해 항상 IXFR을 지원 | Cloudflare가 AXFR만 보낼지, AXFR과 IXFR을 모두 보낼지 지정 |

## 제공 여부

Zone transfer는 Enterprise 요금제 고객만 사용할 수 있습니다.

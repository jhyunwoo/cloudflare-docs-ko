Cloudflare가 [secondary DNS 제공자](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/)인 경우 Access Control List(ACL)를 생성해야 합니다. 이 ACL은 Cloudflare가 수신해야 하는 추가 NOTIFY IP를 지정합니다.

ACL은 계정 수준에서 구성되므로 계정 안의 모든 primary zone과 secondary zone에 적용됩니다.

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 새 ACL을 만들려면:

1. Cloudflare 대시보드에서 계정 **Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/configurations" />

2. **DNS Settings**로 이동합니다.
3. **DNS Zone Transfers** 아래의 **ACL**에서 **Create**를 선택합니다.
4. 다음 정보를 입력합니다.
   - **ACL name**: 설명하기 쉬운 이름을 입력합니다.
   - **IP range**: IPv4 또는 IPv6 주소 범위를 입력합니다(IPv4는 최대 /24, IPv6는 최대 /64까지 허용).
5. **Create**를 선택합니다.

</TabItem> <TabItem label="API">

API로 새 ACL을 만들려면 [POST](/api/resources/dns/subresources/zone_transfers/subresources/acls/methods/create/) 요청을 보냅니다.

</TabItem> </Tabs>

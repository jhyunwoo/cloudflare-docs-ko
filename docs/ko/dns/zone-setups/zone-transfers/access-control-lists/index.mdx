Access Control List(ACL)는 서버가 들어오는 데이터나 제어 메시지를 허용할 원본 IP 주소를 정의합니다.

새 DNS zone transfer([incoming](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/) 또는 [outgoing](/dns/zone-setups/zone-transfers/cloudflare-as-primary/))를 설정할 때는, Cloudflare가 상대 DNS 제공자의 서버와 통신할 수 있도록 그 제공자 쪽 ACL을 업데이트해야 합니다. 다른 DNS 제공자에서 허용해야 하는 Cloudflare IP 주소는 [Cloudflare IP addresses](/dns/zone-setups/zone-transfers/access-control-lists/cloudflare-ip-addresses/)에서 확인할 수 있습니다.

Cloudflare 계정 측에서는, Cloudflare가 수신해야 하는 추가 NOTIFY IP를 지정하려는 경우에만 [새 ACL 만들기](/dns/zone-setups/zone-transfers/access-control-lists/create-new-list/)가 필요합니다.

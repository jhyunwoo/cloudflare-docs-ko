import { Example } from "~/components";

도메인을 Cloudflare에 연결하면 [DNS 레코드 빠른 스캔](/dns/zone-setups/reference/dns-quick-scan/)이 영역에 여러 레코드를 자동으로 추가할 수 있습니다.

대부분의 레코드가 실제로는 필요하지 않다는 것을 알게 되어 DNS 레코드를 일괄 삭제하고 싶다면 아래 단계를 따르세요. 이 방법은 [API 호출 기초](/fundamentals/api/)에 익숙하다는 것을 전제로 합니다.

:::note[대시보드에서 대량 삭제 가능]
대시보드에서도 레코드를 대량 삭제할 수 있으므로, 아래와 같은 사용자 지정 스크립트를 따로 만들 필요가 없습니다. 자세한 내용은 [Batch record changes](/dns/manage-dns-records/how-to/batch-record-changes/#delete-records-in-bulk)를 참고하세요.
:::

1. 영역의 DNS를 수정할 수 있는 [API 토큰](/fundamentals/api/get-started/create-token/)이 있는지 확인합니다.
2. [zone ID](/fundamentals/account/find-account-and-zone-ids/)를 확인합니다.
3. 아래 스크립트를 실행하되, `<ZONE_ID>`와 `<API_TOKEN>`을 앞 단계에서 확인한 값으로 바꿉니다.

<Example>
:::caution[경고]
이 스크립트는 `JSON` 출력을 읽기 쉽게 포맷하기 위해 [jq](https://jqlang.github.io/jq/)를 사용합니다. 자세한 내용은 [Make API calls](/fundamentals/api/how-to/make-api-calls/)를 참고하세요.
:::

```bash
zoneid=<ZONE_ID>
bearer=<API_TOKEN>
curl --silent "https://api.cloudflare.com/client/v4/zones/$zoneid/dns_records?per_page=50000" \
--header "Authorization: Bearer $bearer" \
| jq --raw-output '.result[].id' | while read id
do
  curl --silent --request DELETE "https://api.cloudflare.com/client/v4/zones/$zoneid/dns_records/$id" \
--header "Authorization: Bearer $bearer"
done
```
</Example>

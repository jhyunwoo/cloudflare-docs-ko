도메인이 삭제되는 가장 일반적인 원인은 다음과 같습니다.

- 도메인에 접근 권한이 있는 사용자가 도메인을 제거했습니다.
- 네임서버가 더 이상 Cloudflare를 가리키지 않습니다. Cloudflare는 도메인 등록 상태를 지속적으로 모니터링합니다.
- 도메인이 인증되지 않았습니다(pending 상태 28일).

---

## Audit Logs 확인

Cloudflare [Audit Logs](/fundamentals/account/account-security/review-audit-logs/)에는 도메인 삭제에 대한 정보가 포함됩니다.

:::note

_Delete_는 도메인 삭제를 의미하는 **Action**이지만, 다른 다양한 계정 설정 삭제에도 공통적으로 사용됩니다. 따라서 **Resource**가 _Zone_인지 반드시 확인하세요.
:::

---

## 등록기관에서 Cloudflare 네임서버 확인

도메인이 [기본 설정(전체)](/dns/zone-setups/full-setup/)을 사용하고 있었다면, 등록기관에서 도메인의 authoritative 네임서버로 Cloudflare 네임서버를 사용해야 합니다.

1. 운영체제에 포함된 명령줄 기반 `whois` 애플리케이션이나 [ICANN Lookup](https://lookup.icann.org/) 같은 웹사이트를 사용합니다.
   - 도메인의 네임서버 정보를 찾지 못하면 도메인 등록기관 또는 도메인 공급자에 문의해 도메인 등록 정보를 확인하세요.
   - 도메인 등록 정보에 Cloudflare 네임서버 두 개만 나열되어 있는지 확인하세요.
   - 도메인 등록 정보에서 네임서버 철자가 정확한지 확인하세요.

2. 네임서버가 [**DNS Records**](https://dash.cloudflare.com/?to=/:account/:zone/dns/records) 페이지의 **Cloudflare Nameservers** 카드에 표시된 값과 정확히 일치하는지 확인합니다.

3. 잘못된 정보가 발견되면 도메인 공급자 포털에 로그인해 업데이트하거나 도메인 공급자에 도움을 요청하세요.

이 전환을 수행하려면 아래 단계를 따르세요.

## 1. 영역 전송 중지

<Render file="secondary-conversion-unlink" product="dns" />

## 2. authoritative DNS 공급자 구성

1. (선택 사항) 새 authoritative DNS 공급자로도 이전 중이라면, 이전 공급자에서 영역 파일을 내보내 새 공급자로 가져옵니다.
2. authoritative DNS 공급자에서 Cloudflare를 통해 프록시하려는 모든 호스트명에 대해 `{your-hostname}.cdn.cloudflare.net`을 가리키는 `CNAME` 레코드를 만듭니다.

   <Details header="authoritative DNS 공급자의 예시 CNAME 레코드">

   `www.example.com`에 대한 `CNAME` 레코드는 다음과 같습니다.

   ```txt
   www.example.com CNAME www.example.com.cdn.cloudflare.net
   ```

   </Details>

3. authoritative DNS 공급자에서 Cloudflare를 통해 프록시하려는 호스트명을 참조하는 기존 `A`, `AAAA`, `CNAME` 레코드를 모두 제거합니다. 이러한 호스트명에 대해서는 `{your-hostname}.cdn.cloudflare.net`을 가리키는 레코드만 남겨 두세요.

## 3. Cloudflare 영역 전환

1. Cloudflare 영역에서 앞 단계에서 `{your-hostname}.cdn.cloudflare.net`을 가리키도록 설정한 호스트명에 대해 필요한 모든 `A`, `AAAA`, `CNAME` [DNS 레코드](/dns/manage-dns-records/how-to/create-dns-records/)가 있는지 확인합니다. 또한 영역을 CNAME 설정(부분)으로 전환한 후 더 이상 해석되지 않을 다른 유형의 DNS 레코드는 삭제할 수 있습니다.
2. [Edit Zone 엔드포인트](/api/resources/zones/methods/edit/)에서 `type`을 `partial`로 설정해 영역 유형을 전환합니다. 기존 DNS 레코드는 영향을 받지 않습니다.
3. [**DNS Records**](https://dash.cloudflare.com/?to=/:account/:zone/dns/records) 페이지에서 **Verification TXT Record**를 확인하고 authoritative DNS 공급자에 추가합니다.

   <Details header="예시 확인 레코드">

   `sub.example.com`에 대한 확인 레코드 예시는 다음과 같습니다.

   | Type | Name                                | Content             |
   | ---- | ----------------------------------- | ------------------- |
   | TXT  | `cloudflare-verify.sub.example.com` | 966215192-518620144 |

   authoritative DNS 공급자가 DNS 레코드 `name` 필드에 도메인을 자동으로 덧붙인다면, 레코드 이름에는 `cloudflare-verify`만 입력해야 합니다. 그렇지 않으면 `cloudflare-verify.sub.example.com.sub.example.com`처럼 잘못된 레코드 이름이 될 수 있습니다.

   레코드를 만든 후에는 이 [Dig Web Interface 링크](https://digwebinterface.com/?type=TXT&ns=auth&nameservers=)를 사용해 `cloudflare-verify.<YOUR DOMAIN>`을 조회(`dig`)하고 동작 여부를 확인할 수 있습니다.

   </Details>

   :::note
   확인 레코드는 Cloudflare에서 CNAME 설정(부분)을 활성 상태로 유지하는 동안 계속 유지되어야 합니다.
   :::

## 4. 네임서버 업데이트

등록기관(또는 부모 영역)에서 [네임서버를 업데이트](/dns/nameservers/update-nameservers/)합니다. CNAME 설정(부분)에서는 외부 DNS 공급자의 네임서버만 나열되어 있어야 합니다.

    - 이전에 사용하던 `secondary.cloudflare.com` 네임서버가 있다면 제거합니다.
    - 새 authoritative DNS 공급자로도 이전 중이라면 새 네임서버를 추가합니다.

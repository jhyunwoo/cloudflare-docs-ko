처음에 [기본 설정(전체)](/dns/zone-setups/full-setup/)으로 구성했다면, 나중에 [인바운드 영역 전송(Cloudflare를 보조로 사용)](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/setup/)으로 전환할 수 있습니다.

<Render file="conversion-subdomain-setup-callout" product="dns" />

이 전환을 수행하려면 아래 단계를 따르세요.

## 1. DNS 레코드 준비

1. [영역 파일을 내보냅니다](/dns/manage-dns-records/how-to/import-and-export/#export-records).
2. 영역 파일을 새 기본 DNS 공급자로 가져옵니다.
3. Cloudflare 영역에서 [Update DNS Settings](/api/resources/dns/subresources/settings/subresources/zone/methods/edit/) 엔드포인트를 사용해 [secondary DNS overrides](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/proxy-traffic/)를 활성화합니다. `secondary_overrides` 값을 `true`로 설정합니다.

   :::note
   프록시 상태를 유지하고 싶은 DNS 레코드가 있는 경우 secondary DNS overrides를 활성화해야 합니다.
   :::

## 2. 영역 전송 준비

1. [보조 설정에서의 DNSSEC](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/dnssec-for-secondary/) 옵션에 맞게 DNSSEC를 조정합니다.

## 3. 영역 전환 및 영역 전송 시작

1. [Edit Zone 엔드포인트](/api/resources/zones/methods/edit/)에서 `type`을 `secondary`로 설정해 영역 유형을 전환합니다. 기존 레코드는 그대로 유지됩니다.
2. Cloudflare 대시보드에서 **DNS Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/dns/settings" />

3. **DNS Zone Transfers** 아래의 **Manage linked peers**를 선택합니다.
3. 앞 단계에서 만든 피어 서버를 연결하고 **Save**를 선택합니다.
4. 다시 [**DNS Settings**](https://dash.cloudflare.com/?to=/:account/:zone/dns/settings) 페이지에서 **Initiate zone transfer**를 선택합니다.
5. DNS 레코드가 예상대로 전송되는지 확인합니다.
6. [**DNS Records**](https://dash.cloudflare.com/?to=/:account/:zone/dns/records) 페이지로 이동해 새 **Cloudflare Nameservers**를 확인합니다.
7. 도메인 등록기관(또는 부모 영역)에서 [네임서버를 업데이트](/dns/nameservers/update-nameservers/)하여 `secondary.cloudflare.com` 네임서버를 포함하도록 합니다.

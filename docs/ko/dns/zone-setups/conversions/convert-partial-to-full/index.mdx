처음에 Cloudflare에서 부분 도메인으로 설정했다면, 나중에 [기본 설정](/dns/zone-setups/full-setup/) (전체 설정이라고도 함)으로 마이그레이션할 수 있습니다.

<Render file="conversion-subdomain-setup-callout" product="dns" />

## 1. Cloudflare SSL/TLS 준비

Cloudflare 대시보드에서 웹사이트 또는 애플리케이션용 [고급 인증서](/ssl/edge-certificates/advanced-certificate-manager/manage-certificates/)를 주문하거나 [사용자 지정 SSL 인증서](/ssl/edge-certificates/custom-certificates/uploading/)를 업로드합니다.

또한 SSL 인증서의 [상태](/ssl/reference/certificate-statuses/)가 **Active**인지 확인해야 합니다.

:::note

[Universal SSL](/ssl/edge-certificates/universal-ssl/)을 대신 사용할 수도 있지만 다음 사항을 고려해야 합니다.

- Universal 인증서는 발급까지 최소 [15분](/ssl/edge-certificates/universal-ssl/enable-universal-ssl/#full-dns-setup)이 걸릴 수 있습니다.
- 전환 프로세스 후 72시간 이내에 등록기관에 Cloudflare 네임서버를 추가해야 합니다.
- Universal SSL은 1단계 서브도메인만 지원합니다. [고급 인증서](/ssl/edge-certificates/advanced-certificate-manager/)와 [Total TLS](/ssl/edge-certificates/additional-options/total-tls/) 옵션을 사용하면 프록시된 모든 호스트명에 대해 인증서를 자동 발급할 수 있습니다.
- 다운타임을 최소화하려면 미리 인증서를 준비해 두는 것이 좋습니다.

:::

## 2. authoritative DNS에서 설정 업데이트

영역을 전환하기 최소 24시간 전에 authoritative DNS 공급자에서 DNSSEC를 비활성화합니다.

:::note

모범 사례로, authoritative DNS 공급자에서 이전 [영역 활성화 TXT 레코드](/dns/zone-setups/partial-setup/setup/#1-convert-your-zone-and-review-dns-records)도 삭제하는 것이 좋습니다. 이 값을 Cloudflare 대시보드에서 찾으려면 [**DNS Records**](https://dash.cloudflare.com/?to=/:account/:zone/dns/records) 페이지로 이동해 **Verification TXT Record**를 확인하세요.

:::

## 3. 전체 설정으로 전환

Cloudflare 대시보드에서 다음을 수행합니다.

1. Cloudflare 대시보드에서 부분 영역(CNAME 설정)을 선택하고 **DNS Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/dns/settings" />

2. **Convert to Primary DNS**를 선택합니다. 이 과정은 트래픽 프록시 방식에는 영향을 주지 않습니다.
3. 레코드를 Cloudflare DNS로 가져오고, 올바르게 구성되었는지 확인합니다. 일반적으로는 [프록시되지 않은 레코드](/dns/proxy-status/)를 가져오는 것이 좋습니다.

## 4. 전체 설정 활성화

[**DNS Records**](https://dash.cloudflare.com/?to=/:account/:zone/dns/records) 페이지에서 할당된 Cloudflare 네임서버를 확인하고, 등록기관에서 [네임서버를 업데이트](/dns/nameservers/update-nameservers/)합니다.

:::caution

Universal SSL 인증서가 웹사이트 또는 애플리케이션을 보호해 주기를 기대하고 있다면, 전환 과정 후 72시간 이내에 등록기관에 Cloudflare 네임서버를 추가해야 합니다.

:::

Cloudflare는 [**DNS Settings**](https://dash.cloudflare.com/?to=/:account/:zone/dns/settings) 페이지에서 [DNSSEC를 활성화](/dns/dnssec/)하고 등록기관에 DS 레코드를 추가하는 것도 권장합니다.

모든 DNS TTL이 만료되면 모든 DNS 쿼리는 Cloudflare 글로벌 네트워크에서 응답하게 됩니다.

특정 DNS 레코드에서 [프록시 상태](/dns/proxy-status/)를 활성화해 추가 호스트명을 프록시하기 시작하세요. 이전에 프록시되던 서브도메인은 중단 없이 계속 프록시됩니다.

## 시작하기 전에

<Steps>

1. Cloudflare 계정을 만들고 도메인을 추가합니다.
2. 요금제로 **Business** 또는 **Enterprise**를 선택합니다.
3. 새 도메인을 Cloudflare에 온보딩하는 경우 네임서버를 변경하라는 지침은 무시합니다.
4. (권장) SSL/TLS 인증서를 미리 계획합니다.

   전환 전에 [Universal SSL](/ssl/edge-certificates/universal-ssl/)만 사용 중이었다면, 각 DNS 레코드([아래 3단계](#3-dns-레코드-추가))가 [프록시](/dns/proxy-status/)된 후에야 서브도메인용 인증서가 발급됩니다. 자세한 내용은 [Enable Universal SSL](/ssl/edge-certificates/universal-ssl/enable-universal-ssl/#partial-dns-setup)을 참고하세요.

   도메인이 다운타임에 민감하다면 Universal SSL 대신 [고급 인증서](/ssl/edge-certificates/advanced-certificate-manager/)와 [delegated DCV](/ssl/edge-certificates/changing-dcv-method/methods/delegated-dcv/#setup)를 고려하세요.

</Steps>

## 1. 영역 전환 및 DNS 레코드 검토


<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

:::caution[올바른 요금제를 사용 중인지 확인하세요]
영역이 Business 또는 Enterprise 요금제에 있는지 확인하세요. Free 또는 Pro 요금제라면 아래에 언급된 옵션이 표시되지 않습니다.
:::

<Steps>
1. **Overview** 페이지에서 **Convert to CNAME DNS Setup**을 선택합니다.
2. 확인을 위해 **Convert**를 선택합니다.
3. **Verification TXT Record**의 정보를 저장합니다. 이 정보를 잃어버린 경우 [**DNS Records**](https://dash.cloudflare.com/?to=/:account/:zone/dns/records) 페이지의 **Verification TXT Record** 아래에서도 확인할 수 있습니다.
4. Cloudflare를 통해 프록시하려는 서브도메인에 필요한 DNS 레코드(A, AAAA, CNAME)가 모두 있는지 확인합니다.

</Steps>

</TabItem> <TabItem label="API">

API를 통해 처음 영역을 추가하는 경우에는 전환 과정 없이 처음부터 `type`을 `partial`로 지정해 추가할 수 있습니다.

## 3. DNS 레코드 추가

<Steps>

1. authoritative DNS 공급자에서 다음을 수행합니다.
   1. Cloudflare를 통해 프록시하려는 모든 호스트명에 대해 `{your-hostname}.cdn.cloudflare.net`을 가리키는 CNAME 레코드를 생성합니다.

   <Details header="authoritative DNS 공급자의 예시 CNAME 레코드">

   `www.example.com`에 대한 CNAME 레코드는 다음과 같습니다.

   ```txt
   www.example.com CNAME www.example.com.cdn.cloudflare.net
   ```

   </Details>
2. Cloudflare를 통해 프록시하려는 호스트명을 참조하는 기존 A, AAAA, CNAME 레코드를 모두 제거합니다. 이러한 호스트명에 대해서는 `{your-hostname}.cdn.cloudflare.net`을 가리키는 레코드만 남겨 둡니다.

2. Cloudflare를 통해 프록시되어야 하는 각 서브도메인에 대해 이 과정을 반복합니다.

</Steps>

## 기타 레코드 유형

CNAME 설정(부분)에서 기본 설정(전체)으로 전환을 준비 중이거나 보다 특수한 사용 사례가 있다면, [Create DNS Record](/api/resources/dns/subresources/records/methods/create/) API 엔드포인트를 사용해 지원되는 임의의 유형의 DNS 레코드를 만들 수 있습니다.

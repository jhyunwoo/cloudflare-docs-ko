[서브도메인 설정](/dns/zone-setups/subdomain-setup/)을 롤백하고, 이에 해당하는 서브도메인 DNS 레코드를 Cloudflare 안의 기존 부모 zone에 다시 만드는 방법은 아래 절차를 참고하세요.

## 시작하기 전에

* 이 가이드는 하위 도메인(`blog.example.com`)과 그 부모 도메인(`example.com`)이 모두 Cloudflare에 있다고 가정합니다.
* 하위 zone에서 DNS 레코드를 검토하고 [내보내기](/dns/manage-dns-records/how-to/import-and-export/#export-records)합니다.

:::caution[중요]

이 과정에서는 다운타임이 발생할 수 있습니다. 부모 zone 안에 [같은 이름의 해당 NS 레코드](/dns/manage-dns-records/troubleshooting/existing-ns-record/)가 남아 있는 동안에는 주소 레코드(A/AAAA)를 추가할 수 없기 때문입니다.
:::

## 단계

1. (선택 사항) 부모 zone에서 하위 도메인에 필요할 수 있는 설정([WAF 사용자 지정 규칙](/waf/custom-rules/), [Rules](/rules/), [Workers](/workers/) 등)을 옮깁니다.
2. (선택 사항) 필요하다면 하위 도메인과 그보다 더 깊은 서브도메인을 포괄하는 [고급 SSL 인증서](/ssl/edge-certificates/advanced-certificate-manager/)를 주문합니다.
3. 부모 zone에서 [**DNS Records**](https://dash.cloudflare.com/?to=/:account/:zone/dns/records) 페이지로 이동합니다.
4. 하위 도메인에 정의된 `NS` 레코드 중 하나를 삭제합니다.
5. 남아 있는 `NS` 레코드를 편집해 서브도메인 주소 레코드를 만듭니다.
6. [시작하기 전에](#시작하기-전에) 확보한 레코드를 [가져오기](/dns/manage-dns-records/how-to/import-and-export/#import-records)합니다.

[서브도메인 설정](/dns/zone-setups/subdomain-setup/)을 사용할 때, 서브도메인을 부모 도메인과 같은 계정 안의 별도 zone으로 둘 수도 있고 다른 계정 안에 둘 수도 있습니다.

같은 계정 안에 [독립형 서브도메인 zone](/dns/zone-setups/subdomain-setup/setup/)을 이미 만들었다면, 이를 별도의 계정으로 옮길 수도 있습니다.

1. 새 Cloudflare 계정에 [서브도메인을 추가](/fundamentals/manage-domains/add-site/)합니다.
2. 원래 서브도메인 zone에서 DNS 레코드를 [내보내기](/dns/manage-dns-records/how-to/import-and-export/#export-records)합니다.
3. 내보낸 레코드를 검토하고 불필요한 항목을 삭제한 다음, 새 서브도메인 zone으로 [가져오기](/dns/manage-dns-records/how-to/import-and-export/#import-records)합니다.
4. 부모 zone의 `NS` 레코드를 업데이트하여 하위 zone에 새로 할당된 네임서버를 가리키도록 합니다.

서브도메인 설정을 사용하면 하나 이상의 서브도메인에 대한 [Cloudflare 구성](/fundamentals/concepts/how-cloudflare-works/)을 <GlossaryTooltip term="apex domain">apex domain</GlossaryTooltip>에 연결된 구성과 별도로 관리할 수 있습니다. 즉, [계정 홈](https://dash.cloudflare.com/?to=/:account/)에서 `example.com`이나 `blog.example.com` 같은 웹사이트가 각각 별도의 <GlossaryTooltip term="DNS zone">zone</GlossaryTooltip>으로 표시됩니다.

:::note
이는 Cloudflare에 이미 존재하는 사이트에 단순히 서브도메인을 만드는 것과는 다릅니다. 서브도메인에 대해 별도의 Cloudflare 구성이 필요하지 않다면 [서브도메인 레코드 만들기](/dns/manage-dns-records/how-to/create-subdomain/)를 참고하세요.
:::

apex domain에는 더 엄격한 제어를 유지하면서 특정 서브도메인 설정에 대한 접근 권한을 서로 다른 팀과 공유하려는 경우 이 설정을 사용할 수 있습니다. 예를 들어 서브도메인 설정을 사용하면 문서 팀이 `docs.example.com`의 Cloudflare 구성을 관리하도록 허용하면서 `example.com`의 설정은 변경하지 못하게 할 수 있습니다.

서브도메인마다 완전히 다른 설정이 필요한 경우에도 서브도메인 설정이 유용합니다. 예를 들어 `docs.example.com`, `blog.example.com`, `community.example.com`에 서로 다른 요구사항이 있을 수 있습니다.

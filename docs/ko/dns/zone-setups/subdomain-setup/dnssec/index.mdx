DNSSEC를 활성화하는 [일반적인 절차](/dns/dnssec/)와 달리, 서브도메인 설정에서의 DNSSEC는 몇 가지 추가 단계가 필요합니다.

## 요구 사항

서브도메인 설정에 DNSSEC를 사용하려면 상위 zone에서 DNSSEC가 활성화되어 있어야 합니다. 상위 zone에서 DNSSEC를 활성화한 뒤에는 DNS resolver가 동일한 DNS 쿼리 응답을 제공하도록, 상위 zone의 [SOA 레코드](https://www.cloudflare.com/learning/dns/dns-records/dns-soa-record/)에 지정된 최소 <GlossaryTooltip term="time-to-live (TTL)">TTL</GlossaryTooltip> 값만큼 기다려야 합니다.

## 설정

1. 하위 zone을 [생성](/dns/zone-setups/subdomain-setup/setup/#how-to)합니다.

2. 하위 zone이 Cloudflare에서 [활성](/dns/zone-setups/reference/domain-status/) 상태인지, 그리고 서브도메인에 대한 DNS 해석이 올바르게 동작하는지 확인합니다.

3. 하위 zone에 [DNSSEC](/dns/dnssec/)를 활성화하고, DS 레코드 출력에 제공되는 정보를 저장합니다.

4. 상위 zone의 [**DNS Records**](https://dash.cloudflare.com/?to=/:account/:zone/dns/records) 페이지에서 이전 단계의 [DS 레코드](/dns/manage-dns-records/how-to/create-dns-records/)를 추가합니다.

   ![Cloudflare에서 DS 레코드를 추가하는 방법을 보여 주는 스크린샷](~/assets/images/dns/ds-record-example.png)

5. DNS 해석을 검증하기 위해 하위 zone에 A 레코드를 추가합니다.

6. 2시간에서 6시간 정도 기다립니다. 그 다음 이전 단계에서 추가한 A 레코드를, DNSSEC 검증을 사용하는 여러 DNS resolver(`1.1.1.1`, `8.8.8.8`, `9.9.9.9`)로 [테스트](/dns/dnssec/troubleshooting/#test-dnssec-with-dig)합니다. 예를 들어 A 레코드가 `test.child.example.com`용이라면 `dig test.child.example.com +dnssec @1.1.1.1`을 사용할 수 있습니다.

Cloudflare DNS를 사용할 때는 DNS 영역 설정에 몇 가지 선택지가 있습니다.

* [기본 설정(전체)](/dns/zone-setups/full-setup/) (가장 일반적): Cloudflare를 기본 DNS 공급자로 사용하고 Cloudflare에서 DNS 레코드를 관리합니다.
* [CNAME 설정(부분)](/dns/zone-setups/partial-setup/): 기본 DNS 공급자는 그대로 유지하고 개별 서브도메인에 대해서만 Cloudflare 리버스 프록시를 사용합니다.
* [영역 전송](/dns/zone-setups/zone-transfers/): Cloudflare와 다른 DNS 공급자를 전체 영역에 걸쳐 함께 사용해 가용성과 장애 허용성을 높입니다. DNS 레코드는 [AXFR](https://datatracker.ietf.org/doc/html/rfc5936) 또는 [IXFR](https://datatracker.ietf.org/doc/html/rfc1995)을 사용해 공급자 간에 전송됩니다.
* [서브도메인 설정](/dns/zone-setups/subdomain-setup/): apex 도메인(`example.com`)이 CNAME 설정(부분) 또는 기본 설정(전체)에 있는 상태에서, 위임된 서브도메인(`blog.example.com`)의 설정을 별도 영역과 경우에 따라 별도 계정에서 독립적으로 관리합니다.

## 영역 상태

영역에 적용될 수 있는 상태는 다음과 같습니다.

- `Initializing`
- `Pending`
- `Active`
- `Moved`
- `Deleted`
- `Purged`

각 상태의 의미와 영역이 한 상태에서 다른 상태로 어떻게 전환되는지에 대한 자세한 내용은 [참조 페이지](/dns/zone-setups/reference/domain-status/)를 참고하세요.

:::caution[운영 환경에서는 pending 영역을 사용하지 마세요]
유료 요금제를 사용 중이라면 운영 트래픽에 pending 영역을 사용하지 마세요. Cloudflare는 pending 영역에 대해 할당된 Cloudflare 네임서버 IP에서 DNS 쿼리에 응답하지만, 특히 [zone hold](/fundamentals/account/account-security/zone-holds/)를 사용하지 않는 경우 관련 위험이 있습니다.
:::

## 일반적인 사용 사례와 제공 여부

어떤 설정을 사용해야 할지 확신이 없다면, 아래 질문을 통해 일반적인 사용 사례와 각 설정, 그리고 [다양한 요금제](https://www.cloudflare.com/plans/#overview)의 대응 관계를 개괄적으로 확인해 보세요.


<Details header="Free 또는 Pro 요금제를 사용 중인가요?">

Free 또는 Pro 요금제를 사용 중이라면, 사용 가능한 옵션은 [기본 설정(전체)](/dns/zone-setups/full-setup/)뿐입니다. 이것이 권장되는 가장 일반적인 선택입니다.


</Details>


<Details header="Cloudflare를 다른 DNS 공급자와 함께 사용할 예정인가요?">

Business 또는 Enterprise 요금제를 사용 중이라면 [CNAME 설정(부분)](/dns/zone-setups/partial-setup/)을 사용해 기본 DNS 공급자는 유지한 채 개별 서브도메인만 Cloudflare를 통해 프록시할 수 있습니다.

Enterprise 요금제를 사용 중이라면 [영역 전송](/dns/zone-setups/zone-transfers/)을 사용해 Cloudflare를 기본 또는 보조 DNS 공급자로 설정할 수도 있습니다.
</Details>


<Details header="서브도메인을 별도로 관리해야 하나요?">

Enterprise 요금제를 사용 중이라면 [서브도메인 설정](/dns/zone-setups/subdomain-setup/)을 사용해 하나 이상의 서브도메인에 대한 Cloudflare 설정을 도메인 apex와 별도로 관리할 수 있습니다.


</Details>

:::note
자체 authoritative 네임서버를 운영하면서도 Cloudflare의 글로벌 anycast 네트워크 혜택을 받고 싶다면 [DNS Firewall](/dns/dns-firewall/)을 확인해 보세요.
:::

Free 영역의 도메인이 [Pending](/dns/zone-setups/reference/domain-status/#pending) 또는 [Moved](/dns/zone-setups/reference/domain-status/#moved) 상태로 너무 오래 머무르면 Cloudflare는 해당 도메인을 계정과 Cloudflare 네트워크에서 자동으로 제거합니다. 자세한 내용은 [영역 상태](/dns/zone-setups/reference/domain-status/)를 참고하세요.

[수동으로 도메인을 제거](/fundamentals/manage-domains/remove-domain/)할 수도 있습니다.

도메인을 계정에 다시 추가해야 한다면 [일반적인 온보딩 절차](/fundamentals/manage-domains/add-site/)를 따르세요.

:::caution[Purged 영역]


기본적으로 영역은 제거된 후 7일이 지나면 자동으로 purge됩니다. 이 경우 같은 Cloudflare 계정에 도메인을 다시 추가하더라도 기존 영역 설정이 복구되지 않을 수 있습니다. 자세한 내용은 [영역 상태](/dns/zone-setups/reference/domain-status/)를 참고하세요.


:::

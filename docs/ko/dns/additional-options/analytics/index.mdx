Cloudflare DNS를 사용할 때는 다양한 소스를 통해 DNS 쿼리 데이터를 확인할 수 있습니다.

---

## 분석

DNS 분석을 사용하면 Zone으로 들어오는 DNS 쿼리 데이터를 평가할 수 있습니다.

[대시보드](#view-on-the-dashboard)를 사용하면 [미리 정의된 차원](#available-dimensions)을 기준으로 빠르게 인사이트를 얻을 수 있고, [API](#explore-with-the-api)를 사용하면 GraphQL DNS 분석 스키마에서 제공하는 모든 필드에 접근할 수 있습니다.

GraphQL을 사용할 때는 특정 Cloudflare 계정 내 모든 Zone에 대한 DNS 쿼리 데이터도 가져올 수 있습니다.

### 대시보드에서 보기

빠른 요약은 대시보드의 DNS 분석에서 확인할 수 있습니다.

<DashButton url="/?to=/:account/:zone/dns/analytics" />

DNS 분석 대시보드에는 [네 개의 주요 패널](#dns-analytics-panels)이 있습니다. 페이지 상단에서 지정한 필터와 시간 범위는 이 모든 패널에 적용됩니다.

#### 사용 가능한 차원

- 쿼리 이름
- 쿼리 유형(DNS 레코드 유형과 동일)
- 응답 코드
- 데이터 센터
- Source IP
- Destination IP
- 프로토콜
- IP 버전

#### 패널

- **쿼리 개요**: 쿼리 수와 시간에 따른 분포를 보여줍니다. 이 정보는 [사용 가능한 차원](#available-dimensions)별로 나뉘며, 그래프는 상위 다섯 개 값을 표시합니다. 그래프 위 탭을 통해 차원을 선택할 수 있고, 특정 값을 가리킨 뒤 **Filter** 또는 **Exclude**를 선택해 결과를 빠르게 필터링하거나 제외할 수 있습니다.

- **쿼리 통계**: 적용한 필터와 선택한 시간 범위를 기반으로 한 쿼리 메트릭 개요입니다. 구체적으로 **Total queries**, **Average queries per second**, **Average processing time**을 보여줍니다. 평균 처리 시간은 밀리초 단위로 표시되며, [flatten된 CNAME 레코드](/dns/cname-flattening/)의 경우 upstream 쿼리도 포함합니다.

  :::note
  처리 시간은 응답 시간과 다릅니다. 응답 시간에는 클라이언트에서 리졸버까지, 리졸버에서 Cloudflare(권한 DNS 제공업체)까지 걸리는 시간처럼 Cloudflare가 알 수 없는 정보도 포함되어야 하기 때문입니다.
  :::

- **데이터 센터별 DNS 쿼리**: 선택한 기간 동안 어떤 Cloudflare 데이터 센터가 여러분 Zone의 DNS 쿼리를 처리했는지 보여주는 지도입니다. 상위 10개 결과 목록도 제공하며, 특정 데이터 센터를 가리킨 뒤 **Filter** 또는 **Exclude**를 선택해 결과를 빠르게 필터링하거나 제외할 수 있습니다.

- **소스별 쿼리**: 선택한 기준에 따라 상위 5개, 10개 또는 15개 결과를 [사용 가능한 차원](#available-dimensions)별로 그룹화해 보여줍니다.

### API로 탐색하기

더 자세한 메트릭이 필요하다면 [GraphQL API](/analytics/graphql-api/)를 사용하세요. 시작 방법은 GraphQL Analytics API 문서의 [get started](/analytics/graphql-api/getting-started/)를 참고하세요.

DNS 분석에는 두 가지 [스키마](/analytics/graphql-api/getting-started/querying-basics/)가 있습니다.

* `dnsAnalyticsAdaptive`: 개별 DNS 쿼리 정보를 가져옵니다.
* `dnsAnalyticsAdaptiveGroups`: 집계 정보만 담은 리포트를 가져옵니다.

계정 수준 데이터를 얻으려면 다음과 유사한 쿼리를 설정할 수 있습니다.

<Details header="NXDOMAIN으로 끝난 최근 10,000개 쿼리 가져오기" open = {true}>

```graphql graphql-api-explorer
query GetLastNXDOMAINResponses {
  viewer {
    accounts(filter: { accountTag: "83a4527361bcdec24566fd7f837b6de5" }) {
      dnsAnalyticsAdaptive(
        limit: 10000
        filter: {
          date_geq: "2025-06-16",
          responseCode: "NXDOMAIN",
          date_leq: "2025-06-18"
        }
        orderBy: [datetime_DESC]
      ) {
        zoneTag
        queryName
        responseCode
        queryType
        datetime
      }
    }
  }
}
```
</Details>

<Details header="계정별 전체 쿼리 수 가져오기" open = {true}>

```graphql graphql-api-explorer
query GetTotalDNSQueryCount {
  viewer {
    accounts(filter: { accountTag: "83a4527361bcdec24566fd7f837b6de5" }) {
      dnsAnalyticsAdaptiveGroups(
        filter: {
          date_geq: "2025-05-01"
          date_leq: "2025-05-30"
        }
        limit: 1
      ) {
        count
      }
    }
  }
}
```
</Details>

## 로그

로그를 사용하면 Enterprise 고객이 개별 DNS 쿼리에 대한 [상세 정보](/logs/logpush/logpush-job/datasets/zone/dns_logs/)를 볼 수 있습니다.

Logpush 설정 방법은 [Logpush](/logs/logpush/) 문서를 참고하세요.

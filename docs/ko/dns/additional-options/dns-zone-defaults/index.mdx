Cloudflare가 모든 새 Zone에 적용하는 DNS 설정 기본값이 존재하지만, Enterprise 계정은 원하는 방식에 맞게 자체 DNS Zone 기본값을 구성할 수 있습니다.

:::caution

<Render file="zone-defaults-exceptions" product="dns" />

:::

## 단계

1. Cloudflare 대시보드에서 계정 **Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/configurations" />

2. **DNS Settings**로 이동합니다. 이 옵션이 Cloudflare 대시보드에 표시되지 않는다면 계정 팀에 추가 요청을 해야 할 수 있습니다.
3. **DNS zone defaults**에서 **Configure defaults**를 선택합니다.

목록에 있는 설정에서 선택한 값은 앞으로 Cloudflare 계정에 새 Zone을 추가할 때 자동으로 적용됩니다.

## 사용 가능한 설정

- [Nameserver assignment](/dns/nameservers/nameserver-options/#assignment-method): 새 Zone에 Cloudflare가 사용할 기본 네임서버 유형 또는 할당 방식을 선택합니다. 이 설정은 기본 Zone([full setup](/dns/zone-setups/full-setup/))과 [secondary zone](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/) 모두에 적용됩니다.

기본 Zone의 경우:

- [Multi-provider DNS](/dns/nameservers/nameserver-options/#multi-provider-dns): Zone apex에 추가한 `NS` 레코드를 Cloudflare가 고려할지 여부, 그리고 등록기관에 외부 네임서버가 등록된 Zone을 활성화할지 여부를 제어합니다.
- [Nameserver TTL](/dns/nameservers/nameserver-options/#nameserver-ttl): 네임서버(`NS`) 레코드가 캐시되는 시간을 초 단위로 제어합니다. 기본 TTL(Time-to-Live)은 24시간입니다. 이 설정은 Cloudflare 네임서버와 [사용자 지정 네임서버](/dns/nameservers/custom-nameservers/) 모두에 적용됩니다.
- [SOA record](/dns/manage-dns-records/reference/dns-record-types/#soa): Cloudflare가 Zone에 대해 생성하는 start of authority(SOA) 레코드 값을 조정합니다.

Secondary zone의 경우:

- [Secondary DNS override](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/proxy-traffic/): Cloudflare [proxy](/dns/proxy-status/)를 사용하고 Zone apex에 `CNAME` 레코드를 추가하는 옵션을 활성화합니다.

  Multi-provider DNS는 secondary zone에서는 이미 필수 동작이므로 별도 설정으로 적용되지 않습니다. `SOA` 레코드와 `NS` 레코드 TTL은 외부 DNS 제공업체에서 정의되며 Cloudflare로 전송되기만 합니다.

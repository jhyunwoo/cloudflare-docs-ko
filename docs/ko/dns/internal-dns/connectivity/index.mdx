Cloudflare Gateway resolver에 연결하려면, 즉 [Internal DNS의 사설 리소스에 도달하는 데 필요](/dns/internal-dns/#architecture-overview)한 이 resolver에 연결하려면 다음 옵션을 사용할 수 있습니다.

- [DNS locations](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/)에서 지원되는 DNS 엔드포인트
  - DNS over UDP/TCP port 53 (IPv4 또는 IPv6)
  - DNS over TLS
  - DNS over HTTPS
- [Proxy Auto-Configuration (PAC) files](/cloudflare-one/networks/resolvers-and-proxies/proxy-endpoints/)
- [WARP device client](/cloudflare-one/team-and-resources/devices/warp/)
- [Clientless browser isolation](/cloudflare-one/remote-browser-isolation/setup/clientless-browser-isolation/#filter-dns-queries)
- [Cloudflare WAN](/cloudflare-wan/zero-trust/cloudflare-gateway/)

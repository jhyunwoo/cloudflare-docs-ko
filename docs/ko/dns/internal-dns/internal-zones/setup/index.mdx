## 기타 API 작업

internal zones를 관리하는 API 엔드포인트는 public zones 관리와 동일합니다. 가장 큰 차이는 zone type을 `internal`로 설정해야 한다는 점입니다. 자세한 내용은 아래 API 문서를 참고하세요.

- [내부 영역 업데이트](/api/resources/zones/methods/edit/) (`PATCH`)
- [내부 영역 세부 정보 가져오기](/api/resources/zones/methods/get/) (`GET`)
- [내부 영역 목록 조회](/api/resources/zones/methods/list/) (`GET`)
- [내부 영역 삭제](/api/resources/zones/methods/delete/) (`DELETE`)

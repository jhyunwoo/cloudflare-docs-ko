Internal DNS zones는 내부 DNS 레코드의 그룹입니다. [public DNS records](/dns/manage-dns-records/)에는 공용 인터넷에 공개하려는 리소스에 대한 정보가 담기는 반면, [internal DNS records](/dns/internal-dns/internal-zones/internal-dns-records/)를 사용하면 사설 네트워크 내부에서만 사용 가능해야 하는 리소스를 관리할 수 있습니다.

전체 구성 조건 목록과 단계별 안내는 [내부 영역 관리](/dns/internal-dns/internal-zones/setup/)를 참고하세요.

Internal DNS zones에는 Cloudflare 네임서버가 할당되지 않으며, [DNS view](/dns/internal-dns/dns-views/)에 연결된 경우에만 [Cloudflare Gateway](/cloudflare-one/traffic-policies/resolver-policies/)를 통해 질의할 수 있습니다. Gateway 구성은 internal zone이 존재하는 것과 동일한 Cloudflare 계정 안에 있어야 합니다.

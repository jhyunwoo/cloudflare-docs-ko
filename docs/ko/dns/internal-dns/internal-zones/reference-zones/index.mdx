:::note
일치하는 internal zone 안의 와일드카드 레코드(`*.example.local`)는 reference zone 안의 정확한 일치보다 우선합니다.
:::

## 구성 조건

- 각 internal zone은 하나의 다른 zone만 참조할 수 있습니다.
- 동일한 zone은 여러 internal zone에서 참조할 수 있습니다.
- public zones는 reference zone으로 사용할 수 없습니다.
- reference zones는 참조하는 zone과 같은 [DNS view](/dns/internal-dns/dns-views/)에 연결되어 있을 필요가 없습니다. 어떤 view에도 연결되지 않아도 됩니다.

## 설정

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

1. Cloudflare 대시보드에서 **Internal DNS** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/internal-dns" />

2. zone을 선택합니다.
3. 선택한 zone 안에서 **Reference zone**으로 이동합니다.
4. **Add reference zone**을 선택합니다. 이미 reference zone이 설정되어 있다면 먼저 제거해야 합니다. [구성 조건](#configuration-conditions)에서 설명했듯이 각 internal zone은 한 번에 하나의 zone만 참조할 수 있습니다.
5. 참조로 사용할 zone을 찾아 해당 행에서 **Select**를 선택합니다.

</TabItem>

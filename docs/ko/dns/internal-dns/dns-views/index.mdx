Internal DNS views는 [internal DNS zones](/dns/internal-dns/internal-zones/)의 논리적 그룹입니다. [아키텍처 개요](/dns/internal-dns/#architecture-overview)에서 설명했듯이, DNS views는 [Gateway resolver policies](/cloudflare-one/traffic-policies/resolver-policies/)에서 참조되어 특정 쿼리를 어떻게 해석할지 정의합니다.

DNS views를 관리하는 방법에 대한 자세한 내용은 아래 섹션을 참고하거나, 전체 워크플로는 [시작하기](/dns/internal-dns/get-started/)를 참고하세요.

## 뷰 삭제

DNS views는 여전히 internal zones가 연결되어 있어도 삭제할 수 있습니다. internal DNS zones는 계속 존재하지만 view가 삭제되면 연결이 해제됩니다.

Gateway resolver policy에서 참조 중인 DNS view를 삭제하는 것도 가능합니다. 이 경우 해당 정책과 일치하는 쿼리는 SERVFAIL을 반환합니다.

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

1. Cloudflare 대시보드에서 **Internal DNS** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/internal-dns" />

2. **Internal DNS Views**로 이동합니다.
3. 삭제하려는 view를 찾습니다.
4. 해당 행의 점 세 개를 선택하고 _Delete_를 선택합니다.
5. 확인 대화상자에서 다시 **Delete**를 선택해 진행합니다.

</TabItem>
<TabItem label="API">

[Delete Internal DNS View](/api/resources/dns/subresources/settings/subresources/account/subresources/views/methods/delete/) 엔드포인트를 사용하세요.

</TabItem> </Tabs>

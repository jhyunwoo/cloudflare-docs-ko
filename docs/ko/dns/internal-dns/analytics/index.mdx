Internal DNS는 [Gateway analytics](/cloudflare-one/insights/analytics/gateway/)를 활용합니다. 아래에서 이 데이터에 접근하는 데 사용할 수 있는 특정 필드와 방법에 대한 정보를 확인할 수 있습니다.

## GraphQL

세부 메트릭이 필요하면 [GraphQL API](/analytics/graphql-api/)를 사용하세요. 시작 방법은 GraphQL Analytics API 문서의 [시작하기](/analytics/graphql-api/getting-started/)를 참고하세요.

Internal DNS를 지원하기 위해 추가된 [fields](/analytics/graphql-api/getting-started/querying-basics/)는 다음과 같습니다.

- `InternalDNSFallbackStrategy`: 내부 DNS 응답에 적용된 fallback 전략입니다. fallback 전략이 적용되지 않았다면 비어 있습니다.
- `InternalDNSRCode`: 내부 DNS 서비스가 반환한 응답 코드입니다.
- `InternalDNSViewID`: 내부 DNS 서비스로 전송된 view 식별자입니다.
- `InternalDNSZoneID`: 내부 DNS 서비스가 반환한 내부 zone 식별자입니다.

## 로그

[Gateway DNS](/logs/logpush/logpush-job/datasets/account/gateway_dns/#internaldnsfallbackstrategy)에 대한 Logpush 작업을 활용하세요. Logpush 설정 방법은 [Logpush](/logs/logpush/) 문서를 참고하세요.

[Logpush filters](/logs/logpush/logpush-job/filters/)를 설정해 특정 [internal zone](/dns/internal-dns/internal-zones/) 또는 [view](/dns/internal-dns/dns-views/) ID와 관련된 로그만 전송하도록 할 수도 있습니다.

## 2025-01-27

**개별 DNS 레코드에서 Zone ID 및 이름 제거**

API가 반환하는 레코드에는 더 이상 `zone_id` 및 `zone_name` 필드가 포함되지 않습니다. 이 변경 사항이 완전히 배포되기까지 최대 4주가 걸릴 수 있습니다. 영향받는 필드는 2024년 11월 30일을 End of Life(EOL) 날짜로 하여 더 이상 사용되지 않는 것으로 지정되었습니다.

## 2024-10-15

**대시보드에서 추가한 TXT 레코드의 따옴표 검증**

이제 대시보드에서 [TXT 레코드](/dns/manage-dns-records/reference/dns-record-types/#txt)를 만들 때 다음을 확인할 수 있습니다.

* 큰따옴표 `"`가 일관되지 않게 추가된 경우 필드 검증 오류 표시
* 레코드 콘텐츠 필드에 따옴표가 없으면 저장 시 TXT 콘텐츠를 자동으로 따옴표로 감싸기

## 2024-10-07

**레코드별 CNAME flattening에 대한 API 지원**

이제 유료 Zone은 특정 CNAME 레코드를 flatten할 수 있습니다. API를 사용할 때는 `cname_flatten` 설정에 `true` 또는 `false`를 지정하세요. 자세한 내용은 [문서](/dns/cname-flattening/set-up-cname-flattening/#per-record)를 참고하세요.

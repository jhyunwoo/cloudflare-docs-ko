Cloudflare 내에서 DNS 레코드의 목적을 분류하고 명확하게 설명하려면 DNS 레코드 댓글과 태그를 사용하세요.

댓글은 특정 레코드에 대한 고유한 설명을 제공하고, 태그는 유사한 레코드를 범주로 묶습니다.

이 속성은 특히 다음과 같은 경우에 유용합니다.

* 여러 팀이 같은 zone 내에서 DNS 레코드를 관리하는 경우
* zone에 많은 수의 DNS 레코드가 포함되어 있는 경우
* 일치하는 속성(예: 같은 팀이 관리하거나 같은 애플리케이션에서 사용하는 경우)을 기준으로 DNS 레코드를 필터링하려는 경우

:::note


레코드 속성 정보는 DNS 레코드 해석이나 전파 시간에는 영향을 주지 않으며, 개인적인 참고용으로만 사용됩니다. 이 정보는 Cloudflare 계정의 [members](/fundamentals/manage-members/manage/)에게만 보이며 공개적으로는 노출되지 않습니다.


:::

## 레코드 속성 추가 또는 편집

레코드 속성은 다른 DNS 레코드 요소와 마찬가지로 [대시보드](/dns/manage-dns-records/how-to/create-dns-records/) 또는 [API](/api/resources/dns/subresources/records/methods/create/)를 통해 만들거나 편집할 수 있습니다.

[레코드를 내보낸 후 다시 가져오기](/dns/manage-dns-records/how-to/import-and-export/#dns-record-attributes) 또는 [Batch record changes API](/dns/manage-dns-records/how-to/batch-record-changes/#use-the-api)를 사용해 속성을 추가하거나 편집할 수도 있습니다.

내보내기 및 가져오기 시 `cf-`로 시작하는 특수 태그를 사용하면 특정 Cloudflare 구성을 제어할 수 있습니다. 내보낼 때는 zone 내 각 레코드의 현재 구성을 반영하도록 이 태그가 자동으로 추가됩니다. 자세한 내용은 [reserved cf- tags](/dns/manage-dns-records/how-to/import-and-export/#reserved-cf--tags)를 참고하세요.

## 참조

### 댓글

댓글은 [그래픽 유니코드 문자](https://en.wikipedia.org/wiki/Graphic_character)로 취급되므로 대소문자를 구분하며 문자 제한이 없습니다. 다만 줄바꿈(`\n`) 또는 캐리지 리턴(`\r`) 문자는 지원하지 않습니다.

### 태그

태그는 `name:value` 쌍의 배열로 취급되므로, 태그 이름은 대소문자를 구분하지 않으며 문자, 숫자, `-`, `_`만 포함할 수 있습니다. 태그 값에는 댓글과 동일한 문자 제한이 적용됩니다.

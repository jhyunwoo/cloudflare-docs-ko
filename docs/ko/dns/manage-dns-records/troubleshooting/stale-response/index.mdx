아래 시나리오 중 하나에서 오래된 DNS 응답이 사용되는 것을 확인할 수 있습니다. 시나리오와 구성의 다른 요소에 따라 잘못된 콘텐츠가 반환되거나 아무 콘텐츠도 반환되지 않을 수 있습니다.

- <GlossaryTooltip term="proxy status">proxied</GlossaryTooltip> 상태인 CNAME 레코드([기본적으로 flattening 적용](/dns/cname-flattening/))
- flattening이 활성화된 DNS-only CNAME 레코드. 이는 특정 레코드 설정 때문이거나 [zone settings](/dns/cname-flattening/set-up-cname-flattening/)의 결과일 수 있습니다.
- 외부 호스트명으로 하위 요청을 보내는 [Workers](/workers/) 스크립트[^1]

## 원인

업스트림 DNS 서버의 응답이 지나치게 지연되거나 업스트림이 SERVFAIL을 반환하는 경우, Cloudflare는 캐시에 있는 만료된 DNS 응답을 사용한 뒤 캐시를 비동기적으로 업데이트하려고 시도합니다.

## 해결 방법

- 가능하다면 proxied CNAME을 일시적으로 proxied A 레코드로 교체하세요. 다만 업스트림 대상이 로드 밸런서이거나 동적 응답을 반환하는 경우에는 항상 가능하지는 않습니다.

- 응답하지 않는 업스트림 대상의 zone 소유자 또는 DNS 공급자에게 문제를 보고하세요.

- DNS Operations Analysis and Research Center(DNS OARC)를 통해서도 문제를 제기할 수 있습니다. [채팅 플랫폼](https://www.dns-oarc.net/oarc/services/chat) 또는 [이메일 목록](https://www.dns-oarc.net/oarc/lists)을 참고하세요.

[^1]: Cloudflare를 [authoritative DNS provider](/dns/concepts/#authoritative-dns)로 사용하지 않는 호스트명입니다.

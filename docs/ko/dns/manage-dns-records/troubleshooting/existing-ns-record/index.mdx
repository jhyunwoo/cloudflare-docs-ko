새 DNS 레코드를 만들려고 할 때 Cloudflare가 다음 오류를 표시할 수 있습니다.

```txt
NS records with that host already exist. (Code:81056)
```

## 원인

도메인(`example.com`)의 자식 도메인(`blog.example.com`)이 별도의 [subdomain zone](/dns/zone-setups/subdomain-setup/)으로 설정되었다면, 부모 zone 안에 해당 `NS` 레코드가 배치되어 있어야 합니다.

부모 zone(`example.com`)의 DNS 레코드를 관리하는 동안에는, 이미 별도의 subdomain zone으로 존재하는 동일한 서브도메인 이름으로 IP 주소 해석 레코드(`A`, `AAAA`, `CNAME`)를 만들 수 없습니다.

<Example>

| Type       | Name   | Content     | TTL    |
| ---------- | ------ | ----------- | ------ |
| `A`        | `blog` | `192.0.2.0` | `Auto` |

</Example>

## 해결 방법

이러한 레코드를 만들기 전에 같은 이름의 `NS` 레코드를 제거하세요.

:::caution[중요]

이 작업은 기존 subdomain setup을 되돌리는 것이 될 수 있으며, 다운타임이 발생할 수 있습니다. 자세한 내용은 [Rollback subdomain setup](/dns/zone-setups/subdomain-setup/rollback/)을 참고하세요.

:::

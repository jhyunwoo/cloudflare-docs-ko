가끔 Cloudflare는 **Name** 필드 값이 같은 [새 DNS 레코드](/dns/manage-dns-records/how-to/create-dns-records/#create-dns-records)의 생성을 허용하지 않습니다.

이 오류는 CNAME 레코드의 특별한 요구사항[^1] 때문에 발생할 수 있습니다.

## 원인

다음 중 하나를 시도하면 이 오류가 발생합니다.

- 기존 A/AAAA[^2] 또는 CNAME 레코드의 이름과 일치하는 **Name**으로 CNAME 레코드를 생성하려는 경우
- 기존 CNAME 레코드의 이름과 일치하는 **Name**으로 A/AAAA 레코드를 생성하려는 경우

Cloudflare가 이런 조합의 레코드 생성을 막는 이유는, 어떤 호스트명에 대해 CNAME 레코드가 제공되면 DNS 서버는 해당 호스트명에 대한 DNS 정보가 그 CNAME 레코드에만 들어 있다고 기대하기 때문입니다.

여기에 추가 레코드를 더하면 DNS 서버에 상충되는 정보를 보내게 됩니다. 이 메커니즘의 기술적 배경은 [RFC 1034](https://www.rfc-editor.org/rfc/rfc1034)를 참고하세요.

## 해결 방법

기존 DNS 레코드를 검토해 **Name** 필드가 일치하는 값을 찾으세요. 그런 다음 현재 레코드를 유지할지, 삭제하고 새로 만들지를 결정합니다.

:::note

CNAME 레코드는 이런 제약을 갖는 유일한 IP 해석 레코드입니다. 하나의 호스트명에 대해 둘 이상의 A/AAAA 레코드를 둘 수 있으며, 일부 도메인은 이를 활용해 들어오는 요청에 대해 [단순한 로드 밸런싱](/dns/manage-dns-records/how-to/round-robin-dns/)을 구현합니다.

:::

서브도메인 위임을 사용하면 사이트의 서로 다른 서브도메인을 서로 다른 개인, 팀 또는 조직이 관리할 수 있습니다.

:::note

Cloudflare 도메인이 [CNAME setup (partial)](/dns/zone-setups/partial-setup)를 사용하는 경우 DNS 위임은 불가능합니다.
:::

예를 들어 `example.com`이 Cloudflare 도메인이고 `www.example.com`은 Cloudflare의 **DNS** 앱에서 관리되며 `blog.example.com`은 Cloudflare 외부의 네임서버로 위임된 경우를 생각해 보세요. 이 예시에서는 `blog.example.com`을 `example.com` 도메인에 대한 Cloudflare 자격 증명에 접근할 수 없는 사람들도 관리할 수 있게 됩니다.

:::caution

Cloudflare의 CDN 및 보안 서비스는 위임된 서브도메인에는 적용되지 않습니다.
:::

## 서브도메인 위임(외부로)

`blog.example.com` 같은 서브도메인을 위임하려면, DNS 확인자에게 zone file을 어디에서 찾을 수 있는지 알려야 합니다.

1. [Cloudflare 대시보드](https://dash.cloudflare.com)에 로그인하고 계정을 선택합니다.
2. 위임하려는 서브도메인을 포함하는 도메인을 선택합니다.
3. **DNS Records** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/dns/records" />

4. 서브도메인에 대해 `NS` 레코드를 만듭니다. 예:
   * `blog.example.com NS ns1.externalhost.com`
   * `blog.example.com NS ns2.externalhost.com`
   * `blog.example.com NS ns3.externalhost.com`
   :::note
   서브도메인용 `A` 레코드는 위임 중인 현재 zone의 서브도메인 안에 위치한 네임서버에 대한 glue record로만 필요합니다.
   :::
5. (선택 사항) 위임된 네임서버에 DNSSEC가 활성화되어 있다면 Cloudflare에 [`DS` 레코드](/dns/dnssec/#1-activate-dnssec-in-cloudflare)를 추가합니다.

## 서브도메인 위임(외부에서 Cloudflare로)

외부 DNS 공급자에서 Cloudflare로 서브도메인을 위임하려면 [subdomain setups](/dns/zone-setups/subdomain-setup/setup/)를 참고하세요.

도메인을 Cloudflare에 추가할 때, zone apex의 DNS 레코드를 생성하거나 검토해야 할 수도 있습니다. Zone apex는 [Cloudflare에 추가하는](/dns/concepts/#zone) 도메인(`example.com`) 또는 서브도메인(`blog.example.com`)을 의미합니다.

일반적으로 zone apex 레코드는 방문자가 도메인에 접근할 수 있게 해 줍니다. 이 경우 필요한 레코드 유형([A, AAAA, 또는 CNAME](/dns/manage-dns-records/reference/dns-record-types/#ip-address-resolution))과 그 내용은 웹사이트나 애플리케이션을 [호스팅하는](/fundamentals/manage-domains/#host-your-domain) 공급자에 따라 달라집니다. Cloudflare Pages를 사용 중이라면 [Custom domains](/pages/configuration/custom-domains/)를 참고하세요. 다른 공급자를 사용하는 경우에는 외부 DNS 서비스에서 관리되는 도메인을 연결하는 방법에 대한 해당 공급자의 안내를 확인하세요.

## 도메인 리디렉션

도메인을 만든 뒤에는 해당 트래픽을 다른 위치로 라우팅하고 싶을 수 있습니다.

자세한 내용은 [Redirect domain to subdomain](/fundamentals/manage-domains/manage-subdomains/#redirect-the-apex-domain-to-a-subdomain) 또는 [Redirect one domain to another](/fundamentals/manage-domains/redirect-domain/)를 참고하세요.

## 무료 SSL 인증서 받기

DNS는 웹사이트나 애플리케이션이 어디에서 도달 가능한지 전달하는 역할을 하고, SSL/TLS는 웹사이트와 애플리케이션이 안전한 방식으로 연결을 설정할 수 있게 해 줍니다.

도메인이 SSL/TLS 인증서로 올바르게 보호되지 않으면 방문자는 브라우저에서 웹사이트나 애플리케이션이 안전하지 않다는 경고를 보게 됩니다.

Cloudflare는 모든 Cloudflare 도메인에 대해 무료의 비공유형 공개 신뢰 [Universal SSL certificates](/ssl/edge-certificates/universal-ssl/)를 제공합니다.

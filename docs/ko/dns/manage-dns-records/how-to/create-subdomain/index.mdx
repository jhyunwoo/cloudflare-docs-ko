## 서브도메인 리디렉션

서브도메인을 메인 도메인이나 다른 위치로 리디렉션하는 방법에 대한 자세한 내용은 [Set up subdomain redirects](/fundamentals/manage-domains/manage-subdomains/#set-up-redirects)를 참고하세요.

## 서브도메인을 위한 SSL/TLS

DNS는 웹사이트나 애플리케이션이 어디에서 도달 가능한지 전달하는 역할을 하고, SSL/TLS는 웹사이트와 애플리케이션이 안전한 방식으로 연결을 설정할 수 있게 해 줍니다.

서브도메인이 SSL/TLS 인증서로 올바르게 보호되지 않으면 방문자는 브라우저에서 웹사이트나 애플리케이션이 안전하지 않다는 경고를 보게 됩니다.

대부분의 인터넷 서비스 공급자와 일부 호스팅 공급자는 고객의 IP 주소를 동적으로 변경합니다. 이 상황에 해당한다면 Cloudflare의 DNS 레코드를 동적으로 업데이트할 자동화 솔루션이 필요합니다.

## Cloudflare API

IP 주소 변경을 감시하는 스크립트를 만들고, 해당 스크립트가 [Cloudflare API](/api/resources/dns/subresources/records/methods/update/)로 변경 사항을 푸시하도록 구성하세요.

## ddclient

[ddclient](https://github.com/ddclient/ddclient)는 여러 DNS 공급자 계정의 동적 DNS 항목을 업데이트하는 데 사용되는 서드파티 Perl 클라이언트입니다.

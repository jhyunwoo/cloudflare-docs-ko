:::caution[경고]

새 분석 대시보드에 접근하려면 [**DNS Analytics**](https://dash.cloudflare.com//?to=/:account/:zone/dns/analytics)로 이동하세요. 자세한 내용은 [Analytics and logs](/dns/additional-options/analytics/)를 참고하세요.
:::

## 메트릭

메트릭은 데이터의 속성을 기반으로 한 수치 값입니다. 예를 들어 쿼리 수가 있습니다.

API 요청에서 메트릭은 `metrics` 매개변수에 설정합니다. 여러 메트릭을 나열해야 한다면 쉼표로 구분하세요.

| Metric             | Name                          | Example | Unit                 |
| ------------------ | ----------------------------- | ------- | -------------------- |
| queryCount         | Query count                   | `1000`  | Count                |
| uncachedCount      | Uncached query count          | `1`     | Count                |
| staleCount         | Stale query count             | `1`     | Count                |
| responseTimeAvg    | Average response time         | `1.0`   | Time in milliseconds |
| responseTimeMedian | Median response time          | `1.0`   | Time in milliseconds |
| responseTime90th   | 90th percentile response time | `1.0`   | Time in milliseconds |
| responseTime99th   | 99th percentile response time | `1.0`   | Time in milliseconds |

## 차원

차원은 주어진 속성에 따라 데이터를 세분화하는 데 사용할 수 있습니다.

API 요청에서 차원은 `dimensions` 매개변수에 설정합니다. 여러 차원을 나열해야 한다면 쉼표로 구분하세요.

| Dimension          | Name                 | Example       | Notes                                                                                                                                     |
| ------------------ | -------------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| queryName          | Query Name           | `example.com` |                                                                                                                                           |
| queryType          | Query Type           | `AAAA`        | [IANA가 정의한 타입](http://www.iana.org/assignments/dns-parameters/dns-parameters.xhtml#dns-parameters-4)입니다. 알 수 없는 타입은 비어 있습니다.   |
| responseCode       | Response Code        | `NOERROR`     | [IANA가 정의한 응답 코드](http://www.iana.org/assignments/dns-parameters/dns-parameters.xhtml#dns-parameters-6)입니다. 항상 대문자입니다. |
| responseCached     | Response Cached      | `Cached`      | `Cached` 또는 `Uncached` 중 하나입니다.                                                                                                            |
| coloName           | Colo Name            | `SJC`         | PoP 코드입니다.                                                                                                                                 |
| origin             | Origin               | `2001:db8::1` | 쿼리를 해석하는 데 사용된 origin입니다. N/A이거나 캐시에서 응답된 쿼리라면 비어 있습니다.                                                   |
| dayOfWeek          | Day Of Week          | `1`           | 요일별로 세분화합니다. 월요일은 `1`, 일요일은 `7`입니다.                                                                              |
| tcp                | TCP                  | `1`           | 사용된 프로토콜에 따라 `1` 또는 `0`입니다.                                                                                         |
| ipVersion          | IP Version           | `6`           | 사용된 IP 프로토콜 버전(현재 `4` 또는 `6`)입니다.                                                                                          |
| querySizeBucket    | Query Size Bucket    | `16-31`       | 16단위 배수로 나눈 쿼리 크기 버킷입니다.                                                                                                     |
| responseSizeBucket | Response Size Bucket | `16-31`       | 16단위 배수로 나눈 응답 크기 버킷입니다.                                                                                                  |

## 필터

필터는 `dimension operator expression` 형태를 사용하며, 각 부분은 다음에 해당합니다.

* **Dimension**: 필터링할 [차원](#dimensions)을 지정합니다. 예: `queryName`.
* **Operator**: 사용할 필터 일치 유형을 정의합니다. 연산자는 차원별로 다릅니다.
* **Expression**: 결과에 포함하거나 제외할 값을 지정합니다. 표현식은 정규식(regex) 문법을 사용합니다.

<Details header="OR 사용 예시">

* `responseCode==NOERROR,responseCode==NXDOMAIN`은 응답 코드가 `NOERROR` 또는 `NXDOMAIN`임을 의미합니다.
* `coloName==SJC OR coloName==LAX`는 `SJC` 또는 `LAX`에서 발생한 쿼리를 의미합니다.

</Details>

<Details header="AND 사용 예시">

* `responseCode==NOERROR;queryType==AAAA`는 응답 코드가 `NOERROR`이고 쿼리 타입이 `AAAA`임을 의미합니다.
* `queryType==AAAA AND coloName==SJC`는 `SJC`의 `AAAA` 쿼리를 의미합니다.

</Details>

아래 나열된 서드파티 도구를 사용해 DNS 설정을 테스트하고 문제를 해결할 수 있습니다.

* [DNSViz](https://dnsviz.net): DNS zone의 상태를 시각화해 DNS Security Extensions(DNSSEC) 배포를 이해하고 문제를 해결할 수 있도록 도와주는 웹 기반 도구입니다.

* [Dig Web Interface](https://digwebinterface.com): 명령줄 인터페이스 `dig`를 기반으로 한 온라인 DNS 조회 도구입니다. 사용자는 복잡한 매개변수를 직접 입력하는 대신 웹 도구에 같은 정보를 입력해 동일한 결과를 얻을 수 있습니다.

* [dns.google](https://dns.google): Dig Web Interface와 유사한 웹 기반 도구로, 특정 쿼리에 대한 DNS 응답을 얻을 수 있습니다.

* [Mess with DNS](https://messwithdns.net): 사용자가 DNS 레코드를 실험해 볼 수 있는 도메인을 제공하여 학습 과정에서 자유롭게 시도하고 깨뜨려 볼 수 있게 돕는 교육용 리소스입니다.

[Foundation DNS](/dns/foundation-dns/)를 사용하면 [DNSSEC](/dns/dnssec/)에 사용되는 ZSK/KSK 쌍을 Cloudflare 계정에 고유한 값으로 지정해 달라고 요청할 수 있습니다. 이 기능을 사용하려면 계정 팀에 문의하세요.

[표준](/dns/nameservers/#standard-nameservers) 네임서버를 사용하든 [고급 네임서버](/dns/foundation-dns/advanced-nameservers/)를 사용하든, Cloudflare 계정 내의 모든 영역은 DNSSEC에 대해 전용 Zone Signing Key(ZSK)와 Key Signing Key(KSK)를 사용합니다. 이 키들은 계정 수준에서 설정됩니다.

## 추가 읽을거리

배경 정보는 [DNSSEC 동작 방식](https://www.cloudflare.com/learning/dns/dnssec/how-dnssec-works/)을 참고하세요.

Cloudflare에서의 DNSSEC 설정에 대한 자세한 내용은 [DNSSEC 문서](/dns/dnssec/)를 참고하세요.

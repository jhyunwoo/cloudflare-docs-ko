Foundation DNS는 Enterprise 고객을 위한 Cloudflare DNS 상품입니다.

Foundation DNS를 사용하면 더 높은 안정성, 보안, 가시성을 이용할 수 있습니다. 주요 기능은 다음과 같습니다.

* 다음을 제공하는 [고급 네임서버](/dns/foundation-dns/advanced-nameservers/):
  * 복원력을 높이기 위해 전략적으로 분산된 IP
  * 사고나 소프트웨어 회귀에 대한 노출 감소
  * 더 일관된 네임서버 할당
* 계정에 고유한 [DNSSEC 키](/dns/foundation-dns/dnssec-keys/)
* 다음을 포함한 추가 DNS 설정:
  * [Zone 기본값](/dns/additional-options/dns-zone-defaults/)
  * [계정 사용자 지정 네임서버](/dns/nameservers/custom-nameservers/account-custom-nameservers/)
  * 사용자 지정 [SOA 레코드](/dns/manage-dns-records/reference/dns-record-types/#soa) 및 [Nameserver TTL](/dns/nameservers/nameserver-options/#nameserver-ttl)

## 제공 여부

Foundation DNS는 Enterprise 고객에게만 제공됩니다.

:::note
고급 네임서버와 고유한 ZSK/KSK 모두 선택적(opt-in) 구성입니다. 자세한 내용은 [고급 네임서버 설정](/dns/foundation-dns/setup/) 및 [DNSSEC 키](/dns/foundation-dns/dnssec-keys/)를 참고하세요.
:::

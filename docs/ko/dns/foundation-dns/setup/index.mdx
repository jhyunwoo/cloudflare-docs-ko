[Foundation DNS](/dns/foundation-dns/)에 포함된 고급 네임서버는 선택적(opt-in) 구성입니다.

:::note
고급 네임서버를 활성화한 후에도 표준 네임서버는 계속 DNS 쿼리에 응답합니다.
:::

## 시작하기 전에

고급 네임서버를 사용하기 전에 다음 사항을 고려하세요.

- <Render file="ns-advanced-vs-custom" product="dns" />

### 표준 네임서버와의 차이점

일부 동작은 표준 Cloudflare 네임서버와 다릅니다.

- 와일드카드 레코드는 계속 지원되지만, 고급 네임서버에서는 빈 비종단(empty non-terminal)인 하위 도메인에 와일드카드 레코드(`*.example.com`)가 적용되지 않습니다. 빈 비종단은 DNS 트리에서 자체 레코드는 없지만 하위 노드는 있는 노드를 뜻합니다. 아래 예시를 참고하세요. 이 동작은 와일드카드 해석에서 빈 비종단의 역할을 정의하는 [RFC 4592](https://www.rfc-editor.org/rfc/rfc4592.html)를 준수합니다.

<Details header="예시">

<Example>

**example.com**의 DNS 관리

| **Type** | **Name** | **Content** |
| -------- | -------- | ------------------------- |
| A | * | `192.0.2.1` |
| A | a.b | `192.0.2.5` |

</Example>

이 예시에서 `a.b.example.com`은 `b.example.com`의 하위이며, `b.example.com`은 빈 비종단입니다. 따라서 `*.example.com` 와일드카드는 `b.example.com`에 적용되지 않습니다.

</Details>

- 하위 도메인 위임: 하위 도메인이 NS 레코드로 위임되면, 해당 레코드가 존재하더라도 Cloudflare는 부모 영역에서 그 하위 도메인에 대한 다른 레코드(A, TXT, CNAME 등)를 제공하지 않습니다.

<Details header="예시">

<Example>

**example.com**의 DNS 관리

| **Type** | **Name** | **Content** |
| -------- | -------- | ------------------------- |
| NS | www | ns1.externalhost.com |
| NS | www | ns2.externalhost.com |
| TXT | www | "5bb16e6b5a444eedb48ace40c471bcc9" |
| A | www | `192.0.2.1` |

</Example>

이 예시에서는 `www.example.com`에 대한 TXT 레코드와 A 레코드가 제공되지 않습니다.

</Details>

## 영역에서 활성화

기존 영역에서 고급 네임서버를 활성화하려면 다음 단계를 따르세요.

1. 영역에서 고급 네임서버를 선택합니다.

   <Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">
   1. Cloudflare 대시보드에서 **DNS Records** 페이지로 이동합니다.

      <DashButton url="/?to=/:account/:zone/dns/records" />

   2. **Cloudflare nameservers** 카드에서 **Advanced nameservers**를 활성화합니다.
   3. 페이지를 새로 고치면 카드에 고급 네임서버 `NS` 레코드 값이 표시됩니다.

   </TabItem> <TabItem label="API">

   [Update DNS Settings](/api/resources/dns/subresources/settings/subresources/zone/methods/edit/) 엔드포인트를 사용해 다음과 같은 PATCH 요청을 보냅니다.

   <APIRequest
   	path="/zones/{zone_id}/dns_settings"
   	method="PATCH"
   	json={{
   		foundation_dns: true,
   	}}
   />

   응답 본문에는 `nameservers` 객체 안에 할당된 네임서버가 포함됩니다. 다음 단계에서 이 네임서버를 사용합니다.

   </TabItem> </Tabs>

2. 등록기관에서 권한 네임서버를 업데이트합니다. 이 단계는 [Cloudflare Registrar](/registrar/) 사용 여부에 따라 달라집니다.
   - Cloudflare Registrar를 사용 중이라면 [Cloudflare Support](/support/contacting-cloudflare-support/)에 문의하여 네임서버를 업데이트해 달라고 요청하세요.
   - 다른 등록기관을 사용하거나 영역이 위임된 상태라면 [직접 네임서버를 업데이트](/dns/nameservers/update-nameservers/#specific-processes)하세요.

     :::caution

     할당된 네임서버 값을 정확히 그대로 복사해야 합니다.
     :::

`1.1.1.1`을 설정한 뒤에는 Cloudflare 리졸버에 제대로 연결되었는지 확인할 수 있습니다.

1. 설정한 기기(스마트폰이나 컴퓨터) 또는 구성한 라우터에 연결된 기기에서 웹 브라우저를 엽니다.
2. 브라우저 주소창에 [https://1.1.1.1/help](https://one.one.one.one/help)을 입력합니다.

페이지가 로드되어 테스트를 완료할 때까지 기다리면, 해당 페이지가 `1.1.1.1`에 어떤 방식으로 연결되어 있는지와 연결된 Cloudflare 데이터 센터 정보 요약을 보여 줍니다.

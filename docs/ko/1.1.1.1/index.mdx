<Description>

Cloudflare의 공개 DNS 리졸버로 더 빠르고 안전한 인터넷 환경을 경험하세요.

</Description>

<Plan type="all" />

1.1.1.1은 Cloudflare가 운영하는 공개 DNS 리졸버입니다. [DNS 리졸버](https://www.cloudflare.com/learning/dns/what-is-dns/)는 `cloudflare.com`과 같은 도메인을 웹사이트에 접속하는 데 필요한 IP 주소(예: `104.16.123.96`)로 변환하여 인터넷을 빠르고 사적으로 이용할 수 있게 합니다.

대부분의 DNS 리졸버와 달리 1.1.1.1은 사용자 데이터를 광고주에게 판매하지 않습니다. [가장 빠른 DNS 리졸버](https://www.dnsperf.com/#!dns-resolvers)로 측정되었으며, [전 세계 수백 개 도시](https://www.cloudflare.com/network/)에 배포되어 자체 서버에서 서비스 중인 수백만 개 도메인 주소에 직접 접근할 수 있습니다.

1.1.1.1은 완전히 무료이며, 설정에는 몇 분밖에 걸리지 않고 별도 소프트웨어도 필요하지 않습니다.

***

## 주요 기능

<Feature header="1.1.1.1 for Families" href="/1.1.1.1/setup/#1111-for-families">
1.1.1.1 for Families는 악성 코드와 성인 콘텐츠를 추가로 차단합니다.
</Feature>

<Feature header="암호화된 서비스" href="/1.1.1.1/encryption/">
1.1.1.1은 DNS over HTTPS(DoH) 또는 DNS over TLS(DoT)를 통해 한층 강화된 보안과 프라이버시를 제공합니다. [Tor 숨김 서비스](/1.1.1.1/additional-options/dns-over-tor/)로도 1.1.1.1에 접근할 수 있습니다.
</Feature>

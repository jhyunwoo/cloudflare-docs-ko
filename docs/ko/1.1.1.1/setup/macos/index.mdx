변경 전에 기존 DNS 주소가 있다면 기록해 두었다가 필요할 때 다시 사용할 수 있도록 하세요.

1. **System Settings**를 엽니다. 키보드에서 `CMD + Space`를 눌러 `System Settings`를 검색해도 됩니다.
2. **Network**로 이동합니다.
3. 네트워크 서비스를 선택합니다.
4. **Details**를 선택합니다.
5. **DNS** 탭으로 이동합니다.
6. **DNS Servers**에서 **Add**를 선택합니다.
7. <Render file="all-ipv4" product="1.1.1.1" />
8. <Render file="all-ipv6" product="1.1.1.1" />
9. **OK**를 선택합니다.

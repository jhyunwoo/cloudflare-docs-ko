[1.1.1.1: Faster Internet](https://apps.apple.com/us/app/1-1-1-1-faster-internet/id1423538627)는 iOS 기기에서 1.1.1.1 DNS 리졸버와 1.1.1.1 for Families를 설정하는 가장 권장되는 방법입니다. 어떤 네트워크에 연결하든 자동으로 1.1.1.1을 사용하도록 구성하며, 셀룰러 연결에서 대체 DNS를 지정할 수 없는 iOS의 한계도 해결합니다.

이 앱에서는 DNS 쿼리 암호화를 켜거나 [WARP 모드](/warp-client/)를 활성화해 DNS 쿼리를 포함한 HTTP 트래픽 전체를 안전하게 보호할 수도 있습니다.

앱 설정에서 원하는 옵션을 선택하면 되며, 기본값은 WARP 모드입니다.

## 1.1.1.1: Faster Internet 설정

1. [App Store에서 1.1.1.1: Faster Internet](https://apps.apple.com/us/app/1-1-1-1-faster-internet/id1423538627)을 무료로 다운로드합니다.
2. 앱을 실행해 서비스 약관에 동의합니다.
3. 기기가 1.1.1.1에 안전하게 연결될 수 있도록 VPN 프로필 설치를 허용합니다.
4. **WARP** 버튼을 **Connected**로 전환합니다.

### 1.1.1.1 for Families 활성화

1. 1.1.1.1: Faster Internet를 엽니다.
2. **메뉴 버튼**을 탭합니다.
3. **Advanced** > **Connection options**를 선택합니다.
4. **DNS settings** > **1.1.1.1 for Families**에서 사용할 옵션을 고릅니다.

## 수동으로 1.1.1.1 구성

:::note


수동으로 1.1.1.1을 구성하면 연결하는 Wi-Fi 네트워크마다 반복 설정해야 하며, 셀룰러 연결에는 적용되지 않습니다.


:::

기존에 설정해 둔 DNS 주소가 있다면 기록해 두었다가 필요 시 다시 사용할 수 있도록 하세요.

1. **Settings** > **Wi-Fi**로 이동합니다.
2. 연결된 Wi-Fi 네트워크 옆의 **'i'** 아이콘을 선택합니다.
3. 아래로 스크롤해 **Configure DNS**를 선택합니다.
4. 구성을 **Automatic**에서 **Manual**로 바꿉니다.
5. **Add Server**를 선택합니다.

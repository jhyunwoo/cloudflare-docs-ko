변경 전에 기존 DNS 주소가 있다면 기록해 두었다가 필요할 때 다시 사용할 수 있도록 하세요.

선호하는 방식을 선택해 [명령줄 인터페이스(CLI)](#use-command-line-interface-cli) 또는 [그래픽 사용자 인터페이스(GUI)](#use-graphical-user-interface-gui)로 1.1.1.1을 설정할 수 있습니다.

## Use command line interface (CLI)

1.1.1.1 또는 1.1.1.1 for Families 중 어떤 구성을 사용할지 결정하고, 필요한 경우 `1.1.1.1`을 해당 [IPv4/IPv6 주소](/1.1.1.1/ip-addresses/)로 바꿔서 사용하세요.

### `resolv.conf`

대부분 `/etc/resolv.conf`에서 시스템이 사용하는 리졸버 IP를 지정합니다.

그렇다면 아래 원라인 명령으로 기본 리졸버를 `1.1.1.1`, 백업을 `1.0.0.1`로 지정할 수 있습니다.

```sh
echo -e "nameserver 1.1.1.1\nnameserver 1.0.0.1" | sudo tee /etc/resolv.conf
```

:::caution

DHCP 같은 다른 시스템이 `/etc/resolv.conf`를 자동으로 덮어쓸 수 있습니다. 이 경우 네트워크 설정이나 DHCP 서버에서 1.1.1.1을 사용하도록 변경하는 편이 좋습니다.
:::

물론 `nano`, `vim` 등 편집기를 사용해 수동으로 수정해도 됩니다.

### `systemd-resolved`

`systemd-resolved`를 사용하며 `/etc/systemd/resolved.conf`에서 리졸버를 설정한다면 다음 단계를 따르세요.

1. 아래 명령을 실행합니다. `<EDITOR>`는 선호하는 편집기로 바꿉니다.

```sh
sudo <EDITOR> /etc/systemd/resolved.conf
```

2. 편집기에서 다음 내용을 추가하거나 수정합니다.

```txt
[Resolve]
DNS=1.1.1.1
```
DNS over TLS를 사용하려면 `#one.one.one.one`을 추가하고 `DNSOverTLS`를 `yes`로 설정합니다.

```txt
[Resolve]
DNS=1.1.1.1#one.one.one.one
DNSOverTLS=yes
```

## Use graphical user interface (GUI)

### GNOME

1. **Show Applications** > **Settings** > **Network**로 이동합니다.
2. 구성하려는 어댑터(예: Ethernet 또는 Wi-Fi)를 선택하고 **Settings** 버튼을 누릅니다.
3. **IPv4** 탭 > **DNS** 섹션에서 **Automatic** 토글을 끕니다.
4. <Render file="all-ipv4" product="1.1.1.1" />
5. **IPv6** 탭으로 이동합니다.
6. <Render file="all-ipv6" product="1.1.1.1" />
7. **Apply**를 선택합니다.

### KDE Plasma

1. **System Settings** > **Wi-Fi & Internet** > **Wi-Fi & Networking**(Plasma 5에서는 **Connections**)으로 이동합니다.
2. 구성하려는 연결(현재 접속 중인 네트워크 등)을 선택합니다.
3. **IPv4** 탭에서 **Method** 드롭다운을 _Automatic (Only addresses)_로 바꿉니다.
4. **DNS servers** 입력란을 선택합니다.
5. <Render file="all-ipv4" product="1.1.1.1" />
6. **IPv6** 탭에서 **Method** 드롭다운을 _Automatic (Only addresses)_로 바꿉니다.
7. **DNS servers** 입력란을 선택합니다.
8. <Render file="all-ipv6" product="1.1.1.1" />
9. **Apply**를 선택합니다.

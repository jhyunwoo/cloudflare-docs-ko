1. Azure 포털에 로그인합니다.
2. 왼쪽 메뉴에서 **Virtual Networks**를 선택합니다.
3. 가상 머신(VM)과 연결된 가상 네트워크로 이동합니다.
4. **DNS Servers** > **Custom**을 선택하고 항목을 두 개 추가해 <Render file="ipv4" product="1.1.1.1" /> 값을 입력합니다.
5. **Save**를 선택합니다.

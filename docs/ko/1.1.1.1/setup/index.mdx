## 1.1.1.1 for Families

1.1.1.1 for Families는 멀웨어·피싱 등 보안 위협 가능성에 따라 인터넷 목적지를 분류합니다.

디폴트 옵션은 두 가지입니다.


<Details header='멀웨어 차단'>

다음 DNS 리졸버를 사용하면 악성 컨텐츠를 차단할 수 있습니다.

* `1.1.1.2`
* `1.0.0.2`
* `2606:4700:4700::1112`
* `2606:4700:4700::1002`


</Details>


<Details header="멀웨어·성인 컨텐츠 차단">

다음 DNS 리졸버를 사용하면 멀웨어와 성인 컨텐츠를 모두 차단할 수 있습니다.

* `1.1.1.3`
* `1.0.0.3`
* `2606:4700:4700::1113`
* `2606:4700:4700::1003`


</Details>

DNS 쿼리에 포함된 [정규화된 도메인 이름(FQDN)](https://en.wikipedia.org/wiki/Fully_qualified_domain_name)이나 IP가 악성으로 분류되면 Cloudflare는 `0.0.0.0`을 반환합니다.

:::note[도메인 오분류]


1.1.1.1 for Families 사용 중 도메인이 잘못 분류됐다고 생각되면 [이 양식](https://radar.cloudflare.com/categorization-feedback/)으로 알려 주세요. 제출 내용은 익명으로 처리되며, Cloudflare는 해당 정보를 바탕으로 카테고리 정확도를 개선합니다.


:::

### 1.1.1.1 for Families 테스트

설정을 마친 뒤 아래 URL로 필터링이 잘 동작하는지 확인할 수 있습니다.

* [https://malware.testcategory.com/](https://malware.testcategory.com/): 알려진 멀웨어 주소가 제대로 차단되는지 확인합니다.
* [https://nudity.testcategory.com/](https://nudity.testcategory.com/): 성인 컨텐츠 및 멀웨어 주소를 동시에 차단하는지 확인합니다.

### DNS over HTTPS(DoH)

DoH를 지원하는 라우터 등의 클라이언트를 사용 중이라면 1.1.1.1 for Families와 함께 DNS 쿼리를 HTTPS로 암호화할 수 있습니다. 그러면 악성 행위자나 광고주, ISP 등이 쿼리를 감청하거나 조작하지 못합니다. DoH에 대한 자세한 내용은 [DNS 암호화 학습 센터](https://www.cloudflare.com/learning/dns/dns-over-tls/)를 참고하세요.

암호화된 DoH 연결을 설정하려면 클라이언트의 해당 입력란에 아래 URL을 입력합니다.


<Details header="멀웨어 차단">

```txt
https://security.cloudflare-dns.com/dns-query
```


</Details>


<Details header="멀웨어·성인 컨텐츠 차단">

```txt
https://family.cloudflare-dns.com/dns-query
```


</Details>

### DNS over TLS(DoT)

1.1.1.1 for Families는 DoT도 지원합니다. DoT 지원 라우터 등 호환 클라이언트를 사용하면 DNS 쿼리를 암호화해 스푸핑이나 감시에 대비할 수 있습니다. 자세한 내용은 [DNS 암호화 학습 센터](https://www.cloudflare.com/learning/dns/dns-over-tls/)를 참고하세요.

암호화된 DoT 연결을 설정하려면 클라이언트의 해당 입력란에 아래 호스트명을 입력합니다.


<Details header="멀웨어 차단">

```txt
security.cloudflare-dns.com
```


</Details>


<Details header="멀웨어·성인 컨텐츠 차단">

```txt
family.cloudflare-dns.com
```


</Details>

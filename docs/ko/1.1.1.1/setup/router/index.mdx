1. 브라우저에서 라우터 관리 콘솔의 **IP 주소**로 이동합니다.
   * Linksys·Asus 라우터: `http://192.168.1.1` 또는 `http://router.asus.com`
   * Netgear 라우터: `http://192.168.1.1` 또는 `http://routerlogin.net`
   * D-Link 라우터: `http://192.168.0.1`
   * Ubiquiti 라우터: `http://unifi.ubnt.com`

2. 라우터 자격 증명을 입력합니다. 가정용 라우터의 기본 관리자 정보는 장치 뒤나 아래에 표기돼 있는 경우가 많습니다.

3. 관리자 콘솔에서 **DNS settings**를 찾습니다. **WAN**, **IPv6**(ASUS) 또는 **Internet**(Netgear) 같은 항목에 있을 수 있으니 장치 설명서를 참고하세요.

4. 현재 설정된 DNS 주소가 있다면 기록해 두었다가 필요 시 다시 사용할 수 있도록 합니다.

## OpenWrt에서 DNS-Over-TLS 사용

OpenWrt를 실행 중인 라우터라면 DNS-over-TLS로 라우터의 DNS 트래픽을 암호화할 수 있습니다. 자세한 단계는 블로그 글 [Adding DNS-Over-TLS support to OpenWrt (LEDE) with Unbound](https://blog.cloudflare.com/dns-over-tls-for-openwrt/)을 참고하세요.

## FRITZ!Box

[FRITZ!OS 7.20](https://en.avm.de/press/press-releases/2020/07/fritzos-720-more-performance-convenience-security/)부터 DNS over TLS가 지원됩니다. 구성 방법은 [Configuring different DNS servers in the FRITZ!Box](https://en.avm.de/service/knowledge-base/dok/FRITZ-Box-7590/165_Configuring-different-DNS-servers-in-the-FRITZ-Box/) 문서를 참고하세요.

[1.1.1.1: Faster Internet](https://play.google.com/store/apps/details?id=com.cloudflare.onedotonedotonedotone)는 1.1.1.1 DNS 리졸버와 1.1.1.1 for Families를 설정하는 가장 쉬운 방법입니다. 어떤 네트워크에 연결하든 기기가 자동으로 1.1.1.1을 사용하도록 구성해 줍니다.

이 앱에서는 DNS 쿼리 암호화를 켜거나 [WARP 모드](/warp-client/)를 활성화해 DNS 쿼리를 포함한 HTTP 트래픽 전체를 안전하게 보호할 수도 있습니다.

앱 설정에서 원하는 옵션을 선택하면 되며, 기본값은 WARP 모드입니다.
## 1.1.1.1: Faster Internet 설정

1. [Google Play에서 1.1.1.1: Faster Internet](https://play.google.com/store/apps/details?id=com.cloudflare.onedotonedotonedotone)을 무료로 다운로드합니다.
2. 앱을 실행해 서비스 약관에 동의합니다.
3. **WARP** 스위치를 **Connected** 상태로 전환합니다.
4. 기기가 1.1.1.1에 안전하게 연결될 수 있도록 VPN 프로필 설치를 허용합니다.

이제 인터넷 연결과 DNS 쿼리가 보호됩니다.

### 1.1.1.1 for Families 활성화

1. 1.1.1.1: Faster Internet를 엽니다.
2. **메뉴 버튼**을 탭합니다.
3. **Advanced** > **Connection options**를 선택합니다.
4. **DNS settings** > **1.1.1.1 for Families**에서 사용할 옵션을 고릅니다.

## 수동으로 1.1.1.1 구성

### Android 11 이상

Android 11 이상 버전은 DNS over TLS(DoT)와 DNS over HTTPS(DoH)를 모두 지원합니다.

1. **Settings** > **Network & internet**으로 이동합니다.
2. **Advanced** > **Private DNS**를 선택합니다.
3. **Private DNS provider hostname** 옵션을 고릅니다.
4. 원하는 구성에 따라 아래 DNS 호스트명 또는 [IP 주소](/1.1.1.1/ip-addresses/) 중 하나를 입력하고 **Save**를 누릅니다.


  <Details header="1.1.1.1 리졸버 사용">

  * `one.one.one.one`

  기기에서 IP 주소 입력이 필요하면 아래 값을 사용하세요.

    * **IPv4**: `1.1.1.1` 또는 `1.0.0.1`
    * **IPv6**: `2606:4700:4700::1111` 또는 `2606:4700:4700::1001`

  </Details>

  <Details header="1.1.1.1 for Families(멀웨어 차단)">

  * `security.cloudflare-dns.com`

  기기에서 IP 주소 입력이 필요하면 아래 값을 사용하세요.

    * **IPv4**: `1.1.1.2` 또는 `1.0.0.2`
    * **IPv6**: `2606:4700:4700::1112` 또는 `2606:4700:4700::1002`

  </Details>

  <Details header="1.1.1.1 for Families(멀웨어·성인 컨텐츠 차단)">

  * `family.cloudflare-dns.com`

  기기에서 IP 주소 입력이 필요하면 아래 값을 사용하세요.

    * **IPv4**: `1.1.1.3` 또는 `1.0.0.3`
    * **IPv6**: `2606:4700:4700::1113` 또는 `2606:4700:4700::1003`

  </Details>

### Android 9 또는 10

Android 9/10은 DNS over TLS를 지원해 쿼리를 암호화할 수 있으며, Android에서는 이 기능을 Private DNS라고 부릅니다. 이전 버전과 달리 새로운 Wi-Fi 네트워크마다 1.1.1.1을 다시 설정할 필요가 없습니다.

1. **Settings** > **Network & internet**으로 이동합니다.
2. **Advanced** > **Private DNS**를 선택합니다.
3. **Private DNS provider hostname** 옵션을 고릅니다.
4. `one.one.one.one`을 입력하고 **Save**를 누릅니다. 1.1.1.1 for Families를 쓰고 싶다면 아래 옵션을 참고하세요.


  <Details header="1.1.1.1 for Families(멀웨어 차단)">

  * `security.cloudflare-dns.com`

  기기에서 IP 주소 입력이 필요하면 아래 값을 사용하세요.

    * **IPv4**: `1.1.1.2` 또는 `1.0.0.2`
    * **IPv6**: `2606:4700:4700::1112` 또는 `2606:4700:4700::1002`

  </Details>

  <Details header="1.1.1.1 for Families(멀웨어·성인 컨텐츠 차단)">

  * `family.cloudflare-dns.com`

  기기에서 IP 주소 입력이 필요하면 아래 값을 사용하세요.

    * **IPv4**: `1.1.1.3` 또는 `1.0.0.3`
    * **IPv6**: `2606:4700:4700::1113` 또는 `2606:4700:4700::1003`

  </Details>

### 이전 Android 버전

변경 전에 기존 DNS 주소가 있다면 기록해 두었다가 필요할 때 다시 사용할 수 있도록 하세요.

1. **Settings** > **Wi-Fi**를 엽니다.
2. 현재 연결된 네트워크 이름을 길게 누릅니다.
3. **Modify Network**를 선택합니다.
4. **Show Advanced Options** 체크박스를 켭니다.
5. IP Settings를 **Static**으로 변경합니다.

7. <Render file="all-ipv6" product="1.1.1.1" />
8. **Save**를 선택합니다. 변경 사항을 적용하려면 네트워크를 끊었다가 다시 연결해야 할 수도 있습니다.

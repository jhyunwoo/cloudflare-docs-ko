Google Cloud는 Cloud DNS에서 [아웃바운드 서버 정책](https://cloud.google.com/dns/docs/server-policies-overview#dns-server-policy-out)을 설정할 수 있습니다. 정책은 VPC(Virtual Private Cloud) 네트워크 단위로 적용되며, 기존 가상 머신을 포함한 해당 네트워크의 모든 리소스에 영향을 줍니다.

:::note

[Cloudflare Zero Trust](/cloudflare-one/)를 사용 중이라면 지정된 [location](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/)별로 [DNS 정책](/cloudflare-one/traffic-policies/dns-policies/)을 Gateway에서 적용할 수도 있습니다.

:::

Google Cloud VPC 네트워크에 1.1.1.1을 설정하려면:

1. [Google Cloud Console](https://console.cloud.google.com)에 접속합니다.
2. **Network Services** > **Cloud DNS**로 이동한 뒤 [**DNS Server Policies**](https://console.cloud.google.com/net-services/dns/policies)를 선택합니다.
3. **Create Policy**를 선택합니다.
4. 정책 이름(예: `cloudflare-1-1-1-1`)을 입력하고 연결할 VPC 네트워크를 지정합니다.
5. **Alternate DNS servers**에서 **Add Item**을 선택하고 <Render file="ipv4" product="1.1.1.1" /> 값을 입력합니다.
6. **Create**를 선택합니다.

이제 지정한 VPC 네트워크에서 발생하는 DNS 요청은 1.1.1.1을 사용하게 됩니다.

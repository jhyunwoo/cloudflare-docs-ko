## Windows 10

변경 전에 기존 DNS 주소가 있다면 기록해 두었다가 필요할 때 다시 사용할 수 있도록 하세요.

1. **Start 메뉴** > **Settings**를 선택합니다.
2. **Network and Internet**에서 **Change Adapter Options**를 선택합니다.
3. 연결 중인 Ethernet 또는 Wi-Fi 네트워크를 마우스 오른쪽 버튼으로 클릭해 **Properties**를 선택합니다.
4. **Internet Protocol Version 4**를 선택합니다.
5. **Properties** > **Use the following DNS server addresses**를 선택합니다.
6. <Render file="all-ipv4" product="1.1.1.1" />
7. **OK**를 선택합니다.
8. **Internet Protocol Version 6**으로 이동합니다.
9. **Properties** > **Use the following DNS server addresses**를 선택합니다.
10. <Render file="all-ipv6" product="1.1.1.1" />
11. **OK**를 선택합니다.

## Windows 11

변경 전에 기존 DNS 주소가 있다면 기록해 두었다가 필요할 때 다시 사용할 수 있도록 하세요.

1. **Start 메뉴** > **Settings**를 선택합니다.
2. **Network and Internet**에서 구성하려는 어댑터(예: Ethernet 또는 Wi-Fi)를 선택합니다.
3. **DNS server assignment**까지 스크롤한 뒤 **Edit**을 선택합니다.
4. **Automatic (DHCP)** 드롭다운을 **Manual**로 변경합니다.
5. **IPv4** 토글을 켭니다.
6. <Render file="all-ipv4" product="1.1.1.1" />
7. **IPv6** 토글을 켭니다.
8. <Render file="all-ipv6" product="1.1.1.1" />
9. **Save**를 선택합니다.

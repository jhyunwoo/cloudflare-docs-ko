## PS4

1. **Settings** > **Network** > **Set Up Internet Connection**으로 이동합니다.
2. 인터넷 연결 방식에 따라 **Wi-Fi** 또는 **LAN**을 선택합니다.
3. **Custom**을 선택합니다.
4. **IP Address Settings**를 **Automatic**으로 설정합니다.
5. **DHCP Host Name**을 **Do Not Specify**로 변경합니다.
6. **DNS Settings**를 **Manual**로 설정합니다.
7. **Primary DNS**와 **Secondary DNS**에 <Render file="ipv4" product="1.1.1.1" /> 값을 입력합니다.
8. 추가 DNS 서버를 입력할 수 있다면 <Render file="ipv6" product="1.1.1.1" /> 값도 넣습니다.
9. **MTU Settings**를 **Automatic**으로 설정합니다.
10. **Proxy Server**를 **Do Not Use**로 설정합니다.

## Xbox One

1. 컨트롤러에서 Xbox 버튼을 눌러 네트워크 화면을 엽니다.
2. **Settings** > **Network** > **Network Settings**로 이동합니다.
3. **Advanced Settings** > **DNS Settings**로 이동합니다.
4. **Manual**을 선택합니다.
5. **Primary DNS**와 **Secondary DNS**에 <Render file="ipv4" product="1.1.1.1" /> 값을 입력합니다.
6. 추가 DNS 서버 입력 옵션이 있다면 <Render file="ipv6" product="1.1.1.1" /> 값도 넣습니다.
7. 완료되면 확인 화면이 표시됩니다. **B**를 눌러 저장합니다.

## Nintendo

다음 지침은 New Nintendo 3DS/3DS XL/2DS XL, Nintendo 3DS/3DS XL, Nintendo 2DS에서 모두 사용할 수 있습니다.

1. 홈 메뉴에서 **System Settings**(렌치 아이콘)를 선택합니다.
2. **Internet Settings** > **Connection Settings**를 선택합니다.
3. 인터넷 연결을 선택한 뒤 **Change Settings**를 누릅니다.
4. **Change DNS**를 선택합니다.
5. **Auto-Obtain DNS**를 **No**로 설정합니다.
6. **Detailed Setup**을 선택합니다.
7. **Primary DNS**와 **Secondary DNS**에 <Render file="ipv4" product="1.1.1.1" /> 값을 입력합니다.
8. 추가 DNS 서버를 입력할 수 있다면 <Render file="ipv6" product="1.1.1.1" /> 값도 넣습니다.
9. **Save** > **OK**를 선택합니다.

## Nintendo Switch

1. 홈 버튼을 누른 뒤 **System Settings**를 선택합니다.
2. 아래로 스크롤해 **Internet** > **Internet Settings**를 선택합니다.
3. 인터넷 연결을 선택하고 **Change Settings**를 선택합니다.
4. **DNS Settings** > **Manual**을 선택합니다.
5. **Primary DNS**와 **Secondary DNS**에 <Render file="ipv4" product="1.1.1.1" /> 값을 입력합니다.
6. **Save** > **OK**를 선택합니다.

[DNSSEC는 DNS에 보안 계층을 추가하는 프로토콜](https://www.cloudflare.com/learning/dns/dns-records/dnskey-ds-records/)입니다. DNSSEC는 DNSKEY와 DS라는 두 가지 DNS 레코드를 통해 공개 서명 키 기반 인증을 제공합니다. 이 레코드들은 [RRSIG 레코드](https://www.cloudflare.com/dns/dnssec/how-dnssec-works/)에 포함된 DNSSEC 서명을 검증하는 데 사용됩니다.

1.1.1.1이 지원하는 서명 알고리즘은 다음과 같습니다.

* RSA/SHA-1
* RSA/SHA-256
* RSA/SHA-512
* RSASHA1-NSEC3-SHA1
* ECDSA Curve P-256 with SHA-256 (ECDSAP256SHA256)
* ECDSA Curve P-384 with SHA-384 (ECDSAP384SHA384)
* ED25519

DNS over HTTPS(DoH)를 사용하면 DNS 질의와 응답을 암호화한 뒤 HTTP, HTTP/2, HTTP/3 프로토콜 위로 전달할 수 있습니다. 이 방식을 적용하면 공격자가 DNS 트래픽을 위조하거나 변조하기가 훨씬 어려워집니다. DoH는 표준 HTTPS 포트(443)를 이용해 DNS 질의를 HTTPS 요청 안에 캡슐화하며, 모든 HTTPS 트래픽이 같은 포트를 공유하므로 DNS 트래픽이 다른 HTTPS 트래픽 속에 섞여 보입니다.

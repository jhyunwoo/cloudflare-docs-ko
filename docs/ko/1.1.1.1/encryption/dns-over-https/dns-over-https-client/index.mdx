1.1.1.1에 연결할 때 사용할 수 있는 DoH 클라이언트는 다양합니다.

## Cloudflare WARP 클라이언트

[WARP 클라이언트](/warp-client/) 문서에서 모드별 동작과 각 [운영체제별 시작하기](/warp-client/get-started/) 가이드를 확인하세요.

## DNSCrypt-Proxy

[DNSCrypt-Proxy](https://dnscrypt.info) 2.0 이상은 기본 설정으로 DoH를 지원합니다. 1.1.1.1뿐 아니라 다른 리졸버에도 연결할 수 있고, 로드 밸런싱이나 로컬 필터링 같은 고급 기능도 제공합니다.

1. [DNSCrypt-Proxy를 설치](https://github.com/jedisct1/dnscrypt-proxy/wiki/installation)합니다.

2. `dnscrypt-proxy`가 설치되었고 버전이 2.0 이상인지 확인합니다.

   ```sh
   dnscrypt-proxy -version
   ```

   ```sh output
   2.0.8
   ```

3. [공식 지침](https://github.com/jedisct1/dnscrypt-proxy/wiki/installation#setting-up-dnscrypt-proxy)에 따라 설정 파일을 구성하고, `dnscrypt-proxy.toml`의 서버 목록에 `cloudflare`와 `cloudflare-ipv6`를 추가합니다.

   ```toml
   server_names = ['cloudflare', 'cloudflare-ipv6']
   ```

4. `localhost:53` 포트를 다른 프로세스가 사용하고 있지 않은지 확인한 뒤 다음 명령으로 동작을 점검합니다.

   ```sh
   dnscrypt-proxy -resolve cloudflare-dns.com
   ```

   ```sh output
   Resolving [cloudflare-dns.com]

   Domain exists:  yes, 3 name servers found
   Canonical name: cloudflare-dns.com.
   IP addresses:   2400:cb00:2048:1::6810:6f19, 2400:cb00:2048:1::6810:7019, 104.16.111.25, 104.16.112.25
   TXT records:    -
   Resolver IP:    172.68.140.217
   ```

5. [DNSCrypt-Proxy 설치 안내](https://github.com/jedisct1/dnscrypt-proxy/wiki/installation)에 따라 시스템 서비스로 등록합니다.

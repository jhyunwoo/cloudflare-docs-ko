여러 브라우저가 DNS over HTTPS(DoH)를 지원합니다. DoH를 활성화하면 1.1.1.1과의 연결이 암호화되어 DNS 질의가 프라이버시 침해나 변조로부터 보호됩니다.

브라우저에 따라 이 설정이 이미 기본값으로 켜져 있을 수도 있습니다.

:::note

1.1.1.1 For Families를 사용하려면 아래 단계를 그대로 진행하되 기본 1.1.1.1 옵션 대신 [설정](/1.1.1.1/setup/#dns-over-https-doh) 문서에 제공된 URL을 입력하세요.
:::

## Mozilla Firefox

1. 메뉴 버튼을 열고 **Settings**를 선택합니다.
2. **Privacy & Security** 메뉴에서 **Enable secure DNS using:** 섹션까지 스크롤합니다.
3. **Increased Protection** 또는 **Max Protection**을 선택합니다. 기본값은 **Cloudflare** 공급자입니다.
4. 다른 공급자가 선택되어 있다면 **Choose Provider** 드롭다운에서 **Cloudflare**를 선택합니다.

## Google Chrome

1. 브라우저의 더보기 메뉴(세 점)를 열고 **Settings**로 이동합니다.
2. **Privacy and security** > **Security**를 차례로 선택합니다.
3. 아래로 스크롤해 **Use secure DNS**를 활성화합니다.
4. **With** 옵션을 선택한 후 드롭다운에서 *Cloudflare (1.1.1.1)*을 고릅니다.

## Microsoft Edge

1. 브라우저의 더보기 메뉴를 열어 **Settings**로 이동합니다.
2. **Privacy, Search, and Services**를 선택한 뒤 **Security** 섹션까지 스크롤합니다.
3. **Use secure DNS**를 활성화합니다.
4. **Choose a service provider**를 선택합니다.
5. **Enter custom provider** 드롭다운에서 *Cloudflare (1.1.1.1)*를 선택합니다.

## Brave

1. 브라우저 메뉴 버튼을 열고 **Settings**를 선택합니다.
2. **Privacy and security** > **Security**를 차례로 선택합니다.
3. **Advanced** 아래에서 **Use secure DNS**를 활성화합니다.
4. **Select DNS provider** 드롭다운에서 *Cloudflare (1.1.1.1)*를 선택합니다.

## 브라우저 설정이 올바른지 확인하기

[1.1.1.1 도움말 페이지](https://one.one.one.one/help)을 열어 `Using DNS over HTTPS (DoH)` 항목이 `Yes`인지 확인하세요.

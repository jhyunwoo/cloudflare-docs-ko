## Cloudflare의 개인정보 보호 약속: 1.1.1.1 Public DNS Resolver

1.1.1.1 Public DNS Resolver에는 당사의 [개인정보 처리방침](https://www.cloudflare.com/privacypolicy/)이 적용됩니다. 이 문서는 1.1.1.1 Public DNS Resolver에서 수집하는 정보의 수집, 사용 및 공개 방식에 대한 추가 세부 사항을 제공합니다.

***

인터넷에서 거의 모든 활동은 DNS 요청으로 시작됩니다. DNS는 인터넷의 디렉터리입니다. 링크를 선택하고, 앱을 열고, 이메일을 보내면 휴대폰이나 컴퓨터가 가장 먼저 디렉터리에 묻습니다. "이것은 어디에서 찾을 수 있지?"

안타깝게도 기본적으로 DNS는 대개 느리고 안전하지 않습니다. ISP와 인터넷에서 트래픽을 엿듣는 다른 사람들은 콘텐츠가 암호화되어 있더라도 사용자가 방문하는 모든 사이트와 사용하는 모든 앱을 볼 수 있습니다. 더 우려스러운 점은 일부 DNS 제공자가 사용자의 인터넷 활동에 관한 데이터를 판매하거나 광고 타기팅에 사용한다는 사실입니다.

이러한 현실을 고려해 Cloudflare는 사용자의 프라이버시와 보안을 염두에 두고 DNS 리졸버를 만들었습니다. Cloudflare는 APNIC과 협력하여 사용자 프라이버시와 보안을 중시하는 재귀 DNS 서비스인 1.1.1.1 Public Resolver를 운영합니다. 공용 리졸버로 전송되는 DNS 요청은 안전한 채널을 통해 전달될 수 있으므로, 원치 않는 감시나 중간자 공격이 발생할 가능성을 크게 줄일 수 있습니다.

1.1.1.1 Public DNS Resolver는 프라이버시를 최우선으로 설계되었으며, Cloudflare는 다음을 약속합니다.

1. Cloudflare는 Public Resolver 사용자의 개인 데이터를 제3자에게 판매하거나 공유하지 않으며, Public Resolver의 개인 데이터를 광고 타기팅에 사용하지 않습니다.
2. Cloudflare는 요청 내용 자체만 보관하거나 사용하며, 요청한 사람이 누구인지 식별할 수 있는 정보는 보관하지 않습니다. Cloudflare 네트워크 인프라로 전송되는 전체 트래픽의 최대 0.05%에서 무작위로 샘플링해 캡처한 네트워크 패킷을 제외하면, Cloudflare는 Public Resolver에 대한 DNS 질의의 source IP를 비휘발성 저장소에 보관하지 않습니다. 이러한 무작위 샘플 패킷은 네트워크 문제 해결과 DoS 완화 목적으로만 사용됩니다.
3. Public Resolver 사용자의 IP 주소(클라이언트 또는 source IP 주소)는 비휘발성 저장소에 저장되지 않습니다. Cloudflare는 IP truncation 방식을 사용해 source IP 주소를 익명화합니다(IPv4는 마지막 옥텟, IPv6는 마지막 80비트). Cloudflare는 이 축약된 IP 주소를 25시간 이내에 삭제합니다.
4. Cloudflare는 Public Resolver의 정상적인 운영과 연구 목적을 위해 아래에 명시된 제한된 거래 및 디버그 로그 데이터("Public Resolver Logs")만 보관하거나 사용하며, 해당 Public Resolver Logs는 25시간 이내에 삭제합니다.
5. Cloudflare는 APNIC과의 연구 협력 계약(Research Cooperative Agreement)에 따라 APNIC에 제공하는 경우를 제외하고, Public Resolver Logs를 제3자와 공유하지 않습니다. APNIC은 Public Resolver Logs 안의 익명화된 데이터에 제한적으로 질의할 수 있으며, DNS 시스템 운영과 관련된 연구를 수행할 수 있습니다.

Cloudflare는 사용자 정보를 보관할 수 없도록 하기 위해 기술적 조치를 취했습니다.

또한 당사가 약속한 내용을 실제로 지키고 있음을 확인하는 공개 보고서를 발행하기 위해, 세계 4대 회계법인 중 하나에 감사를 의뢰했습니다. 해당 보고서는 [Certifications and compliance resources](https://www.cloudflare.com/trust-hub/compliance-resources/) 페이지에서 확인할 수 있습니다.

## APNIC과의 제한된 데이터 공유

Cloudflare는 아시아 태평양 지역의 지역 인터넷 레지스트리인 [APNIC Labs](https://labs.apnic.net/?p=1127)와 협력하여 `1.1.1.1` IP 주소를 Cloudflare Public DNS Resolver의 주소로 사용하고 있습니다. 전 세계적으로 개방적이고 안전한 인터넷을 보장한다는 사명의 일환으로 APNIC은 인터넷의 작동 방식과 거버넌스에 대한 연구를 수행하며, 그 결과를 [www.apnic.net](http://www.apnic.net) 웹사이트에서 공개합니다.

Cloudflare는 Cloudflare Public DNS Resolver를 통해 수집한 익명화 데이터 일부에 대해 APNIC이 접근할 수 있도록 제공하기로 합의했습니다. 구체적으로 APNIC은 Cloudflare API를 통해 query names, query types, resolver location 및 기타 메타데이터에 접근할 수 있으며, 이를 통해 인터넷에서 발생하는 DDoS 공격 규모나 IPv6 도입 현황과 같은 주제를 연구할 수 있습니다.

APNIC Labs는 이러한 데이터를 비영리 운영 연구 목적으로 사용합니다. Cloudflare는 프라이버시 약속의 일환으로 클라이언트와 연결된 IP 주소에 대한 접근 권한은 APNIC에 제공하지 않습니다.

APNIC을 제외하면, Cloudflare는 Public Resolver Logs를 어떠한 제3자와도 공유하지 않습니다.

## Public Resolver Logs에 포함되는 데이터

당사가 저장하는 Public Resolver Logs는 오직 다음 필드로만 구성됩니다.

* answerData type
* answerData
* coloID (unique Cloudflare data center ID)
* date
* dateTime
* dstIPVersion
* dstIPv6
* dstIPv4
* dstPort
* ede
* ednsVersion
* ednsPayload
* ednsNsid
* feature.uid
* feature.value
* metalId (unique Cloudflare data center ID)
* ns ip
* ns name
* protocol
* queryName
* queryType
* queryClass
* queryRd
* queryDo
* querySize
* queryEdns
* queryCd
* responseType
* responseCode
* responseSize
* responseCount
* responseTimeMs
* responseCached
* responseMinTTL
* reused
* srcAsNum
* srcCountry
* srcIPVersion
* validationState

또한 재귀 리졸버는 DNS 계층 구조에 있는 여러 authoritative nameserver로 나가는 질의를 수행하며, 이 요청들은 subrequest 필드에 기록됩니다. 이 로그는 공용 DNS 리졸버 서비스의 운영과 디버깅을 위해 사용됩니다.

Public Resolver Logs에는 다음 subrequest 데이터가 포함됩니다.

* subrequest.ipv6 (authoritative nameserver)
* subrequest.ipv4 (authoritative nameserver)
* subrequest.protocol
* subrequest.durationMs
* subrequest.queryName
* subrequest.queryType
* subrequest.responseCode
* subrequest.responseCount
* subrequest.recordType
* subrequest.recordData
* subrequest.error

아래에 설명된 집계 데이터를 생성하는 데 사용되는 Public Resolver Logs의 제한된 샘플 데이터(이 데이터에는 축약된 IP 주소가 포함되지 않음)를 제외하면, 모든 Public Resolver Logs는 Cloudflare가 해당 정보를 수신한 후 25시간 이내에 삭제됩니다.

Cloudflare는 다음과 같은 집계를 생성할 수 있습니다.

* Cloudflare 데이터 센터별, 서로 다른 프로토콜 설정(예: tcp/udp/dnssec)을 사용하는 질의의 총 수
* Cloudflare 데이터 센터별, 서로 다른 프로토콜 설정에 대한 응답 코드/시간 분위수
* Cloudflare 데이터 센터가 처리한 총 요청 수
* 지역별로 요청된 모든 도메인 이름의 집계 목록, 집계 요청 수, 그리고 처음 요청된 시각의 타임스탬프
* 분, 일, 프로토콜(HTTPS/UDP/TCP/TLS), 지역, Cloudflare 데이터 센터, Autonomous System Number별로 집계한 고유 클라이언트 수, IPv4 질의 수, IPv6 질의 수, RD 비트가 설정된 질의 수, DNSSEC를 요청한 질의 수, DNSSEC 응답의 bogus/valid/invalid 수, 유형별 질의 수, 각 응답 코드별 응답 수, 응답 시간 분위수(예: 50 percentile), 응답 TTL, 캐시된 응답 수
* 일, 월, Cloudflare 데이터 센터, IPv4 대 IPv6 기준으로 집계한 질의 수, EDNS가 포함된 질의 수, 바이트 수, 응답 시간 분위수(예: 50 percentile)
* 일, 지역, 이름, 유형 기준으로 집계한 질의 수, 응답 코드, 응답 코드 분위수(예: 50 percentile)

Cloudflare는 Cloudflare Radar를 구동하고 Cloudflare Resolver의 전반적인 성능 향상 및 보안 위협 식별 등 Cloudflare 서비스 개선을 지원하기 위해 위에 설명한 데이터를 무기한 저장할 수 있습니다.

## 콘텐츠 차단 요청은 어떻게 처리하나요?

Cloudflare는 콘텐츠 차단이나 필터링을 목적으로 설계되지 않은, 직접적이고 빠른 DNS 해석을 위한 1.1.1.1 Public DNS Resolver를 통해 어떤 콘텐츠도 차단하거나 필터링하지 않습니다. 반면 1.1.1.1 for Families는 가정 네트워크를 보호하려는 개인을 돕기 위해 설계되었으며, 악성코드와 성인 콘텐츠를 차단·필터링합니다.

일반적으로 Cloudflare는 정부 또는 민사상의 DNS 수준 콘텐츠 차단 요청이 비효율적이고 비능률적이며 과도하다고 봅니다. 이러한 차단은 사용자의 위치와 관계없이 리졸버의 모든 사용자에게 전 세계적으로 적용되므로, 차단을 요청한 정부의 관할권 밖에 있는 최종 사용자에게도 영향을 미칩니다. 따라서 1.1.1.1 Public DNS Resolver나 1.1.1.1 for Families와 같이 전 세계에서 이용 가능한 공용 재귀 리졸버를 통한 콘텐츠 차단 요청은 전 세계적 차단 요청으로 평가되어야 합니다.

이처럼 광범위한 역외 효과를 고려할 때, Cloudflare가 1.1.1.1 Public DNS Resolver를 통해 도메인이나 콘텐츠에 대한 접근을 차단해 달라는 서면 요청을 사법 기관이나 정부 기관으로부터 받거나, 1.1.1.1 for Families의 필터링 범위를 벗어나는 도메인 또는 콘텐츠 차단 요청을 받는다면, Cloudflare는 그러한 요청을 이행하기 전에 법적 구제 수단을 추구할 것입니다. 또한 법적으로 금지되지 않는 한, 접근 차단을 요청한 모든 정부 요청을 반기별 투명성 보고서에 기록하겠다는 점도 약속드립니다.

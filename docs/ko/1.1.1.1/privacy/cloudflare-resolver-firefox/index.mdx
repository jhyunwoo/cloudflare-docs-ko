## Firefox용 Cloudflare Resolver에 대한 자주 묻는 질문

### Firefox용 Cloudflare Resolver란 무엇인가요?

[www.mozilla.org](http://www.mozilla.org) 또는 [www.firefox.com](http://www.firefox.com)과 같은 웹 주소를 웹 브라우저에 입력할 때마다, 웹 브라우저는 DNS 리졸버에 질의를 보냅니다. DNS를 인터넷의 카드 색인이라고 생각하면, DNS 리졸버는 그 색인의 정보를 활용해 웹사이트의 정확한 위치를 찾아주는 유능한 사서와 같습니다. 리졸버는 질의를 받으면 사용자가 입력한 웹 주소에 연결된 IP 주소를 조회한 뒤 그 정보를 웹 브라우저에 전달합니다. 이 과정을 "DNS resolution"이라고 하며, 즐겨 찾는 웹사이트를 호스팅하는 서버와 브라우저가 통신하려면 해당 웹사이트의 IP 주소를 알아야 하므로 인터넷 사용 경험에서 매우 중요한 구성 요소입니다.

대부분의 인터넷 사용자는 자신의 기기에서 실행되는 운영 체제에 기본으로 포함된 DNS 리졸버나 네트워크 제공자가 설정한 리졸버를 사용합니다. 하지만 경우에 따라 이러한 리졸버는 원치 않는 감시나 기타 보안 위협에 취약해 만족스럽지 못할 수 있습니다.

이러한 위협에 대응하기 위해 Mozilla는 Cloudflare와 협력하여 Firefox 브라우저 내부에서 Firefox용 Cloudflare Resolver를 통해 직접 DNS 해석을 제공하고 있습니다. 즉, Firefox 브라우저에서 웹 주소를 선택하거나 입력할 때 DNS 조회 요청은 알려지지 않은 DNS 리졸버가 아니라 안전한 채널을 통해 Firefox용 Cloudflare Resolver로 전송되므로, 원치 않는 감시나 중간자 공격이 발생할 가능성을 크게 줄일 수 있습니다.

### Firefox용 Cloudflare Resolver는 어떤 정보를 수집하나요?

Cloudflare가 Firefox용 Resolver의 결과로 처리하는 모든 데이터는 Firefox의 데이터 처리 지침에 따라 데이터 처리자로서 처리됩니다. 따라서 Cloudflare가 Firefox와의 계약에 따라 수집하고 처리하는 데이터에는 [Cloudflare 개인정보 처리방침](https://www.cloudflare.com/privacypolicy/)이 적용되지 않습니다. Firefox와의 계약에 따라 Cloudflare는 Firefox 브라우저를 통해 Firefox용 Cloudflare Resolver로 전송되는 DNS 요청에 대해 제한된 양의 데이터만 수집하기로 합의했습니다. Cloudflare는 Firefox 사용자로부터 다음 정보만 수집합니다.

* date
* dateTime
* srcAsNum
* srcIPVersion
* dstIPVersion
* dstIPv6
* dstIPv4
* dstPort
* protocol
* queryName
* queryType
* queryClass
* queryRd
* queryDo
* querySize
* queryEdns
* ednsVersion
* ednsPayload
* ednsNsid
* responseType
* responseCode
* responseSize
* responseCount
* responseTimeMs
* responseCached
* responseMinTTL
* answerData type
* answerData
* validationState
* coloID (unique Cloudflare data center ID)
* metalId (unique Cloudflare data center ID)

위 정보는 모두 Cloudflare의 임시 로그에 잠시 저장된 후, Cloudflare가 해당 정보를 수신한 시점으로부터 24시간 이내에 영구적으로 삭제됩니다. 위 정보 외에도 Cloudflare는 영구 로그의 일부로 다음 정보를 수집하고 저장합니다.

* 각 Cloudflare 코로케이션 시설이 처리한 총 요청 수
* 요청된 모든 도메인 이름의 집계 목록
* 질의 시각과 함께 수집한 도메인 이름 샘플

Cloudflare의 영구 로그에 저장되는 정보는 익명화되며, Cloudflare의 내부 연구 및 개발 목적을 위해 무기한 보관될 수 있습니다.

### Cloudflare의 약속은 무엇인가요?

Cloudflare는 사용자 데이터가 얼마나 중요한지 잘 알고 있으므로, Firefox용 Cloudflare Resolver에서 수집한 정보는 Firefox용 Cloudflare Resolver의 성능을 개선하고 문제가 발생했을 때 디버깅을 돕는 용도로만 사용하겠다고 약속합니다. 데이터 수집 및 사용을 제한하는 것 외에도 Cloudflare는 다음을 약속합니다.

* Cloudflare는 Firefox 브라우저에서 Firefox용 Cloudflare Resolver로 전송된 DNS 질의에서 개인 정보, IP 주소 또는 기타 사용자 식별자를 보관, 판매 또는 제3자에게 이전하지 않습니다(법률상 요구되는 경우 제외).

* Cloudflare는 이러한 질의에서 수집한 데이터를 다른 Cloudflare 데이터 또는 제3자 데이터와 결합하여 개별 최종 사용자를 식별할 수 있는 방식으로 사용하지 않습니다.

* Cloudflare는 Mozilla의 명시적인 서면 허가 없이 사용자의 데이터를 판매, 라이선스, 서브라이선스하거나 다른 개인 또는 단체에 어떠한 권리도 부여하지 않습니다.

### 콘텐츠 차단에 대한 정부 요청은 어떻게 처리하나요?

Cloudflare는 Firefox용 Cloudflare Resolver를 통해 콘텐츠를 차단하거나 필터링하지 않습니다. Mozilla와의 계약에 따라 Cloudflare는 직접적인 DNS 해석만 제공합니다. Firefox용 Cloudflare Resolver를 통해 도메인이나 콘텐츠에 대한 접근을 차단해 달라는 서면 요청을 사법 기관이나 정부 기관으로부터 받을 경우, Cloudflare는 Mozilla와 협의하여 그러한 요청을 이행하기 전에 이용 가능한 법적 구제 수단을 모두 활용할 것입니다. 또한 법적으로 금지되지 않는 한, 접근 차단을 요청한 모든 정부 요청을 반기별 투명성 보고서에 기록하겠다는 점도 약속드립니다.

* [1.1.1.1 Public DNS Resolver](/1.1.1.1/privacy/public-dns-resolver/): 이 문서는 1.1.1.1 Public DNS Resolver가 처리하는 정보의 수집, 사용 및 공개 방식에 대한 세부 사항을 제공합니다. 1.1.1.1 Public DNS Resolver 서비스에는 당사의 [개인정보 처리방침](https://www.cloudflare.com/privacypolicy/)이 적용됩니다.

* [Resolver for Firefox](/1.1.1.1/privacy/cloudflare-resolver-firefox/): 이 문서는 Firefox용 Cloudflare Resolver가 처리하는 정보의 수집, 사용 및 공개 방식에 대해 설명합니다. Cloudflare가 Firefox용 Cloudflare Resolver와 관련해 처리하는 모든 데이터는 Mozilla의 데이터 처리 지침에 따라 데이터 처리자로서 처리됩니다. Firefox용 Cloudflare Resolver에는 당사의 기본 개인정보 처리방침이 적용되지 않으며, 1.1.1.1 Public DNS Resolver와는 별개의 서비스입니다.

* [1.1.1.1 Application](https://www.cloudflare.com/application/privacypolicy/): 이 정책은 iOS 및 Android용 1.1.1.1 앱과 같은 Cloudflare의 소비자 대상 1.1.1.1 애플리케이션에서 수집, 사용 및 공개하는 정보에 적용됩니다.

[Extended DNS Error Codes](https://www.rfc-editor.org/rfc/rfc8914.html)는 DNS 오류의 원인에 관한 추가 정보를 반환하는 방법입니다. DNS 질의가 실패하는 이유는 매우 다양하므로, 오류의 정확한 원인에 대한 추가 정보를 제공할 필요가 생겼습니다.

1.1.1.1은 Extended DNS Error Codes를 지원합니다. 아래는 1.1.1.1이 반환하는 오류 코드 목록과 그 의미, 그리고 문제 해결을 위해 취해볼 수 있는 단계입니다.

            <td>RRSIG 누락</td>
            <td><code>EDE: 10 (RRSIGs Missing): (for DNSKEY example.com., id = 12345)</code></td>
            <td>1.1.1.1이 레코드의 진위 여부를 확인하는 데 필요한 Resource Record Signatures(RRSigs)를 가져오지 못했습니다. <a href="/dns/">DNS 구성</a>과 응답 코드를 확인하세요. 응답 코드가 <code>SERVFAIL</code>이 아니라면, 이 오류는 경로 어딘가에 비운영 키 문제가 있지만 리졸버가 적어도 하나의 검증 가능한 경로는 찾았음을 뜻합니다. 비운영 키 문제의 예로는 키 롤오버 진행 중, 대기 키, 특정 키로 생성된 서명을 공격자가 제거한 경우 등이 있습니다.</td>
        </tr>

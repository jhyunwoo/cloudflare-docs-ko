인터넷 서비스 제공업체(ISP), 기기 제조사, 공공 Wi-Fi 네트워크, 지방 광대역 제공업체, 보안 스캐닝 서비스 등을 포함한 네트워크 운영자는 자체 재귀 DNS 인프라를 운영하는 대신 [1.1.1.1](/1.1.1.1/setup/)을 사용할 수 있습니다.

Cloudflare는 ISP 및 네트워크 장비 제공업체와 협력하여 그들의 서비스 안에서 [1.1.1.1 for Families](/1.1.1.1/setup/#1111-for-families)를 사용할 수 있도록 지원합니다. 자세한 내용은 [블로그 게시물](https://blog.cloudflare.com/safer-resolver/)을 참고하세요.

1.1.1.1을 사용하면 Cloudflare의 광범위한 [글로벌 네트워크](https://www.cloudflare.com/network/) 덕분에 최종 사용자 성능을 개선할 수 있으며, 지역 캐시를 기반으로 전반적인 캐시 적중률도 높일 수 있습니다.

1.1.1.1 리졸버는 프라이버시 우선 접근 방식을 기반으로 설계되었습니다. 1.1.1.1이 무엇을 기록하고 얼마나 보관하는지에 대해서는 [데이터 및 개인정보 보호 정책](/1.1.1.1/privacy/public-dns-resolver/)을 참고하세요.

## 1.1.1.1 구성

운영자가 1.1.1.1을 사용하는 방법은 여러 가지가 있습니다.

- 최종 사용자 라우터나 기기에 [DNS over HTTPS](/1.1.1.1/encryption/dns-over-https/) 또는 [DNS over TLS](/1.1.1.1/encryption/dns-over-tls/) 프록시를 포함하는 방법(프라이버시에 가장 유리)
- 운영자 네트워크 내에서 DHCP/PPP를 통해 기기에 1.1.1.1을 배포하는 방법(권장, 가장 실용적)
- 엣지 라우터에 있는 DNS 프록시가 연결된 모든 기기를 대신해 1.1.1.1에 요청하도록 하는 방법

가능한 경우 질의에 암호화된 전송(DNS over HTTPS 또는 TLS)을 사용하는 것을 권장합니다. 이렇게 하면 마지막 구간(last-mile) 네트워크에서 사용자 프라이버시를 가장 높은 수준으로 보호할 수 있습니다.

## 사용 가능한 엔드포인트

:::note

[Cloudflare Zero Trust](https://www.cloudflare.com/products/zero-trust/)는 사용자 지정 가능한 [DNS 정책](/cloudflare-one/traffic-policies/dns-policies/), 분석, 추가 기본 제공 필터링 카테고리, 사용자 지정 속도 제한 기능을 지원합니다.

공용 1.1.1.1 리졸버에 대해 추가 제어 기능이 필요하다면 [문의해 주세요](https://www.cloudflare.com/products/zero-trust/).

:::

공개적으로 사용할 수 있는 1.1.1.1 엔드포인트는 다음 표에 정리되어 있습니다.

| 리졸버 | IPv4 주소 | IPv6 <br /> 주소 | DNS over <br /> HTTPS 엔드포인트 | DNS over <br /> TLS 엔드포인트 |
| ---------------------------------------- | -------------------------- | ---------------------------------------------------- | ----------------------------------------------- | ----------------------------- |
| 1.1.1.1 <br />(필터 없음) | `1.1.1.1` <br /> `1.0.0.1` | `2606:4700:4700::1111` <br /> `2606:4700:4700::1001` | `https://cloudflare-dns.com/dns-query` | `one.one.one.one` |
| Families <br />(멀웨어 차단) | `1.1.1.2` <br /> `1.0.0.2` | `2606:4700:4700::1112` <br /> `2606:4700:4700::1002` | `https://security.cloudflare-dns.com/dns-query` | `security.cloudflare-dns.com` |
| Families <br />(성인 콘텐츠 + 멀웨어 차단) | `1.1.1.3` <br /> `1.0.0.3` | `2606:4700:4700::1113` <br /> `2606:4700:4700::1003` | `https://family.cloudflare-dns.com/dns-query` | `family.cloudflare-dns.com` |

최종 사용자가 기본 1.1.1.1 리졸버에서 [1.1.1.1 for Families](/1.1.1.1/setup/#1111-for-families) 엔드포인트 중 하나로 변경할 수 있도록 옵션을 제공하고 싶을 수도 있습니다.

## 속도 제한

일반적인 인터넷 연결 애플리케이션 및/또는 사용자를 위해 1.1.1.1을 사용하는 운영자는 대체로 사용자 대상 속도 제한을 겪지 않아야 합니다. 다만 드문 경우에 보안 스캐닝 사용 사례나 프록시 처리된 트래픽은 당사 인프라와 업스트림 DNS 인프라를 잠재적 남용으로부터 보호하기 위해 속도 제한될 수 있습니다.

권장 모범 사례는 다음과 같습니다.

- 높은 비율로 모든 질의를 단일 IP 주소에서 터널링하거나 프록시하지 마세요. 여러 공인 IP에 질의를 분산하면 캐시 적중률에 영향을 주지 않으면서 이 문제를 완화할 수 있습니다(캐시는 지역 단위입니다).
- 동일한 도메인에 대해 `SERVFAIL`과 같은 "캐시 불가" 응답이 높은 비율로 발생하면, 업스트림 authoritative nameserver를 보호하기 위해 속도 제한될 수 있습니다. 많은 authoritative nameserver는 자체 속도 제한을 시행하며, Cloudflare는 가능한 한 제3자 인프라에 과부하를 주지 않도록 노력합니다.

## 도움말

네트워크 운영자인데도 여전히 해결되지 않은 질문이 있다면, 사용 사례를 `resolver@cloudflare.com`으로 보내 주세요. 보다 자세히 논의할 수 있습니다. Cloudflare에 문의할 때는 반드시 네트워크 내부에서 [1.1.1.1/help](https://one.one.one.one/help)를 방문해 생성된 보고서를 함께 공유하세요.

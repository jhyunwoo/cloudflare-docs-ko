## 함수 만들기

1.1.1.1은 Google Sheets 안에서 바로 작동합니다. 시작하려면 다음 코드를 사용해 [Google Function](https://developers.google.com/apps-script/guides/sheets/functions)을 만드세요:

```js
function NSLookup(type, domain, useCache = false, minCacheTTL = 30) {

  if (typeof type == 'undefined') {
    throw new Error('Missing parameter 1 dns type');
  }

  if (typeof domain == 'undefined') {
    throw new Error('Missing parameter 2 domain name');
  }

  if (typeof useCache != "boolean") {
    throw new Error('Only boolean values allowed in 3 use cache');
  }

  if (typeof minCacheTTL != "number") {
    throw new Error('Only numeric values allowed in 4 min cache ttl');
  }

  type = type.toUpperCase();
  domain = domain.toLowerCase();

  let cache = null;
  if (useCache) {
    // 캐시 키와 해시 생성
    cacheKey = domain + "@" + type;
    cacheHash = Utilities.base64Encode(cacheKey);
    cacheBinKey = "nslookup-result-" + cacheHash;

    cache = CacheService.getScriptCache();
    const cachedResult = cache.get(cacheBinKey);
    if (cachedResult != null) {
      return cachedResult;
    }
  }

  const url = 'https://cloudflare-dns.com/dns-query?name=' + encodeURIComponent(domain) + '&type=' + encodeURIComponent(type);
  const options = {
    muteHttpExceptions: true,
    headers: {
      accept: "application/dns-json"
    }
  };

  const result = UrlFetchApp.fetch(url, options);
  const rc = result.getResponseCode();
  const resultText = result.getContentText();

  if (rc !== 200) {
    throw new Error(rc);
  }

  const errors = [
    { name: "NoError", description: "오류 없음"}, // 0
    { name: "FormErr", description: "형식 오류"}, // 1
    { name: "ServFail", description: "서버 실패"}, // 2
    { name: "NXDomain", description: "존재하지 않는 도메인"}, // 3
    { name: "NotImp", description: "미구현"}, // 4
    { name: "Refused", description: "쿼리 거부"}, // 5
    { name: "YXDomain", description: "존재하면 안 되는 이름이 존재함"}, // 6
    { name: "YXRRSet", description: "존재하면 안 되는 RR 세트가 존재함"}, // 7
    { name: "NXRRSet", description: "존재해야 하는 RR 세트가 없음"}, // 8
    { name: "NotAuth", description: "권한 없음"} // 9
  ];

  const response = JSON.parse(resultText);

  if (response.Status !== 0) {
    return errors[response.Status].name;
  }

  const outputData = [];
  let cacheTTL = 0;

  for (const i in response.Answer) {
    outputData.push(response.Answer[i].data);
    const ttl = response.Answer[i].TTL;
    cacheTTL = Math.min(cacheTTL || ttl, ttl);
  }

  const outputString = outputData.join(',');

  if (useCache) {
    cache.put(cacheBinKey, outputString, Math.max(cacheTTL, minCacheTTL));
  }

  return outputString;
}
```

## 1.1.1.1 사용하기

`NSLookup` 함수에 레코드 유형과 도메인을 전달하면, 함수가 호출된 셀에서 해당 DNS 레코드 값을 반환합니다.

DNS 조회 횟수를 줄이고 결과를 더 빠르게 받으려면(특히 Google Sheets가 클수록) 반환된 DNS 레코드를 캐시할 수 있습니다. 캐시 사용 여부와 캐시 TTL은 각각 함수의 세 번째와 네 번째 인자로 제어합니다.

<Details header="지원되는 DNS 레코드 유형">

* `A`
* `AAAA`
* `CAA`
* `CNAME`
* `DS`
* `DNSKEY`
* `MX`
* `NS`
* `NSEC`
* `NSEC3`
* `RRSIG`
* `SOA`
* `TXT`


</Details>

예를 들어 다음과 같이 입력하면:

```txt
NSLookup(B1, B2)
```

지역 설정에 따라 아래 수식을 사용해야 할 수도 있습니다.

```txt
NSLookup(B1; B2)
```

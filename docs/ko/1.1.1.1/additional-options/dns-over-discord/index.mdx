1.1.1.1 봇 덕분에 Discord 서버에서도 1.1.1.1을 사용할 수 있습니다. DNS over Discord를 이용하려면 [봇을 Discord 서버에 초대](https://cfl.re/3nM6VfQ)하거나, [자신의 Discord 계정에 추가](https://dns-over-discord.v4.wtf/invite/user)해 Discord 어디서든 사용할 수 있습니다.

## DNS 조회 수행하기

봇을 서버에 추가한 뒤 `/dig`를 입력하면 DNS 조회를 시작할 수 있습니다. 이 명령은 Discord 안에 기본 UI를 제공하며 조회할 도메인, 선택적인 DNS 레코드 유형, 간단한 응답을 위한 옵션 플래그를 지정할 수 있습니다.

도메인만 입력하면 봇은 기본적으로 `A` 레코드를 조회하고, 기본 형식(짧은 형식 아님)으로 결과를 반환합니다.

예시:

```txt
/dig domain: cloudflare.com
```

### 지원 레코드 유형

Discord 슬래시 명령은 옵션을 25개까지 제공할 수 있으므로, DNS over Discord는 가장 많이 사용되는 25개 DNS 레코드 유형만 선택지로 제공합니다.

다른 DNS 레코드 유형을 조회하거나 여러 레코드 유형을 동시에 조회하려면 `/multi-dig` 명령을 사용하세요.

### 간단한 형식 응답

DNS over Discord는 `/dig` 명령에 응답을 간단한 형식으로 요청할 수 있는 옵션 플래그를 제공합니다.

간단한 형식을 선택하면 이름과 TTL 열이 제외되고, CLI `dig` 명령과 유사하게 데이터 열만 포맷 없이 반환됩니다.

예시:

```txt
/dig domain: cloudflare.com type: AAAA records short: True
```

### DNSSEC 검사 끄기

`dig` 명령에서 `cdflag`를 true로 전달하면 DNSSEC 검사를 비활성화할 수 있습니다. 이렇게 하면 DNSSEC 검증에 실패하더라도 DNS 레코드를 반환합니다.

예시:

```txt
/dig domain: cloudflare.com type: AAAA records cdflag: True
```

### 기존 결과 새로 고침

결과에 표시되는 Refresh 버튼을 누르면 DNS 조회를 다시 실행하고 메시지의 결과가 업데이트됩니다. 모든 사용자가 버튼을 누를 수 있습니다.

알 수 없는 도메인이나 레코드가 없는 경우 등 오류 응답에도 새로 고침 버튼이 제공됩니다.

### DNS 제공자 변경

기본적으로 DNS over Discord 봇은 Cloudflare의 1.1.1.1 서비스를 사용하지만, 결과 아래의 드롭다운에서 다른 DNS 제공자를 선택해 조회할 수 있습니다. 새 제공자를 선택하면 메시지의 결과가 업데이트되며, 모든 사용자가 제공자를 바꿀 수 있습니다.

## `/multi-dig` 명령

여러 DNS 레코드 유형을 한 번에 조회하려면 `/multi-dig` 명령을 사용하세요. 지원되는 DNS 레코드 유형을 공백으로 구분해 여러 개 지정할 수 있습니다.

예시:

```txt
/multi-dig domain: cloudflare.com types: A AAAA
```

### 지원 레코드 유형

`/multi-dig` 명령에서는 Discord가 옵션을 자동으로 제안하지 않으므로, 공백으로 구분한 유효한 DNS 레코드 유형 목록을 직접 입력해야 합니다. 잘못된 유형은 조용히 무시되며, 유효한 유형이 없으면 기본으로 `A` 레코드를 조회합니다.

### 간단한 형식 응답

기본 `/dig` 명령과 마찬가지로 `/multi-dig` 명령에서도 유형을 지정한 뒤 선택적으로 short 플래그를 설정해 간단한 응답을 요청할 수 있습니다.

예시:

```txt
/multi-dig domain: cloudflare.com types: CDS CDNSKEY short: True
```

### DNSSEC 검사 끄기

`dig` 명령과 동일하게, `cdflag`를 true로 전달하면 DNSSEC 검증과 관계없이 DNS 레코드를 반환합니다.

예시:

```txt
/multi-dig domain: cloudflare.com type: AAAA records cdflag: True
```

### 기존 결과 새로 고침

`/multi-dig` 명령도 조회한 DNS 결과 블록마다 Refresh 버튼을 제공합니다(10개가 넘는 레코드 유형을 요청했다면 10개 단위 블록마다 버튼 표시). `/dig`와 마찬가지로 실패한 조회 결과도 새로 고칠 수 있습니다.

### DNS 제공자 변경

`/dig` 명령과 동일하게 `/multi-dig` 명령 결과에도 DNS 제공자를 바꿀 수 있는 메뉴가 나타납니다. 이 메뉴는 모든 사용자가 사용할 수 있습니다.

## `/whois` 명령

`/whois` 명령을 사용하면 도메인, IP, ASN에 대한 RDAP/WHOIS 조회를 Discord 안에서 바로 실행할 수 있습니다.

예시:

```txt
/whois query: cloudflare.com
/whois query: 104.16.132.229
/whois query: 2606:4700::6810:84e5
/whois query: 13335
```

## 기타 명령

봇에는 봇 정보와 바로 가기를 제공하는 보조 명령도 있습니다.

### `help` 명령

`/help` 명령은 1.1.1.1 DNS over Discord 봇에서 제공하는 모든 명령에 대한 설명서를 Discord 안에서 제공합니다.

예시:

```txt
/help
```

### `privacy` 명령

`/privacy` 명령은 1.1.1.1 DNS over Discord 봇을 사용할 때의 개인정보 처리방침을 보여줍니다. [개인정보 처리방침 페이지](https://dns-over-discord.v4.wtf/privacy)에서도 확인할 수 있습니다.

예시:

```txt
/privacy
```

### `terms` 명령

`/terms` 명령은 1.1.1.1 DNS over Discord 봇의 서비스 약관을 표시합니다. [서비스 약관 페이지](https://dns-over-discord.v4.wtf/terms)에서도 확인할 수 있습니다.

예시:

```txt
/terms
```

### `github` 명령

DNS over Discord 봇은 오픈소스이며 `/github` 명령은 GitHub 저장소로 이동하는 빠른 링크를 제공합니다. 저장소는 [https://github.com/MattIPv4/DNS-over-Discord/](https://github.com/MattIPv4/DNS-over-Discord/)에서 확인할 수 있습니다.

예시:

```txt
/github
```

### `invite` 명령

`/invite` 명령은 1.1.1.1 DNS over Discord 봇을 다른 Discord 서버에 초대하거나 본인 계정에 추가할 수 있는 링크를 제공합니다.
언제든 [https://cfl.re/3nM6VfQ](https://cfl.re/3nM6VfQ)에서 봇을 초대할 수 있으며,
[https://dns-over-discord.v4.wtf/invite/user](https://dns-over-discord.v4.wtf/invite/user)에서는 계정에 추가할 수 있습니다.

```txt
/invite
```

DNS over Discord 봇은 [Cloudflare Workers](https://workers.cloudflare.com/) 위에 배포되어 있습니다.

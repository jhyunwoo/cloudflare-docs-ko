:::caution

숨김 리졸버는 아직 실험 단계 서비스이므로 프로덕션이나 기타 중요한 환경에서는 사용하지 마세요.

:::

리졸버에 자신의 IP 주소를 알리고 싶지 않다면 Tor onion 서비스를 이용하세요. Tor 네트워크를 통해 DNS 쿼리를 전달하면 리졸버가 IP 주소를 볼 수 없고, ISP도 사용자가 어떤 도메인을 조회했는지 알 수 없으므로 직접 요청할 때보다 훨씬 높은 익명성이 보장됩니다.

자세한 내용은 [블로그 게시글](https://blog.cloudflare.com/welcome-hidden-resolver/)을 참고하세요.

## Tor 클라이언트 설정

다른 DNS 모드와 가장 큰 차이점은 패킷 라우팅이 이제 더 이상 IP 주소를 사용하지 않고, 모든 연결이 Tor 클라이언트를 통해 전달되어야 한다는 점입니다.

먼저 [Tor Project 웹사이트](https://www.torproject.org/download/download.html.en)에서 Tor 클라이언트를 다운로드해 설치하세요. Tor Browser를 사용하면 `127.0.0.1:9150`에서 [SOCKS 프록시](https://en.wikipedia.org/wiki/SOCKS)가 자동으로 시작됩니다.

명령줄에서 Tor를 사용한다면 다음과 같은 구성 파일을 만들고:

```txt
SOCKSPort 9150
```

아래 명령으로 Tor를 실행합니다.

```sh
tor -f tor.conf
```

Tor Browser를 사용하는 경우 리졸버 주소로 이동하면 평소와 같은 1.1.1.1 페이지를 볼 수 있습니다.

```txt
https://dns4torpnlfs2ifuz2s2yf3fc7rdmsbhm6rw75euj35pac6ap25zgqad.onion/
```

:::note

HTTPS 인증서 표시가 "Cloudflare, Inc. (US)"인 것을 확인하세요.

:::

1.1.1.1 주소를 잊어버렸다면 cURL로 가져올 수 있습니다.

```sh
curl -sI https://tor.cloudflare-dns.com | grep -i alt-svc
```

```sh output
alt-svc: h2="dns4torpnlfs2ifuz2s2yf3fc7rdmsbhm6rw75euj35pac6ap25zgqad.onion:443"; ma=315360000; persist=1
```

## socat으로 로컬 DNS 프록시 만들기

모든 DNS 클라이언트가 Tor 클라이언트에 직접 연결할 수 있는 것은 아니므로, 숨김 리졸버에 연결하는 가장 쉬운 방법은 포트를 로컬로 전달하는 것입니다. 예를 들어 [`socat`](http://www.dest-unreach.org/socat/)을 사용할 수 있습니다.

### DNS over TCP, TLS, HTTPS

숨김 리졸버는 DNS over TCP/TLS를 위해 TCP 53번과 853번 포트를 청취합니다. Tor 프록시를 설정한 뒤 권한이 있는 사용자로 다음 `socat` 명령을 실행하세요(필요한 경우 포트 번호 변경).

```sh
PORT=853; socat TCP4-LISTEN:${PORT},reuseaddr,fork SOCKS4A:127.0.0.1:dns4torpnlfs2ifuz2s2yf3fc7rdmsbhm6rw75euj35pac6ap25zgqad.onion:${PORT},socksport=9150
```

이제 [1.1.1.1 설정 가이드](/1.1.1.1/setup/)를 따라가되, 주소로 `1.1.1.1` 대신 항상 `127.0.0.1`을 사용하면 됩니다. 다른 기기에서 이 프록시에 접근해야 한다면 `socat` 명령의 `127.0.0.1` 부분을 로컬 IP 주소로 바꾸세요.

### DNS over HTTPS

[블로그 게시글](https://blog.cloudflare.com/welcome-hidden-resolver/)에서도 설명했듯, 숨김 리졸버를 사용하는 가장 좋은 방법은 DNS over HTTPS(DoH)입니다. 설정 순서는 다음과 같습니다.

1. [DNS over HTTPS 클라이언트로 1.1.1.1에 연결하는 가이드](/1.1.1.1/encryption/dns-over-https/dns-over-https-client/)를 따라 `cloudflared`를 다운로드합니다.
2. Tor SOCKS 프록시를 시작한 뒤 `socat`으로 TCP 443 포트를 로컬호스트로 전달합니다.

```sh
socat TCP4-LISTEN:443,reuseaddr,fork SOCKS4A:127.0.0.1:dns4torpnlfs2ifuz2s2yf3fc7rdmsbhm6rw75euj35pac6ap25zgqad.onion:443,socksport=9150
```

3. `.onion` 주소를 로컬호스트로 인식하도록 시스템에 알려줍니다.

```bash
cat << EOF >> /etc/hosts
127.0.0.1 dns4torpnlfs2ifuz2s2yf3fc7rdmsbhm6rw75euj35pac6ap25zgqad.onion
EOF
```

4. 마지막으로 로컬 DNS over UDP 데몬을 시작합니다.

```sh
cloudflared proxy-dns --upstream "https://dns4torpnlfs2ifuz2s2yf3fc7rdmsbhm6rw75euj35pac6ap25zgqad.onion/dns-query"
```

```sh output
INFO[0000] Adding DNS upstream                           url="https://dns4torpnlfs2ifuz2s2yf3fc7rdmsbhm6rw75euj35pac6ap25zgqad.onion/dns-query"
INFO[0000] Starting DNS over HTTPS proxy server          addr="dns://localhost:53"
INFO[0000] Starting metrics server                       addr="127.0.0.1:35659"
```

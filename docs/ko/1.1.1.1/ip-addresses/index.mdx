아래 표에서 Cloudflare DNS 리졸버 상품별로 어떤 IPv4 또는 IPv6 주소가 사용되는지 확인하세요.

자세한 안내는 [설정](/1.1.1.1/setup/)을 참고하세요.

***

## 1.1.1.1

1.1.1.1은 Cloudflare의 공용 DNS 리졸버입니다. 인터넷을 빠르고 사적으로 탐색할 수 있는 방법을 제공합니다.

| IPv4 | IPv6 |
| ------------------------ | -------------------------------------------------- |
| `1.1.1.1` <br/>`1.0.0.1` | `2606:4700:4700::1111` <br/>`2606:4700:4700::1001` |

암호화된 방식으로 1.1.1.1을 사용하는 방법은 [암호화](/1.1.1.1/encryption/)를 참고하세요.

***

## 1.1.1.1 for Families

1.1.1.1 for Families는 인터넷 대상지를 멀웨어, 피싱 또는 기타 보안 위험과 관련된 잠재적 위협 기준으로 분류합니다.

자세한 내용은 [1.1.1.1 for Families 설정](/1.1.1.1/setup/#1111-for-families)을 참고하세요.

### 멀웨어 차단

| IPv4 | IPv6 |
| ------------------------ | -------------------------------------------------- |
| `1.1.1.2` <br/>`1.0.0.2` | `2606:4700:4700::1112` <br/>`2606:4700:4700::1002` |

### 멀웨어 및 성인 콘텐츠 차단

| IPv4 | IPv6 |
| ------------------------ | -------------------------------------------------- |
| `1.1.1.3` <br/>`1.0.0.3` | `2606:4700:4700::1113` <br/>`2606:4700:4700::1003` |

Cloudflare Firewall Rules는 HTTP 요청을 필터링하기위한 유연한 직관적 인 프레임 워크입니다. 그것은 당신이 당신의 응용 프로그램에 도달 할 수있는 고급 제어를 제공합니다, 유동적으로 들어오는 사이트 트래픽을 검사하고 자동으로 위협에 응답.

<Render file="deprecation-notice" product="firewall" />

방화벽 규칙에서[이름 \*](/ruleset-engine/rules-language/expressions/)Cloudflare는 요청에서 볼 수 있는 것, 적절한 지정[이름 \*](/firewall/cf-firewall-rules/actions/)그 조건이 충족될 때 Expressions는 '참고 자료'[IP 목록](/waf/tools/lists/custom-lists/#ip-lists)- '참고 자료'가 이름에 의해 구분되는 IP 주소 그룹

방화벽 규칙 표현을 작성하려면[언어 선택](/ruleset-engine/rules-language/), Wireshark Display Filter 언어에서 영감을 받은 강력한 표현 언어.

Cloudflare 대시보드에서 방화벽 규칙을 구성하려면, 오픈**방화벽 규칙**내 계정**보안 보안** > **‘WAF’**.

<Render file="deprecation-notice" product="firewall" />

아래 이미지에서 묘사 된대로,**방화벽 규칙**대시보드 인터페이스는 다음과 같습니다:

- 기존 규칙 목록 보기, 모두 활성화 및 비활성화.
- [생성, 편집, 삭제](/firewall/cf-dashboard/create-edit-delete-rules/)방화벽 규칙.
- 사용 가능한 규칙.
- 검색 및 기존 규칙의 목록을 필터링합니다.
- Reorder 방화벽 규칙 사용시[목록 주문](/firewall/cf-firewall-rules/order-priority/#managing-rule-evaluation-by-list-order).

![방화벽 규칙 인터페이스, 세 가지 예 방화벽 규칙 목록을 표시합니다. 이 인터페이스는 새로운 방화벽 규칙을 만들고 기존 규칙을 관리하고, 검색 및 규칙 목록을 필터링 할 수 있습니다.](~/assets/images/firewall/cf-firewall-rules-panel.png)

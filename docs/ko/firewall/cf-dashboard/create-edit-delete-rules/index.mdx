## 방화벽 규칙 만들기

1. 로그인하기[‘Cloudflare’ ‘대시보드’](https://dash.cloudflare.com/), 귀하의 계정 및 웹 사이트를 선택.

2. 오시는 길**보안 보안** > **‘WAF’** > **방화벽 규칙**.

3. 제품정보**방화벽 규칙 만들기**.

4. 내 계정**방화벽 규칙 만들기**표시된 페이지, 사용**규칙 이름**descriptive 이름을 공급하는 입력.

5. 이름 \***수신 요청 일치**, 사용**제품정보**HTTP 속성을 선택하는 드롭다운 목록 (refer to the HTTP property)[필드 참고 자료](/ruleset-engine/rules-language/fields/reference/)상세 정보). 각 요청에 대해 선택한 속성의 값**제품정보**지정한 값에 비해**제품정보**.

   대안으로, 사용[Expression 편집기](/ruleset-engine/rules-language/expressions/edit-expressions/#expression-editor)규칙 표현을 정의합니다.

   ![선택된 필드, 연산자, 값으로 방화벽 규칙 표현](~/assets/images/firewall/firewall-rules-expression-builder-value.png)

6. 사용 방법**회사연혁**비교 연산자를 선택하는 드롭다운 목록. 일치할 표현의 경우, 요청의 값**제품정보**그리고 지정된 값**제품정보**입력은 비교 연산자를 만족해야합니다.

7. 다음, 일치 값을 지정합니다. 값이 열렬한 경우, 그 다음**제품정보**컨트롤은 드롭다운 목록입니다. 그렇지 않으면 텍스트 입력이됩니다.

8. 규칙 표현에 새로운 하위 압축을 추가하려면, 선택**이름 \***&#xB610;는**또는**이름 \***제품정보**.

9. 당신의 규칙에 대한 행동을 선&#xD0DD;**- 연혁**드롭다운 목록.

10. 규칙을 저장하고 배포하려면, 선택**계정 만들기**. 규칙을 배포 할 준비가 없다면, 선택**글 탐색**.

옵션을 선택하면 규칙 목록으로 돌아갑니다. 새로운 규칙을 표시합니다.

## 자주 묻는 질문

규칙 목록에서 사용 가능한 옵션을 사용하여 방화벽 규칙을 관리합니다.

![방화벽 규칙을 관리 할 수있는 '대시보드'의 규칙 목록 인터페이스](~/assets/images/firewall/cf-firewall-rules-list.png)

### 편집 규칙

제품정보**제품정보**(wrench icon) 규칙 목록에서 규칙의 오른쪽에 위치한**방화벽 규칙**패널을 만들고 원하는 변화를 만듭니다.

### 법적 고지

방화벽 규칙과 관련된 toggle 스위치를 사용하여 활성화하거나 비활성화하십시오.

### 삭제 규칙

1. 삭제하려는 규칙에 다음, 선택**이름 \*** (**사이트맵**아이콘).
2. 확인 대화에서, 선택**이름 \***&#xC791;업 완료.

### 주문 규칙

기본적으로 Cloudflare는 방화벽 규칙을 평가합니다.**목록 주문**, 규칙이 규칙 목록에 나타나는 순서로 평가되는 곳. 목록 주문이 활성화되면 규칙 목록은 아래에 표시된 것과 같이 위치로 드래그 및 드롭 방화벽 규칙을 지정할 수 있습니다.

![사용자의 애니메이션은 규칙 목록에서 규칙을 드래그하고 삭제합니다.](/images/firewall/firewall-rules-expression-builder-10.gif)

200 개 이상의 총 규칙이 있습니다 (비활성 규칙 포함), 당신은 사용하여 평가를 관리해야합니다**회사 소개**, 즉, Cloudflare는 방화벽 규칙을 그들의 순서대로 평가합니다.**회사연혁**, 가장 낮은 시작. 이 임계값을 교차할 때 방화벽 규칙 인터페이스는 우선순위 주문으로 자동으로 전환합니다. 우선순위순위순위순위순위[주문 및 우선](/firewall/cf-firewall-rules/order-priority/).

## Rule Preview로 방화벽 규칙 테스트

Rule Preview는 엔터프라이즈 플랜에서 고객이 새로운 방화벽 규칙의 잠재적 영향을 이해할 수 있도록, 마지막 72 시간의 트래픽에서 인출 된 요청 샘플에 대해 테스트함으로써.

Rule Preview는**방화벽 규칙 만들기**·**방화벽 규칙**당신이 그것을 편집 한대로 규칙을 테스트 할 수 있도록 패널. 더 많은 정보를 원하시면, 참조[미리보기 규칙](/firewall/cf-dashboard/rule-preview/).

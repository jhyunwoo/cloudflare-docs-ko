Cloudflare는 UI 기반과 동일한 효과를 달성하는 API를 제공합니다.**방화벽 규칙**아래**보안 보안** > **‘WAF’**.

<Render file="deprecation-notice" product="firewall" />

이 API는 다음과 같습니다:

- [**방화벽 규칙 API**](/firewall/api/cf-firewall-rules/): 방화벽 규칙을 관리하고, 필터를 통해 별도로 정의된 표준을 기반으로 합니다.
- [**필터 API**](/firewall/api/cf-filters/): 규칙 일치하는 필터를 관리합니다.
- [**API 목록**](/waf/tools/lists/lists-api/): 다른 Cloudflare 상품의 규칙에 사용할 수 있는 항목(IP 주소와 같은) 목록 관리.

**Cloudflare 필터**boolean 연산자 및 기타 논리에 의존하는 복잡한 기준을 설계하기위한 방화벽 규칙의 API 전용 구성 요소는 HTTP 트래픽을 들어오고 일치를 찾습니다.

<Render file="deprecation-notice" product="firewall" />

예를 들어 필터 매칭 :

- HTTP 사용자 에이전트 및
- HTTP 경로 및
- 소스 IP 주소

해당 규칙의 범위를 정의하는 방화벽 규칙과 필터를 연관시킵니다.

필터 내에서 IP 목록을 사용하여 IP 주소 그룹에 공동으로 참조하십시오. 더 알아보기[API 목록](/waf/tools/lists/lists-api/)더 많은 정보.

'Cloudflare' 필터 API로 시작되기 전에 규칙에 익숙해[이름 \*](/ruleset-engine/rules-language/expressions/). 완전한 참고 자료를 위해, 참고하십시오[언어 선택](/ruleset-engine/rules-language/).

## 다른 'Cloudflare' API의 차이점

방화벽 규칙 API는 두 가지 방법으로 대부분의 Cloudflare API에서 다르게 동작합니다.

- API 호출은 여러 항목을 수락하고, 여러 항목에 데이터를 적용 할 수 있습니다.
- API 호출이 되더라도[표준 응답](/fundamentals/api/), 오류 객체는 다음과 같습니다.[JSON API 표준](http://jsonapi.org/format/#errors), 오류 상태에서 같은, 그것은 오류와 왜 생성 된 항목을 명확합니다.

to \`\`\`, 검토[필터는 무엇입니까?](/firewall/api/cf-filters/what-is-a-filter/), 다음으로 Cloudflare 필터[JSON 객체](/firewall/api/cf-firewall-rules/json-object/)·[이름 \*](/firewall/api/cf-firewall-rules/endpoints/).

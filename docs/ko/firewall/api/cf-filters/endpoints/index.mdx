Cloudflare 필터 API 작동을 호출하려면 Cloudflare API base URL에 endpoint를 추가하십시오.

```txt
https://api.cloudflare.com/client/v4/
```

인증 지침은, 참조[시작하기: 요청](/fundamentals/api/)'Cloudflare' API 문서에서.

endpoints 및 pagination에 대한 도움말, 참조[시작하기: Endpoints](/fundamentals/api/).

:::참조

필터 API 엔드포인트는 값이 필요합니다.`<ZONE_ID>`.

계정과 관련된 영역 목록을 검색하려면, 사용[지역 목록](/api/resources/zones/methods/list/)작업 및 메모는 필터를 관리하려는 도메인과 관련된 영역 ID.

:::

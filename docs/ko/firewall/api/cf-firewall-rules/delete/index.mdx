:::참조
더 보기`DELETE`작업은 방화벽 규칙과 관련된 필터를 삭제하지 않습니다. 필터를 삭제하려면[필터 API](/firewall/api/cf-filters/).
:::

## 여러 규칙을 삭제

이 예제는 ID와 방화벽 규칙을 삭제`{rule_id_1}`·`{rule_id_2}`.

```bash title="Request"
curl --request DELETE \
"https://api.cloudflare.com/client/v4/zones/{zone_id}/firewall/rules?id={rule_id_1}&id={rule_id_2}" \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>"
```

```json title="Response"
{
	"result": [
		{
			"id": "<RULE_ID_1>"
		},
		{
			"id": "<RULE_ID_2>"
		}
	],
	"success": true,
	"errors": [],
	"messages": []
}
```

## 단일 규칙 삭제

이 예제는 ID로 규칙을 삭제`{rule_id}`.

```bash title="Request"
curl --request DELETE \
"https://api.cloudflare.com/client/v4/zones/{zone_id}/firewall/rules/{rule_id}" \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>"
```

```json title="Response"
{
	"result": [
		{
			"id": "<RULE_ID>"
		}
	],
	"success": true,
	"errors": [],
	"messages": []
}
```

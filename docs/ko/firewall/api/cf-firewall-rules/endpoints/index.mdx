Cloudflare 방화벽 규칙 API 작동을 호출하려면 Cloudflare API 기본 URL에 엔드포인트를 추가하십시오.

```txt
https://api.cloudflare.com/client/v4/
```

인증 지침은, 참조[시작하기: 요청](/fundamentals/api/)'Cloudflare' API 문서에서.

endpoints 및 pagination에 대한 도움말, 참조[시작하기: Endpoints](/fundamentals/api/).

:::참조

방화벽 규칙 API 엔드포인트는 값이 필요합니다.`<ZONE_ID>`.

계정과 관련된 영역 목록을 검색하려면, 사용[지역 목록](/api/resources/zones/methods/list/)운영 및 관리하려는 방화벽 규칙과 관련된 영역 ID.

:::

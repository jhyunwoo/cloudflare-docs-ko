Cloudflare Firewall Rules는 수신 트래픽과 블록, 도전, 로그를 검사하는 규칙을 만들거나 특정 요청을 허용하는 것을 허용합니다.

<Render file="deprecation-notice" product="firewall" />

## 주요 특징

- **규칙 기반 보호**: 'Cloudflare'에 의해 제공된 사전 정의된 규칙을 사용하거나 자체 방화벽 규칙을 정의하십시오. 'Cloudflare' 대시보드 또는 API를 통해 규칙을 만듭니다.
- **Complex 사용자 정의 규칙**: 각 규칙의 표현은 가능한 모든 HTTP 요청 매개 변수 및 필드의 다중 필드를 사용하여 복잡한 규칙을 만들 수 있습니다.

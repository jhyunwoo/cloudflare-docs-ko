| Error Code | HTTP Status Code | Description          |
| ---------- | ---------------- | -------------------- |
| `2000`     | 500              | 내부 오류             |
| `2001`     | 400              | 입력 검증 오류        |
| `2002`     | 422              | Query가 최대 비용을 초과함 |
| `1015`     | 429              | 요청이 너무 많음      |
| `7003`     | 404              | 찾을 수 없음          |

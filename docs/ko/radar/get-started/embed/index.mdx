Radar에서는 차트 이미지를 다운로드할 수 있을 뿐 아니라, 대부분의 차트를 대화형 카드로 자신의 웹 페이지에 임베드할 수도 있습니다.

이 기능을 지원하는 차트에는 설명 옆에 share 아이콘이 표시됩니다.

## PNG 형식으로 차트 다운로드

1. 공유하려는 차트 설명 옆의 Share 아이콘을 선택합니다.
2. `Download Image.`를 선택합니다.
3. 요청한 차트가 포함된 .png 파일이 다운로드됩니다.

## 웹사이트에 대화형 차트 임베드

1. 공유하려는 차트 설명 옆의 Share 아이콘을 선택합니다.
2. Fixed Time과 Real Time 중 하나를 선택합니다.
   * Real Time은 선택한 날짜 범위를 기준으로 하는 "sliding window"를 사용하며, 현재 날짜/시간을 기준으로 그 기간만큼 거슬러 올라간 데이터 포인트를 표시합니다.
   * Fixed Time은 현재 보이는 데이터 포인트만 포함하는 차트를 항상 표시합니다.
3. Copy Code를 선택한 뒤 코드를 웹 페이지에 붙여 넣습니다.

**참고**: 날짜 범위, 위치, autonomous system (ASN), 표시 중인 series 등 현재 선택한 항목은 공유된 차트에 그대로 반영됩니다.

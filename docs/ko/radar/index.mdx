전 세계 인터넷 트래픽에 대한 Cloudflare 데이터를 확인하세요.
</Description>

<Plan type="all"/>

[Cloudflare Radar](https://radar.cloudflare.com)는 전 세계 인터넷 트래픽, 공격, 기술 동향과 인사이트를 보여주는 허브입니다. 이 서비스는 [Cloudflare의 글로벌 네트워크](https://www.cloudflare.com/network/) 데이터와, Cloudflare의 [1.1.1.1 public DNS resolver](/1.1.1.1/)에서 집계하고 [익명화한 데이터](/1.1.1.1/privacy/public-dns-resolver/)를 기반으로 합니다.

[Radar API](/api/resources/radar/)를 사용하면 전 세계 인터넷 트래픽에 대한 Cloudflare 데이터에 접근할 수 있습니다.
Radar API는 무료이며, 연구자, 기술 전문가, 그리고 웹을 좋아하는 누구나 전 세계 인터넷 사용 현황을 조사할 수 있도록 해줍니다.

Radar API endpoint를 통해 제공되는 데이터는 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) 라이선스로 공개됩니다.

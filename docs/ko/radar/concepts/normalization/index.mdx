Cloudflare Radar는 일반적으로 원시 값을 그대로 반환하지 않습니다. 대신 값은 백분율로 반환되거나 min-max 방식으로 정규화됩니다.

원시 값에 후처리 방법이 적용되었는지, 그리고 어떤 방식이 적용되었는지는 응답의 `result.meta.normalization` 속성을 확인하세요.

## 방법

| Method                  | Description                                                                                                                                                |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PERCENTAGE`            | 값이 백분율을 나타냅니다.                                                                                                                                   |
| `PERCENTAGE_CHANGE`     | 값이 기준 기간 대비 [percentage change](https://en.wikipedia.org/wiki/Relative_change_and_difference#Percentage_change)를 나타냅니다.                    |
| `OVERLAPPED_PERCENTAGE` | 겹침으로 인해 100%를 초과하는 백분율 값을 나타냅니다.                                                                                                      |
| `MIN_MAX`               | 값이 [min-max](https://en.wikipedia.org/wiki/Feature_scaling#Rescaling_\(min-max_normalization\)) 방식으로 정규화되었습니다.                              |
| `MIN0_MAX`              | 값이 min-max 방식으로 정규화되지만 최소값을 `0`으로 설정합니다. 응답 전체의 최대값 대비 비율을 0과 1 사이로 스케일한 것과 같습니다.                     |
| `RAW_VALUES`            | 값이 원시 값이며 변경되지 않았습니다.                                                                                                                      |

위치/시간 범위 등 여러 조건에 걸쳐 값을 비교하려면, min-max 방식으로 값을 정규화하는 endpoint에서는 같은 요청 안에서 비교해야 합니다. 이는 여러 series를 함께 요청하면 됩니다. 그러면 모든 값이 동일한 최소값과 최대값을 사용해 정규화되므로 안전하게 서로 비교할 수 있습니다. 자세한 내용은 [Make comparisons](/radar/get-started/making-comparisons/)를 참고하세요.

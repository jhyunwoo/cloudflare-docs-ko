집계 간격을 사용하면 지정한 간격(또는 빈도)으로 데이터를 반환할 수 있습니다. 간격을 따로 정의하지 않으면 기본 집계 간격(또는 빈도)으로 데이터가 반환됩니다. 일반적으로 날짜 범위가 길수록 집계 간격도 더 커집니다.

예를 들어 하루치 데이터를 요청하면 기본 집계 간격은 15분입니다. 한 달이 넘는 데이터를 요청하면 기본값은 하루입니다.

## 방법

| Aggregation Interval | Description      |
| -------------------- | ---------------- |
| `15m`                | 15분 단위 빈도.  |
| `1h`                 | 1시간 단위 빈도. |
| `1d`                 | 1일 단위 빈도.   |
| `1w`                 | 1주 단위 빈도.   |

Radar에서 bot class는 [bot scores](/bots/concepts/bot-score/)를 그룹화한 분류입니다.

점수 1에서 29 사이는 봇 트래픽으로 분류됩니다. 30 이상 점수는 비봇/인간 트래픽으로 분류됩니다.

| Class                | Description                |
| -------------------- | -------------------------- |
| **Likely automated** | bot score 1부터 29까지.   |
| **Likely human**     | bot score 30부터 99까지.  |

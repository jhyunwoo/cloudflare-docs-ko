응답의 `result.meta.confidenceInfo.level`은 Cloudflare가 해당 데이터를 얼마나 신뢰하는지를 나타냅니다. 신뢰 수준은 데이터 품질에 영향을 주는 내부 문제나, 특정 위치(예: 남극) 또는 자율 시스템(AS)에 대한 데이터가 충분하지 않은 경우에 영향을 받을 수 있습니다.

| Level | Description                                                                                                                                                           |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1** | 이 시간 범위 및/또는 이 위치 또는 Autonomous System에 대한 데이터가 충분하지 않습니다. 앞서 언급한 이유 때문에 데이터 패턴도 불규칙하게 나타납니다.                  |
| **2** | 이 시간 범위 및/또는 이 위치 또는 Autonomous System에 대한 데이터가 충분하지 않습니다.                                                                                |
| **3** | 데이터가 불규칙한 패턴을 보이지만, 알려진 데이터 문제(예: 파이프라인 문제)의 영향은 받지 않습니다.                                                                   |
| **4** | 할당되지 않음.                                                                                                                                                        |
| **5** | 알려진 데이터 품질 문제가 없습니다.                                                                                                                                   |

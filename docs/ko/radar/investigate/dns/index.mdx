Cloudflare의 [1.1.1.1](/1.1.1.1/) 공개 resolver 서비스로 들어오는 집계되고 익명화된 DNS 쿼리에 접근할 수 있습니다.

## 엔드포인트 목록

### 상위 위치

#### 예시: `google.com`과 `yandex.ru`의 지리적 분포

다음 예시에서는 `google.com` DNS 쿼리의 주요 출발 위치를 요청합니다.

```bash
curl "https://api.cloudflare.com/client/v4/radar/dns/top/locations?domain=google.com&dateRange=1d&format=json&limit=2" \
--header "Authorization: Bearer <API_TOKEN>"
```

응답은 대부분의 쿼리가 미국과 브라질에서 온다는 것을 보여줍니다.

```json
{
  "success": true,
  "errors": [],
  "result": {
		"top_0": [
			{
				"clientCountryAlpha2": "US",
				"clientCountryName": "United States",
				"value": "43.474518"
			},
			{
				"clientCountryAlpha2": "BR",
				"clientCountryName": "Brazil",
				"value": "10.772799"
			}
		],
		"meta": {
      // ...
    }
  }
}
```

러시아 검색 엔진인 `yandex.ru`에 대해 같은 검색 요청을 수행하면:

```bash
curl "https://api.cloudflare.com/client/v4/radar/dns/top/locations?domain=yandex.ru&dateRange=1d&format=json&limit=2" \
--header "Authorization: Bearer <API_TOKEN>"
```

다음 응답이 반환됩니다.

```json
{
  "success": true,
  "errors": [],
  "result": {
		"top_0": [
			{
				"clientCountryAlpha2": "RU",
				"clientCountryName": "Russian Federation",
				"value": "73.710495"
			},
			{
				"clientCountryAlpha2": "DE",
				"clientCountryName": "Germany",
				"value": "5.518052"
			}
		],
		"meta": {
      // ...
    }
  }
}
```

예상대로 대부분의 쿼리는 러시아에서 옵니다.

:::note

이 예시들은 특정 hostname으로 향하는 전체 DNS 쿼리 중에서, 한 위치에서 해당 hostname으로 향한 DNS 쿼리 총수를 반환한다는 점에 유의하세요. 따라서 실제 비율이 낮더라도, 미국처럼 인구가 많은 지역이 상위권에 자주 나타나는 것은 자연스러운 결과입니다.
:::

여러 hostname을 함께 제공할 수도 있습니다. 자세한 내용은 [DNS top locations 가져오기](/api/resources/radar/subresources/dns/subresources/top/methods/locations/)를 참고하세요. 이는 탐색하려는 애플리케이션이 콘텐츠를 제공하기 위해 여러 hostname을 사용할 때 유용합니다. 예를 들어 메인 웹사이트용 hostname과 API 전용 hostname을 별도로 두는 경우가 이에 해당합니다.

R2 SQL은 오픈 베타이며 개발자와 함께 사용할 수 있습니다.[R2 구독](/r2/pricing/).

현재 오픈 베타에서 R2 SQL에 대한 청구는 없습니다. 그러나, 당신은 표준 청구됩니다[R2 스토리지 및 운영](/r2/pricing/)queries에 의해 접근되는 자료.

R2 SQL에 의해 queried 자료의 양에 근거를 둔 계산에 계획합니다. R2 SQL 사용법을 위해 어떤 변화나 시작 위탁하기 전에 적어도 30 일 고시를 제공할 것입니다.

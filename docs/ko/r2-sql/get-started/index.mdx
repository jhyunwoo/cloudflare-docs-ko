이 가이드는 당신을 통해 지시합니다:

- 당신의 첫 번째[R2 물통](/r2/buckets/)그리고 그것을 가능하게[데이터 카탈로그](/r2/data-catalog/).
- 구매하기[API 토큰](/r2/api/tokens/)귀하의 데이터 카탈로그를 인증하는 파이프라인에 필요한.
- 간단한 전자 상거래 스키마와 함께 첫 번째 파이프라인 만들기[아파치 Iceberg](https://iceberg.apache.org/)R2 데이터 카탈로그에 의해 관리되는 테이블.
- HTTP 엔드포인트를 통해 샘플 전자 상거래 데이터를 전송.
- 당신의 물통에 있는 유효한 자료는 R2 SQL로 그것을 쿼리합니다.

## 1. R2 물통 만들기

<Tabs syncKey="CLIvDash">
  <TabItem label="Wrangler 클립">
    <Steps>
      1. 이미 로그인하지 않은 경우, 실행:

         ```
         npx wrangler login
         ```

         ```
         npx wrangler r2 bucket create pipelines-tutorial
         ```

    </Steps>

  <TabItem label="대시보드">

      4. 제품정보**버킷 만들기**.
    </Steps>
  </TabItem>
</Tabs>

## 2. 유효한 R2 데이터 카탈로그

<Tabs syncKey="CLIvDash">

    R2 물통에 카탈로그를 가능하게 하십시오:

    ```
    npx wrangler r2 bucket catalog enable pipelines-tutorial
    ```

    이 명령을 실행할 때 "Warehouse"와 "Catalog URI"의 메모를 수행하십시오. 당신은 나중에 필요합니다.
  </TabItem>

  <TabItem label="대시보드">
    <Steps>
      1. Cloudflare dashboard에서, 가십시오**R2 객체 저장**사이트 맵
         <DashButton url="/?to=/:account/r2/overview" />

      2. 물통을 선택하십시오: 파이프라인 tutorial.

      3. 전환하기**계정 설정**탭, 아래로 스크롤**R2 데이터 카탈로그**, 그리고 선택**이름 \***.

      4. 일단 활성화되면, 참고**카탈로그 URI**·**창고 이름**.

파이프 라인은 R2 데이터 카탈로그에 인증해야합니다.[R2 API 토큰](/r2/api/tokens/)카탈로그 및 R2 권한이 있습니다.

<Steps>
  1. Cloudflare dashboard에서, 가십시오**R2 객체 저장**사이트 맵
     <DashButton url="/?to=/:account/r2/overview" />

  2. 제품정보**API 토큰 관리**.

  3. 제품정보**계정 API 토큰 만들기**.

  4. API 토큰을 이름을 부여합니다.

  5. 이름 \***제출**, 선택**관리자 읽기 및 쓰기**이름 \*

  6. 제품정보**계정 만들기 API 토큰 토큰**.

  7. 이름 \***토큰 값**.
</Steps>

## 4. 파이프라인 만들기

<Tabs syncKey="CLIvDash">
  <TabItem label="Wrangler 클립">
    첫째, 전자 상거래 데이터 구조를 정의하는 스키마 파일을 만듭니다.

    **이름 \*`schema.json`:**

    ```json
    {
    	"fields": [
    		{
    			"name": "user_id",
    			"type": "string",
    			"required": true
    		},
    		{
    			"name": "event_type",
    			"type": "string",
    			"required": true
    		},
    		{
    			"name": "product_id",
    			"type": "string",
    			"required": false
    		},
    		{
    			"name": "amount",
    			"type": "float64",
    			"required": false
    		}
    	]
    }
    ```

    R2 Data Catalog로 작성한 파이프라인을 만들기 위한 대화형 설정 사용:

    ```bash
    npx wrangler pipelines setup
    ```

    프롬프트를 따르십시오:

    1. **Pipeline 이름**: 입력`ecommerce`

    2. **스트림 구성**:
       - HTTP 엔드포인트 활성화:`yes`
       - 인증:`no`(간단한)
       - 사용자 정의 CORS 기원을 구성:`no`
       - Schema 정의:`Load from file`
       - Schema 파일 경로:`schema.json`(또는 파일 경로)

    3. **싱크 구성**:
       - 목적지 유형:`Data Catalog Table`
       - R2 물통 이름:`pipelines-tutorial`
       - 이름 공간:`default`
       - 테이블 이름:`ecommerce`
       - 카탈로그 API 토큰: 단계 3에서 토큰을 입력하십시오.
       - 압축:`zstd`
       - 크기 도달 (MB) 때 목록 파일:`100`
       - 시간 도달 (둘째로) 때 목록 파일:`10`(이 튜토리얼에서 빠른 데이터 가시)

    4. **SQL 변환**: 선택`Use simple ingestion query`사용 :
       ```sql
       INSERT INTO ecommerce_sink SELECT * FROM ecommerce_stream
       ```

    설정 완료 후, 최종 출력에 표시된 HTTP 엔드포인트 URL을 참고하십시오.
  </TabItem>

  <TabItem label="대시보드">
    <Steps>
      1. Cloudflare dashboard에서, 갑니다**파이프 라인** > **파이프 라인**.
         <DashButton url="/?to=/:account/pipelines/overview" />

      2. 제품정보**Pipeline 만들기**.

      3. **스트림에 연결**:
         - 파이프 이름:`ecommerce`
         - 데이터 전송을위한 HTTP 엔드포인트 활성화 : Enabled
         - HTTP 인증: Disabled (과태)
         - 제품정보**이름 \***

      4. **입력 Schema를 정의**:
         - 제품정보**JSON 편집기**
         - 스키마에 복사 :
           ```json
           {
           	"fields": [
           		{
           			"name": "user_id",
           			"type": "string",
           			"required": true
           		},
           		{
           			"name": "event_type",
           			"type": "string",
           			"required": true
           		},
           		{
           			"name": "product_id",
           			"type": "string",
           			"required": false
           		},
           		{
           			"name": "amount",
           			"type": "f64",
           			"required": false
           		}
           	]
           }
           ```
         - 제품정보**이름 \***

      5. **싱크의 정의**:
         - R2 물통을 선택하십시오:`pipelines-tutorial`
         - 저장 유형:**R2 데이터 카탈로그**
         - 이름 공간:`default`
         - 테이블 이름:`ecommerce`
         - **고급 설정**: 변경**최대 시간 간격**으로`10 seconds`

      6. **회사 소개**:
         - 사용 방법**자동으로 싱크에 대한 계정 API 토큰을 만듭니다.**
         - 이름 \***카탈로그 토큰**단계 3
         - 제품정보**이름 \***

      7. **파이프 정의**:
         - 기본 SQL 쿼리를 남겨:
           ```sql
           INSERT INTO ecommerce_sink SELECT * FROM ecommerce_stream;
           ```
         - 제품정보**Pipeline 만들기**

      8. 파이프라인 생성 후에, 주**스트림 ID**다음 단계.

## 5. 표본 자료를 보내십시오

파이프라인의 HTTP 엔드포인트에 전자 상거래 이벤트를 전송:

```bash
curl -X POST https://{stream-id}.ingest.cloudflare.com \
  -H "Content-Type: application/json" \
  -d '[
    {
      "user_id": "user_12345",
      "event_type": "purchase",
      "product_id": "widget-001",
      "amount": 29.99
    },
    {
      "user_id": "user_67890",
      "event_type": "view_product",
      "product_id": "widget-002"
    },
    {
      "user_id": "user_12345",
      "event_type": "add_to_cart",
      "product_id": "widget-003",
      "amount": 15.50
    }
  ]'
```

기타 제품`{stream-id}`파이프라인 설정에서 실제 스트림 엔드 포인트.

## 6. 당신의 물통에 있는 유효한 자료

<Steps>
  1. Cloudflare dashboard에서, 가십시오**R2 객체 저장**사이트 맵

  2. 당신의 물통을 선정하십시오:`pipelines-tutorial`.

  3. 당신은 당신의 파이프라인에 의해 생성 된 Iceberg 메타 데이터 파일 및 데이터 파일을 볼 수 있습니다. 참고 : 버킷에 어떤 파일을 본 적이 없다면 몇 분 동안 기다리고 다시 시도하십시오.

  4. 데이터는 메타데이터 추적 테이블 버전과 Apache Iceberg 형식으로 구성됩니다.
</Steps>

## 7. R2 SQL을 사용하여 데이터를 쿼리

R2 SQL을 사용하여 환경을 설정:

```bash
export WRANGLER_R2_SQL_AUTH_TOKEN=YOUR_API_TOKEN
```

또는 생성`.env`파일 :

```
WRANGLER_R2_SQL_AUTH_TOKEN=YOUR_API_TOKEN
```

이름 \*`YOUR_API_TOKEN`단계 3에서 만든 토큰입니다. 환경 변수 설정에 대한 자세한 내용은 참조[Wrangler 시스템 환경 변수](/workers/wrangler/system-environment-variables/).

데이터를 쿼리:

```bash
npx wrangler r2 sql query "YOUR_WAREHOUSE_NAME" "
SELECT
    user_id,
    event_type,
    product_id,
    amount
FROM default.ecommerce
WHERE event_type = 'purchase'
LIMIT 10"
```

기타 제품`YOUR_WAREHOUSE_NAME`단계 2.에서 창고 이름으로

Apache Iceberg를 지원하는 모든 엔진과 이 테이블을 쿼리할 수 있습니다. R2 Data Catalog에 다른 엔진을 연결하는 것에 대해 자세히 알아 보려면, 참조[Iceberg 엔진에 연결](/r2/data-catalog/config-examples/).

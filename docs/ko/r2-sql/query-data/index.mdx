글쓰기[아파치 Iceberg](https://iceberg.apache.org/)테이블 관리[R2 데이터 카탈로그](/r2/data-catalog/). R2 SQL 쿼리를 통해 만들 수 있습니다[Wrangler](/workers/wrangler/)또는 HTTP API.

## 창고 이름 받기

R2 SQL을 가진 자료를 조회하기 위하여, 당신은 당신의 창고 이름이 당신의 곁에 관련 있을 것입니다[회사 소개](/r2/data-catalog/manage-catalogs/). 그것을 검색하려면, 당신은 실행할 수 있습니다[`r2 bucket catalog get`이름 \*](/workers/wrangler/commands/#r2-bucket-catalog-get):

```bash
npx wrangler r2 bucket catalog get <BUCKET_NAME>
```

또는 dashboard에서 찾을 수 있습니다.**R2 객체 저장**페이지, 버킷 선택, 전환**계정 설정**탭, 스크롤**R2 데이터 카탈로그**, 그리고 발견**창고 이름**.

## Wrangler

시작하기[`npm`](https://docs.npmjs.com/getting-started)·[Wrangler, 개발자 플랫폼 CLI 설치](/workers/wrangler/install-and-update/).

Wrangler는 QXQX0074XQ 데이터 카탈로그, R2 저장, QXQX0074XQX0074XQ SQL에 액세스 권한을 가진 API 토큰을 필요로 합니다. 더 보기`r2 sql query`명령은 토큰을 찾습니다.`WRANGLER_R2_SQL_AUTH_TOKEN`환경 변수.

당신의 환경을 설치하십시오:

```bash
export WRANGLER_R2_SQL_AUTH_TOKEN=YOUR_API_TOKEN
```

또는 생성`.env`파일 :

```
WRANGLER_R2_SQL_AUTH_TOKEN=YOUR_API_TOKEN
```

이름 \*`YOUR_API_TOKEN`만든 토큰입니다.[자주 묻는 질문](#authentication). 환경 변수 설정에 대한 자세한 내용은 참조[Wrangler 시스템 환경 변수](/workers/wrangler/system-environment-variables/).

SQL 쿼리를 실행하려면, 실행[`r2 sql query`이름 \*](/workers/wrangler/commands/#r2-sql-query):

```bash
npx wrangler r2 sql query <WAREHOUSE> "SELECT * FROM namespace.table_name limit 10;"
```

지원 된 sql 명령의 전체 목록의 경우, 참조[R2 SQL reference 페이지](/r2-sql/sql-reference).

## API를 통해 쿼리

아래는 REST 엔드포인트를 통해 R2 SQL을 사용하는 예입니다.

```bash
curl -X POST \
  "https://api.sql.cloudflarestorage.com/api/v1/accounts/{ACCOUNT_ID}/r2-sql/query/{BUCKET_NAME}" \
  -H "Authorization: Bearer ${WRANGLER_R2_SQL_AUTH_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "SELECT * FROM namespace.table_name limit 10;"
  }'
```

API는 권한 헤더에 적합한 권한을 가진 API 토큰을 요구합니다. 더 알아보기[인증현황](#authentication)토큰 만들기에 대한 자세한 내용은.

지원 된 sql 명령의 전체 목록의 경우, 참조[R2 SQL reference 페이지](/r2-sql/sql-reference).

## 인증현황

R2 SQL을 사용하여 데이터를 쿼리하려면 Cloudflare API 토큰을 R2 SQL, R2 데이터 카탈로그 및 QXQX0082XQQQ 저장 권한으로 제공해야합니다. R2 SQL은 카탈로그 메타데이터에 접근하고 R2에 저장되는 underlying 자료 파일을 읽는 이러한 권한을 요구합니다.

### dashboard에서 API 토큰 생성

이름 \*[R2 API 토큰](/r2/api/tokens/#permissions)다음과 같은 권한을 가진:

- R2 데이터 카탈로그에 액세스 (읽기 전용)
- R2 저장에 접근 (Admin 읽기/쓰기)
- R2 SQL (읽기 전용)에 접근

이 토큰 값을 사용하여`WRANGLER_R2_SQL_AUTH_TOKEN`Wrangler 또는 REST API를 사용할 때 인증 헤더에 쿼리 할 때 환경 변수.

### API를 통해 API 토큰 만들기

QXQX0089XQ SQL을 사용하여 API 토큰을 프로그래밍적으로 만들려면 QXR2 SQL, R2XQ 데이터 카탈로그 및 R2Q 저장 권한 그룹을 지정해야합니다.[오시는 길](/r2/api/tokens/#access-policy).

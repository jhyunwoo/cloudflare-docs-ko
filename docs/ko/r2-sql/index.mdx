주요 특징

<Description>
  SQL을 사용하여 R2 데이터 카탈로그에 의해 관리되는 Query Apache Iceberg 테이블.
</Description>

R2 SQL은 Cloudflare's serverless, 배포, 쿼리에 대한 분석 쿼리 엔진입니다[아파치 Iceberg](https://iceberg.apache.org/)테이블에 저장[R2 데이터 카탈로그](/r2/data-catalog/). R2 SQL는 파일 pruning, Cloudflare의 분배된 compute 및 R2 객체 저장을 사용하여 데이터의 대량을 효율적으로 쿼리하도록 설계되었습니다.

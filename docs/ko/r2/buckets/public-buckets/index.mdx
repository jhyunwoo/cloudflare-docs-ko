공개 버킷은 사용자가 인터넷에 직접 R2 버킷의 내용을 노출 할 수있는 기능입니다. 기본적으로 버킷은 결코 공개적으로 접근 할 수 없으며 항상 사용자 권한을 허용해야합니다.

공중 물통은 2가지 방법 중 하나에서 설치될 수 있습니다:

- 당신의 통제의 밑에 관례 도메인으로 당신의 물통을 노출하십시오.
- Cloudflare 관리`https://r2.dev`Non-production 사용 사례에 대한 하위 도메인.

이 옵션은 독립적으로 사용할 수 있습니다. 사용자 정의 도메인을 활성화 할 필요가 없습니다`r2.dev`이름 \*

WAF 사용자 정의 규칙, 캐싱, 액세스 제어, 또는 봇 관리와 같은 기능을 사용하려면 사용자 정의 도메인 뒤에 물통을 구성해야합니다. 이 기능은 사용할 수 없습니다.`r2.dev`개발 URL.

:::참조

현재 공개 버킷은 (sub) 도메인의 루트에서 물통 내용을 나열 할 수 없습니다.

:::

## 주문 영역

### 뚱 베어

사용자 정의 도메인을 통해 도메인 액세스는 사용할 수 있습니다[Cloudflare 캐시](/cache/)R2 물통에 접근을 가속하십시오.

사용시 캐시 구성[Smart Tiered 캐시](/cache/how-to/tiered-cache/#smart-tiered-cache)R2 버킷 옆에있는 단일 상층 데이터 센터가 있습니다.

:::참조

기본적으로 특정 파일 유형만 캐시됩니다. 물통에 모든 파일을 캐시하려면 Cache 모든 페이지 규칙을 설정해야합니다.

기본 캐시 행동에 대한 자세한 내용은, 그것을 사용자 정의하는 방법, 참조[기본 캐시 Behavior](/cache/concepts/default-cache-behavior/#default-cached-file-extensions)

:::

### 오시는 길

사용자 정의 도메인의 버킷에 대한 액세스를 제한하려면 Cloudflare의 기존 보안 제품을 사용하십시오.

- [CloudflareZero Trust 오시는 길](/cloudflare-one/access-controls/): 당신의 teammates에 의해서만 접근해야 하는 물통을 보호합니다. 더 알아보기[R2를 보호합니다 Cloudflare를 가진 물통 오시는 길](/r2/tutorials/cloudflare-access/)더 많은 정보를 위한 튜토리얼.
- [Cloudflare WAF 토큰 인증](/waf/custom-rules/use-cases/configure-token-authentication/): 접근 토큰을 제공함으로써 문서, 파일 및 미디어에 대한 액세스를 제한합니다.

:::카트로션

당신의 대중적인 접근[`r2.dev`이름 \*](#disable-public-development-url)WAF 또는 Cloudflare 액세스와 같은 제품을 사용할 때. 공개 액세스가 비활성화되지 않는 경우, 물통은 공개적으로 사용할 수 있습니다.`r2.dev`하위 도메인.

:::

### 최소 TLS 버전 및 Cipher Suites

R2 버킷의 사용자 정의 호스트 이름의 최소 TLS 버전 또는 cipher 스위트를 사용자 정의하려면 API 호출을 수정할 수 있습니다.[R2 사용자 정의 도메인 설정](/api/resources/r2/subresources/buckets/subresources/domains/subresources/custom/methods/update/). 당신은 선택을 추가해야 할 것입니다`minTLS`·`ciphers`요청 몸에 매개 변수. cipher suites의 목록을 지정할 수 있습니다.[지원되는 cipher 스위트](/ssl/edge-certificates/additional-options/cipher-suites/supported-cipher-suites/).

## 도메인을 Cloudflare에 추가

사용중인 도메인은 추가되었습니다.[이름 \*](/fundamentals/concepts/accounts-and-zones/#zones)R2 물통과 같은 계정에서.

- 도메인이 이미 Cloudflare에 의해 관리되는 경우, 당신은 진행할 수 있습니다[사용자 정의 도메인에 물통을 연결](/r2/buckets/public-buckets/#connect-a-bucket-to-a-custom-domain).
- 도메인이 Cloudflare에 의해 관리되지 않은 경우, 당신은 그것을 사용하여 설정해야합니다[부분 (CNAME) 설정](/dns/zone-setups/partial-setup/)계정에 추가합니다.

도메인이 Cloudflare 계정 (설정 유형의 무시)에 존재하면 물통에 연결할 수 있습니다.

## 도메인 접근

도메인을 비활성화하면 해당 도메인을 통해 귀하의 버킷에 공공 액세스 할 수 있습니다. 다른 도메인 또는 관리`r2.dev`subdomain은 비범죄입니다.
지정된 도메인은 R2에 연결되어 버킷을 제거하거나 삭제할 수 있습니다.

도메인 비활성화:

1. 내 계정**R2**, 수정하려는 물통을 선택합니다.
2. 버킷 페이지에서 선택**계정 설정**, 이동**사용자 정의 도메인**.
3. 비활성화하려는 도메인에 다음, 선&#xD0DD;**...**·**법적 고지**.
4. 배지 아래**버킷에 접근**업데이트**이용안내**.

## 도메인 제거

사용자 정의 도메인 제거는 물통에서 차단하고 dashboard에서 설정을 삭제합니다. 귀하의 버킷은 다른 활성화 된 액세스 방법을 통해 공개적으로 접근 할 수 있지만 도메인은 연결 된 도메인 목록에 더 이상 나타나지 않습니다.

도메인을 제거하려면:

1. 내 계정**R2**, 수정하려는 물통을 선택합니다.
2. 버킷 페이지에서 선택**계정 설정**, 이동**사용자 정의 도메인**.
3. 비활성화하려는 도메인에 다음, 선&#xD0DD;**...**·**도메인 제거**.
4. 제품정보**도메인 제거**확인 창에서. 이 단계는 또한 CNAME 레코드를 도메인으로 제거합니다. 항상 도메인을 다시 추가 할 수 있습니다.

## 공공 개발 URL

R2 버킷의 내용을 Cloudflare-managed r2.dev subdomain을 통해 인터넷에 노출합니다. 이 엔드포인트는 비생산 트래픽을 위한 것입니다.

:::참조

본문 바로가기`r2.dev`subdomains는 제한된 비율이며 개발 목적으로만 사용됩니다.

액세스 관리, 캐시 및 봇 관리 기능을 활성화하려면 물통에 공공 액세스 할 때 사용자 정의 도메인을 설정해야합니다.

CNAME 레코드를 생성하지 마십시오`r2.dev`하위 도메인. 이것은**unsupported 접근 경로**, 그리고 우리는 일관된 신뢰성 또는 성과를 보장할 수 없습니다. 생산 사용을 위해,[도메인을 Cloudflare에 추가](#add-your-domain-to-cloudflare)대신.
주요 특징

### Enable 공공 개발 URL

버킷에 대한 공개 개발 URL 액세스를 활성화하면 Cloudflare-managed를 통해 인터넷에서 콘텐츠를 사용할 수 있습니다.`r2.dev`하위 도메인.

접속 가능`r2.dev`당신의 물통을 위해:

1. 내 계정**R2**, 수정하려는 물통을 선택합니다.
2. 버킷 페이지에서 선택**계정 설정**.
3. 이름 \***공공 개발 URL**, 선택**이름 \***.
4. 내 계정**공공 액세스 허용?**, 입력하여 당신의 선택을 확인합니다`allow`확인 및 선택**지원하다**.
5. 이제 공개 버킷 URL을 사용하여 버킷과 그 객체에 액세스 할 수 있습니다.

당신의 물통이 공개적으로 접근할 수 있다는 것을 확인하기 위하여, 검사하십시오**공공 URL 액세스**제품 설명**지원하다**당신은 물통 조정에서.

### 공공 개발 URL 사용

공개 개발 URL 액세스를 비활성화하면 물통의 노출을 통해 제거합니다.`r2.dev`하위 도메인. 버킷과 그 객체는 공개 버킷 URL을 통해 더 이상 접근 할 수 없습니다.

다른 도메인을 연결하면 물통은 해당 도메인에 접근할 수 있습니다.

당신의 물통을 위한 공중 접근을 해제하기 위하여:

1. 내 계정**R2**, 수정하려는 물통을 선택합니다.
2. 버킷 페이지에서 선택**계정 설정**.
3. 이름 \***공공 개발 URL**, 선택**사용 방법**.
4. 내 계정**공공 액세스는?**, 유형`disallow`확인 및 선택**뚱 베어**.

Cloudflare dashboardXQ 또는 Wrangler를 사용하여 물통을 만들 수 있습니다.

:::참조

Wrangler는 입니다[명령줄 도구](/workers/wrangler/install-and-update/)Cloudflare의 개발자 제품인 R2XQ를 포함한 건물.

R2 지원은 Wrangler에서 물통을 관리하고 물통에 있는 목표에 대하여 기본적인 가동을 실행할 수 있습니다. 더 고급 사용 케이스, 대량 업로드 또는 기존 객체 저장 제공 업체에서 파일을 미러링, 우리는 추천[뚱 베어](/r2/examples/rclone/)또는[S3 호환](/r2/api/s3/)당신의 선택의 공구.

:::

## 물통 수준 가동

버킷 만들기[`r2 bucket create`](/workers/wrangler/commands/#r2-bucket-create)명령:

```sh
wrangler r2 bucket create your-bucket-name
```

:::참조

- 버킷 이름은 더 낮은 케이스 문자 (a-z), 숫자 (0-9) 및 하이픈 (-)를 포함 할 수 있습니다.
- 물통 이름은 hyphen로 시작하거나 끝낼 수 없습니다.
- 물통 이름은 길이에 있는 3-63의 특성 사이에서만 일 수 있습니다.

placeholder 텍스트는 예입니다.

:::

현재 계정의 버킷 목록[`r2 bucket list`](/workers/wrangler/commands/#r2-bucket-list)명령:

```sh
wrangler r2 bucket list
```

버킷 삭제[`r2 bucket delete`](/workers/wrangler/commands/#r2-bucket-delete)명령. 물통이 빈해야하며 모든 개체가 삭제되어야합니다.

```sh
wrangler r2 bucket delete BUCKET_TO_DELETE
```

## 지원하다

- 버킷 이름과 버킷은 기본적으로 공개되지 않습니다. 버킷에 대한 공공 접근을 허용하려면, 참조[공공 버킷](/r2/buckets/public-buckets/).
- R2 버킷에 액세스 제어에 대한 정보를 Cloudflare 오시는 길[R2를 보호합니다 Cloudflare를 가진 물통 오시는 길](/r2/tutorials/cloudflare-access/).
- 무효 (허가되지 않은) 개인 버킷에 대한 액세스 시도는 그 버킷에 대한 R2 운영 비용이 발생하지 않습니다. 더 알아보기[R2 가격 FAQ](/r2/pricing/#frequently-asked-questions)작업이 청구되지 않는 대 청구되는 것을 이해하기 위해.

아래는 사용 예제입니다.[프로젝트](https://py.iceberg.apache.org/)R2 데이터 카탈로그에 연결하십시오.

## 자주 묻는 질문

- 로그인[Cloudflare 계정](https://dash.cloudflare.com/sign-up/workers-and-pages).
- [R2 버킷 만들기](/r2/buckets/create-buckets/)·[데이터 카탈로그](/r2/data-catalog/manage-catalogs/#enable-r2-data-catalog-on-a-bucket).
- [R2 API 토큰 생성](/r2/api/tokens/)둘 다[R2 및 데이터 카탈로그 권한](/r2/api/tokens/#permissions).
- 설치하기[프로젝트](https://py.iceberg.apache.org/#installation)·[프로젝트](https://arrow.apache.org/docs/python/install.html)자유게시판

## 예제 사용

```py
import pyarrow as pa
from pyiceberg.catalog.rest import RestCatalog
from pyiceberg.exceptions import NamespaceAlreadyExistsError

#Define 카탈로그 연결 세부 사항 (replace variables)
WAREHOUSE = "<WAREHOUSE>"
TOKEN = "<TOKEN>"
CATALOG_URI = "<CATALOG_URI>"

#R2 데이터 카탈로그에 연결
catalog = RestCatalog(
    name="my_catalog",
    warehouse=WAREHOUSE,
    uri=CATALOG_URI,
    token=TOKEN,
)

#기본 네임스페이스 만들기
catalog.create_namespace("default")

#간단한 PyArrow 테이블 만들기
df = pa.table({
    "id": [1, 2, 3],
    "name": ["Alice", "Bob", "Charlie"],
})

#Iceberg 테이블 만들기
test_table = ("default", "my_table")
table = catalog.create_table(
    test_table,
    schema=df.schema,
)
```

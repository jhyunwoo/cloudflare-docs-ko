아래는 빌드 할 수있는 방법의 예입니다.[아파치 Spark](https://spark.apache.org/)R2 Data Catalog에 연결되는 Scala와 함께 적용 이 응용 프로그램은 로컬 실행에 내장되지만 클러스터에서 실행할 수 있습니다.

## 자주 묻는 질문

- 로그인[Cloudflare 계정](https://dash.cloudflare.com/sign-up/workers-and-pages).
- [R2 버킷 만들기](/r2/buckets/create-buckets/)·[데이터 카탈로그](/r2/data-catalog/manage-catalogs/#enable-r2-data-catalog-on-a-bucket).
- [R2 API 토큰 생성](/r2/api/tokens/)둘 다[R2 및 데이터 카탈로그 권한](/r2/api/tokens/#permissions).
- Java 17, Spark 3.5.3 및 SBT 1.10.11 설치
  - 참고 : 도구의 특정 버전은이 예에서 일하는 것을 얻기 위해 중요합니다.
  - 팁 :[“SDKMAN”이란?](https://sdkman.io/)SDK 설치에 편리한 패키지 관리자입니다.

## 예제 사용

시작하려면 기계에 새로운 빈 프로젝트 디렉토리를 만듭니다.

그 디렉토리 안에 다음 파일을 만듭니다.`src/main/scala/com/example/R2DataCatalogDemo.scala`. 이것은 당신의 불꽃 신청을 위한 주요 입장 점으로 봉사할 것입니다.

```java
package com.example

import org.apache.spark.sql.SparkSession

object R2DataCatalogDemo {
    def main(args: Array[String]): Unit = {

        val uri = sys.env("CATALOG_URI")
        val warehouse = sys.env("WAREHOUSE")
        val token = sys.env("TOKEN")

        val spark = SparkSession.builder()
            .appName("My R2 Data Catalog Demo")
            .master("local[*]")
            .config("spark.sql.extensions", "org.apache.iceberg.spark.extensions.IcebergSparkSessionExtensions")
            .config("spark.sql.catalog.mydemo", "org.apache.iceberg.spark.SparkCatalog")
            .config("spark.sql.catalog.mydemo.type", "rest")
            .config("spark.sql.catalog.mydemo.uri", uri)
            .config("spark.sql.catalog.mydemo.warehouse", warehouse)
            .config("spark.sql.catalog.mydemo.token", token)
            .getOrCreate()

        import spark.implicits._

        val data = Seq(
            (1, "Alice", 25),
            (2, "Bob", 30),
            (3, "Charlie", 35),
            (4, "Diana", 40)
        ).toDF("id", "name", "age")

        spark.sql("USE mydemo")

        spark.sql("CREATE NAMESPACE IF NOT EXISTS demoNamespace")

        data.writeTo("demoNamespace.demotable").createOrReplace()

        val readResult = spark.sql("SELECT * FROM demoNamespace.demotable WHERE age > 30")
        println("Records with age > 30:")
        readResult.show()
    }
}
```

이 응용 프로그램을 구축하고 의존성을 관리하기 위해, 우리는 사용할 것입니다[sbt (“간단한 빌드 도구”)](https://www.scala-sbt.org/). 다음은 예입니다.`build.sbt`프로젝트의 뿌리에 배치 할 파일. "fat JAR"을 생산하기 위해 구성되며 필요한 모든 의존성을 묶습니다.

```java
name := "R2DataCatalogDemo"

version := "1.0"

val sparkVersion = "3.5.3"
val icebergVersion = "1.8.1"

// You need to use binaries of Spark compiled with either 2.12 or 2.13; and 2.12 is more common.
// If you download Spark 3.5.3 with sdkman, then it comes with 2.12.18
scalaVersion := "2.12.18"

libraryDependencies ++= Seq(
    "org.apache.spark" %% "spark-core" % sparkVersion,
    "org.apache.spark" %% "spark-sql" % sparkVersion,
    "org.apache.iceberg" % "iceberg-core" % icebergVersion,
    "org.apache.iceberg" % "iceberg-spark-runtime-3.5_2.12" % icebergVersion,
    "org.apache.iceberg" % "iceberg-aws-bundle" % icebergVersion,
)

// build a fat JAR with all dependencies
assembly / assemblyMergeStrategy := {
    case PathList("META-INF", "services", xs @ _*) => MergeStrategy.concat
    case PathList("META-INF", xs @ _*) => MergeStrategy.discard
    case "reference.conf" => MergeStrategy.concat
    case "application.conf" => MergeStrategy.concat
    case x if x.endsWith(".properties") => MergeStrategy.first
    case x => MergeStrategy.first
}

// For Java  17 Compatability
Compile / javacOptions ++= Seq("--release", "17")
```

사용 방법[sbt 집합 플러그인](https://github.com/sbt/sbt-assembly?tab=readme-ov-file)(지방 JAR를 구축하는 데 사용), 새 파일에 다음을 추가`project/assembly.sbt`:

```
addSbtPlugin("com.eed3si9n" % "sbt-assembly" % "1.2.0")
```

Java, Spark 및 sbt가 설치되고 쉘에서 사용할 수 있는지 확인하십시오. SDKMAN을 사용하는 경우 아래에서 볼 수 있습니다.

```bash
sdk install java 17.0.14-amzn
sdk install spark 3.5.3
sdk install sbt 1.10.11
```

모든 것을 설치, 당신은 지금 sbt를 사용하여 프로젝트를 구축 할 수 있습니다. 단일 번들 JAR 파일을 생성합니다.

```bash
sbt clean assembly
```

건물 후에, 산출 JAR는 안으로 있어야 합니다`target/scala-2.12/R2DataCatalogDemo-assembly-1.0.jar`.

응용 프로그램을 실행하려면, 당신은`spark-submit`. 아래 예제 쉘 스크립트입니다 (`submit.sh`Java 17의 Spark에 필요한 Java compatibility flags를 포함하는 ):

```
# We need to set these "--add-opens" so that Spark can run on Java 17 (it needs access to
# parts of the JVM which have been modularized and made internal).
JAVA_17_COMPATABILITY="--add-opens=java.base/sun.nio.ch=ALL-UNNAMED --add-opens=java.base/java.nio=ALL-UNNAMED --add-opens=java.base/java.lang=ALL-UNNAMED --add-opens=java.base/java.util=ALL-UNNAMED --add-opens=java.base/java.util.concurrent=ALL-UNNAMED"

spark-submit \
--conf "spark.driver.extraJavaOptions=$JAVA_17_COMPATABILITY" \
--conf "spark.executor.extraJavaOptions=$JAVA_17_COMPATABILITY" \
--class com.example.R2DataCatalogDemo target/scala-2.12/R2DataCatalogDemo-assembly-1.0.jar
```

그것을 실행하기 전에 스크립트가 실행되도록:

```bash
chmod +x submit.sh
```

작업 제출하기 전에 카탈로그 URI, 창고 및 필요한 환경 변수 설정이 있는지 확인하십시오.[Cloudflare API 토큰](/r2/api/tokens/).

```bash
export CATALOG_URI=
export WAREHOUSE=
export TOKEN=
```

당신은 지금 작업을 실행할 준비가:

```bash
./submit.sh
```

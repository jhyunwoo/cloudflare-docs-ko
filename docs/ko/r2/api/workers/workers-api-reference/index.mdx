in-Worker R2 API는 R2 물통을 a에 바인딩해서 접근됩니다[작업자](/workers). 쓰기 노동자는 경로 또는 조작 R2 객체를 통해 물통에 외부 액세스를 노출 할 수 있습니다.

R2 API는 S3 API에서 몇 가지 확장 및 세심한 차이를 포함합니다. S3 호환성이 필요한 경우,[S3- 호환 API](/r2/api/s3/).

## 회사 소개

R2는 당신이 물건을 저장하는 자료, 물통이라고 불리는 콘테이너로, 불린. 물통은 R2 내에서 성능, 스케일링 및 액세스의 기본 단위입니다.

<Tabs syncKey="workersExamples">
  <TabItem label="JavaScript" icon="seti:javascript">
    ```js
    export default {
    	async fetch(request, env) {
    		const url = new URL(request.url);
    		const key = url.pathname.slice(1);

    		switch (request.method) {
    			case "PUT":
    				await env.MY_BUCKET.put(key, request.body);
    				return new Response(`Put ${key} successfully!`);

    			default:
    				return new Response(`${request.method} is not allowed.`, {
    					status: 405,
    					headers: {

    					},
    				});
    		}
    	},
    };
    ```

    ```py
    from workers import WorkerEntrypoint, Response
    from urllib.parse import urlparse

    class Default(WorkerEntrypoint):
    	async def fetch(self, request):
    		url = urlparse(request.url)
    		key = url.path[1:]

    		if request.method == "PUT":
    			await self.env.MY_BUCKET.put(key, request.body)
    			return Response(f"Put {key} successfully!")
    		else:
    			return Response(
    				f"{request.method} is not allowed.",
    				status=405,
    ```

## `R2Object`이름 \*

`R2Object`당신이 할 때 생성`PUT`R2 물통에 목표.`R2Object`업로드자가 제공하는 정보에 근거한 객체의 메타데이터를 나타냅니다. 모든 물체`PUT`R2 물통으로`R2Object`로그인

- `key` <Type text="string" />

  - 객체의 키.

- `version` <Type text="string" />

  - 키의 특정 업로드와 관련된 랜덤 고유 문자열.

- `size` <Type text="number" />

  - 바이트의 객체의 크기.

:::

#### 연락처

`R2GetOptions`이름 \*`range`매개 변수, 즉 반환된 데이터를 제한하는 데 사용할 수 있습니다`body`.

범위에서 사용할 수있는 인수의 3 가지 변형이 있습니다.

- 옵션 길이로 오프셋.

- 길이를 가진 선택적인 상쇄.

- 스프릭스

  - byte는, 포괄적 인에서 데이터를 반환하기 시작합니다.

### R2List옵션

- `limit` <Type text="number" /> <MetaInfo text="optional" />

  - 반환 결과의 수. 기본 설정`1000`, 최대의`1000`.

  - 이름 \*`include`세트, 당신은 보다는 더 적은을 받을지도 모릅니다`limit`metadata를 수용하기 위해 응답에 있는 결과.

- `prefix` <Type text="string" /> <MetaInfo text="optional" />

  - 키에 대한 접두사. 열쇠는 주어진 접두사로 시작하는 경우에만 반환될 것입니다.

- `cursor` <Type text="string" /> <MetaInfo text="optional" />

  - 불투명 토큰은 다음과 같은 객체를 계속 나열하는 것을 나타냅니다. 커서를 이전 목록 작업에서 검색 할 수 있습니다.

- `delimiter` <Type text="string" /> <MetaInfo text="optional" />

  - 키를 그룹화 할 때 사용하는 문자.

- `include` <Type text="Array<string>" /> <MetaInfo text="optional" />

  - 수 있습니다.`httpMetadata`및/또는`customMetadata`. 포함되는 경우, 목록에 의해 반환된 항목은 지정된 metadata를 포함합니다.

  - 단일 데이터의 총 금액에 제한이 있음`list`가동은 돌려보낼 수 있습니다. 데이터 요청 시, 보다 적은 금액을 받을 수 있습니다.`limit`metadata를 수용하기 위해 응답에 있는 결과.

  - 더 보기[호환성 날짜](/workers/configuration/compatibility-dates/)설정하기`2022-08-04`또는 나중에 Wrangler 파일에서. 그렇지 않다면`r2_list_honor_include`호환성 깃발은 놓아야 합니다. 그렇지 않으면 그것은 대우됩니다`include: ['httpMetadata', 'customMetadata']`무엇에 관계없이`include`실제로 제공된 옵션입니다.

  이것은 응용 프로그램이 당신의 반환 개체의 양을 비교하는 것을 주의해야`limit`. 대신, 사용`truncated`속성을 결정하는 경우`list`요청은 더 많은 데이터를 반환합니다.

```js
const options = {
	limit: 500,
	include: ["customMetadata"],
};

const listed = await env.MY_BUCKET.list(options);

let truncated = listed.truncated;
let cursor = truncated ? listed.cursor : undefined;

//✓ - 제한이 단일 응답 또는 당신의에 적합하지 않는 경우
//물통은 한계 보다는 더 적은 목표를 가지고 있습니다, 그것은 여기에서 찔릴 것입니다.
while (listed.objects.length < options.limit) {
	//· ...
}

//✅ - truncated 속성을 사용하여 더 많은 것을 확인
//반환된 객체
while (truncated) {
	const next = await env.MY_BUCKET.list({
		...options,
		cursor: cursor,
	});
	listed.objects.push(...next.objects);

	truncated = next.truncated;
	cursor = next.cursor;
}
```

### 상태 작업

당신은 통과 할 수 있습니다`R2Conditional`관련 기사`R2GetOptions`·`R2PutOptions`. 상태 체크를 위한 경우에`get()`실패, 몸은 반환되지 않습니다. 이것은`get()`더 낮은 대기 시간.

상태 확인을 위해`put()`실패,`null`대신 반환됩니다`R2Object`.

- `etagMatches` <Type text="string" /> <MetaInfo text="optional" />

  - 객체의 etag가 주어진 문자열을 일치하면 작업을 수행합니다.

- `etagDoesNotMatch` <Type text="string" /> <MetaInfo text="optional" />

  - 객체의 etag가 주어진 문자열과 일치하지 않는 경우 작업 수행.

- `uploadedBefore` <Type text="Date" /> <MetaInfo text="optional" />

  - 주어진 날짜 전에 객체가 업로드 된 경우 작업 수행.

- `uploadedAfter` <Type text="Date" /> <MetaInfo text="optional" />

  - 주어진 날짜 이후에 객체가 업로드 된 경우 작업 수행.

대안으로, 당신은 통과할 수 있습니다`Headers`상태 헤더를 포함하는 객체`R2GetOptions`·`R2PutOptions`. 이 상태 우두머리에 대한 정보는 참조[상태 요청에 MDN docs](https://developer.mozilla.org/en-US/docs/Web/HTTP/Conditional_requests#conditional_headers). 모든 조건부 headers에서`If-Range`지원됩니다.

상태 요청에 대한 자세한 내용은 참조[RFC 7232의](https://datatracker.ietf.org/doc/html/rfc7232).

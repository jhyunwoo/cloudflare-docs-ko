이 페이지 문서 오류 코드는 R2에 의해 반환[모델 번호: Workers](/r2/api/workers/)또는[S3- 호환 API](/r2/api/s3/), 문제 해결에 도움이 권장 수정과 함께.

## 오류가 반환되는 방법

제품정보**모델 번호: Workers**, R2 가동은 당신이 붙잡을 수 있는 예외를 던졌습니다. 오류 코드는 끝에 포함되어 있습니다.`message`이름:

```js
try {
  await env.MY_BUCKET.put("my-key", data, { customMetadata: largeMetadata });
} catch (error) {
  console.error(error.message);
  //"put: 메타데이터 헤더는 최대 허용된 메타데이터 크기를 초과합니다. (10012)"
}
```

제품정보**S3- 호환 API**, 과실은 응답 몸에 있는 XML로 돌려보냅니다:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Error>
  <Code>NoSuchKey</Code>
  <Message>The specified key does not exist.</Message>
</Error>
```

R2는 S3 API를 구현하여 사용자 및 응용 프로그램을 쉽게 마이그레이션할 수 있습니다. AWS S3에 비교할 때, Cloudflare는 몇몇 API 가동의 특징을 제거하고 다른 사람을 추가했습니다. S3 API 작업은 현재 구현 상태에 따라 나열됩니다. 기능 구현은 현재 진행 중입니다. 이 페이지에 다시 업데이트합니다.
API를 통해 사용할 수 있습니다`https://<ACCOUNT_ID>.r2.cloudflarestorage.com`끝점. 내 계정[Cloudflare dashboardXQ의 계정 ID](/fundamentals/account/find-account-and-zone-ids/).

## 이 페이지를 읽는 방법

이 페이지에는 2개의 섹션이 있습니다: 물통 수준 가동 및 목표 수준 가동.

각 섹션에는 두 개의 테이블이 있습니다 : 구현 된 API 및 단순화 된 API의 테이블.

각 테이블의 기능 열을 참고하여 API의 기능을 구현하고 있지 않다는 것을 검토하십시오.

✅ 기능 구현<br />기능 구현 (Experimental)<br />❌ 기능 구현되지 않음

## 물통 지역

S3 API를 사용할 때, R2 버킷의 영역은`auto`. 지역을 지정할 수 없는 도구와 호환성을 위해, 빈 값 및`us-east-1`의지 alias 에`auto`지역.

또한 적용`LocationConstraint`제품정보`CreateBucket`API.

## 체크섬 유형

체크섬에는 알고리즘과[제품정보](https://docs.aws.amazon.com/AmazonS3/latest/userguide/checking-object-integrity.html#ChecksumTypes). 아래에 테이블에 Refer.

| 체크섬 Algorithm                  | `FULL_OBJECT` | `COMPOSITE` |
| ------------------------------ | ------------- | ----------- |
| 모델 번호: CRC-64/NVME`CRC64NVME`) | ✅             | ❌           |
| 모델 번호: CRC-32`CRC32`)          | ❌             | ✅           |
| 모델 번호: CRC-32C`CRC32C`)        | ❌             | ✅           |
| SHA-1 (주)`SHA1`)               | ❌             | ✅           |
| SHA-256 (주)`SHA256`)           | ❌             | ✅           |

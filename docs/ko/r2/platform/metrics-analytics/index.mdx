R2는 당신이 당신의 계정에 있는 물통의 요구 그리고 저장을 검열하는 것을 허용하는 분석을 노출합니다.

물통에 표시된 미터[Cloudflare dashboard](https://dash.cloudflare.com/)Cloudflare[GraphQL 분석 API](/analytics/graphql-api/). 미터에 접근할 수 있습니다[프로그램](#query-via-the-graphql-api)GraphQL 또는 HTTP 클라이언트를 통해.

미터는 지난 31 일 동안 (그리고 유지됩니다) 수 있습니다. 이 datasets는 요구합니다`accountTag`Cloudflare 계정 ID를 가진 여과기.

:::caution\[관할권 제한을 가진 쿼리 물통]
귀하의 계정에서 동일한 이름의 두 개의 버킷이있을 수 있으며 지정된 관할 구역과 하나가 없습니다.

따라서 지정된 관할 구역이있는 물통에 대한 통계를 쿼리하려면 반드시 포함해야 합니다.[회사연혁](https://developers.cloudflare.com/r2/reference/data-location/#jurisdictional-restrictions)물통 이름의 앞에 underscore에 의해 뒤에. 예를 들면:`eu_bucket-name`. 이것은 당신이 정확한 물통을 쿼리합니다.
주요 특징

## dashboard를 통해보기

R2에 대한 Per-bucket 분석은 Cloudflare dashboard에서 사용할 수 있습니다. 물통을 위한 현재와 역사적인 미터를 전망하기 위하여:

1. Cloudflare dashboard에서, 가십시오**R2 객체 저장**사이트 맵

   <DashButton url="/?to=/:account/r2/overview" />
2. 당신의 물통을 선택하십시오.
3. 선택하기**미터**탭.

쿼리에 시간 창을 선택 할 수 있습니다. 이 기본값은 마지막 24시간입니다.

## GraphQL API를 통해 쿼리

당신은 당신의 R2 물통을 위한 programmatically 쿼리 분석 할 수 있습니다[GraphQL 분석 API](/analytics/graphql-api/). 이 API는 Cloudflare dashboard로 동일한 dataset를 쿼리하고, GraphQL를 지원합니다[관련 상품](/analytics/graphql-api/features/discovery/introspection/).

### 영업 시간

주어진 시간 동안 물통에 각 가동 유형의 양을 조회하기 위하여 당신은 같은 쿼리를 실행할 수 있습니다

```graphql graphql-api-explorer
query R2VolumeExample(
	$accountTag: string!
	$startDate: Time
	$endDate: Time
	$bucketName: string
) {
	viewer {
		accounts(filter: { accountTag: $accountTag }) {
			r2OperationsAdaptiveGroups(
				limit: 10000
				filter: {
					datetime_geq: $startDate
					datetime_leq: $endDate
					bucketName: $bucketName
				}
			) {
				sum {
					requests
				}
				dimensions {
					actionType
				}
			}
		}
	}
}
```

더 보기`bucketName`필드는 작업의 계정 수준 overview를 제거 할 수 있습니다. 작업의 볼륨은 쿼리에 더 많은 크기를 추가하여 더 끊을 수 있습니다.

### 제품 정보

같은 쿼리를 실행할 수 있는 주어진 시간 기간 동안 물통의 저장을 쿼리하려면.

```graphql graphql-api-explorer
query R2StorageExample(
	$accountTag: string!
	$startDate: Time
	$endDate: Time
	$bucketName: string
) {
	viewer {
		accounts(filter: { accountTag: $accountTag }) {
			r2StorageAdaptiveGroups(
				limit: 10000
				filter: {
					datetime_geq: $startDate
					datetime_leq: $endDate
					bucketName: $bucketName
				}
				orderBy: [datetime_DESC]
			) {
				max {
					objectCount
					uploadCount
					payloadSize
					metadataSize
				}
				dimensions {
					datetime
				}
			}
		}
	}
}
```

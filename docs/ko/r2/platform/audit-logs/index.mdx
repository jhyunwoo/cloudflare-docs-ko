[감사 로그](/fundamentals/account/account-security/review-audit-logs/)Cloudflare 계정 내에서 작성된 변경 사항들을 R2 버킷으로 제공합니다. 이 기능은 모든 플랜 유형, 무료, 항상 활성화됩니다.

## 감사 로그보기

R2 버킷에 대한 감사 로그를 보려면, 이동**감사 로그**사이트 맵

<DashButton url="/?to=/:account/audit-log" />

액세스 및 사용 감사 로그에 대한 자세한 내용은 참조[리뷰 감사 로그](/fundamentals/account/account-security/review-audit-logs/).

## 로그아웃

다음 구성 작업은 로그입니다:

| - 연혁                    | 이름 \*                           |
| ----------------------- | ------------------------------- |
| 회사 소개                   | 새로운 물통의 창조.                     |
| 파일 형식                   | 기존 버킷의 삭제.                      |
| 사용자 정의                  | 사용자 정의 도메인의 추가 물통.              |
| 제거CustomDomain          | 버킷에서 사용자 정의 도메인 제거.             |
| ChangeBucket고객          | 관리 공공 액세스 변경 (`r2.dev`) 물통의 조정. |
| PutBucket저장 클래스         | 버킷의 기본 저장 클래스로 변경합니다.           |
| PutBucketLifecycle구성    | 버킷의 객체 수명주기 구성 변경.              |
| DeleteBucketLifecycle구성 | 버킷의 객체 수명주기 구성의 삭제.             |
| 카테고리                    | 물통에 대한 CORS 구성 변경.              |
| DeleteBucket커           | 물통을 위한 CORS 윤곽의 삭제.             |

:::참조
데이터 액세스 작업에 대한 로그 등`GetObject`·`PutObject`, 감사 로그에 포함되지 않습니다. 공용 R2 버킷으로 만든 HTTP 요청을 로그하려면[HTTP 요청](/logs/logpush/logpush-job/datasets/zone/http_requests/)Logpush 데이터 세트.
주요 특징

## 자주 묻는 질문

아래는 새로운 버킷의 생성을 보여주는 감사 로그 항목의 예입니다.

```json
{
  "action": { "info": "CreateBucket", "result": true, "type": "create" },
  "actor": {
    "email": "<ACTOR_EMAIL>",
    "id": "3f7b730e625b975bc1231234cfbec091",
    "ip": "fe32:43ed:12b5:526::1d2:13",
    "type": "user"
  },
  "id": "5eaeb6be-1234-406a-87ab-1971adc1234c",
  "interface": "API",
  "metadata": { "zone_name": "r2.cloudflarestorage.com" },
  "newValue": "",
  "newValueJson": {},
  "oldValue": "",
  "oldValueJson": {},
  "owner": { "id": "1234d848c0b9e484dfc37ec392b5fa8a" },
  "resource": { "id": "my-bucket", "type": "r2.bucket" },
  "when": "2024-07-15T16:32:52.412Z"
}

```

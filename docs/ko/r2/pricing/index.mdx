R2는 그 자료에 가동의 2개의 종류와 더불어 저장된 자료의 총 양에 근거를 둡니다:

1. [클래스 A 작업](#class-a-operations)mutate 상태에 더 비싸고 경향이 있습니다.
2. [클래스 B 작업](#class-b-operations)기존 상태를 읽는 경향이 있습니다.

Infrequent Access 스토리지 클래스의 경우,[데이터 검색](#data-retrieval)수수료 적용 모든 저장 클래스의 egress 대역폭에 대한 수수료가 없습니다.

모든 포함 된 사용은 월별입니다.

## R2 가격

|                       | 표준 저장          | Infrequent Access 스토리지 |
| --------------------- | -------------- | ---------------------- |
| 제품 정보                 | $0.015 / GB-월  | $0.01 / GB-월           |
| Class A 운영            | $ 4.50 / 백만 요청 | $9.00 / 백만 요청          |
| 클래스 B 운영              | $0.36 / 백만 요청  | $0.90 / 백만 요청          |
| Data Retrieval (처리)   | 이름 \*          | $0.01 / 기가바이트          |
| Egress (인터넷으로 데이터 전송) | 무료 다운로드[^1]    | 무료 다운로드[^1]            |

:::caution\[일부 단위 라운드]
Cloudflare는 다음 청구 단위에 당신의 사용법을 돌립니다.

예를 들면:

- 1백만개와 1개의 가동을 실행한 경우에, 당신은 2백만개의 가동을 청구될 것입니다.
- 당신이 1.1 GB 달을 사용한 경우에, 당신은 2개 GB 달을 청구될 것입니다.
- 1.1 GB의 데이터 (자본 액세스 저장 용)를 검색 한 경우 2 GB에 청구됩니다.
  주요 특징

### 무료 계층

저장 및 운영의 다음 금액을 무료로 사용할 수 있습니다.

|                       | 무료 다운로드     |
| --------------------- | ----------- |
| 제품 정보                 | 10 GB 달/달   |
| Class A 운영            | 1백만개의 요구/달  |
| 클래스 B 운영              | 10백만개의 요구/달 |
| Egress (인터넷으로 데이터 전송) | 무료 다운로드[^1] |

:::카트로션
무료 계층은 표준 저장에만 적용되며 Infrequent Access Storage에 적용되지 않습니다.
주요 특징

### 저장 사용

저장은 청구 미터로 gigabyte-month (GB-month)를 사용하여 청구됩니다. GB-month는 averaging에 의해 산출됩니다*주 메뉴*빌링 기간(30일) 이상일당 보관.

예를 들면:

- 30 일 동안 지속적으로 1 GB를 저장하는 것은 1 GB 달로 위탁될 것입니다.
- 30 일 동안 지속적으로 3 GB를 저장하는 것은 3 GB 달로 위탁될 것입니다.
- 5 일 동안 1 GB를 저장하고, 나머지 25 일 동안 3 GB는 위탁될 것입니다`1 GB * 5/30 month + 3 GB * 25/30 month = 2.66 GB-month`

Infrequent Access Storage에 저장되는 개체의 경우, 객체가 삭제되거나 지정된 기간 전에 이동하더라도 최소한의 저장 기간에 대한 객체에 대해 청구됩니다.

### 클래스 A 작업

Class A 운영에는`ListBuckets`, `PutBucket`, `ListObjects`, `PutObject`, `CopyObject`, `CompleteMultipartUpload`, `CreateMultipartUpload`, `LifecycleStorageTierTransition`, `ListMultipartUploads`, `UploadPart`, `UploadPartCopy`, `ListParts`, `PutBucketEncryption`, `PutBucketCors`·`PutBucketLifecycleConfiguration`.

### 클래스 B 작업

Class B 운영에는`HeadBucket`, `HeadObject`, `GetObject`, `UsageSummary`, `GetBucketEncryption`, `GetBucketLocation`, `GetBucketCors`·`GetBucketLifecycleConfiguration`.

### 무료 운영

무료 작업 포함`DeleteObject`, `DeleteBucket`·`AbortMultipartUpload`.

### 데이터 검색

Data retrieval fee는 Infrequent Access Storage 클래스에서 데이터를 액세스하거나 검색할 때 적용됩니다. 이 포함 어떤 시간 개체 읽거나 복사.

### 공급 능력

Infrequent Access Storage에 저장되는 개체의 경우, 객체가 삭제되었거나 이동하거나 지정된 기간 전에 교체되는 경우에도 최소한의 저장 기간에 대한 개체를 청구합니다.

| 저장 종류                  | 공급 능력 |
| ---------------------- | ----- |
| 표준 저장                  | 이름 \* |
| Infrequent Access 스토리지 | 30 일  |

## QXQX0969XQ 데이터 카탈로그 가격

R2 데이터 카탈로그는**공공 베타**, 어떤 개발자와[R2 구독](/r2/pricing/)그것을 사용하여 시작할 수 있습니다. 현재 표준 R2 저장과 가동의 외부, 당신은 R2 자료 카탈로그의 당신의 사용을 위해 청구되지 않을 것입니다. 우리는 우리가 어떤 변화든지 만들거나 사용법을 위한 위탁을 시작하기 전에 적어도 30 일의 고시를 제공할 것입니다.

미래 가격에 대한 우리의 생각에 대해 더 알아 보려면, 참조[R2 데이터 카탈로그 발표 블로그](https://blog.cloudflare.com/r2-data-catalog-public-beta).

## 데이터 마이그레이션 가격

### 슈퍼 Slurper

Super Slurper는 무료로 사용할 수 있습니다. Super Slurper가 R2 버킷으로 만드는 클래스 A 작업에만 충전됩니다. 크기와 개체 \< 100MiB는 단일 클래스 A 작업에서 R2에 업로드됩니다. Larger object use multipart uploads to increase transfer success rate and will perform multiple Class A operations. 소스 버킷은 R2XQ에 슈퍼 슬러퍼 사본 개체로 추가 요금이 발생할 수 있습니다.

마이그레이션이 완료되면 이전 섹션에 설명 된 저장 및 클래스 A / B 작업을 청구됩니다.

### 사이트맵

Sippy는 무료입니다. 작업 Sippy 만 충전됩니다. R2 버킷. 요청한 객체가 R2에서 존재하지 않는 경우, Sippy는 소스 버킷에서 복사합니다. 크기가있는 개체 \< 200MiB는 단일 클래스 A 작업에서 R2에 업로드됩니다. Larger object use multipart uploads to increase transfer success rate, and will perform multiple Class A operations. 소스 버킷이 R2에 Sippy 사본 개체로 추가 요금을 처리 할 수 있음을주의하십시오.

객체는 R2XQ로 마이그레이션되며 R2XQ에서 제공되며 이전 섹션에서 설명된 저장 및 클래스 A/B 작업을 담당합니다.

## R2 청구 예

### 표준 저장 예

사용자가 R2의 1,000 객체를 작성하면**표준 저장**1 GB의 평균 크기를 가진 1 달을 위해 달 도중 각 목표를 1,000배 읽습니다, 달을 위한 예상한 비용은 일 것입니다:

|                     | 제품 정보                                     | 무료 Tier | Billable 양 | 가격대비       |
| ------------------- | ----------------------------------------- | ------- | ---------- | ---------- |
| 제품 정보               | (1,000개의 객체) \* (1개 GB) = 1,000 GB-months | 10 GB 달 | 990 GB 개월  | $14.85     |
| Class A 운영          | (1,000 개체) \* (1 객체 당 쓰기) = 1,000 쓰기      | 1 백만    | 0          | $0.00      |
| 클래스 B 운영            | (1,000 개체) \* (1,000 개체당 읽음) = 1 백만 읽음    | 10 백만   | 0          | $0.00      |
| Data retrieval (처리) | (1,000 객체) \* (1GB 대상) = 1,000 GB         | 이름 \*   | 이름 \*      | $0.00      |
| **사이트맵**            |                                           |         |            | **$14.85** |

### Infrequent 액세스 예제

사용자가 R2의 1,000 객체를 작성하는 경우 1 GB의 평균 크기로 인하여 액세스 저장은 5 일 동안 저장하고 그 후에 삭제합니다 (운영은 무료입니다), 그 5 일 동안 각 개체는 1,000 번 읽습니다, 달의 예상 비용은 다음과 같습니다 :

|                     | 제품 정보                                     | 무료 Tier | Billable 양  | 가격대비       |
| ------------------- | ----------------------------------------- | ------- | ----------- | ---------- |
| 제품 정보               | (1,000개의 객체) \* (1개 GB) = 1,000 GB-months | 이름 \*   | 1,000 GB 개월 | $10.00     |
| Class A 운영          | (1,000 개체) \* (1 객체 당 쓰기) = 1,000 쓰기      | 이름 \*   | 1,000       | $9.00      |
| 클래스 B 운영            | (1,000 개체) \* (1,000 개체당 읽음) = 1 백만 읽음    | 이름 \*   | 1 백만        | $0.90      |
| Data retrieval (처리) | (1,000 객체) \* (1GB 대상) = 1,000 GB         | 이름 \*   | 1000년 GB    | $10.00     |
| **사이트맵**            |                                           |         |             | **$29.90** |

즉시 액세스 저장을위한 최소 저장 기간은 30 일이며, 청구 가능한 수량은 1,000 GB-months이지만 167 GB-months입니다.

### 자산 호스팅

사용자가 100 KB 객체의 평균 크기로 100,000 파일을 작성하고 하루에 10,000,000 개체를 읽으면 한 달에 예상된 비용은 다음과 같습니다.

|            | 제품 정보                        | 무료 Tier | Billable 양  | 가격대비        |
| ---------- | ---------------------------- | ------- | ----------- | ----------- |
| 제품 정보      | (100,000 개체) \* (물자당 100KB)  | 10 GB 달 | 0개 GB 달     | $0.00       |
| Class A 운영 | (100,000 쓰기)                 | 1 백만    | 0           | $0.00       |
| 클래스 B 운영   | (10,000,000 일당 읽기) \* (30 일) | 10 백만   | 290,000,000 | $104.40     |
| **사이트맵**   |                              |         |             | **$104.40** |

## 자주 묻는 질문

### R2 버킷에 무단 요청을 청구 할 수 있습니까?

이름 \* 콜러가 요청을 할 수없는 경우 작업에 대해 청구되지 않습니다 (HTTP 401`Unauthorized`응답 상태 부호).

[^1]: R2에서 직접 진입[모델 번호: Workers](/r2/api/workers/), [사이트맵](/r2/api/s3/)·[`r2.dev`이름 \*](/r2/buckets/public-buckets/#enable-managed-public-access)데이터 전송 (egress) 수수료가 부과되지 않습니다. R2 버킷에 다른 미터 서비스를 연결하면 해당 서비스에 의해 충전 될 수 있습니다.

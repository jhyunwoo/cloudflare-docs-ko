구성해야 합니다.[`boto3`](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html)preconstructed를 사용하여`endpoint_url`가치. 이 작업을 수행 할 수 있습니다.`boto3`연결 인수를 허용하는 사용; 예를 들어:

```python
import boto3

s3 = boto3.resource('s3',
  #Cloudflare 계정 ID 제공
  endpoint_url = 'https://<ACCOUNT_ID>.r2.cloudflarestorage.com',
  #API 토큰을 통해 R2 버킷에 대한 S3 API 자격 증명을 검색하십시오 (참고 : https://developers.cloudflare.com/r2/api/tokens)
  aws_access_key_id = '<ACCESS_KEY_ID>',
  aws_secret_access_key = '<SECRET_ACCESS_KEY>'
)
```

당신은 할 수 있습니다, 그러나, omit`aws_access_key_id`·`aws_secret_access_key `인수 및 허용`boto3`에 의존`AWS_ACCESS_KEY_ID`·`AWS_SECRET_ACCESS_KEY` [환경 변수](https://boto3.amazonaws.com/v1/documentation/api/latest/guide/configuration.html#using-environment-variables)대신.

예 스크립트는 다음과 같습니다.

```python
import boto3

s3 = boto3.client(
    service_name="s3",
    #Cloudflare 계정 ID 제공
    endpoint_url='https://<ACCOUNT_ID>.r2.cloudflarestorage.com',
    #API 토큰을 통해 R2 버킷에 대한 S3 API 자격 증명을 검색하십시오 (참고 : https://developers.cloudflare.com/r2/api/tokens)
    aws_access_key_id='<ACCESS_KEY_ID>',
    aws_secret_access_key='<SECRET_ACCESS_KEY>',
    region_name="auto", #SDK에 의해 필요하지만 R2
)

#오브젝트 정보
object_information = s3.head_object(Bucket='my-bucket', Key='dog.png')

#업로드/업데이트 단일 파일
s3.upload_fileobj(io.BytesIO(file_content), 'my-bucket', 'dog.png')

#객체 삭제
s3.delete_object(Bucket='my-bucket', Key='dog.png')
```

## 사전 서명된 URL 생성

공개 읽기를 공유하거나 일시적으로 버킷에 액세스 할 수있는 사전 서명 된 링크도 생성 할 수 있습니다.

```python
import boto3

s3 = boto3.client(
    service_name="s3",
    #Cloudflare 계정 ID 제공
    endpoint_url='https://<ACCOUNT_ID>.r2.cloudflarestorage.com',
    #API 토큰을 통해 R2 버킷에 대한 S3 API 자격 증명을 검색하십시오 (참고 : https://developers.cloudflare.com/r2/api/tokensQ)
    aws_access_key_id='<ACCESS_KEY_ID>',
    aws_secret_access_key='<SECRET_ACCESS_KEY>',
    region_name="auto", #SDK가 필요하지만 R2
)

#읽기에 대한 사전 서명 된 URL 생성 (GET)
#ExpiresIn 매개 변수는 긴 할당 된 링크가 유효하다는 것을 결정합니다 (초)
get_url = s3.generate_presigned_url(
    'get_object',
    Params={'Bucket': 'my-bucket', 'Key': 'dog.png'},
    ExpiresIn=3600  #1 시간 동안 유효
)

print(get_url)

#작성을위한 사전 서명 된 URL 생성 (PUT)
#ContentType을 지정하여 특정 파일 유형에 업로드
put_url = s3.generate_presigned_url(
    'put_object',
    Params={
        'Bucket': 'my-bucket',
        'Key': 'dog.png',
        'ContentType': 'image/png'
    },
    ExpiresIn=3600
)

print(put_url)
```

```sh output
https://<ACCOUNT_ID>.r2.cloudflarestorage.com/my-bucket/dog.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=...&X-Amz-Date=<timestamp>&X-Amz-Expires=3600&X-Amz-SignedHeaders=host&X-Amz-Signature=<signature>
https://<ACCOUNT_ID>.r2.cloudflarestorage.com/my-bucket/dog.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=...&X-Amz-Date=<timestamp>&X-Amz-Expires=3600&X-Amz-SignedHeaders=content-type%3Bhost&X-Amz-Signature=<signature>
```

생성된 링크를 사용할 수 있습니다.`put_object`지정된 버킷과 키에 업로드 할 수 있는 예, 사전 서명된 링크가 만료될 때까지. 지정된 URL을 사용할 때`ContentType`, 고객은 일치를 포함해야 합니다`Content-Type`요청의 헤더.

```sh
curl -X PUT "https://<ACCOUNT_ID>.r2.cloudflarestorage.com/my-bucket/dog.png?X-Amz-Algorithm=..." \
  -H "Content-Type: image/png" \
  --data-binary @dog.png
```

## CORS 및 Content-Type으로 업로드 제한

사전 서명 된 URL을 생성 할 때, 당신은 학대를 제한 할 수 있습니다 :

1. **콘텐츠 유형 제한**: 할당된 URL 매개변수에 있는 허용된 내용 유형 지정. 업로드는 클라이언트가 다른 것을 보낼 경우 실패합니다`Content-Type`헤더.

2. **CORS 구성**: 설정[CORS 규칙](/r2/buckets/cors/#add-cors-policies-from-the-dashboard)파일 업로드를 할 수 있습니다. CORS 구성[Cloudflare dashboard](https://dash.cloudflare.com/?to=/:account/r2/overview)Bucket 설정에 JSON 정책을 추가함으로써:

```json
[
  {
    "AllowedOrigins": ["https://example.com"],
    "AllowedMethods": ["PUT"],
    "AllowedHeaders": ["Content-Type"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

그런 다음 Content-Type 제한으로 사전 서명 된 URL을 생성합니다.

```python
#Content-Type 제한을 가진 사전 서명된 URL 생성
#업로드는 클라이언트가 Content-Type: image/png를 보내는 경우에만 성공할 것입니다
put_url = s3.generate_presigned_url(
    'put_object',
    Params={
        'Bucket': 'my-bucket',
        'Key': 'dog.png',
        'ContentType': 'image/png'
    },
    ExpiresIn=3600
)
```

클라이언트가이 할당 된 URL을 사용할 때, 그들은 반드시:

- 허용된 근원에서 요청을 만드십시오 (CORS에 의해 강화하는)
- 관련 기사`Content-Type: image/png`헤더 (시그니처에 의해 강화)

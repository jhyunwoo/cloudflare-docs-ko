## 사전 서명된 URL 생성

공개 읽기를 공유하거나 일시적으로 버킷에 액세스 할 수있는 사전 서명 된 링크도 생성 할 수 있습니다.

```ts
import { getSignedUrl } from "@aws-sdk/s3-request-presigner";

//만료되는 속성을 사용하여 지정된 링크가 유효하다는 것을 결정하십시오.
console.log(
	await getSignedUrl(
		S3,
		new GetObjectCommand({ Bucket: "my-bucket", Key: "dog.png" }),
		{ expiresIn: 3600 },
	),
);
//PutObject와 같은 작업에 대한 링크를 만들 수도 있습니다.
//ContentType을 지정하여 특정 파일 유형에 업로드합니다.
console.log(
	await getSignedUrl(
		S3,
		new PutObjectCommand({
			Bucket: "my-bucket",
			Key: "dog.png",
			ContentType: "image/png",
		}),
		{ expiresIn: 3600 },
	),
);
```

```sh output
https://my-bucket.<ACCOUNT_ID>.r2.cloudflarestorage.com/dog.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Content-Sha256=UNSIGNED-PAYLOAD&X-Amz-Credential=<credential>&X-Amz-Date=<timestamp>&X-Amz-Expires=3600&X-Amz-SignedHeaders=content-type%3Bhost&X-Amz-Signature=<signature>&x-id=PutObject
```

생성된 링크를 사용할 수 있습니다.`PutObject`지정된 버킷과 키에 업로드 할 수 있는 예, 사전 서명된 링크가 만료될 때까지. 지정된 URL을 사용할 때`ContentType`, 고객은 일치를 포함해야 합니다`Content-Type`요청의 헤더.

```sh
curl -X PUT "https://my-bucket.<ACCOUNT_ID>.r2.cloudflarestorage.com/dog.png?X-Amz-Algorithm=..." \
  -H "Content-Type: image/png" \
  --data-binary @dog.png
```

## CORS 및 Content-Type으로 업로드 제한

사전 서명 된 URL을 생성 할 때, 당신은 학대를 제한 할 수 있습니다 :

1. **콘텐츠 유형 제한**: 허용된 내용 유형 지정`PutObjectCommand`. 업로드는 클라이언트가 다른 것을 보낼 경우에 실패할 것입니다`Content-Type`헤더.

2. **CORS 구성**: 설정[CORS 규칙](/r2/buckets/cors/#add-cors-policies-from-the-dashboard)파일 업로드를 할 수 있습니다. CORS 구성[Cloudflare dashboard](https://dash.cloudflare.com/?to=/:account/r2/overview)Bucket 설정에 JSON 정책을 추가함으로써:

```json
[
  {
    "AllowedOrigins": ["https://example.com"],
    "AllowedMethods": ["PUT"],
    "AllowedHeaders": ["Content-Type"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

그런 다음 Content-Type 제한으로 사전 서명 된 URL을 생성합니다.

```ts
const putUrl = await getSignedUrl(
	S3,
	new PutObjectCommand({
		Bucket: "my-bucket",
		Key: "dog.png",
		ContentType: "image/png",
	}),
	{ expiresIn: 3600 },
);
```

클라이언트가이 할당 된 URL을 사용할 때, 그들은 반드시:

- 허용된 근원에서 요청을 만드십시오 (CORS에 의해 강화하는)
- 관련 기사`Content-Type: image/png`헤더 (시그니처에 의해 강화)

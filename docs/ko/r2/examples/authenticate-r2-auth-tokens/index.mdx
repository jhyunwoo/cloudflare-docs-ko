다음 예제는 S3 API 및 API 토큰을 사용하여 R2에 대해 인증하는 방법을 보여줍니다.

:::참조
익명 사용자를 위한 버킷 개체에 안전한 액세스를 제공함으로써, 우리는 사용하는 것을 추천합니다[사전 서명된 URL](/r2/api/s3/presigned-urls/)대신.

사전 서명 된 URL은 사용자가 조직의 구성원이 될 필요가 없으며 R2에 직접적인 프로그래밍 액세스를 가능하게합니다.
주요 특징

예를 실행하기 전에 다음 환경 변수를 설정해야 합니다. 더 알아보기[인증현황](/r2/api/tokens/)더 많은 정보.

```sh
export AWS_REGION=auto
export AWS_ENDPOINT_URL=https://<account_id>.r2.cloudflarestorage.com
export AWS_ACCESS_KEY_ID=your_access_key_id
export AWS_SECRET_ACCESS_KEY=your_secret_access_key
```

    제품 정보`go get`추가하기`aws-sdk-go-v2`Go 프로젝트에 패키지:

    ```sh
    go get github.com/aws/aws-sdk-go-v2
    go get github.com/aws/aws-sdk-go-v2/config
    go get github.com/aws/aws-sdk-go-v2/credentials
    go get github.com/aws/aws-sdk-go-v2/service/s3
    ```

    다음 Go 애플리케이션을 스크립트로 실행`go run main.go`. 변경 사항`bucket`당신의 물통의 이름에,`objectKey`R2 버킷의 기존 파일에 해당합니다.

    ```go
    package main

    import (
      "context"
      "fmt"
      "io"
      "log"
      "github.com/aws/aws-sdk-go-v2/aws"
      "github.com/aws/aws-sdk-go-v2/config"
      "github.com/aws/aws-sdk-go-v2/service/s3"
    )

    func main() {
        cfg, err := config.LoadDefaultConfig(context.TODO())
        if err != nil {
    	    log.Fatalf("Unable to load SDK config, %v", err)
        }

        // Create an S3 client
        client := s3.NewFromConfig(cfg)

        // Specify the object key
        bucket := "<YOUR_BUCKET_NAME>"
        objectKey := "pfp.jpg"

        // Fetch the object
        output, err := client.GetObject(context.TODO(), &s3.GetObjectInput{
    	    Bucket: aws.String(bucket),
    	    Key:    aws.String(objectKey),
        })
        if err != nil {
    	    log.Fatalf("Unable to fetch object, %v", err)
        }
        defer output.Body.Close()

        fmt.Println("Successfully fetched the object")

        // Process the object content as needed
        // For example, to save the file:
        // file, err := os.Create("ingested_0001.parquet")
        // if err != nil {
        // 	log.Fatalf("Unable to create file, %v", err)
        // }
        // defer file.Close()
        // _, err = io.Copy(file, output.Body)
        // if err != nil {
        // 	log.Fatalf("Unable to write file, %v", err)
        // }

        // Or to read the content:
        content, err := io.ReadAll(output.Body)
        if err != nil {
    	    log.Fatalf("Unable to read object content, %v", err)
        }
        fmt.Printf("Object content length: %d bytes\n", len(content))
    }
    ```

이 예제는 Terraform을 사용하여 R2를 구성하는 방법을 보여줍니다[Cloudflare 공급자](https://github.com/cloudflare/terraform-provider-cloudflare).

:::note\[AWS 공급자 사용]

Cloudflare Terraform 공급자를 사용할 때 물통만 관리할 수 있습니다. CORS 및 객체 수명주기와 같은 항목을 구성하려면 사용해야합니다.[AWS 공급자](/r2/examples/terraform-aws/).

:::

이름 \*[`terraform`](https://developer.hashicorp.com/terraform/downloads)설치, 생성`main.tf`API Token을 대체하고 아래 내용을 복사합니다.

```hcl
terraform {
  required_providers {
    cloudflare = {
      source = "cloudflare/cloudflare"
      version = "~> 4"
    }
  }
}

provider "cloudflare" {
  api_token = "<YOUR_API_TOKEN>"
}

resource "cloudflare_r2_bucket" "cloudflare-bucket" {
  account_id = "<YOUR_ACCOUNT_ID>"
  name       = "my-tf-test-bucket"
  location   = "WEUR"
}
```

다음을 사용할 수 있습니다.`terraform plan`변화를 보고`terraform apply`변경 사항

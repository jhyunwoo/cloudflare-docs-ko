Cloudflare R2 Storage는 개발자가 일반적인 클라우드 스토리지 서비스와 관련된 비용의 egress 대역폭 수수료 없이 많은 양의 비구조 데이터를 저장할 수 있습니다.

## 시작하기 전에

R2XQ 계정이 필요합니다. 당신은 아무도없는 경우:

1. 오시는 길[사이트맵 대시보드](https://dash.cloudflare.com/).
2. 제품정보**스토리지 및 데이터베이스 > R2 > 개요**
3. R2 구독을 계정에 추가하려면 체크 아웃 흐름을 완료하십시오.

R2는 get started에 무료 매달 사용법을 포함했습니다. 월간 이용에 대해 청구됩니다. 더 알아보기[가격 책정](/r2/pricing/)상세 정보

<DashButton url="/?to=/:account/r2/overview" />

## R2

R2는 다수 접근 방법을 지원합니다, 그래서 당신은 당신의 사용 케이스 제일 적합한 것을 선택할 수 있습니다:

| 제품 설명                                                         | 사용시                                                        |
| ------------------------------------------------------------- | ---------------------------------------------------------- |
| [Workers의 API](/r2/get-started/workers-api/)                  | Cloudflare WorkersXQXQ에 응용 프로그램을 구축하고 R2QQQXQ에서 작성하거나 작성해야 |
| [사이트맵](/r2/get-started/s3/)                                   | 기존 애플리케이션에서 R2와 상호 작용하기 위해 S3-compatible SDK를 사용하고 싶습니다.   |
| [CLI 도구](/r2/get-started/cli/)                                | 업로드, 다운로드, 또는 단말기에서 개체를 관리하고 싶습니다.                         |
| [대시보드](https://dash.cloudflare.com/?to=/:account/r2/overview) | 브라우저에서 버킷 및 개체를 빠르게 볼 수 있습니다.                              |

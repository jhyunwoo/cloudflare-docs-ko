## 3. 손잡이 파일 업로드

파일 업로드를 처리하려면 먼저 R2 바인딩을 추가해야합니다. Wrangler 파일에서 다음 코드를 추가하십시오.

<WranglerConfig>
  ```jsonc
  {
  	"r2_buckets": [
  		{
  			"binding": "MY_BUCKET",
  			"bucket_name": "<R2_BUCKET_NAME>"
  		}
  	]
  }
  ```
</WranglerConfig>

기타 제품`<R2_BUCKET_NAME>`R2 버킷의 이름으로.

다음, 업데이트`src/index.ts`파일. 더 보기`src/index.ts`파일은 다음과 같은 코드를 포함해야합니다:

```ts title="src/index.ts"
export default {
	async fetch(request, env, ctx): Promise<Response> {
		//자주 묻는 질문
		const pathname = new URL(request.url).pathname;

		if (pathname === "/api/upload" && request.method === "POST") {
			//요청에서 파일을 가져옵니다
			const formData = await request.formData();
			const file = formData.get("pdfFile") as File;

			//Cloudflare R2에 파일을 업로드
			const upload = await env.MY_BUCKET.put(file.name, file);
			return new Response("File uploaded successfully", { status: 200 });
		}

		return new Response("incorrect route", { status: 404 });
	},
} satisfies ExportedHandler<Env>;
```

위의 코드는 다음과 같습니다 :

- 요청이 POST 요청인지 확인`/api/upload`끝점. 그것이라면 요청에서 파일을 가져 와서 Cloudflare R2에 업로드하십시오.[Workers API를 설치하십시오](/r2/api/workers/).
- 요청이 POST 요청이 아닌 경우`/api/upload`endpoint, 그것은 404 응답을 반환합니다.

Worker 코드가 TypeScript에 기록되어 있기 때문에 필요한 유형 정의를 추가하려면 다음 명령을 실행해야합니다. 이 필요는 없지만 오류를 피할 수 있습니다.

## 5. 핸들 이벤트 알림

이제 이벤트 알림을 수신 할 수 있습니다. 이벤트 알림을 처리하기 위해 Worker를 업데이트해야합니다. Workers AI를 사용하여 PDF에서 텍스트 콘텐츠를 추출하고 내용을 요약하고 R2XQ를 사용하여 R2 물통에 저장해야합니다.

업데이트`src/index.ts`Queue 핸들러를 추가하는 파일:

```ts title="src/index.ts"
export default {
	async fetch(request, env, ctx): Promise<Response> {
		//fetch 핸들러의 변경 사항 없음
	},
	async queue(batch, env) {
		for (let message of batch.messages) {
			console.log(`Processing the file: ${message.body.object.key}`);
		}
	},
} satisfies ExportedHandler<Env>;
```

위의 코드는 다음과 같습니다 :

- 더 보기`queue`핸들러는 새로운 메시지가 큐에 추가 될 때 호출됩니다. 일괄 처리의 메시지를 통해 반복하고 파일의 이름을 기록합니다.

현재 위치`queue`핸들러는 아무것도하지 않습니다. 다음 단계에서, 당신은 업데이트됩니다`queue`PDF에서 텍스트 콘텐츠를 추출하는 핸들러는 Workers AI를 사용하여 콘텐츠를 요약하고 물통에 추가합니다.

## 6. PDF에서 텍스트 콘텐츠를 추출

PDF에서 텍스트 콘텐츠를 추출하려면 Worker는 사용[다운로드](https://github.com/unjs/unpdf)도서관. 더 보기`unpdf`라이브러리는 PDF 파일로 작업할 수 있는 유틸리티를 제공합니다.

설치하기`unpdf`다음 명령을 실행하여 라이브러리:

<PackageManagers pkg="unpdf" />

업데이트`src/index.ts`필요한 모듈을 가져올 파일`unpdf`도서관:

```ts title="src/index.ts" ins={1}
import { extractText, getDocumentProxy } from "unpdf";
```

다음, 업데이트`queue`PDF의 텍스트 콘텐츠를 추출하는 핸들러:

```ts title="src/index.ts" ins={4-15}
async queue(batch, env) {
  for(let message of batch.messages) {
    console.log(`Processing file: ${message.body.object.key}`);
    //R2 버킷에서 파일을 가져옵니다
    const file = await env.MY_BUCKET.get(message.body.object.key);
    if (!file) {
				console.error(`File not found: ${message.body.object.key}`);
				continue;
			}
    //PDF에서 텍스트 콘텐츠를 추출
    const buffer = await file.arrayBuffer();
    const document = await getDocumentProxy(new Uint8Array(buffer));

    const {text} = await extractText(document, {mergePages: true});
    console.log(`Extracted text: ${text.substring(0, 100)}...`);
    }
}
```

위의 코드는 다음과 같습니다 :

- 더 보기`queue`핸들러는 R2 물통에서 파일을 가져옵니다.
- 더 보기`queue`handler는 PDF에서 텍스트 콘텐츠를 추출합니다.`unpdf`도서관.
- 더 보기`queue`handler는 textual content를 로그합니다.

## 7. 내용을 요약하는 Workers AI를 사용하십시오

Workers AI를 사용하려면 Workers AIXQ 바인딩을 Wrangler 파일에 추가해야합니다. Wrangler 파일은 다음 코드를 포함해야 합니다.

<WranglerConfig>
  ```jsonc
  {
  	"ai": {
  		"binding": "AI"
  	}
  }
  ```
</WranglerConfig>

다음 명령을 실행하여 AI 유형 정의를 추가하십시오.

```sh
npm run cf-typegen
```

업데이트`src/index.ts`Workers AI를 사용하여 콘텐츠를 요약 할 파일 :

```ts title="src/index.ts" ins={7-15}
async queue(batch, env) {
  for(let message of batch.messages) {
    //PDF에서 텍스트 콘텐츠를 추출
    const {text} = await extractText(document, {mergePages: true});
    console.log(`Extracted text: ${text.substring(0, 100)}...`);

    //내용을 요약하려면 Workers AI를 사용하십시오.
    const result: AiSummarizationOutput = await env.AI.run(
    "@cf/facebook/bart-large-cnn",
      {
        input_text: text,
      }
    );
    const summary = result.summary;
    console.log(`Summary: ${summary.substring(0, 100)}...`);
  }
}
```

더 보기`queue`핸들러는 이제 Workers AI를 사용하여 콘텐츠를 요약합니다.

## 8. R2 물통에 요약을 추가하십시오

이제 요약이있어 R2 버킷에 추가해야합니다. 업데이트`src/index.ts`R2 물통에 요약을 추가하는 파일:

```ts title="src/index.ts" ins={8-14}
async queue(batch, env) {
  for(let message of batch.messages) {
    //PDF에서 텍스트 콘텐츠를 추출
    //· ...
    //내용을 요약하려면 Workers AI를 사용하십시오.
    //· ...

    //R2 버킷에 대한 요약 추가
    const upload = await env.MY_BUCKET.put(`${message.body.object.key}-summary.txt`, summary, {
					httpMetadata: {
						contentType: 'text/plain',
					},
		});
		console.log(`Summary added to the R2 bucket: ${upload.key}`);
  }
}
```

큐 핸들러는 이제 텍스트 파일로 R2 버킷에 요약을 추가합니다.

## 9. 이벤트 알림 사용

내 계정`queue`핸들링은 이벤트 알림 메시지를 처리 할 준비가되어 있습니다. 이벤트 알림을 활성화해야 합니다.[`wrangler r2 bucket notification create`이름 \*](/workers/wrangler/commands/#r2-bucket-notification-create)당신의 물통을 위해. 다음 명령은 이벤트 알림을 만듭니다.`object-create`이벤트 유형`pdf`스프록:

```sh
npx wrangler r2 bucket notification create <R2_BUCKET_NAME> --event-type object-create --queue pdf-summarizer --suffix "pdf"
```

기타 제품`<R2_BUCKET_NAME>`R2 버킷의 이름으로.

이벤트 알림이 생성됩니다.`pdf`뚱 베어 새 파일이 있을 때`pdf`suffix는 R2 물통에 업로드됩니다,`pdf-summarizer`queue는 트리거됩니다.

## 이름 \*

이 튜토리얼에서 R2 이벤트 알림을 사용하여 업로드 대상을 처리하는 방법을 배웠습니다. PDF 파일을 업로드하고, PDF 파일의 요약을 생성하는 소비자 노동자를 만들었습니다. Workers AI를 사용하여 PDF 파일의 내용을 요약하고 R2 Bucket에 요약을 업로드하는 방법을 배웠습니다.

이미지, 비디오 및 오디오 파일과 같은 다른 유형의 파일을 처리하는 동일한 접근 방식을 사용할 수 있습니다. 다른 유형의 이벤트를 처리하는 것과 같은 접근 방식을 사용할 수 있습니다. object deletion, object update.

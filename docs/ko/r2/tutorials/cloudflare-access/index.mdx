R2 물통에 안전하게 접근할 수 있습니다[모델 번호: Cloudflare 오시는 길](/cloudflare-one/access-controls/applications/http-apps/).

액세스는 특정 사용자, 그룹 또는 응용 프로그램을 허용 할 수 있습니다. 조직 내에서 개체에 액세스 할 수, 또는 특정 하위 경로, 당신이 정의하는 정책에 따라.

:::참조

익명 사용자를 위한 버킷 개체에 안전한 액세스를 제공함으로써, 우리는 사용하는 것을 추천합니다[사전 서명된 URL](/r2/api/s3/presigned-urls/)대신.

사전 서명 된 URL은 사용자가 조직의 구성원이 될 필요가 없으며 프로그래밍 응용 프로그램을 직접 가능하게합니다.

:::

## 1. 버킷 만들기

*기존 R2 버킷을 가지고 있다면 이 단계를 건너뛸 수 있습니다.*

R2 버킷을 만들 필요가 있습니다. 자주 묻는 질문[R2 get started 가이드](/r2/get-started/)이 가이드로 돌아가기 전에 물통을 만들려면.

## 2. 액세스 신청서 작성

내 계정**모델 번호: Zero Trust**Cloudflare 대시보드의 단면도는, 당신은 당신의 R2 물통에 접근 제한하기 위하여 접근 신청 그리고 정책을 만들 필요가 있을 것입니다.

Cloudflare 앞에 접근, 우리는 추천합니다:

- 설정하기[회사 소개](/cloudflare-one/integrations/identity-providers/)먼저 조직의 단일 서명(SSO) 공급자를 인증 방법으로 이용할 수 있습니다.

R2 버킷에 대한 액세스 응용 프로그램을 만들려면 :

1. 오시는 길[**오시는 길**](https://one.dash.cloudflare.com/?to=/:account/access/apps)선택하기**앱 추가**

2. 제품정보**셀프 호스팅**.

3. 이름 \***신청 이름**.

4. 제품정보**대중적인 hostname 추가**앱 도메인을 입력합니다. 더 보기**이름 \***&#x43;loudflare에서 호스팅되는 도메인이어야 하며,**이름 \***&#xC0AC;용자 정의 도메인의 일부는 R2 버킷에 연결됩니다. 예를 들어, 파일이 있는 경우`behind-access.example.com`·`example.com`Cloudflare 계정 내에서 도메인입니다.`behind-access`하위 도메인 필드에서 선택`example.com`으로**이름 \***&#xC774;름 \*

5. 더 보기[오시는 길](/cloudflare-one/access-controls/policies/)당신의 신청에 연결할 수 있는 통제. 이것은**지원하다**이 액세스 응용 프로그램 뒤에 물통 내에서 개체를 액세스 할 수 있도록 정책.

   :::참조
   이 R2 버킷에 액세스해야하는 조직 내에서만 사용자를 허용한다는 것을 보장합니다.
   주요 특징

6. 자주 묻는 질문[자체 호스팅 응용 프로그램 생성 단계](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/)앱을 게시합니다.

## 3. 사용자 정의 도메인 연결

:::카트로션

사용자 정의 도메인을 연결하기 전에 액세스 응용 프로그램을 만들려면 사용자 정의 도메인을 연결하면 기본으로 물통을 공개합니다.

:::

당신은 필요[사용자 정의 도메인 연결](/r2/buckets/public-buckets/#connect-a-bucket-to-a-custom-domain)액세스 응용 프로그램으로 구성하려면 물통에. 사용자 정의 도메인 확인**같은 도메인**액세스 정책을 설정할 때 입력했습니다.

## 4. 액세스 정책을 테스트

R2 버킷에 연결되는 사용자 정의 도메인을 방문하여 CloudflareQ 선택한 ID 공급자(s) 및/또는 인증 방법을 가진 액세스 인증 페이지.

예를 들어 Google 및/또는 GitHub ID 공급자를 연결하면 해당 공급자와 로그인할 수 있습니다. 로그인이 성공하면 QXQX1086XQ 버킷 내에서 액세스 정책에 액세스 할 수 있습니다.

정통하거나 정통 후 블록 페이지를받을 수없는 경우, 당신이 가지고 있는지 확인[오시는 길](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/#1-add-your-application-to-access)사용자 계정 그룹을 명시적으로 허용하는 액세스 응용 프로그램 내에서 구성.

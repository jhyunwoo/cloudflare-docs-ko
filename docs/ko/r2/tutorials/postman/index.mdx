Postman은 API와 상호 작용하는 API 플랫폼입니다. 이 가이드는 Postman을 사용하는 방법을 설명합니다. 인증 된 R2 요청을 사용하여 버킷을 만들고 새로운 객체를 업로드하고 객체를 검색합니다. R2[Postman 수집](https://www.postman.com/cloudflare-r2/workspace/cloudflare-r2/collection/20913290-14ddd8d8-3212-490d-8647-88c9dc557659?action=share\&creator=20913290)플랫폼에서 지원하는 전체 운영 목록이 포함되어 있습니다.

## 1. 구매 R2

이 가이드는 Cloudflare 계정을 만들고 R2Q를 구입했다고 가정합니다.

## 2. Postman에서 R2 탐색

R2의 공개 사용 가능[Postman 수집](https://www.postman.com/cloudflare-r2/workspace/cloudflare-r2/collection/20913290-14ddd8d8-3212-490d-8647-88c9dc557659?action=share\&creator=20913290). 수집은`Buckets`버킷 레벨 작업 및 폴더`Objects`object-level 작업용 폴더. 작업에`Objects > Upload`폴더는 R2에 새로운 개체를 추가 할 수 있습니다.

## 3. R2 자격 증명

내 계정[포스트맨 dashboard](https://www.postman.com/cloudflare-r2/workspace/cloudflare-r2/collection/20913290-14ddd8d8-3212-490d-8647-88c9dc557659?action=share\&creator=20913290\&ctx=documentation), 선택**Cloudflare R2**수집 및 탐색**변수**탭. 내 계정**변수**R2 컬렉션 내에서 변수를 설정할 수 있습니다. R2 플랫폼과 인증 및 상호 작용하는 데 사용됩니다. 항상 선택**제품 정보**변수를 업데이트 한 후.

기본 작업을 수행하려면 설정해야 합니다.`account-id`, `r2-access-key-id`·`r2-secret-access-key`Postman dashboard의 변수 >**변수**.

이 작업을 수행:

1. Cloudflare dashboard에서, 가십시오**R2 객체 저장**사이트 맵

   <DashButton url="/?to=/:account/r2/overview" />
2. 내 계정**모델 번호: R2**, 밑에**R2 API 관리 토큰 토큰**dashboard의 오른쪽에 Cloudflare 계정 ID를 복사하십시오.
3. 바로가기[포스트맨 dashboard](https://www.postman.com/cloudflare-r2/workspace/cloudflare-r2/collection/20913290-14ddd8d8-3212-490d-8647-88c9dc557659?action=share\&creator=20913290\&ctx=documentation).
4. 설정하기**현재 위치**이름 \*`account-id`Cloudflare 계정 ID 및 선택**제품 정보**.

다음, R2 API 토큰 생성:

1. Cloudflare dashboard에서, 가십시오**R2 객체 저장**사이트 맵

   <DashButton url="/?to=/:account/r2/overview" />
2. 오른쪽 손 측바에서, 선택**R2 API 관리 토큰 토큰**.
3. 제품정보**API 토큰 만들기**.
4. 토큰 이름**포스트맨**API 이름 옆에 연필 아이콘을 선택하고 그것을 부여**제품정보**이름 \*

이 토큰과**액세스 키 ID**·**비밀 액세스 키**밀접한. 이 단계를 끝내면 이 값을 다시 검토 할 수 없습니다. 이 정보를 가진 사람은 당신의 물통 전부와 완전히 상호 작용할 수 있습니다.

Cloudflare dashboard에서 API 토큰을 생성한 후:

1. 오시는 길[포스트맨 dashboard](https://www.postman.com/cloudflare-r2/workspace/cloudflare-r2/collection/20913290-14ddd8d8-3212-490d-8647-88c9dc557659?action=share\&creator=20913290\&ctx=documentation) > **변수**.
2. 관련 기사`Access Key ID`Cloudflare dashboard의 값은 Postman의`r2-access-key-id`변수 값 및 선택**제품 정보**.
3. 제출하기`Secret Access Key`Cloudflare dashboard의 값은 Postman의`r2-secret-access-key`변수 값 및 선택**제품 정보**.

지금, 당신은해야합니다`account-id`, `r2-secret-access-key`·`r2-access-key-id`Postman에서 설정.

토큰을 확인하려면:

1. Postman dashboard에서, 선택**Cloudflare R2**폴더 드롭다운 화살표 >**기타 제품**폴더 드롭다운 화살표 >**`GET`목록Buckets**.
2. 제품정보**이름 \***.

Postman 컬렉션은 AWS SigV4 인증을 사용하여 Handhake를 완료합니다.

당신은 볼 수`200 OK`기존 버킷의 목록과 응답. 오류를 수신하면 R2 구독이 활성화되고 Postman 변수가 올바르게 저장됩니다.

이 예제는 사용 단계별 가이드를 제공합니다.[이벤트 알림](/r2/buckets/event-notifications/)별도의 버킷에서 R2 업로드 로그를 캡처하고 저장합니다.

![푸시 기반 R2 이벤트 알림](~/assets/images/reference-architecture/event-notifications-for-storage/pushed-based-event-notification.svg)

## 1. Wrangler 설치

시작하기[설치/업데이트 Wrangler](/workers/wrangler/install-and-update/#install-wrangler)Wrangler, Cloudflare 개발자 플랫폼 CLI를 설치하십시오.

## 2. R2 물통 만들기

당신은 2개의 R2 물통을 창조할 필요가 있을 것입니다:

- `example-upload-bucket`: 새로운 개체가 이 물통에 업로드되면,[소비자 노동자](/queues/get-started/#4-create-your-consumer-worker)로그를 작성합니다.
- `example-log-sink-bucket`: 로그 업로드`example-upload-bucket`이 물통에 기록될 것입니다.

물통을 만들려면 다음 Wrangler 명령을 실행하십시오.

```sh
npx wrangler r2 bucket create example-upload-bucket
npx wrangler r2 bucket create example-log-sink-bucket
```

## 3. queue 만들기

Event 알림 캡처는 데이터로 변경됩니다.`example-upload-bucket`. 알림을 받기 위해 새로운 큐를 만들 필요가 있습니다.

```sh
npx wrangler queues create example-event-notification-queue
```

이벤트 알림을 활성화하기 전에`example-upload-bucket`, 당신은 만들 필요가[소비자 노동자](/queues/reference/how-queues-works/#create-a-consumer-worker)알림 받기

## 5. 당신의 노동자를 구성하십시오

## 6. R2로 이벤트 알림 메시지 쓰기

추가하기[`queue`회사 소개](/queues/configuration/javascript-apis/#consumer)으로`src/index.ts`우리의 로그 싱크 버킷에 알림의 배치를 처리하기 위해 (당신은 필요가 없습니다[회사 소개](/workers/runtime-apis/handlers/fetch/)):

```ts
export interface Env {
	LOG_SINK: R2Bucket;
}

export default {
	async queue(batch, env): Promise<void> {
		const batchId = new Date().toISOString().replace(/[:.]/g, "-");
		const fileName = `upload-logs-${batchId}.json`;

		//JSON에 메시지의 전체 배치를 직렬화
		const fileContent = new TextEncoder().encode(
			JSON.stringify(batch.messages),
		);

		//R2에 메시지의 배치를 쓰기
		await env.LOG_SINK.put(fileName, fileContent, {
			httpMetadata: {
				contentType: "application/json",
			},
		});
	},
} satisfies ExportedHandler<Env>;
```

## 7. 노동자를 배포

소비자 노동자를 배포하려면, 실행[`wrangler deploy`](/workers/wrangler/commands/#deploy)명령:

```sh
npx wrangler deploy
```

## 8. 이벤트 알림

이제 소비자 근로자가 들어오는 이벤트 알림 메시지를 처리 할 준비가되어있어 이벤트 알림을 활성화해야합니다.[`wrangler r2 bucket notification create`이름 \*](/workers/wrangler/commands/#r2-bucket-notification-create)제품 정보`example-upload-bucket`:

```sh
npx wrangler r2 bucket notification create example-upload-bucket --event-type object-create --queue example-event-notification-queue
```

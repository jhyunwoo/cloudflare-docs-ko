  모든 데이터에 대한 개체 저장.
</Description>

CloudflareR2 Storage는 개발자가 일반적인 클라우드 스토리지 서비스와 관련된 비용의 egress 대역폭 수수료 없이 많은 양의 비구조 데이터를 저장할 수 있습니다.

여러 시나리오에 대해 R2를 사용할 수 있지만 제한되지 않습니다.

- 클라우드 기반 응용 분야의 스토리지
- 클라우드 스토리지 웹 콘텐츠
- 팟캐스트 에피소드 저장
- 데이터 호수 (분석 및 큰 데이터)
- 기계 학습 모형 artifacts 또는 datasets와 같은 큰 배치 과정을 위한 클라우드 저장 산출

## 주요 특징

<Feature header="위치 힌트" href="/r2/reference/data-location/#location-hints">
  위치 힌트는 선택적 매개 변수입니다. 버킷 생성 중에 데이터를 기대하는 기본 지리적 위치를 나타냅니다.
</Feature>

<Feature header="사이트맵" href="/r2/buckets/cors/">
  CORS를 구성하여 버킷의 개체와 상호 작용하고 버킷의 정책을 구성합니다.
</Feature>

<Feature header="공공 버킷" href="/r2/buckets/public-buckets/">
  공중 물통은 당신의 R2 물통의 내용을 인터넷에 직접 노출합니다.
</Feature>

<Feature header="버켓 범위 토큰" href="/r2/api/tokens/">
  데이터에 액세스 할 수있는 과립 제어를위한 버킷 범위 토큰을 만듭니다.
</Feature>

이 페이지는 암호화 거래 (EAR), 암호화 거래 (EIT) 및 CloudflareQ의 준수 인증을 포함하여 R2XQXQ의 데이터 보안 속성을 상세히 설명합니다.

## 복원

모든 개체는 R2에 저장, 자신의 메타 데이터를 포함, 나머지에서 암호화됩니다. 암호화 및 해독은 자동이며 사용자 구성이 필요하지 않으며 R2의 유효 성능에 영향을 미치지 않습니다.

암호화 키는 Cloudflare에 의해 관리되며 CloudflareXQXQ 내부에서 암호화 된 데이터를 관리하는 데 사용됩니다.

Objects는 암호화되어 있습니다.[사이트맵](https://www.cloudflare.com/learning/ssl/what-is-encryption/), 넓게 시험해, 높게 performant와 기업 표준 암호화 알고리즘. R2는 그것의 선호한 형태로 GCM (Galois/Counter 형태)를 이용합니다.

## Transit의 암호화

클라이언트와 R2 사이의 데이터 전송은 동일하게 보호됩니다[수송 층 안전](https://www.cloudflare.com/learning/ssl/transport-layer-security-tls/)모든 Cloudflare 도메인에 지원되는 TLS/SSL.

일반 텍스트 HTTP에 액세스 (TLS / SSL없이) 연결하여 비활성화 할 수 있습니다[사용자 정의 도메인](/r2/buckets/public-buckets/#custom-domains)R2 버킷에[항상 HTTPS 사용](/ssl/edge-certificates/additional-options/always-use-https/).

:::참조

R2 사용자 정의 도메인 사용 Cloudflare SaaS 인증서 및 사용자 정의 할 수 없습니다. 당신이 가지고 있다면[고급 인증서 관리자](/ssl/edge-certificates/advanced-certificate-manager/), 진보된 증명서는 때문에 사용될 것입니다[증명서 우선권](/ssl/reference/certificate-and-hostname-priority/).

:::

## 견적 요청

Cloudflare의 업계 표준 보안 준수 인증에 대한 준수에 대한 자세한 내용은 CloudflareXQ[신뢰 허브](https://www.cloudflare.com/trust-hub/compliance-resources/).

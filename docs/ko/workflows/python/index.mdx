주요 특징

## 시작하기

Python 워크플로우의 주요 항목점은[`WorkflowEntrypoint`](/workflows/build/workers-api/#workflowentrypoint)수업. 작업 흐름 논리는 내부에 있어야 합니다.[`run`](/workflows/build/workers-api/#run)핸들러.

```python
from workers import WorkflowEntrypoint

class MyWorkflow(WorkflowEntrypoint):
    async def run(self, event, step):
        #여기에
```

예를 들어, Workflow는 다음과 같이 정의될 수 있습니다.

```python
from workers import Response, WorkflowEntrypoint, WorkerEntrypoint

class PythonWorkflowStarter(WorkflowEntrypoint):
    async def run(self, event, step):

        @step.do('step1')
        async def step_1():
            #기타 제품
            print('executing step1')

        @step.do('step2')
        async def step_2():
            #기타 제품
            print('executing step2')

        await step_1()
        await step_2()

class Default(WorkerEntrypoint):
    async def fetch(self, request):
        await self.env.MY_WORKFLOW.create()
        return Response("Hello world!")
```

모두 추가해야 합니다.`python_workflows`·`python_workers`compatibility flags를 Wrangler 설정 파일에 입력하십시오.

<WranglerConfig>
  ```jsonc
  {
  	"$schema": "./node_modules/wrangler/config-schema.json",
  	"name": "hello-python",
  	"main": "src/entry.py",
  	"compatibility_flags": [
  		"python_workers",
  		"python_workflows"
  	],
  	"compatibility_date": "$today",
  	"workflows": [
  		{
  			"name": "workflows-demo",
  			"binding": "MY_WORKFLOW",
  			"class_name": "PythonWorkflowStarter"
  		}
  	]
  }
  ```
</WranglerConfig>

Python를 실행하려면 로컬 작업 흐름, 사용[Wrangler](/workers/wrangler/)Cloudflare Workers를 위한 클립:

```bash
npx wrangler@latest dev
```

Python Cloudflare에 워크 플로우, 실행[`wrangler deploy`](/workers/wrangler/commands/#deploy):

```bash
npx wrangler@latest deploy
```

Workflows는 무료 및 유료 모두에 포함되어 있습니다[Workers 계획](/workers/platform/pricing/#workers).

:::

Workflows 가격과 동일[Workers 표준 가격](/workers/platform/pricing/#workers)그리고 3 차원에 청구됩니다:

- **CPU 시간**: 주어진 작업 흐름에 의해 소모된 (밀리초로 측정)의 총량.
- **제품정보**(직업): Workflow invocations의 수.[구독하기](/workers/platform/limits/#subrequests)Workflow에서 추가 요청 비용이 발생하지 않습니다.
- **제품 정보**: Workflows에 의해 지속되는 저장 (GB에서 측정되는)의 총계.

API 호출에 대한 응답을 기다리고있는 작업 흐름, 호출의 결과로 일시`step.sleep`, 또는 그렇지 않으면 idle는 CPU 시간을 incur하지 않습니다.

### Workflows 가격

| 제품정보        | Workers 무료                                                       | Workers 계정 만들기                                    |
| ----------- | ---------------------------------------------------------------- | ------------------------------------------------- |
| 요청 (방사)     | 일 당 100,000 ([Workers 요청 공유](/workers/platform/pricing/#workers) | 달 당 10 백만 + 추가 백만 당 $ 0.30                        |
| CPU 시간 (ms) | 직업 당 CPU 시간의 10 milliseconds                                     | 한 달에 포함 된 30 백만 CPU 밀리 초 + 추가 백만 CPU 밀리 초 당 $0.02 |
| 저장 (GB-mo)  | 1기가바이트                                                           | 1GB는 달 당 + $0.20/GB 달 포함했습니다                      |

:::노트\[CPU 한계]

워크 플로우 당 최대 5 분의 워크 플로우에 사용할 수있는 CPU 한계를 증가 할 수 있습니다.[설정하기`limits.cpu_ms`이름 \*](/workers/wrangler/configuration/#limits)당신의 Wrangler 윤곽에서.

:::

### 공급 능력

:::참조

Workflows를 위한 저장 청구는 9월 15일에, 2025에 생길 것입니다.

:::

저장은 청구 미터로 gigabyte-month (GB-month)를 사용하여 청구됩니다.[Durable Objects SQL 저장](/durable-objects/platform/pricing/#sqlite-storage-backend). GB-month는 청구 기간 (30 일)에 일 당 첨단 저장을 평균화해서 산출됩니다.

- 저장은 모든 인스턴스에 걸쳐 계산되며, 실행, 오류, 수면 및 완료된 인스턴스를 포함합니다.
- 기본적으로 인스턴스 상태는 유지됩니다.[무료 플랜 3 일](/workflows/reference/limits/)·[유료 플랜 7 일](/workflows/reference/limits/).
- 워크 플로우 인스턴스를 만들 때 오류 또는 완료된 Workflows에 대한 상태를 유지하지 않으면 더 짧은 상태 유지 기간을 설정할 수 있습니다.
- 삭제된 인스턴스를 통해[모델 번호: Workers](/workflows/build/workers-api/), [Wrangler 클립](/workers/wrangler/commands/#workflows), REST API, 또는 dashboard는 저장을 해방할 것입니다. 저장 제한을 몇 분으로 업데이트 할 수 있습니다.

무료 플랜의 저장 제한에 도달했을 때 상태를 저장하려고 하는 경우 오류가 발생 합니다.

## 자주 묻는 질문

자주 묻는 질문 Workflows 가격:

### Workflows에 대한 추가 비용이 있습니까?

No. Workflows는 Workers로 동일한 compute (CPU 시간), 요구 (invocations), 뿐 아니라 저장 (Workflow에서 국가)에 근거를 둔 가격 입니다.

### Workflows는 유효합니다[Workers 무료 다운로드](/workers/platform/pricing/#workers)계획?

예.

### Workflow invocation이란 무엇입니까?

Workflow invocation는 새로운 Workflow 인스턴스를 트리거 할 때입니다. 예를 들어,[Workers API를](/workflows/build/workers-api/), wrangler CLI, 또는 REST API. 작업 흐름 내에서 단계는 직업이 없습니다.

### Workflows는 어떻게 나의 청구서에 보여줍니다?

Workflows는 Workers로 청구되며 동일한 CPU 시간 및 요청 SKU를 공유합니다.

### Workflows에 제한이 있습니까?

출판물[제한 사항](/workflows/reference/limits/)문서.

이 예제는 사용 방법을 설명합니다.`waitForEvent()`Cloudflare QXWorkflows에 있는 API는 인간에서 반복 단계 소개하기 위하여. 워크 플로우는 이미지 업로드에 의해 트리거됩니다, 어느 메타 데이터가 D1 데이터베이스에 저장되는 동안. 워크 플로우는 사용자 승인을 기다리고 있으며 승인시 Workers AI를 사용하여 데이터베이스에 저장되는 이미지 태그를 생성합니다. Next.js 프론트엔드 애플리케이션은 이미지 업로드 및 승인 프로세스를 용이하게 합니다.

## Workflow의 개요

이 워크 플로우에서 업로드 된 이미지가 AI 기반 처리 전에 인간의 승인을 필요로하는 시나리오를 시뮬레이션합니다. 이미지는 R2에 업로드되며 Workflow는 다음 단계를 수행합니다.

1. D1 데이터베이스의 이미지 메타 데이터를 저장합니다.
2. Pauses 실행`waitForEvent()`Next.js frontend에서 보낸 외부 이벤트에 대한 대기, 승인 또는 거부를 나타내는.
3. 승인되면 Workflow는 Workers AI를 사용하여 이미지 태그를 생성하고 D1 데이터베이스에서 태그를 저장합니다.
4. 거부되면 Workflow가 더 동작하지 않고 종료됩니다.

이 패턴은 특정 작업이 명시되지 않고 진행되지 않는 시나리오에서 유용합니다.

## Frontend 통합

이 예제에는 이미지 업로드 및 승인 프로세스를 용이하게하는 Next.js frontend 애플리케이션이 포함되어 있습니다. frontend는 이미지 업로드를 위한 인터페이스를 제공하고, 그(것)들을 검토하고, 개선하거나 거절합니다. 이미지 업로드시, 응용 프로그램은 Cloudflare Workflow를 트리거하여 사용자가 승인 및 승인에 따라 AI 기반 이미지 태그를 수행하는 등 후속 단계를 관리합니다.

더 알아보기`/nextjs-workflow-frontend`폴더에[GitHub 저장소](https://github.com/cloudflare/docs-examples/tree/main/workflows/waitForEvent)완전한 frontend 구현 및 배포 세부 사항.

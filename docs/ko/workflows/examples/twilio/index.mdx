다음을 사용하여[관련 기사](https://github.com/craigsdennis/twilio-cloudflare-workflow), Twilio와 Cloudflare WorkflowsXQ를 통합하는 방법을 배우십시오, 개발자가 APIs를 통해 메시징, 음성, 비디오 및 인증 기능을 통합하는 가능하게 하는 대중적인 클라우드 커뮤니케이션 플랫폼. 비디오 자습서의 끝으로, 당신은 Cloudflare WorkflowsXQXQ를 설정하는 과정에서 익숙해져 Twilio의 API와 원활하게 상호 작용하여 응용 프로그램에 직접 흥미로운 통신 기능을 구축 할 수 있습니다.

Cloudflare QXdashboardXQ의 다이어그램으로 파인 워크 플로 코드의 시각적 표현을 볼 수 있습니다.

다이어그램은 시퀀스 및 병렬 단계, 조건, 루프 및 배열 논리를 보여줍니다. 높은 수준의 작업 흐름을 볼 수 있도록, 루프와 조건으로 다이어그램을 볼 수, 또는 자세한보기를 확장.

![예제 다이어그램](~/assets/images/changelog/workflows/2026-02-03-workflows-diagram.png)

워크 플로우 다이어그램은 현재 모든 유형 및 Javascript Workers에 대한 베타입니다. Workflows를 확인하세요[Cloudflaredashboard](https://dash.cloudflare.com/?to=/:account/workers/workflows)도표를 볼 수 있습니다.

:::카트로션

이 기능은 현재 베타에 있습니다.

- Workflows는 비과태 번들러를 사용하는 것은 예상치 못한 행동을 표시할 수 있습니다.
- Python Workflows는 현재 지원되지 않습니다.

:::

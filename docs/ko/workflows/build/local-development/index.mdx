Workflows 지원 로컬 개발 사용[Wrangler](/workers/wrangler/install-and-update/), Workers를 위한 명령 선 공용영역. Wrangler는 Cloudflare가 전 세계적으로 실행되는 것과 비교된 WorkflowsXQXQ의 에뮬레이션 버전을 실행합니다.

## 자주 묻는 질문

WorkflowsXQ로 로컬로 개발하려면 다음이 필요합니다.

- [Wrangler의 v3.89.0](https://blog.cloudflare.com/wrangler3/)또는 나중에.

- Node.js 버전의`18.0.0`또는 나중에. Node 버전 관리자를 사용하여 고려하십시오.[볼트](https://volta.sh/)또는[사이트맵](https://github.com/nvm-sh/nvm)권한 문제를 방지하고 노드 버전을 변경합니다.

- Workflows 및 / 또는 Cloudflare QXWorkersXQ에 새로운 경우, 참조[Workflows - 연혁](/workflows/get-started/guide/)설치하기`wrangler`첫 번째 Workflows를 배포합니다.

## 현지 개발 세션 시작

터미널을 열고 다음 명령을 실행하여 로컬 개발 세션을 시작합니다.

```sh
#우리가 wrangler v3.89.0 +를 사용 하 여 확인
npx wrangler --version
```

```sh output
⛅️ wrangler 3.89.0
```

로컬 dev 세션 시작

```sh
#로컬 dev 세션 시작:
npx wrangler dev
```

```sh output
------------------
Your worker has access to the following bindings:
- Workflows:
  - MY_WORKFLOW: MyWorkflow
⎔ Starting local server...
[wrangler:inf] Ready on http://127.0.0.1:8787/
```

로컬 개발 세션은 생산 환경 Workflows를 미러링하는 독립, 로컬 전용 환경을 만들기 때문에 WorkflowsXQ를 테스트 할 수 있습니다*이전 다음*당신은 생산에 배치합니다.

더 알아보기[`wrangler dev`관련 기사](/workers/wrangler/commands/#dev)로컬 개발 세션을 구성하는 방법에 대해 자세히 알아보세요.

## Known 문제

Workflows는 지원되지 않습니다[먼 바인딩](/workers/development-testing/#remote-bindings)또는 사용시`npx wrangler dev --remote`.

Wrangler Workflows 명령`npx wrangler workflow [cmd]`로컬 개발을 지원하지 않습니다, 그들은 대상 생산 API. 방법 에`pause()`, `resume()`, `terminate()`·`restart()`아직 현지 개발에서 구현되지 않았습니다.

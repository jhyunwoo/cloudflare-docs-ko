[^1]: 로그인 / 고객 Metadata Boundary를 사용할 때 미국 지역 밖에서는 안됩니다.

[^3]: [Adaptive DDoS 차단](/ddos-protection/managed-rulesets/adaptive-protection/)CMB = 미국에서만 지원됩니다. 다른 모든 기능은 모든 CMB 지구에 유효합니다.

[^4]: API Discovery, 부피 측정 분석 및[Sequence Analytics 및 소송](/api-shield/security/sequence-analytics/)CMB = EU로 작동하지 않습니다. 다른 모든 기능은 모든 CMB 지구에 유효합니다.

[^6]: Workers 또는[Transform 규칙](/images/transform-images/serve-images-custom-paths/)같은 영역 안에.

[^7]: [Durable Objects에 대한 관할 제한](/durable-objects/reference/data-location/#restrict-durable-objects-to-a-jurisdiction).

[^8]: 만 사용할 때[주문 영역](/r2/buckets/public-buckets/#connect-a-bucket-to-a-custom-domain)지역 및 사용 설정[S3 API의 관할권](/r2/reference/data-location/#using-jurisdictions-with-the-s3-api).

[^9]: Argo는 지역 서비스에서 사용할 수 없습니다.

[^10]: Argo는 고객 Metadata Boundary와 함께 사용할 수 없습니다.

[^11]: 사용시[주문 영역](/pages/configuration/custom-domains/)지역으로 설정.

[^12]: CMB = US를 사용할 때 Logpull을 사용할 수 있습니다. Logpull은 레거시 기능입니다.[다운로드](/data-localization/metadata-boundary/logpush-datasets/)또는[로그 탐색](/log-explorer/)대신.

[^13]: 고객 Metadata Boundary에서 사용할 수 있는 Logpush[이 datasets](/data-localization/metadata-boundary/logpush-datasets/). 다른 dataset를 필요로 하는 경우에 당신의 계정 팀에 연락하십시오.

[^14]: 액세스 앱 SSL 키는 Geo Key Manager를 사용할 수 있습니다.[액세스 JWT](/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/validating-json/)아직 현지화되지 않았습니다.

[^15]: 미국 FedRAMP 모더레이트 국내 지역에서만 현지화될 수 있습니다.

[^16]: Metadata Boundary는 외부 지역에 데이터 전송을 제한하는 데 사용할 수 있지만 Access User Logs는 미국 이외의 지역에서 사용할 수 없습니다. EU 고객은 Logpush를 사용하여 로그를 유지해야합니다.

[^17]: 현재 미국 FedRAMP 지역에서만 사용할 수 있습니다.

[^18]: Cloudflare 터널이 Cloudflare에 연결되면 연결 옵션은 Global Region(기본값)이며[미국 FedRAMP 모뎀 국내 지역](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/run-parameters/#region). Cloudflare Edge에 들어오는 요청을 위해, 지역 서비스는 사용시에만 적용됩니다.[관련 앱](/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/). 이 경우, DNS 레코드와 관련된 영역이 적용됩니다.

[^19]: Gateway HTTP 및 CASB를 사용합니다.

[^20]: 당신은 할 수[자신의 인증서를 가져옵니다](https://blog.cloudflare.com/bring-your-certificates-cloudflare-gateway/)Gateway 하지만 이러한 특정 지역에 제한할 수 없습니다.

[^21]: Gateway HTTP는 지역 서비스를 지원합니다. Gateway DNS는 아직 지역화를 지원하지 않습니다.<br />ICMP 프록시 및 WARP-to-WARP 프록시는 지역 서비스 사용자에게 제공되지 않습니다.[파일 Sandboxing](/cloudflare-one/traffic-policies/http-policies/file-sandboxing/)(add-on)는 DLS와 호환이 됩니다.

[^22]: Dashboard Analytics 및 Logs는 미국 전역의 CMB를 사용할 때 비어 있습니다. 대신 Logpush를 사용하십시오.

[^23]: 현재 고객은 Cloudflare 관리 R2 버킷의 위치를 선택할 수 없습니다.

[^26]: 정체되는 IP/BYOIP는 유산 스펙트럼 설정과 함께 사용될 수 있습니다.

[^27]: Custom Domain 및 a를 사용할 때만[주문 증명서](/r2/reference/data-security/#encryption-in-transit)또는[열쇠가 없는 SSL](/ssl/keyless-ssl/).

[^28]: R2 대시보드[미터 및 분석](/r2/platform/metrics-analytics/)관련 상품[관할 구역](/r2/reference/data-location/#jurisdictional-restrictions)버킷의 개체를 특정 관할 내에서 저장합니다.

[^31]: DLP는 Gateway HTTP의 일부이지만,[DLP 검출 항목](/cloudflare-one/data-loss-prevention/detection-entries/)고객 Metadata Boundary를 사용할 때 미국 지역에서 사용할 수 없습니다.

[^32]: Dashboard Analytics는 미국 지역 이외의 CMB를 사용할 때 비어 있습니다. 대신 Logpush를 사용하십시오.

[^44]: Workers 루트 및 도메인 및 사용자 지정 인증서를 사용할 때만.

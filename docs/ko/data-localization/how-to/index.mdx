## Verify 지역 서비스 행동

지역 서비스가 일하고 있는지 확인하려면 다음 중 하나를 실행하여 행동을 확인할 수 있습니다.`curl`지역화된 호스트명의 명령:

```bash
curl -X GET -I https://<HOSTNAME>/ 2>&1 | grep cf-ray
```

```bash
curl -s https://<HOSTNAME>/cdn-cgi/trace | grep "colo="
```

첫 번째 명령은 세 개의 터미널 IATA 코드를 반환합니다.[Cf 레이](/fundamentals/reference/http-headers/#cf-ray)처리 및/또는 TLS 종료의 Cloudflare 데이터 센터 위치를 나타내는 헤더. 두 번째 명령은 직접 세 개의 터미널 IATA 코드를 반환합니다.

예를 들어, 호스트 이름은 유럽 연합 (EU)을 사용하는 구성 될 때, 세 개의 터미널 IATA 코드는 항상 EU 내부의 데이터 센터를 반환합니다.

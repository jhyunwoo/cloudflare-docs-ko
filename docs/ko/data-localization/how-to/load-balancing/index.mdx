다음 섹션에서는 지역 서비스 및 고객 Metadata Boundary로 Load Balancing을 구성하는 방법에 대한 세부 정보를 제공합니다.

## 지역 서비스

네트워크 스택의 다른 수준에서 균형 트래픽을로드 할 수 있습니다.[프록시 모드](/load-balancing/understand-basics/proxy-modes/): 층 7 (`HTTP/S`)와 층 4 (`TCP`)는 지원됩니다; 그러나,`DNS-only`지원되지 않습니다.[뚱 베어](/dns/proxy-status/).

hostname에 대한 Regional Services 구성[뚱 베어](/dns/proxy-status/)Cloudflare를 통해 Load Balancer가 사용할 수 있도록 대시보드 또는 API 구성에 대한 이러한 단계를 따르십시오.

## 고객 메타데이터 경계

[Load Balancing 분석](/load-balancing/reference/load-balancing-analytics/)고객 Metadata Boundary를 사용할 때 미국 지역에서 사용할 수 없습니다.

고객 메타데이터 경계 설정`EU`, **교통안내** > **Load Balancing 분석** > **영업 및 지원**Zone 대시보드의 탭은 팝업되지 않습니다.

더 알아보기[관련 문서](/load-balancing/)더 많은 정보.

다음 섹션에서, 우리는 당신에게 다른 Zero Trust 제품에 대한 몇 가지 세부 사항을 제공 할 것입니다 Data Localization Suite.

## 오시는 길

지역 서비스는 모든 Gateway와 함께 사용할 수 있습니다.[지원 영역](/data-localization/region-support/). 교통 및 DNS 모드에서 WARP 클라이언트를 사용할 때 지역 서비스만 적용할 수 있습니다.

### Egress 정책

기업 고객은 구매할 수 있습니다[전용 egress IP](/cloudflare-one/traffic-policies/egress-policies/dedicated-egress-ips/)(IPv4 및 IPv6) 또는 IP의 범위는 하나 이상의 Cloudflare 네트워크 위치에 위치합니다.
이것은 당신의 egress 트래픽을 당신의 도시에 게 선택[egress 정책](/cloudflare-one/traffic-policies/egress-policies/).

### HTTP 정책

지역 서비스의 일부로서 Cloudflare Gateway만 수행[TLS 해독](/cloudflare-one/traffic-policies/http-policies/tls-decryption/)사용시[WARP 클라이언트](/cloudflare-one/team-and-resources/devices/warp/)(기본값에서[교통 및 DNS 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/)).

#### 데이터 손실 방지 (DLP)

당신은 할 수 있습니다[일치하는 DLP 규칙의 페이로드를 로그](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/#log-the-payload-of-matched-rules)그리고 공개 키로 암호화하여 나중에 검사할 수 있습니다.

[Cloudflare는 암호화된 페이로드를 해독할 수 없습니다](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/#data-privacy).

### 네트워크 정책

당신은 할 수 있습니다[SSH 프록시 및 명령 로그 구성](/cloudflare-one/traffic-policies/network-policies/ssh-logging/). Hybrid Public Key Encryption (HPKE) 키 페어 생성 및 공개 키 업로드`sshkey.pub`대시보드에. 모든 proxied SSH 명령은 즉시이 공개 키를 사용하여 암호화됩니다. 일치하는 개인 키 – 귀하의 소유물에 – 로그를 볼 필요가있다.

### DNS 정책

Cloudflare가 트래픽을 해독하는 지역 서비스 제어; 대부분의 DNS 트래픽이 암호화되지 않기 때문에 게이트웨이 DNS는 지역 서비스로 지역화 될 수 없습니다.

더 알아보기[사이트맵 계정 설정](/data-localization/how-to/zero-trust/#warp-settings)더 많은 정보를 위한 단면도.

### 주문 증명서

당신은 할 수[자신의 인증서를 가져옵니다](/cloudflare-one/team-and-resources/devices/user-side-certificates/custom-certificate/)Gateway 하지만 이러한 특정 지역에 제한할 수 없습니다.

### 로그 및 분석

기본적으로 Cloudflare는 글로벌 네트워크의 데이터 센터에서 로그를 저장하고 전달합니다. 데이터에 대한 지역 통제를 유지하기 위해, 당신은 사용할 수 있습니다[고객 메타데이터 경계](/data-localization/metadata-boundary/)특정 지리적 지역에 데이터 저장을 제한합니다. 자세한 내용은 섹션을 참조[Logpush 데이터 세트 지원](/data-localization/metadata-boundary/logpush-datasets/).

고객은 Cloudflare 상점의 로그를 줄이기위한 옵션이 있습니다.

- 당신은 할 수[로그에서 PII 제외](/cloudflare-one/insights/logs/gateway-logs/manage-pii/)
- 당신은 할 수[로그인 또는 로그인 차단된 요청](/cloudflare-one/insights/logs/gateway-logs/#selective-logging).

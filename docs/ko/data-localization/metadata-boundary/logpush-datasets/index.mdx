아래 표[Logpush 데이터 세트](/logs/logpush/logpush-job/datasets/)지원 영역 또는 고객 Metadata Boundary (CMB)와 계정. 열의**CMB를 존중**CMB가 dataset (yes/no)에 영향을 미치는지 나타냅니다. 마지막 두 열은 CMB가 미국과 EU와 함께 사용할 수 있는지 알려줍니다.

CMB를 지원하지 않는 데이터 세트에 사용할 수 있다면, 데이터가 귀하의 목적지에 밀어되지 않습니다.

로그인 및 분석이 API 또는 대시보드를 통해 저장되는 지역을 선택하기 위해 Metadata Boundary를 구성할 수 있습니다.

현재 계정 수준에서만 적용할 수 있습니다. Metadata Boundary를 원한다면 동일한 계정 아래에 영역의 부분에 적용 할 수 있습니다.[새로운 계정에 영역의 나머지를 이동](/fundamentals/manage-domains/move-domain/).

## 대시보드의 고객 메타데이터 경계 구성

대시보드에서 고객 메타데이터 경계를 구성하려면:

1. Cloudflare 대시보드에서**계정 설정**사이트 맵

   <DashButton url="/?to=/:account/configurations" />

2. 내 계정**고객 메타데이터 경계**, 사용하려는 지역을 선택하십시오. 선택할 수있는 옵션이 있습니다.`EU`또는`US`. 두 지역을 선택하려는 경우, 선택`Global`대신.

## API를 통해 고객 메타데이터 경계 구성

API를 통해 고객 메타데이터 경계를 구성할 수 있습니다.

현재 SuperAdmins 및 Admin 역할만 DLS 구성을 편집할 수 있습니다. 사용 방법**계정 레벨 로그:Read/Write**API 권한`/logs/control/cmb`endpoint to read/write 고객 메타데이터 경계 구성.

API 요청의 예입니다.

<Details header="현재 지역">
  현재 지역을 얻는 cURL를 사용하여 예 요청은 다음과 같습니다.

  <APIRequest path="/accounts/{account_id}/logs/control/cmb/config" method="GET" />
</Details>

<Details header="지역 설정">
  다음은 CURL을 사용하여 지역 설정 예입니다.

  <APIRequest
    path="/accounts/{account_id}/logs/control/cmb/config"
    method="POST"
    json={{
  regions: "eu",
  allow_out_of_region_access: false
}}
  />

  이것은 이전 지역을 덮을 것입니다.
  변화는 몇 분 후에 효력에서 일 것입니다.
</Details>

<Details header="사이트 맵">
  다음은 cURL을 사용하여 지역 삭제를 요청하는 예입니다.

  <APIRequest path="/accounts/{account_id}/logs/control/cmb/config" method="DELETE" />
</Details>

## 표시 또는 변경 설정

고객 Metadata Boundary 설정을 보거나 변경하려면:

1. Cloudflare 대시보드에서**계정 설정**사이트 맵

   <DashButton url="/?to=/:account/configurations" />

2. 오시는 길**P참고 자료s의 특징**.

3. 자주 묻는 질문**고객 메타데이터 경계**이름 \*

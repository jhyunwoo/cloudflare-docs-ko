## 고객 Metadata Boundary에 대한 데이터는 무엇입니까?

거의 모든 최종 사용자 메타데이터는 고객 메타데이터 경계에 의해 커버됩니다. Cloudflare는 모든 최종 사용자 데이터가 프로세서이며, 정의된[Cloudflare 개인 정보 정책](https://www.cloudflare.com/privacypolicy/). Cloudflare는 대시보드 또는 기타 온라인 인터페이스를 통해 고객에게 사용할 수있는 최종 사용자 로그로 정의 된 고객 로그의 데이터 프로세서입니다. 최종 사용자는 고객의 도메인, 네트워크, 웹 사이트, 응용 프로그램 인터페이스 및 응용 프로그램을 액세스하거나 사용하는 사람들입니다.

이 데이터의 특정 예에는 대시보드 및 API의 모든 분석과 관련된 요청, 응답 및 보안 제품 및 Logpush를 통해 수신 된 로그의 모든 포함.

## 고객 Metadata Boundary에 의해 어떤 자료가 포함되지 않습니까?

Cloudflare가 컨트롤러로 정의된 데이터의 일부[Cloudflare 개인 정보 정책](https://www.cloudflare.com/privacypolicy/).

몇몇 예:

- 고객 계정 데이터 (예, 이름 및 청구 정보).
- 고객 구성 데이터 (예 : WAF 사용자 정의 규칙의 내용).
- 자연의 "operational" 인 Metadata - Cloudflare에 필요한 데이터는 제대로 네트워크 작동. 다음과 같은 메타데이터를 포함합니다:
  - 디버깅을 위해 생성 된 시스템 데이터 (예 : 내부 시스템, 핵심 덤프에서 애플리케이션 로그).
  - 네트워킹 흐름 데이터 (예를 들면, 우리의 라우터에서 sFlow), DDoS 공격에 대한 데이터를 포함.

## 고객은 Metadata Boundary를 사용할 수 있습니까?

현재 Data Localization Suite의 일부로 엔터프라이즈 고객을 위해 사용할 수 있습니다.

고객 Metadata Boundary는 EU 또는 미국 이외의 개인 데이터 전송을 제한하려는 고객을위한 것입니다 (고객의 선택 지역에 따라). 이 고객은 이미 지역 서비스를 사용해야합니다. 트래픽 콘텐츠가 고객에 의해 지정 된 지리적 영역 내에서만 해독된다는 것을 보장합니다.

## Metadata Boundary에 사용할 수있는 분석 제품은 무엇입니까?

HTTP 및 방화벽 분석이 가능합니다.

현재 Workers, DNS 및 Load Balancing에 대한 분석이 없습니다. 또한 대시보드 로그 또는 분석이 없습니다.[오시는 길](/cloudflare-one/insights/logs/gateway-logs/#limitations). 기업 사용자는 아직도 Gateway logs를 통해 수출할 수 있습니다[다운로드](/cloudflare-one/insights/logs/logpush/).

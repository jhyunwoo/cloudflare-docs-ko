Metadata Boundary에 대한 기본 구성으로 구성 영역 외부 사용자는 대시보드 또는 기본 API 엔드포인트에 대한 분석을 볼 수 없습니다. 시간 :**아웃-of-region 액세스 허용**고객 로그는 여전히 구성 영역 내에서만 저장되지만 지역 이외의 사용자에게도 사용할 수 있습니다.

예를 들어, 언제**아웃-of-region 액세스 허용**이름 \***이름 \***&#xBBF8;국 고객 메타데이터 경계를 위해 구성된 계정에서 유럽 사용자들은 대시보드에서 모든 분석 또는 고객 로그를 볼 수 없습니다.

시간 :**아웃-of-region 액세스 허용**미국 고객 Metadata Boundary를 위해 구성 된 계정에 활성화되어 유럽과 미국의 사용자는 대시보드에 분석 할 수 있지만 고객 로그는 미국에만 저장됩니다.

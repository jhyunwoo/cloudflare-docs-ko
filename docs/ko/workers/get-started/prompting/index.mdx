Cursor, Windsurf, VS Code, Claude Code, Codex 및 OpenCode를 포함한 좋아하는 에이전트 또는 편집기에서 WorkersXQ 응용 프로그램을 만들 수 있습니다.

## Workers

연결하기[`cloudflare-docs`](https://github.com/cloudflare/mcp-server-cloudflare/tree/main/apps/docs-vectorize)MCP (모델 컨텍스트 프로토콜) 서버는 Workers에 대한 에이전트를 가르치기 위해. 서버 URL 추가`https://docs.mcp.cloudflare.com/mcp`당신의 대리인 윤곽에 ([더 알아보기](/agents/model-context-protocol/mcp-servers-for-cloudflare/)).

또한 연결할 수 있습니다[`cloudflare-observability`](https://github.com/cloudflare/mcp-server-cloudflare/tree/main/apps/workers-observability)MCP 서버 (`https://observability.mcp.cloudflare.com/mcp`). 이것은 에이전트 확인 로그, 예외를 찾고, 자동으로 문제를 해결.

## 예제 프롬프트

```txt
Create a Cloudflare Workers application that serves as a backend API server.
```

```txt
Show me how to use Hyperdrive to connect my Worker to an existing Postgres database.
```

```txt
Create an AI chat Agent using the Cloudflare Agents SDK that responds to user messages and maintains conversation history.
```

```txt
Build a WebSocket-based pub/sub application using Durable Objects Hibernation APIs, where the server allows me to POST to /send-message with {topic: "foo", message: "bar"} and delivers that message to any connected client listening to that topic.
```

```txt
Build an image upload application using R2 pre-signed URLs that allows users to securely upload images directly to object storage without exposing bucket credentials.
```

## 빠른 사용

Workers API 및 모범 사례에 대한 컨텍스트와 AI 도구를 제공하기 위해 아래의 기본 프롬프트를 사용할 수 있습니다.

1. 클립보드에 전체 프롬프트를 복사하기 위해 아래의 코드 블록의 오른쪽 상단에서 클릭 투 복사 버튼을 사용하십시오.
2. 선택의 AI 도구로 붙여넣기 (예를 들어 OpenAI의 ChatGPT 또는 Anthropic의 Claude).
3. 끝에서 프롬프트의 일부를 입력`<user_prompt>`·`</user_prompt>`태그.

위의 프롬프트는 다음과 같은 몇 가지 모범 사례를 채택한다.

- 사용 방법`<xml>`태그를 구조로

- 구성을 생성하는 방법에 대한 설명 (예를 들어,`wrangler.jsonc`) 모형의 응답의 부분으로
- Cloudflare 제품의 추천은 특정 저장 또는 국가 필요를 위해 사용

### 추가 용도

당신은 몇 가지 방법으로 신속한 사용할 수 있습니다:

- 사용자 컨텍스트 윈도우 내에서, 사용자의 프롬프트 삽입`<user_prompt>`태그 (**뚱 베어**)
- 이름 \*`system`시스템 프롬프트를 지원하는 모델
- 선호하는 IDE에서 신속한 라이브러리 또는 파일 컨텍스트에 추가:
  - Cursor: 신속한 추가[프로젝트 규칙](https://docs.cursor.com/context/rules-for-ai)
  - Zed: 사용[이름 \*`/file`이름 \*](https://zed.dev/docs/assistant/assistant-panel)Assistant context에 신속한 추가
  - Windsurf: 사용[이름 \*`@-mention`이름 \*](https://docs.codeium.com/chat/overview)채팅에 신속한 파일을 포함
  - Claude Code: 당신의 것에 신속한 추가`CLAUDE.md`실행 후 설정`/init`Workers 프로젝트에 대한 모범 사례 포함
  - GitHub Copilot: 생성[`.github/copilot-instructions.md`](https://docs.github.com/en/copilot/customizing-copilot/adding-repository-custom-instructions-for-github-copilot)프로젝트의 루트에 파일을 추가하고 신속한 추가

:::참조

여기에 프롬프트는 예이며 특정 사용 사례에 적응해야합니다.

모델 및 사용자 프롬프트에 따라 잘못된 코드, 구성 또는 기타 오류를 생성 할 수 있습니다. 배포하기 전에 생성 된 코드를 검토하고 테스트합니다.

:::

## 편집에서 docs 사용

Cursor 및 Windsurf를 포함한 AI-enabled 편집기는 문서를 색인할 수 있습니다. Cursor는 기본적으로 Cloudflare 개발자 Docs를 포함합니다: 당신은 사용할 수 있습니다[`@Docs`](https://cursor.com/docs/context/mentions#docs)명령.

Zed 또는 Windsurf와 같은 다른 편집기에서 URL에 붙여넣을 수 있습니다. 사용 방법*본문 바로가기*Cloudflare docs에 직접 붙여넣기 위하여 단추, 또는 appending에 의하여 각 제품을 위한 fetch docs`llms-full.txt`루트 URL에. 예를 들어,`https://developers.cloudflare.com/agents/llms-full.txt`또는`https://developers.cloudflare.com/workflows/llms-full.txt`.

이 페이지에 Workers 시스템 프롬프트를 사용하여 편집기 또는 에이전트의 Workers API의 이해를 개선할 수 있습니다.

## 관련 자료

AI 모델 및 도구에서 가장 많은 것을 얻으려면 신속한 엔지니어링 및 구조에 다음 가이드를 검토하십시오.

- 오픈AI[신속한 엔지니어링](https://platform.openai.com/docs/guides/prompt-engineering)가이드 및[좋은 관행](https://platform.openai.com/docs/guides/reasoning-best-practices)reasoning 모형을 사용하여.
- 더 보기[신속한 엔지니어링](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview)Anthropic의 가이드.
- 구글의[빠른 시작 가이드](https://services.google.com/fh/files/misc/gemini-for-google-workspace-prompting-guide-101.pdf)효과적인 신속한 쓰기.
- 메타의[문서 편집](https://www.llama.com/docs/how-to-guides/prompting/)Llama 모형 가족을 위해.
- GitHub의 가이드[신속한 엔지니어링](https://docs.github.com/en/copilot/using-github-copilot/copilot-chat/prompt-engineering-for-copilot-chat)Copilot 채팅을 사용할 때.

## 자주 묻는 질문

[Cloudflare 계정 만들기](/fundamentals/account/create-account/), 만약 당신이 이미 없습니다.

## 설치하기

get started에 새로운 Workers 신청:

1. Cloudflare dashboard에서,**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />

2. 제품정보**회사연혁**. 여기에서, 당신은 할 수 있습니다:
   - 프로듀서 템플릿의 갤러리에서 선택
   - 자신의 계정에 기존 Git 저장소 가져 오기
   - Cloudflare 클론 및 부츠 스트랩 Workers 응용 프로그램을 포함하는 공공 저장소를하자.

3. 선택한 후[Git 공급자](/workers/ci-cd/builds/git-integration/github-integration/), 프로젝트를 구성하고 선택**계정 만들기**.

4. Cloudflare는 새로운 빌드 및 배포를 시작합니다. 배포되면, 제공된 작업자 미리보기`workers.dev`하위 도메인.

## 계속 개발

응용 프로그램은 dashboard에서 시작되어 Git로 설정하여 개발 워크플로우를 돕습니다. 저장소에 계속 개발하려면, 실행할 수 있습니다:

```bash
#로컬 저장소 clone
git clone <git repo URL>

#root 디렉토리에 있는지 확인하십시오.
cd <directory>
```

지금, 당신은 미리보기 및 당신의 변경을 테스트 할 수 있습니다[로컬 개발 환경에서 Wrangler 실행](/workers/development-testing/). 일단 당신이 실행할 수 있는 배치 준비가:

```bash
#git tracking 파일 추가
git add .

#변경 사항
git commit -m "your message"

#Git 공급자의 변경을 밀어
git push origin main
```

더 많은 것을 하기:

- 우리의 의견[이름 \*](/workers/examples/)·[다운로드](/workers/tutorials/)감사합니다.
- 설치하기[관련 제품](/workers/runtime-apis/bindings/)작업자가 다른 리소스와 상호 작용하고 새로운 기능을 잠금 해제 할 수 있도록합니다.
- 자주 묻는 질문[테스트 및 디버그](/workers/testing/)당신의 Workers.
- 자세히보기[Workers 제한 및 가격](/workers/platform/).

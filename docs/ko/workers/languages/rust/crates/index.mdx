## 이름 \*

RustXQXQXQXQXQXQXQXQXQXQXQ에 대해 자세히 알아보기[`workers-rs`](https://github.com/cloudflare/workers-rs)(또는 일부 경우에만`wasm-bindgen`), WebAssembly에 있는 Workers를 쓰기 위하여.
각 Rust 크레이트 예제는 필요한 모든 사용자 정의 구성을 포함합니다.

이것은 소진 목록이 아닙니다, 많은 Rust 크레이트는 컴파일될 수 있습니다[`wasm32-unknown-unknown`](https://doc.rust-lang.org/rustc/platform-support/wasm64-unknown-unknown.html)Workers에 의해 지원되는 표적.
일부 경우에, 이것은 기본 기능을 비활성화하거나 Wasm-specific 기능을 활성화해야합니다. 새로운 의존성의 추가를 고려하는 것이 중요합니다. 이것은 크게 증가 할 수 있습니다.[제품 정보](/workers/platform/limits/#worker-size)당신의 노동자의.

## `time`

Wasm-friendly 만든 많은 크레이트, 사용`time`대신에 크레이트`std::time`. 를 위해`time`Wasm에서 일하기 위해,`wasm-bindgen`기능은 JavaScript에서 타이밍 정보를 얻을 수 있어야 합니다.

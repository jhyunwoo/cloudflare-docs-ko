## Fetch 핸들러

견적 요청[Python Workers에 소개](/workers/languages/python/)Python 노동자는 부호의 4개의 선으로 간단한 일 수 있습니다:

```python
from workers import WorkerEntrypoint, Response

class Default(WorkerEntrypoint):
    async def fetch(self, request):
        return Response("Hello World!")
```

다른 Workers와 유사한, Python 노동자를 위한 주요 입장 점은 입니다[`fetch`회사 소개](/workers/runtime-apis/handlers/fetch)어떤 핸들 수신 요청
노동자에게 보내.

Python Worker, 이 핸들러는`Default`클래스를 확장`WorkerEntrypoint`클래스 (당신은에서 가져올 수 있습니다)`workers`SDK 모듈).

## 더 보기`Request`제품 설명

더 보기`request`매개 변수에 전달`fetch`핸들러는 JavaScript 요청 객체, 노출 via[외국 기능 인터페이스 (FFI)](/workers/languages/python/ffi)·
Python 코드에서 직접 액세스 할 수 있습니다.

POST 요청을 수락하기 위해 worker를 편집하려고 합니다. 우리는에서 알고
[한국어`Request`](/workers/runtime-apis/request)우리가 호출 할 수있는
`await request.json()`이름 \*`async`요청 몸을 파는 기능
JSON입니다.

Python 노동자, 당신은 쓸 것이다:

```python
from workers import WorkerEntrypoint, Response
from hello import hello

class Default(WorkerEntrypoint):
    async def fetch(self, request):
        name = (await request.json()).name
        return Response(hello(name))
```

다른 많은 JavaScript APIs는 FFI를 통해 QXQX0408XQ QXQXWorkersXQ에서 유효합니다, 그래서 당신은 할 수 있습니다
비슷한 방법으로 다른 방법을 호출합니다.

편집하면`src/entry.py`, Wrangler는 자동적으로 국부적으로 재시작할 것입니다
개발 서버.

이제 적절한 몸과 POST 요청을 보낼 경우,
당신의 노동자는 개인화한 메시지로 응답할 것입니다.

```bash
curl --header "Content-Type: application/json" \
  --request POST \
  --data '{"name": "Python"}' http://localhost:8787
```

```bash output
Hello, Python!
```

## 더 보기`env`사이트 맵

더 보기`env`속성에`WorkerEntrypoint`접근에 사용될 수 있습니다
[환경 변수](/workers/configuration/environment-variables/),
[이름 \*](/workers/configuration/secrets/), 및
[관련 제품](/workers/runtime-apis/bindings/).

예를 들어, Python Worker에서 환경 변수를 설정하고 사용하도록 하십시오. 첫째, 작업자의 환경에 변수를 추가[Wrangler 구성 파일](/workers/wrangler/configuration/):

<WranglerConfig>
  ```jsonc
  {
  	"$schema": "./node_modules/wrangler/config-schema.json",
  	"name": "hello-python-worker",
  	"main": "src/entry.py",
  	"compatibility_flags": [
  		"python_workers"
  	],
  	"compatibility_date": "$today",
  	"vars": {
  		"API_HOST": "example.com"
  	}
  }
  ```
</WranglerConfig>

그런 다음 액세스 할 수 있습니다.`API_HOST`환경 변수를 통해`env`모수:

```python
from workers import WorkerEntrypoint, Response

class Default(WorkerEntrypoint):
    async def fetch(self, request):
        return Response(self.env.API_HOST)
```

## 모듈

Python 노동자는 다수 파일을 통하여 분할될 수 있습니다.

새로운 Python 파일을 만들려면`src/hello.py`:

```python
def hello(name):
    return "Hello, " + name + "!"
```

지금, 우리는 수정할 수 있습니다`src/entry.py`새 모듈의 사용을 만들기 위해.

```python
from hello import hello
from workers import WorkerEntrypoint, Response

class Default(WorkerEntrypoint):
    async def fetch(self, request):
        return Response(hello("World"))
```

편집하기`src/entry.py`, [`pywrangler`](/workers/languages/python/#the-pywrangler-cli-tool)변경을 자동으로 감지하고
당신의 노동자를 reload.

## 유형과 Autocompletion

Python QXWorkers를 개발할 때, 당신은 유형 힌트 및 autocompletion의 이점을 가지고 갈 수 있습니다
내 계정

그들을 활성화하려면, 설치`workers-runtime-sdk`당신의 상품`pyproject.toml`파일.

```toml
[dependency-groups]
dev = [
    "workers-py",
    "workers-runtime-sdk"
]
```

또한, Worker 구성에 따라 유형을 생성할 수 있습니다.`uv run pywrangler types`

이것은 compatibility date에 근거를 둔 Env 유형, 모듈 규칙 및 실행 시간 유형을 포함합니다
그리고 config 파일에 compatibility flags.

## 업그레이딩`pywrangler`

최신 버전으로 업그레이드하려면[`pywrangler`](/workers/languages/python/#the-pywrangler-cli-tool)글로벌, 다음 명령을 실행:

```bash
uv tool upgrade workers-py
```

최신 버전으로 업그레이드하려면`pywrangler`특정 프로젝트에서 다음 명령을 실행하십시오.

```bash
uv lock --upgrade-package workers-py
```

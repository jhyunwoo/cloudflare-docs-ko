## 제한된 기능이있는 모듈

- `decimal`: 소수 단위는 C ( decimal) 및 Python ( pydecimal) 구현을 가지고 있습니다.
  동일한 기능으로. C 구현 만 가능합니다 (WebAssembly로 컴파일 됨)
- `pydoc`: Python 내장 메시지는 사용할 수 없습니다
- `webbrowser`: 원래 webbrowser 모듈은 사용할 수 없습니다.

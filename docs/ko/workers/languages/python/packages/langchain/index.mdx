[랭체인](https://www.langchain.com/)큰 언어 모델 (LLMs)에 의해 구동되는 AI 응용 프로그램을 구축하기위한 가장 인기있는 프레임 워크입니다.

LangChain은 여러 Python 패키지를 출판합니다. 다음은 Workers 런타임에 의해 제공됩니다.

- [`langchain`](https://pypi.org/project/langchain/)(버전)`0.1.8`)
- [`langchain-core`](https://pypi.org/project/langchain-core/)(버전)`0.1.25`)
- [`langchain-openai`](https://pypi.org/project/langchain-openai/)(버전)`0.0.6`)

## 시작하기

외계인`cloudflare/python-workers-examples`저장소와 LangChain 예제를 실행:

```bash
git clone https://github.com/cloudflare/python-workers-examples
cd 05-langchain
uv run pywrangler dev
```

### 예제 코드

```python
from workers import WorkerEntrypoint, Response
from langchain_core.prompts import PromptTemplate
from langchain_openai import OpenAI

class Default(WorkerEntrypoint):
    async def fetch(self, request):
        prompt = PromptTemplate.from_template("Complete the following sentence: I am a {profession} and ")
        llm = OpenAI(api_key=self.env.API_KEY)
        chain = prompt | llm

        res = await chain.ainvoke({"profession": "electrician"})
        return Response(res.split(".")[0].strip())
```

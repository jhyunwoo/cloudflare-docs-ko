[채용정보](https://github.com/cloudflare/workers-py?tab=readme-ov-file#pywrangler)패키지 및 Python Workers를 관리하기위한 CLI 도구입니다.
당신의 패키지를 묶는 것을 포함하여 당신을 위한 가득 차있는 환경을 놓는 wrangler를 위한 래퍼로 의미됩니다
당신의 worker 번들을 배포합니다.

get started에, 다음 내용을 가진 pyproject.toml 파일을 만듭니다:

```toml
[project]
name = "YourProjectName"
version = "0.1.0"
description = "Add your description here"
requires-python = ">=3.12"
dependencies = [
    "fastapi"
]

[dependency-groups]
dev = [
	"workers-py",
	"workers-runtime-sdk"
]
```

위는 당신의 노동자가 위에 달려 있을 것을 허용합니다[빠른 API](https://fastapi.tiangolo.com/)패키지.

worker를 로컬로 실행하려면:

```
uv run pywrangler dev
```

작업자를 배포하려면:

```
uv run pywrangler deploy
```

당신의 종점은 배포에 자동으로 작업자와 번들됩니다.

더 보기`pywrangler`CLI는 모든 명령을 지원합니다.`wrangler`도구, 명령 실행의 전체 목록`uv run pywrangler --help`.

## 지원되는 Libraries

Python Workers는 순수한 Python 패키지를 지원합니다[사이트맵](https://pypi.org/)·
뿐만 아니라[Pyodide에 포함 된 패키지](https://pyodide.org/en/stable/usage/packages-in-pyodide.html).

만약 당신이 순수한 Python가 아닌 패키지를 사용 하 고 아직 Pyodide에서 지원 하지, 요청 지원
이름 \*[모델 번호: Python 패키지 토론](https://github.com/cloudflare/workerd/discussions/categories/python-packages)에 의해
Cloudflare Workers GitHub 저장소 실행

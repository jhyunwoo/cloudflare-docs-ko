## 제품정보

Python 노동자는 부호의 4개의 선으로 간단한 일 수 있습니다:

```python
from workers import WorkerEntrypoint, Response

class Default(WorkerEntrypoint):
    async def fetch(self, request):
        return Response("Hello World!")
```

다른 Workers와 유사한, Python 노동자를 위한 주요 입장 점은 입니다[`fetch`회사 소개](/workers/runtime-apis/handlers/fetch)어떤 핸들 수신 요청
노동자에게 보내.

Python에서 Worker, 이 핸들러는`Default`클래스를 확장`WorkerEntrypoint`클래스 (당신은에서 가져올 수 있습니다)`workers`SDK 모듈).

:::caution\[Python Workers는 베타에 있습니다.]

당신은 추가해야합니다`python_workers`Python WorkersXQ는 오픈 베타에 있습니다. 패키지는 사용 가능[채용 정보](/workers/languages/python/packages)도구.

우리는 당신의 의견을 사랑합니다. #python-workers 채널에 가입[Cloudflare 개발자 Discord](https://discord.cloudflare.com/)그리고 당신이 다음을보고 싶은 것을 알려주세요.
주요 특징

### 더 보기`pywrangler`CLI 도구

Python를 실행하려면 로컬로 작업, 패키지를 설치, Cloudflare에 배포, 당신은 사용[채용 정보](https://github.com/cloudflare/workers-py)·
Python Workers를 위한 CLI.

그것을 위로 놓기 위하여, 첫째로, 지킵니다[사이트맵](https://docs.astral.sh/uv/#installation)·[이름 \*](https://nodejs.org/en)설치.

다음 개발 환경을 설정:

```
uv init
uv tool install workers-py
uv run pywrangler init
```

이것은 만들 것입니다`pyproject.toml`파일 첨부`workers-py`회사연혁
신뢰성.`pywrangler init`wrangler config 파일을 만들 것입니다. 다음을 할 수 있습니다
지원하다`pywrangler`이름:

```bash
uv run pywrangler dev
```

Python Cloudflare, 실행에 노동자`pywrangler deploy`:

```bash
uv run pywrangler deploy
```

### 모델 번호: Python 작업자 템플릿

새로운 Python를 초기화할 때 Worker 프로젝트와 많은 템플릿 중 하나를 선택:

```bash
uv run pywrangler init
```

또는 더 많은 옵션을 탐구하기 위해 예제 저장소를 복제 할 수 있습니다 :

```bash
git clone https://github.com/cloudflare/python-workers-examples
cd python-workers-examples/01-hello
```

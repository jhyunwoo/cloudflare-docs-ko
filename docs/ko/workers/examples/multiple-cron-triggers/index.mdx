## Wrangler

Cron Triggers 테스트의 권장 방법은 Wrangler를 사용합니다.

Cron Triggers는 Wrangler를 사용하여 테스트 할 수 있습니다.`--test-scheduled`본문 바로가기[`wrangler dev`](/workers/wrangler/commands/#dev). 이것은 노출될 것입니다`/__scheduled`(주)`/cdn-cgi/handler/scheduled`Python Workers) 경로에 대한 HTTP 요청을 사용하여 테스트 할 수 있습니다. 다른 cron 패턴을 시뮬레이션하기 위해,`cron`질 모수는 안으로 통과될 수 있습니다.

```sh
npx wrangler dev --test-scheduled

curl "http://localhost:8787/__scheduled?cron=*%2F3+*+*+*+*"

curl "http://localhost:8787/cdn-cgi/handler/scheduled?cron=*+*+*+*+*" #Python Workers
```

get started를 신속히 원한다면 아래 버튼을 클릭하십시오.

[![Cloudflare에 배포](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/cloudflare/docs-examples/tree/main/workers/images-workers)

GitHub 계정에서 저장소를 생성하고 QXQX0228XQQ WorkersXQ에 응용 프로그램을 배포합니다.

import { TabItem, Tabs } from "~/components";

사용자 정의 도메인에서 이미지를 제공하려면:

1. Cloudflare dashboard에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />

2. 제품정보**회사연혁** > **모델 번호: Workers** > **회사 소개**당신의 노동자를 창조하십시오.

3. 당신의 노동자에서, 선택**빠른 편집**다음 코드를 붙여넣기.

사용자 정의 도메인에서 이미지를 제공 할 수있는 또 다른 방법은 다음과 같습니다.`cdn-cgi/imagedelivery`방아쇠 경로로 사용되는 접fix 경로`cdn-cgi`이미지 프록시.

아래는 이미지와 같은 계정에서 Cloudflare proxied 도메인으로 hostname을 보여주는 예입니다. 접두사 경로와 이미지와 함께`<ACCOUNT_HASH>`, `<IMAGE_ID>`·`<VARIANT_NAME>`찾을 수 있습니다**제품정보**Cloudflare dashboard에.

```js
https://example.com/cdn-cgi/imagedelivery/<ACCOUNT_HASH>/<IMAGE_ID>/<VARIANT_NAME>
```

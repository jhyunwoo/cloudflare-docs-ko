사용 방법[스트림 API](/workers/runtime-apis/streams/)작업자의 128 MB 메모리 제한을 완전히 버퍼링하면 JSON 페이로드를 처리합니다. 스트리밍을 통해 JSON data incrementally를 전달할 수 있습니다. 이것은 기억으로 전체 페이로드를 버퍼보다 빠르며 작업자가 데이터 처리를 시작할 수 있으므로 작업자가 멀티 기가 바이트 페이로드 또는 메모리 제한 내에서 파일을 처리 할 수 있습니다.

더 보기[`@streamparser/json-whatwg`](https://www.npmjs.com/package/@streamparser/json-whatwg)라이브러리는 Web Streams API와 호환되는 스트리밍 JSON parser를 제공합니다.

신뢰성을 설치하십시오:

```sh
npm install @streamparser/json-whatwg
```

## JSON 요청 body Stream

이 예제는 큰 JSON 요청 바디를 파고 메모리로 전체 페이로드를로드하지 않고 특정 필드를 추출합니다.

<Tabs syncKey="workersExamples">
  <TabItem label="TypeScript" icon="seti:typescript">
    ```ts
    import { JSONParser } from "@streamparser/json-whatwg";

    export default {
    	async fetch(request): Promise<Response> {
    		const parser = new JSONParser({ paths: ["$.users.*"] });

    		const users: string[] = [];

    		//JSON 파서를 통해 요청 몸을 파이프
    		const reader = request.body
    			.pipeThrough(parser)
    			.getReader();

    		//JSON 값에 대응하는 프로세스
    		while (true) {
    			const { done, value } = await reader.read();
    			if (done) break;
    			//각 사용자 객체의 이름 필드만 추출
    			if (value.value?.name) {
    				users.push(value.value.name);
    			}
    		}

    		return Response.json({ userNames: users });
    	},
    } satisfies ExportedHandler;
    ```
  </TabItem>

## 스트림 및 JSON 응답을 변환

이 예제는 upstream API에서 큰 JSON 응답을 태우고 특정 필드를 변환하고 클라이언트에 수정 된 응답을 스트림합니다.

<Tabs syncKey="workersExamples">
  <TabItem label="모델 번호: TypeScript" icon="seti:typescript">
    ```ts
    import { JSONParser } from "@streamparser/json-whatwg";

    export default {
    	async fetch(request): Promise<Response> {
    		const response = await fetch("https://api.example.com/large-dataset.json");

    		const parser = new JSONParser({ paths: ["$.items.*"] });

    		const { readable, writable } = new TransformStream();
    		const writer = writable.getWriter();
    		const encoder = new TextEncoder();

    		//배경에서 상류 응답을 처리
    		(async () => {
    			const reader = response.body
    				.pipeThrough(parser)
    				.getReader();

    			await writer.write(encoder.encode('{"processedItems":['));
    			let first = true;

    			while (true) {
    				const { done, value } = await reader.read();
    				if (done) break;

    				//각 항목을 통해 스트림으로 변환
    				const item = value.value;
    				const transformed = {
    					id: item.id,
    					title: item.title.toUpperCase(),
    					processed: true,
    				};

    				if (!first) await writer.write(encoder.encode(","));
    				first = false;
    				await writer.write(encoder.encode(JSON.stringify(transformed)));
    			}

    			await writer.write(encoder.encode("]}"));
    			await writer.close();
    		})();

    		return new Response(readable, {
    			headers: { "Content-Type": "application/json" },
    		});
    	},
    } satisfies ExportedHandler;
    ```
  </TabItem>

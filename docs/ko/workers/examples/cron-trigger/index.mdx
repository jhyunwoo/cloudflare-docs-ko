## Wrangler에서 Cron 트리거 세트

더 알아보기[Cron 트리거](/workers/configuration/cron-triggers/)Cron Trigger를 추가하는 방법에 대한 자세한 내용은.

Wrangler로 배포하는 경우, Wrangler 파일에 추가하여 cron 구문 (시간 당)을 설정합니다.

<WranglerConfig>
  ```jsonc
  {
  	"$schema": "./node_modules/wrangler/config-schema.json",
  	"name": "worker",
  	//· ...
  	"triggers": {
  		"crons": [
  			"0 * * * *"
  		]
  	}
  }
  ```
</WranglerConfig>

또한 서로 다른 Cron 트리거를 설정할 수 있습니다.[환경분야](/workers/wrangler/environments/)내 계정[Wrangler 구성 파일](/workers/wrangler/configuration/). 당신은`[triggers]`선택한 환경에서 테이블. 예를 들면:

<WranglerConfig>
  ```jsonc
  {
  	"env": {
  		"dev": {
  			"triggers": {
  				"crons": [
  					"0 * * * *"
  				]
  			}
  		}
  	}
  }
  ```
</WranglerConfig>

## Wrangler

Cron Triggers 테스트의 권장 방법은 Wrangler를 사용합니다.

Cron Triggers는 Wrangler를 사용하여 테스트 할 수 있습니다.`--test-scheduled`본문 바로가기[`wrangler dev`](/workers/wrangler/commands/#dev). 이것은 노출될 것입니다`/__scheduled`(주)`/cdn-cgi/handler/scheduled`Python Workers) 경로는 HTTP 요청을 사용하여 테스트 할 수 있습니다. 다른 cron 패턴을 시뮬레이션하기 위해,`cron`질 모수는 안으로 통과될 수 있습니다.

```sh
npx wrangler dev --test-scheduled

curl "http://localhost:8787/__scheduled?cron=0+*+*+*+*"

curl "http://localhost:8787/cdn-cgi/handler/scheduled?cron=*+*+*+*+*" #Python Workers
```

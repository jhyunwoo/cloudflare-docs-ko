### 기본 설정

환경 변수를 설정하는 단계는 다음과 같습니다.`.dev.vars`또는`.env`파일.

<Steps>
  1. 이름 \*`.dev.vars` / `.env`프로젝트 루트에 파일.

  2. 키 값 쌍 추가:

     ```ini title=".dev.vars/.env"
     API_HOST="localhost:3000"
     DEBUG="true"
     SECRET_TOKEN="my-local-secret-token"
     ```

  3. 너에게`dev`이름 \*

     **Wrangler**

     <PackageManagers type="exec" pkg="wrangler" args="dev" />

     **Vite 플러그인**

     <PackageManagers type="exec" pkg="vite" args="dev" />
</Steps>

## 현지 환경

다른 로컬 환경을 시뮬레이션하려면 환경 별 파일을 제공 할 수 있습니다.
예를 들어, 당신은 가질 수 있습니다`staging`당신의 발달 환경 보다는 다른 조정을 요구하는 환경.

<Steps>
  1. 파일 생성`.dev.vars.<environment-name>`/`.env.<environment-name>`. 예를 들면, 우리는 사용할 수 있습니다`.dev.vars.staging`/`.env.staging`.

  2. 키 값 쌍 추가:

     ```ini title=".dev.vars.staging/.env.staging"
     API_HOST="staging.localhost:3000"
     DEBUG="false"
     SECRET_TOKEN="staging-token"
     ```

  3. 실행할 때 환경 지정`dev`명령:

     **Wrangler**

     <PackageManagers type="exec" pkg="wrangler" args="dev --env staging" />

     **Vite 플러그인**

     <PackageManagers type="exec" pkg="vite" args="dev" prefix="CLOUDFLARE_ENV=staging" />

     - 사용 방법`.dev.vars.staging`, 그 파일에서 값은 대신 적용된다`.dev.vars`.
     - 사용 방법`.env.staging`, 값은 병합됩니다`.env`파일, 가장 특정 파일과 함께 precedence.
</Steps>

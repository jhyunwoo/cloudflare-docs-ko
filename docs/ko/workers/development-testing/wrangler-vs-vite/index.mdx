# Wrangler vs Vite를 사용할 때

Wrangler와 CloudflareQ Vite 플러그인은 프로젝트의 초점과 개발 작업 흐름에 달려 있습니다. 여기에 당신이 선택할 수있는 몇 가지 빠른 지침이 있습니다:

## Wrangler를 사용할 때

- **백엔드 & Workers 초점:**&#x41;PI, Serverless 기능, 또는 배경 작업을 구축하는 경우 Wrangler를 사용하십시오.

- **원격 개발:**&#xD504;로젝트가 Cloudflare의 네트워크에 원격으로 실행할 수 있는 능력을 필요로 하는 경우, Wrangler's를 사용하십시오`--remote`플래그.

- **간단한 frontends:**&#xCD5C;소 프론트 엔드 요구 사항이 있으면 핫 리로드 또는 고급 번들링이 필요하지 않습니다. Wrangler는 충분할 수 있습니다.

## Cloudflare Vite 플러그인을 사용할 때

사용 방법[Vite 플러그인](/workers/vite-plugin/)제품 정보:

- **Frontend-centric 개발:**&#xC774;미 React, Vue, Svelte 또는 Solid와 같은 현대 frontend 프레임 워크와 Vite를 사용하는 경우, Vite 플러그인은 개발 워크플로우에 통합됩니다.

- **React 대패 v7:**&#xC790;주 묻는 질문[모델 번호: React 라우터 v7](https://reactrouter.com/)(Remix에 성공자), 그것은 공식적으로 Vite 플러그인에 의해 전체 스택 SSR 프레임 워크.

- **급속한 여정 (HMR):**&#xBE0C;라우저에서 가까운 업데이트가 필요한 경우 Vite 플러그인 제공[핫 모듈 교체 (HMR)](https://vite.dev/guide/features.html#hot-module-replacement)현지 개발 중.

- **고급 최적화:**&#xB354; 고급 최적화를 필요로 하는 경우 (분쇄, 효율적인 번들링, CSS 처리, 구축 시간 변환 등), Vite는 강한 적합.

- **더 중대한 융통성:**&#x56;ite의 고급 구성 옵션과 플러그인의 큰 생태계로 인해 개발 경험을 사용자 정의하고 출력을 구축 할 수있는 유연성이 더 있습니다.

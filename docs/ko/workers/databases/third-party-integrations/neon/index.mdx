[이름 \*](https://neon.tech/)완전히 관리된 serverless PostgreSQL입니다. 저장을 분리하고 Serverless, Branching 및 Bottomless 스토리지와 같은 현대 개발자 기능을 제공 할 수 있습니다.

:::참조

네온에 연결할 수 있습니다.[Hyperdrive](/hyperdrive)(추천), 또는 네온 서버리스 드라이버를 사용하여,`@neondatabase/serverless`. 둘 다 연결 풀을 제공하고 당신의 데이타베이스에 WorkersXQ에서 안전한 연결을 창조하기 위하여 요구되는 둥근 여행의 양을 감소시킵니다.

Hyperdrive는 Cloudflare의 네트워크를 통해 데이터베이스 연결 설정 및 연결 풀링을 수행하기 때문에 가장 낮은 가능한 latencies를 제공 할 수 있습니다. Hyperdrive는 기본 데이터베이스 드라이버, 라이브러리 및 ORM을 지원하며 모든 것에 포함되어 있습니다.[Workers 계획](/hyperdrive/platform/pricing/). Hyperdrive에 대해 자세히 알아보기[Hyperdrive 이름 \*](/hyperdrive/concepts/how-hyperdrive-works/).

:::

  <TabItem label="네온 서버리스 드라이버">
    네온에 연결하기`@neondatabase/serverless`, 다음 단계를 따르십시오:

    1. 기존의 네온 데이터베이스가 있어야 합니다.[네온 데이터베이스 만들기](https://neon.tech/docs/postgres/tutorial-createdb#create-a-table)또는[기존 데이터베이스에서 네온으로 데이터로드](https://neon.tech/docs/import/import-from-postgres).

    2. 이름 \*`elements`네온 SQL 편집기를 사용하여 테이블. SQL 편집기는 네온 콘솔에서 데이터베이스를 직접 쿼리 할 수 있습니다.

       ```sql
       CREATE TABLE elements (
         id INTEGER NOT NULL,
         elementName TEXT NOT NULL,
         atomicNumber INTEGER NOT NULL,
         symbol TEXT NOT NULL
       );
       ```

    3. 새로 만들어진 테이블에 데이터를 삽입합니다.

       ```sql
       INSERT INTO elements (id, elementName, atomicNumber, symbol)
       VALUES
         (1, 'Hydrogen', 1, 'H'),
         (2, 'Helium', 2, 'He'),
         (3, 'Lithium', 3, 'Li'),
         (4, 'Beryllium', 4, 'Be'),
         (5, 'Boron', 5, 'B'),
         (6, 'Carbon', 6, 'C'),
         (7, 'Nitrogen', 7, 'N'),
         (8, 'Oxygen', 8, 'O'),
         (9, 'Fluorine', 9, 'F'),
         (10, 'Neon', 10, 'Ne');
       ```

    4. 작업자의 네온 데이터베이스 자격 구성 :

       네온 데이터베이스 연결 문자열을 작업자에게 비밀로 추가해야합니다. 연결 문자열을 가져옵니다[네온 콘솔](https://console.neon.tech)이름 \***연결 세부사항**, 다음 Wrangler를 사용하여 비밀로 추가:

       ```sh
       #데이터베이스 연결 문자열을 비밀로 추가
       npx wrangler secret put DATABASE_URL
       #언제 신속하게, 네온 데이터베이스 연결 문자열을 붙여
       ```

    5. 직장에서, 설치`@neondatabase/serverless`데이터베이스에 연결하고 데이터를 조작하려면 드라이버:

       <PackageManagers pkg="@neondatabase/serverless" />

    6. 다음 예제는 작업자의 네온 데이터베이스에 쿼리를 만드는 방법을 보여줍니다. 네온에 연결하기 위해 필요한 자격은 직장인에게 비밀로 추가되었습니다.

       ```js
       import { Client } from "@neondatabase/serverless";

       export default {
       	async fetch(request, env, ctx) {
       		const client = new Client(env.DATABASE_URL);
       		await client.connect();
       		const { rows } = await client.query("SELECT * FROM elements");

       		return new Response(JSON.stringify(rows));
       	},
       };
       ```

    네온에 대해 더 알아보기 위해, 참조[네온 공식 문서](https://neon.tech/docs/introduction).

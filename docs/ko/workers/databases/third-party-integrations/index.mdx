## 이름 \*

연결 문자열과 credentials를 구성하여 데이터베이스에 연결[이름 \*](/workers/configuration/secrets/)당신의 노동자에.

:::note\[Worker에서 지역 데이터베이스에 연결?]

작업자가 지역 데이터베이스에 연결되면, 사용함으로써 쿼리 대기 시간을 줄일 수 있습니다.[Hyperdrive](/hyperdrive)·[스마트 배치](/workers/configuration/placement/)어떤 Workers 계획에서 둘 다 포함되는. Hyperdrive는 Cloudflare의 네트워크를 통해 전 세계적으로 데이터베이스 연결을 풀 것입니다. Smart Placement는 WorkersXQ를 실행하기 위해 응용 프로그램을 모니터링 할 것입니다. 이 작업자의 지연을 줄일 때 백엔드 인프라에 가까운. 더 알아보기[Smart Placement는 어떻게 작동합니까?](/workers/configuration/placement/).
:::

## 데이터베이스 자격

데이터베이스 자격 증명을 회전하거나 업데이트 할 때, 해당 정보를 업데이트해야합니다.[이름 \*](/workers/configuration/secrets/)당신의 노동자에. 사용 방법[`wrangler secret put`](/workers/wrangler/commands/#secret)비밀을 안전하게 업데이트하거나 비밀을 직접 업데이트하는 명령[Cloudflare dashboard](https://dash.cloudflare.com/?to=/:account/workers/services/view/:worker/production/settings).

## 데이터베이스 제한

각 데이터베이스 연결에 대한 비밀의 분리 세트를 구성하여 여러 데이터베이스에 연결할 수 있습니다. 다른 데이터베이스 연결 (예를 들면,`DATABASE_URL_PROD`·`DATABASE_URL_STAGING`).

Node.js 도구를 사용하여 WorkersXQ를 디버깅할 수 있습니다. breakpoints 설정,
값을보고 통화 스택을 검사하는 것은 당신이 할 수있는 것들의 모든 예입니다
디버거로 한다.

## Visual Studio 코드

### 설정 만들기

VSCode의 Worker를 디버깅하는 가장 쉬운 방법은 새로운 구성을 만듭니다.

자주 묻는 질문**실행 및 디버그**VSCode 활동 막대기에 있는 메뉴는 창조합니다
`.vscode/launch.json`다음을 포함하는 파일:

```json
---
filename: .vscode/launch.json
---
{
  "configurations": [
    {
      "name": "Miniflare",
      "type": "node",
      "request": "attach",
      "port": 9229,
      "cwd": "/",
      "resolveSourceMapLocations": null,
      "attachExistingChildren": false,
      "autoAttachChildProcesses": false,
    }
  ]
}
```

에 의해**실행 및 디버그**활동 바에서 메뉴, 선택`Miniflare`구성 및 녹색 재생 버튼을 클릭하여 디버깅을 시작합니다.

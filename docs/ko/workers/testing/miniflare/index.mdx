**미니 플레어**개발 및 테스트를위한 시뮬레이터
[**CloudflareWorkers**](https://workers.cloudflare.com/). 그것은 안으로 쓰입니다
TypeScript, Workers'런타임 API를 구현 샌드박스에서 코드를 실행합니다.

- 🎉 **재미:**&#x57;orkers를 상세한 로깅, 파일보고 및 쉽게 개발
  소스 맵을 지원하는 꽤 오류 페이지.
- 🔋 **가득 차있 특징:**&#x4B;V, 내구재를 포함하여 대부분의 Workers 특징을, 지원하십시오
  Objects, WebSockets, 모듈 등
- ⚡ **완전히 지역:**&#xC778;터넷 연결 없이 Workers를 시험하고 개발하십시오.
  빠르게 변화하는 코드를 다시로드합니다.

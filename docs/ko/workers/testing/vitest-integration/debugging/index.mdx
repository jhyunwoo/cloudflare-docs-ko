이 가이드는 당신의 WorkersXQ 시험을 Vitest로 디버그하는 방법을 보여줍니다. 이용 가능`@cloudflare/vitest-pool-workers`v0.7.5 이상.

## Vitest를 가진 열려있는 inspector

디버깅을 시작하려면 다음 명령으로 Vitest를 실행하고 포트에 디버거를 부착하십시오.`9229`:

```sh
vitest --inspect --no-file-parallelism
```

## 검사기 항구를 주문을 받아서 만드십시오

기본적으로, 검사기는 포트에 열릴 것이다`9229`. 다른 포트를 사용해야하는 경우 (예를 들어,`3456`), 다음 명령을 실행할 수 있습니다:

```sh
vitest --inspect=3456 --no-file-parallelism
```

또는 Vitest 설정 파일에서 정의할 수 있습니다:

```ts
import { defineWorkersConfig } from "@cloudflare/vitest-pool-workers/config";

export default defineWorkersConfig({
  test: {
    inspector: {
        port: 3456,
    },
    poolOptions: {
      workers: {
        //· ...
      },
    },
  },
});
```

## 설정 VS Breakpoints를 사용하는 코드

Worker 테스트에서 Breakpoint 디버깅을 위한 VS Code를 설정하려면, 생성`.vscode/launch.json`다음 구성을 포함하는 파일:

```json
{
    "configurations": [
        {
            "type": "node",
            "request": "launch",
            "name": "Open inspector with Vitest",
            "program": "${workspaceRoot}/node_modules/vitest/vitest.mjs",
            "console": "integratedTerminal",
            "args": ["--inspect=9229", "--no-file-parallelism"]
        },
        {
            "name": "Attach to Workers Runtime",
            "type": "node",
            "request": "attach",
            "port": 9229,
            "cwd": "/",
            "resolveSourceMapLocations": null,
            "attachExistingChildren": false,
            "autoAttachChildProcesses": false,
        }
    ],
    "compounds": [
        {
            "name": "Debug Workers tests",
            "configurations": ["Open inspector with Vitest", "Attach to Workers Runtime"],
            "stopAll": true
        }
    ]
}
```

제품정보**디버그 Workers 테스트**맨 위로**실행 및 디버그**Vitest를 가진 검사기를 열고 Workers 런타임에 디버거를 붙입니다. 그런 다음 테스트 파일에 Breakpoint를 추가하고 디버깅을 시작합니다.

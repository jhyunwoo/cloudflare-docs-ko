:::참조
대부분의 사용자를 위해 Cloudflare는 Workers Vitest 통합을 사용하는 것이 좋습니다. 사용중인 경우`unstable_dev()`, 참조[Migrate에서`unstable_dev()`- 연혁](/workers/testing/vitest-integration/migration-guides/migrate-from-unstable-dev/).
:::

:::카트로션
`unstable_startWorker()`변화를 끊는 실험적인 API 주제입니다.
주요 특징

Vitest를 사용하지 않는 경우, 사용 고려[Wrangler의`unstable_startWorker()`사이트맵](/workers/wrangler/api/#unstable_startworker). 이 API는 Wrangler의 dev 서버의 내부를 노출하고, 어떻게 실행하는지 사용자 정의 할 수 있습니다. 사용 비교[시험에 직접 Miniflare](/workers/testing/miniflare/writing-tests/), 당신은 Wrangler 윤곽 파일에서 통과할 수 있고, 그것은 당신을 위한 윤곽을 자동으로 적재할 것입니다.

이 예제는`node:test`, 그러나 어떤 테스트 기구든지에 적용합니다:

```ts
import assert from "node:assert";
import test, { after, before, describe } from "node:test";
import { unstable_startWorker } from "wrangler";

describe("worker", () => {
	let worker;

	before(async () => {
		worker = await unstable_startWorker({ config: "wrangler.json" });
	});

	test("hello world", async () => {
		assert.strictEqual(
			await (await worker.fetch("http://example.com")).text(),
			"Hello world",
		);
	});

	after(async () => {
		await worker.dispose();
	});
});

```

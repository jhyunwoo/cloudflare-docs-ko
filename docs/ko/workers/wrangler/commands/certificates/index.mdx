import { WranglerCommand, WranglerConfig } from "~/components";

이 명령을 사용하여 mTLS 연결을 위해 인증서를 관리합니다.

더 보기`mtls-certificate`명령은 Worker subrequests의 클라이언트 인증서를 관리합니다. 더 보기`cert`명령은 mTLS 클라이언트 인증서 및 인증서 권한 (CA) 체인 인증서를 모두 관리하여 주로 사용[모델 번호: Hyperdrive](/workers/wrangler/commands/hyperdrive/)구성.

***

## `mtls-certificate`

subrequests에서 mTLS 연결을 위해 사용되는 클라이언트 인증서를 관리합니다.

이 증명서는 안으로 사용될 수 있습니다[`mtls_certificate`관련 제품](/workers/runtime-apis/bindings/mtls)클라이언트 인증 (mTLS)을 필요로 하는 근원과 연결을 설정할 때 인증서를 제시할 수 있는 노동자.

<WranglerCommand command="mtls-certificate upload" headingLevel={3} />

다음은 사용 예제입니다.`upload`mTLS 인증서를 업로드 할 명령.

```sh
npx wrangler mtls-certificate upload --cert cert.pem --key key.pem --name my-origin-cert
```

```sh output
Uploading mTLS Certificate my-origin-cert...
Success! Uploaded mTLS Certificate my-origin-cert
ID: 99f5fef1-6cc1-46b8-bd79-44a0d5082b8d
Issuer: CN=my-secured-origin.com,OU=my-team,O=my-org,L=San Francisco,ST=California,C=US
Expires: 1/01/2025
```

다음이 인증서를 추가 할 수 있습니다.[관련 제품](/workers/runtime-apis/bindings/)내 계정[Wrangler 구성 파일](/workers/wrangler/configuration/):

<WranglerConfig>
  ```jsonc
  {
  	"mtls_certificates": [
  		{
  			"binding": "MY_CERT",
  			"certificate_id": "99f5fef1-6cc1-46b8-bd79-44a0d5082b8d",
  		},
  	],
  }
  ```
</WranglerConfig>

인증서 및 개인 키가 별도이어야합니다 (일반적으로`.pem`) 업로드 할 때 파일.

<WranglerCommand command="mtls-certificate list" headingLevel={3} />

다음은 사용 예제입니다.`list`mTLS 인증서를 업로드 할 명령.

```sh
npx wrangler mtls-certificate list
```

```sh output
ID: 99f5fef1-6cc1-46b8-bd79-44a0d5082b8d
Name: my-origin-cert
Issuer: CN=my-secured-origin.com,OU=my-team,O=my-org,L=San Francisco,ST=California,C=US
Created on: 1/01/2023
Expires: 1/01/2025

ID: c5d004d1-8312-402c-b8ed-6194328d5cbe
Issuer: CN=another-origin.com,OU=my-team,O=my-org,L=San Francisco,ST=California,C=US
Created on: 1/01/2023
Expires: 1/01/2025
```

<WranglerCommand command="mtls-certificate delete" headingLevel={3} />

다음은 사용 예제입니다.`delete`mTLS 인증서를 삭제하는 명령.

```sh
npx wrangler mtls-certificate delete --id 99f5fef1-6cc1-46b8-bd79-44a0d5082b8d
```

```sh output
Are you sure you want to delete certificate 99f5fef1-6cc1-46b8-bd79-44a0d5082b8d (my-origin-cert)? [y/n]
yes
Deleting certificate 99f5fef1-6cc1-46b8-bd79-44a0d5082b8d...
Deleted certificate 99f5fef1-6cc1-46b8-bd79-44a0d5082b8d successfully
```

## `cert`

보안 연결을 위해 사용되는 mTLS 클라이언트 인증서 및 인증 기관 (CA) 체인 인증서를 관리합니다.

이 인증서는 Hyperdrive 구성에서 사용할 수 있으며 클라이언트 인증 (mTLS) 또는 사용자 정의 인증서 권위 (CA)을 요구하는 원산지 데이터베이스에 연결 할 때 인증서를 제시 할 수 있습니다.

<WranglerCommand command="cert upload mtls-certificate" headingLevel={3} />

다음은 사용 예제입니다.`upload`mTLS 인증서를 업로드 할 명령.

```sh
npx wrangler cert upload --cert cert.pem --key key.pem --name my-origin-cert
```

```sh output
Uploading mTLS Certificate my-origin-cert...
Success! Uploaded mTLS Certificate my-origin-cert
ID: 99f5fef1-6cc1-46b8-bd79-44a0d5082b8d
Issuer: CN=my-secured-origin.com,OU=my-team,O=my-org,L=San Francisco,ST=California,C=US
Expires: 1/01/2025
```

인증서 및 개인 키가 별도이어야합니다 (일반적으로`.pem`) 업로드 할 때 파일.

<WranglerCommand command="cert upload certificate-authority" headingLevel={3} />

다음은 사용 예제입니다.`upload`CA 인증서 업로드 명령.

```sh
npx wrangler cert upload certificate-authority --ca-cert server-ca-chain.pem --name SERVER_CA_CHAIN

```

```sh output
Uploading CA Certificate SERVER_CA_CHAIN...
Success! Uploaded CA Certificate SERVER_CA_CHAIN
ID: 99f5fef1-6cc1-46b8-bd79-44a0d5082b8d
Issuer: CN=my-secured-origin.com,OU=my-team,O=my-org,L=San Francisco,ST=California,C=US
Expires: 1/01/2025
```

<WranglerCommand command="cert list" headingLevel={3} />

다음은 사용 예제입니다.`list`mTLS 또는 CA 인증서를 업로드하는 명령.

```sh output

Issuer: CN=another-origin.com,OU=my-team,O=my-org,L=San Francisco,ST=California,C=US
Created on: 1/01/2023
Expires: 1/01/2025
```

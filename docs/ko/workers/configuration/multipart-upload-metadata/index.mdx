Workers를 업로드하는 새로운 API가 있습니다. 더 알아보기[이 문서](/workers/platform/infrastructure-as-code#cloudflare-rest-api)더 많은 정보.
주요 특징

당신이 사용 하는 경우[Workers 스크립트 업로드 API](/api/resources/workers/subresources/scripts/methods/update/)또는[버전 업로드 API](/api/resources/workers/subresources/scripts/subresources/versions/methods/create/)직접,`multipart/form-data`업로드는 지정해야 합니다.`metadata`이름 \* 이 메타데이터는 JSON 형식의 Worker의 구성을 정의하고, 아날로그[wrangler.toml 파일](/workers/wrangler/configuration/).

## 제품 설명`metadata`

```json
{
	"main_module": "main.js",
	"bindings": [
		{
			"type": "plain_text",
			"name": "MESSAGE",
			"text": "Hello, world!"
		}
	],
	"compatibility_date": "2021-09-14"
}
```

:::참조

Workers Script Upload API와 함께 사용되는 메타데이터 예제 보기[이름 \*](/workers/platform/infrastructure-as-code#cloudflare-rest-api).
:::

## 관련 기사

다음 속성은 최상위에서 설정할 수 있습니다.

:::참조

최소에,`main_module`키는 노동자를 업로드해야합니다.
주요 특징

- `main_module` <Type text="string" /> <MetaInfo text="required" />
  - 실행될 Worker의 Module Entry Point를 포함하는 부분 이름. 예를 들어,`main.js`.

- `assets` <Type text="object" /> <MetaInfo text="optional" />
  - [투자정보](/workers/static-assets/)작업자의 구성.
  - `config` <Type text="object" /> <MetaInfo text="optional" />
    - [html 핸들링](/workers/static-assets/routing/advanced/html-handling/)HTML 콘텐츠에 대한 요청의 리디렉션 및 리디렉션을 결정합니다.
    - [not found handling에 대해](/workers/static-assets/#routing-behavior)요청이 정적 자산과 일치하지 않을 때 응답을 결정합니다.
  - `jwt`필드는 Worker에 붙어있는 토큰 승인 자산을 제공합니다.

- `keep_assets` <Type text="boolean" /> <MetaInfo text="optional" />
  - 이전에 업로드 된 Worker 버전에서 자산을 유지해야하는지 여부를 지정합니다. 완료 된 토큰을 제공 한 거짓말에 사용됩니다.

- `bindings`array\[object] 옵션
  - [회사 소개](#bindings)노동자에 노출.

- `placement` <Type text="object" /> <MetaInfo text="optional" />
  - [스마트 배치](/workers/configuration/placement/)노동자를 위한 목표.
  - `mode`현장 지원`smart`자동적인 배치를 위해.

- `compatibility_date` <Type text="string" /> <MetaInfo text="optional" />
  - [호환성 날짜](/workers/configuration/compatibility-dates/#setting-compatibility-date)Workers 런타임에서 대상 지원을 나타냅니다. 이 날짜를 따르는 runtime에 뒤로 incompatible 고침은 이 노동자에 영향을 미치지 않습니다. 설정하는 것이 좋습니다.`compatibility_date`, 그렇지 않으면 API를 통해 업로드 할 경우, 어떤 플래그가 효력을 발생하기 전에 가장 오래된 호환성 날짜에 기본 (2021-11-02).

- `compatibility_flags`array\[string] 옵션
  - [호환성 깃발](/workers/configuration/compatibility-flags/#setting-compatibility-flags)Workers 런타임에서 특정 기능을 활성화하거나 비활성화할 수 있습니다. 다음 기능을 사용하거나 특정 변경 사항의 선택 해제`compatibility_date`.

## 추가 속성:[Workers 스크립트 업로드 API](/api/resources/workers/subresources/scripts/methods/update/)

제품 정보[즉시 업로드](/workers/configuration/versions-and-deployments/#upload-a-new-version-and-deploy-it-immediately), 다음**이름 \***&#xC18D;성은 최상위에서 설정할 수 있습니다.

:::참조

특별 할인`annotations`, 이 속성은**이용안내**버전의 업로드.
주요 특징

- `migrations`array\[object] 옵션
  - [Durable Objects 마이그레이션](/durable-objects/reference/durable-objects-migrations/)신청하기

- `logpush` <Type text="boolean" /> <MetaInfo text="optional" />
  - 이름 \*[다운로드](/cloudflare-for-platforms/cloudflare-for-saas/hostname-analytics/#logpush)노동자를 위해 켜집니다.

- `tail_consumers`array\[object] 옵션
  - [꼬리 Workers](/workers/observability/logs/tail-workers/)첨부된 작업자에서 로그를 소비합니다.

- `tags`array\[string] 옵션
  - 이 작업자의 태그로 사용할 문자열 목록.

- `annotations` <Type text="object" /> <MetaInfo text="optional" />
  - 이 업로드에 의해 생성 된 Worker 버전의 주석 객체. 또한 사용할 수 있습니다[버전 업로드 API](#additional-attributes-version-upload-api).
  - `workers/message`버전에 대한 사용자 정의 메시지를 지정합니다.
  - `workers/tag`버전의 사용자 정의 식별자를 지정합니다.

## 추가 속성:[버전 업로드 API](/api/resources/workers/subresources/scripts/subresources/versions/methods/create/)

제품 정보[버전 업로드](/workers/configuration/versions-and-deployments/#upload-a-new-version-to-be-gradually-deployed-or-deployed-at-a-later-time), 다음**이름 \***&#xC18D;성은 최상위에서 설정할 수 있습니다.

- `annotations` <Type text="object" /> <MetaInfo text="optional" />
  - Worker 버전에 특정한 표기물.
  - `workers/message`버전에 대한 사용자 정의 메시지를 지정합니다.
  - `workers/tag`버전의 사용자 정의 식별자를 지정합니다.
  - `workers/alias`이 버전의 사용자 정의 별명을 지정합니다.

이전 배포로 다시 롤 할 수 있습니다.[이름 \*](/workers/configuration/versions-and-deployments/#versions)당신의 노동자의 사용[Wrangler](/workers/wrangler/commands/#rollback)또는 Cloudflare dashboard. 당신의 노동자의 이전 버전으로 다시 회전은 즉시 새로운 만들 것입니다[설치하기](/workers/configuration/versions-and-deployments/#deployments)지정된 버전과 모든 배포 경로와 도메인에 걸쳐 활성 배포가됩니다.

## Wrangler

Wrangler를 통해 노동자의 지정된 버전으로 다시 롤하려면, 사용[`wrangler rollback`](/workers/wrangler/commands/#rollback)명령.

## Cloudflare 대시보드를 통해

Cloudflare dashboard를 통해 노동자의 지정된 버전으로 돌아 가기 위하여:

1. Cloudflare dashboard에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />

2. 작업자 선택 >**계정 만들기**.

3. 오른쪽에있는 세 개의 도트 아이콘을 선택하면 다시 롤하고 선택해야합니다.**롤백**.

:::카트로션

**[작업자에 연결된 리소스](/workers/runtime-apis/bindings/)롤백에서 변경되지 않습니다.**

오류는 이전 버전의 코드를 사용한다면 데이터의 구조가 활성 배포판의 버전과 롤백에 선택된 버전 사이에 변경되는 경우 발생할 수 있습니다.

:::

## 제한 사항

### 롤백 제한

가장 최근 게시된 버전으로 다시 롤 할 수 있습니다.

:::참조

대화형 모드에서 Wrangler를 사용할 때 가장 최근 버전은 선택에 표시됩니다. 이전 버전으로 다시 롤하려면 (10 가장 최근), 명령 줄에 직접 버전 ID를 지정해야합니다. 더 알아보기[`wrangler versions deploy`](/workers/wrangler/commands/#versions-deploy)버전 ID를 지정하는 세부 사항에 대한 문서.

우리는 대화 형 모드에서 모든 100 사용할 수있는 버전을 표시 할 수 있도록이 제한을 해결 계획.

:::

### 회사 소개

작업자의 이전 버전으로 다시 롤 할 수 없습니다[Cloudflare 개발자 플랫폼 자원](/workers/runtime-apis/bindings/)(예 :[KV](/kv/)·[D1](/d1/))는 버전이 다시 롤하고 활성 배포판의 버전으로 선택된 사이에 삭제되거나 수정되었습니다. 특히, 롤백은 허용되지 않습니다 :

- ·[튼튼한 목표 마이그레이션](/durable-objects/reference/durable-objects-migrations/)활성 배포 버전과 롤백으로 선택된 버전 사이에 발생했습니다.
- 대상 배포가 있는 경우[관련 제품](/workers/runtime-apis/bindings/)R2 버킷, KV 네임스페이스 또는 더 이상 존재하지 않는 큐에.

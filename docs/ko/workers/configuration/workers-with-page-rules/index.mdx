페이지 규칙은 URL 패턴 중 하나를 일치 할 때마다 특정 작업을 트리거합니다. 특정 URL 패턴이 일치할 때마다 하나 이상의 작업을 트리거하는 페이지 규칙을 정의할 수 있습니다. 더 알아보기[페이지 규칙](/rules/page-rules/)configuring Page Rules에 대해 자세히 알아보세요.

## 페이지 규칙 Workers

Cloudflare는 행동합니다[역 프록시](https://www.cloudflare.com/learning/what-is-cloudflare/)서비스 제공, 페이지 규칙과 같은, 인터넷 속성에. 애플리케이션의 트래픽은 방문자에게 가장 가까운 Cloudflare 데이터 센터를 통과합니다. Workers 및 페이지 규칙과 같은 실행 서비스가 가능한 각 세계의 수백이 있습니다. 응용 프로그램이 Workers 및 / 또는 Pages에 내장 된 경우[Cloudflare 글로벌 네트워크](https://www.cloudflare.com/learning/serverless/glossary/what-is-edge-computing/)당신의 근원 서버로 행동하고 Cloudflare 글로벌 네트워크에서 요구에 직접 응답합니다.

Workers로 페이지 규칙을 사용할 때 다음 워크플로우가 적용됩니다.

1. Cloudflare 데이터 센터에 도착하십시오.
2. Cloudflare는 이 요청이 노동자 경로인지 결정합니다. Cloudflare는 작업자 경로이기 때문에 페이지 규칙에 의해 설정 될 몇 가지를 포함하여 다양한 기능을 평가하고 비활성화합니다.
3. 페이지 규칙은 현재 몇 가지 기능으로 처리하는 정상적인 요청의 일부로 실행됩니다.
4. 작업자 실행.
5. 노동자는 동일한 지역 또는 다른 지역 subrequest를 만듭니다. 이것은 노동자 경로이기 때문에, Cloudflare는 페이지 규칙에 의해 놓인 몇몇을 포함하여 특징의 수를 무능하게 합니다.

페이지 규칙은 클라이언트 투 노동자 요청 단계 (단계 2) 및 노동자 잠수함 단계 (단계 5)에서 모두 평가됩니다.

Workers를 실행할 때 페이지 규칙 오류를 경험하는 경우, Cloudflare 계정 팀에 문의하거나[Cloudflare 지원](/support/contacting-cloudflare-support/).

:::카ution\[테스트]

Workers 런타임의 지속적인 변화로 인해 이러한 규칙에 대한 자세한 문서는 테스트에 따라 업데이트됩니다.

:::

이 페이지 규칙을 배우려면, 참조[페이지 규칙](/rules/page-rules/).

:::note\[기타 영역]

동일한 영역 subrequest는 Worker가 같은 영역에서 오렌지 클라우드 호스트 이름으로 작업자가 실행됩니다. DNS 구성에 따라 정의가 Cloudflare 네트워크에 의해 다른 영역 요청으로 간주 될 수 있음을 제외한 모든 요청.

:::

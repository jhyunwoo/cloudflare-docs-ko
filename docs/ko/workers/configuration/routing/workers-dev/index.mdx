Cloudflare Workers 계정이 함께 제공됩니다`workers.dev`Cloudflare dashboardXQ에서 구성할 수 있는 subdomain. 내 계정`workers.dev`subdomain을 사용하면 WorkersXQ를 배포하여 빠르게 시작할 수 있습니다.

생산 Workers를 실행하는 것이 좋습니다[Workers 노선 또는 사용자 정의 도메인](/workers/configuration/routing/), 오히려 당신의 것에`workers.dev`하위 도메인. 내 계정`workers.dev`subdomain는 대우됩니다[무료 웹사이트](https://www.cloudflare.com/plans/)개인 또는 취미 프로젝트가 아닌 비즈니스를 위한 것입니다.

## 설정하기`workers.dev`

`workers.dev`subdomains는 형식을 가지고:`<YOUR_ACCOUNT_SUBDOMAIN>.workers.dev`. 변경하기 위하여`workers.dev`하위 도메인:

1. Cloudflare dashboard에서, 갑니다**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />

2. 제품정&#xBCF4;**- 기타**이름 \***당신의 subdomain**.

모든 Workers는 할당됩니다`workers.dev`구문을 따르거나 이름을 바꾸는 경로`<YOUR_WORKER_NAME>.<YOUR_SUBDOMAIN>.workers.dev`·[`name`](/workers/wrangler/configuration/#inheritable-keys)작업자 구성의 필드는 배치 된 노동자에 대한 하위 도메인으로 사용됩니다.

## 자주 묻는 질문`workers.dev`

지원할 때`workers.dev`URL은 공개적으로 사용할 수 있습니다. 사용 가능[모델 번호: Cloudflare 오시는 길](/cloudflare-one/access-controls/policies/)미리보기 URL에 액세스하기 전에 인증하는 방문자가 필요합니다. 당신은 자신에 대한 액세스를 제한 할 수 있습니다, 당신의 팀원, 조직, 또는 다른 사람에 지정[본문 바로가기](/cloudflare-one/access-controls/policies/).

제한하기`workers.dev`URL은 이메일만 허용됩니다:

1. Cloudflare dashboard에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />

2. 내 계정**제품정보**, 당신의 노동자를 선정하십시오.

3. 오시는 길**계정 설정** > **도메인 및 경로**.

4. 제품 정보`workers.dev`, 클릭**유효한 Cloudflare 오시는 길**.

5. 선택적으로, 액세스 응용 프로그램을 구성하려면, 클릭**Cloudflare 관리 오시는 길**. 제출하려는 이메일 주소를 변경할 수 있습니다. - 연혁[오시는 길](/cloudflare-one/access-controls/policies/#selectors)변경된 규칙을 설정하는 것에 대해 알아보세요.

6. [액세스 JWT 유효](https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/validating-json/#cloudflare-workers-example)청중을 사용하여 작업자 스크립트에서 (`aud`) 태그 및 JWKs URL 제공.

## 지원하다`workers.dev`

### 지원하다`workers.dev`dashboard

사용 방법`workers.dev`노동자를위한 경로:

1. Cloudflare dashboard에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />

2. 내 계정**제품정보**, 당신의 노동자를 선정하십시오.

3. 오시는 길**계정 설정** > **도메인 및 경로**.

4. 이름 \*`workers.dev`"Disable"을 클릭하십시오.

5. 당신이 비활성화하려면.

### 지원하다`workers.dev`Wrangler 설정 파일

사용 방법`workers.dev`노동자의 경로는 노동자의 다음을 포함[Wrangler 구성 파일](/workers/wrangler/configuration/):

<WranglerConfig>
  ```jsonc
  {
  	"workers_dev": false
  }
  ```
</WranglerConfig>

이 변화로 노동자를 돌릴 때,`workers.dev`경로가 비활성화됩니다. 당신의 도움`workers.dev`경로는 미리보기 URL을 비활성화하지 않습니다. 자주 묻는 질문[비활성화 미리보기 URL](/workers/configuration/previews/#disabling-preview-urls).

지정하지 않는 경우`workers_dev = false`하지만 추가[`routes`제품정보](/workers/wrangler/configuration/#routes)내 계정[Wrangler 구성 파일](/workers/wrangler/configuration/), 값의`workers_dev`일 것입니다`false`다음 배포에.

:::카트로션

당신은 당신의 잘못`workers.dev`Cloudflare QXdashboard에 있는 노선은 그러나 당신의 노동자의 Wrangler 파일을 가진 새롭게 하지 않습니다`workers_dev = false`·`workers.dev`경로는 Wrangler로 노동자를 배치하는 다음 시간을 다시 활성화됩니다.

## 제한 사항

Worker를 배포할 때`workers.dev`subdomain 활성화, 작업자는 다음 요구 사항을 충족해야합니다:

- 63자 이하
- 알파벳만 포함해야 합니다 ()`a-z`, `A-Z`, `0-9`)와 dashes (`-`)
- dash로 시작하거나 종료 할 수 없습니다 (`-`)

이 제한은 Worker 이름이 DNS 라벨로 사용되기 때문에 적용됩니다.`workers.dev`URL. DNS 라벨은 최대 길이 63 문자를 가지고 있으며 dash로 시작하거나 종료 할 수 없습니다.

:::참조

노동자 이름은 사용할 때 최대 255 문자 수 있습니다.`workers.dev`하위 도메인. 더 긴 이름이 필요하면 비활성화 할 수 있습니다.`workers.dev`관련 기사[오시는 길](/workers/configuration/routing/routes/)또는[주문 영역](/workers/configuration/routing/custom-domains/)대신.

:::

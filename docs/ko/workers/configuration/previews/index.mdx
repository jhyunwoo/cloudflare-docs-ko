# 제품정보

미리보기 URL을 사용하면 생산에 배포하지 않고 작업자의 새로운 버전을 미리 볼 수 있습니다.

미리보기 URL의 두 가지 유형이 있습니다.

- **버전 미리보기 URL**: 작업자의 각 새 버전에 대한 고유 URL 생성.
- **별명 미리보기 URL**: 작업자 버전에 수동으로 할당 할 수있는 정적 인 인간 읽기 가능한 별.

두 미리보기 URL 유형은 형식을 따릅니다:`<VERSION_PREFIX OR ALIAS>-<WORKER_NAME>.<SUBDOMAIN>.workers.dev`.

미리보기 URL은:

- CI/CD 파이프라인에 통합되어 모든 풀 요청에 대한 미리보기 환경을 자동 생성 할 수 있습니다.
- 팀 간의 협업을 위해 라이브 환경에서 코드 변경을 테스트하고 업데이트 확인.
- 새로운 API 엔드포인트를 테스트하는 데 사용, 데이터 형식을 검증, 기존 서비스에 백워드 호환성을 보장합니다.

버전의 영역 수준 성능 또는 보안 기능을 테스트 할 때, 우리는 사용하는 것이 좋습니다[버전 overrides](/workers/configuration/versions-and-deployments/gradual-deployments/#version-overrides)귀하의 영역의 성능과 보안 설정이 적용됩니다.

:::참조
미리보기 URL은 2024-09-25 이후에 업로드된 Worker 버전에서만 사용할 수 있습니다.
주요 특징

## 미리보기 URL의 유형

### 버전 미리보기 URL

새로운 것을 만들 때마다[이름 \*](/workers/configuration/versions-and-deployments/#versions)작업자의 고유 한 정적 버전 미리보기 URL이 자동으로 생성됩니다. 이 URL은 버전 접두사를 사용하고 형식을 따르십시오.`<VERSION_PREFIX>-<WORKER_NAME>.<SUBDOMAIN>.workers.dev`.

작업자의 새로운 버전은 실행할 때 생성됩니다.

- [`wrangler deploy`](/workers/wrangler/commands/#deploy)
- [`wrangler versions upload`](/workers/wrangler/commands/#versions-upload)
- 또는 Cloudflare dashboard를 통해 편집을 할 때

미리보기 URL이 활성화되면 버전 생성 후 즉시 공개 및 사용할 수 있습니다.

:::참조
최소 필요한 Wrangler 버전: 3.74.0. 실행하여 버전 확인`wrangler --version`. Wrangler를 업데이트하려면, 참조[설치/업데이트 Wrangler](/workers/wrangler/install-and-update/).
:::

#### Wrangler

더 보기[`wrangler versions upload`](/workers/wrangler/commands/#versions-upload)명령 새 업로드[이름 \*](/workers/configuration/versions-and-deployments/#versions)당신의 노동자의 업로드 각 버전 미리보기 URL을 반환합니다.

#### Workers dashboard에 버전 미리보기 URL보기

1. Cloudflare dashboard에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />

2. 당신의 노동자를 선택하십시오.

3. 오시는 길**계정 만들기**탭을 찾아보기를 원하는 버전을 찾을 수 있습니다.

### 별표 URL

Aliased 미리보기 URL은 특정 작업자 버전에 persistent, readable alias를 할당할 수 있습니다. 이러한 많은 버전 (예를 들어, 곧 공유하지만 여전히 새로운 기능을 개발)의 안정적인 미리보기에 연결에 유용합니다. 일반적인 작업 흐름은 작업중인 지점의 별명을 할당할 것입니다. 미리보기 URL의 이러한 유형은 다른 미리보기 URL과 동일한 패턴을 따릅니다.
`<ALIAS>-<WORKER_NAME>.<SUBDOMAIN>.workers.dev`

:::참조
최소 필요한 Wrangler 버전:`4.21.0`. 실행하여 버전 확인`wrangler --version`. Wrangler를 업데이트하려면, 참조[설치/업데이트 Wrangler](/workers/wrangler/install-and-update/).
:::

#### Alias 만들기

Aliases는 도중 창조될지도 모릅니다`versions upload`, 제공`--preview-alias`유효한 별명으로 깃발:

```bash
wrangler versions upload --preview-alias staging
```

resulting alias는이 버전과 관련 될 것이며, 즉시 다음에서 사용할 수 있습니다.
`staging-<WORKER_NAME>.<SUBDOMAIN>.workers.dev`

#### 규칙 및 제한

- Aliases는 버전 업로드 중 만 생성 될 수 있습니다.
- Aliases는 낮은 케이스 문자, 숫자 및 dashes만 사용해야합니다.
- Aliases는 더 낮은 케이스 문자로 시작해야합니다.
- alias 및 Worker name 결합 (dash 포함) DNS 라벨 제한으로 인해 63 문자를 초과하지 않아야합니다.
- 가장 최근에 배포 된 별칭 만 유지됩니다. 새로운 별명이 이 한계를 넘어 창조될 때, 최근에 배치된 별명은 삭제됩니다.

## 미리보기 URL에 대한 액세스를 관리

활성화되면 모든 미리보기 URL이 공개됩니다. 사용 가능[Cloudflare 오시는 길](/cloudflare-one/access-controls/policies/)미리보기 URL에 액세스하기 전에 인증하는 방문자가 필요합니다. 당신은 자신에 대한 액세스를 제한 할 수 있습니다, 당신의 팀원, 조직, 또는 다른 사람에 지정[본문 바로가기](/cloudflare-one/access-controls/policies/).

미리 URL을 인증된 이메일에 제한하려면:

1. Cloudflare dashboard에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />

2. 내 계정**제품정보**, 당신의 노동자를 선정하십시오.

3. 오시는 길**계정 설정** > **도메인 및 경로**.

4. 미리보기 URL의 경우, 클릭**유효한 Cloudflare 오시는 길**.

5. 선택적으로, 액세스 응용 프로그램을 구성하려면, 클릭**Cloudflare 관리 오시는 길**. 제출하려는 이메일 주소를 변경할 수 있습니다. - 연혁[오시는 길](/cloudflare-one/access-controls/policies/#selectors)변경된 규칙을 설정하는 것에 대해 알아보세요.

6. [액세스 JWT 유효](https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/validating-json/#cloudflare-workers-example)청중을 사용하여 작업자 스크립트에서 (`aud`) 태그 및 JWKs URL 제공.

## 토글 미리보기 URL (Enable or Disable)

참고 :

- 미리보기 URL은 기본적으로 활성화됩니다.`workers_dev`지원하다
- 미리보기 URL은 기본적으로 비활성화됩니다.`workers_dev`이용안내
- 미리보기 URL을 해제하면 버전과 별표 미리보기 URL을 모두 해제할 수 있습니다.

### Dashboard에서

toggle 미리보기 URLs for Worker:

1. Cloudflare dashboard에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />

2. 내 계정**제품정보**, 당신의 노동자를 선정하십시오.

3. 오시는 길**계정 설정** > **도메인 및 경로**.

4. 미리보기 URL의 경우, 클릭**이름 \***&#xB610;는**사용 방법**.

5. 자주 묻는 질문

### 에 의해[Wrangler 구성 파일](/workers/wrangler/configuration/)

:::참조
Wrangler 3.91.0 이상은 이 기능을 사용해야합니다.
주요 특징

:::참조
이전 Wrangler 버전은 기본적으로 미리보기 URL을 활성화합니다.
주요 특징

노동자를 위한 toggle 미리보기 URL에, 노동자의 Wrangler 파일에서 뒤에 오는 것:

<WranglerConfig>
  ```jsonc
  {
  	"preview_urls": true
  }
  ```
</WranglerConfig>

<WranglerConfig>
  ```jsonc
  {
  	"preview_urls": false
  }
  ```
</WranglerConfig>

하지 않은 경우,`preview_urls = workers_dev`기본값입니다.

:::카트로션
Cloudflare QXdashboard에서 미리보기 URL을 활성화하거나 비활성화하면 작업자의 WranglerXQ 파일을 업데이트하지 마십시오. 미리보기 URL 상태는 WranglerXQ로 작업자를 배치하는 다음 시간을 변경합니다.

## 제한 사항

- 미리보기 URL은 Workers를 위해 생성되지 않습니다.[튼튼한 목표](/durable-objects/).
- 미리보기 URL은 현재 생성되지 않습니다.[플랫폼을위한 Workers](/cloudflare-for-platforms/workers-for-platforms/) [사용자 Workers](/cloudflare-for-platforms/workers-for-platforms/how-workers-for-platforms-works/#user-workers). 이것은 임시 제한입니다, 우리는 그것을 제거하는 일입니다.
- 현재 미리 보기 URL을 구성할 수 없습니다.[`workers.dev`](/workers/configuration/routing/workers-dev/).
- 오늘 미리보기 URL에 대한 로그를 볼 수 없습니다, 이것은 Workers 로그, Wrangler 꼬리 및 Logpush가 포함되어 있습니다.

Cloudflare WorkersXQXQ에서 제3자 API와 통합하기 위하여는, 사용[페치 API](/workers/runtime-apis/fetch/)API endpoint에 HTTP 요청을 만들려면. 그런 다음 응답 데이터를 사용하여 컨텐츠를 수정하거나 조작하십시오.

예를 들어, 날씨 API와 통합하려면 API 엔드포인트에 fetch 요청을 만들고 현재 기상 데이터를 검색하십시오. 그런 다음이 데이터를 사용하여 웹 사이트에 현재 기상 조건을 표시합니다.

제품정보`fetch()`요청, 프로젝트의 다음 코드를 추가`src/index.js`파일 :

```js
async function handleRequest(request) {
	//제3자 API 엔드포인트에 fetch 요청을 만드십시오.
	const response = await fetch("https://weather-api.com/endpoint", {
		method: "GET",
		headers: {
			"Content-Type": "application/json",
		},
	});

	//응답에서 데이터를 검색
	const data = await response.json();

	//데이터를 사용하여 콘텐츠를 수정하거나 조작할 수 있습니다.
	return new Response(data);
}
```

## 인증현황

API가 인증이 필요하면 Wrangler 비밀을 사용하여 자격 증명을 안전하게 저장합니다. 이렇게하려면 다음을 사용하여 Cloudflare QXWorkers 프로젝트에서 비밀을 만듭니다.[`wrangler secret`](/workers/wrangler/commands/#secret)명령:

```sh
wrangler secret put SECRET_NAME
```

그런 다음 다음 다음 코드 스니펫을 사용하여 코드의 비밀 값을 검색하십시오.

```js
const secretValue = env.SECRET_NAME;
```

그런 다음 외부 서비스에 정통하는 비밀 값을 사용합니다. 예를 들어, 외부 서비스가 인증에 대한 API 키가 필요하면 요청 헤더에 포함됩니다.

mTLS 인증을 요구하는 서비스[mTLS 인증서](/workers/runtime-apis/bindings/mtls)클라이언트 인증서를 제시합니다.

## 제품 정보

- 사용 방법[캐시 API](/workers/runtime-apis/cache/)타사 API에서 데이터를 캐시합니다. API로 만든 캐시 가능한 요청을 최적화 할 수 있습니다. Cloudflare WorkersXQXQ에서 타사 API와 통합하여 응용 프로그램에 추가 기능과 기능을 추가합니다.

- 제품 정보[사용자 정의 도메인](/workers/configuration/routing/custom-domains/)외부 API로 communicating할 때, 당신의 핵심 신청으로 노동자를 대우하십시오.

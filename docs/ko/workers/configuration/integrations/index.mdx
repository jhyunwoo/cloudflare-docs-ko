QXQX0067XQQ Workers의 주요 특징의 한개는 다른 서비스 및 제품과 통합하는 기능입니다. 이 문서에서, 우리는 Cloudflare Workers와 함께 사용할 수있는 통합의 유형을 설명하고 그들을 사용하는 단계별 지침을 제공합니다.

## 통합 유형

Cloudflare Workers는 다음을 포함하여 몇몇 유형의 통합을 제안합니다:

- [데이터베이스](/workers/databases/): Cloudflare Workers는 SQL 및 NoSQL 데이터베이스를 포함한 다양한 데이터베이스와 통합 할 수 있습니다. QXQX0071XQQ QXWorkers 코드에서 데이터베이스에서 데이터를 저장하고 검색 할 수 있습니다.
- [API를](/workers/configuration/integrations/apis/): Cloudflare Workers는 외부 API와 통합하기 위하여 이용될 수 있고, 당신의 자신의 부호에 있는 그 APIs에 의해 드러낸 자료 및 기능을 이용할 수 있습니다.
- [제3자 서비스](/workers/configuration/integrations/external-services/): Cloudflare Workers는 결제 게이트웨이, 인증 제공업체 등과 같은 다양한 타사 서비스와 통합할 수 있습니다. Cloudflare QXWorkersXQ 코드에서 이러한 서비스를 사용할 수 있습니다.

## 통합을 사용하는 방법

사용 가능한 통합:

- 당신이 사용 하 고 그것을 위해 필요한 계정 및 자격 증명을 확인 하는 통합 결정.
- Cloudflare QXWorkers 코드에서 통합을 위한 필요한 라이브러리 또는 모듈을 가져옵니다.
- API 및 기능을 사용하여 통합 및 데이터 또는 기능에 액세스 할 수 있습니다.
- 필요한 비밀과 키를 사용하여 비밀을 통해[`wrangler secret put <KEY>`](/workers/wrangler/commands/#secret).

## 팁과 모범 사례

Cloudflare Workers와 통합을 사용하여 대부분의 통합을 얻을 수 있도록:

- 통합을 확보하고 민감한 데이터를 보호합니다. 보안 인증 및 권한 부여를 유지하고 가능한 라이브러리의 유효성을 보장하십시오.
- 제품 정보[뚱 베어](/workers/reference/how-the-cache-works)성능 향상 및 외부 서비스에 부하를 줄일 수 있습니다.
- Workers를 서비스 중심 아키텍처로 분할[서비스 바인딩](/workers/runtime-apis/bindings/service-bindings/)당신의 신청을 더 모듈, 유지하게 쉬운, 및 더 많은 performant 만들기 위하여.
- 제품 정보[사용자 정의 도메인](/workers/configuration/routing/custom-domains/)외부 API 및 서비스로 통신할 때, DNS 레코드를 대신하고 프록시 대신 애플리케이션으로 작업자를 치료할 수 있습니다.

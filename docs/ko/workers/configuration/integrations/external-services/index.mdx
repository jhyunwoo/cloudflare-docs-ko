많은 외부 서비스는 라이브러리 및 SDK를 제공하여 API와 상호 작용합니다. 많은 노드 호환 라이브러리가 Workers에 작업하는 동안, 어떤, 이는 구현`fs`, `http/net`, 또는 브라우저에 접근`window`직접 v8 기반 인 Workers 실행 시간에 번역하지 마십시오.

## 인증현황

귀하의 서비스가 인증이 필요하면 Wrangler 비밀을 사용하여 자격 증명을 안전하게 보관하십시오. 이렇게하려면 다음을 사용하여 Cloudflare QXWorkers 프로젝트에서 비밀을 만듭니다.[`wrangler secret`](/workers/wrangler/commands/#secret)명령:

```sh
wrangler secret put SECRET_NAME
```

그런 다음 다음 다음 코드 스니펫을 사용하여 코드의 비밀 값을 검색하십시오.

```js
const secretValue = env.SECRET_NAME;
```

그런 다음 외부 서비스에 정통하는 비밀 값을 사용합니다. 예를 들어, 외부 서비스가 인증에 대한 API 키가 필요하면 라이브러리의 구성에 비밀이 포함되어 있습니다.

mTLS 인증을 요구하는 서비스[mTLS 인증서](/workers/runtime-apis/bindings/mtls)클라이언트 인증서를 제시합니다.

제품 정보[사용자 정의 도메인](/workers/configuration/routing/custom-domains/)외부 API로 communicating할 때, 당신의 핵심 신청으로 노동자를 대우하십시오.

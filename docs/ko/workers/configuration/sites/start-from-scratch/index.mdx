이 가이드는 새로운 Workers를 시작하는 방법을 보여줍니다 처음부터 프로젝트.

## 시작하기

1. 최신 버전의 유지[사이트맵](https://git-scm.com/downloads)·[모델 번호: Node.js](https://nodejs.org/en/download/)설치.

2. 당신의 맨끝에서, clone`worker-sites-template`스타터 저장소.
   다음 예제는 프로젝트가 호출됩니다.`my-site`:

   ```sh
   git clone --depth=1 --branch=wrangler2 https://github.com/cloudflare/worker-sites-template my-site
   ```

3. 지원하다`npm install`모든 의존도를 설치합니다.

4. 사이트를 미리 볼 수 있습니다.[`wrangler dev`](/workers/wrangler/commands/#dev)명령:

   ```sh
   wrangler dev
   ```

5. Cloudflare에 사이트 배포:

   ```sh
   npx wrangler deploy
   ```

## 프로젝트 레이아웃

템플릿 프로젝트는 다음과 같은 파일과 디렉토리를 포함합니다:

- `public`: 프로젝트의 정적 자산. 기본적으로 그것은 포함`index.html`·`favicon.ico`.
- `src`: 자산을 제공하기위한 작업자. 당신은 이것을 편집할 필요가 없습니다 그러나 그것이 작동하는 방법을 보고 싶은 경우에 또는 당신의 노동자에 더 많은 기능을 추가하십시오, 당신은 편집할 수 있습니다`src/index.ts`.
- `wrangler.jsonc`: 프로젝트 구성을 포함하는 파일.
  더 보기`bucket`속성은 정적 자산을 찾기 위해 Wrangler를 말한다 (예 :`site = { bucket = "./public" }`).
- `package.json`/`package-lock.json`: 필수 Node.js 의존성을 정의합니다.

## 사용자 정의`wrangler.jsonc`파일 :

- 수정하기`name`프로젝트의 이름에 재산:

  <WranglerConfig>
    ```jsonc
    {
      "$schema": "./node_modules/wrangler/config-schema.json",
      "name": "my-site"
    }
    ```
  </WranglerConfig>

- 자주 묻는 질문`compatibility_date`최신 Workers 기능에 액세스 할 수있는 오늘의 날짜 :

  <WranglerConfig>
    ```jsonc
    {
      "compatibility_date": "yyyy-mm-dd"
    }
    ```
  </WranglerConfig>

- 사이트에 배포[사용자 정의 도메인](/workers/configuration/routing/custom-domains/)당신이 소유하고 이미 Cloudflare 지역으로 붙어:

  <WranglerConfig>
    ```jsonc
    {
      "route": "https://example.com/*"
    }
    ```
  </WranglerConfig>

  :::참조

  문서에 대한 참조[오시는 길](/workers/configuration/routing/routes/)설정하기`route`견적 요청

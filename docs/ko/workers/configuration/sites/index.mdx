Workers 사이트는 개발자가 Workers에 직접 정적 응용 프로그램을 배포 할 수 있습니다. 그것은 정체되는 위치 발전기로 건설한 신청을 위해 사용될 수 있습니다[채용 정보](https://gohugo.io)·[인기 있는](https://www.gatsbyjs.org), 또는 프런트 엔드 프레임 같은[Vue](https://vuejs.org)·[모델 번호: React](https://reactjs.org).

Workers 사이트, 대상 프로젝트의 상태에 따라 이러한 세 가지 접근 중 하나를 선택:

***

## 1. 처음부터 시작

새로운 프로젝트를 시작할 준비가 된 경우, 이 빠른 시작 가이드는 HTML 웹 사이트를 Workers에 배포하는 인프라를 설정하는 데 도움이 될 것입니다.

<LinkButton href="/workers/configuration/sites/start-from-scratch/">
  처음부터 시작
</LinkButton>

***

## 2. 기존 정적 사이트 배포

WorkersXQ로 배포하려는 기존 프로젝트 또는 정적 자산이 있다면, 이 빠른 시작 가이드는 Wrangler를 설치하고 WorkersXQXQXQXQXQ를 구성하는 데 도움이 될 것입니다. 프로젝트의 현장.

<LinkButton href="/workers/configuration/sites/start-from-existing/">
  기존 정적 사이트에서 시작
</LinkButton>

***

## 3. 기존 Workers 프로젝트에 정적 자산 추가

이미 Cloudflare에 배포 된 노동자가 있다면,이 빠른 시작 가이드는 Workers 사이트를 사용하는 기존 코베이스를 구성하는 방법을 보여줍니다.

<LinkButton href="/workers/configuration/sites/start-from-worker/">
  기존 Worker에서 시작
</LinkButton>

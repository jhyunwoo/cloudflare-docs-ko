Cloudflare Vite 플러그인은 기본적으로 활성화되어 포트에 들립니다.`9229`·
사용자 정의 포트 또는 디버깅을 선택 할 수 있습니다.`inspectorPort`옵션에서[플러그인 구성](/workers/vite-plugin/reference/api#interface-pluginconfig)·
로컬 개발 중에 Workers를 디버깅하기위한 두 가지 권장 방법이 있습니다.

## 다운로드

현재 위치`vite dev`또는`vite preview`·`/__debug`경로가 추가됩니다.[Cloudflare의 구현](https://github.com/cloudflare/workers-sdk/tree/main/packages/chrome-devtools-patches)이름 \*[크롬의 DevTools](https://developer.chrome.com/docs/devtools/overview)·
이 루트로 이동하면 응용 프로그램에서 WorkersXQ의 각각의 DevTools 탭을 엽니다.

탭(s)가 열리면 애플리케이션에 요청을 만들고 작업자 코드를 디버깅할 수 있습니다.

:::참조
여러 WorkersXQ를 디버깅하면 브라우저가 팝업을 엽니다.
주요 특징

## VS 코드

설정하기[VS 코드](https://code.visualstudio.com/)당신의 응용 프로그램에서 breakpoint 디버깅을 지원하려면, 당신은 만들해야합니다`.vscode/launch.json`다음 구성을 포함하는 파일:

```json title=".vscode/launch.json"
{
	"configurations": [
		{
			"name": "<NAME_OF_WORKER>",
			"type": "node",
			"request": "attach",
			"websocketAddress": "ws://localhost:9229/<NAME_OF_WORKER>",
			"resolveSourceMapLocations": null,
			"attachExistingChildren": false,
			"autoAttachChildProcesses": false,
			"sourceMaps": true
		}
	],
	"compounds": [
		{
			"name": "Debug Workers",
			"configurations": ["<NAME_OF_WORKER>"],
			"stopAll": true
		}
	]
}
```

이름 \*`<NAME_OF_WORKER>`Worker config 파일에 지정된 Worker의 이름을 나타냅니다.
사용중인 경우`inspectorPort`사용자 정의 포트를 설정할 수있는 옵션이 제공 된 값이어야합니다.`websocketaddress`이름 \*

:::참조
응용 프로그램에 한 명 이상의 노동자가 있다면 구성을 추가해야합니다.`configurations`각 필드는 구성 이름을 포함`compounds` `configurations`배열.
주요 특징

이 설정으로 실행할 수 있습니다.`vite dev`또는`vite preview`다음 선택**디버그 Workers**맨 위로**실행 및 디버그**debugging를 시작하는 패널.

이 튜토리얼에서 Cloudflare QXWorkersXQ 응용 프로그램을 만들고 MySQL 데이터베이스에 연결하는 방법을 배울 것입니다.[TCP 소켓](/workers/runtime-apis/tcp-sockets/)·[모델 번호: Hyperdrive](/hyperdrive/). 이 튜토리얼에서 생성하는 Workers 응용 프로그램은 MySQL 내부의 제품 데이터베이스와 상호 작용합니다.

:::주\[주]

자주 묻는 질문[모델 번호: Hyperdrive](/hyperdrive/)MySQL 데이터베이스에 연결하기. Hyperdrive는 최선 성과를 제공하고 당신의 노동자와 당신의 MySQL 데이타베이스 사이 안전한 연결을 지킬 것입니다.

MySQL 데이터베이스에 직접 연결하면 (Hyperdrive 없이), MySQL 드라이버가 지원되지 않은 Node.js API에 의존하여 연결을 방지합니다.
주요 특징

## 자주 묻는 질문

계속하려면:

1. 로그인[Cloudflare 계정](https://dash.cloudflare.com/sign-up/workers-and-pages)이미 없다면.
2. 설치하기[`npm`](https://docs.npmjs.com/getting-started).
3. 설치하기[`Node.js`](https://nodejs.org/en/). Node version Manager를 사용하여[볼트](https://volta.sh/)또는[사이트맵](https://github.com/nvm-sh/nvm)허가 문제를 방지하고 Node.js 버전을 변경하십시오.[모델 번호: Wrangler](/workers/wrangler/install-and-update/)Node 버전이 필요합니다.`16.17.0`또는 나중에.
4. MySQL 데이터베이스에 액세스해야 합니다.

## 3. Hyperdrive 구성

MySQL 데이터베이스의 연결 문자열을 사용하여 Hyperdrive 구성을 만듭니다.

```bash
npx wrangler hyperdrive create <NAME_OF_HYPERDRIVE_CONFIG> --connection-string="mysql://user:password@HOSTNAME_OR_IP_ADDRESS:PORT/database_name"
```

이 명령은 Hyperdrive 설정 출력`id`Hyperdrive[관련 제품](/workers/runtime-apis/bindings/). 바인딩을 지정하여 설정`id`Wrangler 파일에서.

<WranglerConfig>
  ```jsonc
  {
  	"$schema": "./node_modules/wrangler/config-schema.json",
  	"name": "hyperdrive-example",
  	"main": "src/index.ts",
  	"compatibility_date": "$today",
  	"compatibility_flags": [
  		"nodejs_compat"
  	],
  	//`wrangler hyperdrive create <NAME_OF_HYPERDRIVE_CONFIG> --connection-string=[...]`의 출력에서 붙여 넣으십시오.
  	"hyperdrive": [
  		{
  			"binding": "HYPERDRIVE",
  			"id": "<ID OF THE CREATED HYPERDRIVE CONFIGURATION>"
  		}
  	]
  }
  ```
</WranglerConfig>

## 5. 작업자를 배포

다음 명령을 실행하여 노동자를 배치하십시오.

```sh
npx wrangler deploy
```

당신의 응용 프로그램은 지금 살고 접근 가능`<YOUR_WORKER>.<YOUR_SUBDOMAIN>.workers.dev`.

## 안녕하세요 Cloudflare Workers

놀이터에 도착하면이 기본 코드를 볼 수 있습니다.

```js
import welcome from "welcome.html";

/** 이름
* @typedef {Object} 엔브*/

export default {
	/** 이름
* @param {Request} 요청
* @param {Env} 파일
* @param {ExecutionContext} ctx
* @returns {책임}*/
	fetch(request, env, ctx) {
		console.log("Hello Cloudflare Workers!");

		return new Response(welcome, {
			headers: {
				"content-type": "text/html",
			},
		});
	},
};
```

이것은 멀티 모듈 노동자의 예입니다.[이름 \*](/workers/runtime-apis/request/), 콘솔에 메시지를 기록하고, 그 후에 반환[이름 \*](/workers/runtime-apis/response/)본문내용 바로가기`welcome.html`.

더 알아보기[Fetch handler 문서](/workers/runtime-apis/handlers/fetch/)더 알아보기.

## 놀이터 사용

기본적으로 코드를 편집하면, Worker는 브라우저에서 실행되는 작업자의 미리보기와 같은 자동 업데이트됩니다. 작업자가 URL 경로를 사용한다면, 올바른 입력 필드에 입력할 수 있습니다. 놀이터는 JSDoc 의견을 통해 유형 검사를 제공합니다[`workers-types`](https://www.npmjs.com/package/@cloudflare/workers-types). 놀이터는 애플리케이션 오류의 이벤트에서 꽤 오류 페이지를 제공합니다.

HTTP 요청을 테스트하려면 (예를 들면, 테스트`POST`요청), 이동**HTTP: HTTP**탭 및 선택**이름 \***. 이 패널을 통해 headers를 추가하고 편집 할 수 있으며 요청의 몸을 편집 할 수 있습니다.

## 로그 뷰어

놀이터와 Workers dashboard의 빠른 편집기는 미리보기 패널의 하단에 가벼운 로그 뷰어를 포함합니다. log viewer는 모든 통화의 출력을 표시합니다.`console.log`미리보기 실행 중에 만든.

로그 뷰어는 다음을 지원합니다:

- Logging primitive 값, 객체, 배열.
- 실행 사이에 로그 출력을 삭제합니다.

현재 로그 뷰어는 로그 클래스 인스턴스 또는 속성을 지원하지 않습니다 (예를 들어,`request.url`).

전체 디버깅 기능을 갖춘 더 많은 개발 경험이 필요한 경우, 사용할 수 있습니다.[모델 번호: Wrangler](/workers/wrangler/install-and-update/)한국어 로컬 개발을위한 dashboard에서 기존 작업자를 복제하려면 가입 및 사용[`wrangler init --from-dash`](/workers/wrangler/commands/#init)일단 작업자가 배치되면 명령.

## 지원하다

당신이 만든 것을 공유하려면, 선택**링크 복사**화면 오른쪽 상단에. 이것은 누구와 공유 할 수있는 클립 보드에 독특한 URL을 복사합니다. 이 링크는 만료되지 않습니다, 그래서 당신은 당신의 창조를 북마크하고 언제든지 공유 할 수 있습니다. 공유 링크를 열 사용자는 공유 코드와 미리보기로 놀이터를 볼 수 있습니다.

## 계정 만들기

놀이터에서 노동자를 배치 할 수 있습니다. 이미 로그인한 경우, 배포하기 전에 Worker를 검토할 수 있습니다. 그렇지 않으면, 리뷰 및 배포하기 전에 첫 번째 사용자 온보드 흐름을 통해 이동합니다.

배포되면 Worker는 자신의 고유 URL을 얻을 것이며 Cloudflare의 글로벌 네트워크에서 거의 즉시 사용할 수 있습니다. 여기에서 추가할 수 있습니다.[사용자 정의 도메인](/workers/configuration/routing/custom-domains/), [저장 자원](/workers/platform/storage-options/), 더 많은 것.

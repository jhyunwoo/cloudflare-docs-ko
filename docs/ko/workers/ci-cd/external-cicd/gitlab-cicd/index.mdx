Workers를 배포할 수 있습니다.[프로젝트](https://docs.gitlab.com/ee/ci/pipelines/index.html). Gitlab CI/CD 파이프라인을 설정할 수 있는 방법은 다음과 같습니다.

## 1. 인증

로컬로 Wrangler를 실행하면 Cloudflare API에 인증이 진행됩니다.[`wrangler login`](/workers/wrangler/commands/#login)대화 형 인증 흐름을 시작 하는 명령. CI/CD 환경이 비동기이기 때문에, Wrangler는 요구합니다[Cloudflare API 토큰](/fundamentals/api/get-started/create-token/)·[계정 ID](/fundamentals/account/find-account-and-zone-ids/)Cloudflare API로 인증

### Cloudflare 계정 ID

Cloudflare 계정 ID를 찾으려면, 참조[계정 및 영역 ID 찾기](/fundamentals/account/find-account-and-zone-ids/).

### API 토큰

Wrangler를 인증하는 API 토큰을 만들려면:

1. Cloudflare dashboard에서, 갑니다**계정 API 토큰**사이트 맵

   <DashButton url="/?to=/:account/api-tokens" />

2. 제품정보**토큰 만들기**> 찾기**Cloudflare Workers**> 선택**템플릿 사용**.

3. 토큰 이름을 지정합니다.

4. 토큰 선택

생성 된 API 토큰이 액세스 할 수있는 계정 및 영역 리소스를 선택할 필요가 있습니다. 토큰의 접근을 제한할 수 있기 때문에 이러한 다운을 활용할 수 있습니다. 예를 들어, Cloudflare 계정에 액세스 할 경우 생성 된 API 토큰을 Worker를 배포 할 수있는 계정에 제한해야합니다.

## 2. CI 설정

CI/CD 환경에서 Wrangler를 실행하는 방법은 프로젝트의 특정 설정에 따라 달라집니다 ( GitHub Actions/Jenkins/GitLab 또는 다른 모든 것을 사용).

CI를 설정하려면:

1. CI 플랫폼으로 이동하고 비밀로 다음을 추가하십시오.

- `CLOUDFLARE_ACCOUNT_ID`: 설정[Cloudflare 계정 ID](#cloudflare-account-id)당신의 노동자를 배치하려는 계정에 대한.
- `CLOUDFLARE_API_TOKEN`: 설정[Cloudflare API 토큰 생성](#api-token).

:::카트로션

의 가치를 저장하지 마십시오`CLOUDFLARE_API_TOKEN`귀하의 저장소에, 그것은 귀하의 계정에 Workers을 배포하는 액세스 권한을 부여. 대신 비밀을 저장하기 위해 CI/CD 공급자의 지원을 활용해야 합니다.
주요 특징

2. Worker를 배포할 수 있는 작업 흐름을 만듭니다. 이 작업은 실행되어야 합니다.`wrangler deploy`. 보기[GitHub 작업](https://docs.github.com/en/actions/using-workflows/about-workflows)다음 섹션에서 작업 흐름.

### GitLab 파이프 라인

더 알아보기[GitLab의 블로그](https://about.gitlab.com/blog/2022/11/21/deploy-remix-with-gitlab-and-cloudflare/)예를 들어 파이프라인. 이름 \*`script`키, 교체`npm run deploy`이름 \*[`npx wrangler deploy`](/workers/wrangler/commands/#deploy).

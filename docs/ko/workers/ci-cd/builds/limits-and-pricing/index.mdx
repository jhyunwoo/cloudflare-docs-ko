모델 번호: Workers 빌드에는 다음과 같은 제한이 있습니다.

| 기본 정보          | 무료 플랜     | 유료 계획                         |
| -------------- | --------- | ----------------------------- |
| **몇 분**        | 달 당 3,000 | 달 당 6,000 (그 후에, 분 당 +$0.005) |
| **동시 구축**      | 1         | 6                             |
| **타임 아웃**      | 20 분      | 20 분                          |
| **CPU의 CPU**   | 2개의 vCPU  | 4개의 vCPU                      |
| **기억하기**       | 8개 GB     | 8개 GB                         |
| **디스크 공간**     | 20GB 이상   | 20GB 이상                       |
| **환경 변수**      | 64        | 64                            |
| **환경 변수 당 크기** | 5개 KB     | 5개 KB                         |

## 이름 \*

- **몇 분**: 프로젝트를 구축하는 데 걸리는 분의 양.
- **동시 구축**: 계정에서 병렬로 실행할 수 있는 빌드 수.
- **타임 아웃**: 빌드가 종료되기 전에 실행될 수 있는 시간의 양.
- **사이트맵**: CPU 코어의 수는 빌드에 사용할 수 있습니다.
- **기억하기**: 당신의 빌드에 사용할 수있는 메모리의 양.
- **디스크 공간**: 당신의 빌드에 사용할 수있는 디스크 공간의 양.
- **환경 변수**: Worker 당 구성할 수 있는 사용자 정의 환경 변수 수.
- **환경 변수 당 크기**: 각 개별 환경 변수의 최대 크기.

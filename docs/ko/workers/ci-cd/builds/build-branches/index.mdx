Workers에 git 저장소를 연결하면 생산 git 지점에서 만든 커밋이 Workers 빌드를 생성합니다. 당신이 장점을 가지고 싶다면[URL 미리보기](/workers/configuration/previews/)·[풀 요청 코멘트](/workers/ci-cd/builds/git-integration/github-integration/#pull-request-comment), 당신은 추가 할 수 있습니다 "비 생산 지점 빌드" 당신의 저장소의 모든 지점에 구축을 트리거하기 위해.

## 회사연혁

프로젝트의 생산 지점을 변경하려면:

1. 내 계정**제품정보**Workers 프로젝트를 선택하십시오.
2. 오시는 길**계정 설정** > **제품정보** > **지점제어**. Workers는 당신의 git 저장소의 기본 분지에 과태될 것입니다, 그러나 이것은 dropdown에서 바뀔 수 있습니다.

이 지점으로 만든 모든 푸시 이벤트는 빌드를 트리거하고 실행합니다.[빌드 명령](/workers/ci-cd/builds/configuration/#build-command), 다음으로[배포 명령](/workers/ci-cd/builds/configuration/#deploy-command).

## Non-production Branch 구축

non-production 브랜딩을 활성화하거나 비활성화하려면:

1. 내 계정**제품정보**Workers 프로젝트를 선택하십시오.
2. 오시는 길**계정 설정** > **제품정보** > **지점제어**. 체크박스**비 생산 지점을 위한 빌드**non-production 브랜딩을 활성화하거나 비활성화할 수 있습니다.

활성화되면, 모든 푸시 이벤트가 비 생산 지점으로 만들어 빌드를 트리거하고 실행합니다.[빌드 명령](/workers/ci-cd/builds/configuration/#build-command), 다음으로[non-production 분기 배포 명령](/workers/ci-cd/builds/configuration/#non-production-branch-deploy-command).

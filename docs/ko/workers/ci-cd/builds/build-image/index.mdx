Workers 빌드는 Node.js, Python, PHP, Ruby 및 Go와 같은 다양한 언어 및 도구를 지원하는 빌드 이미지를 사용합니다.

## 지원 툴링

Workers 빌드는 다양한 런타임, 언어 및 도구를 지원합니다. Builds는 사용자 정의 버전이 감지되거나 지정되지 않는 한 아래에 나열된 기본 버전을 사용합니다. 당신은 할 수[기본 버전 무시](/workers/ci-cd/builds/build-image/#overriding-default-versions)환경변수 또는 버전 파일을 사용하여. 모든 버전은 override에 사용할 수 있습니다.

:::note\[기본 버전 업데이트]
기본 버전은 최신 버전에 정기적으로 업데이트됩니다. 주요 버전 업데이트가 없습니다. 특정 미성년자 버전이 필요한 경우, 지정해 주세요.[기본 버전 overriding](/workers/ci-cd/builds/build-image/#overriding-default-versions).
:::

## 고급 설정

### Overriding 기본 버전

당신이 override 필요하면[특정 버전](/workers/ci-cd/builds/build-image/#overriding-default-versions)이미지 내에서 언어 또는 도구의 경우 지정할 수 있습니다.[환경 변수](/workers/ci-cd/builds/configuration/#build-settings), 또는 위에 표시된 것과 같이 소스 코드에 관련된 파일을 설정합니다.

빌드 환경 변수를 사용하여 버전을 설정하려면 다음을 할 수 있습니다.

1. 언어 또는 도구 및 원하는 버전의 환경 변수 이름을 찾습니다 (e.g.`NODE_VERSION = 22`)
2. dashboard에 환경 변수를 추가하고 저장**계정 설정** > **제품정보** > **변수 및 비밀 구축**Workers 프로젝트

또는, 당신의 프로젝트에 파일을 추가하여 버전을 설정하려면, 당신은 할 수:

1. 언어 또는 도구의 파일명 찾기 (e.g.`.nvmrc`)
2. 지정된 파일 이름을 루트 디렉토리에 추가하고 원하는 버전 번호를 파일의 내용으로 설정합니다. 예를 들어, 버전 번호가 22, 파일이 '22'를 포함해야 하는 경우.

### Skip Dependency 설치

다음 빌드 변수를 추가하여 자동 의존성 설치를 비활성화하고 대신 사용자 정의 설치 명령을 실행할 수 있습니다.

| 컴파일하기                     | 제품정보        |
| ------------------------- | ----------- |
| `SKIP_DEPENDENCY_INSTALL` | `1`또는`true` |

## 이미지 정책

### Preinstalled 소프트웨어 업데이트

Preinstalled software (언어 및 도구)는 end-of-life (EOL)에 도달하기 전에 업데이트됩니다. 이 업데이트는 당신이하지 않은 경우에만 적용[overridden 기본 버전](/workers/ci-cd/builds/build-image/#overriding-default-versions).

- **Minor 버전 업데이트**: 공지없이 최신 버전으로 업데이트 될 수 있습니다. semantic versioning (e.g., Bun 또는 Hugo)을 따르지 않는 도구는 변경 사항을 포함 할 수있는 업데이트는 3 개월의 통지를 받게됩니다.
- **주요 버전 업데이트**: 다음 안정적인 장기 지원 (LTS) 버전으로 3 개월의 통지.

**당신은 통지를 요구할 경우 (예고를 요구하는 변화를 위해):**

- [Cloudflare 변경 로그](https://developers.cloudflare.com/changelog/)
- Dashboard는 업데이트가 될 프로젝트의 알림
- 프로젝트 소유자에게 이메일 알림

특정 버전을 유지하고 자동 업데이트를 방지하기 위해,[기본 버전 삭제](/workers/ci-cd/builds/build-image/#overriding-default-versions).

### 최고의 연습

예상치 못한 빌드 실패를 피하기 위해:

- **모니터 발표**을 통해[Cloudflare 변경 로그](https://developers.cloudflare.com/changelog/), dashboard 알림 및 이메일
- **Pin 특정한 버전**중요한 preinstalled 소프트웨어의[overriding 기본 버전](/workers/ci-cd/builds/build-image/#overriding-default-versions)

Workers 빌드는 프로젝트를 구성하거나 배포 문제를 해결하기 위해 저장소에서 pull request를 자동으로 만들 수 있습니다.

## 구성 PR

Wrangler 구성 파일이 없는 저장소를 연결하면 Workers 빌드 실행`wrangler deploy`어떤 트리거[자동 프로젝트 구성](/workers/framework-guides/automatic-configuration/). 실패의 대신, 그것은 당신의 검출한 기구를 위한 필요한 윤곽을 가진 잡아당기기 요구를 창조합니다.

:::참조
구성 PR은 배포 명령이 될 때만 생성됩니다.`npx wrangler deploy`. 사용자 정의 배포 명령이있는 경우, autoconfig는 여전히 실행하고 프로젝트를 구성하지만 PR이 생성되지 않습니다.
주요 특징

### 왜 당신은 PR을 합병해야

저장소의 구성없이, 모든 빌드는 autoconfig를 먼저 실행해야, 즉, 프로젝트가 두 번 내장 - 한 번 autoconfig에서 구성을 생성, 그리고 다시 실제 배포에 대한. PR은 저장소에 구성을 커밋합니다. 그래서 미래의 빌드는 자동 구성을 건너 뛰고 건물 및 배치로 이동합니다. 빠른 배포 및 버전 제어 설정에서이 결과.

### PR의 특징

![Workers Builds에 의해 생성된 자동적인 윤곽 잡아당기기 요구의 보기](~/assets/images/workers/ci-cd/builds/automatic-pr.png)

구성 PR은 프레임 워크에 따라 다음과 같은 파일로 변경할 수 있습니다.

- **`wrangler.jsonc`**- 당신의 노동자 조정을 가진 Wrangler 윤곽 파일
- **Framework 어댑터**- 프레임 워크에 필요한 Cloudflare 어댑터 (예를 들면,`@astrojs/cloudflare`Astro를 위해)
- **Framework 구성**- Framework config 파일 업데이트 (예를 들어,`astro.config.mjs`Astro 또는`svelte.config.js`SvelteKit를 위해)
- **`package.json`**- 같은 새로운 스크립트`deploy`, `preview`·`cf-typegen`, 플러스 필수 종속
- **`package-lock.json`** / **`yarn.lock`** / **`pnpm-lock.yaml`**- 새로운 의존성으로 업데이트 된 잠금 파일
- **`.gitignore`**- 문의`.wrangler`·`.dev.vars*`이름 \*
- **`.assetsignore`**- 출력 디렉토리에 worker 파일을 생성하는 프레임워크

### PR 설명

PR 설명은 다음과 같습니다 :

- **검출된 설정**- Framework, build 명령, 배포 명령 및 버전 명령
- **미리보기 링크**- 검출 된 설정을 사용하여 생성 된 작업 미리보기
- **다음 단계**- 바인딩, 사용자 정의 도메인 및 기타 추가 문서에 대한 링크

:::참조
PR을 병합 할 때 Workers 빌드는 감지 된 설정을 일치하지 않는 경우 빌드 및 배포 명령을 업데이트하고 성공적인 배포를 보장합니다.
주요 특징

## 이름 분쟁 PR

Workers QXQX0013XQ QXdashboard 및`name`Wrangler 윤곽 파일에 있는 분야는, 충돌을 고치기 위하여 잡아당기기 요구에 창조할 것입니다.

이 때 일어날 수 있습니다:

- dashboard에 있는 노동자를 이름을 바꾸십시오 그러나 당신의 설정 파일에
- 당신은 이전에 다른 노동자와 함께 사용 된 저장소를 연결
- 더 보기`name`config의 필드는 연결된 Worker와 일치하지 않습니다.

PR 업데이트`name`WranglerXQ 설정에서 dashboard의 Worker 이름과 일치합니다.

자세한 내용은 참조[이름 충돌 changelog](/changelog/2025-02-20-builds-name-conflict/).

## PRS 소개

Workers 빌드에서 PR을받을 때 :

1. **자주 묻는 질문**- 구성이 프로젝트 요구사항에 맞는지 확인하십시오.
2. **시험하기**- 모든 작업을 확인하려면 PR 설명의 미리보기 링크를 사용하십시오.

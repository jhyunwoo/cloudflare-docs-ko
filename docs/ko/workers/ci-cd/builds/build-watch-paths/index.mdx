Workers에 git 저장소를 연결하면 저장소의 모든 파일에 변경이 빌드를 트리거합니다. WorkersXQ를 구성하거나 Workers가 주어진 경로에 대한 빌드를 건너야 할 경우 특정 경로 제외 할 수 있습니다. 모노레포 프로젝트 구조를 사용하고 빌드의 양을 제한하고 싶다면 특히 도움이 될 수 있습니다.

## 경로 구성

어떤 경로가 포함되고 제외되는 구성하려면:

1. 내 계정**제품정보**Workers 프로젝트를 선택하십시오.
2. 오시는 길**계정 설정** > **제품정보** > **시계 경로 구축**. Workers는 프로젝트의 모든 경로 (\[\*]) 및 아무것도 경로 제외 (`[]`).

구성 필드는 두 가지 방법으로 채워질 수 있습니다:

- **정체되는 filepaths**: 포함하거나 제외하려는 파일의 정확한 이름을 입력하십시오 (예를 들어,`docs/README.md`).
- **Wildcard 구문:**&#xC640;일드카드를 사용하여 여러 경로 디렉토리와 일치합니다. 규칙의 시작 또는 끝에서 와일드 카드를 지정할 수 있습니다.

:::노트\[Wildcard 구문]

와일드 카드 (Bildcard)`*`) 규칙 내에서 사용되는 문자입니다. 분기 구성에 더 나은 통제를 허용하는 규칙의 시작 또는 끝에서 무엇이든 일치하기 위하여 혼자 둘 수 있습니다. 와일드 카드는 0 이상 문자와 일치합니다. 예를 들어, 시작된 모든 지점과 일치하려는 경우`fix/`그러면 규칙을 만들 것입니다.`fix/*`문자열을 일치`fix/1`, `fix/bugs`또는`fix/`.

:::

푸시 이벤트의 각 경로에 대한, 시계 경로는 다음과 같이 평가됩니다:

- 조건을 만족시키는 경로는 첫 번째 무시됩니다
- 모든 나머지 경로는 조건을 포함합니다.
- 어떤 일치하는 경로가 발견되면 빌드가 트리거됩니다. 그렇지 않으면 빌드는 Skipped

Workers는 푸시 이벤트 및 기본에 해당하는 경로를 우회하여 프로젝트를 구축 할 수 있습니다.

- 푸시 이벤트는 0 파일 변경이 포함되며 사용자가 빌드를 트리거하기 위해 빈 푸시 이벤트를 푸시합니다.
- 푸시 이벤트는 3000 + 파일 변경 또는 20 + 커밋이 포함되어 있습니다.

## 이름 \*

### 예제 1

폴더의 모든 변경에서 빌드를 트리거하려는 경우`project-a/`·`packages/`

- 경로 포함:`project-a/*, packages/*`
- 경로 제외: \`\`

### 예제 2

어떤 변경 사항에 대한 빌드를 트리거하려는 경우, 하지만 docs/ 디렉토리의 모든 변경과 같은 특정 디렉토리에 변경을 제외하고

- 경로 포함:`*`
- 경로 제외:`docs/*`

### 예제 3

특정 파일 또는 특정 파일 형식의 빌드를 트리거하려는 경우, 예를 들어 모든 파일이 종료됩니다.`.md`.

- 경로 포함:`*.md`
- 경로 제외: \`\`

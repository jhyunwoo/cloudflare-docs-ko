이 가이드는 Workers Builds 배포 프로세스에서 오류를 확인하고 해결하는 방법을 설명합니다.

빌드 역사를 보려면, Cloudflare dashboardXQ에서 작업자 프로젝트로 이동, 선택**계정 만들기**, 선택**빌드 History**페이지의 하단에, 당신이 보기 원하는 빌드를 선택합니다. 빌드를 복원하려면 빌드 옆에 ellipses를 선택하고 선택**Retry 빌드**. 대안으로, 당신은 선택할 수 있습니다**Retry 빌드**Build Details 페이지에.

## 알려진 문제 또는 제한

다음은 빌드 로그 또는 일반 문제에서 표면이 될 수있는 일반적인 빌드 오류이며 어떻게 해결할 수 있습니다.

### Workers 이름 필요조건

`✘ [ERROR] The name in your Wrangler configuration file (<Worker name>) must match the name of your Worker. Please update the name field in your Wrangler configuration file.`

Workers 프로젝트에 Git 저장소를 연결하면 Cloudflare QXQXQXdashboard에 Worker의 지정된 이름과 일치해야합니다.`name`지정된 루트 디렉토리에 위치한 Wrangler 구성 파일에 인수. 일치하지 않으면 WranglerXQ 구성 파일의 이름을 dashboard에 Worker의 이름을 일치시키기 위해 이름 필드를 업데이트하십시오.

빌드 시스템 사용`name`WranglerXQ 구성 파일의 인수는 Cloudflare의 글로벌 네트워크에 배포하는 작업자를 결정합니다. 이 필요조건은 dashboard와 배치된 노동자에 노동자의 이름 사이에서 견실함을 지킵니다.
:::참조
이 적용되지 않음[Wrangler 환경분야](/workers/wrangler/environments/)노동자 이름 앞에`-<env_name>`suffix는 Wrangler 윤곽 파일에 있는 이름을 일치합니다.

예를 들어, Worker는 이름을 붙입니다.`my-worker-staging`dashboard는 인수를 가진 WranglerXQ 윤곽 파일을 포함하는 저장소에서 배치될 수 있습니다`name = my-worker`·`[env.staging]`배포 명령을 사용하여`npx wrangler deploy --env staging`·
Wrangler v3 이상, Workers 자동으로 연결 된 노동자의 이름을 일치시킵니다.`WRANGLER_CI_OVERRIDE_NAME`환경 변수.
주요 특징

### Missing Wrangler 구성 파일

`✘ [ERROR] Missing entry-point: The entry-point should be specified via the command line (e.g. wrangler deploy path/to/script) or the main config field.`

이 오류를 볼 경우 Wrangler 구성 파일은 루트 디렉토리에서 누락 될 수 있습니다. 바로가기**계정 설정** > **제품정보** > **구성**root 디렉토리를 업데이트하거나 추가[Wrangler 구성 파일](/workers/wrangler/configuration/)지정된 디렉토리에.

### 잘못된 계정 id

`Could not route to /client/v4/accounts/<Account ID>/workers/services/<Worker name>, perhaps your object identifier is invalid? [code: 7003]`

이 오류를 볼 경우 WranglerXQ 구성 파일이 있음`account_id`다른 계정. 제거하기`account_id`인수 또는 계정의 업데이트`account_id`, 안으로 유효한**Workers & Pages 제품정보**이름 \***계정 세부 정보**.

### Stale API 토큰

` Failed: The build token selected for this build has been deleted or rolled and cannot be used for this build. Please update your build token in the Worker Builds settings and retry the build.`

Build Configuration 설정에서 API Token dropdown은 편집, 삭제 또는 압연된 stale 토큰을 보여줄 수 있습니다. stale 토큰으로 인해 오류가 발생하면 새로운 API 토큰을 만들고 빌드를 선택합니다.

### Timed 아웃

`Build was timed out`

20 분의 최대 빌드 기간이 있습니다. 빌드가 이 시간을 초과하면 빌드가 종료되고 위의 오류 로그가 표시됩니다. 더 자세한 내용을 보려면[Workers 제한 사항](/workers/ci-cd/builds/limits-and-pricing/).

### Git 통합 문제

Git 통합과 관련된 오류로 실행되는 경우, 액세스 제거를 시도할 수 있습니다.[프로젝트](/workers/ci-cd/builds/git-integration/github-integration/#removing-access)또는[프로젝트](/workers/ci-cd/builds/git-integration/gitlab-integration/#removing-access)Cloudflare에서 통합한 다음 재설치[프로젝트](/workers/ci-cd/builds/git-integration/github-integration/#reinstall-a-git-integration)또는[프로젝트](/workers/ci-cd/builds/git-integration/gitlab-integration/#reinstall-a-git-integration)통합.

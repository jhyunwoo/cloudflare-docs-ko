## 연락처

이벤트를 생성하고 Slack, Discord 또는 webhook endpoint에 알림을 보내주는 Worker를 배포할 수 있습니다.

[![Cloudflare에 배포](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/cloudflare/templates/tree/main/workers-builds-notifications-template)

템플릿은 다음과 같은 알림을 보냅니다.

- 성공적인 빌드와 미리보기 또는 라이브 배포 URL
- 오류 메시지와 실패
- 연락처

![Workers 이벤트](~/assets/images/changelog/workers/builds-notifications-slack.png)

웹훅 공급자에 대한 메시지를 포맷하는 Worker를 사용자 정의 할 수 있습니다. 설정 지침을 위해, 참조[템플릿 README](https://github.com/cloudflare/templates/tree/main/workers-builds-notifications-template#readme).

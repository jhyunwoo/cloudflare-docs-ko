Workers는 확장성을 캐싱하고 프로젝트 전체 공유 캐시와 빌드 사이의 출력을 구축하여 시간을 구축합니다.

Workers 프로젝트에서 캐싱을 구축 할 수 있도록 첫 번째 빌드는 캐시에 관련된 artifacts를 저장합니다. 이후 모든 빌드는 다르게 구성되지 않는 캐시에서 복원됩니다.

## 빌드 캐시

활성화 할 때, 캐싱을 구축하는 것은 자동으로 패키지 관리자 및 프레임 워크 프로젝트를 사용하여`package.json`빌드에 따라 캐시 데이터.

패키지 관리자 및 프레임 워크가 의존성을 위해 지원되는 다음 쇼는 각각 출력 캐싱을 구축합니다.

### 패키지 관리자

Workers 빌드 캐시는 다음 패키지 관리자의 글로벌 캐시 디렉토리를 캐시합니다.

| 패키지 관리자                       | 감독 캐시                |
| ----------------------------- | -------------------- |
| [₢ 킹](https://www.npmjs.com/) | `.npm`               |
| [주요 특징](https://yarnpkg.com/) | `.cache/yarn`        |
| [사이트맵](https://pnpm.io/)      | `.pnpm-store`        |
| [한국어](https://bun.sh/)        | `.bun/install/cache` |

### 프레임 워크

일부 프레임 워크는 일반적으로 빌드 시간 동안 중간 빌드 출력 또는 의존성을 가진 프레임 워크에 의해 팝업되는 캐시 디렉토리를 제공합니다. 모델 번호: Workers 빌드는 자동으로 프레임 워크를 감지하고 이후 빌드에서 재사용 할 수있는이 디렉토리를 캐시합니다.

뒤에 오는 기구 지원은 산출 캐싱을 건설합니다:

| 관련 기사          | 감독 캐시                                         |
| -------------- | --------------------------------------------- |
| 모델 번호: Astro   | `node_modules/.astro`                         |
| 카테고리           | `node_modules/.cache`, `.docusaurus`, `build` |
| 한국어            | `.cache`                                      |
| 인기 있는          | `.cache`, `public`                            |
| 모델 번호: Next.js | `.next/cache`                                 |
| 사이트맵           | `node_modules/.cache/nuxt`                    |

### 제한 사항

다음 제한은 캐싱 빌드에 부과됩니다 :

- **공지사항**: 캐시는 마지막 읽기 날짜 후 7 일 순화됩니다. 캐시 해석은 생성 후 7 일 순화됩니다.
- **제품 정보**: 모든 프로젝트는 할당 된 10 GB입니다. 프로젝트 캐시가이 한계를 초과하면, 프로젝트는 최근 적어도 읽은 artifacts를 자동으로 삭제합니다.

## Enable build 캐시

캐싱을 만들려면:

1. 바로가기[Workers & Pages 제품정보](https://dash.cloudflare.com)대시보드에.
2. Workers 프로젝트를 찾으십시오.
3. 오시는 길**계정 설정** > **제품정보** > **비밀번호**.
4. 제품정보**이름 \***&#xBE4C;드 캐싱을 켜기.

## 명확한 빌드 캐시

빌드 캐시는 빌드 문제를 디버깅 할 때 필요한 프로젝트에 대해 명확하게 할 수 있습니다. 빌드 캐시를 취소하려면:

1. 바로가기[Workers & Pages 제품정보](https://dash.cloudflare.com)대시보드에.
2. Workers 프로젝트를 찾으십시오.
3. 오시는 길**계정 설정** > **제품정보** > **비밀번호**.
4. 제품정보**명확한 캐시**빌드 캐시를 삭제합니다.

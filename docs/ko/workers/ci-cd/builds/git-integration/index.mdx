Cloudflare는 당신의 연결을 지원합니다[프로젝트](/workers/ci-cd/builds/git-integration/github-integration/)·[프로젝트](/workers/ci-cd/builds/git-integration/gitlab-integration/)Cloudflare에 저장소 Worker, 자동으로 코드를 배포합니다.

Git 통합을 추가하면 Git 공급자에서 직접 빌드 상태를 모니터링 할 수 있습니다.[풀 요청 코멘트](/workers/ci-cd/builds/git-integration/github-integration/#pull-request-comment), [체크 실행](/workers/ci-cd/builds/git-integration/github-integration/#check-run), 또는[현재 위치](/workers/ci-cd/builds/git-integration/gitlab-integration/#commit-status), 그래서 작업 흐름을 떠나지 않고 배포를 관리 할 수 있습니다.

## Git 공급자 지원

Cloudflare는 Cloudflare WorkersXQ를 GitHub 및 GitLab 저장소에 연결합니다. Workers 빌드는 현재 GitHub 또는 GitLab의 자체 호스팅 인스턴스를 연결하지 않습니다.

다른 Git 공급자 (예를들면 Bitbucket)를 사용하면 사용할 수 있습니다.[외부 CI/CD 제공업체(예: GitHub Actions)](/workers/ci-cd/external-cicd/)관련 기사[Wrangler 클립](/workers/wrangler/commands/#deploy).

## Git 통합 추가

Workers Build는 GitHub 및 GitLab 계정과 직접 통합되어 개인 및 조직 계정 모두 포함*아니다.*&#xC790;체 호스팅.

Cloudflare 계정에 연결된 Git 계정이 없다면 GitHub 또는 GitLab에 설치를 설정할 수 있습니다.[저장소 연결](/workers/ci-cd/builds/#get-started)처음으로, 또는 새로운 Git 계정을 추가 할 때. Cloudflare Git 통합을 승인하는 프롬프트를 따르십시오.

![Git 공급자](~/assets/images/workers/platform/ci-cd/workers-git-provider.png)

Git 통합이 설치된 경우 다음 페이지를 확인할 수 있습니다.

- [GitHub 앱 페이지](https://github.com/settings/installations)(당신이 조직에 있다면, 선택**Switch 설정**GitHub 조직 설정에 액세스하려면
- [GitLab 공인 응용 프로그램 페이지](https://gitlab.com/-/profile/applications)

조직 계정에 대한 액세스를 제공하는 세부 사항, 참조[GitHub 조직 액세스](/workers/ci-cd/builds/git-integration/github-integration/#organizational-access)·[GitLab 조직 접근](/workers/ci-cd/builds/git-integration/gitlab-integration/#organizational-access).

## Git 통합 관리

Git 설치 관리:

<Steps>
  1. 오시는 길**Workers & Pages**Cloudflare dashboard에 있는 페이지.

     <DashButton url="/?to=/:account/workers-and-pages" />

  2. 당신의 노동자를 선택하십시오.

  3. 오시는 길**계정 설정** > **회사연혁**.

  4. 이름 \***Git 저장소**, 선택**계정 관리**.
</Steps>

repository 접근 또는 재설치하여 설치 문제를 해결하는 데 유용합니다. 자세한 내용은[프로젝트](/workers/ci-cd/builds/git-integration/github-integration)·[프로젝트](/workers/ci-cd/builds/git-integration/gitlab-integration)설치 관리 방법 안내

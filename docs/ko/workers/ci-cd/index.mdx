통합 빌드 시스템을 사용하여 WorkersXQX0002XQXQ에 대한 지속적인 통합 및 지속적인 배포 (CI/CD)를 설정할 수 있습니다.[Workers 회사연혁](#workers-builds), 또는 사용[외부 공급자](#external-cicd)개발 작업 흐름을 최적화합니다.

## 왜 CI/CD를 사용합니까?

Workers를 배포하기 위해 CI/CD 파이프라인을 사용하여 다음과 같은 가장 좋은 연습입니다.

- Automates 빌드 및 배포 프로세스, 수동에 대한 필요 제거`wrangler deploy`명령.
- 동일한 소스 제어 관리 (SCM) 시스템을 사용하여 팀 전반에 걸쳐 일관된 빌드 및 배포를 보장합니다.
- 획일한 환경에서 배포하여 variability 및 Errors를 감소시킵니다.
- 생산 자격 증명에 대한 관리 접근을 단순화합니다.

## 어떤 CI/CD를 사용해야합니까?

제품 정보[Workers 빌드](/workers/ci-cd/builds)Cloudflare의 생태계 내에서 완전 통합 솔루션을 원한다면 GitHub 또는 GitLab 사용자의 최소 설정과 구성을 필요로 합니다.

자주 묻는 질문[외부 CI/CD 공급자](/workers/ci-cd/external-cicd)이름:

- 현재 QXQX0007XQ Builds에서 지원되지 않는 GitHub 또는 GitLabs의 자체 호스팅 인스턴스가 있습니다.[Git 통합](/workers/ci-cd/builds/git-integration/)
- GitHub 또는 GitLab이 아닌 Git Provider를 사용하고 있습니다.

Worker 메모리 사용을 이해하면 성능 최적화, 메모리 (OOM) 오류 방지
때리기[Worker 메모리 제한](/workers/platform/limits/#memory), 및 수정 메모리 누출.

DevTools에서 스냅 샷으로 메모리 사용을 프로파일 할 수 있습니다. Memory snapshots의 요약을 볼 수 있습니다
메모리 사용, 얼마나 많은 메모리가 다른 데이터 유형에 할당 된, 그리고 세부 정보를 얻을
메모리의 개체.

DevTools를 사용하여 프로필 메모리를 사용하여 특정 행동을 복제하는 것이 어려울 수 있습니다.
회사 소개 mimic 생산 행동에, 로컬 노동자에게 보내는 요청을 확인합니다
생산에 있는 요구와 유사합니다. 이것은 요청의 큰 볼륨을 보내고, 요청을 만들기
특정 경로, 또는 생산 같은 데이터를 사용하여[--remote 플래그](/workers/development-testing/#remote-bindings).

## 스냅 샷 찍기

메모리 스냅 샷을 생성하려면:

- 지원하다`wrangler dev`당신의 노동자를 시작
- 공지사항`D`당신의 터미널에서 DevTools를 엽니 다
- "Memory"탭 선택
- 할당 메모리를 시작하려면 작업자에게 요청 보내기
  - 선택적으로 적절한 시간에 실행을 일시 중지 할 수 있는지 확인 debugger를 포함
- 제품정보`Take snapshot`

이제 Worker 메모리를 검사 할 수 있습니다.

## 예 Snapshot

메모리 스냅샷을 읽는 방법을 알아봅시다. 다음 노동자를 가지고 상상:

```js title="index.js"
let responseText = "Hello world!";

export default {
	async fetch(request, env, ctx) {
		let now = new Date().toISOString();
		responseText = responseText + ` (Requested at: ${now})`;
		return new Response(responseText.slice(0, 53));
	},
};
```

이 코드는 처음에 잘 작동하지만, 시간이 지남에 따라 느린 응답과
메모리 오류가 발생했습니다. DevTools를 사용하면 메모리 누출이 있는지 확인할 수 있습니다.

위에서 언급 한대로 DevTools를 눌러서 엽니다.`D`달리기 후에 열쇠`wrangler dev`·
그런 다음 "Memory"탭으로 이동합니다.

다음, 요청을 전송하여 작업자에게 큰 볼륨을 생성합니다. 이 작업을 수행 할 수 있습니다`curl`으로
브라우저를 반복적으로 다시로드. 다른 WorkersXQ가 reproduce에 더 특정한 요구를 요구할지도 모르다 주의하십시오
메모리 누출.

그런 다음 "Take Snapshot"버튼을 클릭하고 결과를 볼 수 있습니다.

첫 번째, 드롭다운에서 "Statistics"로 이동하여 메모리를 수행하는 일반적인 감각을 얻을 수 있습니다.

![메모리 통계](~/assets/images/workers/observability/memory-stats.png)

이 통계를 보면 많은 메모리가 67 kB에서 문자열에 전념한다는 것을 볼 수 있습니다. 이것은
기억 누출의 근원. 더 많은 요청을 만들고 다른 스냅 샷을 찍으면 볼 수 있습니다.
이 숫자는 성장합니다.

![메모리 요약](~/assets/images/workers/observability/memory-summary.png)

메모리 요약은 메모리의 양에 의해 데이터 유형을 나열합니다. "(string)"을 클릭하면 볼 수 있습니다.
나머지보다 훨씬 큰 문자열. 텍스트는 "Requested at"와 반복적으로 날짜를 승인하는 것을 보여줍니다.
inadvertently overwriting the global variable 와 점점 큰 문자열:

```js
responseText = responseText + ` (Requested at: ${now})`;
```

DevTools에서 메모리 스냅 샷을 사용하여 메모리 누출을 일으키는 코드의 객체와 라인을 식별했습니다.
이제 작은 코드 변경으로 수정할 수 있습니다.

## DevTools 사용

직장인을 현지으로 실행할 때[Wrangler 클립](https://developers.cloudflare.com/workers/wrangler/) (`wrangler dev`) 또는 사용[뚱 베어](https://vite.dev/)이름 \*[Cloudflare Vite 플러그인](https://developers.cloudflare.com/workers/vite-plugin/), 당신은 자동적으로 접근이 있습니다[Cloudflare의 구현](https://github.com/cloudflare/workers-sdk/tree/main/packages/chrome-devtools-patches)이름 \*[Chrome 도구](https://developer.chrome.com/docs/devtools/overview).

Chrome DevTools를 사용할 수 있습니다.

- Chrome 콘솔에서 직접 로그 보기
- [Breakpoints 설정으로 디버그 코드](/workers/observability/dev-tools/breakpoints/)
- [단면도 CPU 사용법](/workers/observability/dev-tools/cpu-usage/)
- [메모리 사용과 디버그 메모리 누출을 설정할 수 있는 코드에서 out-of-memory (OOM) 오류](/workers/observability/dev-tools/memory-usage/)

## DevTools를 열기

### 모델 번호: Wrangler

- 실행하여 작업자를 로컬로 실행하십시오.`wrangler dev`
- 공지사항`D`브라우저 탭에서 DevTools를 엽니 다

### 뚱 베어

- 실행하여 작업자를 로컬로 실행하십시오.`vite`
- 새로운 크롬 탭에서 콘솔에서 보여주는 디버그 URL을 엽니다 (예를 들어,`http://localhost:5173/__debug`)

### Dashboard 편집기 및 놀이터

둘 다[Cloudflare dashboard](https://dash.cloudflare.com/)그리고[노동자의 놀이터](https://workers.cloudflare.com/playground)UI에 DevTools가 포함되어 있습니다.

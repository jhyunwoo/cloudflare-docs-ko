Query Builder는 구조화된 쿼리를 작성하여 원격 측정 데이터를 조사하고 시각화합니다. Query Builder는 Workers Observability dataset을 검색하여 현재 저장된 모든 로그를 포함합니다.[Workers 로그인](/workers/observability/logs/workers-logs/).

Query Builder를 찾을 수 있습니다.**옵션 정보**Cloudflare dashboard의 페이지:

## Enable Query 빌더

Query Builder는 모든 개발자에게 사용할 수 있으며 활성화가 필요하지 않습니다. 쿼리는 모든 Workers를 검색 Cloudflare에 의해 저장되는 통나무. 아직 Workers 로그를 활성화하지 않은 경우 다음 설정을 추가하여 수행 할 수 있습니다.[노동자의 Wrangler 파일](/workers/observability/logs/workers-logs/#enable-workers-logs)그리고 당신의 노동자를 충성.

<WranglerConfig>
  ```jsonc
  {
  	"observability": {
  		"enabled": true,
  		"logs": {
  			"invocation_logs": true,
  			"head_sampling_rate": 1 //옵션. 기본값 = 1.
  		}
  	}
  }
  ```
</WranglerConfig>

![여러 시각화로 Query Builder를 보여주는 예](~/assets/images/workers-observability/wobs_QB_visualization_122.png)

모든 방법은 집계 기능입니다. 대부분의 방법은 로그 이벤트의 특정 필드에 작동.`Count`예외이며 필터 조건과 일치하는 로그 이벤트 수를 반환하는 집단 함수입니다.

### 제품정보

필터는 지정된 조건과 일치하는 열을 반환합니다. 필터에는 세 가지 구성 요소가 있습니다. 키, 연산자 및 값.

키는 로그 이벤트에 어떤 필드입니다. 예를 들어, 선택할 수 있습니다.`$workers.cpuTimeMs`또는`$metadata.message`.

연산자는 true 또는 false로 평가하는 논리적 조건입니다. 지원된 조건에 대한 아래 표 참조:

| 데이터 유형 | 유효 조건 (운영자)                                                     |
| ------ | --------------------------------------------------------------- |
| 한국어    | 본부, 동일하지 않습니다, 그레이터, 그레이터 또는 동등, 덜, 덜 또는 동등, 존재, 존재하지 않습니다      |
| 스트레이트  | 본부, 동일하지 않습니다, 포함, 포함하지 않습니다, Regex, Exists, 존재하지 않습니다, 와 함께 시작 |

숫자 필드의 값은 정수입니다. 문자열 필드의 값은 문자열입니다.

필터를 추가하려면:

<Steps>
  1. 제품정&#xBCF4;**+**&#xB0B4; 계정**제품정보**이름 \* 2. 선택**키 선택 ...**·
     키 이름을 입력합니다. 예를 들어,`$workers.cpuTimeMs`. 3. 연산자 선택
     작업자가 가장 적합하도록 변경합니다. 예를 들어,`Greater than`·
     제품정보**선택 값...**&#xAC12;을 입력합니다. 예를 들어,`100`.
</Steps>

위의 필터로 쿼리를 실행할 때, 단지 로그 이벤트`$workers.cpuTimeMs > 100`반환됩니다.

여러 필터를 추가하고 연산자와 결합하여 모든 필터를 일치하는 이벤트 만 반환됩니다.

### 이름 \*

Search는 지정된 텍스트를 포함하는 이벤트를 반환하는 텍스트 필터입니다. 검색은 빠른 필터링 메커니즘으로 도움이 될 수 있습니다, 또는 당신의 로그에 고유 한 IDifiable 값을 검색.

### 그룹 By

이름 \* 같은 값을 요약 행에 결합하여. 예를 들어, 쿼리가 추가되면`$workers.event.request.cf.country`그룹으로 필드에 의해, 다음 요약 테이블 국가 그룹.

### 주문하기

이름 \* 결과가 요약 표에서 분류되는 방법에 영향을 미칩니다. 이름 \*`asc`선택된 결과는 ascending 순서에서 분류됩니다 - 적어도에서 가장 큰. 이름 \*`desc`선택된 결과 중 가장 큰 순서로 정렬됩니다.

### 지원하다

제한은 반환된 결과의 수를 제한합니다. 설정할 때[주문하기](/workers/observability/query-builder/#order-by), 그것은 "top"또는 "first"N 결과를 반환하는 데 사용할 수 있습니다.

### 시간 범위 선택

시간 범위를 선택하면 매칭 이벤트를 찾고 싶은 시간 간격을 지정합니다. 보존 기간은 당신의 것에 달려 있습니다[계획 유형](/workers/observability/logs/workers-logs/#pricing).

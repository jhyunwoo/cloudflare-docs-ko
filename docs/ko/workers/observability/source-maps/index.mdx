## 소스 맵

소스 맵을 활성화하려면 Worker의 다음을 추가하십시오.[Wrangler 구성](/workers/wrangler/configuration/):

<WranglerConfig>
  ```jsonc
  {
  	"upload_source_maps": true
  }
  ```
</WranglerConfig>

시간 :`upload_source_maps`설정`true`, Wrangler는 당신이 실행할 때 자동적으로 근원 지도 파일을 생성합니다[`wrangler deploy`](/workers/wrangler/commands/#deploy)또는[`wrangler versions deploy`](/workers/wrangler/commands/#versions-deploy).
​​

:::참조

Miniflare는 또한 할 수 있습니다[출력 소스 맵](https://miniflare.dev/developing/source-maps)현지 개발 또는 사용[제품정보](/workers/testing/miniflare/writing-tests).

:::

## 스택 추적

당신의 노동자가 불행한 예외를 던질 때, 우리는 근원 지도를 fetch하고 당신의 노동자의 본래 근원 부호의 선에 예외의 더미 추적을 지도하기 위하여 사용합니다.

스트리밍 할 때 스택 추적을 볼 수 있습니다.[실시간 로그](/workers/observability/logs/real-time-logs/)또는[꼬리 Workers](/workers/observability/logs/tail-workers/).

:::참조

소스 맵은 작업자 인 직업이 완료 한 후 다시 검색됩니다. - 작업자의 CPU 활용 또는 성능에 영향을 미치지 않는 비동기 프로세스입니다. 소스 맵은 실행 시간에 Worker 내부에 접근하지 않습니다.`console.log()`이름 \*[회사 소개](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error/stack)노동자 안에, 당신은 deobfuscated 더미 추적을 얻을 수 없습니다.

:::

Cloudflare가 노동자의 소스 맵에 스택 추적을 다시 시도 할 때, 그것은 너무 라인에 의해, 가능한만큼 재 매핑. 더미 추적의 선이 어떤 이유든지를 위해 재지도될 수 없는 경우에, Cloudflare는 더미 추적의 선을 바꾸지 않으며, 더미 추적의 다음 선을 계속할 것입니다.

## 제한 사항

:::note\[Wrangler 버전]
최소 필요한 Wrangler 버전 소스 맵: 3.46.0. 실행하여 버전 확인`wrangler --version`.
:::

## 이름 \*

간단한 프로젝트를 고려하십시오.`src/index.ts`신청의 엔트리 포인트로 봉사`src/calculator.ts`기본 arithmetic을 지원하는 ComplexCalculator 클래스를 정의합니다.

<FileTree>
  - 다운로드
  - 사이트맵
  - 사이트맵
    - 계산기.ts
    - 사이트맵
</FileTree>

소스 맵이 ComplexCalculator 클래스에서 오류를 디버깅하는 방법을 참조하십시오.

![소스 맵 remapping없이 스택 추적](~/assets/images/workers-observability/without-source-map.png)

이름 \***다운로드**: 모든 자바 스크립트가 하나의 파일로 축소되었는지, 그래서 스택 추적은 파일 이름에 누락 된 정보이며, 잘못된 줄 번호와 잘못된 referenceS를 보여줍니다`js`대신에`ts`.

![소스 맵 remapping 스택 추적](~/assets/images/workers-observability/with-source-map.png)

이름 \***소스 맵 업로드**: 모든 방법 reference 올바른 파일 및 라인 번호.

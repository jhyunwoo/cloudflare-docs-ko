Axiom은 저장, 검색 및 다량의 데이터를 분석하는 데 도움이되는 서버가 없는 로그 분석 플랫폼입니다. Cloudflare WorkersXQ 신청 전세를 Axiom에 수출해서, 당신은 할 수 있습니다:

- 저장 및 쿼리 로그 및 스케일에 추적
- dashboard를 생성하고 WorkersXQ를 감시하는 경고

![Timeline에 표시된 타이밍 정보와 추적](~/assets/images/workers-observability/axiom-example.png)

이 가이드는 OpenTelemetry-compliant 추적을 내보내고 CloudflareXQ에서 Axiom에 로그인합니다. 작업자 신청

## 자주 묻는 질문

시작하기 전에, 당신은 가지고:

- 이름 \*[Axiom 계정](https://app.axiom.co/register)(무료 계층 가능)
- 모니터링 할 작업자 배치
- Axiom dataset 데이터 전송

## 단계 1: dataset 만들기

이미 dataset을 가지고 있지 않은 경우:

1. 로그인[Axiom 계정](https://app.axiom.co/)
2. 바로가기**데이터셋**왼쪽 사이드바에서
3. 이름 \***새로운 Dataset**
4. 이름 입력 (예:`cloudflare-workers-otel`)
5. 이름 \***Dataset 만들기**

## 단계 2: 당신의 Axiom API 토큰 및 dataset를 얻으십시오

1. 바로가기**계정 설정**왼쪽 사이드바에서
2. 관련 기사**API 토큰**
3. 이름 \***API 만들기 토큰 토큰**
4. API 토큰 구성:
   - **이름 \***: descriptive name (예를 들어,`cloudflare-workers-otel`)
   - **제출**: 선택**이름 \***&#xAD8C;한 ( telemetry data 전송 필요)
   - **데이터셋**: 이 토큰이 쓸 수 있는 데이터셋을 선택하거나 선택**모든 Datasets**
5. 이름 \***이름 \***
6. **주요 특징**: API 토큰을 즉시 복사하고 안전하게 보관하십시오 - 다시 볼 수 없습니다.

API 토큰은 다음과 같습니다:`xaat-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

## 단계 3: Cloudflare 목적지 구성

이제 당신은 Axiom에 포인트 Cloudflare dashboardXQ에 목적지를 만들 것입니다.

### Axiom OTLP 엔드 포인트

Axiom은 추적 및 로그에 대한 별도의 OTLP 엔드 포인트를 제공합니다.

- **팟캐스트**: `https://api.axiom.co/v1/traces`
- **로그인**: `https://api.axiom.co/v1/logs`

### 추적 또는 로그를 구성

1. Cloudflare 계정으로 이동[모델 번호: Workers 옵션 정보](https://dash.cloudflare.com/?to=/:account/workers-and-pages/observability/pipelines)이름 \*
2. 이름 \***자주 묻는 질문**
3. 추적 대상을 구성:
   - **대상 이름**: `axiom-traces`(또는 원고 이름)
   - **여행 정보**: 선택**팟캐스트**
   - **OTLP 엔드포인트**: `https://api.axiom.co/v1/traces`(주)`/v1/logs`)
   - **공급 업체**: 두 가지 필수 헤더를 추가 :
     - 인증 헤더
       - 헤더 이름:`Authorization`
       - 공급 능력:`Bearer <your-api-token>`
     - Dataset 헤더:
       - 헤더 이름:`X-Axiom-Dataset`
       - 헤더 값: 데이터셋 이름(예:`cloudflare-workers-otel`)
4. 이름 \***제품 정보**

## 단계 3: 노동자를 구성

QXQX0456XQQ dashboardXQ에서 생성된 목적지로, 원격 측정 수출을 가능하게 하기 위하여 노동자의 윤곽을 새롭게 합니다.

<WranglerConfig>
  ```json
  {
    "observability": {
      "traces": {
        "enabled": true,
        // Must match the destination name in the dashboard
        "destinations": ["axiom-traces"]
      },
      "logs": {
        "enabled": true,
        // Must match the destination name in the dashboard
        "destinations": ["axiom-logs"]
      }
    }
  }
  ```
</WranglerConfig>

구성을 업데이트 한 후, 효과에 대한 변경 사항에 대한 작업자를 배치하십시오.

:::참조

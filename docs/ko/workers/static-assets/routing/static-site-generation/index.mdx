Static Site Generation (SSG) 응용 프로그램은 사전적으로 내장 된 웹 응용 프로그램입니다 또는 "prerendered"-of-time. 그들은 종종 같은 프레임 워크와 내장[인기 있는](/workers/framework-guides/web-apps/more-web-frameworks/gatsby/)또는[카테고리](/workers/framework-guides/web-apps/more-web-frameworks/docusaurus/). 이 기구의 구조 과정은 많은 HTML 파일을 생성하고 클라이언트 측 자원 (예를들면 JavaScript 번들, CSS 스타일 시트, 이미지, 글꼴, 등)를 동반할 것입니다. 데이터는 정적, fetched 및 HTML을 빌드 타임으로 컴파일하거나 클라이언트 측 요청으로 API에서 클라이언트에 의해 fetched.

종종 SSG 프레임 워크는 사용자 정의 404 페이지를 만들 수 있습니다.

## 제품 설명

정적 사이트 생성 애플리케이션을 WorkersXQ에 배포하려면 구성해야 합니다.`assets.directory`, 그리고 선택적으로,`assets.not_found_handling`·`assets.html_handling`당신의 선택[Wrangler 구성 파일](/workers/wrangler/configuration/#assets):

<WranglerConfig>
  ```json
  {
  	"name": "my-worker",
  	"compatibility_date": "$today",
  	"assets": {
  		"directory": "./dist/",
  		"not_found_handling": "404-page",
  		"html_handling": "auto-trailing-slash"
  	}
  }
  ```
</WranglerConfig>

`assets.html_handling`기본값으로`auto-trailing-slash`그리고 이것은 보통 당신에게 원하는 행동을 자동적으로 줄 것입니다: 개별 파일 (예를들면.`foo.html`) 제공*없음*트레일 슬래시 및 폴더 인덱스 파일 (e.g.`foo/index.html`) 제공*이름 \**&#xD2B8;레일 슬래시. 대안으로, 당신은 충돌을 강제 할 수 있습니다 (`force-trailing-slash`) 또는 드롭 트레일 슬링 (drop trailing slashes)`drop-trailing-slash`) HTML 페이지에 대한 요청에.

### 관례 404 페이지

설정하기`assets.not_found_handling`으로`404-page`정적 자산에 대한 Workers의 기본 서빙 동작을 무시합니다. 수신 요청이 파일에 일치하지 않을 때`assets.directory`, Workers는 가장 가까운의 내용을 봉사할 것입니다`404.html`파일 첨부`404 Not Found`이름 \*

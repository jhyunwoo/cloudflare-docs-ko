CloudflareXQ에서 응용 프로그램 또는 웹 사이트를 구축하면 README, 블로그 게시물 또는 문서에서 CloudflareXQ 버튼과 내장 할 수 있습니다.

![Cloudflare로 건축하는](https://workers.cloudflare.com/built-with-cloudflare.svg)

:::노트\[시각]

"Cloudflare"버튼을 사용하여 Cloudflare 제품을 웹 사이트 또는 응용 프로그램에 공유 할 수 있습니다. 사용자가 자신의 계정에 응용 프로그램을 배포 할 수있는 경우, 참조[Cloudflare 버튼 배포](/workers/platform/deploy-buttons).

:::

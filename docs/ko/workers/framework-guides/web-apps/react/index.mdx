**CLI에서 시작**- React SPA, Cloudflare Workers API, 그리고[Cloudflare Vite 플러그인](/workers/vite-plugin/)lightning-fast 개발을 위해.

<PackageManagers type="create" pkg="cloudflare@latest" args="my-react-app --framework=react" />

***

**또는 그냥 배포**- React, Hono API 및 Vite, CI/CD를 사용하여 풀스택 앱을 만들고 당신을 위해 모든 설정 미리보기를 만듭니다.

[![Workers에 배포](https://deploy.workers.cloudflare.com/button)](https://dash.cloudflare.com/?to=/:account/workers-and-pages/create/deploy-to-workers\&repository=https://github.com/cloudflare/templates/tree/main/vite-react-template)

## React는 무엇입니까?

[모델 번호: React](https://react.dev/)사용자 인터페이스를 구축하기위한 프레임 워크입니다. Reusable UI 구성 요소를 만들고 응용 프로그램의 상태를 효율적으로 관리 할 수 있습니다. ReactXQXQXQXQXWorkersXQXQ에서 실행되는 백엔드 API를 사용하여 전체 태스크 응용 프로그램을 만들 수 있습니다.

## React

<Steps>
  1. **Create-cloudflare CLI(C3)로 새로운 프로젝트를 만들 수 있습니다.**

     <PackageManagers type="create" pkg="cloudflare@latest" args="my-react-app --framework=react" />

     <Details header="이 프로젝트는 어떻게 설정됩니까?">
       아래 프로젝트의 단순화 된 파일 트리입니다.

       <FileTree>
         - 내 계정
           - 사이트맵
             - 앱.tsx
           - 작업자/
             - 사이트맵
           - 프로젝트
           - 파일 형식
           - 다운로드
       </FileTree>

       `wrangler.jsonc`이름 \*[Wrangler 구성 파일](/workers/wrangler/configuration/)·
       이 파일에서:

       - `main`이름 \*`worker/index.ts`. 이것은 당신의 백엔드 API로 행동하는 노동자입니다.
       - `assets.not_found_handling`설정`single-page-application`즉, React SPA가 Worker로 갈 수 없다는 것을 의미합니다. 따라서 무료입니다.
       - Cloudflare의 개발자 플랫폼에서 리소스에 바인딩을 추가하려면 여기에서 구성하십시오. 더 알아보기[관련 제품](/workers/runtime-apis/bindings/).

       `vite.config.ts`사용 설정[Cloudflare Vite 플러그인](/workers/vite-plugin/). 이것은 Cloudflare QXQXWorkers 런타임에 있는 당신의 노동자를 실행하고, 당신의 국부적으로 발달 환경을 가능한 생산에 가깝습니다.

       `worker/index.ts`단일 엔드포인트를 포함하는 백엔드 API입니다.`/api/`, 그 반환 텍스트 응답.
       으로`src/App.tsx`, 당신의 React 앱은 이 엔드포인트를 호출하여 메시지를 백업하고 표시합니다.
     </Details>

  2. **현지 개발[Cloudflare Vite 플러그인](/workers/vite-plugin/)**

     프로젝트를 작성한 후 프로젝트 디렉토리에서 다음 명령을 실행하여 로컬 개발 서버를 시작합니다.

     <PackageManagers type="run" args="dev" />

     <Details header="현지 개발에서 무슨 일이 일어나는가?">
       이 프로젝트는 로컬 개발 및 빌드에 대한 Vite를 사용하고, 따라서 핫 모듈 교체 (HMR)를 포함한 Vite의 모든 기능을 갖추고 있습니다.

       또한,`vite.config.ts`Cloudflare Vite 플러그인을 사용하기 위해 설정됩니다. 이 QXQX0317XQ Workers 런타임에서 응용 프로그램을 실행하고, 단지 생산과 같은 로컬 에뮬레이션에 액세스 할 수 있습니다.
     </Details>

  3. **프로젝트 배포**

     프로젝트에 배포할 수 있습니다.`*.workers.dev`하위 도메인 또는[주문 영역](/workers/configuration/routing/custom-domains/)당신의 자신의 기계에서 또는 Cloudflare를 포함하여 어떤 CI/CD 체계에서,[Workers 회사연혁](/workers/ci-cd/builds/).

     다음 명령은 프로젝트를 빌드하고 배포합니다. CI를 사용하는 경우, 귀하의 업데이트를 확인["deploy 명령"](/workers/ci-cd/builds/configuration/#build-settings)적절하게 구성.

     <PackageManagers type="run" args={"deploy"} />
</Steps>

## React를 가진 바인딩을 사용하십시오

당신의 새로운 프로젝트는 또한 노동자를 안으로 포함합니다`./worker/index.ts`React 응용 프로그램에 대한 백엔드 API로 사용할 수 있습니다. React 신청이 직접 Workers 바인딩에 접근할 수 없더라도, 이 노동자를 통해서 그들과 상호 작용할 수 있습니다. 당신은 할 수 있습니다[`fetch()`이름 \*](/workers/runtime-apis/fetch/)React 신청에서 노동자에, 그 때 요구와 사용 바인딩을 취급할 수 있는. 자주 묻는 질문[Workers 바인딩 구성](/workers/runtime-apis/bindings/).

이 가이드에서, 당신은 새로운 만들 것입니다[모델 번호: Vue](https://vuejs.org/)응용 프로그램 및 Cloudflare Workers에 배포 (새로운[모델 번호: Workers 투자정보](/workers/static-assets/)).

## 1. 새로운 프로젝트를 설정

사용 방법[`create-cloudflare`](https://www.npmjs.com/package/create-cloudflare)CLI (C3)는 새로운 프로젝트를 설정합니다. C3는 새로운 프로젝트 디렉토리를 만들 것이며 공식 Vue 템플릿에서 코드를 사용하여 즉시 배포 할 수있는 옵션을 제공합니다.

이용안내`create-cloudflare`WorkersXQXQ 프로젝트를 만들려면 자산은 다음 명령을 실행합니다.

<PackageManagers type="create" pkg="cloudflare@latest" args="my-vue-app --framework=vue" />

<Details header="이 프로젝트는 어떻게 설정됩니까?">
  아래 프로젝트의 단순화 된 파일 트리입니다.

  <FileTree>
    - 내 계정
      - 사이트맵
        - 앱.vue
      - 서버/
        - 사이트맵
      - 프로젝트
      - 파일 형식
      - 다운로드
  </FileTree>

  `wrangler.jsonc`이름 \*[Wrangler 구성 파일](/workers/wrangler/configuration/)·
  이 파일에서:

  - `main`이름 \*`server/index.ts`. 이것은 당신의 백엔드 API로 행동하는 노동자입니다.
  - `assets.not_found_handling`설정`single-page-application`Vue SPA에 의해 처리되는 경로가 노동자에 갈 수 없다는 것을 의미합니다.
  - Cloudflare의 개발자 플랫폼에서 리소스에 바인딩을 추가하려면 여기에서 구성하십시오. 더 알아보기[관련 제품](/workers/runtime-apis/bindings/).

  `vite.config.ts`사용 설정[Cloudflare Vite 플러그인](/workers/vite-plugin/). 이것은 Cloudflare QXQXWorkers 런타임에 있는 당신의 노동자를 실행하고, 당신의 국부적으로 발달 환경을 가능한 생산에 가깝습니다.

  `server/index.ts`단일 엔드포인트를 포함하는 백엔드 API입니다.`/api/`, 그 반환 텍스트 응답.
  으로`src/App.vue`, Vue 앱은 이 엔드포인트를 호출하여 메시지를 뒤로 표시하고 이를 표시합니다.
</Details>

## 3. 프로젝트 배포

프로젝트에 배포할 수 있습니다.`*.workers.dev`하위 도메인 또는[주문 영역](/workers/configuration/routing/custom-domains/), 당신의 자신의 기계에서 또는 어떤 CI/CD 체계든지에서, 포함하여[Cloudflare의 자체](/workers/ci-cd/builds/).

다음 명령은 프로젝트를 빌드하고 배포합니다. CI를 사용하는 경우, 귀하의 업데이트를 확인["deploy 명령"](/workers/ci-cd/builds/configuration/#build-settings)적절하게 구성.

## Vue에 바인딩을 사용하십시오

당신의 새로운 프로젝트는 또한 노동자를 안으로 포함합니다`./server/index.ts`Vue 응용 프로그램에 대한 백엔드 API로 사용할 수 있습니다. Vue 응용 프로그램은 직접 액세스 할 수 없습니다 Workers 바인딩, 그것은이 노동자를 통해 그들과 상호 작용할 수 있습니다. 당신은 할 수 있습니다[`fetch()`이름 \*](/workers/runtime-apis/fetch/)Vue 신청에서 노동자에, 그 때 요구와 사용 바인딩을 취급할 수 있는.

## React 라우터는 무엇입니까?

[모델 번호: React 라우터 v7](https://reactrouter.com/)웹 응용 프로그램을 구축하기위한 풀 스택 React 프레임 워크입니다.
그것은 결합[모델 번호: Cloudflare Vite 플러그인](/workers/vite-plugin/)Cloudflare에서 앱 개발, 구축 및 배포에 대한 일류 경험을 제공합니다.

  1. **Create-cloudflare CLI(C3)로 새로운 프로젝트를 만들 수 있습니다.**

       - 추가하려면[관련 제품](/workers/runtime-apis/bindings/)Cloudflare의 개발자 플랫폼에 자원에, 당신은 여기에서 구성합니다.

## React 라우터와 연결

바인딩으로, 당신의 신청은 Cloudflare 개발자 플랫폼과 완전히 통합될 수 있어, 당신에게 compute, 저장, AI 및 더 많은 것에 접근을 줍니다.

WranglerXQ 설정 파일에 바인딩을 구성하면 다음에서 사용할 수 있습니다.`context.cloudflare`당신의 장전기 또는 활동 기능에서:

```ts title="app/routes/home.tsx"
export function loader({ context }: Route.LoaderArgs) {
	return { message: context.cloudflare.env.VALUE_FROM_CLOUDFLARE };
}

export default function Home({ loaderData }: Route.ComponentProps) {
	return <Welcome message={loaderData.message} />;
}
```

작업자 입력 파일에 직접 액세스 ()`workers/app.ts`), 당신은 또한 추가 수출을 추가할 수 있습니다[모델 번호: Durable Objects](/durable-objects/)·[Workflows](/workflows/)

<Details header="예: Workflows 사용">
  작업자 입력 파일에서 간단한 작업 흐름을 설정하는 방법의 예입니다.

  ```ts title="workers/app.ts"
  import { createRequestHandler } from "react-router";
  import { WorkflowEntrypoint, type WorkflowStep, type WorkflowEvent } from 'cloudflare:workers';

  declare global {
  	interface CloudflareEnvironment extends Env {}
  }

  type Env = {
  	MY_WORKFLOW: Workflow;
  };

  export class MyWorkflow extends WorkflowEntrypoint<Env> {
  	override async run(event: WorkflowEvent<{ hello: string }>, step: WorkflowStep) {
  		await step.do("first step", async () => {
  			return { output: "First step result" };
  		});

  		await step.sleep("sleep", "1 second");

  		await step.do("second step", async () => {
  			return { output: "Second step result" };
  		});

  		return "Workflow output";
  	}
  }

  const requestHandler = createRequestHandler(
  	() => import("virtual:react-router/server-build"),
  	import.meta.env.MODE
  );

  export default {
  	async fetch(request, env, ctx) {
  		return requestHandler(request, {
  			cloudflare: { env, ctx },
  		});
  	},
  } satisfies ExportedHandler<CloudflareEnvironment>;
  ```

  Wrangler 설정 파일에서 구성:

  <WranglerConfig>
    ```jsonc
    {
      "workflows": [
        {
          "name": "my-workflow",
          "binding": "MY_WORKFLOW",
          "class_name": "MyWorkflow"
        }
      ]
    }
    ```
  </WranglerConfig>

  그리고 그 후에 당신의 신청에서 그것을 이용합니다:

  ```ts title="app/routes/home.tsx"
  export async function action({ context }: Route.ActionArgs) {
  	const env = context.cloudflare.env;
  	const instance = await env.MY_WORKFLOW.create({ params: { "hello": "world" } })
  	return { id: instance.id, details: await instance.status() };
  }
  ```
</Details>

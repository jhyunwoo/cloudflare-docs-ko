이 가이드에서, 당신은 새로운 만들 것입니다[와쿠](https://waku.gg/)응용 프로그램 및 Cloudflare Workers에 배포 (새로운[모델 번호: Workers 투자정보](/workers/static-assets/)). Waku는 최소 React 프레임 워크입니다.[React 19](https://react.dev/blog/2024/12/05/react-19)·[React 서버 구성 요소](https://react.dev/reference/rsc/server-components). 서버 성분의 사용은 완전하게 선택적입니다. 빌드 및 출력 정적 HTML 동안 서버 구성 요소를 실행할 수 있으며 동적 React 서버 렌더링으로 실행할 수 있습니다. 상단에 내장[호노](https://hono.dev/)·[뚱 베어](https://vite.dev/).

## 1. 새로운 프로젝트를 설정

사용 방법[`create-cloudflare`](https://www.npmjs.com/package/create-cloudflare)CLI (C3)는 새로운 프로젝트를 설정합니다. C3는 새로운 프로젝트 디렉토리를 만들 것입니다, Waku의 공식 설정 도구를 시작, 즉시 배포 할 수있는 옵션을 제공합니다.

이용안내`create-cloudflare`Workers 자산으로 새로운 Waku 프로젝트를 만들려면 다음 명령을 실행하십시오.

<PackageManagers type="create" pkg="cloudflare@latest my-waku-app" args={"--framework=waku"} />

<Render
  file="c3-post-run-steps"
  product="workers"
  params={{
  	category: "web-framework",
  	framework: "Waku",
  }}
/>

프로젝트를 설정한 후 다음 명령을 실행하여 디렉토리를 변경하십시오.

```sh
cd my-waku-app
```

## 2. 현지 개발

프로젝트를 작성한 후, 프로젝트 디렉토리에서 다음 명령을 실행하여 로컬 서버를 시작합니다. 이것은 개발 중에 프로젝트를 로컬로 미리 볼 수 있습니다.

<PackageManagers type="run" args={"dev"} />

## 3. 프로젝트 배포

프로젝트에 배포할 수 있습니다.`*.workers.dev`하위 도메인 또는[주문 영역](/workers/configuration/routing/custom-domains/), 당신의 자신의 기계에서 또는 어떤 CI/CD 체계든지에서, 포함하여[Cloudflare의 자체](/workers/ci-cd/builds/).

다음 명령은 프로젝트를 빌드하고 배포합니다. CI를 사용하는 경우, 귀하의 업데이트를 확인["deploy 명령"](/workers/ci-cd/builds/configuration/#build-settings)적절하게 구성.

<PackageManagers type="run" args={"deploy"} />

***

## 회사 소개

Waku 응용 프로그램은 Cloudflare 개발자 플랫폼과 완전히 통합 될 수 있으며 로컬 개발 및 생산에서 제품 바인딩을 사용하여. 더 보기[Waku Cloudflare 문서](https://waku.gg/guides/cloudflare#accessing-cloudflare-bindings-execution-context-and-request-response-objects)React 서버 구성에 대한 정보를 제공합니다.

## 정적 자산

Waku 응용 프로그램에 정적 자산을 제공 할 수 있습니다.`./public/`디렉토리. 일반적인 예제에는 이미지, 스타일 시트, 글꼴 및 웹이 나타납니다.

빌드 과정에서 Waku 사본`.js`, `.css`, `.html`·`.txt`이 디렉토리에서 최종 자산 출력으로 파일.`.txt`파일은 빌드 시간에 렌더링 된 Server Components에 의해 사용되는 데이터를 저장하는 데 사용됩니다.

이 가이드에서, 당신은 새로운 만들 것입니다[인기 있는](https://www.gatsbyjs.com/)응용 프로그램 및 Cloudflare Workers에 배치 (새로운[모델 번호: Workers 투자정보](/workers/static-assets/)).

## 1. 새로운 프로젝트를 설정

사용 방법[`create-cloudflare`](https://www.npmjs.com/package/create-cloudflare)CLI (C3)는 새로운 프로젝트를 설정합니다. C3는 새로운 프로젝트 디렉토리를 만들 것입니다, Gatsby의 공식 설정 도구 시작, 즉시 배포 할 수있는 옵션을 제공합니다.

이용안내`create-cloudflare`Workers 자산을 사용하여 새로운 Gatsby 프로젝트를 만들려면 다음 명령을 실행하십시오.

<PackageManagers type="create" pkg="cloudflare@latest" args="my-gatsby-app --framework=gatsby" />

프로젝트를 설정한 후 다음 명령을 실행하여 디렉토리를 변경하십시오.

```sh
cd my-gatsby-app
```

## 2. 현지 개발

프로젝트를 작성한 후, 프로젝트 디렉토리에서 다음 명령을 실행하여 로컬 서버를 시작합니다. 이것은 개발 중에 프로젝트를 로컬로 미리 볼 수 있습니다.

<PackageManagers type="run" args={"dev"} />

## 3. 프로젝트 배포

프로젝트에 배포할 수 있습니다.`*.workers.dev`하위 도메인 또는[주문 영역](/workers/configuration/routing/custom-domains/), 당신의 자신의 기계에서 또는 어떤 CI/CD 체계든지에서, 포함하여[Cloudflare의 자체](/workers/ci-cd/builds/).

다음 명령은 프로젝트를 빌드하고 배포합니다. CI를 사용한다면, 업데이트할 수 있습니다["deploy 명령"](/workers/ci-cd/builds/configuration/#build-settings)적절하게 구성.

<PackageManagers type="run" args={"deploy"} />

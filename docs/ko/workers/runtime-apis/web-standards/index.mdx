## JavaScript 표준

Cloudflare Workers 런타임은[V8 JavaScript 및 WebAssembly 엔진의 상단에 내장](/workers/reference/how-workers-works/). Workers 런타임은 적어도 일주일에 한 번 업데이트되며, 현재 Google Chrome의 안정적인 릴리스에 의해 사용되는 V8 버전이 적어도 버전으로 업데이트됩니다. 즉, 최신 JavaScript 기능을 안전하게 사용할 수 있습니다.

모든 것[표준 내장 객체](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference)현재 Google Chrome 안정적인 릴리스에 의해 지원되며 몇 가지 주목할만한 예외가 있습니다.

- 보안상의 이유로 다음은 허용되지 않습니다.
  - `eval()`
  - `new Function`
  - [`WebAssembly.compile`](https://developer.mozilla.org/en-US/docs/WebAssembly/JavaScript_interface/compile_static)
  - [`WebAssembly.compileStreaming`](https://developer.mozilla.org/en-US/docs/WebAssembly/JavaScript_interface/compileStreaming_static)
  - `WebAssembly.instantiate`한국어[완충기 모수](https://developer.mozilla.org/en-US/docs/WebAssembly/JavaScript_interface/instantiate_static#primary_overload_%E2%80%94_taking_wasm_binary_code)
  - [`WebAssembly.instantiateStreaming`](https://developer.mozilla.org/en-US/docs/WebAssembly/JavaScript_interface/instantiateStreaming_static)
- `Date.now()`마지막 I/O의 시간을 반환; 그것은 코드 실행 중에 사전하지 않습니다.

## 웹 표준 및 글로벌 API

다음 방법은 다음과 같습니다.[Worker 글로벌 범위](https://developer.mozilla.org/en-US/docs/Web/API/WorkerGlobalScope):

### Base64 유틸리티 방법

- 에버()
  - base-64 인코딩을 사용하여 인코딩 된 데이터의 문자열을 디코딩합니다.

- btoa()를
  - 이진 데이터의 문자열에서 base-64 인코딩된 ASCII 문자열을 생성합니다.

### 계정 정보

- setInterval()의 정의
  - 주어진 수 milliseconds elapses를 실행하는 함수를 실행합니다.

- clearInterval()의 정의
  - 반복된 실행 설정 취소[`setInterval()`](https://developer.mozilla.org/en-US/docs/Web/API/setInterval).

- setTimeout() 설정
  - 주어진 시간에 실행하는 함수를 계획합니다.

- clearTimeout()에 대하여
  - 지연된 실행 설정 취소[`setTimeout()`](https://developer.mozilla.org/en-US/docs/Web/API/setTimeout).

- [`scheduler.wait()`](/workers/runtime-apis/scheduler/)
  - 주어진 수 밀리 초 후에 해결하는 약속을 반환합니다. 이름 \*`await`-able 대안`setTimeout()`.

:::참조

Timers는 만 사용할 수 있습니다.[요청 Context](/workers/runtime-apis/request/#the-request-context).

:::

### `performance.timeOrigin`·`performance.now()`

- 성능.timeOrigin
  - 높은 해상도 시간 기원을 반환합니다. Workers는 시간 근원으로 UNIX epoch를, 의미합니다`performance.timeOrigin`항상 반환`0`.

- 성능.now()
  - 구매하기`DOMHighResTimeStamp`이후 밀리 초의 수를 나타내는`performance.timeOrigin`. Workers는 의도적으로 정밀도를 감소시킵니다`performance.now()`그런 다음 마지막 I/O의 시간을 반환하고 코드 실행 중에 미리하지 않습니다. 이 때문에 효과적인, 그리고 때문에`performance.timeOrigin`항상,`0`, `performance.now()`항상 동등한 것`Date.now()`, 노동자 안에 시간의 통행의 일관된 전망 산출.

### `EventTarget`·`Event`

더 보기[`EventTarget`](https://developer.mozilla.org/en-US/docs/Web/API/EventTarget)·[`Event`](https://developer.mozilla.org/en-US/docs/Web/API/Event)API는 개체를 게시하고 이벤트에 가입 할 수 있습니다.

### `AbortController`·`AbortSignal`

더 보기[`AbortController`](https://developer.mozilla.org/en-US/docs/Web/API/AbortController)·[`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal)APIs는 비동기 작업을 취소하기위한 일반적인 모델을 제공합니다.

### Fetch 글로벌

- 뚱 베어()
  - 네트워크에서 리소스를 태칭하는 프로세스를 시작합니다. 더 알아보기[페치 API](/workers/runtime-apis/fetch/).

:::참조

Fetch API는 내부에서만 사용할 수 있습니다.[요청 Context](/workers/runtime-apis/request/#the-request-context).

:::

언제까지[`global_navigator`](/workers/configuration/compatibility-flags/#global-navigator)호환성 깃발은 놓입니다,[`navigator.userAgent`](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/userAgent)재산은 가치로 유효합니다`'Cloudflare-Workers'`. 이것은 예를 들면, 믿을 수 있는 Workers 환경 안에 그 부호가 실행된다는 것을 결정하기 위하여 사용될 수 있습니다.

## 자주 묻는 질문

더 보기[`unhandledrejection`](https://developer.mozilla.org/en-US/docs/Web/API/Window/unhandledrejection_event)이벤트는 JavaScript가 리젝션 핸들러가 붙어 있지 않고 글로벌 범위에 의해 방출됩니다.

더 보기[`rejectionhandled`](https://developer.mozilla.org/en-US/docs/Web/API/Window/rejectionhandled_event)이벤트는 JavaScript의 약속 거부가 늦게 처리 될 때 글로벌 범위에 의해 방출됩니다 (주사 핸들러가 약속 후 첨부됩니다`unhandledrejection`이벤트는 이미 방출되었습니다.

```js title="worker.js"
addEventListener("unhandledrejection", (event) => {
	console.log(event.promise); //거부 된 약속.
	console.log(event.reason); //약속이 거부 된 값 또는 오류.
});

addEventListener("rejectionhandled", (event) => {
	console.log(event.promise); //거부 된 약속.
	console.log(event.reason); //약속이 거부 된 값 또는 오류.
});
```

## `navigator.sendBeacon(url[, data])`

언제까지[`global_navigator`](/workers/configuration/compatibility-flags/#global-navigator)호환성 깃발은 놓입니다,[`navigator.sendBeacon(...)`](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/sendBeacon)API는 HTTP를 보낼 수 있습니다`POST`웹 서버에 소량의 데이터를 포함하는 요청. 이 API는 분석 또는 진단 정보 전달의 수단으로 최고의 노력에 비동기적으로 이루어집니다.

예를 들면, 당신은 대체할 수 있습니다:

```js
const promise = fetch("https://example.com", {
	method: "POST",
	body: "hello world",
});
ctx.waitUntil(promise);
```

이름 \*`navigator.sendBeacon(...)`:

```js
navigator.sendBeacon("https://example.com", "hello world");
```

## 웹 파일 시스템 액세스 API

언제까지`enable_web_file_system`호환성 깃발은 놓입니다, Workers는 지원합니다[웹 파일 시스템 액세스 API](https://developer.mozilla.org/en-US/docs/Web/API/File_System_Access_API), 파일을 읽고 쓰기 할 수 있습니다 그리고 노동자 환경 내에서 가상 파일 시스템에 디렉터리. 이 API는 같은 in-memory 가상 파일 시스템에 대한 액세스를 제공합니다.[`node:fs`모듈](/workers/runtime-apis/nodejs/fs/)하지만 Node.js 호환성이 필요하지 않습니다.

```js
const root = await navigator.storage.getDirectory();

export default {
	async fetch(request) {
		const fileHandle = await root.getFileHandle("hello.txt", { create: true });
		const writable = await fileHandle.createWritable();
		await writable.write("Hello, world!");
		await writable.close();

		const file = await fileHandle.getFile();
		const contents = await file.text();

		return new Response(contents, { status: 200 });
	},
};
```

자주 묻는 질문[MDN 문서](https://developer.mozilla.org/en-US/docs/Web/API/File_System_Access_API)이 API를 사용하여 더 많은 정보를 위해, 그리고에[`node:fs`관련 기사](/workers/runtime-apis/nodejs/fs/)가상 파일 시스템 구조 및 제한에 대한 세부 사항.

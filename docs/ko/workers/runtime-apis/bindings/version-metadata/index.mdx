버전 metadata 바인딩은 metadata와 관련된 접근하기 위하여 사용될 수 있습니다[이름 \*](/workers/configuration/versions-and-deployments/#versions)Workers 실행 시간 안에.

Worker version ID, 버전 태그 및 버전이 생성되었을 때의 타임스탬프는 버전 메타데이터 바인딩을 통해 사용할 수 있습니다. 그들은 사건에서 보내질 수 있습니다[모델 번호: Workers Analytics 엔진](/analytics/analytics-engine/)또는 제3자 분석 / 측정 서비스로 Worker 버전에 의해 집계합니다.

버전 메타 데이터 바인딩을 사용하려면 Worker의 Wrangler 파일을 업데이트하십시오.

<WranglerConfig>
  ```jsonc
  {
  	"version_metadata": {
  		"binding": "CF_VERSION_METADATA"
  	}
  }
  ```
</WranglerConfig>

### 제품 설명

작업자 내에서 버전 ID 및 버전 태그에 액세스하는 방법의 예는 이벤트를 보내려면[모델 번호: Workers Analytics 엔진](/analytics/analytics-engine/):

<Tabs>
  <TabItem label="모델 번호: JavaScript" icon="seti:javascript">
    ```js
    export default {
      async fetch(request, env, ctx) {
        const { id: versionId, tag: versionTag, timestamp: versionTimestamp } = env.CF_VERSION_METADATA;
        env.WAE.writeDataPoint({
          indexes: [versionId],
          blobs: [versionTag, versionTimestamp],
          //· ...
        });
        //· ...
      },
    };
    ```
  </TabItem>

  <TabItem label="모델 번호: TypeScript" icon="seti:typescript">

  </TabItem>

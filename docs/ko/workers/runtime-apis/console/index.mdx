더 보기`console`객체는 로그, 경고, 디버그 코드를 방출하는 데 도움이되는 메소드 세트를 제공합니다.

모든 표준[방법의`console`사이트맵](https://developer.mozilla.org/en-US/docs/Web/API/console)현재 위치`console`Workers에 있는 목표.

그러나 일부 방법은 ops가 없습니다. 그들은 호출 할 수 있으며 오류를 방출하지 않지만 아무것도하지 않습니다. 이 API를 사용할 수 있는 라이브러리와 호환성을 보장합니다.

아래 표는 각 방법을 enumerates, 그리고 Workers에서 지원하는 범위.

모든 방법은 "✅ 지원" 다음과 같은 행동을 가지고:

- 그들은 로컬 dev에서 콘솔에 작성됩니다 (`npx wrangler@latest dev`)
- dashboard 또는 실행에 로그를 지정할 때 라이브 로그에 표시됩니다.[`wrangler tail`](https://developers.cloudflare.com/workers/observability/log-from-workers/#use-wrangler-tail)
- 그들은 항목을 만들 것입니다`logs`주요연혁[꼬리 노동자](https://developers.cloudflare.com/workers/observability/tail-workers/)이벤트 및[모델 번호: Workers Trace 이벤트](https://developers.cloudflare.com/logs/logpush/logpush-job/datasets/account/workers_trace_events/), 당신의 선택의 목적지로 밀어질 수 있는[다운로드](https://developers.cloudflare.com/workers/observability/logpush/).

모든 방법은 " All 부분 지원" 다음과 같은 행동을 가지고:

- 두 생산 및 로컬 개발 방법은 안전하게 호출 할 수 있지만 아무것도하지 않습니다 ( op)
- 내 계정[모델 번호: Workers 회사연혁](https://workers.cloudflare.com/playground), QXQX0716XQQ dashboard 및 원격 미리보기 모드에서 빠른 편집기 ()`wrangler dev --remote`) 메소드 호출은 예상대로 행동하며 콘솔에 인쇄합니다.

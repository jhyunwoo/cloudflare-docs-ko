## 이름 \*

Worker에 HTTP 요청이 전달됩니다.`fetch()`핸들러[`Request`](/workers/runtime-apis/request/)객체. 응답 요청에 응답하려면, 반환[`Response`](/workers/runtime-apis/response/)객체:

```js
export default {
	async fetch(request, env, ctx) {
		return new Response('Hello World!');
	},
};
```

:::참조

Workers 런타임은 지원하지 않습니다`XMLHttpRequest`(XHR). 차이를 알아보기`XMLHttpRequest`·`fetch()`내 계정[사이트맵](https://developer.mozilla.org/en-US/docs/Web/API/XMLHttpRequest)문서.

:::

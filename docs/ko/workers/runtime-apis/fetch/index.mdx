더 보기[페치 API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API)Worker 내부 HTTP 요청을 통해 비동기적으로 fetching 리소스에 대한 인터페이스를 제공합니다.

:::참조

Asynchronous 작업과 같은`fetch`실행해야 한다.[회사 소개](/workers/runtime-apis/handlers/). 전화하려고 하는 경우`fetch()`내 계정[글로벌 범위](https://developer.mozilla.org/en-US/docs/Glossary/Global_scope), 당신의 노동자는 과실을 던질 것입니다. 더 알아보기[자주 묻는 질문](/workers/runtime-apis/request/#the-request-context).

:::

:::caution\[작업자]

작업자에 작업자`fetch`요청은 가능[서비스 바인딩](/workers/runtime-apis/bindings/service-bindings/)또는 활성화[`global_fetch_strictly_public`호환성 깃발](/workers/configuration/compatibility-flags/#global-fetch-strictly-public).

:::

## 이름 \*`Accept-Encoding`header는 취급됩니다

자주 묻는 질문`fetch()`API, 서버가 지원되는 것을 선호하는 압축 형태를 지정할 수 있습니다 (서버가 지원하는 경우)[`Accept-Encoding`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Accept-Encoding)헤더.

Workers는 gzip과 brotli 압축 알고리즘을 모두 지원합니다. 일반적으로 지정할 필요가 없습니다.`Accept-Encoding`또는`Content-Encoding`Workers의 헤더 Runtime 생산 환경 - brotli 또는 gzip 압축은 클라이언트와 기원 서버의 기능에 따라 클라이언트에 데이터를 반환 할 때 원래의 fetching 할 때 자동으로 요청됩니다.

기원에서 brotli 요청을 지원하려면 활성화해야합니다.[`brotli_content_encoding`](/workers/configuration/compatibility-flags/#brotli-content-encoding-support)당신의 노동자에 있는 겸용성 깃발. 곧, 이 호환성 깃발은 곧 겸용성 날짜를 과거에 모든 WorkersXQ를 위해 기본적으로 활성화될 것입니다.

### Passthrough 행동

Accept-Encoding 헤더가 유용할 수 있는 하나의 시나리오는 서버에서 클라이언트로 압축된 데이터를 전달하는 데 유용합니다. Accept-Encoding을 사용하면 작업자가 서버에서 압축된 데이터 스트림을 직접 수신할 수 있습니다. 클라이언트로 돌아가기 전에 압축 응답의 몸을 읽지 못하고 계속하십시오`Content-Encoding`header intact, 그것은 decompressed 없이 "pass through"이고 그 후에 다시 recompressed. Workers를 사용하거나 압축 된 미디어 자산을 태칭 할 때 도움이 될 수 있습니다. 원래 서버가 사용 된 동일한 압축이 작업자가 반환하는 응답에 사용됩니다.

콘텐츠 인코딩의 변경 외에도 recompression은 클라이언트가 지원되지 않는 인코딩을 사용할 때도 필요합니다. 예를 들어, Worker가 인코딩으로 brotli 또는 gzip을 요청할 때 클라이언트는 gzip을 지원하며, 서버가 서버로 brotli-encoded 데이터를 반환하면 다시 압축이 필요할 것입니다. (그리고 자동으로 적용됩니다). 이 행동은 또한 다를 수 있음[압축 규칙](/rules/compression-rules/)압축이 서버 측에 다른 유형에 적용되어야 하는 것을 구성하기 위하여 사용될 수 있는 ,.

```typescript
export default {
	async fetch(request) {
		//brotli 또는 gzip 압축을 받아들이십시오
		const headers = new Headers({
			"Accept-Encoding": "br, gzip",
		});
		let response = await fetch("https://developers.cloudflare.com", {
			method: "GET",
			headers,
		});

		//원래 응답 몸이 반환되고 Content-Encoding 헤더는
		//보존 된 동일한 인코딩 된 데이터는 다시 압축해야합니다.
		return new Response(response.body, {
			status: response.status,
			statusText: response.statusText,
			headers: response.headers,
		});
	},
};
```

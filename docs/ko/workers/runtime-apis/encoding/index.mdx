## 텍스트Encoder

### 이름 \*

더 보기`TextEncoder`입력으로 코드 포인트의 스트림을 꺼내 바이트의 스트림을 방출합니다. 생성기로 전달되는 인코딩 유형은 무시되고 UTF-8`TextEncoder`로그인

[`TextEncoder()`](https://developer.mozilla.org/en-US/docs/Web/API/TextEncoder/TextEncoder)새로 만들기`TextEncoder`UTF-8 인코딩으로 바이트 스트림을 생성합니다.`TextEncoder`매개 변수가없고 예외를 던져.

### 회사연혁

```js
let encoder = new TextEncoder();
```

### 제품 정보

- `encoder.encoding`DOMString 읽기 전용
  - encoder의 이름은 문자열을 설명하는 방법`TextEncoder`사용 (always)`utf-8`).

### 제품 설명

- <code>인코딩 (inputUSVString)</code>: Uint8Array

  - 문자열 입력을 인코딩합니다.

***

## 텍스트데코더

### 이름 \*

더 보기`TextDecoder`인터페이스는 UTF-8 디코더를 나타냅니다. Decoders는 바이트의 스트림을 입력하고 코드 포인트의 스트림을 방출합니다.

[`TextDecoder()`](https://developer.mozilla.org/en-US/docs/Web/API/TextDecoder/TextDecoder)새로 만들기`TextDecoder`코드 포인트 스트림을 생성합니다.

### 회사연혁

```js
let decoder = new TextDecoder();
```

### 제품 정보

- `decoder.encoding`DOMString 읽기 전용

  - 메서드를 설명하는 데코더의 이름`TextDecoder`이름 \*

- `decoder.fatal`boolean 읽기 전용

  - 오류 모드가 치명적인지 나타냅니다.

- `decoder.ignoreBOM`boolean 읽기 전용
  - byte-order marker가 무시되는 경우를 나타냅니다.

### 제품 설명

- `decode()`: DOMString
  - 지정된 메소드를 사용하여 디코딩`TextDecoder`객체. 더 알아보기[MDN의`TextDecoder`관련 기사](https://developer.mozilla.org/en-US/docs/Web/API/TextDecoder/decode).

사용 가능[`node:tls`](https://nodejs.org/api/tls.html)안전한 연결 만들기
외부 서비스[사이트맵](https://developer.mozilla.org/en-US/docs/Web/Security/Transport_Layer_Security)(Transport 층 보안).

```js
import { connect } from "node:tls";

//... 요청 핸들러에서 ...
const connectionOptions = { key: env.KEY, cert: env.CERT };
const socket = connect(url, connectionOptions, () => {
	if (socket.authorized) {
		console.log("Connection authorized");
	}
});

socket.on("data", (data) => {
	console.log(data);
});

socket.on("end", () => {
	console.log("server ends connection");
});
```

다음 API를 사용할 수 있습니다:

- [`connect`](https://nodejs.org/api/tls.html#tlsconnectoptions-callback)
- [`TLSSocket`](https://nodejs.org/api/tls.html#class-tlstlssocket)
- [`checkServerIdentity`](https://nodejs.org/api/tls.html#tlscheckserveridentityhostname-cert)
- [`createSecureContext`](https://nodejs.org/api/tls.html#tlscreatesecurecontextoptions)

다른 모든 API, 포함[`tls.Server`](https://nodejs.org/api/tls.html#class-tlsserver)·[`tls.createServer`](https://nodejs.org/api/tls.html#tlscreateserveroptions-secureconnectionlistener)·
지원되지 않고 던질 것`Not implemented`호출시 오류.

전체장편`node:tls`API는 문서화[Node.js 문서`node:tls`](https://nodejs.org/api/tls.html).

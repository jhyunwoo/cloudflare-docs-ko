## `MockTracker`

더 보기`MockTracker`Node.js의 API는 테스트에서 추적 및 관리의 의미를 제공합니다
환경.

```js
import { mock } from 'node:test';

const fn = mock.fn();
fn(1,2,3);  //아무것도...하지만

console.log(fn.mock.callCount());  //얼마나 많은 시간을 기록했다
console.log(fn.mock.calls[0].arguments));  //각 호출을 통과 한 인수를 거부
```

전체장편`MockTracker`API는 문서화[Node.js 문서`MockTracker`](https://nodejs.org/docs/latest/api/test.html#class-mocktracker).

Workers 구현`MockTracker`현재는 구현이 포함되지 않습니다.[Node.js 모조 타이머 API](https://nodejs.org/docs/latest/api/test.html#class-mocktimers).

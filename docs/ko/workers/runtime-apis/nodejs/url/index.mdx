## 도메인ToASCII

도메인의 Punycode ASCII serialization을 반환합니다. 도메인이 잘못된 도메인이라면 빈 문자열이 반환됩니다.

```js
import { domainToASCII } from "node:url";

console.log(domainToASCII("español.com"));
//인쇄 xn--espaol-zwa.com
console.log(domainToASCII("中文.com"));
//인쇄 xn--fiq228c.com
console.log(domainToASCII("xn--iñvalid.com"));
//빈 문자열을 인쇄
```

## 도메인ToUnicode

도메인의 Unicode serialization를 반환합니다. 도메인이 잘못된 도메인이라면 빈 문자열이 반환됩니다.

inverse 작업 수행`domainToASCII()`.

```js
import { domainToUnicode } from "node:url";

console.log(domainToUnicode("xn--espaol-zwa.com"));
//인쇄 español.com
console.log(domainToUnicode("xn--fiq228c.com"));
//저작권 © 2018 문신 예술 아이디어
console.log(domainToUnicode("xn--iñvalid.com"));
//빈 문자열을 인쇄
```

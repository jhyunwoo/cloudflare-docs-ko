더 보기[`node:assert`](https://nodejs.org/docs/latest/api/assert.html)Node.js에 있는 단위는 건물 시험을 건설할 때 유용합니다 유용한 assertions의 수를 제공합니다.

```js
import { strictEqual, deepStrictEqual, ok, doesNotReject } from "node:assert";

strictEqual(1, 1); //·
strictEqual(1, "1"); //실패! AssertionError를 던져

deepStrictEqual({ a: { b: 1 } }, { a: { b: 1 } }); //·
deepStrictEqual({ a: { b: 1 } }, { a: { b: 2 } }); //실패! AssertionError를 던져

ok(true); //·
ok(false); //실패! AssertionError를 던져

await doesNotReject(async () => {}); //·
await doesNotReject(async () => {
	throw new Error("boom");
}); //실패! AssertionError를 던져
```

:::참조

Workers 구현`assert`, 모든 assertions에서 실행, Node.js 호출, 엄격한 assertion 모드. 엄격한 assertion 형태에서, 비 제한 방법은 해당 엄격한 방법과 같습니다. 예를 들어,`deepEqual()`같은 행동`deepStrictEqual()`.
:::

더 알아보기[Node.js 문서`assert`](https://nodejs.org/dist/latest-v19.x/docs/api/assert.html)더 많은 정보.

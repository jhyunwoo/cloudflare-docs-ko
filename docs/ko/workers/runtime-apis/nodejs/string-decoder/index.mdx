더 보기[`node:string_decoder`](https://nodejs.org/api/string_decoder.html)WHATWG 표준을 미리 업데이트하는 유산 유틸리티 모듈입니다.[텍스트Encoder](/workers/runtime-apis/encoding/#textencoder)·[텍스트데코더](/workers/runtime-apis/encoding/#textdecoder)API. 대부분의 경우 사용해야 합니다.`TextEncoder`·`TextDecoder`대신.`StringDecoder`Workers 런타임은 주로 기존의 npm 패키지와 호환이 가능합니다.`StringDecoder`사용 가능:

```js
const { StringDecoder } = require("node:string_decoder");
const decoder = new StringDecoder("utf8");

const cent = Buffer.from([0xc2, 0xa2]);
console.log(decoder.write(cent));

const euro = Buffer.from([0xe2, 0x82, 0xac]);
console.log(decoder.write(euro));
```

더 알아보기[Node.js 문서`string_decoder`](https://nodejs.org/dist/latest-v20.x/docs/api/string_decoder.html)더 많은 정보.

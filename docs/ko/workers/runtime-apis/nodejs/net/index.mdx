사용 가능[`node:net`](https://nodejs.org/api/net.html)TCP 소켓을 통해 서버에 직접 연결하기
이름 \*[`net.Socket`](https://nodejs.org/api/net.html#class-netsocket).

이 기능 사용[`connect`](/workers/runtime-apis/tcp-sockets/#connect)내장에서 기능`cloudflare:sockets`모듈.

<TypeScriptExample filename="index.ts">
  ```ts
  import net from "node:net";

  const exampleIP = "127.0.0.1";

  export default {
    async fetch(req): Promise<Response> {
      const socket = new net.Socket();
      socket.connect(4000, exampleIP, function () {
        console.log("Connected");
      });

      socket.write("Hello, Server!");
      socket.end();

      return new Response("Wrote to server", { status: 200 });

  },
  } satisfies ExportedHandler;

  ```
</TypeScriptExample>

또한 다른 API와 같은[`net.BlockList`](https://nodejs.org/api/net.html#class-netblocklist)·[`net.SocketAddress`](https://nodejs.org/api/net.html#class-netsocketaddress)있습니다.

주의사항[`net.Server`](https://nodejs.org/api/net.html#class-netserver)클래스는 Workers에 의해 지원되지 않습니다.

전체장편`node:net`API는 문서화[Node.js 문서`node:net`](https://nodejs.org/api/net.html).

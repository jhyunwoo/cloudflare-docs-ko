노드:zlib 모듈은 Gzip, Deflate/Inflate, Brotli를 이용하여 구현된 압축 기능을 제공합니다.
접근하기:

```js
import zlib from "node:zlib";
```

전체장편`node:zlib`API는 문서화[Node.js 문서`node:zlib`](https://nodejs.org/api/zlib.html).

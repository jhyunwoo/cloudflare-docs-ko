Worker를 작성하면 패키지를 가져올 필요가 있습니다.[₢ 킹](https://www.npmjs.com/). 많은 npm 포장은 APIs에서 의존합니다[Node.js 런타임](https://nodejs.org/en/about)이 Node.js APIs가 유효하지 않는 한, 그리고 작동하지 않을 것입니다.

Cloudflare Workers는 2개의 모양에 있는 QXQX0465XQQ APIs의 subset를 제공합니다:

1. Workers Runtime에 의해 제공된 API로. 이러한 API의 대부분은
   대응 Node.js API의 전체 구현은 몇 가지이지만
   부분적으로 지원되거나 비 기능적인 stubs는 APIs를 위해 예정됩니다
   수입에 사용할 수 있지만 실제 사용은 아닙니다.
2. polyfill shim 구현으로[Wrangler](/workers/wrangler/)Worker의 코드를 추가하면 모듈을 가져올 수 있지만 API 메소드를 호출하면 오류를 발생시킵니다.

## 시작하기

내장 된 Node.js API를 활성화하고 polyfills를 추가하려면 추가하십시오.`nodejs_compat`호환성 플래그[Wrangler 구성 파일](/workers/wrangler/configuration/), 당신의 노동자의[호환성 날짜](/workers/configuration/compatibility-dates/)2024-09-23 이상입니다.[Node.js 호환성 깃발과 v2에 관하여 더 알아보기](/workers/configuration/compatibility-flags/#nodejs-compatibility-flag).

<WranglerConfig>
  ```jsonc
  {
  	"compatibility_flags": [
  		"nodejs_compat"
  	],
  	"compatibility_date": "$today"
  }
  ```
</WranglerConfig>

### 모델 번호: Node.js 폴리필

Node.js API는 아직 Workers 런타임에서 지원되지 않는 API를 통해 polyfilled 입니다[모델 번호: Wrangler](/workers/wrangler/), 사용[다운로드](https://github.com/unjs/unenv). 만약`nodejs_compat` [호환성 깃발](/workers/configuration/compatibility-flags/)활성화, 당신의 노동자의[호환성 날짜](/workers/configuration/compatibility-dates/)2024-09-23 또는 나중에, Wrangler는 노동자의 부호로 자동적으로 polyfills를 주사할 것입니다.

polyfills를 추가하면 기존 npm 패키지와 호환이 가능합니다. 이 모의 방법을 호출하는 것은 noop 또는 같은 메시지와 오류를 던질 것이다 :

```
[unenv] <method name> is not implemented yet!
```

이 Node.js 모듈을 사용하여 패키지를 가져올 수 있습니다.

## AsyncLocalStorage만 사용 가능

Node.js`AsyncLocalStorage`API를 사용할 수 있습니다.`nodejs_als`호환성 깃발:

<WranglerConfig>
  ```jsonc
  {
  	"compatibility_flags": [
  		"nodejs_als"
  	]
  }
  ```
</WranglerConfig>

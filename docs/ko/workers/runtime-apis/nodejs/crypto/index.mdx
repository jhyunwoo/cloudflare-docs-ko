더 보기[`node:crypto`](https://nodejs.org/docs/latest/api/crypto.html)모듈은 OpenSSL의 해시, HMAC, cipher, decipher, sign 및 확인 기능을 위한 래퍼 세트를 포함하는 암호화 기능을 제공합니다.

모든 것`node:crypto`API는 다음 예외로 Workers에서 완전히 지원됩니다:

- 이 함수[생성KeyPair](https://nodejs.org/api/crypto.html#cryptogeneratekeypairtype-options-callback)·[생성KeyPairSync](https://nodejs.org/api/crypto.html#cryptogeneratekeypairsynctype-options)DSA 또는 DH 키 쌍을 지원하지 마십시오.
- `ed448`·`x448`곡선은 지원되지 않습니다.
- 수동으로 사용하거나 비활성화 할 수 없습니다.[FIPS 모드](https://nodejs.org/docs/latest/api/crypto.html#fips-mode).

전체장편`node:crypto`API는 문서화[Node.js 문서`node:crypto`](https://nodejs.org/api/crypto.html).

더 보기[웹 크립토 API](/workers/runtime-apis/web-crypto/)Cloudflare WorkersXQ에서 또한 유효합니다. 이 없습니다.
요구 사항`nodejs_compat`호환성 깃발.

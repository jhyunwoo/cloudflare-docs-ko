더 보기[`node:path`](https://nodejs.org/api/path.html)모듈은 파일 및 디렉토리 경로 작업을위한 유틸리티를 제공합니다. 더 보기`node:path`모듈은 사용할 수 있습니다:

```js
import path from "node:path";
path.join("/foo", "bar", "baz/asdf", "quux", "..");
//반환: '/foo/bar/baz/asdf'
```

더 알아보기[Node.js 문서`path`](https://nodejs.org/api/path.html)더 많은 정보.

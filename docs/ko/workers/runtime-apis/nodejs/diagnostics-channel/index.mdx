더 보기[`diagnostics_channel`](https://nodejs.org/dist/latest-v20.x/docs/api/diagnostics_channel.html)모듈은 진단 목적으로 arbitrary 메시지 데이터를 보고하는 채널을 만드는 API를 제공합니다. API는 특별히 저 오버 헤드 진단 보고를 지원하기 위하여 디자인된 간단한 사건 pub/sub 모형입니다.

```js
import {
	channel,
	hasSubscribers,
	subscribe,
	unsubscribe,
	tracingChannel,
} from "node:diagnostics_channel";

//채널에 메시지를 게시하려면 채널 개체를 취득:
const myChannel = channel("my-channel");

//어떤 JS 값은 채널에 게시 될 수 있습니다.
myChannel.publish({ foo: "bar" });

//채널에 메시지를 수신, 구독을 사용:

subscribe("my-channel", (message) => {
	console.log(message);
});
```

모든 것`Channel`인스턴스는 각 Isolate/context(예를 들어, 동일한 엔트리 포인트)당 싱글턴입니다. 가입자는 항상 비동기적으로 보이며, 그들이 등록 된 순서에서 훨씬 좋아합니다.`EventTarget`또는 Node.js`EventEmitter`수업.

## 꼬리 Workers와 통합

사용 방법[꼬리 Workers](/workers/observability/logs/tail-workers/), 어떤 수로든지 간행된 모든 메시지는 또한 전달될 것입니다[꼬리 노동자](/workers/observability/logs/tail-workers/). 꼬리 노동자 안에, 진단 수로 메시지는 통해 접근될 수 있습니다`diagnosticsChannelEvents`이름:

```js
export default {
	async tail(events) {
		for (const event of events) {
			for (const messageData of event.diagnosticsChannelEvents) {
				console.log(
					messageData.timestamp,
					messageData.channel,
					messageData.message,
				);
			}
		}
	},
};
```

꼬리 노동자에 게시 된 메시지는 통과[구조화된 clone 알고리즘](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Structured_clone_algorithm)(same 기계장치로[`structuredClone()`](https://developer.mozilla.org/en-US/docs/Web/API/structuredClone)API) 성공적으로 복제 할 수있는 유일한 값은 지원됩니다.

## `TracingChannel`

Node.js 문서 당, "[`TracingChannel`](https://nodejs.org/api/diagnostics_channel.html#class-tracingchannel)단일 추적 가능한 작업을 표현하는 \[Channels]의 컬렉션입니다.`TracingChannel`tracing Application Flow에 대한 이벤트를 생성하고 단순화하는 데 사용됩니다.

```js
import { tracingChannel } from "node:diagnostics_channel";
import { AsyncLocalStorage } from "node:async_hooks";

const channels = tracingChannel("my-channel");
const requestId = new AsyncLocalStorage();
channels.start.bindStore(requestId);

channels.subscribe({
	start(message) {
		console.log(requestId.getStore()); //{ 요청: '123'}
		//핸들 시작 메시지
	},
	end(message) {
		console.log(requestId.getStore()); //{ 요청: '123'}
		//핸들 끝 메시지
	},
	asyncStart(message) {
		console.log(requestId.getStore()); //{ 요청: '123'}
		//핸들 asyncStart 메시지
	},
	asyncEnd(message) {
		console.log(requestId.getStore()); //{ 요청: '123'}
		//핸들 asyncEnd 메시지
	},
	error(message) {
		console.log(requestId.getStore()); //{ 요청: '123'}
		//처리 오류 메시지
	},
});

//가입자 핸들러는 async의 실행을 추적하면서 호출됩니다.
//`channel.tracePromise`XQ로 전달되는 기능 ...
channel.tracePromise(
	async () => {
		//일부 비동기 작업을 수행 ...
	},
	{ requestId: "123" },
);
```

## 이름 \*

Web Crypto API는 일반적인 암호화 작업에 대한 낮은 수준의 기능을 제공합니다. Workers 런타임은 이 API의 전체 표면을 구현하지만 일부 차이점은[지원되는 알고리즘](#supported-algorithms)대부분의 브라우저에서 구현된 사람들에 비해.

Web Crypto API를 사용하여 암호화 작업을 수행하면 JavaScript에서 순전히 수행 할 수 있습니다. CPU 기반 암호화 작업을 수행하려면 웹 Crypto API를 사용하여 고려해야합니다.

Web Crypto API가 구현되었습니다.`SubtleCrypto`인터페이스, 글로벌을 통해 접근`crypto.subtle`바인딩. digest (일컬어 hash)를 계산하는 간단한 예는:

```js
const myText = new TextEncoder().encode('Hello world!');

const myDigest = await crypto.subtle.digest(
  {
    name: 'SHA-256',
  },
  myText //arrayBuffer로 해시 할 데이터
);

console.log(new Uint8Array(myDigest));
```

몇몇 일반적인 용도는 포함합니다[서명 요청](/workers/examples/signing-requests/).

:::카트로션

Web Crypto API는 크게 다릅니다.[Node.js 암호화 API](/workers/runtime-apis/nodejs/crypto/). Node.js Crypto API에 의존하는 코드로 작업하는 경우, 활성화하여 사용할 수 있습니다.[`nodejs_compat`호환성 깃발](/workers/runtime-apis/nodejs/).
:::

2. <a name="footnote-2" />레거시 비표준 EdDSA는 Secure Curves 버전 외에도 Ed25519 곡선에 대해 지원됩니다. 이 알고리즘이 비표준이기 때문에 다음과 같은 것을 사용합니다.

   - 제품 정보<code>모델 번호: NODE-ED25519</code>알고리즘과`namedCurve`모수.
   - NodeJS와는 달리, Cloudflare는 개인적인 열쇠의 익지않는 수입품을 지원하지 않을 것입니다.
   - 알고리즘 구현은 시간이 초과될 수 있습니다. Cloudflare는 이 시간에 그것을 보장할 수 없더라도, Cloudflare는 NodeJS의 행동과 후방 겸용성 및 겸용성을 유지하기 위하여 노력할 것입니다. 모든 주목할만한 호환성 노트는 릴리스 노트와 개발자 문서를 통해 통신됩니다.

3. <a name="footnote-3" />MD5는 WebCrypto 표준의 일부가 아니지만 MD5가 요구하는 레거시 시스템과 상호 작용하는 경우 QXQX0688XQQ WorkersXQ에서 지원됩니다. MD5는 약한 알고리즘으로 간주됩니다. 보안을 위해 MD5에 의존하지 마십시오.

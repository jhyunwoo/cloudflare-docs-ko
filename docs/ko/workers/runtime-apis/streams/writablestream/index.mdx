## 이름 \*

·`WritableStream`이름 \*`writable`의 모든 호텔[`TransformStream`](/workers/runtime-apis/streams/transformstream/). Workers 플랫폼에,`WritableStream`직접 만들 수 없습니다`WritableStream`생성기.

자주 묻는 질문`WritableStream`관에 입니다[`ReadableStream`](/workers/runtime-apis/streams/readablestream/)그것으로.

```js
readableStream
  .pipeTo(writableStream)
  .then(() => console.log('All data successfully written!'))
  .catch(e => console.error('Something went wrong!', e));
```

에 쓰기`WritableStream`직접, 당신은 그것의 작가를 사용해야합니다.

```js
const writer = writableStream.getWriter();
writer.write(data);
```

## 제품 설명

- <code>(reasonstringoptional)를 구합니다</code>: 프로\<misevoid>

  - 스트림을 정렬합니다. 이 방법은 응답을 충족하는 약속을 반환`undefined`. `reason`취소의 이유를 나타내는 선택적인 인간 읽기 쉬운 끈입니다.`reason`아래 싱크의 abort 알고리즘에 전달됩니다. 이 writable 스트림이 한쪽의 a[관련 링크](/workers/runtime-apis/streams/transformstream/), 그 abort 알고리즘은 변형의 읽기 쉬운 측면을 유발합니다.`reason`.

  :::카트로션\[Warning]

  아직 작성되지 않은 모든 데이터는 abort에 손실됩니다.

## 이름 \*

독자는 당신이 읽을 때 사용됩니다[`ReadableStream`](/workers/runtime-apis/streams/readablestream/), 오히려 그것의 산출을 배관하는 것보다[`WritableStream`](/workers/runtime-apis/streams/writablestream/).

·`ReadableStreamDefaultReader`그것의 constructor를 통해 즉석이 아닙니다. Rather, 그것은에서 재생됩니다[`ReadableStream`](/workers/runtime-apis/streams/readablestream/):

```js
const { readable, writable } = new TransformStream();
const reader = readable.getReader();
```

***

## 제품 정보

- `reader.closed`: 약속

  - 독자가 닫히면 약속. 이 약속은 리더 스트림이 닫을 때 수행하고 스트림에 오류가 있으면 거부됩니다.

## 제품 설명

- `read()`: 약속

  - 독자 큐를 통해 전달되는 데이터의 다음 사용 가능한 펑크를 반환하는 약속.

- <code>취소(reasonstringoptional)</code>: void의

  - 스트림을 취소.`reason`취소의 이유를 나타내는 선택적인 인간 읽기 쉬운 끈입니다.`reason`아래 소스의 취소 알고리즘에 전달됩니다 -- 이 읽기 가능한 스트림이 한쪽의 경우[`TransformStream`](/workers/runtime-apis/streams/transformstream/), 그 취소 알고리즘은 변형의 writable 측면을 발생시켜 오류가 발생합니다.`reason`.

  :::카트로션\[Warning]

  아직 읽지 않은 모든 자료는 손실됩니다.
  주요 특징

- `releaseLock()`: void의

  - 읽기 쉬운 스트림에 잠금을 해제합니다. 독자가 읽기 작업을 종료 한 경우 잠금을 해제 할 수 없습니다. ·`TypeError`던지고 독자가 잠겨 있습니다.

## 이름 \*

·`ReadableStream`에 의해 반환`readable`재산 내부[`TransformStream`](/workers/runtime-apis/streams/transformstream/).

## 제품 정보

- `locked`한국어
  - 읽을 수있는 스트림이 독자에 잠겨 있는지 나타내는 Boolean 값.

## 제품 설명

- <code>pipeTo(destinationWritableStream, 옵션PipeToOptions)</code>: 프로\<misevoid>

  - 주어진 writable 스트림에 읽기 가능한 스트림을 파이프`destination`그리고 그 약속을 반환할 때`write`작업이 실패하면 성공하거나 거부합니다.

- <code>getReader(옵션)</code>: ReadableStreamDefaultReader의

  - 인스턴스를 가져옵니다.`ReadableStreamDefaultReader`그리고 자물쇠`ReadableStream`그 리더 인스턴스에. 이 방법은 옵션을 나타내는 객체 인수를 허용합니다. 지원되는 옵션은`mode`설정할 수 있는 ,`byob`더 보기[`ReadableStreamBYOBReader`](/workers/runtime-apis/streams/readablestreambyobreader/), 다음과 같이:

```js
let reader = readable.getReader({ mode: 'byob' });
```

### `PipeToOptions`

- `preventClose`한국어

  - 시간 :`true`, 근원의 마감`ReadableStream`대상이 되지 않습니다.`WritableStream`자주 묻는 질문

- `preventAbort`한국어

  - 시간 :`true`, 소스의 오류`ReadableStream`더 이상 목적지를 예약하지 않습니다`WritableStream`. `pipeTo`해당 이용 후기에 달린 코멘트가 없습니다.

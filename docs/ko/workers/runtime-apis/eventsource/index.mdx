## 이름 \*

더 보기[`EventSource`](https://developer.mozilla.org/en-US/docs/Web/API/EventSource)인터페이스는 서버가 클라이언트에게 이벤트를 푸시 할 수 있도록하는 API입니다. 더 보기`EventSource`객체는 server-sent 이벤트를 수신하는 데 사용됩니다. HTTP를 통해 서버에 연결하고 텍스트 기반 형식으로 이벤트를받습니다.

### 회사연혁

```js
let eventSource = new EventSource(url, options);
```

- `url`USVString - 연결 URL.
- `options`EventSourceInit - 옵션 설정이 포함 된 옵션 사전.

기본적으로,`EventSource`글로벌`fetch()`기능 아래
요청을 처리 할 수 있습니다. 다른 fetch 구현을 사용하는 경우
Cloudflare Workers 바인딩에 의해 제공해, 당신은 통과할 수 있습니다`fetcher`옵션 :

```js
export default {
  async fetch(req, env) {
    let eventSource = new EventSource(url, { fetcher: env.MYFETCHER });
    //· ...
  }
};
```

주의사항`fetcher`선택권은 Cloudflare Workers 특정한 연장입니다.

### 제품 정보

- `eventSource.url`USVString 읽기 전용
  - 이벤트 소스의 URL.
- `eventSource.readyState`USVString 읽기 전용
  - 연결 상태.
- `eventSource.withCredentials`Boolean 읽기 전용
  - 보로란은`EventSource`객체는 Cross-origin (CORS) 자격 설정으로 즉시 처리되었습니다 (`true`), 또는 아닙니다 (`false`).

### 제품 설명

- `eventSource.close()`
  - 연결 닫기.
- `eventSource.onopen`
  - 연결이 열릴 때 호출 된 이벤트 핸들러.
- `eventSource.onmessage`
  - 메시지가 수신되면 호출 된 이벤트 핸들러.
- `eventSource.onerror`
  - 오류가 발생했을 때 호출 된 이벤트 핸들러.

### (주)

- `message`
  - 메시지가 수신되면 화재.
- `open`
  - 연결이 열릴 때 화재.
- `error`
  - 오류가 발생했을 때 화재.

### 수업 방법

- <code>EventSource.from(readableStreamReadableStream) : 이벤트소스</code>
  - 이것은 새로운 것을 창조하는 Cloudflare Workers 특정한 연장입니다`EventSource`기존의 객체`ReadableStream`. 그런 인스턴스는 새로운 연결을 시작하지 않지만 제공된 스트림에 첨부합니다.

Workers 런타임은 설계되어[JavaScript 표준 준수](https://ecma-international.org/publications-and-standards/standards/ecma-262/)그리고 웹 가동 가능한. 가능한 한, 그것은 웹 플랫폼 API를 사용, 그래서 코드는 클라이언트와 서버에서 재사용 될 수있다, 뿐만 아니라[겨울CG](https://wintercg.org/)JavaScript 런타임.

[Workers 런타임 기능](/workers/runtime-apis/)이름 \*[Node.js API의 하위 세트와 호환](/workers/runtime-apis/nodejs)그리고 설정할 수있는 능력[호환성 날짜 또는 호환성 깃발](/workers/configuration/compatibility-dates/).

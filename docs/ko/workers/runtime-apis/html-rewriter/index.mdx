## 이름 \*

더 보기`HTMLRewriter`클래스는 개발자가 Cloudflare WorkersXQ 응용 프로그램 내부의 포괄적이고 표현식 HTML 패서를 구축 할 수 있습니다. Workers 응용 프로그램에서 직접 jQuery와 같은 경험으로 생각할 수 있습니다. 강력한 JavaScript API를 사용하여 HTML을 파고 변환합니다.`HTMLRewriter`개발자가 Deeply Function 응용 프로그램을 구축 할 수 있습니다.

더 보기`HTMLRewriter`클래스는 Workers 스크립트에서 한 번 즉시 처리해야합니다.`on`·`onDocument`기능.

***

## 회사연혁

```js
new HTMLRewriter()
	.on("*", new ElementHandler())
	.onDocument(new DocumentHandler());
```

***

## 글로벌 유형

채용 정보`HTMLRewriter`API, 많은 속성과 방법 사용은 몇 가지 일관된 유형이 있습니다.

- `Content`문자열 | 응답 | ReadableStream
  - 출력 스트림에 삽입 된 콘텐츠는 문자열이어야한다,[`Response`](/workers/runtime-apis/response/), 또는[`ReadableStream`](/workers/runtime-apis/streams/readablestream/).

- `ContentOptions`계정 만들기
  - `{ html: Boolean }`HTMLRewriter는 삽입된 내용을 대우합니다. 만약에`html`boolean은 true로 설정되며, 콘텐츠는 HTML로 처리됩니다. 만약에`html`boolean은 false 또는 제공하지 않습니다. 텍스트와 적절한 HTML escaping으로 콘텐츠가 처리됩니다.

***

## 핸들러

함께 사용할 수있는 두 가지 핸들러 유형이 있습니다.`HTMLRewriter`: 요소 핸들러 및 문서 핸들러.

### 성분 Handlers

요소 핸들러는 어떤 들어오는 요소에 반응합니다.`.on`기능의`HTMLRewriter`예. 요소 핸들러가 응답해야 합니다.`element`, `comments`·`text`. 예제 프로세스`div`요소와`ElementHandler`수업.

```js
class ElementHandler {
	element(element) {
		//`div`와 같은 들어오는 성분
		console.log(`Incoming element: ${element.tagName}`);
	}

	comments(comment) {
		//자주 묻는 질문
	}

	text(text) {
		//텍스트의 들어오는 조각
	}
}

async function handleRequest(req) {
	const res = await fetch(req);

	return new HTMLRewriter().on("div", new ElementHandler()).transform(res);
}
```

### 문서 핸들러

문서 핸들러는 들어오는 HTML 문서를 나타냅니다. 문서 핸들러에 정의되어 문서의 조작을 할 수 있습니다.`doctype`, `comments`, `text`·`end`. 요소 핸들러와는 달리 문서 핸들러의`doctype`, `comments`, `text`·`end`함수는 특정 selector에 의해 배열되지 않습니다. 문서 핸들러의 기능은 top-level HTML 태그 이외의 콘텐츠를 포함하여 페이지의 모든 콘텐츠에 사용됩니다.

```js
class DocumentHandler {
	doctype(doctype) {
		//<!DOCTYPE html>과 같은 들어오는 문서
	}

	comments(comment) {
		//자주 묻는 질문
	}

	text(text) {
		//텍스트의 들어오는 조각
	}

	end(end) {
		//문서의 끝
	}
}
```

#### Async 핸들러

모두 요소와 문서 핸들러에 정의 된 모든 기능 중 하나를 반환 할 수 있습니다`void`또는`Promise<void>`. 핸들러 기능을 만들기`async`fetch, Workers KV, Durable ObjectsXQ, 또는 캐시를 통해 API와 같은 외부 리소스에 액세스 할 수 있습니다.

```js
class UserElementHandler {
	async element(element) {
		let response = await fetch(new Request("/user"));

		//응답을 사용하여 사용자 정보 작성
	}
}

async function handleRequest(req) {
	const res = await fetch(req);

	//ID `user_info`를 사용하여 사용자 요소 핸들러를 실행
	return new HTMLRewriter()
		.on("div#user_info", new UserElementHandler())
		.transform(res);
}
```

### 텍스트 펑크

Cloudflare는 제로 복사 스트리밍을 수행하므로 텍스트 펑크는 lexical 트리의 텍스트 노드와 동일하지 않습니다. lexical 트리 텍스트 노드는 여러 개의 펑크로 표현할 수 있으며, 원래의 와이어에 도착합니다.

뒤에 오는 markup를 고려하십시오:`<div>Hey. How are you?</div>`. Workers 스크립트가 원시에서 전체 텍스트 노드를 한 번에 수신하지 않을 수 있음을 가능합니다. 대신,`text`엘리먼트 핸들러는 각 텍스트 노드의 수신된 부분을 호출합니다. 예를 들어, 핸들러가 호출될 수 있습니다.`"Hey. How "`, 다음`"are you?"`. 마지막 펑크가 도착하면 텍스트의`lastInTextNode`숙박 시설`true`. 개발자는 이러한 펑크를 함께 concatenate해야합니다.

#### 제품 정보

- `removed`한국어
  - 요소가 제거되거나 이전 핸들러 중 하나에 의해 대체되었는지 나타냅니다.

## 이름 \*

이것은 어떤 선택자이며 그들이 사용하는 것입니다.

- `*`
  - 모든 요소.

- `E`
  - 유형 E의 어떤 성분.

- `E:nth-child(n)`
  - E 요소, 부모의 n-th 아이.

- `E:first-child`
  - E 요소, 부모의 첫 아이.

- `E:nth-of-type(n)`
  - E 요소, 그것의 유형의 n-th sibling.

- `E:first-of-type`
  - E 요소, 그것의 유형의 첫 번째 주사.

- `E:not(s)`
  - 화합물 선택자를 일치하지 않는 E 요소.

- `E.warning`
  - 클래스 경고에 속하는 E 요소.

- `E#myid`
  - ID와 같은 ID를 가진 E 성분.

- `E[foo]`
  - foo 속성이있는 E 요소.

- `E[foo="bar"]`
  - foo 속성 값이 바와 똑같은 E 요소.

- `E[foo="bar" i]`
  - foo 속성 값이 어떤 (ASCII-range)의 경우의 비율과 정확히 동일하게되는 E 요소.

- `E[foo="bar" s]`
  - foo 속성 값이 정확하고 현명하게 바와 동일 한 E 요소.

- `E[foo~="bar"]`
  - foo 속성 값이있는 E 요소는 whitespace-separated 값의 목록입니다.

- `E[foo^="bar"]`
  - foo 속성 값이 문자열 바와 정확히 시작되는 E 요소.

- `E[foo$="bar"]`
  - foo 속성 값이 문자열 바와 정확히 끝나는 E 요소.

- `E[foo*="bar"]`
  - foo 속성 값이 하위 문자열 바를 포함 한 E 요소.

- `E[foo|="en"]`
  - foo 속성 값이있는 E 요소는 en로 시작하는 값의 hyphen-separated 목록입니다.

- `E F`
  - F 요소는 E 요소의 후손입니다.

- `E > F`
  - E 요소의 F 요소 어린이.

## 계정 관리

핸들러가 예외를 던지면, 패싱은 즉시 반감됩니다. 변형 된 응답 몸은 thrown 예외로 과실되며 전달되지 않은 응답 몸은 취소됩니다 (닫히는). 변형 된 응답 몸이 이미 부분적으로 클라이언트로 돌아가면 클라이언트는 truncated 응답을 볼 수 있습니다.

```js
async function handle(request) {
	let oldResponse = await fetch(request);
	let newResponse = new HTMLRewriter()
		.on("*", {
			element(element) {
				throw new Error("A really bad error.");
			},
		})
		.transform(oldResponse);

	//이 시점에서 `await newResponse.text()`
	//`new Error("A really bad error.")`를 던질 것입니다.
	//거기, `newResponse.body`의 어떤 사용은 동일한 과실을 던질 것입니다,
	//그리고 `oldResponse.body`는 닫힐 것입니다.

	//대안으로, 이것은 클라이언트에게 truncated 응답을 생성할 것입니다:
	return newResponse;
}
```

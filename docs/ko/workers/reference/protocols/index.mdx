Cloudflare Workers는 뒤에 오는 의정서 및 공용영역을 지원합니다:

| 프로젝트             | 인바운드                                                                                                                                                                                                                                                         | 아웃바운드                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| **HTTP / HTTPS** | HTTP 요청 처리[`fetch()`회사 소개](/workers/runtime-apis/handlers/fetch/)                                                                                                                                                                                            | HTTP subrequests 만들기[`fetch()`사이트맵](/workers/runtime-apis/fetch/)     |
| **직접 TCP 소켓**    | inbound TCP 연결 처리 지원[현재 위치](https://blog.cloudflare.com/workers-tcp-socket-api-connect-databases/)                                                                                                                                                           | 아웃바운드 TCP 연결 만들기[`connect()`사이트맵](/workers/runtime-apis/tcp-sockets/) |
| **웹소켓**          | WebSocket 연결 수신[`WebSocket`사이트맵](/workers/runtime-apis/websockets/)                                                                                                                                                                                          |                                                                       |
| **HTTP/3 (필수)**  | inbound 요청을 수락[HTTP / 1 페이지](https://www.cloudflare.com/learning/performance/what-is-http3/)로그인[이름 \*](/fundamentals/concepts/accounts-and-zones/#zones)내 계정**제품 정보** > **계정 설정** > **Protocol 최적화**지역의[Cloudflare dashboard](https://dash.cloudflare.com/). |                                                                       |
| **사이트맵**         | 제품 정보[이메일 Workers](/email-routing/email-workers/)SMTP 이메일 서버에 TCP 연결을 관리하지 않고 처리 및 전달 이메일                                                                                                                                                                    | [이메일 Workers](/email-routing/email-workers/)                          |

더 보기[Sender 정책 프레임 워크 (SPF)](https://datatracker.ietf.org/doc/rfc4408/)사양은 SPF 레코드를 완전히 해결해야 DNS 조회 수에 제한이 있습니다. 명세에 따르면 SPF는 SPF 검사 당 10에 DNS 조회의 수를 제한해야 합니다. SPF 레코드가 이 번호를 초과하는 경우, 귀하의 이메일은 목적지에 도달하지 않을 수 있습니다.

SPF 레코드가 SPF 사양과 호환되는지 확인하려면:

1. 로그인하기[‘Cloudflare’ ‘대시보드’](https://dash.cloudflare.com/), 귀하의 계정과 도메인을 선택합니다.
2. 오시는 길**이름 \*** > **DMARC 관리**.
3. 내 계정**이메일 기록 개요**, 선택**기록 보기**.
4. SPF 레코드를 찾아 다음 세 가지 점을 선택하세요 >**제품정보**.
5. 사이트맵 관리는 기록과 DNS 조회의 총 수를 검사합니다. 기록이 DNS 조회의 최대 수를 초과하면 DMARC 관리는 이것에 대해 경고합니다. DNS 페이지에서 불필요한 레코드를 편집하고 제거해야합니다. 더 알아보기[DNS 레코드 관리](/dns/manage-dns-records/how-to/create-dns-records/#delete-dns-records)DNS 레코드를 삭제하는 방법에 대한 자세한 내용은.

## 보안 레코드 생성

이메일 보안 기록을 설정하려면:

1. 로그인하기[‘Cloudflare’ ‘대시보드’](https://dash.cloudflare.com/), 귀하의 계정과 도메인을 선택합니다.
2. 오시는 길**이름 \*** > **DMARC 관리**.
3. 내 계정**이메일 기록 개요**, 선택**기록 보기**.
4. 설정 가능한 옵션을 사용하여[사이트맵](https://www.cloudflare.com/en-gb/learning/dns/dns-records/dns-spf-record/), [사이트맵](https://www.cloudflare.com/en-gb/learning/dns/dns-records/dns-dkim-record/)·[DMARC 기록](https://www.cloudflare.com/en-gb/learning/dns/dns-records/dns-dmarc-record/). 이 페이지는 또한 당신의 계정에 이미 있을 수 있는 이전 기록들을 나열할 것입니다.

## 편집 또는 삭제 기록

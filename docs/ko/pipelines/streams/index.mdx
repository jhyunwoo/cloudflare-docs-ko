Streams는 내구성, 버퍼링 queues that receive and store event for processing in[모델 번호: Cloudflare 파이프 라인](/pipelines/). 그들은 HTTP endpoints 및 Worker 바인딩을 통해 신뢰할 수있는 데이터 ingestion을 제공하며, 다운스트림 처리 지연 또는 실패 중에 데이터 손실을 방지합니다.

단일 스트림은 여러 개의 파이프라인에 의해 읽을 수 있으며, 다른 목적지로 동일한 데이터를 경로를 통과하거나 다른 변환을 적용합니다. 예를 들어 실시간 분석 파이프라인과 데이터 창고 파이프라인 모두에 사용자 이벤트를 보낼 수 있습니다.

스트림은 현재 JSON 형식의 이벤트를 수락하고 정의 된 스키마와 unstructured JSON으로 구성 된 이벤트를 지원합니다. 스키마가 제공되면 스트림이 유효하며 들어오는 이벤트를 시행합니다.

싱크는 Cloudflare 파이프 라인의 데이터를 위한 목적지를 정의합니다. 그들은 쓰기를 지원[R2 데이터 카탈로그](/r2/data-catalog/)아파치 Iceberg 테이블 또는[모델 번호: R2](/r2/)raw JSON 또는 Parquet 파일로.

싱크는 정확하게 온스 납품 보증을 제공하고, 사건을 결코 복제하거나 떨어뜨리지 않습니다. 그들은 더 큰, 더 나은 쿼리 성능을 위해 더 적은 빈번한 파일을 작성하기 위해 파일을 자주 쓸 수 있습니다.

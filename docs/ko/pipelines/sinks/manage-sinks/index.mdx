학습 방법:

- Data Storage용 싱크 생성 및 구성
- 싱크 구성 보기
- 더 이상 필요로 할 때 싱크대 삭제

## 비밀번호

싱크는 싱크 이름을 사용하여 SQL 테이블로 파이프라인에 사용할 수 있습니다 (예 :`INSERT INTO my_sink SELECT * FROM my_stream`).

### 대시보드

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**파이프 라인**사이트 맵

     <DashButton url="/?to=/:account/pipelines/overview" />
  2. 제품정보**Pipeline 만들기**파이프라인 생성 마법사를 시작합니다.
  3. 관련 스트림 및 파이프라인과 함께 싱크를 만들 수 마법사를 완료하십시오.
</Steps>

### Wrangler 클립

싱크를 만들려면, 실행[`pipelines sinks create`](/workers/wrangler/commands/#pipelines-sinks-create)명령:

```bash
npx wrangler pipelines sinks create <SINK_NAME> \
  --type r2 \
  --bucket my-bucket \
```

싱크 특정 구성 옵션의 경우, 참조[사용 가능한 싱크](/pipelines/sinks/available-sinks/).

대신, 스트림, 싱크 및 파이프라인을 구성하는 데 도움이되는 대화형 설정 마법사를 사용하려면[`pipelines setup`](/workers/wrangler/commands/#pipelines-setup)명령:

```bash
npx wrangler pipelines setup
```

## 싱크 구성 보기

### 대시보드

<Steps>
  1. Cloudflare 대시보드에서, 갑니다**파이프 라인** > **관련 상품**.

  2. 싱크를 선택하여 구성을 볼 수 있습니다.
</Steps>

### Wrangler 클립

특정 싱크를 보시려면, 실행[`pipelines sinks get`](/workers/wrangler/commands/#pipelines-sinks-get)명령:

```bash
npx wrangler pipelines sinks get <SINK_ID>
```

계정에 모든 싱크를 나열하려면, 실행[`pipelines sinks list`](/workers/wrangler/commands/#pipelines-sinks-list)명령:

```bash
npx wrangler pipelines sinks list
```

## 싱크 삭제

### 대시보드

<Steps>
  1. Cloudflare 대시보드에서, 갑니다**파이프 라인** > **관련 상품**.

  2. 삭제하려는 싱크를 선택합니다.

  3. 내 계정**계정 설정**탭, 탐색**주요사업**, 그리고 선택**이름 \***.
</Steps>

### Wrangler 클립

싱크를 삭제하려면, 실행[`pipelines sinks delete`](/workers/wrangler/commands/#pipelines-sinks-delete)명령:

```bash
npx wrangler pipelines sinks delete <SINK_ID>
```

:::카트로션
싱크를 삭제하는 모든 데이터는 그 목적지에 쓰기.
주요 특징

## 제한 사항

- 싱크는 생성 후에 수정될 수 없습니다. 싱크 구성을 변경하려면 싱크를 삭제하고 다시 생성해야합니다.
- R2 데이터 카탈로그 싱크는 현재 다른 관할권으로 R2 물통에 쓰기를 지원하지 않습니다.

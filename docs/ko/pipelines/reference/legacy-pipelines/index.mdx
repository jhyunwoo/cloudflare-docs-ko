레거시 파이프라인은 유산 API를 통해 9 월 25, 2025 전에 생성 된 것입니다.

파이프라인이 레거시 파이프라인인 경우, 아래 대시보드에서 볼 수 있습니다.**파이프 라인** > **파이프 라인**또는 실행[`pipelines list`](/workers/wrangler/commands/#pipelines-list)명령에서[모델 번호: Wrangler](/workers/wrangler/). 레거시 파이프라인은 둘 다 위치에 있는 “legacy” 상표를 붙입니다.

새로운 파이프라인은 SQL 변환, 다중 출력 형식 및 향상된 아키텍처를 제공합니다.

## 변경 사항

- 새로운 파이프라인은 데이터 처리를위한 SQL 변환을 지원합니다.
- 새로운 파이프라인은 JSON 대신 JSON, Parquet 및 Apache Iceberg 형식으로 작성합니다.
- 새로운 파이프라인은 분리된 시내, 파이프라인 및 다른 자원으로 싱크.
- 새로운 파이프라인은 검증을 가진 선택적인 Structured schemas를 지원합니다.
- 새로운 파이프라인은 구성할 수 있는 회전 정책 및 customizable 분할을 제안합니다.

## 새로운 파이프로 이동

레거시 파이프 라인은 일반적으로 사용할 수 있지만 새로운 기능과 개선은 새로운 파이프라인 아키텍처에서만 사용할 수 있습니다. 태그 :

1. 대화형 설정으로 새로운 파이프라인 만들기:

   ```bash
   npx wrangler pipelines setup
   ```

2. 원하는 스트림, SQL 변환 및 싱크로 새로운 파이프라인 구성.

3. 새 스트림 엔드포인트에 데이터를 보내려면 응용 프로그램을 업데이트하십시오.

4. 확인되면 레거시 파이프라인을 삭제합니다.

상세한 지도를 위해, 참조[자주 묻는 질문](/pipelines/getting-started/).

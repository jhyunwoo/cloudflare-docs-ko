SELECT 문은 Cloudflare 파이프 라인의 데이터를 변환하는 데 사용됩니다. 일반적인 형태는:

```sql
[WITH with_query [, ...]]
SELECT select_expr [, ...]
FROM from_item
[WHERE condition]
```

## 이름 \*

항목은 기본 쿼리에서 참고 자료d 될 수있는 하위 쿼리를 정의 할 수 있습니다. 이것은 복잡한 변환을 파괴함으로써 쿼리의 readability를 향상시킬 수 있습니다.

Syntax:

```sql
WITH query_name AS (subquery) [, ...]
```

간단한 예:

```sql
WITH filtered_events AS
    (SELECT user_id, event_type, amount
        FROM user_events WHERE amount > 50)
SELECT user_id, amount * 1.1 as amount_with_tax
FROM filtered_events
WHERE event_type = 'purchase';
```

## SELECT 항목

SELECT 항목은 선택적 별명과 더불어 표현의 필수 목록입니다. 열 이름은 독특해야합니다.

```sql
SELECT select_expr [, ...]
```

예제:

```sql
-- Select specific columns
SELECT user_id, event_type, amount FROM events

-- Use expressions and aliases
SELECT
    user_id,
    amount * 1.1 as amount_with_tax,
    UPPER(event_type) as event_type_upper
FROM events

-- Select all columns
SELECT * FROM events
```

## 이름 \*

항목은 쿼리에 대한 데이터 소스를 지정합니다. 테이블 이름 또는 복부가 될 것입니다. 테이블 이름은 점에서 만든 스트림 이름 또는 테이블 일 수 있습니다.

```sql
FROM from_item
```

표는 별명으로 주어질 수 있습니다:

```sql
SELECT e.user_id, e.amount
FROM user_events e
WHERE e.event_type = 'purchase'
```

## WHERE 항목

boolean 조건을 사용하여 WHERE 항목 필터 데이터. Predicates는 입력 행에 적용됩니다.

```sql
WHERE condition
```

예제:

```sql
-- Filter by field value
SELECT * FROM events WHERE event_type = 'purchase'

-- Multiple conditions
SELECT * FROM events
WHERE event_type = 'purchase' AND amount > 50

-- String operations
SELECT * FROM events
WHERE user_id LIKE 'user_%'

-- Null checks
SELECT * FROM events
WHERE description IS NOT NULL
```

## UNNEST 연산자

UNNEST 연산자는 여러 행으로 배열을 변환합니다. 이것은 목록 자료 유형 가공에 유용합니다.

UNNEST 제한:

- SELECT 항목 만 나타날 수 있습니다
- 1개의 배열은 SELECT 문 당 unnested 일지도 모릅니다

예:

```sql
SELECT
    UNNEST([1, 2, 3]) as numbers
FROM events;
```

이것은 생성할 것입니다:

```
+---------+
| numbers |
+---------+
|       1 |
|       2 |
|       3 |
+---------+
```

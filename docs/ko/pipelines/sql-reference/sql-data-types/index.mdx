Cloudflare Pipelines는 SQL 변환에 대한 primitive 및 복합 데이터 유형의 세트를 지원합니다. 이 유형은 스트림 스키마 및 SQL 리터럴에서 자동 유형 인섭을 사용할 수 있습니다.

## Primitive 유형

| 파이프 라인      | SQL 유형                              | 예제 리터럴                                               |
| ----------- | ----------------------------------- | ---------------------------------------------------- |
| `bool`      | `BOOLEAN`                           | `TRUE`, `FALSE`                                      |
| `int32`     | `INT`, `INTEGER`                    | `0`, `1`, `-2`                                       |
| `int64`     | `BIGINT`                            | `0`, `1`, `-2`                                       |
| `float32`   | `FLOAT`, `REAL`                     | `0.0`, `-2.4`, `1E-3`                                |
| `float64`   | `DOUBLE`                            | `0.0`, `-2.4`, `1E-35`                               |
| `string`    | `VARCHAR`, `CHAR`, `TEXT`, `STRING` | `"hello"`, `"world"`                                 |
| `timestamp` | `TIMESTAMP`                         | `'2020-01-01'`, `'2023-05-17T22:16:00.648662+00:00'` |
| `binary`    | `BYTEA`                             | `X'A123'`(헥스)                                        |
| `json`      | `JSON`                              | `'{"event": "purchase", "amount": 29.99}'`           |

## 복합형

primitive 유형 외에도 Pipelines SQL은 더 복잡한 데이터 구조를 위한 복합 유형을 지원합니다.

### 회사 소개

동일한 유형의 0 또는 더 많은 요소를 함께 목록 그룹. 스트림 스키마에서 목록은 선언됩니다.`list`유형과`items`요소 유형 지정 필드. SQL에서는, 목록은 배열에 대응하고 다른 유형에 suffixing에 의해 선언됩니다`[]`예를 들어`INT[]`.

목록 값은 1-indexed subscript 표기를 이용하여 인덱스될 수 있습니다.`v[1]`첫 번째 요소는`v`).

목록은 통해 건설될 수 있습니다`[]`리터:

```sql
SELECT [1, 2, 3] as numbers
```

Pipelines는 목록 값을 조작하기 위한 배열 기능을 제공하고, 목록은 unnested 사용될지도 모릅니다`UNNEST`회사 소개

### Struct 유형

Structs는 관련 분야를 단일 값으로 결합합니다. 스트림 스키마에서, structs는 선언`struct`유형과`fields`배열. SQL에서, structs는 창조될 수 있습니다`struct`기능.

SQL에서 struct를 만드는 예제:

```sql
SELECT struct('user123', 'purchase', 29.99) as event_data FROM events
```

이 필드에 struct를 만듭니다.`c0`, `c1`, `c2`사용자 ID, 이벤트 유형 및 금액 포함.

Struct 필드를 통해 액세스 할 수 있습니다`.`예를 들어,`event_data.c0`사용자 ID.

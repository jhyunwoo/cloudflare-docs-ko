## `date_bin`

시간 간격을 계산하고 지정된 타임스탬프에 가장 가까운 간격의 시작을 반환합니다.
제품 정보`date_bin`as downsample time series data by grouping rows into time-based "bins" 또는 "windows"
각 창에 집합 또는 선택기 기능을 적용하십시오.

예를 들어, "bin" 또는 "window" 데이터가 15 분 간격으로 입력하면
타임 스탬프`2023-01-01T18:18:18Z`15의 시작 시간에 업데이트됩니다
분 궤 그것은 안으로 입니다:`2023-01-01T18:15:00Z`.

```
date_bin(interval, expression, origin-timestamp)
```

**이름 \***

- **관련 상품**: 빈 간격.
- **이름 \***: 운영 시간표
  일정한, 란, 또는 기능일 수 있습니다.
- **근원 timestamp**: 옵션. bin 경계를 결정하는 데 사용 된 지점. 지정하지 않은 경우
  기본 정보`1970-01-01T00:00:00Z`(UTC의 UNIX epoch).

다음의 간격은 지원됩니다:

- 나노초
- 마이크로 초
- 밀리 초
- 지원하다
- 1시간
- 영업시간
- 일 시
- 주 메뉴
- 1 개월 전
- \- 연혁
- 한국어

## `extract`

정수로 시간 값에서 하위 필드를 반환합니다.

```
extract(field FROM source)
```

자주 묻는 질문`date_part('field', source)`. 예를 들면, 이들은 동등합니다:

```sql
extract(day FROM '2024-04-13'::date)
date_part('day', '2024-04-13'::date)
```

이름 \*[날짜 부](#date_part).

## `to_timestamp`

타임스탬프에 값을 변환 (`YYYY-MM-DDT00:00:00Z`).
문자열, 정수, unsigned integer, 그리고 입력으로 두 배 유형 지원.
문자열은 RFC3339 (예 : '2023-07-20T05:44:00')로 나뉩니다.
Integers, unsigned integers, 그리고 두 배는 unix epoch (`1970-01-01T00:00:00Z`).
해당 타임스탬프를 반환합니다.

참고 :`to_timestamp`이름 \*`Timestamp(Nanosecond)`. integer 입력을 위한 지원된 범위는 사이 입니다`-9223372037`·`9223372036`·
문자열 입력에 대한 지원 범위는 사이`1677-09-21T00:12:44.0`·`2262-04-11T23:47:16.0`. 이용`to_timestamp_seconds`지원되는 경계의 밖에 입력을 위해.

```
to_timestamp(expression[, ..., format_n])
```

**이름 \***

- **이름 \***: 운영되는 표현.
  일정한, 란, 또는 기능 및 arithmetic 통신수의 어떤 조합일 수 있습니다.
- **형식 n**: 옵션[Chrono 형식][Chrono format]문자열을 사용하여 표현을 파싱합니다. 체재는 순서에서 시도될 것입니다
  그들은 첫 번째 성공으로 나타났습니다. 형식의 아무도 성공적으로 표현
  오류가 반환됩니다.

[chrono format]: https://docs.rs/chrono/latest/chrono/format/strftime/index.html

**이름 \***

```
> select to_timestamp('2023-01-31T09:26:56.123456789-05:00');
+-----------------------------------------------------------+
| to_timestamp(Utf8("2023-01-31T09:26:56.123456789-05:00")) |
+-----------------------------------------------------------+
| 2023-01-31T14:26:56.123456789                             |
+-----------------------------------------------------------+
> select to_timestamp('03:59:00.123456789 05-17-2023', '%c', '%+', '%H:%M:%S%.f %m-%d-%Y');
+--------------------------------------------------------------------------------------------------------+
| to_timestamp(Utf8("03:59:00.123456789 05-17-2023"),Utf8("%c"),Utf8("%+"),Utf8("%H:%M:%S%.f %m-%d-%Y")) |
+--------------------------------------------------------------------------------------------------------+
| 2023-05-17T03:59:00.123456789                                                                          |
+--------------------------------------------------------------------------------------------------------+
```

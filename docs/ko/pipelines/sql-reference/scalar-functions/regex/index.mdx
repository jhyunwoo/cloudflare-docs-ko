## `regexp_like`

반환 true 경우[일반 표현][regular expression]문자열에 적어도 하나의 일치가,
그렇지 않으면.

[regular expression]: https://docs.rs/regex/latest/regex/#syntax

```
regexp_like(str, regexp[, flags])
```

**이름 \***

- **사이트맵**: 동작하는 문자열 표현.
  연속, 열, 또는 기능 및 문자열 연산자의 모든 조합이 될 수 있습니다.
- **구매하기**: 문자열 표현에 대해 테스트하는 정규식.
  일정한, 란, 또는 기능일 수 있습니다.
- **기본 정보**: 선택적 정규 표현식 플래그는 동작을 제어합니다.
  일반 표현. 뒤에 오는 깃발은 지원됩니다:
  - **이름 \***: case-insensitive : 문자는 위와 더 낮은 케이스 모두 일치
  - **m/분**: 멀티 라인 모드 : ^ 및 $ 일치 시작 / 라인 종료
  - **₢ 킹**: \n에 일치 할 수 있음
  - **사이트맵**: CRLF 모드가 활성화되면 \r\n이 사용됩니다.
  - **·**: x\*와 x\*의 의미를 교환합니까?

**이름 \***

```sql
select regexp_like('Köln', '[a-zA-Z]ö[a-zA-Z]{2}');
+--------------------------------------------------------+
| regexp_like(Utf8("Köln"),Utf8("[a-zA-Z]ö[a-zA-Z]{2}")) |
+--------------------------------------------------------+
| true                                                   |
+--------------------------------------------------------+
SELECT regexp_like('aBc', '(b|d)', 'i');
+--------------------------------------------------+
| regexp_like(Utf8("aBc"),Utf8("(b|d)"),Utf8("i")) |
+--------------------------------------------------+
| true                                             |
+--------------------------------------------------+
```

추가 예제를 찾을 수 있습니다.[이름 \*](https://github.com/apache/datafusion/blob/main/datafusion-examples/examples/regexp.rs)

## `regexp_replace`

일치 문자열에 substrings를 대체합니다.[일반 표현](https://docs.rs/regex/latest/regex/#syntax).

```
regexp_replace(str, regexp, replacement[, flags])
```

**이름 \***

- **사이트맵**: 동작하는 문자열 표현.
  연속, 열, 또는 기능 및 문자열 연산자의 모든 조합이 될 수 있습니다.
- **구매하기**: 일반 표현
  일정한, 란, 또는 기능일 수 있습니다.
- **기타 제품**: 교체 문자열 표현.
  연속, 열, 또는 기능 및 문자열 연산자의 모든 조합이 될 수 있습니다.
- **기본 정보**: 선택적 정규 표현식 플래그는 동작을 제어합니다.
  일반 표현. 뒤에 오는 깃발은 지원됩니다:
  - **사이트맵**: (global) 글로벌 검색 및 첫 경기 후 반환하지 마십시오
  - **이름 \***: case-insensitive : 문자는 위와 더 낮은 케이스 모두 일치
  - **m/분**: 멀티 라인 모드 : ^ 및 $ 일치 시작 / 라인 종료
  - **₢ 킹**: \n에 일치 할 수 있음
  - **사이트맵**: CRLF 모드가 활성화되면 \r\n이 사용됩니다.
  - **·**: x\*와 x\*의 의미를 교환합니까?

**이름 \***

```sql
SELECT regexp_replace('foobarbaz', 'b(..)', 'X\\1Y', 'g');
+------------------------------------------------------------------------+
| regexp_replace(Utf8("foobarbaz"),Utf8("b(..)"),Utf8("X\1Y"),Utf8("g")) |
+------------------------------------------------------------------------+
| fooXarYXazY                                                            |
+------------------------------------------------------------------------+
SELECT regexp_replace('aBc', '(b|d)', 'Ab\\1a', 'i');
+-------------------------------------------------------------------+
| regexp_replace(Utf8("aBc"),Utf8("(b|d)"),Utf8("Ab\1a"),Utf8("i")) |
+-------------------------------------------------------------------+
| aAbBac                                                            |
+-------------------------------------------------------------------+
```

추가 예제를 찾을 수 있습니다.[이름 \*](https://github.com/apache/datafusion/blob/main/datafusion-examples/examples/regexp.rs)

## `position`

반환의 위치`substr`내 계정`origstr`(1에서). 이름 \*`substr`이름 \*
에 표시되지 않음`origstr`, 반환 0.

```
position(substr in origstr)
```

**이름 \***

- **서브스트리트**: 패턴 문자열.
- **파일 형식**: 모델 문자열.

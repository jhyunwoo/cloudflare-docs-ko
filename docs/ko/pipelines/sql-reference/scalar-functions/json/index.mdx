기능 및 구문 및 두 번째 기반

## SQL 기능

SQL 함수는 기본 JSON 파싱 함수를 사용하여 발견된 것들과 비슷한 기능을 제공합니다.
프로젝트

### json 컨테이너

기타 제품`true`JSON 문자열이 지정된 키(s)를 포함합니다.

```sql
SELECT json_contains('{"a": 1, "b": 2, "c": 3}', 'a') FROM source;
true
```

또한 이용 가능`?`통신수:

```sql
SELECT '{"a": 1, "b": 2, "c": 3}' ? 'a' FROM source;
true
```

### 프로젝트

지정된 경로 (keys)에 의해 JSON 문자열에서 값을 검색합니다. 수익률
기본 타입(string, int, etc.)으로 값이 됩니다.

```sql
SELECT json_get('{"a": {"b": 2}}', 'a', 'b') FROM source;
2
```

또한 이용 가능`->`통신수:

```sql
SELECT '{"a": {"b": 2}}'->'a'->'b' FROM source;
2
```

다양한 permutations의`json_get`함수는 retrieving 값을 위해 유효합니다
특정 유형, 또는 SQL 유형 annotations를 사용할 수 있습니다:

```sql
SELECT json_get('{"a": {"b": 2}}', 'a', 'b')::int FROM source;
2
```

### 프로젝트

지정된 경로로 JSON 문자열에서 문자열 값을 검색합니다. 자주 묻는 질문
값이 존재하지 않거나 문자열이 아닙니다.

```sql
SELECT json_get_str('{"a": {"b": "hello"}}', 'a', 'b') FROM source;
"hello"
```

### 프로젝트

지정된 경로로 JSON 문자열에서 정수 값을 검색합니다. 기타 제품`0`값이 존재하지 않거나 정수가 아닙니다.

```sql
SELECT json_get_int('{"a": {"b": 42}}', 'a', 'b') FROM source;
42
```

### 프로젝트

지정된 경로로 JSON 문자열에서 float 값을 검색합니다. 기타 제품`0.0`값이 존재하지 않거나 float가 없습니다.

```sql
SELECT json_get_float('{"a": {"b": 3.14}}', 'a', 'b') FROM source;
3.14
```

### 프로젝트

지정된 경로로 JSON 문자열에서 boolean 값을 검색합니다. 기타 제품
`false`값이 존재하지 않거나 boolean이 아닙니다.

```sql
SELECT json_get_bool('{"a": {"b": true}}', 'a', 'b') FROM source;
true
```

### 프로젝트

지정된 경로로 JSON 문자열에서 배열된 JSON 문자열을 검색합니다. 더 보기
값은 raw JSON으로 반환됩니다.

```sql
SELECT json_get_json('{"a": {"b": {"c": 1}}}', 'a', 'b') FROM source;
'{"c": 1}'
```

### json as 텍스트

지정된 경로로 JSON 문자열에서 모든 값을 검색하고 반환합니다.
문자열, 원래 유형에 관계없이.

```sql
SELECT json_as_text('{"a": {"b": 42}}', 'a', 'b') FROM source;
"42"
```

또한 이용 가능`->>`통신수:

```sql
SELECT '{"a": {"b": 42}}'->>'a'->>'b' FROM source;
"42"
```

### json 길이

지정된 경로에서 JSON 객체 또는 배열의 길이를 반환합니다. 기타 제품`0`경로가 존재하지 않거나 object/array가 아닙니다.

```sql
SELECT json_length('{"a": [1, 2, 3]}', 'a') FROM source;
3
```

## Json 경로 기능

JSON 함수는 기본 json parsing 함수를 제공합니다.
[JsonPath, 영국](https://goessner.net/articles/JsonPath/),를 위한 진화 기준
JSON 객체를 쿼리합니다.

### 추출 json

두번째 인수에서 JsonPath와 일치하는 첫 번째 인수에서 JSON 요소를 반환합니다.
반환 값은 json 문자열의 배열입니다.

```sql
SELECT extract_json('{"a": 1, "b": 2, "c": 3}', '$.a') FROM source;
['1']
```

### 추출 json string

JsonPath와 일치하는 첫 번째 항목에 대한 unescaped 문자열을 반환합니다.

```sql
SELECT extract_json_string('{"a": "a", "b": 2, "c": 3}', '$.a') FROM source;
'a'
```

## `nullif`

기타 제품*한국어*이름 \**표현1*이름 \**표현2*; 그렇지 않으면 반환*표현1*·

```

```

**이름 \***

- **표현1**: 표현과 같은 경우를 비교하고 반환하는 표현2.
  일정한, 란, 또는 기능 및 arithmetic 통신수의 어떤 조합일 수 있습니다.
- **표현2**: 표현식을 비교하는 표현1.
  일정한, 란, 또는 기능 및 arithmetic 통신수의 어떤 조합일 수 있습니다.

## `overlay`

지정된 위치와 지정된 수 길이에서 다른 문자열로 교체되는 문자열을 반환합니다.
예를 들어,`overlay('Txxxxas' placing 'hom' from 2 for 4) → Thomas`

```
overlay(str PLACING substr FROM pos [FOR count])
```

**이름 \***

- **사이트맵**: 동작하는 문자열 표현.
- **서브스트리트**: str의 부분을 대체하는 문자열.
- **팟캐스트**: str을 대체하는 시작 위치.
- **사이트맵**: str의 시작 위치에서 교체 할 문자의 수. 지정되지 않은 경우, 대신 substr 길이를 사용합니다.


**이름 \***

- **사이트맵**: str2로 Levenshtein 거리를 계산하는 문자열 표현.
- **사이트맵**: str1과 Levenshtein 거리를 컴파일하는 문자열 표현.

## `substr_index`

delimiter delim의 발생하기 전에 str에서 substring을 반환합니다.
카운트가 긍정적 인 경우, 최종 delimiter의 왼쪽에있는 모든 것은 (왼쪽에서 계산) 반환됩니다.
숫자가 부정적인 경우, 최종 delimiter의 오른쪽에 모든 것이 반환됩니다.
예를 들어,`substr_index('www.apache.org', '.', 1) = www`, `substr_index('www.apache.org', '.', -1) = org`

```
substr_index(str, delim, count)
```

**이름 \***

- **사이트맵**: 동작하는 문자열 표현.
- **이름 \***: str을 분할하는 문자열.
- **사이트맵**: delimiter를 검색하는 시간의 수. 긍정 또는 부정적인 수 둘 다 일 수 있습니다.

## `find_in_set`

문자열 str이 N substrings로 구성된 문자열 목록 strlist에 있다면 1-N 범위에서 값을 반환합니다.
예를 들어,`find_in_set('b', 'a,b,c,d') = 2`

```
find_in_set(str, strlist)
```

**이름 \***

- **사이트맵**: strlist에서 찾을 문자열 표현.
- **프로젝트**: 문자열 목록은 , 캐릭터에 의해 분리된 substrings로 구성된 문자열입니다.

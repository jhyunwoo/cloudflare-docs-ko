## `array_append`

배열의 끝에 요소를 승인합니다.

```
array_append(array, element)
```

**이름 \***

- **지원하다**: 배열 표현.
  일정한, 란, 또는 기능 및 배열 통신수의 어떤 조합일 수 있습니다.
- **이름 \***: 요소는 배열에 추가합니다.

**이름 \***

```
> select array_append([1, 2, 3], 4);
+--------------------------------------+
| array_append(List([1,2,3]),Int64(4)) |
+--------------------------------------+
| [1, 2, 3, 4]                         |
+--------------------------------------+
```

**이름 \***

- 배열 push back
- 목록 부
- 목록 push back

## `array_sort`

정렬 배열.

```
array_sort(array, desc, nulls_first)
```

**이름 \***

- **지원하다**: 배열 표현.
  일정한, 란, 또는 기능 및 배열 통신수의 어떤 조합일 수 있습니다.
- **사이트맵**: 후속 순서에 정렬 여부(`ASC`또는`DESC`).
- **nulls 첫번째**: null을 분류하는 것`NULLS FIRST`또는`NULLS LAST`).

**이름 \***

```
> select array_sort([3, 1, 2]);
+-----------------------------+
| array_sort(List([3,1,2]))   |
+-----------------------------+
| [1, 2, 3]                   |
+-----------------------------+
```

**이름 \***

- 목록 sort

```

```

**이름 \***

- **지원하다**: 배열 표현.
  일정한, 란, 또는 기능 및 배열 통신수의 어떤 조합일 수 있습니다.
- **제품 정보**: 주어진 배열의 새로운 크기.

## `range`

시작과 중지 사이에 화살표 배열을 반환합니다.`SELECT range(2, 10, 3) -> [2, 5, 8]`또는`SELECT range(DATE '1992-09-01', DATE '1993-03-01', INTERVAL '1' MONTH);`

range start..end는 start \<= x \< end로 모든 값을 포함합니다. 시작 >= 끝이 비어 있습니다.

단계는 0 일 수 없습니다 (그 후에 범위는 비감일 것입니다.).

필요한 범위가 숫자일 때, (stop), (start, stop) 및 (start, stop, step) 매개 변수로 허용하지만 필요한 범위가 날짜일 때, 3 non-NULL 매개 변수이어야합니다.
예를 들어,

```
SELECT range(3);
SELECT range(1,5);
SELECT range(1,5,1);
```

숫자 범위에서 허용

하지만 날짜 범위에서, 만

```
SELECT range(DATE '1992-09-01', DATE '1993-03-01', INTERVAL '1' MONTH);
```

허용하고,

```
SELECT range(DATE '1992-09-01', DATE '1993-03-01', NULL);
SELECT range(NULL, DATE '1993-03-01', INTERVAL '1' MONTH);
SELECT range(DATE '1992-09-01', NULL, INTERVAL '1' MONTH);
```

허용되지 않음

**이름 \***

- **시작하기**: 범위 시작
- **이름 \***: 범위의 끝 (포함되지 않음)
- **한국어**: 단계별 증가(0일 수 없습니다)

**이름 \***

- 생성 series

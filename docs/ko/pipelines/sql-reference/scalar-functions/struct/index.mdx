## `struct`

지정된 입력 표현을 사용하여 화살표를 반환합니다.
반환된 struct의 필드는`cN`naming 대회.
예를 들면:`c0`, `c1`, `c2`등

```
struct(expression1[, ..., expression_n])
```

예를 들어, 이 쿼리는 두 개의 열을 변환`a`·`b`단일 열에
struct 유형의 필드`c0`·`c1`:

```
select * from t;
+---+---+
| a | b |
+---+---+
| 1 | 2 |
| 3 | 4 |
+---+---+

select struct(a, b) from t;
+-----------------+
| struct(t.a,t.b) |
+-----------------+
| {c0: 1, c1: 2}  |
| {c0: 3, c1: 4}  |
+-----------------+
```

#### 이름 \*

- **표현 n**: 출력 구조에 포함된 Expression.
  arithmetic의 일정한, 란, 또는 기능 및 어떤 조합일 수 있습니다
  문자열 연산자.

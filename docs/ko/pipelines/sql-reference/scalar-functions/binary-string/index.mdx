*Cloudflare Pipelines scalar 함수 구현은
[아파치 DataFusion](https://arrow.apache.org/datafusion/)(대략)[아로요](https://www.arroyo.dev/)) 그리고 이 문서는에서 파생됩니다
DataFusion 기능 참고 자료.*

## `encode`

텍스트 표현으로 바이너리 데이터를 인코딩합니다.

```
encode(expression, format)
```

**이름 \***

- **이름 \***: 문자열 또는 바이너리 데이터를 포함하는 표현

- **지원하다**: 지원되는 체재는:`base64`, `hex`

**관련 기능**:
[이름 \*](#decode)

## `decode`

문자열의 textual 표현에서 바이너리 데이터를 디코딩합니다.

```
decode(expression, format)
```

**이름 \***

- **이름 \***: 인코딩된 문자열 데이터를 포함하는 Expression

- **지원하다**: 같은 인수[이름 \*](#encode)

**관련 기능**:
[이름 \*](#encode)

*Cloudflare Pipelines scalar 함수 구현은
[아파치 DataFusion](https://arrow.apache.org/datafusion/)(대략)[아로요](https://www.arroyo.dev/)) 그리고 이 문서는에서 파생됩니다
DataFusion 기능 참고 자료.*

## `arrow_cast`

특정 Arrow 데이터 유형에 값을 매깁니다:

```
arrow_cast(expression, datatype)
```

**이름 \***

- **이름 \***: 캐스트의 표현.
  arithmetic의 일정한, 란, 또는 기능 및 어떤 조합일 수 있습니다
  문자열 연산자.
- **데이터 유형**: [Arrow 데이터 유형](https://docs.rs/arrow/latest/arrow/datatypes/enum.DataType.html)이름 \*
  to cast to, 문자열로. 형식은 그 반환과 동일 \[`arrow_typeof`]

**이름 \***

```
> select arrow_cast(-5, 'Int8') as a,
  arrow_cast('foo', 'Dictionary(Int32, Utf8)') as b,
  arrow_cast('bar', 'LargeUtf8') as c,
  arrow_cast('2023-01-02T12:53:02', 'Timestamp(Microsecond, Some("+08:00"))') as d
  ;
+----+-----+-----+---------------------------+
| a  | b   | c   | d                         |
+----+-----+-----+---------------------------+
| -5 | foo | bar | 2023-01-02T12:53:02+08:00 |
+----+-----+-----+---------------------------+
1 row in set. Query took 0.001 seconds.
```

## `arrow_typeof`

아래쪽의 이름을 반환[Arrow 데이터 유형](https://docs.rs/arrow/latest/arrow/datatypes/enum.DataType.html)표현의:

```
arrow_typeof(expression)
```

**이름 \***

- **이름 \***: 평가하는 표현.
  arithmetic의 일정한, 란, 또는 기능 및 어떤 조합일 수 있습니다
  문자열 연산자.

**이름 \***

```
> select arrow_typeof('foo'), arrow_typeof(1);
+---------------------------+------------------------+
| arrow_typeof(Utf8("foo")) | arrow_typeof(Int64(1)) |
+---------------------------+------------------------+
| Utf8                      | Int64                  |
+---------------------------+------------------------+
1 row in set. Query took 0.001 seconds.
```

*Cloudflare Pipelines scalar 함수 구현은
[아파치 DataFusion](https://arrow.apache.org/datafusion/)(대략)[아로요](https://www.arroyo.dev/)) 그리고 이 문서는에서 파생됩니다
DataFusion 기능 참고 자료.*

## `digest`

지정된 알고리즘을 사용하여 표현의 바이너리 해시를 계산합니다.

```
digest(expression, algorithm)
```

**이름 \***

- **이름 \***: 동작하는 문자열 표현.
  연속, 열, 또는 기능 및 문자열 연산자의 모든 조합이 될 수 있습니다.
- **언어 선택**: 알고리즘을 지정하는 문자열 표현
  다음 중 하나가 될 수 있습니다:
  - 사이트맵
  - 면도224
  - 면도256
  - 면도384
  - 면도512
  - 브레이크2s
  - 브레이크2b
  - 브레이크3

파이프 라인은**오픈 베타**, 어떤 개발자와 함께[Workers 유료 플랜](/workers/platform/pricing/)그것을 사용하여 시작할 수 있습니다. 현재 표준 R2 저장과 가동의 외부, 당신은 파이프라인의 당신의 사용을 청구하지 않을 것입니다.
주요 특징

<Description>
  R2에서 Apache Iceberg 또는 Parquet로, 변환 및 로드 스트리밍 데이터를 가져옵니다.
</Description>

<Plan type="paid" />

Cloudflare Pipelines ingests 이벤트는 SQL로 변환하고 R2로 전달합니다.[Iceberg 테이블](/r2/data-catalog/)또는 Parquet 및 JSON 파일로.

서버 로그, 모바일 응용 프로그램 이벤트, IoT 원격 측정, 또는 clickstream 데이터 처리 여부, 파이프 라인은 HTTP 엔드 포인트 또는 작업자 바인딩, SQL 기반 변환 및 R2에 정확하게 온스 배달을 통해 내구성을 제공합니다. 스트리밍 인프라를 관리하지 않고 Analytics-ready data Warehouses and lakehouse를 구축하는 것은 쉽습니다.

첫 번째 파이프라인 만들기[자주 묻는 질문](/pipelines/getting-started)또는 이것을 실행[Wrangler](/workers/wrangler/)명령:

```sh
npx wrangler pipelines setup
```

## 주요 특징

<Feature header="첫 번째 파이프라인 만들기" href="/pipelines/getting-started/" cta="Get started">
  HTTP 또는 Workers를 통해 첫 번째 파이프 라인을 구축하고 SQL 변환을 적용하고 Iceberg 테이블 또는 Parquet 파일로 R2XQ에 전달합니다.
</Feature>

<Feature header="사이트 맵" href="/pipelines/streams/" cta="Learn about Streams">
  HTTP 엔드포인트 또는 Worker 바인딩을 통해 이벤트를 수신하는 튼튼한, 버퍼 큐.
</Feature>

<Feature header="파이프 라인" href="/pipelines/pipelines/" cta="Learn about Pipelines">
  SQL 변환을 사용하여 스트림을 연결하여 유효성 검사, 필터, 변환 및 ingestion 시간에 데이터를 풍부하게합니다.
</Feature>

<Feature header="관련 상품" href="/pipelines/sinks/" cta="Learn about Sinks">
  귀하의 데이터에 대한 목적지 구성. R2 데이터 카탈로그 또는 Parquet 및 JSON 파일로 내보내기
</Feature>

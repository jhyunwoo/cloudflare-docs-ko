## 파이프라인 만들기

Pipelines는 스트림에서 싱크로의 데이터 흐름을 정의하는 SQL 선언을 실행합니다.

### 대시보드

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**파이프 라인**사이트 맵

     <DashButton url="/?to=/:account/pipelines/overview" />
  2. 제품정보**Pipeline 만들기**파이프라인 생성 마법사를 시작합니다.
  3. 스트림, 싱크 및 SQL 변환을 구성하는 마법사를 따르십시오.
</Steps>

### Wrangler 클립

파이프라인을 만들려면, 실행[`pipelines create`](/workers/wrangler/commands/#pipelines-create)명령:

```bash
npx wrangler pipelines create my-pipeline \
  --sql "INSERT INTO my_sink SELECT * FROM my_stream"
```

파일에서 SQL을 제공 할 수도 있습니다.

```bash
npx wrangler pipelines create my-pipeline \
  --sql-file pipeline.sql
```

대신, 스트림, 싱크 및 파이프라인을 구성하는 데 도움이되는 대화형 설정 마법사를 사용하려면[`pipelines setup`](/workers/wrangler/commands/#pipelines-setup)명령:

```bash
npx wrangler pipelines setup
```

### SQL 변환

데이터 변환을위한 Pipelines 지원 SQL 문. 완전한 문법, 지원된 기능 및 데이터 유형의 경우,[SQL 참고 자료](/pipelines/sql-reference/).

일반적인 본은 다음을 포함합니다:

#### 기본 데이터 흐름

스트림에서 싱크로 모든 데이터를 전송:

```sql
INSERT INTO my_sink SELECT * FROM my_stream
```

#### 필터링 이벤트

조건을 기반으로 필터 이벤트:

```sql
INSERT INTO my_sink
SELECT * FROM my_stream
WHERE event_type = 'purchase' AND amount > 100
```

#### 특정 분야 선택

필요한 필드만 선택하십시오:

```sql
INSERT INTO my_sink
SELECT user_id, event_type, timestamp, amount
FROM my_stream
```

#### 데이터 전송

필드에 변환하기:

```sql
INSERT INTO my_sink
SELECT
  user_id,
  UPPER(event_type) as event_type,
  timestamp,
  amount * 1.1 as amount_with_tax
FROM my_stream
```

## 파이프라인 구성 보기

### 대시보드

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**파이프 라인**사이트 맵

  2. SQL 변환, 연결 스트림/싱크를 볼 파이프라인을 선택하고
     관련 미터.
</Steps>

### Wrangler 클립

특정 파이프라인을 보려면, 실행[`pipelines get`](/workers/wrangler/commands/#pipelines-get)명령:

```bash
npx wrangler pipelines get <PIPELINE_ID>
```

계정의 모든 파이프라인을 나열하려면, 실행[`pipelines list`](/workers/wrangler/commands/#pipelines-list)명령:

```bash
npx wrangler pipelines list
```

## 파이프 삭제

연결된 스트림의 데이터 흐름을 중지합니다.

### 대시보드

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**파이프 라인**사이트 맵

  2. 삭제하려는 파이프라인을 선택합니다. 3. 에서**계정 설정**탭 및 선택**이름 \***.
</Steps>

### Wrangler 클립

파이프라인을 삭제하려면[`pipelines delete`](/workers/wrangler/commands/#pipelines-delete)명령:

```bash
npx wrangler pipelines delete <PIPELINE_ID>
```

:::카트로션
파이프 라인이 즉시 스트림과 싱크 사이의 데이터 흐름을 중지합니다.

## 제한 사항

Pipeline SQL은 생성 후 수정할 수 없습니다. SQL 변환을 변경하려면 파이프라인을 삭제하고 재구성해야합니다.

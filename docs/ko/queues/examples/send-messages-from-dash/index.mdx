dashboard에서 메시지를 전송하면 제작자 노동자없이 Queues 또는 큐 소비자를 디버깅 할 수 있습니다.

dashboard에서 메시지를 보내려면:

1. Cloudflare dashboard에서, 가십시오**Queues**사이트 맵

   <DashButton url="/?to=/:account/workers/queues" />

2. 메시지를 보내려면 큐를 선택하십시오.

3. 선택하기**이름 \***&#xD0ED;.

4. 제품정보**이름 \***.

5. 자주 묻는 질문**내용 유형**: *이름 \**&#xB610;는*JSON 파일*.

6. 자주 묻는 질문 또는 textbox에 파일을 드래그하여 메시지로 파일을 업로드합니다.

7. 제품정보**이름 \***.

귀하의 메시지는 큐에 전송됩니다.

더 알아보기[자주 묻는 질문](/queues/get-started/)작업자에서 큐에 메시지를 보내는 방법을 배우기 위해.

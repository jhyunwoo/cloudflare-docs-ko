## dashboard의 메시지 목록

dashboard의 목록 메시지는 소비자 노동자 없이 Queues 또는 큐 프로듀서를 디버깅할 수 있습니다. 미리보기에 메시지의 배치를 표시하거나 메시지를 재발하거나 큐의 위치에 영향을 미치지 않습니다. 큐는 여전히 소비자 노동자에 의해 일반적으로 소비 될 수 있습니다.

dashboard의 메시지 목록:

<Steps>
  1. Cloudflare dashboard에서, 가십시오**Queues**사이트 맵

     <DashButton url="/?to=/:account/workers/queues" />

  2. 메시지를 미리 보기 위해 큐를 선택합니다.

  3. 선택하기**이름 \***&#xD0ED;.

  4. 제품정보**이름 \***.

  5. 메시지의 목록이로드되면 각 행의 오른쪽에 파란색 화살표를 선택하고 메시지 미리보기를 확장합니다.
</Steps>

이것은 현재 Queue에서 메시지의 배치를 미리보기합니다.

## dashboard

Acknowledging 메시지[Cloudflare dashboard](https://dash.cloudflare.com)queue에서 영구적으로 제거 할 것입니다.`ack()`직장에서.

<Steps>
  1. 각 행의 왼쪽에 체크 박스를 선택하여 인증에 대한 메시지를 선택하거나 테이블 헤더의 체크 박스를 선택하여 모든 메시지를 선택하십시오.
  2. 제품정보**Acknowledge 메시지**.
  3. 메시지를 인정하고, 선택**Acknowledge 메시지**.
</Steps>

queue에서 선택한 메시지를 제거하고 소비자를 처리하는 것을 방지합니다.

더 알아보기[자주 묻는 질문](/queues/get-started/)작업자에서 큐의 메시지를 처리하고 인정하는 방법을 배우기 위해.

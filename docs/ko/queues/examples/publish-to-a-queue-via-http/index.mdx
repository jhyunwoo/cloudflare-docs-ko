다음 예제는 Cloudflare API 토큰을 사용하여 HTTP 클라이언트에서 큐에 메시지를 게시하는 방법을 보여줍니다.

이것은 Go, Rust, PythonXQX0237XQXQXQ 또는 Bash 스크립트를 포함한 HTTP를 지원하는 모든 서비스 또는 프로그래밍 언어에서 큐에 쓰기 할 수 있습니다.

## 자주 묻는 질문

- ·[queue 생성](/queues/get-started/#3-create-a-queue)을 통해[Cloudflare dashboard](https://dash.cloudflare.com)또는[wrangler 클립](/workers/wrangler/install-and-update/).
- Cloudflare API 토큰`Queues Edit`이름 \*

### 1. 시험 메시지를 보내십시오

성공적으로 인증하고 큐에 메시지를 작성하려면, 사용`curl`명령줄에:

```sh
#공유 비밀을 가진 placeholder를 대체해야 합니다.
curl -XPOST -H "Authorization: Bearer <paste-your-api-token-here>" "https://api.cloudflare.com/client/v4/accounts/<paste-your-account-id-here>/queues/<paste-your-queue-id-here>/messages" --data '{ "body": { "greeting": "hello" } }'
```

```sh output
{"success":true}
```

이것은 HTTP POST 요청을 발급하고 성공하면 HTTP 200을 반환합니다.`success: true`응답 몸.

- HTTP 403을 수신하면 API 토큰이 유효하지 않거나 존재하지 않는 것이기 때문입니다.`Queues Edit`이름 \*

HTTP Push API에 대한 전체 문서의 경우, 참조[Cloudflare API 문서](https://developers.cloudflare.com/api/resources/queues/subresources/messages/).

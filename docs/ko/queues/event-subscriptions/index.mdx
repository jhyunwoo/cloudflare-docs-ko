이벤트 구독은 Cloudflare 계정에서 이벤트가 진행될 때 메시지를 수신할 수 있습니다. Cloudflare 제품 (예 :[KV](/kv/), [Workers AI](/workers-ai), [Workers](/workers)) 다음 Workers 또는로 소비 할 수있는 큐에 구조 된 이벤트를 게시 할 수 있습니다[HTTP 풀 소비자](/queues/configuration/pull-consumers/)사용자 정의 워크플로우, 통합, 또는 논리를 구축합니다.

![이벤트 구독 아키텍처](public/images/queues/queues-event-subscriptions.png)

## 이벤트는 무엇인가요?

이벤트는 Cloudflare 계정에서 일어나는 무언가의 구조화 된 기록입니다. Workers AI 일괄 처리 요청은 누비질되고, 노동자 빌드 완료 또는 R2 버킷 생성됩니다. 이 이벤트에 가입하면, 큐는 이벤트가 발생할 때 자동으로 메시지를 수신합니다.

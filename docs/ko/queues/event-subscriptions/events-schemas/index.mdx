## 일반 스키마 분야

모든 이벤트는 이러한 일반적인 필드를 포함합니다:

| 제품정보                           | 제품정보  | 이름 \*                                |
| ------------------------------ | ----- | ------------------------------------ |
| `type`                         | 이름 \* | 이벤트 유형 식별자                           |
| `source`                       | 기타 제품 | ID 및 이름과 같은 소스 별 정보를 포함합니다.          |
| `metadata.accountId`           | 이름 \* | Cloudflare 계정 ID                     |
| `metadata.eventSubscriptionId` | 이름 \* | 이 이벤트를 트리거 한 구독                      |
| `metadata.eventSchemaVersion`  | 이름 \* | 이벤트 스키마의 버전                          |
| `metadata.eventTimestamp`      | 이름 \* | 사건이 발생했을 때 ISO 8601 타임스탬프            |
| `payload`                      | 기타 제품 | 어떤 일이 일어나는지에 대한 세부 정보를 포함하는 이벤트별 데이터 |

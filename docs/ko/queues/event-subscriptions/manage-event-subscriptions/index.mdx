학습 방법:

- Cloudflare 서비스의 메시지를 수신하는 이벤트 구독을 만듭니다.
- queues에서 기존 구독을 확인하세요.
- 더 이상 필요하지 않은 구독을 삭제합니다.

## 구독하기

구독을 작성하면 Cloudflare 서비스에 이벤트가 발생할 때 메시지를 수신 할 수 있습니다. 구독하려는 소스 및 이벤트를 지정할 수 있습니다.

### 대시보드

<Steps>
  1. Cloudflare QXdashboard에서, 갑니다**Queues**사이트 맵

     <DashButton url="/?to=/:account/workers/queues" />

  2. 구독을 추가하려면 queue를 선택하십시오.

  3. 전환하기**이름 \***&#xD0ED;.

  4. 제품정보**자주 묻는 질문**.

  5. 구독을 이름하고 원하는 소스와 이벤트를 선택합니다.

  6. 제품정보**이름 \***.
</Steps>

### Wrangler 클립

Wrangler를 사용하여 구독을 만들려면, 실행[`queues subscription create command`](/queues/reference/wrangler-commands/#queues-subscription-create):

```bash
npx wrangler queues subscription create <queue-name> --source <source-type> --events <event1,event2> --<source-specific-option> <value>
```

어떤 소스와 이벤트에 대한 자세한 내용을 보려면, 참조[이벤트 & 스키마](/queues/event-subscriptions/events-schemas/).

## 기존 구독 보기

현재 수신 중인 이벤트를 볼 수 있는 모든 구독을 볼 수 있습니다.

### 대시보드

<Steps>
  1. Cloudflare dashboard에서, 가십시오**Queues**사이트 맵

     <DashButton url="/?to=/:account/workers/queues" />

  2. 구독을 볼 수 있습니다.

  3. 전환하기**이름 \***&#xD0ED;.
</Steps>

### Wrangler 클립

큐에 대한 구독을 나열하려면, 실행[`queues subscription list command`](/queues/reference/wrangler-commands/#queues-subscription-list):

```bash
npx wrangler queues subscription list <queue-name>
```

## 구독하기

구독을 삭제할 때, queue는 즉시 해당 이벤트에 대한 메시지를 수신합니다.

### 대시보드

<Steps>
  1. Cloudflare dashboard에서, 가십시오**Queues**사이트 맵

     <DashButton url="/?to=/:account/workers/queues" />

  2. 삭제하려는 구독을 포함하는 큐를 선택합니다.

  3. 전환하기**이름 \***&#xD0ED;.

  4. 제품정&#xBCF4;**...**&#xC0AD;제하려는 구독을 위해.

  5. 제품정보**구독하기**.
</Steps>

### Wrangler 클립

구독을 삭제하려면, 실행[`queues subscription delete command`](/queues/reference/wrangler-commands/#queues-subscription-delete):

```bash
npx wrangler queues subscription delete <queue-name> --id <subscription-id>
```

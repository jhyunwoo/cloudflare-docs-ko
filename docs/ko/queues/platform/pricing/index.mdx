## 이름 \*

응용 프로그램 쓰기, 읽기 및 삭제 (소비자) 하루 백만 메시지 (30 일 개월에서), 각 메시지는 크기에서 64 KB 미만이며, 달의 예상 청구는 다음과 같습니다.

|          | 총 사용량                | 무료 사용     | Billed 사용법 | 가격대비       |
| -------- | -------------------- | --------- | ---------- | ---------- |
| 표준 작업    | 3 \* 30 \* 1,000,000 | 1,000,000 | 89,000,000 | $35.60     |
|          | (쓰기, 읽기, 삭제)         |           |            |            |
| **사이트맵** |                      |           |            | **$35.60** |

쓰기, 읽기 및 삭제 (소문) 100 만 \~ 127 KB 메시지 (각 메시지는 두 개의 64 KB 펑크로 계산) 한 달에 다음과 같은 예상 청구가있을 것입니다 :

|          | 총 사용량                      | 무료 사용     | Billed 사용법  | 가격대비        |
| -------- | -------------------------- | --------- | ----------- | ----------- |
| 표준 작업    | 2 \* 3 \* 100 \* 1,000,000 | 1,000,000 | 599,000,000 | $239.60     |
|          | (2x ops for > 64KB 메시지)    |           |             |             |
| **사이트맵** |                            |           |             | **$239.60** |

## 청구 연락처 정보 변경

청구 연락처 정보가 변경되었다면 가능한 한 빨리 [Cloudflare 이메일 주소를 업데이트](/billing/update-billing-info/#update-billing-email-address)하세요.

## Cloudflare 구독 또는 계정 변경

청구서 데이터는 Cloudflare 계정이 변경된 날짜를 기준으로 합니다. 플랜, 추가 도메인 또는 애드온 서비스에 대해서는 즉시 요금이 청구됩니다. 계정 변경 후 24시간 이내에 Cloudflare 대시보드에서 청구서를 확인할 수 있습니다.

청구 기간은 30일입니다. 반복되는 월별 비용에 대한 결제는 청구 기간 마지막 날에 처리됩니다. 청구서는 같은 날 생성되며 24시간 이내에 [Cloudflare 대시보드](https://dash.cloudflare.com)의 **Billing** 섹션에 표시됩니다.

## 회사명이 없는 Cloudflare 청구서

청구서에 사업체명 또는 회사명, VAT ID, Tax ID/EIN을 추가하려면 [청구 정보 업데이트](/billing/update-billing-info/) 시 회사명을 추가하세요.

## 청구서 금액과 결제 금액이 일치하지 않음

Cloudflare 결제가 연체된 상태에서 추가 서비스를 주문하면 연체 금액이 청구서에 합산됩니다. 이로 인해 청구서 금액과 [Cloudflare 대시보드](https://dash.cloudflare.com)에서 보이는 금액이 다를 수 있습니다. 계정 상태가 정상으로 돌아오면 Cloudflare 대시보드의 금액도 업데이트됩니다.

:::note
변경 사항이 Cloudflare 청구서에 반영되기까지 최대 한 청구 기간이 걸릴 수 있습니다.
:::

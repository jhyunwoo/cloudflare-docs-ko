## 기본 결제 수단 추가

Cloudflare 제품 및 서비스를 결제하려면 기본 결제 수단이 필요합니다. Cloudflare는 사용자의 기밀성과 개인정보를 중요하게 여기며, 은행 정보, 신용카드 정보, PIN 또는 PayPal 계정 비밀번호에 접근할 수 없습니다.

:::note
[Enterprise 요금제](https://www.cloudflare.com/plans/enterprise/contact/) 고객은 송금 및 ACH 같은 [추가 결제 옵션](/billing/create-billing-profile/#payment-options)과 연간 또는 분기별 청구를 이용할 수 있습니다.
:::

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />

2. **Payment**를 선택합니다. 등록된 결제 수단이 없으면 **Payment methods** 대화 상자가 자동으로 열립니다.
3. 현재 결제 수단 옆의 **Manage**를 선택합니다. **Manage payment methods** 대화 상자가 열립니다.
4. 아래 결제 옵션에 따라 필요한 정보를 입력합니다.
   **Credit card**:
   1. **Credit Card Details** 양식에서 필요한 정보를 입력합니다.
   2. 해당하는 경우 인보이스에 표시할 비즈니스 정보(**Company**, **VAT/GST Number**)를 추가합니다.

   **PayPal**(PayPal 계정에 잔액이 부족하면 신용카드에 청구됩니다):
   1. **PayPal**을 선택합니다.
   2. PayPal이 Cloudflare **Payment Method**로 다시 돌아올 때까지 온라인 안내를 따라 설정을 계속합니다.
   3. 이제 PayPal 로고 옆에 **PayPal username**이 표시되는지 확인합니다.
   4. 필요한 경우 계정 연락처 정보와 **Company**, **VAT/GST Number**를 추가합니다.

:::note
일부 국가에서는 개인 계정의 상품 및 서비스에도 세금을 부과하므로, 세금 적용 여부를 판단하기 위해 Cloudflare 계정이 개인용인지 비즈니스용인지 표시하라는 요청을 받을 수 있습니다.
:::

5. 결제 수단과 연락처 정보가 정확한지 검토합니다.
6. 마무리하려면 **Confirm**을 선택합니다.
7. 새 결제 수단이 **Payment Method** 섹션에 표시되는지 확인합니다.

Enterprise 고객은 신용카드 마지막 네 자리와 만료일을 포함해 [ar@cloudflare.com](mailto:ar@cloudflare.com)으로 이메일을 보내야 합니다.

## 백업 결제 수단 추가

선택 사항으로, 기본 결제 수단 결제에 실패할 경우 사용할 백업 결제 수단을 추가할 수 있습니다.

<Render file="two-payment-methods" product="billing" />

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />

2. **Payment**를 선택합니다.
3. **Payment methods**에서 **Manage**를 선택합니다.
4. **Backup**에서 **Add**를 선택해 백업 결제 수단을 입력합니다.
5. 원하는 결제 수단(신용카드 또는 PayPal)에 따라 필요한 정보를 입력한 후 **Confirm**을 선택합니다.
6. 백업 결제 수단을 기본 수단으로 설정하려면 **Make primary payment method**를 선택합니다.

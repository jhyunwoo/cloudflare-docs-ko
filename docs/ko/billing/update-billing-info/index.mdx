Cloudflare 서비스 중단 가능성을 피하려면 청구 정보를 최신 상태로 정확하게 유지하세요.

Cloudflare가 결제를 처리할 수 없는 경우 [결제 실패 문제 해결](/billing/troubleshoot-failed-payments/)을 검토하세요.

## 결제 수단 업데이트

<Render file="two-payment-methods" product="billing" />

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />

2. **Payment**를 선택합니다.
3. 현재 결제 수단 옆의 **Manage**를 선택합니다. **Manage payment methods** 대화 상자가 열립니다.
4. 수정하려는 결제 수단 옆의 **Edit**를 선택합니다.
5. 필요한 정보를 입력한 뒤 **Save Payment Information**을 선택합니다.

## 결제 수단 삭제

등록된 결제 수단을 삭제하기 전에 모든 Cloudflare 유료 서비스를 취소해야 합니다.

:::caution
현재 [추가 서비스](/billing/usage-based-billing/)를 구독 중이라면 Cloudflare에는 항상 등록된 결제 수단이 있어야 합니다. 결제 수단을 삭제해야 하는 경우 이를 대체할 새 결제 수단을 먼저 입력해야 합니다.

결제가 실패했거나 미결제 잔액이 있으면 결제 수단을 삭제할 수 없습니다. Cloudflare가 결제를 처리할 때까지는 결제 수단을 추가하거나 수정하는 것만 가능합니다.
:::

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />

2. **Payment**를 선택합니다.
3. **Payment methods**에서 **Manage**를 선택합니다.
4. 현재 결제 수단 옆의 **Delete**를 선택합니다.
5. 마무리하려면 **Confirm**을 선택합니다.

## 청구 주소 업데이트

청구 주소는 결제 수단에 연결되어 있으며 판매세 계산에 사용됩니다. 청구 주소를 업데이트해야 한다면 결제 수단 정보도 함께 입력해야 합니다. 청구 주소를 업데이트하는 절차는 결제 수단에 따라 다릅니다.

신용카드로 결제하는 경우:

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />

2. **Billing Address**에서 **Edit**를 선택하고 정보를 입력합니다.
3. 팝업 창에 제안된 주소를 검토합니다. 정보가 정확하면 **Confirm**을 선택합니다.

PayPal로 결제하는 경우 PayPal의 [청구 주소 문서](https://www.paypal.com/ai/smarthelp/article/how-do-i-edit-the-billing-address-linked-to-my-credit-card-faq680)를 참고하세요.

## 청구 이메일 주소 업데이트

청구 이메일 주소는 특히 [인보이스 이메일 수신을 활성화](/billing/invoices/#enable-email-invoices-from-cloudflare)한 경우 매우 중요합니다.

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />

2. **Invoices and documents**로 이동합니다.
3. **Billing email preference**에서 **Change email address**를 선택합니다.
4. 새 이메일 주소를 입력하고 확인한 뒤 **Save**를 선택합니다.

## Tax ID, VAT 또는 GST 번호 추가 또는 변경

결제 수단을 추가할 때 Tax ID, VAT 또는 GST 번호를 포함하지 않았다면, 이후 결제 수단에 연결된 Tax ID, VAT 또는 GST 번호를 추가하거나 변경할 수 있습니다.

:::note 
과거 인보이스에는 VAT 또는 GST 번호를 적용할 수 없습니다. VAT 또는 GST 번호를 추가해도 계정에서 앞으로 발행되는 인보이스에만 적용됩니다.
:::

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />

2. **Payment**로 이동합니다.
3. **Billing Address**에서 **Edit**를 선택합니다.
4. **VAT/GST** 필드에 VAT 또는 GST 번호를 입력합니다.
5. **Confirm**을 선택합니다.

## Tax ID, VAT 또는 GST 번호 제거

:::note 
과거 인보이스에서는 VAT 또는 GST 번호를 제거할 수 없습니다. VAT 또는 GST 번호를 제거해도 계정에서 앞으로 발행되는 인보이스에만 적용됩니다.
:::

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />

2. **Payment**로 이동합니다.
3. **Billing Address**에서 **Edit**를 선택합니다.
4. **VAT/GST** 필드에서 VAT 또는 GST 번호를 삭제합니다.
5. **Confirm**을 선택합니다.

취소는 청구 기간이 끝날 때까지 처리되지 않으므로, 새 청구 기간이 시작될 때까지 애드온 또는 구독을 계속 사용할 수 있습니다. 원치 않는 청구를 피하려면 청구 기간이 끝나기 전에 취소 절차를 시작하세요.

연간 플랜에서 월간 플랜으로 변경하거나 유료 플랜에서 무료 플랜으로 변경하는 등 구독 다운그레이드를 진행하는 경우, 다운그레이드와 취소는 즉시 적용되지 않으며 계약된 서비스 기간이 끝날 때까지 계속 청구되고 서비스를 계속 이용할 수 있다는 점에 유의하세요. 이 정책의 예외나 조기 다운그레이드 및 취소에 대한 환불을 요청하기 위해 Cloudflare에 문의해서는 안 됩니다.

또한 각 구독마다 항상 취소 버튼이 표시되는 것은 아니며, 유료 플랜에서 무료 플랜으로 전환하는 것이 유료 구독 취소로 처리되는 경우가 많습니다.

:::note

청구서와 대시보드의 모든 청구 기간 날짜는 현지 시간이 아니라 UTC/GMT 시간대를 기준으로 표시됩니다. 시간대 혼동으로 인한 문제를 피하려면 명시된 청구일 최소 24시간 전에 다운그레이드 또는 구독 변경을 수행하는 것을 권장합니다.

또한 도메인 이름의 DNS를 변경해도 계정이나 활성 구독 플랜이 취소되지 않는다는 점에 유의하세요. 시스템은 구독 플랜의 수동 취소를 기다립니다. 도메인 이름 소유자가 계정을 제거할 의도가 없었기 때문에 DNS를 다시 변경해야 하는 경우가 있기 때문입니다.

DNS 변경과 관련된 알림은 받게 되지만, 이는 구독 플랜 취소를 의미하지는 않습니다.

:::

## 1단계: Cloudflare 구독 비활성화

구독을 비활성화하려면 다음 단계를 따르세요.

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />

2. **Subscriptions**를 선택합니다.
3. **Active Subscriptions**(Free 또는 Pro 고객) 또는 **Plan Extensions**(Enterprise 고객) 아래에서 비활성화하려는 기능을 선택합니다.
4. 안내에 따라 기능을 비활성화합니다. 기능마다 과정이 다르며, 스위치를 끄거나 버튼을 클릭하거나 드롭다운 목록에서 *Disable*을 선택해야 할 수 있습니다.

## 2단계: 청구 프로필에서 구독 취소

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />

2. **Subscriptions**를 선택합니다.
3. 비활성화하려는 구독을 찾아 **Cancel**을 선택합니다.
4. 피드백 공유 요청이 표시되면 해당하는 항목을 모두 선택합니다.
5. 마무리하려면 **Confirm**을 선택합니다.

:::note

플랜을 변경하려면 **Active Subscriptions** 아래에서 **Change**를 선택하고 새 플랜 유형을 고르세요. 유료 플랜을 취소하려면 **Free**를 선택하세요.

수수료는 환불되지 않습니다. 구독을 취소한 구독 기간 전체 금액이 청구되며, 해당 구독 기간의 미사용 부분에 대해서는 환불되지 않습니다. 다만 취소 후에도 현재 구독 기간이 끝날 때까지는 유료 서비스에 계속 액세스할 수 있습니다(사용량 기반 청구가 적용되는 서비스 제외). 당사는 단독 재량으로 특정 사례에 한해 환불, 할인 또는 크레딧("Credits")을 제공할 수 있으나, 특정 사례에서 크레딧을 제공했다고 해서 향후 유사한 사례에 대해 크레딧을 받을 권리가 생기거나 당사가 추가 크레딧을 제공할 의무를 지는 것은 아닙니다.

:::

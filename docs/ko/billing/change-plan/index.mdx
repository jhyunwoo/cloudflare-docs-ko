때때로 특정 Cloudflare 도메인에 연결된 요금제를 업그레이드하거나 다운그레이드해야 할 수 있습니다.

## 제한 사항

도메인 요금제 변경은 Super Administrator만 관리할 수 있습니다.

요금제를 다운그레이드하거나 도메인을 제거하더라도 Cloudflare는 환불을 제공하지 않습니다. 자세한 내용은 [청구 정책](/billing/billing-policy/)을 참고하세요.

업그레이드는 즉시 처리되지만 다운그레이드는 청구 기간이 끝날 때까지 처리되지 않습니다. 미납 인보이스가 있으면 업그레이드할 수 없습니다. 다운그레이드하는 경우 새 청구 기간이 시작될 때까지는 상위 요금제의 제품을 계속 사용할 수 있습니다.

요금제를 다운그레이드하면 [페이지 규칙](/rules/page-rules/)을 더 적게 사용할 수 있습니다. 요금제 한도보다 많은 페이지 규칙을 계속 사용하면 추가 규칙에 대한 요금이 청구될 수 있습니다. 요금이 청구되지 않도록 하려면 초과 규칙을 제거하고 [추가 구독을 취소](/billing/cancel-subscription/)하세요.

Enterprise App Sec Advanced 및 Enterprise App Sec Core 요금제는 [Cloudflare에 문의](/support/contacting-cloudflare-support/)하지 않고는 다운그레이드할 수 없습니다.

추가 도움말은 [이 커뮤니티 스레드](https://community.cloudflare.com/t/communitytip-page-rules-best-practices-when-downgrading-pro-to-free/305725)를 참고하세요.

## 요금제 유형 변경

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

대시보드에서 도메인의 Cloudflare 요금제를 변경하려면 다음 단계를 따르세요.

1. [Cloudflare 대시보드](https://dash.cloudflare.com)에 로그인한 후 계정과 도메인을 선택합니다.

2. **Overview**로 이동합니다.

3. Plan Extensions에서 **Change**를 선택합니다.

   ![Plan extension 섹션이 강조 표시된 Overview 페이지 스크린샷](~/assets/images/fundamentals/get-started/change-plan.png)

4. 적절한 요금제 유형을 선택한 다음 **Continue**를 선택합니다.

5. **Confirm**을 선택합니다.

</TabItem> <TabItem label="API">

API를 사용해 도메인의 Cloudflare 요금제를 변경하려면 먼저 [`GET`](/api/resources/zones/subresources/plans/methods/list/) 요청을 보내 사용 가능한 구독을 확인합니다.

그런 다음 `rate_plan` 객체에 원하는 요금제 유형을 포함하여 [`PUT`](/api/resources/zones/subresources/subscriptions/methods/update/) 요청을 보냅니다.

</TabItem> </Tabs>

:::note

Enterprise 고객인데 요금제 유형을 변경할 수 없다면 Customer Success Manager에게 문의하세요.

:::

## 요금제 기간 변경

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

대시보드에서 Cloudflare 요금제 기간을 변경하려면 다음 단계를 따르세요.

1. [Cloudflare 대시보드](https://dash.cloudflare.com)에 로그인한 후 계정과 도메인을 선택합니다.

2. **Overview**로 이동합니다.

3. Plan Extensions에서 **Change**를 선택합니다.

   ![Plan extension 섹션이 강조 표시된 Overview 페이지 스크린샷](~/assets/images/fundamentals/get-started/change-plan.png)

4. **Monthly** 또는 **Annual** 사이에서 토글을 전환합니다.

   ![연간 또는 월간 토글이 강조 표시된 요금제 선택 화면 스크린샷](~/assets/images/fundamentals/get-started/plan-duration.png)

5. 적절한 요금제 유형을 선택한 다음 **Continue**를 선택합니다.

6. **Confirm**을 선택합니다.

</TabItem> <TabItem label="API">

API를 사용해 도메인의 Cloudflare 요금제 기간을 변경하려면 `frequency` 매개변수의 값을 업데이트한 [`PUT`](/api/resources/zones/subresources/subscriptions/methods/update/) 요청을 보냅니다.

</TabItem> </Tabs>

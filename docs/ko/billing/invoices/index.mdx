다음과 같은 경우 Cloudflare 계정의 **Billing** 섹션에서 인보이스를 받게 됩니다.

* Cloudflare 요금제 유형을 변경한 경우
* 유료 요금제로 업그레이드하거나 다운그레이드한 경우
* Cloudflare 계정에 새 도메인을 추가한 경우
* 구독 또는 추가 서비스(add-on service)를 활성화하거나 갱신한 경우

**Billing** 섹션에 포함되지 않은 과거 인보이스가 필요하면 [Cloudflare 지원팀에 문의](/support/contacting-cloudflare-support/)하세요.

:::note
Enterprise 고객은 Cloudflare 회계 팀으로부터 직접 인보이스를 받습니다.
:::

## Cloudflare 인보이스 이메일 활성화

계정에서 구독을 추가하거나 제거할 때 전송되는 Cloudflare 인보이스 이메일을 활성화하려면 다음 단계를 따르세요.

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />
    
3. **Invoices & Documents**를 선택합니다.
4. **Billing email preferences**에서 알림 스위치를 **On**으로 전환합니다.

인보이스 이메일을 활성화하면 다음 시점에 이메일로 인보이스를 받게 됩니다.

* 최초 설정 후 영업일 기준 1일 이내
* 매월 청구 기간 종료 시점
* 모든 신규 구매 후 영업일 기준 1일 이내

## 인보이스 다운로드

1. Cloudflare 대시보드에서 **Billing** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/billing" />

2. **Invoices & Documents**를 선택합니다.
4. 다운로드하려는 인보이스를 찾아 인보이스 번호 옆 아이콘을 선택합니다.

:::note
인보이스는 발행된 뒤 다시 생성할 수 없습니다. 보류 중인 청구 업데이트나 변경 사항은 다음 달 인보이스에 표시됩니다.
:::

## 청구 주기

월간 구독과 연간 구독은 서로 다른 청구 주기로 운영됩니다.

Cloudflare 계정에서 첫 번째 월간 구매가 이후 월간 구독의 청구일을 정합니다. 연간 구독도 동일한 방식으로 동작합니다.

계정에는 월간 구독용 청구 주기 하나와 연간 구독용 청구 주기 하나, 이렇게 두 가지 서로 다른 청구 주기가 있을 수 있습니다.

WARP Client 애플리케이션은 사용자가 활성화한 서비스에 따라 DNS 질의를 가로채 보호하고, 기기에서 Cloudflare 네트워크를 통해 데이터를 전송할 수 있게 하는 VPN profile 및/또는 service를 사용합니다. Cloudflare는 앱이 기기에서 활성화되어 있을 때 네트워크로 전송되는 제한적인 DNS 질의 데이터와 트래픽 데이터(payload 제외)만 수집합니다. 모든 정보는 [Privacy Policy](https://www.cloudflare.com/application/privacypolicy/)에 따라 처리됩니다.

## Cloudflare는 사용자의 데이터를 어떻게 사용하나요?

Cloudflare for Teams 조직에 속하지 않은 경우, Cloudflare는 서비스를 제공하는 데 필요하다고 판단하는 최소한의 데이터만 저장합니다. 서비스를 제공하는 데 필요하거나 Privacy Policy에 설명된 경우를 제외하고는, 사전에 통지하고 동의 기회를 제공하지 않은 상태에서 개인 정보를 판매, 대여, 공유하거나 기타 방식으로 공개하지 않습니다. 아래 예외를 제외하면 Cloudflare는 사용자가 누구인지, 인터넷에서 무엇을 하는지를 식별하기 위해 데이터를 사용하지 않습니다. Cloudflare는 Privacy Policy에 명시된 경우를 제외하고는 어떤 데이터도 저장하지 않습니다. 여기에는 앱 설치 ID, Cloudflare 네트워크를 통해 전송된 데이터 양, WARP Client 애플리케이션을 사용할 때의 평균 속도 등이 포함될 수 있습니다.

## Cloudflare의 사용자 데이터 사용 방식

### Registration ID

Cloudflare는 앱 설치 시 생성되는 임의 식별자를 사용해 사용자가 다른 사람에게 앱을 추천했을 때 referral bonus를 제공합니다.

### Data Transferred

Cloudflare는 WARP+ 사용량을 추적하기 위해 WARP 설치가 전송한 데이터 양을 추적합니다. 친구를 WARP에 추천하면 이 quota가 증가합니다.

### Average Speed

Cloudflare는 이 데이터를 사용해 WARP Client 애플리케이션이 인터넷 연결을 얼마나 더 빠르게 만드는지 이해합니다. 이 정보를 알면 지역 및 모바일 carrier 또는 인터넷 provider 환경에서 애플리케이션을 개선하는 데 도움이 됩니다.

### Aggregate Usage

Cloudflare는 웹사이트별, 지역별 aggregate 트래픽 양을 추적합니다. 이 정보는 향후 어떤 시점에 새로운 데이터 센터를 구축해야 하는지 더 잘 계획하는 데 도움이 됩니다.

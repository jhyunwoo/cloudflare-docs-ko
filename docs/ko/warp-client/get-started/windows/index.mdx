1. [Download](https://downloads.cloudflareclient.com/v1/download/windows/ga) Cloudflare WARP for Windows.
2. 미리 지정된 다운로드 폴더로 이동해 실행 파일을 열고 WARP를 설치합니다.
3. 안내에 따라 설치를 완료합니다. Cloudflare WARP는 자동으로 실행되며 Cloudflare 로고와 함께 menu bar에 표시됩니다.
4. **Next**와 **Accept**를 선택해 Cloudflare의 privacy policy에 동의합니다.
5. 토글을 켜서 WARP를 활성화합니다.

이제 WARP가 실행 중이며 인터넷 연결을 보호하고 있습니다.

## Cloudflare가 기기에 설치하는 항목

### Cloudflare WARP GUI

이 애플리케이션은 사용자가 직접 상호작용하는 기본 GUI 애플리케이션입니다. 다음 위치에서 찾을 수 있습니다.

- **Start** 메뉴 > **Cloudflare**
- 디스크의 `C:\Program Files\Cloudflare\Cloudflare WARP\Cloudflare WARP.exe`

### Cloudflare WARP service

이 Windows service는 wireguard tunnel을 설정하고 Cloudflare의 service endpoint와 client application 사이의 모든 상호작용을 담당합니다. `C:\Program Files\Cloudflare\Cloudflare WARP\warp-svc.exe`에서 찾을 수 있습니다.

### 로그 파일

Windows 애플리케이션은 어떤 부분이 정보를 기록하는지에 따라 두 위치에 로그 파일을 저장합니다. 이 로그는 **Feedback** > **Share debug information**를 체크했을 때 피드백 제출에 포함됩니다. 로그 위치는 다음과 같습니다.

- **WARP Service**: `C:\ProgramData\Cloudflare`
- **Application GUI Logs**: `C:\Users\<your username>\AppData\Local\Cloudflare`

## 애플리케이션 제거 방법

1. **Start** 메뉴를 선택하고 **Settings**를 검색합니다. `⊞ Win + I`를 눌러도 됩니다.
2. **Apps** > **App & Features**를 선택합니다.
3. 아래로 스크롤해 Cloudflare WARP를 선택한 뒤 **Uninstall**을 누릅니다.

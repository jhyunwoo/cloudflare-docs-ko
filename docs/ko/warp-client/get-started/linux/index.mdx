Linux에서 WARP를 설치하는 방법은 사용 중인 distro에 따라 두 가지가 있습니다.

- [package repository](https://pkg.cloudflareclient.com/)에서 최신 WARP client를 찾습니다.
- distro에 맞는 `cloudflare-warp` 패키지를 설치합니다.
  - **apt-based OS**(예: Ubuntu): `sudo apt install cloudflare-warp`
  - **yum-based OS**(예: CentOS 또는 RHEL): `sudo yum install cloudflare-warp`

:::note

터미널을 통한 설치 중 오류 메시지가 나타나면, [package repository](https://pkg.cloudflareclient.com/)에서 distro에 맞는 패키지를 다운로드하세요.

:::

## WARP 사용

command line interface는 WARP를 사용하는 기본 방법입니다.

### 최초 연결

처음으로 연결하려면 다음을 수행하세요.

1. 클라이언트를 등록합니다 `warp-cli registration new`.
2. 연결합니다 `warp-cli connect`.
3. `curl https://www.cloudflare.com/cdn-cgi/trace`를 실행해 `warp=on`인지 확인합니다.

### 모드 전환

전환 가능한 모드 목록은 `warp-cli mode --help`로 확인할 수 있습니다. 예를 들면 다음과 같습니다.

- **DoH를 통한 DNS only mode:** `warp-cli mode doh`
- **DoH와 함께 사용하는 WARP:** `warp-cli mode warp+doh`

### 터널 프로토콜 전환

기기에서 Cloudflare로 트래픽을 라우팅할 때 WARP가 사용하는 프로토콜을 바꿀 수 있습니다.

- **WireGuard:** `warp-cli tunnel protocol set WireGuard`
- **MASQUE:** (기본값) `warp-cli tunnel protocol set MASQUE`

:::note
프로토콜 값은 대소문자를 구분합니다.
:::

WireGuard와 MASQUE의 차이에 대한 정보는 [blog post](https://blog.cloudflare.com/zero-trust-warp-with-a-masque)를 참고하세요.

### 1.1.1.1 for Families 사용

Linux client는 WARP on 모드와 DNS-only 모드 모두에서 1.1.1.1 for Families의 모든 모드를 지원합니다.

- **Families mode 끔:** `warp-cli dns families off`
- **Malware protection:** `warp-cli dns families malware`
- **Malware and adult content:** `warp-cli dns families full`

### WARP+ Unlimited 활성화

Linux에서 [WARP+ Unlimited](/warp-client/warp-modes/#warp-unlimited)를 활성화하려면, 기존 WARP+ Unlimited 구독이 있는 iOS 또는 Android 기기가 필요합니다.

1. iOS 또는 Android 기기에서 **1.1.1.1 Faster Internet** 앱을 실행합니다.
2. **Settings** > **Account**로 이동해 **Key** 값을 복사합니다.
3. Linux 기기에서 다음 명령을 실행합니다.

	```sh
	warp-cli registration license <KEY>
	```
4. 새 등록 정보를 확인합니다.

	```sh
	warp-cli registration show
	```

	```sh output
	Account type: Unlimited
	...
	```

이제 이 기기에서 WARP+ Unlimited 구독이 활성화되었습니다.

### 추가 명령

지원되는 모든 명령의 전체 목록은 다음을 실행하여 확인할 수 있습니다.

```sh
warp-cli --help
```

## 피드백

WARP 문제를 디버깅하는 데 필요한 로그는 `sudo warp-diag`를 실행해 찾을 수 있습니다. 이 명령은 실행한 경로에 `warp-debugging-info.zip` 파일을 생성합니다.

버그를 신고하거나 팀에 피드백을 제공하려면 `sudo warp-diag feedback` 명령을 사용하세요. 이 명령은 support ticket을 제출합니다.

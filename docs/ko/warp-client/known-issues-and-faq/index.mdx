아래에는 WARP client와 관련해 가장 자주 묻는 질문에 대한 답변이 정리되어 있습니다. 찾고 있는 답을 찾지 못했다면, 더 많은 자료를 보려면 [community page](https://community.cloudflare.com/)를 참고하세요.

## 왜 더 가까운 Cloudflare 데이터 센터에 연결되지 않나요?

[Network Map](https://www.cloudflare.com/network/)에서 보듯이, Cloudflare는 전 세계에 위치를 보유하고 있습니다. 그러나 애플리케이션의 Advanced Connection stats를 보면, 연결 중인 서버가 물리적으로 가장 가까운 위치의 서버가 아닐 수 있습니다. 그 이유는 여러 가지가 있을 수 있습니다.

* Cloudflare는 이를 방지하기 위해 노력하지만, 때때로 가장 가까운 서버에 문제가 있을 수 있습니다. 자세한 내용은 [system status](https://www.cloudflarestatus.com/?_ga=2.155811579.1117044671.1600983837-1079355427.1599074097)를 확인하세요.
* 인터넷 제공업체가 비용 절감, 안정성, 기타 인프라상의 이유로 트래픽을 다른 경로로 라우팅할 수 있습니다.
* 모든 Cloudflare location이 WARP를 지원하는 것은 아닙니다. Cloudflare는 성능과 사용자 연결 방식을 지속적으로 평가하며, WARP를 지원하는 서버를 계속 추가하고 있습니다.

## WARP는 내가 방문하는 웹사이트에 내 IP 주소를 드러내나요?

아니요. 1.1.1.1 + WARP는 원래 IP 주소를 대략적인 위치를 일관되고 정확하게 나타내는 Cloudflare IP로 대체합니다. 이 동작은 사이트가 Cloudflare 네트워크 위에 있든 아니든 관계없이 동일합니다. 이 주제에 대한 자세한 내용은 [blog post](https://blog.cloudflare.com/geoexit-improving-warp-user-experience-larger-network/)를 참고하세요.

:::note
웹사이트에 마이크나 카메라 접근 권한을 부여하면 트래픽이 [bypass WARP](#known-issues)하고 원래 IP 주소가 표시됩니다.
:::

## WARP를 사용할 때 처리량이 떨어진 이유는 무엇인가요?

Cloudflare WARP는 부분적으로 세계에서 가장 빠른 DNS resolver인 [1.1.1.1](/1.1.1.1/)을 기반으로 동작합니다. 사이트를 방문하거나 인터넷의 새로운 위치로 이동할 때 빠른 DNS 조회를 기대할 수 있습니다. 그러나 WARP는 기기에서 나가고 들어오는 모든 트래픽을 암호화함으로써, 향상된 프라이버시를 위해 일부 처리량을 희생하도록 설계되어 있습니다. 대부분의 모바일 속도에서는 눈에 띄지 않지만, 고속 광대역이 보급된 국가의 데스크톱 시스템에서는 처리량 저하를 느낄 수 있습니다. Cloudflare는 이 tradeoff가 가치 있다고 생각하며, 시스템 전반의 성능 향상을 계속 진행하고 있습니다.

## WARP 앱 자체의 성능은 어떤가요?

Cloudflare WARP와 1.1.1.1 with WARP 애플리케이션은 배터리, 네트워크, CPU를 포함한 성능 테스트를 정기적으로 거칩니다. 또한 두 애플리케이션 모두 전 세계 수백만 명의 사용자가 실제로 사용하고 있어, 다양한 기기·네트워크·사이트·애플리케이션 전반의 문제를 빠르게 파악할 수 있도록 도와줍니다.


## Windows client에 필요한 .NET Framework 버전은 무엇인가요?

Windows용 WARP client를 사용하려면 컴퓨터에 .NET Framework 4.7.2 이상이 설치되어 있어야 합니다.

## 알려진 문제

- 위치 정보를 사용해 콘텐츠 라이선스 계약을 강제하는 애플리케이션이나 사이트(예: 일부 게임, 비디오 스트리밍, 음악 스트리밍, 라디오 스트리밍)는 제대로 동작하지 않을 수 있습니다. Cloudflare는 이들 client가 정상적으로 작동할 수 있도록, 해당 트래픽을 WARP로 보내지 않는 제품 업데이트를 작업 중입니다.

- Cloudflare WARP와 호환되지 않는 기기, 소프트웨어, 구성에 대한 정보는 [Known Limitations](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/known-limitations/)를 참고하세요.

- WARP는 WebRTC 트래픽을 프록시하지 않습니다. 실시간 화상 통화나 온라인 게임처럼 마이크 또는 카메라에 접근하는 애플리케이션이나 사이트는 WARP를 우회합니다. 그 결과 이러한 웹사이트에는 사용자의 IP 주소가 노출됩니다.

일반적으로 Expression Builder와 Expression Editor 사이에 다시 전환 할 수 있습니다. 그러나 Expression Builder는 다음과 같은 고급 기능을 지원하지 않습니다.

- [배열된 표현](#create-nested-expressions)
- [기능 호출](/ruleset-engine/rules-language/functions/)

Builder는 모든 필드를 표시할 수 없습니다.

고급 표현 기능을 사용하거나 편집기를 사용할 때 표시되지 않은 필드를 입력하면 Expression Builder로 전환 할 수 없습니다. 당신은 표시가 빌더에서 지원되지 않는 경고 팝업을 얻을 것이다. 진행하려면 편집기에서 만든 변경 사항을 삭제하거나, 스위치를 취소하고 편집기에서 작업을 계속할 수 있습니다.

## Expression 빌더

Expression Builder를 사용하면 드롭다운 리스트를 사용하여 규칙식을 시각화하고 필드 값을 입력하여 하나의 또는 여러 하위 압축을 정의할 수 있습니다.

![Expression Builder 인터페이스는 시각적으로 표현을 정의하는 데 사용됩니다.](~/assets/images/ruleset-engine/language/expression-builder.png)

더 보기**Expression 미리보기**텍스트의 표현 표시:

```sql
(ip.src.country ne "GB")
```

Expression Builder는[자동 탈출](#escape-special-characters)백슬래시 (Backslash)`\`)와 두 배 인용 (`"`) 문자열 리터럴의 특수 문자를 사용할 때[인용 문자열 구문](/ruleset-engine/rules-language/values/#quoted-string-syntax).

## Expression 편집기

더 보기**Expression 편집기**Cloudflare의 전체 사양을 지원하는 정의 규칙 표현을위한 텍스트 전용 인터페이스입니다[언어 선택](/ruleset-engine/rules-language/), 그룹 기호로 모체를 포함.

![Expression Editor는 고급 표현을 입력하는 데 사용됩니다.](~/assets/images/ruleset-engine/language/expression-editor.png)

Expression Editor에 액세스하려면, 선택**본문 바로가기**이름 \***Expression 미리보기**:

![사용자 정의 규칙 페이지의 편집 표현 선택 Expression Editor로 전환](~/assets/images/ruleset-engine/language/expression-builder.png)

Expression Editor에서 Expression Builder로 다시 전환하려면,**사용표시**.

### 특수 문자를 탈출

표현에서[인용 문자열 구문](/ruleset-engine/rules-language/values/#quoted-string-syntax), 모든 backslash (`\`)와 두 배 인용 (`"`) 문자열 리터럴의 문자는 탈출해야합니다. Visual Expression Builder는 이러한 특수 문자를 자동으로 탈출합니다.`\`·`"`이름 \*`\\`·`\"`각각.

```txt
# Example of an expression with a " character written using quoted string syntax
http.request.uri.path eq "/foo\"bar"
```

Expression Builder는 모두 지원합니다.[인용 문자열 구문](/ruleset-engine/rules-language/values/#quoted-string-syntax)그리고[원시 문자열 구문](/ruleset-engine/rules-language/values/#raw-string-syntax). 원시 문자열 구문에서, 특별한 문자나 탈출 순서가 없다, 그래서 모든 문자는 종료 delimiter로 해석된다.

```txt
# Example of an expression with a " character written using the raw string syntax
http.request.uri.path eq r#"/foo"bar"#
```

당신이 선택할 때*경기 regex*내 계정**회사연혁**대시보드의 드롭다운, 표현 미리보기는 자동으로 원시 문자열 구문을 사용합니다. 다른 상황에서 Expression Editor로 전환해야 할 수도 있습니다. 이 경우 Expression Builder로 다시 전환하면 편집기에서 사용되는 구문을 유지할 수 있습니다.

당신이 쓸 때[일반 표현](/ruleset-engine/rules-language/operators/#regular-expression-matching)인용 문자열 구문을 사용하여 추가 escaping을 수행해야합니다. — 참조[인용 문자열 구문](/ruleset-engine/rules-language/values/#quoted-string-syntax)상세 정보

복잡한 정규 표현식을 작성하려면 Cloudflare는 당신이 사용하는 것이 좋습니다[원시 문자열 구문](/ruleset-engine/rules-language/values/#raw-string-syntax)더 적은 escaping를 필요로 하는,.

### 배열된 표현 만들기

Expression Editor는 부모를 지원합니다.[그룹 기호](/ruleset-engine/rules-language/operators/#grouping-symbols). 턴에서 명시적으로 그룹과 둥지 표현식을 사용하며, 매우 표적으로 표현된 표현식을 만듭니다.

다음과 같은 규칙 표현은 말레이시아에서 아닌 모든 방문자로부터 요청을 일치하고 WordPress URI 경로에 액세스 할 것입니다.

```txt
((http.request.uri.path contains "/xmlrpc.php") or (http.request.uri.path
contains "/wp-login.php") or (http.request.uri.path contains "/wp-admin/"
and not http.request.uri.path contains "/wp-admin/admin-ajax.php" and not
http.request.uri.path contains "/wp-admin/theme-editor.php")) and
ip.src.country ne "MY"
```

Expression Editor는 위와 같은 배열된 표현들을 지원합니다. Expression Editor에서 배열된 표현을 가진 규칙을 작성하고 Expression Builder로 전환하려고 하는 경우, 대화상자는 Builder에서 사용할 수 없는 표현을 경고합니다. 당신은 신속하게 될 것입니다**Discard 변경**Expression Builder 또는 스위치**이름 \***&#xADF8;리고 편집기에서 계속 작업.

:::참조

규칙 표현의 문자열 비교는 case-sensitive입니다. 표정에 있는 문자열 수도화의 변화에 대해, 당신은 사용할 수 있습니다[`lower()`](/ruleset-engine/rules-language/functions/#lower)함수는 아래와 같이 lowcased 문자열로 결과를 비교합니다.

```txt
lower(http.request.uri.path) contains "/wp-login.php"
```

:::

## Expression 검증

Cloudflare는 저장하기 전에 모든 표현을 검증하므로 표현이 오류가 발생하면 Cloudflare QXQX대시보드의 오류 메시지를 받게됩니다.

```txt
Filter parsing error (1:313): ((http.request.uri.path contains
"/xmlrpc.php") or (http.request.uri.path contains "/wp-login.php") or
(http.request.uri.path contains "/wp-admin/" and not
http.request.uri.path contains "/wp-admin/admin-ajax.php" and not
http.request.uri.path contains "/wp-admin/theme-editor.php")) and
ip.src.country ne "MY") ^ unrecognised input
```

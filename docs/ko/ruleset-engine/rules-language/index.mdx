Cloudflare 규칙 언어는 건물 규칙 표식을 위한 가동 가능하고 직관적인 명세입니다. 널리 알려진[Wireshark 디스플레이 필터](https://www.wireshark.org/docs/wsug_html_chunked/ChWorkBuildDisplayFilterSection.html), 규칙 언어는 보안 엔지니어에게 익숙한 구문 및 semantics와 HTTP 요청을 정확하게 타겟팅 할 수 있습니다.

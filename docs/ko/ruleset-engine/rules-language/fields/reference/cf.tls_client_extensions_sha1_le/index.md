# 클라이언트 extensions sha1 le

`cf.tls_client_extensions_sha1_le`스트레이트

TLS 클라이언트 확장의 SHA-1 지문은 Base64에서 작은 엔디 형식을 사용하여 인코딩됩니다.

이 필드의 큰 끝 버전을 위해, 참조[`cf.tls_client_extensions_sha1`](https://developers.cloudflare.com/ruleset-engine/rules-language/fields/reference/cf.tls_client_extensions_sha1/).

예제 값:

```txt
"7zIpdDU5pvFPPBI2/PCzqbaXnRA="
```

# cf.edge.server 포트

`cf.edge.server_port`이름 \*

Cloudflare 글로벌 네트워크가 요청을 받은 포트 번호가 표시됩니다.

이 필드를 사용하여 특정 포트에 트래픽을 필터링합니다. 값은 범위 1–65535의 포트 번호입니다.

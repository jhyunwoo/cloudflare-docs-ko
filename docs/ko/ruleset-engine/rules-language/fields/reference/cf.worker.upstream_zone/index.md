# cf.worker.upstream zone에 대해

`cf.worker.upstream_zone`스트레이트

요청이 worker나 not에서 나온지 확인합니다.

요청이 노동자에서 온다 때, 이 필드는 그 노동자를위한 영역의 이름을 붙들 것입니다. 다른 것,`cf.worker.upstream_zone`비어 있습니다.

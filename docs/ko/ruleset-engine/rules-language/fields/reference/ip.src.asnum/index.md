# 사이트맵

`ip.src.asnum`이름 \*

16비트 또는 32비트 정수는 클라이언트 IP 주소와 관련된 Autonomous System(AS) 번호를 나타냅니다.

이 분야에는 동일한 값이 있습니다.`ip.geoip.asnum`분야, 이는 deprecated. 더 보기`ip.geoip.asnum`필드는 여전히 새로운 기존 규칙에 사용할 수 있지만, 사용해야합니다`ip.src.asnum`대신 필드.

*GeoIP는 MaxMind, Inc.의 등록 상표입니다.*

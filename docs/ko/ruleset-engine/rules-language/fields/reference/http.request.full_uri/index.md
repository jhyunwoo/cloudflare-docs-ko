# 다운로드

`http.request.full_uri`스트레이트

웹 서버에서 수신 한 전체 URI.

값은 포함되지 않습니다.`#fragment`웹 서버로 전송되지 않는 부분.

예제 값:

```txt
"https://www.example.org/articles/index?section=539061&expand=comments"
```

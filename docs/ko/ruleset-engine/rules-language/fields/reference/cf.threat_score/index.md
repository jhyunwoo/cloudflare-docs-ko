# 인기 카테고리

`cf.threat_score`이름 \*

Cloudflare 위협 점수를 나타냅니다.

이전의 위협 점수는 0-100에서 Cloudflare 위협 점수를 나타냅니다. 0이 낮은 위험을 나타냅니다. 이제 위협 점수는 항상`0`(제로).

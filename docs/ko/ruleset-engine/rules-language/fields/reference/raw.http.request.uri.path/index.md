# 원본.http.request.uri.path

`raw.http.request.uri.path`스트레이트

어떤 변화없이 요청의 원시 URI 경로.

이것은 원시 필드 버전의[`http.request.uri.path`](https://developers.cloudflare.com/ruleset-engine/rules-language/fields/reference/http.request.uri.path/)이름 \* 원료 분야, prefixed`raw.`, 나중에 평가에 대한 원래 요청 값을 보존. 이 필드는 전체 요청 평가 워크플로에서 immutable이며, 이전에 일치하는 규칙의 행동에 영향을 미치지 않습니다.

**이름 \***: 이 원시 필드는 Cloudflare의 HTTP 서버에서 수행 한 기본 정상화가 포함될 수 있습니다. 그러나 미래에 변화 할 수 있습니다.

# 원본.http.request.full uri

`raw.http.request.full_uri`스트레이트

웹 서버에 의해 수신 한 원시 풀 URI.

값은 포함되지 않습니다.`#fragment`웹 서버로 전송되지 않는 부분.

이것은 원시 필드 버전의[`http.request.full_uri`](https://developers.cloudflare.com/ruleset-engine/rules-language/fields/reference/http.request.full_uri/)이름 \* 원료 분야, prefixed`raw.`, 나중에 평가에 대한 원래 요청 값을 보존. 이 필드는 전체 요청 평가 워크플로에서 immutable이며, 이전에 일치하는 규칙의 행동에 영향을 미치지 않습니다.

**이름 \***: 이 원시 필드는 Cloudflare의 HTTP 서버에서 수행 한 기본 정상화가 포함될 수 있습니다. 그러나 미래에 변화 할 수 있습니다.

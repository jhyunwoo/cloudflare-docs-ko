# 클라이언트 auth.cert verified

`cf.tls_client_auth.cert_verified`스낵 바

기타 제품`true`요청이 유효한 클라이언트 인증서를 선물할 때.

자주 묻는 질문`true`요청 시 개정된 유효한 인증서가 포함될 때(refer to[`cf.tls_client_auth.cert_revoked`](https://developers.cloudflare.com/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_revoked/)).

이 필드는 요청이 클라이언트 인증서를 포함하는 경우에만 채워집니다[mTLS 인증](https://developers.cloudflare.com/ssl/client-certificates/enable-mtls/).

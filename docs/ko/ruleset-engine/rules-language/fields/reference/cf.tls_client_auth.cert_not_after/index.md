# 클라이언트 auth.cert not after

`cf.tls_client_auth.cert_not_after`스트레이트

요청의 인증서는이 날짜 이후에 유효하지 않습니다.

이 필드는 요청이 클라이언트 인증서를 포함하는 경우에만 채워집니다[mTLS 인증](https://developers.cloudflare.com/ssl/client-certificates/enable-mtls/).

예제 값:

```txt
"Mar 21 13:35:00 2023 GMT"
```

# cf.llm.prompt.unsafe topic  탐지

`cf.llm.prompt.unsafe_topic_detected`스낵 바

자주 묻는 질문[`cf.llm.prompt.unsafe_topic_categories`](https://developers.cloudflare.com/ruleset-engine/rules-language/fields/reference/cf.llm.prompt.unsafe_topic_categories/)필드는 비어 있지 않습니다.

Cloudflare 기업 계획을 요구합니다. 당신은 또한 활성화해야합니다[AI 보안 앱](https://developers.cloudflare.com/waf/detections/ai-security-for-apps/).

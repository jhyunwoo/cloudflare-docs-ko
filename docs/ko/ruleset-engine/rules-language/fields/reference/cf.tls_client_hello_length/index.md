# 클라이언트 hello length

`cf.tls_client_hello_length`이름 \*

클라이언트의 길이 hello 메시지를 보낸[카테고리](https://www.cloudflare.com/learning/ssl/what-happens-in-a-tls-handshake).

구체적으로, 클라이언트 hello의 bytestring의 길이.

예제 값:

```txt
508
```

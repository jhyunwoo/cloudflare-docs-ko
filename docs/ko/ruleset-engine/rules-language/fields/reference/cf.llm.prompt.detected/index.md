# cf.llm.prompt. 탐지

`cf.llm.prompt.detected`스낵 바

Cloudflare가 들어오는 요청에 LLM 프롬프트를 감지했는지 나타냅니다.

프롬프트가 존재하지 않을 때 다른 LLM 관련 필드는 기본 값이 있습니다.

Cloudflare 기업 계획을 요구합니다. 당신은 또한 활성화해야합니다[AI 보안 앱](https://developers.cloudflare.com/waf/detections/ai-security-for-apps/).

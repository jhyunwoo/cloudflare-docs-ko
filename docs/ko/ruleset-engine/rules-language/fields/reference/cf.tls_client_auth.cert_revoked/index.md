# 클라이언트 auth.cert revoked

`cf.tls_client_auth.cert_revoked`스낵 바

요청이 유효한지 여부를 표시하지만 클라이언트 인증서를 취소.

시간 :`true`·[`cf.tls_client_auth.cert_verified`](https://developers.cloudflare.com/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_verified/)분야도`true`.

이 필드는 요청이 클라이언트 인증서를 포함하는 경우에만 채워집니다[mTLS 인증](https://developers.cloudflare.com/ssl/client-certificates/enable-mtls/).

# 카테고리

`cf.waf.score`이름 \*

각 WAF 공격 벡터를 단일 점수로 결합한 1-99의 글로벌 점수.

특별한 점수`100`Cloudflare는 요청을 점수하지 않았다는 것을 나타냅니다.

이것은 표준입니다[WAF 공격 점수](https://developers.cloudflare.com/waf/detections/attack-score/)공격 패턴의 변형을 감지합니다.

Cloudflare 기업 계획을 요구합니다. 당신은 또한 활성화해야합니다[공격 점수 탐지](https://developers.cloudflare.com/waf/detections/attack-score/).

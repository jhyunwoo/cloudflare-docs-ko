# 클라이언트 auth.cert fingerprint sha256

`cf.tls_client_auth.cert_fingerprint_sha256`스트레이트

이 필드는 요청이 클라이언트 인증서를 포함하는 경우에만 채워집니다[mTLS 인증](https://developers.cloudflare.com/ssl/client-certificates/enable-mtls/).

예제 값:


# ip.src.subdivision 1 iso code

`ip.src.subdivision_1_iso_code`스트레이트

IP 주소와 관련된 첫번째 수준 지역을 위한 ISO 3166-2 부호.

실제 값이 유효하지 않을 때, 이 필드는 빈 문자열을 포함합니다.

Cloudflare 사업 또는 기업 계획을 요구합니다.

ISO 3166-2 표준 및 사용 가능한 지역에 대한 자세한 내용은 참조[자료: ISO 3166-2](https://en.wikipedia.org/wiki/ISO_3166-2)Wikipedia에.

이 분야에는 동일한 값이 있습니다.`ip.geoip.subdivision_1_iso_code`분야, 이는 deprecated. 더 보기`ip.geoip.subdivision_1_iso_code`필드는 여전히 새로운 기존 규칙에 사용할 수 있지만, 사용해야합니다`ip.src.subdivision_1_iso_code`대신 필드.

*GeoIP는 MaxMind, Inc.의 등록 상표입니다.*

예제 값:

```txt
"GB-ENG"
```

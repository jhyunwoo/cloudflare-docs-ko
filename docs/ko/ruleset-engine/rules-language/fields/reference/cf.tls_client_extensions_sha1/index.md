# 클라이언트 extensions sha1

`cf.tls_client_extensions_sha1`스트레이트

TLS 클라이언트 확장의 SHA-1 지문은 Base64에서 Big-endian 형식을 사용하여 인코딩됩니다.

이 필드의 작은 끝 버전의 경우, 참조[`cf.tls_client_extensions_sha1_le`](https://developers.cloudflare.com/ruleset-engine/rules-language/fields/reference/cf.tls_client_extensions_sha1_le/).

예제 값:

```txt
"OWFiM2I5ZDc0YWI0YWYzZmFkMGU0ZjhlYjhiYmVkMjgxNTU5YTU2Mg=="
```

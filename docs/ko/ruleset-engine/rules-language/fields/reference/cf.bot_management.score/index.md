# cf.bot management.score의

`cf.bot_management.score`이름 \*

요청이 1-99에서 점수를 사용하여 봇에서 시작되는 것을 의미한다.

낮은 점수는 bot 또는 자동화된 에이전트에서 요청이 제공된다는 것을 나타냅니다. 높은 점수는 인간이 요청을 발행한다는 것을 나타냅니다.

Cloudflare 기업 계획[Bot 관리](https://developers.cloudflare.com/bots/plans/bm-subscription/)지원하다

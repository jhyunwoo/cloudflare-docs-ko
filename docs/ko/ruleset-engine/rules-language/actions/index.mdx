## 지원된 행동

아래 표는 규칙 언어에서 사용할 수있는 작업을 나열합니다.

몇 가지 행동*제품정보*, 종료 작업을 호출, 나머지 규칙의 평가를 중지합니다. 더 보기*팟캐스트*행동은 평가를 건너*이름 \**&#xC77C;치 할 때 규칙, 그러나 정확한 행동은 규칙 구성에 따라 달라집니다.

사용 가능한 행동은[단계별](/ruleset-engine/about/phases/)규칙을 구성하는 곳. 이 제품에 의해 지원되는 단계 (s)에 대한 각 제품의 문서를 참조하십시오.

## 이용 약관

지역 또는 계정의 유효한 규칙을 나열할 수 있습니다.

API 엔드포인트 목록은[목록 및 볼 규칙](/ruleset-engine/rulesets-api/view/).

### 예: 영역 수준에서 유효한 규칙 보기

에 대한 응답[자주 묻는 질문](/api/resources/rulesets/methods/list/)지역 수준에서 규칙 목록을 얻는 것은 다음과 같은 규칙을 포함합니다:

- 당신이 배치 할 수있는 관리 규칙, 에 의해 표시`"kind": "managed"`.
- Zone-level 단계 항목 포인트 규칙, 설정된 경우, 표시된`"kind": "zone"`.
- 사용자 정의 규칙, 구성하는 경우, 표시된`"kind": "custom"`.

## 입장 포인트 규칙 받기

정의를 얻을 수 있습니다[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)이름 \*[단계별](/ruleset-engine/about/phases/)영역 또는 계정 수준에서.

항목 포인트 규칙이 존재하는 경우, API는 반환됩니다`200 OK`규칙 정의와 함께 HTTP 상태 코드.

항목 포인트 규칙이 존재하지 않는 경우, API는 반환됩니다`404 Not Found`HTTP 상태 코드.

### 예: 영역 수준에서 항목 포인트 규칙을 가져옵니다

다음 것[자주 묻는 질문](/api/resources/rulesets/subresources/phases/methods/get/)항목 포인트 규칙의 정의를 얻을`http_request_firewall_managed`영역 수준에서 단계. 이 경우, 엔트리 포인트 규칙은 존재하고 하나의 규칙을 포함합니다.

<APIRequest
  path="/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint"
  method="GET"
  parameters={{
  	ruleset_phase: "http_request_firewall_managed",
  }}
/>

```json output collapse={11-17}
{
	"result": {
		"id": "<RULESET_ID>",
		"name": "Zone-level phase entry point ruleset",
		"description": "This ruleset executes a managed ruleset.",
		"kind": "zone",
		"version": "2",
		"rules": [
			{
				"id": "<RULE_ID>",
				"version": "1",
				"action": "execute",
				"expression": "true",
				"action_parameters": {
					"id": "<MANAGED_RULESET_ID>"
				},
				"last_updated": "2021-03-17T15:42:37.917815Z"
			}
		],
		"last_updated": "2021-03-17T15:42:37.917815Z",
		"phase": "http_request_firewall_managed"
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

### 예: 계정 수준에서 엔트리 포인트 규칙 받기

다음 것[자주 묻는 질문](/api/resources/rulesets/subresources/phases/methods/get/)항목 포인트 규칙의 정의를 얻을`http_request_firewall_managed`계정 수준에서 단계.

<APIRequest
  path="/accounts/{account_id}/rulesets/phases/{ruleset_phase}/entrypoint"
  method="GET"
  parameters={{
  	ruleset_phase: "http_request_firewall_managed",
  }}
/>

## 규칙에 포함 된 규칙보기

당신은 단계 항목 포인트 규칙의 모든 버전을 볼 수 있습니다 (계정과 영역 수준에서) 및 사용자 정의 규칙, 하지만 당신은 관리 규칙의 가장 최근 버전을 볼 수 있습니다.

### 예: 영역 수준에서 단계 항목 포인트 규칙에 규칙을 볼

다음 것[자주 묻는 질문](/api/resources/rulesets/subresources/phases/subresources/versions/methods/get/)버전의 규칙 목록`2`이름 \*`http_request_firewall_managed`영역 수준에서 단계 항목 포인트 규칙.

<APIRequest
  path="/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint/versions/{ruleset_version}"
  method="GET"
  parameters={{
  	ruleset_phase: "http_request_firewall_managed",
  	ruleset_version: "2",
  }}
/>

```json output
{
	"result": {
		"id": "<RULESET_ID>",

		"description": "This ruleset executes a managed ruleset.",

			{
				"id": "<RULE_ID>",
				"version": "1",
				"action": "execute",
				"expression": "true",
				"action_parameters": {
					"id": "<MANAGED_RULESET_ID>"
				},

		],

```

사용 방법[규칙 세트 API](/ruleset-engine/rulesets-api/)규칙을 배포합니다. 규칙을 배포하려면 규칙을 추가하십시오.`"action": "execute"`한국어[단계 항목 점 규칙](/ruleset-engine/about/rulesets/#entry-point-ruleset)규칙 ID를 지정하여 동작 매개 변수로 실행합니다. 배포하려는 각 규칙에 대한 별도의 규칙을 사용하십시오.

규칙은 다음과 같다:

- 실행하려는 규칙의 ID, 포함`action_parameters.id`.
- 표현식.
- 더 보기`execute`활동.

룰렛의 규칙은 요청이 표현할 때 실행됩니다.

:::참조
영역 수준에서 각 요청에 따라 규칙을 적용하려면 규칙 표현을 설정하십시오.`true`.
:::

## 이름 \*

다음 예제를 배치[Cloudflare 관리되는 통치자](/waf/managed-rules/reference/cloudflare-managed-ruleset/)(ID 포함)<RuleID id="efb7b8c949ac4650a09736fc376e9aee" />)에`http_request_firewall_managed`주어진 영역의 단계 (`$ZONE_ID`) 관리 규칙을 추가하여.

<APIRequest
  path="/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint"
  method="PUT"
  parameters={{
  	ruleset_phase: "http_request_firewall_managed",
  }}
  json={{
  	rules: [
  		{
  			action: "execute",
  			action_parameters: {
  				id: "efb7b8c949ac4650a09736fc376e9aee",
  			},
  			expression: "true",
  			description: "Execute Cloudflare Managed Ruleset on my zone ruleset",
  		},
  	],
  }}
/>

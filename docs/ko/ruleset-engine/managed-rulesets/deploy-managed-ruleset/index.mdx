영역 수준 또는 계정 수준에서 관리 된 규칙을 배포 할 수 있습니다. 관리 규칙을 단계로 배포하려면, 사용[규칙 세트 API](/ruleset-engine/rulesets-api/).

Terraform을 사용하는 경우, 참조[WAF 관리 규칙 구성을 사용하여 Terraform](/terraform/additional-configurations/waf-managed-rulesets/)더 많은 정보.

Cloudflare 대시보드를 사용하는 경우 다음 페이지를 참조하십시오.

- [대시보드 (zone)에서 WAF 관리 규칙 배포](/waf/managed-rules/deploy-zone-dashboard/)
- [대시보드XQ에서 WAF 관리 규칙을 배포합니다.](/waf/account/managed-rulesets/deploy-dashboard/)

## 영역 수준에서 관리되는 규칙을 배포합니다.

다음 작업 흐름을 사용하여 관리된 규칙을 영역 수준에서 단계로 배치합니다.

1. 내 계정[지역 ID](/fundamentals/account/find-account-and-zone-ids/).
2. Invoke에[계정 규칙](/api/resources/rulesets/methods/list/)사용 가능한 관리 규칙을 얻기 위해 작업. 관리 규칙은 계정 수준에 존재하지만, 당신은 영역에 배치 할 수 있습니다. 배포하려는 관리 규칙의 규칙 ID를 찾으십시오.
3. 자주 묻는 질문[단계별](/ruleset-engine/reference/phases-list/)관리 규칙을 배포하고 싶은 곳. 관리 규칙은 배포하려는 동일한 단계에 속합니다.
4. 영역 수준의 단계에 규칙을 추가[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)관리된 규칙을 실행한다. 이 단계에서 세부 사항에 대한 다음 예제를 참조하십시오.

## 계정 수준에서 관리된 규칙을 배포합니다.

다음 작업 흐름을 사용하여 관리된 규칙을 계정 수준에서 단계로 배포합니다.

1. 내 계정[계정 ID](/fundamentals/account/find-account-and-zone-ids/).
2. Invoke에[계정 규칙](/api/resources/rulesets/methods/list/)사용 가능한 관리 규칙을 얻기 위해 작업. 배포하려는 관리 규칙의 규칙 ID를 찾으십시오.
3. 자주 묻는 질문[단계별](/ruleset-engine/reference/phases-list/)관리 규칙을 배포하고 싶은 곳. 관리 규칙은 배포하려는 동일한 단계에 속합니다.
4. 계정 수준의 단계에 규칙을 추가[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)관리된 규칙을 실행한다. 모체를 사용하여 규칙 표현에 대한 사용자 정의 조건을 닫고 표현을 종료하십시오.`and cf.zone.plan eq "ENT"`Enterprise 플랜의 영역에만 적용됩니다. 이 단계에서 세부 사항에 대한 다음 예제를 참조하십시오.

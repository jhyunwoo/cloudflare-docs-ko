룰렛 오버라이드를 사용 하 여 단계 항목 포인트 규칙에 덮여 관리된 규칙에만 선택한 규칙을 실행.

1. [규칙 추가](/ruleset-engine/basic-operations/deploy-rulesets/)관리 규칙을 실행하는 단계 항목 포인트 규칙.
2. [통치자 override 구성](/ruleset-engine/managed-rulesets/override-managed-ruleset/)관리 규칙에 모든 규칙을 비활성화합니다.
3. [규칙 override 구성](/ruleset-engine/managed-rulesets/override-managed-ruleset/)실행하려는 규칙에 대한 작업을 설정합니다.

## 지역 수준 예

다음 것`PUT`요청은[지역 항목 포인트 규칙 업데이트](/ruleset-engine/rulesets-api/update/)관리 규칙에서 두 가지 규칙을 실행하는 구성을 정의하는 작업`http_request_firewall_managed`단계.

이 예제에서:

- `"id": "<MANAGED_RULESET_ID>"`지정된 영역에서 요청을 실행하기 위해 관리 된 규칙을 정의합니다 (`$ZONE_ID`).
- `"enabled": false`모든 규칙을 처리하는 규칙 수준에서 배속을 정의합니다.
- `"rules": [{"id": "<RULE_ID_1>", "action": "block", "enabled": true}, {"id": "<RULE_ID_2>", "action": "log", "enabled": true}]`규칙 수준에서 중복 목록을 정의하여 두 개의 개별 규칙을 활성화합니다.

<APIRequest
  path="/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint"
  method="PUT"
  parameters={{
  	ruleset_phase: "http_request_firewall_managed",
  }}
  json={{
  	rules: [
  		{
  			action: "execute",
  			expression: "true",
  			action_parameters: {
  				id: "<MANAGED_RULESET_ID>",
  				overrides: {
  					enabled: false,
  					rules: [
  						{
  							id: "<RULE_ID_1>",
  							action: "block",
  							enabled: true,
  						},
  						{
  							id: "<RULE_ID_2>",
  							action: "log",
  							enabled: true,
  						},
  					],
  				},
  			},
  		},
  	],
  }}
/>

## 계정 수준 예

다음 것`PUT`요청은[계정 입력 포인트 규칙 업데이트](/ruleset-engine/rulesets-api/update/)관리 규칙에서 두 가지 규칙을 실행하는 구성을 정의하는 작업`http_request_firewall_managed`단계.

이 예제에서:

- `"id": "<MANAGED_RULESET_ID>"`요청 주소를 실행하기 위해 관리된 규칙을 정의합니다.`example.com`.
- `"enabled": false`모든 규칙을 처리하는 규칙 수준에서 배속을 정의합니다.
- `"rules": [{"id": "<RULE_ID_1>", "action": "block", "enabled": true}, {"id": "<RULE_ID_2>", "action": "log", "enabled": true}]`규칙 수준에서 중복 목록을 정의하여 두 개의 개별 규칙을 활성화합니다.

<Render file="deploy-account-ruleset-requirement" product="ruleset-engine" />

<APIRequest
  path="/accounts/{account_id}/rulesets/phases/{ruleset_phase}/entrypoint"
  method="PUT"
  parameters={{
  	ruleset_phase: "http_request_firewall_managed",
  }}
  json={{
  	rules: [
  		{
  			action: "execute",
  			expression: 'cf.zone.name eq "example.com" and cf.zone.plan eq "ENT"',
  			action_parameters: {
  				id: "<MANAGED_RULESET_ID>",
  				overrides: {
  					enabled: false,
  					rules: [
  						{
  							id: "<RULE_ID_1>",
  							action: "block",
  							enabled: true,
  						},
  						{
  							id: "<RULE_ID_2>",
  							action: "log",
  							enabled: true,
  						},
  					],
  				},
  			},
  		},
  	],
  }}
/>

QXQX0001XQ HTTP DDoS 공격 보호 관리 규칙의 특정 규칙의 감도를 무시하기 위해 아래의 단계를 따르십시오.

1. [규칙 추가](/ruleset-engine/basic-operations/deploy-rulesets/)Cloudflare HTTP DDoS 공격 보호 관리 규칙을 배치하는 단계. 당신은 기본적으로 활성화되어 있기 때문에 하나 이상의 override를 정의 할 때이 특정 규칙을 배포해야합니다.
2. [규칙 override 구성](/ruleset-engine/managed-rulesets/override-managed-ruleset/)그 세트`sensitivity_level`특정 규칙의.

## 이름 \*

다음 예제는[지역 항목 포인트 규칙 업데이트](/ruleset-engine/rulesets-api/update/)단일의 두 단계 실행`PUT`이름 \*

- 규칙을 설정`ddos_l7`Cloudflare HTTP DDoS 공격 보호 관리 규칙을 실행하는 단일 규칙에 단계 항목 포인트 규칙 (ID와)`<HTTP_DDOS_RULESET_ID>`).
- ID를 가진 규칙에 대한 override 만들기`<RULE_ID>`규칙 감도를 설정`low`. 다른 모든 규칙은 CloudflareXQ에 의해 정의된 과태 감도를 이용합니다.

<APIRequest
  path="/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint"
  method="PUT"
  parameters={{
  	ruleset_phase: "ddos_l7",
  }}
  json={{
  	rules: [
  		{
  			action: "execute",
  			expression: "true",
  			action_parameters: {
  				id: "<HTTP_DDOS_RULESET_ID>",
  				overrides: {
  					rules: [
  						{
  							id: "<RULE_ID>",
  							sensitivity_level: "low",
  						},
  					],
  				},
  			},
  		},
  	],
  }}
/>

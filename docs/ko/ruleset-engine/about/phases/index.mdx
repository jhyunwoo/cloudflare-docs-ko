단계는 실행할 수있는 요청의 삶에서 단계 정의[이름 \*](/ruleset-engine/about/rulesets/). 단계는 Cloudflare에 의해 정의되고 변경될 수 없습니다.

단계는 2개의 수준에 존재합니다:

- 에 의해[계좌정보](/fundamentals/concepts/accounts-and-zones/#accounts)1 단계
- 에 의해[이름 \*](/fundamentals/concepts/accounts-and-zones/#zones)1 단계

동일한 단계의 경우, 계정 수준에서 정의된 규칙은 영역 수준에서 정의된 규칙의 앞에 평가됩니다.

각 단계는 대부분의 것에 있습니다[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)계정과 영역 수준에서.

:::참조
현재 계정 수준에서 단계는 엔터프라이즈 플랜에서만 사용할 수 있습니다.
주요 특징

다음 다이어그램은 요청 처리 프로세스를 설명합니다. 요청은 사용 가능한 단계를 통해 이동합니다.

![요청 처리 프로세스를 보여주는 다이어그램. 사용자 요청은 결국 원래 서버에 도달 할 때까지 여러 요청 단계를 통해 간다 (요청도 차단 될 수있다). 원래는 응답을 반환, 이는 사용자가 도달 할 때까지 여러 응답 단계를 통해 간다.](~/assets/images/ruleset-engine/rulesets-phases.png)

Cloudflare 제품은 1개 이상 단계에 특정하고, 다른 특징을 위한 지원을 추가합니다. 해당 단계에 대한 자세한 내용은 각 Cloudflare 제품에 대한 문서를 확인하십시오.

더 알아보기[단계 목록](/ruleset-engine/reference/phases-list/)단계 및 해당 Cloudflare 제품의 목록을 위해.

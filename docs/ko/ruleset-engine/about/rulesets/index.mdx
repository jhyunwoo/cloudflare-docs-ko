규칙은 주문 집합입니다[【특전】](/ruleset-engine/about/rules/)Cloudflare 글로벌 네트워크의 트래픽에 적용 할 수 있습니다. Rulesets는 단계에 속하며 동일한 단계에서만 실행할 수 있습니다. 룰렛을 단계로 배포하려면, 규칙을 실행하는 규칙을 추가하십시오.[단계 항목 점 규칙](/ruleset-engine/about/rulesets/#entry-point-ruleset).

Rulesets는 버전입니다. 각 규칙 수정은 규칙의 새로운 버전을 만듭니다. 같은 시간에 사용할 규칙의 몇 가지 버전을 가질 수 있습니다. 규칙을 배포 할 때 - 즉, 규칙을 실행하는 규칙을 만들 때 - 규칙의 가장 최근 버전은 기본적으로 선택됩니다.

규칙의 몇몇 유형이 있습니다:

- 단계에는 항목 포인트 규칙이 있습니다.
- Cloudflare는 당신이 배치할 수 있는 관리한 규칙을 제공합니다.
- 사용자 정의 규칙을 만들고 관리 할 수 있습니다.

특정 Cloudflare 제품은 다른 유형의 규칙을 제공할지도 모릅니다.

## 관련 항목

항목 포인트 규칙은 주문 된 목록이 포함되어 있습니다.[【특전】](/ruleset-engine/about/rules/)그것에서 실행[단계별](/ruleset-engine/about/phases/)계정 또는 영역 수준에서. 이 규칙은 단계에서 실행된 모든 규칙에 대한 항목 포인트입니다. 이러한 규칙 중 일부는 다른 규칙을 실행할 수 있습니다.

각 단계에는 계정 수준과 영역 수준에서 가장 하나의 항목 포인트 규칙이 있습니다.

:::참조

더 보기`kind`단계 항목 포인트 규칙의 필드는 다음과 같은 값 중 하나입니다:

- `root`계정 수준에서 단계 항목 포인트 규칙
- `zone`영역 수준에서 단계 항목 포인트 규칙

:::

## 관련 규칙

매니지드 규칙은 Cloudflare에 의해 제공되는 사전 설정된 규칙입니다. Cloudflare는 이 규칙을 수정할 수 있습니다.

관리되는 규칙에는 기본 동작과 상태가 있습니다. 그러나 정의 할 수 있습니다.**관련 기사**이 기본값을 변경합니다.

관리되는 규칙을 당신에게 제공하는 몇몇 Cloudflare 제품이 있습니다. 사용 가능한 관리 규정에 대한 자세한 내용은 각 제품의 문서를 확인하십시오.

관리된 규칙을 배포하고 과도한 삭제에 대한 자세한 내용은 참조[관리 규칙과 함께 일](/ruleset-engine/managed-rulesets/).

## 주문 규칙

:::참조
현재, 사용자 정의 규칙은 Cloudflare QXWAF에서만 지원됩니다.
주요 특징

사용자 정의 규칙을 사용하여 규칙의 자신의 세트를 정의하십시오. 사용자 정의 규칙을 작성한 후, 규칙을 실행하는 규칙을 작성하여 단계에 배치하십시오.

사용자 정의 규칙 생성 및 배포에 대한 자세한 내용은 참조[주문 규칙 작업](/ruleset-engine/custom-rulesets/).

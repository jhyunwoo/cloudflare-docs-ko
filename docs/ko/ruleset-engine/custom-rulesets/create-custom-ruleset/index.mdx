사용 방법[계정 또는 영역 규칙 만들기](/api/resources/rulesets/methods/create/)사용자 정의 통치자를 만들려면, 당신이 확인:

- 설정하기`kind`관련 제품`custom`.
- 이름 지정[단계별](/ruleset-engine/reference/phases-list/)사용자 정의 규칙을 만드는 곳`phase`이름 \*

규칙 목록을 지정할 수도 있습니다.`rules`배열. 사용자 정의 규칙을 만들기 후 규칙을 추가하려면, 참조[사용자 정의 규칙에 규칙을 추가](/ruleset-engine/custom-rulesets/add-rules-ruleset/).

## 예 A - 계정 수준에서 사용자 정의 규칙

다음 요청은 계정 수준에서 새로운 사용자 정의 규칙을 만듭니다. 응답은 새로운 사용자 정의 규칙의 ID를 포함 할 것입니다`id`이름 \*

<APIRequest
  path="/accounts/{account_id}/rulesets"
  method="POST"
  json={{
  	name: "Custom Ruleset 1",
  	description: "My First Custom Ruleset (account)",
  	kind: "custom",
  	phase: "http_request_firewall_custom",
  }}
/>

```json output {3}
{
	"result": {
		"id": "f82ccda3d21f4a02825d3fe45b5e1c10",
		"name": "Custom Ruleset 1",
		"description": "My First Custom Ruleset (account)",
		"kind": "custom",
		"version": "1",
		"last_updated": "2025-08-09T10:27:30.636197Z",
		"phase": "http_request_firewall_custom"
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

사용자 정의 규칙 작성 요청에 규칙의 목록을 포함 할 수 있습니다. 어떤 규칙을 추가하지 않은 경우, 참조[사용자 정의 규칙에 규칙을 추가](/ruleset-engine/custom-rulesets/add-rules-ruleset/)더 많은 정보.

기존의 사용자 정의 규칙에 규칙을 추가하려면, 사용[계정 또는 영역 규칙 업데이트](/api/resources/rulesets/methods/update/)작업 및 배열의 규칙을 전달합니다. 각 규칙에는 표현과 행동이 있습니다.

:::tip\[ 적합한 API 방법]

더 보기[계정 또는 영역 규칙 업데이트](/api/resources/rulesets/methods/update/)작업은 요청의 규칙과 규칙의 모든 규칙을 대체합니다. 한 번에 여러 규칙을 추가하거나 업데이트 할 때이 API 작동을 사용하십시오. 이 작업은 한 번만 규칙 버전 번호를 업데이트합니다.

수행하려는 업데이트에 따라 다음 API 작업 중 하나를 사용하여 고려하십시오.

- 기존의 사용자 정의 규칙에 단일 규칙을 추가하십시오 : 사용[계정 또는 영역 규칙 규칙 만들기](/api/resources/rulesets/subresources/rules/methods/create/)가동. 더 알아보기[규칙에 추가](/ruleset-engine/rulesets-api/add-rule/)예를 들어.
- 사용자 정의 규칙에 단일 규칙을 업데이트 : 사용[계정 또는 영역 규칙 규칙 업데이트](/api/resources/rulesets/subresources/rules/methods/edit/)가동. 더 알아보기[규칙을 업데이트](/ruleset-engine/rulesets-api/update-rule/)예를 들어.

:::

## 규칙 추가

다음 요청은 ID로 계정 수준에서 맞춤 규칙에 두 가지 규칙을 추가합니다.`$RULESET_ID`. 이 규칙의 유일한 두 가지 규칙이 될 것입니다.

응답은 새로운 규칙의 규칙 ID를 포함합니다`id`이름 \*

<APIRequest
  path="/accounts/{account_id}/rulesets/{ruleset_id}"
  method="PUT"
  json={{
  	rules: [
  		{
  			expression:
  				'(ip.src.country in {"GB" "FR"} and cf.bot_management.score < 20 and not cf.bot_management.verified_bot)',
  			action: "challenge",
  			description: "challenge GB and FR based on bot score",
  		},
  		{
  			expression: 'not http.request.uri.path matches "^/api/.*$"',
  			action: "challenge",
  			description: "challenge not /api",
  		},
  	],
  }}
/>

## 업데이트 규칙

사용자 정의 규칙에 하나 이상의 규칙을 업데이트하려면, 사용[계정 또는 영역 규칙 업데이트](/api/resources/rulesets/methods/update/)가동. 규칙 배열에서 수정하고 업데이트하려는 필드를 추가하려는 규칙의 ID를 포함. 요청은 새로운 버전으로 전체 규칙을 대체합니다. 따라서, 당신은 유지하려는 모든 규칙의 ID를 포함해야합니다.

다음 것`PUT`요청은 계정 수준에서 사용자 정의 규칙에 하나의 규칙을 편집하고 규칙의 실행 순서를 업데이트합니다.

응답은 수정 된 사용자 정의 규칙을 포함합니다. 업데이트 된 규칙과 규칙 버전 번호 증가 참고.

<APIRequest
  path="/accounts/{account_id}/rulesets/{ruleset_id}"
  method="PUT"
  json={{
  	rules: [
  		{
  			id: "<CUSTOM_RULE_ID_2>",
  			expression: 'not http.request.uri.path matches "^/api/.*$"',
  			action: "js_challenge",
  			description: "js_challenge when not /api",
  		},
  		{
  			id: "<CUSTOM_RULE_ID_1>",
  		},
  	],
  }}
/>

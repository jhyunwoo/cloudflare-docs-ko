다음 작업 흐름을 사용하여 사용자 정의 규칙을 배포합니다.

1. [사용자 정의 규칙 만들기](/ruleset-engine/custom-rulesets/create-custom-ruleset/), 선택적으로 사용자 정의 규칙에 포함 규칙 목록을 제공.
2. (선택)[사용자 정의 규칙에 규칙을 추가](/ruleset-engine/custom-rulesets/add-rules-ruleset/).
3. [사용자 정의 규칙 배포](/ruleset-engine/custom-rulesets/deploy-custom-ruleset/)더 보기`execute`단계 항목 포인트 규칙. 이 단계를 건너면 사용자 정의 규칙의 규칙이 실행되지 않습니다.

현재, 사용자 정의 규칙은에서만 지원됩니다.[CloudflareWAF](/waf/), 계정과 지역 수준에 둘 다.

:::참조
다른 사용자 정의 규칙에서 사용자 정의 규칙을 실행할 수 없습니다.[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset).
:::

## 사용자 정의 규칙의 행동을 변경

사용자 정의 규칙 행동을 수정하려면 Cloudflare가 권장합니다.[새로운 사용자 정의 규칙 만들기](/ruleset-engine/custom-rulesets/create-custom-ruleset/)또는[사용자 정의 규칙 편집](/ruleset-engine/custom-rulesets/add-rules-ruleset/)overrides 대신.

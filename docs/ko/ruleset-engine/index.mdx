Cloudflare 규칙 세트 엔진은 동일한 기본 구문을 사용하여 다른 Cloudflare 제품에 규칙과 규칙을 만들고 배치할 수 있습니다.

## 주요 특징

- **강력한 구문**: 규칙 표현은 복잡한 규칙을 만들 수있는 Wirefilter 문법과 유사한 강력한 규칙 언어를 사용합니다.
- **고성능 규칙 평가**: 성능에 거의 영향을 미치지 않고 다른 Cloudflare 제품에서 많은 규칙을 가질 수 있습니다.
- **엔진 전원 다른 Cloudflare 제품**: Cloudflare는 같은 사용자 정의 가능성을 사용하여 다른 제품을 구성하기위한 동일한 API 방법을 사용할 수있는 규칙 설정 엔진의 상단에 건물 제품을 유지합니다. 또한, 통치자 엔진은 CloudflareXQ에서 요청 수명주기의 다른 단계를 지원합니다.

다음 표 목록[회사연혁](/ruleset-engine/about/phases/)의 Cloudflare 제품에 의해 구동되는 규칙 세트 엔진, 순서 그 단계는 실행됩니다. Cloudflare 웹 신청 방호벽과 같은 몇몇 제품은 1개의 관련 단계가 있습니다.

## 네트워크 층

[네트워크 층](https://www.cloudflare.com/learning/ddos/glossary/open-systems-interconnection-model-osi/)단계는 Cloudflare 글로벌 네트워크에서 수신된 패킷에 적용됩니다.

| 단계 이름                       | 제품/기능에서 사용하는                                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------------ |
| `ddos_l4`                   | [Network-layer DDoS 공격 보호](/ddos-protection/managed-rulesets/network/network-overrides/configure-api/) |
| `magic_transit`             | [Cloudflare 네트워크 방화벽](/cloudflare-one/traffic-policies/packet-filtering/add-policies/)                 |
| `magic_transit_managed`     | [Cloudflare 네트워크 방화벽 관리 규칙](/cloudflare-network-firewall/how-to/enable-managed-rulesets/)              |
| `magic_transit_ratelimit`   | [Cloudflare 네트워크 방화벽 비율 제한 정책](/cloudflare-network-firewall/how-to/create-rate-limiting-policies/)     |
| `magic_transit_ids_managed` | [Cloudflare 네트워크 방화벽 침입 감지 시스템 (IDS)](/cloudflare-network-firewall/about/ids/)                         |

## 신청 층

[신청 층](https://www.cloudflare.com/learning/ddos/what-is-layer-7/)단계는 Cloudflare 글로벌 네트워크에서 수신된 요청에 적용됩니다.

### 요청 단계

단계는 테이블에 나타나는 순서에서 실행합니다.

| 단계 이름                              | 제품/기능에서 사용하는                                                            |
| ---------------------------------- | ----------------------------------------------------------------------- |
| `http_request_dynamic_redirect`    | [단일 Redirects](/rules/url-forwarding/single-redirects/)                 |
| `http_request_sanitize`            | [URL 정상화](/rules/normalization/)                                        |
| `http_request_transform`           | [URL Rewrite 규칙](/rules/transform/url-rewrite/)                         |
| *사이트맵*(내부 단계)                      | [대기실 규칙](/waiting-room/additional-options/waiting-room-rules/)          |
| `http_request_api_gateway_early`\* | [모델 번호: API Shield](/api-shield/)                                       |
| `http_config_settings`             | [구성 규칙](/rules/configuration-rules/)                                    |
| `http_request_origin`              | [회사 소개](/rules/origin-rules/)                                           |
| `ddos_l7`\*                        | [HTTP DDoS 공격 보호](/ddos-protection/managed-rulesets/http/)              |
| `http_request_firewall_custom`     | [사용자 정의 규칙 (Web Application Firewall)](/waf/custom-rules/)              |
| `http_ratelimit`                   | [제한 규칙 (WAF)](/waf/rate-limiting-rules/)                                |
| `http_request_api_gateway_late`    | [모델 번호: API Shield](/api-shield/)                                       |
| `http_request_firewall_managed`    | [WAF 관리 규칙](/waf/managed-rules/)                                        |
| `http_request_sbfm`                | [슈퍼 Bot 전투 모드](/bots/get-started/super-bot-fight-mode/)                 |
| *사이트맵*(내부 단계)                      | [모델 번호: Cloudflare 오시는 길](/cloudflare-one/access-controls/policies/)    |
| `http_request_redirect`            | [대량 Redirects](/rules/url-forwarding/bulk-redirects/)                   |
| *사이트맵*(내부 단계)                      | [관리된 Transforms](/rules/transform/managed-transforms/)                  |
| `http_request_late_transform`      | [Header Transform 규칙 요청](/rules/transform/request-header-modification/) |
| `http_request_cache_settings`      | [캐시 규칙](/cache/how-to/cache-rules/)                                     |
| `http_request_snippets`            | [뚱 베어](/rules/snippets/)                                                |
| `http_request_cloud_connector`     | [클라우드 커넥터](/rules/cloud-connector/)                                     |

\* *이 단계는 구성 목적으로만 사용됩니다. 해당 규칙은 요청 처리 과정에서 이 단계에서 실행되지 않습니다.*

| 단계 이름                             | 제품/기능에서 사용하는                                                         |

계정 또는 영역 수준에서 규칙에 단일 규칙을 삭제합니다.

다음 API 엔드포인트 중 하나를 사용하십시오:

- [계정 규칙 삭제](/api/resources/rulesets/subresources/rules/methods/delete/)<br />
  `DELETE /accounts/{account_id}/rulesets/{ruleset_id}/rules/{rule_id}`
- [지역 규칙 규칙 삭제](/api/resources/rulesets/subresources/rules/methods/delete/)<br />
  `DELETE /zones/{zone_id}/rulesets/{ruleset_id}/rules/{rule_id}`

삭제 작업이 성공하면 API 메소드 호출이 반환됩니다.`200 OK`응답 몸에서 완전한 통치자를 가진 HTTP 상태 부호.

## 이름 \*

다음 예제 삭제 규칙`$RULE_ID_1`관련 기사`$RULESET_ID`.

응답은 규칙을 삭제 한 후 완전한 규칙을 포함합니다.

<APIRequest
  path="/accounts/{account_id}/rulesets/{ruleset_id}/rules/{rule_id}"
  method="DELETE"
  parameters={{
  	rule_id: "$RULE_ID_1",
  }}
/>

## 규칙 삭제

계정 또는 영역 수준에서 기존 규칙의 모든 버전을 삭제합니다.

다음 API 엔드포인트 중 하나를 사용하십시오:

- [계정 규칙 삭제](/api/resources/rulesets/methods/delete/)<br />
  `DELETE /accounts/{account_id}/rulesets/{ruleset_id}`
- [지역 규칙 삭제](/api/resources/rulesets/methods/delete/)<br />
  `DELETE /zones/{zone_id}/rulesets/{ruleset_id}`

삭제 작업이 성공하면 API 메소드 호출이 반환됩니다.`204 No Content`HTTP 상태 코드.

:::참조

다른 규칙에서 여전히 참고 자료d 인 규칙을 삭제할 수 없습니다. 예를 들어 규칙에 배치되는 사용자 정의 규칙을 삭제할 수 없습니다.`execute`활동.

규칙을 삭제하려면 참고 자료 규칙을 업데이트하거나 삭제하고 다시 시도하십시오.

:::

### 이름 \*

다음 예제 요청은 ID로 기존의 규칙을 삭제합니다.`$RULESET_ID`.

<APIRequest path="/accounts/{account_id}/rulesets/{ruleset_id}" method="DELETE" />

## 규칙 버전 삭제

규칙의 특정 버전 삭제.

다음 API 엔드포인트 중 하나를 사용하십시오:

- [계정 규칙 버전 삭제](/api/resources/rulesets/subresources/versions/methods/delete/)<br />
  `DELETE /accounts/{account_id}/rulesets/{ruleset_id}/versions/{version_number}`
- [지역 규칙 버전 삭제](/api/resources/rulesets/subresources/versions/methods/delete/)<br />
  `DELETE /zones/{zone_id}/rulesets/{ruleset_id}/versions/{version_number}`

삭제 작업이 성공하면 메소드 호출이 반환됩니다.`204 No Content`HTTP 상태 코드.

규칙에 대한 나중에 업데이트는 삭제 된 규칙 버전의 버전 번호를 재사용하지 않습니다.

:::참조

최신 규칙 버전이면 규칙을 삭제할 수 없습니다.`execute`그 규칙을 배치하는 작업.

규칙 버전을 삭제하려면 참고 자료 규칙을 업데이트하거나 삭제하고 다시 시도하십시오.

:::

### 이름 \*

다음 예제 요청은 기존 규칙의 버전을 삭제합니다.

<APIRequest path="/accounts/{account_id}/rulesets/{ruleset_id}/versions/{ruleset_version}" method="DELETE" />

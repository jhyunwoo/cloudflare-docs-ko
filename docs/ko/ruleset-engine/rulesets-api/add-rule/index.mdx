기존 규칙에 단일 규칙을 추가합니다. 이 엔드포인트를 사용하여 요청의 모든 기존 규칙 규칙을 포함하지 않고 규칙을 추가하십시오.

다음 API 엔드포인트 중 하나를 사용하십시오:

- [계정 규칙 생성](/api/resources/rulesets/subresources/rules/methods/create/)<br />
  `POST /accounts/{account_id}/rulesets/{ruleset_id}/rules`
- [영역 규칙을 작성](/api/resources/rulesets/subresources/rules/methods/create/)<br />
  `POST /zones/{zone_id}/rulesets/{ruleset_id}/rules`

요청 몸의 규칙 정의를 포함.

기본적으로 규칙은 규칙의 기존 목록의 끝에 추가됩니다. 규칙에 대한 특정 위치를 정의하려면`position`요청에 따라 신체의 객체는 지침에 따라[규칙의 순서를 변경](/ruleset-engine/rulesets-api/update-rule/#change-the-order-of-a-rule-in-a-ruleset).

이 방법을 호출하면 규칙의 새로운 버전을 만듭니다.

## 이름 \*

다음 것`POST`요청은 규칙을 추가합니다.`$RULESET_ID`영역의`$ZONE_ID`. 규칙 ID는 이전에 얻었다[영역 규칙](/api/resources/rulesets/methods/list/)작업, 및 항목 점 규칙에 대응`http_request_firewall_custom`단계.

응답은 규칙을 추가 한 후 완전한 규칙을 포함합니다.

몇몇 가동을 위해, 당신은 단계 입장 점 규칙을 관리하는 통치자 API에 의해 제공된 특정한 엔드포인트를 이용할 수 있습니다. 이 엔드포인트는 규칙 ID 대신 엔드포인트의 단계 이름을 포함합니다.

예를 들어, 다음과 같은 엔드포인트를 사용하는 경우:

```txt
PUT /zones/{zone_id}/rulesets/{ruleset_id}
```

다음 엔드포인트를 사용할 수 있습니다:

```txt
PUT /zones/{zone_id}/rulesets/phases/{phase_name}/entrypoint
```

규칙 설정 API 작동을 호출하려면 Cloudflare API 기본 URL에 엔드포인트를 추가하십시오.

```txt
https://api.cloudflare.com/client/v4
```

인증 지침은, 참조[시작하기: 요청](/fundamentals/api/)Cloudflare API 문서에서.

endpoints 및 pagination에 대한 도움말, 참조[시작하기: Endpoints](/fundamentals/api/).

:::참조

Rulesets API 엔드포인트는 값이 필요합니다.`{account_id}`또는`{zone_id}`.

계정 목록을 검색하려면 액세스 할 수 있습니다.[계정 목록](/api/resources/accounts/methods/list/)가동. 관리하려는 계정의 ID를 참고하십시오.

액세스해야 할 영역 목록을 검색하려면[지역 목록](/api/resources/zones/methods/list/)가동. 관리하려는 영역의 ID를 참고하십시오.

:::

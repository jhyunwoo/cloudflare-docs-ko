이 페이지는 API 요청 생성 또는 업데이트 규칙 및 규칙 API를 통해 JSON 객체를 설명하고, API에 의해 반환된 객체.

## Ruleset 객체

완전히 populated 통치자는 뒤에 오는 JSON 구조를 비치하고 있습니다.

```json
{
	"id": "6a359df138c442b385d20140d4d96919",
	"name": "Example Ruleset",
	"description": "Description of Example Ruleset",
	"kind": "custom",
	"version": "2",
	"phase": "http_request_firewall_custom",
	"rules": [
		{
			"id": "fdb0dd271f3f40b19679cc5d91396024",
			"version": "2",
			"action": "block",
			"expression": "cf.zone.name eq \"example.com\" ",
			"last_updated": "2022-07-20T10:44:29.124515Z"
		}
	],
	"last_updated": "2022-07-20T10:44:29.124515Z"
}
```

규칙의 속성에 대한 자세한 내용은`rules`배열, 참조[규칙 객체 구조 및 속성](#rule-object-structure-and-properties)이름 \*

### 제품 정보

통치자는 다음과 같은 속성을 가지고:

- `id` <Type text="String" />
  - 독특한 Cloudflare-generated 식별자를 나타내는 32-character UUIDv4 문자열.
  - 독특한, 읽기 전용.

- `name` <Type text="String" />
  - 룰렛의 인간적인 이름.
  - 이름은 immutable입니다. 규칙의 일생에 이름을 변경할 수 없습니다.

- `description` <Type text="String" />
  - 규칙에 대한 옵션 설명.
  - 규칙의 일생에 대한 설명을 변경할 수 있습니다.

- `kind` <Type text="String" />
  - JSON 객체의 종류는 나타냅니다.
  - 한국어`root`, `zone`, `managed`, `custom`.
  - `kind`불균형.

- `version` <Type text="Integer" />
  - 규칙의 버전.
  - 읽기 전용 값 시작`1`관련 기사`1`각각의 규칙은 수정됩니다.

- `rules` <Type text="Array<Rule>" />
  - 규칙에 포함 하는 규칙의 목록. 더 알아보기[규칙 객체 구조 및 속성](#rule-object-structure-and-properties)상세 정보

- `last_updated` <Type text="Timestamp" />
  - 규칙이 ISO 8601 형식으로 업데이트되었을 때 시간 (UTC) :`YYYY-MM-DDThh:mm:ss.TZD`.
  - 읽기 전용.

## 규칙 객체 구조 및 속성

완전히 채워진 규칙 JSON 객체에는 다음과 같은 구조가 있습니다.

```json
{
	"id": "fdb0dd271f3f40b19679cc5d91396024",
	"version": "2",
	"ref": "<REF>",
	"description": "<DESCRIPTION>",
	"action": "block",
	"action_parameters": [
		// action parameters vary according to the action
	],
	"categories": ["<CATEGORY_1>", "<CATEGORY_2>"],
	"expression": "cf.zone.name eq \"example.com\"",
	"last_updated": "2025-07-20T10:44:29.124515Z",
	"enabled": true
}
```

규칙의 JSON 객체 속성은 다음과 같이 정의됩니다.

- `id` <Type text="String" />
  - 규칙의 주어진 버전을 위한 독특한 Cloudflare-generated 식별자를 나타내는 32-character UUIDv4 문자열.
  - 독특한, 읽기 전용.

- `version` <Type text="Integer" />
  - 규칙의 버전.
  - 읽기 전용 값 시작`1`관련 기사`1`각 시간 규칙은 수정됩니다.
  - 규칙의 순서를 변경하지 않습니다 버전.

- `ref` <Type text="String" />
  - 규칙의 각 규칙에 고유해야합니다 사용자 정의 외부 식별자.
  - 이 필드를 사용하여 Terraform 구성에서 Terraform을 변경에 대한 규칙을 재구성합니다. 더 알아보기[수정 사이에 동일한 규칙 ID를 유지하는 방법](/terraform/troubleshooting/rule-id-changes/#how-to-keep-the-same-rule-id-between-modifications)더 많은 정보.

- `description` <Type text="String" />
  - 규칙의 설명 이름.

- `action` <Type text="String" />
  - 규칙 표현에 대한 일치가있을 때 무슨 일이 발생.
  - 이용안내[기타](/ruleset-engine/rules-language/actions/)에 따라[단계별](/ruleset-engine/about/phases/)규칙의 규칙이 실행되는 곳.

- `action_parameters` <Type text="Object" />
  - 규칙 동작을 구성하는 하나 이상의 매개 변수.
  - 정확한 속성은 행동에 따라 다릅니다. 자세한 내용은 각 Cloudflare 제품 API 지침을 참조하십시오.

- `categories` <Type text="Array<String>" />
  - 현재 규칙과 관련된 태그. 주어진 태그와 규칙에 영향을 미칩니다.
  - 읽기 전용. 이용 가능[WAF 관리 규칙](/waf/managed-rules/)·[DDoS 관리 규정](/ddos-protection/managed-rulesets/).

- `expression` <Type text="String" />
  - 현재 규칙에 대한 일치가있을 때 Criteria defining.
  - 규칙 표현에서 사용할 수있는 필드와 함수는 규칙의 규칙이 실행되는 단계에 따라 달라집니다.

- `last_updated` <Type text="Timestamp" />
  - 규칙이 ISO 8601 형식으로 업데이트되었을 때 시간 (UTC) :`YYYY-MM-DDThh:mm:ss.TZD`.
  - 읽기 전용.

- `enabled` <Type text="Boolean" />
  - 설정할 때`true`, 현재 규칙이 활성화됩니다.

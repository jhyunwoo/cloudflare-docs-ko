## 자주 묻는 질문

계정 수준 또는 영역 수준에서 기존 규칙 목록을 반환합니다.

다음 API 엔드포인트 중 하나를 사용하십시오:

- [계정 규칙](/api/resources/rulesets/methods/list/)<br />
  `GET /accounts/{account_id}/rulesets`
- [영역 규칙](/api/resources/rulesets/methods/list/)<br />
  `GET /zones/{zone_id}/rulesets`

결과는 주어진 수준 (계좌 또는 지역)에 모든 단계에 걸쳐 규칙을 포함합니다. 더 보기`phase`각 결과 요소의 필드는[단계별](/ruleset-engine/about/phases/)그 규칙은 정의된다.

또한, 영역 수준에서 규칙 목록은 지정된 영역으로 배포 할 수 있습니다 계정 레벨 규칙을 포함합니다.

:::참조
모든 영역 레벨 단계는 이 API 메소드에 의해 반환된 목록에서 제시되는 경우에도 모든 유형의 규칙을 지원합니다. 각 CloudflareXQ 제품에 대한 문서 확인은 해당 제품의 지원 단계에서 허용됩니다.
주요 특징

결과는 규칙에 규칙의 목록을 포함하지 않습니다. 더 알아보기[규칙의 특정 버전보기](#view-a-specific-version-of-a-ruleset)규칙 목록을 얻는 방법을 배우기 위해.

### 이름 \*

<APIRequest path="/zones/{zone_id}/rulesets" method="GET" />

```json output
{
	"result": [
		{
			"id": "<PHASE_RULESET_ID>",
			"name": "Zone-level phase entry point",
			"description": "",
			"kind": "zone",
			"version": "5",
			"last_updated": "2025-03-18T18:30:08.122758Z",
			"phase": "http_request_firewall_managed"
		}
	],
	"success": true,
	"errors": [],
	"messages": []
}
```

## 특정 규칙 보기

지정된 규칙 ID와 규칙의 가장 최근 버전의 속성을 반환합니다.

다음 API 엔드포인트 중 하나를 사용하십시오:

- [계정 규칙 받기](/api/resources/rulesets/methods/get/)<br />
  `GET /accounts/{account_id}/rulesets/{ruleset_id}`
- [계정 입력 포인트 규칙 받기](/api/resources/rulesets/subresources/phases/methods/get/)<br />
  `GET /accounts/{account_id}/rulesets/phases/{phase_name}/entrypoint`
- [지역 규칙 받기](/api/resources/rulesets/methods/get/)<br />
  `GET /zones/{zone_id}/rulesets/{ruleset_id}`
- [지역 항목 포인트 규칙 받기](/api/resources/rulesets/subresources/phases/methods/get/)<br />
  `GET /zones/{zone_id}/rulesets/phases/{phase_name}/entrypoint`

:::참조
만 사용할 수 있습니다[지역 규칙 받기](/api/resources/rulesets/methods/get/)Zone-level 단계 항목 포인트 규칙에 대한 운영 (위험점)`kind`설정`zone`).
:::

API는 반환`404 Not Found`이러한 조건 하에서 HTTP 상태 코드:

- 규칙을 찾을 수 없습니다.
- 지정된 규칙이 관리되지 않을 때 호출 계정은 실행할 수 있습니다.

### 이름 \*

<APIRequest path="/zones/{zone_id}/rulesets/{ruleset_id}" method="GET" />

```json output
{
	"result": {
		"id": "<RULESET_ID>",
		"name": "Zone-level phase entry point",
		"description": "Executes a managed ruleset.",
		"kind": "zone",
		"version": "3",
		"rules": [
			{
				"id": "<RULE_ID>",
				"version": "1",
				"action": "execute",
				"expression": "true",
				"action_parameters": {
					"id": "<MANAGED_RULESET_ID>"
				},
				"last_updated": "2025-03-17T15:42:37.917815Z"
			}
		],
		"last_updated": "2025-03-17T15:42:37.917815Z",
		"phase": "http_request_firewall_managed"
```

## 모든 버전의 규칙 목록

규칙의 모든 버전의 목록을 반환합니다.

다음 API 엔드포인트 중 하나를 사용하십시오:

- [계정 규칙 버전](/api/resources/rulesets/subresources/versions/methods/list/)<br />
  `GET /accounts/{account_id}/rulesets/{ruleset_id}/versions`
- [계정 항목 포인트 규칙 버전](/api/resources/rulesets/subresources/phases/subresources/versions/methods/list/)<br />
  `GET /accounts/{account_id}/rulesets/phases/{phase_name}/entrypoint/versions`
- [영역 규칙 버전](/api/resources/rulesets/subresources/versions/methods/list/)<br />
  `GET /zones/{zone_id}/rulesets/{ruleset_id}/versions`
- [지역 항목 포인트 규칙 버전](/api/resources/rulesets/subresources/phases/subresources/versions/methods/list/)<br />
  `GET /zones/{zone_id}/rulesets/phases/{phase_name}/entrypoint/versions`

결과는 각 버전의 규칙 속성을 포함하지만 규칙 목록을 포함하지 않습니다. 더 알아보기[규칙의 특정 버전보기](#view-a-specific-version-of-a-ruleset)이 정보를 얻기에 대한 지침.

## 규칙의 특정 버전보기

규칙의 특정 버전의 구성을 반환합니다.

다음 API 엔드포인트 중 하나를 사용하십시오:

- [계정 규칙 버전 받기](/api/resources/rulesets/subresources/versions/methods/get/)<br />
  `GET /account/{account_id}/rulesets/{ruleset_id}/versions/{version_number}`
- [계정 항목 포인트 규칙 버전 받기](/api/resources/rulesets/subresources/phases/subresources/versions/methods/get/)<br />
  `GET /accounts/{account_id}/rulesets/phases/{phase_name}/entrypoint/versions/{version_number}`
- [지역 규칙 버전 받기](/api/resources/rulesets/subresources/versions/methods/get/)<br />
  `GET /zones/{zone_id}/rulesets/{ruleset_id}/versions/{version_number}`
- [지역 항목 포인트 규칙 버전 받기](/api/resources/rulesets/subresources/phases/subresources/versions/methods/get/)<br />
  `GET /zones/{zone_id}/rulesets/phases/{phase_name}/entrypoint/versions/{version_number}`

지정된 단계 항목 포인트 규칙이 존재하지 않는 경우, 이 API 방법은 반환`404 Not Found`HTTP 상태 코드.

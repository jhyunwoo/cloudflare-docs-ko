Rulesets API는 Ruleset Engine의 다른 Cloudflare 제품을 지원하는 규칙의 실행을 관리하고 구성하는 인터페이스를 제공합니다.

## 시작하기

시작하기에, 리뷰[JSON 객체](/ruleset-engine/rulesets-api/json-object/)이용안내[끝점](/ruleset-engine/rulesets-api/endpoints/).

***

## 제한 사항

동일한 규칙에 동시 업데이트를 방지해야합니다. 동시 업데이트에서 같은 규칙을 방지하기 위해 장소에 제한이 있습니다. 정확한 제한은 규칙의 크기와 요청에 따라 달라집니다. 각 규칙에 따라 다를 수 있습니다.

비율 제한은 동시에 동일한 규칙에 여러 규칙을 수정할 때 가장 자주 히트합니다. 이것을 피하기 위해, 당신은해야합니다[단일 작업에서 전체 규칙을 업데이트](/ruleset-engine/rulesets-api/update/)대신.

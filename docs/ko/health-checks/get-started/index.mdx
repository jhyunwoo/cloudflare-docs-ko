이 가이드는 구성된 Health Checks를 생성하고 관리하는 방법을 시작부터 안내합니다.

## Health Check 생성

1. Cloudflare 대시보드에서 **Health Checks** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/traffic/health-checks" />

2. **Create**를 선택하고 양식을 작성합니다. 특히 다음 항목에 주의하세요.
   - **Interval**과 **Check regions** 값. **Interval**을 줄이고 **Check regions**를 늘리면 오리진 서버에 가해지는 부하가 증가할 수 있습니다.
   - **Retries**. 타임아웃이 발생했을 때 오리진을 비정상으로 표시하기 전에 몇 번 재시도할지 지정합니다.
   - **Response body**. 검사 성공을 위해 응답 본문 첫 10KB 안에 반드시 포함되어야 하는 부분 문자열을 지정합니다.
3. **Save and Deploy**를 선택합니다.

## Health Checks 관리

1. [Cloudflare 대시보드](https://dash.cloudflare.com)에 로그인한 뒤 계정과 도메인을 선택합니다.
2. **Traffic** > **Health Checks**로 이동합니다.
3. 상태 확인 항목으로 이동해 **Edit**를 선택합니다.
4. Health Check를 수정합니다.
5. **Save**를 선택합니다.

:::note

구성된 Health Checks는 활성화, 비활성화 또는 삭제할 수도 있습니다.

:::

:::note

Authenticated origin pull은 Standalone Health Checks에서 지원되지 않습니다.

:::

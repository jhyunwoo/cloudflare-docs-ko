Health Check가 오리진 서버 상태 변경을 감지했을 때 알림을 받을 수 있도록 [알림 이메일](/health-checks/how-to/health-checks-notifications/#configure-notifications)을 구성할 수 있습니다. Cloudflare는 고객에게 영향이 가기 전에 필요한 조치를 취할 수 있도록 몇 초 안에 이메일을 보내줍니다.

이 이메일에는 상태 변화의 원인을 파악하는 데 필요한 정보가 포함됩니다. 변화가 발생한 시점, 오리진 서버 상태, 왜 비정상인지 여부와 이유, 예상 응답 코드, 실제 수신한 응답 코드를 확인할 수 있습니다.

## 알림 구성

1. Cloudflare 대시보드에서 **Health Checks** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/traffic/health-checks" />

2. **Configure an alert**를 선택합니다.
3. **Notification name**과 **Description**을 입력합니다.
4. 알림 이메일을 추가합니다.
5. **Next**를 선택합니다.
6. 경고에 포함할 health checks를 추가합니다.
7. 경고를 받을 시점을 결정하는 **Notification trigger**를 선택합니다.
8. **Create**를 선택합니다.

:::note


알림은 선택된 전체 지역의 과반수에서 상태 변화가 발생한 뒤에만 전송됩니다.

단일 지역의 경우 3개 데이터 센터 중 2개가 기준입니다. 13개 지역을 선택한 경우 13개 지역 중 7개가 기준입니다.


:::

[일반 오류 코드](/health-checks/health-checks-analytics/#common-error-codes)를 참고하면 Health Check 변경 원인에 대한 자세한 정보를 확인할 수 있습니다.

Cloudflare는 서버 상태 변화를 시간에 따라 더 잘 이해할 수 있도록 [Health Checks Analytics](/health-checks/health-checks-analytics/#common-error-codes)를 확인할 것을 권장합니다.

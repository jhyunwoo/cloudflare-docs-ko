Vectorize 청구서는 다음을 기준으로 합니다:

- **Queried 벡터 차원**: queried 벡터 차원의 총 수. 인덱스의 384-dimensions를 가진 10,000의 벡터를 가지고 있고, 그 인덱스에 대하여 100개의 쿼리를 만들고, 당신의 총 queried 벡터 차원은 3.878백만에 합계할 것입니다 (`(10000 + 100) * 384`).
- **저장된 벡터 차원**: 저장된 벡터 차원의 총 수. 인덱스의 1536-dimensions를 가진 1,000개의 벡터가 있는 경우에, 당신의 저장된 벡터 차원은 1.536 백만에 합계할 것입니다 (`1000 * 1536`).

CPU, 메모리, "활성 인덱스 시간", 또는 생성 된 인덱스 수에 대해 청구되지 않습니다. 인덱스에 대한 쿼리를 발급하지 않는 경우, queried 벡터 크기를 청구하지 않습니다.

### 사용 예제

다음 표는 Vectorize 인덱스 쿼리에 대한 예를 들어 사용 사례와 추정 월간 비용을 정의합니다. 이 견적은 VectorizeXQ의 일부인 Workers 무료 및 유료 플랜을 포함하지 않습니다.

| ----- | ------- | ----------- | --------- | ------------------------------------------------------------------------- | ------------------------- |
| 회사 소개 | 384     | 5,000 벡터    | 10,000    | `((10000+5000)*384*(0.01/1000000))      + (5000*384*(0.05/100000000))`    | $0.06 / 모<sup>(주)</sup>   |
| 관련 상품 | 768     | 25,000 벡터   | 50,000    | `((50000+25000)*768*(0.01/1000000))     + (25000*768*(0.05/100000000))`   | $0.59 / 월<sup>인기 있는</sup> |
| 제품정보  | 768     | 50,000 벡터   | 200,000   | `((200000+50000)*768*(0.01/1000000))    + (50000*768*(0.05/100000000))`   | $1.94 / 월                 |
| 큰 가슴  | 768     | 250,000 벡터  | 500,000   | `((500000+250000)*768*(0.01/1000000))   + (250000*768*(0.05/100000000))`  | $5.86 / 모                 |
| 사이트맵  | 1536    | 500,000의 벡터 | 1,000,000 | `((1000000+500000)*1536*(0.01/1000000)) + (500000*1536*(0.05/100000000))` | $23.42 / 월                |

## 자주 묻는 질문

자주 묻는 질문 Vectorize 가격:

- Vectorize는 항상 자유로운 층이 있습니까?

네,[Workers 무료 계층](/workers/platform/pricing/#workers)항상 무료 Vectorize로 프로토 타입 및 실험 능력을 포함합니다.

- 매달 포함 된 읽기, 쓰기 및 / 또는 저장을 초과하면 어떻게됩니까?

추가 읽기, 쓰기 및 저장에 따라 청구됩니다.[Vectorize의 가격](#billing-metrics).

- Vectorize는 데이터 전송 / egress를 담당합니까?

이름 \*

- HTTP API 또는 Wrangler 명령줄 수를 청구 가능한 사용으로 쿼리합니까?

예: Workers API, HTTP API 및 CLI와 같은 인덱스에 대해 문제가 발생하면 사용량으로 계산됩니다.

- 빈 인덱스, 벡터 없음, 스토리지에 기여?

이름 \* 빈 색인은 저장된 벡터 차원으로 조사하지 않습니다.

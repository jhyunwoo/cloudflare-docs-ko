다음 제한은 계정, 인덱스 및 벡터에 적용됩니다.

:::노트\[더 높은 한계를 못했다?]
한계에 조정을 요청하려면, 완료[제한 증가 요청 양식](https://forms.gle/nyamy2SM9zwWTXKE6). 한계가 증가될 수 있는 경우에, Cloudflare는 다음 단계로 당신에게 연락할 것입니다.
주요 특징

| 제품 정보                         | 현재 제한                            |
| ----------------------------- | -------------------------------- |
| 계정 당 인덱스                      | 50,000 (Workers 유료) / 100 (무료)   |
| 벡터 당 최대 차원                    | 1536 차원, 32 조금 정밀도               |
| 벡터 차원 당 정밀도                   | 32 비트 (float32)                  |
| 최대 벡터 ID 길이                   | 64 바이트                           |
| 벡터 당 Metadata                 | 10키비                             |
| 최대 반환 결과 (`topK`) 값 또는 메타데이터  | 20                               |
| 최대 반환 결과 (`topK`) 값과 메타데이터 없이 | 100                              |
| 최대 upsert 배치 크기 (배치 당)        | 1000 (Workers) / 5000 (HTTP API) |
| list-vectors 페이지의 최대 벡터       | 1000                             |
| 최대 색인 이름 길이                   | 64 바이트                           |
| 색인 당 최대 벡터                    | 10,000,000                       |
| 색인 당 최대 namespaces            | 50,000 (Workers 유료) / 1000 (무료)  |
| 최대 namespace 이름 길이            | 64 바이트                           |
| 최대 벡터 업로드 크기                  | 100개 MB                          |
| Vectorize 색인 당 최대 메타데이터 색인    | 10                               |
| 벡터 당 metadata 색인 당 최대 색인된 자료  | 64 바이트                           |

<Description>
  Vectorize, CloudflareXQ의 강력한 벡터 데이터베이스를 사용하여 전체 스택 AI 응용 프로그램을 구축하십시오.
</Description>

Vectorize는 전단, AI-powered 응용 프로그램을 구축 할 수있는 글로벌 분산 벡터 데이터베이스입니다[CloudflareWorkers](/workers/). Vectorize는 텍스트, 이미지, 기계 학습 모델 및 semantic 검색 알고리즘에 의해 소모되는 오디오와 같은 가치 또는 개체의 표현을 쿼리 할 수 있습니다 - 빠르고, 쉽고 저렴한.

<Render file="vectorize-ga" product="vectorize" />

예를 들어, 내장을 포함한 기계 학습 모델에 의해 생성 된 embeddings (vectors)를 저장하여[Workers AI](/workers-ai/)또는 같은 플랫폼에서 가져 오기[오시는 길](#), 당신은 당신의 자신의 자료에 근거를 둔 강력한 검색, 유사성, 권고, 분류 및/또는 anomaly 탐지 기능을 가진 신청을 건설할 수 있습니다.

반환된 벡터는 Cloudflare QXQXQXQXR2, KV에 있는 문서, 및/또는 D1XQ에 저장된 사용자 단면도에 저장된 KVXQXQ 플랫폼에서 벡터 검색 결과에서 구체적인 목표에 가는 가능하게 하고, 추가 인프라를 서 있는 없이.

</Feature>

<Feature header="Vectorize 및 AI 검색" href="/ai-search/" cta="Build a RAG with Vectorize">

</Feature>

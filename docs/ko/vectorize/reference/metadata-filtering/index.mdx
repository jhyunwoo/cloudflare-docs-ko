입력 벡터를 쿼리에 제공 할뿐만 아니라, 당신은 또한 필터링 할 수 있습니다[벡터 메타데이터](/vectorize/best-practices/insert-vectors/#metadata)모든 벡터와 관련. Query 결과는 해당 벡터만 포함됩니다.`filter`표준, 의미`filter`첫번째 적용되고,`topK`결과 필터링 세트에서 가져온다.

메타데이터 필터링을 사용하여 쿼리의 범위를 제한하여 특정 고객 ID, tenant, 제품 카테고리 또는 다른 메타데이터로 필터링할 수 있습니다.

## Metadata 색인

Vectorize 지원[이름공간](/vectorize/best-practices/insert-vectors/#namespaces)기본적으로 필터링하지만, 벡터의 다른 메타 데이터 속성에 필터링하려면 메타 데이터 인덱스를 만들 필요가 있습니다. Vectorize 인덱스당 최대 10개의 메타데이터 인덱스를 생성할 수 있습니다.

유형의 속성에 대한 Metadata 색인`string`, `number`·`boolean`지원됩니다. 자주 묻는 질문[metadata 색인 생성](/vectorize/get-started/intro/#4-optional-create-metadata-indexes)상세 정보

벡터당 메타데이터의 10KiB까지 저장할 수 있습니다. 이름 \*[모델 번호: Vectorize 제한 사항](/vectorize/platform/limits/)제한의 전체 목록입니다.

type의 메타데이터 인덱스`number`, 색인 번호 정밀도는 float64의 그것입니다.

type의 메타데이터 인덱스`string`, 각 벡터는 UTF-8 특성에 truncated 문자열 데이터의 첫 번째 64B를 인덱스는 그 제한 내에서 가장 잘 형성된 UTF-8 substring에 경계, 그래서 벡터는 각 색인 속성에 대한 값의 첫 64B에 필터링 할 수 있습니다.

:::노트\[Enable metadata filtering]

메타데이터 인덱스가 생성되기 전에 벡터는 그 인덱스에 포함 된 메타데이터가 없습니다. 생성된 후에 Upserting/re-upserting 벡터는 예상대로 그(것)들을 색인했습니다. 자주 묻는 질문[metadata 색인 생성](/vectorize/get-started/intro/#4-optional-create-metadata-indexes)상세 정보

:::

## 지원된 가동

선택 사항`filter`이름 \*`query()`metadata 필터를 지정하는 방법:

| 회사연혁   | 이름 \*          |
| ------ | -------------- |
| `$eq`  | 이름 \*          |
| `$ne`  | 아니다.           |
| `$in`  | 내 계정           |
| `$nin` | 이름 \*          |
| `$lt`  | 더 적은 보다는       |
| `$lte` | 더 적은 또는 동등한 것  |
| `$gt`  | 더 큰            |
| `$gte` | 더 중대한 또는 동등한 것 |

- `filter`컴팩트 JSON 표현이 2048 바이트 미만이어야하는 비 빈 객체가 있어야합니다.
- `filter`객체 키가 비어있을 수 없습니다, 포함`" | .`(집합은 예약), 시작`$`, 또는 512자 이상이어야 합니다.
- 제품 정보`$eq`·`$ne`, `filter`객체 비선형 값은`string`, `number`, `boolean`, 또는`null`가치.
- 제품 정보`$in`·`$nin`, `filter`object 값은 배열할 수 있습니다.`string`, `number`, `boolean`, 또는`null`가치.
- 상행 범위 쿼리 (i.e.`$lt`·`$lte`)는 낮행 범위 쿼리와 결합될 수 있습니다 (i.e.`$gt`·`$gte`) 동일한 여과기 안에. 다른 조합은 허용되지 않습니다.
- 범위 쿼리 (i.e.`$lt`, `$lte`, `$gt`, `$gte`), `filter`객체 비선형 값은`string`또는`number`가치. 문자열은 lexicographically 명령.
- 벡터 (\~10M 이상)의 큰 숫자를 포함하는 범위 쿼리는 감소된 정확도를 경험할지도 모릅니다.

### Namespace versus 메타데이터 필터링

모두 보기[이름공간](/vectorize/best-practices/insert-vectors/#namespaces)그리고 metadata 필터링은 쿼리에 대한 벡터 검색 공간을 축소합니다. 두 필터 유형을 평가할 때 다음을 고려하십시오:

- namespace 필터는 metadata filter(s) 이전에 적용됩니다.
- 벡터는 문서화 된 단일 네임스페이스의 일부일 수 있습니다.[제한 사항](/vectorize/platform/limits/). 벡터 metadata는 다수 열쇠 가치 쌍을 최대 포함할 수 있습니다[벡터 제한 당 메타데이터](/vectorize/platform/limits/). Metadata 값 지원 다른 유형 (`string`, `boolean`, 그리고 다른 사람), 그러므로 더 융통성을 제안하십시오.

### (주)`filter`이름 \*

#### 기타 제품`$eq`회사연혁

```json
{ "streaming_platform": "netflix" }
```

#### Explicit 연산자

```json
{ "someKey": { "$ne": "hbo" } }
```

#### `$in`회사연혁

```json
{ "someKey": { "$in": ["hbo", "netflix"] } }
```

#### `$nin`회사연혁

```json
{ "someKey": { "$nin": ["hbo", "netflix"] } }
```

#### 번호를 포함하는 범위 쿼리

```json
{ "timestamp": { "$gte": 1734242400, "$lt": 1734328800 } }
```

#### 문자열을 포함하는 범위 쿼리

범위 쿼리는 구현할 수 있습니다.**연락처**문자열 metadata 필드에. 이것은 또한 같습니다**시작하기**필터.

예를 들어, 다음과 같은 필터는 "net":

```json
{ "someKey": { "$gte": "net", "$lt": "neu" } }
```

#### Implicit 논리`AND`다수 열쇠로

```json
{ "pandas.nice": 42, "someKey": { "$ne": "someValue" } }
```

#### Keys는 배열을 정의`.`(도)

```json
{ "pandas.nice": 42 }

// looks for { "pandas": { "nice": 42 } }
```

```ts
let queryVector: Array<number> = [54.8, 5.5, 3.1, ...];
let metadataMatches = await env.YOUR_INDEX.query(queryVector, {
	topK: 3,
	filter: { streaming_platform: "netflix" },

	returnMetadata: 'all',
});
```

## 제한 사항

- 현재, 메타데이터 인덱스는 Vectorize 인덱스를 위해 생성되어야 합니다.*이전 다음*벡터는 metadata filtering를 지원하기 위하여 삽입될 수 있습니다.
- 2023-12-06 지원 메타 데이터 필터링 후 생성 된 인덱스 만. 이전에 생성 된 인덱스는 metadata 필터링을 지원할 수 없습니다.

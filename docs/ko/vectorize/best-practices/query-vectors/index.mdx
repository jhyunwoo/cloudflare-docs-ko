인덱스 또는 벡터 검색을 쿼리하면 입력 벡터를 제공하고 가장 가까운 벡터를 반환하여 인덱스를 검색할 수 있습니다.[형성된 거리 미터](/vectorize/best-practices/create-indexes/#distance-metrics).

선택적으로, 당신은 적용할 수 있습니다[metadata 필터](/vectorize/reference/metadata-filtering/)또는[이름공간](/vectorize/best-practices/insert-vectors/#namespaces)벡터 검색 공간을 축소하기 위해.

## 예제 쿼리

인덱스에 쿼리로 벡터를 전달하려면, 사용`query()`인덱스 자체의 방법.

쿼리 벡터는 JavaScript 번호, 32 비트 부동점 또는 64 비트 부동점 번호의 배열입니다:`number[]`, `Float32Array`, 또는`Float64Array`. 때와는 달리[벡터 삽입](/vectorize/best-practices/insert-vectors/), 쿼리 벡터는 ID 또는 메타 데이터가 필요하지 않습니다.

```ts
//질문 벡터 차원은 정복되는 Vectorize 색인 차원 일치해야 합니다
let queryVector = [54.8, 5.5, 3.1, ...];
let matches = await env.YOUR_INDEX.query(queryVector);
```

이것은 Vectorize 색인을 위해 형성된 거리 미터에 근거를 둔 뒤에 오는 일치의 세트를 돌려보낼 것입니다. 예제 응답과`cosine`거리 미터:

```json
{
	"count": 5,
	"matches": [
		{ "score": 0.999909486, "id": "5" },
		{ "score": 0.789848214, "id": "4" },
		{ "score": 0.720476967, "id": "4444" },
		{ "score": 0.463884663, "id": "6" },
		{ "score": 0.378282232, "id": "1" }
	]
}
```

결과가 metadata 및 값을 포함해야 할지 여부를 반환하고 / 또는 결과를 변경할 수 있습니다.

```ts
//질문 벡터 차원은 정복되는 Vectorize 색인 차원 일치해야 합니다
let queryVector = [54.8, 5.5, 3.1, ...];
//topK 기본값은 5; returnValues 기본값은 false; returnMetadata 기본값은 "none"
let matches = await env.YOUR_INDEX.query(queryVector, {
	topK: 1,
	returnValues: true,
	returnMetadata: "all",
});
```

이것은 Vectorize 색인을 위해 형성된 거리 미터에 근거를 둔 뒤에 오는 일치의 세트를 돌려보낼 것입니다. 예제 응답과`cosine`거리 미터:

```json
{
	"count": 1,
	"matches": [
		{
			"score": 0.999909486,
			"id": "5",
			"values": [58.79999923706055, 6.699999809265137, 3.4000000953674316, ...],
			"metadata": { "url": "/products/sku/55519183" }
		}
	]
}
```

더 알아보기[모델 번호: Vectorize](/vectorize/reference/client-api/)추가 예제.

## 벡터 식별자에 의한 쿼리

Vectorize는 지금 색인에서 이미 존재하는 벡터와 유사한 벡터를 검색하는 기능을 제안합니다`queryById()`가동. 이것은 결합하는 단 하나 가동으로 고려될 수 있습니다`getById()`그리고`query()`가동.

```ts
//id `some-vector-id`를 가진 벡터가 색인에서 이미 존재하는 경우에 조회 가동은 결과를 산출할 것입니다.
let matches = await env.YOUR_INDEX.queryById("some-vector-id");
```

## 정밀도 및 쿼리 정확도를 득점하는 제어

벡터를 조회할 때, 당신은 높은 정밀도 득점을 사용하는 것을 지정할 수 있습니다, 쿼리 일치 점수의 정밀도를 증가시키고 뿐 아니라 쿼리 결과의 정확도, 또는 빠른 응답 시간 동안 대략적인 득점을 사용하십시오.
대략적인 득점을 사용하여, 반환 점수는 당신의 질문과 반환된 벡터 사이 진짜 거리/similarity의 대략적일 것입니다; 이것은 정확도와 대기권 사이 좋은 무역 떨어져이기 때문에 쿼리의 과태입니다.

높은 정밀도 득점은 조정에 의해 활성화됩니다`returnValues: true`자주 묻는 질문 이 설정은 Vectorize가 일치를 위해 원래의 벡터 값을 사용하며 정확한 일치 점수의 계산을 허용하고 결과의 정확도를 증가시킵니다. 더 많은 데이터를 처리하기 때문에 높 정밀도 득점은 쿼리의 지연을 증가합니다.

## Workers AI

당신은에서 embeddings를 생성하는 경우[모델 번호: Workers AI](/workers-ai/models/#text-embeddings)텍스트 embedding 모델, 응답 유형에서`env.AI.run()`모두 포함 된 객체입니다.`shape`응답 벡터의 - e.g.`[1,768]`- 벡터`data`벡터의 배열로:

```ts
interface EmbeddingResponse {
	shape: number[];
	data: number[][];
}

let userQuery = "a query from a user or service";
const queryVector: EmbeddingResponse = await env.AI.run(
	"@cf/baai/bge-base-en-v1.5",
	{
		text: [userQuery],
	},
);
```

벡터를 전달할 때`query()`Vectorize 색인의 방법, 자체를 삽입하는 벡터 만 통과`.data`sub-object 및 최고 수준의 응답이 아닙니다.

예를 들면:

```ts
let matches = await env.TEXT_EMBEDDINGS.query(queryVector.data[0], { topK: 1 });
```

패스워드`queryVector`또는`queryVector.data`관련 상품`query()`오류를 반환합니다.

## 오시는 길

OpenAI를 사용할 때[JavaScript 클라이언트 API](https://github.com/openai/openai-node)·[API 구현](https://platform.openai.com/docs/guides/embeddings/what-are-embeddings), 응답 유형에서`embeddings.create`모델, 사용 정보 및 요청된 벡터 embedding을 포함하는 객체입니다.

```ts
const openai = new OpenAI({ apiKey: env.YOUR_OPENAPI_KEY });

let userQuery = "a query from a user or service";

let embeddingResponse = await openai.embeddings.create({
	input: userQuery,
	model: "text-embedding-ada-002",
});
```

Workers AI와 유사한, 당신은 자체를 embedding 벡터를 제공해야합니다 (`.embedding[0]`) 그리고 아니`EmbeddingResponse`Vectorize 색인을 쿼리 할 때 래퍼 :

```ts
let matches = await env.TEXT_EMBEDDINGS.query(embeddingResponse.embedding[0], {
	topK: 1,
});
```

Vectorize는 Cloudflare의 벡터 데이타베이스입니다. 벡터 데이터베이스는 기계 학습 (ML) 모델을 사용하여 매혹적인 검색, 권고, 분류 및 분석 작업을 수행 할 수 있으며 LLMs (Large Language Models)에 대한 컨텍스트를 제공합니다.

이 가이드는 당신을 통해 지시합니다:

- 첫 번째 Vectorize 인덱스 만들기.
- 연결하기[Cloudflare 작업자](/workers/)당신의 색인에.
- 인덱스를 쿼리하여 유사성 검색을 삽입하고 수행하십시오.

## 자주 묻는 질문

:::노트\[Workers 무료 또는 유료 플랜 필수]

Vectorize는 모든 사용자에게 유효합니다[Workers 무료 또는 유료 계획](/workers/platform/pricing/#workers).

:::

계속하려면:

1. 로그인[Cloudflare 계정](https://dash.cloudflare.com/sign-up/workers-and-pages)이미 없다면.
2. 설치하기[`npm`](https://docs.npmjs.com/getting-started).
3. 설치하기[`Node.js`](https://nodejs.org/en/). Node version Manager를 사용하여[볼트](https://volta.sh/)또는[사이트맵](https://github.com/nvm-sh/nvm)허가 문제를 방지하고 Node.js 버전을 변경하십시오.[Wrangler](/workers/wrangler/install-and-update/)Node 버전이 필요합니다.`16.17.0`또는 나중에.

## 2. 인덱스 생성

벡터 데이터베이스는 전통적인 SQL 또는 NoSQL 데이터베이스와 구별됩니다. 벡터 데이터베이스는 벡터 embeddings를 저장하도록 설계되었지만 원본 데이터 자체가 아닙니다.

첫 번째 Vectorize 인덱스를 만들려면 Workers 프로젝트에서 만든 디렉토리로 변경하십시오.

```sh
cd vectorize-tutorial
```

<Render file="vectorize-legacy" product="vectorize" />

인덱스를 만들려면, 당신은 사용해야합니다`wrangler vectorize create`명령과 인덱스의 이름을 제공합니다. 좋은 색인 이름은:

- 더 낮은 케이스 및 / 또는 숫자 ASCII 문자의 조합, 32 문자보다 짧은, 문자로 시작, 대신 공백 대신 dashes (-)를 사용.
- 사용 사례 및 환경의 설명. 예를 들어, "production-doc-search" 또는 "dev-recommendation-engine".
- 인덱스를 설명하는 데만 사용되며 코드에서 직접 referenced가 아닙니다.

또한 둘 다 정의해야 할 것`dimensions`벡터의 당신은 인덱스뿐만 아니라 거리에 저장됩니다`metric`인덱스를 만들 때 유사한 벡터를 결정하는 데 사용됩니다. ·`metric`euclidean, cosine, 또는 dot 제품 일 수 있습니다.**이 구성은 나중에 변경할 수 없습니다.**, 벡터 데이터베이스로 설정된 벡터 구성을 구성합니다.

다음을 실행`wrangler vectorize`명령:

```sh
npx wrangler vectorize create tutorial-index --dimensions=32 --metric=euclidean
```

```sh output

📋 To start querying from a Worker, add the following binding configuration into 'wrangler.toml':

[[vectorize]]

```

위의 명령은 새로운 벡터 데이터베이스를 만들고 출력합니다.[관련 제품](/workers/runtime-apis/bindings/)다음 단계에서 필요한 구성.

## 3. 당신의 색인에 당신의 노동자를 바짝 죄십시오

Vectorize 색인에 연결하기 위하여 노동자를 위한 바인딩을 창조해야 합니다.[회사 소개](/workers/runtime-apis/bindings/)QXQX0033XQXVectorize 또는 R2XQ, CloudflareQ QXWorkersQXQ와 같은 접근 자원에 당신의 WorkersXQXQXQXQ를 허용하십시오. 노동자의 Wrangler 파일을 업데이트하여 바인딩을 만듭니다.

작업자에게 인덱스를 바인딩하려면 Wrangler 파일의 끝에 다음을 추가하십시오.

<WranglerConfig>
  ```jsonc
  {
  	"vectorize": [
  		{
  			"binding": "VECTORIZE", //env.VECTORIZE에 있는 당신의 노동자에서 유효한
  			"index_name": "tutorial-index"
  		}
  	]
  }
  ```
</WranglerConfig>

특정한:

- value (string) 설정`<BINDING_NAME>`reference이 작업자의 데이터베이스에 사용됩니다. 이 튜토리얼에서 바인딩 이름을`VECTORIZE`.
- 바인딩은 있어야 합니다[유효한 JavaScript 가변 이름](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Grammar_and_types#variables). 예를 들면,`binding = "MY_INDEX"`또는`binding = "PROD_SEARCH_INDEX"`둘 다 바인딩을 위한 유효한 이름일 것입니다.
- 당신의 의무는 당신의 노동자에서 유효합니다`env.<BINDING_NAME>`Vectorize[클라이언트 API](/vectorize/reference/client-api/)Workers 신청 내의 사용을 위한 이 의무에 드러납니다.

## 4. \[선택] 메타데이터 인덱스 생성

Vectorize를 사용하면 벡터 당 10KiB의 메타데이터를 인덱스로 추가할 수 있으며, 벡터를 쿼리하면서 메타데이터를 필터링할 수 있습니다. 이렇게하려면 Vectorize 인덱스의 "metadata index"로 메타데이터 필드를 지정해야 합니다.

:::note\[ 메타데이터 인덱스를 만들 때?]

현재 벡터가 삽입되기 전에 지정되어야 하는 벡터가 필터링될 수 있는 메타데이터 필드는 이 메타데이터 필드가 Vectorize 인덱스의 생성 후 바로 지정된다는 것을 권장합니다.

:::

쿼리 중 메타데이터 필드에 벡터 필터링을 활성화하려면 다음과 같은 명령을 사용하십시오.

```sh
npx wrangler vectorize create-metadata-index tutorial-index --property-name=url --type=string
```

```sh output
📋 Creating metadata index...
✅ Successfully enqueued metadata index creation request. Mutation changeset identifier: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.
```

이름 \*`url`필터링 할 메타데이터 필드입니다. 더 보기`--type`매개변수는 메타데이터 필드의 데이터 유형을 정의한다;`string`, `number`·`boolean`유형은 지원됩니다.

그것은 일반적으로 메타 데이터 인덱스를 위해 몇 초 걸립니다. 실행하여 Vectorize 인덱스의 메타데이터 인덱스 목록을 확인할 수 있습니다.

```sh
npx wrangler vectorize list-metadata-index tutorial-index
```

```sh output
📋 Fetching metadata indexes...
┌──────────────┬────────┐
│ propertyName │ type   │
├──────────────┼────────┤
│ url          │ String │
└──────────────┴────────┘
```

Vectorize 인덱스당 최대 10개의 메타데이터 인덱스를 생성할 수 있습니다.

type의 메타데이터 인덱스`number`, 색인 번호 정밀도는 float64의 그것입니다.

type의 메타데이터 인덱스`string`, 각 벡터는 UTF-8 특성에 truncated 문자열 데이터의 첫 번째 64B를 인덱스는 그 제한 내에서 가장 잘 형성된 UTF-8 substring에 경계, 그래서 벡터는 각 색인 속성에 대한 값의 첫 64B에 필터링 할 수 있습니다.

이름 \*[Vectorize 제한 사항](/vectorize/platform/limits/)제한의 전체 목록입니다.

## 7. 노동자를 배포

전 세계 노동자를 배포하기 전에 Cloudflare 계정으로 로그인하십시오.

```sh
npx wrangler login
```

QXQX0054XQ QXdashboard에 로그인하려면 웹 페이지로 이동합니다. 로그인 한 후 Wrangler가 Cloudflare 계정에 변경할 수 있는 경우 요청됩니다. 스크롤 다운 및 선택**지원하다**계속.

여기에서, 당신은 인터넷에 액세스 할 수있는 프로젝트를 만들 수 있습니다. 노동자를 배포하려면, 실행:

```sh
npx wrangler deploy
```

배포되면, 작업자 미리보기`https://vectorize-tutorial.<YOUR_SUBDOMAIN>.workers.dev`.

## 8. Query 당신의 색인

벡터를 삽입하고 쿼리하려면 배포 된 노동자의 URL을 사용하십시오.`https://vectorize-tutorial.<YOUR_SUBDOMAIN>.workers.dev/`. 브라우저를 열고:

1. 먼저 벡터를 삽입하여`/insert`. JSON 아래를 반환해야 합니다.

```json
// https://vectorize-tutorial.<YOUR_SUBDOMAIN>.workers.dev/insert
{
	"mutationId": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
}
```

mutationId는 이 비동기 인서트 작업에 대응하는 고유 식별자를 나타냅니다. 일반적으로 쿼리에 사용할 수있는 삽입 된 벡터에 대한 몇 초가 걸립니다.

마지막 처리 된 돌연변이를 확인하기 위해 인덱스 정보 작업을 사용할 수 있습니다.


자주 묻는 질문`search`방법은 단순하지만 빠른 검색 엔진을 구현할 수 있습니다. 이 예제는[Workers 회사 소개](/ai-search/usage/workers-binding/), 그러나 사용하기 위하여 쉽게 적응될 수 있습니다[REST API를](/ai-search/usage/rest-api/)대신.

이 예제를 복제하려면 :

- 사용 방법`rewrite_query`, 원본 사용자 쿼리 일치 하려면
- 작은 펑크 크기를 가지고 AI 검색 구성, 보통 256 토큰 충분

<TypeScriptExample>
  ```ts
  export interface Env {
  	AI: Ai;
  }

  export default {
  	async fetch(request, env): Promise<Response> {
  		const url = new URL(request.url);
  		const userQuery =
  			url.searchParams.get("query") ??
  			"How do I train a llama to deliver coffee?";
  		const searchResult = await env.AI.autorag("my-rag").search({
  			query: userQuery,
  			rewrite_query: false,
  		});

  		return Response.json({
  			files: searchResult.data.map((obj) => obj.filename),
  		});
  	},
  } satisfies ExportedHandler<Env>;
  ```
</TypeScriptExample>

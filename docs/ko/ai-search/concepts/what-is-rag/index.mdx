Retrieval-Augmented Generation (RAG)는 큰 언어 모델 (LLM)으로 자신의 데이터를 사용하는 방법입니다. 모델이 훈련된 것에만 의존하는 대신, RAG는 데이터 소스에서 관련 정보를 검색하고 질문에 답하는 데 도움을줍니다.

## RAG는 어떻게 작동합니까?

RAG 파이프라인의 단순 개요:

1. **색인:**&#xADC0;하의 콘텐츠 (예: docs, wikis, 제품 정보)는 작은 펑크로 나눌 수 있으며 embedding 모델을 사용하여 벡터로 변환됩니다. 이 벡터는 벡터 데이터베이스에 저장됩니다.
2. **공급 능력:**&#xC0AC;용자가 질문을 할 때, 그것은 벡터에 내장되어 벡터 데이터베이스에서 가장 관련된 펑크를 찾을 수 있습니다.
3. **생성:**&#x52;etrieved 콘텐츠 및 사용자의 원래 질문은 단일 프롬프트로 결합됩니다. LLM은 신속한 응답을 생성합니다.

결과 응답은 정확하고 관련적이며, 자신의 데이터를 기반으로해야합니다.

:::note\[AI 검색은 어떻게 작동하나요?]
AI 검색이 후드 아래에 RAG를 사용하는 방법에 대한 자세한 내용을 보려면 참고 자료[AI 검색 작업](/ai-search/concepts/how-ai-search-works/).
:::

## 왜 RAG를 사용합니까?

RAG는 LLM 세대로 자신의 데이터를 재연하거나 모델의 미세 조정없이 가져갈 수 있습니다. 쿼리 시간에 관련된 콘텐츠를 검색하여 정확성과 신뢰를 모두 개선하고 응답을 기반으로합니다.

RAG 사용의 이점:

- **정확하고 현재 답변 :**&#xC751;답은 최신 내용에 근거하여, outdated 훈련 자료.
- **정보 소스에 대한 제어 :**&#xB2F9;신은 지식베이스를 정의 그래서 답변은 당신이 신뢰하는 내용에서 온다.
- **Fewer 강당:**&#xC751;답은 실제, 검색 된 데이터, 생성 된 또는 misleading 답변 감소.
- **요구되는 모형 훈련 없음:**&#xC2DC;간과 비용을 절약 할 수있는 자신의 LLM을 구축하거나 미세 조정하지 않고 고품질의 결과를 얻을 수 있습니다.

RAG는 AI-powered 앱 구축에 이상적입니다.

- 내부 지식을위한 AI 보조
- 최신 컨텐츠에 연결된 Chatbots 지원
- 문서 및 파일 전역의 엔터프라이즈 검색

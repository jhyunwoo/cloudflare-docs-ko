이 가이드는 AI Search REST API를 사용하여 AI Search에 대한 쿼리를 만들 수 있습니다.

:::note\[AI 검색은 AutoRAG의 새로운 이름]
API 엔드포인트는 여전히 참고 자료`autorag`시간 동안. Functionality는 동일하, 새로운 naming을 위한 지원은 점차적으로 소개될 것입니다.
주요 특징

## Prerequisite: AI 검색 API 토큰 받기

API 토큰이 필요합니다.`AI Search - Read`·`AI Search - Edit`REST API를 사용하는 권한. 새로운 토큰 만들기:

1. Cloudflare 대시보드에서, 가십시오**AI 검색**사이트 맵

<DashButton url="/?to=/:account/ai/ai-search" />

2. AI 검색을 선택하십시오.
3. 제품정보**AI 검색**다음 선택**사이트맵**.
4. 제품정보**API 토큰 만들기**.
5. 사전 작성된 정보를 검토한 후 선택**API 만들기 토큰 토큰**.
6. 제품정보**복사 API 토큰 토큰**미래에 대한 그 가치를 저장합니다.

## AI 검색

이 REST API는 데이터 소스에서 관련 결과를 검색하고 모델과 관련 상황에 대한 응답을 생성합니다.

```bash

curl https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/autorag/rags/{AUTORAG_NAME}/ai-search \
-H 'Content-Type: application/json' \
-H "Authorization: Bearer {API_TOKEN}" \
-d '{
	"query": "How do I train a llama to deliver coffee?",
	"model": @cf/meta/llama-3.3-70b-instruct-fp8-fast,
	"rewrite_query": false,
	"max_num_results": 10,
	"ranking_options": {
		"score_threshold": 0.3,
	},
	"reranking": {
		"enabled": true,
    	"model": "@cf/baai/bge-reranker-base"
	},
	"stream": true,
}'

```

:::참조

당신을 얻을 수 있습니다`ACCOUNT_ID`으로 navigating 에[Workers & PagesXQ에 Workers](/fundamentals/account/find-account-and-zone-ids/#find-account-id-workers-and-pages).

:::

## 이름 \*

이 REST API는 데이터 소스에서 결과를 검색하고 관련 결과를 반환합니다.

```bash

curl https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/autorag/rags/{AUTORAG_NAME}/search \
-H 'Content-Type: application/json' \
-H "Authorization: Bearer {API_TOKEN}" \
-d '{
	"query": "How do I train a llama to deliver coffee?",
	"rewrite_query": true,
	"max_num_results": 10,
	"ranking_options": {
		"score_threshold": 0.3,
	},
	"reranking": {
		"enabled": true,
    	"model": "@cf/baai/bge-reranker-base"
	}'

```

:::참조

당신을 얻을 수 있습니다`ACCOUNT_ID`Workers & PagesXQXQXQ를 대시보드에 항해하여 계정 세부 사항에 따라 계정 ID를 복사합니다.

:::

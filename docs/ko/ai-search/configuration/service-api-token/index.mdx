서비스 API 토큰은 AI 검색 권한을 부여하여 Cloudflare 계정에 리소스를 액세스하고 구성합니다. 이 토큰은 AI Search 인스턴스와 상호 작용하는 API 토큰과 다릅니다.

:::\[베타]
서비스 API 토큰은 AI 검색 베타에서 필요합니다. 이 필요조건은 미래 방출에서 변화할지도 모릅니다.
주요 특징

## 서비스 API 토큰이란?

AI Search 인스턴스를 만들 때 대신 다른 Cloudflare 서비스와 상호 작용해야 합니다.[R2](/r2/), [Vectorize](/vectorize/)·[Workers AI](/workers-ai/). 서비스 API 토큰은 AI Search를 사용하여 이러한 작업을 수행 할 수 있습니다. AI Search는 데이터를 색인하거나 쿼리에 응답 할 수 없습니다.

이 토큰은 AI Search Index Engine 권한을 요구합니다 (`9e9b428a0bcd46fd80e580b46a69963c`AI Search Index Engine을 실행하는 액세스 권한을 부여하는 ).

## 서비스 API 토큰 vs. AI 검색 API 토큰

AI Search는 다른 목적을 위한 API 토큰의 2가지 유형을 사용합니다:

| 토큰 유형        | 제품정보                                  | 누가 그것을 사용  | 만들 때                     |
| ------------ | ------------------------------------- | ---------- | ------------------------ |
| 서비스 API 토큰   | R2, Vectorize, 브라우저 렌더링 및 Workers AI  | AI 검색 (내부) | 계정 당 한 번, 첫 번째 인스턴스 생성 중 |
| AI 검색 API 토큰 | 쿼리 또는 AI Search 인스턴스를 관리 할 수있는 요청을 인증 | 당신 (외부)    | AI 검색 REST API 호출시       |

더 보기**서비스 API 토큰**AI Search에 의해 내부적으로 사용되어 컨텐츠를 색인하고 응답을 생성하고 같은 배경 작업을 수행 할 수 있습니다. 한 번 만들고 AI Search는 자동으로 사용합니다.

더 보기**AI 검색 API 토큰**표준[Cloudflare API 토큰](/fundamentals/api/get-started/create-token/)AI Search 권한으로 만들 수 있습니다. 이 토큰을 사용하여 인스턴스 생성, 구성 업데이트 또는 AI 검색 쿼리와 같은 REST API 요청을 인증합니다.

## 어떻게 작동합니까?

AI Search 인스턴스를 만들 때[대시보드](/ai-search/get-started/dashboard/), 서비스 API 토큰은 설정 흐름의 일부로 자동으로 생성됩니다.

인스턴스를 만들 때[사이트맵](/ai-search/get-started/api/), 인스턴스를 만들기 전에 서비스 API 토큰을 수동으로 등록해야 합니다.

일단 등록되면 서비스 API 토큰은 계정의 모든 AI 검색 인스턴스에서 안전하게 저장되고 재사용됩니다. 각 인스턴스의 새로운 토큰을 만들 필요가 없습니다.

## 토큰 수명주기

서비스 API 토큰은 AI Search 인스턴스를 가지고 있기 때문에 사용할 수 있습니다.

:::카트로션
서비스 API 토큰을 삭제하지 마십시오. 토큰을 수정하거나 삭제하면 AI Search 인스턴스는 해당 리소스에 액세스하고 기능을 중지합니다.
주요 특징

새로운 서비스 API 토큰이 필요한 경우 대시보드 또는 API를 통해 하나를 만들 수 있습니다.

### 대시보드

1. 기존 AI Search 인스턴스로 이동[Cloudflare 대시보드](https://dash.cloudflare.com/?to=/:account/ai/ai-search).
2. 제품정보**계정 설정**.
3. 이름 \***주요사업**, 찾기**서비스 API 토큰 토큰**편집 아이콘을 선택합니다.
4. 제품정보**새로운 토큰 만들기**.
5. 제품정보**제품 정보**.

### 사이트맵

단계 따라 1-4 에[API 가이드](/ai-search/get-started/api/)새로운 토큰을 생성하고 등록합니다.

## 등록된 토큰

계정에서 AI Search로 등록된 서비스 API 토큰을 볼 수 있습니다.[토큰 API](/api/resources/ai_search/subresources/tokens/methods/list/). 교체`<API_TOKEN>`AI Search 읽는 권한이 있는 API 토큰으로.

```bash
curl https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/ai-search/tokens \
  -H "Authorization: Bearer <API_TOKEN>"
```

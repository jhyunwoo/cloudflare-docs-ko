AI Search는 자동적으로 semantic 수색을 위해 낙관된 벡터 embedding로 당신의 자료를 색인합니다. 데이터 소스가 연결되면, 색인은 배경에서 지속적으로 지식베이스 신선하고 쿼리 할 수 있습니다.

## 채용 정보

AI Search는 모든 컨텐츠를 업데이트하고 재구성하는 데이터 소스를 자동으로 모니터링합니다.**6시간**. 각 주기 도중, 새로운 변경한 파일은 날짜까지 당신의 Vectorize 색인을 지키는 재처리됩니다.

작업 탭의 모든 색인 활동의 상태와 역사를 모니터링 할 수 있습니다, 각 작업에 대한 실시간 로그를 포함 하 여 문제 해결 및 성공적인 동기화를 확인.

## 제품정보

대시보드의 다음 작업을 통해 색인 작업을 제어 할 수 있습니다.

- **Sync 인덱스**: 수동으로 트리거 AI는 새, 수정, 삭제 된 파일에 대한 데이터 소스를 스캔하고 관련 Vectorize 인덱스를 업데이트 할 색인 작업을 시작. 새로운 색인 작업은 30 초마다 시작될 수 있습니다.
- **Sync 개인 파일**: 특정 파일에 대한 동기화를 트리거**제품정보**사이트 맵 오시는 길**공지사항**reindex를 원하는 특정 파일 옆에 동기화 아이콘을 선택합니다.
- **Pause 지수**: Temporarily는 모든 예정된 색인 검사 및 재처리를 중지합니다. 벌레잡기를 위해 유용한 또는 당신의 지식 기초를 얼기.

## - 연혁

인덱스의 총 시간은 데이터 소스의 파일 수와 유형에 따라 달라집니다. 성능에 영향을 미치는 요인은 다음과 같습니다.

- 총 파일 수 및 크기
- 파일 형식 (예를 들어, 이미지는 일반 텍스트보다 오래 걸립니다)
- Workers AI 모델의 지연 및 이미지 처리에 사용

## 좋은 관행

매끄러운 믿을 수 있는 색인을 지키기 위하여:

- 파일이 있는지 확인하십시오.[**크기 제한**](/ai-search/platform/limits-pricing/#limits)지원되는 형식에서 건너뛰는 것을 피하십시오.
- 서비스 API 토큰을 유지하십시오.
- 당신의 지식 기초에 있는 정기적으로 청소 또는 불필요한 내용은 타격을 피하기 위하여[Vectorize 인덱스 제한](/vectorize/platform/limits/).

Cloudflare QXR2를 사용하여 색인을 저장합니다. 시작하기에,[R2 물통을 구성하십시오](/r2/get-started/)데이터 포함

AI Search는 자동으로 그 버킷에 저장된 파일을 스캔하고 처리합니다. 지원되지 않은 파일 또는 크기 제한을 초과하는 파일은 색인 및 오류로 기록 된 동안 건너 뛸 것입니다.

## 경로 필터링

파일이 defining에 의해 색인을 얻고 객체 경로에 대한 규칙을 제외 할 수 있습니다. 특정 폴더에 인덱스를 제한하거나 검색할 수없는 파일을 제외하면됩니다.

예를 들어, 단지 문서 인덱스를 제외하고:

- **포함 :** `/docs/**`
- **제외 :** `/docs/drafts/**`

더 알아보기[경로 필터링](/ai-search/configuration/path-filtering/)패턴 문법, 필터링 행동, 그리고 더 많은 예제.

## 파일 제한

AI Search는 파일 크기 제한이 있습니다 \*\* 최대**4개 MB**.

이 제한을 초과하는 파일은 인덱스되지 않으며 오류 로그에서 표시됩니다.

## 파일 형식

AI Search는 RAG를 강화하기 위해 다양한 파일 형식을 섭취 할 수 있습니다. 다음 일반 텍스트 파일 및 풍부한 형식 파일이 지원됩니다.

### 일반 텍스트 파일 형식

AI Search는 다음과 같은 일반 텍스트 파일 유형을 지원합니다:

| 지원하다          | 파일 확장자                                                                         | Mime 유형                                                               |
| ------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| 이름 \*         | `.txt`, `.rst`                                                                 | `text/plain`                                                          |
| 로그인           | `.log`                                                                         | `text/plain`                                                          |
| 사이트맵          | `.ini`, `.conf`, `.env`, `.properties`, `.gitignore`, `.editorconfig`, `.toml` | `text/plain`, `text/toml`                                             |
| 옵션 정보         | `.markdown`, `.md`, `.mdx`                                                     | `text/markdown`                                                       |
| 사이트맵          | `.tex`, `.latex`                                                               | `application/x-tex`, `application/x-latex`                            |
| 스크립트          | `.sh`, `.bat` , `.ps1`                                                         | `application/x-sh` , `application/x-msdos-batch`, `text/x-powershell` |
| 사이트맵          | `.sgml`                                                                        | `text/sgml`                                                           |
| JSON 파일       | `.json`                                                                        | `application/json`                                                    |
| 모델 번호:        | `.yaml`, `.yml`                                                                | `application/x-yaml`                                                  |
| 사이트맵          | `.css`                                                                         | `text/css`                                                            |

Reranking은 사용자의 쿼리에 대한 semantic relevance를 기반으로 재평가 된 문서를 재주문하여 AI 검색 결과의 품질을 향상시킬 수 있습니다. 그것은 출력되기 전에 "rerank"의 최고 결과에 retrieval 후에 이차 모형을 적용합니다.

## 어떻게 작동합니까?

기본적으로 reranking은**이름 \***&#xBAA8;든 AI Search 인스턴스를 위해. 설정 페이지에서 생성 또는 나중에 활성화 할 수 있습니다.

활성화 될 때, AI 검색은:

1. 당신의 색인에서 관련 결과를 만회합니다, 당신의 곁에 따라서 제약해`max_num_of_results`·`score_threshold`모수.
2. 결과 전달[reranking 모형](/ai-search/configuration/models/supported-models/).
3. reranked 결과를 반환, 텍스트 생성 모델은 응답 생성에 사용할 수 있습니다.

Reranking은 정확성을 향상 시키는 데 도움이, 특히 큰 또는 noisy datasets에 대한 벡터 유사성 만 최적의 주문을 생산하지 않을 수 있습니다.

## 제품 설명

몇 가지 방법으로 reranking을 구성할 수 있습니다:

### API를 통해 구성

당신이 할 때`/search`또는`/ai-search`자주 묻는 질문[Workers 바인딩](/ai-search/usage/workers-binding/)또는[REST API를](/ai-search/usage/rest-api/), 당신은 할 수 있습니다:

- 요청에 따라 실행할 수 있습니다.
- reranking 모델 지정

예를 들면:

```javascript
const answer = await env.AI.autorag("my-autorag").aiSearch({
  query: "How do I train a llama to deliver coffee?",
  model: "@cf/meta/llama-3.3-70b-instruct-fp8-fast",
  reranking: {
    enabled: true,
    model: "@cf/baai/bge-reranker-base"
  }
});
```

### 새로운 AI 검색 대시보드에서 구성

대시보드에서 새로운 RAG를 만들 때:

1. 오시는 길**AI 검색**Cloudflare 대시보드에서.

   <DashButton url="/?to=/:account/ai/ai-search" />

2. 제품정보**이름 \*** > **시작하기**.

3. 내 계정**Retrieval 구성**단계, 열다**회사 소개**드롭다운.

4. 제품정보**회사 소개**이름 \*

5. reranking 모델을 선택하십시오.

6. 설정 완료.

### 기존 AI 검색 대시보드에서 구성

기존 인스턴스에 reranking을 업데이트하려면:

1. 오시는 길**AI 검색**Cloudflare 대시보드에서.

   <DashButton url="/?to=/:account/ai/ai-search" />

2. 기존 AI 검색 인스턴스를 선택하십시오.

3. 오시는 길**계정 설정**탭.

4. 이름 \***회사 소개**, toggle는 위에 reranking.

5. reranking 모델을 선택하십시오.

### 관련 기사

reranking 추가는 쿼리 요청에 추가 단계를 포함, 결과적으로, 요청의 지연에 증가 될 수 있습니다.

AI Search 인스턴스가 데이터를 색인하고 검색하고 쿼리에 대한 응답을 생성하는 방법을 사용자 정의 할 수 있습니다. 일부 설정은 인스턴스가 생성 된 후 업데이트 될 수 있으며 다른 사람들이 생성 시간에 고정됩니다.

아래 표는 모두 사용할 수 있는 구성 옵션:

| 제품 설명                                                           | 작성 후 편집 가능 | 이름 \*                                                                                |
| --------------------------------------------------------------- | ---------- | ------------------------------------------------------------------------------------ |
| [데이터 소스](/ai-search/configuration/data-source/)                 | 없음         | 지식 베이스가 저장되는 소스                                                                      |
| [경로 필터링](/ai-search/configuration/path-filtering/)              | 이름 \*      | 인덱스에서 특정 경로 포함 또는 제외                                                                 |
| [Chunk 크기](/ai-search/configuration/chunking/)                  | 이름 \*      | chunk 당 토큰 수                                                                         |
| [프로젝트](/ai-search/configuration/chunking/)                      | 이름 \*      | chunks 사이에서 overlapping 토큰의 수                                                        |
| [Embedding 모형](/ai-search/configuration/models/)                | 없음         | 벡터 embeddings 생성에 사용된 모형                                                             |
| [Query 다시 쓰기](/ai-search/configuration/query-rewriting/)        | 이름 \*      | 검색 결과를 찾을 수 없음 한국어 사전에 rewriting                                                     |
| [Query 다시 작성 모델](/ai-search/configuration/models/)              | 이름 \*      | 쿼리 rewriting에 사용되는 모델                                                                |
| [Query 다시 작성 시스템 프롬프트](/ai-search/configuration/system-prompt/) | 이름 \*      | 사용자 정의 시스템 신속한 가이드 쿼리 rewriting 동작                                                   |
| [연락처](/ai-search/configuration/retrieval-configuration/)        | 이름 \*      | 벡터 일치에 필요한 최소 유사점                                                                    |
| [최대 결과 수](/ai-search/configuration/retrieval-configuration/)    | 이름 \*      | 벡터 일치의 최대 수 반환 (`top_k`)                                                             |
| [회사 소개](/ai-search/configuration/reranking/)                    | 이름 \*      | reorder retrieved result by semantic relevance by reranking model after 초기 retrieval |
| [세대 모델](/ai-search/configuration/models/)                       | 이름 \*      | 최종 응답을 생성하는 데 사용되는 모델                                                                |
| [세대 시스템 신속한](/ai-search/configuration/system-prompt/)           | 이름 \*      | 사용자 정의 시스템 신속한 응답 생성                                                                 |
| [유사성 캐싱](/ai-search/configuration/cache/)                       | 이름 \*      | 비슷한 응답의 Enable 또는 비활성화 캐싱 (정확하지 않음) 신속한                                              |
| [유사성 캐싱 문](/ai-search/configuration/cache/)                     | 이름 \*      | 새로운 프롬프트가 이전에 있어야한다는 것을 통제하십시오.                                                      |
| [AI 게이트웨이](/ai-gateway)                                         | 이름 \*      | 모니터링 및 제어 모델 사용을위한 AI Gateway                                                        |
| AI 검색 이름                                                        | 없음         | AI Search 인스턴스의 이름                                                                   |
| [서비스 API 토큰](/ai-search/configuration/service-api-token/)       | 이름 \*      | AI Search 권한을 부여하는 API 토큰은 계정에서 리소스를 구성하는                                            |

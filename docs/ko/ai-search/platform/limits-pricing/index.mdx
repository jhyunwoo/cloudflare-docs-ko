## 가격 책정

오픈 베타 중, AI Search는**무료 다운로드**. AI Search 인스턴스를 만들 때, Cloudflare 서비스의 상단에 규정하고 실행합니다. 이 자료는**Cloudflare 사용의 일부로 청구**, 다음을 포함:

| 서비스 & 가격                                        | 이름 \*                                                                                  |
| ----------------------------------------------- | -------------------------------------------------------------------------------------- |
| [**R2**](/r2/pricing/)                          | 소스 데이터를 저장                                                                             |
| [**Vectorize**](/vectorize/platform/pricing/)   | 상점 벡터 embeddings 및 힘 semantic 수색                                                       |
| [**Workers AI**](/workers-ai/platform/pricing/) | image-to-Markdown 변환, embedding, 쿼리 rewriting 및 응답 발생 처리                               |
| [**AI 게이트웨이**](/ai-gateway/reference/pricing/)  | 모니터 및 제어 모델 사용                                                                         |
| [**브라우저 렌더링**](/browser-rendering/pricing/)     | 동적 JavaScript 콘텐츠로드[사이트 맵](/ai-search/configuration/data-source/website/)Render 옵션과 충돌 |

각 자원이 AI Search, 참고 자료에서 사용되는 방법에 대한 자세한 내용은[AI 검색 작업](/ai-search/concepts/how-ai-search-works/).

## 제한 사항

다음과 같은 제한은 현재 열린 베타 중 AI Search에 적용됩니다.

:::노트\[더 높은 한계를 못했다?]
한계에 조정을 요청하려면, 완료[제한 증가 요청 양식](https://forms.gle/wnizxrEUW33Y15CT8). 한계가 증가될 수 있는 경우에, Cloudflare는 다음 단계로 당신에게 연락할 것입니다.
주요 특징

| 지원하다               | 제품정보      |
| ------------------ | --------- |
| 계정 당 최대 AI 검색 인스턴스 | 50        |
| AI Search 당 최대 파일  | 1,000,000 |
| 최대 파일 크기           | 4개 MB     |

이 제한은 AI Search로 변경 될 수 있습니다.

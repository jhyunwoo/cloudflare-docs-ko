이 가이드는 Cloudflare QX대시보드를 사용하여 AI 검색 인스턴스를 만들 수 있습니다.

## 자주 묻는 질문

AI Search는 데이터를 저장하는 R2와 통합합니다. 첫 번째 AI 검색 인스턴스를 만들기 전에 활성 R2 구독이 있어야합니다.

<DashButton url="/?to=/:account/r2/overview" buttonName="R2 Overview" />

## AI Search 인스턴스 만들기

<DashButton url="/?to=/:account/ai/ai-search" buttonName="AI Search" />

<Steps>
  1. Cloudflare 대시보드에서 이동**컴퓨터 & AI** > **AI 검색**.
  2. 제품정보**이름 \***.
  3. 연결하려는 방법을 선택하십시오.[데이터 소스](/ai-search/configuration/data-source/).
  4. 설정하기[춘킹](/ai-search/configuration/chunking/)·[이름 \*](/ai-search/configuration/models/)내용이 처리되는 방법에 대한 설정.
  5. 설정하기[retrieval 설정](/ai-search/configuration/retrieval-configuration/)검색 결과가 반환되는 방법.
  6. AI Search 인스턴스 이름을 지정합니다.
  7. 이름 \*[서비스 API 토큰](/ai-search/configuration/service-api-token/).
  8. 제품정보**이름 \***.
</Steps>

## 더 알아보기

인덱스가 완료되면 첫 번째 쿼리를 실행할 수 있습니다. 인덱스 상태를 확인할 수 있습니다.**제품정보**인스턴스의 탭.

<Steps>
  1. 오시는 길**컴퓨터 & AI** > **AI 검색**.
  2. 귀하의 인스턴스를 선택합니다.
  3. 선택하기**회사연혁**탭.
  4. 제품정보**AI로 찾기**또는**이름 \***.
  5. 응답을 테스트하는 쿼리를 입력합니다.
</Steps>

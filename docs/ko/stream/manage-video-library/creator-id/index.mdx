토큰화된 업로드 URL이 요청된 시간에 내부 사용자 ID를 가진 제작자 필드를 설정할 수 있습니다. 비디오가 업로드되면, 제작자 재산은 분석 데이터에 사용되거나 특정 제작자에 의해 비디오를 검색 할 수있는 내부 사용자 ID에 자동으로 설정됩니다.

기본 업로드를 위해서는 동영상 업로드 후 Creator ID를 추가해야합니다.

## URL에서 업로드

```bash
curl "https://api.cloudflare.com/client/v4/accounts/{account_id}/stream/copy" \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{"url":"https://example.com/myvideo.mp4","creator": "<CREATOR_ID>","thumbnailTimestampPct":0.529241,"allowedOrigins":["example.com"],"requireSignedURLs":true,"watermark":{"uid":"ea95132c15732412d22c1476fa83f27a"}}'
```

## 동영상에 대한 기본 제작자 설정

기본 제작자 ID 값을 설정하여 단일 제작자와 비디오를 연결할 수 있습니다. 나중에 제작자 ID 또는 분석 데이터를 검색하는 데 사용할 수 있습니다.

```bash
curl "https://api.cloudflare.com/client/v4/accounts/{account_id}/stream/live_inputs" \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{"DefaultCreator":"1234"}'
```

라이브 스트림을 시작하는 여러 제작자가 있다면,[실시간 입력](/stream/get-started/#step-1-create-a-live-input)스트림을 살린 각 창조자를 위해 다음 설정`DefaultCreator`입력 당 값. 각 입력에 대한 기본 제작자 ID를 설정하면 제작자의 입력에서 스트림 된 기록 된 동영상이 상속됩니다.`DefaultCreator`가치.

이번에는 API를 통해 기본 제작자 ID 값을 관리할 수 있습니다.

## 기존 동영상의 업데이트 제작자

기존 동영상의 제작자 속성을 업데이트하려면`POST`아래 예시로 제작자 속성을 지정하는 JSON payload로 video object endpoint에 요청합니다.

```bash
curl "https://api.cloudflare.com/client/v4/accounts/{account_id}/stream/<VIDEO_UID>" \
--header "Authorization: Bearer <AUTH_TOKEN>" \
--header "Content-Type: application/json" \
--data '{"creator":"test123"}'
```

Stream API로 이름을 통해 동영상을 검색할 수 있습니다.`search`쿼리 매개 변수[목록 미디어 파일](/api/resources/stream/methods/list/)끝점.

## 당신이 필요로 할 것

API 요청을 만들려면[Cloudflare API 토큰](https://www.cloudflare.com/a/account/my-account)Cloudflare[계정 ID](https://www.cloudflare.com/a/overview/).

## cURL 예제

이 예제는 이름 일치 미디어 목록`puppy.mp4`.

```bash
curl -X GET "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/stream?search=puppy" \
     -H "Authorization: Bearer <API_TOKEN>" \
     -H "Content-Type: application/json"
```

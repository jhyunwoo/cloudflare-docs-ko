비디오 또는 이미지를 변환하려면, 당신은해야합니다[변환하기](/stream/transform-videos/#getting-started)당신의 지역을 위해. 이미 영역이 이미 Image Transformations가 활성화되면 Media Transformations로 비디오를 최적화 할 수 있습니다.

## 시작하기

저장되는 비디오에서 여전히 이미지를 최적화하고 생성 할 수 있습니다.*기타*Cloudflare 스트림 미디어 변환.

Cloudflare는 자동적으로 당신의 근원에 본래 이미지를 저장하는 우리의 세계적인 네트워크에 각 변환한 영상 또는 이미지를 구울 것입니다.

영역에서 변환을 활성화하려면:

1. Cloudflare dashboard에서, 가십시오**연락처**사이트 맵

2. 변환을 가능하게 할 특정 영역을 찾습니다.

3. 제품정보**이름 \***&#xC9C0;역을 위해.

## URL로 비디오를 변환

특정 코드를 작성하지 않고 특별히 포맷 된 URL을 통해 요청하여 변환 및 크기를 조정할 수 있습니다. URL 형식은:

```
https://example.com/cdn-cgi/media/<OPTIONS>/<SOURCE-VIDEO>
```

- `example.com`: Cloudflare의 웹 사이트 또는 영역, Transformations 활성화.
- `/cdn-cgi/media/`: Cloudflare의 내장 미디어 변환 서비스에 의해 처리되는 특수 경로 식별.
- `<OPTIONS>`: 옵션의 comma-separated 목록. 아래에서 사용할 수있는 옵션 참조.
- `<SOURCE-VIDEO>`: 전체 URL (시작`https://`또는`http://`) 원래의 자산의 크기.

예를 들어,이 URL은 R2 버킷에서 HD 비디오를 소스, 그것을 단축, 작물과 크기를 평방으로, 오디오를 제거합니다.

```
https://example.com/cdn-cgi/media/mode=video,time=5s,duration=5s,width=500,height=500,fit=crop,audio=false/https://pub-8613b7f94d6146408add8fefb52c52e8.r2.dev/aus-mobile-demo.mp4
```

결과는 플레이어 라이브러리없이 HTML 비디오 요소에서 사용할 수있는 MP4입니다.

## 옵션 정보

### `mode`

출력의 종류를 생성합니다.

- `video`: H.264/AAC 최적화 MP4 파일을 출력합니다.
- `frame`: 여전히 이미지를 출력합니다.
- `spritesheet`: 여러 프레임으로 JPEG를 출력합니다.
- `audio`: AAC 인코딩 된 M4A 파일 출력.

### `time`

입력 파일에 출력을 추출 할 때 지정합니다. 에 따라`mode`:

- 시간 :`mode`이름 \*`spritesheet`, `video`, 또는`audio`, 산출이 시작될 타임스탬프를 지정합니다.
- 시간 :`mode`이름 \*`frame`, 아직도 이미지를 추출하는 타임스탬프를 지정합니다.
- 문자열로 형식, 예를 들면: 5s, 2m
- 허용 범위: 0 – 10m
- 기본: 0

### `duration`

출력 비디오 또는 spritesheet의 기간. 에 따라`mode`:

- 시간 :`mode`이름 \*`video`또는`audio`, 산출의 내구를 지정합니다.
- 시간 :`mode`이름 \*`spritesheet`, 프레임을 선택할 수있는 시간 범위를 지정합니다.
- 허용 범위: 1s - 60s (또는 1m)
- 과태: 입력 내구 60 초, 어느것이 더 짧습니다

### `fit`

함께`width`·`height`, resize와 작물 산출을 지정하는 방법. 출력이 재사이즈인 경우, 항상 비례적으로 크기를 재사이즈할 것입니다.

- `contain`: 종횡비를 존중하고, 영상을 최대로 늘리고, 출력 치수 내에서 완전히 함유되어 있습니다.
- `scale-down`: 포함과 동일하지만, downscales만 적합. 고급하지 마십시오.
- `cover`: 종횡비를 존중하고, 영상을 완전히 덮어 산출 차원을, 나머지의 중앙 무게를 다는 작물과 더불어 확장합니다.

### `height`

픽셀의 출력의 최대 높이를 지정합니다. 정확한 행동은에 달려 있습니다`fit`.

- 수락가능한 범위: 10-2000의 화소

### `width`

픽셀의 이미지의 최대 폭을 지정합니다. 정확한 행동은에 달려 있습니다`fit`.

- 수락가능한 범위: 10-2000의 화소

### `audio`

시간 :`mode`이름 \*`video`출력의 소스 오디오를 포함하지 여부를 지정합니다.

- `true`: 소스 오디오 포함.
- `false`: 출력은 침묵합니다.
- 기본 정보:`true`

시간 :`mode`이름 \*`audio`, 오디오는 거짓일 수 없습니다.

### `format`

이름 \*`mode`이름 \*`frame`, 이미지 출력 형식을 지정합니다.

- 수락가능한 선택권:`jpg`, `png`

이름 \*`mode`이름 \*`audio`, 오디오 출력 형식을 지정합니다.

- 수락가능한 선택권:`m4a`(과태)

### `filename`

반환된 Content-Disposition 헤더에서 사용할 파일명을 지정합니다. 지정된 경우, 파일 이름은 소스 URL에서 파생됩니다.

- 수락가능한 가치:
  - 길이 120 문자의 최대.
  - (a-z), 숫자 (0-9), hyphens (-), underscores ( ) 및 선택적인 연장만 포함할 수 있습니다. 유효한 이름은 이 정규 표현식을 satisfies:`^[a-zA-Z0-9-_]+.?[a-zA-Z0-9-_]+$`.
- 예제:`default.mp4`, `shortened-clip_5s`

## 근원 영상 필요조건

- 입력 영상은 100MB 미만이어야 합니다.
- 입력 비디오는 H.264 인코딩 된 비디오 및 AAC 또는 MP3 인코딩 된 오디오와 MP4이어야한다. 다른 형식은 작동하지만 시험되지 않습니다.
- Origin은 HTTP HEAD 및 범위 요청을 지원해야 하며 콘텐츠 범위 헤더를 반환해야 합니다.

## 제한 사항

- 최대 입력 파일 크기는 100 MB입니다. 입력 비디오의 최대 기간은 10 분입니다.
- Media Transformations는 호환되지 않습니다.[자신의 IP를 가져 오기 (BYOIP)](/byoip/).
- 입력 비디오는 H.264 인코딩 된 비디오 및 AAC 또는 MP3 인코딩 된 오디오 또는 애니메이션 GIF와 MP4이어야한다. 다른 형식은 작동하지만 시험되지 않습니다.

## 가격 책정

:::note\[미디어 변환은 현재 GA:]

미디어 변환에 대한 청구는 11 월 1 일, 2025에서 시작됩니다.

:::

Media Transformations를 사용하여 비디오를 변환하고 실패를 경험하는 경우 응답 몸은 오류 메시지가 이유뿐만 아니라`Cf-Resized`관련 상품`err=code`:

- 9401 — 필수 옵션은 누락되거나 무효합니다. 더 알아보기[옵션 정보](/stream/transform-videos/#options)지원되는 인수.
- 9402 - 비디오는 너무 크거나 원래 서버는 예상대로 응답하지 않았다. 더 알아보기[공급 업체](/stream/transform-videos/#source-video-requirements)더 많은 정보.
- 9404 - 비디오는 Origin 서버 또는 비디오 변환에 사용되는 URL에 존재하지 않습니다. 비디오가 존재하고 URL을 확인합니다.
- 9406 & 9419 - 비디오 URL은 비-HTTPS URL 또는 URL은 공백 또는 unescaped 유니코드가 있습니다. URL을 확인하고 다시 시도하십시오.
- 9407 — 보기 오류는 Origin 서버 도메인 이름과 함께 발생했습니다. DNS 설정을 확인하고 다시 시도하십시오.
- 9408 - Origin 서버는 HTTP 4xx 상태 코드를 반환하고 비디오에 액세스 할 수 있습니다. 비디오 설정을 확인하고 다시 시도하십시오.
- 9412 — 소스 서버는 비 비디오, 예를 들어, HTML 페이지. 일반적으로 잘못된 URL이 지정되거나 서버 측 소프트웨어는 오류를 인쇄하거나 로그인 페이지를 발표 할 때 발생합니다.
- 9504 - Origin 서버가 다운되거나 과부하될 수 있기 때문에 Origin 서버는 연락할 수 없습니다. 나중에 다시 시도하십시오.
- 9509 — Origin 서버는 HTTP 5xx 상태 코드를 반환합니다. 이것은 원래 서버 측 소프트웨어와 가장 가능성이 높습니다.
- 9517 및 9523 - 내부 오류. 이 오류를 발생하면 지원 문의.

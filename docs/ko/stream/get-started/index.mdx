## 첫 번째 비디오를 업로드

### Step 1: 공개 URL에서 예 동영상을 업로드

API를 사용하여 동영상을 업로드하거나 직접 업로드할 수 있습니다.**사이트 맵**Cloudflare dashboardXQ의 페이지.

<DashButton url="/?to=/:account/stream/videos" />

허용된 파일 형식의 목록을 위해, 참조[지원되는 영상 체재](/stream/uploading-videos/#supported-video-formats).

API를 사용하려면`API_TOKEN`·`ACCOUNT_ID`아래 예제에서 자격 증명을 가진 값.

```bash title="Upload a video using the API"
curl \
-X POST \
-d '{"url":"https://storage.googleapis.com/stream-example-bucket/video.mp4","meta":{"name":"My First Stream Video"}}' \
-H "Authorization: Bearer <API_TOKEN>" \
https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/stream/copy
```

### 단계 2: 비디오가 스트림 할 준비가 될 때까지 기다립니다

스트림을 다운로드하고 비디오를 처리하기 때문에 비디오는 비디오의 길이에 따라 몇 초 동안 사용할 수 없습니다. Stream API를 투표해야 합니다.`readyToStream`이름 \*`true`또는 사용[웹훅](/stream/manage-video-library/using-webhooks/)동영상이 스트리밍을 준비할 때 알림을 받게 됩니다.

비디오를 투표하는 첫 번째 단계에서 비디오 UID를 사용합니다 :

```bash title="Request"
curl \
-H "Authorization: Bearer <API_TOKEN>" \
https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/stream/<VIDEO_UID>
```

### 3 단계 : 웹 사이트 또는 앱에서 비디오를 재생

스트림에 업로드 된 비디오는 웹 사이트에서 기본 앱으로 모든 장치 및 플랫폼에서 재생할 수 있습니다. 이름 \*[재생 동영상](/stream/viewing-videos)플랫폼 전반에 걸쳐 비디오 재생의 세부 사항 및 예.

당신의 웹 사이트에 비디오를 재생[스트림 플레이어](/stream/viewing-videos/using-the-stream-player/), 복사`uid`위의 요청에 비디오의, 당신의 독특한 고객 코드와 함께, 그리고 교체`<CODE>`·`<VIDEO_UID>`아래 embed 코드에서:

```html
<iframe
	src="https://customer-<CODE>.cloudflarestream.com/<VIDEO_UID>/iframe"
	title="Example Stream video"
	frameborder="0"
	allow="accelerometer; autoplay; encrypted-media; gyroscope; picture-in-picture"
	allowfullscreen
>
</iframe>
```

위 embed 부호는 또한 위에 찾아낼 수 있습니다**사이트 맵**Cloudflare dashboard의 페이지.

## 첫 라이브 스트림을 시작

### Step 1: 실시간 입력 생성

API 또는**실시간 입력**Cloudflare dashboardXQ의 페이지.

<DashButton url="/?to=/:account/stream/inputs" />

API를 사용하려면`API_TOKEN`·`ACCOUNT_ID`아래 예제에서 자격 증명을 가진 값.

```bash title="Request"
curl -X POST \
-H "Authorization: Bearer <API_TOKEN>" \
-D '{"meta": {"name":"test stream"},"recording": { "mode": "automatic" }}' \
https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/stream/live_inputs
```

### 3 단계 : 웹 사이트 또는 앱에서 라이브 스트림을 재생

라이브 스트림은 웹 사이트에서 네이티브 앱에 이르기까지 모든 장치 및 플랫폼에서 스트림에 업로드 된 비디오 플레이어와 동일한 비디오 플레이어를 사용하여 재생할 수 있습니다. 이름 \*[재생 동영상](/stream/viewing-videos)플랫폼 전반에 걸쳐 비디오 재생의 세부 사항 및 예.

라이브 스트림을 재생하려면 웹 사이트에서 시작[스트림 플레이어](/stream/viewing-videos/using-the-stream-player/), 복사`uid`위의 요청에서 라이브 입력의, 당신의 독특한 고객 코드와 함께, 그리고 교체`<CODE>`·`<VIDEO_UID>`아래 embed 코드에서:

```html
	allowfullscreen
>
</iframe>
```

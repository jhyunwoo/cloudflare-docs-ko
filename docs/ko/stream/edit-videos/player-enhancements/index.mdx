플레이어 향상을 통해 비디오 플레이어가 로고와 같은 브랜드의 요소를 통합하여 시청자에게 추가 옵션을 사용자 정의 할 수 있습니다.

플레이어 향상은 Stream Player를 사용하여 비디오에 자동으로 적용되지만 세부 사항을 추가해야합니다.`publicDetails`해당 이용 후기에 달린 코멘트가 없습니다.

## 제품 정보

- `title`: 시청자가 비디오를 통해 호버를 볼 때 나타나는 제목. 제목은 비디오의 파일 이름과 다를 수 있습니다.
- `share_link`: 영상 URL을 쉽게 공유할 수 있는 click-to-copy 옵션으로 사용자를 제공합니다. 일반적으로 비디오가 내장 된 페이지의 URL로 설정됩니다.
- `channel_link`: URL 사용자는 비디오 플레이어에서 로고를 선택할 때 지시됩니다.
- `logo`: 로고의 이미지에 대한 유효한 HTTPS URL.

## 사용자 정의

아래 예제에는 모든 속성이 포함되어 있습니다.`publicDetails`.

```bash
curl --location --request POST "https://api.cloudflare.com/client/v4/accounts/<$ACCOUNT_ID>/stream/<$VIDEO_UID>" \
--header "Authorization: Bearer <$SECRET>" \
--header 'Content-Type: application/json' \
--data-raw '{
    "publicDetails": {
        "title": "Optional video title",
        "share_link": "https://my-cool-share-link.cloudflare.com",
        "channel_link": "https://www.cloudflare.com/products/cloudflare-stream/",
        "logo": "https://upload.wikimedia.org/wikipedia/commons/thumb/9/94/Cloudflare_Logo.png/480px-Cloudflare_Logo.png"
    }
}' | jq ".result.publicDetails"
```

그 때문에`publicDetails`재산은 선택적입니다, 당신은 포함하는 어떤 재산을 선택할 수 있습니다. 아래 예에서, 단지`logo`비디오에 추가됩니다.

```bash
curl --location --request POST "https://api.cloudflare.com/client/v4/accounts/<$ACCOUNT_ID>/stream/<$VIDEO_UID>" \
--header "Authorization: Bearer <$SECRET>" \
--header 'Content-Type: application/json' \
--data-raw '{
    "publicDetails": {
        "logo": "https://upload.wikimedia.org/wikipedia/commons/thumb/9/94/Cloudflare_Logo.png/480px-Cloudflare_Logo.png"
    }
}'
```

아래 엔드포인트를 사용하여 JSON을 풀 수 있습니다.

`https://customer-<ID>.cloudflarestream.com/<VIDEO_ID>/metadata/playerEnhancementInfo.json`

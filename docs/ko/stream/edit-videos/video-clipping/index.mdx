## 자주 묻는 질문

비디오를 클립하기 전에 API 토큰이 필요합니다. API 토큰 생성에 대한 자세한 내용은 참조[API 토큰 만들기](/fundamentals/api/get-started/create-token/).

## 필수 모수

비디오를 클립하려면 기존 비디오에서 사용하려는 시작과 끝 시간을 결정하여 새로운 비디오를 만듭니다. 사용 방법`videoUID`그리고 당신의 요구를 만드는 시작 끝 시간.

:::참조

Clipped 동영상은 상속되지 않습니다.`scheduledDeletion`이름 \* 삭제 날짜를 설정하려면 먼저 비디오를 클립하고 삭제 날짜를 설정해야합니다.

:::

```json title="Required parameters"
{
	"clippedFromVideoUID": "0ea62994907491cf9ebefb0a34c1e2c6",
	"startTimeSeconds": 20,
	"endTimeSeconds": 40
}
```

- **`clippedFromVideoUID`**: 새로운 비디오 만들기에 사용되는 비디오의 고유 식별자.
- **`startTimeSeconds`**: 새로운 비디오가 시작될 때 나타내는 기존 비디오에서 타임스탬프.
- **`endTimeSeconds`**: 새로운 비디오가 끝날 때 나타내는 기존 비디오에서 타임스탬프.<br /><br />

```bash title="Example: Clip a video" {5,6,7}
curl --location --request POST 'https://api.cloudflare.com/client/v4/accounts/<YOUR_ACCOUND_ID_HERE>/stream/clip' \
--header 'Authorization: Bearer <YOUR_TOKEN_HERE>' \
--header 'Content-Type: application/json' \
--data-raw '{
    "clippedFromVideoUID": "0ea62994907491cf9ebefb0a34c1e2c6",
    "startTimeSeconds": 10,
    "endTimeSeconds": 15
    }'
```

## 설정 비디오 이름

비디오를 클립 할 때, 클립 비디오에 새로운 이름을 지정할 수 있습니다. 아래 예제에서,`name`필드는 클립 비디오에 사용할 새 이름을 나타냅니다.

```json title="Example: Specify a custom name" {6}
{
	"clippedFromVideoUID": "0ea62994907491cf9ebefb0a34c1e2c6",
	"startTimeSeconds": 10,
	"endTimeSeconds": 15,
	"meta": {
		"name": "overriding-filename-clip.mp4"
	}
}
```

비디오가 클립 및 처리 된 경우 목록 비디오에서 QXQX0007XQ QXQXdashboardXQXQ에 새로 지명 된 비디오 디스플레이.

## 워터마크 추가

당신은 또한 당신의 영상에 관례 Watermark를 추가할 수 있습니다. 워터 마크에 대한 자세한 내용은 워터 마크 프로파일을 업로드, 참조[워터마크 적용](/stream/edit-videos/applying-watermarks).

```json title="Example: Clip a video, set a new video name, and apply a watermark" {5,6,9}
{
	"clippedFromVideoUID": "0ea62994907491cf9ebefb0a34c1e2c6",
	"startTimeSeconds": 10,
	"endTimeSeconds": 15,
	"watermark": {
		"uid": "4babd675387c3d927f58c41c761978fe"
	},
	"meta": {
		"name": "overriding-filename-clip.mp4"
	}
}
```

## 로그인 URL

비디오 클립 할 때, 당신은 비디오 개인을 만들고 특정 사용자에게 접근 할 수[서명된 URL을 요구하는](/stream/viewing-videos/securing-your-stream/).

```json title="Example: Clip a video and require signed URLs" {5}
{
	"clippedFromVideoUID": "0ea62994907491cf9ebefb0a34c1e2c6",
	"startTimeSeconds": 10,
	"endTimeSeconds": 15,
	"requireSignedURLs": true,
	"meta": {
		"name": "signed-urls-demo.mp4"
	}
}
```

비디오 클립이 완료되면 Cloudflare dashboard 및 비디오 목록을 열어 비디오를 찾습니다. 비디오를 선택할 때,**계정 설정**탭 옆에 체크 마크 표시**로그인 URL**.

## thumbnail 이미지 지정

백분율값을 사용하여 비디오의 엄밀 이미지를 지정할 수 있습니다. 몇 초에서 백분율로 엄지나일의 타임스탬프를 변환하려면 비디오의 전체 기간에 사용하려는 타임 스탬프를 분할하십시오. 엄지나일에 대한 자세한 내용은 참조[디스플레이 thumbnails](/stream/viewing-videos/displaying-thumbnails).

```json title="Example: Clip a video with a thumbnail generated at the 50% mark" {5}
{
	"clippedFromVideoUID": "0ea62994907491cf9ebefb0a34c1e2c6",
	"startTimeSeconds": 10,
	"endTimeSeconds": 15,
	"thumbnailTimestampPct": 0.5,
	"meta": {
		"name": "thumbnail_percentage.mp4"
	}
}
```

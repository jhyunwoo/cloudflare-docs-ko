스트림 플레이어는 기본적으로 라이브 뷰어 카운트에 대한 전체 지원이 있습니다. 세 번째 파티 플레이어와 함께 사용을위한 라이브 비디오의 시청자를 얻으려면,`GET`요청하기`/views`끝점.

```bash
https://customer-<CODE>.cloudflarestream.com/<INPUT_ID>/views
```

아래는 몇 가지 활성 뷰어와 라이브 비디오에 대한 응답입니다:

```json
{ "liveViewers": 113 }
```

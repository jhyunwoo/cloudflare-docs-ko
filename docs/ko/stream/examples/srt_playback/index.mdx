라이브 입력의 SRT 재생 URL을 복사:

- 더 보기**실시간 입력**Cloudflare dashboard의 페이지.

  <DashButton url="/?to=/:account/stream/inputs" />

- 더 보기[스트림 API](/stream/stream-live/start-stream-live/#use-the-api)

아래 URL로 붙여넣기, 교체`<SRT_PLAYBACK_URL>`:

```sh title="SRT playback with ffplay"
ffplay -analyzeduration 1 -fflags -nobuffer -probesize 32 -sync ext '<SRT_PLAYBACK_URL>'
```

더 많은 것, 참조[기본 앱에서 라이브 비디오를 1 초 미만의 대기 시간](/stream/viewing-videos/using-own-player/#play-live-video-in-native-apps-with-less-than-1-second-latency).

### 앱 다운로드 및 실행

1. 다운로드[이 예제 앱](https://developer.apple.com/documentation/avfoundation/offline_playback_and_storage/using_avfoundation_to_play_and_persist_http_live_streams)Apple의 개발자 문서
2. 앱을 열고 실행[파일 형식](https://developer.apple.com/xcode/).
3. Xcode에서 검색`m3u8`, 그리고 열기`Streams`이름 \*
4. 값 바꾸기`playlist_url`HLS가 비디오의 URL을 나타냅니다.

![상단에 Cloudflare 워터 마크가있는 비디오의 스크린 샷](~/assets/images/stream/ios-example-screenshot-edit-hls-url.png)

5. Xcode에서 재생 버튼을 클릭하여 앱을 실행하고 비디오를 재생합니다.

더 보기[docs를 읽으십시오](/stream/viewing-videos/using-own-player/ios/).

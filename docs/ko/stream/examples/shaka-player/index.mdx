첫째, poster 속성을 사용하여 미리보기 thumbnail 이미지를 설정합니다. 더 알아보기[디스플레이 thumbnails](/stream/viewing-videos/displaying-thumbnails/)Cloudflare 스트림을 사용하여 썸네일 이미지를 생성하는 방법에 대한 지침.

```html
<video
	id="video"
	width="640"
	poster="https://customer-f33zs165nr7gyfy4.cloudflarestream.com/6b9e68b07dfee8cc2d116e4c51d6a957/thumbnails/thumbnail.jpg"
	controls
	autoplay
></video>
```

다음 듣기`DOMContentLoaded`이벤트, Shaka Player의 새로운 인스턴스를 만들고, URI를로드합니다.

```javascript
//HLS 또는 DASH가 Cloudflare 스트림에서 나타날 URI를 대체합니다.
const manifestUri =
	'https://customer-f33zs165nr7gyfy4.cloudflarestream.com/6b9e68b07dfee8cc2d116e4c51d6a957/manifest/video.mpd';

document.addEventListener('DOMContentLoaded', () => {
	const video = document.getElementById('video');
  const player = new shaka.Player(video);
	await player.load(manifestUri);
});
```

더 알아보기[Shaka Player 문서](https://github.com/shaka-project/shaka-player)더 많은 정보.

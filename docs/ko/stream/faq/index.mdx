## 사이트 맵

### 스트림에서 원본 비디오 파일을 다운로드 할 수 있습니까?

다운로드 할 수 없습니다*견적 요청*업로드 된 파일 입력. 그러나 사용 사례에 따라 사용할 수 있습니다.[다운로드](/stream/viewing-videos/download-videos/)오프라인 보기와 같은 사용 케이스에 인코딩된 MP4s를 얻는 특징.

### 업로드 할 수있는 동영상의 양에 제한이 있습니까?

- 기본적으로 비디오 업로드는 대부분의 30 GB에있을 수 있습니다.

- 기본적으로 최대 120개의 동영상이 설치되어 있거나 동시에 인코딩될 수 있습니다. 비디오에서`ready`상태는 재생 가능하지만 여전히 특정 품질 수준을 인코딩 할 수있다`pctComplete`도달 100. 비디오에서`error`, `ready`, 또는`pendingupload`상태는 이 한계를 넘지 않습니다. 모금 한도가 필요한 경우,[접촉 Cloudflare 지원](/support/contacting-cloudflare-support/)사용 사례를 설명하고 왜 제한이 제기되었는지.

:::참조

동영상의 수에 제한은 Cloudflare 스트림에 업로드된 비디오에만 적용됩니다. 이 제한은 끝 사용자 스트리밍 동영상의 수와 관련이 없습니다.

:::

- 전체 비디오 지속 시간이 구매 한 비디오 저장 용량을 초과하는 경우 계정을 업로드 할 수 없습니다.

Limits apply to Direct Creator 업로드 URL 생성시에 업로드합니다.

이 제한을 통해 업로드하면[429 (수 많은 요청)](/support/troubleshooting/http-status-codes/4xx-client-error/error-429/)또는[413(유료)](/support/troubleshooting/http-status-codes/4xx-client-error/error-413/)HTTP 상태는 응답 몸에 더 많은 정보를 가진 부호. 더 높은 한계를 위한 Cloudflare 지원 또는 당신의 고객 성공 매니저에 쓰기.

### 내 도메인이 CloudflareXQ에없는 경우에도 스트림에 비디오를 삽입 할 수 있습니까?

예. 스트림 비디오는 어떤 도메인에 포함 될 수 있습니다, 심지어 도메인에 CloudflareXQ.

### 스트림 지원 높은 동적 범위 (HDR) 비디오 콘텐츠?

HDR 동영상이 스트림에 업로드되면 SDR 형식으로 다시 인코딩되고 전달되며 가장 넓은 범위의 시청 장치와 호환성을 보장합니다.

### 비디오 업로드에 대한 권장 업로드 설정은 무엇입니까?

Cloudflare 스트림의 새로운 파일을 생산하는 경우 다음 설정을 사용하는 것이 좋습니다.

- MP4 콘테이너, AAC 오디오 코덱, H264 영상 코덱, 초당 30 이하 구조
- moov 원자는 파일의 앞에 있어야한다 (빠른 시작)
- H264 진보적 인 검사 (간헐 없음)
- H264 높은 단면도
- 닫히는 GOP
- 콘텐츠는 기록 된 동일한 프레임 속도에 인코딩 및 업로드해야합니다
- 단청 또는 입체 음향 오디오 (스트림은 입체 음향에 2개 이상 수로를 가진 오디오 궤도를 섞을 것입니다)

아래는 스트림을위한 새로운 비디오를 인코딩하는 것이 좋습니다.

  | 1080p의 | 8개 Mbps     |
  | 뚱 베어   | 4.8 Mbps의   |

### 스트림 구독을 취소하면 동영상이 삭제됩니까?

비디오는 30 일 이내에 구독이 갱신되지 않는 경우 제거됩니다.

### 웹 사이트에 콘텐츠 보안 정책 (CSP)을 사용합니다. 어떤 도메인은 어떤 지시어를 추가해야 합니까?

웹 사이트 사용<GlossaryTooltip term="content security policy (CSP)" link="https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy">콘텐츠 보안 정책 (CSP)</GlossaryTooltip>구성에 따라, Cloudflare Stream의 도메인을 특정 지침에 추가해야 할 수 있습니다. 비디오를 사용자에 의해 볼 수 있거나 업로드 할 수 있습니다.

제공된 경우[스트림 플레이어](/stream/viewing-videos/using-the-stream-player/), `videodelivery.net`·`*.cloudflarestream.com`에 포함해야`frame-src`또는`default-src`플레이어를 허용하는 지시어`<iframe>`짐에 성분.

```http
Content-Security-Policy: frame-src 'self' videodelivery.net *.cloudflarestream.com
```

당신이 사용 하는 경우**이름 \***&#xD50C;레이어, 추가`*.videodelivery.net`·`*.cloudflarestream.com`이름 \*`media-src`, `img-src`·`connect-src`CSP 지시어는 비디오 파일과 썸네일 이미지를 로드할 수 있습니다.

```http
Content-Security-Policy: media-src 'self' videodelivery.net *.cloudflarestream.com; img-src 'self' *.videodelivery.net *.cloudflarestream.com; connect-src 'self' *.videodelivery.net *.cloudflarestream.com
```

Cloudflare 스트림에 직접 자신의 비디오를 업로드 할 수 있다면, 추가`*.videodelivery.net`·`*.cloudflarestream.com`이름 \*`connect-src`CSP 지침.

```http
Content-Security-Policy: connect-src 'self' *.videodelivery.net *.cloudflarestream.com
```

### 왜 PageSpeed Insights는 스트림 플레이어를 사용할 때 나쁜 점수를 제공합니까?

웹 사이트가 많은 플레이어 인스턴스에로드되면 PageSpeed Insights는 각 플레이어 인스턴스에 대한 JavaScript로드를 처벌합니다. 우리의 테스트는 실제로 페이지를로드 할 때, 스크립트 자체는 로컬 브라우저 캐시가 동일한 페이지에서 다른 플레이어 개체에 대한 스크립트를 검색 한 번만 다운로드됩니다. 따라서 PageSpeed Insights 점수는이 상황에서 실제 행동과 일치하지 않다는 것을 믿는다.

thumbnails를 사용하는 경우, 당신은 사용할 수 있습니다[애니메이션 썸네일](/stream/viewing-videos/displaying-thumbnails/#animated-gif-thumbnails)그것은 비디오 페이지에 연결.

여러 플레이어가 같은 페이지에 있다면, 초기 뷰포트에서 볼 수없는 플레이어를 게으른다. 게으른 로딩에 대한 자세한 내용은 참조[Mozilla의 게으른 로딩 문서](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/iframe#lazy).

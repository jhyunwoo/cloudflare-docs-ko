| 업로드 방법                                                             | 이용 시                                                      |
| ------------------------------------------------------------------ | --------------------------------------------------------- |
| [Stream 대시보드](https://dash.cloudflare.com/?to=/:account/stream)    | Stream Dashboard에서 비디오를 업로드하십시오.                          |
| [연결하기](/stream/uploading-videos/upload-via-link/)                  | S3 버킷 또는 콘텐츠 관리 시스템과 같은 링크를 사용하여 비디오를 업로드하십시오.            |
| [동영상 파일 업로드](/stream/uploading-videos/upload-video-file/)          | 컴퓨터에 저장된 비디오 업로드.                                         |

## 자주 묻는 질문

- 선택적이지만 이상적인 설정:
  - MP4 컨테이너
  - AAC 오디오 코덱
  - H264 비디오 코덱
  - 초당 60 또는 몇몇 구조
- 닫히는 GOP (*라이브 스트리밍만 필요.*)
- 단청 또는 입체 음향 오디오. 스트림은 스테레오로 두 개 이상의 채널을 가진 오디오 트랙을 혼합합니다.

## 프레임 속도

스트림은 모든 프레임 속도에서 비디오 업로드를 허용합니다. 인코딩 중 최대 70 FPS 재생을위한 스트림 리 인코딩 동영상. 원래 비디오가 프레임 속도가 70 FPS보다 낮으면 원래 프레임 속도에서 스트림 리 인코딩.

가변 프레임 속도 콘텐츠, 스트림 드롭 추가 프레임. 예를 들어, 1 / 30 초 창 내에서 1 개 이상의 프레임이 있다면 스트림은 그 기간 내에 여분의 프레임을 제거합니다.

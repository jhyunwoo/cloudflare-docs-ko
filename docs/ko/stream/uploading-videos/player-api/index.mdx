속성에 추가`<stream>`견적없이 태그, 당신이 아래를 볼 수로:

```
<stream attribute-added-here src="5d5bc37ffcf54c9b82e996823bffbb81"></stream>
```

여러 속성을 함께 사용할 수 있습니다, 이 같은 각 다른 후 하나를 추가:

```
<stream attribute-1 attribute-2 attribute-3 src="5d5bc37ffcf54c9b82e996823bffbb81"></stream>
```

## 지원된 속성

- `autoplay`한국어

  - 브라우저를 즉시 다운로드하여 비디오를 다운로드하고 즉시 재생할 수 있습니다. 모바일 브라우저는 일반적으로이 속성을 지원하지 않습니다, 사용자는 비디오를 재생하기 위해 화면을 탭해야합니다. 인터넷 사용 제한으로 모바일 사용자 또는 사용자를 고려하시기 바랍니다 일부 사용자는이 속성을 사용하기 전에 무제한 인터넷 액세스를하지 않습니다.

  :::참조
  비디오 autoplay를 비활성화하려면,`autoplay`속성은이 속성으로 altogether를 제거해야합니다. 설치하기`autoplay="false"`작동하지 않을 것이다; 비디오는 속성이 거기있는 경우 autoplay 할 것이다`<stream>`태그.

또한 일부 브라우저는 이제 자동으로 재생에서 오디오로 비디오를 방지합니다. 당신은 추가 할 수 있습니다`mute`비디오를 autoplay에 허용하는 속성. 더 많은 정보를 원하시면,[iOS의 새로운 비디오 정책](https://webkit.org/blog/6784/new-video-policies-for-ios/).
:::

- `controls`한국어

  - 재생/쉼, 볼륨 컨트롤 버튼과 같은 기본 비디오 컨트롤을 표시합니다. 플레이어와 함께 작업하는 버튼과 컨트롤을 만들 수 있습니다.[예제 보기.](/stream/viewing-videos/using-own-player/)

- `height`뚱 베어

  - 비디오 디스플레이 영역의 높이, CSS 픽셀.

- `loop`한국어

  - Boolean 속성; HTML 태그에 포함 된 경우, 플레이어는 비디오의 끝에 도달하기 위해 시작을 자동으로 추구합니다.

- `muted`한국어

  - 비디오에 포함된 오디오의 기본 설정을 나타냅니다. 설정하면 오디오가 초기 침묵됩니다.

- `preload`문자열 | null

  - 이 enumerated 속성은 저자가 가장 좋은 사용자 경험으로 이어질 것이라고 생각하는 것에 대한 브라우저에 힌트를 제공하는 것입니다. 이 속성을 값없이 boolean 속성으로 포함하도록 선택할 수 있습니다. 또는 값을 지정할 수 있습니다.`preload="auto"`비디오의 시작을 미리로드합니다. 속성을 포함하거나 사용`preload="metadata"`요청 시 비디오 재생을 시작할 필요가 있는 메타데이터를 로드합니다.

  :::참조
  더 보기`<video>`이 속성의 값을 따르는 브라우저를 강제하지 않습니다; 그것은 단지 힌트입니다. 비록`preload="none"`옵션은 유효한 HTML5 속성이며, 스트림 플레이어는 항상 플레이어를 초기화하기 위해 메타 데이터를로드합니다. 이 경우에 적재된 자료의 양은 negligible 입니다.
  주요 특징

- `poster`이름 \*

  - 동영상이 시작되거나 비디오가 다운로드되는 동안 이미지에 대한 URL. 이 속성이 지정되지 않은 경우, 비디오의 미리보기 이미지가 표시됩니다.

- `src`이름 \*

  - 동영상에서 Cloudflare 스트림에 업로드했습니다.

- `width`뚱 베어

  - 비디오 디스플레이 영역의 너비, CSS 픽셀.

## 제품 설명

- `play()`회사 소개

  - 동영상 재생 시작.

- `pause()`한국어

  - Pause 비디오 재생.

## 제품 정보

- `autoplay`

  - autoplay 속성이 설정되었는지 여부를 설정하거나 반환합니다. 비디오 재생을로드에서 시작합니다.

- `controls`

  - 비디오가 컨트롤 (Play/pause 등과 같은)를 표시해야 할지 여부를 설정하거나 반환합니다.

- `currentTime`

  - 초에 현재 재생 시간을 반환합니다. 이 값을 설정하면 비디오를 새로운 시간에 추구합니다.

- `duration`한국어

  - 초에 비디오의 지속 시간을 반환합니다.

- `ended`한국어

  - 동영상이 종료된지 확인합니다.

- `loop`

  - 설정 또는 비디오가 끝에 도달 할 때 시작해야하는지 반환

- `muted`

  - 오디오가 비디오로 재생되어야 할지 여부 설정 또는 반환

- `paused`한국어

  - 동영상이 일시 중지 여부

- `preload`

  - 설정 또는 반환 여부 비디오는 요소 부하에 preloaded.

- `volume`

  - 0.0(silent)에서 1.0(maximum 값)으로 설정 또는 반환 볼륨

## (주)

### 표준 비디오 요소 이벤트

스트림은 대부분을 지원합니다[표준화 된 미디어 요소 이벤트](https://developer.mozilla.org/en-US/docs/Web/Guide/Events/Media_events).

- `abort`

  - 재생이 낙관 될 때 전송; 예를 들어, 미디어가 재생되고 시작된 경우,이 이벤트가 전송됩니다.

- `canplay`

  - 미디어가 재생 될 수 있음을 충분히 알 수 있을 때, 적어도 몇 가지 프레임에 대 한.

- `canplaythrough`

  - 전체 미디어가 중단 없이 재생될 수 있을 때, 다운로드 비율을 적어도 현재 수준 남아있는 것과 같이 말하십시오. 재생이 일시 중지되고 재생될 때도 불화될 것입니다. 참고 : currentTime을 수동으로 설정하면 Firefox에서 canplaythrough 이벤트를 불립니다. 다른 브라우저는이 이벤트를 불지 않을 수 있습니다.

- `durationchange`

  - metadata는로드되거나 변경되어 미디어의 지속 시간이 변경됩니다. 이 전송, 예를 들어, 미디어가 지속 시간이 알려진 충분히로드 할 때.

- `ended`

  - 재생이 완료되면 전송합니다.

- `error`

  - 오류가 발생했을 때 문장. (예를 들어, 비디오는 아직 인코딩을 완료하지 않았거나 비디오는 잘못된 서명 URL로 인해로드 실패)

- `loadeddata`

  - 매체의 첫번째 구조는 적재를 완료했습니다.

- `loadedmetadata`

  - 미디어의 메타데이터는 로딩을 완료했습니다. 이제 모든 속성은 훨씬 유용한 정보를 가지고 있습니다.

- `loadstart`

  - 미디어의 로딩이 시작됩니다.

- `pause`

  - 재생 상태가 일시적으로 변경 될 때 전송 (사용 된 속성은 true).

- `play`

  - 재생 상태가 더 이상 일시 중지되지 않을 때, 재생 방법의 결과로, 또는 autoplay 속성.

- `playing`

  - 미디어가 재생을 시작하기 위해 충분한 데이터가있을 때, 재생 이벤트 이후, 또한 쌓아올릴 때, 미디어 재시작을 반복, 추구 후, 그것이 찾고 전에 재생 된 경우.

- `progress`

  - 미디어를 다운로드하는 진행 상황을 알리기 위해 주기적으로 말하십시오. 다운로드 된 미디어의 현재 금액에 대한 정보는 미디어 요소의 버퍼드 속성에서 사용할 수 있습니다.

- `ratechange`

  - 재생 속도가 변경 될 때 전송.

- `seeked`

  - 작업이 완료되면 문장.

- `seeking`

  - 찾은 작업이 시작됩니다.

- `stalled`

  - 사용자 에이전트가 미디어 데이터를 fetch하려고 할 때 전송, 하지만 데이터는 예기치 않게 될 수 없습니다.

- `suspend`

  - 미디어의 로딩이 중단될 때 전송; 다운로드가 완료되었거나 다른 이유로 일시적으로 사용되었기 때문에 이러한 일이 발생할 수 있습니다.

- `timeupdate`

  - 요소의 현재에 의해 표시된 시간 Time 속성이 변경되었습니다.

- `volumechange`

  - 오디오 볼륨 변경 (양이 설정되고 점유 속성이 변경 될 때)를 전송합니다.

- `waiting`

  - 요청한 가동 (Playback와 같은)가 다른 가동 (찾은 것과 같은)의 완료를 연기하는 때 문장.

### 비표준 이벤트

비표준 이벤트는 접두사`stream-`표준 이벤트를 구별합니다.

- `stream-adstart`

  - 화재 때`ad-url`속성은 현재이며 광고는 재생 시작

- `stream-adend`

  - 화재 때`ad-url`속성은 현재와 광고 끝 playback

- `stream-adtimeout`

  - 화재 때`ad-url`속성이 존재하고 광고는 너무 오래 걸었다.

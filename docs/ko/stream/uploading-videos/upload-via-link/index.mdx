클라우드 스토리지 버킷에 저장된 비디오가 있는 경우, 파일을 HTTP 링크를 통과할 수 있으며, Stream은 사용자를 대신하여 파일을 가져올 수 있습니다.

## HTTP 요청 확인

더 보기`POST`Stream API에 요청하여 동영상에 링크합니다.

```bash
curl \
--data '{"url":"https://storage.googleapis.com/zaid-test/Watermarks%20Demo/cf-ad-original.mp4","meta":{"name":"My First Stream Video"}}' \
--header "Authorization: Bearer <API_TOKEN>" \
https://api.cloudflare.com/client/v4/accounts/{account_id}/stream/copy
```

## 영상 상태 확인

스트림은 비디오의 길이에 따라 몇 초 걸릴 수있는 비디오를 다운로드하고 인코딩해야합니다.

언제까지`readyToStream`값 반환`true`, 동영상 스트리밍을 준비합니다.

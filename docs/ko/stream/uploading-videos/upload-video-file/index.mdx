## 기본 업로드

200MB 미만의 파일에 대해서는 간단한 양식 기반 업로드를 사용할 수 있습니다.

## Cloudflare dashboard를 통해 업로드

1. Cloudflare dashboard에서, 갑니다**사이트 맵**사이트 맵

   <DashButton url="/?to=/:account/stream/videos" />

2. 드래그와 드롭 당신의 비디오로**빠른 업로드**지역. 당신은 또한 당신의 기계에 파일을 찾아 볼 수 있습니다.

비디오가 업로드 한 후, 비디오는 목록에서 나타납니다.

## Stream API로 업로드

더 보기`POST`자주 묻는 질문`content-type`헤더 설정`multipart/form-data`이름과 함께 입력한 미디어를 포함`file`.

```bash title="Upload video POST request"
curl --request POST \
--header "Authorization: Bearer <API_TOKEN>" \
--form file=@/Users/user_name/Desktop/my-video.mp4 \
https://api.cloudflare.com/client/v4/accounts/{account_id}/stream
```

:::참조
cURL의 참고`--form`플래그는 자동으로 구성`content-type`헤더 및 맵`my-video.mp4`본문내용 바로가기`file`.
:::

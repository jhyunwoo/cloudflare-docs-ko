Stream Live는 옵트 인 기반에 "DVR 모드"를 지원하여 시청자가 되감기를 허용합니다.
라이브 방송을 다시, 그리고 빠른. DVR 모드를 활성화하려면 추가
`dvrEnabled=true`스트림 플레이어에 쿼리 매개 변수 소스 또는 HLS
정의 URL.

## 스트림 플레이어

```html title="Stream Player embed format"
<div style="position: relative; padding-top: 56.25%;">
  <iframe
    src="https://customer-<CODE>.cloudflarestream.com/<INPUT_ID|VIDEO_ID>/iframe?dvrEnabled=true"
    style="border: none; position: absolute; top: 0; left: 0; height: 100%; width: 100%;"
    allow="accelerometer; gyroscope; autoplay; encrypted-media; picture-in-picture;"
    allowfullscreen="true"
  ></iframe>
</div>
```

DVR 모드가 스트림 플레이어가 활성화되면:

- 타이머를 표시할 수 있는 타임라인을 표시해 주세요.
  비디오. 타임 라인은 자동적으로 증가한 기간을 보여주기 위하여 확장할 것입니다
  라이브 방송
- "LIVE"표시 표시는 라이브 가장자리 뒤에 회색을 보여줄 것입니다 또는
  그들은 최신 콘텐츠를보고 있다면 빨간색. 그 표시를 클릭하면
  살아있는 가장자리에 앞으로.
- 시청자가 플레이어를 일시 중지하면 대신 재생을 다시 시작합니다.
  살아있는 가장자리에 앞으로 뛰어납니다.

## HLS는 사용자 정의 선수에 대 한 표시

```text title="HLS manifest URL format"
https://customer-<CODE>.cloudflarestream.com/<INPUT_ID|VIDEO_ID>/manifest/video.m3u8?dvrEnabled=true
```

DVR-capable HLS를 사용하는 사용자 정의 플레이어는 추가 할 수 있습니다
표면이 도움이되는 제어 또는 정보로 구성. 플레이어에게
추가 정보를 위한 라이브러리.

스트림 라이브는 비디오 ID 또는 라이브 입력으로 플레이어 또는 HLS를로드 할 수 있습니다
ID. 참조[라이브 스트림 보기](/stream/stream-live/watch-live-stream/)관련 기사
이 URL을 검색하고 이러한 옵션을 비교합니다. 더 많은 것
DVR 모드를 사용할 때 고려:

**추천 :**&#xBE44;디오 ID URL에서 DVR 모드를 사용하십시오:

- 플레이어가로드되면 활성화 된 방송을 시작합니다.
  방송이 끝나는 경우 여전히 라이브 또는 재생 녹음.

라이브 입력 ID URL의 DVR 모드:

- 플레이어가로드되면 현재 라이브 방송을 시작합니다.
  하나 있다 (refer to[실시간 입력 상태](/stream/stream-live/watch-live-stream/#live-input-status)).
- 시청자가 여전히 시청하는 경우*방송 종료 후,*&#xADF8;들은 계속할 수 있습니다.
  시계. 그러나 플레이어가 나타날 경우 다시로드됩니다.
  최근 방송 또는 "Stream은 아직 시작되지 않았습니다" (`HTTP 204`). 과거 방송

## Known 제한

- 라이브 입력 ID를 사용하여 만든 DVR 모드 및 플레이어 / manifest를 사용할 때,
  플레이어는 시청자가 여전히 인 경우 품질 수준을 전환하려고 할 수 있습니다
  방송 후 시청이 종료되었습니다.
- 성과는 3 시간 이상 DVR 가능하게 한 방송을 위해 degraded 할지도 모릅니다.
  Manifests는 7,200 세그먼트의 maxiumum에 제한됩니다. 세그먼트 길이는
  키프레임 간격에 의해 결정, 또한 GOP 크기를 호출.
- DVR 모드는 HLS의 버전 8에 의존합니다 명세. Stream 사용
  HLS 버전 6 다른 모든 상황에. HLS v8는 극단적으로 넓은 겸용성을 제안합니다
  하지만 특정 이전 플레이어 라이브러리 또는 이전 장치와 작동하지 않을 수 있습니다.
- DVR의 DASH는 사용할 수 없습니다.

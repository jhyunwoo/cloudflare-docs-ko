라이브 스트림은 자동으로 기록되며 즉시 라이브 스트림이 종료됩니다. 주어진 입력 ID에 대한 기록 목록을 얻으려면,[`GET`지원하다`/live_inputs/<UID>/videos`](/api/resources/stream/subresources/live_inputs/methods/get/)동영상 필터`state`설정`ready`:

```bash title="Request"
curl -X GET \
-H "Authorization: Bearer <API_TOKEN>" \
https://dash.cloudflare.com/api/v4/accounts/<ACCOUNT_ID>/stream/live_inputs/<LIVE_INPUT_UID>/videos
```

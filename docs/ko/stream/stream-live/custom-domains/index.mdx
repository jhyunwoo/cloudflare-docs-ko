사용자 정의 ingest 도메인을 사용하면 RTMPS 피드를 구성하여 사용 대신 지정한 ingest URL을 사용할 수 있습니다.`live.cloudflare.com.`

:::참조

Custom Ingest Domains는 도메인을 구성할 수 없습니다.[지역 보유](/fundamentals/account/account-security/zone-holds/)지원하다

:::

1. Cloudflare dashboard에서, 가십시오**실시간 입력**사이트 맵

   <DashButton url="/?to=/:account/stream/inputs" />

2. 제품정보**계정 설정**, 위 목록. 더 보기**사용자 정의 입력 영역**페이지 표시.

3. 이름 \***이름 \***, 도메인 추가 및 선택**도메인 이름**.

4. DNS 공급자에서 CNAME 레코드를 추가하십시오.`live.cloudflare.com`. DNS 공급자가 Cloudflare인 경우에, 이 단계는 자동적으로 행해집니다.

DNS를 위해 Cloudflare를 사용하는 경우,[**프록시 상태**](/dns/proxy-status/)당신의 ingest 도메인은**DNS 전용**(grey-clouded).

## 사용자 정의 도메인 삭제

1. 에 의해**사용자 정의 입력 영역**내 계정**이름 \***, 도메인을 찾습니다.
2. 메뉴 아이콘을 선&#xD0DD;**- 연혁**. 선택**이름 \***.

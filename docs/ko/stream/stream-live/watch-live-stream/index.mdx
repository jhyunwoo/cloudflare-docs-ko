## 라이브 입력 ID 또는 비디오 ID로보기

Stream Player 또는 사용자 정의 플레이어를 사용 여부, 당신은 할 수 있습니다
reference 라이브 입력 ID 또는 특정 비디오 ID. 주요 차이점은 무엇입니까?
방송이 종료될 때 발생합니다.

플레이어가 항상 활성화되어야하는 인스턴스의 라이브 입력 ID를 사용하십시오.
방송, 하나가있는 경우, 또는 입력하면 "스트림이 시작되지 않았습니다" 메시지
아이들입니다. 이 옵션은 페이지가 제작자, 채널에 전념하는 경우 가장 좋습니다.
반복 프로그램. 라이브 입력 ID는 당신이 만들 때 당신에게 제공된다
입력; 그것은 바꾸지 않을 것입니다.

플레이어가 단일 디스플레이에 사용해야하는 인스턴스의 비디오 ID를 사용하십시오.
방송 또는 녹화 한 번 방송이 종료되었습니다. 이 옵션은 경우에 가장 좋습니다
페이지는 한 번의 이벤트, 특정 에피소드/관람, 또는 날짜에 전념 합니다.
있습니다.*새로운 소식*각 방송에 생성 된 비디오 ID*시작하면.*

아래 설명 된 DVR 모드를 사용하여 추가 고려 사항이 있습니다.

스트림의 URL은 쉬운 세대에 대한 모든 templatized :

**스트림 내장 플레이어 URL 형식 :**

```
https://customer-<CODE>.cloudflarestream.com/<INPUT_ID|VIDEO_ID>/iframe
```

전체 embed 코드는 Dash 또는 API로 생성될 수 있습니다.

**HLS Manifest URL 형식:**

```
https://customer-<CODE>.cloudflarestream.com/<INPUT_ID|VIDEO_ID>/manifest/video.m3u8
```

대시 또는 API에서 embed 코드 또는 URL을 검색할 수도 있습니다.

## API 사용

플레이어 코드 또는 API를 통해 URL을 검색하려면 라이브 입력을 fetch
동영상 목록:

```bash title="Request"
curl -X GET \
-H "Authorization: Bearer <API_TOKEN>" \
https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/stream/live_inputs/<LIVE_INPUT_UID>/videos
```

라이브 입력은 여러 비디오와 관련된, 각 방송에 대한 하나.
활성 방송이 있다면, 응답의 첫 번째 비디오는
`live-inprogress`이름 \* 응답의 다른 동영상은 녹음을 나타냅니다.
주문할 수 있습니다.

응답의 각 비디오, 활성 방송을 포함 한 경우,
HLS 및 DASH URL과 스트림 플레이어에 대한 링크가 포함되어 있습니다. 이름 \*
속성은 다음과 같습니다:

- `preview`-- 스트림 플레이어에 링크
- `playback`.`hls`-- HLS 매퍼
- `playback`.`dash`-- 대시 Manifest

## 실시간 입력 상태

라이브 입력이 현재 스트리밍과 그 활성화 여부를 확인할 수 있습니다.
비디오 ID는 요청에 따라`lifecycle`끝점. Stream 플레이어
입력이 안될 때 주의를 보여주는 것이 자동적으로 입니다. 사용자 정의
추가 지원이 필요할 수 있습니다.

```bash
curl -X GET \
-H "Authorization: Bearer <API_TOKEN>" \
https://customer-<CODE>.cloudflarestream.com/<INPUT_ID>/lifecycle
```

아래 예에서 응답은 나타냅니다.`ID`입력을 위한 Active`videoUID`·`live`상태 값은 입력이 적극적으로 스트리밍을 나타냅니다.

```json
{
	"isInput": true,
	"videoUID": "55b9b5ce48c3968c6b514c458959d6a",
	"live": true
}
```

```json
{
	"isInput": true,
	"videoUID": null,
	"live": false
}
```

라이브 입력 ID를 통해 라이브 스트림을 볼 때,`requireSignedURLs`·`allowedOrigins`라이브 입력 녹음 설정 옵션이 사용됩니다. 이 설정은 비디오 레벨 설정의 독립적입니다.

## 라이브 스트림 레코딩 재생

라이브 스트림 끝 후, 기록은 자동으로 생성되고 60 초 이내에 사용할 수 있습니다. 성공적인 비디오보기 및 재생을 보장하려면 다음을 염두에두고 :

- 스트림 플레이어를 사용하여 시청자가보고있는 동안 라이브 스트림 끝이 60 초를 기다릴 수 있고 플레이어가 라이브 스트림의 기록을 볼 수 있습니다.
- 라이브 스트림 종료 후 API를 통해 녹화의 상태를 확인할 수 있습니다. 비디오 상태가 될 때`ready`, 당신은 기록을 스트림하는 표시된 URL 중 하나를 사용할 수 있습니다.

라이브 스트림의 기록이 생성되는 동안, 비디오는보고 할 수 있습니다`not-found`또는`not-started`.

스트림 플레이어를 사용 하지 않는 경우 라이브 스트림 녹음, 참조[기록 및 재생 라이브 스트림](/stream/stream-live/replay-recordings/)라이브 스트림 레코딩을 재생하는 방법에 대한 자세한 내용은.

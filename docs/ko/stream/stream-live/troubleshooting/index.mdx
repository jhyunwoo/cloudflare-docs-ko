이 가이드의 라이브 스트림 문제 해결 단계 외에도 비디오 설정이 함께 정렬되도록하십시오.[Cloudflare 라이브 스트림 추천](/stream/stream-live/start-stream-live/#recommendations-requirements-and-limitations). 당신이 OBS를 사용하는 경우에, 당신은 또한 이것을 검사할 수 있습니다[OBS별 추천](/stream/examples/obs-from-scratch/#6-optional-optimize-settings).

## 버퍼링, 프리징, 그리고 지연

라이브 스트림이 버퍼링, 얼어붙고, 대기 문제 발생, 또는 다른 유사한 문제 발생, 이러한 문제 해결 단계 시도:

<Steps>
  1. Cloudflare dashboard에서, 갑니다**실시간 입력**사이트 맵

     <DashButton url="/?to=/:account/stream/inputs" />

  2. 실시간 입력을 위해, 선택**미터**탭.

  3. 너에게**Keyframe 간격**차트.

     그것은 2s와 8s 사이 체재하는 일관된 편평한 선이어야 합니다. 만약 당신이 inconsistent 또는 wavy 선을 보거나, 또는 2s 이상 또는 8s의 밑에 일관되게 하는 선은, 당신의 소프트웨어 또는 Cloudflare에 스트림을 보내기 위하여 이용된 서비스에서 keyframe 간격 (또한 GOP 크기를 부르는)를 조정합니다. 그 설정을 편집하기위한 정확한 단계는 플랫폼에 달려 있습니다.

     - keyframe 간격을 4s로 설정하여 시작합니다. 재생이 안정적이지만 대기 시간이 여전히 높으면 2s로 낮추십시오. 재생에서 버퍼링 또는 냉동을 경험하는 경우, 8s로 증가합니다.

     - keyframe 간격이 "variable"또는 "automatic"인 경우에, 대신 특정 번호로 바꾸십시오, 4s 같이.

     <Details header="키프레임 간격이란?">
       키프레임 간격 (또한 GOP 크기라고 함)은 종종 키프레임이 스트림으로 전송되는 측정입니다. 더 짧은 키 프레임 간격은 방송 측에 더 많은 인터넷 대역폭을 요구합니다, 그러나 유리에 유리에 유리 대기권을 감소시킬 수 있습니다. 더 긴 keyframe은 더 적은 인터넷 대역폭을 필요로 하고 버퍼링과 얼기를 감소시킬 수 있습니다, 그러나 유리에 유리 잔류물을 증가할 수 있습니다.
     </Details>

  4. 너에게**업로드 비율**차트.

     그것은 90% 이하 일관된 편평한 선이어야 합니다. 100% 이상의 일관성이 있는 선 또는 방수선을 볼 경우 다음 문제 해결 단계를 시도하십시오.

     - [인터넷 업로드 속도 확인](https://speed.cloudflare.com/)적어도 20 Mbps입니다. 20Mbps 미만인 경우 라우터를 재시작하거나 Wi-Fi 대신 이더넷 연결을 사용하거나 인터넷 서비스 공급자에게 연락하는 것과 같은 일반적인 문제 해결 단계를 사용합니다.

     - Cloudflare에 스트림을 보내려면 소프트웨어 또는 서비스에 비디오 비트레이트 설정을 확인하십시오.
       - "variable"이라면 8 Mbps와 같은 특정 번호로 "constant"로 변경하십시오.
       - 15 Mbps의 위인 경우에, 당신의 인터넷 속도의 8 Mbps 또는 70%에 더 낮은.

     - 위의 단계를 따르십시오 (키프레임 간격 단계)*지원하다*소프트웨어 또는 서비스에 있는 keyframe 간격은 Cloudflare에 스트림을 보낼 것을 사용합니다.

     <Details header="업로드 비율은 무엇입니까?">
       업로드-to-duration ratio는 몇 부분이 재생하는 방법에 비해 스트림의 일부를 업로드하는 데 걸리는 몇 가지 측정입니다. 100 % 미만의 비율은 스트림이 재생되기 때문에 적어도 업로드한다는 것을 의미하므로 대부분의 사용자는 버퍼링 또는 냉동을 경험하지 않아야합니다. 100 % 이상의 비율은 비디오를 재생하는 것보다 느리게 업로드한다는 것을 의미하므로 대부분의 사용자는 완충 및 냉동을 경험할 가능성이 높습니다.
     </Details>
</Steps>

## 연결 거부 또는 연결할 수 없습니다

방송 소프트웨어가 연결 오류 또는 스트림이 시작되면 실시간 입력이 활성화되었는지 확인합니다. 실시간 입력*이름 \**&#xBAA8;든 들어오는 연결을 거부합니다.

입력을 비활성화하거나 활성화 할 수 있습니다.**실시간 입력**목록 페이지 또는 Dashboard의 라이브 입력 세부 페이지.

<DashButton url="/?to=/:account/stream/inputs" />

API를 통해 실시간 입력 상태를 확인하고 업데이트하려면`enabled`이름:

```bash
curl -X GET \
--header "Authorization: Bearer <API_TOKEN>" \
https://api.cloudflare.com/client/v4/accounts/{account_id}/stream/live_inputs/{input_id}
```

이름 \*`enabled`이름 \*`false`응답에서, 그것을 가능하게 하는 살아있는 입력을 새롭게 하십시오:

```bash
curl --request PUT \
https://api.cloudflare.com/client/v4/accounts/{account_id}/stream/live_inputs/{input_id} \
--header "Authorization: Bearer <API_TOKEN>" \
--data '{"enabled": true}'
```

Cloudflare dashboardXQ에서 라이브 스트림 비디오를 다운로드 할 수 있습니다. 동영상은 다운로드 후 사용할 수 있습니다.**지원하다**국가.

:::참조

다운로드 가능한 MP4s는 4 시간 미만의 라이브 녹음에만 사용할 수 있습니다. 4시간을 초과하는 라이브 녹음은 나중에 재생할 수 있지만 MP4로 다운로드할 수 없습니다.

:::

1. Cloudflare dashboard에서, 가십시오**실시간 입력**사이트 맵

   <DashButton url="/?to=/:account/stream/inputs" />

2. 목록에서 라이브 입력을 선택합니다.

3. 이름 \***라이브 입력으로 만든 동영상**, 비디오를 선택하십시오.

4. 이름 \***계정 설정**, 선택**MP4 다운로드**.

5. 제품정보**제품 정보**. 비디오로 진행중인 바를 볼 수 있습니다. 다운로드 링크를 생성합니다.

6. 다운로드 링크가 준비되어 있을 때, 아래**URL을 다운로드**, URL을 복사하고 브라우저에서 비디오를 다운로드합니다.

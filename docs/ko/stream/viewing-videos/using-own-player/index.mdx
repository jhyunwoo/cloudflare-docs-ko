## Fetch HLS와 대시가 나타납니다.

### 사이트 맵

각 비디오 및 라이브 스트림은 자신의 독특한 HLS 및 DASH 나타났습니다. 대체로 표시할 수 있습니다.`<UID>`비디오 또는 라이브 입력의 UID, 및 교체`<CODE>`아래의 URL에서 고유한 고객 코드로:

```txt title="HLS"
https://customer-<CODE>.cloudflarestream.com/<UID>/manifest/video.m3u8
```

```txt title="DASH"
https://customer-<CODE>.cloudflarestream.com/<UID>/manifest/video.mpd
```

#### LL-HLS 재생<Badge text="Beta" variant="caution" size="small" />

Live Inputs가 Low-Latency HLS beta에 활성화되면 쿼리 문자열을 추가합니다.`?protocol=llhls`HLS는 사용자 정의 플레이어에서 낮은 대기 시간을 테스트하는 URL을 나타냅니다. 더 알아보기[라이브 스트림 시작](/stream/stream-live/start-stream-live/#use-the-api)이 옵션을 활성화합니다.

```txt title="HLS"
https://customer-<CODE>.cloudflarestream.com/<UID>/manifest/video.m3u8?protocol=llhls
```

## 사용 가능한 클라이언트 대역폭을 지정하여 표시를 사용자 정의

각 HLS 및 DASH는 비디오 또는 라이브 스트림의 여러 해상도를 제공합니다. 플레이어는 시청자의 사용 가능한 대역폭을 추정하기 위해 적응 비트레이트 논리를 포함하고, 플레이에 최적의 해상도를 선택합니다. 각 플레이어는이 결정을 내릴 수있는 다른 논리를 가지고 있으며 대부분의 구성 옵션이있어 대역폭 또는 해상도를 사용자 정의하거나 override 할 수 있습니다.

플레이어가 이러한 구성 옵션이 부족하거나 삭제해야하는 경우 추가 할 수 있습니다.`clientBandwidthHint`지정된 파일을 fetch 할 수 있도록 요청을 지정합니다. 이것은 마지막 리조트로만 사용되어야 합니다 — 우리는 당신의 선수에 의해 제공된 주문화 선택권을 사용하여 첫째로 추천합니다. 웹 사이트 또는 앱을 빠른 인터넷 연결에 개발할 수 있지만, 고품질 재생을 강제하기 위해이 설정을 사용하도록 유혹하고, 많은 시청자가 느린 모바일 네트워크에 연결할 가능성이 있습니다.

- `clientBandwidthHint`팟캐스트
  - 제공된 대역폭 값(Mbps에서)에 가까운 비디오 표현만 반환합니다. 이것은 특정한 품질 수준을 시행하기 위하여 사용될 수 있습니다. 유효하지 않은 또는 비어있는 표시를 일으키는 값을 지정하면, hint는 무시됩니다.

아래 예제를 참조하여 비디오 표현을 비트레이트로 1.8 Mbps로 표시합니다.

```txt title="Example"
https://customer-f33zs165nr7gyfy4.cloudflarestream.com/6b9e68b07dfee8cc2d116e4c51d6a957/manifest/video.m3u8?clientBandwidthHint=1.8
```

## 기본 앱에서 라이브 비디오를 1 초 미만의 대기 시간으로 재생

매우 낮은 대기 시간이 필요하면, 사용자들은 기본 앱에서 라이브 비디오를 볼 수 있습니다.[**1 초 미만의 유리 투 유리 지연**](https://blog.cloudflare.com/magic-hdmi-cable/)재생을 위한 SRT 또는 RTMPS를 사용하여,.

![Cloudflare 네트워크를 통해 SRT 및 RTMPS 재생을 보여주는 다이어그램](~/assets/images/stream/stream-rtmps-srt-playback-magic-hdmi-cable.png)

SRT 및 RTMPS 재생은 내장[인기 카테고리](https://ffmpeg.org/). 당신은 당신의 자신의 비디오 플레이어와 함께 ffmpeg을 통합해야합니다 — 도[AVPlayer (이오스)](/stream/viewing-videos/using-own-player/ios/)이름 \*[ExoPlayer (안드로이드)](/stream/viewing-videos/using-own-player/android/)기본적으로 SRT 또는 RTMPS 재생을 지원합니다.

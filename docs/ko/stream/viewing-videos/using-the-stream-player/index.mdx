Cloudflare는 주문형 비디오 및 라이브 비디오를 모두 재생할 수있는 맞춤형 웹 플레이어를 제공하며, 추가 엔지니어링 작업을 필요로합니다.

<figure data-type="stream">
  <div class="AspectRatio" style="--aspect-ratio: calc(16 / 9)">
    <iframe class="AspectRatio--content" src="https://iframe.videodelivery.net/5d5bc37ffcf54c9b82e996823bffbb81?mute=true" style="border: none" frame-border="0" allow="accelerometer; gyroscope; autoplay; encrypted-media; picture-in-picture;" allow-full-screen />
  </div>
</figure>

Stream Player를 웹 페이지로 추가하려면 다음을 할 수 있습니다.

- 임베디드 코드를 생성**사이트 맵**Cloudflare QXdashboardXQ의 페이지는 특정한 영상 또는 살아있는 입력을 위해 입니다.

  <DashButton url="/?to=/:account/stream/videos" />

- 아래 코드 예제를 사용하여 교체`<VIDEO_UID>`비디오 UID (또는[관련 토큰](/stream/viewing-videos/securing-your-stream/))와`<CODE>`Stream Dashboard에서 찾을 수있는 독특한 고객 코드와 함께.

```html
<iframe
	src="https://customer-<CODE>.cloudflarestream.com/<VIDEO_UID>/iframe"
	style="border: none"
	height="720"
	width="1280"
	allow="accelerometer; gyroscope; autoplay; encrypted-media; picture-in-picture;"
	allowfullscreen="true"
></iframe>
```

스트림 플레이어도 사용할 수 있습니다.[React](https://www.npmjs.com/package/@cloudflare/stream-react)또는[이름 \*](https://www.npmjs.com/package/@cloudflare/stream-angular)부품.

## 브라우저 호환성

### 제품정보

- 크롬: 버전 88 이상
- Firefox: 버전 87 이상
- 가장자리: 버전 89 이상
- Safari: 버전 14 이상
- 오페라 : 버전 75 이상

:::참조

Cloudflare 스트림은 Chromium에서 사용할 수 없습니다, 크롬은 H.264 비디오를 지원하지 않습니다.

:::

### 제품 정보

- Android의 크롬 : 버전 90
- Android의 UC 브라우저 : 버전 12.12 이상
- 삼성 인터넷 : 버전 13 이상
- iOS의 Safari : 버전 13.4 이상 (풀 스크린에 없을 때 지원되는 속도 선택기)

## 선수 크기

### 고정 치수

견적 요청`height`·`width`속성에`iframe`호스트 페이지에 표시된 iframe의 픽셀 값 크기를 변경합니다.

```html
<iframe
	src="https://customer-<CODE>.cloudflarestream.com/<VIDEO_UID>/iframe"
	style="border: none"
	height="400"
	width="400"
	allow="accelerometer; gyroscope; autoplay; encrypted-media; picture-in-picture;"
	allowfullscreen="true"
></iframe>
```

### 책임감

iframe 응답을 만들기 위해 스타일은 측면 비율을 조정하여 스타일을 필요로합니다.`iframe`으로`position: absolute;`계산 된 컨테이너를 채우고`padding-top`비율.

```html
<!--패딩 탑 계산은 높이 / 폭 (16 : 9 종횡비)-->
<div style="position: relative; padding-top: 56.25%">
	<iframe
		src="https://customer-<CODE>.cloudflarestream.com/<VIDEO_UID>/iframe"
		style="border: none; position: absolute; top: 0; height: 100%; width: 100%"
		allow="accelerometer; gyroscope; autoplay; encrypted-media; picture-in-picture;"
		allowfullscreen="true"
	></iframe>
</div>
```

## 기본 옵션

Player 옵션은 iframe의 쿼리 문자열 매개 변수로 구성됩니다.`src`이름 \* 예를 들면:

`https://customer-<CODE>.cloudflarestream.com/<VIDEO_UID>/iframe?autoplay=true&muted=true`

- `autoplay`기본 :`false`
  - autoplay 플래그가 쿼리 문자열 매개 변수로 포함되면 플레이어는 비디오를 autoplay하려고합니다. autoplay에 비디오를 원하지 않는 경우, autoplay 플래그를 전혀 포함하지 마십시오 (설정에서 설정할 수 있음)`autoplay=false`.) 모바일 브라우저는 일반적으로이 속성을 지원하지 않는 참고, 사용자는 화면을 탭하여 비디오 재생을 시작합니다. 인터넷 사용 제한으로 모바일 사용자 또는 사용자를 고려하십시오. 일부 사용자는이 속성을 사용하기 전에 무제한 인터넷 액세스를 가지고 있지 않습니다.

    :::카트로션

    일부 브라우저는 자동으로 재생에서 오디오로 비디오를 방지합니다. 설정할 수 있습니다.`muted`으로`true`비디오를 autoplay로 허용하십시오. 더 많은 정보를 원하시면, 참조[- 한국어`<video>`iOS용 정책](https://webkit.org/blog/6784/new-video-policies-for-ios/).

    :::

- `controls`기본 :`true`
  - 재생/쉼, 볼륨 컨트롤 버튼과 같은 비디오 컨트롤을 표시합니다.

- `defaultTextTrack`
  - 지정된 언어 코드의 텍스트 트랙을 사용하여 플레이어를 초기화합니다. 값은 사용 된 BCP-47 언어 코드이어야합니다.[텍스트 트랙 업로드](/stream/edit-videos/adding-captions/). 지정된 언어 코드가 사용할 수없는 경우, 플레이어는 언어 코드가 제공되지 않았기 때문에 행동합니다.

    :::카트로션

    이것은*한국어*초기화 중에 한 번 작업. 사용자가 텍스트 트랙 설정에 대한 전체 제어가 있습니다.

    :::

- `letterboxColor`
  - 모든 유효한[CSS 색상 값](https://developer.mozilla.org/en-US/docs/Web/CSS/color_value)제공된 플레이어 UI의 Letterboxing/pillarboxing에 적용 됩니다. 설정할 수 있습니다.`transparent`fullscreen 형태에 없을 때 Letterboxing/pillarboxing를 피하십시오.

    :::참조

    **참고 :**&#xBAA8;든 쿼리 문자열 매개 변수처럼, 이 값*지원하다*URI 인코딩. 예를 들어 색상 값`hsl(120 80% 95%)`JavaScript`encodeURIComponent()`기능에`hsl(120%2080%25%2095%25)`.

    :::

- `loop`기본 :`false`
  - 플레이어를 활성화하면 자동으로 비디오의 끝에 도달 할 때 시작을 다시 추구합니다.

- `muted`기본 :`false`
  - 설정하면 오디오가 초기 침묵됩니다.

- `preload`기본 :`none`
  - 이 열렬한 옵션은 저자가 가장 좋은 사용자 경험으로 이어지는 것에 대한 브라우저에 힌트를 제공하는 것입니다. 값을 지정할 수 있습니다.`preload="auto"`비디오의 시작을 미리로드합니다. 옵션 또는 사용 제외`preload="metadata"`요청 시 비디오 재생을 시작할 필요가 있는 메타데이터를 로드합니다.

    :::참조

    더 보기`<video>`요소는이 옵션의 가치를 따르는 브라우저를 강제하지 않습니다; 그것은 단지 힌트입니다. 비록`preload="none"`옵션은 유효한 HTML5 옵션이며, 스트림 플레이어는 항상 플레이어를 초기화하기 위해 메타 데이터를로드합니다. 이 경우에 적재된 자료의 양은 negligible 입니다.

    :::

- `poster`기본적으로 비디오의 첫 번째 프레임에
  - 동영상이 시작되거나 비디오가 다운로드되는 동안 이미지에 대한 URL. 이 속성이 지정되지 않은 경우, 비디오의 썸네일 이미지가 표시됩니다.

    :::참조

    **참고 :**&#xBAA8;든 쿼리 문자열 매개 변수처럼, 이 값*지원하다*URI 인코딩. 예를 들어, thumbnail at`https://customer-f33zs165nr7gyfy4.cloudflarestream.com/6b9e68b07dfee8cc2d116e4c51d6a957/thumbnails/thumbnail.jpg?time=1s&height=270`JavaScript`encodeURIComponent()`기능에`https%3A%2F%2Fcustomer-f33zs165nr7gyfy4.cloudflarestream.com%2F6b9e68b07dfee8cc2d116e4c51d6a957%2Fthumbnails%2Fthumbnail.jpg%3Ftime%3D1s%26height%3D600`.

    :::

- `primaryColor`
  - 모든 유효한[CSS 색상 값](https://developer.mozilla.org/en-US/docs/Web/CSS/color_value)제공된 플레이어 UI의 특정 요소에 적용 됩니다.

    :::참조

    **참고 :**&#xBAA8;든 쿼리 문자열 매개 변수처럼, 이 값*지원하다*URI 인코딩. 예를 들어 색상 값`hsl(120 80% 95%)`JavaScript`encodeURIComponent()`기능에`hsl(120%2080%25%2095%25)`.

    :::

- `src`
  - 동영상에서 Cloudflare 스트림에 업로드했습니다.

- `startTime`
  - 재생이 시작될 때 시간을 지정하는 타임스탬프. 일반 번호가 같은 경우`?startTime=123`, 그것은 해석될 것입니다`123`초. 더 인간 읽기 쉬운 타임스탬프는 또한 사용될 수 있습니다,`?startTime=1h12m27s`제품 정보`1 hour, 12 minutes, and 27 seconds`.

- `ad-url`
  - 스트림 플레이어는 VAST를 지원합니다 prerolls와 같은 광고를 삽입하는 태그. VAST 태그 URI가있는 경우, Stream Player에 전달할 수 있습니다.`ad-url`모수. URI는 JavaScript's와 같은 기능을 사용하여 인코딩되어야 합니다`encodeURIComponent()`.

## Debug 정보

스트림 플레이어 디버그 메뉴는 키 조합을 사용하여 표시되고 숨겨질 수 있습니다.`Shift-D`비디오가 연주하는 동안.

## 라이브 스트림 레코딩 재생

라이브 스트림 끝 후, 기록은 자동으로 생성되고 60 초 이내에 사용할 수 있습니다. 성공적인 비디오보기 및 재생을 보장하려면 다음을 염두에두고 :

- 라이브 스트림이 보면서 시청자는 60 초를 기다리고 플레이어를 다시로드하여 라이브 스트림의 녹음을 볼 수 있습니다.
- 라이브 스트림 종료 후 API를 통해 녹화의 상태를 확인할 수 있습니다. 비디오 상태가 될 때`ready`, 당신은 기록을 스트림하는 표시된 URL 중 하나를 사용할 수 있습니다.

라이브 스트림의 기록이 생성되는 동안, 비디오는보고 할 수 있습니다`not-found`또는`not-started`.

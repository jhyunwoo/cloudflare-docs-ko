[Response Header Transform Rules](/rules/transform/response-header-modification/)를 사용하면 크롤러가 차단된 경우에도 크롤러 응답에 `Link` 헤더를 추가할 수 있습니다. 이를 통해 이용 약관이나 [RSL](https://rslstandard.org/) 라이선스 정보를 전달할 수 있습니다.

## 예시: 차단된 응답에 라이선스 조건 추가

<Example>

**표현식:**

```txt
(cf.bot_management.verified_bot and http.response.code eq 403)
```

**헤더 수정:**

- **작업:** 정적 값 설정
- **헤더 이름:** `Link`
- **값:** `<https://example.com/ai-licensing-terms>; rel="license"; type="text/html"`

</Example>

[Response Header Transform Rules](/rules/transform/response-header-modification/)에 대한 자세한 내용도 참고하세요.

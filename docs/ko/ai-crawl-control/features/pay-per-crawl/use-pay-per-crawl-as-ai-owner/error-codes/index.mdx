크롤당 결제 오류 응답에는 특정 오류 코드가 담긴 `crawler-error` 헤더가 포함됩니다. 아래 표는 가능한 모든 오류 코드의 전체 참조를 제공합니다.

| 오류 코드                  | HTTP 상태 | 조치 방법                                                                                                                                                  |
| -------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CrawlerForbidden`         | 403       | 사이트 소유자가 현재 크롤러를 차단했습니다. 이 콘텐츠에는 접근할 수 없습니다.                                                                             |
| `StrongAuthRequired`       | 400       | 요청에 강한 인증이 포함된 유효한 Web Bot Auth 헤더를 포함하세요.                                                                                          |
| `InvalidSignature`         | 400       | 요청에 `signature-input` 과 `signature` 헤더를 모두 포함하세요. [Web Bot Auth documentation](/bots/reference/bot-verification/web-bot-auth/)를 참고하세요. |
| `InvalidCrawlerPriceValue` | 400       | `crawler-exact-price` 또는 `crawler-max-price` 헤더 값의 형식이 올바른지 확인하세요(예: `USD 0.01`).                                                     |
| `MissingCrawlerPrice`      | 402       | 요청에 `crawler-exact-price` 또는 `crawler-max-price` 헤더 중 하나를 포함하세요.                                                                          |
| `PaymentFailed`            | 403       | Pay Per Crawl 설정에서 결제 처리가 올바르게 구성되었는지 확인하세요. 문제가 계속되면 Cloudflare 지원팀에 문의하세요.                                      |
| `InvalidCrawlerExactPrice` | 402       | `crawler-exact-price` 를 응답 헤더의 `crawler-price` 값과 일치하도록 업데이트하세요.                                                                      |
| `InvalidCrawlerMaxPrice`   | 402       | 응답 헤더의 `crawler-price` 값을 충족하거나 초과하도록 `crawler-max-price` 를 높이세요.                                                                   |
| `ConflictingPriceHeaders`  | 400       | 요청당 하나의 가격 헤더만 사용하세요. `crawler-max-price` 또는 `crawler-exact-price` 중 하나를 제거하세요.                                               |
| `InvalidContentPrice`      | 502       | 원본 서버가 잘못된 가격을 반환했습니다. 이는 사이트 소유자 측 구성 문제입니다. 나중에 다시 시도하거나 사이트 소유자에게 문의하세요.                       |
| `InternalError`            | 500       | 서버 오류가 발생했습니다. 지수 백오프로 요청을 재시도하세요.                                                                                               |

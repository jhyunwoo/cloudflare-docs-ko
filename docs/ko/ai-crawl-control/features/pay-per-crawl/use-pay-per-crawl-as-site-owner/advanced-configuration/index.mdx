## URI 패턴으로 Pay Per Crawl 비활성화

일부 페이지에는 무료 액세스를 제공하고, 다른 페이지에는 과금하고 싶을 수 있습니다.

- 크롤러가 유료 콘텐츠를 발견할 수 있도록 **홈페이지, 카테고리 페이지 또는 내비게이션**에는 무료 액세스를 허용합니다.
- 과금 가능한 콘텐츠가 없는 **로그인, 검색 또는 API 엔드포인트** 같은 기능성 페이지는 제외합니다.
- 확장하기 전에 사이트의 **작은 섹션 하나**에 먼저 Pay Per Crawl을 적용해 시작합니다.
- **프로모션 콘텐츠나 아카이브 콘텐츠**에는 무료 액세스를 제공하고, 프리미엄 아티클에는 과금합니다.

시작하려면 [Configuration Rules](/rules/configuration-rules/)를 사용해 특정 URI 패턴을 과금 대상에서 제외하세요.

1. Cloudflare 대시보드에서 **Rules** > **Overview**로 이동합니다.

   <DashButton url="/?to=/:account/:zone/rules/overview" />

2. **Create rule** > **Configuration Rule**을 선택합니다.

3. **When incoming requests match**에서 URI 패턴을 설정합니다.
   - Field: `URI Full`
   - Operator: `wildcard`
   - Value: `https://*example.com/public/*`

4. **Disable Pay Per Crawl** > **Add**를 선택합니다.

5. **Deploy**를 선택합니다.

**예시 패턴:**

- 무료 홈페이지: `URI Full` equals `https://example.com/`
- 무료 디렉터리: `URI Full` wildcard `https://*example.com/public/*`

:::note
일부 경로는 항상 무료로 크롤링할 수 있습니다. 해당 경로는 `/robots.txt`, `/sitemap.xml`, `/security.txt`, `/.well-known/security.txt`, `/crawlers.json` 입니다.
:::

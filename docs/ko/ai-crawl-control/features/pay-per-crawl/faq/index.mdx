## 사이트 소유자를 위한 자주 묻는 질문

### AI 크롤러별로 다른 가격을 설정할 수 있나요?

아니요. 크롤당 결제에서는 각 크롤러마다 서로 다른 작업(차단, 과금, 허용)을 구성할 수 있지만, "과금" 옵션으로 설정된 모든 크롤러에 공통으로 적용되는 단일 가격만 설정할 수 있습니다.

## AI 봇 운영자를 위한 자주 묻는 질문

### 같은 페이지를 다시 크롤링해도 요금이 부과되나요?

예. AI 크롤러가 크롤당 결제로 보호되는 웹사이트의 콘텐츠에 접근할 때마다 사이트 소유자가 설정한 비용이 발생합니다. 크롤러 내부에 지출을 추적하고 원하는 지출 한도를 강제하는 메커니즘을 구현해야 합니다.

일부 경로는 항상 무료로 크롤링할 수 있습니다. 해당 경로는 `/robots.txt`, `/sitemap.xml`, `/security.txt`, `/.well-known/security.txt`, `/crawlers.json` 입니다.

### 오류 응답에도 요금이 부과되나요?

아니요. 과금 이벤트는 성공적인 HTTP 응답 코드에 대해서만 발생합니다. `crawler-exact-price` 또는 `crawler-max-price` 헤더를 보냈더라도 오류 응답에는 요금이 청구되지 않습니다.

### 어떤 user agent를 사용해야 하나요?

Cloudflare에 온보딩되었고 Web Bot Auth를 통해 식별되는, 해당 AI 크롤러에 연결된 표준 user agent를 사용하세요.

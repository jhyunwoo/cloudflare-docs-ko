AI Crawl Control 분석 데이터는 Cloudflare의 [GraphQL Analytics API](/analytics/graphql-api/)를 통해 사용할 수 있습니다. 대시보드에 표시되는 것과 동일한 데이터를 쿼리하여 맞춤 보고서를 만들고, 모니터링 시스템과 통합하거나, 분석용으로 내보낼 수 있습니다. [GraphQL API Explorer](https://graphql.cloudflare.com/)로 쿼리를 테스트하거나, [Chrome DevTools](/analytics/graphql-api/tutorials/capture-graphql-queries-from-dashboard/)를 사용해 대시보드가 실제로 사용하는 정확한 쿼리를 캡처할 수 있습니다.

## 주요 필터

| 필터                              | 설명                                                                                           | 사용 가능 여부                                       |
| --------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `requestSource: "eyeball"`        | 실제 클라이언트 요청만 포함합니다. Cloudflare 내부 트래픽은 제외됩니다.                        | 모든 요금제                                          |
| `userAgent_like: "%...%"`         | [사용자 에이전트](/ai-crawl-control/reference/bots/)로 필터링합니다. 스푸핑될 수 있습니다.     | 모든 요금제                                          |
| `edgeResponseStatus_geq` / `_lt`  | HTTP 상태 코드 범위로 필터링합니다.                                                            | 모든 요금제                                          |
| `clientRequestPath_like: "%...%"` | URL 경로 패턴으로 필터링합니다.                                                                | 모든 요금제                                          |
| `clientRefererHost_like: "%...%"` | [리퍼러 도메인](/ai-crawl-control/reference/bots/#referrer-domains-by-operator)으로 필터링합니다. | 유료 요금제만 가능                                   |
| `botDetectionIds_hasany: [...]`   | [탐지 ID](/ai-crawl-control/reference/bots/)로 필터링합니다. Cloudflare가 신뢰성 있게 검증합니다. | [Bot Management](/bots/get-started/bot-management/) |

## 쿼리 예시

<Details header="탐지 ID를 사용해 시간대별 AI 크롤러 요청 가져오기">

```graphql
{
	viewer {
		zones(filter: { zoneTag: "<ZONE_ID>" }) {
			httpRequestsAdaptiveGroups(
				filter: {
					datetime_geq: "2027-01-01T00:00:00Z"
					datetime_leq: "2027-01-02T00:00:00Z"
					requestSource: "eyeball"
					# 123815556 = GPTBot, 132995013 = ChatGPT-User, 126255384 = OAI-SearchBot
					botDetectionIds_hasany: [123815556, 132995013, 126255384]
				}
				limit: 5000
			) {
				count
				dimensions {
					datetimeHour
					botDetectionIds
					clientRequestHTTPHost
				}
				sum {
					edgeResponseBytes
				}
			}
		}
	}
}
```

</Details>

<Details header="사용자 에이전트를 사용해 시간대별 AI 크롤러 요청 가져오기">

```graphql
{
	viewer {
		zones(filter: { zoneTag: "<ZONE_ID>" }) {
			httpRequestsAdaptiveGroups(
				filter: {
					datetime_geq: "2027-01-01T00:00:00Z"
					datetime_leq: "2027-01-02T00:00:00Z"
					requestSource: "eyeball"
					userAgent_like: "%GPTBot%"
				}
				limit: 5000
			) {
				count
				dimensions {
					datetimeHour
					userAgent
					clientRequestHTTPHost
				}
				sum {
					edgeResponseBytes
				}
			}
		}
	}
}
```

</Details>

<Details header="가장 많이 크롤링된 경로 가져오기">

```graphql
{
	viewer {
		zones(filter: { zoneTag: "<ZONE_ID>" }) {
			httpRequestsAdaptiveGroups(
				filter: {
					datetime_geq: "2027-01-01T00:00:00Z"
					datetime_leq: "2027-01-02T00:00:00Z"
					requestSource: "eyeball"
					edgeResponseStatus_geq: 200
					edgeResponseStatus_lt: 400
					userAgent_like: "%GPTBot%"
				}
				limit: 5000
				orderBy: [count_DESC]
			) {
				count
				dimensions {
					clientRequestPath
					clientRequestHTTPHost
				}
			}
		}
	}
}
```

</Details>

<Details header="AI 리퍼럴 트래픽 가져오기">

```graphql
{
	viewer {
		zones(filter: { zoneTag: "<ZONE_ID>" }) {
			httpRequestsAdaptiveGroups(
				filter: {
					datetime_geq: "2027-01-01T00:00:00Z"
					datetime_leq: "2027-01-02T00:00:00Z"
					requestSource: "eyeball"
					OR: [
						{ clientRefererHost_like: "%.chatgpt.com%" }
						{ clientRefererHost: "chatgpt.com" }
						{ clientRefererHost_like: "%.perplexity.ai%" }
						{ clientRefererHost: "perplexity.ai" }
					]
				}
				limit: 5000
				orderBy: [count_DESC]
			) {
				count
				dimensions {
					datetimeHour
					clientRefererHost
				}
			}
		}
	}
}
```

</Details>

<Details header="크롤러별 데이터 전송량 가져오기">

```graphql
{
	viewer {
		zones(filter: { zoneTag: "<ZONE_ID>" }) {
			httpRequestsAdaptiveGroups(
				filter: {
					datetime_geq: "2027-01-01T00:00:00Z"
					datetime_leq: "2027-01-02T00:00:00Z"
					requestSource: "eyeball"
					userAgent_like: "%GPTBot%"
				}
				limit: 5000
				orderBy: [sum_edgeResponseBytes_DESC]
			) {
				count
				dimensions {
					userAgent
				}
				sum {
					edgeResponseBytes
				}
			}
		}
	}
}
```

</Details>

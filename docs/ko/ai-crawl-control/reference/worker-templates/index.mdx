[AI Crawl Control 분석 데이터](/ai-crawl-control/features/analyze-ai-traffic/)를 사용해 어떤 크롤러가 사이트에 접근하는지 식별한 다음, 해당 트래픽을 처리하는 방식을 사용자 지정할 수 있도록 Worker 템플릿을 배포하세요.

## x402 결제 게이트 프록시

x402-proxy 템플릿은 [x402 protocol](https://www.x402.org/)을 사용한 결제 게이트 접근을 구현합니다. 이는 HTTP 402(Payment Required)를 중심으로 구축된 개방형 결제 표준입니다. 이를 사용해 크롤러 접근을 수익화하고, 특정 경로에 페이월을 적용하거나, 사람 사용자에게는 무료로 열어두면서 봇에는 과금할 수 있습니다.

설정 지침과 Bot Management 통합 예시는 [GitHub의 템플릿](https://github.com/cloudflare/templates/tree/main/x402-proxy-template)을 참조하세요.

## 제한 사항

Cloudflare에 gRPC 트래픽을 실행하는 것은 대부분의 Cloudflare 제품과 호환됩니다.

그러나 다음 제품은 gRPC 요청으로 제한된 기능을 가지고 있습니다.

- 더 보기[Cloudflare WAF](/waf/)연결 단계 도중 우두머리 검사를 위해만 달릴 것입니다. 모델 번호: WAF 관리 규칙은 gRPC 스트림의 내용에 실행되지 않습니다.
- <Render file="tunnel/grpc-support" product="cloudflare-one" />
- [모델 번호: Cloudflare 오시는 길](/cloudflare-one/access-controls/policies/)Cloudflare의 역 프록시를 통해 전송된 gRPC 트래픽을 지원하지 않습니다. gRPC 트래픽은 Cloudflare에서 gRPC가 활성화되면 액세스에 의해 무시됩니다. 액세스에 의해 보호되는 모든 민감한 기원 서버에 대한 GRPC를 비활성화하거나 원래 서버에 gRPC 트래픽을 인증하는 다른 방법을 활성화하는 것이 좋습니다.

## 사용 가능한 gRPC

### 제품 정보

- gRPC 엔드포인트는 포트 443을 듣아야 합니다.
- gRPC 엔드포인트는 TLS와 HTTP/2를 지원해야 합니다.
- HTTP/2는 ALPN에 광고되어야 합니다.
- 제품 정보`application/grpc`또는`application/grpc+<message type`(예:`application/grpc+proto`)에 대한**내용 유형**gRPC 요청 헤더.
- gRPC 엔드포인트를 호스트하는 호스트명 확인:
  - 설정하기[뚱 베어](/dns/proxy-status/)
  - 적어도 사용[SSL/TLS 암호화 모드](/ssl/origin-configuration/ssl-modes/full/).

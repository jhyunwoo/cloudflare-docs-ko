IP 위치 추가[`CF-IPCountry`기타 제품](/fundamentals/reference/http-headers/#cf-ipcountry)당신의 근원 서버에 모든 요구.

Cloudflare는 주 당 그것의 IP 위치 데이타베이스를 다수 새롭게 합니다.

## IP 위치 정보 추가

IP Geolocation 정보를 사용할 수있는 권장 절차는[지원하다**자주 묻는 질문**관리 Transform](/rules/transform/managed-transforms/reference/#add-visitor-location-headers). 이 관리된 Transform는 도시의 국가, 대륙, 경도 및 위도와 같은 방문자의 IP 주소를 위한 위치 정보를 가진 HTTP 요구 우두머리를 추가합니다.

방문자 국가의 요청 헤더를 원하면 활성화 할 수 있습니다.**IP 위치**.

## 잘못된 IP 위치를 보고하십시오

당신이 믿는 위치와 IP 주소를 찾을 경우 잘못된, 채우기[데이터 보정 폼](https://www.cloudflare.com/lp/ip-corrections/)관련 IP 주소 범위 (s)와 함께 적절한 정보 (국가, 국가 / 지방, 도시 이름 및 ZIP 코드).

데이터가 확인되면 Cloudflare는 48 시간 이내에 반영되어야하는 필요한 변경을 할 것입니다.

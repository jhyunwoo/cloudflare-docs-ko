Onion Routing을 가능하게하여 Tor 사용자 경험을 향상시키며 Cloudflare를 활성화하여 Tor 네트워크를 통해 웹 사이트의 콘텐츠를 직접 제공하고 종료 노드를 필요로하지 않고도 제공합니다.

## 어떻게 작동합니까?

Onion Routing은 Tor 브라우징을 다음과 같이 개선합니다.

- Tor 사용자는 더 이상 종료 노드를 통해 사이트에 액세스 할 수 없습니다. 때때로 손상 될 수 있으며 사용자 트래픽에 스누프가있을 수 있습니다.
- 한국어 Tor 사용자 및 봇은 상호 작용하는 도전과 같은 Onion 서비스에 의해 구별될 수 있습니다.

[사이트 맵](https://tb-manual.torproject.org/about/)사용자 수신[alt-svc 헤더](https://httpwg.org/specs/rfc7838.html#alt-svc)웹 사이트에 첫 번째 요청에 대한 응답의 일부로. 브라우저는 Tor Circuit을 사용하여이 웹 사이트에 액세스합니다.`.onion`이 헤더에 의해 제공되는 TLD 서비스.

사용자 인터페이스에서 눈에 보이는 도메인이 변경되지 않도록주의해야하며 호스트 헤더와 SNI가 보존됩니다. 그러나 Tor를 통해 경로를 변경할 수 있습니다.[주소 표시의 왼쪽에 UI 표시](https://tb-manual.torproject.org/managing-identities/#managing-identities)Tor 회로로. Cloudflare는 증명서를 제공하지 않습니다`.onion`도메인은 alt-svc 흐름의 일부로 제공되므로 HTTPS를 통해 액세스 할 수 없습니다.

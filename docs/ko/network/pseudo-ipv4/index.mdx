Cloudflare 고객은 사용할 수 있습니다**Pseudo의 IPv4**그들의 기원 웹 서버가 IPv4 포맷 된 IP 주소를 이해하는 경우 (그것은 Cloudflare의 기본을 지원하지 않을 것입니다)[IPv6 호환성](/network/ipv6-compatibility/)).

## 이름 \*

일부 오래된 소스 서버 분석 및 사기 탐지 소프트웨어는 IPv4 형식으로 IP 주소를 기대하고 IPv6 주소를 지원하지 않습니다.

**Pseudo의 IPv4**사용 방법[클래스 E IPv4 주소 공간](https://tools.ietf.org/html/rfc1112#section-4)IPv6 주소와 호환되는 많은 고유 IPv4 주소를 제공할 수 있습니다.

- 클래스 E IPv4 주소 예:`240.16.0.1`
- IPv6 주소 예:`2400:cb00:f00d:dead:beef:1111:2222:3333`

:::참조

Class E IPv4 주소는 실험적으로 지정되며 사용되지 않습니다.
생산 인터넷 트래픽을 위해.
주요 특징

## Pseudo IPv4 구성

Cloudflare는 구성을 위한 3개의 선택권을 제안합니다**Pseudo의 IPv4**:

- **이름 \***: 기본 값.
- **헤더를 추가**: Cloudflare 자동으로 추가`Cf-Pseudo-IPv4`클래스 E IPv4 주소로 헤더는 원래 IPv6 주소에서 해시됩니다.
- **Headers를 덮기**: <Render file="pseudo-ipv4-warning" product="fundamentals" />

:::참조

사용 방법*Headers를 덮기*, 소프트웨어 변경은 필요하지 않습니다
당신의 근원 웹 서버.

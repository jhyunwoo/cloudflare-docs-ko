인간적인 의견은 AI 모형의 성과를 평가하는 귀중한 미터입니다. 인간의 피드백을 통합함으로써 모델의 응답이 인식되고 사용자 중심의 관점에서 어떻게 수행 할 수 있습니다. 이 피드백은 성능 메트릭, 운전 최적화 및 궁극적으로 AI 응용 프로그램의 신뢰성, 정확도 및 효율성을 강화하는 평가에서 사용할 수 있습니다.

인간적인 의견은 직접적인 인간적인 입력에 근거를 둔 당신의 dataset의 성과를 측정합니다. 미터는 Cloudflare QXQX대시보드의 로그 탭에 할당 된 로그에 주어진 긍정적 인 피드백의 비율로 계산됩니다. 이 피드백은 출력의 실제 평가를 고려하여 모델 성능이 향상됩니다.

이 튜토리얼은 Cloudflare 대시보드를 사용하여 AI Gateway의 평가에 대한 인간의 피드백을 추가하는 과정을 안내합니다.

다음 가이드에서, 당신은 할 수 있습니다[API를 통해 인간의 피드백을 추가하는 방법 알아보기](/ai-gateway/evaluations/add-human-feedback-api/).

## 1. 대시보드에 로그인

Cloudflare 대시보드에서, 가십시오**AI 게이트웨이**사이트 맵

<DashButton url="/?to=/:account/ai/ai-gateway" />

## 2. 로그 탭에 액세스

1. 오시는 길**로그인**.
2. 로그 탭은 데이터셋과 관련된 모든 로그를 표시합니다. 이 로그는 다음과 같은 주요 정보를 보여줍니다:
   - Timestamp: 상호 작용이 발생했을 때.
   - 상태: 요청이 성공했는지 여부, 캐시 또는 실패.
   - 모델: 요청에 사용되는 모델.
   - 토큰: 응답에 의해 소비 된 토큰 수.
   - 비용: 토큰 사용에 근거한 비용.
   - 기한: 응답을 완료하는 데 걸리는 시간.
   - 상표: 각 로그에 대한 인간 피드백을 제공 할 수 있습니다.

## 3. 인간의 피드백 제공

1. 자주 묻는 질문 이 로그를 확장, 더 자세한 정보를 볼 수 있습니다.
2. 확장 로그에서 다음과 같은 추가 정보를 볼 수 있습니다:
   - 사용자 안내
   - 모델 응답.
   - HTTP 응답 세부사항.
   - Endpoint 정보.
3. 두 아이콘을 볼 수 있습니다:
   - Thumbs up: 긍정적 인 피드백을 나타냅니다.
   - 엄지 아래로: 부정적인 의견을 나타냅니다.
4. 특정 로그 항목에 대한 모델 응답을 평가하는 방법을 기준으로 엄지 또는 엄지 아래로 아이콘을 클릭합니다.

## 4. 인간적인 의견 Evaluate

로그인에 대한 피드백을 제공 한 후 평가 프로세스의 일부가됩니다.

평가를 실행할 때 (밖으로 정렬됨)[평가 설정](/ai-gateway/evaluations/set-up-evaluations/)가이드), 인간적인 의견 미터는 thumbs-up 의견을 받는 통나무의 백분율을 기준으로 산출될 것입니다.

:::주\[주]

evaluator로 인간의 피드백을 선택하여 메트릭을 수신해야합니다.

:::

## 5. 리뷰 결과

평가를 실행한 후, 평가 탭의 결과를 검토합니다.
당신은 비용, 속도, 그리고 지금 인간적인 의견에 근거를 둔 모형의 성과를 볼 수 있을 것입니다, 긍정적인 의견의 비율로 대표되는 (위험).

인간의 피드백 점수는 데이터베이스에서 긍정적으로 평가 된 응답의 배포를 보여주는 비율로 표시됩니다.

실행 평가에 대한 자세한 내용은 문서 참조[평가 설정](/ai-gateway/evaluations/set-up-evaluations/).

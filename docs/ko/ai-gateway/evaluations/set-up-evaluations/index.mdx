이 가이드는 AI Gateway에서 평가를 설정하는 과정을 통해 걸어갑니다. 이 단계는[Cloudflare 대시보드](https://dash.cloudflare.com/).

## 1. Dataset 선택 또는 생성

Datasets는 평가에서 사용할 수있는 분석에 저장된 로그 모음입니다. Logs 탭에 필터를 적용하여 datasets를 만들 수 있습니다. Datasets는 설정 필터를 기반으로 자동으로 업데이트됩니다.

### Logs 탭에서 dataset 설정

1. 필터를 사용하여 로그를 축소합니다. 필터 옵션은 공급자, 토큰 수, 요청 상태 및 더 많은 것을 포함합니다.
2. 제품정보**Dataset 만들기**미래 분석을위한 필터 된 로그를 저장합니다.

선택하여 datasets를 관리할 수 있습니다.**Datasets 관리**로그 탭에서.

:::주\[주]

datasets가 현재 사용 중인 것을 염두에 두고 있습니다.`AND`가입, 그래서 필터 당 하나의 항목 (예를 들어, 하나의 모델 또는 하나의 공급자). 미래 업데이트는 dataset 생성에 더 많은 유연성을 허용합니다.

:::

## 2. 선택 증발기

dataset 만들기 후에, 평가 모수를 선택하십시오:

- 비용: dataset 내의 inference 요청의 평균 비용 계산 (만 요청과[비용 데이터](/ai-gateway/observability/costs/)).
- 속도: dataset 내의 inference 요청의 평균 기간을 계산합니다.
- 성과:
  - 인간적인 의견: 인간적인 의견에 근거를 둔 성과는, 통나무 탭에서 주석으로 입힌 통나무의 %에 의해 산출됩니다.

:::주\[주]

추가 evaluators는 성능 분석 기능을 확장하기 위해 미래 업데이트에 도입 될 것입니다.

:::

## 3. 이름, 검토 및 평가를 실행

1. 참고 자료XQ에 대한 평가에 대한 독특한 이름을 대시보드XQ.
2. 선택한 데이터 세트 및 증발기를 검토합니다.
3. 제품정보**지원하다**프로세스를 시작합니다.

## 4. 결과 검토 및 분석

평가 결과는 평가 탭에 표시됩니다. 결과는 평가의 상태를 보여줍니다 (예를 들면, 진행, 완료, 또는 오류). 선택된 증발기를 위한 미터는 표시될 것입니다, 누락된 분야를 가진 어떤 통나무를 제외하고. 각 미터를 계산하는 데 사용되는 로그 수를 볼 수 있습니다.

datasets가 자동으로 필터를 기반으로 업데이트하는 동안, 평가는 하지 않습니다. 새로운 로그를 평가하려는 경우 새로운 평가를 만들 수 있습니다.

이러한 통찰력을 사용하여 응용 프로그램의 우선 순위를 기반으로 최적화합니다. 결과에 따라, 당신은 선택할 수 있습니다:

- 모형을 바꾸거나[회사 소개](/ai-gateway/usage/providers/)
- 당신의 신속한 조정
- 더 많은 최적화를 살펴보세요.[Retrieval 증강 발생 (RAG)](/reference-architecture/diagrams/ai/ai-rag/)

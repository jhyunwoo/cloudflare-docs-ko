[감사 로그](/fundamentals/account/account-security/review-audit-logs/)CloudflareQ 계정 내에서 생성된 변경 사항을 종합적으로 제공합니다. 이 기능은 모든 플랜 유형에 사용할 수 있으며, 무료이며, 기본적으로 활성화됩니다.

## 보기 감사 로그

Cloudflare 대시보드XQ에서 AI 게이트웨이에 대한 감사 로그를 보시려면**감사 로그**사이트 맵

<DashButton url="/?to=/:account/audit-log" />

액세스 및 사용 감사 로그에 대한 자세한 내용은 참조[리뷰 감사 로그 문서](/fundamentals/account/account-security/review-audit-logs/).

## 로그아웃

다음 구성 작업은 로그입니다:

| - 연혁         | 이름 \*          |
| ------------ | -------------- |
| 비밀번호         | 새로운 게이트웨이의 창조. |
| 비밀번호         | 기존의 출입구의 삭제.   |
| Gateway 업데이트 | 기존 게이트웨이의 편집.  |

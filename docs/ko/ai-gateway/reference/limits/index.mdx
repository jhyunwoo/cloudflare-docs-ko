다음 제한은 Cloudflare의 플랫폼의 게이트웨이 구성, 로그 및 관련 기능에 적용됩니다.

## Gateway 및 로그 제한

| 제품 정보                                                              | 지원하다                     |
| ------------------------------------------------------------------ | ------------------------ |
| [Cacheable 요구 크기](/ai-gateway/features/caching/)                   | 요구에 의하여 25 MB            |
| [캐시 TTL](/ai-gateway/features/caching/#cache-ttl-cf-aig-cache-ttl) | 1 개월                     |
| [주문 metadata](/ai-gateway/observability/custom-metadata/)          | 요청 당 5 항목                |
| [데이터셋](/ai-gateway/evaluations/set-up-evaluations/)                | 게이트 당 10                 |
| 게이트웨이 무료 플랜                                                        | 계정 당 10                  |
| Gateways 유료 플랜                                                     | 계정 당 20                  |
| Gateway 이름 길이                                                      | 64자                      |
| 로그 저장 속도 제한                                                        | 게이트 당 초당 500 로그          |
| 로그 저장[지불 계획](/ai-gateway/reference/pricing/)                       | 게이트 당 10 백만<sup>1</sup>  |
| 로그 저장[무료 플랜](/ai-gateway/reference/pricing/)                       | 계정 당 100,000<sup>2</sup> |
| [로그 크기 저장](/ai-gateway/observability/logging/)                     | 로그당 10MB<sup>3</sup>     |
| [Logpush 작업](/ai-gateway/observability/logging/logpush/)           | 계정 당 4                   |
| [Logpush 크기 제한](/ai-gateway/observability/logging/logpush/)        | 로그인 당 1MB                |

<sup>1</sup>게이트웨이에 저장된 10 백만 로그에 도달하면 새로운 로그
저장됩니다. 로그를 계속 저장하려면 이전 로그를 삭제해야합니다.
이 게이트웨이는 공간을 해방하거나 새로운 게이트웨이를 만듭니다. 더 알아보기[자동 로그인
회사 소개](/ai-gateway/observability/logging/#auto-log-cleanup)더 많은 정보
자동으로 로그를 삭제하는 방법.

<sup>2</sup>계정 당 100,000 로그에 도달 한 경우, 모든
Gateway, 새로운 로그가 저장됩니다. 로그를 계속 저장하려면, 당신은해야합니다
이전 로그를 삭제합니다. 더 알아보기[자동 로그인
회사 소개](/ai-gateway/observability/logging/#auto-log-cleanup)더 많은 정보
자동으로 로그를 삭제하는 방법.

<sup>3</sup>10MB 미만의 로그가 저장되지 않습니다.

## DLP 제한

[사이트맵](/ai-gateway/features/dlp/)AI Gateway는 공유[모델 번호: Cloudflare DLP 프로필](/cloudflare-one/data-loss-prevention/dlp-profiles/). 다음 제한은 계정 수준에서 DLP 프로파일 및 탐지 항목에 적용됩니다.

<Render file="data-loss-prevention/dlp-limits-table" product="cloudflare-one" />

DLP 프로필은 Cloudflare 하나는 개별 출입구에 결합되지 않습니다. 추가 프로파일 제한 없이 여러 개의 게이트웨이에서 동일한 DLP 프로파일을 적용할 수 있습니다. 게이트웨이 당 DLP 정책의 수에 별도의 제한이 없습니다.

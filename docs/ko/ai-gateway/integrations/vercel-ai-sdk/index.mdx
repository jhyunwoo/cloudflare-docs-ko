더 보기[Vercel AI SDK를](https://sdk.vercel.ai/)AI 응용 프로그램을 구축하기위한 TypeScript 라이브러리입니다. SDK는 다양한 AI 제공업체, 스트리밍 완료 도구 등을 지원합니다.
Vercel AI SDK를 사용하여 Cloudflare AI 게이트웨이를 사용하려면 사용해야합니다.`ai-gateway-provider`패키지.

## 설치하기

```bash
npm install ai-gateway-provider
```

### Fallback 공급자

모델 또는 공급자를 지정하려면 요청 실패를 처리하고 신뢰성을 보장하기 위해 모델의 배열을 전달할 수 있습니다.`model`옵션.

```js title=""
const { text } = await generateText({
  model: aigateway([
		openai.chat("gpt-5.1"), anthropic("claude-sonnet-4-5")
  ]),
  prompt: 'Write a vegetarian lasagna recipe for 4 people.',
});
```

AI Gateway는 다양한 헤더를 지원하여 구성, 사용자 정의 및 API 요청을 관리합니다. 이 페이지는 짧은 설명과 함께 지원된 모든 헤더의 전체 목록을 제공합니다.

<Glossary product="ai-gateway" />

## 구성 hierarchy

AI Gateway의 설정은 세 가지 수준에서 설정할 수 있습니다.**회사 소개**, **제품 정보**·**오시는 길**. 동일한 설정이 여러 위치에서 구성될 수 있기 때문에 다음과 같은 계층은 값이 적용된 것을 결정합니다.

1. **공급자 수준 headers**::
   관련 만 사용할 때[범용 엔드포인트](/ai-gateway/usage/universal/), 이 우두머리는 다른 모든 윤곽에 전진합니다.
2. **요청 레벨 헤더**::
   공급자 수준의 헤더가 설정되지 않는 경우 적용하십시오.
3. **Gateway-level 설정**::
   헤더가 공급자 또는 요청 수준에서 설정된 경우 기본값으로 동작합니다.

이 계층은 일관된 행동을 보장, 가장 특정 구성 우선. 공급자 수준 및 요청 레벨 헤더를 사용하여 더 미세 조정 컨트롤 및 일반 기본값의 게이트웨이 설정.

AI Gateway에 대한 크레딧을 로드하려면:

1. Cloudflare 대시보드에서, 가십시오**AI 게이트웨이**사이트 맵

   <DashButton url="/?to=/:account/ai/ai-gateway" />

   더 보기**크레딧 사용**오른쪽 상단의 카드는 현재 계정에있는 많은 AI 게이트웨이 크레딧을 보여줍니다.

2. 내 계정**크레딧 사용**, 선택**계정 관리**.

3. 계정이 사용 가능한 지불 방법이 없다면, AI Gateway는 신용을 구입하는 지불 방법을 추가 할 것입니다. 결제 방법 추가.

4. 제품정보**Top-up 크레딧**.

5. 구매하려는 크레딧의 금액을 추가, 다음 선택**확인 및 지불**.

### 자동 정상 위로

AI Gateway를 구성하여 특정 임계값을 떨어뜨릴 때 자동으로 크레딧을 보충할 수 있습니다. 자동 top-up을 구성하려면:

1. Cloudflare 대시보드에서, 가십시오**AI 게이트웨이**사이트 맵

   <DashButton url="/?to=/:account/ai/ai-gateway" />

2. 내 계정**크레딧 사용**, 선택**계정 관리**.

3. 제품정보**자동 Top-up 크레딧 설정**.

4. 임계값과 자동 상부에 대한 충전량 선택.

설정 임계값 아래 잔액이 떨어지면 AI 게이트웨이가 자동으로 계정으로 자동 최고 수준의 금액을 적용합니다.

## 사용 Unified Billing

API Key를 통과하지 않고 지원되는 공급자에게 전화하십시오. 요청은 자동으로 계정에서 Cloudflare의 키와 공제 크레딧을 사용합니다.

예를 들어 Unified API를 사용할 수 있습니다.

```bash
curl -X POST https://gateway.ai.cloudflare.com/v1/$CLOUDFLARE_ACCOUNT_ID/default/compat/chat/completions \
  --header "cf-aig-authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "google-ai-studio/gemini-2.5-pro",
    "messages": [
      {
        "role": "user",
        "content": "What is Cloudflare?"
      }
    ]
  }'
```

더 보기`default`게이트웨이는 첫 번째 요청에 자동으로 생성됩니다. 기타 제품`default`이미 만든 경우 특정 게이트웨이 ID로.

### 제한 사항

적재된 크레딧에 예상치 못한 비용을 방지하기 위해 지출 제한을 설정합니다. 일일, 주간 또는 월간 제한을 정의 할 수 있습니다. 제한이 도달되면 AI Gateway는 주기가 리셋될 때까지 처리 요청을 자동으로 중지하거나 제한을 증가시킵니다.

### 제로데이터 보유 (ZDR)

Zero Data Retention (ZDR)는 신속한 응답을 유지하지 않는 공급자 엔드포인트를 통해 빌링 트래픽을 통합했습니다. Gateway-level에 적용`zdr`설정, ZDR-capable 업스트림 제공 업체 구성에 맵. 이 설정은 Cloudflare-managed credentials를 사용하는 통합 청구 요청에만 적용됩니다. BYOK 또는 기타 AI 게이트웨이 요청에 적용하지 않습니다.

ZDR는 AI Gateway 로깅을 제어하지 않습니다. AI Gateway에서 요청/response 로깅을 비활성화하려면 로그인 설정을 별도로 업데이트하십시오.[로그아웃](/ai-gateway/observability/logging/).

ZDR는 현재 지원됩니다:

- [오시는 길](/ai-gateway/usage/providers/openai/)
- [인기 카테고리](/ai-gateway/usage/providers/anthropic/)

ZDR가 지원하지 않는 공급자를 위해 활성화되면, AI Gateway는 표준 (non-ZDR)에 다시 떨어지지 않는 빌링 구성.

#### Per-request override (이제한)`cf-aig-zdr`)

사용 방법`cf-aig-zdr`header to override the Gateway default for a single Unified Billing request. 설정하기`true`힘 ZDR, 또는`false`요청에 대한 ZDR를 비활성화합니다.

```bash title="Unified Billing request with ZDR"
curl -X POST https://gateway.ai.cloudflare.com/v1/$CLOUDFLARE_ACCOUNT_ID/{gateway_id}/openai/chat/completions \
  --header "cf-aig-authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  --header 'Content-Type: application/json' \
  --header 'cf-aig-zdr: true' \
  --data '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": "Explain Zero Data Retention."
      }
    ]
  }'
```

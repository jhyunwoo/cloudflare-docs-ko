Guardrails 현재 사용[라마 가드 3 8B](https://ai.meta.com/research/publications/llama-guard-llm-based-input-output-safeguard-for-human-ai-conversations/)에 의해[모델 번호: Workers AI](/workers-ai/)콘텐츠 평가를 실시합니다. 아래 모델은 미래에 업데이트 될 수 있으며, 가드 레일 내에서 이러한 변화를 반영합니다.

가드 레일이 Workers AIXQ에서 실행되기 때문에 Workers AIXQ에 대한 사용 권한을 부여합니다. Workers AI Dashboard를 통해 사용량을 모니터링 할 수 있습니다.

## 자주 묻는 질문

- **모델 가용성**: 적어도 하나의 위험 범주가 설정되면`block`, 그러나 AI 출입구는 Workers AI에서 응답을 받을 수 없습니다, 요구는 막을 것입니다. 위험 범주가 설정되면`flag`AI 게이트웨이는 Workers AI의 응답을 얻을 수 없습니다, 요청은 평가없이 진행됩니다. 이 접근법은 가용성을 우선시하며, 콘텐츠 평가가 불가능할 때 계속 요청할 수 있습니다.
- **공급 능력**: Guardrails가 일부 대기 시간을 추가합니다. Enabling Guardrails는 요청에 대한 추가 대기 시간을 소개합니다. 일반적으로 Workers AIXQ에 Llama Guard 3 8B를 사용하여 평가는 요청에 따라 약 500 밀리 초를 추가합니다. 그러나 더 큰 요청은 증가 된 대기 시간을 경험할 수 있지만이 증가는 선형이 아닙니다. 안전과 성능을 균형을 잡을 때 이것을 고려하십시오.
- **취급 긴 내용**: 긴 프롬프트 또는 응답을 평가 할 때, 가드 레일은 별도의 가드 레일 요청을 통해 각 처리하는 작은 덩크로 콘텐츠를 자동으로 구분합니다. 이 접근법은 포괄적인 형태를 보장하지만 더 긴 입력에 대한 증가 된 대기 시간에서 발생할 수 있습니다.
- **지원 언어**: Llama Guard 3.3 8B는 다음 언어로 콘텐츠 안전 분류를 지원합니다. 영어, 프랑스어, 독일어, 힌디어, 이탈리아어, 포르투갈어, 스페인어, 태국어.
- **고객지원**: Guardrails를 사용할 때 스트리밍이 지원되지 않습니다.

:::참조

Llama Guard는 어떤 표현, 보증, 또는 보증 없이 제공됩니다. 블로그, 개발자 문서 또는 기타 참고 자료 자료에 포함된 모든 규칙 또는 예는 정보 목적으로만 제공됩니다. AI Gateway의 사용의 결과 및 결과에 대한 책임을 인정하고 이해합니다.

:::

AI Gateway's Guardrails는 AI 모델의 유형을 사용 하 고 적용 안전 검사에 따라:

- **텍스트 생성 모델**: 신속한 및 응답 모두 평가됩니다.
- **Embedding 모델**: 응답으로만 평가됩니다. 수치를 나타내는 수치를 나타내는 수치입니다.
- **알려진 모델**: 모델 유형이 결정될 수 없는 경우, 프롬프트만 평가되며, 응답 바이패스 가드레일즈가 됩니다.

:::주\[주]

Guardrails는 아직 스트리밍 응답을 지원하지 않습니다. 스트리밍 지원은 향후 업데이트 계획입니다.

:::

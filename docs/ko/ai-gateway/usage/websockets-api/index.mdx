AI Gateway WebSockets API는 AI 상호 작용을 위한 지속적인 연결을 제공하고 반복된 Handhakes를 제거하고 대기 시간을 감소시킵니다. 이 API는 두 가지 범주로 나뉩니다.

- **실시간 API**- WebSockets에서 저속성, 다중화 상호 작용을 제공하는 AI 공급자를 위해 디자인했습니다.
- **비 실시간 API**- WebSockets를 기본적으로 지원하지 않는 사람들을 포함하여 AI 공급자를 위한 표준 WebSocket 커뮤니케이션을 지원합니다.

## WebSockets를 사용할 때

WebSocket은 클라이언트와 서버 간의 양방향, 실시간 및 비 실시간 통신을 가능하게 하는 오랜 TCP 연결입니다. WebSockets는 각 요청에 대한 반복적인 Handhakes가 필요한 HTTP 연결과는 달리, 지속적인 데이터 교환이 감소된 오버 헤드를 지원합니다. WebSockets는 음성 조수와 같은 저경도, 실시간 데이터가 필요한 응용 분야에 이상적입니다.

## 주요 혜택

- **감소된 머리**: 반복된 Handhakes와 TLS 협상의 overhead를 단 하나, 지속적인 연결을 유지해서 피하십시오.
- **공급자 호환성**: AI Gateway의 모든 AI 공급자와 함께 작동합니다. 선택한 공급자가 WebSockets를 지원하지 않는 경우에도 Cloudflare는 선호하는 AI 공급자에게 요청을 관리합니다.

| :------------ | :-------------------------------------------------------------------------------------------------- | :----------------------------------------------------- |

| **사용 사례**     | 음성, 비디오 및 실시간 상호 작용에 대한 응답 스트리밍.                                                                    | LLM 요청과 같은 텍스트 기반 쿼리 및 응답.                             |
| **AI 공급자 지원** | [실시간 WebSocket APIs 제공 업체에 한정.](/ai-gateway/usage/websockets-api/realtime-api/#supported-providers) | [AI Gateway의 모든 AI 공급자.](/ai-gateway/usage/providers/) |

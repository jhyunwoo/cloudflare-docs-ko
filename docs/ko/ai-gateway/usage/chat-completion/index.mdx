Cloudflare의 AI 게이트웨이는 OpenAI 호환`/chat/completions`endpoint는 단일 URL을 사용하여 여러 AI 공급자와 통합할 수 있습니다. 이 기능은 통합 프로세스를 단순화하고 중요한 코드 수정없이 다른 모델 간의 원활한 전환을 가능하게합니다.

## 엔드포인트 URL

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/default/compat/chat/completions
```

기타 제품`{account_id}`Cloudflare 계정 ID로. 더 보기`default`게이트웨이는 첫 번째 요청에 자동으로 생성됩니다 — 설치가 필요하지 않습니다. 당신은 또한 대체 할 수 있습니다`default`이미 만든 경우 특정 게이트웨이 ID로.

## 매개 변수

전환 제공업체`model`·`apiKey`모수.

모델 지정`{provider}/{model}`파일 형식. 예를 들면:

- `openai/gpt-5-mini`
- `google-ai-studio/gemini-2.5-flash`
- `anthropic/claude-sonnet-4-5`

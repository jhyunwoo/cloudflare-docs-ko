[관련 제품](https://parallel.ai/)AI를 위한 웹 API 목적 건축은, 최소 복권과 증거 근거한 결과를 가진 생산 독서 산출을 제공하.

## 끝점

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/parallel
```

## URL 구조

병렬을 요청할 때, AI Gateway를 통해 병렬 엔드포인트를 통해 경로에 접근할 수 있습니다.`parallel`. 예를 들어, Tasks API에 접근하기`/v1/tasks/runs`, 사용:

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/parallel/v1/tasks/runs
```

## 자주 묻는 질문

병렬에 요청을 만들 때, 다음을해야합니다:

- AI Gateway 계정 ID.
- AI Gateway 게이트웨이 이름.
- Active Parallel API 키입니다.

## 이름 \*

### 작업 API

더 보기[작업 API](https://docs.parallel.ai/task-api/task-quickstart)포괄적인 연구 및 분석 작업을 만들 수 있습니다.

#### cURL 예제

```bash
curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/parallel/v1/tasks/runs \
  --header 'x-api-key: {parallel_api_key}' \
  --header 'Content-Type: application/json' \
  --data '{
    "input": "Create a comprehensive market research report on the HVAC industry in the USA including an analysis of recent M&A activity and other relevant details.",
    "processor": "ultra"
  }'
```

### 검색 API

더 보기[검색 API](https://docs.parallel.ai/search-api/search-quickstart)configurable 매개변수로 고급 검색을 가능하게 합니다.

#### cURL 예제

```bash
curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/parallel/v1beta/search \
  --header 'x-api-key: {parallel_api_key}' \
  --header 'Content-Type: application/json' \
  --data '{
    "objective": "When was the United Nations established? Prefer UN'\''s websites.",
    "search_queries": [
      "Founding year UN",
      "Year of founding United Nations"
    ],
    "processor": "base",
    "max_results": 10,
    "max_chars_per_result": 6000
  }'
```

## 채팅 API

더 보기[채팅 API](https://docs.parallel.ai/chat-api/chat-quickstart)AI Gateway의 Unified Chat Completions API를 통해 지원됩니다. 자세한 내용은 아래를 참조하십시오:

<Render
  file="chat-completions-providers"
  product="ai-gateway"
  params={{
  	name: "Parallel",
  	jsonexample: `
{
  "model": "parallel/{model}"
}`

  }}
/>

#### JavaScript SDK 예제

```js
import OpenAI from "openai";

const apiKey = "{parallel_api_key}";
const accountId = "{account_id}";
const gatewayId = "{gateway_id}";
const baseURL = `https://gateway.ai.cloudflare.com/v1/${accountId}/${gatewayId}/compat`;

const client = new OpenAI({
	apiKey,
	baseURL,
});

try {
	const model = "parallel/speed";
	const messages = [{ role: "user", content: "Hello!" }];
	const chatCompletion = await client.chat.completions.create({
		model,
		messages,
	});
	const response = chatCompletion.choices[0].message;
	console.log(response);
} catch (e) {
	console.error(e);
}
```

### 모든 API 찾기

더 보기[모든 API 찾기](https://docs.parallel.ai/findall-api/findall-quickstart)복잡한 쿼리에서 구조화된 데이터 추출이 가능합니다.

#### cURL 예제

```bash
curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/parallel/v1beta/findall/ingest \
  --header 'x-api-key: {parallel_api_key}' \
  --header 'Content-Type: application/json' \
  --data '{
    "query": "Find all AI companies that recently raised money and get their website, CEO name, and CTO name."
  }'
```

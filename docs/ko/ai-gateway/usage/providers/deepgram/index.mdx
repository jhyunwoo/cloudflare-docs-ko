[딥그램](https://developers.deepgram.com/home)Speech AI APIs for Speech-to-text, text-to-speech 및 음성 에이전트를 제공합니다.

:::참조

Deepgram는 또한 Workers AI를 통해서 유효합니다, 보기[그림 Workers AI](/ai-gateway/usage/websockets-api/realtime-api/#deepgram-workers-ai).

:::

## 끝점

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/deepgram
```

## URL 구조

Deepgram에 요청을 만들 때, 교체`https://api.deepgram.com/`현재 사용중인 URL에서`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/deepgram/`.

## 자주 묻는 질문

Deepgram에 요청을 만들 때 다음을 수행하십시오.

- AI Gateway 계정 ID.
- AI Gateway 게이트웨이 이름.
- Active Deepgram API 토큰.

### SDK 지원

```ts title="TS"
import { createClient, LiveTranscriptionEvents } from "@deepgram/sdk";


const deepgram = createClient("{deepgram_api_key}", {
    global: {
      websocket: {
        options: {
          url: "wss://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/deepgram/",
          _nodeOnlyHeaders: {
            "cf-aig-authorization": "Bearer {CF_AIG_TOKEN}"
          }
        }
      }
    }
});


const connection = deepgram.listen.live({
    model: "nova-3",
    language: "en-US",
    smart_format: true,
});

connection.send(...);
```

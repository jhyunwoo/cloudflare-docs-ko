[구매하기](https://replicate.com/)오픈 소스 모델을 실행하고 미세 조정합니다.

## 끝점

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/replicate
```

## URL 구조

Replicate에 요청을 만들 때, 교체`https://api.replicate.com/v1`현재 사용중인 URL에서`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/replicate`.

## 자주 묻는 질문

Replicate에 요청을 만들 때 다음을 수행하십시오.

- AI Gateway 계정 ID.
- AI Gateway 게이트웨이 이름.
- 활성 Replicate API 토큰. 당신은 하나에서 만들 수 있습니다[replicate.com/설정/api-tokens](https://replicate.com/settings/api-tokens)
- 사용하려는 복제 모델의 이름, 같은`anthropic/claude-4.5-haiku`또는`google/nano-banana`.

## 이름 \*

### 사이트맵

```bash title="Request"
curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/replicate/predictions \
  --header 'Authorization: Bearer {replicate_api_token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "version": "anthropic/claude-4.5-haiku",
    "input":
      {
        "prompt": "Write a haiku about Cloudflare"
      }
    }'
```

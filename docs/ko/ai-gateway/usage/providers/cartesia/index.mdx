[카테고리](https://docs.cartesia.ai/)customizable 음성 모형을 가진 진보된 text-to-speech 서비스를 제공합니다.

## 끝점

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/cartesia
```

## URL 구조

Cartesia에 요청을 할 때, 교체`https://api.cartesia.ai/v1`현재 사용중인 URL에서`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/cartesia`.

## 자주 묻는 질문

Cartesia에 요청을 할 때 다음을해야합니다.

- AI Gateway 계정 ID.
- AI Gateway 게이트웨이 이름.
- 활성 Cartesia API 토큰.
- 사용하려는 Cartesia 음성 모델에 대한 모델 ID 및 음성 ID.

## 이름 \*

### 사이트맵

```bash title="Request"
curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/cartesia/tts/bytes \
  --header 'Content-Type: application/json' \
  --header 'Cartesia-Version: 2024-06-10' \
  --header 'X-API-Key: {cartesia_api_token}' \
  --data '{
    "transcript": "Welcome to Cloudflare - AI Gateway!",
    "model_id": "sonic-english",
    "voice": {
        "mode": "id",
        "id": "694f9389-aac1-45b6-b726-9d9369183238"
    },
    "output_format": {
        "container": "wav",
        "encoding": "pcm_f32le",
        "sample_rate": 44100
    }
}
```

[Azure 오픈AI](https://azure.microsoft.com/en-gb/products/ai-services/openai-service/)데이터에 자연스러운 언어 알고리즘을 적용할 수 있습니다.

## 끝점

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/azure-openai/{resource_name}/{deployment_name}
```

## 자주 묻는 질문

Azure OpenAI에 요청을 만들면 다음이 필요합니다.

- AI 게이트웨이 계정 ID
- AI Gateway Gateway 이름
- Azure OpenAI API 키
- Azure OpenAI 리소스 이름
- Azure OpenAI 배포 이름 (aka model name)

## URL 구조

새로운 기본 URL은 이 구조에서 위의 데이터를 사용합니다.`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/azure-openai/{resource_name}/{deployment_name}`. 그런 다음 기본 URL의 끝에 엔드포인트와 api-version을 추가 할 수 있습니다.`.../chat/completions?api-version=2023-05-15`.

## 이름 \*

### 사이트맵

```bash title="Example fetch request"
curl 'https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway}/azure-openai/{resource_name}/{deployment_name}/chat/completions?api-version=2023-05-15' \
  --header 'Content-Type: application/json' \
  --header 'api-key: {azure_api_key}' \
  --data '{
  "messages": [
    {
      "role": "user",
      "content": "What is Cloudflare?"
    }
  ]
}'
```

### 제품 정보`openai`JavaScript SDK는

```js title="JavaScript"
import { AzureOpenAI } from "openai";

const azure_openai = new AzureOpenAI({
  apiKey: "{azure_api_key}",
  baseURL: `https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway}/azure-openai/{resource_name}/`,
  apiVersion: "2023-05-15",
  defaultHeaders: { "cf-aig-authorization": "{cf-api-token}" }, //인증된 경우
});

const result = await azure_openai.chat.completions.create({
  model: '{deployment_name}',
  messages: [{ role: "user", content: "Hello" }],
});
```

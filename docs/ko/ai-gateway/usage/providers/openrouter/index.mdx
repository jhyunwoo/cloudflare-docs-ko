[열린Router](https://openrouter.ai/)큰 언어 모델 (LLMs)을 사용하여 액세스 및 사용하기위한 통합 인터페이스를 제공하는 플랫폼입니다.

## 끝점

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openrouter
```

## URL 구조

요청을 할 때[열린Router](https://openrouter.ai/), 교체`https://openrouter.ai/api/v1/chat/completions`현재 사용중인 URL에서`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openrouter/chat/completions`.

## 자주 묻는 질문

OpenRouter에 요청을 만들 때 다음을 가지고:

- AI Gateway 계정 ID.
- AI Gateway 게이트웨이 이름.
- Active OpenRouter API 토큰 또는 원래 모델 공급자로부터 토큰.
- 사용하려는 OpenRouter 모델의 이름.

## 이름 \*

### 사이트맵

```bash title="Request"
curl -X POST https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openrouter/v1/chat/completions \
 --header 'content-type: application/json' \
 --header 'Authorization: Bearer OPENROUTER_TOKEN' \
 --data '{
    "model": "openai/gpt-5-mini",
    "messages": [
        {
            "role": "user",
            "content": "What is Cloudflare?"
        }
    ]
}'

```

### JavaScriptXQ와 OpenAI SDK 사용

JavaScriptXQ를 가진 OpenAI SDK를 사용하는 경우에, 당신은 이 같이 당신의 endpoint를 놓을 수 있습니다:

```js title="JavaScript"
import OpenAI from "openai";

const openai = new OpenAI({
	apiKey: env.OPENROUTER_TOKEN,
	baseURL:
		"https://gateway.ai.cloudflare.com/v1/ACCOUNT_TAG/GATEWAY/openrouter",
});

try {
	const chatCompletion = await openai.chat.completions.create({
		model: "openai/gpt-5-mini",
		messages: [{ role: "user", content: "What is Cloudflare?" }],
	});

	const response = chatCompletion.choices[0].message;

	return new Response(JSON.stringify(response));
} catch (e) {
	return new Response(e);
}
```

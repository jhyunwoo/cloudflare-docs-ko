[스낵 바](https://inference-docs.cerebras.ai/)AI Model inference를 위한 저전력 솔루션 제공

## 끝점

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/cerebras
```

## 자주 묻는 질문

Cerebras에 요청을 할 때 다음을해야합니다.

- AI Gateway 계정 ID.
- AI Gateway 게이트웨이 이름.
- 활성 Cerebras API 토큰.
- 사용하려는 Cerebras 모델의 이름.

## 이름 \*

### 사이트맵

```bash title="Example fetch request"
curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/cerebras/chat/completions \
 --header 'content-type: application/json' \
 --header 'Authorization: Bearer CEREBRAS_TOKEN' \
 --data '{
    "model": "llama3.1-8b",
    "messages": [
        {
            "role": "user",
            "content": "What is Cloudflare?"
        }
    ]
}'
```

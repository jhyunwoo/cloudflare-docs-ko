[카테고리](https://huggingface.co/)사용자가 구축, 배포 및 훈련 기계 학습 모델을 돕습니다.

## 끝점

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/huggingface
```

## URL 구조

HuggingFace Inference API에 요청을 만들 때, 대체`https://api-inference.huggingface.co/models/`현재 사용중인 URL에서`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/huggingface`. 당신이 접근을 시도하는 모델은 예를 들어, 오른쪽에 있어야합니다`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/huggingface/bigcode/starcoder`.

## 자주 묻는 질문

HuggingFace에 요청을 할 때 다음을해야합니다.

- AI Gateway 계정 ID.
- AI Gateway 게이트웨이 이름.
- 활성 HuggingFace API 토큰.
- 사용하려는 HuggingFace 모델의 이름.

## 이름 \*

### 사이트맵

```bash title="Request"
curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/huggingface/bigcode/starcoder \
  --header 'Authorization: Bearer {hf_api_token}' \
  --header 'Content-Type: application/json' \
  --data '{
    "inputs": "console.log"
}'
```

### JavaScriptXQ

HuggingFace.js 라이브러리를 사용 중인 경우 다음과 같은 inference endpoint를 설정할 수 있습니다.

```js title="JavaScript"
import { HfInferenceEndpoint } from "@huggingface/inference";

const accountId = "{account_id}";
const gatewayId = "{gateway_id}";
const model = "gpt2";
const baseURL = `https://gateway.ai.cloudflare.com/v1/${accountId}/${gatewayId}/huggingface/${model}`;
const apiToken = env.HF_API_TOKEN;

const hf = new HfInferenceEndpoint(baseURL, apiToken);
```

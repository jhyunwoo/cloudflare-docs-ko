[미스트랄 AI](https://mistral.ai)Mistral의 고급 AI 모델로 빠르게 구축할 수 있습니다.

## 끝점

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/mistral
```

## 자주 묻는 질문

Mistral AI에 요청을 할 때, 당신은 필요합니다 :

- AI 게이트웨이 계정 ID
- AI Gateway Gateway 이름
- Mistral AI API 토큰
- Mistral AI 모델 이름

## URL 구조

새로운 기본 URL은 이 구조에서 위의 데이터를 사용합니다.`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/mistral/`.

그런 다음, 예를 들어 hit하려는 endpoint를 추가 할 수 있습니다.`v1/chat/completions`

그래서 당신의 마지막 URL은 함께 올 것이다:`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/mistral/v1/chat/completions`.

## 이름 \*

### 사이트맵

```bash title="Example fetch request"
curl -X POST https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/mistral/v1/chat/completions \
 --header 'content-type: application/json' \
 --header 'Authorization: Bearer MISTRAL_TOKEN' \
 --data '{
    "model": "mistral-large-latest",
    "messages": [
        {
            "role": "user",
            "content": "What is Cloudflare?"
        }
    ]
}'
```

### 제품 정보`@mistralai/mistralai`JavaScript를 가진 포장

사용중인 경우`@mistralai/mistralai`포장, 당신은 당신의 endpoint를 같이 놓을 수 있습니다:

```js title="JavaScript example"
import { Mistral } from "@mistralai/mistralai";

const client = new Mistral({
	apiKey: MISTRAL_TOKEN,
	serverURL: `https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/mistral`,
});

await client.chat.create({
	model: "mistral-large-latest",
	messages: [
		{
			role: "user",
			content: "What is Cloudflare?",
		},
	],
});
```

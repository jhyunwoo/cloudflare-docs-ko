[Google AI 스튜디오](https://ai.google.dev/aistudio)Google Gemini 모델로 빠르게 구축할 수 있습니다.

## 끝점

**기본 URL:**

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/google-ai-studio
```

그런 다음, 예를 들어 hit하려는 endpoint를 추가 할 수 있습니다.`v1/models/{model}:{generative_ai_rest_resource}`

그래서 당신의 마지막 URL은 함께 올 것이다:`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/google-ai-studio/v1/models/{model}:{generative_ai_rest_resource}`.

### `@google/genai`

사용중인 경우`@google/genai`포장, 당신은 당신의 endpoint를 같이 놓을 수 있습니다:

<Details header="요청에 있는 열쇠로">
  <Tabs>
    <TabItem label="인증된 Gateway">
      ```js title=""
      import { GoogleGenAI } from "@google/genai";

      const ai = new GoogleGenAI({
        apiKey: "{google_studio_api_key}",
        httpOptions: {
      	  baseUrl: `https://gateway.ai.cloudflare.com/v1/${account_id}/${gateway_name}/google-ai-studio`,
      	  headers: {
      		  'cf-aig-authorization': 'Bearer {cf_aig_token}',
      	  }	
        }
      });

      const response = await ai.models.generateContent({
        model: "gemini-2.5-flash",
        contents: "What is Cloudflare?",
      });

      console.log(response.text);
      ```
    </TabItem>

    <TabItem label="자주 묻는 질문">

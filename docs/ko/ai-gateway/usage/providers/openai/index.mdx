[오시는 길](https://openai.com/about/)GPT 모델로 빌드할 수 있습니다.

## 끝점

**기본 URL**

```
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai
```

OpenAI에 요청을 만들 때, 대체`https://api.openai.com/v1`현재 사용중인 URL에서`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai`.

**채팅 완료 endpoint**

`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai/chat/completions`

**응답 endpoint**

`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai/responses`

## 이름 \*

### 오픈AI SDK

<Details header="요청에 있는 열쇠로">
  <Tabs>
    <TabItem label="인증된 Gateway">
      ```js title=""
      import OpenAI from "openai";

      const client = new OpenAI({
      	apiKey: "YOUR_OPENAI_API_KEY",
      	defaultHeaders: {
      		"cf-aig-authorization": `Bearer {cf_api_token}`,
      	},
      	baseURL:
      		"https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai",
      });

      const response = await client.chat.completions.create({
      	model: "gpt-4o-mini",
      	messages: [{ role: "user", content: "Hello, world!" }],
      });
      ```
    </TabItem>

    <TabItem label="자주 묻는 질문">
      ```js title=""

      const client = new OpenAI({
      	apiKey: "YOUR_OPENAI_API_KEY",
      	baseURL:
      		"https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai",
      });

      const response = await client.chat.completions.create({
      	model: "gpt-4o-mini",
      	messages: [{ role: "user", content: "Hello, world!" }],
      });
      ```
    </TabItem>
  </Tabs>
</Details>

<Details header="Stored Keys (BYOK) / 통합 청구" open>
  ```js title=""
  import OpenAI from "openai";

  const client = new OpenAI({
  	apiKey: "{cf_api_token}",
  	baseURL:
  		"https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai",
  });

  //OpenAI API 키가 BYOK로 저장됩니다.
  //또는 자격이 없는 청구에는 신용이 있습니다
  const response = await client.chat.completions.create({
  	model: "gpt-4o-mini",
  	messages: [{ role: "user", content: "Hello, world!" }],
  });
  ```
</Details>

<Details header="응답 API 요청에서 API 키">

        --header 'cf-aig-authorization: Bearer {CF_AIG_TOKEN}' \
        --header 'Content-Type: application/json' \
        --data '{
        	"model": "gpt-5.1",

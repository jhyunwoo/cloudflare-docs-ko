[딥스카이](https://www.deepseek.com/)DeepSeek의 고급 AI 모델로 빠르게 구축할 수 있습니다.

## 끝점

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/deepseek
```

## 자주 묻는 질문

DeepSeek에 요청을 할 때 다음을해야합니다.

- AI Gateway 계정 ID.
- AI Gateway 게이트웨이 이름.
- Active DeepSeek AI API 토큰.
- 사용하고 싶은 DeepSeek AI 모델의 이름.

## URL 구조

새로운 기본 URL은 이 구조에서 위의 데이터를 사용합니다.

`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/deepseek/`.

다음을 추가 할 수 있습니다 끝점 당신은 명중, 예를 들어:`chat/completions`.

그래서 당신의 마지막 URL은 함께 올 것이다:

`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/deepseek/chat/completions`.

## 이름 \*

### 사이트맵

```bash title="Example fetch request"
curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/deepseek/chat/completions \
 --header 'content-type: application/json' \
 --header 'Authorization: Bearer DEEPSEEK_TOKEN' \
 --data '{
    "model": "deepseek-chat",
    "messages": [
        {
            "role": "user",
            "content": "What is Cloudflare?"
        }
    ]
}'
```

### JavaScriptXQ와 DeepSeek 사용

OpenAI SDK를 사용하는 경우, 다음과 같은 엔드포인트를 설정할 수 있습니다:

```js title="JavaScript"
import OpenAI from "openai";

const openai = new OpenAI({
	apiKey: env.DEEPSEEK_TOKEN,
	baseURL:
		"https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/deepseek",
});

try {
	const chatCompletion = await openai.chat.completions.create({
		model: "deepseek-chat",
		messages: [{ role: "user", content: "What is Cloudflare?" }],
	});

	const response = chatCompletion.choices[0].message;

	return new Response(JSON.stringify(response));
} catch (e) {
	return new Response(e);
}
```

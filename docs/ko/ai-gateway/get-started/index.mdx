## 계정 ID 및 인증 토큰 받기

요청하기 전에 두 가지가 필요합니다.

1. 내 계정**계정 ID**— 에서 찾을[Cloudflare 대시보드](/fundamentals/account/find-account-and-zone-ids/).
2. ·**Cloudflare API 토큰** — [API 토큰 생성](/fundamentals/api/get-started/create-token/)이름 \*`AI Gateway - Read`·`AI Gateway - Edit`이름 \* 아래 예제는 Workers AI를 사용하므로 추가`Workers AI - Read`또한.

## 당신의 첫번째 요구

AI Gateway를 통해 첫 번째 요청을 만들기 위해 다음 명령을 실행하십시오.

```bash
curl -X POST https://gateway.ai.cloudflare.com/v1/$CLOUDFLARE_ACCOUNT_ID/default/compat/chat/completions \
  --header "cf-aig-authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "workers-ai/@cf/meta/llama-3.3-70b-instruct-fp8-fast",
    "messages": [
      {
        "role": "user",
        "content": "What is Cloudflare?"
      }
    ]
  }'
```

:::참조
AI Gateway는 첫번째 요청에 대한 게이트웨이를 자동으로 생성합니다. 게이트웨이는[인증 및 인증](/ai-gateway/configuration/authentication/)켜기, 그래서`cf-aig-authorization`모든 요청에 대한 헤더가 필요합니다. 기본 게이트웨이가 작동하는 방법에 대한 자세한 내용은 참조[기본 Gateway](/ai-gateway/configuration/manage-gateway/#default-gateway).
:::

## 공급자 인증

다음 옵션 중 하나를 사용하여 업스트림 AI 공급자와 인증:

- **자격이 된 청구:**&#x41;I Gateway 청구를 사용하여 결제 및 출국 요청을 인증합니다. 더 알아보기[통합 빌링](/ai-gateway/features/unified-billing/).
- **BYOK (상점 열쇠):**&#x43;loudflareXQ와 자체 제공 업체 API 키 저장, AI 게이트웨이는 실행 시간에 포함. 더 알아보기[로드 중 ...](/ai-gateway/configuration/bring-your-own-keys/).
- **요청 헤더:**&#xC77C;반적으로 요청 헤더에서 공급자 API Key를 포함 (예를 들어,`Authorization: Bearer <OPENAI_API_KEY>`).

AI Gateway를 가진 시작하기XQ에 가장 쉬운 방법은 우리의 OpenAI-compatible를 통해서 입니다`/chat/completions`끝점. 기존 OpenAI SDK와 도구를 사용하여 최소한의 코드 변경으로 여러 AI 공급자에 액세스할 수 있습니다.

`https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/compat/chat/completions`

**주요 이점:**

- OpenAI API에 대한 드롭 인 교체, 기존 OpenAI SDK 및 기타 OpenAI 호환 클라이언트와 함께 작동
- 공급자 간의 전환`model`이름 \*
- 동적 루팅 - 조건 논리를 요구하는 복잡한 라우팅 시나리오를 정의하고 A / B 테스트를 수행하고, 설정 속도 / 예산 제한 등을 설정

### 공급자 별점

특정 AI 공급자와 직접적인 통합을 위해, AI Gateway 특징을 추가하는 동안 본래 공급자의 API schema를 유지하는 전용 엔드포인트를 사용하십시오.

```txt
https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/{provider}
```

**유효한 공급자:**

- [오시는 길](/ai-gateway/usage/providers/openai/)- GPT 모델 및 embeddings
- [인기 카테고리](/ai-gateway/usage/providers/anthropic/)- 클로드 모델
- [Google AI 스튜디오](/ai-gateway/usage/providers/google-ai-studio/)- Gemini 모델
- [모델 번호: Workers AI](/ai-gateway/usage/providers/workersai/)- Cloudflare의 의도 플랫폼
- [AWS 베드 락](/ai-gateway/usage/providers/bedrock/)- Amazon의 관리 AI 서비스
- [Azure 오픈AI](/ai-gateway/usage/providers/azureopenai/)- Microsoft의 OpenAI 서비스
- [더 보기](/ai-gateway/usage/providers/)

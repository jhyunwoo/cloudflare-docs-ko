이 튜토리얼은 QXQX0003XCloudflareQ QXQXQX대시보드XQ를 사용하여 최초의 AI 게이트웨이 만들기를 통해 안내합니다. 의도한 청중은 AI 게이트웨이와 Workers AI에 새로운 초보자입니다. AI Gateway를 사용하면 콘텐츠 생성, 데이터 처리, 예측 분석, 향상된 제어 및 성능으로 AI 모델을 활용할 수 있습니다.

## 로그인 및 로그인

1. **이름 \***: CloudflareQ 계정이 없는 경우[로그인](https://cloudflare.com/sign-up).
2. **로그인**: Cloudflare 대시보드에 로그인하여 액세스[Cloudflare 대시보드](https://dash.cloudflare.com/login).

## AI 공급자를 연결합니다

1. AI 게이트웨이 섹션에서 생성 된 게이트웨이를 선택하십시오.
2. 제품정보**모델 번호: Workers AI**Workers AIXQ에 대한 엔드포인트를 설정하는 공급자로.
   요청을 보내기 위한 엔드포인트 URL을 받게 됩니다.

## Workers AI

1. 오시는 길**사이트맵** > **모델 번호: Workers AI**Cloudflare 대시보드에서.
2. 제품정보**REST API 사용**API 토큰 및 계정 ID를 생성하고 복사하는 단계를 따르십시오.
3. **Workers AIXQ에 요청 보내기**: 제공된 API 엔드포인트를 사용하십시오. 예를 들어, 컬 명령을 사용하여 API를 통해 모델을 실행할 수 있습니다. 기타 제품`{account_id}`, `{gateway_id}`·`{cf_api_token}`실제 계정 ID 및 API 토큰으로:

   ```bash
   curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/workers-ai/@cf/meta/llama-3.1-8b-instruct \
   --header 'Authorization: Bearer {cf_api_token}' \
   --header 'Content-Type: application/json' \
   --data '{"prompt": "What is Cloudflare?"}'
   ```

## Analytics 보기

AI Gateway를 모니터링하여 사용 통계를 볼 수 있습니다.

1. 오시는 길**사이트맵** > **AI 게이트웨이**대시보드에서.
2. 요청 카운트, 토큰 사용, 캐싱 효율성, 오류 및 예상 비용과 같은 메트릭을 볼 수있는 게이트웨이를 선택하십시오. 로깅 및 속도 제한과 같은 추가 구성을 설정할 수 있습니다.

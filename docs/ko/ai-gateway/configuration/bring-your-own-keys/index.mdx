## 제품정보

자신의 키를 가져 (BYOK)는 QXQX0003XQX0002XQQQXQXQ에서 직접 AI 공급자 API 키를 안전하게 저장 할 수있는 Cloudflare 대시보드에서 기능입니다. AI 모델에 대한 모든 요청에 API 키 대신 대시보드 및 참고 자료XQ에서 한 번 구성 할 수 있습니다.

열쇠는 안전하게 저장됩니다[비밀번호](/secrets-store/)그리고 허용:

- 안전한 저장과 한계 노출
- Easier 열쇠 교체
- 요금 제한, 예산 제한 및 기타 제한[동 노선](/ai-gateway/features/dynamic-routing/)

### 앱 업데이트

대시보드XQ에서 API 키를 구성하면:

1. **코드에서 API 키를 제거**: 모든 hardcoded API 키 또는 환경 변수 삭제.
2. **업데이트 요청 헤더**: 귀하의 요청에 따라 공급자 승인 헤더를 제거하십시오. 아직 통과해야 할 사항`cf-aig-authorization`.
3. **당신의 통합을 테스트**: API 키를 포함한 요청 작업을 검증합니다.

## 이름 \*

BYOK 활성화로 워크플로우 변경 사항:

1. **전통적 접근**: 모든 요청 헤더에서 API 키 포함

   ```bash
   curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai/chat/completions \
     -H 'cf-aig-authorization: Bearer {CF_AIG_TOKEN}' \
     -H "Authorization: Bearer YOUR_OPENAI_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"model": "gpt-4", "messages": [...]}'
   ```

2. **BYOK 접근**: 대시보드XQ에서 한 번 키 구성, 키 만료없이 요청
   ```bash
   curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai/chat/completions \
     -H 'cf-aig-authorization: Bearer {CF_AIG_TOKEN}' \
     -H "Content-Type: application/json" \
     -d '{"model": "gpt-4", "messages": [...]}'
   ```

## 공급자 당 다수 열쇠

AI Gateway는 동일한 공급자를 위한 다수 API 열쇠를 저장합니다. 이렇게 하면:

- 다른 사용 사례에 대한 다른 키 사용 (예를 들어, 개발 대 생산)
- 회전 중에 키 사이에 Gradually migrate

### 키 별칭

각 API 키는 별명을 할당할 수 있습니다. 키를 추가하면 사용자 정의 별명을 지정할 수 있습니다. 또는 시스템은 사용할 수 있습니다.`default`별명으로.

요청을 할 때 AI Gateway는 열쇠를 사용합니다.`default`기본적으로 별명. 다른 열쇠를 사용하기 위하여는, 포함합니다`cf-aig-byok-alias`사용하려는 열쇠의 별명으로 우두머리.

### 예: 특정 키 별명으로 사용

다른 별명으로 구성된 여러 OpenAI 키가 있다면 (예를 들어,`default`, `production`·`testing`), 당신은 어느 것을 사용 지정할 수 있습니다:

```bash
#alias "default"와 키를 사용합니다 (필수 헤더 없음)
curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai/chat/completions \
  -H 'cf-aig-authorization: Bearer {CF_AIG_TOKEN}' \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4", "messages": [...]}'
```

```bash
#alias "production"로 키 사용
curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai/chat/completions \
  -H 'cf-aig-authorization: Bearer {CF_AIG_TOKEN}' \
  -H 'cf-aig-byok-alias: production' \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4", "messages": [...]}'
```

```bash
#alias "testing"로 키 사용
curl https://gateway.ai.cloudflare.com/v1/{account_id}/{gateway_id}/openai/chat/completions \
  -H 'cf-aig-authorization: Bearer {CF_AIG_TOKEN}' \
  -H 'cf-aig-byok-alias: testing' \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4", "messages": [...]}'
```

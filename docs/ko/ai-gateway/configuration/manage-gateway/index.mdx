AI Gateway 관리에 대한 여러 가지 옵션이 있습니다.

## Gateway 만들기

### 기본 Gateway

AI Gateway는 자동으로 게이트웨이를 만들 수 있습니다. 이용 시`default`게이트웨이 ID와 그 ID가 계정에 존재하지 않는 게이트웨이로, AI Gateway는 첫 번째 인증된 요청에 그것을 만듭니다.

auto-creation을 트리거하는 요청은 유효하다`cf-aig-authorization`헤더. 자주 묻는 질문`default`아직 존재하지 않는 게이트웨이는 게이트웨이를 만들지 않습니다.

auto-created default Gateway는 다음과 같은 설정을 사용합니다.

| 설치하기  | 기본 값        |
| ----- | ----------- |
| 인증현황  | 이름 \*       |
| 회사소개  | 이름 \*       |
| 뚱 베어  | 오프 (TTL의 0) |
| 비율 제한 | 이름 \*       |

생성 후 다른 게이트웨이와 같은 기본 게이트웨이 설정을 편집할 수 있습니다. 기본 게이트웨이를 삭제하면 새로운 인증 요청을 전송합니다.`default`Gateway ID 자동 생성 다시.

:::참조
Auto-creation만 게이트웨이 ID에 적용`default`. 다른 게이트웨이 ID를 사용하면 게이트웨이를 먼저 만들 수 있습니다.

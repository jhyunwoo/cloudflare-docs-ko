## 오류 523 : 기원은 제한이 없습니다

CloudflareXQ가 당신의 근원 웹 서버에 연락할 수 없을 때 이 오류가 발생합니다.

### 일반적인 원인

이것은 일반적으로 Cloudflare와 근원 웹 서버 사이 네트워크 장치가 근원의 IP 주소에 노선이 없을 때 발생합니다.

### 제품 설명

호스팅 공급자에게 연락하고 필요한 공유[오류 정보](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/#required-error-details-for-hosting-provider)웹 서버에서 다음과 같은 일반적인 원인을 제외하려면:

- 올바른 IP 주소를 확인하려면 Cloudflare DNS 앱 내 A 또는 AAAA 레코드에 나열되어 있습니다.
- 당신의 근원과 Cloudflare 사이에서 인터넷 여정 문제점, 또는 근원 자체와 더불어 문제.

위에서 언급하지 않은 경우, 호스팅 공급자 또는 사이트 관리자에서 다음 정보를 요청하십시오.

- 이름 \*[MTR 또는 추적](/support/troubleshooting/general-troubleshooting/gathering-information-for-troubleshooting-sites/#perform-a-traceroute)당신의 근원 웹 서버에서[Cloudflare IP 주소](http://www.cloudflare.com/ips)문제가 발생하기 전에 원산지 웹 서버에 가장 일반적으로 연결됩니다. 원래 웹 서버의 로그에서 Cloudflare IP 연결을 식별합니다.

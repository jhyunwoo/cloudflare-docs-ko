## Error 520: 웹 서버가 알 수없는 오류를 반환합니다.

이 오류는 원래 서버가 빈, 알 수없는, 또는 CloudflareXQ에 예기치 않은 응답을 반환 할 때 발생합니다.

### 일반적인 원인

이 오류는 종종 트리거됩니다 :

- Origin 서버 충돌 또는 misconfigurations.
- 방화벽 또는 보안 플러그인 차단[Cloudflare의 IP](https://www.cloudflare.com/ips)당신의 근원에.
- 128KB를 초과하는 우두머리 ( 과도한 쿠키로 인해).
- HTTP 상태 코드 또는 응답 체가 부족한 빈 또는 변형 된 응답.
- 응답 헤더 또는 웹 서버가 반환하지 않는[적절한 HTTP 오류 응답](https://www.iana.org/assignments/http-status-codes/http-status-codes.xhtml).
- 근원 서버에서 HTTP/2 윤곽을 Incorrect.
- Authentication Origin Pull은 Cloudflare에서 활성화되었지만 기원은[예상대로 구성되지 않음](/ssl/origin-configuration/authenticated-origin-pull/set-up/zone-level/#2-configure-origin-to-accept-client-certificates).

:::참조

`520`오류는 원래 웹 서버 충돌 특정 PHP 응용 프로그램과 동일합니다.

:::

### 제품 설명

:::참조

임시 작업으로, 영향을받는 DNS 레코드를 설정할 수 있습니다.[DNS 전용](/dns/proxy-status/)Cloudflare**DNS 보호**앱 또는[일시 정지 Cloudflare](/fundamentals/manage-domains/pause-cloudflare/).

:::

- 호스팅 제공 업체 또는 사이트 관리자에 문의하고 필요한 공유[오류 정보](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/#required-error-details-for-hosting-provider)문제 해결에 도움. 웹 서버 오류 로그의 검토를 요청하고 충돌 및 확인[일반적인 원인](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-520/#common-causes)이전 섹션에서 언급.

- HTTP / 2가 소스 서버에서 활성화되면 올바르게 설정됩니다. Cloudflare는 HTTP/2 연결을 통해 지원하는 서버를 연결[사이트맵](https://blog.cloudflare.com/introducing-http2). 웹 서버가 HTTP / 2 연결을 허용하면 프로토콜을 존중하거나 지원하지 않는다면 HTTP`520`오류가 반환됩니다. 당신은 비활성화 할 수 있습니다[HTTP/2의 근원](/speed/optimization/protocol/http2-to-origin/#disable-http2-to-origin)내 계정**제품 정보** > **계정 설정** > **Protocol 최적화**Cloudflare 대시보드에.

- 이름 \*`520`오류는 호스팅 공급자 또는 사이트 관리자에게 연락하여 다음 정보를 제공합니다.[Cloudflare 지원](/support/contacting-cloudflare-support/):
  - 오류가 발생했을 때 요청된 리소스의 전체 URL(s).
  - 모델 번호: Cloudflare[**cf 레이**](/fundamentals/reference/cloudflare-ray-id/)으로`520`오류 메시지.
  - 산출에서`http://<YOUR_DOMAIN>/cdn-cgi/trace`.
  - 2 일[HAR 파일](/support/troubleshooting/general-troubleshooting/gathering-information-for-troubleshooting-sites/#generate-a-har-file):
    - 웹 사이트에서 Cloudflare를 사용할 수 있습니다.
    - 또 다른[일시적으로 CloudflareXQ](/fundamentals/manage-domains/pause-cloudflare/).

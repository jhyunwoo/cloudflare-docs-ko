## 오류 521: 웹 서버가 다운

오류 수정`521`원래 웹 서버가 Cloudflare에서 연결을 거부 할 때 발생합니다. 당신의 근원에 보안 해결책은 특정한 연결을 막을지도 모릅니다[Cloudflare IP 주소](https://www.cloudflare.com/ips).

### 일반적인 원인

두 가지 일반적인 원인`521`오류는:

- Offlined Origin 웹 서버 애플리케이션.
- 블록 Cloudflare 요청.

### 제품 설명

호스팅 제공 업체 또는 사이트 관리자에 문의하고 필요한 공유[오류 정보](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/#required-error-details-for-hosting-provider)이러한 일반적인 원인을 해결하는 데 도움이 :

- 웹 서버가 반응합니다.
- 웹 서버 오류 로그를 검토하여 웹 서버 응용 프로그램 충돌 또는 정전을 식별합니다.
- 이름 \*[Cloudflare IP 주소](https://www.cloudflare.com/ips)제한되지 않습니다.
- 모든 것[Cloudflare IP 범위](https://www.cloudflare.com/ips)당신의 근원 웹 서버의 방화벽 또는 다른 보안 소프트웨어에서.
- 확인하기 — 당신이 가지고 있다면**SSL/TLS 모드**설정하기**한국어**또는**전체 (Strict)**) — 당신의 근원은 HTTPS를 지원하고/또는 당신은 설치했습니다[Cloudflare 근원 증명서](/ssl/origin-configuration/origin-ca)또는 인증 일치[이 형태를 위한 필요조건](/ssl/origin-configuration/ssl-modes/#custom-ssltls).
- 원래 웹 서버 애플리케이션이 적극적으로 SSL/TLS 모드에 의해 요구되는 포트에 대해 듣는 것을 보장합니다. 포트 80**제품정보**, 또는 항구 443를 위해**한국어**·**전체 (Strict)**.
- 자주 묻는 질문[Cloudflare 커뮤니티](https://community.cloudflare.com/t/community-tip-fixing-error-521-web-server-is-down/42461).

## 오류 522 : 연결 시간

오류 수정`522`CloudflareXQ가 웹서버에 연락할 때 발생합니다.

### 일반적인 원인

두 가지 다른 timeouts 원인 HTTP 오류`522`Cloudflare 및 웹 서버 사이에 발생할 때에 따라:

- 연결이 설치되기 전에, 원래 웹 서버는 SYN + ACK를 CloudflareXQX0001XQXQXQXQXQ의 19 초 안에 반환하지 않습니다 (SYN 재try 백 오프 계획은 1,1,1,1,2,4,8).
- 연결이 설치되면, 원래 웹 서버는 90 초 이내에 (ACK) Cloudflare의 자원 요청을받지 않습니다.

### 제품 설명

- 호스팅 공급자에게 연락하고 필요한 공유[오류 정보](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/#required-error-details-for-hosting-provider)이러한 일반적인 원인을 해결하는 데 도움이 :

  - [Cloudflare IP 주소](https://www.cloudflare.com/ips/).htaccess, iptables, 또는 방화벽에서 제한되거나 차단됩니다. 호스팅 공급자 확인**모든 Cloudflare IP 범위**(대부분의 원인). 당신은 사용할 수[Cloudflare WAF 주문 규칙](/waf/custom-rules/use-cases/block-by-geographical-location/)지리적 위치에서 트래픽을 제한하는 경우.
  - 과부하 또는 오프라인 소스 웹 서버는 수신 요청을 삭제합니다.
  - [관련 기사](http://tldp.org/HOWTO/TCP-Keepalive-HOWTO/overview.html)웹 서버에서 비활성화됩니다.
  - CloudflareXQ에 있는 근원 IP 주소**DNS 보호**앱은 현재 IP 주소와 일치하지 않습니다. 호스팅 제공 업체의 웹 서버.
  - Packets는 웹 서버에서 떨어졌다.

- 자주 묻는 질문[CloudflarePages](/pages/), 당신은 사용자 정의 도메인 설정 및 당신의 CNAME 레코드가 일치 확인[관례 Pages 도메인](/pages/configuration/custom-domains/#add-a-custom-domain).

- 자주 묻는 질문[사용자 정의 도메인 Workers](/workers/configuration/routing/custom-domains/), 수행`fetch`자신의 호스트명에게는`522`오류. 자주 묻는 질문[오시는 길](/workers/configuration/routing/), 다른 호스트명을 대상으로, 또는 활성화[`global_fetch_strictly_public`호환성 깃발](/workers/configuration/compatibility-flags/#global-fetch-strictly-public)대신.

- 자주 묻는 질문[회사 소개](/rules/origin-rules/), resulting hostname이 해결 될 수 있는지 확인합니다. 예를 들어, Origin Rule이 Worker 노선에 가리면,`522`이 루트의 hostname이 지정한 경우 오류가 반환됩니다.`100::`또는`192.0.2.0`.

- 위에서 언급하지 않은 경우, 호스팅 공급자 또는 사이트 관리자에서 다음 정보를 요청하십시오.[접촉 Cloudflare 지원](/support/contacting-cloudflare-support/):

  - 이름 \*[MTR 또는 추적](/support/troubleshooting/general-troubleshooting/gathering-information-for-troubleshooting-sites/#perform-a-traceroute)당신의 근원 웹 서버에서[Cloudflare IP 주소](http://www.cloudflare.com/ips)문제가 발생하기 전에 원산지 웹 서버에 가장 일반적으로 연결됩니다. Cloudflare IP가 웹 서버 로그에 기록된 연결을 식별합니다.
  - 호스팅 제공 업체의 조사에서 세부 사항, pertinent 로그 또는 호스팅 제공 업체와의 대화와 같은.

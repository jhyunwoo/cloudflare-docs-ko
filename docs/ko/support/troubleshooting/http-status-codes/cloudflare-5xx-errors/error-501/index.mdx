## 오류 501: 구현되지 않음

Cloudflare Workers는 반환합니다`501`요청이 Workers Runtime에 의해 지원되지 않는 HTTP 방법을 사용합니다.

### 일반적인 원인

- 클라이언트는 사용자 정의 또는 비표준 HTTP 방법을 사용하여 WorkersXQ 스크립트에 요청을 보냈습니다 (외부의 MEthods`GET`, `POST`, `PUT`, 등).
- HTTP 메소드의 typo (예를 들어,`POT`대신에`POST`).

### 제품 설명

- 클라이언트를 업데이트하여 유효한, 표준[HTTP 요청 방법](https://developer.mozilla.org/en-US/docs/Web/HTTP/Methods).

## 오류 525 : SSL 핸디케이크 실패

이 오류는 Cloudflare과 웹 서버가 실패한 SSL 핸디케이크가 나타냅니다.

### 일반적인 원인

오류 수정`525`이 두 가지 조건이 true일 때 발생합니다.

- 더 보기[SSL 핸즈](https://www.cloudflare.com/learning/ssl/what-happens-in-a-tls-handshake/)Cloudflare와 웹 서버 사이에 실패합니다.
- [*한국어*또는*전체 (Strict)*](/ssl/origin-configuration/ssl-modes) **사이트맵**설정은**제품정보**Cloudflare의 탭**사이트맵**앱.

:::참조

호스팅 공급자가 자주 웹 서버의 IP 주소를 변경하면 Cloudflare의 문서를 참조하십시오.[동적 DNS 업데이트](/dns/manage-dns-records/how-to/managing-dynamic-ip-addresses).
:::

### 제품 설명

호스팅 공급자에 문의하여 다음과 같은 일반적인 원인을 제외하고 웹 서버:

- 유효한 SSL 인증서가 없습니다.
- 항구 항구`443`(또는 다른 사용자 정의 보안 포트)가 열리지 않습니다.
- 이름 \*<GlossaryTooltip term="Server Name Indication (SNI)">사이트맵</GlossaryTooltip>지원.
- 더 보기[cipher 스위트](/ssl/origin-configuration/cipher-suites/)Cloudflare에 의해 사용은 원래 웹 서버에서 지원되는 cipher 스위트와 일치하지 않습니다.

:::참조

이름 \*`525`오류가 발생하게, 원인을 결정하기 위해 Origin 웹 서버 오류 로그를 검토합니다. 아파치 구성[mod ssl 오류 로그](https://cwiki.apache.org/confluence/display/HTTPD/DebuggingSSLProblems#Enable_SSL_logging). 또한, nginx는 표준 오류 로그에 SSL 오류를 포함하지만, 아마도 필요할 수 있습니다[증가된 로그 수준](https://docs.nginx.com/nginx/admin-guide/monitoring/logging/).
:::

- 인증서가 Origin 서버에 설치된다는 것을 확인합니다. 실행 시험에 대한 세부 사항, 참조[컬을 가진 문제 해결 요구](/support/troubleshooting/general-troubleshooting/gathering-information-for-troubleshooting-sites/#troubleshoot-requests-with-curl). 증명서가 설치되지 않는 경우에, 당신은 생성하고 무료로 설치할 수 있습니다[Cloudflare 근원 CA 증명서](/ssl/origin-configuration/origin-ca)Cloudflare 및 웹 서버 간의 트래픽을 암호화합니다.

- [cipher 스위트 리뷰](/ssl/edge-certificates/additional-options/cipher-suites/)서버가 CloudflareXQ와 호환되도록 합니다.

- timetamps에서 서버의 오류 로그를 확인합니다.`525`오류는 SSL 핸디케이크 중에 재설정 할 수있는 연결이 발생하는 문제를 식별 할 수 있습니다.

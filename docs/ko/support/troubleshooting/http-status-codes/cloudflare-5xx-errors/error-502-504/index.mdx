## 오류 502 나쁜 게이트웨이 또는 오류 504 게이트웨이 타임 아웃

HTTP 정보`502`또는`504`오류는 Cloudflare가 원래 웹 서버와 접촉을 설정할 수 없다는 것을 나타냅니다.

### 일반적인 원인

가능한 두 가지 원인이 있습니다:

- [`502/504`웹 서버에서 오류](#502504-from-your-origin-web-server)(대부분).
- [`502/504`Cloudflare의 오류](#502504-from-cloudflare).

당신은 또한 볼 수 있습니다`504`로그 또는 분석의 상태 코드에 의해 발생[Early Hints의 캐시 MISS 응답](/cache/advanced-configuration/early-hints/#emit-early-hints), 또는 Cloudflare WorkersXQ에 의하여 캐시 API[`cache.match`캐시 MISS의 작업 결과](https://developers.cloudflare.com/workers/runtime-apis/cache/#errors-1).

### 제품 설명

해결하기`502/504`오류, 그것은 문제가 원래 웹 서버 또는 Cloudflare에서 시작 여부를 식별하는 데 필수적입니다. 다음 섹션에서는 두 소스에서 문제 해결 및 해결 오류에 대한 자세한 내용을 찾을 수 있습니다.

#### 502/504 당신의 근원 웹 서버에서

Cloudflare는 Cloudflare-branded HTTP를 돌려줍니다.`502`또는`504`웹 서버가 표준 HTTP로 응답할 때 오류`502 bad gateway`또는`504 gateway timeout`오류:

![Cloudflare-branded 오류의 예 502.](~/assets/images/support/image1.png)

호스팅 공급자에 문의하여 이러한 일반적인 원인을 해결하십시오. 웹 서버:

- 원래 서버가 생성 된 방문자의 URL 내에서 호스트 이름 및 도메인에 대한 요청에 응답`502`또는`504`오류.
- 과도한 서버 부하, 충돌, 또는 네트워크 실패를 조사합니다.
- 시간 또는 차단 된 응용 프로그램 또는 서비스를 식별.

#### 502/504 에서 Cloudflare

·`502`또는`504`CloudflareXQ에서 시작된 오류는 다음과 같이 나타납니다. CloudflareQ 브랜딩이없는 빈 페이지 :

![unbranded 오류의 예 502.](~/assets/images/support/image5.png)

오류가 언급되지 않는 경우`cloudflare`, 지원을위한 호스팅 제공 업체에 문의하십시오. 더 알아보기[502/504 당신의 근원에서 과실](#502504-from-your-origin-web-server)더 많은 정보.

이 오류는 원래 서버가 gzip-encoded 압축 콘텐츠를 제공 할 때와 같은 원래의 압축 문제로 인해 발생할 수 있지만 업데이트 실패`content-length`header, 또는 근원이 부서진 gzip 압축 내용을 봉사하는 경우에. 이 진단을 위해, 당신은 오류를 해결하는 경우 확인하기 위해 원산지에서 압축을 해제 할 수 있습니다.

또한 일부 경우에 특정 데이터 센터는 트래픽에서 급격한 증가를 경험할 수 있습니다. 고객의 최소 충격을 보장하기 위해 자동화된 프로세스는 다른 데이터 센터에 트래픽을 리디렉션합니다. 이 조정은 일반적으로 이음새가 없고 단지 몇 초를 가지고 갑니다. 그러나, 이 과정에서, 몇몇 클라이언트는 임시 대기권 또는 HTTP를 경험할지도 모릅니다`502`오류. 자동화된 트래픽 관리 도구에 대한 자세한 정보를 찾을 수 있습니다.[블로그 포스트](https://blog.cloudflare.com/meet-traffic-manager).

지원 팀에서 더 많은 도움을 필요로 하는 경우, 다음 세부 정보를 제공[Cloudflare 지원](/support/contacting-cloudflare-support/)당신의 조회를 가공하는에 있는 지연을 피하기 위하여:

- 문제가 발생한 시간대와 함께 타임스탬프.
- HTTP에서 발생하는 URL`502`또는`504`응답 (예를 들면,`https://www.example.com/images/icons/image1.png`).
- 검색에서 출력`<YOUR_DOMAIN>/cdn-cgi/trace`.

### 알려진 Cloudflare는 HTTP 오류 502 또는 504로 이어질 문제

- 사용 방법[오시는 길](/cloudflare-one/traffic-policies/)HTTP 오류로 이어질 수 있습니다.`502`원래는 부분적으로 HTTP / 2를 지원합니다. 참고[게이트웨이 FAQ](/cloudflare-one/faq/troubleshooting/#i-see-error-504-when-browsing-to-a-website)자세한 내용 및 해상도.

- 당신은 볼 수 있습니다`502 Bad Gateway`HTTP 또는 HTTPS 애플리케이션에 연결할 때 오류[Cloudflare 갱도](/cloudflare-one/networks/connectors/cloudflare-tunnel/), 와`Unable to reach the origin service. The service may be down or it may not be responding to traffic from cloudflared`. 그것은 갱도 자체가 Cloudflare 네트워크에 연결된다는 것을 의미합니다, 그러나`cloudflared`당신의 진입 규칙에 정의된 원래 서비스에 도달할 수 없습니다. 더 알아보기[터널 공통 오류 페이지](/cloudflare-one/networks/connectors/cloudflare-tunnel/troubleshoot-tunnels/common-errors/#i-see-a-502-bad-gateway-error-when-connecting-to-an-http-or-https-application-through-tunnel)자세한 내용 및 해상도.

- HTTP 오류의 유출을 볼 수 있습니다.`504`이름 \*`RequestSource`이름 \*`earlyHintsCache`Cloudflare 초기 힌트가 활성화 될 때 로그, 예상되고 benign. 더 알아보기[초기 힌트 기사](/cache/advanced-configuration/early-hints/#emit-early-hints)자세한 내용 및 해상도.

문제 해결`5XX`오류, 올바른 작업 과정은 호스팅 제공 업체 또는 사이트 관리자에게 문제를 해결하고 데이터를 수집하는 것입니다. 뒤에 오는 단면도 개요:

- 더 보기[\* 이름](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/#required-error-details-for-hosting-provider)호스팅 제공 업체를 제공하여 오류를 해결하는 데 도움이됩니다.
- 오시는 길[오류 분석](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/#error-analytics)Cloudflare 대시보드에서.

:::참조

모델 번호: Cloudflare 도메인 소유자만 지원하여 문제를 해결합니다. 사이트 방문자 인 경우 사이트 소유자에게 문제를 신고하십시오.

:::

### 호스팅 공급자를 위한 필수 오류 세부사항

호스팅 공급자에게 연락할 때 다음 정보를 공유하십시오:

- 특정`5XX`오류 코드 및 메시지.
- 시간과 시간대`5XX`오류가 발생했습니다.
- HTTP에서 발생하는 URL`5XX`오류 (예를 들어,`https://www.example.com/images/icons/image1.png`).

오류의 원인은 항상 원래 서버의 오류 로그에서 발견되지 않습니다. QXQX0001XQ 및 Origin 웹 서버간에 로드밸런서, 캐시, 프록시, 방화벽의 로그를 확인해야합니다.

호스팅 제공 업체 또는 사이트 관리자에 제공 하는 추가 세부 사항 아래 오류 설명에서 찾을 수 있습니다. Cloudflare[사용자 정의 오류](/rules/custom-errors/)이 페이지에서 논의 된 기본 오류 페이지의 외관을 변경할 수 있습니다.

### 오류 분석

도메인 당 오류 분석은 사용할 수 있습니다[영역 분석](/analytics/account-and-zone-analytics/zone-analytics/). 오류 분석은 HTTP 오류 코드로 전체 오류로 통찰력을 제공하고 URL, 소스 IP 주소 및 Cloudflare 데이터 센터와 같은 세부 정보를 진단하고 문제를 해결해야합니다. 오류 분석은 1% 트래픽 샘플에 근거합니다.

오류 분석 보기:

1. Cloudflare 대시보드에서, 가십시오**HTTP 트래픽**사이트 맵

   <DashButton url="/?to=/:account/:zone/analytics/traffic" />

2. 제품정보**필터 추가**, 선택**Edge 상태 코드**또는**근원 상태 부호**그리고 어떤 선택`5xx`진단하고 싶은 오류 코드.

### 로그 탐색

[로그 탐색](/log-explorer/)Cloudflare 로그에 대한 액세스는 Cloudflare 플랫폼 내에서 사용할 수있는 모든 컨텍스트를 제공합니다.
사용자 정의 대시보드S 또는 로그 검색과 문제 해결 문제를 모니터링 할 수 있습니다.
비밀번호[쿼리를 구축 할 수 있습니다](/log-explorer/log-search/)특정 Ray ID에 대한 필터링, HTTP 오류를 조사하는 데 유용 할 수 있습니다.

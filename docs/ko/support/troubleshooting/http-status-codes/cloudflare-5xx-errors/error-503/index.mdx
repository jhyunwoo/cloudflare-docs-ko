## 오류 503 : 일시적으로 사용할 수없는 서비스

HTTP 오류 503는 웹 서버가 과부하 될 때 발생합니다.

### 일반적인 원인

오류 메시지 또는 오류의 위치에 의해 식별 된 다른 원인이 있습니다.

- 오류는 포함되지 않습니다.`cloudflare`또는`cloudflare-nginx`HTML 응답 몸에서. 이 경우, 문제는 Origin 서버에서 가능성이 있습니다.
- 오류 포함`cloudflare`또는`cloudflare-nginx`HTML 응답 몸에서. 이 경우 CloudflareXQ에서 문제가 발생할 수 있습니다.
- 오류는 로그 또는 분석에서만 볼 수 있습니다.

### 제품 설명

해결하기`503`오류, 첫 번째는 문제가 당신의 기원 웹 서버 또는 Cloudflare에서 유래 여부를 결정합니다. 다음 섹션은 두 시나리오를 문제 해결에 대한 지침을 제공합니다.

#### 503 오류없이`cloudflare`또는`cloudflare-nginx`

오류가 포함되지 않는 경우`cloudflare`또는`cloudflare-nginx`HTML 응답 몸에서 호스팅 제공 업체에 연락하여 원치 웹 서버에 제한 요청을 평가하십시오.

#### 503 오류`cloudflare`또는`cloudflare-nginx`

오류가 포함되면`cloudflare`또는`cloudflare-nginx`HTML 응답 몸에서 연결 문제는 Cloudflare 데이터 센터에서 발생했습니다. 제품정보[Cloudflare 지원](/support/contacting-cloudflare-support/)다음 정보:

- 도메인 이름
- 시간과 시간대`503`오류 발생
- 출력의`www.example.com/cdn-cgi/trace`브라우저에서`503`오류가 관찰되었습니다 (replace`www.example.com`실제 도메인 및 호스트 이름과 함께

#### 503 오류 로그 및 분석에서만 볼 수

이 오류 결과에서[unsuccessful prefetches 에서 속도 뇌](/speed/optimization/content/speed-brain/#how-speed-brain-works)그리고 discarded 할 수 있습니다. 이 오류는 웹 사이트의 방문자에 볼 수 없습니다.[속도 뇌](/speed/optimization/content/speed-brain/#enable-and-disable-speed-brain)필요한 경우 영역에서 비활성화 할 수 있습니다 (이 기능은 특정 경로에 사용할 수 없습니다).

### Workers-특성 원인

오류 503는 Cloudflare Workers를 사용할 때 발생할 수 있습니다:

- 노동자는 CPU 시간 한계를 초과합니다 (봅니다)[오류 1102](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1102/))
- Worker 코드는 메모리 제한 문제 발생 (see)[오류 1102](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1102/))

Workers를 사용하는 경우, Workers 대시보드XQXQ를 오류 로그 및 리소스 제한 문제를 확인하십시오.

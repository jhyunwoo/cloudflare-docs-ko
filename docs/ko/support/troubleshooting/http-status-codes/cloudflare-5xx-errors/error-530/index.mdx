## 오류 530

이 오류는 Cloudflare가 원래 호스트 이름을 해결할 수 없다는 것을 나타냅니다. 원래 서버에 연결을 설정에서 방지.

### 일반적인 원인

HTTP 오류`530`Cloudflare가 원래 호스트 이름을 해결하는 문제가 발생하면 반환됩니다.
이 경우 응답의 몸은 포함[1XXX 오류](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/)이름 \*

### 제품 설명

특정에 대한 참조[1XXX 오류](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/)문제 해결 정보.

## 오류 500: 내부 서버 오류

이 오류는 웹 서버로 문제를 나타내며, 요청을 처리하는 것을 방지합니다.

### 일반적인 원인

더 보기`Error establishing database connection message`일반적인 HTTP`500`오류, 일반적으로 웹 서버 문제를 나타내는. 이 오류가 발생하면, 지원을위한 호스팅 제공 업체에 문의하십시오.

### 제품 설명

가장 많이 취급할 때`5XX`오류, 첫 번째 단계는 호스팅 제공 업체 또는 사이트 관리자에 도달하여 문제를 해결하는 데 도움이됩니다. 자주 묻는 질문[오류 정보](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/#required-error-details-for-hosting-provider)호스팅 공급자에게 문제 해결을 지원하기 위해.

그러나,`500`오류 포함`cloudflare`또는`cloudflare-nginx`HTML 응답 몸에서 접촉[Cloudflare 지원](/support/contacting-cloudflare-support/)그리고 뒤에 오는 세부사항을 제공합니다:

- 도메인 이름
- 시간과 시간대`500`오류 발생
- 출력의`www.example.com/cdn-cgi/trace`브라우저에서`500`오류가 관찰되었습니다 (replace`www.example.com`실제 도메인 및 호스트 이름과 함께

:::참조

웹 사이트를 방문 할 때 빈 또는 흰색 페이지를 관찰하면 문제가 발생했는지 확인하십시오.[일시적인 포장 Cloudflare](/fundamentals/manage-domains/pause-cloudflare/)호스팅 제공업체에게 문의하세요.
주요 특징

### Workers-특성 원인

오류 500은 Cloudflare Workers를 사용할 때 발생할 수 있습니다.

- Cloudflare 노동자는 실행 시간 JavaScript 예외를 던졌습니다 (참고하십시오[오류 1101](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1101/))

Workers를 사용하는 경우 Workers 대시보드XQ를 오류 로그 및 예외로 확인하십시오.

### 문제 해결 단계

1. **최근 구성 변경 사항 보기**: 요청 처리에 영향을 미칠 수있는 페이지 규칙, 변형 규칙 또는 WorkersXQ에 대한 최근 변경 사항을 검토하십시오.
2. **Verify 근원 연결**: 소스 서버가 올바르게 응답하고 수락 가능한 시간대 내에서 응답합니다.
3. **Workers 로그 검토**: Workers를 사용하는 경우 JavaScript 예외 또는 Workers QXQXQXQXQXQ에서 CPU 시간 제한 오류를 확인하십시오.
4. **Cloudflare를 사용한 테스트**: 임시 일시 정지 CloudflareXQ는 문제가 발생하면 결정합니다.

### 알려진 Cloudflare 문제 HTTP 오류 500

- 페이지 규칙의 구성 문제는 HTTP 오류를 생성할 수 있습니다.`500`. 참고[페이지 규칙 문제 해결](/rules/page-rules/troubleshooting/general/#error-500-internal-server-error)자세한 내용 및 해상도.

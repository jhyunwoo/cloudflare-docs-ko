## 오류 1036 : 잘못된 요청 재 작성 (최대 길이 초과)

이 오류는 rewritten URI 경로 또는 쿼리 문자열이 최대 허용 길이를 초과한다는 것을 나타냅니다.

### 일반적인 원인

rewritten URI 경로 또는 쿼리 문자열의 값 또는 표현은 너무 길다.

### 제품 설명

새로운 URI 경로/query 문자열 값에 대한 짧은 값 또는 표현을 사용합니다.

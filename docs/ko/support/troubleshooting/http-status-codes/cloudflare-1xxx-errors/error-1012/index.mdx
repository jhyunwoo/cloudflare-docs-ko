## 오류 1012 : 접근 거부

이 오류는 웹 사이트에 액세스하는 것을 거부합니다.

### 일반적인 원인

웹 사이트 소유자는 방문자의 컴퓨터 또는 네트워크 (ip address)에서 감지 악의적 인 활동을 기반으로합니다. 가장 가능성이 원인은 방문자의 컴퓨터에서 바이러스 또는 악성 바이러스 감염입니다.

### 제품 설명

바이러스 백신 소프트웨어를 업데이트하고 전체 시스템 스캔을 실행하십시오. Cloudflare는 보안 설정을 무시할 수 없습니다 사이트 소유자는 도메인을 설정했습니다. 웹 사이트 액세스를 요청하려면 사이트 소유자에게 IP 주소를 허용하십시오. 웹 사이트 소유자에게 연락하는 방법을 결정할 수 없다면 도메인에 대한 연락처 정보를 검색하십시오.[Whois 데이터베이스](https://lookup.icann.org/).

:::참조
웹 사이트 소유자가 차단을 수행했기 때문에 Cloudflare 지원은 고객의 보안 설정을 무시할 수 없습니다.

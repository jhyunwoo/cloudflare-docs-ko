## 오류 1000 : IP를 금지하는 DNS 포인트

이 오류는 Cloudflare DNS 레코드 포인트가 금지된 IP로, 요청된 도메인에 대한 액세스를 차단한다는 것을 나타냅니다.

### 일반적인 원인

Cloudflare는 다음 이유 중 하나에 대한 요청을 중단 :

- Cloudflare DNS 앱 포인트 내의 기록[Cloudflare IP 주소](https://www.cloudflare.com/ips/), 또는 proxied 기록에 짐 Balancer 근원 점.
- Cloudflare DNS A 또는 CNAME 레코드 참고 자료s 또 다른 역 프록시 (nginx 웹 서버와 같은 프록시 pass 기능을 사용하는) 다음 Cloudflare에 요청을 두 번째로 프록시합니다.
- 자주 묻는 질문`X-Forwarded-For`헤더는 100자 이상입니다.
- 요청은 두 개의`X-Forwarded-For`머리.
- 요청은 포함`CF-Connecting-IP`헤더.
- Server Name Indication (SNI) 문제 또는 원래의 잘못.

### 제품 설명

- Cloudflare DNS 앱 포인트 안에 기록하는 경우[Cloudflare IP 주소](https://www.cloudflare.com/ips/), 당신의 근원 웹 서버 IP 주소에 IP 주소를 업데이트하십시오. IP 주소를 얻는 데 도움이 필요한 경우 호스팅 제공 업체에 도달하십시오.
- Cloudflare 프록시를 통해 요청을 전송하는 원산지의 역 프록시가 있습니다. 대신 역 프록시를 사용하여 호스팅 제공 업체 또는 사이트 관리자에게 HTTP 리디렉션을 구성합니다.

## 오류 1014 : CNAME 크로스 사용자 금지

이 오류는 다른 Cloudflare 계정의 도메인 사이에 CNAME 레코드가 금지되어 있음을 나타냅니다.

### 일반적인 원인

기본적으로, Cloudflare는 다른 QXQX0001XQQ 계정에서 도메인 사이 DNS CNAME 레코드를 prohibits. CNAME 레코드는 도메인 내에서 허용됩니다 (`www.example.com`CNAME 에`api.example.com`)와 같은 사용자 계정 내의 영역 (`www.example.com`CNAME 에`www.example.net`) 또는 우리의 사용[SaaS를 위한 Cloudflare](https://www.cloudflare.com/saas/)해결책.

다른 일반적인 원인은 사용자 정의 도메인을 R2 버킷에 연결하고 도메인은 활성 영역입니다.[지역 파악](/fundamentals/account/account-security/zone-holds/)기능 활성화 또는 영역이 금지되는 경우.

### 제품 설명

- CNAME 레코드 해상도를 다른 Cloudflare 계정에서 도메인에 허용하려면 CNAME 대상의 도메인 소유자가 사용해야합니다.[SaaS를 위한 Cloudflare](/cloudflare-for-platforms/cloudflare-for-saas/).
- 사용자 정의 도메인과 R2 버킷에 연결 할 수 있도록[지역 파악](/fundamentals/account/account-security/zone-holds/)1014 오류를 해결하기 위해 사용자 정의 도메인 대상 영역에 기능.
- R2 버킷에 연결을 허용하려면 지역이 금지됩니다.

  - 첫째, 어떤 것이 있는지 확인[phishing 보고서](/fundamentals/reference/report-abuse/complaint-types/)hostname의 경우 (하나가 있다면 리뷰 요청).
  - 둘째, 선불 송장 (s)이 없으므로 새로운 서비스를 활성화 할 수 없습니다.[어떤 걸출한 균형](/billing/pay-invoices-overdue-balances/)이름 \* 문제가 해결되지 않으면 계정 팀에 문의하십시오.

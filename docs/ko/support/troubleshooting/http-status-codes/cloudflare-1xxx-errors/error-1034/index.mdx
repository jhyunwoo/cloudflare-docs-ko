## 오류 1034 : 가장자리 IP 제한

이 오류는 도메인에 사용되는 IP 주소가 Cloudflare의 가장자리 검증에 의해 제한된다는 것을 나타냅니다.

### 일반적인 원인

이전에 도메인을 지적한 고객`1.1.1.1`지금 만나기`1034`오류. 이 CloudflareQ의 시스템에서 새로운 가장자리 검증 검사로 인해 잘못 구성 및 / 또는 잠재적 인 학대를 방지합니다.

### 제품 설명

DNS 레코드를 관리할 IP 주소로 점유하고, IP 주소가 "originless" 설정에 필요한 경우, IPv6 예약 주소를 사용하십시오.`100::`또는 IPv4 예약 주소`192.0.2.0`.

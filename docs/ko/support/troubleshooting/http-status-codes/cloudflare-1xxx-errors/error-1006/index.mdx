## 오류 1006, 1007, 1008 또는 1106 액세스 거부 : 귀하의 IP 주소가 금지되었습니다

이 오류는 IP 주소가 금지되어 있기 때문에 액세스가 거부된다는 것을 나타냅니다.

### 일반적인 원인

Cloudflare 고객은 고객 또는 브라우저에서 트래픽을 차단했습니다.

:::참조

오류 1006 또한 Cloudflare에서 발생합니다**모델 번호: Workers**앱 아래**다운로드**고객 사용시 &#xD0ED;**[지역 Lockdown](/waf/tools/zone-lockdown/)**&#xB610;는 다른 Cloudflare 보안 기능은 Google Cloud Platform IP를 차단하는 기능**다운로드**탭에 의존합니다.
주요 특징

### 제품 설명

Cloudflare 보안 설정을 조사하거나 클라이언트 IP 주소를 허용하는 웹 사이트 소유자를 요청하십시오. 웹 사이트 소유자가 귀하의 요청을 차단했기 때문에 Cloudflare 지원은 고객의 보안 설정을 무시할 수 없습니다.

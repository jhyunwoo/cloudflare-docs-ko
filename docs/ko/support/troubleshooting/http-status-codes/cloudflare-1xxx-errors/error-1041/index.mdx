## 오류 1041 : 잘못된 요청 리깅 (무효한 헤더 값)

이 오류는 헤더 값이 유효하지 않다는 것을 나타냅니다.

### 일반적인 원인

추가/변경된 헤더 값은 너무 길거나 허용되지 않은 문자를 포함합니다.

### 제품 설명

- 더 짧은 값이나 표현을 사용하여 헤더 값을 정의합니다.
- 허용되지 않은 문자를 제거하십시오. 관련 기사[HTTP 요청 헤더 이름과 값의 형식](/rules/transform/request-header-modification/reference/header-format/)Developer Docs는 허용된 문자에 대한 자세한 정보를 제공합니다.

## 오류 1037 : 잘못된 재쓰기 규칙 (표현을 평가하기 위해 실패)

이 오류는 규칙 표현이 평가되지 않을 수 있음을 나타냅니다.

### 일반적인 원인

이 오류에 대한 몇 가지 원인이 있지만 평가 될 때 정의되지 않은 값이 포함 된 것을 의미 할 수 있습니다.

예를 들어 다음과 같은 URL을 사용하여 1037 오류가 동적 표현과`X-Source`헤더는 요청에 포함되지 않습니다:

`http.request.headers["x-source"][0]`

### 제품 설명

모든 요소를 다시 작성하는 표현은 정의됩니다. 예를 들어, 헤더 값을 참조하면 헤더가 설정됩니다.

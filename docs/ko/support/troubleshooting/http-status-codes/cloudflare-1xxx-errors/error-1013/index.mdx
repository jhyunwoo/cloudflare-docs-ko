## 오류 1013 : HTTP 호스트 이름 및 TLS SNI 호스트 이름 잘못

이 오류는 HTTP hostname과 TLS SNI hostname 사이의 mismatch를 나타냅니다.

### 일반적인 원인

클라이언트 또는 브라우저로 보내는 호스트명<GlossaryTooltip term="Server Name Indication (SNI)">서버 이름 표시 (SNI)</GlossaryTooltip>요청 호스트 헤더와 일치하지 않습니다.

### 제품 설명

오류 수정`1013`다음과 같이 일반적으로 발생:

- incorrect SNI 호스트 헤더 또는
- 네트워크 프록시 SSL 트래픽은 SNI와 요청 호스트 헤더 사이에 mismatch를 발생했습니다.

온라인 도구를 통해 SNI mismatch에 대한 테스트[SSL 호퍼](https://www.sslshopper.com/ssl-checker.html).

Cloudflare 다음 정보를 지원:

- ·[HAR 파일](/support/troubleshooting/general-troubleshooting/gathering-information-for-troubleshooting-sites/)오류를 확산하면서 캡처.

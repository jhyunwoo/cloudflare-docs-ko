## 오류 1018 : 호스트를 찾을 수 없습니다

이 오류는 호스트가 찾을 수 없다는 것을 나타냅니다.

### 일반적인 원인

- Cloudflare 도메인은 최근에 활성화되었으며 Cloudflare 가장자리 네트워크에 도메인의 설정을 전파하는 지연이 있습니다.
- Cloudflare 도메인은 Cloudflare 파트너 (예 : 호스팅 제공 업체) 및 공급자의 DNS가 실패했습니다.

:::참조
오류 1018은 HTTP를 통해 반환됩니다.`409`응답 부호.
주요 특징

### 제품 설명

제품정보[Cloudflare 지원](/support/contacting-cloudflare-support/)뒤에 오는 세부사항으로:

- 도메인 이름.
- 스크린 샷`1018`오류 포함[**레이 ID**](/fundamentals/reference/cloudflare-ray-id/)오류 메시지에 언급.
- ·[HAR 파일](/support/troubleshooting/general-troubleshooting/gathering-information-for-troubleshooting-sites/)오류를 확산하면서 캡처.

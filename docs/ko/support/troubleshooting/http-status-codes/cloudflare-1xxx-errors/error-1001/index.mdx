## 오류 1001: DNS 해상도 오류

이 오류는 요청된 도메인에 접근을 방지하는 DNS 해상도 실패를 나타냅니다.

### 일반적인 원인

- 웹 요청은 Cloudflare IP 주소로 전송되었습니다.
- CloudflareXQ는 Cloudflare에 도메인 활성에 CNAME 레코드가 없습니다
- DNS CNAME 레코드의 대상은 해결되지 않습니다.
- Cloudflare DNS 앱의 CNAME 레코드는 현재 오프라인으로 DNS 공급자를 통해 해결해야 합니다.
- [항상 온라인](/cache/how-to/always-online/)지원하다[사용자 정의 호스트 이름 (SaaS 용 Cloudflare)](/cloudflare-for-platforms/cloudflare-for-saas/)사이트 맵

### 제품 설명

비-Cloudflare 도메인은 Cloudflare 도메인에 CNAME을 할 수 없으며 비-CloudflareXQ 도메인이 Cloudflare 계정에 추가됩니다.

직접 DNS 레코드에 액세스하려면[Cloudflare CNAME 설정](/dns/zone-setups/partial-setup)또한 오류 1001을 발생합니다. 예를 들어,`www.example.com.cdn.cloudflare.net`.

사용 방법[항상 온라인](/cache/how-to/always-online/#enable-always-online), 사용시[사용자 정의 호스트 이름 (SaaS 용 Cloudflare)](/cloudflare-for-platforms/cloudflare-for-saas/)사이트 맵

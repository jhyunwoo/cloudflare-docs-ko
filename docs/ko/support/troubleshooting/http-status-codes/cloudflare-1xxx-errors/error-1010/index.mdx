## 오류 1010 :이 웹 사이트의 소유자는 브라우저의 서명을 기반으로 액세스 금지

이 오류는 웹 사이트에 액세스하는 것은 브라우저의 서명을 기반으로 거부됩니다.

### 일반적인 원인

웹 사이트 소유자는 고객의 웹 브라우저를 기반으로 요청을 차단했습니다.

### 제품 설명

차단의 웹 사이트 소유자를 통지합니다. 웹 사이트 소유자에게 연락하는 방법을 결정할 수 없다면 도메인에 대한 연락처 정보를 검색하십시오.[Whois 데이터베이스](https://lookup.icann.org/). 사이트 소유자는 할 수 있습니다[브라우저 Integrity 체크 아웃](/waf/tools/browser-integrity-check/#disable-browser-integrity-check)보안에서**계정 설정**사이트 맵

:::참조
웹 사이트 소유자가 차단을 수행했기 때문에 Cloudflare 지원은 고객의 보안 설정을 무시할 수 없습니다.

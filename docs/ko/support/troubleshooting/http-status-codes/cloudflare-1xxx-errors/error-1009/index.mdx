## 오류 1009 액세스 거부 : 국가 또는 지역 금지

이 오류는 웹 사이트에 액세스하는 것은 국가 또는 지역에서 거부됩니다.

### 일반적인 원인

웹 사이트의 소유자 (예를 들어,`example.com`) 국가 또는 지역이 웹 사이트에 액세스하여 IP 주소를 금지했습니다.

### 제품 설명

IP 주소가 허용됩니다.[IP 액세스 규칙](/waf/tools/ip-access-rules/)보안 기능.

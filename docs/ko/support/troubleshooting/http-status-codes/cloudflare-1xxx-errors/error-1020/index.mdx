## 오류 1020 : 액세스 거부

이 오류는 웹 사이트에 액세스하는 것은 Cloudflare 방화벽 규칙에 의해 거부됩니다.

### 일반적인 원인

클라이언트 또는 브라우저는 Cloudflare 고객 방화벽 규칙(deprecated)에 의해 차단됩니다.

### 제품 설명

웹 사이트 소유자가 아닌 경우 웹 사이트 소유자에게 스크린 샷을 제공`1020`당신이 받은 오류 메시지.

웹 사이트 소유자 인 경우 :

이 문서에 포함 된 오류는 CloudflareXQ에 의해 웹 사이트에 액세스 할 때 발생할 수 있습니다. Cloudflare API 또는 대시보드QQ와 관련된 문제점은, 우리의 참고합니다[Cloudflare API 문서](/api/).

HTTP 오류와 같은`409`, `530`, `403`·`429`응답의 HTTP 상태 헤더에 반환되며, 1XXX 오류가 응답의 HTML 몸에 나타납니다.

:::note\[주문 오류 페이지]
더 알아보기[사용자 정의 오류](/rules/custom-errors/)이 문서에서 논의 된 기본 오류 페이지를 사용자 정의에 대한 지침.
주요 특징

### 지원 및 지원

각 오류에 대한 제안 된 해상도가 문제점을 해결하지 않으면 연락처[Cloudflare 지원](/support/contacting-cloudflare-support/).

- 웹 사이트 소유자 만 기술 지원을위한 Cloudflare에 문의 할 수 있습니다. 도메인의 연락처 세부 정보를 찾을 수 있습니다.[비밀번호](https://lookup.icann.org/).
- Pro, Business 및 Enterprise 계획 사용자는 이메일 지원에 액세스 할 수 있습니다.
- Business and Enterprise 사용자는 채팅 지원을 액세스 할 수 있습니다.
- 추가 지원 옵션의 경우, 참조[Cloudflare 계획](https://www.cloudflare.com/plans/).

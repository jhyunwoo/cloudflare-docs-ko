## 오류 1035 : 잘못된 요청 재 작성 (무효한 URI 경로)

이 오류는 요청의 잘못된 URI 경로를 나타냅니다.

### 일반적인 원인

rewritten URI 경로의 값 또는 표현은 유효하지 않습니다.

이 오류는 URL rewrite의 대상이 아래 경로가 될 때 발생합니다.`/cdn-cgi/`.

### 제품 설명

rewritten URI 경로가 비어 있지 않다는 것을 확인합니다.`/`(slash) 캐릭터.

예를 들어, 다음과 같은 URI 경로 재 작성 표현은 유효하지 않습니다 :

`concat(lower(ip.src.country), http.request.uri.path)`

위의 표현을 수정하려면 추가`/`접두사:

`concat("/", lower(ip.src.country), http.request.uri.path)`

## 오류 1023 : 호스트를 찾을 수 없습니다

이 오류는 호스트가 구성 문제 또는 전파 지연으로 인해 찾을 수 없다는 것을 나타냅니다.

### 일반적인 원인

- 소유자가 CloudflareXQ에 가입하면 웹 사이트의 정보에 대한 몇 분이 글로벌 네트워크에 배포 될 수 있습니다. 사이트의 구성에 문제가 있습니다.
- 일반적으로, 계정이 파트너 조직 (예를 들어, 호스팅 제공자)과 공급자의 DNS가 실패했을 때 발생합니다.

:::참조
오류 수정`1023`HTTP를 통해 반환`503`응답 부호.
주요 특징

### 제품 설명

제품정보[Cloudflare 지원](/support/contacting-cloudflare-support/)뒤에 오는 세부사항으로:

- 도메인 이름.
- 스크린 샷`1023`오류 포함[**레이 ID**](/fundamentals/reference/cloudflare-ray-id/)오류 메시지에 언급.
- ·[HAR 파일](/support/troubleshooting/general-troubleshooting/gathering-information-for-troubleshooting-sites/)오류를 확산하면서 캡처.

## 오류 1200 : 캐시 연결 제한

이 오류는 Cloudflare의 가장자리가 한계를 초과하는 요청 수를 나타냅니다.

### 일반적인 원인

원래 웹 서버에서 프로세스를 기다리고있는 Cloudflare의 가장자리에 너무 많은 요청이 있습니다. 이 한계는 Cloudflare의 체계를 보호합니다.

### 제품 설명

Tune 당신의 근원 webserver는 들어오는 연결을 빨리 받아들입니다. 캐시 히트율을 개선하기 위해 캐싱 설정을 조정하여 몇 가지 요청이 웹 서버에 도달합니다. 호스팅 제공 업체 또는 웹 관리자에게 도움을 주셔서 감사합니다.

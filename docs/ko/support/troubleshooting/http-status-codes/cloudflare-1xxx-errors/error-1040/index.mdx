## 오류 1040 : 잘못된 요청 재 작성 (헤더 수정 허용되지 않음)

이 오류는 제한된 HTTP 헤더를 수정하기 위해 시도되었다는 것을 나타냅니다.

### 일반적인 원인

Header Transform 규칙을 변경할 수 없는 HTTP 헤더를 수정하려고 합니다.

### 제품 설명

당신이 수정하려고 하지 않도록[HTTP 요청 헤더](/rules/transform/request-header-modification/#important-remarks).

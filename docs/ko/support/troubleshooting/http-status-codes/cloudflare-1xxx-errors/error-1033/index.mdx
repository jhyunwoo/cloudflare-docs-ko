## 오류 1033 : Cloudflare 터널 오류

이 오류는 문제점을 나타냅니다.[Cloudflare 갱도](/cloudflare-one/networks/connectors/cloudflare-tunnel/).

### 일반적인 원인

웹 사이트에 페이지를 요청했습니다 (`tunnel.example.com`) Cloudflare 네트워크에 있습니다. 호스트 (`tunnel.example.com`)는 Cloudflare 갱도로 구성되고, Cloudflare는 현재 그것을 해결할 수 없습니다.

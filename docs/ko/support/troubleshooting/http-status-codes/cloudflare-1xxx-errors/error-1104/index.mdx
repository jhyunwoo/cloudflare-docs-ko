## 오류 1104: 이 이메일 주소의 변화는 이미 우리 시스템에 촬영. 한 변이 허용됩니다.

이 오류는 추가하려고 하는 이메일 주소는 이미 시스템에 촬영.

### 일반적인 원인

이 오류는 이메일이 추가되었는지 확인할 수 있습니다. 예를 들어,`my+user@example.com`·`my.user@example.com`우리의 체계에서 동일한 대우될 것입니다.

### 제품 설명

이전 사용자로 로그인하고 새로운 이메일을 무료로 "throwaway"주소로 이메일을 변경하십시오.

## Error 1004: 웹 트래픽을 Serve로 구성하지 않는 호스트

이 오류는 호스트가 웹 트래픽을 제공하지 않는 것을 나타냅니다.

### 일반적인 원인

- Cloudflare 직원은 서비스 위반의 남용 또는 용어로 인해 도메인에 대한 책임을 지지 않습니다.
- DNS 변경은 아직 전파되지 않았거나 사이트 소유자의 DNS 레코드 포인트[Cloudflare IP 주소](https://www.cloudflare.com/ips).

### 제품 설명

5 분 이상의 문제가 발생하면[접촉 Cloudflare 지원](/support/contacting-cloudflare-support/).

## 오류 1102 : 노동자는 자원 제한을 초과

이 오류는 Cloudflare 노동자는 그것의 CPU 시간 한계 또는 기억 한계를 초과했습니다.

### 흥분된 CPU 시간

Cloudflare 노동자는 초과합니다[CPU 시간 제한](/workers/platform/limits/#cpu-time). CPU 시간은 시간을 보냈다 실행 코드 (예를 들어, 루프, JSON을 파싱 등). 네트워크 요청에 소요되는 시간(그림, 응답)은 CPU 시간으로 계산되지 않습니다.

#### 관련 링크

CPU 집중 코드를 식별하려면:

1. 제품 정보[DevTools와 CPU 프로파일링](/workers/observability/dev-tools/cpu-usage/)로컬로 비싼 작업을 식별합니다.
2. 이름 \*[Workers 로그](/workers/observability/logs/workers-logs/)- CPU 시간은 invocation log에서 표면 처리됩니다. 이 특정 경로 또는 요청이 높은 CPU 시간을 소비하는 경우 찾을 수 있습니다.

#### 제품 설명

WorkersXQ 코드의 개발자에게 CPU 사용률을 최적화합니다. 일반적인 최적화 전략은 다음과 같습니다 :

- 반복의 반복의 수를 감소
- JSON 파싱 작업 최적화
- Caching computed 값
- 더 작은 펑크로 큰 작업을 파괴

당신은 또한 할 수 있습니다[CPU 시간 제한 증가](/workers/platform/limits/#cpu-time)Workers에서 CPU-바운드 작업을위한 5 분까지 유료 계획.

### 흥분된 기억

Cloudflare 노동자는 초과합니다[128 MB 메모리 제한](/workers/platform/limits/#memory). 이것은 per-isolate 한계입니다, isolate는 배수 요청을 concurrently 취급할지도 모릅니다.

#### 관련 링크

메모리 문제를 식별하려면:

1. 제품 정보[DevTools와 메모리 프로파일링](/workers/observability/dev-tools/memory-usage/)로컬 메모리 스냅샷을 가지고 누출을 식별합니다.
2. 대형(request or response)이 될 수 있는 몸 버퍼링과 같은 패턴을 찾습니다.

#### 제품 설명

기억 한계를 초과하는 것을 피하기 위하여:

- 메모리에 큰 물체 또는 응답을 버퍼 방지
- 같은 스트리밍 API 사용[`TransformStream`](/workers/runtime-apis/streams/transformstream/)또는[`node:stream`](/workers/runtime-apis/nodejs/streams/)버퍼링 없이 데이터 처리
- 글로벌 범위에서 큰 개체를 저장하지 마십시오
- 축적된 데이터(예를 들어, 문자열이나 배열을 반복적으로 적용)하는 작업과 주의

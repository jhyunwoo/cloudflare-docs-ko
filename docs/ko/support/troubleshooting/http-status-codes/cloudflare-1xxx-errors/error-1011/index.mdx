## 오류 1011 : 액세스 Denied (핫 링크드 인)

이 오류는 자원에 액세스하는 것은 핫 링크 보호로 인해 거부됩니다.

### 일반적인 원인

요청은 사용하는 자원에 사용됩니다.[Cloudflare 핫 링크 보호](/waf/tools/scrape-shield/hotlink-protection/).

### 제품 설명

차단의 웹 사이트 소유자를 통지합니다. 웹 사이트 소유자에게 연락하는 방법을 결정할 수 없다면 도메인에 대한 연락처 정보를 검색하십시오.[Whois 데이터베이스](https://lookup.icann.org/).

:::참조
웹 사이트 소유자가 차단을 수행했기 때문에 Cloudflare 지원은 고객의 보안 설정을 무시할 수 없습니다.

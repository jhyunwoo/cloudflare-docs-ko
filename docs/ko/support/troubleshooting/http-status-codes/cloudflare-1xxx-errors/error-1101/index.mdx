## 오류 1101: 오류 렌더링

이 오류는 렌더링 문제를 나타냅니다.

### 일반적인 원인

이 오류는 일반적으로 Cloudflare 노동자는 가동 시간 JavaScript 예외를 만납니다.

### 관련 링크

특정 JavaScriptXQ 예외를 식별하려면:

1. Workers 로그를 Cloudflare 대시보드XQ에서 확인하십시오.**Workers & Pages** > **당신의 노동자** > **로그인**.
2. Workers 코드를 검토하여 잠재적 인 실행 시간 오류와 같은:
   - undefined 변수 또는 함수
   - 유형 오류
   - 약속
   - 네트워크 요청 실패
3. 시험하기[작업자 로컬](/workers/development-testing/#local-development)샘플 요청으로 오류를 재현합니다.
4. 더 알아보기[Workers 오류 처리](/workers/observability/errors/)WorkersXQ를 디버깅에 대한 자세한 내용은.

### 제품 설명

JavaScriptXQ 예외를 Workers 코드를 수정합니다. 도움이 필요한 경우,[적절한 문제 세부 사항 제공](/support/contacting-cloudflare-support/)다음을 포함하는 Cloudflare 지원에:

- 오류 페이지에서 Ray ID
- 노동자 이름
- Worker 코드의 최근 변경
- 오류를 재현하는 단계

### 관련 오류

- [오류 1102](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/error-1102/)- Workers CPU 시간 제한 초과
- [오류 500](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-500/)- 내부 서버 오류 (Workers 예외로 발생할 수 있음)

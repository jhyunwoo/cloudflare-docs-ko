## 오류 1005 액세스 거부 : 자율 시스템 번호 (ASN) 금지

이 오류는 Autonomous System Number (ASN)의 금지로 인해 웹 사이트에 액세스하는 것을 나타냅니다.

### 일반적인 원인

웹 사이트의 소유자 (예를 들어,`example.com`) 웹 사이트에 액세스에서 자율 시스템 번호 (ASN) 금지.

### 제품 설명

웹 사이트 소유자가 아니라면 수신 된 1005 오류 메시지의 스크린 샷이있는 웹 사이트 소유자를 제공합니다.

웹 사이트 소유자 인 경우 :

1. 스크린 샷을 검색`1005`고객의 소리
2. 자주 묻는 질문[**보안 이벤트 로그**](/waf/analytics/security-events/)(사용 가능)**보안 보안** > **(주)**)에 대한[**레이 ID**](/fundamentals/reference/cloudflare-ray-id/), 또는 클라이언트 IP 주소 방문자의 1005 오류 메시지.

:::참조
UTC 타임스탬프를 변환`1005`현지 시간대에 오류가 발생하면**보안 이벤트 로그**.
:::

3. 블록의 원인을 확인하고 ASN이 허용되도록[IP 액세스 규칙](/waf/tools/ip-access-rules/)보안 기능.

## 오류 1025 : 나중에 다시 확인하시기 바랍니다

이 오류는 도메인이 Cloudflare Workers에 대한 플랜 제한을 도달했다고 나타냅니다.

### 일반적인 원인

도메인이 도달했기 때문에 요청은 서비스되지 않습니다.[Cloudflare QXWorkers](/workers/platform/limits).

### 해결책:

무제한 Workers 플랜 구입[계획 페이지](https://dash.cloudflare.com/redirect?account=workers/plans)Workers 대시보드에.

## 오류 1015 : 제한 된 비율입니다.

이 오류는 웹 사이트에서 제한된 비율이 있음을 나타냅니다.

### 일반적인 원인

사이트 소유자 구현[비율 제한](/waf/reference/legacy/old-rate-limiting/)방문자 트래픽에 영향을 미칩니다.

:::참조
*뚱뚱하다*다른 것`1015`오류 코드 관련[Cloudflare 캐시 퍼지](/cache/how-to/purge-cache). 캐시 퍼지와 접촉을 재기[Cloudflare 지원](/support/contacting-cloudflare-support/)오류가 발생하면
주요 특징

### 제품 설명

- 사이트 방문자 인 경우 사이트 소유자에게 연락하여 IP의 예외를 요청하십시오.
- 사이트 소유자 인 경우, 리뷰[모델 번호: Cloudflare 비율 한계 문](/waf/reference/legacy/old-rate-limiting/)그리고 당신의 비율 제한 윤곽을 조정하십시오.
- 짧은 시간 내에 블록 요청을 제한하는 경우 (예를 들어, 1 초) 시간이 10 초로 증가합니다.

:::참조
새로운 CloudflareXQ를 기대한다면 작업자 비율 제한을 초과, 참조[Workers 문서](/workers/platform/limits/)관련 기사

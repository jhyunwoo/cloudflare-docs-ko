## 오류 1002: IP에 DNS 포인트

이 오류는 Cloudflare DNS 레코드 포인트를 금지 IP로 표시하고 적절한 도메인 해상도를 방지합니다.

### 일반적인 원인

- Cloudflare DNS 앱 포인트에 DNS 레코드[Cloudflare의 IP 주소](https://www.cloudflare.com/ips/).
- 잘못된 대상은 Cloudflare DNS 앱에서 CNAME 레코드에 지정됩니다.
- 도메인은 CloudflareXQ에 없지만 Cloudflare 도메인을 나타내는 CNAME이 없습니다.

### 제품 설명

Cloudflare 업데이트 Cloudflare IP 주소 대신 원산지 IP 주소에 대한 CNAME 레코드 :

1. 호스트 IP 주소 또는 CNAME 레코드 대상을 확인하려면 호스팅 제공 업체에 문의하십시오.

2. Cloudflare 대시보드에서, 가십시오**이름 \***&#xC0AC;이트 맵

   <DashButton url="/?to=/:account/:zone/dns/records" />

3. 오류 1002를 생성하는 도메인을 선택하십시오.

4. 선택하기**DNS 보호**앱.

5. 제품정보**제품정보**업데이트에 대한 기록.

6. A 기록을 업데이트합니다.

당신의 근원 웹 서버를 지키는 것은 Cloudflare를 통해 그것의 자신의 요구를 프록시하지 않습니다, 당신의 근원 webserver를 당신의 Cloudflare 도메인을 해결하기 위하여 구성하십시오:

- 내부 NAT'd IP 주소 또는
- 웹 서버의 공개 IP 주소.

## 오류 1002: 제한

이 오류는 도메인이 제한되거나 IP 주소를 비활성화하는 것을 나타냅니다.

### 일반적인 원인

Cloudflare 도메인은 로컬 또는 IP 주소 또는 도메인과 관련된 IP 주소로 해결합니다.

### 제품 설명

웹 사이트를 소유하는 경우 :

1. 호스팅 공급자와 함께 웹 서버 IP 주소를 확인,
2. CloudflareXQ 계정에 로그인하고,
3. 호스팅 공급자가 확인한 IP 주소에 Cloudflare DNS 앱의 레코드를 업데이트하십시오.

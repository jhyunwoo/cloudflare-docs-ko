## 401 인증

이 오류는 요청이 적절한 인증 자격 증명으로 전송되지 않았다는 것을 나타냅니다. 서버는 요청을 처리하는 인증이 필요합니다.

더 자세한 내용은 참조[RFC 7235년](https://tools.ietf.org/html/rfc7235).

### 일반적인 사용 사례

·`401 Unauthorized`클라이언트가 유효한 인증 자격 증명을 제공할 때 오류가 발생합니다. 서버는 적어도 하나의 문제로 응답합니다.`WWW-Authenticate`header 필드, outlined in[단면도 4.1](https://datatracker.ietf.org/doc/html/rfc7235#section-4.1).

클라이언트가 동일한 자격 증명과 같은 요청을 거부하고 도전은 변경되지 않습니다, 서버는 필요한 올바른 자격 증명을 식별하는 클라이언트를 지원할 수있는 법인을 반환 할 수 있습니다.

### Cloudflare-특징 정보

참여할 때`401`Cloudflare API를 사용하는 동안 오류는 올바른 인증 자격 증명 (예를 들면,[API 토큰](/fundamentals/api/get-started/create-token/)또는[지원하다](/fundamentals/api/get-started/ca-keys/)). 두 배 체크는 credentials가 활동적이고 제대로 형식화된다는 것을. 오류가 발생하면, 참조`WWW-Authenticate`문제 해결에 대한 지침에 대한 응답 헤더.

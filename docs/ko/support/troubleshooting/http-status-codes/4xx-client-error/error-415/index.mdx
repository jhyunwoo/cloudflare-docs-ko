## 415 지원되지 않은 미디어 유형

더 보기`415 Unsupported Media Type`상태 코드는 서버가 payload의 형식이 지원되지 않기 때문에 요청을 처리하는 것을 나타냅니다. 이 문제를 식별하고 수정하는 방법`Content-Type`또는`Content-Encoding`headers는 클라이언트의 요청에 보냈습니다.

더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

서버가 지원되지 않은 이미지 또는 문서 형식을 업로드와 같은 핸들을 구성하지 않는 파일 형식 또는 형식을 제출함으로써 트리거 될 수 있습니다, 또한이 오류를 트리거 할 수 있습니다.

### Cloudflare-특징 정보

Cloudflare는 일반적으로 클라이언트의 요청 페이로드에서 지원되지 않은 미디어 유형을 만날 경우 원래 서버에서이 응답을 전달합니다.

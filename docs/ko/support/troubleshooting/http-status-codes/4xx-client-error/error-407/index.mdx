## 407 인증

더 보기`407 Proxy Authentication Required`상태 코드는 클라이언트가 프록시 서버를 통해 요청한 리소스에 액세스하기 위해 필요한 인증 자격 증명을 제공하지 않았다는 것을 나타냅니다.
더 자세한 내용은 참조[RFC 7235년](https://tools.ietf.org/html/rfc7235).

### 일반적인 사용 사례

이 오류는 일반적으로 프록시 서버가 클라이언트와 대상 서버 간의 상호 작용으로 사용됩니다. 이 문제를 해결하기 위해 클라이언트는 적절한`Proxy-Authorization`유효한 자격 증명을 가진 요청에 있는 우두머리.

### Cloudflare-특징 정보

Cloudflare는 생성하지 않습니다`407`오류는 원래 서버 또는 업스트림 프록시에서 프록시합니다. 이름 \*`407`Cloudflare-powered 사이트에 오류가 발생하여 인증 요구 사항을 올바르게 설정하고 클라이언트가 필요한 자격 증명을 제공하도록 원래 서버의 프록시 구성을 검토합니다.

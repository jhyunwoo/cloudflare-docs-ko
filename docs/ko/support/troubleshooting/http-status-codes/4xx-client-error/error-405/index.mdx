## 405 허용되지 않는 방법

405 방법 허용되지 않은 상태 코드는 원래 서버가 요청한 리소스를 인식하지만 요청에 사용되는 HTTP 방법을 지원하지 않습니다.

더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

이 오류는 일반적으로 클라이언트가 특정 리소스와 상호 작용하는 지원되지 않는 HTTP 방법을 사용합니다. Origin 서버는 포함해야 합니다.`Allow`응답의 헤더, 해당 리소스에 대해 지원하는 HTTP 메소드를 나열합니다.

예를 들어, 시도`POST`변경할 수 없는 리소스에 대한 요청 및 지원`GET`요청은 결과적으로`405`오류.

### Cloudflare-특징 정보

Cloudflare는 직접 생성하지 않습니다`405`오류. 이 오류는 요청에서 사용되는 HTTP 방법을 허용하지 않을 때 원래 서버로 반환됩니다. 당신이 만난다면`405`오류, 당신의 근원 서버의 구성을 검토하여 올바른 방법을 확인하는 것은 문제의 자원에 사용할 수 있습니다.

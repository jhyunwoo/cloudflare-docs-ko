## 409 원

더 보기`409 Conflict`상태 코드는 요청이 대상 자원의 현재 상태와 충돌로 완료 될 수 없다는 것을 나타냅니다.

더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

이 오류는 일반적으로 발생합니다.`PUT`여러 클라이언트가 동일한 리소스를 편집하려고 할 때 요청. 이 문제를 해결하려면:

- 서버는 클라이언트에 대한 충분한 정보를 포함 payload를 생성하여 분쟁의 소스를 인식해야합니다.
- 클라이언트는 분쟁을 해결 한 후 다시 요청을 다시 복원해야합니다.

## 403 금지

더 보기`403 Forbidden`상태 코드는 클라이언트 요청이 서버에 의해 이해되었는지 나타내지만 요청된 리소스에 액세스하기 위해 충분한 권한으로 인해 수행 할 수 없습니다.
더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

당신이 만난다면`403`Cloudflare 브랜딩없이 오류가 CloudflareXQ가 아닌 원래 웹 서버로 직접 반환된다는 것을 의미합니다. 이것은 일반적으로 서버에서 설정된 권한 규칙과 관련이 있습니다. 이 오류의 일반적인 이유는:

- 웹 서버 (예를 들어, Apache에서 설정된 권한 규칙`.htaccess`파일).
- mod security 규칙.
- 특정 IP 범위에서 트래픽 차단과 같은 IP deny 규칙. 견적 요청[Cloudflare의 IP 범위](https://www.cloudflare.com/ips)차단되지 않습니다.

### Cloudflare-특징 정보

Cloudflare는 봉사할지도 모릅니다`403`다음 시나리오의 응답 :

- **WAF 규칙**: 요청은 기본 WAFXQ 관리 규칙을 위반 (모든 오렌지 클라우드 CloudflareXQ 도메인에 대해 사용) 또는 사용자 정의 WAF 관리 규칙을 귀하의 영역에. 더 많은 정보를 원하시면, 참조[WAF 관리 규칙](/waf/managed-rules/).

- **보안 기능**: 아`403`응답 몸에 있는 Cloudflare 브랜딩을 가진 응답은에 의해 트리거될지도 모릅니다:
  - [WAF 사용자 정의 또는 관리 규칙](/waf/)도전이나 블록 작업으로.
  - [보안 수준](/waf/tools/security-level/)기본적으로 중간에 설정한다.
  - [DDoS 보호](/ddos-protection/)기본적으로 Cloudflare, IP 애플리케이션에 내장되어 있는 영역에서 기본적으로 활성화되고, Magic Transit에 내장된 IP Prefixes.
  - 이름 \*[1xxx Cloudflare 오류 코드](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/).
  - 더 보기[브라우저 Integrity Check](/waf/tools/browser-integrity-check/).
  - [유효성 검사](/waf/tools/validation-checks/).

Cloudflare는 또한 unstyled를 봉사할지도 모릅니다`403`특정한 경우에 오류 페이지. 이 오류는 Cloudflare의 인프라에서 일찍 발생하기 때문에 로그가되지 않습니다. 도메인 구성이로드되기 전에. 예는:

- [사이트맵](https://www.cloudflare.com/learning/ssl/what-is-sni/): 아`403`클라이언트가 SNI (Server Name Indication)와 일치하지 않는 호스트를 보낼 때 오류가 반환됩니다.

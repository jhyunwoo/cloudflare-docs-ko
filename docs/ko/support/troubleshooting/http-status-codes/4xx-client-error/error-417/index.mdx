## 417 예상 실패

더 보기`417 Expectation Failed`상태 코드는 서버가 지정된 요구 사항을 충족 할 수 없다는 것을 나타냅니다.`Expect`고객의 요청 헤더.

더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

몇몇 클라이언트 사용`Expect`헤더 등`Expect: 100-continue`, 서버가 큰 페이로드를받을 준비가되어 있는지 확인하려면 서버가 기대를 충족 할 수 없다면 417 응답을 반환합니다. 마찬가지로 서버는 클라이언트가 포함되면 이 오류로 요청을 거부 할 수 있습니다.`Expect`지원되지 않은 또는 잘못된 값을 가진 헤더.

### Cloudflare-특징 정보

Cloudflare는 일반적으로 지원되지 않았거나 부풀어지지 않은 문제와 관련된 문제를 발생하면 Origin 서버에서이 응답을 전달합니다.`Expect`클라이언트의 요청에 있는 헤더.

## 400 나쁜 요구

이 오류는 클라이언트가 요청 자체에 문제가 발생하거나 처리 할 수없는 서버에 요청을 보냈습니다.

더 많은 정보를 원하시면, 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

·`400 Bad Request`오류는 클라이언트 측 문제로 인해 오류가 발생했습니다. malformed request syntax, invalid request content, message framing problem, or deceptive request routing.
예를 들면:

- 요청이 제대로 되지 않은 특수 문자를 포함 하는 경우[URL 인코딩 (또는 % 인코딩)](https://en.wikipedia.org/wiki/Percent-encoding)·`HTTP Error 400`반환됩니다.
- 요청이 모두 포함되면`Content Length`·`Transfer Encoding`chunked,이 두 framing 방법은 서로 반대합니다.`Content Length`고정 크기 몸을 선언하면서 chunked 인코딩은 알려진 크기와 스트림 바디를 선언합니다.[RFC 7230 단면도 3.3.3](https://datatracker.ietf.org/doc/html/rfc7230#section-3.3.3)그 때`Transfer Encoding`현재,`Content Length`헤더는 무시해야하며 모두 포함 된 요청은 malformed로 간주됩니다. 이것은 몸 framing에 있는 주위를 창조하고 다른 체계가 경계를 다르게 파는 경우에 smuggling 요청할 수 있습니다. Cloudflare는 RFC와 따릅니다`HTTP Error 400`반환됩니다.

### Cloudflare-특징 정보

HTTP 오류가 발생하면[모델 번호: Cloudflare](/api/), 당신이 올바른 구문, 매개 변수 및 API 호출에 대한 신체를 사용하는 것을 확인합니다.

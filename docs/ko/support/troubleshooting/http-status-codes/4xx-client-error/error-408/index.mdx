## 408 타임아웃 요청

더 보기`408 Request Timeout`상태 코드는 원래 서버가 합리적인 시간 프레임 내에서 완전한 요청을받지 못하고 연결을 기다리지 않으려는 것을 나타냅니다. 이 응답은 일반적으로 사용되지 않습니다, 서버는 종종 "닫기" 연결 옵션을 사용하여 idle 연결을 종료

더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

이 오류는 일반적으로 클라이언트가 서버의 타임 아웃 기간 내에 완전한 요청을 보낼 때 발생합니다. Common 시나리오에는 느린 네트워크 연결, 서버 하중 초과 또는 클라이언트 측 지연이 포함됩니다.

### Cloudflare-특징 정보

이름 \*`408`오류는 Cloudflare-powered 사이트에 발생, 그것은 가장 자주 기원에서 proxied. 이 경우, 원래 서버의 타임 아웃 설정을 검토하는 데 필수적이며 서버가 과부하되지 않다는 것을 보장합니다. 또한 클라이언트의 인터넷 연결이 안정적이며 요청이 신속하게 전송된다는 것을 확인합니다.

Cloudflare는 반환할지도 모릅니다`408`우리의 네트워크에 대한 공개 클라이언트 요청이 특정 내부 정의 타임 아웃을 초과하는 경우 오류 응답. 이 타임아웃은 방어적인 측정으로 구성되며 변경할 수 없습니다.

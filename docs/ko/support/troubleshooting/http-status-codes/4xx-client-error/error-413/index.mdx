## 413 Payload 너무 큰

더 보기`413 Payload Too Large`상태 코드는 서버가 클라이언트가 서버의 허용한 크기 제한을 초과하기 때문에 payload가 요청을 처리하는 것을 나타냅니다. 서버는 선택적으로 연결을 닫을 수 있습니다. 이 refusal이 일시적으로 발생하면 서버가 전송되어야 합니다.`Retry-After`클라이언트가 요청을 다시 시도 할 때 헤더를 지정합니다.

더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

더 보기`413 Payload Too Large`상태 코드는 종종 클라이언트가 비디오 또는 이미지와 같은 큰 파일을 업로드하려고 할 때 발생합니다. 또는 JSON 또는 XML 페이로드와 같은 대형 요청 몸을 보내 서버의 크기 제한을 초과합니다. 서버가 요청을 거부하기 위해 대용량 데이터셋을 포함하는 파일 전송 또는 API 요청 중에 발생할 수 있습니다.

Cloudflare API에 대한 업로드 제한은 플랜에 따라 다릅니다. 이 제한을 초과하면 API 호출이 받게됩니다.`413 Request Entity Too Large`오류.

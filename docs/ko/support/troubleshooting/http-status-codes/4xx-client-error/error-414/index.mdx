## 414 URI 토오 롱

더 보기`414 URI Too Long`상태 코드는 서버가 클라이언트가 과도하게 긴 URI가 제공했기 때문에 요청을 처리하는 것을 나타냅니다.

더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

예를 들어, 클라이언트가 시도하는 경우`GET`쿼리 매개 변수의 과도한 수를 포함하는 것과 같은 비정상적인 긴 URI를 가진 요구, 후에`POST`, 이것은 보안 위험과 것으로 볼 수`414`생성.

### Cloudflare-특징 정보

Cloudflare는 생성합니다`414`URI 길이가 32KB를 초과하면 응답.

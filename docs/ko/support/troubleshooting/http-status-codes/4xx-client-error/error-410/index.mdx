## 410 뼈

리소스가 의도적으로 제거되고 영구적으로 제거되면 서버는`410 Gone`리소스가 더 이상 사용할 수없는 클라이언트를 알리는 상태 코드.
이 경우:

- 서버는 리소스를 참조하는 링크가 제거되어야합니다.
- 서버는 이 상태 코드를 대신 사용할 의무가 없습니다`404`응답, 또는 그것은 어떤 특정 기간 동안이 응답을 유지해야합니다.

더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

이 상태는 통용되는 페이지 또는 중단된 제품과 같은 deprecated 내용에 일반적으로 적용됩니다.

### Cloudflare-특징 정보

Cloudflare는 생성하지 않습니다`410`고객 웹 사이트에 대한, 우리는 단지 소스 서버에서 요청을 프록시. 당신이 만난다면`410`Cloudflare-powered 사이트에 오류, 문제는 원래 서버와 함께. 이러한 경우, 지원을위한 호스팅 제공 업체에 문의하십시오.

## 411 길이 필수

더 보기`411 Length Required`status code는 클라이언트가 지정하지 않았다는 것을 나타냅니다.`Content-Length`머리에 요청 몸의, 이 정보는 리소스를 얻기 위해 필요합니다. 클라이언트는 필요한 헤더 필드를 추가한 후 요청을 다시 보낼 수 있습니다.

더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

이 상태 코드는 클라이언트가 요구하지 않고 API 요청을 보낼 때와 같은 다양한 시나리오에서 발생할 수 있습니다`Content-Length`헤더, 서버가 리소스를 할당할 수 있는 헤더를 필요로 하는 파일을 업로드할 때, 또는 프록시 또는 레거시 시스템이 엄격한 HTTP 준수를 시행합니다. 각 경우에, 서버 또는 중간에는 요구합니다`Content-Length`자주 묻는 질문

### Cloudflare-특징 정보

Cloudflare는 생성하지 않습니다`411`고객 웹 사이트에 대한, 우리는 단지 소스 서버에서 요청을 프록시. 당신이 만난다면`411`Cloudflare-powered 사이트에 오류, 문제는 원래 서버와 함께. 이러한 경우, 지원을위한 호스팅 제공 업체에 문의하십시오.

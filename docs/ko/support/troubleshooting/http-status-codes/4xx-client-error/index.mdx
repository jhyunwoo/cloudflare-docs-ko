`4xx`코드는 클라이언트의 끝에 문제가 나타내는 오류 응답, 잠재적으로 네트워크 문제로 인해.

- `4xx`코드는 어떤 요청에 응답으로 사용될 수 있습니다.
- Origin 서버는 User-Agent에 의해 표시되어야 하는 설명을 포함해야 합니다.`HEAD`이름 \*
- [주문 규칙](/waf/custom-rules/)어떤 응답 코드를 범위에서 반환할 수 있습니다`400–499`사이트 소유자가 규칙을 작성한 경우 HTML 페이지에*제품정보*동작 및 사용자 지정 응답 코드를 구성. 더 자세한 내용은 참조[주문 응답](/waf/custom-rules/create-dashboard/#configure-a-custom-response-for-blocked-requests).

## 로그 탐색

[로그 탐색](/log-explorer/)Cloudflare 로그에 대한 액세스는 Cloudflare 플랫폼 내에서 사용할 수있는 모든 컨텍스트를 제공합니다.
사용자 정의 대시보드S 또는 로그 검색과 문제 해결 문제를 모니터링 할 수 있습니다.
비밀번호[쿼리를 구축 할 수 있습니다](/log-explorer/log-search/)특정 필터링[레이 ID](/fundamentals/reference/cloudflare-ray-id/)HTTP Errors를 조사하는 데 유용 할 수 있습니다.

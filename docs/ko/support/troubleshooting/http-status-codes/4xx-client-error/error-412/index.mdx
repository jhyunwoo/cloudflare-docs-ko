## 412 사전 상태 실패

더 보기`412 Precondition Failed`상태 코드는 서버가 클라이언트에 의해 지정된 조건을 충족하지 않기 때문에 요청을 거부한다는 것을 나타냅니다.

더 자세한 내용은 참조[RFC 7232의](https://tools.ietf.org/html/rfc7232).

### 일반적인 사용 사례

1개의 일반적인 사용 케이스`412 Precondition Failed`상태 코드는 버전 제어입니다. 예를 들어, 클라이언트는 기존 리소스를 수정할 수 있습니다.`If-Unmodified-Since`클라이언트가 편집을 위해 그것을 다운로드했기 때문에 자원이 변경되지 않았습니다. 다른 클라이언트가 지정된 날짜 이후 리소스를 편집하지만 원래 클라이언트가 변경을 업로드하기 전에 서버가 반환됩니다`412`더 새로운 업데이트를 방지하기 위해 응답.

### Cloudflare-특징 정보

Cloudflare는 이 응답을 봉사할지도 모릅니다: 자세한 내용은 참조하시기 바랍니다[ETag 헤더](/cache/reference/etag-headers/).

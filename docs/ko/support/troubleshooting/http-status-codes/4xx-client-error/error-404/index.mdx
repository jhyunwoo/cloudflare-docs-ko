## 404 발견되지 않음

더 보기`404 Not Found`상태 코드는 지정된 리소스를 찾을 수 없습니다. 일반적으로 호스트 서버는 리소스를 찾을 수 없습니다. 이 오류의 더 영구 버전의 경우 410 Gone 상태 코드가 사용되어야합니다.

더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

이 오류는 일반적으로 웹 사이트의 URL을 잘못 입력 할 때 발생합니다. 다른 페이지의 끊긴 링크가있을 때 이전에 존재하는 페이지가 이동하거나 제거되거나 오류가 발생하거나 검색 엔진이 사이트를 색인 할 때.

이 오류는 일반적으로 전형적인 사이트의 총 페이지보기의 약 3 %를 차지합니다. 그러나 그들은 종종 Google Analytics와 같은 전통적인 분석 플랫폼에 의해 추적되지 않습니다. 사용자 경험을 향상시키기 위해 웹 사이트 소유자는 일반적으로이 오류가 생성 될 때 표시 될 사용자 정의 404 페이지를 구현합니다.

### Cloudflare-특징 정보

Cloudflare는 생성하지 않습니다`404s`고객 웹 사이트에 대한, 우리는 단지 소스 서버에서 요청을 프록시. 당신이 만난다면`404`Cloudflare-powered 사이트에 오류, 문제는 원래 서버와 함께. 이러한 경우, 지원을위한 호스팅 제공 업체에 문의하십시오.

## 416 범위 만족하지 않는

더 보기`416 Range Not Satisfiable`상태 코드는 서버가 요청된 범위를 충족할 수 없다는 것을 나타냅니다.`Range`고객의 요청 헤더.

더 자세한 내용은 참조[RFC 7233의](https://datatracker.ietf.org/doc/html/rfc7233).

### 일반적인 사용 사례

이 오류는 클라이언트가 파일의 총 크기를 초과하는 범위와 같은 자원의 경계 밖에 바이트 범위를 요청할 때 발생할 수 있습니다. 서버가 부분적인 내용 납품을 지원하지 않거나 요청한 범위와 자원의 서버의 이해에 충돌이 있는 경우에, 종종 outdated 또는 잘못된 캐시에 기인한 경우에 발생할 수 있습니다.

### Cloudflare-특징 정보

Cloudflare는 일반적으로 근원 서버가 거부할 때 이 응답을 봉사합니다`Range`자원에 대한 헤더 요청. 요청된 범위가 파일의 크기를 초과하면 종종 발생합니다.`Content-Range`헤더.

## 406 허용되지 않음

더 보기`406 Not Acceptable`상태 코드는 요청된 리소스가 클라이언트에 의해 지정된 내용 협상 헤더에 준수하는 형식으로 사용할 수 없다는 것을 나타냅니다 (예를 들어,`Accept-Charset`또는`Accept-Language`).

더 자세한 내용은 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

예를 들어, 특정 언어 또는 문자에 클라이언트 요청 내용이 서버가 지원되지 않는 경우, 이 오류가 생성됩니다. 반환을 피하기 위해`406`오류, 서버는 대신 요청을 거부하는 것보다 클라이언트의 User-Agent에 덜 선호하는 방법을 제공 할 수 있습니다.

### Cloudflare-특징 정보

Cloudflare는 생성하지 않습니다`406`오류는 직접하지만, 원래 서버에서 이러한 응답을 프록시 할 수 있습니다. 콘텐츠 협상 문제가 발생하면 일반적으로 언어 또는 문자 설정 설정과 같은 Origin 서버에서 구성과 관련이 있습니다.

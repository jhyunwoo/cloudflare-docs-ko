## 451 법적인 이유를 사용할 수 없음

더 보기`451`상태 코드는 서버가 법적 조치 또는 제한으로 인해 요청 된 리소스를 제공 할 수 없다는 것을 나타냅니다.

더 자세한 내용은 참조[RFC 7725년](https://tools.ietf.org/html/rfc7725).

### 일반적인 사용 사례

법원 명령, 저작권 주장 또는 기타 법적 요구 사항 때문에 자원에 액세스 할 때 발생합니다. 일반적으로 검색 엔진 (예를 들어, Google) 및 ISP (예를 들어, ATT)는 원래 서버 자체보다이 응답 코드에 영향을 미칩니다. 서버는 응답 몸에 대한 설명, 법적 요구 사항 또는 제한에 대한 이유를 세부.

### Cloudflare-특징 정보

Cloudflare는 통과할지도 모릅니다`451`요청된 리소스가 합법적으로 제한되는 경우 Origin 서버의 응답.

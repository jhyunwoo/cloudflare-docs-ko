## 오류 10048: 보존 경로 suffix는 하위 경로 일치하는 활성화를 요구합니다

이 오류는 구성 mismatch를 나타냅니다.**예약 경로 suffix**옵션은 활성화 없이 사용**Subpath 일치**URL 리디렉션에서.

### 일반적인 원인

이 오류가 발생하면**예약 경로 suffix**사용하지 않고 리디렉션 옵션**Subpath 일치**옵션. 더 보기**예약 경로 suffix**URL 리디렉션의 옵션은 해당 URL 리디렉션의 경우만 적용 가능합니다.**Subpath 일치**옵션도 있습니다.

### 제품 설명

이름 \***Subpath 일치**URL을 리디렉션**예약 경로 suffix**지원하다

## 오류 10052 : 포트가있는 잘못된 리디렉션 소스 URL

이 오류는 소스 URL이 지원되지 않은 포트를 포함합니다.

### 일반적인 원인

URL 리다이렉트의 소스 URL이 포트(예를 들어,`https://example.com:8081`), 지원되지 않는. 가능한 원인은 사용자 정의 또는 비표준 포트를 사용하여, 포트를 포함하는 다른 환경에서 URL을 복사, 또는 개발 또는 테스트 URL을 사용하여 실수로.

### 제품 설명

리디렉션 소스 URL에서 포트를 제거. 더 알아보기[대량 Redirects에서 URL 구성품 지원](/rules/url-forwarding/bulk-redirects/reference/url-components/)리디렉션 URL에 대한 지원 URL 구성 요소에 대한 자세한 내용은.

## Error 10028: 추가 목록 항목 작업에는 중복 항목이 포함되어 있습니다.

이 오류는 목록에 항목을 추가하는 작업이 동일한 요청 내에서 중복 항목을 포함합니다.

### 일반적인 원인

이 오류는 단일 작업에 중복 목록 항목이있을 때 발생합니다 (IP 목록 또는 대량 Redirect List를 사용). 이 오류가 발생할 수 있습니다:

- IP 목록에 반복 IP 주소를 추가하십시오.
- 대량 Redirect List에 반복된 소스 URL 추가

### 제품 설명

중복 아이템을 제거하고 다시 시도해야합니다.

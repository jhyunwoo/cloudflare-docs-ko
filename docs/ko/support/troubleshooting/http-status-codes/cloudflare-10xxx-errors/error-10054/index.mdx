## Error 10054: 파편을 가진 잘못된 리디렉션 소스 URL

이 오류는 소스 URL이 지원되지 않은 파편 구성 요소를 포함한다는 것을 나타냅니다.

### 일반적인 원인

URL 리다이렉트의 소스 URL이 파편 구성 요소(예를 들어,`https://example.com/search/#fragment`). Fragment 구성 요소는 HTTP 요청의 일부가 아닙니다. 페이지가로드되면 특정 위치로 스크롤하는 브라우저의 표시입니다. 이 오류의 가능한 원인은 브라우저 또는 외부 소스에서 파편으로 URL을 복사하거나 URL 구성 또는 편집 중에 파편을 추가합니다.

### 제품 설명

리디렉션 소스 URL에서 파편을 제거하십시오. 더 알아보기[대량 Redirects에서 URL 구성품 지원](/rules/url-forwarding/bulk-redirects/reference/url-components/)리디렉션 URL에 대한 지원 URL 구성 요소에 대한 자세한 내용은.

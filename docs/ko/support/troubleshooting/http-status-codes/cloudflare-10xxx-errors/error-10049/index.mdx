## 오류 10049: 리디렉션 소스 URL에서 잘못된 계획

이 오류는 소스 URL의 계획이 유효하지 않다는 것을 나타냅니다.

### 일반적인 원인

이 오류는 URL 리다이렉트의 소스 URL이 잘못된 방식이있을 때 발생합니다. 이는 misspelled 또는 unsupported 계획으로 인해 또는 계획이 누락되거나 부적절하게 포맷되어 있기 때문입니다.

### 제품 설명

소스 URL을 검토하고 지원 된 계획 중 하나를 사용하는 것을 보장합니다.`http`, `https`, 또는 빈 (계획 정보 없음, 즉 두 계획에 적용). 더 알아보기[대량 Redirects에서 URL 구성품 지원](/rules/url-forwarding/bulk-redirects/reference/url-components/)리디렉션 URL에 대한 지원 URL 구성 요소에 대한 자세한 내용은.

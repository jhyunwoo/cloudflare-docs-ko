Cloudflare 목록 또는 대량 Redirects와 함께 일할 때, 당신은 10xxx 오류 코드를 만날 수 있습니다. 이 오류는 일반적으로 중복 목록 항목, 변형 된 URL, 또는 호환 리디렉션 설정과 같은 요청에서 잘못된 구성 또는 지원되지 않은 값에 해당합니다. 이 가이드는 각 오류에 대한 상세한 설명과 해상도를 제공하여 문제 해결 및 문제를 해결합니다.

## Error 10028: 추가 목록 항목 작업에는 중복 항목이 포함되어 있습니다.

이 오류의 완전한 설명은 참조[오류 10028](/support/troubleshooting/http-status-codes/cloudflare-10xxx-errors/error-10028/)사이트 맵

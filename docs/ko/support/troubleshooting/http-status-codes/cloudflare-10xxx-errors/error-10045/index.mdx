## 오류 10045 : 잘못된 리디렉션 소스 URL

이 오류는 리다이렉트의 소스 URL이 유효하지 않다는 것을 나타냅니다.

### 일반적인 원인

URL 리다이렉트를 위해 제공된 소스 URL이 유효하지 않을 때 오류가 발생하며, 방식과 같은 누락된 구성 요소로 인해 제대로 함수하는 것을 방지합니다.`http`또는`https`) 또는 improper 체재.

### 제품 설명

소스 URL로 유효한 URL을 지정해야 합니다. 더 알아보기[대량 Redirects에서 URL 구성품 지원](/rules/url-forwarding/bulk-redirects/reference/url-components/)리디렉션 URL에 대한 지원 URL 구성 요소에 대한 자세한 내용은.

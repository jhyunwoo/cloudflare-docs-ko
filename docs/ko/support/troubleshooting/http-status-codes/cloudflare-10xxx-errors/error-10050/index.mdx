## Error 10050: 사용자 정보와 잘못된 리디렉션 소스 URL

이 오류는 소스 URL이 지원되지 않는 사용자 정보를 나타냅니다.

### 일반적인 원인

URL 리다이렉트의 소스 URL이 사용자 정보 구성 요소(예를 들어,`https://user:password@example.com`), 지원되지 않는.

### 제품 설명

리디렉토리 URL에서 사용자 정보 구성 요소를 제거해야합니다. 더 알아보기[대량 Redirects에서 URL 구성품 지원](/rules/url-forwarding/bulk-redirects/reference/url-components/)리디렉션 URL에 대한 지원 URL 구성 요소에 대한 자세한 내용은.

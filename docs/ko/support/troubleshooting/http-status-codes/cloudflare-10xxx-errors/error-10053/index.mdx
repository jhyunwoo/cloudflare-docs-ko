## Error 10053: 쿼리 문자열을 가진 잘못된 리디렉션 소스 URL

이 오류는 소스 URL이 지원되지 않은 쿼리 문자열 구성 요소를 나타냅니다.

### 일반적인 원인

URL 리디렉션의 소스 URL이 지원되지 않는 쿼리 문자열 구성 요소를 포함 할 때이 오류가 발생합니다. 가능한 원인은 쿼리 매개 변수와 URL을 복사, 설정 중 구성, 또는 경로 대신 쿼리 매개 변수에 따라 리디렉션 시도.

### 제품 설명

리디렉션 소스 URL에서 쿼리 문자열을 제거. 더 알아보기[대량 Redirects에서 URL 구성품 지원](/rules/url-forwarding/bulk-redirects/reference/url-components/)리디렉션 URL에 대한 지원 URL 구성 요소에 대한 자세한 내용은.

## 오류 10051 : 리디렉션 소스 URL에 대한 미스링 권한

이 오류는 소스 URL이 필요한 권한 구성 요소를 누락한다는 것을 나타냅니다.

### 일반적인 원인

URL 리다이렉트의 소스 URL이 포함되지 않는 경우 이 오류가 발생합니다 (예를 들어,`http:///path`, hostname없이), 이는 필수입니다.

### 제품 설명

리디렉토리 소스 URL에 권한을 추가 (예를 들어, 호스트 이름을 포함). 더 알아보기[대량 Redirects에서 URL 구성품 지원](/rules/url-forwarding/bulk-redirects/reference/url-components/)리디렉션 URL에 필요한 URL 구성 요소에 대한 자세한 내용은.

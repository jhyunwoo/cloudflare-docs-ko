## 오류 10047: 잘못된 리디렉션 상태 코드

이 오류는 unsupported 또는 incorrectly 포맷 된 상태 코드가 URL 리디렉션에 지정되었다는 것을 나타냅니다.

### 일반적인 원인

이 오류는 지원되지 않은 URL 리디렉션 상태 코드를 지정할 때 발생합니다. 일반적으로 잘못된 번호를 입력하거나 지원되지 않은 상태 코드를 사용하여.

### 제품 설명

URL 리디렉션의 지원된 상태 코드 중 하나를 사용:`301`, `302`, `307`, 또는`308`.

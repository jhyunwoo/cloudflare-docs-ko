## Error 10059: 반복된 URL 소스 경로의 최대 수 초과

이 오류는 같은 URL 경로가 대량 Redirect Lists에서 너무 많은 시간을 반복한다는 것을 나타냅니다.

### 일반적인 원인

이 오류는 URL 리디렉션 도메인에 관계없이 모든 대량 리디렉션 목록에서 동일한 소스 URL 경로와 리디렉션의 URL 리디렉션의 최대 수 이상이있을 때 발생합니다. 가능한 원인은 동일한 리디렉션, 중복 구성, 또는 중복 소스 URL 경로에 대한 mismanagement 결과를 포함하는 여러 목록이 포함되어 있습니다.

### 제품 설명

소스 URL의 경로를 검토하므로 URL의 최대 수는 도메인 또는 목록에 관계없이 계정에서 동일한 URL 경로를 리디렉션하는 것보다 더 많은 것을 가지고 있지 않습니다. 더 알아보기[URL 리디렉션 매개 변수](/rules/url-forwarding/bulk-redirects/reference/parameters/)현재 제한에 대한 자세한 내용은.

## Error 10058: 목록 유형과 호환되는 항목 목록

이 오류는 잘못된 목록 유형에 해당하는 항목이 추가되었는지 나타냅니다.

### 일반적인 원인

이 오류는 목록에 항목을 추가 할 때 발생합니다 (ither IP 목록, 호스트 이름 목록, 또는 대량 Redirect 목록) 및 목록 항목은 목록 유형과 호환됩니다.

### 제품 설명

올바른 목록에 항목이 추가되도록하십시오.

- IP 주소(IP lists)를 가진 사용자 지정 목록은 목록 항목으로 IP 주소를 포함할 수 있습니다.
- 호스트 이름과 사용자 지정 목록은 목록 항목으로 호스트 이름만 포함할 수 있습니다.
- Bulk Redirect List는 목록 항목으로 URL 리디렉션을 포함 할 수 있습니다.

## Error 10055: 리디렉션 대상 URL과 호환되는 Query 문자열 설정

이 오류는 충돌을 나타냅니다.**자주 묻는 질문**옵션과 리디렉션 대상 URL의 쿼리 문자열.

### 일반적인 원인

이 오류가 발생하면**자주 묻는 질문**URL 리디렉션의 옵션은 리디렉션 대상 URL에서 쿼리 문자열을 제공합니다. 이 경우 URL 리디렉션은 수신 요청의 쿼리 문자열을 처리하는 방법에 대한 충돌 구성이있을 것입니다.

### 제품 설명

이 문제를 해결하기 위해**자주 묻는 질문**URL에서 옵션을 리디렉션하거나 리디렉션 대상 URL에서 쿼리 문자열 구성 요소를 제거하여 충돌을 제거하십시오.

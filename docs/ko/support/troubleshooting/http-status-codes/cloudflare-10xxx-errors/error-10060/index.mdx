## 오류 10060 : 대상 URL을 리디렉션하는 미싱 제도

이 오류는 대상 URL이 계획되지 않은 것을 나타냅니다.

### 일반적인 원인

이 오류는 URL 리다이렉트의 대상 URL이 포함되지 않는 경우, 이는 필수입니다. 이 태풍이나 URL로 인해 발생할 수 있습니다.

### 제품 설명

URL 리디렉션의 대상 URL을 검토하고 계획 (예를 들어,`https`). 더 알아보기[대량 Redirects에서 URL 구성품 지원](/rules/url-forwarding/bulk-redirects/reference/url-components/)리디렉션 대상 URL에 필요한 URL 구성 요소에 대한 자세한 내용은.

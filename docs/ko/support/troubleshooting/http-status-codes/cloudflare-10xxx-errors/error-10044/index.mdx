## 오류 10044 : 리디렉션의 대상 URL은 너무 길다.

이 오류는 리다이렉트의 대상 URL이 최대 허용된 길이를 초과한다는 것을 나타냅니다.

### 일반적인 원인

이 오류는 URL 리디렉션의 대상 URL 값이 너무 길 때 발생합니다. 대상 URL의 최대 길이는 32,768자입니다. 이 오류의 가능한 원인은:

- 과도한 쿼리 매개 변수 또는 추적 코드를 포함하는 동적 URL.
- URL의 불필요한 경로 세그먼트 또는 중복 하위 디렉토리.

### 제품 설명

대상 URL로 단축 URL을 사용해야 합니다.

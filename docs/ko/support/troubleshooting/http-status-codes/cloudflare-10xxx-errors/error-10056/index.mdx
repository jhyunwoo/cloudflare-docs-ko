## Error 10056: 추가 목록 항목 작업에는 목록 항목의 다른 유형이 포함되어 있습니다.

이 오류는 목록 항목의 다른 유형이 단일 추가 작업에 결합 된 것을 나타냅니다.

### 일반적인 원인

이 오류는 다른 유형의 목록 항목 (IP 주소, 호스트 이름 및 URL 리디렉션과 같은)이 목록에 항목을 추가하는 단일 작업에 포함되어 있습니다. IP 목록, 호스트 이름 목록 또는 대량 Redirect List로 발생할 수 있습니다.

### 제품 설명

목록 유형에 적용되지 않는 목록 항목을 제거하십시오. 이 수단:

- 요청에서 IP 주소를 제거하여 대량 Redirect List에 아이템을 추가합니다.
- URL을 제거하려면 IP 목록에 항목을 추가해야합니다.

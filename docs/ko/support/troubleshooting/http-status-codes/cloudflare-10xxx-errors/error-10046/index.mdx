## 오류 10046: 잘못된 리디렉션 대상 URL

이 오류는 URL 리디렉션에 제공된 대상 URL이 유효하지 않다는 것을 나타냅니다.

### 일반적인 원인

이 오류는 URL 리다이렉트에 제공된 대상 URL이 유효하지 않을 때 발생하며, 방식과 같은 누락된 구성 요소로 인해 제대로 작용하는 것을 방지합니다.`http`또는`https`) 또는 improper 체재.

### 제품 설명

대상 URL로 유효한 URL을 지정해야 합니다. 더 알아보기[대량 Redirects에서 URL 구성품 지원](/rules/url-forwarding/bulk-redirects/reference/url-components/)지원 URL 구성 요소에 대한 자세한 내용은 대상 URL을 리디렉션합니다.

1xx 정보 상태 코드는 요청 응답 주기를 완료하지 않고 연결 상태 업데이트를 제공하는 간 응답 역할을합니다. 이 코드는 최종 행동을 위해 예정되지 않지만 요청이 처리되거나 추가 단계가 필요합니다.

서버는 클라이언트 요청에 응답에 1xx 정보 상태 코드를 보낼 때 따라야 합니다.

- 응답은 상태 선을 따르는 첫번째 빈 선에 의해 종결되어야 합니다.
- 1xx 응답은 HTTP/1.0에 의해 지원되지 않습니다; 근원 서버는 HTTP/1.0 클라이언트에 1xx 응답을 결코 보내지 않아야 합니다.

Cloudflare는 기원 서버에서 모든 1xx 응답을 전달하지만 직접 생성하지 않습니다.

## 100 계속

100 Continue 상태는 서버가 요청 헤더를 수신하고 요청 몸을 보낼 클라이언트를 위해 준비가되어 있음을 나타냅니다. 더 많은 정보를 원하시면, 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

클라이언트가 서버가 잠재적으로 큰 또는 사용 가능한 요청 몸을 전송하기 전에 요청 헤더를 허용하는 경우, 데이터 흐름을 최적화.

클라이언트가 포함될 때`Expect: 100-continue`헤더, 요청 몸을 보내기 전에 확인을 요청하고 서버가 즉시 응답 할 수 있도록`100 Continue`진행 또는 적절한 상태 코드 (예를 들어,`401 Unauthorized`또는`413 Payload Too Large`) 요청이 허용되지 않는 경우.

### Cloudflare-특징 정보

Cloudflare는 클라이언트와 서버간에 지속적인 커뮤니케이션을 유지하기 위하여 Keep-Alive 연결을 이용합니다, 만들기`100 Continue`응답은 일반적으로 불필요한, Keep-Alive는 머리 위를 감소시키고 중간 확인을 위한 필요를 삭제합니다.

## 101 전환 프로토콜

101 Switching Protocols 상태 코드는 Origin 서버가 프로토콜을 전환하는 클라이언트 요청을 허용한다는 것을 나타냅니다. 더 많은 정보를 원하시면, 참조[RFC 7231의](https://tools.ietf.org/html/rfc7231).

### 일반적인 사용 사례

101 Switching Protocols 상태 코드는 서버가 프로토콜을 변경하는 클라이언트 요청을 허용한다는 것을 나타냅니다.`Upgrade`헤더 또는 연결에 애플리케이션 프로토콜의 변경을 통해. 언제까지`Upgrade`헤더가 사용됩니다. 서버는 클라이언트의 우선 순위 목록에 더 높은 프로토콜로 전환하고 응답합니다.`Upgrade`헤더는 새로운 프로토콜(s)를 지정합니다. 이 변경은 클라이언트와 서버 모두 혜택을 가리킵니다. WebSockets는 가장 일반적인 사용 사례입니다.

### Cloudflare-특징 정보

Cloudflare는 WebSocket 연결을 지원하며, 이는 종종 101개의 스위칭 프로토콜 상태 코드와 관련이 있습니다. 프로토콜 스위치는 클라이언트가 실시간, 양방향 통신을 위해 WebSocket 연결을 설정할 수 있습니다. Cloudflare의 Websockets에 대한 정보는 참조[Cloudflare 지금 지원 Websockets](https://blog.cloudflare.com/cloudflare-now-supports-websockets/).

## 102 가공

102 처리 상태 코드는 서버가 요청을 받고 현재 처리되었지만 최종 응답은 아직 준비되지 않습니다. 이 상태 코드는 HTTP / 1.1 이상에서만 적용됩니다. 더 많은 정보를 원하시면, 참조[RFC 2518년](https://tools.ietf.org/html/rfc2518).

### 일반적인 사용 사례

102 처리 상태 부호는 복잡한 데이타베이스 거래 또는 큰 파일 처리와 같은 장기간 가동을 요구하는 시나리오에서 통용됩니다. 20 초를 초과하는 장시간 처리 시간 도중 연결을 유지하고, 가동을 통하여 클라이언트와 서버 사이 능률적인 커뮤니케이션을 지키.

### Cloudflare-특징 정보

Cloudflare가 102 처리 응답을 받으면 120 초 이내에 최종 응답을 기대합니다. 이 응답 결과를 수신 실패[오류 522 : 연결 시간](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-522/). 그러나, interim 102 가공 응답을 보내는 것은 막을 것을 도울 수 있습니다[오류 524 : 타임 아웃이 발생했습니다.](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-524/), 서버가 요청을 처리하는 동안 연결이 활성화되었는지 확인합니다.

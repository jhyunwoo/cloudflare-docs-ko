Cloudflare는 할당된 IP 주소가 어떤 국가 또는 인터넷 서비스 공급자 (ISP)에 의해 차단되지 않다는 것을 보증할 수 없습니다. Cloudflare 프록시가 영역에 IP 주소를 Cloudflare 네트워크에서 공유 풀에서 지정합니다. Cloudflare는 무료, Pro 또는 비즈니스 계획에 대한 사용자 전용 또는 독점적 인 IP 주소를 제공하지 않으며 CloudflareXQ는 요청시 지정된 IP 주소를 회전합니다.

ISP가 웹 사이트를 차단하면 다음을 기대해야합니다.

- CloudflareXQ 설정의 잘못 구성으로 인해 안됩니다.
- 당신은 당신의 교통에 드롭을 볼 수 있습니다[모델 번호: Cloudflare 회사 소개](/analytics/).
- 이러한 행동은 ISP 수준에서 가져온 것처럼 Cloudflare는 영향을받는 사용자를위한 인터넷 연결을 복원 할 수있는 기능이 없습니다.

Enterprise 사용자는 임대할 수 있습니다.[정적 IP](/byoip/concepts/static-ips/)또는 자신의 IP를 사용하여 광고[자신의 IP를 가져 오기 (BYOIP)](/byoip/). 자세한 내용은, 접촉합니다[모델 번호: Cloudflare 판매 팀](https://www.cloudflare.com/plans/enterprise/contact/).

ISP 수준 블록이 웹 사이트 차단의 다른 유형과 구별된다는 것을 주목하는 것이 중요합니다. 예를 들어, 웹 사이트 소유자는 특정 제한을 시행할 수 있습니다 (IP, ASN, 국가, 또는 다른 요인과 같은 비율 제한) 그 반환[`1XXX`오류 수정](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/)응답의 HTML 몸에서. 웹 사이트 소유자는이 블록을 구성하므로 웹 사이트 소유자와 직접 주소해야합니다. 웹 사이트 차단에 대한 자세한 내용은 참조[웹 응용 프로그램 방화벽 FAQ](/waf/troubleshooting/faq/#why-have-i-been-blocked).

CloudflareXQ-protected 웹 사이트를 방문할 때 개별 사용자에 대한 정보, 참조[Cloudflare-protected 사이트에 도전](/cloudflare-challenges/troubleshooting/#challenges-on-cloudflare-protected-sites).

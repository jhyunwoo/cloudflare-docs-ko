## Anti-bot 모듈

Cloudflare를 통해 proxied 할 때 엔진 크롤러의 요청을 검색하면 원래 서버에 설치된 anti-bot 모듈에 의해 차단 될 수 있습니다. 이 요청을 차단함으로써 안티봇 모듈을 비활성화하십시오.

## Google 및 Bing 크롤링 속도 조정

CDN 성능 최적화, Google 및 Bing은 주문시 CDN 서비스를 사용하는 웹 사이트에 특별한 크롤링 속도를 할당합니다. 특수 크롤링 비율은 검색 엔진 최적화 (SEO) 및 검색 엔진 결과 Pages (SERPs)에 부정적인 영향을 미치지 않습니다. Bing과 Google의 크롤링 속도를 변경하려면 아래 가이드를 따르십시오.

- Google 크롤링 속도 변경[Google의 문서 검토](https://support.google.com/webmasters/answer/48620?hl=en).
- Bing의 문서에서 지도를 통해 Bing crawl rate를 변경:
  - [Bing Crawl 통제](https://www.bing.com/webmasters/help/?topicid=55a30303)
  - [크레wl Delay와 블링 크롤러](https://blogs.bing.com/webmaster/2009/08/10/crawl-delay-and-the-bing-crawler-msnbot)

## crawl 오류 방지

다음 권장 사항을 검토하여 크롤러 오류를 방지하십시오.

- 타사 도구를 사용하여 웹 사이트의 성능 및 가용성을 모니터링:
  - [주 메뉴](http://www.statuscake.com/)
  - [핑덤](http://www.pingdom.com/)
  - [모니터. 제품 정보](http://www.monitor.us/)
  - [맨 위로](https://updown.io/)

- Google 크롤러 IP 주소를 차단하지 마십시오[주문 규칙](/waf/custom-rules/)또는[IP 접근 규칙](/waf/tools/ip-access-rules/). 사용중인 경우[비율 제한 규칙](/waf/rate-limiting-rules/), 그들은 Google 크롤러에 적용하지 않습니다.

  IP 주소는 Google의 문서 컨설팅으로 Google에 속합니다.[googlebot IP 주소 확인](https://support.google.com/webmasters/bin/answer.py?answer=80553).

- 미국을 통해 차단하지 마십시오[주문 규칙](/waf/custom-rules/)또는[IP 접근 규칙](/waf/tools/ip-access-rules/).

- Google 사용자를 차단하지 마십시오.`.htaccess`파일, 서버 구성,[`robots.txt`](http://support.google.com/webmasters/bin/answer.py?answer=35303), 또는 웹 신청.

Google은[다양한 User-Agents](https://developers.google.com/search/docs/crawling-indexing/overview-google-crawlers)웹 사이트를 크롤러. 당신은 할 수[시험하기`robots.txt`Google을 통해](https://support.google.com/webmasters/answer/6062598?hl=en).

- 파일의 크롤러를 허용하지 마십시오`/cdn-cgi/`디렉토리. 이 경로는 내부적으로 Cloudflare 및 Google이 충돌 할 때 오류가 발생합니다. Disallow의 크롤링`cdn-cgi`이름 \*`robots.txt`:

`Disallow: /cdn-cgi/`

:::참조

자주 묻는 질문`cdn-cgi`사이트 순위에 영향을 미치지 않습니다.
주요 특징

- 감사합니다.[`robots.txt`파일은 AdSense 크롤러를 허용합니다](http://support.google.com/webmasters/bin/answer.py?hl=en\&answer=1061943).
- [원래 방문자 IP 주소 복원](/support/troubleshooting/restoring-visitor-ips/restoring-original-visitor-ips/)서버 로그에서.

## Troubleshoot 크롤러

가장 일반적으로 보고된 크롤러 오류를 위한 문제 해결 단계는 아래에 언급됩니다.

### HTTP 4XX 오류

[HTTP 4XX 오류](/support/troubleshooting/http-status-codes/4xx-client-error/)크롤 오류의 가장 일반적인 유형입니다. Cloudflare는 웹 서버에서 Google에 이러한 오류를 제공합니다. 이 오류는 웹 서버의 누락된 페이지 또는 HTML의 수정된 링크와 같은 다양한 이유로 발생합니다. 이 솔루션은 문제가 발생했습니다.

### HTTP 5XX 오류

[HTTP 5XX 오류](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/)Cloudflare 또는 웹 서버가 내부 오류를 경험한다는 것을 나타냅니다. 사이트 중단과 크롤링 오류의 발생을 방지하려면 웹 서버의 건강을 모니터링하십시오. Cloudflare를 통해 웹 사이트 건강을 모니터링하고 원본 웹 서버 IP로 직접 CloudflareXQ 또는 웹 서버로 인해 오류가 발생했는지 결정합니다.

### DNS 오류

귀하의 도메인이 전체 또는 CNAME 설정을 통해 CloudflareXQ에 있는지 여부에 따라 문제 해결 단계가 다릅니다. 도메인 사용 설정을 확인하려면 터미널을 열고 다음 명령을 실행하십시오 (replace`www.example.com`Cloudflare 도메인과 함께:

`dig +short SOA` `www.example.com`

도메인의 경우[부분 (CNAME) 설정](/dns/zone-setups/partial-setup/), 결과는 cdn.cloudflare.net를 포함합니다. 예를 들면:

`example.com.cdn.cloudflare.net.`

도메인의 경우[전체 설정](/dns/zone-setups/full-setup/), 결과 응답 포함`cloudflare.com`나열된 네임서버의 도메인. 예를 들면:

`josh.ns.cloudflare.com. dns.cloudflare.com. 2013050901 10000 2400 604800 3600`

도메인이 Cloudflare로 설정되었는지 확인하면 도메인 설정에 적합한 문제 해결 단계로 진행됩니다.

**이름 \***

DNS 오류를 조사하고 날짜 Google이 DNS 오류를 제공합니다. 또한, 리뷰[Cloudflare 시스템 상태](http://www.cloudflare.com/system-status)Google에서 오류가 발생했습니다.

**한국어**

[접촉 Cloudflare 지원](/support/contacting-cloudflare-support/)Google이 오류를 관찰 한 날짜와 시간을 제공합니다.

### 자주 묻는 질문

위의 문제 해결 단계가 크롤링 오류를 해결하지 않으면 크롤러 오류를 내보내기 위해 아래의 단계를 따르십시오.`.csv`Google 웹 마스터 도구 Dashboard에서 파일. 다음을 포함`.csv`파일 때[접촉 Cloudflare 지원](/support/contacting-cloudflare-support/).

1. Google 웹 마스터 도구 계정에 로그인하고 탐&#xC0C9;**\* 필수**영향을받는 도메인의 섹션.
2. 이름 \***크롤 오류**왼쪽 손 항법에서.
3. 이름 \***다운로드**오류 목록 내보내기`.csv`파일.
4. 다운로드`.csv`Cloudflare 지원에 파일.

## 계획된 정비

Cloudflare는 중복을 운영합니다[anycast 네트워크](https://www.cloudflare.com/en-gb/learning/cdn/glossary/anycast-network/)이 웹 사이트는 귀하가 웹 사이트를 탐색하는 동안 귀하의 경험을 향상시키기 위해 쿠키를 사용합니다. 이러한 경우, 트래픽은 대체 위치에 자동으로 다시 시작합니다.

계획되지 않은 유지 보수를 확인하려면, 해당 상태가 "Re-routed"로 나열되어 있는지 확인하여 위치가 다시 종료되면 모든 시간에 확인할 수 있습니다.[모델 번호: https://www.cloudflarestatus.com](https://www.cloudflarestatus.com). 예외적으로, 사건은 위치에 정비를 위해 선언될지도 모릅니다, 어느 경우 갱신은 우리의 상태 페이지에서 유효합니다[모델 번호: https://www.cloudflarestatus.com](https://www.cloudflarestatus.com).

## 유지 보수에 따른 위치

당신이 있는 경우에[CNI 연결](/network-interconnect/)re-routed 위치에 Cloudflare로, 계획되거나 계획되지 않은 정비 도중 일시적으로 사용할 수 있고, 일정한 인터넷 여정은 당신의 네트워크에 도달 대신 사용될지도 모릅니다.

제품의 마술 가족에서, 여정은 명시적으로 사용[정적 경로](/cloudflare-wan/configuration/manually/how-to/configure-routes/#create-a-static-route)지정된 터널에 트래픽을 보내려면 고객 구성 우선 순위와 함께. CNI 터널을 가지고 있다면, 그것은 당신이 또한 대체 터널에 루트를 추가하는 것이 좋습니다, 등 가을 인터넷 터널, 당신의 트래픽이 모든 시간에 노선을 확인할 수 있도록.

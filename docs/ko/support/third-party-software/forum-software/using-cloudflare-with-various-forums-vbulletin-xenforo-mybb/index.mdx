## 제품정보

많은 널리 사용되는 포럼 플랫폼은 Cloudflare와 호환됩니다.

다음을 포함합니다:

- [공지사항](https://community.cloudflare.com/t/using-discourse-with-cloudflare-best-practices/602890)
- vBulletin의
- 인기 카테고리
- 뚱 베어

이 플랫폼을 사용하여 포럼이있는 경우 CloudflareXQ를 추가하여 속도와 안전을 높일 수 있습니다.

***

## 한국어

**1**. Cloudflare는 역 프록시 역할을하며 모든 방문자 IP 주소가 Cloudflare-affiliated IP 주소가됩니다. 당신이 같은 서비스를 사용하는 경우**카테고리**또는 IP 주소로 등록 차단, 당신은 필요[원래 방문자 IP를 복원](/support/troubleshooting/restoring-visitor-ips/restoring-original-visitor-ips/).

**2**. 캐싱 또는 성능 기능에 영향을 미치는 admin 함수를 방지하기 위해, 생성[캐시 규칙](/cache/how-to/cache-rules/settings/#bypass-cache)사이트 관리자 섹션에서 캐시를 우회합니다.

**3**. 웹 사이트에 액세스 할 특정 서비스를 원한다면 (API 또는 특정 IP),[WAF](/waf/).

**4**. DNS 레코드를 검토하여 모든 하위 도메인 레코드를 확인할 수 있습니다. 하위 도메인을 찾을 수없는 경우,[DNS 레코드 추가](/dns/manage-dns-records/how-to/create-dns-records/).

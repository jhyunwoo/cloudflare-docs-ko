## 제품정보

Cloudflare는 2018년에 Bandwidth Alliance를 발사했습니다 - 상호 고객을 위한 웨이퍼 또는 가파른 할인 egress 비용에 동의한 운송 전망 구름과 저장 공급자의 그룹.

Azure를 사용하는 CloudflareXQ 고객은 QXQX0001XQ 및 Azure 사이의 egress 요금을 낮출 수 있습니다.[마이크로 소프트 루팅 P참고 자료](https://docs.microsoft.com/en-us/azure/virtual-network/routing-preference-overview).

***

## 이름 \*

Azure 및 CloudflareXQ에서 데이터 전송 비용을 낮추기 위해:

1. Azure 포털에서 스토리지 계정으로 이동합니다.
2. 바로가기**네트워크 루팅 > 방화벽 및 가상 네트워크**.
3. 제품 정보**회전 p참고 자료**, 선택**인터넷 룰렛**.
4. 경로 별 endpoint를 게시**인터넷 룰렛**.
5. 바로가기**제품 정보**.
6. endpoint 값을 찾습니다.**인터넷 Routing**.
7. Cloudflare 대시보드에 이러한 엔드포인트 값을 입력하십시오.

![Microsoft Azure의 엔드포인트 URL을 Cloudflare 대시보드로 입력하는 곳의 예.](~/assets/images/support/bandwidth-alliance.png)

자세한 내용은 참조[Azure Storage를 위한 네트워크 라우팅 p참고 자료](https://docs.microsoft.com/en-us/azure/storage/common/configure-network-routing-preference?tabs=azure-portal)·[마이크로 소프트 루팅 P참고 자료](https://docs.microsoft.com/en-us/azure/storage/common/network-routing-preference).

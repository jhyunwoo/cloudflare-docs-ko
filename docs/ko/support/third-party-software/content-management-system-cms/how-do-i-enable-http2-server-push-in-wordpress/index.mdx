HTTP / 2 Server Push는 웹 사이트가 브라우저에 콘텐츠를 밀어 넣을 수 있으므로 HTML을 원하면 먼저 렌더링 할 수 있습니다. HTTP / 2에 내장 된 concurrency 지원과 함께 서버 푸시는 웹 사이트를로드하는 데 필요한 요청의 금액을 극적으로 줄일 수 있습니다.

![오래된 URL: https://support.cloudflare.com/hc/en-us/article\_attachments/115005733367/http2-server-push-2.png

](~/assets/images/support/hc-import-http2_server_push_2.png)

Cloudflare는 HTTP / 2 서버 푸시를 지원하며 Cloudflare의 WordPress 플러그인을 사용하여 스타일 시트 및 스크립트에 사용할 수 있습니다. 이 기능을 활용하려면 먼저 Cloudflare 워드 프레스 플러그인이 있어야 합니다.[귀하의 사이트에 설치 및 설정](/automatic-platform-optimization/).

플러그인이 설치되면 다음 줄을 추가하여 HTTP / 2 Server Push를 활성화 할 수 있습니다.`wp-config.php`파일 :

```php
define('CLOUDFLARE_HTTP2_SERVER_PUSH_ACTIVE', true);
```

이 줄을 위에 삽입해야 합니다.*"/\* 그게 전부, 편집 중지! 행복한 블로그. \*/*", 다음과 같습니다 :|

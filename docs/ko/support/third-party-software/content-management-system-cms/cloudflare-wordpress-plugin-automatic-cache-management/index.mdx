## 제품정보

Cloudflare WordPress 플러그인은 자동 캐시 관리라는 기능이 포함되어 있습니다. 사용자가 추가 할 때, 편집, 또는 게시물을 삭제, 페이지, 첨부 파일, 또는 댓글 - 어떤 관련 URL은 Cloudflare 캐시에서 추적됩니다.

테마를 전환하거나 WordPress 관리자 패널 내에서 테마를 사용자 정의 할 때 캐시가 자동으로 삭제됩니다.

자동 캐시 관리는 WordPress에 내장 된 네이티브 후크를 사용합니다. Cloudflare 워드 프레스 플러그인은 다음과 같은 캐시 URL을 퍼집니다:

- 삭제하기
- 편집 post
- delete attachment를 삭제
- autoptimize action cachepurged (Autoptimize WordPress 플러그인과의 호환성)
- 스위치 theme
- 사용자 정의 save after

***

## 자동 캐시 관리

자동 캐시 관리 활성화[WordPress 플러그인 설치](/automatic-platform-optimization/):

1. WordPress 계정으로 로그인하십시오.
2. 이름 \***계정 설정**그리고 Cloudflare 플러그인을 선택합니다. Cloudflare 플러그인 홈 페이지가 나타납니다.
3. 이름 \***이름 \***&#xC624;른쪽으로**자동 캐시**이름 \* 확인 대화 상자가 나타납니다.
4. 이름 \***나는 확실하다**확인 대화 상자에서 확인.

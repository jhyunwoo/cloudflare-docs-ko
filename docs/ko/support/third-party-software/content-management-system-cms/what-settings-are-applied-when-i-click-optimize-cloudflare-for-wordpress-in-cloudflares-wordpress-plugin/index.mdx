자주 묻는 질문[Cloudflare의 워드 프레스 플러그인](/automatic-platform-optimization/), 우리의 "에 최적화 Cloudflare 워드 프레스에 대한"하나 클릭 구성은 다음과 같은 설정을 적용 워드 프레스 사이트:

| **설치하기**         | **제품정보**                |
| ---------------- | ----------------------- |
| 캐싱 수준            | 제품 정보                   |

| 항상 온라인           | 이름 \*                   |
| 개발 모드            | 지원하다                    |
| IPV6 호환성         | 이름 \*                   |
| 웹소켓              | 이름 \*                   |
| IP 위치            | 이름 \*                   |
| 이메일 주소           | 이름 \*                   |
| Hotlink 보호       | 이름 \*                   |
| 이미지 최적화 (Polish) | 할인 (Pro 또는 더 높은 계획에 무한) |
| Rocket 로더        | 이름 \*                   |

## 제품정보

Cloudflare 및 WordPress 용 Jetpack은 추가 구성이 필요하지 않습니다. 그러나 우리는 Jetpack 설치를 보호하기 위해 설계된 일부 보안 기능을 가지고 있으며, 아래에서 자세히 알아보세요.

### CloudflareXQ에서 기본 Jetpack 보호

Cloudflare WAF 관리 규칙 WP0007는 보호합니다`xmlrpc.php`모든 CloudflareXQ에 파일에 Jetpack만 사용 가능`xmlrpc.php?for=jetpack`쿼리 문자열. Cloudflare는 Jetpack의 자동화 시스템의 IP 범위를 허용함으로써 이것을 합니다. 같은, 액세스 할 수있는 시도`xmlrpc.php?for=jetpack`Jetpack IP 주소가 차단되지 않는 IP에서`HTTP 403 Forbidden`Cloudflare에서 메시지. 이 자체는 걱정하지 않고 웹 사이트의 보안을 개선하고 Jetpack의 기능에 영향을 미치지 않습니다.

원래 구현 된 이유에 대한 자세한 내용은, 주제에 우리의 블로그 게시물을 살펴:

[모델 번호: https://blog.cloudflare.com/our-waf-is-keeping-wordpress-jetpack-on-track/](https://blog.cloudflare.com/our-waf-is-keeping-wordpress-jetpack-on-track/)

### Jetpack에 영향을 미칠 수있는 추가 WAF 관리 규칙

특정 규칙이 있습니다.[웹 응용 프로그램 방화벽 (WAF)](https://www.cloudflare.com/waf/)활성화된 규칙은 설정 관리에서 Jetpack의 서버를 차단합니다. WAF 관리 규칙 “WP0002 - 블록 워드 프레스 XML-RPC” 규칙은 기본적으로 비활성화되지만 완전히 접근을 해제 할 때`xmlrpc.php`파일. 같은 경우, 우리는이 규칙을 긴급 측정으로만 권장합니다.`xmlrpc.php`endpoint는 공격됩니다.

더 많은 지도를 위해, 우리의 지원 팀을 접촉하십시오.

Cloudflare는 우리의 서비스 및 네트워크의 상태에 업데이트를 제공합니다[모델 번호: https://www.cloudflarestatus.com/](https://www.cloudflarestatus.com/)CloudflareXQ로 예기치 않은 행동을 확인해야 합니다.

페이지를보고 넘어,이 정보를 소비하는 프로그래밍 방법이 있습니다.

## 알림 설정

Cloudflare는 전용 알림을 제공합니다**사용 약관**Cloudflare가 사건을 경험할 때 당신이 알고 있는 ,.

이 알림을 설정할 수 있습니다.[이름 \*](/notifications/get-started/), [웹훅](/notifications/get-started/configure-webhooks/), 또는[카테고리](/notifications/get-started/configure-pagerduty/).

## API 사용

Cloudflare는 또한 상태 정보를 통해 제공합니다[Cloudflare 상태 API](https://www.cloudflarestatus.com/api).

엔드포인트는 cURL과 우리의 embededed JavaScript 위젯을 사용하여 예시로 표시됩니다.

[네트워크 시간 보안](https://datatracker.ietf.org/doc/html/rfc8915)(NTS)는 Network Time Protocol (NTP)의 클라이언트 서버 모드에 대한 암호화 보안을 제공합니다. 사용자가 정통 방식으로 시간을 얻을 수 있습니다.

## 이름 \*

NTS 프로토콜은 두 단계로 나뉩니다.

1. **NTS 키 교환**: NTP 클라이언트와 서버 사이에 필요한 키 소재를 설치하여[전송 층 보안 (TLS) Handhake](https://www.cloudflare.com/learning/ssl/what-happens-in-a-tls-handshake/)(웹과 같은 공공 키 인프라). 열쇠가 교환되면, TLS 수로는 닫히고 의정서는 두번째 단계에 들어갑니다.
2. **NTS 확장 분야 NTPv4**: 이전에 설치된 키 소재를 사용하여 NTP 시간 동기화 패킷을 인증합니다. 더 많은 정보를 원하시면, 참조[RFC 8915년](https://tools.ietf.org/html/rfc8915).

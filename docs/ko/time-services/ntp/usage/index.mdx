## 맥 OS

Mac에서 시간을 동기화하려면`time.cloudflare.com`:

1. 오시는 길**시스템 설정**.
2. 오시는 길**주요사업** > **날짜 & 시간**.
3. 이름 \***날짜 및 시간 자동 설정**.
4. 제품 정보**이름 \***, 선택**설정 ...**&#xC774;름 \*`time.cloudflare.com`표시된 텍스트 필드에.

## 리눅스

Cloudflare의 시간 서버는 안으로 포함됩니다[풀.ntp.org](https://www.ntppool.org/en/)많은 Linux 배포 및 네트워크 제품에 대한 기본 시간 서비스입니다. NTP 클라이언트가 아래의 서버 중 하나에서 동기화되면 이미 Cloudflare의 시간 서비스를 사용하고 있습니다.

- [162.159.200.1](https://www.ntppool.org/scores/162.159.200.1)
- [162.159.200.123](https://www.ntppool.org/scores/162.159.200.123)
- [2606:4700:f1::1](https://www.ntppool.org/scores/2606:4700:f1::1)
- [2606:4700:f1::123](https://www.ntppool.org/scores/2606:4700:f1::123)

NTP 클라이언트를 수동으로 설정하려면 우리의 시간 서비스를 사용하려면 먼저 Linux 배포에 대한 문서를 참조하여 NTP 클라이언트를 사용하고 구성 파일이 저장되는 곳을 결정하십시오.

예를 들면:

- [다운로드](https://ubuntu.com/server/docs/about-time-synchronisation)
- [한국어](https://wiki.debian.org/NTP)
- [IR정보](https://access.redhat.com/documentation/en-us/red_hat_enterprise_linux/7/html/system_administrators_guide/ch-configuring_ntp_using_the_chrony_suite)

Exact 구성은 Linux 배포에 따라 다를 것입니다. 그러나 아래는 인기있는 클라이언트의 일부 예 구성입니다.

### [한국어](https://chrony-project.org)

1. 더 보기`time.cloudflare.com`시스템의 구성 파일에 서버 (예:`/etc/chrony/chrony.conf`)

   ```
   server time.cloudflare.com iburst
   ```

2. 동기화된 서비스를 재시작합니다.

   ```
   systemctl restart chronyd
   ```

### [systemd-timesyncd의 경우](https://man7.org/linux/man-pages/man5/timesyncd.conf.5.html)

1. 더 보기`time.cloudflare.com`이름 \*`[Time]`시스템의 구성 파일의 섹션 (예 :,`/etc/systemd/timesyncd.conf`)

   ```
   [Time]
   NTP=time.cloudflare.com
   ```

2. systemd-timesyncd 서비스 재시작.

   ```
   systemctl restart systemd-timesyncd
   ```

### [사이트맵](https://linux.die.net/man/5/ntp.conf)

1. 더 보기`time.cloudflare.com`시스템의 구성 파일에 서버 (예:`/etc/ntp.conf`)

   ```
   server time.cloudflare.com iburst
   ```

2. ntpd 서비스 복원.

   ```
   systemctl restart ntpd
   ```

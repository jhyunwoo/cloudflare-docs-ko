거친 시간의 "Hello, world!"는 매우 간단합니다. 클라이언트는 UDP를 서버로 보내고 서버는 서명한 타임스탬프로 응답합니다.

프로토콜을 실행하려면 서버의 주소와 공공 키가 필요합니다.

- **서버 주소**: `roughtime.cloudflare.com:2003`(IP 주소로 해결)[anycast IP 범위](https://www.cloudflare.com/learning/cdn/glossary/anycast-network/)). IPv4 또는 IPv6를 사용할 수 있습니다.
- **공공 키**: `0GD7c3yP8xEc4Zl2zeuN2SlLvDVVocjsPSL8/Rl/7zg=`

시작하기, 다운로드 및 실행 Cloudflare의[고객지원](https://github.com/cloudflare/roughtime):

```go
go install github.com/cloudflare/roughtime/cmd/getroughtime@latest
getroughtime -ping roughtime.cloudflare.com:2003 -pubkey 0GD7c3yP8xEc4Zl2zeuN2SlLvDVVocjsPSL8/Rl/7zg=
```

## 베타 공지

모델 번호: Cloudflare 거친 시간은 현재 베타입니다. 그런 것과 같이, 우리의 뿌리 공중 열쇠는 할지도 모릅니다
미래에 변화. 현재 공개 키로 최신이 페이지를 유지하겠습니다.

또한 DNS를 사용하여 프로그래밍 할 수 있습니다. 예를 들면:

```sh
dig TXT roughtime.cloudflare.com | grep -oP 'TXT\s"\K.*?(?=")'
```

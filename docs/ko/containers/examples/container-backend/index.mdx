## 간단한 index.html 파일 추가

간단한 만들기`index.html`파일에`./dist`디렉토리.

<Details header="프로젝트">
  ```html
  <!DOCTYPE html>
  <html lang="en">

  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Widgets</title>
    <script defer src="https://cdnjs.cloudflare.com/ajax/libs/alpinejs/3.13.3/cdn.min.js"></script>
  </head>

  <body>
    <div x-data="widgets()" x-init="fetchWidgets()">
      <h1>Widgets</h1>
      <div x-show="loading">Loading...</div>
      <div x-show="error" x-text="error" style="color: red;"></div>
      <ul x-show="!loading && !error">
        <template x-for="widget in widgets" :key="widget.id">
          <li>
            <span x-text="widget.name"></span> - (ID: <span x-text="widget.id"></span>)
          </li>
        </template>
      </ul>

      <div x-show="!loading && !error && widgets.length === 0">
        No widgets found.
      </div>

    </div>

    <script>
      function widgets() {
        return {
          widgets: [],
          loading: false,
          error: null,

          async fetchWidgets() {
            this.loading = true;
            this.error = null;

            try {
              const response = await fetch('/api/widgets');
              if (!response.ok) {
                throw new Error(`HTTP ${response.status}: ${response.statusText}`);
              }
              this.widgets = await response.json();
            } catch (err) {
              this.error = err.message;
            } finally {
              this.loading = false;
            }
          }
        }
      }
    </script>

  </body>

  </html>
  ```
</Details>

이 예제에서, 우리는 사용[알파인](https://alpinejs.dev/)to fetch a list of 위젯에서`/api/widgets`.

이것은 매우 간단한 예 일 것입니다. 그러나 훨씬 더 복잡해질 수 있습니다.
이름 \*[Workers의 예는 frontend 프레임 워크와 통합](/workers/framework-guides/web-apps/)더 많은 정보.

## 노동자 정의

작업자는 정적 자산과 경로 요청을 컨테이너화 된 백엔드에 모두 제공 할 수 있어야합니다.

이 경우 경로가 시작하면 3개의 컨테이너 인스턴스 중 하나에 요청을 전달합니다.`/api`·
다른 모든 요청은 정적 자산으로 제공됩니다.

```javascript
import { Container, getRandom } from "@cloudflare/containers";

const INSTANCE_COUNT = 3;

class Backend extends Container {
	defaultPort = 8080; //컨테이너에서 8080 포트에 요청 전달
	sleepAfter = "2h"; //2 시간 만에 요청하지 않은 경우 컨테이너를 잠
}

export default {
	async fetch(request, env) {
		const url = new URL(request.url);
		if (url.pathname.startsWith("/api")) {
			//참고 : "getRandom"은 가까운 미래에 지연으로 대체됩니다.
			const containerInstance = await getRandom(env.BACKEND, INSTANCE_COUNT);
			return containerInstance.fetch(request);
		}

		return env.ASSETS.fetch(request);
	},
};
```

:::참조
이 예제는`getRandom`함수는, 랜덤하게 될 임시 돕는
컨테이너의 N 인스턴스를 선택하여 요청을 전달합니다.

앞으로, 우리는 개량한 latency-aware 짐 균형을 잡고 Autoscaling를 제공할 것입니다.

이것은 stateless 인스턴스를 간단하고 더 효율적으로 routing 할 것입니다. 이름 \*
[자동화 문서](/containers/platform-details/scaling-and-routing)더 많은 정보.

## 백엔드 컨테이너 정의

당신의 콘테이너는 요구에 응할 수 있어야 합니다`/api/widgets`.

이 경우, 우리는 위젯의 하드 코딩 된 목록을 반환 간단한 Golang 백엔드를 사용합니다.

<Details header="서버.go">
  ```go
  package main

  import (
  	"encoding/json"
  	"log"
  	"net/http"
  )

  func handler(w http.ResponseWriter, r \*http.Request) {
  	widgets := []map[string]interface{}{
  		{"id": 1, "name": "Widget A"},
  		{"id": 2, "name": "Sprocket B"},
  		{"id": 3, "name": "Gear C"},
  	}

  	w.Header().Set("Content-Type", "application/json")
  	w.Header().Set("Access-Control-Allow-Origin", "*")
  	json.NewEncoder(w).Encode(widgets)

  }

  func main() {
  	http.HandleFunc("/api/widgets", handler)
  	log.Fatal(http.ListenAndServe(":8080", nil))
  }

  ```
</Details>

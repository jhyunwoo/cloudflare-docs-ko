WebSocket 요청은 기본적으로 컨테이너에 자동으로 전달됩니다.`fetch`에 대한 방법`Container`종류:

```js
import { Container, getContainer } from "@cloudflare/containers";

export class MyContainer extends Container {
	defaultPort = 8080;
	sleepAfter = "2m";
}

export default {
	async fetch(request, env) {
		//기본적으로 인스턴스를 가져오고 외부 Worker에서 websocket을 전달합니다.
		return getContainer(env.MY_CONTAINER).fetch(request);
	},
};
```

전체 보기[컨테이너 클래스 저장소](https://github.com/cloudflare/containers/tree/main/examples/websocket).

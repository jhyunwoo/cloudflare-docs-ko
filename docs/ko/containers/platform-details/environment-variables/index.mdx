## Runtime 환경 변수

컨테이너 런타임은 다음과 같은 변수를 자동으로 설정합니다:

- `CLOUDFLARE_APPLICATION_ID`- 용기의 ID
- `CLOUDFLARE_COUNTRY_A2`- 한국어[ISO 3166-1 알파 2 부호](https://www.iso.org/obp/ui/#search/code/)국가의 컨테이너가 배치됩니다
- `CLOUDFLARE_LOCATION`- 위치의 이름은 컨테이너에 배치됩니다
- `CLOUDFLARE_REGION`- 지역명
- `CLOUDFLARE_DURABLE_OBJECT_ID`- 컨테이너가 경계되는 튼튼한 객체 인스턴스의 ID. 대시보드에 특정 컨테이너 인스턴스를 식별할 수 있습니다.

## 사용자 정의 환경 변수

작업자의 컨테이너를 정의할 때 환경 변수를 설정할 수 있습니다. 또는 컨테이너 인스턴스를 시작할 때.

예를 들면:

```javascript
class MyContainer extends Container {
	defaultPort = 4000;
	envVars = {
		MY_CUSTOM_VAR: "value",
		ANOTHER_VAR: "another_value",
	};
}
```

defining 환경 변수 및 비밀에 대한 자세한 내용은에서 찾을 수 있습니다[이 예제](/containers/examples/env-vars-and-secrets).

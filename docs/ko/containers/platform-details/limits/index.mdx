## Instance 유형

메모리, vCPU 및 컨테이너의 디스크 공간은 인스턴스 유형을 통해 설정됩니다. 6개의 사전 정의된 인스턴스 유형 중 하나를 사용하거나 구성할 수 있습니다.[사용자 정의 인스턴스 유형](#custom-instance-types).

이것은 지정된 사용[`instance_type`이름 \*](/workers/wrangler/configuration/#containers)당신의 노동자의 Wrangler 윤곽 파일에서.

:::참조
더 보기`dev`·`standard`인스턴스 유형은 백워드 호환성을 위해 보존되며 aliases입니다.`lite`·`standard-1`각각.
주요 특징

### 주문 Instance 유형

미리 정의된 인스턴스 유형 외에도 지정하여 사용자 지정 인스턴스 유형을 구성할 수 있습니다.`vcpu`, `memory_mib`·`disk_mb`가치. 이름 \*[Wrangler 구성 문서](/workers/wrangler/configuration/#custom-instance-types)구성 세부 사항.

Custom 인스턴스 유형에는 다음과 같은 제약이 있습니다.

| 회사연혁        | 지원하다                  |
| ----------- | --------------------- |
| 최소 vCPU     | 1                     |
| 최대 vCPU     | 4                     |
| 최대 기억       | 12 지브                 |
| 최대 디스크      | 20GB 이상               |
| vCPU 비율에 기억 | vCPU 당 최소 3 GiB 메모리   |
| 디스크 메모리 비율  | 최대 2 GB 디스크 1 GiB 메모리 |

1 vCPU 미만의 workloads를 위해, 같은 predefined 인스턴스 유형을 사용하십시오`lite`또는`basic`.

더 큰 인스턴스를 찾고?[저희에 게 연락](/containers/beta-info/#feedback-wanted)그리고 당신이 필요로 하는 어떤 크기 인스턴스를 알려, 그리고 당신이 그들을 사용 하 여 원하는 것.

## 제한 사항

오픈 베타에서, 다음 제한은 현재 효과:

| 제품 정보                                          | 모델 번호: Workers 계정 만들기               |
| ---------------------------------------------- | ----------------------------------- |
| 모든 동시 살아있는 콘테이너 인스턴스를 위한 기억                    | 6티B                                 |
| 모든 concurrent 살아있는 콘테이너 예를 들면 vCPU             | 1,500                               |
| TB Disk for all concurrent live container 인스턴스 | 30TB의                               |
| 이미지 크기                                         | 같은 것과[인스턴스 디스크 공간](#instance-types) |
| 계정 당 총 이미지 저장                                  | 100개 GB[^1]                         |

[^1]: 컨테이너 이미지 삭제`wrangler containers delete`무료 공간. 컨테이너 이미지를 삭제하면[롤백](/workers/configuration/versions-and-deployments/rollbacks/)이전 버전으로 작업자는 더 이상 작동하지 않을 수 있습니다.

## vCPU, 메모리 및 디스크

컨테이너는 매월 $ 5 USD의 일부로 포함 된 월간 사용과 함께 다음 요금에서 적극적으로 실행되는 모든 10ms에 청구됩니다.[모델 번호: Workers 유료 플랜](/workers/platform/pricing/):

|                           | 기억하기                                                     | CPU의 CPU                                         | 팟캐스트                                           |
| ------------------------- | -------------------------------------------------------- | ------------------------------------------------ | ---------------------------------------------- |
| **무료 다운로드**               | 사이트맵                                                     | 사이트맵                                             |                                                |
| **모델 번호: Workers 계정 만들기** | 포함되는 25 GiB-hours/month<br />+$0.0000025 추가 GiB-second 당 | 375 vCPU 분 / 월<br />+ 추가 vCPU-second 당 $0.000020 | 200 GB 시간 / 월<br />+$0.00000007 추가 GB-second 당 |

당신은 당신이 사용하는 것에 대한 지불 - 요청이 컨테이너로 보내거나 수동으로 시작할 때 요금 시작. 컨테이너 인스턴스가 수면으로 이동한 후 충전을 중지합니다. 이것은 0으로 스케일을 쉽게 만들고 파열 트래픽도 높은 활용도를 얻을 수 있습니다.

메모리 및 디스크 사용은*관련 자료*선택한 인스턴스 유형의 경우 CPU 사용량이 기반으로 합니다.*관련 상품*이름 \*

#### Instance 유형

컨테이너를 배포할 때, 지정[인스턴스 유형](/containers/platform-details/#instance-types).

선택한 인스턴스 유형은 청구서에 영향을 미칩니다. 더 큰 인스턴스에는 더 많은 메모리 및 디스크, 추가 비용 처리 및 더 높은 CPU 용량이 포함되어있어 활성 사용량을 기반으로 CPU 비용을 절감 할 수 있습니다.

## 네트워크 Egress

컨테이너의 Egress는 다음과 같은 속도로 가격이 책정됩니다.

| (주)             | GB 당 가격 | 한 달에 할당 |
| --------------- | ------- | ------- |
| 북미 및 유럽         | $0.025  | 1 TB의   |
| Oceania, 한국, 대만 | $0.05   | 100개 GB |
| 모든 곳에서 Else     | $0.04   | 100개 GB |

## Workers 및 Durable Objects 가격

컨테이너를 사용할 때 컨테이너에 들어오는 요청은 컨테이너에 의해 처리됩니다.[작업자](/workers/platform/pricing/), 그리고 각 콘테이너에는 그것의 소유가 있습니다
[튼튼한 목표](/durable-objects/platform/pricing/). 당신은 Workers와 Durable ObjectsXQ 둘 다의 당신의 사용법을 위해 청구됩니다.

## 로그 및 Observability

컨테이너는 통합되어 있습니다.[Workers 로그인](/workers/observability/logs/workers-logs/)플랫폼과 같은 비율에 청구. 더 알아보기[Workers 로그 가격](/workers/observability/logs/workers-logs/#pricing)상세 정보

당신은[당신의 노동자를 위한 관찰 가능](/workers/observability/logs/workers-logs/#enable-workers-logs)컨테이너에 바인딩, 컨테이너에서 로그는 Cloudflare QXQXQXQX대시보드의 컨테이너 및 Observability 섹션 모두에서 표시됩니다.

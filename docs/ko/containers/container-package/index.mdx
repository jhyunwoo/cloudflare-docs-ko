컨테이너 인스턴스와 상호 작용하는 코드를 작성할 때 사용할 수 있습니다.
[튼튼한 목표 직접](/containers/platform-details/durable-object-methods)또는 사용[`Container`한국어](https://github.com/cloudflare/containers)수입하기[`@cloudflare/containers`](https://www.npmjs.com/package/@cloudflare/containers).

자주 묻는 질문`Container`대부분의 사용 사례에 대한 클래스.

<PackageManagers pkg="@cloudflare/containers" />

그런 다음 확장 된 클래스를 정의 할 수 있습니다.`Container`, 당신의 노동자에서 그것을 사용:

```javascript
import { Container } from "@cloudflare/containers";

class MyContainer extends Container {
	defaultPort = 8080;
	sleepAfter = "5m";
}

export default {
	async fetch(request, env) {
		//default 인스턴스를 가져오고 외부 Worker에서 요청을 전달합니다.
		return env.MY_CONTAINER.getByName("hello").fetch(request);
	},
};
```

더 보기`Container`클래스 확장`DurableObject`그래서 모두[튼튼한 목표](/durable-objects)기능도 있습니다.
그것은 또한 일반적인 콘테이너 행동을 위한 추가 기능과 좋은 공용영역을 제공합니다,
같은:

- inactivity timeout 후 수면 인스턴스
- 특정 포트에 요청하기
- 시작, 중지, 오류에 상태 걸이 실행
- 요청하기 전에 특정 포트를 대기
- 환경변수 및 비밀 설정

이름 \*[GitHub 저장소](https://github.com/cloudflare/containers)더 많은 정보
그리고 완전한 API.

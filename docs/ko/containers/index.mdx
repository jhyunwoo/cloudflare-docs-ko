<Description>
  서버리스 컨테이너로 Workers 향상
</Description>

<Plan type="workers-paid" />

모든 프로그래밍 언어로 작성된 코드를 실행, 어떤 runtime에 내장, 응용 프로그램의 일부로[Workers](/workers).

귀하의 컨테이너 이미지를 지역으로 배포하십시오: 인프라 관리에 대해 걱정없이 - 그냥 정의
노동자와[`wrangler deploy`](/workers/wrangler/commands/#deploy).

당신이 실행할 수 있는 콘테이너로:

- 메모리 또는 디스크 공간에서 CPU 코어를 실행하는 데 필요한 리소스 기반 응용
- 풀 파일 시스템, 특정 실행 시간 또는 Linux 같은 환경을 요구하는 응용 및 라이브러리
- 컨테이너 이미지로 배포 된 응용 및 도구

컨테이너 인스턴스는 on-demand를 회전하고 코드를 사용하여 제어됩니다.[작업자](/workers). API 호출 또는 쓰기 쿠버네티스 연산자를 chaining 대신 JavaScriptXQ를 작성:

<Tabs>
  <TabItem label="Worker 코드">
    ```js
    import { Container, getContainer } from "@cloudflare/containers";

    export class MyContainer extends Container {
    	defaultPort = 4000; //항구는 위에 듣습니다
    	sleepAfter = "10m"; //요청이 전송되지 않은 경우 인스턴스를 중지 10 분
    }

    export default {
    	async fetch(request, env) {
    		const { "session-id": sessionId } = await request.json();
    		//주어진 세션 ID에 대한 컨테이너 인스턴스를 가져옵니다
    		const containerInstance = getContainer(env.MY_CONTAINER, sessionId);
    		//기본 포트에서 컨테이너 인스턴스에 요청을 전달
    		return containerInstance.fetch(request);
    	},
    };
    ```
  </TabItem>

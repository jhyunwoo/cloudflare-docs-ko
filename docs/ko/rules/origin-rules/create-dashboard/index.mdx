import { Render, Steps, DashButton } from "~/components";

<Steps>
  1. Cloudflare 대시보드에서 규칙에 가십시오**제품정보**사이트 맵

     <DashButton url="/?to=/:account/:zone/rules/overview" />

  2. 제품정보**규칙 만들기** > **근원 규칙**.

  3. (선택 사항) 일반적인 사용 사례를 해결하는 규칙 템플릿 중 하나를 선택하십시오. 그런 다음, 검토 및 제안 된 규칙 구성을 조정합니다.

  4. 규칙에 대한 설명 이름 입력**규칙 이름**.

  5. 이름 \***수신 요청 일치**, 정의[규칙 표현](/ruleset-engine/rules-language/expressions/edit-expressions/).

  6. 이름 \***세트 근원 모수**, 정의[근원 규칙 조정](/rules/origin-rules/features/)규칙 표현을 일치하는 요청을 변경하려면.

  7. 규칙을 저장하고 배포하려면, 선택**계정 만들기**. 규칙을 배포 할 준비가 없다면, 선택**Draft로 저장**.

     <Render file="rules-creation-dash-dns-popup" product="rules" />
</Steps>

뒤에 오는 근원 규칙은 HTTP를 삭제합니다`Host`맨 위로`hr-server.example.com`URI 경로로 시작하는 모든 요청`/hr-app/`. 그것은 또한 같은 hostname에 DNS 레코드를 overrides.

더 보기`Host`header override는 헤더 값만을 업데이트합니다. DNS 레코드 override는 수신 요청의 rerouting을 처리합니다. 이러한 overrides에 대한 자세한 내용은 참조[Origin 규칙 설정](/rules/origin-rules/features/).

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드" no-code="true">
    <Example>
      Expression Builder를 사용할 때 표현:

      | 제품정보   | 회사연혁 | 제품정보       |
      | ------ | ---- | ---------- |
      | URI 경로 | 시작하기 | `/hr-app/` |

      Expression Editor를 사용할 때 Expression:

      ```txt
      (starts_with(http.request.uri.path, "/hr-app/"))
      ```

      후에 가치**호스트 헤더** > **자주 묻는 질문**:

      ```txt
      hr-server.example.com
      ```

      후에 가치**DNS 기록** > **관련 기사**:

      ```txt
      hr-server.example.com
      ```
    </Example>
  </TabItem>

다음의 기원 규칙은 목적지 포트를 무시합니다.`8081`URI 경로가 시작되는 모든 요청에 대해`/team/calendar/`.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드" no-code="true">
    <Example>
      Expression 편집기의 텍스트:

      ```txt
      starts_with(http.request.uri.path, "/team/calendar/")
      ```

      후에 가치**관광 명소** > **자주 묻는 질문**:

      ```txt
      8081
      ```
    </Example>
  </TabItem>

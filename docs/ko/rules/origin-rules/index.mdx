Origin 규칙은 들어오는 트래픽이 이동하고 어떤 매개 변수를 사용자 정의 할 수 있습니다. 현재 다음과 같은 overrides를 수행 할 수 있습니다.

- [호스트 헤더](/rules/origin-rules/features/#host-header): 상속`Host`수신 요청 헤더.
- [서버 이름 표시 (SNI)](/rules/origin-rules/features/#server-name-indication-sni): 수신 요청의 Server Name Indication (SNI) 값을 상속합니다.
- [DNS 기록](/rules/origin-rules/features/#dns-record): 들어오는 요청의 해결 된 호스트 이름을 부여합니다.
- [항만 항구](/rules/origin-rules/features/#destination-port): 들어오는 요청의 해결 대상 포트를 부여합니다.

이 overrides가 적용될 때의 근원 규칙 표정은 결정할 것입니다.

## 중요한 말

당신은 근원 규칙을 가진 hostname을 override 경우에 (via`Host`header override 또는 DNS 레코드 override) 및 부하 잔액 구성에 헤더 override를 추가, 기원 규칙은 부하 잔액 구성에 우선 복용합니다.

이름 \*[페이지 규칙](/rules/page-rules/), 기원 규칙을 수행`Host`header override는 원래 요청의 SNI 값을 동일한 값으로 업데이트합니다.`Host`헤더. SNI 값을 다른 설정하려면`Host`header override는 동일한 기원 규칙에 SNI override를 추가하거나 이 목적을 위한 별도의 기원 규칙을 만듭니다.

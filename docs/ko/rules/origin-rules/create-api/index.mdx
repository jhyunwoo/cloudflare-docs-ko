사용 방법[규칙 세트 API](/ruleset-engine/rulesets-api/)API를 통해 원래 규칙을 만들 수 있습니다.

## 기본 규칙 설정

API를 통해 원래 규칙을 만들 때, 당신을 확인:

- 규칙 작업을 설정`route`.
- 수정하기[이름 \*](/rules/origin-rules/parameters/)내 계정`action_parameters`근원 override의 유형에 따라 분야.
- 규칙을 배포`http_request_origin`영역 수준에서 단계.

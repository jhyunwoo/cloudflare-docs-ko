이름 \*[다른 overrides](/rules/origin-rules/features/)다른 행동 매개변수를 포함해서`action_parameters`유형:

| Override 유형                  | 자주 묻는 질문                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------ |
| 호스트 헤더 override              | [`host_header`이름 \*](#host-header-override-parameters)                         |
| SNI 오버라이드                    | [`sni`기타 제품](#sni-override-parameters)                                         |
| DNS 레코드 오버라이드 / 목적지 포트 오버라이드 | [`origin`기타 제품](#dns-record-override-and-destination-port-override-parameters) |

:::참조
동일한 기원 규칙은 다른 유형의 과도한을 가질 수 있습니다. 더 알아보기[동일한 규칙에서 여러 배의 구성](#configuring-several-overrides-in-the-same-rule)문법 예제.
주요 특징

## 호스트 헤더 override 매개 변수

전체 구문`action_parameters`HTTP overriding 필드`Host`헤더는 다음과 같습니다:

```json
"action_parameters": {
  "host_header": "<HOST_HEADER_VALUE>"
}
```

## SNI override 모수

전체 구문`action_parameters`수신 요청의 SNI 값을 무시하는 필드는 다음과 같습니다.

```json
"action_parameters": {
  "sni": {
    "value": "<SNI_VALUE>"
  }
}
```

## DNS 레코드 override 및 대상 포트 override 매개 변수

전체 구문`action_parameters`호스트 이름과 들어오는 요청의 대상 포트를 무시하는 필드는 다음과 같습니다.

```json
"action_parameters": {
  "origin": {
    "host": "<HOSTNAME>",
    "port": <PORT>
  }
}
```

호스트 이름 또는 포트를 무시하면 omit`port`또는`host`모수, 각각.

## 동일한 규칙에서 여러 배의 구성

동일한 기원 규칙은 다른 유형의 과도한을 가질 수 있습니다. 예를 들어 단일 기원 규칙은 HTTP를 수행 할 수 있습니다.`Host`header override와 목적지 항구 override. 그러한 규칙의 구문은 다음과 같습니다.

```json
"action_parameters": {
  "host_header": "<HOST_HEADER_VALUE>",
  "origin": {
    "port": <PORT>
  }
}
```

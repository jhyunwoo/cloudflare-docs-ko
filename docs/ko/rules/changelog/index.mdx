## 2024-09-20

**CloudflareXQ에 대한 자동 DNS 검증 이름 \***

Cloudflare 대시보드는 지금 자동적으로 유효합니다[DNS 레코드](https://developers.cloudflare.com/dns/proxy-status/)·[SaaS 사용자 정의 호스트 이름에 대한 Cloudflare](https://developers.cloudflare.com/cloudflare-for-platforms/cloudflare-for-saas/domain-support/)특정 호스트명 또는 URL을 대상으로 하는 규칙. misconfigured 규칙을 방지하고 더 부드러운 배포를 보장하기 위해, 당신은 누락 또는 잘못 설정된 DNS 레코드 및 사용자 정의 호스트 이름에 대한 proactive 경고를 얻을 것이다.

## 2024-09-17

**Zstandard 지원으로 모든 계획에 사용할 수있는 압축 규칙**

[압축 규칙](https://developers.cloudflare.com/rules/compression-rules/)이제 Zstandard 압축을 지원하며 모든 Cloudflare 계획에서 사용할 수 있습니다. 무료 플랜 사용자는 점차 2024 년 내내 액세스 할 수 있습니다.

## 2024-09-13

**Snippets는 베타에서 사용할 수 있습니다.**

[Cloudflare 스니펫](https://developers.cloudflare.com/rules/snippets/)알파에서 beta로 전환했습니다.

## 2024-09-10

**wildcard replace() URL rewrite에서 지원되는 기능**

지금 사용할 수 있습니다[`wildcard_replace()`](https://developers.cloudflare.com/ruleset-engine/rules-language/functions/#wildcard_replace)rewrite 표현의 기능[URL 재 작성](https://developers.cloudflare.com/rules/transform/url-rewrite/).

## 2024-09-05

**새로운 규칙 만들기**

새 소식**이름 \*** > **한국어**Cloudflare QX대시보드의 페이지는 수십 개의 사전 제작 템플릿을 갖춘 단일 클릭으로 일반적인 규칙을 만들 수 있습니다. 각 상품의 규칙 제작자에게서 이 템플렛에 직접 접근할 수 있습니다. 또한, 탐구[본문 바로가기](https://developers.cloudflare.com/rules/examples/)실제 사용 사례 및 영감을위한 개발자 문서.

## 2024-08-22

**wildcard 지원으로 단일 Redirects에 대한 간단한 UI**

간단한 UI[단일 Redirects](https://developers.cloudflare.com/rules/url-forwarding/single-redirects/)이제 모든 사용자에게 사용할 수 있으며 URL을 쉽게 리디렉션하고 더 직관적입니다. 이 업데이트는 최근 빌드[wildcard 지원](https://developers.cloudflare.com/ruleset-engine/rules-language/functions/#wildcard_replace)Ruleset 엔진 제품에서. 새로운 UI에 접근하기**규칙 > Redirect 규칙**. 와일드 카드 지원 및 오픈 소스 Rust 크레이트에 대해 자세히 알아보기[블로그 게시물](https://blog.cloudflare.com/wildcard-rules).

## 2024-08-20

**클라우드 커넥터는 모든 고객에게 제공**

Cloud Connector (beta)는 이제 모든 고객에게 제공됩니다. 설정 세부 사항, 참조[관련 기사](https://developers.cloudflare.com/rules/cloud-connector/), 탐구[이름 \*](https://developers.cloudflare.com/rules/cloud-connector/examples/), 체크 아웃[블로그 게시물](https://blog.cloudflare.com/cloud-connector).

## 2024-08-16

**클라우드 커넥터는 이제 모든 무료 고객에게 제공**

Cloud Connector (beta)는 이제 모든 무료 및 유료 고객의 하위 세트에 사용할 수 있습니다. 이 롤아웃은[점차 확장](https://developers.cloudflare.com/rules/cloud-connector/#availability)모든 Cloudflare 사용자에게 멀티 클라우드 관리를 단순화하고 Cloudflare의 연결성 클라우드와 통합을 강화. 더 많은 정보를 원하시면, 참조[블로그 게시물](https://blog.cloudflare.com/cloud-connector).

## 2024-08-12

**모델 번호: Cloudflare Snippets 제한이 업그레이드되었습니다.**

Cloudflare Snippets (alpha)는 이제 플랜에 따라 여러 하위 요청을 허용합니다. 더 많은 정보를 원하시면, 참조[적용분야](https://developers.cloudflare.com/rules/snippets/#availability).

## 2024-07-31

**Wildcard 지원에 추가됨 Ruleset Engine 제품**

Wildcards는 Single Redirects, Cache Rules, Transform Rules, WAFXQ, Waiting Room 등의 Ruleset Engine 기반 제품을 통해 지원됩니다.

- 지금 사용할 수 있습니다`wildcard`·`strict wildcard`전체 URI, 호스트, 헤더, 쿠키, 사용자 시약 및 국가와 같은 Ruleset Engine의 문자열 필드와 연산자. 더 자세한 내용은 참조[회사 소개](https://developers.cloudflare.com/ruleset-engine/rules-language/operators/)·[Wildcard 일치](https://developers.cloudflare.com/ruleset-engine/rules-language/operators/#wildcard-matching).
- 내 계정[단일 Redirects](https://developers.cloudflare.com/rules/url-forwarding/single-redirects/)·`wildcard_replace()`함수는 일치한 세그먼트를 사용할 수 있습니다`wildcard`·`strict wildcard`URL 대상을 리디렉션하는 연산자. 더 많은 정보를 원하시면, 참조[제품정보](https://developers.cloudflare.com/ruleset-engine/rules-language/functions/#wildcard_replace).

## 2024-03-22

**규칙 표현의 새로운 TLS 필드**

고객은 이제 새로운 필드를 사용할 수 있습니다.`cf.tls_client_hello_length`(TLS Handhake에서 보내진 클라이언트 인사 메시지의 길이),`cf.tls_client_random`(TLS Handhake에서 클라이언트가 제공하는 32 바이트 임의 값) 및`cf.tls_client_extensions_sha1`(TLS 클라이언트 연장의 SHA-1 지문) Ruleset Engine에 내장 된 다양한 제품.

## 2024-03-20

**Origin 규칙은 이제 Host Header Override의 포트 번호를 허용합니다.**

고객은 이제 Host Header Override의 임의 포트 번호를 사용할 수 있습니다. 너무 이른 호스트 이름은 값으로 허용되었다 (예를 들어,`example.com`). 이제 값을 설정할 수 있습니다.`hostname:port`(예:`example.com:1234`) 뿐만 아니라.

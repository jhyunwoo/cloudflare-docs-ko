규칙 구성을 해결 할 때, 검토[Transform 규칙 평가](/rules/transform/#transform-rules-evaluation)Transform 규칙이 각 요청에 대해 평가되는 방법을 이해하는 섹션.

Transform Rules 구성과 관련된 런타임 오류에 대한 자세한 내용은 참조[Cloudflare 1xxx 오류](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/).

## 왜 내 요청 헤더 수정을 볼 수 없습니다?

요청 헤더 수정을 수행하는 변형 규칙은 Cloudflare의 네트워크에 의해 전송 된 HTTP 헤더에 영향을줍니다. 브라우저 요청 또는 응답 데이터에 이러한 헤더를 찾을 수 없습니다. 규칙이 의도대로 작동되는지 말해 줄 수 있습니다.

요청 헤더 변형 규칙이 효력을 발생하면, 원래 서버에서 로그를 확인하거나 사용[Cloudflare 추적](/rules/trace-request/)규칙이 올바르게 일치하는 트래픽을 확인하려면. 이름 \*[Cloudflare Logpush의](/logs/logpush/)원래 HTTP 요청/response 헤더만 로그 푸쉬 로그는 Transform 규칙을 통해 수행 한 헤더 변환을 포함하지 않습니다.

웹 사이트 방문자가 브라우저에서 수신되는 HTTP 헤더를 추가하려면 반드시 해야 합니다.[응답 헤더 수정](/rules/transform/response-header-modification/)대신.

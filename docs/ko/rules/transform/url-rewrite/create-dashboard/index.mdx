## Wildcard 패턴 매개 변수

Cloudflare 대시보드는 와일드카드 매칭 및 교체를 기반으로 URL 리깅을 만드는 간단한 사용자 인터페이스를 제공합니다. 당신이 선택할 때**Wildcard 패턴**, 당신은 유효한 뒤에 오는 모수가 있을 것입니다:

- **URL 요청**: 입력[wildcard 패턴](/ruleset-engine/rules-language/operators/#wildcard-matching)asterisk 사용`*`) 다수 요구에 응하는 특성. 예를 들어,`http*://*.example.com/*`.

- **그런 다음 경로 및 / 또는 쿼리를 다시 작성**: 정의[URL rewrite 설정](/rules/transform/url-rewrite/reference/parameters/)포함 :
  - **오시는 길** > **대상 경로**: 와일드카드를 포함할 수 있는 URI 경로 입력(예를 들어,`/oldpath/*`).
  - **오시는 길** > **자주 묻는 질문**: 새로운 URI 경로 입력. 사용 가능[wildcard 교체](/ruleset-engine/rules-language/functions/#wildcard_replace)등`${1}`·`${2}`동적 대상 경로 정의 (예를 들면,`/newpath/${1}`). URI 경로를 제거하기 위해이 필드를 비워.
  - **글쓰기** > **대상 쿼리**: 와일드카드를 포함할 수 있는 쿼리 문자열을 입력(예를 들어,`?sort=*`).
  - **글쓰기** > **자주 묻는 질문**: 새로운 쿼리 문자열을 입력하십시오. 사용 가능[wildcard 교체](/ruleset-engine/rules-language/functions/#wildcard_replace)등`${1}`·`${2}`동적 쿼리 문자열 정의 (예를 들어,`?order=${1}`). 쿼리 문자열을 제거하기 위해이 필드를 비웁니다.

더 알아보기[URL rewrite 모수](/rules/transform/url-rewrite/reference/parameters/#wildcard-matching-and-replacement)API를 사용할 때 동등한 규칙 구성을 위해.

:::주\[주]

더 보기**URL 요청**값은 규칙과 들어오는 요청과 일치하기 위해서만 사용됩니다. URL 패턴을 복제하는 데 사용할 수 없습니다. URL 경로 또는 쿼리 문자열을 일치하면**대상 경로**또는**대상 쿼리**, 각각은, 확인합니다**URL 요청**패턴은 들어오는 요청이나 다른 규칙이 트리거되지 않습니다.

URL rewrite 규칙 일치를 유효한, 사용[Cloudflare 추적](/rules/trace-request/). rewritten URL을 유효하게 하기 위하여, 당신의 근원 서버를 검사하십시오.

:::

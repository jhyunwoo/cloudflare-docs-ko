## 표현을 씁니다.

다시 쓰기 표현 (즉, 동적 URL을 정의하는 표현은 수행 할 수 있습니다) 다음 필드를 포함 할 수 있습니다:

- `http.request.uri.*`
- `http.request.headers.*`
- `http.request.accepted_languages`

더 알아보기[필드 참고 자료](/ruleset-engine/rules-language/fields/reference/)이 분야에서 더 많은 정보를 제공합니다.

더 보기[`concat()`](/ruleset-engine/rules-language/functions/#concat), [`regex_replace()`](/ruleset-engine/rules-language/functions/#regex_replace)·[`wildcard_replace()`](/ruleset-engine/rules-language/functions/#wildcard_replace)함수는 다시 작성된 표현에서 한 번만 나타납니다. 또한, 당신은 배열 할 수 없습니다`regex_replace()`·`wildcard_replace()`기능.

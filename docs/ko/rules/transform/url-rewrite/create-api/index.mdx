사용 방법[규칙 세트 API](/ruleset-engine/rulesets-api/)API를 통해 URL Rewrite 규칙을 만들려면. 더 알아보기[규칙 예제 갤러리](/rules/transform/examples/?operation=Rewrite+URL)일반적인 사용 사례.

Terraform을 사용하는 경우, 참조[Terraform을 사용하여 규칙 구성](/terraform/additional-configurations/transform-rules/#create-a-url-rewrite-rule).

## 기본 규칙 설정

API를 통해 URL rewrite 규칙을 만들 때, 확인:

- 규칙 작업을 설정`rewrite`.
- 수정하기[URL rewrite 모수](/rules/transform/url-rewrite/reference/parameters/#api-information)내 계정`action_parameters`URL rewrite의 유형에 따라 필드 (정적 또는 동적).
- 규칙을 배포`http_request_transform`영역 수준에서 단계.

## 예제 요청

<Details header="예제: 정적 URL rewrite를 수행하는 규칙을 추가">
  다음 예제는 기존 단계 규칙의 규칙을 설정합니다 (`$RULESET_ID`) 단일 URL 재쓰기 규칙에 - URI 경로의 정적 재쓰기 - 사용[지역 규칙 업데이트](/api/resources/rulesets/methods/update/)가동. 응답은 업데이트되는 규칙의 완전한 정의를 포함합니다.

  <APIRequest
    path="/zones/{zone_id}/rulesets/{ruleset_id}"
    method="PUT"
    json={{

  		{
  			ref: "rewrite_eu_to_emea",
  			expression: '(http.request.uri.query contains "eu")',
  			description: "My first static URL rewrite rule",
  			action: "rewrite",
  			action_parameters: {
  				uri: {
  					path: {
  						value: "/emea.html",
  					},
  				},
  			},
  		},
  	],
  }}
  />

  <APIRequest

  			action_parameters: {
  				uri: {
  					path: {

## 필수 API 토큰 권한

API 요청에서 사용되는 API 토큰은 URL Rewrite 규칙을 최소한의 다음 권한이 있어야 합니다.

- *계좌정보* > *Transform 규칙* > *제품정보*
- *계좌정보* > *계정 규칙* > *...에서*

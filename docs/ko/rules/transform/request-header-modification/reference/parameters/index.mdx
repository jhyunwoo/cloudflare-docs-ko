API를 통해 HTTP 요청 헤더를 설정하려면 다음 매개 변수를 설정하십시오.`action_parameters`유형:

- **(주)**: `set`
- 정적 또는 동적 값을 정의하는 다음 매개 변수 중 하나를 포함:

  - **제품정보**: HTTP 요청 헤더에 대한 정적 값을 지정합니다.
  - **이름 \***: HTTP 요청 헤더의 값을 정의하는 표현을 지정합니다.

API를 통해 HTTP 요청 헤더를 제거하려면 다음 매개 변수를 설정하십시오.`action_parameters`유형:

- **(주)**: `remove`

Step-by-step 지시를 위해, 참고하십시오[API를 통해 요청 헤더 변형 규칙 만들기](/rules/transform/request-header-modification/create-api/).

## 정체되는 우두머리 가치 모수

전체 구문`action_parameters`정적 HTTP 요청 헤더 값을 정의하는 필드는 다음과 같습니다.

```json
"action_parameters": {
  "headers": {
    "<HEADER_NAME>": {
      "operation": "set",
      "value": "<URI_PATH_VALUE>"
    }
  }
}
```

## 동적 헤더 값 매개 변수

전체 구문`action_parameters`표현식을 사용하여 동적 HTTP 요청 헤더 값을 정의하는 필드는 다음과 같습니다.

```json
"action_parameters": {
  "headers": {
    "<HEADER_NAME>": {
      "operation": "set",
      "expression": "<EXPRESSION>"
    }
  }
}
```

:::참조
자주 묻는 질문[유효한 분야 및 기능](/rules/transform/request-header-modification/reference/fields-functions/)표현에서 사용할 수 있습니다.

## Header 제거 모수

전체 구문`action_parameters`HTTP 요청 헤더를 제거하는 필드는 다음과 같습니다.

```json
"action_parameters": {
  "headers": {
    "<HEADER_NAME>": {
      "operation": "remove"
    }
  }
}
```

## 동일한 규칙에 다른 헤더 수정

동일한 규칙은 다른 가동을 사용하여 다른 HTTP 요청 헤더를 수정할 수 있습니다 (set or remove header). 예를 들어, 단일 규칙은 헤더의 값을 설정하고 다른 헤더를 제거 할 수 있습니다. 그러한 규칙의 구문은 다음과 같습니다.

```json
"action_parameters": {
  "headers": {
    "<HEADER_NAME_1>": {
      "operation": "set",
      "value": "<HEADER_VALUE_1>"
    },
    "<HEADER_NAME_2>": {
      "operation": "remove"
    }
  }
}
```

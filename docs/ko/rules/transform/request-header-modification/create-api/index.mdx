사용 방법[규칙 세트 API](/ruleset-engine/rulesets-api/)API를 통해 Request Header Transform Rule을 작성합니다. 더 알아보기[규칙 예제 갤러리](/rules/transform/examples/?operation=Request+modification)일반적인 사용 사례.

Terraform을 사용하는 경우, 참조[Terraform을 사용하여 규칙 구성](/terraform/additional-configurations/transform-rules/#create-a-request-header-transform-rule).

## 기본 규칙 설정

요청 헤더를 생성하면 API를 통해 규칙을 변형시키면 다음을 확인하십시오.

- 규칙 작업을 설정`rewrite`.
- 수정하기[header 수정 매개 변수](/rules/transform/request-header-modification/reference/parameters/)내 계정`action_parameters`작업에 따라 현장 수행 (설정 또는 헤더 제거).
- 규칙을 배포`http_request_late_transform`영역 수준에서 단계.

## 예제 요청

<Details header="예: 정적 값으로 HTTP 요청 헤더를 추가">
  다음 예제는 기존 단계 규칙의 규칙을 설정합니다 (`$RULESET_ID`) 단일 요청 헤더 변형 규칙 - HTTP 요청 헤더를 정적 값으로 추가 - 사용[지역 규칙 업데이트](/api/resources/rulesets/methods/update/)가동. 응답은 업데이트되는 규칙의 완전한 정의를 포함합니다.

  <APIRequest
    path="/zones/{zone_id}/rulesets/{ruleset_id}"
    method="PUT"
    json={{
  	rules: [
  		{
  			ref: "add_header_source",
  			expression: '(starts_with(http.request.uri.path, "/en/"))',
  			description: "My first request header transform rule",
  			action: "rewrite",
  			action_parameters: {
  				headers: {
  					"X-Source": {
  						operation: "set",
  						value: "Cloudflare",
  					},
  				},
  			},
  		},
  	],
  }}
  />

  ```json output
  {
  	"result": {
  		"id": "<RULESET_ID>",
  		"name": "Zone-level Late Transform Ruleset",
  		"description": "Zone-level ruleset that will execute Late Transform Rules.",
  		"kind": "zone",
  		"version": "2",
  		"rules": [
  			{
  				"ref": "add_header_source",
  				"id": "<RULE_ID>",
  				"version": "1",
  				"action": "rewrite",
  				"action_parameters": {
  					"headers": {
  						"X-Source": {
  							"operation": "set",
  							"value": "Cloudflare"
  						}
  					}
  				},
  				"expression": "(starts_with(http.request.uri.path, \"/en/\"))",
  				"description": "My first request header transform rule",
  				"last_updated": "2021-04-14T14:42:04.219025Z",
  				"ref": "<RULE_REF>"
  			}
  		],
  		"last_updated": "2021-04-14T14:42:04.219025Z",
  		"phase": "http_request_late_transform"
  ```

Transform 규칙은 Cloudflare 글로벌 네트워크에서 요청 및 응답의 URI 경로, 쿼리 문자열 및 HTTP 헤더를 조정할 수 있습니다.

Transform 규칙의 몇몇 유형이 있습니다:

- [**URL Rewrite 규칙**](/rules/transform/url-rewrite/): HTTP 요청의 URL 경로 및 쿼리 문자열을 다시 작성합니다.
- [**Header Transform 규칙 요청**](/rules/transform/request-header-modification/): HTTP 요청 헤더의 값을 설정하거나 요청 헤더를 제거하십시오.
- [**응답 헤더 Transform 규칙**](/rules/transform/response-header-modification/): HTTP 응답 헤더의 값을 설정하거나 응답 헤더를 제거하십시오.
- [**관리된 Transforms**](/rules/transform/managed-transforms/): 버튼 클릭으로 HTTP 요청 및 응답 헤더에 일반적인 조정을 수행합니다.

## 적용분야

Cloudflare Transform 규칙은 모든 고객에게 유효합니다. 일반 표현에 대한 지원은 Cloudflare 계획에 따라 다릅니다.

이 테이블은 각 고객 계획에 사용할 수있는 Transform 규칙을 설명합니다.

## Transform 규칙 평가

HTTP 헤더를 수정하는 Transform 규칙의 다른 유형의 앞에 관리된 Transform:

- HTTP 요청 헤더를 요청하기 전에 실행되는 관리형 변환.
- HTTP 응답 헤더가 응답 헤더 Transform 규칙 전에 실행되도록 관리 된 변환.

Transform 규칙은 순서대로 실행됩니다. Transform 규칙 목록에서 나중에 나타나는 규칙은 이전 규칙에 의해 수행 된 변경을 덮을 수 있습니다. 대시보드XQ 또는 API를 통해 규칙 순서를 정의할 수 있습니다.

요구와 응답 분야는 각 안에 immutable 입니다[단계별](/ruleset-engine/about/phases/)요청/response에 대한 Transform 규칙을 평가하는 동안. 더 많은 정보를 원하시면, 참조[규칙 평가 중 필드 값](/ruleset-engine/about/rules/#field-values-during-rule-evaluation).

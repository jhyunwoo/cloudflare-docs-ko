Managed Transforms는 버튼 클릭으로 HTTP 요청 및 응답 헤더에 일반적인 조정을 수행 할 수 있습니다. 유효한 조정은 다음을 포함합니다:

- 봇 보호 요청 헤더를 추가합니다.
- 방문자의 IP 주소와 관련된 헤더를 제거하거나 추가합니다.
- WAFXQ가 누출 된 자격 증명을 감지 할 때 요청 헤더를 추가하십시오.
- 보안 관련 응답 헤더를 추가합니다.
- "X-Powered-By" 응답 헤더를 제거하십시오.

전체 목록은 참조[가능한 관리형 Transforms](/rules/transform/managed-transforms/reference/).

관리형 Transform을 사용할 때 CloudflareXQ는 내부적으로 선택한 일반적인 구성을 처리하기 위해 하나 이상의 Transform 규칙을 배치합니다. 이 생성 된 규칙은 계산되지 않습니다.[Transform 규칙의 최대 수](/rules/transform/#availability)Cloudflare 계획에서 유효한.

Enabled Managed Transforms는 영역의 모든 inbound 요청에 적용됩니다.

:::참조
생성 된 내부 변형 규칙은 Cloudflare 대시보드의 Transform 규칙 목록에 나타나지 않습니다.

  <TabItem label="사이트맵">
    **1. 유효한 관리된 Transforms의 명부를 얻으십시오**

    Managed Transform의 현재 상태 및 가용성 확인[관리 된 Transforms 목록](/api/resources/managed_transforms/methods/list/)가동.

    다음 예시 요청은 현재 상태에 대한 정보와 함께 요청 또는 응답으로 구성된 유효한 관리형 변환 목록을 얻습니다.`enabled`필드) 그리고 당신이 그들을 업데이트 할 수 있다면, 다른 활성화 된 변환과 충돌에 기반 (`has_conflict`분야).

    각 관리한 Transform 품목은 선택적으로 포함합니다`conflicts_with`현재 Managed Transform과 충돌 할 수있는 모든 Managed Transforms에 대해 알려줍니다.

    응답은 Cloudflare 계획 및 제품 구독에 따라 관리 된 변환 만 포함됩니다.

    <APIRequest path="/zones/{zone_id}/managed_headers" method="GET" />

    **2. 관리된 Transforms의 상태를 변경하십시오**

    상태 변경[원하는 관리된 Transforms](/rules/transform/managed-transforms/reference/)사용 방법[Managed Transforms의 업데이트 상태](/api/resources/managed_transforms/methods/edit/)가동.

    요청 몸으로 변경하려면 관리 된 Transforms를 추가하고 상태를 업데이트하십시오.`enabled`이름 \* 현재 관리된 Transform과 충돌이 있는 관리형 Transform을 활성화할 수 없습니다.`has_conflict`이름 \*`true`).

    올바른 JSON 객체에 업데이트되는 Managed Transforms를 포함하십시오.`managed_request_headers`또는`managed_response_headers`).

    응답은 업데이트 후 모든 가능한 관리 된 변환 및 새로운 상태를 포함합니다.

    <APIRequest
      path="/zones/{zone_id}/managed_headers"
      method="PATCH"
      json={{
  	managed_request_headers: [
  		{
  			id: "add_visitor_location_headers",
  			enabled: true,
  		},
  	],
  	managed_response_headers: [
  		{
  			id: "remove_x-powered-by_header",
  			enabled: true,
  		},
  	],
  }}
    />

두 언어의 환영 페이지를 가지고, 경로 구성 요소의 정적 쓰기 규칙을 두 URL을 다시 작성:

**URL 리깅 규칙 #1**

<Example>
  본문 바로가기**Expression 편집기**:

  ```txt
  http.request.uri.path == "/welcome.html" && ip.src.country == "GB"
  ```

  텍스트 후**오시는 길** > **자주 묻는 질문** > *제품 정보*:

  ```txt
  /welcome-gb.html
  ```
</Example>

**URL 리깅 규칙 #2**

<Example>
  본문 바로가기**Expression 편집기**:

  ```txt
  http.request.uri.path == "/welcome.html" && ip.src.country == "PT"
  ```

  텍스트 후**오시는 길** > **자주 묻는 질문** > *제품 정보*:

  ```txt
  /welcome-pt.html
  ```
</Example>

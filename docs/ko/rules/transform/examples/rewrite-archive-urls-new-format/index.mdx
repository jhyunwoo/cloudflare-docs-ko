URL 형식을 따르는 블로그 아카이브의 URL을 다시 작성하려면`/posts/<YYYY>-<MM>-<DD>-<TITLE>`새로운 형식으로`/posts/<YYYY>/<MM>/<DD>/<TITLE>`, 다음 URL rewrite 규칙을 만듭니다:

<Example>
  본문 바로가기**Expression 편집기**:

  ```txt
  http.request.uri.path ~ "^/posts/[0-9]+-[0-9]+-[0-9]+-.*"
  ```

  텍스트 후**오시는 길** > **자주 묻는 질문** > *·*:

  ```txt
  regex_replace(http.request.uri.path, "^/posts/([0-9]+)-([0-9]+)-([0-9]+)-(.*)$", "/posts/${1}/${2}/${3}/${4}")
  ```
</Example>

함수`regex_replace()`정규 표현의 캡처 그룹을 사용하여 URL의 일부를 추출 할 수 있습니다. 괄호에서 정규 표현의 일부를 입력하여 캡처 그룹을 만듭니다. 그런 다음 참고 자료를 사용하여 캡처 그룹`${<NUMBER>}`교체 문자열에서, 어디`<NUMBER>`캡처 그룹의 수입니다.

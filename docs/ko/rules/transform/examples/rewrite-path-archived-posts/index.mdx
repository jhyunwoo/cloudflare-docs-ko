모든 요청을 다시 쓰기`/news/2012/...`으로`/archive/news/2012/...`원래 URL의 내용에 참고 자료를 추가해야합니다. 새로운 URL을 다시 작성 규칙을 작성하고 동적 URL 경로를 정의[wildcard 패턴 매개 변수](/rules/transform/url-rewrite/create-dashboard/#wildcard-pattern-parameters):

<Example>
  **수신 요청 일치**

  - **Wildcard 패턴**
    - **URL 요청**: `https://<YOUR_HOSTNAME>/news/2012/*`

  **그런 다음 경로 및 / 또는 쿼리를 다시 작성**

  - **대상 경로**: \[`/`] `news/2012/*`
  - **자주 묻는 질문**: \[`/`] `archive/news/2012/${1}`
</Example>

자주 묻는 질문`<YOUR_HOSTNAME>`실제 호스트 이름과 설정에 따라 예제 경로 조정.

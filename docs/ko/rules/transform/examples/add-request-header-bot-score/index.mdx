다음 요청 헤더 변형 규칙은 header 이름을 추가합니다.`X-Bot-Score`HTTP 요청에 현재 봇 점수:

<Example>
  본문 바로가기**Expression 편집기**:

  ```txt
  starts_with(http.request.uri.path, "/en/")
  ```

  선택된 작업**요청 헤더를 수정**: *동적 설정*

  **헤더 이름**: `X-Bot-Score`

  **제품정보**: `to_string(cf.bot_management.score)`
</Example>

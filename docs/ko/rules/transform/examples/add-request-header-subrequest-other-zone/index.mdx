다음 요청 헤더 변형 규칙은 다른 영역에서 오는 Workers subrequests에 HTTP 헤더를 추가합니다.

<Example>
  본문 바로가기**Expression 편집기**(장소)`myappexample.com`귀하의 도메인):

  ```txt
  (cf.worker.upstream_zone != "" and cf.worker.upstream_zone != "myappexample.com")
  ```

  선택된 작업**요청 헤더를 수정**: *설정 static*

  **헤더 이름**: `X-External-Workers-Subrequest`

  **제품정보**: `1`
</Example>

더 보기[`cf.worker.upstream_zone`](/ruleset-engine/rules-language/fields/reference/cf.worker.upstream_zone/)규칙 표현에서 사용되는 필드는 현재 요청이 Workers subrequest가 아닌 경우 빈으로 설정됩니다.

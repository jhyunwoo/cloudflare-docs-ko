다음 요청 헤더 변형 규칙은 header 이름을 추가합니다.`X-Source`정적 값으로 (`Cloudflare`) HTTP 요청에:

<Example>
  본문 바로가기**Expression 편집기**:

  ```txt
  starts_with(http.request.uri.path, "/en/")
  ```

  선택된 작업**요청 헤더를 수정**: *설정 static*

  **헤더 이름**: `X-Source`

  **제품정보**: `Cloudflare`
</Example>

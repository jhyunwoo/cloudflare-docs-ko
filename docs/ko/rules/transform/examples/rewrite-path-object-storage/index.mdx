제거하기`/files/`URI 경로에서 개체 저장 물통에 대한 라우팅 요청하기 전에 새로운 URL을 다시 쓰기 규칙을 만들고 동적 URL 경로 재 작성을 정의[wildcard 패턴 매개 변수](/rules/transform/url-rewrite/create-dashboard/#wildcard-pattern-parameters):

<Example>
  **수신 요청 일치**

  - **Wildcard 패턴**
    - **URL 요청**: `https://<YOUR_HOSTNAME>/files/*`

  **그런 다음 경로 및 / 또는 쿼리를 다시 작성**

  - **대상 경로**: \[`/`] `files/*`
  - **자주 묻는 질문**: \[`/`] `${1}`
</Example>

자주 묻는 질문`<YOUR_HOSTNAME>`실제 호스트 이름과 설정에 따라 예제 경로 조정.
다음, 사용[클라우드 커넥터](/rules/cloud-connector/)물체 저장 물통에 교통을 경로로.

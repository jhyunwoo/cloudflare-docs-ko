아래 모든 것을 다시 작성`/blog/<PATH>`으로`/marketing/<PATH>`, 새로운 URL rewrite 규칙을 만들고 동적 URL 경로를 정의[wildcard 패턴 매개 변수](/rules/transform/url-rewrite/create-dashboard/#wildcard-pattern-parameters):

<Example>
  **수신 요청 일치**

  - **Wildcard 패턴**
    - **URL 요청**: `https://<YOUR_HOSTNAME>/blog/*`

  **그런 다음 경로 및 / 또는 쿼리를 다시 작성**

  - **대상 경로**: \[`/`] `blog/*`
  - **자주 묻는 질문**: \[`/`] `marketing/${1}`
</Example>

자주 묻는 질문`<YOUR_HOSTNAME>`실제 호스트 이름과 설정에 따라 예제 경로 조정.

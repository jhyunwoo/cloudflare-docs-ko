자주 묻는 질문`/blog`오시는 길`/blog?sort-by=date`, 다음 설정으로 URL rewrite 규칙을 만듭니다:

<Example>
  본문 바로가기**Expression 편집기**:

  ```txt
  http.request.uri.path == "/blog"
  ```

  텍스트 후**글쓰기** > **자주 묻는 질문** > *제품 정보*:

  ```txt
  sort-by=date
  ```
</Example>

또한 같은 규칙의 동작을 다시 씁니다.*예약안내*URL 경로가 변경되지 않습니다.

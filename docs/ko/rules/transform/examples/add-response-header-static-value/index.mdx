다음 응답 헤더 변형 규칙은 header 이름을 추가합니다.`set-cookie`정적 값으로 (`cookiename=value`HTTP 응답에 ):

<Example>
  본문 바로가기**Expression 편집기**:

  ```txt
  starts_with(http.request.uri.path, "/en/")
  ```

  선택된 작업**응답 헤더를 수정**: *더 보기*

  **헤더 이름**: `set-cookie`

  **제품정보**: `cookiename=value`
</Example>

이 규칙은 어떤 존재를 지킬 것입니다`set-cookie`헤더는 이미 HTTP 응답에 존재한다.

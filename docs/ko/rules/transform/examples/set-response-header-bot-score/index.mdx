다음 응답 헤더 변형 규칙은 header 이름을 설정합니다.`X-Bot-Score`HTTP 응답의 현재 봇 점수:

<Example>
  본문 바로가기**Expression 편집기**:

  ```txt
  starts_with(http.request.uri.path, "/en/")
  ```

  선택된 작업**응답 헤더를 수정**: *동적 설정*

  **헤더 이름**: `X-Bot-Score`

  **제품정보**: `to_string(cf.bot_management.score)`
</Example>

이 규칙은 어떤 존재를 덮어`X-Bot-Score`헤더는 이미 HTTP 응답에 존재한다.

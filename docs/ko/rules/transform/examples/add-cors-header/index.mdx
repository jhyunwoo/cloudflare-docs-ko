다음 응답 헤더 변형 규칙은 header 이름을 추가합니다.`Access-Control-Allow-Origin`정적 와일드 카드 값 (static wildcard value)`*`HTTP 응답에 ):

<Example>
  본문 바로가기**Expression 편집기**:

  ```txt
  (http.host eq "<YOUR_HOSTNAME>")
  ```

  선택된 작업**응답 헤더를 수정**: *설정 static*

  **헤더 이름**: `Access-Control-Allow-Origin`

  **제품정보**: `*`
</Example>

CORS 헤더를 여러 특정 호스트 이름에 적용하기 위해 다음과 같은 표현식을 사용할 수 있습니다.

```txt
(http.host in {"<YOUR_HOSTNAME_1>" "<YOUR_HOSTNAME_2>"})
```

같은 경로를 다시 쓰기`/images/<FOLDER1>/<FOLDER2>/<FILENAME>`— 어디`<FOLDER1>`, `<FOLDER2>`·`<FILENAME>`다를 수 있습니다 —`/img/<FILENAME>`, 경로 구성 요소의 동적 재 작성 규칙을 작성:

<Example>
  본문 바로가기**Expression 편집기**:

  ```txt
  http.request.uri.path ~ "^/images/[^/]+/[^/]+/[^/]+$"
  ```

  텍스트 후**오시는 길** > **자주 묻는 질문** > *·*:

  ```txt
  regex_replace(http.request.uri.path, "^/images/[^/]+/[^/]+/(.+)$", "/img/${1}")
  ```
</Example>

예를 들어,이 규칙은 다시 쓰기`/images/nature/animals/tiger.png`오시는 길`/img/tiger.png`.

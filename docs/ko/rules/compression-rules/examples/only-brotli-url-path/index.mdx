  <TabItem label="대시보드">
    다음 예제 규칙은 특정 URI 경로에 대한 Brotli 압축 만 구성합니다.

    <Example>
      **수신 요청 일치**

      - 사용자 정의 필터 표현:
        - *URI 경로* *이름 \** `/download/assets.tar`

      **다음 것**

      - **압축 옵션**: 사용자 정의
      - **압축 유형에 대한 사용자 정의 주문 정의**: `Brotli`
    </Example>

    규칙 설정이 포함되지 않기 때문에*자동차*사용자 정의 알고리즘 목록의 끝에 웹 방문자가 Brotli를지지하지 않는 경우 응답이 uncompressed 것입니다.
  </TabItem>

  <TabItem label="사이트맵">
    다음 예제는 기존의 규칙을 설정합니다.[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)(ID 포함)`{ruleset_id}`)에 대한`http_response_compression`단일 압축 규칙에 단계, 사용[지역 규칙 업데이트](/api/resources/rulesets/methods/update/)가동:

    <APIRequest
      path="/zones/{zone_id}/rulesets/{ruleset_id}"
      method="PUT"
      json={{
  	rules: [
  		{
  			ref: "use_only_brotli_for_assets_tar",
  			expression: 'http.request.uri.path eq "/download/assets.tar"',
  			action: "compress_response",
  			action_parameters: {
  				algorithms: [{ name: "brotli" }],
  			},
  		},
  	],
  }}
    />

    <Render file="terraform-use-ref-field" product="rules" params={{ addDocsLocation: true }} />
  </TabItem>

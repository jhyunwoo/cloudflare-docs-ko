    <Example>
      **수신 요청 일치**

      - 사용자 정의 필터 표현:
        - *미디어 유형* *이름 \** `image/avif` **이름 \***
        - *파일 확장* *이름 \** `avif`

      **다음 것**

      - **압축 옵션** > *압축 해제*
    </Example>
  </TabItem>

  <TabItem label="사이트맵">
    다음 예제는 기존의 규칙을 설정합니다.[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)(ID 포함)`{ruleset_id}`)에 대한`http_response_compression`단일 압축 규칙에 단계, 사용[지역 규칙 업데이트](/api/resources/rulesets/methods/update/)가동:

    <APIRequest
      path="/zones/{zone_id}/rulesets/{ruleset_id}"
      method="PUT"
      json={{
  	rules: [
  		{
  			ref: "disable_compression_for_avif",
  			expression:
  				'http.response.content_type.media_type eq "image/avif" or http.request.uri.path.extension eq "avif"',
  			action: "compress_response",
  			action_parameters: {
  				algorithms: [{ name: "none" }],
  			},
  		},
  	],
  }}
    />

    <Render file="terraform-use-ref-field" product="rules" params={{ addDocsLocation: true }} />

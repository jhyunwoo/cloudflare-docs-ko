  <TabItem label="대시보드">
    다음과 같은 예 규칙은 주어진 영역의 모든 들어오는 요청에 대한 Brotli 압축을 해제합니다. 사용 가능한 압축 알고리즘은 Gzip입니다.

    <Example>
      **수신 요청 일치**

      - 모든 수신 요청

      **다음 것**

      - **압축 옵션**: 사용자 정의
      - **압축 유형에 대한 사용자 정의 주문 정의**: `Gzip`
    </Example>

    클라이언트가 Gzip 압축을 지원하지 않는 경우에, 응답은 압축될 것입니다.
  </TabItem>

  <TabItem label="사이트맵">
    다음 예제는 기존의 규칙을 설정합니다.[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)(ID 포함)`{ruleset_id}`)에 대한`http_response_compression`단일 압축 규칙에 단계, 사용[지역 규칙 업데이트](/api/resources/rulesets/methods/update/)가동:

    <APIRequest
      path="/zones/{zone_id}/rulesets/{ruleset_id}"
      method="PUT"
      json={{
  	rules: [
  		{
  			ref: "always_use_gzip",
  			expression: "true",
  			action: "compress_response",
  			action_parameters: {
  				algorithms: [{ name: "gzip" }],
  			},
  		},
  	],
  }}
    />

    <Render file="terraform-use-ref-field" product="rules" params={{ addDocsLocation: true }} />
  </TabItem>

  <TabItem label="대시보드">
    다음과 같은 예 규칙은 CSV 파일에 대한 선호 압축 방법으로 Gzip 압축을 구성합니다. 방문자가이 알고리즘을 지원하지 않는 경우 Cloudflare는 방문자가 지원하는 다른 알고리즘을 사용하여 응답을 압축하려고합니다.

    <Example>
      **수신 요청 일치**

      - 사용자 정의 필터 표현:
        - *파일 확장* *이름 \** `csv`

      **다음 것**

      - **압축 옵션**: 사용자 정의
      - **압축 유형에 대한 사용자 정의 주문 정의**: `Gzip`, `Auto`
    </Example>
  </TabItem>

  <TabItem label="사이트맵">
    다음 예제는 기존의 규칙을 설정합니다.[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)(ID 포함)`{ruleset_id}`)에 대한`http_response_compression`단일 압축 규칙에 단계, 사용[지역 규칙 업데이트](/api/resources/rulesets/methods/update/)가동:

    <APIRequest
      path="/zones/{zone_id}/rulesets/{ruleset_id}"
      method="PUT"
      json={{
  	rules: [
  		{
  			ref: "use_gzip_for_csv",
  			expression: 'http.request.uri.path.extension eq "csv"',
  			action: "compress_response",
  			action_parameters: {
  				algorithms: [{ name: "gzip" }, { name: "auto" }],
  			},
  		},
  	],
  }}
    />

    <Render file="terraform-use-ref-field" product="rules" params={{ addDocsLocation: true }} />

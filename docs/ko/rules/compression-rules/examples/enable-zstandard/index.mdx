  <TabItem label="대시보드">
    다음과 같은 예 규칙은 응답 내용 유형에 대한 Zstandard 압축을 켜집니다.[Cloudflare는 기본적으로 압축을 적용합니다](/speed/optimization/content/compression/). 클라이언트가 Zstandard 압축을 지원하지 않는 경우에, 그것은 Brotli 또는 Gzip 압축을 fallback로 사용할 것입니다.

    <Example>
      **수신 요청 일치**

      - 사용자 정의 필터 표현:
        - *미디어 유형* *로그인* `text/html, text/richtext, text/plain, text/css, text/x-script, text/x-component, text/x-java-source, text/x-markdown, application/javascript, application/x-javascript, text/javascript, text/js, image/x-icon, image/vnd.microsoft.icon, application/x-perl, application/x-httpd-cgi, text/xml, application/xml, application/rss+xml, application/vnd.api+json, application/x-protobuf, application/json, multipart/bag, multipart/mixed, application/xhtml+xml, font/ttf, font/otf, font/x-woff, image/svg+xml, application/vnd.ms-fontobject, application/ttf, application/x-ttf, application/otf, application/x-otf, application/truetype, application/opentype, application/x-opentype, application/font-woff, application/eot, application/font, application/font-sfnt, application/wasm, application/javascript-binast, application/manifest+json, application/ld+json, application/graphql+json, application/geo+json`

      **다음 것**

      - **압축 옵션**: 사용자 정의
      - **압축 유형에 대한 사용자 정의 주문 정의**: `Zstandard`, `Brotli`, `Gzip`
    </Example>
  </TabItem>

  <TabItem label="사이트맵">
    다음 예제는 기존의 규칙을 설정합니다.[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)(ID 포함)`{ruleset_id}`)에 대한`http_response_compression`단일 압축 규칙에 단계, 사용[지역 규칙 업데이트](/api/resources/rulesets/methods/update/)가동:

    <APIRequest
      path="/zones/{zone_id}/rulesets/{ruleset_id}"
      method="PUT"
      json={{
  	rules: [
  		{
  			ref: "use_zstd_compression",
  			expression:
  				'(http.response.content_type.media_type in {"text/html" "text/richtext" "text/plain" "text/css" "text/x-script" "text/x-component" "text/x-java-source" "text/x-markdown" "application/javascript" "application/x-javascript" "text/javascript" "text/js" "image/x-icon" "image/vnd.microsoft.icon" "application/x-perl" "application/x-httpd-cgi" "text/xml" "application/xml" "application/rss+xml" "application/vnd.api+json" "application/x-protobuf" "application/json" "multipart/bag" "multipart/mixed" "application/xhtml+xml" "font/ttf" "font/otf" "font/x-woff" "image/svg+xml" "application/vnd.ms-fontobject" "application/ttf" "application/x-ttf" "application/otf" "application/x-otf" "application/truetype" "application/opentype" "application/x-opentype" "application/font-woff" "application/eot" "application/font" "application/font-sfnt" "application/wasm" "application/javascript-binast" "application/manifest+json" "application/ld+json" "application/graphql+json" "application/geo+json"})',
  			action: "compress_response",
  			action_parameters: {
  				algorithms: [{ name: "zstd" }, { name: "brotli" }, { name: "gzip" }],
  			},
  		},
  	],
  }}
    />

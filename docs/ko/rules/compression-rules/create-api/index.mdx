사용 방법[규칙 세트 API](/ruleset-engine/rulesets-api/)API를 통해 압축 규칙을 만듭니다.

## 기본 규칙 설정

API를 통해 압축 규칙을 만들 때, 당신을 확인:

- 규칙 작업을 설정`compress_response`.
- 매개 변수를 정의`action_parameters`분야에 따라[제품정보](/rules/compression-rules/settings/#api-configuration-settings)일치하는 요청에 대한 override를 원합니다.
- 규칙을 배포`http_response_compression`영역 수준에서 단계.

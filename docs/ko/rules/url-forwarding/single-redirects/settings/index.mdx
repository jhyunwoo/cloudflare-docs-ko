다음 섹션은 정적 및 동적 URL 리디렉션을 구성하는 리디렉션 규칙의 설정을 설명합니다.

## Wildcard URL 리디렉션

URL을 사용하여 리디렉션 수행[wildcard 패턴](/ruleset-engine/rules-language/operators/#wildcard-matching)여러 요청을 일치합니다. 이 방법은 복잡한 표현이 필요없는 소스와 대상 URL 패턴을 정의합니다.

와일드 카드 URL 리디렉션에는 다음과 같은 구성 매개 변수가 있습니다:

- **URL 요청**: 입력[wildcard 패턴](/ruleset-engine/rules-language/operators/#wildcard-matching)asterisk 사용`*`) 다수 요구에 응하는 특성. 예를 들어,`https://*.example.com/files/*`.

- **대상 URL**: 정적일 수 있는 대상 URL을 입력합니다.`https://example.com`) 또는 동적인 (예를 들면,`https://example.com/${1}/files/${2}`). 제품 정보[wildcard 교체](/ruleset-engine/rules-language/functions/#wildcard_replace)이름 \*`${1}`, `${2}`, 등, 동적 대상을 정의합니다.

- **상태 코드**: 리디렉션 응답의 HTTP 상태 코드 (*301*기본적으로). 다음 중 하나가 있어야합니다.*301*(정상적으로),*302*(단, 일시적으로 이동으로도 알려져 있음),*307*(Temporary redirect) 또는*308*(Permanent 리디렉션).

- **자주 묻는 질문**: 리디렉션 할 때 쿼리 문자열을 보존하는 것 (기본값으로 비활성화).

## 정적 URL 리디렉션

주어진 HTTP 상태 코드와 선택적으로 쿼리 문자열을 보존하는 정적 URL을 수행합니다.

정적 URL 리디렉션에는 다음과 같은 구성 매개 변수가 있습니다.

- **사이트 맵**: 리터럴 문자열은`Location`HTTP 헤더는 리디렉션 응답에 반환.

- **상태 코드**: 리디렉션 응답의 HTTP 상태 코드 (*301*기본적으로). 다음 중 하나가 있어야합니다.*301*(정상적으로),*302*(단, 일시적으로 이동으로도 알려져 있음),*307*(Temporary redirect) 또는*308*(Permanent 리디렉션).

- **자주 묻는 질문**: 리디렉션 할 때 쿼리 문자열을 보존하는 것 (기본값으로 비활성화).

<Details header="API 정보">
  전체 구문`"action_parameters"`static URL 리디렉션을 수행하는 리디렉션 규칙 필드는 다음과 같습니다.

  ```json
  "action_parameters": {
    "from_value": {
      "target_url": {
        "value": "<STATIC_URL_VALUE>"
      },
      "status_code": <STATUS_CODE>,
      "preserve_query_string": <BOOLEAN_VALUE>
    }
  }
  ```

  필수 매개 변수는`<STATIC_URL_VALUE>`.

## 동적 URL 리디렉션

동적 URL 리디렉션을 수행, 대상 URL이 표현에 의해 결정되는 곳. 리디렉션 HTTP 상태 코드를 구성하고 리디렉션할 때 쿼리 문자열을 보존할 수 있습니다.

동적 URL 리디렉션에는 다음과 같은 구성 매개 변수가 있습니다.

- **패스워드**: 한국어[이름 \*](/ruleset-engine/rules-language/expressions/)리다이렉트의 대상 URL을 정의한다. 이 표현을 평가하는 결과가 사용됩니다.`Location`HTTP 헤더는 리디렉션 응답에 반환. 더 알아보기[주요연혁](/ruleset-engine/rules-language/fields/reference/)·[제품정보](/ruleset-engine/rules-language/functions/)표현에서 사용할 수 있습니다.

- **상태 코드**: 리디렉션 응답의 HTTP 상태 코드 (*301*기본적으로). 다음 중 하나가 있어야합니다.*301*(정상적으로),*302*(단, 일시적으로 이동으로도 알려져 있음),*307*(Temporary redirect) 또는*308*(Permanent 리디렉션).

- **자주 묻는 질문**: 리디렉션 할 때 쿼리 문자열을 보존하는 것 (기본값으로 비활성화).

<Details header="API 정보">
  전체 구문`"action_parameters"`동적 URL 리디렉션을 수행하는 리디렉션 규칙 필드는 다음과 같습니다.

  ```json
  "action_parameters": {
    "from_value": {
      "target_url": {
        "expression": "<DYNAMIC_URL_EXPRESSION>"
      },
      "status_code": <STATUS_CODE>,
      "preserve_query_string": <BOOLEAN_VALUE>
    }
  }
  ```

  필수 매개 변수는`<DYNAMIC_URL_EXPRESSION>`.

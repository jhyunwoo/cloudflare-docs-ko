Single Redirects는 정적 또는 동적 URL을 만들 수 있습니다.<GlossaryTooltip term="redirect">관련 기사</GlossaryTooltip>. 간단한 공용영역[wildcard 지원](/ruleset-engine/rules-language/operators/#wildcard-matching)복잡한 기능이나 일반 표현이 필요없는 소스 및 대상 URL 패턴을 정의하기 쉬운 것은 단일 규칙으로 수천 개의 URL을 효율적으로 처리합니다. 동적 URL 리디렉션은 문자열 교체 작업과 같은 고급 기능을 지원합니다.[일반 표현](/ruleset-engine/rules-language/values/#string-values-and-regular-expressions)(CloudflareXQ 계획에 따라 다름).

이 예제는 영역에 대한 단일 리디렉션`example.com`특정 하위 도메인의 관리 영역에 대한 요청을 리디렉션합니다 (`store.example.com`)에 HTTPS, 원래 경로 및 쿼리 문자열을 유지.

<Example>
  **수신 요청 일치**

  - **Wildcard 패턴**
    - **URL 요청**: `http://store.example.com/admin*`

  **다음 것**

  - **대상 URL**: `https://store.example.com/admin${1}`
  - **상태 코드:** *301*
  - **preserve 쿼리 문자열:**&#xC774;름 \*
</Example>

예를 들어, 리디렉션 규칙은 다음 리디렉션을 수행 할 것입니다.

| URL 요청                                            | 대상 URL                                             | 상태 코드 |
| ------------------------------------------------- | -------------------------------------------------- | ----- |
| `http://store.example.com/admin/products/`        | `https://store.example.com/admin/products/`        | `301` |
| `https://store.example.com/admin/products/`       | (변경)                                               | ₢ 킹   |
| `http://store.example.com/admin/?logged_out=true` | `https://store.example.com/admin/?logged_out=true` | `301` |
| `http://store.example.com/?all_items=true`        | (변경)                                               | ₢ 킹   |
| `http://example.com/admin/`                       | (변경)                                               | ₢ 킹   |

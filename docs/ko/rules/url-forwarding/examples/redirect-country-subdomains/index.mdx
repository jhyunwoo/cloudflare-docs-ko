이 예제는 영역에 대한 단일 리디렉션`example.com`웹 사이트 루트 경로 요청 영국과 프랑스 방문자를 리디렉션합니다 (`/`) 현지화된 하위 도메인에`https://gb.example.com`·`https://fr.example.com`각각.

<Example>
  **수신 요청 일치**

  Expression 편집기 사용:<br />
  `(ip.src.country eq "GB" or ip.src.country eq "FR") and http.request.uri.path eq "/"`

  **다음 것**

  - **유형:** *·*
  - **표현:** `lower(concat("https://", ip.src.country, ".example.com"))`
  - **상태 코드:** *301*
</Example>

예를 들어, 리디렉션 규칙은 다음 리디렉션을 수행 할 것입니다.

| 국가 선택 | URL 요청        | 대상 URL                   | 상태 코드 |
| ----- | ------------- | ------------------------ | ----- |
| 대한민국  | `example.com` | `https://gb.example.com` | `301` |
| 한국어   | `example.com` | `https://fr.example.com` | `301` |
| 대한민국  | `example.com` | (변경)                     | ₢ 킹   |

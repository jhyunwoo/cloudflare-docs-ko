다음 예제는 모바일 장치를 사용하여 방문자를 리디렉션합니다 - 요청 사용자 에이전트 문자열 - 다른 호스트 이름.

## Redirect 모바일 사용자는 원래 URI 경로 삭제

이 예제 정적 리디렉션은 현재 영역에 대한 요청을 리디렉션합니다 (`example.com`) 모바일 사용자에서`m.example.com`원래 HTTP 요청에 URI 경로를 보존하지 않고.

<Example>
  **수신 요청 일치**

  - 다음 표현을 입력하십시오.[Expression 편집기](/ruleset-engine/rules-language/expressions/edit-expressions/#expression-editor):<br />
    `not http.host in {"m.example.com"} and (http.user_agent contains "mobi" or http.user_agent contains "Mobi")`

  **다음 것**

  - **유형:** *제품 정보*
  - **URL:** `m.example.com`
  - **상태 코드:** *301*
</Example>

이 예제에 대한 메모 :

- 더 보기`not http.host in {"m.example.com"}`상태는 리디렉션 루프를 방지합니다.
- 사용자 에이전트 조건[Mozilla의 추천](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/User-Agent/Firefox#device-specific_user_agent_strings)모바일 기기 식별
- 더 보기**다음 것** > **사이트 맵**값은 입력 한 것과 동일해야합니다.`http.host`규칙의 필터 표현의 조건.
- CloudflareXQ 또는 CloudflareXQ에 다른 이름에 사용자를 리디렉션할 수 있습니다.

## Redirect 모바일 사용자는 원래 경로 유지

이 예제 단일 리디렉션은 현재 영역에 대한 요청을 리디렉션합니다 (`example.com`) 모바일 사용자에서`m.example.com`원래 HTTP 요청의 URI 경로 유지.

<Example>
  **수신 요청 일치**

  - 다음 표현을 입력하십시오.[Expression 편집기](/ruleset-engine/rules-language/expressions/edit-expressions/#expression-editor):<br />
    `not http.host in {"m.example.com"} and (http.user_agent contains "mobi" or http.user_agent contains "Mobi")`

  **다음 것**

  - **유형:** *·*
  - **표현:** `concat("https://m.example.com", http.request.uri.path)`
  - **상태 코드:** *301*
</Example>

이 예제에 대한 메모 :

- 더 보기`not http.host in {"m.example.com"}`상태는 리디렉션 루프를 방지합니다.
- 사용자 에이전트 조건[Mozilla의 추천](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/User-Agent/Firefox#device-specific_user_agent_strings)모바일 기기 식별
- 호스트 이름**다음 것** > **패스워드**입력 한 것과 동일해야합니다.`http.host`규칙의 필터 표현의 조건.
- 사용 사례에 따라 사용할 수 있습니다.**다음 것** > **자주 묻는 질문**또한 원래 요청의 쿼리 문자열을 유지합니다.
- CloudflareXQ 또는 CloudflareXQ에 다른 이름에 사용자를 리디렉션할 수 있습니다.

이 예제 영역에 대한 정적 리디렉션`example.com`자주 묻는 질문`/contact-us/`페이지에 새 페이지 URL`/contacts/`.

<Example>
  **수신 요청 일치**

  - **유형:** *URI 경로*
  - **모델 번호:** *이름 \**
  - **가치:** `/contact-us/`

  Expression Editor를 사용하는 경우 다음의 표현을 입력하십시오.<br />
  `http.request.uri.path eq "/contact-us/"`

  **다음 것**

  - **유형:** *제품 정보*
  - **URL:** `/contacts/`
  - **상태 코드:** *301*
  - **preserve 쿼리 문자열:**&#xC774;름 \*
</Example>

예를 들어, 리디렉션 규칙은 다음 리디렉션을 수행 할 것입니다.

| URL 요청                             | 대상 URL                           | 상태 코드 |
| ---------------------------------- | -------------------------------- | ----- |
| `example.com/contact-us/`          | `example.com/contacts/`          | `301` |
| `example.com/contact-us/?state=TX` | `example.com/contacts/?state=TX` | `301` |
| `example.com/team/`                | (변경)                             | ₢ 킹   |

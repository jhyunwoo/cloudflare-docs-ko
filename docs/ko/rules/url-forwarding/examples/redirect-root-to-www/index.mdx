이 예제는 루트 도메인에서 HTTPS 요청을 전달하는 리디렉션 규칙을 만듭니다 (`example.com`) WWW 하위 도메인에 (`www.example.com`), 원래 경로 및 쿼리 문자열을 유지하면서.

<Example>
  **수신 요청 일치**

  - **Wildcard 패턴**
    - **URL 요청**: `https://example.com/*`

  **다음 것**

  - **대상 URL**: `https://www.example.com/${1}`
  - **상태 코드**: *301*
  - **자주 묻는 질문**: 지원
</Example>

이 규칙은 루트 도메인의 HTTPS 요청만 WW 하위 도메인에 리디렉션되어 다른 요청을 남기는 것을 보장합니다 (예 : HTTP 또는 다른 하위 도메인에 요청) 변경되지.

예를 들어, 리디렉션 규칙은 다음 리디렉션을 수행 할 것입니다.

| URL 요청                                       | 대상 URL                                           | 상태 코드 |
| -------------------------------------------- | ------------------------------------------------ | ----- |
| `https://example.com/products/`              | `https://www.example.com/products/`              | `301` |
| `https://store.example.com/products/`        | (변경)                                             | ₢ 킹   |
| `https://example.com/admin/?logged_out=true` | `https://www.example.com/admin/?logged_out=true` | `301` |
| `http://example.com/?all_items=true`         | (변경)                                             | ₢ 킹   |
| `http://www.example.com/admin/`              | (변경)                                             | ₢ 킹   |

자주 묻는 질문`example.com`당신의 규칙을 배포하기 전에 실제 호스트 이름과 함께.

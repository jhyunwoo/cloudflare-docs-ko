이 예제는 영역에 대한 단일 리디렉션`example.com`locale 포함 된 이전 URL 형식의 방문자를 리디렉션합니다 (예를 들어,`/en-us/<page_name>`) 새로운 체재에`/<page_name>`.

<Example>
  **수신 요청 일치**

  - **유형:** *URI 경로*
  - **모델 번호:** *경기 regex*
  - **가치:** `^/[A-Za-z]{2}-[A-Za-z]{2}/`

  Expression Editor를 사용하는 경우 다음의 표현을 입력하십시오.<br />
  `http.request.uri.path matches "^/[A-Za-z]{2}-[A-Za-z]{2}/"`

  **다음 것**

  - **유형:** *·*
  - **표현:** `regex_replace(http.request.uri.path, "^/[A-Za-z]{2}-[A-Za-z]{2}/(.*)", "/${1}")`
  - **상태 코드:** *301*
  - **preserve 쿼리 문자열:**&#xC774;름 \*
</Example>

함수[`regex_replace()`](/ruleset-engine/rules-language/functions/#regex_replace)정규 표현의 캡처 그룹을 사용하여 URL의 일부를 추출 할 수 있습니다. 괄호에서 정규 표현의 일부를 입력하여 캡처 그룹을 만듭니다. 그런 다음 참고 자료를 사용하여 캡처 그룹`${<num>}`교체 문자열에서, 어디`<num>`캡처 그룹의 수입니다.

예를 들어, 리디렉션 규칙은 다음 리디렉션을 수행 할 것입니다.

| URL 요청                                  | 대상 URL                            | 상태 코드 |
| --------------------------------------- | --------------------------------- | ----- |
| `example.com/en-us/meet-our-team`       | `example.com/meet-our-team`       | `301` |
| `example.com/pt-BR/meet-our-team`       | `example.com/meet-our-team`       | `301` |
| `example.com/en-us/calendar?view=month` | `example.com/calendar?view=month` | `301` |
| `example.com/meet-our-team`             | (변경)                              | ₢ 킹   |
| `example.com/robots.txt`                | (변경)                              | ₢ 킹   |

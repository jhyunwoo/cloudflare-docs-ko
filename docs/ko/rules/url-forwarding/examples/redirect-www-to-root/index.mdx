이 예제는 WWW 하위 도메인에서 HTTPS 요청을 전달하는 리디렉션 규칙을 만듭니다 (`www.example.com`) 루트 도메인에 (`example.com`), 원래 경로 및 쿼리 문자열을 유지하면서.

<Example>
  **수신 요청 일치**

  - **Wildcard 패턴**
    - **URL 요청**: `https://www.*`

  **다음 것**

  - **대상 URL**: `https://${1}`
  - **상태 코드**: *301*
  - **자주 묻는 질문**: 지원
</Example>

이 규칙은 HTTPS 요청 만 보장`www.`subdomains는 다른 요청을 남기는 루트 도메인에 리디렉션됩니다 (HTTP 또는 non-WWW와 같은).

예를 들어, 리디렉션 규칙은 다음 리디렉션을 수행 할 것입니다.

| URL 요청                                           | 대상 URL                                       | 상태 코드 |
| ------------------------------------------------ | -------------------------------------------- | ----- |
| `https://www.example.com/products/`              | `https://example.com/products/`              | `301` |
| `https://www.store.example.com/products/`        | `https://store.example.com/products/`        | `301` |
| `https://store.example.com/products/`            | (변경)                                         | ₢ 킹   |
| `https://www.example.com/admin/?logged_out=true` | `https://example.com/admin/?logged_out=true` | `301` |
| `http://www.example.com/?all_items=true`         | (변경)                                         | ₢ 킹   |
| `http://example.com/admin/`                      | (변경)                                         | ₢ 킹   |

이 예에서 영국에서 모든 웹 사이트 방문자는 다른 도메인으로 리디렉션되지만 동일한 경로의 현재 기능을 유지하십시오.

<Steps>
  1. 대량 리디렉트 목록 만들기`uk_redirect_list`다음 URL로 리디렉션:

     - **소스 URL**: `https://example.com/`
     - **대상 URL**: `https://example.co.uk/`
     - **Subpath 일치**: 지원
     - **자주 묻는 질문**: 지원

  2. 이전 대량 Redirect List를 활성화하고 다음의 규칙식을 설정하는 대량 Redirect Rule을 만듭니다.

     ```txt
     ip.src.country == "GB" and http.request.full_uri in $uk_redirect_list
     ```
</Steps>

이 구성은 영국 방문객을위한 다음 리디렉션을 수행 할 것입니다 :

| URL 요청                                    | 리디렉션 후 URL                                  |
| ----------------------------------------- | ------------------------------------------- |
| `https://example.com/`                    | `https://example.co.uk/`                    |
| `https://example.com/my/path/to/page.htm` | `https://example.co.uk/my/path/to/page.htm` |
| `https://example.com/search?q=term`       | `https://example.co.uk/search?q=term`       |

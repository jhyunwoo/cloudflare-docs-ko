Cloudflare 대시보드QXQ에서 대량 리디렉트를 만들려면 다음을해야합니다.

<Steps>
  1. 대량 Redirect List를 하나 이상의 URL 리디렉션으로 만듭니다.
  2. 목록에서 URL을 리디렉션할 수 있도록 대량 리디렉션 규칙을 만듭니다.
</Steps>

당신은 Cloudflare 대시보드에 대량 간접 명부 및 대량 간접 규칙을 창조할 수 있습니다:

- 계정 수준에서**대량 리디렉션**.
- 영역 수준에서 이동**이름 \*** > **계정 설정**그리고 선택**대량 Redirects**탭.

그러나 목록과 규칙은 계정 수준과 동일한 계정의 모든 영역에서 존재합니다.

## 1. 대량 Redirect 목록 만들기

{/* prettier-ignore-start */}

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**대량 리디렉션**사이트 맵

     <DashButton url="/?to=/:account/bulk-redirects" />

  2. 이름 \***대량 Redirect 목록**, 선택**대량 Redirect 목록 만들기**.

  3. 목록 이름과 설명을 입력하고, 선택**이름 \***.

  4. 여러 URL 리디렉션을 포함하는 CSV 파일을 가져올 수 있거나 URL 리디렉션을 입력하면 대시보드에서 한 번에 리디렉션됩니다.

     :::참조
     각 리디렉션의 소스 URL은 쿼리 문자열을 포함 할 수 없습니다. 더 많은 정보를 원하시면, 참조[지원 URL 구성](/rules/url-forwarding/bulk-redirects/reference/url-components/).
     :::

     <Details header="CSV 파일 가져 오기">
       1. URL 리디렉션을 포함하는 CSV 파일을 드래그하고 드롭하거나 선택**제품정보**CSV 파일을 선택합니다. 파일 형식에 대한 자세한 내용은 참조[대량 Redirects의 CSV 파일 형식](/rules/url-forwarding/bulk-redirects/reference/csv-file-format/).

       2. 대시보드는 파일에서 성공적으로 수입 된 URL 리디렉션을 표시합니다. 표시된 레코드 또는 추가/제거 URL을 수동으로 조정할 수 있습니다.

       3. 제품정보**이름 \***.
     </Details>

     <Details header="URL 리디렉션을 수동으로 추가">
       1. 제품정보**또는 수동으로 URL을 리디렉션 추가**.

       2. URL을 입력하면 목록을 추가합니다. 당신은 적어도 다음 세 가지 필드를 입력해야합니다:**소스 URL**, **대상 URL**·**주요연혁**. 추가 옵션을 설정하려면 확장**편집 모수**.

       3. URL 리디렉션 추가, 필요한 경우.

       4. 제품정보**이름 \***.
     </Details>

  5. URL을 리디렉션 및 편집하여 수입 또는 생성, 선택**이름 \***.

  6. 제품정보**Redirect 규칙을 계속**규칙 작성 페이지로 이동하고 다음 섹션에서 지침을 따르십시오. 정의된 URL 리디렉션을 활성화하려면 대량 리디렉션 규칙을 작성해야 합니다.
</Steps>

## 2. 대량 Redirect 규칙 만들기

<Steps>
  1. (선택) 이전 섹션의 지시에 따라 Bulk Redirect List 생성 마법사를 사용하지 않는 경우:
     1. Cloudflare 대시보드에서, 가십시오**대량 리디렉션**사이트 맵

        <DashButton url="/?to=/:account/bulk-redirects" />

     2. 제품정보**대량 Redirect 규칙 만들기**.

  2. 내 계정**규칙 이름**, 규칙에 대한 descriptive 이름을 입력합니다.

  3. 이전에 만든 대량 Redirect 목록을 선택하십시오.

  4. (선택) 필요한 경우, 선택**또는 표현 편집기를 사용**편집하기[규칙 표현](/rules/url-forwarding/bulk-redirects/concepts/#expression)또는[규칙 키](/rules/url-forwarding/bulk-redirects/concepts/#key).

  5. 대량 Redirect 규칙을 저장하고 배포하려면, 선택**저장 및 배포**. 규칙을 배포 할 준비가 없다면, 선택**Draft로 저장**.

     <Render file="rules-creation-dash-dns-popup" product="rules" />
</Steps>

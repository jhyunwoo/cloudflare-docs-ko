대량 Redirects는 계정 수준에서 URL 리디렉션의 큰 숫자를 정의 할 수 있습니다. 이 리디렉션은 소스 URL에서 주어진 HTTP 상태 코드를 사용하여 대상 URL로 이동합니다. URL 리디렉션은 URL 전달으로도 알려져 있습니다.

동적 URL 리디렉션과 같은[단일 Redirects](/rules/url-forwarding/single-redirects/), 대량 Redirects는 기본적으로 정적이다 — 그들은 문자열 교체 작업 또는 일반 표현을 지원하지 않습니다. 그러나 URL을 리디렉션 매개 변수를 구성할 수 있습니다. URL 일치 행동과 실행 동작에 영향을 미치는.

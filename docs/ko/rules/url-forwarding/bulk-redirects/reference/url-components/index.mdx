URL의 소스 및 대상 URL은 다른 URL 구성 요소를 리디렉션합니다.

제공되는 URL 구성 요소는 참고 자료 테이블에 다음과 같은 URL을 기반으로합니다.

```txt
https://user:password@www.example.com:443/search?q=term#results
```

| URL 구성                                       | 소스 URL에서 지원[^1]                | 대상 URL에서 지원                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **사이트맵**<br />예를 들면:<br />`https`            | 예,`http`또는`https`한국어<br />(선택) | 이름 \*                                                                                                                                                                                                                                                                                                                                             |
| **사용자 정보**<br />예를 들면:<br />`user:password`  | 이름 \*                          | 예 (옵션)                                                                                                                                                                                                                                                                                                                                            |
| **이름 \***<br />예를 들면:<br />`www.example.com` | 이름 \*                          | 예 (옵션)                                                                                                                                                                                                                                                                                                                                            |
| **항구 항구**<br />예를 들면:<br />`443`             | 이름 \*                          | 예 (옵션)                                                                                                                                                                                                                                                                                                                                            |
| **오시는 길**<br />예를 들면:<br />`/search`         | 이름 \*                          | 이름 \*                                                                                                                                                                                                                                                                                                                                             |
| **Query 문자열**<br />예를 들면:<br />`q=term`      | 이름 \*                          | 네,[**자주 묻는 질문**](/rules/url-forwarding/bulk-redirects/reference/parameters/#preserve-query-string)이름 \*`false`(선택)<br /><br />쿼리 문자열을 대상 URL에 추가할 수 있습니다.**자주 묻는 질문**이름 \*`false`). 설정하기**자주 묻는 질문**으로`true`, 요청의 쿼리 문자열은 따라 전달됩니다.[소스 URL에 대한 일치가있을 때](/rules/url-forwarding/bulk-redirects/how-it-works/#matching-the-source-url-of-redirects). |
| **회사 소개**<br />예를 들면:<br />`results`         | 이름 \*                          | 예 (옵션)                                                                                                                                                                                                                                                                                                                                            |

[^1]: **소스 URL에서 지원** = **이름 \***&#xC18C;스 URL의 구성 요소를 포함 할 수없는 경우 수신 요청의 URL에 일치합니다.

Bulk Redirects는 권한 컴포넌트 없이 대상 URL을 지원합니다.[^2]다음 URL과 같이:

```txt
magnet:?xt=urn:btih:2bd9d334e8d1e5bd7768755173222db5c6dea13b&dn=archlinux-2021.07.01-x86_64.iso
```

[^2]: URL 권한은 사용자 정보, 호스트 및 포트 구성 요소의 조합입니다.

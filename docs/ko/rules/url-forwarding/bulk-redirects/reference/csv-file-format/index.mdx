CSV 파일을 사용하여 URL을 대량 Redirect List로 리디렉션할 수 있습니다.[Cloudflare 대시보드](/rules/url-forwarding/bulk-redirects/create-dashboard/#1-create-a-bulk-redirect-list). CSV 파일의 각 라인은이 형식을 따라야 합니다.

```txt
<SOURCE_URL>,<TARGET_URL>[,<STATUS_CODE>,<PRESERVE_QUERY_STRING>,<INCLUDE_SUBDOMAINS>,<SUBPATH_MATCHING>,<PRESERVE_PATH_SUFFIX>]
```

한국어`<SOURCE_URL>`·`<TARGET_URL>`값은 필수입니다. 기본 값`<STATUS_CODE>`이름 \*`301`그리고 모든 boolean 매개 변수의 기본 값은`FALSE`.

URL 리디렉션 매개 변수 중 하나를 활성화하려면 다음 값 중 하나를 사용하십시오.`TRUE`또는`true`. 사용 가능한 옵션을 유지하려면`FALSE`또는`false`, 또는 어떤 값을 입력하지 않고 comma (delimiter)를 입력하십시오.

## CSV 파일 보기

이 예의 모든 라인은 대시보드XQ에 가져올 수있는 유효 라인입니다 :

```txt
example.com/contacts,https://example.net/contact-us,301,,,,
example.com/about,https://example.net/about-us,,FALSE,TRUE,,
example.com/docs,https://example.com/draft-docs,302,,TRUE
```

## 중요한 말

- CSV 파일은 열 이름과 헤더 행을 포함하지 않아야합니다.
- 소스/타겟 URL은 인용문에 동봉되어야 합니다 (`"`) comma를 포함 할 때 (`,`). 항상 인용 된 URL 값을 닫을 수 있지만 필요하지 않습니다.
- 선택값을 즉시 입력하지 않고 comma (delimiter)에 입력하여 선택값을 건너 뛸 수 있습니다.
- 쉼표를 포함 할 필요가 없습니다.

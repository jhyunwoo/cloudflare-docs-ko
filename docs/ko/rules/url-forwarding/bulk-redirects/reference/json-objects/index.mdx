## 대량 Redirect 규칙

완전히 채워진 대량 Redirect 규칙 객체에는 다음과 같은 JSON 구조가 있습니다.

```json
{
	"action": "redirect",
	"expression": "http.request.full_uri in $<LIST_NAME>",
	"action_parameters": {
		"from_list": {
			"name": "<LIST_NAME>",
			"key": "http.request.full_uri"
		}
	}
}
```

JSON 객체 속성은 다음과 같습니다.

- `action`\*필수`redirect`

- `action_parameters`자주 묻는 질문`from_list`추가 설정으로 객체.

- `from_list`다음 속성을 포함해야:
  - `name`: 기존 Bulk Redirect List의 이름은 현재 Bulk Redirect Rule을 준수합니다.
  - `key`: 구성 URL 리다이렉트의 소스 URL 값과 일치하는 값을 정의하는 표현[URL 매칭 알고리즘](/rules/url-forwarding/bulk-redirects/how-it-works/#url-matching-algorithm). 참고[대량 Redirects 개념](/rules/url-forwarding/bulk-redirects/concepts/#bulk-redirect-rules)더 많은 정보.

- `expression`참고 자료 요청 필드가 있어야 합니다.`key`호텔 위치 더 알아보기[대량 Redirects 개념](/rules/url-forwarding/bulk-redirects/concepts/#bulk-redirect-rules)더 많은 정보.

## URL 리디렉션 목록 항목

완전히 채워진 URL 리디렉션 목록 항목 객체에는 다음과 같은 JSON 구조가 있습니다.

```json
{
	"id": "7c5dae5552338874e5053f2534d2767a",
	"redirect": {
		"source_url": "https://example.com/blog",
		"target_url": "https://example.com/blog/latest",
		"status_code": 301,
		"include_subdomains": false,
		"subpath_matching": false,
		"preserve_query_string": false,
		"preserve_path_suffix": true
	},
	"created_on": "2021-10-11T12:39:02Z",
	"modified_on": "2021-10-11T12:39:02Z"
}
```

자세한 내용은`redirect`object 속성, 참조[URL 리디렉션 매개 변수](/rules/url-forwarding/bulk-redirects/reference/parameters/).

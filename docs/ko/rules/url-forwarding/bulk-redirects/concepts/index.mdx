Bulk Redirects는 다음과 같은 요소를 포함합니다.

- **URL 리디렉션**: 소스 URL, 대상 URL, 상태 코드 및 리디렉션 매개 변수와 간단한 객체. URL 리디렉션은 Bulk Redirect Lists의 목록 항목입니다.

- **대량 Redirect 목록**: IP 목록과 유사한 목록, 하나 이상의 URL 리디렉션을 포함. 대량 리디렉션 목록에서 모든 URL 리디렉션을 활성화하려면 참고 자료는 대량 리디렉션 규칙의 목록입니다. 다른 대량 간접 규칙은 동일한 대량 간접 명부를 참고 자료 할 수 있습니다.

- **대량 Redirect 규칙**: Ruleset Engine에 의해 구동되는 규칙[Transform 규칙](/rules/transform/). 대량 Redirect 규칙에는 관련 대량 Redirect 명부가 있습니다.

대량 리디렉션은 대량 리디렉션리스트를 활성화하여 1개 이상의 URL 리디렉션을 포함합니다.

![대량 Redirect Rules, 대량 Redirect Lists, URL 리디렉션 간의 계층 관계 강화](~/assets/images/rules/bulk-redirects/concepts-diagram.png)

다음 예제는 대량 Redirect List를 정의합니다.`list_b`두 URL 리디렉션으로:

<Example>
  **`list_b`대량 Redirect 목록**

  | 소스 URL                    | 대상 URL                     | 상태 코드      |
  | ------------------------- | -------------------------- | ---------- |
  | `example.com/about`       | `https://example.com/news` | `301`(기본값) |
  | `example.com/new_feature` | `https://example.com/soon` | `302`      |
</Example>

다음과 같은 대량 Redirect 규칙, 이름`Rule 2`, URL 리디렉션을 활성화`list_b`대량 간접 명부:

<Example>
  **`Rule 2`대량 Redirect 규칙**

  - **규칙 이름**: `Rule 2`
  - **관련 목록**: `list_b`
</Example>

## URL 리디렉션

URL 리디렉션을 사용하면 소스 URL, 대상 URL, 상태 코드 및 리디렉션 매개 변수를 구성할 수 있습니다.

소스 URL을 지정할 때, 와일드카드 대신 사용할 수 있는 리디렉션 매개 변수를 사용합니다. 예를 들어,**하위 도메인 포함**매개 변수는 하위 도메인에 적용되는 단일 URL 리디렉션을 구성할 수 있습니다 (예를 들어,`https://b.example.com`·`https://a.b.example.com`) 및 apex 도메인에 (`https://example.com`). 다른 매개 변수는 소스 URL의 경로와 쿼리 문자열이 처리되는 방법을 지정할 수 있습니다. 더 많은 정보를 원하시면, 참조[대량 Redirects 작업 방법](/rules/url-forwarding/bulk-redirects/how-it-works/).

URL 리디렉션은 Bulk Redirect Lists의 목록 항목입니다.

## 대량 Redirect 목록

Bulk Redirect List는 다른 목적으로 URL 리디렉션을 만들 수 있습니다. 대량 Redirect List를 하나 이상의 대량 Redirect Rules에서 사용할 수 있습니다.

대량 리디렉션 목록은 자체적으로 리디렉션을 수행하지 않습니다. 목록에서 리디렉션을 활성화하기 위해 대량 리디렉션 규칙의 목록은 참고 자료가 있어야 합니다.

대량 간접 목록은 정확한 동일한 소스 URL로 여러 URL을 리디렉션할 수 없습니다.

CSV 형식에 대한 자세한 내용은 대량 Redirect List에 항목 가져 오기, 참조[대량 Redirects의 CSV 파일 형식](/rules/url-forwarding/bulk-redirects/reference/csv-file-format/).

:::참조

대량 Redirect 규칙에 참고 자료 대량 Redirect 목록만 할 수 있습니다. Ruleset Engine에 의해 구동되는 규칙의 다른 유형은 대량 Redirect Lists를 지원하지 않습니다.

:::

## 대량 Redirect 규칙

Bulk Redirect Rules는 대량 Redirect List를 통해 하나 이상의 URL을 리디렉션할 수 있는 Ruleset Engine에 의해 구동되는 규칙입니다.

대량 리디렉션을 구성할 때, 대량 리디렉션 목록을 사용하여 해당 목록에서 모든 URL 리디렉션을 활성화합니다. 각 목록의 규칙을 만들 수 있습니다, 또는 같은 대량 Redirect 목록을 참조 많은 대량 Redirect 규칙.

규칙셋 엔진에 의해 구동되는 모든 규칙과 같은 대량 간접 규칙은 행동과 표현이 있습니다. 이 두 속성 외에도 이름, 옵션 설명, 관련 대량 Redirect List 및 키가 있습니다.

### 패스워드

규칙 표현, 또는 필터 표현, 규칙을 실행할 수 있어야 조건을 지정합니다. 기본적으로 지정된 목록의 모든 URL 리디렉션이 적용됩니다.

Bulk Redirect Rule의 기본 표현은 다음과 같습니다.

```txt
http.request.full_uri in $<LIST_NAME>
```

이 표현은 요청 URL, 몇 가지 기본 후<GlossaryTooltip term="URL normalization">일반화</GlossaryTooltip>(이후)[URL 정상화](/rules/normalization/)활성화), 목록에서 리디렉션 URL의 소스 URL과 일치해야합니다`<LIST_NAME>`적용하기 위해 리디렉션을 위해.

URL 리디렉션의 특정성을 증가시키기 위해 기본적으로 다른 표현식을 사용할 수 있습니다. 예를 들어, Bulk Redirect Rule의 표현을 다음과 같은 표현으로 설정하면 영국에서 오는 요청에 대한 일치가됩니다.

```txt
ip.src.country == "GB" and http.request.full_uri in $<LIST_NAME>
```

사용 가능한 필드에 대한 자세한 내용은 참조[유효한 분야 및 기능](/rules/url-forwarding/bulk-redirects/reference/fields-functions/).

:::참조

왼쪽에`in`작업자는 직접 필드를 사용할 수 있으며 함수에 의해 반환되지 않습니다. 대부분의 상황에서 다음 필드 중 하나를 사용하려는`in`통신수:

- `http.request.full_uri`
- `raw.http.request.full_uri`

더 알아보기[필드 참고 자료](/ruleset-engine/rules-language/fields/reference/)더 많은 정보.

:::

### 이름 \*

규칙 키는 규칙과 관련된 대량 리디렉션 목록과 결합하여 URL을 리디렉션으로 변환합니다.

규칙 표현에 대한 일치가있을 때, Cloudflare는 각 URL의 소스 URL과 규칙 키의 값을 비교하여 관련 대량 간접 목록에서 리디렉션합니다. 경기를 검색합니다.

열쇠는 하나 있어야 합니다`http.request.full_uri`또는`raw.http.request.full_uri`. 사용`raw.http.request.full_uri`웹 서버에서 수신한 URI를 비교하기 위해, 정상적인화의 앞에, 대량 Redirect 명부에 있는 근원 URL과.

키에 사용되는 URI 필드는 URI 필드와 동일해야합니다. 그렇지 않으면 규칙 표현에 대한 일치가있을 수 있지만 목록의 소스 URL의 일치는 없습니다. 예를 들어, 키를 설정하면`http.request.full_uri`, 규칙 표현에 사용되는 필드는 또한해야합니다`http.request.full_uri`. 당신은 열쇠를에 놓으면,`raw.http.request.full_uri`, 표식에 사용되는 필드는 반드시 있어야 합니다.`raw.http.request.full_uri`.

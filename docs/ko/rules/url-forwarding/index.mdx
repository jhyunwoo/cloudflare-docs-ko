URL 전달, URL 리디렉션으로 알려진, 소스 URL에서 특정 HTTP 상태 코드와 대상 URL로 사용자를 탐색.

다음 Cloudflare 제품을 사용하여 URL 리디렉션을 수행 할 수 있습니다.

- [**단일 Redirects**](/rules/url-forwarding/single-redirects/): 영역 수준에서 정적 또는 동적 리디렉션을 만들 수 있습니다. 간단한 인터페이스[wildcard 지원](/ruleset-engine/rules-language/operators/#wildcard-matching)복잡한 기능이나 일반 표현이 필요없는 소스와 대상 URL 패턴을 쉽게 정의할 수 있도록 단일 규칙으로 수천 개의 URL을 효율적으로 처리할 수 있습니다.

- [**대량 Redirects**](/rules/url-forwarding/bulk-redirects/): 계정 수준에서 리디렉션의 큰 숫자를 정의 할 수 있습니다. 이 URL 리디렉션은 기본적으로 정적이다 — 그들은 문자열 교체 작업 또는 일반 표현을 지원하지 않습니다. 그러나 리다이렉트의 URL 매칭 동작과 런타임 동작에 영향을 주는 매개 변수를 구성할 수 있습니다.

- [**뚱 베어**](/rules/snippets/): JavaScriptXQ 코드를 사용하여 복잡한 리디렉션 기능을 정의할 수 있습니다. 몇 가지[이름 \*](/rules/snippets/examples/?operation=Redirect)시작하기.에.

## 적용분야

단일 Redirects 및 대량 Redirects는 모든 Cloudflare 계획에서 사용할 수 있습니다. 정확한 인용과 특징은 당신의 계획에 달려 있습니다.

### 대량 리디렉션

<FeatureTable id="rules.bulk_redirects" />

제품 정보*URL 목록에서 리디렉션*, 이 테이블은 엔터프라이즈 플랜의 기본 할당량을 제공합니다. Bulk Redirects는 수백만 개의 URL 리디렉션을 지원합니다. 더 리디렉션을 얻으려면 계정 팀에 문의하십시오.

대량 Redirects 기능 및 quotas는 계정 당이며 계정에 가장 높은 Cloudflare 계획에 따라 다릅니다.

### 단일 Redirects

<FeatureTable id="rules.single_redirects" />

단일 Redirects 기능 및 quotas는 영역 당이며 지역 계획에 따라 다릅니다.

Custom Errors to return custom content to your website visitors in case of HTTP errors by a Origin 서버 또는 Cloudflare 제품 (포함[CloudflareWorkers](/workers/)), 또는 보여주는 경우[보안 도전](/cloudflare-challenges/).

다음 방법을 사용하여 사용자 정의 오류 콘텐츠를 구성할 수 있습니다.

- [**오류 페이지**](#error-pages): 특정 오류가 발생했을 때 웹 사이트 방문자에 표시된 HTML 페이지 (다른 페이지로 참조)[오류 페이지 유형](/rules/custom-errors/reference/error-page-types/)) 또는 보안 도전을 보여주는 경우. 오류 Pages는 영역 수준에서 정의 할 수 있으며 유료 계획의 계정 수준에서 우선 순위를 가지고 있습니다.
- [**사용자 정의 오류 규칙**](#custom-error-rules): CloudflareXQ가 HTTP 오류의 경우 방문자에게 사용자 정의 오류 응답을 제공 할 수 있음 (status codes)`400`그리고 위에), 그리고 정확한 내용은 봉사될 것입니다. 사용자 정의 오류 규칙은 계정 또는 같은 오류에 적용 할 영역 수준에서 구성 된 오류 페이지 이상 우선 순위가 있습니다.

사용자 정의 오류는 당신을 요구합니다[DNS 레코드 프록시](/dns/proxy-status/)CloudflareXQ를 통해 도메인 (또는 하위 도메인)의.

## 어떻게 작동합니까?

Cloudflare는 웹 사이트 방문자에게 오류 및 도전을 제시하기위한 기본 페이지 세트가 있습니다. 오류 Pages 및 사용자 정의 오류 규칙을 사용하여 그 페이지를 사용자 정의 할 수 있습니다.

오류가 있을 때[특정 유형](/rules/custom-errors/reference/error-page-types/)발생, Cloudflare는 다음과 같습니다 :

<Steps>
  1. 특정 오류의 계정 수준에서 구성 된 오류 페이지 검색.
  2. 특정 오류에 대한 영역 수준에서 구성 된 오류 페이지 검색 (그것은 계정 수준 오류 페이지에 우선 순위가있을 것입니다.).
  3. 계정 수준에서 일치하는 사용자 정의 오류 규칙 검색. 규칙은 계정 또는 영역 수준에서 500 및 1000 클래스 오류 Pages에 우선 순위가있을 것입니다.
  4. 영역 수준에서 일치하는 사용자 정의 오류 규칙 검색. 규칙은 계정 또는 영역 수준에서 500 및 1000 클래스 오류 Pages에 우선 순위가 있으며 계정 수준에서 사용자 정의 오류 규칙을 초과합니다.
  5. 보안 규칙이 있으면[WAF 사용자 정의 규칙](/waf/custom-rules/)또는[비율 제한 규칙](/waf/rate-limiting-rules/)기본 Cloudflare QXQXQXQXWAF 블록 페이지 대신 사용자 정의 블록 응답이 오류 Pages 또는 일치 사용자 정의 오류 규칙에 우선 순위를 부여합니다.
  6. 이전 구성의 경우, 사용자 정의 오류 콘텐츠를 방문자에게 제공합니다. 그렇지 않으면 특정 오류 유형의 기본 오류 페이지를 제공합니다.
</Steps>

:::참조
문제 페이지 또는 블록 페이지를 사용자 정의하려면 사용자 정의 오류 규칙이 Cloudflare 제품에서 시작된 보안 조치에 적용되지 않기 때문에 오류 페이지를 사용하십시오. 자주 묻는 질문[관례 WAF 응답](/waf/custom-rules/create-dashboard/#configure-a-custom-response-for-blocked-requests)오류 페이지 및 사용자 정의 오류 규칙에 대한 우선 순위가 걸립니다.

## 오류 Pages

Cloudflare는 광범위를 이용합니다[오류 코드](/support/troubleshooting/http-status-codes/)처리 요청 트래픽에서 문제를 식별합니다. 기본적으로이 오류 페이지는 Cloudflare를 언급합니다. 그러나 사용자의 일관된 브랜드 경험을 제공하기 위해 사용자 정의 오류 페이지를 만들 수 있습니다.

오류 Pages HTTP 상태 코드와 응답에 적용되지 않습니다`500`, `501`, `503`, 또는`505`. 이러한 예외는 특정 API 엔드포인트 및 기타 웹 애플리케이션과 문제를 방지합니다. 사용자 정의 오류 규칙을 사용하여 이러한 상태 코드에 대한 응답을 사용자 정의 할 수 있습니다.

CloudflareXQ 유료 플랜에 있다면, 영역 레벨 또는 전체 계정에 사용자 지정 오류 페이지를 만들 수 있습니다. Zone-level 오류 페이지는 계정 수준 오류 페이지에 우선 순위가 있습니다.

또한 엔터프라이즈 고객은 5XX 오류 페이지를 사용자 정의 할 수 있습니다 (오류 제외)`520`-`527`) 그들의 근원에서 돌기**근원 과실 Pages**내 계정**오류 Pages**대시보드에서.

보안 문제 또는 오류가 발생하면 사용자 정의 오류 페이지를 설계 할 수 있습니다. 다른 오류 페이지 유형에 대한 자세한 내용은 참조[오류 페이지 유형](/rules/custom-errors/reference/error-page-types/).

:::참조
Cloudflare는 사용자 정의 오류 Pages 대신 기본 QXQXQX0001XQ 오류 페이지를 반환합니다. 수신 요청이 포함되지 않는 경우`accept-encoding`헤더. Custom Error Rules에서 시작된 응답에 적용되지 않습니다.

## 사용자 정의 오류 규칙

사용자 정의 오류 규칙은 Cloudflare가 HTTP 오류 (status codes)의 경우 방문자에게 사용자 정의 오류 콘텐츠를 제공합니다`400`그리고 위에), 그리고 방문자에게 봉사될 정확한 내용.

컨텐츠를 정의할 때, 인라인 응답 또는 기존 웹 페이지의 URL을 제공합니다. URL은 웹 페이지 또는 JSON 콘텐츠와 같은 다른 리소스에 해당할 수 있습니다.

URL을 제공 할 때 Cloudflare는 필요한 이미지, CSS 및 JavaScriptQ 코드를 수집하고 Cloudflare 글로벌 네트워크에서 전체 페이지의 분화 된 버전을 저장합니다. 이 자료는 호출[주문 오류 자산](#custom-error-assets)자산 (zone 또는 계정)의 동일한 범위에서 하나 이상의 사용자 정의 오류 규칙을 사용할 수 있습니다.

사용자 정의 오류 규칙이 트리거되면 Cloudflare는 이전에 정의 된 응답과 (선택적으로) 응답 HTTP 상태 코드를 방문자로 대체합니다. Cloudflare는 어떤 기존 HTTP 응답 헤더든지를 제외하고 유지할 것입니다`Content-Type`·`Content-Length`.

또한 구성할 수 있습니다.[응답 헤더 Transform 규칙](/rules/transform/response-header-modification/)오류 응답에 대한 추가, 변경, 또는 응답에서 HTTP 헤더를 제거.

사용자 정의 오류 규칙은 우선 순위[오류 Pages](#error-pages).

## 사용자 정의 오류 자산

사용자 정의 오류 자산은 HTML 웹 페이지와 같은 웹 리소스에 해당합니다 (참고 자료d 이미지, CSS 및 JavaScript 코드 포함) Cloudflare fetches 및 오류 페이지로 방문자에게 제공 할 URL에 따라 저장.

사용자 정의 오류 자산이 Cloudflare의 글로벌 네트워크에 저장되면 처음에는 더 이상 사용할 필요가 없습니다. 기존 사용자 정의 오류 자산을 다시 fetching하여 업데이트 할 수 있습니다. 각 사용자 정의 오류 자산과 관련된 메타 데이터는 마지막 fetch가 발생했을 때 타임스탬프를 포함하고, 이 정보는 대시보드XQ에 표시됩니다.

하나 이상의 사용자 정의 오류 자산을 사용할 수 있습니다.[사용자 정의 오류 규칙](#custom-error-rules)자산 (zone 또는 계정)을 정의하는 동일한 범위에서.

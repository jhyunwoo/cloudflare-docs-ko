## 오류 페이지를 미리보기 할 수 없습니다

Cloudflare가 사이트에로드 할 수 없거나 미국 (미국)을 통해 차단했습니다.[IP 접근 규칙](/waf/tools/ip-access-rules/)또는[WAF 사용자 정의 규칙](/waf/custom-rules/), 게시 및 사용자 정의 오류 페이지를 미리보기 할 수 없습니다.

일반적인 오류는 다음과 같습니다 :`Error fetching page: Fetch failed, https://example.com/ipcountryblock.html returned 403 (Code: 1202)`.

WAF 규칙은 사용자 정의 오류 페이지의 내용을 fetching하거나 도전적인 사용자 정의 오류 제품이다는 것을 확인합니다.

## 차단된 요청을 위한 오류 페이지

국가 또는 IP 주소를 차단하면[IP 접근 규칙](/waf/tools/ip-access-rules/), 영향을받는 방문자가 얻을 것이다`1005`오류 및**IP/Country 구획**주문 페이지.

국가 또는 IP 주소를 차단하면[WAF 사용자 정의 규칙](/waf/custom-rules/)그리고 당신은 구성하지 않습니다[사용자 정의 오류 규칙](/rules/custom-errors/create-rules/#create-a-custom-error-rule-dashboard)또는[WAF 주문 응답](/waf/custom-rules/create-dashboard/#configure-a-custom-response-for-blocked-requests)차단된 요청을 위해, 영향을 받은 방문자가 얻을 것이다**WAF 구획**사이트 맵

요청을 차단하면[비율 제한 규칙](/waf/rate-limiting-rules/)그리고 당신은 구성하지 않습니다[사용자 정의 오류 규칙](/rules/custom-errors/create-rules/#create-a-custom-error-rule-dashboard)또는[WAF 주문 응답](/waf/rate-limiting-rules/create-zone-dashboard/#configure-a-custom-response-for-blocked-requests)차단된 요청을 위해, 영향을 받은 방문자가 얻을 것이다**429 오류**Cloudflare`1015`오류.

방화벽 규칙을 가진 국가 또는 IP 주소를 차단하는 경우 (지금 탈선), 영향을받는 방문자가 얻을 것이다**1000 클래스 오류**사이트 맵

## 1XXX 오류

오류 PagesXQ를 통해 다음 1XXX 오류를 사용자 정의 할 수 없습니다 :

- `1001`- 해결 가능
- `1003`- 나쁜 호스트 헤더
- `1018`- 소유권 조회 실패 때문에 해결 가능
- `1023`- 기능상실 실패 때문에 해결 가능

## 주문 오류 페이지 크기

사용자 정의 오류 페이지는 공백이 없으며 모든 페이지 자산의 결합 된 크기는 1.5 MB (1,500,000 문자)를 초과 할 수 없습니다. 사용자 정의 오류 페이지 제한을 초과하지 않도록, 게시하기 전에 자신의 크기를 확인하기 위해 페이지를 미리보기.

## 자주 묻는 질문

사용자 정의 오류 페이지를 미리 시도하거나 게시하는 동안 오류를 발생하면 사용[HTML 검증기](https://validator.w3.org/)코드를 제대로 해결하도록하십시오.

다음 섹션은 영역 수준에서 사용자 정의 오류 자산 및 오류 Pages를 관리하기위한 일반적인 API 호출의 예를 제공합니다.

계정 수준에서 동일한 작업을 수행하려면 해당 계정 레벨 API 엔드포인트를 사용하십시오.

### 사용자 정의 오류 자산 만들기

다음 것`POST`요청은 제공된 URL을 기반으로 한 영역에 새로운 사용자 정의 오류 자산을 생성합니다.

```bash
curl "https://api.cloudflare.com/client/v4/zones/$ZONE_ID/custom_pages/assets" \
--header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
--json '{
  "name": "500_error_template",
  "description": "Standard 5xx error template page",
  "url": "https://example.com/errors/500_template.html"
}'
```

```json output
{
	"result": {
		"name": "500_error_template",
		"description": "Standard 5xx error template page",
		"url": "https://example.com/errors/500_template.html",
		"last_updated": "2025-02-10T11:36:07.810215Z",
		"size_bytes": 2048
	},
	"success": true
}
```

계정 수준에서 자산을 만들려면 계정 수준 엔드포인트를 사용하십시오.

```txt
https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/custom_pages/assets
```

### 주문 오류 자산 목록

다음 것`GET`요청은 영역에서 구성된 사용자 정의 오류 자산 목록을 검색합니다.

```bash
curl "https://api.cloudflare.com/client/v4/zones/$ZONE_ID/custom_pages/assets" \
--header "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

```json output
{
	"result": [
		{
			"name": "500_error_template",
			"description": "Standard 5xx error template page",
			"url": "https://example.com/errors/500_template.html",
			"last_updated": "2025-02-10T11:36:07.810215Z",
			"size_bytes": 2048
		}
		// ...
	],
	"success": true,
	"errors": [],
	"messages": [],
	"result_info": {
		"count": 2,
		"page": 1,
		"per_page": 20,
		"total_count": 2,
		"total_pages": 1
	}
}
```

계정 수준에서 자산 목록을 검색하려면 계정 레벨 엔드포인트를 사용하십시오.

```txt
https://api.cloudflare.com/client/v4/accounts/$ZONE_ID/custom_pages/assets
```

### 사용자 정의 오류 자산 업데이트

다음 것`PUT`요청은 지정된 영역 수준에서 기존 사용자 정의 오류 자산의 URL을 업데이트`500_error_template`:

```bash
curl --request PUT \
"https://api.cloudflare.com/client/v4/zones/$ZONE_ID/custom_pages/assets/500_error_template" \
--header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
--json '{
  "description": "Standard 5xx error template page",
  "url": "https://example.com/errors/500_new_template.html"
}'
```

```json output
{
	"result": {
		"name": "500_error_template",
		"description": "Standard 5xx error template page",
		"url": "https://example.com/errors/500_new_template.html",
		"last_updated": "2025-02-10T13:13:07.810215Z",
		"size_bytes": 3145
	},
	"success": true
}
```

자산 설명과 URL을 업데이트할 수 있습니다. 생성 후 자산 이름을 업데이트할 수 없습니다.

자산을 업데이트 할 때 동일한 URL을 제공하면 Cloudflare는 URL을 다시 가져올 것입니다.

계정 수준에서 자산을 업데이트하려면 계정 수준의 엔드포인트를 사용하십시오.

```txt
https://api.cloudflare.com/client/v4/accounts/{account_id}/custom_pages/assets/{asset_name}
```

### 사용자 정의 오류 자산 받기

다음 것`GET`요청은 영역 수준에서 기존 사용자 정의 오류 자산의 세부 사항을 검색합니다.`500_error_template`:

```bash
curl "https://api.cloudflare.com/client/v4/zones/$ZONE_ID/custom_pages/assets/500_error_template" \
--header "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

```json output
{
	"result": {
		"name": "500_error_template",
		"description": "Standard 5xx error template page",
		"url": "https://example.com/errors/500_new_template.html",
		"last_updated": "2025-02-10T13:13:07.810215Z",
		"size_bytes": 3145
	},
	"success": true
}
```

계정 수준에서 자산을 검색하려면 계정 수준의 엔드포인트를 사용하십시오.

```txt
https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/custom_pages/assets/$ASSET_NAME
```

### 사용자 정의 오류 자산 삭제

다음 것`DELETE`요청은 영역 수준에서 기존 사용자 정의 오류 자산을 삭제합니다.`500_error_template`:

```bash
curl --request DELETE \
"https://api.cloudflare.com/client/v4/zones/$ZONE_ID/custom_pages/assets/500_error_template" \
--header "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

요청이 성공하면 응답은`204`HTTP 상태 코드.

계정 수준에서 자산을 삭제하려면 계정 수준의 엔드포인트를 사용하십시오.

```txt
https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/custom_pages/assets/$ASSET_NAME
```

### 오류 페이지

이 예제는 현재 구성을 얻습니다.`Rate limiting block`오류 페이지 (ID 포함)`ratelimit_block`).

<APIRequest
  path="/zones/{zone_identifier}/custom_pages/{identifier}"
  method="GET"
  parameters={{
  	identifier: "ratelimit_block",
  }}
/>

```json output
{
	"result": {
		"id": "ratelimit_block",
		"description": "Rate limit Block",
		"required_tokens": [],
		"preview_target": "block:rate-limit",
		"created_on": "2025-06-03T08:33:17.091587Z",
		"modified_on": "2025-06-03T08:33:17.091587Z",
		"url": null,
		"state": "default"
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

응답은 현재 Cloudflare 기본 페이지로 설정된 것을 나타냅니다 (`"state": "default"`).

오류 페이지 식별자의 목록을 위해, 참조[오류 페이지 유형](/rules/custom-errors/reference/error-page-types/).

### 업데이트 오류 페이지

이 예제는 사용자 정의 오류 페이지를 정의`Rate limiting block`오류 (ID 포함)`ratelimit_block`) 제공된 URL을 기반으로 합니다.

<APIRequest
  path="/zones/{zone_identifier}/custom_pages/{identifier}"
  method="PUT"
  parameters={{
  	identifier: "ratelimit_block",
  }}
  json={{
  	state: "customized",
  	url: "https://example.com/rate_limiting_block_error_page.html",
  }}
/>

```json output
{
	"result": {
		"id": "ratelimit_block",
		"description": "Rate limit Block",
		"required_tokens": [],
		"preview_target": "block:rate-limit",
		"created_on": "2025-06-03T08:33:17.091587Z",
		"modified_on": "2025-06-03T08:35:32.639114Z",
		"url": "https://example.com/rate_limiting_block_error_page.html",
		"state": "customized"
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

오류 페이지를 다시 기본 페이지로 설정하려면 사용`"state": "default"`요청 몸에서.

오류 페이지 식별자의 목록을 위해, 참조[오류 페이지 유형](/rules/custom-errors/reference/error-page-types/).

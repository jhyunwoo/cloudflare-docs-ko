## 주문 오류 규칙

[주문 오류 규칙](/rules/custom-errors/#custom-error-rules)사용자 정의 오류가 트리거되고 방문자에게 제공되는 내용이 정의됩니다. 규칙 모수는 다음과 같습니다:

### 응답 유형

API 이름:*사이트맵*(통행)[`asset_name`](#asset)·[`content_type`](#response)모수)

웹 사이트 방문자 (JSON, HTML, Text, 또는 XML)로 보내는 인라인 응답의 내용 유형, 또는**주문 오류 자산**사용자 정의 오류 자산의 내용을 보내면.

API를 사용할 때 설정해야 합니다.`asset_name`또는 둘 다 설정`content_type`·`content`모수. 더 알아보기[JSON 응답 / HTML 응답 / 텍스트 응답 / XML 응답](#response).

### 응답 코드

API 이름:**`status_code`** <Type text="Integer" /> <MetaInfo text="Optional" />

응답의 HTTP 상태 코드. 제공된 경우, 이 값은 현재 응답 상태 코드를 무시합니다.

상태 부호는 사이에서 있어야 합니다`400`·`999`.

### 투자정보

API 이름:**`asset_name`** <Type text="String" /> <MetaInfo text="Optional" />

이름의[주문 오류 자산](#custom-error-assets)이전에 업로드 (대시보드XQ에서 규칙을 만들 때 자산을 만들 수 있습니다). 자산은 포함될 수 있습니다[오류 토큰](/rules/custom-errors/reference/error-tokens/)방문자에 오류 응답을 보내기 전에 실제 값으로 교체됩니다.

사용자 정의 오류 규칙은 참고 자료 규칙과 동일한 범위에서 정의 된 자산 (즉, 같은 영역 또는 계정).

대시보드에서, 이 모수는 당신이 선택할 때만 유효합니다`Custom error asset`내 계정**응답 유형**.

API를 사용할 때, 하나를 제공해야합니다`asset_name`또는`content`모수.

### JSON 응답 / HTML 응답 / 텍스트 응답 / XML 응답{/* response */}

API 이름:**`content`** <Type text="String" /> <MetaInfo text="Optional" />·**`content_type`** <Type text="String" /> <MetaInfo text="Required" />

반환에 응답 몸. 그것은 포함할 수 있습니다[오류 토큰](/rules/custom-errors/reference/error-tokens/)방문자에 오류 응답을 보내기 전에 실제 값으로 교체됩니다.

당신은 하나를 제공해야합니다`asset_name`또는`content`모수.

최대 콘텐츠 크기는 10 KB입니다.

API를 사용할 때 설정해야 합니다.`content_type`반환 응답의 내용 유형을 정의하는 매개 변수. 값은 다음과 같습니다.

- `text/html`
- `text/plain`
- `application/json`
- `text/xml`

:::카트로션

HTML 오류 응답을 만들면 확인`referrer`메타 태그는 HTML 코드에서 존재 하지 않기 때문에 그것은 혼란[Cloudflare 도전 과제](/cloudflare-challenges/):

```html
<meta name="referrer" (...) />
```

:::

## 주문 오류 자산

·[주문 오류 자산](/rules/custom-errors/#custom-error-assets)HTML 웹 페이지 (참고 자료D 이미지, CSS 및 JavaScriptXQ 코드 포함)와 같은 웹 리소스에 해당 QXQX0002XQ fetches를 포함 하 고 당신이 제공 하는 URL에 따라 저장, 오류 페이지로 방문자에 제공.

사용자 정의 오류 자산은 다음과 같은 매개 변수가 있습니다.

### 자산 이름

API 이름:**`name`** <Type text="String" /> <MetaInfo text="Required" />

사용자 정의 오류 자산의 이름. 예제 값:`"500_error_template"`.

자산 이름은 다음과 같은 문자를 포함 할 수 있습니다.

- Uppercase 및 더 낮은 케이스 문자 (`A-Z`·`a-z`)
- 번호 (`0-9`)
- underscore (한국어)`_`) 문자

최대 길이는 200자입니다.

### 이름 \*

API 이름:**`description`** <Type text="String" /> <MetaInfo text="Optional" />

사용자 정의 오류 자산을 설명하는 문자열. 예제 값:`"Standard 5xx error template page"`.

### 자산 주소

API 이름:**`url`** <Type text="String" /> <MetaInfo text="Required" />

CloudflareXQ를 원하는 페이지의 URL을 fetch 및 store로 전달하여 설정된 오류 페이지로 나중에 방문자에게 제공[사용자 정의 오류 규칙](#custom-error-rules). 예 값:`"https://example.com/errors/500.html"`.

자산을 생성하거나 업데이트하면 URL을 제공 할 때 Cloudflare는 페이지에 사용되는 모든 이미지, CSS 및 JavaScriptXQ 코드를 수집하고 내용을 축소하고 내부로 저장합니다.

지정된 URL의 페이지의 내용이 포함될 수 있습니다.[오류 토큰](/rules/custom-errors/reference/error-tokens/)방문자에 오류 응답을 보내기 전에 실제 값으로 교체됩니다.

대시보드XQ를 사용할 때 나중에 리소스와 함께 페이지의 최신 버전을 얻을 다른 fetch를 트리거하고 내부적으로 저장 할 수 있습니다.

API를 사용할 때 자산을 업데이트하고 동일한 URL을 제공하면 Cloudflare는 URL을 다시 가져올 것이며, 리소스와 함께 저장합니다.

최대 자산 크기는 1.5 MB입니다.

| 페이지 유형                         | 이름 \*                                                                                                                                                                                   | API 식별자             |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| WAF 구획                         | 방문자가 차단 될 때 표시된 페이지[웹 애플리케이션 방화벽](/waf/)이름 \* 이 페이지는 반환`403`상태 코드.                                                                                                                      | `waf_block`         |
| IP/Country 구획                  | 요청이 시작될 때 표시된 페이지[차단된 IP 주소 또는 국가](/waf/tools/ip-access-rules/). 이 페이지는 반환`403`상태 코드.                                                                                                   | `ip_block`          |
| IP/Country 도전                  | 지정된 IP 주소 또는 국가에서 방문자에 대한 도전을 제시합니다. 이 페이지는 반환`403`상태 코드. 더 많은 정보를 원하시면, 참조[IP 접근 규칙](/waf/tools/ip-access-rules/).                                                                     | `country_challenge` |
| 500 클래스 오류                     | 웹 서버가 요청을 처리 할 수없는 경우 500 클래스 오류 페이지가 표시됩니다. 더 많은 정보를 원하시면, 참조[Cloudflare 5xx 오류](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/).                                   | `500_errors`        |
| 1000 클래스 오류                    | 1000 클래스 오류 페이지는 도메인의 구성, 보안 설정 또는 기원 설정이 요청을 완료하여 Cloudflare를 방지 할 때 표시됩니다. 더 많은 정보를 원하시면, 참조[Cloudflare 1xxx 오류](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/). | `1000_errors`       |
| 관리된 도전 / I'm Under Attack Mode | 그들의 요청과 보안 설정의 본질에 따라 방문자에 대한 다른 유형의 도전을 제시합니다. 이 페이지는 반환`403`상태 코드. 더 많은 정보를 원하시면, 참조[공격 모드](/fundamentals/reference/under-attack-mode/).                                              | `managed_challenge` |
| 비율 제한 구획                       | 그들이 막을 때 방문자에 표시[비율 제한 규칙](/waf/rate-limiting-rules/). 이 페이지는 반환`429`상태 코드.                                                                                                             | `ratelimit_block`   |

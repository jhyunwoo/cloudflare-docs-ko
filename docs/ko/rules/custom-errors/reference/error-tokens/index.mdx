## 오류 Pages

각 사용자 정의 오류 토큰은 오류 페이지에 나타나는 진단 정보 또는 특정 기능을 제공합니다. 특정 오류 페이지는 페이지 별 사용자 정의 오류 토큰이 필요합니다.

각 오류에 대한 사용자 정의 페이지를 표시하려면 오류 당 별도의 페이지를 만듭니다. 예를 들어, 모두 오류 페이지를 만들려면**IP/Country 구획**·**대화 도전**, 당신은 디자인하고 두 개의 별도 페이지를 게시해야합니다.

다음 사용자 정의 오류 토큰은 해당 오류 페이지에 의해 요구됩니다.

| 토큰 토큰                            | 견적 요청                                                                          |
| -------------------------------- | ------------------------------------------------------------------------------ |
| `::CAPTCHA_BOX::`                | 대화 도전<br />국가 도전 (Managed Challenge)<br />매니지드 챌린지 / 공격 모드 (Interstitial Page) |
| `::IM_UNDER_ATTACK_BOX::`        | 비동기 도전                                                                         |
| `::CLOUDFLARE_ERROR_500S_BOX::`  | 5XX 오류                                                                         |
| `::CLOUDFLARE_ERROR_1000S_BOX::` | 1XXX 오류                                                                        |

각 사용자 정의 오류 토큰은 기본 보기와 느낌이 있습니다. 그러나 각 태그의 클래스 ID를 사용하여 각 사용자 정의 오류 태그를 stylize CSS를 사용할 수 있습니다. 이미지, CSS 및 스크립트와 같은 모든 외부 리소스는 프로세스 중에 줄어들 것입니다. 이러한 모든 외부 자원은 사용할 수 있어야합니다 (그, 그들은 반환해야합니다)`200 OK`) 그렇지 않으면 오류가 발생한다.

## 사용자 정의 오류 자산, 인라인 응답 및 오류 Pages

사용자 정의 오류 자산, 인라인 응답, 또는 오류 페이지는 방문자에 대한 응답을 보내기 전에 실제 값으로 대체 될 다음과 같은 오류 토큰을 포함 할 수 있습니다 :

| 토큰 토큰           | 이름 \*                                   |
| --------------- | --------------------------------------- |
| `::CLIENT_IP::` | IP 주소                                   |
| `::RAY_ID::`    | CloudflareXQ를 통해서 가는 각 요구에 주어진 유일한 식별자. |
| `::GEO::`       | 방문자의 IP 주소와 관련된 국가 또는 지역.               |

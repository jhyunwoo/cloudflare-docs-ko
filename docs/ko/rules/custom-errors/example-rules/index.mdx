지정된 예는 규칙 표현의 다음 필드를 사용합니다.

- [`http.response.code`](/ruleset-engine/rules-language/fields/reference/http.response.code/)(Response Status Code): Cloudflare 제품에 의해 설정된 클라이언트에 반환된 HTTP 상태 코드를 나타냅니다 또는 원래 서버로 반환. 이 필드를 사용하여 오류 코드에 대한 응답을 사용자 정의하는 소스 서버 또는 Cloudflare 제품 같은 노동자.

- [`cf.response.1xxx_code`](/ruleset-engine/rules-language/fields/reference/cf.response.1xxx_code/): Cloudflare-generated 오류에 대한 특정 오류 코드를 포함합니다. 이 분야는 CloudflareXQ-generated 과실 뿐 아니라 일할 것입니다[크기: 52X](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/)·[뚱 베어](/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/).

### 모든 5XX 오류에 대한 사용자 정의 JSON 응답

이 예제는 모든 5XX 오류에 대한 사용자 정의 JSON 오류 응답을 구성합니다 (`500`-`599`) 영역에서. 사용자 지정 오류 응답의 HTTP 상태 코드 설정`530`.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    **사용자 정의 오류 규칙 구성:**

    - **이름 \***: `Custom JSON response for all 5XX errors`

    - **자주 묻는 질문** > **사용자 정의 필터 표현**:

      | 제품정보     | 회사연혁           | 제품정보  | 로그인   |
      | -------- | -------------- | ----- | ----- |
      | 응답 상태 부호 | 더 중대한 또는 동등한 것 | `500` | 이름 \* |
      | 응답 상태 부호 | 더 적은 또는 동등한 것  | `599` |       |

      Expression Editor를 사용하는 경우:<br />
      `(http.response.code ge 500 and http.response.code le 599)`

    - **응답 유형**: *JSON 응답*

    - **응답 코드**: `530`

    - **JSON 응답**: `{"message": "A server error occurred."}`
  </TabItem>

  <TabItem label="사이트맵">
    <APIRequest
      path="/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint"
      method="PUT"
      parameters={{
  	ruleset_phase: "http_custom_errors",
  }}
      json={{
  	rules: [
  		{
  			ref: "json_response_for_5xx_errors",
  			action: "serve_error",
  			action_parameters: {
  				content: '{"message": "A server error occurred."}',
  				content_type: "application/json",
  				status_code: 530,
  			},
  			expression: "http.response.code ge 500 and http.response.code lt 600",
  			enabled: true,
  		},
  	],
  }}
    />

    <Render file="terraform-use-ref-field" product="rules" params={{ addDocsLocation: true }} />

    이름 \*`PUT`요청, 대응[지역 항목 포인트 규칙 업데이트](/api/resources/rulesets/subresources/phases/methods/update/)작업, 어떤 기존 규칙을 대체`http_custom_errors`단계 항목 포인트 규칙.
  </TabItem>
</Tabs>

### 사용자 지정 HTML 응답 업데이트 상태 코드

이 예제는 응답에 대한 사용자 정의 HTML 오류 응답을 구성`500`HTTP 상태 코드 및 redefines 응답 상태 코드`503`.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    **사용자 정의 오류 규칙 구성:**

    - **이름 \***: `Custom HTML response for 500 errors`

    - **자주 묻는 질문** > **사용자 정의 필터 표현**:

      | 제품정보     | 회사연혁  | 제품정보  |
      | -------- | ----- | ----- |
      | 응답 상태 부호 | 이름 \* | `500` |

      Expression Editor를 사용하는 경우:<br />
      `(http.response.code eq 500)`

    - **응답 유형**: *HTML 응답*

    - **응답 코드**: `503`

    - **HTML 응답**:

      ```txt
      <!DOCTYPE html><html><head><meta charset="utf-8"><title>Application unavailable</title></head><body><h1>Application temporarily unavailable</h1><p>Please try again later.</p></body></html>
      ```
  </TabItem>

  <TabItem label="사이트맵">
    <APIRequest
      path="/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint"
      method="PUT"
      parameters={{
  	ruleset_phase: "http_custom_errors",
  }}
      json={{
  	rules: [
  		{
  			ref: "html_response_500_to_503",
  			action: "serve_error",
  			action_parameters: {
  				content:
  					'<!DOCTYPE html><html><head><meta charset="utf-8"><title>Application unavailable</title></head><body><h1>Application temporarily unavailable</h1><p>Please try again later.</p></body></html>',
  				content_type: "text/html",
  				status_code: 503,
  			},
  			expression: "http.response.code eq 500",
  			enabled: true,
  		},
  	],
  }}
    />

    <Render file="terraform-use-ref-field" product="rules" params={{ addDocsLocation: true }} />

    이름 \*`PUT`요청, 대응[지역 항목 포인트 규칙 업데이트](/api/resources/rulesets/subresources/phases/methods/update/)작업, 어떤 기존 규칙을 대체`http_custom_errors`단계 항목 포인트 규칙.
  </TabItem>
</Tabs>

### URL에서 생성 된 사용자 정의 오류 자산

이 예제는 이전에 만든 사용자 정의 오류 자산을 반환하는 사용자 정의 오류 규칙을 구성`500_error_template`응답을 위해`500`HTTP 상태 코드.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    **사용자 정의 오류 규칙 구성:**

    - **이름 \***: `Serve asset for HTTP 500 errors`

    - **자주 묻는 질문** > **사용자 정의 필터 표현**:

      | 제품정보     | 회사연혁  | 제품정보  |
      | -------- | ----- | ----- |
      | 응답 상태 부호 | 이름 \* | `500` |

      Expression Editor를 사용하는 경우:<br />
      `(http.response.code eq 500)`

    - **응답 유형**: *주문 오류 자산*

    - **투자정보**: `500_error_template`
  </TabItem>

  <TabItem label="사이트맵">
    <APIRequest
      path="/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint"
      method="PUT"
      parameters={{
  	ruleset_phase: "http_custom_errors",

  				content_type: "text/html",
  			},
  			expression: "http.response.code eq 500",

  		},
  	],

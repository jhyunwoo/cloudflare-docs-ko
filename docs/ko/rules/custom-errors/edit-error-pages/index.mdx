## 1. 사용자 정의 오류 페이지 디자인

CloudflareQ 계정에서 사용자 정의 오류 페이지를 정의하기 전에 페이지의 디자인 및 코드가 필요합니다. 그것은 당신의 자신의 웹 서버에 호스팅되거나 Cloudflare 제품을 사용하여[뚱 베어](/rules/snippets/).

사용자 정의 오류 페이지를 지정할 때, 페이지 별을 포함할 수 있습니다.[주문 오류 토큰](/rules/custom-errors/reference/error-tokens/). 각 주문 오류 토큰은 오류 페이지에서 나타나는 진단 정보를 제공합니다.

각 오류에 대한 사용자 정의 페이지를 표시하려면 오류 당 별도의 페이지를 만듭니다. 예를 들어, 둘 다 사용자 정의 오류 페이지를 만들려면**IP/Country 구획**·**WAF 구획**, 당신은 디자인하고 두 개의 별도 페이지를 게시해야합니다.

:::주\[주]

- 사용자 정의 오류 페이지는 적용 가능한 경우 페이지 별 사용자 정의 오류 토큰을 포함해야하며 1.5 MB (1,500,000 바이트)를 초과 할 수 없습니다. 또한 HTML을 포함해야합니다.`<head>`·`</head>`태그.
- 확인하기`referrer`메타 태그는 사용자 정의 오류 페이지의 HTML 코드에 존재하지 않습니다.[Cloudflare 도전 과제](/cloudflare-challenges/): `<meta name="referrer" (...) />`

:::

오류 페이지를 구축하려면 다음 템플릿을 사용할 수 있습니다.

```html
<html>
	<head></head>
	<body>
		::[REPLACE WITH CUSTOM ERROR TOKEN NAME]::
	</body>
</html>
```

<Details header="5XX 오류에 대한 오류 페이지">
  다음 HTML 코드는 스타일링없이 5XX 오류의 예 오류 페이지입니다.

  ```html
  <!doctype html>
  <html>
  	<head>
  		<meta charset="utf-8" />
  		<title>5XX Level Errors page</title>
  	</head>
  	<body>
  		<h1>5XX Level Errors</h1>
  		<h2>::CLOUDFLARE_ERROR_500S_BOX::</h2>
  	</body>
  </html>
  ```
</Details>

## 2. 대시보드XQ에서 오류 페이지를 업데이트

영역 수준 또는 전체 계정에 오류 페이지를 정의 할 수 있습니다. Zone-level 오류 페이지는 계정 수준 오류 페이지에 우선 순위가 있습니다.

<Tabs>
  <TabItem label="지역 수준">
    Zone-level 사용자 정의 오류 페이지를 편집하려면:

    <Steps>
      1. Cloudflare 대시보드에서, 가십시오**오류 Pages**사이트 맵

         <DashButton url="/?to=/:account/:zone/error-pages" />

      2. 원하는 사용자 정의 오류 페이지 유형을 식별합니다.

      3. (선택 사항) 현재 오류 페이지를 미리보기하려면 (기본 또는 사용자 정의), 링크 선택**이름 \***&#xC5F4;.

      4. 오류 페이지를 편집하려면 세 가지 점을 선택하십시오 >**제품정보**이전 확인된 페이지 유형 옆에.

      5. Cloudflare의 기본 페이지를 사용하려면, 선택**Cloudflare 기본 페이지.**&#xC0AC;용자 정의 오류 페이지를 제공하기 위해, 선택**주문 페이지**사용자 정의 오류 페이지의 URL을 입력합니다.

      6. 제품정보**이름 \***.
    </Steps>
  </TabItem>

  <TabItem label="계정 수준">
    계정 수준 사용자 정의 오류 페이지를 업데이트하려면:

    <Steps>
      1. Cloudflare 대시보드에서, 가십시오**계정 설정**사이트 맵

         <DashButton url="/?to=/:account/configurations" />

      2. 오시는 길**오류 Pages**원하는 사용자 정의 오류 페이지 유형을 식별합니다.

      3. (선택 사항) 현재 오류 페이지를 미리보기하려면 (기본 또는 사용자 정의), 링크 선택**이름 \***&#xC5F4;.

      4. 오류 페이지를 편집하려면 세 가지 점을 선택하십시오 >**제품정보**이전 확인된 페이지 유형 옆에.

      5. Cloudflare의 기본 페이지를 사용하려면, 선택**Cloudflare 기본 페이지.**&#xC0AC;용자 정의 오류 페이지를 제공하기 위해, 선택**주문 페이지**사용자 정의 오류 페이지의 URL을 입력합니다.

## Fetch 사용자 정의 오류 페이지 다시

성공적으로 사용자 정의 오류 페이지의 내용을 설정 한 후**오류 Pages**, 당신은 당신의 근원 서버에서 페이지를 제거할 수 있습니다.

미래에, 당신은 당신의 사용자 정의 오류 페이지를 업데이트해야합니다, 당신은 다시 페이지를 fetch해야합니다, 페이지 URL이 변경되지 않은 경우에도. 이 경우, 업데이트하려는 페이지 유형 옆에, 세 가지 점을 선택하십시오 >**Fetch 사용자 정의 페이지 다시**.

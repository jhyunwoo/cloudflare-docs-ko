## 자동 규칙 우회

Trace는 조작상의 이유로 자동으로 우회되는 규칙을 표시하지 않습니다.

예를 들어 SSL/TLS 인증서가 있을 때`pending_validation`상태, 보안 규칙은 도메인 제어 검증 (DCV) 경로에 자동으로 비활성화됩니다.`/.well-known/pki-validation/`·`/.well-known/acme-challenge/`. 이 우회는 추적 결과에서 나타나지 않을 것입니다.

더 많은 정보를 원하시면, 참조[왜 몇 가지 규칙을 우회합니까?](/waf/troubleshooting/faq/#why-are-some-rules-bypassed-when-i-did-not-create-an-exception)WAF 문서에서.

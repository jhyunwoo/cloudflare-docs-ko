Cloudflare 추적<ProductAvailabilityText product="trace-request" />Cloudflare의 역 프록시를 통해 HTTP / S 요청을 따르십시오. 이 도구를 사용하여 다른 CloudflareXQ 구성이 호스트 이름의 HTTP / S 요청과 상호 작용하는 방법을 이해하십시오. 테스트가 아닌 호스트명이라면[CloudflareXQ](/dns/proxy-status/)모델 번호: Cloudflare Trace는 여전히 Cloudflare가 요청에 적용됩니다 모든 구성을 반환합니다.

HTTP/S 요청을 위한 다른 조건을 시뮬레이션할 수 있는 특정 요청 속성을 정의할 수 있습니다. CloudflareXQ 제품에 구성 된 비활성 규칙은 평가되지 않습니다.

모델 번호: Cloudflare Trace는 Administrator 또는 Super Administrator 역할을 하는 사용자에게 제공됩니다.

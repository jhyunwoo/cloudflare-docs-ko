## 대시보드XQ에서 추적 사용

### 1. 1개 이상의 Cloudflare 제품 구성

<Steps>
  1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com), 귀하의 계정을 선택합니다.
  2. 설정 설정 설정에서 계정 수준, 또는 도메인을 선택하고 설정 하나 이상의 Cloudflare 제품.
</Steps>

### 2. 추적

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**제품 정보**사이트 맵

     <DashButton url="/?to=/:account/trace" />

  2. 추적 URL을 입력합니다. URL은 계정에 속한 호스트명을 포함해야 합니다.

  3. HTTP 메소드를 선택합니다. 자주 묻는 질문*사이트맵*, *펌프 펌프*, 또는*공지사항*, 당신은 값에 입력해야합니다**본문 바로가기**.

  4. (선택 사항) 특정 HTTP / S 요청의 상태를 시뮬레이션 할 수있는 사용자 정의 요청 속성을 정의합니다. 당신은 뒤에 오는 요구 재산을 주문을 받아서 만들 수 있습니다:
     - **프로젝트**(HTTP 프로토콜 버전)
     - **사용자 에이전트 및 요청 헤더**
     - **제품 정보**
     - **관련 기사**(request 소스[이름 \*](/ruleset-engine/rules-language/fields/reference/ip.src.country/), [이름 \*](/ruleset-engine/rules-language/fields/reference/ip.src.region/)·[도시 :](/ruleset-engine/rules-language/fields/reference/ip.src.city/))
     - [**봇 점수**](/bots/concepts/bot-score/)
     - **본문 바로가기**(대략)`POST`, `PUT`·`PATCH`요청)
     - **공지사항**(CloudflareXQ-issued를 스키[- 연혁](/cloudflare-challenges/), 어떤 경우, 추적을 계속 허용)

  5. 제품정보**Trace 소개**.
</Steps>

### 3. 결과 분류

더 보기**결과 추적**페이지는 평가 순서에서 다른 Cloudflare 제품에서 모든 평가하고 실행한 윤곽을 보여줍니다. 모든 비활성 규칙은 평가되지 않습니다.

<Steps>
  1. 항문 다른[계정 만들기](#steps-in-trace-results)현재 추적에 대한 평가 및 실행 구성. Trace 결과는 계정 수준 또는 특정 도메인 또는 하위 도메인에 구성 여부를 모든 활성 규칙 및 구성에 대한 일치를 포함합니다.

     요청과 일치하지 않은 것들을 포함하여 모든 구성을 표시하려면, 선택*모든 구성*내 계정**결과 표시**드롭다운.

  2. (선택 사항) Cloudflare 구성 업데이트 (계정 또는 도메인/subdomain 수준에서) 변경의 영향을 확인하기 위해 새로운 추적을 만듭니다.
</Steps>

### 4. (선택) 추적 윤곽을 저장하십시오

같은 구성으로 나중에 추적을 실행하려면:

<Steps>
  1. 현재 추적 구성을 가진 대시보드에서 보이는 JSON을 복사합니다.
  2. 새로운 추적을 만들 때 JSON 상자에 붙여 새로운 추적의 모든 설정을 정의합니다.
</Steps>

## API를 통해 Trace 사용

사용 방법[Trace 소개](/api/resources/request_tracers/subresources/traces/methods/create/)Cloudflare API를 사용하여 추적을 수행 할 수 있습니다.

***

## 추적 결과의 단계

- Cloudflare 제품의 하나 이상의 규칙의 실행[Ruleset 엔진](/ruleset-engine/). 통치자 엔진의 참조[단계 목록](/ruleset-engine/reference/phases-list/)그런 제품의 목록을 위해.
- [페이지 규칙](/rules/page-rules/): 하나 이상의 규칙의 실행.
- [모델 번호: Workers](/workers/): 하나 이상의 스크립트의 실행.

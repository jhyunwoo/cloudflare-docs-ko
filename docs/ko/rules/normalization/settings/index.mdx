Cloudflare 대시보드는 URL 정상화 관리를 위한 뒤에 오는 조정을 제공합니다:

## 정상화 유형

기본 값:*RFC-3986를*

실행할 정상화의 유형을 선택합니다:

- *RFC-3986를*– URL 정상화에 따라 엄격하게 적용[RFC 3986년](https://datatracker.ietf.org/doc/html/rfc3986).
- *모델 번호: Cloudflare*– RFC 3986에서 정의된 것 외에도 적용[추가 URL 정상화 기술](/rules/normalization/how-it-works/#cloudflare-normalization).

## 수신 URL을 정상화

기본 값:*이름 \**

Cloudflare에 모든 들어오는 교통의 URL을 구성:

- 활성화되면 모든 수신 URL은 페이지 규칙, WAF 사용자 정의 규칙, QXQXQXQXQXQXQXQ 및 액세스와 같은 입력으로 URL을받을 수있는 후속 Cloudflare 기능에 전달하기 전에 정상화됩니다.
- 비활성화 할 때 수신 URL은 이후 Cloudflare 기능에 전달하기 전에 정상화되지 않습니다.

## 원래 URL을 정상화

기본 값:*이름 \**

URL 구성은 원산지로 전송:

- 활성화될 때, 근원에 보내지는 요구는 정상화됩니다.
- 비활성화되면, 기원에 보내진 요청은 수정되지 않습니다.

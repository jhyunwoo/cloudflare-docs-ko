Cloudflare는 수신 요청의 URL을 수정하는 URL 정상화 기능을 제공하여 일관된 포맷 표준을 준수합니다.

URL을 정상화할 때, 모든 들어오는 URL은 WAF 관례 규칙, Workers 및 접근과 같은 URL 입력을 받아들이는 그 후에 세계적인 네트워크 특징에 전달하기 전에 정상화됩니다. URL을 기반으로 한 트래픽을 필터링하는 규칙 표현은 URL의 형식에 관계없이 올바르게 트리거됩니다. URL 정상화가 비활성화되면 Cloudflare는 원래 형태로 URL을 전달합니다.

:::카트로션
트래픽이 CloudflareXQ를 통해 proxied 때, 필수 요청 URL 정상화는 특정 영역에 사용할 수 있는지 여부에 관계없이 항상 적용됩니다. 예를 들어, URL 정상화를 해제하여 요청 URL에 단일 슬래시로 두 개 이상의 인접한 슬래시로 변환 할 수 없습니다.
주요 특징

URL 정상화는 어떤 수행하지 않습니다<GlossaryTooltip term="redirect">관련 기사</GlossaryTooltip>, 따라서 방문자의 브라우저에 표시된 주소를 변경하지 않습니다. 정상적인 작업, 활성화 될 때, 글로벌 네트워크에 발생 하 고 Cloudflare 기능 나중에 실행 하 고 (선택) 원래 서버에서 수신된 URL.

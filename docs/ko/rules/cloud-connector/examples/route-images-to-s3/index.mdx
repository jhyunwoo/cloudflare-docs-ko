경로 요청`/images`AWS S3 물통에 도메인에:

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**클라우드 커넥터**사이트 맵

     <DashButton url="/?to=/:account/:zone/rules/cloud-connector" />

  2. 제품정보**아마존 S3**이름 \*[클라우드 공급자](/rules/cloud-connector/providers/).

  3. 버킷 URL을 입력하십시오. 두 가지 방법으로 URL을 구성할 수 있습니다.
     - **하위 도메인 스타일 URL**: 호스트명 설정`<BUCKET_NAME>.s3.amazonaws.com`. 이 경우, 파일이 버킷의 뿌리에서 구성되어야하며, URI 경로는 파일에 직접지도 할 것입니다. 예를 들어,`https://<YOUR_HOSTNAME>/images/file.jpg`본문 바로가기`https://<BUCKET_NAME>.s3.amazonaws.com/images/file.jpg`.
     - **URI 경로 스타일 URL**: 호스트명 설정`s3.amazonaws.com`. 여기, 당신의 물통은 지명된 폴더를 포함해야 합니다`images`, 파일은이 폴더 안쪽에 배치해야합니다. URI 경로는 버킷 이름을 포함, 같은`https://<YOUR_HOSTNAME>/<BUCKET_NAME>/images/file.jpg`지도하기`https://s3.amazonaws.com/<BUCKET_NAME>/images/file.jpg`.

  4. (선택) 사용[URL Rewrite 규칙](/rules/transform/url-rewrite/)URL 구조를 조정합니다. 예를 들면, 당신은 할 수 있습니다[URL을 다시 작성](/rules/transform/url-rewrite/create-dashboard/)그 변화`/images`으로`/<BUCKET_NAME>/images`URI 경로 스타일 URL 구조와 일치합니다.

  5. (선택) 사용[캐시 규칙](/cache/how-to/cache-rules/)물통에서 반환된 개체에 대한 캐싱 동작을 조정합니다. 예를 들면, 당신은 할 수 있습니다[캐시 규칙 만들기](/cache/how-to/cache-rules/create-dashboard/)그 캐시는 모든 반환 객체 일치`/images/*`7 일 동안 URI 경로:
     - **자주 묻는 질문**> 사용자 정의 필터 표현:`(starts_with(http.request.uri.path, "/images/"))`
     - **캐시 자격**: 캐시에 대한 Eligible
       - **가장자리 TTL**> 캐시 제어 헤더를 무시하고이 TTL을 사용합니다 :*7 일*

  6. 제품정보**이름 \***&#xBCF8;문내용 바로가기 주메뉴 바로가기`Route images to S3`내 계정**Cloud Connector 이름**.

  7. 이름 \***이름 \***, 선택**사용자 정의 필터 표현**그리고 다음과 같은 표현을 입력:<br />
     `http.request.full_uri wildcard "http*://<YOUR_HOSTNAME>/images/*"`<br />기타 제품`<YOUR_HOSTNAME>`원하는 호스트 이름.

  8. 제품정보**계정 만들기**규칙을 활성화합니다.
</Steps>

이 설정은 모든 트래픽 일치하는 경로`http*://<YOUR_HOSTNAME>/images/*`(HTTPS 및 HTTP 요청) 귀하의 S3 버킷에. 자주 묻는 질문`<YOUR_HOSTNAME>`실제 호스트 이름과 설정에 따라 예제 경로 조정.

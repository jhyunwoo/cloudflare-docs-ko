유럽 연합 (EU)의 방문자로부터 Google Cloud Storage Bucket에 대한 요청을 경로로:

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**클라우드 커넥터**사이트 맵

     <DashButton url="/?to=/:account/:zone/rules/cloud-connector" />

  2. 제품정보**Google 클라우드 스토리지**이름 \*[클라우드 공급자](/rules/cloud-connector/providers/).

  3. 버킷 URL을 입력하십시오. 두 가지 방법으로 URL을 구성할 수 있습니다.
     - **하위 도메인 스타일 URL**: 대`<BUCKET_NAME>.storage.googleapis.com`, 당신의 파일은 물통의 뿌리에서 조직되어야 합니다. 예를 들어,`https://<YOUR_HOSTNAME>/index.html`본문 바로가기`https://<BUCKET_NAME>.storage.googleapis.com/index.html`.
     - **URI 경로 스타일 URL**: 호스트명을 설정하면`storage.googleapis.com`, 당신의 물통은 예정된 URI 경로에 대응하는 폴더를 포함해야 합니다. 예를 들어, 원한다면`https://<YOUR_HOSTNAME>/eu/index.html`당신의 물통에 있는 파일에 지도에, 파일은 위에 두어야 합니다`https://storage.googleapis.com/<BUCKET_NAME>/eu/index.html`.

  4. (선택) 사용[URL Rewrite 규칙](/rules/transform/url-rewrite/)URL 구조를 조정합니다. 예를 들면, 당신은 할 수 있습니다[URL을 다시 작성](/rules/transform/url-rewrite/create-dashboard/)그 변화`/eu`으로`/<BUCKET_NAME>`URI 경로 스타일 URL 구조와 일치합니다.

  5. (선택) 사용[캐시 규칙](/cache/how-to/cache-rules/)물통에서 반환된 개체에 대한 캐싱 동작을 조정합니다. 예를 들면, 당신은 할 수 있습니다[캐시 규칙 만들기](/cache/how-to/cache-rules/create-dashboard/)그 캐시는 모든 반환 객체 일치`/eu`7 일 동안 URI 경로 (을 통해 정의 됨)**가장자리 TTL**설정).

  6. 제품정보**이름 \***&#xBCF8;문내용 바로가기 주메뉴 바로가기`Route EU visitors to GCP`내 계정**Cloud Connector 이름**.

  7. 이름 \***이름 \***, 선택**사용자 정의 필터 표현**그리고 다음과 같은 표현을 입력:
     `(ip.src.is_in_european_union)`<br />이 표현은 유럽 연합 사용자의 트래픽을 대상으로합니다.

  8. 제품정보**계정 만들기**규칙을 활성화합니다.
</Steps>

이 구성은 EU 방문자에서 Google Cloud Storage Bucket으로 트래픽을 경로를 경로를 경로를 지정합니다. 자주 묻는 질문`<YOUR_HOSTNAME>`실제 호스트 이름과 설정에 따라 예제 경로 조정.

Azure Blob Storage 컨테이너의 정적 자산을 제공하려면:

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**클라우드 커넥터**사이트 맵

     <DashButton url="/?to=/:account/:zone/rules/cloud-connector" />

  2. 제품정보**마이크로 소프트 Azure**이름 \*[클라우드 공급자](/rules/cloud-connector/providers/).

  3. 버킷 URL을 입력하십시오. 다음 URL 구조를 사용하십시오:
     - **하위 도메인 스타일 URL**: 호스트명 설정`<BUCKET_NAME>.blob.core.windows.net`. 이 경우에, 당신의 물통은 지명된 폴더를 포함해야 합니다`static-assets`, 파일은이 폴더 안쪽에 배치해야합니다. 예를 들어,`https://<YOUR_HOSTNAME>/static-assets/style.css`본문 바로가기`https://<BUCKET_NAME>.blob.core.windows.net/static-assets/style.css`.

  4. (선택) 사용[URL Rewrite 규칙](/rules/transform/url-rewrite/)URL 구조를 조정합니다. 예를 들면, 당신은 할 수 있습니다[URL을 다시 작성](/rules/transform/url-rewrite/create-dashboard/)그 변화`/static-assets`으로`/my-pages-project/static-assets`물체 저장 물통의 파일 구조를 일치하기 위하여.

  5. (선택) 사용[캐시 규칙](/cache/how-to/cache-rules/)물통에서 반환된 개체에 대한 캐싱 동작을 조정합니다. 예를 들면, 당신은 할 수 있습니다[캐시 규칙 만들기](/cache/how-to/cache-rules/create-dashboard/)그 캐시는 모든 반환 객체 일치`/static-assets`7 일 동안 URI 경로 (을 통해 정의 됨)**가장자리 TTL**설정).

  6. 이름 \***이름 \***&#xBCF8;문내용 바로가기 주메뉴 바로가기`Serve static assets from Azure`내 계정**Cloud Connector 이름**.

  7. 이름 \***이름 \***, 선택**사용자 정의 필터 표현**그리고 다음과 같은 표현을 입력:
     `http.request.full_uri wildcard "http*://<YOUR_HOSTNAME>/static-assets/*"`<br />

  8. 제품정보**계정 만들기**규칙을 활성화합니다.
</Steps>

이 설정은 모든 트래픽 매칭을 보장합니다.`http*://<YOUR_HOSTNAME>/static-assets/*`(HTTPS 및 HTTP 요청)은 Azure Blob Storage 컨테이너에서 제공됩니다. 자주 묻는 질문`<YOUR_HOSTNAME>`실제 호스트 이름과 설정에 따라 예제 경로 조정.

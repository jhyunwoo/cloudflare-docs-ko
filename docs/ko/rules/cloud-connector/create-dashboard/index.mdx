대시보드XQ에서 클라우드 커넥터 규칙을 구성하려면:

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**클라우드 커넥터**사이트 맵

     <DashButton url="/?to=/:account/:zone/rules/cloud-connector" />

  2. 자주 묻는 질문[클라우드 공급자](/rules/cloud-connector/providers/)(Cloudflare R2 또는 외부 공급자).

  3. 이전 단계에서 Cloudflare R2를 선택한 경우 물통과 사용자 정의 도메인을 선택하고 선택하십시오.**이름 \***.<br />다른 스토리지 공급자를 선택하면 버킷 URL을 입력하고 선택**이름 \***.

     :::카트로션
     버킷 URL을 따라야 합니다.[특정 형식](/rules/cloud-connector/providers/)당신의 공급자에 따라.
     주요 특징

  4. 규칙에 대한 설명 이름 입력**Cloud Connector 이름**.

  5. 이름 \***이름 \***, 선택**사용자 정의 필터 표현**·[본문 바로가기](/ruleset-engine/rules-language/expressions/edit-expressions/)물통에 리디렉션되는 트래픽을 정의합니다. 예를 들면:

     - 모든 요청 일치를 경로`http*://example.com/images/*`(HTTPS 및 HTTP 요청) 다음 표현을 입력 할 수 있습니다 :<br />
       `http.request.full_uri wildcard "http*://example.com/images/*"`
     - 모든 요청 일치를 경로`http*://images.example.com/*`(HTTPS 및 HTTP 요청) 다음 표현을 입력 할 수 있습니다 :<br />
       `http.request.full_uri wildcard "http*://images.example.com/*"`

     대안으로, 선택**모든 수신 요청**선택한 스토리지 버킷에 영역에 대한 모든 들어오는 트래픽을 리디렉션합니다.

  6. 규칙을 저장하고 배포하려면, 선택**계정 만들기**. 규칙을 배포 할 준비가 없다면, 선택**Draft로 저장**.

     <Render file="rules-creation-dash-dns-popup" product="rules" />
</Steps>

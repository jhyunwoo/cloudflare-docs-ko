## 페이지 규칙 만들기

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    대시보드XQ의 페이지 규칙을 만들려면:

    <Steps>
      1. Cloudflare 대시보드에서, 가십시오**페이지 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/rules/page-rules" />

      2. 제품정보**페이지 규칙**.

      3. 제품 정보**사이트 맵**, 규칙과 일치해야 URL 또는 URL 패턴을 입력 ([wildcard matching에 대한 자세한 내용](/rules/page-rules/reference/wildcard-matching/)).

      4. 제품 정보**설정 선택**, 선택[Cloudflare 설정](/rules/page-rules/reference/settings/)조정. 원하는 경우, 선택**설정 추가**동일한 규칙을 가진 다수 Cloudflare 조정을 조정하기 위하여.

      5. 내 계정**이름 \***&#x64;ropdown, 원하는 순서를 지정:*첫 번째, 마지막*또는*제품 정보*.

      6. 규칙을 저장하고 배포하려면, 선택**저장 및 배포 페이지 규칙**. 규칙을 배포 할 준비가 없다면, 선택**Draft로 저장**.

         <Render file="rules-creation-dash-dns-popup" product="rules" />
    </Steps>

    당신이 만들 수있는 규칙에 대한 아이디어, 참조[추천 페이지 규칙](/rules/page-rules/reference/recommended-rules/).
  </TabItem>

  <TabItem label="사이트맵">
    API를 사용하여 페이지 규칙을 만들기 위해, 보냅니다[`POST`이름 \*](/api/resources/page_rules/methods/create/).

    문서를 검토 할 수도 있습니다.[wildcard 일치](/rules/page-rules/reference/wildcard-matching/), [옵션 설정](/rules/page-rules/reference/settings/)·[추천 규칙](/rules/page-rules/reference/recommended-rules/).
  </TabItem>
</Tabs>

:::주\[주]

- 페이지 규칙은[DNS 레코드](/dns/proxy-status/)일하기. 페이지 규칙은 DNS에 존재하지 않는 하위 도메인에 적용되지 않거나 CloudflareXQ로 지시되지 않습니다.

- Cloudflare는 페이지 규칙에서 punycode/unicode 도메인과 같은 비 ASCII 문자를 지원하지 않습니다. 대신 문자열을 URL 인코딩 할 수 있습니다.[Punycode 변환기](https://www.punycoder.com/).
  :::

## 페이지 규칙 편집

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    대시보드XQ의 페이지 규칙을 편집하려면:

    <Steps>
      1. Cloudflare 대시보드에서, 가십시오**페이지 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/rules/page-rules" />

      2. 특정 규칙을 위해:
         - 규칙을 활성화하거나 비활성화하려면 on/off toggle을 선택하십시오.
         - URL 패턴, 설정 및 주문 수정, 선택**제품정보**(렌치 아이콘). 그런 다음 변경하려는 정보를 입력하십시오.
    </Steps>
  </TabItem>

  <TabItem label="사이트맵">
    API를 사용하여 하나 이상의 필드를 업데이트하려면[`PATCH`이름 \*](/api/resources/page_rules/methods/edit/).

    페이지 규칙의 구성을 완전히 대체하려면,[`PUT`이름 \*](/api/resources/page_rules/methods/update/).
  </TabItem>
</Tabs>

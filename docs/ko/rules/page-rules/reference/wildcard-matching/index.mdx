당신은 asterisk를 사용할 수 있습니다 (`*`) 어떤 URL 세그먼트에서 특정 패턴 일치. 예를 들어,`example.com/t*st`일치합니다:

- `example.com/test`
- `example.com/toast`
- `example.com/trust`

`example.com/foo/* `일치하지 않음`example.com/foo`, 하지만`example.com/foo*`일치합니다.

## 유용한 팁

- 모두 일치`http`·`https`, 쓰기`example.com`. 쓰기`*example.com`이름 \*
- 도메인에 모든 페이지를 일치하려면, 쓰기`example.com/*`. 쓰기`example.com`일하지 않습니다.
- 도메인 및 그 하위 도메인에 모든 페이지를 일치하려면, 쓰기`*example.com/*`. 쓰기`example.com`일하지 않습니다.
- 와일드 카드 (Bildcard)`*`) 페이지 규칙 URL에서 문자가 존재하는 경우에도 일치하고 쿼리 문자열을 포함하여 URL의 일부가 포함될 수 있습니다.

## 참조 wildcard 일치

참고 자료가 나중에 일치한 와일드카드를 사용할 수 있습니다.`$<X>`구문, 어디`<X>`glob 패턴의 인덱스를 나타냅니다. 예를 들어,`$1`첫번째 와일드카드 일치를 나타내고`$2`두 번째 와일드 카드 일치를 나타냅니다.

더 보기`$<X>`구문은 특히 유용합니다.*전송 URL*설정. 예를 들면, 당신은 앞으로 할 수 있었습니다`http://*.example.com/*`으로`http://example.com/images/$1/$2.jpg`.

이 규칙은 일치합니다`http://cloud.example.com/flare.jpg`, 전달될 것`http://example.com/images/cloud/flare.jpg`.

추가하기`$`전달 URL의 문자, backslash를 추가하여 탈출`\`앞`\$`.

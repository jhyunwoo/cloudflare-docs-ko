## 페이지 규칙으로 이동

페이지 규칙을 사용하여 URL 전달 또는 리디렉션을 구성하려면:

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**페이지 규칙**사이트 맵

     <DashButton url="/?to=/:account/:zone/rules/page-rules" />

  2. 제품정보**페이지 규칙**.

  3. 이름 \***URL이 일치하면**, 규칙과 일치해야 URL 또는 URL 패턴을 입력하십시오.

  4. 내 계정**설정 선택**, 선택**전송 URL**드롭다운 메뉴에서.

  5. 제품 정보**상태 코드 선택**, 선택*301 - 영구 Redirect*또는*302 - 임시 간접*.

  6. 대상 URL을 입력합니다.

  7. 제품정보**저장 및 배포 페이지 규칙**.
</Steps>

:::참조
페이지 규칙은[DNS 레코드](/dns/proxy-status/)일하기. 페이지 규칙은 DNS에 존재하지 않는 하위 도메인에 적용되지 않거나 CloudflareXQ로 지시되지 않습니다.

## Forwarding 예제

사이트 방문자를 상상해 다양한 URL 패턴을 웹 사이트에 도달합니다. 예를 들어, 페이지 규칙 URL 패턴`*www.example.com/products`·`*example.com/products`일치:

```txt
http://example.com/products

http://www.example.com/products

https://www.example.com/products

https://blog.example.com/products

https://www.blog.example.com/products
```

그러나 일치하지 마십시오:

```txt
http://www.example.com/blog/products (extra directory)
or
http://www.example.comproducts (no trailing slash)
```

당신이 원하는 것을 일치하는 패턴을 만들면, 선택**회사연혁**토글. 요청을 전달 할 수있는 주소를 입력 할 수있는 필드를 표시합니다.

```txt
https://example.com/products
```

운송 상자에 위의 주소를 입력하면 선택**추가 규칙**, 몇 초 안에 당신이 입력한 본과 일치하는 어떤 요구든지 자동적으로 전달될 것입니다`HTTP 302`새로운 URL로 상태 코드를 리디렉션합니다.

## 고급 운송 옵션

apex 도메인 전달과 같은 기본 리디렉션을 사용하는 경우 (`example.com`)에`www.example.com`, 그런 다음 URL에서 다른 것을 잃습니다.

예를 들어, 패턴을 설정할 수 있습니다.

```txt
example.com
```

그리고 그것에 앞으로 있다:

```txt
http://www.example.com
```

그러나 누군가가 입력한 경우`example.com/some-particular-page.html`, 그들은에 리디렉션 될 것 이다:

```txt
www.example.com
```

대신:

```txt
www.example.com/some-particular-page.html
```

이 솔루션은 변수를 사용한다. 각 와일드 카드는 전달 주소에서 참고 자료d일 수 있는 변수에 대응합니다. 변수는 다음과 같습니다.`$`(dollar sign)는 숫자에 따라 따릅니다. 첫 번째 와일드 카드를 참조하려면`$1`, 당신이 사용할 두 번째 와일드 카드를 참조`$2`, 등.

apex에서 전달을 수정하려면`www`위의 예에서 동일한 패턴을 사용할 수 있습니다.

```txt
example.com/*
```

다음 URL을 설정할 수 있습니다:

```txt
http://www.example.com/$1
```

이 경우 누군가가 갔다면:

```txt
example.com/some-particular-page.html
```

그들은에 리디렉션 될 것입니다:

```txt
http://www.example.com/some-particular-page.html
```

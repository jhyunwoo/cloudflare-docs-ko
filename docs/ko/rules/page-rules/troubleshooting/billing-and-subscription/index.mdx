## 페이지 규칙을 실행하면 더 많은 것을 살 수 있습니까?

아니, 당신은 추가 페이지 규칙을 살 수 없습니다. 당신은 필요[현대 규칙 특징에 migrate](/rules/reference/page-rules-migration/)증가된 quotas에서 이득.

## 내 페이지 규칙 구매를 취소하는 방법?

구매 취소:

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**계정 관리**사이트 맵

     <DashButton url="/?to=/:account/billing" />

  2. 오시는 길**이름 \***.

  3. 관련 웹 사이트 ( 알파벳 순서로 표시) 및 선택**제품정보**.

  4. 제품 정보**추가 페이지 규칙**, 이전 값에 금액을 변경합니다. 현재 제한을 초과하면 기존 페이지 규칙을 삭제해야 할 수 있습니다 (사용 또는 활성).

  5. 구독에 업데이트 완료.
</Steps>

## 계획이 변경되면 추가 구독을 유지합니까?

계획을 변경할 때, 페이지 규칙 추가 구독을 유지할 것입니다.

## 페이지 규칙을 취소하면 어떻게됩니까?

현재 청구 사이클의 끝까지 추가 페이지 규칙에 액세스 할 수 있습니다.

당신의 계획은 당신의 다음 청구 주기의 시작에 조정할 것입니다. 더 자세한 내용은, 참조[청구 정책](/billing/billing-policy/).

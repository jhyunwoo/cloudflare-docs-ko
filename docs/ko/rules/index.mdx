모델 번호: Cloudflare 규칙은 요청 및 응답에 대한 조정을 만들 수 있으며 Cloudflare 설정을 구성하고 일치하는 요청에 대한 특정 작업을 트리거 할 수 있습니다.

규칙은 당신이 필요로한다[DNS 레코드 프록시](/dns/proxy-status/)CloudflareXQ를 통해 도메인 (또는 하위 도메인)의.

***

## 주요 특징

<Feature header="구성 규칙" href="/rules/configuration-rules/">
  일치 수신 요청에 대한 Cloudflare 구성 설정을 사용자 지정합니다.
</Feature>

<Feature header="뚱 베어" href="/rules/snippets/">
  웹 사이트 또는 응용 프로그램의 동작을 짧은 조각으로 사용자 정의
  JavaScript 코드.
</Feature>

<Feature header="Transform 규칙" href="/rules/transform/">
  요청 및 응답의 URI 경로, 쿼리 문자열 및 HTTP 헤더를 조정
  Cloudflare 글로벌 네트워크.
</Feature>

<Feature header="회사 소개" href="/rules/url-forwarding/">
  소스 URL에서 특정 HTTP로 대상 URL로 이동
  상태 코드. 용도에 따라 Single Redirects 또는 Bulk Redirects 사용
  이름 \*
</Feature>

<Feature header="회사 소개" href="/rules/origin-rules/">
  들어오는 트래픽이 이동하고 그 매개 변수를 지정합니다.
  Override 요청 속성과 같은`Host`헤더, 목적지 hostname 및
  항구.
</Feature>

<Feature header="클라우드 커넥터" href="/rules/cloud-connector/">
  웹 사이트에서 공개 클라우드 공급자로 들어오는 트래픽을 경로
  AWS, Google Cloud 및 Azure와 같은.
</Feature>

<Feature header="압축 규칙" href="/rules/compression-rules/">
  Cloudflare의 글로벌 응답에 적용되는 압축을 사용자 정의
  웹 사이트 방문자에 네트워크, 파일 확장 및 콘텐츠 기반
  유형.
</Feature>

<Feature header="페이지 규칙" href="/rules/page-rules/" cta="Use Page Rules">
  요청이 URL 패턴 일치 할 때 Trigger 특정 작업.
</Feature>

<Feature header="URL 정상화" href="/rules/normalization/" cta="Configure URL normalization">
  수신 요청의 URL을 수정하여 일관성을 준수합니다.
  표준 포맷.
</Feature>

<Feature header="사용자 정의 오류" href="/rules/custom-errors/" cta="Configure Custom Errors">
  원본 서버로 반환된 오류에 대한 사용자 정의 콘텐츠를 정의하거나
  CloudflareXQ 제품으로 WorkersXQ.
</Feature>

## 관련 제품

</RelatedProduct>

<RelatedProduct header="비율 제한 규칙" href="/waf/rate-limiting-rules/" product="waf">

</RelatedProduct>

<RelatedProduct header="캐시 규칙" href="/cache/how-to/cache-rules/" product="cache">

</RelatedProduct>

<RelatedProduct header="모델 번호: Workers" href="/workers/" product="workers">

  새로운 응용 프로그램 또는 augment 기존의 구성 또는 없이
  인프라 유지.
</RelatedProduct>

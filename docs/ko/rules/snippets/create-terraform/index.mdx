Snippets를 만들 수 있습니다.[Terraform Cloudflare 공급자](https://registry.terraform.io/providers/cloudflare/cloudflare/latest).

시작하기XQ는 Cloudflare 구성을 위한 Terraform로, 참조합니다[시작하기](/terraform/installing/).

## 예제 구성

<Render file="v4-code-snippets" product="terraform" />

다음 예제 Terraform 구성은 스니펫 코드가 실행될 때 정의된 스니펫 규칙을 만듭니다. snippet 코드가 로드됩니다.`file1.js`당신의 기계에 있는 파일.

```tf
resource "cloudflare_snippet" "my_snippet" {
	zone_id  = "<ZONE_ID>"
	name = "my_test_snippet_1"
	main_module = "file1.js"
	files {
		name = "file1.js"
		content = file("file1.js")
	}
}

resource "cloudflare_snippet_rules" "cookie_snippet_rule" {
	zone_id  = "<ZONE_ID>"
	rules {
		enabled = true
		expression = "http.cookie eq \"a=b\""
		description = "Trigger snippet on specific cookie"
		snippet_name = "my_test_snippet_1"
	}
	depends_on = [cloudflare_snippet.my_snippet]
}
```

스니펫의 이름은 문자만 포함할 수 있습니다.`a-z`, `0-9`·`_`(underscore). 이름은 영역의 상황에 독특해야합니다. 스니펫을 만드는 후 스니펫 이름을 변경할 수 없습니다.

모든 것`snippet_name`값에`cloudflare_snippet_rules`자원은 기존의 스니펫의 이름을 일치해야합니다.

import { Render, Steps, DashButton } from "~/components";

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**뚱 베어**사이트 맵

     <DashButton url="/?to=/:account/:zone/rules/snippets" />

  2. (선택) 아직 스니펫을 만들지 않은 경우, 일반적인 사용 사례를 해결하는 스니펫 템플릿 중 하나를 선택하십시오. 그런 다음 검토 및 제안 된 스니펫 코드를 조정합니다.

     처음부터 시작, 선택**Snippet 만들기**.

  3. 내 계정**Snippet 이름**, snippet에 대한 descriptive 이름을 입력합니다. 스니펫을 만들면 이름을 변경할 수 없습니다.

  4. 코드 편집기에서 snippet의 JavaScript 코드를 입력하십시오. 당신의 스니펫이 들어오는 요청을 처리하는 방법을 테스트 할 수 있습니다.**HTTP: HTTP**·**다운로드**탭.

  5. 제품정보**Snippet 규칙**snippet가 실행될 때 구성할 수 있습니다.

  6. 이름 \***이 Snippet을 실행하면 수신 요청 일치**, 맞춤 필터 표현 또는 모든 들어오는 요청에만 스니펫을 실행하려는 경우 선택.

  7. (선택) 사용자 정의 표현을 정의하려면 Expression Builder를 사용 (하나 이상의 값을 지정)**제품정보**, **회사연혁**·**제품정보**) 또는 수동으로 Expression Editor를 사용하여 표현을 입력합니다. 더 많은 정보를 원하시면, 참조[대시보드](/ruleset-engine/rules-language/expressions/edit-expressions/).

  8. 제품정보**이름 \***.

  9. snippet을 배포하려면, 선택**계정 만들기**. 당신은 당신의 스니펫을 배포 할 준비가되지 않은 경우, 옆에 드롭 다운을 엽니 다**계정 만들기**선택하기**Draft로 저장**.

     <Render file="rules-creation-dash-dns-popup" product="rules" />
</Steps>

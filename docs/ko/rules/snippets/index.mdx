## Snippets 요소

snippet을 만들고 배포하려면 다음 요소를 정의해야합니다.

- **코드 snippet**: JavaScript 코드는 요청 핸들링 과정에서 실행됩니다.
- **Snippet 규칙**: 아[필터 표현](/ruleset-engine/rules-language/expressions/)Snippet을 요청하는 것을 결정합니다. 각 스니펫은 하나의 스니펫 규칙과 연관될 수 있습니다.

더 많은 정보를 원하시면, 참조[Snippets 작업](/rules/snippets/how-it-works/)·[대시보드](/rules/snippets/create-dashboard/).

:::참조
Cloudflare API를 사용하여 스니펫 규칙과 관련되지 않은 코드 스니펫을 만들려면 Cloudflare QXQX대시보드는 별도의 탭에 스니펫이 표시됩니다.**사용 된 Snippets**. 당신은 스니펫 코드를 편집하고 스니펫 규칙과 연관, 또는 사용되지 않는 코드 스니펫을 삭제 할 수 있습니다.

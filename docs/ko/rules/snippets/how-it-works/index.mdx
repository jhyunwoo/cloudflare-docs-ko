모델 번호: Cloudflare Snippets는 영역 내에서 정의된 규칙을 기반으로 합니다. 프로세스가 어떻게 작동합니까?

![snippets 실행 워크플로우의 다이어그램](~/assets/images/rules/snippets/snippets-execution.png)

## 1. 뱀파이트 규칙

각 수신 요청을 위해 Cloudflare는 영역에서 정의 된 모든 스니펫 규칙의 표현을 평가합니다. 다양한 요청 속성을 기반으로 한 일치에 대한 평가 체크 (봇 점수, WAF 공격 점수, 원산지 국가 및 쿠키와 같은).

## 2. Snippets 테이블 구축

들어오는 요청과 일치하는 영역의 모든 스니펫 규칙을 위해 CloudflareXQ는 Snippets 테이블에 해당 고유 스니펫 ID를 추가합니다.

## 3. snippets 코드 실행

모든 규칙이 평가되고 전체 테이블이 컴파일되면 Snippets Internal Worker Service는 테이블에 모든 정보를 처리 시작합니다.

이 노동자는 순차적으로 실행되는 테이블에 저장된 모든 스니펫 ID를받습니다. 각 스니펫은 이전 스니펫에서 수정된 요청을 받고 새로운 수정을 적용합니다.

## 4. 요청 실행 워크플로우로 계속

최종 snippet ID를 실행한 후, 수정된 요청은 요청 실행 워크플로우로 다시 전달됩니다. 더 알아보기[실행 순서](/rules/snippets/#execution-order)규칙에 대한 자세한 내용은 Cloudflare Snippets 전에 평가 된 기능에 대한 자세한 내용은.

## 오류 1201 : Snippet은 여러 번 기원을 계속 시도했습니다.

이 오류는 Snippet 시도가 호출 될 때 발생합니다.`fetch(request)`한 번 이상.

### 제품 설명

Snippet 코드만 호출할 수 있음`fetch(request)`한 번. 이 방법은 원래 서버에 수정 된 요청을 보내려면 사용되며 충돌을 방지하기 위해 Snippet 당 한 번 호출해야합니다.

## 오류 1202 : Snippets는 하위 규칙 제한을 초과

이 오류는 수의<GlossaryTooltip term="Snippets subrequest" prepend="A subrequest is ">구독하기</GlossaryTooltip>더 보기[제한 사항](/rules/snippets/#availability)Cloudflare 플랜

### 제품 설명

코드를 보장하기 위해 Snippet을 검토하십시오.<GlossaryTooltip term="Snippets subrequest" prepend="A subrequest is ">구독하기</GlossaryTooltip> [제한 사항](/rules/snippets/#availability)당신의 계획을 위해. 각 하위 퀘스트는 하위 퀘스트 체인 내에서 리디렉션을 포함한 제한에 대해 계산합니다.

## 오류 1203 : Snippets는 CPU 시간 제한을 초과

이 오류는 Snippet이 정의를 초과 할 때 발생합니다.[CPU 시간 제한](/rules/snippets/#limits)Snippets의 경우.

### 제품 설명

코드를 CPU 시간 제한 내에서 보장하기 위해 Snippet을 검토하십시오. 더 높은 CPU 시간 제한이 필요한 경우, 사용 고려[CloudflareWorkers](/workers/). 참고[Snippets 대 Workers를 사용할 때](/rules/snippets/when-to-use/)상세 정보

## 오류 1204 : Snippets는 메모리 제한을 초과

이 오류는 Snippet이 정의를 초과 할 때 발생합니다.[메모리 제한](/rules/snippets/#limits)Snippets의 경우.

### 제품 설명

당신의 코드를 보장하기 위해 Snippet을 검토 메모리 제한 내에서. 더 높은 메모리 제한이 필요한 경우, 사용 고려[CloudflareWorkers](/workers/). 참고[Snippets 대 Workers를 사용할 때](/rules/snippets/when-to-use/)상세 정보

## 오류 1205 : 진행중인 배포

새로운 Snippet은 배포되었으며 현재 Cloudflare의 글로벌 네트워크를 통해 전파됩니다. 이 짧은 창 동안, 요청은 예상대로 처리되지 않을 수 있습니다.

### 제품 설명

이것은 임시 문제입니다. 몇 초 후에 귀하의 요청을 다시 시도 - Snippet는 한 번 propagation 완료됩니다.

## 오류 1206 : Snippet threw 예외

Snippet는 실행 중에 unhandled JavaScript 예외를 발견했습니다. 다음은 다음과 같습니다.

- Runtime JavaScript 오류 Snippet 코드
- 자주 묻는 질문
- 유형 오류 또는 참고 자료 오류

### 제품 설명

- Snippet 코드를 검토하여 예외가 발생하고 검출 된 버그를 수정할 수 있는지 확인합니다.
- 적절한 오류 처리 추가 (Add proper error handling)[`try...catch`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/try...catch)블록).

## Snippets는 이름을 변경할 수 없습니다.

Snippet을 만들 때 정의하는 이름은 Snippet ID로 사용되며 나중에 편집 할 수 없습니다.

### 제품 설명

Snippet의 이름을 변경하려면 새로운 Snippet을 만들고 오래된 것을 삭제하십시오.

***

## 다른 런타임 오류

Snippets는 Workers, 즉 오류와 일부 오류 코드를 공유합니다.`11xx`범위. 이 오류에 대한 자세한 내용은 참조[오류 및 예외](/workers/observability/errors/).

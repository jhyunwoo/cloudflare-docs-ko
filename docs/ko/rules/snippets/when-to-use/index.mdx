이 가이드는 Cloudflare의 글로벌 네트워크에 Snippets 또는 WorkersXQ를 사용할 때 결정하는 데 도움이됩니다. 최고의 관행, 비교 및 실제 사용 사례를 제공하여 작업 부하에 적합한 제품을 선택할 수 있습니다.

## Snippets는 무엇입니까?

모델 번호: Cloudflare Snippets는 HTTP 요청과 응답을 수정하는 빠른, 선언적인 방법을 제공합니다. Snippets 확장[Cloudflare 규칙](/rules/)JavaScriptXQ 기반 논리를 작성하여 업스트림에서 반환 한 후 원래와 응답에 도달하기 전에 요청을 수정합니다.

Snippets는 다음을 가능하게 합니다:

- headers, validate JWTs를 수정하고 복잡한 재 작성 또는 리디렉션을 구현합니다.
- Retry는 다른 기원에 대한 요청을 실패하고 사용자 정의 캐싱 전략을 적용합니다.
- 여러 Snippets를 연속적으로 실행하여 각 Snippet가 요청 또는 응답을 수정하여 다음으로 차단합니다.

Snippets는 추가 비용 없이 포함되어 있습니다.[모든 유료 계획](/rules/snippets/#availability), 경량 가장자리 논리를 위한 선호한 해결책을 만들기.

## Workers는 무엇입니까?

대비,[CloudflareWorkers](/workers/)Cloudflare의 응용 프로그램에 필요한 상태, compute 및 통합을 위해 설계된 풀 스택 컴퓨팅 플랫폼을 제공합니다[개발자 플랫폼](/learning-paths/workers/devplat/intro-to-devplat/). Workers는 안으로 운영합니다[사용 기반 가격 모델](/workers/platform/pricing/)무료 계층이 포함되어 있습니다.

## 올바른 제품을 선택

Snippets는 가장자리에 빠르고, 비용 자유로운 요구 및 응답 수정에 대하 이상적입니다. 그들은 확장[Cloudflare 규칙](/rules/)추가 인프라 또는 외부 솔루션을 필요로하지 않고.

### Snippets를 사용할 때

- Cloudflare의 네트워크에 직접 적용되는 초고속 트래픽 수정.
- Cloudflare를 확장하십시오 더 큰 통제를 위한 붙박이 활동을 넘어서 규칙.
- VCL, EdgeWorkers, 또는 온프레미스 논리를 대체하여 CDN 마이그레이션을 단순화합니다.
- 헤더, 캐시 응답을 수정하고 리디렉션을 수행합니다.
- JavaScriptXQ를 사용하여 개발 워크플로우에 가장자리 논리를 통합합니다.

### Snippets는 설계되지 않습니다.

- Persistent 상태 관리 (예, 세션 저장 또는 데이터베이스).
- Compute-intensive task (예를 들면, 이미지 변환 또는[AI 소개](/workers-ai/)).
- 딥 통합과[개발자 플랫폼](/learning-paths/workers/devplat/intro-to-devplat/)같은 서비스[모델 번호: Durable Objects](/durable-objects/)또는[모델 번호: D1](/d1/).
- 진보된 런타임 특징을 요구하는 케이스를 사용하십시오:
  - [환경 변수](/workers/configuration/environment-variables/)
  - [옵션 정보](/workers/observability/logs/)
  - [회사 소개](/workers/runtime-apis/bindings/)
  - [Cron 트리거](/workers/configuration/cron-triggers/)
  - 사이트맵[보상 제한](/rules/snippets/#limits)

### 키 기능

- Ultra-fast, Edge-optimized 실행, 에 의해 구동[Ruleset 엔진](/ruleset-engine/)·[Workers 런타임](/workers/runtime-apis/).
- 추가 비용 없음[모든 유료 계획](/rules/snippets/#availability).
- 수십 개의 요청 속성을 사용하는 Granular 요청[한국어](/ruleset-engine/rules-language/fields/reference/http.request.full_uri/), [사용자 시약](/ruleset-engine/rules-language/fields/reference/http.user_agent/)·[제품 정보](/ruleset-engine/rules-language/fields/reference/http.request.cookies/).
- 순차적 실행 – 여러 Snippets[실행할 수 있습니다](/rules/snippets/how-it-works/)동일한 요청에 따라 수정 단계 적용.
- Native 통합[Cloudflare 규칙](/rules/)– Snippets는 이전의 다른 제품에서 요청 수정을 상속[요청 단계](/ruleset-engine/reference/phases-list/#request-phases).
- JavaScript 및 웹 API 지원, 포함 :
  - [페치 API](/workers/runtime-apis/fetch/)
  - [캐시 API](/workers/runtime-apis/cache/)
- \* 필수[Workers 런타임](/workers/runtime-apis/)기능:
  - [`request.cf`기타 제품](/workers/runtime-apis/request/#incomingrequestcfproperties)
  - [`HTMLRewriter`](/workers/runtime-apis/html-rewriter/)
- 자동화된 배포 및 버전[옵션 정보](/rules/snippets/create-terraform/).

## 코드 예제: Common Snippets 템플릿

아래는 실제 사용 사례가 행동에 Snippets를 해독합니다. 시작하기에 더 많은 템플릿을 찾을 수 있습니다[이름 \*](/rules/snippets/examples/)이름 \*

### HTTP 헤더를 수정

요청 및 응답 헤더를 동적으로 수정합니다.

```javascript
export default {
	async fetch(request) {
		//현재 타임스탬프 받기
		const timestamp = Date.now();

		//timetamp를 hexadecimal 형식으로 변환
		const hexTimestamp = timestamp.toString(16);

		//요청을 복제하고 HEX 타임스탬프와 사용자 정의 헤더를 추가
		const modifiedRequest = new Request(request, {
			headers: new Headers(request.headers),
		});
		modifiedRequest.headers.set("X-Hex-Timestamp", hexTimestamp);

		//자주 묻는 질문
		const response = await fetch(modifiedRequest);

		//더 이상 immutable 인 응답을 복제
		const newResponse = new Response(response.body, response);

		//응답 값으로 사용자 정의 헤더를 추가
		newResponse.headers.append(
			"x-snippets-hello",
			"Hello from Cloudflare Snippets",
		);

		//응답에서 헤더 삭제
		newResponse.headers.delete("x-header-to-delete");
		newResponse.headers.delete("x-header2-to-delete");

		//응답의 기존 헤더에 대한 값을 조정
		newResponse.headers.set("x-header-to-change", "NewValue");

		//방문자에 대한 수정 된 응답
		return newResponse;
	},
};
```

당신의 근원이 계획한 정비를 겪는 때 정비 페이지로 교통.

```javascript
export default {

```

### 사용자 정의 캐시

원사 부하를 줄이기 위해 가장자리에서 programmatic 캐싱을 수행합니다.

```javascript
const CACHE_DURATION = 30 * 24 * 60 * 60; //30 일

export default {
	async fetch(request) {
		const cache = caches.default;
		const cacheKey = new Request(request.url, { method: "GET" });

		let response = await cache.match(cacheKey);
		if (!response) {
			response = await fetch(request);
			response = new Response(response.body, response);
			response.headers.set("Cache-Control", `s-maxage=${CACHE_DURATION}`);
			await cache.put(cacheKey, response.clone());
		}
		return response;
	},
};
```

### 국가 코드에 따라 Redirect

해당 이용 후기에 달린 코멘트가 없습니다.

```javascript
export default {
	async fetch(request) {
		const country = request.cf.country;
		const redirectMap = {
			US: "https://example.com/us",
			EU: "https://example.com/eu",
		};
		if (redirectMap[country])
			return Response.redirect(redirectMap[country], 301);
		return fetch(request);
	},
};
```

### Redirect 403 다른 페이지로 이동

원본이 응답한 경우`403 Forbidden`오류 코드, 다른 페이지로 방문자를 리디렉션.

```javascript
export default {
	async fetch(request) {
		//원래 요청을 원산지로 보내십시오.
		const response = await fetch(request);
		//403개의 상태 코드로 응답된 경우 확인
		if (response.status == 403) {
			//그래서,이 URL로 리디렉션
			const destinationURL = "https://example.com";
			//이 상태 코드로
			const statusCode = 301;
			//연락처
			return Response.redirect(destinationURL, statusCode);
		}
		//그렇지 않으면, 기원의 응답
		else {
			return response;
		}
	},
};
```

### 다른 근원에 Retry

원래 요청에 대한 응답이 아니라면`200 OK`또는 리디렉션은 다른 기원으로 보냅니다.

```javascript
export default {
	async fetch(request) {
		//원래 요청을 원산지로 보내십시오.
		const response = await fetch(request);

		//응답이 200 OK 또는 리디렉션되지 않은 경우, 다른 기원으로 보내
		if (!response.ok && !response.redirected) {
			//첫째로, clone 새로운 요구를 건설하는 본래 요구
			const newRequest = new Request(request);
			//새로운 기원의 재선명 요청을 식별하기 위해 헤더를 추가하십시오.
			newRequest.headers.set("X-Rerouted", "1");
			//원래 URL을 복제
			const url = new URL(request.url);
			//다른 기원 / hostname에 요청 보내기
			url.hostname = "example.com";
			//원산지의 새로운 요청에 대한 응답
			return await fetch(url, newRequest);
		}

		//응답이 200 OK 또는 리디렉션 인 경우, 제공
		return response;
	},
};
```

### API 응답에서 필드를 제거

JSON으로 인해 응답을 반환하기 전에 민감한 필드를 삭제합니다.

```javascript
export default {
	async fetch(request) {
		//원래 요청을 원산지로 보내십시오.
		const response = await fetch(request);
		//JSON으로 응답되는 경우 확인
		try {
			//JSON으로 Parse API 응답
			var api_response = response.json();
			//삭제하려는 필드를 지정합니다. 예를 들어, parsed JSON에서 "botManagement" 배열을 삭제하려면:
			delete api_response.botManagement;
			//Serve는 API 응답을 수정했습니다
			return Response.json(api_response);
		} catch (err) {
			//실패에, unmodified 근원의 응답을 봉사하십시오
			return response;
		}
	},
};
```

### CORS 헤더 설정

지원하다[Cross-Origin 자원 공유 (CORS)](https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS)헤더 및 핸들 preflight 요청.

```javascript
//CORS 헤더 정의
const corsHeaders = {
	"Access-Control-Allow-Origin": "*", //* 허용된 근원으로 대체하십시오 (s)
	"Access-Control-Allow-Methods": "GET, POST, PUT, DELETE, OPTIONS", //필요한 방법 조정
	"Access-Control-Allow-Headers": "Content-Type, Authorization", //필요에 따라 허용된 헤더를 조정하십시오
	"Access-Control-Max-Age": "86400", //최대 연령 조정 (초에서) 필요에 따라
};

export default {
	async fetch(request) {
		//헤더를 수정하려면 요청의 사본을 만드십시오.
		const modifiedRequest = new Request(request);

		//핸들 preflight 요청 (OPTIONS)
		if (request.method === "OPTIONS") {
			return new Response(null, {
				headers: {
					...corsHeaders,
				},
				status: 200, //preflight 요청에 대한 OK 상태와 대응
			});
		}

		//수정된 요청을 전달합니다.
		const response = await fetch(modifiedRequest);

		//헤더를 수정하기 위해 응답의 사본을 만드십시오
		const modifiedResponse = new Response(response.body, response);

		//응답에 CORS 헤더 설정
		Object.keys(corsHeaders).forEach((header) => {
			modifiedResponse.headers.set(header, corsHeaders[header]);
		});

		return modifiedResponse;
	},
};
```

### HTML 페이지에 링크 쓰기

당신의 근원에 변화를 만들기 없이 outdated 연결을 대체하십시오.

```javascript
export default {
	async fetch(request) {
		//여기에 오래된 호스트 이름을 정의합니다.
		const OLD_URL = "oldsite.com";
		//그런 다음 새로운 hostname을 추가하십시오.
		const NEW_URL = "newsite.com";

		class AttributeRewriter {
			constructor(attributeName) {
				this.attributeName = attributeName;
			}
			element(element) {
				const attribute = element.getAttribute(this.attributeName);
				if (attribute) {
					element.setAttribute(
						this.attributeName,
						attribute.replace(OLD_URL, NEW_URL),
					);
				}
			}
		}

		const rewriter = new HTMLRewriter()
			.on("a", new AttributeRewriter("href"))
			.on("img", new AttributeRewriter("src"));

		const res = await fetch(request);
		const contentType = res.headers.get("Content-Type");

		//응답이 HTML이라면 변환 할 수 있습니다.
		//HTMLRewriter -- 그렇지 않으면, 통과해야 합니다
		if (contentType.startsWith("text/html")) {
			return rewriter.transform(res);
		} else {
			return res;
		}
	},
};
```

### 느린 요청

수신 요청이 규칙과 일치할 때 사용할 지연을 무시합니다. 의심스러운 요청에 대한 유용한.

```javascript
export default {
	async fetch(request) {
		//연락처
		const delay_in_seconds = 5;
		//공지사항
		await new Promise((resolve) =>
			setTimeout(resolve, delay_in_seconds * 1000),
		); //밀리 초에 지연 설정

		//자주 묻는 질문
		const response = await fetch(request);
		return response;
	},
};
```

## Snippets 및 Workers를 함께 사용

Snippets 및 Workers는 차별화된 기능을 가지고 있지만 복잡한 트래픽 워크플로우를 처리할 수 있습니다.

충돌을 방지하려면 Snippets 및 Workers는 동일한 URL에서 실행하는 것보다 별도의 요청 경로에 작동해야합니다. 자신의 논리 내에서 하위 퀘스트로 자신의 URL을 태워, 부드러운 실행과 캐싱 동작을 보장합니다.

### 예 1: Snippets와 WorkersQ 사이의 데이터를 전달

Snippets는 Worker에 도달하기 전에 수신 요청을 수정할 수 있으며 Workers는 이러한 수정을 읽을 수 있으며 추가 변환을 수행하고 다운스트림을 전달합니다.

#### Snippet: 사용자 정의 헤더를 추가

```javascript
export default {
	async fetch(request) {
		//현재 타임스탬프 받기
		const timestamp = Date.now();
		const hexTimestamp = timestamp.toString(16);

		//Clone 요청 및 사용자 정의 헤더를 추가
		const modifiedRequest = new Request(request, {
			headers: new Headers(request.headers),
		});
		modifiedRequest.headers.set("X-Hex-Timestamp", hexTimestamp);

		console.log(`X-Hex-Timestamp: ${hexTimestamp}`);

		//비밀번호
		return fetch(modifiedRequest);
	},
};
```

#### 노동자: 헤더를 읽고 응답에 추가

```javascript
export default {
	async fetch(request) {
		const response = await fetch("https://{snippets_url}", request); // Ensure {snippets_url} points to the endpoint modified by Snippets
		const newResponse = new Response(response.body, response);

		let hexTimestamp = request.headers.get("X-Hex-Timestamp") || "null";
		console.log(hexTimestamp);

		newResponse.headers.set("X-Hex-Timestamp", hexTimestamp);
		return newResponse;
	},
};
```

**결과:**&#x53;nippet 세트`X-Hex-Timestamp`노동자는 근원에 읽고 전달합니다.

### 예제 2 : Snippets를 사용하여 캐싱 노동자 응답

작업자는 compute-heavy 처리 (예를 들어, 이미지 변환)을 수행하며 Snippet은 불필요한 작업 실행을 방지하기 위해 캐시 된 결과를 제공합니다. WorkersXQ[캐시 전](/cache/interaction-cloudflare-products/workers/)바람직하지 않다.

#### 노동자: Transform와 캐시 응답

```javascript
export default {
	async fetch(request) {
		const url = new URL(request.url);
		url.hostname = "origin.example.com"; //리소스가 호스팅되는 근원에 이 hostname 점을 지키십시오

		const newRequest = new Request(url, request);
		const customKey = `https://${url.hostname}${url.pathname}`; // This custom cache key should be the same in both Worker and Snippet configuration for cache to work

		//Fetch 및 수정 응답
		const response = await fetch(newRequest);
		const newResponse = new Response(response.body, response);

		//변형 된 응답 캐시
		const cache = caches.default;
		const cachedResponse = newResponse.clone();
		cachedResponse.headers.set("X-Cached-In-Workers", "true");
		await cache.put(customKey, cachedResponse);

		newResponse.headers.set("X-Retrieved-From-Workers", "true");
		return newResponse;
	},
};
```

#### Snippet: Serve 캐시된 응답 또는 Worker에 전달

```javascript
export default {
	async fetch(request) {
		const url = new URL(request.url);
		url.hostname = "origin.example.com"; //리소스가 호스팅되는 근원에 이 hostname 점을 지키십시오
		const cacheKey = `https://${url.hostname}${url.pathname}`; // This custom cache key should be the same in both Worker and Snippet configuration for cache to work

		//액세스 캐시
		const cache = caches.default;
		let response = await cache.match(cacheKey);

		if (!response) {
			console.log(`Cache miss for: ${cacheKey}. Fetching from Worker...`);
			url.hostname = "worker.example.com"; //WorkersQ 경로에 이 호스트명 점을 보장
			response = await fetch(new Request(url, request));

			//미래 사용에 대한 응답을 캐시
			response = new Response(response.body, response);
			response.headers.set("Cache-Control", `s-maxage=3600`);
			response.headers.set("x-snippets-cache", "stored");
		} else {
			console.log(`Cache hit for: ${cacheKey}`);
			response = new Response(response.body, response);
			response.headers.set("x-snippets-cache", "hit");
		}

		return response;
	},
};
```

**결과:**&#xBCC0;환된 응답 (`X-Cached-In-Workers: true`)는 캐시에서 제공, 중복 노동자 실행을 피 (`X-Retrieved-From-Workers`현재는 없습니다. 캐시가 만료될 때, Snippet는 신선한 버전을 fetches.

## Snippets와 Workers 사이의 마이그레이션

Snippets와 Workers는 동일합니다[Workers 런타임](/workers/runtime-apis/), 의미 JavaScript 코드는 바인딩에 의존하지 않는, 지속적인 저장, 또는 진보된 실행 특징은 그들 사이에서 이음새가 없는 migrated 일 수 있습니다.

### Snippets에 작업로드를 마이그레이션 할 때

당신은 그것을 Snippets에 노동자를 마이그레이션해야한다:

- 헤더, 리디렉션, 캐싱 규칙, 또는 원래 라우팅을 수정합니다.
- 바인딩, 지속적인 저장, 또는 외부 통합이 필요하지 않습니다.
- 간단한 논리를 가진 경량 JavaScript 기능입니다.
- Pro, Business 또는 Enterprise 플랜에서 무료로 무제한의 시간을 실행할 수 있습니다.

Snippets로 마이그레이션할 수 있습니다:

- Leverage 고급 요청을 통해 일치[Ruleset 엔진](/ruleset-engine/).
- 사용 기반 청구 제거 — Snippets는[비용 없음](/rules/snippets/#availability)모든 유료 계획.
- Cloudflare 규칙에 직접 트래픽 수정을 통합하여 관리 단순화.

### WorkersXQ

논리가 있다면 Snippets에서 WorkersXQ로 마이그레이션해야 합니다.

- 실행 시간, 메모리 또는 기타 제외[제한 사항](/rules/snippets/#limits).
- persistent 상태 관리와 같은:
  - [Key-Value (KV) 저장](/kv/)
  - [SQL 데이터베이스 (D1)](/d1/)
  - [모델 번호: Durable Objects](/durable-objects/)
- Compute-intensive 작업을 수행합니다.
  - [AI 소개](/workers-ai/)
  - [벡터 검색](/vectorize/)
  - [이미지 변환](/images/transform-images/transform-via-workers/)
- Cloudflare의 해석[개발자 플랫폼](/learning-paths/workers/devplat/intro-to-devplat/).
- 이름 \*[단위 테스트](/workers/testing/).
- CLI를 통해 배포 자동화 필요 ([모델 번호: Wrangler](/workers/wrangler/)).

Snippet가 실행 시간, 메모리, 또는 기능의 한계에 도달하면 Workers로 전환하면 논리가 제한없이 스케일 할 수 있습니다.

## 이름 \*

모델 번호: Cloudflare Snippets는 빠른, 선명한 가장자리 교통 논리를 위한 생산 독서 해결책을 제공합니다, 사이 간격을 밝히기[Cloudflare 규칙](/rules/)·[개발자 플랫폼](/learning-paths/workers/devplat/intro-to-devplat/).

Snippets와 Workers는 다른 문제를 해결합니다:

- 헤드 리깅, 캐싱, 리디렉션, 기원 라우팅, 사용자 정의 응답, A / B 테스트 및 인증을 포함하여 빠르고 가벼운 트래픽 수정을위한 Snippets를 사용합니다.
- Workers는 진보된 compute, 지속적인 국가 및 가득 차있 토크 신청을 위해 건축됩니다.

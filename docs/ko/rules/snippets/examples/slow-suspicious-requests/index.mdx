## Snippet 코드

```js
export default {
	async fetch(request) {
		//연락처
		const delay_in_seconds = 5;
		//공지사항
		await new Promise((resolve) =>
			setTimeout(resolve, delay_in_seconds * 1000),
		); //밀리 초에 지연 설정

		//자주 묻는 질문
		const response = await fetch(request);
		return response;
	},
};
```

## Snippet 규칙

사용자 정의 필터 표현 구성:

| 제품정보 | 회사연혁     | 제품정보 |
| ---- | -------- | ---- |
| 봇 점수 | 더 적은 보다는 | `10` |

Expression Editor를 사용하는 경우 다음의 표현을 입력하십시오.

```txt
(cf.bot_management.score lt 10)
```

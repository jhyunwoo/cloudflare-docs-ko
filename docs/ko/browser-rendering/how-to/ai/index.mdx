웹 사이트를 검색 할 수있는 기능은 AI로 워크플로우를 구축 할 때 중요합니다. 여기서 우리는 브라우저 렌더링을 사용하여 예를 제공합니다.
`https://labs.apnic.net/`그리고, 기계 학습 모델을 사용하여[모델 번호: Workers AI](/workers-ai/), 지정된 스키마와 JSON으로 첫 번째 게시물을 추출합니다.

## 자주 묻는 질문

1. 사용 방법`create-cloudflare`새로운 Hello World Cloudflare Worker 스크립트:

```sh
npm create cloudflare@latest -- browser-worker
```

2. 설치하기`@cloudflare/puppeteer`브라우저 렌더링 인스턴스를 제어할 수 있는 ,:

```sh
npm i @cloudflare/puppeteer
```

2. 설치하기`zod`그래서 우리는 우리의 산출 체재를 정의할 수 있습니다`zod-to-json-schema`그래서 JSON schema 형식으로 변환 할 수 있습니다.

```sh
npm i zod
npm i zod-to-json-schema
```

3. nodejs 호환성 플래그를 활성화하고 새로운 Wrangler 설정에 바인딩을 추가하십시오.

<WranglerConfig>
  ```jsonc
  {
  	"compatibility_flags": [
  		"nodejs_compat"
  	]
  }
  ```
</WranglerConfig>

<WranglerConfig>
  ```jsonc
  {
  	"browser": {
  		"binding": "MY_BROWSER"
  	}
  }
  ```
</WranglerConfig>

4. 이용하기[모델 번호: Workers AI](/workers-ai/), 당신은 당신의 것을 얻을 필요가 있습니다[계정 ID 및 API 토큰](/workers-ai/get-started/rest-api/#1-get-api-token-and-account-id)·
   당신이 그들을 가지고 있다면, 창조[`.dev.vars`](/workers/configuration/environment-variables/#add-environment-variables-via-wrangler)파일 및 설정 :

```
ACCOUNT_ID=
API_TOKEN=
```

제품정보`.dev.vars`지역 개발에만 있기 때문에, 그렇지 않으면 사용[계정 관리](/workers/configuration/secrets/).

## 브라우저 렌더링을 사용하여 페이지로드

아래 코드에서 우리는 브라우저를 실행`await puppeteer.launch(env.MY_BROWSER)`, 렌더링 된 텍스트를 추출하고 브라우저를 닫습니다.
그런 다음, 사용자 프롬프트와 함께, 원하는 출력 스키마와 렌더링 된 텍스트, LLM에 보낼 신속한 준비.

본문 바로가기`src/index.ts`다음과 같이 skeleton 스크립트:

```ts
import { z } from "zod";
import puppeteer from "@cloudflare/puppeteer";
import zodToJsonSchema from "zod-to-json-schema";

export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    if (url.pathname != "/") {
      return new Response("Not found");
    }

    //당신의 신속하고 사이트 스크랩
    const userPrompt = "Extract the first post only.";
    const targetUrl = "https://labs.apnic.net/";

    //공지사항
    const browser = await puppeteer.launch(env.MY_BROWSER);
    const page = await browser.newPage();
    await page.goto(targetUrl);

    //웹 사이트 텍스트
    const renderedText = await page.evaluate(() => {
      //@ts-ignore js 코드를 브라우저에서 실행
      const body = document.querySelector("body");
      return body ? body.innerText : "";
    });
    //더 이상 필요로하지 않기 때문에 브라우저 닫기
    await browser.close();

    //원하는 json schema를 정의
    const outputSchema = zodToJsonSchema(
      z.object({ title: z.string(), url: z.string(), date: z.string() })
    );

    //예제 프롬프트
    const prompt = `
    You are a sophisticated web scraper. You are given the user data extraction goal and the JSON schema for the output data format.
    Your task is to extract the requested information from the text and output it in the specified JSON schema format:

        ${JSON.stringify(outputSchema)}

    DO NOT include anything else besides the JSON output, no markdown, no plaintext, just JSON.

    User Data Extraction Goal: ${userPrompt}

    Text extracted from the webpage: ${renderedText}`;

    //TODO 통화 llm
    //const result = getLLMResult (env, 프롬프트, outputSchema);
    //반환 응답.json (result);
  }

} satisfies ExportedHandler<Env>;
```

## LLM을 호출

웹 페이지 텍스트를 가지고, 사용자의 목표와 출력 스키마, 우리는 이제 사용자의 요청에 따라 JSON으로 변환하기 위해 LLM을 사용할 수 있습니다.
아래 예제`@hf/thebloke/deepseek-coder-6.7b-instruct-awq`하지만 다른[모델 번호:](/workers-ai/models/)또는 OpenAI와 같은 서비스는 최소 변경 사항으로 사용될 수 있습니다.

````ts
async function getLLMResult(env, prompt: string, schema?: any) {
  const model = "@hf/thebloke/deepseek-coder-6.7b-instruct-awq"
  const requestBody = {
    messages: [{
      role: "user",
      content: prompt
    }],
  };
  const aiUrl = `https://api.cloudflare.com/client/v4/accounts/${env.ACCOUNT_ID}/ai/run/${model}`

  const response = await fetch(aiUrl, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${env.API_TOKEN}`,
    },
    body: JSON.stringify(requestBody),
  });
  if (!response.ok) {
    console.log(JSON.stringify(await response.text(), null, 2));
    throw new Error(`LLM call failed ${aiUrl} ${response.status}`);
  }

  //공정 응답
  const data = await response.json();
  const text = data.result.response || '';
  const value = (text.match(/```(?:json)?\s*([\s\S]*?)\s*```/) || [null, text])[1];
  try {
    return JSON.parse(value);
  } catch(e) {
    console.error(`${e} . Response: ${value}`)
  }
}
````

Browser Rendering with OpenAI를 사용하려면 대신 변경해야 합니다.`aiUrl`엔드포인트 및`requestBody`(또는 체크 아웃)[llm 스크레이퍼 작업자](https://www.npmjs.com/package/llm-scraper-worker)패키지).

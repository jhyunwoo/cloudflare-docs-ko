에 본[이 Workers 바인딩 가이드](/browser-rendering/workers-bindings/screenshots/), 브라우저 렌더링은 주어진 URL에 대한 스크린 샷을 생성 할 수 있습니다. Alongside 스크린 샷, 주어진 웹 페이지에 전체 PDF 문서를 생성 할 수 있으며 웹 페이지 마크 업 및 스타일을 제공 할 수도 있습니다.

두 가지 방법으로 브라우저 렌더링으로 PDF를 생성할 수 있습니다:

- **[REST API를](/browser-rendering/rest-api/)**: 사용[/pdf 엔드포인트](/browser-rendering/rest-api/pdf-endpoint/). 이것은 당신이 연출 행동을 주문을 받아서 만들 필요가 없는 경우에 이상적입니다.
- **[Workers 회사 소개](/browser-rendering/workers-bindings/)**: 사용[제품정보](/browser-rendering/puppeteer/)또는[공유하기](/browser-rendering/playwright/)Workers로 추가 제어 및 사용자 정의에 대한 바인딩.

가장 적합한 방법 선택.

다음 예제에서는 PDF 생성 방법을 보여줍니다.[제품정보](/browser-rendering/puppeteer/).

## 자주 묻는 질문

1. 사용 방법`create-cloudflare`새로운 Hello World Cloudflare Worker 스크립트:

<PackageManagers type="create" pkg="cloudflare@latest" args="browser-worker" />

2. 설치하기`@cloudflare/puppeteer`브라우저 렌더링 인스턴스를 제어할 수 있는 ,:

<PackageManagers pkg="@cloudflare/puppeteer" dev />

3. 브라우저 렌더링을 새로운 Wrangler 구성에 추가하십시오:

<WranglerConfig>
  ```jsonc
  {
  	"browser": {
  		"binding": "BROWSER"
  	}
  }
  ```
</WranglerConfig>

<Render file="remote-binding-note" product="workers" />

4. 본문 바로가기`src/index.ts`(주)`src/index.js`다음 skeleton 스크립트와 JavaScript 프로젝트용:

```ts
import puppeteer from "@cloudflare/puppeteer";

const generateDocument = (name: string) => {};

export default {
	async fetch(request, env) {
		const { searchParams } = new URL(request.url);
		let name = searchParams.get("name");

		if (!name) {
			return new Response("Please provide a name using the ?name= parameter");
		}

		const browser = await puppeteer.launch(env.BROWSER);
		const page = await browser.newPage();

		//단계 1: HTML과 CSS 정의
		const document = generateDocument(name);

		//2단계: HTML과 CSS를 브라우저로 전송
		await page.setContent(document);

		//단계 3: 생성 및 반환 PDF

		return new Response();
	},
};
```

## 1. HTML과 CSS 정의

브라우저 렌더링을 사용하여 사용자 정의 URL로 탐색하고 수동으로 웹 페이지를 생성 한 다음 브라우저 렌더링 인스턴스에 해당 웹 페이지를 제공합니다. 이것은 당신이 원하는 어떤 디자인을 렌더링 할 수 있습니다.

:::참조
당신이 좋아하는 어떤 방법을 사용하여 HTML 또는 CSS를 생성 할 수 있습니다. 이 예제는 문자열 교환을 사용하지만, QXReact, Remix 및 VueXQ와 같은 WorkersXQ에서 HTML 렌더링 할 수있는 웹 프레임 워크와 완전히 호환됩니다.
주요 특징

이 예제의 경우, 우리는 user-provided content ('?name=' 매개 변수를 통해)를 취하고 최종 PDF 문서의 이름을 출력해야합니다.

시작하려면`generateDocument`다음과 같이 기능:

```ts
const generateDocument = (name: string) => {
	return `
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <style>
      html,
      body,
      #container {
        width: 100%;
        height: 100%;
        margin: 0;
      }
      body {
        font-family: Baskerville, Georgia, Times, serif;
        background-color: #f7f1dc;
      }
      strong {
        color: #5c594f;
        font-size: 128px;
        margin: 32px 0 48px 0;
      }
      em {
        font-size: 24px;
      }
      #container {
        flex-direction: column;
        display: flex;
        align-items: center;
        justify-content: center;
        text-align: center;
      }
    </style>
  </head>

  <body>
    <div id="container">
      <em>This is to certify that</em>
      <strong>${name}</strong>
      <em>has rendered a PDF using Cloudflare Workers</em>
    </div>
  </body>
</html>
`;
};
```

이 예 HTML 문서는 사용자 보호 된 이름이 QXQX0103XQ QXWorkersXQXWorkers를 사용하여 PDF를 성공적으로 렌더링 한 인증서를 보여주는 베이지 배경을 렌더링해야합니다.

:::참조
이미지 또는 PDF 렌더링기로 직접 상호 교환하는 것이 가장 좋습니다. 송장과 같은 내용을 렌더링하려면 데이터 입력을 검증하고 같은 도구를 사용하여 데이터를 직접 가져올 수 있습니다.[D1](/d1/)또는[Workers KV](/kv/).
:::

## 2. HTML 및 CSS Into 브라우저로드

이제 완전히 스타일링 된 HTML 문서가있어 컨텐츠를 가지고 브라우저 인스턴스에 전송할 수 있습니다. 이 문서를 다음과 같이 저장할 빈 페이지를 작성:

```ts
const browser = await puppeteer.launch(env.BROWSER);
const page = await browser.newPage();
```

더 보기[`page.setContent()`](https://github.com/cloudflare/puppeteer/blob/main/docs/api/puppeteer.page.setcontent.md)함수는 문자열에서 페이지의 HTML 내용을 설정하는 데 사용할 수 있으므로 직접 만든 문서를 전달할 수 있습니다.

```ts
await page.setContent(document);
```

## 3. PDF 생성 및 반품

브라우저 렌더링 인스턴스를 사용하면 제공된 HTML과 CSS를 렌더링할 수 있습니다.[`page.pdf()`](https://github.com/cloudflare/puppeteer/blob/main/docs/api/puppeteer.page.pdf.md)PDF 파일을 생성하고 클라이언트로 돌아가는 명령.

```ts
let pdf = page.pdf({ printBackground: true });
```

더 보기`page.pdf()`전화 지원[옵션 수](https://github.com/cloudflare/puppeteer/blob/main/docs/api/puppeteer.pdfoptions.md)생성 된 PDF의 크기를 특정 용지 크기로 설정하고 특정 마진을 설정하고 완전 투명 배경을 허용합니다. 지금, 당신은 단지 overriding입니다`printBackground`사용자 정의`body`배경 스타일이 표시됩니다.

이제 PDF 데이터를 가지고, 클라이언트로 돌아가`Response`이름 \*`application/pdf`내용 유형:

```ts
return new Response(pdf, {
	headers: {
		"content-type": "application/pdf",
	},
});
```

## 이름 \*

전체 Worker 스크립트는 다음과 같습니다:

```ts
import puppeteer from "@cloudflare/puppeteer";

const generateDocument = (name: string) => {
	return `
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <style>
	  html, body, #container {
		width: 100%;
	    height: 100%;
		margin: 0;
	  }
      body {
        font-family: Baskerville, Georgia, Times, serif;
        background-color: #f7f1dc;
      }
      strong {
        color: #5c594f;
		font-size: 128px;
		margin: 32px 0 48px 0;
      }
	  em {
		font-size: 24px;
	  }
      #container {
		flex-direction: column;
        display: flex;
        align-items: center;
        justify-content: center;
		text-align: center
      }
    </style>
  </head>

  <body>
    <div id="container">
		<em>This is to certify that</em>
		<strong>${name}</strong>
		<em>has rendered a PDF using Cloudflare Workers</em>
	</div>
  </body>
</html>
`;
};

export default {
	async fetch(request, env) {
		const { searchParams } = new URL(request.url);
		let name = searchParams.get("name");

		if (!name) {
			return new Response("Please provide a name using the ?name= parameter");
		}

		const browser = await puppeteer.launch(env.BROWSER);
		const page = await browser.newPage();

		//단계 1: HTML과 CSS 정의
		const document = generateDocument(name);

		//// Step 2: HTML과 CSS를 브라우저로 전송
		await page.setContent(document);

		//// Step 3: PDF 생성 및 반환
		const pdf = await page.pdf({ printBackground: true });

		//더 이상 필요로하지 않기 때문에 브라우저 닫기
		await browser.close();

		return new Response(pdf, {
			headers: {
				"content-type": "application/pdf",
			},
		});
	},
};
```

## 사용자 정의 글꼴

PDF가 브라우저 렌더링 환경에서 사전 설치되지 않은 특정 글꼴을 필요로한다면 사용자 정의 글꼴을 사용하여로드 할 수 있습니다.`addStyleTag`. 이것은 CDN에서 글꼴을 주입하거나 PDF 생성하기 전에 Base64 문자열로 지정할 수 있습니다.

자세한 설명 및 예시, 참조[사용자 정의 글꼴 사용](/browser-rendering/reference/supported-fonts/#use-your-own-custom-font).

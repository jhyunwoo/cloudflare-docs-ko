오픈 그래프 (OG) 이미지는 소셜 미디어에 링크를 공유 할 때 나타나는 미리보기 이미지입니다. 수동으로 모든 블로그 게시물에 대한이 이미지를 생성하는 대신 Cloudflare 브라우저 렌더링을 사용하여 Astro 템플릿에서 브랜드 소셜 미리보기 이미지를 생성합니다.

이 튜토리얼에서:

1. OG 이미지 디자인을 렌더링하는 Astro 페이지를 만듭니다.
2. 브라우저 렌더링을 사용하여 스크린 샷을 PNG로 만듭니다.
3. 소셜 미디어 크롤러에 생성 된 이미지.

## 자주 묻는 질문

- Cloudflare 계정[브라우저 렌더링 활성화](/browser-rendering/get-started/#rest-api)
- Astro 사이트에 배포[Cloudflare Workers](/workers/framework-guides/web-apps/astro/)
- Astro 및 QXQX0074XQQ Workers를 가진 기본적인 친화성

## 1. OG 이미지 템플릿 만들기

OG 이미지 디자인을 렌더링하는 Astro 경로 만들기. 이 페이지는 이미지 레이아웃에 대한 진실의 소스 역할을합니다.

이름 \*`src/pages/social-card.astro`:

```astro
---
export const prerender = false;

const title = Astro.url.searchParams.get("title") || "Untitled";
const image = Astro.url.searchParams.get("image");
const author = Astro.url.searchParams.get("author");
---

<html>
	<head>
		<meta charset="utf-8" />
		<style>
			* {
				margin: 0;
				padding: 0;

			}
			body {
				width: 1200px;
				height: 630px;
				display: flex;
				flex-direction: column;
				justify-content: flex-end;
				padding: 60px;
				font-family: system-ui, sans-serif;
				background: linear-gradient(135deg, #f38020 0%, #f9a825 100%);
				color: white;
			}
			.title {
				font-size: 64px;
				font-weight: bold;
				line-height: 1.1;
				margin-bottom: 24px;
			}
			.author {
				font-size: 24px;

			}

```

템플릿을 테스트하려면 Astro 개발 서버를 시작하십시오.

```sh
npm run dev
```

자주 묻는 질문`http://localhost:4321/social-card?title=My%20Blog%20Post&author=Omar`.

:::참조

이 튜토리얼은 Markdown 게시물이 frontmatter 필드를 가정합니다.`title`, `slug`, 그리고 선택적으로`author`. 예를 들면:

```yaml
---
title: "My First Post"
slug: "my-first-post"
author: "John Doe"
---
```

조정하기`readPosts()`frontmatter 구조와 일치하기 위해 스크립트의 기능.

:::

진행하기 전에 사이트를 구축하여`/social-card`경로는:

```sh
#Cloudflare Workers를 위해
npx wrangler deploy
```

업데이트`BASE_URL`아래 스크립트에서 배포된 사이트 URL과 일치합니다.

## 2. 빌드 시간에 OG 이미지를 생성

Astro는 Cloudflare 브라우저 렌더링 REST API를 사용하여 모든 OG 이미지를 생성합니다.

이름 \*`scripts/generate-social-cards.ts`:

```ts
import { existsSync, mkdirSync, readdirSync, readFileSync, writeFileSync } from "fs";
import { join } from "path";

//제품 설명
const BASE_URL = "https://your-site.com"; // Your deployed site URL
const CF_API = "https://api.cloudflare.com/client/v4/accounts";
const OUTPUT_DIR = "public/social-cards"; //생성된 이미지에 대한 출력 디렉토리
const POSTS_DIR = "src/data/posts"; //Markdown 게시물을 포함하는 디렉토리 (당신의 프로젝트와 일치하는 것)

interface Post {
	slug: string;
	title: string;
	author?: string;
}

/** 익지않는 markdown 내용에서 frontmatter 분야 가치를 추출하십시오.*/
function getFrontmatterField(content: string, field: string): string | null {
	const match = content.match(new RegExp(`^${field}:\\s*"?([^"\\n]+)"?`, "m"));
	return match ? match[1].trim() : null;
}

/** 이름
* 모든 포스트 파일을 읽고 { slug, title, 저자 }[]를 반환합니다.
* 이 기능은 마크 다운 파일에 대한 POSTS DIR을 스캔하고 frontmatter를 추출합니다.
* 필드 (slug, 제목, 저자) 및 게시물 개체의 배열을 반환합니다.
* slug 및 slug에 대한 파일 이름에 뒤를 폴딩하면 frontmatter가 누락됩니다.*/
function readPosts(): Post[] {
	if (!existsSync(POSTS_DIR)) return [];
	const files = readdirSync(POSTS_DIR).filter((f) => f.endsWith(".md"));
	return files.map((file) => {
		const raw = readFileSync(join(POSTS_DIR, file), "utf-8");
		const slug = getFrontmatterField(raw, "slug") ?? file.replace(/\.md$/, "");
		const title = getFrontmatterField(raw, "title") ?? slug;
		const author = getFrontmatterField(raw, "author") ?? undefined;
		return { slug, title, author };
	});
}

/** 이름
* Cloudflare 브라우저 렌더링 REST API를 사용하여 스크린 샷 캡처*/
async function captureScreenshot(
	accountId: string,
	apiToken: string,
	pageUrl: string
): Promise<ArrayBuffer> {
	const endpoint = `${CF_API}/${accountId}/browser-rendering/screenshot`;

	const res = await fetch(endpoint, {
		method: "POST",
		headers: {
			Authorization: `Bearer ${apiToken}`,
			"Content-Type": "application/json",
		},
		body: JSON.stringify({
			url: pageUrl,
			viewport: { width: 1200, height: 630 }, //표준 OG 이미지 크기
			gotoOptions: { waitUntil: "networkidle0" }, //페이지가 완전히 로드
		}),
	});

	if (!res.ok) {
		const text = await res.text();
		throw new Error(`Screenshot API returned ${res.status}: ${text}`);
	}

	return res.arrayBuffer();
}

async function main() {
	//환경 변수에서 credentials 읽기
	const accountId = process.env.CF_ACCOUNT_ID;
	const apiToken = process.env.CF_API_TOKEN;

	if (!accountId || !apiToken) {
		console.error("Error: CF_ACCOUNT_ID and CF_API_TOKEN required");
		process.exit(1);
	}

	//--force 플래그가 모든 이미지를 재생하도록 전달되는 경우
	const force = process.argv.includes("--force");

	//markdown 파일에서 게시물을 읽으십시오
	const posts = readPosts();

	if (posts.length === 0) {
		console.log("No posts found. Check your POSTS_DIR path.");
		process.exit(0);
	}

	console.log(`Found ${posts.length} posts to process\n`);

	//출력 디렉토리를 확인합니다.
	mkdirSync(OUTPUT_DIR, { recursive: true });

	let generated = 0;
	let skipped = 0;

	//각 게시물에 대한 소셜 카드 생성
	for (let i = 0; i < posts.length; i++) {
		const post = posts[i];
		const outPath = join(OUTPUT_DIR, `${post.slug}.png`);
		const label = `[${i + 1}/${posts.length}]`;

		//파일이 존재하고 --force 플래그가 설정되지 않는 경우 Skip
		if (!force && existsSync(outPath)) {
			console.log(`${label} ${post.slug}.png — skipped (exists)`);
			skipped++;
			continue;
		}

		//OG 템플릿에 대한 쿼리 매개 변수와 URL 구축
		const params = new URLSearchParams({
			title: post.title,
			author: post.author || "",
		});
		const url = `${BASE_URL}/social-card?${params}`;

		try {
			//캡처 스크린 샷 및 파일 저장
			const png = await captureScreenshot(accountId, apiToken, url);
			writeFileSync(outPath, Buffer.from(png));
			console.log(`${label} ${post.slug}.png — done`);
			generated++;
		} catch (err) {
			console.error(`${label} ${post.slug}.png — failed:`, err);
		}

		//제한 속도 : 요청에 따라 작은 지연
		if (i < posts.length - 1) {
			await new Promise((resolve) => setTimeout(resolve, 200));
		}
	}

	console.log(`\nDone. Generated: ${generated}, Skipped: ${skipped}`);
}

main();
```

Cloudflare 자격 증명을 환경 변수로 설정:

```sh
export CF_ACCOUNT_ID=your_account_id
export CF_API_TOKEN=your_api_token
```

:::참조

브라우저 렌더링[비율 제한](/browser-rendering/limits/)계획에 따라 달라집니다. 스크립트에는 이러한 제한 내에서 체류하는 데 도움이되는 요청 사이에 200ms 지연이 포함됩니다. 큰 사이트를 위해, 당신은 배치에 스크립트를 실행해야합니다.

:::

이미지를 생성하기 위해 스크립트를 실행:

```sh
#새로운 이미지를 생성
bun scripts/generate-social-cards.ts

#모든 이미지를 재생
bun scripts/generate-social-cards.ts --force
```

선택적으로, 빌드 스크립트에 추가`package.json`:

```json
{
	"scripts": {
		"build": "bun scripts/generate-social-cards.ts && astro build"
	}
}
```

## 3. 페이지에 OG 메타 태그 추가

참고 자료에 블로그 게시물 레이아웃을 업데이트 생성 된 이미지 :

```astro
---
// src/layouts/BlogPost.astro
const { title, slug, author } = Astro.props;
const ogImageUrl = `/social-cards/${slug}.png`;
---

<html>
	<head>
		<meta property="og:title" content={title} />
		<meta property="og:image" content={ogImageUrl} />
		<meta property="og:image:width" content="1200" />
		<meta property="og:image:height" content="630" />
		<meta name="twitter:card" content="summary_large_image" />
		<meta name="twitter:image" content={ogImageUrl} />
	</head>
	<body>
		<slot />
	</body>
</html>
```

## 템플릿을 사용자 정의

### 배경 이미지 추가

```astro
---
const title = Astro.url.searchParams.get("title") || "Untitled";
const image = Astro.url.searchParams.get("image");
---

<body style={image ? `background-image: url(${image})` : undefined}>
	<!-- content -->
</body>
```

### 사용자 정의 글꼴 사용

```astro
<head>
	<link
		href="https://fonts.googleapis.com/css2?family=Inter:wght@700&display=swap"
		rel="stylesheet"
	/>
	<style>
		body {
			font-family: "Inter", sans-serif;
		}
	</style>
</head>
```

### Tailwind CSS 추가하기

Astro 사이트를 사용하는 경우, OG 템플릿에서 사용할 수 있습니다.

```astro
---
import "../styles/global.css";
---

<body
	class="flex h-[630px] w-[1200px] flex-col justify-end bg-gradient-to-br from-orange-500 to-amber-500 p-16 text-white"
>
	<h1 class="mb-6 text-6xl leading-tight font-bold">{title}</h1>
</body>
```

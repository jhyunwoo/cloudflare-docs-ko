<Plan type="workers-all" />

Browser Rendering은 개발자가 Cloudflare의 글로벌 네트워크에서 실행되는 헤더리스 브라우저 인스턴스와 프로그래밍할 수 있도록 합니다.

## 사용 사례

Programmatically 로드 및 완전히 동적 웹 페이지를 렌더링하거나 HTML을 캡처하고 다음과 같은 특정 출력을 캡처 :

- [옵션 정보](/browser-rendering/rest-api/markdown-endpoint/)
- [스크린샷](/browser-rendering/rest-api/screenshot-endpoint/)
- [PDF 파일](/browser-rendering/rest-api/pdf-endpoint/)
- [스냅샷](/browser-rendering/rest-api/snapshot/)
- [관련 기사](/browser-rendering/rest-api/links-endpoint/)
- [HTML 요소](/browser-rendering/rest-api/scrape-endpoint/)
- [구조화된 자료](/browser-rendering/rest-api/json-endpoint/)
- [웹 콘텐츠](/browser-rendering/rest-api/crawl-endpoint/)

## 키 기능

- **수천 개의 브라우저로 축소**: 낮은 콜드 스타트 시간, 높은 볼륨 스크린 샷 생성, 데이터 추출, 또는 스케일에서 자동화와 브라우저의 글로벌 풀에 즉시 액세스
- **기본적으로 Global**: 브라우저 세션은 Cloudflare의 가장자리 네트워크에서 실행되며, 전 세계 사용자들에게 더 나은 속도와 가용성을 제공합니다.
- **쉽게 통합**: [REST API](/browser-rendering/rest-api/)일반적인 행동을 위해, 동안[제품정보](/browser-rendering/puppeteer/)·[공유하기](/browser-rendering/playwright/)복잡한 워크플로우에 익숙한 자동화 라이브러리 제공
- **세션 관리**: [브라우저 세션 재사용](/browser-rendering/workers-bindings/reuse-sessions/)성능 향상 및 냉연 오버 헤드 감소
- **유연한 가격**: 관대한 무료 계층과 함께 사용되는 브라우저 시간 만 지불하십시오 ([가격 보기](/browser-rendering/pricing/))

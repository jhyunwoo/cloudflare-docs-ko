더 보기`/crawl`endpoint는 시작 URL에서 콘텐츠를 스크랩하고 사이트 전체에 대한 링크를 따르고, 구성 가능한 깊이 또는 페이지 제한까지. 응답은 HTML, Markdown 또는 JSON으로 반환될 수 있습니다.

## 끝점

```txt
https://api.cloudflare.com/client/v4/accounts/<account_id>/browser-rendering/crawl
```

## 관련 분야

- `url`(문자)

더 알아보기[옵션 매개 변수](/browser-rendering/rest-api/crawl-endpoint/#optional-parameters)추가 사용자 정의 옵션.

## 일반적인 사용 사례

- 지식베이스 또는 교육 AI 시스템 구축 (예 :[RAG 신청](/reference-architecture/diagrams/ai/ai-rag/)) 최신 웹 콘텐츠로
- 연구, summarization, 또는 감시를 위한 다수 페이지의 맞물림 및 분석 내용

## 어떻게 작동합니까?

두 단계가 있습니다.`/crawl`엔드포인트:

1. [크롤러 작업 시작](/browser-rendering/rest-api/crawl-endpoint/#initiate-the-crawl-job)— A`POST`당신은 크롤러를 시작 하 고 작업에 대 한 응답을 받을`id`.
2. [crawl 작업의 결과 요청](/browser-rendering/rest-api/crawl-endpoint/#request-results-of-the-crawl-job)— A`GET`해당 이용 후기에 달린 코멘트가 없습니다.

크롤 작업은 7 일의 최대 실행 시간이 있습니다. 이 시간 내에 끝나지 않는 경우에, 그것은 timeout 때문에 취소될 것입니다. 작업 결과는 작업 완료 후 14 일 동안 사용할 수 있습니다. 작업 데이터가 삭제 된 후.

:::노트\[무료 플랜 제한]
Workers 무료 플랜의 사용자는 추가 크롤러 특정 제한이 적용됩니다. 더 알아보기[크롤링 엔드포인트 제한](/browser-rendering/limits/#crawl-endpoint-limits)상세 정보
주요 특징

## 크롤러 작업 시작

이름 \*`POST`자주 묻는 질문`url`크롤러 작업 시작. API는 작업에 즉시 응답`id`검색 결과를 검색할 수 있습니다. 더 알아보기[옵션 매개 변수](/browser-rendering/rest-api/crawl-endpoint/#optional-parameters)추가 사용자 정의 옵션.

```bash
curl -X POST 'https://api.cloudflare.com/client/v4/accounts/{account_id}/browser-rendering/crawl' \
  -H 'Authorization: Bearer <apiToken>' \
  -H 'Content-Type: application/json' \
  -d '{
    "url": "https://developers.cloudflare.com/workers/"
  }'
```

예 응답:

```json output
{
  "success": true,
  "result": "c7f8s2d9-a8e7-4b6e-8e4d-3d4a1b2c3f4e"
}
```

## crawl 작업의 결과 요청

상태를 확인하거나 당신의 크롤러 작업의 결과를 요청하려면, 작업을 사용`id`당신은 받았습니다:

```bash
curl -X GET 'https://api.cloudflare.com/client/v4/accounts/{account_id}/browser-rendering/crawl/c7f8s2d9-a8e7-4b6e-8e4d-3d4a1b2c3f4e' \
  -H 'Authorization: Bearer YOUR_API_TOKEN'
```

응답은 포함`status`크롤러의 현재 상태를 나타내는 필드. 가능한 작업 상태는:

- `running`- 크롤러 작업은 현재 진행 중입니다.
- `cancelled_due_to_timeout`— 크롤러 작업은 7 일의 최대 실행 시간을 초과했습니다.
- `cancelled_due_to_limits`— 크롤링 작업이 타격했기 때문에 취소되었습니다.[계정 제한](/browser-rendering/limits/).
- `cancelled_by_user`- 크롤러 작업은 수동으로 사용자에 의해 취소되었습니다.
- `errored`— crawl 작업은 오류가 발생했습니다.
- `completed`— 크롤링 작업이 성공적으로 완료되었습니다.

### 완료를 위한 투표

crawl 작업이 비동기적으로 실행되기 때문에, 작업이 완료 될 때 확인하기 위해 endpoint 정기적으로 투표 할 수 있습니다. 더 보기`?limit=1`요청 URL에 따라서 응답은 경량 유지 — 당신은 작업 필요`status`, 크롤러 기록의 가득 차있는 세트 아닙니다.

```javascript
async function waitForCrawl(accountId, jobId, apiToken) {
  const maxAttempts = 60;
  const delayMs = 5000;

  for (let i = 0; i < maxAttempts; i++) {
    const response = await fetch(
      `https://api.cloudflare.com/client/v4/accounts/${accountId}/browser-rendering/crawl/${jobId}?limit=1`,
      {
        headers: {
          Authorization: `Bearer ${apiToken}`,
        },
      },
    );

    const data = await response.json();
    const status = data.result.status;

    if (status !== "running") {
      return data.result;
    }

    await new Promise((resolve) => setTimeout(resolve, delayMs));
  }

  throw new Error("Crawl job did not complete within timeout");
}
```

작업이 터미널 상태에 도달하면 전체 결과를 볼 수 있습니다.`limit`모수. 당신은 또한 다음과 같은 쿼리 매개 변수를 사용하여 필터 및 결과 paginate:

- `cursor`— 질에 대한 커서. 응답이 10 MB를 초과하면`cursor`값이 포함되어 있습니다. 다음에 결과를 검색하려면 쿼리 매개 변수로 전달하십시오.
- `limit`— 반환에 기록의 최대 수.
- `status`— URL 상태 필터:`queued`, `completed`, `disallowed`, `skipped`, `errored`, 또는`cancelled`.

쿼리 매개 변수와 예:

```bash
curl -X GET 'https://api.cloudflare.com/client/v4/accounts/{account_id}/browser-rendering/crawl/c7f8s2d9-a8e7-4b6e-8e4d-3d4a1b2c3f4e?cursor=10&limit=10&status=completed' \
  -H 'Authorization: Bearer YOUR_API_TOKEN'
```

## 크롤링 작업을 취소

현재 진행중인 크롤러 작업을 취소하려면 일자리를 사용하십시오.`id`당신은 받았습니다:

```bash
curl -X DELETE 'https://api.cloudflare.com/client/v4/accounts/{account_id}/browser-rendering/crawl/c7f8s2d9-a8e7-4b6e-8e4d-3d4a1b2c3f4e' \
  -H 'Authorization: Bearer YOUR_API_TOKEN'
```

성공적인 취소는 반환됩니다`200 OK`상태 코드. 작업 상태는 취소 될 것이며, 모든 URL은 크롤러가 취소 될 것입니다.

## 옵션 매개 변수

뒤에 오는 선택적인 모수는 당신의 크롤러 요구에, 필요에 더하여 사용될 수 있습니다`url`모수. 전체 목록은 참조[API 문서](/api/resources/browser_rendering/).

| 옵션 매개 변수                       | 제품정보    | 이름 \*                                                                                                                                                                                                                                    |
| ------------------------------ | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `limit`                        | 이름 \*   | 크롤러에 페이지의 최대 수 (기본은 10, 최대 100,000입니다).                                                                                                                                                                                                  |
| `depth`                        | 이름 \*   | 시작 URL에서 크롤러에 최대 링크 깊이 (기본은 100,000, 최대 100,000입니다).                                                                                                                                                                                     |
| `source`                       | 스트레이트   | URL을 발견하는 소스. 옵션은`all`, `sitemaps`, 또는`links`. 기본값은`all`.                                                                                                                                                                                |
| `formats`                      | 문자열의 배열 | 응답 형식 (기본 HTML, 다른 옵션은 Markdown 및 JSON입니다). JSON 형식 레버리지[모델 번호: Workers AI](/workers-ai/)기본적으로 Workers AI에 사용중인 데이터 추출. 더 알아보기[`/json`끝점](/browser-rendering/rest-api/json-endpoint/)사용자 정의 모델과 fallbacks를 사용하는 방법을 포함하여 더 많은 것을 배우기 위해. |
| `render`                       | 스낵 바    | false가 JavaScript를 실행하지 않고 빠른 HTML fetch를한다.[더 알아보기`render`](#render-parameter)).                                                                                                                                                        |
| `jsonOptions`                  | 계정 만들기  | 자주 묻는 질문`formats`기타`json`. 결론`prompt`, `response_format`·`custom_ai`속성 (같은 유형으로[`/json`끝점](/browser-rendering/rest-api/json-endpoint/)).                                                                                                 |
| `maxAge`                       | 이름 \*   | 초에 있는 시간의 최대 길이는 크롤러가 근원 서버 (과태는 86,400의 최대입니다 604,800입니다)에서 그것을 re-fetch 해야 하기 전에 캐시한 리소스를 사용할 수 있습니다. 캐시는 URL과 매개 변수가 정확히 일치하면 R2에서만 제공됩니다.                                                                                            |
| `modifiedSince`                | 이름 \*   | 유닉스 타임스탬프 (초) 이 시간 이후 수정 된 크롤 페이지 만 나타내는.                                                                                                                                                                                                |
| `options.includeExternalLinks` | 스낵 바    | 진정한 경우, 외부 도메인에 대한 링크를 따르십시오 (기본은 false입니다).                                                                                                                                                                                             |
| `options.includeSubdomains`    | 스낵 바    | 진정한 경우, 시작 URL의 하위 도메인에 대한 링크 (기본은 false입니다).                                                                                                                                                                                            |
| `options.includePatterns`      | 문자열의 배열 | 이 와일드 카드 패턴 중 하나를 일치하는 URL 만 방문. 제품 정보`*`문자를 제외하고는`/`, 또는`**`모든 문자와 일치`/`.                                                                                                                                                               |
| `options.excludePatterns`      | 문자열의 배열 | 이 와일드 카드 패턴의 일치 URL을 방문하지 않습니다. 제품 정보`*`문자를 제외하고는`/`, 또는`**`모든 문자와 일치`/`.                                                                                                                                                                |

### 패턴 행동

`excludePatterns`높은 우선권이 있습니다. URL이 규칙을 제외하면, 포함 규칙과 일치 여부에 관계없이 건너 뛸 수 있습니다.

- **규칙 없음**— 모든 것은 색인됩니다.
- **특별 할인**— 모두는 제외 패턴을 일치하는 항목을 제외하고 색인됩니다.
- **단지 포함**- 포함 된 패턴 만 일치하는 항목 만 색인; 다른 모든 것은 무시됩니다.

### 건너뛰기 URL

발견되었지만 건너뛰는 URL을 보시려면, crawl 작업 결과와 쿼리`status=skipped`. URL로 인해 건너 뛸 수 있습니다.`includeExternalLinks`, `includeSubdomains`, `includePatterns`/`excludePatterns`, 또는`modifiedSince`모수. Skipped URL은 향후 릴리스의 대시보드에서 볼 수 있습니다.

```bash
curl -X GET 'https://api.cloudflare.com/client/v4/accounts/{account_id}/browser-rendering/crawl/{job_id}?status=skipped' \
  -H 'Authorization: Bearer YOUR_API_TOKEN'
```

### `render`이름 \*

이용안내`render: true`기본값인 ,`crawl`endpoint는 머리없는 브라우저를 회전하고 페이지를 실행 JavaScript. 이용안내`render: false`·`crawl`endpoint는 JavaScript를 실행하지 않고 빠른 HTML fetch를 사용합니다.

제품 정보`render: true`페이지가 브라우저에서 콘텐츠를 구축 할 때. 제품 정보`render: false`초기 HTML 응답에 이미 필요한 콘텐츠를 할 때.

이용 약관`render: true`머리없는 브라우저를 사용하고 일반적인 브라우저 렌더링 가격 아래에 청구됩니다. 이용 약관`render: false`지원하다[Workers](/workers/)머리없는 브라우저 대신. 베타 중,`render: false`크롤러는 청구되지 않습니다. 베타 이후, 그들은 아래에 청구됩니다[Workers 가격](/workers/platform/pricing/).

### 모든 옵션 매개 변수를 가진 예

```bash
curl -X POST 'https://api.cloudflare.com/client/v4/accounts/{account_id}/browser-rendering/crawl' \

    "options": {
      "includeExternalLinks": true,
      "includeSubdomains": true,
      "includePatterns": [
        "**/api/v1/*"
      ],
      "excludePatterns": [
        "*/learning-paths/*"
      ]
    }
}'
```

### 제품 카탈로그 추출 AI

Extract Structured 제품 데이터 사용`json`파일 형식. 이 레버리지[Workers AI](/workers-ai/)기본적으로.

```bash
curl -X POST 'https://api.cloudflare.com/client/v4/accounts/{account_id}/browser-rendering/crawl' \
  -H 'Authorization: Bearer <apiToken>' \
  -H 'Content-Type: application/json' \
  -d '{
    "url": "https://shop.example.com/products",
    "limit": 50,
    "formats": ["json"],
    "jsonOptions": {
      "prompt": "Extract product name, price, description, and availability",
      "response_format": {
        "type": "json_schema",
        "json_schema": {
          "name": "product",
          "properties": {
            "name": "string",
            "price": "number",
            "currency": "string",
            "description": "string",
            "inStock": "boolean"
          }
        }
      }
    },
    "options": {
      "includePatterns": [
        "https://shop.example.com/products/*"
      ]
    }
  }'
```

```bash
      "visible": true
    }
  }'
```

### 블록 불필요한 자원

이미지와 미디어를 차단함으로써 가속화:

```bash
curl -X POST 'https://api.cloudflare.com/client/v4/accounts/{account_id}/browser-rendering/crawl' \
  -H 'Authorization: Bearer <apiToken>' \
  -H 'Content-Type: application/json' \
  -d '{
    "url": "https://example.com",
    "limit": 100,
    "rejectResourceTypes": [
      "image",
      "media",
      "font",
      "stylesheet"
    ]
  }'
```

## Crawler 행동

### 크롤러는 URL을 발견하는 방법

크롤러는 다음과 같은 순서로 URL을 발견하고 처리합니다 (사용 중`source: all`, 기본):

1. **URL을 시작**— 귀하의 요청에 지정된 URL.
2. **사이트 맵**- 사이트의 사이트 맵에서 발견 된 URL.
3. **페이지 링크**— 링크는 이미 사이트 맵에서 발견되지 않는 경우.

사용 방법`source`crawler 사용 소스를 사용자 정의 매개 변수. 사용 가능한 옵션은:

- `all`- 사이트 맵 및 페이지 링크 모두 사용 (기본).
- `sitemaps`- 사이트의 사이트 맵에서 발견 된 만 크롤러 URL.
- `links`- 페이지에 발견 된 만 크롤러 링크, ignoring sitemaps.

### robots.txt 및 봇 보호

더 보기`/crawl`endpoint는 지시어를 존중한다.`robots.txt`파일 등`crawl-delay`. 모든 URL은`/crawl`크롤링에 대한 지시는 응답에 나열되지 않습니다`"status": "disallowed"`. 구성에 대한 지침`robots.txt`사이트 맵은 크롤러 계획, 참조[robots.txt 및 사이트 맵](/browser-rendering/reference/robots-txt/).

:::caution\[Bot 보호는 크롤러를 막을지도 모릅니다]
브라우저 렌더링은 CAPTCHA를 우회하지 않습니다, Turnstile 도전, 또는 다른 봇 보호 메커니즘. 대상 사이트가 Cloudflare 제품을 사용하여 제어하거나 봇 트래픽을 제한하는 경우[Bot 관리](/bots/), [웹 응용 프로그램 방화벽 (WAF)](/waf/), 또는[모델 번호: Turnstile](/turnstile/), 같은 규칙은 브라우저 렌더링 크롤러에 적용됩니다.

자신의 사이트를 크롤링하고 무료로 액세스하려면 브라우저 렌더링을 원하면 WAF Skip 규칙을 만들 수 있습니다. 더 알아보기[How do I allowlist 브라우저 렌더링?](/browser-rendering/faq/#can-i-allowlist-browser-rendering-on-my-own-website)자주 묻는 질문

## 문제 해결

### Crawl 작업은 결과를 반환하거나 모든 URL은 건너 뛰기

crawl 작업이 완료되면 빈 레코드 배열을 반환하거나 모든 URL 표시`skipped`또는`disallowed`상태:

- **robots.txt 차단**— 크롤러 존중`robots.txt`이름 \* 더 보기`/crawl`endpoint는 스스로를 식별합니다.`CloudflareBrowserRenderingCrawler/1.0`. 대상 사이트 확인`robots.txt`이 사용자 에이전트를 확인하는 파일이 허용됩니다. 차단된 URL은 다음과 같습니다.`"status": "disallowed"`.
- **패턴 필터 너무 제한**- 당신의`includePatterns`사이트의 URL과 일치할 수 없습니다. URL을 발견 할 수 있도록 먼저 패턴없이 크롤링을 시도, 다음 패턴을 추가합니다.
- **자주 묻는 질문**— 시작 URL은 링크가 포함되지 않을 수 있습니다. 사용 방법`source: "sitemaps"`, 증가`depth`모수, 또는 조정`includeSubdomains`또는`includeExternalLinks`으로`true`.

### 크롤 작업 너무 긴

크롤러 작업이 남아있는 경우`running`장시간 기간을 위한 상태:

- **느린 페이지 짐**— Pages는 무거운 JavaScriptXQ를 가진 더 긴 연출합니다. 제품 정보`render: false`초기 HTML에 필요한 내용이 있다면.
- **비율 제한**— 엄격한 비율을 가진 위치는 느린 크롤러를 제한합니다. 크롤러 존중`robots.txt` `Crawl-delay`백오프를 구현합니다. 이름 \*`limit`여러 개의 작은 크롤러를 실행합니다.
- **관련 자료**— 콘텐츠 추출에 필요한 Block 리소스`rejectResourceTypes`(예:`image`, `media`, `font`).

### 제한으로 인해 크롤 작업 취소

·`cancelled_due_to_limits`상태는 귀하의 계정이 브라우저 시간 제한을 명중합니다.[Workers 무료 플랜](/browser-rendering/limits/#workers-free)계정은 하루에 10 분의 브라우저 사용으로 캡핑됩니다. 해결하기:

- [Workers로 업그레이드 유료 플랜](/workers/platform/pricing/)더 높은[제한 사항](/browser-rendering/limits/#workers-paid).
- 제품 정보`render: false`브라우저 시간을 피하기 위해 정적 콘텐츠.
- 더 보기`maxAge`가능한 결과를 사용할 수 있습니다.
- 더 읽기`limit`모수.

### JSON 추출 오류

만약에`json`형식 반환 null 또는 빈 결과:

- **명확한 신속한 제공**— 추출하고 페이지에 나타나는 데이터에 대해 특정하십시오 (예 : "제품 이름, 가격 및 주요 제품 섹션에서 설명 제외).
- **응답 schema를 정의**— 사용`response_format`JSON schema로 예상된 출력 구조를 시행합니다.
- **사용자 정의 모델 사용**- 기본값인 경우[Workers AI](/workers-ai/)모델은 원하는 결과를 생성하지 않습니다, 사용`custom_ai`다른 모델을 지정하는 매개 변수. 더 알아보기[사용자 정의 모델 사용 (BYO API Key)](/browser-rendering/rest-api/json-endpoint/#using-a-custom-model-byo-api-key)상세 정보

질문이나 다른 오류가 발생하면, 참조[브라우저 렌더링 FAQ 및 문제 해결 가이드](/browser-rendering/faq/).

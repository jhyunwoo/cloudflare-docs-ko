더 보기`/markdown`endpoint는 웹 페이지의 콘텐츠를 검색하고 Markdown 형식으로 변환합니다. URL과 옵션 파라미터를 지정할 수 있습니다.

<Render file="rest-api-token-permissions" product="browser-rendering" />

## 끝점

```txt
https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/markdown
```

## 관련 분야

자주 묻는 질문`url`또는`html`:

- `url`(문자)
- `html`(문자)

## 일반적인 사용 사례

- 다운스트림 처리를위한 정상적인 내용 (summaries, diffs, embeddings)
- 문서 저장 또는 문서 편집 또는 저장
- 스트립 스타일링 / 기술 및 읽기 쉬운 내용 + 링크 유지

## 기본 사용

### URL을 Markdown로 변환

### Raw HTML을 Markdown로 변환

URL을 지정하여 콘텐츠를 fetching 대신, HTML 콘텐츠를 직접 제공 할 수 있습니다.

```bash
curl -X 'POST' 'https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/markdown' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <apiToken>' \
  -d '{
    "html": "<div>Hello World</div>"
  }'
```

```json output
{
	"success": true,
	"result": "Hello World"
}
```

## 고급 사용

자주 묻는 질문[브라우저 렌더링 API 참고 자료](/api/resources/browser_rendering/subresources/markdown/methods/create/)HTTP credentials 설정과 같은 모든 사용 가능한 매개 변수에 대해`authenticate`, 설정`cookies`, 및 사용자 정의 로드 동작 사용`gotoOptions`.

### 원치 않는 요청 제외 (예를 들어, CSS)

Markdown 추출을 사용하여 제거 할 수 있습니다.`rejectRequestPattern`모수. 이 예에서 주어진 regex 패턴 (예 : CSS 파일)과 일치하는 요청은 제외됩니다.

```bash
curl -X 'POST' 'https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/markdown' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <apiToken>' \
  -d '{
    "url": "https://example.com",
    "rejectRequestPattern": ["/^.*\\.(css)/"]
  }'
```

```json output
{
	"success": true,
	"result": "# Example Domain\n\nThis domain is for use in illustrative examples in documents. You may use this domain in literature without prior coordination or asking for permission.\n\n[More information...](https://www.iana.org/domains/example)"
}
```

더 보기`/pdf`브라우저가 Cloudflare의 머리없는 브라우저 렌더링 서비스를 사용하여 웹 페이지 또는 사용자 정의 HTML의 PDF를 생성하도록 지시합니다.

<Render file="rest-api-token-permissions" product="browser-rendering" />

## 끝점

```txt
https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/pdf
```

## 관련 분야

자주 묻는 질문`url`또는`html`:

- `url`(문자)
- `html`(문자)

## 일반적인 사용 사례

- 웹 페이지의 PDF 캡처
- 문서, 라이선스, 보고서, 인증서 등 PDF 생성

## 기본 사용

### URL을 PDF로 변환

<Tabs syncKey="workersExamples">
  <TabItem label="컬럼">
    바로가기`https://example.com/`그리고 사용자 정의 CSS 및 외부 스타일 시트를 주사합니다. 그런 다음 렌더링 된 페이지를 PDF로 반환합니다.

    ```bash
    curl -X POST 'https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/pdf' \
      -H 'Authorization: Bearer <apiToken>' \
      -H 'Content-Type: application/json' \
      -d '{
        "url": "https://example.com/",
        "addStyleTag": [
          { "content": "body { font-family: Arial; }" }
        ]
      }' \
      --output "output.pdf"
    ```
  </TabItem>

  <TabItem label="TypeScript SDK 지원">
    ```typescript
    import Cloudflare from "cloudflare";

    const client = new Cloudflare({
    	apiToken: process.env["CLOUDFLARE_API_TOKEN"],
    });

    const pdf = await client.browserRendering.pdf.create({
    	account_id: process.env["CLOUDFLARE_ACCOUNT_ID"],
    	url: "https://example.com/",
        addStyleTag: [
            { content: "body { font-family: Arial; }" }
        ]
    });

    console.log(pdf);

    const content = await pdf.blob();
    console.log(content);
    ```
  </TabItem>

### HTML을 PDF로 변환

원시 HTML이 있다면 PDF를 생성합니다.`html`옵션. 당신은 아직도 사용자 정의 스타일을 적용 할 수 있습니다`addStyleTag`모수.

```bash
curl -X POST https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/pdf \
  -H 'Authorization: Bearer <apiToken>' \
  -H 'Content-Type: application/json' \
  -d '{
  "html": "<html><body>Advanced Snapshot</body></html>",
	"addStyleTag": [
      { "content": "body { font-family: Arial; }" },
      { "url": "https://cdn.jsdelivr.net/npm/bootstrap@3.3.7/dist/css/bootstrap.min.css" }
    ]
}' \
  --output "invoice.pdf"
```

:::노트\[Request size limits]
PDF 엔드포인트는 최대 50MB의 요청체를 허용합니다. 이보다 더 큰 요청은 실패합니다.`Error: request entity too large`.
:::

## 고급 사용

:::note\[더 많은 매개 변수를 찾고?]
자주 묻는 질문[브라우저 렌더링 API 참고 자료](/api/resources/browser_rendering/subresources/pdf/methods/create/)HTTP credentials 설정과 같은 모든 사용 가능한 매개 변수에 대해`authenticate`, 설정`cookies`, 및 사용자 정의 로드 동작 사용`gotoOptions`.
:::

### 사용자 정의 헤더 및 viewport 고급 페이지로드

바로가기`https://example.com`, 추가 HTTP 헤더 설정 및 페이지 크기 설정 (viewport). PDF 생성은 적어도 500 ms를 위한 2개의 네트워크 연결이 없을 때까지 기다릴 것입니다, 또는 4500 ms의 최대 타임아웃은, 렌더링하기 전에 도달됩니다.

더 보기`goToOptions`매개 변수는 대부분의 노출[Puppeteer의 API](https://pptr.dev/api/puppeteer.gotooptions).

```bash
curl -X POST 'https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/pdf' \
  -H 'Authorization: Bearer <apiToken>' \
  -H 'Content-Type: application/json' \
  -d '{
    "url": "https://example.com/",
    "setExtraHTTPHeaders": {
      "X-Custom-Header": "value"
    },
    "viewport": {
      "width": 1200,
      "height": 800
    },
    "gotoOptions": {
      "waitUntil": "networkidle2",
      "timeout": 45000
    }
  }' \
  --output "advanced-output.pdf"
```

### PDF 생성시 이미지와 스타일을 차단

옵션 정보`rejectResourceTypes`·`rejectRequestPattern`렌더링 중에 요청을 차단하는 데 사용할 수 있습니다. 반대도 할 수 있습니다,*한국어*자주 묻는 질문`allowResourceTypes`·`allowRequestPattern`.

```bash
curl -X POST https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/pdf \
  -H 'Authorization: Bearer <apiToken>' \
  -H 'Content-Type: application/json' \
  -d '{
  "url": "https://cloudflare.com/",
  "rejectResourceTypes": ["image"],
  "rejectRequestPattern": ["/^.*\\.(css)"]
}' \
  --output "cloudflare.pdf"
```

### 사용자 정의 페이지 헤더 및 footers

페이지를 사용자 정의 할 수 있습니다. 헤더와 footers HTML 템플릿을 사용하여`headerTemplate`·`footerTemplate`옵션. 이름 \*`displayHeaderFooter`출력에 포함. 이 예제는 브랜드 헤더, footer 메시지 및 페이지 번호로 A5 PDF를 생성합니다.

```bash
curl -X POST 'https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/pdf' \
  -H 'Authorization: Bearer <apiToken>' \
  -H 'Content-Type: application/json' \
  -d '{
    "url": "https://example.com",
    "pdfOptions": {
      "format": "a5",
      "headerTemplate": "<div style=\"font-size: 10px; text-align: center; width: 100%; padding: 5px;\"><span>brand name</span></div>",
      "displayHeaderFooter": true,
      "footerTemplate": "<div style=\"color: lightgray; border-top: solid lightgray 1px; font-size: 10px; padding-top: 5px; text-align: center; width: 100%;\"><span>This is a test message</span> - <span class=\"pageNumber\"></span></div>",
      "margin": {
        "top": "70px",
        "bottom": "70px"
      }
    }
  }' \
  --output "header-footer.pdf"
```

### 페이지 metadata에서 동적 플레이스 홀더 포함

동적 위주자를 포함할 수 있습니다.`title`, `date`, `pageNumber`·`totalPages`header 또는 footer에서 각 페이지의 metadata를 표시합니다. 이 예제는 회사 브랜드 헤드러, 현재 날짜 및 제목, 발러의 페이지 번호와 A4 PDF를 생성합니다.

```bash
curl -X POST 'https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/pdf' \
  -H 'Authorization: Bearer <apiToken>' \
  -H 'Content-Type: application/json' \
  -d '{
    "url": "https://news.ycombinator.com",
    "pdfOptions": {
      "format": "a4",
      "landscape": false,
      "printBackground": true,
      "preferCSSPageSize": true,
      "displayHeaderFooter": true,
      "scale": 1.0,
      "headerTemplate": "<div style=\"width: 100%; font-size: 10px; padding: 10px; text-align: center;\"><div style=\"border-bottom: 1px solid #ddd;\"><span style=\"color: #666;\">회사명</span> |<span class=\"date\"></span> | <span class=\"title\"></span></div></div>
      "footerTemplate": "<div style=\"width: 100%; font-size: 10px; padding: 10px; text-align: center;\"><div style=\"border-top: 1px solid #ddd;\">페이지 <span class="pageNumber"></span> <span class="totalPages"></span></div></div>
      "margin": {
        "top": "100px",
        "bottom": "80px",
        "right": "30px",
        "left": "30px"
      },
      "timeout": 30000
    }
  }' \
  --output "dynamic-header-footer.pdf"
```

### 사용자 정의 글꼴 사용

PDF가 브라우저 렌더링 환경에서 사전 설치되지 않은 글꼴이 필요하면 사용자 정의 글꼴을 사용하여로드 할 수 있습니다.`addStyleTag`모수. 지침 및 예시, 참조[사용자 정의 글꼴 사용](/browser-rendering/reference/supported-fonts/#rest-api).

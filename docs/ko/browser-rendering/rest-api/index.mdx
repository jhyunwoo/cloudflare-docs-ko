REST API는 HTML 콘텐츠 추출, PDF 생성 등 일반적인 브라우저 작업을 위한 엔드포인트를 제공하는 RESTful 인터페이스입니다.
다음은 유효한 옵션입니다:

import { DirectoryListing } from "~/components";

<DirectoryListing />

REST API를 사용하면 스크린 샷 캡처, HTML 추출 또는 복잡한 스크립트를 작성하지 않고 PDF 생성과 같은 일반적인 브라우저 작업을 수행하는 빠르고 간단한 방법이 필요합니다. 고급 자동화, 사용자 정의 워크플로우, 또는 지속적인 브라우저 세션이 필요한 경우[Workers 회사 소개](/browser-rendering/workers-bindings/)더 나은 선택입니다.

## 시작하기 전에

시작하기 전에, 확인[사용자 정의 API 토큰 만들기](/fundamentals/api/get-started/create-token/)다음과 같은 권한을 가진:

- `Browser Rendering - Edit`

:::주\[주]

두 가지 방법으로 브라우저 렌더링 사용을 모니터링 할 수 있습니다:

- Cloudflare 대시보드에서, 가십시오**브라우저 렌더링**총 REST API 요청 및 총 브라우저 시간을 포함하여 집계 지표를 볼 수 있습니다.
  <DashButton url="/?to=/:account/workers/browser-rendering" />
- `X-Browser-Ms-Used`헤더: 모든 REST API 응답에서 반환, 그 요청에 사용되는 브라우저 시간을보고 (밀리 초).

:::

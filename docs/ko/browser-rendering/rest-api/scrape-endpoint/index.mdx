더 보기`/scrape`endpoint는 웹 페이지의 특정 요소에서 구조화 된 데이터를 추출하고 요소 치수 및 내부 HTML과 같은 세부 정보를 반환합니다.

<Render file="rest-api-token-permissions" product="browser-rendering" />

## 끝점

```txt
https://api.cloudflare.com/client/v4/accounts/<accountId>/browser-rendering/scrape
```

## 관련 분야

자주 묻는 질문`url`또는`elements`:

- `url`(문자)
- `elements`(물자의 레이) - 각 개체는 포함해야합니다`selector`(문자)

## 일반적인 사용 사례

- headings, 링크, 가격, 또는 CSS selectors와 다른 반복된 내용 추출
- metadata 수집 (예, 제목, 설명, canonical 링크)

## 기본 사용

### URL에서 headings 및 링크 추출

HTTP credentials 설정과 같은 많은 옵션이 존재합니다.`authenticate`, 설정`cookies`, 및 사용`gotoOptions`페이지로드 동작을 제어하기 위해 - endpoint를 확인[참고 자료](/api/resources/browser_rendering/subresources/scrape/methods/create/)모든 유효한 모수를 위해.

### 응답 분야

- `results` *(물자의 레이)*- 각 선택자를 위한 추출된 자료를 포함합니다.
  - `selector` *(문자)*- CSS 선택기 사용.
  - `results` *(물자의 레이)*- selector와 일치하는 추출 된 요소 목록.
    - `text` *(문자)*- 요소의 내부 텍스트.
    - `html` *(문자)*- 요소의 내부 HTML.
    - `attributes` *(물자의 레이)*- 추출된 속성 목록`href`링크입니다.
    - `height`, `width`, `top`, `left` *(번호)*- 요소의 위치 및 치수.

## 고급 사용

:::

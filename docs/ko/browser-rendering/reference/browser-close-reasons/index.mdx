브라우저 세션은 다양한 이유로 닫을 수 있습니다, 때때로 연결 오류 또는 오류로 인해 헤더 브라우저 인스턴스. 최고의 연습으로, 랩`puppeteer.connect`또는`puppeteer.launch`로그인[`try/catch`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/try...catch)이름 \*

브라우저가 닫히는 이유를 찾으려면:

1. Cloudflare 대시보드에서, 가십시오**브라우저 렌더링**사이트 맵

   <DashButton url="/?to=/:account/workers/browser-rendering" />

2. 선택하기**로그인**탭.

브라우저 렌더링 세션은 청구됩니다.[제품 정보](/browser-rendering/pricing/). 브라우저 렌더링 인프라로 인해 오류가 발생하는 세션에 대해 책임을 지지 않습니다.

| 세션이 종료될 수 있습니다.           |
| ------------------------- |
| 사용자는 일반적으로 브라우저를 열고 닫습니다. |
| 브라우저는 60 초 동안 idle입니다.    |
| 크롬 인스턴스 충돌.               |
| 클라이언트, 서버 또는 작업자와의 오류 연결. |
| 브라우저 세션은 evicted입니다.      |

[Wrangler](/workers/wrangler/)Cloudflare 개발자 제품으로 건물을 위한 명령행 도구입니다.

Wrangler를 사용하여 Workers 브라우저 렌더링 API를 사용하여 프로젝트를 배포합니다.

## 설치하기

Wrangler를 설치하려면[설치 및 업데이트 Wrangler](/workers/wrangler/install-and-update/).

## 회사 소개

[회사 소개](/workers/runtime-apis/bindings/)Workers는 Cloudflare 개발자 플랫폼에 리소스와 상호 작용할 수 있습니다. 브라우저 바인딩은 전용 Chromium 브라우저 인스턴스와 상호 작용하기 위해 인증된 엔드포인트를 사용하여 작업자를 제공합니다.

Browser Rendering Worker를 배포하려면 선언해야 합니다.[브라우저 바인딩](/workers/runtime-apis/bindings/)당신의 노동자의 Wrangler 윤곽 파일에서.

<Render file="nodejs-compat-howto" product="workers" />

<WranglerConfig>
  ```jsonc
  {
  	"$schema": "./node_modules/wrangler/config-schema.json",
  	//Top-level 구성
  	"name": "browser-rendering",
  	"main": "src/index.ts",
  	"workers_dev": true,
  	"compatibility_flags": [
  		"nodejs_compat_v2"
  	],
  	"browser": {
  		"binding": "MYBROWSER"
  	}
  }
  ```
</WranglerConfig>

바인딩이 선언 된 후 DevTools endpoint에 액세스하십시오.`env.MYBROWSER`당신의 노동자 부호에서:

```javascript
const browser = await puppeteer.launch(env.MYBROWSER);
```

지원하다`npx wrangler dev`작업자를 로컬로 테스트합니다.

Browser Rendering은 표준 글꼴 세트를 포함하는 관리 Chromium 환경을 사용합니다. 스크린 샷 또는 PDF를 생성할 때 텍스트는이 환경에서 사용할 수있는 글꼴을 사용하여 렌더링됩니다.

웹 페이지가 아직 지원되지 않은 글꼴을 지정하면 Chromium은 유사한 지원 글꼴로 자동으로 떨어지게됩니다. 현재 지원되지 않은 글꼴을 사용하고 싶다면, 참조[사용자 정의 글꼴](/browser-rendering/features/custom-fonts/).

## 사전 설치된 글꼴

다음 섹션은 Browser Rendering 환경에서 사용할 수있는 글꼴을 나열합니다.

### 일반 CSS 폰트 가족 지원

다음과 같은 일반적인 CSS 글꼴 제품군은 지원됩니다.

- `serif`
- `sans-serif`
- `monospace`
- `cursive`
- `fantasy`

### 일반 시스템 글꼴

- Andale 단청
- 아리아
- Arial 검정
- 만화 산 MS
- 채용정보
- Courier 새로운
- 주요 특징
- 헬베티카
- 제품정보
- 루시다 Handwriting
- 런닝타임
- 타임즈 뉴 로마
- 트레버치 MS
- 베다나
- 웹딩

### 오픈 소스 및 확장 글꼴

- Bitstream Vera (Serif, 산, 모노)
- 비밀번호
- DejaVu (Serif, 산, 모노)
- FreeFont (FreeSerif, FreeSans, 프리모노)
- GFS 네오넬닉
- Liberation (Serif, 산, 모노)
- 산을 열기
- 채용정보

### 국제 폰트

Browser Rendering에는 비 라틴 스크립트 및 이모티콘에 대한 추가 글꼴 패키지가 포함되어 있습니다.

- IPAfont 고딕 (일본어)
- Indic 글꼴 (Devanagari, Bengali, 타밀 및 기타)
- KACST 글꼴 (아라빅)
- Noto CJK (중국어, 일본어, 한국어)
- Noto 색깔 Emoji
- 사이트맵 태국 폰트
- WenQuanYi Zen Hei (중국어)

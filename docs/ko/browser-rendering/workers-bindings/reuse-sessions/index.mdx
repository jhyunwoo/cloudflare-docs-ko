브라우저 렌더링 작업자의 성능을 향상시키는 가장 좋은 방법은 세션을 재사용하는 것입니다. 한 가지 방법[모델 번호: Durable Objects](/browser-rendering/workers-bindings/browser-rendering-with-do/)Worker에서 브라우저로 긴 실행 연결을 유지할 수 있습니다. 또 다른 방법은 브라우저가 그것을 완료 한 후 열리고, 새 요청이 있으면 세션에 연결됩니다.

짧은, 이 entails 사용`browser.disconnect()`대신에`browser.close()`, 그리고, 사용 가능한 세션이 있다면`puppeteer.connect(env.MY_BROWSER, sessionID)`대신 새로운 브라우저 세션을 시작합니다.

## 1. Worker 프로젝트 만들기

[Cloudflare Workers](/workers/)configuring나 유지 인프라 없이 새로운 애플리케이션 또는 augment 기존의 하나들을 만들 수 있는 Serverless 실행 환경을 제공합니다. 작업자 응용 프로그램은 스크린 샷을 복용과 같은 행동을 수행하는 헤드리스 브라우저와 상호 작용하는 용기입니다.

## 4. 부호

아래 스크립트는 현재 실행 세션을 fetching. 이미 노동자 연결이 없다면 임의 세션 ID를 선택하고 연결 시도하십시오 (`puppeteer.connect(..)`) 그것에. 실패 또는 실행 세션이 없으면 새로운 브라우저 세션을 시작합니다 (`puppeteer.launch(..)`). 그때, 그것은 웹 사이트로 이동하고 dom을 fetches. 완료되면, 그것은 분리 (`browser.disconnect()`), 다른 노동자에 유효한 연결을 만들기.

브라우저가 idle인 경우, i.e.는 현재 어떤 명령을 얻지 못합니다.[지원하다](/browser-rendering/limits/), 그것은 자동적으로 닫을 것입니다, 그래서 당신은 그것을 살아야 할 분 당 충분한 요구가 있어야 합니다.

<TypeScriptExample>
  ```ts
  import puppeteer from "@cloudflare/puppeteer";

  interface Env {
  	MYBROWSER: Fetcher;
  }

  export default {
  	async fetch(request: Request, env: Env): Promise<Response> {
  		const url = new URL(request.url);
  		let reqUrl = url.searchParams.get("url") || "https://example.com";
  		reqUrl = new URL(reqUrl).toString(); //일반화

  		//열린 세션에서 무작위 세션을 선택합니다.
  		let sessionId = await this.getRandomSession(env.MYBROWSER);
  		let browser, launched;
  		if (sessionId) {
  			try {
  				browser = await puppeteer.connect(env.MYBROWSER, sessionId);
  			} catch (e) {
  				//다른 노동자는 첫째로 연결될지도 모릅니다
  				console.log(`Failed to connect to ${sessionId}. Error ${e}`);
  			}
  		}
  		if (!browser) {
  			//오픈 세션 없음, 새 세션 시작
  			browser = await puppeteer.launch(env.MYBROWSER);
  			launched = true;
  		}

  		sessionId = browser.sessionId(); //현재 세션 ID

  		//당신의 일을 여기
  		const page = await browser.newPage();
  		const response = await page.goto(reqUrl);
  		const html = await response!.text();

  		//모든 일, 그래서 무료 연결 (IMPORTANT!)
  		browser.disconnect();

  		return new Response(
  			`${launched ? "Launched" : "Connected to"} ${sessionId} \n-----\n` + html,
  			{
  				headers: {
  					"content-type": "text/plain",
  				},
  			},
  		);
  	},

  	//무작위 무료 세션
  	//다른 주문 논리는 대신 사용될 수 있었습니다
  	async getRandomSession(endpoint: puppeteer.BrowserWorker): Promise<string> {
  		const sessions: puppeteer.ActiveSession[] =
  			await puppeteer.sessions(endpoint);
  		console.log(`Sessions: ${JSON.stringify(sessions)}`);
  		const sessionsIds = sessions
  			.filter((v) => {
  				return !v.connectionId; //노동자와 함께 세션을 제거
  			})
  			.map((v) => {
  				return v.sessionId;
  			});
  		if (sessionsIds.length === 0) {
  			return;
  		}

  		const sessionId =
  			sessionsIds[Math.floor(Math.random() * sessionsIds.length)];

  		return sessionId!;
  	},
  };
  ```
</TypeScriptExample>

기타`puppeteer.sessions()`, 우리는 촉진하는 다른 방법을 추가했습니다[세션 관리](/browser-rendering/puppeteer/#session-management).

## 6. 배포

지원하다`npx wrangler deploy`Cloudflare 글로벌 네트워크에 Worker를 배포하고 다음 URL로 이동하십시오.

`<YOUR_WORKER>.<YOUR_SUBDOMAIN>.workers.dev/?url=https://example.com`

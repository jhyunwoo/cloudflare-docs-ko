Workers 바인딩은 Cloudflare Workers 내에서 고급 브라우저 렌더링 스크립트를 실행할 수 있습니다. 개발자는 복잡한 워크플로우와 브라우저 상호 작용을 자동화하고 제어할 수 있는 유연성을 제공합니다. 다음 옵션은 브라우저 렌더링 작업을 사용할 수 있습니다:

<DirectoryListing />

사용 Workers 기본 렌더링을 넘어 고급 브라우저 자동화, 사용자 정의 워크플로우 또는 복잡한 상호 작용을 필요로 할 때 바인딩. 빠른 경우, 스크린 샷 캡처 또는 HTML 추출과 같은 하나의 작업,[REST API를](/browser-rendering/rest-api/)간단한 선택입니다.

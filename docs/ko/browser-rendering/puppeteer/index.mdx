[제품정보](https://pptr.dev/)개발자의 저수준 DevTools 프로토콜을 초록하는 가장 인기있는 라이브러리 중 하나이며 Chrome/Chromium 및 Automate 브라우징 세션을 쉽게 사용할 수있는 고급 API를 제공합니다. Puppeteer는 스크린 샷, 크롤링 페이지 및 웹 응용 프로그램을 생성하고 같은 작업을 위해 사용됩니다.

Puppeteer는 일반적으로 DevTools 포트를 사용하여 로컬 크롬 또는 크롬 브라우저에 연결됩니다. 더 알아보기[Puppeteer API 문서`Puppeteer.connect()`제품 설명](https://pptr.dev/api/puppeteer.puppeteer.connect)더 많은 정보.

Workers 팀은 Puppeteer의 버전을 위조하고 대신 Workers 브라우저 렌더링 API에 연결하기 위해 패치되었습니다. 연결 후에, 개발자는 그 후에 충분히 사용할 수 있습니다[공급 업체 API](https://github.com/cloudflare/puppeteer/blob/main/docs/api/index.md)그들은 표준 설정에있을 것입니다.

우리의 버전은 열려있는 sourced이고에서 찾아낼 수 있습니다[Cloudflare의 포크](https://github.com/cloudflare/puppeteer). npm는 설치될 수 있습니다[프로젝트](https://www.npmjs.com/)이름 \*[@클라우드/puppeteer](https://www.npmjs.com/package/@cloudflare/puppeteer):

<PackageManagers pkg="@cloudflare/puppeteer" dev />

:::참조
현재 버전은[`@cloudflare/puppeteer`v1.0.4의](https://github.com/cloudflare/puppeteer/releases/tag/v1.0.4), 기반[파이터 v22.13.1](https://pptr.dev/chromium-support).
:::

## 노동자에 Puppeteer 사용

한 번에[브라우저 바인딩](/browser-rendering/reference/wrangler/#bindings)구성 및`@cloudflare/puppeteer`라이브러리는 설치, Puppeteer는 노동자에 사용될 수 있습니다:

<TypeScriptExample>
  ```ts
  import puppeteer from "@cloudflare/puppeteer";

  interface Env {
  	MYBROWSER: Fetcher;
  }

  export default {
  	async fetch(request, env): Promise<Response> {
  		const browser = await puppeteer.launch(env.MYBROWSER);
  		const page = await browser.newPage();
  		await page.goto("https://example.com");
  		const metrics = await page.metrics();
  		await browser.close();
  		return Response.json(metrics);
  	},
  } satisfies ExportedHandler<Env>;
  ```
</TypeScriptExample>

이 스크립트[출시일](https://pptr.dev/api/puppeteer.puppeteernode.launch)이름 \*`env.MYBROWSER`브라우저, 열다[새 페이지](https://pptr.dev/api/puppeteer.browser.newpage), [계속하기](https://pptr.dev/api/puppeteer.page.goto) [https://example.com/](https://example.com/), 페이지 부하를 가져옵니다[미터](https://pptr.dev/api/puppeteer.page.metrics), [이름 \*](https://pptr.dev/api/puppeteer.browser.close)브라우저 및 JSON의 메트릭을 인쇄합니다.

### 계속 Alive

사용자가 omit을 하는 경우`browser.close()`문, 그것은 열려있을 것입니다, 다시 연결될 준비하고[재사용](/browser-rendering/workers-bindings/reuse-sessions/)그러나 기본적으로, 불완전의 1 분 후에 자동적으로 닫을 것입니다. 사용자는 10 분까지 이 idle 시간을, 사용해서 선택적으로 늘릴 수 있습니다`keep_alive`옵션, 밀리 초에서 설정:

```js
const browser = await puppeteer.launch(env.MYBROWSER, { keep_alive: 600000 });
```

위와 같이 브라우저는 최대 10 분 동안 열려있을 것입니다.

:::참조
이것은 inactivity timeout, 최대 세션 기간입니다. 세션은 10 분보다 오래 지속될 수 있습니다. inactivity timeout을 넘어 세션을 계속 유지하려면, 구성된 창 내에서 적어도 한 번 명령을 보내 (예를 들어, 10 분마다). 더 알아보기[세션 기간 제한](/browser-rendering/limits/#is-there-a-maximum-session-duration)더 많은 정보.
주요 특징

### 사용자 정의 에이전트 설정

Puppeteer의 사용자 에이전트를 지정하려면`page.setUserAgent()`방법. 대상 웹 사이트가 사용자 에이전트에 따라 다른 콘텐츠를 제공 하는 경우 유용합니다.

```js
await page.setUserAgent(
  "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/119.0.0.0 Safari/537.36"
);
```

:::참조
더 보기`userAgent`매개변수는 bot 보호를 우회하지 않습니다. 브라우저 렌더링에서 요청은 항상 봇으로 식별됩니다.
주요 특징

## 성분 선택

Puppeteer는 페이지의 선택 요소에 대한 여러 가지 방법을 제공합니다. CSS 선택기는 예상대로 작동하지만, XPath 선택자는 Workers 실행 시간에 보안 제약으로 인해 지원되지 않습니다.

Xpath selectors 대신 CSS selectors를 사용할 수 있습니다.`page.evaluate()`브라우저에서 XPath 쿼리를 실행하려면:

```ts
const innerHtml = await page.evaluate(() => {
	return (
		//@ts-ignore 이 브라우저에서 실행
		new XPathEvaluator()
			.createExpression("/html/body/div/h1")
			//@ts-ignore 이 브라우저에서 실행
			.evaluate(document, XPathResult.FIRST_ORDERED_NODE_TYPE).singleNodeValue
			.innerHTML
	);
});
```

:::참조

`page.evaluate()`문자열, 숫자 및 불린과 같은 원시 유형만 반환할 수 있습니다. 같은 복잡한 개체를 반환`HTMLElement`일하지 않습니다.

:::

## 세션 관리

브라우저 세션 관리를 용이하게하려면 새로운 방법을 추가했습니다.`puppeteer`:

### 열린 세션

`puppeteer.sessions()`현재 실행 세션을 나열합니다. 그것은 이것과 유사한 산출을 돌려보낼 것입니다:

```json
[
	{
		"connectionId": "2a2246fa-e234-4dc1-8433-87e6cee80145",
		"connectionStartTime": 1711621704607,
		"sessionId": "478f4d7d-e943-40f6-a414-837d3736a1dc",
		"startTime": 1711621703708
	},
	{
		"sessionId": "565e05fb-4d2a-402b-869b-5b65b1381db7",
		"startTime": 1711621703808
	}
]
```

세션 공지`478f4d7d-e943-40f6-a414-837d3736a1dc`활성 노동자 연결 (Active worker connection)`connectionId=2a2246fa-e234-4dc1-8433-87e6cee80145`), 세션`565e05fb-4d2a-402b-869b-5b65b1381db7`무료. 연결이 활성화되어 있지만 다른 근로자는 그 세션에 연결할 수 있습니다.

### 최근 세션

`puppeteer.history()`최근 세션 목록, 오픈 및 폐쇄 모두. 현재 사용의 감각을 얻는 것이 유용합니다.

```json
[
	{
		"closeReason": 2,
		"closeReasonText": "BrowserIdle",
		"endTime": 1711621769485,
		"sessionId": "478f4d7d-e943-40f6-a414-837d3736a1dc",
		"startTime": 1711621703708
	},
	{
		"closeReason": 1,
		"closeReasonText": "NormalClosure",
		"endTime": 1711123501771,
		"sessionId": "2be00a21-9fb6-4bb2-9861-8cd48e40e771",
		"startTime": 1711123430918
	}
]
```

회사연혁`2be00a21-9fb6-4bb2-9861-8cd48e40e771`명시적으로 닫히는`browser.close()`클라이언트에 의해, 세션`478f4d7d-e943-40f6-a414-837d3736a1dc`최대 유휴 시간에 도달하기 때문에 닫혔다 (check)[제한 사항](/browser-rendering/limits/)).

대시보드, 약간의 지연을 가진 albeit에 이 정보를 접근할 수 있어야 합니다.

### 활동 제한

`puppeteer.limits()`활동 제한 목록:

```json
{
  "activeSessions": [
    { "id": "478f4d7d-e943-40f6-a414-837d3736a1dc" },
    { "id": "565e05fb-4d2a-402b-869b-5b65b1381db7" }
  ],
  "allowedBrowserAcquisitions": 1,
  "maxConcurrentSessions": 2,
  "timeUntilNextAllowedBrowserAcquisition": 0
}
```

- `activeSessions`현재 열린 세션의 ID 목록
- `maxConcurrentSessions`여러 브라우저가 동시에 열 수 있는지 정의합니다.
- `allowedBrowserAcquisitions`새로운 브라우저 세션이 비율에 따라 열 수 있는지 확인합니다.[제한 사항](/browser-rendering/limits/)내 계정
- `timeUntilNextAllowedBrowserAcquisition`새로운 브라우저가 시작되기 전에 대기 기간을 정의합니다.

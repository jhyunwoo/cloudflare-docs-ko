[DNS 레코드를 확인](/automatic-platform-optimization/get-started/confirm-dns-records/)한 후 네임서버를 변경하세요.

도메인이 Cloudflare 네임서버를 사용하도록 업데이트하는 것은 Cloudflare가 사이트를 최적화하고 보호할 수 있도록 보장하는 중요한 단계입니다. 네임서버는 기본 DNS 제어 지점이며 인터넷에서 도메인의 위치를 식별합니다.

도메인 등록기관이 네임서버 업데이트를 처리하는 데 최대 24시간이 걸릴 수 있습니다. 사이트가 활성화되면 Cloudflare에서 이메일을 보냅니다.

## 도메인 등록 정보 조회

1. [WHOIS](https://lookup.icann.org/)에 접속하여 도메인 등록 정보를 조회합니다.
2. 텍스트 필드에 `https://www.`를 제외한 도메인 이름을 입력하고 **Lookup**을 선택합니다.
3. **Domain Information**에서 표시되는 네임서버 정보를 기록해 둡니다. 이 네임서버를 Cloudflare를 가리키도록 업데이트하게 됩니다.

이 브라우저 탭이나 창은 열어 둔 상태로 유지하고, 다음 섹션을 위해 새 탭이나 창을 여는 것을 권장합니다.

## 도메인 등록기관에서 네임서버 업데이트

1. 도메인 등록기관의 관리자 계정에 로그인합니다.
2. DNS 관리 메뉴로 이동합니다.
3. 네임서버 정보를 찾습니다. 네임서버는 도메인 등록 정보 조회의 3단계에서 확인한 정보와 일치해야 합니다.
4. 기존 네임서버 정보를 Cloudflare에서 사용자 지정 네임서버 만들기의 4단계에서 받은 Cloudflare 네임서버로 교체합니다.

:::note


도메인 등록기관에서 네임서버 변경 확인을 요구할 수 있습니다. 업데이트를 완료한 뒤 확인하거나 계속 진행하세요.


:::

[네임서버를 변경](/automatic-platform-optimization/get-started/change-nameservers/)한 다음 Cloudflare WordPress 플러그인을 활성화하세요.

## 사전 요구 사항

Cloudflare WordPress 플러그인을 활성화하기 전에 다음 사전 요구 사항을 확인하세요.

### 요금제 유형

무료 요금제 사용자는 WordPress 플러그인을 설치하기 전에 [APO를 구매](#purchase-apo)해야 합니다.

Pro 이상 요금제 사용자는 [설치 및 활성화](#install-and-activate-the-cloudflare-wordpress-plugin) 단계로 진행하여 Cloudflare WordPress 플러그인을 활성화하세요.

### 플러그인 호환성

Cloudflare는 APO를 처음 설정할 때 WP Rocket Cache Plugin, W3 Total Cache 또는 유사한 플러그인을 꺼 두는 것을 권장합니다. APO가 정상 동작하는 것을 확인한 뒤, 위 플러그인을 다시 켰을 때 결과가 개선되는지, 혹은 예상치 못한 동작이 발생하는지 테스트해 보기를 권장합니다. 많은 경우 APO를 다른 캐시 플러그인과 함께 사용하면 예상치 못한 결과가 발생할 수 있습니다.

또한 APO 활성화 후에는 WP Rocket Cache 플러그인, W3 Total Cache 또는 유사한 플러그인의 서버 캐시를 비우는 것도 권장합니다.

자세한 내용은 [플러그인 호환성](/automatic-platform-optimization/about/plugin-compatibility/)을 참고하세요.

### 제한 사항

Cloudflare APO WordPress 플러그인은 multisite WordPress 설치를 지원하지 않습니다.

## APO 구매

1. Cloudflare 대시보드에서 **Speed** > **Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/speed/optimization" />

2. **Content Optimization**으로 이동합니다.
3. **Automatic Platform Optimization for WordPress**에서 **Purchase**를 선택합니다.
4. 결제 정보를 입력하고 **Confirm payment**를 선택합니다.

<div id="install-and-activate-the-cloudflare-wordpress-plugin"></div>

## Cloudflare WordPress 플러그인 설치 및 활성화

APO를 시작하는 가장 쉬운 방법은 Cloudflare의 WordPress 플러그인을 직접 사용하는 것입니다. APO를 사용하려면 먼저 플러그인을 설치하고 활성화한 뒤 APO도 활성화해야 합니다.

1. WordPress 계정으로 이동해 로그인합니다.
2. **Plugins** > **Add new**를 선택합니다.
3. 검색 필드에 `Cloudflare`를 입력합니다.
4. Cloudflare 플러그인을 찾아 **Install now**를 선택합니다.
5. 플러그인 설치가 끝나면 **Activate**를 선택합니다. 이제 Cloudflare 플러그인이 Plugins 목록에 표시됩니다.

## APO 활성화

WordPress와 Cloudflare 사이 연결을 만들기 위해 Cloudflare 대시보드에서 API 토큰을 생성하고 WordPress에 추가합니다. 서브도메인에 APO를 설정하려면 [서브도메인과 서브디렉터리](/automatic-platform-optimization/reference/subdomain-subdirectories/)를 참고하세요.

## Cloudflare에서 API 토큰 생성

1. Cloudflare 대시보드에서 **Account API tokens** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/api-tokens" />

2. **Create Token**을 선택합니다.
3. 목록에서 **WordPress**를 찾아 **Use template**를 선택합니다.
4. 페이지 하단에서 **Continue to summary**를 선택합니다.
5. **WordPress API token summary** 페이지에서 **Create Token**을 선택합니다. API 토큰이 표시됩니다.
6. **Copy** 버튼을 선택해 토큰을 복사합니다. 다음 섹션에서 이 토큰을 붙여 넣게 됩니다.

:::note

API 토큰을 다시 쉽게 참조할 수 있도록 컴퓨터에 저장된 문서에 복사해 두세요.

:::

## API 토큰을 WordPress에 추가

1. WordPress 계정을 열고 Plugins로 이동합니다.
2. Cloudflare 플러그인을 찾아 **Settings**를 선택합니다.
3. 기존 계정으로 로그인하는 옵션을 선택합니다.
4. 이메일 주소를 입력하고, Cloudflare에서 API 토큰 생성 6단계에서 복사한 토큰을 붙여 넣습니다.
5. **Save API Credentials**를 선택합니다.
6. **Apply Recommended Cloudflare Settings for WordPress**에서 **Apply**를 선택합니다.
7. **Automatic Platform Optimization**의 토글을 **On**으로 전환하여 APO를 활성화합니다.

APO가 정상 동작하는지 확인하려면 [APO 동작 확인](/automatic-platform-optimization/get-started/verify-apo-works/)을 참고하세요.

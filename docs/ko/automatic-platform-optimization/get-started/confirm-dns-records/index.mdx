네임서버를 변경하기 전에 DNS 레코드가 올바르게 표시되는지 확인하세요.

1. Cloudflare 대시보드에서 DNS **Records** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/dns/records" />

2. 레코드를 추가하려면 **Add record**를 선택합니다.
3. 기존 레코드를 수정하려면 해당 레코드의 **Edit**를 선택합니다.
4. 변경을 마쳤으면 **Save**를 선택합니다.

DNS 레코드 확인이 끝나면 [네임서버를 변경](/automatic-platform-optimization/get-started/change-nameservers/)하세요.

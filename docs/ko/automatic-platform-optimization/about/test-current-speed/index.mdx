APO 사용을 시작하기 전에 현재 사이트 속도를 테스트하는 것을 권장합니다. 사이트 속도 결과는 웹사이트의 문자 등급과 성능 점수를 제공합니다.

1. [GTmetrix](https://gtmetrix.com/)에 방문합니다.
2. 텍스트 필드에 웹사이트 URL을 입력합니다.
3. **Test your site**를 클릭합니다.

테스트가 완료되면 사이트의 등급, 성능 점수 및 기타 성능 지표를 확인할 수 있습니다.

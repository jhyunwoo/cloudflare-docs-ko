현재 WordPress는 50,000개가 넘는 플러그인을 제공합니다. 따라서 APO와 이용 가능한 모든 플러그인의 호환성을 전부 테스트하는 것은 불가능합니다. 하지만 Cloudflare는 공식적으로 지원하는 플러그인 목록과, APO를 활성화했을 때 문제를 일으키는 것으로 알려진 플러그인 목록을 관리하고 있습니다.

목록에 없는 특정 플러그인에 대해 궁금한 점이 있다면 [Cloudflare Community](https://community.cloudflare.com/)에 스레드를 만들어 논의를 시작하세요.

:::note


Cloudflare APO WordPress 플러그인은 multisite WordPress 설치를 지원하지 않습니다.


:::

Automatic Platform Optimization(APO)을 사용하면 Cloudflare가 전체 사이트를 엣지 네트워크에서 제공하므로, 고객이 사이트를 방문할 때 향상된 성능을 경험할 수 있습니다. Cloudflare는 일반적으로 정적 콘텐츠만 캐시하지만, APO를 사용하면 HTML 같은 동적 콘텐츠도 캐시하여 전체 사이트를 캐시에서 제공할 수 있습니다. 이 과정은 오리진과의 왕복 요청을 제거해 첫 바이트까지 걸리는 시간(TTFB)을 비롯한 다양한 사이트 성능 지표를 크게 개선합니다. 또한 동적 콘텐츠 캐싱 외에도 APO는 서드파티 스크립트를 캐시하여 Cloudflare 엣지 네트워크를 벗어나는 요청 수를 더 줄여 줍니다.

APO를 사용해도 WordPress 사이트는 평소처럼 관리할 수 있습니다. WordPress에서 콘텐츠를 업데이트하면, Cloudflare는 Cloudflare의 WordPress 플러그인을 사용할 때 오래된 콘텐츠가 제공되지 않도록 엣지의 콘텐츠를 갱신합니다. 또한 로그인한 사용자나 관리자 사용자의 경우에는 개인 콘텐츠가 캐시되어 다른 방문자에게 제공되지 않도록 캐시를 우회합니다. [APO가 어떤 도움을 줄 수 있는지](https://www.youtube.com/watch?v=DWANhxoDxFI?feature=youtu.be)도 확인해 보세요.

## 제한 사항

Automatic Platform Optimization은 `www` 같은 서브도메인이 apex 도메인과 다른 zone에 있는 Enterprise [subdomain setup](/dns/zone-setups/subdomain-setup/)과는 호환되지 않습니다.

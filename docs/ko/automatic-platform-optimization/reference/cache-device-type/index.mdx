디바이스 유형별 APO 캐시는 Cloudflare 캐시의 모든 장점을 그대로 제공하면서도, 방문자에게 그 디바이스에 적합한 콘텐츠를 제공합니다. Cloudflare는 HTTP 요청의 `User-Agent` 헤더를 평가해 디바이스 유형을 식별합니다. 그런 다음 아래 정규식에 대한 대소문자 구분 없는 일치로 각 디바이스 유형을 식별합니다.

* **모바일**: `(?:phone|windows\s+phone|ipod|blackberry|(?:android|bb\d+|meego|silk|googlebot) .+? mobile|palm|windows\s+ce|opera mini|avantgo|mobilesafari|docomo|kaios)`
* **태블릿**: `(?:ipad|playbook|(?:android|bb\d+|meego|silk)(?! .+? mobile))`
* **데스크톱**: 위 조건에 일치하지 않는 나머지 모든 경우

디바이스 유형별 캐싱을 활성화하려면 Cloudflare 대시보드의 APO 카드에서 해당 설정을 켜거나, WordPress 플러그인 버전 4.4.0 이상에서 활성화하세요.

활성화되면 Cloudflare는 방문자의 디바이스 유형을 지정하기 위해 모든 요청마다 `mobile`, `tablet`, `desktop` 중 하나의 값을 담은 `CF-Device-Type` HTTP 헤더를 오리진으로 전송합니다. 오리진이 해당 디바이스 유형에 맞는 콘텐츠로 응답하면, Cloudflare는 그 특정 디바이스 유형에 대해서만 리소스를 캐시합니다.

:::note


Cache By Device Type 설정을 변경하면 캐시가 무효화됩니다.


:::

Cloudflare for WordPress 플러그인은 업데이트된 페이지에 대한 모든 캐시 변형을 자동으로 비웁니다.

Cloudflare는 디바이스 유형별 캐시를 지원하는 플러그인을 사용할 것을 권장하며, 이 경우 플러그인에서 해당 기능을 활성화해야 할 수 있습니다. 또한 플러그인이 예상대로 동작하는지 직접 테스트해야 합니다.

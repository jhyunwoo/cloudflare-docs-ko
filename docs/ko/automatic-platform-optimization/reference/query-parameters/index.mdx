쿼리 매개변수는 동적 콘텐츠의 존재를 나타내는 경우가 많습니다. 그 결과, URL에 쿼리 매개변수가 있으면 APO는 기본적으로 캐시를 우회하고 오리진에서 새 버전의 페이지를 가져오려고 시도합니다. 쿼리 매개변수는 UTM처럼 마케팅 기여 분석에도 자주 사용되므로, 사용자에게 빠른 로딩 시간은 특히 중요합니다.

쿼리 매개변수를 allowlist에 추가하려면 검토를 위해 [커뮤니티에 게시글을 작성](https://community.cloudflare.com/)하세요.

URL의 쿼리 매개변수가 다음 중 하나라면 APO는 캐시된 콘텐츠를 제공합니다.

* `ref`
* `utm_source`
* `utm_medium`
* `utm_campaign`
* `utm_term`
* `utm_content`
* `utm_expid`
* `fbclid`
* `fb_action_ids`
* `fb_action_types`
* `fb_source`
* `mc_cid`
* `mc_eid`
* `gclid`
* `dclid`
* `_ga`
* `campaignid`
* `adgroupid`
* `_ke`
* `cn-reloaded`
* `age-verified`
* `ao_noptimize`
* `usqp`
* `mkt_tok`
* `epik`
* `ck_subscriber_id`

## Cloudflare 대시보드에서 WordPress 플러그인이 감지되지 않음

WordPress 플러그인이 Cloudflare 대시보드에서 감지되지 않는 이유는 몇 가지가 있을 수 있습니다.

* WordPress 플러그인 버전이 3.8.2보다 오래된 경우
  * **해결 방법:** WordPress 플러그인 버전 4.4.0을 설치하세요.
* 플러그인 버전 3.8.2가 설치되어 있지만 기존 캐시 플러그인이 `cf-edge-cache` 헤더 없이 오래된 응답을 반환하는 경우
  * **해결 방법:** WordPress 플러그인에서 APO를 활성화하고, 기존 캐시 플러그인의 캐시를 비우세요.
* WordPress가 서브도메인에서만 실행되지만, WordPress와 WordPress 플러그인이 apex 도메인을 기준으로 검사하는 경우
  * **해결 방법:** 자세한 내용은 [서브도메인과 서브디렉터리](/automatic-platform-optimization/reference/subdomain-subdirectories/)를 참고하세요.

위 해결 방법을 모두 시도한 뒤에도 Cloudflare 대시보드가 WordPress 플러그인을 감지하지 못한다면, [Cloudflare WordPress 플러그인 활성화](/automatic-platform-optimization/get-started/activate-cf-wp-plugin/)에 나열된 모든 단계를 완료했는지 확인하세요.

:::note


Cloudflare APO WordPress 플러그인은 multisite WordPress 설치를 지원하지 않습니다.


:::

## WordPress가 오래된 콘텐츠를 반환함

WordPress가 오래된 콘텐츠를 반환한다면, APO가 활성화된 상태에서 [캐시를 비우세요](/cache/how-to/purge-cache/).

WordPress 사이트 성능을 한 단계 끌어올리려면 Automatic Platform Optimization(APO)을 사용하세요. APO를 사용하면 Cloudflare가 전체 WordPress 사이트를 엣지 네트워크에서 제공하므로, 방문자가 어디에 있든 일관되고 빠른 성능을 보장할 수 있습니다.

Automatic Platform Optimization은 [Cloudflare Workers](/workers/)의 성능을 활용해 동적 콘텐츠를 지능적으로 캐시한 결과물입니다. 동적 콘텐츠를 캐시함으로써 Cloudflare는 전체 웹사이트를 엣지 네트워크에서 제공할 수 있고, 그 결과 사이트의 첫 바이트까지 걸리는 시간(TTFB)을 빠르고 일관되게 유지할 수 있습니다.

사이트에서 APO를 사용할 때의 이점을 더 자세히 알아보려면 [Automatic Platform Optimization의 이점 블로그](https://blog.cloudflare.com/automatic-platform-optimizations-starting-with-wordpress/#the-benefits-of-automatic-platform-optimization)를 참고하세요. APO를 사용하려면 Cloudflare for WordPress 플러그인을 사용해야 합니다.

Bot 피드백 루프는 Bot 관리의 경우 'Cloudflare' 직접 피드백을 잠재적으로 보낼 수있는 방법입니다<GlossaryTooltip term="bot score" link="/bots/concepts/bot-score/">스코링</GlossaryTooltip>자주 묻는 질문 고객이 False Negative 또는 False Positive 보고서를 제출할 때, Cloudflare는 수동으로이 데이터를 분석하고 다음 기계 학습 모델에 대한 교육 데이터 세트로 사용합니다.

## 적용분야

Bot 의견 반복은 기업 Bot 관리 고객을 위해 유효합니다. 기타[계획](/bots/plans/)더 많은 정보.

## False 긍정적인

'Cloudflare'가 브라우저, 모바일 응용 프로그램 또는 데스크톱 응용 프로그램을 사용하여 사람의 요청을 득점하면 false 긍정적 일 수 있습니다.*자동화*또는*자동화*범위.

## False 부정

'Cloudflare'가 귀하의 사이트에 자동화 된 트래픽의 일부를 감지 할 수없는 경우 False Negative 보고서를 제출하면 미래에 잡을 수 있습니다.

### Expression 필드

| 제품정보                         | 제품정보  | 이름 \*                                                                        |
| ---------------------------- | ----- | ---------------------------------------------------------------------------- |
| `cf.bot_management.ja3_hash` | 이름 \* | SSL/TLS 지문을 제공하여 잠재적인 봇 요청을 식별할 수 있습니다.                                      |
| `cf.bot_management.score`    | 뚱 베어  | 이것은 요청이 1-99에서 점수를 사용하여 봇에서 시작한다는 것을 의미합니다.                                  |
| `http.host`                  | 이름 \* | 이것은 전체 요청 URI에 사용되는 호스트명을 나타냅니다.                                             |
| `http.request.uri.path`      | 이름 \* | 이 요청의 URI 경로를 나타냅니다.                                                         |
| `http.user_agent`            | 이름 \* | 클라이언트 운영 체제 및 웹 브라우저의 식별을 허용하기 위해 특성 문자열을 포함하는 요청 헤더 인 HTTP 사용자 에이전트를 나타냅니다. |
| `ip.src.asnum`               | 뚱 베어  | 이것은 클라이언트 IP 주소와 관련된 Autonomous System (AS) 번호를 나타내는 16 비트 정수를 나타냅니다.        |
| `ip.src.country`             | 이름 \* | 이것은 ISO 3166-1 알파 2 체재에 있는 2 letter 국가 부호를 대표합니다.                            |
| `ip.src`                     | 이름 \* | IP의 소스 주소.                                                                   |

## 자주 묻는 질문

보고서를 제출할 때, Bot Analytics 대시보드에서 필터를 사용하여 보고서는 부정확한 점수를 받은 트래픽만 포함합니다. 점수 (필수)에 의해 필터링 외에도, 사용자 시약, IP, ASN 또는 JA3에 의해 필터링 할 수 있습니다 더 정확 하 게 잘못된 점수 트래픽의 부분을 강조.

일부 트래픽이 잘못된 점수를 받았다면이 트래픽을 보고서에 보관하십시오.

우리는 당신이 당신의 도메인에 일반적인 교통의 맥락에서 이러한 요청을 더 잘 이해할 수 있도록 우리의 팀에 도움이 될 수있는 설명 필드에 남기고 싶은 모든 의견에 감사드립니다.

## 잘못된 긍정적 인 제출 후 추천

:::참조
아래 지침은 Bot Management와 Enterprise 구독에 적용됩니다.
주요 특징

긍정을 제출한 후, 이 트래픽 소스가 미래의 학대에 사용할 수 없다는 것을 확신하면 트래픽을 명시적으로 허용할 수 있습니다. 트래픽을 허용하려면 'WAF'사용자 정의 규칙을 만들 수 있습니다.[자주 묻는 질문](/waf/custom-rules/skip/options/#skip-the-remaining-custom-rules-current-ruleset)잘못된 긍정적 인 보고서의 특성을 일치시키는 행동. 이 웹 사이트는 귀하가 웹 사이트를 탐색하는 동안 귀하의 경험을 향상시키기 위해 쿠키를 사용합니다. 이 쿠키들 중에서 필요에 따라 분류 된 쿠키는 웹 사이트의 기본적인 기능을 수행하는 데 필수적이므로 브라우저에 저장됩니다.

- 지원하&#xB2E4;**[JA3/JA4 지문](/bots/additional-configurations/ja3-ja4-fingerprint/)**: 전용 IP에서 올 수없는 안정적인 소프트웨어 클라이언트에 액세스 할 수 싶다면 Bot Analytics 대시보드에서 클라이언트에 의해 사용되는 JA3 지문 (s)를보고하고 JA3 지문을 기반으로 트래픽을 허용하기 위해 'WAF'사용자 정의 규칙을 생성 할 수 있습니다. JA3 지문은 클라이언트의 TLS 라이브러리에만 일치하므로 운영 체제에 따라 다른 클라이언트와 변이를 찾고 있습니다.<br /><br />Cloudflare는 학대 할 수있는 모바일 응용 프로그램에 대한 JA3 규칙에 의존하지 않습니다. 모바일 애플리케이션에서 트래픽을 안전하게 허용하는 방법에 대한 질문이 있으시면 계정 팀에 문의하십시오.

:::참조
아래 지침은 Bot Management, Bot Fight Mode 및 Super Bot Fight Mode와 Enterprise 구독에 적용됩니다.
주요 특징

- 자주 묻는 질문**IP 주소**: IP가 허용하려는 트래픽 소스에만 속한 전용 리소스인 경우 트래픽을 허용하는 IP 주소를 사용합니다.<br />트래픽이 다른 트래픽 소스로 IP를 공유하거나 IP가 자주 변경되면 IP 주소로 허용하는 대안을 고려하십시오.

## 잘못된 부정적인 제출 후 권고

잘못된 부정적인 보고서를 제출 한 후 IP 주소, JA3 지문, ASN 및 사용자 시약과 같은 특성의 조합을 사용하여 부정적으로 점수 트래픽을 차단하거나 비율 제한 할 수 있습니다. JA3 지문을 기반으로 차단 또는 속도 제한하기 전에 Bot Analytics를 사용하여 지문이 합법적 인 트래픽 소스로 사용되지 않도록하십시오.

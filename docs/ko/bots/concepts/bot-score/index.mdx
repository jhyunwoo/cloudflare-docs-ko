봇 점수는 점수에서*1*으로*99*그 요청이 봇에서 온 것을 나타냅니다.

예를 들어, 1의 점수는 Cloudflare는 상당히 특정 요청이 자동화되었지만 99의 점수는 Cloudflare는 매우 특정 요청이 인간에서 온 것입니다.

Bot 점수는 규칙 표현에서 사용할 수 있으며, Workers를 사용하여 애플리케이션 동작을 사용자 정의합니다. 더 자세한 내용은 참조[Bot 관리 변수](/bots/reference/bot-management-variables/).

:::참조

Granular bot 점수는 Bot Management를 구입한 기업 고객에게만 사용할 수 있습니다. 다른 모든 고객은 이 정보를 통해서만 접근할 수 있습니다[봇 그룹화](#bot-groupings)Bot Analytics에서.
주요 특징

## 봇 그룹화

프로 플랜 이상의 고객은 그룹으로 나누어 봇 트래픽을 자동으로 볼 수 있습니다.**보안 보안** > **로그아웃**.

| (주)       | 주요 특징                                                |
| --------- | ---------------------------------------------------- |
| **견적 요청** | 봇 점수 0.                                              |
| **자동화**   | 봇 점수 1.                                              |
| **자동화**   | 봇 점수 2 - 29.                                         |
| **매우 인간** | 봇 점수 30 \~ 99.                                       |
| **인증 봇**  | Non-malicious 자동화 된 트래픽 (전력 검색 엔진 및 기타 응용 프로그램에 사용). |

:::참조

Bot 점수는 'Cloudflare'에 의해 처리되는 경로에 대한 요청을 준수하지 않으며 원래에 차단되거나 전달되지 않습니다. Redirect Rule과 같은 Bot Management 이전에 활성화된 일부 기능을 참고하면, 점수가 없는 요청에서 결과가 발생할 수 있습니다.

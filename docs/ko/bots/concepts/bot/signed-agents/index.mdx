서명된 대리인은 최종 사용자에 의해 통제되고 그들의 웹 Bot Auth 실시에서 확인한 서명 시약.

에이전트에 대해 요청할 수 있습니다. Cloudflare's bots and Agent directory by Filling out[온라인 신청](https://dash.cloudflare.com/?to=/:account/configurations/verified-bots)‘Cloudflare’ ‘대시보드’에서

:::참조
봇은 검증된 봇과 서명한 에이전트로 등록할 수 없습니다. 'Cloudflare'의 리뷰[검증된 봇](/bots/concepts/bot/verified-bots/)봇을 식별하는 방법을 결정합니다.
주요 특징

## 표시된 대리인 필요조건

인식될 대리인을 위해, 그것은 뒤에 오는 요구에 응해야 합니다:

1. 대리인은 따르야 합니다[서명된 대리인 정책](/bots/concepts/bot/signed-agents/policy/).
2. 봇은 사용해야 합니다.[웹 봇 Auth](/bots/reference/bot-verification/web-bot-auth/).

Cloudflare가 서명한 에이전트를 승인하면,[Cloudflare 레이더의 봇과 에이전트 디렉토리](https://radar.cloudflare.com/verified-bots).

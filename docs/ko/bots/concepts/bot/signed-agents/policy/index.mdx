서명한 대리인으로 Cloudflare에 의해 목록으로 만들기 위하여, 당신의 대리인은 밑에 요구에 응해야 합니다. 고객에게 최고의 보호를 제공하기 위해이 정책은 새로운 봇 행동에 적응하여 미래에 변화 할 수 있습니다.

## 에이전트 정책

### 최소 영역

서비스 영역의 광범위한 사용을 위해해야합니다.

#### 이름 \*

하나의 사이트를 크롤링하는 봇은 유효하지 않습니다.

### 대리인 ID

사용자 시약 필드는 Web Bot 인증에 필요하지 않습니다.

그러나 사용자 시약을 제공하기 위해 선택하는 경우, 그리고 메시지 서명은 다음과 같은 요구 사항을 충족해야합니다:

- 적어도 5개의 문자가 있습니다.
- 특수 문자를 포함하지 마십시오.
- 다른 검증된 서비스의 동일한 사용자 시약을 포함하지 마십시오.

#### 이름 \*

`cloudflare-browser-rendering`유효한 메시지 서명입니다.

### 회사 소개

서비스의 목적은 영역의 소유자와 서비스의 사용자 모두에게 또는 도움이되어야한다. 서비스는 다음과 같이 수행 할 수 없습니다 :

- 봇 툴링
- 스칼퍼
- 연락처
- 연락처
- 데이터 스크랩
- DDoS 차단

#### 이름 \*

가격 스크랩 직접 전자 상거래 경쟁자는 유효 사용 사례가 아닙니다.

### 관련 문서

에이전트는 공개적으로 문서화 된 목적과 예상 행동을해야합니다.

***

## 정책의 표

유효성 검사에 대한 요구 사항 중 하나가 breached 경우, 서비스가 서명 된 에이전트 목록에서 제거됩니다.

다음은 정책의 위반의 예입니다.

- 이 서비스는 패치되지 않은 취약점이 있습니다.
- 서비스의 공개 목적은 트래픽에 반영되지 않습니다.

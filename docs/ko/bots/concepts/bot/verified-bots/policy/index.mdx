Cloudflare에 의해 목록으로 만들기 위해<GlossaryTooltip term="verified bot" link="/bots/concepts/bot/verified-bots/">확인 봇</GlossaryTooltip>, 당신의<GlossaryTooltip term="bot">봇</GlossaryTooltip>아래 요구 사항을 준수해야합니다. 고객에게 최고의 보호를 제공하기 위해이 정책은 새로운 봇 행동에 적응하여 미래에 변화 할 수 있습니다.

## 봇 정책

### 최소 교통

봇 또는 프록시는 샘플 데이터에서 찾을 수 있도록 'Cloudflare'에 대한 트래픽의 최소 금액을해야합니다. 최소 트래픽은 여러 도메인에서 하루 1,000 개 이상의 요청이 있어야 합니다.

:::참조
최소 트래픽은 사용중인 경우 요구 사항이 아닙니다.[웹 봇 Auth](/bots/reference/bot-verification/web-bot-auth/)인증방법
주요 특징

### 최소 영역

서비스 영역의 광범위한 사용을 위해해야합니다.

#### 이름 \*

하나의 사이트를 크롤링하는 봇은 유효하지 않습니다.

### 봇 식별

다음 요구 사항과 사용자 시약 또는 메시지 서명:

- 적어도 5개의 문자가 있습니다.
- 특수 문자를 포함하지 마십시오.
- 다른 검증된 서비스의 동일한 사용자 시약을 포함하지 마십시오.

#### 이름 \*

`GoogleBot/1.0`유효한 사용자 시약입니다.

### 도메인 소유자 동의

도메인은 영역의 소유자 또는 사용 약관의 명시적 또는 부적절한 동의와 함께 크롤링해야합니다. 검색 엔진 크롤러는 읽기해야합니다`robots.txt`소유자에서 크롤러에 경로 제외.

#### 이름 \*

다른 웹 사이트에서 scalp inventories를 시도하는 도구는 검색 엔진 봇 인덱싱 웹 사이트가 있지만 준수하는 동안 사용 조건을 끊을 수 있습니다.`robots.txt`유효한 서비스입니다.

### 회사 소개

서비스의 목적은 영역의 소유자와 서비스의 사용자 모두에게 또는 도움이되어야한다. 서비스는 다음과 같이 수행 할 수 없습니다 :

- 봇 툴링
- 스칼퍼
- 연락처
- 연락처
- 데이터 스크랩
- DDoS 차단

#### 이름 \*

가격 스크랩 직접 전자 상거래 경쟁자는 유효 사용 사례가 아닙니다.

### 크롤링 etiquette

크롤링 etiquette는 체크해야합니다`robots.txt`전체 웹 사이트를 크롤링하는 경우, 그것은 crawl 민감한 경로에 시도하지 않아야합니다.

#### 이름 \*

검색 엔진 크롤러 건너뛰기`robots.txt`, 그것은 거절될 것입니다.

### 관련 문서

봇은 공개적으로 예상된 행동 또는 사용자 시약 형식을 문서화해야합니다.

***

## 정책의 Breach

유효성 검사에 대한 요구 사항이 위반되는 경우, 서비스는 글로벌 수당으로부터 삭제됩니다.

다음은 정책의 위반의 예입니다.

- 검증된 서비스로 사용되지 않은 IP 세트를 추가합니다.
- 서비스 IP는 공격자가 위반합니다.
- 이 서비스는 패치되지 않은 취약점이 있습니다.
- IP의 차단은 목록에 추가되지 않습니다.
- 서비스의 공개 목적은 트래픽에 반영되지 않습니다.
- robots.txt에 있는 크롤러 지연 지시를 존중하지 않는 AI 크롤러.

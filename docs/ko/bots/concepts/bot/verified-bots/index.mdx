확인된 봇은 'Cloudflare'의 목록에 추가된 봇입니다.<GlossaryTooltip term="verified bot">검증된 봇</GlossaryTooltip>.

봇을 요청할 수 있습니다. Cloudflare의 봇과 에이전트 디렉토리에 추가됩니다.[온라인 신청](https://dash.cloudflare.com/?to=/:account/configurations/verified-bots)‘Cloudflare’ ‘대시보드’에서

:::참조
봇은 검증된 봇과 서명한 에이전트로 등록할 수 없습니다. 'Cloudflare'의 리뷰[서명된 대리인](/bots/concepts/bot/signed-agents/)봇을 식별하는 방법을 결정합니다.
주요 특징

## Verified bot 요구 사항

봇을 확인하려면 다음 요구 사항을 충족해야합니다.

1. 봇을 따라야 합니다.[검증된 봇 정책](/bots/concepts/bot/verified-bots/policy/).
2. 봇은 다음과 같은 검증 방법을 사용하여 확인해야합니다.
   - [웹 봇 Auth](/bots/reference/bot-verification/web-bot-auth/)
   - [IP 검증](/bots/reference/bot-verification/ip-validation/)

Cloudflare가 검증된 봇을 승인하면,[Cloudflare 레이더의 봇과 에이전트 디렉토리](https://radar.cloudflare.com/verified-bots).

## Inactive 확인된 봇

Cloudflare는 확인된 봇으로 봇을 나열하면, 이 항목은 캐시되고 트래픽이 정의 된 시간 동안 봇에서 오는 'Cloudflare' 네트워크에서 볼 수없는 경우 delisted 얻을 수 있습니다.

검증된 봇으로 제거하기 위해 Inactive IP를 24시간 정도 걸립니다.

***

### 알려진 문제

Yandex bot은 검증 된 Bot으로 분류되지만 트래픽은 때때로 차단 될 수 있습니다.[WAF 관리 규칙](/waf/managed-rules/)(ID와 같은 규칙`...f6cbb163`).

이것은 일반적으로 Yandex가 소스 IP 주소 범위를 업데이트 할 때 발생합니다. 새로운 IP는 업데이트 된 Bot IP 목록이 'Cloudflare'네트워크에서 완전히 동기화 될 때까지 'WAF' 관리 규칙에 의해 일시적으로 인식됩니다.

Yandex 트래픽을 복원하려면[WAF 예외](/waf/managed-rules/waf-exceptions/)일시적으로 ID로 관리 된 규칙을 건너`<RuleID id="2854e3f18ad946049e6d90ccf6cbb163" />`요청이 올 때**IP 정보**사용자 시약 포&#xD568;**·**. 이것은 합법적 인 Yandex 트래픽이 다른 트래픽에 대한 보안 기능을 비활성화하지 않고 차단 규칙을 우회합니다.

또한 만들 수 있습니다[WAF 사용자 정의 규칙](/waf/custom-rules/skip/)이름 \**팟캐스트*블록 규칙을 포함하는 관리 규칙을 대상으로 행동. 규칙 표현은 특히 요청의 Yandex IP 및 User-Agent와 일치해야합니다.

문제가 일시적으로 해결되며 새로운 Yandex IP 주소가 완전히 'Cloudflare'의 시스템에 전파됩니다. 이 전파는 일반적으로 48 시간까지 걸립니다. 봇이 48 시간 후 차단되면 연락처[Cloudflare 지원](/support/contacting-cloudflare-support/).

  고객 및 사용자 계정에서 Identify 및 mitigate 공격.
</Description>

Fraud 탐지를 통해 트래픽 중 포용 및 mitigate 계정 남용을 감지하고, 특히 대량 계정 생성 및 계정 공격을 할 수 있습니다. 사기 신호를 사용할 수 있습니다[업데이트 또는 새로운 규칙 만들기](/waf/custom-rules/)suspicious 계정 활동을 위해, 또는 그들의 근원에 신호는 입증과 허가 체계로 통합합니다.

## 적용분야

Account Abuse Protection은 사전 액세스에서 사용할 수 있습니다.[Bot 관리 기업](/bots/get-started/bot-management)고객. 이 기능을 사용할 수 없습니다 추가 비용에 대한 제한된 기간까지 일반적으로 사용할 수 있습니다.

## 회사 소개

### 사용자 ID

사용자 ID는 암호화 된 해시, per-zone 식별자는 고객이 사용할 수있는[보안 Analytics](/waf/analytics/security-analytics/), [보안 규칙](/waf/custom-rules/)·[관리된 Transforms](/rules/transform/managed-transforms/reference/). hashed User ID에 액세스하여 웹 사이트 소유자는 할 수 있습니다.

- 사용자가 웹 사이트에 가장 많은 활동이있는 리뷰.
- 특정 사용자의 특성 및 활동 패턴에 대한 세부 정보를 찾으십시오.
- 사용자를 기반으로 한 Mitigate 트래픽은 역사적으로 의심스러운 활동으로 사용자를 차단합니다.
- 계정이 유출 된 자격으로 대상 될 때 볼 수있는 필드를 결합합니다.
- 특정 사용자와 관련된 네트워크 패턴 또는 신호를 관리합니다.

:::노트\[데이터 프라이버시]
사용자 프로파일링은 개인 정보 보호로 만들어졌습니다. 우리의 개인 정보 보호 및 준수 프로그램과 함께 설계 및 엔지니어링 정렬하고 사용자의 개인 정보를 보호하는 기술 제어를 포함합니다. Hashed User IDs는 사용자가 응용 프로그램에 액세스하기 위해 사용하는 기본 자격 증명을 암호화하여 생성됩니다.

다른 Cloudflare 고객은 사용자 프로필에 액세스 할 수 없습니다. 그들은 당신의 지역에 독특합니다.
주요 특징

User ID는 Cloudflare 대시보드에서 기본적으로 활성화됩니다.

수정하거나 비활성화하려면:

## 시작하기

### 자주 묻는 질문

Fraud 검출은 다음과 같은 구성과 설정이 제대로 의심스러운 행동을 식별 할 수 있습니다.

#### 보안 설정

- 사용자 ID: Cloudflare는 암호화 또는 사용자 ID가 응용 프로그램에 따라 일반적인 사용자 트래픽 패턴을 더 잘 이해할 수 있습니다. Cloudflare를 사용하여 사용자 ID 매핑을 사용자 ID로 만들 수 있습니다. 계정 takeover 및 대량 계정 생성 탐지를받을 수 있습니다.

#### Eligible 교통

Cloudflare는 특정 로그인을 식별하고 응용 프로그램에 트래픽을 표시하고 추가 구성없이이 감지를 실행합니다.

- Sign-ups:Cloudflare는 공통 서명을 일치하는 endpoints에 트래픽을 자동으로 모니터링합니다.
- 로그인:Cloudflare는 일반적인 로그인 엔드포인트와 일치하는 엔드포인트에 트래픽을 자동으로 모니터링합니다.

'Cloudflare'가 올바르게 감지하고 모니터링 할 수 있도록 엔드포인트가 제대로 라벨을 지정합니다.

### 제품정보

Fraud Detections는 계정 takeover, 대량 계정 생성 및 credential 질과 같은 계정 남용 공격에 집중합니다. 이 감지는 모든 자격이 된 트래픽을 실행하고 주변에서 사용할 수 있습니다.[Cloudflare 규칙](/rules/)로그인, 도전, 및/또는 블록 요청으로 가입 및 로그인 엔드포인트.

#### 계정 생성

일회용 이메일 체크는 사용자가 홍보 남용 및 가짜 계정 생성을 위해 일반적으로 사용되는 throwaway 이메일 주소로 가입 할 때 감지합니다. 이 일회용 이메일 서비스는 공격자가 실제 인프라를 유지하지 않고 수천 개의 고유 계정을 만들 수 있습니다.

보안 p참고 자료를 시행하기 위해 규칙을 구축하기 위해 다음과 같은 바이너리 필드를 사용할 수 있습니다, 모든 일회용 이메일 선택, 또는 문제[- 연혁](/cloudflare-challenges/challenge-types/)일회용 이메일 계정 만들기를 시도하는 사람.

#### Suspicious 이메일

Cloudflare는 의심스러운 패턴을 식별하는 데 도움이되는 이메일의 구성 요소를 분석합니다. 더 알아보기[자주 묻는 질문](#prerequisites)귀하의 트래픽을 감지 할 수 있습니다.

Cloudflare는 이 분석 중 이메일 주소를 저장하지 않습니다. 어떤 저장 또는 캐싱 없이 처리되는 모든 탐지.

| 검색 태그                                 | 이름 \*                                                                                                            |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `cf.fraud_detection.disposable_email` | 임시 또는 일회용 이메일 서비스의 목록에서 일반적으로 발견되는 도메인과 이메일 식별.                                                                  |
| `cf.fraud.email_risk`                 | 이메일 사용자 이름과 최상위 도메인에서 문자의 무작위성을 분석합니다.<br />높은 위험 이메일은 높은 entropy를 나타냅니다, 중간 및 낮은 위험 이메일은 문자의 문자열에 적은 임의를 나타냅니다. |

다음과 같은 Fraud 탐지 필드는 보안 규칙에서 사용 될 수 있으며 의심스러운 트래픽을 식별하고 완화 할 수 있습니다.

#### 보안 규칙

다음 필드는 새로운 기존 보안 규칙에서 사용할 수 있습니다.

| 제품정보                                  | 이름 \*                                         | 제품정보                                                                                                                                                      |
| ------------------------------------- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cf.fraud_detection.dispoable_domain` | 주어진 이메일에 대한 도메인이 주어진 이메일 목록에 포함되는 플래그.        | `True`또는`False`                                                                                                                                           |
| `cf.fraud.email_risk`                 | 사용자 이름과 도메인에 있는 문자의 무작위성을 기반으로 하는 이메일의 위험 측정. | `Low`임의 및 간단한 이메일 감소로 인한 낮은 위험을 나타냅니다.<br />`Medium`더 큰 문자열을 기반으로 한 중간 위험을 나타냅니다. 약간 더 무작위.<br />`High`더 크고 무작위 문자 문자열을 기반으로 높은 위험을 나타냅니다.<br />`Unknown` |

#### 다른 규칙

## 회사 소개

Secure Analytics의 데이터 및 탐지를 찾을 수 있습니다.

<DashButton url="/?to=/:account/:zone/security/analytics" />

Fraud 필드는 필터로 사용하여 트래픽의 의심스러운 패턴을 식별 할 수 있습니다.

Security Analytics 내의 해시드 사용자 ID 필드는 요청보다 개별 사용자당 탐지 및 패턴을 검토하는 데 도움이되는 데이터로 고객을 제공합니다. IP 및 IP 카운트, 이벤트 유형 (로그인 또는 가입), 위치, 장치 및 브라우저에 대한 사용자 수준의 집계를 검토 할 수 있습니다.

사용자 수준의 프로파일은 또한 사용자와 관련된 최신 이벤트를 검토하는 빠른 방법을 제공합니다. 어떤 anomalies를 식별하고 사용자의 로그, 블록 또는 도전에 사용자 정의 규칙을 만들 수 있습니다.

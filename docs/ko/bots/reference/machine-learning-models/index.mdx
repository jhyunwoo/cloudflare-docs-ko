## 기계 학습 모델에 자동 업데이트 가능

<Render file="latest-ml-model-enable" product="bots" />

### 변경 사항

이전 기계 학습 모델에 있다면 점수 변경을 볼 수 있습니다.**기계 학습**소스 즉시. 최신 모델에 이미 있다면, 새로운 기계 학습 모델이 글로벌 디폴트가 됩니다.

새로운 기계 학습 모델이 글로벌 디폴트가 되는 새로운 머신러닝 모델의 이메일과 대시보드를 통해 통보됩니다.

### 업데이트되지 않은 위험

최신 버전으로 업데이트되지 않으시면, 더 이상 유지되거나 우리의 엔지니어링 팀에 의해 모니터링되지 않습니다. 인터넷 트래픽 변경과 새로운 트렌드가 진화함에 따라, 이전 버전의 정확도를 계산할 수 있습니다.

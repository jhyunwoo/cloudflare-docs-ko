Cloudflare는 고객이 인공 지능 (AI) 교육 및 데이터 스크랩과 관련된 봇을 구체적으로 해결하기 위해 서비스 약관을 업데이트하는 것이 좋습니다. 아래 텍스트는 웹 사이트 이용 약관에 추가 될 수있는 언어의 일종의 정보 예를 제공합니다.

> **인공 지능 제한**
>
> 이 웹 사이트는 귀하가 웹 사이트를 탐색하는 동안 귀하의 경험을 향상시키기 위해 쿠키를 사용합니다. 이 쿠키들 중에서 필요에 따라 분류 된 쿠키는 웹 사이트의 기본적인 기능을 수행하는 데 필수적이므로 브라우저에 저장됩니다. 또한이 웹 사이트의 사용 방식을 분석하고 이해하는 데 도움이되는 제 3 자 쿠키를 사용합니다. 이 쿠키는 귀하의 동의하에 만 브라우저에 저장됩니다. 이러한 쿠키 중 일부를 선택 해제하면 검색 환경에 영향을 미칠 수 있습니다.`robots.txt`파일 및 (II)는 AI 목적으로 사용되는 봇을 식별하는 데 사용 (즉,이 조항은 검색 엔진 색인 및 AI 목적과 같은 여러 목적으로 사용되는 사용자 에이전트에 적용되지 않습니다).

:::카ution\[면책]

이 언어는 정보 목적으로만 제공됩니다. 법적 조언을 구성하지 않으며 특정 결과를 보장하지 않습니다.

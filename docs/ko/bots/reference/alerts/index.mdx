Bot alerts tell you whenCloudflare는 다음 특성의 트래픽에서 스파이크를 감지 :

- 30 미만의 봇 점수가 있는 트래픽의 글로벌 스파이크.
- 사용 가능한 차원의 트래픽 증가[사용자 정의 Bot 감지 경고](#custom-bot-detection-alerts).
- 당신의 선택의 필터[사용자 정의 Bot 감지 경고](#custom-bot-detection-alerts).

### 봇 탐지 경고 설정

Bot 경고를 수신하려면,[알림 설정](/notifications/get-started/). 알림은 'Cloudflare' 계정으로 이메일, PagerDuty 또는 webhooks를 통해 최신 상태로 유지됩니다.

<Steps>
  1. 'Cloudflare'에서 '대시보드'로 이동**공지사항**사이트 맵

     <DashButton url="/?to=/:account/notifications" />
  2. 제품정보**더 보기**.
  3. 제품정보**Bot 관리**제품 목록에서.
  4. 사용 가능한 봇 탐지 경고 중 하나를 선택하십시오 (사용자 지정 필터 및 / 또는 그룹 설정 여부에 따라 다름):
     - Bot 탐지 경고
     - 사용자 정의 Bot 감지 경고
  5. 알림 이름과 (선택)를 입력합니다.
  6. 이 경고를 모니터링하려면 도메인(s)을 선택합니다.
  7. 알림에 대한 배달 방법을 구성합니다. 이용 가능한 배송 방법은 'Cloudflare\` 플랜에 따라 다릅니다. 더 많은 정보를 원하시면, 참조[Cloudflare 알림](/notifications/).
  8. Custom Bot Detection Alert에 대한 알림을 작성하면 알림을 필터링하는 매개 변수를 정의합니다.
  9. 제품정보**제품 정보**.
</Steps>

## Alert 로직

Bot Detection Alert는 Cloudflare가 Z-score > 영역에서 비정상적인 스파이크를 감지 할 때 사용자를 통지합니다.[3.5](https://blog.cloudflare.com/introducing-thresholds-in-security-event-alerting-a-z-score-love-story/)그리고 봇 요청 > 봇 트래픽 200/5 분 (봇 점수 \< 30).

Z-score는 6 시간의 긴 창 내구와 5 분의 짧은 창 내구로 계산됩니다.

Bot Detection Alerts는 이메일, webhook 또는 Pager Duty를 통해 Cloudflare의 알림 시스템으로 전달됩니다.

다른 경고 값이 동시에 경고를 유발하는 드문 경우를 제외하고 동일한 시간 시간 프레임 내에서 중복 경고를받지 않습니다.

위의 정보 외에도 Custom Bot Detection Alerts는 특정 조건을 포함하거나 제외 할 수 있습니다.

- 사용자 시약
- 이름 \*
- URI 경로
- IP 근원 주소
- 사이트맵
- JA3 지문
- JA4 지문
- 봇 탐지 ID

다음 차원에서 그룹으로 선택할 수 있습니다. 따라서 그들은 부피 측정 anomalies에 따라 경고 될 수 있습니다.

- JA4 지문 (봇 점수의 필터 제거 \< 30)
- 사이트맵
- 봇 탐지 ID

:::참조
Bot 탐지 경고는 제외합니다[검증된 봇](/bots/concepts/bot/verified-bots/).
:::

사용자가 WordPress 설치에 대한 사이트 상태 페이지의 진단을 실행하려고 할 때 루프백 문제가 발생하면 봇 감지 서비스가 차단됩니다.

WordPress는 루프백 요청을 사용하여 웹 사이트를 모니터링하고 때때로 관리합니다. 고객은 WordPress의 Super Bot Fight 모드를 최적화 할 수 있습니다. 이 기능이 활성화되면 WordPress 사이트에서 만든 자동화 된 루프백 요청은 Super Bot Fight 모드 블록 다른 봇이 승인됩니다.

:::참조
Loopback 요청도 차단 될 수 있습니다.[공격 모드 중](/fundamentals/reference/under-attack-mode/)또는 특정[WAF 사용자 정의 규칙](/waf/custom-rules/).
:::

## WordPress에 최적화

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 ‘대시보드’" icon="rocket">
    <Steps>
      1. 'Cloudflare'에서 '대시보드'로 이동**보안 설정**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/settings" />
      2. 필터 로**봇 트래픽**.
      3. 오시는 길**슈퍼 Bot 전투 모드**.
      4. 이름 \***제품 설명**, 편집 아이콘을 선택**WordPress에 최적화**그리고 그것을 켜십시오.
    </Steps>
  </TabItem>

  <TabItem label="'대시보드'">
    <Steps>
      1. 로그인하기[‘Cloudflare’ ‘대시보드’](http://dash.cloudflare.com), 귀하의 계정과 도메인을 선택합니다.
      2. 오시는 길**보안 보안** > **로그아웃**.
      3. 제품정보**Bot 관리 구성**.
      4. 이름 \***WordPress에 최적화**.
    </Steps>
  </TabItem>
</Tabs>

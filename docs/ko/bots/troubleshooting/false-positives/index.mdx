[Bot 전투 모드 (BFM)](/bots/get-started/bot-fight-mode/)·[슈퍼 봇 전투 모드 (SBFM)](/bots/get-started/bot-fight-mode/)활성 공격을 신속하게 중지하도록 설계되었습니다. 자신의 공격적인 성격 때문에, 거짓 긍정적 인 것은 합법적 인 인간 또는 자동화 된 트래픽이 잘못되거나 차단 된 곳을 발생할 수 있습니다.

거짓 긍정적으로 취급할 때 다음과 같은 핵심 차이점과 솔루션을 고려하십시오.

- Bot Fight 형태는 제한한 통제가 있습니다. Bot Fight 모드를 우회하거나 건너 뛸 수 없습니다.*팟캐스트*'WAF' 사용자 정의 규칙 또는 페이지 규칙을 사용하여 행동. Bot Fight 모드는 IP 액세스 규칙이 존재하는 경우 비활성화됩니다. 공격 중 BFM에서 설정한 경우 공격이 나면 IP Access 규칙을 사용하여 기능을 활성화하거나 BFM을 우회하는 것이 좋습니다.[기업을 위한 Bot 관리](/bots/plans/bm-subscription/)보안 임계값을 정확하게 사용자 정의하고 필요에 따라 예외 규칙을 만듭니다.
- 최고 Bot 전투 형태는 IP 접근으로 우회될 수 있습니다*지원하다*활동 규칙. 당신은 사용할 수 있습니다*팟캐스트*관련 기사[WAF 사용자 정의 규칙](/waf/custom-rules/skip/)Super Bot Fight 모드가 실행되지 않도록 지정하십시오.

Bot Fight 모드를 우회하거나 건너 뛸 수 없습니다.*팟캐스트*'WAF' 사용자 정의 규칙 또는 페이지 규칙을 사용하여 행동.*팟캐스트*, *비밀번호*·*지원하다*행동은 규칙이나 규칙에 적용됩니다.[Ruleset 엔진](/ruleset-engine/). Super Bot Fight 모드 규칙은 Ruleset Engine에서 구현되었지만, Bot Fight 모드 체크는 없습니다. 왜 슈퍼 봇 전투 모드를 건너 뛸 수 있지만 Bot Fight 모드가 아닙니다. Bot Fight 모드를 건너야 하는 경우,[슈퍼 Bot 전투 모드](/bots/get-started/super-bot-fight-mode/).

Bot Fight 모드는 여전히 IP 액세스 규칙이있는 경우 트리거 할 수 있지만 IP 액세스 규칙이 요청을 일치하면 트리거 할 수 없습니다. 예를 들어 IP 액세스 규칙은 연결 IP에 일치합니다.

persistent false 긍정적 인 경우, 당신은 할 수 있습니다[Cloudflare 대시보드의 기능을 비활성화](/bots/get-started/bot-fight-mode/#disable-bot-fight-mode).

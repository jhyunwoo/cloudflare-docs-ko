Bot Management가 실행되지 않고 특정 필드에 인스턴스가 있습니다.[JA3/JA4 분야](/bots/additional-configurations/ja3-ja4-fingerprint/)Bot Management를 실행하는 것을 결정했기 때문에 대중화되지 않습니다.

더 알아보기<GlossaryTooltip term="bot score" link="/bots/concepts/bot-score/#not-computed">봇 점수</GlossaryTooltip>더 많은 정보를 위해 왜 요청이 점수가 없습니다.

## Bot Management의 일반적인 이유는 요청을 점수하지 않습니다.

### 내부 endpoints에 요청

같은 요청`/cdn-cgi/`개별적으로 처리되고 Bot 관리 점수를받지 않습니다. 이메일 의무, 웹 분석, 추적 요청, 도전 Pages, 그리고 JavaScript 탐지는 봇 점수를받지 않습니다. 내부 엔드 포인트의 일부 예에 대한 아래 표에 참조.

| 오시는 길                                                             |
| ----------------------------------------------------------------- |
| `/cdn-cgi/rum`                                                    |
| `/cdn-cgi/script_monitor/report`                                  |
| `/cdn-cgi/trace`                                                  |
| `/cdn-cgi/challenge-platform/…`                                   |
| `/cdn-cgi/scripts/5c5dd728/cloudflare-static/email-decode.min.js` |

### Purge 요청

모든 HTTP 퍼지 요청은 봇 점수를받지 않습니다.

### 초기 힌트 캐시 요청

이른 힌트 캐시 요청은 봇 점수를받지 않습니다.

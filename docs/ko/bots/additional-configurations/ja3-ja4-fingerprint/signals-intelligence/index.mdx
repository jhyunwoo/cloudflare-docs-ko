모든 것[JA4 지문](/bots/additional-configurations/ja3-ja4-fingerprint/), Bot 관리 고객은 Cloudflare가 인터넷에 그것을보고 우리가 지문을 볼 수있는 행동을 볼 수 있습니다. 이 데이터는 특정 패션에 점수를 매거나 자신의 ML 모델에서 집계 데이터를 사용할 수 있도록하는 이유를 이해할 수 있습니다.[Cloudflare구인](/workers/)또는 원래 위치.

구체적으로, 각 JA4 지문을 위해, 당신은 뒤에 오는 정보를 접근할 수 있을 것입니다:

- 'Cloudflare'가 보이는 브라우저와 관련된 트래픽의 비율.
- 알려진 봇과 관련된 트래픽의 비율은 다음과 같습니다.
- 네트워크 Cloudflare의 수는이 지문을 사용하여 적극적으로 볼 수 있습니다.
- 이 지문에서 트래픽을 볼 수있는 'Cloudflare' 사이트 수.
- 지문 요청이 콘텐츠를 캐시하고 오류를 생성합니다.

이 데이터는 'Cloudflare' 네트워크를 통해 제공되는 통찰력에 액세스하고 모든 인터넷 트래픽의 20 % 이상을 앉아 우리의 독특한 가장자리 네트워크에 의해 생성됩니다. 또한이 데이터를 자체로 공급할 수 있습니다.[\`Workers AI\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`\`](/workers-ai/)- Signals Intelligence 필드를 통해 맞춤형 기계 학습 모델.

## Signals 지능 분야

Signals Intelligence 필드는 특정 JA4에 대한 관측을 보여줍니다. 즉, 마지막 시간 동안 전 세계적으로 볼 수 있습니다.

| <div style="width:170px">필드 이름</div> | 이름 \*                                                                                                                      |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| `h2h3_ratio_1h`                      | HTTP / 2 및 HTTP / 3 요청의 비율은 마지막 시간에 JA4 지문에 대한 총 번호와 결합됩니다. 높은 값은 다른 프로토콜 버전과 비교된 HTTP / 2 및 HTTP / 3 요청의 높은 비율을 나타냅니다.    |
| `heuristic_ratio_1h`                 | 요청의 비율`scoreSrc`마지막 시간에 있는 JA4 지문을 위한 "heuristics"의 가치. 더 높은 값은 헤리티지 기반 득점에 의해 퍼지는 요청의 더 큰 비율을 제안합니다.                      |
| `reqs_quantile_1h`                   | 마지막 시간에 있는 모든 지문의 수에 근거를 둔 JA4 지문의 quantile 위치. 높은 값은 다른 지문과 비교된 상대적으로 더 높은 요청을 나타냅니다.                                     |
| `uas_rank_1h`                        | JA4 지문의 순위는 마지막 시간에 있는 모든 지문의 맞은편에 명백한 사용자 대리인의 수에 기초를 두었습니다. 더 낮은 값은 지문과 관련된 사용자 에이전트의 높은 다양성을 나타냅니다.                     |
| `browser_ratio_1h`                   | 마지막 시간에 JA4 지문을 위한 브라우저 기반 사용자 에이전트에서 시작된 요청의 비율. 높은 값은 브라우저 기반 요청의 높은 비율을 제안합니다.                                          |
| `paths_rank_1h`                      | JA4 지문의 순위는 지난 시간에 모든 지문을 통해 고유 한 요청 경로의 수를 기반으로합니다. 더 낮은 값은 지문과 관련된 요청 경로의 높은 다양성을 나타냅니다.                                 |
| `reqs_rank_1h`                       | 마지막 시간에 있는 모든 지문의 수에 근거를 둔 JA4 지문의 순위. 더 낮은 값은 지문과 관련된 더 높은 요청을 나타냅니다.                                                     |
| `cache_ratio_1h`                     | 지난 시간에 JA4 지문에 대한 캐시 가능한 응답의 비율. 높은 값은 캐시 할 수있는 응답의 높은 비율을 제안합니다.                                                          |
| `ips_rank_1h`                        | JA4 지문의 순위는 지난 시간에 모든 지문을 통해 고유 한 클라이언트 IP 주소의 번호를 기반으로합니다. 낮은 가치는 지문과 관련된 명백한 클라이언트 IPs의 더 높은 수를 나타냅니다.                   |
| `ips_quantile_1h`                    | JA4 지문의 quantile 위치는 지난 시간에 모든 지문을 통해 고유 한 클라이언트 IP 주소의 번호를 기반으로합니다. 높은 가치는 다른 지문과 비교된 명백한 클라이언트 IPs의 상대적으로 더 높은 수를 나타냅니다. |

아래 검출 ID를 사용하여, 당신은 검출하고 mitigate 계정 takeover 공격을 할 수 있습니다. 지정된 소프트웨어 및 네트워크 조합에 대한 로그인 요청의 수를 모니터링 할 수 있으며 로그인 오류의 백분율. 의심스러운 수준에 도달하면 이러한 공격을 방지 할 수 있습니다.[주문 규칙](/waf/custom-rules/), [비율 제한 규칙](/waf/rate-limiting-rules/)·[작업자](/workers/).

| <div style="width:100px">탐지 ID</div> | 이름 \*                                                                                                                                                                                                                 |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `201326592`                          | 영역에 모든 로그인 실패를 관찰합니다.                                                                                                                                                                                                 |
| `201326593`                          | 지역으로 모든 로그인 트래픽을 관찰합니다.                                                                                                                                                                                               |
| `201326598`                          | 정상적인 트래픽을 기반으로 동적 임계값을 설정하면 해당 영역에 고유합니다.<br /><br />ID가 로그인 실패를 일치할 때, Bot Management는[봇 점수](/bots/concepts/bot-score/)29과 용도[anomaly 검출](/bots/concepts/bot-detection-engines/#anomaly-detection-enterprise)점수 소스로. |

## 계정 takeover 탐지와 제한 로그인

제한 규칙의 비율은 특정 IP, JA4 지문, 또는 국가에서 로그인의 수를 제한할 수 있습니다.

계정으로 제한 규칙을 사용하려면 takeover detections:

      3. 양식을 작성**사용자 정의 표현 빌더**·`cf.bot_management_detection_ids`다른 정보와 함께.
      4. 제품정보**글 탐색**규칙을 나중에 반환하거나**계정 만들기**규칙을 배포합니다.

      2. 오시는 길**보안 보안** > **‘WAF’**.

      4. 양식을 작성**사용자 정의 표현 빌더**·`cf.bot_management_detection_ids`다른 정보와 함께.
      5. 제품정보**글 탐색**규칙을 나중에 반환하거나**계정 만들기**규칙을 배포합니다.

규칙은 누설된 Credential 검사로 강화될 수 있습니다. 더 알아보기[WAF 문서](/waf/detections/leaked-credentials/)유출된 자격 증명과 계정이 제한하는 규칙에 대한 더 많은 정보를 제공합니다.

:::

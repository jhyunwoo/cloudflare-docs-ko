Scraping actal detection IDs는 부적당한 행동을 식별하여 웹 사이트를 더 잘 보호 할 수 있습니다. 아래 검출 ID는 영역 수준에서 의심스러운 긁는 활동을 잡기 위해 특별히 설계되었습니다.

| <div style="width:100px">탐지 ID</div> | 이름 \*                                    |
| ------------------------------------ | ---------------------------------------- |
| `50331648`                           | ASN의 역동적 분석 행동으로 영역으로 전송된 요청의 패턴을 관찰합니다. |
| `50331649`                           | JA4 지문에 의해 영역으로 전송된 요청의 패턴을 관찰합니다.       |

```js title="Rule example"

(any(cf.bot_management.detection_ids[*] in {50331648 50331649}) and not cf.bot_management.verified_bot)
```

:::tip\[최고의 연습]
당신이 당신의 규칙 행동으로 도전을 선택하면, 당신은 당신이 도전을 발행하지 않으려는 어떤 API 통화를 제외. 이러한 경로에 대한 요청을 제외하고, 편집[WAF 사용자 정의 규칙](/waf/custom-rules/)관련 경로 제외.
주요 특징

:::참조
탐지 ID를 위한 일치한 교통`50331648`·`50331649`단 하나 지문을 의미하는 역동적으로 재 계산은 항상 의심스러운 행동을 계속하지 않는 한 영구적으로 조각되지 않을 것입니다.

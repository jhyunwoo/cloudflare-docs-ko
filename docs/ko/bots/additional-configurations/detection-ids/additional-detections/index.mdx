Cloudflare bot detection는 자동화 된 트래픽의 다른 종류를 잡는 추가 신호를 포함합니다.

Bot 관리 고객은 아래에 주거 프록시 탐지 개선에서 자동적으로 혜택을 줍니다.[봇 점수](/bots/concepts/bot-score/)일치하는 요청을 위해. 검출 ID 사용[주문 규칙](/waf/custom-rules/)더 가시성을 제공하고 주거 프록시 트래픽을 mitigating합니다.

| <div style="width:100px">탐지 ID</div> | 이름 \*                                                                                                                                                                    |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `50331651`                           | 주거 프록시 네트워크 및 유사한 상업 프록시의 트래픽을 관찰합니다.<br /><br />ID가 요청 시 봇 관리는 봇 점수를 29로 설정하고 사용[anomaly 검출](/bots/concepts/bot-detection-engines/#anomaly-detection-enterprise)점수 소스로. |

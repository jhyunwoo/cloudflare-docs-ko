## API를 통한 시퀀스 규칙 관리

### Enable 순서 규칙

<Steps>
  1. [API 토큰 만들기](/fundamentals/api/get-started/create-token/)당신은 이미 하나가없는 경우. API 토큰은 포함해야 합니다.*지역 명소* > *Fraud 탐지* > *제품정보*이름 \*
  2. [지역 ID 받기](/fundamentals/account/find-account-and-zone-ids/)순서 규칙을 활성화하고 싶은 지역 (s)를 위해.
  3. [endpoints 추가](/api-shield/management-and-monitoring/)API Shield의 Endpoint Management를 사용하여 시퀀스 규칙을 추적하고 짧은 ID의 메모를 만듭니다.
  4. API 토큰과 Zone ID를 다음 API 호출에 추가하여 순서 쿠키를 활성화하십시오.
</Steps>

:::참조

계정 팀이 이 기능을 활성화 할 때까지 짧은 ID가 보이지 않습니다.
주요 특징

```bash title="API call"
curl --request PUT \
https://api.cloudflare.com/client/v4/zones/{zone_id}/fraud_detection/sequence_cookies \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{"enabled": true}'
```

5. 표현 편집기를 사용하여 순서 또는 타이밍 기반 규칙을 작성[주문 규칙](/waf/custom-rules/), [비율 제한 규칙](/waf/rate-limiting-rules/), 또는[변환 규칙](/rules/transform/). 이 규칙을 모니터링 할 수있는 모드만 로그에 넣을 수 있습니다.

:::참조
순서 규칙을 활성화할 때, Cloudflare는 endpoints와 일치하는 모든 요청에 대한 쿠키를 설정 시작합니다.
주요 특징

순서 규칙을 활성화하면 규칙 필드가 팝업되고 규칙의 새로운 필드를 사용할 수 있습니다.

### 사용 방법

순서 규칙을 해제하는 것은 populated에서 규칙 필드를 중지합니다. 이 필드에 따라 배포되는 규칙이 있다면, 그 규칙은 의도대로 동작하지 않을 수 있습니다. 순서 규칙을 비활성화하기 전에 순서 필드에 의존하는 규칙을 제거하거나 비활성화하십시오.

순서 규칙을 비활성화하려면:

<Steps>
  1. [API 토큰 만들기](/fundamentals/api/get-started/create-token/)당신은 이미 하나가없는 경우. API 토큰은 포함해야 합니다.*지역 명소* > *Fraud 탐지* > *제품정보*이름 \*
  2. [지역 ID 받기](/fundamentals/account/find-account-and-zone-ids/)순서 규칙을 활성화하고 싶은 지역 (s)를 위해.
  3. [endpoints 추가](/api-shield/management-and-monitoring/)API Shield의 Endpoint Management를 사용하여 시퀀스 규칙을 추적하고 짧은 ID의 메모를 만듭니다.
  4. API 토큰, Zone ID 및 설정을 사용하여 순서 쿠키를 비활성화`enabled`으로`false`다음 API 호출에.
</Steps>

:::참조
계정 팀이 이 기능을 활성화 할 때까지 짧은 ID가 보이지 않습니다.
주요 특징

```bash title="API call"
curl --request PUT https://api.cloudflare.com/client/v4/zones/{zone_id}/fraud_detection/sequence_cookies \
--header "Authorization: Bearer <API_TOKEN>" \
--data '{"enabled": false}'
```

## 규칙 필드

Sequence 규칙은 'Cloudflare\` 규칙에 세 가지 새로운 필드를 소개합니다. 이 분야의 모든 ‘참고 자료’는 짧은 ID로 작업합니다. Fraud Detection 구독이 있는 계정은 endpoint 세부 정보를 통해 짧은 ID를 참조할 수 있습니다.**API 방패** > **Endpoint 관리**‘Cloudflare’ ‘대시보드’에서 Fraud 탐지 없는 계정은 이 분야에 접근할 수 없습니다.

Cloudflare는 최대 1 시간 동안 시퀀스에서 가장 최근의 작업을 저장합니다. 순서에 있는 10 이상 가동이 있는 경우에, 이전 가동은 떨어질 것입니다 뒤에 오는 분야에서 포함되지 않을 것입니다. 마찬가지로 작업이 1 시간 전에 더 많은 일이 발생하면 다음 필드에 포함되지 않습니다.

### 예제 규칙

고객은 endpoint B 전에 endpoint A를 요청해야합니다.

```txt title="Valid sequence"
cf.sequence.current_op eq "bbbbbbbb" and
any(cf.sequence.previous_ops[*] == "aaaaaaaa")
```

```txt title="Invalid sequence"
cf.sequence.current_op eq "bbbbbbbb" and
not any(cf.sequence.previous_ops[*] == "aaaaaaaa")
```

고객은 endpoint B.의 앞에 적어도 1 초를 요구합니다.

```txt title="Valid sequence"
cf.sequence.current_op eq "bbbbbbbb" and
cf.sequence.msec_since_op["aaaaaaaa"] ge 1000
```

```txt title="Invalid sequence"
cf.sequence.current_op eq "bbbbbbbb" and
not cf.sequence.msec_since_op["aaaaaaaa"] ge 1000
```

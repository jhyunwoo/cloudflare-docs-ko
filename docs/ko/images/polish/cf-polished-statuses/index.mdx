이름 \*`Cf-Polished`헤더가 반환되지 않습니다, 시도[단일 파일 캐시 퍼지 사용](/cache/how-to/purge-cache)이미지를 퍼지려면. 더 보기`Cf-Polished`헤더는 비이미지를 보내면 누락될 수도 있습니다.`Content-Type`또는 non-cacheable`Cache-Control`.

- `input_too_large`: 입력 이미지는 너무 크거나 복잡하며, 낮은 해상도를 필요로 합니다. Cloudflare는 어떤 차원든지에 있는 4,000 화소 보다는 더 적은 PNG 또는 JPEG 이미지를 사용하여 추천하고, 20 MB 보다는 더 작습니다.
- `not_compressed`또는`not_needed`: 이미지는 원래 서버에서 완전히 최적화되었으며 압축이 적용되지 않았습니다.
- `webp_bigger`: 폴란드어는 WebP로 변환하려고했지만 WebP 이미지는 원래 형식보다 더 좋지 않았습니다. WebP 버전이 존재하지 않기 때문에, 상태는 응답의 JPEG/PNG 버전에 설정됩니다. 더 알아보기[왜 폴란드어가 WebP를 사용하지 않는 이유](/images/polish/no-webp/).
- `cannot_optimize`또는`internal_error`: 입력 이미지는 원본 서버에서 손상되거나 불완전합니다. 새로운 버전의 이미지를 Origin 서버에 업로드합니다.
- `format_not_supported`: 입력 이미지 형식은 지원되지 않습니다 (예 : BMP 또는 TIFF) 또는 원본 서버는 폴란드어와 호환되지 않는 추가 최적화 소프트웨어를 사용합니다. 웹 호환 형식으로 입력 이미지 변환 (PNG 또는 JPEG와 같은) 및/또는 원래 서버에서 추가 최적화 소프트웨어를 비활성화.
- `vary_header_present`: 웹서버는`Vary`다른 값으로 헤더`accept-encoding`. 웹 서버가 WebP를 지원하려고 하는 경우, 웹 서버에서 WebP를 비활성화하고 폴란드어는 WebP 변환을 수행합니다. 폴란드어는 아직도 일할 것입니다`accept-encoding`안에 나열된 유일한 헤더입니다.`Vary`헤더. 폴란드어 건너뛰기 이미지 URL 처리[사이트맵 제품정보](/images/transform-images/).

Lossless 및 Lossy 모드로 Cloudflare는 가능한 한 많은 메타 데이터를 스트립하려고합니다. 그러나 Cloudflare는 캐싱 상태와 같은 다른 요인 때문에 모든 메타 데이터를 스트립 할 수 없으며, metadata가 마침내 응답으로 보내질 수 있습니다.

:::카트로션\[Warning]

폴란드어는 근원 응답에 적용되지 않을지도 모릅니다`Vary`헤더. 자주 묻는 질문`Vary`헤더는`Vary: Accept-Encoding`.

:::

## 압축 옵션

### 이름 \*

폴란드어는 무능하고 압축은 적용되지 않습니다. 폴란드어를 비활성화 이전에 광택 이미지를 원래, 그들은 만료 될 때까지 또는 캐시에서 순화.

### 뚱 베어

Lossless 옵션은 이미지 픽셀의 변경없이 파일 크기를 줄일 수 있으며 원본과 동일한 이미지를 유지합니다. 그것은 EXIF 데이터와 같은 대부분의 메타 데이터를 제거하고, 손실없이 이미지 데이터를 다시 압축합니다. JPEG 이미지는 진보적인 체재로 개조될지도 모릅니다. 평균적으로 손실없는 압축은 이미지 파일에 비해 21 %의 파일 크기를 감소시킵니다.

Lossless 옵션은 JPEG의 변환을 WebP로 방지하므로 항상 손실 된 작동입니다.

### 이름 \*

Lossy 옵션은 작은 품질 손실의 비용에서 Lossless 옵션보다 이미지에 크게 더 나은 압축을 적용합니다. uncompressed 때, 원본 이미지에서 중복된 정보의 일부는 잃습니다. 손실 모드를 사용하여 평균적으로 파일 크기를 48 % 감소시킵니다.

이 옵션은 이미지에서 메타 데이터를 제거합니다. 손실 옵션은 주로 JPEG 이미지에 영향을 미치지 만 PNG 이미지는 손실 된 방법으로 압축되거나 JPEG로 변환 할 수도 있습니다.

### 웹페이지

다른 최적화 외에도 폴란드어는 WebP 형식으로 변환 된 이미지의 버전을 만듭니다.

WebP 압축은 PNG 이미지에서 매우 효과적이며 파일 크기를 약 26 % 감소시킵니다.
약 17 %의 JPEG 이미지의 파일 크기를 줄일 수 있지만이[몇몇 요인에 달려 있습니다](/images/polish/no-webp/)·
WebP는 Internet Explorer 및 KaiOS를 제외한 모든 브라우저에서 지원됩니다. 더 많은 것을 배울 수 있습니다.[블로그 게시물](https://blog.cloudflare.com/a-very-webp-new-year-from-cloudflare/).

WebP 버전은 언제만 제공됩니다.`Accept`브라우저의 헤더는 WebP를 포함하고, WebP 이미지는 원래 형식의 손실이나 손실없는 재압축보다 크게 작습니다.

```txt
Accept: image/avif,image/webp,image/*,*/*;q=0.8
```

폴란드어는 표준 이미지 형식을 변환<em>으로</em>WebP 형식. Origin 서버가 WebP 이미지를 제공하는 경우 폴란드어는 변환되지 않으며 최적화되지 않습니다.

#### 파일 크기, 이미지 품질 및 WebP

JPEG 및 WebP와 같은 손실 형식은 모든 크기의 파일을 생성 할 수 있으며 각 이미지는 이론적으로 더 작을 수 있습니다. 그러나 파일 크기의 감소는 이미지 품질에 있는 감소의 비용에 옵니다. 각 체재의 최선 크기 한계의 밑에 파일 크기 감소는 질에 있는 disproportionally 큰 손실을 일으키는 원인이 됩니다. 이미 최적화된 파일의 재 인코딩은 파일 크기를 줄일 수 있습니다.

Cloudflare는 JPEG에서 WebP로 변환하지 않을 때 변환은 더 큰 파일을 만들거나, 파일 크기에서 저장할 것 보다는 이미지 질을 더 감소시킬 것입니다.

Lossless 폴란드어 설정을 선택하면 WebP는 매우 드물게 사용됩니다. 이것은 사실로 인해, 이 모드에서 WebP는 PNG 이미지에만 적절하며 JPEG 이미지를 압축 할 수 없습니다.

WebP는 평균 JPEG보다 더 잘 압축하지만 예외가 있으며, 일부 경우 JPEG는 WebP보다 잘 압축됩니다. Cloudflare는이 사례를 감지하고 JPEG 형식을 유지합니다.

원본 (품질 설정 60 또는 낮은)에서 낮은 품질의 JPEG 이미지를 제공하면 WebP로 변환하는 것이 좋습니다. 이것은 낮은 질 JPEG 이미지에는 압축에 기인한 blocky 가장자리 및 소음이 있고, 이 왜곡은 WebP 이미지의 파일 크기를 증가합니다. 원본 서버에서 고품질 JPEG 이미지 (80와 90 사이의 품질 설정)을 제공하여이 문제를 피할 수 있습니다.

서버 또는 콘텐츠 관리 시스템 (CMS)이 내장 된 이미지 변환기 또는 최적화 된 경우 폴란드어와 방해 할 수 있습니다. 손실 최적화를 이미지에 두 번 적용하는 감각을 만들지 않습니다. 품질 향상은 파일 크기에서 절감보다 더 커질 것입니다.

## 이미지 최적화와 폴란드어 상호 작용

폴란드어는 이미지 변환을 사용하여 URL에 적용되지 않습니다. 크기 이미지는 이미 가능한 한 무손잡이 압축을 가지고 있으므로 폴란드어로 제공 된 최적화가 필요하지 않습니다. 사용 방법`format=auto`WebP 및 AVIF 형식의 사용을 허용하는 옵션.

모델 번호: Cloudflare 폴란드어는 사이트 이미지를 자동으로 최적화하는 원클릭 이미지 최적화 제품입니다. 이미지에서 폴란드어 스트립 메타데이터를 줄이고 손실이나 손실없는 압축을 통해 이미지 크기를 줄일 수 있습니다.

이미지가 당신의 근원에서 fetched 때, 우리의 체계는 Cloudflare의 캐시에서 그것을 자동적으로 낙관합니다. 동일한 이미지에 대한 지속적인 요청은 웹 사이트의 속도를 향상, 이미지의 더 작고, 빠르고 최적화 된 버전을 얻을 것입니다.

![폴란드어 압축의 질의 보기.](~/assets/images/images/polish.png)

## 제품정보

- <b>담당자: Ms.</b>모든 이미지를 소스 서버에서 자동으로 최적화합니다. 동일한 이미지 URL을 유지하고 페이지를 변경할 필요가 없습니다.
- <b>모델 번호: Cloudflare 제품정보</b>API는 resizing, 자르기, 워터 마크 및 기타 처리와 새로운 이미지를 만들 수 있습니다. 이 이미지는 자신의 새로운 URL을 얻을, 당신은이 서비스를 활용하기 위해 페이지에 그들을 삽입해야합니다. 이미지는이 방법을 이미 최적화하고 있으며 폴란드어를 적용 할 필요가 없습니다.

이미지에서[캐시는 순화되어야 합니다](/cache/how-to/purge-cache/)또는 폴란드어 설정에서 변경 사항을 볼 전에 만료.

:::카트로션

폴란드어를 활성화하지 않고[이미지 변환](/images/transform-images/)동시. 이미지 변환은 이미 손실 압축을 적용, 이는 폴란드어 중복.

:::

1. Cloudflare 대시보드에서, 가십시오**계정 홈**사이트 맵

   <DashButton url="/?to=/:account/home" />

2. 폴란드를 활성화하려는 도메인을 선택하십시오.

3. 제품정&#xBCF4;****제품 정보** > **계정 설정**** > **이미지 최적화**.

4. 이름 \***담당자: Ms.**, 선택*이름 \**&#xB610;는*뚱 베어*드롭다운 메뉴에서.[*이름 \**](/images/polish/compression/#lossy)더 큰 파일 크기 저축을 줍니다.

5. (선택 사항) 선택**웹페이지**. 원본 서버에서 저장된 PNG 및 JPEG 이미지를 최적화하려는 경우이 옵션을 활성화하고이 형식을 지원하는 브라우저에 WebP 파일로 봉사합니다.

WebP는 WebP 지원없이 캐시에서 브라우저로 제공되지 않습니다. 폴란드어를 사용할 때 웹 서버에서 WebP 변환 유틸리티를 비활성화하십시오.

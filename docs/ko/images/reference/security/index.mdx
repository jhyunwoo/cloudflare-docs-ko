이미지 최적화 서비스의 보안 및 효율성을 보장하려면 악성 행위에 대해 보호하는 Cloudflare 제품을 채택할 수 있습니다.

Cloudflare 보안 제품[Cloudflare WAF](/waf/), [Cloudflare Bot 관리](/bots/get-started/bot-management/)·[Cloudflare 비율 제한](/waf/rate-limiting-rules/)당신의 이미지 최적화 요청의 보호를 강화할 수 있습니다. 이 유능한 접근은 모든 합법적인 사용자를 위한 믿을 수 있는 능률적인 경험을 지킵니다.

Cloudflare Images는 개발자가 다양한 방법으로 이미지를 업로드할 수 있도록 합니다.

## 지원된 이미지 체재

다음 이미지 형식을 Cloudflare 이미지로 업로드할 수 있습니다:

- 한국어
- GIF (애니메이션 포함)
- 사이트맵
- 웹 사이트 (Cloudflare 이미지 또한 업로드 animated WebP 파일을 지원합니다.
- 사이트맵
- 이름 \*

:::참조

Cloudflare는 해독을 위한 HEIC 이미지를 소화할 수 있습니다, 그러나 그들은 AVIF, WebP, JPG, 또는 PNG와 같은 웹 안전 체재에서 봉사되어야 합니다.

:::

## 크기 및 크기

이 이미지에 업로드할 때 최대 허용된 크기 및 차원입니다:

- 최대 이미지 치수는 12,000 픽셀입니다.
- 최대 이미지 면적은 100 메가픽셀(예: 10,000×10,000픽셀)으로 제한됩니다.
- 이미지 메타데이터는 1024 바이트로 제한됩니다 (Cloudflare에서 업로드 및 저장하면).
- 이미지에는 10 메가바이트 (MB) 크기 제한이 있습니다 (Cloudflare에서 업로드하고 저장하십시오).
- 모든 프레임을 포함한 애니메이션 GIF / WEBP는 50 메가 픽셀 (MP)로 제한됩니다.

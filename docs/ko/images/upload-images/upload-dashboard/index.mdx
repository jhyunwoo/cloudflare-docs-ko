이미지를 업로드하기 전에, 목록 확인[지원되는 체재 및 차원](/images/upload-images/#supported-image-formats)이미지를 확인하려면 허용됩니다.

Cloudflare 대시보드에서 이미지를 업로드하려면:

1. Cloudflare 대시보드에서, 가십시오**연락처**사이트 맵

   <DashButton url="/?to=/:account/images/transformations" />

2. 이미지를 드래그하고 드롭**빠른 업로드**이름 \* 대안으로, 당신은 선택할 수 있습니다**여기에 드롭 이미지**또는 이미지를 로컬로 선택합니다.

3. 업로드 완료 후, 이미지는 파일의 목록에서 나타납니다.

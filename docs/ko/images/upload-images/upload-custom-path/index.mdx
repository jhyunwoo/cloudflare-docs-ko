Cloudflare Images’ Universal Unique Identifier (UUID)에 의해 생성된 경로 대신 이미지를 업로드할 수 있습니다.

사용자 정의 경로 지원:

- 최대 1,024자.
- 어떤 수의 subpaths.
- 더 보기[UTF-8 인코딩 표준](https://en.wikipedia.org/wiki/UTF-8)문자의 경우.

:::참조

사용자 정의 ID 경로가있는 이미지는 개인을 사용하여 만들 수 없습니다.[URL 토큰](/images/manage-images/serve-images/serve-private-images). 또한, 때[본문 바로가기](/images/manage-images/serve-images/), 어떤`%`사용자 지정 ID에 존재하는 문자는 인코딩되어야 합니다.`%25`이미지 전송 URL에서.
주요 특징

더 보기`POST`참고 자료로 아래 예제를 사용하여 요청. URL 또는 직접 파일 업로드를 통해 업로드 할 때 사용자 정의 ID 경로를 사용할 수 있습니다.

```bash
curl --request POST https://api.cloudflare.com/client/v4/accounts/{account_id}/images/v1 \
--header "Authorization: Bearer <API_TOKEN>" \
--form 'url=https://<REMOTE_PATH_TO_IMAGE>' \
--form 'id=<PATH_TO_YOUR_IMAGE>'
```

이미지를 성공적으로 업로드 한 후 아래 예와 비슷한 응답을 받게됩니다.

```json
{
  "result": {
    "id": "<PATH_TO_YOUR_IMAGE>",
    "filename": "<YOUR_IMAGE>",
    "uploaded": "2022-04-20T09:51:09.559Z",
    "requireSignedURLs": false,
    "variants": ["https://imagedelivery.net/Vi7wi5KSItxGFsWRG2Us6Q/<PATH_TO_YOUR_IMAGE>/public"]
  },
  "result_info": null,
  "success": true,
  "errors": [],
  "messages": []
}
```

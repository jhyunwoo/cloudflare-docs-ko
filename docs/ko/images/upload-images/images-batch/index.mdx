이미지 배치 API는 Cloudflare의 글로벌 API 속도 제한을 우회하면서 순서에 여러 요청을 만들 수 있습니다.

Images 일괄 API를 사용하려면 일괄 토큰을 취득하고 여러 요청을 만들기 위해 토큰을 사용합니다. 이 배치 토큰에 의해 허가 된 요청은 별도의 엔드 포인트로 만들어졌으며 글로벌 API 비율 제한을 계산하지 않습니다. 각 토큰은 초당 200개의 요청의 비율 제한이 적용됩니다. 당신은 Cloudflare 이미지 API에 더 높은 처리량을 요구하는 경우에 다수 토큰을 이용할 수 있습니다.

토큰을 얻기 위해 새로운 것을 사용할 수 있습니다.`images/v1/batch_token`아래 예시로 endpoint.

```bash
curl "https://api.cloudflare.com/client/v4/accounts/{account_id}/images/v1/batch_token" \
--header "Authorization: Bearer <API_TOKEN>"

#응답:
{
  "result": {
    "token": "<BATCH_TOKEN>",
    "expiresAt": "2023-08-09T15:33:56.273411222Z"
  },
  "success": true,
  "errors": [],
  "messages": []
}
```

토큰을 얻기 후에, 요청을 만들기 위해 사용:

- [이미지 업로드](/api/resources/images/subresources/v1/methods/create/) - `POST /images/v1`
- [이미지 삭제](/api/resources/images/subresources/v1/methods/delete/) - `DELETE /images/v1/{identifier}`
- [Image 세부사항](/api/resources/images/subresources/v1/methods/get/) - `GET /images/v1/{identifier}`
- [업데이트 이미지](/api/resources/images/subresources/v1/methods/edit/) - `PATCH /images/v1/{identifier}`
- [이미지 목록 V2](/api/resources/images/subresources/v2/methods/list/) - `GET /images/v2`
- [직접 업로드 V2](/api/resources/images/subresources/v2/subresources/direct_uploads/methods/create/) - `POST /images/v2/direct_upload`

이 옵션은 다른 호스트와 동일한 방법, 요청 및 응답 기관과 다른 경로를 사용합니다.

```bash title="Request for list images V2 against api.cloudflare.com"
curl "https://api.cloudflare.com/client/v4/accounts/{account_id}/images/v2" \
--header "Authorization: Bearer <API_TOKEN>"
```

```bash title="Example request using a batch token"
curl "https://batch.imagedelivery.net/images/v1" \
--header "Authorization: Bearer <BATCH_TOKEN>"
```

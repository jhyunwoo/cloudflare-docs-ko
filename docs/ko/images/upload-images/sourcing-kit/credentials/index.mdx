Amazon S3에서 이미지를 마이그레이션하려면 Sourcing Kit는 물통에 액세스 권한을 요구합니다. AWS Identity 및 Access Management (IAM) 사용자 자격 증명을 사용하여 Sourcing Kit 소스를 만들 수 있지만 CloudflareXQ는 사용자를 좁은 권한으로 만듭니다.

올바른 Sourcing 키트 권한을 만들려면 :

1. AWS IAM 계정으로 로그인하세요.

2. 다음 형식으로 정책을 작성하십시오 (replace`<BUCKET_NAME>`당신이에 액세스 권한을 부여하고 싶은 물통으로:

   ```json
   {
       "Version": "2012-10-17",
       "Statement": [
           {
               "Effect": "Allow",
               "Action": [
                   "s3:Get*",
                   "s3:List*"
               ],
               "Resource": [
                   "arn:aws:s3:::<BUCKET_NAME>",
                   "arn:aws:s3:::<BUCKET_NAME>/*"
               ]
           }
       ]
   }
   ```

3. 다음, 새로운 사용자를 만들고 그 사용자에게 창조 된 정책을 첨부합니다.

이제 액세스 키 ID와 비밀 액세스 키 모두 사용하여 Sourcing Kit의 새로운 소스를 만들 수 있습니다. 더 알아보기[Enable Sourcing 키트](/images/upload-images/sourcing-kit/enable/)더 알아보기.

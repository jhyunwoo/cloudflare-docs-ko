Sourcing Kit 메인 페이지에는 정의된 모든 수입 작업 및 소스의 목록이 있습니다. 이것은 소스 또는 abort 실행 수입 작업에 대한 세부 정보를 편집 할 수있는 곳입니다.

## Source 세부사항

소스에 대해 자세히 알아볼 수 있습니다.**이름 \***&#x53;ourcing 장비에 탭 대시보드. 이 옵션을 사용하여 이름을 변경하거나 소스를 삭제합니다.

1. Cloudflare 대시보드에서, 가십시오**호스트 이미지**사이트 맵

   <DashButton url="/?to=/:account/images/hosted" />

2. 제품정보**Sourcing 장비**.

3. 제품정보**이름 \***&#xBCC0;경하고 싶은 소스를 선택합니다.

4. 이 페이지에서 이름을 바꾸거나 소스를 삭제할 수 있습니다. 제품정보**이름 소스**또는**비밀번호**당신이해야 할 일에 따라.

## Abort 수입 작업

Cloudflare 이미지는 여전히 당신의 계정에 이미지를 가져올 작업 실행, 당신은 그것을 완료하기 전에 abort 할 수 있습니다.

1. Cloudflare 대시보드에서, 가십시오**호스트 이미지**사이트 맵

   <DashButton url="/?to=/:account/images/hosted" />

2. 제품정보**Sourcing 장비**.

3. 내 계정**계정 만들기**당신이 abort를 원하는 수입 작업을 선택합니다.

4. 다음 페이지는 수입 요약을 보여줍니다. 제품정보**한국어**.

5. 당신이 선택하여 당신의 수입 일자리를 구할 것을 확인**한국어**대화 상자에서.

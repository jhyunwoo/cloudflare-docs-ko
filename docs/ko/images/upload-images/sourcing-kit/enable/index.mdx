Sourcing 장비가 Amazon S3 계정에서 이미지를 가져 오기 시작하는 데 필요한 정보를 설정할 수 있습니다.

## 첫 번째 수입 작업 만들기

1. Cloudflare 대시보드에서, 가십시오**호스트 이미지**사이트 맵

   <DashButton url="/?to=/:account/images/hosted" />

2. 제품정보**Sourcing 장비**.

3. 제품정보**수입 이미지**수입 작업을 만들려면.

4. 내 계정**소스 이름**당신의 근원에게 적합한 이름을 줍니다.

5. 내 계정**Amazon S3 버킷 정보**이미지가 저장되는 S3의 물통 이름을 입력하십시오.

6. 내 계정**필수 자격**Amazon S3 자격 증명을 입력하십시오. Cloudflare 당신의 소스에 이미지 및 이미지를 가져 오기. 더 알아보기[회사 소개](/images/upload-images/sourcing-kit/credentials/)credentials를 설정하는 방법에 대해 자세히 알아보세요.

7. 제품정보**이름 \***.

8. 내 계정**기본 규칙**Amazon S3 경로를 정의하여 이미지를 가져올 수 있고 Cloudflare 이미지 계정에 이미지를 복사하려는 경로. 이것은 선택적이고, 당신은 이 분야 공백을 떠날 수 있습니다.

9. 같은 페이지에서,**이미지를 덮어**, 당신은 당신의 근원 변화에 있는 파일이 언제 일어나는 것을 선택해야 합니다. 권장 동작은 새로운 이미지를 복사하고 Cloudflare 이미지 계정에서 오래된 것들을 덮는 것입니다. Cloudflare Images 계정에서 이미 가지고 있는 것을 선택할 수도 있습니다.

10. 제품정보**이름 \***.

11. 리뷰 및 생성 된 수입 작업에 대한 정보를 확인합니다. 제품정보**수입 이미지**소스에서 이미지를 가져 오기 시작합니다.

당신의 수입 일은 지금 창조됩니다. Sourcing Kit 메인 페이지의 작업 상태를 검토 할 수 있습니다. 그것은 얼마나 많은 물체와 같은 정보를 표시 할 것입니다, 얼마나 많은 이미지가 수입 된, 어떤 오류가 발생했는지.

:::참조

Sourcing Kit는 계획 공간 할당량의 한계에 도달 할 때 경고합니다. 계획에서 사용할 수있는 공간을 배기하면 수입 작업이 낙관됩니다. Sourcing Kit의 메인 페이지에 이 경고를 볼 경우, 선택**계획 보기**계획의 한계를 변경하려면.

## 새로운 소스 정의

1. Cloudflare 대시보드에서, 가십시오**호스트 이미지**사이트 맵

   <DashButton url="/?to=/:account/images/hosted" />

2. 제품정보**Sourcing 장비**.

3. 제품정보**수입 이미지** > **새로운 소스 정의**.

반복 단계 4-11 in[첫 번째 수입 작업 만들기](#create-your-first-import-job)당신의 새로운 근원을 설치하기 위하여.

## 추가 수입 작업 정의

같은 다른 소스에서 많은 수입 작업을 할 수 있습니다. 기존 소스를 선택하면 새로운 수입 일자리를 창출 할 필요가 없습니다.

1. Cloudflare 대시보드에서, 가십시오**호스트 이미지**사이트 맵

   <DashButton url="/?to=/:account/images/hosted" />

2. 제품정보**Sourcing 장비**.

3. 제품정보**수입 이미지**.

4. 이미 형성된 소스 중 하나에서 선택하십시오.

반복 단계 8-11에서[첫 번째 수입 작업 만들기](#create-your-first-import-job)새로운 수입 작업 설정 완료.

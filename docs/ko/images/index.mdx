Cloudflare Images는 단일 API에서 이미지 인프라를 간소화하고 실행할 수 있도록 설계된 엔드 투 엔드 솔루션을 제공합니다.[Cloudflare의 글로벌 네트워크](https://www.cloudflare.com/network/).

이미지를 사용하는 두 가지 방법이 있습니다:

- **효율적으로 저장하고 이미지를 전달합니다.**&#x43;loudflare 이미지로 이미지를 업로드 할 수 있으며 동적 원본 이미지의 여러 변형을 제공합니다.
- **이미지 밖에 저장된 이미지 최적화**인터넷에서 공개적으로 사용할 수있는 이미지를 최적화 할 수있는 변환 요청을 만들 수 있습니다.

Cloudflare 이미지는 둘 다에 유효합니다[무료 및 유료 계획](/images/pricing/). 기본적으로, 모든 사용자는 원격 소스에서 이미지를 최적화하는 변환 기능의 제한된 사용법을 포함하는 Images Free plan에 액세스해야합니다.

:::note\[Image Resizing은 이제 변형으로 사용할 수 있습니다]

모든 이미지 조정 기능은 이미지와 변형으로 사용할 수 있습니다. 각 독특한 변화는 달력 달 당 한 번만 청구됩니다.

Image Resizing와 레거시 계획을 사용하는 경우 방문[대시보드](https://dash.cloudflare.com/)이미지 계획으로 전환합니다.

:::

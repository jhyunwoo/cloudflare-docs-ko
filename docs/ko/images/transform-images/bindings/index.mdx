·[관련 제품](/workers/runtime-apis/bindings/)연결하기[작업자](/workers/)개발자 플랫폼에 대한 외부 리소스에[제품정보](/images/transform-images/transform-via-workers/), [R2 물통](/r2/buckets/), 또는[모델 번호: KV 이름공간](/kv/concepts/kv-namespaces/).

이미지 API를 Worker에 바인딩하여 변환, 크기 및 URL을 통해 접근할 수 없는 이미지를 인코딩할 수 있습니다.

예를 들어, Workers를 사용하면 이미지와 상호 작용할 수 있습니다.

- 이미지를 변환 한 다음 브라우저에 게재하지 않고 R2로 직접 출력 이미지를 업로드하십시오.
- 이미지를 나타내는 바이트의 blob를 전달하여 R2에 저장된 이미지를 최적화하여 이미지에 대한 공개 URL을 fetching 대신합니다.
- 이미지를 크기를 조정, 워터 마크로 두 번째 이미지에 출력을 오버레이, 다음이 출력을 최종 결과로 변경.

바인딩은 당신의 노동자를 위한 Cloudflare 대시보드XQ 또는 당신의 프로젝트의 디렉토리에 있는 Wrangler 윤곽 파일에서 형성될 수 있습니다.

:::노트\[빌링]

이미지 바인딩에 모든 호출은 하나의 독특한 변환으로 계산합니다. 더 알아보기[이미지 가격](/images/pricing/)변형 청구에 대한 자세한 내용은.

:::

## 설치하기

이미지 바인딩은 per-Worker 기초에 활성화됩니다.

작업자 프로젝트의 디렉토리의 Wrangler 구성 파일에서 변수를 정의할 수 있습니다. 이 변수는 runtime에 외부 리소스에 바인딩되며, 이 변수를 통해 그와 상호 작용할 수 있습니다.

작업자에게 이미지를 바인딩하려면 WranglerXQ 구성 파일의 끝에 다음을 추가하십시오.

<WranglerConfig>
  ```jsonc
  {
  	"images": {
  		"binding": "IMAGES", //i.e. env.IMAGES에 당신의 노동자에서 유효한
  	},
  }
  ```
</WranglerConfig>

작업자 코드 내에서 사용해서 이 바인딩과 상호 작용할 수 있습니다.`env.IMAGES.input()`이미지를 조작 할 수있는 객체를 구축하기 위해 (passed as`ReadableStream`).

## 제품 설명

### `.transform()`

- 이미지를 최적화하고 조작해야 하는 방법[이름 \*](/images/transform-images/transform-via-workers/#fetch-options)등`width`, `height`·`blur`.

### `.draw()`

- 지원하다[이미지 보기](/images/transform-images/draw-overlays/)다른 이미지.
- 그려진 이미지는 스트림, 또는 다른 이미지로 돌아갈 수 있습니다`.input()`그것은 조작 된.
- overlaid 이미지는 조작될 수 있습니다`opacity`, `repeat`, `top`, `left`, `bottom`·`right`. 다른 모수를 적용하기 위하여, 당신은 아이를 통과할 수 있습니다`.transform()`이 방법 안쪽에 기능.

예를 들어, 이미지에 크기를 둔 워터 마크를 그리기 위해:

<TypeScriptExample>
  ```ts
  //Workers 자산, R2, KV 등에서 워터 마크를 넣으십시오
  const watermark: ReadableStream = getWatermarkStream();

  //본문 바로가기
  const image: ReadableStream = getImageStream();

  const response = (
  	await env.IMAGES.input(image)
  		.draw(env.IMAGES.input(watermark).transform({ width: 32, height: 32 }), {
  			bottom: 32,
  			right: 32,
  		})
  		.output({ format: "image/avif" })
  ).response();

  return response;
  ```
</TypeScriptExample>

### `.output()`

- 당신은 정의해야[지원되는 형식](/images/transform-images/#supported-output-formats)AVIF, WebP 또는 JPEG와 같은[변환된 이미지](/images/transform-images/).
- 이것은 기본 형식이 없어서 필요합니다.
- [이미지 품질](/images/transform-images/transform-via-url/#quality)지정하여 변경할 수 있습니다.`quality`1-100 스케일에.
- [애니메이션 보정](/images/transform-images/transform-via-url/#anim)통제될 수 있습니다`anim`모수. 설치하기`anim: false`애니메이션을 여전히 이미지로 줄일 수 있습니다.

예를 들어, 회전, 크기 및 이미지를 흐르려면 AVIF로 이미지를 출력하십시오.

<TypeScriptExample>
  ```ts
  const info = await env.IMAGES.info(stream);
  //Stream은 유효한 이미지를 포함하고 width/height는 info object에서 사용할 수 있습니다.

  //사용 사례에 따라 형식을 결정할 수 있습니다.
  const outputFormat = "image/avif";

  const response = (
  	await env.IMAGES.input(stream)
  		.transform({ rotate: 90 })
  		.transform({ width: 128 })
  		.transform({ blur: 20 })
  		.output({ format: outputFormat })
  ).response();

  return response;
  ```
</TypeScriptExample>

### `.info()`

- 이미지에 대한 출력 정보 등`format`, `fileSize`, `width`·`height`.

:::참조

Images 바인딩의 응답은 자동으로 캐시되지 않습니다. Workers는 당신이 직접 상호 작용할 것을 시켰습니다[캐시 API](/workers/runtime-apis/cache/)캐시 행동을 사용자 정의합니다. Cloudflare의 캐시에서 변환을 저장하기 위해 스크립트에서 논리를 구현할 수 있습니다.

:::

## 로컬 이미지 바인딩을 가진 Interact

Images API는 로컬 개발에서 사용할 수 있습니다.[모델 번호: Wrangler](/workers/wrangler/install-and-update/), Workers를 위한 명령 선 공용영역. 로컬 개발의 이미지 바인딩을 사용하면 사용료가 부과되지 않습니다.

Wrangler는 이미지 API의 2개의 다른 버전을 지원합니다:

- Images API를 통해 사용할 수있는 모든 기능을 지원하는 고밀도 버전. 이것은 Cloudflare가 생산에서 세계적으로 실행되는 동일한 버전입니다.
- Resizing 및 회전과 같은 기능의 하위 세트 만 지원되는 저렴한 오프라인 버전.

이미지의 저편성 버전을 테스트하려면 실행할 수 있습니다.`wrangler dev`:

```txt
npx wrangler dev
```

현재 이 버전은 오직 지원`width`, `height`, `rotate`·`format`.

이미지의 고밀도 먼 버전을 시험하기 위하여, 당신은 사용할 수 있습니다`--remote`플래그:

```txt
npx wrangler dev --remote
```

테스트 할 때[Workers Vitest 통합](/workers/testing/vitest-integration/), 낮은 fidelity 오프라인 버전은 기본적으로 사용되며 테스트에서 Cloudflare API를 타격합니다.

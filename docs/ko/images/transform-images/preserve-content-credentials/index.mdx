[콘텐츠 Credentials](https://contentcredentials.org/)(또는 C2PA 메타데이터)는 디지털 자산의 전체 검증 체인을 포함하는 메타데이터의 유형입니다. 이미지의 생성, 저자, 편집 흐름에 대한 정보를 제공합니다. 이 데이터는 암호화되어 인증되고 검증 될 수 있습니다.[공지사항](https://contentcredentials.org/verify).

원격 소스에 저장된 이미지를 최적화할 때 Content Credentials를 보존할 수 있습니다.

## 이름 \*

Content Credentials가 각 영역에 대해 처리되는 방법을 구성할 수 있습니다.

Cloudflare 대시보드**제품정보** > **연락처**, 특정 영역으로 이동하고 내용을 보존하기 위해 toggle을 활성화:

![대시보드의 필수 보존 내용](~/assets/images/images/preserve-content-credentials.png)

이 설정의 동작은 다음과 같다.[`metadata`](/images/transform-images/transform-via-url/#metadata)각 변환의 매개 변수.

예를 들어, 변환 specifies`metadata=copyright`, 그런 다음 EXIF 저작권 태그와 모든 콘텐츠 Credentials는 결과 이미지에 보존되고 다른 모든 메타 데이터가 불멸 될 것입니다.

CloudflareXQ는 소스 이미지에 포함된 기존 콘텐츠 Credentials를 유지하고 자동적으로 추가하고 암호화적으로 추가 작업을 서명합니다.

이 설정이 비활성화되면 기존 콘텐츠 Credentials가 항상 삭제됩니다.

특별히 포맷 된 URL을 통해 요청하여 이미지를 변환하고 크기를 조정할 수 있습니다. 이 방법은 코드를 작성할 필요가 없습니다, 웹 사이트의 HTML 마크 업만 변경하여 새로운 URL을 사용합니다. 형식은:

```txt
https://<ZONE>/cdn-cgi/image/<OPTIONS>/<SOURCE-IMAGE>
```

URL의 각 부분의 고장은 다음과 같습니다.

- `<ZONE>`
  - 귀하의 도메인 이름 Cloudflare. 다른 제3자 이미지 재생 서비스와는 달리, 이미지 변환은 API를 위한 별도의 도메인 이름을 사용하지 않습니다. 이미지 변환을 가진 각 Cloudflare 지역은 자체를 resizing 취급할 수 있습니다. 웹 사이트에서 사용되는 URL에서이 부분은 omitted 할 수 있으므로 URL은 시작`/cdn-cgi/image/`.

- `/cdn-cgi/image/`
  - Cloudflare의 내장 노동자에 의해 처리되는 특별한 경로는 식별하는 고정 접두사.

- `<OPTIONS>`
  - 같은 옵션의 상품 목록`width`, `height`·`quality`.

- `<SOURCE-IMAGE>`
  - 원래 서버의 절대 경로, 또는 절대 URL (와 함께 시작)`https://`또는`http://`), 크기를 resize 이미지에 지적. URL 인코딩되지 않은 경로는 URL 인코딩되지 않습니다. URL을 재구성하여 안전하게 구성할 수 있습니다.`/cdn-cgi/image/options`원본 이미지 URL. 예를 들면:`/cdn-cgi/image/width=100/https://s3.example.com/bucket/image.png`.

다음은 URL의 예입니다.`<OPTIONS>`설정하기`width=80,quality=75`·`<SOURCE-IMAGE>`이름 \*`uploads/avatar1.jpg`:

```html
<img src="/cdn-cgi/image/width=80,quality=75/uploads/avatar1.jpg" />
```

## 이미지 크기

이상적으로, 이미지 크기는 페이지에 표시된 크기 정확하게 일치해야 합니다. 페이지가 표시된 썸네일을 포함하면`<img width="200" …>`, 그 후에 이미지는 resize 있어야 합니다`width=200`. 정확한 크기는 시간의 앞에 알려지지 않은 경우에, 사용[반응형 이미지 기술](/images/manage-images/create-variants/).

사용할 수 없는 경우`<img srcset>`마크 업, 그리고 특정 최대 크기를 하드 코딩해야, Cloudflare는 다음과 같은 크기를 권장합니다:

- 데스크톱 브라우저의 최대 1920 픽셀.
- 정제를 위한 960 화소의 최대.
- 휴대전화를 위한 640의 화소의 최대.

여기에는 이미지의 최대 크기를 구성하는 Markup의 예입니다.

```txt
/cdn-cgi/image/fit=scale-down,width=1920/<YOUR-IMAGE>
```

더 보기`fit=scale-down`옵션은 이미지를 크게 확대하지 않습니다.

장치를 감지 할 수 있습니다.`CF-Device-Type`기타 제품[Cache 규칙을 통해](/cache/how-to/cache-rules/examples/cache-device-type/).

## 뚱 베어

Resizing 원인 원래 이미지는 원래 서버와 캐시에서 fetched - HTTP 캐싱의 일반적인 규칙,`Cache-Control`헤더 등 여러 가지 이미지 크기를 요청하면 원래의 이미지를 재사용 할 수 있습니다. 원래 서버에서 여분의 전송을 발생시키지 않고.

:::참조

Custom Cache Keys가 원래 이미지에 사용되면, 원본 이미지는 캐시되지 않을 수 있으며 더 많은 통화로 인해 발생할 수 있습니다.

:::

크기 이미지는 원본 이미지로 동일한 캐싱 규칙을 따르고, 최소 캐시 시간이 1 시간입니다. 이미지가 더 자주 업데이트되면 추가`must-revalidate`이름 \*`Cache-Control`헤더. Resizing support cache revalidation, 그래서 우리는 이미지 제공`Etag`헤더. 더 알아보기[더 많은 정보를 위한 Cache docs](/cache/concepts/cache-control/#revalidation).

Cloudflare 이미지는 별도의 크기 변형을 제거하지 않습니다. 시작 URL`/cdn-cgi/`수 없습니다. 그러나, 원본 이미지의 URL의 정화는 또한 크기의 변종의 모두를 순화할 것입니다.

브라우저 TTL는 브라우저의 캐시에 얼마나 오래 머무는지 제어하고 특히 구성합니다.`cache-control`응답 헤더.

### 기본 TTL

기본적으로, 이미지의 TTL는 2 일로 설정하여 사용자의 요구를 충족시키기 위해 동일한 이미지를 다시로드합니다.[주문 ID](/images/upload-images/upload-custom-path/).

## 주문 설정

브라우저 TTL, 계정 또는 이름 변형을 제어하는 두 가지 사용자 정의 설정을 사용할 수 있습니다. 브라우저가 캐시에 이미지를 유지해야하는 방법을 조정하려면, 몇 초에 TTL을 설정, 얼마나 유사한`max-age`헤더 설정입니다. 값은 1 시간에서 1 년 사이에 간격이어야합니다.

### 브라우저 TTL 계정

계정 당 브라우저 TTL 설정은 기본 TTL을 무시합니다.

```bash title="Example"
curl --request PATCH 'https://api.cloudflare.com/client/v4/accounts/{account_id}/images/v1/config' \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "browser_ttl": 31536000
}'
```

브라우저 TTL이 모든 이미지에 대해 1 년으로 설정되면 응답`cache-control`헤더는 기본적으로`public`, `max-age=31536000`, `stale-while-revalidate=7200`.

### Browser TTL 에 대한 이름 변종

Browser TTL 를 정의하는 것은 이미지 변형을 만들거나, 특히 이미지 변형을 업데이트 할 때 위의 모든 것을 무시하는 더 많은 과립 옵션입니다.`browser_ttl`몇 초 안에 옵션.

```bash title="Example"
curl 'https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_TAG>/images/v1/variants' \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "id":"avatar",
  "options": {
    "width":100,
    "browser_ttl": 86400
  }
}'
```

브라우저 TTL이 이 변종과 관련된 이미지에 대해 1 일로 설정되면 응답`cache-control`헤더는 기본적으로`public`, `max-age=86400`, `stale-while-revalidate=7200`.

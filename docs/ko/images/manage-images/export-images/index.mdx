모델 번호: Cloudflare 이미지는 Cloudflare QXQX대시보드 및 API를 통해 이미지 내보내기를 지원합니다. 이미지의 원본 버전을 얻을 수 있습니다.

## Cloudflare 대시보드를 통해 이미지 내보내기

1. Cloudflare 대시보드에서, 가십시오**연락처**사이트 맵

   <DashButton url="/?to=/:account/images/transformations" />

2. 수출하려는 이미지 또는 이미지를 찾습니다.

3. 단일 이미지를 내보내려면, 선택**수출입**메뉴에서 여러 이미지를 내보내려면 각 이미지 옆에 체크 박스를 선택하고 다음 선택**수출 선택**.

당신의 이미지는 당신의 기계에 다운로드됩니다.

## API를 통한 내보내기 이미지

더 보기`GET`아래 예시로 요청합니다.`<IMAGE_ID>`API 호출 URL에 인코딩된 완전히 URL이어야 합니다.

`GET accounts/<ACCOUNT_ID>/images/v1/<IMAGE_ID>/blob`

Cloudflare에 업로드된 이미지 제공 이미지, 당신은 있어야 합니다:

- 이미지 계정 해시
- 이미지 ID
- Variant 또는 유연한 변형 이름

이미지에 업로드된 적어도 하나의 이미지가 있어야 합니다. 개발자 리소스에서 이미지 대시보드에서 기본 URL 형식을 찾을 수 있습니다.

![이미지 제품 내의 개발자 리소스 섹션은 Cloudflare Dashboard를 형성합니다.](~/assets/images/images/image-delivery-url.png)

일반적인 이미지 배송 URL은 아래 예와 유사합니다.

`https://imagedelivery.net/<ACCOUNT_HASH>/<IMAGE_ID>/<VARIANT_NAME>`

예를 들어, 교체해야 합니다.`<ACCOUNT_HASH>`이미지 계정 해시와 함께`<IMAGE_ID>`·`<VARIANT_NAME>`, 이미지를 게재하기 시작합니다.

선택할 수 있습니다.**다운로드**이미지 옆에 이미지로 복사할 수 있는 이미지 URL로 이미지를 미리 볼 수 있습니다. 링크가 완전히 형성됩니다**이미지 URL**아래 예제와 비슷하게 보일 것입니다.

이 예제에서:

- `ZWd9g1K7eljCn_KDTu_MWA`이미지 계정 해시입니다.
- `083eb7b2-5392-4565-b69e-aff66acddd00`이미지 ID입니다. 생성된 ID 대신 Custom ID를 사용할 수 있습니다.
- `public`변형 이름입니다.

사용자가 이미지를 요청할 때, Cloudflare Images는 클라이언트 헤더와 이미지 유형에 의해 결정되는 최적의 형식을 선택합니다.

## Optimize 형식

모델 번호: Cloudflare 이미지는 PNG, JPEG 및 GIF 파일을 더 효율적인 AVIF 및 WebP 형식으로 자동으로 변환합니다. 고객 브라우저가 지원할 때마다 발생합니다. 브라우저가 AVIF를 지원하지 않는 경우, Cloudflare 이미지는 WebP로 돌아갑니다. WebP에 대한 지원이 없다면 Cloudflare Images는 원래 형식의 압축 파일을 제공합니다.

Uploaded SVG 파일이 제공됩니다.[질산염 SVGs](/images/upload-images/).

Variants는 이미지가 다른 사용 사례에 대해 크기를 지정할 수 있도록 합니다. 기본적으로 이미지가 제공됩니다.`public`변형,하지만 당신은 당신의 요구에 맞는 100 변형까지 만들 수 있습니다. 이 단계를 따라 변형을 만듭니다.

:::참조

Cloudflare 이미지는 SVG 파일을 전달할 수 있지만 잘못된 확장 형식이기 때문에 크기를 조정할 수 없습니다.
Cloudflare 대시보드를 통해 크기.
주요 특징

1. Cloudflare 대시보드에서, 얻은**호스트 이미지**사이트 맵

   <DashButton url="/?to=/:account/images/hosted" />

2. 선택하기**이름 \***&#xD0ED;.

3. 제품정보**생성 변형**.

4. 당신의 변종 및 선택**이름 \***.

5. 새로운 변종에 대한 변수를 정의합니다. 옵션, 적합 유형, 특정 메타 데이터 옵션.

## API를 통해 크기

더 보기`POST`지원하다[변형 생성](/api/resources/images/subresources/v1/subresources/variants/methods/create/).

```bash
curl "https://api.cloudflare.com/client/v4/accounts/{account_id}/images/v1/variants" \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{"id":"<NAME_OF_THE_VARIANT>","options":{"fit":"scale-down","metadata":"none","width":1366,"height":768},"neverRequireSignedURLs":true}
```

## 옵션 정보

더 보기`Fit`재산은 폭과 고도 차원이 해석되어야 하는 방법을 설명합니다. 아래 차트는 각 옵션을 설명합니다.

| 적당한 선택권 | 채용 정보                                                                                                                                            |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 지금 연락   | 이미지는 주어진 폭 또는 고도 안에 완전히 적합하기 위하여 크기에 있는 싹, 그러나 확대되지 않을 것입니다.                                                                                     |
| 제품정보    | 이미지는 지정된 폭 또는 고도 안에 가능한 한 큰 크기 (shrunk 또는 확대되는) 입니다 종횡비를 보존하는 동안.                                                                                |
| 회사 소개   | 이미지는 정확히 폭과 고도에 의해 지정된 전체 영역을 채우고 필요한 경우 작을 것입니다.                                                                                                |
| 뚱 베어    | 이미지는 폭과 고도에 의해 지정된 지역 안에 적합하기 위하여 새겨지고. 이미지는 확대되지 않습니다. 주어진 차원 보다는 더 작은 이미지를 위해, 그것은 동일입니다`scale-down`. 주어진 차원 보다는 더 큰 이미지를 위해, 그것 동일입니다`cover`. |
| 회사 소개   | 이미지는 지정된 폭 또는 고도 안에 가능한 한 큰 크기 (shrunk 또는 확대되는) 입니다 종횡비를 보존하는 동안. 추가 영역은 배경 색상으로 채워집니다 (기본적으로 흰색).                                               |

## Metadata 옵션

Variants는 이미지의 메타 데이터 정보와 함께 할 것을 선택할 수 있습니다. 에 의해**메타데이터**dropdown, 선택:

- 모든 메타데이터
- 저작권을 제외한 모든 메타데이터
- 모든 메타데이터

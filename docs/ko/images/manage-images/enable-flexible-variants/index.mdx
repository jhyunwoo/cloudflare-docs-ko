유연한 변형은 일반 변형보다 더 많은 옵션을 제공 할 수있는 동적 재조합과 변형을 만들 수 있습니다. 이 옵션은 기본적으로 활성화되지 않습니다.

## Cloudflare 대시보드를 통해 유연한 변형 가능

1. Cloudflare 대시보드에서, 얻은**호스트 이미지**사이트 맵

   <DashButton url="/?to=/:account/images/hosted" />

2. 선택하기**이름 \***&#xD0ED;.

3. 이름 \***유연한 변형**.

## API를 통해 유연한 변형 가능

더 보기`PATCH`요청하기[변형 endpoint 업데이트](/api/resources/images/subresources/v1/subresources/variants/methods/edit/).

```bash
curl --request PATCH https://api.cloudflare.com/client/v4/accounts/{account_id}/images/v1/config \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{"flexible_variants": true}'
```

활성화 후에, 당신은 사용할 수 있습니다[변환 모수](/images/transform-images/transform-via-url/#options)어떤 Cloudflare 이미지에. 예를 들어,

`https://imagedelivery.net/{account_hash}/{image_id}/w=400,sharpen=3`

:::참조

유연한 변형은 이미지에 사용할 수 없습니다.[서명된 납품 URL](/images/manage-images/serve-images/serve-private-images).

:::

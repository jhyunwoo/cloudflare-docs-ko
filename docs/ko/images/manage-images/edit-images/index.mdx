편집 옵션은 특정 이미지를 수정할 수있는 옵션을 제공합니다. 이미지를 편집 할 선택 후, 당신은 할 수:

- 특정 이미지와 함께 사용하려면 서명된 URL을 요구합니다.
- CURL 명령을 사용하여 이미지에 접근하기 위해 예로 사용할 수 있습니다.
- 계정에서 설정된 모든 변종에 대한 완전형 URL을 사용합니다.

이미지를 편집하려면:

1. Cloudflare 대시보드에서, 가십시오**연락처**사이트 맵

   <DashButton url="/?to=/:account/images/transformations" />

2. 수정 및 선택하려는 이미지를 찾습니다**제품정보**.

이 효과에 대한 특정 변형을 처음 만들거나 이전에 생성 된 변형을 편집하여 이미지 변형에 blur를 적용 할 수 있습니다. SVG 파일을 blur 할 수 없습니다.

더 알아보기[Resize 이미지](/images/manage-images/create-variants/)변형을 만드는 데 도움이됩니다. API를 참조하여 유연한 변형을 사용하여 blur를 사용하는 방법을 배울 수 있습니다.

이미지를 흐르기 위하여:

1. Cloudflare 대시보드에서, 얻은**호스트 이미지**사이트 맵

   <DashButton url="/?to=/:account/images/hosted" />

2. 선택하기**이름 \***&#xD0ED;.

3. blur로 원하는 변형을 찾아 선택**제품정보** > **사용자 정의 옵션**.

4. blurring 효력을 조정하기 위하여 slider를 사용하십시오. blurring 효과가 얼마나 강한지 볼 미리보기 이미지를 사용할 수 있습니다.

5. 제품정보**제품 정보**.

이미지는 지금 blurred 효력을 표시해야 합니다.

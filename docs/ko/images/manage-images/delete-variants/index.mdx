이미지 대시보드 또는 API를 통해 변형을 삭제할 수 있습니다. 삭제할 수 없는 유일한 변형은 공개됩니다.

:::카트로션

변형을 삭제하는 것은 그 변형을 포함하는 다른 이미지에 영향을 미칠 수있는 글로벌 액션입니다.

:::

## Cloudflare 대시보드를 통해 변형을 삭제

1. Cloudflare 대시보드에서, 얻은**호스트 이미지**사이트 맵

   <DashButton url="/?to=/:account/images/hosted" />

2. 선택하기**이름 \***&#xD0ED;.

3. 제거하고 선택하려는 변형 찾기**이름 \***.

## API를 통한 변형 삭제

더 보기`DELETE`삭제 변형 endpoint에 요청.

```bash
curl --request DELETE https://api.cloudflare.com/client/v4/account/{account_id}/images/v1/variants/{variant_name} \
--header "Authorization: Bearer <API_TOKEN>"
```

변형이 삭제 된 후 응답 반환`"success": true.`

Cloudflare 이미지 저장에서 이미지를 삭제할 수 있습니다.

## Cloudflare 대시보드XQ를 통해 이미지 삭제

1. Cloudflare 대시보드에서, 갑니다**연락처**사이트 맵

   <DashButton url="/?to=/:account/images/transformations" />

2. 제거하고 선택하려는 이미지 찾기**이름 \***.

3. (선택) 한 이미지 이상 삭제하려면 삭제하고 싶은 이미지 옆에 체크 박스를 선택하십시오.**선택 사항**.

당신의 이미지는 계정에서 삭제됩니다.

## API를 통한 이미지 삭제

더 보기`DELETE`요청하기[이미지 endpoint 삭제](/api/resources/images/subresources/v1/methods/delete/). `{image_id}`API 호출 URL에 인코딩된 완전히 URL이어야 합니다.

```bash
curl --request DELETE https://api.cloudflare.com/client/v4/accounts/{account_id}/images/v1/{image_id} \
--header "Authorization: Bearer <API_TOKEN>"
```

이미지가 삭제 된 후 응답 반환`"success": true`.

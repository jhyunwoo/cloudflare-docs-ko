웹 페이지에 이미지를 최적화하는 게으른 로딩을 사용할 수 있습니다. 이것은 느린 네트워크 연결 또는 약한 처리 기능 같이 이동할 수 있는 보기의 일반적인 어려움을 돕습니다.

Lazy 선적에는 2개의 주요 이점이 있습니다:

- **더 빠른 페이지로드 시간**— 이미지는 페이지가 열릴 때 페이지 대신 페이지의 사용자 스크롤으로로드됩니다.
- **이미지 납품을 위한 더 낮은 비용**- Cloudflare를 사용할 때 이미지, 사용자가 실제로 볼 이미지 만로드 할 수 있습니다. 게으른 로딩, 이미지로 스크롤하지 않은 이미지는 청구 가능한 이미지 요청을 통해 계산되지 않습니다.

Lazy 로딩은 Chrome, Safari, Firefox, Opera 및 Edge와 같은 모든 크롬 기반 브라우저에서 기본적으로 지원됩니다.

:::참조
사용자 정의 JavaScript 또는 JavaScript 라이브러리를 포함하는 이전 방법을 사용하는 경우, 게으른 로딩은 브라우저가 다운로드, 파스를 필요로하고 JavaScript를 실행하기 때문에 페이지의 초기 로드 시간을 증가시킬 수 있습니다.
주요 특징

## 적재 속성을 수정

로드 속성을 수정하지 않고, 대부분의 브라우저는 페이지에 모든 이미지를 읽을 것이며, 기본적으로 viewport에 가까운 이미지의 우선 순위. 수정하여 이것을 과도하게 할 수 있습니다.`loading`이름 \*

2 개 있습니다.`loading`당신의 속성`<img>`태그 :`lazy`·`eager`.

### Lazy 선적

Lazy 로딩은 대부분의 이미지를 추천합니다. Lazy 로딩으로, 이미지와 같은 리소스는 viewport에서 특정 거리를 도달 할 때까지 무시됩니다. 이미지가 문턱에 도달하지 않으면로드되지 않습니다.

수정의 예`loading`당신의 속성`<img>`태그가 될`"lazy"`:

```html
<img src="example.com/cdn-cgi/width=300/image.png" loading="lazy">
```

### Eager 선적

viewport에 있는 이미지가 있는 경우에, eager 선적은, 게으른 선적 대신, 추천됩니다. Eager로드는 페이지의 위치와 관계없이 초기 페이지로드에서 자산을로드합니다.

수정의 예`loading`당신의 속성`<img>`태그가 될`"eager"`:

```html
<img src="example.com/cdn-cgi/width=300/image.png" loading="eager">
```

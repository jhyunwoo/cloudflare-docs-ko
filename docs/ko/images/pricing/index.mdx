기본적으로 모든 사용자는 Images Free 플랜에 있습니다. 무료 플랜은 R2와 같은 이미지 밖에 저장된 이미지를 최적화 할 수있는 변환 기능에 액세스 할 수 있습니다.

Paid 계획은 변환뿐만 아니라 이미지 저장에 액세스 할 수 있습니다.

가격은 당신이 사용하는 특징에 달려 있습니다. 아래 표는 각 사용 케이스에 사용할 수 있습니다.

| 사용 사례                        | 미터                    | 적용분야       |
| ---------------------------- | --------------------- | ---------- |
| Images 밖에 저장된 이미지 최적화        | 이미지 Transformed       | 무료 및 유료 계획 |
| Cloudflare 이미지에 저장되는 낙관한 이미지 | Images Stored, 이미지 전달 | 유료 플랜      |

## 이미지 무료

무료 플랜에서 매월 5,000개의 독특한 변환을 무료로 요청할 수 있습니다.

5,000개의 독특한 변형을 초과하면:

- 캐시의 기존 변형은 예상대로 계속됩니다.
- 새로운 변화가 돌아갑니다.`9422`오류. 소스 이미지가 같은 도메인에서 전달되는 경우, 다음을 사용할 수 있습니다.[`onerror`이름 \*](/images/transform-images/transform-via-url/#onerror)원본 이미지로 리디렉션합니다.
- 무료 플랜의 제한을 초과하지 않습니다.

매월 5,000 개 이상의 독특한 변환을 요청하려면 이미지 유료 플랜을 구입할 수 있습니다.

## 이미지 유료

Images Paid 플랜을 구입하면 자신의 저장을 선택할 수 있으며 이미지에 저장을 추가 할 수 있습니다.

| 기본 정보           | 가격 책정                                           |
| --------------- | ----------------------------------------------- |
| 이미지 Transformed | 첫 번째 5,000 독특한 변환 포함 + $0.50 / 1,000 독특한 변환 / 월 |
| 이미지 저장          | $5 / 100,000 이미지 저장 / 월                         |
| 이미지 제공          | $1 / 100,000 이미지 배달 / 월                         |

이미지의 외부에 저장된 이미지를 최적화하면 이미지에 대해서만 청구됩니다.

또는 Images Stored 및 Images Delivered는 이미지에 저장되는 이미지에만 적용됩니다. 이미지에 저장 된 이미지를 최적화 할 때 이미지 전달을 통해이 카운트 - 이미지가 변형되지 않습니다.

## 미터

### 이미지 Transformed

독특한 변환은 설정에 따라 원래 이미지를 변환하는 요청입니다.[지원된 모수](/images/transform-images/transform-via-url/#options). 이 미터는 이미지의 외부 저장되는 이미지를 최적화할 때만 사용됩니다.
사용시[이미지 바인딩](/images/transform-images/bindings/)Workers에서 이미지 또는 매개 변수가 독특하다는 것을 여부에 관계없이 변형으로 모든 호출합니다.

예를 들어, 변환하는 경우`thumbnail.jpg`100x100으로, 그 다음 하나의 독특한 변환으로 계산합니다. 같은 변화`thumbnail.jpg`200x200로, 이 계산은 별도의 독특한 변환입니다.

각 달력 달 안에 요청한 고유한 변환의 수에 청구됩니다. 같은 달 안에 동일한 변화에 대한 반복 요청은 그 달 동안 한 번만 계산됩니다.

더 보기`format`매개 변수는 하나의 청구 가능한 변환으로 계산되며 이미지의 여러 사본이 제공됩니다. 즉,`width=100,format=auto/thumbnail.jpg`일부 사용자에게 AVIF 및 WebP로 다른 사용자에게 제공되며, 이 두 가지 대신 하나의 고유 한 변환으로 계산됩니다.

#### 예제 #1

매달 5개의 다른 크기에 있는 2,000의 먼 이미지를 봉사하는 경우에, 그 후에 10,000의 유일한 변환에 있는 이 결과. 매월 예상 비용은 다음과 같습니다.

|     | 제품 정보               | 지원하다  | 청구 수량 | 가격대비       |
| --- | ------------------- | ----- | ----- | ---------- |
| 연락처 | 10,000개의 독특한 변환[^5] | 5,000 | 5,000 | $2.50 [^6] |

#### 예 #2

이용안내[R2](/r2/)저장을 위해, 당신의 추정된 매달 비용은 당신의 월간 이미지 비용 및 매달의 합계일 것입니다[R2 비용](/r2/pricing/#storage-usage).

예를 들어, 평균 크기 5 MB를 가진 R2에 5,000 이미지를 업로드하고 5 가지 크기의 이미지의 2,000을 제공합니다. 그 다음 달의 예상 비용은 다음과 같습니다.

|          | 제품 정보               | 지원하다   | 청구 수량 | 가격대비        |
| -------- | ------------------- | ------ | ----- | ----------- |
| 제품 정보    | 25개 GB[^1]          | 10개 GB | 1개 GB | $0.22 [^7]  |
| 클래스 A 작업 | 5,000 글[^2]         | 1 백만   | 0     | $0.00 [^8]  |
| 클래스 B 작업 | 10,000 읽음[^3]       | 10 백만  | 0     | $0.00	[^9]  |
| 연락처      | 10,000개의 독특한 변환[^4] | 5,000  | 5,000 | $2.50	[^10] |
| **전체보기** |                     |        |       | **$2.72**   |

### 이미지 저장

이미지 저장은 이미지 유료 플랜에서만 가능합니다. 한 달에 저장 된 모든 100,000 이미지에 대해 $ 5의 증가에 저장을 구입할 수 있습니다.

미리 정의된 변형을 만들 수 있습니다. 이미지가 크기를 변경해야 합니다.`thumbnail`100x100로`hero`1600x500로.

Images Stored에 업로드 된 이미지 수만; defining 변형은 저장 한계에 영향을 미치지 않습니다.

### 이미지 제공

이미지에 저장되는 이미지를 위해, 당신은 달 당 배달된 각 100,000의 이미지를 위해 $1를 incur. 이 미터는 원격 소스에 저장 된 변환 된 이미지가 포함되지 않습니다.

브라우저에 의해 요청된 모든 이미지는 청구 가능한 요청으로 계산됩니다.

#### 이름 \*

소매 웹 사이트에는 이미지가 10 이미지를 제공하는 제품 페이지가 있습니다. 페이지가 이번 달에 10,000 번 방문한 경우, 이 결과는 100,000 이미지 전달 — 또는 $1.00 청구 가능한 사용.

[^1]: 5,000 객체 × 객체 당 5MB

[^2]: 5,000 객체 × 1 객체 당 쓰기

[^3]: 2,000 객체 × 5 객체당 읽기

[^4]: 2,000 원본 이미지 × 5 크기

[^5]: 2,000 원본 이미지 × 5 크기

[^6]: (5,000개의 변화 / 1,000) × $0.50

[^7]: 15 GB × $0.015 / GB 개월

[^8]: 0 × $ 4.50 / 백만 요청

[^9]: 0 × $0.36 / 백만 요청

[^10]: (5,000개의 변화 / 1,000) × $0.50

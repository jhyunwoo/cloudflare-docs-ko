먼저 API 요청을 만들기 전에 CloudflareXQ를 가지고 있는지 확인하십시오. 계정 ID 및 API 토큰.

## 첫 번째 API 요청 확인

```bash
curl --request POST \
  --url https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/images/v1 \
  --header 'Authorization: Bearer <API_TOKEN>' \
  --header 'Content-Type: multipart/form-data' \
  --form file=@./<YOUR_IMAGE.IMG>
```

## 영역에서 변환

Cloudflare 이미지의 외부에 저장되는 이미지를 동적으로 최적화하고 사용하여 전달할 수 있습니다.[변환 URL](/images/transform-images/transform-via-url/).

1. Cloudflare 대시보드에서, 가십시오**연락처**사이트 맵

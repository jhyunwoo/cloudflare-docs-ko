<Description>
  사용자의 개인 정보를 보호하는 MASQUE 기반 포워드 프록시는 지리적 위치 정확도를 보존하면서.
</Description>

<Plan type="enterprise" />

프라이버시 프록시는 Cloudflare의 글로벌 네트워크에서 실행되는 관리 프록시 서비스입니다. 그것은 사용[이름 \*](https://datatracker.ietf.org/wg/masque/about/)HTTP CONNECT 및 CONNECT-UDP 방식을 통해 TCP 및 UDP 트래픽 프록시에 대한 프로토콜 스위트. HTTP/2 및 HTTP/3.

개인 정보 보호 프록시는 사용자의 활동에서 사용자 ID를 분리합니다. 사용자가 방문한 목적지를 공개하지 않고 프록시에 인증하고, 대상 서버는 Cloudflare IP 주소에서 요청을 참조하십시오.

개인 정보 보호 정책[Microsoft Edge 보안 네트워크](https://blog.cloudflare.com/cloudflare-now-powering-microsoft-edge-secure-network/)두 번째 홉 릴레이로 봉사[iCloud 전용 릴레이](https://blog.cloudflare.com/icloud-private-relay/).

## 주요 특징

<Feature header="Single-hop 배포" href="/privacy-proxy/concepts/deployment-models/#single-hop">
  Cloudflare가 인증, 프록시 및 egress를 처리하는 독립 프록시로 개인 프록시를 배포합니다.
</Feature>

<Feature header="Double-hop 배포" href="/privacy-proxy/concepts/deployment-models/#double-hop">
  CloudflareXQ를 통해 사용자를 인증할 수 있는 최초의 hop 프록시를 운영합니다.
</Feature>

<Feature header="Geolocation 보존" href="/privacy-proxy/concepts/geolocation/">
  실제 IP 주소를 폭발하지 않고 사용자를 위한 정확한 지리적 위치 파악을 유지하고 위치 추적 콘텐츠 및 서비스 작업을 올바르게 보장합니다.
</Feature>

<Feature header="개인정보처리방침" href="/privacy-proxy/concepts/authentication/">
  Authenticate user with Privacy Pass token for production deploy, 개인 정보 보호 정책 액세스 제어를 보장합니다.
</Feature>

이 페이지 목록은 오픈 소스 라이브러리 및 도구로 개인 정보 보호 프록시에 연결할 수 있습니다.

## 채용정보

[채용정보](https://github.com/cloudflare/quiche/tree/master/tokio-quiche)Cloudflare의 Rust에 대한 오픈 소스 동기화 QUIC 및 HTTP / 3 라이브러리입니다. 그것은 결합[퀵메뉴](https://github.com/cloudflare/quiche)QUIC 구현[토키오](https://tokio.rs/)async 실행 시간.

tokio-quiche powers 개인 프록시 인프라, iCloud Private Relay 및 Cloudflare의 Oxy 기반 프록시에 대한 프록시 B를 포함하여. 그것은 생산에서 초당 HTTP / 3 요청의 수백만을 처리한다.

### 주요 특징

- Async QUIC 클라이언트 및 서버
- HTTP/3 지원`H3Driver`
- MASQUE CONNECT 및 CONNECT-UDP 지원
- Cloudflare의 네트워크의 규모로 전투 테스트

### 설치하기

tokio-quiche 추가하기`Cargo.toml`:

```toml
[dependencies]
tokio-quiche = "0.1"
```

### 지원하다

- [GitHub 저장소](https://github.com/cloudflare/quiche/tree/master/tokio-quiche)
- [프로젝트](https://crates.io/crates/tokio-quiche)
- [블로그 게시물: Async QUIC 및 HTTP/3은 쉽게 만들었습니다](https://blog.cloudflare.com/async-quic-and-http-3-made-easy-tokio-quiche-is-now-open-source/)

## 퀵메뉴

[퀵메뉴](https://github.com/cloudflare/quiche)Cloudflare의 저수준 QUIC와 RustXQ에 있는 HTTP/3 실시입니다. 그것은 어떤 신청 건축든지 통합할 수 있는 sans-io 디자인을 제공합니다.

quiche는 tokio-quiche가 빌드하는 기초입니다. quiche를 직접 사용하여 I / O에 미세 곡물 제어가 필요하거나 non-Tokio 런타임과 통합됩니다.

## 스낵 바

[스낵 바](https://github.com/cloudflare/chaussette)Privacy Proxy를 위해 설계된 SOCKS5-to-CONNECT 프록시입니다. 로컬 SOCKS5 연결을 수락하고 HTTP CONNECT 요청으로 전달합니다.

Chaussette는 SOCKS5를 지원하는 통합 애플리케이션에 유용하지만 HTTP CONNECT 프록시가 아닙니다.

### 주요 특징

- SOCKS5에서 HTTP CONNECT 변환
- 사전 공유 키 인증
- Geohash 지원 geolocation hints
- 옵션 mTLS 인증

### 제품 정보

```sh
MASQUE_PRESHARED_KEY=<YOUR_PSK> chaussette \
  --listen 127.0.0.1:1987 \
  --proxy https://your-proxy.example.com:443 \
  --geohash xn76c-JP
```

그런 다음 응용 프로그램을 구성`socks5://127.0.0.1:1987`그것의 프록시로.

### 지원하다

- [GitHub 저장소](https://github.com/cloudflare/chaussette)

## 컬럼

HTTP/2에 기본적인 테스트를 위해, 표준 컬은 CONNECT 프록시를 지원합니다:

```sh
curl -v \
  --proxy https://your-proxy.example.com \
  --proxy-header "Proxy-Authorization: Preshared <YOUR_PSK>" \
  https://example.com
```

컬은 또한 일 수 있습니다[quiche로 내장](https://github.com/curl/curl/blob/master/docs/HTTP3.md#quiche-version)HTTP/3 지원

## 비밀번호

[비밀번호](https://github.com/cloudflare/privacypass-ts)Cloudflare의 TypeScript는 프라이버시 패스 프로토콜의 구현입니다. 이 라이브러리를 사용하여 문제 및 redeem Privacy Pass 토큰을 개인 정보 보호 프록시로 인증합니다.

### 주요 특징

- 개인정보처리방침
- 공개적으로 검증 및 속도 제한 토큰 유형 지원
- 브라우저와 Node.js 환경과 호환

### 설치하기

```sh
npm install @cloudflare/privacypass-ts
```

### 지원하다

- [GitHub 저장소](https://github.com/cloudflare/privacypass-ts)
- [npm 패키지](https://www.npmjs.com/package/@cloudflare/privacypass-ts)

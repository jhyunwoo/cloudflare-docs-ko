일반적인 알림 오류에 대한 자세한 내용은 아래 정보를 참조하고 해결하는 방법.

## Webhook 테스트 상태 코드로 실패 400 400 나쁜 요청

이 오류는 현재 지원되지 않은 webhook을 구성하려고 할 때 발생할 수 있습니다. PagerDuty webhook 설정.

PagerDuty는 아래 구성해야 합니다.[연결 알림 서비스](/notifications/get-started/configure-pagerduty/).

## 삭제된 사용자는 여전히 알림을 받고 있습니다.

계정을 통해 사용자를 제거 할 때**계정 관리** > **이름 \***&#x43;loudflare 대시보드에서, 그들의 이메일 주소는 기존 알림에서 제거되지 않습니다.

알림 설정에서 이메일 주소를 제거해야 합니다.[자주 묻는 질문](/notifications/get-started/#edit-a-notification).

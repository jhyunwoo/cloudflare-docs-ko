알림 역사는 알림 서비스를 통해 계정에 전송 된 알림의 로그입니다. 알림 역사에 포함된 정보에는 알림 자체가 포함될 때 알림이 전송되고, 알림이 전송된 경우.

## 공지사항

현재 고객은 알림 History에 액세스 할 수 있습니다.[Cloudflare API를 통해](/api/resources/alerting/subresources/history/methods/list/). 사용`GET`, 고객은 계정으로 전송된 알림에 대한 기록의 목록을 검색할 수 있습니다. 기록은 계획의 유형에 따라 지난 30 또는 90 일 동안 표시됩니다.

```txt title="Syntax"
GET accounts/{account_id}/alerting/v3/history
```

```bash title="Example"
curl "https://api.cloudflare.com/client/v4/accounts/{account_id}/alerting/v3/history?page=1&per_page=25" \
--header "Authorization: Bearer <API_TOKEN>"
```

## 적용분야

알림 역사는 모든 계획에 사용할 수 있습니다. 역사 클라이언트의 양은 계획의 유형에 따라 접근해야 합니다:

- **무료, Pro 및 비즈니스**: 지난 30일 역사.
- **회사 소개**: 지난 90일 역사.

:::참조

고객은 2021-10-11 이전의 알림 내역에 액세스 할 수 없습니다.

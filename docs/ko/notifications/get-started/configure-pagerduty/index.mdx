Cloudflare의 알림 서비스는 PagerDuty에 알림을 올리는 것을 지원합니다. PagerDuty에 알림을 보내면 PagerDuty에 연결되는 다른 타사 서비스에 대해 동일한 서비스 정의와 에스컬레이션 경로를 활용할 수 있습니다.

이전에 설정 한 구성은 PagerDuty에 대한 알림을 트리거 할 때 Cloudflare는 대신 PagerDuty에 대한 알림을 보낼 것입니다. 알림 설정된 PagerDuty 서비스 모두는 알림을 받게 됩니다. PagerDuty는 서비스의 구성을 따라 적절한 알림을 처리합니다. de-duping과 rate limiting 같은 동작은 알림 유형에 따라 다릅니다.

연결된 서비스로 PagerDuty를 사용하려면 반드시 해야 합니다.[PagerDuty 계정 등록](https://www.pagerduty.com/sign-up/).

:::참조

PagerDuty에 따르면 연결된 서비스를 추가하기 위해 다음과 같은 권한을 가진 계정이 필요합니다. 사용자, 관리자, 글로벌 관리자 또는 계정 소유자.

3. 내 계정**Connected 알림 서비스**카드, 선택**연결하기**.
4. 로그인[PagerDuty 계정](https://www.pagerduty.com/)Cloudflare 계정에 연결하십시오.
5. 사용하려는 서비스를 선택하고 선택**연결하기**.
6. 브라우저는 Cloudflare 대시보드로 돌아갈 것입니다. 제품정보**계속하기**.

새로운 연결된 PagerDuty가 나타납니다.**Connected 알림 서비스**카드.

## PagerDuty 연결 서비스 편집

PagerDuty 서비스가 Cloudflare 계정에 연결되는 것을 편집하려면 Cloudflare에서 PagerDuty를 먼저 차단해야하며, PagerDuty에서 필요한 변경 사항을 확인하고 다시 연결하십시오.

Disconnecting PagerDuty는 현재 구성되는 PagerDuty에 전송되는 알림을 비활성화합니다. PagerDuty가 단지 구성 된 목적지였다면, PagerDuty를 분리하면 대상이 없는 알림이 발생할 수 있습니다.

다른 배송 목적지가 선택된 경우, 그 알림은 여전히 구성될 것입니다.

1. Cloudflare 대시보드에서, 갑니다**공지사항**사이트 맵

   <DashButton url="/?to=/:account/notifications" />
2. 오시는 길**오시는 길**.
3. 내 계정**Connected 알림 서비스**카드, 선&#xD0DD;**- 연혁**PagerDuty 서비스에 연결하고 싶습니다.
4. 제품정보**연결하기** > **이름 \***.
5. 로그인[PagerDuty 계정](https://www.pagerduty.com/)자주 묻는 질문
6. [Cloudflare에 Reconnect PagerDuty](/notifications/get-started/configure-pagerduty/).

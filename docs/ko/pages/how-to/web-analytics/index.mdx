## Pages 프로젝트에서 사용 가능

Cloudflare Pages는 웹 분석을위한 원 클릭 설정을 제공합니다.

<Render file="web-analytics-setup" product="pages" />

## 메트릭 보기

Pages 프로젝트와 관련된 메트릭을 보려면:

1. Cloudflare 대시보드에서, 가십시오**웹 분석**사이트 맵

   <DashButton url="/?to=/:account/web-analytics" />
2. Pages 프로젝트와 관련된 분석을 선택하십시오.

Web Analytics를 사용하는 방법에 대한 자세한 내용은 참조[웹 분석 문서](/web-analytics/data-metrics/).

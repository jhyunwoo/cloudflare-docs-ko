자주 묻는 질문`www`apex 도메인에 하위 도메인 ()`example.com`).

이 설정은 이미 가지고 있다고 가정[사용자 정의 도메인](/pages/configuration/custom-domains/)Pages 프로젝트에 첨부.

## 설치하기

로그인`www`귀하의 도메인 apex에 하위 도메인:

1. Cloudflare 대시보드에서, 가십시오**대량 Redirects**사이트 맵

   <DashButton url="/?to=/:account/bulk-redirects" />
2. [대량 리디렉션 목록 만들기](/rules/url-forwarding/bulk-redirects/create-dashboard/#1-create-a-bulk-redirect-list)다음과 같이 모델링 된 (하지만 값을 적절하게 교체) :

<Example>
  | 소스 URL            | 대상 URL                | 주요연혁  | 매개 변수                                                                                |
  | ----------------- | --------------------- | ----- | ------------------------------------------------------------------------------------ |
  | `www.example.com` | `https://example.com` | `301` | <ul><li>자주 묻는 질문</li><li>Subpath 일치</li><li>예약 경로 suffix</li><li>하위 도메인 포함</li></ul> |
</Example>

4. [대량 리디렉션 규칙 만들기](/rules/url-forwarding/bulk-redirects/create-dashboard/#2-create-a-bulk-redirect-rule)당신이 만든 목록을 사용하여.
5. 오시는 길**DNS 보호**.
6. [DNS 레코드 만들기](/dns/manage-dns-records/how-to/create-dns-records/#create-dns-records)제품정보`www`다음과 같은 값을 사용하여 하위 도메인 :

<Example>
  | 제품정보 | 이름 \* | IPv4 주소     | 프록시 상태 |
  | ---- | ----- | ----------- | ------ |
  | `A`  | `www` | `192.0.2.1` | 견적 요청  |
</Example>

그것은 propagate에 이 DNS 변화를 위한 순간을 가지고 갈지도 모르지만, 일단 완료되면, 당신은 당신의 맨끝에 뒤에 오는 명령을 실행할 수 있습니다.

```sh
curl --head -i https://www.example.com/
```

그런 다음 출력을 검사합니다.`location`헤더 및 상태 코드가 설정되어 있습니다.

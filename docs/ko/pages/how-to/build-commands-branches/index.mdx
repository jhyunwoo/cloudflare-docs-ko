이 가이드는 특정 지점에서 빌드 명령을 설정하는 방법을 지시합니다. 당신은 사용할 것이다`CF_PAGES_BRANCH`지정된 지점에서 스크립트를 실행하는 환경 변수는 생산 지점과 반대합니다. 이 가이드는 Cloudflare 계정과 Pages 프로젝트를 가지고 있다고 가정합니다.

## 설치하기

이름 \*`.sh`프로젝트 디렉토리에 파일. 파일 이름을 선택할 수 있지만, 파일 이름을 추천`build.sh`.

다음 스크립트에서, 당신은 사용할 것이다`CF_PAGES_BRANCH`환경 변수를 확인하는 것은 현재 내장되어 있습니다. 감사합니다.`.sh`다음 파일:

```bash
#!/빈/배쉬

if [ "$CF_PAGES_BRANCH" == "production" ]; then
  #`package.json`의 "production" 스크립트를 실행
  #"production"는 생산 지점의 이름으로 교체해야합니다

  npm run production

elif [ "$CF_PAGES_BRANCH" == "staging" ]; then
  #`package.json`의 "staging" 스크립트를 실행
  #"staging"는 특정 지점의 이름을 대체해야합니다

  npm run staging

else
  #Else는 dev 스크립트를 실행
  npm run dev
fi
```

## 당신의 변화를 게시

당신의 변화를 효과로 넣기 위하여:

1. Cloudflare 대시보드에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />
2. Pages 프로젝트를 선택하십시오.
3. 오시는 길**계정 설정** > **빌드 및 배포** > **구성** > **편집 구성**.
4. 업데이트**명령 실행**필드 값`bash build.sh`선택하기**제품 정보**.

빌드가 성공적이기 때문에 프로젝트를 배포합니다.

[모델 번호: Cloudflare 관련 제품](/cloudflare-one/networks/connectors/cloudflare-tunnel/)가벼운 데몬을 실행 (`cloudflared`) 당신의 근원 웹 서버와 Cloudflare 글로벌 네트워크 사이에서 outbound 연결 (Tunnels)를 설치하는 당신의 인프라에서. 실제적인 기간에서는, 당신은 Cloudflare를 사용할 수 있습니다 당신의 국부적으로 기계에 달리는 서비스에 원격 액세스를 허용하는 갱도. 그것은 같은 인기있는 도구에 대안입니다[사이트맵](https://ngrok.com), 무료 제공, 긴 실행 터널을 통해[테스트Cloudflare](/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)서비스.

Cloudflare PagesXQ는 고유한 기능을 제공합니다[미리보기 URL을 배치](/pages/configuration/preview-deployments/)새로운 분지 및 프로젝트에 커밋, Cloudflare 터널은 개발 과정에서 로컬 실행 애플리케이션 및 서버에 대한 액세스를 제공 할 수 있습니다. 이 가이드에서 Cloudflare 터널을 설치하고 로컬 실행 응용 프로그램에 액세스 할 수있는 새로운 터널을 만듭니다. Cloudflare 터널을 사용하려면 CloudflareXQ 계정이 필요합니다.

## 설치 Cloudflare 관련 제품

모델 번호: Cloudflare 터널은 Windows, Linux 및 macOS에 설치할 수 있습니다. Cloudflare 터널 설치에 대해 알아 보려면, 참조[Cloudflared 설치](/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/)팀 문서에 대한 Cloudflare의 페이지.

견적 요청`cloudflared`실행에 의해 올바르게 설치`cloudflared --version`명령줄에서:

```sh
cloudflared --version
```

```sh output
cloudflared version 2021.5.9 (built 2021-05-21-1541 UTC)
```

## 현지 서비스 실행

Cloudflare 터널은 로컬로 실행되는 응용 프로그램이 있습니다.[모델 번호: React](/pages/framework-guides/deploy-a-react-site/)또는[모델 번호: SvelteKit](/pages/framework-guides/deploy-a-svelte-kit-site/)사이트 맵 이 프레임 워크와 응용 프로그램을 개발할 때, 그들은 종종 사용`npm run develop`스크립트, 또는 뭔가 유사한, 이는 응용 프로그램을 마운트하고 그것을 실행`localhost`항구. 예를 들면, 대중`vite`도구는 포트에 in-development React 응용 프로그램을 실행`5173`, 그것에 접근 가능`http://localhost:5173`이름 \*

## Cloudflare 시작 관련 제품

로컬 개발 서버 실행, 새로운 Cloudflare 갱도는 달리기에 의해 순간일 수 있습니다`cloudflared tunnel`새 명령 줄 창에서 전달`--url`당신의 계정`localhost`URL 및 포트.`cloudflared`터널 URL을 가진 배너를 포함하여 명령 줄에 로그를 출력합니다.

```sh
cloudflared tunnel --url http://localhost:5173
```

## 다음 단계

모델 번호: Cloudflare 터널은 다양한 방법으로 구성되며 내부 개발 응용 프로그램에 대한 액세스를 제공 할 수 있습니다. 예를 들어, 제공 할 수 있습니다`cloudflared`한국어[구성 파일](/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/local-management/configuration-file/)더 복잡한 라우팅과 터널 설정 추가하기`--url`플래그. 당신은 또한 할 수 있습니다[Cloudflare DNS 레코드를 첨부](/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/dns/)쉽게 접근할 수 있는 도메인 또는 하위 도메인에, 당신의 국부적으로 기계에 장수한 갱도.

마지막으로, Cloudflare를 통합하여 오시는 길[당신의 갱도에 안전한 접근](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/)전체 서버를 탐험하지 않고, 또는 보안을 준수. 더 알아보기[팀 문서에 대한 Cloudflare](/cloudflare-one/)Cloudflare의 Zero Trust 도구의 전체 제품군에 대해 자세히 알아보세요.

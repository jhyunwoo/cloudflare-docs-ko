이전에 노동자를 배포하지 않은 경우 시작하기[관련 기사](/workers/get-started/guide/). 이 튜토리얼의 목적을 위해, 단계 하나 (Workers 계정에 가입) 4을 통해 (새로운 프로젝트를 강화) 이 페이지로 돌아가기 전에.

계속하기 전에 Cloudflare Pages 프로젝트가 연결된다는 것을 보증하십시오[사용자 정의 도메인](/pages/configuration/custom-domains/#add-a-custom-domain).

## Workers 기능 작성

Workers 기능은 안으로 쓰입니다[JavaScript](https://www.cloudflare.com/learning/serverless/serverless-javascript/). 노동자가 Cloudflare Pages 신청에 요구에 응할 때, 그것은 응답을 받을 것입니다. Worker 수신 응답은 immutable이며, 변경할 수 없습니다. 추가하기 위해, 삭제 또는 변경 헤더, 응답을 복제하고 새로운에 헤더를 수정`Response`예. 원하는 헤더 변경으로 브라우저에 새로운 응답을 반환합니다. 이 예는 다음과 같습니다.

```js title="Setting custom headers with a Workers function"
export default {
	async fetch(request) {
		//이 프록시는 Pages 응용 프로그램에서 작업자 스크립트가 Pages 프로젝트와 동일한 사용자 정의 도메인에 배포됩니다
		const response = await fetch(request);

		//더 이상 immutable 인 응답을 복제
		const newResponse = new Response(response.body, response);

		//사용자 정의 헤더를 값으로 추가
		newResponse.headers.append(
			"x-workers-hello",
			"Hello from Cloudflare Workers",
		);

		//맨 위
		newResponse.headers.delete("x-header-to-delete");
		newResponse.headers.delete("x-header2-to-delete");

		//기존 헤더의 값을 조정
		newResponse.headers.set("x-header-to-change", "NewValue");

		return newResponse;
	},
};
```

## CLI를 사용하여 Workers 기능을 배포

이 파일을 직접 작성하고 싶으신 경우, 다음을 사용할 수 있습니다.`custom-headers-example` [관련 기사](https://github.com/kristianfreeman/custom-headers-example)새로운 Workers 기능을 생성하기 위해[채용정보](/workers/wrangler/install-and-update/), Workers CLI 공구.

```sh title="Generating a serverless function with wrangler"
git clone https://github.com/cloudflare/custom-headers-example
cd custom-headers-example
npm install
```

PagesXPagesXQ 응용 프로그램을 따라 Pages 응용 프로그램을 따라 QXPages와 같은 사용자 정의 도메인에 배포합니다. 이렇게하려면 Wrangler 파일을 계정과 영역 세부 정보로 업데이트하십시오.

<WranglerConfig>
  ```jsonc
  {
  	"$schema": "./node_modules/wrangler/config-schema.json",
  	"name": "custom-headers-example",
  	"account_id": "FILL-IN-YOUR-ACCOUNT-ID",
  	"workers_dev": false,
  	"route": "FILL-IN-YOUR-WEBSITE.com/*",
  	"zone_id": "FILL-IN-YOUR-ZONE-ID"
  }
  ```
</WranglerConfig>

계정 ID와 Zone ID를 찾는 방법을 모르는 경우, 참조[우리의 가이드](/fundamentals/account/find-account-and-zone-ids/).

설정하면[Wrangler 구성 파일](/pages/functions/wrangler-configuration/), 실행`npx wrangler deploy`당신의 노동자를 배치하는 맨끝에서:

```sh
npx wrangler deploy
```

Worker를 배포 한 후 원하는 HTTP 헤더 조정이 효력을 발생합니다. 노동자가 배치되는 동안, 당신은 당신의 Pages 신청에서 정상으로 내용을 계속 볼 수 있어야 합니다.

Cloudflare Pages는 당신의 신청에 있는 개인적인 의존도를 포함할 수 있는 주문 포장 등록을 지원합니다. 이 walkthrough 초점은 특히 위에[₢ 킹](https://www.npmjs.com/)노드 패키지 관리자 및 레지스트리, 같은 접근법은 다른 레지스트리 도구에 적용 할 수 있습니다.

당신은 조정 될 것입니다[환경 변수](/pages/configuration/build-configuration/#environment-variables)Pages 프로젝트의**계정 설정**. 기존 웹 사이트는 언제든지 수정 될 수 있지만 새로운 프로젝트는 이러한 설정으로 초기화 될 수 있습니다. 프로젝트 설정을 변경하면 다음 배포까지 반영되지 않습니다.

:::카트로션

설정 변경 후 새로운 배포를 트리거해야합니다.

:::

## 레지스트리 액세스 토큰

모든 패키지 레지스트리에는 새로운 액세스 토큰을 발급하는 수단이 있어야 합니다. 이상적으로, 당신은 Pages, 당신이 다른 CI/CD 플랫폼과 함께 할 것 같이 새로운 토큰을 특히 창조해야 합니다.

npm로, 당신은 할 수 있습니다[웹 사이트를 통해 토큰 생성 및 전망](https://docs.npmjs.com/creating-and-viewing-access-tokens)또는 당신은 사용할 수 있습니다`npm`로그인 CLI가 로컬로 설정하고 인증되면 터미널에서 다음 명령을 실행합니다.

```sh
#현재 npm 사용자를 검증합니다.
npm whoami

#readonly 토큰 만들기
npm token create --read-only
#-> -> 비밀번호 입력
#-> 2FA 코드를 입력하면 구성
```

UUID 문자열처럼 보이는 읽기 전용 토큰을 생성합니다. 나중에 단계에 대한이 값을 저장합니다.

## npm 레지스트리의 개인 모듈

다음 섹션은 npm 레지스트리에서 개인 모듈을 사용하는 응용 프로그램에 적용됩니다.

Pages 프로젝트의 경우**계정 설정** > **환경 변수**, 새로운 추가[환경 변수](/pages/configuration/build-configuration/#environment-variables)이름 \*`NPM_TOKEN`이름 \***제품정보**·**다운로드**환경과 풀[읽기 전용 토큰](#registry-access-token)그것의 가치로.

:::카트로션

추가하기`NPM_TOKEN`모두 변수**제품정보**·**다운로드**환경.

:::

기본적으로,`npm`환경 변수를 찾습니다`NPM_TOKEN`그리고 당신이 정의하지 않았기 때문에[주문 레지스트리 endpoint](#custom-registry-endpoints)npm 레지스트리가 가정됩니다. 현지 개발은 예상대로 계속해야하며, 팀메이트는 npm 계정으로 인증됩니다. (see`npm whoami`·`npm login`) 개인 패키지에 액세스 권한을 부여했다 (s).

## 사용자 정의 레지스트리 endpoints

여러 등록자가 사용할 때, 프로젝트는 자신의 루트 레벨을 정의해야합니다.[`.npmrc`](https://docs.npmjs.com/cli/v7/configuring-npm/npmrc)구성 파일. 예제`.npmrc`파일은 다음과 같습니다 :

```ini
@foobar:registry=https://npm.pkg.github.com
//registry.npmjs.org/:_authToken=${TOKEN_FOR_NPM}
//npm.pkg.github.com/:_authToken=${TOKEN_FOR_GITHUB}
```

여기, 모든 패키지 아래`@foobar`GitHub Packages 레지스트리를 향한 범위. 그런 다음 등록자는 해당 환경 변수 이름을 통해 자신의 액세스 토큰을 할당합니다.

:::참조

npm 레지스트리에 대한 액세스 토큰을 정의해야 (refer to`TOKEN_FOR_NPM`예를 들어) 애플리케이션이 필요한 개인 패키지를 호스팅하는 경우.

:::

Pages 프로젝트가 일치해야 합니다.[환경 변수](/pages/configuration/build-configuration/#environment-variables)모든 환경에 정의. 우리의 예에서, 즉`TOKEN_FOR_NPM`자주 묻는 질문[읽기 전용 npm 토큰](#registry-access-token)가치와`TOKEN_FOR_GITHUB`자주 묻는 질문[개인 액세스 토큰](https://docs.github.com/en/github/authenticating-to-github/creating-a-personal-access-token#creating-a-token).

### 다중 환경 관리

현지 개발이 더 이상 새로운 작업을하지 않는 이벤트`.npmrc`파일, 당신은 몇 가지 추가 변경을 추가해야합니다:

<Steps>
  1. Pages-compliant 이름을 바꾸십시오`.npmrc`파일 형식`.npmrc.pages`. 환경 변수를 참조해야 합니다.

  2. 당신의 이전을 복원`.npmrc`파일 - 이전에 당신과 당신의 팀원을 위해 일한 버전.

  3. 오시는 길**Workers & Pages**Cloudflare 대시보드XQ에서.

     <DashButton url="/?to=/:account/workers-and-pages" />

  4. Pages 프로젝트를 선택하십시오.

  5. 오시는 길**계정 설정** > **환경 변수**, 새로운 추가[환경 변수](/pages/configuration/build-configuration/#environment-variables)이름 \*[`NPM_CONFIG_USERCONFIG`](https://docs.npmjs.com/cli/v6/using-npm/config#npmrc-files)그 가치를 설정한다.`/opt/buildhome/repo/.npmrc.pages`. 너의 것`.npmrc.pages`파일은 프로젝트의 루트 디렉토리에 있지 않습니다, 따라이 경로를 조정할.
</Steps>

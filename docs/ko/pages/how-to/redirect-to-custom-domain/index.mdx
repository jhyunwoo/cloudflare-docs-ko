자주 묻는 질문[대량 Redirects](/rules/url-forwarding/bulk-redirects/)연결하기`*.pages.dev`subdomain로[사용자 정의 도메인](/pages/configuration/custom-domains/).

이 작업을 수행 할 수 있습니다. 사이트의 콘텐츠는 사용자 정의 도메인에서만 제공되며, 그렇지 않다.`<project>.pages.dev`먼저 Pages 배포에 자동으로 생성됩니다.

## 설치하기

로그인`<project>.pages.dev`사용자 정의 도메인에 하위 도메인:

1. Cloudflare 대시보드에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />
2. Pages 프로젝트를 선택하십시오.
3. 오시는 길**주문 영역**사용자 정의 도메인이 나열되어 있는지 확인하십시오. 그렇지 않은 경우, 클릭하여 추가**사용자 정의 도메인 설정**.
4. 이름 \***대량 Redirects**.
5. [대량 리디렉션 목록 만들기](/rules/url-forwarding/bulk-redirects/create-dashboard/#1-create-a-bulk-redirect-list)다음과 같이 모델링 된 (하지만 값을 적절하게 교체) :

<Example>
  | 소스 URL                | 대상 URL                | 주요연혁  | 매개 변수                                                                                |
  | --------------------- | --------------------- | ----- | ------------------------------------------------------------------------------------ |
  | `<project>.pages.dev` | `https://example.com` | `301` | <ul><li>자주 묻는 질문</li><li>Subpath 일치</li><li>예약 경로 suffix</li><li>하위 도메인 포함</li></ul> |
</Example>

6. [대량 리디렉션 규칙 만들기](/rules/url-forwarding/bulk-redirects/create-dashboard/#2-create-a-bulk-redirect-rule)당신이 만든 목록을 사용하여.

당신의 리디렉션이 작동하도록 테스트하려면`<project>.pages.dev`사이트 맵 URL이 이제 사용자 정의 도메인에 설정되면 규칙이 전파되었습니다.

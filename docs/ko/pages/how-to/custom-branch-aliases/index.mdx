이 가이드에서 사용자 정의 도메인을 추가하는 방법을 배울 것입니다 (`staging.example.com`) 특정 지점에 지점 (`staging`) 당신의 Pages 프로젝트에.

이것은 항상 당신의 Pages 프로젝트에 특정 지점을위한 최신 빌드를 보여줄 수있는 사용자 정의 도메인을 가질 수 있습니다.

:::참조

이 설정은 proxied Cloudflare DNS 레코드를 사용할 때만 지원됩니다.

외부 DNS 제공 업체 또는 비보호 DNS 레코드를 사용하여이 가이드를 따라 시도하면 사용자 정의 별명은 Pages 프로젝트의 생산 지점으로 보내집니다.

:::

먼저, 당신은 분기에 성공적인 배포가있어 당신은 사용자 정의 도메인을 설정하고 싶습니다.

다음, 원하는 사용자 정의 도메인에 대한 Pages 프로젝트 아래의 사용자 정의 도메인을 추가, 예를 들어,`staging.example.com`.

![QXQX2067XQ QXQX2065XQ에 대한 사용자 정의 도메인 QXQX2066XQ에 액세스하려면 아래의 지침을 따르십시오.](~/assets/images/pages/how-to//pages_custom_domain-1.png)

이 작업을 수행:

1. Cloudflare 대시보드에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />
2. Pages 프로젝트를 선택하십시오.
3. 제품정보**주문 영역** > **사용자 정의 도메인 설정**.
4. 사용하려는 도메인을 입력합니다.`staging.example.com`
5. 제품정보**계속하기** > **도메인 이름**

![사용자 정의 도메인을 선택하면 활성화해야합니다.](~/assets/images/pages/how-to//pages_custom_domain-2.png)

사용자 정의 도메인을 활성화 한 후, 이동[DNS 보호](https://dash.cloudflare.com/?to=/:account/:zone/dns)제품정보`example.com`지역 및 찾기`CNAME`이름과 기록`staging`alias를 포함 하 여 대상을 변경 합니다.

이 인스턴스에서 변경`your-project.pages.dev`으로`staging.your-project.pages.dev`.

![사용자 정의 도메인을 활성화 한 후, CNAME 대상을 변경하여 지점 이름을 포함.](~/assets/images/pages/how-to//pages_custom_domain-3.png)

현재 위치`staging`Pages 프로젝트의 분지가 가능합니다.`staging.example.com`.

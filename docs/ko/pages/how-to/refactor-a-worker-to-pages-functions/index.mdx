## Airtable와 Workers를 가진 손잡이 모양 입장

이름 \*[에어 테이블](https://airtable.com/)협력 응용 프로그램을 구축하기위한 낮은 코드 플랫폼입니다. 작업 흐름을 사용자 정의하고, 협업 및 처리 양식 제출. 이 예제의 경우 Airtable의 양식 제출 기능을 활용합니다.

[에어 테이블](https://airtable.com/)같은 계정에 대한 다른 표의 항목의 항목을 저장할 수 있습니다. 제출 논리를 처리하기위한 노동자를 만들 때, 첫 번째 단계는 사용[모델 번호: Wrangler](/workers/wrangler/install-and-update/)특정 폴더 내에서 새로운 노동자를 초기화하거나 응용 프로그램의 루트에.

이 단계는 보일러판을 사용하여 Airtable 제출 노동자를 작성합니다. 작업자를 작성한 후 Cloudflare의 글로벌 네트워크에 배포할 수 있습니다.[프로젝트 구성](/workers/wrangler/configuration/). Workers 문서에 대한 자세한 내용은[Workers를 가진 손잡이 모양 제출](/workers/tutorials/handle-form-submissions-with-airtable/).

다음 코드 블록은 Airtable 양식 제출을 처리하는 Worker의 예를 보여줍니다.

더 보기`submitHandler`async 함수는 작업의 pathname이면 호출됩니다.`/submit`. 이 기능 체크는 요청 방법 이다`POST`요청한 다음 파삭스로 진행하고 당신의 자격 증명을 사용하여 Airtable에 양식 항목을 게시합니다.[Wrangler`secret`](/workers/wrangler/commands/#secret).

```js
export default {
	async fetch(request, env, ctx) {
		const url = new URL(request.url);

		if (url.pathname === "/submit") {
			return submitHandler(request, env);
		}

		return fetch(request.url);
	},
};

async function submitHandler(request, env) {
	if (request.method !== "POST") {
		return new Response("Method not allowed", {
			status: 405,
		});
	}
	const body = await request.formData();

	const { first_name, last_name, email, phone, subject, message } =
		Object.fromEntries(body);

	const reqBody = {
		fields: {
			"First Name": first_name,
			"Last Name": last_name,
			Email: email,
			"Phone number": phone,
			Subject: subject,
			Message: message,
		},
	};

	return HandleAirtableData(reqBody, env);
}

const HandleAirtableData = (body, env) => {
	return fetch(
		`https://api.airtable.com/v0/${env.AIRTABLE_BASE_ID}/${encodeURIComponent(
			env.AIRTABLE_TABLE_NAME,
		)}`,
		{
			method: "POST",
			body: JSON.stringify(body),
			headers: {
				Authorization: `Bearer ${env.AIRTABLE_API_KEY}`,
				"Content-type": `application/json`,
			},
		},
	);
};
```

### 당신의 노동자를 다시

위 노동자를 재구성하려면 Pages 프로젝트 디렉토리에 가서`/functions`폴더. 내 계정`/functions`, 만들기`form.js`파일. 이 파일은 양식 제출을 처리합니다.

그런 다음`form.js`파일, 수출 단일`onRequestPost`:

```js
export async function onRequestPost(context) {
	return await submitHandler(context);
}
```

모든 노동자는`addEventListener`관련 기사`fetch`이벤트, 그러나 Pages 기능에서 이것을 필요로하지 않을 것입니다. 대신, 당신은`export`단일`onRequest`기능, 그리고 HTTPS에 따라 핸들을 요청, 당신은 그에 따라 이름을 지정합니다. 더 알아보기[기능 문서](/pages/functions/get-started/)당신의 기능을 위한 적당한 방법을 선정하기 위하여.

위 코드는`request`·`env`이 속성을 아래로 전달하는 인수로`submitHandler`unchanged 기능,[회사 소개](#handle-form-entries-with-airtable-and-workers). 그러나 Functions가 HTTPS 요청 유형을 지정할 수 있기 때문에 제거 할 수 있습니다.`request.method`당신의 노동자에 체크. 이것은 지금 Pages에 의해 취급됩니다 기능 naming`onRequest`핸들러.

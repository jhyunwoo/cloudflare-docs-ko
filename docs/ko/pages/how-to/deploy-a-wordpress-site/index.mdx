## 제품정보

이 가이드에서 WordPress 플러그인을 사용할 수 있습니다.[단순히 정적](https://wordpress.org/plugins/simply-static/)기존 WordPress 사이트를 Cloudflare Pages로 배포하는 정적 웹 사이트로 변환하려면.

## 자주 묻는 질문

이 가이드는 다음과 같다:

- WordPress 사이트의 관리자 계정.
- 사이트의 WordPress 플러그인을 설치할 수 있습니다.

## 설치하기

시작하려면 설치[단순히 정적](https://wordpress.org/plugins/simply-static/)WordPress 사이트를 수출하는 플러그인. 워드 프레스 대시보드에서, 이동**플러그인** > **새소식**.

관련 기사`Simply Static`그리고 그 결과 플러그인을 확인하면 아래 플러그인을 설치합니다.

![Simply Static 플러그인](~/assets/images/pages/how-to/simply-static.png)

제품정보**설치하기**플러그인에. 설치 완료 후, 선택**이름 \***.

### WordPress 사이트 수출

플러그인을 설치 한 후 WordPress 대시보드로 이동 >**단순히 정적** > **일반 파일**.

내 계정**활동 로그**, 찾기**ZIP 아카이브 생성**메시지 및 선택**다운로드**ZIP 파일을 다운로드합니다.

### Pages

다운로드 ZIP 파일로, Pages에 사이트를 배치:

1. Cloudflare 대시보드에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />

2. 제품정보**회사연혁** > **Pages** > **직접 업로드**.

3. 프로젝트 이름, 다음 선택**프로젝트**.

4. 드래그 및 ZIP 파일을 드롭 (또는 자산의 압축 폴더) 또는 컴퓨터에서 선택.

5. 파일이 업로드된 후, 선택**Deploy 사이트**.

이제 WordPress 사이트는 Pages에서 라이브됩니다.

WordPress 사이트로 변경할 때마다 WordPress 대시보드 및 Redeploy에서 새로운 ZIP 파일을 다운로드해야합니다. Cloudflare QXPages. 자동 업데이트는 Simply Static의 무료 버전으로 사용할 수 없습니다.

## 제한 사항

정적 사이트 환경에서 지원되지 않는 WordPress 사이트에서 사용할 수있는 일부 기능이 있습니다.

- WordPress 양식.
- WordPress 댓글.
- 모든 링크`/wp-admin`또는 유사한 내부 WordPress 경로.

## 이름 \*

이 가이드에 따라 WordPress 사이트의 정적 버전을 Cloudflare QXPagesXQ로 성공적으로 배포했습니다.

제공된 사이트의 정적 버전으로, 당신은 할 수 있습니다:

- WordPress 사이트를 사용자 정의 도메인 또는 하위 도메인으로 이동합니다. 더 알아보기[주문 영역](/pages/configuration/custom-domains/)더 알아보기.
- WordPress 인스턴스를 로컬로 실행하거나 WordPress 사이트를 넣으십시오.[모델 번호: Cloudflare 오시는 길](/pages/configuration/preview-deployments/#customize-preview-deployments-access)당신의 기여자에 대한 액세스를 제공합니다. 이것은 WordPress 사이트 및 콘텐츠에 대한 공격 벡터의 수에 중요한 영향을 미칩니다.
- WordPress 호스팅 계획을 저렴한 계획으로 낮추십시오. WordPress 인스턴스의 메모리 및 대역폭 요구 사항이 이제 작기 때문에 더 저렴한 계획에서 호스트하거나 공유 호스팅으로 이동할 수 있습니다.

연결하기[모델 번호: Cloudflare Discord의 개발자 커뮤니티](https://discord.cloudflare.com)질문과 다른 개발자와 플랫폼에 대해 논의합니다.

이 가이드에서 시작하기XQX2007XQXQ QXQXPages를 사용하여 PagesXQ 플랫폼으로 첫 웹 사이트를 배포합니다. Git 통합은 자동 빌드 및 배포를 가능하게하여 연결될 때마다 변경을 밀어줍니다.[프로젝트](/pages/configuration/git-integration/github-integration/)또는[프로젝트](/pages/configuration/git-integration/gitlab-integration/)관련 기사

:::caution\[이전에 직접 업로드할 수 없습니다]
Git 통합을 사용하여 배포하면 전환 할 수 없습니다.[연락처](/pages/get-started/direct-upload/)나중에. 그러나 이미 Git-integrated 프로젝트를 사용한다면 매번 배포를 트리거 할 필요가 없습니다.[disable 자동적인 배치](/pages/configuration/git-integration/#disable-automatic-deployments)모든 지점에서. 그런 다음 Pages 프로젝트를 직접 배포하고 빌드를 자동으로 트리거하지 않고 Git 저장소로 변경할 수 있습니다.

:::

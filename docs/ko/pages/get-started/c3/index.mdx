## 계정 만들기

프로젝트가 구성되면 프로젝트가 Cloudflare에 배포하려는 경우 요청됩니다. 이것은 선택적입니다.

배포를 선택하면 Cloudflare 계정에 로그인할 수 있습니다. (이렇지 않은 경우)

## git 저장소에 연결되는 새로운 Pages 프로젝트 만들기

새 프로젝트를 만들기 위해`npm create cloudflare`Github 또는 Gitlab 계정에서 Git 저장소에 연결하면 다음 단계를 수행하십시오.

1. 지원하다`npm create cloudflare@latest`, 그리고 당신의 원한 선택권을 선택하십시오
2. 제품정보`no`"당신은 응용 프로그램을 배포하고 싶습니까?". 이것은 중요하다 — 당신이 선택하면`yes`당신의 맨끝에서 당신의 신청을 배치하십시오 ([연락처](/pages/get-started/direct-upload/)), 다음이 Pages 프로젝트를 나중에 git 저장소에 연결할 수 없습니다. 당신은 새로운 Cloudflare Pages 프로젝트를 만들 필요가 있습니다.
3. 새로운 git 저장소 만들기, 응용 프로그램을 사용하여`npm create cloudflare@latest`당신을 위해 만든.
4. 자주 묻는 질문[Git 통합 가이드](/pages/get-started/git-integration/)

## 회사 소개

C3는 일련의 대화 형 프롬프트를 통해 필요한 입력을 수집합니다. 명령줄 인수를 통해 선택을 지정할 수도 있습니다. 이 프롬프트를 건너 뛸 것입니다. CI와 같은 비동기적 맥락에서 C3를 사용하려면 명령행을 통해 필요한 모든 인수를 지정해야 합니다.

가능한 CLI 인수와 함께 C3 invocation의 전체 형식입니다.

<PackageManagers type="create" pkg="cloudflare@latest" args="--platform=pages [<DIRECTORY>] [OPTIONS] [-- <NESTED ARGS...>]" />

- `DIRECTORY` <Type text="string" /> <MetaInfo text="optional" />

  - 응용 프로그램이 만든 디렉토리. 응용 프로그램의 이름은 디렉토리 이름에서 가져온 것입니다.

- `NESTED ARGS..` <Type text="string[]" /> <MetaInfo text="optional" />

  - Eventual 제3자 CLIs C3에 전달하는 CLI 인수는 invoke (전체 스택 응용 프로그램의 경우).

- `--category` <Type text="string" /> <MetaInfo text="optional" />

  - 만든 템플릿의 종류.

  - 이 옵션의 가능한 값은:

    - `hello-world`: Hello World 예제
    - `web-framework`: Framework 스타터
    - `demo`: 신청 시동기
    - `remote-template`: GitHub 저장소에서 템플릿

- `--type` <Type text="string" /> <MetaInfo text="optional" />

  - 만든 응용 프로그램의 유형.

  - 이 옵션의 가능한 값은:

    - `hello-world`: 기본 "Hello World"Cloudflare 작업자.
    - `hello-world-durable-object`: 아[튼튼한 목표](/durable-objects/)그리고 그와 소통하는 노동자.
    - `common`: Cloudflare routing/proxying 기능의 일반적인 예를 실행하는 노동자.
    - `scheduled`: 예정된 Cloudflare 노동자 (를 통해 더 큰[Cron 트리거](/workers/configuration/cron-triggers/)).
    - `queues`: Cloudflare 소비자와 생산되는 노동자[모델 번호: Queues](/queues/).
    - `openapi`: OpenAPI REST 엔드포인트 구현
    - `pre-existing`: Cloudflare QX대시보드에서 초기화되는 노동자를 흠뻑 취하십시오.

- `--framework` <Type text="string" /> <MetaInfo text="optional" />

  - 웹 응용 프로그램을 만들기 위해 프레임 워크의 유형 (이 옵션을 사용하려면,`--type`무시).

  - 이 옵션의 가능한 값은:

    - `angular`
    - `astro`
    - `docusaurus`
    - `gatsby`
    - `hono`
    - `next`
    - `nuxt`
    - `qwik`
    - `react`
    - `redwood`
    - `remix`
    - `solid`
    - `svelte`
    - `vue`

- `--template` <Type text="string" /> <MetaInfo text="optional" />

  - git 저장소에서 호스팅되는 외부 템플릿을 통해 새로운 프로젝트를 만듭니다.

  - 이 옵션의 값은 다음과 같이 지정될 수 있습니다.

    - `user/repo`
    - `git@github.com:user/repo`
    - `https://github.com/user/repo`
    - `user/repo/some-template`(보통)
    - `user/repo#canary`(브레이크)
    - `user/repo#1234abcd`(주)
    - `bitbucket:user/repo`(BitBucket)
    - `gitlab:user/repo`(기타)

    이름 \*`degit` [한국어](https://github.com/Rich-Harris/degit)더 많은 정보.

    최소 템플릿은 다음과 같습니다.

    - `package.json`
    - [Wrangler 구성 파일](/pages/functions/wrangler-configuration/)
    - `src/`WranglerXQXQXQXQX

    이름 \*[템플릿 폴더](https://github.com/cloudflare/workers-sdk/tree/main/packages/create-cloudflare/templates)더 많은 예제를 위한 이 재포의.

- `--deploy` <Type text="boolean" /> <MetaInfo text="(default: true) optional" />

  - 만든 후 응용 프로그램을 배포합니다.

- `--lang` <Type text="string" /> <MetaInfo text="(default: ts) optional" />

  - 템플릿의 프로그래밍 언어.

  - 이 옵션의 가능한 값은:

    - `ts`
    - `js`
    - `python`

- `--ts` <Type text="boolean" /> <MetaInfo text="(default: true) optional" />

  - 응용 프로그램에서 TypeScript를 사용하십시오. 인기 있는 제품 정보`--lang=ts`대신.

- `--git` <Type text="boolean" /> <MetaInfo text="(default: true) optional" />

  - 응용 프로그램에 대한 로컬 git 저장소를 초기화합니다.

- `--open` <Type text="boolean" /> <MetaInfo text="(default: true) optional" />

  - 브라우저에서 배포된 응용 프로그램을 엽니다 (이 옵션은 응용 프로그램이 배포되지 않은 경우 무시됩니다).

- `--existing-script` <Type text="string" /> <MetaInfo text="optional" />

  - 기존의 Cloudflare Workers 스크립트의 이름을 로컬로 복제합니다. 이 옵션을 사용할 때,`--type`으로 coerced`pre-existing`.

  - 시간 :`--existing-script`지정된,`deploy`무시됩니다.

- `-y`, `--accept-defaults` <Type text="boolean" /> <MetaInfo text="optional" />

  - 모든 기본 C3 옵션을 사용하여 각을 지정하여 overridden 할 수 있습니다.

- `--auto-update` <Type text="boolean" /> <MetaInfo text="(default: true) optional" />

  - 자동적으로 C3의 최신 버전을 사용합니다.

- `-v`, `--version` <Type text="boolean" /> <MetaInfo text="optional" />

  - 버전 번호 표시.

- `-h`, `--help` <Type text="boolean" /> <MetaInfo text="optional" />

  - 도움 메시지를 표시하십시오.

:::참조

위의 모든 boolean 옵션은 값없이 지정할 수 있습니다. 예를 들어`--open`·`--open true`동일한 효력이, 접두사 있습니다`no-`옵션의 이름으로 negates 그것, 그래서 예를 들어`--no-open`·`--open false`동일한 효력이 있습니다.

:::

## 원격 측정

Cloudflare는 익명 사용 데이터를 수집하여 개선합니다.`create-cloudflare`시간 이상. 더 자세히 알아보기[데이터 정책](https://github.com/cloudflare/workers-sdk/blob/main/packages/create-cloudflare/telemetry.md).

당신은 어떤 정보를 공유하지 않으려면 옵트 아웃 할 수 있습니다.

<PackageManagers type="create" pkg="cloudflare@latest" args="telemetry disable" />

또는, 당신은 환경 변수를 설정할 수 있습니다:

```sh
export CREATE_CLOUDFLARE_TELEMETRY_DISABLED=1
```

언제든지 telemetry 컬렉션의 상태를 확인할 수 있습니다.

<PackageManagers type="create" pkg="cloudflare@latest" args="telemetry status" />

항상 원격 측정 컬렉션을 재사용할 수 있습니다.

<PackageManagers type="create" pkg="cloudflare@latest" args="telemetry enable" />

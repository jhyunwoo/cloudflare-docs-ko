직접 업로드는 Pages에 미리 만들어진 자산을 업로드하고 Cloudflare 글로벌 네트워크에 배포할 수 있습니다. Git 통합에 직접 업로드를 선택해야 합니다.[자신의 빌드 플랫폼을 통합](/pages/how-to/use-direct-upload-with-continuous-integration/)또는 로컬 컴퓨터에서 업로드.

이 가이드는 Wrangler 또는 드래그 및 드롭 방법을 사용하여 자산을 업로드하는 방법을 안내합니다.

:::caution\[ 나중에 Git 통합으로 전환할 수 없습니다]
직접 업로드를 선택하면 전환 할 수 없습니다.[Git 통합](/pages/get-started/git-integration/)나중에. Git 통합으로 새로운 프로젝트를 만들 수 있습니다.
주요 특징

## 자주 묻는 질문

직접 업로드로 프로젝트를 배포하기 전에 적절한 실행[빌드 명령](/pages/configuration/build-configuration/#framework-presets)프로젝트 구축

## 업로드 방법

준비된 자산이 있다면, 업로드를 시작하는 두 가지 방법이 있습니다.

- [모델 번호: Wrangler](/pages/get-started/direct-upload/#wrangler-cli).
- [드래그와 드롭](/pages/get-started/direct-upload/#drag-and-drop).

:::참조

직접 업로드 프로젝트 내에서 Wrangler 또는 드래그 및 드롭과 함께 배포를 만들 수 있습니다. 기존 Git-integrated 프로젝트를 위해, 수동으로 배포를 만들 수 있습니다.[`wrangler deploy`](/workers/wrangler/commands/#deploy). 그러나 기존의 Git-integrated 프로젝트를 가진 대시보드에 드래그 앤 드롭을 사용할 수 없습니다.

:::

## 지원된 파일 유형

아래는 각 직접 업로드 옵션에 대한 지원 파일 유형입니다:

- QXQX1984XQ: 자산의 단일 폴더. (Zip 파일은 지원되지 않습니다.)
- 드래그 및 드롭 : zip 파일 또는 자산의 단일 폴더.

## Wrangler 클립

### 설치 Wrangler

시작하기[`npm`](https://docs.npmjs.com/getting-started)·[Wrangler, 개발자 플랫폼 CLI 설치](/workers/wrangler/install-and-update/).

#### 프로젝트

Wrangler에 로그인[`wrangler login`이름 \*](/workers/wrangler/commands/#login). 다음 실행[`pages project create`이름 \*](/workers/wrangler/commands/#project-create):

```sh
npx wrangler pages project create
```

프로젝트 이름을 지정할 수 있습니다. 당신의 프로젝트는`<PROJECT_NAME>.pages.dev`(또는 프로젝트 이름과 프로젝트 이름이 이미 찍은 경우 몇 가지 임의 문자). 당신은 또한 당신의 생산 지점을 지정할 수 있습니다.

초기 배포는 이러한 값 모두 재사용됩니다 (당신의 안으로 새겨진)`node_modules/.cache/wrangler`폴더).

#### 자산 배포

여기에서, 당신은 빈 프로젝트를 생성하고 이제 당신의 첫 번째 배포에 대한 자산을 배포하고 생산 환경에서 모든 후속 배포 할 수 있습니다. 이 작업을 수행하려면[`wrangler pages deploy`](/workers/wrangler/commands/#deploy-1)명령:

```sh
npx wrangler pages deploy <BUILD_OUTPUT_DIRECTORY>
```

프로젝트에 적합한 빌드 출력 디렉토리를 찾습니다.[Framework presets에서 디렉토리를 컴파일](/pages/configuration/build-configuration/#framework-presets).

당신의 생산 배치는 유효합니다`<PROJECT_NAME>.pages.dev`.

:::참조

사용하기 전에`wrangler pages deploy`명령, 당신은 프로젝트 안에 있는지 확인해야합니다. 그렇지 않은 경우 프로젝트 경로에 전달할 수 있습니다.

:::

미리보기 환경에 자산을 배포하려면, 실행:

```sh
npx wrangler pages deploy <OUTPUT_DIRECTORY> --branch=<BRANCH_NAME>
```

작성된 모든 지점의 경우, 분기 별명은 당신에게 사용할 수 있습니다.`<BRANCH_NAME>.<PROJECT_NAME>.pages.dev`.

:::참조

Git workspace에 있는 경우에, Wrangler는 당신을 위한 분지 정보를 자동적으로 당길 것입니다. 그렇지 않으면이 명령에 있는 지점을 지정해야 합니다.

:::

프로젝트 생성 및 자산 배포 단계를 간소화하고 싶다면 배포 명령을 사용하여 동시에 자산을 생성하고 배치 할 수 있습니다. 이 명령을 먼저 실행하면 프로젝트 이름과 생산 지점을 지정할 수 있습니다. 이 값은 위에서 명시된 것과 같이 후속 배포에 대해 캐시됩니다. 캐시가 이미 존재하고 새로운 프로젝트를 만들려면, 당신은 실행해야합니다[`create`이름 \*](#create-your-project).

#### 다른 유용한 명령

Wrangler를 사용하여 직접 업로드를 위한 모든 가능한 프로젝트 목록을 얻을 수 있습니다.[`pages project list`](/workers/wrangler/commands/#project-list):

```sh
npx wrangler pages project list
```

Wrangler를 사용하여 특정 프로젝트의 모든 고유 미리보기 URL 목록을 얻을 수 있습니다.[`pages deployment list`](/workers/wrangler/commands/#deployment-list):

```sh
npx wrangler pages deployment list
```

Wrangler 및 GitHub Action, Circle CI 및 Travis CI와 같은 지속적인 통합 도구와 함께 지속적인 배포를 위해 Wrangler 및 연속 통합 도구를 사용하는 방법에 대한 단계별 방향을 위해[연속 통합과 Direct 업로드](/pages/how-to/use-direct-upload-with-continuous-integration/).

## 드래그와 드롭

#### 드래그 및 드롭으로 프로젝트 배포

드래그 및 드롭으로 배포하려면:

1. Cloudflare QX대시보드에서, 갑니다**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />
2. 제품정보**회사연혁** > **시작하기** > **파일을 드래그하고 드롭**.
3. 지정된 필드에 프로젝트 이름을 입력하고 자산을 드래그하고 드롭하십시오.
4. 제품정보**Deploy 사이트**.

당신의 프로젝트는`<PROJECT_NAME>.pages.dev`. 다음 드래그 및 빌드 출력 디렉토리를 업로드 프레임에 드롭합니다. 파일이 성공적으로 업로드되면, 선택**저장 및 배포**새로 배포된 프로젝트에 계속.

#### 새로운 배포 만들기

프로젝트를 만든 후, 선택**새로운 배포 만들기**사이트의 새로운 버전을 시작합니다. 다음, 당신의 새로운 배포가 생산 또는 미리보기 환경에 만들지 여부를 선택하십시오. 미리보기를 선택하면 새로운 배포 지점을 만들거나 기존에 입력할 수 있습니다.

## 문제 해결

### 제한 사항

| 업로드 방법          | 파일 제한     | 파일 크기 |
| --------------- | --------- | ----- |
| 모델 번호: Wrangler | 20,000 파일 | 25 미브 |
| 드래그와 드롭         | 1,000 파일  | 25 미브 |

드래그 앤 드롭 방법을 사용하는 경우, 빨간색 경고 기호는 너무 크면 자산 옆에 나타납니다. 따라서 제대로 업로드. 이 경우 자산을 삭제할 수 있지만 대체할 수 없습니다. 이렇게하려면 전체 프로젝트를 다시로드해야합니다.

### 제품정보

Cloudflare 대시보드에서 만든 드래그 및 드롭 배포는 현재 보완하지 않습니다`functions`폴더의[Pages 기능](/pages/functions/). 배포하기`functions`폴더는 WranglerXQ를 사용해야합니다. WranglerXQ를 사용하여 프로젝트를 배포할 때,`functions`명령이 실행되는 폴더가 존재합니다.`functions`폴더는 프로젝트에 업로드됩니다.

그러나, 주의`_worker.js`파일은 Wrangler와 대시보드에서 만든 드래그 및 드롭 배포 모두에 의해 지원됩니다.

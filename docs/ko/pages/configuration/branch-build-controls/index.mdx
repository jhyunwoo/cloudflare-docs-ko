git repository에 연결될 때, Pages는 당신이 자동적으로 배치하고 싶은 어떤 환경 및 분지를 통제할 수 있습니다. 기본적으로 Pages는 생산 또는 미리보기 환경 중 어느 때라도 배포할 수 있습니다. 그러나, 분지 배포 제어와 함께, 당신은 프로젝트에 따라 p참고 자료XQ에 맞게 자동 배포를 구성할 수 있습니다.

## 생산 분지 제어

:::caution\[직접 업로드]

:::

배포 옵션을 구성하려면 Pages 프로젝트로 이동 >**계정 설정** > **빌드 및 배포** > **생산 배치**. Pages는 당신이 첫번째 강요를 분지에 생산 환경을 조정하기 위하여 과태할 것입니다, 그러나 당신은 당신이 선택하는 경우에 다른 분지에 생산을 놓을 수 있습니다.

생산 지점에서 자동 배포 동작을 활성화하거나 비활성화할 수 있습니다.**자동 생산 지점 배포 가능**상자. 새로운 생산 지점 제어를 위해 설정을 저장해야합니다.

## 미리보기 분기 제어

자동 미리보기 배포를 구성하면 선택할 수있는 세 가지 옵션이 있습니다.

- **모든 비 생산 지점**: 기본적으로 Pages는 미리보기 지점을 자동으로 배치합니다.
- **이름 \***: 모든 미리보기 지점을 위한 자동 빌드를 해제합니다.
- **회사 소개**: 특정 미리보기 지점의 자동 배포를 사용자 정의합니다.

### 사용자 정의 미리보기 지점 제어

선택하기**회사 소개**, 당신은 포함 하 고 제공된 구성 필드에 자동 배포에서 제외 하는 지점을 지정할 수 있습니다. 구성 필드는 두 가지 방법으로 채워질 수 있습니다:

- **정체되는 분지 이름**: 포함하거나 제외하려는 지점의 정확한 이름을 입력합니다 (예, staging 또는 dev).
- **Wildcard 구문**: 여러 가지 지점과 일치하는 와일드카드를 사용합니다. 규칙의 시작 또는 끝에서 와일드 카드를 지정할 수 있습니다. 구성에 대한 실행의 순서는 (1) 제외, (2) 포함, (3) Skip. Pages는 첫번째를 제외하고, 그 후에 포함합니다 윤곽을 가공할 것입니다. 지점이 일치하지 않으면 건너 뛸 것입니다.

:::노트\[Wildcard 구문]

와일드 카드 (Bildcard)`*`) 규칙 내에서 사용되는 문자입니다. 분기 구성에 더 나은 통제를 허용하는 규칙의 시작 또는 끝에서 무엇이든 일치하기 위하여 혼자 둘 수 있습니다. 와일드 카드는 0 이상 문자와 일치합니다. 예를 들어, 시작된 모든 지점과 일치하려는 경우`fix/`그러면 규칙을 만들 것입니다.`fix/*`문자열을 일치`fix/1`, `fix/bugs`또는`fix/`.

:::

**예제 1:**

분기를 시행하려는 경우`fix/`, `feat/`, 또는`chore/`와일드 카드 구문과 함께 다음 규칙과 특정 지점을 제외 할 수 있습니다 :

- 미리보기 지점 포함:
  `fix/*`, `feat/*`, `chore/*`

- 미리보기 지점 제외:
  ₢ 킹

Pages는 표시된 접두사로 어떤 분지를 포함하고 다른 모든 것을 제외할 것입니다. 이 예에서 제외 옵션은 빈 왼쪽입니다.

**예제 2:**

예방을 원하신다면[카테고리](https://github.com/dependabot)각 PR에 대한 배포를 만들기에서 생성, 당신은 다음과 같은 것들을 제외 할 수 있습니다:

- 미리보기 지점 포함:
  `*`

- 미리보기 지점 제외:
  `dependabot/*`

Pages는 어떤 분지를 제외하고 모든 분지를 포함합니다`dependabot`. 이 예에서, 제외 옵션은 어떤 의미`dependabot/`지점은 건축되지 않습니다.

**예제 3:**

릴리즈를 배포하려면 다음 규칙을 사용할 수 있습니다.

- 미리보기 지점 포함:
  `release/*`

- 미리보기 지점 제외:
  `*`

이것은 단지 지점을 배치합니다.`release/`.

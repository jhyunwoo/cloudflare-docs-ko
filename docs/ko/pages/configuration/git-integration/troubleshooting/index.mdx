git 통합이 문제가 발생하면 Pages 프로젝트의 Deployment 페이지에서 다음 배너를 찾을 수 있습니다.

## 프로젝트 생성

#### `This repository is being used for a Cloudflare Pages project on a different Cloudflare account.`

동일한 GitHub/GitLab 저장소를 사용하여 별도의 Cloudflare 계정이 비활성화됩니다. Pages 프로젝트에 대한 저장소를 사용하려면 CloudflareQ 계정에서 Pages 프로젝트를 다른 QXQX0401XQQQ 계정에서 저장소를 사용하여 삭제해야합니다.

## 계정 만들기

배포 또는 실패와 관련된 모든 문제로 실행하면 프로젝트 대시보드를 확인하고 아래 스크린 샷에 표시된 것과 같이 SCM 설치 경고가 표시됩니다.

![Pages 프로젝트의 설정에서 배포](~/assets/images/pages/platform/git.dashboard-error.png)

Cloudflare Pages QXQX대시보드XQ에 표시된 어떤 오류를 해결하려면 아래 단계를 따르십시오.

#### `This project is disconnected from your Git account, this may cause deployments to fail.`

이 문제를 해결하려면 위의 단계를 따르십시오.[Git 설치 섹션을 다시 설치](/pages/configuration/git-integration/#reinstall-a-git-installation)적용 가능한 SCM 공급자를 위해. 제거 및 재설치 후 문제가 발생하면 연락처 지원.

#### `Cloudflare Pages is not properly installed on your Git account, this may cause deployments to fail.`

이 문제를 해결하려면 위의 단계를 따르십시오.[Git 설치 섹션을 다시 설치](/pages/configuration/git-integration/#reinstall-a-git-installation)적용 가능한 SCM 공급자를 위해. 제거 및 재설치 후 문제가 발생하면 연락처 지원.

#### `The Cloudflare Pages installation has been suspended, this may cause deployments to fail.`

GitHub 설치 설정으로 이동:

- `https://github.com/settings/installations`개별 계정
- `https://github.com/organizations/<YOUR_ORGANIZATION_NAME>/settings/installations`조직 계정

이름 \***설정하기**Cloudflare Pages 신청에. 페이지 하단에 스크롤하고 클릭**다운로드**Cloudflare Pages를 허용하여 미래의 배포를 만듭니다.

#### `The project is linked to a repository that no longer exists, this may cause deployments to fail.`

이 QXQX0413XQQ Pages 프로젝트와 관련된 저장소를 삭제하거나 전송할 수 있습니다. 삭제 된 저장소의 경우 새로운 Cloudflare Pages 프로젝트를 삭제되지 않은 저장소로 만들 필요가 있습니다. 전송 저장소에 대 한, 당신은 원래 Git 계정에 저장소를 전송할 수 있습니다 또는 전송된 저장소와 새로운 Cloudflare Pages 프로젝트를 만들 필요가.

#### `The repository cannot be accessed, this may cause deployments to fail.`

설치 저장소 액세스 설정에서 이 저장소를 제외할 수 있습니다. GitHub 설치 설정으로 이동:

- `https://github.com/settings/installations`개별 계정
- `https://github.com/organizations/<YOUR_ORGANIZATION_NAME>/settings/installations`조직 계정

이름 \***설정하기**Cloudflare Pages 신청에. 이름 \***Repository 접근**, Cloudflare Pages 프로젝트와 관련된 저장소가 목록에 포함되어 있는지 확인하십시오.

#### `There is an internal issue with your Cloudflare Pages Git installation.`

QXQX0423XQQ Pages SCM 시스템의 내부 오류입니다. 당신은 시도할 수 있습니다[Git 설치](/pages/configuration/git-integration/#reinstall-a-git-installation), 그러나 문제 persists 경우,[연락처](/support/contacting-cloudflare-support/).

#### `GitHub/GitLab is having an incident and push events to Cloudflare are operating in a degraded state. Check their status page for more details.`

이것은 GitHub 또는 GitLab이 Cloudflare에 푸시 이벤트에 영향을 미치는 사건을 경험할 수 있음을 나타냅니다. 상태 페이지를 감시하는 것이 좋습니다 ([프로젝트](https://www.githubstatus.com/), [프로젝트](https://status.gitlab.com/)) 업데이트 및 나중에 배포하려고합니다.

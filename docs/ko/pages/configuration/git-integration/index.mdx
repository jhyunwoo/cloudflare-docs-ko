각 Cloudflare Pages 프로젝트를 연결할 수 있습니다.[프로젝트](/pages/configuration/git-integration/github-integration)또는[프로젝트](/pages/configuration/git-integration/gitlab-integration)저장소 및 Cloudflare는 자동으로 코드를 배포합니다.

:::참조
Cloudflare Workers는 이제 Git 통합을 지원하여 연결 된 Git 저장소에서 WorkersXQ를 자동으로 구축하고 배포합니다. 더 알아보기[Workers 회사연혁](/workers/ci-cd/builds/).
:::

CloudflareQXPagesXQ 프로젝트, CloudflareXQXQ에 git 저장소를 연결할 때:

- **사용자 정의 지점을위한 미리보기**, 생산 배포에 영향을 미치지 않고 저장소의 모든 지점에 대한 미리보기 URL 생성.
- **풀 요청에 미리보기 URL**(PRs) 저장소에.
- **빌드 및 배포 상태 체크**Git 저장소 안에.
- **Skipping builds using a 커밋 메시지**.

이 기능은 GitHub 또는 GitLab 내에서 직접 배포를 관리할 수 있습니다.

:::caution\[이전에 직접 업로드할 수 없습니다]
Git 통합을 사용하여 배포하면 전환 할 수 없습니다.[연락처](/pages/get-started/direct-upload/)나중에. 그러나 이미 Git-integrated 프로젝트를 사용한다면 매번 배포를 트리거 할 필요가 없습니다.[disable 자동적인 배치](/pages/configuration/git-integration/#disable-automatic-deployments)모든 지점에서. 그런 다음 Wrangler를 사용하여 Pages 프로젝트에 직접 배포하고 빌드를 자동으로 트리거하지 않고 Git 저장소로 변경할 수 있습니다.

:::

## Git 공급자 지원

CloudflareXQ는 Cloudflare Pages를 GitHub 및 GitLab 저장소에 연결합니다. Pages는 현재 GitHub 또는 GitLab의 자체 호스팅 인스턴스를 연결하지 않습니다.

다른 Git 공급자 (예: Bitbucket) 또는 자체 호스팅 된 인스턴스를 사용하는 경우 직접 업로드 프로젝트와 CI/CD 공급자 (예: GitHub Actions)를 사용하여 배포 할 수 있습니다.[Wrangler 클립](/pages/how-to/use-direct-upload-with-continuous-integration/).

## Git 통합 추가

Cloudflare 계정에 연결된 Git 계정이 없다면 GitHub 또는 GitLab에 설치를 설정할 수 있습니다.[Git에 연결](/pages/get-started/git-integration/)처음으로, 또는 새로운 Git 계정을 추가 할 때. Cloudflare Git 통합을 승인하는 프롬프트를 따르십시오.

Git 통합이 설치된 경우 다음 페이지를 확인할 수 있습니다.

- [GitHub 앱 페이지](https://github.com/settings/installations)(당신이 조직에 있다면, 선택**Switch 설정**GitHub 조직 설정에 액세스하려면
- [GitLab 공인 응용 프로그램 페이지](https://gitlab.com/-/profile/applications)

조직 계정에 대한 액세스 제공에 대한 자세한 내용은, 참조[프로젝트](/pages/configuration/git-integration/github-integration/#organizational-access)·[프로젝트](/pages/configuration/git-integration/gitlab-integration/#organizational-access)관련 기사

## Git 통합 관리

Pages 프로젝트에 항해하여 저장소 연결과 관련된 Git 설치를 관리할 수 있습니다.**계정 설정** > **회사연혁**선택하기**계정 관리**이름 \***Git 저장소**.

repository 접근 또는 재설치하여 설치 문제를 해결하는 데 유용합니다. 자세한 내용은[프로젝트](/pages/configuration/git-integration/github-integration/#managing-access)·[프로젝트](/pages/configuration/git-integration/gitlab-integration/#managing-access)관련 기사

## 자동 배포

Git-integrated 프로젝트를 사용하고 있는 경우 매번 배포를 트리거할 필요가 없습니다.[지점제어](/pages/configuration/branch-build-controls/)disable/pause 구조에:

<Steps>
  1. 오시는 길**Workers & Pages**Cloudflare 대시보드에서.

     <DashButton url="/?to=/:account/workers-and-pages" />

  2. Pages 프로젝트를 선택하십시오.

  3. 바로가기**제품정보**> 편집**지점제어**> 턴오프**자동 생산 지점 배포 가능**.

  4. 미리보기 지점을 변경할 수도 있습니다.**없음 (자동 분지 배포 가능)**&#x74;o pause 자동 미리보기 배포.
</Steps>

그런 다음 Wrangler를 사용하여 Pages 프로젝트에 직접 배포하고 빌드를 자동으로 트리거하지 않고 Git 저장소로 변경할 수 있습니다.

각 Cloudflare Pages 프로젝트를 GitHub 저장소에 연결할 수 있으며, CloudflareXQ는 분기로 변경할 때마다 코드를 자동으로 배포합니다.

## 주요 특징

자동 배포를 넘어 Cloudflare GitHub 통합은 GitHub에서 직접 모니터링, 관리 및 미리보기 배포를 할 수 있으며 워크플로우를 떠나지 않고 알려줍니다.

### 회사 소개

Pages는 기본적으로 당신의 설정에[생산 환경](/pages/configuration/branch-build-controls/#production-branch-control)첫 번째 푸시 지점으로. 기본 지점 이외의 지점(e.g.`main`) 당신의 프로젝트의 생산 분지를 대표합니다, 그 후에 갈**계정 설정** > **회사연혁** > **지점제어**, 생산 지점을 클릭하여 변경**생산 지점**드롭다운 메뉴와 다른 지점을 선택하십시오.

당신은 또한 사용할 수 있습니다[관련 기사](/pages/configuration/preview-deployments/)생산 지점을 merging하기 전에 프로젝트의 미리보기 버전, 생산에 배포합니다. Pages를 사용하면 미리보기 지점을 자동으로 사용하여 구성 할 수 있습니다.[Branch 구축 제어](/pages/configuration/branch-build-controls/). 구성하려면, 이동**계정 설정** > **회사연혁** > **지점제어**옵션 선택**미리보기 지점**. 사용[**회사 소개**](/pages/configuration/branch-build-controls/)자동 미리보기 배포에서 포함하거나 제외하려는 지점을 지정합니다.

### 미리보기 URL

GitHub 저장소에 새로운 풀 요청을 열 때마다 Cloudflare PagesXQ는 새로운 커밋을 지우기 위해 업데이트되는 독특한 미리보기 URL을 만들 것입니다. URL을 미리 표시하는 것은 저장소의 포크에서 만들어진 풀 요청을 위해 생성되지 않습니다. 더 알아보기[미리보기 배포](/pages/configuration/preview-deployments/).

![GitHub 미리보기 URL](~/assets/images/pages/configuration/ghpreviewurls.png)

### 커밋 메시지를 통해 빌드를 건너

어떤 구성이 필요 없이, 당신은 광고 hoc 기반에 배포를 건너 뛸 수 있습니다. 추가하기`[CI Skip]`, `[CI-Skip]`, `[Skip CI]`, `[Skip-CI]`, 또는`[CF-Pages-Skip]`커밋 메시지의 접두사로 플래그, Pages는 배포가 중단됩니다. 접두사는 과민하지 않습니다.

### 자주 묻는 질문

저장소에 연결된 하나의 또는 여러 프로젝트가 있다면 (즉,.[모노레포](/pages/configuration/monorepos/)) GitHub에서 각 빌드의 상태를 확인할 수 있습니다.[GitHub 체크 실행](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/collaborating-on-repositories-with-code-quality-features/about-status-checks#checks).

GitHub 저장소 내에서 커밋하는 상태 아이콘을 선택하여 체크를 볼 수 있습니다. 아래 예에서 체크 실행 결과를 볼 수있는 녹색 체크 마크를 선택할 수 있습니다.

![GitHub 상태](~/assets/images/workers/platform/ci-cd/gh-status-check-runs.png)

체크 실행은 저장소에서 다음과 같이 나타납니다.

![GitHub 체크 실행](~/assets/images/pages/configuration/ghcheckrun.png)

어떤 이유로 빌드 건너뛰기 (즉, CI Skip, 빌드 시계 경로, 또는 지점 배포 제어), 체크 run/commit 상태는 표시되지 않습니다.

## 자주 묻는 질문

GitHub에서 Cloudflare WorkersXQ에 프로젝트를 배포할 수 있습니다.[Cloudflare Workers & Pages GitHub 앱](https://github.com/apps/cloudflare-workers-and-pages).

### 회사연혁

Cloudflare Pages를 GitHub 및 GitLab의 회사 또는 측 프로젝트에서 프로젝트 배포할 수 있습니다.

Cloudflare QXPages를 승인하면 GitHub 계정에 액세스할 수 있으며 GitHub에 속한 개인 계정 또는 조직에 액세스할 수 있습니다. Cloudflare Pages 설치를 조직에 추가 할 수 있도록 사용자 계정은 소유자이어야하며 조직 내에서 적절한 역할을해야합니다 (그, GitHub Apps Manager 역할). 이 역할에 대한 더 많은 정보는 위에 볼 수 있습니다[GitHub의 문서](https://docs.github.com/en/organizations/managing-peoples-access-to-your-organization-with-roles/roles-in-an-organization#github-app-managers).

:::caution\[GitHub 보안 고려사항]

GitHub 계정은 하나의 Cloudflare 계정으로만 해당해야 합니다. CloudflareXQ를 조직의 GitHub로 설정하면 CloudflareXQ는 PagesXQ로 구축하려는 저장소에만 응용 프로그램의 범위를 제한하는 것이 좋습니다. 이 권한을 수정하려면, 이동[회사연혁](https://github.com/settings/installations)GitHub에서 선택**Switch 설정**GitHub 조직 설정에 액세스하십시오. 다음, 선택**QXQX0311XQQWorkers & Pages**> 용**Repository 접근**, 선택**자주 묻는 질문**> 저장소를 선택하십시오.

:::

### 자주 묻는 질문

GitHub 저장소 또는 계정으로 Cloudflare PagesXQ를 제거할 수 있습니다.[회사연혁](https://github.com/settings/installations)GitHub에서 (당신이 조직에 있다면, GitHub 조직 설정에 액세스하기 위해 Switch 설정 컨텍스트를 선택합니다). GitHub 앱은 Cloudflare Workers 및 PagesXQ라는 이름이며 Workers 및 Pages 프로젝트 사이에 공유됩니다.

#### GitHub 저장소에 Cloudflare 액세스 제거

개인 GitHub 저장소에 액세스하려면 탐색할 수 있습니다.**Repository 접근**. 선택**자주 묻는 질문**옵션 및 Cloudflare와 같은 저장소를 재구성하여 액세스 할 수 있습니다.

![GitHub 저장소 액세스](~/assets/images/workers/platform/ci-cd/github-repository-access.png)

#### 전체 GitHub 계정에 Cloudflare 액세스 제거

Cloudflare QXWorkers 및 Pages를 전체 Git 계정에 액세스하려면 탐색 할 수 있습니다.**제거 "Cloudflare Workers 및 Pages"**, 다음 선택**다운로드**. Cloudflare Workers 및 PagesXQ 앱에 대한 액세스를 제거하면 Cloudflare의 액세스가 수정됩니다.*모든 저장소*GitHub 계정에서. 자동 빌드 및 배포만 비활성화하려면[Disable 구조](/workers/ci-cd/builds/#disconnecting-builds)이름 \*

GitHub에 액세스 제거는 Workers 및 Pages 프로젝트에 대한 새로운 빌드를 비활성화 할 수 있지만 이전 배포는 Cloudflare WorkersXQ에 의해 계속 호스팅됩니다.

### Cloudflare GitHub 앱 설치

Cloudflare PagesXQ가 git 저장소에 액세스할 수 없는 오류가 발생하면 Cloudflare QXPagesQ 설치와 관련된 GitHub 응용 프로그램을 제거하고 재설치할 수 있습니다.

1. GitHub의 설치 설정 페이지로 이동:
   - 바로가기**설정 > 회사연혁**Pages 프로젝트 및 선택**계정 관리**Git 저장소 아래.
   - 대체로, Cloudflare QXWorkers 및 Pages 설치 및 선택이 링크를 방문**설정하기**:

|          |                                                                                    |
| -------- | ---------------------------------------------------------------------------------- |
| **한국어**  | `https://github.com/settings/installations`                                        |
| **회사연혁** | `https://github.com/organizations/<YOUR_ORGANIZATION_NAME>/settings/installations` |

2. Cloudflare QXWorkers 및 Pages GitHub 앱 설정 페이지에서 탐색**제거 "Cloudflare Workers 및 Pages"**&#xC120;택하기**다운로드**.
3. 바로가기[**Workers & Pages**모델 번호: 개요](https://dash.cloudflare.com)사이트 맵 제품정보**회사연혁** > **모델 번호: Pages** > **Git에 연결**.
4. 선택하&#xAE30;**+ 계정 추가**버튼, 추가하려는 GitHub 계정을 선택하고, 다음 선택**설치 및 권한**.
5. 계정 목록에서 GitHub 계정 또는 조직으로 프로젝트 페이지를 리디렉션해야합니다.
6. 이전에 깨진 프로젝트로 새로운 배포를 만들려면.

[초기 힌트](/cache/advanced-configuration/early-hints/)브라우저가 웹 페이지를 더 빨리로드하는 데 도움이됩니다. Early Hints는 모두 자동으로 활성화됩니다.`pages.dev`도메인 및 사용자 정의 도메인.

Early Hints는 자동으로 모든 것을 캐시합니다.[`preload`](https://developer.mozilla.org/en-US/docs/Web/HTML/Link_types/preload)·[`preconnect`](https://developer.mozilla.org/en-US/docs/Web/HTML/Link_types/preconnect)제품정보[`Link`맨 위로](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Link)브라우저에 이른 힌트로 보내려면. Hints는 전체 응답이 준비되기 전에 브라우저에 전송되며 브라우저는 최종 사용자를 위해 웹 페이지를 빠르게로드하는 방법을 파악할 수 있습니다. 이 두 가지 방법이 있습니다.`Link`Pages의 헤더:

## 초기 힌트 구성

Early Hints는 아래의 두 가지 방법 중 하나로 만들 수 있습니다.

### 1. 구성`_headers`이름 \*

사용자 정의 헤더 만들기[`_headers`이름 \*](/pages/configuration/headers/). 특정 스타일 시트를 포함 하는 경우`/blog/`웹 사이트의 섹션, 당신은 다음 규칙을 만들 것입니다 :

```txt
/blog/*
  Link: </styles.css>; rel=preload; as=style
```

Pages는 이것을 붙일 것입니다`Link: </styles.css>; rel=preload; as=style`헤더. 이른 힌트는 다음이 헤더를 초기 힌트로 방출합니다.

### 2. 자동`Link`헤드러 세대

저자 경험을 쉽게 만들기 위해 Pages 또한 자동으로 생성`Link`모든 상품`<link>`다음 속성을 가진 HTML 요소:

- `href`
- `as`(선택)
- `rel`(하나의)`preconnect`, `preload`, 또는`modulepreload`)

`<link>`다른 추가 속성을 포함하는 요소 (예를 들어,`fetchpriority`, `crossorigin`또는`data-do-not-generate-a-link-header`) 생성에 사용되지 않습니다`Link`실수로 잃을 방지하기 위해 헤더는 초기 힌트로 떨어질 것입니다.

이 문서를 작성하고 HTML과의 교체없이 초기 힌트를 직접 만들 수 있습니다.`_headers`파일.

```html
<html>
	<head>
		<link rel="preload" href="/style.css" as="style" />
		<link rel="stylesheet" href="/style.css" />
	</head>
</html>
```

### 무능 자동`Link`헤드러 세대 자동`Link`기타 제품

자동 생성`Link`다음을 추가하여 헤더`_headers`파일 :

```txt
/*
  ! Link
```

:::카트로션

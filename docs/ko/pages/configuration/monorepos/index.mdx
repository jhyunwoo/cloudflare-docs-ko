일부 앱은 단일 저장소에서 내장되어 있지만, Pages는 더 복잡한 설정으로 앱을 지원합니다. monorepo는 자신의 응용 프로그램을 포함하는 여러 하위 디렉토리를 가지고있는 저장소입니다.

## 설치하기

동일한 저장소를 사용하여 여러 프로젝트를 만들 수 있습니다.[다른 Pages 프로젝트를 만들 수있는 동일한 방법으로](/pages/get-started/git-integration). 빌드 명령과 / 또는 프로젝트의 루트 디렉토리가 실행하려면 Pages를 알려야 할 옵션이 있습니다. 모든 프로젝트 이름은 동일한 저장소에 연결하면 고유해야합니다.

## 회사연혁

PagesXQ에 git 저장소를 연결하면 저장소에 있는 모든 파일에 변경이 Pages 빌드를 트리거합니다.

![Monorepo 예제 다이어그램](~/assets/images/pages/configuration/pages-path.png)

예를 들어`my-monorepo`두 가지 관련 Pages 프로젝트 이상 (`marketing-app`·`ecommerce-app`) 그리고 그들의 나열된 종점. 기본적으로 프로젝트 디렉토리에 파일을 변경하면`marketing-app`, 다음을위한 빌드`ecommerce-app`프로젝트는 또한 트리거됩니다, 비록 비록`ecommerce-app`그리고 그것의 의존도가 변경되지 않았습니다. 이러한 중복 빌드를 방지하려면 모두 포함 및 제외 할 수 있습니다.[시계 경로 구축](/pages/configuration/build-watch-paths)또는[제품정보](/pages/configuration/branch-build-controls)Pages가 주어진 프로젝트를 위해 빌드를 건너야 하는 경우 지정할 수 있습니다.

## Git 통합

Git 저장소 내에서 프로젝트를 위한 별도의 Pages 프로젝트를 만들면, 각 Git 푸시는 빌드 구성에 지정하지 않는 모든 연결 프로젝트에 대한 새로운 빌드 및 배포를 발행합니다.

GitHub는 업데이트 된 프로젝트와 배포 URL을 가진 각 프로젝트에 대한 별도의 코멘트를 표시합니다.

### GitHub 체크 실행 및 GitLab 커밋 상태

저장소와 관련된 여러 프로젝트가 있다면, 당신의[GitHub 체크 실행](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/collaborating-on-repositories-with-code-quality-features/about-status-checks#checks)또는[Gitlab 커밋 상태](https://docs.gitlab.com/ee/user/project/merge_requests/status_checks.html)저장소에 다음과 같이 나타납니다:

![GitHub 체크 실행](~/assets/images/pages/configuration/ghcheckrun.png)
![GitLab 커밋 상태](~/assets/images/pages/configuration/glcommitstatus.png)

어떤 이유로 빌드 건너뛰기 (즉, CI Skip, 빌드 시계 경로, 또는 지점 배포 제어), 체크 run/commit 상태는 표시되지 않습니다.

## Monorepo 관리 공구:

Pages는 monorepos에 있는 의존성 관리를 위한 전문화한 장식새김을 제공하지 않습니다, 당신은 당신의 저장소를 관리하는 것을 도울 것이다 추가 장식새김을 가져올지도 모릅니다. 간단한 subpackage 관리를 위해, 당신은 같은 도구를 활용할 수 있습니다[₢ 킹](https://docs.npmjs.com/cli/v8/using-npm/workspaces), [사이트맵](https://pnpm.io/workspaces)·[주요 특징](https://yarnpkg.com/features/workspaces)작업 공간. 또한 더 강력한 도구를 사용할 수 있습니다.[터보레포](https://turbo.build/repo/docs), [사이트맵](https://nx.dev/getting-started/intro), 또는[뚱 베어](https://lerna.js.org/docs/getting-started)의존성 및 작업 실행을 추가로 관리합니다.

## 제한 사항

- 자주 묻는 질문[시스템 구축 V2](/pages/configuration/build-image/#v2-build-system)또는 monorepo 지원에 대 한 나중에 활성화.
- 저장소 당 최대 5 Pages 프로젝트를 구성할 수 있습니다. 이 제한이 발생하면 Cloudflare 계정 팀에 연락하거나 사용하십시오.[제한 증가 요청 양식](https://docs.google.com/forms/d/e/1FAIpQLSd_fwAVOboH9SlutMonzbhCxuuuOmiU1L_I5O2CFbXf_XXMRg/viewform).

### 프레임 워크

프레임 워크의 특정 버전을 사용하려면 프로젝트의 패키지 관리자 구성 파일에 지정하십시오.
예를 들어, Gatsby를 사용하는 경우,`package.json`다음을 포함해야:

```
"dependencies": {
	"gatsby": "^5.13.7",
}
```

당신의 빌드가 시작되면, 이미[뚱 베어](/pages/configuration/build-caching/), Gatsby의 버전 5.13.7은 사용 가능`npm install`.

## 고급 설정

### Override 기본 버전

빌드 시스템의 언어 및 도구의 기본 버전을 무시하려면 환경 변수를 통해 원하는 버전을 설정하거나 프로젝트에 파일을 추가하여 할 수 있습니다.

환경 변수를 사용하여 버전을 설정하려면:

1. 언어 또는 도구의 환경 변수 이름 찾기[이 테이블](/pages/configuration/build-image/#supported-languages-and-tools).
2. 대시보드에 환경 변수를 추가하여**계정 설정** > **환경 변수**Pages 프로젝트 또는[Wrangler를 통해 환경 변수 추가](/workers/configuration/environment-variables/#add-environment-variables-via-wrangler).

또는, 당신의 프로젝트에 파일을 추가하여 버전을 설정하려면, 당신은 할 수:

1. 언어 또는 도구의 파일 이름 찾기[이 테이블](/pages/configuration/build-image/#supported-languages-and-tools).
2. 프로젝트의 루트 디렉토리에 지정된 파일 이름을 추가하고, 파일의 내용으로 원하는 버전 번호를 추가합니다.

예를 들어, 이전에 v1 빌드 시스템에서 Node.js의 기본 버전에 의존하는 경우, v2로 마이그레이션하려면 Node.jsXQXQXQXQXQXQXQXQXQXQXQ`12.18.0`으로 설정`NODE_VERSION = 12.18.0`환경 변수 또는 추가`.node-version`또는`.nvmrc`당신의 프로젝트에 파일`12.18.0`파일에 내용을 추가합니다.

## v3 빌드 시스템

v3 빌드 시스템 업데이트 기본 도구, 라이브러리 및 언어는 LTS 버전, 5 월 2025.

### v2에서 v3 마이그레이션

이 새로운 버전으로 마이그레이션하려면 Pages 프로젝트 설정을 대시보드:

1. Cloudflare 대시보드에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />
2. Pages 프로젝트를 선택하십시오.
3. 오시는 길**계정 만들기** > **모든 배포**> 최신 버전을 선택하십시오.

이전에 빌드 시스템의 모든 언어 또는 도구의 기본 버전에 의존하면 빌드가 v3로 마이그레이션 할 때 빌드가 실패 할 수 있습니다. 이 문제를 해결하려면 사용하려는 버전을 지정해야합니다.[회사 소개](/pages/configuration/build-image/#overriding-default-versions)기본 버전.

### 제한 사항

다음 기능은 현재 v3 빌드 시스템을 사용할 때 지원되지 않습니다.

- 코드명으로 Node.js 버전 지정 (예를 들면,`hydrogen`또는`lts/hydrogen`).
- 원사 버전 감지`yarn.lock`파일 버전.
- pnpm 버전 감지 기반`pnpm-lock.yaml`파일 버전.
- Node.js 및 패키지 관리자 감지`package.json` -> `"engines"`.
- `pipenv`·`Pipfile`지원.

## 이미지 정책

### Image Version 사전 구축

현재 v1 또는 v2 빌드 이미지를 사용하는 경우 프로젝트는 v3로 자동으로 이동됩니다.

- **v1 이미지**: Pages v1 빌드 이미지를 사용하는 경우 프로젝트는 9 월 15, 2026에서 v3로 자동으로 이동됩니다.
- **v2 이미지 구축**: Pages v2 빌드 이미지를 사용하는 경우, 프로젝트는 2 월 23, 2027에서 v3로 자동으로 이동됩니다.

퇴직일로부터 6개월 전의 통지를 받게 됩니다.[Cloudflare 공지사항](https://developers.cloudflare.com/changelog/), 대시보드 알림 및 이메일.

앞으로 가기, v3 빌드 이미지는 아래 정책 당 사전 설치된 소프트웨어에 롤링 업데이트를 받게됩니다. 더 이상 이미지 버전 변경을 구축 할 수 없습니다.

### Preinstalled 소프트웨어 업데이트

Preinstalled software (언어 및 도구)는 end-of-life (EOL)에 도달하기 전에 업데이트됩니다. 이 업데이트는 당신이하지 않은 경우에만 적용[overridden 기본 버전](/pages/configuration/build-image/#override-default-versions).

- **Minor 버전 업데이트**: 공지없이 최신 버전으로 업데이트 될 수 있습니다. semantic versioning (e.g., Bun 또는 Hugo)을 따르지 않는 도구는 변경 사항을 포함 할 수있는 업데이트는 3 개월의 통지를 받게됩니다.
- **주요 버전 업데이트**: 다음 안정적인 장기 지원 (LTS) 버전으로 3 개월의 통지.

**당신은 통지를 요구할 경우 (예고를 요구하는 변화를 위해):**

- [Cloudflare 변경 로그](https://developers.cloudflare.com/changelog/)
- Dashboard는 업데이트가 될 프로젝트의 알림
- 프로젝트 소유자에게 이메일 알림

특정 버전을 유지하고 자동 업데이트를 방지하기 위해,[기본 버전 삭제](/pages/configuration/build-image/#override-default-versions).

### 최고의 연습

예상치 못한 빌드 실패를 피하기 위해:

- **모니터 발표**을 통해[Cloudflare 변경 로그](https://developers.cloudflare.com/changelog/), 대시보드 알림 및 이메일
- **이민 계획**업데이트 알림을 받으면
- **Pin 특정한 버전**중요한 preinstalled 소프트웨어의[overriding 기본 버전](/pages/configuration/build-image/#override-default-versions)

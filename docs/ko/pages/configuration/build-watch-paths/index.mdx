Pages에 git 저장소를 연결하면 저장소에 있는 모든 파일에 변경이 Pages 빌드를 트리거합니다. Pages를 구성하거나 Pages가 주어진 경로에 대한 빌드를 건너야 할 경우 특정 경로 제외 할 수 있습니다. 모노레포 프로젝트 구조를 사용하고 빌드의 양을 제한하고 싶다면 특히 도움이 될 수 있습니다.

## 경로 구성

어떤 경로가 포함되고 제외되는 구성하려면:

<Steps>
  1. 오시는 길**Workers & Pages**Cloudflare 대시보드에서.

     <DashButton url="/?to=/:account/workers-and-pages" />

  2. Pages 프로젝트 찾기

  3. 오시는 길**계정 설정** > **제품정보** > **시계 경로 구축**. Pages는 프로젝트의 설정에 기본적으로 모든 경로 (\[\*]) 및 아무것도 경로 제외 (`[]`).
</Steps>

구성 필드는 두 가지 방법으로 채워질 수 있습니다:

- **정체되는 filepaths**: 포함하거나 제외하려는 파일의 정확한 이름을 입력하십시오 (예를 들어,`docs/README.md`).
- **Wildcard 구문:**&#xC640;일드카드를 사용하여 여러 경로와 일치합니다. 규칙의 시작 또는 끝에서 와일드 카드를 지정할 수 있습니다.

:::노트\[Wildcard 구문]

와일드 카드 (Bildcard)`*`) 0 이상의 문자를 일치,**path 분리기를 포함하여 (`/`)**. 이것은 단일 의미`*`경로 패턴의 끝에서 배열 된 하위 디렉토리뿐만 아니라 파일. 예를 들면:

- `docs/*`이름 \*`docs/README.md`, `docs/guides/setup.md`·`docs/guides/advanced/config.md`.
- `*.md`이름 \*`README.md`, `docs/README.md`·`src/content/guide.md`.
- `*`혼자서 저장소에 모든 파일을 일치.

:::

푸시 이벤트의 각 경로에 대한, 시계 경로는 다음과 같이 평가됩니다:

- 조건을 만족시키는 경로는 첫 번째 무시됩니다
- 모든 나머지 경로는 조건을 포함합니다.
- 어떤 일치하는 경로가 발견되면 빌드가 트리거됩니다. 그렇지 않으면 빌드는 Skipped

Pages는 푸시 이벤트 및 기본에 대한 경로 일치를 우회하여 프로젝트를 구축 할 것입니다.

- 푸시 이벤트는 0 파일 변경이 포함되며 사용자가 빌드를 트리거하기 위해 빈 푸시 이벤트를 푸시합니다.
- 푸시 이벤트는 3000 + 파일 변경 또는 20 + 커밋이 포함되어 있습니다.

## 이름 \*

### 특정 감독 (monorepo)에 대한 방아쇠 구축

파일이 특정 디렉토리 내에서 변경 될 때만 빌드를 트리거하려면`project-a/`·`packages/`. 때문에`*`경로 분리기의 맞은편에, 이것은 배열된 subdirectories에 있는 변화를 포함합니다`project-a/src/index.js`또는`packages/utils/lib/helpers.ts`.

- 경로 포함:`project-a/*, packages/*`
- 경로 제외: \`\`

### 트리거 빌드에서 디렉토리 제외

어떤 변경 사항에 대한 빌드를 트리거하려면, 하지만 특정 디렉토리에 변경을 제외하고, 모든 변경 사항`docs/`디렉토리 (포함 배열 같은 경로`docs/guides/setup.md`).

- 경로 포함:`*`
- 경로 제외:`docs/*`

### Trigger는 특정 파일 형식을 구축

특정 파일 또는 특정 파일 유형에 대한 빌드를 트리거하려는 경우, 예를 들어 모든`.md`저장소에 있는 파일.

- 경로 포함:`*.md`
- 경로 제외: \`\`

### Trigger builds for directory 하지만 하위 디렉토리 제외

빌드를 트리거하려는 경우`src/`하지만 변경을 무시하려면`src/tests/`.

- 경로 포함:`src/*`
- 경로 제외:`src/tests/*`

## 사용자 지정 미리보기 배포 액세스

사용 가능[모델 번호: Cloudflare 오시는 길](/cloudflare-one/access-controls/policies/)배포 미리보기에 대한 액세스를 관리합니다. 기본적으로 이러한 배포 URL이 공개됩니다. 액세스 정책을 제거하면 Cloudflare 계정에 프로젝트 배포를 제한합니다.

일단 활성화되면,[다중 사용자 계정 설정](/fundamentals/manage-members/)다른 구성원의 팀을 볼 미리보기 배포.

기본적으로 미리보기 배포가 활성화되고 공개적으로 사용할 수 있습니다. 프로젝트의 설정에서 미리보기 배포를 볼 수있는 방문자가 필요할 수 있습니다. 이를 통해 이러한 미리보기 배포에 대한 액세스를 차단할 수 있습니다. 팀원, 조직 또는 누구에게도 지정[오시는 길](/cloudflare-one/traffic-policies/).

Cloudflare 접근:

1. Cloudflare 대시보드에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />

2. Pages 프로젝트를 선택하십시오.

3. 오시는 길**계정 설정** > **주요사업**> 선택**이용 약관**.

주의 이만 보호 미리보기 배포 (예를 들어,`373f31e2.user-example.pages.dev`그리고 다른 모든 무작위로 생성된 미리보기 링크) 그리고 당신의`*.pages.dev`도메인 또는 사용자 정의 도메인.

## 미리보기 aliases

미리보기 배포가 게시되면, 고유의 해시 기반 주소를 부여합니다. 예를 들어,`<hash>.<project>.pages.dev`. 이것은 원자이고 항상 미래에 방문될지도 모릅니다. 그러나 Pages는 또한 별명을 위해 창조합니다`git`분기의 이름과 업데이트는 alias 항상 그 지점의 최신 커밋에 맵.

예를 들어, 변경을 푸시하면`development`분지 (당신의 생산 환경에 관련되지 않는), 그 후에 Pages는 배치할 것입니다`abc123.<project>.pages.dev`그리고 별`development.<project>.pages.dev`그것으로. 나중에 새로운 일을 밀어 줄 수 있습니다.`development`분기, 이는`xyz456.<project>.pages.dev`설치. 이 시점에서,`development.<project>.pages.dev`alias 포인트`xyz456`배포,하지만`abc123.<project>.pages.dev`자주 묻는 질문

Branch name aliases는 lowcased이고 non-alphanumeric 문자는 hyphen로 대체됩니다 — 예를 들면,`fix/api`지점 생성`fix-api.<project>.pages.dev`한국어

Pages 프로젝트 내에서 분기 별칭을 볼 수 있습니다.**뷰 빌더**모든 미리보기 배포.**Deployment 세부사항**그 배포와 관련된 모든 별명을 표시합니다.

Preview alias를 사용자 정의 도메인에 첨부할 수 있습니다.[사용자 정의 도메인을 분기에 추가](https://developers.cloudflare.com/pages/how-to/custom-branch-aliases/).

## 검색 엔진의 미리보기 색인

건강한 SEO 프로파일을 유지하기 위해 웹에서 중복 콘텐츠를 찾는 검색 엔진을 방지하는 것이 중요합니다. 미리 배치는 생산 환경의 정확한 복제이기 위하여 디자인됩니다 때문에, 그들은 이 정확한 상황을 inherently 창조합니다. Cloudflare Pages는 기본적으로 당신의 검색 순위를 이 임시 미리보기에 의해 해치지 않습니다.

### X-Robots-Tag: 미리보기 배포시 인덱스

기본적으로 Cloudflare PagesXQXQ에 의해 생성된 모든 미리보기 배치는 X-Robots-Tag를 포함합니다: noindex HTTP 응답 헤더. 이 헤더는 엔진 크롤러를 검색하는 명확한 지시로 작동하며 페이지를 파괴하고 검색 결과에 포함하지 않습니다.

미리보기 배포가 올바르게 구성되도록 쉽게 확인할 수 있습니다. 터미널에서 다음 컬 명령을 실행하고, 고유 미리보기 URL을 가진 placeholder를 대체하십시오.

```
curl -I https://<your-preview-url>.pages.dev
```

x-robots-tag에 대한 출력을 검사하십시오. 미리보기 사이트가 색인되지 않다는 것을 확인하려면 인덱스 라인이 없습니다.

당신은 Cloudflare QXPages를 말할 수 있습니다 당신의 위치는 건축될 뿐 아니라 그것의 산출 파일이 어디에 있을지 건축될 필요가 있는.

## 명령 및 디렉토리 구축

Cloudflare QXPagesXQ를 작성하는 빌드 명령을 제공해야 합니다. 여기에 나열되지 않은 프로젝트에 대한, 도구의 문서 또는 프레임 워크를 읽고, 여기에 추가 할 풀 요청을 제출.

프로젝트의 빌드 명령이 Cloudflare Pages 사이트의 내장 버전을 출력하는 위치를 나타냅니다. 종종,이 기본값은 업계 표준`public`, 그러나 당신은 당신이 그것을 주문을 받아서 만들 필요가 있다는 것을 찾아낼지도 모릅니다.

<Details header="빌드 구성 이해">
  빌드 명령은 프레임 워크에 의해 제공됩니다. 예를 들어, Gatsby Framework 사용`gatsby build`빌드 명령으로. 프레임 워크없이 작업 할 때, 떠나**명령 실행**필드 빈. Pages는 빌드가 성공하거나 사용자가 공급한 빌드 명령에서 반환된 출구 코드를 읽고 실패 여부를 결정합니다. non-zero 반환 코드는 실패로 표시 될 빌드가 발생할 것입니다. 0의 출구 코드는 Pages 빌드가 표준 오류로 작성된 경우 오류 로그에 관계없이 성공적인 자산이 업로드됩니다.

  빌드 디렉토리는 빌드 명령에서 생성됩니다. 각 프레임 워크는 자체 naming 컨벤션을 가지고 있습니다. 예를 들어, 빌드 출력 디렉토리는 다음과 같습니다.`/public`많은 기구를 위해.

  root 디렉토리는 사이트의 콘텐츠가 살고 있는 곳입니다. 지정되지 않은 경우, Cloudflare는 연결된 git 저장소가 루트 디렉토리임을 가정합니다. root 디렉토리는 monorepos와 같은 경우에 지정되어야하며, 하나의 저장소에 여러 프로젝트가있을 수 있습니다.
</Details>

## 프레임 워크

Cloudflare는 대중적인 기구 및 공구를 위한 건축 윤곽의 명부를 유지합니다. 프로젝트 작성 중에 사용할 수 있습니다. 아래는 인기있는 프레임 워크 및 도구에 대한 일부 표준 빌드 명령 및 디렉터리입니다.

미리 설정하지 않으면 사용`exit 0`이름 \***명령 실행**.

## 환경 변수

프로젝트가 귀하의 사이트를 구축하기 위해 환경 변수의 사용을 만들면 사용자 정의 환경 변수를 제공 할 수 있습니다.

1. Cloudflare QX대시보드에서, 갑니다**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />
2. Pages 프로젝트를 선택하십시오.
3. 제품정보**계정 설정** > **환경 변수**.

다음과 같은 시스템 환경 변수는 기본적으로 주사됩니다 (그러나 overridden 일 수 있습니다):

| 환경 변수                 | 잘못된 값                                 | 사용 사례                                           |
| --------------------- | ------------------------------------- | ----------------------------------------------- |
| `CI`                  | `true`                                | CI versus 로컬에서 실행할 때 빌드 동작 변경                   |
| `CF_PAGES`            | `1`                                   | Pages를 로컬로 실행할 때 빌드 동작 변경                       |
| `CF_PAGES_COMMIT_SHA` | `<sha1-hash-of-current-commit>`       | 현재 커밋 ID를 오류 보고, 예를 들어, Sentry                  |
| `CF_PAGES_BRANCH`     | `<branch-name-of-current-deployment>` | 분기에 따라 사용자 정의 빌드, 예를 들어, 디버그 로깅을 해제`production` |
| `CF_PAGES_URL`        | `<url-of-current-deployment>`         | URL을 알기 위해 빌드 도구를 허용하면 페이지가 배포됩니다.              |

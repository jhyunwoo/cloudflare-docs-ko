모델 번호: Pages Functions는 Cloudflare 네트워크에서 코드를 실행하여 전체 스택 응용 프로그램을 구축할 수 있습니다.[Cloudflare Workers](/workers/). 기능으로, 당신은 정통, 취급 모양 제출과 같은 신청 양상을 소개할 수 있습니다, 또는 미들웨어로 일.[Workers 런타임 기능](/workers/runtime-apis/)Pages 기능에 구성 가능[Node.js API의 하위 세트와 호환](/workers/runtime-apis/nodejs)그리고 설정할 수있는 능력[호환성 날짜 또는 호환성 깃발](/workers/configuration/compatibility-dates/). 기능을 사용하여 서버 측 코드를 배포하여 전용 서버를 실행하지 않고 동적 기능을 활성화합니다.

피드백을 제공하거나 기능에 질문을하기 위해, 가입[Cloudflare 개발자 Discord](https://discord.com/invite/cloudflaredev)그리고 Cloudflare 팀과 연결하십시오[#functions 채널](https://discord.com/channels/595317990191398933/910978223968518144).

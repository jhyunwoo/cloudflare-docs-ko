Pages 기능 지원 TypeScript. 저자 당신의 파일`/functions`디렉토리`.ts`대신 확장`.js`TypeScriptXQ를 사용하여 시작하는 확장.

runtime 유형과 Env 유형을 실행하여 추가할 수 있습니다:

<PackageManagers type="exec" pkg="wrangler" args={"types --path='./functions/types.d.ts'"} />

그런 다음 유형을 구성`functions/tsconfig.json`파일 :

```json
{
	"compilerOptions": {
		"target": "esnext",
		"module": "esnext",
		"lib": ["esnext"],
		"types": ["./types.d.ts"]
	}
}
```

이름 \*[이름 \*`wrangler types`명령 docs](/workers/wrangler/commands/#types)더 많은 정보.

이미 있다면`tsconfig.json`프로젝트의 뿌리에서 명시적으로 제외하면`/functions`분쟁을 피하기 위해 디렉토리. 제외하기`/functions`디렉토리:

```json
{
	"include": ["src/**/*"],
	"exclude": ["functions/**/*"],
	"compilerOptions": {}
}
```

모델 번호: Pages 함수는 typed일 수 있습니다`PagesFunction`유형. 이 유형은 받아들입니다`Env`모수. 더 보기`Env`유형은 생성되어야 합니다`wrangler types`그리고 위에 찾을 수 있습니다`types.d.ts`.

또는, 당신은 정의 할 수 있습니다`Env`수동으로 입력. 예를 들면:

```ts
interface Env {
	KV: KVNamespace;
}

export const onRequest: PagesFunction<Env> = async (context) => {
	const value = await context.env.KV.get("example");
	return new Response(value);
};
```

자주 묻는 질문`nodejs_compat`, 당신이 설치한 것을 확인합니다`@types/node`업데이트`tsconfig.json`.

```json
{
	"compilerOptions": {
		"target": "esnext",
		"module": "esnext",
		"lib": ["esnext"],
		"types": ["./types.d.ts", "node"]
	}
}
```

:::참조

당신이 이전에 사용 된 경우`@cloudflare/workers-types`대신에 생성된 runtime 유형의`wrangler types`, 당신은 이것을 참조할 수 있습니다[본문 바로가기](/workers/languages/typescript/#migrating).

:::

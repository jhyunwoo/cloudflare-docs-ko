## Wrangler 설치

시작하기XQ에 QXQXQXQ, 참조[설치/업데이트 Wrangler](/workers/wrangler/install-and-update/).

## 로컬 Pages 프로젝트 실행

Pages의 로컬 개발의 주요 명령은`wrangler pages dev`. 이것은 당신이 당신의 Pages 신청을 로컬로 달릴 것입니다, 정체되는 자산을 봉사하고 당신의 기능을 달리는 포함하는.

정적 자산의 폴더로 설정된 다음 명령을 실행하여 로컬 개발을 시작할 수 있습니다.

```sh
npx wrangler pages dev <DIRECTORY-OF-ASSETS>
```

다음 Pages 프로젝트를 제공 시작합니다. 자주 묻는 질문`b`로컬 사이트에 브라우저를 열려면 (사용 가능, 기본적으로, on[모델 번호: http://localhost:8788](http://localhost:8788)).

:::참조

당신이 있는 경우에[Wrangler 구성 파일](/pages/functions/wrangler-configuration/)Pages 프로젝트를 위해 구성된 파일로 실행할 수 있습니다.[`wrangler pages dev`](/workers/wrangler/commands/#dev-1)디렉토리를 지정하지 않고.

:::

### HTTPS 지원

자체 서명 된 인증서로 HTTPS를 통해 로컬 개발 서버를 제공하려면 \[설정`local_protocol`을 통해[Wrangler 구성 파일](/pages/functions/wrangler-configuration/#local-development-settings)또는 당신은 통과할 수 있습니다`--local-protocol=https`인수하기[`wrangler pages dev`](/workers/wrangler/commands/#dev-1):

```sh
npx wrangler pages dev --local-protocol=https <DIRECTORY-OF-ASSETS>
```

## 로컬 개발에 바인딩을 첨부

로컬 개발에 바인딩을 부착하려면, 참조[회사 소개](/pages/functions/bindings/)Cloudflare 개발자 플랫폼 리소스를 찾을 수 있습니다.

## 추가 Wrangler 구성

프로젝트의 Wrangler 구성 파일을 사용 중인 경우 다음과 같은 dev 서버 값을 설정할 수 있습니다.`port`, `local protocol`, `ip`·`port`. 더 많은 정보를 위해, 자세히보기[로컬 개발 설정](/pages/functions/wrangler-configuration/#local-development-settings).

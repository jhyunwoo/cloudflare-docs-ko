다음 방법은 Pages 기능을 구성하는 데 사용할 수 있습니다.

## 제품 설명

### `onRequests`

더 보기`onRequest`메서드는 더 구체적인 경우 호출됩니다.`onRequestVerb`방법은 수출됩니다. 예를 들면, 둘 다`onRequest`·`onRequestGet`수출되고, 단지`onRequestGet`에 대한 호출`GET`이름 \*

- <code>onRequest(콘텍스트)[이벤트Context](#eventcontext))</code>응답 | 약속\<Response>

  - 이 기능은 모든 요청에 부각 될 것입니다 어떤 요청 방법은, 특정 요청 동사 (아래 방법 중 하나와 같은) 수출.

- <code>onRequestGet(콘텍스트[이벤트Context](#eventcontext))</code>응답 | 약속\<Response>

  - 이 기능은 전부에 invoked 일 것입니다`GET`이름 \*

- <code>onRequestPost(콘텍스트)[이벤트Context](#eventcontext))</code>응답 | 약속\<Response>

  - 이 기능은 전부에 invoked 일 것입니다`POST`이름 \*

- <code>onRequestPatch(콘텍스트)[이벤트Context](#eventcontext))</code>응답 | 약속\<Response>

  - 이 기능은 전부에 invoked 일 것입니다`PATCH`이름 \*

- <code>onRequestPut(콘텍스트)[이벤트Context](#eventcontext))</code>응답 | 약속\<Response>

  - 이 기능은 전부에 invoked 일 것입니다`PUT`이름 \*

- <code>onRequestDelete (콘텍스트)[이벤트Context](#eventcontext))</code>응답 | 약속\<Response>

  - 이 기능은 전부에 invoked 일 것입니다`DELETE`이름 \*

- <code>onRequestHead(콘텍스트)[이벤트Context](#eventcontext))</code>응답 | 약속\<Response>

  - 이 기능은 전부에 invoked 일 것입니다`HEAD`이름 \*

- <code>onRequestOptions (콘텍스트[이벤트Context](#eventcontext))</code>응답 | 약속\<Response>

  - 이 기능은 전부에 invoked 일 것입니다`OPTIONS`이름 \*

### `env.ASSETS.fetch()`

더 보기`env.ASSETS.fetch()`함수는 Pages 프로젝트에서 정적 자산을 가져올 수 있습니다.

당신은 통과 할 수 있습니다[자주 묻는 질문](/workers/runtime-apis/request/), URL 문자열, 또는 URL 객체`env.ASSETS.fetch()`기능. URL은 꽤 경로에 있어야합니다, 자산에 직접. 예를 들어, 경로가 있다면`/users/index.html`, 당신은 요구할 것입니다`/users/`대신에`/users/index.html`. 이 메소드 호출은 헤더를 실행하고 규칙을 리디렉션하고 반환되는 응답을 수정합니다.

## 제품정보

### `EventContext`

다음은 속성입니다.`context`위에 통과되는 객체`onRequest`방법 :

- `request` [제품 정보](/workers/runtime-apis/request/)

  이것은 들어오는[제품 정보](/workers/runtime-apis/request/).

- `functionPath`이름 \*

  요청의 경로입니다.

- <code>waitUntil(프로미스프로미스\<any>)</code>뚱 베어

  더 알아보기[`waitUntil`관련 기사](/workers/runtime-apis/context/#waituntil)더 많은 정보.

- <code>패스ThroughOnException()</code>뚱 베어

  더 알아보기[`passThroughOnException`관련 기사](/workers/runtime-apis/context/#passthroughonexception)더 많은 정보. 이 작업을 수행하지 않습니다[고급 모드 프로젝트](/pages/functions/advanced-mode/).

- <code>다음(입력) 요청 | 문자열, init? 견적 요청</code>약속\<Response>

  다음 기능을 통해 요청을 전달하거나 다른 기능을 사용할 수 없는 경우 자산 서버로.

- `env` [사이트맵](#envwithfetch)

- `params`파라스\<P>

  가치 저장[동적인 routing](/pages/functions/routing/#dynamic-routes).

  다음 예제에서는 동적 경로가 있습니다.`/users/[user].js`. 당신이 위치에 방문할 때`/users/nevi`이름 \*`params`객체는 다음과 같습니다:

  ```js
  {
  	user: "nevi";
  }
  ```

  이 경로에서 역동적 가치를 끌어낼 수 있습니다:

  ```js
  export function onRequest(context) {
  	return new Response(`Hello ${context.params.user}`);
  }
  ```

  어떤 반환`"Hello nevi"`.

- `data`자료실

### `EnvWithFetch`

환경변수, 비밀 및 함수에 대한 바인딩을 잡아라. 이것은 또한 보유`ASSETS`자산 관리 행동에 어떻게 떨어질 수 있는 바인딩.

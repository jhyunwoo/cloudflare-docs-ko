정체되는 모양 Pages Plugin intercepts 모든 양식 제출 만든`data-static-form-name`속성 설정. 이 양식 제출에 대한 작업을 수행 할 수 있습니다, 예를 들어, KVXQ에 제출 저장.

## 설치하기

<PackageManagers pkg="@cloudflare/pages-plugin-static-forms" />

## 제품 정보

```typescript
import staticFormsPlugin from "@cloudflare/pages-plugin-static-forms";

export const onRequest: PagesFunction = staticFormsPlugin({
	respondWith: ({ formData, name }) => {
		const email = formData.get("email");
		return new Response(
			`Hello, ${email}! Thank you for submitting the ${name} form.`,
		);
	},
});
```

```html
<body>
	<h1>Sales enquiry</h1>
	<form data-static-form-name="sales">
		<label>Email address <input type="email" name="email" /></label>
		<label>Message <textarea name="message"></textarea></label>
		<button type="submit">Submit</button>
	</form>
</body>
```

플러그인은 단일 인수, 객체를 가지고`respondWith`호텔 위치 이 기능은 객체를 가지고`formData`재산 (the[`FormData`](https://developer.mozilla.org/en-US/docs/Web/API/FormData)인스턴스) 및`name`재산 (이름의 값)`data-static-form-name`속성). 그것은 반환해야`Response`또는`Promise`한국어`Response`. 그것은 이것에`respondWith`일련화와 같은 작업을 수행 할 수있는 기능`formData`KV 네임스페이스에 저장합니다.

더 보기`method`·`action`HTML 양식의 속성은 설정할 필요가 없습니다. 플러그인은 자동으로 제출을 방해 할 수 있도록합니다.

그래프QL Pages Plugin은 GraphQL 서버를 생성한다.`application/json`·`application/graphql` `POST`이름 \* 그것은 응답[GraphQL 놀이터](https://github.com/graphql/graphql-playground)제품 정보`GET`이름 \*

## 설치하기

<PackageManagers pkg="@cloudflare/pages-plugin-graphql" />

## 제품 정보

```typescript
import graphQLPlugin from "@cloudflare/pages-plugin-graphql";
import {
	graphql,
	GraphQLSchema,
	GraphQLObjectType,
	GraphQLString,
} from "graphql";

const schema = new GraphQLSchema({
	query: new GraphQLObjectType({
		name: "RootQueryType",
		fields: {
			hello: {
				type: GraphQLString,
				resolve() {
					return "Hello, world!";
				},
			},
		},
	}),
});

export const onRequest: PagesFunction = graphQLPlugin({
	schema,
	graphql,
});
```

이 플러그인은 단일 경로 만 노출되므로 마운트 된 경우 사용할 수 있습니다. 위의 예에서, 그것은 안으로 거치되기 때문에`functions/graphql.ts`, 서버는 안으로 유효할 것입니다`/graphql`Pages 프로젝트.

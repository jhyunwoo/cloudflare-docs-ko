hCaptcha Pages 플러그인은 hCaptcha 토큰을 검증합니다.

## 설치하기

<PackageManagers pkg="@cloudflare/pages-plugin-hcaptcha" />

## 제품 정보

```typescript
import hCaptchaPlugin from "@cloudflare/pages-plugin-hcaptcha";

export const onRequestPost: PagesFunction[] = [
	hCaptchaPlugin({
		secret: "0x0000000000000000000000000000000000000000",
		sitekey: "10000000-ffff-ffff-ffff-000000000001",
	}),
	async (context) => {
		//요청은 인간에서 오는 것으로 검증되었습니다.

		const formData = await context.request.formData();

		//사용자 자격

		return new Response("Successfully registered!");
	},
];
```

이 플러그인은 단일 경로 만 노출됩니다. 그것은 거치되는 곳에 유효할 것입니다. 위의 예에서, 그것은 안으로 거치되기 때문에`functions/register.ts`, 그것은 유효한 요청을`/register`. 플러그인은 다음과 같은 속성을 가진 단일 객체 매개 변수로 마운트됩니다.

[`secret`](https://dashboard.hcaptcha.com/settings)(필수) 및[`sitekey`](https://dashboard.hcaptcha.com/sites)(선택) hCaptcha 대시보드에서 둘 다 찾아낼 수 있습니다.

`response`·`remoteip`옵션 문자열입니다.`response`hCaptcha 토큰을 확인하기 위해 (기본 추출`h-captcha-response`한국어`multipart/form-data`요청).`remoteip`requester의 IP 주소 (기본값에서`CF-Connecting-IP`요청의 헤더).

`onError`Pages 기능 컨텍스트 객체를 취하고 반환하는 옵션 기능입니다.`Promise`한국어`Response`. 기본적으로, 그것은 인간의 읽기 쉬운 오류를 반환합니다`Response`.

`data.hCaptcha`다음 Pages에서 대중화될 것입니다 기능 (를 포함하여`onError`기능)와[hCaptcha 응답 객체](https://docs.hcaptcha.com/#verify-the-user-response-server-side).

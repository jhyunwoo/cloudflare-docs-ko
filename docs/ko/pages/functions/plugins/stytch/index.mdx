Stytch Pages 플러그인은 모든 요청과 그들의 유효한 미들웨어입니다.`session_token`.

## 설치하기

<PackageManagers pkg="@cloudflare/pages-plugin-stytch" />

## 제품 정보

```typescript
import stytchPlugin from "@cloudflare/pages-plugin-stytch";
import { envs } from "@cloudflare/pages-plugin-stytch/api";

export const onRequest: PagesFunction = stytchPlugin({
	project_id: "YOUR_STYTCH_PROJECT_ID",
	secret: "YOUR_STYTCH_PROJECT_SECRET",
	env: envs.live,
});
```

KVXQ에 비밀을 저장하는 것이 좋습니다.

Stytch Plugin은 단일 인수, 여러 속성을 가진 객체가 걸립니다.`project_id`·`secret`필수 문자열이며, 찾을 수 있습니다[Stytch의 대시보드](https://stytch.com/dashboard/api-keys). `env`또한 필수 문자열이며, 팝업 될 수 있습니다.`envs.test`또는`envs.live`API의 변수. 기본적으로, Plugin validates`session_token`수신 요청의 쿠키, 그러나 당신은 또한 선택적으로 패스 할 수 있습니다`session_token`또는`session_jwt`다른 메커니즘을 사용하여 사용자 세션을 식별하는 경우 문자열. 마지막으로, 당신은 또한 통과 할 수 있습니다`session_duration_minutes`세션의 수명을 연장하기 위해. 이 매개 변수에 대한 더 많은 정보를 찾을 수 있습니다[Stytch 문서](https://stytch.com/docs/api/session-auth).

사용자 정보를 포함하는 검증된 세션 응답은 다음 Pages 기능에 유효합니다`data.stytch.session`.

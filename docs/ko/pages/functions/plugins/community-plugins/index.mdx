다음은 커뮤니티 기반 Pages 플러그인의 일부입니다. Pages 플러그인을 생성하고 개발자와 공유하고자 하는 경우, 이 알파벳순으로 주문된 리스트에 추가하기 위해 PR을 만들 수 있습니다.

- [페이지-plugin-asset-negotiation](https://github.com/Cherry/pages-plugin-asset-negotiation)

  여러 형식의 자산의 폴더를 제공, 이 플러그인은 클라이언트와 자동으로 요청 된 자산의 최적화 된 버전을 제공 할 것입니다.

- [proxyflare - 페이지](https://github.com/flaregun-net/proxyflare-for-pages)

  Cloudflare QXPages 도메인 주변의 트래픽을 쉽게 이동하십시오. Proxyflare는 다음과 같은 역 프록시입니다.

  - 인터넷에서 HTTP 및 websocket 트래픽을 전달하고 리디렉션하고 재시작합니다.
  - subpath에 전체 웹 사이트를 마운트 (예를 들어,`mysite.com/docs`) 당신의 apex 도메인에.
  - 정적 텍스트 (like)`robots.txt`다른 구조화된 메타데이터)

  더 알아보기[Proxyflare는](https://proxyflare.works)더 많은 정보.

- [클라우드 플레어 페이지-plugin-rollbar](https://github.com/hckr-studio/cloudflare-pages-plugin-rollbar)

  더 보기[롤바](https://rollbar.com/)모델 번호: Pages Plugin 캡처 및 실행 체인에서 발생하는 모든 예외를 로그
  너의 것[모델 번호: Pages 제품정보](/pages/functions/). 발견, 예측 및 실시간 오류 해결.

- [클라우드 플레어 페이지-plugin-trpc](https://github.com/toyamarinyon/cloudflare-pages-plugin-trpc)

  개발자가 Cloudflare QXPages 기능으로 tRPC 서버를 신속하게 만들 수 있습니다.

- [페이지 플러그인](https://github.com/helloimalastair/twind-plugin)

  자동적으로 스 테일 윈드 CSS 스타일을 HTML 페이지로 주사하여 어떤 클래스가 사용됩니다.

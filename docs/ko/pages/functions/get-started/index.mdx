이 가이드는 Pages 기능을 생성하고 배포할 수 있습니다.

## 자주 묻는 질문

Cloudflare QX대시보드에서 로컬 머신에 설치하거나 Cloudflare QXQXQXQ에 배포해야 합니다. Pages 프로젝트를 만들려면, 참조[시작하기](/pages/get-started/).

## 기능 만들기

시작하기에 Pages 기능, 창조`/functions`디렉토리. 확인하기`/functions`디렉토리는 Pages 프로젝트의 루트에 있습니다 (과 같은 정적 루트에 없습니다)`/dist`).

:::노트\[Advanced mode]

Pages Functions의 내장 파일 경로 기반 라우팅 및 미들웨어 시스템이 바람직하지 않은 기존 애플리케이션의 경우, 사용[고급 모드](/pages/functions/advanced-mode/). 진보된 형태는 당신이 당신의 Pages를 개발할 것을 허용합니다 기능과 기능`_worker.js`파일 보다는 오히려`/functions`디렉토리.

:::

기능 파일을 작성`/functions`디렉토리는 지정된 경로에서 사용자 정의 기능을 사용하여 노동자를 자동으로 생성합니다.

다음 코드를 복사하고 붙여넣기`helloworld.js`당신이 당신의안에 창조하는 파일`/functions`폴더:

```js
export function onRequest(context) {
	return new Response("Hello, world!");
}
```

위 예제 코드에서,`onRequest`핸들러가 요청[`context`](/pages/functions/api-reference/#eventcontext)객체. 핸들러는 반환해야 합니다.`Response`또는`Promise`한국어`Response`.

이 기능은 켜집니다`/helloworld`경로 및 반환`"Hello, world!"`. 이 함수는 이 경로에 사용할 수 있는 이유는 파일이 이름이기 때문에`helloworld.js`. 마찬가지로, 이 파일이 호출 된 경우`howdyworld.js`, 이 기능은 위에 달릴 것입니다`/howdyworld`.

더 알아보기[로그아웃](/pages/functions/routing/)경로 사용자 정의에 대한 자세한 내용은.

### Runtime 기능

[Workers 런타임 기능](/workers/runtime-apis/)Pages 기능에 설정 가능[Node.js API의 하위 세트와 호환](/workers/runtime-apis/nodejs)그리고 설정할 수있는 능력[호환성 날짜 또는 호환성 깃발](/workers/configuration/compatibility-dates/).

이 구성을 설정하여 인수를 전달합니다.[Wrangler](/workers/wrangler/commands/#dev-1)명령 또는 대시보드에서 설정하여. Pages QX호환성 플래그XQX1448XQXQ QX대시보드를 놓기 위하여:

1. 로그인[Cloudflare 대시보드](https://dash.cloudflare.com)계정 선택
2. 제품정보**Workers & Pages**Pages 프로젝트 선택
3. 제품정보**계정 설정** > **제품정보** > **호환성 깃발**.
4. 생산 및 미리보기 호환성 플래그를 필요에 따라 구성하십시오.

게다가, 다른 Cloudflare 제품 같이 사용[모델 번호: D1](/d1/)(serverless DB) 및[R2](/r2/)Pages 프로젝트 내에서 설정[관련 제품](/pages/functions/bindings/).

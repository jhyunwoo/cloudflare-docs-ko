Pages에 대한 업로드 소스 맵에 대한 지원은 이제 오픈 베타에서 사용할 수 있습니다. 최소 필요한 Wrangler 버전: 3.60.0.

:::

## 소스 맵

소스 맵을 활성화하려면`--upload-source-maps`본문 바로가기[`wrangler pages deploy`](/workers/wrangler/commands/#deploy-1)또는 Pages 신청의 옆에 추가하십시오[Wrangler 구성 파일](/pages/functions/wrangler-configuration/)Pages 건축 환경을 사용하는 경우에:

<WranglerConfig>
  ```jsonc
  {
  	"upload_source_maps": true
  }
  ```
</WranglerConfig>

업로드 소스 맵이 활성화되면 Wrangler는 자동으로 생성 및 업로드 소스 맵 파일을 실행할 수 있습니다.[`wrangler pages deploy`](/workers/wrangler/commands/#deploy-1).

## 스택 추적

응용 프로그램이 uncaught 예외를 던질 때, 우리는 소스 맵을 꺼내 응용 프로그램의 원래 소스 코드의 줄에 예외의 스택 추적을 맵으로 사용합니다.

스트리밍 할 때 스택 추적을 볼 수 있습니다.[실시간 로그](/pages/functions/debugging-and-logging/).

:::참조

소스 맵은 Pages Function invocation가 완료된 후 재평가됩니다. 애플리케이션의 CPU 활용 또는 성능에 영향을 미치지 않는 비동기 공정입니다. 소스 맵은 실행 시간에 응용 프로그램에 액세스 할 수 없습니다, 만약 당신이`console.log()`이름 \*[회사 소개](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error/stack), 당신은 deobfuscated 더미 추적을 얻을 수 없습니다.

:::

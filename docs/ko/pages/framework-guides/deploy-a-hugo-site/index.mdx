## Hugo 설치

Hugo CLI를 설치하여 운영 체제의 특정 지침을 사용합니다.

<Tabs>
  <TabItem label="맥 OS">
    패키지 관리자를 사용하는 경우[홈 양조장](https://brew.sh), 실행`brew install`Hugo를 설치하려면 터미널에서 명령:

    ```sh
    brew install hugo
    ```
  </TabItem>

  <TabItem label="윈도우">
    패키지 관리자를 사용하는 경우[스낵 바](https://chocolatey.org/), 실행`choco install`Hugo를 설치하려면 터미널에서 명령:

    ```sh
    choco install hugo --confirm
    ```

    패키지 관리자를 사용하는 경우[사이트맵](https://scoop.sh/), 실행`scoop install`Hugo를 설치하려면 터미널에서 명령:

    ```sh
    scoop install hugo
    ```
  </TabItem>

  <TabItem label="리눅스">
    Linux 배포의 패키지 관리자는 Hugo를 포함 할 수 있습니다. 이 경우, Hugo를 직접 배포 패키지 관리자를 사용하여 설치 - 예를 들어, 우분투에서, 다음 명령을 실행:

    ```sh
    sudo apt-get install hugo
    ```

    패키지 관리자가 Hugo를 포함하지 않는 경우 또는 직접 릴리스를 다운로드하고 싶습니다.[**제품 설명**](/pages/framework-guides/deploy-a-hugo-site/#manual-installation)이름 \*

Hugo GitHub 저장소에는 다양한 운영 체제를 위한 Hugo 명령줄 도구의 사전 제작 버전이 포함되어 있습니다.[공지사항](https://github.com/gohugoio/hugo/releases).

이 릴리스를 설치하는 데 더 많은 지침을 들어, 참조[Hugo 문서](https://gohugo.io/getting-started/installing/).

## 새 프로젝트 만들기

Hugo 설치, 참조[Hugo의 빠른 시작](https://gohugo.io/getting-started/quick-start/)프로젝트를 만들거나 새로운 프로젝트를 만들려면`hugo new`터미널에서 명령:

```sh
hugo new site my-hugo-site
```

Hugo 사이트가 테마를 사용하여 statically HTML 사이트를 구축하고 느낄 수 있습니다. 다양한 테마가 있습니다.[다운로드](https://themes.gohugo.io)— 지금, 사용[Ananke 테마](https://themes.gohugo.io/themes/gohugo-theme-ananke/)터미널에서 다음 명령을 실행하여:

```sh
cd my-hugo-site
git init
git submodule add https://github.com/theNewDynamic/gohugo-theme-ananke.git themes/ananke
echo "theme = 'ananke'" >> hugo.toml
```

## 게시물 만들기

Hugo 사이트 몇 가지 초기 콘텐츠를 제공하는 새로운 게시물을 만듭니다. 시작하기`hugo new`새 게시물을 생성하려면 터미널에서 명령:

```sh
hugo new content posts/hello-world.md
```

내부의`hello-world.md`, 당신의 포스트를 창조하는 몇몇 처음 내용을 추가하십시오. 제거하기`draft`게시물을 게시 할 준비가되면 게시물의 frontmatter에 라인. 자주 묻는 질문`draft: true`설정은 Hugo의 빌드 프로세스에 의해 건너 뛸 것입니다.

## Cloudflare Pages

<Render file="deploy-to-pages-steps-no-preset" product="pages" />

<PagesBuildPreset framework="hugo" />

한국어`public`Hugo 사이트에 대한 기본 빌드 디렉토리이며이 설정은 구성 할 수 있습니다.[`publishDir`설치하기](https://gohugo.io/configuration/all/#publishdir).

:::note\[기본 URL 구성]

Hugo는 구성 할 수 있습니다.`baseURL`당신의 신청의. 이것은 당신이 활용할 수 있습니다`absURL`완전한 canonical URL을 건설하는 데 도움이. Pages로 이것을 하기 위하여, 당신은 제공해야 합니다`-b`또는`--baseURL`플래그와`CF_PAGES_URL`환경변수`hugo`명령을 빌드합니다.

최종 빌드 명령은 다음과 같이 보일 수 있습니다:

```sh
hugo -b $CF_PAGES_URL
```

:::

배포 설정 완료 후, 선택**저장 및 배포**. 당신은 Cloudflare Pages 설치를 참조하십시오`hugo`당신의 프로젝트 의존성 및 사이트 구축하기 전에.

:::참조

CloudflareQXPages에 첫 번째 사이트를 배포하는 완벽한 가이드를 위해, 참조[자주 묻는 질문](/pages/get-started/).

:::

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`·
당신이 당신의 후고 사이트에 새로운 코드를 투입 때마다, Cloudflare Pages는 자동으로 당신의 프로젝트를 재건하고 그것을 배치합니다. 당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에, 그래서 당신은 생산에 배치하기 전에 사이트로 변경 사항을 볼 수 있습니다.

## 특정 또는 새로운 Hugo 버전 사용

이용하기[Hugo의 특정 또는 새로운 버전](https://github.com/gohugoio/hugo/releases), 창조`HUGO_VERSION`Pages 프로젝트의 환경 변수 >**계정 설정** > **환경 변수**. 지정하려는 Hugo 버전으로 값을 설정 (see the value)[자주 묻는 질문](https://gohugo.io/getting-started/quick-start/#prerequisites)최소 권장 버전).

예를 들어,`HUGO_VERSION`: `0.128.0`.

:::참조

이용 계획[관련 기사](/pages/configuration/preview-deployments/), 당신은 또한 환경 변수를 추가 확인**다운로드**환경.

:::

이 가이드에서 새로운 Nuxt 응용 프로그램을 만들고 Cloudflare QXPages를 사용하여 배포합니다.

## 새 프로젝트 만들기`create-cloudflare`클립 (C3)

더 보기[`create-cloudflare`클립 (C3)](/pages/get-started/c3/)Cloudflare Pages를 위한 당신의 Nuxt 위치를 구성할 것입니다. 터미널에서 다음 명령을 실행하여 새로운 Nuxt 사이트를 만듭니다.

<PackageManagers type="create" pkg="cloudflare@latest" args="my-nuxt-app --framework=nuxt --platform=pages" />

C3는 당신에게 일련의 설정 질문을하고 새로운 프로젝트를 만들 것입니다[`nuxi`(공식 Nuxt CLI)](https://github.com/nuxt/cli). C3는 또한 필요에 따라 접합기를 설치할 것입니다[Wrangler 클립](/workers/wrangler/install-and-update/#check-your-wrangler-version).

프로젝트를 작성한 후, C3는 새로운 것을 생성할 것입니다.`my-nuxt-app`기본 Nuxt 템플릿을 사용하여 디렉토리는 QXQX0625XQ Pages와 완벽하게 호환됩니다.

새로운 프로젝트를 만들 때 C3는 응용 프로그램의 초기 버전을 배포하는 옵션을 제공합니다[연락처](/pages/how-to/use-direct-upload-with-continuous-integration/). 프로젝트 디렉토리에 다음 명령을 실행하여 언제든지 응용 프로그램을 redeploy 할 수 있습니다.

```sh
npm run deploy
```

:::note\[Git 통합]

C3를 통해 생성 된 초기 배포는 다음과 같습니다.[연락처](/pages/get-started/direct-upload/). Pages를 통해 배포 설정 Git 통합, 참조[Git 통합](#git-integration)아래에 단면도.

:::

## Nuxt 응용 프로그램에서 바인딩 사용

·[관련 제품](/pages/functions/bindings/)Cloudflare 개발자 제품과 상호 작용할 수 있는 애플리케이션을 허용합니다.[모델 번호: KV](/kv/), [모델 번호: Durable Objects](/durable-objects/), [모델 번호: R2](/r2/)·[모델 번호: D1](/d1/).

프로젝트에서 바인딩을 사용하려면 먼저 로컬 및 원격 개발을 위해 바인딩을 설정해야합니다.

### 로컬 개발을 위한 바인딩 설정

C3를 통해 생성 된 프로젝트는 다음과 같습니다.`nitro-cloudflare-dev`·`nitro`개발 중에 바인딩 작업을 단순화하는 모듈:

```typescript
export default defineNuxtConfig({
	modules: ["nitro-cloudflare-dev"],
});
```

이 모듈은[`getPlatformProxy`helper 기능](/workers/wrangler/api#getplatformproxy). `getPlatformProxy`프로젝트의 Wrangler 구성 파일에 정의된 모든 바인딩을 자동으로 감지하고 로컬 개발에서 그 바인딩을 에뮬레이트합니다. 이름 \*[Wrangler 연동 정보](/workers/wrangler/configuration/#bindings)바인딩을 구성하는 방법에 대한 자세한 내용은[Wrangler 구성 파일](/workers/wrangler/configuration/).

:::참조

Wrangler 구성은 현지 개발을 위해 주로 사용됩니다. 정의된 바인딩은 원격으로 사용할 수 없습니다.[먼 바인딩](/workers/development-testing/#remote-bindings).

:::

### 배포된 애플리케이션에 대한 바인딩 설정

배포 된 응용 프로그램에 바인딩에 액세스하려면 필요할 것입니다.[당신의 바인딩을 구성](/pages/functions/bindings/)Cloudflare 대시보드에서.

### TypeScript 프로젝트에 바인딩 추가

적절한 유형 지원을 얻으려면 새로운 것을 만들 필요가 있습니다.`env.d.ts`프로젝트의 루트에 파일 및 선언[관련 제품](/pages/functions/bindings/). 당신이 생성한 Cloudflare 런타임 유형이 있는 것을 확인합니다[`wrangler types`](/pages/functions/typescript/).

다음은 추가의 예입니다.`KVNamespace`연결:

```ts null {9}
declare module "h3" {
	interface H3EventContext {
		cf: CfProperties;
		cloudflare: {
			request: Request;
			env: {
				MY_KV: KVNamespace;
			};
			context: ExecutionContext;
		};
	}
}
```

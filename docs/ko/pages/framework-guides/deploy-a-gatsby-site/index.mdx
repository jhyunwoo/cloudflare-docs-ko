[인기 있는](https://www.gatsbyjs.com/)웹 사이트 및 응용 프로그램을 만들기위한 오픈 소스 React 프레임 워크입니다. 이 가이드에서 새로운 Gatsby 응용 프로그램을 만들고 Cloudflare Pages를 사용하여 배포합니다. 당신은 사용할 것이다`gatsby`새로운 Gatsby 사이트를 만들려면 CLI.

## Gatsby 설치

설치하기`gatsby`터미널에서 다음 명령을 실행하여 CLI:

```sh
npm install -g gatsby-cli
```

## 새 프로젝트 만들기

Gatsby 설치를 통해 새로운 프로젝트를 만들 수 있습니다.`gatsby new`·`new`명령은 기존 템플릿을 사용하여 GitHub URL을 허용합니다. 예를 들어, 사용`gatsby-starter-lumen`터미널에서 다음 명령을 실행하여 템플릿. 더 많은 것을 찾을 수 있습니다[Gatsby의 스타터 섹션](https://www.gatsbyjs.com/starters/?v=2):

```sh
npx gatsby new my-gatsby-site https://github.com/alxshelepenok/gatsby-starter-lumen
```

## Cloudflare Pages

사이트를 구성하면 첫 번째 배포를 시작할 수 있습니다. 당신은 Cloudflare Pages 설치를 참조하십시오`gatsby`, 당신의 프로젝트 의존성 및 사이트를 구축하기 전에, 배포하기 전에.

:::참조

Cloudflare PagesXQ에 첫 번째 사이트를 배포하는 완벽한 가이드를 위해, 참조[자주 묻는 질문](/pages/get-started/).

:::

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`·
언제 당신은 당신의 Gatsby 사이트에 새로운 코드를 커밋, Cloudflare PagesXQ는 자동으로 프로젝트를 재구성하고 배포합니다. 당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에, 그래서 당신은 생산에 배치하기 전에 사이트로 변경 사항을 볼 수 있습니다.

## 동적인 노선

자주 묻는 질문[동적인 노선](https://www.gatsbyjs.com/docs/reference/functions/routing/#dynamic-routing)당신의 Gatsby 프로젝트에서, 설정[프록시 리디렉션](/pages/configuration/redirects/#proxying)이 루트에 대한 효과.

동적 경로가 있는 경우`/users/[id]`, 다음 예제를 참조하여 프록시 리디렉션을 생성:

```
/users/* /users/:id 200
```

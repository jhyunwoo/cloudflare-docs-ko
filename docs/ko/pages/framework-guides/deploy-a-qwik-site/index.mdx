[프로젝트](https://github.com/builderio/qwik)오픈 소스, DOM-centric, resumable 웹 응용 프레임 워크는 최고의 가능한 시간에 초점을 맞추고 대화 형으로 설계되었습니다.[관련 상품](https://qwik.builder.io/docs/concepts/resumable/)HTML과 서버 측 렌더링[고급스러운 게으른-loading](https://qwik.builder.io/docs/concepts/progressive/#lazy-loading)코드의.

이 가이드에서, 당신은 새로운 Qwik 응용 프로그램을 만들 것입니다[Qwik 시티](https://qwik.builder.io/qwikcity/overview/)(Qwik의 메타 프레임 워크) 및 Cloudflare Pages를 사용하여 배포합니다.

## 새로운 프로젝트 만들기

사용 방법[`create-cloudflare`](https://www.npmjs.com/package/create-cloudflare)CLI (C3)는 새로운 프로젝트를 만듭니다. C3는 새로운 프로젝트 디렉토리를 만들 것이며 Qwik의 공식 설정 도구를 시작하며 즉시 배포 할 수있는 옵션을 제공합니다.

이용안내`create-cloudflare`새로운 Qwik 프로젝트를 만들려면 다음 명령을 실행하십시오.

<PackageManagers type="create" pkg="cloudflare@latest" args="my-qwik-app --framework=qwik --platform=pages" />

`create-cloudflare`추가 의존도를 설치합니다.[Wrangler 클립](/workers/wrangler/install-and-update/#check-your-wrangler-version)그리고 어떤 필요한 어댑터, 당신은 설정 질문을.

일부로`cloudflare-pages`어댑터 설치, a`functions/[[path]].ts`파일이 생성됩니다. 더 보기`[[path]]`filename은 이 파일이 들어오는 URL에 요청을 처리한다는 것을 나타냅니다. 더 알아보기[경로 세그먼트](/pages/functions/routing/#dynamic-routes)더 알아보기.

서버 옵션을 선택한 후, 프로젝트에 디렉토리를 변경하고 다음 명령을 실행하여 프로젝트를 렌더링하십시오.

```sh
npm start
```

## Qwik 응용 프로그램에서 바인딩 사용

·[관련 제품](/pages/functions/bindings/)Cloudflare 개발자 제품과 상호 작용할 수 있는 애플리케이션을 허용합니다.[모델 번호: KV](/kv/concepts/how-kv-works/), [튼튼한 목표](/durable-objects/), [모델 번호: R2](/r2/)·[모델 번호: D1](https://blog.cloudflare.com/introducing-d1/).

QwikCity에서 server-side 코드를 추가하십시오.[비밀번호](https://qwik.builder.io/qwikcity/route-loader/)·[기타](https://qwik.builder.io/qwikcity/action/). 그 후에 당신의 신청을 위한 접근 바인딩 세트`platform`프레임워크에 의해 제공된 객체.

뒤에 오는 부호 구획은 QwikCity에 있는 KV namespace에 접근의 예를 보여줍니다.

```typescript null {4,5}
//· ...

export const useGetServerTime = routeLoader$(({ platform }) => {
  //유형 `KVNamespace`는 `wrangler types`XQ를 달리기에 의해 생성된 런타임 유형에서 옵니다
  const { MY_KV } = (platform.env as { MY_KV: KVNamespace }));

  return {
    //.....
  }
});
```

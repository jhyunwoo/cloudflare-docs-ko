[한국어](https://www.11ty.dev/)간단한 정적 사이트 생성기입니다. 이 가이드에서 새로운 Eleventy 사이트를 만들고 Cloudflare Pages를 사용하여 배포합니다. 당신은 사용할 것이다`eleventy`새로운 Eleventy 사이트를 만들려면 CLI.

## Eleventy 설치

설치하기`eleventy`터미널에서 다음 명령을 실행하여 CLI:

```sh
npm install -g @11ty/eleventy
```

## 새로운 프로젝트 만들기

많이 있다[스타트업](https://www.11ty.dev/docs/starter/)Eleventy 웹 사이트에서 사용할 수 있습니다. 예를 들어, 사용`eleventy-base-blog`터미널에서 다음 명령을 실행하여 프로젝트:

```sh
git clone https://github.com/11ty/eleventy-base-blog.git my-blog-name
cd my-blog-name
npm install
```

## GitHub 저장소 만들기

새로운 GitHub 저장소 만들기[최근 업데이트](https://repo.new). 새 저장소를 생성한 후, 다음 명령을 터미널에서 실행하여 GitHub에 로컬 응용 프로그램을 준비하고 밀어:

```sh
git remote set-url origin https://github.com/yourgithubusername/githubrepo
git branch -M main
git push -u origin main
```

모든 시간 당신은 당신의 Eleventy 사이트에 새로운 코드를 커밋, Cloudflare PagesXQ는 자동으로 프로젝트를 재구성하고 배포합니다. 당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에, 그래서 당신은 생산에 배치하기 전에 사이트로 변경 사항을 볼 수 있습니다.

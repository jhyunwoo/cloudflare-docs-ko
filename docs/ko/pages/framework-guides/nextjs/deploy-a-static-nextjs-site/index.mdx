[모델 번호: Next.js](https://nextjs.org)웹 사이트 및 응용 프로그램을 만들기위한 오픈 소스 React 프레임 워크입니다. 이 가이드에서, 당신은 새로운 Next.js 응용 프로그램을 만들고 Cloudflare QXPages를 사용하여 그것을 배치합니다.

이 가이드는 정적 사이트 Next.js 프로젝트를 배포하는 방법을 안내합니다.[정적 수출](https://nextjs.org/docs/app/building-your-application/deploying/static-exports).

## Next.js 프로젝트 선택

이미 배포하려는 Next.js 프로젝트가 있다면, 그것이 무엇인지 확인하십시오.[정적 수출에 대한 구성](https://nextjs.org/docs/app/building-your-application/deploying/static-exports), 디렉토리로 변경, 다음 단계로 진행. 그렇지 않으면, 사용`create-next-app`새로운 Next.js 프로젝트를 만들려면.

```sh
npx create-next-app --example with-static-export my-app
```

프로젝트 만들기 후, 새로운`my-app`디렉토리는 공식을 사용하여 생성됩니다.[`with-static-export`](https://github.com/vercel/next.js/tree/canary/examples/with-static-export)템플릿으로 예. 이 디렉토리를 계속 변경합니다.

```sh
cd my-app
```

### GitHub 저장소 만들기

새로운 GitHub 저장소 만들기[최근 업데이트](https://repo.new). 새 저장소를 생성한 후, 다음 명령을 터미널에서 실행하여 GitHub에 로컬 응용 프로그램을 준비하고 밀어:

```sh
git remote add origin https://github.com/<GH_USERNAME>/<REPOSITORY_NAME>.git
git branch -M main
git push -u origin main
```

## 사이트 맵

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`.

Next.js 사이트, Cloudflare PagesXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQXQ 당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에, 그래서 당신은 생산에 배치하기 전에 사이트로 변경 사항을 볼 수 있습니다.

Cloudflare PagesXQ에 첫 번째 사이트를 배포하는 완벽한 가이드를 위해, 참조[자주 묻는 질문](/pages/get-started/).

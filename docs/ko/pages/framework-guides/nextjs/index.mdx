[Next.js](https://nextjs.org)웹 사이트 및 응용 프로그램을 만들기위한 오픈 소스 React 프레임 워크입니다.

전체 스택 서버 사이드 렌더링 Next.js 응용 프로그램을 배포하려면[Next.js Workers 가이드](/workers/framework-guides/web-apps/nextjs).

대신 PagesXQ를 사용하여 정적 Next.js 사이트를 배포하려면[정체되는 Next.js Pages 가이드](/pages/framework-guides/nextjs/deploy-a-static-nextjs-site).

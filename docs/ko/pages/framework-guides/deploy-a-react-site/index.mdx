[모델 번호: React](https://reactjs.org/)Facebook의 오픈 소스 팀에 의해 구축 된 민감하고 강력한 프런트 엔드 응용 프로그램을 구축하기위한 인기있는 프레임 워크입니다.

이 가이드에서, 당신은 새로운 React 응용 프로그램을 만들고 Cloudflare QXPages를 사용하여 그것을 배치 할 것입니다.

## 새 프로젝트 설정

사용 방법[`create-cloudflare`](https://www.npmjs.com/package/create-cloudflare)CLI (C3)는 새로운 프로젝트를 설정합니다. C3는 새로운 프로젝트 디렉토리를 만들고, React의 공식 설정 도구를 시작하며 즉시 배포 할 수있는 옵션을 제공합니다.

이용안내`create-cloudflare`새로운 React 프로젝트를 만들려면 다음 명령을 실행하십시오.

<PackageManagers type="create" pkg="cloudflare@latest" args="my-react-app --framework=react --platform=pages" />

`create-cloudflare`의존성을 설치합니다.[모델 번호: Wrangler](/workers/wrangler/install-and-update/#check-your-wrangler-version)CLI 및 Cloudflare QXPages 어댑터 및 설정 질문.

Application의 디렉토리로 이동:

```sh
cd my-react-app
```

여기에서 응용 프로그램을 실행할 수 있습니다:

```sh
npm run dev
```

### Cloudflare 대시보드를 통해 배포

1. Cloudflare 대시보드에서**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />
2. 제품정보**회사연혁** > **사이트맵** > **기존 Git 저장소 가져 오기**.
3. 만든 새로운 GitHub 저장소를 선택하고,**빌드 및 배포 설정**단면도는, 뒤에 오는 정보를 제공합니다:

<div>
  <PagesBuildPreset framework="react" />
</div>

사이트를 구성하면 첫 번째 배포를 시작할 수 있습니다. 당신은 Cloudflare PagesXQ 설치를 참조하십시오`react`, 당신의 프로젝트 의존성 및 사이트를 구축하기 전에, 배포하기 전에.

:::참조

CloudflareQXPages에 첫 번째 사이트를 배포하는 완벽한 가이드를 위해, 참조[자주 묻는 질문](/pages/get-started/).

:::

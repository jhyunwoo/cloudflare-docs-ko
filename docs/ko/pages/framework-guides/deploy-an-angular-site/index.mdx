[이름 \*](https://angular.io/)건축 민감하고 강력한 정면 신청을 위한 믿을 수 있는 대중적인 기구입니다.

이 가이드에서 새로운 모난 응용 프로그램을 만들고 Cloudflare Pages를 사용하여 배포합니다.

## 새 프로젝트 만들기`create-cloudflare`클립 (C3)

사용 방법[`create-cloudflare`](https://www.npmjs.com/package/create-cloudflare)CLI (C3)는 새로운 프로젝트를 설정합니다. C3는 새로운 프로젝트 디렉토리를 만들고 Angular의 공식 설정 도구를 시작하며 즉시 배포 할 수있는 옵션을 제공합니다.

이용안내`create-cloudflare`새로운 Angular 프로젝트를 만들려면 다음 명령을 실행하십시오.

<PackageManagers type="create" pkg="cloudflare@latest" args="my-angular-app --framework=angular --platform=pages" />

`create-cloudflare`의존성을 설치합니다.[모델 번호: Wrangler](/workers/wrangler/install-and-update/#check-your-wrangler-version)CLI 및 Cloudflare QXPages 어댑터 및 설정 질문.

:::note\[Git 통합]

C3를 통해 생성 된 초기 배포는 다음과 같습니다.[연락처](/pages/get-started/direct-upload/). Pages를 통해 배포 설정 Git 통합, 참조[Git 통합](#git-integration)아래에 단면도.

:::

첫 번째 배포 파이프라인을 검토하십시오. Pages는 모든 의존성을 설치하고 프로젝트를 지정합니다. Cloudflare Pages는 자동적으로 당신의 프로젝트를 재건하고 각 새로운 강요된 투입에 그것을 배치할 것입니다.

[기타 제품](https://preactjs.com)현대 웹 응용 프로그램을 구축하기위한 인기있는 오픈 소스 프레임 워크입니다. Preact는 또한 동일한 API와 성분 모형을 공유하기 때문에 ReactXQ에 경량 대안으로 사용될 수 있습니다.

이 가이드에서 새로운 사전 응용 프로그램을 만들고 Cloudflare Pages를 사용하여 배포합니다.
이용안내[`create-preact`](https://github.com/preactjs/create-preact), 경량 프로젝트 비계 공구는 초에 있는 새로운 정확한 app를 설치하기 위하여.

## 새 프로젝트 설정

새로운 프로젝트 만들기[`npm init`](https://docs.npmjs.com/cli/v6/commands/npm-init)터미널에서 명령은 제목을 부여합니다.

```sh
npm init preact
cd your-project-name
```

:::참조

초기화 도중, 당신은 받아들일 수 있습니다`Prerender app (SSG)?`자주 묻는 질문`create-preact`static HTML 페이지를 생성하는 응용 프로그램을 비계, 자산과 함께, 생산 빌드. 이 옵션은 Pages에 적합합니다.

:::

## Cloudflare Pages

<Render file="deploy-to-pages-steps-no-preset" product="pages" />

<div>
  | 구성 옵션 | 제품정보            |
  | ----- | --------------- |

선택적으로, 당신은 주문을 받아서 만들 수 있습니다**프로젝트 이름**이름 \* GitHub 저장소의 이름에 기본적으로, 하지만 일치할 필요가 없습니다. 더 보기**프로젝트 이름**값은 할당됩니다.`*.pages.dev`하위 도메인.

설정 완료 후, 선택**저장 및 배포**.

첫 번째 배포 파이프라인을 볼 수 있습니다. Pages는 모든 의존성을 설치하고 프로젝트를 지정합니다.

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`.

Cloudflare Pages는 자동적으로 당신의 프로젝트를 재건하고 각 새로운 강요된 투입에 그것을 배치할 것입니다.

또한 액세스 할 수 있습니다.[관련 기사](/pages/configuration/preview-deployments/)풀 요청에 대한 빌드 및 배포 프로세스를 반복하는 ,. 이 작업을 통해 실제 URL로 변경할 수 있습니다.

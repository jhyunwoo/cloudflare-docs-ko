[브뤼헤](https://brunch.io/)빠른 개발을위한 간단한 설명 구성과 원활한 증가 컴파일과 빠른 프런트 엔드 웹 애플리케이션 빌드 도구입니다.

## Brunch 설치

시작하려면 Brunch를 설치하십시오.

```sh
npm install -g brunch
```

## Brunch 프로젝트 만들기

Brunch는 커뮤니티의 라이브러리를 유지[스켈레톤](https://brunch.io/skeletons)당신의 프로젝트를 위한 보일러판을 제안하기 위하여. Brunch의 추천`es6`skeleton 와 함께`brunch new`명령:

```sh
brunch new proj -s es6
```

## Cloudflare Pages로 배포

<Render file="deploy-to-pages-steps-no-preset" product="pages" />

<PagesBuildPreset framework="brunch" />

CloudflareQXPages에 첫 번째 사이트를 배포하는 완벽한 가이드를 위해, 참조[자주 묻는 질문](/pages/get-started/).

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`.

브런치 사이트, Cloudflare PagesXQ에 대한 새로운 코드를 자동 재구성하고 배포합니다. 당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에 따라 생산에 배포하기 전에 사이트의 변경 사항을 미리 볼 수 있습니다.

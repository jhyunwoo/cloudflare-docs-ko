## 새로운 프로젝트를 설정

이용안내`create-cloudflare`새로운 Astro 프로젝트를 만들려면 다음 명령을 실행하십시오.

<PackageManagers type="create" pkg="cloudflare@latest" args="my-astro-app --framework=astro --platform=pages" />

Astro는 요구할 것입니다:

1. 당신이 설정하고 싶은 어떤 프로젝트 유형. 답변은이 튜토리얼의 나머지에 영향을 미치지 않습니다. 당신의 프로젝트에 이상적인 대답을 선택하십시오.

2. Git 저장소를 초기화하려는 경우. 선택하기`No`이 가이드를 따르십시오.[Git 지침](/pages/framework-guides/deploy-an-astro-site/#create-a-github-repository)아래. 자주 묻는 질문`Yes`, Git 지시의 밑에 정확하게 따르지 마십시오 그러나 당신의 필요에 그(것)들을 조정하십시오.

`create-cloudflare`그러면 의존성을 설치합니다.[모델 번호: Wrangler](/workers/wrangler/install-and-update/#check-your-wrangler-version)CLI와`@astrojs/cloudflare`어댑터 및 설정 질문.

### 현지 시간

Local runtime 서포트는`platformProxy`옵션 :

```js null {6}
import { defineConfig } from "astro/config";
import cloudflare from "@astrojs/cloudflare";

export default defineConfig({
	adapter: cloudflare({
		platformProxy: {
			enabled: true,
		},
	}),
});
```

## Astro 신청에 있는 바인딩을 사용하십시오

·[관련 제품](/pages/functions/bindings/)Cloudflare 개발자 제품과 상호 작용할 수 있는 응용 프로그램을 허용합니다.[KV](/kv/concepts/how-kv-works/), [튼튼한 목표](/durable-objects/), [모델 번호: R2](/r2/)·[모델 번호: D1](https://blog.cloudflare.com/introducing-d1/).

Astro 구성 요소 및 API 경로에서 바인딩을 사용하여`context.locals`이름 \*[Astro 기타 제품](https://docs.astro.build/en/guides/middleware/)다른 분야에서 Cloudflare 런타임에 액세스하려면 CloudflareQ의 환경과 연속적으로 응용 프로그램에 대한 바인딩이 포함되어 있습니다.

TypeScript로 QXQXQXQ 네임스페이스에 액세스하는 방법의 다음 예제를 참조하십시오.

먼저 Cloudflare 런타임과 KVXQ 유형을 업데이트해야 합니다.`env.d.ts`. 당신이 생성한 Cloudflare 런타임 유형이 있는지 확인합니다[`wrangler types`](/pages/functions/typescript/).

```typescript
/// <참고 자료 type="astro/client" />

type ENV = {
	//`MY_KV`를 KV 네임스페이스로 교체
	MY_KV: KVNamespace;
};

//기본 런타임 설정(advanced mode)을 사용합니다.
type Runtime = import("@astrojs/cloudflare").Runtime<ENV>;
declare namespace App {
	interface Locals extends Runtime {}
}
```

다음 방법으로 API 엔드포인트에서 KV에 액세스할 수 있습니다.

```typescript null {3,4,5}
import type { APIContext } from "astro";

export async function get({ locals }: APIContext) {
	const { MY_KV } = locals.runtime.env;

	return {
		//· ...
	};
}
```

엔드포인트 외에도 Astro 구성품에서 직접 바인딩을 사용할 수 있습니다.

```typescript null {2,3}
---
const myKV = Astro.locals.runtime.env.MY_KV;
const value = await myKV.get("key");
---
<div>{value}</div>
```

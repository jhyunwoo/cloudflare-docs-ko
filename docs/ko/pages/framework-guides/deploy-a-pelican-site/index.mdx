## Pelican 프로젝트 만들기

시작하려면 Pelican 프로젝트 디렉토리를 만듭니다.`cd`새 디렉토리로 실행:

```sh
python3 -m pip install pelican
```

다음 실행:

```sh
pip freeze > requirements.txt
```

프로젝트의 디렉토리 만들기`content`:

```sh
mkdir content
```

빌드 명령에서 설정할 디렉토리 이름입니다.

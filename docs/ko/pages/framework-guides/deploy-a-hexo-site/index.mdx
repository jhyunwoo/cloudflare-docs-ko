[사이트맵](https://hexo.io/)Node.js에 의해 구동되는 정적 웹 사이트를 생성하기위한 도구입니다. Hexo의 장점은 속도, 단순성 및 유연성을 포함하며, Node.js를 통해 정적 웹 페이지로 Markdown 파일을 렌더링 할 수 있습니다.

이 가이드에서 새로운 Hexo 응용 프로그램을 만들고 Cloudflare Pages를 사용하여 배포합니다. 당신은 사용할 것이다`hexo`새로운 Hexo 사이트를 만들려면 CLI.

## Hexo 설치

첫째, Hexo CLI를 설치`npm`또는`yarn`터미널에서 다음 명령 중 하나를 실행하여:

```sh
npm install hexo-cli -g
#또는
yarn global add hexo-cli
```

macOS 및 Linux에서 설치할 수 있습니다.[양조장](https://brew.sh/):

```sh
brew install hexo
```

## 새로운 프로젝트 만들기

Hexo CLI를 설치하여 새로운 프로젝트를 만듭니다.`hexo init`터미널에서 명령:

```sh
hexo init my-hexo-site
cd my-hexo-site
```

Hexo 사이트 사용 테마는 statically 내장 HTML 사이트의 외관을 사용자 정의합니다. Hexo는 기본적으로 설치된 테마를 가지고 있습니다.[Hexo의 테마 페이지](https://hexo.io/themes/).

## 게시물 만들기

Hexo 사이트에 몇 가지 초기 콘텐츠를 제공하는 새로운 게시물을 만듭니다. 시작하기`hexo new`새 게시물을 생성하려면 터미널에서 명령:

```sh
hexo new "hello hexo"
```

내부의`hello-hexo.md`, Markdown을 사용하여 기사의 내용을 작성합니다. 문서의 태그, 범주 또는 기타 변수를 사용자 정의 할 수 있습니다. 더 알아보기[정면 Matter 단면도](https://hexo.io/docs/front-matter)이름 \*[Hexo 문서](https://hexo.io/docs/)더 많은 정보.

:::참조

CloudflareQXPages에 처음 사이트를 배치하는 완벽한 가이드를 위해, 참조하십시오[자주 묻는 질문](/pages/get-started/).

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`·
당신이 당신의 Hexo 위치에 새로운 코드를, Cloudflare PagesXQ는 자동적으로 당신의 프로젝트를 재건하고 그것을 배치할 것입니다. 당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에, 그래서 당신은 생산에 배치하기 전에 사이트로 변경 사항을 볼 수 있습니다.

## 특정 Node.js 버전 사용

일부 Hexo 테마 또는 플러그인 다른 Node.js 버전에 대한 추가 요구 사항이 있습니다. Hexo를 위한 특정한 Node.js 버전을 사용하기 위하여:

1. Pages 프로젝트로 이동하십시오.
2. 오시는 길**계정 설정** > **환경 변수**.
3. 환경 변수 설정`NODE_VERSION`그리고 필요한 Node.js 버전의 값 (예를 들면,`14.3`).

[사이트맵](https://www.solidjs.com/)JSX에 기반을 둔 현대 개발자 경험으로 수행 응용 프로그램을 생성하는 오픈 소스 웹 응용 프로그램입니다.

이 가이드에서, 당신은 통해 구현 된 새로운 솔리드 응용 프로그램을 만들 것입니다[다운로드](https://start.solidjs.com/getting-started/what-is-solidstart)(Solid의 메타 프레임 워크) 및 Cloudflare Pages를 사용하여 배포합니다.

## 새 프로젝트 만들기

사용 방법[`create-cloudflare`](https://www.npmjs.com/package/create-cloudflare)CLI (C3)는 새로운 프로젝트를 설정합니다. C3는 새로운 프로젝트 디렉토리를 만들 것이며 Solid의 공식 설정 도구를 시작하며 즉시 배포할 옵션을 제공합니다.

이용안내`create-cloudflare`새로운 솔리드 프로젝트를 만들려면 다음 명령을 실행하십시오.

<PackageManagers type="create" pkg="cloudflare@latest" args="my-solid-app --framework=solid" />

스타터를 선택할 수 있습니다. 사용 가능한 옵션 중 하나를 선택하십시오. Server Side Rendering을 활성화하려면 다음을 요청합니다. 이름 \*`yes`. 마지막으로, 당신은 당신이 TypeScript를 사용하고 싶은 경우에, 선택될 것입니다`yes`또는`no`.

`create-cloudflare`그러면 의존성을 설치합니다.[모델 번호: Wrangler](/workers/wrangler/install-and-update/#check-your-wrangler-version)CLI 및 SolidStart Cloudflare Pages 어댑터를 선택하고 설정 질문을하십시오.

프로젝트 의존도를 설치 한 후 응용 프로그램을 시작하십시오.

```sh
npm run dev
```

## SolidStart Cloudflare 구성

<Render file="c3-adapter" product="pages" />

SolidStart를 구성하려면 Cloudflare 페이지에 배포할 수 있으므로 다음과 같은 구성 파일을 업데이트하십시오.

```diff
import { defineConfig } from "@solidjs/start/config";

export default defineConfig({
+  server: {
+    preset: "cloudflare-pages",

+    rollupConfig: {
+      external: ["node:async_hooks"]
+    }
+  }
});
```

### Cloudflare 대시보드를 통해 배포

<Render file="deploy-to-pages-steps-no-preset" product="pages" />

<div>
  | 구성 옵션 | 제품정보            |
  | ----- | --------------- |
  | 생산 지점 | `main`          |
  | 명령 실행 | `npm run build` |
  | 연락처   | `dist`          |
</div>

사이트를 구성하면 첫 번째 배포를 시작할 수 있습니다. 당신은 Cloudflare Pages 설치를 참조하십시오`npm`, 당신의 프로젝트 의존성, 그것을 배치하기 전에 사이트를 구축.

:::참조

Cloudflare QXPagesXQ에 첫 번째 사이트를 배포하는 완벽한 가이드를 위해, 참조[자주 묻는 질문](/pages/get-started/).

:::

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`·
당신이 당신의 단단한 저장소에 새로운 코드를 투입할 때마다, Cloudflare Pages는 당신의 프로젝트를 자동적으로 재건하고 그것을 배치할 것입니다. 당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에 따라 사이트로 변경 사항을 미리 볼 수 있습니다.

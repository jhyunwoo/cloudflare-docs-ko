[스핑크](https://www.sphinx-doc.org/)Python 문서의 출판을 쉽게 만들 수있는 도구입니다. 그것은 그것의 단순성 및 사용의 용이함을 위해 잘 알려져 있습니다.

이 가이드에서 새로운 Sphinx 프로젝트를 만들고 QXQX0742XQ QXQXQXPagesXQ를 사용하여 배포합니다.

## 자주 묻는 질문

- 모델 번호: Python 3 - Sphinx는 Python에 근거를 둡니다, 그러므로 당신은 Python가 설치되어야 합니다

- [뚱 베어](https://pypi.org/project/pip/)- Python 패키지 설치를 위한 PyPA 권장 도구

- [파이프](https://pipenv.pypa.io/en/latest/)- 자동적으로 당신의 프로젝트를 위한 virtualenv를 창조하고 관리합니다

:::참조

이미 Python 3.7 버전을 실행하면 Python 버전 3.7이 가이드를 시작하기 전에 컴퓨터에 설치됩니다. 모델 번호: Python 3.7는 QXQX0748XQ QXPages에 의해 지원하는 최신 버전입니다.

:::

Python 3.7의 최신 버전은 3.7.11입니다:

[Python 3.7.11년](https://www.python.org/downloads/release/python-3711/)

### Pipenv 설치

이미 버전 3.7을 설치하기 전에 설치된 Python의 이전 버전을 가지고 있다면, 다른 글로벌 패키지는 Pipenv를 설치하기 위해 다음 단계를 방해 할 수 있습니다, 또는 글로벌 패키지에 따라 다른 Python 프로젝트.

[파이프](https://pipenv.pypa.io/en/latest/)Python-기반 패키지 관리자로 가상 환경 관리가 간편합니다. 이 가이드는 Sphinx 사이트 배포를 완료하기 위해 Pipenv의 사전 경험 또는 지식이 필요하지 않습니다. Cloudflare Pages는 기본적으로 Pipenv의 사용을 지원하고, 설치된 최신 버전이 있습니다.

Pipenv를 설치하는 가장 빠른 방법은 명령을 실행하여 다음과 같습니다.

```sh
pip install --user pipenv
```

이 명령은 사용자 레벨 디렉토리에 Pipenv를 설치하고 터미널을 통해 액세스 할 수 있습니다. 다음 명령을 실행하고 예상 출력을 검토하여 이것을 확인할 수 있습니다.

```sh
pipenv --version
```

```sh output
pipenv, version 2021.5.29
```

### Sphinx 프로젝트 디렉토리 만들기

터미널에서 다음 명령을 실행하여 새 디렉토리를 만들고 탐색하십시오.

```sh
mkdir my-wonderful-new-sphinx-project
cd my-wonderful-new-sphinx-project
```

### Python 3.7를 가진 Pipenv

Pipenv는 Python의 버전을 가상 환경과 연계하도록 지정할 수 있습니다. 이 가이드의 목적을 위해 Sphinx 프로젝트에 대한 가상 환경은 Python 3.7을 사용해야합니다.

다음 명령을 사용하십시오:

```sh
pipenv --python 3.7
```

### Sphinx 설치

Sphinx를 설치하기 전에 프로젝트를 원하는 디렉토리를 만듭니다.

터미널에서 Sphinx를 설치하려면 다음 명령을 실행하십시오.

```sh
pipenv install sphinx
```

## 새로운 프로젝트 만들기

Sphinx를 설치하면 Quickstart 명령을 실행하여 템플릿 프로젝트를 만들 수 있습니다. 이 명령은 이전 단계에서 생성한 Pipenv 환경에서만 작동합니다. 그 환경을 입력하려면 터미널에서 다음 명령을 실행하십시오.

```sh
pipenv shell
```

```sh output
Launching subshell in virtual environment...
ubuntu@sphinx-demo:~/my-wonderful-new-sphinx-project$  . /home/ubuntu/.local/share/virtualenvs/my-wonderful-new-sphinx-project-Y2HfWoOr/bin/activate
```

이제 다음 명령을 실행:

```sh
sphinx-quickstart
```

당신은 질문의 수로를 선물할 것입니다, 뒤에 그들에게 대답하십시오:

```sh output
Separate source and build directories (y/n) [n]: Y
Project name: <Your project name>
Author name(s): <You Author Name>
Project release []: <You can accept default here or provide a version>
Project language [en]: <You can accept en here or provide a regional language code>
```

이것은 활성 디렉토리에 4 개의 새로운 파일을 만들 것입니다.`source/conf.py`, `index.rst`, `Makefile`·`make.bat`:

```bash
my-wonderful-new-sphinx-project
|--Pipfile
|--Pipfile.lock
|--source
|----_static
|----_templates
|----conf.py
|----index.rst
|--Makefile
|--make.bat
```

이제 QXQX0765XQ QXPages에 사이트를 배포하는 데 필요한 모든 것을 가지고 있습니다. Sphinx 문서를 만드는 방법을 배우려면 공식을 참조하십시오.[Sphinx 문서](https://www.sphinx-doc.org/en/master/usage/quickstart.html).

## GitHub 저장소 만들기

Pipenv Shell 세션 내에서는 별도의 단말 창에서 SSH 키 기반 인증이 작동한다는 것을 확인합니다.

```sh
eval "$(ssh-agent)"
ssh-add -T ~/.ssh/id_rsa.pub
ssh -T git@github.com
```

```sh output

The authenticity of host 'github.com (140.82.113.4)' can't be established.
RSA key fingerprint is SHA256:nThbg6kXUpJWGl7E1IGOCspRomTxdCARLviKw6E5SY8.
Are you sure you want to continue connecting (yes/no/[fingerprint])? yes
Warning: Permanently added 'github.com,140.82.113.4' (RSA) to the list of known hosts.
Hi yourgithubusername! You've successfully authenticated, but GitHub does not provide shell access.
```

새로운 GitHub 저장소 만들기[최근 업데이트](https://repo.new). 저장소가 설정된 후, 터미널의 다음 명령을 실행하여 GitHub에 응용 프로그램을 밀어:

```sh
git init
git config user.name "Your Name"
git config user.email "username@domain.com"
git remote add origin git@github.com:yourgithubusername/githubrepo.git
git add .
git commit -m "Initial commit"
git branch -M main
git push -u origin main
```

사이트를 구성하면 첫 번째 배포를 시작할 수 있습니다. 당신은 Cloudflare Pages 설치를 참조하십시오`Pipenv`, 당신의 프로젝트 의존성, 및 사이트를 구축, 배포하기 전에.

:::참조

CloudflareQXPagesXQ에 첫 번째 사이트를 배포하는 완벽한 가이드를 위해, 참조[자주 묻는 질문](/pages/get-started/).

:::

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`. 매번 Sphinx 사이트에 새 코드를 커밋합니다. Cloudflare PagesXQ는 프로젝트를 자동으로 재구성하고 배포합니다.

당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에, 그래서 당신은 생산에 배치하기 전에 사이트로 변경 사항을 볼 수 있습니다.

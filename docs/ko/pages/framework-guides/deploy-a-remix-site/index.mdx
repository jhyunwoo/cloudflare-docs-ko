[리믹스](https://remix.run/)웹 표준에 초점을 맞춘 프레임 워크입니다. 프레임 워크는 저자 및 그 성공자 React에 의해 새로운 프로젝트에 더 이상 권장되지 않습니다 라우터는 대신 사용해야합니다.

새로운 React를 시작하려면 라우터 프로젝트는 참조하시기 바랍니다[React 라우터 Workers 가이드](/workers/framework-guides/web-apps/react-router).

그리고 기존 Remix 응용 프로그램이 React 라우터에 마이그레이션을 고려하면[Remix 업그레이드 문서](https://reactrouter.com/upgrading/remix).

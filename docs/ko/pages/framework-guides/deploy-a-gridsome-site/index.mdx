[회사 소개](https://gridsome.org)Vue.js는 기본적으로 빠른 정적 생성 웹 사이트 및 응용 프로그램을 구축하기위한 Jamstack 프레임 워크를 구동한다. 이 가이드에서 새로운 Gridsome 프로젝트를 만들고 Cloudflare Pages를 사용하여 배포합니다. 당신은 사용할 것이다[`@gridsome/cli`](https://github.com/gridsome/gridsome/tree/master/packages/cli), 새로운 Gridsome 프로젝트를 만들기 위한 명령줄 도구.

## Gridsome 설치

설치하기`@gridsome/cli`터미널에서 다음 명령을 실행하여:

```sh
npm install --global @gridsome/cli
```

## 새로운 프로젝트를 설정

Gridsome 설치, 실행하여 새로운 프로젝트를 설정`gridsome create`·`create`명령은 만든 프로젝트의 디렉토리를 정의하는 이름을 수락하고 선택적 스타터 키트 이름. 더 많은 스타터를 검토 할 수 있습니다.[Gridsome 시동기 단면도](https://gridsome.org/docs/starters/).

```sh
npx gridsome create my-gridsome-website
```

## Cloudflare Pages

Pages에 사이트를 배포하려면:

사이트를 구성하면 첫 번째 배포를 시작할 수 있습니다. 당신은 Cloudflare PagesXQ 설치를 참조하십시오`vuepress`, 당신의 프로젝트 의존성 및 사이트를 구축하기 전에, 배포하기 전에.

:::참조

Cloudflare PagesXQ에 첫 번째 사이트를 배포하는 완벽한 가이드를 위해, 참조[자주 묻는 질문](/pages/get-started/).

:::

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`. 매번 당신은 당신의 Gridsome 프로젝트, Cloudflare Pages에 새로운 코드를 투입하고 그것을 배치할 것입니다. 당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에 따라 사이트가 생산에 배포하기 전에 어떻게 변경 사항을 미리 볼 수 있습니다.

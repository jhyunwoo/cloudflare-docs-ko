[사이트맵](https://www.mkdocs.org/)팀은 문서 제품, 내부 지식베이스 및 API를 문서화 할 수있는 현대 문서 플랫폼입니다.

## MkDocs 설치

MkDocs는 Python 및 Python 패키지 관리자, pip의 최근 버전이 시스템에 설치되어야합니다. pip를 설치하려면, 참조[MkDocs 설치 가이드](https://www.mkdocs.org/user-guide/installation/). pip 설치, 실행:

```sh
pip install mkdocs
```

## MkDocs 프로젝트 만들기

사용 방법`mkdocs new`새로운 응용 프로그램을 만들려면 명령:

```sh
mkdocs new <PROJECT_NAME>
```

다음 것`cd`프로젝트로, MkDocs 및 의존성을 가져와 그들에 넣어`requirements.txt`파일 :

```sh
pip freeze > requirements.txt
```

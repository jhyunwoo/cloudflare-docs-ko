[모델 번호: Vue](https://vuejs.org/)사용자 인터페이스를 구축하기위한 진보적인 JavaScript 프레임 워크입니다. Vue의 핵심 원리는 incremental 채택입니다: 이것은 당신의 기존하는 부호로 측 옆에 사는 VueXQ 신청을 건축하게 쉬운 합니다.

이 가이드에서, 당신은 새로운 Vue 응용 프로그램을 만들고 Cloudflare QXPages를 사용하여 그것을 배치 할 것입니다. 이용안내`vue-cli`새로운 Vue 응용 프로그램을 생성하기위한 배터리 포함 도구.

## 새 프로젝트 설정

사용 방법[`create-cloudflare`](https://www.npmjs.com/package/create-cloudflare)CLI (C3)는 새로운 프로젝트를 설정합니다. C3는 새로운 프로젝트 디렉토리를 만들고, Vue의 공식 설정 도구를 시작하며 즉시 배포 할 수있는 옵션을 제공합니다.

이용안내`create-cloudflare`새로운 Vue 프로젝트를 만들려면 다음 명령을 실행하십시오.

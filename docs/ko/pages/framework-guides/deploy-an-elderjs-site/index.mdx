[다운로드](https://elderguide.com/tech/elderjs/)정적 사이트 구축을위한 SEO 중심 프레임 워크입니다.[SvelteKit](/pages/framework-guides/deploy-a-svelte-kit-site/).

이 가이드에서 새로운 Elder.js 응용 프로그램을 만들고 Cloudflare QXPages를 사용하여 배포합니다.

## 새 프로젝트 설정

새 프로젝트 만들기[`npx degit Elderjs/template`](https://docs.npmjs.com/cli/v6/commands/npm-init), 프로젝트 이름을 주는:

```sh
npx degit Elderjs/template elderjs-app
cd elderjs-app
```

Elder.js 템플릿에는 정적 사이트를 구축하는 방법을 보여주는 페이지와 예제가 포함되어 있지만 프로젝트를 생성함으로써 이미 Cloudflare Pages에 배포 할 준비가되어 있습니다.

선택적으로, 당신은 주문을 받아서 만들 수 있습니다**프로젝트 이름**이름 \* GitHub 저장소의 이름에 기본적으로, 하지만 일치할 필요가 없습니다. 더 보기**프로젝트 이름**값은 할당됩니다.`*.pages.dev`하위 도메인.

### 설정 완료

설정 완료 후, 클릭**저장 및 배포**버튼.

첫 번째 배포 파이프라인을 볼 수 있습니다. Pages는 모든 의존성을 설치하고 프로젝트를 지정합니다.

Cloudflare Pages는 자동적으로 당신의 프로젝트를 재건하고 각 새로운 강요된 투입에 그것을 배치할 것입니다.

또한 액세스 할 수 있습니다.[관련 기사](/pages/configuration/preview-deployments/)풀 요청에 대한 빌드 및 배포 프로세스를 반복하는 ,. 이 작업을 통해 실제 URL로 변경할 수 있습니다.

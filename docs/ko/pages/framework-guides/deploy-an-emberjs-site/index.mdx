[다운로드](https://emberjs.com)현대 웹 응용 프로그램을 구축하기위한 생산적 인 전투 테스트 JavaScript 프레임 워크입니다. 모든 기기에서 작업하는 풍부한 UI를 구축해야 할 모든 것을 포함합니다.

## Ember 설치

시작하려면 Ember를 설치하십시오.

```sh
npm install -g ember-cli
```

## Ember 프로젝트 만들기

사용 방법`ember new`새로운 응용 프로그램을 만들려면 명령:

```sh
npx ember new ember-quickstart --lang en
```

응용 프로그램이 생성 된 후, 프로젝트에 디렉토리를 변경하고 다음 명령을 실행하여 프로젝트를 실행하십시오.

```sh
cd ember-quickstart
npm start
```

## Cloudflare Pages로 배포

<PagesBuildPreset framework="ember-js" />

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`.

매번 당신은 당신의 Ember 사이트에 새로운 코드를 커밋합니다, Cloudflare PagesXQ는 자동으로 프로젝트를 재구성하고 배포합니다. 당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에 따라 사이트로 변경 사항을 미리 볼 수 있습니다.

Cloudflare QXPages에 첫 번째 사이트를 배포하는 완벽한 가이드를 위해, 참조[자주 묻는 질문](/pages/get-started/).

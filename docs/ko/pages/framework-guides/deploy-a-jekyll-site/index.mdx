[주 메뉴](https://jekyllrb.com/)웹 사이트를 만들기위한 오픈 소스 프레임 워크, Liquid Templates와 Markdown 주위에 기반. 이 가이드에서 새로운 Jekyll 응용 프로그램을 만들고 Cloudflare PagesXQ를 사용하여 배포합니다. 당신은 사용`jekyll`새로운 Jekyll 사이트를 만들려면 CLI.

:::참조

GitHub Pages의 기존 Jekyll 사이트가 있는 경우, 참조[Jekyll 마이그레이션 가이드](/pages/migrations/migrating-jekyll-from-github-pages/).

:::

## Jekyll 설치

Jekyll은 Ruby로 작성되어 Ruby를 사용하여 Ruby 설치가 필요한 것을 의미합니다.`rbenv`, Jekyll 설치.

컴퓨터에 Ruby를 설치하려면[`rbenv`설치 설명서](https://github.com/rbenv/rbenv#installation)루비의 최근 버전을 선택하여 실행`rbenv`터미널에서 명령. Ruby version을 설치하면 Pages 배포를 구성할 수 있습니다.

```sh
rbenv install <RUBY_VERSION> #예를 들어, 3.1.3
```

Ruby를 설치하면 설치할 수 있습니다.`jekyll`루비 보석:

```sh
gem install jekyll
```

## 새로운 프로젝트 만들기

Jekyll 설치로 새로운 프로젝트를 실행할 수 있습니다.`jekyll new`당신의 맨끝에서:

```sh
jekyll new my-jekyll-site
```

기본 설정`index.html`새로 만든 폴더에서 사이트 콘텐츠를 제공:

```html
<!doctype html>
<html>
	<head>
		<meta charset="utf-8" />
		<title>Hello from Cloudflare Pages</title>
	</head>
	<body>
		<h1>Hello from Cloudflare Pages</h1>
	</body>
</html>
```

선택적으로 새로운 Jekyll 사이트로 테마를 사용할 수 있습니다. 멋진 스타일링 기본으로 시작하려면. 예를 들어,[`minimal-mistakes`](https://github.com/mmistakes/minimal-mistakes)테마는["시작`jekyll new`"](https://mmistakes.github.io/minimal-mistakes/docs/quick-start-guide/#starting-from-jekyll-new)새 사이트에 테마를 추가하는 데 도움이되는 섹션.

이름 \*[환경 변수](/pages/configuration/build-image/)로컬로 사용하는 Ruby 버전과 일치합니다. 설정하기`RUBY_VERSION`당신의 미리보기 및 생산 배포 모두에. 아래,`3.1.3`예로 사용됩니다.

| 환경 변수          | 제품정보    |
| -------------- | ------- |
| `RUBY_VERSION` | `3.1.3` |

사이트를 구성하면 첫 번째 배포를 시작할 수 있습니다. 당신은 Cloudflare Pages 설치를 참조하십시오`jekyll`, 당신의 프로젝트 의존성, 그것을 배치하기 전에 사이트를 구축.

:::참조

CloudflareQXPagesXQ에 첫 번째 사이트를 배포하는 완벽한 가이드를 위해, 참조[자주 묻는 질문](/pages/get-started/).

:::

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`·
언제든지 Jekyll 사이트에 새로운 코드를 투입, Cloudflare Pages는 자동으로 프로젝트를 재구성하고 배포합니다. 당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에, 그래서 당신은 생산에 배치하기 전에 사이트로 변경 사항을 볼 수 있습니다.

[호노](https://honojs.dev/)Cloudflare QXPages 및 WorkersXQ, Deno 및 Bun를 위한 작은, 간단한 및 매우 빠른 웹 기구입니다. Hono의 창조에 대해 자세히 알아보기[인터뷰보기](#creator-interview)창조자로서[유스케 와다](https://yusu.ke/).

이 가이드에서 새로운 Hono 응용 프로그램을 만들고 Cloudflare Pages를 사용하여 배포합니다.

## 새 프로젝트 만들기

사용 방법[`create-cloudflare`](https://www.npmjs.com/package/create-cloudflare)CLI (C3)는 새로운 프로젝트를 만듭니다. C3는 새로운 프로젝트 디렉토리를 만들 것입니다, Hono의 공식 설정 도구를 시작, 즉시 배포 할 수있는 옵션을 제공합니다.

이용안내`create-cloudflare`새로운 Hono 프로젝트를 만들려면 다음 명령을 실행하십시오.

<PackageManagers type="create" pkg="cloudflare@latest" args="my-hono-app --framework=hono --platform=pages" />

새로운 Hono 프로젝트에서, 당신은 찾을 수 있습니다`public/static`정적 파일 디렉토리 및 a`src/index.ts`서버 측 코드를 위한 엔트리포인트입니다.

## 로컬 dev에서 실행

로컬로 앱 개발:

<PackageManagers type="run" args={"dev"} />

### Cloudflare 대시보드를 통해 배포

<Render file="deploy-to-pages-steps-no-preset" product="pages" />

<div>
  | 구성 옵션 | 제품정보            |

  | 생산 지점 | `main`          |
  | 명령 실행 | `npm run build` |

사이트를 구성하면 첫 번째 배포를 시작할 수 있습니다. 당신은 Cloudflare PagesXQ 설치를 참조하십시오`my-hono-app`, 당신의 프로젝트 의존성, 그것을 배치하기 전에 사이트를 구축.

:::참조

CloudflareQXPagesXQ에 첫 번째 사이트를 배포하는 완벽한 가이드를 위해, 참조[자주 묻는 질문](/pages/get-started/).

:::

사이트를 배포 한 후, 프로젝트에 대한 독특한 하위 도메인을 받게됩니다.`*.pages.dev`·
항상 새로운 코드를 Hono 사이트, Cloudflare PagesXQ에 투입하고 프로젝트를 자동으로 재구성하고 배포합니다. 당신은 또한 접근을 얻을 것이다[관련 기사](/pages/configuration/preview-deployments/)새로운 풀 요청에, 그래서 당신은 생산에 배치하기 전에 사이트로 변경 사항을 볼 수 있습니다.

[카테고리](https://docusaurus.io)정적 사이트 발전기입니다. React의 전체 전력을 활용하여 빠른 클라이언트 측 내비게이션과 단일 페이지 애플리케이션을 구축하여 사이트 대화형을 만듭니다. 그것은 out-of-the-box 문서 기능을 제공하지만 개인 웹 사이트, 제품 사이트, 블로그 또는 마케팅 방문 페이지와 같은 어떤 종류의 사이트를 만들 수 있습니다.

## 새로운 프로젝트를 설정

사용 방법[`create-cloudflare`](https://www.npmjs.com/package/create-cloudflare)CLI (C3) 프로젝트 설정. C3는 새로운 프로젝트 디렉토리를 만들 것입니다, Docusaurus의 공식 설정 도구 시작, 즉시 배포 할 수있는 옵션을 제공합니다.

이용안내`create-cloudflare`새로운 Docusaurus 프로젝트를 만들려면 다음 명령을 실행하십시오.

<PackageManagers type="create" pkg="cloudflare@latest" args="my-docusaurus-app --framework=docusaurus --platform=pages" />

`create-cloudflare`추가 의존도를 설치합니다.[모델 번호: Wrangler](/workers/wrangler/install-and-update/#check-your-wrangler-version)CLI 및 필요한 어댑터 및 설정 질문을하십시오.

## 빌드 명령 및 빌드 디렉토리 찾기

Netlify Dashboard에서 배포하려는 프로젝트를 찾습니다. GitHub 저장소에서 배포하도록 구성해야 합니다.

## 리디렉션 및 헤더

사이트가 포함 된 경우`_redirects`게시 디렉토리의 파일, Cloudflare Pages 및 리디렉션에서 동일한 파일을 성공적으로 실행할 수 있습니다. 리디렉션이 있다면`netlify.toml`파일, 당신은 그들에게 추가해야합니다`_redirects`폴더. Cloudflare Pages는 현재 한정된 제안합니다[고급 리디렉션 지원](/pages/configuration/redirects/). 2000 정적 및 / 또는 100 동적 리디렉션 규칙을 가지고있는 경우, 사용하기 좋습니다[대량 Redirects](/rules/url-forwarding/bulk-redirects/create-dashboard/).

헤더 파일도 이동할 수 있습니다.`_headers`게시 디렉토리에 폴더. 사용자 정의 헤더가 정의 된 것을 주목하는 것이 중요합니다.`_headers`파일은 현재 기능의 응답에 적용되지 않습니다, 심지어 기능 경로가 URL 패턴 일치. 더 알아보기[핸들 헤더, 헤더 참조](/pages/configuration/headers/).

:::참조

Redirects는 헤더 앞에 실행합니다. 두 파일에서 일치하는 규칙의 경우, 리디렉션은 선행합니다.

:::

## Serverless 기능

Netlify 기능 및 Pages Functions는 같은 filesystem 컨벤션을 사용하여 공유합니다.`functions`프로젝트의 기초에 디렉토리는 서버의 기능을 처리합니다. 그러나 구문과 함수가 배포되는 방법. Pages 함수는 Cloudflare WorkersXQ에서 실행되며 기본적으로 Cloudflare 글로벌 네트워크에서 작동하며, 배포에 대한 추가 코드 또는 구성이 필요하지 않습니다.

Cloudflare Pages 함수는 함수 경로 핸들러가 되기 전에 실행해야 하는 논리를 처리할 수 있는 미들웨어도 제공합니다.

### 기능 문법

Netlify 함수는 이벤트를 수락하는 async 이벤트 핸들러와 인자로 컨텍스트를 수출합니다. Pages 기능의 경우에는, 당신은 단 하나 수출해야 할 것입니다`onRequest`함수는`context`객체. 더 보기`context`object는 같은 요청에 대한 모든 정보를 포함합니다.`request`, `env`, `params`, 새로운 응답을 반환합니다. 더 알아보기[첫 번째 기능 작성](/pages/functions/get-started/)

Netlify 기능으로 Hello World:

```js
exports.handler = async function (event, context) {
	return {
		statusCode: 200,
		body: JSON.stringify({ message: "Hello World" }),
	};
};
```

Pages 기능:

```js
export async function onRequestPost(request) {
	return new Response(`Hello world`);
}
```

## 새로운 Pages 프로젝트 만들기

빌드 디렉토리와 빌드 명령을 발견하면 프로젝트가 QXQX2307XQ QXPagesXQ로 이동할 수 있습니다.

더 보기[자주 묻는 질문](/pages/get-started/)GitHub 프로젝트를 Cloudflare QXPagesXQ에 추가하는 방법을 안내합니다.

Pages에 대한 사용자 정의 도메인을 사용하려면 현재 Netlify 응용 프로그램으로 동일한 사용자 정의 도메인에 설정할 수 있습니다. Pages 프로젝트에 사용자 정의 도메인을 할당하려면, 참조[사용자 정의 도메인](/pages/configuration/custom-domains/).

## 오래된 응용 프로그램을 청소하고 도메인을 할당

Cloudflare 대시보드에서, 가십시오**DNS 기록**사이트 맵

<DashButton url="/?to=/:account/:zone/dns/records" />

Netlify에서 Cloudflare QXPages에 도메인에 대한 CNAME 레코드를 업데이트했습니다. 업데이트 된 DNS 레코드를 사용하면 Pages 응용 프로그램에 참여할 수 있습니다.

내 계정**DNS 보호**, 당신의 기록**이름 \***&#xB108;의 것`<SUBDOMAIN>.pages.dev`하위 도메인.

위의 단계를 완료하면 Netlify 프로젝트를 Cloudflare QXPagesXQ로 성공적으로 마이그레이션했습니다.

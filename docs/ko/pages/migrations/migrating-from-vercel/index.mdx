이 튜토리얼에서, 당신은 Cloudflare QXPages에 Vercel 응용 프로그램을 배포하는 방법을 배울 것입니다.

이미 Cloudflare PagesXQ에서 호스트하려는 Vercel에 배포 된 기존 프로젝트가 있어야 합니다. Vercel의 서버가 없는 기능과 같은 특징은 현재 Cloudflare QXPages에서 지원되지 않습니다.

## 빌드 명령을 찾아서 디렉토리를 빌드하십시오.

Cloudflare PagesXQ에 응용 프로그램을 이동하려면 빌드 명령과 빌드 디렉토리를 찾을 필요가 있습니다. Cloudflare Pages는 이 정보를 사용하여 응용 프로그램을 구축하고 배포합니다.

Vercel Dashboard에서 배포하려는 프로젝트를 찾습니다. GitHub 저장소에서 배포할 수 있습니다.

![Vercel Dashboard의 사이트를 선택](~/assets/images/pages/migrations/vercel-deploy-1.png)

사이트의 내부 대시보드, 선택**계정 설정**, 다음**주요사업**.

![사이트 설정 선택 대시보드](~/assets/images/pages/migrations/vercel-deploy-2.png)

자주 묻는 질문**빌드 및 개발 설정**패널, 이는**명령을 실행**·**출력 디렉토리**이름 \* 프레임 워크를 사용하는 경우, 이 값은 채워지지 않을 수 있지만 프레임 워크에서 사용하는 기본을 표시합니다. Cloudflare PagesXQ에 배포를 위해 이러한 저장하십시오. 아래 이미지에서,**명령을 실행**이름 \*`npm run build`, 그리고**출력 디렉토리**이름 \*`build`.

![빌드 명령 및 출력 디렉토리 필드 찾기](~/assets/images/pages/migrations/vercel-deploy-3.png)

## 새로운 Pages 프로젝트 만들기

빌드 디렉토리 및 빌드 명령을 발견 한 후, 프로젝트가 Cloudflare QXQXPagesXQ로 이동할 수 있습니다.

더 보기[자주 묻는 질문](/pages/get-started/)GitHub 프로젝트를 Cloudflare PagesXQ에 추가하는 방법을 안내합니다.

## 사용자 정의 도메인 추가

다음, 연결[사용자 정의 도메인](/pages/configuration/custom-domains/)Pages 프로젝트에. 이 도메인은 현재 Vercel 응용 프로그램을 배포 한 것과 동일해야합니다.

### 도메인 네임서버 변경

대부분의 경우에, 당신은 원할 것입니다[도메인을 Cloudflare에 추가](/dns/zone-setups/full-setup/setup/).

이것은 도메인 네임서버를 변경하지만 Pages 설정을 단순화하고 프로젝트를 위해 apex 도메인을 사용할 수 있습니다.`example.com`).

다른 접근 방식을 취하고 싶다면 더 읽어 보세요.[주문 영역](/pages/configuration/custom-domains/).

## Vercel 앱 삭제

사용자 정의 도메인이 설정되고 Cloudflare PagesXQ에 요청을 전송하면 Vercel 응용 프로그램을 안전하게 삭제할 수 있습니다.

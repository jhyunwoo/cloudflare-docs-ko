이 튜토리얼에서 Cloudflare PagesXQXQXQ에 기존의 Firebase 응용 프로그램을 마이그레이션하는 방법을 배울 것입니다. 당신은 이미 Cloudflare PagesXQ에 호스트하려는 Firebase에 배포 된 기존 프로젝트가 있어야합니다.

## 빌드 명령 및 빌드 디렉토리 찾기

Cloudflare Pages에 응용 프로그램을 이동하려면 빌드 명령과 빌드 디렉토리를 찾을 필요가 있습니다.

Cloudflare PagesQ 프로젝트를 배포하는 방법을 알려줍니다. 로컬 머신에서 수동으로 배포하는 경우`firebase`명령줄 도구,`firebase.json`구성 파일은 포함해야`public`빌드 디렉토리가되는 키:

```json title="firebase.json"
{
	"public": "public"
}
```

Firebase 호스팅은 빌드 명령을 요청하지 않습니다. 표준 JavaScript를 설정하면 아마도 사용할 것입니다.`npm build`또는 프레임 워크 또는 도구에 특정 명령을 사용하여 (예를 들어,`ng build`).

빌드 디렉토리를 발견하고 명령을 빌드 한 후 QXQX2265XQ QXQXQXPagesXQ로 프로젝트를 이동할 수 있습니다.

## 새로운 Pages 프로젝트 만들기

앞에 GitHub에 정적 사이트를 밀어넣지 않은 경우, 계속하기 전에 해야 합니다. 이것은 또한 당신에게 자동 배포와 같은 기능을 액세스 할 수 있습니다.[배포 미리보기](/pages/configuration/preview-deployments/).

방문해서 새로운 저장소를 만들 수 있습니다.[최근 업데이트](https://repo.new)GitHub까지 프로젝트를 밀어주는 지침을 따르십시오.

사용 방법[자주 묻는 질문](/pages/get-started/)Cloudflare Pages에 프로젝트를 추가하려면**빌드 명령**·**회사연혁**당신은 이전 저장.

## 오래된 응용 프로그램을 청소하고 도메인을 할당

응용 프로그램을 배포하면 Firebase 대시보드로 이동하고 오래된 Firebase 프로젝트를 제거합니다. 귀하의 도메인에 대한 Cloudflare DNS 설정에서 Firebase에서 Cloudflare QXPages에 도메인에 대한 CNAME 레코드를 업데이트해야합니다.

이 가이드를 완료하면 Firebase 프로젝트를 QXQX2274XQQ PagesXQXQXQXQ로 성공적으로 마이그레이션했습니다.

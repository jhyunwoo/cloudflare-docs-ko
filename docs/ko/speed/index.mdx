<Description>

웹사이트 또는 웹 애플리케이션의 성능을 개선하세요.
</Description>

<Plan type="all" />

Speed를 사용하면 웹사이트 성능을 평가하고, 웹사이트 성능 향상에 도움이 되는 Cloudflare 제품 추천을 받을 수 있습니다.

***

## 기능

<Feature header="Observatory" href="/speed/observatory/">

합성 데이터와 실제 사용자 데이터를 모두 사용해 테스트를 수행하고, 웹사이트 성능을 향상시킬 수 있는 잠재적인 지점을 파악할 수 있습니다.


</Feature>

<Feature header="설정" href="/speed/optimization/">

웹사이트 성능을 개선하기 위한 Cloudflare 제품과 설정 추천을 받아보세요.


</Feature>

<Feature header="집계 인터넷 측정" href="/speed/aim/">

인터넷 품질을 이해하여 인터넷 연결이 좋은 상황과 나쁜 상황을 파악하세요.


</Feature>

***

## 관련 제품

<RelatedProduct header="Cache rules" href="/cache/how-to/cache-rules/" product="cache">
HTTP 요청의 캐시 속성을 사용자 지정합니다.
</RelatedProduct>

<RelatedProduct header="Cloudflare Web Analytics" href="/web-analytics/" product="analytics">
사이트 방문자가 체감하는 웹페이지 성능을 이해하세요.
</RelatedProduct>

<RelatedProduct header="Cloudflare Image Resizing" href="/images/transform-images/" product="images">
Cloudflare 엣지 플랫폼에서 이미지를 변환하세요. 크기 조정, 품질 조정, WebP 또는 AVIF 형식 변환을 필요에 따라 수행할 수 있습니다.
</RelatedProduct>

<RelatedProduct header="Early Hints" href="/cache/advanced-configuration/early-hints/" product="cache">
"서버 처리 시간"을 활용해, 원본 서버가 전체 응답을 준비하는 동안 브라우저가 리소스 로드를 시작할 수 있도록 지시를 비동기적으로 전송하세요.
</RelatedProduct>

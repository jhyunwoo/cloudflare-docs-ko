RUM 비콘은 Cloudflare 고객이 [Web Analytics](/web-analytics/) 또는 [Observatory](/speed/observatory/)를 통해 RUM을 활성화할 때 실행되는 JavaScript 스니펫입니다. 이 스크립트는 사용자가 고객 사이트를 방문할 때 브라우저에서 실행되며, 페이지 로드 시간과 같은 성능 관련 데이터를 수집해 Cloudflare 시스템으로 전송하여 처리하는 것이 목적입니다. 이렇게 수집된 [데이터](/web-analytics/data-metrics/)는 이후 고객에게 제공되어 웹사이트 성능과 사용량에 대한 유용한 인사이트를 제공합니다.

RUM 비콘 스크립트는 두 가지 방법으로 웹페이지에 활성화할 수 있습니다.

- **원클릭 설정**: Web Analytics가 활성화된 [Cloudflare를 통해 프록시되는 사이트](/web-analytics/get-started/#sites-proxied-through-cloudflare)의 경우, HTML 응답이 Cloudflare 엣지 네트워크를 거쳐 브라우저로 전달되는 과정에서 자동 삽입 옵션을 켜는 것만으로 스니펫이 페이지에 _자동으로_ 삽입될 수 있습니다.

- **수동 설정**: 웹사이트는 페이지에 코드 스니펫을 삽입하여 스크립트를 _수동으로_ 추가할 수 있습니다. HTML에 스니펫을 수동으로 삽입하는 방법에 대한 자세한 내용은 [Cloudflare를 통해 프록시되지 않는 사이트 섹션](/web-analytics/get-started/#sites-not-proxied-through-cloudflare)을 참고하세요.

## 데이터 수집

브라우저에 다운로드된 후 RUM 비콘 스크립트는 브라우저에서 JavaScript로 실행됩니다. 브라우저 [API](https://developer.mozilla.org/en-US/docs/Web/API/Performance_API)에서 성능 데이터를 수집하여 Cloudflare로 전송해 처리합니다.

## 데이터 처리

RUM 데이터는 일반적으로 들어오는 요청이 라우팅되는 방식에 따라 가장 가까운 Cloudflare 데이터 센터에서 처리됩니다. 이는 [Anycast](https://www.cloudflare.com/en-gb/learning/cdn/glossary/anycast-network/)와 [Unimog](https://blog.cloudflare.com/unimog-cloudflares-edge-load-balancer/)를 포함한 여러 요인에 의해 결정됩니다. RUM 데이터는 위치 서비스를 사용하지 않으므로 원래 발생한 국가나 지역과 다른 곳에서 처리될 수 있습니다. RUM 서비스는 정상적인 HTTP 요청 처리 과정의 일부로 비콘에서 클라이언트/소스 IP 주소를 수신하지만, 가장 가까운 Cloudflare 데이터 센터에서 해당 IP 주소를 폐기하며 핵심 데이터베이스나 로그에 저장하지 않습니다.

## 개인정보 정보

RUM 비콘 스크립트는 브라우저에 데이터를 저장하지 않으며, [cookies](https://developer.mozilla.org/en-US/docs/Web/API/Document/cookie), [localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage), [sessionStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage), IP 주소, [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB)와 같은 저장소 데이터에도 접근하지 않습니다. 우리가 수집하는 데이터는 브라우저 성능 [API](https://developer.mozilla.org/en-US/docs/Web/API/Performance_API)의 성능 데이터입니다. 이 성능 데이터는 일시적이며 현재 보고 있는 웹페이지에만 관련됩니다. 사용자가 브라우저를 새로 고치면 이전 성능 데이터는 모두 사라지고 새로운 성능 데이터를 사용할 수 있게 됩니다. 이 데이터는 장치 어딘가에 저장되거나 다른 곳에서 읽히지 않으며, 메모리 내 데이터로만 존재합니다.

## EEA/EU 제외 RUM

고객은 RUM을 전역으로 활성화하거나, EEA/EU에 위치한 Cloudflare 데이터 센터에 연결하는 사용자를 제외하도록 제한할 수 있습니다. 후자를 선택하면 RUM 비콘은 다음 국가(ISO 코드)에 위치한 Cloudflare 데이터 센터에 연결하는 사용자에 대해 성능 데이터를 처리하지 않습니다: AT, BE, BG, HR, CY, CZ, DK, EE, FI, FR, DE, GR, HU, IS, IE, IT, LV, LI, LT, LU, MT, NL, NO, PL, PT, RO, SK, SI, ES, SE, CH, GB.

무료 고객은 EU 트래픽을 제외한 상태로 RUM이 자동 활성화되며, 원하면 비활성화할 수 있습니다. 다른 요금제 고객은 필요에 따라 RUM을 활성화할 수 있습니다.

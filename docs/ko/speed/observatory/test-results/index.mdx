테스트 결과 페이지는 여러 주요 업계 메트릭과 관련해 웹사이트가 어떤 성능을 보였는지 보여줍니다. 일부 메트릭은 합성 테스트와 실제 사용자 모니터링 모두에 대해 제공되며, 다른 메트릭은 합성 테스트에만 적용되거나 실제 사용자 모니터링에만 적용됩니다.

## 합성 테스트 및 실제 사용자 모니터링 메트릭

이 메트릭은 합성 테스트에 대해 제공되며 실제 사용자 데이터의 일부로도 수집됩니다.

| Metric                                                                  | Definition                                                                                                                            |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Time to First Byte ([TTFB](https://web.dev/ttfb/))                      | 리소스 요청부터 응답의 첫 번째 바이트가 도착하기 시작할 때까지의 시간을 측정합니다.                          |
| First Contentful Paint ([FCP](https://web.dev/first-contentful-paint/)) | 페이지 로딩이 시작된 시점부터 페이지 콘텐츠의 어느 부분이든 화면에 렌더링될 때까지의 시간을 측정합니다.                 |
| Largest Contentful Paint ([LCP](https://web.dev/lcp/))                  | 뷰포트 내에서 보이는 가장 큰 이미지 또는 텍스트 블록이 렌더링되는 시간을 보고합니다.                                            |
| Cumulative Layout Shift ([CLS](https://web.dev/cls/))                   | 페이지 전체 수명 동안 발생한 예기치 않은 레이아웃 변경에 대한 최대 레이아웃 이동 점수 묶음을 측정합니다. |

## 합성 테스트 메트릭

이 메트릭은 합성 테스트에서 생성됩니다.

| Metric                                            | Definition                                                                                                                                                                              |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Time to Interactive ([TTI](https://web.dev/tti/)) | 페이지 로딩 시작 시점부터 주요 하위 리소스가 로드되고 사용자 입력에 안정적으로 빠르게 반응할 수 있을 때까지의 시간을 측정합니다.                          |
| Total Blocking Time ([TBT](https://web.dev/tbt/)) | First Contentful Paint(FCP)와 Time to Interactive(TTI) 사이에서, 메인 스레드가 사용자 입력 응답을 막을 만큼 오래 차단된 전체 시간을 측정합니다. |
| [Speed index](https://web.dev/speed-index/)       | 페이지 로드 중 콘텐츠가 시각적으로 얼마나 빨리 표시되는지를 측정합니다.                                                                                                                    |

## 실제 사용자 모니터링 메트릭

이 메트릭은 페이지와의 실제 사용자 상호작용이 필요하므로 실제 사용자 데이터의 일부로 수집됩니다.

| Metric                                                  | Definition                                                                                                                                                                       |
| ------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Interaction to Next Paint ([INP](https://web.dev/inp/)) | 페이지에서 발생한 모든 클릭, 탭, 키보드 상호작용을 측정하여 페이지의 전반적인 반응성을 나타내는 것을 목표로 합니다.                                                       |

실제 사용자 모니터링 대시보드에서 찾을 수 있는 메트릭에 대한 자세한 내용은 [데이터 및 메트릭](/web-analytics/data-metrics/)을 참고하세요. [Core Web Vitals](/web-analytics/data-metrics/core-web-vitals/), 디버그 뷰, 수집되는 데이터에 대한 세부 정보도 확인할 수 있습니다.

## 네트워크 모니터링 메트릭

| Metric                                            | Definition                                                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Wait Time | 요청이 이루어진 후 서버가 응답의 첫 번째 바이트를 보내기 전까지 기다리는 시간을 측정합니다.                                           |
| Load Time | 네트워크 관점에서 웹페이지가 사용자의 브라우저에 완전히 로드되기까지 걸리는 총 시간을 측정합니다.                                                         |
| Time to First Byte ([TTFB](https://web.dev/articles/ttfb))  | 웹페이지 요청을 시작한 시점과 서버에서 첫 번째 바이트를 받는 시점 사이의 시간을 측정합니다. |
| Server Response Time | 사용자의 브라우저 요청에 대해 서버가 응답하는 데 걸리는 시간을 측정합니다.                                                           |
| Connect Time | 사용자의 브라우저와 웹 서버 사이에 연결을 설정하는 데 걸리는 시간을 측정합니다.                                                         | 
| TLS Time | 사용자의 브라우저와 웹 서버 사이에서 TLS/SSL 핸드셰이크를 완료하는 데 필요한 시간을 측정합니다.                                                  |

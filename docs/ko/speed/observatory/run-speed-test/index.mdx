## 합성 테스트 실행

1. Cloudflare 대시보드에서 **Synthetic Monitoring** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/speed/test" />

2. 테스트하려는 URL을 입력합니다. 이 URL은 테스트하려는 zone에 속해야 합니다.
3. 사용할 테스트 유형을 선택합니다. **Browser** 또는 **Network tests**를 선택할 수 있습니다.
4. 자동화된 브라우저가 사용할 **Region**을 선택합니다.
5. 요금제에 따라 테스트를 **한 번**, **매일**, 또는 **매주** 실행하도록 선택할 수 있습니다. 요금제별로 사용할 수 있는 테스트 빈도 정보는 [Quotas](/speed/observatory/run-speed-test/#quotas) 섹션을 참고하세요. 이러한 제한은 시간이 지나면서 변경될 수 있습니다.
6. 테스트가 끝나면 Lighthouse 점수를 확인할 수 있고, 실행된 테스트 목록에도 접근할 수 있습니다. 테스트 결과 페이지는 데스크톱 버전과 모바일 버전 모두에 대한 웹사이트 성능 세부 정보를 제공합니다. 자세한 내용은 [테스트 결과 이해하기](/speed/observatory/test-results/)를 참고하세요.

### 권장 사항

Observatory는 웹사이트 테스트 결과에 따라 **Recommendations** 탭을 보여줍니다. **Recommendations** 섹션은 Lighthouse 감사 결과를 기반으로 웹사이트를 개선할 수 있는 기회를 보여주고, 해당 메트릭 개선에 도움이 되는 Cloudflare 기능 또는 제품을 추천합니다. 또한 권장 기능이나 제품을 활성화했을 때 얻을 수 있는 예상 절감 효과도 보여줍니다.

### 추세 및 기록 보고서

Tested URLs 표의 마지막 열에서 점 세 개를 선택한 다음 **View history report**를 선택하면, 시간에 따른 웹사이트 성능 메트릭을 보여주는 **Trend** 표와 사이트에서 실행한 모든 테스트의 **History report**에 접근할 수 있습니다.

## 실제 사용자 모니터링(RUM) 활성화

테스트를 한 번 실행하면 테스트 결과 페이지에서 [RUM](/speed/observatory/#real-user-monitoring-rum) 데이터를 활성화할 수 있습니다.

1. **Observatory**로 이동하여 **Enable RUM**을 선택합니다. 전역으로 활성화하거나 EU를 제외한 모든 곳에서 활성화할 수 있습니다.
2. 사이트에서 RUM 데이터가 수집되기 시작하면 테스트 결과 페이지의 **Real user measurements**에 접근할 수 있습니다. 일반적으로 데이터가 들어오기 시작하는 데 5분 미만이 걸리지만, 실제로는 트래픽 상황에 따라 달라집니다.

실제 사용자 데이터가 제공하는 결과에 대한 자세한 내용은 [테스트 결과 이해하기](/speed/observatory/test-results/)를 참고하세요.

### 수집되는 정보

RUM은 Observatory가 사용하는 정보를 수집하기 위해 가벼운 JavaScript 비콘을 사용합니다. 사용량 메트릭을 수집하기 위해 쿠키나 `localStorage` 같은 클라이언트 측 상태를 사용하지 않습니다.

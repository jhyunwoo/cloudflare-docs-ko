Observatory는 합성 테스트와 브라우저의 실제 사용자 데이터를 사용해 웹사이트 성능을 평가합니다. 이러한 데이터 소스는 웹사이트 성능에 대해 서로 다른 유형의 인사이트를 제공하는 메트릭을 생성합니다. Cloudflare는 이후 Observatory의 분석 결과를 사용해, 현재 성능 문제에 가장 잘 맞는 도구로 최적화를 추천합니다.

## 합성 테스트

이름에서 알 수 있듯이 합성 테스트는 사용자가 웹사이트에 접속할 때 마주할 수 있는 조건을 서버로 시뮬레이션합니다. 이는 테스트를 실행할 때마다 같은 조건을 쉽게 재현할 수 있으므로 일관성이 있다는 장점이 있습니다. 또한 코드 변경이 웹사이트 전체 성능에 어떤 영향을 줄지 분석할 수 있고, 원하는 URL을 테스트할 수도 있습니다. 다만 합성 방식의 특성상 실제 사용자가 경험하는 다양한 조건의 폭과 다양성을 완전히 재현할 수는 없습니다.

Observatory는 두 가지 유형의 합성 테스트를 제공합니다.

### 브라우저 테스트

브라우저 테스트는 요청한 페이지를 헤드리스 브라우저에서 로드하고 Google Lighthouse를 실행합니다. 이를 통해 핵심 성능 메트릭을 보고하고, 개선을 위한 간단한 제안을 제공합니다.

### 네트워크 테스트

네트워크 테스트는 엔드포인트의 네트워크 및 백엔드 성능을 자세히 분석하는 데 초점을 둡니다. 수집되는 메트릭에 대한 자세한 내용은 [네트워크 모니터링 메트릭](/speed/observatory/test-results/#network-monitoring-metrics)을 참고하세요.

### 네트워크 비교 테스트

Observatory에서는 완료된 테스트 두 개를 선택해 네트워크 테스트를 비교할 수도 있습니다. 각 테스트 결과는 히스토그램으로 나란히 표시되므로, 두 테스트 전반의 데이터 분포를 쉽게 시각화하고 비교할 수 있습니다.

## 실제 사용자 모니터링(RUM)

반면 실제 사용자 모니터링(Real User Monitoring, RUM)은 웹사이트에 접속하는 실제 사용자로부터 실제 메트릭을 수집합니다. 이를 통해 사용자가 세계 각지, 서로 다른 네트워크 상태, ISP, 브라우저, 컴퓨터 하드웨어에서 사이트에 접속할 수 있기 때문에 합성 테스트로는 포착할 수 없는 정보를 얻을 수 있습니다. 다만 RUM 데이터는 사용자의 자체 웹사이트에만 적용됩니다. 또한 실제 사용자 데이터에는 합성 테스트에서 제공하지 않는 두 가지 사용자 상호작용 메트릭, 즉 [First Input Delay (FID)](https://web.dev/fid/)와 [Interaction to Next Paint (INP)](https://web.dev/inp/)가 포함됩니다.

무료 고객은 EU 트래픽을 제외한 상태로 RUM이 자동 활성화되며, 원할 경우 비활성화할 수 있습니다. 다른 요금제 고객은 필요에 따라 RUM을 활성화할 수 있습니다.

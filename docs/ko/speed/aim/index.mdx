Aggregated Internet Measurement(AIM)은 인터넷 품질을 이해하여 인터넷 연결이 좋은 상황과 나쁜 상황을 파악할 수 있도록 도와줍니다. 일반적인 인터넷 속도 테스트는 업로드와 다운로드 속도를 제공하지만, 이것만으로는 인터넷 품질을 항상 전체적으로 파악하기 어렵습니다.

AIM은 속도 테스트를 기반으로 점수를 부여하는 채점 기준을 사용하여, 스트리밍, 게이밍, 웹채팅/실시간 통신(RTC)에서 인터넷 품질이 어떻게 작동할지 이해할 수 있도록 도와줍니다.

## 채점 기준

AIM은 다음 메트릭을 분석하여 점수를 생성합니다.

* 지연 시간
* 패킷 손실
* 다운로드
* 업로드
* 부하 시 지연 시간
* 지터

테스트를 실행하고 각 메트릭에 점수를 부여한 후, 이 점수는 스트리밍, 게이밍, 웹채팅/RTC에 대한 네트워크 점수로 변환됩니다. 이 점수는 각 시나리오에서 인터넷 상태가 얼마나 좋은지를 나타냅니다.

가능한 네트워크 점수는 다음과 같습니다.

* 나쁨
* 미흡
* 보통
* 좋음
* 매우 좋음

## 네트워크 점수 개선하기

네트워크 점수를 개선하는 데 도움이 되는 몇 가지 방법이 있습니다.

* **유선 연결로 전환하세요.** 가능하다면 무선 대신 유선 연결을 사용해 전파 간섭과 신호 강도로 인한 성능 문제를 피하세요.
* **라우터에 더 가까이 이동하세요.** 유선 연결을 사용할 수 없다면 무선 라우터에 더 가까이 이동해 보세요. 라우터에서 멀어질수록 신호 강도는 떨어지며, 신호가 약할수록 연결 품질도 나빠집니다. 또한 사용자와 무선 라우터 사이에 있는 물체나 재질도 신호 강도에 부정적인 영향을 줄 수 있다는 점을 유념하세요.
* **라우터를 업그레이드하세요.** 더 똑똑한 큐잉을 처리할 수 있고 부하가 걸려도 버티는 하드웨어를 갖춘 라우터를 사용하고 있는지 확인하세요.
* **ISP에 문의하세요.** 유선 연결을 사용 중이거나 무선 라우터와의 연결 상태가 좋은데도 여전히 문제가 있다면 인터넷 연결 자체에 문제가 있을 수 있으므로 ISP에 문의해야 합니다.

:::caution[지원 중단 안내]
Mirage는 2025년 9월 15일에 지원이 중단되었으며 더 이상 사용할 수 없습니다.

대안으로 Cloudflare는 모든 기기에서 이미지 성능을 최적화하기 위해 [지연 로딩](/images/tutorials/optimize-mobile-viewing/)과 [반응형 이미지](/images/transform-images/make-responsive-images/)를 사용할 것을 권장합니다.
:::

## Mirage란 무엇이었나요?

Cloudflare Mirage는 대역폭 사용량을 줄이고 느린 모바일 연결 및 HTTP/1 환경에서 이미지 로딩을 가속화하는 모바일 이미지 최적화 기능이었습니다.

Mirage는 다음과 같은 방식으로 동작했습니다.

- 이미지를 하나의 파일로 묶인 저해상도 썸네일로 대체했습니다.
- 지연 로더로 동작하여, 더 높은 해상도의 이미지는 화면에 보일 때까지 로딩을 미뤘습니다.

## 왜 지원이 중단되었나요?

현대의 웹 표준과 브라우저 기능은 Mirage의 많은 기능을 기본적으로 지원하도록 발전했습니다.

- `loading="lazy"` HTML 속성을 사용하는 기본 지연 로딩
- `srcset`과 `<picture>` 요소를 사용하는 반응형 이미지
- 더 나은 성능을 제공하는 HTTP/2 및 HTTP/3
- 공격적인 최적화 필요성을 줄여 준 향상된 모바일 네트워크

## 마이그레이션 경로

Mirage 대신 다음을 사용하세요.

- **[Polish](/images/polish/)** - 모바일에만 국한되지 않고 모든 브라우저에서 이미지를 원활하게 최적화하며, 이미지를 전체 해상도로 유지합니다.
- **[Image Resizing](/images/transform-images/)** - `loading="lazy"` 및 `srcset` HTML 속성과 함께 사용하면 최신 반응형 이미지 전송을 제공합니다.
- **[지연 로딩 가이드](/images/tutorials/optimize-mobile-viewing/)** - 기본 지연 로딩 구현 방법을 알아보세요.
- **[반응형 이미지 가이드](/images/transform-images/make-responsive-images/)** - 다양한 기기에 적응하는 이미지를 만드는 방법을 알아보세요.

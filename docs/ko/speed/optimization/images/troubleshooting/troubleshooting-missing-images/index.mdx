title: 누락된 이미지 문제 해결

---

웹사이트에서 이미지가 누락된다면, 다른 Cloudflare 기능이 해당 이미지에 간섭하고 있을 수 있습니다.

문제를 해결하려면 다음을 수행하세요.

1. 다음 작업 중 하나를 수행합니다.

   * 누락된 이미지 파일 URL에 대해 [캐시 비우기](/cache/how-to/purge-cache)를 수행합니다.
   * [Cloudflare를 일시적으로 일시 중지](/fundamentals/manage-domains/pause-cloudflare/)합니다.
   * [Rocket Loader](/speed/optimization/content/rocket-loader/enable/)를 비활성화합니다.
2. 프라이빗 브라우저 탭에서 이미지 로드를 다시 테스트합니다.
3. 문제가 해결되지 않으면 1단계에서 제안한 다른 작업을 시도합니다.

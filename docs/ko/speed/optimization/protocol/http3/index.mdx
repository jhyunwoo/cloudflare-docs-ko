HTTP/3는 기본적으로 안전한 전송 프로토콜인 QUIC를 사용합니다. HTTP/3는 HTTP/2와 비슷한 방식으로 페이지 로드 시간을 개선합니다. 다만 QUIC 전송 프로토콜은 TCP의 head-of-line blocking 문제를 해결하므로, 손실이 있는 네트워크에서는 더 나은 성능을 제공할 수 있습니다.

:::note

HTTP/3에 대한 더 많은 배경 설명은 [Learning Center](https://www.cloudflare.com/learning/performance/what-is-http3/)를 참고하세요.

:::

:::note

이 설정은 사용자와 Cloudflare 사이의 연결에 대한 것입니다. 오리진까지의 HTTP/3 연결은 아직 지원되지 않습니다.

:::

## HTTP/3 활성화

HTTP/3는 모든 플랜에서 사용할 수 있습니다(단, [Cloudflare 엣지 네트워크의 SSL 인증서](/ssl/get-started/)는 필요합니다).

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

대시보드에서 **HTTP/3**를 활성화하려면 다음을 수행하세요.

1. [Cloudflare dashboard](https://dash.cloudflare.com)에 로그인합니다.
2. 계정과 zone을 선택합니다.
3. **Speed** > **Settings**로 이동합니다.
4. **Protocol Optimization**으로 이동합니다.
5. **HTTP/3**의 토글을 **On**으로 전환합니다.

</TabItem> <TabItem label="API">

API로 **HTTP/3**를 활성화하려면 URI 경로에서 설정 이름을 `http3`로 지정하고, `value` 파라미터를 `"on"`으로 설정한 [`PATCH`](/api/resources/zones/subresources/settings/methods/edit/) 요청을 보내세요.

</TabItem> </Tabs>

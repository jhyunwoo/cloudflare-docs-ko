향상된 HTTP/2 우선순위 지정을 사용하면 Cloudflare가 모든 브라우저에서 가장 빠른 경험을 위해 리소스를 최적의 순서로 전달합니다. 또한 [Workers](/workers/)와 함께 사용할 경우 콘텐츠 전달을 제어하는 기능도 지원합니다.

## 작동 방식

사용자 관점에서 웹 콘텐츠 로드 속도는 리소스가 로드되는 순서에 따라 달라집니다. HTTP/2에서는 기본적으로 Cloudflare가 브라우저가 요청한 순서를 따릅니다. 이 순서는 브라우저마다 달라 성능에 큰 차이를 만들 수 있습니다.

향상된 HTTP/2 우선순위 지정을 사용하면 Cloudflare가 브라우저와 관계없이 리소스 전달 순서를 최적화하도록 브라우저의 기본 동작을 재정의합니다. 가장 큰 개선 효과는 Safari 및 Edge 브라우저를 사용하는 방문자에게서 나타납니다.

자세한 내용은 [소개 블로그 게시물](https://blog.cloudflare.com/better-http-2-prioritization-for-a-faster-web/)을 참고하세요.

## 향상된 HTTP/2 우선순위 지정 활성화

<Tabs syncKey="dashPlusAPI"> <TabItem label="Dashboard">

Cloudflare 대시보드에서 **Enhanced HTTP/2 Prioritization**을 활성화하려면 다음을 수행하세요.

1. [Cloudflare dashboard](https://dash.cloudflare.com)에 로그인합니다.
2. 계정과 zone을 선택합니다.
3. **Speed** > **Settings**로 이동합니다.
4. **Protocol Optimization**으로 이동합니다.
5. **Enhanced HTTP/2 Prioritization**의 토글을 **On**으로 전환합니다.

</TabItem> <TabItem label="API">

Cloudflare API를 사용해 **Enhanced HTTP/2 Prioritization**을 활성화하려면 URI 경로에서 설정 이름을 `h2_prioritization`으로 지정하고 `value` 파라미터를 `"on"`으로 설정한 [`PATCH` request](/api/resources/zones/subresources/settings/methods/edit/)를 보내세요.

</TabItem> </Tabs>

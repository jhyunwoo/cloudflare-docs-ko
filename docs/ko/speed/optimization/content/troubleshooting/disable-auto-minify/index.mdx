사이트가 아직 [Auto Minify](/fundamentals/api/reference/deprecations/#2024-08-05)의 사용 중단된 기능을 사용하고 있다면, API를 통해 Auto Minify를 끄세요.

## 시작하기 전에

다음 권한을 가진 [API token](/fundamentals/api/get-started/create-token/)이 필요합니다.

- _Zone_ > _Zone Settings_ > _Edit_
- _Zone_ > _Zone Settings_ > _Read_

## (선택 사항) zone 상태 확인

zone의 Auto Minify 상태를 확인하려면 `/zones/{zone_id}/settings/minify` 엔드포인트로 `GET` 요청을 보내세요.

```bash
curl "https://api.cloudflare.com/client/v4/zones/{zone_id}/settings/minify" \
--header "Authorization: Bearer <API_TOKEN>"
```

```json output {4}
{
	"result": {
		"id": "minify",
		"value": { "css": "off", "html": "off", "js": "off" },
		"modified_on": null,
		"editable": true
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

강조 표시된 줄의 값 중 하나라도 `"on"`이라면, 이를 꺼야 합니다.

## API를 사용해 Auto Minify 끄기

zone의 Auto Minify를 끄려면 `/zones/{zone_id}/settings/minify` 엔드포인트로 `PATCH` 요청을 보내세요. 응답에서 `success` 값은 `true`여야 합니다.

```bash
curl --request PATCH \
"https://api.cloudflare.com/client/v4/zones/{zone_id}/settings/minify" \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{ "value": { "css": "off","html": "off","js": "off" } }'
```

```json output {8}
{
	"result": {
		"id": "minify",
		"value": { "js": "off", "css": "off", "html": "off" },
		"modified_on": "2024-11-15T19:32:20.882640Z",
		"editable": true
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

Rocket Loader는 렌더링 이후로 모든 JavaScript 로딩을 지연시켜 웹사이트의 콘텐츠(텍스트, 이미지, 글꼴 등)를 우선시합니다.

이러한 로딩 방식(비동기 로딩이라고 함)은 페이지 콘텐츠를 더 이르게 렌더링하게 합니다. Rocket Loader는 실행 순서를 유지하면서 인라인 스크립트와 외부 스크립트를 모두 처리합니다. Cloudflare는 호환되지 않는 브라우저를 감지하면 Rocket Loader를 비활성화합니다.

JavaScript가 있는 페이지에서는 이를 통해 사용자에게 [훨씬 더 빠른 로딩 경험](https://www.cloudflare.com/learning/performance/test-the-speed-of-a-website/)을 제공하고, 다음 성능 지표를 개선합니다.

- Time to First Paint (TTFP)
- Time to First Contentful Paint (TTFCP)
- Time to First Meaningful Paint (TTFMP)
- Document Load

## 제한 사항

Rocket Loader와 Email Obfuscation을 포함한 Cloudflare의 일부 선택 기능은 [w3.org](https://validator.w3.org/) 같은 도구로 엄격한 HTML 검증을 수행할 때 실패하는 비표준 태그를 사용합니다. 이러한 실패는 사이트 방문자에게 발생하는 문제와는 관련이 없습니다.

웹사이트에서 JavaScript 또는 jQuery 문제가 발생한다면 [Rocket Loader를 비활성화](/speed/optimization/content/rocket-loader/enable/)한 뒤 웹사이트를 다시 테스트하세요.

Rocket Loader가 특정 스크립트를 무시하게 하려면, 해당 script 태그에 `data-cfasync="false"` 속성을 추가하세요.

```html
<script data-cfasync="false" src="/javascript.js"></script>
```

Rocket Loader는 여전히 페이지의 다른 모든 스크립트 로딩은 최적화합니다.

:::note


Rocket Loader의 영향이 특정 페이지에만 있다면, [Configuration Rule](/rules/configuration-rules/)을 사용해 URL 기준으로 해당 페이지를 제외하세요.


:::

## 제한 사항

* Rocket Loader 대상에서 스크립트를 제외하려는 경우, JavaScript 내부에서 이 속성을 추가하는 방식은 동작하지 않습니다.
* Rocket Loader가 무시해야 할 스크립트가 페이지의 다른 JavaScript에 의존한다면, 그 의존 스크립트들에도 `data-cfasync="false"` 속성이 있어야 합니다.
* `data-cfasync` 속성은 `src` 속성보다 앞에 추가되어야 합니다.
* Rocket Loader는 속성 값이 작은따옴표 또는 큰따옴표로 감싸져 있어도 태그를 인식합니다.

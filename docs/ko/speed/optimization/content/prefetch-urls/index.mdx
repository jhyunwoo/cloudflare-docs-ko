URL 미리 가져오기는 Cloudflare가 방문자가 다음에 요청할 가능성이 높은 콘텐츠로 캐시를 미리 채우는 기능입니다. 이 설정은 [추가 설정](#setup)과 함께 사용할 때 캐시 적중률을 높여 사용자에게 더 빠른 경험을 제공합니다.

## 설정

Cloudflare가 URL을 미리 가져오기 시작하려면 [기능을 활성화](#enable-prefetch-urls)하고 [미리 가져올 URL 목록을 포함](#choose-urls-to-prefetch)해야 합니다.

### Prefetch URLs 활성화

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 **Prefetch URLs**를 활성화하려면 다음 단계를 따르세요.

1. Cloudflare 대시보드에서 **Speed** > **Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/speed/optimization" />

2. **Content Optimization**으로 이동합니다.
3. **Prefetch URLs** 토글을 **On**으로 전환합니다.

</TabItem> <TabItem label="API">

API로 **Prefetch URLs**를 활성화하거나 비활성화하려면 URI 경로의 설정 이름으로 `prefetch_preload`를 사용하고, `value` 파라미터를 원하는 설정값(`"on"` 또는 `"off"`)으로 지정한 [`PATCH`](/api/resources/zones/subresources/settings/methods/edit/) 요청을 보내세요.

</TabItem> </Tabs>

### 미리 가져올 URL 선택

[기능을 활성화](#enable-prefetch-urls)한 후에는 Cloudflare가 어떤 URL을 미리 가져와야 하는지도 지정해야 합니다.

이를 위해 `rel="prefetch"` 속성이 포함된 매니페스트 파일을 가리키는 Link HTTP 응답 헤더를 포함하고, 매니페스트 파일은 `text/plain`을 Content-type 응답 헤더로 사용해 제공하세요.

<Example>
예시 HTTP 응답 헤더:<br/>
`Link: <http://www.example.com/manifest.txt>; rel="prefetch"`

예시 `manifest.txt` 파일:

```txt
/static/fetch1
//other.example.com/fetch2
http://another.example.com/fetch3
```

</Example>

매니페스트 파일에는 줄바꿈으로 구분된 URI, 프로토콜 상대 URL 또는 전체 URL이 들어 있어야 합니다. 이 파일들은 Cloudflare에 연결된 웹사이트 상에 있어야 합니다. HTML 페이지를 참조하는 경우 HTML 페이지 자체만 미리 가져와지며, 해당 HTML의 하위 요청은 매니페스트에 명시적으로 정의하지 않으면 가져오지 않습니다.

:::note[참고]

매니페스트 파일에 대한 미리 가져오기 요청을 수행할 때 사용되는 IP 주소는 Cloudflare 로그에 `127.0.0.1`로 기록됩니다.
:::

### Prefetch 파일 제한

Prefetch 파일에는 다음과 같은 제한이 있습니다.

- 매니페스트 파일의 최대 개수는 16개입니다.
- 매니페스트 파일 하나당 포함할 수 있는 최대 파일 수는 100개입니다.
- 매니페스트 파일 크기 제한은 1MB입니다.

## 제한 사항

- Cloudflare는 리소스가 [기본적으로 캐시되는](/cache/concepts/default-cache-behavior/#default-cached-file-extensions) 경우에만 매니페스트 파일에 나열된 파일을 미리 가져옵니다.

- Prefetch는 사용자 지정 캐시 키 구성과 호환되지 않습니다. 자세한 내용은 [Cache Key 제한 사항](/cache/how-to/cache-keys/#limitations)을 참고하세요.

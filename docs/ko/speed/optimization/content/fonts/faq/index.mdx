아래 섹션에서 성능, 개인정보 보호, 보안, 구현 및 통합에 관한 자주 묻는 질문을 확인할 수 있습니다.

## 성능

### Cloudflare Fonts는 웹사이트 성능을 어떻게 개선하나요?

Cloudflare Fonts는 Cloudflare의 최적화된 인프라를 통해 사용자의 도메인에서 글꼴을 제공하므로 DNS 조회, TLS 연결 설정, 지연 시간을 줄여 줍니다. 그 결과 페이지 로드 시간이 빨라지고 웹사이트 전체 성능이 향상됩니다.

## 개인정보 보호 및 보안

### Cloudflare Fonts는 사용자 데이터를 수집하거나 기록하나요?

아니요. Cloudflare Fonts는 글꼴 전달 과정에서 사용자 데이터를 수집하거나 기록하지 않습니다. Cloudflare는 [privacy-first](https://www.cloudflare.com/privacypolicy/) 접근 방식을 지향하며, 사용자의 데이터가 기밀로 유지되도록 보장합니다.

## 구현 및 통합

### Cloudflare Fonts를 사용할 때 글꼴 파일을 별도로 호스팅해야 하나요?

아니요. Cloudflare Fonts는 글꼴 전달 과정을 단순화합니다. 글꼴 파일을 별도로 호스팅할 필요가 없습니다. 이 서비스는 웹페이지 HTML을 다시 작성하여 Google Fonts 링크를 제거하고 인라인 CSS로 대체하는 방식으로 동작합니다.

### Cloudflare Fonts를 사용하려면 코드 변경이 필요한가요?

아니요. Cloudflare Fonts를 사용하기 위해 코드 변경은 필요하지 않습니다.

### Cloudflare Fonts를 통해 제공된 글꼴 파일의 분석 데이터를 볼 수 있나요?

네. Cloudflare가 사용자의 zone을 통해 이러한 글꼴을 제공하므로 분석 데이터가 Cloudflare 대시보드에 표시됩니다. 이를 통해 Cloudflare Fonts가 없었다면 알기 어려웠을 글꼴 파일 요청도 분석할 수 있습니다.

### Cloudflare Fonts 요청은 어떤 경로로 이루어지나요?

글꼴 요청은 `/cf-fonts/` 경로 접두사를 사용해 origin으로 전송됩니다.

### 그 밖에 어떤 변환이 이루어지나요?

Cloudflare는 HTML 응답 본문에서 Google Fonts 도메인을 향한 preconnect 헤더를 제거합니다. 이렇게 하면 불필요한 연결이 제거되어 성능이 향상됩니다.

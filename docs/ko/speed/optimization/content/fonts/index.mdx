Cloudflare Fonts는 Google Fonts를 사용하는 웹사이트를 위해 설계된 기능입니다. 이 기능은 Google Fonts를 웹사이트 자체 origin에서 제공되도록 다시 작성하므로, 서드파티 글꼴 제공자에 의존할 필요가 없습니다. Cloudflare Fonts는 코드 변경이나 글꼴 자체 호스팅 없이도 웹사이트 성능과 사용자 개인정보 보호를 향상하도록 설계되었습니다.

## Cloudflare Fonts 작동 방식

Cloudflare Fonts는 웹페이지의 HTML을 다시 작성하는 방식으로 동작합니다. Google Fonts 링크를 제거하고 인라인 CSS로 대체합니다. 이 CSS에는 Google 서버가 아니라 자체 Cloudflare zone의 글꼴을 가리키는 링크가 포함됩니다. 이를 통해 글꼴 파일이 Cloudflare 인프라를 거쳐 사용자의 도메인에서 제공되므로, 성능이 최적화되고 사용자 개인정보 보호도 강화됩니다.

### 브라우저 지원

Cloudflare Fonts는 Unicode-range 서브세팅과 WOFF 또는 WOFF2 형식을 지원하는 브라우저와 호환되며, 여기에는 다음이 포함됩니다.

```
Chrome 36+
Edge 16+
Safari 10+
Firefox 44+
Opera 22+
IE 9+
Chrome for Android 115+
Safari on iOS 10+
Samsung Internet 5+
```

## 시작하기

전체 도메인에 대해 Cloudflare Fonts를 활성화하려면 다음 단계를 따르세요.

1. Cloudflare 대시보드에서 **Speed** > **Settings** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/speed/optimization" />

2. **Content Optimization**으로 이동합니다.
3. **Cloudflare Fonts**의 토글을 **On**으로 전환합니다.

## 제한 사항

Cloudflare Fonts는 강력한 글꼴 최적화 기능을 제공하지만, 다음과 같은 제한 사항을 알아두는 것이 중요합니다.

- **글꼴 변환**: 현재 Cloudflare Fonts는 Google Fonts 변환만 지원합니다.
- **APO 호환성**: [Automatic Platform Optimization](/automatic-platform-optimization/) (APO)이 활성화된 경우 Cloudflare Fonts는 동작하지 않습니다. Cloudflare APO는 Google Fonts를 유사한 방식으로 자동 최적화합니다.
- **CSS import**: Cloudflare Fonts는 Google Fonts의 `<link>` 설정과만 호환되며 CSS `@import` 방식은 지원하지 않습니다.
- **CSP headers**: Cloudflare Fonts는 <GlossaryTooltip term="content security policy (CSP)" link="https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy">콘텐츠 보안 정책(CSP)</GlossaryTooltip> 헤더를 수정하지 않습니다. [`style-src`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/style-src)를 통한 인라인 스타일 제한이나, [`font-src`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/font-src)를 통해 사이트 자체 origin에서 제공되는 글꼴을 제한하는 설정처럼 특정 CSP 구성은 Cloudflare Fonts가 동작하지 않게 만들 수 있습니다.
- **Fallback 메커니즘**: Cloudflare Fonts가 특정 페이지를 지원하지 않는 경우, Google Fonts를 사용하는 방식으로 자연스럽게 fallback합니다.

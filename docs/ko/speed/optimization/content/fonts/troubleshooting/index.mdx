## Fonts 기능이 동작하는지 확인하기

Fonts 기능이 올바르게 동작하는지 테스트하려면 다음 단계를 따르세요.

1. Fonts 기능이 비활성화된 상태에서 웹페이지로 이동한 뒤 브라우저 개발자 도구의 network panel을 엽니다. Chrome에서는 웹페이지를 마우스 오른쪽 버튼으로 클릭하고 **Inspect**를 선택하면 개발자 도구가 열립니다. 그런 다음 콘솔 안의 **Network** 탭으로 이동합니다.
2. 페이지를 다시 로드합니다.
3. Network 탭에서 `fonts.googleapis.com`에 대한 요청과 `fonts.gstatic.com`에 대한 요청이 보여야 합니다. 이는 해당 페이지에서 Google Fonts가 다운로드되고 있음을 의미합니다. 이 요청들이 목록에 없다면, 웹페이지가 Google Fonts를 사용하지 않거나 호스팅 제공자가 다른 방식으로 Google Fonts를 최적화하고 있을 수 있습니다.
4. [Cloudflare Fonts를 활성화](/speed/optimization/content/fonts/#get-started)하고 몇 초 기다립니다.
5. 검사 창에서 **Disable cache**를 켠 뒤 페이지를 다시 로드합니다.
6. 이제 network panel에서 `/cf-fonts/` 경로 접두사를 사용하는 zone 요청이 보여야 합니다. `fonts.googleapis.com`과 `fonts.gstatic.com` 요청은 사라져야 합니다. 이는 기능이 올바르게 동작하고 있음을 의미합니다.

## 기능이 동작하지 않을 때

이 기능이 동작하려면, 응답 HTML(기능이 비활성화된 상태일 때)에 `href`가 `fonts.googleapis.com`을 가리키는 link 태그가 포함되어 있어야 합니다. 브라우저에서 웹페이지의 소스 코드를 확인해 이를 점검할 수 있습니다. 예를 들어, 아래 link 태그는 Roboto Google Font를 위한 것입니다.

```html
<link href="https://fonts.googleapis.com/css2?family=Roboto&display=swap" rel="stylesheet">
```

이 태그가 HTML에 없는데도 페이지가 Google Fonts를 사용한다고 확신한다면, 호스팅 제공자가 서버 측에서 Google Fonts를 최적화하고 있을 수 있습니다. 이 경우 Cloudflare Fonts가 제대로 동작하지 않을 수 있습니다.

## Cloudflare Fonts 관련 기타 문제

Cloudflare Fonts를 사용하는 동안 문제가 발생하거나 질문이 있다면 [Cloudflare Community](https://community.cloudflare.com/) 페이지를 참고하거나 [Cloudflare Support](/support/contacting-cloudflare-support/)에 문의해 도움을 받으세요.

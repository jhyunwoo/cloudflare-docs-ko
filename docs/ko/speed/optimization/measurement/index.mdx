[Web Analytics](/web-analytics/)를 웹사이트에서 활성화한 뒤, 개인정보를 우선하는 방식으로 트래픽을 추적하고 사이트의 속도 도구를 최적화하려면 측정을 활성화하세요. 이 분석 도구는 실제 사용자 상호작용에 기반한 인사이트를 제공하기 위해 [실사용자 측정(Real User Measurement)](/speed/observatory/run-speed-test/#enable-real-user-monitoring-rum) (RUM) 데이터를 활용하며, 이를 통해 사이트 성능을 효과적으로 개선할 수 있습니다.

Cloudflare 에이전트는 현재 베타에 있으며 무료 계획에 계정 만 사용할 수 있습니다. 기능 및 행동이 변경 될 수 있습니다.
주요 특징

Cloudflare로 대리인, 당신은 할 수 있습니다:

- Cloudflare 제품 및 계정 구성에 대한 질문에 대한 답변
- Cloudflare 실행 API 작업과 승인 흐름을 쓰기 작업
- DNS 조회, 인증서 확인 및 연결 테스트와 같은 네트워크 진단을 실행
- 관련 정보 Cloudflare 문서 검색

Cloudflare 에이전트는 내장[에이전트 SDK](/agents/), 당신이 Cloudflare에 당신의 자신의 AI 대리인을 건설하기 위하여 사용할 수 있는 동일한 기구.

***

## 회사연혁

### 문서 검색

Cloudflare 문서 검색 제품, 기능 및 모범 사례에 대한 답변을 찾을 수 있습니다.

### Cloudflare API 가동

Cloudflare API에 대한 작업 수행 DNS 레코드 생성, 방화벽 규칙 관리, 또는 계정 설정을 확인 같은 작업을 수행 할 수 있습니다.

작업이 실행하기 전에 승인해야 합니다.

### 네트워크 진단

연결 및 구성 문제를 해결하는 네트워크 진단 명령을 실행:

- **DNS 조회**- 모든 도메인에 대한 Query DNS 레코드
- **HTTP 요청**- 시험 endpoints 및 검사 응답
- **도메인 정보**- WHOIS 및 RDAP 등록 데이터 보기
- **인증서 확인**- TLS/SSL 인증서 검사
- **연결성 시험**- 네트워크 접근성 검증

***

## 제한 사항

베타 기간 동안:

- 기능 및 행동은 공지없이 변경 될 수 있습니다.
- 작업은 항상 실행하기 전에 명시적 승인이 필요합니다.

<Description>
  Cloudflare QXWorkers를 가진 기계 학습 모형을 실행하십시오.
</Description>

Constellation은 Cloudflare QXWorkersXQ에 기본적으로 미리 훈련된 기계 학습 모형에 빠르고, 낮경 inference 일을 실행할 수 있습니다. 그것은 가장 인기있는 기계 학습 (ML) 및 AI 런타임 및 모델의 여러 클래스를 지원합니다.

Cloudflare는 확인된 모형의 curated 명부를 제공하고, 또는 당신은 당신의 자신의 업로드할 수 있습니다.

Constellation을 사용하여 응용 프로그램에 배포 할 수있는 기능 :

- 콘텐츠 생성, 요약, 또는 이와 유사한 분석
- 질문 답변
- 오디오 transcription
- 이미지 또는 오디오 분류
- 객체 검출
- Anomaly 탐지
- 감정 분석

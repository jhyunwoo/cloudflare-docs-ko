Cloudflare는 400 이상 지원합니다[최상위 도메인(TLD)](https://www.cloudflare.com/learning/dns/top-level-domain/)그리고 항상 새로운 TLD를 추가 evaluating. TLD의 특정 시간대는 아직 나열되지 않습니다. 지원되는 전체 목록과 곧 TLD를 찾을 수 있습니다.[TLD 정책 페이지](https://www.cloudflare.com/tld-policies/).

:::참조

등록하려면`.us`도메인 참조[.US 도메인의 추가 요구 사항](/registrar/top-level-domains/us-domains/).
:::

## 도메인 가용성

당신의 시간[TLD 등록 절차](/registrar/get-started/register-domain/#how-to-register-a-new-domain)모델 번호: Cloudflare 등록할 수 있는 TLD가 있다면 등록할 수 있습니다. 검색 목록에 나타나지 않는 경우, TLD는 등록이 불가능합니다.

사용할 수없는 도메인에 대한 가능한 원인은 다음과 같습니다.

- 다른 사람은 도메인을 소유합니다.
- Cloudflare Registrar가 지원하지 않는 Internationalized Domain Name (IDN)입니다. 이 도메인은 국제 문자 (예 :`á`, `ü`, 다른 사람 사이에서).

## 도메인 전송

도메인을 Cloudflare Registrar로 전송하면[도메인은 제한된 상태입니다.](/registrar/troubleshooting/#domain-is-in-a-restricted-status)전송을 차단할 수 있는 상태를 위해.

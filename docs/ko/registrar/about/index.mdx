모델 번호: Cloudflare Registrar는 다른 이점을 제공합니다[계정 관리](https://www.cloudflare.com/learning/dns/glossary/what-is-a-domain-name-registrar/)도메인 이름 등록 갱신과 같은[표시 수수료 없이](https://www.cloudflare.com/products/registrar/). 당신은 단지 등록에 의해 청구되는 것을 지불하고[ICANN 정보](https://www.icann.org/). Cloudflare Registrar는 또한 무료과 같은 추가 보안 기능을 제공합니다.[도메인 이름 시스템 보안 확장 (DNSSEC)](/registrar/get-started/enable-dnssec/), [사용자 정의 도메인 보호](/registrar/custom-domain-protection/)·[WHOIS 활동](/registrar/account-options/whois-redaction/).

Cloudflare Registrar 또는 타사에서 도메인을 구입할 수 있습니다. 제 3 자로부터 그것을 살 때 CloudflareXQ로 도메인을 관리 할 수 있습니다. 모든 기능 Cloudflare의 혜택을 누리십시오.

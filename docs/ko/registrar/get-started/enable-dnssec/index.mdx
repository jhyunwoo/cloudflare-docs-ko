도메인 이름 시스템 (DNS)는 숫자 인터넷 주소로 도메인 이름을 번역합니다. 그러나 DNS는 기본적으로 insecure 프로토콜입니다. DNS 레코드가 어디에서 왔는지 보장하지 않으며 주어진 요청을 수락하지 않습니다.

[다운로드](/dns/dnssec/)보안 레이어를 DNS 레코드에 암호화 서명을 추가하여 도메인 이름 시스템에 생성합니다. 이렇게하면, 요청은 저자명서에서 필요한 레코드를 확인하고 길을 따라 변경하지 못하도록 서명 할 수 있습니다.

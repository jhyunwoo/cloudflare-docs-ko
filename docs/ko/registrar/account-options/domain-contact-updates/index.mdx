다음 필드를 변경하면 Cloudflare Registrar는 변경 전에 레지스트리 승인을 변경해야 합니다.

- 이름 \*
- 이름 \*
- 회사연혁
- 이메일 주소

위에서 언급 한 필드를 업데이트하면 Cloudflare Registrar는 현재 등록자의 이메일 주소로 승인 이메일을 보낼 것입니다. 승인 이메일은 요청한 변경이 보고 승인되거나 거부될 수 있는 웹 페이지로 연결됩니다. 대출 변경이 승인되지 않거나 7 일 이내에 거부되면, 요청은 자동으로 취소됩니다.

이 필드를 업데이트하지 않는 경우, 연락처 정보는 즉시 업데이트되고 더 많은 작업이 필요하지 않습니다.

:::카ution\[중요]

승인 이메일 Cloudflare의 링크를 선택하면 연락처 변경을 수락하거나 거부 할 수있는 옵션이 있습니다. 선택하면**이름 \***&#xBC84;튼, 도메인은 60 일 동안 전송됩니다.

도메인을 잠겨 싶지 않으면, 선택해야합니다**60 일 이동 자물쇠를 적용하지 마십시오**체크박스*이전 다음*선택하기**이름 \***&#xBC84;튼. 모든 지원된 TLD에 적용`.uk`.

:::

## 이메일 문의

등록 연락처 업데이트가 이메일 주소로 변경되는 경우, Cloudflare는 새 이메일 주소로 두 번째 승인 이메일을 보냅니다. 이전 (원래) 이메일 주소와 새로운 것은 성공적으로 완료 될 변경에 대한 변경을 승인해야합니다.

현재 등록자 만 이동 잠금을 선택 할 수 있지만. 새로운 등록자의 승인 페이지는 선택 옵션을 포함하지 않습니다.

## 60 일 이동 자물쇠

등록 연락처의 변경이 승인되면 도메인은 60 일 동안 전송 잠금에 배치됩니다. 전송 잠금을 방지하기 위해 박스를 검사하지 않고 레지스트리 접촉으로 변경 될 때 발생합니다.

이 전송 잠금은 다른 레지스트라에 도메인의 전송을 방지, 다른 Cloudflare 계정에 전송. 그것은 도메인 이름에 추가 업데이트를 방지하지 않습니다.

레지스트리 접촉이 다시 업데이트되면 도메인은 60 일 자물쇠 기간에 있으며, 자물쇠 만료는 가장 최근 업데이트에서 60 일 이상 연장됩니다.

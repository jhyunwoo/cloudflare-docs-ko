모든 uncaught 예외는 던져진<GlossaryTooltip term="Durable Object">튼튼한 목표</GlossaryTooltip>또는 Durable Objects의 인프라(Overloads 또는 네트워크 오류와 같은)가 클라이언트의 호출에 전파됩니다. 이러한 예외를 촉구할 수 있습니다.[`DurableObjectStub`](/durable-objects/api/stub)견적 요청

JavaScript 속성에 오류`.retryable`True로 설정하면 튼튼한 개체에 요청이 idempotent인지 또는 응답을 변경하지 않고 여러 번 적용 할 수 있습니다. 요청이 idempotent되지 않은 경우, 응용 프로그램에 가장 적합한 것을 결정해야합니다. 그것은 요청을 복원 할 때 exponential backoff를 적용하는 것이 좋습니다.

JavaScript 속성에 오류`.overloaded`true로 설정하면 검색되지 않습니다. 튼튼한 개체가 과부하된 경우, 다시 시도는 과부하를 악화하고 전반적인 과실율을 증가시킬 것입니다.

:::note\[ 예외 후 ElasticObjectStub을 다시 설정]

많은 예외는 떠나[`DurableObjectStub`](/durable-objects/api/stub)"broken"상태에서 추가 요청을 보내는 모든 시도는 원래 예외로 즉시 실패합니다. 이를 피하기 위해, 당신은 재사용을 피해야`DurableObjectStub`예외를 던지기 후에. 다음 요청을 위해 새로운 것을 만들려면 대신해야합니다.

:::

## 예외는 thrown

Durable Objects는 2가지 방법 중 하나에서 예외를 던질 수 있습니다:

- 예외는 사용자 코드 내에서 던져질 수 있습니다.<GlossaryTooltip term="Durable Object class">튼튼한 목표 종류</GlossaryTooltip>. 결과 예외는`.remote`호텔 위치`True`이 경우.
- 예외는 튼튼한 Object의 인프라에 의해 생성될 수 있습니다. 인프라 예외의 일부 소스는 다음과 같습니다. 일시적 내부 오류, 단일 내구성 개체에 너무 많은 요청을 전송, 너무 많은 요청은 느리거나 과도한 I / O (외부 API 호출 또는 스토리지 작업) 개인 내구성 개체 내에서. 일부 인프라 예외는 수도 있습니다.`.remote`호텔 위치`True`-- 예를 들면, 튼튼한 목표가 그것의 기억 또는 CPU 한계를 초과할 때.

더 알아보기[문제 해결](/durable-objects/observability/troubleshooting/)튼튼한 개체 및/또는 Durable Objects 인프라에 의해 반환된 오류의 유형을 검토하고 그(것)들을 막는 방법.

## 이름 \*

이 예제는 권장된 exponential backoff 알고리즘을 사용하여 재시동 요청을 보여줍니다.

```ts
import { DurableObject } from "cloudflare:workers";

export interface Env {
	ErrorThrowingObject: DurableObjectNamespace;
}

export default {
	async fetch(request, env, ctx) {
		let userId = new URL(request.url).searchParams.get("userId") || "";

		//Retry 행동은 애플리케이션에 맞게 조정될 수 있습니다.
		let maxAttempts = 3;
		let baseBackoffMs = 100;
		let maxBackoffMs = 20000;

		let attempt = 0;
		while (true) {
			//자주 묻는 질문
			try {
				//각 시도를 위한 튼튼한 목표 stub 창조, 특정 유형의
				//오류는 튼튼한 개체를 깰 것입니다.
				const doStub = env.ErrorThrowingObject.getByName(userId);
				const resp = await doStub.fetch("http://your-do/");

				return Response.json(resp);
			} catch (e: any) {
				if (!e.retryable) {
					//실패는 일시적 내부 오류가 아니므로 재발송하지 마십시오.
					break;
				}
			}
			let backoffMs = Math.min(
				maxBackoffMs,
				baseBackoffMs * Math.random() * Math.pow(2, attempt),
			);
			attempt += 1;
			if (attempt >= maxAttempts) {
				//최대 시도에 도달, 그래서 다시 시도하지 않습니다.
				break;
			}
			await scheduler.wait(backoffMs);
		}
		return new Response("server error", { status: 500 });
	},
} satisfies ExportedHandler<Env>;

export class ErrorThrowingObject extends DurableObject {
	constructor(state: DurableObjectState, env: Env) {
		super(state, env);

		//당신의 constructor에서 제기되는 모든 예외는 또한 놓을 것입니다
		//True 속성
		throw new Error("no good");
	}

	async fetch(req: Request) {
		//uncaught 예외 생성
		//.remote 속성은 콜러에 대한 예외에 추가됩니다
		//true로 설정
		throw new Error("example error");

		//우리는 결코 도달하지 않습니다
		return Response.json({});
	}
}
```

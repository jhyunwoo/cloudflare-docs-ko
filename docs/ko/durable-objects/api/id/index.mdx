## 이름 \*

튼튼한 개체 ID는 64-digit hexadecimal 번호로 식별<GlossaryTooltip term="Durable Object">튼튼한 목표</GlossaryTooltip>. 모든 64digit hex 수는 유효한 ID입니다. 튼튼한 개체 ID는 간접적으로 형성됩니다[`DurableObjectNamespace`](/durable-objects/api/namespace)인터페이스.

더 보기`DurableObjectId`인터페이스는 새로운 또는 기존의 튼튼한 개체를 나타냅니다. 이 인터페이스는 대부분 자주 사용[`DurableObjectNamespace::get`](/durable-objects/api/namespace/#get)구매하기[`DurableObjectStub`](/durable-objects/api/stub)튼튼한 개체에 요청을 제출하기 위해. 튼튼한 개체에 대한 ID를 생성하는 것은 튼튼한 개체를 만들지 않습니다. 튼튼한 개체는 lazily를 창조한 후에 stub를에서 창조합니다`DurableObjectId`. 이 객체는 실제로 접근 할 때까지 건설되지 않습니다.

:::노트\[로깅]

특정 튼튼한 개체에 문제가 발생하면 로그인 할 수 있습니다.`DurableObjectId`당신의 노동자에서 그리고 당신의 CloudflareQ 지원 요구에 그것을 포함하십시오.

:::

## 제품 설명

### `toString`

`toString`변환하기`DurableObjectId`64 자리 hex 문자열로. 이 문자열은 로깅 목적으로 유용하거나 저장`DurableObjectId`예를 들어, 세션 쿠키에서. 이 문자열은 reconstruct에 사용될 수 있습니다`DurableObjectId`이름 \*`DurableObjectNamespace::idFromString`.

#### 매개 변수

- 없음.

#### 반환 값

- 64 자리 hex 문자열.

### `equals`

`equals`2개의 인스턴스 사이 equality를 비교하기 위하여 사용됩니다`DurableObjectId`.

<Tabs>
  <TabItem label="모델 번호: JavaScript" icon="seti:javascript">
    ```js
    const id1 = env.MY_DURABLE_OBJECT.newUniqueId();
    const id2 = env.MY_DURABLE_OBJECT.newUniqueId();
    console.assert(!id1.equals(id2), "Different unique ids should never be equal.");
    ```
  </TabItem>

  <TabItem label="모델 번호: Python" icon="seti:python">
    ```python
    id1 = env.MY_DURABLE_OBJECT.newUniqueId()
    id2 = env.MY_DURABLE_OBJECT.newUniqueId()
    assert not id1.equals(id2), "Different unique ids should never be equal."
    ```
  </TabItem>
</Tabs>

#### 매개 변수

- 자주 묻는 질문`DurableObjectId`비교하기.

#### 반환 값

- 한국어 그렇지 않으면 진정한.

## 제품 정보

### `name`

`name`옵션 속성은`DurableObjectId`, 이는 이름을 반환하는 데 사용 된`DurableObjectId`이름 \*[`DurableObjectNamespace::idFromName`](/durable-objects/api/namespace/#idfromname). 이 값은 정의되지 않는다면`DurableObjectId`사용방법[`DurableObjectNamespace::newUniqueId`](/durable-objects/api/namespace/#newuniqueid). 이 값은 또한 정의되지 않습니다.`ctx.id`튼튼한 개체 생성기로 전달 (refer to[GitHub 문제](https://github.com/cloudflare/workerd/issues/2240)토론).

<Tabs>
  <TabItem label="모델 번호: JavaScript" icon="seti:javascript">
    ```js
    const uniqueId = env.MY_DURABLE_OBJECT.newUniqueId();
    const fromNameId = env.MY_DURABLE_OBJECT.idFromName("foo");
    console.assert(uniqueId.name === undefined, "unique ids have no name");
    console.assert(
    	fromNameId.name === "foo",
    	"name matches parameter to idFromName",
    );
    ```
  </TabItem>

  <TabItem label="모델 번호: Python" icon="seti:python">
    ```python
    unique_id = env.MY_DURABLE_OBJECT.newUniqueId()
    from_name_id = env.MY_DURABLE_OBJECT.idFromName("foo")
    assert unique_id.name is None, "unique ids have no name"
    assert from_name_id.name == "foo", "name matches parameter to idFromName"
    ```
  </TabItem>
</Tabs>

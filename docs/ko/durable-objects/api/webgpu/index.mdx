:::카트로션

WebGPU API는 로컬 개발에서만 사용할 수 있습니다. WebGPU API에 의존하는 QXQXQXQXQXQXQXQXQXQ를 배포할 수 없습니다. 이름 \*[Workers AI](/workers-ai/)Cloudflare의 글로벌 네트워크에서 GPU에서 기계 학습 모델에 대한 정보를 제공합니다.

:::

더 보기[웹GPU API](https://developer.mozilla.org/en-US/docs/Web/API/WebGPU_API)JavaScript에서 GPU를 직접 사용할 수 있습니다.

WebGPU API는 WebGPU API에서만 접근 가능[모델 번호: Durable Objects](/durable-objects/). Workers 내에서 WebGPU API를 사용할 수 없습니다.

로컬 개발에서 WebGPU API를 사용하려면, 활성화`experimental`·`webgpu` [모델 번호: 호환성 플래그](/workers/configuration/compatibility-flags/)내 계정[Wrangler 구성 파일](/workers/wrangler/configuration/)당신의 튼튼한 목표의.

```
compatibility_flags = ["experimental", "webgpu"]
```

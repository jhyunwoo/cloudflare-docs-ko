## 이름 \*

더 보기`DurableObjectStub`인터페이스는 원격에 invoke 메소드에 사용되는 클라이언트입니다.<GlossaryTooltip term="Durable Object">튼튼한 목표</GlossaryTooltip>. 유형의`DurableObjectStub`RPC 메소드를 허용하는 일반적인 stub에 호출됩니다.

Durable Objects는 E-order semantics, 개념을 구현합니다[E 분산 프로그래밍 언어](https://en.wikipedia.org/wiki/E_\(programming_language\)). 동일한 튼튼한 목표에 다수 전화를 만들 때, 그것은 당신이 그(것)들을 한 순서에 있는 리모트 튼튼한 목표에 전달될 것이라는 점을 보장됩니다. E-order semantics는 많은 배부된 프로그램 문제를 더 쉽게 만듭니다. E-order는 구현[모자'n Proto](https://capnproto.org)Cloudflare WorkersXQ는 내부 커뮤니케이션을 위해 사용됩니다.

예외가 튼튼한 개체에 의해 던지는 경우<GlossaryTooltip term="stub">뚱 베어</GlossaryTooltip>모든 in-flight 통화 및 향후 통화는 실패합니다.[옵션 정보](/durable-objects/observability/troubleshooting/). 먼 튼튼한 목표에 invoking 방법을 계속하기 위하여 노동자는 stub를 재창조해야 합니다. 다른 스텁 사이에 주문 보증이 없습니다.

## 제품 정보

### `id`

`id`숙박 시설`DurableObjectStub`관련 기사[`DurableObjectId`](/durable-objects/api/id)stub를 만들기 위하여 사용해.

<Tabs>
  <TabItem label="JavaScript" icon="seti:javascript">
    ```js
    const id = env.MY_DURABLE_OBJECT.newUniqueId();
    const stub = env.MY_DURABLE_OBJECT.get(id);
    console.assert(id.equals(stub.id), "This should always be true");
    ```
  </TabItem>

  <TabItem label="Python" icon="seti:python">
    ```python
    id = env.MY_DURABLE_OBJECT.newUniqueId()
    stub = env.MY_DURABLE_OBJECT.get(id)
    assert id.equals(stub.id), "This should always be true"
    ```
  </TabItem>
</Tabs>

### `name`

`name`옵션 속성은`DurableObjectStub`, 그것이 stub 창조에 직접 제공 한 경우 이름을 반환[`DurableObjectNamespace::getByName`](/durable-objects/api/namespace/#getbyname)또는 간접적으로[`DurableObjectId`](/durable-objects/api/id)이름 \*[`DurableObjectNamespace::idFromName`](/durable-objects/api/namespace/#idfromname). 이 값은 정의되지 않는다면[`DurableObjectId`](/durable-objects/api/id)생성하기`DurableObjectStub`사용방법[`DurableObjectNamespace::newUniqueId`](/durable-objects/api/namespace/#newuniqueid).

<Tabs>
  <TabItem label="JavaScript" icon="seti:javascript">
    ```js
    const stub = env.MY_DURABLE_OBJECT.getByName("foo");
    console.assert(stub.name === "foo", "This should always be true");
    ```
  </TabItem>

  <TabItem label="Python" icon="seti:python">
    ```python
    stub = env.MY_DURABLE_OBJECT.getByName("foo")
    assert stub.name == "foo", "This should always be true"
    ```
  </TabItem>
</Tabs>

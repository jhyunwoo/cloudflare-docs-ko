이 튜토리얼에서는 Durable Objects를 사용하여 좌석 예약 앱을 구축하는 방법을 배울 수 있습니다. 이 응용 프로그램은 사용자가 비행에 대한 좌석을 예약 할 수 있습니다. 앱은 TypeScript로 작성되며 새로운 기능을 사용할 수 있습니다.[SQLite 저장 backend 에 튼튼한 개체](/durable-objects/best-practices/access-durable-objects-storage/#sqlite-storage-backend)데이터를 저장합니다.

Durable Objects를 사용하여 여러 클라이언트에 대한 조정 및 상태 관리를 처리 할 수있는 재사용 가능한 코드를 작성할 수 있습니다. 또한 Durable Objects의 SQLite에 데이터를 작성하고 로컬 디스크를 사용하므로 모든 쿼리는 훌륭한 성능으로 실행됩니다. Durable Objects에서 SQLite 저장소에 대해 자세히 알아볼 수 있습니다.[Durable Objects 블로그 게시물에 SQLite](https://blog.cloudflare.com/sqlite-in-durable-objects).

:::note\[Durable Objects에서 SQLite]

Durable Objects의 SQLite는 현재 베타에 있습니다. Durable Objects에서 SQLite의 제한에 대해 자세히 알아볼 수 있습니다.[Durable Objects 문서의 SQLite](/durable-objects/best-practices/access-durable-objects-storage/#sqlite-storage-backend).

:::

신청은 다음과 같이 작용할 것입니다:

- 사용자는 쿼리 매개 변수로 전달된 비행 번호로 응용 프로그램을 탐색합니다.
- 이 응용 프로그램은 비행 번호를위한 새로운 튼튼한 개체를 만들 것입니다, 이미 존재하지 않는 경우.
- 튼튼한 개체가 이미 존재하는 경우, 응용 프로그램은 SQLite 데이터베이스에서 좌석 정보를 검색합니다.
- 튼튼한 개체가 존재하지 않는 경우, 응용 프로그램은 새로운 튼튼한 개체를 만들고 좌석 정보와 SQLite 데이터베이스를 초기화합니다. 이 튜토리얼의 목적을 위해 좌석 정보는 응용 프로그램에 하드 코딩됩니다.
- 사용자가 좌석을 선택하면 응용 프로그램은 이름을 요청합니다. 이 응용 프로그램은 좌석을 예약하고 SQLite 데이터베이스의 이름을 저장합니다.
- 이 응용 프로그램은 모든 고객에게 좌석의 변경 사항을 방송합니다.

시작하기를하자!

2. 추가하기`initializeSeats()`기능에`Flight`수업. 이 기능은 튼튼한 목표가 초기화될 때 호출될 것입니다. 테이블이 존재하지 않는 경우, 그것을 만들 것입니다. 테이블에 좌석 정보를 삽입합니다.

이 튜토리얼의 기능은 모든 항공편의 동일한 좌석 계획을 만듭니다. 그러나, 생산에서, 당신은 비행 유형에 근거를 둔 좌석을 삽입하는 이 기능을 업데이트하고 싶습니다.

수정하기`Flight`다음 코드 클래스:

```ts title="src/index.ts"
import { DurableObject } from "cloudflare:workers";

export class Flight extends DurableObject {
	sql = this.ctx.storage.sql;

	constructor(ctx: DurableObjectState, env: Env) {
		super(ctx, env);
		this.initializeSeats();
	}

	private initializeSeats() {
		const cursor = this.sql.exec(`PRAGMA table_list`);

		//테이블이 존재하는 경우 확인.
		if ([...cursor].find((t) => t.name === "seats")) {
			console.log("Table already exists");
			return;
		}

		this.sql.exec(`
				  CREATE TABLE IF NOT EXISTS seats (
					seatId TEXT PRIMARY KEY,
					occupant TEXT
				  )
				`);

		//이 데모의 경우 테이블을 60 석으로 교체합니다.
		//SQLite가 DOs가 빠르기 때문에 거래에서 일괄 처리 대신 INSERT 당 쿼리를 할 수 있습니다.
		for (let row = 1; row <= 10; row++) {
			for (let col = 0; col < 6; col++) {
				const seatNumber = `${row}${String.fromCharCode(65 + col)}`;
				this.sql.exec(`INSERT INTO seats VALUES (?, null)`, seatNumber);
			}
		}
	}
}
```

4. Next, Worker의 fetch 핸들러를 업데이트하여 각 항공편의 독특한 내구성을 만듭니다.

```ts title="src/index.ts"
export default {
	async fetch(request, env, ctx): Promise<Response> {
		//쿼리 매개 변수에서 비행 ID를 가져옵니다
		const url = new URL(request.url);
		const flightId = url.searchParams.get("flightId");

		if (!flightId) {
			return new Response(
				"Flight ID not found. Provide flightId in the query parameter",
				{ status: 404 },
			);
		}

		const stub = env.FLIGHT.getByName(flightId);
		return stub.fetch(request);
	},
} satisfies ExportedHandler<Env>;
```

쿼리 매개 변수에서 비행 ID를 사용하여 고유 한 튼튼한 개체가 생성됩니다. 이 튼튼한 목표는 존재하지 않는 경우 테이블로 초기화됩니다.

## 4. 내구재 목표에 방법을 추가하십시오

1. 추가하기`getSeats()`기능에`Flight`수업. 이 기능은 테이블에 모든 좌석을 반환합니다.

```ts title="src/index.ts" {8-22}
import { DurableObject } from "cloudflare:workers";

export class Flight extends DurableObject {
    ...

	private initializeSeats() {
		...
	}

	//모든 좌석을 얻으십시오.
	getSeats() {
		let results = [];

		//Query는 커서를 반환합니다.
		let cursor = this.sql.exec(`SELECT seatId, occupant FROM seats`);

		//Cursors는 iterable입니다.
		for (let row of cursor) {
			//각 행은 각 열의 속성을 가진 객체입니다.
			results.push({ seatNumber: row.seatId, occupant: row.occupant });
		}

		return results;
	}
}
```

2. 추가하기`assignSeat()`기능에`Flight`수업. 이 기능은 승객에게 좌석을 할당합니다. 좌석 번호와 여객 이름이 매개 변수로 걸립니다.

```ts title="src/index.ts" {13-48}
import { DurableObject } from "cloudflare:workers";

export class Flight extends DurableObject {
	...

	private initializeSeats() {
		...
	}

	//모든 좌석을 얻으십시오.
	getSeats() {
		...
	}

	//승객에게 좌석을 할당합니다.
	assignSeat(seatId: string, occupant: string) {
		//해당 좌석은 점유하지 않습니다.
		let cursor = this.sql.exec(
			`SELECT occupant FROM seats WHERE seatId = ?`,
			seatId,
		);
		let result = cursor.toArray()[0]; //커서에서 첫 번째 결과를 가져옵니다.

		if (!result) {
			return {message: 'Seat not available',  status: 400 };
		}
		if (result.occupant !== null) {
			return {message: 'Seat not available',  status: 400 };
		}

		//점유가 이미 다른 좌석에 있다면 제거하십시오.
		this.sql.exec(
			`UPDATE seats SET occupant = null WHERE occupant = ?`,
			occupant,
		);

		//좌석 할당. 참고 : 동시 요청이 발생할 수 있음을 걱정할 필요가 없습니다.
		//코드가 비동기이기 때문에 두 개의 쿼리 사이의 자리를 잡아
		//(`await`s 없음) 그리고 데이터베이스는 이 튼튼한 목표에 개인적입니다. 다른 것
		//좌석이 이전에 사용할 수 있는지 확인했기 때문에 변경 될 수 있습니다!
		this.sql.exec(
			`UPDATE seats SET occupant = ? WHERE seatId = ?`,
			occupant,
			seatId,
		);

		//업데이트 된 좌석 방송.
		this.broadcastSeats();
		return {message: `Seat ${seatId} booked successfully`, status: 200 };
	}
}
```

위 함수는`broadcastSeats()`업데이트 된 좌석을 모든 연결된 고객에게 방송 할 수있는 기능. 다음 섹션에서 우리는 추가 할 것이다`broadcastSeats()`기능.

## 5. 손잡이 WebSocket 연결

모든 클라이언트는 WebSockets를 사용하여 내구성 객체에 연결됩니다. 튼튼한 목표는 모든 연결된 고객에게 업데이트 된 좌석을 방송합니다. UI를 실시간으로 업데이트할 수 있습니다.

1. 추가하기`handleWebSocket()`기능에`Flight`수업. 이 기능은 WebSocket 연결을 처리합니다.

```ts title="src/index.ts" {18-26}
import { DurableObject } from "cloudflare:workers";

export class Flight extends DurableObject {
	...

	private initializeSeats() {
		...
	}

	//모든 좌석을 얻으십시오.
	getSeats() {
		...
	}

	//승객에게 좌석을 할당합니다.
	assignSeat(seatId: string, occupant: string) {
		...
	}

  private handleWebSocket(request: Request) {
		console.log('WebSocket connection requested');
		const [client, server] = Object.values(new WebSocketPair());

		this.ctx.acceptWebSocket(server);
		console.log('WebSocket connection established');

		return new Response(null, { status: 101, webSocket: client });
	}
}
```

2. 추가하기`broadcastSeats()`기능에`Flight`수업. 이 기능은 모든 연결된 클라이언트에게 업데이트 된 좌석을 방송합니다.

```ts title="src/index.ts" {22-24}
import { DurableObject } from "cloudflare:workers";

export class Flight extends DurableObject {
	...

		...
	}

	//모든 좌석을 얻으십시오.

		...
```

3. 다음, 업데이트`fetch`핸들러`Flight`수업. 이 핸들러는 Worker에서 모든 들어오는 요청을 처리하고 WebSocket 연결을 사용하여 처리합니다.`handleWebSocket()`방법.

4. 마지막으로, 업데이트`fetch`노동자의 핸들러.

```ts title="src/index.ts" {8-23}
export default {
	...

	async fetch(request, env, ctx): Promise<Response> {
		//쿼리 매개 변수에서 비행 ID를 가져옵니다
		...

		if (request.method === "GET" && url.pathname === "/seats") {
			return new Response(JSON.stringify(await stub.getSeats()), {
				headers: { 'Content-Type': 'application/json' },
			});
		} else if (request.method === "POST" && url.pathname === "/book-seat") {
			const { seatNumber, name } = (await request.json()) as {
				seatNumber: string;
				name: string;
			};
			const result = await stub.assignSeat(seatNumber, name);
			return new Response(JSON.stringify(result));
		} else if (request.headers.get("Upgrade") === "websocket") {
			return stub.fetch(request);
		}

		return new Response("Not found", { status: 404 });
	},
} satisfies ExportedHandler<Env>;
```

더 보기`fetch`Worker의 핸들러는 들어오는 요청을 처리하기 위해 적절한 튼튼한 개체 함수를 호출합니다. 요청이 있는 경우`GET`지원하다`/seats`, 노동자는 튼튼한 목표에서 좌석을 반환합니다. 요청이 있으면`POST`지원하다`/book-seat`, 노동자 호출`bookSeat`튼튼한 개체의 방법 좌석을 여객에 할당합니다. 요청이 WebSocket 연결이라면, 튼튼한 개체는 WebSocket 연결을 처리합니다.

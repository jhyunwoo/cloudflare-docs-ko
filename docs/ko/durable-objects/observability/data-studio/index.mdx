각 튼튼한 목표는 개인적인 저장을 사용하여 접근할 수 있습니다[저장 API](/durable-objects/api/sqlite-storage-api/)이용안내`ctx.storage`. 객체의 저장된 데이터에보고 쓰기하려면 Durable Objects Data Studio를 Cloudflare QXQ QXQX대시보드XQ에서 사용할 수 있는 UI 편집기로 사용할 수 있습니다.

:::note\[SQLite-backed 개체에서만 지원되는 데이터 스튜디오]

Data Studio를 사용하여 데이터에 액세스할 수 있습니다.[SQLite 백업 Durable Objects](/durable-objects/best-practices/access-durable-objects-storage/#create-sqlite-backed-durable-object-class).

순간에, 당신은 단지 읽기 / 쓰기 데이터 persisted 사용[SQL API를](/durable-objects/api/sqlite-storage-api/#sql-api). KV API를 이용하여 Key-value data persisted는 앞으로 읽기 전용으로 만들 것입니다.
주요 특징

## Data Studio 보기

당신은 적어도해야`Workers Platform Admin` [이름 \*](/fundamentals/manage-members/roles/)Data Studio에 액세스합니다.

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**모델 번호: Durable Objects**사이트 맵

     <DashButton url="/?to=/:account/workers/durable-objects" />
  2. 기존의 튼튼한 오브젝트 네임스페이스를 선택합니다.
  3. 선택하기**데이터 스튜디오**버튼.
  4. 튼튼한 개체 식별자를 제공, 사용자 정의[이름 \*](/durable-objects/api/namespace/#getbyname)또는 Cloudflare 생성[튼튼한 목표 ID](/durable-objects/api/id/).
</Steps>

- Data Studio가 실행한 쿼리는 원격, 배포된 객체 및 incur에 요청을 보냅니다.[사용 청구](/durable-objects/platform/pricing/)요청에 대한, 지속, 행 읽기 및 열 작성. Data Studio를 사용하여 생산, 실행 개체를 처리해야합니다.
- 내 계정**글쓰기**모든 진술을 실행할 때 탭, 각 SQL 문은 별도의 튼튼한 목표 요구로 보내집니다.

## 감사 로깅

Data Studio가 발행한 모든 쿼리는 로그인되어 있습니다.[감사 로깅 v1](/fundamentals/account/account-security/review-audit-logs/)보안 및 준수 요구 사항.

- 각 쿼리는 두 감사 로그를 방출, a`query executed`활동과 a`query completed`쿼리 성공 또는 실패를 나타내는 행동.`query_id`로그 이벤트에서 쿼리 당 두 개의 이벤트를 구성 할 수 있습니다.

<GlossaryTooltip term="Durable Object">모델 번호: Durable Objects</GlossaryTooltip>튼튼한 Object namespace-level 및 request-level metrics에 대한 분석.

표시된 미터[Cloudflare대시보드](https://dash.cloudflare.com/)차트는 Cloudflare의 queried[GraphQL 분석 API](/analytics/graphql-api/). 미터에 접근할 수 있습니다[GraphQL을 통해 프로그래밍](#query-via-the-graphql-api)또는 HTTP 클라이언트.

:::노트\[Durable Object namespace]

튼튼한 오브젝트 네임스페이스는 Durable Objects의 집합이며, 동일한 클래스에 의해 뒷받침된 이름을 지정할 수 있습니다. 클래스당 하나의 튼튼한 오브젝트 네임스페이스만 있습니다. 튼튼한 목표 네임스페이스는 Durable Objects의 번호를 포함할 수 있습니다.
주요 특징

## 통계 및 분석

Durable Objects의 Per-namespace 분석은 Cloudflare 대시보드에서 유효합니다. namespace의 현재와 역사적인 메트릭스를 볼 수 있습니다.

<Steps>
  1. Cloudflare 대시보드에서, 가십시오**Durable Objects**사이트 맵

     <DashButton url="/?to=/:account/workers/durable-objects" />
  2. 계정 수준 Durable Objects 사용법 보기.
  3. 기존의 튼튼한 오브젝트 네임스페이스를 선택합니다.
  4. 선택하기**미터**탭.
</Steps>

쿼리에 시간 창을 선택 할 수 있습니다. 이 기본값은 마지막 24시간입니다.

## 로그아웃

Cloudflare 대시보드XQ에서 튼튼한 목표 로그를 볼 수 있습니다. 로그는 스크립트 이름과 튼튼한 개체 클래스 이름에 의해 집계됩니다.

튼튼한 개체 로깅을 사용하여 시작하려면:

<Steps>
  1. WranglerXQ 구성 파일에서 튼튼한 개체 클래스를 정의하는 작업자의 사용 가능
     <WranglerConfig>
       ```jsonc
       {
           "observability": {
               "enabled": true
           }
       }
       ```
     </WranglerConfig>
  2. 업데이트 된 바인딩으로 Worker의 최신 버전을 배포합니다.
  3. 오시는 길**모델 번호: Durable Objects**사이트 맵

     <DashButton url="/?to=/:account/workers/durable-objects" />
  4. 기존의 튼튼한 오브젝트 네임스페이스를 선택합니다.
  5. 선택하기**로그인**탭.
</Steps>

:::참조
로그 제한에 대한 정보 (최대 로그 유지 기간과 같은), 참조[Workers 비밀번호](/workers/observability/logs/workers-logs/#limits).
:::

## GraphQL API를 통해 쿼리

튼튼한 목표 미터는 GraphQL에 의해 강화됩니다.

튼튼한 Object metrics를 포함하는 datasets는 다음을 포함합니다:

- `durableObjectsInvocationsAdaptiveGroups`
- `durableObjectsPeriodicGroups`
- `durableObjectsStorageGroups`
- `durableObjectsSubrequestsAdaptiveGroups`

제품 정보[GraphQL 소개](/analytics/graphql-api/features/discovery/introspection/)각 데이터셋에 노출된 필드에 대한 정보를 얻을 수 있습니다.

### WebSocket 미터

Durable Objects 사용[웹소켓](/durable-objects/best-practices/websockets/)WebSockets가 다른 유형의 요청을 가지고 있기 때문에 여러 GraphQL 데이터 세트에서 요청 메트릭을 볼 수 있습니다.

- WebSocket 연결에 대한 미터 자체가 표현됩니다.`durableObjectsInvocationsAdaptiveGroups`연결이 닫습니다. WebSocket 연결이 길기 때문에 연결은 종종 내구성 객체가 종료 될 때까지 종료하지 않습니다.
- WebSocket 연결의 WebSocket 메시지 수신 및 전송을위한 미터는 사용할 수 있습니다`durableObjectsPeriodicGroups`. WebSocket 연결이 사용하는 경우[웹소켓 Hibernation](/durable-objects/best-practices/websockets/#websocket-hibernation-api)WebSocket 메시지가 나타날 때`durableObjectsInvocationsAdaptiveGroups`.

## Durable Objects

```js
  viewer {
    /*계정 태그와 교체, 어떤 URL의 시작 부분에 볼 32 hex 문자 ID
dash.cloudflare.com 또는 Workers & Pages 개요의 사이드 바에 "Account ID"의 밑에 로그인 할 때*/
    accounts(filter: {accountTag: "your account tag here"}) {
      //최근 날짜를 대체
      durableObjectsInvocationsAdaptiveGroups(filter: {date_gt: "2023-05-23"}, limit: 1000) {
        sum {
          //introspection을 통해 발견된 다른 분야는 여기에서 추가될 수 있습니다
          requests
          responseBodySize
        }
      }
      durableObjectsPeriodicGroups(filter: {date_gt: "2023-05-23"}, limit: 1000) {
        sum {
          cpuTime
        }
      }
      durableObjectsStorageGroups(filter: {date_gt: "2023-05-23"}, limit: 1000) {
        max {
          storedBytes
        }
      }
    }
  }
```

더 알아보기[질문 Workers GraphQL를 가진 미터](/analytics/graphql-api/tutorials/querying-workers-metrics/)인증을위한 자습서 및 Workers 데이터 세트에 대해 자세히 알아 보려면.

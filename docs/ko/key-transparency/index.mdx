<Description>
  엔드 투 엔드 암호화 (E2EE) 메시징 시스템에서 공공 키의 배포를 확보
</Description>

Cloudflare's Key Transparency Auditor는 엔드 투 엔드 암호화 (E2EE) 메시징 시스템에 대한 공공 키의 배포를 확보하는 것을 목표로[WhatsApp에](https://engineering.fb.com/2023/04/13/security/whatsapp-key-transparency/). 로그라고 불리는 verifiable append-only 데이터 구조를 구축하여 이것을 달성한다.[인증서 투명성](https://developer.mozilla.org/en-US/docs/Web/Security/Certificate_Transparency).

Cloudflare는 Key Transparency Logs의 감사로 엔드 투 엔드 암호화 메시징 공개 키의 투명성을 보장한다. Cloudflare는 우리가 수행하는 검증 작업을 모니터링하고 로컬로 연결된 로그의 상태를 확인합니다.

## 관련 제품

  인증서 투명성 (CT) 모니터링은 도메인에 발급 된 SSL / TLS 인증서를 이중 검사 할 수 있도록하여 보안을 개선하는 것을 목표로 공공 베타의 선택 기능입니다.
</RelatedProduct>

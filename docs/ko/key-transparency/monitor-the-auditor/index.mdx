Cloudflare's Key Transparency Auditor는 Log Audit proofs를 검증하고 서명을 제공합니다. 로그는 그 최종 사용자에게 이러한 서명을 배포 할 수 있으며, 키가 타락되지 않은 신뢰를 사용자에게 제공합니다.

우리의 일을 확인하기 위해, 당신은 사용할 수 있습니다[프로젝트](https://github.com/cloudflare/plexi), 누군가가 공공을 통해 증거 검증을 로컬로 수행 할 수있는 CLI 도구[사이트맵](/key-transparency/api/).

## 주요 특징

- 서명의 인증, 주어진 공공 키에 의해 서명 된 확인
- 유효성 검증[페이스북](https://github.com/facebook/akd)인증현황
- List는 감사 모니터를 로그

## 설치하기

| 환경 정책                                                       | CLI 명령                |
| :---------------------------------------------------------- | :-------------------- |
| [제품정보](https://www.rust-lang.org/tools/install)(Rust 1.81+) | `cargo install plexi` |

## 제품 정보

사용 방법`--help`명령과 옵션에 대한 자세한 내용은 옵션.

```bash
plexi [OPTIONS] <COMMAND>
```

### 당신의 감사 리모트를 구성하십시오

`plexi`기본 원격 감사관과 함께 제공되지 않습니다, 당신은 당신의 자신의 선택해야합니다.

당신은 통과해서 이렇게 할 수 있습니다`--remote-url=<REMOTE>`또는 설정`PLEXI_REMOTE_URL`환경 변수.

일반적인 리모트는 아래에 제공됩니다:

| 이름 \*  | 원격 제어                                           |
| :----- | :---------------------------------------------- |
| '클라우드' | `https://plexi.key-transparency.cloudflare.com` |

자신의 감사를 배포 한 경우, 당신은 원격을 추가 할 수 있습니다[GitHub 문제](https://github.com/cloudflare/plexi/issues).

### 표시된 로그

감사관은 한 번에 여러 로그를 모니터링합니다. 감사자가 감시하는 것을 발견하려면 다음을 실행하십시오.

```shell
plexi ls --remote-url 'https://plexi.key-transparency.cloudflare.com'
whatsapp.key-transparency.v1
```

### 서명 감사

epoch 고유성을 보장하고 관련 증명을 검증하여 Log validity에 대한 Key Transparency Auditor vouches.

`plexi audit`주어진 epoch 및 그것의 유효성에 대한 정보를 제공합니다. 감사의 행동을 확인하는 로컬 감사를 수행 할 수 있습니다.

예를 들어, Cloudflare Auditor가 감사한 WhatsApp Log를 확인하려면 다음을 실행하십시오.

```shell
> plexi audit --remote-url 'https://plexi.key-transparency.cloudflare.com' --namespace 'whatsapp.key-transparency.v1' --long
```

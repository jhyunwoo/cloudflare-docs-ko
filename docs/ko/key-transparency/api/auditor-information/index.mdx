심사원은 심사원, epoch 번호 및 epoch digest에 의해 접수되는 시간을 포함하는 epoch 정보를 서명하도록 설계되었습니다. Auditor serializes this information in binary using protobuf or bincode and checks the required inclusion is valid, as in it satisfies[출판 constraints](/key-transparency/api/epochs/#constraints).

로그인이 설정되면[사이트맵](https://github.com/facebook/akd)감사 증거, 감사는 그들을 비동기적으로 정의합니다.

## 감사정보

`keys`열쇠 교체를 위해 나중에 허용한 강당 공중 열쇠를 포함합니다.

```sh
curl 'https://plexi.key-transparency.cloudflare.com/info'
{
  "keys": [
    {
      "public_key": "d1036a33a8731e82a29dc68210988b32b60b7c1bd22d2341f2e339f4db3a2f4a",
      "not_before": 1712311441501
    }
  ],
  "logs": [
    "508607faff7cb16be841e901eca41a6239461f239e7e610c9ea2576f334bc144"
  ]
}
```

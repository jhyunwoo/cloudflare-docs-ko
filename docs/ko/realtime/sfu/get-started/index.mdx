## 첫 앱 만들기

모든 Realtime App은 별도의 환경이므로 제품 개발을 위해 개발, staging 및 생산 버전을 만들 수 있습니다.
이름 \*[대시보드](https://dash.cloudflare.com/?to=/:account/realtime/sfu), 또는[사이트맵](/api/resources/calls/subresources/sfu/methods/create/)Realtime 앱을 만듭니다. Realtime App을 만들 때, 다음을 얻을 것이다:

- 앱 ID
- 앱 비밀

이 두 개의 결합은 백엔드 서버에서 Realtime을 만들 수 있습니다.

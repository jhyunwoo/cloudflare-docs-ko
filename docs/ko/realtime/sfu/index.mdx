<Description>
  실시간 Serverless 비디오, 오디오 및 데이터 애플리케이션 구축
</Description>

모델 번호: Cloudflare Realtime SFU는 실시간 오디오/비디오/데이터 애플리케이션을 위한 인프라입니다. 사기 또는 지역에 대해 걱정 없이 실시간 앱을 구축할 수 있습니다. 그것은 선택적 운송 단위 (WebRTC SFU), 방송을위한 팬 아웃 배달 시스템 (WebRTC CDN) 또는간에 아무것도.

모델 번호: Cloudflare 실시간 SFU 실행[Cloudflare의 글로벌 클라우드 네트워크](https://www.cloudflare.com/network/)전세계 수백 도시에서.

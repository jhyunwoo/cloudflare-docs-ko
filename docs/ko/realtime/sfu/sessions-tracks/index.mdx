Cloudflare Realtime은 실시간 경험을 구축하기 위한 간단하고 강력한 프레임워크를 제공합니다. 이 체계의 핵심은 3개의 중요한 개념입니다:**이름 \***,  **교육과정**·**제품정보**. 이 개념과 자신감은 Realtime을 사용하는 것이 중요합니다.

## 제품 설명

Realtime Application은 다른 세션 내에서 환경이며 트랙은 상호 작용할 수 있습니다. 이 예제는 세션과 트랙 사이에 분리 할 수있는 생산, staging 또는 다른 환경이 될 수 있습니다. Cloudflare 실시간 사용은 애플리케이션, 세션 또는 트랙 레벨에서 queried 수 있습니다.

## 교육과정

·**회사연혁**Cloudflare Realtime은 WebRTC PeerConnection에 직접 상관합니다. 그것은 클라이언트와 가장 가까운 Cloudflare 데이터 센터 사이에 통신 채널의 설립을 나타냅니다, Cloudflare의 anycast 여정에 의해 결정. 일반적으로 고객은 단일 세션을 유지하고 클라이언트와 Cloudflare 사이의 모든 통신을 우회합니다.

- **PeerConnection을 가진 원-to-One Mapping**: 각 세션은 WebRTC PeerConnection의 직접 표현이며 실시간 미디어 데이터 전송을 촉진합니다.
- **전체장편**: 고객은 가까운 Cloudflare 데이터 센터에 연결하여 대기시간과 성능을 최적화합니다.
- **통합 통신 채널**: 단일 세션은 클라이언트와 Cloudflare 사이의 모든 종류의 통신을 처리 할 수 있으며 유선 데이터 흐름을 보장합니다.

## 제품정보

세션 내에서, 하나 이상의**제품정보**.

- **MediaStreamTrack에 지도를 추적**: MediaStreamTrack 개념과 일치하여 오디오, 비디오 또는 데이터 전송을 촉진합니다.
- **글로벌 고유 Ids**: Cloudflare에 대한 트랙을 푸시하면 다른 세션으로 트랙을 끌어올릴 수 있습니다.
- **글로벌 서비스**: 푸시 및 풀 트랙의 능력은 실시간 응용 프로그램에 대한 다양한 도구를 만드는 것입니다. 각 트랙은 전 세계적으로 App 내의 모든 세션에서 검색할 수 있습니다.

## 풀그릴 "Switchboard"로 Realtime

Switchboard의 아날로그는 Realtime을 이해하기 위해 apt입니다. 역사적으로, 스위치 보드 운영자는 잭에서 수동으로 플러그 링하여 통화를 연결. 마찬가지로 Realtime은 미디어 스트림의 동적 라우팅을 허용하고 현대 실시간 통신을위한 프로그래밍 가능한 스위치 보드 역할을합니다.

## Beyond "Rooms", "사용자", 그리고 "파트너"

많은 SFUs는 사용자가 미디어 스트림을 관리하기 위해 "방"과 같은 개념을 활용하지만,이 접근법은 확장성 및 유연성 제한이 있습니다. 모델 번호: Cloudflare Realtime은 세션과 트랙을 통해 더 많은 과립 및 유연한 모델을 선택하여 다양한 사용 사례를 제공합니다.

- 수천 명의 참가자와 함께 '불사이드 채팅'과 같은 대규모 원격 이벤트.
- 관객과의 대화 "단계에서"
- 강사가 동시에 여러 가상 교실을 제시 할 수있는 교육 응용 프로그램입니다.

### Presence Protocol vs. 미디어 흐름

Realtime은 기존의 프로토콜과 미디어 흐름을 구별하며 실시간 애플리케이션에서 확장성과 유연성을 제공합니다. 이 분리는 개발자가 친밀한 통화에서 대규모 저전력 방송에 이르기까지 맞춤형 경험을 제공합니다.

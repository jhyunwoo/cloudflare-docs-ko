Cloudflare 실시간 오디오, 비디오 및 데이터를 응용 프로그램에 추가하는 데 사용할 수 있습니다. Cloudflare Realtime은 브라우저, 모바일 및 네이티브 앱과 같은 광범위한 플랫폼에서 통신하는 가장 낮은 대기 시간 방법입니다.

Realtime은 실시간 기능을 추가하기 위해 백엔드 및 프론트엔드 애플리케이션과 통합됩니다.

## 왜 Cloudflare 실시간 존재

- **WebRTC를 확장하는 것은 어렵습니다.**: 많은 투쟁은 WebRTC 서버를 사기. 운영자는 같은 "룸"에있을 수있는 방법에 대한 문제로 실행하거나 높은 수준의 API의 현재 개념에 적합하지 않는 독특한 솔루션을 구축 할 수 있습니다.

- **높은 egress 비용**: WebRTC는 클라우드 egress에서 높은 프리미엄을 충전하고 자체 서버 incur 시스템 관리 및 스케일링 오버 헤드를 실행하는 관리 솔루션으로 사용됩니다. Cloudflare는 이미 몇몇 위치에 있는 1,000의 서버로 300+ 위치가 있습니다. Cloudflare Realtime Scales는 이 아키텍처의 상단에 쉽게 확장하고 가장 낮은 WebRTC 사용 비용을 제공 할 수 있습니다.

- **WebRTC 성장**: 개발자는 WebRTC가 비디오 conferencing을 위해 아닙니다. WebRTC는 많은 플랫폼에서 지원되며 성숙하고 잘 이해됩니다.

## Cloudflare 실시간 고유

- **분류되지 않음**: Cloudflare Realtime은 SDK를 제공하지 않습니다. 대신 Raw WebRTC에 액세스하여 기존 개념에 적합하지 않을 수있는 독특한 문제를 해결 할 수 있습니다. API는 deliberately 간단합니다.

- **객실 수**: 다른 WebRTC 제품과 달리 Cloudflare Realtime은 객실과 같은 요약을 제공하는 대신 각 트랙 (audio/video/data)의 충전을 할 수 있습니다. 간단한 pub/sub의 상단에 존재 프로토콜을 정의합니다. 각 최종 사용자는 오디오 / 비디오 / 데이터 트랙에 게시하고 구독 할 수 있습니다.

- **자물쇠에서**: Cloudflare SFU와 확장성 문제를 해결하는 실시간. 피어 투 피어 아키텍처와 함께 사용할 수 있습니다. Cloudflare Realtime 독립을 사용할 수 있습니다. Cloudflare 현실은 당신까지 입니다.

## Cloudflare 실시간?

- **사이트맵**: Realtime은 특정 데이터를 구독하는 고객에게 전달 미디어 데이터에 좋은 pub/sub 서버의 특별한 종류입니다. 각 클라이언트는 Cloudflare에 연결합니다 Realtime via WebRTC and one sends data, 수신 데이터 또는 둘 다 WebRTC. 이것은 오디오/영상 궤도 또는 DataChannels일 수 있습니다.

- **그것은 가늠자**: 모든 Cloudflare 서버는 단일 서버로 웹RTC 클라이언트의 수백만은 Cloudflare Realtime에 연결할 수 있습니다. 각은 자료를 보낼 수 있습니다, 다른 클라이언트와 자료 또는 둘 다.

## 대부분의 개발자 get started

1. Cloudflare dashboardXQ에서 Realtime App을 만들 때 echo 예제로 시작하십시오.[데모](/realtime/sfu/demos/). 이것은 당신에게 오디오와 영상을 보내고 받는 방법을 보여줄 것입니다.

2. 세션 및 트랙 ids를 통과하여 미디어를 수신 할 수있는 조작 방법을 이해하십시오. 기억하십시오, 당신은 어떤 매체를 받는 사람을 통제합니다. 각 미디어 트랙은 고유 ID로 표시됩니다. 이 ID를 저장하고 배포하는 책임입니다.

:::note\[Realtime은 존재 프로토콜이 아닙니다]
Realtime은 방이 무엇인지 알 수 없습니다. 미디어 트랙만 알고 있습니다. 미디어 트랙을 식별하는 트랙 ID와 함께 방에서 누구를 저장함으로써 방을 만들 수 있습니다. 각 참가자가 오디오 / 비디오를 출판하고 서로의 오디오 / 비디오를 수신하면 비디오 회의를 직접 가지고 있습니다!

3. 각 연결을 Cloudflare Realtime과 각 연결에 의해 생성 된 트랙 ID로 관리하는 앱을 만듭니다. 모든 도구를 사용하여 저장 및 공유 트랙을 사용할 수 있습니다. 앱 보기[데모](/realtime/sfu/demos/), 등[오렌지 대회](https://github.com/cloudflare/orange), 사용하는 full-fledged video conferencing 응용 프로그램입니다[Workers Durable Objects](/durable-objects/)트랙 ID를 보관하십시오.

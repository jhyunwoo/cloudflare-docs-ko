1. 클라이언트는 백엔드 서비스에 연결
2. 백엔드 서비스는 클라이언트와 트랙 간의 관계를 관리하여 가입해야 합니다.
3. 백엔드 서비스는 Cloudflare Realtime API에 연락하여 클라이언트에서 SDP를 WebRTC 연결을 설정합니다.
4. Realtime API는 Realtime API SDP 응답과 renegotiation 메시지를 다시 릴레이합니다.
5. 원하는 경우, headless 클라이언트는 다른 클라이언트 또는 게시 내용에서 콘텐츠를 기록하는 데 사용할 수 있습니다.
6. 관리자는 객실과 룸 회원을 관리합니다.

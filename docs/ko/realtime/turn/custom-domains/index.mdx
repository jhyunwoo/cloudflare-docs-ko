Cloudflare Realtime TURN 서비스는 UDP 및 TCP에 대한 사용자 정의 도메인을 사용하여 지원하지만 TLS 프로토콜이 아닙니다. 사용자 정의 도메인은 Cloudflare Realtime TURN의 성능에 영향을 미치지 않으며 도메인에 간단한 CNAME DNS 레코드를 통해 설정됩니다.

| 프로젝트      | 주문 영역 | 1 차 항구    | 공급 능력       |
| --------- | ----- | --------- | ----------- |
| UDP에 STUN | ✅     | 3478 / 초  | 53/두프       |
| UDP에 TURN | ✅     | 3478 / 초  | 53 그라프      |
| TCP에 TURN | ✅     | 3478 / 탭  | 80/tcp의     |
| TURN에 TLS | 이름 \* | 5349/tcp의 | 크기: 443/tcp |

## CNAME 레코드 설정

TURN에 대한 사용자 정의 도메인을 사용하려면 CNAME DNS 레코드를 작성해야합니다.`turn.cloudflare.com`.

:::카트로션

해결하지 마십시오`turn.cloudflare.com`또는`stun.cloudflare.com`또는 DNS 레코드에 입력된 값으로 IP 주소를 사용합니다. CNAME 레코드만 지원됩니다.

:::

Cloudflare DNS를 포함한 모든 DNS 제공 업체는 사용자 정의 도메인의 CNAME을 설정하는 데 사용할 수 있습니다.

:::참조

Cloudflare의 권위있는 DNS 서비스가 사용되는 경우 기록은 설정해야합니다.[DNS 전용 또는 "회색 클라우드"모드](/dns/proxy-status/#dns-only-records).\`

:::

Cloudflare Realtime TURN을 사용하여 사용자 정의 호스트 이름을 사용하는 추가 요금이 없습니다.

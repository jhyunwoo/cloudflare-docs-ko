## TURN은 무엇입니까?

TURN (NAT 주변 릴레이를 사용하는 트레이버)는 네트워크 주소 번역기 (NATs) 또는 방화벽을 통해 피어 투 피어 통신을 용이하게하는 프로토콜입니다. STUN (Session Traversal Utilities for NAT) 프로토콜의 확장이며 정의됩니다.[RFC 8656년](https://datatracker.ietf.org/doc/html/rfc8656).

## 어떻게 TURN을 사용합니까?

웹 브라우저 또는 cURL을 사용하여 HTTP 프로토콜을 사용하려면 도구 또는 라이브러리를 사용하여 응용 프로그램에서 TURN 프로토콜을 사용합니다.

TURN의 대부분의 사용자는 브라우저 또는 브라우저의 일부와 같은 WebRTC 라이브러리의 일부로 사용합니다.[팟캐스트](https://github.com/pion/webrtc), [웹rtc-rs](https://github.com/webrtc-rs/webrtc)또는[다운로드](https://webrtc.googlesource.com/src/).

응용 프로그램에 직접 TURN을 사용할 수 있습니다.[팟캐스트](https://github.com/pion/turn)Golang의 TURN 클라이언트 라이브러리를 제공하므로[웹rtc-rs](https://github.com/webrtc-rs/webrtc/tree/master/turn)Rust에서.

## TURN을 이해할 때 알아야 할 중요한 개념

1. **NAT (네트워크 주소 번역)**: 라우터에 의해 사용되는 방법은 단일 공공 IP 주소로 여러 개인 IP 주소를 맵합니다. 이것은 일반적으로 홈 인터넷 라우터에 의해 수행 그래서 같은 네트워크에 여러 컴퓨터는 단일 공공 IP 주소를 공유 할 수 있습니다.

2. **TURN 서버**: NAT 뒤에 클라이언트 간의 트래픽을 위한 중급 서버. Cloudflare Realtime TURN 서비스는 TURN 서버의 예입니다.

3. **고객지원**: TURN 서버를 통해 통신하기 위해 TURN 프로토콜을 사용하는 응용 프로그램 또는 장치. 이것은 당신의 신청입니다. WebRTC API 또는 모바일 또는 데스크톱에서 실행되는 기본 응용 프로그램을 사용하여 웹 응용 프로그램입니다.

4. **회사 소개**: TURN 서버가 할당을 만들 때, TURN 서버는 IP와 그 클라이언트에 고유 한 포트를 보유합니다.

5. **릴레이 운송 주소**: 인터넷에 다른 사람이 TURN 서버에 IP 주소와 포트가 TURN 클라이언트에 데이터를 보낼 수 있도록 사용할 수 있도록 TURN 서버에서 예약.

## TURN 작품

1. TURN 클라이언트는 TURN 서버에 할당된 요청을 보냅니다.
2. TURN 서버는 할당을 생성하고 클라이언트에게 릴레이 전송 주소를 반환합니다.
3. 클라이언트는 그 동료에게이 릴레이 주소를 줄 수 있습니다.
4. 피어가 릴레이된 주소로 데이터를 보낼 때, TURN 서버는 클라이언트에게 전달합니다.
5. 클라이언트가 피어에 데이터를 보내려면 TURN 서버를 통해 전송합니다. 그런 다음 동료에게 전달합니다.

## TURN 대 VPN

TURN은 VPN과 유사합니다 (Virtual Private Network). 그러나 TURN 서버 및 VPN은 다른 목적으로 작동하며 다른 방법으로 작동합니다.

VPN은 장치에서 모든 인터넷 트래픽을 암호화하는 범용 도구이며, VPN 서버를 통해 프라이버시, 보안 및 익명성을 향상시킵니다. 네트워크 층에서 작동, 모든 인터넷 활동에 영향을, 종종 공공 Wi-Fi에 지리적 제한 또는 보안 연결을 우회하는 데 사용됩니다.

TURN 서버는 실시간 통신을 위해 특정 응용 프로그램에 의해 사용되는 전문 도구입니다. 애플리케이션 레이어에서 작동하며, 애플리케이션의 트래픽에 영향을 미치며, 동료 간의 직접 연결이 불가능할 때 트레버스 NAT 및 방화벽에 릴레이 역할을 합니다. VPN은 전반적인 인터넷 속도에 영향을 미치며 익명성을 제공합니다. TURN 서버는 특정 애플리케이션의 성능에 영향을 미칩니다.

## 왜 유용한 TURN?

TURN은 NAT 또는 방화벽 제한으로 인해 직접 피어 투 피어 통신이 불가능한 시나리오에서 종종 귀중합니다. 몇몇 중요한 이점은 여기 있습니다:

1. **NAT 트레이널**: TURN은 NAT 뒤에있는 동료들과의 연결을 설정하는 방법을 제공합니다. 그렇지 않으면 도전하거나 불가능합니다.

2. **방화벽 우회**: 엄격한 방화벽 정책을 가진 환경에서, TURN은 그렇지 않으면 차단될 커뮤니케이션을 가능하게 할 수 있습니다.

3. **일관된 연결성**: TURN은 직접 또는 NAT 보조 연결이 실패 할 때 신뢰할 수있는 낙하 방법을 제공합니다.

4. **제품 정보**: TURN 서버를 통해 트래픽을 릴레이함으로써, 통일 당사자의 실제 IP 주소는 서로 숨길 수 있습니다.

5. **VoIP 및 비디오 회의**: TURN은 IP (VoIP) 및 비디오 conferencing과 같은 응용 프로그램에 중요하며 네트워크 구성에 관계없이 신뢰할 수있는 연결을 보장합니다.

6. **온라인 게임**: TURN은 온라인 게임이 NAT의 다른 유형 뒤에 플레이어 사이의 피어 투 피어 연결을 설정할 수 있습니다.

7. **IoT 장치 통신**: Internet of Things (IoT) 장치는 NAT 또는 방화벽 뒤에 통신 할 때 TURN을 사용할 수 있습니다.

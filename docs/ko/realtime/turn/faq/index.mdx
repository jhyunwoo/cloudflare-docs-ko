## 주요사업

### Cloudflare Realtime TURN 가격이란 무엇입니까? 정확히 어떻게 계산됩니까?

Cloudflare TURN 가격은 TURN 클라이언트에 Cloudflare 가장자리에서 보내진 자료에 근거를 둡니다,[RFC 8656 숫자 1](https://datatracker.ietf.org/doc/html/rfc8656#fig-turn-model). TURN 서버에서 TURN 클라이언트로 보낸 데이터는 TURN 오버헤드를 포함한 모든 데이터를 캡처하고 성공적인 인증을 따르는 것입니다.

Cloudflare에 대한 가격 실시간 TURN 서비스는 GB 당 $0.05입니다.

Cloudflare의 STUN 서비스`stun.cloudflare.com`무료 및 무제한입니다.

모든 요금 시작 전에 1,000 GB의 무료 계층이 있습니다. Cloudflare 실시간 청구는 Cloudflare 청구서에 단일 라인 항목으로 표시되며 SFU 및 TURN을 모두 포함합니다.

Cloudflare Realtime TURN과 Cloudflare Realtime SFU 또는 CloudflareXQ Stream (WHIP/WHEP) 사이 교통은 어떤 책임든지 incur 아닙니다.

### Realtime TURN HIPAA/GDPR/FedRAMP는 호환됩니까?

Cloudflare[인증 및 준수 리소스](https://www.cloudflare.com/trust-hub/compliance-resources/)자세한 내용은 Cloudflare 기업 계정 관리자에게 문의하십시오.

### TURN이 WebRTC와 함께 사용할 때 Cloudflare 액세스 할 수있는 데이터는 무엇입니까?

언제 Cloudflare Realtime TURN은 WebRTC와 함께 사용되며 CloudflareXQ는 미디어의 내용을 릴레이 할 수 없습니다. WebRTC는 Datagram Transport Layer Security (DTLS) 암호화를 사용하므로 TURN 서버에 도달하기 전에 데이터 종료를 암호화합니다. 결과적으로 Cloudflare는 암호화 된 패킷을 릴레이하고 오디오, 비디오 또는 데이터 채널 정보를 포함 할 수있는 미디어 콘텐츠를 해독하거나 검사 할 수 없습니다.

데이터 개인 정보 보호 관점에서, 유일한 정보 Cloudflare 프로세스는 TURN 서비스 설정 및 릴레이 연결을 유지하기위한 메타 데이터입니다. TURN 클라이언트, 포트 번호 및 세션 타이밍 정보의 IP 주소가 포함되어 있습니다. Cloudflare는 암호화 된 미디어 스트림 내에서 포함 된 모든 개인 식별 정보에 액세스 할 수 없습니다.

이 아키텍처는 Cloudflare Realtime TURN은 참가자 간의 엔드 투 엔드 암호화를 유지합니다. Cloudflare는 암호화 된 콘텐츠에 가시성없이 중간 릴레이 서비스로만 기능합니다.

### 실시간 TURN 엔드 투 엔드 암호화?

TURN 프로토콜,[RFC 8656년](https://datatracker.ietf.org/doc/html/rfc8656), TLS에 TURN과 같은 래퍼 프로토콜을 넘어 암호화를 논의하지 않습니다. WebRTC에 TURN을 사용하는 경우 WebRTC 수준에서 데이터를 암호화합니다.

### Cloudflare Realtime TURN은 어떤 지역입니까?

모델 번호: Cloudflare 실시간 TURN 서버가 실행됩니다.[Cloudflare의 글로벌 네트워크](https://www.cloudflare.com/network)- Cloudflare의 주목할만한 예외를 가진 수백개의 위치에 걸쳐 배부된 수천대의 기계의 성장 세계적인 네트워크[중국 네트워크](/china-network/).

### Cloudflare Realtime TURN은 Cloudflare Backbone을 사용하거나 "magic"Cloudflare가 연결 속도를 높일 수 있습니까?

Cloudflare Realtime TURN 할당은 가장 가까운 유효한 Cloudflare 데이터 센터에서 TURN 클라이언트에게 공개됩니다. 연결의 두 끝이 Cloudflare Realtime TURN을 사용하는 경우에, CloudflareXQ는 routing를 통제할 수 있고, 가능한 경우에, Cloudflare 백본을 통해서 TURN 소포를 노선합니다.

### Cloudflare Realtime TURN의 차이는 기업 계획 대 셀프 서비스 (당신의 신용 카드로 지불) 계획?

Cloudflare 기업의 실시간 TURN 서비스 또는 셀프 서비스 계획, 그러나 그 위에[기업 계획](https://www.cloudflare.com/enterprise/)우선 지원, 예측 가능한 평평한 가격과 SLA 보증의 혜택을 얻을 것이다.

### Cloudflare Realtime TURN은 Cloudflare 중국 네트워크에서 실행됩니까?

Cloudflare의[중국 네트워크](/china-network/)중국에서 Realtime 트래픽 및 TURN 트래픽을 제공하는 것은 중국에서 Cloudflare 위치에 연결됩니다.

### 분석에서 사용할 수있는 TURN 활동에 대해 얼마나 걸리나요?

TURN 사용은 분석에서 30 초까지 보여줍니다.

## 제품정보

### 허용 목록 (화이트리스트) Cloudflare 실시간 TURN IP 주소. 어떤 IP 주소가 사용해야합니까?

Cloudflare Realtime TURN은 다른 공급자와 비교할 수 있기 때문에 엄격한 방화벽을 가지고 있는 IT 관리자가 사용하기 쉽습니다. IPv6 및 IPv4 주소를 모두 허용해야 합니다.

다음 IP 주소를 허용하십시오:

- `2a06:98c1:3200::1/128`
- `2606:4700:48::1/128`
- `141.101.90.1/32`
- `162.159.207.1/32`

:::caution\[IP 변경을 위한 배치]

Cloudflare는, 그러나 TURN 서비스에 사용된 IP 주소가 변화하지 않을 것이라는 점을 보증할 수 없습니다. IP 주소를 허용하고 기업 계약이없는 경우 DNS 응답을 변경하는 경고를 설정해야합니다.`turn.cloudflare.com`(A 및 AAAA 레코드) 및 DNS 변경의 14 일 이내에 하드 코딩 IP 주소 (es)를 업데이트합니다.

정적 IP, 보증 및 기타 배열에 대한 자세한 내용은 엔터프라이즈 계정 팀과 논의하십시오.

귀사의 엔터프라이즈 팀은 향후 백업을 통해 IP의 짧은 목록을 유지하면서도 주소 다양성을 달성할 수 있는 추가 주소를 제공할 수 있습니다.

:::

### DNS 조회를 저장하기 위해 응용 프로그램에서 TURN에 사용되는 IP 주소를 hardcode하고 싶습니다.

이 권장되지는 않지만 IP 주소가 유용 할 수있는 매우 작은 환경 설정이 있습니다. 이 경우 DNS 응답을 변경하는 경고를 설정해야 합니다.`turn.cloudflare.com`(A 및 AAAA 레코드) 및 DNS 변경의 14 일 이내에 하드 코딩 IP 주소 (es)를 업데이트합니다. 이 DNS 응답이 1 IP 주소보다 더 많은 수익을 올릴 수 있음을 주의하십시오. 또한, 하드코드 IP 주소에 대한 문제가있는 경우 DNS 쿼리에 실패를 설정해야합니다. Cloudflare는, 그러나 TURN 서비스에 사용된 IP 주소가 당신의 기업 계약에 없는 경우에 변화하지 않을 것이라는 점을 보증할 수 없습니다. 정적 IP, 보증 및 기타 배열에 대한 자세한 내용은 엔터프라이즈 계정 팀과 논의하십시오.

### TURN IP가 위에서 발행되는 것을 볼 수 있습니다. 당신은 또한 STUN에 대한 IP를 게시?

TURN 서비스`turn.cloudflare.com`또한 바인딩 요청에 응답합니다 ("STUN 요청").

### Cloudflare Realtime TURN은 만료 된 IETF RFC 초안 "draft-uberti-behave-turn-rest-00"를 지원합니까?

Cloudflare Realtime credential 세대 함수는 JSON 구조와 유사합니다.[만료된 RFC 초안 "draft-uberti-behave-turn-rest-00"](https://datatracker.ietf.org/doc/html/draft-uberti-behave-turn-rest-00), 하지만 TTL 값을 포함 하지 않습니다. 이 형식의 응답이 필요한 경우, Cloudflare Realtime 자격 생성 엔드포인트에서 백엔드 서버 또는 Cloudflare QXWorkersXQ에서 JSON을 수정할 수 있습니다.

### Cloudflare Realtime TURN을 사용할 때 패킷 손실을 관찰하고 있습니까?

패킷 손실은 UDP에서 정상이며 신뢰할 수있는 연결에도 때때로 발생할 수 있습니다. 그러나 체계적인 패킷 손실을 관찰한다면 다음을 고려하십시오.

- 단일 TURN 클라이언트에서 높은 비율 (> 50-100Mbps)에서 데이터를 전송 또는 수신합니까? Realtime TURN은 패킷을 떨어뜨릴 수 있습니다.
- 단일 TURN 클라이언트에서 매우 작은 패킷 크기 (높은 패킷 비율 > 5-10kpps)로 대용량 데이터를 전송 또는 수신합니까? Cloudflare 실시간 드롭핑 패킷이 될 수 있습니다.
- 패킷을 새로운 고유 주소로 전송합니다.[항구 스캐닝](https://en.wikipedia.org/wiki/Port_scanner)행동?

### Realtime TURN을 스케일로 사용할 계획입니다. 자격 증명을 발급 할 수있는 비율은 무엇입니까?

credential issuance에 대한 정의 된 제한이 없습니다. 500개의 credentials/sec에서 시작하고 선형으로 확장하십시오. 발행된 자격 증명의 50% 이상 사용하십시오.

### TURN 자격 만료 시간에 사용할 수있는 최대 값은 무엇입니까?

향후 48시간까지 자격 증명을 위한 만료 시간을 설정할 수 있습니다. 이보다 오래 지속되는 TURN 할당이 필요하면 필요할 것입니다.[지원하다](https://developer.mozilla.org/en-US/docs/Web/API/RTCPeerConnection/setConfiguration)TURN 자격.

### 실시간 TURN 지원 IPv6?

예. Cloudflare 실시간는 TURN 서버 통신에 대한 IPv4 및 IPv6 둘 다에서 사용할 수 있지만, IPv6에서 릴레이 주소를 발급하지 않습니다.[RFC 6156년](https://datatracker.ietf.org/doc/html/rfc6156).

### 실시간 TURN 문제 IPv6 릴레이 주소?

이름 \* 실시간 TURN은 존중하지 않습니다.`REQUESTED-ADDRESS-FAMILY`지정된 경우 STUN 속성은 IPv4 주소만 발급됩니다.

### 실시간 TURN 지원 TCP 릴레이?

이름 \* Realtime은 구현하지 않습니다.[사이트맵](https://datatracker.ietf.org/doc/html/rfc6062)견적 요청`REQUESTED-TRANSPORT`STUN 속성.

### 특정 IP 주소로 CreatePermission 또는 ChannelBind 요청을 만들 수 없습니다. 왜 그런가요?

Cloudflare Realtime denies CreatePermission 또는 ChannelBind 요청 개인 IP 범위 (e.g 루프백 주소, linklocal unicast 또는 멀티캐스트 블록) 또는 IP 주소가 있는 경우[BYOIP의 특징](/byoip/)이용안내

Cloudflare BYOIP 고객이며 Realtime TURN과 BYOIP 범위에 연결하려면 계정 관리자에게 자세한 내용은 문의하십시오.

### TURN 할당에 대한 최대 기간 제한은 무엇입니까?

TURN 할당에 대한 최대 기간 제한이 없습니다. 으로[RFC 8656 단면도 3.2](https://datatracker.ietf.org/doc/html/rfc8656#section-3.2), 일단 릴레이 수송 주소가 할당되면, 클라이언트는 할당 살아야 한다. 이를 위해 클라이언트는 정기적으로 서버에 새로 고침 요청을 보냅니다. 새로 고침 요청은 유효한 TURN 자격 증명으로 인증되어야 합니다. 자격에 대한 최대 기간은 48 시간입니다. 더 긴 할당이 필요한 경우, 새로운 자격은 적어도 48 시간 생성해야합니다.

### Cloudflare는 TURN 할당을 적극적으로 처리하는 서버의 유지보수를 수행하는 방법? 이의 영향은 무엇입니까?

이 일반적인 것은 아니지만, 특정 시나리오에서 TURN 할당은 혼란 될 수있다. 이것은 할당을 처리하거나 다른 QXQX0197XQ 데이터 센터에 도착하기 위해 TURN 패킷을 일으키는 Internet Network topology 변화와 관련 될 수 CloudflareXQ 데이터 센터. 이유에 관계없이,[ICE 재시작](https://datatracker.ietf.org/doc/html/rfc8445#section-2.4)고객 지원은 매우 좋습니다.

### TURN 자격 증명이 만료되면 어떻게됩니까?

Cloudflare Realtime은 즉시 분석에 대한 청구 및 녹음 사용을 중지합니다. 짧은 지연 후 연결이 차단됩니다.

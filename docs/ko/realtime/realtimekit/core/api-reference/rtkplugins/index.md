RTKPlugins 모듈은 회의에서 모든 플러그인으로 구성됩니다. 그것에는 2개의 지도가 있습니다:

- `all`: 회의에서 모든 플러그인의 일관성.
- `active`: 현재 사용중인 플러그인의 단점.

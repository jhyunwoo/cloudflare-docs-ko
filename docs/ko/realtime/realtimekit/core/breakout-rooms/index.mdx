### 휴식 방에 현지 참가자를 이동

지역 참가자를 다른 방으로 이동하거나 부모 회의로 돌아가려면 다른 참가자를 이동하는 것과 동일한 API를 사용하지만 지역 참가자의 ID를 전달하십시오. 현지 참가자는 적절한 허가를해야합니다.`canSwitchConnectedMeetings`방의 전환, 또는`canSwitchToParentMeeting`부모 회의에 돌아 가기 위해, 요청이 비 호스트 로컬 참가자에 의해 시작된 경우.

### 핸들 방 행사

참가자가 방으로 이동 한 경우,`changingMeeting`이벤트는 방아쇠, 다음`meetingChanged`이벤트 이 이벤트는 메인 미팅과 휴식 룸 사이의 참가자 스위치가 될 때도 방아쇠가됩니다. 참가자는 방을 Autojoin 할 것입니다. 당신은 명시적으로 회의에 가입 할 필요가 없습니다.

- 해당 이용 후기에 달린 코멘트가 없습니다.
- 메인 미팅과 휴식 룸 사이 전환

:::노트\[필수]

당신의 participant's preset에는 있습니다**Kick 참가자** (`kick_participant`) 호스트 권한 활성화.
주요 특징

현재 종료[이름 \*](/realtime/realtimekit/concepts/meeting/#session/)모든 참가자는 모든 참가자를 사용하여 제거`kickAll()`. 이 세션에 대한 지속적인 녹화를 중지하고 세션 상태를 설정`ENDED`.

세션 종료는 회의를 떠나는 것과 다릅니다. Leaving는 현재 참가자만 분리합니다. 다른 참가자가 여전히 존재하면 세션이 활성화됩니다.

2. 모든 참가자를 제거하여 세션 종료.

   <RTKCodeSnippet id="web-react">
     참가자가 필요한 권한이 없으면,`kickAll()`오류 코드로 ClientError를 던져`1201`.

     ```ts
     try {
     	await meeting.participants.kickAll();
     } catch (err) {
     	if (err?.code === 1201) {
     		//참가자는 세션을 종료할 수 없습니다.
     		//UI를 업데이트하면 동작이 허용되지 않습니다.
     		return;
     	}
     	throw err;
     }
     ```

3. 세션 종료 이벤트를 듣는다.

   <RTKCodeSnippet id="web-react">
     세션이 종료되면 모든 참가자가 세션을 남겨주세요. SDK는`roomLeft`이벤트`state`설정하기`ended`.

     ```ts
     meeting.self.on("roomLeft", ({ state }) => {
     	if (state === "ended") {
     		//회의 세션이 종료되었는지 보여주는 UI를 업데이트하십시오.
     	}
     });
     ```
   </RTKCodeSnippet>

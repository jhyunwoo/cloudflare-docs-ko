:::노트\[필수]

지역 참가자 (예를 들어, 호스트 또는 모더레이터)가 필요한 경우**호스트 컨트롤**사전 설정에서 사용할 수 있습니다. 자주 묻는 질문[공지사항](/realtime/realtimekit/concepts/preset/).
:::

RealtimeKit 호스트 컨트롤을 사용하여 라이브 세션에서 다른 참가자를 관리합니다. 오디오 또는 비디오, 참가자를 핀 또는 세션에서 참가자를 제거 할 수 있습니다.
이 작업은 지역 참가자의 특정 호스트 제어 권한을 요구합니다.[공지사항](/realtime/realtimekit/concepts/preset/)·
UI 컨트롤을 표시하거나이 방법을 호출하기 전에 로컬 참가자가 필요한 권한을 가지고 있는지 확인하십시오.
이 가이드에서**지역 participant**행동을 수행하는 사용자를 나타냅니다.

## Mute 오디오

배경 소음을 관리해야 할 때 참가자의 오디오, 교실이나 웨비나를 관리하거나 세션 중에 중단을 방지해야합니다.
이 행동은**Mute 오디오** (`disable_participant_audio`) 현지 참가자의 사전 설정에서 호스트 제어 권한 활성화.

<RTKCodeSnippet id="mobile-android">
  1. 현지 참가자가 다른 참가자의 오디오를 음미할 수 있는 권한을 확인합니다.

  ```kotlin
  val canMuteAudio = meeting.localUser.permissions.host.canMuteAudio
  if (!canMuteAudio) {
  	// Disable the control in your UI.
  }
  ```

  2. 이름 \*`disableAudio()`대상 참가자에. 현지 참가자가 필요한 권한이 없으면,`disableAudio()`계정 만들기`HostError`.

  ```kotlin
  val error = participant.disableAudio()
  if (error != null) {
  	// Handle error - permission denied.
  }
  ```

  3. 업데이트에 대한 청취로 결과 처리. 호출이 성공한 후, 대상 참가자의`audioEnabled`계정이 없습니다.`false`.

  ```kotlin
  meeting.addParticipantsEventListener(object : RtkParticipantsEventListener {
  	override fun onAudioUpdate(participant: RtkRemoteParticipant, isEnabled: Boolean) {
  		// audioEnabled is false
  		// Update UI for the participant
  	}
  })
  ```
</RTKCodeSnippet>

<RTKCodeSnippet id="mobile-ios">
  1. 현지 참가자가 다른 참가자의 오디오를 음미할 수 있는 권한을 확인합니다.

  ```swift
  let canMuteAudio = meeting.localUser.permissions.host.canMuteAudio
  ```

  ```swift
  if let error = participant.disableAudio() {
  	// Handle error - permission denied.
  }
  ```

  3. 업데이트에 대한 청취로 결과 처리. 호출이 성공한 후, 대상 참가자의`audioEnabled`계정이 없습니다.`false`.

  ```swift
  extension MeetingViewModel: RtkParticipantsEventListener {
  	func onAudioUpdate(participant: RtkRemoteParticipant, isEnabled: Bool) {
  		// audioEnabled is false
  		// Update UI for the participant
  	}
  }

  // Register the listener
  meeting.addParticipantsEventListener(participantsEventListener: self)
  ```
</RTKCodeSnippet>

  ```jsx
  });
  ```

## 핀 참가자

웹 세미나 발표자 또는 교실 교사와 같은 그들을 강조하는 참가자를 핀. 이 세션 전체 작업입니다. 모든 참가자는 초점으로 pinned participant를 볼 것입니다.
이 행동은**핀 참가자** (`pin_participant`) 현지 참가자의 사전 설정에서 호스트 제어 권한 활성화.

:::참조
1개의 participant만 한 번에 피할 수 있습니다. 새로운 참가자를 자동적으로 이전의 핀으로 꼿습니다.

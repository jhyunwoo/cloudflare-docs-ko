로컬 사용자 미디어 장치를 관리하고 오디오, 비디오 및 Screenshare를 제어하고 RealtimeKit 회의에서 이벤트를 처리하십시오.

:::노트\[필수]
SDK를 초기화하고 미팅 객체 구조를 이해합니다. 더 알아보기[SDK 초기화](/realtime/realtimekit/core/)·[회의 목표 설명](/realtime/realtimekit/core/meeting-object-explained/).
:::

## 제품정보

로컬 사용자를 통해 접근 가능`meeting.self`현재 참가자와 관련된 모든 정보와 방법을 포함합니다. 이에는 미디어 컨트롤, 장치 관리, 참가자 메타 데이터 및 상태 정보가 포함되어 있습니다.

### 국가 속성

접근 방 국가 및 participant 상태:

<RTKCodeSnippet id={["web-angular","web-web-components"]}>
  ```js
  //룸 상태
  meeting.self.roomJoined; //Boolean: 회의에 합류 했습니까?
  meeting.self.roomState; //현재 방 상태 (아래의 가능한 값 참조)
  meeting.self.isPinned; //Boolean: 현지 사용자는 핀으로 꼿습니까?

  //권한 및 설정
  meeting.self.permissions; //Preset에 의해 정의된 기능
  meeting.self.config; //회의 외관에 대한 구성
  ```

  **룸 상태 값:**

  - `'init'`- 처음에 가입하지 않는
  - `'joined'`- 성공적으로 회의에 합류
  - `'waitlisted'`- 대기실에서 대기
  - `'rejected'`- 입력 거부
  - `'kicked'`- 회의에서 제거
  - `'left'`- 회의 왼쪽
  - `'ended'`- 회의 종료
  - `'disconnected'`- 회의에서 분리
</RTKCodeSnippet>

<RTKCodeSnippet id="web-react">

### 오디오 제어

Mute 및 마이크를 삭제:

<RTKCodeSnippet id={["web-angular","web-web-components"]}>
  ```js
  //오디오 활성화 (unmute)
  await meeting.self.enableAudio();

  //무능 오디오 (mute)
  await meeting.self.disableAudio();

  //현재 상태 확인
  const isAudioEnabled = meeting.self.audioEnabled;
  ```
</RTKCodeSnippet>

<RTKCodeSnippet id="web-react">
  ```jsx
  import { useRealtimeKitClient } from "@cloudflare/realtimekit-react";

  function AudioControls() {
  	const [meeting] = useRealtimeKitClient();
  	const audioEnabled = useRealtimeKitSelector((m) => m.self.audioEnabled);

  	const toggleAudio = async () => {
  		if (audioEnabled) {
  			await meeting.self.disableAudio();
  		} else {
  			await meeting.self.enableAudio();
  		}
  	};

  	return (
  		<button onClick={toggleAudio}>{audioEnabled ? "Mute" : "Unmute"}</button>
  	);
  }
  ```
</RTKCodeSnippet>

  :::note\[Android API 14 이상]
  AndroidManifest.xml의 앱의 AndroidManifest.xml에서 다음 권한을 결정하여 Android API 14 이상을 실행하는 Android 기기에서 Screenshare를 사용합니다.

  ```

  ```

  이 권한을 추가하면 Google Play 콘솔에서 추가 단계가 필요합니다. 더 알아보기[Google의 문서](https://support.google.com/googleplay/android-developer/answer/13392821?hl=en#declare)더 많은 정보.

## 스크린 공유 설정 (iOS)

<RTKCodeSnippet id="mobile-ios">
  ### 방송 업로드 확장

  Xcode에서 방송 업로드 확장을 추가합니다.`File` → `New` → `Target`. 선택`iOS` → `Broadcast Upload Extension`자주 묻는 질문

  ### 앱 그룹 구성

  앱 그룹에 확장을 추가:

  1. 프로젝트의 확장 목표로 이동
  2. Signings & Capabilities 탭에서 왼쪽 상단의 + 버튼을 클릭합니다
  3. 앱 그룹 추가
  4. 앱 그룹을 메인 앱에 추가하고, App Group 식별자를 모두 동일하게 보장

  ### SampleHandler 구성

  SampleHandler 클래스 편집:

  ```swift
  import RealtimeKit

  class SampleHandler: RtkSampleHandler {}
  ```

  ### 업데이트 Info.plist

  이름 \***모두 보기**App 및 Extension Info.plist 파일에는 이러한 키가 포함되어 있습니다.

  ```xml
  <key>RTKRTCAppGroupIdentifier</key>
  <string>(name of the group you have created)</string>
  ```

  주요 앱의 Info.plist 내부의이 키를 추가하십시오.

  ```xml
  <key>RTKRTCScreenSharingExtension</key>
  <string>(Bundle Identifier of the Broadcast upload extension)</string>
  ```

  ### 스크린 공유

  방송 확장을 시작하고 스크린 공유를 활성화:

  ```swift
  meeting.localUser.enableScreenShare()
  ```

### 미디어 권한 오류

미디어 권한이 거부되거나 미디어 캡처가 실패했을 때 트리거 :

<RTKCodeSnippet id={["web-angular","web-web-components"]}>
  ```js
  meeting.self.on("mediaPermissionError", ({ message, kind }) => {
  	console.log(`Failed to capture ${kind}: ${message}`);

  	//다른 오류 유형
  	if (message === "DENIED") {
  		console.log("User denied permission");
  	} else if (message === "SYSTEM_DENIED") {
  		console.log("System denied permission");
  	} else if (message === "COULD_NOT_START") {
  		console.log("Failed to start media stream");
  	}
  });
  ```

  **가능한 값:**

  - `message`: `'DENIED'`, `'SYSTEM_DENIED'`, `'COULD_NOT_START'`

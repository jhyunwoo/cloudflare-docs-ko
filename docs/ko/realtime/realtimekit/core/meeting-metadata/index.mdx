회의에 관한 모든 메타데이터는 저장`meeting.meta`. 이것은 회의 상태, 유형 및 연결에 대한 중요한 정보를 포함합니다.

<RTKSDKSelector />

## 가능한 metadata

플랫폼에 기반을 둔 프레임 워크를 선택하십시오.

<RTKCodeSnippet id={["web-angular","web-web-components"]}>
  더 보기`meeting.meta`객체는 다음과 같은 속성을 포함합니다:

  - **`viewType`**- 회의의 유형을 나타냅니다. 가능한 값은`WEBINAR`, `GROUP_CALL`
  - **`roomType`**- 회의가 그룹 통화 또는 웹 세미나인지 나타냅니다.
  - **`meetingTitle`**- 회의의 제목
  - **`meetingStartedTimestamp`**- 회의가 시작될 때 타임스탬프
  - **`mediaState`**- 미디어 연결 상태
  - **`socketState`**- 소켓 연결 상태
</RTKCodeSnippet>

## 접근 회의 metadata

metadata에 액세스하려면`meeting.meta`객체.

<RTKCodeSnippet id={["web-angular","web-web-components"]}>
  ```javascript
  //MeetingTitle을 얻기 위해 메타 데이터를 분리
  const { meetingTitle } = meeting.meta;

  if (meeting.self.roomJoined) {
  	console.log(
  		`The local user has joined a meeting with title ${meetingTitle}.`,
  	);
  }
  ```
</RTKCodeSnippet>

<RTKCodeSnippet id="web-react">
  ```jsx
  import { useRealtimeKitSelector } from "@cloudflare/realtimekit-react";
  import { useEffect } from "react";

  function MeetingInfo() {
  	const [meetingTitle, roomJoined] = useRealtimeKitSelector((m) => [
  		m.meta.meetingTitle,
  		m.self.roomJoined,
  	]);

  	useEffect(() => {
  		if (roomJoined) {
  			console.log(
  				`The local user has joined a meeting with title ${meetingTitle}.`,
  			);
  		}
  	}, [roomJoined, meetingTitle]);

  	return null;
  }
  ```
</RTKCodeSnippet>

## 연결 이벤트

더 보기`meta`객체는 또한 회의의 연결 상태에 변화를 나타내는 사건을 방출합니다.

### Media 연결 업데이트

<RTKCodeSnippet id={["web-angular","web-web-components"]}>
  미디어 연결 (웹RTC 연결은 실제 미디어 전송에 사용) 전송`mediaConnectionUpdate`이벤트

  ```javascript
  meeting.meta.on("mediaConnectionUpdate", ({ transport, state }) => {
  	//수송-'consuming' |'producing'
  	//국가 - 'new' | 'connecting' | 'connected' | 'disconnected' | 'reconnecting' | 'failed' | 'failed'

  	console.log(`Media connection ${transport} is now ${state}`);
  });
  ```

  더 보기`mediaConnectionUpdate`이벤트 제공:

  - **`transport`**- 한국어`'consuming'`(리빙 미디어) 또는`'producing'`(지속 미디어)
  - **`state`**- 연결 상태:`'new'`, `'connecting'`, `'connected'`, `'disconnected'`, `'reconnecting'`, 또는`'failed'`
</RTKCodeSnippet>

<RTKCodeSnippet id="web-react">
  미디어 연결 (웹RTC 연결은 실제 미디어 전송에 사용) 전송`mediaConnectionUpdate`이벤트

  ```jsx
  import { useRealtimeKitClient } from "@cloudflare/realtimekit-react";
  import { useEffect } from "react";

  function MediaConnectionMonitor() {
  	const [meeting] = useRealtimeKitClient();

  	useEffect(() => {
  		if (meeting) {
  			const handleMediaConnection = ({ transport, state }) => {
  				//수송-'consuming' |'producing'
  				//국가 - 'new' | 'connecting' | 'connected' | 'disconnected' | 'reconnecting' | 'failed' | 'failed'

  				console.log(`Media connection ${transport} is now ${state}`);
  			};

  			meeting.meta.on("mediaConnectionUpdate", handleMediaConnection);

  			return () => {
  				meeting.meta.off("mediaConnectionUpdate", handleMediaConnection);
  			};
  		}
  	}, [meeting]);

  	return null;
  }
  ```

  더 보기`mediaConnectionUpdate`이벤트 제공:

  - **`transport`**- 한국어`'consuming'`(리빙 미디어) 또는`'producing'`(지속 미디어)
  - **`state`**- 연결 상태:`'new'`, `'connecting'`, `'connected'`, `'disconnected'`, `'reconnecting'`, 또는`'failed'`
</RTKCodeSnippet>

<RTKCodeSnippet id="mobile-android">
  metadata에서 현재 미디어 연결 상태에 직접 액세스 할 수 있습니다.

</RTKCodeSnippet>

### 소켓 연결 업데이트

<RTKCodeSnippet id={["web-angular","web-web-components"]}>
  WebSocket 연결 업데이트 (채팅, 설문 조사 및 기타 기본 신호에 사용)은 전송`socketConnectionUpdate`이벤트

  ```javascript
  meeting.meta.on(
  	"socketConnectionUpdate",
  	({ state, reconnectionAttempt, reconnected }) => {
  		//국가 - 'connected' | 'disconnected' | 'reconnecting' | 'failed'

  		console.log(`Socket connection is now ${state}`);

  		if (reconnectionAttempt) {
  			console.log(`Reconnection attempt: ${reconnectionAttempt}`);
  		}

  		if (reconnected) {
  			console.log("Successfully reconnected");
  		}
  	},
  );
  ```

  더 보기`socketConnectionUpdate`이벤트 제공:

  - **`state`**- 연결 상태:`'connected'`, `'disconnected'`, `'reconnecting'`, 또는`'failed'`
  - **`reconnectionAttempt`**- 재연결 시도 수 (연결하는 경우)
  - **`reconnected`**- 연결이 성공적으로 설치 한 경우 Boolean
</RTKCodeSnippet>

<RTKCodeSnippet id="web-react">
  WebSocket 연결 업데이트 (채팅, 설문 조사 및 기타 기본 신호에 사용)은 전송`socketConnectionUpdate`이벤트

  ```jsx
  import { useRealtimeKitClient } from "@cloudflare/realtimekit-react";
  import { useEffect } from "react";

  function SocketConnectionMonitor() {
  	const [meeting] = useRealtimeKitClient();

  	useEffect(() => {
  		if (meeting) {
  			const handleSocketConnection = ({
  				state,
  				reconnectionAttempt,
  				reconnected,
  			}) => {
  				//국가 - 'connected' | 'disconnected' | 'reconnecting' | 'failed'

  				console.log(`Socket connection is now ${state}`);

  				if (reconnectionAttempt) {
  					console.log(`Reconnection attempt: ${reconnectionAttempt}`);
  				}

  				if (reconnected) {
  					console.log("Successfully reconnected");
  				}
  			};

  			meeting.meta.on("socketConnectionUpdate", handleSocketConnection);

  			return () => {
  				meeting.meta.off("socketConnectionUpdate", handleSocketConnection);
  			};
  		}
  	}, [meeting]);

  	return null;
  }
  ```

  더 보기`socketConnectionUpdate`이벤트 제공:

  - **`state`**- 연결 상태:`'connected'`, `'disconnected'`, `'reconnecting'`, 또는`'failed'`
  - **`reconnectionAttempt`**- 재연결 시도 수 (연결하는 경우)
  - **`reconnected`**- 연결이 성공적으로 설치 한 경우 Boolean
</RTKCodeSnippet>

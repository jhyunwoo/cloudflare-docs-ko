**가능한 상태 값:**

- **`ON_STAGE`**- 사용자는 현재 무대에서 오디오 및 비디오를 공유하고 있습니다.
- **`OFF_STAGE`**- 사용자는 세션을보고 있지만 무대에 있지 않으며 오디오 또는 비디오를 공유하지 않습니다.
- **`REQUESTED_TO_JOIN_STAGE`**- 사용자는 단계에 가입하고 오디오 및 비디오를 공유 할 수 있습니다. 이 상태는 호스트가 허용하거나 요청을 거부 할 때까지 남아있다.
- **`ACCEPTED_TO_JOIN_STAGE`**- 호스트는 사용자의 요청을 받아 단계에 합류했습니다.

:::참조
직접 단계에 가입 할 수있는 사용자 만 가정 할 수 있습니다`ON_STAGE`·`ACCEPTED_TO_JOIN_STAGE`상태 값.

  //사용RealtimeKitSelector 걸이는 `RealtimeKitProvider`가 사용될 때만 작동합니다.
  const stageStatus = useRealtimeKitSelector((m) => m.stage.status);

### 오염 유형

<RTKCodeSnippet id={["web-angular","web-web-components"]}>
  더 보기`Poll`유형은 다음과 같이 정의됩니다:

  ```typescript
  interface Poll {
  	id: string;
  	question: string;
  	options: PollOption[];
  	anonymous: boolean;
  	hideVotes: boolean;
  	createdBy: string;
  	createdByUserId: string;
  	voted: string[]; //부품 ID
  }

  interface PollOption {
  	text: string;
  	votes: {
  		id: string; //부품 ID
  		name: string;
  	}[];
  	count: number;
  }
  ```
</RTKCodeSnippet>

  모든 제품`PollOption`목록 포함`PollVote`각 투표가 유권자의 포함`id`·`name`.

  ```kotlin
  class PollOption(
    val text: String,
    val votes: List<PollVote>,
    val count: Int
  )
  ```

  ```kotlin
  class PollVote(
    val id: String,
    val name: String
  )
  ```
</RTKCodeSnippet>

  ```swift

  class PollVote {
    let id: String

  }
  ```
</RTKCodeSnippet>

  더 보기`Poll`클래스는 다음과 같은 속성을 가지고:

  - `id`: 각 설문 조사에 할당된 고유 ID.
  - `question`: 설문 조사의 문제.
  - `anonymous`: 완료 후 각 사용자의 투표를 숨기려면. (기본값)
  - `hideVotes`: 투표가 완료 될 때까지 숨기기 투표. ( 익명이 활성화되면 사용 가능)
  - `createdBy`: 작성자의 이름
  - `options`: 배열`PollOption`객체는 설문 조사에 모든 옵션을 포함합니다.
  - `voted`: 투표한 사용자 ID를 포함하는 문자열의 배열.

  유형`Poll`RealtimeKit 회의에서 설문 조사를 나타냅니다. 그것은 또한 목록의 포함`PollOption`주어진 설문 조사에 대한 옵션입니다. 그리고 모든`PollOption`그것은 내부의 투표 목록이 있습니다. 표는 클래스의 객체입니다`PollVote`내부는 투표의 ID와 이름을 가지고 있습니다.

  ```dart
  class PollOption(
    final String text;   // Option text.
    final List<PollVote> votes;   // List of votes.
    final int count;    // Number of votes.
  );

  class PollVote {
    final String id;    // ID of the voter.
    final String name;  // Name of the voter.
  }
  ```
</RTKCodeSnippet>

<RTKCodeSnippet id={["web-angular","web-web-components"]}>
  새로운 설문 조사를 사용하여 만들 수 있습니다.`create`방법에서`meeting.polls`객체. 더 보기`meeting.polls.create()`방법은 다음과 같은 매개 변수를 받아들입니다:

  - `question`(string) - 설문 조사
  - `options`(string\[]) - 투표 옵션의 배열
  - `anonymous`(boolean) - 투표가 익명인지 여부
  - `hideVotes`(boolean, 옵션) - 투표 수를 숨기기 여부

  다음과 같은 스니펫은 투표가 익명 인 poll를 만듭니다.

  ```js
  await meeting.polls.create(
  	"Are you an early bird or a night owl?",
  	["Early bird", "Night owl"],
  	true,
  );
  ```

  | 비밀번호   | `Poll`       | -     | 이름 \* | 모든 설문 조사 속성 (퀘스트, 옵션 등) |
  | 비밀번호   | `PollOption` | 이름 \* | 이름 \* | 사용자가 투표 한 옵션            |

  회의에서 만든 첫 번째 투표에 대한 다음 스니펫 투표.

  ```dart
  final poll = meeting.polls.items[0];
  final selectedPollOption = poll.options[0];

  meeting.polls.vote(poll: poll, pollOption: selectedPollOption);
  ```
</RTKCodeSnippet>

<RTKCodeSnippet id="mobile-react-native">
  더 보기`meeting.polls.vote()`방법은 투표에 투표를 등록 할 수 있습니다. 그것은 뒤에 오는 모수를 받아들입니다:

  | 계정 만들기 | 제품정보     | 기본 값 | 견적 요청 | 이름 \*           |
  | ------ | -------- | ---- | ----- | --------------- |
  | 이름 \*  | `string` | -    | 이름 \* | 투표 될 설문 조사의 ID. |
  | 이름 \*  | `number` | -    | 이름 \* | 옵션의 인덱스.        |

  회의에서 만든 첫 번째 투표에 대한 다음 스니펫 투표.

  ```ts
  const poll = meeting.polls.items[0];
  await meeting.poll.vote(poll.id, 0);
  ```
</RTKCodeSnippet>

### 오염이 생성되거나 업데이트 될 때 통지

<RTKCodeSnippet id={["web-angular","web-web-components"]}>
  이벤트는 매번 불이 켜져 있습니다.`meeting.polls.items`업데이트 또는 생성. 설문 조사의 업데이트 목록을 얻을 수 있습니다. 응답 객체는 다음과 같은 속성을 포함합니다:

  - `polls`- 모든 설문 조사 목록
  - `newPoll`- boolean 변수는`true`새 설문 조사가 생성되었을 때

  ```js
  meeting.polls.on("pollsUpdate", ({ polls, newPoll }) => {
  	console.log("Polls updated:", polls);
  	console.log("Is new poll:", newPoll);
  });
  ```
</RTKCodeSnippet>

<RTKCodeSnippet id="web-react">
  이벤트는 매번 불이 켜져 있습니다.`meeting.polls.items`업데이트 또는 생성. 설문 조사의 업데이트 목록을 얻을 수 있습니다. 응답 객체는 다음과 같은 속성을 포함합니다:

<RTKCodeSnippet id="mobile-android">
  회의 기간 동안 새로운 설문 조사 또는 설문 조사에 대한 업데이트를 수신하려면, 구현`RtkPollsEventListener`인터페이스. 청취자 등록`meeting.addPollsEventListener(rtkPollsEventListener)`.

  더 보기`onNewPoll()`새 설문 조사가 회의에서 생성될 때마다 메소드가 호출됩니다.

  더 보기`onPollUpdate()`특정 설문 조사가 업데이트되면 참가자 투표 또는 설문 조사 세부 변경과 같은 방법을 호출합니다. 더 보기`onPollUpdates()`새로운 설문 조사를 포함하여 설문 조사의 목록을 업데이트 할 때 메소드가 호출됩니다. 이 콜백을 사용하여 poll UI를 최신 설문 조사 데이터와 동기화합니다.

  ```kotlin
  meeting.addPollsEventListener(object : RtkPollsEventListener {
      override fun onNewPoll(poll: Poll) {
      }

      override fun onPollUpdate(poll: Poll) {
      }

      override fun onPollUpdates(pollItems: List<Poll>) {
      }
    }
  )
  ```
</RTKCodeSnippet>

<RTKCodeSnippet id="mobile-ios">
  새로운 poll 메시지를 수신 할 수 있도록 방법`onPollUpdates()`callback에서 방법`RtkPollsEventListener`. 이 이벤트를 호출하여 구독할 수 있습니다.`meeting.addPollsEventListener(meetingViewModel)`

  ```swift
  extension MeetingViewModel: RtkPollsEventListener {
    func onNewPoll(poll: Poll) {
      // code to handle new poll
    }

    func onPollUpdates(pollItems: [Poll]) {
      // code to handle polls and their vote updates.
    }

    func onPollUpdate(poll: Poll) {}
  }
  ```
</RTKCodeSnippet>

<RTKCodeSnippet id="mobile-flutter">
  새로운 poll 메시지를 수신 할 수 있도록 방법`onPollUpdates()`callback에서 방법`RtkPollsEventListener`:

  설문조사 업데이트 받기`onPollUpdates()`콜백:

  ```dart
  class PollEventsListener extends RtkPollsEventListener {
    @override
    void onPollUpdates(List<Poll> pollItems) {
      /// code to handle polls
    }

    @override
    void onNewPoll(Poll poll) {
      /// code to handle new poll
    }
  }
  ```

  다음과 같이 이러한 이벤트에 가입할 수 있습니다:

  ```dart
  meeting.addPollsEventListener(PollEventsListener());
  ```

이 페이지는 RealtimeKit 오류 코드를 사용하여 식별 및 문제 해결 문제를 돕습니다.

  모든 웹 프레임 워크 (웹 구성 요소, React, 각도) 같은 오류 코드를 공유합니다.

  ## RealtimeKit클라이언트

  #### 오류 코드 : 0001

  - **오류 메시지**: 초기화에 실패
  - **가능한 이유**: RealtimeKitClient는 초기화되지 않습니다.
  - **Possible 해결책**: RealtimeKitClient를 올바르게 초기화하면 검증`await RealtimeKitClient.init({ ... })`. 보기[RealtimeKit클라이언트](https://docs.realtime.cloudflare.com/web-core/reference/RealtimeKitClient). 문제가 계속되면 Cloudflare 지원에 도달하십시오.

  #### 오류 코드 : 0002

  - **오류 메시지**: 방에 들어가기
  - **가능한 이유**: RealtimeKitClient에 문제가 있음.
  - **Possible 해결책**: 한국어`join()`RealtimeKit의 회의실에 참여하는 방법은 사용됩니다. RealtimeKitClient에서 이 메소드를 다시 호출하십시오.

  ```javascript
  await meeting.join();
  ```

  회의실 과정이 완료되면,`roomJoined`이벤트가 방출됩니다.`meeting.self`네임스페이스

  #### 오류 코드 : 0003

  - **오류 메시지**: 방을 떠날 실패
  - **가능한 이유**: RealtimeKitClient에 문제가 있음.
  - **Possible 해결책**: 한국어`leave()`RealtimeKit에서 회의실을 떠나는 방법은 사용됩니다. RealtimeKitClient에서 이 메소드를 다시 호출하십시오.

  ```javascript
  await meeting.leave();
  ```

  #### 오류 코드 : 0004

  - **오류 메시지**: 잘못된 auth 토큰
  - **가능한 이유**: 전달된 participant auth 토큰으로 문제를 나타냅니다.
  - **Possible 해결책**: auth 토큰이 아직 만료되지 않은 유효한 JWT auth 토큰을 보장한다.

  #### 오류 코드 : 0010

  - **오류 메시지**: 브라우저 지원되지 않음
  - **가능한 이유**: 브라우저는 너무 오래되고 WebRTC를 지원하지 않습니다.
  - **Possible 해결책**: 최신 버전으로 업그레이드 브라우저. Google Chrome은 선호됩니다.

  #### 오류 코드 : 0011

  - **오류 메시지**: HTTP 네트워크 오류
  - **가능한 이유**: 인터넷 문제가 존재하는 경우 또는 API 요청은 다른 경우의 잘못된 우스 토큰으로 인해 실패합니다.
  - **Possible 해결책**: 인터넷 연결이 적절하다는 것을 보장한다. 속도 시험은에서 실행될 수 있습니다[사이트 맵](https://fast.com/). 회의가 활성화되고 토큰은 만료되지 않았습니다.

  #### 오류 코드 : 0012

  - **오류 메시지**: Websocket 네트워크 오류
  - **가능한 이유**: 인터넷 문제가 존재하거나 Websocket 연결이 다른 경우의 결함이 auth 토큰으로 인해 실패했습니다.
  - **Possible 해결책**: 인터넷 연결이 적절하다는 것을 보장한다. 속도 시험은에서 실행될 수 있습니다[사이트 맵](https://fast.com/). 회의가 활성화되고 토큰은 만료되지 않았습니다.

  #### 오류 코드 : 0013

  - **오류 메시지**: 가격 제한
  - **가능한 이유**: 호출이 너무 자주 호출되는 SDK API
  - **Possible 해결책**: 웹 페이지가 짧은 기간 내에 특정한 높은 요청을 만들 때 일반적으로 발생되는 API 속도. 이 문제를 해결하려면 코드를 분석하여 많은 요청이 전송되고 불필요한 통화를 줄이기 위해 최적화를 구현합니다.

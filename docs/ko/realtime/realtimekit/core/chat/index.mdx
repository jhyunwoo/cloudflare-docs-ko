<RTKCodeSnippet id={["web-angular","web-web-components"]}>

  ```js
  meeting.chat.on("chatUpdate", ({ message, messages }) => {
  	console.log(`Received message ${message}`);
  	console.log(`All messages in chat: ${messages.join(", ")}`);
  });
  ```

  이름 \*`message`유형의`Message`, 도입에 정의.`messages`회의에서 모든 채팅 메시지 목록입니다.`meeting.chat.messages`.

  ```js
  console.log(JSON.stringify(meeting.chat.messages));

  meeting.chat.on("chatUpdate", () => {
  	console.log(JSON.stringify(meeting.chat.messages));
  });
  ```

### 채팅 메시지

<RTKCodeSnippet id={["web-angular","web-web-components"]}>
  채팅에 메시지의 번호를 핀 할 수 있습니다. 메시지를 핀 할 때, 메시지 객체는 속성이 있습니다.`pinned: true`, 메시지를 피하면 식별 할 수 있는 사용.

  메시지 핀에:

  ```js
  //채팅의 첫 번째 메시지를 핀 (텍스트, 이미지, 또는 파일).
  const { id } = meeting.chat.messages[0];
  await meeting.chat.pin(id);
  ```

  메시지가 핀되면 추가됩니다.`meeting.chat.pinned`.

  ```js
  const { id } = meeting.chat.messages[0];
  await meeting.chat.pin(id);

  console.log(meeting.chat.pinned);
  console.log(meeting.chat.pinned.length > 0); //진정한
  ```

  당신은 또한 핀 메시지를 해제 할 수 있습니다`meeting.chat.unpin()`방법.

  ```js
  //첫 번째 핀 메시지가없는.
  const { id } = meeting.chat.pinned[0];
  await meeting.chat.unpin(id);
  ```

  메시지가 핀 또는 unpinned 때 알아야 할 이벤트를들을 수 있습니다.

  ```js
  meeting.chat.on("pinMessage", ({ message }) => {
  	console.log("A message was pinned", JSON.stringify(message));
  });

  meeting.chat.on("unpinMessage", ({ message }) => {
  	console.log("A message was unpinned", JSON.stringify(message));
  });
  ```
</RTKCodeSnippet>

## 수출 채팅 메시지

다음 방법으로 RealtimeKit 세션의 모든 채팅 메시지를 검색 할 수 있습니다:

- 채팅 재생 API 사용
- webhook 설정`meeting.chatSynced`행사일정

### 채팅 다운로드 URL

채팅 다운로드 URL을 얻으려면 HTTP를`GET`요청하기[채팅 재생 API 엔드포인트](/api/resources/realtime_kit/subresources/sessions/methods/get_session_chat/). API 반환:

```json
{
	"success": true,
	"data": {
		"chat_download_url": "string",
		"chat_download_url_expiry": "string"
	}
}
```

- **`chat_download_url`**- AWS S3에서 CSV 형식의 전체 채팅 덤프를 다운로드 할 수있는 URL
- **`chat_download_url_expiry`**- 만료된 타임스탬프`chat_download_url`. URL이 만료되면 새로운 다운로드 URL을 얻기 위해이 엔드포인트를 다시 호출합니다.

Chat Replay API endpoint에 대한 자세한 내용은 참조[Realtime Kit API 문서](/api/resources/realtime_kit/subresources/sessions/methods/get_session_chat/).

### 채팅 덤프 파일을 다운로드

CSV 형식으로 채팅 덤프 파일을 다운로드 할 수 있습니다. HTTP`GET`요청하기`chat_download_url`이전 단계에서 획득.

HTTP URL에서 파일을 다운로드하는 과정은 클라이언트 측 또는 서버 측에 다운로드 여부에 따라 다릅니다.

#### 고객지원

클라이언트 측에 다운로드하기:

1. 더 보기`GET`요청하기`chat_download_url`
2. blob에 대한 응답 변환
3. 자주 묻는 질문`<a>`HTML 요소와`download`속성을 추가하고 blob에 그것의`href`
4. Programmatically 클릭`<a>`브라우저가 자동으로 다운로드 시작되므로 제거`<a>`이름 \*

#### 서버에 다운로드

Node.js 스트림을 사용하여 서버에 다운로드하려면:

1. 로컬 파일에 writable 스트림 만들기
2. 더 보기`GET`지원하다`chat_download_url`
3. 읽기 쉬운 스트림을 얻기`res.body`첫번째 단계에서 창조된 writable 시내에 관

### CSV 채팅 덤프 형식

CSV 파일은 참가자 정보 및 메타데이터와 함께 모든 채팅 메시지를 포함합니다. 다음 열 제목을 포함합니다:

- **`id`**- 고유 채팅 메시지 ID
- **`participantId`**- 메시지를 보낸 참가자의 ID
- **`sessionId`**- 채팅 메시지가 전송 된 세션 ID
- **`meetingId`**- 이 세션이 속한 회의의 ID
- **`displayName`**- 이 메시지를 보낸 참가자의 이름 표시
- **`pinned`**- 현재 메시지가 핀이 있다면 나타내는 불린
- **`isEdited`**- 현재 메시지가 편집되었는지 나타내는 불린
- **`payloadType`**- 채팅 메시지에 보내지는 페이로드의 유형을 나타냅니다. 그것은의 하나일 수 있습니다`TEXT_MESSAGE`, `IMAGE_MESSAGE`, `FILE_MESSAGE`
- **`payload`**- 실제 페이로드는 채팅 메시지에서 전송
- **`createdAt`**- 이 채팅 메시지가 전송되었을 때 Timestamp

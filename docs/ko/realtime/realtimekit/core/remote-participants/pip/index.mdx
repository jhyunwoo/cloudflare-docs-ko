Picture-in-Picture API를 사용하면 렌더링 할 수 있습니다.`meeting.participants.active`participant의 비디오는 현재 웹 페이지의 컨텍스트 밖에 뜨 타일로.

:::참조
Chrome, Edge 및 Chromium 기반 브라우저에서만 지원됩니다.
주요 특징

<RTKSDKSelector />

<RTKCodeSnippet id={["mobile-android", "mobile-ios", "mobile-flutter", "mobile-react-native"]}>
  Picture-in-Picture는 이 플랫폼에서 사용할 수 없습니다.
</RTKCodeSnippet>

<RTKCodeSnippet id={["web-web-components", "web-angular"]}>
  ## 자주 묻는 질문

  Picture-in-Picture API는 브라우저에서 지원되지 않을 수 있습니다. API를 사용하기 전에 항상 지원을 확인합니다.

  ```js
  const isSupported = meeting.participants.pip.isSupported();
  ```

  ## Enable 그림에서 그림

  ```js
  await meeting.participants.pip.enable();
  ```

  ## 무능한 그림에서 그림

  ```js
  await meeting.participants.pip.disable();
  ```
</RTKCodeSnippet>

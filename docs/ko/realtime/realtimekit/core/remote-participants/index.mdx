이 가이드는 참가자 데이터, 디스플레이 동영상, 핸들 이벤트에 액세스하는 방법을 설명하고 RealtimeKit 회의에서 참가자 권한을 관리합니다.

:::노트\[필수]
이 페이지는 이미 SDK를 초기화하고 미팅 객체 구조를 이해해야 합니다. 더 알아보기[SDK 초기화](/realtime/realtimekit/core/)·[회의 목표 설명](/realtime/realtimekit/core/meeting-object-explained/)필요한 경우.
주요 특징

<RTKSDKSelector />

참가자는 특정 참가자와 관련된 모든 정보를 포함, 그리드 및 각 참가자 미디어 스트림에 대한 정보를 포함, 이름, 및 상태 변수. 오시는 길`meeting.participants`.

### 제품 정보

<RTKCodeSnippet id={["web-web-components", "web-angular", "web-react", "mobile-react-native"]}>
  #### Metadata 속성

  - `id`- 한국어`participantId`참가자의 (aka)`peerId`)
  - `userId`- 한국어`userId`참가자의
  - `name`- 참가자의 이름
  - `picture`- 참가자의 그림 (모든 경우)
  - `customParticipantId`- 참가자를 식별 할 수있는 임의 ID
  - `isPinned`- 설정`true`participant가 pinned 경우에
  - `presetName`- 참가자와 관련된 미리 설정의 이름
</RTKCodeSnippet>

<RTKCodeSnippet id="mobile-android">
  #### Metadata 속성

  - `id`- 참가자가 회의 세션에 참여할 때 생성 된 세션 별 식별자 (일컬어`peerId`)
  - `userId`- 회의에 참여할 때 생성 된 참가자의 영구 식별자
  - `name`- 참가자의 표시 이름
  - `picture`- participant의 표시 그림에 문자열 URL (모든 경우)
  - `customParticipantId`- 고객의 회의에 참여하는 동안 설정할 수있는 사용자 정의 식별자
  - `isHost`- 이 참가자가 호스트 특전을 가지고 있는지 Boolean 값
  - `isPinned`- 이 참가자는 현재 회의에서 핀
  - `presetName`- 회의에 추가하는 동안이 참가자에게 적용되는 미리 설정의 이름
  - `stageStatus`- 참가자의 현재 단계 상태를 나타냅니다 (단계 지원 회의에서만 적용 가능)

## 지역 맵

<RTKCodeSnippet id={["web-web-components", "web-angular", "web-react", "mobile-react-native"]}>
  모든 참가자는 아래에 저장됩니다`meeting.participants`. 이들은 로컬 사용자를 포함하지 않습니다.

  더 보기`meeting.participants`객체는 다음과 같은 맵을 포함합니다:

  - **`joined`**- 현재 회의에서 모든 참가자 (지역 사용자 제외)
  - **`waitlisted`**- 모든 참가자는 회의에 참여
  - **`active`**- 미디어가 구독되는 모든 참가자 (화면에 표시되어야하는 참가자)
  - **`pinned`**- 회의에서 모든 pinned 참가자

  비디오 / 오디오 그리드를 구축하는 경우, 사용`active`지도. 모든 참가자의 목록을 표시하려면`joined`지도.

  이 맵의 각 참가자는 유형입니다`RTKParticipant`.
</RTKCodeSnippet>

## 모드 보기

관람 모드는 참가자가 참여하는 것을 나타냅니다.`ACTIVE_GRID`모드 또는`PAGINATED`모드.

- **`ACTIVE_GRID`지원하다**- 참가자는 자동으로 대체됩니다.`meeting.participants.active`누가 말하거나 누가 그들의 비디오가 켜져 있는지
- **`PAGINATED`지원하다**- 참가자`meeting.participants.active`고정. 제품 정보`setPage()`참여자 변경

### 설정 보기 모드

<RTKCodeSnippet id={["web-web-components", "web-angular"]}>
  ```js
  //paginated에 전망 형태를 놓으십시오
  await meeting.participants.setViewMode("PAGINATED");

  //보기 모드를 활성화 그리드로 설정
  await meeting.participants.setViewMode("ACTIVE_GRID");
  ```

## 호스트 컨트롤

participant 객체는 호스트의 여러 컨트롤을 허용합니다. 이 호스트를 만들면서 선택할 수 있습니다.[기타 제품](/api/resources/realtime_kit/subresources/presets/methods/create/).

### 미디어 컨트롤

올바른 권한으로 호스트는 원격 참가자를 위해 미디어를 비활성화 할 수 있습니다.

<RTKCodeSnippet id={["web-web-components", "web-angular"]}>
  ```js
  const participant = meeting.participants.joined.get(participantId);

  //participant의 비디오 스트림을 비활성화
  participant.disableVideo();

  //참가자의 오디오 스트림을 비활성화
  participant.disableAudio();

  //회의에서 참여
  participant.kick();
  ```
</RTKCodeSnippet>

<RTKCodeSnippet id="web-react">

### participant 권한 업데이트

<RTKCodeSnippet id={["web-web-components", "web-angular", "web-react", "mobile-react-native"]}>
  호스트는 참가자의 권한을 수정할 수 있습니다. 참가자의 권한은 사전 설정에 의해 정의됩니다.

  :::참조
  호스트가 참여자에게 권한을 업데이트 할 때, 미리 설정은 수정되지 않으며 권한 변경은 회의 기간에 제한됩니다.
  주요 특징
</RTKCodeSnippet>

<RTKCodeSnippet id={["mobile-android", "mobile-ios", "mobile-flutter"]}>
  참여 권한은 이 플랫폼에서 사용할 수 없습니다.
</RTKCodeSnippet>

<RTKCodeSnippet id={["web-web-components", "web-angular", "web-react", "mobile-react-native"]}>
  첫째, 업데이트하려는 participant(s)를 찾습니다.

  ```js
  const participantIds = meeting.participants.joined
  	.toArray()
  	.filter((e) => e.name.startsWith("John"))
  	.map((p) => p.id);
  ```

  사용 방법`updatePermissions`참가자의 권한을 수정하는 방법.

  ```js
  //파일 업로드 권한을 공공 채팅에서 허용
  const newPermissions = {
  	chat: {
  		public: {
  			files: true,
  		},
  	},
  };

  meeting.participants.updatePermissions(participantIds, newPermissions);
  ```

  다음 권한은 수정될 수 있습니다:

  ```typescript
  interface UpdatedPermissions {
  	polls?: {
  		canCreate?: boolean;
  		canVote?: boolean;
  	};
  	plugins?: {
  		canClose?: boolean;
  		canStart?: boolean;
  	};
  	chat?: {
  		public?: {
  			canSend?: boolean;
  			text?: boolean;
  			files?: boolean;
  		};
  		private?: {
  			canSend?: boolean;
  			text?: boolean;
  			files?: boolean;
  		};
  	};
  }
  ```
</RTKCodeSnippet>

## Display participant 동영상

<RTKCodeSnippet id={["web-web-components", "web-angular"]}>
  참가자의 비디오 트랙을 재생하려면`<video>`성분:

  ```html
  <video class="participant-video" id="participant-video"></video>
  ```

  ```js
  //비디오 요소 받기
  const videoElement = document.getElementById("participant-video");

  //참가자에게
  const participant = meeting.participants.joined.get(participantId);

  //동영상 요소 등록
  participant.registerVideoElement(videoElement);
  ```

  로컬 사용자 미리보기 (video not sent to other users) :

  ```js
  meeting.self.registerVideoElement(videoElement, true);
  ```

  비디오 요소가 더 이상 필요하지 않을 때 정리 :

  ```js
  participant.deregisterVideoElement(videoElement);
  ```
</RTKCodeSnippet>

  import { MediaStream, RTCView } from "@cloudflare/react-native-webrtc";

  	return (
  		<RTCView

  			mirror={true}
  			zOrder={1}

RealtimeKit는 음성 통화를 지원하며 오디오 룸, 지원 라인 또는 커뮤니티 행아웃과 같은 오디오 전용 경험을 구축할 수 있습니다.
이 회의에서 참가자들은 마이크를 사용하고 다른 사람들을 들지만 카메라를 사용할 수 없습니다. 음성 회의는 대역폭 요구 사항을 줄이고 오디오 통신에 중점을 둡니다.

## 오디오 통화 작업 방법

참가자의 회의 경험은**공지사항**그 participant에 적용.
음성 회의를 실행하려면 모든 참가자가 회의 유형 세트를 가지고있는 Preset과 함께 참여하십시오.`Voice`.

Presets에 대한 세부 사항 및 구성 방법, 참조[공지사항](/realtime/realtimekit/concepts/preset/).

## 가격 책정

참가자가 참여할 때`Voice`회의 유형 미리 설치, 그들은 간주됩니다**오디오 전용 참가자**청구를 위해. 이것은 Audio/Video 참가자를 위한 청구서에서 다릅니다.

자세한 가격 정보, 참조[가격 책정](/realtime/realtimekit/pricing/).

## 건축 오디오 경험

UI Kit 또는 Core SDK를 사용하여 음성 회의 경험을 구축할 수 있습니다.

### UI 키트

UI Kit는 사용자 정의 옵션과 사전 제작된 미팅 경험을 제공합니다.

참가자가 참여할 때`Voice`회의 유형 미리 설치, UI 키트는 자동으로 음성 전용 인터페이스를 렌더링합니다.
기본 회의 UI를 사용하거나 UI 키트 구성 요소를 사용하여 자신의 UI를 구축 할 수 있습니다.

get started, 참조[UI Kit를 사용하여 빌드](/realtime/realtimekit/ui-kit/).

### 핵심 SDK

Core SDK는 사용자 정의 오디오 전용 인터페이스를 구축하는 전체 컨트롤을 제공합니다. Video-related APIs는 참가자를 위한 비 기능입니다`Voice`유형 Presets.

get started에, 참고하십시오[Core SDK 사용](/realtime/realtimekit/core/).

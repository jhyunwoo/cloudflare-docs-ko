사전 설정은**re-usable 윤곽**회의에서 참가자의 경험을 정의합니다.
그것은 결정합니다:

- 회의 유형 (비디오, 오디오, 또는 웨비나)
- 그들이 수행 할 수있는 행동 (출발 및 통제)
- UI의 모양과 느낌, 색상과 테마를 포함, 그래서 경험은 응용의 브랜드 일치.

Presets는 App에 속하며 참가자에게는 적용되지 않습니다.

추가 Participant API를 통해 생성할 때 동일한 Preset을 여러 참가자에게 할당할 수 있습니다. 동일한 회의에 있는 참가자는 다른 미리 설치가 있을 수 있고, 각 사용자는 명백한 역할 및 경험이 있는 것을 허용하.

예: 대형 Ed-Tech 교실

- **뚱 베어**사용 방법`webinar-host`preset - 그들은 미디어 및 액세스 호스트 컨트롤을 공유 할 수 있습니다.
- **한국어**이용안내`webinar-participant`preset - 그들은 미디어를 공유 할 수 없지만 채팅과 같은 기능을 사용할 수 있습니다.
- **한국어**조력자는`group-call-host`preset - 그들은 미디어를 공유 할 수 있지만 전체 호스트 권한이 없습니다.

### Preset 만들기

기본 presets의 세트는 당신을 위해 창조됩니다, 당신이 앱을 통해 만들 때[Cloudflare dashboard](https://dash.cloudflare.com/?to=/:account/realtime/kit).

미리 설정할 수도 있습니다.[모델 번호: dashboard](https://dash.cloudflare.com/?to=/:account/realtime/kit)또는[Preset API 만들기](/api/resources/realtime_kit/subresources/presets/methods/create/).

```bash
curl https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/realtime/kit/$APP_ID/presets \
    -H 'Content-Type: application/json' \
    -H "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
    -d '{
          "config": {
            ...<preset-configuration-json>
        }'
```

### Preset 편집기

UI 기반 편집기를 제공하여 미리 설정할 수 있습니다.[Cloudflare dashboard](https://dash.cloudflare.com/?to=/:account/realtime/kit).

![Preset 편집기](~/assets/images/realtime/realtimekit/preset-editor.png)

허가는 다음과 같은 범주로 나뉩니다.

- **호스트 컨트롤:**&#xC774; 권한은 사용자가 회의를 제어하고, 참가자를 관리하고, 킥 사용자와 같은 관리 작업을 수행 할 수 있습니다, 다른 사람들과 더 많은 비디오 / 오디오.

- **단계 관리:**&#xD070; 회의는 가상 단계로 구성될 수 있습니다. 무대의 참가자들은 오디오 및 비디오를 공유 할 수 있으며, 참가자는이 미디어를 볼 수 있으며 채팅, 설문 조사 및 플러그인과 같은 기능을 사용합니다.

  사용자는 단계에 참여할 수 있습니다, 호스트는 어떤 시점에서 단계에서 사용자를 추가/제거 할 수 있습니다.
  단계 관리에 대해 자세히 알아보기[회사연혁](/realtime/realtimekit/concepts/meeting#stage).

- **채팅:**&#x52;ealtimeKit는 사용자가 실시간으로 메시지를 보내고 수신 할 수 있습니다. 개인 메시지를 보낼 수도 있습니다 (특정 사용자에서만 가능). 전송 및 메시지에 액세스하고 다양한 종류의 메시지를받을 수 있습니다.

- **오염:**&#xC0AC;용자가 작성할 수 있는 구성을 허용하고, 미팅에서 설문 조사와 상호 작용합니다.

- **플러그인:**&#xD50C;러그인은 협업을 쉽게 만들기 위해 회의 내에서 실행되는 대화 형 실시간 응용 프로그램입니다. RealtimeKit는 자체 플러그인을 구축하고 Whiteboard 및 Document Sharing과 같은 내장 옵션을 제공합니다.

  participant가 볼 수 있는 플러그인을 제어할 수 있습니다.

- **대기실:**&#xB300;기실은 참가자가 참석하기 전에 회의에 참여할 수 있으며, 호스트가 입력하고 언제든 제어할 수 있습니다. 접근을 관리하고 중단을 줄이고 회의가 원활하게 시작합니다.

  호스트는 언제든지 참가자를 인정하거나 제거 할 수 있으며 대기실을 자동으로 우회할 수 있습니다.
  대기실에 대해 더 알아보기[회사연혁](/realtime/realtimekit/concepts/meeting#waiting-room).

- **연결 회의:** <RTKPill>베타 베타</RTKPill>Connected Meetings는 메인 미팅에 연결된 공간, 소규모 그룹 토론 또는 병렬 세션을 가능하게 합니다. 참가자는 회의 또는 부모 회의로 돌아갈 수있는 권한을 부여 할 수 있습니다. 호스트는, 업데이트, 또는 이러한 연결된 공간을 삭제할 수 있습니다.

  연결 회의에 대해 자세히 알아보기[회사연혁](/realtime/realtimekit/concepts/meeting#connected-meetings).

- **기타 :**&#x4D;iscellaneous 권한은 특정 범주에서 떨어지지 않는 참가자 경험의 일부 추가 측면을 미세 조정 할 수 있습니다.

  이 옵션은 다음과 같은 기능을 제어 - 이름 편집, 참여 목록보기, 동기화 탭보기, 사용자가 회의 내에서 상호 작용하는 방법을 강화하는 비문 및 기타 보완 기능을 활성화.

### 오시는 길

회의 및 세션에 대한 학습 후 다음 단계를 탐험 할 수 있습니다.

- 더 보기[회사 소개](/realtime/realtimekit/concepts/participant)회의에 - 가입 할 수있는 관리, 그들의 역할, 그리고 액세스 제어 그들은 상속.
- 시작하기[RealtimeKit SDK는](/realtime/realtimekit/quickstart/)– RealtimeKit을 웹 또는 모바일 앱으로 통합하여 몇 줄의 코드가 있습니다.

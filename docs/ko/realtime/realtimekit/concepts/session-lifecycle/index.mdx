더 보기[세션 가이드](/realtime/realtimekit/concepts/meeting/#session)세션이 무엇인지와 어떻게 초기화하는지 설명합니다.
이 가이드에서는, 그들은 세션을 통해 이동으로 동료에 무슨 일이 일어나는지 이야기할 것입니다, 그들은 설정 화면에 갈 때, waitlist 스크린, 끝 스크린 또는 다른 어떤 스크린, 그리고 당신이 주문 작업을 수행하기 위해이 이벤트에 걸이 할 수있는 방법.

### 세션에서 Peer의 Lifecycle

![Peer 수명주기 세션에서](~/assets/images/realtime/realtimekit/peer-lifecycle.svg)

피어 라이프사이클이 어떻게 작동하나요?

1. **초기화 상태**: SDK가 초기화될 때, 동료는 처음에 참여하기 전에 오디오 및 비디오를 미리보기할 수 있는 Setup Screen을 볼 수 있습니다.
2. **로그인**: 동료가 참여하기로 결정하면 두 가지 중 하나는 다음과 같습니다.
   - 대기열이 활성화되면 대기열로 이동하여 대기열 화면을 볼 수 있습니다.
   - 대기하지 않으면 세션에 가입하고 다른 사람들과 상호 작용 할 수있는 주요 회의 화면 (Stage)를 참조하십시오.
3. **세션 중**: 동료는 주요 회의 화면 (Stage)에서 다른 사람들과 대화 할 수 있습니다.
4. **세션 전환**:
   - 피어가 대기 목록에서 거부되면 전용 거부 된 화면을 볼 수 있습니다.
   - 동료가 밖으로 걷고 있다면 그들은 끝없는 화면과 세션이 종료됩니다.
   - 동료가 배운 경우, 또는 회의가 끝나는 경우, 그들은 종료 된 화면을보고, 세션은 그들을 위해 끝납니다.

이 스크린의 각각은 UI 장비 성분으로 건축됩니다, 당신은 완전히 당신의 app의 디자인 및 필요조건 일치하기 위하여 주문을 받아서 만들 수 있습니다.

UI Kit SDK는 각 상태에 표시하는 알림이나 화면을 자동으로 처리하므로 이러한 전환을 수동으로 관리할 필요가 없습니다.

다가오는 페이지, 우리는이 이벤트에 후크가 맞춤 작업을 수행하고 자신의 맞춤 회의 경험을 구축하는 방법을 볼 것입니다.

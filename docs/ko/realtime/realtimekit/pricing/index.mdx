Cloudflare RealtimeKit는 현재 베타에 있으며 이 기간 동안 비용 없이 사용할 수 있습니다.

RealtimeKit가 일반 가용성 (GA)에 도달 할 때, 사용은 아래의 가격 모델에 따라 청구됩니다 :

| 제품 정보                             | 가격대비                    |
| --------------------------------- | ----------------------- |
| 오디오/영상 Participant                | $0.002 / 분              |
| 오디오 전용 참가자                        | $0.0005 / 분             |
| 수출 (기록, RTMP 또는 HLS 스트리밍)         | $0.010 / 분              |
| 수출 (기록, RTMP 또는 HLS 스트리밍, 오디오 전용) | $0.003 / 분              |
| R2                                | $0.0005 / 분             |
| (실시간)                             | Workers AI를 통해 표준 모형 가격 |

참가자는 오디오 전용 참가자 또는 오디오 / 비디오 참가자가 결정하는 것`Meeting Type`그들의[기타 제품](/realtime/realtimekit/concepts/preset/).

RealtimeKit는 Transcript 데이터에서 AI 전원 회의 요약을 생성합니다.

:::참조
[이름 \*](/realtime/realtimekit/ai/transcription/)summarization를 사용할 수 있습니다.
주요 특징

## 결제 옵션

설치하기`summarize_on_end: true`현재 위치[회의 만들기](/realtime/realtimekit/concepts/meeting/):

```json
{
  "title": "Product Review",
  "ai_config": {
    "transcription": {
      "language": "en-US"
    },
    "summarization": {
      "word_limit": 500,
      "text_format": "markdown",
      "summary_type": "team_meeting"
    }
  },
  "summarize_on_end": true
}
```

## 제품 설명

| 옵션 정보          | 제품정보  | 기본 정보        | 이름 \*                          |
| -------------- | ----- | ------------ | ------------------------------ |
| `word_limit`   | 이름 \* | 300          | 요약 길이 (150-1000 단어)            |
| `text_format`  | 이름 \* | `plain_text` | 산출 체재:`plain_text`또는`markdown` |
| `summary_type` | 이름 \* | `general`    | tailored summaries에 대한 회의 컨텍스트 |

### 관련 상품

더 나은 결과를 위해 회의를 일치하는 유형 선택:

| 제품정보                 | 제품 정보        |
| -------------------- | ------------ |
| `general`            | 모든 회의 (과태)   |
| `team_meeting`       | 일반 팀 동기화     |
| `daily_standup`      | 애자일 standups |
| `one_on_one_meeting` | 1:1 회의       |
| `sales_call`         | 고객 판매 대화     |
| `client_check_in`    | 고객 상태 업데이트   |
| `interview`          | 작업 인터뷰       |
| `lecture`            | 교육 내용        |
| `code_review`        | 기술 코드 리뷰     |

## 요약 요약

### 웹훅

설정하기`meeting.summary`행사일정[웹훅](/api/resources/realtime_kit/subresources/webhooks/):

```json
{
  "event": "meeting.summary",
  "meetingId": "meeting-123",
  "sessionId": "session-456",
  "summaryDownloadUrl": "https://...",
  "summaryDownloadUrlExpiry": "2024-08-14T10:15:30.000Z"
}
```

### REST API를

#### Fetch 요약

더 알아보기[세션에 대한 성적표 요약](/api/resources/realtime_kit/subresources/sessions/#fetch-summary-of-transcripts-for-a-session).

```bash
curl -X GET "https://api.cloudflare.com/client/v4/accounts/{account_id}/realtime/kit/{app_id}/sessions/{session_id}/summary" \
  -H "Authorization: Bearer {api_token}"
```

#### Trigger 수동으로

회의 후 요약 생성`summarize_on_end`설정되지 않았습니다. 더 알아보기[세션에 대한 성적표 요약](/api/resources/realtime_kit/subresources/sessions/#generate-summary-of-transcripts-for-the-session).

```bash
curl -X POST "https://api.cloudflare.com/client/v4/accounts/{account_id}/realtime/kit/{app_id}/sessions/{session_id}/summary" \
  -H "Authorization: Bearer {api_token}"
```

## 예제 출력

이름 \*`text_format: "markdown"`·`summary_type: "team_meeting"`:

```markdown
## Meeting Summary

### Key Discussion Points
- Reviewed Q4 roadmap priorities
- Discussed deployment timeline for v2.0
- Identified blockers for the auth migration

### Action Items
- @alice: Update design specs by Friday
- @bob: Schedule security review
- @charlie: Create migration runbook

### Decisions Made
- Approved moving forward with Kubernetes migration
- Delayed analytics dashboard to next sprint
```

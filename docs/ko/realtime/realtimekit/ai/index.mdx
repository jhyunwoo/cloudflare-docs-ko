RealtimeKit는 Cloudflare의 AI 인프라를 사용하여 AI 기반 기능을 제공하여 트래픽 및 요약 기능을 향상시킵니다.

<DirectoryListing />

## 사용 가능한 기능

| 제품 정보                                            | 이름 \*                        |
| ------------------------------------------------ | ---------------------------- |
| [이름 \*](/realtime/realtimekit/ai/transcription/) | 실시간 및 포스트-meeting 연설-to-text |
| [제품정보](/realtime/realtimekit/ai/summary/)        | AI-generated 회의 요약           |

## 빠른 시작

회의를 만들 때 Enable AI 특징:

```json
{
  "title": "Team Standup",
  "ai_config": {
    "transcription": {
      "language": "en-US"
    },
    "summarization": {
      "summary_type": "team_meeting"
    }
  },
  "summarize_on_end": true
}
```

참가자들은`transcription_enabled: true`그들의[기타 제품](/realtime/realtimekit/concepts/preset/).

- 을 통해[웹훅](/api/resources/realtime_kit/subresources/webhooks/)또는 REST API

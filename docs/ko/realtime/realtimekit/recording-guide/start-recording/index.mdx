이 항목은 RealtimeKit을 사용하여 합성 기록을 구현하는 방법을 설명합니다.

이 가이드를 시작하기 전에, 우리는 당신이 읽는 것을 추천합니다
[RealtimeKit 시작하기](/realtime/realtimekit/quickstart/)RealtimeKit로 자신을 익숙하게합니다.

RealtimeKit REST API로 자신을 익숙하게하려면, 우리는 탐험을 추천합니다[실시간Kit REST API](/api/resources/realtime_kit/).

RealtimeKit 회의 녹음을 시작하는 세 가지 방법이 있습니다.

- 사용 방법`record_on_start`플래그 when
  [회의 만들기](/api/resources/realtime_kit/subresources/meetings/methods/create/)
- 사용 방법[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/)
- SDK에서 클라이언트 측 시작 기록 방법

RealtimeKit는 7 일 동안 기록합니다. 만료되고 더 이상 접근 할 수 없습니다. 기록의 사본을 다운로드하는 것이 중요합니다.[설정 저장](/realtime/realtimekit/recording-guide/custom-cloud-storage/)링크가 만료되기 전에.

:::참조

1. 우리의 시스템은 현재 5 초 미만의 간략한 내구의 기록을 지원하지 않습니다. 이러한 경우, 녹화 API가 가끔 실패를 경험할 수 있다는 것입니다. 짧은 기간의 인코딩 녹음에 제한으로 인해 이러한 실패는 ERRORED 상태로 발생할 수 있습니다.
2. 녹음은 60 초 동안 회의에서 참가자가없는 경우 중지됩니다.
3. 기록의 1 시간 동안 평균 파일 크기는 약 300MB입니다.
4. 주어진 시간에 회의의 한 활성 녹음이있을 수 있습니다.`allow_multiple_recording`필드는 설정[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/).
5. 최대 기록 시간은 24 시간입니다. 기록은 자동적으로 후에 중지할 것입니다
   24 시간은 녹음 시작 시간 이후 탈출했다. 이 옵션은
   24시간까지 모든 값으로 구성`max_seconds`이름 \*
   내 계정[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/)이름 \*

:::

## 사용 방법`record_on_start`이름 \*

시간 :[회의 만들기](/api/resources/realtime_kit/subresources/meetings/methods/create/), 당신은 할 수 있습니다
이름 \*`record_on_start`누군가가 가입 한 즉시 녹음을 시작합니다.
회의.

:::note\[스펙팅 설정]

이 방법을 사용하여 녹화를 시작하려면 지정해야 합니다.
`storage-config`Developer Portal 사용

:::

### 제품 정보

이름 \*`record_on_start`모수. 이 플래그가 사실이라면 녹음
회의가 RealtimeKit, i.e에서 시작될 때,
참가자는 회의에 참여합니다.

```bash
curl --location 'https://api.cloudflare.com/client/v4/accounts/<account_id>/realtime/kit/<app_id>/meetings' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer <api_token>' \
  --data '{
  "title": "Lorem Ipsum",
  "record_on_start": true
}'
```

## 시작 기록 API 사용

녹화를 시작할 수 있습니다.
[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/).

이름 \*`meeting ID`당신이 기록하려는 회의의.

사용 방법[회의 목록 API](/api/resources/realtime_kit/subresources/meetings/methods/get/)한국어
앱 또는[미팅 API 만들기](/api/resources/realtime_kit/subresources/meetings/methods/create/)으로
회의 ID를 가져옵니다. API는 호출 매개 변수를 반환`id`, 당신의 것
회의 ID.

### 제품 정보

```bash title="Calling Start Recording API"
curl --location 'https://api.cloudflare.com/client/v4/accounts/<account_id>/realtime/kit/<app_id>/recordings' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer <api_token>' \
  --data '{
  "meeting_id": "97440c6a-140b-40a9-9499-b23fd7a3868a"
}'
```

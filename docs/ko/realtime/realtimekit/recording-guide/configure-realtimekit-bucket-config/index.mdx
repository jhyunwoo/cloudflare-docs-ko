녹화가 완료되면 RealtimeKit 는 RealtimeKit의 Cloudflare QXQXQXQXR2 버킷에 모든 레코딩을 업로드합니다. 또한, 할당 된 URL은 7 일 만료로 생성됩니다. 녹음은 사용할 수 있습니다.`downloadUrl`각 기록과 관련.

그러나 RealtimeKit는 RealtimeKit의 R2 Bucket에 녹화를 업로드하거나 있는지 여부를 선택할 수있는 유연성을 제공합니다. RealtimeKit의 버킷에 업로드를 비활성화하려면 설정할 수 있습니다.`realtimekit_bucket_config`false에 매개 변수[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/).

예를 들면:

```json
{
	"realtimekit_bucket_config": {
		"enabled": false
	}
}
```

:::참조

외부 저장 구성을 지정하지 않은 경우 RealtimeKit의 버킷에 업로드 할 수 없습니다. 잘못된 녹음으로 간주됩니다.

외부 저장 구성을 설정하는 방법에 대한 자세한 내용은, 참조[클라우드 공급자에 기록된 파일](/realtime/realtimekit/recording-guide/custom-cloud-storage/).

:::

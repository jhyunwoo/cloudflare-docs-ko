옵션 객체를 전달할 수 있습니다.`storage_config`시작 녹음 요청에서
클라우드 공급자에게 직접 녹화를 게시합니다. 이름 \*`path`이름 \*
지정된 기록 된 비디오는 저장됩니다. 그렇지 않으면 기본값은
디렉토리의 루트.

기록의 파일 이름은 주어진 것과 동일합니다`output_file_name`.

:::참조

RealtimeKit APIs에 제공하는 클라우드 키가 한정된 액세스가 보장됩니다.

:::

## 저장 설정

RealtimeKit Recordings에 대한 스토리지 구성을 다음과 같은 방법으로 구성할 수 있습니다.

### RealtimeKit Dashboard를 사용하여 스토리지 구성 세부 설정

RealtimeKit Dashboard를 사용하여 스토리지 구성 세부 사항을 지정할 수 있습니다.

1. Cloudflare에서[RealtimeKit 대시보드](https://dash.cloudflare.com/?to=/:account/realtime/kit), 기록 탭으로 이동.
2. 이름 \***Setup 저장**.
3. 클라우드 공급자의 세부 사항을 지정합니다. 고객 지원
   CloudflareQXR2, AWS S3, Azure, DigitalOcean 및 Google Cloud Storage (GCS) 버킷에 레코딩합니다.

![녹화 저장 스크린샷](~/assets/images/realtime/realtimekit/setup-recording-storage.png)

<br />

:::참조

저장 구성을 지정하면[시작 기록](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/)API 요청,
RealtimeKit Dashboard에 설정된 스토리지 세부 정보를 통해 구성됩니다.

:::

RealtimeKit REST API로 자신을 익숙하게하려면, 우리는 탐험을 추천합니다[실시간Kit REST API](/api/resources/realtime_kit/).

### 사용 방법`storage_config`시작 기록 API 옵션

이것은 대부분의 granular 수준의 제어를 허용하고, 당신은 특정한 storage config를 지정할 수 있습니다
[기록 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/)회의에.

```bash
curl --request POST \
  --url https://api.cloudflare.com/client/v4/accounts/<account_id>/realtime/kit/<app_id>/recordings \
  --header 'Authorization: Bearer <api_authorization_token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "meeting_id": "97440c6a-140b-40a9-9499-b23fd7a3868a",
  "storage_config": {
    "type": "cloudflare",
    "access_key": "your-access-key",
    "secret": "your-secret-key",
    "bucket": "your-bucket-name",
    "path": "/"
  }
}'
```

RealtimeKit REST API로 자신을 익숙하게하려면, 우리는 탐험을 추천합니다[실시간Kit REST API](/api/resources/realtime_kit/).

## 클라우드 공급자 지원

현재 다음과 같은 클라우드 공급자가 지원됩니다.

### Cloudflare R2

Cloudflare R2에 녹화를 전송하려면 다음 필드를 설정하십시오.
이름 \*`storage_config`모수:

- 유형: 지정`cloudflare`.
- 접근 열쇠: 당신의 R2 접근 열쇠 ID를 입력하십시오. 더 많은 정보를 원하시면,[API 토큰 만들기](/r2/api/tokens/).
- 물통: 당신의 R2 물통의 이름을 입력하십시오.
- (선택) 경로: 기록이 있어야 하는 하위 폴더에 경로 지정
  전송. 이 매개 변수가 전달되지 않은 경우, 녹음이 전송됩니다.
  물통의 루트 폴더에.
- 비밀: 당신의 R2 비밀 접근 열쇠를 입력하십시오.
- 계정 ID: Cloudflare 계정 ID를 입력하십시오.

### 사이트맵

AWS S3 버킷에 레코딩을 전송하려면 다음 필드를 설정하십시오.
`storage_config`모수:

- 유형: 지정`aws`.
- 액세스 키: 입력`aws_access_key_id`.
- 물통: 당신의 AWS S3 물통 이름을 입력하십시오.
- (선택) 경로: 기록이 있어야 하는 하위 폴더에 경로 지정
  전송. 이 매개 변수가 전달되지 않은 경우, 녹음이 전송됩니다.
  물통의 루트 폴더에.
- 비밀: 입력`aws_secret_access_key`.
- 지역: 당신의 물통이 호스팅되는 지역을 지정하십시오, 예를 들면,
  `ap-south-1`.

### Azure Blob 스토리지

Azure Blob Storage로 녹화를 전송하려면 다음 필드를 설정하십시오.
이름 \*`storage_config`모수:

- 유형: 지정`azure`.
- 액세스 키: azure 연결 문자열을 입력하십시오. 자세한 내용은
  액세스 키를 얻을, 참조
  [계정 액세스 키 보기](https://learn.microsoft.com/en-us/azure/storage/common/storage-account-keys-manage?toc=%2Fazure%2Fstorage%2Fblobs%2Ftoc.json\&bc=%2Fazure%2Fstorage%2Fblobs%2Fbreadcrumb%2Ftoc.json\&tabs=azure-portal#view-account-access-keys).
- 물통: 당신의 콘테이너의 이름을 입력하십시오. 컨테이너는 동일해야
  연결 문자열로 저장 계정.
- (선택) 경로: 기록이 있어야 하는 하위 폴더에 경로 지정
  전송. 이 매개 변수가 전달되지 않은 경우, 녹음이 전송됩니다.
  컨테이너의 루트 폴더에.
- 비밀: 공백 문자열로 설정 "".
- 지역: 공백 문자열로 설정 "".

### 디지털Ocean

DigitalOcean Spaces에 녹화를 전송하려면 다음 필드를 설정하십시오.
이름 \*`storage_config`모수:

- 유형: 지정`digitalocean`.
- 액세스 키: 디지털 바다 액세스 키 입력. 더 많은 정보를 원하시면,
  [DigitalOcean Space 및 API Key 생성](https://www.digitalocean.com/community/tutorials/how-to-create-a-digitalocean-space-and-api-key).
- Bucket: 스페이스 버킷의 이름을 입력합니다.
- (선택) 경로: 기록이 있어야 하는 하위 폴더에 경로 지정
  전송. 이 매개 변수가 전달되지 않은 경우, 녹음이 전송됩니다.
  컨테이너의 루트 폴더에.
- 비밀: 스페이스 비밀을 입력.
- 지역 : 스페이스 버킷이 호스팅되는 지역을 지정합니다. 예를 들어,
  `SGP1`. 더 많은 정보를 위해, 보기
  [지역 가용성 모체](https://docs.digitalocean.com/products/platform/availability-matrix/).

### Google 클라우드 스토리지 (GCS)

GCS로 녹화를 전송하려면 다음 필드를 설정하십시오.
이름 \*`storage_config`모수:

- 유형: 지정`gcs`.
- Bucket: Cloud Storage Bucket의 이름을 입력합니다.
- (선택) 경로: 기록이 있어야 하는 하위 폴더에 경로 지정
  전송. 이 매개 변수가 전달되지 않은 경우, 녹음이 전송됩니다.
  컨테이너의 루트 폴더에.
- 비밀: 서비스 계정 자격 증명을 입력하십시오. 더 많은 정보를 원하시면,[서비스 계정 자격](https://developers.google.com/workspace/guides/create-credentials#service-account).
- 지역 : Cloud Storage Bucket이 호스팅되는 지역을 지정합니다. 예를 들어,
  `US multi-region`. 더 많은 정보를 위해, 보기
  [물통 위치](https://cloud.google.com/storage/docs/locations).

## 녹음 파일 이름 업데이트

녹화 파일의 이름을 변경할 수 있습니다.`file_name_prefix`이름 \* 기록된 파일 이름의 기본 형식은`roomname_timestamp`, 그러나 당신은 기본 파일 이름에 알파벳 및 underscore prefix를 추가할 수 있습니다.

기본 형식에 접두사를 추가할 수 있는 것이 중요합니다. 전체 파일 이름을 변경할 수 없습니다. 예를 들어 RealtimeKit을 사용하여 9 a.m에서 온라인 물리 수업을 가르치면 추가 할 수 있습니다.`Physics_9am`파일 이름에.`Physics_9am_roomname_timestamp`새 파일 이름이 될 것입니다.

더 많은 정보를 원하시면,[회의를 녹음](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/).

RealtimeKit의 워터 마크 기능은 녹음에서 워터 마크로 이미지를 포함 할 수 있습니다. 워터 마크를 추가하려면 다음 매개 변수를 video config로 구성하십시오.[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/).

| **제품 설명** | **이름 \***                                                                                   |
| --------- | ------------------------------------------------------------------------------------------- |
| 사이트 맵     | 워터마크 이미지의 URL을 지정합니다.                                                                       |
| 제품정보      | 워터 마크의 배치를 지정하면 왼쪽 상단, 오른쪽 상단, 왼쪽 하단 또는 오른쪽 하단 사이에 선택할 수있는 유연성이 있습니다. 기본 위치는 왼쪽 상단으로 설정됩니다. |
| 크기 (mm)   | 픽셀의 워터 마크의 높이와 너비를 지정합니다.                                                                   |

```json
{
  "video_config": {
    "watermark": {
      "url": "https://test.io/images/client-logos-6.webp",
      "position": "left top",
      "size": {
        "height": 20,
        "width": 100
      }
    }
  }
}
```

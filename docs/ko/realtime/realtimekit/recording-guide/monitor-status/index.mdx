## 기록 국가

회의의 기록은 다음과 같은 상태를 가질 수 있습니다.

| 이름 \* | 이름 \*                                                                                                                        |
| ----- | ---------------------------------------------------------------------------------------------------------------------------- |
| 구매하기  | 우리의 백엔드 서버는 녹음 요청을 받았고 마스터는 녹음 작업을 할당 할 준비가 된 노동자를 찾고 있습니다.                                                                  |
| 공지사항  | 회의는 현재 노동자에 의해 기록되고있다; 회의가 라이브 스트림 인 경우이 진실을 보유 할 것이다.                                                                       |
| 공지사항  | 녹음이 멈추고 파일이 클라우드 저장소에 업로드되었습니다. 지정된 저장 정보가 없는 경우 RealtimeKit 서버에서만 파일을 업로드할 수 있습니다. 모든 RTMP 및 livestreaming 링크는이 단계에서 중지됩니다. |
| 공지사항  | 녹화 파일 업로드는 완료되고 상태 webhook도 트리거됩니다.                                                                                          |
| 제품정보  | 회의를 기록하고 파일을 사용할 수 없습니다 동안 취소 할 수없는 오류가있었습니다.                                                                                |

## 국가 찾기

어떤 국가를 추적할 수 있는 두 가지 방법이 있습니다.
녹음에 대한 세부 사항:

### 사용 방법`recording.statusUpdate`웹훅

RealtimeKit 는`recording.statusUpdate`webhook 각 시간 녹화
그 수명주기 동안 국가의 전환. RealtimeKit 앱에서 webhooks를 구성하여 이러한 알림을 수신합니다.

### HTTP API를 투표

또는 다음 API를 사용할 수도 있습니다.

- [기록 목록](/api/resources/realtime_kit/subresources/recordings/methods/get_recordings/)::
  이 엔드포인트는 회의에 연결된 모든 과거 및 지속적인 녹음을 가져옵니다.
- [Fetch 활동 기록](/api/resources/realtime_kit/subresources/recordings/methods/get_active_recordings/): 이
  endpoint는 회의의 모든 지속적인 녹음을 가져옵니다.
- [기록의 Fetch 세부 사항](/api/resources/realtime_kit/subresources/recordings/methods/get_one_recording/): 이
  endpoint는 레코드 ID를 사용하여 특정 기록을 가져옵니다.

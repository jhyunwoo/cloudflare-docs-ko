RealtimeKit는 회의에서 여러 사용자의 오디오 및 비디오뿐만 아니라
RealtimeKit 플러그인과의 상호 작용, 복합 레코딩 모드를 사용하여 단일 파일.

## RealtimeKit 녹화는 어떻게 작동합니까?

RealtimeKit 녹음은 익명의 가상 봇 사용자에 의해 구동됩니다.
회의, 그것을 기록하고, RealtimeKit의 Cloudflare R2 물통에 올려주기하십시오. 영상 파일을 위해,
현재 지원
[크기: H.264](https://en.wikipedia.org/wiki/Advanced_Video_Coding)·
[사이트맵](https://en.wikipedia.org/wiki/VP8)코드.

1. 기록이 완료되면 RealtimeKit의 Cloudflare R2 물통에 저장됩니다.

2. RealtimeKit는 녹음이 될 수있는 다운로드 링크를 생성합니다.
   다운로드 다운로드 URL을 사용하여 얻을 수 있습니다.
   [레코딩 API의 Fetch 세부 사항](/api/resources/realtime_kit/subresources/recordings/)또는 Developer Portal에서.

   다음의 기록 상태의 알림을 받을 수 있습니다.
   방법:

   - 사용 방법`recording.statusUpdate`웹훅. RealtimeKit는 이벤트가 발생할 때 응용 프로그램을 통지하는 웹훅을 사용합니다.
   - 사용 방법[Fetch 활성 레코딩 API](/api/resources/realtime_kit/subresources/recordings/methods/get_active_recordings/).
   - Developer Portal에서 녹음 상태를 볼 수 있습니다.

3. 다운로드 URL에서 녹음을 다운로드하고 클라우드에 저장
   저장. 이 파일은 RealtimeKit의 서버에서 7 일 전에 유지됩니다
   로그아웃

   다운로드 URL을 사용하여 얻을 수 있습니다.
   [Fetch 활성 레코딩 API](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/)또는
   개발자 포털에서.

   AWS, Azure 및 DigitalOcean 스토리지로 전송 기록을 지원합니다.
   물통. 저장 구성을 미리 설정할 수도 있습니다.
   개발자 포털 또는
   [미팅 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/).

## 작업 흐름

회의를 녹음하기위한 전형적인 작업 흐름은 다음과 같습니다.

1. 녹음 시작[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/)또는 클라이언트 측 SDK.
2. 녹음을 중지[기록 API](/api/resources/realtime_kit/subresources/recordings/)또는 클라이언트 측 SDK.
3. 기록 다운로드 URL을 Fetch[Fetch 레코드 세부 정보 API](/api/resources/realtime_kit/subresources/recordings/methods/get_one_recording/), webhook, 또는 개발자 포털에서.

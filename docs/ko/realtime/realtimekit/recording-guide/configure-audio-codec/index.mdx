녹음 오디오는 구성해야 합니다.**코덱**·**채널 :**&#xCD5C;적의 품질과 호환성을 보장하는 매개 변수.
코덱은 오디오용 인코딩 형식을 결정하고, 채널은 녹음용 오디오 채널의 수를 지정합니다.
다음을 수정할 수 있습니다.`audio_config`오디오 녹음을 위해 사용하는:

## 비밀번호

Codec는 MP3 및 AAC가 지원되는 형식으로 녹화를 위한 오디오 인코딩 형식을 결정합니다.

- AAC (과태)
- MP3 다운로드

:::참조

이름 \*[사이트맵](/realtime/realtimekit/recording-guide/configure-codecs/)선택 사항`video_config`, 변화`audio_config`허용되지 않습니다. 이 경우, 코덱에`audio_config`자동 설정`vorbis`.

:::

## 채널 :

특정 사운드 소스를 운반하는 오디오 파일 내의 오디오 신호 통로. 다음 채널은 지원됩니다:

- 스테레오 (과태)
- 모노모

configs를 수정할 수 있습니다.`audio_config`현장에[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/)예를 들면:

```json
{
  "audio_config": {
    "codec": "AAC"
    "channel": "stereo"
  }
}
```

## 오디오 파일 다운로드

녹음을 위한 오디오 파일이 생성되는 경우에만`audio_config`매개 변수[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/).

녹음이 완료되면 사용할 수 있습니다.`audio_download_url`응답 몸에서 제공[레코딩 API의 Fetch 세부 사항](/api/resources/realtime_kit/subresources/recordings/methods/get_one_recording/)오디오 파일을 다운로드 및 내보내기합니다.

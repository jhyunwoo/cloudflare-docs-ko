RealtimeKit 기록은 다음과 같은 방법으로 중지 될 수 있습니다:

1. **자동 정지 (Empty 회의)**: RealtimeKit 레코딩은 자동으로 중지됩니다.
   회의는 1 분 이상 참가자가 없습니다. 이름 \*
   대기 시간은 RealtimeKit의 지원 팀에 연락하여 사용자 정의 할 수 있습니다.
   앱에 대한 사용자 정의 값.
2. **자동 정지 (maxSeconds elapsed)**: 녹음이 자동으로 중지됩니다.
   지정된 기간에 도달하면`max_seconds`매개 변수
   참가자가 존재 여부에 관계없이 녹음을 시작하면서
   회의에서. 이 매개 변수가 전달되지 않은 경우, 기본값은 24 시간
   (86400 초).
3. **Stop Recording API 사용**: 녹음도 중지할 수 있습니다.
   기록 ID 및`stop`활동하기[기록 API](/api/resources/realtime_kit/subresources/recordings/).

녹음이 중지되면 전환`UPLOADING`상태와 그 후에`UPLOADED`RealtimeKit의 저장 및 설정된 외부 저장소로 전송 된 후 상태.

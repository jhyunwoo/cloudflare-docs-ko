RealtimeKit의 대화 형 레코딩 기능은 비디오 스트림에 타임 메타 데이터를 추가 할 수 있습니다. Timed metadata는 고객을위한 cue 포인트로 정보를 표시하고 시간 정렬 작업을 트리거합니다. metadata는 고객의 형태로 제공됩니다.[신분증3](https://en.wikipedia.org/wiki/ID3)재생 타임 라인에 태그.

## 대화형 녹음이란?

Netflix가 찾는 바에 작은 이미지를 표시하거나 Hotstar에서 크리켓 일치를 보는 동안 추가 콘텐츠가 어떻게 보일까요? 그것은 비디오 피드 자체 내부에 특정 시간에 삽입 된 모든 메타 데이터, 이는 timed 메타 데이터라고.

Timed 메타데이터는 타임스탬프와 메타데이터입니다. 콘텐츠 범위의 특정 지점에서 추가 컨텍스트 및 정보를 제공하기 위해 비디오 파일에 추가 된 디지털 마커를 나타냅니다. 이 데이터 포인트는 스트림 programmatically에 삽입 할 수 있습니다.`interactive_config`내 계정[미팅 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/).

RealtimeKit가 스트림을 처리하면 timed metadata는 오디오 및 비디오 프레임과 동기화됩니다. 이 메타데이터는 스트림과 같은 시간에 재생하는 동안 모든 시청자에게 사용할 수 있습니다. timecode는 cue 포인트로 작동하며 데이터를 기반으로 특정 작업을 트리거 할 수 있습니다. 예를 들면:

이 기능은 비디오 세그먼트에 내장 된 ID3 태그의 사용을 통해 가능합니다. 기록 된 비디오에서 사용할 수 있습니다.

## RealtimeKit 녹음에 대한 상호 작용

RealtimeKit 녹음에 대한 상호 작용을 추가하려면 다음 단계를 수행하십시오.

1. 내 계정[미팅 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/), 패스`interactive_config`모수.

이 매개 변수는 ID3 태그를 통해 HLS 형식으로 클라이언트에 사용할 수있는 녹화에 timed 메타 데이터를 추가 할 수 있습니다. 출력 파일은 tar 파일로 포장됩니다.

2. 내 계정[RealtimeKit클라이언트](https://docs.realtime.cloudflare.com/web-core/reference/RealtimeKitClient), 전화`broadcastMessage`매개변수를 가진 방법,`ID3`(문자)와`yourData`(Timed metadata로 보낼 데이터)[회사연혁](https://docs.realtime.cloudflare.com/web-core/reference/RealtimeKitClient#module_RealtimeKitClient+participants)객체.

```ts
meeting.participants.broadcastMessage(“ID3Data”, yourData);
```

:::참조

이 작업은 녹음이 시작된 후만 수행되어야하며 시스템은`RECORDING`국가. 이전에 수행 한 경우, 관련 ID3 태그가 손실 될 수 있습니다.

이 작업을 수행 할 수있는 권장 시간은 기록 지표가 3 \~ 4 초 동안 표시됩니다.

:::

3. 데이터를 전송하려면 다음 방법을 호출합니다. 이 호출을하면 더 이상 ID3 데이터를 보낼 수 없습니다.

```ts
meeting.participants.broadcastMessage(“ID3Data”,”CLOSE_TRANSPORT”)
```

이 매개 변수를 통과하지 않는 경우, ID3 메타 데이터 스트림은 기록이 중지 될 때 자동으로 닫힙니다.

4. 녹화가 완료되면 비디오 세그먼트와 재생 목록을 포함하는 tar 파일을 검색할 수 있습니다. 더 보기`download_url`tar 파일에 대한 링크를 제공합니다. 아래는 tar 파일의 예 스크린 샷입니다:

![기록 Tar 체재](~/assets/images/realtime/realtimekit/interactive-recording-tar-format.png)

각 세그먼트의 길이는 비디오의 프레임에 따라 달라집니다. 따라서, 각 세그먼트는 기록이 시작될 때 지정된 세그먼트 길이에 전형적으로 가깝더라도 동일한 길이가 있을지도 모릅니다. 기본적으로 세그먼트 길이는 10 초로 설정됩니다.

5. 스트림을 재생할 수 있습니다.[`hls.js`](https://github.com/video-dev/hls.js/).

```js
const onFragChanged = (_) => {
  //우리는 먼저 올바른 metadata 트랙을 찾아보십시오.
  //https://developer.mozilla.org/en-US/docs/Web/API/TextTrack
  const textTrackListCount = videoEl.textTracks.length;
  let metaTextTrack;
  for (let trackIndex = 0; trackIndex < textTrackListCount; trackIndex++) {
    const textTrack = videoEl.textTracks[trackIndex];
    if (textTrack.kind !== 'metadata') {
      continue;
    }
    textTrack.mode = 'showing';
    metaTextTrack = textTrack;
    break;
  }
  if (!metaTextTrack) {
    return;
  }
  //해당 트랙의 oncuechange listener를 추가하십시오.
  metaTextTrack.oncuechange = (event) => {
    let cue = metaTextTrack.activeCues[metaTextTrack.activeCues.length - 1];
    console.log(cue.value.data);
  };
};
//hls.js에서 Hls.Events.FRAG CHANGED에 대해 알아보기
hls.on(Hls.Events.FRAG_CHANGED, onFragChanged);
```

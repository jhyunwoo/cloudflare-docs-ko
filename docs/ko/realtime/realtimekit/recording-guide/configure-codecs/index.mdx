비디오 코덱은 전송, 저장 또는 재생을위한 디지털 비디오 데이터를 압축하고 decompress하는 소프트웨어 프로그램입니다. 적절한 비디오 코덱 구성은 파일 크기를 줄이고 비디오 품질을 향상시키고 다른 재생 장치와 호환성을 보장합니다.

## Codecs 구성

동영상 녹화에 사용되는 코덱을 수정할 수 있습니다. 현재 위치
다음 코덱 지원:

- **H264 (과태)**: 1280px × 720px의 H.264 코덱을 사용하여 비디오 녹화
  해상도 및 MP4 컨테이너의 384kbps AAC 오디오.
- **사이트맵**: 1280px × 720px의 VP8 코덱을 사용하여 비디오 녹화
  WebM 컨테이너의 Vorbis 코덱 오디오.

코덱을 지정하여 코덱을 변경할 수 있습니다.`video_config`내 계정
이름 \*[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/), 를 위해
예:

```json
{
  "video_config": {
    "codec": "H264"
  }
}
```

## Video Files 다운로드

녹화에 대한 비디오 파일은 만 생성됩니다.`video_config`매개 변수[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/).

녹음이 완료되면 사용할 수 있습니다.`downloadUrl`응답 몸에서 제공[녹화 API 시작](/api/resources/realtime_kit/subresources/recordings/methods/start_recordings/)다운로드 및 내보내기 비디오 파일.

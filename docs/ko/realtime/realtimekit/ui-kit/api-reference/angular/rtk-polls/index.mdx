모든 가능한 플러그인을 나열하는 구성 요소는 사용자가 액세스 할 수 있습니다.
해당 이용 후기에 달린 코멘트가 없습니다.

## 제품 정보

| 회사 정보      | 제품정보       | 견적 요청 | 기본 정보                   | 이름 \*   |
| ---------- | ---------- | ----- | ----------------------- | ------- |
| `config`   | `UIConfig` | ❌     | `createDefaultConfig()` | 사이트맵    |
| `iconPack` | `IconPack` | ❌     | `defaultIconPack`       | Icon 팩  |
| `meeting`  | `Meeting`  | ✅     | -                       | 회의 목표   |
| `size`     | `Size`     | ✅     | -                       | 크기 (mm) |
| `t`        | `RtkI18n`  | ❌     | `useLanguage()`         | 한국어     |

## 사용 예제

### 기본 사용

```html
<!--구성 요소.html-->
<rtk-polls></rtk-polls>
```

### 재산

```html
<!--구성 요소.html-->
<rtk-polls
 [meeting]="meeting"
 size="md">
</rtk-polls>
```

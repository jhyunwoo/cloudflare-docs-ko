RTK 디자인 시스템을 따르는 스위치 구성 요소.

## 제품 정보

| 회사 정보      | 제품정보       | 견적 요청 | 기본 정보             | 이름 \*              |
| ---------- | ---------- | ----- | ----------------- | ------------------ |
| `checked`  | `boolean`  | ✅     | -                 | 스위치가 활성화 / 검사 여부   |
| `disabled` | `boolean`  | ✅     | -                 | 스위치가 readonly인지 여부 |
| `iconPack` | `IconPack` | ❌     | `defaultIconPack` | Icon 팩             |
| `readonly` | `boolean`  | ✅     | -                 | 스위치가 readonly인지 여부 |
| `t`        | `RtkI18n`  | ❌     | `useLanguage()`   | 한국어                |

## 사용 예제

### 기본 사용

```html
<!--구성 요소.html-->
<rtk-switch></rtk-switch>
```

### 재산

```html
<!--구성 요소.html-->
<rtk-switch
 [checked]="true"
 [disabled]="true"
 [readonly]="true">
</rtk-switch>
```

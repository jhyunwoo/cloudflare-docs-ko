increment와 decrement 단추를 가진 수 피커.

## 제품 정보

| 회사 정보      | 제품정보        | 견적 요청 | 기본 정보             | 이름 \*   |
| ---------- | ----------- | ----- | ----------------- | ------- |
| `iconPack` | `IconPack1` | ❌     | `defaultIconPack` | Icon 팩  |
| `minValue` | `number`    | ✅     | -                 | 최소 값    |
| `size`     | `Size1`     | ✅     | -                 | 크기 (mm) |
| `t`        | `RtkI18n`   | ❌     | `useLanguage()`   | 한국어     |
| `value`    | `number`    | ✅     | -                 | 초기 값    |

## 사용 예제

### 기본 사용

```html
<!--구성 요소.html-->
<rtk-counter></rtk-counter>
```

### 재산

```html
<!--구성 요소.html-->
<rtk-counter
 minValue="42"
 size="md"
 value="42">
</rtk-counter>
```

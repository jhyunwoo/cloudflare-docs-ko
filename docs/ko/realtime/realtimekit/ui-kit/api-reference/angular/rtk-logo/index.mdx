구성에서 로고를로드하는 구성 요소 또는`logo-url`이름 \*

## 제품 정보

| 회사 정보     | 제품정보       | 견적 요청 | 기본 정보                   | 이름 \*     |
| --------- | ---------- | ----- | ----------------------- | --------- |
| `config`  | `UIConfig` | ❌     | `createDefaultConfig()` | Config 객체 |
| `logoUrl` | `string`   | ✅     | -                       | 로고 URL    |
| `meeting` | `Meeting`  | ✅     | -                       | 회의 목표     |
| `t`       | `RtkI18n`  | ❌     | `useLanguage()`         | 한국어       |

## 사용 예제

### 기본 사용

```html
<!--구성 요소.html-->
<rtk-logo></rtk-logo>
```

### 재산

```html
<!--구성 요소.html-->
<rtk-logo
 logoUrl="example"
 [meeting]="meeting">
</rtk-logo>
```

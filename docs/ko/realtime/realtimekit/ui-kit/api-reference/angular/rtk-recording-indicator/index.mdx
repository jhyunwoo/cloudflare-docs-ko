회의의 기록 상태를 나타냅니다.
녹음이 일어나지 않는 경우 아무것도 렌더링하지 않습니다.

## 제품 정보

| 회사 정보      | 제품정보       | 견적 요청 | 기본 정보             | 이름 \*   |
| ---------- | ---------- | ----- | ----------------- | ------- |
| `iconPack` | `IconPack` | ❌     | `defaultIconPack` | Icon 팩  |
| `meeting`  | `Meeting`  | ✅     | -                 | 회의 목표   |
| `size`     | `Size`     | ✅     | -                 | 크기 (mm) |
| `t`        | `RtkI18n`  | ❌     | `useLanguage()`   | 한국어     |

## 사용 예제

### 기본 사용

```html
<!--구성 요소.html-->
<rtk-recording-indicator></rtk-recording-indicator>
```

```html
<!--구성 요소.html-->
<rtk-recording-indicator
 [meeting]="meeting"
 size="md">
</rtk-recording-indicator>
```

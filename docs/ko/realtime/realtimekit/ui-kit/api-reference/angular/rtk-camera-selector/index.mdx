오디오 장치와 오디오 preferenceS를 관리할 수 있는 구성품.
사이트맵`rtkStateUpdate`muting 통보를 위한 자료로 사건 소리:

```ts
{
 prefs: {
   muteNotificationSounds: boolean
 }
}
```

## 제품 정보

| 회사 정보      | 제품정보                 | 견적 요청 | 기본 정보             | 이름 \*   |
| ---------- | -------------------- | ----- | ----------------- | ------- |
| `iconPack` | `IconPack`           | ❌     | `defaultIconPack` | Icon 팩  |
| `meeting`  | `Meeting`            | ✅     | -                 | 회의 목표   |
| `size`     | `Size`               | ✅     | -                 | 크기 (mm) |
| `t`        | `RtkI18n`            | ❌     | `useLanguage()`   | 한국어     |
| `variant`  | `'full' \| 'inline'` | ✅     | -                 | 기타 제품   |

## 사용 예제

### 기본 사용

```html
<!--구성 요소.html-->
<rtk-camera-selector></rtk-camera-selector>
```

### 재산

```html
<!--구성 요소.html-->
<rtk-camera-selector
 [meeting]="meeting"
 size="md"
 [variant]="'full' | 'inline'">
</rtk-camera-selector>
```

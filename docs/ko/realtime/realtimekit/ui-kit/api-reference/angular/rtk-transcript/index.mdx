transcript를 보여주는 구성 요소.
당신은 후에 요소를 제거해야합니다.
`rtkTranscriptDismiss`이벤트

## 제품 정보

| 회사 정보        | 제품정보                                   | 견적 요청 | 기본 정보           | 이름 \* |
| ------------ | -------------------------------------- | ----- | --------------- | ----- |
| `t`          | `RtkI18n`                              | ❌     | `useLanguage()` | 한국어   |
| `transcript` | `Transcript & { renderedId?: string }` | ❌     | -               | 이름 \* |

## 사용 예제

### 기본 사용

```html
<!--구성 요소.html-->
<rtk-transcript></rtk-transcript>
```

### 재산

```html
<!--구성 요소.html-->
<rtk-transcript
 [t]="rtki18n"
 transcript="example">
</rtk-transcript>
```

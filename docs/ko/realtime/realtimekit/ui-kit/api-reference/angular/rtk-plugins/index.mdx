사전 설정에서 모든 사용 가능한 플러그인을 나열하는 구성 요소,
플러그인을 활성화하거나 비활성화 할 수있는 능력.

## 제품 정보

| 회사 정보      | 제품정보       | 견적 요청 | 기본 정보                   | 이름 \*   |
| ---------- | ---------- | ----- | ----------------------- | ------- |
| `config`   | `UIConfig` | ❌     | `createDefaultConfig()` | 사이트맵    |
| `iconPack` | `IconPack` | ❌     | `defaultIconPack`       | Icon 팩  |
| `meeting`  | `Meeting`  | ✅     | -                       | 회의 목표   |
| `size`     | `Size`     | ✅     | -                       | 크기 (mm) |
| `t`        | `RtkI18n`  | ❌     | `useLanguage()`         | 한국어     |

## 사용 예제

### 기본 사용

```html
<!--구성 요소.html-->
<rtk-plugins></rtk-plugins>
```

### 재산

```html
<!--구성 요소.html-->
<rtk-plugins
 [meeting]="meeting"
 size="md">
</rtk-plugins>
```

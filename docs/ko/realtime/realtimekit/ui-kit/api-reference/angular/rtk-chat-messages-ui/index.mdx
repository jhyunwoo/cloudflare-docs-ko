## 제품 정보

| 회사 정보            | 제품정보        | 견적 요청 | 기본 정보             | 이름 \*              |

| `iconPack`       | `IconPack1` | ❌     | `defaultIconPack` | Icon 팩             |
| `messages`       | `Chat[]`    | ✅     | -                 | 채팅 메시지             |
| `selectedGroup`  | `string`    | ✅     | -                 | 선택한 그룹 키           |
| `selfUserId`     | `string`    | ✅     | -                 | 사용자 ID             |

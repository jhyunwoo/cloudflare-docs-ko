모든 참가자를 나열하는 구성 요소, 능력
허가에 따라 각 참가자의 권한 작업을 실행합니다.

## 제품 정보

| 회사 정보                      | 제품정보                | 견적 요청 | 기본 정보                   | 이름 \*   |
| -------------------------- | ------------------- | ----- | ----------------------- | ------- |
| `config`                   | `UIConfig`          | ❌     | `createDefaultConfig()` | 사이트맵    |
| `defaultParticipantsTabId` | `ParticipantsTabId` | ✅     | -                       | 기본 섹션   |
| `iconPack`                 | `IconPack`          | ❌     | `defaultIconPack`       | Icon 팩  |
| `meeting`                  | `Meeting`           | ✅     | -                       | 회의 목표   |
| `size`                     | `Size`              | ✅     | -                       | 크기 (mm) |
| `states`                   | `States`            | ✅     | -                       | 미국 객체   |
| `t`                        | `RtkI18n`           | ❌     | `useLanguage()`         | 한국어     |

## 사용 예제

### 기본 사용

```html
<!--구성 요소.html-->
<rtk-participants></rtk-participants>
```

### 재산

```html
<!--구성 요소.html-->
<rtk-participants
 [defaultParticipantsTabId]="participantstabid"
 [meeting]="meeting"
 size="md">
</rtk-participants>
```

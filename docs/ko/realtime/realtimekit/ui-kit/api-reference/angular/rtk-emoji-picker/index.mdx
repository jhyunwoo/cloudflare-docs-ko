아주 간단한 이모티콘 피커 성분.

## 제품 정보

| 회사 정보             | 제품정보       | 견적 요청 | 기본 정보             | 이름 \*              |
| ----------------- | ---------- | ----- | ----------------- | ------------------ |
| `focusWhenOpened` | `boolean`  | ✅     | -                 | 마운트에 초점을 맞추지 않고 제어 |
| `iconPack`        | `IconPack` | ❌     | `defaultIconPack` | Icon 팩             |
| `t`               | `RtkI18n`  | ❌     | `useLanguage()`   | 한국어                |

## 사용 예제

### 기본 사용

```html
<!--구성 요소.html-->
<rtk-emoji-picker></rtk-emoji-picker>
```

### 재산

```html
<!--구성 요소.html-->
<rtk-emoji-picker
 [focusWhenOpened]="true">
</rtk-emoji-picker>
```

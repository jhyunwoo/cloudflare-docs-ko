채팅에서 텍스트 메시지를 렌더링하는 구성 요소.

## 제품 정보

| 회사 정보        | 제품정보      | 견적 요청 | 기본 정보 | 이름 \*                                             |
| ------------ | --------- | ----- | ----- | ------------------------------------------------- |
| `isMarkdown` | `boolean` | ✅     | -     | 엠에디터 매크로 참조:Renders text as markdown (기본값 = true) |
| `text`       | `string`  | ✅     | -     | 문자 메시지                                            |

## 사용 예제

### 기본 사용

```html
<rtk-text-message-view></rtk-text-message-view>
```

### 재산

```html
<rtk-text-message-view
 text="example">
</rtk-text-message-view>
```

```html
<script>
  const el = document.querySelector("rtk-text-message-view");

  el.isMarkdown= true;
</script>
```

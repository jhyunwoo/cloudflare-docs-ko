메뉴 구성 요소.

## 제품 정보

| 회사 정보       | 제품정보        | 견적 요청 | 기본 정보             | 이름 \*   |
| ----------- | ----------- | ----- | ----------------- | ------- |
| `iconPack`  | `IconPack`  | ❌     | `defaultIconPack` | Icon 팩  |
| `offset`    | `number`    | ✅     | -                 | px의 오프셋 |
| `placement` | `Placement` | ✅     | -                 | 메뉴의 배치  |
| `size`      | `Size`      | ✅     | -                 | 크기 (mm) |
| `t`         | `RtkI18n`   | ❌     | `useLanguage()`   | 한국어     |

## 사용 예제

### 기본 사용

```html
<rtk-menu></rtk-menu>
```

### 재산

```html
<rtk-menu
 size="md">
</rtk-menu>
```

```html
<script>
  const el = document.querySelector("rtk-menu");

  el.offset= 42;
</script>
```

뚱 베어`rtk-text-message`deprecated는 곧 제거 될 것입니다. 제품 정보`rtk-text-message-view`대신.
채팅에서 텍스트 메시지를 렌더링하는 구성 요소.

## 제품 정보

| 회사 정보         | 제품정보          | 견적 요청 | 기본 정보             | 이름 \*                     |
| ------------- | ------------- | ----- | ----------------- | ------------------------- |
| `iconPack`    | `IconPack`    | ❌     | `defaultIconPack` | Icon 팩                    |
| `isContinued` | `boolean`     | ✅     | -                 | 메시지가 계속되는지 여부             |
| `message`     | `TextMessage` | ✅     | -                 | 텍스트 메시지 객체                |
| `now`         | `Date`        | ✅     | -                 | 현재 날짜 객체, 날짜 사이의 거리를 계산하기 |
| `showBubble`  | `boolean`     | ✅     | -                 | 메시지 표시                    |
| `t`           | `RtkI18n`     | ❌     | `useLanguage()`   | 한국어                       |

## 사용 예제

### 기본 사용

```html
<rtk-text-message></rtk-text-message>
```

### 재산

```html
<rtk-text-message>
</rtk-text-message>
```

```html
<script>
  const el = document.querySelector("rtk-text-message");

  el.isContinued= true;
</script>
```

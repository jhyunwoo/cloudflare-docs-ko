설문 조사의 눈에 띄는 버튼.
당신은 통과해야합니다`meeting`읽지 않은 설문 조사 수 배지를 볼 수 있습니다.
클릭할 때`rtkStateUpdate`데이터가있는 이벤트 :

```ts
{ activeSidebar: boolean; sidebar: 'polls' }
```

## 제품 정보

| 회사 정보      | 제품정보                | 견적 요청 | 기본 정보             | 이름 \*   |
| ---------- | ------------------- | ----- | ----------------- | ------- |
| `iconPack` | `IconPack`          | ❌     | `defaultIconPack` | Icon 팩  |
| `meeting`  | `Meeting`           | ✅     | -                 | 회의 목표   |
| `size`     | `Size`              | ✅     | -                 | 크기 (mm) |
| `states`   | `States`            | ✅     | -                 | 미국 객체   |
| `t`        | `RtkI18n`           | ❌     | `useLanguage()`   | 한국어     |
| `variant`  | `ControlBarVariant` | ✅     | -                 | 한국어     |

svg 문자열을 받아들이는 아이콘 구성 요소와 렌더링.

## 제품 정보

| 회사 정보     | 제품정보          | 견적 요청 | 기본 정보 | 이름 \*   |
| --------- | ------------- | ----- | ----- | ------- |
| `icon`    | `string`      | ✅     | -     | 아이콘     |
| `size`    | `Size1`       | ✅     | -     | 크기 (mm) |
| `variant` | `IconVariant` | ✅     | -     | Icon 변형 |

## 사용 예제

### 기본 사용

```html
<rtk-icon></rtk-icon>
```

### 재산

```html
<rtk-icon
 icon="example"
 size="md"
 variant="primary">
</rtk-icon>
```

<script>
  const el = document.querySelector("rtk-icon");

</script>

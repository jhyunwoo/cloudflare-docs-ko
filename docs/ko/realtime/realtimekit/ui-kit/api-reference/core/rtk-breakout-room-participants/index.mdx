모든 참가자를 나열하는 구성 요소, 능력
허가에 따라 각 참가자의 권한 작업을 실행합니다.

## 제품 정보

| 회사 정보                    | 제품정보       | 견적 요청 | 기본 정보             | 이름 \*   |
| ------------------------ | ---------- | ----- | ----------------- | ------- |
| `iconPack`               | `IconPack` | ❌     | `defaultIconPack` | Icon 팩  |
| `meeting`                | `Meeting`  | ✅     | -                 | 회의 목표   |
| `participantIds`         | `string[]` | ✅     | -                 | 참가자 ids |
| `selectedParticipantIds` | `string[]` | ✅     | -                 | 선택된 참가자 |
| `t`                      | `RtkI18n`  | ❌     | `useLanguage()`   | 한국어     |

## 사용 예제

### 기본 사용

```html
<rtk-breakout-room-participants></rtk-breakout-room-participants>
```

### 재산

```html
<rtk-breakout-room-participants
 participantIds="example"
 selectedParticipantIds="example">
</rtk-breakout-room-participants>
```

```html
<script>
  const el = document.querySelector("rtk-breakout-room-participants");

  el.meeting= meeting
  el.participantIds= [];
  el.selectedParticipantIds= [];
</script>
```

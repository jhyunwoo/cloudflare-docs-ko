## 제품 정보

| 회사 정보       | 제품정보     | 견적 요청 | 기본 정보 | 이름 \*                      |
| ----------- | -------- | ----- | ----- | -------------------------- |
| `maxLength` | `number` | ✅     | -     | markdown로 렌더링 할 텍스트의 최대 길이 |
| `text`      | `string` | ✅     | -     | Markdown으로 렌더링 할 수있는 원본    |

## 사용 예제

### 기본 사용

```html
<rtk-markdown-view></rtk-markdown-view>
```

### 재산

```html
<rtk-markdown-view
 text="example">
</rtk-markdown-view>
```

```html
<script>
  const el = document.querySelector("rtk-markdown-view");

  el.maxLength= 42;
</script>
```

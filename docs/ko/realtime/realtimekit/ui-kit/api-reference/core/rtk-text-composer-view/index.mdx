텍스트 작곡가를 렌더링하는 구성 요소

## 제품 정보

| 회사 정보               | 제품정보                              | 견적 요청 | 기본 정보             | 이름 \*                            |
| ------------------- | --------------------------------- | ----- | ----------------- | -------------------------------- |
| `disabled`          | `boolean`                         | ✅     | -                 | 텍스트 입력 비활성화 (기본 = false)         |
| `iconPack`          | `IconPack1`                       | ❌     | `defaultIconPack` | Icon 팩                           |
| `keyDownHandler`    | `(e: KeyboardEvent)`              | ✅     | -                 | Keydown 이벤트 핸들러 기능               |
| `maxLength`         | `number`                          | ✅     | -                 | 텍스트 입력을위한 최대 길이                  |
| `placeholder`       | `string`                          | ✅     | -                 | 회사연혁                             |
| `rateLimitBreached` | `boolean`                         | ✅     | -                 | 비율 제한이 breached 경우를 나타내는 Boolean |
| `setText`           | `(text: string, focus?: boolean)` | ❌     | -                 | 텍스트 입력의 값 설정                     |
| `t`                 | `RtkI18n1`                        | ❌     | `useLanguage()`   | 한국어                              |
| `value`             | `string`                          | ✅     | -                 | 텍스트 입력의 기본 값                     |

## 사용 예제

### 기본 사용

```html
<rtk-text-composer-view></rtk-text-composer-view>
```

### 재산

```html
<rtk-text-composer-view>
</rtk-text-composer-view>
```

```html
<script>
  const el = document.querySelector("rtk-text-composer-view");

  el.disabled= true;
  el.maxLength= 42;
</script>
```

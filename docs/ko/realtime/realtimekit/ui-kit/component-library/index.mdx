UI Kit 구성 요소 라이브러리는 사용자 정의 회의 인터페이스를 구축하기 위해 사용할 수있는 사전 제작, 사용자 정의 구성 요소의 포괄적 인 세트를 제공합니다.

<RTKSDKSelector />

:::참조
모든 UI 키트 구성 요소는 프레임 워크 (React/Angular)에 관계없이 웹 구성 요소의 상단에 내장되어 있습니다. 브라우저 DOM의 웹 컴포넌트로 렌더링합니다.

**Component naming 컨벤션:**

- **웹 구성 요소 및 각도**: kebab-case 사용 (예 :`rtk-meeting`)
- **React**: PascalCase 사용 (예:`RtkMeeting`)

React와 모난 성분은 동일한 underlying 웹 성분의 주위에 래퍼입니다, 그래서 기능은 모든 기구의 맞은편에 동일합니다.

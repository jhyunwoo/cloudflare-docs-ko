:::노트\[필수]
이 가이드는 상단의 빌드[자체 UI 구축](/realtime/realtimekit/ui-kit/build-your-own-ui/). 먼저 가이드를 읽는 것이 좋습니다. 코드의 항구는 brevity에 대한 여기에 반복되지 않습니다.

사용 가능한 UI Kit 구성 요소의 전체 목록은 참조[Component 도서관](/realtime/realtimekit/ui-kit/component-library/).
:::

이 가이드에서 RealtimeKit 회의 경험에 대한 사용자 정의 헤더를 추가하는 방법을 배울 것입니다.

<RTKSDKSelector />

<RTKCodeSnippet id="web-react">
  실시간Kit UI 키트 제공[`RtkHeader`](/realtime/realtimekit/ui-kit/component-library/#rtk-header)기본 헤더의 구성 요소.

  추가 컨트롤이 필요한 경우, 교체`RtkHeader`개별 UI 키트 구성 요소 및 사용자 정의 요소.

  필수 성분을 수입하십시오:

  ```jsx
  import {
  	RtkLogo,
  	RtkRecordingIndicator,
  	RtkLivestreamIndicator,
  	RtkMeetingTitle,
  	RtkGridPagination,
  	RtkParticipantCount,
  	RtkViewerCount,
  	RtkClock,
  } from "@cloudflare/realtimekit-ui";
  ```

  내 계정`RtkUIProvider`이름 \*[자체 UI 구축](/realtime/realtimekit/ui-kit/build-your-own-ui/), 교체:

  ```jsx
  <RtkHeader />
  ```

  이름:

  ```jsx
  <div
  	style={{
  		display: "flex",
  		justifyContent: "space-between",
  		backgroundColor: "black",
  		color: "white",
  	}}
  >
  	<div
  		id="header-left"
  		style={{ display: "flex", alignItems: "center", height: "48px" }}
  	>
  		<RtkLogo />
  		<RtkRecordingIndicator />
  		<RtkLivestreamIndicator />
  	</div>
  	<div
  		id="header-center"
  		style={{ display: "flex", alignItems: "center", height: "48px" }}
  	>
  		<RtkMeetingTitle />
  	</div>
  	<div
  		id="header-right"
  		style={{ display: "flex", alignItems: "center", height: "48px" }}
  	>
  		<RtkGridPagination />
  		<RtkParticipantCount />
  		<RtkViewerCount />
  		<RtkClock />
  		<button onClick={handleReportBugClick}>Report Bug</button>
  	</div>
  </div>
  ```

  클릭 핸들러 정의:

  ```jsx
  const handleReportBugClick = () => {
  	console.log("Report Bug Clicked");
  };
  ```

  사용자 정의 헤더로 자신의 UI를 구축하는 완벽한 예는 찾을 수 있습니다[이름 \*](https://github.com/cloudflare/realtimekit-web-examples/tree/main/react-examples/examples/create-your-own-ui)사용자 정의 헤더 구성 요소[이름 \*](https://github.com/cloudflare/realtimekit-web-examples/blob/main/react-examples/examples/create-your-own-ui/src/components/meeting-header.tsx).
</RTKCodeSnippet>

<RTKCodeSnippet id="web-web-components">
  실시간Kit UI 키트 제공[`rtk-header`](/realtime/realtimekit/ui-kit/component-library/#rtk-header)기본 헤더의 구성 요소.

  추가 컨트롤이 필요한 경우, 교체`rtk-header`개별 UI 키트 구성 요소 및 사용자 정의 요소. 내 계정`renderJoinedScreen`기능에서[자체 UI 구축](/realtime/realtimekit/ui-kit/build-your-own-ui/), 교체:

  ```html
  <rtk-header style="display: flex; justify-content: space-between;"></rtk-header>
  ```

  이름:

  ```html
  <div
  	style="display: flex; justify-content: space-between; align-items: center; height: 48px; padding: 0 12px; background-color: black; color: white;"
  >
  	<div style="display: flex; align-items: center; gap: 8px;">
  		<rtk-logo></rtk-logo>
  		<rtk-recording-indicator></rtk-recording-indicator>
  		<rtk-livestream-indicator></rtk-livestream-indicator>
  	</div>

  	<div style="display: flex; align-items: center;">
  		<rtk-meeting-title></rtk-meeting-title>
  	</div>

  	<div style="display: flex; align-items: center; gap: 8px;">
  		<rtk-grid-pagination></rtk-grid-pagination>
  		<rtk-participant-count></rtk-participant-count>
  		<rtk-viewer-count></rtk-viewer-count>
  		<rtk-clock></rtk-clock>
  		<button id="report-bug-button" type="button">Report Bug</button>
  	</div>
  </div>
  ```

  렌더링 후 클릭 핸들러 등록:

  ```javascript
  document.querySelector("#report-bug-button").addEventListener("click", () => {
  	console.log("Report Bug Clicked");
  });
  ```

  사용자 정의 헤더로 자신의 UI를 구축하는 완벽한 예는 찾을 수 있습니다[이름 \*](https://github.com/cloudflare/realtimekit-web-examples/tree/main/html-examples/examples/create-your-own-ui)사용자 정의 헤더 구성 요소[이름 \*](https://github.com/cloudflare/realtimekit-web-examples/blob/main/html-examples/examples/create-your-own-ui/components/meeting-header.js).
</RTKCodeSnippet>

<RTKCodeSnippet id="web-angular">
  실시간Kit UI 키트 제공[`rtk-header`](/realtime/realtimekit/ui-kit/component-library/#rtk-header)기본 헤더의 구성 요소.

  추가 컨트롤이 필요한 경우, 교체`rtk-header`개별 UI 키트 구성 요소 및 사용자 정의 요소. RealtimeKit angular Components를 직접 사용하는 사용자 정의 헤더 구성 요소를 만듭니다.

  #### Custom Header 컴포넌트 만들기

  ```typescript title="custom-header.component.ts"
  import { Component, AfterViewInit } from "@angular/core";

  @Component({
  	selector: "app-custom-header",
  	template: `
  		<div class="custom-header">
  			<div class="header-left">
  				<rtk-logo></rtk-logo>
  				<rtk-recording-indicator></rtk-recording-indicator>
  				<rtk-livestream-indicator></rtk-livestream-indicator>
  			</div>

  			<div class="header-center">
  				<rtk-meeting-title></rtk-meeting-title>
  			</div>

  			<div class="header-right">
  				<rtk-grid-pagination></rtk-grid-pagination>
  				<rtk-participant-count></rtk-participant-count>
  				<rtk-viewer-count></rtk-viewer-count>
  				<rtk-clock></rtk-clock>
  				<button
  					type="button"
  					class="report-bug-button"
  					(click)="onReportBugClick()"
  				>
  					Report Bug
  				</button>
  			</div>
  		</div>
  	`,
  	styles: [
  		`
  			.custom-header {
  				display: flex;
  				justify-content: space-between;
  				align-items: center;
  				height: 48px;
  				padding: 0 12px;
  				background-color: black;
  				color: white;
  			}

  			.header-left,
  			.header-right {
  				display: flex;
  				align-items: center;
  				gap: 8px;
  			}

  			.header-center {
  				display: flex;
  				align-items: center;
  			}

  			.report-bug-button {
  				background: none;
  				border: 1px solid white;
  				color: white;
  				padding: 4px 8px;
  				border-radius: 4px;
  				cursor: pointer;
  				font-size: 12px;
  			}

  			.report-bug-button:hover {
  				background-color: rgba(255, 255, 255, 0.1);
  			}
  		`,
  	],
  })
  export class CustomHeaderComponent implements AfterViewInit {
  	ngAfterViewInit() {
  		console.log("Custom header initialized");
  	}

  	onReportBugClick() {
  		console.log("Report Bug Clicked");
  		//사용자 정의 로직을 추가
  		//예를 들어: modal을 열고, 양식으로 이동하십시오.
  	}
  }
  ```

  #### 당신의 회의 성분에 있는 사용

  주요 회의 구성 요소 템플릿에서, 교체:

  ```html
  <rtk-header style="display: flex; justify-content: space-between;"></rtk-header>
  ```

  이름:

  ```html
  <app-custom-header></app-custom-header>
  ```

  #### 완전한 회의 성분 보기

  ```typescript title="meeting.component.ts"
  import {
  	Component,
  	ElementRef,
  	OnInit,
  	OnDestroy,
  	ViewChild,
  } from "@angular/core";

  @Component({
  	selector: "app-meeting",
  	template: `
  		<rtk-meeting #meetingComponent id="meeting-component">
  			<!-- Custom header replaces rtk-header -->
  			<app-custom-header></app-custom-header>

  			<!-- Other meeting UI components -->
  			<rtk-grid></rtk-grid>
  			<rtk-sidebar></rtk-sidebar>
  		</rtk-meeting>
  	`,
  })
  export class MeetingComponent implements OnInit, OnDestroy {
  	@ViewChild("meetingComponent", { static: true }) meetingElement!: ElementRef;

  	meeting: any;
  	private authToken = "<participant_auth_token>";

  	async ngOnInit() {
  		const RealtimeKitClient = await import(
  			"https://cdn.jsdelivr.net/npm/@cloudflare/realtimekit@latest/dist/index.es.js"
  		);

  		this.meeting = await RealtimeKitClient.default.init({
  			authToken: this.authToken,
  		});

  		const meetingComponent = this.meetingElement.nativeElement;
  		meetingComponent.showSetupScreen = true;
  		meetingComponent.meeting = this.meeting;
  	}

  	ngOnDestroy() {
  		//클린업 로직
  	}
  }
  ```

  #### 모듈 구성

  Angular 모듈에서 사용자 정의 헤더 구성 요소를 선언하는 것을 잊지 마세요:

  ```typescript title="app.module.ts"
  import { NgModule, CUSTOM_ELEMENTS_SCHEMA } from "@angular/core";
  import { BrowserModule } from "@angular/platform-browser";

  import { AppComponent } from "./app.component";
  import { MeetingComponent } from "./meeting.component";
  import { CustomHeaderComponent } from "./custom-header.component";

  @NgModule({
  	declarations: [AppComponent, MeetingComponent, CustomHeaderComponent],
  	imports: [BrowserModule],
  	providers: [],
  	bootstrap: [AppComponent],
  	schemas: [CUSTOM_ELEMENTS_SCHEMA], //RTK 웹 컴포넌트에 필요한
  })
  export class AppModule {}
  ```

  이 접근법은 Angular의 구성 요소 아키텍처 및 이벤트 처리 패턴을 유지하면서 헤더 레이아웃에 전체 제어를 제공합니다.
</RTKCodeSnippet>

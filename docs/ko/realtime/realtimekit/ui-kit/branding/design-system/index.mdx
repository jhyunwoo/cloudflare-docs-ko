RealtimeKit의 UI Kit는 모든 UI 키트 구성품을 완성할 수 있도록 필요한 UI 구성품을 제공합니다. 브랜드 색상, 글꼴, 로고 등을 사용자 정의 할 수 있습니다.

## 자주 묻는 질문

get started로 회의를 위한 아이콘을 사용자 정의할 수 있습니다.[RealtimeKit의 웹 SDK 통합](/realtime/realtimekit/ui-kit/)당신의 웹 신청으로.

## Override 디자인 시스템

더 보기`provideRtkDesignSystem()`유틸리티는 사용자 정의 디자인 시스템을 가진 exisiting 디자인 시스템을 override 할 수 있습니다.

  ```html
  </script>
  ```
</RTKCodeSnippet>

<RTKCodeSnippet id="web-react">

## 디자인 토큰

UI 키트 사용[디자인 토큰](https://css-tricks.com/what-are-design-tokens/)그것을 위해 디자인 체계.

디자인 토큰은 디자인 시스템을 유지하기 위해 사용되는 디자인 관련 값이며, 이는 다음과 같은 가치를 가진 시스템의 전체적인 디자인을 사용자 정의하는 유연성을 제공합니다: 전기, 간격, 색상 등.

이 디자인 토큰은 구성 요소들 사이에서 저장되고 공유됩니다.[CSS 변수](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties).

### 자료실

이 토큰을 사용하여 UI Kit 구성품에 쉽게 사용되는 글꼴 제품군을 조정할 수 있습니다. provideRtkDesignSystem 유틸리티로 두 가지 방법으로 이 값을 편집할 수 있습니다.

```css
--rtk-font-family: Inter;
```

#### 제품 정보

디자인 토큰에 이러한 값 중 하나를 설정합니다.

- fontFamily - 사용자 정의 글꼴 가족을 사용하여 글꼴을 수동으로로드해야합니다.
- googleFont - Google 글꼴을 사용하여 글꼴은 자동으로로드됩니다.

```javascript
const designTokens = {
	fontFamily: "Custom Font",
	//또는
	googleFont: "A Google Font",
};
```

### 색상

CSS 변수는 형식에서 설정된다:`R G B`.

기본 값과 함께 모든 색상 토큰이 있습니다.

```css
--rtk-colors-brand-500: 33 96 253;
--rtk-colors-background-1000: 8 8 8;
/_ ... rest of the shades _/
```

#### 제품 정보

:::참조

자주 묻는 질문`text`·`text-on-brand`색상, 다음 음영이 있지만 단일 색상 만 지정합니다. 1000 - 600.

이것은 때문에`provideRtkDesignSystem()`유틸리티는 텍스트 1000을 통과하고 더 가벼운 그늘을 계산하고 그뿐만 아니라 설정합니다.

비밀번호`brand`·`background`색깔.

:::

일반적으로 사용되는 세트`background`그늘은 기본적으로 사용할 수 있습니다.`theme`호텔 위치

테마 값은:`light`, `dark`, `darkest`.

이처럼 색상 토큰을 편집합니다. 지정한 색상만 설정됩니다.

```javascript
const designTokens = {
	theme: "darkest",
	colors: {
		brand: { 500: "#0D51FD" },
		background: { 1000: "#080808" },
		text: "#ffffff",
		"text-on-primary": "#ffffff",
		"video-bg": "#181818",
	},
};
```

### 사이트 맵

간격 가늠자는 성분을 통하여 폭, 고도, 마진, 패딩, 위치 등을 놓기를 위해 이용됩니다.

- 간격 가늠자 기초를 위한 과태값은 4px입니다.
- 값의 나머지는이 기초로 계산되며, 설정`--rtk-space-1`.
- 현재 간격 가늠자는 0에서 96에 배열합니다.

```css
--rtk-space-1: 4px;
/* ... rest of the spacing scale */
```

#### 제품 정보

간격 가늠자의 기초를 놓으십시오`spacingBase`호텔 위치

```javascript
const designTokens = {
	spacingBase: 4, //px의 가치
};
```

### 주문하기

국경 폭과 국경 반경 재산은 또한 디자인 토큰으로 주문을 받아서 만들어질 수 있습니다!

| 토큰 이름          | 제품정보                                            |
| -------------- | ----------------------------------------------- |
| `borderWidth`  | `none`, `thin`, `fat`                           |
| `borderRadius` | `sharp`, `rounded`, `extra-rounded`, `circular` |

#### 제품 정보

```javascript
const designTokens = {
	borderWidth: "thin",
	borderRadius: "rounded",
};
```

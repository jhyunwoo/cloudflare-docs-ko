### 제품정보

RealtimeKit는 실시간 미디어 응용 프로그램을 구축하는 두 가지 방법을 제공합니다:

**UI 키트**: <RTKPill>(주)</RTKPill>사전 제작된 UI 라이브러리, 신속한 개발을 위한 맞춤형 구성 요소 — Core SDK의 상단에 앉아 있습니다.

**핵심 SDK**: Realtime SFU의 상단에 내장 된 클라이언트 SDK는 화상 통화를 관리하기위한 API의 전체 세트를 제공하고 세션을 뮤팅, 변하지 않고 오디오 및 비디오를 견인합니다.

:::참조
UI Kit를 사용할 때 필요한 추가 기능을 구축할 수 있는 핵심 SDK에 액세스할 수 있습니다.

### 기술 비교

프로젝트에 적합한 옵션을 선택할 수 있도록 포괄적 인 가이드입니다. 이 비교는 UI 키트와 결합한 Core SDK를 사용하여 거래 오프를 이해할 수 있습니다.

| 제품 정보             | Core SDK 전용                          | UI 키트                                                      |
| ----------------- | ------------------------------------ | ---------------------------------------------------------- |
| **당신이 얻는 무엇**     | 미디어 관리를위한 핵심 API, 호스트 컨트롤, 채팅, 녹음 등. | Core API와 함께 미리 만들어진 UI 구성 요소.                             |
| **번들 크기**         | Minimal (미디어/네트워크 전용)                | 더 큰 (Core SDK + UI 구성 요소 포함)                               |
| **배송 시간**         | 더 긴 (찰상에서 UIbuild). 일반적으로 5-6 일.     | Faster (UI 키트는 Core SDK 호출을 처리합니다). 2 시간 이내에 배를 만들 수 있습니다. |
| **주문화**           | 완전한 통제, 수동 실시. UI를 만들어야 합니다.         | 플러그 및 재생 구성 요소 라이브러리와 사용자 정의의 높은 수준.                       |
| **국가 관리**         | 수동으로 처리 될 필요가있다.                     | 자동, UI 키트는 상태 관리에 대한 관리가 필요합니다.                            |
| **UI 유연성**        | 무제한 (모든 것을 구축)                       | 높은 (성분 라이브러리 + 애드온)                                        |
| **학습 곡선**         | Steeper (리드 코어 SDK API)              | Gentler (지정적인 구성 요소 랩 코어 SDK)                              |
| **- 연혁**          | 더 많은 코드를 유지. 더 큰 프로젝트.               | 덜 코드, 구성 요소 업데이트 포함                                        |
| **설계 시스템**        | Headless는, 어떤 디자인 체계도 통합합니다.         | 테마를 제공 할 수 있습니다.                                           |
| **Core SDK에 액세스** | API 접근                               | 직접 API 접근 + UI 성분                                          |

:::참조

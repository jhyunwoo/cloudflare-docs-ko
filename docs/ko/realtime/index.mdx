<Description>
  Cloudflare Realtime은 강력한 확장 가능한 실시간 애플리케이션을 구축할 수 있도록 설계된 종합 제품군입니다.
</Description>

### 실시간Kit

[실시간Kit](/realtime/realtimekit/)사용자 정의 라이브 비디오 및 음성을 웹 또는 모바일 응용 프로그램에 추가 할 수있는 SDK 및 API 세트입니다. 그것은 완전히 customisable이고 당신은 부호의 다만 약간 선에서 설치합니다.

Realtime SFU의 상단에 앉아 미디어 라우팅, 동료 관리 및 기타 복잡한 WebRTC 작업의 무거운 리프팅을 요약.

### 실시간 SFU

더 보기[실시간 SFU (선택적인 운송 단위)](/realtime/sfu/)강력한 미디어 서버로 비디오 및 오디오를 효율적으로 경로를 제공합니다. 실시간 SFU 실행[Cloudflare의 글로벌 클라우드 네트워크](https://www.cloudflare.com/network/)전세계 수백 도시에서.

WebRTC 전문성을 가진 개발자를 위해, SFU는 미디어 스트림에 전체 제어를 요구하는 고도로 사용자 정의 응용 프로그램을 구축하기 위해 독립적으로 사용될 수 있습니다. 이것은 Cloudflare의 네트워크를 자체 WebRTC 논리로 활용하려는 사람들에게만 권장됩니다.

### TURN 서비스

더 보기[TURN 서비스](/realtime/turn/)WebRTC 트래픽의 릴레이 역할을 하는 관리 서비스입니다. 미디어 스트림의 공개 릴레이 포인트를 제공함으로써 제한적 방화벽 또는 NAT의 사용자에 대한 연결을 보장합니다.

## 실시간 제품 선택

이 비교표를 사용하여 빠른 당신의 필요를 위한 적당한 Realtime 제품을 찾아내십시오:

| **누가 그것을 위해**       | WebRTC 복잡성을 처리하지 않고 신속하게 비디오 / 음성 기능을 추가하려는 개발자.                           | 웹RTC 전문 지식과 개발자는 미디어 스트림을 통해 전체 제어를 필요로하고 고도의 사용자 정의 응용 프로그램을 구축 할 수 있습니다.                    | 모든 WebRTC 애플리케이션은 제한적인 네트워크 환경에서 신뢰할 수 있는 연결을 필요로 합니다.                      |

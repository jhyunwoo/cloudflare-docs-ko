애플리케이션 보안 보고서는 'Cloudflare' 계정에서 엔터프라이즈 영역의 모든 사이버 공격 통찰력과 트렌드를 제공합니다.

보고서는 매월 생성됩니다.

보고서에 액세스 할 수 있습니다.**보안 보고서**페이지 또는[사이트맵](#api). 드롭다운에서 달을 선택하여 이전 개월에서 보고서에 액세스 할 수 있습니다.

<DashButton url="/?to=/:account/security-center/reports" />

보고서를 다운로드하려면, 선택**인쇄 보고서**.

4월 2025일 이전에 보고할 수 있습니다.**보안 보고서** > **Legacy 보고서**. 유산 보고서의 제한으로 인해 일부 고객은 4 월 2025 이전에 매월 보고서가 없을 수 있습니다.

현재 보고서는 Cloudflare에 의해 큐레이션되며 더 많은 통찰력을 포함하도록 확장됩니다. 사용자 정의 보고서를 만들 수있는 옵션, 다양한 필드에 의해 필터, 및 일정 보고서는 다가오는 개선에 추가됩니다.

***

## 공지사항

현재 Application Security 보고서만 사용할 수 있습니다. 그들은 제품과 같은 전체 제품군을 커버[HTTP DDoS 보호](/ddos-protection/managed-rulesets/http/), [‘WAF’](/waf/)·[Bot 관리](/bots/).

신청 성과에 대한 보고,['Cloudflare' 1개](/cloudflare-one/), 네트워크 서비스 등[매직 트레인](/magic-transit/), 미래 개선에서 사용할 수 있습니다.

***

## 공지사항

각 보고서에는 다음과 같은 섹션이 포함되어 있습니다.

- 회사 개요
- 허용 및 mitigated 요청의 배포
- [산업 벤치 마크](#industry-benchmarks)귀하의 산업을 선택하여 동료와 비교하는 방법을 보여줍니다.
- 지도 시각화를 포함한 허용된 교통 및 이동 트래픽의 상위 5 개 소스 국가
- 상위 5위 가장 타겟된 호스트 이름
- Top 5 가장 효과적인 완화 규칙

자세한 내용을 보려면 필터를 적용하고 데이터를 분석하고 ad-hoc 보고서를 생성합니다.[보안 보안 Analytics ‘대시보드’](/waf/analytics/security-analytics/)또는[로그 탐색](/log-explorer/).

### 산업 벤치 마크

업계 벤치 마크는 동일한 업계에서 다른 사람에 대한 조직의 공격 활동을 비교하여 귀하의 이동 트래픽에 대한 추가 상황을 제공합니다. 이러한 벤치 마크는 당신이 경험의 볼륨과 빈도가 일반적이거나, 또는 당신의 동료보다 낮다는 것을 이해하는 데 도움이 - 귀하의 조직이 위협 환경에서 서있는 명확한 감각을 제공합니다.

컨텍스트를 제공 넘어 벤치 마크는 조직의 얼굴을 위협하고 효과적으로 'Cloudflare'가 그들을 모방하여 이해 관계자에게 가치를 보여줄 수 있도록 도와줍니다. 이 정보는 보안 자세를 내부 또는 미래의 보안 투자를 우선시 할 때 유용합니다.

공정성과 정확성을 보장하기 위해, Cloudflare는 비교하기 전에 데이터를 정상화합니다. 각 달 동안, 우리는 귀하의 계정과 자격 영역에 걸쳐 총 요청과 관련된 미량 요청의 비율을 계산합니다. 이 정상화는 벤치 마크가 전체 트래픽 볼륨보다 상대적 공격 강도를 기반으로하므로 더 큰 소규모 조직은 의미적으로 비교할 수 있습니다.

결과는 상황에 따라 미량 트래픽 데이터를 해석하는 데 도움이됩니다. 예를 들어, "과 같은 진술을 볼 수 있습니다.*화장품 업계에서 상위 25 %의 가장 공격적인 회사에 있습니다.*"이 통찰력은 위협 노출을 잘 이해하고 이해 관계자에게 결과를 전달하고 보호 'Cloudflare'의 가치를 이해합니다.

귀하의 계정이 산업을 할당하지 않거나 표시된 산업이 잘못된 경우, 올바른 산업을 선택하는 보고서 내에서 링크를 사용하십시오.

새로운 선택에 대한 시간이 걸릴 수 있으며 향후 보고서에만 적용 될 수 있습니다.

여러 Cloudflare 계정이있는 경우 특정 계정에 가장 관련있는 산업을 선택하십시오.

## 자주 묻는 질문

당신은 적어도 1개의 기업 지역이 있어야 합니다. Application Security 보고서는 엔터프라이즈 영역에 자동으로 활성화됩니다. 작업이 필요 없습니다.

Enterprise 영역이 없으면 보고서가 생성되지 않습니다. 한 달 이상되지 않은 계정이있는 경우 보고서는 아직 생성되지 않습니다.

## 사이트맵

```sh title="List all report policies for a specific account"
GET /accounts/{account_id}/reporting/policies
```

```sh title="Retrieve the details of a single, specific report policy"
GET /accounts/{account_id}/reporting/policies/{policy_id}
```

```sh title="List all generated reports for a specific account"
GET /accounts/{account_id}/reporting/reports
```

```sh title="Retrieve a single, specific report, including its data and findings"
GET /accounts/{account_id}/reporting/reports/{report_id}
```

<Details header="API에 의해 반환된 데이터">
  - 계정 ID
  - 계정 이름
  - 계정 산업
  - 시간 범위
  - 총 지역
  - 총 영역 분석
  - 산업 퍼센트 (nullable float)
  - 총 요청 (count, 비율)
  - 총 mitigated 요청 (count, 비율)
  - 총 제공 요청 (count, 비율)
  - mitigated 요청에 의해 상위 5 호스트 이름 (hostname, count)
  - 최고 5 소스 국가 제공 요청 (국가, 수)
  - mitigated 요청에 의해 상위 5 소스 국가 (국가, 수)
  - mitigated 요청에 의해 상위 5 규칙 (rule 이름, 규칙 유형, 수)
</Details>

:::참조
데이터의 시간 범위는 보고서가 생성 될 때 독립적입니다.

## 제한 사항

애플리케이션 보안 보고서는 현재 미국 고객 메타데이터 경계 (CMB)만 지원합니다. EU CMB를 아직 지원하지 않습니다.

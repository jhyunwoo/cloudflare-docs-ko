## API 요청 제한

위협 인텔리전스 엔드 포인트로 만든 모든 API 통화는 월간 할당량에 기여할 것입니다. 또한 Security Intelligence API를 활용한 Page Shield와 같은 Investigate 및 Brand Protection, 또는 기타 제품과 같은 Security Center 내의 기능을 활용하면 할당량의 소비에 기여할 것입니다.

이 요청은 현재 DDoS Botnet 위협 피드 API에 적용되지 않습니다.

| Cloudflare 플랜       | 월별 통화  |
| ------------------- | ------ |
| 무료 다운로드             | 100    |
| 지원하다                | 100    |
| 회사연혁                | 100    |
| 회사 소개               | 2,500  |
| Cloudforce 1개의 핵심   | 10,000 |
| Cloudforce One 프리미어 | 50,000 |

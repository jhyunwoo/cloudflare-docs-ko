Cloudflare는 다양한 인터넷 보안 및 통찰력을 다루는 엔드포인트 시리즈를 제공합니다. 'Cloudflare' 플랜 유형에 따라[지원하다](/security-center/intel-apis/limits/)API 호출은 달마다 다를 것입니다.

| 지능 Endpoint                                                                                                              | 이름 \*                                                                         |
| ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| [ASN 정보](/api/resources/intel/subresources/asn/methods/get/)                                                             | Autonomous System Number (ASN)의 개요와 하위넷 목록 제공                                 |
| [사용자 정의 표시 피드 다운로드](/api/resources/intel/subresources/indicator_feeds/subresources/downloads/)                           | 사용자 정의 표시기 피드를 다운로드 할 수있는 능력을 제공합니다.                                          |
| [도메인 정보](/api/resources/intel/subresources/domains/methods/get/)                                                         | 보안 세부 사항 및 도메인에 대한 통계를 제공합니다.                                                 |
| [도메인 연혁](/api/resources/intel/subresources/domain_history/methods/get/)                                                  | 현재 도메인에 할당 된 과거 보안 위협 및 콘텐츠 범주를 제공합니다.                                        |
| [IP 정보](/api/resources/intel/subresources/ips/methods/get/)                                                              | ASN의 지리적 위치, ASN, 인프라 유형 및 IP 주소의 보안 위협 범주를 제공합니다.                            |
| [IP로 DNS 전달](/api/resources/intel/subresources/dns/methods/list/)                                                        | 특정 IP 주소로 해결 된 첫 번째 본 및 마지막으로 본 날짜를 포함한 모든 도메인 목록을 제공합니다.                     |
| [Phishing 지능](/api/resources/brand_protection/methods/url_info/)                                                         | URL에 대한 phishing 세부 사항 제공.                                                    |
| [Miscategorization 지능](/api/resources/intel/subresources/miscategorizations/methods/create/)                             | 도메인의 범주를 수정하기위한 요청을 제출할 수 있으며, 나중에 'Cloudflare' Intelligence 팀에 의해 검토를 진행합니다. |
| [Priority Intelligence 요구 사항](/api/resources/cloudforce_one/subresources/requests/subresources/priority/methods/create/) | 인텔리전스 격차를 식별하고 정확한 요구 사항을 공식화하고 범주로 구성하는 구조 접근 방식을 제공합니다.                     |
| [자주 묻는 질문](/api/resources/cloudforce_one/subresources/requests/methods/create/)                                          | 특정 인텔리전스 인사이트에 대한 타겟팅 된 문의를 작성하여 조직을 이해하고 임박한 보안 위협과 취약점에 대응합니다.              |
| [위협 사건](/api/resources/cloudforce_one/subresources/scans/subresources/results/methods/get/)                              | Cloudflare telemetry and 위협 actor activity in the Cloudflare 네트워크.            |
| [이름 \*](/api/resources/intel/subresources/whois/methods/get/)                                                            | 특정 도메인에 대한 WHOIS 등록 정보를 제공합니다.                                                |
| [DDoS Botnet 위협 피드](/ddos-protection/botnet-threat-feed/)<br />(적용)                                                      | HTTP DDoS 공격에 참여한 자체 IP 주소에 대한 서비스 제공업체에 대한 정보를 제공합니다.                        |
| [구름 하나](/api/resources/cloudforce_one/subresources/requests/subresources/assets/methods/create/)                         | 사용자 목록, 삭제, 도착, 또는 요청 자산을 업데이트 할 수 있습니다.                                      |
| [상표 보호 API](/api/resources/brand_protection/)                                                                            | 로고 및 문자열 쿼리에 대한 쿼리를 다운로드하고 삭제 할 수있는 능력을 제공, 로고 및 문자열 쿼리에 대한 일치를 읽으십시오.        |

## API 예제

아래에서 Threat Intelligence API 호출의 예제를 찾을 수 있습니다. 자주 묻는 질문[API 토큰](/fundamentals/api/get-started/create-token/)적절한 편집 권한으로. 자세한 내용은 위의 링크를 사용하여 각각의 API 문서로 이동합니다.

### ASN 정보

<Details header="ASN 개요" open>
  ```bash
  curl "https://api.cloudflare.com/client/v4/accounts/{account_id}/intel/asn/13335" \
  --header "Authorization: Bearer <API_TOKEN>" | jq .

  #예 응답:
  {
      "result": {
          "asn": 13335,
          "description": "CLOUDFLARENET",
          "country": "US",
          "type": "isp"
      },
      "success": true,
      "errors": [],
      "messages": []
  }
  ```
</Details>

:::참조
API를 사용할 때, 선호하는 언어 필드 이름은`preferred_languages`(snake case). 예를 들면:`"preferred_languages": "en, de"`.
:::

Cloudflare\`대시보드를 통해 security.txt 파일을 관리하려면:

    1. 로그인하기[‘Cloudflare’ ‘대시보드’](https://dash.cloudflare.com/), 계정 및 도메인을 선택하십시오.
    2. 오시는 길**보안 보안** > **계정 설정**필터링**웹 애플리케이션 악용**.
    3. 이름 \***보안.txt** > **제품 설명**, 편집 아이콘을 선택합니다.
  </TabItem>

  <TabItem label="'대시보드'">
    1. 로그인하기[‘Cloudflare’ ‘대시보드’](https://dash.cloudflare.com/), 계정 및 도메인을 선택하십시오.
    2. 오시는 길**보안 보안** > **계정 설정**.
    3. 이름 \***보안.txt**, 선택**보안.txt를 편집**.
  </TabItem>
</Tabs>

여기에서, 당신은 창조하고 당신의 관리할 수 있습니다`security.txt`vulnerabilities를 보고하는 표준화된 방법으로 보안 연구 팀을 제공 할 파일.

다음 정보를 입력:

- **(필수) 문의**: 보안 문제에 대해 문의하려면 다음 중 하나를 입력 할 수 있습니다.

  - 이메일 주소: 이메일 주소로 시작해야 합니다.`mailto:`(예:`mailto:help@example.com`).
  - 전화 번호: 전화 번호는 시작해야 합니다`tel:`(예:`tel:+1 1234567890`).
  - URL 링크: URL 링크가 시작되어야 합니다.`https://`(예:`https://example.com`).

  제품정보**더 보기**여러 연락처를 추가합니다.

- **(필수)**: 만료일 및 시간 입력`security.txt`파일.

- **암호화**: 보안 연구원이 당신과 의사 소통 할 수있는 열쇠에 대한 링크.

- **관련 기사**: 인정 페이지에 대한 링크.

- **(주)캐논**: 귀하의 링크`security.txt`파일.

- **채용 정보**: 보안 관련 업무에 대한 링크.

- **- 연혁**: 보안 연구원이 보안 문제를 검색하거나보고 할 때 어떻게해야합니까?

- **선호하는 언어**: 보안 팀이 말하는 언어 코드 목록.

필요한 정보를 입력하면 선택**제품 정보**.

security.txt 파일을 편집하려면:

- 대시보드: 선택**보안 보안** > **계정 설정** > **보안.txt를 편집**.
- 새로운 보안 대시보드:
  1. 오시는 길**보안 보안** > **계정 설정**필터링**웹 애플리케이션 악용**.
  2. 이름 \***보안.txt** > **제품 설명**, 편집 아이콘을 선택합니다.

security.txt 파일을 다운로드하려면:

- 대시보드: 선택**보안 보안** > **계정 설정** > **Security.txt 다운로드**.
- 새로운 보안 대시보드:
  1. 오시는 길**보안 보안** > **계정 설정**필터링**웹 애플리케이션 악용**.
  2. 이름 \***보안.txt** > **제품 설명**, 다운로드 아이콘을 선택합니다.

security.txt 파일을 삭제하려면:

- '대시보드':
  - 제품정보**보안 보안** > **계정 설정** > **보안 삭제.txt**.
- 새로운 보안 대시보드:
  1. 제품정보**보안 보안** > **계정 설정**필터링**웹 애플리케이션 악용**.
  2. 이름 \***보안.txt** > **제품 설명**, 편집 아이콘을 선택합니다.
  3. 제품정보**이름 \***.

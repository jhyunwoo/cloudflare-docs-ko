:::note\[사용자 권한]
Super Admin 사용자만 편집 권한으로 스캔을 시작할 수 있고, 스캔을 해제하거나 문제를 관리할 수 있습니다.
주요 특징

이름 \*[보안 통찰력](/security-center/get-started/)첫 번째 스캔 실행을 letting, the**회사연혁**탭은 Cloudflare 계정과 관련된 인프라의 개요를 표시합니다.

자주 묻는 질문**회사연혁**탭, 계정으로 이동 홈 >**보안센터** > **회사연혁**.

다음 작업을 수행 할 수 있습니다 :

- 표시된 정보를 필터링
- 인쇄 또는 PDF 보고서 다운로드
- security.txt 파일을 관리

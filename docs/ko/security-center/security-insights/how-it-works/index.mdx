당신은[보안 Insights 활성화](/security-center/get-started/), Cloudflare는 Cloudflare 계정과 관련된 인프라에서 일반 보안 검사를 실행합니다. 이 스캔은 'Cloudflare\` 계정 설정 및 'Cloudflare' 계정의 도메인에 대한 다른 'Cloudflare' 제품의 구성에 일련의 체크를 수행합니다.

수행 된 체크는 이상적인 제품 구성 및 좋은 보안 자세를 나타내는 상태의 설정으로 이동합니다. 현재 구성이 하나 이상의 체크에 대한 이상적인 구성을 충족하지 않으면 Security Center는 이러한 상황을보고합니다.**보안 통찰력**.

통찰력의 목록은 잠재적 인 보안 위협, 취약점, 준수 위험, insecure 구성 또는 기타 식별 위험이 포함될 수 있습니다.

:::참조
Security Insights는 비보호된 hostnames를 확인합니다.

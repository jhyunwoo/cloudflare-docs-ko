각 검출된 통찰력을 위해, 당신은 그것의 위험을 이해한 후에 그것을 해결하거나 아카이브 할 수 있습니다.

1. 'Cloudflare'에서 '대시보드'로 이동**보안 통찰력**사이트 맵

   <DashButton url="/?to=/:account/security-center" />

2. 다음 주소로 원하는 통찰력, 선택**이름 \***&#xAD00;련 기사

## 인사이트를 해결

:::해설
Insights는 ‘대시보드’에서 자동으로 제거되지 않습니다. 자주 묻는 질문[아카이브](#archive-insights), 수동으로 다른 검사를 방아쇠를 당기거나 자동적인 검사를 기다리십시오[검사 빈도](/security-center/security-insights/how-it-works/#scan-frequency).
:::

Resolve insights 페이지에서 권장 행동을 기반으로 구성을 업데이트하려면 통찰력 세부 페이지에서 지침을 따르십시오.

다음과 같은 통찰력은 해결하기 위해 다른 아직 straightforward 워크플로를 따릅니다.

- **TLS의 최소 버전 1.2 시행되지 않음**: 이 통찰력을 해결하기 위해 :
  - 오시는 길**사이트맵** > **Edge 인증서**.
  - 제품정보**사이트맵**.
- **"Always use HTTPS"없이 도메인**: 이 통찰력을 해결하기 위해 :
  - 오시는 길**사이트맵** > **Edge 인증서**.
  - 제품정보**항상 HTTPS 사용**.
- **JavaScript로 설정**: 이 통찰력을 해결하기 위해 :
  - 오시는 길**보안 보안** > **로그아웃**> 선택**Bot 관리 구성**.
  - 제품정보**JavaScript 탐지**.

## 수출 통찰력

보안 통찰력을 '대시보드'에서 CSV 형식으로 직접 내보내실 수 있습니다.

보안 통찰력을 내보내기:

1. 'Cloudflare'에서 '대시보드'로 이동**보안 통찰력**사이트 맵

   <DashButton url="/?to=/:account/security-center" />

2. 제품정보**수출 통찰력**.

보안 통찰력을 내보내는 것은 통찰력의 더 깊은 분석을 수행 할 수 있습니다.

수출한 CSV 파일에는 당신의 자료, 통찰력 유형 검사 날짜, 문제 종류 및 추가 선택적인 분야의 severity와 같은 정보를 통찰력 세부사항, 위험 평가, 탐지 방법 및 추천한 행동 포함합니다.

## 뉴스 레터

'대시보드'에서 하나 이상의 통찰력을 아카이브 할 수 있습니다.

아카이브:

1. 'Cloudflare'에서 '대시보드'로 이동**보안 통찰력**사이트 맵

   <DashButton url="/?to=/:account/security-center" />

2. insight(s)를 선택하여 아카이브를 원하는 다음 선택**선택 사항**.

대안으로, 통찰력을 아카이브:

1. 아카이브 및 선택하려는 통찰력을 선택하십시오.**이름 \***. '대시보드'는 페이지를 열어서 검토 할 수 있습니다.[insight 특성](/security-center/security-insights/how-it-works/#scan-properties).
2. 제품정보**아카이브 insight**.

## 법적 고지

중요한 통찰력에 대한 경고를 활성화 할 수 있습니다.

경고를 활성화하려면:

1. 'Cloudflare'에서 '대시보드'로 이동**보안 통찰력**사이트 맵

   <DashButton url="/?to=/:account/security-center" />

2. 보안 통찰력(s)을 선택하면 경고를 만들 수 있습니다.**선택된 수업에 대한 알림 생성**.

3. 알림 이름을 입력하고 알림을 필터링하기 위해 하나 이상의 통찰력 클래스를 선택합니다.

4. 제품정보**자주 묻는 질문**경고를 받기 위한 이메일 주소를 입력하십시오.

5. 제품정보**제품 정보**.

포트 스캔을 열고[매직 트레인](/magic-transit/)·[자신의 IP를 가져옵니다](/byoip/)보안 취약점을위한 IP 범위를 효율적으로 모니터링 할 수 있습니다. 이 API는 사용자가 지정한 IP 범위를 검사하고, 열려있는 항구를 검출하고, 새로 열린 항구에 관하여 매일 통보를 받으십시오.

이 기능을 통해 액세스 할 수 있습니다.[사이트맵](/api/resources/cloudforce_one/subresources/scans/subresources/config/).

## 자주 묻는 질문

- Cloudforce One Administrator, 관리자 및 슈퍼 관리자 역할.
- 계정 토큰:**사용자 정의 API 토큰 토큰** >  **구름 하나:Edit**.

사용자 정의 API 토큰 만들기:

1. 에 의해[‘Cloudflare’ ‘대시보드’](https://dash.cloudflare.com/profile/api-tokens/), 이동**내 프로필** > **API 토큰**사용자 토큰 오시는 길**사용자 정의 토큰 만들기** > **시작하기**.
2. 이름 \***토큰 이름**예를 들면,`Open Port Scanning`.
3. 내 계정**제출**:
   - 제품 정보**계좌정보**.
   - 제품정보**구름 하나**계정으로.
   - 제품 정보**제품정보**이름 \*
4. 클라이언트 IP 주소 필터링:
   - 내 계정**회사연혁**, 선택`is in`.
   - 내 계정**제품정보**, 유효한 IP 주소를 입력하십시오.
5. 제품정보**자주 묻는 질문**.
6. 토큰을 검토 한 다음 선택**토큰 만들기**.

:::참조
오픈 포트 스캐너는 IP의 사전 설정에서 실행됩니다. Cloudforce One 팀은 규칙에 이러한 IP를 허용하도록 권장합니다.

## 열린 포트 스캔 구성

Open Port Scanning을 구성하려면 다음 단계를 따르십시오.

1. **새로운 스캔 구성 만들기**:
   - **IP 정보**: 모니터를 원하는 IP 범위를 입력합니다. 범위를 정확하게 스캔 오류를 방지하기 위해 포맷 된 것을 보장합니다. API는 요청된 IP가 Cloudflare에 내장되어 있고 API 토큰에 속한 계정과 관련되어 있는지 검증합니다.
   - **주파수 영역**: 작업 빈도를 입력합니다.
   - **항구 항구**: 포트를 스캔합니다. 중 선택:
     - 모든 것
     - 기본값(refer to[기본 포트](/security-center/cloudforce-one/open-port-scanning/#default-ports)포괄적인 명부를 위해)
     - 특정 포트 목록
2. **검사 IP**: 스캔 프로세스 시작. 시스템은 지정된 IP 범위를 분석하여 개방 포트를 식별합니다.
3. **열린 포트의 목록 생성**: 스캔이 완료되면 API는 검토 및 행동에 대한 감지 된 열린 포트 목록을 생성합니다.
4. **목록 열기 포트 선택**: 어떤 포트를 열고 싶으신가요? 즉시주의를 요구하지 않는 모든 포트를 제외 할 수 있습니다.
5. **이전 스캔에서 차이 보기**: API는 마지막 스캔 이후 오픈 포트에서 변경 사항을 강조하며 새로운 취약점을 신속하게 평가할 수 있습니다.
6. **관련 상품**: 필요한 경우 언제든지 스캔 프로세스를 중지 할 수 있습니다.
7. **알림 설정**: 관심의 특정 포트에 대한 경고를 구성합니다. 지정된 포트가 새로 오픈되면 이메일 또는 webhook을 통해 즉시 통보됩니다.

:::note\[Beta 기능 공지]
Open Port Scanning 기능은 현재 닫힌 베타입니다. Cloudforce One 팀은 기능 및 사용자 경험을 향상시키기 위해 팀의 피드백을 평가합니다.
이 기능을 구독하거나 베타 프로그램에 참여하려는 경우,[Port Scanning에 대한 우리의 닫힌 베타 가입](https://www.cloudflare.com/lp/open-port-scanning-beta/).
:::

## 자주 묻는 질문

1. IP는 스캔이 어떻게 진행되나요?

   - `2a09:bac0:1008:5000:1000:0000:0000:0050/104.30.128.13`
   - `2a09:bac0:1008:5000:1000:0000:0000:0048/104.30.129.33`
   - `2001:19f0:1000:2941:5400:4ff:fe70:2a7a/140.82.60.241`

2. 포트 스캐너는 다른 보안 규칙을 무시할 수 있습니까?

   - Cloudforce One 팀은 고객이 스캐너의 IP를 올바르게 실행할 수 있도록 보장합니다.

3. 스캔은 얼마나 오래 걸리나요?

   - 스캔 한 포트의 IP 주소와 숫자에 따라 스캔은 몇 분과 최대 10 시간 사이에 걸릴 수 있습니다.

4. 자동 스캐닝을 중지 할 수 있습니까?

   - 예, 스캔을 중지하고 스캔을 다시 시작 할 모든 지점에서 결정할 수 있습니다.

5. 스캔의 제한은 무엇입니까?

   - 스캔은 최대 5,000 IP 범위로 제한됩니다.
   - API는 IPv4 및 IPv6 IP 주소를 모두 스캔합니다.

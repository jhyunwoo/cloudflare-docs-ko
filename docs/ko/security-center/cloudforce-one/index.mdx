## Analyze 위협 사건

위협 사건은 자산을 보호하고 새로운 위협에 응답 할 수 있습니다.

'Cloudflare 대시보드\`에 위협 인텔리전스 데이터를 액세스하고 분석하기 위해**위협 정보**사이트 맵

<DashButton url="/?to=/:account/security-center/threat-intelligence" />

당신은 또한 위협 이벤트를 통해 액세스 할 수 있습니다[사이트맵](/api/resources/cloudforce_one/subresources/threat_events/).

사업영역 1개의 고객은 뒤에 오는 기존하는 datasets에 접근이 있습니다:

- APTs (과태)
- DDoS 공격
- 채용정보
- Compromised 장치
- 주거 Proxies
- WAF 공격

### 청약을 식별

Cloudflare 대시보드는 다음과 같은 동적 시각화를 제공합니다:

- 샌키 다이어그램 : 공격을 추적 할 수있는 다이어그램은 원래 인프라에서 대상에 흐릅니다.
- 산업 유통 : 캠페인이 특정 분야를 대상으로하는 경우 식별 (예, 금융 또는 소매).

### 지표 검색

특정 지표에 대한 글로벌 데이터셋을 통해 검색:

- IP 주소 및 도메인
- 파일 hashes
- [JA3 지문](/bots/additional-configurations/ja3-ja4-fingerprint/)
- 위협 인텔리전스 : 특정 캠페인 또는 업계 별칭 (예를 들어, APT28)에 이벤트를 연결하여 위협 통찰력을 숨깁니다.

### 알림 받기

- Threat event 저장된 조회: 조사를 recurring를 위한 주문 여과기를 저장하십시오.
- 자동화된 규칙: 위협 자료에서 보안 규칙을 직접 생성하고 Cloudflare로 밀어[‘WAF’](/waf/)또는 방화벽.
- [STIX2 수출](https://www.cloudflare.com/en-gb/learning/security/what-is-stix-and-taxii/): 타사 SIEM / SOAR 플랫폼과 원활한 통합을위한 수출 인텔리전스.

## Cloudy를 사용하여 위협 이벤트 분석

Cloudy, Cloudflare's AI Agent를 사용하여 위협 이벤트의 분석 및 요약을 수신 할 수 있습니다.

Cloudy를 사용하여 위협 이벤트 분석 :

1. 'Cloudflare'에서 '대시보드'로 이동**위협 정보**사이트 맵

   <DashButton url="/?to=/:account/security-center/threat-intelligence" />

2. 오시는 길**위협 사건** > **Analyze 와 Cloudy**.

Cloudy는 최고의 위협 이벤트를 표시하고 분석하고 위협 이벤트 요약을 제공합니다. 분석도 할 수 있습니다.**공격자**, **회사연혁**, 더 많은 것. 예를 들어, "ABC Attacker 용 위협 이벤트 요약"을 입력 할 수 있습니다. Cloudy는 ABC 공격자를위한 위협 이벤트를 요약합니다.

3. 제품정보**새로운 요청**.

4. 필요한 필드에 채우기, 다음 선택**제품 정보**.

<Details header="RFI 유형 목록">
  Cloudflare\`대시보드는 Cloudforce One Requests를 구성할 때 다음과 같은 요청 유형을 제시합니다.

  - **이진 분석 - IOCs**: 고수준 악성코드 분석[회사연혁](https://www.cloudflare.com/en-gb/learning/security/what-are-indicators-of-compromise/)콜백 도메인 또는 IP 주소와 같은.

  - **Binary Analysis - 보고서**: 악성 코드 샘플의 철저한 분석으로 attribution 평가를 생성하고 더 분석을위한 샘플의 구성을 추출합니다. 문제를 조사하거나 검출 논리를 개발하려고하는 고객을 위해 유용한[사이트맵](https://en.wikipedia.org/wiki/Endpoint_detection_and_response)또는 네트워크 센서.

  - **DDoS 공격**: 특정 웹 사이트에 대한 공격이 발생하면 사용 가능한 지표 및 잠재적 인 공격을 공유 할 수 있습니다.

  - **지표 분석 - IOCs**: DNS 조회, 기원 피벗 및 DNS 해상도, 기원 IP 및 하위 도메인과 같은 지표를 제공하는 계정 피벗. 분석은 계정 등록 패턴과 희생학을 포함 할 수 있습니다.

  - **지표 분석 - Report**: 형식, 구조형 형식으로 작성된 지표의 철저한 분석. 자주 묻는 질문[타협의 지표 (IOCs)](https://www.cloudflare.com/en-gb/learning/security/what-are-indicators-of-compromise/), 보고서는 공격 체인 내에서 IOCs 함수를 어떻게 설명하고 IOCs를 특정 캠페인 및/또는 위협 행위자 및 TTP에 연결하여 컨텍스트를 추가합니다.

  - **수동적인 DNS 해결책**: IP 주소 쌍을 도메인에 연구하여 지정된 시간 동안 해결했습니다.

  - **전략적 위협 연구**: 전략적 위협 연구는 더 넓은 분석, 장기적인 추세, 위협 행위자 및 산업 - 종종 오픈 소스 인텔리전스에 의해 보충하고 즉시 행동 가능한 인텔리전스를 제공보다 높은 수준의 관리 및 계획을 알리는 것입니다.

  - **위협 탐지 서명 - IOCs**: IP 주소, 도메인, 파일 해시 또는 파일 또는 HTTP 요청의 속성과 같은 샘플, 행동 또는 네트워크 관찰을 감지하는 Yara와 같은 규칙을 개발합니다.

  - **위협 탐지 서명 - Report**: 위협 탐지 경고의 세부사항을 조사하고 또는 그들의 응답 노력 또는 위협 배우에 재산 활동의 우선권을 시도하는 고객의 이익을 위한 보고하는 철저한 분석 보고서.

  - **트래픽 분석 - IOCs**: 문제의 IOCs의 HTTP telemetry를 검토하고 피해 국가 및 일부 경우에 피해자 ASNs를 포함 할 수있는 관련 위생 트래픽을 제공합니다. 악성 파일/Payloads 및 특정 파일 경로 또는 요청 패턴을 식별합니다.

  - **교통 분석 - Report**: HTTP telemetry를 분석하여 패턴, anomalies 및 악의적 행동에 대한 데이터 포인팅을 식별합니다. 관찰 된 네트워크 행동에 대한 컨텍스트를 제공하고 특정 위협 그룹의 TTP를 알려줍니다.

  - **취약점**: IP, 도메인, 또는 취약점의 위협 배우 또는 조사에 취약점 취약점에 대한 조사. 응답은 관련, 위생화한 교통은 피해 국가 및 기업의 악용과 ID를 해독할 수 있습니다.

## 자주 묻는 질문

1. 'Cloudflare'에서 '대시보드'로 이동**위협 정보**사이트 맵

   <DashButton url="/?to=/:account/security-center/threat-intelligence" />

2. 오시는 길**Incident 응답 서비스**다음 지침을 완료:

- **회사 소개**:
  - 선택 중**post-incident 지원 받기**, **회사 소개**, **행동 탁상 운동**, **자주 묻는 질문**.
  - 원하는 서비스를 선택한 후, 선택**이름 \***.

  - 이전에 선택한 서비스에 따라 필요한 정보를 입력합니다. 모든 정보를 입력하면, 선택**이름 \***.

## Active Attack에 대한 도움말

활성 사이버 공격을 중지하려면 'Cloudflare\`\`대시보드를 통해 도움을 요청할 수 있습니다.

1. 'Cloudflare'에서 '대시보드'로 이동**계정 홈**페이지 및 계정 선택.

<DashButton url="/?to=/:account/home" />

2. 상단 바에, 선택**지원하다** > **도움 받기** > **공격 중**.
3. 이름 \***Active cyberattacks를 중지하는 데 도움이 필요**, 선택**자주 묻는 질문**.
4. '대시보드'는 휴대폰 번호를 입력하고 확인해야 할 팝업을 표시합니다.
5. 휴대폰 번호를 입력하면 선택**확인 번호 및 요청 도움**. '대시보드'에서 요청하는 것은 사건 응답자를 페이지하고 가능한 한 빨리 전화를 기대할 수 있습니다. 우리는 전화 백을 기다리고 조언하고 10 분 이내에 팀에서 다시 들지 않은 경우 전화 라인 만 사용합니다.

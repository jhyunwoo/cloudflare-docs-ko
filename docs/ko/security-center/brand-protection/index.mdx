## 쿼리의 종류

Cloudflare 브랜드 보호는 감시 impersonation: 도메인 검색 및 로고 검색에 대한 두 가지 명백한 방법을 제공합니다.

### 도메인 검색

텍스트 패턴, 마우스, 또는 서비스 조합을 기반으로 도메인 검색.

새로운 도메인 검색을 시작하려면 브랜드를 식별하려고 할 수 있습니다.

1. 'Cloudflare'에서 '대시보드'로 이동**상표 보호**사이트 맵

   <DashButton url="/?to=/:account/security-center/brand-protection" />

2. 내 계정**문자열 쿼리**, 당신의 조회를 위한 이름을 제공합니다. 동일한 쿼리에 여러 개의 브랜드 구문을 추가 할 수 있으며 결과가 모두 일치합니다. 문자열 쿼리를 입력하면 선택**검색 일치**.

3. 내 계정**문자 거리**, 에서 선택`0-3`. 결과가 문자열과 다를 수 있다는 것을 정의한다 (예를 들어, 1의 거리는 잡을 것이다`clpudflare.com`). 검색 결과를 찾을 수 없음 한국어 사전에

   :::참조

   브랜드 구문 또는 검색 용어가 5 개 미만의 경우 최대 거리를 선택할 수 있습니다.`0`(제로).
   주요 특징

4. 선택할 수 있습니다.**자주 묻는 질문**미래에 모니터링하고 삭제, 복제 및 설정 경고와 같은 다른 작업을 수행, 당신의 유료 계획 제한에 따라.

5. 저장된 쿼리에서 모든 경기를 내보내려면, 당신의 선택**Query 이름**> 3개의 점 선택 >**수출 경기**.

섹션에서**모니터 문자열**, 당신은 모니터에 선택한 모든 문자열 쿼리를 확인할 수 있습니다. 삭제, 복제, 또는 문자열 쿼리에 대한 알림을 만들 수 있습니다. 더 알아보기[상표 보호 경고](#brand-protection-alerts)알림 설정.

### 로고 검색 (AI-powered)

로고 검색은 시각적 자산을 사용하여 도메인을 감지하기 위해 컴퓨터 비전을 사용합니다. 도메인 이름은 브랜드 문자열을 포함하지 않습니다.

새 로고 쿼리를 설정하려면:

1. 제품정보**모니터 로고**선택하기**로고 추가**.
2. 쿼리에 이름을 추가하고 로고를 업로드하십시오. 한국어`.png`, `.jpeg`·`.jpg`파일 확장자는 지원됩니다.
3. 임계값을 설정하십시오: 일치 임계값을 설정하십시오 (최소 75 %입니다). 높은 점수는 높은 정밀도 일치를 보장하지만 낮은 점수는 로고의 혼합 또는 약간 변경 된 버전을 잡습니다.
4. 제품정보**로고 저장**. 시스템은 이제 시각적 일치에 대한 새로 발견 된 인프라를 스캔합니다.

브라우저가 반환됩니다.**감시된 로고**페이지, 쿼리에 액세스하고 알림을 구성 할 수 있습니다.

## 자주 묻는 질문

이 섹션에서 대시보드 표시:

- **도메인 개요**요청할 수 있는 곳[categorization를 바꾸십시오](/security-center/investigate/change-categorization/)7 일 동안 도메인의 해상도 역사를 볼 수 있습니다.
- **이름 \***&#xD574;당 이용 후기에 달린 코멘트가 없습니다.
- **도메인 역사**그것은 도메인 범주에 대한 정보를 제공하고 마지막으로 변경 될 때. 더 알아보기[위험 경고](/security-center/investigate/investigate-threats/)더 많은 정보.
- **URL 보고서**그것은 어떤 보고된 URL에 정보를 제공합니다.

문자열 쿼리를 조사하려면:

1. 오시는 길**모니터 문자열**또는**모니터 로고**모든 쿼리를 볼 수있는 섹션.
2. 쿼리를 일치하는 모든 도메인을 검사하는 모니터링 된 쿼리를 선택합니다.
3. 도메인에 다음, 선택**이름 \***&#xB610;는**사이트 맵**. 이것은 검색을 트리거합니다.[**투자정보**](/security-center/investigate/)별도의 탭의 섹션. URL 스캐너는 또한 트리거됩니다**상표 보호**오시는길**보안센터** > **투자정보**. 자동으로 생성된 보고서에 액세스할 수 있습니다. 이 보고서는 일치하는 도메인의 스크린 샷을 표시하고 도메인의 등록 상표입니다.

## 상표 보호 API

더 보기[상표 보호 API](/api/resources/brand_protection/)programmatic 관리 및 통합을 허용합니다.[사이트맵](https://www.cloudflare.com/en-gb/learning/security/glossary/what-is-a-security-operations-center-soc/)또는[사이트맵](https://www.cloudflare.com/en-gb/learning/security/what-is-siem/). 상표 보호 API를 사용하여, 당신은 할 수 있습니다:

- 쿼리를 관리: 작성, 편집, 삭제 문자열 및 로고 쿼리.
- Data retrieval: 자동화 된 섭취에 대한 읽기 및 다운로드 일치.
- Query 편집 : 역사적인 데이터를 잃지 않고 기존 쿼리 매개 변수를 업데이트합니다.

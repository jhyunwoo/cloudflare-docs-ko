## 적용분야

Cloudflare Security Center는 모든 계획에 고객에게 제공됩니다. 어떤 의견, 질문, 또는 버그가 있다면, 게시물을 작성['Cloudflare' 커뮤니티 포럼](https://community.cloudflare.com/c/security/security-center/65).

보안 검사의 주파수는 'Cloudflare\` 계획에 따라 다릅니다. 더 알아보기[검사 빈도](/security-center/security-insights/how-it-works/#scan-frequency)더 많은 정보.

## 제한 사항

- 사용자와[Administrator 읽기 전용](/fundamentals/manage-members/roles/#account-scoped-roles)역할은 Cloudflare Security Center에 접근할 수 없습니다.
- 'Cloudflare' 계정은 적어도 하나의 비즈니스 또는 엔터프라이즈 영역, 또는 팀 표준 또는 팀 엔터프라이즈 계획에 계정, 수동으로 새로운 스캔을 시작할 수 있습니다.

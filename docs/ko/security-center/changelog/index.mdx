## 2025-02-03

- Security Center는 이제 Brand Protection이라는 역할을 합니다. 이 역할은 API 및 Cloudflare 대시보드에서 브랜드 보호 기능에 액세스할 수 있습니다. 브랜드 보호 역할도 Investigate 플랫폼에 액세스 할 수 있습니다. Threat Intel API 및 URL 스캐너 API 통화를 사용할 수 있습니다.

## 2025-01-20

- URL 스캐너에서 보고서를 검색하는 고객은 해당 특정 호스트 이름과 관련된 모든 보고서 목록을 얻을 수 있습니다. 보안 보고서도 있습니다. 해시를 선택하면 대시보드는 같은 해시를 포함하는 보고서를 나열합니다.

## 2024-09-23

- 고객은 이제 저장된 쿼리에서 모든 경기를 수출 할 수 있습니다. 자주 묻는 질문**Query 이름**> 3개의 점 선택 >**수출 경기**.

## 2024-09-19

- 고객은 지금 만들 수 있습니다`security.txt`vulnerabilities를 보고하는 표준화된 방법으로 보안 연구 팀을 제공 할 파일.

## 2024-07-22

- 고객은 동시에 여러 보안 통찰력을 아카이브 할 수 있습니다. 오시는 길**보안센터** > **보안 통찰력**아카이브에 대한 통찰력을 선택합니다.

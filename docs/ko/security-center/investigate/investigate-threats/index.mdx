## IP 주소

이름 \*[IP 주소](https://www.cloudflare.com/learning/dns/glossary/what-is-my-ip-address/)서버 식별의 고유 주소입니다. 그것은 뜻합니다[인터넷 프로토콜](https://www.cloudflare.com/learning/network-layer/internet-protocol/), 서버가 서로 소통 할 수있는 규칙의 집합이다.

IP 주소 검색 가능[IPv4 및 IPv6](https://www.cloudflare.com/learning/dns/glossary/what-is-my-ip-address/)포인터 레코드, AS 번호 및 수동 DNS 레코드와 같은 관련 정보를 검색합니다.

## 이름 \*

·[도메인 이름](https://www.cloudflare.com/learning/dns/glossary/what-is-a-domain-name/)IP 주소로 지도하는 텍스트의 문자열입니다. 도메인 이름은 사람들이 웹 사이트가 호스팅되는 곳을 기억하는 데 도움이됩니다. 도메인 네임을 통해 구매[계정 관리](/registrar/)누구나 쉽게 취득할 수 있습니다.

도메인 이름을 검색할 때, Cloudflare는 도메인의 개요를 제공하게 됩니다.[·](#domain-categories)IP 주소는 현재 해결합니다.

## AS 번호

이름 \*[AS 번호](https://www.cloudflare.com/learning/network-layer/what-is-an-autonomous-system/)IP 주소의 그룹은 단일 조직에 의해 부과되고 제어됩니다. 네트워크의 전체 그룹은 단일 미화 정책이 있습니다. 더 보기[인터넷 위탁 번호 기관](https://www.iana.org/)(IANA)는 AS 번호의 할당 및 배포를 관리 할 책임있는 조직입니다. AS 번호의 여정 정책은 다음과 같습니다.[사이트맵](https://www.cloudflare.com/learning/security/glossary/what-is-bgp/)Cloudflare\`는[anycast 네트워크](https://www.cloudflare.com/learning/cdn/glossary/anycast-network/)이름 \*

AS 번호를 검색하면 Cloudflare는 국가, 설명 및 유형과 같은 등록 데이터를 반환합니다. 또한 도메인 수, 상위 10 도메인 및 하위넷과 같은 데이터를 표시합니다.

충분한 데이터로, AS 번호 검색 결과는 네트워크, 애플리케이션 레벨 공격 및 네트워크 레벨 공격에 대한 트래픽의 지리적 분포를 반환합니다. 각각 'Cloudflare' mitigation 기술 및 네트워크 프로토콜에 의해 끊긴 각.

## 사이트 맵

URL을 검색할 때, Cloudflare는 지난 30일 동안 특정 URL에 대한 최근의 스캔 보고서를 제공합니다. 이전에 생성 된 보고서를 보거나 새로운 보고서를 생성하기 위해 다시 스캔 할 수 있습니다.

다른 Cloudflare 계획은 다른 것[스캔 제한](/security-center/investigate/scan-limits/).

URL을 스캔하려면:

1. 'Cloudflare'에서 '대시보드'로 이동**투자정보**사이트 맵

   <DashButton url="/?to=/:account/security-center/investigate" />

2. URL을 입력한 다음 선택**이름 \***.

또는 URL을 스캔하려면 URL로 이동[Cloudflare 레이더](https://radar.cloudflare.com/) > **URL 스캐너**. URL을 입력한 후 선택**관련 기사**.

주요 특징

### 제품정보

새로운 스캔 보고서를 생성하면 기본 가시성은 설정됩니다.`Unlisted`,하지만 당신은 그것을 설정 옵션이`Public`. 선택하여`Public`, 생성된 검사는 모든 Cloudflare 대시보드와 Cloudflare Radar user alike에 사용할 수 있으며, 다른 사람들에게 잠재적으로 악성 웹 사이트의 인식을 높일 수 있습니다.

우리는 선택을 추천합니다`Unlisted`Wider Cloudflare 커뮤니티와 공유하지 않는 인프라를 스캔하는 경우.

### 필터링

가장 최근의 스캔을 보면서 필터링 옵션을 사용할 수 있습니다. 제품정보`All account scans`모두 표시`Unlisted`또는`Public`'Cloudflare\` 계정에서 시작된 스캔. 그러나, 선택하여`All global scans`, 만`Public`스캔이 표시됩니다.

보고서 다운로드:

   <DashButton url="/?to=/:account/security-center/investigate" />

2. 도메인을 입력하고 선택**이름 \***.

3. 보고서가 생성되면, 선택**다운로드**그리고 사이에서 선택**다운로드 HAR**또는**JSON 다운로드**.

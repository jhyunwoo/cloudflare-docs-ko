:::note\[사용자 권한]
모든 사용자는 Investigate에 접근할 수 있습니다. URL 스캔 및 필터 수동 DNS 범위에 액세스 할 수 있습니다.
주요 특징

Investigate는 도메인의 범주를 볼 수 있습니다. IP는 속보이며, 범주가 이전 변경되었는지 여부. 소스 및 수동 DNS 레코드를 포함하여 포인트를 기록 할 수 있습니다. Investigate로 검색하면 동일한 검색 결과를 검색하는 API 컬을 얻을 수 있습니다.

IP 주소를 통해 검색하여 IP 주소의 IP 주소에 대해 자세히 알아볼 수 있습니다. IP 주소, 도메인 이름 및 호스트 이름을 입력하여 위협 관점에서 분류 된 방법을 참조하십시오.

조사도 쇼[웹 애플리케이션 방화벽](https://developers.cloudflare.com/waf/)'Cloudflare'의 웹 사이트에 대한 분석은 취약점이 무엇인지 발견하는 데 도움이되며 공격이 어디에서 왔는지 알 수 있습니다.

Cloudflare는 자신의 내용과 보안 유형에 따라 도메인을 분류합니다. 당신은 categorization 변화를 통해 요청할 수 있습니다[‘대시보드’](#via-the-cloudflare-dashboard), [Cloudflare 레이더](#via-cloudflare-radar), 또는[사이트맵](#via-the-api).

카테고리의 상세한 목록은, 참조[도메인 범주](/cloudflare-one/traffic-policies/domain-categories/).

## ‘Cloudflare’ 대시보드를 통해

Cloudflare\`대시보드를 통해 categorization 변경을 요청하려면:

1. 'Cloudflare'에서 '대시보드'로 이동**투자정보**사이트 맵

   <DashButton url="/?to=/:account/security-center/investigate" />

2. 변경하려면 도메인 검색.

3. 내 계정**도메인 개요**, 선택**categorization를 바꾸기 위하여 요구**.

4. 변경 사항[보안 범주](/cloudflare-one/traffic-policies/domain-categories/#security-categories)또는[사이트 맵](/cloudflare-one/traffic-policies/domain-categories/#content-categories).

5. 도메인에서 추가하거나 제거하려는 범주를 선택하십시오.

   :::노트\[Content Category limit]

   도메인은 두 개 이상의 관련 내용 범주를 가질 수 없습니다. 두 개 이상의 기존 카테고리로 도메인의 범주로 변경하려면 기존 범주 중 하나 이상의 제거하십시오.
   주요 특징

6. 제품정보**제출하기**자주 묻는 질문

보안 카테고리 변경 요청은 제출이 유효하다는 것을 확인하려면 'Cloudflare'에 의해 더 깊은 조사를 트리거합니다. 콘텐츠 카테고리 변경을 요청하면 'Cloudflare' 유효성 검사가 필요하지만, 이러한 제출의 반환 시간은 일반적으로 더 적은 조사가 필요합니다.

카테고리 변경 요청은 변경 유형에 따라 'Cloudflare' 팀에 의해 수정됩니다. 요청이 검토되고 'Cloudflare'팀에 의해 적용된 경우, 새로운 범주는 'Cloudflare' 대시보드에서 볼 수 있습니다.**보안센터** > **투자정보**, 뿐 아니라[Cloudflare 레이더](https://radar.cloudflare.com/).

:::카트로션

Cloudflare는 카테고리 변경을 보장하지 않습니다.
주요 특징

## ‘Cloudflare’ 라다

'Cloudflare\` Radar를 통해 recategorization 요청하려면 피드백을 제출하십시오.[Radar 도메인 Categorization](https://radar.cloudflare.com/domains/feedback).

## API를 통해

API를 통해 categorization 변화를 요청하려면:

1. [API 토큰 만들기](/fundamentals/api/get-started/create-token/)Intel 계정을 편집할 권한이 있습니다.

   | **제출** |      |      |
   | ------ | ---- | ---- |
   | 계좌정보   | 지원하다 | 제품정보 |

   | **계정 리소스** |       |
   | ---------- | ----- |
   | 이름 \*      | 모든 계정 |

2. 자주 묻는 질문[miscategorization 엔드포인트](/api/resources/intel/subresources/miscategorizations/methods/create/)도메인 이름 및 어떤 카테고리를 포함 하 여 추가 또는 제거 하 고 싶습니다. 예를 들면:

   ```bash
   curl https://api.cloudflare.com/client/v4/accounts/{account_id}/intel/miscategorization \
   --header "Authorization: Bearer <API_TOKEN>" \
   --header "Content-Type: application/json" \
   --data '{
     "content_adds": [
       82
     ],
     "content_removes": [
       155
     ],
     "indicator_type": "domain",
     "ip": null,
     "security_adds": [
       117,
       131
     ],
     "security_removes": [
       83
     ],
     "url": "example.com"
   }'
   ```

MoQ (Media over QUIC)는 QUIC 운송을 사용하여 라이브 미디어 콘텐츠를 제공하는 프로토콜입니다. QUIC의 다중화 및 연결 관리 기능을 레버링하여 효율적이고 저렴한 미디어 스트리밍을 제공합니다.

MoQ는 HTTP가 콘텐츠 전달과 WebRTC가 실시간 통신을 제공하는 방식과 같은 애플리케이션에 미디어 전달을 제공하는 인터넷 인프라 수준의 서비스로 설계되었습니다.

Cloudflare의 MoQ의 구현은 현재 MoQ의 서브셋을 지원합니다.[초안 07 MoQ 수송 specfication](https://datatracker.ietf.org/doc/html/draft-ietf-moq-transport-07).

프로토콜의 최신 문서의 경우 IETF 작업 그룹 문서를 방문하십시오.

## 자주 묻는 질문

- Safari는 무엇입니까?

  Safari는 아직 완전히 기능적인 WebTransport 지원이 없습니다. Apple은이 같은 새로운 기능을 위해 적시에 투입하지 않습니다. 그러나, 애플은 그들의 표시[WebTransport를 지원하기 위해](https://github.com/WebKit/standards-positions/issues/18#issuecomment-1495890122). Apple 직원은 공동 저자이기도합니다.[HTTP/3 이상 WebTransport](https://datatracker.ietf.org/doc/draft-ietf-webtrans-http3/)한국어 Safari 18.4 (2025-03-31) 이후 WebTransport API의 초기 구현은 개발자 모드 / 고급 설정 기능 플래그 (iOS 포함) 뒤에 테스트 할 수 있습니다.

  Safari는 완전히 기능적인 WebTransport 구현을 가지고 있기 때문에 일부 MoQ 사용 사례는 WebRTC 또는 일부 경우 WebSockets에 fallback이 필요할 수 있습니다.

## Known 문제

- Extra Subgroup 헤더 필드

  현재 구현에는`subscribe_id`Subgroup Headers의 필드[`draft-ietf-moq-transport-07`](https://datatracker.ietf.org/doc/html/draft-ietf-moq-transport-07)미츠.

  섹션 7.3.1에서,`draft-ietf-moq-transport-07` [관련 상품](https://www.ietf.org/archive/id/draft-ietf-moq-transport-07.html#section-7.3.1):

  ```txt
  STREAM_HEADER_SUBGROUP Message {
    Track Alias (i),
    Group ID (i),
    Subgroup ID (i),
    Publisher Priority (8),
  }
  ```

  우리의 구현은 기대하고 생산 :

  ```txt
  STREAM_HEADER_SUBGROUP Message {
    Subscribe ID (i),
    Track Alias (i),
    Group ID (i),
    Subgroup ID (i),
    Publisher Priority (8),
  }
  ```

  이전 초안 버전에서 실수로 남아 있으며 향후 릴리스에 고정 될 것입니다. 이름 \*[@yuki-uchida, 일본](https://github.com/yuki-uchida)견적 요청

Cloudflare는 보안 이벤트에서 모든 스파이크를 알리는 두 가지 유형의 보안 경고를 제공합니다.

- **보안 이벤트 Alert**: 보안 이벤트에서 로그 항목을 생성하는 모든 서비스에서 스파이크에 대해 경고합니다.
- **고급 보안 이벤트 Alert**: 추가 필터링 옵션에 대한 지원으로 Security Events Alert와 유사합니다.

경고 유형과 그 가용성에 대한 세부 사항, 참조[Alert 유형](#alert-types).

보안 경고를 수신하려면 구성해야 합니다.[공지사항](/notifications/). 알림은 Cloudflare 계정으로 이메일, PagerDuty 또는 webhooks를 통해 귀하의 Cloudflare 플랜에 따라 최신 상태로 유지됩니다.

## 보안 경고 알림 설정

보안 경고에 대한 알림을 설정하는 방법에 대한 지침은 참조[공지사항](/notifications/get-started/#create-a-notification).

***

## Alert 로직

보안 경고는 정적 임계값을 사용하여[z 코어](https://en.wikipedia.org/wiki/Standard_score)지난 6 시간 동안 계산 및 이벤트의 5 분 버킷. 경고는 z-score 값이 3.5 이상이고 스파이크는 200 보안 이벤트의 임계값을 교차합니다. 동일한 두 시간의 프레임 내에서 중복 경고를받지 않습니다.

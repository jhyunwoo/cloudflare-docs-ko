Web Application Firewall은 다음을 제공합니다.[회사연혁](/ruleset-engine/about/phases/)규칙과 규칙을 만들 수있는 곳 :

- `http_request_firewall_custom`
- `http_ratelimit`
- `http_request_firewall_managed`

이 단계는 계정 수준과 영역 수준에서 모두 존재합니다. 사용 가능한 단계와 두 가지 다른 수준 고려, 규칙은 다음 순서로 평가됩니다:

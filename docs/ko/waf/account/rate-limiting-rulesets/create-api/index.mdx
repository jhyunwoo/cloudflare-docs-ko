계정 수준에서 제한 규칙을 배포하려면 하나 이상의 규칙을 가진 제한 규칙을 작성해야합니다. 사용 방법[규칙 세트 API](/ruleset-engine/rulesets-api/)API를 통해 규칙을 제한하고 배포합니다.

규칙 매개 변수에 대한 자세한 내용은 참조[비율 제한 모수](/waf/rate-limiting-rules/parameters/).

:::참조
API 수준에서, 제한 룰렛은 일반적입니다[주문 규칙](/waf/account/custom-rulesets/)하나 이상의 속도 제한 규칙을 사용하면`http_ratelimit`단계. 규칙을 제한하는 사용자 정의 비율의 개념은 Cloudflare 대시보드에 존재하여 계정 수준에서 설정 및 배포 속도 제한 규칙을 명확하게합니다. API 지시를 가진 이 페이지는 동일한 terminology를 이용합니다.
주요 특징

각 비율 제한 규칙은 포함합니다`ratelimit`제한 설정과 객체. 더 알아보기[비율 제한 모수](/waf/rate-limiting-rules/parameters/)이 객체와 그 매개 변수에 대한 자세한 내용은.

Terraform을 사용하는 경우, 참조[Terraform을 사용하여 제한 규칙 구성](/terraform/additional-configurations/rate-limiting-rules/#create-a-rate-limiting-rule-at-the-account-level).

## 회사연혁

계정의 제한 규칙을 배포하려면 이러한 일반적인 단계를 따르십시오.

1. 규칙을 제한하는 비율 생성 (즉, 사용자 정의 규칙에`http_ratelimit`단계) 하나 이상의 비율 제한 규칙.
2. 규칙을 배포[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)이름 \*`http_ratelimit`계정 수준에서 단계.

### 1. 규칙을 제한하는 비율 만들기

다음 예제는 단일 비율 제한 규칙을 가진 비율 제한 규칙을 만듭니다.`rules`배열.

<APIRequest
  path="/accounts/{account_id}/rulesets"
  method="POST"
  json={{
  	description: "",
  	kind: "custom",
  	name: "My rate limiting ruleset",
  	rules: [
  		{
  			description: "Rate limit API requests",
  			expression: '(starts_with(http.request.uri.path, "/my-api/"))',
  			ratelimit: {
  				characteristics: ["ip.src", "cf.colo.id"],
  				requests_to_origin: false,
  				requests_per_period: 30,
  				period: 60,
  				mitigation_timeout: 120,
  			},
  			action: "block",
  			action_parameters: {
  				response: {
  					status_code: 429,
  					content_type: "application/json",
  					content:
  						'{ "error": "Your API requests have been rate limited. Wait a couple of minutes and try again." }',
  				},
  			},
  			enabled: true,
  		},
  	],
  	phase: "http_ratelimit",
  }}
  roles="account"
/>

유효한 특성은 Cloudflare 계획 및 제품 구독에 달려 있습니다. 더 알아보기[적용분야](/waf/rate-limiting-rules/#availability)더 많은 정보.

다음 단계에 대한 응답에 규칙 ID를 저장합니다.

### 2. 규칙 제한 속도 배포

규칙을 제한하는 비율을 배포하려면 규칙을 추가하십시오.`"action": "execute"`이름 \*`http_ratelimit`계정 수준에서 단계 항목 포인트 규칙.

1. <Render file="rulesets/api-account/step1-get-entrypoint" product="waf" params={{ phaseName: "http_ratelimit" }} />

   <APIRequest
     path="/accounts/{account_id}/rulesets/phases/{ruleset_phase}/entrypoint"
     method="GET"
     parameters={{
     	ruleset_phase: "http_ratelimit",
     }}
     roles="account"
   />

   ```json output {4}
   {
   	"result": {
   		"description": "Account-level phase entry point",
   		"id": "<RULESET_ID>",
   		"kind": "root",
   		"last_updated": "2024-03-16T15:40:08.202335Z",
   		"name": "root",
   		"phase": "http_ratelimit",
   		"rules": [
   			// ...
   		],
   		"source": "firewall_managed",
   		"version": "10"
   	},
   	"success": true,
   	"errors": [],
   	"messages": []
   }
   ```

2. <Render
     file="rulesets/api-account/step2-create-rule"
     product="waf"
     params={{
     	deploymentItem: "rate limiting ruleset",
     }}
   />

   다음 요청은 ID로 제한 규칙을 실행하는 규칙을 만듭니다.`<RATE_LIMITING_RULESET_ID>`계정의 모든 엔터프라이즈 영역에 대한:

   <APIRequest
     path="/accounts/{account_id}/rulesets/{ruleset_id}/rules"
     method="POST"
     json={{
     	description: "Execute rate limiting ruleset",
     	expression: '(cf.zone.plan eq "ENT")',
     	action: "execute",
     	action_parameters: {
     		id: "<RATE_LIMITING_RULESET_ID>",
     	},
     	enabled: true,
     }}
     roles="account"
   />

   <Render file="account-enterprise-zones-only-api" product="waf" />

3. <Render
     file="rulesets/api-account/step3-create-ruleset"
     product="waf"
     params={{
     	deploymentItem: "rate limiting ruleset",
     	scope: "all incoming requests of Enterprise zones in your account",
     }}
   />

   <APIRequest
     path="/accounts/{account_id}/rulesets"
     method="POST"
     json={{
     	description: "",
     	kind: "root",
     	name: "Account-level phase entry point",
     	rules: [
     		{
     			action: "execute",
     			expression: '(cf.zone.plan eq "ENT")',
     			action_parameters: {
     				id: "<RATE_LIMITING_RULESET_ID>",
     			},
     		},
     	],
     	phase: "http_ratelimit",
     }}
     roles="account"
   />

API의 규칙 정의를 제한하는 비율의 예를 들어, 참조[API를 통해 제한 규칙을 생성](/waf/rate-limiting-rules/create-api/).

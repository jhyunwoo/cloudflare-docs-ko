이 기능은 유료 애드온과 엔터프라이즈 플랜이 필요합니다.
주요 특징

계정 수준에서 제한 규칙을 제한하는 비율은 규칙을 제한하는 비율로 그룹화됩니다. 당신은 먼저 하나의 또는 더 많은 속도 제한 규칙을 가진 사용자 정의 규칙을 만들고, 그 다음 엔터프라이즈 계획에 하나 이상의 영역으로 배포해야합니다.

규칙 매개 변수에 대한 자세한 내용은 참조[비율 제한 모수](/waf/rate-limiting-rules/parameters/).

## 1. 규칙을 제한하는 주문 비율을 창조하십시오

<Steps>
  1. Cloudflare 대시보드에서**사이트맵**사이트 맵

     <DashButton url="/?to=/:account/application-security/waf" />

  2. 오시는 길**비율 제한 규칙**탭.

  3. 새로운 빈 규칙을 만들려면, 선택**규칙 만들기**. 기존 규칙을 복제하려면 다음 세 가지 점을 선택하십시오 >**기타 제품**.

  4. 규칙과 (선택)의 이름을 입력합니다.

  5. 규칙 작성 페이지에서, 선택**규칙 만들기**.

  6. 규칙 작성 페이지에서 규칙에 대한 설명 이름을 입력합니다.**규칙 이름**.

     ![Cloudflare 대시보드의 계정 수준에서 제한 규칙을 생성](~/assets/images/waf/custom-rules/rate-limiting-create-account.png)

  7. 이름 \***수신 요청 일치**, 사용**제품정보**드롭다운 목록은 HTTP 속성을 선택합니다. 각 요청에 대해 선택한 속성의 값**제품정보**지정한 값에 비해**제품정보**선택된 연산자를 사용하여**회사연혁**.

  8. (선택) 밑에**캐시 상태**, 비활성화**또한 캐시된 자산에 제한하는 비율 적용**비율을 결정할 때 기원에 도달하는 요청만 고려하십시오.

  9. 이름 \***동일한 특성으로**, 값 제한 목적을 위해 요청 카운터를 정의하는 특성을 구성합니다. 각 가치 조합은 그것의 자신의 카운터가 비율을 결정할 것입니다. 더 알아보기[Cloudflare가 요청 비율을 결정하는 방법](/waf/rate-limiting-rules/request-rate/)더 많은 정보.

     유효한 특성은 Cloudflare 계획 및 제품 구독에 달려 있습니다.

  10. (선택) 비율 카운터를 증가시키는 조건을 지정하는 표현을 정의하려면, 활성화**사용자 정의 계산 표현**그리고 표현을 설정한다. 기본적으로, 카운트 표현은 규칙 표현과 동일합니다. 계산 표현은 포함될 수 있습니다[응답 분야](/ruleset-engine/rules-language/fields/reference/?field-category=Response).

  11. 이름 \***비율 초과시**, 최대 요청 수와 시간을 정의하여 비율을 결정할 때 고려하십시오.

  12. 이름 \***다음 작업을 수행**, 규칙 작업을 선택**작업 선택**드롭다운 목록. 예를 들어, 선택*제품정보*Cloudflare는 요청 제한이 도달되면 지정된 조건에서 요청을 거부합니다.

  13. (선택) 선택한 경우*제품정보*활동, 당신은 할 수 있습니다[사용자 지정 응답 구성](#configure-a-custom-response-for-blocked-requests)지정된 비율 제한을 초과하는 요청을 위해.

  14. 소송 시간 선택**이름 \***&#xB4DC;롭다운. Cloudflare가 한 번의 비율이 도달되면 선택 동작을 적용합니다.

      유료 애드온을 가진 기업 고객[throttle 요청](/waf/rate-limiting-rules/parameters/#with-the-following-behavior)선택된 기간 동안 구성된 작업을 적용하는 대신. throttle 요청에 따라**다음 행동으로**제품정보*최대 구성 비율을 통해 스로틀 요청*.

  15. 제품정보**규칙 추가**.

  16. 추가 속도 제한 규칙을 필요에 따라 만들고, 다음 선택**이름 \***&#xADDC;칙을 만들려면.
</Steps>

## 2. 규칙을 제한하는 사용자 정의 속도 배포

엔터프라이즈 플랜에 한 개 이상의 영역에 대한 사용자 정의 속도 제한 규칙을 배치하려면:

<Steps>
  1. Cloudflare 대시보드에서**사이트맵**사이트 맵

     <DashButton url="/?to=/:account/application-security/waf" />

  2. 오시는 길**비율 제한 규칙**탭.

  3. 이름 \***사용자 정의 속도 제한 규칙**배포하려는 규칙을 제한하는 속도 옆에, 선택**계정 만들기**.

  4. 규칙 배포 페이지에서 규칙을 배치하는 규칙에 대한 설명 이름을 입력**실행 이름**.

  5. 이름 \***실행 범위**, 배포할 룰렛 제한 비율의 범위를 검토합니다. 필요한 경우, 선택**연락처**현재 규칙의 범위를 결정하는 표현을 구성합니다.

     :::카트로션
     규칙을 제한하는 사용자 정의 비율을 배포하는 것은 기업 계획에 영역의 들어오는 트래픽에만 적용됩니다. Expression Builder는 이 필터를 자동으로 포함합니다. Expression Editor를 사용하여 사용자 정의 표현을 정의하면 다음을 포함해야합니다.`AND zone.level eq "ENT"`당신의 표현에서 규칙은 엔터프라이즈 플랜의 영역에만 적용됩니다.
     주요 특징

  6. 규칙을 즉시 배포하려면, 선택**계정 만들기**. 규칙을 배포 할 준비가 없다면, 선택**Draft로 저장**.
</Steps>

더 보기**규칙을 제한하는 사용자 정의 속도 배포**목록은 각 배치 된 사용자 정의 속도 제한 규칙에 대한 규칙을 보여줍니다.

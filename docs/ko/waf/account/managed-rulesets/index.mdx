## 계정 수준 배치

계정 수준에서 각각 배포할 수 있습니다.[WAF 관리 규정](/waf/managed-rules/#available-managed-rulesets)한 번 이상. 이것은 당신이 당신의 계정에 있는 기업 지역을 위한 들어오는 교통의 다른 subsets에 다른 윤곽을 가진 동일한 관리한 통치자를 적용할 수 있다는 것을 의미합니다.

예를 들어, 배포할 수 있습니다.[Cloudflare OWASP 핵심 통치자](/waf/managed-rules/reference/owasp-core-ruleset/)다른 paranoia 수준과 다른 행동을 가진 다수 시간 (*관리 도전*PL3 및*로그인*PL4의 동작.

<Details header="예제: 두 가지 다른 구성을 가진 OWASP 배포">
  다음 예제를 배치[Cloudflare OWASP 핵심 통치자](/waf/managed-rules/reference/owasp-core-ruleset/)다음 실행 규칙을 통해 계정 수준에서 여러 번:

  - 첫 번째 실행 규칙 : 파라노아 수준 3 (PL3)까지 OWASP 규칙을 활성화하고 행동을 설정*관리 도전*.
  - 두 번째 규칙을 실행 : PL4까지 OWASP 규칙을 활성화하고 행동을 설정*로그인*.

  이 구성은 PL3 규칙을 활성화하여 추가 보호를 제공합니다, 그러나 요청을 차단하지 않고, 더 높은 파라노아 수준은 거짓 긍정적으로 더 많은 장점입니다.

  두 번째 규칙은 PL4 규칙에 대한 모든 경기를 기록합니다. 규칙의 가장 엄격한 규칙은 라이브 트래픽에 영향을 미치지 않습니다. 이 구성을 사용하여 트래픽이 PL4 규칙에 영향을 줄 수 있습니다.

  <Tabs syncKey="dashPlusAPI">
    <TabItem label="대시보드">
      1. 다음으로 Cloudflare OWASP Core Ruleset 배포[대시보드 지침](/waf/account/managed-rulesets/deploy-dashboard/#deploy-a-managed-ruleset), 이러한 설정을 사용하여 규칙 행동을 사용자 정의:
         - **OWASP Anomaly 점수 위협**: *중간 - 40 이상*
         - **OWASP 파라노아 수준**: *공장 투어*
         - **OWASP 활동**: *관리 도전*

      2. 제품정보**계정 만들기**.

      3. OWASP 규칙에 대한 배포 절차를 반복, 하지만 다음과 같은 규칙 구성:
         - **OWASP Anomaly 점수 위협**: *중간 - 40 이상*
         - **OWASP 파라노아 수준**: *공장 투어*
         - **OWASP 활동**: *로그인*

      구성을 완료하면,**관련 규칙**목록은 2를 보여줄 것입니다*계정 관리*Cloudflare OWASP Core Ruleset의 규칙.
    </TabItem>

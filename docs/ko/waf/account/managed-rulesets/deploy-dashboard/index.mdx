## 관리 규칙 배포

<Steps>
  1. Cloudflare 대시보드에서**사이트맵**사이트 맵

     <DashButton url="/?to=/:account/application-security/waf" />

  2. 오시는 길**관련 규칙**탭.

     ![예 WAF 관리된 규칙 탭에서 구성.](~/assets/images/waf/account/managed-rulesets-dashboard.png)

  3. 제품정보**계정 만들기** > **Deploy 관리 규칙**.

  4. 배포하려는 관리 규칙에 다음, 선택**자주 묻는 질문**.

  5. 규칙을 배포하는 규칙에 이름을 부여**실행 이름**.

  6. (선택) 수신 요청의 하위 설정에 대한 관리 규칙을 실행하려면, 선택**연락처**·[본문 바로가기](/ruleset-engine/rules-language/expressions/edit-expressions/)관리 규칙을 배치하는 현재의 규칙의 범위를 결정합니다.

     :::카트로션
     배포 규칙은 계정의 엔터프라이즈 도메인의 수신 트래픽에만 적용됩니다. Expression Builder는 이 필터를 자동으로 포함합니다. Expression Editor를 사용하여 사용자 정의 표현을 정의하면 사용자 정의 조건을 둘러싸고 표현을 끝낼 수 있습니다.`and cf.zone.plan eq "ENT"`그래서 규칙은 엔터프라이즈 계획에 도메인에만 적용됩니다.
     주요 특징

  7. (선택) 다음과 같은 방법으로 관리 된 규칙의 행동을 사용자 정의 할 수 있습니다 :
     - [전체 규칙 구성](#configure-field-values-for-all-the-rules)(모든 규칙을 준수)
     - [특정 태그와 여러 규칙 또는 규칙을 구성](#configure-rules-in-bulk-in-a-managed-ruleset)
     - [단일 규칙 구성](#configure-a-single-rule-in-a-managed-ruleset)

  8. 관리 규칙을 즉시 배포하려면, 선택**계정 만들기**. 배포할 준비가 되지 않은 경우, 선택**Draft로 저장**.
</Steps>

더 보기**관련 규칙**목록이 표시됩니다.*계정 관리*배포된 관리 규칙에 대한 규칙.

## 관리 규칙 구성

한 개 이상의 규칙에 대한 특정 필드 값을 정의하는 관리 규칙을 구성 (예를 들어, Cloudflare에 의해 구성 된 액션과 다른 규칙을 구성). 특정 규칙을 해제 할 수 있습니다.

하나 이상의 규칙을 건너 뛰기 - 또는 WAF 관리 규칙 - 특정 수신 요청에 대한,[예외 추가](/waf/managed-rules/waf-exceptions/). 예외, 또한 건너뛰기 규칙이라고 부르는, 것과 같이 보입니다*팟캐스트*규칙에**관련 규칙**이름 \*

:::참조

일부 관리 된 규칙은 Cloudflare 계획에 따라 사용자 정의 구성을 허용 할 수 없습니다.
주요 특징

### 모든 규칙의 필드 값 구성

전체 관리 규칙을 구성하려면:

<Steps>
  1. Cloudflare 대시보드에서**사이트맵**사이트 맵

     <DashButton url="/?to=/:account/application-security/waf" />

  2. 오시는 길**관련 규칙**탭.

  3. 규칙 설명 선택*계정 관리*구성하려면 관리되는 규칙을 배포합니다. 대안으로, 3개의 점을 선정하십시오 >**제품정보**.

     아직 관리 된 규칙을 배포하지 않은 경우 다음을 수행하십시오.

     1. 제품정보**계정 만들기** > **Deploy 관리 규칙**.
     2. 배포 및 구성하려는 관리 규칙에 다음, 선택**자주 묻는 질문**.

  4. 규칙 설정 섹션에서 드롭다운 목록에서 사용 가능한 값에서 하나 이상의 규칙 필드를 설정합니다. 정확한 옵션은 구성하는 관리 규칙에 따라 다릅니다.

     예를 들어, 규칙의 모든 규칙에 대해 수행하기위한 조치를 선택하십시오.**Ruleset 작업**드롭다운 목록.

     ![설정 배포 페이지 표시 가능한 옵션을 override 모든 규칙에 규칙. 표시된 관리 규칙에서 당신은 규칙 작업을 삭제할 수 있습니다.](~/assets/images/waf/account/waf-configure-ruleset-account.png)

  5. 배포 된 관리 규칙을 편집하는 경우, 선택**제품 정보**. 아직 관리된 규칙을 배포하지 않은 경우, 선택**계정 만들기**규칙을 즉시 배포하거나**Draft로 저장**나중에 배포 설정을 저장합니다.
</Steps>

계정 수준에서 사용자 정의 규칙은 유료 애드온과 엔터프라이즈 플랜을 요구합니다.

계정 또는 영역 수준에서 사용자 정의 규칙을 만들 수 있습니다. 그러나 Cloudflare 대시보드는 현재 영역 수준에서 사용자 정의 규칙과 함께 작동하지 않습니다. Cloudflare API를 사용하여 이러한 규칙을 구성하거나 배포해야 합니다.

:::

## 사용자 정의 규칙 작성 및 배포

계정 수준에서 사용자 정의 규칙을 만들고 배포하려면:

<Steps>
  1. Cloudflare 대시보드에서**사이트맵**사이트 맵

     <DashButton url="/?to=/:account/application-security/waf" />

  2. 오시는 길**주문 규칙**탭.

     ![Cloudflare 대시보드의 맞춤 규칙 페이지](~/assets/images/waf/account/custom-rulesets-dashboard.png)

  3. 새로운 빈 규칙을 만들려면, 선택**규칙 만들기**. 기존 규칙을 복제하려면 다음 세 가지 점을 선택하십시오 >**기타 제품**.

  4. 표시된 페이지에서, 이름을 입력하고 (선택) 사용자 정의 규칙에 대한 설명.

  5. 이름 \***관련 상품**, 사용자 정의 규칙이 실행 될 때 정의.

     - 제품정보**모든 수신 요청**엔터프라이즈 플랜의 모든 영역에 대한 모든 수신 요청에 대한 사용자 정의 규칙을 적용하십시오.
     - 제품정보**사용자 정의 필터 표현**사용자 정의 규칙을 실행할 때 정의 표현을 정의합니다. 사용 방법**제품정보**드롭다운 목록은 HTTP 속성을 선택합니다. 각 요청에 대해 선택한 속성의 값**제품정보**지정한 값에 비해**제품정보**선택된 연산자를 사용하여**회사연혁**. 대안으로, 선택**본문 바로가기**표현을 정의하기 위해[Expression 편집기](/ruleset-engine/rules-language/expressions/edit-expressions/#expression-editor).

     :::카트로션
     계정 수준에서 배포되는 사용자 정의 규칙은 엔터프라이즈 도메인의 수신 트래픽에만 적용됩니다. Expression Builder는 이 필터를 자동으로 포함합니다. Expression Editor를 사용하여 규칙에 대한 사용자 정의 표현을 정의하면 사용자 정의 조건을 둘러싸고 표현을 종료해야합니다.`and cf.zone.plan eq "ENT"`그래서 규칙은 엔터프라이즈 계획에 도메인에만 적용됩니다.
     주요 특징

  6. 새로운 규칙을 만들려면, 선택**규칙 추가**.

  7. 규칙에 대한 설명 이름 입력**규칙 이름**.

  8. 이름 \***수신 요청 일치**, 사용**제품정보**드롭다운 목록은 HTTP 속성을 선택합니다. 각 요청에 대해 선택한 속성의 값**제품정보**지정한 값에 비해**제품정보**선택된 연산자를 사용하여**회사연혁**. 대안으로, 선택**본문 바로가기**표현을 정의하기 위해[Expression 편집기](/ruleset-engine/rules-language/expressions/edit-expressions/#expression-editor).

  9. 규칙을 선택합니다.**자주 묻는 질문**드롭다운 목록. 예를 들어, 선택*제품정보*Cloudflare가 지정된 조건과 일치하지 않는 요청을 거부합니다.

  10. (선택) 선택한 경우*제품정보*활동, 당신은 할 수 있습니다[사용자 지정 응답 구성](#configure-a-custom-response-for-blocked-requests).

  11. 제품정보**계정 만들기**.

  12. 사용자 정의 규칙에 다른 규칙을 추가, 필요한 경우. 사용자 정의 규칙에 기존 규칙을 복제 할 수 있습니다.

  13. 제품정보**이름 \***.
</Steps>

## 사용자 정의 규칙 편집

<Steps>
  1. Cloudflare 대시보드에서**사이트맵**사이트 맵

     <DashButton url="/?to=/:account/application-security/waf" />

  2. 오시는 길**주문 규칙**탭.

     ![Cloudflare 대시보드의 맞춤 규칙 페이지](~/assets/images/waf/account/custom-rulesets-dashboard.png)

  3. 사용자 정의 규칙을 편집하려면 다음 세 가지 점을 선택하십시오 >**제품정보**.

  4. 선택하여 규칙에 대한 원하는 변경 사항**제품정보**변경하려는 항목 옆에.

  5. 당신이 할 때, 선택**규칙 목록으로 돌아가기**.
</Steps>

주요 특징

계정 수준에서 사용자 정의 규칙을 배포하려면:

1. 한 개 이상의 규칙을 가진 사용자 정의 규칙을 만듭니다. 대신, 기존의 사용자 정의 규칙을 식별하여 배포하려는[계정 규칙](/api/resources/rulesets/methods/list/)API 가동.
2. 정의 규칙을 배포하여 실행됩니다. 사용자 정의 규칙을 배포하려면 규칙을 만듭니다.`execute`활동.

사용 방법[규칙 세트 API](/ruleset-engine/rulesets-api/)API를 사용하여 사용자 정의 규칙과 함께 작동합니다.

Terraform을 사용하는 경우, 참조[WAF Terraform을 사용하여 사용자 정의 규칙 구성](/terraform/additional-configurations/waf-custom-rules/#create-and-deploy-a-custom-ruleset).

## 회사연혁

사용자 정의 규칙을 배포하려면 이러한 일반적인 단계를 따르십시오.

1. 사용자 정의 규칙 만들기`http_request_firewall_custom`하나 이상의 규칙을 가진 단계.
2. 규칙을 배포[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)이름 \*`http_request_firewall_custom`단계.

### 1. 사용자 정의 규칙 만들기

다음 예제는 계정 수준에서 단일 규칙으로 사용자 정의 규칙을 만듭니다.`rules`배열.

<APIRequest
  path="/accounts/{account_id}/rulesets"
  method="POST"
  json={{
  	description: "",
  	kind: "custom",
  	name: "My custom ruleset",
  	rules: [
  		{
  			description: "Challenge web traffic (not /api)",
  			expression: 'not starts_with(http.request.uri.path, "/api/")',
  			action: "managed_challenge",
  		},
  	],
  	phase: "http_request_firewall_custom",
  }}
  roles="account"
/>

다음 단계에 대한 응답에 규칙 ID를 저장합니다.

### 2. 사용자 정의 규칙 배포

사용자 정의 규칙을 배포하려면 규칙을 추가하십시오.`"action": "execute"`이름 \*`http_request_firewall_custom`단계 항목 포인트 규칙.

1. <Render file="rulesets/api-account/step1-get-entrypoint" product="waf" params={{ phaseName: "http_request_firewall_custom" }} />

   <APIRequest
     path="/accounts/{account_id}/rulesets/phases/{ruleset_phase}/entrypoint"
     method="GET"
     parameters={{
     	ruleset_phase: "http_request_firewall_custom",
     }}
     roles="account"
   />

   ```json output {4}
   {
   	"result": {
   		"description": "Account-level phase entry point",
   		"id": "<RULESET_ID>",
   		"kind": "root",
   		"last_updated": "2024-03-16T15:40:08.202335Z",
   		"name": "root",
   		"phase": "http_request_firewall_custom",
   		"rules": [
   			// ...
   		],
   		"version": "9"
   	},
   	"success": true,
   	"errors": [],
   	"messages": []
   }
   ```

2. <Render
     file="rulesets/api-account/step2-create-rule"
     product="waf"
     params={{
     	deploymentItem: "custom ruleset",
     }}
   />

   다음 요청은 ID로 사용자 정의 규칙을 실행하는 규칙을 만듭니다.`<CUSTOM_RULESET_ID>`계정의 모든 엔터프라이즈 영역에 대한:

   <APIRequest
     path="/accounts/{account_id}/rulesets/{ruleset_id}/rules"
     method="POST"
     json={{
     	description: "Execute custom ruleset",
     	expression: '(cf.zone.plan eq "ENT")',
     	action: "execute",
     	action_parameters: {
     		id: "<CUSTOM_RULESET_ID>",
     	},
     	enabled: true,
     }}
     roles="account"
   />

   :::카트로션
   계정 수준에서 엔터프라이즈 계획에 영역의 들어오는 트래픽에 맞춤 규칙 만 적용 할 수 있습니다. 이 요구 사항을 시행하려면 다음을 포함해야합니다.`cf.zone.plan eq "ENT"`본문내용 바로가기`execute`사용자 정의 규칙을 배포하는 규칙.
   주요 특징

3. <Render
     file="rulesets/api-account/step3-create-ruleset"
     product="waf"
     params={{
     	deploymentItem: "custom ruleset",
     	scope: "all incoming requests of Enterprise zones in your account",
     }}
   />

   <APIRequest
     path="/accounts/{account_id}/rulesets"
     method="POST"
     json={{
     	description: "",
     	kind: "root",
     	name: "Account-level phase entry point",
     	rules: [
     		{
     			action: "execute",
     			expression: '(cf.zone.plan eq "ENT")',
     			action_parameters: {
     				id: "<CUSTOM_RULESET_ID>",
     			},
     		},
     	],
     	phase: "http_request_firewall_custom",
     }}
     roles="account"
   />

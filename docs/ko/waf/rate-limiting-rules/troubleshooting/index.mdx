## 일부 Workers 잠수함은 별도의 요청으로 계산됩니다.

Cloudflare는 Workers가 별도의 요청으로 동일한 영역에서 Workers subrequest를 계산할 수 있으며 예상보다 빨리 트리거 할 수 있는 비율 제한 규칙을 일으킬 수 있습니다. 이 행동은 제한 규칙을 설정할 때 발생합니다.[**또한 캐시된 자산에 제한하는 비율 적용**](/waf/rate-limiting-rules/parameters/#also-apply-rate-limiting-to-cached-assets)false로 설정한다.

이 행동을 방지하기 위해 Workers subrequests가 동일한 영역에서 레이트 제한 규칙을 사용하여[`cf.worker.upstream_zone`](/ruleset-engine/rules-language/fields/reference/cf.worker.upstream_zone/)이름 \* 예를 들어, 다음 하위 압축을 추가 할 수 있습니다.[비율 제한 규칙 표](/waf/rate-limiting-rules/parameters/#when-incoming-requests-match):

```txt
and (cf.worker.upstream_zone == "" or cf.worker.upstream_zone != "<YOUR_ZONE>")
```

첫 번째 조건 (비어 있는 문자열에 대한 테스트)는 직접 방문자 요청과 일치합니다. 두 번째 조건은 영역에서 시작하지 않는 하위 규칙과 동일한 영역에서 하위 규칙을 제외하고 효과적으로 일치합니다.

더 보기**견적문의**탭에서[보안 Analytics](/waf/analytics/security-analytics/)선택된 필터와 시간을 일치하는 트래픽의 요청 속도에 데이터를 표시합니다. 이 탭을 사용하여 적용된 필터와 일치하는 수신 트래픽에 가장 적합한 비율 제한을 결정합니다.

:::참조
더 보기**견적문의**탭은 Enterprise 고객에게만 사용할 수 있습니다.
주요 특징

## 사용자 인터페이스 개요

더 보기**견적문의**탭은 영역 수준에서 사용할 수 있습니다.**회사 소개**사이트 맵

![Security Analytics의 요청 속도 분석 탭의 스크린 샷](~/assets/images/waf/rate-limit-analytics.png)

주요 차트는 선택된 시간 간격 동안 관찰된 최고 50의 유일한 클라이언트를 위한 요구 비율의 배급을 표시합니다 (예를 들면,`1 minute`) 후손 순서에서. 다음과 같은 독특한 요청 속성에 의해 요청 요금을 그룹 할 수 있습니다 :

- **IP 주소**
- [**JA3 지문**](/bots/additional-configurations/ja3-ja4-fingerprint/)(봇 관리로 고객에게만 제공)
- **IP 및 JA3**(봇 관리로 고객에게만 제공)
- [**JA4 지문**](/bots/additional-configurations/ja3-ja4-fingerprint/)(봇 관리로 고객에게만 제공)
- **IP 및 JA4**(봇 관리로 고객에게만 제공)

:::참조

Cloudflare가 수신 트래픽의 요청 속도를 계산하는 방법에 대한 자세한 내용은 참조[요금 계산](/waf/rate-limiting-rules/request-rate/).
:::

***

## 적당한 비율 한계를 결정하십시오

### 1. 범위 정의

<Steps>
  1. Cloudflare 대시보드에서**회사 소개**사이트 맵

     <DashButton url="/?to=/:account/:zone/security/analytics" />

  2. 내 계정**교통 분석**탭, 특정 시간 기간을 선택하십시오:
     - 정기적인 비율 배포를 보면, 비말 트래픽을 가진 기간을 지정합니다.
     - 방문자/봇의 비율을 분석하려면 공격에 대응하는 기간을 선택하십시오.

  3. 필터를 적용하여 해당 애플리케이션의 특정 상황을 분석할 수 있습니다.`/login`URL 경로).

  4. (선택 사항) 비 자동화 / 휴먼 트래픽에 초점을 맞추려면 사이드 바에 봇 점수 빠른 필터를 사용합니다.
</Steps>

### 2. 비율을 찾기

<Steps>
  1. 전환하기**견적문의**탭.

  2. 요청 속성 (JA3, IP, IP 및 JA3, 또는 JA4) 및 기간 (1 분, 5 분, 또는 1 시간) 귀하의 비율 제한 규칙. 선택한 요청 속성은 다음과 같이 사용됩니다.[비율 제한 규칙 특성](/waf/rate-limiting-rules/parameters/#with-the-same-characteristics).

  3. 차트의 슬라이더를 사용하여 속도 제한을 정의하는 수평선을 이동합니다. 슬라이더를 이동하고 아래로 이동하면서 표시된 트래픽에서 선택한 제한 규칙을 정의하는 비율의 영향을 확인합니다.

     ![요청 속도 분석 차트의 속도 제한을 조정하여 최근 트래픽에 영향을 확인](/images/waf/rate-limit-adjust.gif)
</Steps>

:::참조

당신의 조정 도중 뒤에 오는 질문은 당신의 분석에 당신을 도울 수 있습니다:

- "많은 클라이언트가 규칙과 비율이 제한되었습니까?"
- "내가 위 평균 사용자의 긴 꼬리를 가진 학대를 시각적으로 식별 할 수 있습니까?"

:::

### 3. 당신의 비율을 검증하십시오

<Steps>
  1. 이전 섹션에 설명 된 비율 선택 프로세스를 반복하지만 공격이나 트래픽 피크가 있는지 알고있는 트래픽의 일부를 선택. 선택한 비율은 공격 중 아웃 런 트래픽을 차단하고 정기적인 기간 동안 트래픽을 허용해야합니다.

  2. (선택 사항) 확인[샘플 로그](/waf/analytics/security-analytics/#sampled-logs)지문과 필터를 확인하기 위해 선택했습니다.
</Steps>

### 4. 제한 규칙을 창조하십시오

<Steps>
  1. 내 계정**견적문의**탭, 선택**생성 속도 제한 규칙**오시는 길[비율 제한 생성 페이지](/waf/rate-limiting-rules/create-zone-dashboard/)필터, 특성 및 선택된 비율 제한으로 사전 판매됩니다.

  2. 규칙을 선택합니다. 귀하의 필요에 따라, 선택된 임계값을 초과하는 로그, 도전, 또는 블록 요청을 설정할 수 있습니다.

     먼저 규칙을 배치하는 것이 좋습니다.*로그인*임계값을 검증하고, 규칙 행동에 대해 확신 할 때 블록 또는 도전 수신 요청을 변경합니다.

  3. 제한 규칙을 저장하고 배포하려면, 선택**계정 만들기**. 규칙을 배포 할 준비가 없다면, 선택**Draft로 저장**.
</Steps>

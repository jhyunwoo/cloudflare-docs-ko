<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    <Steps>
      1. Cloudflare 대시보드에서**보안 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/security-rules" />

      2. 새로운 빈 규칙을 만들기 위해, 선택**규칙 만들기** > **비율 제한 규칙**. 기존 규칙을 복제하려면 다음 세 가지 점을 선택하십시오 >**기타 제품**.

      3. <a id="rule-form" />

         규칙에 대한 설명 이름 입력**규칙 이름**.

         ![Cloudflare 대시보드의 규칙 페이지를 제한하는 창조 비율](~/assets/images/waf/custom-rules/rate-limiting-create.png)

      4. 내 계정**제품정보**드롭다운, HTTP 속성을 선택합니다. 각 요청에 대해 선택한 속성의 값**제품정보**지정한 값에 비해**제품정보**선택된 연산자를 사용하여**회사연혁**.

      5. (선택) 밑에**캐시 상태**, 비활성화**또한 캐시된 자산에 제한하는 비율 적용**비율을 결정할 때 기원에 도달하는 요청만 고려하십시오.

      6. 이름 \***동일한 특성으로**, 제한 목적을 위한 요청 카운터를 정의할 것이다 1개 이상 특성을 추가하십시오. 각 가치 조합은 그것의 자신의 카운터가 비율을 결정할 것입니다. 더 알아보기[Cloudflare가 요청 비율을 결정하는 방법](/waf/rate-limiting-rules/request-rate/)더 많은 정보.

      7. (선택) 비율 카운터를 증가시키는 조건을 지정하는 표현을 정의하려면, 활성화**사용자 정의 계산 표현**그리고 표현을 설정한다. 기본적으로, 카운트 표현은 규칙 표현과 동일합니다. 계산 표현은 포함될 수 있습니다[응답 분야](/ruleset-engine/rules-language/fields/reference/?field-category=Response).

      8. 이름 \***비율 초과시**, 최대 요청 수와 시간을 정의하여 비율을 결정할 때 고려하십시오.

      9. 이름 \***다음 작업을 수행**, 규칙 작업을 선택**자주 묻는 질문**드롭다운 목록. 예를 들어, 선택*제품정보*Cloudflare는 요청 제한이 도달되면 지정된 조건에서 요청을 거부합니다.

      10. (선택) 선택한 경우*제품정보*활동, 당신은 할 수 있습니다[사용자 지정 응답 구성](#configure-a-custom-response-for-blocked-requests)지정된 비율 제한을 초과하는 요청을 위해.

      11. 소송 시간 선택**이름 \***&#xB4DC;롭다운. Cloudflare가 한 번의 비율이 도달되면 선택 동작을 적용합니다.

          유료 애드온을 가진 기업 고객[throttle 요청](/waf/rate-limiting-rules/parameters/#with-the-following-behavior)선택된 기간 동안 구성된 작업을 적용하는 대신. throttle 요청에 따라**다음 행동으로**제품정보*최대 구성 비율을 통해 스로틀 요청*.

      12. 규칙을 저장하고 배포하려면, 선택**계정 만들기**. 규칙을 배포 할 준비가 없다면, 선택**Draft로 저장**.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com/), 귀하의 계정과 영역을 선택.

      2. 오시는 길**보안 보안** > **사이트맵** > **비율 제한 규칙**.

      3. 새로운 빈 규칙을 만들기 위해, 선택**규칙 만들기**. 기존 규칙을 복제하려면 다음 세 가지 점을 선택하십시오 >**기타 제품**.

      4. 규칙에 대한 설명 이름 입력**규칙 이름**.

         ![Cloudflare 대시보드의 규칙 페이지를 제한하는 창조 비율](~/assets/images/waf/custom-rules/rate-limiting-create.png)

      5. 내 계정**제품정보**드롭다운, HTTP 속성을 선택합니다. 각 요청에 대해 선택한 속성의 값**제품정보**지정한 값에 비해**제품정보**선택된 연산자를 사용하여**회사연혁**.

      6. (선택) 밑에**캐시 상태**, 비활성화**또한 캐시된 자산에 제한하는 비율 적용**비율을 결정할 때 기원에 도달하는 요청만 고려하십시오.

      7. 이름 \***동일한 특성으로**, 1개 이상 추가[주요 특징](/waf/rate-limiting-rules/parameters/#with-the-same-characteristics)해당 이용 후기에 달린 코멘트가 없습니다. 각 가치 조합은 그것의 자신의 카운터가 비율을 결정할 것입니다. 더 많은 정보를 원하시면, 참조[요금 계산](/waf/rate-limiting-rules/request-rate/).

      8. (선택) 비율 카운터를 증가시키는 조건을 지정하는 표현을 정의하려면, 활성화**사용자 정의 계산 표현**그리고 표현을 설정한다. 기본적으로, 카운트 표현은 규칙 표현과 동일합니다. 계산 표현은 포함될 수 있습니다[응답 분야](/ruleset-engine/rules-language/fields/reference/?field-category=Response).

      9. (선택) 안으로**비율 초과시**, 사이에서 선택:

         - **자주 묻는 질문**: 주어진 기간 동안 들어오는 요청 수를 기준으로 한 비율.
         - **회사연혁**: 정해진 기간 동안의 처리 요청의 복잡성 또는 비용에 근거를 둔 비율.

         :::참조
         [복잡한 비율 제한](/waf/rate-limiting-rules/request-rate/#complexity-based-rate-limiting)Advanced Rate Limiting으로 Enterprise 고객에게만 사용할 수 있습니다. 다른 사용자는 항상 요청 기반 비율 제한을 사용합니다.
         주요 특징

      10. 선택한 경우**자주 묻는 질문**이전 단계에서 (또는 제한 방법을 선택 할 수없는 경우), 값을 입력 :

          - **제품정보**: 최대 요청 수.
          - **기간 :**: 비율을 결정할 때 고려하는 시간 기간.

          선택한 경우**회사연혁**, 값을 입력:

          - **기간별 점수**: 기간 당 최대 점수. 이 값이 초과되면 규칙 동작이 실행됩니다.
          - **기간 :**: 비율을 결정할 때 고려하는 시간 기간.
          - **응답 헤더 이름**: 응답의 HTTP 헤더의 이름, 원래 서버로 설정, 현재의 요청에 대한 점수.

      11. 이름 \***다음 작업을 수행**, 규칙 작업을 선택**자주 묻는 질문**드롭다운 목록. 예를 들어, 선택*제품정보*Cloudflare는 요청 제한이 도달되면 지정된 조건에서 요청을 거부합니다.

      12. (선택) 선택한 경우*제품정보*활동, 당신은 할 수 있습니다[사용자 지정 응답 구성](#configure-a-custom-response-for-blocked-requests)지정된 비율 제한을 초과하는 요청을 위해.

      13. 소송 시간 선택**이름 \***&#xB4DC;롭다운. Cloudflare가 한 번의 비율이 도달되면 선택 동작을 적용합니다.

          유료 애드온을 가진 기업 고객[throttle 요청](/waf/rate-limiting-rules/parameters/#with-the-following-behavior)선택된 기간 동안 구성된 작업을 적용하는 대신. throttle 요청에 따라**다음 행동으로**제품정보*최대 구성 비율을 통해 스로틀 요청*.

## 일반 업데이트

### 2024-12-18

**향상된 VPN 관리 목록**

고객은 이제 VPN IP를 시작으로 확인된 수신 트래픽을 효과적으로 관리할 수 있습니다. 준수 제한을 가진 고객은 이제 지역 법률 및 규정 준수를 보장 할 수 있습니다. CDN 제한을 가진 고객은 향상된 VPN Managed List를 사용하여 지리적 제한을 우회하는 사용자로부터 무단 액세스를 방지할 수 있습니다. 새로운 VPN 관리된 목록 개선으로, 고객은 원치 않는 악의적인 교통에 노출을 감소시키기 위하여 전반적인 안전 자세를 개량할 수 있습니다.

### 2024-12-10

**IP 목록의 목록 항목의 주문 변경 (API 및 Terraform 사용자 용)**

API 구현의 변화로 인해 API 또는 Terraform을 통해 얻은 IP 목록의 목록 항목의 주문은 Terraform 상태의 변화를 감지하기 위해 Terraform을 일으킬 수 있습니다. 이 문제를 해결하려면 Terraform state를 재 동기화하거나 Terraform Cloudflare 공급자의 버전을 업그레이드하십시오.[버전 4.44.0](https://github.com/cloudflare/terraform-provider-cloudflare/releases/tag/v4.44.0)또는 나중에.

### 2024-11-14

**보안 이벤트 pagination**

보안 이벤트에서 pagination에 문제가 수정되었습니다. 일부 페이지가 누락 된 데이터. 또한 이벤트 로그에서 총 카운트를 제거하면 샘플 로그가됩니다.

### 2024-11-04

**Security Analytics 및 Security Events의 새로운 테이블**

Security Analytics 및 Security Events의 새로운 응답 테이블에 전환했습니다.

### 2024-08-29

**고정 가끔 공격 점수 mismatches**

글로벌 사이 점수 mismatches의 문제 해결[WAF 공격 점수](/waf/detections/attack-score/)그리고 subscores. 특정 경우에, subscores는 예상보다 더 높았지만, 글로벌 공격 점수는 예상보다 낮았습니다 (attack), false 긍정적으로 이어졌습니다.

### 2024-05-23

**향상된 탐지 기능**

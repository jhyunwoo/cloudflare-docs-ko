## 2025-10-23

**WAF 릴리스 - 2025-10-23 - 긴급**

이번 주 강조는 CVE-2025-54236과 연계된 Adobe Commerce 및 Magento Open Source의 취약점 향상을 위한 탐지 서명 개선을 강조합니다.

**키 찾기**

## 2025-10-17

**WAF 관리 규정 발표**

이번 주에는 Cloudflare Managed Rulesets에 걸쳐 여러 가지 새로운 검출을 도입했으며 SSRF, SQLi, SSTI, 역 쉘 시도 및 프로토 타입 오염과 같은 고 영향도 클래스에 대한 적용을 확장했습니다. 이 규칙은 웹 애플리케이션에서 misconfiguration 또는 unvalidated 입력을 악용하는 공격자 통제 된 페이로드에 대한 보호를 향상시킵니다.

**키 찾기**

여러 악용 범주에 추가 된 새로운 탐지 :

SSRF (Server-Side Request Forgery) - 로컬 및 클라우드 메타 데이터 남용 패턴 (Beta)를 대상으로 새로운 규칙.

SQL Injection (SQLi) - 일반적인 패턴, 수면 / 시간 기반 주입 및 헤더 및 URI에 걸쳐 문자열 / 낭비 기능 악용 규칙.

SSTI (Server-Side Template Injection) - URI, 헤더 및 바디 필드에서 소개 된 arithmetic 기반 조사 탐지.

쉘 및 XXE 페이로드 - 명령 실행 및 XML 외부 인문자를 위한 향상된 헤리티지.

Prototype Pollution - 객체 프로토 타입 중독에 사용되는 일반적인 JSON 페이로드 구조를 식별하는 새로운 베타 규칙.

PHP 포장 및 HTTP 매개 변수 오염 검출 - 경로 추적 및 멀티 매개 변수 조작 시도를 잡기 위해.

Anomaly Header Checks - 헤더 이름에서 CRLF 주입 시도 검출.

**제품정보**

이 업데이트는 SSRF + RCE 또는 SQLi + SSTI 공격을 혼합하는 멀티 벤더 페이로드를 감지하는 데 도움이, 특히 노출 된 메타 데이터 엔드 포인트 또는 안전한 템플릿 렌더링과 클라우드 호스팅 응용 프로그램에서.

Prototype Pollution 및 HTTP 매개 변수 오염 규칙은 JavaScript 공급 체인 악용 패턴을 점점 실제 사건에서 볼 수 있습니다.

## 2025-10-06

**WAF 출시 - 2025-10-06**

이번 주에는 긴급 오라클 E-Business Suite RCE 규칙이 우선 순위가 높고 충격적인 착취를 막기 위해 배포되었습니다. 또한 주소는 높은 신뢰성 Chaos Mesh Controller 명령어 인젝션 flaws로, HTTP Parameter Pollution(HPP)을 허용하는 형식 데이터 멀티 파트 경계 문제와 같은 클러스터 RCE 및 잠재적 클러스터 손상을 가능하게 합니다. 두 개의 새로운 일반 SQLi 검출은 인라인 구성 obfuscation 및 정보 공개 기술을 붙잡기 위해 추가되었습니다.

**키 찾기**

## 2025-07-21

**WAF 릴리스 - 2025-07-21 - 긴급**

이번 주 업데이트는 Microsoft SharePoint Server에 영향을 미치는 몇 가지 높은 충격 취약점을 강조합니다. 이 결함은 안전한 deserialization를 포함하는, 네트워크에 unauthenticated 먼 부호 실행을 허용하고, 협력과 문서 관리를 위한 SharePoint에 의존하는 기업 환경에 중요한 위협을 posing.

**키 찾기**

- Microsoft SharePoint Server (CVE-2025-53770) : 신뢰할 수없는 데이터의 탈중앙화와 관련된 중요한 취약점은 네트워크에서 무해한 원격 코드 실행을 가능하게합니다. 이 결함은 사용자 상호 작용 없이 취약한 SharePoint 서버에 arbitrary 코드를 실행할 수 있습니다.
- Microsoft SharePoint Server (CVE-2025-53771) : 무해한 공격자에 의해 악화 될 수있는 밀접한 관련 탈선 문제, 잠재적으로 전체 시스템 타협에 선두. 취약점은 기업의 협업 플랫폼에서 insecure serialization logic의 주위에 계속 위험을 강조합니다.

**제품정보**

함께 이러한 취약점은 Microsoft SharePoint Server 배포의 보안 자세를 크게 약화했습니다. 인증없이 원격 코드 실행을 활성화함으로써 공격자의 문이 지속 가능한 액세스를 얻기 위해, 악성 코드를 배포하고, 기업 환경에 따라 나중에 이동.

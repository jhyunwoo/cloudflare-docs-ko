## 2025-07-21

**WAF 출시 - 2025-07-21**

이번 주 업데이트는 Citrix NetScaler Memory Disclosure, FTP 서버 및 네트워크 애플리케이션을 통해 몇 가지 중요한 취약점이 표시됩니다. 몇몇 결함은 unauthenticated 먼 부호 실행 또는 과민한 자료 노출, 기업 안전에 뜻깊은 위험을 posing 가능하게 합니다.

**키 찾기**

- 윙 FTP 서버 (CVE-2025-47812) : 루아 주사 결함을 악용하여 루트 / SYSTEM 수준의 특권을 가진 임의 코드를 실행하는 데 도움이되는 중요한 원격 코드 실행 (RCE) 취약점.
- Infoblox NetMRI (CVE-2025-32813): 공격자가 임의 명령을 실행할 수 있도록 원격 unauthenticated command injection flaw, 잠재적으로 권한 접근을 선도하는.
- Citrix Netscaler ADC (CVE-2025-5777, CVE-2023-4966) : "Citrix Bleed2"라고도 알려진 민감한 정보 공개 취약점은 메모리 및 후속 원격 액세스 세션 납치의 공개를 허용합니다.
- Akamai CloudTest (CVE-2025-49493) : XML 입력을 조작하여 시스템에 로컬 파일을 읽을 수있는 XML 외부 Entity (XXE) 주입.

**제품정보**

이 취약점은 파일 전송 서비스 및 네트워크 관리 기기에서 애플리케이션 전달 컨트롤러에 중요한 엔터프라이즈 인프라에 영향을 미칩니다. 윙 FTP RCE 및 Infoblox 명령 주입 결함은 딥 시스템 손상에 직접 경로를 제공합니다. Citrix "Bleed2"와 Akamai XXE 취약점은 세션 납치 및 민감한 데이터 도난을 가능하게합니다.

## 2025-07-14

**WAF 출시 - 2025-07-14**

이번 주 취약성 분석은 현대 JavaScript 행동과 SQL 패싱 야심성을 활용하는 새로운 웹 애플리케이션 위협을 강조합니다. 공격자는 evade 검출 및 손상 front-end 및 back-end 시스템에 대한 속성 과부하 및 손상된 논리 조작과 같은 기술을 계속합니다.

**키 찾기**

- XSS – Attribute Overloading: 공격자 남용 사용자 지정 또는 비표준 HTML 속성에 대 한 새로운 크로스 사이트 스크립트 기술 DOM에 반환. 이 페이로드 evade 전통적인 위생 논리, 특히 느슨하게 속성 또는 신뢰할 수없는 토큰을 검증하는 프레임 워크에서.
- XSS - onToggle 이벤트 남용 : 더 적은 사용 onToggle 이벤트 (매체에 의해 트리거 됨)`<details>`) UI 요소와 상호 작용할 때 arbitrary JavaScript를 실행할 수 있습니다. 이 벡터는 종종 정적 분석가에 의해 보이며, 겉으로 benign 구성 요소에 내장 될 수 있습니다.

**제품정보**

이 취약점은 사용자가 직면하는 구성 요소와 백엔드 데이터베이스를 모두 대상으로, credential theft, session hijacking, 또는 전체 데이터 exfiltration에 대한 잠재적 인 벡터를 소개합니다. XSS 변형은 기존 필터를 통해 HTML 동작을 내려다 볼 수 있으며, 손상된 SQLi는 공격자가 훔칠 수 있는 프로브 백엔드 로직을 활성화하고, 특히 감지하고 차단하기 어렵습니다.

## 2025-07-07

**Enterprise 계정의 IP 목록 제한 증가**

우리는 크게 한계를 증가[IP 목록](https://developers.cloudflare.com/waf/tools/lists/)엔터프라이즈에서 유연성과 제어를 제공 할 계획:

- **전체 목록**: 10에서 1,000으로 증가했습니다.
- **전체 목록 항목**: 10,000에서 500,000까지 증가

다른 목록 유형에 대한 제한 및 계획은 변경되지 않습니다. 자세한 내용은 참조[자주 묻는 질문](https://developers.cloudflare.com/waf/tools/lists/#availability).

**제품정보**

## 2025-06-16

**WAF 출시 - 2025-06-16**

이번 주 라운드 업은 인기있는 웹 프레임 워크, 플러그인 및 엔터프라이즈 플랫폼에서 여러 가지 중요한 취약점을 강조합니다. 초점은 원격 코드 실행 (RCE), 서버 측 요청 forgery (SSRF) 및 전체 시스템 손상 또는 데이터 exfiltration을 가능하게하는 insecure 파일 업로드 벡터에 있습니다.

**키 찾기**

- Cisco IOS XE (CVE-2025-20188) : 중요한 RCE 취약점은 네트워크 인프라 장치에서 임의 명령을 실행하기 위해 타당한 공격자를 가능하게하고 총 라우터 타협을 위험.
- Axios (CVE-2024-39338) : 서버 측 요청 제어에 영향을 미치는 SSRF 결함, 손상된 사용자 입력으로 잘못 구성 할 때 내부 서비스 요청을 조작 할 수 있습니다.
- vBulletin (CVE-2025-48827, CVE-2025-48828): 두 개의 높은 충격 RCE 결함은 공격자를 원격으로 PHP 코드를 실행하고, 포럼 설치 및 웹 서버를 이해합니다.
- Invision Community (CVE-2025-47916) : 중요한 RCE 취약점은 커뮤니티 플랫폼의 임의 코드를 실행하고 데이터 및 측면 운동 위험을 위협 할 수 있습니다.
- CrushFTP (CVE-2025-32102, CVE-2025-32103) : SSRF 취약점 처리 허용 공격자는 내부 네트워크 검사 및 학대 내부 서비스에 피벗을 수 있습니다.
- Roundcube (CVE-2025-49113) : 이메일 처리를 통해 RCE는 웹 메일 배포를 위해 특별히 위험한 기술 이메일보기에 코드를 실행하는 공격자를 가능하게합니다.
- WooCommerce WordPress 플러그인 (CVE-2025-47577) : 위험한 파일 업로드 취약점은 실행 가능한 페이로드를 업로드하기 위해 unauthenticated 사용자를 허용, 전체 WordPress 사이트 takeover에 선도.
- Cross-Site Scripting (XSS) 탐지 개선: 향상된 탐지 패턴.

**제품정보**

이 취약점 스팬 코어 시스템 — 라우터에서 전자 상거래에 이메일. Cisco IOS XE, Roundcube 및 vBulletin에 있는 RCE는 가득 차있는 체계 타협을 포즈합니다. Axios 및 CrushFTP의 SSRF는 내부 피벗을 지원하지만 WooCommerce의 파일 업로드 버그는 대량 WordPress 활용에 문을 엽니다.

## 2025-06-09

**WAF 출시 - 2025-06-09**

이번 주 업데이트는 CMS 플랫폼, VoIP 시스템 및 엔터프라이즈 애플리케이션을 통해 4 가지 중요한 취약점입니다. 몇몇 결함은 먼 부호 실행 또는 특권 에스컬레이션, 뜻깊은 기업 위험을 posing 가능하게 합니다.

**키 찾기**

- WordPress OttoKit 플러그인 (CVE-2025-27007) : Privilege escalation flaw는 사용자가 계정을 만들거나 높이기 위해 타당한 공격자를 허용하며 WordPress 관리 통제를 준수합니다.
- SAP NetWeaver (CVE-2025-42999) : 원격 코드 실행 취약점은 SAP NetWeaver 시스템의 임의 코드를 실행하고 핵심 ERP 및 비즈니스 작업을 위협 할 수 있습니다.
- Fortinet FortiVoice (CVE-2025-32756) : 버퍼 오류 취약점은 메모리 손상 및 잠재적 인 코드 실행, 직접 엔터프라이즈 VoIP 인프라에 영향을 미칠 수 있습니다.

#### Next.js CVE-2025-29927

WAF (Web Application Firewall) 규칙을 Cloudflare의 모든 사이트에 사용할 수 있도록 만들어졌습니다.[Next.js 인증 바이패스 취약성](https://github.com/advisories/GHSA-f82v-jwr5-mffw) (`CVE-2025-29927`) 3 월 21 일에 발표, 2025.

**이름 \***: 이 규칙은 특정 인증 미들웨어에 대한 사이트에서 차단된 요청으로 기본적으로 활성화되지 않습니다.

- Workers 및 Pages에 Next.js를 사용하는 사이트뿐만 아니라 Cloudflare를 사용하여 Next.js 응용 프로그램을 다른 곳에서 호스팅합니다.
- 이 규칙은 사용할 수있었습니다 (하지만 기본적으로 활성화되지 않음) 우리의 일부로 모든 사이트에[WAF 관리되는 통치자](https://developers.cloudflare.com/waf/managed-rules/reference/cloudflare-managed-ruleset/)Next.js 애플리케이션에서 인증을 우회하려고 하는 블록 요청.
- 취약점은 거의 모든 Next.js 버전에 영향을 미치며 Next.js에서 완전히 패치되었습니다.`14.2.26`·`15.2.4`. Earlier, interim 방출은 완전히 이 취약점을 패치하지 않았다.
- **Next.js의 이전 버전 사용자 (`11.1.4`으로`13.5.6`)는 원래 사용할 수있는 패치가 없습니다**, 그러나이 취약점에 대한 패치와 후속 추가 패치는 Next.js 버전으로 백업되었습니다.`12.3.6`·`13.5.10`3월 24일 월요일 Next.js v11의 사용자는 명시된 운동을 배포하거나 WAF 규칙을 활성화해야합니다.

관리 WAF 규칙은 차단함으로써 이것을 mitigates*기타 제품*사용자 요청`x-middleware-subrequest`Next.js 버전에 관계없이 헤더는 Next.js 14 및 15 업그레이드를 사용하여 Next.js의 패치 된 버전에 추가 mitigation을 사용하여 사용자를 권장합니다.

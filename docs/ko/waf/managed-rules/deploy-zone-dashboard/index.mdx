이 페이지의 지침은 영역의 관리 규칙을 배치하고 구성하기위한 일반적인 지침을 제공합니다.

자세한 내용은 다음 페이지를 참조하십시오.

- [Cloudflare 관리 규칙 설정 배포](/waf/managed-rules/reference/cloudflare-managed-ruleset/#deploy-in-the-dashboard)
- [Cloudflare OWASP Core Ruleset 배포](/waf/managed-rules/reference/owasp-core-ruleset/configure-dashboard/#deploy-in-the-dashboard)
- [Cloudflare 민감한 데이터 탐지 규칙 배포](/waf/managed-rules/reference/sensitive-data-detection/#deploy-in-the-dashboard)

:::가격
계정에서 여러 엔터프라이즈 도메인에 대한 관리 규칙을 배포하려면, 참조[WAF 관리 규정을 대시보드 (account)에 배포합니다.](/waf/account/managed-rulesets/deploy-dashboard/).
:::

## 관리 규칙 배포

지역 관리 규칙을 배포하려면:

<Render file="dash-deploy-managed-ruleset-zone" product="waf" />

배포 구성을 삭제하지 않고 관리 된 규칙을 일시적으로 끄려면 관리 된 규칙을 배치하는 규칙 옆에 toggle을 사용하십시오.

## 관리 규칙 구성

관리 규칙 구성 :

- 규칙에 규칙을 적용하기 위해 사용자 정의 필터 표현을 지정하십시오.
- 하나 이상의 규칙에 대한 특정 설정 (예를 들어, Cloudflare에 의해 구성 된 기본 동작에서 다른 규칙을 구성), 또는 그 규칙을 해제.

하나 이상의 규칙을 건너 뛰기 - 또는 전체 관리 규칙 - 특정 수신 요청에 대한,[예외 추가](/waf/managed-rules/waf-exceptions/).

:::참조
일부 관리 된 규칙은 Cloudflare 계획에 따라 사용자 정의 구성을 허용 할 수 없습니다.

### 관리 규칙의 규칙을 검색

관리된 규칙에서 사용 가능한 규칙을 검색하고 개별 규칙이나 태그를 검색할 수 있습니다.

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    1. Cloudflare 대시보드에서 보안으로 이동**계정 설정**사이트 맵

       <DashButton url="/?to=/:account/:zone/security/settings" />

    2. (선택) 필터 로**웹 애플리케이션 악용**.

    3. 검색하고 싶은 관리 규칙 찾기**자주 묻는 질문**.

    4. 규칙 및 측면 패널의 태그를 검토합니다.
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Render file="managed-rules-browse-zone" product="waf" />
  </TabItem>
</Tabs>

### 관리 규칙 배포 규칙 또는 예외 삭제

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    <Steps>
      1. Cloudflare 대시보드에서**보안 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/security-rules" />

      2. (선택) 필터 로**관리 규칙**.

      3. 구성하려면 관리된 규칙을 검색합니다.

      4. 관리된 규칙 배포 규칙 (execute 규칙) 또는 예외 (skip 규칙) 당신은 삭제하고 싶은, 세 가지 점을 선택하십시오 >**이름 \***&#xADF8;리고 가동을 확인합니다.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com/)계정 및 도메인을 선택하십시오.
      2. 오시는 길**보안 보안** > **사이트맵** > **관리 규칙**탭.
      3. 삭제하려는 규칙 또는 예외 (skip 규칙)에 다음, 세 가지 점을 선택하십시오 >**이름 \***&#xADF8;리고 가동을 확인합니다.
    </Steps>
  </TabItem>
</Tabs>

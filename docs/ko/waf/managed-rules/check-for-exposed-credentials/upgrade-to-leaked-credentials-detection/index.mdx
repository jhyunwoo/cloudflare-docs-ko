이 가이드는 전반적인 단계를 설명합니다.[노출된 Credentials 체크](/waf/managed-rules/check-for-exposed-credentials/)새로운 구성[누출 검출](/waf/detections/leaked-credentials/).

Cloudflare는 고객이 다음의 이점을 제공하는 새로운 누출된 credentials 탐지를 사용하는 그들의 윤곽을 새롭게 하는 것을 추천합니다:

- 15 억 이상의 암호를 포함하는 누출 된 자격 증명의 포괄적 인 데이터베이스를 사용합니다.
- 탐지를 가능하게 한 후, 보안 분석에서 누출 된 자격 증명을 포함하는 수신 요청의 양을 검토 할 수 있습니다., 심지어 어떤 완화 규칙을 만들기 전에.
- WAF 기능을 사용하여 누출 된 자격 증명을 포함하는 요청에 대한 조치를 취할 수 있습니다.

:::참조
이 업그레이드 가이드는 Exposed Credentials Check at the Zone 레벨에서 변화하는 고객에게 적용됩니다.
주요 특징

## 1. 노출된 Credentials 체크를 끄십시오

Cloudflare 노출 Credentials 검사 관리 규칙을 배치 한 경우:

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    <Steps>
      1. Cloudflare 대시보드에서**보안 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/security-rules" />

      2. (선택) 필터 로**관리 규칙**.

      3. Cloudflare를 실행하는 규칙을 편집하여 Credentials Check Ruleset을 확인하고 현재 구성의 메모를 작성합니다. 다음, 삭제 (또는 해제) 그 규칙.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com/), 귀하의 계정과 도메인을 선택합니다.
      2. 오시는 길**보안 보안** > **사이트맵** > **관리 규칙**탭.
      3. 이름 \***관리 규칙**, Cloudflare 노출 Credentials Check Ruleset을 실행하는 규칙을 편집하고 현재 구성의 메모를 취합니다 (이름으로 수행 된 동작). 다음, 삭제 (또는 해제) 그 규칙.
    </Steps>
  </TabItem>
</Tabs>

:::참조
노출된 Credentials 검사 및 누출된 credentials 탐지는 측에 의하여 작동할 수 있습니다, 둘 다 특징은 입증과 관련있는 들어오는 요구에 있는 대기권을 증가할 것입니다.

## 3. 행동을 구성

이전 구성에 따라 다음 중 하나를 수행하십시오.

- 당신이 사용하는 경우[기본 동작](/waf/managed-rules/check-for-exposed-credentials/#available-actions)노출된 Credentials 검사: 켜기[**유출된 Credentials 체크 Header 추가**회사연혁](/rules/transform/managed-transforms/reference/#add-leaked-credentials-checks-header)그것은 추가`Exposed-Credential-Check`누출된 credentials를 포함하는 수신 요청에 헤더. 헤더 이름은 노출 된 Credentials Check와 동일하지만, 새로운 구현의 헤더 값은 다음과 같습니다.`1`·`4`.

- 다른 행동을 사용하는 경우: 만들기[주문 규칙](/waf/custom-rules/)당신이 사용 한 것과 같은 행동. 규칙은 일치해야합니다`User and password leaked is true`(문헌 편집기를 사용하는 경우, 입력`(cf.waf.credential_check.username_and_password_leaked)`).

사용 방법[규칙 세트 API](/ruleset-engine/rulesets-api/)영역 수준에서 관리되는 규칙을 배치합니다.

WAF를 배포하는 규칙`http_request_firewall_managed`단계. DDoS 공격 보호 관리 규칙과 같은 다른 관리 규칙은 다른 단계로 배포해야합니다. 특정 관리 규정 문서에 대한 자세한 내용은.

더 보기[WAF 관리 규칙](/waf/managed-rules/#available-managed-rulesets)페이지에는 다른 WAF 관리 규칙의 ID가 포함되어 있습니다. API를 통해 규칙을 배포 할 때이 정보가 필요합니다.

Terraform을 사용하는 경우, 참조[사이트맵 Terraform을 사용하여 관리 된 규칙 구성](/terraform/additional-configurations/waf-managed-rulesets/).

## 다음 단계

## 더 많은 리소스

API를 통해 계정 수준에서 관리되는 규칙을 배포하는 방법에 대한 지침은 참조[API를 통해 WAF 관리 규칙 배포 (계정)](/waf/account/managed-rulesets/deploy-api/).

API를 통해 관리되는 규칙에 대한 자세한 내용은 참조[관리 규칙과 함께 일](/ruleset-engine/managed-rulesets/)Ruleset Engine 문서에서.

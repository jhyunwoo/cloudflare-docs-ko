다음 예제는 들어오는 요청에 대한 OWASP 요청 위협 점수를 계산합니다. OWASP 관리 규칙 구성은 다음과 같습니다.

- OWASP Anomaly 점수 Threshold:*높은 - 25 이상*
- OWASP 파라노아 수준:*공장 투어*
- OWASP 활동:*관리 도전*

최종 요청 위협 점수:`26`

이름 \*`26` >= `25`— 즉, 위협 점수는 구성 점수 임계값보다 더 크다 — Cloudflare는 구성된 동작을 적용한다 (*관리 도전*). 점수 임계값을 구성한 경우*중간 - 40 이상*Cloudflare는 요청 위협 점수가 점수 임계값보다 낮기 때문에 동작을 적용하지 않을 것입니다 (`26` \< `40`).

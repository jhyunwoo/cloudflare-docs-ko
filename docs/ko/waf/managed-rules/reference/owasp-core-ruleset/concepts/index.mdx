## Paranoia 수준

파라노아 수준 (PL)은 공격에 따라 OWASP 규칙을 분류합니다. 파라노아 수준은 PL1에서 PL4로 다양하며, PL4는 가장 엄격한 수준입니다.

- PL1 (기본값)
- 공장 투어
- 공장 투어
- 공장 투어

OWASP 관리 규칙의 각 규칙은 파라노아 수준과 관련이 있습니다. 더 높은 paranoia 수준과 관련된 규칙은 더 적극적이고 증가 된 보호를 제공합니다. 그러나, 그들은 더 합법적 인 트래픽을 유발할 수 있습니다.

OWASP 규칙의 파라노아 수준을 구성하면 선택 레벨까지 모든 파라노아 수준에 속하는 모든 규칙을 활성화합니다. 예를 들어, 규칙 파라노아 레벨을 PL3로 구성하면 파라노아 레벨 PL1, PL2 및 PL3에 속하는 규칙을 활성화합니다.

규칙 파라노아 수준을 설정할 때 WAF는 대량의 대응 규칙을 가능하게 합니다. 당신은 개별 또는 태그로 특정 규칙을 비활성화 할 수 있습니다, 필요한 경우. 가장 높은 파라노아 레벨 (PL4)을 사용하면 복잡한 입력 패턴을받을 필요가있는 응용 프로그램에 대한 규칙의 일부를 비활성화해야합니다.

## 위협 점수

현재 요청을 일치하는 각 OWASP 규칙에는 관련 점수가 있습니다. 요청 위협 점수는 모든 OWASP 규칙의 개별 점수의 합입니다.

## 점수 임계 값

점수 임계 값 (또는 anomaly 임계 값)은 OWASP 규칙과 일치하여 최소 누적 점수를 정의합니다. WAF는 구성 된 OWASP 규칙 작업을 적용합니다.

사용 가능한 점수 임계 값은 다음과 같습니다.

- *낮음 – 60 이상*
- *중간 – 40 이상*(과태 값)
- *높은 - 25 이상*

각 임계 값 (각 임계 값)*이름 \**, *한국어*·*사이트맵*) 관련 값 (*60*, *40*·*25*, 각각). 설정하기*이름 \**&#xC784;계 값은 더 많은 규칙이 WAF에 대한 현재 요청과 일치해야합니다.

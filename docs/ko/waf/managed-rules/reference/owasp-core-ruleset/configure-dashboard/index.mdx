## 대시보드 구성

Cloudflare OWASP Core Ruleset을 구성할 수 있습니다.

- [규칙 설정 수준](#ruleset-level-configuration)
- [태그 수준](#tag-level-configuration)
- [규칙 수준](#rule-level-configuration)

더 특정 구성 (rule 및 태그 수준) 보다 더 큰 우선 순위 보다 적은 특정 구성 (ruleset 레벨).

### Ruleset-level 구성

Cloudflare 대시보드에 다음 Cloudflare OWASP Core Ruleset 설정을 구성할 수 있습니다.

- **관련 상품**: 사용자 정의 필터 표현을 지정할 때 Cloudflare OWASP Core Ruleset은 수신 요청의 하위 집합에만 적용됩니다. 기본적으로 대시보드에 배포된 관리된 규칙은 모든 수신 트래픽에 적용됩니다.
- **[Paranoia 수준](/waf/managed-rules/reference/owasp-core-ruleset/concepts/#paranoia-level)**: 패러노아 레벨 (PL)은 공격성에 따라 OWASP 규칙을 분류하고 다양한*공장 투어*으로*공장 투어*, 어디*공장 투어*가장 엄격한 수준입니다. 유효한 수준은:
  - *공장 투어*(과태)
  - *공장 투어*
  - *공장 투어*
  - *공장 투어*
- **[점수 임계 값](/waf/managed-rules/reference/owasp-core-ruleset/concepts/#score-threshold)**: 점수 임계 값 (또는 anomaly 임계 값)은 OWASP 규칙과 일치하여 최소 누적 점수를 정의합니다. WAF는 구성 된 OWASP 규칙 작업을 적용합니다. 유효한 문턱은:
  - *낮음 - 60 이상*
  - *중간 - 40 이상*(과태)
  - *높은 - 25 이상*
- **OWASP 활동**: 계산할 때 수행 할 작업[관련 위협 점수](/waf/managed-rules/reference/owasp-core-ruleset/concepts/#request-threat-score)더 큰[점수 임계 값](/waf/managed-rules/reference/owasp-core-ruleset/concepts/#score-threshold). 유효한 활동은:*제품정보*, *로그인*, *비동기 도전*, *관리 도전*·*대화 도전*.
- **[Payload 로깅](/waf/managed-rules/payload-logging/configure/)**: 사용할 때, 요청 정보를 로그 (payload) 관리 규칙의 특정 규칙을 트리거. 당신은 payload를 암호화하는 공공 키를 구성해야합니다.

당신은[Cloudflare OWASP Core Ruleset 배포](#deploy-in-the-dashboard), 대시보드에서 그것을 구성하는 뒤에:

<Render
  file="dash-configure-all-rules"
  params={{
  	rulesetName: "Cloudflare OWASP Core Ruleset",
  }}
  product="waf"
/>

### Tag-level 구성

OWASP Core Ruleset 규칙에 대한 대시보드의 다음 설정을 구성할 수 있습니다.

- **규칙 상태**: 선택한 태그를 가진 모든 규칙에 대한 규칙 상태를 설정한다. 태그 수준에서 동작 override를 제거하려면 행동을 설정*기본 정보*.

:::참조
특정 태그의 규칙 상태를 설정하면 선택한 태그와 함께 현재 및 미래의 규칙에 영향을 미칩니다.
주요 특징

당신은[Cloudflare OWASP Core Ruleset 배포](#deploy-in-the-dashboard), 대시보드에 특정 태그와 규칙을 구성하려면 다음을 수행:

<Render
  file="dash-configure-rules-by-tag"
  product="waf"
  params={{
  	rulesetName: "Cloudflare OWASP Core Ruleset",
  }}
/>

### 규칙 수준 윤곽

선택된 OWASP Core Ruleset 규칙을 위한 대시보드에서 다음과 같은 설정을 구성할 수 있습니다.

- **규칙 상태**: 단일 규칙의 상태(enabled or disabled)를 설정하거나, 선택된 규칙의 여러 규칙을 선택하면 됩니다.

당신은[Cloudflare OWASP Core Ruleset 배포](#deploy-in-the-dashboard)대시보드의 개별 규칙을 구성하려면 다음을 수행하십시오.

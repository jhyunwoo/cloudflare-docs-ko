Cloudflare OWASP Core Ruleset은 Cloudflare의 구현입니다.[OWASP ModSecurity 핵심 규칙 세트](https://owasp.org/www-project-modsecurity-core-rule-set/)(CRS). Cloudflare는 공식 코드 저장소에서 최신 버전을 기준으로 OWASP에서 업데이트를 위해 정기적으로 모니터합니다.

Cloudflare OWASP Core Ruleset은 단일 엔티티티티로 작동하도록 설계되었습니다.[위협 점수](/waf/managed-rules/reference/owasp-core-ruleset/concepts/#request-threat-score)그 점수를 기준으로 동작을 실행합니다. 규칙의 규칙이 요청을 일치 할 때, 위협 점수는 규칙 점수에 따라 증가합니다. 최종 위협 점수가 구성보다 크면[점수 임계 값](/waf/managed-rules/reference/owasp-core-ruleset/concepts/#score-threshold)Cloudflare는 규칙의 마지막 규칙에서 형성된 활동을 실행합니다.

:::참조

Cloudflare OWASP Core Ruleset은 OWASP ModSecurity Core Rule Set의 Cloudflare의 구현이며, 다른 것과는 다릅니다.[OWASP 정상 10](https://owasp.org/www-project-top-ten/).

OWASP Top 10은 애플리케이션에 영향을 줄 수있는 가장 심한 보안 위험 목록입니다. 확인된 보안 위험 중 일부는 OWASP Core Ruleset에 의해 주소 될 수 있지만, 다른 위험은 다음과 같은 웹 애플리케이션 방화벽에 의해 보호 될 수 없습니다.

- Insecure 디자인
- 식별 및 인증 실패
- 보안 로깅 및 모니터링 실패

이러한 위험은 애플리케이션이 구축되었거나 전체 모니터링 파이프라인이 설정되는 방법에 대해 더 많이 의존합니다.

:::

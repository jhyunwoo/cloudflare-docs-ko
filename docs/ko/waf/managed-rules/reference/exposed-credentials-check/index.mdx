Cloudflare Exposed Credentials Check Managed Ruleset은 도난당한 자격 증명의 공공 데이터베이스에 대한 검색을 수행하는 잘 알려진 CMS 응용 프로그램에 대한 사전 구성 규칙 세트입니다.

<Render file="leaked-credentials-recommend-detection" product="waf" />

관리 규칙에는 다음과 같은 CMS 응용 프로그램에 대한 규칙이 포함되어 있습니다.

- 사이트 맵
- 프로젝트
- 박사후
- 팟캐스트
- 뚱 베어
- 마젠토

또한,이 관리 규칙은 다른 일반적인 패턴에 대한 일반적인 규칙을 포함합니다:

- 자주 묻는 질문`POST`자주 묻는 질문`username`·`password`이름 \*
- JSON으로 보내진 자격 증명`email`·`password`지원하다
- JSON으로 보내진 자격 증명`username`·`password`지원하다

관리 규칙의 규칙에 대한 기본 동작은*Exposed-Credential-Check 헤더*(이름)`rewrite`API에서[보안 이벤트](/waf/analytics/security-events/#sampled-logs)).

관리된 규칙은 또한 HTTP 요청을 이미 포함하는 규칙을 포함합니다`Exposed-Credential-Check`HTTP 헤더에 의해 사용*Exposed-Credential-Check 헤더*활동. 이 요청은 (또는 포함되지 않은) 노출된 자격 증명을 구할 때 사용 될 수 있습니다.

노출된 자격 검사에 대한 자세한 내용은 참조[노출된 자격 증명을 확인](/waf/managed-rules/check-for-exposed-credentials/).

## 대시보드 구성

:::참조
노출된 Credentials 체크 관리되는 통치자는 당신이 이전에 배치한 경우에 Cloudflare 대시보드에서 단지 보입니다. Cloudflare는 당신이 이용하는 것을 추천합니다[누출 검출](/waf/detections/leaked-credentials/)대신.
주요 특징

Cloudflare의 다음 설정을 구성할 수 있습니다. 대시보드에서 관리되는 Credentials 검사:

- **수행 할 작업을 설정합니다.**&#xADDC;칙에 대한 행동을 정의 할 때, 각 규칙에 정의 된 기본 동작을 무시합니다. 사용 가능한 작업은:*제품정보*, *로그인*, *비동기 도전*, *관리 도전*·*대화 도전*. 동작을 제거하려면, 규칙 작업을 설정*기본 정보*.
- **개인 규칙에 의해 수행 된 행동을 무시합니다.**&#xC0AC;용 가능한 작업은:*Exposed-Credential-Check 헤더*, *제품정보*, *로그인*, *비동기 도전*, *관리 도전*·*대화 도전*. 자세한 내용은 참조[자주 묻는 질문](/waf/managed-rules/check-for-exposed-credentials/#available-actions).
- **특정 규칙.**
- **필터 표현을 지정합니다.**&#xC0AC;용자 정의 표현으로 Cloudflare 노출 Credentials Check Managed Ruleset은 들어오는 요청의 하위 집합에만 적용됩니다.
- **설정하기[payload 로깅](/waf/managed-rules/payload-logging/configure/)**.

대시보드에서 관리되는 규칙 구성에 대한 자세한 내용은 참조[관리 규칙 구성](/waf/managed-rules/deploy-zone-dashboard/#configure-a-managed-ruleset).

## API를 통해 구성

Cloudflare 노출 Credentials Check Managed Ruleset for a 주어진 영역에 대한 API, 규칙을 작성`execute`활동 중[관련 항목](/ruleset-engine/about/rulesets/#entry-point-ruleset)제품정보`http_request_firewall_managed`단계.

### 이름 \*

이 예제는 Cloudflare 노출 Credentials Check Managed Ruleset을 배포합니다.`http_request_firewall_managed`주어진 영역의 단계 (`$ZONE_ID`) 관리된 규칙을 실행하는 규칙을 작성하여. 관리 규칙의 규칙은 모든 들어오는 요청을 위해 실행됩니다.

:::note\[주문 규칙에 노출된 자격 증명을 확인]

Exposed Credentials Check Managed Ruleset을 활성화하면 사용자 정의 규칙에 노출 된 자격 증명을 확인할 수 있습니다. 1개의 일반적인 사용 케이스는 당신의 신청의 최종 사용자 입증 endpoints에 주문 규칙을 드러내는 것입니다 드러내는 credentials를 검사하기 위하여.

더 많은 정보를 원하시면, 참조[노출된 credentials를 위한 주문 규칙을 창조하십시오](/waf/managed-rules/check-for-exposed-credentials/configure-api/#create-a-custom-rule-checking-for-exposed-credentials).

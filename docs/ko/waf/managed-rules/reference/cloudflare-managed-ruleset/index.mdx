Cloudflare 보안 팀에 의해 생성 된이 규칙은 모든 응용 프로그램에 빠르고 효과적인 보호를 제공합니다. 규칙은 새로운 취약점을 커버하고 거짓 긍정적을 감소시키기 위해 자주 업데이트됩니다.

Cloudflare는 기술 스택에 대응하는 규칙을 활성화하는 것이 좋습니다. 예를 들어 WordPress를 사용하는 경우 규칙 태그를 활성화하십시오.`wordpress`.

Cloudflare의[WAF 변경 로그](/waf/change-log/)WAF의 관리 규칙에 대한 지속적인 변경을 모니터링 할 수 있습니다.

:::참조

Cloudflare Managed Ruleset의 일부 규칙은 기본적으로 비활성화되어 적절한 보호를 제공하고 가짜 긍정적 인 수를 줄임간에 균형을 잡습니다.

이 웹 사이트는 귀하가 웹 사이트를 탐색하는 동안 귀하의 경험을 향상시키기 위해 쿠키를 사용합니다. 이 쿠키들 중에서 필요에 따라 분류 된 쿠키는 웹 사이트의 기본적인 기능을 수행하는 데 필수적이므로 브라우저에 저장됩니다.

:::

## 대시보드 구성

Cloudflare Managed Ruleset, 여러 레벨에서 기본 구성을 overriding 할 수 있습니다.

- [규칙 설정 수준](#ruleset-level-configuration)
- [태그 수준](#tag-level-configuration)

다른 수준에서 여러 오버라이드를 만들 때, 더 구체적인 구성 (tag 및 규칙 수준)은 더 적은 특정 구성 (ruleset 레벨)에 우선 순위가 있습니다. 더 알아보기[관리된 규칙을 무시](/ruleset-engine/managed-rulesets/override-managed-ruleset/)더 많은 정보를 위한 Ruleset Engine 문서에.

### Ruleset-level 구성

Cloudflare 대시보드에 다음 Cloudflare 관리 규칙 설정을 구성할 수 있습니다.

- **관련 상품**: 범위의 사용자 정의 필터 표현을 정의 할 때 Cloudflare Managed Ruleset은 들어오는 요청의 하위 집합에만 적용됩니다. 기본적으로 대시보드에 배포된 관리된 규칙은 모든 수신 트래픽에 적용됩니다.

- **Ruleset 작업**: 규칙에 대한 동작을 정의할 때, 각 규칙에 정의된 기본 동작을 무시합니다.<Markdown text={availableActions} />규칙 수준에서 동작을 제거하려면 규칙 작업을 설정*기본 정보*.

- **Ruleset 상태**: 규칙의 모든 규칙을 사용하거나 비활성화합니다.

  :::참조
  규칙의 모든 규칙을 활성화 할 때, 당신은 기본으로 비활성화하는 규칙에 영향을 미칠 것이며 미래의 관리 규칙에 추가되는 모든 규칙.
  주요 특징

- **[Payload 로깅](/waf/managed-rules/payload-logging/configure/)**: 사용할 때, 요청 정보를 로그 (payload) 관리 규칙의 특정 규칙을 트리거. 당신은 payload를 암호화하는 공공 키를 구성해야합니다.

당신은[Cloudflare 관리 규칙 세트 배포](#deploy-in-the-dashboard), 대시보드에서 그것을 구성하는 뒤에:

### 규칙 수준 윤곽

선택된 규칙을 위한 Cloudflare Managed Ruleset 설정에 다음과 같은 Cloudflare를 구성할 수 있습니다.

- **규칙 활동**: 단일 규칙의 동작을 설정하거나, 여러 규칙을 선택하면, 선택한 규칙을 선택합니다.<Markdown text={availableActions} />규칙의 구성을 변경하면 Cloudflare Managed Ruleset에서 정의 된 기본으로 구성을 다시 재설정 할 수있는 옵션이 있습니다.

- **규칙 상태**: 단일 규칙의 상태(enabled or disabled)를 설정하거나, 선택된 규칙의 여러 규칙을 선택하면 됩니다.

## Terraform을 사용하여 구성

다음 예제는 영역의 Cloudflare Managed Ruleset을 배포하고 특정 규칙의 동작과 상태를 무시합니다.

<Render file="v4-code-snippets" product="terraform" />

```tf
# Configure a ruleset at the zone level for the "http_request_firewall_managed" phase
resource "cloudflare_ruleset" "zone_level_managed_waf" {
  zone_id     = "<ZONE_ID>"
  name        = "Managed WAF entry point ruleset"
  description = "Zone-level WAF Managed Rules config"
  kind        = "zone"
  phase       = "http_request_firewall_managed"

  # Execute Cloudflare Managed Ruleset
  rules {
    ref         = "execute_cloudflare_managed_ruleset"
    description = "Execute Cloudflare Managed Ruleset on my zone-level phase entry point ruleset"
    expression  = "true"
    action      = "execute"
    action_parameters {
      id = "efb7b8c949ac4650a09736fc376e9aee"
      overrides {
        rules {
          id      = "5de7edfa648c4d6891dc3e7f84534ffa"
          action  = "log"
          enabled = true
        }
      }
    }
  }
}
```

더 많은 정보를 원하시면, 참조[사이트맵 Terraform을 사용하여 관리 된 규칙 구성](/terraform/additional-configurations/waf-managed-rulesets/).

사용 방법`matched-data-cli`명령 줄에 payload를 해독하는 도구.

<Steps>
  1. [다운로드](https://github.com/cloudflare/matched-data-cli/releases)이름 \*`matched-data-cli`플랫폼에 대한 도구**공지사항**GitHub의 페이지, 아래**투자정보**.

  2. 다운로드의 내용을 추출`.tar.gz`로컬 폴더에 파일.

  3. 명령 줄 창을 열고 로컬 폴더로 변경`matched-data-cli`이진.

     ```sh
     cd matched-data-cli
     ```

  4. 두 파일 생성 : 개인 키와 암호화 된 페이로드와 다른 하나 :

     ```sh
     printf "<PRIVATE_KEY>" > private_key.txt && chmod 400 private_key.txt

     printf "<ENCRYPTED_PAYLOAD>" > encrypted_payload.txt
     ```

     기타 제품`<PRIVATE_KEY>`개인 키와 함께`<ENCRYPTED_PAYLOAD>`암호화된 페이로드로.

     참고 : 첫 번째`printf`명령은 명령 기록에 표시된 개인 키가 표시됩니다.

  5. 다음 명령을 실행하여 payload를 해독하십시오.

     ```sh
     decrypt -k private_key.txt encrypted_payload.txt
     ```
</Steps>

:::참조

macOS를 사용하고 있다면 실행할 때 오류가 발생합니다.`matched-data-cli`도구, 참조[macOS 오류 해결](/waf/managed-rules/payload-logging/command-line/generate-key-pair/#troubleshooting-macos-errors).
:::

## 이름 \*

다음 예제는 두 개의 파일을 만듭니다 - 개인 키와 암호화 된 페이로드와 다른 하나 - 및 실행`matched-data-cli`payload를 해독하는 도구`encrypted_payload.txt`파일 :

```sh
~ cd matched-data-cli

printf "uBS5eBttHrqkdY41kbZPdvYnNz8Vj0TvKIUpjB1y/GA=" > private_key.txt && chmod 400 private_key.txt

printf "AzTY6FHajXYXuDMUte82wrd+1n5CEHPoydYiyd3FMg5IEQAAAAAAAAA0lOhGXBclw8pWU5jbbYuepSIJN5JohTtZekLliJBlVWk=" > encrypted_payload.txt

decrypt -k private_key.txt encrypted_payload.txt
```

```txt output
test matched data
```

:::note\[암호화 형식]

암호화 된 페이로드의 형식은 시간을 초과 할 수 있습니다. 더 보기`matched-data-cli`도구는 새로운 암호화 형식을 해독 할 수없는 오류를 반환합니다.

이 오류를 수정하려면[다운로드](https://github.com/cloudflare/matched-data-cli/releases)GitHub에서 도구의 새로운 버전이 다시 시도합니다.

:::

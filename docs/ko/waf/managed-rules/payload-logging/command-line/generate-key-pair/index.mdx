Cloudflare를 사용하여 공공 / 개인 키 쌍 생성[`matched-data-cli`](https://github.com/cloudflare/matched-data-cli)명령줄 도구. 키 쌍을 생성 한 후, payload 로깅 설정에서 생성 된 공공 키를 입력하십시오.

다음을 수행:

<Steps>
  1. [다운로드](https://github.com/cloudflare/matched-data-cli/releases)이름 \*`matched-data-cli`플랫폼에 대한 도구**공지사항**GitHub의 페이지, 아래**투자정보**.

  2. 다운로드의 내용을 추출`.tar.gz`로컬 폴더에 파일.

  3. 터미널을 열고 로컬 폴더에 이동`matched-data-cli`도구.

     ```sh
     cd matched-data-cli
     ```

  4. 다음 명령을 실행:

     ```sh
     ./matched-data-cli generate-key-pair
     ```

     ```json output
     {
     	"private_key": "uBS5eBttHrqkdY41kbZPdvYnNz8Vj0TvKIUpjB1y/GA=",
     	"public_key": "Ycig/Zr/pZmklmFUN99nr+taURlYItL91g+NcHGYpB8="
     }
     ```
</Steps>

키 쌍을 생성 한 후, 공공 키 값을 복사하고 페이로드 로깅 구성에 입력합니다.

## macOS 오류 해결

macOS를 사용하는 경우 운영 체제가 차단될 수 있습니다.`matched-data-cli`도구, 보안 설정에 따라.

unsigned binaries를 실행하는 방법에 대한 지침`matched-data-cli`macOS의 도구, 참조[Mac에서 안전하게 앱을 엽니 다](https://support.apple.com/en-us/102445#openanyway)Apple 지원 페이지.

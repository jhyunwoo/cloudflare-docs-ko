WAF는 관리 규칙의 특정 규칙을 유발하는 요청 정보를 로그 할 수 있습니다. 이 정보는 페이로드로 알려져 있습니다. Payload 정보에는 규칙을 트리거 한 특정 문자열이 포함되어 있으며, 바로 앞에 나타나는 텍스트와 일치합니다.

Payload 로깅은 특히 WAF 규칙의 동작을 진단 할 때 유용합니다. 규칙을 트리거 한 값은 민감한 데이터를 포함 할 수 있으므로 고객 보호 된 공공 키와 암호화되어 나중에 검사 할 수 있습니다.

:::참조
이 기능은 기업 계획에 고객에게만 사용할 수 있습니다.
주요 특징

## 페이로드 로깅 켜기

각 관리된 통치자는 자체 탑재량 로깅 구성을 가지고 있습니다. payload 로깅을 켜려면 다음 중 하나를 수행하여 로그인 된 페이로드를 암호화하는 공공 키를 구성하십시오.

- Cloudflare 대시보드에서 직접 키 쌍 생성
- 당신의 대중적인 열쇠를 사용하십시오

일단 활성화되면 WAF는 페이로드 로깅으로 구성된 관리 된 통치자에 대한 급여로드를 절약하고 공개 키로 페이로드를 암호화합니다. 같은 요청 필드 일치를 확인하는 여러 규칙 (예를 들어, 필드에 대한`http.cookie`), 해당 필드에 대한 기록 된 페이로드는 마지막 일치 규칙을 참조합니다.

더 많은 정보를 원하시면, 참조[대시보드에서 페이로드 로깅 구성](/waf/managed-rules/payload-logging/configure/)또는[API를 통해 페이로드 로깅 구성](/waf/managed-rules/payload-logging/configure-api/).

:::카ution\[중요]
대시보드의 키 쌍을 생성하면 Cloudflare는 생성 된 공공 키 만 개인 키가 아닌 생성 된 키를 저장합니다. 개인 키를 안전하게 저장해야합니다.
주요 특징

## payload 내용 보기

명확한 텍스트의 페이로드의 내용을 보려면 다음 중 하나를 수행하십시오.

- 내 계정[보안 이벤트](/waf/analytics/security-events/)페이지, 브라우저에서 로그 입력의 페이로드를 해독하기 위해 개인 키를 입력하십시오. 더 알아보기[대시보드의 페이로드 컨텐츠 보기](/waf/managed-rules/payload-logging/view/)상세 정보

- 명령줄에서 payload를 호출합니다.`matched-data-cli`도구. 더 알아보기[명령 줄의 페이로드 내용을 해독](/waf/managed-rules/payload-logging/command-line/decrypt-payload/)상세 정보

- 당신의 일치한 payload를 해독하십시오[다운로드](/logs/logpush/)로그인을 저장하기 전에 작업자를 사용하여 작업<GlossaryTooltip term="SIEM">SIEM 시스템</GlossaryTooltip>. 참고[로그에 매각된 매각을 저장](/waf/managed-rules/payload-logging/decrypt-in-logs/)상세 정보

:::카ution\[중요]

모든 Cloudflare 로그는 나머지에서 암호화됩니다. 페이로드 콘텐츠 암호화는 규칙을 트리거 한 일치 값에 대한 암호화의 두 번째 레이어를 추가합니다.

개인 키를 안전하게 저장하십시오. 개인 키를 잃으면, 새로운 공공 키로 페이로드 로깅을 구성합니다. 새로운 요청의 페이로드는 새로운 공개 키로 암호화됩니다.

Cloudflare는 암호화 된 페이로드를 해독 할 수 없습니다. 이 작업은 개인 키를 필요로합니다. Cloudflare 직원은 절대 개인 키를 요청하지 않습니다.

:::

## 사용자 역할 요구 사항

사용자 만[Super 관리자 역할](/fundamentals/manage-members/roles/)payload 로깅을 활성화하거나 payload 로깅 구성을 편집 할 수 있습니다.

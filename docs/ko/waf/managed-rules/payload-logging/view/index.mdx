개인 키를 입력하여 대시보드의 일치한 규칙 탑재량을 볼 수 있습니다.

<Steps>
  {/* prettier-ignore-start */}

  1. 기타[보안 이벤트](/waf/analytics/security-events/):

     <Tabs syncKey="dashNewNav">
       <TabItem label="새로운 대시보드" icon="rocket">
         1. Cloudflare 대시보드에서**회사 소개**사이트 맵

            <DashButton url="/?to=/:account/:zone/security/analytics" />

         2. 선택하&#xAE30;**(주)**&#xD0ED;.
       </TabItem>

       <TabItem label="오래된 대시보드">
         - Cloudflare 대시보드에서 이동**보안 보안** > **(주)**.
       </TabItem>
     </Tabs>

  2. 이름 \***샘플 로그**, 관리 규칙에 의해 트리거 된 이벤트의 세부 사항을 확장하는 것은 페이로드 로깅 활성화.

  3. 이름 \***관련 상품**, 선택**Decrypt 페이로드 일치**.

     ![사용 가능한 페이로드 매치 데이터와 보안 이벤트 예 (still Encrypt)](~/assets/images/waf/transform-rules/payload-logging-example.png)

  4. 팝업 창에서 개인 키를 입력하고 선택**암호 해독**.

     :::참조
     개인 키는 Cloudflare 서버로 전송되지 않습니다. 해독은 브라우저에서 완전히 발생합니다.
     주요 특징

  {/* prettier-ignore-end */}
</Steps>

암호화 된 페이로드를 성공적으로 해독 한 개인 키가면 대시보드는 이전에 나타나는 일부 텍스트와 일치하고 일치 한 문자열의 이름을 표시 할 것입니다.

![대시보드에서 개인 키를 입력 한 후 해독 된 페이로드 일치 데이터를보기](~/assets/images/waf/transform-rules/payload-decrypted.png)

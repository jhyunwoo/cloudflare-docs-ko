## 사용 가능한 관리 규정

- [**Cloudflare 관리되는 통치자**](/waf/managed-rules/reference/cloudflare-managed-ruleset/): Cloudflare 보안 팀에 의해 생성 된이 규칙은 모든 응용 프로그램에 빠르고 효과적인 보호를 제공합니다. 규칙은 새로운 취약점을 커버하고 거짓 긍정적을 감소시키기 위해 자주 업데이트됩니다.<br />규칙 세트 ID:<RuleID id="efb7b8c949ac4650a09736fc376e9aee" />

- [**Cloudflare OWASP 핵심 통치자**](/waf/managed-rules/reference/owasp-core-ruleset/): Cloudflare의 Open Web Application Security Project 또는 OWASP ModSecurity Core Rule Set의 구현. Cloudflare는 공식 코드 저장소에서 사용할 수있는 최신 버전에 따라 OWASP에서 업데이트를 위해 정기적으로 모니터링합니다.<br />규칙 세트 ID:<RuleID id="4814384a9e5d4991b9815dcfc25d2f1f" />

- [**Cloudflare 노출 Credentials 체크**](/waf/managed-rules/reference/exposed-credentials-check/): 최종 사용자 인증 엔드포인트에서 자동화된 자격 증명 체크를 배포합니다. 어떤 자격 쌍을 위해, Cloudflare WAF는 도난당한 자격 증명의 공중 데이타베이스에 대한 조회를 수행합니다. Cloudflare는 당신이 이용하는 것을 추천합니다[누출 검출](/waf/detections/leaked-credentials/)이 규칙 대신.<br />규칙 세트 ID:<RuleID id="c2e184081120413c86c3ab7e14069605" />

- **Cloudflare 무료 관리되는 통치자**: 모든 Cloudflare 계획에서 사용 가능 높은 충격력에 대한 완화를 제공하기 위해 설계. 규칙은 대부분의 응용 프로그램에 배포하는 것이 안전합니다. Cloudflare Managed Ruleset을 사이트에 배포하면 이 관리 규칙을 배포할 필요가 없습니다.<br />규칙 세트 ID:<RuleID id="77454fe2d30c4220b5701f6fdfb893ba" />

다음 관리 규칙은 응답 단계에서 실행됩니다.

- [**Cloudflare 민감한 데이터 탐지**](/waf/managed-rules/reference/sensitive-data-detection/): Cloudflare에 의해 만들어 일반적인 데이터 손실 위협을 해결합니다. 이 규칙은 특정 민감한 데이터의 다운로드를 모니터링 — 예를 들어, 금융 및 개인 식별 정보.<br />규칙 세트 ID:<RuleID id="e22d83c647c64a3eae91b71b499d988e" />

## 중요한 말

### 최대 몸 크기

Cloudflare는 Cloudflare 계획에 따라 변화하는 특정 최대 크기까지 수신 요청의 몸을 분석합니다.

- 기업 고객을 위해, 최대 몸 크기는 128 KB입니다.
- 다른 유료 계획의 경우, 제한은 기본적으로 낮습니다. - 계정 팀이나 Cloudflare 지원으로 제한을 증가시킵니다.
- 무료 플랜 사용자의 경우, 제한은 1MB입니다.

이것은 요청 신체를 분석하는 특정 관리 규칙의 행동이 현재 계획에 따라 다를 수 있음을 의미합니다. 예를 들어, OWASP Core Ruleset은 더 많은 데이터를 분석하기 때문에 더 큰 페이로드 크기와 거짓 긍정적 인 비율을 가질 수 있으므로 총 점수가 초과하는 것과 같은 결과를 증가시킵니다.[임계 값](/waf/managed-rules/reference/owasp-core-ruleset/concepts/#score-threshold).

플랜에 포함 된 경우, 사용할 수 있습니다.[본문내용 바로가기](/ruleset-engine/rules-language/fields/reference/?field-category=Body)등`http.request.body.truncated`또는`http.request.headers.truncated`내 계정[주문 규칙](/waf/custom-rules/)Cloudflare에 의해 완전히 분석되지 않은 요청에 적절한 조치를 적용하는 것은 최대 신체 크기로 인해.

### Zone-level 배포

영역 수준에서 각 관리 규칙을 한 번 배치 할 수 있습니다. 에 의해[계정 수준](/waf/account/managed-rulesets/)각 관리 규칙을 여러 번 배포할 수 있습니다.

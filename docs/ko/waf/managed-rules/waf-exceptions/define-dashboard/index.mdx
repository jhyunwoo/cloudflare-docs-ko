## 1. 지역 또는 계정 대시보드 페이지로 이동

영역 수준에서 예외를 추가하려면:

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    <Steps>
      1. Cloudflare 대시보드에서**보안 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/security-rules" />

      2. 제품정보**이름 \*** > **관리 규칙**.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com), 귀하의 계정과 도메인을 선택합니다.
      2. 오시는 길**보안 보안** > **사이트맵** > **관리 규칙**탭.
      3. 제품정보**자주 묻는 질문**.
    </Steps>
  </TabItem>
</Tabs>

계정 수준에서 예외를 추가하려면 (Enterprise plans only):

<Steps>
  1. Cloudflare 대시보드에서**사이트맵**사이트 맵

     <DashButton url="/?to=/:account/application-security/waf" />

  2. 오시는 길**관련 규칙**탭.

  3. 제품정보**계정 만들기** > **Deploy 관리 예외**.
</Steps>

## 2. 기본 예외 매개변수 정의

<Steps>
  1. 내 계정**예외 이름**, 예외의 이름을 입력합니다.

     ![Cloudflare 대시보드의 추가 예외 페이지](~/assets/images/waf/waf-exception-create.png)

  2. 내 계정**수신 요청 일치**, 예외를 적용하기위한 조건을 정의하는 필터 표현을 지정합니다. 표현이 일치할 때 WAF는 WAF 관리 규칙의 하나 이상의 규칙을 건너 예외를 평가합니다. 필터 표현은[언어 선택](/ruleset-engine/rules-language/).
</Steps>

## 3. 건너뛰기 규칙을 선택하십시오.

<Steps>
  1. 내 계정**다음 것**, 선택[예외 유형](/waf/managed-rules/waf-exceptions/#types-of-exceptions)이 규칙은 건너뛰기:
     - **자주 묻는 질문**: WAF 관리 규칙의 나머지 규칙을 건너. 이 옵션을 선택하면 진행[4. 예외 만들기](#4-create-the-exception).
     - **Managed Ruleset의 특정 규칙을 건너**: 관리 규칙의 하나 이상의 규칙을 건너.

  2. 제품정보**자주 묻는 질문**.

  3. 규칙을 포함하는 규칙에 다음 (s) 당신은 건너뛰고 싶은, 선택**자주 묻는 질문**.

  4. **A) 규칙에 하나 이상의 규칙을 건너려면 :**

     1. 사용 가능한 필터를 사용하여 규칙 검색. 설명, 규칙 ID 또는 태그로 검색 할 수 있습니다. 예를 들어 Cloudflare OWASP Core Ruleset에서 검색할 수 있습니다.`920460`자주 묻는 질문`920460: Abnormal character escapes in request`.
     2. 당신은 건너뛰고 싶은 규칙(s) 옆에 체크박스를 선택합니다.
     3. 필요한 경우, 다른 규칙을 검색하고 그들을 선택하십시오. 대시보드는 검색 중 선택한 규칙 목록을 유지합니다.

     **B) 규칙의 모든 규칙을 건너려면 :**

     1. 테이블 헤더의 체크 박스를 선택하여 현재 페이지의 모든 규칙을 선택하십시오.**기술/Rule ID**. 테이블 우두머리는 전시할 것입니다`10 rules selected (of <TOTAL> rules)`.

        ![규칙 선택 페이지는 모든 규칙을 선택할 수있는 옵션을 보여줍니다](~/assets/images/waf/waf-exception-select-all-rules.png)

     2. 제품정보**모두 선택 \<TOTAL> 규칙**테이블 헤더에서 모든 페이지의 모든 규칙을 선택합니다.

  5. 제품정보**이름 \***.
</Steps>

## 4. 예외 만들기

<Steps>
  1. (선택) 예외를 일치하는 요청에 대한 로깅을 비활성화하려면 비활성화**로그 매칭 요청**.

  2. 예외를 저장하고 배포하려면, 선택**계정 만들기**. 예외를 배포 할 준비가 없다면, 선택**Draft로 저장**.
</Steps>

## 5. (선택) 예외 편집

영역 수준에서 예외를 편집하려면:

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    <Steps>
      1. Cloudflare 대시보드에서**보안 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/security-rules" />

      2. (선택) 필터 로**관리 규칙**.

      3. 편집하고 원하는 예외를 찾아 이름을 선택하십시오. 예외는 다음과 같은 규칙입니다.**- 연혁** = **팟캐스트**.

      4. 변경을 완료하면 선택**제품 정보**.<br />대신 예외를 삭제하려면, 선택**자주 묻는 질문**.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com), 귀하의 계정과 도메인을 선택합니다.
      2. 오시는 길**보안 보안** > **사이트맵** > **관리 규칙**탭.
      3. 편집하고 원하는 예외를 찾아 이름을 선택하십시오. 예외는 다음과 같은 규칙입니다.**- 연혁** = **팟캐스트**.
      4. 변경을 완료하면 선택**제품 정보**.
    </Steps>

    예외를 삭제하려면**관리 규칙**탭, 세 가지 점을 선택 >**이름 \***.
  </TabItem>
</Tabs>

계정 수준에서 예외를 편집하려면 (Enterprise plans only):

<Steps>
  1. Cloudflare 대시보드에서**사이트맵**사이트 맵

     <DashButton url="/?to=/:account/application-security/waf" />

  2. 오시는 길**관련 규칙**탭.

  3. 편집하고 원하는 예외를 찾아 이름을 선택하십시오. 예외는 다음과 같은 규칙입니다.**- 연혁** = **팟캐스트**.

  4. 변경을 완료하면 선택**제품 정보**.<br />대신 예외를 삭제하려면, 선택**자주 묻는 질문**.
</Steps>

:::참조
예외는 해당 후 관리된 규칙을 실행하는 규칙에만 적용됩니다. 예를 들어 Cloudflare OWASP Core Ruleset에 속하는 규칙을 건너면 예외가 규칙 목록에 나열되어 있는지 확인하십시오.*계정 관리*이 관리 규칙을 배포하는 규칙.

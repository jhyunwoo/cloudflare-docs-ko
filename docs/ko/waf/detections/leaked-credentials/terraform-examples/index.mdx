더 많은 정보를 원하시면, 참조[Terraform Cloudflare 공급자 문서](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs).

## 누출 된 자격 증명을 사용하여 요청을 도전하는 사용자 정의 규칙을 추가하십시오.

이 예제는 추가[주문 규칙](/waf/custom-rules/)그 도전 과제가 해결된 자격 증명을 사용하여[유출된 자격 분야](/waf/detections/leaked-credentials/#leaked-credentials-fields)규칙 표현에서.

이용하기[`cf.waf.credential_check.username_and_password_leaked`](/ruleset-engine/rules-language/fields/reference/cf.waf.credential_check.username_and_password_leaked/)당신은 있어야[누출 검출 가능](#enable-leaked-credentials-detection).

<Render file="v4-code-snippets" product="terraform" />

```tf
resource "cloudflare_ruleset" "zone_custom_firewall_leaked_creds" {
  zone_id     = "<ZONE_ID>"
  name        = "Phase entry point ruleset for custom rules in my zone"
  description = ""
  kind        = "zone"
  phase       = "http_request_firewall_custom"

  rules {
    ref         = "challenge_leaked_username_password"
    description = "Challenge requests with a leaked username and password"
    expression  = "(cf.waf.credential_check.username_and_password_leaked)"
    action      = "managed_challenge"
  }
}
```

## 비율 한계 의심의 여지 없이 로그인

:::참조
오시는 길`cf.waf.credential_check.username_and_password_leaked`필드는 프로 플랜 또는 위가 필요합니다.
주요 특징

[제한 규칙을 작성](/waf/rate-limiting-rules/create-zone-dashboard/)이름 \*[계정 takeover (ATO) 탐지](/bots/additional-configurations/detection-ids/#account-takeover-detections)특정 IP 주소, JA4 지문, 또는 국가에서 부피를 제한하는 자격 필드를 누출.

다음 예제 규칙은 특정 요청에 제한하는 비율을 적용합니다.[ATO 탐지 ID](/bots/additional-configurations/detection-ids/#account-takeover-detections)(응답하기`Observes all login traffic to the zone`) 이전에 유출 된 사용자 이름과 암호를 포함:

<Example>
  **수신 요청 일치**:<br />
  `(any(cf.bot_management.detection_ids[*] eq 201326593) and cf.waf.credential_check.username_and_password_leaked)`

  **동일한 특성으로**: *IP 정보*

  비율이 초과될 때:

  - **제품정보**: `5`
  - **기간 :**: *1 분*
</Example>

## 유출된 자격 증명을 포함하는 도전 요청

:::참조
오시는 길*사용자 및 비밀번호 유출* (`cf.waf.credential_check.username_and_password_leaked`) 분야는 직업적인 계획 또는 위에 요구합니다.
주요 특징

[사용자 정의 규칙 만들기](/waf/custom-rules/create-dashboard/)이전에 유출된 자격(username and password)를 포함하는 과제 요청.

- **패스워드**: Expression Builder를 사용하면 다음과 같은 표현을 구성합니다.

  | 제품정보          | 회사연혁  | 제품정보 |
  | ------------- | ----- | ---- |
  | 사용자 및 비밀번호 유출 | 이름 \* | 한국어  |

  Expression Editor를 사용하면 다음과 같은 표현식을 입력합니다.

  ```txt
  (cf.waf.credential_check.username_and_password_leaked)
  ```

- **- 연혁**: *관리 도전*

***

## 2. 콘텐츠 스캔 동작을 검증

제품 정보[보안 Analytics](/waf/analytics/security-analytics/)and HTTP logs to validate that malicious content object are being detected 정확하게.

당신은 사용할 수 있습니다[EICAR 안티 멀웨어 테스트 파일](https://www.eicar.org/download-anti-malware-testfile/)콘텐츠 스캔 테스트 ( ZIP 형식 선택).

대안으로, 다음 단계에서 설명 된 사용자 정의 규칙을 만듭니다.*로그인*mitigation action 대신 동작*제품정보*. 이 규칙은 생성합니다[보안 이벤트](/waf/analytics/security-events/)구성을 검증할 수 있습니다.

## 3. 사용자 정의 규칙 만들기

[사용자 정의 규칙 만들기](/waf/custom-rules/create-dashboard/)그것은 당신의 응용 프로그램에 업로드 된 악의적인 내용 개체를 차단.

예를 들어, 사용자 정의 규칙을 만듭니다.*제품정보*동작과 다음과 같은 표현:

| 제품정보      | 회사연혁  | 제품정보 |
| --------- | ----- | ---- |
| 악성 콘텐츠 객체 | 이름 \* | 한국어  |

Expression Editor를 사용하면 다음과 같은 표현식을 입력합니다.

```txt
(cf.waf.content_scan.has_malicious_obj)
```

규칙 활동:*제품정보*

이 규칙은 Cloudflare가 의심스러운 또는 악의적인 내용 객체를 감지하는 요청과 일치합니다. WAF 콘텐츠 스캐닝에 의해 제공된 필드 목록은 참조[검색 폼](/waf/detections/malicious-uploads/#content-scanning-fields).

<Details header="옵션: 다른 규칙 언어 필드와 결합">
  이전 표현식을 다른 사람들과 결합할 수 있습니다.[주요연혁](/ruleset-engine/rules-language/fields/)·[제품정보](/ruleset-engine/rules-language/functions/)규칙의 언어. 이것은 규칙 범위를 사용자 정의하거나 다른 보안 기능으로 콘텐츠를 스캔 결합 할 수 있습니다. 예를 들면:

  - 다음과 같은 표현은 특정 엔드포인트에 업로드 된 악의적 내용 객체와 일치합니다.

    | 제품정보      | 회사연혁  | 제품정보         | 로그인   |
    | --------- | ----- | ------------ | ----- |
    | 악성 콘텐츠 객체 | 이름 \* | 한국어          | 이름 \* |
    | URI 경로    | 지원하다  | `upload.php` |       |

    편집자를 사용할 때 표현:

    ```txt
    (cf.waf.content_scan.has_malicious_obj and http.request.uri.path contains "upload.php")
    ```

  - 다음과 같은 표현은 봇 업로드 콘텐츠 객체의 요청을 일치합니다.

    | 제품정보 | 회사연혁     | 제품정보 | 로그인   |
    | ---- | -------- | ---- | ----- |
    | 내용물  | 이름 \*    | 한국어  | 이름 \* |
    | 봇 점수 | 더 적은 보다는 | `10` |       |

    편집자를 사용할 때 표현:

    ```txt
    (cf.waf.content_scan.has_obj and cf.bot_management.score lt 10)
    ```
</Details>

추가 예제의 경우, 참조[예제 규칙](/waf/detections/malicious-uploads/example-rules/).

## 4. (선택) 사용자 정의 스캔 표현 구성

기본 설정에 의해 덮지 않는 방법에 업로드 된 내용을 확인하려면 추가[사용자 정의 스캔 표현](/waf/detections/malicious-uploads/#custom-scan-expressions).

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    <Steps>
      1. Cloudflare 대시보드에서 보안으로 이동**계정 설정**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/settings" />

      2. (선택) 필터 로**검색 툴**.

      3. 이름 \***악성행위 탐지** > **제품 설명**, 편집 아이콘을 선택합니다.

      4. 제품정보**자주 묻는 질문**.

      5. 내 계정**내용 위치**, 당신의 주문 검사 표식을 입력하십시오. 예를 들면:

         ```txt
         lookup_json_string(http.request.body.raw, "file")
         ```

      6. 제품정보**제품 정보**.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com/), 귀하의 계정과 도메인을 선택합니다.

      2. 오시는 길**보안 보안** > **계정 설정**.

      3. 이름 \***교통 감지**, 선택**맛있는 업로드**.

      4. 제품정보**콘텐츠 객체 위치 추가**.

      5. 내 계정**내용 위치**, 당신의 주문 검사 표식을 입력하십시오. 예를 들면:

         ```txt
         lookup_json_string(http.request.body.raw, "file")
         ```

      6. 제품정보**제품 정보**.
    </Steps>
  </TabItem>

  <TabItem label="사이트맵">
    지원하다`POST`다음과 같은 요청 :

    <APIRequest
      path="/zones/{zone_id}/content-upload-scan/payloads"
      method="POST"
      json={[
  	{
  		payload: 'lookup_json_string(http.request.body.raw, "file")',
  	},
  ]}
    />

    위의 요청은 사용자 정의 스캔 표현의 현재 목록에 다음 표현을 추가합니다.

    ```txt
    lookup_json_string(http.request.body.raw, "file")
    ```
  </TabItem>

  <TabItem label="옵션 정보">
    <Render file="detections/malicious-uploads-configure-expression-terraform" product="waf" />
  </TabItem>
</Tabs>

더 많은 정보를 원하시면, 참조[사용자 정의 스캔 표현](/waf/detections/malicious-uploads/#custom-scan-expressions).

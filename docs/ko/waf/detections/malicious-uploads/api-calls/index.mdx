다음 예제는 Cloudflare API를 사용하여 공통 시나리오를 사용하여 WAF 콘텐츠 스캔을 관리하고 구성합니다.

Terraform을 사용하는 경우, 참조[Terraform 구성 예제](/waf/detections/malicious-uploads/terraform-examples/).

## 일반 작업

다음 API 예제는 WAF 콘텐츠 스캔을 활성화하고 비활성화하는 것과 같은 기본 작업을 다룹니다.

### WAF 콘텐츠 스캐닝

콘텐츠 스캔을 활성화하려면`POST`다음과 같은 요청 :

<APIRequest path="/zones/{zone_id}/content-upload-scan/enable" method="POST" />

### WAF 콘텐츠 스캔 사용

콘텐츠 스캔을 비활성화하려면`POST`다음과 같은 요청 :

<APIRequest path="/zones/{zone_id}/content-upload-scan/disable" method="POST" />

### WAF 콘텐츠 스캔 상태를 얻는다

콘텐츠 스캔 기능의 현재 상태를 얻으려면, 사용`GET`다음과 같은 요청 :

<APIRequest path="/zones/{zone_id}/content-upload-scan/settings" method="GET" />

## 회사 소개

다음 API 예제는 콘텐츠 스캔에 대한 사용자 정의 스캔 표현에 대한 작업 커버.

### 기존 사용자 정의 스캔 표현

기존 사용자 정의 스캔 표현 목록을 얻으려면, 사용`GET`다음과 같은 요청 :

<APIRequest path="/zones/{zone_id}/content-upload-scan/payloads" method="GET" />

```json output
{
	"result": [
		{
			"id": "<EXPRESSION_ID>",
			"payload": "lookup_json_string(http.request.body.raw, \"file\")"
		}
	],
	"success": true,
	"errors": [],
	"messages": []
}
```

### 사용자 정의 스캔 표현 추가

지원하다`POST`다음과 같은 요청 :

<APIRequest
  path="/zones/{zone_id}/content-upload-scan/payloads"
  method="POST"
  json={[
  	{
  		payload: 'lookup_json_string(http.request.body.raw, "file")',
  	},
  ]}
/>

### 사용자 정의 스캔 표현 삭제

지원하다`DELETE`다음과 같은 요청 :

<APIRequest path="/zones/{zone_id}/content-upload-scan/payloads/{expression_id}" method="DELETE" />

## 악성행위를 막는 사용자 정의 규칙을 추가

이 예제는 추가[주문 규칙](/waf/custom-rules/)그 블록은 하나 이상의 요청<GlossaryTooltip term="content object">내용물</GlossaryTooltip>악의적 행위[콘텐츠 스캔 필드](/waf/detections/malicious-uploads/#content-scanning-fields)규칙 표현에서.

이용하기[`cf.waf.content_scan.has_malicious_obj`](/ruleset-engine/rules-language/fields/reference/cf.waf.content_scan.has_malicious_obj/)당신은 있어야[콘텐츠 스캔](#enable-waf-content-scanning).

<Render file="v4-code-snippets" product="terraform" />

```tf
resource "cloudflare_ruleset" "zone_custom_firewall_malicious_uploads" {
  zone_id     = "<ZONE_ID>"
  name        = "Phase entry point ruleset for custom rules in my zone"
  description = ""
  kind        = "zone"
  phase       = "http_request_firewall_custom"

  rules {
    ref         = "block_malicious_uploads"
    description = "Block requests uploading malicious content objects"
    expression  = "(cf.waf.content_scan.has_malicious_obj and http.request.uri.path eq \"/upload.php\")"
    action      = "block"
  }
}
```

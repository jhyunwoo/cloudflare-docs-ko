활성화 될 때, AI Security for Apps는 다음 필드를 대체합니다.

| 제품정보                                                                                                      | 이름 \*                                                                                                                                                |
| --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| LLM PII 검출<br /> [`cf.llm.prompt.pii_detected`][1] <br /> <Type text="Boolean" />                         | 개인 식별 정보 (PII)가 요청에 포함 된 LLM 프롬프트에 감지되었는지 나타냅니다.                                                                                                     |
| LLM PII 카테고리<br /> [`cf.llm.prompt.pii_categories`][2] <br /> <Type text="Array<String>" />               | 개인 식별 정보 (PII) 카테고리가 요청에 포함 된 LLM 프롬프트에 표시된 문자열 값의 배열.<br />[범주 목록](/ruleset-engine/rules-language/fields/reference/cf.llm.prompt.pii_categories/)   |
| 사이트맵 검색 결과<br /> [`cf.llm.prompt.detected`][3] <br /> <Type text="Boolean " />                            | Cloudflare가 들어오는 요청에 LLM 프롬프트를 검출하는지 나타냅니다.                                                                                                          |
| 사이트맵 Unsafe 항목 감지<br /> [`cf.llm.prompt.unsafe_topic_detected`][4] <br /> <Type text="Boolean" />         | 수신 요청이 LLM 프롬프트에서 안전한 항목 범주를 포함 여부를 나타냅니다.                                                                                                           |
| 사이트맵 Unsafe 항목 범주<br /> [`cf.llm.prompt.unsafe_topic_categories`][5] <br /> <Type text="Array<String>" /> | LLM 프롬프트에서 탐지되지 않은 주제의 유형과 문자열 값의 배열.<br />[범주 목록](/ruleset-engine/rules-language/fields/reference/cf.llm.prompt.unsafe_topic_categories/)           |
| LLM 주입 점수<br /> [`cf.llm.prompt.injection_score`][6] <br /> <Type text="Number" />                        | 1-99의 점수는 요청에서 LLM 프롬프트가 신속한 주사 공격을 수행하려고한다는 것을 나타냅니다. 더 낮은 점수는 더 높은 위험을 나타냅니다.                                                                      |
| 사이트맵 토큰 수<br /> [`cf.llm.prompt.token_count`][7] <br /> <Type text="Number" />                            | 요청에서 LLM 프롬프트에 대한 추정된 토큰 수. 더 알아보기[토큰 계산](/waf/detections/ai-security-for-apps/token-counting/)상세 정보                                                 |
| LLM 사용자 정의 항목 카테고리<br /> [`cf.llm.prompt.custom_topic_categories`][8] <br /> <Type text="Map<Number>" />  | 사용자 정의 주제의지도는 반사 점수 (1–99). 더 낮은 점수는 그 주제에 더 많은 관련이 있음을 나타냅니다. 일시 정지[사용자 정의](/waf/detections/ai-security-for-apps/unsafe-topics/#custom-topics)설정한다. |

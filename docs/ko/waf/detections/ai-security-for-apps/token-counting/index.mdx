AI Security for Apps (이전 Firewall for AI)는 각 들어오는 LLM 프롬프트의 추정된 토큰 수를 제공합니다. 이것은 신속한 크기를 모니터링하고, 오버 긴 프롬프트에 제한을 설정하고, AI 엔드포인트를 통해 토큰 사용을 추적 할 수 있습니다.

## 토큰 계산 작업

AI Security for Apps가 요청을 처리할 때`cf-llm`labeled endpoint, 그것은 신속한 콘텐츠를 위해 대략적인 토큰 수를 계산합니다. 결과는 유효합니다**사이트맵 토큰 수** ([`cf.llm.prompt.token_count`](/ruleset-engine/rules-language/fields/reference/cf.llm.prompt.token_count/)) 참고 자료를 규칙 표식과 분석을 볼 수 있는 필드.

:::참조
**토큰은 견적입니다.**&#xADF8;것은 범용 Tokenizer를 사용하고 LLM 공급자에 의해보고 된 토큰 수와 정확히 일치하지 않습니다. 다른 모델 사용 다른 Tokenizers — GPT-4, Claude, Llama, 다른 모든 토큰화 텍스트를 다르게 사용합니다. 이 필드를 사용하여 상대 임계값과 anomaly detection, 청구 또는 모델 별 토큰 예산에 대한 정확한 측정.
주요 특징

## 사용 사례

### 블록 오버사이즈 프롬프트

특정 추정된 토큰 수를 초과하는 프롬프트를 차단하는 하드 임계 값을 설정합니다. 이것은 당신의 모형에 도달에서 예기치 않게 큰 입력을 방지합니다.

- **수신 요청 일치**:

  편집기의 다음 표현을 입력하십시오:<br />
  `(cf.llm.prompt.token_count gt 4000)`

- **- 연혁**: *제품정보*

### 비율 한계 큰 신속한s

이름 \*[비율 제한 규칙](/waf/rate-limiting-rules/)한 번의 클라이언트가 한 번의 창에서 보낼 수 있도록 큰 프롬프트 수를 제한합니다. 이것은 공격자가 모델 리소스를 소비하기 위해 과도하게 긴 프롬프트를 보낼 수있는 남용을 방지하는 데 도움이됩니다.

편집기에서 다음 규칙식을 입력하십시오.<br />
`(cf.llm.prompt.token_count gt 2000)`

예를 들면, IP 당 분 당 10의 요구, 활동과 더불어*제품정보*또는*관리 도전*.

### 다른 탐지를 가진 토큰 조사

또한 신속한 주사의 징후를 보여주는 큰 프롬프트 대상 - 공격자 패드 주입이 긴 컨텍스트로 시도하는 일반적인 패턴.

예 규칙 표현:<br />
`(cf.llm.prompt.token_count gt 3000 and cf.llm.prompt.injection_score lt 50)`

## 중요한 고려사항

- **견적 요청**토큰 수는 일반 대강입니다. 모델의 실제 토큰 소비는 모델의 Tokenizer에 따라 다를 수 있습니다.
- **입력 토큰 만.**&#xD1A0;큰 수는 들어오는 프롬프트를 반영합니다. 산출 또는 응답 토큰을 견적하지 않습니다.
- **추출된 프롬프트만.**&#xD1A0;큰 수치는 요청 몸에서 추출된 프롬프트 텍스트에 계산됩니다. Cloudflare는 주요 LLM 공급자를 위한 알려진 JSON 경로 세트를 사용하여 신속한 추출합니다. 프롬프트가 추출 될 수 없을 때 Cloudflare는 풀 요청체를 fallback으로 사용합니다. 이러한 상황에서 토큰 수는 전체 요청 몸을 반영합니다.

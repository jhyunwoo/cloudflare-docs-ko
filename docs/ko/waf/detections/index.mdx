교통 감지는 악의적 또는 잠재적으로 악의적 인 활동에 대한 수신 요청을 확인합니다. 각 활성화된 탐지는 1개 이상 특성 분류 들어오는 요구에 제공합니다. 이 속성은 필터로 사용할 수 있습니다.[보안 Analytics](/waf/analytics/security-analytics/)대시보드 및 사용은 규칙 표현에서 사용할 수 있습니다.

일단 활성화되면, 탐지는 항상 켜져 있습니다. 이것은 당신이 탐지 결과를 안으로 사용할 수 있다는 것을 의미합니다[보안 Analytics](/waf/analytics/security-analytics/)트래픽 패턴을 식별하고 잠재적으로 악의적인 트래픽을 확인합니다. 예를 들어, 공격 점수를 기반으로 들어오는 트래픽을 분석 할 수 있습니다, 봇 점수,[검색 결과](/waf/detections/malicious-uploads/), 또는[개인 식별 정보의 존재 (PII)](/waf/detections/ai-security-for-apps/)큰 언어 모델 (LLM) 프롬프트.

Cloudflare는 현재 들어오는 요청에 보안 위협을 찾는 다음 탐지를 제공합니다.

## 감지 켜기

트래픽 감지를 켜려면 :

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    <Steps>
      1. Cloudflare 대시보드에서 보안으로 이동**계정 설정**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/settings" />

      2. 필터 로**검색 툴**.

      3. 원하는 검출을 켜십시오.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com/), 귀하의 계정과 도메인을 선택합니다.
      2. 오시는 길**보안 보안** > **계정 설정**.
      3. 이름 \***교통 감지**, 원한 탐지를 켜십시오.
    </Steps>
  </TabItem>
</Tabs>

활성화된 검출은 모든 수신 트래픽을 위해 실행됩니다.

:::주\[주]

무료 계획에서 누출 된 자격 탐지는 기본적으로 활성화되며 작업이 필요하지 않습니다.

현재 관리할 수 없습니다.[봇 점수](/bots/concepts/bot-score/)·[공격 점수](/waf/detections/attack-score/)검색 결과**계정 설정**사이트 맵 각 기능의 문서에 대한 세부 정보.

:::

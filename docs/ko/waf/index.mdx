## 주요 특징

<Feature header="주문 규칙" href="/waf/custom-rules/">
  웹 사이트 및 API를 보호하기 위해 자신의 사용자 정의 규칙을 만드십시오
  악의적 인 수신 트래픽. 같은 고급 기능 사용[WAF 공격
  이름 \*](/waf/detections/attack-score/)·[악의적 인 업로드
  제품정보](/waf/detections/malicious-uploads/)당신의 관례 규칙에서.
</Feature>

<Feature header="비율 제한 규칙" href="/waf/rate-limiting-rules/">
  표현과 일치하는 수신 요청에 대한 비율 제한을 정의합니다.
  해당 이용 후기에 달린 코멘트가 없습니다.
</Feature>

<Feature header="관리 규칙" href="/waf/managed-rules/">
  사전 구성 관리 규칙을 사용하여 즉각적인 보호를 얻을 수 있습니다. 이름 \*
  규칙은[자주 묻는 질문](/waf/change-log/)고급 Zero-day 제공
  취약점 보호, 당신은 그들의 행동을 조정할 수 있습니다.
</Feature>

<Feature header="계정 수준 구성" href="/waf/account/">
  <Plan type="ent-add-on" />

  여러 엔터프라이즈 영역에 규칙을 만들고 배포합니다.
</Feature>

<Feature header="보안 이벤트" href="/waf/analytics/security-events/" cta="Explore Security Events">
  직관적 인 인터페이스를 사용하여 mitigated 요청 (rule match)을 검토하십시오. 테일러
  샘플 로그에 근거한 보안 구성.
</Feature>

<Feature header="보안 Analytics" href="/waf/analytics/security-analytics/" cta="Explore Security Analytics">
  모든 수신 HTTP 요청에 대한 정보를 표시, 그를 포함하여
  보안 조치에 의해 영향을.
</Feature>

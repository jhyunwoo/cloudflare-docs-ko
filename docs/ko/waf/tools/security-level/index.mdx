오래된 Cloudflare 대시보드에서는, 안전 수준에는 가치가 있습니다*항상 보호*이 설정을 변경할 수 없습니다. 설정하기[공격 모드](/fundamentals/reference/under-attack-mode/)또는 떨어져, 분리된 toggle를 사용하십시오.

새로운 보안 대시보드에서 Cloudflare API 및 Terraform에서 공격 모드를 켜거나 해제하는 보안 수준을 사용합니다.

Cloudflare의[공격 모드](/fundamentals/reference/under-attack-mode/)추가 보안 검사를 수행하여 mitigate layer 7 DDoS 공격을 돕습니다. 공격 모드를 활성화 할 때 Cloudflare는 관리 된 도전 페이지를 제공합니다.

:::카트로션

만 사용[공격 모드](/fundamentals/reference/under-attack-mode/)웹 사이트가 DDoS 공격의 밑에있을 때. 공격 모드에서는 API 트래픽과 같은 도메인에서 일부 작업에 영향을 미칠 수 있습니다.

귀하의 API 또는 도메인의 다른 부분에 대한 공격 모드를 활성화하거나 비활성화하려면[구성 규칙](/rules/configuration-rules/).

:::

## 위협 점수

Previously, 위협 점수는 0-100에서 Cloudflare 위협 점수를 나타냅니다. 0은 낮은 위험을 나타냅니다. 이제 위협 점수는 항상`0`(제로).

:::주최\[추천]
현재 우리는 위협 점수를 기반으로 규칙을 만드는 것이 좋습니다. 이 점수는 더 이상 대중화되지 않습니다.

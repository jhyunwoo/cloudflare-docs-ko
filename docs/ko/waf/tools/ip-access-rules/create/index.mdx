:::tip\[추천: 대신 사용자 정의 규칙 사용]
Cloudflare는 당신이 창조하는 것을 추천합니다[주문 규칙](/waf/custom-rules/)IP 액세스 규칙 대신 IP 기반 또는 지리 기반 차단을 수행 (geoblocking).
주요 특징

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    :::참조
    IP 액세스 규칙은 적어도 하나의 IP 액세스 규칙을 구성 한 경우 새로운 보안 대시보드에서만 사용할 수 있습니다. Cloudflare는 당신이 이용하는 것을 추천합니다[주문 규칙](/waf/custom-rules/)IP 액세스 규칙 대신.
    주요 특징

    <Steps>
      1. Cloudflare 대시보드에서**보안 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/security-rules" />

      2. 제품정보**규칙 만들기** > **IP 접근 규칙**.

      3. 다음 규칙을 입력하십시오:
         1. 제품 정보**IP, IP 범위, 국가 이름, 또는 ASN**IP 주소, IP 범위, 국가 코드 / 이름, 또는 자율 시스템 번호 (ASN)를 입력하십시오. 자주 묻는 질문[IP 접근 규칙 모수](/waf/tools/ip-access-rules/parameters/).
         2. 제품 정&#xBCF4;**- 연혁**, 선택[이름 \*](/waf/tools/ip-access-rules/actions/).
         3. 제품 정보**지역 명소**, 규칙이 현재 웹 사이트에 적용 여부를 선택하거나 계정에 모든 웹 사이트에.
         4. (선택 사항) 규칙에 대한 메모를 입력 (예를 들어,`Payment Gateway`).

      4. 제품정보**이름 \***.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com), 귀하의 계정과 도메인을 선택합니다.

      2. 오시는 길**보안 보안** > **사이트맵** > **회사 소개**.

      3. 이름 \***IP 액세스 규칙**, 뒤에 오는 세부사항을 입력하십시오:
         1. 제품 정보**제품정보**IP 주소, IP 범위, 국가 코드 / 이름, 또는 자율 시스템 번호 (ASN)를 입력하십시오. 자주 묻는 질문[IP 접근 규칙 모수](/waf/tools/ip-access-rules/parameters/).
         2. 자주 묻는 질문[이름 \*](/waf/tools/ip-access-rules/actions/).
         3. 제품 정보**지역 명소**, 규칙이 현재 웹 사이트에 적용 여부를 선택하거나 계정에 모든 웹 사이트에.
         4. (선택 사항) 규칙에 대한 메모를 입력 (예를 들어,`Payment Gateway`).

      4. 제품정보**더 보기**.
    </Steps>
  </TabItem>

  <TabItem label="사이트맵">
    Cloudflare API를 사용하여 프로그래밍 방식으로 IP 액세스 규칙을 만듭니다. 더 많은 정보를 원하시면, 참조[IP 액세스 규칙 만들기](/api/resources/firewall/subresources/access_rules/methods/create/).
  </TabItem>
</Tabs>

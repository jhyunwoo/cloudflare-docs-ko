IP 액세스 규칙은 다음과 같은 작업을 수행 할 수 있습니다 :

- **제품정보**: 귀하의 사이트를 방문에서 방문자를 방지합니다.

- **지원하다**: 모든 보안 검사에서 방문자를 제외[브라우저 Integrity Check](/waf/tools/browser-integrity-check/), [공격 모드](/fundamentals/reference/under-attack-mode/), 그리고 WAF. 신뢰할 수있는 방문자가 Cloudflare의 기본 보안 기능에 의해 차단 될 때이 옵션을 사용하십시오. 더 보기*지원하다*행동은 계속*제품정보*활동.<br />주어진 국가 코드를 허용하면 WAF 관리 규칙 (이전 및 새로운 버전)을 우회하지 않습니다. 더 알아보기[국가에 의해 허용 / 차단에 대한 중요한 말](/waf/tools/ip-access-rules/#important-remarks-about-allowingblocking-by-country)더 많은 정보.

- **관리 도전**: 요청의 특성에 따라 Cloudflare는 동적으로 가능한 작업 목록에서 도전의 적절한 유형을 선택합니다. 더 많은 정보를 원하시면, 참조[Interstitial 도전 Pages](/cloudflare-challenges/challenge-types/challenge-pages/#managed-challenge).

- **비동기 도전**: 방문자에게 비동기적인 도전 페이지를 선물합니다. 사이트에 액세스하는 봇을 방지합니다.

- **대화 도전**: 방문자가 사이트를 방문하기 전에 대화 형 도전을 완료해야합니다. 사이트에 액세스하는 봇을 방지합니다.

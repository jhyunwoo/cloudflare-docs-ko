IP 액세스 규칙은 방문자의 IP 주소, IP 범위, Autonomous System Number (ASN) 또는 국가를 기반으로 한 트래픽을 수신하는 특정 조치를 적용합니다.

## IP 주소

| 제품정보    | 예제 값         |
| ------- | ------------ |
| IPv4 주소 | `192.0.2.3`  |
| IPv6 주소 | `2001:db8::` |

## IP 범위

| 제품정보             | 예제 값             | 범위의 시작        | 범위의 끝                                    |                                     주소 |
| ---------------- | ---------------- | ------------- | ---------------------------------------- | -------------------------------------: |
| IPv4 지원`/24`제품정보 | `192.0.2.0/24`   | `192.0.2.0`   | `192.0.2.255`                            |                                    256 |
| IPv4 지원`/16`제품정보 | `192.168.0.0/16` | `192.168.0.0` | `192.168.255.255`                        |                                 65,536 |

| 제품정보 | 예제 값      |
| ---- | --------- |
| 사이트맵 | `AS13335` |

## 이름 \*

2-letter를 사용하여 국가 지정[ISO-3166-1 알파 2 부호](https://www.iso.org/iso-3166-country-codes.html). 게다가, Cloudflare 대시보드는 국가명을 받아들입니다. 예를 들면:

- `US`
- `CN`
- `germany`(대시보드 전용)

Cloudflare는 ISO의 일부가 아닌 다음과 같은 특수 국가 알파-2 코드를 사용합니다.

- `T1`: [Tor 종료 노드](/network/onion-routing/)(국가 이름:`Tor`)
- `XX`: 취소 / 취소

:::주\[주]

국가 블록은 Enterprise 계획에서만 사용할 수 있습니다.

Cloudflare에 의해 전 세계적으로 IP 주소는 IP 액세스 규칙을 통해 국가 블록을 과도하게되지만 국가 블록을 통해 무시하지 않습니다.[주문 규칙](/waf/custom-rules/).

:::

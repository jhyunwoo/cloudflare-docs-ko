IP 정보 액세스 규칙<GlossaryTooltip term="allowlist">관련 상품</GlossaryTooltip>방문자의 IP 주소, 자율 시스템 번호 (ASN), 또는 국가를 기반으로 한 , 블록 및 도전 트래픽.

IP Access 규칙은 일반적으로 블록 또는 의심의 여지없이 악의적인 트래픽을 차단하는 데 사용됩니다. IP Access 규칙의 또 다른 일반적인 사용은 API, 크롤러 및 지불 공급자와 같은 정기적으로 귀하의 사이트에 액세스 할 수있는 서비스를 허용하는 것입니다.

:::카트로션

IP 또는 ASN을 허용하는 것은 어떤 구성을 우회할 것입니다[주문 규칙](/waf/custom-rules/), [비율 제한 규칙](/waf/rate-limiting-rules/), [WAF 관리 규칙](/waf/managed-rules/), 방화벽 규칙(deprecated).

국가별로 교통을 허용하거나 차단하는 데 중요한 노트를 들어, 참조[국가에 의해 허용 / 차단에 대한 중요한 말](#important-remarks-about-allowingblocking-by-country).

:::

## 국가에 의해 허용 / 차단에 대한 중요한 말

국가 별 블록은 Enterprise 계획에서만 사용할 수 있습니다.

Cloudflare에 의해 전 세계적으로 IP 주소는 IP 액세스 규칙 국가 차단을 무시하지만 국가 차단을 무시하지 않습니다[주문 규칙](/waf/custom-rules/).

국가 허용 :

- 모든 구성을 우회[주문 규칙](/waf/custom-rules/), [비율 제한 규칙](/waf/rate-limiting-rules/), 방화벽 규칙(deprecated).
- 비밀번호[WAF 관리 규칙](/waf/managed-rules/)또는[WAF 관리 규칙 (이전 버전)](/waf/reference/legacy/old-waf-managed-rules/).

## 권장 사항 : 대신 사용자 정의 규칙 사용

Cloudflare는 당신이 창조하는 것을 추천합니다[주문 규칙](/waf/custom-rules/)IP 액세스 규칙 대신 IP 기반 또는 지리 기반 차단 (geoblocking)을 수행 할 수 있습니다.

- IP 기반 차단을 위해, 사용[IP 목록](/waf/tools/lists/custom-lists/#ip-lists)사용자 정의 규칙 표현. 더 알아보기[수당 IP 주소에서 트래픽을 허용](/waf/custom-rules/use-cases/allow-traffic-from-ips-in-allowlist/)예를 들어.
- geoblocking를 위해, 같은 사용 분야*사이트맵*, *이름 \**·*제품 정보*사용자 정의 규칙 표현. 더 알아보기[특정 국가에서의 블록 트래픽](/waf/custom-rules/use-cases/block-traffic-from-specific-countries/)예를 들어.

## 적용분야

IP 접근 규칙은 모든 고객에게 유효합니다.

각 Cloudflare 계정은 최대 50,000 규칙을 가질 수 있습니다. 기업 고객이며 더 많은 규칙이 필요하면 계정 팀에 문의하십시오.

국가별 블록은 엔터프라이즈 플랜에서만 가능합니다. 다른 고객은 국가 차단을 수행 할 수 있습니다[WAF 사용자 정의 규칙](/waf/custom-rules/).

## 최종 알림

- 디자인, IP 접근 규칙에 따라*지원하다*교통이 표시되지 않습니다[보안 이벤트](/waf/analytics/security-events/).

- 특정 공격 패턴을 포함하는 요청`User-Agent`필드는 일반 방화벽 파이프라인에 의해 처리되기 전에 검사됩니다. 그러므로, 그러한 요청은 모든 수당 논리가 발생하기 전에 차단됩니다. 이 발생하면 API 쇼에서 다운로드 된 보안 이벤트`rule_id`이름 \*`security_level`그리고 행동으로`drop`.

- Cloudflare 지원`fail2ban`서버에서 IP를 차단합니다. 그러나, 예방`fail2ban`Cloudflare IP를 차단하고 일부 방문자에 대한 오류를 발생시키면 원본 방문자 IP를 Origin 서버 로그에 복원하십시오. 자주 묻는 질문[원래 방문자 IP를 복원](/support/troubleshooting/restoring-visitor-ips/restoring-original-visitor-ips/).

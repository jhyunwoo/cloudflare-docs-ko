User Agent Blocking은 특정 브라우저 또는 웹 응용 프로그램을 차단할 수 있습니다.[`User-Agent`요청 헤더](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/User-Agent). 사용자 에이전트 규칙은 개별 하위 도메인 대신 전체 도메인에 적용됩니다.

사용자 대리인 규칙은 후에 적용됩니다[지역 lockdown 규칙](/waf/tools/zone-lockdown/). Zone Lockdown을 통해 IP 주소를 허용하면 사용자 에이전트 규칙을 건너 뛸 수 있습니다.

:::참조

Cloudflare는 당신이 이용하는 것을 추천합니다[주문 규칙](/waf/custom-rules/)사용자 에이전트 규칙 대신 특정 사용자 에이전트를 차단.

예를 들어, 사용자 에이전트와 동등한 사용자 정의 규칙[예제 규칙](#create-a-user-agent-blocking-rule)이 페이지에서 제공된 설정은 다음과 같습니다.

- **패스워드**: `http.user_agent eq "BadBot/1.0.2 (+http://bad.bot)"`
- **- 연혁**: (블록이나 도전)

:::

## 적용분야

Cloudflare 사용자 에이전트 블록은 모든 계획에 사용할 수 있습니다. 그러나이 기능은 만 사용할 수 있습니다.[새로운 보안 대시보드](/security/)적어도 하나의 사용자 에이전트 규칙을 구성 한 경우.

사용 가능한 사용자 에이전트 규칙의 수는 Cloudflare 계획에 따라 다릅니다.

## 사용자 에이전트 차단 규칙 만들기

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    :::참조
    User Agent Blocking은 최소 1개의 사용자 에이전트 규칙을 구성한 경우 새로운 보안 대시보드에서만 사용할 수 있습니다. Cloudflare는 당신이 이용하는 것을 추천합니다[주문 규칙](/waf/custom-rules/)사용자 에이전트 규칙 대신.
    주요 특징

    <Steps>
      1. Cloudflare 대시보드에서**보안 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/security-rules" />

      2. 제품정보**규칙 만들기** > **사용자 에이전트 규칙**.

      3. 규칙에 대한 설명 이름 입력**이름/설명**.

      4. 내 계&#xC815;**- 연혁**, 수행 작업을 선택:*제품정보*, *비동기 도전*, *관리 도전*, 또는*대화 도전*.

      5. 사용자 에이전트 값 입력**사용자 에이전트**(wildcards 등)`*`지원되지 않음). 예를 들어, Bad Bot 웹 스파이더를 차단하기 위해, 입력`BadBot/1.0.2 (+http://bad.bot)`.

      6. 제품정보**저장 및 배포 차단 규칙**.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com/)계정 및 도메인을 선택하십시오.

      2. 오시는 길**보안 보안** > **사이트맵**, 그리고 선택**회사 소개**탭.

      3. 이름 \***사용자 에이전트 차단**, 선택**차단 규칙**.

      4. 규칙에 대한 설명 이름 입력**이름/설명**.

      5. 내 계&#xC815;**- 연혁**, 수행 작업을 선택:*제품정보*, *비동기 도전*, *관리 도전*, 또는*대화 도전*.

      6. 사용자 에이전트 값 입력**사용자 에이전트**(wildcards 등)`*`지원되지 않음). 예를 들어, Bad Bot 웹 스파이더를 차단하기 위해, 입력`BadBot/1.0.2 (+http://bad.bot)`.

      7. 제품정보**저장 및 배포 차단 규칙**.
    </Steps>
  </TabItem>

  <TabItem label="사이트맵">
    계정 만들기`POST`요청사항[사용자 에이전트 차단 규칙 만들기](/api/resources/firewall/subresources/ua_rules/methods/create/)다음과 같이 가동:

    <APIRequest
      path="/zones/{zone_id}/firewall/ua_rules"
      method="POST"
      json={{
  	description: "Block Bad Bot web spider",
  	mode: "block",
  	configuration: {
  		target: "ua",
  		value: "BadBot/1.0.2 (+http://bad.bot)",
  	},
  }}
    />
  </TabItem>
</Tabs>

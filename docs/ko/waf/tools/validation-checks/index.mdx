Cloudflare는 모든 요청에 대한 유효성 검사를 수행합니다. Validation 구성 요소는 사용자 정의 규칙 또는 관리 규칙과 같은 다른 모든 보안 기능을 실행합니다. Shellshock 공격과 HTTP 헤더의 특정 공격 패턴과 같은 유효성 검사 블록 변형 요청<GlossaryTooltip term="allowlist">관련 상품</GlossaryTooltip>논리가 발생합니다.

:::참조
현재 유효성 검사를 비활성화 할 수 없습니다. Cloudflare의 인프라를 초기에 실행하여 도메인의 구성이 로드 되었습니다.
주요 특징

## 유효성 검사를 위한 이벤트 로그

유효성분에 의해 수행된 행동은[샘플 로그](/waf/analytics/security-events/#sampled-logs)Security Events와 관련된`Validation`서비스 및 규칙 ID없이. API 쇼 소스에서 다운로드 된 이벤트 로그`Validation`그리고 행동으로`drop`이 행동이 발생했을 때.

다음과 같은 예제는 malformed로 인해 Validation 구성품에 의해 차단된 요청을 보여줍니다.`User-Agent`HTTP 요청 헤더:

![Sampled 로그는 유효성 검사 이벤트의 예를 표시](~/assets/images/waf/validation-service.png)

이벤트에 대한 다운로드 된 JSON 파일에서,`ruleId`값은 검출 된 문제를 나타냅니다. 이 경우 Shellshock 공격이었습니다.

```json null {3}
{
	"action": "drop",
	"ruleId": "sanity-shellshock",
	"source": "sanitycheck",
	"userAgent": "() { :;}; printf \\\\\"detection[%s]string\\\\\" \\\\\"TjcLLwVzBtLzvbN\\\\"
	//...
}
```

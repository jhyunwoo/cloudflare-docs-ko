Zone Lockdown은 도메인, 하위 도메인 또는 URL에 액세스 할 수있는 유일한 IP 인 하나 이상의 IP 주소, CIDR 범위 또는 네트워크 목록을 지정합니다. 단일 영역 잠금 규칙에서 IPv4/IPv6 주소를 포함하여 여러 목적지를 구성할 수 있습니다.

지역 lockdown 규칙에서 지정되지 않은 모든 IP 주소는 지정된 리소스에 액세스 할 수 없습니다. IP 주소의 요청은 수신됩니다.`Access Denied`응답.

:::참조

Cloudflare는 당신이 이용하는 것을 추천합니다[주문 규칙](/waf/custom-rules/)IP 주소에서 요청을 차단하는 영역 잠금 규칙 대신 IP 및 CIDR 범위의 허용 목록에 표시되지 않습니다.

이 목적을 위해 사용자 정의 규칙을 사용하는 예시에는 다음과 같은 사용 사례를 참조하십시오.

- [수당 IP 주소에서 트래픽을 허용](/waf/custom-rules/use-cases/allow-traffic-from-ips-in-allowlist/)
- [사이트 관리자 영역에서 알려진 IP 주소](/waf/custom-rules/use-cases/site-admin-only-known-ips/)

:::

## 적용분야

Cloudflare Zone Lockdown은 유료 플랜에서 사용할 수 있습니다. 그러나이 기능은 만 사용할 수 있습니다.[새로운 보안 대시보드](/security/)적어도 하나의 영역 lockdown 규칙을 구성 한 경우.

유효한 지역 lockdown 규칙의 수는 당신의 Cloudflare 계획에 달려 있습니다.

    주요 특징

    **Zone Lockdown 규칙에 액세스해야하는 경우**

    <Steps>
      1. Cloudflare 대시보드에서**보안 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/security-rules" />

      2. 제품정보**규칙 만들기** > **지역 lockdown 규칙**.<br />이 옵션을 사용할 수 없으면 아래 지침을 참조하십시오.

      3. 규칙에 대한 설명 이름 입력**이름 \***.

      4. 제품 정보**사이트 맵**, 도메인, 하위 도메인 또는 URL을 입력하여 무단 IP로부터 보호합니다. 와일드 카드를 사용할 수 있습니다.`*`. 선 당 1개의 품목을 입력하십시오.

      5. 제품 정보**IP 범위**, 하나 이상의 허용된 IPv4/IPv6 주소 또는 CIDR 범위, 선 당 하나 입력. 이 IP 주소와 범위만 입력한 리소스에 액세스할 수 있습니다.**사이트 맵**.

      6. (선택) 기존 규칙과 중복되는 영역 lockdown 규칙을 만들면 확장**고급 옵션**그리고 규칙에 대한 우선 순위를 입력**회사연혁**. 더 낮은 수, 더 높은 우선 순위. 높은 우선 순위 규칙은 우선권을 가지고.

      7. 제품정보**저장 및 배포 lockdown 규칙**.
    </Steps>

    <Steps>

      2. 제품정보**한국어**, 다음 템플릿을 선택**지정된 IP 주소만 허용**.

      3. 필요한 필드를 채우고 선택**계정 만들기**.
    </Steps>

### 예제 규칙

다음과 같은 예 규칙은 회사의 본사 또는 지점 사무소에서 연결하여 staging 환경 및 위키에 액세스 할 수 있습니다.

- 이름:

  ```txt
  Block all traffic to staging and wiki unless it comes from HQ or branch offices
  ```

- URL:

  ```txt
  staging.example.com/*
  example.com/wiki/*
  ```

- IP 범위:

  ```txt
  192.0.2.0/24
  2001:DB8::/64
  203.0.133.1
  ```

이 예제는 다른 디렉토리 경로에 위치한 내부 위키를 보호하지 않을 것입니다.`example.com/internal/wiki`.

:::참조

·[주문 규칙](/waf/custom-rules/create-dashboard/)동일한 행동으로 다음과 같은 구성이 있을 것입니다:

**이름 \***:<br />
`Block all traffic to staging and wiki unless it comes from HQ or branch offices`

**패스워드**:

```txt
((http.host eq "staging.example.com") or (http.host eq "example.com" and http.request.uri.path wildcard "/wiki/*")) and not ip.src in {192.0.2.0/24 2001:DB8::/64 203.0.133.1}
```

**- 연혁**: *제품정보*

:::

으로 invoke[API 목록](/api/resources/rules/subresources/lists/)작동, Cloudflare API 기본 URL에 엔드포인트를 추가:

`https://api.cloudflare.com/client/v4/`

인증 지침은 Cloudflare API의 참조[시작하기](/fundamentals/api/get-started/)사이트 맵

API 호출 및 paginating 결과를 만들기 위해, 참조[API 호출](/fundamentals/api/how-to/make-api-calls/).

:::참조

목록 API 엔드포인트는 값이 필요합니다.`{account_id}`.

액세스가 있는 계정 목록을 검색하려면[계정 목록](/api/resources/accounts/methods/list/)운영 및 관리하려는 계정의 ID.

:::

Lists API는 아래와 같이 운영을 지원합니다. 예를 들어 관련 링크 방문.

## 자주 묻는 질문

### 자주 묻는 질문

- **- 연혁**: [자주 묻는 질문](/api/resources/rules/subresources/lists/methods/create/)
- **방법 및 엔드포인트**: `POST accounts/{account_id}/rules/lists`
- **지원하다**: 빈 목록 만들기.

### 자주 묻는 질문

- **- 연혁**: [자주 묻는 질문](/api/resources/rules/subresources/lists/methods/list/)
- **방법 및 엔드포인트**: `GET accounts/{account_id}/rules/lists`
- **지원하다**:
  - 계정의 모든 목록.
  - 이 요청은 목록에서 항목을 fetch하지 않습니다.

### 자주 묻는 질문

- **- 연혁**: [자주 묻는 질문](/api/resources/rules/subresources/lists/methods/get/)
- **방법 및 엔드포인트**: `GET accounts/{account_id}/rules/lists/{list_id}`
- **지원하다**:
  - ID로 리스트를 입력하세요.
  - 이 요청은 목록에서 항목을 표시하지 않습니다.

### 자주 묻는 질문

- **- 연혁**: [자주 묻는 질문](/api/resources/rules/subresources/lists/methods/update/)
- **방법 및 엔드포인트**: `PUT accounts/{account_id}/rules/lists/{list_id}`
- **지원하다**:
  - 업데이트`description`이름 \*
  - 편집할 수 없습니다.`name`또는`kind`, 당신은 목록에 항목을 업데이트 할 수 없습니다. 목록에서 항목을 업데이트하려면, 사용[모든 목록 항목 업데이트](#update-all-list-items)가동.

### 자주 묻는 질문

- **- 연혁**: [자주 묻는 질문](/api/resources/rules/subresources/lists/methods/delete/)
- **방법 및 엔드포인트**: `DELETE accounts/{account_id}/rules/lists/{list_id}`
- **지원하다**: 목록 삭제, 만 없을 때[제품정보](/firewall/api/cf-filters/)참고 자료 그것.

## 자주 묻는 질문

목록에서 항목을 관리하기위한 거의 모든 작업은 비동기입니다. 대량의 품목을 추가하거나 삭제할 때 목록에서 대량 가동이 완료되기 전에 지연 될 수 있습니다.

비동기 목록 가동 반환`operation_id`, API 작업의 상태를 모니터링 할 수 있습니다. 동시 조작의 상태를 모니터링하려면, 사용[대량 가동 상태를 얻으십시오](/api/resources/rules/subresources/lists/subresources/bulk_operations/methods/get/)endpoint 및 모니터링 할 작업의 ID를 지정합니다.

목록에서 대량 작업이 진행중인 동안 목록을 요청할 때, 요청은 순서 (첫번째, 첫 번째 아웃)에 할당되고 처리됩니다. 성공적인 비동기 운영을 위한 요청은`HTTP 201`상태 코드.

### 관련 상품

- **- 연혁**: [관련 상품](/api/resources/rules/subresources/lists/subresources/items/methods/list/)
- **방법 및 엔드포인트**: `GET accounts/{account_id}/rules/lists/{list_id}/items[?search={query}]`
- **지원하다**:
  - 목록의 Fetches 항목 (모든 항목, 기본적으로).
  - 품목은 ascending 순서에서 분류됩니다.
  - IP 목록의 경우, CIDR는 IP 주소로 분류되며, 하위넷 마스크로 분류됩니다.
  - 필터 반환 항목에, 옵션 사용`search`쿼리 문자열 매개 변수. 더 많은 정보를 원하시면, 참조[관련 상품](/api/resources/rules/subresources/lists/subresources/items/methods/list/)API 가동.

### 계정 만들기

- **- 연혁**: [계정 만들기](/api/resources/rules/subresources/lists/subresources/items/methods/get/)
- **방법 및 엔드포인트**: `GET accounts/{account_id}/rules/lists/{list_id}/items/{item_id}`
- **지원하다**: ID로 리스트에서 아이템

### 관련 상품

- **- 연혁**: [관련 상품](/api/resources/rules/subresources/lists/subresources/items/methods/create/)
- **방법 및 엔드포인트**: `POST accounts/{account_id}/rules/lists/{list_id}/items`
- **지원하다**:
  - 새 아이템이나 아이템을 리스트에 추가합니다.
  - 목록에서 이미 존재하는 항목 교체, 어떤 항목을 삭제하지 않습니다.
  - 더 읽기`comment`원래 항목의.
  - 응답은 포함`operation_id`.

### 모든 목록 항목 업데이트

- **- 연혁**: [모든 목록 항목 업데이트](/api/resources/rules/subresources/lists/subresources/items/methods/update/)
- **방법 및 엔드포인트**: `PUT accounts/{account_id}/rules/lists/{list_id}/items`
- **지원하다**:
  - 목록에서 모든 현재 항목을 삭제하고 그들과 교체`items`.
  - 시간 :`items`빈, 삭제**모든 것**목록의 항목.
  - 응답은 포함`operation_id`.

### 목록 항목 삭제

- **- 연혁**: [목록 항목 삭제](/api/resources/rules/subresources/lists/subresources/items/methods/delete/)
- **방법 및 엔드포인트**: `DELETE accounts/{account_id}/rules/lists/{list_id}/items`
- **지원하다**:
  - 지정된 목록 항목을 삭제합니다.
  - 응답은 포함`operation_id`.

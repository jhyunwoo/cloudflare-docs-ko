## 객체 구조 및 속성 목록

JSON 응답[API 목록](/api/resources/rules/subresources/lists/)이 구조가 있다:

```json
{
	"id": "2c0fc9fa937b11eaa1b71c4d701ab86e",
	"name": "my_list_name",
	"description": "List description.",
	"kind": "(ip|hostname|asn|redirect)",
	"num_items": 10,
	"num_referencing_filters": 2,
	"created_on": "2021-01-01T08:00:00Z",
	"modified_on": "2021-01-10T14:00:00Z"
}
```

## 항목 객체 구조 및 속성 목록

각 목록 유형 (IP 주소, hostname, ASN, 리디렉션)은 동일한 유형의 품목을 포함할 수 있습니다.

### IP 주소

IP 주소 목록 항목에 대한 완전히 팝업 된 JSON 객체는 다음과 같은 구조가 있습니다.

```json
{
	"id": "7c5dae5552338874e5053f2534d2767a",
	"ip": "10.0.0.1/32",
	"comment": "CF DNS server",
	"created_on": "2021-10-01T05:20:00.12345Z",
	"modified_on": "2021-10-01T05:20:00.12345Z"
}
```

### 이름 \*

hostname list 항목에 대한 전체 JSON 객체는 다음과 같은 구조가 있습니다.

```json
{
	"id": "7c5dae5552338874e5053f2534d2767a",
	"hostname": {
		"url_hostname": "*.example.com"
	},
	"created_on": "2021-10-11T12:39:02Z",
	"modified_on": "2021-10-11T12:39:02Z"
}
```

### 사이트맵

ASN 목록 항목에 대한 전체 JSON 객체는 다음과 같은 구조가 있습니다.

```json
{
	"id": "7c5dae5552338874e5053f2534d2767a",
	"asn": 13335,
	"comment": "My provider's ASN",
	"created_on": "2021-10-11T12:39:02Z",
	"modified_on": "2021-10-11T12:39:02Z"
}
```

### URL 리디렉션

대량 Redirect List 항목에 대한 전체 JSON 객체는 다음과 같은 구조가 있습니다.

```json
{
	"id": "7c5dae5552338874e5053f2534d2767a",
	"redirect": {
		"source_url": "https://example.com/blog",
		"target_url": "https://example.com/blog/latest",
		"status_code": 301,
		"include_subdomains": false,
		"subpath_matching": false,
		"preserve_query_string": false,
		"preserve_path_suffix": true
	},
	"created_on": "2021-10-11T12:39:02Z",
	"modified_on": "2021-10-11T12:39:02Z"
}
```

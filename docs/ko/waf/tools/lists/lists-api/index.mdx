더 보기[API 목록](/api/resources/rules/subresources/lists/)다음과 같은 유형의 목록을 프로그래밍하기위한 인터페이스를 제공합니다:

- [주문 목록](/waf/tools/lists/custom-lists/): 참고 자료가 공동으로 참고 자료를 할 수 있도록 동일한 유형 (IP 주소 또는 호스트 이름과 같은)의 하나 이상의 문자열을 포함합니다.

- [대량 Redirect 목록](/rules/url-forwarding/bulk-redirects/concepts/#bulk-redirect-lists): 대량 Redirect Rule을 생성하여 활성화하는 URL 리디렉션을 포함합니다.

규칙 표현의 목록을 사용하려면, 참조[이름 \*](/ruleset-engine/rules-language/values/#lists)규칙 언어 문서에서.

## 시작하기

시작하기에, 목록 검토[JSON 객체](/waf/tools/lists/lists-api/json-object/)·[이름 \*](/waf/tools/lists/lists-api/endpoints/).

***

## 목록 API 요청에 대한 제한 비율

Cloudflare는 사용자 정의 목록 및 대량 리디렉트 목록에서 API 요청 생성, 수정 또는 삭제 목록 항목에 제한 비율을 적용 할 수 있습니다.

목록 항목의 각 작업 (create, edit, or delete)은 수정으로 계산합니다. 다음 제한이 적용됩니다:

- 최대 1,000,000개의 목록 항목 수정을 12시간 이상 API 요청으로 만들 수 있습니다.
- 목록 항목 수정을하는 12 시간 이상 30,000 API 요청의 최대를 만들 수 있습니다.

쓰기 작업이 여전히 처리되고있는 경우 - 비동기적으로 발생 - 당신은 새로운 요청을 제출, 당신은 받게됩니다`429`HTTP 상태 코드. 이 일이 발생하면 나중에 요청을 다시 제출하십시오.

## Expression Builder의 목록 사용

Expression Builder의 목록을 사용하려면:

<Steps>
  1. 에 의해**회사연혁**드롭다운 목록, 선택*이름 \**&#xB610;는*목록은 없습니다.*. 모든 필드가 이러한 연산자를 지원하지 않는 참고.

     ![WAF 사용자 정의 규칙의 표현을 구성 할 때 값 드롭다운 목록에서 IP 목록 선택](~/assets/images/fundamentals/lists/cf-open-proxies-list.png)

  2. 목록 선택**제품정보**드롭다운 목록. 플랜에 따라 선택할 수 있습니다.[관리 IP 목록](/waf/tools/lists/managed-lists/#managed-ip-lists).

  3. 변경을 진행하고 규칙을 활성화하려면, 선택**계정 만들기**. 규칙을 활성화 할 준비가 없다면, 선택**Draft로 저장**.
</Steps>

## Expression Editor의 목록 사용

Expression Editor의 목록을 사용하려면`in`연산자 및 사용`$<list_name>`목록의 이름을 지정합니다.

예제:

- IP 주소의 Expression matching 요청은 IP 목록에서 지정됩니다.`office_network`:

  ```txt
  ip.src in $office_network
  ```

- IP 주소와 같은 소스 IP 주소와 Expression 일치 요청`office_network`IP 목록:

  ```txt
  not ip.src in $office_network
  ```

- Cloudflare Open Proxies의 IP 주소에서 Expression matching 요청[관리 IP 목록](/waf/tools/lists/managed-lists/#managed-ip-lists):

  ```txt
  ip.src in $cf.open_proxies
  ```

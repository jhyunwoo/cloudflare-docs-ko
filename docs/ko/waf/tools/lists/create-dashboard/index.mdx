목록을 작성하려면 다음 단계를 따르십시오.

<Steps>
  1. Cloudflare 대시보드에서**계정 설정**사이트 맵

     <DashButton url="/?to=/:account/configurations" />

  2. 오시는 길**이름 \***.

  3. 제품정보**새 목록 만들기**.

  4. 목록의 이름을 입력하고, 관찰[게시판 목록](/waf/tools/lists/#list-names).

  5. (선택 사항) 목록에 대한 설명을 입력, 최대 길이 500 문자.

  6. 제품 정보**내용 유형**, 선택[이름 \*](/waf/tools/lists/custom-lists/)당신은 창조합니다.

  7. 제품정보**이름 \***.

  8. 다음 섹션에서 지침을 따르고 항목을 목록에 추가하십시오.
</Steps>

## 자주 묻는 질문

<Steps>
  1. (선택) 기존 목록에 항목을 추가하려면:
     1. 오시는 길**계정 설정**사이트 맵

        <DashButton url="/?to=/:account/configurations" />

     2. 오시는 길**이름 \***.

     3. 제품정보**제품정보**편집하려는 목록 옆에.

  2. 제품정보**관련 상품**.

  3. 으로[자주 묻는 질문](#add-items-to-a-list-manually), 사용 가능한 텍스트 입력 페이지에.

  4. 으로[CSV 파일을 사용하여 항목을 추가](#add-items-using-a-csv-file), 선택**CSV 업로드**.
</Steps>

### 자주 묻는 질문

<Steps>
  1. 내 계정**자주 묻는 질문**페이지, 다른 필드에 대한 값을 입력 (정확한 필드는 목록 유형에 따라 달라집니다).

     텍스트 입력에 정보를 입력하면 현재 표시의 새로운 행이 표시됩니다. 입력한 항목의 삭제하려면, 선택**사이트맵**.

  2. 제품정보**자주 묻는 질문**.
</Steps>

### CSV 파일로 항목 추가

CSV 파일을 업로드하여 목록을 추가하려면:

<Steps>
  1. 내 계정**자주 묻는 질문**페이지, 선택**CSV 업로드**.

  2. CSV 파일의 위치로 검색하고, 파일을 선택하고, 선택한 다음**기타**. 페이지의 표시된 항목은 CSV 파일에서 로드된 항목이 포함될 것입니다.

     정확한 CSV 파일 형식은 목록 유형에 달려 있습니다. 더 알아보기[주문 목록 유형](/waf/tools/lists/custom-lists/#custom-list-types)상세 정보

  3. 추가하기 전에 목록에서 항목을 편집 할 수 있습니다 :
     - 입력한 항목의 삭제하려면, 선택**사이트맵**.
     - 수동으로 추가하려면 텍스트 입력에 정보를 입력하십시오.

  4. 제품정보**자주 묻는 질문**.
</Steps>

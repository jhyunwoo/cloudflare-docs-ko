Cloudflare 제품의 규칙 표식에서 이름과 동일하게 항목 (IP 주소와 같은)의 그룹을 참조하는 목록을 사용합니다. 당신은 Cloudflare에 의해 관리된 당신의 자신의 주문 명부 또는 사용 명부를 창조할 수 있습니다[관리 IP 목록](/waf/tools/lists/managed-lists/#managed-ip-lists).

## 지원된 명부

Cloudflare는 다음 목록을 지원합니다:

- [주문 목록](/waf/tools/lists/custom-lists/): 사용자 정의 IP 목록, 호스트 이름 목록 및 ASN 목록을 포함합니다.
- [관리 목록](/waf/tools/lists/managed-lists/): Cloudflare에 의해 관리되고 업데이트 된 목록은 관리 IP 목록과 같습니다.

자세한 내용은 각 페이지를 참조하십시오.

:::주\[주]

- 대량 Redirects 사용[대량 Redirect 목록](/rules/url-forwarding/bulk-redirects/concepts/#bulk-redirect-lists), 규칙 문서에 포함 된 다른 유형.

- 이 페이지에서 설명된 목록은 동일하지 않습니다.[Zero Trust 목록](/cloudflare-one/reusable-components/lists/). 목록의 두 가지 유형은 다른 데이터 유형을 지원하며 목록 이름에 대해 다른 검증 규칙이 있습니다.

- 당신은 또한 사용할 수 있습니다[inline 목록](/ruleset-engine/rules-language/values/#inline-lists)규칙 표현. 인라인 목록은 직접 표현의 값 목록을 포함 할 수 있습니다. 목록에서 목록 항목을 구성 할 필요가 없지만, 항목은 표식에 하드 코딩됩니다.

:::

## 이름 \*

목록의 이름은 다음과 같은 요구 사항을 준수해야합니다.

- 이름은 저소문자, 숫자 및 밑줄만 사용합니다 (`_`) 이름의 문자. 유효한 이름은 이 정규 표현식을 satisfies:`^[a-z0-9_]+$`.
- 목록 이름의 최대 길이는 50자입니다.

## 작업 목록

### 목록 작성 및 편집

당신은 할 수[Cloudflare 대시보드의 목록 만들기](/waf/tools/lists/create-dashboard/)또는 사용[API 목록](/waf/tools/lists/lists-api/).

목록을 작성하면 목록에서 항목을 추가하고 제거 할 수 있지만 목록 이름이나 유형을 변경할 수 없습니다.

### 표현의 목록 사용

Cloudflare 대시보드와 Cloudflare API 지원 명부 둘 다:

- Cloudflare 대시보드에서 표식을 사용하려면[표현의 목록 사용](/waf/tools/lists/use-in-expressions/).
- 참고 자료에 API 표현 목록은 참조[이름 \*](/ruleset-engine/rules-language/values/#lists)규칙 언어 참고 자료에서.

:::카트로션
현재 모든 Cloudflare 제품은 표현식에서 목록을 지원합니다. 각 문서의 참조[개별 제품](/directory/)목록 지원에 대한 자세한 내용은.

### 자주 묻는 질문

대시보드 또는[API를 통해](/api/resources/rules/subresources/lists/subresources/items/methods/list/).

IP 목록의 경우, Cloudflare는 검색 쿼리를 시작 IP 주소/범위를 반환합니다 (예를 들어 검색). 현재 IP 목록의 CIDR 범위에 포함된 IP 주소를 검색할 수 없습니다.

대량 Redirect Lists의 경우, Cloudflare는 소스 URL 또는 대상 URL이 검색 쿼리를 포함하도록 목록에서 URL 리디렉션을 리디렉션합니다.

## 최종 알림

참고 자료가 목록이 없을 때만 목록을 삭제할 수 있습니다.<br />

<Render file="lists-import-notes" product="fundamentals" />

목록의 전체 내용을 대체하려면 배열로 데이터를 포맷하고 사용[모든 목록 항목 업데이트](/api/resources/rules/subresources/lists/subresources/items/methods/update/)작업 중[API 목록](/waf/tools/lists/lists-api/endpoints/).

Cloudflare 대시보드에서 CSV 형식으로 목록을 다운로드 할 수 없습니다. 목록의 내용을 다운로드해야하는 경우, 사용[관련 상품](/api/resources/rules/subresources/lists/subresources/items/methods/list/)목록 항목을 fetch하는 작업.

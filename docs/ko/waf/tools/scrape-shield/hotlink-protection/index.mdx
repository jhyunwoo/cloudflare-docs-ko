Hotlink Protection은 다른 사이트에서 사용되는 이미지를 방지하며 대역폭을 줄일 수 있습니다.[소스 서버](https://www.cloudflare.com/learning/cdn/glossary/origin-server/).

지원된 파일 확장자는`gif`, `ico`, `jpg`, `jpeg`·`png`.

## 이름 \*

Cloudflare가 귀하의 사이트에 대한 이미지 요청을받을 때, 우리는 요청이 다른 사이트에 방문자로부터 시작되지 않았다는 것을 확인. 도메인 방문객은 여전히 이미지를 다운로드하고 볼 수 있습니다.

기술적으로, 이것은 HTTP referer가 요청할 Hotlink Protection denies 접근을 의미합니다.
웹 사이트 도메인 이름을 포함하지 않습니다 (그리고 공백이 없습니다).

Hotlink 보호는 크롤링에 영향을 미치지 않지만 Google 이미지, Pinterest 및 Facebook과 같은 사이트에서 표시되는 이미지를 방지합니다.

### Cloudflare를 사용하는 SaaS 공급자

SaaS 공급자인 경우[SaaS를 위한 Cloudflare](/cloudflare-for-platforms/cloudflare-for-saas/), 주의, 기본적으로, Hotlink 보호는 당신의 지역을 참조로만 요구할 수 있습니다. 고객의 요청에 차단하기 위해 (custom hostnames), 사용 고려[구성 규칙](/rules/configuration-rules/settings/#hotlink-protection)또는[주문 규칙](/waf/custom-rules/use-cases/exempt-partners-hotlink-protection/).

## 특정 이미지에 hotlinking 허용

외부 웹 사이트 (Google과 같은) 또는 RSS 피드를 사용할 때 특정 이미지가 hotlinked 할 수 있습니다.

### 구성 규칙

선택적으로 Hotlink Protection을 비활성화하려면[구성 규칙](/rules/configuration-rules/)이미지 폴더의 경로를 덮습니다.

### hotlink-ok 디렉토리

지정된 디렉토리에 배치하여 특정 이미지를 hotlinked 할 수 있습니다.`hotlink-ok`·`hotlink-ok`디렉토리는 웹 사이트에 어디에서 배치 할 수 있습니다.

다른 웹 사이트를 허용`logo.png`이름 \*`example.com`, 칫`logo.png`새 폴더에서 호출`hotlink-ok`.

URL의 일부 예는 hotlinking에 대해 확인되지 않습니다.

- `http://example.com/hotlink-ok/pic.jpg`
- `http://example.com/images/hotlink-ok/pic.jpg`
- `http://example.com/hotlink-ok/images/pic.jpg`
- `http://example.com/images/main-site/hotlink-ok/pic.jpg`

비밀번호 체크는 기본적으로 활성화됩니다.

## Disable Browser Integrity 확인

### 글로벌 서비스

지구를 위해 전 세계적으로 BIC를 비활성화하려면:

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    <Steps>
      1. Cloudflare 대시보드에서 보안으로 이동**계정 설정**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/settings" />

      2. (선택) 필터 로**DDoS 공격**.

      3. 공지사항**브라우저 무결성 체크**.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인[Cloudflare 대시보드](https://dash.cloudflare.com).
      2. 계정과 영역을 선택하십시오.
      3. 오시는 길**보안 보안** > **계정 설정**.
      4. 공지사항**브라우저 Integrity Check**.
    </Steps>
  </TabItem>
</Tabs>

### 선택 해제

선택적으로 BIC를 비활성화하려면 브라우저 Integrity Check를 건너 뛸 수 있습니다.[건너뛰기](/waf/custom-rules/skip/).

또한, 사용[구성 규칙](/rules/configuration-rules/)필터 표현을 사용하여 웹 사이트의 특정 섹션을 선택적으로 활성화하거나 비활성화 할 수 있습니다 (예 : 일치 호스트 이름 또는 URL 경로와 같은).

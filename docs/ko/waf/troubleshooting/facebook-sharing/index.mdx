Cloudflare는 기본적으로 Facebook에서 차단하거나 도전하지 않습니다. 그러나 웹 사이트의 포스트는 Facebook에 반환*주의사항*다음 상황에서 오류 :

- 전 세계[공격 모드의 밑에 활성화](/fundamentals/reference/under-attack-mode/).
- 있습니다.[구성 규칙](/rules/configuration-rules/)또는[페이지 규칙](/rules/page-rules/)공격 모드 아래에서 설정.
- 있습니다.[주문 규칙](/waf/custom-rules/)Facebook IP 주소를 포함하는 도전 또는 차단 작업.

국가 도전은 Facebook IP 주소를 차단할 수 있습니다. Facebook은 미국과 아일랜드 모두에서 크롤러로 알려져 있습니다.

## 제품 설명

Facebook에 공유하는 문제를 해결하려면 다음 중 하나를 수행하십시오.

- 해당 IP, ASN 또는 국가 사용자 정의 규칙을 제거하여 문제 또는 Facebook IP를 차단합니다.
- 이름 \*[비밀번호](/waf/custom-rules/skip/)제품 정보<GlossaryTooltip term="autonomous system numbers (ASNs)">사이트맵</GlossaryTooltip> `AS32934`·`AS63293`(사용)*팟캐스트*동작과 룰을 설정하여 건너뛰기**보안 수준**).
- 기존 구성 규칙 및 페이지 규칙을 검토하고 Facebook IPs에서 요청에 영향을 미치지 않도록하십시오.

Facebook 공유에 문제가 있다면, 페이지를 다시 스크랩 할 수 있습니다.**Fetch 새로운 스크랩 정보**Facebook의 Object Debugger 옵션. 페이스북[API 제공](https://developers.facebook.com/docs/sharing/opengraph/using-objects)많은 리소스를 업데이트하는 데 도움이됩니다.

문제가 있는 경우,[접촉 Cloudflare 지원](/support/contacting-cloudflare-support/)Facebook에 공유 할 수없는 웹 사이트의 URL을 사용하여 URL을 재 스크램핑하고 URL을 재 스크램핑해야합니다.

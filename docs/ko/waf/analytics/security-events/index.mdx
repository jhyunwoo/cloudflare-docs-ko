Security Events를 사용하면 리뷰<GlossaryTooltip term="mitigated request">mitigated 요청</GlossaryTooltip>보안 구성을 맞춤화할 수 있습니다.

대시보드의 주요 요소는 다음과 같습니다.

- [이벤트 요약](#events-summary): 선택한 시간 동안 트래픽에 보안 이벤트의 수를 제공, 선택한 차원에 따라 그룹화 (예 : Action, Host, Country).
- [행사 일정](#events-by-service): 보안 기능별 보안 관련 활동 목록(예: WAF, API Shield)
- [소스의 최고 이벤트](#top-events-by-source): Cloudflare 보안 기능(예: IP 주소, 사용자 에이전트, 경로, 국가, 호스트, ASNs)에 의해 전달되는 트래픽의 세부 사항 제공
- [샘플 로그](#sampled-logs): 적용 가능한 Cloudflare 보안 제품을 보여주기 위해 날짜별 보안 이벤트를 요약합니다.

Security Events는 Cloudflare 보안 제품에 의해 행동 또는 조각에 관한 정보를 표시합니다.[브라우저 Integrity Check](/waf/tools/browser-integrity-check/). 각 수신 HTTP 요청은 하나 이상의 보안 이벤트를 생성할 수 있습니다. Security Events 대시보드는 HTTP 요청이 아닌이 이벤트를 보여줍니다.

### 필터 추가

수동으로 필터 상태를 입력하여 분석 범위를 조정할 수 있습니다. 대안으로, 선택**제품정보**또는**이름 \***&#xD544;드 값으로 필터링합니다. 이 버튼은 분석 데이터 전설을 hover 할 때 나타납니다.

수동으로 필터를 추가하려면:

<Steps>
  1. 제품정보**필터 추가**.
  2. 필드, 연산자 및 값을 선택합니다. 예를 들어 IP 주소로 이벤트를 필터링하려면, 선택*IP 정보*제품 정&#xBCF4;**- 연혁**, 선택*이름 \**&#xC6B4;영자의 경우 IP 주소를 입력하십시오.
  3. 제품정보**지원하다**.
</Steps>

필터 값을 입력할 때 계정으로 다음을 가져 가라:

- 값에 대한 견적을 추가하지 마십시오.
- 입력하지 마십시오`AS`ASN 번호를 입력할 때 접두사. 예를 들어, 입력`1423`대신에`AS1423`.
- Wildcards는 지원되지 않습니다.

## 샘플 로그

**샘플 로그**적용된 Cloudflare 보안 특징을 보여주기 위하여 날짜에 의하여 보안 사건을 요약하십시오.

![Sampled logs의 이벤트 목록, 이벤트 중 하나가 세부 사항을 표시하도록 확장](~/assets/images/waf/events-sampled-logs.png)

보안 이벤트는 요청에 따라 개별 이벤트로 표시됩니다. 예를 들어, 단일 요청이 세 가지 다른 보안 기능을 트리거하면 보안 이벤트는 3 개의 개별 이벤트가 표시됩니다.**샘플 로그**.

각 이벤트를 확장하여, 필터를 정의하고 이벤트의 필드 값에 따라 배정합니다. 선택하기**제품정보**또는**이름 \***&#xD45C;시된 분석의 필터 또는 exclusions 목록에 필드 값을 추가 할 필드를 hovering 할 때 버튼. JSON 형식으로 이벤트 데이터를 다운로드하려면, select**수출 이벤트 JSON**.

### 표시된 열

열을 구성하려면**샘플 로그**, 선택**열 편집**. 이것은 당신이 실행할 필요가 있는 분석의 유형에 따라서 융통성을 줍니다.

예를 들어, 봇 관련 문제를 진단하는 경우, 표시 할 수 있습니다.**회사 소개**그리고**이름 \***&#xC5F4;. 다른 한편, DDoS 공격을 식별하려고 하는 경우, 당신은 표시 할 수 있습니다**IP 주소**, **사이트맵**·**오시는 길**열.

### 이벤트 작업

대부분의 행동에 대한 자세한 내용은**샘플 로그**, 참조[관련 기사](/ruleset-engine/rules-language/actions/).

Cloudflare 보안 제품에 대한 규칙을 구성 할 때 선택할 수있는 작업 외에도 다음 관련 작업과 함께 이벤트를 찾을 수 있습니다.

- *연결 닫기*
- *힘 연결 닫기*

이 행동에 대한 자세한 내용은 참조[HTTP DDoS 공격 보호 매개 변수](/ddos-protection/managed-rulesets/http/override-parameters/#action).

더 보기[*관리 도전*](/cloudflare-challenges/challenge-types/challenge-pages/#managed-challenge)표시할 수 있는 작업**샘플 로그**다음 보안 기능 및 제품에서 사용할 수 있습니다 : WAF 사용자 정의 규칙, 제한 규칙, Bot Fight 모드, IP 액세스 규칙, 사용자 에이전트 블록 규칙 및 방화벽 규칙 (deprecated).

### 수출 이벤트 로그 데이터

최대 500의 원시 이벤트를 수출할 수 있습니다.**샘플 로그**JSON 형식으로. 별도의 시스템 또는 데이터베이스에 저장된 Cloudflare 데이터를 결합하고 분석하는 내보내기 이벤트 데이터<GlossaryTooltip term="SIEM">SIEM 시스템</GlossaryTooltip>. 당신이 수출하는 자료는 당신이 적용되는 어떤 여과기든지 반영할 것입니다.

표시된 이벤트 (최대 500)를 내보내려면, 선택**수출입**내 계정**샘플 로그**.

## 보안 이벤트 필터

필터를 추가하고 보안 이벤트에서 보고서 기간 (시간 창)을 지정할 때 Cloudflare 대시보드 URL은 구성 매개 변수를 반영합니다. 다른 사용자와 URL을 공유 할 수 있으므로 당신이 볼 동일한 정보를 분석 할 수 있습니다.

예를 들어 필터를 추가한 후`Action equals Managed Challenge`보고서 기간을 72 시간으로 설정하면 URL은 다음과 같습니다.

`https://dash.cloudflare.com/{account_id}/example.net/security/events?action=managed_challenge&time-window=4320`

## Known 제한

Security Events는 현재 이러한 제한이 있습니다.

- 보안 이벤트는 성능 향상을 위해 샘플 데이터를 사용할 수 있습니다. 검색이 사용되는 경우 샘플 데이터, 보안 이벤트는 모든 이벤트와 필터를 표시하지 않을 수 있습니다 예상 결과. 더 많은 이벤트를 표시하려면 더 작은 시간 프레임을 선택하십시오.

- Cloudflare 대시보드는 페이지 당 사건의 inaccurate 수를 보여줄지도 모릅니다. Data queries는 매우 최적화되었지만, 품질이 항상 작동하지 않을 수 있음을 의미합니다. GraphQL Analytics API는 이 질 문제점이 없습니다.

- Triggered OWASP 규칙은 보안 이벤트 페이지에서 나타납니다.**추가 로그**, 그러나 그들은 수출한 JSON 파일에서 포함되지 않습니다.

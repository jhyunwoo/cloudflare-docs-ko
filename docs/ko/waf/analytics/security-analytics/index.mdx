보안 보안 Analytics는 Cloudflare 보안 제품에 의해 처리되지 않은 요청을 포함하여 도메인에 대한 모든 수신 HTTP 요청에 대한 정보를 표시합니다.

기본적으로 Security Analytics 쿼리 필터`requestSource = 'eyeball'`최종 사용자로부터 요청을 나타냅니다. Cloudflare Workers (subrequest) 요청은 Security Analytics에서 볼 수 없습니다.

보안 분석 대시보드를 사용하여:

- 도메인에 대한 트래픽 분배보기.
- 트래픽이 Cloudflare 보안 제품에 의해 미분화되고 비 이동 트래픽이 (Cloudflare 글로벌 네트워크 또는[소스 서버](https://www.cloudflare.com/learning/cdn/glossary/origin-server/)).
- Analyze 의심스러운 트래픽을 분석하고 적용 필터를 기반으로 맞춤 WAF 맞춤 규칙을 만듭니다.
- Cloudflare의 보안 점수에 대해 자세히 알아보기 (<GlossaryTooltip term="attack score" link="/waf/detections/attack-score/">공격 점수</GlossaryTooltip>, [봇 점수](/bots/concepts/bot-score/), [악의적 인 업로드](/waf/detections/malicious-uploads/)·[새소식](/waf/detections/leaked-credentials/)결과) 실제 데이터.
- [적절한 비율 제한 찾기](/waf/rate-limiting-rules/find-rate-limit/)들어오는 교통.
- 분석 의심스러운 교통 ( Analyze suspicious traffic)[새로운 보안 대시보드](/security/)만).

이미 구성된 기존 보안 관련 규칙을 수정해야 하는 경우, 확인을 고려하십시오.[보안 이벤트](/waf/analytics/security-events/). 이 대시보드는 Cloudflare 보안 제품에 영향을 미치는 요청에 대한 정보를 표시합니다.

## 적용분야

Zone/domain-level analytics는 모든 계획과 함께 포함되지만 보존 기간, 쿼리 창, 표시된 통계 및 필터 옵션은 플랜에 따라 다릅니다. 계정 수준의 분석은 비즈니스 및 엔터프라이즈 도메인 계획에 고객에게만 사용할 수 있습니다.

### 자주 묻는 질문

메인 차트는 선택한 탭에 따라 선택한 시간 프레임의 다음 데이터를 표시합니다.

- **교통 분석**: Cloudflare 보안 플랫폼에 의해 이동, Cloudflare에 의해 제공, 다음 분류에 따라 원래 서버에 의해 제공:
  - **WAF에 의해 마이그레이션**: WAF 및 HTTP DDoS 보호와 같은 Cloudflare의 애플리케이션 보안 제품에 의해 차단되거나 도전합니다. 다음과 같은 작업을 수행 한 요청이 포함되지 않습니다.*로그인*, *팟캐스트*·*지원하다*.
  - **Cloudflare에 의해 봉사**: Cloudflare 글로벌 네트워크에 의해 캐시된 콘텐츠 및 리디렉션과 같은 요청.
  - **에 의해 봉사**: Origin 서버에서 요청합니다.

- **공격 분석**: [WAF 공격 점수](/waf/detections/attack-score/)수신 요청 분석, 분류*제품정보*, *자주 묻는 질문*, *자주 묻는 질문*, 또는*관련 기사*.

- **Bot 분석**: [봇 점수](/bots/concepts/bot-score/)수신 요청 분석, 분류*자동화*, *자동화*, *매우 인간*, 또는*인증 봇*.

- **견적문의**: 선택된 필터와 시간을 일치하는 트래픽에 대한 요청률에 대한 데이터 표시. 이 탭을 사용하여[적절한 비율 제한 찾기](/waf/rate-limiting-rules/find-rate-limit/)적용된 필터와 일치하는 들어오는 트래픽을 위해.

- **Cloudy 분석**(beta): 일반 언어를 사용하여 애플리케이션 보안에 대한 통찰력을 얻고 데이터를 방해합니다. 더 많은 정보를 원하시면, 참조[우리의 블로그 게시물](https://blog.cloudflare.com/security-analytics-ai-assistant).

또한 현재 미터에 따라 들어오는 요청을 필터링하기 위해 차트 아래의 슬라이더 도구를 사용할 수 있습니다. 이것은 predefined 세그먼트 밖에 트래픽 그룹을 필터링 할 수 있습니다.

### 로그인

보안 보안 Analytics는 선택한 시간 프레임 및 적용 필터에 대한 요청 로그를 보여줍니다. 자세한 정보와 해당 요청의 보안 분석.

기본적으로 Security Analytics는 로그 테이블의 샘플 로그를 사용합니다. 가입하면[로그 탐색](/log-explorer/), 당신은 또한 접근이 있을지도 모릅니다[이름 \*](#raw-logs).

#### 샘플 로그

이 섹션은 개별에 대한 자세한 로그 정보를 포함합니다 ([샘플링](#sampling)) 선택된 시간 구조에 있는 요구.

![Security Analytics의 샘플 로그 섹션은 추가 세부 사항으로 확장 로그 항목을 표시합니다.](~/assets/images/waf/security-analytics/security-analytics-sampled-logs.png)

표시된 정보는 다음을 포함합니다:

- 요청에 적용되는 Mitigation action
- 캐시 상태
- Origin 서버에서 Cloudflare로 리턴된 상태 코드 (캐시 미트의 경우)
- Cloudflare에 의해 반환된 상태 코드
- 요청 시 보안 점수 (attack, bot, 업로드된 콘텐츠 스캔)
- 자주 묻는 질문

이 기능은 현재 초기 액세스 단계입니다. 접근을 요청하려면 계정 팀에 문의하십시오.
주요 특징

법의학 분석을 수행 할 때 때때로 매우 짧은 시간 프레임을 선택하고 특정 요청에 따라 여러 필터를 적용합니다. 이 상황에서 주어진 시점에서 수신 요청의 더 나은 이해를 얻을 수, 당신은 요청의 전체 목록을 요구하고 단지 샘플이 필요하지 않습니다.

기본적으로 Security Analytics는 적용된 필터를 기반으로 샘플화된 로그를 보여줍니다. 특정 조건에서, 당신은 전환할 수 있습니다**회사 소개**. 이 전망은 샘플 로그 대신 선택한 시간 프레임 및 필터에 대한 모든 요청 로그를 보여줍니다. 이 시점에서 Security Analytics 페이지에 표시된 샘플 로그 수가 100 이하일 때만 볼 수 있습니다.

##### 견적 요청

샘플 로그에서 원시 로그로 전환하려면, 선택**원시 로그로 전환**이름 \***샘플 로그**. 이 옵션은 선택된 시간 프레임의 숫자가 100보다 낮을 때만 사용할 수 있습니다.

샘플 로그로 돌아가기 위해, 선택**샘플 로그로 다시 전환**.

다음 섹션은 사용자 정의 규칙에서 사용할 수있는 건너뛰기 옵션을 다룹니다.

:::참조
계정 수준에서 건너뛰기 규칙을 구성하면 해당 계정 수준에서 설정된 다른 규칙/단계에만 영향을 미칩니다. 지역 수준에서 규칙/단계를 건너려면 지역 수준에서 건너뛰기 규칙을 구성해야 합니다.
주요 특징

## 나머지 사용자 정의 규칙을 건너 (현재 규칙)

- Dashboard 옵션:**모든 나머지 사용자 정의 규칙**
- API 활동 모수:`ruleset`

현재 규칙에 남아있는 규칙을 건너.

## 연락처

- Dashboard 옵션:**모든 비율 제한 규칙**, **모든 슈퍼 봇 전투 모드 규칙**·**모든 관리 규칙**
- API 활동 모수:`phases`

하나 이상의 단계의 실행을 건너. 당신이 건너갈 수 있는 단계에 기초를 두어, 이 선택권은 효과적으로 건너뛰기 위하여 당신을 허용합니다[비율 제한 규칙](/waf/rate-limiting-rules/), [Super Bot 전투 모드 규칙](/bots/get-started/super-bot-fight-mode/), 및/또는[WAF 관리 규칙](/waf/managed-rules/).

건너뛰는 단계는 다음과 같습니다.

- `http_ratelimit`
- `http_request_sbfm`
- `http_request_firewall_managed`

더 알아보기[단계별](/ruleset-engine/about/phases/)더 많은 정보.

## 회사소개

- API 활동 모수:`products`

Ruleset Engine을 기반으로하지 않는 특정 보안 제품을 건너 뛸 수 있습니다. 건너뛰는 제품이 다음과 같습니다.

| 대시보드의 제품명                                                     | API 값           |
| ------------------------------------------------------------- | --------------- |
| [지역 Lockdown](/waf/tools/zone-lockdown/)                      | `zoneLockdown`  |
| [사용자 에이전트 차단](/waf/tools/user-agent-blocking/)                | `uaBlock`       |
| [브라우저 Integrity Check](/waf/tools/browser-integrity-check/)   | `bic`           |
| [Hotlink 보호](/waf/tools/scrape-shield/hotlink-protection/)    | `hot`           |
| [보안 수준](/waf/tools/security-level/)                           | `securityLevel` |
| [제한 규칙 (이전 버전)](/waf/reference/legacy/old-rate-limiting/)     | `rateLimit`     |
| [관리 규칙 (이전 버전)](/waf/reference/legacy/old-waf-managed-rules/) | `waf`           |

테이블의 API 값은 case-sensitive입니다.

현재 건너뛰기[Bot 전투 모드](/bots/get-started/bot-fight-mode/), 슈퍼 봇 전투 모드 (refer to[연락처](#skip-phases)).

## 나머지 사용자 정의 규칙을 건너 (현재 단계)

- 대시보드 옵션: N/A (현재 API를 통해 사용 가능)
- API 활동 모수:`phase`

현재 단계의 나머지 규칙을 건너. 사용자 정의 규칙 (지역 수준에서)에 사용되는 경우, 그것은 사용자 정의 규칙에 남아있는 규칙에 대한 모든 규칙을 건너 뛰고, 나중에 규칙은 사용자 정의 규칙을 실행하는 항목 포인트 규칙에 규칙을 정의했다.

현재이 옵션은 영역 수준에서만 사용할 수 있습니다.`http_request_firewall_custom`단계. 사용자 정의 규칙이나 항목 포인트 규칙에 사용할 수 있습니다.

## 기타 옵션

### 건너뛰기

- Dashboard 옵션:**로그 매칭 요청**
- API 활동 모수:`logging` > `enabled`(선택 불린)

Cloudflare는 현재 건너뛰기 규칙과 일치하는 모든 요청을 기록하지 않을 때, 이 요청은 나타나지 않습니다[보안 이벤트](/waf/analytics/security-events/).

API에서 이 옵션을 지정하지 않으면 기본값은`true`건너뛰기 행동을 가진 사용자 정의 규칙을 위해 (스위스 규칙과 일치하는 것과 같이).

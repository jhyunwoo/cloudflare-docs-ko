사용 방법*팟캐스트*사용자 정의 규칙에서 하나 이상의 보안 기능을 건너뛰기. 정의된 규칙*팟캐스트*행동은 또한 Skip 규칙으로 알려져있다.

사용 가능한 옵션에 대한 자세한 내용은 참조[옵션 선택](/waf/custom-rules/skip/options/).

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    <Steps>
      1. Cloudflare 대시보드에서**보안 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/security-rules" />

      2. [사용자 정의 규칙 만들기](/waf/custom-rules/create-dashboard/)선택하기**규칙 만들기** > **주문 규칙**, 또는 기존 사용자 정의 규칙을 편집합니다.

      3. 규칙 이름과 규칙 표현을 정의합니다.

      4. 이름 \***자주 묻는 질문**, 선택*팟캐스트*드롭다운에서.

         ![사용자 정의 규칙을 구성 할 때 사용 가능한 Skip action options](~/assets/images/waf/custom-rules/skip-action-options.png)

      5. 원하는 구성[옵션 정보](/waf/custom-rules/skip/options/).

      6. 당신의 변화를 저장하십시오.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com), 귀하의 계정과 도메인을 선택합니다.

      2. 오시는 길**보안 보안** > **사이트맵** > **주문 규칙**.

      3. [사용자 정의 규칙 만들기](/waf/custom-rules/create-dashboard/)선택하기**규칙 만들기**, 또는 기존 사용자 정의 규칙을 편집합니다.

      4. 규칙 이름과 규칙 표현을 정의합니다.

      5. 이름 \***자주 묻는 질문**, 선택*팟캐스트*드롭다운에서.

         ![사용자 정의 규칙을 구성 할 때 사용 가능한 Skip action options](~/assets/images/waf/custom-rules/skip-action-options.png)

      6. 원하는 구성[옵션 정보](/waf/custom-rules/skip/options/).

      7. 당신의 변화를 저장하십시오.
    </Steps>
  </TabItem>

  <TabItem label="사이트맵">
    사용 방법[규칙 세트 API](/ruleset-engine/rulesets-api/)API를 통해 사용자 정의 규칙을 구성합니다.

    더 알아보기[API 예제](/waf/custom-rules/skip/api-examples/)Skip 규칙을 만들기위한 예.
  </TabItem>
</Tabs>

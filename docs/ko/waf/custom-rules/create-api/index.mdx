사용 방법[규칙 세트 API](/ruleset-engine/rulesets-api/)영역 수준에서 API를 통해 사용자 정의 규칙을 만듭니다.

사용자 정의 규칙을 배포해야합니다.`http_request_firewall_custom` [단계 항목 점 규칙](/ruleset-engine/about/rulesets/#entry-point-ruleset).

Terraform을 사용하는 경우, 참조[WAF Terraform을 사용하여 사용자 정의 규칙 구성](/terraform/additional-configurations/waf-custom-rules/).

## 사용자 정의 규칙 만들기

<Render
  file="api-generic-create-rule-procedure"
  product="waf"
  params={{
  	ruleType: "custom rule",
  	extraObject: "",
  	phaseName: "http_request_firewall_custom",
  }}
/>

### 예제 A

이 예제 요청은 규칙을 추가합니다.`http_request_firewall_custom`ID를 가진 지역을 위한 단계 입장 점 통치자`$ZONE_ID`. 항목 포인트 규칙은 이미 존재하며 ID`$RULESET_ID`.

규칙에 마지막 규칙이 될 새로운 규칙은 영국 또는 프랑스에서 요청을 도전합니다.<GlossaryTooltip term="attack score">공격 점수</GlossaryTooltip>더 낮은`20`.

<APIRequest
  path="/zones/{zone_id}/rulesets/{ruleset_id}/rules"
  method="POST"
  json={{
  	description: "My custom rule",
  	expression:
  		'(ip.src.country eq "GB" or ip.src.country eq "FR") and cf.waf.score lt 20',
  	action: "challenge",
  }}
  roles={false}
/>

<Render file="api-create-ruleset-with-rule" product="waf" />

### 예제 B

이 예제 요청은 규칙을 추가합니다.`http_request_firewall_custom`ID를 가진 지역을 위한 단계 입장 점 통치자`$ZONE_ID`. 항목 포인트 규칙은 이미 존재하며 ID`$RULESET_ID`.

규칙에 마지막 규칙이 될 새로운 규칙은 규칙의 정의를 포함[주문 응답](/waf/custom-rules/create-dashboard/#configure-a-custom-response-for-blocked-requests)차단된 요청을 위해.

<APIRequest
  path="/zones/{zone_id}/rulesets/{ruleset_id}/rules"
  method="POST"
  json={{
  	description: "My custom rule with plain text response",
  	expression:
  		'(ip.src.country eq "GB" or ip.src.country eq "FR") and cf.waf.score lt 20',
  	action: "block",
  	action_parameters: {
  		response: {
  			status_code: 403,
  			content: "Your request was blocked.",
  			content_type: "text/plain",
  		},
  	},
  }}
  code={{
  	mark: [{ range: "9-13" }],
  }}
  roles={false}
/>

<Render file="api-create-ruleset-with-rule" product="waf" />

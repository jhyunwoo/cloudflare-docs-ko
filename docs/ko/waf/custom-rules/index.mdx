## 주문 규칙

1개 이상의 영역에 적용되는 사용자 정의 규칙의 세트를 정의하려면 사용[주문 규칙](/waf/account/custom-rulesets/). 지역 수준에서, 모든 고객은 주문 규칙을 창조하고 배치할 수 있습니다. 계정 수준에서 사용자 정의 규칙은 유료 애드온과 엔터프라이즈 플랜을 요구합니다.

:::참조
현재 Cloudflare 대시보드는 영역 수준에서 사용자 정의 규칙과 함께 작동하지 않습니다. 당신은 필요[Cloudflare API 사용](/waf/custom-rules/create-api/)이 규칙을 구성하거나 배포합니다.

## 적용분야

<FeatureTable id="security.waf_c_custom_rules" />

사용자 정의 규칙의 최대 수는 전체에 적용됩니다.[단계별](/ruleset-engine/about/phases/). 각 범위 (zone 또는 계정)에는 다음과 같은 방법으로 계산 된 별도의 최대 규칙이 있습니다.

- Zone: 모든 사용자 정의 규칙과 영역 수준에서 정의된 사용자 정의 규칙의 모든 규칙.
- 계정: 계정 수준에서 정의된 사용자 정의 규칙의 모든 규칙.

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 대시보드" icon="rocket">
    <Steps>
      1. Cloudflare 대시보드에서**보안 규칙**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/security-rules" />

      2. 새로운 빈 규칙을 만들기 위해, 선택**규칙 만들기** > **주문 규칙**. 기존 규칙을 복제하려면 다음 세 가지 점을 선택하십시오 >**기타 제품**.

      3. <a id="rule-form" />

         규칙에 대한 설명 이름 입력**규칙 이름**.

         ![Cloudflare 대시보드](~/assets/images/waf/custom-rules/firewall-custom-rule-create.png)

      4. 이름 \***수신 요청 일치**, 사용**제품정보**드롭다운 목록은 HTTP 속성을 선택합니다. 각 요청에 대해 선택한 속성의 값**제품정보**지정한 값에 비해**제품정보**선택된 연산자를 사용하여**회사연혁**.

      5. 이름 \***다음 작업을 수행**, 규칙 작업을 선택**자주 묻는 질문**드롭다운. 예를 들어, 선택*제품정보*Cloudflare가 지정된 조건과 일치하지 않는 요청을 거부합니다.

      6. (선택) 선택한 경우*제품정보*활동, 당신은 할 수 있습니다[사용자 지정 응답 구성](#configure-a-custom-response-for-blocked-requests).

      7. 규칙을 저장하고 배포하려면, 선택**계정 만들기**. 규칙을 배포 할 준비가 없다면, 선택**Draft로 저장**.
    </Steps>
  </TabItem>

  <TabItem label="오래된 대시보드">
    <Steps>
      1. 로그인하기[Cloudflare 대시보드](https://dash.cloudflare.com), 귀하의 계정과 도메인을 선택합니다.

      2. 오시는 길**보안 보안** > **사이트맵** > **주문 규칙**.

      3. 새로운 빈 규칙을 만들기 위해, 선택**규칙 만들기**. 기존 규칙을 복제하려면 다음 세 가지 점을 선택하십시오 >**기타 제품**.

      4. 규칙에 대한 설명 이름 입력**규칙 이름**.

         ![Cloudflare 대시보드](~/assets/images/waf/custom-rules/firewall-custom-rule-create.png)

      5. 이름 \***수신 요청 일치**, 사용**제품정보**드롭다운 목록은 HTTP 속성을 선택합니다. 각 요청에 대해 선택한 속성의 값**제품정보**지정한 값에 비해**제품정보**선택된 연산자를 사용하여**회사연혁**.

      6. 이름 \***다음 작업을 수행**, 규칙 작업을 선택**자주 묻는 질문**드롭다운. 예를 들어, 선택*제품정보*Cloudflare가 지정된 조건과 일치하지 않는 요청을 거부합니다.

      7. (선택) 선택한 경우*제품정보*활동, 당신은 할 수 있습니다[사용자 지정 응답 구성](#configure-a-custom-response-for-blocked-requests).

      8. 규칙을 저장하고 배포하려면, 선택**계정 만들기**. 규칙을 배포 할 준비가 없다면, 선택**Draft로 저장**.
    </Steps>
  </TabItem>
</Tabs>

사용할 때[Cloudflare 핫 링크 보호](/waf/tools/scrape-shield/hotlink-protection/)도메인 또는 영역의 일부가 아닌 모든 HTTP referrers를 차단합니다. 그것은 당신이 당신의 자산에 인라인 링크를 사용할 수있는 파트너를 허용하는 경우 문제를 제시합니다.

## 사용자 정의 규칙을 사용하여 파트너로부터 요청을 허용

사용자 정의 규칙을 사용하여 Hotlinking에 대해 보호하고 파트너로부터 인라인 링크를 허용 할 수 있습니다. 이 경우 비활성화해야합니다.[Hotlink 보호](/waf/tools/scrape-shield/hotlink-protection/)그래서 파트너 추천은 그 기능에 의해 차단되지 않습니다.

이 예제 사용자 정의 규칙은[`http.referer`](/ruleset-engine/rules-language/fields/reference/http.referer/)파트너 사이트에서 HTTP 참조를 대상으로합니다.

더 보기`not`운영자는 파트너 사이트가 아닌 HTTP 참조를 일치하고, 그 동작은 다음과 같습니다.

- **패스워드**: `not (http.referer contains "example.com" or http.referer eq "www.example.net" or http.referer eq "www.cloudflare.com")`
- **- 연혁**: *제품정보*

## Configuration Rule을 사용하여 파트너로부터 요청을 허용

대안으로, 당신은 할 수 있습니다[설정 규칙 만들기](/rules/configuration-rules/create-dashboard/)Hotlink Protection의 파트너 사이트에서 HTTP 참조를 제외합니다. 이 경우 Hotlink Protection 기능을 사용할 수 있습니다.

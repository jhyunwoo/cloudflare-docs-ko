기본적으로 Cloudflare는 요청에 따라[다른 HTTP 포트 수](/fundamentals/reference/network-ports/).

HTTP 포트를 기반으로 요청할 수 있습니다.[`cf.edge.server_port`](/ruleset-engine/rules-language/fields/reference/cf.edge.server_port/)이름 \* 사용 방법`in` [비교 연산자](/ruleset-engine/rules-language/operators/#comparison-operators)항구의 세트를 표적으로 하기 위하여.

이 예제 사용자 정의 규칙 블록 요청`www.example.com`포트에 있지 않다`80`또는`443`:

- **패스워드**: `(http.host eq "www.example.com" and not cf.edge.server_port in {80 443})`
- **- 연혁**: *제품정보*

:::노트\[오픈 서버 포트 및 차단 트래픽]

<Render file="open-ports-blocked-traffic" product="waf" />

사용자 정의 규칙과 WAF 관리 규칙은 애플리케이션 레이어에서 트래픽을 차단할 수 있습니다 (레이어 7 in[OSI 모델](https://www.cloudflare.com/learning/ddos/glossary/open-systems-interconnection-model-osi/)), HTTP/HTTPS 요청을 비표준 포트에 전달하는 소스 서버.

:::

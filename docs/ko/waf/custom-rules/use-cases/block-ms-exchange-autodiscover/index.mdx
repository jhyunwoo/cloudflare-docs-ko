일부 경우 Microsoft Exchange Autodiscover 서비스 요청은 "noisy", 큰 숫자를 트리거 할 수 있습니다.`HTTP 404` (`Not found`) 오류.

이 예제 사용자 정의 규칙 블록 요청`autodiscover.xml`·`autodiscover.src`:

- **패스워드**: `(ends_with(http.request.uri.path, "/autodiscover.xml") or ends_with(http.request.uri.path, "/autodiscover.src"))`
- **- 연혁**: *제품정보*

대안으로, 사업 또는 기업 계획에 고객은 사용할 수 있습니다`matches` [비교 연산자](/ruleset-engine/rules-language/operators/#comparison-operators)같은 목적을 위해. 이 예제의 표현은 다음과 같습니다.

```txt
(http.request.uri.path matches "/autodiscover.(xml|src)$")
```

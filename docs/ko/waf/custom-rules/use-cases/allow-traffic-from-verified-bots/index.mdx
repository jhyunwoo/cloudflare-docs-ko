이 예제 사용자 정의 규칙은 국가 목록에서 요청하지만, Googlebot 및 Bingbot과 같은 검색 엔진 봇에서 트래픽을 허용 - 다른 곳에서[검증된 봇](/bots/concepts/bot/verified-bots/).

규칙 표현은[`cf.client.bot`](/ruleset-engine/rules-language/fields/reference/cf.client.bot/)요청이 알려진 좋은 봇 또는 크롤러에서 시작된 경우를 결정하는 필드.

- **패스워드**: `(ip.src.country in {"US" "MX"} and not cf.client.bot)`
- **- 연혁**: *관리 도전*

더 보기[공격 점수](/waf/detections/attack-score/)알려진 공격과 악의적 인 페이로드의 변화를 식별하는 데 도움이됩니다.

이 예 사용자 정의 규칙 블록 요청 국가 코드 (국가 코드)[ISO 3166-1 알파 2](https://www.iso.org/obp/ui/#search/code/)형식), 20 미만의 공격 점수와 요청에 따라. 더 많은 정보를 원하시면, 참조[WAF 공격 점수](/waf/detections/attack-score/).

- **패스워드**: `(ip.src.country in {"CN" "TW" "US" "GB"} and cf.waf.score lt 20)`
- **- 연혁**: *제품정보*

이 예제는 IP 주소에서 수신 된 요청을 차단하여 허용 목록에서 제시되지 않습니다 (을 사용하여 정의 됨)[IP 목록](/waf/tools/lists/custom-lists/#ip-lists)).

<Steps>
  1. [IP 목록 만들기](/waf/tools/lists/create-dashboard/)접속을 허용하려는 IP 주소로.<br />예를 들어, 지정된 IP 목록 만들기`allowed_ips`하나 이상의 IP 주소로. 허용되는 IP 주소 형식에 대한 자세한 내용은 참조[IP 목록](/waf/tools/lists/custom-lists/#ip-lists).

  2. [사용자 정의 규칙 만들기](/waf/custom-rules/create-dashboard/)IPs에서 어떤 요청을 차단하지 않은 목록에서 생성 (`allowed_ips`현재 예).
     - **수신 요청 일치**:

       | 제품정보     | 회사연혁      | 제품정보          |
       | -------- | --------- | ------------- |
       | IP 근원 주소 | 목록은 없습니다. | `allowed_ips` |

       Expression Editor를 사용하는 경우:<br />
       `(not ip.src in $allowed_ips)`

     - **- 연혁**: *제품정보*

  3. (선택 사항) 특정 URI 경로 만 차단하지 않는 IP와 같은 추가 필터로 표현을 업데이트하십시오.

     | 제품정보     | 회사연혁      | 제품정보          |       |
     | -------- | --------- | ------------- | ----- |
     | IP 근원 주소 | 목록은 없습니다. | `allowed_ips` | 이름 \* |
     | URI 경로   | 와일드카드     | `/admin/*`    |       |

     Expression Editor를 사용하는 경우:<br />
     `(not ip.src in $allowed_ips and http.request.uri.path wildcard "/admin/*")`
</Steps>

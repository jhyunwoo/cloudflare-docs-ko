이 예 사용자 정의 규칙 블록 요청에 따라 국가 코드 사용[`ip.src.country`](/ruleset-engine/rules-language/fields/reference/ip.src.country/)필드, 두 국가에서만 요청 가능: 미국과 멕시코.

- **패스워드**: `(not ip.src.country in {"US" "MX"})`
- **- 연혁**: *제품정보*

사용자 정의 규칙을 조정할 수 있습니다 고객 또는 파트너에 의해 액세스 증가.

Potential 예제는 다음과 같습니다.

- API를 위한 제한 비율 제거
- 브랜드 자산 및 마케팅 자료 공유

:::카트로션
이 페이지의 예 사용자 정의 규칙은 Cloudflare의 보안 기능을 우회하고 일반적으로 권장되지 않습니다. caution와 사용.
주요 특징

## 사용자 정의 규칙에서 ASN 사용

고객 또는 파트너가 충분히 크면 사용자 정의 규칙을 설정할 수 있습니다.[자율 시스템 번호 (ASN)](https://www.cloudflare.com/learning/network-layer/what-is-an-autonomous-system/).

### ASN의 트래픽 허용

이 예제는:

- 더 보기[`ip.src.asnum`](/ruleset-engine/rules-language/fields/reference/ip.src.asnum/)일반 지역을 지정합니다.
- 더 보기[`cf.bot_management.score`](/ruleset-engine/rules-language/fields/reference/cf.bot_management.score/)파트너 트래픽을 보장하는 필드는 봇에서 올 수 없습니다.

예제 사용자 정의 규칙 :

- **패스워드**: `(ip.src.asnum eq 64496 and cf.bot_management.score gt 30)`
- **- 연혁**: *건너뛰기:*
  - *모든 나머지 사용자 정의 규칙*

:::참조
오시는 길[Bot 관리](/bots/plans/bm-subscription/)Cloudflare Enterprise 플랜이 필요합니다.
주요 특징

### ASN에 의해 규칙을 조정하십시오

이 예제 사용자 정의 규칙 용도 :

- 더 보기[`ip.src.asnum`](/ruleset-engine/rules-language/fields/reference/ip.src.asnum/)일반 지역을 지정합니다.
- 더 보기[`cf.bot_management.score`](/ruleset-engine/rules-language/fields/reference/cf.bot_management.score/)요청이 인간에게서 오는지 확인하는 분야.

요청이 이러한 기준을 충족하는 경우, 사용자 정의 규칙은 건너 뛸 것입니다[사용자 에이전트 차단](/waf/tools/user-agent-blocking/)이름 \*

- **패스워드**: `(ip.src.asnum eq 64496 and cf.bot_management.score gt 50)`
- **- 연혁**: *건너뛰기:*
  - *사용자 에이전트 차단*

## 사용자 정의 규칙의 IP 주소 사용

작은 조직의 경우 IP 주소에 따라 사용자 정의 규칙을 설정할 수 있습니다.

### IP 주소로 트래픽 허용

이 예제:

- 소스 IP 주소와 호스트를 지정합니다.
- 사용 방법[`cf.bot_management.score`](/ruleset-engine/rules-language/fields/reference/cf.bot_management.score/)요청을 보장하기 위해 필드는 높은 위험이 없습니다.

예제 사용자 정의 규칙 :

- **패스워드**: `(ip.src eq 203.0.113.1 and http.host eq "example.com" and cf.bot_management.score gt 30)`
- **- 연혁**: *건너뛰기:*
  - *모든 나머지 사용자 정의 규칙*

### IP 주소로 규칙을 조정하십시오

이 예제 사용자 정의는 소스 IP 주소와 호스트를 지정합니다.

요청이 이러한 기준을 충족하는 경우, 사용자 정의 규칙은 건너 뛸 것입니다[비율 제한 규칙](/waf/rate-limiting-rules/).

- **패스워드**: `(ip.src eq 203.0.113.1 and http.host eq "example.com")`
- **- 연혁**: *건너뛰기:*
  - *모든 나머지 사용자 정의 규칙*

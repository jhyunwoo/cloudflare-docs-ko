JSON Web Token (JWT) 내부 청구를 사용하려면 먼저 설정해야합니다.[토큰 검증 구성](/api-shield/security/jwt-validation/api/)API Shield에.
주요 특징

이 예제는 JSON Web Token (JWT)을 사용하여 요청에 대한 추가 보호를 구성합니다.`admin`, 요청에 따라[공격 점수](/waf/detections/attack-score/).

JWT에 대한 사용자 주장이 관리 된 과제를 해결하는 사용자 정의 규칙을 만듭니다.`admin`공격 점수는 40 이하입니다.

- **패스워드**: `(lookup_json_string(http.request.jwt.claims["<TOKEN_CONFIGURATION_ID>"][0], "user") eq "admin" and cf.waf.score < 40)`
- **- 연혁**: *관리 도전*

이 예제에서,`<TOKEN_CONFIGURATION_ID>`이름 \*[토큰 구성 ID](/api-shield/security/jwt-validation/api/)JWT 유효성 검사에서 발견`user`JWT 청구입니다.

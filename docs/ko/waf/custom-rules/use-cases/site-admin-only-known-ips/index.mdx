웹 사이트의 관리 영역을 손상하면 결과가 심각 할 수 있습니다. 사용자 정의 규칙으로 알려진 IP 주소에서 온 관리자 경로에 대한 액세스를 차단하여 사이트의 관리자 영역을 보호 할 수 있습니다.

이 예제[주문 규칙](/waf/custom-rules/create-dashboard/)WordPress 관리자 영역에 대한 제한 액세스,`/wp-admin/`IP 주소의 지정된 설정에서 시작하지 않는 요청을 차단함으로써:

- **수신 요청 일치**:

  | 제품정보     | 회사연혁  | 제품정보                           |       |
  | -------- | ----- | ------------------------------ | ----- |
  | IP 근원 주소 | 없습니다. | `10.20.30.40` `192.168.1.0/24` | 이름 \* |
  | URI 경로   | 와일드카드 | `/wp-admin/*`                  |       |

  Expression Editor를 사용하는 경우:<br />
  `(not ip.src in {10.20.30.40 192.168.1.0/24} and http.request.uri.path wildcard "/wp-admin/*")`

- **- 연혁**: *제품정보*

Workers VPC와 관련된 문제 해결 및 디버그 오류.

## 연결 오류

Workers VPC는 Cloudflare 갱도를 통해서 개인적인 서비스에 연결될 때 런타임에 과실을 돌려보낼지도 모릅니다.

### 터널 오류

| 오류 메시지                         | 이름 \*                                                                                                                                                                                                                               | 자주 묻는 질문                                                                                                                                                                                                  |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Error: ProxyError: dns_error` | DNS 해상도는 터널을 통해 개인 서비스에 연결할 때 실패했습니다.                                                                                                                                                                                               | 이 오류가 발생할 수 있습니다.`cloudflared`버전이 출력되었습니다. 실행 중`cloudflared`버전 2025.7.0 이상 (최신 버전 권장). 이름 \*[Cloudflare 터널 업데이트 지침](/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/update-cloudflared/). |
| `Error: ProxyError: dns_error` | 모델 번호: Cloudflare 터널을 구성할 수 있습니다.`http2`프로토콜 (`TUNNEL_TRANSPORT_PROTOCOL:http2`), Cloudflare Zero Trust를 위해 작동하는[(주의 사항)](/workers-vpc/configuration/tunnel/#create-and-run-tunnel-cloudflared)트래픽하지만 Workers VPC에서 DNS 해상도를 방지합니다. | Workers VPC는 Cloudflare를 요구합니다 터널을 사용하여 연결[QUIC 수송 의정서](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/run-parameters/#protocol). 포트 7844에 아웃바운드 UDP 트래픽이 방화벽을 통해 허용됩니다.         |
| VPC 내에서 숙박하지 않는 요청             | Worker 요청 사용`.fetch()`public hostname은 VPC 서비스로 구성된 호스트 이름에 VPC를 routing한다.                                                                                                                                                         | Worker 코드와 VPC 서비스 사용은 백엔드 서비스에 대한 내부 VPC 호스트 이름, 공개 호스트 이름.                                                                                                                                              |

## 제출 오류

dashboardXQ 또는 WranglerXQ를 통해 VPC 서비스 및 터널을 볼 수 없으면 사용자가 필요한 역할을 보장합니다.

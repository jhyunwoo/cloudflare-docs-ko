## Recommend

생산 사용 사례를 위해 다음과 같은 기본 구성을 권장합니다.

- 네트워크 위치 당 두 개의 전용 호스트 기계에 클라우드 복제를 실행합니다. 두 호스트를 사용하여 서버 측 중복이 가능합니다. 이름 \*[터널 가용성 및 복제](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-availability/)설정 지침.
- 크기 최소 4GB RAM 및 4 CPU 코어와 각 호스트.

이 설정은 일반적으로 작은 중간 크기의 응용에서 트래픽을 처리하는 것이 충분합니다. Cloudflared에 의해 사용 된 자원의 실제 금액은 초당 요청 수, 대역폭, 네트워크 경로 및 하드웨어를 포함하여 많은 변수에 따라 달라집니다. 기존 터널 용량을 넘어 사용량이 증가하는 경우, 클라우드 플레어드 호스트에 할당된 하드웨어를 증가시켜 터널을 확장할 수 있습니다.

## 용량 계산기

배치에 대한 터널 용량 요구 사항을 추정하려면, 참조[Zero Trust 문서의 터널 용량 계산기](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-availability/system-requirements/).

## 확장 고려사항

갱도 성과와 가늠자를 그러므로 감시하십시오:

- **CPU 활용**: 70% 평균 사용량 이하 유지
- **메모리 사용**: 교통 스파이크를위한 헤드룸 유지
- **네트워크 대역폭**: 피크 부하를 위한 적절한 처리량
- **연결 수**: 용량 제한에 접근 할 때 수직으로 확장

Workers VPC는 Workers를 외부 구름 (AWS, Azure, GCP, 온프레미스, 등)에 있는 당신의 개인 APIs 그리고 서비스에 당신의 WorkersXQ를, 공중 인터넷에서 접근하지 않는 것을 허용합니다.

Workers VPC로, 당신은 구성할 수 있습니다[Cloudflare 갱도](/cloudflare-one/networks/connectors/cloudflare-tunnel/)보안을 설정하려면 개인 네트워크에서 Cloudflare에 개인 연결. 그런 다음 구성할 수 있습니다.[VPC 서비스](/workers-vpc/configuration/vpc-services/)외부 개인 네트워크의 각 서비스에 대해 연결하고, 사용[VPC 서비스 바인딩](/workers-vpc/api/)Workers에서 연결하십시오.

:::참조

QXQX0010XQVPC는 현재 베타에 있습니다. 특징 및 API는 일반적인 가용성의 앞에 변화할지도 모릅니다. 베타에서, Workers VPC는 모든 Workers 계획에 무료로 사용할 수 있습니다.

:::

## 사용 사례

### Workers 신청에서 개인 API 접근

Workers에 API 또는 전체 스택 응용 프로그램을 배포하여 개인 인증 서비스, CMS 시스템, 내부 API 등과 연결됩니다. Workers 응용 프로그램은 전 세계적으로 개인 네트워크의 백엔드 서비스에 최적화된 액세스를 제공합니다.

### API 게이트웨이

URL 경로에 따라 개인 네트워크의 내부 microservices에 경로 요청. Workers에 여러 개인 서비스에 대한 액세스 제어 및 부하 균형을 구분합니다.

### 내부 장식품, 대리인, dashboards

여러 개인 서비스에서 데이터를 집계하는 직원 모니터링 및 MCP 서버. 통합된 dashboards, 관리 패널 및 내부 도구를 사용하여 백엔드 시스템을 탐험하십시오.

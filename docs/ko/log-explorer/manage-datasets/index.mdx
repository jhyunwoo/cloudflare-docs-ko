## Log Explorer 활성화

Log Explorer가 로그 저장을 시작하려면 원하는 데이터세트를 활성화해야 합니다. 대시보드 또는 API를 통해 이를 수행할 수 있습니다.

1. Cloudflare 대시보드에서 **Log Explorer** > **Manage datasets** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/log-explorer/manage-sources" />

2. **Add dataset**을 선택하여 쿼리하려는 데이터세트를 선택합니다.
3. 데이터세트를 선택한 다음 영역을 선택합니다. 그런 다음 **Add**를 선택합니다. 이 페이지로 언제든 다시 돌아와 더 많은 데이터세트를 활성화하거나 기존 데이터세트를 관리할 수 있습니다.

:::note
로그를 쿼리할 수 있게 되기까지 몇 분 정도 걸릴 수 있습니다.
:::

API를 사용하는 경우 저장하려는 각 데이터세트에 대해 Log Explorer API를 사용해 Log Explorer를 활성화하세요. 로그 스트림이 활성화된 후 로그를 볼 수 있게 되기까지 몇 분 정도 걸릴 수 있습니다.

다음 `curl` 명령은 영역 수준 데이터세트 `http_requests`를 활성화하는 예시이며, 명령이 성공했을 때 예상되는 응답도 함께 보여줍니다.

```bash
curl https://api.cloudflare.com/client/v4/zones/{zone_id}/logs/explorer/datasets \
--header "Authorization: Bearer <API_TOKEN>" \
--json '{
  "dataset": "http_requests"
}'
```

```json output
{
	"result": {
		"dataset": "http_requests",
		"object_type": "zone",
		"object_id": "<ZONE ID>",
		"created_at": "2025-06-03T14:33:16Z",
		"updated_at": "2025-06-03T14:33:16Z",
		"dataset_id": "01973635f7e273a1964a02f4d4502499",
		"enabled": true
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

계정 수준 데이터세트를 활성화하려면 `curl` 명령에서 `zones/{zone_id}`를 `accounts/{account_id}`로 바꾸세요. 예를 들면 다음과 같습니다.

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/logs/explorer/datasets \
--header "Authorization: Bearer <API_TOKEN>" \
--json '{
  "dataset": "access_requests"
}'
```

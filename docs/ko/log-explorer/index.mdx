<Description>
Cloudflare 로그를 Cloudflare 대시보드나 API에서 직접 저장하고 탐색하세요.
</Description>

Log Explorer는 Cloudflare의 기본 관측성과 포렌식 제품으로, 보안 팀과 개발자가 로그를 서드파티 도구로 전달하는 데 따르는 비용과 복잡성 없이 Cloudflare 대시보드에서 직접 문제를 분석, 조사, 모니터링할 수 있도록 지원합니다.

Log Explorer는 Cloudflare 플랫폼 내부에서 사용할 수 있는 모든 맥락과 함께 Cloudflare 로그에 대한 액세스를 제공합니다. 맞춤형 대시보드로 보안 및 성능 문제를 모니터링하거나 로그 검색으로 문제를 조사하고 해결할 수 있습니다. 주요 이점은 다음과 같습니다.

- **비용과 복잡성 감소**: 외부 도구로 수 테라바이트 규모의 로그 데이터를 전달, 저장, 분석하는 데 필요한 비용과 운영 오버헤드를 크게 줄일 수 있습니다.
- **더 빠른 탐지와 초기 대응**: Cloudflare 고유 로그에 직접 접근하여 번거로운 데이터 파이프라인과 중요한 보안 인사이트를 지연시키는 수집 지연을 없앨 수 있습니다.
- **완전한 맥락을 바탕으로 조사 가속화**: Cloudflare의 탁월한 맥락 데이터를 사용해 사고를 조사함으로써 "정확히 무슨 일이 일어났는가?"와 "어떻게 일어났는가?"에 대한 분석과 이해를 더 빠르게 진행할 수 있습니다.
- **최소한의 복구 시간**: Cloudflare 플랫폼의 직접적인 완화 기능을 통해 조사에서 대응으로 매끄럽게 전환할 수 있습니다.

계약 고객은 월 GB당 $0.10의 추가 비용으로 최대 2년 동안 Log Explorer에 로그를 저장할 수 있습니다. 이 기능에 관심이 있는 고객은 계정 팀에 문의하여 계약에 추가할 수 있습니다.

## 권한

Log Explorer 기능에 대한 액세스는 특정 권한으로 제어됩니다. 각 권한은 로그 쿼리, 데이터세트 관리, 대시보드 생성 등 특정 작업을 수행할 수 있는 권한을 사용자에게 부여합니다.

| 기능 | 필요한 권한 | 설명 |
|----------|--------------------|--------------|
| **데이터세트 관리** | `Logs Edit` | 데이터세트를 추가, 활성화 또는 비활성화합니다. |
| **로그 검색** | `Logs Read` | 대시보드 또는 API에서 로그를 쿼리합니다. |
| **로그 검색(쿼리 저장)** | `Logs Write` | 로그 검색 쿼리를 저장합니다. |
| **맞춤형 대시보드** | `Analytics Read` | 맞춤형 대시보드를 생성하고 확인합니다. |

이 권한은 대시보드와 API 모두에 적용되며, 액세스해야 하는 데이터세트에 따라 계정 수준 또는 영역 수준에서 부여되어야 합니다.

API 인증은 API 토큰 또는 이메일이 포함된 API 키로 수행할 수 있습니다. 자세한 내용은 [API 토큰 만들기](/fundamentals/api/get-started/create-token/)를 참고하세요.

Argo Smart Routing은 전 세계 트래픽을 가속하는 원클릭 솔루션입니다.

<Tabs syncKey="dashPlusAPI"> <TabItem label="대시보드">

대시보드에서 [Argo Smart Routing](https://dash.cloudflare.com/?to=/:account/:zone/traffic)을 활성화하려면 다음 단계를 따르세요.

1. Cloudflare 대시보드에서 **Argo Smart Routing** 페이지로 이동합니다.

   <DashButton url="/?to=/:account/:zone/traffic" />

2. **Argo Smart Routing**의 토글을 **On**으로 전환합니다.
3. 청구 정보를 입력합니다.

   - [청구 프로필](/billing/create-billing-profile/)이 없다면 청구 정보를 입력합니다.

   - 청구 프로필이 있다면 청구 정보를 확인합니다.

</TabItem> <TabItem label="API">

API로 Argo Smart Routing을 활성화하거나 비활성화하려면 `value` 매개변수를 원하는 설정값(`"on"` 또는 `"off"`)으로 지정한 [`PATCH`](/api/resources/argo/subresources/smart_routing/methods/edit/) 요청을 보내세요.

Argo Smart Routing을 활성화하려면 계정에 이미 [청구 프로필](/billing/create-billing-profile/)이 있어야 합니다.

</TabItem> </Tabs>

## 청구

Cloudflare가 DDoS 보호, WAF 또는 기타 메커니즘을 통해 사이트에 대한 공격을 완화하는 경우, 해당 트래픽은 Argo Smart Routing 청구 대상에 포함되지 않습니다.

<Render file="ubb-recommendation" product="fundamentals" />

## Tiered Cache 활성화

[Cache](/cache/)는 웹사이트 콘텐츠 사본을 Cloudflare 데이터 센터에 저장하는 방식으로 동작합니다. [Tiered Cache](/cache/how-to/tiered-cache/)는 이러한 데이터 센터를 위치 기반 계층 구조로 나눕니다. 이 동작 덕분에 Cloudflare는 방문자와 가장 가까운 데이터 센터에서 콘텐츠를 전달할 수 있습니다.

Argo Smart Routing과 Tiered Cache는 함께 작동하여 사이트 방문자에게 가장 효율적인 연결을 제공합니다. 자세한 내용은 [Tiered Cache](/cache/how-to/tiered-cache/)를 참고하세요.

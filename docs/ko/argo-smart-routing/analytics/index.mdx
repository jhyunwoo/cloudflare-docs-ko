Cloudflare는 Argo Smart Routing의 성능 이점을 보여 주는 분석 기능을 제공합니다.

도메인의 Argo 분석은 [Cloudflare 대시보드](https://dash.cloudflare.com/)의 **Analytics** > **Performance**에서 확인할 수 있습니다. 대시보드의 전체 분석 기능에 대한 정보는 [Analytics](/analytics/)를 참고하세요.

:::note


**Origin Performance (Argo)**의 상세 성능 데이터는 지난 48시간 동안 Argo가 최소 500개의 오리진 요청을 라우팅했을 때만 표시됩니다.


:::

## 분석 유형

대시보드에는 성능 데이터를 위한 두 가지 보기 방식이 표시됩니다.

* **Origin Response Time**: 히스토그램은 오리진에서 Cloudflare 네트워크까지의 응답 시간을 보여 줍니다. 파란 막대는 Argo를 사용하지 않았을 때의 TTFB를 나타내고, 주황 막대는 Argo가 Smart Route를 찾은 경우의 TTFB를 나타냅니다.

* **Geography**: 지도는 각 Cloudflare 데이터 센터에서의 응답 시간 개선 정도를 보여 줍니다.

  * 음수 값은 해당 위치의 요청이 Argo Smart Routing의 이점을 얻지 못했을 것이므로, 대신 직접 라우팅되었음을 의미합니다.

Argo for Packets는 [Magic Transit](/magic-transit/), [Cloudflare WAN](/cloudflare-wan/) (이전 명칭: Magic WAN), [Cloudflare for Offices](https://blog.cloudflare.com/cloudflare-for-offices/)와 같은 Cloudflare 네트워크 서비스 제품의 성능을 끌어올릴 수 있도록 IP 계층 네트워크 최적화를 제공합니다.

Argo for Packets는 Cloudflare 네트워크를 통과하는 최적의 경로를 동적으로 선택하며, 각 Cloudflare 데이터 센터에서 오리진으로 되돌아가는 모든 경로를 개별 네트워크 경로 수준까지 살펴봅니다. Argo는 이러한 고유 경로 전반의 기존 Layer 4 트래픽과 네트워크 분석 데이터를 비교하여 가장 빠르고 가용성이 높은 경로를 결정합니다.

여러 위치를 운영하는 고객은 Argo for Packets의 이점을 특히 크게 얻을 수 있습니다. 인터넷상의 복잡한 경로를 최적화해 다른 경로와 마찬가지로 빠르게 만들어 주기 때문입니다.

Argo for Packets 사용을 시작하려면 계정 담당자에게 문의하세요.

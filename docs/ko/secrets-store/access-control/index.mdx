Secrets Store는 보안 관리자가 역할 기반 액세스를 구현함으로써 더 많은 제어를 할 수 있습니다. Cloudflare의 역할에 대한 자세한 내용은, 참조[기본 정보](/fundamentals/manage-members/).

:::노트\[Availability]
모든 'Cloudflare' 계정은 '대시보드'에 Secrets Store 섹션에 액세스 할 수 있지만, 필요한 권한을 가진 사용자는 아래에 설명 된대로 상호 작용 할 수 있습니다.
주요 특징

## 관련 역할

기본 역할 정의에 대한 아래 목록을 참조하십시오.

#### 슈퍼 관리자

- 생성, 편집, 복제, 삭제 및 비밀 메타 데이터를 볼 수 있습니다.
- 수 있습니다.[작업자에게 비밀 저장 바인딩을 추가](/secrets-store/integrations/workers/).
- 수 있습니다.[비밀과 AI 게이트웨이 간의 연관](/ai-gateway/configuration/bring-your-own-keys/).

#### 비밀번호

- 생성, 편집, 복제, 삭제 및 비밀 메타 데이터를 볼 수 있습니다.

#### 비밀 저장 Deployer

- 비밀 메타 데이터를 볼 수 있지만 만들 수 없습니다, 편집, 복제, 또는 비밀을 삭제.
- 수 있습니다.[작업자에게 비밀 저장 바인딩을 추가](/secrets-store/integrations/workers/).
- 수 있습니다.[비밀과 AI 게이트웨이 간의 연관](/ai-gateway/configuration/bring-your-own-keys/).

#### 비밀번호

- 비밀 메타데이터를 볼 수 있습니다.
- 어떤 작업을 수행 할 수 없습니다 (작성, 편집, 복제, 삭제 비밀), 또는 다른 'Cloudflare' 제품과 비밀 저장 통합을 사용.

## API 토큰 권한

다음 API 토큰 권한은 Secrets Store 리소스에 액세스 권한을 부여하는 데 사용할 수 있습니다.

- **계정 비밀 저장 편집**: 사용자가 생성, 편집, 복제 또는 비밀을 삭제할 수 있습니다.
- **계정 비밀 상점 읽기**: 사용자가 비밀 메타데이터를 볼 수 있습니다.

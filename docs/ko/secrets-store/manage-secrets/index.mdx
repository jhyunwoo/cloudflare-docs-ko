비밀은 API 토큰, public/private 키, 권한 키, 암호, 심지어 코드 변수가 될 수 있습니다. 유일한 제한은 비밀은 1024 바이트를 초과하지 않는 문자열이어야한다.

비밀이 비밀 저장에 추가되면 API 또는 '대시보드'를 통해 더 이상 해독되거나 액세스 할 수 없습니다. 주어진 비밀과 관련된 서비스 만 액세스 할 수 있습니다.

## 제한 사항

오픈 베타에서 비밀 저장을 만드는 고객은 계정 당 100 비밀까지 가질 수 있습니다. 또한, 계정당 하나의 상점이 될 수 있습니다.

:::note\[제품 비밀]
이용안내[Wrangler\`\`를](/secrets-store/manage-secrets/how-to/#manage-via-wrangler), 생산 비밀과 비밀의 차이는 로컬로 생성 된 (없이)`--remote`플래그). 계정 당 100 비밀의 한계는 생산 비밀을 고려합니다.

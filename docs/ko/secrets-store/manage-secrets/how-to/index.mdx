## 비밀을 복제

동일한 비밀 값을 유지하려면 비밀을 복제하지만 이름, 범위 또는 코멘트를 변경합니다.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    1. 'Cloudflare'에서 '대시보드'로 이동**비밀번호**사이트 맵

       <DashButton url="/?to=/:account/secrets-store" />

    2. 비밀번호 찾기

    3. 비밀 옆에 세 가지 점을 선택하고 선택하십시오.**기타 제품**.

    4. 수정하기**비밀 이름**, **제출 범위**, 또는**이름 \***&#xB2F9;신의 필요에 따라,.

    5. 제품정보**제품 정보**확인하기.
  </TabItem>

  <TabItem label="사이트맵">
    :::참조
    비밀 번호`name`공간을 포함 할 수 없습니다. 더 알아보기[비밀 저장 API](/api/resources/secrets_store/)전체 API 문서에 대한.
    주요 특징

    ```bash
    curl https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/secrets_store/stores/$STORE_ID/secrets/$SECRET_ID/duplicate \
    --header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
    --header "Content-Type: application/json" \
    --data '{
        "name":"<NEW_DUPLICATE_NAME>",
        "scopes":["workers"],
        "comment":""
    }'
    ```
  </TabItem>
</Tabs>

## 비밀 수정

새로운 것을 가진 기존 가치를 대체하는 비밀을 편집합니다.

:::카트로션
이 작업은 비밀을 사용하여 모든 서비스에 교체를 일으킬 것입니다.
주요 특징

비밀도 편집할 수 있습니다.**제출 범위**·**이름 \***.

  <TabItem label="대시보드">

    2. 비밀번호 찾기

    3. 비밀 옆에 세 가지 점을 선택하고 선택하십시오.**제품정보**.

    4. 당신의 필요에 따라 사용 가능한 필드를 편집하고 선택**제품 정보**확인하기.
  </TabItem>

  <TabItem label="사이트맵">

    https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/secrets_store/stores/$STORE_ID/secrets/$SECRET_ID \
    --header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
    --header "Content-Type: application/json" \
    --data '{
        "comment":"<NEW_COMMENT>",
        "value":"<NEW_SECRET_VALUE>",
        "scopes":["workers"]
    }'

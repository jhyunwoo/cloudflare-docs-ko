<Plan id="secrets_store.properties.availability.summary" />

Cloudflare Secrets Store는 보안, 중앙화 된 위치로서 계정 수준의 비밀이 저장되고 관리됩니다. 비밀은 모두 안전하게 암호화되고 저장됩니다.[Cloudflare 데이터 센터](https://www.cloudflare.com/network/).

Secrets Store는 현재 호환됩니다.[Cloudflare구인](/secrets-store/integrations/workers/)·[AI 게이트웨이](/ai-gateway/configuration/bring-your-own-keys/). 다른 제품과의 통합은 미래에 추가될 것입니다.

:::note\[중국 가용성]
Secrets Store는 사용할 수 없습니다.[Cloudflare 중국 네트워크](/china-network/), Cloudflare의 파트너 JD 클라우드에 의해 운영.

[Cloudflare 비밀 저장](/secrets-store/)계정 수준의 비밀이 저장되고 관리되는 안전한 중앙화된 위치입니다. 비밀은 모든 Cloudflare 데이터 센터에 안전하게 암호화되고 저장됩니다.

아래 단계를 고려하여 계정 비밀 저장에서 값을 사용하는 방법을 배우십시오.[Cloudflare구인](/workers/)·
:::참조
이것은 Workers와 다릅니다.[변수 및 비밀](/workers/configuration/secrets/), 당신이 정의하고 per-Worker 수준에 비밀을 관리.

## 2. 당신의 노동자에 계정 비밀

[회사 소개](/workers/runtime-apis/bindings/)'Cloudflare' 계정에 리소스와 상호 작용할 수 있습니다.

작업자에게 계정 비밀을 바인딩하려면 다음 중 하나를해야합니다.['Cloudflare' 계정 내에서 역할](/secrets-store/access-control/):

- 슈퍼 관리자
- 비밀 저장 Deployer

### 비아 Wrangler

1. Secrets Store 바인딩을 추가하십시오.[Wrangler 설정 파일](/workers/wrangler/configuration/):
   - `binding`: 당신의 바인딩을 위한 descriptive 이름. 'Workers' 애플리케이션에서 사용할 수 있습니다.[비밀에 접근`env`기타 제품](/secrets-store/integrations/workers/#3-access-the-secret-on-the-env-object).
   - `store_id`: 계정 비밀이 생성 된 해당 비밀 번호.
   - `secret_name`: 계정 비밀이 생성되었을 때 정의된 유일한 비밀명.

<WranglerConfig>
  ```jsonc
  {
  	"main": "./src/index.js",
  	"secrets_store_secrets": [
  		{
  			"binding": "<BINDING_VARIABLE>",
  			"store_id": "<STORE_ID>",
  			"secret_name": "<MY_SECRET_NAME>"
  		}
  	]
  }
  ```
</WranglerConfig>

### Dashboard를 통해

1. 'Cloudflare'에서 '대시보드'로 이동**Workers와 Pages**.

   <DashButton url="/?to=/:account/workers-and-pages" />

2. Workers 응용 프로그램을 선택합니다.

5. 필요한 필드에 기입:
   - **변수 이름**: 바인딩의 이름. 비밀에 액세스하기 위해 노동자에 사용됩니다 ([단계 3](#3-access-the-secret-on-the-env-object)아래).
   - **비밀 이름**: 사용 가능한 계정 비밀 목록에서 선택[단계 1](#1-set-up-account-secrets-in-secrets-store).

6. 제품정보**계정 만들기**바인딩을 배포합니다. 배포 할 때 두 가지 옵션이 있습니다.
   - **배포 :**&#xC989;시 관객의 100 %에 바인딩을 배치합니다.
   - **버전 저장:**&#xBBF8;래에 배포 할 수있는 바인딩의 버전을 저장합니다.

## 3. 비밀에 접근`env`기타 제품

[회사 소개](/workers/runtime-apis/bindings/)에 위치`env`객체. 비밀에 액세스하려면 먼저 비동기 통화가 필요합니다.

### 이름 \*`get()`바인딩 변수에

:::caution\[Local 개발 모드]
API 또는 API를 통해 '대시보드'에 생성된 생산 비밀에 액세스할 수 없습니다.`--remote`flag) 로컬 개발 설정에서. Secrets Store를 로컬로 사용하려면 사용해야 합니다.`secrets-store secret` [Wrangler 명령](/workers/wrangler/commands/)없음`--remote`플래그.
주요 특징

```js
export default {
  async fetch(request, env) {
    //API 요청에 안전하게 비밀을 사용하는 예
		const APIkey = await env.<BINDING_VARIABLE>.get()

    const response = await fetch("https://api.example.com/data", {
      headers: { "Authorization": `Bearer ${APIKey}` },
    });

    if (!response.ok) {
      return new Response("Failed to fetch data", { status: response.status });
    }

    const data = await response.json();
    return new Response(JSON.stringify(data), {
      headers: { "Content-Type": "application/json" },
    });
  },
};
```

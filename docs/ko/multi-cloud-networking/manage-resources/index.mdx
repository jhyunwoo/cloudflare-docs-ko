## Cloud 리소스 카탈로그

클라우드 환경은 가상 개인 클라우드 (VPC), 서브넷, 가상 머신 (VMs), 경로 테이블 및 경로와 같은 개별 클라우드 리소스에서 구축됩니다. Cloudflare One Multi-Cloud Networking (이전 Magic Cloud Networking) (베타)는 클라우드 리소스를 모두 발견하고 클라우드 리소스 카탈로그의 구성 및 상태를 저장하고 클라우드 환경의 읽기 전용 스냅 샷을 저장합니다. 디스커버리는 정기적으로 배경에서, 당신의 환경 변화로 날짜까지 카탈로그를 유지.

카탈로그의 리소스를 검색하려면:

1. 오시는 길**연결관**사이트 맵

   <DashButton url="/?to=/:account/magic-networks/connections" />

2. 선택하기**클라우드 (beta)**&#xD0ED;.

3. 내 계정**클라우드 리소스**, 그것의 세부사항을 검열하기 위하여 리소스를 선정하십시오.

## Cloud 통합 편집

통합을 클라우드 계정으로 변경하거나 통합을 삭제할 수 있습니다.

1. 오시는 길**Cloud 통합**.

   <DashButton url="/?to=/:account/mcn/integrations" />

2. 통합 선택 >**제품정보**.

3. 내 계정**Linked 계정 세부 정보**, 선택**다른 클라우드 계정에 연결 통합**.

4. 제품정보**제품 정보**당신이 완료되면.

5. (선택) 당신은 또한 선택할 수 있습니다**이름 \***&#xD074;라우드 통합을 삭제합니다.

## 클라우드 리소스 카탈로그

모든 클라우드 리소스에 메타데이터 및 구성을 포함하는 JSON 파일을 다운로드 할 수 있습니다.

1. 오시는 길**연결관**사이트 맵

   <DashButton url="/?to=/:account/magic-networks/connections" />

2. 선택하기**클라우드 (beta)**&#xD0ED;.

3. 내 계정**클라우드 리소스**, 선택**카탈로그**.

브라우저가 ZIP 파일을 다운로드 한 후 클라우드 리소스에 대한 정보로 JSON에 액세스 할 수 있습니다.

## 2024-11-21

**VM 및 LB에 대한 클라우드 리소스 가져 오기**

클라우드 네트워크 발견은 이제 클라우드 네이티브 가상 머신(VM) 및 로드밸런서(LB) 리소스를 포함합니다.

## 2024-11-21

**수출 리소스 카탈로그**

고객은 오프라인 분석에 적합한 모든 검색된 리소스 메타데이터를 다운로드 가능한 JSON 파일에 포함한 리소스 카탈로그를 수출할 수 있습니다.

## 2024-10-01

**관리된 클라우드 구성에 대한 비용 가시성**

고객은 이제 발견 된 네트워크 리소스의 클라우드 공급자 목록 가격을 볼 수 있으며 관리 구성을 배치 할 때 총 비용과 델타 비용의 정보를 알려줍니다.

## 2024-08-14

**GCP on-램핑**

Magic Cloud Networking은 Google Cloud Platform을 지원합니다.

## 2024-07-01

**닫힌 베타 출시**

Magic Cloud Networking 폐쇄 베타 릴리스는 관리 된 클라우드 On-ramps 기능으로 제공됩니다.

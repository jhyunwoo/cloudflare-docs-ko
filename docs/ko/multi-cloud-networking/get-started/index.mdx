시작하기로 Cloudflare One Multi-Cloud 네트워킹 (이전 Magic Cloud Networking) (베타)를 사용하면 Cloudflare 권한을 제공하여 클라우드 공급자와 상호 작용할 수 있습니다. 동일한 클라우드 공급자의 여러 공급자 계정이 있을 수 있습니다. 예를 들어, Cloudflare를 원하는 경우, 두 개의 다른 AWS 계정에 속하는 가상 개인 클라우드(VPC)를 관리할 수 있습니다.

Cloudflare가 클라우드 환경에 액세스하기 위해 필요한 자격 증명을 가지고 있다면 Multi-Cloud 네트워킹은 routing table 및 virtual private network와 같은 클라우드 리소스를 자동으로 발견합니다. 발견 된 리소스가 당신의 모습[Cloud 리소스 카탈로그](/multi-cloud-networking/manage-resources/#cloud-resource-catalog).

## Amazon AWS 설정

### 1. 통합 만들기

1. 오시는 길**클라우드 통합 (beta)**&#xC0AC;이트 맵

   <DashButton url="/?to=/:account/mcn/integrations" />

2. 제품정보**더 보기** > **AWS 통합**.

3. 당신의 통합에 descriptive 이름을 부여합니다. 선택적으로, 당신은 또한 그것에 대한 설명을 추가 할 수 있습니다.

4. 제품정보**통합 만들기**.

5. 제품정보**접근성 준수**Amazon AWS에 Cloudflare 계정을 연결하는 프로세스를 시작하십시오.

### 2. IAM 정책 만들기

1. 이름 \*[주문 IAM 정책](https://docs.aws.amazon.com/IAM/latest/UserGuide/access_policies_create-console.html)AWS 계정에서 입력한 이름의 메모를 입력합니다. 다음, 다음을 붙여[JSON 코드](https://docs.aws.amazon.com/IAM/latest/UserGuide/reference_policies_elements_version.html)JSON 탭에서:

```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "ec2:AcceptTransitGatewayPeeringAttachment",
                "ec2:CreateTransitGatewayPeeringAttachment",
                "ec2:DeleteTransitGatewayPeeringAttachment",
                "ec2:DescribeRegions",
                "ec2:DescribeTransitGatewayPeeringAttachments",
                "ec2:RejectTransitGatewayPeeringAttachment",
                "ec2:GetManagedPrefixListEntries",
                "ec2:CreateManagedPrefixList",
                "ec2:ModifyManagedPrefixList",
                "ec2:DeleteManagedPrefixList",
                "ec2:CreateTransitGatewayPrefixListReference",
                "ec2:DeleteTransitGatewayPrefixListReference",
                "ec2:GetTransitGatewayPrefixListReferences",
                "ec2:ModifyTransitGatewayPrefixListReference"
            ],
            "Resource": "*"
        }
    ]
}
```

### 3. AWS 계정에 액세스 권한을 부여

1. 이름 \*[AWS 역할](https://docs.aws.amazon.com/IAM/latest/UserGuide/id_roles_create_for-custom.html)다음 설정으로:

   - **신뢰 정책**: Cloudflare 대시보드가 반환한 사용자 지정 신뢰 정책을 붙여넣습니다.
   - **제출**: 이전 단계에서 만든 IAM 정책 추가, 이러한 AWS 관리 정책:
     - `NetworkAdministrator`
     - `AmazonEC2ReadOnlyAccess`
     - `AmazonVPCReadOnlyAccess`
     - `IAMReadOnlyAccess`
   - **사이트맵**: 새로 생성된 사용자를 위한 ARN 복사

   :::참조
   신뢰 정책은 모든 지역에 propagate에 몇 분 걸릴 수 있습니다. 보통 4 분 미만이 걸리지만 때로는 더 오래 걸릴 수 있습니다. 구할 수 있습니다.**이름 \***&#x70;ropagation가 효력을 가지고 있는 동안 단추.
   주요 특징

2. 제품정보**AWS 계정에 액세스하려면 Cloudflare를 승인합니다.**

3. 제품정보**이름 \***.

:::참조
자원의 첫 발견은 IAM 정책이 전파 중 모든 지역에서 성공할 수 없습니다. 클라우드 통합을 생성한 후 모든 리소스를 볼 수 없다면 다시 발견해 보세요.

   - 연결된 문서의 3 단계에서, 선택**회사 소개**역할에서**Privileged 관리자 역할**탭.
   - 연결된 문서의 단계 4에서 검색`mcn-provider-integrations-bot-prod`회원가입

6. 내 계정**계정 소유권 확인**, [Cloudflare 대시보드에서 표시된 꼬리표를 추가하십시오](https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/tag-resources-portal).

   주요 특징

7. 제품정보**Azure 계정에 액세스하려면 Cloudflare를 승인합니다.**&#xACC4;정이 관리자 권한이 없으면 관리자 권한이 있는 계정에 이 링크를 전달해야 합니다.

8. 제품정보**이름 \***.

## Google Cloud 설정

### 1. 통합 만들기

1. Cloudflare 대시보드에서, 갑니다**클라우드 통합 (beta)**.

   <DashButton url="/?to=/:account/mcn/integrations" />

2. 제품정보**더 보기** > **Google 통합**.

3. 당신의 통합에 descriptive 이름을 부여합니다. 선택적으로, 당신은 또한 그것에 대한 설명을 추가 할 수 있습니다.

4. 제품정보**통합 만들기**.

5. 제품정보**접근성 준수**Cloudflare 계정을 Google Cloud에 연결하는 프로세스를 시작합니다.

### 2. Google 계정에 액세스 권한을 부여

1. 새로운 기능[GCP 서비스 계정](https://cloud.google.com/iam/docs/service-accounts-create)내 계정**Google 계정** > **GCP 콘솔** > **IAM 및 관리자** > **서비스 계정**.
2. 새로운 서비스 계정 부여 이러한 역할:
   - `Compute Network Admin`
   - `Compute Viewer`
3. 이름 \***IAM 및 관리자** > **서비스 계정**, 방금 만든 서비스 계정을 선택하고 탐색**제출**탭.
4. 제출하기**서비스 계정 Token Creator**우리의 봇 계정에 역할은이 서비스 계정의 임의로 허용. 특정 역할에 대한 권한을 부여하는 방법 알아보기[Google의 문서](https://cloud.google.com/iam/docs/manage-access-service-accounts#grant-single-role):
   - `mcn-integrations-bot-prod@mcn-gcp-01.iam.gserviceaccount.com`
5. 내 계정**서비스 계정 이메일 필드**, GCP 서비스 계정을 생성하는 데 사용되는 이메일 계정을 입력하십시오.
6. 내 계정**프로젝트 ID 필드**, 입력[프로젝트 ID](https://support.google.com/googleapi/answer/7014113?hl=en)당신의 프로젝트와 관련.
7. [상표 추가](https://cloud.google.com/resource-manager/docs/creating-managing-labels#create-labels)프로젝트의 대시보드에 표시됩니다.
8. 제품정보**GCP 계정에 액세스하려면 Cloudflare를 승인합니다.**&#xACC4;정이 관리자 권한이 없으면 관리자 권한이 있는 계정에 이 링크를 전달해야 합니다.
9. 제품정보**이름 \***.

클라우드 공급자를 Multi-Cloud Networking에 성공적으로 연결했습니다. Multi-Cloud Networking에 의해 발견 된 클라우드 리소스는 사용할 수 있습니다[Cloud 리소스 카탈로그](/multi-cloud-networking/manage-resources/#cloud-resource-catalog).

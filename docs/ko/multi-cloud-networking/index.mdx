Cloudflare One Multi-Cloud Networking (이전 Magic Cloud Networking) (베타)는 Amazon Web Services, Google Cloud Platform 또는 Azure와 같은 공공 클라우드 인프라에 연결하는 프로세스를 단순화합니다. 멀티 클라우드 네트워킹을 통해 Cloudflare의 대시보드를 통해 클라우드 리소스를 자동으로 발견하고 사무실 및 데이터 센터 네트워크와 함께 클라우드 네트워크를 쉽게 결합 할 수 있습니다.

멀티 클라우드 네트워킹을 사용하면 Cloudflare를 통해 가상 개인 클라우드를 안전하게 연결할 수 있습니다. Cloudflare의 연결 클라우드 서비스에 중점을 둔 일관적이고 확장 가능한 방식으로 멀티 클라우드 네트워크 아키텍처를 성장하십시오.

Multi-Cloud Networking은 현재 닫히는 베타입니다. 당신이 시도하는 첫번째 고객 중 하나인 경우에,[이 양식을 작성](https://www.cloudflare.com/lp/cloud-networking/).

자주 묻는 질문[모델 번호: 시작하기](/multi-cloud-networking/get-started/).

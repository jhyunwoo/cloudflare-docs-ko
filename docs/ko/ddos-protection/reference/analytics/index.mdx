서비스 및 계획에 따라 다른 대시보드에서 DDoS 분석이 가능합니다.

- 더 보기[보안 이벤트 ‘대시보드’](/waf/analytics/security-events/)HTTP DDoS 공격과 TCP 공격을 포함하여 영역을 대상으로 L7 보안 이벤트에 가시성을 제공합니다. 대시보드는 HTTP DDoS 이벤트로 HTTP DDoS 공격의 완화를 표시합니다. 이 이벤트도 가능합니다.[Cloudflare 로그](/logs/).

- 더 보기[네트워크 분석 대시보드](/analytics/network-analytics/)L3/4 트래픽 및 DDoS 공격에 대한 가시성을 제공하여 IP 범위 또는 스펙트럼 애플리케이션을 타겟팅합니다.

## 이름 \*

어떤 상황에서 분석 대시보드는 패킷/복구를 처리하는 DDoS 관리 규칙의 ID를 표시하지 않습니다. 이것은 "Cloudflare"라는 내부 DDoS 규칙이 공개적으로 노출되지 않는 것을 의미합니다. 패킷/복구에 작용을 적용했습니다. 이 내부 DDoS 규칙은 매우 낮은 거짓 긍정적 인 비율을 가지고 있으며 항상 DDoS 공격에 대한 속성을 보호해야합니다. 같은 이유로 DDoS 규칙 ID는 'Cloudflare' 로그 및 API 응답에서 사용할 수 없습니다.

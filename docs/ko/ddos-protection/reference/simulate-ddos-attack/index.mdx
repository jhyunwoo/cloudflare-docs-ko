Cloudflare로 온 후, 인터넷 속성에 대한 DDoS 공격을 시뮬레이션하고 보호 테스트를 수행 할 수 있습니다.[관련 기사](/ddos-protection/reference/reports/)·[계정 관리](/ddos-protection/reference/alerts/)기계. 이 섹션의 지침을 따라 DDoS 공격을 시뮬레이션합니다.

자신의 인터넷 속성에 대한 DDoS 공격을 실행할 수 있습니다 - 귀하의 영역, 스펙트럼 응용 프로그램, 또는 IP 범위 (당신의 'Cloudflare' 서비스에 따라 다름) - 그리고 제공:

- 인터넷 속성은 다른 조직 또는 개인과 공유되지 않습니다.
- 인터넷 속성은 이름이나 소유권 아래 계정에서 Cloudflare로 표시됩니다.

## 시작하기 전에

'Cloudflare'에서 허가를받지 않고 자신의 인터넷 속성에 대한 DDoS 공격 시뮬레이션을 시작하십시오.

적절한 서비스를 선택하고 해당 DDoS 공격에 대한 테스트에 올바른 기능을 활성화하는 것이 좋습니다. 예를 들어, HTTP DDoS 공격에 대해 Cloudflare를 테스트하고 Magic Transit을 사용하는 경우, HTTP 애플리케이션을 Cloudflare'''s reverse proxy service to test our HTTP DDoS Protection에 추가해야 하기 때문에 테스트가 실패합니다.

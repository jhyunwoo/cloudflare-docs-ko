더 보기[DDoS 공격 보호 관리 규정](/ddos-protection/managed-rulesets/)다양한 보호<GlossaryTooltip term="distributed denial-of-service (DDoS) attack">DDoS 공격</GlossaryTooltip>L3/4 (layers 3/4)와 OSI 모델의 L7를 통하여. 'Cloudflare'는 이러한 관리 된 규칙을 지속적으로 업데이트하여 공격 범위를 개선하고 완화 일관성을 증가시키고 새로운 신흥 위협을 커버하고 비용 효율적인 완화를 보장합니다.

[고급 TCP 보호](/ddos-protection/advanced-ddos-systems/overview/advanced-tcp-protection/), [고급 DNS 보호](/ddos-protection/advanced-ddos-systems/overview/advanced-dns-protection/)·[풀그릴 교류 보호](/ddos-protection/advanced-ddos-systems/overview/programmable-flow-protection/)Magic Transit 고객에 사용할 수 있습니다. 고급 TCP 보호는 정교한 TCP 기반 DDoS 공격에 대한 추가 보호를 제공합니다. 고급 DNS 보호는 정교한 완전히 무작위 DNS 공격에 대해 보호합니다. 프로그래밍 가능한 Flow Protection은 고객 정의 프로그램을 실행하여 UDP 기반 공격을 모방합니다.

일반적인 가이드라인으로, 다양한 Cloudflare 제품은 다른 개방형 시스템 상호 연결 (OSI) 레이어에서 작동하며 귀하의 서비스가 작동하는 레이어까지 보호됩니다. 내장된 레이어에서 DDoS 설정을 사용자 정의할 수 있습니다. 예를 들어, CDN/WAF서비스가 레이어 7(HTTP/HTTPS) 서비스이므로, Cloudflare는 L4 공격을 포함하여 L7에서 DDoS 공격으로부터 보호합니다.

:::참조

Magic Transit 고객을 위해, Cloudflare는 Magic Transit 고객에 사용할 수있는 고급 DNS 보호 시스템과 함께 L7 보호를 제공합니다. DNS는 L7 프로토콜로 간주됩니다.

## 추가 DNS 보호 받기

Network-layer DDoS 공격 보호 관리 규정은 DNS 공격의 일부 유형에 대한 보호를 제공합니다.

Magic Transit 고객은 액세스 할 수 있습니다[고급 DNS 보호](/ddos-protection/advanced-ddos-systems/overview/advanced-dns-protection/) <InlineBadge preset="beta" />. 다른 고객은 뒤에 오는 선택권을 고려할지도 모릅니다:

- 'Cloudflare'를 저자 DNS 공급자로 사용하십시오 ([기본 DNS](/dns/zone-setups/full-setup/)또는[두 번째 DNS](/dns/zone-setups/zone-transfers/cloudflare-as-secondary/)).
- 당신은 당신의 자신을 실행하는 경우<GlossaryTooltip term="nameserver">이름서버</GlossaryTooltip>, 사용[DNS 방화벽](/dns/dns-firewall/)임의 접두사 공격과 같은 DNS 공격에 대한 추가 보호를 얻기 위해.

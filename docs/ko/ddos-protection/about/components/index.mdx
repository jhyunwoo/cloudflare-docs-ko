## 자율주행

'Cloudflare' 자율 Edge는 denial-of-service에 의해 구동됩니다.<GlossaryTooltip term="daemon" prepend="A daemon is ">인기있는</GlossaryTooltip> (`dosd`), home-grown 소프트웨어 정의 시스템입니다. 흐름 추적 daemon,`flowtrackd`, 우리의 stateful mitigation platform alongside입니다`dosd`·`dosd`인스턴스는 모든 단일 서버에서 실행됩니다.[Cloudflare 글로벌 네트워크 데이터 센터](https://www.cloudflare.com/network/)전세계. 이름 \*`dosd`인스턴스는 중앙 합의를 필요로하지 않고 DDoS 공격을 감지하고 mitigate DDoS 공격 할 수 있습니다. Cloudflare 사용자는 이 시스템을 구성할 수 있습니다.[DDoS 공격 보호 관리 규정](/ddos-protection/managed-rulesets/).

'Cloudflare''s Autonomous Edge의 또 다른 구성 요소는 다음과 같습니다.[고급 TCP 보호](/ddos-protection/advanced-ddos-systems/overview/advanced-tcp-protection/)시스템. 이것은 ‘Cloudflare’의 TCP 상태 추적기입니다. 단방향 라우팅 토폴로지에서 가장 무작위화되고 정교한 TCP 기반 DDoS 공격을 탐지하고 mitigating하기위한 것입니다.[매직 트레인](/magic-transit/). 고급 TCP 보호는 TCP 연결의 상태를 확인하고, 방어, 또는 합법적인 연결에 속하지 않는 속도 제한 패킷을 삭제할 수 있습니다.

자세한 내용은 블로그 게시물 참조['Cloudflare'의 자율적 인 Edge DDoS 보호에 대한 깊은 이해](https://blog.cloudflare.com/deep-dive-cloudflare-autonomous-edge-ddos-protection/).

## DDoS 차단 시스템

Autonomous Edge에 대한 보완, Cloudflare의 전체 글로벌 네트워크는 글로벌 버전에 의해 overwatched`dosd`. 이 구성 요소는 전역의 분산 볼륨 디도스 공격을 감지하고 mitigating하여 'Cloudflare\`의 전체 글로벌 네트워크를 보호합니다.

중앙화된 시스템은 Cloudflare의 핵심 데이터 센터에서 실행됩니다. 그들은 모든 글로벌 네트워크 데이터 센터에서 샘플을 수신, 분석, 그리고 자동으로 공격을 감지 할 때 완화 지침을 보내. 시스템은 또한 고객의 웹 서버의 각에 동기화되어 건강 상태를 확인하고 필요한 완화 작업을 트리거합니다.

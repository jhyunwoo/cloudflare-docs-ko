HTTP DDoS 공격 보호 관리 규칙의 주요 범주 (또는 태그)는 다음과 같습니다.

| 이름 \*              | 이름 \*                                                                                                                                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `botnets`          | 알려진 botnets의 요청에 대한 규칙, 매우 높은 정확도와 거짓 긍정적의 낮은 위험. 이 규칙을 활성화하는 것이 좋습니다.                                                                                                                                                    |
| `unusual-requests` | 일반적으로 합법적 인 트래픽에서 볼 수없는 의심스러운 특성을 가진 요청 규칙.                                                                                                                                                                               |
| `advanced`         | 고급 DDoS 차단 고객에게 제공되는 기능과 관련된 규칙[Adaptive DDoS 차단](/ddos-protection/managed-rulesets/adaptive-protection/).                                                                                                                |
| `generic`          | 요청의 홍수를 감지하고 mitigating하기위한 규칙. 이 규칙은 알려진 서명이없는 공격에 유용하지만 그들은 합법적 인 트래픽의 비정상적인 높은 볼륨에 방아쇠를 수 있습니다. 거짓 긍정적의 위험을 줄이기 위해, 두 번째 (rps) 활성화 임계 값 당 그들의 요청은 더 높습니다. 이 규칙은 기본적으로 속도 제한 또는 도전 트래픽 중 하나이지만, 필요한 경우 트래픽을 차단할 수 있습니다. |
| `read-only`        | <Render file="managed-rulesets/read-only-rules-description" product="ddos-protection" />                                                                                                                                  |
| `test`             | <Render file="managed-rulesets/test-rules-description" product="ddos-protection" />                                                                                                                                       |

고급 DDoS 차단 구독을 통해 엔터프라이즈 고객에게만 사용할 수 있습니다.
주요 특징

HTTP DDoS 공격 보호 관리 규정에 대한 override 표현을 설정하여 특정 범위를 정의합니다.[감도 수준](/ddos-protection/managed-rulesets/http/override-parameters/#sensitivity-level)또는[이름 \*](/ddos-protection/managed-rulesets/http/override-parameters/#action)조정.

예를 들어, 다른 요청 URI 경로에 대한 다른 감도 수준을 설정할 수 있습니다. URI 경로의 중간 감도 수준`A`URI 경로의 낮은 감도 수준`B`.

## 본문 바로가기

override expressions에서 다음 필드를 사용할 수 있습니다.

- `cf.bot_management.ja3_hash`
- `cf.bot_management.ja4`
- `cf.client.bot`
- `cf.threat_score`
- `cf.tls_cipher`
- `cf.tls_client_auth.cert_verified`
- `cf.tls_version`
- `cf.verified_bot_category`
- `http.cookie`
- `http.host`
- `http.referer`
- `http.request.headers`
- `http.request.headers.names`
- `http.request.headers.truncated`
- `http.request.headers.values`
- `http.request.uri`
- `http.request.uri.path`
- `http.request.uri.path.extension`
- `http.request.uri.query`
- `http.request.full_uri`
- `http.request.method`
- `http.request.version`
- `http.request.cookies`
- `http.user_agent`
- `http.x_forwarded_for`
- `ip.geoip.asnum`
- `ip.geoip.continent`
- `ip.geoip.country`
- `ip.geoip.is_in_european_union`
- `ip.src`
- `ip.src.asnum`
- `ip.src.continent`
- `ip.src.country`
- `ip.src.is_in_european_union`
- `ssl`

더 알아보기[필드 참고 자료](/ruleset-engine/rules-language/fields/reference/)더 많은 정보를 위한 규칙 언어 문서에.

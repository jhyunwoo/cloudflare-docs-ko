정의하여 HTTP DDoS 공격 보호 관리 규칙 구성[관련 기사](/ruleset-engine/managed-rulesets/override-managed-ruleset/)‘Cloudflare’ ‘대시보드’에서 DDoS overrides를 사용하면 사용자 정의 할 수 있습니다.**이름 \***·**감도:**&#xAD00;리된 규칙에 한 개 이상의 규칙.

사용 가능한 매개 변수에 대한 자세한 내용은 허용된 값을 참조하십시오.[Ruleset 매개 변수](/ddos-protection/managed-rulesets/http/override-parameters/).

:::note\[유효한 과다수]

고급 DDoS 차단 구독을 가진 엔터프라이즈 고객은 최대 10개의 중복을 정의할 수 있습니다. 이 overrides는 수신 요청의 하위 설정에만 적용되도록 사용자 정의 표현을 가질 수 있습니다. 고급 DDoS 보호 가입이 없다면 항상 모든 수신 요청에 적용 할 수 있습니다.

추가 오버라이드를 배포할 수 없다면, 기존의 오버라이드를 편집하여 규칙 구성을 조정할 수 있습니다.

### DDoS를 생성

{/* prettier-ignore */}

<Steps>
  1. override의 descriptive 이름을 입력합니다.**Override 이름**.

  2. 고급 DDoS 차단을 가진 기업 고객인 경우:
     1. 이름 \***공급 능력**, override의 범위를 검토 - 기본적으로, 현재 영역에 대한 모든 들어오는 요청.
     2. 필요한 경우, 선택**연락처**그리고 구성[사용자 정의 필터 표현](/ddos-protection/managed-rulesets/http/http-overrides/override-expressions/)그것은 override 범위를 결정합니다.

  3. 오버라이드를 원하는 것에 따라 다음 섹션을 참조하십시오 (당신은 동일한 오버라이드에 구성을 수행 할 수 있습니다) :

     <Details header="규칙의 모든 규칙을 구성 (ruleset override)">
       4. 항상 규칙의 모든 규칙에 대한 주어진 조치를 적용하려면 행동을 선택하십시오.**Ruleset 작업**.
       5. 모든 규칙에 대한 감도 수준을 설정하려면 규칙에 값을 선택하십시오.**Ruleset 감도**.
     </Details>

     <Details header="하나 이상의 규칙 구성">
       4. 이름 \***규칙 구성**, 선택**검색 규칙**.
       5. 사용 가능한 필터를 사용하여 구성하려는 규칙에 대한 검색. 검색할 수 있습니다.[태그 :](/ddos-protection/managed-rulesets/http/rule-categories/)(일컬어 종류).
       6. 단일 규칙을 구성하려면 다음 규칙에 표시된 드롭다운 필드에 원하는 값을 선택합니다.
          하나의 규칙을 구성하려면, 행 체크 박스를 사용하여 규칙을 선택하고 테이블 이전에 표시되는 드롭다운을 사용하여 선택한 규칙에 필드를 업데이트하십시오. 지정된 태그로 모든 규칙을 구성할 수 있습니다. 더 많은 정보를 원하시면, 참조[관리 규칙 구성](/waf/managed-rules/deploy-zone-dashboard/#configure-a-managed-ruleset).
       7. 제품정보**이름 \***.
     </Details>

     :::주\[주]

     - 태그와 규칙 overrides에는 통치자 overrides에 우선 순위가 있습니다.
     - <Render file="managed-rulesets/read-only-rules-note" product="ddos-protection" />

     :::

  4. 제품정보**제품 정보**.
</Steps>

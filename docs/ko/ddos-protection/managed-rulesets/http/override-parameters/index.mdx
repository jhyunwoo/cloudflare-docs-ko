HTTP DDoS 공격 보호 관리 규정을 구성하여 주어진 공격에 적용된 행동을 변경하거나 탐지 메커니즘의 감도 수준을 수정합니다. 당신은 할 수['Cloudflare 대시보드\`에서 관리된 규칙을 구성](/ddos-protection/managed-rulesets/http/http-overrides/configure-dashboard/)또는[Rulesets API를 통한 오버라이드 정의](/ddos-protection/managed-rulesets/http/http-overrides/configure-api/).

사용 가능한 매개 변수는 다음과 같습니다:

- [- 연혁](#action)
- [감도 수준](#sensitivity-level)

## - 연혁

API 속성 이름:`"action"`.

'Cloudflare'의 DDoS 완화 서비스의 특정 규칙과 일치하는 요청에 대해 수행됩니다. 사용 가능한 작업은:

- **제품정보**
  - API 가치:`"block"`.
  - 규칙 표현과 일치하는 HTTP 요청을 차단합니다.

- **관리 도전**
  - API 가치:`"managed_challenge"`.
  - [관리 도전](/cloudflare-challenges/challenge-types/challenge-pages/#managed-challenge)인간의 시간의 수명을 줄일 수 있습니다 인터넷에서 CAPTCHA를 해결. 요청의 특성에 따라, Cloudflare는 특정 기준에 따라 적절한 유형의 도전을 동적으로 선택할 것입니다.

- **대화 도전**
  - API 가치:`"challenge"`.
  - 규칙 표현과 일치하는 HTTP 요청을 만드는 클라이언트에 대화 형 도전을 제시합니다.

- **로그인**
  - API 가치:`"log"`.
  - Advanced DDoS Protection 구독을 통해 Enterprise 플랜에서만 사용할 수 있습니다. HTTP DDoS 공격을 탐지하는 규칙의 표현과 일치하는 로그 요청. 더 심한 행동에 투입하기 전에 규칙을 검증하는 것이 좋습니다.

- **연결 닫기**
  - API 가치:*사이트맵*(외부 규칙은 과도하게 사용할 수 없습니다).
  - 클라이언트는 새로운 연결을 설정하기 위해 지시 (해제`keep-alive`) 대신 기존의 연결을 재사용합니다. 기존 요청은 영향을받지 않습니다.

- **힘 연결 닫기**
  - API 가치:*사이트맵*(외부 규칙은 과도하게 사용할 수 없습니다).
  - 지속적인 HTTP 연결. 이 동작은 요청을 차단하지 않지만, 클라이언트가 다시 연결하도록 강제합니다. HTTP / 2 및 HTTP / 3 연결의 경우, 연결은 같은 연결에서 실행되는 다른 요청을 깰 경우에도 닫힙니다.
  - 수행 된 작업은 HTTP 버전에 따라 다릅니다.
    - HTTP/1: 설정[`Connection`기타 제품](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Connection#directives)으로`close`.
    - HTTP/2: 전송[`GOAWAY`제품 정보](https://datatracker.ietf.org/doc/html/rfc7540#section-6.8)고객에.

- **DDoS 역학**
  - API 가치:*사이트맵*(외부 규칙은 과도하게 사용할 수 없습니다).
  - "Cloudflare"에 의해 정의 된 내부 가이드 세트에 따라 특정 작업을 수행합니다. 실행된 동작은 위 중 하나일 수 있습니다.

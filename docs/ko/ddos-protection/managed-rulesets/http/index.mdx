'Cloudflare\` HTTP DDoS 공격 보호 관리 규칙은 일치하기 위해 사용되는 사전 구성 규칙 세트입니다.[알려진 DDoS 공격 벡터](/ddos-protection/about/attack-coverage/)'Cloudflare' 글로벌 네트워크에서 레이어 7 (application layer)에서. 규칙은 알려진 공격 패턴과 도구, 의심스러운 패턴, 프로토콜 위반, 많은 양의 기원 오류, 과도한 트래픽은 기원 / 캐시를 타격, 및 응용 프로그램에 추가 공격 벡터.

Cloudflare는 정기적으로 관리되는 규칙의 목록을 업데이트합니다. 더 알아보기[공지사항](/ddos-protection/change-log/http/)최근 및 다가오는 변경에 대한 자세한 내용은.

HTTP DDoS 공격 보호 관리 규정은 항상 활성화됩니다 - 당신은 단지 행동을 사용자 정의 할 수 있습니다.

HTTP DDoS 공격 보호 관리 규정은 L7 DDoS 공격으로 증가된 관찰성을 제공하여 사용자가 계속 또는 과거 공격의 사용자를 알려줍니다. 더 보기[보안 이벤트 ‘대시보드’](/waf/analytics/security-events/), 안으로 유효한**보안 보안** > **(주)**, 상위 HTTP DDoS 관리 규정에 대한 정보를 표시합니다.

## Ruleset 구성

합법적 인 트래픽의 큰 스파이크를 기대하는 경우 DDoS 보호 설정을 사용자 정의 고려하여[거짓 긍정적](/ddos-protection/managed-rulesets/http/http-overrides/override-examples/#legitimate-traffic-is-incorrectly-identified-as-an-attack-and-causes-a-false-positive)합법적 인 트래픽이 공격 트래픽과 차단/challenged로 거짓으로 식별되는 곳.

다음 매개 변수를 수정하여 관리된 규칙의 행동을 조정할 수 있습니다.

- 수행하기**이름 \***&#xACF5;격이 감지되면.
- 더 보기**감도 수준**공격 감지 메커니즘.

:::주\[주]

- 특정 행동 또는 감도 수준은 모든 Cloudflare 계획에 사용할 수 없습니다.
- 현재 API를 통해 HTTP DDoS 공격 보호 관리 규칙에 대한 계정 수준 구성 (또는 overrides) 만 정의 할 수 있습니다.

:::

규칙 행동을 조정하려면 다음 중 하나를 수행하십시오.

- [API를 통해 관리되는 규칙 구성](/ddos-protection/managed-rulesets/http/http-overrides/configure-api/).

사용 가능한 구성 매개 변수에 대한 자세한 내용은 참조[관리된 통치자 모수](/ddos-protection/managed-rulesets/http/override-parameters/).

## 근원은 규칙을 보호합니다

Cloudflare HTTP DDoS 보호는 원래의 건강에 근거한 완화를 시작할 수 있습니다.[Adaptive DDoS 차단](/ddos-protection/managed-rulesets/adaptive-protection/)사이트의 근원 오류 프로파일에서 탈선하는 트래픽을 감지하고 mitigates합니다. 지역 오류의 높은 수를 일으키는 요청의 홍수 (기본 감도 수준은 초당 1,000 오류) 영역에서 균류를 완화하는 완화에 대한 완화를 시작할 수 있습니다.

| 규칙 ID                              | 이름 \*                       |
| ---------------------------------- | --------------------------- |
| `dd42da7baabe4e518eaf11c393596a9d` | HTTP 요청은 소스 오류의 높은 수를 일으키는. |

:::참조
이 규칙은 모든 계획에 영역에서 사용할 수 있습니다.
주요 특징

'Cloudflare'의 네트워크는 자동적으로 모니터링하고 큰 DDoS 공격을 완화하는 데 내장되어 있지만, 'Cloudflare'는 다음과 같은 일반적인 규칙에 따라 더 작은 DDoS 공격을 완화하는 데 도움이됩니다.

- 어떤 계획에서 영역의 경우, Cloudflare는 HTTP 오류율이 위의 경우 완화를 적용합니다.*사이트맵*(과태) 1,000개의 오류당 초당 비율 임계값의 감도 수준. HTTP DDoS 공격 보호 관리 규정을 구성하여 감도 수준을 줄일 수 있습니다.

- Pro, Business 및 Enterprise 계획의 영역에서 'Cloudflare'는 더 나은 탐지 정확도에 대한 추가 검사를 수행합니다. 오류 - 초당 비율은 DDoS 완화를 적용하기 전에 최소 5 배 이상 일반 트래픽 수준이어야합니다.

모든 HTTP 오류`52x`범위 (Internal Server Error) 및 모든 오류`53x`범위 제외[`530`](/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-530)오류율에 영향을 미칠 때 고려됩니다. HTTP 오류율에 따라 DDoS 완화를 위해 특정 HTTP 오류 코드를 제외할 수 없습니다.

'Cloudflare'의 DDoS 보호에 의한 DDoS 공격 유형에 대한 자세한 내용은 참조[DDoS 공격](/ddos-protection/about/attack-coverage/).

## 적용분야

HTTP DDoS 공격 보호 관리 규정은 지역을위한 모든 계획에서 'Cloudflare'고객을 보호합니다.[Cloudflare에 내장](/dns/zone-setups/full-setup/). 모든 고객은 지역 수준과 계정 수준에서 통치자를 둘 다 주문을 받아서 만들 수 있습니다.

Enterprise 플랜의 고객은 고급 DDoS 보호 가입을 통해 최대 10개의 오버라이드(또는 최대 10개의 규칙, API 사용자용)을 만들 수 있습니다.[이름 \*](/ddos-protection/managed-rulesets/http/http-overrides/override-expressions/)다른 들어오는 요구를 위한 DDoS 보호를 주문을 받아서 만들기 위하여.

다른 고객은 하나의 오버라이드 (또는 규칙) 만 만들 수 있으며 규칙 표현을 사용자 정의 할 수 없습니다. 이 경우, 하나의 override, 하나 이상의 구성을 포함, 항상 모든 들어오는 트래픽에 적용.

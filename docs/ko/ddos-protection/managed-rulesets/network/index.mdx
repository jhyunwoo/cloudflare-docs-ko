### Network Analytics 규칙 표시

Cloudflare는 Network-layer DDoS 관리 규정에 대한 새로운 탐지 규칙을 정기적으로 배포합니다. 높은 정확도를 보장하고 거짓 긍정을 극소화하기 위해, 이 규칙은 완전히 승진되기 전에 테스트 단계를 겪습니다.

규칙이 테스트 단계에있을 때, Cloudflare 대시보드에서 특정 행동을 알 수 있습니다.

새로운 규칙은 종종 기본적으로`Log`(방문 가능)**DDoS 관리 규칙** > **검색 규칙**). 이것은 합법적 인 패킷에 영향을 미치지 않고 실제 트래픽에 대한 규칙의 성능을 평가하는 것을 허용합니다.

내 계정[네트워크 Analytics](/analytics/network-analytics/)대시보드, 이러한 테스트 단계 규칙과 일치한 트래픽은`Log (rule disabled)`. 이 규칙을 나타내는 보고 협약은 사전 제작 모니터링 상태에 있습니다.

수동으로 규칙을 무시할 수 있지만`Log`으로`Block`, 이렇게 하기 전에 뒤에 고려하십시오:

- 테스트 단계의 규칙은 아직 완전히 넓은 배포를 위해 조정되지 않았습니다. 완화 활동에 대한 그들에게 배워 (like)`Block`)는 합법적인 교통의 위험을 증가시킬 수 있습니다.

- 규칙의 기본 동작은 테스트 기간 동안 결정됩니다. Cloudflare는 기본 동작을 설정할 수 있습니다.**DDoS 역학**트래픽 요인에 따라 속도 제한 또는 다중 단계 완화 조합을 사용할 수 있습니다. 자주 묻는 질문`Block`override, 한 번 더 nuanced DDoS 동적 동작을 자동으로 상속하여 구성을 방지합니다.

테스트 규칙을 무시하면 활성 공격을 완화 할 수 있습니다. "Cloudflare"는 규칙이 영구적 인 기본 행동으로 승진 한 경우 기간 동안 검토하는 것이 좋습니다.

## 적용분야

Network-layer DDoS 공격 보호 관리 규정은 모든 'Cloudflare' 계획에서 사용할 수 있습니다.

- 이름 \*[Cloudflare에 내장](/dns/zone-setups/full-setup/)(‘Cloudflare’ 네트워크를 통해 트래픽을 경로로 구분)
- IP 애플리케이션[스펙트럼](/spectrum/)
- IP 접두사 내장[매직 트레인](/magic-transit/)

그러나 Enterprise 플랜의 Magic Transit 및 Spectrum 고객만 관리 규칙을 사용자 정의 할 수 있습니다.

## 관련 Cloudflare 제품

Magic Transit 고객은 다음과 같은 추가 제품을 구성할 수 있습니다.

- 이름 \*[고급 TCP 보호](/ddos-protection/advanced-ddos-systems/overview/advanced-tcp-protection/)임의화된 ACK 홍수 또는 SYN 및 SYN-ACK 홍수와 같은 정교한 아웃 상태 TCP 공격을 감지하고 mitigate합니다.
- 사용자 정의[네트워크 방화벽](/cloudflare-network-firewall/)추가 네트워크 레이어 공격을 차단하는 규칙.

Spectrum 고객은 사용할 수 있습니다.[IP 접근](/waf/tools/ip-access-rules/)추가 네트워크 레이어 공격을 차단하는 규칙.

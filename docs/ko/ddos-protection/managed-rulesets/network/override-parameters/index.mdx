Network-layer DDoS 공격 보호 관리 규정에 대한 overrides를 정의하여 주어진 공격에 적용된 행동을 변경하거나 탐지 메커니즘의 감도 수준을 수정합니다. 당신은 할 수[Cloudflare 대시보드\`에서 overrides 정의](/ddos-protection/managed-rulesets/network/network-overrides/configure-dashboard/)또는[Rulesets API를 통한 오버라이드 정의](/ddos-protection/managed-rulesets/network/network-overrides/configure-api/).

사용 가능한 매개 변수는 다음과 같습니다:

- \- 연혁
- 감도 수준

## - 연혁

API 속성 이름:`"action"`.

'Cloudflare'의 DDoS 완화 서비스의 특정 규칙과 일치 패킷을 위해 수행 된 작업. 사용 가능한 작업은:

- **로그인**
  - API 가치:`"log"`.
  - Enterprise 플랜에서만 사용할 수 있습니다. 네트워크 레이어 DDoS 공격을 감지하는 규칙의 표현과 일치하는 로그 요청. 더 심한 행동에 투입하기 전에 규칙을 검증하는 것이 좋습니다.<Render file="log-and-monitor-behavior-link" product="ddos-protection" />

- **제품정보**
  - API 가치:`"block"`.
  - 룰 표현과 일치하는 IP 패킷을 차단합니다.

- **DDoS 역학**
  - API 가치:*사이트맵*(외부 규칙은 과도하게 사용할 수 없습니다).
  - "Cloudflare"에 의해 정의 된 내부 가이드 세트에 따라 특정 작업을 수행합니다. 실행된 동작은*제품정보*또는 비공개 완화 활동.

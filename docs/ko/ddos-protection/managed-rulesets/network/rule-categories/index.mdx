Network-layer DDoS 공격 보호의 주요 범주는 다음과 같습니다.

| 이름 \*       | 이름 \*                                                                                                                                                                                                       |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gre`       | 일반적으로 GRE 엔드포인트를 타겟팅하는 Generic Routing Encapsulation (GRE)를 통해 DDoS 공격에 대한 규칙.                                                                                                                              |
| `esp`       | IPsec 보안 네트워크 프로토콜 제품군의 일부인 Encapsulating Security Payload (ESP) 프로토콜과 관련된 DDoS 공격 규칙.                                                                                                                      |
| `advanced`  | Enterprise 고객에게 제공되는 기능과 관련된 규칙[Adaptive DDoS 차단](/ddos-protection/managed-rulesets/adaptive-protection/).                                                                                                  |
| `generic`   | 패킷의 감지 및 mitigating 홍수를위한 규칙. 이 규칙은 알려진 서명이없는 공격에 유용하지만 그들은 합법적 인 트래픽의 비정상적인 높은 볼륨에 방아쇠를 수 있습니다. false 긍정적의 위험을 줄이기 위해, 두 번째 (pps) 활성화 임계 값 당 패킷은 더 높습니다. 이 규칙 속도 제한 트래픽 기본적으로, 하지만 필요한 경우 트래픽을 차단할 수 있습니다. |
| `read-only` | <Render file="managed-rulesets/read-only-rules-description" product="ddos-protection" />                                                                                                                    |
| `test`      | <Render file="managed-rulesets/test-rules-description" product="ddos-protection" />                                                                                                                         |

공격 벡터 / protocol을 기반으로 다른 규칙 범주가 있습니다.`dns`, `quic`·`sip`. 범주 목록은 역동적이고 시간이 넘을 수 있습니다.

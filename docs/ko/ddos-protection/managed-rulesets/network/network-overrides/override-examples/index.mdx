## 사용 사례

다음과 같은 시나리오는 일반적인 네트워크 DDoS 보호 문제에 대한 해결책으로 과도한 규칙의 사용을 만들 수 있는 방법을 상세히 설명합니다.

### VPN 트래픽은 UDP 규칙에 의해 차단됩니다.

VPN 트래픽이 단일 또는 몇 가지 단일 대상 IP 주소에 집중하고 트래픽은 UDP 규칙에 의해 차단되고, 대상 IP 또는 범위에 UDP 규칙에 대한 오버라이드 규칙을 만들 수 있습니다.

:::참조
override는 검출에 적용하고 지문이 생성되지 않고 완화에 사용됩니다. 더 알아보기[중요한 말](/ddos-protection/managed-rulesets/network/network-overrides/override-expressions/#important-remarks)더 많은 정보.
주요 특징

### 공격 트래픽은 UDP 및 대상 포트에 따라 적응 규칙에 의해 떨어졌다

UDP 및 목적지 포트를 기반으로 적응 규칙에 의해 전달되는 트래픽이 공격을 인식하면, 당신은 완화 모드에서 적응 규칙을 활성화하고 트래픽을 차단하는 작업을 설정하는 오버라이드 규칙을 만듭니다.

### 생산 트래픽에 영향을 미치는 false Positives의 위험을 최소화

초기 배포 중에 혼란을 피하기 위해, 당신은 만들 수 있습니다*로그인*만 –*자주 묻는 질문*모든 트래픽을 추적하는 동안 규칙 override. 이 작업을 안전하게 관찰하고 수행하기 전에 DDoS 활동을 분석합니다.

1. 'Cloudflare'에서 '대시보드'로 이동**보안 규칙**사이트 맵

   <DashButton url="/?to=/:account/:zone/security/security-rules" />
2. 오시는 길**DDoS 보호**탭.
3. 이름 \***HTTP DDoS 공격 보호**, 선택**오버라이드**.
4. 설정하기**관련 상품**으로*모든 수신 요청에 적용*.
5. 이름 \***Ruleset 구성**:
   - 설정하기**Ruleset 작업**으로*로그인*.
   - 설정하기**Ruleset 감도**으로*자주 묻는 질문*.
6. 제품정보**제품 정보**.

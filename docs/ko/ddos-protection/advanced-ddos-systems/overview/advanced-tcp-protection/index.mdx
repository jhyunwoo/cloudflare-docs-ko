## 어떻게 작동합니까?

고급 TCP 보호는 다른 종류의 공격에 대하여 동시에 보호할 수 있습니다:

- 특정 목적지 IP / 포트 조합을 대상으로 핀 포인트 공격.
- IP 접두사의 여러 IP 주소를 동시에 타겟팅하는 넓은 공격.

고급 TCP 보호는 Cloudflare 데이터 센터 사이에서 이동하는 경우에도 TCP 연결을 추적 할 수 있습니다.

특징은 보호의 2가지 유형을 제안합니다:

- [SYN 홍수 보호](/ddos-protection/advanced-ddos-systems/overview/advanced-tcp-protection/#syn-flood-protection): 완전히 무작위 SYN 및 SYN-ACK 홍수와 같은 공격에 대한 보호.
- [Out-of-state TCP 보호](/ddos-protection/advanced-ddos-systems/overview/advanced-tcp-protection/#out-of-state-tcp-protection): ACK 홍수 및 RST 홍수와 같은 아웃 상태 TCP DDoS 공격에 대한 보호.

각 보호 유형은 규칙과 (선택) 필터를 사용하여 자주적으로 형성됩니다. 고급 TCP 보호를 가능하게 하기 전에 보호의 각 유형에 대 한 적어도 하나의 규칙을 구성 해야 합니다.

### SYN 홍수 보호

이 시스템은 완전히 무작위 SYN 및 SYN-ACK 홍수와 같은 공격에 대해 보호합니다. 고급 TCP 보호를 가능하게 하기 전에 적어도 1개의 SYN 홍수 규칙을 구성해야 합니다.

완화 모드에서 SYN 홍수 규칙은 구성 된 패킷 당 두 번째 임계값을 초과하면 새로운 연결 개시 요청 (SYN, SYN-ACK)에 도전합니다. 임계 값은 네트워크가 수신하는 합법적 인 SYN 및 SYN-ACK 패킷의 정상적인 비율보다 높아야한다. 아래 패킷은 도전되지 않습니다. 사용 방법[비율 감도](/ddos-protection/advanced-ddos-systems/concepts/#rate-sensitivity)·[파열 감도](/ddos-protection/advanced-ddos-systems/concepts/#burst-sensitivity)설정은 SYN과 SYN-ACK 패킷의 공차를 증가하거나 줄일 수 있습니다.

SYN 홍수 규칙의 구성 설정에 대한 자세한 내용은 참조[규칙 설정](/ddos-protection/advanced-ddos-systems/concepts/#rule-settings).

### Out-of-state TCP 보호

이 시스템은 완전히 무작위 ACK 홍수 및 RST 홍수와 같은 아웃 상태 TCP DDoS 공격에 대해 보호합니다. 고급 TCP 보호를 가능하게 하기 전에 1개의 아웃-of-state TCP 규칙을 구성해야 합니다.

mitigation mode에서, out-of-state TCP 규칙은 지정된 임계값을 초과하는 경우 기존 (그리고 추적) TCP 연결에 속하지 않는 외부 패킷을 삭제합니다. 임계 값은 네트워크가 수신하는 비 SYN 또는 SYN-ACK TCP 패킷의 정상적인 비율보다 높아야 합니다. 아래 패킷은 평가되지 않습니다. 사용 방법[비율 감도](/ddos-protection/advanced-ddos-systems/concepts/#rate-sensitivity)·[파열 감도](/ddos-protection/advanced-ddos-systems/concepts/#burst-sensitivity)설정은 out-of-state TCP 패킷의 공차를 늘릴 수 있습니다.

out-of-state TCP 규칙의 구성 설정에 대한 자세한 내용은 참조[규칙 설정](/ddos-protection/advanced-ddos-systems/concepts/#rule-settings).

## 어떻게 작동합니까?

Cloudflare의 고급 DNS 보호는 트래픽 패턴을 처음 학습하고 DNS 쿼리 유형의 기본 구성을 일반적으로 수신합니다. 나중에 시스템은 합법적 인 트래픽에 영향을 미치지 않고 DNS 인프라를 보호하는 합법적 인 악의적 인 쿼리와 구별 할 수 있습니다.

현재 보호 시스템은 UDP에 DNS 만 분석합니다. TCP에 DNS가 포함되지 않습니다.

더 보기[네트워크 분석 대시보드](/analytics/network-analytics/)고급 DNS 보호를 위한 시스템별 분석**DNS 보호**queried 도메인 및 레코드 유형을 포함하여 탭.

## 데이터 수집

Cloudflare는 쿼리 유형과 같은 DNS 관련 데이터를 수집합니다 (예를 들어,`A`기록) 그리고 잡은 도메인. 자주 묻는 질문[데이터 수집](/analytics/network-analytics/reference/data-collection/).

:::카트로션

현재, 이 데이터 수집을 비활성화하려면 Cloudflare\`대시보드 또는[접두사 삭제](/ddos-protection/advanced-ddos-systems/api/tcp-protection/#prefix-operations)API 가동. 그러나이 절차는 고급 DNS 보호와의 접두사를 제거 할 것입니다.[고급 TCP 보호](/ddos-protection/advanced-ddos-systems/overview/advanced-tcp-protection/).
:::

## 문제 해결

### Network Analytics의 고급 DNS 보호에 대한 데이터 없음

고급 DNS 보호와 관련된 모든 데이터를 찾을 수 없는 경우**DNS 보호**Network Analytics의 탭은 이러한 이유 중 하나가 될 수 있습니다.

- 당신은하지 않았다[당신의 접두사 추가](/ddos-protection/advanced-ddos-systems/how-to/add-prefix/)고급 L3/4 DDoS 보호에.
- 1 월 2025 이전에 존재하는 계정은 자동으로 제공되지 않았습니다. 1월 2025일 이전에 온 경우, Advanced DNS Protection은 귀하의 계정에서 사용할 수 없습니다.
- UDP 트래픽에 DNS가 없습니다.

***

## 관련 제품

고급 DNS 보호는 Volumetric DNS DDoS 공격에 대하여 당신을 보호할 수 있습니다. DNS 캐싱, 프록시 및 구성을 수행하려면[Cloudflare DNS 방화벽](/dns/dns-firewall/).

현재 고급 DNS 보호는 DNS 방화벽에 사용할 수 없습니다.

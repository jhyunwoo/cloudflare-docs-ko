고급 DDoS 보호에서 접두사 또는 접두사 잠수함 제외:

<Steps>
  1. 'Cloudflare'에서 '대시보드'로 이동**L3/4 DDoS 보호**사이트 맵

     <DashButton url="/?to=/:account/network-security/ddos" />
  2. 오시는 길**고급 보호**.
  3. [접두사 추가](/ddos-protection/advanced-ddos-systems/how-to/add-prefix/)이전에 Magic Transit을 Advanced TCP Protection에 탑재했습니다.
  4. [접두사 추가](/ddos-protection/advanced-ddos-systems/how-to/add-prefix/)(또는 subset) 당신은 고급 TCP 보호에 새로운 별도의 접두사로 제외합니다.
  5. 이전 단계에 추가된 접두사를 위해, 선택**서브셋 제외**내 계정**연락처**이름 \*
</Steps>

:::참조

Prefixes 또는 subsets 추가*이름 \**&#xACE0;급 TCP 보호에 의해 보호되지 않습니다.

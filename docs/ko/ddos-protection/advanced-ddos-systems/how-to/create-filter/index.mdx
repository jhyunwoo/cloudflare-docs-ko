각 보호 시스템 구성 요소 (SYN 홍수 보호 또는 아웃-of-state TCP 보호) 적어도 하나 있어야[으로](/ddos-protection/advanced-ddos-systems/concepts/#rule), 그러나 여과기는 선택적입니다.

:::참조
고급 TCP 보호에만 필터링합니다.
주요 특징

## 회사연혁

회사 소개[제품정보](/ddos-protection/advanced-ddos-systems/concepts/#filter)체계 성분의 한을 위해:

{/* prettier-ignore */}

<Steps>
  1. 'Cloudflare'에서 '대시보드'로 이동**L3/4 DDoS 보호**사이트 맵

     <DashButton url="/?to=/:account/network-security/ddos" />
  2. 오시는 길**고급 보호** > **고급 TCP 보호**.
  3. 필터를 생성하는 시스템 구성 요소의 밑에 (**SYN 홍수 보호**또는**Out-of-state TCP 보호**), 선택**이름 \***&#xB9CC;든 필터의 유형 옆에:
     - **Mitigation 필터**: 보호 시스템 드롭<GlossaryTooltip term="data packet">제품정보</GlossaryTooltip>필터 표현식 일치. -**감시 필터**: 보호 시스템 로그
       필터식을 일치하는 패킷.
     - **필터 해제**: 보호 시스템은 필터 표현과 일치하는 패킷을 무시합니다.
  4. 이름 \***수신 패킷 일치**Expression Builder를 사용하여 필터 표현을 정의합니다 (하나 이상의 값을 지정)**제품정보**, **회사연혁**·**제품정보**), 또는 수동으로 Expression Editor를 사용하여 표현을 입력합니다. 더 많은 정보를 원하시면, 참조[규칙 표현](/ruleset-engine/rules-language/expressions/edit-expressions/).
  5. 제품정보**제품 정보**.
</Steps>

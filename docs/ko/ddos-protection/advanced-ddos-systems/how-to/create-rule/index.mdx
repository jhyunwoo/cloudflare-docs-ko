## 고급 DNS 보호 규칙 만들기

{/* prettier-ignore */}

<Steps>
  1. 'Cloudflare'에서 '대시보드'로 이동**L3/4 DDoS 보호**사이트 맵

     <DashButton url="/?to=/:account/network-security/ddos" />
  2. 오시는 길**고급 보호** > **일반 설정**.
  3. 당신은 내장을 원한다. 고급 DNS 보호는 내장판에만 적용됩니다. 이미 원하는 접두사를 내장하면 고급 TCP 보호를 구성할 때 다른 작업을 수행 할 필요가 없습니다.
     :::참조
     현재 내장된 접두사 목록은 고급 TCP 보호와 공유됩니다. 모든 내장된 접두사는 고급 TCP 보호 및 고급 DNS 보호에 적용되며 계정 팀이 두 시스템의 초기 구성을 수행했습니다. 그러나 모니터링 모드에서 고급 TCP 보호를 떠날 수 있습니다.
     주요 특징
  4. 오시는 길**고급 DNS 보호**.
  5. 제품정보**고급 DNS 만들기 보호 규칙**.
  6. 내 계정**주요 특징**, 규칙에 대한 모드를 선택합니다.
  7. 이름 \***설정 범위**, 선택[제품정보](/ddos-protection/advanced-ddos-systems/concepts/#scope)규칙에 의해 영향을받을 패킷의 범위를 결정합니다.
  8. 이름 \***IR 정보**, 정의[파열 감도](/ddos-protection/advanced-ddos-systems/concepts/#burst-sensitivity), [비율 감도](/ddos-protection/advanced-ddos-systems/concepts/#rate-sensitivity)·[단면도 감도](/ddos-protection/advanced-ddos-systems/concepts/#profile-sensitivity)완화를 시작할 때 결정하십시오. 9. 선택**계정 만들기**.
</Steps>

## 고급 TCP 보호 규칙 만들기

회사 소개[SYN 홍수 규칙](/ddos-protection/advanced-ddos-systems/overview/advanced-tcp-protection/#syn-flood-protection)또는[외부 TCP](/ddos-protection/advanced-ddos-systems/overview/advanced-tcp-protection/#out-of-state-tcp-protection)규칙 :

{/* prettier-ignore */}

<Steps>
  1. 'Cloudflare'에서 '대시보드'로 이동**L3/4 DDoS 보호**사이트 맵

     <DashButton url="/?to=/:account/network-security/ddos" />
  2. 오시는 길**고급 보호** > **고급 TCP 보호**.
  3. 당신이 만드는 규칙에 따라, 다음 중 하나를 수행:
     - 이름 \***SYN 홍수 보호**, 선택**SYN 홍수 규칙 만들기**.
     - 이름 \***Out-of-state TCP 보호**, 선택**외부 TCP 규칙 만들기**.
  4. 내 계정**주요 특징**, 선택[지원하다](/ddos-protection/advanced-ddos-systems/concepts/#mode)규칙을 위해.
  5. 이름 \***설정 범위**, 선택[제품정보](/ddos-protection/advanced-ddos-systems/concepts/#scope)규칙을 위해. 수신 패킷의 하위 설정에 규칙을 적용하려면 지역 또는 데이터 센터를 선택하십시오.
  6. 이름 \***IR 정보**, 정의[파열 감도](/ddos-protection/advanced-ddos-systems/concepts/#burst-sensitivity)·[비율 감도](/ddos-protection/advanced-ddos-systems/concepts/#rate-sensitivity)규칙의 (기본값으로,*한국어*). 감도 수준은 당신의 특정한 케이스를 위한 처음 형성한 문턱에 근거를 둡니다.
  7. 제품정보**계정 만들기**.
</Steps>

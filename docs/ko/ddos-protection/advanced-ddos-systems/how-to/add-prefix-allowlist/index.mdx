IP 주소를 추가하거나 고급 DDoS 보호에 대한 접두사[관련 상품](/ddos-protection/advanced-ddos-systems/concepts/#allowlist):

<Steps>
  1. 'Cloudflare'에서 '대시보드'로 이동**L3/4 DDoS 보호**사이트 맵

     <DashButton url="/?to=/:account/network-security/ddos" />
  2. 오시는 길**고급 보호**.
  3. 이름 \***일반 설정** > **회사 소개**, 선택**제품정보**.
  4. 접두사 및 (선택) 설명을 입력**연락처**·**이름 \***&#xAC01;각.
  5. 대신 수당에서 현재 접두사를 제외하려면, uncheck the**이름 \***&#xCCB4;크박스. 6. 선택**더 보기**.
</Steps>

허용 목록은 규칙에 대한 단일 표현식의 약 200 IP 주소를 지원합니다.

# JSON 객체

이 페이지에는 API에서 사용되는 DNS 보호 규칙 JSON 객체의 예가 포함되어 있습니다.

```json
{
  "id": "31c70c65-9f81-4669-94ed-1e1e041e7b06",
  "scope": "region",
  "name": "WEUR",
  "mode": "monitoring",
  "profile_sensitivity": "medium",
  "rate_sensitivity": "medium",
  "burst_sensitivity": "medium",
  "created_on": "2023-10-01T13:10:38.762503+01:00",
  "modified_on": "2023-10-01T13:10:38.762503+01:00"
}
```

더 보기`scope`필드 값은 하나이어야한다.`global`, `region`, 또는`datacenter`. 지역 코드(또는 데이터 센터 코드)를 제공해야 합니다.`name`지정할 때 필드`region`(주)`datacenter`) 범위.

더 보기`mode`가치는 1개이어야 합니다`enabled`, `disabled`, 또는`monitoring`.

더 보기`profile_sensitivity`필드 값은 하나이어야한다.`low`(과태)`medium`, `high`, 또는`very_high`.

더 보기`rate_sensitivity`·`burst_sensitivity`필드 값은 하나이어야 한다.`low`, `medium`, 또는`high`.

규칙 설정에 대한 자세한 내용은 참조[규칙 설정](/ddos-protection/advanced-ddos-systems/concepts/#rule-settings).

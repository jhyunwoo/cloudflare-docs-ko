사용 방법[Cloudflare API](/api/)API를 통해 고급 DNS 보호를 구성합니다.

API 호출 예시, 참조[Common API 호출](/ddos-protection/advanced-ddos-systems/api/dns-protection/examples/).

## 이름 \*

완전한 엔드포인트를 얻기 위해, Cloudflare API base URL 아래에 나열된 고급 DNS 보호 API 엔드포인트를 추가하십시오:

```txt
https://api.cloudflare.com/client/v4
```

더 보기`{account_id}`인수는[계정 ID](/fundamentals/account/find-account-and-zone-ids/)(진수 문자열). 'Cloudflare 대시보드\`에서 이 값을 찾을 수 있습니다.

다음 테이블은 사용할 수있는 작업을 요약합니다.

| - 연혁            | Verb + 엔드포인트                                                                                                                             |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| DNS 보호 규칙 목록    | <p>`GET accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules`</p>계정의 모든 DNS 보호 규칙을 Fetches.                  |
| DNS 보호 규칙 추가    | <p>`POST accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules`</p>계정에 DNS 보호 규칙을 추가합니다.                      |
| DNS 보호 규칙 받기    | <p>`GET accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules/{rule_id}`</p>계정의 기존 DNS 보호 규칙의 세부 사항을 Fetches. |
| DNS 보호 규칙 업데이트  | <p>`PATCH accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules/{rule_id}`</p>계정에서 기존 DNS 보호 규칙을 업데이트하십시오.    |
| DNS 보호 규칙 삭제    | <p>`DELETE accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules/{rule_id}`</p>계정에서 기존 DNS 보호 규칙을 삭제합니다.      |
| 모든 DNS 보호 규칙 삭제 | <p>`DELETE accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules`</p>계정에서 모든 기존 DNS 보호 규칙을 삭제합니다.             |

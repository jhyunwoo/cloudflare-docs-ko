다음 섹션에는 공통 API 호출에 대한 예 요청이 포함되어 있습니다. 사용 가능한 API 엔드포인트 목록의 경우, 참조[이름 \*](/ddos-protection/advanced-ddos-systems/api/dns-protection/#endpoints).

## 모든 DNS 보호 규칙을 얻으십시오

다음 예제는 현재 고급 DNS 보호를위한 규칙을 검색합니다.

```bash title="Request"
curl "https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules" \
--header "Authorization: Bearer <API_TOKEN>"
```

```json output
---
{
  "result": [
    {
      "id": "<RULE_ID>",
      "scope": "<SCOPE>",
      "name": "<NAME>",
      "mode": "<MODE>",
      "profile_sensitivity": "<SENSITIVITY>",
      "rate_sensitivity": "<RATE>",
      "burst_sensitivity": "<BURST>",
      "created_on": "2023-10-01T13:10:38.762503+01:00",
      "modified_on": "2023-10-01T13:10:38.762503+01:00",
      }
    ],
  "success": true,
  "errors": [],
  "messages": []
}
```

### DNS 보호 규칙 만들기

다음 예제는 글로벌 범위로 고급 DNS 보호 규칙을 만듭니다.

```bash title="Request"
curl "https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules" \
--header "Authorization: Bearer <API_TOKEN>" \
--data '{
  "scope": "global",
  "name": "global",
  "mode": "<MODE>",
  "rate_sensitivity": "<RATE>",
  "burst_sensitivity": "<BURST>",
  "profile_sensitivity": "<SENSITIVITY>"
}'
```

```json output
{
  "result": {
    "id": "<RULE_ID>",
    "scope": "global",
    "name": "global",
    "mode": "<MODE>",
    "rate_sensitivity": "<RATE>",
    "burst_sensitivity": "<BURST>",
    "profile_sensitivity": "<SENSITIVITY>",
    "created_on": "2023-10-01T13:10:38.762503+01:00",
    "modified_on": "2023-10-01T13:10:38.762503+01:00",
  },
  "success": true,
  "errors": [],
  "messages": []
}
```

더 알아보기[JSON 객체](/ddos-protection/advanced-ddos-systems/api/dns-protection/json-objects/)JSON body의 필드에 더 많은 정보를 제공합니다.

### DNS 보호 규칙 업데이트

다음 예제는 기존 DNS 보호 규칙을 ID로 업데이트`{rule_id}`.

요청 몸은 업데이트하려는 필드 만 포함 할 수 있습니다 (from`mode`, `profile_sensitivity`, `rate_sensitivity`·`burst_sensitivity`).

```bash title="Request"
curl --request PATCH \
"https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules/{rule_id}" \
--header "Authorization: Bearer <API_TOKEN>" \
--data '{
  "mode": "<NEW_MODE>",
  "profile_sensitivity": "<NEW_SENSITIVITY>",
  "rate_sensitivity": "<NEW_RATE>",
  "burst_sensitivity": "<NEW_BURST>"
}'
```

```json output
{
  "result": {
    "id": "<RULE_ID>",
    "scope": "<SCOPE>",
    "name": "<NAME>",
    "mode": "<NEW_MODE>",
    "profile_sensitivity": "<NEW_SENSITIVITY>",
    "rate_sensitivity": "<NEW_RATE>",
    "burst_sensitivity": "<NEW_BURST>",
    "created_on": "2023-10-01T13:10:38.762503+01:00",
    "modified_on": "2023-10-01T13:10:38.762503+01:00",
  },
  "success": true,
  "errors": [],
  "messages": []
}
```

더 알아보기[JSON 객체](/ddos-protection/advanced-ddos-systems/api/dns-protection/json-objects/)JSON body의 필드에 더 많은 정보를 제공합니다.

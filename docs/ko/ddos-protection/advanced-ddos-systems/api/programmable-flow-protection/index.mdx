사용 방법[Cloudflare API](/api/)API를 통해 풀그릴 Flow Protection을 구성합니다.

API 호출의 예를 들어, 참조[풀그릴 교류 보호](/ddos-protection/advanced-ddos-systems/overview/programmable-flow-protection/)문서.

## 이름 \*

완전한 엔드포인트를 얻으려면, 아래 나열된 풀그릴 Flow Protection API 엔드포인트를 Cloudflare API base URL에 추가하십시오.

```txt
https://api.cloudflare.com/client/v4
```

더 보기`{account_id}`인수는[계정 ID](/fundamentals/account/find-account-and-zone-ids/)(진수 문자열). 'Cloudflare 대시보드\`에서 이 값을 찾을 수 있습니다.

다음 테이블은 사용할 수있는 작업을 요약합니다.

### 프로그램 API 엔드포인트

| - 연혁        | Verb + 엔드포인트                                                                                     |
| ----------- | ------------------------------------------------------------------------------------------------ |
| 프로그램        | `POST /accounts/{account_id}/magic/programmable_flow_protection/configs/programs`                |
| 프로그램 업데이트   | `PATCH /accounts/{account_id}/magic/programmable_flow_protection/configs/programs/{program_id}`  |
| 공지사항        | `GET /accounts/{account_id}/magic/programmable_flow_protection/configs/programs`                 |
| 프로그램        | `DELETE /accounts/{account_id}/magic/programmable_flow_protection/configs/programs/{program_id}` |
| 모든 프로그램을 삭제 | `DELETE /accounts/{account_id}/magic/programmable_flow_protection/configs/programs`              |

### 규칙 API 엔드포인트

| - 연혁      | Verb + 엔드포인트                                                                               |
| --------- | ------------------------------------------------------------------------------------------ |
| 규칙 만들기    | `POST /accounts/{account_id}/magic/programmable_flow_protection/configs/rules`             |
| 규칙 업데이트   | `PATCH /accounts/{account_id}/magic/programmable_flow_protection/configs/rules/{rule_id}`  |
| 목록 규칙     | `GET /accounts/{account_id}/magic/programmable_flow_protection/configs/rules`              |
| 규칙을 삭제    | `DELETE /accounts/{account_id}/magic/programmable_flow_protection/configs/rules/{rule_id}` |
| 모든 규칙을 삭제 | `DELETE /accounts/{account_id}/magic/programmable_flow_protection/configs/rules`           |

### 디버그 패킷 캡쳐 (PCAP) API 엔드포인트

| - 연혁             | Verb + 엔드포인트                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 디버그 패킷 캡쳐 (PCAP) | `POST /accounts/{account_id}/magic/programmable_flow_protection/configs/programs/{program_id}/pcap?ip_offset={ip_offset_value}` |

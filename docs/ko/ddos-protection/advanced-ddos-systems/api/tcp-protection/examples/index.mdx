다음 섹션에는 공통 API 호출에 대한 예 요청이 포함되어 있습니다. 사용 가능한 API 엔드포인트 목록의 경우, 참조[이름 \*](/ddos-protection/advanced-ddos-systems/api/tcp-protection/#endpoints).

## 고급 TCP 보호 상태

이 예제는 Advanced TCP Protection (enabled 또는 비활성화)의 현재 상태를 얻습니다.

```bash title="Request"
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/tcp_protection_status \
--header "Authorization: Bearer <API_TOKEN>"
```

```json title="Example response"
{
  "result": {
    "enabled": false
  },
  "success": true,
  "errors": [],
  "messages": []
}
```

## TCP 보호 기능

이 예제는 고급 TCP 보호를 가능하게 합니다.

```bash title="Request"
curl --request PATCH \
https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/tcp_protection_status \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "enabled": true
}'
```

## 기존의 접두사

이 예제는 고급 TCP 보호에서 모든 기존의 접두사를 fetches합니다.

```bash title="Request"
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/prefixes \
--header "Authorization: Bearer <API_TOKEN>"
```

```json output
{
  "result": [
    {
      "prefix": "203.0.113/24",
      "comment": "My prefix",
      "excluded": false
    }
  ],
  "success": true,
  "errors": [],
  "messages": []
}
```

## 연락처

이 예제`POST`요청은 두 개의 접두사를 추가합니다. 두 번째 접두사는 고급 TCP 보호에서 첫 접두사를 제외합니다.

```bash title="Request"
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/prefixes/bulk \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '[
  {
    "prefix": "192.0.2.0/24",
    "comment": "Game ranges",
    "excluded": false
  },
  {
    "prefix": "192.0.2.2/26",
    "comment": "Range for a specific game",
    "excluded": true
  }
]'
```

```json output
{
  "result": [
    {
      "id": "<PREFIX_1_ID>",
      "prefix": "192.0.2.0/24",
      "excluded": false,
      "comment": "Game ranges",
      "created_on": "<TIMESTAMP>",
      "modified_on": "<TIMESTAMP>"
    },
    {
      "id": "<PREFIX_2_ID>",
      "prefix": "192.0.2.2/26",
      "excluded": true,
      "comment": "Range for a specific game",
      "created_on": "<TIMESTAMP>",
      "modified_on": "<TIMESTAMP>"
    }
  ],
  "success": true,
  "errors": [],
  "messages": []
}
```

## allowlist에서 모든 접두사를 얻으십시오

이 예제는 허용 목록에 있는 모든 접두사를 태웁니다.

```bash title="Request"
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/allowlist \
--header "Authorization: Bearer <API_TOKEN>"
```

```json output

  "messages": []

```

## Allowlist에 접두사 추가

이 예제`POST`요청은 계정의 수당에 접두사를 추가합니다.

```bash title="Request"
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/allowlist \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \

  "comment": "Partner range",
```

```bash title="Request"

--header "Content-Type: application/json" \
--data '{
  "scope": "region",
  "name": "WEUR",

  "burst_sensitivity": "medium"
```

## SYN 홍수 필터 생성

이 예제`POST`요청은 SYN 홍수를 만듭니다[제품정보](/ddos-protection/advanced-ddos-systems/concepts/#filter)SYN 홍수 보호 설정은 특정 범위의 대상 IP 주소를 모니터링 할 수 있습니다.

```bash title="Request"
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/syn_protection/filters \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "expression": "ip.dst in { 192.0.2.0/24 }",
  "mode": "monitoring"
}'
```

## out-of-state TCP 필터 생성

이 예제`POST`요청은 out-of-state TCP를 생성합니다.[제품정보](/ddos-protection/advanced-ddos-systems/concepts/#filter), 대상 IP 주소와 포트의 특정 범위에 대 한 밖으로 상태 TCP 보호를 해제.

```bash title="Request"
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/tcp_flow_protection/filters \
--header "Authorization: Bearer <API_TOKEN>" \
--header "Content-Type: application/json" \
--data '{
  "expression": "ip.dst in { 203.0.113.0/24 } and tcp.dstport in { 8000..8081 }",
  "mode": "disabled"
}'
```

```json output
{
  "result": {
    "id": "<OOS_TCP_FILTER_ID>",

    "mode": "disabled",
    "created_on": "<TIMESTAMP>",
    "modified_on": "<TIMESTAMP>"
  },
  "success": true,
  "errors": [],
  "messages": []
}
```

더 알아보기[JSON 객체](/ddos-protection/advanced-ddos-systems/api/tcp-protection/json-objects/)JSON body의 필드에 더 많은 정보를 제공합니다.

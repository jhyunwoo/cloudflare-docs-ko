고급 TCP 보호 API를 사용하여 고급 TCP 보호를 구성할 수 있습니다.

고급 TCP 보호 API만 지원[API 토큰 인증](/fundamentals/api/get-started/create-token/).

API 호출 예시, 참조[Common API 호출](/ddos-protection/advanced-ddos-systems/api/tcp-protection/examples/).

## 이름 \*

완전한 엔드포인트를 얻기 위해, Cloudflare API base URL에 아래 나열된 고급 TCP 보호 API 엔드포인트를 추가합니다.

Cloudflare API base URL은 다음과 같습니다.

```txt
https://api.cloudflare.com/client/v4
```

더 보기`{account_id}`인수는 계정 ID입니다 (Jandecimal string). 'Cloudflare 대시보드\`에서 이 값을 찾을 수 있습니다.

다음 섹션의 테이블은 사용할 수있는 작업을 요약합니다.

### 일반 작업

| - 연혁         | 방법 및 엔드 포인트 / Description                                                                                                               |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| 고급 TCP 보호 상태 | <p>`GET accounts/{account_id}/magic/advanced_tcp_protection/configs/tcp_protection_status`</p>글로벌 고급 TCP 보호 상태(enabled 또는 비활성화)를 가져옵니다. |
| 고급 TCP 보호 상태 | <p>`PATCH accounts/{account_id}/magic/advanced_tcp_protection/configs/tcp_protection_status`</p>TCP 보호 기능을 사용하거나 비활성화합니다.               |

### 연락처

| - 연혁       | 방법 및 엔드 포인트 / Description                                                                                                     |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 연락처        | <p>`GET accounts/{account_id}/magic/advanced_tcp_protection/configs/prefixes`</p>계정의 모든 고급 TCP 보호 접두사.                        |
| 대량의 접두사 추가 | <p>`POST accounts/{account_id}/magic/advanced_tcp_protection/configs/prefixes/bulk`</p>계정에 대량의 접두사를 추가하십시오 (요청 당 300의 접두사까지). |
| 연락처        | <p>`GET accounts/{account_id}/magic/advanced_tcp_protection/configs/prefixes/{prefix_id}`</p>Fetches 기존 접두사의 세부 사항.           |
| 접두사 업데이트   | <p>`PATCH accounts/{account_id}/magic/advanced_tcp_protection/configs/prefixes/{prefix_id}`</p>기존 접두사 업데이트                    |
| 접두사 삭제     | <p>`DELETE accounts/{account_id}/magic/advanced_tcp_protection/configs/prefixes/{prefix_id}`</p>기존의 접두사를 삭제합니다.               |
| 모든 접두사 삭제  | <p>`DELETE accounts/{account_id}/magic/advanced_tcp_protection/configs/prefixes`</p>계정에서 모든 기존 접두사를 삭제합니다.                    |

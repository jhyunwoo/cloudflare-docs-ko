이 페이지에는 API에서 사용되는 TCP 보호 규칙 JSON 객체의 예가 포함되어 있습니다.

## 연락처

```json
{
  "id": "31c70c65-9f81-4669-94ed-1e1e041e7b06",
  "prefix": "192.0.2.0/24",
  "comment": "Game ranges",
  "excluded": false,
  "created_on": "2022-01-01T13:06:04.721954+01:00",
  "modified_on": "2022-01-01T13:06:04.721954+01:00"
}
```

## 허용 목록의 Prefix

```json
{
  "id": "31c70c65-9f81-4669-94ed-1e1e041e7b06",
  "prefix": "192.0.2.0/24",
  "comment": "Game ranges",
  "enabled": true,
  "created_on": "2021-10-01T13:06:04.721954+01:00",
  "modified_on": "2021-10-01T13:06:04.721954+01:00"
}
```

더 보기`prefix`필드는 IP 주소 또는 CIDR 범위를 포함 할 수 있습니다.

## SYN 홍수 규칙 또는 out-of-state TCP 규칙

```json
{
  "id": "31c70c65-9f81-4669-94ed-1e1e041e7b06",
  "scope": "region",
  "name": "WEUR",
  "rate_sensitivity": "medium",
  "burst_sensitivity": "medium",
  "created_on": "2021-10-01T13:10:38.762503+01:00",
  "modified_on": "2021-10-01T13:10:38.762503+01:00"
}
```

더 보기`scope`필드 값은 하나이어야한다.`global`, `region`, 또는`datacenter`. 지역 코드(또는 데이터 센터 코드)를 제공해야 합니다.`name`지정할 때 필드`region`(주)`datacenter`) 범위.

더 보기`rate_sensitivity`·`burst_sensitivity`필드 값은 하나이어야 한다.`low`, `medium`, 또는`high`.

## 제품정보

```json
{
  "id": "20b99eb6-8b48-48dd-a5b9-a995a0843b57",
  "expression": "ip.dst in { 192.0.2.0/24 203.0.113.0/24 } and tcp.dstport in { 80 443 10000..65535 }",
  "mode": "enabled",
  "created_on": "2022-11-01T13:10:38.762503+01:00",
  "modified_on": "2022-11-01T13:10:38.762503+01:00"
}
```

더 보기`expression`분야는[규칙 언어 표현](/ruleset-engine/rules-language/expressions/)다음 필드를 포함 할 수있는 8,192 문자까지 :

- `ip.src`
- `ip.dst`
- `tcp.srcport`
- `tcp.dstport`

:::참조

SYN 홍수 보호 및 out-of-state TCP 보호 필터의 표현은 현재 기능을 지원하지 않습니다.
주요 특징

더 보기`mode`가치는 1개이어야 합니다`enabled`, `disabled`, 또는`monitoring`.

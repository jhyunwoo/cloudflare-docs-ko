**Cloudflare Ray ID**는 Cloudflare를 통과하는 모든 요청에 부여되는 식별자입니다.

Ray ID는 보안 이벤트에서 패턴이나 오탐을 평가하거나, 보다 일반적으로 애플리케이션 트래픽을 이해할 때 특히 유용합니다.

Ray ID는 Cloudflare에서 원본 웹 서버로 가는 연결에 [요청 헤더 `cf-ray`](/fundamentals/reference/http-headers/#cf-ray)로 추가됩니다.
따라서 브라우저의 개발자 도구나, 헤더를 표시하는 `-v` 옵션과 함께 `curl`을 사용해 Ray ID를 찾을 수 있습니다.


:::caution
Ray ID가 모든 요청마다 고유하다고 보장되지는 않습니다. 일부 상황에서는 서로 다른 요청이 동일한 Ray ID를 가질 수 있습니다.
:::

## Ray ID 조회

### 보안 이벤트

모든 고객은 Security Events의 [샘플 로그](/waf/analytics/security-events/#sampled-logs)를 통해 Ray ID와 관련 정보(IP 주소, user agent, ASN 등)를 확인할 수 있습니다.

![확장된 이벤트 중 하나의 세부 정보에서 Ray ID가 강조 표시된 샘플 로그 이벤트 목록 예시](~/assets/images/fundamentals/ray-id.png)

또한 특정 Ray ID를 찾기 위해 [필터를 추가](/waf/analytics/security-events/#adjust-displayed-data)할 수 있습니다.

![Security Events에서 Block 작업용 새 필터를 추가하는 예시](~/assets/images/waf/events-add-filter.png)

Security Events는 성능 향상을 위해 샘플링된 데이터를 사용할 수 있습니다. 검색에 샘플링 데이터가 적용되면 모든 이벤트가 보이지 않을 수 있으며, 필터가 기대한 결과를 반환하지 않을 수 있습니다. 더 많은 이벤트를 표시하려면 더 짧은 시간 범위를 선택하십시오.

### Log Explorer

[Log Explorer](/log-explorer/)는 Cloudflare 플랫폼에서 사용 가능한 모든 컨텍스트와 함께 Cloudflare 로그에 접근할 수 있게 해줍니다.
사용자 지정 대시보드로 보안 및 성능 문제를 모니터링하거나, 로그 검색으로 문제를 조사하고 해결할 수 있습니다.
Log Explorer에서는 특정 Ray ID를 필터링하는 [쿼리 작성](/log-explorer/log-search/)이 가능합니다.

### 로그

Enterprise 고객은 [Cloudflare Logs](/logs/)의 필드로 Ray ID를 활성화할 수 있습니다.

### 서버 로그

Ray ID를 서버 로그로 보내는 방법에 대한 자세한 내용은 [Cf-Ray](/fundamentals/reference/http-headers/#cf-ray) 헤더를 참조하십시오.

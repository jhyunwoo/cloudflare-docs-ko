Cloudflare는 수백만 개의 웹사이트에 보안 및 신뢰성 서비스를 제공하여 온라인 악용을 방지하고 인터넷을 더욱 안전하게 만드는 데 도움을 줍니다.

Cloudflare 서비스를 사용하는 웹사이트에 대한 악용 신고의 경우, Cloudflare가 어떻게 대응할 수 있는지는 문제의 Cloudflare 서비스 유형에 따라 달라집니다. 대부분의 악용 신고는 패스스루 보안 및 콘텐츠 전송 네트워크(CDN) 서비스를 사용하는 웹사이트와 관련되어 있으며, 등록기관 서비스나 엣지에서 콘텐츠를 호스팅하는 서비스와 관련된 신고는 훨씬 적습니다. Cloudflare는 사용자에게 다양한 인터넷 인프라 서비스를 제공하므로, 악용 신고 시스템도 이러한 서로 다른 서비스를 고려해 설계되어 있습니다.

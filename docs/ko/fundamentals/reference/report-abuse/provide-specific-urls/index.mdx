웹사이트의 WHOIS 및 DNS 레코드에 Cloudflare IP 주소가 표시된다는 이유로 Cloudflare에 [악용 신고](https://abuse.cloudflare.com)를 제출하는 경우, 그 웹사이트는 Cloudflare의 패스스루 보안 및 콘텐츠 전송 네트워크(CDN) 서비스를 사용하는 수백만 개의 사이트 중 하나일 가능성이 매우 높습니다. 같은 웹사이트의 자산이라도 서로 다른 제공업체에 호스팅될 수 있으므로, 적절한 조치를 취할 수 있도록 해당 특정 자산의 URL을 제출하는 것이 중요합니다. 이 가이드는 웹페이지에서 특정 비디오나 이미지의 URL을 식별하는 방법을 설명합니다.

## 특정 콘텐츠의 URL 가져오기

웹페이지에서 특정 콘텐츠의 URL을 가져오려면:

1. 웹 브라우저(Google Chrome, Safari, Firefox, Edge)를 엽니다.

2. 신고하려는 웹페이지로 이동합니다.

3. 신고하려는 콘텐츠(보통 비디오 또는 이미지)를 마우스 오른쪽 버튼으로 클릭합니다.

4. **Inspect Element** 를 선택합니다.

5. **DevTools** 패널에서 선택된 이미지, 비디오 또는 iFrame의 **src** 속성을 찾습니다.
   ![Look for the URL in the src attribute of the video or image](~/assets/images/fundamentals/get-started/identify-url.png)

6. URL을 복사합니다.

가장 구체적이고 유용한 URL을 제공하면, Cloudflare가 해당 콘텐츠와 관련해 제공 중인 서비스가 무엇인지 정확히 식별하는 데 도움이 됩니다.

## 악용 신고 제출하기

특정 자산의 URL을 확인한 뒤에는 Cloudflare의 온라인 악용 신고 절차를 통해 [악용 신고를 제출](https://abuse.cloudflare.com)할 수 있습니다.

이 절차에 대한 자세한 내용과, Cloudflare가 이러한 악용 신고에 응답할 때 무엇을 기대할 수 있는지는 [Cloudflare의 악용 정책](https://www.cloudflare.com/trust-hub/reporting-abuse/)에서 확인할 수 있습니다.

Cloudy는 Cloudflare의 첫 번째 AI 에이전트 버전으로, 제품군 전반의 여러 영역에서 사용자가 Cloudflare 구성을 이해하고 개선할 수 있도록 돕는 어시스턴트형 기능을 제공합니다.

Cloudy는 [Workers AI](/workers-ai/)로 구동되며, 중복 규칙 식별, 실행 순서 최적화, 충돌하는 규칙 분석, 비활성화된 규칙 식별과 같은 문제를 찾아 해결하는 데 도움을 줍니다. 또한 위협 이벤트를 조사하고 실행 가능한 권장 사항을 제공할 수 있습니다.

## 제공 범위

현재 베타인 Cloudy는 WAF, Zero Trust, Analytics 등 여러 Cloudflare 제품에서 사용할 수 있습니다. 2025년 남은 기간 동안 Cloudflare는 Cloudflare의 다른 영역으로 추가 AI 에이전트 기능을 확장 배포할 계획입니다.

:::note[의견을 보내주세요]
여러분이 Cloudy를 만나고 새로운 AI 기능을 사용해 보면서 느낀 생각을 듣고 싶습니다. cloudyfeedback@cloudflare.com 으로 피드백을 보낼 수 있습니다. 여러분의 피드백은 AI 향상 로드맵을 형성하고, 모두가 더 안전해질 수 있도록 더 똑똑하고 더 효율적인 도구를 제공하는 데 도움이 됩니다.
:::

## Cloudy는 어떤 데이터에 접근할 수 있나요?

Cloudy는 Cloudflare 구성에 접근할 수 있습니다. 이 데이터는 목적에 맞게 설계된 LLM 프롬프트와 결합됩니다.

또한 Cloudy는 역할 기반 액세스 제어(RBAC) 제한을 고려합니다. 즉, 현재 로그인한 사용자가 자신의 [역할 및 권한](/fundamentals/manage-members/roles/)에 따라 접근할 수 있는 동일한 Cloudflare 구성 설정에만 접근할 수 있습니다.

모든 구성 정보는 목적에 맞게 설계된 프롬프트에만 포함되며, Cloudy나 이를 구동하는 LLM 모델 학습에는 사용되지 않습니다.

## Cloudy는 사용자 또는 고객 데이터로 학습되나요?

아니요. Cloudflare 구성은 Cloudy가 원시 구성 데이터를 일관되고 명확한 요약 및 실행 가능한 권장 사항으로 바꿀 수 있도록 하는 목적별 프롬프트에 사용됩니다.

Cloudy는 다른 고객과 Cloudflare 구성을 공유하지 않습니다. 구성은 LLM 모델 학습에도 사용되지 않습니다.

Cloudy는 Cloudflare의 다른 서비스와 동일한 엔터프라이즈급 보안을 제공합니다. 책임 있는 AI에 대한 Cloudflare의 접근 방식은 [Trust Hub](https://www.cloudflare.com/trust-hub/responsible-ai/)에서 자세히 알아볼 수 있습니다.

## Cloudy를 옵트아웃할 수 있나요?

현재 Cloudflare는 Cloudy의 가능한 모든 사용을 완전히 비활성화하는 옵트아웃 메커니즘을 제공하지 않습니다. Cloudflare 대시보드에서 제공되는 채팅 인터페이스에 대해서만 옵트아웃할 수 있습니다.

하지만 Cloudy는 전적으로 선택 사항인 도구이며, 사용하지 않기로 결정할 수 있습니다. Cloudy를 사용하지 않으면 현재 구성에 기반한 요약이나 실행 가능한 권장 사항을 받지 않게 됩니다.

채팅 인터페이스를 옵트아웃하려면 다음 단계를 따르십시오.

1. [Cloudflare 대시보드](https://dash.cloudflare.com/)에 로그인한 다음 계정을 선택합니다.
2. **Manage Account** > **Configurations**로 이동합니다.
3. **Cloudy features** 설정을 끕니다.

위에서 언급했듯이 Cloudy는 사용자 또는 고객 데이터로 학습되지 않으며, 다른 고객과 Cloudflare 구성을 공유하지 않습니다.

Google이 [권장하는 방법 중 하나](https://support.google.com/analytics/answer/9304153#add-tag)로 웹사이트에 추가되어 있다면, Cloudflare를 사용해도 Google Analytics(GA) 추적에는 영향을 주지 않습니다.

## 표준 GA 설정

Cloudflare는 원본 웹 서버로 가는 트래픽을 프록시하지만, GA JavaScript 코드는 실제로 서버로 트래픽을 보내지 않습니다. 대신 사용자 브라우저에서 직접 실행되며 Cloudflare와 상호작용하지 않습니다.

Cloudflare는 웹 서버 로그를 직접 읽는 분석 도구(예: awstats)에만 영향을 줍니다.

:::note


Google Analytics의 잠재적 문제를 해결하려면 [일반적인 GA 설정 실수](https://support.google.com/analytics/answer/1009683)를 참조하십시오.


:::

## Zaraz

태그/스니펫을 사용하는 표준 Google Analytics 설정의 대안으로, Cloudflare는 [Zaraz](/zaraz/)를 통해 Google Analytics를 사용할 수 있는 방법을 제공합니다. Zaraz는 웹사이트에 스크립트를 로드하지 않고도 Google Analytics가 데이터를 수집할 수 있게 해주는 솔루션입니다. GA가 이 방식으로 설정되면 일부 기능을 사용할 수 없을 수 있습니다.

:::note


Zaraz에서 사용할 수 없는 Google Analytics 기능에 대한 자세한 내용은 [Zaraz FAQ](/zaraz/faq/#tools)에서 확인할 수 있습니다.


:::

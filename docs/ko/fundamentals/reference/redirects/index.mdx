Cloudflare는 방문자 브라우저에 페이지 위치가 변경되었음을 알리는 <GlossaryTooltip term="redirect">URL 리디렉션</GlossaryTooltip>을 수행할 수 있는 다양한 방법을 제공합니다.

각 옵션을 언제 사용해야 하는지 판단하려면 아래 표를 참조하십시오.

| 옵션                                                        | 사용 시점                                               |
| ----------------------------------------------------------- | ------------------------------------------------------- |
| [Single redirects](/rules/url-forwarding/single-redirects/) | 기본 옵션으로 사용할 때                                 |
| [Bulk redirects](/rules/url-forwarding/bulk-redirects/)     | 정적 리디렉션이 매우 많은 경우                          |
| [Pages redirects](/pages/configuration/redirects/)          | Pages 프로젝트가 있는 경우                              |
| [Workers redirect](/workers/examples/redirect/)             | 다른 리디렉션 방식으로 요구사항을 충족할 수 없는 경우   |
| [Page Rules](/rules/page-rules/how-to/url-forwarding/)      | 이미 다른 요구사항 때문에 Page Rules를 사용 중인 경우   |

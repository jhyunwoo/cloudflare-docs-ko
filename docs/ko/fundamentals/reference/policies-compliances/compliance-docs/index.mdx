---

슈퍼 관리자(Super Administrator)는 Cloudflare 대시보드를 통해 PCI, SOC 2, ISO 등 일반적인 규정 준수 문서에 접근할 수 있습니다.

규정 준수 문서에 접근하려면:

1. [Compliance Documents](https://dash.cloudflare.com/?to=/:account/compliance-docs)로 이동한 뒤, 자신이 **Super Administrator** 인 계정을 선택합니다.
2. 이 페이지에 처음 접근하는 경우 기밀 유지 안내문을 읽고 **I Agree** 를 선택합니다.
3. 필요한 문서를 선택하고 **Download** 를 선택합니다.

:::note

기밀 유지 목적상, 계정의 **Super Administrators** 만 규정 준수 문서에 접근할 수 있습니다.
:::

## 공개 데이터 보호 및 규정 준수 문서

Cloudflare의 개인정보 보호 및 데이터 보호에 관한 정보와 문서는 공개 웹사이트 [cloudflare.com/trust-hub/](https://www.cloudflare.com/trust-hub/)에서 확인할 수 있습니다.

[Trust Hub](https://www.cloudflare.com/trust-hub/)에서는 다음과 관련된 정보와 문서를 찾을 수 있습니다.

* 개인정보 처리방침
* 데이터 처리 부속 계약(DPA)
* 유럽 일반개인정보보호법(GDPR)
* 브라질 일반 데이터 보호법(LGPD)
* 일본 개인정보 보호법(APPI)
* 싱가포르 개인정보보호법(PDPA)
* 대한민국 개인정보 보호법(PIPA)
* 인도 디지털 개인정보 보호 법안(DPDP)
* 호주 개인정보 보호법
* 미국 캘리포니아 소비자 개인정보 보호법(CCPA) 및 소비자 개인정보 권리법(CPRA)
* EU 디지털 운영 복원력 법(DORA)
* ISO 27001:2022
* ISO 27701:2019
* ISO 27018:2019
* FedRAMP Moderate
* SOC 2 Type II
* PCI DSS 4.0
* Global CBPR
* Global PRP
* EU Cloud Code of Conduct
* Cyber Essentials
* C5:2020
* ENS
* IRAP
* BSI Qualification
* WCAG 2.1 AA 및 Section 508

## 세금 문서

슈퍼 관리자, 결제 관리자(Billing Administrator), 관리자(Administrator)는 Cloudflare 대시보드를 통해 W-9 및 세금 증명서와 같은 세금 문서에 접근할 수 있습니다.

세금 문서에 접근하려면:

1. [Tax Documents](https://dash.cloudflare.com/?to=/:account/tax-docs)로 이동한 뒤, 자신이 **Super Administrator**, **Billing Administrator**, 또는 **Administrator** 인 계정을 선택합니다.
2. 필요한 문서를 선택하고 **Download** 를 선택합니다.

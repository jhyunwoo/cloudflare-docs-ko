**콘텐츠 보안 정책(CSP)** 은 다음을 포함한 특정 유형의 공격을 탐지하고 완화하는 데 도움이 되는 추가 보안 계층입니다.

- 콘텐츠/코드 주입
- 크로스 사이트 스크립팅(XSS)
- 악성 리소스 임베딩
- 악성 iframe(클릭재킹)

일반적인 CSP 구성 방법에 대해 더 알아보려면 [Mozilla 문서](https://developer.mozilla.org/docs/web/http/csp)를 참고하세요.

## Cloudflare와 함께 CSP 사용하기

Cloudflare의 [CDN](/cache/)은 CSP와 호환됩니다.

Cloudflare는 다음을 하지 않습니다.

- 오리진 웹 서버의 CSP 헤더를 수정하지 않습니다. 단, Zaraz 사용 시 [Zaraz 스크립트가 항상 실행되도록 보장](https://blog.cloudflare.com/cloudflare-zaraz-supports-csp/)하기 위한 경우는 예외입니다.
- 퍼스트파티 또는 서드파티 콘텐츠에 허용된 소스 변경을 요구하지 않습니다.
- URL을 수정하지 않습니다. 단, [`/cdn-cgi/` 엔드포인트](/fundamentals/reference/cdn-cgi-endpoint/)를 추가하거나 [Cloudflare Fonts](/speed/optimization/content/fonts/)가 Google Fonts URL을 다시 쓰는 경우는 예외입니다.
- CSP에 지정한 위치를 방해하지 않습니다.

CSP 헤더를 변경하거나 추가해야 한다면, 일부 Cloudflare 제품을 사용해 수정할 수 있습니다.

- 웹사이트가 Cloudflare를 통해 [프록시](/dns/proxy-status/)되고 있다면, [응답 헤더 변환 규칙](/rules/transform/response-header-modification/)을 사용해 CSP 헤더를 교체하거나 추가할 수 있습니다.
- 웹사이트가 [Cloudflare Pages](/pages/)로 호스팅된다면, [`_headers file`](/pages/configuration/headers/)을 설정해 CSP 헤더를 수정하거나 추가할 수 있습니다.

### 제품별 요구 사항

다만 특정 Cloudflare 기능을 사용하려면 CSP의 헤더를 업데이트해야 할 수 있습니다.

| 기능                                                                                                      | 업데이트할 헤더                                                                                                                                      |
| --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Rocket Loader](/speed/optimization/content/rocket-loader/)                                               | `script-src 'self' ajax.cloudflare.com;`                                                                                                            |
| [Scrape Shield](/waf/tools/scrape-shield/)                                                                | `script-src 'self' 'unsafe-inline'`                                                                                                                 |
| [Web Analytics](/web-analytics/)                                                                          | `script-src static.cloudflareinsights.com; connect-src cloudflareinsights.com`                                                                      |
| [Bot products](/bots/)                                                                                    | [JavaScript detections and CSPs](/cloudflare-challenges/challenge-types/javascript-detections/#if-you-have-a-content-security-policy-csp)를 참고하세요. |
| [Page Shield](/page-shield/)                                                                              | [Page Shield CSP Header format](/page-shield/reference/csp-header/)을 참고하세요.                                                                   |
| [Zaraz](/zaraz/)                                                                                          | 업데이트가 필요하지 않습니다([세부 정보](https://blog.cloudflare.com/cloudflare-zaraz-supports-csp/)).                                              |
| [Turnstile](/turnstile/)                                                                                  | [Turnstile CSP](/turnstile/reference/content-security-policy/)를 참고하세요.                                                                        |

Cloudflare는 네트워크 리소스를 극대화하고, 트래픽을 관리하며, 고객 사이트를 악성 트래픽으로부터 보호하기 위해 다양한 쿠키를 사용합니다.

## Cloudflare 쿠키 이해하기

[개인정보 처리방침](https://www.cloudflare.com/privacypolicy/)에 정의된 바와 같이, 아래에 나열된 모든 쿠키는 별도 명시가 없는 한 고객이 요청한 서비스를 제공하는 데 엄격히 필요한 항목입니다.

개인정보 처리방침에서 언급했듯이, Cloudflare는 고객이 최종 사용자에게 이러한 쿠키 사용 사실을 고지할 것을 권장합니다. 일부 관할권에서는 고객이 법적으로 이러한 쿠키를 최종 사용자에게 고지해야 할 수 있습니다.

기본적으로 쿠키 데이터는 미국 내 Cloudflare 데이터 센터에서 처리될 수 있으며, Cloudflare [개인정보 처리방침](https://www.cloudflare.com/privacypolicy/)의 국경 간 데이터 전송 섹션 7의 적용을 받습니다. [Data Localization Suite](/data-localization/)를 사용하는 고객은 쿠키 데이터가 처리되는 위치([Regional Services](/data-localization/regional-services/))와 기록되는 위치([Customer Metadata Boundary](/data-localization/metadata-boundary/) 사용)를 제어할 수 있습니다.

### Cloudflare Load Balancer 세션 어피니티용 \_\_cflb 쿠키

[Cloudflare Load Balancer](/load-balancing/understand-basics/session-affinity/)에서 세션 어피니티를 활성화하면, Cloudflare는 요청 클라이언트에 대한 첫 번째 응답에서 고유한 값을 가진 `__cflb` 쿠키를 설정합니다. Cloudflare는 이후 요청을 동일한 오리진으로 라우팅하여 네트워크 리소스 사용을 최적화합니다. 페일오버가 발생하면, Cloudflare는 이후 요청을 페일오버 풀로 보내기 위해 새로운 `__cflb` 쿠키를 설정합니다.

`__cflb` 쿠키를 사용하면 Cloudflare가 고객이 구성한 특정 기간 동안 최종 사용자를 동일한 고객 오리진으로 되돌릴 수 있습니다. 이를 통해 최종 사용자는 끊김 없는 경험을 할 수 있습니다. 예를 들어, 사용자가 웹사이트를 계속 탐색하는 동안 장바구니의 상품을 유지하는 데 이 쿠키가 사용됩니다. 이 쿠키는 몇 초에서 최대 24시간까지 유지되는 세션 쿠키입니다.

:::note
현재 Cloudflare는 "orange-cloud"(프록시) 모드에서만 세션 어피니티를 지원합니다.
:::

### Cloudflare 봇 제품용 \_\_cf_bm 쿠키

Cloudflare의 [봇 제품](/bots/)은 자동화된 트래픽을 식별하고 완화하여 사이트를 악성 봇으로부터 보호합니다. Cloudflare는 Bot Management 또는 Bot Fight Mode로 보호되는 고객 사이트에 접근하는 최종 사용자 디바이스에 `__cf_bm` 쿠키를 배치합니다. `__cf_bm` 쿠키는 이러한 봇 솔루션이 올바르게 작동하는 데 필요합니다.

이 쿠키는 최종 사용자가 연속으로 30분 동안 활동이 없으면 만료됩니다. 이 쿠키에는 Cloudflare의 독자적인 봇 점수 계산과 관련된 정보가 포함되며, Bot Management에서 이상 탐지가 활성화된 경우 세션 식별자도 포함됩니다. 쿠키에 포함된 정보(시간 관련 정보 제외)는 암호화되어 있으며 Cloudflare만 복호화할 수 있습니다.

최종 사용자가 방문하는 각 사이트마다 별도의 `__cf_bm` 쿠키가 생성되며, Cloudflare는 사이트 간 또는 세션 간에 사용자를 추적하지 않습니다. `__cf_bm` 쿠키는 Cloudflare가 독립적으로 생성하며, 고객 웹 애플리케이션의 사용자 ID 또는 기타 식별자와 대응되지 않습니다.

:::note
Bot Management는 Enterprise 고객에게 애드온 서비스로 제공됩니다. 사이트에서 Bot Management를 활성화하려면 Cloudflare 계정 팀에 문의하세요. Enterprise가 아닌 고객은 [Bot Fight Mode 또는 Super Bot Fight Mode](/bots/)를 활성화할 수 있습니다.
:::

### Cloudflare 봇 제품용 cf_clearance 쿠키

`cf_clearance` 쿠키는 [JavaScript 감지](/bots/additional-configurations/javascript-detections/)에 필요합니다. JavaScript 감지 결과는 `cf_clearance` 쿠키에 저장됩니다.

### Cloudflare Always Online용 cf_ob_info 및 cf_use_ob 쿠키

`cf_ob_info` 쿠키는 다음 정보를 제공합니다.

- 오리진 웹 서버가 반환한 HTTP 상태 코드
- 원래 실패한 요청의 Ray ID
- 트래픽을 제공하는 데이터 센터

`cf_use_ob` 쿠키는 지정된 포트에서 Always Online 캐시로부터 요청된 리소스를 가져오도록 Cloudflare에 알립니다. 적용 가능한 값은 0, 80, 443입니다. `cf_ob_info` 및 `cf_use_ob` 쿠키는 30초 후 만료되는 영속 쿠키입니다.

### Cloudflare Waiting Room용 \_\_cfwaitingroom

[Cloudflare Waiting Room](/waiting-room/) 제품은 하나의 존 내 특정 호스트 및 경로 조합에 대해 대기실을 활성화합니다. 방문자는 대기실로 이동되며, 즉시 접근이 불가능한 경우 애플리케이션에 접근할 수 있을 것으로 예상되는 시간을 안내받습니다.

`__cfwaitingroom` 쿠키는 존에서 대기실이 활성화된 호스트 및 경로 조합에 접근하는 방문자를 추적하는 데만 사용됩니다. 쿠키를 허용하지 않는 브라우저를 사용하는 방문자는 대기실이 활성화되어 있는 동안 해당 호스트 및 경로 조합에 접근할 수 없습니다. 자세한 내용은 [Waiting Room cookies](/waiting-room/reference/waiting-room-cookie/)를 참고하세요.

### Cloudflare Rate Limiting 지원용 \_\_cfruid(이전 버전)

`__cfruid` 쿠키는 Cloudflare Rate Limiting 제품을 지원하는 데 엄격히 필요합니다. Rate Limiting 솔루션의 일부로서, 이 쿠키는 들어오는 트래픽을 관리하고 특정 요청의 출처를 더 잘 파악하는 데 필요합니다.

### Rate Limiting Rules용 \_cfuvid

Rate Limiting Rules 제품은 NAT 뒤의 트래픽처럼 여러 고유 방문자가 동일한 IP 주소를 공유하는 트래픽에 속도 제한을 적용하기 위해 여러 기법을 사용합니다. 이러한 기법은 속도 제한 구성에서 `cf.unique_visitor_id` 필드를 사용해 활성화할 수 있습니다.

`_cfuvid` 쿠키는 사이트가 Rate Limiting Rule에서 이 옵션을 사용하는 경우에만 설정되며, 동일한 IP 주소를 공유하는 개별 사용자를 Cloudflare WAF가 구분할 수 있도록 하는 데만 사용됩니다. 이 쿠키를 제공하지 않는 방문자는 함께 그룹화될 가능성이 높으며, 동일한 IP 주소를 사용하는 다른 방문자가 많으면 사이트에 접근하지 못할 수 있습니다.

### Challenge Platform에서 사용하는 추가 쿠키

아래 표는 Challenge Platform에서 사용하는 추가 쿠키를 보여줍니다.

| 쿠키 이름                                    | 설명                                                                                                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `cf_clearance`                               | Clearance Cookie는 통과한 챌린지의 증명을 저장합니다. 이 쿠키가 있으면 더 이상 챌린지를 제시하지 않는 데 사용됩니다. 오리진 서버에 도달하는 데 필요합니다. |
| `cf_chl_rc_i`; `cf_chl_rc_ni`; `cf_chl_rc_m` | 이 쿠키는 내부 용도로 사용되며, Cloudflare가 클라이언트의 프로덕션 이슈를 식별할 수 있게 해줍니다.                                                   |

:::caution

웹사이트가 [HTTPS를 사용하지 않으면](/ssl/edge-certificates/encrypt-visitor-traffic/), [`cf_clearance` 쿠키](/waf/troubleshooting/samesite-cookie-interaction/#known-issues-with-samesite-and-cf_clearance-cookies)와 관련된 문제가 발생할 수 있습니다.

:::

## Cloudflare 서비스 사용

Cloudflare는 2010년에 모든 사람이 안전하고 빠르며 신뢰할 수 있는 웹 존재를 가질 자격이 있다고 믿으며 시작했습니다. 사이버 공격을 받을 때 더 많은 비용을 지불해서는 안 된다고 보았기 때문에 웹사이트에 대해 무료 및 고정 요금제를 제공했습니다. 대부분의 웹사이트는 대역폭을 많이 소비하지 않기 때문에 이러한 모델이 가능했고, 그 덕분에 누구에게나 합리적인 비용으로 서비스를 제공할 수 있었습니다. 초기부터 우리는 Cloudflare 대역폭을 사용한 비디오 스트리밍을 금지했습니다. 다른 제공업체의 비디오를 임베드할 수는 있었지만, 네트워크에서 방문자에게 비디오 비트를 전달하는 용도로 Cloudflare 서비스를 사용하는 것은 제한했습니다. 이러한 제한이 존재하는 이유는 일반적인 비디오의 1초 분량이 전체 웹페이지 하나를 로드하는 것만큼의 대역폭을 필요로 하기 때문입니다.

시간이 지나면서 일부 고객이 Cloudflare 네트워크를 사용해 비디오를 스트리밍하고 싶어 한다는 점을 알게 되었습니다. 이를 수용하기 위해 [Stream](https://www.cloudflare.com/products/cloudflare-stream/) 제품을 개발했습니다. Stream은 네트워크에 가해지는 부하량을 기준으로 합리적인 요금을 부과하면서 우수한 성능을 제공합니다.

안타깝게도 대부분의 사용자는 이러한 제한을 존중하고, 모든 Cloudflare 고객에게 높은 서비스 품질을 보장하기 위해 제한이 존재한다는 점을 이해하지만, 일부 사용자는 [서비스 약관](https://www.cloudflare.com/en-gb/website-terms/)을 위반하면서 비디오를 스트리밍하도록 서비스를 잘못 구성하려고 시도합니다. 우리는 [Project Galileo](https://www.cloudflare.com/galileo/), [The Athenian Project](https://www.cloudflare.com/athenian/), [Project Fair Shot](https://www.cloudflare.com/fair-shot/)과 같은 공익 이니셔티브를 포함해 모두에게 훌륭한 서비스를 제공하고자 합니다. 소수의 사용자가 서비스를 오용하면 이러한 이니셔티브를 운영할 수 있는 역량이 제한됩니다.

아래는 이 페이지에 오게 된 이유별로 Cloudflare 서비스를 사용하는 데 대한 몇 가지 권장 사항입니다.

## 웹사이트 운영자인데 서비스 약관 위반으로 콘텐츠가 리디렉션되었습니다

Free, Pro 또는 Business 플랜을 사용 중이고 아래에 설명된 적절한 유료 서비스를 사용하지 않은 채 애플리케이션이 비디오 또는 과도하게 많은 대용량 파일을 제공하는 것으로 보이면, Cloudflare는 서비스 품질을 보호하기 위해 콘텐츠를 리디렉션하거나 기타 조치를 취할 수 있습니다. 이 경우 Cloudflare의 조치와 가능한 선택지를 안내하는 이메일 알림을 받게 됩니다.

## 웹 관리자용 리디렉션 해제 옵션

* **리디렉션된 콘텐츠를 grey-cloud 처리된 하위 도메인에서 제공**

* **아래에 설명된 유료 서비스에서 리디렉션된 콘텐츠 제공**

## 유료 제품을 사용해 Cloudflare로 비디오 제공하기

Cloudflare는 특정 유료 서비스를 통해 비디오 콘텐츠를 제공하는 것을 허용합니다. 비디오 콘텐츠를 제공하고자 한다면 두 가지 권장 옵션이 있습니다.

### 옵션 1: Cloudflare Stream

[Stream](https://www.cloudflare.com/products/cloudflare-stream/)은 비디오 애플리케이션 구축을 위한 주문형 비디오 플랫폼입니다. Stream은 다양한 디바이스와 네트워크 연결에 맞게 최적화된 비디오를 인코딩, 저장, 전달합니다.

Stream을 시작하려면 대시보드에서 **Stream** 으로 이동하거나 [가입](https://dash.cloudflare.com/sign-up/stream)하세요. Stream 비디오는 Cloudflare 계정의 도메인에 연결되지 않으며, Stream을 사용하기 위해 Cloudflare의 도메인이 필요하지도 않습니다.

### 옵션 2: Stream Delivery(Enterprise 전용)

[Stream Delivery](https://www.cloudflare.com/products/stream-delivery/)는 전 세계 Cloudflare 데이터 센터를 통해 비디오 콘텐츠를 캐싱하고 전달합니다. 이 CDN 기능은 Cloudflare Enterprise 플랜에서만 사용할 수 있습니다. 이 옵션을 검토하고 싶다면 [영업팀에 문의](https://www.cloudflare.com/products/stream-delivery/#)하세요.

## 제공 중인 콘텐츠 정보 확인하기

존이 제공하는 콘텐츠(예: 콘텐츠 유형)에 대해 더 많은 정보가 필요하다면 다음 도구를 사용할 수 있습니다.

* Cache Analytics 사용자: 대시보드의 **Caching** 탭을 열어 콘텐츠 유형으로 필터링하고 전송 중인 트래픽 유형을 식별합니다.
* Cache Analytics를 사용하지 않는 사용자: 대시보드의 **Analytics** 탭을 열고 **Performance** 섹션을 선택해 제공 중인 콘텐츠 정보를 확인합니다.

## 여전히 궁금한 점이 있나요? 지원팀에 문의하세요

리디렉션에 대해 추가 질문이 있다면(예: 콘텐츠가 잘못 리디렉션되었다고 생각하고 이를 뒷받침할 근거가 있는 경우), [지원 티켓](https://dash.cloudflare.com/redirect?account=support)을 제출하고 다음 정보를 포함하세요.

* 도메인 이름
* 문제 설명
* Cloudflare 네트워크를 통해 제공 중인 콘텐츠 설명

## Cloudflare가 나를 공격하고 있나요

다음 두 가지 흔한 상황 때문에 Cloudflare가 사이트를 공격하고 있다는 오해가 생길 수 있습니다.

* [원래 방문자 IP 주소를 복원](/support/troubleshooting/restoring-visitor-ips/restoring-original-visitor-ips/)하지 않으면, 프록시된 모든 요청에 대해 서버 로그에 Cloudflare IP 주소가 표시됩니다.
* 공격자가 Cloudflare의 IP를 스푸핑하고 있습니다. [Cloudflare Spectrum](/spectrum/)을 사용하지 않는 한, Cloudflare는 [몇 개의 특정 포트](/fundamentals/reference/network-ports/)를 통해서만 원본 웹 서버로 트래픽을 보냅니다.

이상적으로는 Cloudflare가 리버스 프록시이기 때문에, 호스팅 제공업체는 [Cloudflare IP 주소](https://www.cloudflare.com/ips/)에서 들어오는 공격 트래픽을 보게 됩니다. 반대로 Cloudflare 소유가 아닌 IP 주소에서 오는 연결이 보인다면, 그 공격은 원본 웹 서버를 직접 겨냥한 것입니다. 해당 트래픽은 Cloudflare 네트워크를 우회하므로 Cloudflare는 원본 IP 주소를 직접 겨냥한 공격을 차단할 수 없습니다.

:::note

공격자가 원본 웹 서버를 직접 노리고 있다면 [사전 예방적 DDoS 방어 모범 사례](/ddos-protection/best-practices/proactive-defense/)를 참조하십시오.
:::

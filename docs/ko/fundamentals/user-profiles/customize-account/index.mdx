프로필에서 Cloudflare 대시보드에 영향을 주는 설정을 수정할 수 있습니다.

## 언어

Cloudflare 대시보드 전체에서 사용되는 언어를 변경합니다.

1. Cloudflare 대시보드에 로그인합니다.

<DashButton url="/?to=/:account/home" />

2. **Profile**로 이동합니다.
3. **Settings** > **Language**에서 언어를 선택합니다.

대시보드는 자동으로 새 언어로 업데이트됩니다.

## 대시보드 표시

장치에서 Cloudflare 대시보드가 표시되는 방식을 조정합니다.

1. Cloudflare 대시보드에 로그인합니다.

   <DashButton url="/?to=/:account/home" />

2. **Profile**로 이동합니다.
3. **Settings** > **Dashboard appearance**에서 값을 선택합니다.
   * **Dark**: 더 어두운 색상을 기본으로 사용합니다.
   * **Light**: 더 밝은 색상을 기본으로 사용합니다.
   * **Use system setting**: 장치에서 사용하는 설정을 기본값으로 사용합니다.

대시보드 표시는 자동으로 새 모양 설정으로 업데이트됩니다.

## 알림

마케팅 공지나 도메인에 대한 인사이트처럼 Cloudflare에서 받을 알림 유형을 선택합니다.

프로필의 커뮤니케이션 환경설정(이 작업에는 [인증된 이메일 주소](/fundamentals/user-profiles/verify-email-address/)가 필요함)을 업데이트하려면 다음 단계를 따르세요.

1. Cloudflare 대시보드에 로그인합니다.

   <DashButton url="/?to=/:account/home" />

2. **Profile**로 이동합니다.
3. **Notifications**를 선택합니다.
4. 받고 싶은 알림 범주를 선택합니다. 선택 사항은 자동으로 저장됩니다.

:::note

Cloudflare의 모든 이메일 알림은 `noreply@notify.cloudflare.com`에서 발송됩니다. Cloudflare 이메일을 받지 못한다면 Cloudflare를 스팸으로 처리했을 수 있습니다.

이메일을 계속 받으려면 Cloudflare를 신뢰할 수 있는 발신자로 추가하세요.

:::

[Cloudflare Notifications](/notifications/)를 참고하면 서비스 거부 공격이나 서버 문제 같은 계정 관련 정보를 받을 수 있습니다.

## 시간대

Cloudflare 대시보드의 시간대를 협정 세계시(UTC) 또는 브라우저/시스템 시간대로 설정할 수 있습니다.

1. Cloudflare 대시보드에 로그인합니다.

   <DashButton url="/?to=/:account/home" />

2. **Profile**을 선택합니다.
3. **Set Timezone**을 선택한 뒤 **Standard (UTC)** 또는 **Local (CST)** 중 하나를 선택합니다.

새 설정을 적용하기 위해 페이지가 다시 로드됩니다.

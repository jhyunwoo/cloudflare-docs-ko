## 로그인 옵션

Cloudflare는 다음 로그인 옵션을 제공합니다.

### 이메일 및 비밀번호

이메일 주소와 비밀번호를 입력합니다.

### Single Sign-On (SSO)

관리자가 [SSO를 활성화](/fundamentals/manage-members/dashboard-sso/)한 경우 이메일 주소를 입력합니다.

### 소셜 로그인
소셜 로그인을 사용하면 Apple, Google, GitHub 같은 신뢰할 수 있는 제3자 로그인 서비스로 로그인할 수 있습니다. 소셜 로그인은 인증된 이메일 주소가 있는 계정 또는 처음부터 소셜 로그인으로 가입한 계정에서만 사용할 수 있습니다. 계정에 2단계 인증도 추가로 구성한 경우에는 소셜 로그인 제공자가 제공하는 로그인 및 2단계 인증과 함께 표시됩니다.

:::note

Single Sign-On (SSO)으로 Cloudflare 사용자 계정에 로그인하는 경우 소셜 로그인을 사용할 수 없습니다.

:::

:::caution

소셜 로그인으로 로그인하면 처음에는 사용자 프로필에 연결된 비밀번호가 없습니다. 2단계 인증 활성화나 API 토큰 생성 같은 일부 작업에는 비밀번호 설정이 필요합니다.

비밀번호를 설정하려면 Cloudflare 대시보드의 [Forgot Password](https://dash.cloudflare.com/forgot-password)로 이동해 이메일 주소를 붙여넣고 **Send**를 클릭하세요.
그러면 비밀번호 설정 안내가 담긴 이메일을 받게 됩니다. 생성이 완료되면 이메일과 새 비밀번호로 로그인하세요.
:::


#### Apple로 로그인

* **Cloudflare 계정 이메일이 Apple ID와 동일한 경우**: 이메일과 비밀번호로 로그인하거나 Apple로 로그인할 수 있습니다.

* **Cloudflare 계정 이메일이 Apple ID와 다른 경우**: 이 옵션은 새 Cloudflare 계정을 만듭니다. 기존 계정에 로그인하려면 [이메일 주소 변경](/fundamentals/user-profiles/change-password-or-email/)을 통해 Apple ID에 사용하는 주소와 일치시켜야 합니다.

Apple ID로 Cloudflare 계정을 만들 때 이메일 공유를 선택했고 비밀번호 설정 및 API 키 발급이 필요하다면 [Cloudflare 대시보드](https://dash.cloudflare.com/login) 로그인 페이지에서 **Forgot your password?**를 선택해 비밀번호 재설정 이메일을 받으세요.

Apple ID로 Cloudflare 계정을 만들 때 이메일 숨기기를 선택했다면 비밀번호 재설정이 작동하지 않습니다. 아래 우회 방법을 사용할 수 있습니다.

1. 보조 이메일 주소를 사용해 [계정에 새 멤버 추가](/fundamentals/manage-members/manage/#add-account-members)를 합니다.
2. 보조 이메일 주소로 [새 Cloudflare 계정 등록](/fundamentals/account/create-account/)을 하고 비밀번호를 설정합니다.
3. 새 사용자와 비밀번호로 Cloudflare 대시보드에 접근해 API 키를 발급받습니다.

Cloudflare 계정 이메일 주소를 변경하면 Cloudflare 계정에 연결된 Apple ID 로그인 자격 증명 연결이 해제됩니다. 이메일 변경 후 같은 Apple ID로 로그인을 시도하면 새 Cloudflare 계정이 생성됩니다.

Apple Relay를 사용해 Cloudflare 계정을 만들었고 이후 Apple ID나 이메일 주소를 변경하면 해당 Cloudflare 계정을 다시 가져올 수 없으며 모든 로그인 옵션을 영구적으로 잃게 됩니다.

#### Google로 로그인

- **Google 계정 이메일로 이미 Cloudflare 계정이 생성된 경우**: 현재는 이 옵션을 사용할 수 없지만, Cloudflare 계정에 소셜 로그인 제공자를 연결하거나 해제하는 기능을 준비 중입니다.

- 아직 Cloudflare 계정이 연결되지 않은 이메일로 **Sign in with Google**을 선택하면 Cloudflare가 새 계정을 만들고 이후에도 **Sign in with Google** 옵션으로 로그인할 수 있게 합니다.

#### GitHub로 로그인

- GitHub로 로그인은 GitHub 계정에 설정된 [기본 이메일 주소](https://docs.github.com/en/account-and-profile/how-tos/setting-up-and-managing-your-personal-account-on-github/managing-email-preferences/changing-your-primary-email-address)를 사용합니다. GitHub에서 기본 이메일 주소를 변경하면 GitHub 소셜 로그인으로는 Cloudflare 계정에 로그인할 수 없게 됩니다.

- 아직 Cloudflare 계정이 연결되지 않은 이메일로 **Sign in with GitHub**를 선택하면 Cloudflare가 새 계정을 만들고 이후에도 **Sign in with GitHub** 옵션으로 로그인할 수 있게 합니다.

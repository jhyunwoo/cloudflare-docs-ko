## 개요

Cloudflare는 계정 보안을 강화하기 위해 다단계 이메일 인증(MFA) 방식을 사용합니다. MFA는 노출되었거나 추측하기 쉬운 비밀번호 때문에 공격자가 계정에 무단으로 접근했을 때 고객 계정 탈취를 방지합니다.

사용자가 인식되지 않은 IP 주소에서 올바른 자격 증명을 제공하면 Cloudflare는 모든 로그인 시도를 추가 확인합니다.

![알 수 없는 IP 주소에서 계정에 로그인되면 Cloudflare가 이메일을 보냅니다.](~/assets/images/fundamentals/hc-import-account_access_email.png)

Cloudflare는 계정에 등록된 이메일 주소로 30분 후 만료되는 일회용 코드를 보내 로그인 절차를 추가 확인합니다. 대시보드를 통해 올바른 코드가 입력되면 해당 IP가 기록되며, 그 이후 90일 동안은 같은 IP 주소에서의 로그인 시도에 대해 추가 확인이 이루어지지 않습니다.

![알 수 없는 IP 주소에서 계정에 로그인되면 등록된 이메일 주소로 전송된 인증 토큰을 입력해야 합니다.](~/assets/images/fundamentals/hc-import-login_authentication.png)

:::note

이메일 MFA는 [2단계 인증](/fundamentals/user-profiles/2fa/)을 활성화해야만 비활성화할 수 있습니다.
:::

## MFA 문제 해결

Cloudflare 이메일은 수신자의 이메일 서비스에서 스팸으로 분류되는 경우가 있습니다. 인증 토큰을 기다리고 있다면 스팸 폴더에서 Cloudflare 이메일이 있는지 확인하고, *[no-reply@notify.cloudflare.com](mailto:no-reply@notify.cloudflare.com)* 에서 오는 메일을 허용하도록 필터를 설정하세요.

또 다른 경우에는 수신자의 이메일 서비스가 이메일을 거부할 수 있습니다. Cloudflare는 다시 시도하지만, 여러 차례 시도 후에도 실패하면 해당 이메일 주소를 표시하고 더 이상 이메일을 보내지 않습니다.

이메일 서비스에서 Cloudflare 메일을 차단하지 않는 것을 확인했는데도 이메일을 받지 못한다면 [Cloudflare Support](/support/contacting-cloudflare-support/)에 문의하세요.

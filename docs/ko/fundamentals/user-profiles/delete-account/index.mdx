## 계정을 삭제할 수 있는 사용자

계정에서 [Single-Sign On (SSO)](/fundamentals/manage-members/dashboard-sso/)를 사용 중이라면 슈퍼 관리자가 대신 계정을 삭제해야 할 수 있습니다.

계정에서 SSO를 사용하지 않는다면 직접 계정을 삭제할 수 있습니다.

## 사전 준비

Cloudflare가 계정을 해지하고 개인 정보를 삭제하려면, Cloudflare 계정에 연결된 각 도메인에 대해 아래 절차를 따라야 합니다.

- [구독 또는 부가 서비스 해지](/billing/cancel-subscription/)
- [Cloudflare에서 도메인 제거](/fundamentals/manage-domains/remove-domain/)
- [도메인 등록기관에서 Cloudflare 네임서버 제거](/dns/zone-setups/full-setup/setup/)
- [Registrar 도메인의 자동 갱신 비활성화](/registrar/account-options/renew-domains#set-up-automatic-renewals)
- Cloudflare [CNAME setup](/dns/zone-setups/partial-setup/)을 사용하는 경우, DNS 공급자에서 [DNS 레코드 업데이트](/dns/manage-dns-records/how-to/create-dns-records/#edit-dns-records)를 수행해 Cloudflare 대신 웹사이트 IP 또는 호스트 이름을 가리키도록 변경합니다.
- [결제 정보 삭제](/billing/update-billing-info/#delete-your-current-payment-method)
- (*선택 사항*) [청구서 사본 다운로드](/billing/invoices/#download-invoice). 삭제 후에는 청구서에 더 이상 접근할 수 없고 다시 발송받을 수도 없습니다.

## Cloudflare 계정 삭제

Cloudflare에 가입하면 사용자 프로필과 `youremail@example.com's account`라는 이름의 계정이 생성되며, 사용자 프로필은 새로 생성된 계정의 관리자 역할을 합니다. 사용자 프로필에서는 비밀번호나 언어 같은 환경설정을 관리하고, 계정에서는 Cloudflare 제품 구성을 관리합니다.

:::note

사용자 프로필은 다른 Cloudflare 계정에 초대될 수 있으므로 둘 이상의 계정에 접근 권한이 있을 수 있습니다.

:::

프로필을 삭제하면 프로필에 연결된 계정과 여러분이 마지막 활성 멤버인 모든 계정도 함께 삭제됩니다. 계정 삭제는 영구적입니다. 여러분이 주 소유자인 모든 계정도 삭제되며, 그 계정의 다른 사용자도 모두 제거됩니다.

프로필을 삭제한 뒤에는 해당 프로필에 사용한 이메일 주소로 새 계정을 만들 수 있습니다. 대부분의 경우 이메일은 바로 새 가입에 사용할 수 있게 해제됩니다.
다만 법적 사유 등으로 계정에 잠금이 걸린 사용자의 경우에는 예외가 있을 수 있습니다.

계정의 모든 도메인, 구독, 결제 정보는 Cloudflare에서 제거됩니다.

1. Cloudflare 대시보드에 로그인합니다.

    <DashButton url="/?to=/:account/home" />

2. **My Profile**을 선택합니다.
3. **Delete this user**를 선택합니다.
4. **Delete user**를 선택합니다.
5. 안내에 따라 계정 삭제를 완료합니다.

:::note

Cloudflare는 법적 의무(예: 진행 중인 악용 조사 또는 계류 중인 소송)로 인해 보관이 필요한 경우를 제외하고, 삭제 요청 후 1년 이내에 개인 정보를 삭제합니다. 계정 해지 후 개인 정보 삭제에 관한 자세한 내용은 [Cloudflare Data Processing Addendum](https://www.cloudflare.com/cloudflare-customer-dpa/)를 참고하세요.

:::

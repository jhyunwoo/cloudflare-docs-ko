보안상의 이유로 Cloudflare는 계정에 연결된 이메일 주소를 인증하려고 시도합니다. 이메일을 인증하지 않으면 Cloudflare 대시보드에서 특정 작업을 수행할 수 없습니다. 예를 들어 [새 멤버 추가](/fundamentals/manage-members/manage/#add-account-members), [이메일 주소 변경](/fundamentals/user-profiles/change-password-or-email/#change-email-address), [커뮤니케이션 환경설정 업데이트](/fundamentals/user-profiles/customize-account/#notifications)를 할 수 없습니다.

## 계정을 만들 때

처음 [계정을 만들면](/fundamentals/account/create-account/), Cloudflare는 계정에 제공한 이메일 주소로 자동으로 메시지를 보냅니다.

이메일을 인증하려면 다음 단계를 따르세요.

1. 이메일 제공업체에 로그인해 Cloudflare에서 보낸 최근 메시지를 찾습니다. 메시지를 찾을 수 없다면 스팸 폴더를 확인하세요.
2. 이메일에 있는 링크로 이동합니다.
3. Cloudflare에 로그인해 계정에 연결된 이메일 주소를 인증합니다.

:::note

다른 사람이 여러분의 이메일을 사용해 Cloudflare 계정에 가입한 경우 [unintended registration](https://dash.cloudflare.com/unintended-registration) 페이지로 이동해 확인 이메일 끝부분의 정보를 입력하면 이 계정을 제거할 수 있습니다.

:::

## 인증 이메일 다시 보내기

인증 이메일을 찾을 수 없거나 이메일이 만료된 경우 다른 인증 이메일을 요청하세요.

1. Cloudflare 대시보드에 로그인합니다.

    <DashButton url="/?to=/:account/home" />

2. **My Profile**로 이동합니다.
3. **Email Address**에서 **Send verification email**을 선택합니다(이 옵션이 보이지 않으면 이메일이 이미 인증된 상태입니다).

## 인증 문제

인증 링크에 문제가 있다면 이메일 주소가 이미 인증되었을 수 있습니다.

인증 상태를 확인하려면 다음 단계를 따르세요.

1. Cloudflare 대시보드에 로그인합니다.

    <DashButton url="/?to=/:account/home" />

2. **My Profile**로 이동합니다.
3. **Email Address**에서 이메일 주소 뒤에 `(verified)`가 표시되는지 확인합니다.

이메일이 아직 인증되지 않았다면 다른 브라우저나 시크릿 창에서 인증 링크를 클릭해 보세요.

그래도 작동하지 않으면 [인증 이메일 다시 보내기](#인증-이메일-다시-보내기)를 통해 새 인증 링크를 받아 보세요.

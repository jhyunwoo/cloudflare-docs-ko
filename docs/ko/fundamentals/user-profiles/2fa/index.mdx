## Cloudflare 2단계 로그인용 보안 키 인증 구성

:::caution

보안 키는 WebAuthn 프로토콜을 지원하는 브라우저에서만 작동합니다.
:::

보안 키는 내장 인증기(Apple Touch ID, Android 지문 인증, Windows Hello) 또는 USB-A, USB-C, NFC, Bluetooth로 컴퓨터에 연결되는 외부 하드웨어 키([YubiKey](https://www.yubico.com/works-with-yubikey/catalog/cloudflare/) 등)를 사용해 Cloudflare 계정에 피싱 저항성이 있는 다중 인증을 제공합니다.

Cloudflare는 여러 개의 보안 키를 구성할 것을 권장합니다. 기본 키를 사용할 수 없거나 다른 장치에서 작업 중일 때도 여러 키가 있으면 계속 2FA를 사용할 수 있습니다.

[Cloudflare 계정에서 2FA를 활성화](/fundamentals/user-profiles/2fa/#enable-two-factor-authentication-for-your-cloudflare-account)한 후에는 **Manage**를 선택해 2FA 보안 키 인증을 구성할 수 있습니다.

### 내장 인증기

Apple Touch ID, Android 지문 인증, Windows Hello 같은 내장 인증기를 구성할 수 있습니다.

1. **Security Key Authentication**에서 **Add**를 선택합니다.
2. **Add a Security Key**에서 Cloudflare 비밀번호를 입력하고 **Next**를 선택합니다.
3. 내장 인증기와 상호 작용하여 이를 Cloudflare 계정에 추가합니다.
4. 내장 인증기의 이름을 입력합니다. 처음 설정하는 경우 백업 코드 생성 안내가 표시됩니다. 그렇지 않다면 8단계로 이동하세요.
5. Cloudflare 비밀번호를 입력합니다.
6. **Next**를 선택해 백업 코드를 검토합니다. 백업 코드는 모바일 장치 없이 사용자 계정에 접근할 때 사용할 수 있습니다.
7. **Download**, **Print**, 또는 **Copy**를 선택해 백업 코드를 안전한 위치에 저장합니다.
8. **Next**를 선택해 구성을 완료합니다.

### 보안 키

계정에 사용할 Yubikey 같은 보안 키를 구성할 수 있습니다. 시작하기 전에 하드웨어 보안 키가 구성되어 있고 연결되어 있는지 확인하세요.

Windows 장치에서는 Windows Hello를 설정하거나 보안 키를 Microsoft 계정에 등록해야 할 수 있습니다. 자세한 내용은 Windows 문서를 확인하세요.

1. 보안 키를 연결한 뒤 **Profile** > **Authentication**으로 이동합니다.
2. **Two-Factor Authentication**에서 **Set up**을 선택합니다.
3. **Security Key Authentication**에서 **Add**를 선택합니다.
4. **Add a Security Key** 화면에서 Cloudflare 비밀번호를 입력한 다음 **Next**를 선택합니다.
5. 보안 키와 상호 작용하여 Cloudflare 계정에 추가합니다. 대화상자가 보안 키 설정용인지 확인하세요. Windows 장치에서 Windows Hello 대화상자가 나타나면 **Cancel**을 선택합니다. 그러면 보안 키 대화상자가 표시됩니다. 시스템에 따라 보안 키용 PIN 등록이 필요할 수 있습니다.
6. 보안 키의 이름을 입력합니다. 처음 설정하는 경우 백업 코드 생성 안내가 표시됩니다. 그렇지 않다면 8단계로 이동하세요.
7. Cloudflare 비밀번호를 입력합니다.
8. **Next**를 선택해 백업 코드를 검토합니다. 백업 코드는 모바일 장치 없이 사용자 계정에 접근할 때 사용할 수 있습니다.
9. **Download**, **Print**, 또는 **Copy**를 선택해 백업 코드를 안전한 위치에 저장합니다.
10. **Next**를 선택해 구성을 완료합니다.

## TOTP 모바일 애플리케이션 인증 구성

시간 기반 일회용 비밀번호(TOTP) 인증은 Google Authenticator 또는 Microsoft Authenticator 같은 인증 앱을 사용해 작동합니다. 이 앱은 앱과 웹사이트 간에 공유되는 비밀 코드를 생성합니다. 웹사이트에 로그인할 때 사용자 이름, 비밀번호, 그리고 인증 앱이 생성한 비밀 코드를 입력합니다. 이 비밀 코드는 새 코드가 생성되기 전까지 약 30초에서 60초 동안만 유효합니다.

1. 보안 키를 연결한 뒤 **Profile** > **Authentication**으로 이동합니다.
2. **Two-Factor Authentication**에서 **Set up**을 선택합니다.
3. **Mobile App Authentication**에서 **Add**를 선택합니다.
4. 모바일 장치로 QR 코드를 스캔하고 인증 앱의 코드를 입력합니다.
5. Cloudflare 비밀번호를 입력한 후 **Next**를 선택합니다. QR 코드를 스캔할 수 없다면 **Can't scan QR code, Follow alternative steps**를 선택해 인증 앱을 수동으로 구성합니다.

![모바일 장치로 QR 코드를 스캔해 2FA를 활성화할 수 있습니다.](~/assets/images/fundamentals/2FA_scan_QR_code.png)

6. Cloudflare 비밀번호를 다시 입력합니다.
7. **Next**를 선택해 백업 코드를 검토합니다. 백업 코드를 사용하면 모바일 장치 없이 계정에 접근할 수 있습니다.
8. **Download**, **Print**, 또는 **Copy**를 선택해 백업 코드를 안전한 위치에 저장합니다.

:::note

계정 잠금을 방지하려면 복구 코드를 반드시 생성하고 저장하세요. 비밀번호를 잊어 재설정 코드를 받을 수 없거나 인증 앱이 있는 휴대폰에 접근할 수 없게 되면 복구 코드를 사용해 계정에 접근할 수 있습니다.

Cloudflare 대시보드에서 언제든지 백업 코드를 다시 생성할 수 있습니다.
:::

9. 백업 코드 페이지에서 **Next**를 선택해 복구 코드 설정을 완료합니다.

### TOTP 모바일 애플리케이션 인증 다시 구성

새 조직에 참여하거나 모바일 장치에 접근할 수 없게 되면 모바일 애플리케이션 인증을 다시 구성해야 할 수 있습니다. 모바일 애플리케이션 인증을 다시 구성하면 이전 TOTP 코드는 무효가 됩니다.

:::note

TOTP 모바일 애플리케이션 인증을 다시 구성해도 2FA가 비활성화되지는 않습니다.
:::

다시 구성하려면 위에 설명한 [1~7단계](/fundamentals/user-profiles/2fa/#configure-totp-mobile-application-authentication)를 따르세요.

## 이메일 2단계 인증 구성

이메일 2FA는 TOTP 코드를 이메일 주소로 전송하는 방식으로 작동합니다. 하드웨어 기반 키를 잃어버릴까 걱정되는 경우 특히 좋은 선택지입니다.

1. **User Profile**로 이동한 다음 **Authentication**으로 이동합니다.
2. **Two-Factor Authentication**에서 **Set up**을 선택합니다.
3. **Email Authentication**에서 **Enable**을 선택합니다.
4. 비밀번호를 두 번 입력하라는 메시지가 표시되고, 이어서 복구 코드가 표시됩니다. 비밀번호 관리자 같은 안전한 곳에 저장하세요.

## 백업 코드 다시 생성

각 백업 코드는 한 번만 사용할 수 있지만, Cloudflare 대시보드에서 언제든지 새로운 백업 코드 세트를 요청할 수 있습니다. 이전 백업 코드에 접근할 수 없거나 모두 사용한 경우 유용합니다.

:::note

백업 코드를 다시 생성하면 이전 코드는 무효화됩니다.
:::

1. Cloudflare 대시보드에 로그인합니다.

      <DashButton url="/?to=/:account/home" />

2. **My Profile**을 선택합니다.
3. **Authentication**을 선택합니다.
4. **Two-Factor Authentication**에서 **Manage**를 선택합니다.
5. **Backup codes**에서 **Regenerate**를 선택해 새로운 2단계 백업 코드 세트를 생성하고 저장합니다.

## Cloudflare 계정의 2단계 인증 비활성화

Cloudflare 계정의 2FA를 비활성화하려면 계정에서 모든 보안 키와 TOTP 인증기를 삭제해야 합니다.

:::note

**2FA Enforcement**가 활성화된 조직의 슈퍼 관리자가 아니라면 2FA를 비활성화할 권한이 없을 수 있습니다.
:::

1. Cloudflare 대시보드에 로그인합니다.

      <DashButton url="/?to=/:account/home" />

2. **Profile**을 선택합니다.
3. **Authentication**을 선택합니다.
   - 보안 키를 제거하려면:
      1. **Security Key Authentication** 카드에서 **Edit**를 선택합니다. 드롭다운 메뉴에 보안 키의 자세한 정보가 표시됩니다.
      2. **Delete**를 선택합니다.
      3. Cloudflare 비밀번호를 입력한 다음 **Remove**를 선택합니다.
   - TOTP 모바일 애플리케이션 인증을 제거하려면:
      1. **Mobile App Authentication** 카드에서 **Delete method**를 선택합니다.
      2. Cloudflare 비밀번호, 인증 앱 코드 또는 복구 코드를 입력한 다음 **Disable**을 선택합니다.

![TOTP 모바일 애플리케이션 인증을 비활성화하는 방법입니다.](https://developerdocsgifs.cloudflaretraining.com/resampled_5fps_disable_mobile_auth_v2_final.gif)

## 백업 코드 사용

모바일 장치, 보안 키 또는 인증 코드에 접근할 수 없게 되면 백업 코드를 사용하거나 선호하는 인증 앱에서 백업 코드를 가져와 이 문제를 해결할 수 있습니다.

Google 문서에서 [Google Authenticator 코드를 한 Android 기기에서 다른 기기로 전송하는 방법](https://support.google.com/accounts/answer/1066447?co=GENIE.Platform%3DAndroid\&hl=en\&oco=0)을 참고하세요.

2FA를 설정할 때 백업 코드를 안전한 위치에 저장해 두었어야 합니다. Cloudflare 백업 코드를 사용해 접근을 복구하려면 다음 단계를 따르세요.

1. 저장해 둔 위치에서 백업 코드를 가져옵니다.
2. [Cloudflare 로그인 페이지](https://dash.cloudflare.com/login)로 이동하여 사용자 이름과 비밀번호를 입력하고 **Log in**을 선택합니다.

      <DashButton url="/?to=/:account/home" />

3. **Two-Factor Authentication** 제목의 페이지가 나타납니다.
   * 텍스트 상자가 있으면 백업 코드 중 하나를 입력하고 **Log in**을 선택합니다.
   * 대신 "Insert your security key and touch it"가 보이면 브라우저에서 나타나는 프롬프트를 취소하고 **try another authentication method or backup code**를 선택합니다. 이어서 백업 코드 중 하나를 입력하고 **Log in**을 선택합니다.

:::note

백업 코드는 한 번 사용하면 무효가 됩니다.
:::

## 계정 복구

2FA 계정이나 백업 코드에 접근할 수 없고 현재 2FA 코드를 생성할 수도 없다면, 이전에 로그인한 적이 있는 검증된 장치를 사용해 임시 접근 코드를 요청하세요.

1. [Cloudflare 대시보드](https://dash.cloudflare.com/login)에 로그인합니다.

      <DashButton url="/?to=/:account/home" />

2. **Two-Factor Authentication** 페이지에서 **Lost all 2FA devices and backup codes?**의 **Try recovery**를 선택합니다.
3. **Begin recovery**를 선택합니다.
4. Cloudflare 계정에 연결된 이메일 주소로 6자리 접근 코드가 전송됩니다.
5. 임시 접근 코드를 Cloudflare Dashboard에 입력하고 **Verify email**을 선택합니다.
6. **Verify device**를 선택합니다. 이 단계에서는 이전에 계정에 로그인한 적이 있는 장치를 사용 중인지 확인합니다.

**Device verified**가 표시되면 3~5일 내에 계정 접근 권한을 되찾는 방법이 담긴 이메일을 받게 됩니다. 이 과정은 더 빠르게 처리할 수 없으므로, 다음 단계로 진행하려면 해당 이메일이 도착할 때까지 기다려야 합니다.

**Device verification failed**가 표시되면 다음 사항을 고려해 다시 시도할 수 있습니다.

   * 쿠키를 자주 삭제하거나 다른 IP 주소에서 로그인하고 있다면 Cloudflare가 장치를 기억하던 정보가 사라졌을 수 있으므로 다른 장치로 확인해야 합니다.
   * 브라우저가 종료 시 또는 브라우저/OS 업그레이드 후 쿠키를 삭제하도록 설정되어 있을 수 있습니다. 이는 장치 확인 과정을 방해합니다.
   * 브라우저 쿠키를 자동으로 지우는 악성코드 방지 소프트웨어나 다른 소프트웨어를 사용 중일 수 있으며, 이 경우 Cloudflare Dashboard가 장치를 인식하지 못하게 됩니다.

여전히 장치를 확인할 수 없다면 **Device verification failed** 페이지에서 *Request manual verification* 안내를 따르세요.

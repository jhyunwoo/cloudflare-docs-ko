:::note


Cloudflare는 데이터 처리자(Data Processor)로서 PCI 인증을 받았습니다. 자세한 내용은 [PCI compliance and vulnerabilities mitigation](/ssl/reference/compliance-and-vulnerabilities) 및 Cloudflare의 PCI DSS 책임 매트릭스를 참고하세요.


:::

PCI 스캐너는 보안 취약점을 식별하는 데 사용하는 도구입니다. 기업이 규정 준수 감사를 받을 때 PCI 스캔 결과는 규정 준수 검증에 사용됩니다.

## 스캔 시작

1. 스캔이 대상으로 삼아야 할 서버를 확인합니다. 애플리케이션이 호스팅되는 원본 서버를 스캔하나요, 아니면 Cloudflare처럼 원본 앞단에 위치한 프록시 서버를 스캔하나요?

2. 스캐너 도구에서 공개 URL 또는 IP 주소를 입력합니다. 공개 웹사이트 URL을 입력하면 스캐너가 호스트 이름을 해석한 뒤 해당 IP 주소를 스캔합니다. 원본 서버를 스캔하려면 프록시 서버가 아니라 원본 서버의 IP 주소나 원본 서버 IP로 해석되는 호스트 이름을 반드시 입력하세요.

3. 스캔을 시작하고 결과를 분석합니다.

4. (선택 사항) 다른 원본 서버에 대해 추가 스캔을 실행합니다.

### 열린 포트와 차단된 트래픽

Cloudflare의 애니캐스트 네트워크는 80과 443 이외의 포트도 열린 상태로 유지되는 방식으로 동작하며, 이를 통해 해당 포트에서 다른 고객의 트래픽도 처리할 수 있습니다.

하지만 고객은 Cloudflare [WAF Managed Rules](/fundamentals/reference/network-ports/#how-to-block-traffic-on-additional-ports) 또는 [custom rules](/waf/custom-rules/)를 사용해 이러한 포트의 원치 않는 트래픽을 쉽게 차단할 수 있습니다. PCI 스캔에서는 포트가 열려 있는 것으로 보일 수 있지만, 해당 트래픽은 원본 서버에 도달하지 않습니다. 이 부분은 자주 오해되는 사항입니다.

## 추가 리소스

공개된 규정 준수 리소스는 다음 페이지에서 확인할 수 있습니다.

* [Certifications and compliance resources](https://www.cloudflare.com/trust-hub/compliance-resources/)
* [Compliance documentation](/fundamentals/reference/policies-compliances/compliance-docs/)

규정 준수 문서는 Cloudflare 대시보드에서 본인이 슈퍼 관리자(Super Administrator)인 계정을 선택한 뒤 **Support** > **Compliance Documents**로 이동해 확인할 수 있습니다.

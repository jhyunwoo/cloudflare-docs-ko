최근 웹사이트가 해킹되었다면, 아래 권장 단계를 검토해 해킹된 웹사이트를 복구하고 향후 해킹을 예방하세요.

## 공격에서 복구하기

공격에서 복구하려면 호스팅 제공업체에 다음을 요청하세요.

- 해킹이 어떻게 발생했다고 보는지 등 해킹에 대한 세부 정보
- 웹사이트에 삽입된 악성 콘텐츠 제거

해킹 문제가 해결되면 [Google Webmaster Tools](https://www.google.com/webmasters/tools)에서 사이트 경고를 해소하고 Google 검토를 위해 사이트를 다시 제출해야 합니다.

---

## 향후 해킹 위험 예방 및 완화

해킹된 사이트의 위험을 예방하려면 다음을 수행하세요.

- 알려진 악성 동작을 점검하거나 차단할 수 있도록 Cloudflare의 [WAF managed rules](/waf/managed-rules/)를 활성화합니다.
- 콘텐츠 관리 시스템(CMS)을 사용한다면 최신 버전이 설치되어 있는지 확인합니다. CMS 플랫폼은 알려진 취약점을 해결하기 위해 업데이트를 배포합니다.
- 플러그인을 사용한다면 최신 상태인지 확인합니다.
- 관리자 로그인 페이지가 있다면 Cloudflare의 [Rate limiting rules](/waf/rate-limiting-rules/) 또는 [Cloudflare Access policy](/cloudflare-one/access-controls/policies/)로 보호합니다.
- 유효한 콘텐츠 손실을 방지할 수 있도록 백업 서비스를 사용합니다.

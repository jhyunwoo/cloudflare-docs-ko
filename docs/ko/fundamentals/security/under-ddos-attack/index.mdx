## 일반적인 공격 징후

DDoS 공격을 받고 있을 때 흔히 나타나는 징후는 다음과 같습니다.

* 사이트가 오프라인 상태이거나 요청에 대한 응답이 느립니다.
* Cloudflare **Analytics** 앱의 **Requests Through Cloudflare** 또는 **Bandwidth** 그래프에서 예상치 못한 급증이 나타납니다.
* 원본 웹 서버 로그에 정상적인 방문자 동작과 일치하지 않는 이상한 요청이 보입니다.

:::note

현재 DDoS 공격을 받고 있다면 [사전 대응형 DDoS 방어 모범 사례](/ddos-protection/best-practices/proactive-defense/)를 참고하세요.
:::

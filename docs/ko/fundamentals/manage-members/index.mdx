모든 Cloudflare 계정에서는 계정에 멤버를 추가하고 하나 이상의 정책을 통해 접근 권한을 할당하여 협업할 수 있습니다.

모든 정책은 세 부분으로 구성됩니다.

1. 행위자(Actor)
2. 역할(Role)
3. 범위(Scope)

아래 리소스를 참고해 정책을 구성하면 계정 멤버에게 꼭 필요한 접근 권한만 할당할 수 있습니다.

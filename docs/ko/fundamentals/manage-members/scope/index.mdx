범위(scope)는 사용자에게 접근 권한을 부여할 수 있게 해 주는 정책의 세 구성 요소 중 하나입니다.

사용자 접근 권한을 유연하게 조합할 수 있도록, Cloudflare는 현재 계정 수준 범위, 도메인 범위, 리소스별 범위를 제공합니다. 각 범위에는 서로 다른 [역할](/fundamentals/manage-members/roles/) 집합이 연결됩니다.

***

## 역할의 범위 선택

각 정책은 하나의 범위만 가질 수 있지만, 한 사용자에게 여러 정책을 할당할 수 있습니다.

[멤버를 추가](/fundamentals/manage-members/manage/)할 때 정책의 범위를 선택할 수 있습니다.

### 계정 범위

멤버에게 계정 전체에 적용되는 정책을 부여하려면 다음 필드 조합을 사용하세요.

| 필드    | 값            |
| ------- | ------------- |
| Operator | *Include*     |
| Type     | *All domains* |

:::note


이 유형의 정책에는 [계정 범위 역할](/fundamentals/manage-members/roles/#account-scoped-roles)만 할당할 수 있습니다.


:::

### 특정 도메인

멤버에게 특정 도메인에 적용되는 정책을 부여하려면 다음 필드 조합을 사용하세요. 이 정책에 역할을 적용할 때는 도메인 범위 역할만 사용할 수 있습니다.

| 필드    | 값                  |
| ------- | ------------------- |
| Operator | *Include*           |
| Type     | *A specific domain* |
| Name     | *A specific domain* |

### 도메인 그룹

비슷한 성격으로 묶이는 도메인 집합(예: 민감한/프로덕션 도메인 전체, 특정 프로젝트 또는 지역과 관련된 모든 도메인)이 있다면, 이를 도메인 그룹으로 미리 묶은 뒤 이 그룹 내 모든 도메인에 접근 권한을 주는 정책을 만들 수 있습니다.

#### 그룹 만들기

도메인 그룹을 만들려면 다음을 수행하세요.

1. Cloudflare 대시보드에서 **Settings** > **Lists** 페이지로 이동합니다. (**Super Administrator**로 로그인되어 있고 [이메일 주소가 인증](/fundamentals/user-profiles/verify-email-address/)되어 있어야 합니다.)

    <DashButton url="/?to=/:account/configurations" />

2. **Domain Group Manager**에서 **Create**를 선택합니다.
3. 도메인 그룹을 생성합니다.

   1. 포함할 도메인을 선택합니다.
   2. **Name**을 추가합니다.
   3. **Create**를 선택합니다.

필요에 따라 이 그룹은 수정하거나 삭제할 수도 있습니다.

#### 그룹 사용

멤버에게 도메인 그룹에 대한 권한을 할당하려면 다음 필드 조합을 사용하세요.

| 필드    | 값              |
| ------- | --------------- |
| Operator | *Include*       |
| Type     | *Domain Group*  |
| Name     | *Example Group* |

:::note


Domain Groups를 사용할 때는 이 멤버들에게 [도메인 범위 역할](/fundamentals/manage-members/roles/#domain-scoped-roles)만 할당할 수 있습니다.


:::


### 특정 리소스

멤버에게 특정 리소스에 적용되는 정책을 부여하려면 다음 필드 조합을 사용하세요.

| 필드     | 값                  |
| -------- | ------------------- |
| Operator | *Include*           |
| Type     | *Granular*          |
| Product  | *Product Name*      |
| Resource | *Specific Resource* |

#### 사용 가능한 범위

멤버에게 다음과 같은 리소스별 범위를 할당할 수 있습니다.

| 범위                                      | 설명                                                                                                                                        |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Individual Access applications            | 계정 내 특정 [Access application](/cloudflare-one/access-controls/applications/)을 관리할 권한을 부여합니다.                             |
| Individual Access identity providers (IdPs) | 계정 내 특정 [Cloudflare One identity provider (IdP)](/cloudflare-one/integrations/identity-providers/)를 관리할 권한을 부여합니다. |
| Individual Access policies                | 계정 내 특정 [Access policy](/cloudflare-one/access-controls/policies/)를 관리할 권한을 부여합니다.                                      |
| Individual Access service tokens          | 계정 내 특정 [Access service token](/cloudflare-one/access-controls/service-credentials/service-tokens/)을 관리할 권한을 부여합니다.      |
| Individual Access infrastructure targets  | 계정 내 특정 [Access for Infrastructure target](/cloudflare-one/access-controls/applications/non-http/infrastructure-apps/)을 관리할 권한을 부여합니다. |

:::note
특정 리소스 범위를 사용할 때는 이 멤버들에게 [리소스 범위 역할](/fundamentals/manage-members/roles/#resource-scoped-roles)만 할당할 수 있습니다.
:::

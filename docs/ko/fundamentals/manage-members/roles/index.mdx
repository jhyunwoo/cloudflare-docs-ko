새 [멤버를 계정에 추가](/fundamentals/manage-members/manage/)할 때 해당 사용자에게 정책을 할당하고 사용 가능한 역할을 활용할 수 있습니다. 역할은 항상 지정된 범위에만 할당할 수 있으며, 하나의 정책에 여러 역할을 할당할 수 있습니다.

<a id="account-scoped-roles"></a>
## 계정 범위 역할

계정 범위 역할은 Cloudflare 계정 전체와 그 계정에 포함된 모든 도메인에 적용됩니다.

| 역할 | 설명 |
| ---- | ---- |
| Administrator | 계정 전체에 접근하고 구독을 수정할 수 있습니다. 멤버 관리와 청구 프로필 관리는 할 수 없습니다. |
| Super Administrator - All Privileges | 모든 Cloudflare 설정을 수정하고, 구매를 수행하고, 청구를 업데이트하고, 멤버를 관리하고, 계정 소유 API 토큰을 만들 수 있습니다. Super Administrator는 다른 Super Administrator의 접근 권한을 철회할 수 있습니다. |
| Administrator Read Only | 읽기 전용 모드로 계정 전체에 접근할 수 있습니다. |
| Analytics | Analytics를 읽을 수 있습니다. |
| API Gateway | 계정 내 모든 도메인에 대해 [API Gateway (API Shield 포함)](/api-shield/)에 대한 전체 접근 권한을 부여합니다. |
| API Gateway Read | 계정 내 모든 도메인에 대해 [API Gateway (API Shield 포함)](/api-shield/) 읽기 권한을 부여합니다. |
| Audit Logs Viewer | [감사 로그](/fundamentals/account/account-security/review-audit-logs/)를 볼 수 있습니다. |
| Bot Management (Account-wide) | 계정 내 모든 도메인에 대해 [Bot Management](/bots/plans/bm-subscription/) 설정([Super Bot Fight Mode](/bots/get-started/super-bot-fight-mode/) 포함)을 수정할 수 있습니다. |
| Billing | 계정의 [청구 프로필](/billing/create-billing-profile/)과 구독을 수정할 수 있습니다. |
| Cache Purge | 에지 캐시를 비울 수 있으며 영역 설정을 읽을 수 있습니다. |
| Cloudflare Access | [Cloudflare Access](/cloudflare-one/access-controls/policies/)와 [Cloudflare Tunnel](/cloudflare-one/networks/connectors/cloudflare-tunnel/)을 수정할 수 있습니다. |
| Cloudflare CASB | [Cloudflare CASB](/cloudflare-one/cloud-and-saas-findings/)를 수정할 수 있습니다. |
| Cloudflare CASB Read | [Cloudflare CASB](/cloudflare-one/cloud-and-saas-findings/)를 읽을 수 있습니다. |
| Cloudflare DEX | [Cloudflare DEX](/cloudflare-one/insights/dex/)를 수정할 수 있습니다. |
| Cloudflare Gateway | [Cloudflare Gateway](/cloudflare-one/traffic-policies/)를 수정하고 [Access](/cloudflare-one/integrations/identity-providers/)를 읽을 수 있습니다. |
| Cloudflare Images | [Cloudflare Images](/images/) 데이터에 접근할 수 있습니다. |
| Cloudflare R2 Admin | Cloudflare [R2](/r2/) 버킷, 객체 및 관련 구성을 수정할 수 있습니다. |
| Cloudflare R2 Read | Cloudflare [R2](/r2/) 버킷, 객체 및 관련 구성을 읽을 수 있습니다. |
| Cloudflare Stream | [Cloudflare Stream](/stream/) 미디어를 수정할 수 있습니다. |
| Cloudflare Zero Trust | [Cloudflare Zero Trust](/cloudflare-one/)를 수정할 수 있습니다. Access, Gateway, WARP, Tunnel, Browser Isolation, CASB, DLP, DEX, Email security를 포함한 모든 Zero Trust 제품의 관리자 권한을 부여합니다. |
| Cloudflare Zero Trust DNS Locations Write | [Gateway DNS 위치](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/#secure-dns-locations)를 보고 [보안 DNS 위치](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/#secure-dns-locations)를 생성 및 수정할 수 있습니다. |
| Cloudflare Zero Trust PII | [Cloudflare Zero Trust](/cloudflare-one/)의 PII에 접근할 수 있습니다. |
| Cloudflare Zero Trust Read Only | [Cloudflare Zero Trust](/cloudflare-one/)를 읽기 전용 모드로 사용할 수 있습니다. |
| Cloudflare Zero Trust Reporting | [Cloudflare Zero Trust](/cloudflare-one/) 리포팅 데이터에 접근할 수 있습니다. |
| DNS | [DNS 레코드](/dns/manage-dns-records/)를 수정할 수 있습니다. |
| Email Configuration Admin | Email security의 관리자 권한을 부여합니다. 이메일에 대해 작업하거나 이메일 내용을 읽을 수는 없습니다. |
| Email Integration Admin | 통합에 대해서만 읽기 및 쓰기 권한을 부여합니다. |
| Email security Analyst | 분석가 권한을 부여합니다. 이메일에 대해 조치를 취하고 이메일 내용을 읽을 수 있습니다. |
| Email security Read Only | Email security 전체에 대한 읽기 전용 접근 권한을 부여합니다. |
| Email security Reporting | Email security 메트릭 읽기 권한을 부여합니다. |
| Email security Policy Admin | 모든 설정에 대한 읽기 권한과 [allow policies](/cloudflare-one/email-security/settings/detection-settings/allow-policies/), [trusted domains](/cloudflare-one/email-security/settings/detection-settings/trusted-domains/), [blocked senders](/cloudflare-one/email-security/settings/detection-settings/blocked-senders/)에 대한 쓰기 권한을 부여합니다. |
| Firewall | [WAF](/waf/), [IP Access rules](/waf/tools/ip-access-rules/), [Zone Lockdown](/waf/tools/zone-lockdown/), [Cache Rules](/cache/how-to/cache-rules/) 설정을 수정할 수 있습니다. |
| Load Balancer | [Load Balancers](/load-balancing/), Pools, Origins, Health Checks를 수정할 수 있습니다. |
| Log Share | [Log Share](/logs/) 구성을 수정할 수 있습니다. |
| Log Share Reader | Enterprise [Log Share](/logs/)를 읽을 수 있습니다. |
| Magic Network Monitoring | [Network Flow 구성](/network-flow/)을 보고 수정할 수 있습니다. |
| Magic Network Monitoring Admin | [Network Flow 구성](/network-flow/)을 보고, 수정하고, 만들고, 삭제할 수 있습니다. |
| Magic Network Monitoring Read-Only | [Network Flow 구성](/network-flow/)을 볼 수 있습니다. |
| Network Services Write (Magic) | Magic 서비스의 네트워크 구성에 대한 쓰기 권한을 부여합니다. Magic Tunnel 상태 확인에는 관리자 권한이 없는 사용자의 경우 Analytics 역할이 필요합니다. |
| Network Services Read (Magic) | Magic 서비스의 네트워크 구성에 대한 읽기 권한을 부여합니다. Magic Tunnel 상태 확인에는 관리자 권한이 없는 사용자의 경우 Analytics 역할이 필요합니다. |
| Minimal Account Access | 계정만 볼 수 있고 그 외에는 접근할 수 없습니다. |
| Page Shield | 계정 전체에서 [Page Shield](/page-shield/)에 대한 쓰기 권한을 부여합니다. |
| Page Shield Read | 계정 전체에서 [Page Shield](/page-shield/) 읽기 권한을 부여합니다. |
| Hyperdrive Read | [Hyperdrive](/hyperdrive/) 데이터베이스 구성에 대한 읽기 권한을 부여합니다. |
| Hyperdrive Admin | [Hyperdrive](/hyperdrive/) 데이터베이스 구성에 대한 쓰기 권한을 부여합니다. |
| SSL/TLS, Caching, Performance, Page Rules, and Customization | [DNS](/dns/)와 [Firewall](/waf/)을 제외한 대부분의 Cloudflare 설정을 수정할 수 있습니다. |
| Secrets Store Admin | 시크릿 메타데이터를 생성, 수정, 복제, 삭제, 조회할 수 있습니다. 또한 [Secrets Store 바인딩을 Worker에 추가](/secrets-store/integrations/workers/)할 수 있습니다. |
| Secrets Store Deployer | 시크릿 메타데이터는 볼 수 있지만 생성, 수정, 복제, 삭제는 할 수 없습니다. 또한 [Secrets Store 바인딩을 Worker에 추가](/secrets-store/integrations/workers/)할 수 있습니다. |
| Secrets Store Reporter | 시크릿 메타데이터를 볼 수 있습니다. 어떤 작업도(생성, 수정, 복제, 삭제) 수행할 수 없고 Worker에 Secrets Store 바인딩도 추가할 수 없습니다. |
| Security Center Brand Protection | API와 Cloudflare 대시보드에서 Brand Protection 기능에 접근할 수 있습니다. 이 역할에는 Investigate 플랫폼 접근 권한도 포함됩니다. |
| Security Center Cloudforce One Admin | [Cloudforce One](/security-center/cloudforce-one/)에 대한 쓰기 권한을 부여합니다. |
| Security Center Cloudforce One Read | [Cloudforce One](/security-center/cloudforce-one/)에 대한 읽기 권한을 부여하며, RFI나 PIR을 만들거나 수정할 수 없습니다. |
| Trust and Safety | 신뢰 및 안전 관련 서비스에 접근할 수 있습니다. |
| Turnstile | [Turnstile](/turnstile/)에 대한 전체 접근 권한을 부여합니다. |
| Turnstile Read | [Turnstile](/turnstile/) 읽기 권한을 부여합니다. |
| Vectorize Admin | [Vectorize](/vectorize/) 구성을 수정할 수 있습니다. |
| Vectorize Read only | [Vectorize](/vectorize/) 구성을 읽을 수 있습니다. |
| Waiting Room Admin | [Waiting Room](/waiting-room/) 구성을 수정할 수 있습니다. |
| Waiting Room Read | [Waiting Room](/waiting-room/) 구성을 읽을 수 있습니다. |
| Workers Platform Admin | [Workers](/workers/), [Pages](/pages/), [Durable Objects](/durable-objects/), [KV](/kv/), [R2](/r2/), Zones, [Zone Analytics](/analytics/account-and-zone-analytics/zone-analytics/), [Page Rules](/rules/)를 포함해 Cloudflare 개발자 플랫폼에서 일반적으로 사용하는 모든 제품에 대한 읽기 및 수정 권한을 부여합니다. Cloudflare는 새 제품이 도입되면 이 역할에 추가적인 읽기 전용 권한을 더할 수 있습니다. |
| Workers Platform (Read-only) | [Workers](/workers/), [Pages](/pages/), [Durable Objects](/durable-objects/), [KV](/kv/), [R2](/r2/), Zones, [Zone Analytics](/analytics/account-and-zone-analytics/zone-analytics/), [Page Rules](/rules/)를 포함해 Cloudflare 개발자 플랫폼에서 일반적으로 사용하는 모든 제품에 대한 읽기 전용 권한을 부여합니다. Cloudflare는 새 제품이 도입되면 이 역할에 추가적인 읽기 전용 권한을 더할 수 있습니다. |
| Connectivity Directory Read | [Workers VPC Services](/workers-vpc/)와 [Cloudflare Tunnels](/workers-vpc/configuration/tunnel/)를 볼 수 있습니다. |
| Connectivity Directory Bind | [Workers VPC Services](/workers-vpc/)를 읽고 나열하고 바인딩할 수 있으며, [Cloudflare Tunnels](/workers-vpc/configuration/tunnel/)도 읽고 나열할 수 있습니다. |
| Connectivity Directory Admin | [Workers VPC Services](/workers-vpc/)를 보고, 수정하고, 만들고, 삭제할 수 있으며, [Cloudflare Tunnel](/workers-vpc/configuration/tunnel/)에 바인딩되는 VPC Services를 만들 수 있습니다. |
| Zaraz Admin | [Zaraz](/zaraz/) 구성을 수정하고 게시할 수 있습니다. |
| Zaraz Edit | [Zaraz](/zaraz/) 구성을 수정할 수 있습니다. |
| Zaraz Read | [Zaraz](/zaraz/) 구성을 읽을 수 있습니다. |
| Zone Versioning (Account-Wide) | 계정 내 모든 도메인에 대해 [Zone Versioning](/version-management/)을 보고 수정할 수 있습니다. |
| Zone Versioning Read (Account-Wide) | 계정 내 모든 도메인에 대해 [Zone Versioning](/version-management/)을 볼 수 있습니다. |

<a id="domain-scoped-roles"></a>
## 도메인 범위 역할

도메인 범위 역할은 계정 내 특정 도메인에 적용됩니다.

| 역할 | 설명 |
| ---- | ---- |
| AI Crawl Control Read Only | [AI Crawl Control](/ai-crawl-control/)과 메트릭을 읽을 수 있습니다. |
| Bot Management | [Bot Management](/bots/plans/bm-subscription/) 설정([Super Bot Fight Mode](/bots/get-started/super-bot-fight-mode/) 포함)을 수정할 수 있습니다. |
| Cache Domain Purge | 특정 도메인에 대해 [에지 캐시 비우기](/cache/how-to/purge-cache/) 권한을 부여하며 영역 설정을 읽을 수 있게 합니다. |
| Domain Administrator | 계정 내 도메인에 대한 전체 접근 권한과 계정 전체 [Firewall](/waf/account/managed-rulesets/deploy-dashboard/), [Access](/cloudflare-one/access-controls/policies/), [Worker](/workers/) 리소스에 대한 읽기 전용 권한을 부여합니다. |
| Domain Administrator Read Only | 계정 내 도메인에 대한 읽기 전용 접근 권한과 계정 전체 [Firewall](/waf/account/managed-rulesets/deploy-dashboard/), [Access](/cloudflare-one/access-controls/policies/), [Worker](/workers/) 리소스에 대한 읽기 전용 권한을 부여합니다. |
| Domain API Gateway | API Gateway([API Shield](/api-shield/) 포함)에 대한 전체 접근 권한을 부여합니다. |
| Domain API Gateway Read | API Gateway([API Shield](/api-shield/) 포함)에 대한 읽기 권한을 부여합니다. |
| Domain DNS | 계정 내 도메인의 [DNS 설정](/dns/)을 수정할 권한을 부여합니다. |
| Domain Page Shield | 계정 내 도메인에 대해 [Page Shield](/page-shield/) 쓰기 권한을 부여합니다. |
| Domain Page Shield Read | 계정 내 도메인에 대해 [Page Shield](/page-shield/) 읽기 권한을 부여합니다. |
| Domain Waiting Room Admin | [waiting rooms](/waiting-room/) 구성을 수정할 수 있습니다. |
| Domain Waiting Room Read | [waiting rooms](/waiting-room/) 구성을 읽을 수 있습니다. |
| Zone Versioning | [Zone Versioning](/version-management/)에 대한 전체 접근 권한을 부여합니다. |
| Zone Versioning Read | [Zone Versioning](/version-management/)에 대한 읽기 전용 접근 권한을 부여합니다. |

## 리소스 범위 역할

리소스 범위 역할은 계정 내 특정 리소스에 적용됩니다.

:::note
리소스 범위 역할은 현재 Beta입니다.
:::

| 역할 | 설명 |
| ---- | ---- |
| Cloudflare Access App Admin | 계정 내 특정 [Access application](/cloudflare-one/access-controls/applications/)을 수정할 수 있습니다. |
| Cloudflare Access Identity Provider Admin | 계정 내 특정 [Cloudflare One identity provider (IdP)](/cloudflare-one/integrations/identity-providers/)를 수정할 수 있습니다. |
| Cloudflare Access Policy Admin | 계정 내 특정 [Access policy](/cloudflare-one/access-controls/policies/)를 수정할 수 있습니다. |
| Cloudflare Access Service Token Admin | 계정 내 특정 [Access service token](/cloudflare-one/access-controls/service-credentials/service-tokens/)을 수정할 수 있습니다. |
| Access for Infrastructure Target Admin | 계정 내 특정 [Access for Infrastructure target](/cloudflare-one/access-controls/applications/non-http/infrastructure-apps/)을 수정할 수 있습니다. |

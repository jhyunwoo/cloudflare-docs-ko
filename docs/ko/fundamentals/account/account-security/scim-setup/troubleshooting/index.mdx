## 그룹 오구성 후 Super Administrator 복원

실수로 모든 Super Administrator를 제거했다면, SCIM 프로비저닝을 위해 생성한 Account API Token을 사용해 계정 멤버에게 역할을 복원할 수 있습니다.

먼저 [list members](/api/resources/accounts/subresources/members/methods/list/)를 통해 계정 멤버 목록을 가져오고, Super Admin 역할을 복원하려는 사용자의 member ID를 찾습니다.

```curl
curl -X GET "https://api.cloudflare.com/client/v4/accounts/{account_id}/members" \
  -H "Authorization: Bearer YOUR_SCIM_AOT" \
  -H "Content-Type: application/json"
```

그런 다음 [update member](/api/resources/accounts/subresources/members/methods/update/)를 통해 해당 멤버에 Super Admin 역할을 복원합니다.

```curl
curl -X PUT "https://api.cloudflare.com/client/v4/accounts/{account_id}/members/{member_id}" \
  -H "Authorization: Bearer YOUR_SCIM_AOT" \
  -H "Content-Type: application/json" \
  -d '{
    "roles": [
      {
        "id": "33666b9c79b9a5273fc7344ff42f953d"
      }
    ]
  }'
```

값 `33666b9c79b9a5273fc7344ff42f953d`는 Super Administrator의 role ID입니다.

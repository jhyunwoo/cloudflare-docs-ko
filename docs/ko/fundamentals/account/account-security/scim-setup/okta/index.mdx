[필요한 데이터 수집](/fundamentals/account/account-security/scim-setup/#gather-the-required-data)을 완료했다면, Okta로 프로비저닝을 마치기 위해 다음 단계를 진행해야 합니다.

## Okta SCIM 애플리케이션 설정

1. Okta dashboard에서 **Applications** > **Applications**로 이동합니다.
2. **Browse App Catalog**를 선택합니다.
3. **SCIM 2.0 Test App (OAuth Bearer Token)**을 찾아 선택합니다.
4. **Add Integration**을 선택하고 통합 이름을 지정합니다.
5. 다음 옵션을 활성화합니다.
   - **Do not display application icon to users**
   - **Do not display application icon in the Okta Mobile App**
6. **Automatically log in when user lands on login page**를 비활성화합니다.
7. **Next**를 선택한 다음 **Done**을 선택합니다.

## Cloudflare API 통합

:::note
**Update User Attributes** 옵션은 지원되지 않습니다.
:::

1. 통합 페이지에서 **Provisioning** > **Configure API Integration**으로 이동합니다.
2. **Enable API Integration**을 활성화합니다.
3. SCIM 2.0 Base URL에 `https://api.cloudflare.com/client/v4/accounts/<accountID>/scim/v2`를 입력합니다. 여기서 `accountID`는 [Cloudflare Account ID](/fundamentals/account/account-security/scim-setup/#get-your-account-id)로 대체합니다.
4. **OAuth Bearer Token** 필드에 API 토큰 값을 입력합니다.
5. **Import Groups**를 선택 해제합니다.

## Okta에서 사용자 및 그룹 동기화 구성

1. **Provisioning to App**에서 **Edit**를 선택합니다.
2. **Create Users**와 **Deactivate Users**를 활성화합니다. **Save**를 선택합니다.
3. **Done**을 선택합니다.
4. Assignments 탭에서 Cloudflare dashboard와 동기화하려는 사용자를 추가합니다. 그룹을 할당해 사용자를 일괄 추가할 수 있습니다. 사용자가 직접 할당에서 제거되거나 앱에 할당된 그룹에서 제거되면, Okta에서 Cloudflare로 디프로비저닝 이벤트가 트리거됩니다.
5. Push Groups 탭에서 Cloudflare dashboard와 동기화하려는 Okta 그룹을 추가합니다. 이 Okta 그룹은 dashboard의 Manage Account > Manage members > Members > User Groups에서 확인할 수 있습니다.

통합을 검증하려면 Okta SCIM 애플리케이션에서 **View Logs**를 선택하고, Cloudflare dashboard에서 **Manage Account** > **Audit Log**로 이동하여 Audit Logs를 확인합니다.

이렇게 하면 영향을 받는 그룹의 모든 사용자가 "minimal account access" 권한으로 Cloudflare 계정에 프로비저닝됩니다.

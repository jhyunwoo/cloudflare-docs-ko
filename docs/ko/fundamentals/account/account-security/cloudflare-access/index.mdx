때때로 Account Team에 편집 액세스를 허용해야 할 수 있습니다. 대표적인 사용 사례로는 복잡하거나 민감한 도메인을 Cloudflare로 이전하는 작업이 있습니다.

기본적으로 Cloudflare는 계정에 대한 편집 액세스를 가지고 있지 않습니다.

Account Team의 편집 액세스를 활성화하려면 다음 단계를 따르세요.

1. Cloudflare dashboard에서 **Configurations** 페이지로 이동합니다. (반드시 **Super Administrator**로 로그인해야 합니다.)

    <DashButton url="/?to=/:account/configurations" />

2. **Editing Permission**의 토글을 **On**으로 전환합니다.
3. 기간을 선택합니다.
4. **Approve**를 클릭합니다.

:::note


긴급한 상황에서는 Cloudflare Support가 **Editing Permissions**를 재정의하고 계정을 업데이트할 수 있지만, Super Administrator는 이메일을 받게 되며 해당 작업은 [Audit Logs](/fundamentals/account/account-security/review-audit-logs/)에 **Action**이 **Break glass**인 항목으로 기록됩니다.


:::

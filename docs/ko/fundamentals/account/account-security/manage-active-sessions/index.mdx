## 활성 세션 보기

이메일 주소와 연결된 활성 세션을 보려면 다음 단계를 따르세요.

1. Cloudflare dashboard에서 **Account home** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/home" />

2. **My Profile** > **Sessions**로 이동합니다.

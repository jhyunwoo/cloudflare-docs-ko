## 보관 기간

Audit Logs는 삭제되기 전까지 18개월 동안 보관됩니다. Enterprise 고객은 [Logpush](/logs/logpush/)를 사용하여 Audit Logs를 더 오랜 기간 저장할 수 있습니다.

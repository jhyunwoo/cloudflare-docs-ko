Cloudflare는 Cloudflare dashboard에 로그인할 때 비밀번호가 손상되었는지 자동으로 확인합니다. 계정에 로그인할 때마다 위협 인텔리전스 소스를 통해 안전하게 확인하여, 비밀번호가 과거 데이터 유출 사고에서 노출된 적이 있는지 검증합니다.

Cloudflare가 유출된 자격 증명을 확인하는 방식에 대한 자세한 내용은 [블로그 게시물](https://blog.cloudflare.com/helping-keep-customers-safe-with-leaked-password-notification/)을 참조하세요.

:::note[Note]


Cloudflare는 비밀번호를 유출했을 가능성이 있는 특정 침해 사고나 Internet service에 대한 추가 정보를 가지고 있지 않습니다.

[Have I Been Pwned](https://haveibeenpwned.com/)와 같은 널리 사용되는 온라인 도구를 사용하면 외부 계정이 어디에서 공격받았는지 더 잘 이해할 수 있습니다. 이 비밀번호를 다른 시스템에서도 재사용했다면 해당 시스템에서도 비밀번호를 재설정하는 것이 좋습니다.


:::

비밀번호가 데이터 유출 사고에서 발견되면, 비밀번호를 재설정하는 방법에 대한 정보를 이메일로 보내고 Cloudflare dashboard에서도 재설정을 요청합니다.

처음 세 번의 로그인 시도에서는 비밀번호를 재설정해야 한다는 경고가 표시됩니다. 세 번의 시도 이후에는 Cloudflare에 로그인하려면 반드시 비밀번호를 재설정해야 합니다.

[Single Sign-On (SSO)](/fundamentals/manage-members/dashboard-sso/) 또는 [two-factor authentication (2FA)](/fundamentals/user-profiles/2fa/)를 사용하는 사용자는 이러한 기능이 더 높은 수준의 보안을 제공하므로 이 요구 사항의 적용을 받지 않습니다.

계정을 보호하기 위해 two-factor authentication을 활성화하는 것을 권장합니다.

Cloudflare 계정의 Super Administrator는 [모든 멤버가 2FA를 사용하도록 요구](/fundamentals/user-profiles/2fa/#enable-two-factor-authentication-for-your-cloudflare-account)할 수도 있습니다. 이 기능은 Cloudflare dashboard에서 **Manage Account** > **Members**로 이동하여 활성화할 수 있습니다.

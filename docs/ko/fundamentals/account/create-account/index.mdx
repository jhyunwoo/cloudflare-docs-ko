Cloudflare 계정을 만들려면 다음 단계를 따르세요.

1. [Sign up 페이지](https://dash.cloudflare.com/sign-up)로 이동합니다.
2. **Email**과 **Password**를 입력합니다.
3. **Create Account**를 선택합니다.

계정을 만들면 Cloudflare가 해당 주소로 이메일을 자동 전송하여 [이메일 주소를 인증](/fundamentals/user-profiles/verify-email-address/)하도록 안내합니다.

## 계정 이름

계정 이름의 기본값은 `<<YOUR_EMAIL_ADDRESS>>'s Account`입니다.

이 계정의 목적을 더 명확히 하거나 여러 계정과 더 쉽게 연결할 수 있도록 계정 이름을 사용자 지정하고 싶을 수 있습니다.

계정 이름을 변경하려면 다음 단계를 따르세요.

1. Cloudflare 대시보드에서 **Configurations** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/configurations" />

2. **Account Name**에서 **Change Name**을 선택합니다.
3. 새 계정 이름을 입력합니다.
4. **Save**를 선택합니다.

## Cloudflare와 상호 작용하기

코드 없이 작업하는 것을 선호한다면 [Cloudflare 대시보드](https://dash.cloudflare.com/login)를 통해 계정 및 도메인 설정을 관리할 수 있습니다.

:::note

호스팅 파트너가 도메인을 Cloudflare에 추가한 경우 DNS 레코드는 해당 호스팅 파트너를 통해 관리하세요.

:::

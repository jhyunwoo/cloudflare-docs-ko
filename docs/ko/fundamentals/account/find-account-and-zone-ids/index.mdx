새 [계정을 설정](/fundamentals/account/)하고 도메인을 Cloudflare에 [추가](/fundamentals/manage-domains/add-site/)한 후에는 API 작업을 위해 Zone ID와 Account ID가 필요할 수 있습니다.

## Account ID 복사하기

1. Cloudflare 대시보드에서 **Account home** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/home" />

2. 계정 행 끝에 있는 메뉴 버튼을 선택합니다.
![**Overview** 페이지에서 **API** 섹션이 강조 표시된 스크린샷](~/assets/images/fundamentals/get-started/overview-account-id.png)

3. **Copy account ID**를 선택합니다.

### 단일 계정 사용자

계정이 하나뿐일 때 Account ID를 복사하려면 다음 단계를 따르세요.

1. Cloudflare 대시보드에서 **Account home** 페이지로 이동한 다음 계정을 찾습니다.

    <DashButton url="/?to=/:account/home" />

2. 계정 이름 옆의 메뉴 버튼을 선택합니다.
3. 표시되는 목록에서 **Copy account ID**를 선택합니다.
![**Overview** 페이지에서 **API** 섹션이 강조 표시된 스크린샷](~/assets/images/fundamentals/get-started/single-account-id.png)

## Zone ID 복사하기

1. Cloudflare 대시보드에서 **Account** home으로 이동한 다음 계정을 찾습니다.

    <DashButton url="/?to=/:account/home" />

2. 계정의 **Overview** 페이지에서 페이지 하단 쪽에 있는 **API** 섹션을 찾습니다.

![**Overview** 페이지에서 **API** 섹션이 강조 표시된 스크린샷](~/assets/images/fundamentals/get-started/dash-overview-api-highlighted.png)

3. **Zone ID** 아래에서 **Click to copy**를 선택합니다. **API** 섹션 아래에서 **Account ID**도 찾을 수 있습니다.

## Account ID 찾기 (Workers and Pages)

계정의 **Workers & Pages** 섹션에서도 Account ID를 찾을 수 있습니다.

1. Cloudflare 대시보드에서 **Workers & Pages** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/workers-and-pages" />

2. **Account details** 섹션에 **Account ID**가 표시됩니다.
3. Account ID를 복사하려면 **Click to copy**를 선택합니다.

![**Workers & Pages Overview** 페이지에서 account ID 섹션이 강조 표시된 스크린샷](~/assets/images/fundamentals/get-started/workers-account-id.png)

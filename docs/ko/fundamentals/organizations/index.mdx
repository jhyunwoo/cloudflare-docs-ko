Cloudflare 조직은 여러 계정, 도메인(영역이라고도 함), 팀을 한곳에서 중앙 관리할 수 있게 해 주어 관리 방식을 단순화합니다. 또한 계정 간 구성을 공유하고 집계된 분석도 확인할 수 있습니다.

:::note

Cloudflare Organizations는 현재 비공개 베타입니다.

:::

## 조직 만들기

1. [Cloudflare 대시보드](https://dash.cloudflare.com)에 로그인합니다.
2. **Organizations**를 선택합니다.
3. **Organizations** 페이지에서 **Create organization**을 선택합니다.
4. 조직 이름을 입력하고 **Create**를 선택합니다. 조직 개요 페이지가 표시됩니다.

:::note

사용자는 하나의 조직만 만들 수 있습니다.

:::

## 조직 개요

조직 개요에서 조직에 할당된 계정을 확인할 수 있습니다. 계정을 할당한 후에는 계정을 열어보거나, 계정 ID를 복사하거나, 계정 이름을 바꿀 수 있습니다.

### 조직에 계정 할당하기

조직을 만든 후 어떤 계정을 조직에 할당할지 결정합니다.

1. **Organization Overview**에서 **Assign an account**를 선택합니다. 자신이 Super Administrator로 등록된 Enterprise 계정 목록이 표시됩니다.
2. 텍스트 필드에서 계정 이름을 검색한 다음 선택합니다.
3. 완료되면 **Assign to organization**을 선택합니다. 새로 할당된 계정이 포함된 조직 개요 페이지가 표시됩니다.

:::note

조직에서 계정을 제거하려면 Cloudflare 계정 팀에 문의하세요.

:::

## Analytics & Logs

조직을 통해 Cloudflare에 연결된 모든 도메인의 들어오는 HTTP 트래픽을 검토할 수 있습니다. 이 데이터에는 프록시된 호스트 이름의 트래픽이 포함되며, 청구 대상 사용량을 반영하지 않을 수 있고, 적응형 샘플을 기반으로 할 수 있습니다.

선택적 필터를 추가하여 HTTP 트래픽과 관련된 특정 데이터도 볼 수 있습니다. 데이터 보고서를 인쇄하거나 다운로드할 수도 있습니다.

## Shared Configurations

[WAF Custom Rulesets](/waf/custom-rules/)와 [Gateway policies](/cloudflare-one/traffic-policies/)를 사용해 조직 또는 하위 조직 전체에 글로벌 정책을 생성하고 적용할 수 있습니다.

공유 구성을 활용하면 하나 이상의 계정에 적용할 수 있는 WAF 사용자 지정 규칙 세트를 정의하고, 이를 한곳에서 관리할 수 있습니다.

## 조직 관리

조직 이름을 바꾸고, 조직과 관련된 고객 식별 데이터를 추가하거나 수정합니다.

### 조직 이름 바꾸기

1. **Organizations** > **Manage Organization**을 선택합니다.
2. **Organization name**에서 **Rename**을 선택합니다.
3. 조직의 새 이름을 입력하고 **Rename**을 선택합니다.

### 고객 식별 데이터 편집

1. **Organizations** > **Manage Organization**을 선택합니다.
2. **Customer identification data**에서 **Edit**를 선택합니다.
3. 텍스트 필드에 정보를 입력하고 **Save**를 선택합니다.

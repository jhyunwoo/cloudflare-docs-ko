_도메인(domain)_ 또는 _도메인 이름(domain name)_ (또는 _zone_ 이라고도 함)은 웹사이트나 애플리케이션의 위치이거나, 최종 사용자가 웹사이트에 접속하기 위해 브라우저에 입력하는 값입니다 (`example.com`).

## 도메인 이름 얻기

웹사이트용 도메인 이름은 다양한 곳에서 구매할 수 있습니다. Cloudflare는 원가 기반 등록기관 서비스를 제공하여 [새 도메인 이름을 구매](/registrar/get-started/register-domain/)하거나 [기존 도메인 이름을 이전](/registrar/get-started/transfer-domain-to-cloudflare/)할 수 있습니다.

계정과 도메인을 보호하는 방법의 자세한 목록은 [계정 및 도메인 관리 모범 사례](/fundamentals/reference/best-practices/)를 참고하세요.

## 도메인 호스팅

웹 호스트는 방문자가 도메인 이름을 통해 접속할 수 있도록 웹사이트를 온라인 상태로 유지합니다.

Cloudflare는 대부분의 웹사이트에 대해 웹 호스팅을 제공하지 않지만, [Cloudflare Pages](/pages/)를 사용해 JAMstack 사이트를 배포하고 호스팅할 수 있습니다.

<a id="add-a-domain-to-cloudflare"></a>
## Cloudflare에 도메인 추가

도메인을 Cloudflare CDN에 온보딩하는 방법은 [설정 가이드](/fundamentals/manage-domains/add-site/)를 참고하세요.

캐싱, DDoS 보호, Argo Smart Routing 및 기타 [애플리케이션 보안 및 성능 제품](/directory/?product-group=Application+performance%2CApplication+security)의 이점을 얻으려면 [도메인의 네임서버를 업데이트](/dns/zone-setups/full-setup/)하고 웹 트래픽을 [프록시](/dns/proxy-status/)해야 합니다.

## 무료 SSL 인증서 받기

Cloudflare는 모든 Cloudflare 도메인에 대해 무료의 공유되지 않는 공개 신뢰 [Universal SSL 인증서](/ssl/edge-certificates/universal-ssl/)를 제공합니다.

## 서브도메인 관리

서브도메인(`www.example.com` 또는 `blog.example.com`)에 대한 자세한 내용은 [서브도메인 관리](/fundamentals/manage-domains/manage-subdomains/)를 참고하세요.

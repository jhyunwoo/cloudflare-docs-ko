[도메인을 Cloudflare에 추가](/fundamentals/manage-domains/add-site/)하고 [네임서버를 업데이트](/dns/zone-setups/full-setup/)한 뒤에는 서브도메인도 설정하고 싶을 수 있습니다.

대부분의 서브도메인은 웹사이트 전체 맥락에서 특정한 목적을 가집니다. 예를 들어 `blog.example.com`은 블로그, `support.example.com`은 고객 지원 포털, `store.example.com`은 전자상거래 사이트가 될 수 있습니다.

## 서브도메인 만들기

호스트에 이미 서브도메인을 추가했다면, 해당 서브도메인(`blog`, `store`)에 대응하는 [DNS A 또는 CNAME 레코드](/dns/manage-dns-records/how-to/create-dns-records/)를 만드세요.

## 리디렉션 설정

### 서브도메인을 apex domain으로 리디렉션

경우에 따라 서브도메인(`www.example.com`)으로 들어오는 모든 트래픽을 실제로 apex domain(`example.com`)으로 보내고 싶을 수 있습니다.

1. 서브도메인에 대해 [프록시된 DNS A 레코드](/dns/manage-dns-records/how-to/create-dns-records/)를 만듭니다. 모든 트래픽은 해당 주소에 도달하기 전에 리디렉션되므로, 이 레코드는 어떤 IP 주소를 가리켜도 됩니다.

   | **유형** | **이름** | **IPv4 주소** | **프록시 상태** |
   | -------- | -------- | ------------- | --------------- |
   | A        | `www`    | `192.0.2.1`   | Proxied         |

2. [Single Redirect](/rules/url-forwarding/single-redirects/create-dashboard/)를 만들어 서브도메인에서 apex domain으로 트래픽을 전달합니다.

<Example>

**들어오는 요청이 다음과 일치할 때**

Expression Editor 사용:<br/>
`(http.request.full_uri contains "www.example.com")`

**다음 수행**

* **유형:** *Dynamic*
* **식:** `concat("https://","example.com",http.request.uri.path)`
* **상태 코드:** *301*

</Example>

### apex domain을 서브도메인으로 리디렉션

경우에 따라 apex domain(`example.com`)으로 들어오는 모든 트래픽을 실제로 서브도메인(`www.example.com`)으로 보내고 싶을 수 있습니다.

1. 호스트에 해당 서브도메인을 이미 추가했다면, 그 서브도메인에 대응하는 [DNS A 또는 CNAME 레코드](/dns/manage-dns-records/how-to/create-dns-records/)를 만듭니다.

2. apex domain에 대해 프록시된 DNS A 레코드를 만듭니다. 모든 트래픽은 해당 주소에 도달하기 전에 리디렉션되므로, 이 레코드는 어떤 IP 주소를 가리켜도 됩니다.

   | **유형** | **이름** | **IPv4 주소** | **프록시 상태** |
   | -------- | -------- | ------------- | --------------- |
   | A        | `@`      | `192.0.2.1`   | Proxied         |

3. [Single Redirect](/rules/url-forwarding/single-redirects/create-dashboard/)를 만들어 apex domain에서 서브도메인으로 트래픽을 전달합니다.

<Example>

**들어오는 요청이 다음과 일치할 때**

Expression Editor 사용:<br/>
`(lower(http.host) eq "example.com")`

**다음 수행**

* **유형:** *Dynamic*
* **식:** `concat("https://","www.example.com",http.request.uri.path)`
* **상태 코드:** *301*

</Example>

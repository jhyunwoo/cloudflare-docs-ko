사이트 문제를 해결하기 위해 Cloudflare를 전체적으로 일시 중지할 수 있습니다. 이렇게 하면 Cloudflare의 리버스 프록시 대신 원본 웹 서버로 직접 트래픽이 전달됩니다. 일시 중지된 도메인은 [Rules](/rules/), [WAF](/waf/), [SSL/TLS 인증서](/ssl/edge-certificates/) 같은 Cloudflare 서비스도 사용할 수 없습니다. 보호 기능은 유지하면서 캐시만 우회하려면 [개발자 모드](/fundamentals/manage-domains/pause-cloudflare/#enable-development-mode)를 사용하는 것이 더 나을 수 있습니다.

1. Cloudflare 대시보드에서 **Account home** 페이지로 이동해 계정과 도메인을 선택합니다.

    <DashButton url="/?to=/:account/home" />

2. **Overview**에서 **Advanced Actions** > **Pause Cloudflare on Site**를 선택합니다.

Cloudflare를 일시 중지하는 데는 5분 이내가 소요됩니다. 이 방법은 몇 시간의 전파 지연을 유발할 수 있는 [네임서버 변경](/dns/zone-setups/full-setup/setup/)보다 바람직합니다.

:::note
영역을 비활성화해도 Spectrum 애플리케이션에는 영향이 없습니다.
:::

***

## 전체 일시 중지의 대안

### DNS 레코드에서 프록시 비활성화

Cloudflare를 전체적으로 일시 중지하는 대신 개별 레코드에서 프록시를 비활성화할 수 있습니다.

1. [Cloudflare 대시보드](https://dash.cloudflare.com/)에 로그인하고 계정과 도메인을 선택합니다.

2. **DNS** > **Records**로 이동합니다. 레코드를 선택하고 **Edit**를 누릅니다.

3. **Proxy Status**를 **Off**로 전환합니다.

프록시 상태를 조정하면 해당 레코드는 [Rules](/rules/), [WAF](/waf/), [SSL/TLS 인증서](/ssl/edge-certificates/) 같은 Cloudflare 서비스를 사용하지 않게 됩니다.

<a id="enable-development-mode"></a>
### 개발자 모드 활성화

캐싱 문제를 해결하려면 [개발자 모드](/cache/reference/development-mode/)를 활성화할 수 있습니다. 이렇게 하면 [Rules](/rules/), [WAF](/waf/), [SSL/TLS 인증서](/ssl/edge-certificates/) 같은 Cloudflare 서비스는 유지하면서 Cloudflare 캐시만 우회합니다.

다음 섹션에서는 Cloudflare에서 도메인을 제거하는 방법을 설명합니다. 도메인을 제거하면 해당 도메인의 모든 활성 구독이 취소되며, 이는 [청구 정책](/billing/billing-policy/)에 따라 환불되지 않습니다. 나중에 이 도메인을 다시 Cloudflare에 추가하면 모든 구독을 다시 구매해야 합니다. Cloudflare에서 도메인을 제거해도 도메인 등록 정보 자체는 변경되지 않습니다.

## 도메인을 제거하기 전에

웹사이트 문제가 있다면 먼저 [Cloudflare를 일시적으로 중지](/fundamentals/manage-domains/pause-cloudflare/)하여 웹사이트 성능을 평가하는 것을 권장합니다.

Enterprise 플랜을 사용 중이라면 영역 플랜을 **Free**로 [변경](/billing/change-plan/#change-plan-type)해야 합니다.

도메인을 다른 계정에 다시 추가해야 한다면 현재 설정이 저장되어 있는지 확인하세요. 예를 들어 [DNS 레코드를 가져오고 내보낼 수 있습니다](/dns/manage-dns-records/how-to/import-and-export/).

:::note
도메인을 방금 추가했고 아직 플랜을 구성하지 않았다면 해당 도메인은 `Initializing (Setup)` 상태이며 삭제할 수 없습니다.
이 단계에서는 이 도메인에 대해 플랜을 선택해야 하며, 그러면 상태가 `Pending`으로 바뀌고 이후 삭제할 수 있습니다.
또한 `Initializing (Setup)` 또는 `Pending` 상태의 도메인은 활성화되지 않으면 [28일 후 자동으로 삭제](/dns/zone-setups/reference/domain-status/#initializing-setup)됩니다.
:::


### Cloudflare 외부에서 해야 할 작업

* Cloudflare에서 도메인을 제거하면 해당 도메인은 DNS 해석에도 Cloudflare를 사용할 수 없게 됩니다. DNS 오류를 피하려면 도메인 등록기관에서 네임서버를 Cloudflare 소유가 아닌 네임서버로 업데이트하세요.

  * 네임서버가 더 이상 Cloudflare를 가리키지 않는지 확인하려면 [네임서버가 Cloudflare를 가리키는지 확인](/dns/zone-setups/full-setup/setup/#verify-changes)을 참고하세요.

* 등록기관에서 **DS** DNS 레코드가 없는지 확인하세요. 이 레코드는 [DNSSEC](/dns/dnssec/)를 활성화하며 DNS 레코드 변경을 막을 수 있습니다.

### Cloudflare 내부에서 해야 할 작업

* [활성 부가 기능 구독 취소](/billing/cancel-subscription/)

* [해당 도메인의 모든 Logpush 작업 삭제](/logs/logpush/examples/example-logpush-curl/#optional---delete-a-job)

* Cloudflare Registrar를 사용하는 경우:

  * [도메인 자동 갱신 비활성화](/registrar/account-options/renew-domains/) 또는 [도메인을 Cloudflare 외부로 이전](/registrar/account-options/transfer-out-from-cloudflare/)

  * 도메인이 이미 만료되었다면 계정에서 자동으로 제거됩니다. [도메인이 만료되면 어떻게 되나요?](/registrar/faq/#what-happens-when-a-domain-expires)를 참고하세요.

  * 도메인이 아직 만료되지 않았다면 삭제를 요청할 수 있습니다. [도메인 등록 삭제](/registrar/account-options/domain-management/#delete-a-domain-registration)를 참고하세요.

  * 활성화되어 있다면 DNSSEC를 비활성화하세요. 도메인 대시보드에서 **DNS** > **Settings**로 이동합니다. **DNSSEC**에서 **Disable DNSSEC**를 선택한 뒤 **Confirm**을 선택합니다.

## Cloudflare에서 활성화된 도메인 제거

1. Cloudflare 대시보드에 로그인합니다.

    <DashButton url="/?to=/:account/home" />

2. **Overview** 페이지에서 **Advanced Actions**를 찾은 다음 **Remove Site from Cloudflare**를 선택합니다.

   ![웹사이트 개요 페이지의 Advanced Actions 아래에 있는 Remove site from Cloudflare 옵션](~/assets/images/fundamentals/get-started/remove-domain.png)

   :::note
   Enterprise 도메인을 사용 중이라면 **Remove Site from Cloudflare**에 접근하려면 도메인 플랜을 **Free**로 [변경](/billing/change-plan/#change-plan-type)해야 합니다.<br/><br/>그래도 되지 않으면 Customer Success Manager에게 문의하세요.
   :::

3. **Confirm**을 선택합니다.

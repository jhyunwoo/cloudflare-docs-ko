다른 도메인으로 트래픽만 전달하는 별칭 도메인(즉, 자체 원본 서버가 없는 도메인)이 있다면, Cloudflare 내부에서 직접 리디렉션을 설정할 수 있습니다.

1. 별칭 도메인(예: `previous.com`)을 Cloudflare에 [추가](/fundamentals/manage-domains/#add-a-domain-to-cloudflare)합니다.

2. 별칭 도메인에 DNS 쿼리를 올바르게 해석할 수 있는 프록시된 [DNS A 또는 CNAME 레코드](/dns/manage-dns-records/how-to/create-dns-records/)가 있는지 확인합니다. `www`용 서브도메인 DNS 레코드도 포함하는 것이 좋습니다.

   `A` 레코드에는 IP 주소 `192.0.2.1`을 사용하세요. 이 주소는 트래픽을 원본 서버로 라우팅하지 않지만, Cloudflare가 들어오는 트래픽에 규칙, 리디렉션, Workers를 적용할 수 있게 해 줍니다. `AAAA` 레코드에 해당하는 IP 주소는 `100::`입니다.

   | **유형** | **이름** | **IPv4 주소** | **프록시 상태** |
   | -------- | -------- | ------------- | --------------- |
   | A        | `@`      | `192.0.2.1`   | Proxied         |
   | A        | `www`    | `192.0.2.1`   | Proxied         |

3. [리디렉션 규칙](/rules/url-forwarding/)을 사용해 별칭 도메인에서 다른 도메인으로 트래픽을 전달합니다.

이 예시는 `smallshop.example.com`에 대한 모든 요청을 HTTPS를 사용해 다른 호스트명으로 리디렉션하면서, 원래 경로와 쿼리 문자열은 유지합니다.

   <Example>

   **들어오는 요청이 다음과 일치할 때**
   - **필드:** _Hostname_
   - **연산자:** _equals_
   - **값:** `smallshop.example.com`

   Expression Editor를 사용하는 경우 다음 식을 입력합니다:<br/>
   `(http.host eq "smallshop.example.com")`

   **다음 수행**
   - **유형:** _Dynamic_
   - **식:** `concat("https://globalstore.example.net", http.request.uri.path)`
   - **상태 코드:** _301_
   - **쿼리 문자열 유지:** 활성화됨

   </Example>

   예를 들어 이 리디렉션 규칙은 다음과 같은 리디렉션을 수행합니다.

   | 요청 URL                                             | 대상 URL                                                   | 상태 코드 |
   | ---------------------------------------------------- | ---------------------------------------------------------- | --------- |
   | `http://smallshop.example.com/`                      | `https://globalstore.example.net/`                         | `301`     |
   | `http://smallshop.example.com/admin/?logged_out=true` | `https://globalstore.example.net/admin/?logged_out=true` | `301`     |
   | `https://smallshop.example.com/?all_items=1`         | `https://globalstore.example.net/?all_items=1`             | `301`     |
   | `http://example.com/about/`                          | (변경 없음)                                                | n/a       |

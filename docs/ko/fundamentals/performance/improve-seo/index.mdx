검색 엔진 최적화(SEO)의 목표는 웹사이트가 다양한 검색 엔진 제공업체(Google, Bing 등)에서 더 높은 순위를 차지하도록 하는 것입니다.

실제로 SEO는 주로 양질의 콘텐츠, 사용자 경험, 그리고 검색 엔진 크롤러가 작업하기 어렵지 않도록 만드는 것에 관한 것입니다. Cloudflare가 양질의 콘텐츠를 대신 작성해 주지는 못하지만, 특히 [사이트 속도](https://www.cloudflare.com/learning/performance/how-website-speed-boosts-seo/)와 관련된 사용자 경험 및 검색 크롤러 측면에서는 도움이 될 수 있습니다.

:::note[팁:]


SEO 전반에 관한 일반적인 지침은 [Google의 권장 사항](https://developers.google.com/search/docs/advanced/guidelines/overview)을 참고하세요.


:::

## Cloudflare로 SEO 개선하기

여러 Cloudflare 기능이 검색 엔진 사이트 순위를 향상시킵니다. 하지만 의미 있고 정기적으로 업데이트되는 사이트 콘텐츠는 여전히 SEO 개선에 매우 중요합니다.

### 사이트 속도 향상

적어도 2010년부터 Google은 [사이트 속도가 Google 순위에 영향을 준다](https://webmasters.googleblog.com/2010/04/using-site-speed-in-web-search-ranking.html)고 공개적으로 밝혀 왔습니다.

Cloudflare는 [사이트 성능 최적화](/speed/)를 위한 여러 기능을 제공합니다.

### HTTPS 활성화

검색 엔진이 HTTPS를 [순위 신호](https://webmasters.googleblog.com/2014/08/https-as-ranking-signal.html)로 사용하므로 HTTPS는 SEO에 매우 중요합니다.

도메인이 HTTPS를 통해 접근 가능하도록 하려면 다음을 수행하세요.

1. 도메인용 [SSL/TLS 인증서](/ssl/get-started/)를 발급받습니다.
2. 방문자를 도메인의 HTTPS 버전으로 [리디렉션](/ssl/edge-certificates/encrypt-visitor-traffic/)합니다.

### Crawler Hints 활성화

[Crawler Hints](/cache/advanced-configuration/crawler-hints/)를 사용하면 검색 엔진과 기타 봇 기반 경험이 콘텐츠의 최신 버전을 확보할 수 있고, 이는 더 만족스러운 사용자 경험으로 이어지며 궁극적으로 검색 순위에도 영향을 줍니다.

## 문제 해결

도메인의 보안 설정에 따라 실수로 검색 엔진 크롤러를 차단할 수 있습니다.

SEO 문제가 보인다면 다음을 확인하세요.

* [WAF 사용자 지정 규칙](/waf/troubleshooting/faq/#caution-about-potentially-blocking-bots)이 **Verified Bots**를 허용하는지 확인합니다.
* [속도 제한 규칙](/waf/rate-limiting-rules/)이 **Verified Bots**를 허용하는지 확인합니다.
* [봇 보호](/bots/concepts/bot/verified-bots/) 설정이 **Verified Bots**를 차단하지 않는지 확인합니다.

검색 엔진 크롤러 관련 문제가 계속되면 [문제 해결 가이드](/support/troubleshooting/general-troubleshooting/troubleshooting-crawl-errors/)를 참고하세요.

## 흔한 오해

다음 특성은 도메인의 SEO에 영향을 주지 않습니다.

* **네임서버 변경**: Cloudflare 네임서버를 사용해도 도메인의 SEO에는 영향을 주지 않습니다.
* **서버 위치**: Google에 따르면 [서버 위치](http://www.seroundtable.com/seo-geo-location-server-google-17468.html)는 SEO에서 중요하지 않습니다.
* **IP 주소를 공유하는 사이트**: 일반적으로 검색 엔진은 이들 사이트 중 여러 개가 악성 또는 스팸 사이트가 아닌 한, 공유 IP 주소를 사용하는 도메인에 불이익을 주지 않습니다.
* **Cloudflare 캐싱**: Cloudflare가 콘텐츠를 캐시하면 실제로 콘텐츠 전달 속도가 빨라져 SEO에 도움이 됩니다. 캐싱은 중복 콘텐츠를 만들거나, URL을 다시 쓰거나, 추가 하위 도메인을 만들지 않습니다.

Cloudflare는 웹사이트 속도와 인터넷 연결 속도를 테스트할 수 있는 여러 도구를 제공합니다.

***

## 웹사이트 속도 테스트

### Cloudflare 사용

도메인이 [Cloudflare에서 활성화](/fundamentals/manage-domains/add-site/)되면 [Cloudflare 대시보드](https://dash.cloudflare.com/?to=/:account/:zone/speed) 안에서 속도 테스트를 실행할 수 있습니다.

이 속도 테스트는 중요한 로딩 시간, [Cloudflare 프록시](/fundamentals/concepts/how-cloudflare-works/) 사용 여부에 따른 성능 차이, 권장 최적화 정보를 제공합니다.

문제가 발생하면 특정 [사용자 에이전트](/fundamentals/reference/cloudflare-site-crawling/#other-situations)를 차단하고 있지 않은지 확인하세요.

### 타사 도구 사용

도메인이 아직 Cloudflare에서 활성 상태가 아니거나 Cloudflare 사용 전후의 개선 효과를 측정하고 싶다면, Cloudflare는 다음 타사 도구 사용을 권장합니다.

* [PageGym](https://pagegym.com/)
* [GTmetrix](https://gtmetrix.com/)
* [DebugBear](https://www.debugbear.com/test/website-speed)
* [Lighthouse](https://developer.chrome.com/docs/lighthouse/)
* [WebPageTest](https://www.webpagetest.org/)

이러한 타사 도구를 사용한다면 웹사이트 속도 테스트를 위해 다음 단계를 따르세요.

1. 성능 및 캐싱 이점을 제거하기 위해 [Cloudflare를 일시 중지](/fundamentals/manage-domains/pause-cloudflare/)합니다.
2. 속도 테스트를 실행합니다.
3. Cloudflare 일시 중지를 해제합니다.
4. 속도 테스트를 실행합니다[^1].
5. Cloudflare 사용 시 기준 성능을 얻기 위해 두 번째 속도 테스트를 실행합니다.

[^1]: Cloudflare를 사용하는 첫 번째 속도 테스트 결과에는 캐시되지 않은 결과가 포함될 가능성이 높아 정확하지 않을 수 있습니다.<br/><br/>Cloudflare가 사이트 속도를 높이는 핵심 방법 중 하나는 [캐싱](/cache/)이며, 이는 두 번째 테스트 결과에 반영됩니다.

### 속도 개선

이 속도 테스트 결과를 바탕으로 Cloudflare를 사용해 [사이트 속도를 최적화](/speed/)하는 다른 방법을 살펴볼 수 있습니다.

:::note


Cloudflare는 Time to First Byte(TTFB)를 페이지 로드 속도의 가장 중요한 지표로 보지 않습니다. Cloudflare 사용 시 TTFB가 느려지는 것이 걱정된다면 [Cloudflare와 TTFB](http://blog.cloudflare.com/ttfb-time-to-first-byte-considered-meaningles/)에 관한 블로그 게시물을 참고하세요.


:::

## 인터넷 속도 테스트

가정용 네트워크 연결 속도(다운로드, 업로드, 패킷 손실, 핑 측정 등)를 테스트하려면 [speed.cloudflare.com](https://speed.cloudflare.com)을 방문하세요.

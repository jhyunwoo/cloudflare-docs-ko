사용자 토큰은 특정 사용자를 대신해 동작하며 그 사용자의 권한 일부를 상속하는 반면, 계정 API 토큰을 사용하면 자체 권한 집합을 가진 서비스 주체처럼 동작하는 내구성 있는 통합을 구성할 수 있습니다. 이 방식은 CI/CD나 SIEM 같은 외부 서비스와의 통합처럼, 통합을 설정한 사용자가 조직을 떠난 뒤에도 계속 동작해야 하는 시나리오에 적합합니다. 사용자 토큰은 사용자를 대신해 동작하는 것이 유리하고 지속성이 크게 중요하지 않은 스크립팅 같은 임시 작업에 더 적합합니다.

## 계정 소유 토큰 만들기

:::note
계정 소유 토큰을 만들려면 해당 계정에 대한 Super Administrator 권한이 필요합니다.
:::

1. [Cloudflare 대시보드](https://dash.cloudflare.com)에 로그인합니다.
2. **Manage Account** > **Account API Tokens**로 이동합니다.
3. **Create Token**을 선택하고 토큰 이름, 권한, 선택 사항인 만료 날짜를 입력합니다.
4. **Continue to summary**를 선택하고 세부 정보를 검토합니다.
5. **Create Token**을 선택합니다.

또는 [account API token creation API](/api/resources/accounts/subresources/tokens/methods/create/)를 사용해 토큰을 만들 수 있습니다.

자세한 내용은 [블로그 게시물](https://blog.cloudflare.com/account-owned-tokens-automated-actions-zaraz/)을 참조하세요.

Origin CA 키는 [Origin CA certificates](/ssl/origin-configuration/origin-ca/) API와 상호작용할 때 헤더 `X-AUTH-USER-SERVICE-KEY` 값으로 자주 사용됩니다. 또한 [Keyless SSL](/ssl/keyless-ssl/) 키 서버에서도 사용됩니다.

:::note
**Permissions**에 `Zone`-`SSL and Certificates`-`Edit`를 포함한 [API 토큰](/fundamentals/api/get-started/create-token/)을 사용하여 [Origin CA certificates API](/ssl/origin-configuration/origin-ca/#api-calls)와 상호작용할 수도 있습니다.
:::

키 값은 항상 `v1.0-`으로 시작합니다.

## 제한 사항

* Origin CA 키 변경은 [Audit Logs](/fundamentals/account/account-security/review-audit-logs/)에 기록되지 않습니다.
* Origin CA 키를 볼 때마다 다른 값으로 표시됩니다. 이렇게 표시되는 서로 다른 값은 `Change` 버튼을 클릭하기 전까지는 모두 **동시에 유효**하며, `Change`를 클릭하면 이전에 생성된 모든 값이 즉시 무효화됩니다.
* Origin CA 키는 사용자가 접근할 수 있는 모든 계정에 대한 접근 권한을 가집니다.

## Origin CA 키 보기/변경

Origin CA 키를 가져오려면:

1. [Cloudflare 대시보드](https://dash.cloudflare.com)에 로그인합니다.

    <DashButton url="/?to=/:account/home" />

2. **User Profile** > **API Tokens**로 이동합니다.
3. **API Keys** 섹션에서 `Origin CA Key`를 선택합니다.

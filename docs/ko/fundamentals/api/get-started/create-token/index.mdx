1. 사용자 토큰을 사용할지 [계정 API 토큰](/fundamentals/api/get-started/account-owned-tokens/)을 사용할지 결정합니다. 사용자와 연결되지 않은 서비스 토큰을 원하고 [원하는 API 엔드포인트가 호환](/fundamentals/api/get-started/account-owned-tokens/#compatibility-matrix)된다면 계정 API 토큰을 사용하세요.
2. [Cloudflare 대시보드](https://dash.cloudflare.com/profile/api-tokens/)에서 사용자 토큰은 **My Profile** > **API Tokens**로 이동합니다. 계정 토큰은 **Manage Account** > **API Tokens**로 이동합니다.
3. **Create Token**을 선택합니다.
4. 사용 가능한 [API 토큰 템플릿](/fundamentals/api/reference/template/)에서 하나를 선택하거나 사용자 지정 토큰을 만듭니다. 다음 예시는 **Edit zone DNS** 템플릿을 사용합니다.
5. 토큰 이름을 추가하거나 수정하여 토큰의 사용 목적이나 방식을 설명합니다. 템플릿에는 토큰 이름과 권한이 미리 채워져 있습니다.

   ![Token template overview screen](~/assets/images/fundamentals/api/template-customize.png)

6. 토큰 권한을 수정합니다. 권한 그룹(`Account`, `User`, `Zone`)을 선택한 후 토큰에 부여할 접근 수준을 선택합니다. 대부분의 그룹은 `Edit` 또는 `Read` 옵션을 제공합니다. `Edit`는 전체 CRUDL(create, read, update, delete, list) 접근 권한이며, `Read`는 읽기 권한과 필요한 경우 목록 조회 권한입니다. 자세한 내용은 [사용 가능한 토큰 권한](/fundamentals/api/reference/permissions/)을 참조하세요.
7. 토큰이 접근하도록 허용할 리소스를 선택합니다. 예를 들어 zone `example.com`에 `Zone DNS Read` 접근을 부여하면, 해당 토큰은 그 특정 zone의 DNS 레코드만 읽을 수 있습니다. 다른 zone에 대해서는 DNS 레코드 읽기 작업 시 오류가 반환됩니다. 해당 zone의 다른 작업도 오류를 반환합니다.
8. (선택 사항) **Client IP Address Filtering** 및 **TTL (time to live)** 필드에서 토큰 사용 방식을 제한합니다.
9. **Continue to summary**를 선택합니다.
10. 토큰 요약을 검토합니다. 조정이 필요하면 **Edit token**을 선택합니다. 생성 후에도 토큰을 편집할 수 있습니다.

   ![Token summary screen displaying the resources and permissions selected](~/assets/images/fundamentals/api/token-summary.png)

11. **Create Token**을 선택해 토큰 시크릿을 생성합니다.
12. 시크릿을 안전한 장소에 복사해 보관합니다.

![Token creation completion screen displaying your API token and the curl command to test your token](~/assets/images/fundamentals/api/token-complete.png)

토큰 시크릿 페이지에는 토큰을 테스트하기 위한 예제 명령도 포함되어 있습니다. `/user/tokens/verify` 엔드포인트를 사용해 해당 토큰의 현재 상태를 가져오세요.

```bash
curl "https://api.cloudflare.com/client/v4/user/tokens/verify" \
--header "Authorization: Bearer <API_TOKEN>"
```

결과:

```json
{
  "result": {
    "id": "100bf38cc8393103870917dd535e0628",
    "status": "active"
  },
  "success": true,
  "errors": [],
  "messages": [
    {
      "code": 10000,
      "message": "This API Token is valid and active",
      "type": null
    }
  ]
}
```

이제 API 토큰을 성공적으로 만들었으며 Cloudflare API 작업을 시작할 수 있습니다. 첫 번째 API 토큰을 만든 후에는 [API를 통해](/fundamentals/api/how-to/create-via-api/) 추가 API 토큰을 만들 수 있습니다.

Global API key는 Cloudflare API와 상호작용하기 위한 이전 인증 방식입니다. 가능하면 Global API key 대신 [API 토큰](/fundamentals/api/get-started/create-token/)을 사용하세요.

:::note

Global API key는 [계정 이메일 주소가 인증된 후에만](/fundamentals/user-profiles/verify-email-address/) 사용할 수 있습니다.

:::

## 제한 사항

Global API key는 API 토큰과 비교했을 때 여러 제한 사항이 있습니다.

- **모든 Cloudflare 리소스에 대한 접근** - Global API key는 사용자의 모든 리소스에 접근할 수 있습니다. 이 때문에 사용자가 프로덕션 리소스에도 접근할 수 있는 경우, 비프로덕션 리소스에만 안전하게 Global API key를 사용하는 것이 불가능합니다.

- **전체 권한** - 마찬가지로 Global API key는 사용자와 정확히 동일한 권한을 가집니다. 즉 사용자가 zone을 삭제하거나 DNS 레코드를 변경할 수 있다면 Global API key도 그렇게 할 수 있습니다.

- **사용자당 하나로 제한** - 사용자당 하나의 Global API key만 발급할 수 있습니다. 이로 인해 API 접근용 시크릿을 롤링해야 하는 상황에서 두 개의 시크릿을 유지하는 것이 중요한 프로덕션 시스템에서 Cloudflare API를 사용하기가 복잡해집니다.

- **고급 사용 제한 부재** - API 토큰은 특정 시간 범위로 제한하거나 만료되게 설정할 수 있으며, 특정 IP 범위에서만 사용하도록 제한할 수도 있습니다.

이러한 이유로 신규 고객에게는 Global API key를 권장하지 않습니다. 현재 Global API key를 사용 중인 고객은 API 토큰으로 마이그레이션할 것을 권장합니다.

## Global API key 보기

Global API key를 가져오려면:

1. Cloudflare 대시보드에서 **User Profile** > **API Tokens**를 선택합니다.

    <DashButton url="/?to=/:account/api-tokens" />

2. **API Keys** 섹션에서 **Global API Key**의 `View` 버튼을 클릭합니다.

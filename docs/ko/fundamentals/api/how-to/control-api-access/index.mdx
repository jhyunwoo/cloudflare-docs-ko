Enterprise 계정의 최고 관리자는 API 접근 범위를 선택적으로 지정할 수 있습니다. API 접근은 전체 계정에 대해 제한하거나 특정 계정 멤버에 대해서만 제한할 수 있습니다.

이 기능은 Enterprise 계정과 관련 없는 API 호출까지 비활성화하지는 않는다는 점에 유의하세요.

## 계정 수준 접근 제어

전체 계정의 API 접근을 제한하려면:

1. Cloudflare 대시보드에서 **Members** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/members" />

2. **Enable API Access** 섹션을 찾아 설정을 업데이트합니다.

## 멤버 수준 접근 제어

:::note


멤버 수준 설정은 계정 수준 설정보다 우선합니다. 특정 멤버에게 API 접근이 활성화되어 있고 계정 전체에서는 접근이 비활성화되어 있더라도, 그 멤버는 Enterprise 계정과 관련된 API를 계속 호출할 수 있습니다.


:::

특정 멤버의 API 접근을 제한하려면:

1. Cloudflare 대시보드에서 **Members** 페이지로 이동합니다.

    <DashButton url="/?to=/:account/members" />

2. 멤버를 클릭해 확장한 다음 원하는 **API Access**를 선택합니다. `Account Default`이면 계정 수준 설정을 따릅니다.

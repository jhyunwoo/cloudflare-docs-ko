[API 토큰을 만든 후](/fundamentals/api/get-started/create-token/), 모든 API 요청은 동일한 방식으로 인증됩니다. Cloudflare는 [RFC 표준](https://tools.ietf.org/html/rfc6750#section-2.1) `Authorization: Bearer <API_TOKEN>` 인터페이스를 사용합니다. 예시 요청은 아래와 같습니다.

{/* <!-- The following example uses an invalid API key to demonstrate what those keys look like --> */}

```bash
curl "https://api.cloudflare.com/client/v4/zones/$ZONE_ID" \
--header "Authorization: Bearer YQSn-xWAQiiEh9qM58wZNnyQS7FUdoqGIUAbrh7T"
```

API 토큰 시크릿은 절대 평문으로 전송하거나 저장하지 마세요. 특히 공개 저장소를 포함한 코드 저장소에 커밋하지 않도록 주의하세요.

zone 또는 account ID와 인증 자격 증명(예: API 토큰)에 대해 [환경 변수](#environment-variables)를 정의하는 것을 고려하세요.

명령줄에서 JSON 출력을 읽기 쉽게 포맷하려면 명령줄 JSON 프로세서인 `jq` 같은 도구를 사용할 수 있습니다. `jq`를 다운로드하고 설치하는 방법은 [Download jq](https://stedolan.github.io/jq/download/)를 참조하세요.

다음 예시는 `jq`를 사용해 curl의 JSON 출력을 포맷합니다.

```bash
curl "https://api.cloudflare.com/client/v4/zones/$ZONE_ID" \
--header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" | jq .
```

## Cloudflare API 사용

모든 Cloudflare API 요소는 버전 번호에 고정되어 있습니다. 최신 버전은 Version 4입니다. 모든 Version 4 HTTPS 엔드포인트의 안정적인 기본 URL은 `https://api.cloudflare.com/client/v4/`입니다.

API 호출에 대한 구체적인 지침은 다음 리소스를 참조하세요.

- 사용 방법 가이드는 제품의 [Developer Docs 섹션](/directory/)을 참조하세요.
- 각 엔드포인트의 요청 및 응답 페이로드는 [API schema docs](/api/)를 참조하세요.
- [Go](https://github.com/cloudflare/cloudflare-go), [TypeScript](https://github.com/cloudflare/cloudflare-typescript), [Python](https://github.com/cloudflare/cloudflare-python), [HashiCorp Terraform](https://github.com/cloudflare/terraform-provider-cloudflare)용 퍼스트파티 라이브러리도 사용할 수 있습니다.

## 쿼리 매개변수

[List Zones](/api/resources/zones/methods/list/)처럼 일부 Cloudflare 엔드포인트에는 결과를 필터링하는 선택적 쿼리 매개변수가 있습니다.

이러한 쿼리 매개변수를 추가할 때는 헤더 값과 마찬가지로 URL을 큰따옴표 `""`로 감싸야 합니다. 그렇지 않으면 API 호출에서 오류가 발생할 수 있습니다.

```bash '"'
curl "https://api.cloudflare.com/client/v4/zones?account.id=$ACCOUNT_ID" \
--header "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

문자열은 작은따옴표(`''`) 또는 큰따옴표(`""`)로 감쌀 수 있습니다. 다만 작은따옴표를 사용하면 `bash` 같은 셸에서 변수 치환이 이루어지지 않습니다. 앞선 예시에서는 `$ACCOUNT_ID`와 `$CLOUDFLARE_API_TOKEN` [환경 변수](#environment-variables)가 값으로 대체되지 않는다는 뜻입니다.

### 페이지네이션

기본 페이지 크기로는 결과가 너무 많아 모두 표시할 수 없는 경우가 있습니다. 예를 들어 다음과 같은 응답을 받을 수 있습니다.

```txt
"count": 1,
"page": 1,
"per_page": 20,
"total_count": 200,
```

결과를 여러 페이지로 나누기 위해 조합해서 사용할 수 있는 쿼리 매개변수 옵션이 두 가지 있습니다.

- `page=x`는 특정 페이지를 선택합니다.
- `per_page=xx`는 한 페이지에 표시할 결과 수를 조정합니다. 너무 많이 선택하면 타임아웃이 발생할 수 있습니다.

예를 들어 `https://api.cloudflare.com/client/v4/zones/$ZONE_ID/dns_records?per_page=100&page=2` 같은 형식입니다.

그 밖의 옵션은 다음과 같습니다.

- `order`: 정렬 기준 속성을 선택합니다.
- `direction`: `ASC`(오름차순) 또는 `DESC`(내림차순) 중 하나입니다.

사용 가능한 옵션은 [API documentation](/api/)의 각 엔드포인트 `result_info` 끝부분에 나열되어 있습니다.

## Windows에서 API 호출하기

최신 Windows 10 및 11 버전에는 개발자 문서의 API 예시에서 사용하는 [curl 도구가 이미 포함되어 있습니다](https://curl.se/windows/microsoft.html). 다른 Windows 버전을 사용 중이라면 curl 도구를 얻고 설치하는 방법에 대한 자세한 내용은 curl 웹사이트의 [Windows downloads](https://curl.se/windows/)를 참조하세요.

### Command Prompt 창 사용

Command Prompt 창에서 curl로 Cloudflare API를 사용하려면 문자열 구분자로 큰따옴표(`"`)를 사용해야 합니다.

일반적인 `PATCH` 요청은 다음과 비슷합니다.

```txt
C:\>curl --request PATCH "https://api.cloudflare.com/client/v4/user/invites/{id}" --header "X-Auth-Email: <EMAIL>" --header "X-Auth-Key: <API_KEY>" --data "{""status"": ""accepted""}"
```

요청 본문(`POST`/`PATCH` 요청의 `-d` 또는 `--data`)에서 큰따옴표 문자를 이스케이프하려면 다른 큰따옴표(`"`) 또는 백슬래시(`\`)를 앞에 붙이세요.

한 명령을 여러 줄로 나누려면 줄 끝에 `^`를 줄 연속 문자로 사용하세요.

```txt
C:\>curl --request PATCH ^
"https://api.cloudflare.com/client/v4/user/invites/{id}" ^
--header "X-Auth-Email: <EMAIL>" ^
--header "X-Auth-Key: <API_KEY>" ^
--data "{""status"": ""accepted""}"
```

### PowerShell 사용

:::note

Cloudflare는 가능한 한 최신 안정 버전 또는 미리 보기 버전의 PowerShell 사용을 권장합니다. 자세한 내용은 [Installing PowerShell on Windows](https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell-on-windows)를 참조하세요.
:::

PowerShell에는 REST API 호출과 JSON 응답 처리를 위한 전용 cmdlet(`Invoke-RestMethod`, `ConvertFrom-Json`)이 있습니다. 이 cmdlet의 구문은 개발자 문서에 제공된 curl 예시와 다릅니다.

다음 예시는 `Invoke-RestMethod` cmdlet을 사용합니다.

```powershell
Invoke-RestMethod -URI "https://api.cloudflare.com/client/v4/zones/$Env:ZONE_ID/ssl/certificate_packs?ssl_status=all" -Method 'GET' -Headers @{'X-Auth-Email'=$Env:CLOUDFLARE_EMAIL;'X-Auth-Key'=$Env:CLOUDFLARE_API_KEY}
```

```txt output
result      : {@{id=78411cfa-5727-4dc1-8d4a-773d01f17c7c; type=universal; hosts=System.Object[];
              primary_certificate=c173c8a1-9724-4e96-a748-2c4494186098; status=active; certificates=System.Object[];
              created_on=2022-12-09T23:11:06.010263Z; validity_days=90; validation_method=txt;
              certificate_authority=lets_encrypt}}
result_info : @{page=1; per_page=20; total_pages=1; count=1; total_count=1}
success     : True
errors      : {}
messages    : {}
```

이 명령은 `ZONE_ID`, `CLOUDFLARE_EMAIL`, `CLOUDFLARE_API_KEY` 환경 변수가 미리 정의되어 있다고 가정합니다. 자세한 내용은 [환경 변수](#environment-variables)를 참조하세요.

기본적으로 출력에는 JSON 객체 계층 구조의 첫 번째 수준만 포함됩니다. 위 예시에서는 `hosts`, `certificates` 같은 객체 내부 내용이 표시되지 않습니다. `jq` 도구처럼 더 많은 수준을 표시하고 출력을 포맷하려면 원하는 최대 깊이(기본값 `2`)를 지정해 `ConvertTo-Json` cmdlet을 사용할 수 있습니다.

```powershell
Invoke-RestMethod -URI "https://api.cloudflare.com/client/v4/zones/$Env:ZONE_ID/ssl/certificate_packs?ssl_status=all" -Method 'GET' -Headers @{'X-Auth-Email'=$Env:CLOUDFLARE_EMAIL;'X-Auth-Key'=$Env:CLOUDFLARE_API_KEY} | ConvertTo-Json -Depth 5
```

:::caution[ConvertFrom-Json의 DateTime 값 처리]

`ConvertTo-Json` cmdlet은 타임스탬프 형식 문자열을 문자열의 정확한 형식에 따라 DateTime 값으로 변환하려고 시도합니다. 이 동작에 대한 자세한 내용은 [ConvertFrom-Json](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.utility/convertfrom-json#notes) 문서의 참고 사항을 확인하세요.
:::

PowerShell에서도 curl 도구를 사용할 수 있습니다. 그러나 PowerShell에서 `curl`은 `Invoke-WebRequest` cmdlet의 별칭이며, 일반적인 curl 도구와 다른 구문을 지원합니다. curl을 사용하려면 대신 `curl.exe`를 입력하세요.

일반적인 curl `PATCH` 요청은 다음과 비슷합니다.

```powershell
curl.exe --request PATCH "https://api.cloudflare.com/client/v4/user/invites/{id}" --header "Authorization: Bearer $Env:CLOUDFLARE_API_TOKEN" --data '{\"status\": \"accepted\"}'
```

요청 본문(`-d` 또는 `--data`)에서 큰따옴표(`"`) 문자를 이스케이프하려면 다른 큰따옴표(`"`) 또는 백슬래시(`\`)를 앞에 붙이세요. 문자열 구분자로 작은따옴표(`'`)를 사용하더라도 큰따옴표는 반드시 이스케이프해야 합니다.

한 명령을 여러 줄로 나누려면 줄 끝에 백틱 문자(`` ` ``)를 줄 연속 문자로 사용하세요.

```powershell
curl.exe --request PATCH `
"https://api.cloudflare.com/client/v4/user/invites/{id}" `
--header "X-Auth-Email: $Env:CLOUDFLARE_EMAIL" `
--header "X-Auth-Key: $Env:CLOUDFLARE_API_KEY" `
--data '{\"status\": \"accepted\"}'
```

## 환경 변수

zone 또는 account ID처럼 명령 간에 반복되는 값에 대해 환경 변수를 정의할 수 있습니다. 환경 변수의 수명은 현재 셸 세션, 현재 사용자의 향후 모든 세션, 또는 심지어 해당 머신의 모든 사용자의 향후 세션까지가 될 수 있습니다.

인증 자격 증명(API 토큰, API 키, 이메일)을 보관하고 여러 명령에서 재사용하기 위해 환경 변수를 사용할 수도 있습니다. 다만 이러한 값은 가능한 한 가장 좁은 범위(현재 셸 세션만 또는 현재 사용자의 새 세션만)에 정의하세요.

환경 변수를 설정하고 참조하는 절차는 플랫폼과 셸에 따라 다릅니다.

### 환경 변수 정의

<Tabs syncKey="LinuxPowershellCmd"> <TabItem label="Linux and macOS">

현재 셸 세션에 대한 `ZONE_ID` 환경 변수를 정의하려면 다음 명령을 실행하세요.

```sh
export ZONE_ID='f2ea6707005a4da1af1b431202e96ac5'
```

현재 사용자의 모든 새 셸 세션에 대해 변수를 정의하려면 위 명령을 셸 구성 파일 끝부분에 추가하세요. 예를 들어 `bash` 셸은 `~/.bashrc`, `zsh` 셸은 `~/.zshrc`입니다.

</TabItem> <TabItem label="PowerShell">

현재 PowerShell 세션에 대한 `ZONE_ID` 환경 변수를 정의하려면 다음 명령을 실행하세요.

```powershell
$Env:ZONE_ID='f2ea6707005a4da1af1b431202e96ac5'
```

현재 사용자의 모든 새 PowerShell 세션에 대해 환경 변수를 정의하려면 PowerShell 프로필에 변수를 설정하세요. PowerShell 프로필 경로는 `echo $PROFILE`을 실행해 확인할 수 있습니다.

또는 `System.Environment` 클래스의 `SetEnvironmentVariable()` 메서드를 사용해 현재 사용자의 모든 새 PowerShell 세션에 대한 변수를 설정할 수 있습니다. 예:

```powershell
[Environment]::SetEnvironmentVariable("ZONE_ID", "f2ea6707005a4da1af1b431202e96ac5", "User")
```

이 명령은 현재 세션에는 영향을 주지 않습니다. PowerShell 세션을 닫고 새로 시작해야 합니다.

</TabItem> <TabItem label="Windows Command Prompt">

현재 Command Prompt 세션에 대한 `ZONE_ID` 환경 변수를 정의하려면 다음 명령을 실행하세요.

```txt frame="terminal"
set ZONE_ID=f2ea6707005a4da1af1b431202e96ac5
```

현재 사용자의 향후 모든 Command Prompt 세션에 대한 환경 변수를 정의하려면 다음 명령을 실행하세요.

```txt frame="terminal"
setx ZONE_ID f2ea6707005a4da1af1b431202e96ac5
```

이 명령은 현재 창에는 영향을 주지 않습니다. `set` 명령을 다시 실행하거나 Command Prompt 창을 닫았다가 새로 열어야 합니다.

</TabItem> </Tabs>

### 환경 변수 참조

<Tabs syncKey="LinuxPowershellCmd"> <TabItem label="Linux and macOS">

명령에서 환경 변수를 참조할 때는 변수 이름 앞에 `$` 접두사를 붙입니다(예: `$ZONE_ID`). 변수를 참조하는 전체 문자열은 따옴표 없이 사용하거나, 공백이 포함된 경우 큰따옴표(`""`)로 감싸야 합니다.

예:

```sh
curl "https://api.cloudflare.com/client/v4/zones/$ZONE_ID" \
--header "Authorization: Bearer $CLOUDFLARE_API_TOKEN"
```

</TabItem> <TabItem label="PowerShell">

명령에서 환경 변수를 참조할 때는 변수 이름 앞에 `$Env:` 접두사를 붙입니다(예: `$Env:ZONE_ID`). 변수를 참조하는 전체 문자열은 따옴표 없이 사용하거나 큰따옴표(`""`)로 감쌉니다.

예:

```powershell
Invoke-RestMethod -URI "https://api.cloudflare.com/client/v4/zones/$Env:ZONE_ID" -Method 'GET' -Headers @{'Authorization'="Bearer $Env:CLOUDFLARE_API_TOKEN"}
```

</TabItem> <TabItem label="Windows Command Prompt">

명령에서 환경 변수를 참조할 때는 변수 이름을 `%` 문자로 감쌉니다(예: `%ZONE_ID%`).

예:

```txt frame="terminal"
curl "https://api.cloudflare.com/client/v4/zones/%ZONE_ID%" --header "Authorization: Bearer %CLOUDFLARE_API_TOKEN%"
```

</TabItem> </Tabs>

API 토큰은 런타임에 두 가지 방식으로 제한할 수 있습니다.

* [클라이언트 IP 주소 범위 필터링](#client-ip-address-range-filtering)
* [Time To Live (TTL) 제약](#time-to-live-ttl-constraints)

## 클라이언트 IP 주소 범위 필터링

클라이언트 IP 주소 제한은 어떤 IP 주소가 이 토큰으로 API 요청을 보낼 수 있는지 제어합니다. 기본적으로 필터링을 적용하지 않으면 모든 IP 주소가 토큰을 사용할 수 있습니다. `Is in` 규칙을 적용하면 정의된 IP 주소에서만 토큰을 사용할 수 있습니다. 범위는 [CIDR 표기법](https://en.wikipedia.org/wiki/Classless_Inter-Domain_Routing#CIDR_notation)으로 정의하세요. 예외를 둔 상태로 IP 범위를 허용하려면 `Is not in`을 정의해 특정 IP 또는 더 작은 범위를 제외하세요.

![IP Address filtering options](~/assets/images/fundamentals/api/ip-filter.png)

:::note

클라이언트 IP 주소 범위 필터링은 [Verify Token](https://developers.cloudflare.com/api/resources/user/subresources/tokens/methods/verify/) 엔드포인트에는 적용되지 않습니다.

:::


## Time to live (TTL) 제약

기본적으로 토큰은 만료되지 않으며 오래 유지됩니다. TTL을 정의하면 토큰이 유효해지기 시작하는 시점과 더 이상 유효하지 않게 되는 시점을 설정합니다. 이를 흔히 `notBefore`와 `notAfter`라고 부릅니다. 이 타임스탬프를 설정하면 토큰 수명이 정의된 기간으로 제한됩니다. 시작 날짜 또는 `notBefore`를 설정하지 않으면 토큰은 생성되는 즉시 활성화됩니다. 종료 날짜 또는 `notAfter`를 설정하지 않으면 토큰은 만료되지 않습니다.

:::note


선택한 날짜는 해당 날짜의 00:00 UTC로 정의됩니다. 더 세밀한 시간 선택이 필요하면 [API](/fundamentals/api/)를 사용하세요.


:::

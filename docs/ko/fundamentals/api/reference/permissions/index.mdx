권한은 리소스를 기준으로 세 가지 범주로 나뉩니다.

- Zone 권한
- Account 권한
- User 권한

각 범주에는 해당 리소스와 관련된 권한 그룹이 포함됩니다. DNS 권한은 Zone 범주에 속하고, Billing 권한은 Account 범주에 속합니다. 아래는 사용 가능한 토큰 권한 목록입니다.

권한 ID와 각 권한의 범위를 포함한 최신 토큰 권한 목록을 얻으려면 [List permission groups](/api/resources/user/subresources/tokens/subresources/permission_groups/methods/list/) 엔드포인트를 사용하세요.

## User 권한

User 권한에 적용되는 범위는 `com.cloudflare.api.user`입니다.

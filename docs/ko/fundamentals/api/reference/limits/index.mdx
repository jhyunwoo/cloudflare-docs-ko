## 속도 제한 헤더

REST API를 호출하면 다음 헤더가 반환됩니다.

- `Ratelimit`: 제한 이름, 남은 할당량(`r`), 다음 윈도우가 재설정되는 시간(`t`)으로 구성된 서비스 제한 항목 목록입니다. 예: `"default";r=50;t=30`
- `Ratelimit-Policy`: 정책 이름, 전체 할당량(`q`), 할당량이 적용되는 시간 창(`w`)으로 구성된 할당량 정책 항목 목록입니다. 예: `"burst";q=100;w=60`
- `retry-after`: 더 많은 용량을 사용할 수 있게 될 때까지의 초 수를 올림해 나타냅니다. 이 헤더는 요청이 속도 제한을 초과했을 때만 반환됩니다.

[Cloudflare SDK](/fundamentals/api/reference/sdks/)도 이 헤더를 자동으로 처리하고 속도 제한에 대응해 백오프합니다.

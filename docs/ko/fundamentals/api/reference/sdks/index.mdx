Cloudflare는 Cloudflare API 사용 방법을 보여 주기 위해 언어별 소프트웨어 개발 키트(SDK)와 `curl` 예제를 제공합니다. SDK 라이브러리를 사용하면 언어별 구문으로 Cloudflare API와 상호작용할 수 있고 기존 애플리케이션과 더 쉽게 통합할 수 있습니다.

현재 Cloudflare는 다음 SDK를 제공합니다.

- [Go](https://github.com/cloudflare/cloudflare-go)
- [TypeScript](https://github.com/cloudflare/cloudflare-typescript)
- [Python](https://github.com/cloudflare/cloudflare-python)

## cURL과 SDK 중 언제 사용할까

어느 쪽을 사용해야 하는지에 대한 단정적인 답은 없습니다. 대신 사용 사례를 고려해 cURL 또는 SDK 중 무엇이 더 적합한지 판단하세요.

| 사용 사례                                                  | cURL | SDK  |
| --------------------------------------------------------- | ---- | ---- |
| CLI에서 빠르게 테스트                                     | ✅   | ❌   |
| bash 스크립트 또는 CI 내에서 사용                         | ✅   | ❌\* |
| 기존 애플리케이션 또는 프레임워크 내부에서 사용           | ❌   | ✅   |
| 출력을 서로 연결해야 하는 더 복잡한 사용 사례             | ❌   | ✅   |

\* 추가 런타임 의존성과 설정이 필요하지만, bash 스크립트나 CI 환경에서 SDK를 사용하는 것도 가능합니다.

## 예시

다음은 접근 권한이 있는 Cloudflare zone을 모두 조회하는 예시입니다.

### cURL 사용:

```bash
curl "https://api.cloudflare.com/client/v4/zones" \
--header "Authorization: Bearer <API_TOKEN>"
```

### TypeScript SDK 사용:

```js
const client = new Cloudflare({
	apiToken: process.env["CLOUDFLARE_API_TOKEN"],
});

const zones = await client.zones.list();

console.log(zones);
```

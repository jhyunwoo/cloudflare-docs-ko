## 토큰이 검증되지 않음

다음 `curl` 명령을 실행하고 응답에 `"status": "active"`가 반환되는지 확인하여 토큰이 검증되었는지 확인하세요.

```bash
curl "https://api.cloudflare.com/client/v4/user/tokens/verify" \
--header "Authorization: Bearer <API_TOKEN>"
```

```json
{
  "success": true,
  "errors": [],
  "messages": [],
  "result": {
    "id": "f267e341f3dd4697bd3b9f71dd96247f",
    "status": "active",
    "not_before": "2018-07-01T05:20:00Z",
    "expires_on": "2020-01-01T00:00:00Z"
  }
}
```

## 토큰 권한이 올바르지 않음

[Cloudflare 대시보드](https://dash.cloudflare.com/profile/api-tokens)에서 토큰의 권한 그룹을 검토하세요. 자세한 내용은 [API 토큰 권한](/fundamentals/api/reference/permissions/)을 참조하세요.

## 잘못된 문법을 사용함

가끔 고객이 API 키 문법으로 API 토큰을 사용하려고 시도합니다. 이메일과 API 키 쌍이 아니라 Bearer 옵션을 사용하고 있는지 확인하세요.

## 사용자 권한이 올바르지 않음

계정에서 부여된 권한을 초과하는 토큰은 만들 수 없습니다. 예를 들어 **Admin (Read only)** 역할만 부여되어 있다면, 직접 토큰을 만들 수 있도록 최고 관리자(Super Administrator)가 역할을 업데이트해야 합니다.

Cloudflare는 패킷 캡처의 두 가지 유형을 지원합니다: 전체 및 샘플. 전체 패킷 캡처는 기본 동작입니다.

:::참조
최대 패킷 캡처 런타임은 샘플과 풀 패킷 캡처를위한 24 시간입니다.
주요 특징

## 샘플 패킷 캡처

샘플 패킷 캡처는 Cloudflare의 네트워크를 통해 이미 통과 한 네트워크 트래픽에 역사적인 데이터를 수집합니다. 패킷 캡처가 시작된 후 Cloudflare의 네트워크로 전송된 새로운 트래픽을 수집하지 않습니다. 모든 샘플 패킷 캡처는 역사적인 트래픽 데이터를 쿼리하기 때문에 시작된 후 즉시 완료됩니다.

샘플 패킷 캡처는 Cloudflare 대시보드에서 볼 수 있습니다. 그들은 단지 데이터의 첫 160 바이트를 포함한다. 이것은 패킷 헤더를 캡처하는 데 유용하지만 상세한 패킷 데이터를 제공하지 않습니다. 샘플 데이터는 모든 Cloudflare의 데이터 센터를 통해 PCAP 파일을 구축합니다. 모든 데이터 센터의 전 세계 트래픽을 얻을 수 있습니다.

네트워크가 덜 자주 통과하는 패킷에 데이터를 수집해야하는 경우 전체 패킷 캡처를 사용해야합니다.

## 전체 패킷 캡처

Full 패킷 캡처는 Cloudflare의 선택된 필터와 일치하는 패킷 데이터를 캡처합니다. 일치하는 패킷 데이터는 클라우드 스토리지 버킷에 저장되며, 소유하고 구성합니다.

전체 패킷 캡처는 패킷 캡처가 시작된 후 Cloudflare의 네트워크로 전송된 새로운 트래픽을 수집하고 전체 패킷 데이터를 포함합니다. 캡처의이 유형은 Cloudflare 대시보드에서 볼 수 없습니다. 클라우드 스토리지 버킷에서 다운로드하고 Wireshark 또는 다른 패킷 캡처 도구에서 분석 할 수 있습니다.

이 섹션의 기사를 참조하여 패킷 캡처를 사용하는 방법을 배우십시오.

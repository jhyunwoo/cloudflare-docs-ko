시작하기 전에<GlossaryTooltip term="data packet">제품정보</GlossaryTooltip>캡처, 먼저 Cloudflare가 파일을 업로드 할 수 있도록 물통을 구성해야합니다. 버킷 설정은 샘플 패킷 캡처에 필요하지 않습니다.

Amazon S3 또는 Google Cloud Platform Bucket을 구성할 수 있습니다. 당신은 또한 할 수 있습니다[R2 사용](#r2)API를 사용하여 대상입니다.

## 버킷 설정

전체 패킷 캡처와 함께 사용할 물통을 설정하는 방법을 알아보세요.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com)대시보드, 이동**네트워크 가시성** > **진단**.
    2. 선택하기**기타 제품**탭 >**버킷 추가**.
    3. 버킷 서비스 선택 및 선택**이름 \***.
    4. 귀하의 서비스 제공 업체에 대한 귀하의 물통과 관련된 정보를 입력하십시오.
    5. 당신이 할 때, 선택**이름 \***.

    더 보기**Prove 소유권**단계의**물통 윤곽**전시.
  </TabItem>

  <TabItem label="사이트맵">
    물통을 사용하기 전에 먼저 목적지를 활성화해야합니다.

    더 알아보기[아마존 S3](/logs/logpush/logpush-job/enable-destinations/aws-s3/#create-and-get-access-to-an-s3-bucket)또는[Google 클라우드 스토리지](/logs/logpush/logpush-job/enable-destinations/google-cloud-storage/#create-and-get-access-to-a-gcs-bucket)문서 및 그 특정 서비스에 대한 단계를 따르십시오.
  </TabItem>
</Tabs>

Next, 버킷을 검증하고 소유권을 확인합니다.

## 버킷 검증

초기 버킷 설정 후, 소유권 도전을 통해 버킷을 직접 확인해야합니다. 물통을 유효하게 한 후, 전체 패킷 캡처를 수집하기 위해 사용하기 시작할 수 있습니다.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    1. 에 의해**Prove 소유권**단계의**물통 윤곽**, 위치**소유권 토큰**이름 \*
    2. 내 계정**소유권 토큰**필드, 귀하의 서비스 공급자를위한 소유권 토큰을 입력하십시오.
    3. 당신이 할 때, 선택**이름 \***·**Packet 캡처**페이지 표시.

    더 보기**기타 제품**탭은 계정과 관련된 물통 목록을 표시합니다. 더 알아보기**주요연혁**당신의 물통 윤곽의 상태를 볼.
  </TabItem>

  <TabItem label="사이트맵">
    더 보기`bucket`필드는 물통의 URI이어야한다. 아마존 S3의 경우`bucket`필드는 형태로`s3://<bucket-name>/<directory>?region=<bucket-region>`, Google Cloud Storage의 경우 양식은`gs://<bucket-name>/<directory>`.

    ```bash title="Ownership challenge request example"
    curl https://api.cloudflare.com/client/v4/accounts/{account_id}/pcaps/ownership \
    --header "X-Auth-Email: <EMAIL>" \
    --header "X-Auth-Key: <API_KEY>" \
    --header "Content-Type: application/json" \
    --data '{
      "destination_conf": "'${bucket}'"
    }'
    ```

    응답은 있다`"filename"`매개 변수의 내용을 포함`ownership-challenge`이름 \* 당신의 물통에 있는 파일을 찾아서 파일의 내용을 복사하십시오.

    ```json title="Ownership challenge response example"
    {
    	"result": {
    		"id": "cc20c2d6c62e11ecbe646b173af3b6b9",
    		"status": "pending",
    		"submitted": "2022-04-22T18:54:13.397413Z",
    		"validated": "",
    		"destination_conf": "gs://bucket-test", // Ensure you use a bucket that you created and registered in the Cloudflare dashboard.
    		"filename": "ownership-challenge-1234.txt"
    	},
    	"success": true,
    	"errors": [],
    	"messages": []
    }
    ```

    복사 된 텍스트를 삽입하여 버킷을 유효`ownership_text`아래에:

    ```bash title="Bucket validation example"
    curl https://api.cloudflare.com/client/v4/accounts/{account_id}/pcaps/ownership/validate \
    --header "X-Auth-Email: <EMAIL>" \
    --header "X-Auth-Key: <API_KEY>" \
    --header "Content-Type: application/json" \
    --data '{
      "destination_conf": "'${bucket}'",
      "ownership_challenge": "'${ownership_text}'"
    }'
    ```

    ```json title="Bucket validation response"
    {
    	"result": {
    		"id": "cc20c2d6c62e11ecbe646b173af3b6b9",
    		"status": "success",
    		"submitted": "2022-04-22T18:54:13.397413Z",
    		"validated": "2022-04-27T14:54:46.440548Z",
    		"destination_conf": "gs://<bucket-name>", // Ensure you use a bucket that you created and registered in the Cloudflare dashboard
    		"filename": "ownership-challenge-1234.txt"
    	},
    	"success": true,
    	"errors": [],
    	"messages": []
    }
    ```

    만약에`status`제품 설명`success`, 물통은 형성되고 사용하게 준비되어 있습니다.
  </TabItem>
</Tabs>

물통 상태는 뒤에 오는 선택권의 한을 표시합니다:

- **성공:**&#xBB3C;통은 완전히 확인되고 사용하게 준비되어 있습니다.
- **종료:**&#xB3C4;전 응답이 시작되었지만 검증을 종료했습니다. 물통 검증은 처리 완료하기 위하여 5 10 분을 가지고 갈 수 있습니다.
- **실패:**&#xBB3C;통은 유효하지 않을 수 있었습니다. 이 발생하면 소유권 정보를 확인합니다.

## 사이트맵

R2로 패킷 캡처를 수집하려면 먼저 구성해야 합니다. 필요한 모든 세부 사항은 참조[Cloudflare R2](/r2/)문서.

### 버킷 및 API 토큰 만들기

1. Cloudflare 하나 대시보드에서, 이동**사이트맵**사이트 맵

   <DashButton url="/?to=/:account/r2/overview" />

2. 제품정보**버킷 만들기**.

3. 당신의 물통을 이름 >**버킷 만들기**.

4. R2 개요 페이지로 이동하여 선택**R2 API 관리 토큰 토큰**.

5. 제품정보**API 만들기 토큰 토큰**.

6. 내 계정**제출**, 선택**개체 읽기 및 쓰기**. 당신이 또한 선택 확인**특정 버킷에만 적용**, 그리고 당신은 드롭다운 메뉴에서 PCAPs를 위해 창조한 물통을 선정하십시오.

7. 제품정보**API 만들기 토큰 토큰**.

8. 자주 묻는 질문**비밀 액세스 키**·**액세스 키 ID**값, 다음 단계에 대해해야합니다.

### 초기 요청

R2에 대한 초기 요청 만들기:

```bash
curl https://api.cloudflare.com/client/v4/accounts/{account_id}/pcaps/ownership \
--header "X-Auth-Email: <EMAIL>" \
--header "X-Auth-Key: <API_KEY>" \
--header "Content-Type: application/json" \
--data '{
  "destination_conf": "r2://<BUCKET_NAME>?account-id=<ACCOUNT_ID>&access-key-id=<R2_ACCESS_KEY_ID>&secret-access-key=<R2_SECRET_ACCESS_KEY>"
}'
```

더 보기[이름 \*](/api/resources/magic_transit/subresources/pcaps/subresources/ownership/methods/create/)한국어`"filename"`Cloudflare가 R2 버킷에 썼는 파일의 이름을 가진 모수. 다음 단계에 다운로드해야합니다. 예:

```json
{
	"errors": [],
	"messages": [],
	"result": {
		"destination_conf": "<YOUR_R2_BUCKET>",
		"filename": "ownership-challenge-9883874ecac311ec8475433579a6bf5f.txt",
		"id": "9883874ecac311ec8475433579a6bf5f",
		"status": "success",
		"submitted": "2020-01-01T08:00:00Z",
		"validated": "2020-01-01T08:00:00Z"
	},
	"success": true
}
```

### Validate 물통 소유권

더 알아보기[버킷 검증](#validate-a-bucket)전체 과정에 대한 자세한 내용은 API 지침[R2 버킷을 유효](/api/resources/magic_transit/subresources/pcaps/subresources/ownership/methods/validate/). 이 검증을 위한 R2 목적지를 지정할 때, URL에서 비밀과 액세스 키 제외.

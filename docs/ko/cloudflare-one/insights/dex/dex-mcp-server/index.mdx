MCP 서버[(모델 Context 프로토콜)](https://cloudflare.com/learning/ai/what-is-model-context-protocol-mcp/)Digital Experience Monitoring (DEX)는 고객이 같은 질문을 요청할 수있는 AI 도구입니다. "carly @acme.com에 의해 사용되는 장치에 대한 연결성 및 성능 지표를 표시하고 DEX API에서 데이터를 포함하는 답변을받습니다.

모든 Cloudflare Free, PayGo 또는 Enterprise 계정을 사용하는 고객은 DEX MCP Server에 액세스할 수 있습니다. 이 기능은 모두 가능합니다.

DEX MCP 서버에 연결하기위한 두 가지 기본 옵션이 있습니다.

- [Cloudflare의 AI 놀이터에서](#cloudflare-ai-playground)
- [당신의 선호된 AI 조수로](#ai-assistant)

## Cloudflare AI 놀이터

Cloudflare의 AI 놀이터는 새로운 MCP 서버를 빠르게 시도하는 훌륭한 방법입니다.

AI 놀이터 웹 사이트를 방문하여 DEX MCP 서버를 1 분 미만으로 테스트 할 수 있습니다.

1. DEX MCP 서버의 URL 복사:`https://dex.mcp.cloudflare.com/mcp`.
2. 기타[놀이터.ai.cloudflare.com](https://playground.ai.cloudflare.com)브라우저에서.
3. 왼쪽 사이드바 제목의 섹션을 찾아**MCP 서버**.
4. DEX MCP 서버의 URL을 URL 입력 상자에 붙여넣고 선택**연결하기**.
5. Cloudflare 계정을 인증하고 DEX 데이터에 대한 질문을 시작합니다.

:::참조
응답을 얻기 위해 특정하고 명시된 질문을해야합니다. 예를 들어, 첫 번째는 다음과 같은 명령어를 제공해야합니다: "설정 XYZ 활성 계정으로". 그런 다음 특정 질문을 할 수 있습니다 : " 과거 24 시간 동안 사용자 bob@ acme.com에 대한 DEX 테스트 결과를 봅니다.

## AI 보조

고객은 선호하는 AI 조수 (예를 들어, Claude, Gemini 또는 ChatGPT)를 사용하여 DEX MCP 서버를 구성하여 더 유연하고 강력한 신속한 경험을 얻을 수 있습니다.

구성 과정에서 문제가 있으면 URL을 통해 MCP 서버를 구성하는 데 도움이되는 AI Assistant를 요청할 수 있습니다.

### 이름 \*

MCP 서버를 구성하기 위해 Claude Pro 계정 (또는 더 높은 구독)이 필요합니다.

1. 다운로드[Claude 데스크탑 클라이언트](https://claude.ai/download).

2. Claude 데스크톱 클라이언트를 열고 로그인하거나 계정을 설정하십시오.

3. 왼쪽 사이드바 메뉴를 확장하고, 선택**Claude 코드**.

4. 이름 \***데스크탑 앱**, 선택**주요 특징**더 보기**로컬 MCP 서버**사이트 맵

5. 제품정보**Config 편집**그리고 열다`claude_desktop_config.json`선택의 텍스트 편집기에 파일.

6. DEX MCP 서버의 JSON 구성을 복사하고 붙여넣기`claude_desktop_config.json`. 파일 저장.

   ```json
   {
   	"globalShortcut": "",
   	"mcpServers": {
   		"cloudflare-dex-analysis": {
   			"command": "npx",
   			"args": ["mcp-remote", "https://dex.mcp.cloudflare.com/mcp"]
   		}
   	}
   }
   ```

7. 작업 관리자를 사용하여 Claude를 완전히 닫고 Claude와 관련된 배경 프로세스를 중지합니다.

8. Open Claude 및 DEX MCP 서버 구성은**로컬 MCP 서버**사이트 맵

9. Cloudflare 계정을 인증하고 DEX MCP 서버를 허용합니다.

10. DEX에 대한 Claude 질문을 할 수 있습니다. 간단한 테스트로, "DEX MCP 서버에 연결됩니다.

### Gemini 클립

Google AI Free, Pro 및 Ultra의 모든 계층은 Gemini CLI를 통해 MCP 서버 통합을 제공합니다.

선택과 npm 또는 homebrew의 CLI를 사용하여 Gemini CLI를 설치하고 액세스해야합니다.

{/* prettier-ignore-start */}

1. GitHub 페이지 방문하기[Gemini 클립](https://github.com/google-gemini/gemini-cli)그리고 임명 지시를 따르십시오.

2. 탐색하기`settings.json`Gemini CLI에 대한 파일 설치 및 선택의 텍스트 편집기에서 엽니 다.

   <details>
     <summary>파일 경로`settings.json`이름 \*</summary>

     - 윈도우:`%USERPROFILE%\.gemini\settings.json`
     - 맥과 리눅스:`~/.gemini/settings.json`
   </details>

3. DEX MCP 서버의 JSON 구성을 복사하고 붙여넣기**설정.json**. 파일 저장.

   ```json
   {
   	"globalShortcut": "",
   	"mcpServers": {
   		"cloudflare-dex-analysis": {
   			"command": "npx",
   			"args": ["mcp-remote", "https://dex.mcp.cloudflare.com/mcp"]
   		}
   	}
   }
   ```

4. 선택의 CLI에서 Gemini를 실행하십시오.

5. 모든 것이 예상대로 작동되는 경우, Gemini CLI는 다음 메시지를 표시합니다.<br />
   `Using: 1 MCP server (ctrl+t to view)`

6. Gemini CLI의 Cloudflare 계정과 관련된 이메일을 인증합니다.

7. 당신은 DEX에 대해 Gemini CLI 질문을 요청할 수 있습니다. 간단한 테스트로, "DEX MCP 서버에 연결됩니다.

{/* prettier-ignore-end */}

### 채팅GPT

MCP 서버를 구성하려면 ChatGPT Pro 또는 Business 계정이 필요합니다. ChatGPT 무료 및 Plus는 MCP 서버를 지원하지 않습니다.

1. 다운로드[ChatGPT 데스크탑 앱](https://chatgpt.com/features/desktop).
2. ChatGPT 데스크탑 앱을 열고 로그인하거나 계정을 설정하십시오.
3. 자주 묻는 질문**계정 설정**메뉴 및 선택**연결관**.
4. 새로운 커넥터를 만들 수있는 옵션을 선택합니다.
5. 지원하다**이름 \***(기타)`DEX MCP`), **이름 \***(선택), 및**MCP 서버 URL**연결관을 위해. DEX MCP 서버 URL은 다음과 같습니다.`https://dex.mcp.cloudflare.com/mcp`.
6. 새로운 연결관을 창조하십시오.
7. ChatGPT에게 DEX에 대한 질문을하기 전에, 선&#xD0DD;**+**(plus) ChatGPT 프롬프트 박스 옆에 버튼.
8. 제품정보**연결관을 사용하십시오** > **소스 추가**DEX MCP를 소스로 선택합니다.
9. DEX에 대해 ChatGPT 질문을 할 수 있습니다. 간단한 테스트로, "DEX MCP 서버에 연결됩니다.

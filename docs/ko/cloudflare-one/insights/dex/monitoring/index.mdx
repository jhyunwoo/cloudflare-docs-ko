조직의 성능 및 네트워크 상태 모니터링[배틀그라운드](/cloudflare-one/insights/dex/monitoring/#fleet-status)또는 개인[사용자 장치](/cloudflare-one/insights/dex/monitoring/#device-monitoring).

네트워크 및 장치 성능 데이터는 IT 관리자 문제 해결 성능 문제, 네트워크 연결 문제 조사, 및 모니터링 장치 건강.

## 장치 개요

차량은 사용자 장치의 컬렉션입니다. 함대의 모든 장치에는 WARP가 설치되어 있으며 연결됩니다.[Cloudflare Zero Trust 조직](/cloudflare-one/setup/#create-a-zero-trust-organization).

함대 상태를 볼 수:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**관련 기사** > **디지털 경험**.
2. 자주 묻는 질문**본문 바로가기**.

### 메트릭 보기

더 보기**장치 개요**탭은 조직의 모든 장치에 대한 실시간 및 역사적인 연결 메트릭을 보여줍니다.

per-device 수준에 대한 분석보기, 이동[장치 감시](/cloudflare-one/insights/dex/monitoring/#device-monitoring).

### 유효한 미터

- **colo에 의해 연결된 장치**: 주어진 장치에 연결된 장치 수[Cloudflare 데이터 센터](https://www.cloudflarestatus.com/).

- **연결 상태**: 주어진 WARP 클라이언트 상태에 있는 장치의 백분율.

  | 주요연혁  | 이름 \*                                                                                                                                                                                                                                                                                                       |
  | ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
  | 연결하기  | WARP는 Cloudflare 글로벌 네트워크의 연결을 성공적으로 설치했습니다.                                                                                                                                                                                                                                                                |
  | 연결하기  | WARP는 Cloudflare 글로벌 네트워크에서 의도적으로 중단되거나 중단되지 않았습니다.                                                                                                                                                                                                                                                         |
  | 이용 약관 | 사용자 또는 관리자는 일시적으로 WARP를 해제하기 위해 명시된 조치를 취했습니다. 예를 들어[관리자 override 코드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#allow-admin-override-codes). Paused 클라이언트는[자동 연결](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#auto-connect)타임아웃 기간 후. |
  | 연결하기  | WARP는 보류 연결이지만 Cloudflare 글로벌 네트워크에 연결하기 위해 적극적으로 노력하고 있습니다.                                                                                                                                                                                                                                                |

- **주요 특징**: [WARP 형태](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/)장치에 배치.

- **채용 정보**: 주어진 Cloudflare 데이터 센터에 연결된 장치의 비율.

- **회사연혁**: 장치의 운영 체제.

- **주요 버전**: 장치에 설치된 WARP 클라이언트 버전.

- **장치 상태 시간**: 선택된 시간 동안 WARP 클라이언트 연결 상태.

- **연결 방법**: 선택된 시간 동안 장치에 의해 사용되는 WARP 모드.

## 장치 감시

차량에 등록된 기기의 네트워크 및 장치 성능 검토.

### 장치의 성능 보기

장치의 네트워크와 장치 성능 미터를 전망하기 위하여:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**팀 & 자원** > **제품정보** > **당신의 장치**.
2. 장치 선택 >**자주 묻는 질문**.
3. 선택하기**사이트맵**탭.
4. 내 계정**장치 모니터링**, 아래로 스크롤**네트워크 성능**·**장치 성능**.

### 네트워크 및 장치 성능 측정

#### 네트워크 성능 측정

- **시간에 독특한 네트워크**: 몇 가지 독특한 SSIDs 장치가 연결되었습니다.

- **네트워크 I/O**: 1차 네트워크 인터페이스에서 전송되는 장치( 업로드 및 다운로드)를 얼마나 많은 데이터.

#### 장치 성능 미터

- **배터리 비율 및 사이클**: 배터리 비율 표시[배터리 사이클](https://support.apple.com/en-us/102888)시간 이상. 이 메트릭을 사용하여 잠재적 인 성능 문제를 효과적으로 저 배터리 수준에서 트리거하는 배터리 건강 또는 전력 절약 측정과 관련시켰습니다.

- **CPU 사용**: CPU 활용 시간. 이 메트릭을 사용하여 높은 CPU 사용으로 인해 느린 시스템 성능을 디버그합니다.

- **메모리 활용**: 시간에 따른 메모리 활용 이 메트릭을 사용하여 overtaxed 메모리와 관련된 성능 문제를 디버그합니다.

- **디스크 I/O**: 디스크 읽기/쓰기 작업의 수를 표시합니다. 이 메트릭을 사용하여 무거운 디스크 작업으로 인한 성능 오류를 디버그합니다.

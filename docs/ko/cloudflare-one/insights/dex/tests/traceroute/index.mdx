traceroute 테스트는 최종 사용자 장치에서 서버로 IP 패킷의 네트워크 경로를 측정합니다. 네트워크 문제를 해결하기 위해 테스트 결과를 사용할 수 있습니다. 예를 들어, 증가 된 대기 시간은 네트워크 경로와 연결 문제를 나타냅니다.

## 시험 만들기

응용 프로그램에 대한 traceroute 테스트를 설정하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**관련 기사** > **디지털 경험**.
2. 선택하기**테스트**탭.
3. 제품정보**시험 추가**.
4. 다음 필드에 기입:
   - **이름 \***: 시험의 이름을 입력합니다.
   - **제품정보**: 테스트하려는 서버의 IP 주소를 입력하십시오 (예를 들어,`192.0.2.0`). Cloudflare에 연결한 public-facing endpoint 또는 private endpoint 중 하나를 테스트할 수 있습니다.
   - **소스 장치 프로파일**: (선택 사항) 선택[WARP 장치 프로파일](/cloudflare-one/team-and-resources/devices/warp/configure-warp/device-profiles/)테스트 실행을 원합니다. 프로파일이 선택되지 않은 경우 Zero Trust 조직에 연결된 모든 지원 기기에서 테스트가 실행됩니다.
   - **시험 유형**: 선택*트레잇 루트*.
   - **시험 빈도**: 종종 테스트가 실행되는 방법을 지정합니다. 5와 60 사이의 분값을 입력합니다.
5. 제품정보**시험 추가**.

다음 것,[결과보기](/cloudflare-one/insights/dex/tests/view-results/)당신의 시험의.

## 시험 결과

traceroute 테스트는 다음과 같은 데이터를 측정합니다.

| 자료실         | 이름 \*                                                                                                                                                                                                                                                                                           |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 네트워크 경로     | IP 주소, 평균 응답 시간 및 장치와 표적 사이 각 호를 위한 소포 손실.                                                                                                                                                                                                                                                      |
| 둥근 여행 시간    | 패킷을 전송하고 대상에서 응답을 수신 사이의 시간.                                                                                                                                                                                                                                                                    |
| 홉의 수        | 장치와 대상 사이에 발생하는 라우터 수.                                                                                                                                                                                                                                                                          |
| 패킷 손실       | 응답을받지 못하는 IP 패킷의 비율.                                                                                                                                                                                                                                                                            |
| 적용분야        | 적어도 하나의 패킷이 목적지에 도달하는 테스트의 비율.                                                                                                                                                                                                                                                                  |
| 마지막으로 본 ISP | 장치에서 Cloudflare에 연결을 관리하는 인터넷 서비스 제공자. (OS 및 Windows에서만 사용할 수 있습니다.)<br /> <br />DEX는 Geolocation 데이터베이스에서 ISP의 IP 주소를 보고 대응합니다.[ASO 및 ASN](https://www.cloudflare.com/learning/network-layer/what-is-an-autonomous-system/). ASO와 ASN가 있다면`Unknown`, 이 정보는 Geolocation 데이터 제공 업체에서 사용할 수 없습니다. |

DEX의 IP 가시에는 관리자가 장치 당 세 가지 IP 유형에 대한 통찰력을 제공합니다.

1. **제품정보**: 최종 사용자 장치의 개인 IP 주소.
2. **ISP 정보**: ISP가 최종 사용자 디바이스의 트래픽을 전달할 때 공개 IP입니다.
3. **오시는 길**: 라우터의 개인 IP (잠자는 끝 장치가 연결됩니다.)

:::참조

ISP IP는 사용자에게만 볼 수 있습니다.[Zero Trust PII 역할](/cloudflare-one/roles-permissions/#cloudflare-zero-trust-pii).

:::

DEX의 IP 가시성은 IPv6 및 IPv4 주소를 모두 지원합니다.

IP 정보는 IT 관리자가 네트워크 문제를 정확하게 해결하고 사용자 위치를 식별하는 데 중요합니다. IT 관리자는 다음과 같은 문제를 직면:

- 사용자 경험 문제의 정확한 위치를 지정 ( "AP 87는 나쁘다.")
- 네트워크 액세스 제어 정책 위반 식별 ( "NAC Policies는 제대로 적용되지 않습니다.")
- 문제 해결 방화벽 제한 ("VLAN 93의 방화벽은 차단됩니다.")
- 해결 층 2 및 DHCP 관련 문제.
- Indirectly determining 사용자 ID 및 장치 위치.

## 장치의 IP 정보보기

사용자 장치에 대한 IP 정보보기 :

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**팀 & 자원** > **제품정보** > **당신의 장치**.
2. 장치를 선택, 다음 선택**자주 묻는 질문**.
3. 오시는 길**IP 세부사항**.
4. 선택한 장치의 가장 최근 세션에 대한 IP 세부 정보를 검토하십시오.

## 장치의 IP 역사보기

DEX의 IP 가시성을 통해 지난 7일 동안 장치의 IP 기록의 이벤트 로그를 검토할 수 있습니다. 장치의 IP 역사를 볼 수:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**팀 & 자원** > **제품정보** > **당신의 장치**.
2. 장치 선택 >**자주 묻는 질문**> 이동**IP 세부사항**.
3. 제품정보**모든 ISP 보기**.

## IP 가시성 문제 해결

IP 가시성은 장치의 IP 정보를 검사 할 수 있지만, 사용[DEX의 실시간 분석](/cloudflare-one/insights/dex/monitoring/#available-metrics)Cloudflare 데이터 센터가 연결되도록 검토하십시오. 트래픽이 WARP-connected end-user 장치를 나타낼 때, 그것은[Cloudflare 데이터 센터](/support/troubleshooting/general-troubleshooting/gathering-information-for-troubleshooting-sites/#identify-the-cloudflare-data-center-serving-your-request).

Cloudflare 데이터 센터가 연결되도록:

1. 자주 묻는 질문[IP 정보보기](#view-a-devices-ip-history)장치의 IP 정보를 찾을 수 있습니다.
2. 장치 페이지에서, 선택**Colocation & 클라이언트**또는 찾기**회사 소개**페이지 상단의 테이블.
3. 내 계정**회사 소개**테이블, 찾기**회사연혁**Cloudflare 데이터 센터가 선택한 장치의 egress 트래픽이 연결되는 것을 검토하십시오.

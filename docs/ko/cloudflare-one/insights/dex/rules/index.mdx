DEX 규칙은 사용자 그룹을 대상으로 한 테스트 정책을 만들고 관리할 수 있습니다.[배틀그라운드](/cloudflare-one/insights/dex/tests/). 규칙을 만들기 후에, 당신은 그것의 범위를 정의하기 위하여 그것을 사용할 수 있습니다[제품정보](/cloudflare-one/insights/dex/tests/)부서 (금융 또는 판매와 같은 특정 그룹), 장치, 및 / 또는 사용자. 원하는 시험에 적용 및 재사용 규칙을 할 수 있습니다.

DEX 규칙은 테스트의 범위를 특정 그룹에 정의하려는 관리자에 이상적입니다. 더 정확한 문제 감지 및 해상도를 허용하기 위해 자신의 함대 내에서.

## 규칙 만들기

규칙을 만들려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**관련 기사** > **디지털 경험**.
2. 선택하기**이름 \***&#xD0ED;.
3. 제품정보**규칙 추가**.
4. 당신의 규칙을 부여하고 원하는 표현을 구축하십시오.
5. 제품정보**규칙 만들기**당신의 규칙을 완성하십시오.

### 이름 \*

선택자는 DEX 규칙 표현에 필요한 범주로 함대 내에서 그룹을 정의합니다. selector(s)는 규칙에 정의되어 테스트가 영향을 미치는 것을 결정합니다.

다음 목록에서 사용 가능한 선택자 및 해당 범위를 검토하십시오.

| 옵션 정보          | 이름 \*                                                                                  |
| -------------- | -------------------------------------------------------------------------------------- |
| **사용자 이메일**    | 지정하기[사용자 이메일](/cloudflare-one/traffic-policies/identity-selectors/#user-email).        |
| **사용자 그룹 이메일** | 지정하기[그룹 이메일](/cloudflare-one/traffic-policies/identity-selectors/#user-group-email).   |
| **사용자 그룹 ID**  | 지정하기[그룹 ID](/cloudflare-one/traffic-policies/identity-selectors/#user-group-ids).      |
| **사용자 그룹 이름**  | 지정하기[그룹 이름](/cloudflare-one/traffic-policies/identity-selectors/#user-group-names).    |
| **운영 시스템**     | 운영 체제를 지정합니다.                                                                          |
| **운영 시스템 버전**  | 운영 체제 버전을 지정하기 위해 (사용 연산자`in`) 또는 버전 (사용 연산자`is`).                                     |
| **관리 네트워크**    | 원격 액세스에 비해 Office(managed network)에서 네트워크에 액세스하는 사용자 지정.                               |
| **SAML 속성**    | 값 지정하기[SAML 특성](/cloudflare-one/traffic-policies/identity-selectors/#saml-attributes). |
| **인기 카테고리**    | Cloudflare 데이터 센터 위치 사용자 지정을 위해 연결됩니다.                                                 |

## 시험에 규칙을 추가

규칙을 작성한 후 테스트에 추가할 수 있습니다. 테스트 규칙을 추가하지 않는 경우, 테스트는 전체 장치 함대에서 실행됩니다.

시험에 규칙을 추가하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**관련 기사** > **디지털 경험**.
2. 선택하기**테스트**탭.
3. 기존의 테스트를 선택하고 선택**제품정보**, 또는 선택**시험 추가**새로운 시험을 만들기 위하여.
4. 이름 \***DEX 규칙 선택**, 당신이 적용하고 싶은 규칙을 선택하십시오.
5. 제품정보**시험 저장**기존 규칙 또는**규칙 추가**새로운 시험을 위해.

규칙을 테스트하는 것은 다음과 같습니다.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**관련 기사** > **디지털 경험**.
2. 선택하기**이름 \***&#xD0ED;.
3. 규칙을 선택하고 선택**제품정보**.
4. 선택하기**DEX 테스트**탭 및 선택한 규칙을 포함하는 테스트 목록.

## 규칙을 사용하여 테스트 만들기

새로운 테스트를 만들 수 있습니다.[DEX 시험 대시보드 위에서 설명한대로](/cloudflare-one/insights/dex/rules/#add-a-rule-to-a-test)또는 DEX 규칙 대시보드에서 직접.

DEX 규칙을 사용하여 새로운 테스트를 만들려면 :

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**관련 기사** > **디지털 경험**.
2. 선택하기**이름 \***&#xD0ED;.
3. 규칙을 선택하고 선택**제품정보**.
4. 선택하기**DEX 테스트**탭.
5. 현재이 규칙을 포함하는 모든 테스트를 검토 할 수 있습니다. 새로운 테스트를 만들기 위해, 선택**이 규칙을 사용하여 테스트 만들기**.
6. 필요한 모든 정보를 입력하고 규칙 이름 옆에있는 상자를 확인하십시오.
7. 제품정보**시험 추가**.

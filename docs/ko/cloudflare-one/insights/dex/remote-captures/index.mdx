원격 캡처는 관리자가 패킷 캡처 (PCAP) 및 WARP 진단 로그를 최종 사용자 장치에서 직접 수집 할 수 있습니다. 이 데이터는 네트워크 문제를 해결하기 위해 사용될 수 있으며 보안 사고를 조사하고 성능 병목을 식별 할 수 있습니다.

### 장치 PCAP 내용

다운로드 PCAP 폴더에는 세 개의 파일이 포함되어 있습니다.

- `capture-default.pcap`: 1차 네트워크 인터페이스에 대한 패킷 캡처.
- `capture-tunnel.pcap`: WARP 터널 내부의 트래픽에 대한 패킷 캡처.
- `results.json`: 성공적인 패킷 캡처를 보고 실패.

분석할 수 있습니다.`.pcap`Wireshark 또는 다른 타사 패킷 캡처 도구를 사용하여 파일.

## 제한 사항

- 패킷 캡처는 다음과 같은 제한에 적용됩니다:

  | 제한 유형     | 최대 값     |
  | --------- | -------- |
  | 시간 제한     | 600 초    |
  | 파일 크기     | 50 마일    |
  | Packet 크기 | 1500 바이트 |

- WARP 진단 로그에는 파일 크기 제한이 없지만, 100MB 이상의 파일을 Cloudflare에 업로드할 수 없으며 관리자와 직접 공유해야합니다.

- Windows 장치는 동시 먼 붙잡음을 지원하지 않습니다. 다른 동안 원격 캡처를 시작하면 두 번째 캡처가 즉시 실패합니다.

- PCAP는 다른 타사 패킷 캡처 도구를 가지고 있다면 Windows에서 실패합니다 (예 : 패킷 모니터`pktmon`) 실행.

- Windows에서, 패킷 캡처는 언-한국어로 구성되는 장치에 실패할 수 있습니다.`PktMon`도구.

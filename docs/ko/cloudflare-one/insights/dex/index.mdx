DEX는 Cloudflare의 호환[고객 메타데이터 경계](/data-localization/metadata-boundary/)'EU'(European Union)에 대한 고객 로그가 'EU'지역을 남길 수 없다는 것을 보증합니다.

<Render file="analytics/observability-tools-note" product="cloudflare-one" />

## 사용자가 문제를 보고할 때

사용자가 "연결이 작동하지 않습니다"또는 "기능이 느리다"라고 알리면 DEX는 다음과 같습니다.

- 제품 정보[장치 감시](/cloudflare-one/insights/dex/monitoring/)장치 건강과 엔드포인트 연결을 확인합니다.
- 테스트 네트워크 건강 및 응용 응답과[합성 시험](/cloudflare-one/insights/dex/tests/).
- 기기에서 발생하는 문제를 식별 (예 :[WARP 클라이언트와 문제](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/troubleshooting-guide/)), 네트워크, 또는 Cloudflare.

## 다른 Cloudflare를 문제 해결 1개의 특징

다른 Cloudflare 문제 해결 DEX 사용 1개의 특징:

- 테스트 연결[SaaS 애플리케이션 보안](/cloudflare-one/access-controls/applications/http-apps/saas-apps/).
- 웹 사이트를 통해 경로 확인[오시는 길](/cloudflare-one/traffic-policies/)사용자 장치에서 사용할 수 있습니다.
- 사용자가 설정 후 내부 리소스에 성공적으로 도달 할 수 있음을 확인합니다.[관련 제품](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/).

### 시작하기

장치, 네트워크 및 애플리케이션 모니터링을 위한 DEX를 시작하려면:

1. [Zero Trust 조직 만들기](/cloudflare-one/setup/#create-a-zero-trust-organization).
2. [WARP 클라이언트 설치](/cloudflare-one/team-and-resources/devices/warp/)로그인 및 회원가입
3. 이름 \*[제품정보](/cloudflare-one/insights/dex/tests/)애플리케이션 및 네트워크에 대한 장치 연결을 확인합니다.
4. [관련 상품](/cloudflare-one/insights/dex/monitoring/)실시간 및 역사적인 메트릭을 사용하여 차량에 대한 장치 및 네트워크 건강.
5. 지원하다[원격 캡처](/cloudflare-one/insights/dex/remote-captures/)사용자 장치에서 진단 로그 및 패킷 캡처를 수집합니다.
6. 설치하기[공지사항](/cloudflare-one/insights/dex/notifications/)연결 또는 응용 성능이 감지 될 때 경고를 얻기 위해.

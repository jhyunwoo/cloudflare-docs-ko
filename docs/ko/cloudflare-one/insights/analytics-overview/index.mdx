Cloudflare One Analytics 개요는 Cloudflare의 보고서를 제공하는 대시보드를 제공합니다. 하나는 조직과 네트워크를 보호하고 있습니다. 이 페이지를 사용하여 조직 내에서 사용 및 잠재적 보안 문제를 모니터링합니다.

## 글로벌 상태

내 계정**글로벌 상태**, 당신은 당신의 조직 Cloudflare에 보고서를 볼 수 있습니다 뒤에 오는 미터를 포함하는 1개의 채택:

- Access 앱 구성
- Gateway HTTP 정책
- Gateway 네트워크 정책
- Gateway DNS 정책
- SaaS 통합
- DLP 프로필

또한 보고서를 볼 수 있습니다.[좌석 사용](/cloudflare-one/team-and-resources/users/seat-management/)다음 미터를 포함하는 Zero Trust 조직의 맞은편에:

- 총 좌석
- 관련 좌석
- 사용 가능한 좌석

## 오시는 길

내 계정**오시는 길**, 다음을 포함하는 액세스 구성에 대한 보고서를 볼 수 있습니다:

**미터:**

- Total 액세스 시도
- Granted 접근
- 부인 (policy)
- Active 로그인 overtime
- 대부분의 로그인을 가진 최고 신청

**필터:**

- 국가별 연락처

## 오시는 길

### 프록시 트래픽

내 계정**프록시 트래픽**, 포함 게이트웨이 HTTP 트래픽에 대한 보고서를 볼 수 있습니다:

**미터:**

- 총 요청 overtime
- 자주 묻는 질문
- 블록 요청
- 격리된 요청
- 요청을 검사하지 마십시오
- 최고 대역폭 소비자 (GB)
- 사용자 정의

**필터:**

- Gateway 국가별 HTTP 트래픽 데이터

### Gateway (네트워크 요청)

내 계정**Gateway (네트워크 요청)**, 다음을 포함하는 게이트웨이 네트워크 트래픽에 대한 보고서를 볼 수 있습니다:

**미터:**

- 총 세션
- 인증된 세션
- 블록 세션
- 감사 SSH 세션
- 허용된 세션
- Override 세션
- GB의 최고 대역폭 소비자
- 사용자 정의

**필터:**

- Gateway 네트워크 트래픽 데이터

### DNS 트래픽

내 계정**DNS 트래픽**, 포함 게이트웨이 DNS 트래픽에 대한 보고서를 볼 수 있습니다:

**미터:**

- 총 DNS 쿼리
- DNS 쿼리 허용
- DNS 쿼리 차단
- DNS 쿼리
- 안전한 검색 DNS 쿼리
- DNS 쿼리 제한
- 다른 DNS 쿼리

**필터:**

- 쿼리 유형의 Gateway DNS 트래픽
- Gateway 국가별 DNS 트래픽

### Gateway 통찰력

내 계정**Gateway 통찰력**, 다음 미터를 포함하는 Gateway Firewall 정책을 보고서를 볼 수 있습니다.

- 상단 도메인 차단 정책
- 대부분의 사용자 쿼리
- 상단 장치
- 국가 선택

### CASB 미터

내 계정**캐스 번호:**, SaaS 통합에서 발견된 보안 문제의 인스턴스를 검토할 수 있습니다.

- 발견의 수에 의한 통합
- DLP 프로필 이름 찾기

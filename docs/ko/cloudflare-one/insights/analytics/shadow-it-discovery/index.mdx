Shadow IT SaaS 분석은 사용자가 방문한 SaaS 애플리케이션에 가시성을 제공합니다. 이 정보는 ID 및 장치 구동 Cloudflare를 만들 수 있습니다. 사용자 및 데이터 보안을 위한 정책

Shadow IT SaaS 분석에 액세스하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**관련 기사**.
2. 오시는 길**대시보드**.
3. 제품정보**Shadow IT: SaaS 분석**.

## Shadow IT SaaS 분석

### 1. 검토 신청

Shadow IT SaaS 분석 대시보드를 사용하는 첫 번째 단계는 응용 프로그램을 검토하는 것입니다[회사연혁](/cloudflare-one/team-and-resources/app-library/). App Library는 Shadow IT Discovery SaaS 분석 대시보드의 승인 상태와 애플리케이션 검토 상태를 동기화합니다.

### 2. 감시자 사용법

Shadow IT SaaS 분석 대시보드 앱 사용 필터에 근거를 둔 전망:

| 제품정보  | 이름 \*                                                                                                       |
| ----- | ----------------------------------------------------------------------------------------------------------- |
| 제품 설명 | SaaS 애플리케이션의 이름과 로고.                                                                                        |
| 신청 유형 | [신청 유형](/cloudflare-one/traffic-policies/application-app-types/#app-types)Cloudflare Cloudflare에 의해 할당된 한국어 |
| 주요연혁  | 신청의 승인 상태.                                                                                                  |
| 비밀번호  | 응용 프로그램이 현재 Cloudflare 액세스 뒤에 보안 여부.                                                                        |
| 이름 \* | Shadow IT Discovery 개요 페이지에 지정된 시간 동안 응용 프로그램에 연결되는 사용자 수.                                                  |

대량의 애플리케이션 상태를 관리하려면, 선택**인증현황**응용 프로그램을 검토하려면 일반적으로 방문 및 승인 상태를 업데이트하십시오.

### 3. 정책 작성

표하기 신청 후에, 당신은 창조할 수 있습니다[HTTP 정책](/cloudflare-one/traffic-policies/http-policies/)Application review 상태에 근거합니다. 예를 들어, 다음과 같은 정책을 만들 수 있습니다.

- 모두 시작**평가 없음**·**리뷰에서**응용 분야[비밀번호](/cloudflare-one/traffic-policies/http-policies/common-policies/#1-isolate-unreviewed-or-in-review-applications).
- [블록 액세스](/cloudflare-one/traffic-policies/http-policies/common-policies/#2-block-unapproved-applications)모든 것**계정 관리**신청.
- 특정 애플리케이션 상태에 대한 제한 파일 업로드 기능.

Shadow IT Discovery에서 HTTP 상태 정책을 직접 만들려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**관련 기사**.
2. 제품정보**대시보드** > **Shadow IT: SaaS 분석**.
3. 제품정보**앱 상태 설정**.
4. 제품정보**HTTP 상태 정책 관리**, 다음 응용 상태를 선택하고 선택**공지사항**.

## 이용 약관

Shadow IT SaaS 분석 대시보드는 SaaS 애플리케이션 사용을 모니터링하고 관리하기 위해 여러 통찰력을 포함합니다.

- **상태별 애플리케이션 수**: 몇 가지 응용 프로그램이 각각 분류 된 방법의 고장[승인 상태](#1-review-applications). 신청의 명부는 안으로 유효합니다[앱 라이브러리](/cloudflare-one/team-and-resources/app-library/).
- **Application 상태별 Data 업로드**: 주어진 상태의 응용 프로그램에 업로드 된 데이터 (gigabytes)의 양을 보여주는 시간 시리즈 그래프.
- **Application 상태별 Data 다운로드**: 주어진 상태의 응용 프로그램에서 다운로드 한 데이터 (gigabytes에서)의 양을 보여주는 시간 시리즈 그래프.
- **신청 상태 당 사용자 수**: 주어진 상태에 적어도 하나의 응용 프로그램과 상호 작용하는 사용자의 수를 보여주는 시간 시리즈 그래프. 예를 들어, 사용자는 사용할 수 있습니다.**이름 \***&#xC2E0;청은 곧 뒤에**리뷰에서**응용 프로그램, 그 상태의 둘 다에 대 한 계산에 기여.
- **Top-N 미터**: 최고 애플리케이션, 사용자, 장치 및 국가로 인사이트를 제공하는 메트릭 컬렉션.

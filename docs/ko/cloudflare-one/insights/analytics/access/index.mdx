Access event analytics를 사용하면 로그인 시도를 응용 프로그램에 검토 할 수 있습니다.[오시는 길](/cloudflare-one/access-controls/policies/). 액세스 이벤트 분석은 구동된다[Access 인증 로그](/cloudflare-one/insights/logs/audit-logs/).

액세스 이벤트 분석보기:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**관련 기사**.
2. 오시는 길**대시보드**.
3. 제품정보**오시는 길**.

Access Event Analytics는 인증 활동을 기반으로 합니다.[오시는 길](/cloudflare-one/access-controls/policies/policy-management/).

## 이용 약관

액세스 이벤트 분석 대시보드는 시간에 액세스 활동의 차트를 포함합니다. 액세스 이벤트의 연대 차트를 볼 수 있습니다. 액세스 이벤트 분석 대시보드는 액세스 요청이 발생하면 로그인 시도에서 스파이크를 돕습니다.

- 이벤트는 수직 축에 표시됩니다.
- 시간 (현지 시간대에서)는 수평 축을 따라 표시됩니다.

액세스 이벤트 분석 대시보드는 다음과 같은 메트릭으로 사용 패턴에 데이터를 보여줍니다.

- 관련 제품
- 사용자 이름
- IP 주소
- 맨 위로
- 국가 선택
- Top 신청 유형

이 통찰력은 당신이 anomalies를 감지하고, 정책 규칙을 최적화하는 데 도움이됩니다.

Gateway 분석에는 세 개의 별도의 대시보드가 포함됩니다.

- HTTP 요청 분석.
- DNS 쿼리 분석.
- Network 세션 분석.

Gateway analytics를 검토하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**관련 기사**.
2. 오시는 길**대시보드**.
3. 원하는 대시보드를 선택하십시오.

## HTTP 요청 분석

내 계정[Gateway HTTP 정책](/cloudflare-one/traffic-policies/http-policies/)HTTP 요청 분석 대시보드를 강화합니다. Gateway HTTP 정책을 사용하지 않는 경우 대시보드가 빈 상태로 나타납니다.

HTTP 요청 분석 대시보드는 HTTP 정책이 시간이 초과되는지에 대한 트렌드를 식별하는 데 도움이됩니다. 대시보드는 교통 행동 및 정책 동향에 대한 통찰력을 제공하고, 더 쉽게 사용 패턴에 영향을 줄 수 있습니다.

HTTP 요청 및 관련 정책의 상세한 설명을 검토하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**관련 기사**.
2. 제품정보**로그인**.
3. 제품정보**HTTP 요청 로그**.
4. 사용 방&#xBC95;**- 연혁**필터는 정책 또는 기타 필터를 유발하는 HTTP 요청을 볼 수 있습니다.

### 통합 분석

- HTTP 요청 시간
  - HTTP 요청의 시간 시리즈보기
- 맨 위로
- 상위 국가
- 상위 Blocked 사용자
- 상위 대역폭 소비자
- 상단 장치
- 최고 근원 IPs

## DNS 쿼리 분석

내 계정[Gateway DNS 정책](/cloudflare-one/traffic-policies/dns-policies/)DNS 쿼리 분석 대시보드를 강화합니다. Gateway DNS 정책을 사용하지 않는 경우 대시보드가 빈 상태로 나타납니다.

DNS 쿼리 분석 대시보드는 DNS 정책이 시간이 초과되는지에 대한 추세를 식별하는 데 도움이됩니다. 대시보드는 트래픽 행동 및 정책 동향에 대한 통찰력을 제공하여 암종 또는 사용 패턴의 이동을 쉽게 만들 수 있습니다.

DNS 쿼리 및 관련 정책의 상세한 설명을 검토하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**관련 기사**.
2. 제품정보**로그인**.
3. 제품정보**DNS 쿼리 로그**.
4. 사용 방&#xBC95;**- 연혁**정책 또는 기타 필터를 유발하는 DNS 쿼리를 볼 수 있습니다.

### 통합 분석

- DNS 대기 시간

- 맨 위로
- 상위 국가
- 상위 Blocked 사용자
- Top 허용된 사용자
- Top 차단된 장치

## Network 세션 분석

내 계정[Gateway 네트워크 정책](/cloudflare-one/traffic-policies/network-policies/)네트워크 세션 분석 대시보드. 게이트웨이 네트워크 정책을 사용하지 않는 경우 대시보드는 빈번하게 나타납니다.

네트워크 세션 분석 대시보드는 게이트웨이 네트워크 정책이 시간이 초과되는지에 대한 트렌드를 식별하는 데 도움이됩니다. 대시보드는 트래픽 행동과 정책 동향에 대한 통찰력을 제공하고, 더 쉽게 사용 패턴에 영향을 줄 수 있습니다.

네트워크 세션과 관련 정책에 대한 자세한 설명을 검토하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**관련 기사**.
2. 제품정보**로그인**.
3. 제품정보**네트워크 로그**.
4. 사용 방&#xBC95;**- 연혁**필터는 정책 또는 기타 필터를 유발하는 네트워크 세션을 볼 수 있습니다.

- 네트워크 세션

## GraphQL 쿼리

당신은 사용할 수 있습니다[GraphQL 분석 API](/analytics/graphql-api/)Gateway Analytics 데이터를 조회합니다. 이용안내[데이터셋](/analytics/graphql-api/features/data-sets/)Gateway는 다음을 포함합니다:

| 데이터셋                                                      | 이름 \*                                                                                            |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `gatewayL4DownstreamSessionsAdaptiveGroups`               | 사용자 장치에서 Cloudflare 글로벌 네트워크에 게이트웨이 네트워크 세션에 대한 미터.                                              |
| `gatewayL4UpstreamSessionsAdaptiveGroups`                 | Cloudflare 글로벌 네트워크의 게이트웨이 네트워크 세션에 대한 미터.                                                       |
| `gatewayL4SessionsAdaptiveGroups`                         | 적응 샘플링과 게이트웨이 네트워크 세션에 대한 미터.                                                                    |
| `gatewayL7RequestsAdaptiveGroups`                         | Gateway HTTP 요청에 대한 미터 적응 샘플링.                                                                   |
| `gatewayResolverQueriesAdaptiveGroups`                    | Gateway DNS 쿼리에 대한 미터 적응 샘플링.                                                                    |
| `gatewayResolverByRuleExecutionPerformanceAdaptiveGroups` | Cloudflare 글로벌 네트워크에서 Gateway DNS 정책을 실행하는 시간.                                                   |
| `gatewayResolverByCustomResolverGroups`                   | Gateway DNS 쿼리에 대한 미터는 사용자 정의 해결자를 사용하여 해결했습니다.                                                  |
| `gatewayResolverByCategoryAdaptiveGroups`                 | Gateway DNS 쿼리에 대한 미터 정렬[도메인 범주](/cloudflare-one/traffic-policies/domain-categories/)적응시키는 표본으로. |

스키마를 탐험하려면 GraphQL 클라이언트를 사용할 수 있습니다.[그래피QL](https://github.com/graphql/graphiql/tree/main/packages/graphiql#readme)또는[사이트맵](https://altairgraphql.dev/).

1. [API 토큰 만들기](/analytics/graphql-api/getting-started/authentication/api-token-auth/)다음과 같은 권한을 가진:

   | 제품정보 | 제품 정보 | 제출    |
   | ---- | ----- | ----- |
   | 계좌정보 | 계정 분석 | ...에서 |

2. GraphQL 클라이언트에서,[API 토큰 추가](/analytics/graphql-api/getting-started/authentication/graphql-client-headers/)저자화 헤더로.

3. Gateway Analytics 데이터셋에 액세스하는 쿼리를 컴파일합니다. 예를 들어, 쿼리 할 수 있습니다.`gatewayResolverQueriesAdaptiveGroups`Gateway에 의해 해결 된 DNS 쿼리의 적응 그룹을 반환하는 데이터 세트 :

   ```graphql graphql-api-explorer
   query GatewaySampleQuery($accountTag: string!, $start: Time) {
   	viewer {
   		accounts(filter: { accountTag: $accountTag }) {
   			gatewayResolverQueriesAdaptiveGroups(
   				filter: { datetime_gt: $start }
   				limit: 10
   			) {
   				count
   				dimensions {
   					queryNameReversed
   					resolverDecision
   				}
   			}
   		}
   	}
   }
   ```

더 많은 정보를 원하시면, 참조[GraphiQL에서 쿼리를 컴파일](/analytics/graphql-api/getting-started/compose-graphql-query/).

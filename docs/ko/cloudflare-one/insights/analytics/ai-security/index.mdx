AI 보안 보고서 대시보드는 조직의 AI 사용 및 잠재적 인 보안 위험을 요약합니다.

AI 보안 보고서 대시보드를 보려면 :

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**관련 기사**.
2. 오시는 길**대시보드**.
3. 제품정보**AI 보안 보고서**.

## 자주 묻는 질문

AI 보안 보고서 대시보드를 팝업하려면 다음을해야합니다.

- [사이트맵 오시는 길](/cloudflare-one/traffic-policies/)아웃바운드 HTTP 및 DNS 트래픽을 검사 할 수 있습니다.
- Cloudflare Gateway를 통해 보내지는 SaaS AI 애플리케이션(예: ChatGPT 또는 Gemini)에 대한 사용자 트래픽.
- Cloudflare 액세스 정책 뒤에 MCP 서버.

### Top 5 사용자 조사에 의해 AI 응용 프로그램을 방문

조직에서 가장 액세스 된 AI 도구를 표시하고 사용자의 수는 시간 시리즈 그래프에서 각 응용 프로그램을 방문.\
각 바는 특정 AI 응용 프로그램에 대한 사용자 활동을 나타냅니다 (예 : ChatGPT 또는 Gemini) 시간.

이 차트를 사용하여 채택 동향을 모니터링하고 액세스 할 수있는 새로운 공인 AI 도구를 감지합니다.

### Application count에 의해 AI 애플리케이션에 적용된 상태

확인된 AI 응용 프로그램의 총 수를 보고 그들의 검토 상태.\
상태는 다음과 같습니다:

- Unreviewed — 아직 관리자가 평가되지 않았습니다.
- 에서 검토 — 응용 프로그램은 현재 승인에 대한 리뷰 아래.
- Unapproved - 제한되거나 차단 된 응용 프로그램입니다.
- 승인 된 - 조직 사용에 명시된 응용 프로그램.

### Data는 Artificial Intelligence 응용 프로그램에 의해 업로드

AI 도구로 전송 된 데이터의 양을 보고, 검토 상태에 의해 깨어 (Unreviewed, In Review, Unapproved, 승인).\
민감한 데이터를 unapproved 또는 unreviewed AI 응용 프로그램에 전송하는지 이해하는이 보고서를 사용합니다.

### MCP 서버 시간 이상 액세스

관리 제어 계획 (MCP) 서버의 수를 표시합니다. 액세스 정책에 따라 보호됩니다.\
이 패널을 사용하여 액세스 정책 뒤에 보호 MCP 서버 수를 모니터링합니다.

### MCP 서버에 접속 로그인 이벤트

MCP 서버에 로그인 이벤트의 수를보고 액세스 정책 뒤에 보호.\
이 패널을 사용하여 액세스 정책에 따라 MCP 서버로 로그인 이벤트의 수를 모니터링합니다.

Application Access Report는 고급 요약을 제공합니다.[오시는 길](/cloudflare-one/access-controls/policies/)당신의 조직의 맞은편에 사용법. 이 대시보드는 관리자 모니터 인증 패턴, ID 공급자 사용 및 액세스 구성 메트릭을 돕습니다. 액세스가 계정에 구성되지 않는 경우 대시보드가 빈번하게 나타납니다.

Application Access Report에 의해 구동됩니다.[Access 인증 로그](/cloudflare-one/insights/logs/audit-logs/)

신청 접근 보고 대시보드를 전망하기 위하여:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**관련 기사**.
2. 오시는 길**대시보드**.
3. 제품정보**Application 액세스 보고서**.

## 자주 묻는 질문

Application Access Report 대시보드를 대체하려면 다음을해야합니다.

- 적어도 하나[오시는 길](/cloudflare-one/access-controls/applications/)계정에서 구성.
- Cloudflare Access를 통해 이러한 응용 프로그램에 인증하는 사용자.

### 액세스 활동 요약

액세스 활동 섹션의 개요는 선택한 기간 동안 액세스 로그인 이벤트의 시간 시리즈와 로그인 이벤트 요약을 보여줍니다. 대시보드의 오른쪽 코너에서 시간을 필터링 할 수 있습니다.

### 오시는 길

선택한 기간에 액세스 로그인 이벤트의 시간 시리즈를 표시합니다. 각 막대기는 x-축 시간 간격에 있는 로그인 사건의 수를 나타냅니다.
이 그래프를 사용하여 사용자 인증 활동을 검토하고 특정 로그인 스파이크를 감지 할 수 있습니다.

### 이벤트 카운트에 의한 액세스 결정

결과에 의해 그룹화 된 액세스 결정의 총 수 표시 (예를 들어,**지원하다**또는**뚱 베어**).

### 이벤트 카운트에 의한 액세스 응용

애플리케이션 유형별 인증 이벤트 내역 표시(예:**셀프 호스팅**, **SaaS 서비스**, **개인 네트워크**, **회사연혁**또는**MCP 포털**).\
응용 프로그램 유형 사용자를 가장 자주 액세스 결정하는이보기를 사용합니다.

### 오시는 길

Categorizes 인증 이벤트 방법 등**사이트맵**또는**로그인**(직접 자격 증명).\
이 패널은 관리자가 애플리케이션과 ID 공급자를 통해 사용자를 인증하는 방법을 이해하는 데 도움이됩니다.

### 이벤트 정보의 최고 수

가장 일반적인 액세스 이벤트 속성 목록:

- Application name — 상단 액세스 응용 프로그램을 표시합니다.
- Identity 공급자 — ID 공급자 (IdPs)가 가장 많이 사용되었는지 보여줍니다.
- 사용자 — 로그인 이벤트 번호로 최고 사용자 목록.
- 국가 — 사용자가 로그인 한 상위 국가 표시.
- IP 주소 - 로그인 이벤트와 관련된 최고 소스 IP 목록.

이 통찰력은 관리자가 사용 패턴과 트렌드를 확인합니다.

### 액세스 관리자 미터

조직의 관리자에 의해 만들어진 액세스 구성 요약 제공, 포함:

- 응용 프로그램 구성 — 액세스 보호 응용 프로그램의 총 수, 유형에 의해 깨어 (예를 들어, 자체 호스팅, SaaS, RDP, SSH, 개인 네트워크 및 대시 SSO.)
- 구성 된 정책 — 총 액세스 정책의 수, 정책 유형에 의해 그룹화 (예를 들어, 허용, 블록, 우회, 또는 서비스 Auth.)

이 섹션은 관리자가 액세스 설정을 감사하고 예상 리소스 및 정책이 장소에 있는지 확인합니다.

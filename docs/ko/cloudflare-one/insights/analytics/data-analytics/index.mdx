데이터 보안 분석 대시보드는 SaaS 애플리케이션, 클라우드 환경 및 HTTP 트래픽에서 발견된 보안 문제 및 민감한 데이터를 보고합니다. DLP 및 CASB 정책에서 수집된 이벤트 데이터를 시각화합니다. DLP 또는 CASB는 계정에서 활성화되지 않는 경우 대시보드는 비어 있습니다.

데이터 보안 분석을 보려면 대시보드:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**관련 기사**.
2. 오시는 길**대시보드**.
3. 제품정보**Data 보안 분석**.

## 자주 묻는 질문

이 대시보드를 대체하려면 다음을해야합니다.

- [데이터 손실 방지 (DLP)](/cloudflare-one/data-loss-prevention/)스캔 된 웹 트래픽 또는 SaaS 응용 프로그램에서 이벤트 데이터를 생성하는 구성.
- 적어도 하나[클라우드 액세스 보안 브로커 (CASB)](/cloudflare-one/integrations/cloud-and-saas/)SaaS 애플리케이션 또는 클라우드 환경에서 찾기를 캡처하는 통합.

대시보드는 다음과 같은 패널과 미터를 포함합니다:

- Content Finds의 최고 통합
- 톱 클라우드 리소스 찾기
- DLP 정책에 의한 상위 사용자

### SaaS 및 클라우드 조사

SaaS 및 Cloud Finds by count chart는 Posture 및 Content Finds의 시간 시리즈보기를 보여줍니다.[이름 \*](/cloudflare-one/cloud-and-saas-findings/manage-findings/#posture-findings)misconfigurations, unauthorized user activity 및 기타 데이터 보안 문제가 포함된 자세 조사.[이름 \*](/cloudflare-one/cloud-and-saas-findings/manage-findings/#content-findings)denotes content finds that include 인스턴스의 잠재적 인 데이터 노출 식별[사이트맵](/cloudflare-one/data-loss-prevention/).

각 막대기는 주어진 시간 간격 안에 검출된 총 수를 대표합니다. 패턴이나 스파이크를 관찰 할 수 있습니다. 모든 바를 통해 그 기간 동안 Posture 및 Content Finds의 정확한 조사를 볼 수 있습니다.

세부 사항에 대한 검색을 검토하려면 로그인[사이트맵 한국어](https://one.dash.cloudflare.com)·**클라우드 및 SaaS** > **Posture 찾기**또는**콘텐츠 찾기**.

### Severity의 자세 연구

The Posture finds by severity chart 표시 the Distribution of CASB 발견에 따라[severity 수준](/cloudflare-one/cloud-and-saas-findings/manage-findings/#severity-levels). 원형의 각 세그먼트는 분류된 자세 문제점의 수를 나타냅니다`Critical`, `High`, `Medium`, 또는`Low`.

세부 사항에 대한 검색을 검토하려면 로그인[사이트맵 한국어](https://one.dash.cloudflare.com)·**클라우드 및 SaaS** > **Posture 찾기**.

### DLP는 시간에 HTTP 요청에 일치

DLP는 시간 차트가 표시될 때 HTTP 요청에 일치합니다.[DLP 정책](/cloudflare-one/data-loss-prevention/dlp-policies/)지정된 기간 동안 사용자에 의해 트리거되었습니다.

SaaS 및 Cloud와는 달리, 나머지 데이터에서 데이터를 검색하는 CASB에 의존하는, 시간 차트에 HTTP 요청의 DLP 일치는 HTTP 트래픽에서 DLP 탐지를 반영합니다. - 실시간 민감한 데이터 움직임을 모니터링하는 데 도움이됩니다.

세부 사항에 DLP 검출을 검토하려면 로그인[사이트맵 한국어](https://one.dash.cloudflare.com)·**관련 기사** > **로그인** > **HTTP 요청 로그**. 사용**DLP 프로필**또는**DLP 일치 데이터**DLP 정책 트리거 된 HTTP 요청을 보려면 필터.

Posture 로그 쇼[장치 자세 검사](/cloudflare-one/reusable-components/posture-checks/)WARP 클라이언트에 의해 보고된 결과.

장치 자세 로그를 보시려면 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/)·**로그인** > **이름 \***. 로그인만 하면 설정된 경우만 표시 됩니다.[장치 자세 검사](/cloudflare-one/reusable-components/posture-checks/)Zero Trust 조직을 위해.

Enterprise 사용자는 더 자세한 로그를 생성할 수 있습니다.[다운로드](/cloudflare-one/insights/logs/logpush/).

## 분야의 설명

### Device 세부사항

| 제품정보       | 이름 \*                     |
| ---------- | ------------------------- |
| **이름 \***  | 장치의 이름.                   |
| **이름 \***  | WARP 클라이언트에 의해 생성된 장치 ID. |
| **일련 번호**  | 장치의 일련 번호.                |
| **주요 특징**  | 장치의 제조자.                  |
| **모델 번호:** | 장치의 모형.                   |

### 사용자 정보

| 제품정보       | 이름 \*                            |
| ---------- | -------------------------------- |
| **이름 \***  | Zero Trust로 장치를 등록하는 데 사용되는 이메일. |
| **사용자 ID** | 디바이스를 등록한 사용자의 UUID.             |
| **등록 ID**  | 사용자 WARP 클라이언트 등록의 UUID.         |

### Posture 세부사항

| 제품정보      | 이름 \*                                                                                                                                                         |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **이름 \*** | 이름의[장치 자세 검사](/cloudflare-one/reusable-components/posture-checks/).                                                                                           |
| **제품정보**  | 유형의[WARP 클라이언트 체크](/cloudflare-one/reusable-components/posture-checks/warp-client-checks/)또는[서비스 공급자 check](/cloudflare-one/integrations/service-providers/). |
| **규칙 ID** | 장치 자세 검사의 UUID.                                                                                                                                               |
| **조건 충족** | 기기가 전달되거나 실패한 자세 검사 기준 여부. 관련 기사`true`만약에**수신 값**이름 \***예상 값**.                                                                                               |
| **예상 값**  | 장치 자세 검사를 통과해야 하는 가치.                                                                                                                                         |
| **수신 값**  | WARP 클라이언트에 의해 검출되는 자세 체크 가치.                                                                                                                                 |

터널 감사 로그는 사용할 수 있습니다[Cloudflare 대시보드 계정 섹션](https://dash.cloudflare.com/?account=audit-log)대시보드의 오른쪽 상단 모서리에 이름을 선택하여 찾을 수 있습니다. 다음과 같은 행동은 기록됩니다:

| - 연혁     | 이름 \*                                                    |
| -------- | -------------------------------------------------------- |
| 회사연혁     | 터널이 시작되고 Cloudflare 가장자리에 연결되면 로그인됩니다.                   |
| 관련 상품    | 터널이 Cloudflare 가장자리에서 분리 될 때 기록됩니다.                      |
| CNAME 추가 | 터널이 새로운 DNS (CNAME 또는 AAAA)를 터널링 응용 프로그램에 등록 할 때이 기록됩니다. |

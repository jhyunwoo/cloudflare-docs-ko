## Zero Trust 로그 내보내기

:::caution\[Dashboard 제한]
사이트맵 One은 구성을 지원하지 않습니다.[Cloudflare R2](/logs/logpush/logpush-job/enable-destinations/r2/)대시보드에 있는 Logpush 목적지로. R2를 Zero Trust 로그 대상으로 사용하려면 Logpush 작업을 구성하십시오.[API로](/logs/logpush/logpush-job/enable-destinations/r2/#manage-via-api).
:::

Zero Trust 로그를 구성하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**관련 기사** > **로그인**.
2. 제품정보**Logpush 관리**.
3. Logpush에서, 선택**Logpush 작업 만들기**.
4. 선택하기[Logpush 목적지](/logs/logpush/logpush-job/enable-destinations/).
5. 서비스별 지침을 따라 목적지를 구성하고 검증합니다.
6. 선택하기[Zero Trust 데이터셋](#zero-trust-datasets)수출에.
7. 이름 \***이름 \***, 어떤[제품정보](/logs/logpush/logpush-job/filters/)당신은 추가하고 싶은 데이터 필드는 로그에 포함.
8. (선택) 안으로**고급 설정**, 당신이 선호하는 타임스탬프 형식을 선택하고 당신이 로그 샘플링을 활성화하려는 여부.
9. 제품정보**제출하기**.

Logpush 통합의 설정은 이제 완료됩니다. Logpush는 5 분마다 업데이트 로그를 보내드립니다. 여러 목적지를 구성하고 로그에 추가 필드를 추가 할 수 있습니다.**다운로드**사이트 맵

지원 대상에 대한 자세한 내용은 참조[자주 묻는 질문](/logs/logpush/logpush-job/enable-destinations/).

## Parse DNS 로그

Logpush는 각 DNS 쿼리에 대한 다음 필드를 로그:

- Query 이름
- Query 유형
- Query 클래스
- 응답 TTL
- 응답 자료

DNS 쿼리 리소스 레코드는[Base64 인코딩 된 바이너리 형식](https://datatracker.ietf.org/doc/html/rfc1035#section-4.1.3)그리고 JSON. 예를 들면:

```json
{
	"ResourceRecords": [
		{
			"type": "5",
			"data": "d3d3LmV4YW1wbGUuY29tAAABAAUAAABleGFtcGxlLmNvbQ=="
		},
		{
			"type": "1",
			"data": "ZXhhbXBsZS5jb20AAAEAAQAAAQIDBAUGBwgJ"
		}
	],
	"ResourceRecordsJSON": "[{\"name\":\"www.example.com\",\"type\":\"CNAME\",\"class\":\"IN\",\"ttl\":300,\"rdata\":\"example.com.\"},{\"name\":\"example.com\",\"type\":\"A\",\"class\":\"IN\",\"ttl\":300,\"rdata\":\"203.0.113.0\"}]"
}
```

다른 것을 활용할 수 있습니다[로그 필터](/logs/logpush/logpush-job/filters/)Cloudflare Network Firewall에서 특정 데이터를 볼 수 있습니다.

## 필터 활성화 또는 비활성화 규칙

아래의 필터 예제를 사용하여 Cloudflare Network Firewall 트래픽을 필터링하여 활성화 또는 비활성화 규칙을 표시하십시오.

아래 예제[Logpush 작업 생성](/api/resources/logpush/subresources/jobs/methods/create/)Cloudflare Network Firewall과 관련된 필드를 표시하고, 필터는 비활성화 규칙에 대한 이벤트 만 표시됩니다.

<APIRequest
  path="/accounts/{account_id}/logpush/jobs"
  method="POST"
  json={{
  	destination_conf: "<DESTINATION_CONF>",
  	output_options: {
  		field_names: [
  			"ColoName",
  			"Datetime",
  			"Direction",
  			"IPDestinationAddress",
  			"IPDestinationSubnet",
  			"IPProtocol",
  			"IPSourceAddress",
  			"IPSourceSubnet",
  			"Outcome",
  			"RuleID",
  			"RulesetID",
  			"SampleInterval",
  			"Verdict",
  		],
  	},
  	filter:
  		'{"where":{"or":[{"and":[{"key":"MitigationSystem","operator":"eq","value":"magic-firewall"},{"key":"RulesetID","operator":"!eq","value":""},{"key":"Outcome","operator":"eq","value":"pass"},{"key":"Verdict","operator":"eq","value":"drop"}]}]}}',
  }}
/>

아래 예제[Logpush 작업 생성](/api/resources/logpush/subresources/jobs/methods/create/)Cloudflare Network Firewall과 관련된 필드만 표시하고, 필터는 활성화된 규칙을 위한 이벤트만 표시합니다.

<APIRequest
  path="/accounts/{account_id}/logpush/jobs"
  method="POST"
  json={{
  	destination_conf: "<DESTINATION_CONF>",
  	output_options: {
  		field_names: [
  			"ColoName",
  			"Datetime",
  			"Direction",
  			"IPDestinationAddress",
  			"IPDestinationSubnet",
  			"IPProtocol",
  			"IPSourceAddress",
  			"IPSourceSubnet",
  			"Outcome",
  			"RuleID",
  			"RulesetID",
  			"SampleInterval",
  			"Verdict",
  		],
  	},
  	filter:
  		'{"where":{"or":[{"and":[{"key":"MitigationSystem","operator":"eq","value":"magic-firewall"},{"key":"RulesetID","operator":"!eq","value":""},{"or":[{"key":"Outcome","operator":"eq","value":"drop"},{"key":"Verdict","operator":"eq","value":"pass"}]}]}]}}',
  }}
/>

## 허용되거나 차단 된 트래픽 필터

아래의 필터 예제를 사용하여 Cloudflare 네트워크 방화벽 트래픽을 필터링하여 이벤트를 표시하거나 트래픽을 차단합니다.

아래 예제[Logpush 작업 생성](/api/resources/logpush/subresources/jobs/methods/create/)Cloudflare Network Firewall과 관련된 필드만 표시하고, 필터는 명시되지 않은 동작이 촬영되지 않은 이벤트를 표시합니다. 예를 들어, 패킷 "fell through" Cloudflare Network Firewall. 이 예제는 적용된 규칙이 없습니다.

<APIRequest
  path="/accounts/{account_id}/logpush/jobs"
  method="POST"

  	output_options: {
  		field_names: [
  			"ColoName",
  			"Datetime",
  			"Direction",
  			"IPDestinationAddress",
  			"IPDestinationSubnet",
  			"IPProtocol",
  			"IPSourceAddress",
  			"IPSourceSubnet",
  			"Outcome",
  			"RuleID",
  			"RulesetID",
  			"SampleInterval",
  			"Verdict",
  		],
  	},
  	filter:
  		'{"where":{"and":[{"key":"MitigationSystem","operator":"eq","value":"magic-firewall"},{"key":"RulesetID","operator":"eq","value":""}]}}',
  }}
/>

아래 예제[Logpush 작업 생성](/api/resources/logpush/subresources/jobs/methods/create/)Cloudflare Network Firewall과 관련된 필드만 표시하고, 명시된 동작이 촬영된 이벤트만 표시한다. 예제에는 모두 활성화 및 비활성화 Cloudflare 네트워크 방화벽 규칙이 포함되어 있습니다.

## Cloudflare Network Firewall에 관련된 필드 필터

<APIRequest
  path="/accounts/{account_id}/logpush/jobs"

  	output_options: {
  		field_names: [
  			"ColoName",
  			"Datetime",
  			"Direction",
  			"IPDestinationAddress",
  			"IPDestinationSubnet",
  			"IPProtocol",
  			"IPSourceAddress",
  			"IPSourceSubnet",
  			"Outcome",
  			"RuleID",
  			"RulesetID",
  			"SampleInterval",
  			"Verdict",
  		],
  	},
  	filter:
  		'{"where":{"key":"MitigationSystem","operator":"eq","value":"magic-firewall"}}',
  }}
/>

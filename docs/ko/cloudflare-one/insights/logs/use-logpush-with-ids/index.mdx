Cloudflare 네트워크 방화벽 IDS로 Logpush를 사용할 수 있습니다.

1. 자주 묻는 질문[Logpush 대상 문서](/logs/logpush/logpush-job/api-configuration/#destination)어떤 목적지 Logpush 지원에 대해 알아 보려면. 문서는 Logpush의 대상 URL을 올바르게 포맷하는 방법에 대해 설명합니다.

2. 자주 묻는 질문[cURL로 Lopush 관리](/logs/logpush/examples/example-logpush-curl/)Logpush 목적지를 검증하고 Logpush 작업을 정의하는 튜토리얼.

## IDS로 Logpush 사용

- Magic IDS는 계정의 데이터셋입니다. 이것은 문자열을 의미합니다.`/zone/<ZONE_ID>`튜토리얼에서 Cloudflare API URL을 대체해야`/account/<ACCOUNT_ID>`.

- 자주 묻는 질문[매직 ID 탐지 분야 doc](/logs/logpush/logpush-job/datasets/account/magic_ids_detections/)작업에 필요한 필드를 알고 있습니다.

- Logpush 작업을 만들 때, dataset 필드는 동등해야`magic_ids_detections`.

- 기본적으로 Timestamps는 unixnano입니다. 견적 요청[Logpush 옵션 문서](/logs/logpush/logpush-job/api-configuration/#options)어떤 형식을 배우는 것은 목적지와 / 또는 기대와 호환 될 수 있습니다. 모든 옵션이 추가되어야 합니다.*후에*Logpush 작업, URL 매개 변수에 akin에서 원하는 모든 필드.

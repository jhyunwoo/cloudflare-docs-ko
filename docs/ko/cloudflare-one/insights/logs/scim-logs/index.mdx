SCIM 활동 로그는 관리자가 어떻게 감사 할 수 있는지[SCIM 제공](/cloudflare-one/team-and-resources/users/scim/)ID 공급자의 이벤트 (예: 생성, 업데이트, 삭제) Zero Trust의 사용자의 정체성 및 그룹 회원에 영향을 미치는. Zero Trust SCIM 로그는 정체성 공급자의 SCIM 로그와 비교하여 정체성 데이터가 두 서비스간에 공유되는 방법을 추적하고 오류의 소스를 피할 수 있습니다.

## SCIM 로그 보기

모든 사용자의 SCIM 이벤트의 개요를 위해 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/)·**로그인** > **SCIM 제공**. 이 페이지는 SCIM으로 구성된 모든 정체성 공급자로부터 인바운드 SCIM 요청을 나열합니다. SCIM 작업에 대한 자세한 내용을 보려면 개별 요청을 선택할 수 있습니다.

SCIM 이벤트가 특정 사용자에 미치는 영향을 조사하기 위해, 그들의[사용자 등록 ID](/cloudflare-one/team-and-resources/users/users/).

## 공지사항

SCIM 프로비저닝 로그는 각 inbound SCIM 요청에 대한 다음 정보를 보여줍니다.

- **IdP 이름**: ID 공급자의 이름
- **스크린 샷**: 요청일 및 시간
- **- 연혁**: HTTP 요청 방법 (`POST`, `PUT`, `PATCH`, `DELETE`)
- **사용자 이메일**: SCIM ID 업데이트를 받은 사용자
- **그룹 이름**: SCIM ID 업데이트를 받은 그룹
- **Resource 유형**: 수정 된 SCIM 리소스 (`GROUP`또는`USER`)
- **CF 자원 ID**: Cloudflare SCIM에 의해 생성된 사용자 또는 그룹을 위한 고유 식별자
- **IDP 자료 ID**: ID 공급자가 제공하는 사용자 또는 그룹 식별자
- **한국어**: SCIM 요청이 성공적으로 적용되었는지 여부 (`SUCCESS`또는`ERROR`)
- **주문 몸**: HTTP 요청 몸 추가, 수정, 삭제 된 데이터 포함
- **JSON 로그**: JSON 형식으로 SCIM 요청 로그

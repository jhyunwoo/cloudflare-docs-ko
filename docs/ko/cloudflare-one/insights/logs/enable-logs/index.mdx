이메일 보안은 Logpush를 구성하여 선택의 엔드포인트에 탐지 데이터를 보낼 수 있습니다.

## Enable detection 로그

탐지 로그는 이메일 보안 및 탐지와 관련된 메타 데이터의 일부로 만든 로그를 생성합니다.

감지 로그를 활성화하려면, 참조[자주 묻는 질문](/logs/logpush/logpush-job/enable-destinations/).

감지 로그를 활성화하면[사이트맵](/r2/), 선택**이메일 보안 경고**설정할 때**데이터셋**.

## 사용자 행동 로그

사용자 행동 로그를 통해 찍은 모든 행동에 대한 로그를 볼 수 있습니다[사이트맵](/api/resources/email_security/)또는 대시보드.

이메일 보안을 위해 감사 로그를 활성화하기 전에, 당신은 당신의 저장 목적지에 logpush 작업을 활성화해야합니다. 더 알아보기[자주 묻는 질문](/logs/logpush/logpush-job/enable-destinations/)Cloudflare R2, HTTP, Amazon S3 등과 같은 목적지에 로그인할 수 있습니다.

목적지를 구성하면 사용자 행동에 대한 감사 로그를 설정할 수 있습니다.

1. Cloudflare 대시보드에서**다운로드**사이트 맵

   <DashButton url="/?to=/:account/logs" />

2. 당신의 저장 목적지를 선택하십시오.

3. 3 점 선택 >**제품정보**.

4. 이름 \***logpush 작업 구성**:

- **이름 \***: 이미 전염되지 않은 경우 작업 이름을 입력하십시오.
- **로그인**> 선택**필터링 로그**:
  - **제품정보**: 선택`ResourceType`.
  - **회사연혁**: 선택`starts with`.
  - **제품정보**: 입력`email_security`.

5. 제품정보**제출하기**.

Cloudflare 대시보드를 통해 로그를 볼 수 있습니다.

사이트맵 Gateway는 직원의 개인 식별 정보를 안전하게 처리하는 여러 가지 방법을 제공합니다 (PII). 기본적으로 PII는 Super Administrator 및 사용자를 제외한 모든 권한 역할에 대한 Gateway Activity logs에서 redacted[Cloudflare Zero Trust PII 역할](/cloudflare-one/roles-permissions/#cloudflare-zero-trust-pii)그들에게 할당 된. Super Administrator 만 역할 할당하고 PII를 볼 수있는 권한을 결정 할 수 있습니다. Redacting PII는 PII가 데이터로 로그에 캡처되지 않으며 정보가 손실되지 않습니다.

Cloudflare Zero Trust PII를 추가하거나 제거하려면 조직의 사용자에 대한 역할, 참조[제품정보](/fundamentals/manage-members/roles/). 대안으로, 당신은 선택할 수 있습니다[PII 제외](#exclude-pii)Gateway 활동 로그에서 모든 사용자.

## PII 유형

사이트맵 Gateway는 다음과 같은 유형의 PII를 연결할 수 있습니다.

- 근원 IP
- 사용자 이메일
- 사용자 ID
- 장치 ID
- 사이트 맵
- 회사 소개
- 회사 소개

## PII 제외

PII를 제외한 설정에서 설정하면 Cloudflare 게이트웨이가 직원 PII를 저장하지 않고 활동을 기록합니다. 이 설정 변경은 이전 로그의 PII 저장을 변경하지 않습니다. 이것은 설정이 켜지고 켜지면이 설정이 켜진 동안 캡처 된 로그에 대한 PII 데이터가 없습니다. PII 데이터는 Super Administrator를 포함한 Zero Trust 조직 내에서 모든 역할을 사용할 수 없습니다.

설정에서 PII를 제외하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**교통 정책** > **교통 설정**.
2. 내 계정**교통 기록**, 켜기**로그에서 개인 식별 정보 (PII) 제외**.

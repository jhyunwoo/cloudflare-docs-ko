:::note\[개인 소스 IP 대체]

Gateway logs만 공개 IP 주소를 보여준다.**근원 IP**이름 \* 개인 IP 주소는 네트워크 주소 번역 (NAT)을 통해 공개 IP 주소로 대체됩니다.

:::

Gateway 활동 로그는 개별 DNS 쿼리, 네트워크 패킷 및 HTTP 요청을 표시합니다. Gateway. 또한 암호화를 다운로드 할 수 있습니다[SSH 명령 로그](/cloudflare-one/traffic-policies/network-policies/ssh-logging/)Gateway에 의해 proxied 세션.

Gateway 활동 로그를 보시려면 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/)·**관련 기사** > **로그인**Gateway log의 유형을 선택합니다. 이벤트를 더 자세히 조사하기 위해 개별 행을 선택합니다.

Enterprise 사용자는 더 자세한 로그를 생성할 수 있습니다.[다운로드](/cloudflare-one/insights/logs/logpush/).

## 연락처

기본적으로 Gateway는 DNS 쿼리 및 HTTP 요청을 포함하여 모든 이벤트를 기록합니다. 로그를 비활성화하거나 로그 차단 요청만 선택할 수 있습니다. 이벤트의 유형이 기록되는 것을 사용자 정의하려면 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/)·**교통 정책** > **교통 설정**. 아래**교통 기록** > **교통 활동**DNS, 네트워크 및 HTTP 로그 p참고 자료s를 나타냅니다.

이 설정은 Cloudflare One에 표시된 로그에만 적용됩니다. Logpush 데이터는 필수입니다.

| 이름 \*                    | 제품정보 | 이름 \*                                   |

## 네트워크 로그

:::caution\[일부 연결 로그]
Gateway는 TCP 트래픽을 완료한 연결만 로그합니다. 연결이 완료되지 않은 경우 (SYN ACK없이 TCP SYN과 같은), 게이트웨이는 네트워크 로그에이 트래픽을 로그하지 않습니다.

Gateway는 연결이 실패할 수 있습니다.[네트워크 세션 로그](/logs/logpush/logpush-job/datasets/account/zero_trust_network_sessions/). 이 로그는 Enterprise 사용자를 통해 사용할 수 있습니다.[다운로드](/cloudflare-one/insights/logs/logpush/)또는[그래프QL](/cloudflare-one/insights/analytics/gateway/#graphql-queries).
:::

:::참조

오류에서 HTTP 요청 결과를 할 때 게이트웨이는 내부 문제 해결을 위해 30 일 동안 요청의 첫 번째 512 바이트를 기록합니다. 그렇지 않으면 Gateway는 HTTP body를 로그하지 않습니다.

### 향상된 파일 감지

향상된 파일 감지는 HTTP 트래픽에서 더 많은 파일 정보를 추출하는 옵션 기능입니다. 켜면 Gateway는 HTTP 헤더가 더 큰 정확도와 신뢰성을 제공하기 위해 HTTP body에서 파일 정보를 읽을 것입니다. 이 기능은 file-heavy 조직의 성능에 약간의 영향을 미칠 수 있습니다.

향상된 파일 감지를 켜려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**교통 정책** > **교통 설정**.
2. 내 계정**프록시 및 검사 설정**, 켜기**TLS 해독과 HTTPS 요청 검사**.
3. 내 계정**정책 설정**, 켜기**향상된 파일 감지**.

### Isolate 요청

사용자가 만들 때[관련기관](/cloudflare-one/remote-browser-isolation/isolation-policies/), Gateway는 Isolate 동작으로 isolation을 트리거하는 초기 요청을 기록합니다. 이 요청이 아직 격리되지 않기 때문에,`is_isolated`본문 바로가기`false`. Zero Trust 그 다음 안전하게 격리 된 브라우저에서 사용자에게 결과를 반환합니다. 게이트웨이는 분리된 브라우저에서 모든 요청을 기록합니다.`is_isolated`본문 바로가기`true`.

## 제한 사항

Gateway 앞에 연결이 닫을 경우 트래픽을 검사하고 필터링하면 Gateway는 알려진 행동으로 트래픽을 기록합니다.

게이트웨이 활동 로그는 대시보드에서 사용할 수 없습니다.[고객 메타데이터 경계 (CMB)](/data-localization/metadata-boundary/)Cloudflare Data Localization Suite (DLS) 내에서. CMB를 사용하는 기업 사용자는 아직도 로그를 수출할 수 있습니다[다운로드](/cloudflare-one/insights/logs/logpush/). 자세한 내용은 참조[DLS 제품 호환성](/data-localization/compatibility/#zero-trust).

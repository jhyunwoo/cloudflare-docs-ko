## 1. 기기에 할당 UUIDs

당신은 사용할 필요가[회사연혁](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/)UUID를 할당합니다. 수동으로 할당 할 수 없습니다.

1. 각 기업 기기의 고유 식별자를 생성합니다. UUIDs 선택에 대한 모범 사례는 참조[Android 문서](https://developer.android.com/training/articles/user-data-ids#best-practices-android-identifiers).

2. UUIDs를 MDM 구성 파일로 입력[`unique_client_id`주요 특징](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/#unique_client_id).

## 2. UUIDs 목록 만들기

UUIDs에 기반한 규칙을 만들려면 먼저 해야 합니다.[Gateway 목록](/cloudflare-one/reusable-components/lists/)UUIDs의.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **이름 \***.

2. 제품정보**수동 목록 만들기**또는**CSV 업로드**. 더 큰 팀을 위해, 우리는 CSV를 업로드하거나 Cloudflare를 사용하는 것을 추천합니다[API 엔드포인트](/api/resources/zero_trust/subresources/gateway/subresources/lists/methods/list/).

3. 이 이름이 귀하의 정책을 구성할 때 표시됩니다.

4. 설치하기**목록 유형**으로*장치 ID*.

5. UUIDs of the device your team manages, 또는 CSV 파일을 업로드.

6. 제품정보**제품 정보**.

:::참조

Hyphens는 UUIDs에서 자동적으로 벗깁니다. 예를 들어, 자세 검사는 일치합니다.`123e4567-e89b-12d3-a456-426614174000`으로`123e4567e89b12d3a456426614174000`.
:::

## 3. 자세 검사 가능

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **자주 묻는 질문**.

2. 오시는 길**WARP 클라이언트 체크**선택하기**자주 묻는 질문**.

3. 제품정보**유일한 클라이언트 ID**.

4. 당신은 다음 정보를 위해 신속한 것입니다:
   - **이름 \***: 이 장치 자세 검사에 대한 독특한 이름을 입력하십시오.
   - **운영 체계**: 장치의 운영 체제를 선택하십시오.
   - **이름 \***: 선택[UUIDs 목록](#2-create-a-list-of-uuids).

5. 제품정보**제품 정보**.

6. [계정 만들기](/cloudflare-one/reusable-components/posture-checks/#2-verify-device-posture-checks)자세 검사는 예상 결과를 반환합니다.

이제 디바이스가 UUID를 리스트에 제시하는 경우, Access 또는 Gateway Device posture 정책을 만들 수 있습니다.

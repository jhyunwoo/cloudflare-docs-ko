Require Gateway를 사용하면 Zero Trust 조직에 등록 된 장치에서만 애플리케이션에 액세스 할 수 있습니다. 이름 \*[요구 WARP](/cloudflare-one/reusable-components/posture-checks/warp-client-checks/require-warp/)어떤 WARP 인스턴스(소비자 버전 포함)에 대해 확인하는 경우 Require Gateway는 조직 Cloudflare Gateway 구성에 의해 필터링되는 장치에서 요청을 허용한다. 이 정책은 회사 소유 자산을 보호 할 때 가장 잘 사용됩니다.

## 1. Gateway 확인 가능

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **자주 묻는 질문**.

2. 오시는 길**WARP 클라이언트 체크**선택하기**자주 묻는 질문**.

3. 제품정보**오시는 길**, 다음 선택**제품 정보**.

## 2. 액세스 신청서에 체크 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.

2. Gateway를 필요로 하는 응용 프로그램을 찾습니다. 제품정보**설정하기**.

3. 내 계정**회사연혁**탭, 새로운 액세스 정책을 만들거나 기존 정책을 편집합니다.

4. 정책 빌더에서 사용중인 Include 또는 Require 규칙을 추가하십시오.*오시는 길*옵션 정보 자주 묻는 질문

5. 액세스 응용 프로그램을 저장합니다.

신청에 대한 액세스 권한을 부여하기 전에, 정책은 WARP 클라이언트를 실행하고 Zero Trust 조직에 등록되어있는 것을 확인합니다.

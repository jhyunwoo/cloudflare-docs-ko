## 일련 번호 목록 만들기

장치 일련 번호에 근거를 둔 규칙을 창조하기 위하여, 당신은 첫번째 필요 창조합니다[Gateway 목록](/cloudflare-one/reusable-components/lists/)숫자의.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **이름 \***.

2. 제품정보**수동 목록 만들기**또는**CSV 업로드**. 더 큰 팀을 위해, 우리는 CSV를 업로드하거나 Cloudflare를 사용하는 것을 추천합니다[API 엔드포인트](/api/resources/zero_trust/subresources/gateway/subresources/lists/methods/list/).

3. 이 이름이 귀하의 정책을 구성할 때 표시됩니다.

4. 설치하기**목록 유형**으로*일련 번호*.

5. 귀하의 팀 관리 장치의 일련 번호를 입력하거나 CSV 파일을 업로드하십시오.

6. 제품정보**제품 정보**.

지금 만들 수 있습니다[오시는 길](/cloudflare-one/access-controls/policies/)또는 Gateway[네트워크 정책](/cloudflare-one/traffic-policies/network-policies/common-policies/#enforce-device-posture)기기가 목록에서 일련 번호를 제시하면 확인합니다. 액세스에서 일련 번호 체크가 나타납니다.*장치 자세 - 연속 번호 목록*옵션 정보 Gateway에서 일련 번호 목록이 나타납니다.**제품정보**당신이 선택할 때 dropdown[Passed Device Posture 체크](/cloudflare-one/traffic-policies/network-policies/#device-posture)옵션 정보

## 일련 번호 검증

다음 명령을 사용하여 장치의 일련 번호를 확인할 수 있습니다. 결과, 자세 검사가 예상대로 작동되는 경우 유효한 데 도움이 될 수 있습니다.

### 맥 OS

1. 터미널 창을 엽니다.
2. 사용 방법`system_profiler`명령은의 값을 확인합니다.`SPHardwareDataType`일련 번호를 검색합니다.

   ```sh
   system_profiler SPHardwareDataType | grep 'Serial Number'
   ```

### 윈도우

1. PowerShell 창을 엽니다.
2. 사용 방법`Get-CimInstance`SerialNumber 속성을 얻는 명령`Win32_BIOS`수업.

   ```powershell
   Get-CimInstance Win32_BIOS
   ```

### 리눅스

1. 터미널 창구 열기
2. 사용 방법`dmidecode`버전 속성을 얻는 명령`system-serial-number`.

   ```sh
   sudo dmidecode -s system-serial-number
   ```

### iOS, Android 및 ChromeOS

일련 번호 체크는 모바일 장치에 지원되지 않습니다. 모바일 기기를 식별할 수 있습니다.[고유 클라이언트 ID](/cloudflare-one/reusable-components/posture-checks/warp-client-checks/device-uuid)일련 번호 대신.

안티 바이러스 장치 posture 속성은 바이러스 백신 소프트웨어가 설치되고 장치에 능동적 인 경우 확인합니다. WARP 클라이언트 쿼리[Windows 보안 센터 API](https://learn.microsoft.com/en-us/windows/win32/api/iwscapi/ne-iwscapi-wsc_security_product_state)등록된 보안 제품의 상태를 결정하기 위해. 통과하는 자세 검사를 위해, Windows 보안 센터는 안전 제품이 켜지고 날짜까지 보고해야 합니다.

## 바이러스 백신 검사

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **자주 묻는 질문**.
2. 오시는 길**WARP 클라이언트 체크**선택하기**자주 묻는 질문**.
3. 제품정보**안티 바이러스**.
4. 본문 바로가기
5. 운영 체제를 선택하십시오.
6. (선택) 마지막 안티 바이러스 서명 업데이트 이후 허용되는 최대 일 수를 설정합니다. 장치가 이 제한을 초과하는 경우 (예를 들어, 30 일 설정하지만 마지막 업데이트 이후 31 일), 장치는 자세 검사를 실패합니다.
7. 제품정보**제품 정보**.

다음으로 이동**관련 기사** > **로그인** > **Posture 로그**바이러스 백신 검사가 예상 결과를 반환한다는 것을 확인합니다.

## Antivirus 상태 검증

다음 명령을 사용하여 자세 검사가 예상대로 작동하면 검증할 수 있습니다.

### 윈도우

1. PowerShell 창을 엽니다.

2. Windows Security Center에 등록된 모든 설치된 바이러스 백신 제품 목록:

   ```powershell
   Get-WmiObject -Namespace "root\SecurityCenter2" -ClassName "AntiVirusProduct"
   ```

   ```powershell output
   <redacted>
   displayName              : Windows Defender
   instanceGuid             : {00000000-0000-0000-0000-000000000000}
   pathToSignedProductExe   : windowsdefender://
   pathToSignedReportingExe : %ProgramFiles%\Windows Defender\MsMpeng.exe
   productState             : 397568
   timestamp                : Fri, 09 Jan 2026 12:00:00 GMT
   PSComputerName           : ENDPOINT-01
   ```

3. Microsoft는 해독을 지원하지 않습니다`productState`으로`SecurityCenter2`네임스페이스 바이러스 백신 제품이 활성화되었는지 확인하려면[Windows 보안 앱](https://support.microsoft.com/en-us/windows/stay-protected-with-the-windows-security-app-2ae0363d-0ada-c064-8b56-6a39afb6a963)·**Virus & 위협 보호**패널은 말해야 합니다`No action needed`녹색표시.

   바이러스 백신 제품이 실행되는 것을 결정하려면, 선택**Virus & 위협 보호** > **회사 소개**. 당신은 바이러스 백신 제품의 이름을 볼 것 (예를 들어,`Windows Defender Antivirus`)와 그것의 현재 국가.

4. 당신의 자세 검사에서 최대 바이러스 백신 서명 연령을 구성하면 비교`timestamp`PowerShell에서 현재 시스템 시간에 대한 출력. 차이가 형성된 일 수를 초과하는 경우, 자세 검사는 실패합니다.

## 탄소 검정 검사 구성

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **자주 묻는 질문**.

2. 오시는 길**WARP 클라이언트 체크**선택하기**자주 묻는 질문**.

3. 제품정보**탄소 검정**.

4. 당신은 다음 정보를 위해 신속한 것입니다:
   1. **이름 \***: 이 장치 자세 검사에 대한 독특한 이름을 입력하십시오.
   2. **운영 체계**: 운영 체제를 선택하십시오. 운영 체제 (macOS 및 Windows 현재 지원) 당 하나의 자세 검사를 구성해야합니다.
   3. **신청 방법**: 탄소 검정 공정에 대한 전체 경로 입력 (예를 들어,`c:\program files\CarbonBlack\CarbonBlack.exe`).
   4. **인증 썸프린트 (추천)**: 이진에 서명하는 데 사용되는 출판 인증서의 삭제를 입력합니다. 이것은 이진이 탄소 검정에서 와서 프로세스를 검증하는 것이 좋습니다.
   5. **(선택) SHA-256**: SHA-256 값을 입력합니다. 이것은 바이너리의 SHA256 서명을 검증하고 장치의 바이너리 파일의 무결성을 보장합니다. 참고 : 이 필드를 작성하지 마십시오. 탄소 검정에 대한 업데이트를 엄격하게 제어하지 않고이 버전 사이에 변경됩니다.

다음으로 이동**관련 기사** > **로그인** > **Posture 로그**탄소 검정 검사가 예상 결과를 반환한다는 것을 확인합니다.

## 파일 확인 구성

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **자주 묻는 질문**.

2. 오시는 길**WARP 클라이언트 체크**선택하기**자주 묻는 질문**.

3. 제품정보**파일 확인**.

4. 당신은 다음 정보를 위해 신속한 것입니다:
   1. **이름 \***: 이 장치 자세 검사에 대한 독특한 이름을 입력하십시오.
   2. **운영 체계**: 운영 체제를 선택하십시오.
   3. **파일 경로**: 파일 경로 입력 (예를 들어,`c:\my folder\myfile.exe`).
   4. **인증 썸프린트 (추천)**: 입력[엄지 손가락](/cloudflare-one/reusable-components/posture-checks/warp-client-checks/application-check/#determine-the-signing-thumbprint)파일에 서명하는 데 사용되는 출판 인증서의. 이 정보를 추가하면 예상 소프트웨어 개발자에 의해 파일이 서명되었는지 확인 할 수 있습니다.
   5. **(선택) SHA-256**: 입력[SHA-256 가치](/cloudflare-one/reusable-components/posture-checks/warp-client-checks/application-check/#determine-the-sha-256-value)파일의. 이것은 장치의 파일의 무결성을 보장하기 위해 사용됩니다.

5. 제품정보**제품 정보**.

다음으로 이동**관련 기사** > **로그인** > **Posture 로그**파일 확인은 예상된 결과를 반환한다.

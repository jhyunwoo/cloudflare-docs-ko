## 도메인 가입 확인 가능

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **자주 묻는 질문**.
2. 오시는 길**WARP 클라이언트 체크**선택하기**자주 묻는 질문**.
3. 제품정보**도메인 가입**.
4. 본문 바로가기
5. 운영 체제를 선택하십시오.
6. 확인하려면 도메인을 입력하십시오.`example.com`·
   :::참조
   더 보기**이름 \***&#xD544;드는 case-sensitive입니다. 귀하의 도메인은`example.com`, 입력`Example.com`자세 검사가 실패합니다.
   주요 특징
7. 제품정보**제품 정보**.

다음으로 이동**관련 기사** > **로그인** > **Posture 로그**도메인 가입 확인은 예상 결과를 반환합니다.

## 도메인 값 검증

Windows 장치에 도메인 가치를 확인하려면:

1. PowerShell 창을 엽니다.
2. 다음 명령을 실행:

   ```powershell
   (Get-WmiObject Win32_ComputerSystem).Domain
   ```

명령은 디바이스가 속한 Active Directory 도메인을 반환합니다.

## OS 버전의 결정

다른 방법으로 운영 체제 표시 버전 번호. 이 섹션은 각 OS의 버전 번호를 검색하는 방법을 다룹니다., OS 버전 자세 검사는 무엇을 기대하는 형식.

### 맥 OS

1. 터미널 창을 엽니다.
2. 사용 방법`defaults`명령은의 값을 확인합니다.`SystemVersionStampAsString`.

   ```sh
   defaults read loginwindow SystemVersionStampAsString
   ```

### 윈도우

Windows 버전 번호는 4개 부품으로 이루어져 있습니다:`Major.Minor.Build.UBR`. 예를 들면,`10.0.19045.3803`위치:

- `10.0`이름 \***이름 \***(주) 이름)
- `19045`이름 \***제품정보**이름 \*
- `3803`이름 \***UBR의 장점**(업데이트 빌드 개정)

장치에서 Windows 버전을 결정하려면:

1. PowerShell 창을 엽니다.

2. 더 보기**이름 \***(Major.Minor.). 구조):

   ```bash
   (Get-CimInstance Win32_OperatingSystem).version
   ```

   이 형식의 버전을 반환`Major.Minor.Build`(예:`10.0.19045`).

3. 더 보기**UBR의 장점**(업데이트 빌드 개정):

   ```bash
   (Get-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion" -Name UBR).UBR
   ```

   이 UBR 값을 반환합니다 (예를 들어,`3803`).

### 리눅스

#### OS 버전

Linux OS 버전 체크는 시스템 커널 버전을 읽습니다.

1. 터미널 창을 엽니다.

2. 시작하기`uname -r`완전한 커널 버전을 얻는 명령. 예를 들어,

   ```sh
   $ uname -r
   5.14.0-25.el9.x86_64
   ```

3. **이름 \***&#x53;emVer 형식의 출력의 첫 번째 세 숫자입니다 (`5.14.0`).

4. **패치 버전**SemVer 후 첫 번째 숫자입니다 (`25`).

#### Distro 버전

WARP 클라이언트 읽기**Distro 이름**·**Distro 개정**으로`/etc/os-release`파일. 이름에서 온다**이름 \***&#xD544;드와 개정은**다운로드**이름 \*

장치에서 Linux distro 버전을 결정하려면:

1. 터미널 창을 엽니다.

2. 포함 된 OS 식별 필드를 가져옵니다`ID`:

   ```sh
   cat /etc/os-release | grep "ID"
   ```

3. 위의 명령의 출력이 포함된 경우`ID=ubuntu`·`VERSION_ID=22.04`, **Distro 이름**할 수있다`ubuntu`·**Distro 개정**할 수있다`22.04`. WARP 클라이언트는 정확한 일치를 위한 이 끈을 검사할 것입니다.

### 크롬 OS

ChromeOS 버전 번호는 이루어져 있습니다[4개 부품](https://www.chromium.org/developers/version-numbers/): `MAJOR.MINOR.BUILD.PATCH`. OS 버전 자세 검사 반환`MAJOR.MINOR.BUILD`.

장치에서 ChromeOS 버전을 결정하려면:

1. Chrome 브라우저를 열고 이동`chrome://system`.
2. 다음 값 찾기:
   | 회사 정보                               | OS 버전 구성 |
   | ----------------------------------- | -------- |
   | `CHROMEOS_RELEASE_CHROME_MILESTONE` | `MAJOR`  |
   | `CHROMEOS_RELEASE_BUILD_NUMBER`     | `MINOR`  |
   | `CHROMEOS_RELEASE_BRANCH_NUMBER`    | `BUILD`  |
3. Semver 형식의 OS 버전은`MAJOR.MINOR.BUILD`(예:`103.14816.131`).

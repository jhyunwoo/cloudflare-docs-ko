## 디스크 암호화 체크 활성화

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **자주 묻는 질문**.
2. 오시는 길**WARP 클라이언트 체크**선택하기**자주 묻는 질문**.
3. 제품정보**디스크 암호화**.
4. 본문 바로가기
5. 운영 체제를 선택하십시오.
6. 모든 볼륨에 대한 디스크 암호화를 활성화하거나 암호화를 확인하려는 특정 볼륨 (들)을 입력합니다 (예를 들어,`C`).
7. 제품정보**제품 정보**.

다음으로 이동**관련 기사** > **로그인** > **Posture 로그**디스크 암호화 체크가 예상된 결과를 반환한다는 것을 확인합니다.

## Validate 디스크 암호화 상태

뒤에 오는 명령은 각종 운영 체계에 디스크 암호화 상태를 돌려보낼 것입니다. 결과, 자세 검사가 예상대로 작동되는 경우 유효한 데 도움이 될 수 있습니다.

### 맥 OS

1. 터미널 창을 엽니다.

2. 시작하기`/usr/sbin/system_profiler SPStorageDataType`시스템에서 드라이버의 목록을 반환하고 값에 주의**산 점**.

   ```sh
   /usr/sbin/system_profiler SPStorageDataType
   ```

   ```sh output
   Storage:

      Data:

        Free: 428.52 GB (428,519,702,528 bytes)
        Capacity: 494.38 GB (494,384,795,648 bytes)
        Mount Point: /System/Volumes/Data
   ```

3. 시작하기`diskutil info`특정 명령**산 점**반환된 값을 찾습니다.**파일Vault**. 그것은 보여주어야 합니다**이름 \***&#xC554;호화 된 것으로 간주되는 디스크에 대한.

   ```sh
   diskutil info /System/Volumes/Data | grep FileVault
   ```

   ```sh output
    FileVault:                 Yes
   ```

### 윈도우

1. PowerShell 창을 엽니다.
2. 시작하기`Get-BitLockerVolume`시스템에서 검출되는 모든 볼륨을 나열하는 명령.
3. **보호 상태**설정하기**이름 \***&#xC554;호화 된 것으로 간주되는 디스크에 대한.

### 리눅스

시스템에 모든 하드 드라이브를 나열:

```sh
lsblk
```

```sh output
NAME                        MAJ:MIN RM   SIZE RO TYPE  MOUNTPOINT
nvme0n1                     259:0    0 476.9G  0 disk
├─nvme0n1p1                 259:1    0   512M  0 part  /boot/efi
├─nvme0n1p2                 259:2    0   488M  0 part  /boot
└─nvme0n1p3                 259:3    0   476G  0 part
  └─nvme0n1p3_crypt         253:0    0 475.9G  0 crypt
    ├─my--vg-root   253:1            0 474.9G  0 lvm   /
    └─my--vg-swap_1 253:2            0   976M  0 lvm   [SWAP]
```

Linux에서 암호화는 장착 된 파티션 당보고되어 물리적 드라이브가 아닙니다. 위의 예에서 루트 및 스왑 파티션은 암호화되어 있기 때문에 그들은 내부에 위치`crypt`컨테이너. 더 보기`/boot`·`/boot/efi`파티션은 암호화되지 않습니다.

### iOS, Android 및 ChromeOS

이 플랫폼은 항상 암호화되어 있으므로 디스크 암호화 체크가 지원되지 않습니다.

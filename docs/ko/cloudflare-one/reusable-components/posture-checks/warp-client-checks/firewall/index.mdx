## 방화벽 확인 사용

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **자주 묻는 질문**.
2. 오시는 길**WARP 클라이언트 체크**선택하기**자주 묻는 질문**.
3. 제품정보**비밀번호**.
4. 본문 바로가기
5. 운영 체제를 선택하십시오.
6. 설정하기**Enable 방화벽 확인**원하는 보안 정책을 기반으로:

   - **이름 \***: (추천) posture check는 방화벽이 실행되는 경우에만 통과합니다.
   - **지원하다**: posture check는 방화벽이 꺼져 있는 경우에만 통과합니다.

   :::참조
   더 보기**Enable 방화벽 확인**toggle는 posture 체크를 켜지 않습니다. 오히려, toggle는 WARP 클라이언트가 활성 또는 비활성 방화벽을 찾습니다.
   주요 특징
7. 제품정보**제품 정보**.

다음으로 이동**관련 기사** > **로그인** > **Posture 로그**방화벽 검사가 예상 결과를 반환한다는 것을 확인합니다.

## 방화벽 상태 검증

운영 체제는 다양한 방법으로 방화벽 구성을 결정합니다. WARP 클라이언트가 방화벽이 활성화되었는지 이해하기 위해 아래의 단계를 따르십시오.

### macOS에서

macOS에는 두 개의 방화벽이 있습니다. 애플리케이션 기반 방화벽 및 포트 기반 방화벽. WARP 클라이언트는 방화벽이 실행되면 방화벽이 활성화됩니다.

#### Application 기반 방화벽

1. 기타**시스템 설정**·**회사연혁**.
2. 그대는**비밀번호**이름 \*`Active`.

#### 포트 기반 방화벽

1. 터미널을 열고 실행:

   ```sh
   sudo /sbin/pfctl -s info
   ```

2. 그대는**주요연혁**이름 \*`Enabled`.

### Windows에서

1. PowerShell을 열고 실행하십시오:

   ```powershell
   Get-NetFirewallProfile -PolicyStore ActiveStore -Name Public
   ```

2. 그대는**이름 \***&#xC774;름 \*`True`.

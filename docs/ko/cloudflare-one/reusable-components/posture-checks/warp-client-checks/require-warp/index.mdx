이 장치 자세 특성은 소비자 버전을 포함하여 WARP의 모든 버전을 검사합니다.

:::

사이트맵 Cloudflare WARP 클라이언트를 실행하는 장치에 대한 액세스를 제한 할 수 있습니다. 이 사용자는 Cloudflare One 뒤에 보호되는 자원에 접근을 허용하기 전에 사용자의 트래픽이 안전하고 암호화된다는 것을 유연하게 보장 할 수 있습니다.

## 1. WARP 검사 가능

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**교통 정책** > **교통 설정**.
2. 견적 요청*Secure Web Gateway를 프록시 트래픽으로 허용*\* 사용 가능
3. 오시는 길**재사용 가능한 부품** > **자주 묻는 질문**.
4. 내 계정**WARP 클라이언트 체크**, 선택**자주 묻는 질문**.
5. 제품정보**사이트맵**, 다음 선택**제품 정보**.

## 2. 액세스 정책에 체크 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.

2. WARP를 요구하는 응용 프로그램을 찾습니다. 제품정보**설정하기**.

3. 내 계정**회사연혁**탭, 새로운 액세스 정책을 만들거나 기존 정책을 편집합니다.

4. 정책 빌더에서 사용중인 Include 또는 Require 규칙을 추가하십시오.*사이트맵*옵션 정보 자주 묻는 질문

5. 액세스 응용 프로그램을 저장합니다.

응용 프로그램에 액세스 권한을 부여하기 전에, 정책은 WARP 클라이언트를 실행하는 것을 확인한다.

## 앱 확인 구성

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **자주 묻는 질문**.

2. 오시는 길**WARP 클라이언트 체크**선택하기**자주 묻는 질문**.

3. 제품정보**관련 상품**.

4. 당신은 다음 정보를 위해 신속한 것입니다:

   1. **이름 \***: 이 장치 자세 검사에 대한 독특한 이름을 입력하십시오.
   2. **운영 체계**: 운영 체제를 선택하십시오.
   3. **신청 경로**: 실행중인 실행 가능한 파일 경로 입력 (예를 들어,`C:\Program Files\myfolder\myfile.exe`).

   :::참조

   - 이진 파일 경로에 들어가려면 애플리케이션 실행 경로가 아닙니다. macOS에서 응용 프로그램을 확인하면 일반적인 실수가 입력됩니다.`/Applications/ApplicationName.app`. 이것은 작동하지 않을 것입니다`ApplicationName.app`폴더입니다. 실행중인 실행 가능한 파일은 폴더 내에서, 예를 들어`ApplicationName.app/Contents/MacOS/ApplicationName`.
   - 일부 응용 프로그램은 업데이트 후 파일 경로 변경. 응용 프로그램은 항상 안정적인 위치에 있으며 특정 폴더를 식별 할 수있는 환경 변수를 사용합니다. 예를 들면, Windows는 제공합니다[인증된 환경 변수](https://learn.microsoft.com/en-us/windows/deployment/usmt/usmt-recognized-environment-variables)파일 경로에서 참고 자료 할 수 있습니다 (`%PROGRAMFILES%\myfolder\myfile.exe`).
     :::

5. **인증 썸프린트 (추천)**: 입력[출판 증명서의 축소](#determine-the-signing-thumbprint)바이너리에 서명하는 데 사용됩니다. 이 정보를 추가하면 해당 응용 프로그램이 예상 소프트웨어 개발자에 의해 서명되었는지 확인 할 수 있습니다.

6. **(선택) SHA-256**: 입력[SHA-256 가치](#determine-the-sha-256-value)이진의. 이것은 장치의 바이너리 파일의 완전성을 보장하는 데 사용됩니다.

7. 제품정보**제품 정보**.

다음으로 이동**관련 기사** > **로그인** > **Posture 로그**신청 확인은 예상 결과를 반환합니다.

## 서명 엄지 인쇄를 결정하십시오

응용 프로그램의 표시 엄지를 결정하는 과정은 운영 체제에 따라 다릅니다. 이것은 macOS 및 Windows에서 Cloudflare WARP 응용 프로그램의 서명 썸프를 볼 수있는 방법입니다.

:::참조

새로운 장치 자세 검사를 설정할 때 인증서 엄지 인쇄 또는 SHA256 체크섬 값을 설정하지 않고 먼저 테스트를 권장합니다.

:::

### 맥 OS

1. 디렉토리를 만듭니다.

   ```bash
   ~/Desktop $ mkdir tmp

   ~/Desktop $ cd tmp
   ```

2. WARP 응용 프로그램에 대한 인증서를 추출하려면 다음 명령을 실행하십시오.

   ```sh
   ~/Desktop/tmp $ codesign -d --extract-certificates "/Applications/Cloudflare WARP.app/Contents/Resources/CloudflareWARP"
   Executable=/Applications/Cloudflare WARP.app/Contents/Resources/CloudflareWARP
   ```

3. 다음, 다음 명령을 실행하여 SHA1 thumbprint를 추출하십시오.

   ```sh
   ~/Desktop/tmp $ openssl x509 -inform DER -in codesign0 -fingerprint -sha1 -noout | tr -d :
   SHA1 Fingerprint=FE2C359D79D4CEAE6BDF7EFB507326C6B4E2436E
   ```

### 윈도우

1. PowerShell 창을 엽니다.
2. 사용 방법`Get-AuthenticodeSignature`썸프린트를 찾을 명령. 예를 들면:

   ```powershell
   Get-AuthenticodeSignature -FilePath c:\myfile.exe
   ```

## SHA-256 값의 결정

SHA-256 값은 거의 항상 파일 / 응용 프로그램의 버전 사이에 변경됩니다.

### 맥 OS

1. 터미널 창을 엽니다.
2. 사용 방법`shasum`파일의 SHA256 값을 찾을 명령. 예를 들면:

   ```sh
   shasum -a 256 myfile
   ```

### 윈도우

1. PowerShell 창을 엽니다.
2. 사용 방법`get-filehash`파일의 SHA256 값을 찾을 명령. 예를 들면:

   ```powershell
   get-filehash -path "C:\myfile.exe" -Algorithm SHA256 | format-list
   ```

## WARP가 신청하는 방법

WARP 클라이언트가 다양한 시스템에서 실행되는 경우 어떻게 결정하는지 알아보세요.

### 맥 OS

활성 프로세스의 목록을 얻으려면 다음 명령을 실행하십시오.

```sh
ps -eo comm | xargs -I {} which "{}" | sort | uniq | xargs -I {} realpath "{}"
```

신청 경로는 합격을 위한 산출에서 나타납니다.

### 리눅스

WARP 클라이언트는 연약한 연결에 의하여 실행 궤의 명부를 안으로 가져옵니다`/proc/<pid>/exe`. 모든 활성 프로세스와 부드러운 링크보기 :

```sh
ps -eo pid | awk '{print "/proc/"$1"/exe"}' | xargs readlink -f | awk '{print $1}' | sort | uniq
```

신청 경로가 나타납니다.`/proc/<pid>/exe`패스를 위한 출력.

### 윈도우

활성 프로세스의 목록을 얻으려면 다음 명령을 실행하십시오.

```powershell
Get-Process | Select-Object ProcessName, Path | Format-Table -AutoSize
```

신청 경로는 합격을 위한 산출에서 나타납니다.

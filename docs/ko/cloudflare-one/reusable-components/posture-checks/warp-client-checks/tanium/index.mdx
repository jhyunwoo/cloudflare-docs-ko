## Cloudflare 액세스와 Tanium 통합

:::참조

통합은 현재 Safari를 지원하지 않습니다.

:::

1. Tanium 배포 구성[단계별 문서](https://docs.tanium.com/endpoint_identity/endpoint_identity/userguide.html)지원하다 Cloudflare Access로 Tanium 배포를 통합하는 공공 키가 필요합니다.

2. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **자주 묻는 질문**.

3. 오시는 길**WARP 클라이언트 체크**선택하기**자주 묻는 질문**.

4. 제품정보**사이트맵**공급자 목록에서.

5. 이름 \***이름 \***&#xD1B5;합을 위해.

6. 제품 정보**항구 항구**, 입력`17472`.

   이 Tanium endpoints에 의해 사용되는 기본 포트는 Cloudflare Access로 인바운드 및 아웃바운드를 전달합니다. 조직의 배포를 반영하기 위해 수정해야 할 수도 있습니다.

7. 단계 1에서 생성 된 공공 인증서 입력

   인증서를 추가하면 Cloudflare가 Tanium 에이전트의 응답이 유효합니다.

지금 구축 할 수 있습니다[오시는 길](/cloudflare-one/access-controls/policies/)확인하기[장치 자세 신호](#tanium-endpoint-signals)Tanium 엔드포인트에서.

## 예제 액세스 정책

이 예제는 팀의 이메일 도메인의 일부이며 Tanium 에이전트를 실행하는 사용자에게만 권한을 부여합니다.

| - 연혁 | 규칙 유형 | 옵션 정보          | 제품정보        |
| ---- | ----- | -------------- | ----------- |
| 지원하다 | 이름 \* | 이메일 Ending     | `@team.com` |
|      | 이름 \* | 장치 자세 - Tanium | `Managed`   |

Tanium 규칙은 장치 연결이 Tanium 배포에서 관리되고 마지막 7 일에서 Tanium 서버로 검사해야합니다.

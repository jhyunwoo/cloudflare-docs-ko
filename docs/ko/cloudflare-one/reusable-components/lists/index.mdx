Cloudflare로 하나는 URL, hostnames 또는 참고 자료에 다른 항목의 목록을 만들 수 있습니다.[Gateway 정책](/cloudflare-one/traffic-policies/)또는[오시는 길](/cloudflare-one/access-controls/policies/). 이것은 신속하게 일치하고 여러 항목에 대해 작업을 수행 할 수있는 규칙을 만들 수 있습니다.

목록을 만들기 전에, 주의를[제한 사항](#limitations).

:::참조
이 페이지에서 설명된 목록은 동일하지 않습니다.[주문 목록](/waf/tools/lists/custom-lists/)계정 수준에서 정의. 두 가지 유형의 목록은 다른 데이터 유형과 다른 검증 규칙을 지원합니다.
주요 특징

## 회사 소개

목록은 각각 하나의 유형의 데이터를 포함 할 수 있습니다. 지원된 자료 유형은 다음을 포함합니다:

- 사이트 맵
- 호스트 이름 또는 도메인
- 일련 번호
- 사용자 이메일 주소
- IP 주소
- 장치 ID 번호

## 자주 묻는 질문

1. 내 계정**이름 \***&#xD398;이지, 편집하려는 목록을 찾습니다.

2. 제품정보**제품정보**. 이것은 당신을 허용할 것입니다:
   - 목록 이름과 설명을 편집하여 세 가지 점 메뉴를 목록의 이름 오른쪽으로 선택합니다.
   - 목록 이름의 오른쪽에 세 가지 점 메뉴를 선택하여 목록을 삭제합니다.
   - 개별 항목 삭제.
   - 수동으로 귀하의 목록에 항목을 추가합니다.

3. 목록을 편집 한 후, 선택**제품 정보**.

## 제한 사항

### 회사연혁

귀하의 목록은 최대 1,000 항목의 표준 계획 및 5,000 엔터프라이즈 플랜을 포함 할 수 있습니다. 업로드된 CSV 파일은 2MB 미만이어야 합니다.

### Wildcard 항목

Hostname 목록은 Wildcard 항목을 지원하지 않습니다 (`*.example.com`). 정확한 일치로 도메인을 추가해야합니다. hostnames를 구성하는 리스트에 와일드카드를 추가하면 저장할 때 오류가 반환됩니다.

### 비 라틴 문자

Gateway는 모든 도메인과 호스트명을 변환하여 비 라틴 문자를 지원합니다.[뚱 베어](https://www.rfc-editor.org/rfc/rfc3492.txt). 비 라틴 문자로 목록을 저장하면 게이트웨이가 Punycode로 항목을 표시합니다.

### 중복 항목

목록은 중복 항목이 없습니다. 도메인 및 호스트 이름이 변환되기 때문에[뚱 베어](#non-latin-characters)동일한 문자열로 변환하는 여러 목록 항목은 중복으로 계산됩니다. 예를 들어,`éxàmple.com`변환하기`xn—xmple-rqa5d.com`둘 다를 포함하여`éxàmple.com`·`xn—xmple-rqa5d.com`목록에서 중복 오류가 발생합니다.

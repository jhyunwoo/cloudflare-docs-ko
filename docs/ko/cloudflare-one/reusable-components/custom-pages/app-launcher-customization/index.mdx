Pay-as-you-go 및 Enterprise 플랜에서만 사용할 수 있습니다.
주요 특징

자신의 브랜딩, 메시지 및 사용자가 열 때 링크를 표시 할 수 있습니다.[앱 실행기](/cloudflare-one/access-controls/access-settings/app-launcher/).

App Launcher 외관을 사용자 정의하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**재사용 가능한 부품** > **주문 페이지**.
2. 자주 묻는 질문**App Launcher 사용자 정의**설정 및 선택**계정 관리**.
3. App Launcher를 추가하여 조직의 모습과 느낌을 주기:
   - 조직의 이름
   - 로고
   - 헤더에 대한 선호 배경 색상
   - 페이지의 선호 배경 색상
   - 조직의 도움 책상 또는 다른 내부 자원에 대한 링크가있는 사용자 정의 발기.

:::참조

글꼴 기본적으로 검은 색 때문에 더 가벼운 배경 색상을 권장합니다.
주요 특징

4. 다음, 사용자가 App Launcher에 로그인 할 때 방문 페이지를 사용자 정의합니다. 사용 가능한 속성:

   - 주문 제목
   - 주문 자막
   - 이미지
   - 선호하는 색상**로그인**이름 \*
   - 선호하는 색상**로그인**버튼 텍스트

   단계 3에서 구성 된 모든 속성은 착륙 페이지로 적용합니다.

5. 사용자 정의에 만족하면, 선택**제품 정보**.

App Launcher 화면이 업데이트되었습니다. 변경 사항 보기**다운로드**.

사이트맵 액세스는 보안 및 IT 팀이 액세스 응용 프로그램에 로그인 한 후 목적 정당화 화면을 직접 제시 할 수 있습니다. 이것은 조직이 자신의 리소스에 액세스 할뿐만 아니라, 왜 그들은 접근을 요청하는지.

목적 justification 스크린은 신청의 어떤 새로운 회의를 위해 보여줄 것입니다. 예를 들어, 액세스 응용 프로그램이 8 시간의 세션 시간을 가지고 있다면 사용자는 8 시간마다 한 번 목적을 정당화 화면을 볼 수 있습니다.

Configuring the purpose justification screen is done as part of configuring the Access policy.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 응용 프로그램을 선택하고 선택**설정하기**.
3. 오시는 길**회사연혁**.
4. 자주 묻는 질문**지원하다**정책 및 선택**설정하기**.
5. 이름 \***추가 설정**, 켜기**회사 소개**.
6. (선택 사항) 사용자 정의 목적 justification 메시지를 설정합니다. 이것은 목적 justification 스크린에 나타나고 사용자에 볼 것입니다.
7. 자주 묻는 질문

이 정책과 일치하는 사용자는 다음 화면을 볼 수 있습니다 :

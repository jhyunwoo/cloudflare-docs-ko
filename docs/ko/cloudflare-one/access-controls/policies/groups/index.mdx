규칙 그룹은 한 번 구성 할 수있는 액세스 규칙의 컬렉션이며 많은 액세스 정책에 신속하게 적용됩니다. 규칙 그룹은 동일합니다[규칙 유형](/cloudflare-one/access-controls/policies/#rule-types)·[회사 소개](/cloudflare-one/access-controls/policies/#selectors)Access Policy 빌더에 표시됩니다.

:::참조
규칙 그룹은 Okta 그룹과 같은 정체성 공급자에서 구별됩니다. 규칙 그룹은 개별 사용자의 혼합을 포함 할 수 있습니다, ID 공급자 그룹, 서비스 토큰과 같은 서비스 인증 옵션.

## 사용 사례

### IP 기반 규칙

우리는 규칙 그룹을 사용하여 정책에 구성하는 IP 주소 기반 규칙을 정의하는 것이 좋습니다. IP 주소를 한 곳에서 유지하면 각 정책보다 한 번 주소를 수정하거나 제거 할 수 있으며 실수의 잠재력을 감소시킵니다.

:::참조
하나의 IP 주소 또는 규칙 그룹에 범위를 추가하면 IP에 대한 포함 규칙을 사용합니다. 당신은 규칙을 사용하지 않는 경우, 정책은 모든 범위에서 시작 트래픽을 필요로한다.
주요 특징

### 국가 요구 사항

허용하거나 차단할 국가로 구성된 규칙 그룹을 만들 수 있습니다. 액세스는 OR 논리 연산자와 함께 규칙에 국가를 취급합니다. 액세스 응용 프로그램에 대한 정책을 구축 할 때, 이 규칙 그룹을 Require 정책에 할당 할 수 있습니다 적어도 그룹 내부의 국가. 예를 들어, 참조[OR 연산자와 규칙을 요구](/cloudflare-one/access-controls/policies/#require-rules-with-or-operators).

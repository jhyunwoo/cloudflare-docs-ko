액세스 정책에 의해 보호 된 URL을 정의합니다. 자체 호스팅 응용 프로그램을 추가 할 때 액세스에, 당신은 그것의 apex 도메인에 입력하여 전체 웹 사이트를 보호 할 수 있습니다, 또는 대안으로, 특정 하위 도메인과 경로 보호.

## 정책 상속

Cloudflare Zero Trust는 루트 경로를 공유하는 응용 프로그램의 부품에 대한 독특한 규칙을 만들 수 있습니다. 예를 들어 애플리케이션이 배포됩니다.`dashboard.com/eng`엔지니어링 팀에 누구든지 접근 할 수 있어야합니다. 그러나, 도구에 배치`dashboard.com/eng/exec`임원팀에 접속해야 합니다.

여러 규칙이 일반적인 루트 경로에 설정되면 더 구체적인 규칙이 우선합니다. 예를 들어, 규칙을 설정할 때`dashboard.com/eng`·`dashboard.com/eng/exec`별도로, 더 구체적인 규칙`dashboard.com/eng/exec`선지자, 규칙이 상속되지 않습니다.`dashboard.com/eng`. 별도의 경우, 특정 규칙은 설정`dashboard.com/eng/exec`, 그것은 어떤 규칙 세트를 상속할 것입니다`dashboard.com/eng`.

## 와일드카드

특정 하위 도메인 또는 경로에 대한 응용 프로그램을 만들 때, 당신은 asterisks를 사용할 수 있습니다 (`*`) 와일드 카드로. Wildcards는 주어진 apex 도메인에서 여러 하위 도메인 또는 경로로 만들 수있는 응용 프로그램을 확장 할 수 있습니다.

### 이름 \*

#### apex 도메인의 모든 하위 도메인 일치

와일드 카드**이름 \***&#xD544;드는 특정 하위 도메인 수준만 일치합니다. 하위 도메인의 apex 도메인 또는 여러 레벨을 커버하지 않습니다. 여러 하위 도메인 수준을 커버하려는 경우 여러 와일드 카드를 사용할 수 있습니다.

| 제품 설명           | 회사 소개                                         | 커버하지 않음                                    |
| --------------- | --------------------------------------------- | ------------------------------------------ |
| `*.example.com` | `alpha.example.com` <br /> `beta.example.com` | `example.com` <br /> `foo.bar.example.com` |

#### apex 도메인의 모든 경로 일치

apex 도메인을 보호하고 아래 경로의 모든, 떠나**오시는 길**빈 필드. 대안으로, 와일드 카드를 사용**오시는 길**이름 \*

| 제품 설명                                 | 회사 소개                                                              | 커버하지 않음             |
| ------------------------------------- | ------------------------------------------------------------------ | ------------------- |
| `example.com` <br />또는`example.com/*` | `example.com` <br /> `example.com/alpha` <br /> `example.com/beta` | `alpha.example.com` |

#### 경기 멀티 레벨 하위 도메인

와일드카드 사용**이름 \***&#xD544;드는 부모 하위 도메인 또는 apex 도메인을 커버하지 않습니다.

| 제품 설명                | 회사 소개                                                   | 커버하지 않음                                  |
| -------------------- | ------------------------------------------------------- | ---------------------------------------- |
| `*.test.example.com` | `alpha.test.example.com` <br /> `beta.test.example.com` | `test.example.com`  <br /> `example.com` |

#### 부분적으로 일치 subdomains

시작 또는 끝에서 와일드 카드를 사용**이름 \***&#xD544;드는 하위 도메인의 여러 수준을 커버하지 않습니다.

| 제품 설명               | 회사 소개                                             | 커버하지 않음                 |
| ------------------- | ------------------------------------------------- | ----------------------- |
| `*test.example.com` | `test.example.com` <br /> `alphatest.example.com` | `beta.test.example.com` |

#### 멀티 레벨 경로 일치

와일드카드 사용**오시는 길**필드는 부모 경로 또는 apex 도메인을 커버하지 않습니다.

| 제품 설명                 | 회사 소개                                                  | 커버하지 않음                                  |
| --------------------- | ------------------------------------------------------ | ---------------------------------------- |
| `example.com/alpha/*` | `example.com/alpha/one` <br /> `example.com/alpha/two` | `example.com/alpha` <br /> `example.com` |

#### 부분적으로 일치 경로

와일드카드 사용**오시는 길**필드는 URL의 여러 세그먼트를 다룹니다.

| 제품 설명                  | 회사 소개                                                                                  |
| ---------------------- | -------------------------------------------------------------------------------------- |
| `example.com/foo*/bar` | `example.com/foo/bar`<br /> `example.com/food/bar` <br /> `example.com/food/stuff/bar` |

### 제한 사항

- 각 점에서 가장 하나의 와일드 카드에서**이름 \***. 예를 들면,`foo*bar*baz.example.com`허용되지 않습니다.
- 각 슬래시 사이에 가장 하나의 와일드 카드에서**오시는 길**. 예를 들면,`example.com/foo*bar*baz`허용되지 않습니다.

## Subdomain 설정

[Subdomain 설정](/dns/zone-setups/subdomain-setup/)부모 도메인에서 별도로 아이 도메인을 관리 할 수 있습니다. 액세스 애플리케이션 경로에서 구성 된 어린이 도메인이 나타납니다.**이름 \***&#xB4DC;롭다운 메뉴. 당신은[하위 도메인을 분할](/dns/zone-setups/subdomain-setup/setup/)이미 액세스 응용 프로그램을 가지고, 당신은 새로운 아이 도메인과 연계하는 액세스 응용 프로그램을 다시해야합니다.

## 지원된 URL

### 항구 번호

포트 번호는 액세스 애플리케이션 경로에서 지원되지 않습니다. URL에 포트 번호가 포함된 경우, 액세스는 포트 번호를 스트립하고 기본 HTTP / HTTPS 포트에 요청을 리디렉션합니다.

### Query 문자열

Query 문자열 (예 :`?foo=bar`) 액세스 애플리케이션 경로에서 지원되지 않습니다.

### 앵커 링크

앵커 링크가 브라우저에 의해 처리되고 서버가 아닌, 액세스 응용 프로그램은 지원하지 않습니다`#`URL의 문자. 예를 들어, 요청`dashboard.com/#settings`관련 기사`dashboard.com`.

액세스 정책으로, 사용자가 안전한 자체 호스팅 응용 프로그램을 열 수 있습니다[원격 브라우저](/cloudflare-one/remote-browser-isolation/). 리모트 브라우저가 우리의 Secure Web Gateway 플랫폼에 직접 통합되기 때문에,[HTTP 정책](/cloudflare-one/traffic-policies/http-policies/)WARP 클라이언트를 설치하는 필요 없이 고립된 신청에 적용될 수 있습니다. 이로 인해 내부 애플리케이션을 관리하지 않는 사용자에게 배포할 수 있습니다.

## 고립된 신청을 위한 정책

고립된 접근 신청에 교통은 당신의 출입구에 의해 거릅니다[HTTP 정책](/cloudflare-one/traffic-policies/http-policies/). 유용한 정책은 다음과 같습니다 :

- [Identity 기반 정책](/cloudflare-one/traffic-policies/identity-selectors/)사용자 ID를 기반으로 요청을 허용하거나 차단합니다.
- [데이터 손실 방지 정책](/cloudflare-one/data-loss-prevention/)민감한 데이터의 로그 또는 차단 전송.
- [고립 정책](/cloudflare-one/remote-browser-isolation/isolation-policies/)복사 / 붙여넣기, 인쇄 또는 파일 다운로드와 같은 브라우저 작업을 비활성화합니다.

예를 들어, 신청서가 호스팅되는 경우`internal.site.com`, 다음 정책 블록 사용자가 원격 브라우저 내에서 신용 카드 번호를 업로드하고 다운로드 :

| 옵션 정보   | 회사연혁 | 제품정보                    | 로그인   | - 연혁 |
| ------- | ---- | ----------------------- | ----- | ---- |
| 이름 \*   | 내 계정 | `internal.site.com`     | 이름 \* | 제품정보 |
| DLP 프로필 | 내 계정 | `Financial Information` |       |      |

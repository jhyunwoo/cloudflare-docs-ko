Cloudflare가 당신의 근원에 요구를 보낼 때, 요구는 포함합니다[앱 토큰](/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/application-token/)한국어`Cf-Access-Jwt-Assertion`요청 헤더. 브라우저를 통해 만든 요청은 토큰을 토큰으로 전달합니다.`CF_Authorization`사이트 맵

Cloudflare는 귀하의 계정에 고유 한 키 쌍을 가진 토큰을 나타냅니다. 공개 키로 토큰을 유효성 검사해야 합니다. 요청은 액세스에서 와서 악의적인 제3자가 아닙니다. 우리는 유효한 것을 추천합니다`Cf-Access-Jwt-Assertion`대신 헤더`CF_Authorization`쿠키는 전달되지 않습니다.

## 접근 표시 열쇠

signing 열쇠 쌍을 위한 공중 열쇠는 안으로 있습니다`https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/certs`, 어디`<your-team-name>`Cloudflare는 한국어<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>.

기본적으로 액세스는 매 6 주마다 서명 키를 회전합니다. 이것은 프로그래밍 또는 수동으로 키를 회전으로 업데이트해야합니다. 이전 키는 교체 후 7 일 동안 유효하며 업데이트를 만들 수 있습니다.

키를 수동으로 회전 할 수 있습니다.[사이트맵](/api/resources/zero_trust/subresources/access/subresources/keys/methods/rotate/). 이것은 시험 또는 안전 목적을 위해 행해질 수 있습니다.

아래 예시로,`https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/certs`두 개의 공공 키가 포함되어 있습니다. 새로운 토큰을 서명하는 데 사용되는 현재 키와 이전 키가 회전되었습니다.

- `keys`: JWK 형식의 키 모두
- `public_cert`: PEM 형식의 현재 키
- `public_certs`: PEM 형식의 키 모두

## JWT를 수동으로 검증

토큰을 수동으로 확인하려면:

1. JWT를 복사`Cf-Access-Jwt-Assertion`요청 헤더.

2. 오시는 길[사이트맵](https://jwt.io/).

3. RS256 알고리즘을 선택합니다.

4. JWT를 붙여넣기**이름 \***&#xC0C1;자.

5. 내 계정**지불로드**상자는, 그것을 지킵니다`iss`팀 도메인에 필드 포인트 (`https://<your-team-name>.cloudflareaccess.com`). `jwt.io`사용 방법`iss`토큰 유효성에 대한 공개 키를 fetch합니다.

6. 페이지가 말한다**서명 확인**.

이 요청이 액세스에 의해 전송 된 것을 믿을 수 있습니다.

## Programmatic 검증

기존 서버에서 자동 스크립트를 실행할 수 있습니다. 샘플 코드는 요청에서 애플리케이션 토큰을 얻고 공개 키에 대한 서명을 확인합니다. 자신의 팀 도메인 및 응용 프로그램 Audience (AUD) 태그를 샘플 코드에 삽입해야합니다.

### AUD 태그 받기

사이트맵 액세스는 각 응용 프로그램에 고유 한 AUD 태그를 할당합니다. 더 보기`aud`JWT를 적용하는 토큰 탑재량에 대한 청구는 유효합니다.

AUD 태그를 얻으려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**액세스 제어** > **이름 \***.
2. 제품정보**설정하기**당신의 신청을 위해.
3. 에 의해**기본 정보**탭, 복사**신청 Audience (AUD) 꼬리표**.

이제 토큰 검증 스크립트로 AUD 태그를 붙여넣을 수 있습니다. AUD 태그는 삭제하거나 액세스 응용 프로그램을 재구성하지 않는 한 변경하지 않습니다.

### Cloudflare Workers 예

Cloudflare의 경우 오시는 길[작업자](/workers), 당신의 노동자는 아직도 Cloudflare 접근이 추가하는 JWT를 유효한 필요로 합니다`Cf-Access-Jwt-Assertion`수신 요청에 헤더.

다음 코드는 JWT를 사용하여 검증됩니다.[jose NPM 패키지](https://www.npmjs.com/package/jose):

<TypeScriptExample>
  ```ts
  import { jwtVerify, createRemoteJWKSet } from "jose";

  interface Env {
  	POLICY_AUD: string;
  	TEAM_DOMAIN: string;
  }

  export default {
  	async fetch(request: Request, env: Env, ctx: ExecutionContext): Promise<Response> {
  		//POLICY AUD 환경 변수를 지정합니다.
  		if (!env.POLICY_AUD) {
  			return new Response("Missing required audience", {
  				status: 403,
  				headers: { "Content-Type": "text/plain" },
  			});
  		}

  		//요청 헤더에서 JWT 받기
  		const token = request.headers.get("cf-access-jwt-assertion");

  		//토큰이 존재하는 경우 확인
  		if (!token) {
  			return new Response("Missing required CF Access JWT", {
  				status: 403,
  				headers: { "Content-Type": "text/plain" },
  			});
  		}

  		try {
  			//팀 도메인에서 JWKS 만들기
  			const JWKS = createRemoteJWKSet(
  				new URL(`${env.TEAM_DOMAIN}/cdn-cgi/access/certs`)
  			);

  			//JWT 인증
  			const { payload } = await jwtVerify(token, JWKS, {
  				issuer: env.TEAM_DOMAIN,
  				audience: env.POLICY_AUD,
  			});

  			//토큰은 유효합니다, 당신의 신청 논리로 진행
  			return new Response(
  				`Hello ${payload.email || "authenticated user"}!`,
  				{
  					headers: { "Content-Type": "text/plain" },
  				}
  			);
  		} catch (error) {
  			//토큰 검증 실패
  			const message = error instanceof Error ? error.message : "Unknown error";
  			return new Response(`Invalid token: ${message}`, {
  				status: 403,
  				headers: { "Content-Type": "text/plain" },
  			});
  		}
  	},
  };
  ```
</TypeScriptExample>

### Golang 예제

```go
package main

import (
    "context"
    "fmt"
    "net/http"

    "github.com/coreos/go-oidc/v3/oidc"
)

var (
    ctx        = context.TODO()
    teamDomain = "https://test.cloudflareaccess.com"
    certsURL   = fmt.Sprintf("%s/cdn-cgi/access/certs", teamDomain)

    // The Application Audience (AUD) tag for your application
    policyAUD = "4714c1358e65fe4b408ad6d432a5f878f08194bdb4752441fd56faefa9b2b6f2"

    config = &oidc.Config{
        ClientID: policyAUD,
    }
    keySet   = oidc.NewRemoteKeySet(ctx, certsURL)
    verifier = oidc.NewVerifier(teamDomain, keySet, config)
)

// VerifyToken is a middleware to verify a CF Access token
func VerifyToken(next http.Handler) http.Handler {
    fn := func(w http.ResponseWriter, r *http.Request) {
        headers := r.Header

        // Make sure that the incoming request has our token header
        //  Could also look in the cookies for CF_AUTHORIZATION
        accessJWT := headers.Get("Cf-Access-Jwt-Assertion")
        if accessJWT == "" {
            w.WriteHeader(http.StatusUnauthorized)
            w.Write([]byte("No token on the request"))
            return
        }

        // Verify the access token
        ctx := r.Context()
        _, err := verifier.Verify(ctx, accessJWT)
        if err != nil {
            w.WriteHeader(http.StatusUnauthorized)
            w.Write([]byte(fmt.Sprintf("Invalid token: %s", err.Error())))
            return
        }
        next.ServeHTTP(w, r)
    }
    return http.HandlerFunc(fn)
}

func MainHandler() http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        w.Write([]byte("welcome"))
    })
}

func main() {
    http.Handle("/", VerifyToken(MainHandler()))
    http.ListenAndServe(":3000", nil)
}
```

### Python 예제

`pip`다음을 설치:

- 채용정보
- 이름 \*
- 사이트맵
- 비밀번호

```python
from flask import Flask, request
import requests
import jwt
import json
import os
app = Flask(__name__)


#신청 Audience (AUD) 당신의 신청을 위한 꼬리표
POLICY_AUD = os.getenv("POLICY_AUD")

#당신의 CF Access 팀 도메인
TEAM_DOMAIN = os.getenv("TEAM_DOMAIN")
CERTS_URL = "{}/cdn-cgi/access/certs".format(TEAM_DOMAIN)

def _get_public_keys():
    """
    Returns:
        List of RSA public keys usable by PyJWT.
    """
    r = requests.get(CERTS_URL)
    public_keys = []
    jwk_set = r.json()
    for key_dict in jwk_set['keys']:
        public_key = jwt.algorithms.RSAAlgorithm.from_jwk(json.dumps(key_dict))
        public_keys.append(public_key)
    return public_keys

def verify_token(f):
    """
    Decorator that wraps a Flask API call to verify the CF Access JWT
    """
    def wrapper():
				#POLICY AUD 환경 변수 확인
				if not POLICY_AUD:
					return "missing required audience", 403

        token = ''
        if 'CF_Authorization' in request.cookies:
            token = request.cookies['CF_Authorization']
        else:
            return "missing required cf authorization token", 403
        keys = _get_public_keys()

        #우리가 디코더에 열쇠 세트를 통과할 수 없기 때문에 열쇠를 통해서 반복
        valid_token = False
        for key in keys:
            try:
                #decode는 필요할 때 이메일이 있는 주장을 반환합니다.
                jwt.decode(token, key=key, audience=POLICY_AUD, algorithms=['RS256'])
                valid_token = True
                break
            except:
                pass
        if not valid_token:
            return "invalid token", 403

        return f()
    return wrapper


@app.route('/')
@verify_token
def hello_world():
    return 'Hello, World!'


if __name__ == '__main__':
    app.run()
```

### JavaScript (Node.js) 예제

```javascript
const express = require("express");
const jose = require("jose");

//신청 Audience (AUD) 당신의 신청을 위한 꼬리표
const AUD = process.env.POLICY_AUD;

//당신의 CF Access 팀 도메인
const TEAM_DOMAIN = process.env.TEAM_DOMAIN;
const CERTS_URL = `${TEAM_DOMAIN}/cdn-cgi/access/certs`;

const JWKS = jose.createRemoteJWKSet(new URL(CERTS_URL));

//validToken은 CF 인증 토큰을 확인하는 미들웨어입니다
const verifyToken = async (req, res, next) => {
	//AUD 환경 변수 확인
	if (!AUD) {
		return res.status(403).send({
			status: false,
			message: "missing required audience",
		});
	}

	const token = req.headers["cf-access-jwt-assertion"];

	//수신 요청이 우리의 토큰 헤더를 가지고 있는지 확인하십시오.
	if (!token) {
		return res.status(403).send({
			status: false,
			message: "missing required cf authorization token",
		});
	}

	try {
		const result = await jose.jwtVerify(token, JWKS, {
			issuer: TEAM_DOMAIN,
			audience: AUD,
		});

		req.user = result.payload;
		next();
	} catch (err) {
		return res.status(403).send({
			status: false,
			message: "invalid token",
		});
	}
};

const app = express();

app.use(verifyToken);

app.get("/", (req, res) => {
	res.send("Hello World!");
});

app.listen(3333);
```

Cloudflare Access를 최종 사용자와 Origin 서버간에 인증 계층으로 추가하여 내부 도구 및 응용 프로그램을 안전하게 게시할 수 있습니다.

이 가이드는 웹 애플리케이션을 공용 호스트 이름을 통해 인터넷에 액세스하는 방법을 다룹니다. 개인 IP 또는 호스트 이름에서 사용할 수있는 응용 프로그램을 만들려면, 참조[셀프 호스팅 전용 응용 프로그램 추가](/cloudflare-one/access-controls/applications/non-http/self-hosted-private-app/).

## 자주 묻는 질문

- 이름 \*[Cloudflare의 활성 도메인](/fundamentals/manage-domains/add-site/)
- 도메인은[전체 설정](/dns/zone-setups/full-setup/)또는[부분 (`CNAME`) 설정](/dns/zone-setups/partial-setup/)

## 2. Cloudflare에 당신의 근원을 연결하십시오

[Cloudflare 터널 설정](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/)내부 응용 프로그램을 게시합니다. 액세스 정책과 일치하는 사용자 만 액세스 권한을 부여합니다.

:::참조
우리는 추천합니다[액세스 신청서 작성](#1-add-your-application-to-access)터널 경로 설정하기 전에. 액세스 응용 프로그램이없는 경우 게시 된 응용 프로그램은 인터넷에서 누구나 사용할 수 있습니다.
주요 특징

신청이 이미 공개적으로 routable인 경우에, 갱도는 엄격히 요구되지 않습니다. 그러나, 당신은 그 후에 당신의 근원 IP를 사용하여 보호할 필요가 있을 것입니다[다른 방법](/fundamentals/security/protect-your-origin-server/).

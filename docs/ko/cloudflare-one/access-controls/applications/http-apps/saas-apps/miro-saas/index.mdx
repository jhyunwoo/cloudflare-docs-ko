이 가이드는 구성하는 방법[미로](https://help.miro.com/hc/articles/360017571414-Single-sign-on-SSO)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Miro Business 또는 Enterprise 플랜 계정에 대한 관리 액세스
- ·[인증된 도메인](https://help.miro.com/hc/articles/360034831793-Domain-control)Miro 계정 (Enterprise 계획)에 추가하거나 SSO 구성 (사업 또는 기업 계획) 중에 수행 할 준비가되어 있습니다.

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 입력`Miro`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `https://miro.com/`
   - **Assertion 소비자 봉사 URL**: `https://miro.com/sso/saml`
   - **이름 ID 체재**: *이름 \**
7. 제출하기**SSO 엔드포인트**·**공공 키**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 3. 통합 테스트

Miro SAML/SSO 설정 페이지에서 선택**SSO 설정 테스트**. Cloudflare 액세스 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 프롬프트됩니다. 로그인이 성공하면 받게 됩니다.**SSO 구성 시험은 성공했습니다**이름 \*

:::참조
통합을 테스트 할 때, 당신은 SSO 또는 Miro에서 구성 된 사용자의 도메인에서 이메일을 사용할 필요가 없습니다. 유일한 요구 사항은 사용자가 이미 ID 공급자에서 구성된다는 것입니다.

이 가이드는 구성하는 방법[Jamf 프로](https://learn.jamf.com/en-US/bundle/jamf-pro-documentation-current/page/Single_Sign-On.html)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Jamf Pro 계정 관리

## 1. Jamf Pro 정보 수집

1. Jamf Pro에서 이동**계정 설정** > **시스템** > **단일 로그인** > **제품정보**.
2. 미리 채워진 URL을 복사**기업 ID**.
3. 웹 브라우저에서 URL을 붙여 Jamf 메타데이터 파일을 다운로드합니다.
4. 자주 묻는 질문`metadata.xml`텍스트 편집기에서 파일, 그리고 값을 복사**기업 ID**·**Assertion 소비자 봉사**.

## 2. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 입력`Jamf`또는`Jamf Pro`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: Jamf Pro metadata 파일에서 Entity ID 값.
   - **Assertion 소비자 봉사 URL**: Jamf Pro metadata 파일로부터 Assertion Consumer Service 값.
   - **이름 ID 체재**: *이름 \**
7. 제출하기**SAML 메타데이터 엔드포인트**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 3. 액세스 SAML Metadata 수정

1. 패스워드**SAML 메타데이터 엔드포인트**Cloudflare의 응용 구성에서 브라우저에 하나.
2. 파일 복사 및 텍스트 편집기로 붙여 넣기.
3. \- 기타`WantAuthnRequestsSigned="true"`으로`WantAuthnRequestsSigned="false"`.
4. 파일 확장을 설정`.xml`견적 요청

## 4. Jamf Pro에 SAML SSO 공급자를 추가하십시오

1. Jamf Pro에서 이동**계정 설정** > **단일 로그인** > **제품정보**.
2. Identity Provider 메뉴에서, 선택**이름 \***.
3. 이름 \***다른 공급자**이름 \*`Cloudflare`.
4. 다음 필드에 기입:
   - **기업 ID**: Jamf Pro metadata 파일에서 Entity ID.
   - **Identity Provider 메타데이터 소스**: 선택**Metadata 파일**다운로드`.xml`단계별 파일[2. 액세스 SAML Metadata 수정](#2-add-a-saas-application-to-cloudflare-one).
   - **Identity Provider 사용자 매핑**: *이름 ID*
   - **Jamf Pro 사용자 매핑**: *이름 \**
5. 기타 제품**단일 로그인**.

:::참조
이 페이지에 위치한 Failover 로그인 URL은 SSO가 작동하지 않는 경우 로그인 할 수 있습니다.

## 5. 통합 테스트

Jamf Pro에서 로그아웃하고 브라우저 창을 엽니다. Jamf Pro URL로 이동하십시오. Cloudflare Access 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 안내합니다.

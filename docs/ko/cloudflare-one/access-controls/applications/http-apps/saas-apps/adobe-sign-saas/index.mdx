## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Adobe Acrobat Sign 계정에 대한 관리 액세스
- ·[법적고지](https://helpx.adobe.com/sign/using/claim-domain-names.html)Adobe Acrobat 로그인

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 입력`Adobe Sign`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 제출하기**Access Entity ID 또는 발급자**, **공공 키**·**SSO 엔드포인트**.
7. 선택 없이 이 창을 열지 않음**설정 선택**. 당신은 단계에 있는 이 윤곽을 완료할 것입니다[3. Cloudflare One에 SaaS 애플리케이션 추가](#3-finish-adding-a-saas-application-to-cloudflare-one).

## 2. SAML SSO 공급자를 Adobe 표시에 추가하십시오

1. Adobe Acrobat 로그인에서 프로필 사진을 선택하세요 > 이름 >**계정 설정** > **SAML 설정**.
2. 제품정보**SAML 허용**이름 \*
3. hostname(예를 들어,`yourcompanyname`). 사용자는 이 URL을 사용할 수 있습니다 또는`https://secure.adobesign.com/public/login`SSO를 통해 로그인하십시오.
4. (선택)를 위해**단일 로그인 메시지**, custom message (예를 들어,`Log in via SSO`). 기본 메시지는**회사 자격 증명을 사용하여 로그인**.
5. 다음 필드에 기입:
   - **엔티티티 ID/Issuer URL**: Cloudflare One의 Application 구성에서 Entity ID 또는 Issuer에 액세스합니다.
   - **로그인 URL/SSO 엔드포인트**: Cloudflare One의 애플리케이션 구성에서 SSO 엔드포인트.
   - **IdP 인증서**: Cloudflare One의 애플리케이션 구성에서 공개 키. 인증서를 포장`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.
6. 제출하기**엔티티티 ID/SAML Audience**·**Assertion 소비자 URL**.
7. 제품정보**제품 정보**.

## 3. Cloudflare One에 SaaS 애플리케이션 추가

1. 개방 Cloudflare 한 창, 다음 필드에 기입:
   - **기업 ID**: Adobe Acrobat Sign SAML SSO 구성의 ID/SAML Audience.
   - **Assertion 소비자 봉사 URL**: Adobe Acrobat Sign SAML SSO 설정에서 소비자 URL을 Assertion.
   - **이름 ID 체재**: *이름 \**
2. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
3. 신청 저장.

## 4. 통합 및 최종 구성 테스트

1. 브라우저 창을 열고 Adobe Sign hostname URL로 이동하거나`https://secure.adobesign.com/public/login`. SSO를 통해 로그인 할 수있는 옵션을 선택하십시오 (**회사 자격 증명을 사용하여 로그인**사용자 정의 메시지를 구성하지 않은 경우). Cloudflare Access 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 안내합니다.

:::참조

SSO 통합을 테스트하면서 오류를 받으면 프로필 사진으로 이동 > 이름 >**계정 설정** > **SAML 오류**더 많은 정보.

:::

2. 이 성공되면 SSO 필수를 통해 로그인 할 수 있습니다. 프로필 사진 선택 > 이름 >**계정 설정** > **SAML 설정**, 다음 켜기**SAML 소개**. 유지**Acrobat Sign Account Administrators를 사용하여 로그인하십시오.**&#xACC4;정 경험 SSO 문제 경우에도 관리자가 로그인 할 수 있습니다.

이 가이드는 구성하는 방법[철](https://support.ironcladapp.com/hc/articles/12286012625559-Set-Up-Generic-SSO-SAML-Integration)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Ironclad 사이트에 대한 관리자 액세스

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 입력`Ironclad`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 제출하기**SSO 엔드포인트**·**공공 키**.
7. 이 창을 엽니다. 당신은 단계에 이 윤곽을 완료할 것입니다[3. Cloudflare One에 SaaS 애플리케이션 추가](#3-finish-adding-a-saas-application-to-cloudflare-one).

## 2. Ironclad에 SAML SSO 공급자를 추가하십시오

1. Ironclad에서 프로필 사진을 선택 >**회사 설정** > **통합** > **사이트맵**.
2. 제품정보**SAML 구성 추가** > **추가 IdP 설정 표시**.
3. 제출하기**콜백**가치.
4. 다음 필드에 기입:
   - **입력 포인트**: Cloudflare One의 애플리케이션 구성에서 SSO 엔드포인트.
   - **Identity 공급자 증명서**: Cloudflare One의 애플리케이션 구성에서 공개 키. 열쇠는 자동적으로 감싸입니다`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.
5. 제품정보**제품 정보**.

## 3. Cloudflare One에 SaaS 애플리케이션 추가

1. 개방 Cloudflare 한 창, 다음 필드에 기입:
   - **기업 ID**: `ironcladapp.com`
   - **Assertion 소비자 봉사 URL**: Ironclad SAML SSO 설정에서 콜백.
   - **이름 ID 체재**: *이름 \**
2. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
3. 신청 저장.

## 4. Ironclad에 시험 사용자를 추가하고 통합을 시험하십시오

1. Ironclad에서 프로필 사진을 선택 >**회사 설정** > **사용자 및 그룹**.
2. 제품정보**Invite 사용자**.
3. 제품 정보**이메일 주소**, 당신의 시험 사용자를 위한 당신의 원한 이메일 주소를 추가하십시오.
4. 제품 정보**로그인 방법**, 지킵니다**로그인 (your-team-domain.cloudflareaccess.com)**&#xC120;택 사항
5. 제품정보**뚱 베어**.
6. 시험 사용자에게 보내진 초대 이메일에서, 선택**현재 위치**. Cloudflare 액세스 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 프롬프트됩니다.
7. 이 성공하면 계정 팀에 연락하거나`support@ironcladapp.com`SSO 로그인으로 기존 사용자를 마이그레이션합니다.

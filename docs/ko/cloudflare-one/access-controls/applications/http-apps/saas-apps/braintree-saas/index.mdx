이 가이드는 구성하는 방법[뇌 트리](https://developer.paypal.com/braintree/articles/guides/single-sign-on-sso)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Braintree 생산 또는 sandbox 계정에 대한 관리 액세스

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 입력`Braintree`아래 보이는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 임시 값으로 다음 필드에 채우기:
   - **기업 ID**: `placeholder`
   - **Assertion 소비자 봉사 URL**: `https://www.placeholder.com`
   - **이름 ID 체재**: *이름 \**
7. 제출하기**SSO 엔드포인트**·**공공 키**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. Braintree에서 SSO 구성 가능

1. Braintree에서[지원 표](https://developer.paypal.com/braintree/help).
2. 내 계정**검색 문제**, 입력`Login and password issues`그리고 해당 값을 선택합니다.
3. 내 계정**관련 상품**, 다음을 기입:
   - **판매자 ID**: 당신의 Braintree 상인 ID. 이것은 다음과 같은 16 자리 값입니다.`/merchants/`Braintree 제어 패널 URL에서.
   - **이메일 도메인(s)는 사용자 ID로 사용됩니다.**: SSO를 통해 계정에 로그인 할 수있는 이메일 도메인 (s).
   - **단일 로그인 HTTP POST 바인딩 URL**: Cloudflare One의 애플리케이션 구성에서 SSO 엔드포인트
   - **유효성 검사**: Cloudflare One의 애플리케이션 구성에서 공개 키.
4. 자주 묻는 질문**제품정보**또는**샌드박스**계정.
5. 자주 묻는 질문**연락처 정보**필드 및 선택**자주 묻는 질문**.
6. SSO가 성공적으로 계정을 구성 한 이메일을 받게되면 다음 단계로 진행할 수 있습니다.

## 3. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**뇌 트리** > **제품정보** > **제품정보**.
3. 임시 값 교체**기업 ID**·**Assertion 소비자 봉사 URL**Braintree 지원에서 성공적인 SSO 구성 이메일에서 제공하는 링크. 두 값 모두 동일한 링크를 사용합니다.
4. 제품정보**자주 묻는 질문**.

## 4. 통합을 시험하고 SSO 사용자를 추가하십시오

1. Braintree 제어판에서, 선택**제품정보**아이콘 >**회사연혁**.
2. 원하는 테스트 사용자를 선택합니다.
3. 이름 \***단일 로그인**, 선택**이름 \***.
4. 브라우저 창을 엽니다. 주소 표시줄에서 붙여넣기`https://id.sandbox.braintreegateway.com`sandbox 계정 또는
   `https://id.braintreegateway.com`생산 계정.
5. 내 계정**당신의 기업 이메일 주소**필드, 테스트 사용자의 이메일을 입력. Cloudflare Access 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 안내합니다.
6. 성공적인 sign-in에, 당신은 단계 4.1 - 4.3를 사용하여 다른 사용자를 위해 SSO를 활성화할 수 있습니다.

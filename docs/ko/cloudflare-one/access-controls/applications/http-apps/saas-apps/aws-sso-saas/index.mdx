이 가이드는 구성하는 방법[사이트맵](https://docs.aws.amazon.com/singlesignon/latest/userguide/manage-your-identity-source-idp.html)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- AWS 계정 관리

## 1. AWS URL 받기

1. AWS 관리자 패널에서 검색`IAM Identity Center`.
2. 오시는 길**IAM ID 센터** > **계정 설정**.
3. 내 계정**Identity 소스**탭, 선택**관련 기사**드롭다운 및 선택*ID 입력*.
4. ID 소스 변경**외부 ID 공급자**.
5. 표시된 값 복사**서비스 제공업체 metadata**. Cloudflare One에서 SaaS 애플리케이션을 구성할 때 이러한 값을 필요로 합니다.

다음, 우리는 얻을 것이다**Identity 공급자 메타데이터**Cloudflare에서 한국어

## 2. Cloudflare One에 SaaS 애플리케이션 추가

1. 별도의 탭 또는 창에서 열린[사이트맵 한국어](https://one.dash.cloudflare.com)·**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 선택*아마존 AWS*.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: IAM ID 센터 발급 URL
   - **Assertion 소비자 봉사 URL**: IAM Identity Center Assertion 소비자 봉사 (ACS) URL
   - **이름 ID 체재**: *이름 \**
7. (선택 사항) 추가 SAML 속성 문은 IdP에서 AWS SSO로 전달될 수 있습니다. AWS Attribute mapping에 대한 자세한 내용을 보려면 여기를 클릭하십시오.[Attribute 매핑 - AWS 싱글 사인 온](https://docs.aws.amazon.com/singlesignon/latest/userguide/attributemappingsconcept.html#supportedidpattributes).
8. AWS는 metadata XML 파일 업로드를 지원합니다. 액세스에서 SAML 메타 데이터를 다운로드하려면:
   1. 제출하기**SAML 메타데이터 엔드포인트**.
   2. 별도의 브라우저 창에서 SAML 메타데이터 엔드포인트로 이동 (`https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/sso/saml/xxx/saml-metadata`).
   3. 페이지 저장`access_saml_metadata.xml`.
9. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
10. 신청 저장.

## 3. AWS 구성 완료

1. 자주 묻는 질문**IAM ID 센터** > **계정 설정** > **ID 입력**탭.

2. 이름 \***IdP SAML 메타데이터**, 업로드`access_saml_metadata.xml`파일.

3. 제품정보**이름 \***&#xC124;정 검토, 유형**사이트맵**선택하기**ID 입력**변경 사항

4. 견적 요청**회사연혁**설정*제품 설명*.

:::카ution\[중요]

SaaS에 대한 액세스는 현재 지원되지 않습니다.[SCIM 제공](/cloudflare-one/team-and-resources/users/scim/). 확인 :

1. 사용자는 ID 공급자와 AWS 둘 다에서 창조됩니다.
2. 사용자는 ID 공급자와 AWS에 있는 사용자를 일치해야 합니다.
3. 사용자 이름은 이메일 주소입니다. 이것은 타사 SSO 제공 업체와 AWS 만 지원됩니다.

## 4. 통합 테스트

연결을 테스트하려면, 이동**AWS 액세스 포털 URL**. Cloudflare 액세스 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 프롬프트됩니다.

이 가이드는 구성하는 방법[허브스팟](https://knowledge.hubspot.com/account-security/set-up-single-sign-on-sso)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Hubspot Enterprise 플랜 계정에 대한 관리 액세스

## 1. Hubspot 구성

1. 오시는 길**계정 설정** > **계좌정보**, 다음 이동**기본 사항** > **보안 보안**.
2. 제품정보*단일 로그인*.
3. 값 복사*관객 URI*·*URL에 로그인*.

## 2. Cloudflare 구성 오시는 길

1. Cloudflare에서 하나, 이동**액세스 제어** > **이름 \***&#x53;aaS 애플리케이션을 만듭니다.

2. 설정하기**신청 유형**으로*허브스팟*.

3. 다음 Hubspot 필드 맵핑을 사용하십시오.

   | Hubspot 값 | Cloudflare 값         |
   | --------- | -------------------- |
   | 관객 URI    | 기업 ID                |
   | URL에 로그인  | Assertion 소비자 봉사 URL |

4. 설치하기**이름 ID**으로*이름 \**.

5. 자주 묻는 질문[오시는 길](/cloudflare-one/access-controls/policies/)당신의 신청에.

6. 제출하기**SSO 엔드포인트**·**액세스 권한 ID**.

7. 신청 저장.

## 3. x.509 인증서 만들기

1. 패스워드**공공 키**텍스트 편집기에서.
2. 인증서를 포장`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.

## 4. Hubspot 구성 정의

1. 다음 필드 매핑을 사용합니다:

   | Cloudflare 가치 | Hubspot 값               |
   | ------------- | ----------------------- |
   | SSO 엔드포인트     | ID 공급자 단일 로그인 URL       |
   | 기업 ID         | Identity 공급자 Identifier |
   | 공공 키          | 인증번호                    |

2. 제품정보**계정 만들기**통합을 검증합니다.

당신의 윤곽은 지금 완료됩니다. Hubspot SSO는 특정 사용자 또는 전체 계정에 대해 전환 할 수 있습니다.

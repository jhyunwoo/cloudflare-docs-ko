## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 선택*프로젝트*.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `https://github.com/orgs/<your-organization>`
   - **Assertion 소비자 봉사 URL**: `https://github.com/orgs/<your-organization>/saml/consume`
   - **이름 ID 체재**: *이름 \**
7. 제출하기**SSO 엔드포인트**, **Access Entity ID 또는 발급자**·**공공 키**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. X.509 인증서 생성

1. 패스워드**공공 키**텍스트 편집기에서.
2. 인증서를 포장`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.

## 3. GitHub Enterprise Cloud의 ID 공급자 및 SAML SSO 구성

1. GitHub 조직 페이지에서 이동**계정 설정** > **인증 보안**.
2. 이름 \***SAML 싱글 사인온**, 켜기**SAML 인증**.
3. 다음 필드에 기입:
   - **URL에 로그인**: Cloudflare One의 애플리케이션 구성에서 SSO 엔드포인트.
   - **계정 관리**: Cloudflare One의 Application 구성에서 Entity ID 또는 Issuer에 액세스합니다.
   - **공공 인증서**: 전체 x.509 인증서를 단계로 붙여넣기[2. x.509 인증서 만들기](#2-create-a-x509-certificate).

## 4. 통합 테스트

제품정보**SAML 구성 테스트**. Cloudflare 액세스 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 프롬프트됩니다.
이 성공할 때, select**제품 정보**.

당신은 또한 켜질 수 있습니다**조직의 모든 구성원을위한 SAML SSO 인증**Cloudflare 액세스로 SSO 로그인을 강제하려면.

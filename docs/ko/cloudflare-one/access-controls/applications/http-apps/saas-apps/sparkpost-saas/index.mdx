이 가이드는 구성하는 방법[SparkPost 또는 SparkPost EU](https://support.sparkpost.com/docs/my-account-and-profile/sso)Cloudflare Zero Trust에 있는 SAML 신청으로.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- SparkPost 또는 SparkPost EU 계정에 대한 관리 액세스

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 입력`SparkPost`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**:
     - `https://api.sparkpost.com`SparkPost 계정
     - `https://api.eu.sparkpost.com`SparkPost EU 계정
     - `https://<api-host>`SparkPost 계정 전용 임계인
   - **Assertion 소비자 봉사 URL**:
     - `https://api.sparkpost.com/api/v1/users/saml/consume`SparkPost 계정
     - `https://api.eu.sparkpost.com/api/v1/users/saml/consume`SparkPost EU 계정
     - `https://<api-host>/api/v1/users/saml/consume`SparkPost 계정 전용 임계인
   - **이름 ID 체재**: *이름 \**
7. 제출하기**SAML 메타데이터 엔드포인트**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. 메타데이터 파일을 다운로드

1. Cloudflare의 애플리케이션 구성에서 SAML 메타데이터 엔드포인트를 붙여넣기 웹 브라우저에서 하나.
2. URL의 내용을 다운로드하려면 브라우저 별 단계를 따르십시오.`.xml`파일.

## 3. SparkPost에 SAML SSO 공급자를 추가하십시오

1. SparkPost에서 프로필 사진을 선택 >**계정 설정**.
2. 이름 \***단일 로그인**, 선택**보호 SSO**.
3. 이름 \***보안 Assertion Markup 언어 (SAML) 업로드**, 선택**파일 선택**다운로드`.xml`단계로 만든 파일[2. 메타데이터 파일을 다운로드](#2-download-the-metadata-file).
4. 제품정보**보호 SSO**.
5. 제품정보**SSO 사용**.

## 4. 테스트 사용자 추가 및 통합 테스트

1. SparkPost에서 현재 사용자는 SSO를 사용하여 삭제 및 재 활성화해야합니다. 테스트 사용자를 만들려면 프로필 사진을 선택 >**이름 \***> 사용자 이름 >**사용자 정의**. 그때, 선택**Invite 사용자**자주 묻는 질문 대안으로, 새로운 사용자를 초대합니다. 초대 이메일이 전송됩니다.
2. 초대 이메일에 보낸 링크로 이동. Cloudflare Access 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 안내합니다.
3. SSO가 성공적으로 완료되면 SSO를 제거하고 다시 활성화하여 현재 사용자의 나머지를 위해 설정할 수 있습니다.

이 가이드는 구성하는 방법[핑보드](https://support.pingboard.com/hc/en-us/articles/360046585994-Set-Up-a-Custom-SSO-Solution)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Pingboard 계정 관리

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 입력`Pingboard`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `http://app.pingboard.com/sp`
   - **Assertion 소비자 봉사 URL**: `https://sso-demo.pingboard.com/auth/saml/consume`
   - **이름 ID 체재**: *이름 \**
7. 제출하기**SAML 메타데이터 엔드포인트**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. Pingboard에 SAML SSO 공급자를 추가하십시오

1. Pingboard에서 이동**계좌정보** > **더 알아보기**.
2. 이름 \***제3자 통합**, 선택**주문 SSO**.
3. 웹 브라우저에서 Cloudflare One의 애플리케이션 구성에서 복사한 SAML Metadata 엔드포인트를 붙여넣으십시오. 다음, 표시된 페이지의 내용을 복사합니다.
4. Pingboard에서, 아래**IdP 메타데이터**, SAML Metadata endpoint에서 내용을 붙여 넣는다.
5. (선택) 밑에**로그인**, 이름을 입력 (예를 들어,`Cloudflare Access`). 사용자가 로그인할 때 이 이름을 선택합니다.

## 3. 통합 테스트

브라우저 창을 열고 Pingboard URL로 이동합니다. Cloudflare Access 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 안내합니다.

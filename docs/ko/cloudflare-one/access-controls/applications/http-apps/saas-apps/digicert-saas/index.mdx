이 가이드는 구성하는 방법[사이트맵](https://docs.digicert.com/en/certcentral/manage-account/saml-admin-single-sign-on-guide/configure-saml-single-sign-on.html)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Digicert 계정에 대한 관리 접근
- [사이트맵](https://docs.digicert.com/en/certcentral/manage-account/saml-admin-single-sign-on-guide/saml-single-sign-on-prerequisites.html)Digicert 계정에서 활성화

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 입력`Digicert`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `https://www.digicert.com/account/sso/metadata`
   - **Assertion 소비자 봉사 URL**: `https://www.digicert.com/account/sso/`
   - **이름 ID 체재**: *이름 \**
7. 제출하기**SAML 메타데이터 엔드포인트**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. Digicert에 있는 SAML SSO 공급자 추가하십시오

1. Digicert에서, 선택**계정 설정** > **단일 로그인** > **SAML 설정**.
2. 이름 \***IDP에서 데이터를 보낼 수 있습니까?**, 켜기**동적 URL 사용**.
3. 이름 \***동적 URL 사용**, Cloudflare에 있는 신청 윤곽에서 SAML 메타데이터 엔드포인트를 풀십시오.
4. 이름 \***사용자를 식별하는 방법?**, 켜기**이름 ID**.
5. 이름 \***연맹 이름**, 이름을 입력 (예를 들어,`Cloudflare Access`). 사용자가 로그인할 때 이 이름을 선택합니다.
6. 제품정보**SAML 설정 저장**.

## 3. Digicert에 있는 시험 그리고 Enable SSO

1. Digicert에서, 선택**계정 설정** > **단일 로그인**.
2. 제출하기**SP 개시 사용자 정의 SSO URL**.
3. URL을 incognito 브라우저 창에 붙여넣고 로그인합니다. 성공적인 로그인 시 SAML SSO가 완전히 활성화됩니다.
4. (선택) 기본적으로 사용자가 직접 또는 SSO로 로그인할 수 있습니다. SSO 서명을 요구하려면**계좌정보** > **이름 \***. 켜기**SAML/OIDC SSO를 통해 로그인하는 사용자만 허용**원하는 사용자의 사용자 세부 정보에서.

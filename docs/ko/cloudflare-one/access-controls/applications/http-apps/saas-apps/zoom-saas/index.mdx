## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 선택*주 메뉴*.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: ` https://<your-vanity-url>.zoom.us`
   - **Assertion 소비자 봉사 URL**: `https://<your-vanity-url>.zoom.us/saml/SSO`
   - **이름 ID 체재**: *이름 \**
7. 제출하기**Access Entity ID 또는 발급자**, **공공 키**·**SSO 엔드포인트**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. Zoom에서 SAML SSO 공급자를 추가하십시오

1. Zoom에서 이동**지원하다** > **단일 로그인**.
2. 제품 정보**허영 URL**, SSO를 구성하려는 허영 URL을 선택합니다.
3. 다음 필드를 작성:
   - **로그인 페이지 URL**: Cloudflare One의 애플리케이션 구성에서 SSO 엔드포인트
   - **Identity 공급자 증명서**: Cloudflare One의 애플리케이션 구성에서 공개 키
   - **서비스 제공자 (SP) 기업 ID**: `yourvanityurl.zoom.us`(없음)`https://`)
   - **Issuer (DP 엔티티티 ID)**: Cloudflare One의 Application 구성에서 Entity ID 또는 Issuer 액세스
4. 제품 정보**회사 소개**, 선택*웹 사이트*.
5. 제품 정보**서명 해시 Algorithm**, 지킵니다**모델 번호: SHA-256**선택 사항
6. 이름 \***보안 보안**, 꺼짐**SAML 요청**·**SAML 로그아웃 요청**.
7. 제품정보**저장 변화**.
8. 오시는 길**지원하다** > **보안 보안**.
9. 이름 \***로그인 방법**, 지킵니다**사용자가 Single Sign-On(SSO)로 로그인할 수 있습니다.**&#xC124;정한다.

## 3. 통합 테스트

브라우저 창을 열고, Zoom vanity URL로 이동하고, 선택**이름 \***. Cloudflare 액세스 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 프롬프트됩니다.

이 성공하면 다음과 같은 단계를 완료하여 관련 도메인(s)에서 SSO를 요구할 수 있습니다.

1. Zoom에서 이동**지원하다** > **보안 보안**.
2. 이름 \***로그인 방법**, 켜기**사용자가 SSO로 로그인하려면 전자 메일 주소가 아래의 도메인 중 하나에 속한 경우**.
3. 이름 \***도메인 선택**, 당신이 SSO를 요구하는 도메인에 회전.
4. (선택) 밑에**SSO 서명을 우회할 수 있는 사용자 지정**, 원하는 사용자를 추가합니다.
5. 제품정보**제품 정보**.

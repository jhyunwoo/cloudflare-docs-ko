이 가이드는 구성하는 방법[아사나](https://help.asana.com/hc/en-us/articles/14075208738587-Authentication-and-access-management-options-for-paid-plans#gl-saml)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Asana Enterprise, Enterprise+ 또는 Legacy Enterprise 계정에 대한 관리자 액세스

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 선택*아사나*.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `https://app.asana.com/`
   - **Assertion 소비자 봉사 URL**: `https://app.asana.com/-/saml/consume`
   - **이름 ID 체재**: *이름 \**
7. 제출하기**SSO 엔드포인트**·**공공 키**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. 아사나에 SAML SSO 공급자 추가

1. Asana에서 프로필 사진을 선택 >**관리자 콘솔** > **보안 보안** > **SAML 인증**.
2. 이름 \***SAML 옵션**, 선택*옵션 정보*.
3. 다음 필드에 기입:
   - 로그인 페이지 URL: Cloudflare One의 애플리케이션 구성에서 SSO 엔드포인트.
   - X.509 인증서 : Cloudflare One의 응용 프로그램 구성에서 공공 키. 공공 키를 랩`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.
4. 제품정보**비밀번호**.

## 3. 통합을 시험하고 SSO를 요구합니다

1. 브라우저 창을 열고 Asana URL로 이동합니다. Cloudflare Access 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 안내합니다.

2. 이 성공 후 SSO를 통해 로그인 할 사용자를 요구할 수 있습니다. Asana에서 프로필 사진을 선택 >**관리자 콘솔** > **보안 보안** > **SAML 인증**. 아래**SAML 옵션**, 선택**모든 회원에게 필요한 경우, 게스트 계정 제외**.

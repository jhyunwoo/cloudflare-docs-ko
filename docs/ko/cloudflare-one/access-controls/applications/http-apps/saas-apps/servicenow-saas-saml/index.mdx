## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 입력`ServiceNow`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `https://<INSTANCE-NAME>.service-now.com`
   - **Assertion 소비자 봉사 URL**: `https://<INSTANCE-NAME>.service-now.com/navpage.do`

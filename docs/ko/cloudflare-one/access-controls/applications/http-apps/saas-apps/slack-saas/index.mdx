이 가이드는 구성하는 방법[스크랩](https://slack.com/help/articles/203772216-SAML-single-sign-on)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Slack Business+ 또는 Enterprise Grid 플랜 계정에 대한 관리 액세스

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 선택*스크랩*.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `https://slack.com`
   - **Assertion 소비자 봉사 URL**: `https://<YOUR_DOMAIN>.slack.com/sso/saml`
   - **이름 ID 체재**: Slack에 의해 예상되는 형식, 보통*이름 \**
7. 제출하기**SSO 엔드포인트**, **Access Entity ID 또는 발급자**·**공공 키**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. x.509 인증서 만들기

1. 패스워드**공공 키**텍스트 편집기에서.
2. 인증서를 포장`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.

이 가이드는 구성하는 방법[회사연혁](https://help.salesforce.com/s/articleView?id=sf.sso_saml.htm\&type=5)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Salesforce 계정에 대한 관리 접근

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 선택*회사연혁*.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `https://<your-domain>.my.salesforce.com`또는`https://<your-domain>.my.salesforce.com?so=<your-salesforce-org-id>`, 귀하의 계정이 여름 2019 전에 생성 된 경우 또는 내 도메인 하위 도메인이 없습니다.
   - **Assertion 소비자 봉사 URL**: `https://<your-domain>.my.salesforce.com`또는`https://<your-domain>.my.salesforce.com?so=<your-salesforce-org-id>`, 귀하의 계정이 여름 2019 전에 생성 된 경우 또는 내 도메인 하위 도메인이 없습니다.
   - **이름 ID 체재**: *이름 \**

:::참조
URL이 없는 경우**기업 ID**·**Assertion 소비자 봉사 URL**필드, Salesforce 계정 메타 데이터를 확인할 수 있습니다. Salesforce에서, 이동**단일 로그인 설정**페이지 및 선택**Metadata 다운로드**. 이 파일에서 올바른 URL을 사용할 수 있습니다.
주요 특징

7. 제출하기**SSO 엔드포인트**, **공공 키**·**Access Entity ID 또는 발급자**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. 인증서 파일 만들기

1. 패스워드**공공 키**텍스트 편집기에서.
2. 인증서를 포장`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.
3. 파일 확장을 설정`.crt`견적 요청

## 3. SAML SSO 공급자를 Salesforce에 추가하십시오

1. Salesforce에서, 이동**설치하기**.

2. 내 계정**빠른 찾기**상자, 입력`single sign-on`선택하기**단일 로그인 설정**.

3. 내 계정**SAML 단일 로그인 설정**, 선&#xD0DD;**- 한국어**.

4. 다음 필드에 기입:

   - **이름:**&#x53;SO 공급자의 이름 (예를 들면,`Cloudflare Access`). 사용자는 Salesforce에 서명 할 때이 이름을 선택합니다.
   - **API 이름:**(이는 사전 Populate)
   - **발행인:**&#x43;loudflare One의 Application 구성에서 Access Entity ID 또는 Issuer를 붙여넣으십시오.
   - **Identity 공급자 증명서**: 업로드`.crt`인증서 파일 from[2. 인증서 파일 만들기](#2-create-a-certificate-file).
   - **기업 ID**: `https://<your-domain>.my.salesforce.com`
   - **사이트맵 ID 유형:**&#xC0AC;용자의 Salesforce 사용자 이름이 이메일 주소인 경우, 선택*Assertion는 사용자의 Salesforce 사용자를 포함합니다*. 그렇지 않으면, 선택*Assertion에는 사용자 객체의 Federation ID가 포함되어 있습니다.*&#xC0AC;용자의 연맹 ID가 이메일 주소 일치 있는지 확인합니다.

   <Details header="연맹 ID 구성">
     1. 내 계정**빠른 찾기**상자, 입력`users`선택하기**이름 \***. 2. 선택

   - **Identity Provider 로그인 URL**: Cloudflare에서 제공하는 SSO 엔드포인트 한국어
     이 응용 프로그램.

5. 제품정보**제품 정보**.

   2. (선택) Cloudflare 액세스로 로그인하려면, 켜기**Salesforce 자격 증명을 사용하여 로그인 가능**.
   3. 기타 제품**SAML 지원**.
   4. 기타 제품**federation ID 케이스 검출**.

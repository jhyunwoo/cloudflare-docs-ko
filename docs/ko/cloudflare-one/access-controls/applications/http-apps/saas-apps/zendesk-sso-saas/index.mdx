이 가이드는 구성하는 방법[젠 데스크](https://support.zendesk.com/hc/en-us/articles/4408887505690-Enabling-SAML-single-sign-on#topic_u54_wc3_z2b)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Zendesk 계정 관리

## Zendesk 및 Cloudflare 구성

1. Zendesk 관리자 대시보드로 이동하여 일반적으로 사용할 수 있습니다.`<yourdomain>.zendesk.com/admin/security/sso`.

2. 별도의 탭 또는 창에서 열린[사이트맵 한국어](https://one.dash.cloudflare.com), 계정을 선택하고, 이동**액세스 제어** > **이름 \***.

3. 제품정보**앱 추가**, 다음 선택*SaaS 서비스*.

4. Cloudflare 1개의 신청 윤곽에 있는 뒤에 오는 가치를 입력하십시오:

   | 사이트맵 1개의 분야              | 제품정보                                  |
   | ------------------------ | ------------------------------------- |
   | **기업 ID**                | `https://<yoursubdomain>.zendesk.com` |
   | **Assertion 소비자 봉사 URL** | 이름 \***SAML SSO URL**Zendesk 계정       |
   | **이름 ID 체재**             | *이름 \**                               |

5. (선택 사항) 이 속성을 구성하여 사용자의 첫 번째 및 마지막 이름을 포함:

   | Cloudflare 속성 이름 | IdP 속성 값                                                          |
   | ---------------- | ----------------------------------------------------------------- |
   | `<first name>`   | `http://schemas.xmlsoap.org/ws/2005/05/identity/claims/givenname` |
   | `<last name>`    | `http://schemas.xmlsoap.org/ws/2005/05/identity/claims/surname`   |

   Zendesk는[사용자의 이메일 주소를 자신의 이름으로 사용](https://support.zendesk.com/hc/en-us/articles/203663676#topic_dzb_gl5_2v)이름이 제공되지 않는 경우.

6. Zendesk에 접속할 수 있는 사람들을 결정하기 위해[액세스 정책 생성](/cloudflare-one/access-controls/policies/).

7. 제출하기**SSO 엔드포인트**·**공공 키**.

8. 지문으로 공중 열쇠를 변형하십시오:
   1. 공지사항[지문 계산기](https://www.samltool.com/fingerprint.php).

   2. 패스워드**공공 키**로그인**X.509 인증**.

   3. 값을 감싸기`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.

   4. 설치하기**Algorithm, 그리스**으로*모델 번호: SHA256*선택하기**지문을 계산**.

   5. 제출하기**포맷 된 FingerPrint**가치.

9. 다음 Zendesk 필드에 Cloudflare 값을 추가하십시오.

   | Cloudflare IdP 필드   | Zendesk 필드       |
   | ------------------- | ---------------- |
   | **SSO 엔드포인트**       | **SAML SSO URL** |
   | **공공 키**( 지문에 전달하는) | **인증서 지문**       |

10. 오시는 길`https://<yourdomain>.zendesk.com/admin/security/staff_members`설정하기**외부 인증** > **단일 로그인**.

사용자는 이제 Zendesk 사용자 목록에서 이메일 주소가 존재하는 경우 Zendesk에 로그인할 수 있어야 합니다.

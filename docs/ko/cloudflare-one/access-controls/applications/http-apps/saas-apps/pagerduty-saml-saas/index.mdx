이 가이드는 구성하는 방법[카테고리](https://support.pagerduty.com/docs/sso)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- PagerDuty 사이트에 대한 관리자 액세스

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 선택*카테고리*.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `https://<your-subdomain>.pagerduty.com`
   - **Assertion 소비자 봉사 URL**: ` https://<your-subdomain>.pagerduty.com/sso/saml/consume`
   - **이름 ID 체재**: *이름 \**
7. 제출하기**SSO 엔드포인트**·**공공 키**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. x.509 인증서 만들기

1. 패스워드**공공 키**텍스트 편집기에서.
2. 공개 키가 너무 각 행은 최대 64 문자입니다. 원래, 공공 키의 각 전체 행은 65 문자 길이입니다.
3. 인증서를 포장`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.

## 3. PagerDuty에 SAML SSO 공급자를 추가하십시오

1. PagerDuty에서 프로필 사진을 선택하고 이동**계정 설정** > **단일 로그인**.
2. 기타 제품**사이트맵**.
3. 내 계정**X.509 인증서**, 단계에서 전체 x.509 인증서를 붙여[2. x.509 인증서 만들기](#2-create-a-x509-certificate).
4. 내 계정**로그인 URL**, Cloudflare 하나에 있는 신청 윤곽에서 SSO endpoint를 풀기.
5. 제품정보**저장 변화**.

## 4. 통합을 시험하고 SSO 구성을 완성하십시오

1. incognito 창을 열고 PagerDuty URL을 주소 표시줄에 붙여넣으십시오. 제품정보**로그인 단일 로그인**. Cloudflare 액세스 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 프롬프트됩니다.
2. incognito 창에서 PagerDuty URL을 붙여넣고 선택**로그인 단일 로그인**. Cloudflare 액세스 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 프롬프트됩니다.
3. SSO 서명이 성공되면 프로필 사진을 선택하고 이동**계정 설정** > **단일 로그인**.
4. 공지사항**아이디/비밀번호 찾기**선택하기**저장 변화**. 이제 사용자는 SSO로 로그인 할 수 있습니다.

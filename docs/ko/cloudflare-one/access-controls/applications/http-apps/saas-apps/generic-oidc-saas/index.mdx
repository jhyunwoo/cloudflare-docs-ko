## OIDC 청구

OIDC는 성공적인 인증에 OIDC SaaS 응용 프로그램을 사용하여 Cloudflare 액세스 주식을 제공하는 사용자 정체성 특성을 나타냅니다. OIDC 범위는 OIDC 주장의 집합을 정의합니다. 기본적으로 Cloudflare 오시는 길[표준 청구](https://openid.net/specs/openid-connect-core-1_0.html#StandardClaims)그것은에 포함 된`openid`, `email`, `profile`·`groups`범위 (유효한 경우에).

| 관련 상품     | 이름 \*                                |
| --------- | ------------------------------------ |
| `openid`  | 사용자 (필수)에 대한 고유 식별자를 포함합니다.          |
| `email`   | 사용자의 이메일 주소를 포함합니다.                  |
| `profile` | 사용자 이름과 모든 사용자 정의 OIDC는 IdP에서 주장합니다. |
| `groups`  | 사용자의 IdP 그룹 회원 포함.                   |

액세스 애플리케이션에서 OIDC 범위를 구성하고 액세스가 SaaS 공급자에게 보내는 주장을 구성할 수 있습니다. 예를 들어, 제거 할 수 있습니다.`groups`SaaS 애플리케이션이 사용자 그룹 정보를 수신할 필요가 없는 경우 범위.

### 필터 그룹

내 계정**그룹 필터 regex**, 당신은 당신이 포함하려는 ID 공급자 그룹을 정의하는 정규 표현식을 입력 할 수 있습니다`groups`범위. 예를 들어, 표현을 입력하면`(^TEAM-Engineering-.$)|(^TEAM-Product-.$)`, TEAM-Engineering-A 또는 TEAM-Product-B와 같은 이름만 가진 그룹은 SaaS 신청에게 통과될 것입니다.

### 추가 청구

추가하려면 OIDC는 SaaS 애플리케이션에 전송된 ID 토큰에 주장하고, 각 청구에 대한 다음 필드를 구성합니다.

- **이름 \***: OIDC 클레임 이름
- **관련 상품**: 이 주장이 포함되어야하는 OIDC 범위를 선택하십시오. 대부분의 경우, 우리는 selecting를 추천합니다`profile`이미 IdP에서 다른 사용자 정의 주장을 포함.
- **IdP 청구**: 이 OIDC 주장에 지도해야 하는 정체성 공급자 가치. 모든 것을 선택할 수 있습니다.[SAML 속성](/cloudflare-one/integrations/identity-providers/generic-saml/#saml-headers-and-attributes)또는[OIDC 청구](/cloudflare-one/integrations/identity-providers/generic-oidc/#custom-oidc-claims)Zero Trust IdP 통합으로 구성되었습니다.
- **견적 요청**: 청구가 필요하지만 IdP에 의해 제공되지 않는 경우 Cloudflare는 인증 요청을 실패하고 오류 페이지를 표시합니다.
- **IdP 청구 당 추가**: (선택) SaaS 애플리케이션을 위한 여러 ID 제공 업체에서 설정하면 각 IdP에 대한 다른 속성 매핑을 선택할 수 있습니다. 이 값은 부모를 무시합니다.**IdP 청구**.

### OIDC 흐름

일부 SaaS 응용 프로그램은 SSO 공급자가 백엔드 인증없이 브라우저에 토큰을 제공해야합니다. SaaS에 대한 액세스는 다음 OIDC 흐름을 지원합니다:

- **추가 OIDC 흐름 없음**: (기본) 귀하의 응용 프로그램이 추가 흐름을 필요로하지 않는 한 추천.
- **하이브리드 흐름**: 사용자를 인증하기 전에 ID 토큰에서 정보를 요구하는 애플리케이션에 의해 사용됩니다.
- **Implicit 흐름**: (추천하지 않음) 비밀을 저장하지 않는 frontend 응용 프로그램에 의해 일반적으로 사용 하 고 지원 하지 않는**클라이언트 비밀 없는 PKCE**.

Cloudflare는 다양한`response_type`선택한 흐름에 따라 인증 요청의 값. 예를 들어, implicit 흐름은 Cloudflare를 사용하여 ID 토큰, 액세스 토큰 또는 인증 엔드포인트에서 ID 토큰 및 액세스 토큰을 반환합니다.

| `response_type`계정 정보 | 기본 흐름 | 공급 업체 | Implicit 흐름 |
| -------------------- | ----- | ----- | ----------- |
| `code`               | ✅     | ✅     | ❌           |
| `id_token`           | ❌     | ✅     | ✅           |
| `token`              | ❌     | ✅     | ✅           |

관련 기사`id_token`승인 요청에서, 켜기**Authorization Endpoint에서 ID 토큰을 반환**. 포함`token`, 켜기**Authorization Endpoint에서 액세스 토큰을 반환**

[Cloudflare 지역 1](https://www.cloudflare.com/products/zero-trust/email-security/)피싱, 스팸, 다른 악성 메시지에서 조직의 inbox를 보호하는 이메일 보안 플랫폼입니다. 이 가이드는 Cloudflare One에서 SAML 애플리케이션으로 영역을 구성하는 방법을 다룹니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- 귀하의 지역 1 계정에 대한 관리자 액세스
- 사용자의 이메일 영역 1 Cloudflare에 이메일 일치 한국어

## 1. 지역을 Cloudflare에 추가하십시오 한국어

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.

2. 제품정보**앱 추가**.

3. 제품정보**SaaS 서비스**.

4. 내 계정**제품 설명**필드, 입력`Area 1`선택하기**지역 1**. (Area 1은 현재 기본 드롭다운 메뉴에 나열되지 않습니다.)

5. 응용 프로그램 구성에 대한 다음 값을 입력하십시오:
   |                          |                                                    |
   | ------------------------ | -------------------------------------------------- |
   | **기업 ID**                | `https://horizon.area1security.com`                |
   | **Assertion 소비자 봉사 URL** | `https://horizon.area1security.com/api/users/saml` |
   | **이름 ID 체재**             | *이름 \**                                            |

6. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기

7. 신청 저장.

## 2. 지역 1를 위한 SSO를 형성하십시오

마지막으로 Cloudflare Access를 통해 로그인 할 수 있도록 1 영역을 구성해야합니다.

1. 내 계정[지역 1 포털](https://horizon.area1security.com/), 이동**계정 설정** > **사이트맵**.

2. 기타 제품**단일 로그인**.

3. (선택) 접속을 통해 로그인할 수 있도록 설정**SSO 강화**으로*모든 것*. SSO가 시행될 때, 사용자는 더 이상 지역 1개의 credentials로 로그인할 수 없습니다.

4. 내 계정**SAML SSO 도메인**, 입력`<your-team-name>.cloudflareaccess.com`.

5. Metadata XML 파일을 가져옵니다:
   1. Cloudflare에서 하나, 복사**SSO 엔드포인트**당신의 신청을 위해.

      ![Cloudflare One의 SaaS 응용 프로그램 SSO 설정 복사](~/assets/images/cloudflare-one/applications/saas-sso-endpoint.png)

   2. 새로운 브라우저 탭에서 붙여넣기**SSO 엔드포인트**관련 기사`/saml-metadata`URL의 끝에. 예를 들어,`https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/sso/saml/<app-id>/saml-metadata`.

   3. 결과 메타데이터를 복사합니다.

6. 1개의 포털로 돌아와 메타데이터를 붙여넣기**메타데이터 XML**.

   ![지역 1 포털에서 SSO 구성](~/assets/images/cloudflare-one/applications/area1-sso-config.png)

7. 제품정보**업데이트 설정**.

App Launcher에 응용 프로그램을 추가하면 이동하여 통합을 테스트 할 수 있습니다.`<your-team-name>.cloudflareaccess.com`.

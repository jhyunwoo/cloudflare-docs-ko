사이트맵 Access는 추가 인증 레이어를 SaaS 애플리케이션에 추가할 수 있습니다. 액세스와 SaaS 애플리케이션을 통합하면 Cloudflare를 단일 Sign-On 공급자로 사용하여 애플리케이션에 로그인합니다. 사용자가 그 응용 프로그램에 대한 구성 된 정체성 제공 업체로 리디렉션하고 액세스 정책을 통과하면 만 액세스 권한을 부여됩니다.

Cloudflare는 SAML 또는 OIDC 인증 프로토콜을 지원하는 SaaS 애플리케이션의 대부분을 통합합니다. 아래 나열된 응용 프로그램을 볼 수없는 경우, 참조[일반 SAML](/cloudflare-one/access-controls/applications/http-apps/saas-apps/generic-saml-saas/)또는[일반 OIDC](/cloudflare-one/access-controls/applications/http-apps/saas-apps/generic-oidc-saas/)SaaS 애플리케이션의 문서에 대한 가이드 및 상담.

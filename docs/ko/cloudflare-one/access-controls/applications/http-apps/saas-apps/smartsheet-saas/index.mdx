이 가이드는 구성하는 방법[스마트 시트](https://help.smartsheet.com/articles/2483123-domain-level-saml-configuration)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Smartsheet Enterprise 계정에 대한 관리자 액세스
- ·[이름 \*](https://help.smartsheet.com/articles/2483051-domain-management)Smartsheet에서 확인

:::참조
Smartsheet에서 SSO는 도메인을 구성합니다. 동일한 도메인을 사용하는 여러 계획이있는 경우 SSO 구성은 계획 유형에 관계없이 모든 Smartsheet 사용자에게 적용됩니다.
주요 특징

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 입력`Smartsheet`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `urn:amazon:cognito:sp:us-east-1_xww1cbP43`
   - **Assertion 소비자 봉사 URL**: `https://saml.authn.smartsheet.com/saml2/idpresponse`
   - **이름 ID 체재**: *고유 ID*
7. 제출하기**SAML 메타데이터 엔드포인트**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. Smartsheet에 있는 SAML SSO 공급자 창조하고 시험하십시오

1. Smartsheet Admin Center에서 이동**계정 설정** > **인증현황** > **SAML IdP 추가**.
2. 내 계정**기타 IdP (Customize)**, 선택**설정하기**.
3. 제품정보**이름 \***.
4. 이름 \***XML URL**, Cloudflare에 있는 신청 윤곽에서 SAML 메타데이터 엔드포인트를 풀십시오.
5. 이름 \***이름 SAML IdP**, 이름을 입력 (예를 들어,`Cloudflare Access`).
6. 제품정보**저장 & 다음**.
7. 제품정보**연결하기**액세스를 통해 로그인. 유효성 검사가 성공하면 볼 수 있습니다.**SAML IdP가 성공적으로 연결되었습니다!**&#xC774;름 \* 설정 확인 페이지를 닫습니다.
8. 기타 제품**나는 성공적으로 연결을 확인했다**.
9. 제품정보**저장 & 다음**.
10. 이름 \***SAML IdP에 도메인 할당**, 원하는 도메인을 선택하십시오.
11. 제품정보**저장 및 다음**그리고 그때**제품 정보**.

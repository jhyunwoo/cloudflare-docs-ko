이 가이드는 구성하는 방법[채용 정보](https://compass.coupa.com/en-us/products/product-documentation/integration-technical-documentation/coupa-core-user-authentication/coupa-saml-sso-setup)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Coupa Stage 또는 Production 계정에 대한 관리자 액세스

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 입력`Coupa`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**:
     `sso-stg1.coupahost.com`단계 계정 또는`sso-prd1.coupahost.com`생산 계정
   - **Assertion 소비자 봉사 URL**: `https://sso-stg1.coupahost.com/sp/ACS.saml2`단계 계정 또는`https://sso-prd1.coupahost.com/sp/ACS.saml2`생산 계정
   - **이름 ID 체재**: *이름 \**
7. 제출하기**Access Entity ID 또는 발급자**·**SAML 메타데이터 엔드포인트**.
8. 내 계정**과태 릴레이 국가**, 입력`https://<your-subdomain>.coupahost.com/sessions/saml_post`.
9. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
10. 신청 저장.

## 2. 메타데이터 파일을 다운로드

1. Cloudflare의 애플리케이션 구성에서 SAML 메타데이터 엔드포인트를 붙여넣기 웹 브라우저에서 하나.
2. URL의 내용을 다운로드하려면 브라우저 별 단계를 따르십시오.`.xml`파일.

## 3. Coupa에 있는 SAML SSO 공급자 추가하십시오

1. Coupa에서**설치하기** > **회사 설정** > **보안 제어**.
2. 이름 \***SAML 사용 로그인**, 켜기**SAML 사용 로그인**.
3. 내 계정**IdP 메타데이터 업로드**, 선택**파일 형식**, 업로드`.xml`다운로드 한 파일[2. 메타데이터 파일을 다운로드](#2-download-the-metadata-file).
4. 기타 제품**고급 옵션**.
5. 제품 정보**로그인 페이지 URL**·**타임아웃 URL**, 입력`https://sso-stg1.coupahost.com/sp/startSSO.ping?PartnerIdpId=<access-entity-id-or-issuer>&TARGET=https://<your-subdomain>.coupahost.com/sessions/saml_post`Cloudflare One의 애플리케이션 구성에서 Access Entity ID 또는 Issuer를 사용하여.
6. 제품정보**제품 정보**.

## 3. 시험 사용자를 만들고 통합을 시험하십시오

1. Coupa에서**설치하기** > **회사 설정** > **이름 \***.
2. 제품정보**이름 \***, 그 후에 당신의 시험 사용자를 위한 사용자 세부사항을 입력하십시오. 제품 정보**로그인**·**단일 로그인 ID**, 사용자의 이메일 주소를 입력하십시오.
3. 제품정보**제품 정보**.
4. 브라우저 창을 열고 Coupa URL로 이동합니다. Cloudflare Access 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 안내합니다.
5. 로그인이 성공되면 SSO를 위해 다른 사용자를 구성할 수 있습니다.**단일 로그인 ID**내 계정**설치하기** > **회사 설정** > **이름 \***> 사용자 이름.

:::참조

다음 URL을 사용하여 SSO를 우회하고 사용자 이름과 암호를 통해 로그인 할 수 있습니다.`https://<your-subdomain>.coupahost.com/sessions/support_login`.

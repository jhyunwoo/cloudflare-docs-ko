이 가이드는 구성하는 방법[다운로드](https://help.dropbox.com/security/sso-admin)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Dropbox Advanced, Business Plus 또는 Enterprise 계정에 대한 관리 액세스

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 선택`Dropbox`.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `Dropbox`
   - **Assertion 소비자 봉사 URL**: `https://www.dropbox.com/saml_login`
   - **이름 ID 체재**: *이름 \**
7. 제출하기**SSO 엔드포인트**·**공공 키**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. 인증서 파일 만들기

1. 패스워드**공공 키**텍스트 편집기에서.
2. 인증서를 포장`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.
3. 파일 확장을 설정`.pem`견적 요청

## 3. SAML SSO 공급자를 Dropbox에 추가하십시오

1. Dropbox에서 프로필 사진으로 이동 >**계정 설정** > **관리자 콘솔** > **보안 보안** > **단일 사인온**.
2. 제품 정보**단일 사인온**, 선택*옵션 정보*.
3. 제품정보**ID 공급자 로그인 URL 추가**.
4. Cloudflare One의 애플리케이션 구성에서 SSO 엔드포인트를 붙여넣고 선택**이름 \***.
5. 제품정보**X.509 인증서 추가**다운로드`.pem`단계별 파일[2. 인증서 파일 만들기](#2-create-a-certificate-file).
6. 관련 기사**SSO 로그인 URL**. 이것은 사용자 정의 Dropbox SSO URL입니다.
7. 제품정보**제품 정보**.

## 3. 통합을 시험하고 SSO를 요구합니다

1. 브라우저 창을 열고 맞춤 Dropbox SSO URL로 이동합니다. Cloudflare Access 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 안내합니다.

2. 이 성공 후 SSO를 통해 로그인 할 사용자를 요구할 수 있습니다. 프로필 사진으로 이동 >**계정 설정** > **관리자 콘솔** > **보안 보안** > **단일 사인온**.를 위해**단일 사인온**, 선택*견적 요청*. Dropbox는 변경의 그들을 통지하는 사용자에게 이메일을 보낼 것입니다.

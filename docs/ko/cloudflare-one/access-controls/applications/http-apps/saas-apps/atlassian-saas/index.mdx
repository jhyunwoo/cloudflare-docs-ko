- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Atlassian Cloud 계정 관리
- Atlassian Guard 표준 구독
- ·[이름 \*](https://support.atlassian.com/user-management/docs/verify-a-domain-to-manage-accounts/)Atlassian Cloud에서 확인

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 선택*아틀라스*.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 제출하기**Access Entity ID 또는 발급자**, **공공 키**·**SSO 엔드포인트**.
7. 이 창을 엽니다. 당신은 단계에 이 윤곽을 완료할 것입니다[4. Cloudflare One에 SaaS 애플리케이션 추가](#4-finish-adding-a-saas-application-to-cloudflare-one).

## 2. x.509 인증서 만들기

1. 패스워드**공공 키**텍스트 편집기에서.
2. 인증서를 포장`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.

## 3. Atlassian Cloud의 ID 공급자 및 SAML SSO 구성

1. Atlassian 클라우드에서 이동**보안 보안** > **Identity 공급자**.

2. 제품정보**다른 공급자** > **제품 정보**.

3. 제품 정보**전화번호**, 원하는 이름을 입력하십시오. 예를 들어 입력할 수 있습니다.`Cloudflare Access`.

4. 제품정보**더 보기** > **SAML 싱글 사인온 설정** > **이름 \***.

   :::참조
   이 화면은 진행하기 전에 인증 정책을 작성하는 것이 좋습니다. 당신은 단계에 이것을 할 것입니다[5. 통합을 테스트하기위한 응용 정책을 작성](#5-create-an-authentication-policy-to-test-integration).
   :::

5. 다음 필드에 기입:
   - **Identity 공급자 Entity ID**: Cloudflare One의 Application 구성에서 Entity ID 또는 Issuer에 액세스합니다.
   - **ID 공급자 SSO URL**: Cloudflare One의 애플리케이션 구성에서 SSO 엔드포인트.
   - **공공 x509 인증서**: 전체 x.509 인증서를 단계로 붙여넣기[2. x.509 인증서 만들기](#2-create-a-x509-certificate).

6. 제품정보**이름 \***.

7. 제출하기**서비스 제공업체 URL**·**서비스 제공 업체 assertion 소비자 서비스 URL**.

8. 제품정보**이름 \***.

9. 이름 \***링크 도메인**, SAML SSO와 사용하려는 도메인을 선택하십시오.

10. 제품정보**이름 \*** > **정지 및 저장 SAML**.

## 4. Cloudflare One에 SaaS 애플리케이션 추가

1. 개방 Cloudflare 한 창, 다음 필드에 기입:
   - **기업 ID**: Atlassian Cloud SAML SSO 설정에서 서비스 제공 업체 인 엔티티티 URL.
   - **Assertion 소비자 봉사 URL**: Atlassian Cloud SAML SSO 설정에서 서비스 제공자 assertion 소비자 서비스 URL.
   - **이름 ID 체재**: *이름 \**
2. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
3. 신청 저장.

## 5. 인증 정책을 작성하여 통합 테스트

Atlassian Cloud에서 SSO를 활성화하려면[Atlassian 인증 정책](https://support.atlassian.com/security-and-access-policies/docs/configure-authentication-policies-for-your-organization/):

1. Atlassian 클라우드에서 이동**보안 보안** > **인증 정책**.
2. 제품정보**추가 정책**.
3. 이름 \***관련 기사**SAML SSO를 구성하는 데 사용되는 ID 공급자를 선택하십시오.
4. 제품 정보**정책 이름**, 원하는 이름을 입력하십시오.
5. 제품정보**더 보기**.
6. 내 계정**계정 설정**, 켜기**단일 사인온 강화**.
7. 내 계정**이름 \***, 선택**회원 가입**.
8. 내 계정**개인 사용자**, 드롭다운에서 원하는 테스트 사용자(s)를 선택하고, 선택**회원 가입**.
9. 내 계정**계정 설정**, 선&#xD0DD;**(주)** > **(주)**.

## 6. 통합 테스트

브라우저 창을 열고 테스트 인증 정책에 추가된 테스트 사용자의 자격 증명으로 로그인하십시오. Cloudflare Access 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 안내합니다. 이 성공할 때, 켜기**단일 사인온 강화**원하는 인증 정책에서, 또는 단계로 만든 응용 프로그램에 원하는 사용자를 추가[5. 통합을 테스트하는 Application Policy 만들기](#5-create-an-authentication-policy-to-test-integration).

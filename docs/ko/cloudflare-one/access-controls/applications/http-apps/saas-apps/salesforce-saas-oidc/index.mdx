이 가이드는 구성하는 방법[회사연혁](https://help.salesforce.com/s/articleView?id=sf.sso_provider_openid_connect.htm\&type=5)Cloudflare One의 OpenID Connect (OIDC) 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Salesforce 계정에 대한 관리 접근

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 선택*회사연혁*.
4. 인증 프로토콜의 경우, 선택**OIDC 소개**.
5. 제품정보**앱 추가**.
6. 내 계정**채용 정보**, ID 토큰에서 보내는 액세스 권한을 원하는 속성을 선택합니다.
7. 내 계정**리디렉션 URL**, Salesforce에서 얻은 콜백 URL을 입력하십시오 (`https://<your-domain>.my.salesforce.com/services/authcallback/<URL Suffix>`). 더 알아보기[SSO 공급자를 Salesforce에 추가하십시오](#2-add-a-sso-provider-to-salesforce)이 값을 얻기에 대한 지침.
8. (선택) 사용[키 교환 증명 (PKCE)](https://www.oauth.com/oauth2-servers/pkce/)프로토콜이 IdP에 의해 지원되는 경우. PKCE는 모든 로그인 시도에서 수행됩니다.
9. 다음 값을 복사:
   - **고객 ID**
   - **고객 비밀**
   - **인증 endpoint**
   - **토큰 엔드포인트**
   - **사용자 정보 endpoint**
10. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
11. (선택) 안으로**경험 설정**, 구성[App Launcher 설정](/cloudflare-one/access-controls/access-settings/app-launcher/)에 의해**App Launcher에서 앱 사용 가능**그리고,**앱 실행 URL**, 입력`https://<your-domain>.my.salesforce.com`.
12. 신청 저장.

## 2. Salesforce에 SSO 공급자를 추가하십시오

1. Salesforce에서, 이동**설치하기**.
2. 내 계정**빠른 찾기**상자, 입력`auth`선택하기**Auth 공급자**.
3. 제품정&#xBCF4;**- 한국어**.
4. 공급자 유형의 경우, 선택**OpenID 연결**.
5. SSO 공급자의 이름을 입력하십시오 (예를 들어,`Cloudflare Access`).
6. Cloudflare Access에서 얻은 값을 가진 다음 필드에 채우기:
   - **소비자 키**: 고객 ID
   - **소비자 비밀**: 고객 비밀
   - **Endpoint URL 생성**: 승인 종료점
   - **토큰 엔드포인트 URL**: 토큰 엔드포인트
   - **사용자 정보 Endpoint URL**: 사용자 정보 endpoint
   - **토큰 발행자**: 발행인
7. (선택) 사용**Code Exchange용 Proof Key 사용**액세스가 활성화되면.
8. 내 계정**기본 범위**, Access에서 구성 된 범위의 공간 통합 목록 (예를 들어,`openid email profile groups`).
9. 제품정보**제품 정보**.
10. 제출하기**콜백 URL**:
    ```txt
    https://<your-domain>.my.salesforce.com/services/authcallback/<URL Suffix>
    ```
11. Cloudflare에서 하나, 콜백 URL을 붙여넣기**URL을 다시**이름 \*

통합을 테스트하려면 incognito 브라우저 창을 열고**Test-Only 초기화 URL** ( `https://<your-domain>.my.salesforce.com/services/auth/test/<URL Suffix>`)

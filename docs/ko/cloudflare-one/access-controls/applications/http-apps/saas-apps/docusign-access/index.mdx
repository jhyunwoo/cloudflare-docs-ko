## 2. DocuSign SSO 인스턴스 구성

1. DocuSign에서 청구된 도메인이 있습니다.

2. DocuSign Admin 대시보드에서, 선택**Identity 공급자**.

3. Identity Providers 페이지에, 선택**추가 IDENTITY PROVIDER**. 저장된 Access Application 값에서 다음 mappings를 사용하십시오:
   - **이름 \***: 원하는 이름을 선택하십시오.
   - **Identity 공급자 발행인**: 기업 ID.
   - **Identity Provider 로그인 URL**: 소비자 봉사 URL.

4. Identity 공급자를 저장하십시오.

5. 인증서를 업로드*DocuSign ID 공급자*메뉴.

6. SAML Attribute 맵핑 구성. Attribute Names는 값과 일치해야 합니다.**IdP 가치**액세스 신청에서.

7. Identity Provider의 화면으로 돌아가고 선택**관련 기사** > **이름 \***. 복사하고 다음을 저장하십시오:
   - 서비스 제공자 Issuer URL.
   - 서비스 제공자 Assertion 소비자 봉사 URL.

## 3. Cloudflare 구성 완료

1. DocuSign 앱으로 돌아가기**액세스 제어** > **이름 \***.
2. 제품정보**제품정보**.
3. 다음 맵핑을 사용하십시오:
   - EntityID->서비스 제공자 발급 URL.
   - Assertion 소비자 봉사 URL -> 서비스 제공자 Assertion 소비자 봉사 URL.
4. 신청 저장.

준비가되면 DocuSign 계정에 SSO를 활성화하고 Cloudflare SSO 및 Identity Provider를 통해 DocuSign에 로그인 할 수 있습니다.

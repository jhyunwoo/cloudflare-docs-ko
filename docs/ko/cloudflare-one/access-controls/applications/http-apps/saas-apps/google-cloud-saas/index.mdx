이 가이드는 구성하는 방법[Google 클라우드](https://support.google.com/cloudidentity/topic/7558767)Cloudflare 1의 SAML 응용 프로그램입니다.

:::카트로션

액세스로 Google Cloud를 구성할 때 다음 제한이 적용됩니다.

- 로그인할 수 없습니다.[구글 +](/cloudflare-one/integrations/identity-providers/google/)또는[Google 작업 공간](/cloudflare-one/integrations/identity-providers/google-workspace/)Google Cloud가 액세스로 구성 된 후 정체성 공급자로.

- Google Cloud 계정의 단일 서명 온 공급자로 액세스의 통합은 Google 슈퍼 관리자를 위해 작동하지 않습니다. 그것은 다른 사용자를 위해 일할 것입니다.
  주요 특징

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Google Workspace 계정에 대한 관리자 액세스
- [Cloud Identity 무료 또는 프리미엄](https://support.google.com/cloudidentity/answer/7389973)조직의 Google Cloud 계정 설정

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스** > **제품정보**.
3. 제품 정보**제품 설명**, 선택*Google 클라우드*.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 다음 필드에 기입:
   - **기업 ID**: `google.com`
   - **Assertion 소비자 봉사 URL**: `https://www.google.com/a/<your_domain.com>/acs`
   - **이름 ID 체재**: *이름 \**
7. 제출하기**SSO 엔드포인트**, **Access Entity ID 또는 발급자**·**공공 키**.
8. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
9. 신청 저장.

## 2. x.509 인증서 만들기

1. Cloudflare의 애플리케이션 구성에서 공개 키 붙여넣기 텍스트 편집기에 하나.
2. 인증서를 포장`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`.
3. 파일 확장을 설정`.crt`견적 요청

## 3. Google Cloud에서 SSO 공급자 만들기

1. 내 계정[Google 관리자 콘솔](https://admin.google.com/), 이동**보안 보안** > **인증현황** > **SSO 제3자 IdP**.
2. 제품정보**귀하의 조직을위한 타사 SSO 프로필** > **SSO 프로필 추가**.
3. 기타 제품**SSO를 타사 정체 공급자로 설정**.
4. 다음 정보를 입력:
   - **로그인 페이지 URL**: Cloudflare One의 애플리케이션 구성에서 SSO 엔드포인트.
   - **로그인 페이지 URL**: `https://<team-name>.cloudflareaccess.com/cdn-cgi/access/logout`, 어디`<team-name>`Cloudflare는 한국어<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>.
   - **인증 인증서**: 업로드`.crt`단계에서 인증서 파일[2. x.509 인증서 만들기](#2-create-a-x509-certificate).
5. (선택) 켜기**도메인 특정 발행인 사용**. 이 옵션을 선택하면 Google은 Google Cloud 도메인 (Google Cloud Domain)에 대한 발행자를 보낼 것입니다.`google.com/a/<your_domain.com>`표준 대신`google.com`).

## 4. 통합 테스트

브라우저 창을 열고 Google Cloud URL로 이동하십시오 (`https://console.cloud.google.com/a/<your_domain.com>`). 슈퍼 관리자 계정에 속하지 않는 자격 증명을 사용하여 로그인.

## 문제 해결

`Error: "G Suite - This account cannot be accessed because the login credentials could not be verified."`

이 오류를 볼 경우 공공 키와 개인 키가 일치하지 않는 가능성이 있습니다. 인증서 파일은 올바른 공공 키를 포함합니다.

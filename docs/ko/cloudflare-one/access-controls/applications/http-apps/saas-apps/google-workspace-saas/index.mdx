이 가이드는 구성하는 방법[Google 작업 공간](https://support.google.com/a/topic/7579248?ref_topic=7556686\&sjid=14539485562330725560-NA)Cloudflare 1의 SAML 응용 프로그램입니다.

:::참조

Google Workspace 계정의 단일 서명 온 공급자로 액세스의 통합은 Google 슈퍼 관리자를 위해 작동하지 않습니다. 그것은 다른 사용자를 위해 일할 것입니다.

:::

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Google Workspace 계정에 대한 관리자 액세스

## 1. Cloudflare One에 적용

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**액세스 제어** > **이름 \***.

2. 제품정보**앱 추가**.

3. 제품정보**SaaS 서비스**.

4. 다음 정보를 입력:
   - **제품 설명**: *구글 +*.
   - **기업 ID**: Google에서 제공하는 값 사용[SAML SSO 공급자 구성](https://saml-doc.okta.com/SAML_Docs/How-to-Enable-SAML-2.0-in-Google-Apps.html).
   - **Assertion 소비자 봉사 URL**: `https://www.google.com/a/<your_domain.com>/acs`, 어디`<your_domain.com>`Google Workspace 도메인입니다.
   - **이름 ID 체재**: *이름 \**.

:::카트로션

액세스 뒤에 Google Workspace를 넣을 때, 사용자는 사용할 수 없습니다[구글 +](/cloudflare-one/integrations/identity-providers/google/)또는[Google 작업 공간](/cloudflare-one/integrations/identity-providers/google-workspace/)ID 공급자로. 액세스 뒤에 Google Workspace를 확보하기 위해[인증 루프](/cloudflare-one/faq/troubleshooting/#after-putting-google-workspace-behind-access-i-cant-log-in-it-keeps-redirecting-between-access-and-google-without-ever-completing-authentication), 인증에 대한 다른 ID 공급자 (Google 또는 Google Workspace)를 구성해야합니다.
주요 특징

5. [액세스 정책 만들기](/cloudflare-one/access-controls/policies/)당신의 신청을 위해. 예를 들어, 사용자가 사용할 수 있습니다.`@your_domain.com`이메일 주소

6. 제출하기**SSO 엔드포인트**, **Access Entity ID 또는 발급자**·**공공 키**. 이 값은 Google Workspace를 구성하는 데 사용됩니다.

7. 신청 저장.

## 2. 당신의 공중 열쇠에서 증명서를 창조하십시오

1. 복사한 다음 붙여넣기**공공 키**텍스트 편집기로.

2. 인증서를 포장`-----BEGIN CERTIFICATE-----`·`-----END CERTIFICATE-----`. 예를 들면,

   ```txt
   -----BEGIN CERTIFICATE-----
   <PUBLIC_KEY>
   -----END CERTIFICATE-----
   ```

3. 파일 확장을 설정`.crt`견적 요청

## 3. Google Workspace에서 SSO 공급자 만들기

1. 로그인[Google 관리자 콘솔](https://admin.google.com/).
2. 오시는 길**보안 보안** > **인증현황** > **SSO 제3자 IdP**.
3. 제품정보**귀하의 조직을위한 타사 SSO 프로필**.
4. 이름 \***SSO를 타사 정체 공급자로 설정**.
5. 다음 정보를 입력:
   - **로그인 페이지 URL**: 복사 및 붙여넣기**SSO 엔드포인트**Cloudflare에서 한국어
   - **로그인 페이지 URL**: `https://<team-name>.cloudflareaccess.com/cdn-cgi/access/logout`, 어디`<team-name>`Cloudflare는 한국어<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>.
   - **인증 인증서**: 공용 키를 포함하는 인증서 파일을 업로드합니다.
6. (선택) 사용**도메인 특정 발행인 사용**. 이 옵션을 선택하면 Google은 Google Workspace 도메인 (Google Workspace 도메인)에 대한 발행자를 보낼 것입니다.`google.com/a/<your_domain.com>`표준 대신`google.com`).

## 4. 통합 테스트

1. 내 계정[Google 관리자 콘솔](https://admin.google.com/), 이동**앱 다운로드** > **Google 작업 공간** > **사이트맵** > **설치하기**.
2. Gmail을 복사**웹 주소**.
3. 브라우저 창을 열고 Gmail 웹 주소로 이동하십시오 (예를 들어,`https://mail.google.com/a/<your_domain.com>`).

액세스 로그인 화면이 나타납니다.

## 문제 해결

`Error: "G Suite - This account cannot be accessed because the login credentials could not be verified."`

이 오류를 볼 경우 공공 키와 개인 키가 일치하지 않는 가능성이 있습니다. 인증서 파일은 올바른 공공 키를 포함합니다.

이 가이드는 구성하는 방법[회사 소개](https://docs.servicenow.com/bundle/washingtondc-platform-security/page/integrate/single-sign-on/task/create-OIDC-configuration-SSO.html)Cloudflare에 있는 OIDC 신청으로.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- ServiceNow 계정 관리

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 입력`ServiceNow`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**OIDC 소개**.
5. 제품정보**앱 추가**.
6. 내 계정**채용 정보**, ID 토큰에서 보내는 액세스 권한을 원하는 속성을 선택합니다.
7. 내 계정**리디렉션 URL**, 입력`https://<INSTANCE-NAME>.service-now.com/navpage.do`.
8. (선택) 사용[키 교환 증명 (PKCE)](https://www.oauth.com/oauth2-servers/pkce/)프로토콜이 IdP에 의해 지원되는 경우. PKCE는 모든 로그인 시도에서 수행됩니다.
9. 제출하기**고객 비밀**·**고객 ID**.
10. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
11. (선택) 안으로**경험 설정**, 구성[App Launcher 설정](/cloudflare-one/access-controls/access-settings/app-launcher/)에 의해**App Launcher에서 앱 사용 가능**그리고,**앱 실행 URL**, 입력`https://<INSTANCE-NAME>.service-now.com`.
12. 신청 저장.

## 2. Multiple Provider Single Sign-On Installer 플러그인을 ServiceNow에 추가하십시오.

1. In ServiceNow, 선택**모든 것**.
2. 검색 바에서 입력`System Applications`·**모든 용도**, 선택**모든 것**.
3. 검색 바에서 입력`Integration - Multiple Provider Single Sign-On Installer`.
4. 제품정보**설치하기**.
5. 견적 요청**지금 설치**선택 및 선택**설치하기**.

## 3. ServiceNow에서 OIDC SSO 공급자 추가 및 테스트

1. 제품정보**모든 것**.
2. 검색 바에서 입력`Multi-Provider SSO`, 그리고 선택**Identity 공급자**.
3. 제품정&#xBCF4;**- 한국어** > **OpenID 연결**.
4. 팝업에서 다음 필드를 작성하십시오.
   - **이름 \***: SSO의 이름 (예를 들면,`Cloudflare Access`). 그렇지 않으면, 사용자는 ServiceNow에 로그인 할 때이 이름을 선택합니다.
   - **고객 ID**: **고객 ID**Cloudflare One의 응용 구성에서.
   - **고객 비밀**: **고객 비밀**Cloudflare One의 응용 구성에서.
   - **잘 알려진 구성 URL**: `https://<TEAM-DOMAIN>.cloudflareaccess.com/cdn-cgi/access/sso/oidc/<CLIENT-ID>/.well-known/openid-configuration`.
5. 제품정보**제품정보**.
6. 이름 \***지원하다**설정하기
7. 기타 제품**로그인 옵션으로 보기**, 및**SSO 상표**사용자 로그인 화면의 라벨을 입력하면 원하는 경우.
8. 제품정&#xBCF4;**(주)**.

## 4. 통합 테스트

로그인 화면에 나타나는 SSO를 위해, 당신은 있어야 합니다[계정 복구](https://docs.servicenow.com/bundle/washingtondc-platform-security/page/integrate/single-sign-on/concept/sso-acct-recovery.html)적어도 하나의 관리자 계정에서 활성화 및 구성. 계정 복구가 구성되면 ServiceNow에서 로그 아웃하고 incognito 브라우저 창을 엽니다. ServiceNow URL로 이동하십시오. SSO 이름을 선택하면 ID 공급자와 로그인할 수 있습니다. 통합이 성공하면 OIDC 구성 화면으로 돌아갈 수 있습니다.**기본 정보**및/또는**자동 간접 IDP**.

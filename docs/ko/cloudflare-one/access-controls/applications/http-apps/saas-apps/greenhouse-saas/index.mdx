이 가이드는 구성하는 방법[Greenhouse 채용](https://support.greenhouse.io/hc/en-us/articles/360040753811-Configure-single-sign-on-SSO-for-Greenhouse-Recruiting)Cloudflare 1의 SAML 응용 프로그램입니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Advanced 또는 Expert Greenhouse Recruiting 사이트에 대한 관리자 액세스

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 입력`Greenhouse`그리고 일치하는 textbox를 선택합니다.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 제출하기**SAML 메타데이터 엔드포인트**.
7. 이 창을 엽니다. 당신은 단계에 이 윤곽을 완료할 것입니다[4. Cloudflare One에 SaaS 애플리케이션 추가](#4-finish-adding-a-saas-application-to-cloudflare-one).

## 2. 메타데이터 파일을 다운로드

1. Cloudflare의 애플리케이션 구성에서 SAML 메타데이터 엔드포인트를 붙여넣기 웹 브라우저에서 하나.
2. URL의 내용을 다운로드하려면 브라우저 별 단계를 따르십시오.`.xml`파일.

## 3. 온실에 SAML SSO 공급자를 추가하십시오

1. Greenhouse 채용에서, 이동**설정하기**아이콘 >**Dev 센터** > **단일 사인온**.
2. 제출하기**SSO Assertion 소비자 URL**.
3. 이름 \***XML 파일 업로드**, 선택**파일 선택**, 업로드`.xml`단계로 만든 파일[2. 메타데이터 파일을 다운로드](#2-download-the-metadata-file).
4. 수정하기**기업 ID**으로`greenhouse.io`.
5. 선택 없이 이 창을 열지 않음**시험 시작**. 당신은 단계에 있는 이 윤곽을 완료할 것입니다[5. 통합 및 최종 구성 테스트](#5-test-the-integration-and-finalize-configuration).

## 4. Cloudflare One에 SaaS 애플리케이션 추가

1. 개방 Cloudflare 한 창, 다음 필드에 기입:
   - **기업 ID**: `greenhouse.io`
   - **Assertion 소비자 봉사 URL**: SSO Assertion Greenhouse Recruiting의 SSO 구성의 소비자 URL.
   - **이름 ID 체재**: *이름 \**
2. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
3. 신청 저장.

## 5. 통합 및 최종 구성 테스트

1. 열린 Greenhouse Recruiting 창에서 선택**시험 시작** > **지원하다**.
2. 브라우저 창을 열고 Greenhouse Recruiting URL로 이동하십시오. SSO 로그인 옵션을 선택하십시오. Cloudflare Access 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 안내합니다.
3. SSO 서명이 성공되면 이동**설정하기**아이콘 >**Dev 센터** > **단일 사인온**.
4. 제품정보**정의 구성**.
5. 본문 영역에서 입력`CONFIGURE`.
6. 제품정보**옵션 정보**. 이제 사용자는 SSO로 로그인 할 수 있습니다.

이 가이드는 구성하는 방법[Grafana 클라우드](https://grafana.com/docs/grafana-cloud/account-management/authentication-and-permissions/authorization/#configure-oauth-20-with-generic-oauth)Cloudflare에 있는 OIDC 신청으로.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어
- Grafana Cloud 계정 관리

## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가**.
3. 제품정보**SaaS 서비스**.
4. 제품 정보**제품 설명**, 입력`Grafana Cloud`그리고 일치하는 textbox를 선택합니다.
5. 인증 프로토콜의 경우, 선택**OIDC 소개**.
6. 제품정보**앱 추가**.
7. 내 계정**채용 정보**, ID 토큰에서 보내는 액세스 권한을 원하는 속성을 선택합니다.
8. 내 계정**리디렉션 URL**, 입력`https://<your-grafana-domain>/login/generic_oauth`.
9. (선택) 사용[키 교환 증명 (PKCE)](https://www.oauth.com/oauth2-servers/pkce/)프로토콜이 IdP에 의해 지원되는 경우. PKCE는 모든 로그인 시도에서 수행됩니다.
10. 제출하기**고객 비밀**, **고객 ID**, **토큰 엔드포인트**·**인증 endpoint**.
11. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
12. (선택) 안으로**경험 설정**, 구성[App Launcher 설정](/cloudflare-one/access-controls/access-settings/app-launcher/)에 의해**App Launcher에서 앱 사용 가능**그리고,**앱 실행 URL**, 입력`https://<your-grafana-domain>/login`.
13. 신청 저장.

## 2. Grafana Cloud에 SSO 공급자 추가

1. Grafana Cloud에서, 선택**메뉴메뉴**아이콘 >**주요사업** > **인증현황** > **유전자 OAuth**.
2. (선택)를 위해**표시 이름**, 새 디스플레이 이름을 입력 (예를 들어,`Cloudflare Access`). 사용자 선택**로그인 (display 이름)**&#x53;SO를 통해 서명 할 때.
3. 다음 필드에 기입:
   - **클라이언트 Id**: Cloudflare One의 애플리케이션 구성에서 클라이언트 ID
   - **고객 비밀**: Cloudflare One의 애플리케이션 구성에서 클라이언트 비밀
   - **채용 정보**: 삭제`user:email`Cloudflare One에서 설정된 범위를 입력
   - **Auth URL을**: Cloudflare One의 애플리케이션 구성에서 승인 종료점
   - **토큰 URL**: Cloudflare One의 애플리케이션 구성에서 토큰 엔드포인트
4. 제품정보**제품 정보**.

## 3. 통합 테스트

브라우저 창을 열고 Grafana 도메인으로 이동하십시오 (`https://<your-grafana-domain>/login`). 제품정보**로그인 (display 이름)**. Cloudflare 액세스 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 프롬프트됩니다.

## 자주 묻는 질문

- 이름 \*[회사 소개](/cloudflare-one/integrations/identity-providers/)Cloudflare에서 구성 한국어

## 1. SaaS 애플리케이션 URL 받기

SaaS 애플리케이션 계정에서 다음 URL을 가져옵니다:

- **기업 ID**: SaaS 애플리케이션을 위해 발급된 고유 URL`https://<your-domain>.my.salesforce.com`.
- **Assertion 소비자 봉사 URL**: SAML assertions 수신 및 파싱을 위한 서비스 제공업체의 엔드포인트.

## 3. SaaS 애플리케이션에서 SSO 구성

다음으로 SaaS 애플리케이션을 구성하여 Cloudflare Access를 통해 로그인해야 합니다. 타사 SAML SSO 공급자를 구성하는 방법에 대한 지침에 대한 SaaS 응용 문서 참조. Cloudflare One의 다음 값이 필요합니다.

- **SSO 엔드포인트**
- **Access Entity ID 또는 발급자**
- **공공 키**

SaaS 애플리케이션에 이 데이터를 수동으로 입력하거나 메타데이터 XML 파일을 업로드할 수 있습니다. metadata는 URL에서 사용할 수 있습니다.`<SSO endpoint>/saml-metadata`.

### SAML 응답

SAML ID 공급자로 행동할 때 Cloudflare는 SAML 응답과 SHA-256 알고리즘을 사용하여 SAML Assertion을 모두 서명합니다. SaaS 애플리케이션은 이 서명을 사용하여 검증할 수 있습니다.**공공 키**SaaS 애플리케이션에 업로드합니다.

## 4. 통합 테스트

브라우저 창을 열고 SaaS 애플리케이션의 로그인 URL로 이동합니다. Cloudflare Access 로그인 화면에 리디렉션하고 정체 공급자와 서명하도록 안내합니다.

## SAML 속성

[SAML 속성](/cloudflare-one/integrations/identity-providers/generic-saml/#saml-headers-and-attributes)Cloudflare Access가 SAML SaaS 애플리케이션을 성공적으로 인증할 수 있는 사용자 ID 특성을 나타냅니다. 기본적으로 Cloudflare 액세스는 SaaS 애플리케이션에 다음과 같은 속성을 전달합니다.

- `id`- 사용자의 액세스 정체성의 UUID
- `name`- 사용자의 전체 이름 (예를 들면,`John Doe`)
- `email`- 사용자의 이메일 주소
- `groups`- Identity 공급자 그룹 회원

SaaS에 액세스하려면 추가 SAML 속성을 추가하거나 SaaS 응용 프로그램에 전송된 SAML 문명을 사용자 지정할 수 있습니다. 특정 SAML 속성 요구 사항이있는 SaaS 응용 프로그램을 통합 할 수 있습니다.

### SAML 속성 문

추가 SAML 속성을 SaaS 애플리케이션에 전송하려면 각 속성의 다음 필드를 구성하십시오.

- **이름 \***: SAML 속성 이름
- **SAML 친절한 이름**: (선택 사항) SAML 속성에 대한 인간의 읽기 가능한 이름
- **이름 형식**: 지정**이름 \***&#x53;aaS 애플리케이션에 의해 예상되는 형식:
  - `Unspecified`: (기본) 특정 형식이 필요하지 않습니다.
  - `URI`: 이름은 같은 형식에 있습니다.`urn:ietf:params:scim:schemas:core:2.0:User:userName`또는`urn:oid:2.5.4.42`.
  - `Basic`: 이름과 같은 정상적인 문자열입니다.`userName`.
- **IdP 청구**: 이 SAML 속성에 지도해야 하는 정체성 공급자 가치. 모든 것을 선택할 수 있습니다.[SAML 속성](/cloudflare-one/integrations/identity-providers/generic-saml/#saml-headers-and-attributes)또는[OIDC 청구](/cloudflare-one/integrations/identity-providers/generic-oidc/#custom-oidc-claims)Cloudflare One IdP 통합으로 구성되었습니다.
- **견적 요청**: 속성이 필요하지만 IdP에 의해 제공되지 않은 경우 Cloudflare는 인증 요청을 실패하고 오류 페이지를 표시합니다.
- **IdP 청구 당 추가**: (선택) SaaS 애플리케이션을 위한 여러 ID 제공 업체에서 설정하면 각 IdP에 대한 다른 속성 매핑을 선택할 수 있습니다. 이 값은 부모를 무시합니다.**IdP 청구**.

### JSONata 변환

내 계정**고급 설정** > **관련 기사**, 입력할 수 있습니다[JSONata, 그리스](https://jsonata.org/)스크립트를 modifies the copy of[사용자 등록 ID](/cloudflare-one/team-and-resources/users/users/). 이것은 기본 값 설정에 유용합니다, 이메일 주소를 제외하고, 또는 사용자를 보장 arbitrary 표준. 액세스는 SAML 속성으로 SaaS 애플리케이션에 수정된 사용자 ID를 보낼 것입니다.

:::참조
JSONata 변환은 호환되지 않습니다.[SAML 속성 문](#saml-attribute-statements). JSONata 변환은 지정된 SAML 속성을 무시합니다.
주요 특징

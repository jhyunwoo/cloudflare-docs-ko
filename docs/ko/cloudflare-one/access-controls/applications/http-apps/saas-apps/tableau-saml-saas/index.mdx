## 1. Cloudflare One에 SaaS 애플리케이션 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가** > **SaaS 서비스**.
3. 제품 정보**제품 설명**, 선택*스낵 바*.
4. 인증 프로토콜의 경우, 선택**사이트맵**.
5. 제품정보**앱 추가**.
6. 제출하기**SAML 메타데이터 엔드포인트**.
7. 이 창을 엽니다. 당신은 단계에 이 윤곽을 완료할 것입니다[4. Cloudflare One에 SaaS 애플리케이션 추가](#4-finish-adding-a-saas-application-to-cloudflare-one).

## 2. 메타데이터 파일을 다운로드

1. Cloudflare의 애플리케이션 구성에서 SAML 메타데이터 엔드포인트를 붙여넣기 웹 브라우저에서 하나.
2. URL의 내용을 다운로드하려면 브라우저 별 단계를 따르십시오.`.xml`파일.

## 3. Tableau Cloud에 SAML SSO 공급자 추가

1. Tableau Cloud에서 이동**계정 설정** > **인증현황**.
2. 기타 제품**추가 인증 방법 활성화**.를 위해**인증 유형 선택**, 선택*사이트맵*.
3. 이름 \***1. Tableau Cloud 메타데이터 받기**, 복사**Tableau Cloud 법인 ID**·**Tableau 클라우드 ACS URL**.
4. 이름 \***4. Tableau에 메타데이터 업로드**, 선택**파일 선택**, 업로드`.xml`단계로 만든 파일[2. 메타데이터 파일을 다운로드](#2-download-the-metadata-file)
5. 이름 \***5. 맵 속성**, 켜기**이름 \***.를 위해**이름 (전체 이름)**, 입력`name`.
6. (선택 사항) 임베디드 레이아웃에 액세스하는 사용자를 선택**별도의 팝업 창에서 인증**또는**인라인 프레임을 사용하여 인증**.
7. 제품정보**저장 변화**.

   - **Assertion 소비자 봉사 URL**: Tableau Cloud SAML SSO 설정에서 Tableau Cloud ACS URL.
   - **이름 ID 체재**: *이름 \**
2. 설정하기[오시는 길](/cloudflare-one/access-controls/policies/)신청하기
3. 신청 저장.

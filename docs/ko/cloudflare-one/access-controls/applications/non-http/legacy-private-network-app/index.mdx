새로운 배포를 권장하지 않습니다. 자주 묻는 질문[자체 호스팅 응용](/cloudflare-one/access-controls/applications/non-http/self-hosted-private-app/)개인 IP 주소를 확보하기 위해.
주요 특징

구성할 수 있습니다.**개인 네트워크**개인 네트워크의 특정 응용 프로그램에 대한 액세스를 관리하는 응용 프로그램입니다.

개인 네트워크 응용 프로그램을 만들려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \*** > **앱 추가**.

2. 제품정보**개인 네트워크**.

3. 이름 당신의 신청.

4. 제품 정보**신청 유형**, 선택*대상 IP*.

5. 제품 정보**제품정보**, 당신의 신청을 위한 IP 주소를 입력하십시오 (예를 들면,`10.128.0.7`).
   :::참조
   특정 IP 주소 대신 IP / CIDR 범위에 대한 정책을 작성하고 싶다면,[Gateway Network 정책](/cloudflare-one/traffic-policies/network-policies/)사용 방법**대상 IP**옵션 정보
   주요 특징

6. 설정하기[앱 실행기](/cloudflare-one/access-controls/access-settings/app-launcher/)가시성과 로고.

7. 제품정보**이름 \***. 당신은 두 개의 자동 생성 게이트웨이 네트워크 정책을 볼 수 있습니다 : 대상 IP 및 블록 액세스에 액세스 할 수있는 하나.

8. 추가 정체성 조건을 포함하는 정책을 수정합니다. 예를 들면:

   - **정책 1**

     | 옵션 정보   | 회사연혁     | 제품정보             | 로그인   | - 연혁 |
     | ------- | -------- | ---------------- | ----- | ---- |
     | 대상 IP   | 내 계정     | `10.128.0.7`     | 이름 \* | 지원하다 |
     | 사용자 이메일 | 경기 regex | `.*@example.com` |       |      |

   - **정책 2**

     | 옵션 정보 | 회사연혁 | 제품정보         | - 연혁 |
     | ----- | ---- | ------------ | ---- |
     | 대상 IP | 내 계정 | `10.128.0.7` | 제품정보 |

   정책은 평가됩니다.[numerical 순서](/cloudflare-one/traffic-policies/order-of-enforcement/#order-of-precedence), 그래서 @example.com에서 끝나는 이메일을 가진 사용자는 접근할 수 있을 것입니다`10.128.0.7`다른 모든 사람들이 차단됩니다. 건물 네트워크 정책에 대한 자세한 내용은, 참조[관련 문서](/cloudflare-one/traffic-policies/network-policies/).

9. 제품정보**앱 추가**.

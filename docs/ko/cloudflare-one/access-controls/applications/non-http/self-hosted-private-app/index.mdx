## 자주 묻는 질문

- 개인 IP 및 호스트 이름은 Cloudflare WARP, Cloudflare WAN (이전 매직 WAN) 또는 브라우저 고립에 도달 할 수 있습니다. 더 자세한 내용은 참조[개인 네트워크 연결](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/).
- 사용자 정의 DNS 해결자에게 개인 호스트 이름 경로[지역 도메인 Fallback](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/local-domains/)또는[Gateway 해결사 정책](/cloudflare-one/traffic-policies/resolver-policies/).
- 공공 IP 및 호스트 이름은 개인 응용 프로그램을 정의하는 데 사용할 수 있지만 IP 또는 호스트 이름은 Cloudflare를 통해 경로를해야합니다[Cloudflare 갱도](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/), [WARP 연결관](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/warp-connector/), 또는[Cloudflare 대만](/cloudflare-wan/configuration/manually/how-to/configure-routes/).
- (선택) 켜기[Gateway TLS 해독](/cloudflare-one/traffic-policies/http-policies/tls-decryption/)Access JWT를 사용하여 관리하려는 경우[HTTPS 신청 세션](#https-applications).

## 인증 흐름

### HTTPS 신청

이름 \*[Gateway TLS 해독](/cloudflare-one/traffic-policies/http-policies/tls-decryption/)설정 및 사용자는 포트에 HTTPS 응용 프로그램에 액세스`443`· Cloudflare 액세스는 브라우저에서 로그인 페이지를 제시하고 문제점을[앱 토큰](/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/application-token/)당신의 근원에. 이 같은 쿠키 기반 인증 흐름에 의해 사용[자체 호스팅 공개 앱](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/).

이름 \*[Gateway TLS 해독](/cloudflare-one/traffic-policies/http-policies/tls-decryption/)설정, 세션 관리[WARP 클라이언트에서 처리](#non-https-applications)브라우저 대신.

### Non-HTTPS 신청

WARP 클라이언트는 모든 non-HTTPS 응용 프로그램에 대한 세션을 관리합니다. 사용자는 받을 것이다`Authentication required`WARP 클라이언트에서 팝업 알림. 사용자가 알림을 선택하면 WARP는 액세스 로그인 페이지로 브라우저 창을 엽니다.

### 개인 별명 vs 개인 IP

개인 호스트 이름에 의해 정의 된 액세스 응용 프로그램은 개인 IP에 의해 정의 된 액세스 응용 프로그램에 대해 우선합니다. 예를 들어 App-1 포인트를 가정하십시오.`wiki.internal.local`App-2 포인트`10.0.0.1`, 하지만`wiki.internal.local`해결하기`10.0.0.1`. 접속한 사용자`wiki.internal.local`App-2는 결코 일치하지 않습니다; 그들은 App-1 접근 정책 (및에 근거를 둔 엄격히 금지될 것입니다)[Gateway 정책](#access-vs-gateway-policies)).

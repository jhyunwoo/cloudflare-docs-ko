사용자가 액세스 응용 프로그램에 연결할 때`cloudflared`, 브라우저는이 페이지를 표시하여 액세스 할 수있게합니다 :

![액세스 요청 Cloudflared로 로그인 후 표시된 프롬프트 페이지.](~/assets/images/cloudflare-one/applications/non-http/access-screen.png)

제품정보`cloudflared`인증은 이미 활성 IdP 세션이 있는 경우 이 로그인 페이지를 건너뛸 수 있습니다.

자동 활성화`cloudflared`인증:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. 응용 프로그램을 찾아 선택**설정하기**.
3. 오시는 길**기본 정보** > **Browser 렌더링 설정**.
4. 기타 제품**자동 Cloudflared 인증**.
5. 제품정보**자주 묻는 질문**.

이 옵션은 여전히 배경에 브라우저 창을 프롬프트하지만, 인증은 자동으로 발생합니다.

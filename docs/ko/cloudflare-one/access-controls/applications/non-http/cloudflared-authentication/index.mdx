Cloudflare Zero Trust를 사용하면 WARP 클라이언트를 설치하지 않고 공개 호스트 이름을 통해 비HTTP 애플리케이션에 연결할 수 있습니다. 이 방법은 Cloudflare에 도메인을 내장하고 설치해야합니다.`cloudflared`서버와 사용자의 장치 모두에.

사용자가 응용 프로그램에 로그인하여 실행`cloudflared access`터미널에서 명령.`cloudflared`브라우저 창을 시작하고 사용자의 ID 공급자로 인증합니다.

:::참조

자동화된 서비스는 오직 인증해야 합니다.`cloudflared`사용하지 않는 경우[서비스 토큰](/cloudflare-one/access-controls/service-credentials/service-tokens/). Cloudflared 인증은 WebSockets에서 연결을 설정합니다. WebSockets는 지속 가능한 연결이 닫힐 수 있는 알려진 제한이 있습니다. 우리는 추천한다[서비스 Auth 정책](/cloudflare-one/access-controls/policies/#service-auth)또는 사용[터널 라우팅에 전쟁](/cloudflare-one/access-controls/applications/non-http/)이 인스턴스에서.

- [Cloudflared를 가진 RDP 이상 연결](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/rdp/#connect-to-rdp-server-with-cloudflared-access)

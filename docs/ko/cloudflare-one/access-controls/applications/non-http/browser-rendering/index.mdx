Cloudflare는 클라이언트 소프트웨어 또는 최종 사용자 구성 변경을 필요로하지 않고 브라우저에서 SSH, VNC 및 RDP 응용 프로그램을 렌더링 할 수 있습니다. SSH 및 VNC의 경우 사용자는 서버의 사용자 이름과 일치해야합니다. RDP는 기존의 Windows 사용자 이름과 암호를 Windows 서버에 인증합니다. Cloudflare는 Windows 서버에서 자격 증명을 관리하지 않습니다.

## 제한 사항

- Browser 렌더링만 지원됩니다.[자체 호스팅 공공 응용](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/), 개인 IP 또는 호스트 이름.
- 도메인 및 하위 도메인에 브라우저 렌더링 된 터미널 만 렌더링 할 수 있으며 특정 경로에 없습니다.
- <Render file="access/self-hosted-app/ssh-sessions" product="cloudflare-one" />
- Cloudflare는 TLS를 사용하여 Windows 서버에 egress RDP 연결을 보호합니다. 우리는 현재 신뢰의 사슬을 검증하지 않습니다.

## 브라우저 렌더링 설정

### SSH와 VNC

SSH 또는 VNC 응용 프로그램에 대한 브라우저 렌더링을 켜려면 :

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.
2. SSH 또는 VNC 응용 프로그램을 찾을 때[Cloudflare에 서버를 연결](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/). 선택**설정하기**.
3. 내 계정**Browser 렌더링 설정**, 세트**브라우저 렌더링**으로*사이트맵*또는*VNC 소개*.
   <Render file="access/self-hosted-app/browser-rendering-policies" product="cloudflare-one" />
4. 제품정보**자주 묻는 질문**.

사용자가 인증하고 응용 프로그램의 URL을 방문 할 때 Cloudflare는 브라우저에서 터미널을 렌더링합니다.

### 사이트맵

RDP에 대한 브라우저 렌더링을 설정하려면, 우리의 참조[브라우저 기반 RDP 가이드](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/rdp/rdp-browser/).

### SSH 키 교환 알고리즘

Cloudflare의 브라우저 렌더링 SSH 터미널은 다음과 같은 키 교환 (KEX) 알고리즘을 지원합니다.

- `curve25519-sha256@libssh.org`
- `curve25519-sha256`
- `ecdh-sha2-nistp256`
- `ecdh-sha2-nistp384`
- `ecdh-sha2-nistp521`

브라우저 렌더링 SSH 연결을 위해, 당신은 업데이트해야 할 수 있습니다`sshd_config`이 알고리즘을 수락하기 위해 서버의 파일.

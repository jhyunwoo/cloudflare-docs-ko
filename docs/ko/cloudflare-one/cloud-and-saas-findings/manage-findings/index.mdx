Findings는 SaaS 및 클라우드 애플리케이션 내에서 감지된 보안 문제입니다. 이는 사용자, 데이터, 나머지 및 기타 구성 설정을 포함합니다. Cloudflare CASB를 사용하면 Cloudflare의 포괄적인 목록을 검토 할 수 있습니다. 문제의 행동을 즉시 시작.

## 자주 묻는 질문

- 당신은 추가했습니다[클라우드 및 SaaS 통합](/cloudflare-one/integrations/cloud-and-saas/).
- 당신의 검사는 적어도 1개의 안전 찾는 지상에 놓았습니다.

## 게시물 검색

Posture는 misconfigurations, unauthorized user activity 및 기타 데이터 보안 문제를 포함합니다.

에 대한 자세한 내용을 보려면 자세가 발견 된 CASB 찾기 :

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**클라우드 및 SaaS** > **Posture 찾기**.
2. 제품 정보**SaaS 서비스**또는**클라우드**.
3. 찾기에 대한 자세한 내용을 보려면, 찾기의 이름을 선택하십시오

Cloud & SaaS는 찾기 유형,[상급 수준](#severity-levels), 인스턴스 수, 관련 통합, 현재 상태 및 날짜 감지. 찾기의 각 인스턴스에 대한 자세한 내용은, 선택**계정 관리**.

발견의 가시성을 관리하려면, 발견의 업데이트를 업데이트 할 수 있습니다.[상급 수준](#severity-levels)또는[자주 묻는 질문](#hide-findings)본문 바로가기 또한, 몇몇 발견은 문제점 또는 지원을 해결하기 위하여 재약 가이드를 제공합니다[Gateway HTTP 정책 생성](#resolve-finding-with-a-gateway-policy)트래픽을 차단합니다.

### Severity 수준

Cloudflare CASB는 뒤에 오는 severity 수준의 한으로 각 발견합니다:

| Severity 수준 | 긴급 상황                        |
| ----------- | ---------------------------- |
| 한국어         | 제안은 당신의 팀이 오늘 행동해야한다는 것입니다.  |
| 사이트맵        | 발견을 제안하면 팀이 이번 주에 행동해야합니다.   |
| 한국어         | 발견을 제안하면이 달을 검토해야합니다.        |
| 이름 \*       | 발견은 예약 된 검토 과정의 정보 또는 일부입니다. |

#### severity 레벨 변경

기본 할당이 환경에 맞게되지 않는 경우 언제든지 찾을 수 있습니다.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**클라우드 및 SaaS** > **Posture 찾기**.
2. 수정 및 선택하기 원하는 찾기를 찾습니다**계정 관리**.
3. severity Level Drop-down 메뉴에서 원하는 설정을 선택하십시오 (*한국어*, *사이트맵*, *한국어*, 또는*이름 \**).

새로운 severity 레벨은 이 특정 통합 내에서 자세 찾기에만 적용됩니다. 동일한 응용 프로그램의 여러 통합을 추가하면 다른 통합은이 변경에 영향을 미치지 않습니다.

## 회사 소개

Content finds는 잠재적 인 데이터 노출의 인스턴스를 포함[사이트맵](/cloudflare-one/data-loss-prevention/).

CASB가 발견 된 내용을 찾는 것에 대한 자세한 내용을 보려면 :

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**클라우드 및 SaaS** > **콘텐츠 찾기**.
2. 제품 정보**SaaS 서비스**또는**클라우드**.
3. 찾기에 대한 자세한 내용을 보려면, 찾기의 이름을 선택하십시오.

Cloud & SaaS는 파일 이름, DLP 프로파일, 관련 통합 및 날짜 감지 파일과 일치하는 DLP 프로파일에 대한 자세한 내용을 표시 할 것입니다.

AWS 사용자는 구성할 수 있습니다[계정 찾기](/cloudflare-one/integrations/cloud-and-saas/aws-s3/#compute-account)S3 리소스 내에서 데이터 보안 리소스를 스캔합니다.

## 자주 묻는 질문

당신의 발견을 검토 한 후, 당신은 특정 자세 발견이 조직에 적용되지 않다는 것을 결정할 수 있습니다. Cloudflare CASB는 활성 문제의 목록에서 발견 또는 개별 사례를 제거 할 수 있습니다. CASB는 이러한 문제를 검사하는 것을 계속할 것입니다, 그러나 어떤 탐지는 분리되는 탭에서 나타날 것입니다.

### 찾기를 무시

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**클라우드 및 SaaS** > **Posture 찾기**.
2. 당신이 숨길 원하는 활성 발견을 찾습니다.
3. 세 번 메뉴에서, 선택**무시하기**.

발견의 상태는 변화합니다**지원하다**으로**이름 \***. CASB는 이 발견 및 보고 탐지를 위해 계속할 것입니다. 다시 발견을 변경할 수 있습니다.**지원하다**동시에 동일한 과정으로.

### 찾기의 인스턴스를 숨기기

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**클라우드 및 SaaS** > **Posture 찾기**.
2. 숨길 원하는 활성 찾기를 선택, 다음 선택**계정 관리**.
3. 내 계정**지원하다**, 당신이 숨길 원하는 인스턴스를 찾습니다.
4. 세 번 메뉴에서, 선택**숨겨진**.

인스턴스가 이동됩니다.**지원하다**으로**뚱 베어**발견 중. 동일한 사용자에 대한 검색이 다시 발생하면, CASB는 새로운 인스턴스를 조용히보고합니다.**뚱 베어**탭. 숨겨진 인스턴스를 다시 이동할 수 있습니다.**지원하다**언제든지 탭.

## Remediate 발견

SaaS 및 클라우드 애플리케이션을 사용하여 악성 구성 또는 문제점을 탐지 및 추적하는 외에도, CASB는 애플리케이션에서 직접 검색할 수 있습니다.

### 재약 허가

검색하기 전에,[새로운 통합 추가](/cloudflare-one/integrations/cloud-and-saas/#add-an-integration)그리고 선택*Read-Write 모드*설정 중. 또는 기존 통합을 업데이트할 수 있습니다:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**클라우드 및 SaaS** > **통합**.
2. 통합을 선택, 다음 선택**설정하기**.
3. 내 계정**통합 권한**, 선택*Read-Write 모드*.
4. 제품정보**업데이트 통합**. CASB는 당신의 Microsoft 365 윤곽에 당신을 리디렉션할 것입니다.
5. 귀하의 조직에 로그인 한 다음 선택**이름 \***.

CASB는 지금 지원된 발견을 직접 remediate 할 수 있습니다.

### 자주 묻는 질문

지원된 찾는 중:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**클라우드 및 SaaS** > **Posture 찾기**.
2. 지원된 검색 유형 선택, 다음 선택**계정 관리**.
3. 내 계정**활동 Instances**, 인스턴스를 선택합니다.
4. 내 계정**Remediation 세부사항**, 복용에 치료 활동을 선택합니다.

CASB는 인스턴스를 중화하기 시작합니다.

### 관련 검색

Remediated 발견은**클라우드 및 SaaS** > **Posture 찾기**. 발견의 상태는 무슨 행동 CASB에 따라서 변화할 것입니다:

| 주요연혁  | 이름 \*                                        |
| ----- | -------------------------------------------- |
| 관련 기사 | CASB는 remediated 것을 찾는 것을 놓았습니다.             |
| 채용 정보 | CASB는 치료에 대한 발견을 갖췄다.                        |
| 제품정보  | CASB는 현재 찾는 중입니다.                            |
| 옵션 정보 | CASB는 성공적으로 재약을 완료하고 발견이 해결 된 확인을 기다리고 있습니다. |
| 한국어   | CASB는 성공적으로 발견이 해결 된 것을 발견하고 검증했습니다.         |
| 실패한   | CASB는 완전히 발견을 재개했습니다.                        |
| 관련 상품 | CASB는 찾을 수있는 올바른 권한이 없습니다.                   |

상태가 있다면**한국어**, 치료 성공. 상태가 있다면**실패한**또는**관련 상품**, 구제 실패, 당신은 다시 작업을 수행 할 수 있습니다.

CASB는 재약 행동을 기록합니다**로그인** > **계정 관리**. 자세한 내용은 참조[사이트맵 로그인](/cloudflare-one/insights/logs/).

## Gateway 정책과 함께 해결

CASB의 보안 발견을 사용하여 향후 원치 않는 행동을 방지하고 조직의 보안 정책을 정렬하는 데 사용할 수 있도록 미세 곡물 게이트웨이 정책을 허용합니다. 승인되지 않은 응용 프로그램의 사용과 같은 CASB 찾기를 볼 수 있으므로 게이트웨이와 즉시 예방하거나 제어 할 수 있습니다.

CASB는 Gateway 정책을 작성하여[Google Workspace 통합](/cloudflare-one/integrations/cloud-and-saas/google-workspace/):

<Details header="Gateway 정책을 위한 지원된 CASB 발견">
  - Google Workspace: 공용으로 액세스할 수 있는 파일
  - Google Workspace: 파일 공용으로 접근 가능
  - Google Workspace: 파일 공유 외부 회사에서 편집 액세스
  - Google Workspace: 파일 공유 외부 회사보기 액세스
</Details>

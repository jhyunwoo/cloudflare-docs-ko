주요 특징

Cloudflare의 API 구동[Cloud Access 보안 브로커](https://www.cloudflare.com/learning/access-management/what-is-a-casb/)(CASB)는 SaaS 애플리케이션과 클라우드 환경과 통합하여 구성, 무단 사용자 활동,<GlossaryTooltip term="shadow IT" link="https://www.cloudflare.com/learning/access-management/what-is-shadow-it/">그림자 IT</GlossaryTooltip>사용자가 성공적으로 로그인 한 후 발생할 수있는 기타 데이터 보안 문제.

사용 가능한 검색 목록, 참조[클라우드 및 SaaS 통합](/cloudflare-one/integrations/cloud-and-saas/).

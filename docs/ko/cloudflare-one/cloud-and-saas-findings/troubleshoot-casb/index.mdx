Cloud Access Security Broker (CASB)와 공통 문제를 해결하는이 가이드를 사용합니다.

이 가이드는 Microsoft 365, Google Workspace 및 GitHub 통합에 대한 문제 해결 단계를 다룹니다. 다른 통합을 위해, 통합 문서 참조.

## 통합은 연결하거나 오류를 반환합니다.

통합 연결 문제는 CASB 설정 중 가장 일반적인 문제입니다. "연결을 만드는 오류가 있었다"또는 통합이 나타나지 않고 대시보드로 다시 리디렉션하면이 단계를 따르십시오.

### 제3자 애플리케이션의 권한 확인

통합을 승인하기 위해 계정이 제3자 응용 프로그램에 필요한 관리 권한이 있습니다 (예를 들어,**글로벌 관리자**Microsoft 365의 경우**슈퍼 관리자**Google Workspace의 경우, 또는**회사연혁**GitHub의 경우 충분한 권한은 설정 실패의 주요 원인입니다.

### 이전 설치 취소

SaaS 애플리케이션이 이전에 다른 Cloudflare 계정과 통합되면 SaaS 공급자의 관리자 콘솔 내에서 오래된 Cloudflare 애플리케이션을 수동으로 수정해야 합니다.

- **마이크로소프트 365를 위해**: 바로가기**Microsoft 365 관리자 센터** > **Enterprise 응용**기존 Cloudflare One 응용 프로그램을 삭제합니다.
- **Google 작업 공간**: 바로가기**Google 관리자 콘솔** > **보안 보안** > **액세스 및 데이터 제어** > **API 제어**제3자 앱 액세스에서 Cloudflare 앱을 제거하십시오.
- **GitHub에서**: 조직의 이동**계정 설정** > **제3자 액세스**Cloudflare CASB 응용 프로그램을 수정합니다.

오래된 응용 프로그램을 청소 한 후 몇 분 후 Cloudflare One 대시보드에서 통합 프로세스를 다시 시도하십시오.

### OAuth 권한 검증

설정 중, CASB는 권한을 설정하도록 요청합니다. 요청된 권한은 수정 작업을 수행하는 데 필요한 경우, 수정 작업을 수행 할 수 있습니다. 몇몇 권한이 넓을 수 있지만 (예를 들어,`write`액세스), 그들은 파일 또는 공유 설정을 수정 같은 작업을 위해 필요합니다. 특정 통합 가이드에 대한 자세한 목록의 필수 권한.

## 찾기는 stale 또는 치료 후 업데이트되지 않습니다.

주입의 일반적인 점은 해결된 문제점 (예를 들면, 파일이 개인을 만들 때, 또는 사용자가 중단될 때) 계속 CASB 대시보드에 있는 활동적인 찾는 것처럼 보입니다.

### 스캔 빈도를 이해

CASB 통합은 실시간 업데이트를 제공하지 않습니다. 스캔은 정기적으로 새로운 발견을 발견하고 기존의 상태를 검증합니다. 초기 스캔은 몇 시간 걸릴 수 있으며 이후 스캔은 약 24 시간마다 실행됩니다.

### re-scan 힘

새로운 스캔을 트리거하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**통합** > **클라우드 및 SaaS**.
2. 통합 및 선택 찾기**설정하기**.
3. 오시는 길**캐스 번호:**.
4. 공지사항**스캔 찾기**.
5. 몇 분 후, 켜기**스캔 찾기**다시.

이 작업은 통합의 신선한 스캔을 할 것입니다. 새로운 결과를 반영하기 위해 몇 시간을 허용하십시오.

## 치료 활동은 대시보드에서 실패

한 번의 클릭 구제를 사용하려고 하는 경우 ( "Make private"과 같은) 찾기에, 그것은 결과 수 있습니다**실패한**상태, 종종 타임 아웃 오류.

### 자주 묻는 질문

수정 실패는 Cloudflare 앱의 허가로 인해 초기 설정 후 SaaS 애플리케이션에서 변경되거나 수정될 수 있습니다. 모든 필요한 권한을 보장하기 위해 통합을 다시 유효하지 않습니다.

### 수동으로

workaround로, SaaS 애플리케이션 내에서 직접 찾기를 재조정(예를 들어, Google Drive의 파일 공유 설정을 변경). CASB는 다음 성공적인 스캔 후 대시보드에서 찾을 수 있습니다.

## CASB는 거짓 긍정적인 생성

CASB는 incorrectly 깃발 품목을 inactive 구글 Workspace 사용자로 public 또는 archived로 기인하는 내부 공유된 파일과 같은 incorrectly 깃발 품목 할지도 모릅니다.

### 자주 묻는 질문

발견에서 제공되는 증거를 조심하십시오. SaaS 플랫폼의 객체의 상태는 정확하지 않을 수 있습니다.

### 문제 신고

발견이 거짓 긍정적 인 경우 Cloudflare 지원에 대한 행동을보고하십시오. 검색 ID 및 가능한 한 많은 세부 사항 제공. 이 도움 지원 팀은 모든 고객을 위한 탐지 논리를 정유합니다.

### 검색 결과

Cloudflare가 문제점을 조사하는 동안, 당신은 사용할 수 있습니다**공지사항**활동 목록에서 제거하고 소음을 줄입니다.

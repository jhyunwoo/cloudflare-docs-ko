## CASB에서 DLP 스캔 가능

### 새로운 통합 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**클라우드 및 SaaS** > **통합**.
2. 제품정보**통합 연결**그리고 선택[지원 통합](#supported-integrations).
3. 설정 과정에서 통합 DLP 프로파일을 선택할 수 있습니다.
4. 제품정보**통합 저장**.

CASB는 DLP 프로파일과 일치하는 텍스트에 대한 통합에 모든 공개적으로 접근 가능한 파일을 스캔합니다. 초기 스캔은 몇 시간까지 완료할 수 있습니다.

### 기존 통합 수정

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**클라우드 및 SaaS** > **통합**.
2. 선택하기[지원 통합](#supported-integrations)선택하기**설정하기**.
3. 이름 \***DLP 프로필**, 당신은 스캔 할 통합을 원하는 프로파일을 선택합니다.
4. 제품정보**통합 저장**.

DLP 프로파일을 사용할 경우**통합 관리**페이지, CASB는 DLP 프로파일을 활성화하기 때문에 수정 이벤트를 가지고 공개적으로 접근 가능한 파일을 스캔합니다. 수정 이벤트는 다음과 같은 속성으로 변경됩니다:

- 파일의 내용
- 파일 이름
- 파일의 가시성 ( publiclyaccess로 변경되는 경우에만)
- 파일의 소유자
- 파일 위치 (예를 들어 다른 폴더로 이동)

과거 데이터를 스캔하려면 DLP 프로파일을 활성화해야합니다.[통합 설정 흐름](#add-a-new-integration).

## 제한 사항

CASB에 있는 DLP는 단지 검사할 것입니다:

- [텍스트 기반 파일](/cloudflare-one/data-loss-prevention/#supported-file-types)문서, 스프레드시트, PDF 등 이미지는 지원되지 않습니다.
- 파일 크기가 100MB 미만인 경우
- Java 및 R에 대한 최소 5 KB의 소스 코드.

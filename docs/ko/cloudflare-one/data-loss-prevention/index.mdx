<GlossaryDefinition term="Cloudflare Data Loss Prevention (DLP)" />

방해를 방지하기 위해 Cloudflare는 디스크에 스캔 된 콘텐츠를 작성하지 않습니다. 대신 DLP는 메모리에서 암호화 및 일시적으로 저장 콘텐츠를 암호화합니다. 선택적으로, 당신은 구성할 수 있습니다[payload 로깅](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/#log-the-payload-of-matched-rules)HTTP 요청 또는 일치하여 payloads의 암호화 사본을 저장[Logpush 목적지](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/#send-http-requests-to-logpush-destination)HTTP 요청을 모두 내보내기.

## transit의 데이터

데이터 손실 방지 보완[보안 웹 게이트웨이](/cloudflare-one/traffic-policies/)HTTP 요청으로 전송된 민감한 데이터를 감지합니다. DLP는 업로드 또는 다운로드된 파일, 채팅 메시지, 양식 및 기타 웹 콘텐츠가 포함될 수 있는 HTTP body(excluding headers)를 스캔합니다. DLP도 사용할 수 있습니다.[이메일 보안](/cloudflare-one/email-security/)스캔하기[아웃바운드 이메일](/cloudflare-one/email-security/outbound-dlp/).

DLP는 요구합니다[Gateway HTTP 필터링](/cloudflare-one/traffic-policies/get-started/http/)이름 \*[TLS 해독](/cloudflare-one/traffic-policies/http-policies/tls-decryption/)transit에 있는 자료로 가시성을 위해. 가시성의 깊이는 각 사이트 또는 응용 프로그램에 따라 다릅니다. DLP는 Cloudflare 게이트웨이를 우회하는 트래픽을 스캔하지 않습니다.[검사하지 마십시오](/cloudflare-one/traffic-policies/http-policies/#do-not-inspect)정책).

시작하기에, 참조[DLP와 HTTP 트래픽 스캔](/cloudflare-one/data-loss-prevention/dlp-policies/).

## 자주 묻는 질문

데이터 손실 방지 보완[Cloudflare 케이스](/cloudflare-one/integrations/cloud-and-saas/)SaaS 애플리케이션에 저장된 민감한 데이터를 감지합니다. Cloudflare Gateway를 통해 전송된 파일을 읽는 transit scans에 있는 자료와는 달리, API를 통해 CASB 검색 파일. 따라서, 게이트웨이 및 WARP 설정 (예 :[검사하지 마십시오](/cloudflare-one/traffic-policies/http-policies/#do-not-inspect)정책 및[분할 터널](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/split-tunnels/)구성)는 나머지 스캔에서 데이터에 영향을 미치지 않습니다.

시작하기에, 참조[스캔 SaaS 애플리케이션 DLP](/cloudflare-one/cloud-and-saas-findings/casb-dlp/).

## AI 트래픽

Data Loss Prevention과 통합[Cloudflare AI 게이트웨이](/ai-gateway/)민감한 데이터에 대한 AI 프롬프트 및 응답을 스캔합니다. DLP가 AI 게이트웨이에서 활성화되면 게이트웨이 HTTP 필터링 또는 TLS 해독을 필요로하지 않고 AI 모델로 전송된 요청의 텍스트 내용을 검사합니다.

시작하기에, 참조[AI Gateway를 위한 DLP 설정](/ai-gateway/features/dlp/set-up-dlp/).

## 지원된 파일 유형

### 파일 형식

DLP는 보고하고 뒤에 오는 파일 유형을 검사합니다:

- 텍스트 및 CSV
- 마이크로 소프트 오피스 2007 이상 (`.docx`, `.xlsx,` `.pptx`), 마이크로소프트 365를 포함하여
- PDF 파일
- 위의 ZIP 파일

DLP는 텍스트, Microsoft Office 및 PDF 파일에 포함된 텍스트를 스캔합니다.

### 크기 (mm)

DLP는 크기에 있는 100 MB 보다는 더 적은 파일을 검사할 수 있습니다. ZIP 파일은 반복적으로 최대 10 번 압축 할 수 있으며 ZIP 파일 내 각 콘텐츠 파일은 압축되지 않은 크기에서 200MB 미만이어야합니다.

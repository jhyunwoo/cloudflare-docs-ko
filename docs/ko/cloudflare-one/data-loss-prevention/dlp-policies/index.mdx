Secure Web Gateway 정책을 통해 민감한 데이터를 HTTP 트래픽을 스캔할 수 있습니다. DLP 필터링을 수행하려면 먼저 검출하려는 데이터 패턴과 DLP 프로파일을 구성하고, 게이트웨이 HTTP 정책을 구축하여 조직을 떠나서 민감한 데이터를 허용하거나 차단합니다. Gateway는 DLP 프로파일에 명시된 키워드 또는 일반 표현 (regexes)와 일치하는 문자열에 대한 HTTP 트래픽을 파고 스캔합니다.

:::참조
Gateway HTTP 필터링없이 AI 프롬프트 및 응답을 스캔하려면 DLP를 직접 활성화 할 수 있습니다.[AI 게이트웨이](/ai-gateway/features/dlp/).
:::

## 자주 묻는 질문

- 설치하기[Gateway HTTP 필터링](/cloudflare-one/traffic-policies/get-started/http/).
  - HTTP 필터링은 켜져야 합니다.[Gateway 프록시](/cloudflare-one/traffic-policies/proxy/#turn-on-the-gateway-proxy)TCP 트래픽을 위해.
- 기타 제품[TLS 해독](/cloudflare-one/traffic-policies/http-policies/tls-decryption/#turn-on-tls-decryption).

## 1. DLP 프로파일 구성

더 알아보기[DLP 프로파일 구성](/cloudflare-one/data-loss-prevention/dlp-profiles/). 사전 정의된 프로파일로 시작하는 것이 좋습니다.

:::카ution\[중요]

DLP 스캔이 시작할 수 없습니다.[DLP 정책 작성](#2-create-a-dlp-policy).
:::

## 2. DLP 정책 작성

사이트맵 단면도는 다른 Cloudflare와 함께 사용될지도 모릅니다 한 가지 규칙[Gateway HTTP 정책](/cloudflare-one/traffic-policies/http-policies/). 로깅 또는 차단 트래픽을 시작하려면 DLP에 대한 정책을 작성하십시오.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**교통 정책** > **방화벽 정책**. 선택**HTTP: HTTP**.

2. 제품정보**정책 추가**.

3. 회사연혁[HTTP 정책](/cloudflare-one/traffic-policies/http-policies/)사용 방법[DLP 프로필](/cloudflare-one/traffic-policies/http-policies/#dlp-profile)옵션 정보 예를 들어, 다음과 같은 정책은 승인 된 법인 응용 프로그램 이외의 위치에 민감한 데이터 업로드에서 사용자를 방지합니다.

   | 옵션 정보   | 회사연혁 | 제품정보                           | 로그인   | - 연혁 |
   | ------- | ---- | ------------------------------ | ----- | ---- |
   | DLP 프로필 | 내 계정 | *사회 보장, 보험, 세금 및 Identifer 번호* | 이름 \* | 제품정보 |
   | HTTP 방법 | 내 계정 | *사이트맵*                         | 이름 \* |      |
   | 제품 설명   | 뚱 베어 | *Workday 소개*                   |       |      |

4. 제품정보**공지사항**.

DLP 스캐닝은 이제 켜집니다.

## 3. DLP 정책 테스트

Zero Trust 조직에 연결된 모든 장치에서 DLP 정책을 테스트 할 수 있습니다. 기본 테스트를 수행하려면:

1. 오시는 길[사이트맵](http://dlptest.com/http-post/).
2. 텍스트 메시지를 입력하거나 민감한 데이터를 포함하는 파일을 업로드.
3. 제품정보**제출하기**요청을 보내려면.

요청은 DLP 정책에 따라 허용되거나 차단됩니다. 데이터가 DLP 정책에 일치하면 요청을 볼 수 있습니다.[DLP 로그](#4-view-dlp-logs).

다른 사이트는 다른 방법으로 요청을 보낼 것입니다. 예를 들어, 일부 사이트는 여러 요청으로 파일 업로드를 분할합니다. 따라서, 정책이 위에 작동하더라도`dlptest.com`, 그것은 다른 사이트 또는 신청에 동일한 방법을 일하기 위하여 보장되지 않습니다.

## 4. DLP 로그 보기

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**관련 기사** > **로그인** > **HTTP 요청 로그**.
2. 제품정보**제품정보**.
3. 다음 필터 중 하나에서 아이템을 선택하세요:
   - **DLP 프로필**특정 DLP 프로파일을 일치하는 요청을 보여줍니다.
   - **- 연혁**특정 DLP 정책과 일치하는 요청을 보여줍니다.

요청에 대한 세부 정보를 볼 수있는 개별 행을 확장 할 수 있습니다. DLP 정책 트리거 된 데이터를 보려면,[logging 옵션 설정](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/).

### 거짓 긍정적

1. 보고 싶은 로그를 선택합니다.
2. 제품정보**DLP 거짓 긍정적 인 보고서**이름 \***DLP 세부사항**.
3. Cloudflare로 전송되는 정보는 나타납니다. 보고서를 확인하려면, 선택**견적 요청**.

Cloudflare는 보고에 직접 반응하지 않을 것입니다, 그러나 보고 거짓 긍정적인 도움은 우리의 제품을 개량합니다. 기술 지원이 필요한 경우, 도달[지원하다](https://dash.cloudflare.com/?to=/:account/support).

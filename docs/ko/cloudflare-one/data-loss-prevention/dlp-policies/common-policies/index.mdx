다음 인라인 DLP 정책은 일반적으로 업로드 및 다운로드 된 파일에 데이터를 확보하는 데 사용됩니다.

## 로그 업로드/다운로드

더 보기**지원하다**unlicit logger로 작용하는 기능은, 당신의 과민한 자료가 최종 사용자 경험에 영향을 미치지 않고 가는 곳에 가시성을 제공합니다. 다음 예제는 사용자가 앱을 공유하기 위해 데이터를 업로드 또는 다운로드 할 때 활성화 된 금융 정보 프로필 항목을 스캔합니다.

| 옵션 정보   | 회사연혁 | 제품정보    | 로그인   | - 연혁 |
| ------- | ---- | ------- | ----- | ---- |
| DLP 프로필 | 내 계정 | *금융정보*  | 이름 \* | 지원하다 |
| 제품 분류   | 내 계정 | *파일 공유* |       |      |

## Android 앱 제외

많은 안드로이드 응용 프로그램 (Google Drive와 같은) 사용<GlossaryTooltip term="certificate pinning" link="/ssl/reference/certificate-pinning/">인증 핀닝</GlossaryTooltip>Gateway 검사와 호환이 되는 . 필요한 경우, 만들 수 있습니다[Inspect 정책 없음](/cloudflare-one/traffic-policies/http-policies/#do-not-inspect)앱이 Android에서 기능을 계속할 수 있도록:

1. 설정하기[OS 버전 장치 자세 검사](/cloudflare-one/reusable-components/posture-checks/warp-client-checks/os-version/)Android 운영 체제를 확인합니다.

2. Gateway의 다음 HTTP 정책 만들기:

   | 옵션 정보                    | 회사연혁 | 제품정보            | 로그인   | - 연혁      |
   | ------------------------ | ---- | --------------- | ----- | --------- |
   | 제품 설명                    | 내 계정 | *Google 드라이브*   | 이름 \* | 검사하지 마십시오 |
   | Passed Device Posture 검사 | 내 계정 | *OS 버전 Android* |       |           |

Android 사용자는 이제 앱을 사용할 수 있지만 앱 트래픽은 DLP 스캔을 우회합니다.

1. [자주 묻는 질문](/cloudflare-one/reusable-components/lists/)호스트 이름 또는 URL의.

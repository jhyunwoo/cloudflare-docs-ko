DLP 프로파일은 정규 표현식과[검색 결과](/cloudflare-one/data-loss-prevention/detection-entries/)검출하려는 데이터 패턴을 정의합니다. Cloudflare DLP는 일반적인 탐지를 위한 사전 정의된 단면도를 제공합니다, 또는 당신은 당신의 자료, 조직 및 위험 포용력에 특정한 주문 DLP 단면도를 건설할 수 있습니다.

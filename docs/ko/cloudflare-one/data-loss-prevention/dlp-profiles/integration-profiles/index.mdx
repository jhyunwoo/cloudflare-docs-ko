:::참조

통합 프로파일은[Cloudflare 케이스](/cloudflare-one/integrations/cloud-and-saas/).
:::

Cloudflare DLP 통합 프로파일은 타사 데이터 분류 제공업체의 데이터 손실 방지 지원을 가능하게 합니다. 데이터 분류 정보는 제3자 플랫폼에서 검색되며 DLP 프로필로 변환됩니다. DLP 정책을 작성하고 일치하는 데이터를 차단할 수 있습니다.

통합 프로파일의 검색 항목은 타사 플랫폼에 의해 관리되며 Cloudflare DLP 내에서 수동으로 추가, 편집 또는 삭제할 수 없습니다.

## Microsoft Purview 정보 보호 (MIP) 감도 상표

Microsoft는 제공합니다[Purview 정보 보호 감도 상표](https://learn.microsoft.com/en-us/purview/sensitivity-labels)민감한 데이터를 분류하고 보호합니다.

### 설치하기

MIP 감도 라벨을 DLP 프로필에 추가하려면 Microsoft 계정과 통합[Cloudflare 케이스](/cloudflare-one/integrations/cloud-and-saas/microsoft-365/). 새로운 통합 단면도는 아래에 나타날 것입니다**데이터 손실 방지** > **DLP 프로필**. 단면도는 지명됩니다**MIP 감도 상표**CASB 통합의 이름으로 따라.

MIP 감도 상표는 또한 추가될 수 있습니다[사용자 정의 DLP 프로파일](/cloudflare-one/data-loss-prevention/dlp-profiles/#build-a-custom-profile)이름 \*

### 지원하다

레이블 추가 및 편집을위한 24 시간을 허용하십시오. Microsoft 계정에서 Cloudflare DLP에 전파하십시오. Microsoft 계정의 삭제는 Cloudflare DLP 프로필에서 항목을 삭제하지 않습니다.

이 페이지는 구성 할 때 사용할 수있는 프로파일 설정 목록[사전 정의](/cloudflare-one/data-loss-prevention/dlp-profiles/predefined-profiles/)또는[사용자 정의](/cloudflare-one/data-loss-prevention/dlp-profiles/#build-a-custom-profile)DLP 프로파일. 사용자 지정 프로파일을 만들 때 프로파일 설정을 구성할 수 있습니다.[편집 프로파일 설정](#edit-profile-settings)기존의 사전 정의 또는 사용자 정의 프로파일에 대한.

## 프로필 설정

기존의 사전 정의 또는 사용자 정의 DLP 프로파일에 대한 프로파일 설정을 편집하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**데이터 손실 방지** > **회사 소개**.
2. 프로필을 선택, 다음 선택**제품정보**.
3. 내 계정**계정 설정**, 구성[제품정보](#available-settings)당신의 단면도.
4. 제품정보**회사 소개**.

## 옵션 설정

뒤에 오는 진보된 탐지 조정은 predefined와 관례 DLP 단면도를 위해 유효합니다.

### 경기 수

일치 조사는 단면도에 있는 어떤 활성화한 입장이 막거나 로깅과 같은 활동이 방아쇠로 밟기 전에 검출될 수 있는 시간의 수를 나타납니다. 예를 들어, 10의 일치 수를 선택하면 스캔 된 파일 또는 HTTP 몸은 11 또는 더 많은 일치 문자열을 포함해야합니다. 탐지는 독특하지 않습니다.

### 광학 문자 인식 (OCR)

Optical Character Recognition (OCR)는 이미지 파일 내에서 텍스트를 분석하고 해석합니다. DLP 프로파일과 함께 사용할 때 OCR은 사용자가 업로드한 이미지 내에서 민감한 데이터를 감지할 수 있습니다.

OCR 지원 스캐닝`.jpg`/`.jpeg`·`.png`크기 4 KB와 1MB 사이의 파일. 텍스트는 UTF-8 형식으로 인코딩되며 non-Latin 문자에 대한 지원이 포함되어 있습니다.

### AI 컨텍스트 분석<Badge text="Beta" variant="caution" size="small" /> {/* ai-context-analysis */}

:::참조
AI 컨텍스트 분석은 Gateway HTTP 및 HTTPS 트래픽만 지원합니다.
주요 특징

AI 컨텍스트 분석은 주변 상황에 따라 감지에 대한 자신감을 분석하고 조정할 수있는 사전 훈련 된 모델을 사용합니다. DLP는 당신의 신뢰 임계값 위에 있는 어떤 경기든지 기록할 것입니다.

DLP는 어떤 일치하는 텍스트를 redacts, 다음 벡터를 삽입하는 AI 텍스트로 컨텍스트를 제출[Cloudflare Workers AI](/workers-ai/). 벡터는 최대 6개월 동안 사용자별 개인 네임스페이스에 저장되며, 히트 카운트와 함께[false 긍정적 / 부정 보고서](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/#report-false-and-true-positives-to-ai-context-analysis).

AI 컨텍스트 분석을 사용하려면:

1. 선택하기**구성 임계 값**DLP 프로파일.
2. [더 보기](/cloudflare-one/data-loss-prevention/dlp-policies/#2-create-a-dlp-policy)DLP 정책
3. DLP 정책을 구성할 때, 켜기[payload 로깅](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/#log-the-payload-of-matched-rules).

AI 컨텍스트 분석 결과가 귀하의 페이로드 섹션에 표시됩니다.[DLP 로그](/cloudflare-one/data-loss-prevention/dlp-policies/#4-view-dlp-logs). 민감한 자료의 미래 탐지를 개량하기 위하여, 당신은 필요로 합니다[거짓과 진정한 긍정적](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/#report-false-and-true-positives-to-ai-context-analysis).

### 구성 임계 값

Confidence 임계 값은 confident Cloudflare DLP가 DLP 검출에 있는지 나타냅니다. DLP는 감지 주위의 근접 키워드를 검사하여 신뢰를 결정합니다.

Confidence 임계 값은 DLP 프로파일에 설정됩니다. Cloudflare의 신뢰 임계값을 선택할 때 한, DLP 항목이 신뢰 임계 값에 영향을 줄 것으로 볼 수 있습니다. Cloudflare의 신뢰 임계값을 반영하지 않는 항목 아직 지원되지 않거나 적용되지 않습니다.

DLP 신뢰 탐지는 낮은, 중간 및 높은 신뢰 임계값으로 이루어져 있습니다. DLP는 일반 표현을 기반으로하는 낮은 신뢰 검출에 기본적으로, 몇 가지 키워드를 필요로하고 더 자주 트리거됩니다. 중간과 높은 신뢰 탐지는 더 많은 키워드를 요구하고, 더 자주 트리거하고, 정확도의 더 높은 likelihood가 있습니다.

DLP 프로파일의 자신감을 변경하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**데이터 손실 방지** > **회사 소개**.
2. 프로필 선택, 다음 선택**제품정보**.
3. 내 계정**계정 설정** > **구성 임계 값**, 드롭다운 메뉴에서 새로운 신뢰 임계 값을 선택합니다.
4. 제품정보**회사 소개**.

저의 신뢰를 설정하면 중간과 높은 신뢰 감지가 일치합니다. 중간 또는 높은에 대한 신뢰를 설정하면 더 낮은 신뢰 감지를 필터링합니다.

#### Gateway 검출

게이트웨이의 인라인 감지를 위해 낮은 중간 신뢰 감지를 표시하지만 높은 신뢰 감지를 차단하기 위해 Cloudflare는 두 HTTP 정책을 생성하는 것이 좋습니다. 첫 번째 정책은 허용 작업과 낮은 신뢰 DLP 프로파일을 사용해야합니다. 두 번째 정책은 블록 액션과 높은 신뢰 DLP 프로파일을 사용해야합니다. 예를 들면:

| 옵션 정보   | 회사연혁 | 제품정보               | - 연혁 |
| ------- | ---- | ------------------ | ---- |
| DLP 프로필 | 내 계정 | *낮은 Confidence 탐지* | 지원하다 |

| 옵션 정보   | 회사연혁 | 제품정보               | - 연혁 |
| ------- | ---- | ------------------ | ---- |
| DLP 프로필 | 내 계정 | *높은 Confidence 탐지* | 제품정보 |

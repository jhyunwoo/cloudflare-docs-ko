Cloudflare Zero Trust는 민감한 데이터의 일반적인 유형에 대한 사전 정의 DLP 프로파일을 제공합니다. 몇몇 단면도는 검출 과립을 증가하기 위하여 붙박이 유효성 검사를 포함합니다. 또한 구성할 수 있습니다.[고급 설정](/cloudflare-one/data-loss-prevention/dlp-profiles/advanced-settings/)사전 정의된 프로파일을 위해.

## AI 프롬프트

DLP는 다음과 같은 사전 정의 프로파일과 AI 신속한 보호를 제공합니다.

- AI Prompt: AI 보안
- AI Prompt: 고객
- AI Prompt: 금융 정보
- AI 신속한: PII
- AI Prompt: 기술

포함 된 검색 항목에 대한 자세한 내용은 참조[AI 신속한 주제](/cloudflare-one/data-loss-prevention/detection-entries/#ai-prompt-topics).

## Credentials 및 비밀

다음 비밀은 regex로 유효합니다.

- Google 클라우드 플랫폼 키
- AWS 키
- Azure API 키
- SSH 열쇠

| Mastercard 카드 번호       | Luhn의 알고리즘을 사용하여 검증됩니다.                                         |

| 유니온 페이 카드 번호           | Luhn의 알고리즘을 사용하여 검증됩니다.                                         |

## 건강 정보

뒤에 오는 진단 및 약물 이름은 거짓 긍정을 방지하기 위하여 주변 ASCII 문자를 위해 검사됩니다.

- FDA 활성 성분
- FDA 약 이름
- ICD-10 FY2023 짧은 묘사

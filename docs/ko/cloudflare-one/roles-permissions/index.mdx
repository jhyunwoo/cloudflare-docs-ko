Cloudflare Zero Trust 계정을 만들 때, Super Administrator 역할을 받게됩니다. Super Administrator로 Zero Trust 계정에 가입하고 다른 역할을 할당할 수 있습니다. 주어진 계정에 추가할 수 있는 회원 수에 제한이 없습니다. 적절한 권한을 가진 모든 구성원은 Zero Trust에 적극적으로 로그인하면서 구성 변경을 할 수 있습니다.[읽기 전용 모드](/cloudflare-one/api-terraform/#set-dashboard-to-read-only)사용 가능).

계정의 구성원 목록을 확인하거나 역할 및 권한 관리, 우리의 참조[계정 설정](/fundamentals/manage-members/)문서.

### Cloudflare Zero Trust PII

기본적으로 Super Administrators만이 Device ID, Source IP 또는 사용자 이메일과 같은 Gateway 활동 로그에서 최종 사용자 PII를 볼 수 있습니다. 다른 역할은 Super Administrators가 명시적으로 할당하지 않는 한 PII를 읽는 능력이있을 것입니다**Cloudflare Zero Trust PII**그들에게 역할.

Cloudflare Zero Trust PII 역할은 추가에 역할을 고려해야하며 위의 테이블에서 모든 역할을 결합해야합니다. 예를 들어, Super Administrators는 Cloudflare 게이트웨이 역할을 사용자에 할당하고 Cloudflare Zero Trust PII 역할을 추가하여 게이트웨이 로그에서 PII에 액세스 할 수 있습니다.

:::참조
Cloudflare Zero Trust PII 역할은 액세스 인증 로그에 적용되지 않습니다. PII는 항상 접근 로그에서 볼 수 있습니다.

## 이메일 보안 역할

이메일 보안 역할에 대한 자세한 내용은 참조[회계감사 역할](/fundamentals/manage-members/roles/#account-scoped-roles).

- **Cloudflare Zero Trust**: Cloudflare를 편집 할 수 있습니다[사이트맵](/cloudflare-one/). 액세스, 게이트웨이, WARP, 터널, 브라우저 고립, CASB, DLP, DEX 및 이메일 보안을 포함한 모든 Zero Trust 제품에 대한 관리자 액세스 권한을 부여합니다.
- **Cloudflare Zero Trust PII**: Zero Trust에서 PII를 읽을 수 있습니다. 이메일 보안이 포함되어 있습니다.
- **이메일 보안 Analyst**·**이메일 보안 구성 관리자**: 이메일 보안의 모든 관리자 기능에 대한 전체 액세스가 있습니다.
- **이메일 보안 통합 Admin**: 통합을 읽고 설정할 수 있습니다.
- **이메일 보안 구성 관리자**: 관리자 액세스가 있습니다. 이메일에 작업을 수행하거나 이메일을 읽을 수 없습니다.
- **이메일 보안 Analyst**: 분석가 접근. 이메일에 작업을 수행하고 이메일을 읽을 수 있습니다.
- **이메일 보안 보고**: 메트릭을 읽을 수 있습니다.
- **이메일 보안 읽기 만**: 모든 정보를 읽을 수 있지만 아무것도 행동 할 수 없습니다.
- **이메일 보안 정책 관리자**: 모든 설정을 읽을 수 있지만, 단지 쓰기[법적 책임](/cloudflare-one/email-security/settings/detection-settings/allow-policies/), [신뢰할 수 있는 도메인](/cloudflare-one/email-security/settings/detection-settings/trusted-domains/)·[공급 업체](/cloudflare-one/email-security/settings/detection-settings/blocked-senders/).

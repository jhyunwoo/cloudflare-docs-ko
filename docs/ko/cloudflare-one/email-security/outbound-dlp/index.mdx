아웃바운드 DLP는 Microsoft 365와 호환됩니다. 아웃바운드 DLP를 활성화하려면 Microsoft E3 또는 E5 라이센스가 있어야 합니다.
주요 특징

Outbound Data Loss Prevention은 아웃바운드 이메일의 민감한 정보를 보호합니다.[Cloudflare 데이터 손실 방지 (DLP)](/cloudflare-one/data-loss-prevention/). Outbound Data Loss Prevention은 inbox와 통합되며, 무단 데이터 누출을 방지하기 위해 귀하의 이메일을 능동적으로 모니터링합니다.

아웃바운드 DLP를 활성화하려면:

1. [아웃바운드 정책 만들기](/cloudflare-one/email-security/outbound-dlp/#1-create-an-outbound-policy).
2. [DLP Assist 추가 기능 설정](/cloudflare-one/email-security/outbound-dlp/#2-dlp-assist-add-in).

## 1. outbound 정책 생성

아웃바운드 정책은 아웃바운드 이메일 흐름을 제어 할 수 있습니다.

아웃바운드 DLP 정책을 작성하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**이메일 보안** > **아웃바운드 DLP**.

2. 제품정보**정책 추가**.

3. 당신의 정책.

4. 특정 이메일 트래픽과 일치하는 표현을 만듭니다. 예를 들어, 식별 번호를 포함하는 아웃바운드 이메일을 차단하는 정책을 만들 수 있습니다.

   | 옵션 정보        | 회사연혁 | 제품정보                     | 로그인   | - 연혁 |
   | ------------ | ---- | ------------------------ | ----- | ---- |
   | 자주 묻는 질문     | 뚱 베어 | `example.com`            | 이름 \* | 제품정보 |
   | 일치하는 DLP 단면도 | 내 계정 | *사회 보장, 보험, 세금 및 신분증 번호* |       |      |

5. (선택 사항) 기본 블록 메시지 또는 사용자 정의 메시지를 사용하는지 여부를 선택하십시오.

6. 제품정보**공지사항**.

정책 작성 후, 귀하의 정책을 수정하거나 재주문할 수 있습니다.**이메일 보안** > **아웃바운드 DLP**.

### 이름 \*

| 옵션 정보        | 이름 \*                                                                            |
| ------------ | -------------------------------------------------------------------------------- |
| 자주 묻는 질문     | 아웃바운드 이메일의 수신자.                                                                  |
| 이메일 sender   | 귀하의 조직의 사용자는 이메일을 보내.                                                            |
| 일치하는 DLP 단면도 | 더 보기[DLP 프로필](/cloudflare-one/data-loss-prevention/dlp-profiles/)스캔에 이메일 일치의 내용. |

## 2. 차원 Assist 추가

Data Loss Prevention (DLP) Assist add-in은 Microsoft 365 사용자가 Cloudflare의 이메일 보안을 사용하여 무료로 DLP 솔루션을 배포 할 수 있습니다. 사이트맵 Assist add-in은 Outlook 웹 및 dekstop 클라이언트에서 데이터를 보호합니다.

DLP Assist add-in을 설정하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**이메일 보안** > **아웃바운드 DLP**.
2. 제품정보**Microsoft 추가 기능 보기**> 선택**다운로드 add-in**. 이 다운로드`.xml`클라이언트 측에 add-in를 설치해야 하는 파일.
3. Microsoft 365에서 추가 설정:
   - 로그인하기[Microsoft 관리자 패널](https://security.microsoft.com/homepage)·**Microsoft 365 관리자** > **계정 설정** > **통합 앱**.
   - 제품 정보**사용자 정의 앱**선택하기**Office 추가**신청 유형의 경우.
   - 제품정보**장치에서 파일 (.xml) 업로드**.
   - Cloudflare 추가 파일 업로드 단계 3. 그런 다음 마법사를 확인하고 완료하십시오. 그것은 propagate에 추가에서 24 시간까지 가지고 갈 수 있습니다.

차단, 암호화, 또는 승인을 보내려면 Microsoft Purview DLP 내에서 규칙을 구성할 수 있습니다.

3. 어떤 템플릿 또는 사용자 정의 정책을 선택하지 마십시오. 제품정보**이름 \***.
4. 정책에 대한 이름과 설명을 선택하십시오: 당신은 어떤 이름을 선택할 수 있습니다. 그러나이 가이드는 사용할 것`Cloudflare Assist Block`.

8. 이름 \***사용자 알림**, 알림 켜기. 관리자는 그들이 원하는 경우 메시지를 편집 할 수 있습니다. 관리자가 아래의 알림을 받고 싶은 경우도 구성할 수 있습니다.**Incident 보고서** > **관리자 경고 및 보고서에서이 severity 레벨을 사용하십시오.**.

### 제한 사항

Outbound DLP는 그것의 한계를 선물합니다:

- Outbound DLP는 사용자 관리 된 inboxes를 보호합니다.
- 아웃바운드 DLP는 Microsoft가 부과하는 제한으로 인해 Outlook Web App 및 Outlook 데스크톱에서 가장 일관성있는 경험을 제공합니다.

| 회사연혁                             | 주요연혁                         |
| -------------------------------- | ---------------------------- |
| 웹 클라이언트                          | 제품 정보                        |
| 새로운 Outlook 데스크탑 클라이언트 - Windows | 제품 정보                        |
| 데스크탑 클라이언트 - macOS               | Apple 제한으로 인해 지연 될 수 있습니다.   |
| Outlook 데스크톱 클라이언트               | Microsoft 제한으로 인해 작동하지 않습니다. |
| 모바일 클라이언트 - iOS                  | Apple 제한으로 인해 불안정            |
| 모바일 클라이언트 - Android              | Microsoft 제한으로 인해 불안정한       |

도메인을 배포하면 이메일 보안을 추가, 필터 및 편집할 수 있습니다. 스캔 한 도메인을 중지 할 수도 있습니다.

## 도메인 추가

새로운 도메인을 보호하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com)> 이메일 보안.
2. 제품정보**계정 설정**, 이동**이름 \***&#xC120;택하&#xAE30;**- 연혁**.
3. 제품정보**도메인 추가**.

## 필터 영역

도메인을 필터링하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/) > **이메일 보안**.
2. 오시는 길**계정 설정** > **도메인 관리** > **이름 \***, 다음 선&#xD0DD;**- 연혁**.
3. 제품정보**필터 보기** > **구성 방법**. 다음 필터 중 선택: -**MS 그래프 API**: MS Graph API를 통해 연결된 도메인을 볼 수 있습니다. -**BCC/제주**: BCC/Journaling을 통해 연결된 도메인을 볼 수 있습니다. -**MX / 인라인**: MX / 인라인을 통해 연결된 도메인을 볼 수 있습니다. -**Retro 검사**: Retro Scan에서 스캔 한 도메인을 볼 수 있습니다.
4. 제품정보**필터 적용**.

## 웹 사이트

도메인을 편집하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/) > **이메일 보안**.
2. 오시는 길**계정 설정** > **도메인 관리** > **이름 \***, 다음 선&#xD0DD;**- 연혁**.
3. 에 의해**이름 \***&#xD398;이지, 도메인을 찾습니다, 세 가지 점을 선택 >**제품정보**.
4. 도메인을 수동으로 추가하지 않았다면 편집 할 수 있습니다.**뚱 베어**. 도메인을 수동으로 추가하면 편집 할 수 있습니다.**도메인 이름**·**뚱 베어**.
5. 제품정보**제품 정보**.

## 도메인 스캔에서 Cloudflare 방지

스캔 도메인을 중지하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/) > **이메일 보안**.
2. 오시는 길**계정 설정** > **도메인 관리** > **이름 \***, 다음 선&#xD0DD;**- 연혁**.
3. 에 의해**이름 \***&#xD398;이지, 도메인을 찾습니다, 세 가지 점을 선택 >**관련 상품**.
4. 제품정보**관련 상품**도메인 스캔에서 Cloudflare를 다시 중지합니다.

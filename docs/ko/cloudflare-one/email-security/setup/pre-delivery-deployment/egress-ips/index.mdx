이메일 보안을 설정할 때[MX/Inline 배포](/cloudflare-one/email-security/setup/pre-delivery-deployment/mx-inline-deployment/), 당신의 기존 이메일 공급자는 이메일 보안의 egress IP 주소에서 오는 메시지를 받아들일 것입니다.

egress IPs 설정은 Cloudflare를 사용하여 이메일을 수신합니다.

참고 자료를 위한 이 페이지에 어떤 IP subnet 가면 범위든지 사용을 참조하십시오.

:::caution\[Microsoft 365에 대한 추가 정보]

Microsoft 365는 IPv6 주소와 다음과 같은 IPv4 서브넷 마스크 범위를 지원하지 않습니다.

- `104.30.32.0/19`
- `134.195.26.0/23`

Microsoft 365를 사용하는 경우, 깨진 다운을 사용해야합니다.`/24`subnet 가면 IP 주소. 더 알아보기[마이크로 소프트 365`/24`이름 \*](#microsoft-365-24-addresses)지원되는 IPv4 주소 목록.

:::

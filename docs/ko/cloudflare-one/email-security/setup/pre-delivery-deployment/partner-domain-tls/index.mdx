특정 도메인에서 오는 이메일에 대한 추가 TLS (Transport Layer Security) 요구 사항을 추가하려면 SSL/TLS 검사의 높은 수준을 시행할 수 있습니다. TLS가 필요하면 지정된 도메인에서 TLS없이 메일이 떨어질 것입니다.

:::참조
모든 이메일에 걸쳐 TLS를 시행하려면 도메인을 내장 할 때 TLS 요구 사항을 시행해야합니다. 특정 이메일에 대한 TLS 만 시행하려면, 당신은 그렇게 할 수 있습니다**계정 설정** > **파트너 도메인 TLS** > **도메인 추가**.
:::

파트너 도메인 설정:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/)선택하기**이메일 보안**.
2. 제품정보**계정 설정** > **파트너 도메인 TLS** > **- 연혁**.
3. 제품정보**도메인 추가**.
4. 유효한 도메인 이름을 입력하십시오. 선택하여 하위 도메인을 제외할 수도 있습니다.**추가하기**.
5. (선택 사항) 규칙을 설명하는 옵션 노트를 추가합니다.
6. 제품정보**제품 정보**.

파트너 도메인을 편집하려면 세 가지 점을 선택하십시오 >**제품정보**.

파트너 도메인을 삭제하려면 세 가지 점을 선택하십시오 >**이름 \***.

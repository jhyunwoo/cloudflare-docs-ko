## 교통 규칙

이메일 보안에 대한 특정 처분으로 이메일을 보낼 수있는 교통 규칙을 만들려면 :

1. 새소식[Exchange 관리자 센터](https://admin.exchange.microsoft.com/#/homepage).

2. 오시는 길**메일 흐름** > **이름 \***.

3. 제품정보**규칙 추가** > **새로운 규칙 만들기**.

4. 다음 규칙 조건을 설정:
   - **이름 \***: `Email security Deliver to Junk Email folder`.
   - **이 규칙을 적용하면**: *메시지 헤더* > *이 단어를 포함*.
     - **본문 바로가기**: `X-CFEmailSecurity-Disposition` > **제품 정보**.
     - **이름 \***: `BULK` > **더 보기** > **제품 정보**.
   - **이 규칙을 적용하면**: 선&#xD0DD;**+**&#xB450; 번째 상태를 추가합니다.
   - **이름 \***: *보낸 사람* > *IP 주소는 이러한 범위 또는 정확히 일치의 모든*> egress IP를 입력[IP 등급](/cloudflare-one/email-security/setup/pre-delivery-deployment/egress-ips/)사이트 맵
   - **다음 것** - *메시지 속성 수정* > *Spam Confidence 레벨 설정 (SCL)* > *5*.

5. 제품정보**이름 \***.

6. 이 화면의 기본값을 사용할 수 있습니다. 제품정보**이름 \***.

7. 설정 및 선택**제품 정보** > **이름 \***.

8. 규칙 선택`Email security Deliver to Junk Email folder`당신은 단지 생성하고, 선택**이름 \***.

이 튜토리얼에서, 당신은 MX 레코드로 이메일 보안을 사용하여 Google Workspace를 구성하는 방법을 배울 것입니다.

## 제품 정보

- 이메일 보안 계정.
- Google 관리자 콘솔에 액세스 ([Google 관리자 콘솔](https://admin.google.com/) > **앱 다운로드** > **Google 작업 공간** > **사이트맵**).
- 도메인 네임서버에 액세스하여 이메일 보안에 의해 처리되는 도메인에 대한 MX 레코드를 호스팅합니다.

## 1. Inbound 이메일 설정

설치하기[Inbound 이메일 설정](https://support.google.com/a/answer/60730?hl=en)뒤에 오는 세부사항으로:

- 내 계정**게이트웨이 IP**, 선택**더 보기**링크 및 위에서 언급 한 IP를 추가[IP 등급](/cloudflare-one/email-security/setup/pre-delivery-deployment/egress-ips/).
- 제품정보**자동 감지 외부 IP (추천)**.
- 제품정보**위에 나열된 이메일 게이트웨이의 연결을 위한 TLS 필요**.
- 선택 없음**Gateway IPs에서 모든 메일을 거부**. 메일 흐름을 보장하기 위해 나중에이 옵션을 활성화합니다.
- 제품정보**제품 정보**.

## 2. (선택) 이메일 quarantine를 설치하십시오

[이메일 quarantine 설정](https://support.google.com/a/answer/6104172?hl=en#add-new-quarantine)뒤에 오는 세부사항으로:

- **이름 \***: 이메일 보안 맛있는.
- **이름 \***: 이메일 보안 맛있는.
- 제품정보**Inbound denial 결과**, 선택**드롭 메시지**.
- 제품정보**Outbound denial 결과**, 선택**드롭 메시지**.
- 제품정보**제품 정보**.

새로 만든 quarantine에 액세스하려면, 선택**ADMIN QUARANTINE로 이동**또는 브라우저를 지적함으로써 quarantine에 직접 액세스[사이트맵](https://email-quarantine.google.com/adminreview).

## 3. (선택) 내용 수락 여과기를 창조하십시오

오시는 길**견적 요청**, 그리고 창조[콘텐츠 준수 필터](https://support.google.com/a/answer/1346934?hl=en#zippy=%2Cstep-go-to-gmail-compliance-settings-in-the-google-admin-console%2Cstep-enter-email-messages-to-affect)quarantine에 악성 메시지를 보낼 수 있습니다. 다음 정보를 입력하십시오:

- **콘텐츠 준수**: 추가`Quarantine Email security Malicious`.
- **이메일 메시지**: 선택**인바운드**.
- **각 메시지에서 검색 할 콘텐츠를 설명하는 표현 추가**:
  - 제품정보**더 보기**조건을 추가합니다.
  - 내 계정**간단한 내용 일치**, 선택**고급 콘텐츠 일치**.
  - 내 계정**제품정보**, 선택**전체 헤더**.
  - 내 계정**일치 유형**, 선택**본문 바로가기**.
  - 내 계정**이름 \***, 입력`X-CFEmailSecurity-Disposition: MALICIOUS`.
  - 제품정보**제품 정보**상태를 저장합니다.
- 위의 표현이 일치하면, 다음을 수행, 선택**Quarantine 메시지**그리고**이메일 보안 맛있는**이전 단계에서 만든 quarantine.
- 제품정보**제품 정보**.

다른 분해를 quarantine하고 싶다면 위의 단계를 반복하고 다른 분해에 대한 다음 문자열을 사용하십시오.

- `X-CFEmailSecurity-Disposition: BULK`
- `X-CFEmailSecurity-Disposition: SPOOF`
- `X-CFEmailSecurity-Disposition: UCE` (`UCE`해당 사항`SPAM`)

원하는 경우, 분리 된 quarantine을 만들 수 있습니다.

## 5. (추천) MX 레코드 우회에서 Google Workspace 보안

DNS 공격의 한 가지 방법은 오래된 MX 레코드를 검색하고 전송하는 것입니다<GlossaryTooltip term="phishing">피싱</GlossaryTooltip>메일 서버에 직접 이메일을 보냅니다. 이메일 흐름을 확보하려면 이메일 보안을 시작했을 때 인바운드 메시지가 Google Workspace에서 허용되는 이메일 흐름을 시행해야 합니다. 이 커넥터를 추가하여 TLS 암호화를 사용하여 이메일 보안을 허용 할 수 있습니다. 이 단계는 선택적이지만 권장됩니다.

:::카ution\[중요]
이 단계는 Google Workspace의 모든 도메인이 이메일 보안에 내장 된 후 72 시간까지 수행 할 수 없으며 이메일 보안은 MX 레코드입니다. 도메인이 내장되거나 DNS가 여전히 전파되지 않은 경우 도메인의 생산 이메일 흐름에 영향을 줄 것입니다.
주요 특징

72 시간 후, MX 레코드 DNS 업데이트는 인터넷을 통해 충분히 전파됩니다. 이제 이메일 흐름을 확보하는 것이 안전합니다. Google Workspace는 이메일 보안에 의해 첫 번째 수신되는 메시지 만 허용됩니다. 이 단계는 캐시 된 MX 항목을 사용하여 위협 배우를 방지하는 것이 매우 좋습니다. 이메일 보안을 우회하여 Google Workspace로 직접 메시지를 주입하십시오.

1. 오시는 길[Google 관리 콘솔](https://admin.google.com/), 다음 선택**앱 다운로드** > **Google 작업 공간** > **사이트맵**.

2. 제품정보**스팸, Phishing 및 악성 코드**.

3. 오시는 길**Inbound 게이트웨이**선택하기**Inbound 게이트웨이**.

4. 이름 \***Gateway IPs에서 모든 메일을 거부**선택하기**제품 정보**.

5. 제품정보**제품 정보**Gmail 고급 구성 콘솔에서 구성 변경을 커밋하고 활성화합니다.

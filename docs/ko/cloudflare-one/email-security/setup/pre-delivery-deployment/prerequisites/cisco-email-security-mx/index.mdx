## 1. 이메일 보안 이메일 보호 IPs에 대한 Sender 그룹 추가

새로운 Sender 그룹을 추가하려면:

1. 오시는 길**메일 정책** > **HAT 개요**.

2. 제품정보**Sender 그룹 추가**.

3. 다음과 같이 새로운 Sender 그룹 구성:
   - **이름 \***: `Email security`.
   - **이름 \***: 기존 주문**화이트리스트**sender 그룹.
   - **이름 \***: `Email security Email Protection egress IP Addresses`.
   - **- 연혁**: `TRUSTED`(기본적으로, 스팸 탐지는 이 메일 흐름 정책에 대한 비활성화).
   - **사이트맵**: 공백을 남겨두십시오.
   - **DNS 목록**: 공백을 남겨두십시오.
   - **호스트 DNS 검증 연결**: 모든 옵션을 취소.

4. 제품정보**제출 및 제출**IP 주소 추가<a href="/cloudflare-one/email-security/setup/pre-delivery-deployment/egress-ips/" target="_blank">IP 등급</a>

## 2. 들어오는 릴레이를 구성하십시오

수신된 릴레이 섹션을 구성해야 합니다. IronPort를 무시하기 위해 업스트림 홉을 무시하기 위해, 모든 연결은 이제 이메일 보안에서 온다. 이 단계는 철 포트가 IP 평판을 계산하기 위해 원래 IP를 검색 할 수 있도록 필요합니다. IronPort는 또한 메시지의 Anti-Spam (IPAS) 득점에서이 정보를 사용합니다.

1. 수신 릴레이 기능을 활성화하려면, 선택**회사연혁** > **수신 릴레이**.
2. 제품정보**이름 \***&#xADF8;리고 당신의 변화를 투입하십시오.
3. 이제 수신 릴레이를 추가해야합니다. 제품정보**회사연혁** > **수신 릴레이**.
4. 제품정보**릴레이 추가**그리고 당신의 릴레이에게 이름을 줍니다.
5. 수신 메시지에 이메일 게이트웨이에 연결되는 MTA, MX, 기타 기계의 IP 주소를 입력하십시오. IPv4 또는 IPv6 주소를 사용할 수 있습니다.
6. 이름 \*`Received:`원래 외부 보낸 사람의 IP 주소를 식별하는 헤더.

## 3. SPF 검사 사용

IronPort에서 Sender 정책 Framework (SPF)를 비활성화하십시오. 이메일 보안은 MX 레코드로 작동하기 때문에 SPF 체크를 비활성화하지 않으면 IronPort는 SPF 실패로 인해 이메일을 차단합니다.

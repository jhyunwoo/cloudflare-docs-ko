## MX/Inline 구성 시작

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**제품정보**. 다음 옵션 중 하나를 선택:

- 이메일 보안을 구입하지 않은 경우, 선택**연락처**.
- 어떤 통합이 없다면,[통합](/cloudflare-one/email-security/setup/pre-delivery-deployment/mx-inline-deployment-setup/#associate-an-integration), 다음 선택**설치하기**.
- 통합이 있는 경우, 도메인을 연결하지 않고, 선택[**도메인 연결**](/cloudflare-one/email-security/setup/pre-delivery-deployment/mx-inline-deployment-setup/#connect-a-domain).

4. 제품정보**MX / 인라인**.
5. MX/Inline 구성을 시작하려면 이메일 공급자의 플랫폼에서 사전 예약 설정 완료해야 합니다. 이 단계를 완료하면, 선택**나는 필요한 모든 요구 사항을 완료 한 것을 확인**. 그때, 선택**설정 시작**.

:::참조
한 번에 한 도메인 만 내장 할 수 있습니다.

## 통합 관리

MX/Inline은 보호에 대한 통합이 필요하지 않습니다. 그러나 통합을 연결하는 가장 좋은 연습입니다.

통합을 연결하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합** > **클라우드 및 SaaS 통합** > **통합**
2. 제품정보**통합 연결**.
3. 신청 선택: 선택**Google 워크스페이스 CASB + 이메일**, 또는**마이크로 소프트 CASB + 이메일**.
   - 더 알아보기[Gmail BCC 통합 활성화](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/enable-gmail-integration/#1-create-a-service-account-in-your-gcp-project)당신이 선택하면**Google 워크스페이스 CASB + 이메일**.
   - 더 알아보기[Microsoft 통합 활성화](/cloudflare-one/email-security/setup/post-delivery-deployment/api/m365-api/#enable-microsoft-integration)당신이 선택하면**마이크로 소프트 CASB + 이메일**.
4. 통합을 한 후, 이동**이메일 보안** > **설치하기**.
5. 자주 묻는 질문[도메인 연결](/cloudflare-one/email-security/setup/pre-delivery-deployment/mx-inline-deployment-setup/#connect-a-domain).

## 도메인 연결

Cloudflare에서 확인된 영역이 있는 경우 다음 단계로 계속됩니다.

1. **도메인 연결**: 도메인 선택 다음, 선택**계속하기**.
2. **선택 위치**: 이 단계는 이메일 보안이 메일 흐름에 맞는 위치를 선택하고 위치 설정을 구성 할 수 있습니다.
   - **선택 위치**: 선택 :
     - **첫 번째 (합계 = 1)**: 이메일 보안은 이메일 수신 첫 번째 서버입니다. 인터넷과 Cloudflare 사이 다른 이메일 스캐너 또는 서비스가 없습니다.
     - **중간에 앉아 (hop count > 1)**: 이메일 보안은 첫 번째 위치보다 다른 곳에 앉아 있습니다. 다른 서버는 이메일 수신*이전 다음*이메일 보안. 다른 이메일 스캐너 또는 이메일 서비스가 있습니다.
   - **위치 설정**: 이메일 보안이 수신 및 전달하는 방법 :
     - **연락처**: 메일 보안 후 메일 흐름 다음 hop입니다. 이 값은 자동 충전이지만 여전히 변경할 수 있습니다.
     - **아웃바운드 TLS**: 선택 :
       1. **TLS를 통한 모든 메시지 전달**(추천).
       2. **모든 메시지를 전달 opportunistic TLS**.
   - 제품정보**계속하기**.
3. (**옵션 정보**, 선택**현재 위치**이 단계를 건너뛰기)**quarantine 정책 구성**: 수신자의 수신받은 편지함에 도달하여 수신된 메시지의 특정 유형을 자동으로 막을 수 있습니다.
4. (선택)**업데이트 MX 레코드**:
   - 이메일 보안은 자동으로 Cloudflare를 통해 프록시 트래픽에 대한 MX 레코드를 업데이트 할 수 있습니다. 이름 \***자주 묻는 질문**, 메일 처리 위치를 선택하십시오.
   - 선택하여 Cloudflare를 업데이트할 수 있습니다.**나는 Cloudflare를 새로운 MX 레코드로 업데이트 할 수 있음을 확인합니다.**. 이메일 보안 업데이트 MX 레코드 때, 우리는 이메일 보안 MX 레코드로 원래 MX 레코드를 교체합니다.
   - 제품정보**계속하기**.
5. **자주 묻는 질문**: 도메인을 검토 한 다음 선택**본문 바로가기**.

## Cloudflare와 도메인이 없는 사용자

Cloudflare 도메인이 없다면 대시보드는 두 가지 옵션을 표시합니다.

- [도메인을 수동으로 입력](/cloudflare-one/email-security/setup/pre-delivery-deployment/mx-inline-deployment-setup/#enter-domain-manually).
- [Cloudflare에 도메인 추가](/cloudflare-one/email-security/setup/pre-delivery-deployment/mx-inline-deployment-setup/#add-a-domain-to-cloudflare).

## 도메인을 수동으로 입력

1. **도메인 추가**: 수동으로 도메인 이름을 입력합니다.
2. **모든 도메인**: 모든 도메인을 검토 한 다음 선택**계속하기**.
3. **도메인 인증**: 도메인을 확인하려면 24시간까지 걸릴 수 있습니다. 제품정보**이름 \***.
4. 도메인이 확인되면 대시보드는 다음과 같은 메시지를 표시합니다.**이메일 보안에 연결할 준비가 된 도메인이 있습니다.**. 이것은 이제 MX/Inline을 통해 이메일 보안을 설정할 수 있다는 것을 의미합니다.
5. 제품정보**설치하기**, 다음 선택**MX / 인라인**.
6. 단계에 따라[MX/Inline 구성 시작](/cloudflare-one/email-security/setup/pre-delivery-deployment/mx-inline-deployment-setup/#initiate-mxinline-configuration).

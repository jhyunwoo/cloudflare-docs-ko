Gmail을 이메일로 사용하여 고객, 이메일 보안 설정은 빠르고 쉽습니다.

당신은 필요[통합 만들기](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/enable-gmail-integration/), [BCC 규칙 추가](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/add-bcc-rules/)·[도메인 연결(s)](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/connect-domains/). 당신은 선택할 수 있습니다[추가 도메인](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/connect-domains/#add-additional-domains)나중에 단계.

Google 통합을 설정하면 이메일 보안은 이메일 메시지의 사본을 받게됩니다. Google 통합이 필요합니다.[자동 이동](/cloudflare-one/email-security/settings/auto-moves/).

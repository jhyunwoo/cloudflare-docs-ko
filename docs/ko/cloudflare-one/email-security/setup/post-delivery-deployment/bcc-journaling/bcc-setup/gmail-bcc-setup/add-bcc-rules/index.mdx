이 페이지는 Google Admin 콘솔에서 BCC 규칙을 추가하는 방법을 보여줍니다.

BCC는 장님 탄소 사본을 위해 서 있습니다. BCC 규칙은 선택한 아웃바운드 및 인바운드 이메일의 보안 사본을 만들 수있는 Google Workspace 기능입니다. 이메일 보안을 허용하면 이메일 사본을 수신 할 수 있습니다. Cloudflare는 이메일 inbox를 보호하기 위해 포스트 배달 분석을 수행 할 수 있습니다.

BCC 규칙을 추가하려면:

1. 로그인하기[Google 관리자 콘솔](https://admin.google.com/).
2. 사이드바에서 이동**앱 다운로드** > **Google 작업 공간** > **사이트맵** > **견적 요청**.
3. 오시는 길**콘텐츠 준수**> 선택**제품정보**.
4. 추가하기**콘텐츠 준수**필터 및 이름`Email security - BCC`.
5. 내 계정**이메일 메시지**, 선택**인바운드**.
6. BCC를 통해 이메일 보안에 이메일을 보내려면 수신자를 선택하십시오. 이름 \***각 메시지에서 검색 할 콘텐츠를 설명하는 표현 추가**:
   - 제품정보**다음의 메시지가 있다면**.
   - 제품정보**더 보기**표현을 구성합니다.
     - 제품정보**고급 콘텐츠 일치**.
     - 내 계정**제품정보**, 선택**헤더 + 이름 \***.
     - 내 계정**일치 유형**, 선택**경기 regex**.
     - 내 계정**계정 관리**, 입력`.*`. 당신은 regex를 필요에 따라 주문을 받아서 만들 수 있고 admin 페이지 또는 같은 위치에 시험하십시오[레퍼런스](https://regexr.com/).
     - 제품정보**제품 정보**.
7. 내 계정**위의 표현이 일치하면 다음과 같습니다.**:
   - 제품정보**본문 바로가기**.
     - 견적 요청**옷 입은** > **자주 묻는 질문**unselected, 그래서 이메일은 unin resulttended로 떨어질 것입니다. 나중에 이 옵션을 선택하면 됩니다.
     - 오시는 길**자주 묻는 질문**, 선택**더 많은 수상자** > **사이트맵**> 선택**지원하다**:
       - 이름 \***옷 입은**, 선택**자주 묻는 질문** > **자주 묻는 질문**> 서비스 주소를 입력하십시오. 이것은 당신이 copied 서비스 주소이며 단계 5 때[도메인 연결](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/connect-domains/)·
         서비스 주소를 복사하고 붙여 넣지 않았다면: -[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**이메일 보안**. - 이동**계정 설정**도메인을 찾습니다.**귀하의 도메인**. - 3개의 점 선택 >**사이트 맵** > **서비스 주소**. 서비스 주소를 복사하고 붙여넣기.
       - 이름 \***스팸 및 배송 옵션**, 지킵니다**이 수신자에서 Suppress 반송**지원되지 않습니다.
       - 이름 \***기타 제품**, 선택**X-Gm-Spam 및 X-Gm-Phishy 헤더 추가**.
       - 제품정보**제품 정보**.
8. 내 계정**계정 유형에 영향을 미치는**, 선택**이름 \***·**회사 소개**.
9. 제품정보**제품 정보**.

BCC 규칙이 성공적으로 구성되었는지 확인하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**이메일 보안** > **계정 설정**.
2. 제품정보**이름 \*** > **- 연혁**.
3. 도메인 찾기 상태의 밑에, 대시보드는 표시해야 합니다**지원하다**. BCC 규칙이 성공적으로 구성되었는지, 귀하의 메일 흐름은 감지됩니다.

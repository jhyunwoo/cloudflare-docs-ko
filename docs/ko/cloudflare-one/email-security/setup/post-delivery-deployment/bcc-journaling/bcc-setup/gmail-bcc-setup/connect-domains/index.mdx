3. (**옵션 정보**) **조정 hop 조사**: 번호 입력<GlossaryTooltip term="Hops">뚱 베어</GlossaryTooltip>. 그때, 선택**계속하기**. hop count를 구성하면 Cloudflare가 이메일 처리 체인에 앉아있는 곳을 결정합니다.
4. (**옵션 정보**, 선택**현재 위치**이 단계를 건너뛰기)**메시지 이동**: 참고[자동 이동](/cloudflare-one/email-security/settings/auto-moves/)auto-moves를 구성합니다. 다음, 선택**계속하기**.
5. **자주 묻는 질문**: Cloudflare를 원하는 위치를 설정하여 이메일을 처리하십시오.**주요사업**기본 옵션이 될 것입니다. 당신이 선택하는 경우에**주요사업**, `<account tag>@CF-emailsecurity.com`귀하의 지역 서비스 주소가 될 것입니다. 처리 위치를 선택하면, 선택**계속하기**.
6. **자주 묻는 질문**: 연결된 도메인 및 서비스 주소를 검토하십시오. 다음, 선택**본문 바로가기**

## 추가 도메인

추가 도메인 추가:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**이메일 보안** > **계정 설정**.
2. 제품정보**통합 연결** > **BCC/제주** > **Google과의 통합** > **이름 \***.
3. **연결 영역**: 추가하려는 도메인을 선택, 다음 선택**이름 \***.
4. (선택 사항) 선택**수동 도메인 추가**: 추가 도메인을 수동으로 입력 한 다음 선택**이름 \***.
5. (선택 사항) 선택**조정 hop 조사**: 번호 입력<GlossaryTooltip term="Hops">뚱 베어</GlossaryTooltip>.
6. **자주 묻는 질문**: 선택한 도메인을 검토하고 다음 이메일을 사용하여 타사 이메일 공급자와 서비스 주소를 구성하십시오.
   ```txt
   <account tag>@CF-emailsecurity.com
   ```
7. 제품정보**제품 정보**.

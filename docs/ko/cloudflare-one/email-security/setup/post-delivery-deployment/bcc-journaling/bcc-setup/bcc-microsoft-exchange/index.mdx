Microsoft Exchange를 사용하는 고객은 BCC를 통해 이메일 보안 설정이 빠르고 쉽습니다. BCC를 통해 이메일 보안을 전송하려면 인바운드 규칙을 구성해야 하며 잠재적인 처리 및 탐지를 위해 이메일을 보내야 합니다.<GlossaryTooltip term="phishing">피싱</GlossaryTooltip>공격. 다음 이메일 흐름이 어떻게 작동 하는지 보여줍니다:

![이메일 보안과 Microsoft Exchange의 phishing 평가 위험을 설정할 때 이메일 흐름.](~/assets/email-security/Microsoft_Exchange_365.png)

:::note\[Microsoft Exchange 고객을 위한 자동 이동]
Microsoft Exchange 고객은 전자 메일 서비스가 온-프레미스 인 경우 자동 백업 할 수 있으며 Microsoft Exchange Online을 사용합니다.

1. 오시는 길**관리 콘솔**·**조직 구성** > **허브 운송**.

여러 규칙을 가지고 있다면 BCC 규칙의 순서를 변경하고 규칙 순서에 올바른 위치로 이동합니다. 이것은 당신이 이메일 보안에 BCC 메시지를 보낼 수 있도록 필요합니다. 일반적으로 이메일 보안 BCC 규칙은 규칙의 상단에있을 것입니다. 이메일 보안 BCC 규칙의 구성 조건은 인바운드 메시지를 위해 트리거됩니다.

## 이메일 처리 및 보고서

BCC 모드에서, 모든 이메일은 이메일 보안에 의해 자동화 된 피싱 탐지를 통해 넣어. 피싱 탐지를 트리거 하는 이메일은 제품 포털, 이메일 및 Slack을 통해 보고를 위해 기록됩니다. 탐지를 트리거하지 않는 이메일은 삭제됩니다.

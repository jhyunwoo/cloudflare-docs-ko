통합이 없는 경우:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**이메일 보안**.
2. 오시는 길**계정 설정** > **도메인 관리** > **이름 \***> 선&#xD0DD;**- 연혁**.
3. 도메인을 찾습니다, 세 가지 점을 선택 > 제품정보**통합 관리**.
4. 제품정보**통합 연결**. 그런 다음**통합 추가**사이트 맵
5. 제품정보**Google 워크스페이스 CASB+EMAIL** > **통합 선택**.
6. 통합을 선택하면 할 수 있습니다.[Gmail BCC 통합 활성화](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/enable-gmail-integration/#enable-gmail-bcc-integration).

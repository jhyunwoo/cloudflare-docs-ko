## Gmail BCC 통합 활성화:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**제품정보**. 다음 옵션 중 하나를 선택:

- 이메일 보안을 구입하지 않은 경우, 선택**연락처**.
- 어떤 통합이 없는 경우:
  - 제품정보**설치하기**, 다음 선택**BCC/제주**.
  - 제품정보**Google과의 통합** > **이름 \***.
  - 통합 이름, 다음 선택**이름 \***.
  - 오시는 길[단계 1](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/enable-gmail-integration/#1-create-a-service-account-in-your-gcp-project)통합 관련 프로세스를 계속합니다.
- 통합이 있는 경우, 도메인을 연결하지 않았습니다:
  - 제품정보**도메인 연결**.
  - 제품 정보**BCC/제주** > **Google과의 통합**.
  - 더 알아보기[도메인 연결](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/connect-domains/)도메인을 연결하기 위해(s).

### 1. GCP Project의 서비스 계정 만들기

1. 통합을 한 번, 선택**이름 \***.
2. 에 의해[Google 클라우드 콘솔](https://console.cloud.google.com/welcome/new), sidebar로 이동, 선택**API 및 서비스**, 다음 선택**회사 소개**.
3. 제품정보**회사 소개** > **서비스 계정**. 참고[서비스 계정 개요](https://docs.cloud.google.com/iam/docs/service-account-overview)서비스 계정에 대해 더 알아보기.
4. 서비스 계정을 만들려면 세부 사항 작성 :
   - **서비스 계정 이름**: 입력`Cloudflare Google Integration`.
   - **서비스 계정 ID**: 입력`cloudflare-google-integration`.
   - **서비스 계정 설명**: 입력`Cloudflare Google Integration`.
   - 제품정보**결제 및 결제**.

### 2. 서비스 계정의 JSON Key 생성

에 의해[Google 클라우드 콘솔](https://console.cloud.google.com/welcome/new):

1. 사이드바에서, 선택**IAM 및 광고** > **서비스 계정**.
2. 이메일 찾기, 세 가지 점을 선택, 다음 선택**키 관리**.
3. 제품정보**키 추가** > **새 키 만들기**.
4. 제품정보**JSON 파일**> 선택**제품정보**. 이 다운로드`.json`언제 사용할지 파일[JSON 키 업로드](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/enable-gmail-integration/#3-upload-json-key).

### 3. JSON 키 업로드

에 의해[사이트맵 1개의 대시보드](https://one.dash.cloudflare.com/), 업로드`.json`파일 다운로드 단계 3.

### 4. GCP에서 필수 Google Workspace API

Google Cloud Console에서 다음 API를 활성화하십시오.

- [Google 캘린더 API](https://console.cloud.google.com/apis/library/calendar-json.googleapis.com?project=winter-surf-439414-h1)
- [Google 드라이브 API](https://console.cloud.google.com/apis/library/drive.googleapis.com?project=winter-surf-439414-h1)
- [Google 관리자 SDK API](https://console.cloud.google.com/apis/library/admin.googleapis.com?project=winter-surf-439414-h1)
- [Gmail API를](https://console.cloud.google.com/apis/library/gmail.googleapis.com?project=winter-surf-439414-h1)
- [Google 서비스 사용 API](https://console.cloud.google.com/apis/library/serviceusage.googleapis.com?project=winter-surf-439414-h1)

### 5. Google Workspace 관리자 콘솔에 로그인

Google Workspace Admin Console에 로그인하십시오. 암호를 입력하고 Google Workspace Admin Console에 로그인하십시오.

### 6. Domain-Wide Delegation API 클라이언트 만들기

1. 제출하기**고객 ID**·**채용 정보**Cloudflare 하나 대시보드에 표시.
2. Google Admin에서 이동**보안 보안** > **액세스 및 데이터 제어** > **API 제어**.
3. 제품정보**맨션 DOMAIN WIDE DELEGATION** > **새소식**.
4. Client ID를 사용하여 새로운 API 클라이언트를 만들 수있는 범위를 복사합니다. 더 알아보기[Delegate 도메인 전체 권한을 귀하의 서비스 계정에](https://cloud.google.com/chronicle/docs/soar/marketplace-integrations/google-alert-center?_gl=1*skktsb*_ga*MTMxODg5NDExMy4xNzI5NjA1MzYy*_ga_WH2QY8WWF5*MTcyOTc3MDg2Ny40LjEuMTcyOTc3MDg5OC4yOS4wLjA.#delegate_domain-wide_authority_to_your_service_account). 그때, 선택**이름 \***.

### 7. Workspace 관리자 이메일 확인

Google Workspace Administrator 계정과 관련된 이메일을 입력하십시오. 귀하의 이메일은 Google Workspace 계정과 관련된 이메일 또는 통합이 작동하지 않습니다.

### 8. 통합 만들기

1. 제품정보**통합 만들기**.
2. 통합을 만들면, 연결될 것입니다.**자주 묻는 질문**페이지, 당신이 검토 할 수있는 곳**통합 정보**.
3. 세부사항을 검토하고, 그 후에 선정하십시오**완전한 이메일 보안 설정** > **이메일 보안을 계속**.

통합이 성공했는지 확인하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합**.
2. 이름 \***당신의 통합**, 당신의 통합을 찾아내고, 통합 전시를 지킵니다**CASB+이메일**이름 \***제품정보**.

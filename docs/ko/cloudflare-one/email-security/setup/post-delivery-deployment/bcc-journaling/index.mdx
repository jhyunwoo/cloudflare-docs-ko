BCC/Journaling 배포는 포스트 배달 유형의 배포입니다. Cloudflare는 사용자의 inbox에 도달 한 후 이메일을 분석합니다. 전자 메일을 수신 때마다 이메일 공급자는 분석을위한 Cloudflare에 블라인드 사본을 보낼 것입니다.

- 제품 정보[BCC 소개](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/gmail-bcc-setup/)이메일 공급자가 Gmail인 경우.
- 제품 정보[뉴스 레터](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/journaling-setup/m365-journaling/)이메일 공급자가 Microsoft 365일 경우.

이 페이지는 Cloudflare 대시보드에서 BCC/Journaling을 통해 도메인을 수동으로 추가하는 방법을 가르칩니다.

이 설정은 이메일 공급자가 Microsoft 365 또는 Google Workspace가 아니며 직접 계정을 통합 할 필요가 없습니다. 수동으로 추가하지 않는 것이 좋습니다.[자동 몰드](/cloudflare-one/email-security/settings/auto-moves/)또는[디렉토리 동기화](/cloudflare-one/email-security/directories/).

## 자주 묻는 질문

이메일 보안을 사용하려면 다음을해야합니다.

<Render file="email-security/onboarding-prerequisites" product="cloudflare-one" />

## 수동으로 도메인 추가

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/) > **이메일 보안**.
2. 제품정보**제품정보**. 이메일 보안을 구입하지 않은 경우, 선택**연락처**. 그렇지 않으면, 선택**설치하기** > **BCC/제주**.
3. 제품정보**수동 추가**.

## Cloudflare 도메인 사용자

에 의해**이메일 보안 설정**이름:

1. **연결 영역**: 적어도 하나의 도메인을 선택하십시오. 다음, 선택**계속하기**.
2. (**옵션 정보**) **수동 도메인 추가**: 수동으로 추가 도메인을 입력합니다. 다음, 선택**계속하기**.
3. (**옵션 정보**) **조정 hop 조사**: 번호 입력<GlossaryTooltip term="Hops">뚱 베어</GlossaryTooltip>, 다음 선택**계속하기**.
4. **자주 묻는 질문**: Cloudflare를 원하는 위치를 설정하여 이메일을 처리하십시오.**주요사업**기본 옵션이 될 것입니다. 당신이 선택하는 경우에**주요사업**, `<account tag>@CF-emailsecurity.com`귀하의 지역 서비스 주소가 될 것입니다. 처리 위치를 선택하면, 선택**계속하기**.
5. **자주 묻는 질문**: 연결된 도메인 및 지역 서비스 주소를 검토하십시오. 다음, 선택**본문 바로가기**

## Cloudflare와 도메인이 없는 사용자

Cloudflare와 도메인이 없다면 Cloudflare 대시보드는 두 가지 옵션을 표시합니다.

- Cloudflare에 도메인을 추가합니다.
- 도메인을 수동으로 입력합니다.

### Cloudflare에 도메인 추가

제품정보**Cloudflare에 도메인 추가**Cloudflare에 도메인을 연결하는 새로운 페이지로 이동합니다. 기존 도메인에 입력되면, 선택**계속하기**.

### 도메인을 수동으로 입력

에 의해**이메일 보안 설정**이름:

1. **연결 영역**: 적어도 하나의 도메인을 선택하십시오. 다음, 선택**계속하기**.
2. (**옵션 정보**) **수동 도메인 추가**: 수동으로 추가 도메인을 입력합니다. 다음, 선택**계속하기**.
3. (**옵션 정보**) **조정 hop 조사**: 번호 입력<GlossaryTooltip term="Hops">뚱 베어</GlossaryTooltip>, 다음 선택**계속하기**.
4. **제3자 이메일 공급자와 서비스 주소를 구성**: BCC/Journaling을 허용하는 제3자 이메일 공급자로 서비스 주소를 복사하고 붙여넣기:`<account tag>@CF-emailsecurity.com`.
5. **자주 묻는 질문**: 연결된 도메인을 검토하십시오. 다음, 선택**본문 바로가기**

## 자동 이동 가능

auto-move 이벤트를 활성화하려면 통합을 연결해야합니다.

통합을 연결하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/) > **이메일 보안**.
2. 오시는 길**계정 설정** > **도메인 관리** > **이름 \***> 선&#xD0DD;**- 연혁**.
3. 에 의해**도메인 관리**페이지, 도메인을 찾습니다, 세 가지 점을 선택, 다음 선택**통합 관리**.
4. 제품정보**통합 연결**. 단계에 따라[Microsoft 365 통합 활성화](/cloudflare-one/email-security/setup/post-delivery-deployment/api/m365-api/#enable-microsoft-integration).
5. 세 가지 점을 선택, 다음 선택**통합 관리**. 통합을 선택, 다음 선택**이름 \***.

이제 도메인에는 관련 통합이 있습니다.[자동 모드 이벤트](/cloudflare-one/email-security/settings/auto-moves/)당신의 도메인에.

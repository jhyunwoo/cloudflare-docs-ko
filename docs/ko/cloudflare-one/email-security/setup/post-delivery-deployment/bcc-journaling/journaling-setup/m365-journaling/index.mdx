Microsoft 365 저널링은 모든 들어오고 나가는 이메일의 사본을 보장하는 포스트 배달 설정 방법은 분석을위한 Cloudflare에 전달됩니다. 당신이 만들 때[학술지](https://learn.microsoft.com/en-us/exchange/security-and-compliance/journaling/journaling#journal-rules)Microsoft Purview 준수 포털에서 Cloudflare는 이미 inbox에 착륙 한 메시지를 스캔 할 수 있습니다.

다음 다이어그램은 어떻게 작동합니까?

![이메일 보안을 사용하여 Microsoft 365를 설정할 때 이메일 흐름.](~/assets/email-security/M365Deployment_Journaling.png)

Microsoft 365 저널링 배포를 활성화하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/) > **이메일 보안**.
2. 제품정보**제품정보**. 이메일 보안을 구입하지 않은 경우, 선택**연락처**. 그렇지 않으면, 선택**설치하기** > **BCC/제주**.
3. 제품정보**MS와 통합** > **이름 \***.
4. 계속하기[Microsoft 365와 통합](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/journaling-setup/m365-journaling/#1-integrate-with-microsoft-365)Microsoft 통합을 연결합니다.

## 1. Microsoft 365와 통합

Microsoft 365와 통합하려면:

1. **이름 통합**: 통합 이름 추가, 다음 선택**계속하기**.
2. **통합 관리**:
   - 제품정보**이름 \***. 선택**이름 \***&#xB108;에게**Microsoft 로그인**이메일 주소를 입력해야 할 페이지.
   - 이메일 주소를 입력하면 선택**이름 \***.
   - 선택 후**이름 \***, 대시보드는 요청한 권한을 가진 대화 상자가 표시됩니다. 제품정보**이메일 보안을 승인**. 권한이 부여되면 세부 정보를 검토하고 통합을 등록 할 수있는 페이지에 리디렉션됩니다.
3. **자주 묻는 질문**: 통합 세부 사항을 검토 한 다음 :
   - 제품정보**완전한 이메일 보안 설정**도메인을 연결하고 자동 이동을 구성할 수 있습니다.
   - 제품정보**이메일 보안을 계속**.

계속하기[도메인 연결](#connect-your-domains)다음 단계.

### 도메인 연결

에 의해**이메일 보안 설정**이름:

1. **연결 영역**: 적어도 하나의 도메인을 선택하십시오. 다음, 선택**계속하기**.
2. (**옵션 정보**) **수동 도메인 추가**: 선택**도메인 이름**수동으로 추가 도메인을 입력합니다. 다음, 선택**계속하기**.
3. (**옵션 정보**) **조정 hop 조사**: 번호 입력<GlossaryTooltip term="Hops">뚱 베어</GlossaryTooltip>. 그때, 선택**계속하기**.
4. (**옵션 정보**, 선택**현재 위치**이 단계를 건너뛰기)**메시지 이동**: 참고[자동 이동](/cloudflare-one/email-security/settings/auto-moves/)auto-moves를 구성합니다. 다음, 선택**계속하기**.
5. **자주 묻는 질문**: Cloudflare를 원하는 위치를 설정하여 이메일을 처리하십시오.**주요사업**기본 옵션이 될 것입니다. 당신이 선택하는 경우에**주요사업**, `<account tag>@CF-emailsecurity.com`귀하의 지역 서비스 주소가 될 것입니다. 처리 위치를 선택하면, 선택**계속하기**.
6. **자주 묻는 질문**: 연결된 도메인 및 서비스 주소를 검토하십시오. 다음, 선택**본문 바로가기**

도메인은 이제 성공적으로 추가되었습니다.

연결된 도메인을 보시려면:

1. 오시는 길**계정 설정**.
2. 도메인을 찾습니다, 세 가지 점을 선택 >**사이트 맵**. 선택**사이트 맵**도메인에 대한 정보를 표시합니다.

## 2. 학술지 규칙 구성

1. 로그인하기[Microsoft Purview 준수 포털](https://compliance.microsoft.com/homepage).

2. 사이드바에서 이동**계정 설정**(장치 아이콘) >**Data Lifecycle 관리** > **거래소 (legacy)**.

3. 내 계정**undeliverable 저널 보고서 보내기**유효한 사용자 계정의 이메일 주소를 입력하십시오. 팀이나 그룹 주소를 사용할 수 없습니다. 제품정보**제품 정보**이메일 주소를 입력하시면 됩니다.

4. 사이드바에서 이동**회사 소개** > **Data Lifecycle 관리** > **거래소 (legacy)**.

5. 제품정보**저널 규칙**.

6. 제품정보**새로운 규칙**저널링 규칙을 구성하고 다음과 같이 구성하십시오.
   - **학술지 보고서**: 이것은 당신이 복사 한 주소이며 5 단계로 지난[도메인 연결](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/journaling-setup/m365-journaling/#connect-your-domains).
   - **학회소개**: `Journal Messages to Email security`
   - **저널 메시지 전송 또는 수신**: *한국어*
   - **본문 바로가기**: *외부 메시지만*

7. 제품정보**이름 \***.

8. 정보를 정확하고, 선택**제출하기** > **이름 \***.

저장되면, 규칙은 자동으로 활성화됩니다. 그러나, 그것은 propagate에 설정에 대한 몇 분 걸릴 수 있으며 이메일 보안에 메시지를 밀어. 전파 후, 당신은 할 수 있습니다[당신의 inbox를 감시하십시오](/cloudflare-one/email-security/monitoring/)Cloudflare 대시보드에서 처리되는 메시지 수를 검사합니다. 이 번호는 Exchange 서버에서 이메일 보안으로 전송됩니다.

도메인이 성공적으로 추가되었는지 확인하려면 이메일이 스캔됩니다.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 선택**이메일 보안**.
2. 오시는 길**계정 설정** > **도메인 관리** > **이름 \***, 다음 선&#xD0DD;**- 연혁**.
3. 이름 \***귀하의 도메인**, 도메인을 찾습니다, 그리고 확인**주요연혁**설정**지원하다**·**구성 방법**뚱 베어**BCC/제주**.

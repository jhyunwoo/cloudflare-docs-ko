## 대시보드를 통해 이메일 보안 활성화

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/)선택하기**이메일 보안**..
2. 제품정보**제품정보**. 사용 사례에 따라 다음 옵션 중 하나를 선택하십시오.

- 이메일 보안을 구입하지 않은 경우, 선택**연락처**.
- 어떤 통합이 없는 경우:
  - 제품정보**설치하기**.
  - 제품 정보**MS 그래프 API** > **이름 \***.
  - 더 알아보기[Microsoft 통합 활성화](#enable-microsoft-integration)Onboarding 프로세스를 계속합니다.
- 통합이 있는 경우, 도메인을 연결하지 않았습니다:
  - 제품정보**도메인 연결**.
  - 제품 정보**MS 그래프 API**. 참고[도메인 연결](#connect-your-domains)도메인을 연결하기 위해(s).

### Microsoft 통합 활성화

Microsoft 통합을 활성화하려면:

1. **정책 설정**: 방법 선택[캐스 번호:](/cloudflare-one/integrations/cloud-and-saas/)데이터와 상호 작용합니다. 제품정보**읽기 전용 모드**또는**Read-Write 모드**. 당신이 선택하는 것이 좋습니다**Read-Write 모드**.
2. **이름 통합**: 통합 이름 추가, 다음 선택**계속하기**.
3. **통합 관리**:
   - 제품정보**이름 \***. 선택**이름 \***&#xC774;메일 주소를 입력해야 할 페이지의 Microsoft Sign에 가져갈 것입니다.
   - 이메일 주소를 입력하면 선택**이름 \***.
   - 선택 후**이름 \***, 시스템은 요청된 권한 목록을 가진 대화 상자를 표시합니다. 제품정보**이름 \***&#xC774;메일 보안을 인증합니다. 저자화시, 세부 사항 및 등록 통합을 검토 할 수있는 페이지에 리디렉션됩니다.
4. **자주 묻는 질문**: 통합 세부 사항을 검토 한 다음 :
   - 제품정보**완전한 이메일 보안 설정**도메인을 연결하고 자동 이동을 구성할 수 있습니다.
   - 제품정보**이메일 보안을 계속**.

계속하기[도메인 연결](#connect-your-domains)다음 단계.

### 도메인 연결

에 의해**이메일 보안 설정**페이지, Microsoft 도메인을 연결할 수 있습니다. 도메인을 연결하려면:

1. **연결 영역**: 적어도 하나의 도메인을 선택하십시오. 다음, 선택**계속하기**.
2. (선택)**기본 스캔**: 이메일 보안을 스캔할 수 있는 폴더를 구성할 수 있습니다.
3. (선택 사항 - 선택**현재 위치**이 단계를 건너뛰기)**Redirect 메시지**: 참고[자동 이동](/cloudflare-one/email-security/settings/auto-moves/)Auto-moves가 무엇인지, 어떻게 Auto-moves를 구성하는 방법.
4. **자주 묻는 질문**: 연결된 도메인을 검토 한 다음 선택**도메인 바로가기**.

귀하의 도메인은 이제 성공적으로 연결됩니다.

### 새 도메인 연결

새 도메인을 연결하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 선택**이메일 보안**.
2. 제품정보**계정 설정** > **도메인 관리** > **이름 \***, 다음 선&#xD0DD;**- 연혁**.
3. 제품정보**도메인 추가**.
4. 메일 환경을 이메일 보안에 연결하기위한 방법을 선택하십시오.
   - 자주 묻는 질문**MS 그래프 API**, 참조[Microsoft 통합 활성화](/cloudflare-one/email-security/setup/post-delivery-deployment/api/m365-api/#enable-microsoft-integration).
   - BCC/Journaling을 선택하면 도메인을 연결하는 방법을 선택하십시오.
     - 자주 묻는 질문**MS와 통합**, 참조[Microsoft 통합 활성화](/cloudflare-one/email-security/setup/post-delivery-deployment/api/m365-api/#enable-microsoft-integration).
     - 자주 묻는 질문**Google과의 통합**, 참조[도메인 연결](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/connect-domains/).
     - 자주 묻는 질문**수동 추가**, 참조[도메인을 수동으로 입력](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/journaling-setup/manual-add/#enter-domain-manually).

## 도메인 스캔에서 Cloudflare 방지

도메인 스캔에서 Cloudflare를 방지하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 선택**이메일 보안**.
2. 오시는 길**계정 설정** > **도메인 관리** > **이름 \***, 다음 선&#xD0DD;**- 연혁**.
3. 에 의해**도메인 관리**페이지, 스캔 할 도메인을 선택.
4. 3 점 선택 >**관련 상품**.

## 통합 보기

각 연결된 도메인에 대한 통합을 보려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 선택**이메일 보안**.
2. 오시는 길**계정 설정** > **도메인 관리** > **이름 \***, 다음 선&#xD0DD;**- 연혁**.
3. 도메인 선택
4. 3 점 선택 >**통합 보기**.

이메일 보안을 설정하면 inbox를 통해 스캔 할 수 있습니다. 이메일 보안은 inbox에 대한 자세한 정보를 표시 할 것입니다. 더 알아보기[inbox를 감시하십시오](/cloudflare-one/email-security/monitoring/)더 알아보기.

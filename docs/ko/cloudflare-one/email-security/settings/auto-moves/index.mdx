Auto-move 이벤트는 이메일이 자동으로 다른 inboxes로 이동되는 이벤트입니다.

이메일 보안은 자동 이동 및 소스 폴더의 총 수를 보여줍니다. 이 이동이 시작되는지.

auto-move 이벤트를 구성하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**계정 설정**.
4. 제품정보**지원하다**.
5. 이름 \***자동 이동**, 선택**설정하기**.
6. 악의, spoof, 의심스러운, 스팸 및 대량 분해에 근거를 둔 할당 작업. 중 선택:
   - **Soft delete - 사용자 복구 가능**: 사용자의 메시지 이동**복구 항목 - 삭제**폴더. 메시지는 사용자가 복구 할 수 있습니다.
   - **하드 삭제 - 관리자 복구**: user's inbox에서 메시지를 완전히 삭제합니다.
   - **trash로 이동**: trash 또는 삭제 된 항목 이메일 폴더로 메시지를 이동합니다.
   - **이동 junk**: junk 또는 스팸 폴더에 메시지를 이동합니다.
   - **활동 없음**: 메시지는 원본 폴더에 있습니다.
7. 제품정보**제품 정보**.

사용자 및 팀 제출의 대상 주소를 보려면 :

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**계정 설정**.
4. 오시는 길**Phish 제출** > **제출 주소** > **- 연혁**.

대시보드 디스플레이**사용자 제출 주소**·**팀 제출 주소**.

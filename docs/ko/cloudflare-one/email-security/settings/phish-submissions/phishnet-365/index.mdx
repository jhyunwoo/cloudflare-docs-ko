PhishNet은 이메일 보안에 직접 제출하는 데 도움이되는 추가 버튼입니다.<GlossaryTooltip term="phishing">뚱 베어</GlossaryTooltip>이메일 보안의 탐지에 의해 놓인 표본.

PhishNet Microsoft 365를 설정하려면:

1. 사용자 정의 된 URL을 가져옵니다[사이트맵 한국어](https://one.dash.cloudflare.com/?to=/:account/email-security/settings/email-policy/phish-submission?tab=phish-submission).
2. 로그인하기[Microsoft 관리자 패널](https://admin.microsoft.com/).
3. 오시는 길**Microsoft 365 관리자 센터** > **계정 설정** > **통합 앱**.
4. 제품정보**사용자 정의 앱**.
5. 제품 정보**파일 형식**Cloudflare One 대시보드에서 복사한 URL을 붙여넣으십시오.
6. 검증하고 마법사를 완료합니다.

귀하의 지속적인 이메일 보안 자세, 관리자 및 보안 분석가의 일부가 놓칠 필요<GlossaryTooltip term="phishing">피싱</GlossaryTooltip>이메일 보안에 표본, 그래서 Cloudflare는 그(것)들을 가공하고 필요한 활동을 가지고 갈 수 있습니다.

Cloudflare에 놓인 피시 샘플을 제출하는 것은 지속적인 보호에 필요한 기하학적 중요성입니다. 놓인 phish 샘플을 제출하면 Cloudflare는 기계 학습 (ML) 모델을 개선하고 새로운 공격 벡터를 전과되기 전에 경고합니다.

당신이 phish로 이메일을보고 할 수있는 세 가지 경로가 있습니다 :

- 투자를 통해[이메일 reclassifying](/cloudflare-one/email-security/settings/phish-submissions/#reclassify-an-email).
- 이름 \*[피쉬 넷 365](/cloudflare-one/email-security/settings/phish-submissions/phishnet-365/).
- 이름 \*[제출 주소](/cloudflare-one/email-security/settings/phish-submissions/submission-addresses/).

## 자주 묻는 질문

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안** > **투자정보**.
3. 에 의해**투자정보**페이지, 아래**일치하는 메시지**, reclassify하려는 메시지를 선택하십시오. 세 가지 점을 선택, 다음 선택**자주 묻는 질문**. 선택하여**자주 묻는 질문**, 당신은 메시지에 대한 새로운 처분을 요청하고 있습니다.
4. 새로운 분리를 선택, 다음 선택**제품 정보**.

당신이 phish로 이메일을보고 할 때, 이 이메일은 아래에 표시됩니다[사용자 제출](/cloudflare-one/email-security/submissions/user-submissions/).

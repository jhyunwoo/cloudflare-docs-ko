이메일 보안은 전형적인 탐지 스캐닝에서 알려진 파트너 및 내부 도메인을 면제 할 수 있습니다. 신뢰할 수 있는 도메인을 추가하는 것은 악의적, 의심스러운, 그리고 spoof에 거짓 긍정을 줄일 수 있습니다[관련 기사](/cloudflare-one/email-security/reference/dispositions-and-attributes/). 이메일 보안은 도메인이 생성될 때만 날짜를 확인합니다.

## 신뢰할 수있는 도메인 작업

신뢰할 수있는 도메인은 이메일 메시지 자체가 아니라 전체 도메인에 대한 것입니다.

기본적으로, 이메일 보안은 자동으로 lookalike 도메인을 감지합니다. Lookalike 도메인은 다음과 같이 할 수 있습니다.`thisisdomain.com`·`thisisadomain.com`. 두 도메인은 거의 동일합니다.

도메인에서 전자 메일을 수신하면 구성 된 도메인처럼 보이는 도메인에서이 감지를 유발합니다. 신뢰할 수있는 도메인은이 감지를 무시하도록 구성됩니다.

내 계정[추가 감지](/cloudflare-one/email-security/settings/detection-settings/additional-detections/), 당신은 악의적인 도메인과 의심스러운 구성할 수 있습니다[도메인 연령](/cloudflare-one/email-security/settings/detection-settings/additional-detections/#configure-domain-age).

악성 도메인 연령은 누군가가 오늘 도메인을 만들 수 있다는 것을 의미, 대상과 유사, 그리고 그 도메인과 이메일을 전송 시작. 이것은 일반적으로 많은 phish 캠페인 시작. 이 경우 도메인은 일반적으로 맛있는 것으로 표시됩니다. 맛있는 도메인 연령은 보통 7 일로 설정됩니다.

의심스러운 도메인 나이는 7 일 후에 그 의미 (이 번호는 악성 도메인 연령에 해당), 도메인은 악의적이지 않을 수 있지만 여전히 의심스러운 수 있습니다. 이메일 보안은 의심스러운대로이 도메인을 표시 할 것입니다. 구성하는 것이 좋습니다.**Suspicious 도메인 연령**30 \~ 45 일 사이.

도메인이 악의적 또는 의심인지 여부를 볼 수 있습니다:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**투자정보**.
2. 화면을 실행합니다. 예를 들어, 선택**Run 스크린**제품 정보**Malicious 이메일**, 다음 선택**Run 스크린**.
3. 이름 \***일치하는 메시지**, 어떤 메시지 표시**도메인 연령**이름 \***위협 유형**, 즉, 도메인 연령이 너무 낮다는 것을 의미, 따라서 할당 된 분해는 맛있는. 도메인이 합법적 인 경우 신뢰할 수있는 도메인으로 추가 할 수 있습니다.
   - 오시는 길**계정 설정** > **신뢰할 수 있는 도메인**.
   - 이름 \***도메인 정보**, 도메인 추가, 선택**새로운 도메인**. 이것은 신뢰할 수있는 도메인만큼 낮은 도메인을 표시 할 것입니다.

## 신뢰할 수 있는 도메인 구성

신뢰할 수있는 도메인을 구성하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**계정 설정**, 이동**감지 설정** > **신뢰할 수 있는 도메인**.
4. 에 의해**감지 설정**페이지, 선택**도메인 추가**.
5. 선택하기**입력 방법**: 선택**수동 입력**·**신뢰할 수있는 도메인 목록**:
   - **수동 입력**:
     - **도메인 정보**: 유효한 도메인 이름을 입력하십시오.
     - **도메인 유형**: 선택 하나 또는 두 옵션:
       - **Proximity 도메인**: 기존 도메인에 유사한 맞춤법과 도메인.
       - **최근 도메인**: 최근 생성된 도메인.
     * **지원하다**: 신뢰할 수있는 도메인 목록에 대한 추가 정보를 제공합니다.
   - **신뢰할 수있는 도메인 목록**: 여러 신뢰할 수있는 도메인의 150KB 미만의 파일을 업로드 할 수 있습니다. 파일은 포함 할 수 있습니다`Domain`, `Proximity`, `New`·`Notes`사이트 맵 첫 번째 행은 헤더 행이어야 합니다. 더 알아보기[CSV 업로드](/cloudflare-one/email-security/settings/detection-settings/trusted-domains/#csv-uploads)예를 들어 파일.
6. 제품정보**제품 정보**.

### CSV 업로드

여러 신뢰할 수있는 도메인의 150KB 미만의 파일을 업로드 할 수 있습니다. 파일은 포함 할 수 있습니다`Domain`, `Proximity`, `New`·`Notes`사이트 맵 첫 번째 행은 헤더 행이어야 합니다.

예 파일은 다음과 같습니다.

```txt
Domain, Proximity, New, Notes
mydomain.com, true, true, First Person
testdomain.com, false, true, New Hire
```

## 수출 신뢰할 수있는 도메인

모든 신뢰할 수있는 도메인을 수출하려면 :

1. 에 의해**감지 설정**페이지, 선택**이름 \***. 선택**이름 \***&#xBAA8;든 신뢰할 수있는 도메인을 선택합니다.
2. 제품정보**CSV로 내보내기**.

특정 신뢰할 수있는 도메인을 수출하려면 :

1. 에 의해**감지 설정**페이지, 수출하려는 신뢰할 수있는 도메인을 선택하십시오.
2. 제품정보**CSV로 내보내기**.

## 신뢰할 수 있는 도메인

신뢰할 수있는 도메인을 편집하려면 :

1. 에 의해**감지 설정**페이지, 편집하려는 신뢰할 수있는 도메인을 선택합니다.
2. 3 점 선택 > 편집.
3. 신뢰할 수있는 도메인을 편집합니다.
4. 제품정보**제품 정보**.

## 신뢰할 수있는 도메인 삭제

신뢰할 수 있는 도메인을 삭제하려면:

1. 에 의해**감지 설정**페이지, 삭제하려는 신뢰할 수있는 도메인을 선택하십시오.
2. 3 점 선택 >**이름 \***.
3. 팝업 메시지에서, 선택**이름 \***.

여러 신뢰할 수 있는 도메인을 한 번에 삭제하려면:

1. 에 의해**감지 설정**페이지, 삭제하려는 신뢰할 수있는 도메인을 선택합니다.
2. 제품정&#xBCF4;**- 연혁**.
3. 제품정보**이름 \***.

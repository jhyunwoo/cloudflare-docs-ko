이메일 보안은 악의적 인이 senders에서 모든 메시지를 표시합니다.[관련 제품](/cloudflare-one/email-security/reference/dispositions-and-attributes/).

## 차단된 senders 일

Blocked senders는 모든 sender에서 메시지가 자동으로 악의적으로 표시되어 사용자의 inbox에 도달하는 것을 방지합니다.

때때로, 동일한 이메일, IP 주소 또는 도메인은 항상 회사에 악의적인 이메일을 보냅니다. 이 경우, 당신은 이메일 주소를 추가 할 수 있습니다, IP 주소 또는 도메인은 차단 된 sender로. 설정하여 정규식을 입력할 수 있습니다.**일반 표현**이름 \*

## 차단된 senders를 형성하십시오

차단된 senders를 구성하기 위하여:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**계정 설정**, 이동**감지 설정** > **차단된 senders**.
4. 에 의해**감지 설정**페이지, 선택**sender 추가**.
5. 선택하기**입력 방법**: 선택**수동 입력**·**blocked sender 목록 업로드**:
   - **수동 입력**:
     - **Sender 유형**:
       - **이메일 주소**: 유효한 이메일이어야 합니다.
       - **IP 주소**: IPv4만 가능합니다. IPv6 및 CIDR는 유효하지 않은 항목입니다.
       - **이름 \***: 유효한 도메인이어야 합니다.
       - **일반 표현**: Java 표현을 유효해야 합니다. 정규 표현식은 sender 이메일 주소와 관련된 필드와 일치합니다 (, 에서 헤더, 회신), 시작 IP 주소 및 이메일의 서버 이름. 예를 들어 입력할 수 있습니다.`.*@domain\.com`자주 묻는 질문`domain.com`.
     - **지원하다**: blocked sender 정책에 대한 추가 정보를 제공합니다.
   - **blocked sender 목록 업로드**: 150KB 이상 파일 업로드 파일은 포함 할 수 없습니다`Blocked_Sender`, `Pattern Type,`·`Notes`사이트 맵 첫 번째 행은 헤더 행이어야 합니다. 더 알아보기[CSV 업로드](/cloudflare-one/email-security/settings/detection-settings/blocked-senders/#csv-uploads)예를 들어 파일.
6. 제품정보**제품 정보**.

### CSV 업로드

150KB 이상의 파일을 업로드 할 수 있습니다. 파일은 포함 할 수 없습니다`Blocked_Sender`, `Pattern Type,`·`Notes`사이트 맵 첫 번째 행은 헤더 행이어야 합니다.

예 파일은 다음과 같습니다.

```txt
Blocked Sender, Pattern Type, Notes
john.smith@gmail.com, EMAIL, John Smith
example.com, DOMAIN, Melanie Turner
```

## 수출 차단된 senders

모든 차단된 senders를 수출하기 위하여:

1. 에 의해**감지 설정**페이지, 선택**회사 소개**. 선택**회사 소개**모든 차단된 senders를 선정할 것입니다.
2. 제품정보**CSV로 내보내기**.

특정한 차단된 senders를 수출하기 위하여:

1. 에 의해**감지 설정**페이지, 선택**가치 (s)**. 당신이 수출하고 싶은 blocked senders를 선택하십시오.
2. 제품정보**CSV로 내보내기**.

## 차단된 sender 편집

차단된 sender를 편집하기 위하여:

1. 에 의해**감지 설정**페이지, 편집하고 싶은 Blocked sender를 선택합니다.
2. 3 점 선택 >**제품정보**.
3. 차단된 sender를 편집합니다.
4. 제품정보**제품 정보**.

## 차단된 sender 삭제

차단된 sender를 삭제하려면:

1. 에 의해**감지 설정**페이지를 선택하여 삭제하고 싶은 블록 전송기를 선택하십시오.
2. 3 점 선택 >**이름 \***.
3. 팝업 메시지에서, 선택**이름 \***.

한 번에 여러 블록 전송기를 삭제하려면:

1. 에 의해**감지 설정**페이지, 아래**차단된 senders**, 삭제하려는 senders를 선택합니다.
2. 제품정&#xBCF4;**- 연혁**
3. 제품정보**이름 \***.

이메일 보안 핸들 링크를 구성할 수 있습니다.

:::참조
이메일 보안을 배포하면 링크 작업을 구성할 수 있습니다.[MX / 인라인](/cloudflare-one/email-security/setup/pre-delivery-deployment/mx-inline-deployment/).
:::

링크 작업을 구성하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**계정 설정**, 다음 이동**감지 설정** > **링크 작업** > **- 연혁**.

구성할 수 있습니다.**링크 작업 설정**, 또는**URL rewrite 무시 패턴**.

## 링크 작업 설정

링크 작업을 구성하려면, 선택**설정하기**.

대시보드 디스플레이**원격 브라우저에서 의심스러운 것으로 평가 된 링크 (추천)**. 이 옵션은 기본적으로 켜집니다. 이메일 보안은 또한 원격 브라우저에서 처분 된 이메일에 대한 모든 링크를 열 수있는 메시지를 선택 할 수 있습니다.

하나 이상의 분해를 선택, 다음 선택**제품 정보**.

이름 \***원격 브라우저에서 의심스러운 것으로 평가 된 링크 (추천)**&#xAEBC;짐, 당신은 선택할 수 있습니다**URL 플랜지**또는**활동 없음**각 처분에. 제품정보**제품 정보**한 번 구성을 완료했습니다.

링크 열 때, 이메일 보안은 당신을 허용하지 않습니다 :

- [Paste (고객에서 원격으로)](/cloudflare-one/remote-browser-isolation/isolation-policies/)

## URL에 대한 패턴 추가

URL에 대한 패턴을 추가 할 수 있습니다.

1. 이름 \***URL rewrite 무시 패턴**, 선택**패턴 추가**.
2. 유효한 IP, URL, 또는 정규 표현식을 입력하십시오. 512자까지 입력할 수 있습니다.
3. 제품정보**제품 정보**.

패턴을 편집하려면, 편집하려는 패턴으로 이동, 세 가지 점을 선택, 다음**제품정보**. URL 파터를 수정한 후에는 선택**제품 정보**.

패턴을 삭제하려면 삭제하려는 패턴으로 이동, 세 가지 점을 선택, 다음**이름 \***.

impersonation 레지스트리는 식별 될 가능성이있는 사용자의 이메일의 조합을 포함합니다. 전자 메일 주소로 나열되지 않은 임의 레지스트리에있는 이메일이 있다면, 이메일은 잠재적으로보고됩니다[비즈니스 이메일 손상 (BEC)](https://www.cloudflare.com/en-gb/learning/email-security/business-email-compromise-bec/).

:::참조

impersonation 레지스트리를 포함해야 하는 사용자의 목록을 포함 해야 합니다. 이메일 보안은 추가 등록 이메일 주소 변경에 향상된 보안 적용[비즈니스 이메일 Compromise (BEC)](https://www.cloudflare.com/en-gb/learning/email-security/business-email-compromise-bec/)보호.

더 쉬운 추적을 위해, 이메일 보안 팀은 그룹에 있는 VIP를 동기화하고 파괴하고, 사용자의 수동 입력을 하는 것을 피합니다.
주요 특징

impersonation registry에 사용자를 추가하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**계정 설정** > **회원 등록**.
4. 제품정보**사용자 추가**.
5. 제품정보**입력 방법**: 선택**수동 입력**, **비밀번호**·**기존 이사에서 선택**:
   - **수동 입력**: 다음 정보를 입력하십시오:
     - **사용자 정보**: 유효한 입력**표시 이름**.
     - **사용자 이메일**: 다음 중 하나를 입력 :
       - **이메일 주소**: comma에 의해 분리되는 모든 알려진 이메일 주소를 입력하십시오.
       - **일반 표현**: Java 표현을 유효해야 합니다.
   - **비밀번호**: 잠재적 인 이메일의 모든 변수를 포함하는 150KB 이상의 파일을 업로드 할 수 있습니다. 파일은 포함해야`Display_Name`·`Email`, 그리고 첫번째 줄은 우두머리 줄이어야 합니다. 더 알아보기[CSV 업로드](/cloudflare-one/email-security/settings/detection-settings/impersonation-registry/#csv-uploads)예를 들어 파일.
   - **기존 이사에서 선택**:
     - **연락처**: 디렉토리를 선택합니다.
     - **사용자 또는 그룹 추가**: 등록하려는 사용자 또는 그룹을 선택하십시오.
6. 제품정보**제품 정보**.

### CSV 업로드

잠재적 인 이메일의 모든 변수를 포함하는 150 KB 이상의 파일을 업로드 할 수 있습니다. 파일은 포함해야`Display_Name`·`Email`, 그리고 첫번째 줄은 우두머리 줄이어야 합니다.

예 파일은 다음과 같습니다.

```txt
Display Name, Email
Star Phish, star@nophish.com
Phish Ee, phishee@nophish.com
```

## 사용자 정의

:::참조

Administrators는 이메일 보안 디렉토리에 속하는 사용자의 이름과 이메일을 편집 할 수 있습니다. 다른 통합 디렉터리의 관리자는 이름과 사용자의 기본 이메일을 편집 할 수 없습니다.

:::

이메일 보안 디렉토리에서 사용자를 편집하려면:

1. 편집하려는 사용자를 선택하십시오.
2. 3 점 선택 >**제품정보**.
3. 이름 \***표시 이름**, **이름 \***·**두 번째 이메일**.
4. 제품정보**제품 정보**.

다른 통합에서 사용자를 편집하려면:

1. 편집하려는 사용자를 선택하십시오.
2. 3 점 선택 >**제품정보**.
3. 이름 \***두 번째 이메일**.
4. 제품정보**제품 정보**.

## 사용자 정의

:::참조

Adiministrators는 이메일 보안 디렉토리에 속하는 사용자를 제거 할 수 있습니다.**회원 등록**. 통합 디렉토리에서 온 사용자는 제거 할 수 없습니다**회원 등록**직접.

통합 디렉토리에서 사용자를 제거하려면:

1. 제품정보**주요연혁**사이드바에.
2. 사용자가 할당되는 디렉토리를 선택합니다.
3. 선택하기**이름 \***&#xD0ED;.
4. 제거하려는 사용자에 대한 검색.
5. 3 점 선택 >**레지스트리에서 제거**.

:::

impersonation registry에서 사용자를 제거하려면:

1. 제거하려는 사용자를 선택하십시오.
2. 3 점 선택 >**레지스트리에서 제거**.
3. 팝업 메시지 읽기, 다음 선택**사용자 정의**.

임의 레지스트리에서 한 번에 여러 사용자를 제거하려면:

1. 제거하려는 모든 사용자를 선택하십시오.
2. 제품정&#xBCF4;**- 연혁** > **레지스트리에서 제거**.
3. 팝업 메시지 읽기, 다음 선택**사용자 정의**.

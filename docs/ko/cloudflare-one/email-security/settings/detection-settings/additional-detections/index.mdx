이메일 보안은 다음과 같은 추가 탐지를 구성할 수 있습니다.

- 도메인 연령
- 비밀번호
- [자동화된 Clearing House (ACH)](https://en.wikipedia.org/wiki/Automated_clearing_house)무료 이메일 탐지에서 변경
- HTML 이메일 첨부 파일

추가 감지를 구성하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**계정 설정**.
4. 에 의해**계정 설정**사이트 맵**감지 설정** > **추가 감지**, 그리고 선택**제품정보**.

## 도메인 연령 설정

도메인 연령은 도메인 등록 이후입니다.

도메인 연령 감지 때문에,[신뢰할 수 있는 도메인](/cloudflare-one/email-security/settings/detection-settings/trusted-domains/)연령 감지에 대한 예외를 만들 수 있습니다.

도메인 연령을 구성하려면:

1. 에 의해**추가 검출 편집**이름:
   - 제품정보**맛있는 도메인 연령**: 악의적 분리를 위한 임계값을 제어한다. 최대 100 일. 설정하는 것이 좋습니다.**맛있는 도메인 연령**7 일.
   - 제품정보**Suspicious 도메인 연령**: 의심스러운 분해에 대한 임계값을 제어합니다. 최대 100 일. 설정하는 것이 좋습니다.**Suspicious 도메인 연령**30 \~ 45 일 사이.
2. 제품정보**제품 정보**.

## 공백 이메일 탐지

빈 이메일 탐지는 빈 몸을 가진 이메일을 검출하고 기본 분해를 할당합니다. 선택할 수 있습니다.**인기있는**·**인기 있는**파기방법

빈 이메일 탐지를 가능하게 하기 위하여:

1. 에 의해**추가 검출 편집**페이지, 활성화**비밀번호**.
2. 선택하기**인기있는**·**인기 있는**.
3. 제품정보**제품 정보**.

## 무료 이메일 탐지에서 ACH 변경

[자동화된 Clearing House (ACH)](https://en.wikipedia.org/wiki/Automated_clearing_house)직접 입금과 관련된 은행 용어입니다. 무료 이메일 탐지에서 ACH 변경은 payroll 조회 또는 무료 이메일 도메인에서 요청을 변경하고 기본 분해를 할당합니다. 선택할 수 있습니다.**인기있는**·**인기 있는**파기방법

무료 이메일 탐지에서 ACH 변경을 활성화하려면:

1. 에 의해**추가 검출 편집**페이지, 활성화**무료 이메일 탐지에서 ACH 변경**.
2. 선택하기**인기있는**·**인기 있는**.
3. 제품정보**제품 정보**.

## HTML 첨부 파일 압축

HTML 이메일 첨부 파일 탐지는 이메일에 HTM 및 HTML 첨부 파일을 감지하고 기본 분해를 할당합니다.

HTML 첨부 파일 이메일 탐지를 활성화하려면:

1. 에 의해**추가 검출 편집**페이지, 활성화**HTML 이메일 첨부 파일**.
2. 선택하기**인기있는**·**인기 있는**.
3. 제품정보**제품 정보**.

특정 처분과 이메일을 위한 주제 또는 몸 접두사로 사용될 수 있는 주문 상표를 창조할 수 있습니다.

:::참조
이메일 보안을 배포하면 텍스트 애드온 만 구성할 수 있습니다.[MX / 인라인](/cloudflare-one/email-security/setup/pre-delivery-deployment/mx-inline-deployment/).
:::

:::카트로션
현재 텍스트 애드온이 활성화되지 않는 경우, 텍스트 애드온 구성은 주제 줄에 배너를 추가합니다. 결과적으로, 제목 줄과 이메일 몸이 감소됩니다.
주요 특징

## 제목 접두사

주제 접두사를 구성하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**계정 설정**, 다음 이동**감지 설정** > **텍스트 add-ons** > **- 연혁**.
4. 제품정보**설정하기** > **제목 접두사**.
5. 주제 접두사로 각 처분을 Populate하고, 켜기**주요연혁**특정 처분을 위한 주제 접두사를 가능하게 합니다.

### 고급 설정

내 계정**고급 설정**, 당신은 구성할 수 있습니&#xB2E4;**"labels" 변수 추가**. 이 옵션은 목록의 분해 및 추가 텍스트를 허용 라벨에 동적 값을 추가 할 수 있습니다.

계속하&#xAE30;**"labels" 변수 추가**:

1. 오시는 길**고급 설정** > **"labels" 변수 추가**.
2. 사이 선택:
   - **기본 설정**.
   - **사용자 정의 "labels"변환**: 텍스트 상자에 사용자 정의 라벨을 입력하십시오.

제목 접두사를 구성하면 선택**제품 정보**.

## 몸 prefix

몸 접두사는 특정 처분을 가진 이메일을 위한 이메일 몸의 정상에 추가된 주문 상표입니다.

몸 접두사로 각 분리를 포괄하고, 켜기**주요연혁**특정 처분에 대한 신체 접두사를 가능하게합니다.

### 고급 설정

고급 설정에서 구성할 수 있습니다.**"labels"또는 "threat type" 변수 추가**. 이 옵션은 할당 된 분해 뒤에 위협 유형을 나열하는 라벨에 대한 동적 값을 추가 할 수 있습니다.

계속하&#xAE30;**"labels"또는 "threat type" 변수 추가**:

1. 오시는 길**고급 설정**:
2. 사이 선택:
   - **"labels" 변수 추가**: 이 옵션은 목록의 분해 및 추가 텍스트를 허용 라벨에 대한 동적 값을 추가 할 수 있습니다. 사이 선택:
     - **기본 설정**.
     - **사용자 정의 "labels"변환**: 텍스트 상자에 사용자 정의 라벨을 입력하십시오.

몸 접두사를 구성하면 선택**제품 정보**.

### 위협 유형 변수 추가

이 옵션은 할당 된 분해 뒤에 위협 유형을 나열하는 '%THREATS'에 대한 동적 값을 포함 할 수 있습니다. HTML 형식의 텍스트를 추가 할 수 있습니다.

대시보드 디스플레이**기본 정보**또는**제품 정보**( "labels"또는 "threat type"변수)를 사용하여 구성하는 방법에 따라[고급 설정](/cloudflare-one/email-security/settings/detection-settings/configure-text-add-ons/#advanced-settings-1).

이메일 보안을 사용하면 3 가지 유형의 보고서를 다운로드 할 수 있습니다.

- Disposition 보고서
- Retro 검사 보고
- 보안 보고서

## disposition 보고서 다운로드

장애 보고서는 선택한 장애의 유형에 따라 모든 이메일 메시지를 보여줍니다.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 선택**이메일 보안**.
2. 제품정보**관련 기사** > **자주 묻는 질문**.
3. 내 계정**공지사항**, 선택**이메일 disposition 보고서**.
4. 이름 \***이메일 disposition 보고서**, 선택**날짜 범위**(필수), 그리고**관련 제품**.
5. 제품정보**CSV로 내보내기**.

더 알아보기[위치 및 속성](/cloudflare-one/email-security/reference/dispositions-and-attributes/)더 알아보기.

## retro scan 보고서 다운로드

Retro 검사는 당신의 이메일의 마지막 14 일을 검사하고, 당신에게 부피, 스팸, spoof, 의심하고 악의적인 이메일에 보고를 줍니다.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 선택**이메일 보안**.
2. 제품정보**관련 기사** > **자주 묻는 질문**.
3. 내 계정**공지사항**, 선택**Retro 검사 보고**.
4. 제품정보**공지사항**마지막 14 일의 이메일 보고서를 볼 수 있습니다.

더 알아보기[Retro 검사](/cloudflare-one/email-security/retro-scan/)더 알아보기.

## 보안 보고서 다운로드

보안 보고서는 이메일 트래픽의 개요를 제공합니다. 보고서는 마지막 30, 60, 90 일 또는 당신의 선택의 시간 프레임에 생성 될 수 있습니다.

보고서는 다음과 같습니다 :

- 임원 요약 : 지난 30 일 동안 조직의 이메일 트래픽에서 감지 된 위협 요약.
- Threat detection: 장애, 정책 탐지 및 임의 시도에 관한 통계 검토.
- 제출 : 보안 팀 또는 사용자의 이메일 메트릭을 검토하고 재 분류하도록 요청했습니다.

보안 보고서 다운로드:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 선택**이메일 보안**.
2. 제품정보**관련 기사** > **자주 묻는 질문**.
3. 내 계정**공지사항**, 선택**보안 보고서**그리고**날짜 범위**.
4. 제품정보**Generate 보고서**.
5. 보안 보고서가 생성됩니다. 한 번 첨부 된 보안 보고서와 함께 이메일을 받게됩니다.

이메일 보안은 주어진 이메일 메시지, 도메인, URL, 또는 패킷이 일부인지 결정하는 다양한 요인을 사용합니다.<GlossaryTooltip term="phishing">피싱</GlossaryTooltip>공지사항 이 작은 패턴 평가는 자연에서 동적이며 — 많은 경우 — 단일 패턴은 최종 verdict를 결정하지 않습니다.

:::노트\[Detection vs. 분해]
Detection은 이메일 보안을 식별하는 프로세스입니다. 이메일은 여러 탐지를 가질 수 있지만, 그들은 하나의 최종 분해가있을 것입니다. 전자 메일을 감지하면 이메일의 처분을 결정합니다.
주요 특징

## 회사연혁

이메일 보안을 통해 흐르는 모든 트래픽은 특정 메시지의 우리의 평가를 나타내는 최종 처분을받습니다. 각 메시지는 1개의 처분 우두머리만 받을 것입니다, 그래서 당신의 조직은 다른 메시지 유형에 명확하고 특정한 활동을 가지고 갈 수 있습니다.

disposition 값을 사용할 수 있습니다.[Auto-moves 설정](/cloudflare-one/email-security/settings/auto-moves/).

### Header 구조

이메일 보안이 이메일 메시지에 disposition 헤더를 추가하면 헤더가 다음 형식과 일치합니다.

```txt
X-CFEmailSecurity-Disposition: [Value]
```

이메일 주소`SPAM`태그가 될 것입니다`UCE`(Unsolicited commercial email) 그들의 헤더에:

```txt
X-CFEmailSecurity-Disposition: UCE
```

## 관련 기사

이메일 보안을 통해 흐르는 트래픽은 특정 조건이 충족 된 것을 나타내는 하나 이상의 속성을받을 수 있습니다.

### 사용 가능한 값

| 사이트 맵                                   | 지원하다                                                                                                                                                      |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CUSTOM_BLOCK_LIST`                     | 이 메시지는 사용자 정의 블록 목록에 정의 된 값을 일치합니다.                                                                                                                       |
| `NEW_DOMAIN_SENDER=<REGISTRATION_DATE>` | 새로 등록 된 도메인에서 메일에 알림. yyyyy-MM-dd HH로 포맷: mm:ss ZZZ.                                                                                                      |
| `NEW_DOMAIN_LINK=<REGISTRATION_DATE>`   | 새로 등록 된 도메인에 지적 링크와 메일에 경고. yyyyy-MM-dd HH로 포맷: mm:ss ZZZ.                                                                                                |
| `ENCRYPTED`                             | 이메일 메시지가 암호화됩니다.                                                                                                                                          |
| `EXECUTABLE`                            | 이메일 메시지는 executable 파일이 포함되어 있습니다.                                                                                                                        |
| `BEC`                                   | 이메일 주소가 포함 된 표시[impersonation 등록](/cloudflare-one/email-security/settings/detection-settings/impersonation-registry/)이름 \* 관련 기사`MALICIOUS`또는`SPOOF`관련 기사 |

### Header 구조

이메일 보안이 이메일 메시지에 disposition 헤더를 추가하면 헤더가 다음 형식과 일치합니다.

```txt
X-CFEmailSecurity-Attribute: [Value]
X-CFEmailSecurity-Attribute: [Value2]
```

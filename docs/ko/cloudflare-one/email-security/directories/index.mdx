Directories는 사용자 데이터를 저장하는 폴더입니다. 이메일 보안은 Cloudflare 대시보드의 감독을 관리 할 수 있습니다.

디렉토리를 추가하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/) > **이메일 보안**.
2. 제품정보**주요연혁**.
3. 제품정보**디렉토리 추가** > **통합 연결**.
4. 자주 묻는 질문**Google 워크스페이스 CASB + 이메일**또는**마이크로소프트 CASB+EMAIL**.
5. 더 알아보기[Gmail BCC 통합 활성화](/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/enable-gmail-integration/#enable-gmail-bcc-integration)Google Workspace를 선택하는 경우. 더 알아보기[Microsoft 통합 활성화](/cloudflare-one/email-security/setup/post-delivery-deployment/api/m365-api/#enable-microsoft-integration)Microsoft 365를 선택하는 경우.

디렉토리 동기화:

1. 동기화하려는 디렉토리를 찾습니다.
2. 세 가지 점을 선택, 다음 선택**지금 동기화**.

:::참조
더 보기**자동 동기화**옵션은 기본적으로 있습니다. 감독이 항상 동기화되도록 모든 시간에이 옵션을 유지하는 것이 좋습니다.

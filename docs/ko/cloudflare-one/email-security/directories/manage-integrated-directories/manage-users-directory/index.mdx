이메일 보안을 통해 보고 관리할 수 있습니다.[impersonation 등록](/cloudflare-one/email-security/settings/detection-settings/impersonation-registry/)사용자 디렉토리의 상태.

사용자 디렉토리 관리:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**이메일 보안** > **주요연혁**.
2. 디렉토리를 찾습니다, 세 가지 점을 선택 >**자주 묻는 질문**.
3. 제품정보**이름 \***.

## 사용자를 등록

레지스트리에 단일 사용자를 추가하려면:

1. 추가하려는 이름을 선택하십시오.
2. 3 점 선택 >**등록에 추가**.

한 번에 레지스트리에 여러 사용자를 추가하려면:

1. 레지스트리에 추가하려면 이름을 선택하십시오.
2. 선택하&#xAE30;**- 연혁**드롭다운 목록.
3. 제품정보**등록에 추가**.

## 레지스트리에서 사용자 제거

이메일 보안은 레지스트리에서 사용자를 제거 할 수 있습니다.

레지스트리에서 단일 사용자를 제거하려면:

1. 제거하려는 이름을 선택하십시오.
2. 3 점 선택 >**레지스트리에서 제거**.

한 번에 레지스트리에서 여러 사용자를 제거하려면:

1. 레지스트리에서 제거하려는 이름을 선택하십시오.
2. 선택하&#xAE30;**- 연혁**드롭다운 목록.
3. 제품정보**레지스트리에서 제거**.

## 사용자 편집

사용자를 편집하려면:

1. 이름 \***표시 이름**, 당신이 편집하고 싶은 사용자를 찾습니다.
2. 3 점 선택 >**제품정보**.
3. 사용자 편집, 다음 선택**제품 정보**.

## 사용자 필터

등록된 사용자의 목록을 필터링할 수 있습니다.

사용자가 추가될 때 등록됩니다.[impersonation 등록](/cloudflare-one/email-security/settings/detection-settings/impersonation-registry/). 사용자가 임의 레지스트리의 일부가 없을 때 등록되지 않습니다.

임의 레지스트리를 필터링하려면:

1. 제품정보**필터 보기** > **회원 등록**.
2. 다음 중 하나를 선택하십시오:
   - **모든 것**: 등록 및 등록 된 사용자를 볼 수 있습니다.
   - **회사연혁**: 등록된 사용자를 볼 수 있습니다.
   - **관련 상품**: 등록된 사용자를 볼 수 있습니다.
3. 제품정보**필터 적용**.

필터 사용자:

1. 제품정보**필터 보기** > **이름 \***.
2. 다음 중 하나를 선택하십시오:
   - **모든 것**: 그룹에 있는 사용자를 보고 그룹에 없습니다.
   - **그룹 사용자**: 그룹에서 사용자를 볼 수 있습니다.
   - **사용자 그룹에**: 그룹이 아닌 사용자를 볼 수 있습니다.
3. 제품정보**필터 적용**.

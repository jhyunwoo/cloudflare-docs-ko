통합 디렉토리를 관리하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**주요연혁**.
4. 이름 \***전화번호**, 디렉토리를 선택합니다.
5. 관리할 수 있는 페이지로 리디렉션됩니다.[회사 소개](/cloudflare-one/email-security/directories/manage-integrated-directories/manage-groups-directory/)또는[이름 \*](/cloudflare-one/email-security/directories/manage-integrated-directories/manage-users-directory/)감독.

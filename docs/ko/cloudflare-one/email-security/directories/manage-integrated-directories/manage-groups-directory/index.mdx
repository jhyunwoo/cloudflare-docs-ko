이메일 보안을 통해 그룹 디렉토리와 관리할 수 있습니다.[impersonation 등록](/cloudflare-one/email-security/settings/detection-settings/impersonation-registry/). 그룹이 레지스트리에 추가되면, 모든 회원은 기본적으로 등록됩니다.

그룹 디렉토리를 관리하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**이메일 보안** > **주요연혁**.
2. 디렉토리를 찾습니다, 세 가지 점을 선택 >**자주 묻는 질문**.
3. 제품정보**회사 소개**.

## 그룹 추가 레지스트리

이메일 보안은 레지스트리에 그룹 이름을 추가 할 수 있습니다.

레지스트리에 단일 그룹을 추가하려면:

1. 추가하려면 그룹 이름을 선택하십시오.
2. 3 점 선택 >**등록에 추가**.

한 번에 레지스트리에 여러 그룹을 추가하려면:

1. 레지스트리에 추가하려면 그룹 이름을 선택하십시오.
2. 선택하&#xAE30;**- 연혁**드롭다운 목록.
3. 제품정보**등록에 추가**.

## 레지스트리에서 그룹 제거

이메일 보안은 레지스트리에서 그룹 이름을 제거 할 수 있습니다.

레지스트리에서 단일 그룹을 제거하려면:

1. 제거하려면 그룹 이름을 선택하십시오.
2. 3 점 선택 >**레지스트리에서 제거**.

한 번에 레지스트리에서 여러 그룹을 제거하려면:

1. 레지스트리에서 제거하려면 그룹 이름을 선택하십시오.
2. 선택하&#xAE30;**- 연혁**드롭다운 목록.
3. 제품정보**레지스트리에서 제거**.

## 필터 impersonation 레지스트리

등록된 그룹 이름 목록을 필터링할 수 있습니다.

그룹 이름은 등록 될 때의 일부입니다[impersonation 등록](/cloudflare-one/email-security/settings/detection-settings/impersonation-registry/). 그룹 이름은 부주의 등록의 일부가 아닌 때 등록되지 않습니다.

목록을 필터링하려면:

1. 제품정보**필터 보기** > **회원 등록**.
2. 다음 중 하나를 선택하십시오:
   - **모든 것**: 등록 및 등록되지 않은 그룹을 보려면.
   - **회사연혁**: 등록 된 그룹을 볼 수 있습니다.
   - **관련 상품**: 등록된 그룹을 볼 수 있습니다.
3. 제품정보**필터 적용**.

추가된 사용자를 편집하고 삭제하여 이메일 보안 디렉토리를 관리할 수 있습니다.

:::note\[등록 사용자]
이메일 보안 디렉토리에는 등록된 사용자만 포함됩니다. 등록된 사용자는 사용자에게 추가됩니다.[impersonation 등록](/cloudflare-one/email-security/settings/detection-settings/impersonation-registry/).
:::

이메일 보안 디렉토리에서 사용자를 수정하거나 삭제하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**이메일 보안** > **주요연혁**.
2. 제품정보**이메일 보안 디렉토리**.

## 사용자 추가

이메일 보안 디렉토리에 사용자를 수동으로 추가하려면:

1. 사이드바에서 이동**계정 설정** > **회원 등록** > **- 연혁**.
2. 제품정보**사용자 추가**:

- 제품 정보**수동 입력**으로**입력 방법**.
- 이름 \***사용자 정보**, 입력**표시 이름**.
- 이름 \***사용자 이메일**, 입력**이메일 주소**.

3. 제품정보**제품 정보**.

사용자가 수동으로 추가하려면:

1. 오시는 길**주요연혁**.
2. 제품정보**이메일 보안 디렉토리**.
3. 수동으로 추가된 사용자는 테이블 아래에 표시될 것입니다**제출하기**.

## 사용자 편집

이메일 보안 디렉토리에서 사용자를 편집하려면:

1. 편집하려는 사용자를 선택하십시오.
2. 3 점 선택 >**제품정보**.
3. 사용자 이름 및 / 또는 이메일 입력.
4. 제품정보**제품 정보**.

## 사용자 삭제

이메일 보안 디렉토리에서 사용자를 삭제하려면:

1. 삭제하려는 사용자를 선택하십시오.
2. 3 점 선택 >**이름 \***.
3. 팝업 메시지를 읽고, 다음 선택**사용자 정의**.

한 번에 레지스트리에서 여러 사용자를 삭제하려면:

1. 삭제하려는 사용자를 선택하십시오.
2. 선택하&#xAE30;**- 연혁**드롭다운 목록 >**이름 \***.

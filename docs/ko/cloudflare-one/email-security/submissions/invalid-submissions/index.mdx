제출은 유효하지 않습니다 :

- 제출에는 첨부 된 EML 파일이 없습니다.
- 제출은 잘못된 파일 확장자로되었습니다.
- 제출은 잘못된 팀 또는 사용자 별명으로 만들어졌습니다.

제출을 보장하기 위해:

- 제출은 첨부된 파일이 있습니다.`.eml`파일 확장.
- 이메일을 제출하는 도메인을 구성합니다.
- 정책을 올바르게 구성합니다.

잘못된 제출을 볼 수:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안** > **공지사항**.
3. 제품정보**잘못된 제출**.

제출 ID 또는 제출 된 이메일에 의해 검색 할 수 있습니다.

필터 기반**날짜 범위**·**제출하기**( 잘못된 제출을 한 이메일 목록). 원하는 필터를 구성하면 선택**필터 적용**.

## 자주 묻는 질문

잘못된 이메일 알림을 활성화하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안** > **계정 설정**.
3. 오시는 길**잘못된 이메일**관련 기사**잘못된 이메일 알림**.

팀 제출은 제출을 위해 제출 된 보안 팀의 이메일입니다. 모든 팀 제출은 Cloudflare에 의해 인간의 리뷰를받습니다.

## 팀 제출 보기

팀 제출을 보려면 :

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안** > **공지사항**.
3. 제품정보**팀 제출**.

## 필터 팀 제출

다음 필터 중 선택:

- **날짜 범위**: 마지막 7, 마지막 30, 마지막 90 일에서 날짜 범위를 선택할 수 있습니다.
- **원래 분해**: 선택[사용 가능한 값](/cloudflare-one/email-security/reference/dispositions-and-attributes/#available-values).
- **제출하기**: 선택[사용 가능한 값](/cloudflare-one/email-security/reference/dispositions-and-attributes/#available-values).
- **최종 분해**: 선택[사용 가능한 값](/cloudflare-one/email-security/reference/dispositions-and-attributes/#available-values).
- **관련 기사**: escalated 또는 not가 있는 팀 제출에 의한 필터. 선택 중`Yes`, `No`, 또는`All`.

필터를 선택하면 선택**필터 적용**.

대시보드는 제출을 포함하여 귀하의 보안 팀의 목록을 사용하여 테이블을 팝업합니다.**제출 ID**, 그리고**이메일 제목**.

## 공지사항

특정 제출에 대한 자세한 내용을 얻으려면:

1. 더 자세한 정보를 원하신 제출으로 이동합니다.
2. 세 가지 점 선택 > 중 선택**더 보기**, **공지사항**·**비슷한 세부 사항 보기**.

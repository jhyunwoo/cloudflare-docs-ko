사용자 제출은 제출된 이메일입니다. 사용자 제출은 우리의 검출 모델을 향상 시킬 수 있지만, 인간의 검토에 대해 에스컬레이션 할 수 있습니다.

자주 묻는 질문[뚱 베어](/cloudflare-one/email-security/settings/phish-submissions/#reclassify-an-email)아래에 표시될 것입니다**사용자 제출**.

:::참조
[PhishGuard는](/cloudflare-one/email-security/phishguard/)고객은 사용자 또는 팀 수준에 제출할 때 분석된 제출이 가능합니다. non-PhishGuard 고객은 여전히 팀 수준에 제출함으로써 분석 된 제출이있을 수 있습니다.
주요 특징

## 사용자 제출 보기

사용자 제출 보기:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안** > **공지사항**.
3. 제품정보**사용자 제출**.

## 필터 사용자 제출

다음 필터 중 선택:

- **날짜 범위**: 마지막 7, 마지막 30, 마지막 90 일에서 날짜 범위를 선택하십시오.
- **원래 분해**: 선택[사용 가능한 값](/cloudflare-one/email-security/reference/dispositions-and-attributes/#available-values).
- **제출하기**: 선택[사용 가능한 값](/cloudflare-one/email-security/reference/dispositions-and-attributes/#available-values).

필터를 선택하면 선택**필터 적용**.

대시보드는 제출을 포함하여 제출 된 이메일 목록을 사용하여 테이블을 팝업합니다.**제출 ID**, 그리고**이메일 제목**.

## 공지사항

특정 제출에 대한 자세한 내용을 얻으려면:

1. 더 자세한 정보를 원하신 제출으로 이동합니다.
2. 세 가지 점 선택 > 중 선택**더 보기**, **공지사항**, **비슷한 세부 사항 보기**·**관련 기사**.

## 제출하기

제출을 escalate:

1. escalate를 원하신 제출으로 이동합니다.
2. 세 가지 점 선택 > 선택**관련 기사**.
3. 대시보드는 에스컬레이션을 승인하는 메시지를 표시합니다. 제품정보**관련 기사**.

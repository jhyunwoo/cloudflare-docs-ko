PhishGuard는 일상적으로 이메일 환경을 검사하고 이메일 inbox를 통해 오는 위협에 대응하는 분석가 팀입니다.

이메일 보안은 고급 기술을 사용하여 이메일 inbox를 보호하기 위해 PhishGuard는 이메일 환경을 impersonation 이벤트, 의심스러운 항목, 거짓 부정적인 / 가짜 긍정적 인 것에 대한 보호하기위한 추가 인간 구성 요소를 제공하며 자동화 된 지능형 시스템은 컨텍스트 부족 (예 : 타협 된 계정 활동)으로 인해 놓을 수 있습니다.

PhishGuard는 Post-delivery 환경에서만 작동합니다 (이메일 inbox에 이미 착륙 한 이메일 만 리뷰). 결과적으로 PhishGuard Analysts는[자주 묻는 질문](/cloudflare-one/email-security/submissions/#submit-messages-for-review)또는[자동 몰드](/cloudflare-one/email-security/settings/auto-moves/)그들의 발견을 기반으로.

PhishGuard는 이메일 탐지 팀과 협조하여 특정 항목에 대한 즉각적인 탐지를 직접 요청하고 필요에 고유 한 사용자 정의 감지를 구현할 수 있습니다. 이 예는 PayPal 트래픽을 차단하기 위해 요청됩니다. invoicing을 위해 PayPal을 사용하지 않는 경우. 이 기능은 PhishGuard의 인간 개입을 통해 이메일 환경을 관리하는 규칙을 통해 소유권을 얻을 수 있습니다.

또한 PhishGuard 분석가 :

- 실시간 위협 데이터를 사용하여 악성 행위를 식별합니다. 이메일 기반 위협은 신속하게 대응되며 즉시 보고 및 문서화됩니다.
- 자주 묻는 질문[사용자 이름](/cloudflare-one/email-security/investigation/search-email/#user-submissions)·[팀 팀](/cloudflare-one/email-security/investigation/search-email/#team-submissions)보안 팀이 더 중요한 역할을 할 수 있도록 제출하십시오.
- 당신이 감지하고 mitigate 위협을 더 빨리, 시간 공격을 줄이는 데 도움이 네트워크에 액세스. 또한 데이터 침해, 금융 손실 및 평판 손상을 방지하기 때문에 비즈니스 영향을 줄이는 데 도움이됩니다.

PhishGuard를 사용하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**PhishGuard는**.

대시보드는 뒤에 오는 미터를 표시할 것입니다:

- ROI 계산기
- Insider 위협 방어
- 이메일 위협 사냥
- 관련 기사
- API 상태
- 이메일 보안 운영
- 제품정보

## ROI 계산기

ROI 계산기를 사용하여 투자에 대한 PhishGuard의 수익을 계산하는 데 소요 시간 및 시간 비율을 비교하십시오.

ROI 계산기 전시:

- USD 달러의 총 집계 된 저장된 수.
- 삼기 기간: 몇 분 동안의 금액은 메시지를 삼기.
- 시간 비율.

## Insider 위협 방어

이름 \*[내부 위협](https://www.cloudflare.com/en-gb/learning/access-management/what-is-an-insider-threat/)조직과 관련된 누군가에서 조직의 보안 줄기로 위험합니다. PhishGuard는 위협 배우 그룹을 찾습니다.

대시보드 디스플레이의 내부 위협 방어**Insider 리드**·**Insider 보고서 생성**. **Insider 리드**잠재적 인 내부 위협 이메일으로 식별 된 이메일 수를 표시합니다.**Insider 보고서 생성**내부 리드를 기반으로 만든 보고서 수를 표시합니다.

## 이메일 위협 사냥

PhishGuard는 이메일 환경에서 의심스럽고 악적인 활동을 검토합니다.

Cloudflare One 대시보드의 이메일 위협 사냥은 이전에 알려지지 않은 피싱 공격을 표시합니다.

이메일 위협 사냥 또한 당신에게 정보를 제공합니다**Threat 리드 생성**·**생성 된 총 재 게시**.

## 관련 기사

**관련 기사**PhishGuard 팀에 의해 촬영 된 가장 일반적인 작업을 검토 할 수 있습니다, 에스컬레이션과 같은, 위협 사냥, 이동.

## API 상태

API Status는 API 메시지 자동 이동 및 디렉토리 통합의 현재 상태를 모니터링하고 구성할 수 있습니다.

제품정보**메시지 이동**으로[auto-moves 구성](/cloudflare-one/email-security/settings/auto-moves/). 선택**Directory 통합**으로[협력업체](/cloudflare-one/email-security/directories/).

## 이메일 보안 운영

관리 이메일 보안 작업은 PhishGuard 팀에 의해 검토 된 phish 제출의 결과를 검토 할 수 있습니다.

그것은 뒤에 오는 것 표시합니다:

- 전체보기[phish 제출](/cloudflare-one/email-security/settings/phish-submissions/)
- 연락처
- 해결하는 Median 시간
- 연락처

- **공지사항**: 각 보고서에 대한 다음 정보를 제공합니다 :
  - **제품정보**: 보고서 개요. 이 보고서의 날짜와 시간을 포함, 공격의 유형 수행, 그리고 더.
  - **표적과 피해학**: 대상기업
  - **이름 \***: 납품 disposition, 현재 분해, ES Alert ID, Message-ID, Timestamp, Subject 및 Attempted Fraudulent Amount와 같은 정보를 표시합니다.
  - **타협의 지표 (IOC)**: [타협의 지표 (IOC)](https://www.cloudflare.com/en-gb/learning/security/what-are-indicators-of-compromise/)보안팀이 공격이 발생하면 보안팀이 결정할 수 있는 특정 보안 침해에 대한 정보입니다.

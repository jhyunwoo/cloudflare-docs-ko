Retro Scan을 사용하여 현재 이메일 공급자가 놓칠 수 있는 보안 위협을 식별합니다. Cloudflare는 Microsoft 365 inbox의 역사적인 이메일의 14 일까지 분석하고 치료가 필요할 수있는 악성 메시지의 자세한 보고서를 제공합니다. 한 번 이메일 알림을 받게 됩니다.

:::참조
Retro 검사는 Microsoft 365 계정에서만 유효합니다.
주요 특징

무료 스캔을 시작하려면:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안** > **제품정보**.
3. 제품정보**무료 스캔 시작** > **Generate 보고서**.
4. 지원하다[Microsoft 통합](/cloudflare-one/email-security/setup/post-delivery-deployment/api/m365-api/#enable-microsoft-integration). Microsoft 통합을 활성화하면 도메인을 추가하고 현재 이메일 보안 시스템을 지정할 페이지에 리디렉션됩니다.
5. Retro 검사 보고서 생성:
   - **연결 영역**: 통합에서 적어도 하나의 도메인을 선택, 다음 선택**계속하기**.
   - **현재 솔루션 선택**: 현재 사용중인 이메일 보안 도구를 선택한 다음 선택**계속하기**.
   - **자주 묻는 질문**: 이전에 선택한 세부 사항을 검토합니다. 다음, 선택**계속하기**. 일단 보고서를 사용할 때 이메일로 통보됩니다.
6. 이메일 inbox로 이동하고 전체 보고서를 볼 수있는 링크를 선택하십시오.
7. Cloudflare 대시보드에, 선택**공지사항**.

대시보드 디스플레이**제품정보**·**이름 \***&#xC0AC;이트 맵

### 제품정보

개요는 총 스캔된 도메인을 표시합니다. 개요는 당신을 보여줍니다:

- [관련 상품](/cloudflare-one/email-security/monitoring/#disposition-evaluation)
- 악성 위협 유형
- 맛있는 대상
- 맛있는 위협 기원

### 이름 \*

세부사항은 당신이 분해를 할당된 첫번째 1,000의 이메일 검토할 수 있습니다.

자주 묻는 질문[이름 \*](/cloudflare-one/email-security/investigation/search-email/#details)메시지에 관하여.

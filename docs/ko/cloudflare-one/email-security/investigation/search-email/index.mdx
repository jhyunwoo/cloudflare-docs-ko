이메일 보안을 통해 이메일을 통해 검색 할 수있는 다른 스크린 표준을 사용할 수 있습니다, reclassify 및 메시지의 특정 볼륨 이동, 유사한 이메일을 찾아, 및 수출 메시지.

## 스크린 기준

이메일 보안을 사용하면 인기있는, 일반 및 고급 심사 기준을 사용하여 inbox를 검색 할 수 있습니다. 고급 검열은 당신의 inbox의 가장 심층적인 조사를 줄 것입니다.

이메일 트래픽을 통해 화면에:

1. 로그인[사이트맵 한국어](https://one.dash.cloudflare.com/).
2. 제품정보**이메일 보안**.
3. 제품정보**투자정보**, 다음**새로운 화면을 실행**.
4. 선택하기**인기있는**, **(주)**·**지원하다**스크린 방법. 각 방법을 배우기 위해 아래의 설명을 참조하십시오.

결과는 테이블에 표시됩니다. 테이블을 사용하면 선택한 검열 기준에 맞는 메시지를 검토하고 수행 할 수 있습니다.

### 인기 스크린

인기있는 화면은 일반적인 사전 정의 기준을 기반으로 메시지를 볼 수 있습니다.

인기있는 화면 기준을 사용하려면:

1. 이름 \***제품 설명**, 선택**인기 스크린**.
2. 다음 기준 중 하나를 선택하십시오:
   - **연락처**: 전자 메일을 읽거나 수동으로 지난 7 일 이내에 이동하십시오.
   - **연락처**: 마지막 7 일 이내에 재 분류 된 이메일.
   - **Malicious 이메일**: 지난 7일 이내에 악의적 처분을 할당한 이메일.
   - **Spoof 이메일**: 지난 7일 안에 spoof disposition를 할당한 이메일.
   - **Suspicious 이메일**: 지난 7일 이내에 의심스러운 처분을 할당한 이메일.
   - **스팸 메일**: 마지막 7 일 안에 스팸 처분에 할당 된 이메일.
3. 제품정보**Run 스크린**.

스크린 표준을 수정하려면 아래에서**Active 스크린 표준**, 선택**수정하기**.

### 일정한 스크린

일반 화면은 모든 표준을 통해 화면을 삽입하여 inbox를 조사 할 수 있습니다.

일반 화면 기준을 사용하려면:

1. 이름 \***제품 설명**, 선택**일정한 스크린**.
2. 선택하기**날짜 범위**.
3. 키워드 입력
4. 제품정보**Run 스크린**.

검색의 일부로 모든 이메일을 포함하려면 활성화**모든 메일 포함**.

스크린 표준을 수정하려면 아래에서**Active 스크린 표준**, 선택**수정하기**.

화면 상태를 재설정하려면, 선택**이름 \***.

### 고급 화면

고급 화면 기준은 특정 기준에 따라 좁은 메시지 결과를 제공합니다. 고급 스크린에는 몇 가지 옵션이 있습니다 (예 : 키워드, 제목 키워드, 보낸 사람 도메인 및 더 많은) inbox를 스캔합니다.

고급 화면 기준을 사용하려면:

1. 이름 \***제품 설명**, 선택**고급 화면**.
2. (필수) 날짜 선택
3. (선택) 다른 분야에서 채우십시오. 주제를 제외한 모든 필드는 하나의 값으로 채워야합니다.
4. 제품정보**Run 스크린**.

검색의 일부로 모든 이메일을 포함하려면 활성화**모든 메일 포함**.

스크린 표준을 수정하려면 아래에서**Active 스크린 표준**, 선택**수정하기**.

화면 상태를 재설정하려면, 선택**이름 \***.

## 메시지 이동

이동 메시지는 특정 폴더로 메시지를 이동할 수 있습니다. 한 번에 1,000 메시지까지 이동할 수 있습니다.

메시지 이동:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**이메일 보안**, 그리고 선택**투자정보**.
2. 조사 페이지에서 이동하려는 모든 메시지를 선택하십시오.
3. 선택하&#xAE30;**- 연혁**dropdown, 다음 선택**지원하다**.
4. 다음 폴더 중 하나를 선택:
   - **회사 소개**: 기본 이메일 폴더로 메시지 이동.
   - **Junk 이메일**: junk 또는 스팸 폴더로 메시지를 이동합니다.
   - **정보 수집**: trash 또는 삭제 된 항목 이메일 폴더로 메시지를 이동합니다.
   - **Soft delete (사용자 복구 가능)**: 사용자의 삭제 된 항목 폴더로 메시지를 이동합니다. 이 옵션은 Microsoft 365 전용입니다.
   - **하드 삭제 (admin recoverable)**: 사용자의 inbox에서 메시지 삭제.
5. 제품정보**제품 정보**.

대량으로 메시지를 이동하려면, 선택**모든 메시지** > **- 연혁** > **지원하다**.

## 비슷한 이메일 찾기

각 탐지에는 이메일 탐지 지문 (EDF) hash 그 이메일 안전이 유사한 탐지를 검색하는 검색 API에 보냅니다.

유사한 탐지 결과를 찾아내기 위하여:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**이메일 보안**, 그리고 선택**투자정보**.
2. 투자 페이지에, 아래**일치하는 메시지**, 검색**비슷한 이메일**열.
3. 비슷한 이메일 수를 선택하십시오. 번호를 선택하면 비슷한 이메일 목록을 보여줍니다.

## 수출 메시지

이메일 보안을 통해 CSV 파일로 메시지를 내보내실 수 있습니다.

메시지 내보내기:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**이메일 보안**, 그리고 선택**투자정보**.
2. 투자 페이지에, 아래**일치하는 메시지**, 선택**CSV로 내보내기**.
3. 제품정보**수출 메시지**팝업 메시지에. 대시보드에서 최대 500개의 메시지를 수출할 수 있습니다. 최대 1,000개의 매칭 메시지를 내보내려면[사이트맵](/api/resources/email_security/subresources/investigate/methods/get/).

대량으로 메시지 내보내기**모든 메시지** > **CSV로 내보내기**.

## 이메일 상태

이메일 보안은 각 이메일의 상태 및 행동을 검토 할 수 있습니다.

각 이메일의 상태와 행동을 볼 수 있습니다:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**이메일 보안**, 그리고 선택**투자정보**.
2. 조사 페이지에서 세 가지 점을 선택하십시오.
3. 3개의 점을 선정하는 것은 뒤에 오는 선택권을 보여줄 것입니다:

- 이메일이 quarantined 경우:
  - **자주 묻는 질문**: 참고[연락처](#email-details)더 알아보기.
  - **비슷한 이메일 보기**: 비슷한 이메일 찾기`value_edf_hash`(Electronic 탐지 지문 해시).
  - **제품정보**: 이메일 보안은 더 이상 선택된 메시지를 quarantine하지 않습니다.
  - **자주 묻는 질문**: 잘못된 경우 메시지의 분해를 선택하십시오. 더 알아보기[메시지 정렬](#reclassify-messages)더 알아보기.

- 이메일이 보장되지 않는 경우:
  - **자주 묻는 질문**.
  - **비슷한 이메일 보기**.
  - **공지사항**.
  - **[지원하다](/cloudflare-one/email-security/settings/auto-moves/)**(당신은 허가 된 이동만 가능).
  - **[자주 묻는 질문](#reclassify-messages)**.

## 연락처

이메일 보안은 다음 이메일 세부 정보를 보여줍니다 :

- 이름 \*
- 작업 로그
- 이름 \*
- 메일 추적

### 이름 \*

이메일 보안은 뒤에 오는 세부사항을 표시합니다:

1. **위협 유형**: 이메일의 위협 유형, 예를 들어,[회사 소개](/cloudflare-one/email-security/reference/how-es-detects-phish/)·[IP 기반 스팸](/cloudflare-one/email-security/reference/how-es-detects-phish/).
2. **인증 및 인증**: 이메일 검증 방법[사이트맵](https://www.cloudflare.com/learning/dns/dns-records/dns-spf-record/), [사이트맵](https://www.cloudflare.com/learning/dns/dns-records/dns-dkim-record/), [사이트맵](https://www.cloudflare.com/learning/dns/dns-records/dns-dmarc-record/). 대시보드는 SPF, DKIM 및 DMARC 검사가 통과한 경우에 통행을 표시할 것입니다.
3. **Sender 세부사항**: 정보 포함 :
   - IP 주소
   - 도메인 등록
   - 자율 sys 번호: 이 번호는 사용자를 식별[자율 시스템 (AS)](https://www.cloudflare.com/en-gb/learning/network-layer/what-is-an-autonomous-system/).
   - Autonomous sys name: 이 이름은 자율 시스템 (AS)을 식별합니다.
   - 이름 \*
4. **자주 묻는 질문**: 이메일 보안에 의해 식별 된 악성 링크 목록. 더 알아보기[관련 링크](#open-links)Security Center, Browser Isolation 또는 외부 도구에서 링크를 엽니 다.
5. **첨부파일**: 전자 메일이 첨부 파일이있는 경우 Cloudflare 대시보드는 파일 이름을 표시하고 할당 된 분해합니다. 첨부 파일을 열 수 있습니다.[브라우저 고립](/cloudflare-one/remote-browser-isolation/). PDF 파일만 현재 지원됩니다.
6. **분해를위한 이유**: 왜 이메일이 악의, 의심, 또는 스팸으로 악화되었는지 설명합니다. 대시보드 또한 전시[구름 많음](/cloudflare-one/email-security/investigation/search-email/#cloudy-summaries).

#### 구름 많음

Cloudflare 대시보드 용도[구름 많음](/fundamentals/reference/cloudy-ai-agent/)이메일이 원치 않는 것으로 분류되었는지 설명하기 위해.

Cloudy는 underlying detection 코드를 분석하고 이메일을 최종 분해로 이끌 수있는 특정 탐지 논리의 설명을 생성합니다. 각 요약은 이메일 보안 팀에 피드백을 제공 할 수있는 등급 옵션을 제공합니다. Cloudy summaries는 최종 이메일에만 사용할 수 있습니다.[관련 제품](/cloudflare-one/email-security/reference/dispositions-and-attributes/#available-values).

**모든 서명 보기**이 웹 사이트는 귀하가 웹 사이트를 탐색하는 동안 귀하의 경험을 향상시키기 위해 쿠키를 사용합니다.

#### 관련 링크

Security Center에서 링크를 열 수 있습니다.[브라우저 고립](/cloudflare-one/remote-browser-isolation/), 또는 복사 및 붙여넣기 링크 그래서 당신은 외부 도구에서 콘텐츠를 조사 할 수 있습니다.

의심스러운 이메일에 대한 링크를 선택하면 장치와 회사의 네트워크가 악성 코드, 랜섬웨어 및 자격 수확에 폭발합니다.

Browser Isolation는 Cloudflare에 의해 호스팅되는 안전한, 처분할 수 있는 먼 브라우저 회의에 있는 unverified 또는 suspicious 근원에서 모든 웹 내용을 열기에 의해 손상된 장치의 어떤 위험을 삭제합니다.

보안 센터의 링크를 엽니 다 :

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**이메일 보안** > **투자정보**.
2. 링크를 열려면, 세 가지 점을 선택, 다음 선택**자주 묻는 질문**.
3. 이름 \***이름 \***, 이동**자주 묻는 질문**.
4. 링크를 열고, 선택**보안센터**.
5. Cloudflare 대시보드에 투자하여 리디렉션됩니다.
6. 제품정보**현재 위치**.
7. 대시보드는 귀하의 링크에 대한 보고서를 생성합니다.

브라우저 고립에 링크 열기 :

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**이메일 보안** > **투자정보**.
2. 링크를 열려면, 세 가지 점을 선택, 다음 선택**자주 묻는 질문**.
3. 이름 \***이름 \***, 이동**자주 묻는 질문**.
4. 링크를 열고, 선택**브라우저 Isolation에서 열기**.
5. 링크는 별도의 창에서 열릴 수 있는 콘텐츠를 안전하게 검색할 수 있습니다.

대안으로, 당신은 직접 할 수 있습니다[Browser Isolation에서 열린 링크](/cloudflare-one/remote-browser-isolation/setup/clientless-browser-isolation/#open-links-in-browser-isolation).

이메일에서 링크를 열 때 Cloudflare는 파란색 막대로 당신을 선물합니다. 이 페이지는 격리되어 있으며 그 페이지의 잠재적 악명 높은 콘텐츠로부터 보호됩니다.

### 작업 로그

Action log는 선택한 메시지에서 수행된 포스트 배달 작업을 검토할 수 있습니다. 동작 로그 표시:

- **이름 \***: 포스트 배달 작업이 수행되었을 때 날짜.
- **- 연혁**: 이메일에 찍은 활동. 예를 들어, trash 폴더에 이메일을 이동, quarantined 이메일을 해제, 더.

### 이름 \*

Raw 메시지는 메시지의 원료 정보를 볼 수 있습니다. 또한 이메일 메시지를 다운로드 할 수 있습니다. 메시지를 다운로드하려면, select**다운로드 .EML**.

### 메일 추적

메일 추적을 통해 선택한 메시지를 추적 할 수 있습니다. 우편 추적 전시:

- **이름 \***: 메일이 추적될 때 날짜와 시간.
- **제품정보**: 이메일은 인바운드 (이메일은 다른 이메일에서 전송), 또는 아웃바운드 (이메일 주소로 전송).
- **- 연혁**: 이메일에 찍은 활동. 예를 들어, trash 폴더에 이메일을 이동, quarantined 이메일을 해제, 더.

이 튜토리얼은 인증에 대한 Kubernetes Client-go credential 플러그인과 Cloudflare 터널을 사용하는 방법을 설명합니다. 이러한 단계에 따라, Cloudflare 터널을 통해 쿠버네티스 클러스터에 안전하게 접근할 수 있습니다.`kubectl`명령줄 도구.

## 자주 묻는 질문

- Cloudflare 계정
- Cloudflare 터널 클라이언트 (`cloudflared`) 당신의 기계에 설치해
- Kubernetes 클러스터에 접근
- `kubectl`기계에 설치

## 1. Cloudflare 터널 설정

1. 이름 \*`cloudflared`Cloudflare 계정으로:

   ```sh
   cloudflared tunnel login
   ```

2. 새로운 터널 만들기:

   ```sh
   cloudflared tunnel create k8s-tunnel
   ```

3. 지정된 구성 파일을 생성하여 터널 구성`config.yml`:

   ```yaml
   tunnel: <TUNNEL_ID>
   credentials-file: /path/to/credentials.json
   ingress:
     - hostname: k8s.example.com
       service: tcp://kubernetes.default.svc.cluster.local:443
     - service: http_status:404
   ```

   기타 제품`<TUNNEL_ID>`터널 ID를 사용하여 필요한 호스트명을 조정합니다.

4. 터널을 시작:

   ```sh
   cloudflared tunnel run k8s-tunnel
   ```

## 2. Kubernetes API 서버 구성

쿠버네티스 API 서버가 Cloudflare 터널에서 인증을 수락하도록 구성되었습니다. 인증 웹훅을 설정하거나 API 서버를 구성하여 Cloudflare Tunnel의 클라이언트 인증서를 신뢰합니다.

## 3. 클라이언트 go credential 플러그인 설정

1. 이름의 스크립트 만들기`cloudflare-k8s-auth.sh`다음 내용으로:

   ```bash
   #!/bin/bash

   echo '{
     "apiVersion": "client.authentication.k8s.io/v1beta1",
     "kind": "ExecCredential",
     "status": {
       "token": "'"$(cloudflared access token -app=https://k8s.example.com)"'"
     }
   }'
   ```

   스크립트 실행 가능:

   ```sh
   chmod +x cloudflare-k8s-auth.sh
   ```

2. 업데이트`~/.kube/config`credential 플러그인을 사용하는 파일:

   ```yaml
   apiVersion: v1
   kind: Config
   clusters:
     - cluster:
         server: https://k8s.example.com
       name: cloudflare-k8s
   users:
     - name: cloudflare-user
       user:
         exec:
           apiVersion: client.authentication.k8s.io/v1beta1
           command: /path/to/cloudflare-k8s-auth.sh
           interactiveMode: Never
   contexts:
     - context:
         cluster: cloudflare-k8s
         user: cloudflare-user
       name: cloudflare-k8s-context
   current-context: cloudflare-k8s-context
   ```

## 4. Cloudflare 갱도를 가진 kubectl를 사용하십시오

지금 사용할 수 있습니다`kubectl`일반적으로 명령. Client-go credential 플러그인은 Cloudflare 터널을 통해 인증을 자동으로 처리합니다.

```sh
kubectl get pods
```

## 문제 해결

문제가 발생하면:

- 이름 \*`cloudflared`실행하고 터널은 활성화
- 자주 묻는 질문`~/.kube/config`파일이 올바르게 구성됨
- 쿠버네티스 API 서버가 Cloudflare 터널에서 인증을 받아 올바르게 설정되었는지 확인
- 모든 오류 메시지에 대한 Cloudflare 터널 로그 검토

더 많은 정보를 원하시면, 참조[사이트맵 비밀번호](/cloudflare-one/networks/connectors/cloudflare-tunnel/)그리고[Kubernetes client-go credential 플러그인 문서](https://kubernetes.io/docs/reference/access-authn-authz/authentication/#client-go-credential-plugins).

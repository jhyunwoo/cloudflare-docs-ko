이름 \*[상태 접근](https://learn.microsoft.com/entra/identity/conditional-access/overview)Microsoft Entra ID (이전 Azure Active Directory)에서 관리자는 Entra ID에서 응용 프로그램 및 사용자에 직접 정책을 시행 할 수 있습니다. 컨디셔널 액세스는 Windows를 전문으로하는 체크 세트를 가지고 있으며 Windows 전원 사용자와 조직에서 종종 선호합니다.

## 시작하기 전에

당신이 가지고 있는지 확인:

- Microsoft Entra ID 계정에 대한 글로벌 관리자 권한
- Microsoft Entra ID 계정에서 사용자 구성

## 당신의 신청을 위한 ID 공급자를 설치하십시오

더 알아보기[IdP 설정 지침](/cloudflare-one/integrations/identity-providers/entra-id/#set-up-entra-id-as-an-identity-provider)엔트라 ID

## Entra ID에서 API 권한 추가

기본 IdP 통합이 테스트되고 작동되면 Cloudflare에 대한 권한을 부여하여 Entra ID의 조건 액세스 정책을 읽습니다.

1. Microsoft Entra ID에서 이동**앱 등록**.

2. IdP 통합을 위해 만든 응용 프로그램을 선택합니다.

3. 오시는 길**API 권한**선택하기**권한 추가**.

4. 제품정보**Microsoft 그래픽**.

5. 제품정보**신청 허가**그리고 추가`Policy.Read.ConditionalAccess`.

   :::참조
   자주 묻는 질문**신청 허가**; 위임된 허가는 이 특징을 위해 작동하지 않을 것입니다.
   주요 특징

6. 제품정보**Grant 관리자 동의**.

## Entra ID의 조건 접근

1. Microsoft Entra ID에서 이동**Enterprise 응용** > **상태 접근**.
2. 오시는 길**인증 Contexts**.
3. [인증 컨텍스트 만들기](https://learn.microsoft.com/en-us/entra/identity/conditional-access/concept-conditional-access-cloud-apps#authentication-context)참고 자료에 Cloudflare 액세스 정책. 인증 컨텍스트를 descriptive name (예를 들어,`Require compliant devices`).
4. 다음으로 이동**회사연혁**.
5. [새로운 조건 접근 정책 만들기](https://learn.microsoft.com/en-us/entra/identity/conditional-access/concept-conditional-access-policies)또는 기존 정책을 선택하십시오.
6. 인증 상황에 대한 조건 접근 정책 할당 :
   1. 정책 빌더에서, 선택**대상 자원**.
   2. 내 계정**이 정책이 적용되는 것을 선택하십시오.**&#x64;ropdown, 선택*인증 상황*.
   3. 이 정책을 사용할 인증 컨텍스트를 선택합니다.
   4. 자주 묻는 질문

## Zero Trust와 동기화 조건 접근

Cloudflare 액세스로 조건부 액세스 정책을 가져 오기 :

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **액세스 설정**.
2. 내 계정**앱 실행**, 선택**계정 관리**.
3. 제품 정보**로그인 방법**.
4. Microsoft Entra ID 통합 및 선택 찾기**제품정보**.
5. 이름 \***Azure AD 정책 동기화**.
6. 제품정보**제품 정보**.

## 오시는 길

Cloudflare 액세스 응용 프로그램에 대한 조건 접근 정책을 시행하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**액세스 제어** > **이름 \***.

2. 제품정보**앱 추가**.

3. 제품정보**셀프 호스팅**.

4. 신청에 대한 이름 입력.

5. 제품정보**공공 hostname 추가**보호 응용 프로그램의 대상 URL을 입력합니다.

6. 제품정보**새로운 정책 만들기**그리고 빌드[오시는 길](/cloudflare-one/access-controls/policies/)사용 방법*Azure AD - Auth 컨텍스트*옵션 정보 예를 들면:

   | - 연혁 | 규칙 유형 | 옵션 정보                | 제품정보                        |
   | ---- | ----- | -------------------- | --------------------------- |
   | 지원하다 | 이름 \* | 이메일 보내기              | `@example.com`              |
   |      | 이름 \* | Azure AD - Auth 컨텍스트 | `Require compliant devices` |

7. 응용 프로그램 구성에 이 정책을 추가합니다.

8. 제품 정보**Identity 공급자**, Microsoft Entra ID 통합을 선택하십시오.

9. 자주 묻는 질문[자체 호스팅 응용 프로그램 생성 단계](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/)앱을 게시합니다.

사용자는 이 인증 컨텍스트와 관련된 Microsoft Entra ID 조건 액세스 정책을 통과하면 액세스 할 수 있습니다.

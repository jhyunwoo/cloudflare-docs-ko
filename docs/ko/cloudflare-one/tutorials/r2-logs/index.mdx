Zero Trust Enterprise 플랜에서만 사용할 수 있습니다.
주요 특징

이 튜토리얼은 빌드하는 방법을 다룹니다.[Cloudflare R2 물통](/r2/buckets/)로그를 저장하고, Zero Trust에 물통을 연결하는 방법[Logpush 서비스](/cloudflare-one/insights/logs/logpush/)로그를 저장하고 다른 도구로 수출합니다.

## 시작하기 전에

- Cloudflare R2 및 Zero Trust Logpush 통합이 플랜에 포함되어 있습니다. 더 많은 정보를 원하시면 계정 팀에 문의하십시오.

## Cloudflare R2 버킷 만들기

1. 내 계정[Cloudflare 대시보드](https://dash.cloudflare.com/), 이동**사이트맵 제품정보**사이트 맵

   <DashButton url="/?to=/:account/r2/overview" />

2. 제품정보**버킷 만들기**.

3. 버킷에 대한 identifiable 이름을 입력 한 다음 선택**버킷 만들기**.

## R2 API 토큰 만들기

1. 관련 기사**사이트맵**, 다음 선택**R2 API 토큰 관리**.
2. 제품정보**API 토큰 만들기**.
3. 내 계정**제출**, 선택**개체 읽기 및 쓰기**.
4. 내 계정**물통을 지정하십시오 (s)**, 선택*특정 버킷에만 적용*. 만든 물통을 선택하십시오.
5. p참고 자료s에 다른 토큰 설정을 구성합니다.
6. 제품정보**API 만들기 토큰 토큰**.
7. 제출하기**액세스 키 ID**, **비밀 액세스 키**, 엔드포인트 URL 값. 이 값을 다시 접근 할 수 없습니다.
8. 제품정보**제품 정보**.

## Zero Trust 연결 Logpush 작업

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**관련 기사** > **로그인**. 선택**Logpush 관리**.
2. 제품정보**서비스 연결**.
3. 어떤 데이터 세트와 필드를 선택하여 버킷에 보내려면. 제품정보**이름 \***.
4. 제품정보**S3 호환**.
5. 내 계정**S3 호환 버킷 경로**, 당신의 물통의 이름을 입력하십시오.
6. 내 계정**물통 지역**, 입력`auto`.
7. 값 입력**액세스 키 ID**, **비밀 액세스 키**·**엔드포인트 URL**해당 분야에서.
8. 제품정보**기타 제품**. 신속한 경우 토큰 도전과 소유권을 증명할 필요가 없습니다.

Logpush 작업은 선택한 Zero Trust 로그를 R2 버킷에 보낼 것입니다.

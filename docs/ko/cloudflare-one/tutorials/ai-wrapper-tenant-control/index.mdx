		if (request.url.endsWith("/api/chat")) {
			if (request.method === "POST") {
				try {
					const { messages } = await request.json();

					const response = await fetch(
						"https://gateway.ai.cloudflare.com/v1/$ACCOUNT_ID/$GATEWAY_ID/openai/chat/completions",
						{
							method: "POST",
							headers: {
								"Content-Type": "application/json",
								Authorization: `Bearer ${env.OPENAI_API_KEY}`,
							},
							body: JSON.stringify({
								model: "gpt-4o-mini",
								messages: messages,
							}),
						},
					);

					if (!response.ok) {
						throw new Error(`AI Gateway Error: ${response.status}`);
					}

					const result = await response.json();
					return new Response(
						JSON.stringify({
							response: result.choices[0].message.content,
						}),
						{
							headers: { "Content-Type": "application/json" },
						},

						headers: { "Content-Type": "application/json" },

## 4. 액세스로 래퍼를 확보

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**액세스 제어** > **이름 \***.
2. 제품정보**앱 추가**.
3. 제품 정보**셀프 호스팅**.
4. AI Agent 래퍼 애플리케이션의 이름을 입력합니다.
5. 내 계정**세션 기간**, 사용자의 응용 토큰이 만료 될 때 선택.
6. 제품정보**공공 hostname 추가**그리고 당신의 노동자를 위해 놓인 주문 도메인을 입력하십시오.
7. [액세스 앱 구성](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/)당신의 노동자를 위해.
8. 더 보기[오시는 길](/cloudflare-one/access-controls/policies/policy-management/)당신의 신청에 연결할 수 있는 통제.

이제 AI 래퍼는 액세스 정책을 성공적으로 일치하는 사용자에 의해 액세스 할 수 있습니다.

## 6. 데이터 손실 방지 및 Clientless Browser Isolation 강화

이제 AI 에이전트 래퍼에 대한 액세스에 대한 전체 제어가있어 데이터 손실 방지 (DLP) 및 Clientless Web Isolation과 같은 추가 보안 방법을 시행하여 AI 에이전트와 공유 된 데이터를 보호하고 제어 할 수 있습니다.

### 데이터 손실 방지 프로파일 적용

사용 가능[데이터 손실 방지 (DLP)](/cloudflare-one/data-loss-prevention/)민감한 데이터를 AI 에이전트로 전송하는 사용자를 방지하기 위해.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**데이터 손실 방지** > **회사 소개**.

2. 더 알아보기[DLP 프로필](/cloudflare-one/data-loss-prevention/dlp-profiles/)실행을 올바르게 구성하고 싶습니다.

3. HTTP 정책을 추가하여 DLP 프로필을 실행하십시오. 예를 들면:

   | 옵션 정보   | 회사연혁  | 제품정보                     | 로그인   | - 연혁 |
   | ------- | ----- | ------------------------ | ----- | ---- |
   | 이름 \*   | 이름 \* | `ai-wrapper.example.com` | 이름 \* | 제품정보 |
   | DLP 프로필 | 내 계정  | *AI DLP 프로필*             |       |      |

4. 제품정보**공지사항**.

DLP 정책 작성에 대한 자세한 내용은 참조[HTTP 트래픽 검사](/cloudflare-one/data-loss-prevention/dlp-policies/).

### 클라이언트 격리된 브라우저에서 실행

자체 호스팅 액세스 응용 프로그램으로 래퍼를 게시했기 때문에 실행할 수 있습니다.[격리된 세션](/cloudflare-one/remote-browser-isolation/setup/clientless-browser-isolation/)사용자를 위해[오시는 길](/cloudflare-one/access-controls/policies/)그리고 당신의 신청을 위해 그것을 구성.

액세스 응용 프로그램에 대한 자세한 내용은 참조[Isolate 자체 호스팅 응용](/cloudflare-one/access-controls/policies/isolate-application/).

## 추가 혜택

Cloudflare를 채택하여 AI 에이전트에 대한 액세스를 확보하는 조직은 향상된 가시성과 구성성을 제공합니다.

### 제품정보

Zero Trust는 모두 로그인합니다[오시는 길](/cloudflare-one/insights/logs/audit-logs/)·[DLP 검출](/cloudflare-one/insights/logs/gateway-logs/#http-logs). 또한 AI Gateway 제공[제품정보](/ai-gateway/observability/logging/)사용자 프롬프트, 모델 응답, 토큰 사용 및 비용으로.

Logs는 외부 공급자에 수출될 수 있습니다[다운로드](/logs/logpush/).

### 구성

래퍼를 구성할 수 있습니다.[다른 AI 공급자](/ai-gateway/usage/providers/)또는 사용자가 Cloudflare의 글로벌 네트워크에서 직접 실행하는 AI 모델을 포함하여 여러 AI 공급자 사이에서 선택할 수있는 옵션을 제공합니다.[사이트맵](/workers-ai/). 이로, 당신은 AI 사용법과 관련한 비용을 통제할 수 있고 또는 당신의 사용자 또는 접근 제한에 충격 없이 더 새로운 모형을 이미 둡니다.

이 튜토리얼은 관리자에게 할당 된 전용 egress IP 주소 중 하나 사이의 egress IP 주소를 변경할 수있는 쉬운 방법을 제공합니다. 사용자는 WARP 클라이언트에서 가상 네트워크를 직접 전환하여 IP를 사용할 수 있습니다.

egress IP를 변경하는 것은 품질 보증 (QA) 및 기타 유사한 시나리오에서 유용 할 수 있습니다. 로컬 egress 위치와 스위치를 사용하여 다른 원격 위치를 시뮬레이션합니다.

## 시작하기 전에

당신이 가지고 있는지 확인:

- [WARP 클라이언트 배포](/cloudflare-one/team-and-resources/devices/warp/deployment/)사용자의 장치.
- [구성 터널](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/)Cloudflare에 개인 네트워크를 연결하십시오. 이 튜토리얼은 다음과 같습니다 :
  - 두 개의 터널 만들기[대시보드를 통해](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/).
  - 오시는 길`10.0.0.0/8`1개의 갱도를 통해서.
  - 오시는 길`192.168.88.0/24`다른 터널을 통해.
- 다수 받기[전용 IP 주소](/cloudflare-one/traffic-policies/egress-policies/dedicated-egress-ips/).

## 각 egress 경로에 대한 가상 네트워크 생성

첫째, 창조[가상 네트워크](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/tunnel-virtual-networks/)전용 egress IPs에 대응합니다.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**네트워크** > **오시는 길**.
    2. 내 계정**가상 네트워크**, 선택**가상 네트워크 만들기**.
    3. 가상 네트워크 이름. 해당 전용 egress IP 위치와 관련된 이름을 사용하는 것이 좋습니다. 예를 들어, 사용자가 미주에서 egress 할 경우 가상 네트워크 이름을 지정할 수 있습니다.`vnet-AMER`.
    4. 제품정보**제품 정보**.
    5. 각 전용 egress IP를 위해 2-4를 반복하십시오 당신은 사용자를 사이에서 전환하고 싶습니다. 예를 들어, 다른 가상 네트워크를 만들 수 있습니다.`vnet-EMEA`유럽, 중동, 아프리카에서 선거를 위해.
  </TabItem>

  <TabItem label="사이트맵">
    1. 이름 \*[가상 네트워크](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/tunnel-virtual-networks/)전용 IP 중 하나에 해당합니다. 해당 전용 egress IP 위치와 관련된 이름을 사용하는 것이 좋습니다. 예를 들어, 사용자가 미주에서 egress 할 경우 가상 네트워크 이름을 지정할 수 있습니다.`vnet-AMER`.

       <APIRequest
         path="/accounts/{account_id}/teamnet/virtual_networks"
         method="POST"
         json={{
         		comment: "Virtual network to egress from the Americas",
         		is_default: false,
         		name: "vnet-AMER",
         	}}
       />

       더 많은 정보를 원하시면, 참조[가상 네트워크 만들기](/api/resources/zero_trust/subresources/networks/subresources/virtual_networks/methods/create/).

    2. 각 전용 egress IP를 위해 1 단계 반복하십시오. 예를 들어, 다른 가상 네트워크를 만들 수 있습니다.`vnet-EMEA`유럽, 중동, 아프리카에서 선거를 위해.
  </TabItem>
</Tabs>

## 각 가상 네트워크에 할당

가상 네트워크 만들기 후, 각 가상 네트워크에서 개인 네트워크 CIDR을 경로. 이로 인해 사용자는 IP를 사용하지 않는 네트워크에 모든 서비스를 도달할 수 있습니다.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    1. 오시는 길**네트워크** > **연결관** > **사이트맵 연락처**.
    2. 터널 라우팅 선택`10.0.0.0/8`, 다음 선택**설정하기**.
    3. 오시는 길**개인 네트워크**. 선택`10.0.0.0/8`경로.
    4. 내 계정**추가 설정**, 당신의 첫번째 가상 네트워크를 선택하십시오. 예를 들어,`vnet-AMER`.
    5. 제품정보**개인 네트워크**.
    6. 오시는 길`10.0.0.0/8`다른 가상 네트워크 이상, 선택**개인 네트워크 추가**.
    7. 내 계정**CIDR 소개**, 입력`10.0.0.0/8`. 에서**추가 설정**, 당신의 두번째 가상 네트워크를 선택하십시오. 예를 들어,`vnet-EMEA`.
    8. 제품정보**개인 네트워크**.
    9. 각 가상 네트워크에 대해 6-8을 반복합니다.
    10. 관련 기사**네트워크** > **연락처**. 각 개인 네트워크 갱도 노선을 위한 2-9를 반복하십시오.
  </TabItem>

  <TabItem label="사이트맵">
    1. 개인 네트워크 경로에 첫 번째 가상 네트워크 할당. 예를 들어, 할당`vnet-AMER`터널로 가는 길`10.0.0.0/8`:

       <APIRequest
         path="/accounts/{account_id}/teamnet/routes/{route_id}"
         method="PATCH"
         json={{
         		network: "10.0.0.0/8",
         		tunnel_id: "<TUNNEL_UUID>",
         		virtual_network_id: "<VNET_AMER_UUID>",
         	}}
       />

       더 많은 정보를 원하시면, 참조[터널 경로 업데이트](/api/resources/zero_trust/subresources/networks/subresources/routes/methods/edit/).

    2. 각 가상 네트워크에서 이 프로세스를 반복합니다. 예를 들면:

       <APIRequest
         path="/accounts/{account_id}/teamnet/routes/{route_id}"
         method="PATCH"
         json={{
         		network: "10.0.0.0/8",
         		tunnel_id: "<TUNNEL_UUID>",
         		virtual_network_id: "<VNET_EMEA_UUID>",
         	}}
       />

    3. 각 개인 네트워크 터널 경로에 대해 1-2 단계 반복.
  </TabItem>
</Tabs>

개인 네트워크에 연결된 각 터널은 각 가상 네트워크가 할당되어 있어야 합니다. 예를 들어 터널 라우팅이 있다면`10.0.0.0/8`·`192.168.88.0/24`, 갱도 둘 다 있어야 합니다`vnet-AMER`·`vnet-EMEA`가상 네트워크 할당.

| 관련 제품    | CIDR 소개           | 가상 네트워크     |
| -------- | ----------------- | ----------- |
| **터널 1** | `10.0.0.0/8`      | `vnet-AMER` |
|          | `10.0.0.0/8`      | `vnet-EMEA` |
| **터널 2** | `192.168.88.0/24` | `vnet-AMER` |
|          | `192.168.88.0/24` | `vnet-EMEA` |

## 가상 네트워크 egress 정책 만들기

다음, Gateway egress 정책을 사용하여 각 가상 네트워크에 전용 egress IP를 할당합니다.

<Tabs syncKey="dashPlusAPI">
  <TabItem label="대시보드">
    1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**교통 정책** > **Egress 정책**.

    2. 제품정보**정책 추가**.

    3. 당신의 정책. 우리는 국가 또는 지역 교통을 포함하여 추천한다.

    4. 가상 네트워크 추가*가상 네트워크*옵션 정보 예를 들면:

       | 옵션 정보   | 회사연혁  | 제품정보      |
       | ------- | ----- | --------- |
       | 가상 네트워크 | 이름 \* | *vnet-미국* |

    5. 내 계정**IP 선택**, 선택**전용 Cloudflare egress IPs 사용**. 전용 IPv4 및 IPv6 주소를 선택하여 트래픽을 egress로 원합니다.

    6. 제품정보**공지사항**.

    7. 반복 단계 1-6 당신이 만든 각 가상 네트워크에 대한 별도의 egress 정책을 만들.
  </TabItem>

  <TabItem label="사이트맵">
    1. 해당 가상 네트워크와 일치하는 Gateway egress 정책을 추가하십시오. 예를 들면:

       <APIRequest
         path="/accounts/{account_id}/gateway/rules"
         method="POST"
         json={{
         		action: "egress",
         		description: "Egress via North America by connecting to vnet-AMER",
         		enabled: true,
         		filters: [
         			"egress"
         		],
         		name: "Egress AMER vnet",
         		precedence: 0,
         		traffic: "net.vnet_id == <VNET_AMER_UUID>",
         		rule_settings: {
         			egress: {
         				ipv4: "<DEDICATED_IPV4_ADDRESS>",
         				ipv4_fallback: "<SECONDARY_DEDICATED_IPV6_ADDRESS>", // Note: Typo in original JSON - suggests IPv6 for fallback
         				ipv6: "<DEDICATED_IPV6_ADDRESS>",
         			}
         		},
         	}}
       />

       더 많은 정보를 원하시면, 참조[Zero Trust 만들기 Gateway 규칙](/api/resources/zero_trust/subresources/gateway/subresources/rules/methods/create/).

    2. 반복 단계 1 당신이 만든 각 가상 네트워크에 대 한 egress 정책을 만들.
  </TabItem>
</Tabs>

각 정책은 다른 기본 전용 egress IP에 대응해야합니다.

## 가상 네트워크 egress 테스트

<Details header="Windows, macOS 및 Linux">
  1. 사용자의 장치에서 WARP 클라이언트에서 Zero Trust 조직에 로그인하십시오.

  2. 터미널에서, 다음 명령을 실행하여 기본 egress IP 주소를 확인합니다.

     ```sh
     curl ifconfig.me -4
     ```

     명령은 조직의 기본 egress IP를 출력해야 합니다.

  3. 클라이언트 GUI에서, 사용**사이트맵**만든 가상 네트워크로 전환하는 드롭다운.

     <Details header="버전 2026.1 및 이전">
       WARP 클라이언트에서 기어 아이콘을 선택하세요 >**가상 네트워크**.
     </Details>

  4. 실행하여 egress IP 주소를 확인합니다.`curl ifconfig.me -4`다시. 명령은 egress 정책에서 지정된 IP 주소를 출력해야 합니다.
</Details>

<Details header="iOS 및 Android">
  1. 사용자의 장치에서 Zero Trust 조직에 로그인하십시오. Cloudflare One Agent 앱.
  2. 브라우저에서 이동[ifconfig.me 지시어](https://ifconfig.me/). 조직의 기본 egress IP는**IP 주소**.
  3. Cloudflare 한 에이전트에서 이동**지원하다** > **연결 옵션** > **가상 네트워크**. 당신이 창조한 가상 네트워크를 선택하십시오.
  4. 단계 1에서 브라우저 페이지를 다시로드하여 egress IP 주소를 확인합니다. egress 정책에 명시된 IP 주소는**IP 주소**.
</Details>

사용자가 가상 네트워크에 연결되는 동안, 트래픽은 전용 egress IP를 통해 지정됩니다. 각 가상 네트워크가 올바른 IP로부터 egressing되는 것을 테스트하기 위해 이러한 단계를 반복 할 수 있습니다.

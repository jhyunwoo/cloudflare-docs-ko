## 3. 설치 스크립트 만들기

WARP 설치 및 등록을 자동화하는 쉘 스크립트를 사용할 수 있습니다. 다음 예제는 Ubuntu 24.04에서 WARP를 배포하는 방법을 보여줍니다.

1. 터미널에서 새로운`.sh`텍스트 편집기를 사용하여 파일. 예를 들면:
   ```sh
   vim install_warp.sh
   ```

2. 제품정보`i`삽입 형태를 입력하고 다음 줄을 추가하십시오:

   ```bash
   #!/bin/bash
   set -e

   #WARP 클라이언트 다운로드 및 설치
   function warp() {
   		curl -fsSL https://pkg.cloudflareclient.com/pubkey.gpg | sudo gpg --yes --dearmor --output /usr/share/keyrings/cloudflare-warp-archive-keyring.gpg
   		echo "deb [signed-by=/usr/share/keyrings/cloudflare-warp-archive-keyring.gpg] https://pkg.cloudflareclient.com/ $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/cloudflare-client.list
   		sudo apt-get update --assume-yes
   		sudo apt-get install --assume-yes cloudflare-warp
   }

   #WARP 배포 매개 변수로 MDM 파일을 만듭니다.
   function mdm() {
   	sudo touch /var/lib/cloudflare-warp/mdm.xml
   	cat > /var/lib/cloudflare-warp/mdm.xml << "EOF"
   <dict>
   		<key>auth_client_id</key>
   		<string>88bf3b6d86161464f6509f7219099e57.access</string>
   		<key>auth_client_secret</key>
   		<string>bdd31cbc4dec990953e39163fbbb194c93313ca9f0a6e420346af9d326b1d2a5</string>
   		<key>auto_connect</key>
   		<integer>1</integer>
   		<key>onboarding</key>
   		<false/>
   		<key>organization</key>
   		<string>your-team-name</string>
   		<key>service_mode</key>
   		<string>warp</string>
   </dict>
   EOF
   }

   #주요 프로그램
   warp
   mdm
   ```

3. Debian 또는 RHEL / CentOS를 사용하는 경우 수정`warp()`함수 그래서 그것은 올바른 설치[WARP 패키지](https://pkg.cloudflareclient.com/)OS를 위해.

4. 값 수정`mdm()`기능:
   1. 제품 정보`auth_client_id`·`auth_client_secret`, 클라이언트 ID 및 클라이언트 비밀과 문자열 값을 교체[서비스 토큰](/cloudflare-one/tutorials/warp-on-headless-linux/#1-create-a-service-token).
   2. 제품 정보`organization`, 교체`your-team-name`Zero Trust로<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>.
   3. (선택) 다른 추가 또는 수정[WARP 배치 매개 변수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/)p참고 자료s에 따라.

5. 제품정보`esc`, 다음 유형`:x`자주 묻는 질문`Enter`저장 및 출구.

## 4. WARP 설치

예를 들어 스크립트를 사용하여 WARP를 설치하려면:

1. 스크립트 실행 가능:

   ```sh
   chmod +x install_warp.sh
   ```

2. 스크립트를 실행:
   ```sh
   sudo ./install_warp.sh
   ```

WARP는 지금 안으로 저장된 윤곽 모수로 배치됩니다`/var/lib/cloudflare-warp/mdm.xml`. 분류[`auto_connect`](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/#auto_connect)WARP는 Zero Trust 조직에 자동으로 연결됩니다. 연결되면 장치가 나타납니다.[사이트맵 한국어](https://one.dash.cloudflare.com)이름 \***팀 & 자원** > **제품정보**자주 묻는 질문`non_identity@<team-name>.cloudflareaccess.com`.

많은 보안 팀은 Microsoft MCAS (Microsoft Cloud App Security), Microsoft의 CASB 솔루션에 의존하여 인터넷에서 위협을 확인하고 차단할 수 있으며 클라우드 애플리케이션에 액세스할 수 있습니다. 이 튜토리얼은 Cloudflare Zero Trust와 MCAS를 통합하는 방법을 다루고, Gateway HTTP 정책을 작성하여 데이터에 대한 가시성과 제어를 보장합니다.

Microsoft는 MCAS API 엔드포인트를 제공하여 해당 애플리케이션이 차단되거나 허용된 것으로 표시된 것을 볼 수 있습니다. MCAS API 호출을 통해 API 쿼리에 의해 반환된 블록 URL을 포함하는 URL 범주를 관리하고 게이트웨이 HTTP 정책에 의해 사용할 수있는 호스트 이름 목록을 생성하기 위해 출력을 사용합니다.

**완료 시간:**

20 분

## 기본 설정

Microsoft 계정에서 먼저 API 토큰과 URL 엔드포인트를 만들고 MCAS에 의해 차단된 URL을 쿼리할 필요가 있습니다.
자주 묻는 질문[Microsoft Cloud App Security용 API 토큰 관리](https://learn.microsoft.com/defender-cloud-apps/api-authentication)API 엔드포인트에 대한 새로운 API 토큰과 사용자 정의 API URL을 생성합니다.

## API를 사용하여 금지 된 응용 프로그램을 쿼리

API 토큰 및 API URL이 있으면 Microsoft MCAS에서 금지 된 응용 프로그램을 얻기 위해 컬을 사용하십시오.

```sh
curl -v "https://<MCAS API URL>/api/discovery_block_scripts/?format=120&type=banned" -H "Authorization: Token <API token>"
```

이것은 금지 된 hostnames의 목록을 반환합니다. 이 경우 Angie의 목록은 금지 된 응용 프로그램입니다.

![금지된 이름](~/assets/images/cloudflare-one/microsoft-mcas/mcas-domains.png)

### 출력 처리

볼 수 있듯이, 금지 된 hostnames는`.`. Zero Trust 명부를 위한 이 산출을 이용하기 위하여, 우리는 몇몇 원본 처리를 해야 합니다.

1. curl API 호출을 실행하고 파일에 출력을 직접, 이 경우`mcas.txt`:

   ```sh
   curl -v "https://<MCAS API URL>/api/discovery_block_scripts/?format=120&type=banned" -H "Authorization: Token <API token>" > mcas.txt
   ```

2. 주요 기능`.`, 예를 들어 실행`sed`CLI에서:

   ```sh
   sed -i 's/^.//' mcas.txt
   ```

3. 이것은 당신이 지도하지 않고 hostnames의 목록을 줄 것입니다`.`.

4. 파일 교체`.txt`확장과`.csv`. 파일은 이제 Cloudflare Zero Trust에 Hostname 목록에 가져올 수 있습니다.

## API를 사용하여 허용된 애플리케이션을 쿼리합니다.

MCAS 허용 응용 프로그램의 모든 목록을 얻으려면 동일한 API 쿼리를 사용할 수 있지만 사용 대신`type=banned`, 사용`type=allowed`. 이것은 훨씬 더 큰 명부를 돌려보낼 것입니다.

```sh
curl -v "https://<MCAS API URL>/api/discovery_block_scripts/?format=120&type=allowed" -H "Authorization: Token <API token>"
```

## Cloudflare One의 호스트 이름 목록 추가

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**재사용 가능한 부품** > **이름 \***
2. 제품정보**CSV 업로드**. 호스트 이름 목록이 CSV 형식이 아닌 경우에도 문제가 없습니다.
3. 목록의 이름을 추가, 지정*이름 \**&#xBAA9;록 유형으로, 그리고 그것을 설명합니다.
4. API 호출을 통해 생성 된 MCAS 출력 파일을 드래그하고 드롭하거나 선택할 수 있습니다.**파일 선택**.
5. 제품정보**이름 \***. 목록에 추가 된 호스트 이름 목록을 볼 수 있습니다.
6. 자주 묻는 질문

귀하의 목록은 이제 Gateway HTTP 정책에 의해 참고 자료d 될 준비가되어 있습니다.

## HTTP 정책 만들기

1. 오시는 길**교통 정책** > **교통 정책** > **HTTP: HTTP**.
2. 제품정보**정책 추가**.
3. 다음 정책을 작성합니다.

   | 옵션 정보 | 회사연혁   | 제품정보                 | - 연혁 |
   | ----- | ------ | -------------------- | ---- |
   | 이름 \* | 계정 만들기 | \<NEW HOSTNAME LIST> | 제품정보 |

이제 MCAS 정의 사이트 중 하나를 방문하려고 할 때 사용자는 차단됩니다.

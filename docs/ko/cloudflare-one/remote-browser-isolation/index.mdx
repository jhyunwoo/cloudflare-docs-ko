사이트맵 브라우저 고립은 보완[보안 웹 게이트웨이](/cloudflare-one/traffic-policies/)·[Zero Trust 네트워크 액세스](/cloudflare-one/networks/connectors/cloudflare-tunnel/)안전한 고립된 브라우저에서 Active 웹 페이지 콘텐츠를 실행하여 솔루션. endpoint에서 Active content를 원격으로 실행하면 Zero-day attacks 및 malware에서 사용자가 보호합니다. Endpoints를 보호하는 외에도 Browser Isolation는 사용자가 위험 웹 사이트에 입력하고 민감한 웹 응용 프로그램에 데이터 전송을 제어함으로써 피싱 공격으로부터 사용자를 보호합니다. Gateway와 분리된 트래픽을 더 필터링할 수 있습니다.[HTTP: HTTP](/cloudflare-one/traffic-policies/http-policies/)·[DNS 보호](/cloudflare-one/traffic-policies/dns-policies/)정책.

원격 브라우징은 선호하는 브라우저와 습관을 변경하지 않고 브라우저를 지속적으로 사용하는 사용자에게 보이지 않습니다. 모든 열린 탭과 창은 자동으로 격리되어 있습니다. 사용자가 고립 된 브라우저를 닫을 때 세션은 자동으로 삭제됩니다.

## 제품 정보

사이트맵 Browser Isolation는 보안 제품입니다. 투명한 격리된 브라우징과 차단 웹 기반 위협을 제공하기 위해 네트워크는 인터넷 트래픽을 사용하여 해독합니다.[Cloudflare 루트 CA](/cloudflare-one/team-and-resources/devices/user-side-certificates/). 교통 로그는 각각 유지됩니다.[사이트맵](/cloudflare-one/insights/logs/)문서.

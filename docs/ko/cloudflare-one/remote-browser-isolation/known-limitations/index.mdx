## 웹 사이트 호환성

우리의 네트워크 Vector Rendering (NVR) 기술은 비디오 스트림의 대역폭 제한없이 안전한 원격 컴퓨팅 경험을 제공 할 수 있습니다. 우리는 가장 웹 사이트를 완벽하게 작동 할 것으로 예상하지만, 일부 브라우저 기능과 웹 기술은 지원되지 않으며 미래에 구현 될 것입니다 :

- 웹캠 및 마이크 지원은 사용할 수 없습니다.
- WebGL을 사용하는 웹 사이트가 작동하지 않을 수 있습니다. 브라우저에서 WebGL을 끄려면, 참조[WebGL 렌더링 오류](/cloudflare-one/faq/troubleshooting/#i-see-webgl-rendering-error).
- Netflix 및 Spotify 웹 플레이어는 사용할 수 없습니다.
- H.265/HEVC는 이 시간에 지원된 영상 체재 아닙니다.

### 인기 카테고리

Brave의 WebRTC IP 처리 정책은 Cloudflare RBI 부하 및 기능에 어떻게 영향을 미칠 수 있습니다. WebRTC IP 처리 정책이 설정된 경우**Non-Proxied UDP 사용**, RBI는 제대로 로드할 수 없습니다.

RBI 부하를 올바르게 보장하려면`brave://settings/privacy`브라브 브라우저 창에서 찾기**WebRTC IP 처리 정책**, 설정 변경**Non-Proxied UDP 사용**다음 중 하나 :

- **기본 정보**
- **기본 공개 및 개인 인터페이스**
- **기본 Public Interface 전용**

## Protocol 지원

브라우저 고립은 HTTP를 지원하지 않습니다.

## 가상 머신

브라우저 고립은 가상화 환경에서 지원되지 않습니다 (VMs).

## Gateway 선택기

Gateway HTTP 정책 bypass Browser Isolation에 대한 특정 선택자, 포함:

- [대상 IP 위치](/cloudflare-one/traffic-policies/http-policies/#destination-continent)
- [대상 국가 IP 위치](/cloudflare-one/traffic-policies/http-policies/#destination-country)
- [대상 IP](/cloudflare-one/traffic-policies/http-policies/#destination-ip)

이 선택자를 사용하여 트래픽을 격리하고 이 선택자는 게이트웨이 로그에 표시되지 않습니다. 또한, 이 선택자에 따라 다른 정책을 적용할 수 없습니다. 예를 들어, 목적지 IP를 기반으로 트래픽을 일치하는 블록 정책을 가지고 있다면 게이트웨이는 Isolate 정책에 의해 이미 고립 된 경우 일치하는 트래픽을 차단하지 않습니다.

## 파일 다운로드 크기

사용자가 원격 브라우저 내에서 파일을 다운로드 할 때, 파일은 메모리에 보관하고 원격 브라우저 세션의 끝에 파괴됩니다. 따라서 세션 당 다운로드 한 파일의 총 크기는 원격 브라우저에서 사용할 수있는 메모리의 양과 공유됩니다. 우리는 512 MB의 최대 개별 파일 크기를 권장합니다.

## Multifactor 인증

[Clientless 웹 고립](/cloudflare-one/remote-browser-isolation/setup/clientless-browser-isolation/)Yubikey 또는 WebAuthN을 지원하지 않습니다. 이 인증 기술은 격리 된 웹 사이트를 필요로하지 않은 웹 사이트와 같은 도메인 이름을 사용합니다. 따라서, 그들은 prefixed Clientless 웹 고립 URL과 작동하지 않을 것입니다 그러나 일반적으로를 위해[in-line 배포](/cloudflare-one/remote-browser-isolation/setup/)등[고립된 접근 신청](/cloudflare-one/access-controls/policies/isolate-application/).

## SAML 응용

Cloudflare 원격 브라우저 고립 지금[SAML 응용 프로그램을 지원 HTTP-POST 바인딩](/cloudflare-one/changelog/browser-isolation/#2025-05-13). 이것은 이전 문제와 같은 해결`405`SSO 인증 흐름 동안 오류 및 로그인 루프.

더 이상 Identity Provider (IdP) 및 서비스 제공업체 (SP)를 격리하거나 HTTP-Redirect 바인딩으로 전환하여 POST 기반 SSO로 Browser Isolation을 사용합니다. 사용자는 격리된 브라우저에서 내부 또는 SaaS 애플리케이션에 안전하게 로그인할 수 있습니다.

[Clientless 웹 고립](/cloudflare-one/remote-browser-isolation/setup/clientless-browser-isolation/)아직도 몇몇 배치 모형에서 선호될지도 모릅니다. Clientless Web Isolation implicitly는 모든 트래픽 (IdP 및 SP)을 격리하고 HTTP-POST SAML 바인딩을 지원합니다.

Browser Isolation는 원격 브라우저에서 기본 Chromium Web Extension을 실행합니다.

이 기능은 DOM 액세스 (예 : 비밀번호 관리자 및 광고 차단기)가 격리 된 페이지를 확장하는 도구를 허용합니다.

## 원격 브라우저에서 확장 설치

### 필수품: Isolate Chrome 웹 스토어

:::참조

이 단계는 Clientless Web Isolation을 통해 탐색 할 때 필요하지 않습니다. Chrome Web Store에 액세스할 수 있습니다.`https://<authdomain>.cloudflareaccess.com/browser/https://chromewebstore.google.com/`.
:::

확장 설치는 Chrome 웹 스토어 고립을 요구합니다. 이름 \*[HTTP 정책](/cloudflare-one/traffic-policies/http-policies/)크롬 웹 스토어 (chromewebstore.google.com)를 격리하기 위해.

### 확장 설치

1. 오시는 길`https://chromewebstore.google.com/`격리된 동안.
2. 원하는 확장을 선택하십시오.
3. 제품정보**Chrome에 추가**. 확장 임명을 확인하기 위하여, 선택**추가 확장**.

원격 브라우저 확장은 격리된 세션을 통해 자동으로 재설치됩니다.

## 원격 브라우저에서 확장 제거

1. 고립 된 웹 페이지로 이동.
2. 컨텍스트 메뉴를 열고 선택하기**쇼 고립 연장통**.
3. isolation toolbar에서 jigsaw 아이콘을 선택하고 확장 관리자를 엽니 다.
4. 확장 컨트롤을 열려면 hamburger 아이콘을 선택하십시오.
5. 제품정보**크롬에서 제거**. 제거를 확인하기 위하여, 선택**기타 제품**.

## 유용한 확장

### 원격 브라우저 사용자 에이전트 수정

[Chrome용 User-Agent Switcher](https://chromewebstore.google.com/detail/user-agent-switcher-for-c/djflhoibgkdhkhhcedjiklpkjnoahfmg)원격 브라우저에서 고립 된 웹 사이트에 보낸 사용자 에이전트를 제어 할 수 있습니다.

### 원격 브라우저 요청 헤더

[모델 번호: ModHeader](https://chromewebstore.google.com/detail/modheader/idgpnmonknjnojddfkpgkljpfnnfcklj)원격 브라우저에서 격리된 웹 사이트에 전송된 임의 요청 헤더를 제어할 수 있습니다.

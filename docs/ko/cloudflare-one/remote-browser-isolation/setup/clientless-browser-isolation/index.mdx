## 필터 DNS 쿼리

게이트웨이 필터와 격리된 세션을 위한 DNS 쿼리를 해결[DNS 정책](/cloudflare-one/traffic-policies/dns-policies/). 기업 사용자는 창조해서 개인적인 결심자를 통해서만 유효한 도메인을 해결할 수 있습니다[해결사 정책](/cloudflare-one/traffic-policies/resolver-policies/).

Gateway DNS 및 해결자 정책은 항상 장치 구성에 관계없이 Clientless Web Isolation 트래픽에 적용됩니다.

## 원격 브라우저 사용

Clientless Web Isolation는 접두사 URL을 통해 구현됩니다.`<your-team-name>`조직의<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>.

```txt
https://<your-team-name>.cloudflareaccess.com/browser/<URL>
```

예를 들어, isolate`www.example.com`, 사용자는 방문할 것입니다`https://<your-team-name>.cloudflareaccess.com/browser/https://www.example.com/`그들의 선호한 브라우저에서.

이름 \*`<url>`제공되지 않습니다, 사용자는 Cloudflare Zero Trust 랜딩 페이지에서 대상 URL을 입력하거나 웹 사이트를 검색 할 수 있습니다.

## 옵션 구성

### 웹 사이트 허용

사용자가 웹 사이트를 방문 할 때[Clientless 웹 고립 URL](#use-the-remote-browser)Cloudflare 게이트웨이를 통과합니다. 이렇게 하면[HTTP 정책 적용](/cloudflare-one/traffic-policies/http-policies/)원격 브라우저가 연결할 수 있는 웹 사이트를 제어하기 위해 사용자의 장치가 WARP가 설치되어 있지 않는 경우에도 연결됩니다.

예를 들어, 타사 Secure Web Gateway를 사용하여 블록을 차단하는 경우`example.com`, 사용자는 아직도 먼 브라우저에서 페이지를 방문 할 수 있습니다`https://<your-team-name>.cloudflareaccess.com/browser/https://www.example.com/`. 구획에`https://<your-team-name>.cloudflareaccess.com/browser/https://www.example.com/`, Cloudflare 게이트웨이 HTTP 정책을 생성`example.com`:

| 옵션 정보 | 회사연혁 | 제품정보          | - 연혁 |
| ----- | ---- | ------------- | ---- |
| 이름 \* | 내 계정 | `example.com` | 제품정보 |

### 우회 TLS 해독

이름 \*[TLS 해독](/cloudflare-one/traffic-policies/http-policies/tls-decryption/)켜져 있는 Gateway는 Clientless Web Isolation URL을 통해 액세스된 모든 사이트를 해독합니다. TLS decryption과 호환되는 사이트와 연결하려면 Do Not Inspect HTTP policy for the application or domain.

| 옵션 정보 | 회사연혁  | 제품정보         | - 연혁      |
| ----- | ----- | ------------ | --------- |
| 이름 \* | 이름 \* | `mysite.com` | 검사하지 마십시오 |

:::참조

Clientless 웹 고립은 TLS 해독 없이 기능을 활성화할 수 있습니다. 그러나 TLS 해독은 적용해야 합니다.[HTTP 정책](/cloudflare-one/traffic-policies/http-policies/)Clientless Web Isolation 트래픽에.

:::

### 개인 네트워크

Clientless Web Isolation 으로 접속한 내부 웹 서버에 접속할 수 있습니다.[Cloudflare 갱도](/cloudflare-one/networks/connectors/cloudflare-tunnel/). 자세한 내용은 참조[개인 네트워크](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/).

예를 들어, 추가된 경우`192.168.2.1`당신의 갱도에, 사용자는 먼 브라우저를 통해 당신의 신청에 이동할 수 있습니다`https://<your-team-name>.cloudflareaccess.com/browser/http://192.168.2.1`. Clientless 웹 고립은 또한 개인적인 항구에 연결, 예를 들면 지원합니다`https://<your-team-name>.cloudflareaccess.com/browser/http://192.168.2.1:7148`.

:::참조

원격 브라우저에 액세스 할 수있는 모든 사용자는 게이트웨이 HTTP 정책을 차단하지 않고 Cloudflare 터널 응용 프로그램에 액세스 할 수 있습니다.

## 주소 바

Clientless Web Isolation에는 내장된 주소 표시줄이 있습니다. 이 기능은 수정된 URL을 가진 격리한 페이지를 방문하는 동안 사용자의 경험을 개량하기 위하여 디자인됩니다.

클라이언트 주소 표시 줄에는 세 개의 레이아웃이 있습니다: hostname notch, 전체 주소 표시 줄과 숨겨진. 사용자의 선택된 전망은 도메인과 원격 검색 세션을 통해 기억됩니다.

### 호스트명 notch view

기본적으로 고립 된 도메인 이름은 고립 된 페이지의 상단과 중심에 위치하지 않습니다.

![클라이언트의 원격 브라우저에서 격리된 페이지의 hostname 보기](~/assets/images/cloudflare-one/policies/rbi-address-bar-notch.png)

제품정보**지원하다**또는 호스트 이름 텍스트는 전체 주소 표시 줄에 노치를 확장합니다. 고립된 페이지 내용이 노치에 의해 방해되는 경우에, 전체 주소 표시에 확장은 접근 가능한 내용을 만들 것입니다.

### 전체 주소 표시

전체 주소 표시 줄은 사용자가 검색하고 고립 된 웹 사이트로 이동합니다. 사용자는 눌러서 언제든지 주소 표시 줄로 이동합니다.`CTRL + L`키보드에.

![클라이언트의 원격 브라우저에서 격리 된 페이지의 전체 주소를보기](~/assets/images/cloudflare-one/policies/rbi-address-bar-full.png)

### 자위 행위

주소 표시 줄을 끄려면 격리된 페이지를 마우스 오른쪽 단추로 클릭하고 선택**쇼 / 자주 묻는 질문**.

## 원격 브라우저로 이동 트래픽

Cloudflare WARP가 설치된 웹 사이트를 격리하고 싶다면 Clientless Web Isolation에 트래픽을 리디렉션해야합니다.[연락처](#use-the-remote-browser). 이것을 하는 방법 하나는 제삼자 Secure Web Gateway를 통해 이다. 원격 브라우저에 사용자를 리디렉션하려면 아래 예와 비슷한 사용자 정의 블록 페이지를 구현할 수 있습니다.

```html
<!DOCTYPE html>
<html>
	<head>
		<title>Redirecting website to a remote browser</title>
		<script>
			window.location.href =
				"https://<your-team-name>.cloudflareaccess.com/browser/<URL>}";
		</script>
		<noscript>
			<meta
				http-equiv="refresh"
				content="0; url=https://<your-team-name>.cloudflareaccess.com/browser/<URL>"
			/>
		</noscript>
	</head>
	<body>
		<p>
			This website is being redirected to a remote browser. Select
			<a href="https://<your-team-name>.cloudflareaccess.com/browser/<URL>"
				>here</a
			>
			if you are not automatically redirected.
		</p>
	</body>
</html>
```

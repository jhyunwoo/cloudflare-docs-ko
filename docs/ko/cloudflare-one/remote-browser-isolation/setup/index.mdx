Browser Isolation 를 통해 활성화[보안 웹 게이트웨이 HTTP 정책](/cloudflare-one/traffic-policies/http-policies/). 기본적으로, 트래픽은 HTTP 정책에 Isolate 정책을 추가 할 때까지 격리되지 않습니다.

## 1. Cloudflare에 장치를 연결합니다

설정 지침은 Cloudflare에 장치를 연결하는 방법에 따라 다릅니다. 아래 링크를 참조하여 각 배포 옵션을 설정 가이드를 볼 수 있습니다.

| 관련 링크                                                                                              | 주요 특징 | 이름 \*                                                                                          |
| -------------------------------------------------------------------------------------------------- | ----- | ---------------------------------------------------------------------------------------------- |
| [교통 및 DNS 모드](/cloudflare-one/traffic-policies/get-started/http/)                                  | 로그인   | WARP 클라이언트를 통한 트래픽에 대한 정체성 기반 HTTP 정책을 적용합니다.                                                  |
| [오시는 길](/cloudflare-one/access-controls/policies/isolate-application/)                             | 로그인   | 원격 브라우저에서 렌더링되는 ID 기반 HTTP 정책 적용.                                                              |
| [Gateway 프록시 엔드포인트](/cloudflare-one/remote-browser-isolation/setup/non-identity/)                  | 로그인   | 프록시 엔드포인트로 전달되는 트래픽에 비 ID HTTP 정책을 적용하십시오.                                                     |
| [Cloudflare 대만](/cloudflare-one/remote-browser-isolation/setup/non-identity/)                      | 로그인   | GRE 또는 IPsec 터널을 통해 연결된 트래픽에 비 ID HTTP 정책을 적용하십시오.                                             |
| [Clientless 원격 브라우저](/cloudflare-one/remote-browser-isolation/setup/clientless-browser-isolation/) | 연락처   | 원격 브라우저에서 웹 페이지를 렌더링 할 때 사용자가 이동`https://<your-team-name>.cloudflareaccess.com/browser/<URL>`. |

## 2. 고립 정책 구축

Browser Isolation 정책을 구성하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**교통 정책** > **방화벽 정책** > **HTTP: HTTP**.
2. 제품정보**정책 추가**그리고 정책의 이름을 입력합니다.
3. HTTP 정책 사용[회사 소개](/cloudflare-one/traffic-policies/http-policies/#selectors)·[채용 정보](/cloudflare-one/traffic-policies/http-policies/#comparison-operators)웹 사이트 또는 콘텐츠를 지정하려면 isolate를 원합니다.
4. 제품 정&#xBCF4;**- 연혁**, 선택[*사이트맵*](/cloudflare-one/remote-browser-isolation/isolation-policies/#isolate)또는[*격리하지 마십시오*](/cloudflare-one/remote-browser-isolation/isolation-policies/#do-not-isolate).
5. (선택 사항) 구성[제품정보](/cloudflare-one/remote-browser-isolation/isolation-policies/#policy-settings)Isolate 정책.
6. 제품정보**공지사항**.

다음 것,[귀하의 정책이 작업인지 확인](#3-check-if-a-web-page-is-isolated).

## 3. 웹 페이지가 격리된 경우 확인

사용자는 다음 방법 중 하나를 사용하여 웹 페이지가 격리 된 경우 볼 수 있습니다.

- 주소 표시줄에 있는 통제를 선택하고 Cloudflare Root CA의 존재를 검사하십시오.
- 웹 페이지를 마우스 오른쪽 버튼으로 클릭하고 상황에 맞는 메뉴 옵션을 볼 수 있습니다.

### 일반 검색

- 비 Cloudflare 루트 인증서는 Cloudflare이 웹 페이지를 프록시하지 않았다는 것을 나타냅니다.

  ![웹 사이트는 Cloudflare 루트 인증서를 제공하지 않습니다.](~/assets/images/cloudflare-one/rbi/non-cloudflare-root-ca.png)

- 오른쪽 클릭 컨텍스트 메뉴는 모두 정상적인 옵션이 있습니다.

  ![본문 바로가기](~/assets/images/cloudflare-one/rbi/non-isolated-browser.png)

### 연락처

- Cloudflare 루트 인증서는 Cloudflare 게이트웨이를 통해 트래픽을 proxied 나타냅니다.

  ![웹 사이트 Cloudflare 루트 인증서](~/assets/images/cloudflare-one/rbi/cloudflare-gateway-root-ca.png)

- 오른쪽 클릭 컨텍스트 메뉴가 단순화됩니다.

  ![브라우저에서 마우스 오른쪽 클릭 메뉴](~/assets/images/cloudflare-one/rbi/isolated-browser.png)

#### Disconnect 브라우저 고립

WARP 사용자는 일시적으로 원격 검색을 비활성화 할 수 있습니다[WARP 클라이언트 분리](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#lock-warp-switch)·
WARP가 분리되면 새로 고침된 페이지를 반환합니다.

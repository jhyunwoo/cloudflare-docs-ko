Cloudflare로 하나, 당신은 같은 on-ramps에서 HTTP 트래픽을 고립시킬 수 있습니다[프록시 엔드포인트](/cloudflare-one/networks/resolvers-and-proxies/proxy-endpoints/)또는[Cloudflare 대만](/cloudflare-wan/zero-trust/cloudflare-gateway/)(이전 매직 WAN). 이러한 on-ramps는 Cloudflare WARP에 로그인 할 필요가 없습니다.[ID 기반 정책](/cloudflare-one/traffic-policies/identity-selectors/)지원되지 않습니다.

:::참조

사용자 정체성을 기반으로 Isolate 정책을 적용하려면 설치해야 합니다.[WARP 클라이언트](/cloudflare-one/team-and-resources/devices/warp/)또는 수동으로 사용자가[Clientless 웹 고립](/cloudflare-one/remote-browser-isolation/setup/clientless-browser-isolation/)URL.
주요 특징

## non-identity 브라우저 고립 설정

1. [Cloudflare 인증서 설치](/cloudflare-one/team-and-resources/devices/user-side-certificates/)당신의 장치에.
2. 다음 중 하나를 사용하여 Gateway에 인프라를 연결하십시오.
   - 게이트웨이 프록시 엔드포인트에 대한 트래픽을 전달하기 위해 브라우저 구성[PAC 파일](/cloudflare-one/networks/resolvers-and-proxies/proxy-endpoints/).
   - 엔터프라이즈 사이트 라우터를 Gateway로 연결[Cloudflare WAN에 어떤 던지기 GRE 또는 IPsec 갱도](/cloudflare-wan/zero-trust/cloudflare-gateway/).
3. non-identity 브라우저 격리:
   1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**비밀번호** > **Browser isolation 설정**.
   2. 기타 제품**사용자 ID가 알 수없는 경우 격리 된 HTTP 트래픽**.
4. non-identity 빌드[HTTP 정책](/cloudflare-one/remote-browser-isolation/isolation-policies/)원격 브라우저에서 웹 사이트를 격리합니다.

Browser Isolation는 시각 장애 또는 비 영어 요구 사항이있는 사용자를 지원하는 기능을 제공합니다.

## 스크린 리더

고립된 브라우저에는 고립된 페이지의 내용을 확고하게 말하는 붙박이 스크린 독자가 있습니다.

### 화면 리더를 켜거나 끄기

내장 화면 리더를 켜거나 해제하려면 격리 된 페이지에 마우스 오른쪽 버튼으로 클릭하고 선택**오시는 길** > **이름 \*** / **Disable 스크린 독자**.

대안으로, 키보드 단축키를 사용하려면, press`CTRL + ALT + Z`.

## 한국어

고립 된 브라우저는 모든 언어로 키보드 입력을 지원합니다. 사용자는 diacritics (예를 들면,`á`또는`ç`) 또는 문자 기반 스크립트 (예, 중국어, 일본어, 한국어).

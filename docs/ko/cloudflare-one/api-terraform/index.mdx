API 또는 Terraform을 사용하여 Cloudflare Zero Trust 구성을 관리할 수 있습니다. 자세한 내용은 다음 링크 참조 :

- [API 참고 자료](/api/)
- [변형 공급자 참고 자료](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs)
- [문서에 대한 정보](/terraform/)

Cloudflare Zero Trust에 대한 자세한 API 및 Terraform 예제는 당사의[구현 가이드](/cloudflare-one/implementation-guides/)Cloudflare Zero Trust 문서 전체에 걸쳐.

## 읽기 전용 대시보드 설정

Super Administrators는 Cloudflare One 대시보드에서 읽기 전용으로 모든 설정을 잠금 할 수 있습니다. 읽기 전용 모드는 API 또는 Terraform을 통해 계정의 모든 업데이트가 이루어집니다.

읽기 전용 모드를 활성화하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**계정 설정** > **관리자 제어**.
2. 이름 \***읽기 전용 대시보드 설정**.

모든 사용자, 에 관계없이[사용자 권한](/cloudflare-one/roles-permissions/), UI를 통해 구성 변경을 방지합니다.

## Scoped API 토큰

Cloudflare Zero Trust의 정책 및 그룹 관리 관리자는 WAF 사용자 정의 규칙 또는 기타 Cloudflare 설정에 대한 책임있는 사람들로부터 다를 수 있습니다. Cloudflare Zero Trust 설정은 Cloudflare에서 다른 구성을 수정할 수 없는 범위의 API 토큰을 구성할 수 있습니다.

범위의 API 토큰을 만들 수 있습니다.[대시보드를 통해](/fundamentals/api/get-started/create-token/)또는[API를 통해](/fundamentals/api/how-to/create-via-api/). 사용 가능한 토큰 권한 목록을 위해, 참조[API 토큰 권한](/fundamentals/api/reference/permissions/).

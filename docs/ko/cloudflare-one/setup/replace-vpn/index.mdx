사이트맵 Cloudflare의 글로벌 네트워크와 Zero Trust Network Access (ZTNA)를 사용하여 기존 VPN을 대체합니다. 귀하의 장치와 리소스를 Cloudflare에 안전하게 연결한 후, 원격 사용자의 공격 표면을 줄이고 성능을 향상시킬 수 있도록 ID 및 컨텍스트에 기반한 모든 요청을 확인할 수 있습니다. 더 많은 배경을 위해, 참조[왜 VPN을 교체해야합니까?](/learning-paths/replace-vpn/concepts/why-vpn/)

이 작업을 설정하는 방법은 무엇입니까? 사용 사례를 일치하는 시나리오를 선택하십시오:

<CardGrid>
  <LinkTitleCard title="장치 to network" href="/cloudflare-one/setup/replace-vpn/device-to-network/" icon="laptop">
    원격 사용자를 보안을 통해 내부 애플리케이션 및 서비스에 연결
    연결. 개인 네트워크에 대한 원격 액세스를위한 최고의.
  </LinkTitleCard>

  <LinkTitleCard title="네트워크" href="/cloudflare-one/setup/replace-vpn/network-to-network/" icon="seti:db">
    Cloudflare를 통해 양방향으로 두 개 이상의 개인 네트워크를 연결합니다. 인기 있는
    사무실, 데이터 센터 또는 클라우드 환경을 연결하기 위해.
  </LinkTitleCard>
</CardGrid>

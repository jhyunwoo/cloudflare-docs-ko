원격 장치를 개인 네트워크에 연결하기 때문에 사용자는 기존 VPN의 보안 위험과 성능 병목없이 내부 애플리케이션 및 서비스에 안전하게 액세스 할 수 있습니다.

다른 연결 시나리오를 탐구하려면, 참조[VPN 설정](/cloudflare-one/setup/replace-vpn/).

이 가이드는 동일한 단계를 따릅니다**시작하기**내장 마법사에서[사이트맵 1개의 대시보드](https://one.dash.cloudflare.com).

## 어떻게 작동합니까?

[Cloudflare 갱도](/cloudflare-one/networks/connectors/cloudflare-tunnel/)개인 네트워크와 Cloudflare 사이의 아웃바운드 전용 연결을 만드는 네트워크 커넥터입니다. inbound 포트 또는 방화벽 변경은 없습니다.

더 보기<GlossaryTooltip term="WARP client">[WARP 클라이언트](/cloudflare-one/team-and-resources/devices/warp/)</GlossaryTooltip>각 사용자의 장치에 설치되는 앱입니다. Cloudflare와 터널을 통해 트래픽을 전달하므로 사용자는 어디에서나 내부 리소스에 도달 할 수 있습니다.

## 자주 묻는 질문

- Cloudflare 계정으로 Zero Trust 조직. 이 설정하지 않은 경우, 참조[시작하기](/cloudflare-one/setup/).
- 개인 네트워크에서 Linux, Windows 또는 macOS 장치가 터널을 실행합니다.
- Linux, Windows 또는 macOS 장치가 WARP 클라이언트를 설치합니다.

## 1 단계 : 터널 할당

사이트맵 터널은 자원과 Cloudflare 사이의 경계 연결을 설정합니다. 이것은 새로운 장치가 개인 네트워크에 도달 할 수있는 방법입니다. 현재 개인 네트워크에서 Windows, Mac 또는 Linux 장치에서 터널을 설치할 수 있습니다.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 선택**시작하기**탭.
2. 제품 정보**클라이언트 기반 또는 사이트로 VPN 교체**, 선택**시작하기**.
3. 제품 정보**장치 to network**, 선택**계속하기**.
4. 에 의해**개인 네트워크에 원격 장치를 연결**스크린, 선택**계속하기**.
5. 에 의해**터널 할당**스크린은 기존 터널을 선택하거나 새로운 것을 만들 수있는 드롭 다운을 사용합니다.
6. 제품정보**계속하기**.

## 단계 2: 당신의 갱도의 IP 범위를 놓으십시오

개인 네트워크의 IP 범위를 터널에 추가합니다. 이것은 내부 리소스를 원격 사용자가 도달 할 수있는 정의. 당신의 갱도는 Zero Trust 조직에 등록된 장치에서 이 범위에 교통을 받아들입니다.

1. IP 범위를 입력하십시오 (예를 들면,`10.0.1.0/24`).
2. 제품정보**계속하기**.

:::참조
IP 범위가 확실하지 않은 경우 라우터 또는 네트워크 설정을 확인하십시오.

## 3 단계 : 터널을 배포

설치하기`cloudflared`개인 네트워크의 장치에 연결하고 터널을 실행합니다. 이 서비스는 네트워크와 Cloudflare 사이의 안전한 연결을 만듭니다.

1. 장치의 운영 체제 및 아키텍처를 선택하십시오.

2. 설치 명령을 복사하고 장치에서 실행하십시오. Windows의 경우 관리자로 명령 프롬프트를 엽니다. 다른 모든 운영 체제의 경우 터미널 창을 사용하십시오.

   macOS의 경우 명령은 다음과 같습니다.

   ```sh
   brew install cloudflared && sudo cloudflared service install <YOUR_TUNNEL_TOKEN>
   ```

   Windows 및 Linux 용 대시보드는 다운로드 링크를 제공하고 선택한 아키텍처의 명령을 설치합니다. 더 많은 다운로드 옵션을 위해, 참조[다운로드](/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/).

3. 이름 \*`cloudflared`연결, 대시보드는 터널을 활성화합니다.

4. 제품정보**계속하기**.

## 단계 4: 장치를 따르십시오

Cloudflare를 통해 개인 네트워크에 장치를 연결할 수있는 장치 등록 제어. 이 단계에서, 당신은 이메일 주소를 제공하고 WARP 클라이언트를 설치하여 첫 번째 장치를 등록.

1. 첫 번째 장치를 등록하려면 이메일을 입력하십시오.
2. 장치의 운영 체제를 선택하십시오.
3. 제품정보**계속하기**WARP 클라이언트를 다운로드하거나 다운로드 링크를 복사하여 다른 장치에 전송합니다.
4. 제품정보**계속하기**.

:::참조
나중에 장치 등록 권한을 관리 할 수 있습니다.**팀 & 자원** > **제품정보**.
:::

## 5 단계 : WARP 설정 완료

장치에서 클라이언트 설치 마법사를 완료하십시오. 그런 다음 Zero Trust 조직에 클라이언트를 연결합니다. 포괄적 인 OS 별 지침을 위해, 참조[회사연혁](/cloudflare-one/team-and-resources/devices/warp/deployment/manual-deployment/).

1. Cloudflare를 여십시오 1개의 클라이언트. macOS에서 상태 표시줄에서 Cloudflare 아이콘을 선택합니다. Windows에서 시스템 트레이에서 Cloudflare 아이콘을 선택하십시오.

2. 에 의해**WARP를 사용하는 것은 무엇입니까?**&#xC2A4;크린, 선택**Zero Trust 보안**.

3. 신속한 팀 이름을 입력하세요. 귀하의 팀 이름은 Zero Trust 조직의 고유 식별자이며 조직이 생성되었을 때 설정되었습니다. 대시보드는 쉬운 참고 자료를 위한 이 스크린에 당신의 팀 이름을 표시합니다.

   :::참조
   팀 이름 찾기 또는 변경, 이동**계정 설정** > **팀 이름**선택하기**제품정보**.
   :::

4. 인증 단계 완료.

5. 클라이언트는 표시해야 합니다**연결하기**.

6. 제품정보**계속하기**대시보드에.

## 6 단계 : 연결 확인

대시보드는 안전하게 연결되는 것을 확인합니다. 이제 기기와 개인 네트워크 리소스 사이의 원격 액세스가 있습니다.

연결성을 확인하려면 개인 네트워크의 리소스에 도달하십시오 (예를 들어,`http://10.0.1.100`또는`ssh 10.0.1.50`).

## 다음 단계

연결 확인 후, 정책 및 액세스 제어와 개인 네트워크를 확보 고려:

- **Gateway 정책 설정**: 기본적으로 모든 등록 장치는 전체 개인 네트워크에 도달 할 수 있습니다. 게이트웨이 정책은 장치와 개인 네트워크 사이에 스캔, 필터 및 로그 트래픽을 제공합니다. 더 많은 정보를 원하시면, 참조[DNS 정책](/cloudflare-one/traffic-policies/dns-policies/), [네트워크 정책](/cloudflare-one/traffic-policies/network-policies/)·[HTTP 정책](/cloudflare-one/traffic-policies/http-policies/).
- **오시는 길**: ID 기반 규칙과 개인 네트워크의 특정 응용 또는 호스트 이름에 대한 제한. 더 많은 정보를 원하시면, 참조[개인 IP 또는 호스트 이름 보안](/cloudflare-one/access-controls/applications/non-http/self-hosted-private-app/).
- **Zero Trust에 더 많은 것을 탐험하십시오**: 터널, 정책 및 연결 장치 검토[사이트맵 1개의 대시보드](https://one.dash.cloudflare.com).

정책 설계 및 장치 자세 검사에 대한 심층적 인지도, 참조[VPN 학습 경로 변경](/learning-paths/replace-vpn/concepts/).

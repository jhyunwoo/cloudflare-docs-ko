[자주 묻는 질문](/cloudflare-one/faq/)

## Cloudflare 게이트웨이와 1.1.1.1의 차이점은 무엇입니까?

1.1.1.1은 DNS 쿼리를 차단하지 않습니다. example.com에 대한 브라우저 요청이 있을 때, 1.1.1.1은 캐시에 대한 답변을 보거나 전체 재큐브 DNS 쿼리를 수행하여 볼 수 있습니다.

사이트맵 Gateway의 DNS 해결자는 이 흐름에 보안을 도입합니다. 대신 모든 DNS 쿼리를 허용, Gateway first checks the hostname being queried against the Intelligence Cloudflare has about 위협에 대한 인터넷. 쿼리가 알려진 위협을 일치하거나 게이트웨이 정책의 일부로 관리자에 의해 구성 된 차단 된 도메인을 요청하는 경우 게이트웨이는 사용자가로드 할 수 있기 전에 중지합니다 - 그리고 잠재적으로 팀 구성원이 코드 또는 phish를 실행합니다.

## 멀티 요인 인증이 지원됩니까?

접근은 정체성 공급자에서 MFA 정책에 적용됩니다. 예를 들어, 액세스 보호 응용 프로그램에 로그인하려고하는 사용자는 Okta를 통해 로그인 할 수 있습니다. Okta는 Cloudflare Access에 대한 유효한 인증 확인을 보내기 전에 MFA 검사를 시행합니다.

액세스는 독립적 인 또는 아웃 밴드 MFA 기능이 없습니다.

## 어떤 브라우저가 지원됩니까?

이 브라우저는 지원됩니다:

- 인터넷 익스플로러 11
- Edge (현재 릴리스, 마지막 릴리스)
- Firefox (현재 릴리스, 마지막 릴리스)
- Chrome (현재 릴리스, 마지막 릴리스)
- Safari (현재 릴리스, 마지막 릴리스)

## 어떤 데이터 현지화 서비스는 지원됩니까?

Cloudflare Zero Trust는 데이터 로컬라이제이션 스위트와 함께 사용할 수 있으므로 트래픽이 선택한 지역에서만 검사됩니다. 더 많은 정보를 원하시면[Data Localization Suite로 Zero Trust 사용](/data-localization/how-to/zero-trust/).

## Partial DNS(CNAME Setup)와 어떻게 터널을 사용할 수 있습니까?

Cloudflare는 두 가지 모드를 제공합니다.[전체 설정](/dns/zone-setups/full-setup/)도메인이 Cloudflare DNS 네임서버를 사용하고 있는 경우[부분 설정](/dns/zone-setups/partial-setup/)(또한 CNAME 설정으로 알려져) 도메인은 비 Cloudflare DNS 서버를 사용합니다.

Cloudflare 터널을 사용한 최고의 경험은 Cloudflare가 도메인의 DNS를 관리하고 새로 시작된 터널의 DNS 레코드를 자동으로 구성할 수 있기 때문에 Full Setup을 사용하고 있습니다.

당신은 여전히 부분 설정 터널을 사용할 수 있습니다. Cloudflare 터널을 통해 연결된 각 새로운 호스트 이름의 현재 DNS 공급자와 새로운 DNS 레코드를 만들 필요가 있습니다. DNS 레코드는 CNAME 또는 ALIAS를 입력해야 합니다. 레코드의 이름은 하위 도메인에 해당한다 (예를 들어.`example.com`또는`tunnel.example.com`) 그리고 기록의 가치는 있어야 합니다`subdomain.domain.tld.cdn.cloudflare.net`. (예:`example.com.cdn.cloudflare.net`또는`tunnel.example.com.cdn.cloudflare.net`)

## 터널을 사용할 때 서버가 보안 될 수 있습니까?

터널은 NAT 또는 방화벽 뒤에 앉아있는 인터넷에 웹 응용 프로그램을 노출 할 수 있습니다. 따라서 웹 서버를 그렇지 않으면 완전히 잠긴 것을 지킬 수 있습니다. 두 배 체크에 당신의 근원 웹 서버는 Cloudflare 외부 요청에 응답하지 않습니다 갱도는 당신이 명령 선에 netcat를 달릴 수 있는 달리는 동안:

```sh
netcat -zv [your-server's-ip-address] 80
netcat -zv [your-server's-ip-address] 443
```

서버가 여전히 그 포트에 응답하는 경우, 당신은 볼 것이다:

```txt
[ip-address] 80 (http) open
```

서버가 올바르게 잠겨있는 경우 다음을 볼 수 있습니다.

```txt
[ip-address] 443 (https): Connection refused
```

## Named Tunnel의 호스트명에 대한 어떤 기록이 생성됩니까?

Named Tunnels는 DNS 레코드를 통해 경로가 될 수 있으며, CNAME 레코드를 사용하여 포인트로 사용할 수 있습니다.`<UUID>.cfargotunnel.com`; 또는 짐 Balancing endpoints로, 또한 점에`<UUID>.cfargotunnel.com`.

## Cloudflare는 터널은 내 기원에 방문자 IP를 보내?

이름 \* Cloudflare 갱도를 사용할 때, 근원에 모든 요구는 내부로 만듭니다`cloudflared`그리고 근원.

외부 방문자 IP를 로그하려면 필요할 것입니다.[대안 방법을 구성](/support/troubleshooting/restoring-visitor-ips/restoring-original-visitor-ips/).

## 왜 'warp'와 'argo'는 어떤 유산 물질에 나타납니다?

사이트맵 터널은 이전에 베타 단계 동안 Warp라는 이름이었습니다. Warp가 Argo 제품군에 추가되면서 Argo Tunnel에 이름을 변경했습니다. 일단 우리는 더 이상 필요한 사용자를 구입 Argo 터널을 만들기 위해, 우리는 Cloudflare 터널로 Argo 터널을 변경.

## 삭제 된 터널을 복원 할 수 있습니까?

이름 \* 터널의 탈레를 할 수 없습니다. 터널이 로컬 관리되는 경우[`config.yaml`이름 \*](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/tunnel-useful-terms/#configuration-file)여전히 존재하고 동일한 구성으로 새로운 터널을 만들 수 있습니다. 터널이 원격으로 관리 된 경우 터널과 구성 모두 영구적으로 삭제됩니다.

## 어떻게 지원합니까?

Cloudflare 지원 팀에 연락하기 전에:

1. 특정 오류 메시지 및 / 또는 문제 행동에주의하십시오.

2. 견적 요청`cloudflared`업데이트[최신 버전](https://github.com/cloudflare/cloudflared).

3. 서버에서 관련된 오류/access 로그를 가집니다.

4. 필요한 설정[`--loglevel`](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/run-parameters/#loglevel)으로`debug`, 그래서 Cloudflare 지원 팀은 더 많은 정보를 얻을 수 있습니다`cloudflared.log`파일.

5. 당신의 이름[사이트맵 터널 진단 로그](/cloudflare-one/networks/connectors/cloudflare-tunnel/troubleshoot-tunnels/diag-logs/) (`cloudflared-diag-YYYY-MM-DDThh-mm-ss.zip`).

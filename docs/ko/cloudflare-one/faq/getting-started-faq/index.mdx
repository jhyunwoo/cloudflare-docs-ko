## Cloudflare Zero Trust에 가입하는 방법?

오늘 가입 할 수 있습니다.[이 링크](https://one.dash.cloudflare.com). onboarding 단계를 따르십시오, 팀 이름과 지불 계획을 선택하고, 다만 몇 분에 있는 당신의 네트워크를 보호하는 시작하십시오.

## 팀 도메인/팀 이름은 무엇인가요?

귀하의 팀 도메인은 Cloudflare 계정에 할당 된 고유 한 하위 도메인입니다. 예를 들어,`<your-team-name>.cloudflareaccess.com`. [팀 도메인 설정](/cloudflare-one/setup/#create-a-zero-trust-organization)Zero Trust 구성의 필수 단계입니다. 이것은 사용자가 Cloudflare Zero Trust 뒤에 보안 한 응용 프로그램을 찾을 수있는 곳입니다.[앱 실행기](/cloudflare-one/access-controls/access-settings/app-launcher/)- 로그인 요청을 만들 수 있습니다. 당신의 팀 도메인의 customizable 부분은 불립니다**팀 이름**. 당신은 당신의 팀 이름 및 팀 도메인을 볼 수 있습니다[사이트맵 한국어](https://one.dash.cloudflare.com/)이름 \***계정 설정**.

| 팀 이름             | 팀 도메인                                   |
| ---------------- | --------------------------------------- |
| `your-team-name` | `<your-team-name>.cloudflareaccess.com` |

귀하의 계정에서 Cloudflare 대시보드 SSO 기능을 사용할 경우 언제든지 팀 이름을 변경할 수 있습니다. Cloudflare 대시보드 SSO가 활성화되면 반드시 해야 합니다.[SSO를 해제](/fundamentals/manage-members/dashboard-sso/#change-your-zero-trust-team-name)팀 이름을 변경하기 전에.

:::참조

팀 이름이 사용되면 팀 도메인이 나중에 삭제되면 팀 이름은 모든 계정에서 재사용 할 수 없습니다. 팀 이름을 삭제하면 다시 사용할 수 없습니다. 팀 이름을 변경하거나 삭제하기 전에이 제한을 고려하십시오.

:::

:::카트로션\[Warning]

팀 이름을 변경하면 조직의 정체성 제공업체(IdPs) 및 WARP 클라이언트를 업데이트해야 합니다. 새 팀 이름을 반영하기 위해서는 실수 오류를 피해야 합니다.

### 왜 내 오래된 팀 이름은 여전히 로그인 페이지와 앱 실행기에 표시됩니다?

팀 이름을 변경 한 후 블록 페이지를 확인해야합니다, 로그인 페이지 및 App Launcher 설정은 새로운 팀 이름을 반영합니다.

팀 이름 변경이 블록 페이지에서 성공적으로 렌더링되도록 확인하려면 로그인 페이지 및 앱 실행기:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**주문 페이지** > **팀 이름 및 도메인**.
2. 자주 묻는 질문**계정 Gateway 블록 페이지**·**오시는 길**섹션, 다음 선택**계정 관리**처음 리뷰하고 싶습니다.
3. 평가에 가치**당신의 조직의 이름**새로운 팀 이름 일치.
4. 원하는 이름이 이미 표시되지 않은 경우, 원하는 팀 이름에 값을 변경하고 선택**제품 정보**.
5. 두 페이지 모두 보기 (**계정 Gateway 블록 페이지**·**오시는 길**설정하기**당신의 조직의 이름**당신의 원한 팀 이름으로.

App Launcher는 Access 로그인 페이지에서 동일한 팀 이름을 표시하므로 업데이트 할 필요가 없습니다.**당신의 조직의 이름**App Launcher 페이지의 필드.

## 구독 계획은 어떻게 변경합니까?

구독에 변경하려면 아래 청구 섹션을 방문하십시오.**계정 설정**내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/). 언제든지 구독을 변경하거나 취소할 수 있습니다. 다만 기억하십시오 - 청구 주기 도중 당신의 계획을 내리면, 당신의 downgraded 가격은 다음 청구 주기에서 적용합니다. 청구 사이클 동안 업그레이드하면 업그레이드 된 플랜에 청구됩니다.

## 어떻게 측정됩니까?

Cloudflare Zero Trust 구독은 계정이 소모한 좌석으로 구성됩니다. 사용자가 응용 프로그램에 인증하거나 WARP에 에이전트를 등록 할 때, 그들은 활성 좌석 중 하나를 계산합니다. 좌석 추가, 제거, 또는 수정**계정 설정** > **사이트맵 1개의 계획**. 모든 좌석이 현재 소모되면, 먼저 구매한 좌석 수를 감소시키기 전에 사용자를 제거해야합니다.

### 사용자 제거

사용자 좌석은 액세스 및 게이트웨이를 제거 할 수 있습니다.**팀 & 자원** > **이름 \*** > **당신의 사용자**. 사용자를 제거하면 액세스 및 게이트웨이에 모두 결과를 얻을 수 있습니다.

- **오시는 길**: 해당 사용자의 모든 활성 세션은 유효하지 않습니다. 사용자가 만들면 응용 프로그램에 다시 로그인 할 수 있습니다.[오시는 길](/cloudflare-one/access-controls/policies/)그 사용자로부터의 미래 로그인을 차단합니다.

- **오시는 길**: Zero Trust 조직의 모든 활성 장치는 WARP 클라이언트를 통해 모든 필터링 및 라우팅을 중지합니다. 사용자가 만들면 기기를 다시 시작할 수 있습니다.[장치 등록 정책](/cloudflare-one/team-and-resources/devices/warp/deployment/device-enrollment/)그들을 막기.

:::카트로션

제거 작업은 사용자의 좌석을 제거하지만 영구적으로 인증 할 수있는 능력을 수정하지 않습니다. 영구적으로 인증 할 수있는 사용자의 능력을 비활성화하려면 주어진 응용 프로그램에 도달하거나 WARP에 장치를 등록 할 수있는 정책을 수정해야합니다.

:::

### 사용자 정의

Revoke 액션은 활성 세션을 종료하고 활성 장치를 로그하지만 활성 좌석의 사용자의 소비를 제거하지 않습니다.

## Cloudflare Zero Trust 뒤에 내 네트워크가 보호되는지 어떻게 알 수 있습니까?

당신은 방문 할 수 있습니다[Zero Trust 도움말 페이지](https://help.one.cloudflare.com/). 이 페이지는 귀하의 네트워크 세부 사항의 개요뿐만 아니라 개요가 차단되고 / 또는 허용되는 카테고리의 개요를 제공합니다.

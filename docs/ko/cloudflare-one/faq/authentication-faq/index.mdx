[자주 묻는 질문](/cloudflare-one/faq/)

## 동시에 여러 ID 공급자와 함께 액세스 할 수 있습니까?

예. 당신의 팀은 동시에 파트너 또는 계약자와 일할 때 마찰을 감소시키는 다수 공급자를 이용할 수 있습니다. Zero Trust의 로그인 방법으로 선호하는 ID 제공업체를 추가하여 시작하세요. 그런 다음 액세스 뒤에 새로운 응용 프로그램을 확보 할 때, 당신은 사용자가 응용 프로그램에 도달하기 위해 로그인 할 수있는 공급자를 선택할 수 있습니다.

## 내 팀의 정체성 공급자가 나열되지 않은 경우?

Cloudflare에 선호한 ID 공급자를 추가할 수 있습니다 Zero Trust에 나열되지 않은 경우에도 이러한 공급자 지원 SAML 2.0 또는[OpenID 연결 (OIDC)](/cloudflare-one/integrations/identity-providers/generic-oidc/).

## 사용자가 액세스에 의해 보호 된 응용 프로그램을 로그 아웃하는 방법?

액세스는 사용자의 현재 세션을 종료하는 URL을 제공합니다.

액세스 응용 프로그램에서 로그를 강제하려면:

`<your-application-domain>/cdn-cgi/access/logout`

앱 실행 세션에서 로그아웃하려면:

`<your-team-name>.cloudflareaccess.com/cdn-cgi/access/logout`

더 많은 정보를 원하시면,[세션 관리 페이지](/cloudflare-one/access-controls/access-settings/session-management/#log-out-as-a-user).

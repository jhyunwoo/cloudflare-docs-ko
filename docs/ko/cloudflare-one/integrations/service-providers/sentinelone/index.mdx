## SentinelOne을 서비스 제공업체로 설정

### 1. SentinelOne 설정 얻기

다음 SentinelOne 값은 SentinelOne 자세 검사를 설정해야 합니다.

- API 토큰
- REST API URL

그 값을 검색하려면:

1. SentinelOne Dashboard에 로그인하십시오.
2. 오시는 길**계정 설정** > **이름 \*** > **새 서비스 사용자 만들기**.
3. 제품정보**새 서비스 사용자 만들기**.
4. 이름 \***이름 \***·**만료일**선택하기**이름 \***.
5. 설치하기**오시는 길**으로*더 보기*.
6. 제품정보**사용자 정의**. SentinelOne은 이 사용자에게 API 토큰을 생성합니다.
7. 제출하기**API 토큰**안전한 위치에.
8. 제품정보**이름 \***.
9. 제출하기**나머지 API URL**브라우저의 주소 표시 줄에서 (예를 들어,`https://<S1-DOMAIN>.sentinelone.net`).

## 장치 자세 특성

장치 자세 데이터는 SentinelOne Management API에서 수집됩니다. 더 많은 정보를 원하시면, 참조`https://<S1-DOMAIN>.sentinelone.net/api-doc/overview`.

| 옵션 정보   | 이름 \*                                                                                                                 |
| ------- | --------------------------------------------------------------------------------------------------------------------- |
| 감염된     | 장치의 감염 여부                                                                                                             |
| 활동 위협   | 장치의 활성 위협 수                                                                                                           |
| 이름 \*   | SentinelOne Agent가 활성화된지 여부                                                                                           |
| 네트워크 상태 | SentinelOne 에이전트가 SentinelOne 서비스에 연결 여부                                                                              |
| 운영 국가   | 더 보기[운영 상태](https://community.sentinelone.com/s/login/?ec=302\&startURL=%2Fs%2Farticle%2F000005285)SentinelOne 에이전트의. |

### 개인 정보 보호 정책

SentinelOne은 endpoint 검출과 응답 (EDR) 신호를 제공하여 결정합니다.[사용자 위험 점수](/cloudflare-one/team-and-resources/users/risk-score/). 사용자의 위험 점수는 조직에 보안 위험을 제시하는 사용자를 감지 할 수 있습니다. 더 많은 정보를 원하시면, 참조[사전 정의된 위험 행위](/cloudflare-one/team-and-resources/users/risk-score/#predefined-risk-behaviors).

## 서비스 제공 업체로 Tanium 설정

### 1. Tanium 설정 받기

다음 Tanium 값은 Tanium 자세 검사를 설정해야합니다.

- 고객 비밀
- REST API URL

클라이언트 비밀을 검색하려면 API 토큰을 만듭니다.

1. Tanium 인스턴스에 로그인하십시오.
2. 오시는 길**주요사업** > **API 토큰**.
3. 제품정보**새로운 API 토큰 토큰**.
4. 설치하기**날에 만료**귀하의 조직에 적합한 값입니다. 이 토큰이 만료되면 모든 장치 자세 결과는 업데이트되지 않고 실패합니다.
5. 설치하기**신뢰할 수있는 IP 주소**으로`0.0.0.0/0`.
6. 제품정보**제품 정보**.
7. 제출하기**고객 비밀**안전한 장소에.

API URL을 검색하려면 Tanium Gateway 루트 엔드포인트를 결정하십시오.

- Tanium 클라우드:`https://<customerName>-api.cloud.tanium.com/plugin/products/gateway/graphql`
- Prem에 Tanium:`https://<server>/plugin/products/gateway/graphql`

## 장치 자세 특성

Device posture 데이터 수집[탄륨의 EndpointRisk API](https://developer.tanium.com/site/global/apis/graphql/spectaql/index.gsp#definition-EndpointRisk). 점수가 계산되는 방법에 대해 자세히 알아 보려면, 참조[Tanium 위험 점수 문서](https://help.tanium.com/bundle/ug_benchmark_cloud/page/benchmark/risk_score.html).

| 옵션 정보   | 이름 \*                                 | 제품정보                                                        |
| ------- | ------------------------------------- | ----------------------------------------------------------- |
| 총 점수    | `totalScore`장치의.                      | `1`으로`1000`                                                 |
| 위험 수준   | `riskLevel`장치의.                       | 낮은, 중간, 높은, 또는 긴요한                                          |
| 마지막으로 본 | 장치가 마지막으로 본 이래로 탈출된 시간`datetime`이름 \* | 마지막 1 시간에서, 3 시간, 6 시간, 12 시간, 24 시간, 7 일, 30 일, 또는 30 일 이상 |

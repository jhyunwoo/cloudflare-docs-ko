## 1. Microsoft Graph 설정 얻기

다음과 같은 값이 필요합니다:

- 고객 비밀
- 신청 (클라이언트) ID
- 직접 (제한) ID

그 값을 검색하려면:

1. Microsoft Dashboard에 로그인하십시오.
2. 오시는 길**앱 등록**선택하기**새로운 등록**.
3. 제출하기`Application (client) ID`안전한 장소에 가치. 클라이언트 ID가 될 것입니다.
4. 제출하기`Directory (tenant) ID`안전한 장소에 가치. 고객의 ID가 될 것입니다.
5. 오시는 길**인증서 및 비밀**선택하기**새로운 클라이언트 비밀**.
6. 설명에 채우고 비밀이 유효해야 하는 방법.
7. 양식을 작성한 후 즉시 결과 비밀을 복사합니다. 클라이언트 비밀이 될 것입니다.
8. 오시는 길**API 권한**선택하기**자주 묻는 질문**.
9. 제품정보**Microsoft 그래픽**.
10. 제품정보**신청 허가**.
11. 더 보기`DeviceManagementManagedDevices.Read.All`.
12. 권한 상태 표시**이름 \***, 선택**Grant 관리자 동의**.

## 장치 자세 특성

Microsoft Endpoint Manager 장치 자세 검사는 Microsoft Graph API의 정보에 의존합니다. Microsoft의 참조[규정 준수](https://docs.microsoft.com/en-us/graph/api/resources/intune-devices-compliancestate?view=graph-rest-1.0)·[회사연혁 제품정보](https://docs.microsoft.com/en-us/graph/api/intune-devices-manageddevice-list?view=graph-rest-1.0)API에 의해 반환된 속성 목록을 위한 문서.

ComplianceState를 제어하는 방법에 대해 자세히 알아 보려면 Microsoft의 참조[규정 준수 정책](https://docs.microsoft.com/en-us/mem/intune/protect/device-compliance-get-started).

## 서비스 제공업체로 Kolide 설정

### 1. Kolide에서 클라이언트 비밀 만들기

1. Kolide 대시보드에 로그인하십시오.
2. 프로필을 선택하고 이동**계정 설정** > **다운로드**.
3. 제품정보**새 키 만들기**.
4. 이름 \***주요 이름**선택하기**제품 정보**.
5. 제출하기**비밀 토큰**안전한 장소에. 클라이언트 비밀이 될 것입니다.

## 1. Uptycs 설정 얻기

다음 Uptycs 값은 Uptycs 자세 검사를 설정해야 합니다.

- 고객 키
- 고객 비밀
- 고객 ID

이 값을 얻기 위해:

1. Uptycs 콘솔을 엽니다.
2. 오시는 길**계정 설정** > **API 키**.
3. 생성 및 다운로드`.json`파일. 이 파일은 포함될 것입니다**고객 키**, **고객 비밀**·**고객 ID**.

## 1. Workspace ONE 설정 얻기

다음 작업 공간 ONE 값은 Workspace ONE 자세 검사를 설정해야 합니다.

- 고객ID
- 고객 비밀
- REST API URL
- 지역 - 특정 토큰 URL

그 값을 검색하려면:

1. 작업 공간에 로그인 한 대시보드.
2. 오시는 길**그룹 & 설정** > **제품 설명**.
3. 이름 \*`OAuth`검색 표시 줄에**이름 또는 범주를 입력**.
4. 제품정보**OAuth 고객 관리**결과에. OAuth 클라이언트 관리 스크린 전시.
5. 제품정보**더 보기**.
6. 값 입력**이름 \***, **이름 \***, **조직 그룹**·**사이트맵**.
7. 더 알아보기**주요연혁**이름 \***이름 \***.
8. 제품정보**제품 정보**.
9. 제출하기**고객 ID**·**고객 비밀**안전한 장소에.
10. REST API URL을 얻기 위해, gp tp**그룹 & 설정** > **모든 설정** > **시스템** > **(주)** > **사이트 URL** > **REST API URL**.
11. Workspace ONE에서 Region-Specific Token URL을 검색하고 안전한 장소에 복사하십시오.

## 서비스 제공 업체로 CrowdStrike 설정

### 1. CrowdStrike 설정 얻기

다음 CrowdStrike 값은 CrowdStrike 자세 검사를 설정해야 합니다.

- 고객 ID
- 고객 비밀
- 기본 URL
- 고객 ID

그 값을 검색하려면:

1. Falcon Dashboard에 로그인하십시오.
2. 오시는 길**지원 및 자원** > **API 클라이언트와 열쇠**.
3. 제품정보**API 클라이언트 만들기**클라이언트의 이름을 입력합니다.
4. 다음 API 권한에서 설정:
   | 관련 상품         | 제출    |
   | ------------- | ----- |
   | 이름 \*         | ...에서 |
   | Zero Trust 평가 | ...에서 |
5. 제품정보**이름 \***.
6. 제출하기**고객 ID**, **고객 비밀**·**기본 URL**안전한 장소에.
7. 오시는 길**호스트 설정 및 관리** > **센서 다운로드**자주 묻는 질문**고객 ID**.

## 장치 자세 특성

Device posture 데이터 수집[Crowd스트라이크 Zero Trust 평가 API](https://falcon.us-2.crowdstrike.com/documentation/156/zero-trust-assessment-apis). 점수가 계산되는 방법에 대해 자세히 알아 보려면, 참조[Crowd스트라이크 Zero Trust 연구분야](https://falcon.us-2.crowdstrike.com/documentation/138/zero-trust-assessment)문서.

| 옵션 정보   | 이름 \*                                               | 제품정보                                                        |
| ------- | --------------------------------------------------- | ----------------------------------------------------------- |
| 운영 체제   | OS 신호 점수                                            | `1`으로`100`                                                  |
| 제품정보    | 전체 ZTA 점수                                           | `1`으로`100`                                                  |
| 센서 설정   | 센서 신호 점수                                            | `1`으로`100`                                                  |
| 이름 \*   | ZTA 점수 버전                                           | `2.1.0`                                                     |
| 주요 특징   | 장치의 현재 온라인 상태                                       | *- 한국어*, *옵션 정보*, 또는*이름 \**                                 |
| 마지막으로 본 | 장치가 마지막으로 본 이후로 탈출 된 시간. 해당 국가가`online`또는`unknown`. | 마지막 1 시간에서, 3 시간, 6 시간, 12 시간, 24 시간, 7 일, 30 일, 또는 30 일 이상 |

OpenAI 통합은 다양한 데이터 손실 방지, 계정 구성 및 사용자 보안 위험을 감지하여 귀사와 조직 취약하게 떠날 수 있습니다.

이 통합은 OpenAI 제품을 포함합니다:

- ChatGPT 기업 (Workspaces)
- OpenAI 플랫폼 프로젝트 (API 키)
- GPTs (주문 GPTs)

:::참조
시작하기 전에, OpenAI가 ChatGPT Enterprise Compliance API 액세스를 활성화했습니다. 조직, 조직 ID 및 직장 ID에 대한 프로젝트 API 키가 필요합니다. 이것은 당신에 유효합니다[OpenAI 프로젝트 API 열쇠](https://platform.openai.com/settings/organization/projects).

준수 API 액세스가 아직 조직에 켜지지 않는 경우, 참조[Enable Compliance API 액세스](#enable-combliane-api-access).
:::

## 통합 필수

- ChatGPT Enterprise 작업 공간과 OpenAI 조직
- 조직 수준 관리자 권한 생성 및 관리 관리자 API 키
- (선택 사항) 프로젝트 API 키 및 해당 프로젝트 ID 스캔 범위에서 OpenAI 플랫폼 프로젝트를 포함 할 계획이라면

### Enable Compliance API 액세스

Compliance API 액세스는 OpenAI CASB 통합을 사용해야 합니다. 준수 API 액세스를 활성화하려면:

1. 제품정보`support@openai.com`조직에 대한 준수 API에 대한 액세스를 요청하고 API 키에 대한 Cloudflare CASB와 함께 사용할 것입니다. 귀하의 요청에 따라 다음을 포함합니다:
   - API 키의 마지막 4 문자
   - API 키의 이름
   - 열쇠를 창조한 사용자의 이름
   - 요청된 범위 (`read`, `write`또는 둘 다)
2. OpenAI는 열쇠를 확인하고 요청한 규정 준수 API 범위를 부여합니다.
3. 범위가 부여 된 후,[CASB에 OpenAI 통합 추가](/cloudflare-one/integrations/cloud-and-saas/#add-an-integration). 신속한 경우, Open AI Admin API 키, 조직 ID 및 Workspace ID (사용 가능`https://chatgpt.com/admin/settings`).

더 많은 정보를 원하시면, 참조[OpenAI 도움말 센터](https://help.openai.com/articles/9261474-compliance-api-for-enterprise-customers).

## 통합 권한

기능에 OpenAI 통합을 위해, Cloudflare CASB는 API 열쇠를 통해 뒤에 오는 허가를 요구합니다:

- `Admin API key (organization-level)`: ChatGPT Enterprise Compliance API에 의해 노출된 조직/워크스페이스 메타데이터, GPTs, 사용자, 초대 및 감사/컴플리스 오브젝트에 대한 읽기 전용 액세스.
- (선택)`Project API key (project-level)`: OpenAI 플랫폼 프로젝트 메타데이터 및 키에 대한 읽기 전용 액세스 권한을 부여합니다.

이 자격은 최소한의 권한만을 따르므로 최소한의 필수 액세스만 부여됩니다.

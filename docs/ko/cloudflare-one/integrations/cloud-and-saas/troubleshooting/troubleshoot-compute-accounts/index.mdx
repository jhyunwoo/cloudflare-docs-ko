Cloudflare CASB는 compute 계정이 건강하거나 outdated 때 검출합니다. 일반 계정 문제에는 보안 또는 기능 업데이트 및 API 토큰 구성이 포함됩니다.

## unhealthy compute 계정 식별

unhealthy compute 계정을 식별하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합** > **클라우드 및 SaaS 통합**.
2. 클라우드 스캔을 위해 만든 통합을 선택하십시오.
3. 제품정보**계정 관리**.

CASB는 이름 옆에 각 compute 계정의 상태를 표시합니다. compute 계정이 파손되거나 퇴각되면, CASB는 그 상태를 설정한다.**건강하다**. 상태가 있는 경우**제품 정보**, 활동은 요구되지 않습니다.

## 불쾌한 compute 계정 복구

CASB가 compute 계정을 표시할 때**건강하다**, CASB는 새로운 검사 윤곽 변화를 이용하지 않을 것입니다 새로운 검사 결과는 대시보드에 나타날 것입니다.

자주 묻는 질문**건강하다**, 첫째[compute 계정 업그레이드](#upgrade-a-compute-account). compute 계정이 여전히 건강하지 않다면,[API 토큰](#roll-api-tokens).

## Compute 계정 업그레이드

컴퓨팅 계정 업그레이드는 최신 소프트웨어 기능, 버그 수정 및 인프라 변경을 클라우드 컴퓨팅 계정에 적용합니다. Cloudflare에 의해 권장되는 날짜까지 compute 계정 소프트웨어를 유지하기 위해 정기적으로 업그레이드를 실행해야합니다. CASB는 Terraform 업데이트를 통해 계정 업그레이드를 배포합니다.

compute 계정을 업그레이드하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합** > **클라우드 및 SaaS 통합**.
2. 클라우드 스캔을 위해 만든 통합을 선택하십시오.
3. 제품정보**연결 지침**.
4. 로컬 Terraform 및 CLI 구성을 검증하는 지침을 따르십시오.
5. 이름 \***단계 2: 배포 Terraform 구성**, 템플릿을 로컬 구성에 복사합니다. 이 템플릿은 통합의 Terraform 구성의 최신 버전이 될 것입니다.
6. 로컬 터미널에서 CDS Terraform 모듈의 캐시 된 버전을 업데이트하십시오.
   ```bash
   terraform init --upgrade
   ```
7. 업그레이드 된 Terraform 구성을 계산 계정에 적용하십시오.
   ```bash
   terraform apply
   ```

Cloudflare에서 API 토큰을 롤하면 비밀 관리자에서 API 토큰 가치를 업데이트 할 수 있습니다.[Amazon 웹 서비스 (AWS)](https://docs.aws.amazon.com/secretsmanager/latest/userguide/manage_update-secret-value.html)또는[Google 클라우드 플랫폼 (GCP)](https://cloud.google.com/secret-manager/docs/edit-secrets).

### 일반 토큰 문제

#### `cloudflare-cds-secrets`compute 계정의 비밀 관리자에 존재하지 않습니다

당신의 compute 계정에 비밀을 재 작성하려면:

1. 올바른 지역을 선택했습니다.
2. [Compute 계정 업그레이드](#upgrade-a-compute-account)비밀을 재구성합니다.
3. [비밀 값 업데이트](#roll-api-tokens)계정에서.

#### 더 이상 Cloudflare API 토큰에 액세스 할 수 없습니다.

[Cloudflare API 토큰을 롤](#roll-api-tokens)당신의 compute 계정에 추가. 만약에[보상 계정의 상태](#identify-unhealthy-compute-accounts)설정**제품 정보**, 문제는 해결되었습니다.

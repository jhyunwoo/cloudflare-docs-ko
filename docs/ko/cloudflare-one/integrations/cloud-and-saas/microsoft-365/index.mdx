## 통합 권한

기능에 마이크로소프트 365 통합을 위해, Cloudflare CASB는 뒤에 오는 delegated 마이크로소프트 도표 API 허가를 요구합니다:

- `Application.Read.All`
- `Calendars.Read`
- `Domain.Read.All`
- `Group.Read.All`
- `InformationProtectionPolicy.Read.All`
- `MailboxSettings.Read`
- `offline_access`
- `RoleManagement.Read.All`
- `User.Read.All`
- `UserAuthenticationMethod.Read.All`
- `Files.Read.All`
- `AuditLog.Read.All`

이 권한은 최소한의 필수 액세스 만 부여되도록 최소한의 권한의 원칙을 따릅니다.

또한,[관련 기사](/cloudflare-one/cloud-and-saas-findings/manage-findings/#remediate-findings), CASB는 뒤에 오는 허가를 요구합니다:

- `Application.ReadWrite.All`
- `AuditLog.Read.All`
- `Calendars.ReadWrite`
- `Domain.ReadWrite.All`
- `Files.ReadWrite.All`
- `Group.ReadWrite.All`
- `InformationProtectionPolicy.Read.All`
- `MailboxSettings.ReadWrite`
- `IdentityRiskyUser.ReadWrite.All`
- `RoleManagement.ReadWrite.Directory`
- `User.ReadWrite.All`
- `UserAuthenticationMethod.ReadWrite.All`
- `Directory.ReadWrite.All`
- `GroupMember.ReadWrite.All`
- `Organization.ReadWrite.All`
- `Mail.ReadWrite`

각 권한에 대해 자세히 알아 보려면, 참조[Microsoft Graph 권한 문서](https://docs.microsoft.com/en-us/graph/permissions-reference).

## Microsoft 정보 보호 (MIP) 감도 상표

:::참조
이름 \*[Cloudflare 데이터 손실 방지 (DLP)](/cloudflare-one/data-loss-prevention/).
:::

Microsoft는 제공합니다[MIP 감도 상표](https://learn.microsoft.com/en-us/microsoft-365/compliance/sensitivity-labels?view=o365-worldwide)민감한 데이터를 분류하고 보호합니다. CASB Microsoft 365 통합을 추가 할 때 Cloudflare는 Microsoft 계정에서 라벨을 자동으로 검색하고 그들에 팝[DLP 프로필](/cloudflare-one/data-loss-prevention/dlp-profiles/integration-profiles/).

## 통합 필수

- Slack 사용자 계정
- Slack Workspace 회원 (무료, Pro, Business+, Enterprise Grid)
- Workspace 소유자와 같은 경우`Require App Approval`설정은 Workspace에 사용할 수 있습니다.[자주 묻는 질문](https://slack.com/help/articles/202035138-Add-apps-to-your-Slack-workspace)앱을 설치합니다.

## 통합 권한

기능에 Slack 통합을 위해 Cloudflare CASB는 뒤에 오는 Slack API 허가를 요구합니다:

- `channels:read`
- `files:read`
- `groups:read`
- `users:read`

이 권한은 최소한의 필수 액세스 만 부여되도록 최소한의 권한의 원칙을 따릅니다. 각 권한에 대해 자세히 알아 보려면, 참조[Slack 권한 범위 참고 자료](https://api.slack.com/scopes).

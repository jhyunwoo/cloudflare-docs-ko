## 통합 필수

- AWS S3(Simple Storage Service)를 사용하는 AWS 계정
- 초기 설정의 경우 AWS 계정에 액세스하여 아래에 나열된 범위와 새로운 IAM 역할을 만들 수 있습니다.

## 통합 권한

기능에 AWS S3 통합을 위해, Cloudflare CASB는 크로스 계정 접근을 가진 IAM 역할을 통해 뒤에 오는 접근 범위를 요구합니다:

- `s3:PutBucketNotification`
- `s3:GetObject`
- `s3:ListBucket`

이 권한은 최소한의 필수 액세스 만 부여되도록 최소한의 권한의 원칙을 따릅니다. 각 권한 범위에 대해 자세히 알아 보려면, 참조[AWS S3 권한 문서](https://docs.aws.amazon.com/AmazonS3/latest/userguide/using-with-s3-policy-actions.html).

## Compute 계정

수행하려면 AWS compute 계정을 CASB 통합에 연결할 수 있습니다.[데이터 손실 방지](/cloudflare-one/data-loss-prevention/)S3 물통 안에 검사하고 자료 egress를 피하십시오. CASB는 구성의 시간에 물통에 존재하는 어떤 목표를 검사할 것입니다.

통합에 하나의 컴퓨터 계정만 연결할 수 있습니다. compute 계정을 제거하려면, 선택**계정 관리**.

### 계정 스캔 구성

AWS compute 계정이 성공적으로 CASB 통합에 연결되면 어디를 구성하고 민감한 데이터를 스캔하는 방법 :

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**통합** > **클라우드 및 SaaS 통합**.
2. AWS 통합을 찾아보세요.
3. 제품정보**새 구성 만들기**.
4. 내 계정**지원하다**, 당신이 검사하고 싶은 물통을 선택합니다. 제품정보**계속하기**.
5. 파일 유형, 샘플링 비율을 선택하고[DLP 프로필](/cloudflare-one/data-loss-prevention/dlp-profiles/)검사하기.
6. (선택 사항) CASB에 대한 API 호출의 제한과 같은 추가 설정을 구성하여 준수합니다.
7. 제품정보**계속하기**.
8. 스캔의 세부 사항을 검토 한 다음 선택**스캔 시작**.

CASB는 스캐닝을 시작하는 시간까지 가지고 갈 것입니다. 스캔 결과를 보려면, 이동**클라우드 및 SaaS** > **콘텐츠 찾기**.

귀하의 리소스를 관리하려면**통합** > **클라우드 및 SaaS 통합**, 다음 AWS 통합을 찾습니다. 여기에서, 당신은 모든 또는 개별 스캔을 일시 중지 할 수, 추가 또는 리소스를 제거, 및 스캔 설정을 변경.

더 많은 정보를 원하시면, 참조[회사 소개](/cloudflare-one/cloud-and-saas-findings/manage-findings/#content-findings).

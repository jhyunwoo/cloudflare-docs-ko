## 통합 권한

기능에 Google Workspace 통합을 위해 Cloudflare CASB는 다음과 같은 Google API 권한을 요구합니다.

- `https://www.googleapis.com/auth/admin.directory.domain.readonly`
- `https://www.googleapis.com/auth/admin.directory.user.readonly`
- `https://www.googleapis.com/auth/admin.directory.user.security`
- `https://www.googleapis.com/auth/calendar`
- `https://www.googleapis.com/auth/cloud-platform.read-only`
- `https://www.googleapis.com/auth/drive.readonly`
- `https://www.googleapis.com/auth/gmail.settings.basic`

이 권한은 최소한의 필수 액세스 만 부여되도록 최소한의 권한의 원칙을 따릅니다. 각 권한에 대해 자세히 알아 보려면, 참조[Google Workspace 관리자 SDK 디렉토리 API](https://developers.google.com/admin-sdk/directory/v1/guides/authorizing).

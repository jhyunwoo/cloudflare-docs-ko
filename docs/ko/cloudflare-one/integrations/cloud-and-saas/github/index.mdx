## 통합 필수

- 무료, Pro 또는 Enterprise 플랜으로 GitHub 계정
- GitHub 조직에 회원 또는 GitHub 앱 관리자 권한

## 통합 권한

기능에 GitHub 통합을 위해 Cloudflare CASB는 다음 GitHub API 권한을 요구합니다.

| 제출    | 오시는 길       | 이름 \*                                      |
| ----- | ----------- | ------------------------------------------ |
| 주요사업  | `Read-only` | 계정의 기본 관리 정보 보기.                           |
| 이름 \* | `Read-only` | 조직 구성원의 메타데이터 보기                           |
| 메타데이터 | `Read-only` | 조직의 자산을 둘러싼 metadata보기, 민감한 개인 저장소 정보를 제외. |
| 회사연혁  | `Read-only` | 조직 설정에 대한 정보 보기                            |

이 권한은 최소한의 필수 액세스 만 부여되도록 최소한의 권한의 원칙을 따릅니다. 각 권한에 대해 자세히 알아 보려면, 참조[GitHub 앱 권한 참고 자료](https://docs.github.com/en/rest/overview/permissions-required-for-github-apps).

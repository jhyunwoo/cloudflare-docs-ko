:::참조

현재 Bitbucket의 CASB 통합은 Bitbucket Cloud 계정과 호환됩니다. Bitbucket Data Center에 대한 지원은 향후 날짜에 제공됩니다.

:::

## 통합 필수

- Bitbucket Cloud 계획 (무료, 표준, 프리미엄, 기업)
- 사이트 관리자 및/또는 조직 관리자 권한이있는 Bitbucket Cloud 계정에 액세스

## 통합 권한

기능에 Bitbucket Cloud 통합을 위해 Cloudflare CASB는 OAuth 2.0 앱을 통해 다음과 같은 권한 범위를 요구합니다.

- `account`
- `email`
- `issue`
- `pipeline`
- `project`
- `project:admin`
- `pullrequest`
- `repository`
- `repository:admin`
- `runner`
- `snippet`
- `webhook`
- `wiki`

이 권한은 최소한의 필수 액세스 만 부여되도록 최소한의 권한의 원칙을 따릅니다. 각 권한 범위에 대해 자세히 알아 보려면, 참조[Atlassian 범위 문서](https://developer.atlassian.com/cloud/bitbucket/rest/intro/#oauth-2-0).

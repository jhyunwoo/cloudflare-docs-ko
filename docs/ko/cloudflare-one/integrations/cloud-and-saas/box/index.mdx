## 통합 필수

- 비즈니스 계획의 Box 계정 (비즈니스, 비즈니스 플러스, 기업, 기업 플러스)

- Admin 권한으로 Box Business 계정에 액세스

## 통합 권한

기능에 상자 통합을 위해 Cloudflare CASB는 OAuth 2.0 앱을 통해 다음 박스 권한이 필요합니다.

- `Read all files and folders stored in Box`

이 권한은 최소한의 필수 액세스 만 부여되도록 최소한의 권한의 원칙을 따릅니다. 권한에 대한 자세한 내용을 보려면, 참조[Box Scopes 문서](https://developer.box.com/guides/api-calls/permissions-and-errors/scopes/#read-all-files-and-folders).

이번에 Jira의 CASB 통합은 Jira Cloud 계정과 호환됩니다. Jira Data Center 지원은 향후 날짜에 제공됩니다.
주요 특징

## 통합 필수

- Jira Cloud 플랜 (무료, 표준, 프리미엄, 기업)

- 사이트 관리자 및/또는 조직 관리자 권한을 가진 Jira Cloud 계정에 액세스

## 통합 권한

기능에 Jira Cloud 통합을 위해 Cloudflare CASB는 OAuth 2.0 앱을 통해 다음과 같은 권한을 요구합니다.

- `read:jira-work`
- `read:jira-user`

이 권한은 최소한의 필수 액세스 만 부여되도록 최소한의 권한의 원칙을 따릅니다. 각 권한에 대해 자세히 알아 보려면, 참조[Atlassian 범위 문서](https://developer.atlassian.com/cloud/jira/platform/scopes-for-oauth-2-3LO-and-forge-apps/).

## 통합 필수

- Dropbox Business 계획 (표준, 고급, 기업 또는 교육)
- 팀 관리자 권한으로 Dropbox Business 계정에 액세스

## 통합 권한

기능에 Dropbox 통합을 위해 Cloudflare CASB는 OAuth 2.0 앱을 통해 다음과 같은 Dropbox 권한이 필요합니다.

- `account_info.read`
- `files.metadata.read`
- `files.content.read`
- `sharing.read`
- `team_info.read`
- `team_data.member`
- `team_data.governance.write`
- `team_data.governance.read`
- `files.team_metadata.read`
- `members.read`
- `groups.read`
- `sessions.list`

이 권한은 최소한의 필수 액세스 만 부여되도록 최소한의 권한의 원칙을 따릅니다. 각 권한에 대해 자세히 알아 보려면, 참조[Dropbox API 권한 문서](https://developers.dropbox.com/oauth-guide#dropbox-api-permissions).

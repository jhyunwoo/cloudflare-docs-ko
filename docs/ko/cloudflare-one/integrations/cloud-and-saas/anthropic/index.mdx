이 통합은 다음 Anthropic 제품을 포함합니다:

- Claude 콘솔 (조직, 작업 공간/프로젝트, 사용자, 초대)
- Anthropic API 플랫폼 (조직 및 프로젝트 API 키)

## 통합 필수

- Anthropic, 인도[팀 또는 기업 조직](https://www.anthropic.com/pricing#team-&-enterprise)
- [Anthropic의 조직 수준 관리자 (또는 해당) 특권](https://support.anthropic.com/articles/10186004-api-console-roles-and-permissions)조직 메타데이터를 보고 API 키 관리

## 통합 권한

기능에 Anthropic 통합을 위해, Cloudflare CASB는 승인을 통해 요구합니다**API 키**:

- `Organization API key (organization-level)`: 조직/워크스페이스 메타데이터, 회원 및 초대 및 찾기에 사용되는 키 메타데이터에 대한 읽기 전용 액세스 권한을 부여합니다.
- (선택)`Project API key (project-level)`: 프로젝트 메타데이터 및 키에 대한 읽기 전용 액세스는 스캔에서 프로젝트 범위를 포함 할 때.

이 자격은 최소한의 권한만을 따르므로 최소한의 필수 액세스만 부여됩니다.

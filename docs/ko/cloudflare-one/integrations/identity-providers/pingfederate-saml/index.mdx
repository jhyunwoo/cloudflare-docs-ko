PingIdentity에서 제공하는 PingFederate는 SSO ID 관리를 제공합니다. 사이트맵 액세스는 SAML ID 공급자로 PingFederate를 지원합니다.

## PingFederate를 정체성 공급자로 설정

1. 로그인**핑거**대시보드로 이동**이름 \***.

2. 제품정보**회사연혁**.

3. 제품정보**새로운 SAML 신청**.

4. 이름, 설명 및 범주에 대한 필드를 완료합니다.

이것은 어떤 가치일 수 있습니다. signing 인증서를 선택하는 신속한 표시.

5. 내 계정**SAML 속성 구성**대화 상자**Email 속성** > **urn:oasis:names:tc:SAML:1.1:nameid-format:email주소**.

6. 오시는 길**SP 연결** > **SP 연결** > **회사 소개**.

7. Cloudflare SAML 구성에 업로드한 일치하는 인증서를 추가합니다. 제품정보**서명에 인증서를 포함`<KEYINFO>`이름 \***.

:::참조
9.0 이전에 PingFederate에 대한 추가 설정이 있습니다.
주요 특징

8. 내 계정**서명 정책**탭, 옵션을 비활성화**항상 로그인**.

9. 옵션 설정**자주 묻는 질문**.

SAML 대상 헤더가 통합 중에 전송되도록 합니다.

위의 버전 9.0에서는 이러한 옵션 모두 사용할 수 있습니다.

10. Ping에서 SAML 메타데이터를 다운로드하는 신속한 디스플레이.

이 파일은 Cloudflare와 여러 필드를 공유 이 데이터를 입력하지 않아도 됩니다.

11. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**통합** > **Identity 공급자**.

12. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

13. SAML 선택

14. 내 계정**IdP 기업 ID**필드, 다음 URL을 입력:

```txt
https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
```

15. Ping 대시보드에서 값을 가진 다른 필드를 채우십시오.

16. 제품정보**제품 정보**.

당신의 연결이 작동되는 것을 시험하기 위하여, 가기**인증현황** > **로그인 방법**선택하기**제품정보**테스트하려는 로그인 방법 옆에.

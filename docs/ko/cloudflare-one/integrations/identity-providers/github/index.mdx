사이트맵 한 팀이 GitHub 로그인을 사용하여 애플리케이션에 연결할 수 있습니다. GitHub 조직이 통합을 사용할 필요가 없습니다.

## GitHub 액세스 설정

GitHub 및 Cloudflare One에서 GitHub 액세스를 구성하려면:

1. 로그인[프로젝트](https://github.com/).

2. 계정으로 이동 >**계정 설정** > **Developer 설정**.

3. 내 계정**Developer 설정**, 선택**OAuth 앱**선택하기**새로운 OAuth 앱**.

4. 에 의해**새로운 OAuth 응용 프로그램 등록**페이지, 입력**신청 이름**. 사용자가 로그인 페이지에서 이 응용 프로그램 이름을 볼 수 있습니다.

5. 내 계정**홈페이지 URL**필드, 팀 도메인 입력:

   ```txt
   https://<your-team-name>.cloudflareaccess.com
   ```

   <Render file="find-team-name" product="cloudflare-one" />

6. GitHub에서**인증 콜백 URL**필드, 다음 URL을 입력:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
   ```

7. 제품정보**회원가입**.

8. 자주 묻는 질문**고객 ID**.

9. 제품정보**새로운 클라이언트 비밀 생성**안전한 장소에 클라이언트 비밀을 복사합니다.

10. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**통합** > **Identity 공급자**.

11. 제품정보**새로운 ID 공급자 추가**선택하기**프로젝트**.

12. 내 계정**앱 ID**, 입력**고객 ID**GitHub에서 취득 (8 단계).

13. 내 계정**고객 비밀**, 입력**고객 비밀**GitHub에서 취득 (9단계).

14. 제품정보**제품 정보**.

15. 제품정보**끝 설정**GitHub 권한 페이지를 시작합니다. Cloudflare 액세스에 다음 권한을 부여하도록 요청됩니다.
    - 조직 및 팀 (읽기 전용)
    - 이메일 주소(read-only)

16. 제품정보**이름 \***.

당신의 연결이 작동되는 것을 시험하기 위하여, 가기[사이트맵 한국어](https://one.dash.cloudflare.com) > **통합** > **Identity 공급자**선택하기**제품정보**GitHub 로그인 방법 GitHub 2단계 인증이 활성화된 경우 GitHub에 직접 로그인하고 액세스로 돌아가야 합니다.

:::주\[Troubleshooting 조직 정책]

GitHub 조직 정책을 사용할 때 사용자가 실패한 로그인 시도 후 필요한 조직에 가입하면 차단됩니다. 이 문제를 해결하려면 GitHub 설정에서 애플리케이션의 액세스를 수정하고 다시 로그인하여 권한을 업데이트해야합니다.

:::

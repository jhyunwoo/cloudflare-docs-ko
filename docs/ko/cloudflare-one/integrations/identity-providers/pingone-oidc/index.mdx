PingIdentity의 PingOne 클라우드 플랫폼은 SSO ID 관리를 제공합니다. 사이트맵 액세스는 PingOne을 OIDC 정체성 공급자로 지원합니다.

## PingOne을 OIDC 공급자로 설정

### 1. PingOne에서 응용 프로그램을 작성

1. PingIdentity 환경에서는**연결하기** > **이름 \***.

2. 제품정보**회사연혁**.

3. 이름 \***신청 이름**.

4. 제품정보**OIDC 웹사이트**그리고 그때**제품 정보**.

5. 제품정보**Resource 액세스**그리고 추가**이름 \***·**이름 \***&#xBC94;위.

6. 내 계정**제품 설명**탭, 선택**주요사업**.

7. 제출하기**고객 ID**, **고객 비밀**·**환경 ID**안전한 장소에. 이 ID는 나중에 Cloudflare One에 PingOne을 추가하는 데 사용됩니다.

8. 내 계정**제품 설명**탭, 연필 아이콘을 선택합니다.

9. 내 계정**리디렉션 URI**필드, 다음 URL을 입력:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
   ```

   <Render file="find-team-name" product="cloudflare-one" />

10. 제품정보**제품 정보**.

### 2. PingOne를 Cloudflare에 추가하십시오 한국어

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합** > **Identity 공급자**.
2. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.
3. 제품정보**핑원**.
4. 입력하기**고객 ID**, **고객 비밀**·**환경 ID**이전 버전
5. (선택) 사용[키 교환 증명 (PKCE)](https://www.oauth.com/oauth2-servers/pkce/). PKCE는 모든 로그인 시도에서 수행됩니다.
6. (선택) SCIM을 활성화하려면[사용자 및 그룹 동기화](/cloudflare-one/integrations/identity-providers/generic-oidc/#synchronize-users-and-groups).
7. (선택) 밑에**옵션 구성**, 입력[사용자 정의 OIDC 주장](/cloudflare-one/integrations/identity-providers/generic-oidc/#custom-oidc-claims)사용자의 정체성에 추가하고자 합니다.
8. 제품정보**제품 정보**.

지금 할 수 있습니다[연결 테스트](/cloudflare-one/integrations/identity-providers/#test-idps-in-cloudflare-one)그리고 창조[오시는 길](/cloudflare-one/access-controls/policies/)설정된 로그인 방법을 기반으로 합니다.

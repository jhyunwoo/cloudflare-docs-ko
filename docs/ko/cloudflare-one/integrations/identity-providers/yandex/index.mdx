Yandex는 ID 공급자 (IdP) 서비스를 제공하는 웹 검색 엔진입니다.

## Yandex 주차

Cloudflare 액세스의 Yandex를 설정하려면:

1. Yandex 계정에 로그인하십시오.

2. 제품정보**새로운 OAuth 응용 프로그램 열기**.

3. 제품정보**새로운 클라이언트**.

4. 필수 필드를 완료합니다.

5. 제품 정보**가격 비교 여권 API**기본 범위를 설정합니다.

6. 선택하기**자주 묻는 질문**, **사용자 avatar에 액세스,**·**사용자 이름, 이름 및 성, 성별에 대한 액세스**옵션.

7. 제품정보**회사연혁**선택하기**웹 서비스.**

8. 내 계정**콜백 URL #1**필드, 다음 URL을 입력:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
   ```

   ![Yandex 플랫폼 인터페이스 웹 서비스 체크 및 콜백 URI 오픈 양식 필드](~/assets/images/cloudflare-one/identity/yandex/yandex-3.png)

9. 제품정보**더 보기**.

10. 공지사항**플랫폼**카드 및 선택**제출하기**.

    **생산 라인**카드 제목**Cloudflare 액세스 앱**전시.

11. 제출하기**이름 \***·**비밀번호**.

12. Cloudflare에서 하나, 이동**통합** > **Identity 공급자**.

13. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

14. Yandex 선택.

15. 적절한 필드에 ID 및 암호를 붙여.

16. 제품정보**제품 정보**.

## API Config 예제

```json
{
	"config": {
		"client_id": "<your client id>",
		"client_secret": "<your client secret>"
	},
	"type": "yandex",
	"name": "my example idp"
}
```

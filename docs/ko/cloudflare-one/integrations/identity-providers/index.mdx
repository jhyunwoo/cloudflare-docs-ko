사이트맵 One은 Cloudflare One 및 Secure Web Gateway 정책을 적용하기 위해 조직의 정체성 공급자와 통합됩니다. 파트너, 계약자 또는 기타 조직과 함께 일하는 경우, 여러 정체성 제공업체를 동시에 통합할 수 있습니다.

ID 공급자를 구성하는 대안으로 Cloudflare 1개의 보낼 수 있습니다[1회 PIN (OTP)](/cloudflare-one/integrations/identity-providers/one-time-pin/)승인된 이메일 주소. 구성이 필요하지 않습니다 — 단순히 사용자의 이메일 주소를 추가[오시는 길](/cloudflare-one/access-controls/policies/)그리고 당신의 팀이 응용 프로그램에 도달 할 수있는 그룹에. OTP와 ID 공급자를 동시에 구성할 수 있습니다.

로그인 방법으로 ID 공급자를 추가하면 둘 다 설정이 필요합니다.[사이트맵 한국어](https://one.dash.cloudflare.com)그리고 정체적인 공급자로. IdP-specific 문서에 대해 자세히 알아보세요.

:::참조

사이트맵 관리자 계정, 오픈 소스 제공 업체 및 기업 공급자가 필요하지 않은 사회적 정체 공급자를 지원합니다. Cloudflare는 또한 SAML 공급자와 서명한 AuthN 요구를 사용하여 지원합니다.

:::

## Cloudflare에서 IdP를 시험하십시오 한국어

IdP가 올바르게 구성되는지 테스트하려면:

1. 오시는 길**통합** > **Identity 공급자**.
2. 제품정보**제품정보**IdP 옆에 테스트하고 싶습니다. IdP에 연결하여 유효한 연결이 설치되는지 확인합니다.

### 당신의 공급자는 연결됩니다

공급자가 연결되면 다른 창이 브라우저에서 열릴 것입니다. 이 메시지 :

!["당신의 연결 작품!" 성공적인 IdP 테스트에 표시된 메시지](~/assets/images/cloudflare-one/identity/connected-idp.png)

### 당신의 공급자는 연결되지 않습니다

공급자가 연결되지 않은 경우, 다른 창은 브라우저에서 열립니다. 오류 메시지와 함께 테스트가 실패한 이유에 대한 자세한 설명을 받게됩니다.

## API 사용

대시보드를 사용하여 ID 공급자를 구성하는 것이 좋습니다. 그러나, 당신이 사용하려는 경우[Cloudflare API를](https://api.cloudflare.com/), 여기에 포함 된 ID 공급자 주제의 각 예제 API 구성 스니펫뿐만 아니라.

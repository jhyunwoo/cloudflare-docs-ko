사이트맵 하나의 ID 공급자로 Okta와 SAML을 통합 할 수 있습니다.

## SAML 공급자로 Okta 설정

당신의 ID 공급자로 Okta를 가진 SAML를 설치하기 위하여:

1. 당신의 Okta admin 대시보드에, 가다**이름 \*** > **이름 \***.

2. 제품정보**App 통합 만들기**.

3. 팝업 대화 상자에서, 선택**삼성 2.0**그리고 그 후에 elect**이름 \***.

4. 앱 이름을 입력하고 선택**이름 \***.

   ![Cloudflare를 입력 하나의 콜백 URL로 Okta](~/assets/images/cloudflare-one/identity/okta-saml/okta-saml-1.png)

5. 내 계정**URL에 단일 기호**그리고**Audience URI(SP 엔티티티 ID)**&#xD544;드, 다음 URL을 입력:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
   ```

   <Render file="find-team-name" product="cloudflare-one" />

6. 내 계정**법적 고지**단면도는, 뒤에 오는 정보를 입력하십시오:
   - **이름 \***: 입력`email`.
   - **제품정보**: 입력`user.email`.

7. (선택) Okta 그룹을 사용하는 경우, 생성**그룹 특성**다음 정보:
   - **이름 \***: 입력`groups`.
   - **제품정보**: 선택*경기 regex*이름 \*`.*`.

![Okta의 속성 문 구성](~/assets/images/cloudflare-one/identity/okta-saml/okta-saml-2.png)

8. 제품정보**이름 \***.

9. 제품정보**내부 앱을 추가하는 Okta 고객입니다.**&#xC790;주 묻는 질문**이것은 우리가 만든 내부 응용 프로그램입니다**.

![Okta의 피드백 옵션 구성](~/assets/images/cloudflare-one/identity/okta-saml/okta-saml-3.png)

9. 제품정보**제품 정보**.

10. 내 계정**회사연혁**탭, 선택**이름 \***&#xAC1C;인 또는 그룹을 할당하여 액세스 권한을 부여합니다.

11. 제품정보**이름 \***. 할당된 개인 및 그룹은 표시될 것입니다**회사연혁**탭.

![개인 및 그룹을 Okta 신청 할당](~/assets/images/cloudflare-one/identity/okta-saml/okta-saml-4.png)

12. SAML 공급자 정보를 검색하려면**이름 \***&#xD0ED; 및 선택**Setup 지시어 보기**. 새 페이지가 표시됩니다.**ID 공급자 단일 로그인 URL**, **Identity 공급자 발행인**·**X.509 인증서**. Cloudflare 구성에 대한 이 정보를 저장 1개의 조정.

![Okta의 SAML 공급자 정보 검색](~/assets/images/cloudflare-one/identity/okta-saml/okta-saml-5.png)

13. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**통합** > **Identity 공급자**.

14. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**, 그리고 선택*사이트맵*.

15. 다음 정보를 입력:
    - **이름 \***: ID 공급자 이름.
    - **URL에 단일 로그인**: Okta에서 Identity Provider Single-Sign-On URL을 입력하십시오.
    - **발행자 ID**: Okta의 Identity Provider Issuer를 입력합니다.`http://www.okta.com/<your-okta-entity-id>`.
    - **표시 인증서**: Okta에서 X.509 인증서 복사.

16. (추천) 사용 가능**SAML 인증 요청**.

17. (추천)**SAML 속성**, 추가`email`·`groups`이름 \* 더 보기`groups`본 방침을 작성하려는 경우[Okta 그룹](/cloudflare-one/traffic-policies/identity-selectors/#okta-saml).

![Cloudflare One의 옵션 SAML 속성 추가](~/assets/images/cloudflare-one/identity/okta-saml/okta-saml-6.png)

18. 제품정보**제품 정보**.

당신의 연결이 작동되는 것을 시험하기 위하여, 가기**통합** > **Identity 공급자**선택하기**제품정보**Okta에. 성공 응답은 구성 된 SAML 속성을 반환해야합니다.

:::카트로션

SAML 속성은 Okta identity 공급자와 인증 중에만 새로 고침됩니다. Okta 그룹 회원은 WARP 클라이언트의 사용자 로그 및 아웃하지 않고 업데이트되지 않습니다. 또는 액세스 응용 프로그램에 로그인하십시오.

:::

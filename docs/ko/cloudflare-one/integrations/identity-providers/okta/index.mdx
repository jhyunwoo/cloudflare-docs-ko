Okta는 회사가 현대 애플리케이션에 사용자 인증을 관리하고 보안하는 데 도움이되는 클라우드 소프트웨어를 제공하며 개발자가 애플리케이션, 웹 사이트 서비스 및 장치로 ID 제어를 구축하는 데 도움이됩니다. Cloudflare One과 Okta를 통합하고 사용자 정체성과 그룹 회원을 기반으로 하는 규칙을 구축할 수 있습니다. 사이트맵 OIDC (과태) 또는[사이트맵](/cloudflare-one/integrations/identity-providers/okta-saml/)프로토콜.

또한 Cloudflare One의 위험 정보를 사용할 수 있는 Okta를 구성할 수 있습니다.[사용자 위험 점수](/cloudflare-one/team-and-resources/users/risk-score/)SSO 수준 정책을 만들 수 있습니다. 더 많은 정보를 원하시면, 참조[Okta에 위험 점수를 보냅니다](/cloudflare-one/team-and-resources/users/risk-score/#send-risk-score-to-okta).

## 자주 묻는 질문

- ·[사이트맵 회사연혁](/cloudflare-one/setup/)구독 계층과 함께 (무료 포함)
- ·[사이트맵 One 관리자 역할](/cloudflare-one/roles-permissions/)이름 \*`Access Edit`이름 \*

## 지원된 특징

- **SP 개시 SSO**: 사용자가 액세스 응용 프로그램에 갈 때 Access는 Okta와 로그인하는 것을 리디렉션합니다.
- **SCIM 제공**: Okta 그룹을 동기화하고 자동으로 사용자 정의. SCIM은 현재 별도의[사용자 정의 OIDC 응용](#synchronize-users-and-groups).

## OIDC 공급자로 Okta 설정 (Okta App Catalog)

:::note\[액티브 디렉토리 제한]
Okta App Catalog 템플릿은 동기화하지 않습니다.[Active Directory 그룹](https://help.okta.com/en-us/Content/Topics/Directory/ad-agent-import-groups.htm). AD 그룹을 사용하여 정책을 구축하려면 Okta를 사용하십시오.[OIDC 앱 통합](#set-up-okta-as-an-oidc-provider-custom-app-integration)또는[SAML 앱 통합](/cloudflare-one/integrations/identity-providers/okta-saml/).
:::

Okta Integration Network (OIN) 앱 카탈로그를 사용하여 Okta 통합을 설정하려면:

1. Okta admin 대시보드에 로그인하십시오.

## 사용자 및 그룹 동기화

Okta 통합은 IdP 그룹을 동기화하고 자동으로 사용자를 설정할 수 있습니다.[사이트맵](/cloudflare-one/team-and-resources/users/scim/). Access와 Okta 사이의 SCIM 규정을 활성화하려면 Okta에 두 개의 별도의 앱 통합이 필요합니다.

- OIDC 응용 프로그램을 사용하면 Okta를 정체 공급자로 추가 할 수 있습니다. 이 응용 프로그램을 만들 수 있습니다.[Okta 앱 카탈로그](#set-up-okta-as-an-oidc-provider-okta-app-catalog)또는 를 통해[사용자 정의 앱 통합](#set-up-okta-as-an-oidc-provider-custom-app-integration).
- 유형의 두 번째 Okta 응용**SCIM 2.0 테스트 앱 (Header Auth)**. 이것은 기술적으로 SAML 앱이지만 SCIM을 통해 사용자 및 그룹 정보를 전송하는 책임입니다.

:::참조
만약 하나의 Okta 앱 인스턴스만 유지한다면, Okta는 동일한 애플리케이션 내에서 SAML과 SCIM을 지원합니다. 이름 \*[SAML 통합](/cloudflare-one/integrations/identity-providers/generic-saml/)그 값을 설정한다.**이름 \***&#xB2F9;신의 Okta SCIM 신청의 분야.

오류를 볼 경우`Failed to fetch user/group information from the identity`, 두 배 체크 당신의 Okta 윤곽:

- 만약 100개 이상의 Okta 그룹이 있는 경우 API 토큰을 포함해야 합니다.
- 요청에 의해 차단 될 수있다[ThreatInsights 기능](https://help.okta.com/en/prod/Content/Topics/Security/threat-insight/ti-index.htm)Okta 안에.

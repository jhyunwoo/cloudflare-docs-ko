Active Directory는 Windows 도메인 네트워크에 Microsoft가 개발 한 디렉토리 서비스입니다. 대부분의 Windows Server 운영 체제에서 프로세스 및 서비스 세트로 포함되어 있습니다. Active Directory는 Security Assertion Markup Language를 사용하여 Cloudflare Access와 통합합니다 (<GlossaryTooltip term="SAML">사이트맵</GlossaryTooltip>).

## 시작하기 전에

시작하기에, 당신은 필요로 합니다:

- Active Directory 도메인 컨트롤러는 모든 사용자가 이메일 속성을 가지고 있습니다.
- Access Identity Provider (IdP)에 대한 일반적인 SAML 활성화.
- Active Directory Federation Services(AD FS)가 설치된 Microsoft 서버. 이 지침의 모든 스크린 샷은 Server 2012R2에 적용됩니다. 유사한 단계는 더 새로운 버전을 위해 일할 것입니다.
- Active Directory Federation Services (AD FS)에 대한 브라우저 안전 인증서.

위의 요구 사항을 충족하면 시작할 준비가되어 있습니다. Active Directory Federation Services (AD FS)의 설치 및 기본 구성은이 가이드의 범위 밖에 있습니다. 자세한 가이드는 찾을 수 있습니다.[마이크로소프트 KB](https://docs.microsoft.com/en-us/previous-versions/dynamicscrm-2016/deployment-administrators-guide/gg188612\(v=crm.8\)).

Cloudflare Access와 AD FS 사이의 연결을 시작하면 AD FS의 Relying Party Trust를 만듭니다.

## SAML 응답을 서명하는 AD FS 구성

AD FS가 Cloudflare와 통신 할 때 전체 응답을 표시하도록하려면 로컬**전력 공급**다음 명령을 입력하십시오:

```bash
Set-ADFSRelyingPartyTrust -TargetName "Name of RPT Display Name" -SamlResponseSignature "MessageAndAssertion"
```

## Cloudflare 구성 한국어

Cloudflare를 활성화 AD FS에서 보내지는 주장과 주장을 받아들이려면 다음 단계를 따르십시오.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**통합** > **Identity 공급자**.

2. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

3. 제품정보**사이트맵**.

4. IdP 소개**이름 \***.

5. 이름 \***URL에 단일 로그인**입력 :

   ```txt
   https://hostnameOfADFS/adfs/ls/
   ```

   기본값입니다. AD FS에서 federation 서비스 식별자를 찾을 수 있습니다.

6. 내 계정**ID 또는 발급 URL**필드, Cloudflare Zero Trust 팀 도메인을 입력하고 경로의 끝에이 콜백을 포함한다 :`/cdn-cgi/access/callback`. 예를 들면:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
   ```

7. 이름 \***서명 인증서**, 수출한 증명서를 풀기.

   텍스트 필드에 공백이나 반환 문자가 없습니다.

## SP 메타데이터 다운로드 (옵션)

일부 IdPs는 관리자가 SP (서비스 제공 업체)에서 메타 데이터 파일을 업로드 할 수 있습니다.

Cloudflare 메타데이터 파일을 얻으려면:

1. 다음 URL에서 고유 SAML 메타데이터 파일을 다운로드:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/saml-metadata
   ```

   Cloudflare에서 액세스, 이 URL에 대한 링크를 찾을 수 있습니다**SAML ID 공급자 편집**대화 상자 이 링크는 XML 형식으로 SAML SP 데이터로 웹 페이지를 반환합니다.

2. XML 형식으로 파일을 저장합니다.

3. XML 문서를 업로드**연락처**계정.

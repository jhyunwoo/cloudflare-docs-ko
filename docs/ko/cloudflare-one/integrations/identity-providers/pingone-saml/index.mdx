PingIdentity의 PingOne 클라우드 플랫폼은 SSO ID 관리를 제공합니다. 사이트맵 액세스는 PingOne을 SAML ID 공급자로 지원합니다.

## PingOne을 SAML 공급자로 설정

## 1. PingOne에서 응용 프로그램을 작성

1. PingIdentity 환경에서는**연결하기** > **이름 \***.

2. 제품정보**회사연혁**.

3. 이름 \***신청 이름**.

4. 제품정보**SAML 신청**.

5. 제품정보**설정하기**.

6. Cloudflare 액세스 메타 데이터를 입력하려면:

   1. 제품정보**URL에서 가져 오기**.
   2. 설정하기**URL 가져오기**에:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/saml-metadata
   ```

   이름 \*`<your-team-name>`Cloudflare는 한국어<GlossaryTooltip term="team domain">팀 이름</GlossaryTooltip>. 3. 선택**제품정보**. 4. **제품 정보**설정.

7. 내 계정**제품 설명**탭, 선택**metadata 다운로드**XML 메타데이터 파일을 저장합니다. 이 파일은 나중에 PingOne을 Cloudflare One에 추가하기 위해 사용됩니다.

8. 내 계정**Attribute 매핑**탭, 다음 필수 속성을 추가 (문자 민감한) 및 선택**제품 정보**.

   | Application 속성 | Outgoing 가치 |
   | -------------- | ----------- |
   | `email`        | 이메일 주소      |
   | `givenName`    | 이름 \*       |
   | `surName`      | 가족 이름       |

   이름 \*[SAML 속성](/cloudflare-one/integrations/identity-providers/generic-saml/#saml-attributes)Cloudflare 소개 사용자 접근.

9. 신청 설정**지원하다**.

### 2. PingOne를 Cloudflare에 추가하십시오 한국어

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합** > **Identity 공급자**.

2. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

3. 제품정보**사이트맵**.

4. PingOne XML 메타데이터 파일을 업로드합니다.

5. (선택) SCIM을 활성화하려면[사용자 및 그룹 동기화](/cloudflare-one/integrations/identity-providers/generic-saml/#synchronize-users-and-groups).

6. (선택) 밑에**옵션 구성**, 구성[추가 SAML 옵션](/cloudflare-one/integrations/identity-providers/generic-saml/#optional-configurations).

7. 제품정보**제품 정보**.

지금 할 수 있습니다[연결 테스트](/cloudflare-one/integrations/identity-providers/#test-idps-in-cloudflare-one)그리고 창조[오시는 길](/cloudflare-one/access-controls/policies/)구성된 로그인 방법 및 SAML 속성을 기반으로 합니다.

Keycloak은 JBoss에 의해 구축 된 오픈 소스 정체성 및 액세스 관리 솔루션입니다. 테스트를위한 Keycloak 실험실 환경이 필요한 경우, 참조[이 예제](https://github.com/mw866/tunnel-keycloak).

## Keycloak (SAML) 설정

Keycloak (SAML)를 정체성 공급자로 설정하려면:

1. Keycloak에서, 선택**고객 지원**내비게이션 바에서 새로운 클라이언트를 만듭니다.

2. 이름 \***고객 ID**, 다음 URL을 입력하십시오:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
   ```

   <Render file="find-team-name" product="cloudflare-one" />

   ![SAML 클라이언트 인터페이스 팀 도메인 및 클라이언트 ID에서 콜백](~/assets/images/cloudflare-one/identity/keycloak/configure-client.png)

3. 수정하기`Name ID Format`으로`email`

4. 다음, 사용중인 Keycloak 도메인에 유효한 리디렉션 URI를 설정합니다. 예를 들어,`https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback`.

5. 동일한 Keycloak 도메인을 사용하여 마스터 SAML 처리 URL을 설정합니다.`https://<keycloak_domain>/auth/realms/master/protocol/saml`.

6. 클라이언트 서명을 활성화하려면, 활성화`Client Signature Required`선택하기**제품 정보**.
   1. 당신은 필요[인증서를 얻기 위해 여기에 단계를 따르고 Cloudflare 대시보드에서 활성화하십시오.](/cloudflare-one/integrations/identity-providers/signed_authn/).

   2. 액세스 인증서를 가져 오기`SAML Keys`탭. 제품 정보`Certificate PEM`형식으로.

7. 내장 프로토콜 mapper를 설정`email`호텔 위치

   ![Protocol Mapper - 이메일 속성 설정](~/assets/images/cloudflare-one/identity/keycloak/protocol-mapper.png)

   다음 Cloudflare 액세스와 통합해야합니다.

8. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합** > **Identity 공급자**.

9. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

10. 제품 정보**사이트맵**다음 페이지에.

    Keycloak 세부 정보를 수동으로 입력해야합니다. 아래 예제는 Keycloak 및 Cloudflare Access와 함께 특정 도메인으로 대체되어야 합니다.

    | 제품정보         | 이름 \*                                                              |
    | ------------ | ------------------------------------------------------------------ |
    | 단일 로그인 URL   | `https://<keycloak_domain>/auth/realms/master/protocol/saml`       |
    | ID 또는 발급 URL | `https://<unique_id>.cloudflareaccess.com/cdn-cgi/access/callback` |
    | 서명 인증서       | Keycloak의 Realm Settings에서 X509 인증서를 사용하십시오.                       |

11. 제품정보**제품 정보**.

당신의 연결이 작동되는 것을 시험하기 위하여, 가기**통합** > **Identity 공급자**선택하기**제품정보**테스트하려는 로그인 방법 옆에.

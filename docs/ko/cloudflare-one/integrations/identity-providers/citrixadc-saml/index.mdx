사이트맵 SAML IdP로 Citrix ADC (이전 Citrix NetScaler ADC)와 통합 할 수 있습니다. Citrix의 문서는 당신을 보여줍니다[Citrix ADC를 SAML IdP로 구성하는 방법](https://docs.citrix.com/en-us/citrix-adc/12-1/aaa-tm/saml-authentication/citrix-adc-saml-idp.html). 이 단계는 Cloudflare 하나에 특정합니다.

## Citrix ADC (SAML) 설정

Citrix ADC (SAML)를 정체 공급자로 설정하려면:

1. 먼저 2 SAML 인증서를 구성해야 합니다.

   - 인증서에**vServer에서 TLS 종료**. 인증서가 공개적으로 신뢰할 수있는 CA에 의해 발급된다는 것을 보증합니다.
   - A 인증서**SAML 인증**.

   SAML assertions에 서명하는 인증서가 없으면 Citrix ADC에서 생성 된 자체 서명 인증서를 사용할 수 있습니다.

   1. 오시는 길**교통 관리** > **사이트맵**.
   2. 제품정보**Server Test 인증서 생성 및 설치**.

2. 제품정보**제품 설명**자주 묻는 질문**인증서 파일 이름**, **완전히 자격이 된 도메인 이름**, 그리고 선택**이름 \***.

   ![Citrix AD Create and Install Test Certificate interface with file name, 도메인 이름, 국가](~/assets/images/cloudflare-one/identity/citrixadc/citrixadc-saml-2.png)

3. 공개적으로 접근할 수 있는 인증 vServer를 생성하고 다음과 같은 사용자 ID 소스(like, Local user, LDAP)를 구성합니다.[Citrix 문서](https://docs.citrix.com/en-us/citrix-adc/12-1/aaa-tm/authentication-virtual-server/ns-aaa-setup-auth-vserver-tsk.html).

   이 예제의 나머지는, 사용자는 IdP 주소를 나타냅니다`idp.yourdomain.com`.

## 새 프로필 추가

1. 오시는 길**보안 보안** > **AAA - 신청 교통** > **회사연혁** > **인증현황** > **고급 정책** > **샘플 IDP**새 프로필을 추가합니다.

   다음 필수 구성 세부 사항 포함:

   | 제품정보                     | 이름 \*                                                                   |
   | ------------------------ | ----------------------------------------------------------------------- |
   | **이름 \***                | 정의 된 인증서 이름[SAML 구성](#set-up-citrix-adc-saml)                           |
   | **Assertion 소비자 봉사 URL** | `https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback` |
   | **IdP 인증서 이름**           | 정의 된 IdP 인증서 이름[SAML 구성](#set-up-citrix-adc-saml)                       |
   | **Issuer 이름**            | `https://idp.<yourdomain>.com/saml/login`                               |
   | **서비스 제공자 ID**           | `https://idp.<yourdomain>.com/saml/login`                               |
   | **이름 ID 체재**             | 이메일주소                                                                   |
   | **기여 1**                 | `email = AAA.USER.ATTRIBUTE("email")`                                   |

   사이트맵 현재 액세스는 IdP 주소로 전송합니다.*서비스 제공자 ID*AuthN 요청을 위해.

2. 프로필을 생성하고 위에서 언급 한 인증 vServer에 바인딩하는 인증 정책을 작성하십시오.

   ![Citrix AD 인증 SAML IDP 정책 구성](~/assets/images/cloudflare-one/identity/citrixadc/citrixadc-saml-4.png)

   CLI를 사용하여 위의 모든 구성하려면 다음을 실행하십시오.

   ```json
   add authentication samlIdPProfile samlProf_CloudflareAccess \
       -samlIdPCertName SAML_Signing \
       -assertionConsumerServiceURL "https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback" \
       -samlIssuerName "https://idp.yourdomain.com/saml/login" \
       -rejectUnsignedRequests OFF \
       -NameIDFormat emailAddress \
       -Attribute1 email \
       -Attribute1Expr "AAA.USER.ATTRIBUTE(\"email\")" \
       -Attribute1Format Basic \
       -serviceProviderID "https://idp.yourdomain.com/saml/login"

   add authentication samlIdPPolicy samlPol_CloudflareAccess -rule true -action samlProf_CloudflareAccess
   bind authentication vserver nsidp -policy samlPol_CloudflareAccess
   ```

3. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**통합** > **Identity 공급자**.

4. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

5. 다음과 같이 필드를 구성:

   | 제품정보                  | 이름 \*                      |
   | --------------------- | -------------------------- |
   | **이름 \***             | 선택된 이름                     |
   | **URL에 단일 로그인**       | IdP의 FQDN, 경로`/saml/login` |
   | **ID/Issuer URL을 입력** | 현재 위치                      |
   | **표시 인증서**            | NetScaler의 공개 인증서          |
   | **Email 속성 이름**       | 아래에 나열된**옵션 구성**           |

6. 제품정보**제품 정보**.

당신의 연결이 작동되는 것을 시험하기 위하여, 가기**통합** > **Identity 공급자**선택하기**제품정보**테스트하고 싶은 정체성 공급자 옆에.

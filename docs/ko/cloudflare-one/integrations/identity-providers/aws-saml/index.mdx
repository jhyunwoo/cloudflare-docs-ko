AWS IAM Identity Center는 AWS 리소스와 상호 작용하는 사용자를 위한 SSO ID 관리를 제공합니다 (EC2 인스턴스 또는 S3 물통과 같은). Cloudflare Zero Trust와 AWS IAM을 SAML ID 공급자로 통합할 수 있으며, AWS 자격 증명을 사용하여 Zero Trust에 인증할 수 있습니다.

## 자주 묻는 질문

- IAM Identity Center에 대한 관리 접근[조직 인스턴스](https://docs.aws.amazon.com/singlesignon/latest/userguide/identity-center-instances.html)

## AWS IAM을 SAML 공급자로 설정

AWS IAM을 정체 공급자로 설정하려면:

1. 자주 묻는 질문[IAM Identity Center 콘솔](https://console.aws.amazon.com/singlesignon)·**이름 \***.

2. 선택하기**고객 관리**탭.

3. 제품정보**앱 추가**.

4. 제품정보**내가 설정하려는 응용 프로그램이**.

5. 제품 정보**신청 유형**, 선택**삼성 2.0**.

6. 제품정보**이름 \***.

7. 이름 \***표시 이름**신청 (예를 들면,`Cloudflare One`).

8. 다운로드**IAM Identity Center SAML 메타데이터 파일**. Cloudflare One의 ID 공급자를 구성할 때 나중에 이 파일이 필요합니다.

9. 이름 \***신청 metadata**, 선택**metadata 값을 수동으로 입력**.

10. 내 계정**신청 ACS URL**·**SAML 청중**, 다음 URL을 입력하십시오:

```txt
https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
```

<Render file="find-team-name" product="cloudflare-one" />

11. 제품정보**제출하기**.

12. 다음, 선택**관련 기사**드롭다운 메뉴 및 선택*속성 맵핑 편집*.

13. 제품정보`Subject`user 속성, 입력`${user:email}`.

14. (추천) 사용자 이름 속성 추가:

| 사용자 속성      | 문자열 값                |
| ----------- | -------------------- |
| `name`      | `${user:name}`       |
| `surName`   | `${user:familyName}` |
| `givenName` | `${user:givenName}`  |

![IAM Identity Center의 속성 문 구성](~/assets/images/cloudflare-one/identity/aws/aws-saml-attributes.png)

15. 제품정보**비밀번호**.

16. 이름 \***사용자 및 그룹 할당**Cloudflare One에 로그인 할 수 있어야하는 개인 및 / 또는 그룹을 추가하십시오.

17. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**통합** > **Identity 공급자**.

18. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

19. 제품정보**사이트맵**.

20. 이름 \***이름 \***&#x49;dP 통합을 위한 (예를 들면,`AWS`).

21. 다운로드**IAM Identity Center SAML 메타데이터 파일**당신은 단계 8.에서 다운로드

22. (추천) 사용 가능[**SAML 인증 요청**](/cloudflare-one/integrations/identity-providers/generic-saml/#sign-saml-authentication-request).

23. 제품정보**제품 정보**.

으로[제품정보](/cloudflare-one/integrations/identity-providers/#test-idps-in-cloudflare-one)당신의 연결은 일하고, 선정합니다**제품정보**.

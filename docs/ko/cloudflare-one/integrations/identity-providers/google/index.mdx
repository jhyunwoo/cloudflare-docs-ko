Google Workspace 계정 없이 Cloudflare Access로 Google 인증을 통합할 수 있습니다. 통합은 Google 계정으로 로그인 할 수 있습니다 (if)[오시는 길](/cloudflare-one/access-controls/policies/)자원에 도달 할 수 있습니다. 자주 묻는 질문[Google 작업 공간](/cloudflare-one/integrations/identity-providers/google-workspace/)아래 단계는 Google Workspace 계정에서 그룹 회원 정보를 끌어 당길 수 없습니다.

Cloudflare One을 가진 ID 공급자로 Google을 통합하는 Google Cloud Platform 사용자가 될 필요가 없습니다. IdP 통합 설정을 구성하려면 Google Cloud Platform을 열 필요가 있습니다.

## ID 공급자로 Google 설정

1. Google Cloud Platform에 로그인[회사 소개](https://console.cloud.google.com/). 새 프로젝트 만들기, 프로젝트 이름, 선택**이름 \***.

2. 프로젝트 홈 페이지에서, 이동**API 및 서비스**사이드바 선택**회사 소개**.

3. 제품정보**Consent Screen 구성**.

   ![Google Cloud Platform 콘솔에서 일관된 화면을 구성하는 위치.](~/assets/images/cloudflare-one/identity/google/configure-consent-screen.png)

4. 동의 화면을 구성하려면:
   1. 제품정보**시작하기**.
   2. 이름 \***앱 이름**·**사용자 지원 이메일**.
   3. 제품 정보**기타 제품**Audience 유형으로. 이 응용 프로그램은 Google Workspace 계정에서 생성되지 않기 때문에 Gmail 주소가있는 사용자는 로그인 할 수 있습니다.
   4. 이름 \***연락처**. Google Cloud Platform은 계정의 이메일이 필요합니다.
   5. Google의 사용자 데이터 정책에 동의하고 선택**계속하기**.
   6. 제품정보**이름 \***.

5. OAuth 개요 페이지가로드됩니다. OAuth 개요 화면에서 선택**OAuth 클라이언트 만들기**.

   ![Google Cloud Platform 콘솔에서 OAuth 클라이언트를 만드는 위치.](~/assets/images/cloudflare-one/identity/google/create-oauth-client.png)

6. 제품 정보*웹 신청*으로**신청 유형**OAuth Client ID를 이름에 부여합니다.

7. 이름 \***공인 JavaScript 원산지**, 에서**한국어**필드, 팀 도메인 입력:

   ```txt
   https://<your-team-name>.cloudflareaccess.com
   ```

   <Render file="find-team-name" product="cloudflare-one" />

8. 이름 \***공인 리디렉션 URI**, 에서**한국어**필드, 다음 URL을 입력:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
   ```

9. OAuth 클라이언트를 만들면 OAuth 클라이언트를 선택합니다. Google은 현재**OAuth 클라이언트 ID**가치와**고객 비밀**가치. 비밀번호와 같은 클라이언트 비밀 필드 함수는 공유하지 않아야 합니다. 모두 복사**OAuth 클라이언트 ID**가치와**고객 비밀**가치.

10. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합** > **Identity 공급자**.

11. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**. 선택**구글 +**&#xB2E4;음 페이지에.

12. 클라이언트 ID를 입력 (**앱 ID**Cloudflare 대시보드) 및 이전에 생성 된 클라이언트 비밀 필드.

13. (선택) 사용[키 교환 증명 (PKCE)](https://www.oauth.com/oauth2-servers/pkce/). PKCE는 모든 로그인 시도에서 수행됩니다.

14. 제품정보**제품 정보**.

## 연결 테스트

당신의 연결이 작동되는 것을 시험하기 위하여, 가기**통합** > **Identity 공급자**선택하기**제품정보**Google에 다음.

## API Config 예제

```json
{
	"config": {
		"client_id": "<your client id>",
		"client_secret": "<your client secret>"
	},
	"type": "google",
	"name": "my example idp"
}
```

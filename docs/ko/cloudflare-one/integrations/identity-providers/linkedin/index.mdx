사이트맵 Access는 사용자의 ID 공급자 (IdP)로 LinkedIn을 사용할 수 있습니다.

## 자주 묻는 질문

계속하기 전에 LinkedIn 계정에 로그인하십시오. LinkedIn을 Cloudflare Access IdP로 구성하려면 LinkedIn 계정이 필요합니다.

## LinkedIn을 IdP로 설정

LinkedIn을 IdP로 구성하려면:

1. 오시는 길[LinkedIn 개발자 포털](https://www.linkedin.com/developers).

2. 제품정보**앱 만들기**.

3. 에 의해**앱 만들기**페이지, 입력**앱 이름**당신의 신청을 위해.

4. 선택하기**LinkedIn 페이지**당신의 신청 또는 선택**새로운 LinkedIn 페이지 만들기**LinkedIn 페이지가 없습니다.

5. 제품정보**로고 업로드**회사 로고 이미지 파일을 업로드하십시오.

6. 제품정보**API 이용 약관**이용 약관을 읽고 동의합니다.

7. 제품정보**앱 만들기**.

8. 내 계정**제품 정보**LinkedIn 응용 프로그램 탭, 선택**자주 묻는 질문**이름 \***이름 \* OpenID Connect를 사용하여 LinkedIn에서**옵션.

9. 내 계정**오스**LinkedIn 응용 프로그램의 탭, 찾기**고객 ID**·**고객 비밀**.

   ![LinkedIn 계정 설정 클라이언트 ID 및 클라이언트 비밀](~/assets/images/cloudflare-one/identity/linkedin/lin5.png)

10. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합** > **Identity 공급자**.

11. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

12. 제품정보**링크드 인**당신의 IdP로.

13. 내 계정**앱 ID**분야, 복사 및 붙여넣기**고객 ID**단계 9. 에서**고객 비밀**분야, 복사 및 붙여넣기**고객 비밀**단계 9.

14. 제품정보**제품 정보**.

15. 내 계정**오스**LinkedIn 응용 프로그램 탭으로 이동**OAuth 2.0 설정**연필 아이콘을 다음으로 선택합니다.**앱에 대한 공인 리디렉션 URL**.

16. 다음 URL을 입력하십시오:

    ```txt
    https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
    ```

당신의 연결이 작동되는 것을 시험하기 위하여, 가기[사이트맵 한국어](https://one.dash.cloudflare.com/) > **통합** > **Identity 공급자**> 선택**제품정보**LinkedIn 로그인 방법

## API 구성 보기

```json
{
	"config": {
		"client_id": "<your client id>",
		"client_secret": "<your client secret>"
	},
	"type": "linkedin",
	"name": "my example idp"
}
```

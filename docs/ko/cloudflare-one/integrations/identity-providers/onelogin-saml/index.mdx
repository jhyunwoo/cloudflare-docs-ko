OneLogin은 SSO 정체 관리를 제공합니다. 사이트맵 Access는 SAML ID 공급자로 OneLogin을 지원합니다.

## SAML 공급자로 OneLogin 설정

## 1. OneLogin에서 응용 프로그램을 작성

1. OneLogin 관리자 포털에 로그인하십시오.

2. 제품정보**앱 다운로드** > **앱 추가**.

3. 이름 \***회사연혁**, 검색**사이트맵 오시는 길**.

4. 후원 결과 선택**주식회사 Cloudflare**. 당신은 이름 또는 로고를 주문을 받아서 만들 수 있습니다.

5. 제품정보**제품 정보**. 이 정보를 언제든지 변경할 수 있습니다.

6. 선택하기**제품 설명**탭.

7. 내 계정**Cloudflare 액세스 권한 도메인**필드, 팀을 붙여 넣기 도메인:

   ```txt
   https://<your-team-name>.cloudflareaccess.com
   ```

8. 선택하기**매개 변수**탭, 선택**추가 모수**견적 요청**Cloudflare 액세스 필드**.

9. 선택하기**오시는 길**이름 \*

10. 역할에서, programmatically에 맵핑을 사용 하 고 응용 프로그램에 액세스할 수 있는 사용자를 할당.

    ![OneLogin SAML 사용 가능한 역할과 액세스 인터페이스](~/assets/images/cloudflare-one/identity/onelogin/onelogin-saml-6.png)

11. 선택하기**사이트맵**탭.

12. OneLogin 복사**SAML 2.0 엔드포인트 (HTTP)**&#x43;loudflare 단일 로그인 URL.

13. OneLogin 복사**발급 URL**Cloudflare에**IdP 기업 ID**.

14. 제출하기**X.509 인증서**Cloudflare에**표시 인증서**.

    ![OneLogin SAML 응용 SSO 인터페이스 SAML2.0 방법, 발행자 URL 및 X.509 인증서에 서명](~/assets/images/cloudflare-one/identity/onelogin/onelogin-saml-7.png)

### 2. Cloudflare에 OneLogin 추가 한국어

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합** > **Identity 공급자**.

2. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

3. 제품정보**사이트맵**.

4. 필드에 OneLogin 계정에서 세부 정보를 입력합니다.

5. (선택) SCIM을 활성화하려면[사용자 및 그룹 동기화](/cloudflare-one/integrations/identity-providers/generic-saml/#synchronize-users-and-groups).

6. (선택) 밑에**옵션 구성**, 구성[추가 SAML 옵션](/cloudflare-one/integrations/identity-providers/generic-saml/#optional-configurations). 다른 SAML 헤더와 속성 이름을 OneLogin에 추가하면 Cloudflare에 추가해야합니다.

7. 제품정보**제품 정보**.

당신의 연결이 작동되는 것을 시험하기 위하여, 가기**통합** > **Identity 공급자**선택하기**제품정보**테스트하려는 로그인 방법 옆에.

## SP 메타데이터 다운로드 (옵션)

OneLogin SAML은 관리자가 서비스 제공 업체에서 메타데이터 파일을 업로드 할 수 있습니다.

OneLogin SAML 구성에 메타 데이터 파일을 추가하려면:

1. 다음 URL에서 고유 SAML 메타데이터 파일을 다운로드:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/saml-metadata
   ```

2. XML 문서로 파일을 저장합니다.

3. XML 문서를 업로드**다운로드**.

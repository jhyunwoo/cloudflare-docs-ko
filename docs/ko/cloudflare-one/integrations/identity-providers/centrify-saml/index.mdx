## SAML 공급자로 Centrify 설정

## 1. Centrify에서 응용 프로그램 만들기

1. 로그인**회사연혁**관리자 포털 및 선택**앱 다운로드**.

2. 제품정보**웹 앱 추가**.

3. 선택하기**제품 정보**탭.

4. 다음으로**사이트맵**아이콘, 선택**더 보기**.

   ![Centrify 설정 템플릿 텍스트와 응용 프로그램 세부 페이지를 추가](~/assets/images/cloudflare-one/identity/saml-centrify/saml-centrify-3.png)

5. 신청에 필요한 정보를 입력하세요.

6. 제품정보**제품 정보**.

7. 제품정보**계정 설정**왼쪽 팬티에서.

8. 중간 메뉴에서 선택**지원하다**.

9. 선택하기**수동 설정**옵션.

10. 내 계정**SP 관계 ID**·**Assertion 소비자 봉사 (ACS) URL 필드**, 다음 URL을 입력하십시오:

    ```txt
    https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
    ```

11. 제품정보**제품 정보**.

12. 중간 메뉴에서 선택**사용자 액세스**.

13. 제품정보**더 보기**·**역할 선택**대화 상자 표시.

14. 역할 접근 할당 완료. 역할 규칙 표시**사용자 액세스**카드.

15. 내 계정**사용자 액세스**카드의 중간 메뉴 팬, 선택**SAML 응답**.

17. 사용자 이메일 주소를 입력**가치 평가**이름 \*

18. 제품정보**제품 정보**.

19. 제품정보**계정 설정**왼쪽 메뉴에서 다시, 그리고**지원하다**.

20. 선택하기**수동 설정**옵션.

### 2. Cloudflare에 Centrify 추가 한국어

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합** > **Identity 공급자**.

2. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

3. 제품정보**사이트맵**.

4. Centrify에서 필드에 해당 정보를 복사하고 붙여넣기.

5. (선택) SCIM을 활성화하려면[사용자 및 그룹 동기화](/cloudflare-one/integrations/identity-providers/generic-saml/#synchronize-users-and-groups).

6. (선택) 밑에**옵션 구성**, 구성[추가 SAML 옵션](/cloudflare-one/integrations/identity-providers/generic-saml/#optional-configurations).

7. 제품정보**제품 정보**.

당신의 연결이 작동되는 것을 시험하기 위하여, 가기**통합** > **Identity 공급자**선택하기**제품정보**테스트하고 싶은 정체성 공급자 옆에.

## SP 메타데이터 다운로드 (옵션)

일부 IdPs는 관리자가 SP (서비스 제공 업체)에서 메타 데이터 파일을 업로드 할 수 있습니다.

Cloudflare 메타데이터 파일을 얻으려면:

1. 다음 URL에서 고유 SAML 메타데이터 파일을 다운로드:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/saml-metadata
   ```

2. XML 형식으로 파일을 저장합니다.

3. XML 문서를 업로드**회사연혁**계정.

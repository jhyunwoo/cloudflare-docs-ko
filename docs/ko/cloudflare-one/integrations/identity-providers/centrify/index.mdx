## OIDC 공급자로 Centrify 설정

### 1. Centrify에서 응용 프로그램 만들기

1. Centrify 관리자 패널에 로그인하십시오.

2. 제품정보**앱 다운로드**.

3. 제품정보**웹 앱 추가**.

4. 선택하기**제품 정보**탭, 다음 선택**OpenID Connect 추가**.

5. 에 의해**웹 앱 추가**스크린, 선택**이름 \***&#x4F;penID Connect 응용 프로그램을 만들려면.

6. 이름 \***신청 ID**.

   ![Application ID가 추가된 설정](~/assets/images/cloudflare-one/identity/centrify/centrify-4.png)

7. 제품정보**제품 정보**.

8. 제품정보**지원하다**내 계정**계정 설정**메뉴.

9. 강력한 응용 비밀을 입력**지원하다**이름 \*

10. 이름 \***서비스 제공자 구성**애플리케이션의 인증 도메인을 리소스 애플리케이션 URL로 입력합니다.

11. 이름 \***공인 Redirect URI**, 선택**더 보기**.

12. 이름 \***공인 Redirect URI**, 다음 URL을 입력하십시오:

    ```txt
    https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
    ```

    ![팀 도메인 및 콜백과 신뢰 Identity Provider 구성을 자동화](~/assets/images/cloudflare-one/identity/centrify/centrify-6.png)

13. 제품정보**제품 정보**.

14. 다음 값을 복사:

- **고객 ID**
- **고객 비밀**
- **OpenID 연결 문제 URL**
- **신청 ID**으로**계정 설정**이름 \*

15. 오시는 길**사용자 액세스**탭.

16. 귀하의 응용 프로그램에 액세스 권한을 부여하는 역할을 선택합니다.

### 2. Cloudflare에 Centrify 추가 한국어

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**통합** > **Identity 공급자**.

2. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

3. 과거에**고객 ID**, **고객 비밀**, **계정 URL 설정**·**신청 ID**.

4. (선택) SCIM을 활성화하려면[사용자 및 그룹 동기화](/cloudflare-one/integrations/identity-providers/generic-oidc/#synchronize-users-and-groups).

5. (선택) 밑에**옵션 구성**, 입력[사용자 정의 OIDC 주장](/cloudflare-one/integrations/identity-providers/generic-oidc/#custom-oidc-claims)사용자의 정체성에 추가하고자 합니다.

6. 제품정보**제품 정보**.

당신의 연결이 작동되는 것을 시험하기 위하여, 가기**통합** > **Identity 공급자**선택하기**제품정보**테스트하고 싶은 정체성 공급자 옆에.

## API Config 예제

```json
{
	"config": {
		"client_id": "<your client id>",
		"client_secret": "<your client secret>",
		"centrify_account": "https://abc123.my.centrify.com/",
		"centrify_app_id": "exampleapp"
	},
	"type": "centrify",
	"name": "my example idp"
}
```

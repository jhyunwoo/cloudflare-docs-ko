OneLogin은 SSO 정체 관리를 제공합니다. 사이트맵 Access는 OIDC ID 공급자로 OneLogin을 지원합니다.

## OIDC 공급자로 OneLogin 설정

### 1. OneLogin에서 응용 프로그램을 작성

1. OneLogin 관리자 포털에 로그인하십시오.

2. 오시는 길**이름 \*** > **이름 \***&#xC120;택하기**앱 추가**.

3. 관련 기사`OIDC`선택하기**OpenId 연결 (OIDC)**&#xC791;성자: OneLogin

4. 내 계정**표시 이름**, 당신의 신청을 위한 어떤 이름을 입력하십시오. 제품정보**제품 정보**.

5. 다음으로 이동**제품 설명**. 에서**리디렉션 URI**필드, 다음 URL을 입력:

   ```txt
   https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
   ```

8. 오시는 길**사이트맵**선택하기**고객 비밀보기**.

9. 제출하기**고객 ID**·**고객 비밀**.

### 2. Cloudflare에 OneLogin 추가 한국어

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**통합** > **Identity 공급자**.

2. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

3. 제품정보**다운로드**.

4. 다음 정보를 입력:
   - **이름 \***: ID 공급자 이름.
   - **앱 ID**: OneLogin 클라이언트 ID를 입력하십시오.
   - **고객 비밀**: OneLogin 클라이언트 비밀을 입력하십시오.
   - **OneLogin 계정 URL**: OneLogin 도메인을 입력, 예를 들어`https://<your-domain>.onelogin.com`.

5. (선택) SCIM을 활성화하려면[사용자 및 그룹 동기화](/cloudflare-one/integrations/identity-providers/generic-oidc/#synchronize-users-and-groups).

6. (선택) 밑에**옵션 구성**, 입력[사용자 정의 OIDC 주장](/cloudflare-one/integrations/identity-providers/generic-oidc/#custom-oidc-claims)사용자의 정체성에 추가하고자 합니다.

7. 제품정보**제품 정보**.

이 단계를 사용하여 Facebook을 ID 공급자로 설정하십시오.

1. 오시는 길[개발자.facebook.com](https://developers.facebook.com/).

2. 제품정보**앱 만들기**상단에. 더 보기**새 앱 ID 생성**카드 표시.

3. 이름 \***표시 이름**·**연락처**.

4. 제품정보**앱 ID 생성**·**새 앱 ID 생성**창 전시.

5. CAPTCHA 코드를 입력하여 진행하십시오.

6. 제품정보**제출하기**.

7. 에 의해**Facebook 로그인**카드, 선택**설정하기**. Quickstart 카드 전시 제안 플랫폼 선택.

8. 제품정보**웹 사이트**·**웹 사이트**탭 표시.

9. 이름 \***사이트 URL**.

10. 제품정보**제품 정보**.

11. 제품정보**계속하기**. 당신 사이트에 그것을 설치하는 것을 제안하는 JavaScript 페이지를 무시하십시오.

12. 제품정보**계정 설정** > **기본 정보**.

13. 제출하기**앱 ID**·**앱 비밀**.

    ![Facebook App ID 및 App 비밀 강조 설정](~/assets/images/cloudflare-one/identity/facebook/fb6.png)

14. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**통합** > **Identity 공급자**.

15. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

16. 자주 묻는 질문**앱 ID**·**앱 비밀**Facebook에서 획득.

17. (선택) 사용[키 교환 증명 (PKCE)](https://www.oauth.com/oauth2-servers/pkce/). PKCE는 모든 로그인 시도에서 수행됩니다.

18. 제품정보**제품 정보**.

19. 이름 \*[개발자.facebook.com](https://developers.facebook.com/), 선택**Facebook 로그인** > **계정 설정**왼쪽 메뉴에서.

20. 더 알아보기**Redirect URI를 위한 Strict 형태 사용**슬라이더 설정**이름 \***.

21. 내 계정**OAuth 리디렉션 URI**필드, 다음 URL을 입력:

    ```txt
    https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
    ```

    <Render file="find-team-name" product="cloudflare-one" />

22. 제품정보**저장 변화**.

연결이 작동되는지 테스트하려면 단계에 따라[SSO 통합](/cloudflare-one/integrations/identity-providers/#test-idps-in-cloudflare-one).

## API 구성 보기

```json
{
	"config": {
		"client_id": "<your client id>",
		"client_secret": "<your client secret>"
	},
	"type": "facebook",
	"name": "my example idp"
}
```

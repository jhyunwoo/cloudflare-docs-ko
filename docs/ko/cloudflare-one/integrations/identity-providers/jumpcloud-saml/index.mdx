[채용정보](https://jumpcloud.com/#platform)SSO ID 관리 사이트맵 Access는 JumpCloud와 SAML ID 공급자로 통합합니다.

다음 단계는 Cloudflare Access로 JumpCloud를 설정하는 것이 중요합니다. JumpCloud SSO 응용 프로그램 구성에 대한 자세한 내용은 참조[JumpCloud 문서](https://jumpcloud.com/support/integrate-with-cloudflare).

## Jumpcloud를 SAML 공급자로 설정

### 1. JumpCloud에서 SSO 응용 프로그램 만들기

1. 내 계정[JumpCloud 관리자 포털](https://console.jumpcloud.com/#/home), 이동**SSO 신청**.

2. 제품정보**새 앱 추가**.

3. 검색 바에서 입력`Cloudflare`그리고 선택**사이트맵 오시는 길**신청.

4. 제품정보**이름 \***.

5. 내 계정**전시 상표**, 신청 이름을 입력하십시오.

6. 제품정보**자주 묻는 질문**.

7. 앱 요약 및 선택**연락처**.

8. 내 계정**사이트맵**탭, 다음 설정을 구성:
   1. 내 계정**IdP 기업 ID**Cloudflare 팀 도메인을 입력하십시오.

      ```txt
      https://<your-team-name>.cloudflareaccess.com/
      ```

      <Render file="find-team-name" product="cloudflare-one" />

   2. 모두 설정**SP 관계 ID**·**ACS URL을**다음 콜백 URL에:

      ```txt
      https://<your-team-name>.cloudflareaccess.com/cdn-cgi/access/callback
      ```

   3. (선택 사항) Cloudflare 액세스로 보내려면 SAML 속성을 구성합니다.

   4. 더 보기**비밀번호**선택하기**수출 Metadata**. 사용을위한 XML 파일을 저장[다음 단계](#2-add-jumpcloud-to-zero-trust).

9. 내 계정**사용자 그룹**탭,[사용자 그룹 지정](https://jumpcloud.com/support/get-started-applications-saml-sso#managing-employee-access-to-applications)이 응용 프로그램에.

10. 제품정보**제품 정보**.

### 2. Cloudflare에 JumpCloud를 추가하십시오 한국어

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**통합** > **Identity 공급자**.

2. 이름 \***당신의 ID 공급자**, 선택**새로운 ID 공급자 추가**.

3. 제품정보**사이트맵**.

4. JumpCloud XML 메타 데이터 파일을 업로드하십시오.

5. (선택) SCIM을 활성화하려면[사용자 및 그룹 동기화](#synchronize-users-and-groups).

6. (선택) 밑에**옵션 구성**, 구성[추가 SAML 옵션](#optional-configurations).

7. 제품정보**제품 정보**.

지금 할 수 있습니다[연결 테스트](/cloudflare-one/integrations/identity-providers/#test-idps-in-cloudflare-one)그리고 창조[오시는 길](/cloudflare-one/access-controls/policies/)구성된 로그인 방법 및 SAML 속성을 기반으로 합니다.

JumpCloud 통합은 사용자 그룹을 동기화하고 자동으로 사용자를 해독 할 수 있습니다.[사이트맵](/cloudflare-one/team-and-resources/users/scim/).

### 2. JumpCloud에서 SCIM 구성

1. 내 계정[JumpCloud 관리자 포털](https://console.jumpcloud.com/#/home), 이동**SSO 신청**.
2. Cloudflare 응용 프로그램을 선택할 때 생성 된[JumpCloud를 SAML 공급자로 설정](/cloudflare-one/integrations/identity-providers/jumpcloud-saml/#set-up-jumpcloud-as-a-saml-provider).
3. 선택하기**사이트맵**탭.
4. 사용자 그룹 제공, 선택**그룹 속성 포함**이름 \*`groups`. 그룹 속성 이름은 정확히 일치해야`groups`또는 SAML 속성으로 전송됩니다.
5. 선택하기**Identity 관리**탭.
6. 견적 요청**이 응용 프로그램에서 사용자 그룹 및 그룹 회원 관리 가능**설정한다.
7. 제품정보**설정하기**.
8. 내 계정**기본 URL**필드, 입력**SCIM 엔드포인트**Cloudflare에서 획득 한국어
9. 내 계정**토큰 키**필드, 입력**SCIM 비밀**Cloudflare에서 획득 한국어
10. 제품정보**이름 \***. Identity Management 통합이 성공적으로 검증된 확인을 받게 됩니다.
11. 제품정보**제품 정보**.

### Provisioning 속성

Provisioning 속성은 사용자 및 그룹 속성을 정의하여 JumpCloud는 Cloudflare Access와 동기화됩니다. 기본적으로, JumpCloud는 SCIM 업데이트 이벤트 중 다음 속성을 보낼 것입니다:

| JumpCloud 사용자 속성 | 사이트맵 Access 속성 |
| ---------------- | -------------- |
| `email`          | `email`        |
| `firstname`      | `givenName`    |
| `lastname`       | `surname`      |

| JumpCloud 그룹 속성 | 사이트맵 Access 속성 |
| --------------- | -------------- |
| `name`          | `groups`       |

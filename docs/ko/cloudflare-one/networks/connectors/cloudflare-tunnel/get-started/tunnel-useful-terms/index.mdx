Cloudflare 터널에 대한 용어 검토.

## 관련 제품

터널은 보안, 아웃바운드 전용 통로로 원산지와 Cloudflare의 글로벌 네트워크 사이에 설치할 수 있습니다. 창조하는 각 갱도는 할당될 것입니다[이름 \*](#tunnel-name)·[사이트맵](#tunnel-uuid).

## 터널 UUID

터널 UUID는 터널에 할당 된 알파벳, 고유 ID입니다. 갱도 UUID는 당신이 참고 자료 특정한 갱도에 필요로 할 때마다 사용될 수 있습니다.

## 터널 이름

터널명은 터널을 선택할 수있는 독특하고 사용하기 쉬운 식별자입니다. 터널은 여러 서비스에 프록시 트래픽을 할 수 있기 때문에 터널 이름은 호스트 이름이 필요하지 않습니다. 예를 들어, 응용 프로그램 / 네트워크, 특정 서버 또는 클라우드 환경을 나타내는 이름을 지정할 수 있습니다.

## 연결하기

연결관은, 것과 같이 불립니다`cloudflared`, 당신의 근원 서버에서 Cloudflare 세계적인 네트워크에 연결을 설치하십시오. 우리의 연결관은 Cloudflare의 세계적인 네트워크 내의 2개의 명백한 자료 센터에 4개의 긴 살아있는 연결을 창조해서 높은 가용성을 제안합니다. 이 내장 중복은 개별 연결, 서버 또는 데이터 센터가 다운되면, 당신의 기원은 사용할 수 있습니다.

## 레플리카

한 번 터널을 만들 수 있으며 커넥터의 다중, 고유 한 인스턴스를 통해 터널을 실행할 수 있습니다.`cloudflared`. 이 인스턴스는 복제로 알려져 있습니다. DNS 레코드 및 Cloudflare 로드밸런서는 여전히 터널과 DNS 레코드에 대한 포인트입니다 (`UUID.cfargotunnel.com`), 그 터널은 다중 인스턴스에 트래픽을 전송하는 동안`cloudflared`그것을 통해 실행. 오늘, 복제가 선택될 것이라는 보증이 없습니다. Replicas는 종종 이벤트에서 높은 가용성으로 터널을 제공하도록 배치됩니다 주어진 호스트 실행`cloudflared`중단하거나 오프라인 촬영.

## 원격 관리 터널

원격 관리 터널은[회사 소개](#tunnel)그것은[사이트맵 한국어](https://one.dash.cloudflare.com/)이름 \***네트워크** > **연락처**. 갱도 윤곽은 Cloudflare에서 저장됩니다, 당신이 대시보드에서 갱도를 또는 사용하는 것을 허용하는[사이트맵](/api/resources/zero_trust/subresources/tunnels/subresources/cloudflared/subresources/configurations/methods/get/).

## 로컬 관리 터널

로컬 관리 터널은[회사 소개](#tunnel)그것은 실행에 의해 만들어진`cloudflared tunnel create <NAME>`명령줄에. 터널 구성은 로컬에 저장됩니다.[cloudflared 디렉토리](#default-cloudflared-directory). 지역적으로 관리된 갱도에 특정한 terminology를 위해, 참조하십시오[로컬 관리 터널 광택](/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/local-management/local-tunnel-terms/).

## 빠른 터널

빠른 터널, 실행할 때, 웹 사이트의 임의 하위 도메인으로 구성된 URL을 생성합니다.`trycloudflare.com`, 포트에 localhost에 포인트 트래픽`8080`. 그 주소에서 웹 서비스를 실행하면 생성 된 하위 도메인을 방문하는 사용자는 Cloudflare의 네트워크를 통해 웹 서비스를 방문 할 수 있습니다. 더 알아보기[시험Cloudflare](/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/)빠른 터널을 실행하는 방법에 대한 자세한 내용은.

## 가상 네트워크

·[가상 네트워크](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/tunnel-virtual-networks/)개인 네트워크에서 논리적으로 분리 된 리소스를 허용하는 소프트웨어 요약입니다. 가상 네트워크는 특히 IP 경로를 덮는 exposing 리소스에 유용합니다. 리소스에 연결하려면 최종 사용자는 대상 IP를 입력하기 전에 WARP 클라이언트 설정에서 가상 네트워크를 선택할 것입니다.

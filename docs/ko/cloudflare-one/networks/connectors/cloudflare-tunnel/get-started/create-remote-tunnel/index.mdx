## 2a. 신청 게시

이 단계를 따라 응용 프로그램을 인터넷에 게시합니다. 개인 리소스를 연결하려는 경우, 건너뛰기[네트워크 연결](#2b-connect-a-network)이름 \*

:::노트\[필수]
터널을 통해 응용 프로그램을 게시하기 전에, 당신은해야합니다[Cloudflare에 웹 사이트를 추가](/fundamentals/manage-domains/add-site/).
:::

인터넷에서 누구나 지정된 호스트 이름에서 응용 프로그램을 액세스 할 수 있습니다. 특정 사용자를 허용하거나 차단하기 위해,[액세스 신청서 작성](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/).

## 2b. 네트워크 연결

터널을 통해 개인 네트워크를 연결하려면:

1. 오시는 길**CIDR 소개**탭.
2. 내 계정**CIDR 소개**, 개인 IP 주소 또는 CIDR 범위를 입력 (예를 들면,`10.0.0.1`또는`10.0.0.0/24`).
3. 제품정보**완료 설정**.

`cloudflared`이제이 목적지 IP로 트래픽을 경로를 수 있습니다. Zero Trust 정책을 구성하고 사용자로 연결하려면, 참조[IP/CIDR 연결](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/).

:::참조
IP 대신 호스트 이름을 사용하여 개인 응용 프로그램에 루트를 원한다면, 참조[개인 별명 연결](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/connect-private-hostname/).
:::

## 3. 터널보기

터널을 저장 한 후, 당신은에 리디렉션됩니다**네트워크** > **연결관**사이트 맵 터널은 다음과 같습니다.`Healthy`이름 \* 당신의 갱도 상태가 인 경우에`Inactive`, `Down`, 또는`Degraded`, 참조[문제 해결 문서](/cloudflare-one/networks/connectors/cloudflare-tunnel/troubleshoot-tunnels/common-errors/#tunnel-status)다음 단계를 추천합니다.

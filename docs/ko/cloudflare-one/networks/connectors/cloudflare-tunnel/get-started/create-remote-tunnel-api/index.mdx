## 2. 터널 만들기

더 보기`POST`요청하기[Cloudflare 갱도](/api/resources/zero_trust/subresources/tunnels/subresources/cloudflared/methods/create/)엔드포인트:

<APIRequest
  path="/accounts/{account_id}/cfd_tunnel"
  method="POST"
  json={{
  name: "api-tunnel",
  config_src: "cloudflare",
}}
/>

## 3a. 신청 게시

터널을 통해 응용 프로그램을 게시하기 전에, 당신은해야합니다:

- [Cloudflare에 웹 사이트를 추가](/fundamentals/manage-domains/add-site/).
- [도메인 네임서버를 Cloudflare로 변경](/dns/zone-setups/full-setup/setup/).

이 단계를 따라 응용 프로그램을 인터넷에 게시합니다. 개인 리소스를 연결하려는 경우, 건너뛰기[네트워크 연결](#3b-connect-a-network)이름 \*

1. 더 보기[`PUT`이름 \*](/api/resources/zero_trust/subresources/tunnels/subresources/cloudflared/subresources/configurations/methods/update/)자주 묻는 질문[로컬 서비스 URL](/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/protocols/)대중적인 hostname. 예를 들어,

   <APIRequest
     path="/accounts/{account_id}/cfd_tunnel/{tunnel_id}/configurations"
     method="PUT"
     json={{
      		config: {
      			ingress: [
      				{
      					hostname: "app.example.com",
      					service: "http://localhost:8001",
      					originRequest: {},
      				},
      				{
      					service: "http_status:404",
      				},
      			],
      		},
      	}}
   />

   :::참조
   Multi-level subdomain (subdomain의 1 개 이상의 레벨)을 추가하면,[hostname에 대한 고급 인증서를 주문](/cloudflare-one/faq/troubleshooting/#i-see-this-site-cant-provide-a-secure-connection).
   :::

   당신의 진입 규칙은 끝에서 catch-all 규칙을 포함해야합니다. 이 예제에서,`cloudflared`요청이 이전 호스트 이름과 일치하지 않을 때 404 상태 코드와 응답합니다.

2. [DNS 레코드 만들기](/api/resources/dns/subresources/records/methods/create/)당신의 신청을 위해:

   <APIRequest
     path="/zones/{zone_id}/dns_records"
     method="POST"
     json={{
      		type: "CNAME",
      		proxied: true,
      		name: "app.example.com",
      		content: "c1744f8b-faa1-48a4-9e5c-02ac921467fa.cfargotunnel.com",
      	}}
   />

   이 DNS 레코드는 Cloudflare 프록시를 허용`app.example.com`Cloudflare 터널로의 교통`<tunnel-id>.cfargotunnel.com`).

이 응용 프로그램은 한 번 인터넷에서 공개적으로 사용할 수 있습니다[터널을 실행](#4-install-and-run-the-tunnel). 특정 사용자를 허용하거나 차단하기 위해,[액세스 신청서 작성](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/).

## 3b. 네트워크 연결

터널을 통해 개인 네트워크를 연결하기 위해,[터널 경로 추가](/api/resources/zero_trust/subresources/networks/subresources/routes/methods/create/):

<APIRequest
  path="/accounts/{account_id}/teamnet/routes"
  method="POST"
  json={{
  network: "172.16.0.0/16",
  tunnel_id: "c1744f8b-faa1-48a4-9e5c-02ac921467fa",
  comment: "Example private network route",
}}
/>

`cloudflared`이제이 목적지 IP로 트래픽을 경로를 수 있습니다. Zero Trust 정책을 구성하고 사용자로 연결하려면, 참조[개인 네트워크](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/).

## 4. 설치 및 터널 실행

설치하기`cloudflared`서버에서 터널을 실행`token`얻은 값[2. 터널 만들기](#2-create-a-tunnel). 터널 토큰을 사용하여 얻을 수 있습니다.[사이트맵 터널 토큰](/api/resources/zero_trust/subresources/tunnels/subresources/cloudflared/subresources/token/methods/get/)끝점.

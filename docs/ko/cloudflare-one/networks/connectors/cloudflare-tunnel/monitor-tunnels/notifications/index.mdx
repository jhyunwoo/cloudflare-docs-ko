Administrators는 계정의 Cloudflare 터널이 건강 또는 배포 상태를 변경할 때 경고를받을 수 있습니다. 알림은 이메일, webhook 및 제삼자 서비스를 통해 전달될 수 있습니다.

## 알림 관리

터널 알림 설정[Cloudflare 대시보드](https://dash.cloudflare.com/). 자세한 내용은 참조[공지사항](/notifications/get-started/#create-a-notification).

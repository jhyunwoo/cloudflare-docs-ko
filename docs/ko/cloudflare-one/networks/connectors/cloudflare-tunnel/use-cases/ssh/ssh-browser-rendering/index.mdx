Cloudflare의 브라우저 기반 터미널은 SSH 키를 관리하거나 WARP 클라이언트를 설치하지 않고 SSH 서버에 연결할 수 있습니다.

이 방법은 공용 호스트 이름을 통해 서버에 SSH 액세스를 라우팅해야합니다. 트래픽은이 연결에 따라 예상되며 Cloudflare Access 자격 증명을 사용하여 서버에 로그인합니다.

브라우저 기반 터미널은 함께 사용할 수 있습니다.[WARP에 여정](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-warp-to-tunnel/)·[접근성 준수](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-infrastructure-access/)서버에 연결하는 여러 가지 방법이 있습니다. 각 연결 방법을 구성할 때 동일한 Cloudflare 터널을 재사용할 수 있습니다.

## 2. 사용자로 연결

SSH에 대한 브라우저 렌더링을 활성화하려면, 참조[브라우저 렌더링 터미널](/cloudflare-one/access-controls/applications/non-http/browser-rendering/).

사용자가 public hostname URL(예를 들어,`https://ssh.example.com`) 액세스 자격 증명과 로그인, Cloudflare는 브라우저에서 터미널을 렌더링합니다.

최종 사용자는 WARP 클라이언트없이 SSH 서버에 연결할 수 있습니다.`cloudflared`기본 맨끝에서. 이 방법은`cloudflared`서버 기계와 클라이언트 기계에 둘 다에 설치해, 뿐 아니라 Cloudflare에 활동적인 지역. 트래픽은이 연결에 따라 예상되며 Cloudflare Access 자격 증명을 사용하여 서버에 로그인합니다.

고객 측`cloudflared`함께 사용될 수 있습니다[WARP에 여정](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-warp-to-tunnel/)·[접근성 준수](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-infrastructure-access/)서버에 연결하는 여러 가지 방법이 있습니다. 각 연결 방법을 구성할 때 동일한 Cloudflare 터널을 재사용할 수 있습니다.

## 2. 사용자로 연결

1. [설치하기`cloudflared`](/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/)클라이언트 기계에.

2. SSH 구성 파일에 한 번의 변경을 만드십시오:

   ```sh
   vim ~/.ssh/config
   ```

3. 다음 값을 입력; 교체`ssh.example.com`만든 호스트 이름과 함께.

   ```txt
   Host ssh.example.com
   ProxyCommand /usr/local/bin/cloudflared access ssh --hostname %h
   ```

   더 보기`cloudflared`경로는 OS 및 패키지 관리자에 따라 다릅니다. 예를 들어, 설치한 경우`cloudflared`macOS에서 Homebrew를 사용하여 경로 확인`brew --prefix cloudflared`.

4. 이제 서비스에 도달하기 위해 명령을 실행하여 연결을 테스트 할 수 있습니다.

   ```sh
   ssh <username>@ssh.example.com
   ```

   명령이 실행되면,`cloudflared`브라우저 창을 실행하여 터미널에서 연결을 설정하기 전에 ID 공급자와 인증합니다.

Secure Shell Protocol (SSH)는 사용자가 명령 줄을 통해 원격 액세스 장치를 가능하게 합니다. Cloudflare로 한, 서버의 인바운드 포트를 열지 않고 인터넷에서 SSH 서버를 사용할 수 있습니다.

Cloudflare는 SSH를 확보하는 4 가지 방법을 제공합니다.

<CardGrid>
  <LinkTitleCard title="SSH 클라이언트 측 cloudflared" href="/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-cloudflared-authentication/" icon="seti:shell">
    **설치 시간:**&#x31;5-30 분

    **필수 제품:** [Cloudflare 갱도](/cloudflare-one/networks/connectors/cloudflare-tunnel/) (`cloudflared`서버 및 클라이언트에),[오시는 길](/cloudflare-one/access-controls/)

    **가장 좋은:**&#xB124;이티브 터미널을 사용하여 ID 기반 인증이 가능한 SSH 액세스

    **중요한 differentiator:**&#x57;ARP 클라이언트가 필요 없습니다.`cloudflared`두 끝에서
  </LinkTitleCard>

  <LinkTitleCard title="인프라에 대한 액세스 SSH" href="/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-infrastructure-access/" icon="seti:lock">
    **설치 시간:**&#x34;5-60 분

    **필수 제품:** [Cloudflare 갱도](/cloudflare-one/networks/connectors/cloudflare-tunnel/) (`cloudflared`서버에서),[사이트맵](/cloudflare-one/team-and-resources/devices/warp/)또는[Cloudflare 대만](/cloudflare-wan/)(클라이언트 on-ramp),[오시는 길](/cloudflare-one/traffic-policies/), [오시는 길](/cloudflare-one/access-controls/)

    **가장 좋은:**&#x53;SH 인증서 기반 인증

    **중요한 differentiator:**&#x53;SH 인증서 접근 정책 및 명령 로깅
  </LinkTitleCard>

  <LinkTitleCard title="자체 관리 SSH 키" href="/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-warp-to-tunnel/" icon="key">
    **설치 시간:**&#x33;0-45 분

    **필수 제품:** [Cloudflare 갱도](/cloudflare-one/networks/connectors/cloudflare-tunnel/) (`cloudflared`서버에서),[사이트맵](/cloudflare-one/team-and-resources/devices/warp/)또는[Cloudflare 대만](/cloudflare-wan/)(클라이언트 on-ramp),[오시는 길](/cloudflare-one/traffic-policies/)

    **가장 좋은:**&#xB124;트워크 수준의 정책 시행을 가진 전통적인 SSH 키 관리

    **중요한 differentiator:**&#xAE30;존 SSH 키 인프라를 클라이언트 측 없이 유지`cloudflared`또는 SSH 구성 변경
  </LinkTitleCard>

  <LinkTitleCard title="브라우저 렌더링 SSH 터미널" href="/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-browser-rendering/" icon="laptop">
    **설치 시간:**&#x32;0-30 분

    **필수 제품:** [Cloudflare 갱도](/cloudflare-one/networks/connectors/cloudflare-tunnel/) (`cloudflared`서버에서),[오시는 길](/cloudflare-one/access-controls/)

    **가장 좋은:**&#xBE60;른 관리 작업을위한 브라우저 기반 SSH 액세스

    **중요한 differentiator:**&#x53;SH 클라이언트 또는 WARP 필요 없음 — 브라우저에서 직접 연결
  </LinkTitleCard>
</CardGrid>

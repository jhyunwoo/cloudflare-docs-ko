Cloudflare WARP는 사용자가 선호하는 RDP 클라이언트를 사용하여 RDP 서버에 연결할 수 있습니다. 사이트맵 터널은 RDP 서버에서 Cloudflare의 글로벌 네트워크에 보안, 아웃바운드 전용 연결을 만듭니다. 이를 위해서는`cloudflared`서버의 daemon (또는 개인 네트워크 내에서 다른 호스트 기계). 사용자 설치[Cloudflare WARP 클라이언트](/cloudflare-one/team-and-resources/devices/warp/)그들의 장치 및 Zero Trust 조직에 등록하십시오. 원격 장치는 사용자의 개인 네트워크에 있다면 연결 할 수 있습니다. 기본적으로 조직에 등록 된 모든 장치는 특정 사용자를 허용하거나 차단 할 수있는 정책을 구축하지 않는 한 RDP 서버에 연결할 수 있습니다.

이 예제는 Google Cloud Platform (GCP) 가상 머신 (VM)에서 RDP 서버를 설정하는 방법을 통해 걸지만 RDP 연결을 지원하는 모든 기계를 사용할 수 있습니다.

## 1. GCP에서 RDP 서버를 설정

1. 내 계정[Google 클라우드 콘솔](https://console.cloud.google.com/), [새 프로젝트 만들기](https://developers.google.com/workspace/guides/create-project).
2. 오시는 길**Compute 엔진** > **VM 인스턴스**.
3. 제품정보**인스턴스 생성**.
4. VM 인스턴스 이름, 예를 들어`windows-rdp-server`.
5. VM 인스턴스 구성:
   1. 기타 제품**부팅 디스크**선택하&#xAE30;**- 기타**.
   2. 제품 정보**운영 체계**, 선택*Windows 서버*.
   3. 선택하기**이름 \***&#x44;esktop Experience로, 예를 들어*Windows 서버 2016 Datacenter*.
6. VM이 실행되면, 옆에 드롭다운을 엽니다.**사이트맵**선택하기*gcloud 명령을 사용하여 암호 재설정*.
7. 제품정보**Cloud Shell에서 실행**.
8. Cloud Shell 터미널에서 명령을 실행합니다. 비밀번호 재설정을 확인할 수 있습니다.
9. 자동 생성 된 암호 및 사용자 정의를 안전한 장소에 복사합니다.

## 2. Microsoft 원격 데스크톱 설치

RDP 클라이언트를 사용하여 RDP 서버에 액세스하고 구성할 수 있습니다.

Microsoft Remote Desktop을 통해 서버에 액세스하려면:

1. 다운로드 및 설치[Microsoft 원격 데스크톱](https://apps.microsoft.com/store/detail/microsoft-remote-desktop/9WZDNCRFJ3PS).
2. 한 번 다운로드, Microsoft Remote Desktop을 열고 선택**PC 추가**.
3. 제품 정보**PC 이름**, RDP 서버의 공용 IP 주소를 입력하십시오. GCP에서, 이것은**외부 IP**VM 인스턴스의.
4. 제품 정보**사용자 계정**, 선택**사용자 계정 추가**자동 생성된 암호 및 사용자 이름 입력
5. 제품정보**더 보기**. PC는 마이크로소프트 먼 데스크탑에서 전시할 것입니다.
6. 기본 연결을 테스트하려면 새로 추가 된 PC를 더블 클릭.
7. 자주 묻는 질문**계속하기**.

이제 공개 IP를 사용하여 RDP 서버에 원격 액세스 할 수 있습니다. 다음 단계는 개인 IP를 사용하여 서버에 액세스 할 것입니다.

:::참조

기본적으로 Internet Explorer가 설치되고 구성됩니다.[향상된 보안 모드](https://learn.microsoft.com/troubleshoot/developer/browsers/security-privacy/enhanced-security-configuration-faq#internet-explorer-enhanced-security-configuration). 브라우저가 느리거나로드 할 수없는 경우 향상된 보안을 켜고 Google Chrome과 같은 대체 브라우저를 설치 할 수 있습니다.

## 6. 사용자로 연결

WARP 클라이언트가 구성되면, RDP 클라이언트를 사용하여 서버의 개인 IP 주소에 연결할 수 있습니다 (기본적으로 사용되는 공공 IP 주소 대신).

Microsoft Remote Desktop에 연결하려면:

1. Microsoft 원격 데스크톱을 열고 선택**PC 추가**.
2. 제품 정보**PC 이름**, RDP 서버의 개인 IP 주소를 입력하십시오. GCP에서, 이것은**내부 IP**VM 인스턴스의.
3. 제품 정보**사용자 계정**RDP 서버 사용자 이름과 암호를 입력합니다.
4. Zero Trust 연결성을 테스트하려면 새로 추가 된 PC를 더블 클릭.
5. 자주 묻는 질문**계속하기**.

이제 보안, RDP 서버에 원격 액세스가 있습니다.

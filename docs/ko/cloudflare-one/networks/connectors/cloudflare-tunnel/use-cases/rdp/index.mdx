Remote Desktop Protocol (RDP)는 사용자가 컴퓨터에 원격으로 연결할 수있는 그래픽 인터페이스를 제공합니다. RDP는 사용자가 물리적으로 액세스 할 수없는 기계 또는 워크 스테이션에 간단한 원격 액세스를 용이하게하는 가장 일반적으로 사용됩니다. 그러나, 이것은 또한 RDP 연결에게 잘못 구성이 기계에 무단 액세스를 허용하기 때문에 공격의 빈번한 주제를한다.

Cloudflare Zero Trust를 사용하면 로컬 서버에 인바운드 포트를 열지 않고 인터넷에서 RDP 서버를 사용할 수 있습니다.

Cloudflare는 RDP를 확보하는 세 가지 방법을 제공합니다.

- [브라우저 기반 RDP](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/rdp/rdp-browser/)
- [WARP 클라이언트와 RDP](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/rdp/rdp-warp-to-tunnel/)
- [RDP 클라이언트 측 cloudflared](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/rdp/rdp-cloudflared-authentication/)

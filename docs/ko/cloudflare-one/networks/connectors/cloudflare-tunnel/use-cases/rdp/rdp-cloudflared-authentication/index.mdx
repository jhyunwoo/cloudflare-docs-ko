최종 사용자는 WARP 클라이언트없이 RDP 서버에 연결할 수 있습니다.`cloudflared`기본 맨끝에서. 이 방법은`cloudflared`서버 기계와 클라이언트 기계에 둘 다에 설치해, 뿐 아니라 Cloudflare에 활동적인 지역. 트래픽은이 연결에 따라 예상되며 Cloudflare Access 자격 증명을 사용하여 서버에 로그인합니다.

고객 측`cloudflared`함께 사용될 수 있습니다[WARP에 여정](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/rdp/rdp-warp-to-tunnel/)·[브라우저 기반 RDP](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/rdp/rdp-browser/)서버에 연결하는 여러 가지 방법이 있습니다. 각 연결 방법을 구성할 때 동일한 Cloudflare 터널을 재사용할 수 있습니다.

## 1. Cloudflare에 서버를 연결합니다

1. Cloudflare 만들기 다음으로 터널[대시보드 설정 가이드](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/).

2. 내 계정**자주 묻는 질문**탭, 드롭다운 메뉴에서 도메인을 선택하고 하위 도메인을 지정하십시오 (예를 들어,`rdp.example.com`).

3. 제품 정보**제품정보**, 선택*사이트맵*자주 묻는 질문[RDP 청취 포트](https://docs.microsoft.com/en-us/windows-server/remote/remote-desktop-services/clients/change-listening-port)서버의 (예를 들면,`localhost:3389`). 그것은 항구일 것입니다`3389`.

4. 제품정보**제품 정보**.

## 2. (추천) 액세스 신청서 작성

기본적으로 인터넷에서 누구나 게시 된 응용 프로그램의 호스트 이름을 사용하여 서버에 연결할 수 있습니다. 특정 사용자를 허용하거나 차단하려면[자체 호스팅 응용](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/)Cloudflare 액세스.

## 3. 사용자로 연결

1. [설치하기`cloudflared`](/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/)클라이언트 기계에.
2. 이 명령을 실행하여 RDP 청취 포트:

   ```sh
   cloudflared access rdp --hostname rdp.example.com --url rdp://localhost:3389
   ```

   이 과정은 살아있고 autostart를 유지하기 위해 구성해야합니다. 프로세스가 죽었다면, 사용자는 연결할 수 없습니다.

:::참조

클라이언트 기계는 Windows, 항구를 달리는 경우에`3389`이미 로컬로 소비 될 수 있습니다. 대안 포트를 선택`3389`사용되지 않습니다.
주요 특징

3. 한국어`cloudflared access`실행, Microsoft Remote Desktop과 같은 RDP 클라이언트에서 연결:
   1. Microsoft 원격 데스크톱을 열고 선택**PC 추가**.
   2. 제품 정보**PC 이름**, 입력`localhost:3389`.
   3. 제품 정보**사용자 계정**RDP 서버 사용자 이름과 암호를 입력합니다.
   4. 새로 추가된 PC를 두 번 클릭.
   5. 자주 묻는 질문**계속하기**.

클라이언트가 시작할 때 브라우저 창이 열리고 Cloudflare Access로 인증하는 사용자를 프롬프트합니다.

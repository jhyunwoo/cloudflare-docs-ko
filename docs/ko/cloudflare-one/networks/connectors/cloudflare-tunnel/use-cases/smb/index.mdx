Server Message Block (SMB) 프로토콜은 사용자가 네트워크에 읽거나 쓰기 및 액세스 공유 리소스를 읽을 수 있습니다. 보안 위험, 방화벽 및 ISP로 인해 일반적으로 SMB 파일 공유에 공공 연결을 차단합니다. Cloudflare로 터널, 네트워크 외부 사용자에게 안전하고 간단한 SMB 액세스를 제공 할 수 있습니다.

Cloudflare Zero Trust는 SMB 서버에 연결하기위한 두 가지 솔루션을 제공합니다.

- [Cloudflare WARP를 갱도에 가진 개인적인 subnet 여정](#connect-to-smb-server-with-warp-to-tunnel)
- [공공 호스트 이름 routing 와`cloudflared access`](#connect-to-smb-server-with-cloudflared-access)

## Linux에서 SMB 서버를 설정

SMB는 Microsoft Windows용으로 개발되었지만 Samba는 UNIX-like 및 BSD 시스템에서 SMB 연결을 제공합니다. Samba 서버가 설정할 수 있습니다.[- 연혁](https://ubuntu.com/tutorials/install-and-configure-samba#1-overview)우분투 기계에.

## WARP를 터널로 연결

Cloudflare 터널을 사용하여 서버에서 Cloudflare의 글로벌 네트워크에 보안, 아웃바운드 전용 연결을 만들 수 있습니다. 이것은 실행을 요구합니다`cloudflared`서버에서 daemon. 사용자는 설치하여 서비스에 도달[Cloudflare WARP 클라이언트](/cloudflare-one/team-and-resources/devices/warp/)당신의 Zero Trust 조직에 그들의 장치 그리고 등록에. 원격 장치는 사용자의 개인 네트워크에 있다면 연결 할 수 있습니다. 기본적으로, 조직에 등록 된 모든 장치는 특정 사용자를 허용하거나 차단 할 수있는 정책을 구축하지 않고 서비스를 액세스 할 수 있습니다.

## SMB 서버에 연결`cloudflared access`

사이트맵 터널은 WARP 클라이언트 없이 애플리케이션에 연결할 수 있는 public hostname을 통해 애플리케이션을 경로를 지정할 수 있습니다. 이 방법은`cloudflared`서버 기계와 클라이언트 기계에 둘 다에 설치해, 뿐 아니라 Cloudflare에 활동적인 지역. 트래픽은이 연결에 따라 예상되며 Cloudflare Access 자격 증명을 사용하여 서버에 로그인합니다.

public hostname 메소드는 WARP를 통해 라우팅과 함께 구현할 수 있으므로 서버에 연결하는 여러 가지 방법이 있습니다. 개인 네트워크와 공공 호스트 이름 노선 모두 동일한 터널을 재사용할 수 있습니다.

### 1. Cloudflare에 서버를 연결합니다

1. Cloudflare 만들기 다음으로 터널[대시보드 설정 가이드](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/).

2. 내 계정**자주 묻는 질문**탭, 드롭다운 메뉴에서 도메인을 선택하고 하위 도메인을 지정하십시오 (예를 들어,`smb.example.com`).

3. 제품 정보**제품정보**, 선택*사이트맵*SMB 청취 포트(예를 들어,`localhost:445`). SMB 드라이브는 항구를 듣습니다`139`또는`445`기본적으로.

4. 제품정보**제품 정보**.

### 2. (추천) 액세스 신청서 작성

기본적으로 인터넷에서 누구나 게시 된 응용 프로그램의 호스트 이름을 사용하여 서버에 연결할 수 있습니다. 특정 사용자를 허용하거나 차단하려면[자체 호스팅 응용](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/)Cloudflare 액세스.

### 3. 사용자로 연결

1. [설치하기`cloudflared`](/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/)클라이언트 기계에.

2. SMB 청취 포트를 엽니다. 당신은 클라이언트 기계에 어떤 유효한 항구든지 지정할 수 있습니다.

   ```sh
   cloudflared access tcp --hostname smb.example.com --url localhost:8445
   ```

   이 명령은 최종 사용자가 명령 줄을 사용하지 않도록 데스크탑 단축키로 감싸일 수 있습니다.

3. [SMB 클라이언트를 엽니다](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/smb/#4-connect-as-a-user)클라이언트를 설정하여`smb://localhost:8445/sambashare`. 호스트명을 입력하지 마십시오.

4. 서버 설정 중에 생성된 사용자 이름과 암호로 로그인합니다.

#### Windows 특정 요구 사항

Windows 기계를 사용하고 SMB의 포트를 지정할 수 없으면 로컬 서버를 비활성화할 수 있습니다. 클라이언트 기계의 로컬 서버는 동일한 기본 포트를 사용합니다.`445`CIFS/SMB를 위해. 해당 포트를 듣는 경우 로컬 서버는 차단할 수 있습니다.`cloudflare access`연결.

:::카트로션

Windows Server 서비스는 파일, 인쇄 및 이름 파이프와 같은 네트워크에서 공유 작업을 지원합니다. 이 서비스를 비활성화하면 그 작업을 시작할 수 있습니다.

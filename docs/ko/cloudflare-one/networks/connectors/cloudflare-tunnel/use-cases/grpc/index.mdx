## 4. (추천) Gateway 정책을 작성

구성할 수 있습니다.[Gateway 네트워크 정책](/cloudflare-one/traffic-policies/network-policies/)블록 중 하나 또는 gRPC 서버에 액세스 할 수 있습니다. 다음 예제는 두 개의 정책으로 구성됩니다: 첫 번째는 gRPC 연결이 통과하는 장치에서 허용[장치 자세 검사](/cloudflare-one/reusable-components/posture-checks/), 그리고 두번째 구획 다른 모든 교통. 허용 정책이 더 높은 것을 확인[이름 \*](/cloudflare-one/traffic-policies/order-of-enforcement/#order-of-precedence).

| 옵션 정보                    | 회사연혁  | 제품정보                                      | 로그인   | - 연혁 |
| ------------------------ | ----- | ----------------------------------------- | ----- | ---- |
| 관광 명소                    | 이름 \* | `50051`                                   | 이름 \* | 지원하다 |
| 대상 IP                    | 이름 \* | `172.31.0.133`                            | 이름 \* |      |
| Passed Device Posture 검사 | 이름 \* | `macOS firewall (Firewall)`               | 이름 \* |      |
| Passed Device Posture 검사 | 이름 \* | `macOS disk encryption (Disk encryption)` |       |      |

## 5. 클라이언트 설정

gRPC 클라이언트는 장치에서 Cloudflare WARP를 설치하고 Zero Trust 조직에 등록하여 서버에 연결할 수 있습니다. 클라이언트가 Cloudflare 터널을 통해 노출되는 개인 IP에 대한 요청을 할 때 WARP는 Cloudflare의 네트워크에 대한 연결을 우회합니다.

gRPC 클라이언트를 설정하려면:

1. [WARP 클라이언트 배포](/cloudflare-one/team-and-resources/devices/warp/deployment/)트래픽 및 DNS 모드에서 기기에.
2. [장치 등록 규칙](/cloudflare-one/team-and-resources/devices/warp/deployment/device-enrollment/)어떤 기기가 Zero Trust 조직에 등록할 수 있는지 결정하십시오.
3. 다음 장치에서 gRPC 설치[빠른 시작 가이드](https://grpc.io/docs/languages/python/quickstart/).
4. 수정하기`greeter.py`gRPC 서버의 개인 IP에 점. 이것은 동일한 개인 IP로 구성되어 있습니다.[사이트맵 터널 노선](#2-connect-the-server-to-cloudflare). 예를 들면,

```python null {6}
def run():
    #NOTE(gRPC Python 팀): .close()는 채널에서 가능하며,
    #자주 묻는 질문
    #코드의.
    print("Will try to greet world ...")
    with grpc.insecure_channel("172.31.0.133:50051") as channel:
        stub = helloworld_pb2_grpc.GreeterStub(channel)
        response = stub.SayHello(helloworld_pb2.HelloRequest(name="you"))
    print("Greeter client received: " + response.message)
```

## 6. 연결을 시험하십시오

1. 클라이언트 장치에서 WARP는`Connected`.
2. gRPC 클라이언트 응용 프로그램을 실행:


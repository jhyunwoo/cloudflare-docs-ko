여러 인스턴스를 배포하려면`cloudflared`, 하나의 터널을 만들고 여러 호스트에서 실행할 수 있습니다. 터널이 서비스로 실행되면 하나만`cloudflared`인스턴스는 호스트당 허용됩니다.

다양한 터널을 실행할 수 있습니다.`cloudflared`터널당 최대 100개의 연결 (25개의 복제) 프로세스. Cloudflare Load Balancers 및 DNS 레코드는 여전히 터널과 UUID로 포인트 할 수 있습니다. 교통은 모두 전송됩니다`cloudflared`터널과 관련된 프로세스.

:::tip\[카테고리 복제]
운행 정보`cloudflared`쿠버네티스 배포에서, 참조[Kubernetes 가이드](/cloudflare-one/networks/connectors/cloudflare-tunnel/deployment-guides/kubernetes/).
:::

## 원격 관리 터널

1. 원격 관리 터널을 만들려면[대시보드 설정 가이드](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/).
2. 에 의해**연락처**페이지, 새로 만들어진 터널을 선택하십시오.
3. 측면 패널에서 아래로 스크롤**연결관**본문 바로가기`cloudflared`그 터널의 경우.
4. 제품정보**제품정보**.
5. 복제를 배포하려는 호스트의 운영 체제를 선택합니다.
6. 설치 명령을 복사하고 호스트에서 실행합니다.

새로운 복제가 나타납니다.**연결관**터널의 목록. 모든 복제는 동일한 경로와 같은 구성 매개 변수를 사용합니다.

## 로컬 관리 터널

1. 로컬 관리 터널을 만들려면 1 \~ 5 단계를 완료하십시오.[CLI 설정 가이드](/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/local-management/create-local-tunnel/).

2. 새로 만들어진 터널을 실행하십시오.

   ```sh
   cloudflared tunnel run <NAME>
   ```

   이 시작`cloudflared`인스턴스를 생성하고`connector_id`.

3. 별도의 창 또는 다른 호스트에서 동일한 명령을 다시 실행하십시오.

   ```sh
   cloudflared tunnel run <NAME>
   ```

   이것은 또 다른 초기화`cloudflared`인스턴스 및 생성`connector_id`.

4. 지원하다`tunnel info`각을 보여주기`cloudflared`터널을 실행하는 경우:

   ```sh
   cloudflared tunnel info <NAME>
   ```

이것은 당신의 갱도 UUID 뿐 아니라 2개의 연결관 ID, 각각을 위해 하나 산출할 것입니다`cloudflared`터널을 실행하는 과정. 이 명령을 사용하면 터널이 이제 8 개의 연결으로 제공됩니다.

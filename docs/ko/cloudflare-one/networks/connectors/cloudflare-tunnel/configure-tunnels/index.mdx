이름 \*[Cloudflare 터널 제작](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/), 당신은 방법의 각종 양상을 구성할 수 있습니다`cloudflared`Cloudflare의 네트워크에 인프라를 실행하고 연결합니다. 이 섹션은 터널 성능, 보안 및 가용성을 최적화하는 고급 구성 옵션을 다룹니다.

## 일반적인 구성 시나리오

### 생산 최적화

생산 배치의 경우 다음 단계를 고려하십시오.

- [비밀번호](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-availability/deploy-replicas/)- 여러 번 실행`cloudflared`중복을 위한 인스턴스.
- [로그인](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/run-parameters/#loglevel)- 모니터링 및 문제 해결에 적합한 로그 레벨을 설정합니다.
- [리뷰 시스템 요구 사항](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-availability/system-requirements/)- 인프라가 성능 요구 사항을 충족합니다.
- [방화벽 규칙 구성](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-with-firewall/)- 보안을위한 egress-only 트래픽 패턴 구현.

### 터널을 보호

모든 터널 연결`cloudflared`그리고 Cloudflare의 네트워크는 기본적으로 TLS 1.3 및 Post-quantum 암호화로 보안되어 현재와 미래의 암호화 위협에 대한 트래픽을 보호하고 있습니다.

터널 보안 강화 :

- [Tunnel 토큰 관리](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/remote-tunnel-permissions/)- 당신의 갱도 credentials에 접근.
- [Egress-only 방화벽 규칙](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-with-firewall/)- 필요한 아웃바운드 연결을 허용한다.
- Least 특권 허가 - Run`cloudflared`터널 작업에 필요한 최소한의 권한을 가진 비 루트 사용자.

### 신뢰성 향상

터널 가동 시간 극대화:

- [다중 복제](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-availability/#cloudflared-replicas)- 배포`cloudflared`다른 호스트를 통해.
- [건강 경고](/cloudflare-one/networks/connectors/cloudflare-tunnel/monitor-tunnels/notifications/)- 터널이 급증되거나 내려갈 때 통보하십시오.
- [건강 미터](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/run-parameters/#metrics)- 잠재적인 Bottlenecks를 식별하는 갱도 자원 사용법.
- [짐 밸런싱](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-availability/#cloudflare-load-balancers/)- 터널 연결에 따른 분산 트래픽.
- [자동 장애](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-availability/)- 레버리지 내장 연결 중복.

사이트맵 터널 연결은 cipher suites를 사용합니다.`cloudflared`TLS 구현을위한 Go TLS 라이브러리에 의존합니다. 이 cipher 스위트는 Cloudflare의 네트워크와 TLS 연결을 모두 적용`cloudflared`, 그리고 HTTPS 연결 사이`cloudflared`그리고 당신의 근원. 두 경우,`cloudflared`양측에 의해 지원되는 가장 안전한 cipher 스위트 협상. 모든 터널 연결은 기본적으로 TLS 1.3 및 포스트 퀀텀 암호화를 사용합니다.

다음 표는 cipher suites가 지원했습니다.`cloudflared`:

| Protocol 지원     | Cipher 스위트                                                                                                                                                                                                                                                                                 |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| TLS 1.3 전용      | `TLS_AES_128_GCM_SHA256`<br />`TLS_AES_256_GCM_SHA384`<br />`TLS_CHACHA20_POLY1305_SHA256`                                                                                                                                                                                                 |
| TLS 1.2만        | `TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256`<br />`TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384`<br />`TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256`<br />`TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384`<br />`TLS_ECDHE_RSA_WITH_CHACHA20_POLY1305_SHA256`<br />`TLS_ECDHE_ECDSA_WITH_CHACHA20_POLY1305_SHA256` |
| 최대 및 TLS 1.2 포함 | `TLS_ECDHE_RSA_WITH_AES_256_CBC_SHA`<br />`TLS_ECDHE_RSA_WITH_AES_128_CBC_SHA`<br />`TLS_ECDHE_ECDSA_WITH_AES_256_CBC_SHA`<br />`TLS_ECDHE_ECDSA_WITH_AES_128_CBC_SHA`                                                                                                                     |

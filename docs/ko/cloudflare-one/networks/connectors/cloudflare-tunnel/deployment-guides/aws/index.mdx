이 가이드는 우리의 경량 연결관을 사용하여 Cloudflare에 아마존 웹 서비스 (AWS) 가상 기계를 연결하는 방법을 포함합니다,`cloudflared`.

우리는 배포합니다:

- 기본 HTTP 서버를 실행하는 EC2 가상 머신.
- Cloudflare의 특징 사용자가 공공 호스트 이름 또는 개인 IP 주소를 통해 서비스에 연결할 수 있도록 터널.

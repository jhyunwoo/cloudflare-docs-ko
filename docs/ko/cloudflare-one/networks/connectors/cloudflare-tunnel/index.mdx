사이트맵 터널은 공개적으로 routable IP 주소없이 Cloudflare에 리소스를 연결하는 안전한 방법을 제공합니다. 터널을 사용하면 외부 IP로 트래픽을 보내지 않습니다. 대신 인프라의 경량 데몬 (Lightweight daemon)`cloudflared`) 생성[아웃바운드 전용 연결](#outbound-only-connections)Cloudflare의 글로벌 네트워크. 사이트맵 터널은 HTTP 웹 서버를 연결할 수 있습니다.[SSH 서버](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/), [원격 데스크톱](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/rdp/)Cloudflare에 안전하게 다른 의정서. 이 방법, 당신의 근원은 Cloudflare를 우회하는 공격에 취약하지 않고 Cloudflare를 통해 교통을 봉사할 수 있습니다.

우리를 따르라[참고 자료 건축](/reference-architecture/architectures/sase/)Cloudflare 터널을 기존 인프라로 구현하는 방법에 대한 자세한 내용은.

## 어떻게 작동합니까?

`cloudflared`제품정보[아웃바운드 연결](#outbound-only-connections)(tunnels) 자원과 Cloudflare의 글로벌 네트워크 사이에. 터널은 DNS 레코드에 트래픽을 전달하는 지속적 객체입니다. 동일한 갱도 안에, 당신은 필요로 한 많은 'cloudflared'공정 (연결관)로 실행할 수 있습니다. 이 과정은 Cloudflare에 연결하고 가장 가까운 Cloudflare 데이터 센터에 트래픽을 보낼 것입니다.

![HTTP 요청이 Cloudflare 터널과 연결된 개인 응용 프로그램에 도달하는 방법](~/assets/images/cloudflare-one/connections/connect-apps/handshake.jpg)

### 아웃바운드 전용 연결

사이트맵 터널은 경계선 전용 연결 모델을 사용하여 양방향 통신을 가능하게합니다. 설치 및 실행`cloudflared`, `cloudflared`Cloudflare Global Network의 방화벽을 통해 아웃바운드 연결을 시작합니다.

연결이 설치되면, 트래픽은 기원과 Cloudflare 사이의 터널을 통해 방향으로 흐릅니다. 대부분의 방화벽은 기본적으로 아웃바운드 트래픽을 허용합니다.`cloudflared`설치 서버에서 Cloudflare 네트워크에 연결하여 이 표준을 활용`cloudflared`이름 \* 이러한 아웃바운드 연결만 허용하고 모든 인바운드 트래픽을 차단할 수 있도록 방화벽을 구성할 수 있습니다. Cloudflare 이외의 모든 소스에 효과적으로 액세스 차단. 이 설정은 모든 트래픽을 당신의 기원에 안전하게 터널을 통과한다는 것을 보장합니다.

Cloudflare는[원격 관리 터널](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/)대부분의 사용 사례. 원격 관리 터널은 Cloudflare의 구성을 저장하며 대시보드, API 또는 Terraform을 사용하여 모든 기계에서 터널을 관리할 수 있습니다.

다음 페이지는 로컬 개발, 테스트, 레거시 구성과 같은 특정 시나리오에 대한 대안 터널 워크플로우를 커버합니다.

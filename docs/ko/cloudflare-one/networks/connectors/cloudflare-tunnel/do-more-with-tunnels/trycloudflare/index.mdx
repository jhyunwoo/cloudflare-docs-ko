:::참조
빠른 터널은 테스트 및 개발에만 사용됩니다. 생산 사용을 위해,[원격 관리 터널 만들기](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/).
:::

개발자는 Cloudflare의 DNS에 사이트를 추가하지 않고 Cloudflare 터널을 실험하는 TryCloudflare 도구를 사용할 수 있습니다. TryCloudflare는 임의 하위 도메인을 생성하는 프로세스를 시작합니다.`trycloudflare.com`. 그 하위 도메인에 요청은 Cloudflare 네트워크를 통해 로컬 호스트에서 실행하는 웹 서버로 proxied.

## 사용 TryCloudflare

1. 이름 \*[이 지침](/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/)설치하기`cloudflared`. 이전 사본이있는 경우 2020.5.1 이상으로 업데이트하십시오.
2. localhost를 통해 웹 서버를 실행`cloudflared`.
3. 다음 터미널 명령을 실행하여 무료 터널을 시작합니다.

```sh
cloudflared tunnel --url http://localhost:8080
```

`cloudflared`Cloudflare 네트워크에 연결하면 임의 하위 도메인을 생성하고 사용 및 공유 할 수있는 터미널에서 인쇄 할 수 있습니다. 출력은 공공 인터넷에 로컬 머신에서 서버에서 트래픽을 제공 할 것입니다. Cloudflare의 Argo Smart Routing을 사용하여 공공 URL에서.

:::참조

TryCloudflare 빠른 터널은 현재 지원되지 않습니다.`config.yaml`구성 파일은 현재`.cloudflared`디렉토리. 파일을 일시적으로 사용하려면 이름을 변경해야 할 수도 있습니다.

## 제품 정보

### TryCloudflare를 위한 몇몇 예 사용 사례는 무엇입니까?

- 다른 네트워크에서 다른 사람들과 공유하고 싶은 노트북에 대한 웹 서버를 만듭니다.
- 무료 터널을 만들고 다른 브라우저의 링크를 테스트하여 새로운 사이트에 대한 브라우저 호환성을 테스트
- Pingdom 또는 WebPageTest와 같은 도구를 사용하여 다른 지역에서 속도를 테스트하여 TryCloudflare에 의해 생성 된 무작위로 생성 된 하위 도메인에 연결하십시오.

### Cloudflare는 왜 이 서비스를 무료로 제공합니까?

- Cloudflare 터널의 속도와 보안 향상을 경험하기 위해 더 많은 사용자를 원합니다 (그리고 Argo Smart Routing). TryCloudflare로 테스트하고 생산 현장에 추가하기로 결정합니다.
- Cloudflare의 기능은 실제로 도메인을 소유해야 하며, Cloudflare의 네임서버에 도메인의 DNS를 설정하고, DNS 레코드를 구성하기 전에 모든 서비스를 사용할 수 있습니다. 우리는 그 부담 없이 평가할 수 있는 우리의 제품의 점점 더 많은 것을 만들 것을 희망합니다.
- 우리는 TryCloudflare의 SLA 또는 가동 시간을 보장하지 않습니다 - 우리는 새로운 Cloudflare 갱도 특징을 시험하고 이 자유로운 갱도에 개선 계획합니다. 우리는 생산 고객에게 배포하기 전에 테스트하기 위해 연결 그룹을 제공합니다. 무료 터널은 생산 웹 사이트를 배포하지 않는 테스트 및 개발을 위해 사용되지 않습니다.

### 제한 사항

- 빠른 터널은 시간에 어떤 시점에서 proxied 할 수있는 동시 요청의 수에 대한 단단한 한계에 적용됩니다. 현재 이 제한은 200 in-flight 요청입니다. 빠른 터널이 한계를 보았을 경우 HTTP 응답이 반환됩니다.`429`상태 코드.
- 빠른 터널은 Server-Sent 이벤트 (SSE)를 지원하지 않습니다.

이 제한은 Quick Tunnels에만 적용됩니다. 이러한 제한을 피하기 위해,[로그인](https://dash.cloudflare.com/sign-up)Cloudflare 계정 및[Cloudflare 터널 생성](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/).

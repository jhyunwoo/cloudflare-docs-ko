## 개인 네트워크

| 이름 \*                                                      | 이름 \*                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cloudflared tunnel route ip add <IP/CIDR> <NAME or UUID>` | 어떤 네트워크 경로 공간 추가 (CIDR로 대표) 당신의 여정 테이블에. 그 네트워크 공간은 Cloudflare WARP를 사용하고 있기 때문에 사용자의 기계에서 egressing 요청을 위해 도달되고 여기에서 선택된 터널을 실행하는 동일한 계정에 등록됩니다. 그 요청은 지정된 터널에 proxied, 그리고 주어진 CIDR에 IP를 도달, 터널에서 도달 할 때. 특정 IP 경로 지정[가상 네트워크](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/tunnel-virtual-networks/), 사용`--vnet`옵션. |
| `cloudflared tunnel route ip show`(주)`list`)               | 조직의 개인 라우팅 테이블을 표시합니다. 추가 플래그를 사용하여 결과를 필터링 할 수 있습니다.                                                                                                                                                                                                                                                                                                   |
| `cloudflared tunnel route ip delete`                       | routing table에서 주어진 CIDR의 행을 삭제합니다. 네트워크의 그 부분은 WARP 클라이언트에 의해 더 이상 도달할 수 없습니다.                                                                                                                                                                                                                                                                         |
| `cloudflared tunnel route ip get <IP/CIDR>`                | routing 테이블의 행이 주어진 IP를 프록시에 사용할 수 있는지 확인합니다. 이 도움말을 확인하고 구성을 검증합니다.                                                                                                                                                                                                                                                                                    |
| `cloudflared tunnel vnet add <NAME or UUID>`               | IP 경로가 할당될 수 있는 가상 네트워크 만들기. 이 Virtual Network를 만들기 위해 Zero Trust 조직에 대한 기본 설정은 사용`-d`플래그.                                                                                                                                                                                                                                                              |
| `cloudflared tunnel vnet delete <NAME or UUID>`            | 주어진 이름 또는 UUID로 가상 네트워크 삭제. Virtual Network를 삭제하기 전에 먼저 가상 네트워크에 할당 된 모든 IP 루트를 삭제해야합니다.                                                                                                                                                                                                                                                                |
| `cloudflared tunnel vnet list`                             | 모든 활성 가상 네트워크, 기본 가상 네트워크 및 생성 시간을 표시합니다.                                                                                                                                                                                                                                                                                                               |

`cloudflared`Cloudflare 네트워크에서 한 번 유효한 개인 네트워크 및 프록시 로컬 트래픽에서 거의 모든 호스트 기계를 실행할 수있는 데몬 서비스입니다. Cloudflare 터널 제작`cloudflared`아웃바운드 전용이며, 프록시 요청은 사용자에서 개인 네트워크로 시작됩니다. 터널 뒤에 실행되는 서비스 또는 응용 프로그램에 의해 요청은 서버의 기본 라우팅 테이블을 사용합니다.

클라이언트 측에, 최종 사용자는 Cloudflare WARP 클라이언트를 사용하여 Cloudflare의 글로벌 네트워크에 연결합니다. WARP 클라이언트는 사내 MDM 툴링을 사용하여 몇 분 만에 전체 조직으로 나눌 수 있습니다. Cloudflare 터널을 통해 사용할 수있는 IP 주소 또는 호스트 이름에 연결할 때 WARP는 Cloudflare의 네트워크와 내부 서비스에 해당 터널을 통해 연결을 보냅니다. 터널 뒤에 서비스에 트래픽은 호스트 기계의 로컬 소스 IP 주소를 실행한다`cloudflared`이름 \*

![장치, Cloudflare 및 개인 네트워크 간의 연결을 표시합니다.](~/assets/images/cloudflare-one/connections/private-ips-diagram.png)

개인 네트워크에 원격 액세스를 활성화하려면 다음 가이드를 참조하십시오.

- [**개인 별명 연결**](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/connect-private-hostname/): 역명을 사용하여 내부 애플리케이션에 경로 네트워크 트래픽.
- [**IP/CIDR 연결**](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/connect-cidr/): 내부 IP 주소 또는 CIDR 범위의 경로 트래픽.

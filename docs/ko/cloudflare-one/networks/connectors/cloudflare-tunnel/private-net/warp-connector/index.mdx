주요 특징

Cloudflare WARP 커넥터 (베타)는 소프트웨어 클라이언트입니다[^1]사이트 현장, 양방향 및 메쉬 네트워킹 연결을 가능하게하는 것은 네트워크 라우팅 인프라의 변화가 필요없습니다. 사이트맵 연결관은 개인적인 네트워크와 Cloudflare 사이 안전한 층 3 프록시를 설치하고, 당신을 허용하:

- 두 개 이상의 개인 네트워크를 서로 연결합니다.
- 외부 소프트웨어를 실행할 수 없는 IoT 기기를 프린터 및 IP 폰과 같은 연결합니다.
- VoIP 및 SIP 트래픽과 같은 필터 및 로그 서버 개시 트래픽.
- 요청의 소스 IP를 기반으로 Zero Trust 보안 정책을 적용하십시오.

![WARP 연결관과 연결된 2개의 subnets](~/assets/images/cloudflare-one/connections/connect-apps/warp-connector/overview.png)

다이어그램에 표시된 WARP 커넥터는 Cloudflare를 통해 개인 네트워크 내에서 서브넷을 위한 라우터 역할을 합니다. 서브넷의 모든 장치는 Cloudflare에 연결된 모든 서비스에 액세스 할 수 있으며, Cloudflare에 연결된 모든 장치는 서브넷에 어떤 서비스를 액세스 할 수 있습니다. 각 서브넷은 지정된 Linux 기계에 WARP 커넥터를 실행합니다 (일반적으로[기본 Gateway 라우터](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/warp-connector/site-to-internet/#3-route-traffic-from-subnet-to-warp-connector)), 그러나 네트워크에 다른 장치는 소프트웨어를 설치할 필요가 없습니다.

WARP 커넥터를 설정하려면 사용 사례에 대한 가이드를 참조하십시오.

- **[사이트-인터넷](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/warp-connector/site-to-internet/)**: 개인 네트워크에서 인터넷에 요청을 보냅니다.
- **[사이트 맵](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/warp-connector/site-to-site/)**: 두 개 이상의 개인 네트워크 간의 요청을 보냅니다.
- **[사용자 정보](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/warp-connector/user-to-site/)**: WARP 클라이언트 장치를 허용하여 개인 네트워크에 요청을 보낼 수 있습니다.
- **인터넷 사이트**: WARP 커넥터에 의해 지원되지 않습니다. 개인 네트워크에서 애플리케이션에 대한 clientless 액세스를 제공하기 위해 설정[사이트맵 터널과`cloudflared`](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/)그리고 구성[관련 앱](/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/).

[^1]: 사이트맵 연결관은의 연장입니다[WARP 클라이언트](/cloudflare-one/team-and-resources/devices/warp/).

사이트맵 터널은 공공 호스트 이름을 통해 로컬 애플리케이션을 인터넷에 게시 할 수 있습니다. 예를 들면, 당신은 할 수 있습니다[게시된 응용 경로 추가](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/#2a-publish-an-application)그 점`docs.example.com`으로`https://localhost:8080`. Anyone는 이제까지 당신의 신청을 전망할 수 있습니다`docs.example.com`웹 브라우저에서.

Cloudflare는 Cloudflare 터널을 이용하여 트래픽을 우회할 수 있습니다.[DNS 기록](/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/dns/)또는[Cloudflare 로드밸런서](/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/public-load-balancers/). 당신은 DNS를 지적해서 Cloudflare 대시보드에서 선택권을 구성할 수 있습니다`CNAME`당신의 Cloudflare 갱도 subdomain에 기록 또는 짐 balancer 수영장 (`<UUID>.cfargotunnel.com`). 당신은 또한이 기록과 터널을 연결할 수 있습니다`cloudflared`직접.

:::참조

Cloudflare 터널을 통해 응용 프로그램을 게시 할 유료 Cloudflare 액세스 계획이 필요하지 않습니다.[오시는 길](/cloudflare-one/team-and-resources/users/seat-management/)당신이 원하는 경우에만 필수[액세스 정책을 사용하여 응용 프로그램을 확보](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/)ID 공급자를 통해 로그인할 필요가 있는 사용자와 같은.

:::

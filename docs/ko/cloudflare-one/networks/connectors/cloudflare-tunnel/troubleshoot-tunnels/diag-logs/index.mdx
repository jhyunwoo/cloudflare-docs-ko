사이트맵 터널은 문제 해결에 사용될 수있는 진단 로그 세트를 생성합니다.`cloudflared`. 진단 보고서는 단일 인스턴스에서 데이터를 수집합니다.`cloudflared`현지 기계에서 실행.

## 진단 로그 받기

진단 로그를 얻는 단계는 당신의 것에 달려 있습니다`cloudflared`배포 환경.

### 자주 묻는 질문

- `cloudflared`버전 2024.12.2 이상에 설치

### 호스트 환경

이 지침은 원격 관리 및 로컬 관리 터널을 호스트 기계에서 직접 실행합니다.

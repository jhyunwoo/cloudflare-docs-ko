## 터널 상태

Cloudflare에서 터널의 연결 상태를 확인할 수 있습니다. 1 (에 의해 이동**네트워크** > **연결관** > **사이트맵 연락처**) 또는 실행하여`cloudflared tunnel list`명령. 각 갱도는 그것의 현재 연결 상태를 반영하는 상태를 표시합니다:

## 내 터널은 무작위로 차단합니다.

Cloudflare를 통한 오랜 연결 개시 SSH 세션과 같은 하나는 8 시간까지 지속될 수 있습니다. 그러나 서비스 경로를 따라 중단은 더 빈번한 차단으로 발생할 수 있습니다. 종종, 이러한 분리는 데이터 센터, 서버, 서비스 업데이트 및 재시작과 같은 정기적인 유지보수 이벤트에 의해 발생합니다. 이 행사를 믿지 않는 경우, 당신의 환경에서 분리의 원인이 되지 않습니다.[WARP 로그](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/warp-logs/)·[터널 로그](/cloudflare-one/networks/connectors/cloudflare-tunnel/monitor-tunnels/logs/)연락처 지원

## `ping`·`traceroute`명령은 작동하지 않습니다.

Cloudflare 터널 뒤에 IP 주소를 핑하려면 시스템을 통해 ICMP 트래픽을 허용해야합니다.`cloudflared`. 윤곽 지시를 위해, 참조하십시오[ICMP 프록시 문서](/cloudflare-one/traffic-policies/proxy/#icmp).

## 나는`Error: This route's network is inside an existing subnet's network at "100.96.0.0/12"`.

이 오류는 Cloudflare WARP의 WARP에서 떨어지는 CIDR 경로를 추가하려고 할 때 발생합니다.<GlossaryTooltip term="WARP CGNAT IP">CGNAT IP 범위</GlossaryTooltip>·`100.96.0.0/12`범위, 어느 주소에서 커버`100.96.0.1`으로`100.111.255.254`WARP 라우팅은 Cloudflare 터널 루트로 추가할 수 없습니다. 개인 네트워크를 연결하려면 IP/CIDR을 변경해야 합니다.`100.96.0.0/12`.

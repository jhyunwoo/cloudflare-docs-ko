## 문제 해결

터널 건강 경고를 받았지만 트래픽에 영향을 미치는지 확실하지 않습니다.[문제 해결 연결](/cloudflare-one/networks/connectors/cloudflare-wan/troubleshooting/connectivity/)경고가 관련인지 결정하기 위해.

당신의 갱도가 건강하거나 degraded로 보여주면, 나타납니다[Troubleshoot 갱도 건강](/cloudflare-one/networks/connectors/cloudflare-wan/troubleshooting/tunnel-health/)일반적인 문제와 해결책을 위해.

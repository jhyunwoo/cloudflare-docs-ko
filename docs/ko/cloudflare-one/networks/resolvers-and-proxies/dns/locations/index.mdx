## DNS 엔드포인트

### IPv4 및 IPv6 DNS

Cloudflare는 미리 채울 것입니다[**소스 IPv4 주소**](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#source-ip)네트워크에 기반을 두고 있습니다. 또한 Enterprise 사용자는 사용할 수 있습니다.[전용 DNS 해결자 IP 주소](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#dns-resolver-ip)계정으로 할당하거나[해결자 IP 주소 (BYOIP)](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#bring-your-own-dns-resolver-ip).

IPv4 DNS 엔드포인트를 구성할 필요가 없습니다:

- 네트워크는 IPv6만 사용합니다.
- 사용자는 이 위치에서 모든 DNS 요청을 보낼 것입니다.[HTTPS에서 DNS](#dns-over-https-doh)본문 바로가기
- 당신은 배포합니다[WARP 클라이언트](/cloudflare-one/team-and-resources/devices/warp/).

:::note\[당신의 IPv4 주소는 오류가 발생]
IPv4에 DNS 위치를 구성하려고 할 때 Gateway가 표시될 수 있습니다.**소스 IPv4 주소가 촬영됩니다.**&#xC624;류. 이것은 당신이 한 전에 동일한 네트워크 구성 게이트웨이에서 다른 사람을 의미 할 수있다. 네트워크가 IPv6를 지원한다면, 여전히 IPv6를 통해 DNS 쿼리를 전송하여 Gateway의 DNS 필터링을 사용할 수 있습니다. 또한 HTTPS 클라이언트에 DNS를 사용하여 쿼리를 보낼 HTTPS 호스트 이름에 DNS를 사용할 수 있습니다.

만약 누군가가 이 IPv4 주소를 잘못 사용한다면,[접촉 Cloudflare 지원](/support/contacting-cloudflare-support/#getting-help-with-an-issue).
:::

## 보안 DNS 위치

Secure DNS 위치는 악성 도메인에 대한 추가 보호를 제공합니다.[보호 DNS (PDNS)](/reference-architecture/diagrams/sase/gateway-for-protective-dns/). 보안을 고려하기 위해 DNS 위치를 위해 Gateway는 다음과 같습니다.

- IPv4 및 IPv6 엔드포인트를 사용하여[BYOIP 주소](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#bring-your-own-dns-resolver-ip)(모든 경우).
- [소스 네트워크 필터링](/cloudflare-one/traffic-policies/network-policies/)IPv4, IPv6 및 DoT 엔드포인트를 위해 구성됩니다.
- 소스 네트워크 필터링 또는 토큰 인증은 DoH 엔드포인트를 위해 구성됩니다.
- DNS 위치에 대한 모든 활성화 엔드 포인트는 보안 권한을 충족합니다.

사용자를 할당할 수 있습니다.[**Cloudflare Zero Trust DNS 위치 쓰기**이름 \*](/cloudflare-one/roles-permissions/#zero-trust-roles)보안 DNS 위치를 만들고 편집할 권한을 부여합니다. 사용자가 위치를 볼 수 있도록, 당신은 또한 할당해야합니다**Cloudflare Zero Trust 읽기 전용**역할. 이러한 역할과 사용자는 DNS 위치를 볼 수 있지만 보안 위치를 만들거나 편집 할 수 있습니다.

supersede 역할**Cloudflare Zero Trust DNS 위치 쓰기**다음:

- 사이트맵 오시는 길
- Cloudflare Zero Trust
- 슈퍼 관리자

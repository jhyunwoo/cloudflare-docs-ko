기본적으로 DNS는 일반 텍스트 연결을 통해 전송됩니다. DNS over TLS (DoT)는 DNS 쿼리를 암호화하여 보안 및 개인을 보호합니다. DoT는 같은 보안 프로토콜, TLS, HTTPS 웹 사이트가 암호화 및 인증 통신을 사용합니다.

Cloudflare는 표준 항구에 DoT를 지원합니다`853`TLS 1.2 및 TLS 1.3 이상 준수[RFC7858를](https://tools.ietf.org/html/rfc7858).

## DoT 쿼리 구성

### 1. DoT 호스트 이름 얻기

각 게이트웨이 DNS 위치에는 독특한 DoT 호스트 이름이 있습니다. DNS 위치 및 해당 DoT 호스트 이름에는 해당 정책이 있습니다.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**네트워크** > **해결사 및 Proxies**.
2. 이름 \***DNS 위치**, [새로운 위치를 추가](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/)또는 목록에서 기존 위치를 선택하십시오.
3. 이름 \***DoT 엔드포인트**, 값을 안으로 복사하십시오**DoT 주소**.

DoT hostname은 고유한 위치 이름을 포함합니다. 예를 들어, DoT hostname이 있는 경우`9y65g5srsm.cloudflare-gateway.com`, 위치 이름은`9y65g5srsm`.

### 2. DoT 클라이언트 구성

같은 DoT 클라이언트를 구성하려면`dig`, IP 주소와 DoT hostname을 쿼리의 위치에 지정합니다. 예를 들면:

```txt
Hostname: 9y65g5srsm.cloudflare-gateway.com
IP address: 162.159.36.5
```

대체적으로, 당신은 일반 DoT endpoint를 사용할 수 있습니다 (`dns.cloudflare-gateway.com`) 그리고 포함`OPT`비밀번호`65011`. 값의 특정 위치를 선택할 수 있습니다.`OPT`이름 \* 예를 들면:

```txt
Hostname: dns.cloudflare-gateway.com
IP address: 162.159.36.5
OPT Record:
  - Code: 65011
  - Value: 9y65g5srsm
```

몇몇 stub 결실은 기본적으로 DoT를 지원합니다. 예를 들어, DoT 쿼리를 보내려면 Unbound를 구성할 수 있습니다.

```txt
# Unbound TLS Config
tls-cert-bundle: "/etc/ssl/cert.pem"
# Forwarding Config
forward-zone:
 name: "."
 forward-tls-upstream: yes
 forward-addr: 162.159.36.5@853#9y65g5srsm.cloudflare-gateway.com
 forward-addr: 2001:db8:abcd::1234#9y65g5srsm.cloudflare-gateway.com
```

경로는 IP 주소 또는 호스트명을 지도합니다.[사이트맵 1개의 연결관](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/#connectors)개인 네트워크에 설치. Cloudflare의 네트워크를 통해 IP 또는 호스트 이름에 연결하면 Cloudflare는 개인 네트워크에서 해당 리소스에 대한 보안 터널을 우회합니다.

## CIDR 노선 추가

CIDR 경로는 IP 네트워크 세그먼트를 정의합니다 (예 :`10.0.0.0/24`Cloudflare 터널을 통해 도달 할 수 있습니다.

:::노트\[필수]
CIDR 경로를 추가하기 전에 Cloudflare 터널을 생성해야 합니다.[`cloudflared`](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/)또는[WARP 연결관](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/warp-connector/site-to-site/).
:::

CIDR 노선을 추가하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**네트워크** > **오시는 길** > **CIDR 소개**.
2. 제품정보**CIDR 노선 추가**.
3. 내 계정**CIDR 소개**터널을 통과하려는 IP 주소 또는 CIDR 범위를 입력 (예를 들어,`10.0.0.1`또는`10.0.0.0/24`). 개인 또는 공공 IP가 될 수 있습니다.
4. 제품 정보**관련 제품**, Cloudflare 터널을 선택하여 Cloudflare에 개인 네트워크를 연결할 수 있습니다.
5. (선택) 밑에**추가 설정**, 선택[가상 네트워크](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/tunnel-virtual-networks/)이 갱도 노선을 위해. 이 단계는 경로의 IP / CIDR 범위가 계정의 다른 경로로 오버랩을 필요로합니다. 가상 네트워크를 선택하지 않으면 IP 경로가 할당됩니다.`default`네트워크.
   :::참조
   가상 네트워크만 지원됩니다.`cloudflared`터널.
   주요 특징
6. 제품정보**이름 \***.

Cloudflare는 이제 개인 네트워크에 요청을 전달합니다. 그러나, 경로는 자동으로 최종 사용자로부터 트래픽을 캡처하지 않습니다. 클라이언트 측 연결을 활성화하려면, 참조[구름 많음](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/connect-cidr/)또는
[WARP 연결관](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/warp-connector/site-to-site/)설정 가이드.

## hostname 경로 추가

Cloudflare 터널 아래 공공 또는 개인 호스트 이름에 대한 호스트 이름 경로 스티어 트래픽. 사용자가 익숙한 URL을 사용하여 내부 리소스에 액세스 할 수 있습니다 (예 :`wiki.internal.local`) IP 주소 보다는 오히려.

:::노트\[필수]
hostname 루트를 추가하기 전에 Cloudflare 터널을 생성해야 합니다.[`cloudflared`](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/).
:::

hostname 루트를 추가하려면:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**네트워크** > **오시는 길** > **Hostname 노선**.
2. 제품정보**hostname 경로 만들기**.
3. 내 계정**이름 \***, 응용 프로그램을 나타내는 개인 또는 공공 hostname을 입력 (예를 들어,`wiki.internal.local`또는`app.bank.com`).
4. 제품 정보**관련 제품**, Cloudflare 터널을 선택하여 Cloudflare에 개인 네트워크를 연결할 수 있습니다.
5. 제품정보**이름 \***.

Cloudflare는 이제 개인 네트워크에 요청을 전달합니다. 그러나, 경로는 자동으로 최종 사용자로부터 트래픽을 캡처하지 않습니다. 클라이언트 측 연결을 활성화하려면, 참조[개인 별명](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/connect-private-hostname/)또는[공유 hostname](/cloudflare-one/traffic-policies/egress-policies/egress-cloudflared/#3-route-network-traffic-through-warp)설정 가이드.

## 게시 된 응용 프로그램 루트 추가

Cloudflare에 연결 된 도메인을 통해 인터넷에 응용 프로그램을 노출. 사용자는 VPN 또는 전문 클라이언트 소프트웨어를 필요로하지 않고 응용 프로그램을 액세스 할 수 있습니다.

:::노트\[필수]
응용 프로그램을 게시하기 전에, 당신은 가지고:

- [Cloudflare 터널 만들기](/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/)이름 \*`cloudflared`.
- [Cloudflare에 웹 사이트 추가](/fundamentals/manage-domains/add-site/).
  :::

기존 터널에 게시된 애플리케이션 경로 추가하기:

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com), 이동**네트워크** > **연락처**.

2. 터널을 선택하고 선택**제품정보**.

3. 오시는 길**자주 묻는 질문**탭 및 선택**게시 된 응용 프로그램 루트 추가**.

4. 하위 도메인을 입력하고 선택**이름 \***&#xB4DC;롭다운 메뉴에서. 하위 도메인 또는 경로 정보를 지정합니다.
   :::참조
   Multi-level subdomain (subdomain의 1 개 이상의 레벨)을 추가하면,[hostname에 대한 고급 인증서를 주문](/cloudflare-one/faq/troubleshooting/#i-see-this-site-cant-provide-a-secure-connection).
   :::

5. 이름 \***제품정보**, 선택합니다[서비스 유형](/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/protocols/)URL을 지정합니다. 예를 들면:
   - **제품정보**: *HTTP: HTTP*
   - **사이트 맵**: `localhost:8000`

6. 이름 \***추가 신청 설정**, 어떤 지정[이름 \*](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/origin-parameters/)터널 구성에 추가하고 싶습니다.

7. 제품정보**제품 정보**.

인터넷에서 누구나 지정된 호스트 이름에서 응용 프로그램을 액세스 할 수 있습니다. 특정 사용자를 허용하거나 차단하기 위해,[액세스 신청서 작성](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/).

## WAN 노선 추가

WAN 경로는 IP 네트워크 세그먼트 정의 (예 :`10.0.0.0/24`) GRE 또는 IPsec 터널을 통해 도달 할 수 있습니다. WAN 루트를 추가하려면, 참조[WAN 커넥터 문서](/cloudflare-one/networks/connectors/cloudflare-wan/configuration/manually/how-to/configure-routes/).

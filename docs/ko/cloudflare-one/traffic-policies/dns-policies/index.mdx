사용자가 게이트웨이에 DNS 요청을 할 때 게이트웨이는 조직에 설정 한 DNS 정책에 대한 요청을 일치시킵니다. 도메인이 차단된 범주에 속하지 않거나, 오버라이드 정책과 일치한다면, 사용자의 클라이언트는 Cloudflare의 1.1.1.1 서버에서 DNS 해상도를 기반으로 주소를받습니다. 대안으로, 당신은 사용할 수 있습니다[해결 정책](/cloudflare-one/traffic-policies/resolver-policies/)사용자 정의 서버에 DNS 요청을 리디렉션합니다.

DNS 정책&#xC740;**- 연혁**또한 행동의 범위를 결정하는 논리 표현. 표현을 만들기 위해, 당신은 선택할 필요가**옵션 정보**한국어**회사연혁**, 값 또는 값의 범위를 입력**제품정보**이름 \* 사용 가능**이름 \***·**또는**여러 조건을 평가하는 논리 연산자.

DNS 정책을 만들 때, 네트워크의 보안 위험 범주 및 콘텐츠 범주로 선택할 수 있습니다. 더 구체적인 선택자는 정책에 구성되지 않습니다 (예를 들어,*사용자 이메일*또는*근원 IP*), 다음 정책은 조직의 Gateway에 도달하는 모든 DNS 쿼리에 대해 평가됩니다.

#### DNSSEC 유효성 검사

당신이 선택할 때**DNSSEC 유효성 검사**, 게이트웨이는 DNS 레코드의 암호화 서명이 유효할 수 없는 경우에도 DNS 쿼리를 해결합니다. 우리는 검증 실패가 DNSSEC 구성 문제로 인해 악의적 인 공격이 아니라면 DNSSEC 검증을 해제하는 것이 좋습니다.

#### 주문 블록 페이지

블록 동작을 선택할 때, 켜기**Gateway 블록 동작 변경**웹 사이트를 차단하는 사용자가 표시하는 블록 페이지로 쿼리에 응답합니다. 선택적으로, 당신은 특정 DNS 정책을 리디렉션 URL로 글로벌 블록 페이지를 설정 삭제할 수 있습니다. 더 많은 정보를 원하시면, 참조[블록 페이지](/cloudflare-one/reusable-components/custom-pages/gateway-block-page/).

블록 페이지가 정책을 해제되면 게이트웨이는 DNS 수준에서 차단된 쿼리에 응답합니다.`A`이름 \*`0.0.0.0`IPv4 목적지에 대한, 또는`AAAA`이름 \*`::`IPv6 목적지. 브라우저는 기본 연결 오류 페이지를 표시합니다.

이 selector를 사용하여 쿼리가 해결하는 대륙에 기반을 둔 필터를 사용합니다. Geolocation은 응답의 IP 주소에서 결정됩니다. 대륙을 지정하려면 두 개의 터미널 코드를 입력하십시오.**제품정보**유형:

- AF - 아프리카
- 아 - 남극
- AS - 아시아
- EU - 유럽
- NA - 북미
- 오세아니아
- SA - 남미
- T1 - 토 네트워크

### Cloudflare WAN 운송

DNS 정책을 통해 전달된 쿼리에 적용[Cloudflare 대만](/cloudflare-wan/zero-trust/cloudflare-gateway/), 당신은 IPv6, DoH, 또는 DoT 엔드포인트에 조직의 DNS 해설기를 점유하거나 전용 해설 IPv4 주소를 요청할 수 있습니다. 더 많은 정보를 원하시면, 참조[DNS 해결자 IP 및 호스트 이름](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/).

### 파이어백 DNS

WhatsApp 및 Android Studio와 같은 일부 앱은 하드 코딩 된 fallback DNS 서버를 사용합니다. Fallback DNS는 Gateway DNS 정책을 통해 예상치 못한 행동을 일으킬 수 있습니다. 예를 들어, 블록 DNS 정책을 가지고 있다면 게이트웨이는 초기 앱에서 DNS 쿼리를 차단하지만, 쿼리는 드롭백 DNS를 사용하여 올바르게 수행 할 수 있습니다. 이 행동을 완화하려면,[Gateway Network 정책](/cloudflare-one/traffic-policies/network-policies/)TCP/UDP 포트에서 아웃바운드 DNS 트래픽 차단`53`fallback DNS 서버로. 예를 들어, Google의 fallback DNS 서버를 차단하려면:

| 옵션 정보 | 회사연혁 | 제품정보                 | 로그인   | - 연혁 |
| ----- | ---- | -------------------- | ----- | ---- |
| 프로젝트  | 내 계정 | *TCP 포트*, *사이트맵*     | 이름 \* | 제품정보 |
| 관광 명소 | 내 계정 | `53`                 | 이름 \* |      |
| 대상 IP | 내 계정 | `8.8.8.8`, `8.8.4.4` |       |      |

다음 정책은 일반적으로 DNS 트래픽을 확보하는 데 사용됩니다.

권장 정책의 기본 설정에 대한 참조[인터넷 트래픽 및 SaaS 앱 보안](/learning-paths/secure-internet-traffic/build-dns-policies/recommended-dns-policies/).

더 알아보기[DNS 정책 페이지](/cloudflare-one/traffic-policies/dns-policies/)다른 selectors, 연산자 및 작업의 종합 목록.

## 기업 도메인

이 정책은 사용자가 공식 법인 도메인에 액세스 할 수 있습니다. 높은 정책 배포[우선순위](/cloudflare-one/traffic-policies/order-of-enforcement/#order-of-precedence), 당신은 직원이 신뢰할 수있는 도메인에 액세스 할 수 있는지 확인 그들은 같은 블록 카테고리에서 떨어지면*새로 본 도메인*또는*로그인 페이지*.

## 범주의 동적 목록 블록

범주 ID 목록을 추가 할 수 있습니다.[EDNS 헤더](https://datatracker.ietf.org/doc/html/rfc6891)OPT 코드를 사용하여 Gateway에 JSON 객체로 전송된 요청`65050`. 예를 들면:

```json
{
	"categories": [2, 67, 125, 133]
}
```

이름 \*[Context 카테고리](/cloudflare-one/traffic-policies/dns-policies/#request-context-categories)selector, EDNS로 전송된 카테고리 ID를 차단할 수 있습니다. 이 문서는 저작권법의 보호를 받습니다. 이 문서는 저작권법의 보호를 받습니다. 게이트웨이는 DNS 쿼리를 차단하기 위해이 선택기를 사용 할 때, 요청은 확장 된 DNS 오류 (EDE) 코드 15 - 일치 된 카테고리의 배열을 포함하는 필드와 함께 블록 오류를 반환합니다.

## 금지된 국가 차단

당신은 높은 위험으로 분류 된 국가에서 호스팅 된 웹 사이트를 차단하는 정책을 구현할 수 있습니다. 이러한 국가의 지정은 조직의 고객 또는 규정을 통해 발생할 수 있습니다.[제품정보](https://www.tradecompliance.pitt.edu/embargoed-and-sanctioned-countries), [한국어](https://orpa.princeton.edu/export-controls/sanctioned-countries)·[사이트맵](https://www.tradecompliance.pitt.edu/embargoed-and-sanctioned-countries).

## 블록 최상위 도메인

회사 소개[자주 사용되는](https://www.spamhaus.org/statistics/tlds/)최고 수준의 도메인(TLD)은 보안 위험을 줄일 수 있으며, 특히 액세스할 수 있도록 얻은 신중한 장점이 없습니다. 마찬가지로 특정 국가 수준의 TLD에 대한 액세스를 제한하는 것은 규정 준수해야 할 수 있습니다.[사이트맵](https://www.tradecompliance.pitt.edu/embargoed-and-sanctioned-countries)또는[한국어](https://orpa.princeton.edu/export-controls/sanctioned-countries).

## 블록 피싱 공격

에 대한 보호[정교한 피싱 공격](https://blog.cloudflare.com/2022-07-sms-phishing-attacks/), 당신은 특정 조직을 타겟팅하는 phishing 도메인에 액세스하여 사용자를 방지 할 수 있습니다. 다음 정책은 조직 또는 인증 서비스와 관련된 특정 키워드를 차단합니다 (예 :*뚱 베어*, *2파*, *구름 많음*또는*뚱 베어*), 여전히 공식 법인 도메인에 액세스 할 수 있습니다.

    | ----- | -------- | ------------------------------------------- | ----- | ---- |
    | 이름 \* | 이름 \*    | *기업 도메인*                                    | 이름 \* | 제품정보 |
    | 이름 \* | 경기 regex | `.*okta.*\|.*cloudflare.*\|.*mfa.*\|.sso.*` |       |      |

    />

    목록의 UUIDs를 얻으려면, 사용[목록 Zero Trust 목록](/api/resources/zero_trust/subresources/gateway/subresources/lists/methods/list/)끝점.

## CIPA 필터 켜기

CIPA (Children's Internet Protection Act) 필터는 미성년자에 대한 유해하거나 부적절한 주제의 광범위를 우회하는 하위 범주의 컬렉션입니다. 그것은의 일부로 사용됩니다[프로젝트 Cybersafe 학교](/fundamentals/reference/policies-compliances/cybersafe/)원치 않는 유해한 온라인 콘텐츠에 대한 액세스를 차단합니다. 이 정책을 작성하면 조직이 최소한이어야합니다.[CIPA 준수](https://www.fcc.gov/consumers/guides/childrens-internet-protection-act).

## IP 버전 제어

Enterprise 사용자는 이러한 정책을 켤 수 있습니다.[egress 정책](/cloudflare-one/traffic-policies/egress-policies/)IP 버전이 Origin 서버에 egress에 사용됩니다.

선택적으로, 당신은 특정한 위치를 위한 IP 버전을 통제하기 위하여 도메인 selector를 사용할 수 있습니다.

:::참조
선호하는 IP 버전을 통해 트래픽 경로를 보장하기 위해, 턴오프**Gateway 블록 동작 변경**.
:::

### 힘 IPv4

힘 사용자는 IPv6 해결책을 차단해서 IPv4도 연결하기 위하여.

Cloudflare 네트워크 방화벽은 다음과 같은 다양한 패킷 특성에 트래픽을 허용하거나 차단할 수 있습니다.

- **근원과 목적지 IP**— 보낸 사람 및 수신기의 IP 주소
- **근원과 목적지 항구**- 특정 서비스를 식별하는 숫자 포트 (예를 들어, HTTP 포트 80)
- **프로젝트**— TCP 또는 UDP와 같은 통신 방법
- **Packet 길이**— 바이트에 패킷의 크기
- **<GlossaryTooltip term="bit field matching">비트 필드 일치</GlossaryTooltip>**— 패킷 헤더 내에서 개별 플래그를 검사

Cloudflare 네트워크 방화벽은 OSI 레이어 3 및 4에서 작동합니다. 네트워크 레이어 (IP 주소 및 라우팅) 및 전송 레이어 (포트 기반 연결). TCP(reliable, order connection), UDP(fast, connectionless message), ICMP(network Diagnostic message like ping)와 같은 프로토콜을 지원합니다. 레이어 3 또는 4 프로토콜에 대한 규칙을 작성할 수 있습니다. TCP 및 UDP는 아닙니다.

필터식을 작성할 때 사용할 수 있는 필드의 전체 목록을 보려면, 참조[Cloudflare 네트워크 방화벽 필드](/cloudflare-network-firewall/reference/network-firewall-fields/).

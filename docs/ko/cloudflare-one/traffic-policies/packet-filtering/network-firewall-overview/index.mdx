<Plan type="enterprise" />

DDoS 차단을 해제하려면 DDoS 차단을 해제해야 합니다. Cloudflare 네트워크 방화벽은<GlossaryTooltip term="firewall-as-a-service">방화벽 서비스(FWaaS)</GlossaryTooltip>Cloudflare 글로벌 네트워크에서 전달되는 Cloudflare는 자체 하드웨어 대신 클라우드에서 방화벽을 실행합니다. 프로토콜(예: TCP 또는 UDP)과 같은 다양한 표준에 필터 규칙을 적용할 수 있습니다.<GlossaryTooltip term="data packet">제품정보</GlossaryTooltip>길이, 네트워크에 도달하기 전에 원치 않는 트래픽을 필터링합니다.

Cloudflare 네트워크 방화벽은 Wireshark 디스플레이 필터 구문을 사용합니다 - 인기있는 네트워크 분석 도구에서 원래 규칙 언어[채용정보](https://www.wireshark.org/)네트워킹에서 널리 이용되고 다른 Cloudflare 제품의 맞은편에 사용된 동일한 구문. 이 구문으로, 당신은 정확하게 허용하거나 네트워크에서 어떤 트래픽을 거부 할 수있는 규칙을 만들 수 있습니다.

Cloudflare 네트워크 방화벽은 구매로 유효합니다[매직 트레인](/magic-transit/)또는[Cloudflare 대만](/cloudflare-wan/).

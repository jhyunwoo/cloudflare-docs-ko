기본적으로 Cloudflare 네트워크 방화벽은 Cloudflare의 핵심 DDoS 완화를 통해 전달된 모든 들어오는 (ingress) 트래픽을 허용합니다. 공격에 노출을 줄이고 네트워크에 도달하여 원치 않는 트래픽을 방지하려면 다음 지침을 사용하여 규칙을 구성하십시오.

처음 방화벽 규칙을 설정하면 시작[미니멀 규칙](/cloudflare-one/traffic-policies/packet-filtering/best-practices/minimal-ruleset/). 기존의 온프레미스 또는 Edge 방화벽 규칙이 있는 경우, 가장 좋은 방법은 Network Firewall의 규칙을 복제하는 것입니다. 현재 방화벽 규칙을 내보내지 못하면 Cloudflare 구현 관리자에게 네트워크 방화벽 규칙에 대한 규칙을 번역할 수 있습니다.

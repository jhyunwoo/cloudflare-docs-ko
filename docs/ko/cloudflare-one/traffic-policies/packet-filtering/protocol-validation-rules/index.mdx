Cloudflare 네트워크 방화벽은 유효할 수 있습니다[세션 시작 프로토콜 (SIP)](https://datatracker.ietf.org/doc/html/rfc2543)트래픽 - IP 네트워크를 통해 음성 및 화상 통화를 설정하는 데 사용되는 프로토콜 (VoIP). SIP 패킷이 제대로 포맷되고 긍정적 인 보안 모델을 시행 여부를 검사 할 수 있습니다 (만 잘 형성 된 SIP 트래픽을 허용, 다른 모든 것을 차단).

당신은 사용할 수 있습니다`sip`패킷이 유효한 SIP 데이터, 레이어 7 (L7) 프로토콜을 포함 여부를 확인하는 규칙을 만들 때 필드. 더 보기`sip`현장 평가`true`잘 형성된 SIP 소포를 위해. 더 알아보기[Cloudflare 네트워크 방화벽 필드](/cloudflare-network-firewall/reference/network-firewall-fields/), 특히`sip`필드, 이 항목에 대한 자세한 내용은.

현재 SIP는 깊은 검증을 위해 지원하는 유일한 프로토콜입니다. 추가 프로토콜을 지원하는 Cloudflare 네트워크 방화벽이 필요한 경우 계정 관리자에게 문의하십시오.

이 섹션은 다음과 같은 Gateway 정책 유형을 설정하기위한 모범 사례를 다룹니다.

<DirectoryListing />

각 유형의 정책은 다음과 같은 워크플로우를 추천합니다.

1. 정책에 적용하려는 장치 및/또는 네트워크 연결.
2. Gateway가 기기에서 성공적으로 프록시 트래픽을 검증합니다.
3. 기본 보안 및 호환성 정책을 설정 ( 대부분의 사용 사례에 대한 권장).
4. 조직의 고유한 요구에 당신의 윤곽을 주문을 받아서 만드십시오.

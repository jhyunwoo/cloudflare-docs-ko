주요 특징

네트워크 정책은 사용자와 네트워크 목적지 사이의 TCP 및 UDP 트래픽을 제어합니다. IP 주소, 포트 및 프로토콜을 기반으로 SSH, RDP 및 데이터베이스 연결과 같은 비-HTTP 트래픽을 허용하거나 차단할 수 있습니다.

Cloudflare 때문에 한국어[ID 공급자와 통합](/cloudflare-one/integrations/identity-providers/), 당신은 또한 ID 기반 네트워크 정책을 만들 수 있습니다. 사용자의 위치 또는 장치와 관계없이 per-user에 대한 액세스 권한을 제어 할 수 있습니다.

SSH 트래픽을 로그하려면 Cloudflare는 배포를 권장합니다.[접근성 준수](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-infrastructure-access/)SSH 서버 및 구성[SSH 명령 로그](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-infrastructure-access/#ssh-command-logs).
:::

감사 SSH 작업과 정책은 관리자가 SSH 트래픽을 로그 할 수 있습니다. Gateway는 포트에 SSH 트래픽을 감지합니다.`22`. 예를 들어, 다음과 같은 구성 로그 SSH 명령은 주어진 IP 주소로 전송:

| 옵션 정보 | 회사연혁 | 제품정보           | - 연혁   |
| ----- | ---- | -------------- | ------ |
| 대상 IP | 내 계정 | `203.0.113.83` | 감사 SSH |

항구에 SSH 트래픽만 감사`22`. 비표준 포트, 그 지정을 포함 하 여[관광 명소](#destination-port), 지원되지 않습니다.

SSH 로깅에 대한 자세한 내용은 참조[SSH 프록시 및 명령 로그 구성](/cloudflare-one/traffic-policies/network-policies/ssh-logging/).

:::caution\[Legacy 기능 — 새로운 배포를 권장하지 않음]
이 SSH 프록시 및 명령 로깅 방법은 deprecated입니다. 새로운 배포를 위해, use[접근성 준수](/cloudflare-one/networks/connectors/cloudflare-tunnel/use-cases/ssh/ssh-infrastructure-access/)SSH 세션을 관리하고 SSH 명령을 로그합니다.
주요 특징

모델 번호: Cloudflare 보안 웹 게이트웨이와 WARP 클라이언트를 사용하여 SSH 프록시 및 명령 로깅을 지원합니다.

SSH 액세스 관리 및 모니터링 할 수있는 네트워크 정책을 만들 수 있습니다. 장치가 SSH를 통해 Origin 서버에 연결하면 세션 로그는 사용자가 연결되는 표시, 세션 기간 및 세션 기간 동안 실행되는 모든 명령의 전체 재생이 표시됩니다.

## 7. 감사 SSH 정책을 작성

1. 내 계정[모델 번호: Cloudflare 한국어](https://one.dash.cloudflare.com), 이동**교통 정책** > **방화벽 정책**.

2. 내 계정**회사연혁**탭, 선택**네트워크 정책 추가**.

3. 성명 정책 및 지정[대상 IP](/cloudflare-one/traffic-policies/network-policies/#destination-ip)당신의 근원 서버를 위해.

   공공 또는 개인 IP 중 하나를 입력 할 수 있습니다. 개인 IP를 사용하려면, 참조[개인 네트워크](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/).

4. 귀하의 정책에 다른 조건을 추가하십시오. 사용자가 기준을 충족하지 않으면 기본적으로 차단됩니다.

## 8. 사용자로 연결

사용자는 장치에서 WARP 클라이언트에 로그인 한 것과 같은 대상 리소스에 연결할 SSH 클라이언트를 사용할 수 있습니다. 모델 번호: Cloudflare 하나가 인증, 프록시 및 선택적으로 암호화하고 게이트웨이를 통해 모든 SSH 트래픽을 기록합니다.

사용자는 SSH 명령의 일부로 연결하는 원하는 사용자 이름을 지정해야 합니다.

```sh
ssh <username>@<hostname>
```

:::참조

대상 자원이 이미 사용자의 경우`.ssh/known_hosts`파일, 사용자는 먼저 연결 시도하기 전에 기존 SSH 키를 제거해야합니다 :

```sh
ssh-keygen -R <targetIP or hostname>
```

:::

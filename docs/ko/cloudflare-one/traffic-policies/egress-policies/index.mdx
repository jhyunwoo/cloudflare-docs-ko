주요 특징

사용자가 Cloudflare 게이트웨이를 통해 인터넷에 연결하면 기본적으로 트래픽이 모든 Cloudflare WARP 사용자를 통해 공유되는 소스 IP 주소를 할당됩니다. Enterprise 사용자는 구매할 수 있습니다.[전용 egress IP](/cloudflare-one/traffic-policies/egress-policies/dedicated-egress-ips/)조직의 egress 트래픽이 독특하고 정적 IP로 할당되도록합니다. 이 소스 IP는 귀하의 계정에 전념하고 업스트림 서비스에 수당 내에서 사용할 수 있습니다.

Egress 정책은 ID, IP 주소 및 지리적 위치와 같은 속성을 기반으로하는 전용 egress IP를 사용할 수 있습니다. egress 정책과 일치하지 않는 트래픽은 대부분의 실행 전용 egress IP를 사용하여 기본적으로 표시됩니다.

Cloudflare는 WARP egress IP 범위를 간행하지 않습니다. WARP egress IPs는 문서화되지 않습니다[Cloudflare의 IP 범위](https://cloudflare.com/ips). 전용 WARP egress IP를 얻기 위하여는, 당신의 계정 팀을 접촉합니다.

<Render file="gateway/terraform-precedence-warning" product="cloudflare-one" />

## 짐 밸런싱

기본 Cloudflare egress IP 또는 모든 전용 egress IPs, egress 정책과 일치하지 않는 게이트웨이 트래픽을 사용하여 기본 게이트웨이 egress IP를 가진 가장 가까운 Cloudflare 데이터 센터에서 egress. 사용자로부터 동등한 거리의 두 가지 데이터 센터가 있는 경우 게이트웨이는 두 개의 데이터 센터 사이의 트래픽을 분할하고, 로드밸런서는 데이터 센터에 관계없이 동일한 사용자 선택과 egress IP를 유지할 것입니다.

## 힘 IP 버전

IPv4 또는 IPv6가 egress에 사용되었는지 여부를 제어하려면,[DNS 트래픽 필터링](/cloudflare-one/traffic-policies/get-started/dns/), 다음 DNS 정책을 만들[블록 AAAA 또는 레코드](/cloudflare-one/traffic-policies/dns-policies/common-policies/#control-ip-version).

### Catch-all 정책

최고의 성능을 위해, 우리는 기본 Zero Trust IP 범위를 통해 다른 모든 사용자를 경로에 catch-all 정책을 생성하는 것이 좋습니다.

| 정책 이름        | 옵션 정보 | 회사연혁 | 제품정보                     | Egress 방법               |
| ------------ | ----- | ---- | ------------------------ | ----------------------- |
| 기본 egress 정책 | 프로젝트  | 내 계정 | `All options (Protocol)` | Cloudflare 기본 egress 방법 |

Gateway 정책 평가[맨 위로](/cloudflare-one/traffic-policies/order-of-enforcement/#order-of-precedence)UI에서, 목록의 하단에 catch-all 정책을 배치해야합니다. catch-all 정책이 포함되지 않는 경우, 다른 모든 트래픽은 가장 가까운 전용 egress IP 위치를 사용하려고합니다. IP Gateway가 사용하는 것을 제어하려면 egress 정책을 작성합니다.

## Egress 방법

egress 정책을 구성하면 기본 Cloudflare egress 방법 또는 전용 egress IPs를 사용하여 egress 트래픽을 선택할 수 있습니다.

### 기본 Cloudflare egress 방법 사용

**기본 Cloudflare egress 방법 사용**모든 Zero Trust 계정에서 공유되는 기본 소스 IP 범위를 사용합니다. 가장 가까운 Cloudflare 데이터 센터에서 사용자 트래픽 egresses로 가장 뛰어난 인터넷 경험을 보장합니다.

### 전용 egress IPs 사용

**전용 egress IPs (Cloudflare 또는 BYOIP) 사용**드롭다운 메뉴에서 선택된 기본 IPv4 주소와 IPv6 범위를 사용합니다.<Render file="gateway/secondary-ipv4-requirement" product="cloudflare-one" />

기본 전용 egress IPv4와 관련 된 데이터 센터가 내려지면 게이트웨이는 다시 루트 동안 트래픽이 떨어지는 것을 방지하기 위해 이차 데이터 센터에서 egress합니다. IPv6 트래픽이 Cloudflare 데이터 센터에서 egress 할 수 있기 때문에 이차 IPv6에는 필요하지 않습니다. 전용 egress IPs는 Cloudflare 또는[BYOIP의 특징](/cloudflare-one/traffic-policies/egress-policies/dedicated-egress-ips/#bring-your-own-ip-address-byoip).

IPv4 및 IPv6 egress 행동에 대한 자세한 내용을 보려면, 참조[Egress 위치](/cloudflare-one/traffic-policies/egress-policies/dedicated-egress-ips/#egress-location).

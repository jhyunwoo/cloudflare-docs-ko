## 2024-03-21

**타사 쿠키 의존성 제거**

격리된 브라우저의 제3자 쿠키에 대한 의존성을 제거하여 이전에는 격리된 브라우저에서 다중 사이트, 크로스탭 세션을 유지하는 사용자를 위한 간헐적인 혼란을 초래하는 문제를 해결했습니다.

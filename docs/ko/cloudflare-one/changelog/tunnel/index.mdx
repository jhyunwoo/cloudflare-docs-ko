## 2024-10-17

**단순 WARP 연결관 배치**

WARP 커넥터를 간소화하고 가이드 워크플로를 사용하여 배포할 수 있습니다.`cloudflared`연결관. 자세한 설명은, 참조[사이트맵 연결관 문서](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/warp-connector/).

## 2024-10-10

**버그 수정 --grace-period**

새 소식`cloudflared`제품정보[2024.10.0](https://github.com/cloudflare/cloudflared/releases/tag/2024.10.0)관련 버그 수정[--grace 기간](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/run-parameters/#grace-period)터널 실행 매개 변수.`cloudflared`연결관은 지금 Cloudflare의 네트워크에 완전히 닫히는 연결의 앞에 지정된 대기 기간에 의해 abide.

## 2024-08-06

**Cloudflared는 Apple 실리콘을 위해 GitHub에서 사용할 수 있습니다.**

macOS 사용자는 이제 다운로드 할 수 있습니다`cloudflared-arm64.pkg`직접에서[프로젝트](https://github.com/cloudflare/cloudflared/releases)Homebrew를 통해 사용할 수 있는 것 외에도.

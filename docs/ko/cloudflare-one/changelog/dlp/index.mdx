## 2025-01-15

**Payload 로그 일치 가시성**

해독된 페이로드 로그 일치를 볼 때 DLP는 이제 여러 DLP 경기와 일치 DLP 프로파일을 나열하여 더 많은 컨텍스트를 제공합니다.

## 2024-11-25

**단면도 신뢰 수준**

DLP 프로필 이제 설정 지원[신뢰 수준](/cloudflare-one/data-loss-prevention/dlp-profiles/advanced-settings/#confidence-levels)탐지를 허용하는 방법을 선택하는 것은 탐지의 상황에 근거를 둔 거짓 긍정적입니다. 더 높은 프로필의 신뢰 수준은, 더 적은 거짓 긍정적은 허용됩니다. Confidence 수준은 낮은, 중간, 또는 높은 포함합니다. DLP 프로파일 신뢰 수준 supersede[분석](/cloudflare-one/data-loss-prevention/dlp-profiles/advanced-settings/#context-analysis).

## 2024-11-01

**전체 HTTP 요청을 Logpush 목적지로 보내십시오.**

더 알아보기[payload로 로그인](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/#log-the-payload-of-matched-rules)Cloudflare Logs의 DLP 정책과 일치하는 HTTP 요청에서 엔터프라이즈 사용자는 이제 구성할 수 있습니다.[Logpush 작업](/cloudflare-one/data-loss-prevention/dlp-policies/logging-options/#send-http-requests-to-logpush-destination)저장 대상에 DLP 일치를 트리거 한 HTTP 요청을 보내려면. 이것은 법정 조사에서 사용을위한 전체 요청의 장기 저장을 허용합니다.

## 2024-09-03

**Exact Data Match 멀티 엔트리 업로드 지원**

파일 업로드[데이터의 여러 열](/cloudflare-one/data-loss-prevention/detection-entries/#upload-a-new-dataset)Exact Data Match 데이터셋으로 DLP는 별도의 기존 감지 항목으로 각 열을 사용할 수 있습니다.

## 2024-05-23

**Box 및 Dropbox에 대한 데이터 스탠드 DLP**

지금 스캔할 수 있습니다.[제품 정보](/cloudflare-one/integrations/cloud-and-saas/box/#data-loss-prevention-optional)·[다운로드](/cloudflare-one/integrations/cloud-and-saas/dropbox/#data-loss-prevention-optional)DLP 일치 파일.

## 2024-04-16

**광학 문자 인식**

DLP는 지금 할 수 있습니다[민감한 데이터를 감지](/cloudflare-one/data-loss-prevention/dlp-profiles/advanced-settings/#optical-character-recognition-ocr)jpeg, jpg 및 png 파일에 있습니다. 이 회사는 스크린 샷과 같은 이미지에 민감한 데이터의 누출을 방지합니다.

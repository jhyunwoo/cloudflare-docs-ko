## 2025-02-12

**HTTP 정책에 대한 파일 크기 선택기**

Gateway 및 DLP 사용자는 이제 HTTP 정책을 만들 수 있습니다.[다운로드 및 업로드 파일 크기 (MiB)](/cloudflare-one/traffic-policies/http-policies/#download-and-upload-file-size)교통 선택자. 이 업데이트는 사용자가 파일 크기에 따라 업로드 또는 다운로드를 차단할 수 있습니다.

## 2025-02-02

**기본 글로벌 Cloudflare 루트 인증서는 16:05 UTC에서 2025-02-02-02에 만료**

2024-10-17 전에 기본 Cloudflare 인증서를 설치하면 새로운 인증서를 생성하고 Zero Trust 조직에서 검사 오류를 방지해야합니다. 더 알아보기[문제 해결](/cloudflare-one/faq/troubleshooting/#as-of-february-2-2025-my-end-user-devices-browser-is-returning-a-your-connection-is-not-private-warning)지침 및 문제 해결 단계.

## 2025-01-08

**DNS 위치에 대한 자신의 해결 IP (BYOIP) 가져 오기**

기업 사용자는 지금 할 수 있습니다[IP 주소 제공](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/#bring-your-own-dns-resolver-ip)Private DNS의 해결자를 위해[DNS 위치](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/). 게이트웨이는 자신의 IPv4 및 IPv6 주소를 가져다줍니다.

## 2024-11-20

**네트워크 정책 빌더에서 필터링하는 범주**

Gateway 사용자는 이제 네트워크 정책을 만들 수 있습니다.[제품 분류](/cloudflare-one/traffic-policies/network-policies/#content-categories)·[보안 위험](/cloudflare-one/traffic-policies/network-policies/#security-risks)교통 선택자. 이 업데이트는 향상된 보안 관리를 위해 악성 트래픽 차단 및 유선 네트워크 모니터링을 단순화합니다.

## 2024-10-17

**Cloudflare 루트 인증서**

Gateway 사용자는 이제 생성 할 수 있습니다.[독특한 루트 CA](/cloudflare-one/team-and-resources/devices/user-side-certificates/)Zero Trust 계정의 경우 생성 된 인증서 및 사용자 정의 인증서 사용자 모두[루트 인증서 활성화](/cloudflare-one/team-and-resources/devices/user-side-certificates/#activate-a-root-certificate)검사를 위해 그것을 이용하십시오. Per-account 인증서는 기본 Cloudflare 인증서를 대체합니다. 이는 2025-02-02-02에 만료됩니다.

## 2024-10-10

**시간 기반 정책 기간**

Gateway 지금 제공[시간 기반 DNS 정책 기간](/cloudflare-one/traffic-policies/dns-policies/timed-policies/#time-based-policy-duration). 정책 기간으로, 당신은 정책의 기간을 설정하거나 정확한 날짜 및 시간을 설정할 수 있습니다.

## 2024-10-04

**Gateway 로그 필드를 확장**

Gateway 이제 새로운 필드를 제공합니다[활동 로그](/cloudflare-one/insights/logs/gateway-logs/)DNS, 네트워크 및 HTTP 정책을 통해 게이트웨이를 통해 사용자의 트래픽을 더 큰 통찰력을 제공합니다.

## 2024-09-30

**파일 sandboxing**

Enterprise 플랜의 Gateway 사용자는 HTTP 정책을 만들 수 있습니다.[파일 sandboxing](/cloudflare-one/traffic-policies/http-policies/file-sandboxing/)으로 quarantine 이전 unseen 파일에 의해 다운로드 사용자 및 악성 코드를 스캔.

## 2024-07-30

**영국 NCSC 지표는 Gateway에서 공개적으로 사용 가능**

모든 계획에 게이트웨이 사용자는 이제 사용할 수 있습니다[PDNS 위협 정보 피드](/security-center/indicator-feeds/#publicly-available-feeds)DNS 정책의 UK National Cyber Security Centre (NCSC)에 의해 제공됩니다.

## 2024-07-14

**Gateway DNS 필터 비 유독한 쿼리**

Gateway 사용자는 주어진 DNS 위치에 사용할 엔드포인트를 선택할 수 있습니다. 사용 가능한 엔드포인트에는 IPv4, IPv6, HTTPS (DoH) 이상 DNS 및 TLS (DoT) 이상 DNS가 포함되어 있습니다. 사용자는 허용된 소스 네트워크를 지정하여 각 구성된 엔드포인트를 보호할 수 있습니다. 또한, DoH 엔드포인트의 경우, 사용자는 소스 네트워크 및/또는 인증된 사용자 ID 토큰을 기반으로 트래픽을 필터링할 수 있습니다.

## 2024-06-25

**Gateway DNS 정책 설정 무시 CNAME 범주 일치**

Gateway는 이제 선택적으로 DNS 정책에서 CNAME 도메인 범주를 무시할 수있는 능력을 제공합니다.[**Ignore CNAME 도메인 카테고리**설치하기](/cloudflare-one/traffic-policies/domain-categories/#ignore-cname-domain-categories)정책 빌더 및[`ignore_cname_category_matches`설치하기](/api/resources/zero_trust/subresources/gateway/subresources/rules/methods/create/)API에서.

## 2024-04-05

**Gateway 파일 유형 제어 개선**

Gateway 이제는 더 광범위하고, 분류합니다[파일 목록](/cloudflare-one/traffic-policies/http-policies/#download-and-upload-file-types)업로드 및 다운로드를 제어합니다.

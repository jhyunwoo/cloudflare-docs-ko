이 절차는 특정한 Cloudflare Zero Trust 특징을 가능하게 하기 위하여만 요구되고, 당신의 IT 부의 방향에서만 행해야 합니다. 이 절차는 소비자를 위한 WARP 클라이언트를 가능하게 하기 위하여 요구되지 않습니다.
주요 특징

기기가 지원되지 않는 경우[WARP를 통한 인증서 설치](/cloudflare-one/team-and-resources/devices/user-side-certificates/automated-deployment/), 당신은 수동으로 Cloudflare 증명서를 설치할 수 있습니다. 인증서를 모두 추가해야 합니다.[시스템 keychain](#add-the-certificate-to-operating-systems)·[고객 서비스](#add-the-certificate-to-applications). 이 단계는 HTTP 필터링 대상이 되는 각 새로운 장치에서 수행되어야 합니다.

Zero Trust는 설치된 증명서 세트를 사용하여만 교통을 검열할 것입니다[**이용안내**·**제품정보**](/cloudflare-one/team-and-resources/devices/user-side-certificates/#activate-a-root-certificate).

인증서를 수동으로 설치하려면 다음을해야합니다.

1. Cloudflare 인증서를 다운로드하고 확인합니다.
2. 운영 체제의 인증서 저장소에 인증서를 설치합니다.
3. 대상 응용 프로그램은 운영 체제에서 인증서를받지 않는 경우, 응용 프로그램의 인증서 저장소에 인증서를 설치해야합니다.

## 1. Cloudflare 루트 인증서 다운로드

:::note\[다운로드 제한]
Cloudflare One 대시보드 또는 WARP로 Cloudflare-generated 인증서만 다운로드할 수 있습니다.
주요 특징

첫 번째,[제품정보](/cloudflare-one/team-and-resources/devices/user-side-certificates/#generate-a-cloudflare-root-certificate)Cloudflare 인증서 다운로드 증명서는 둘 다에서 유효합니다`.pem`·`.crt`파일 형식. 특정 응용 프로그램은 특정 파일 유형에 있어야 인증서를 요구하므로 사용 사례에 가장 적합한 파일을 다운로드하십시오.

1. 내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**교통 정책** > **교통 설정**.
2. 제품정보**인증서**.
3. 다운로드하려는 인증서를 선택하십시오.
4. 제품정보**더 많은 작업**.
5. 원하는 형식에 따라 선택**다운로드 .pem**및/또는**다운로드 .crt**.

대안으로, 당신은 다운로드하고 인증서를 설치 할 수 있습니다[WARP 사용](/cloudflare-one/team-and-resources/devices/user-side-certificates/automated-deployment/#install-a-certificate-using-warp). WARP는 장치의 시스템 인증서 저장소에 인증서를 추가합니다`installed_certs/<certificate_id>.pem`.

## 2. 다운로드 된 인증서 확인

다운로드를 확인하려면 다운로드 된 인증서의 해시가 아래에 나열된 썸프를 일치시키는 터미널을 사용하십시오.**인증서 썸프린트**. 예를 들면:

### 사이트맵

```sh title="SHA1 .crt example"
openssl x509 -noout -fingerprint -sha1 -inform der -in <certificate.crt>
```

```sh output
SHA1 Fingerprint=BB:2D:B6:3D:6B:DE:DA:06:4E:CA:CB:40:F6:F2:61:40:B7:10:F0:6C
```

```sh title="SHA1 .pem example"
openssl x509 -noout -fingerprint -sha1 -inform pem -in <certificate.pem>
```

```sh output
SHA1 Fingerprint=BB:2D:B6:3D:6B:DE:DA:06:4E:CA:CB:40:F6:F2:61:40:B7:10:F0:6C
```

### 모델 번호: SHA256

```sh title="SHA256 .crt example"
openssl x509 -noout -fingerprint -sha256 -inform der -in <certificate.crt>
```

```sh output
sha256 Fingerprint=F5:E1:56:C4:89:78:77:AD:79:3A:1E:83:FA:77:83:F1:9C:B0:C6:1B:58:2C:2F:50:11:B3:37:72:7C:62:3D:EF
```

```sh title="SHA256 .pem example"
openssl x509 -noout -fingerprint -sha256 -inform pem -in <certificate.pem>
```

```sh output
sha256 Fingerprint=F5:E1:56:C4:89:78:77:AD:79:3A:1E:83:FA:77:83:F1:9C:B0:C6:1B:58:2C:2F:50:11:B3:37:72:7C:62:3D:EF
```

## 3. (선택)는 증명서를 변환합니다

일부 응용 프로그램은 인증서 형식이 필요합니다.`.cer`파일 형식. 다운로드 된 인증서를 변환 할 수 있습니다.[열린SSL](https://www.openssl.org/):

<Tabs>
  <TabItem label="macOS 및 Linux" icon="seti:shell">
    1. [OpenSSL 설치](https://wiki.openssl.org/index.php/Compilation_and_Installation).
    2. [Cloudflare 인증서 다운로드](#download-a-cloudflare-root-certificate)내 계정`.pem`파일 형식.
    3. 터미널에서 인증서를 DER 형식으로 변환`.cer`파일 형식 :
       ```sh
       openssl x509 -inform PEM -in ~/Downloads/certificate.pem -outform DER -out ~/Downloads/certificate.cer
       ```
  </TabItem>

  <TabItem label="윈도우" icon="seti:windows">
    1. [Windows용 OpenSSL 설치](https://slproweb.com/products/Win32OpenSSL.html).
    2. [Cloudflare 인증서 다운로드](#download-a-cloudflare-root-certificate)내 계정`.pem`파일 형식.
    3. PowerShell 터미널에서 인증서를 DER 형식으로 변환`.cer`파일 형식 :
       ```powershell
       openssl x509 -inform PEM -in "$HOME\Downloads\certificate.pem" -outform DER -out "$HOME\Downloads\certificate.cer"
       ```
  </TabItem>
</Tabs>

## 5. 신청에 증명서 추가

몇몇 신청은 체계 증명서 상점을 이용하지 않으며 그러므로 신청에 직접 추가될 증명서가 요구합니다. 아래의 것들과 같은 특정 응용 프로그램을 위해이 섹션에서 단계를 따르고 TLS 해독에 대한 응용 프로그램에 Cloudflare 인증서를 올바르게 추가해야합니다.

Cloudflare 인증서를 신뢰할 수있는 응용 프로그램을 업데이트하지 않으면 응용 프로그램은 연결 거부하고 신뢰할 수없는 인증서 오류를 받게됩니다.

먼저 아래의 모든 응용 프로그램은 Cloudflare 인증서를 다운로드해야합니다.[위의 지침](#download-the-cloudflare-root-certificate). macOS에서 시스템 키 체인 데이터베이스 파일에 기본 경로는`/Library/Keychains/System.keychain`. Windows에서, 기본 경로는 입니다`\Cert:\CurrentUser\Root`.

:::참조
일부 응용 프로그램은 공개적으로 신뢰할 수있는 인증서의 사용을 요구합니다 - 그들은 시스템 인증서를 신뢰하지 않으며 구성 가능한 개인 저장소가 없습니다. 이 응용 프로그램을 위해, 당신은 추가해야합니다[Inspect 정책 없음](/cloudflare-one/traffic-policies/http-policies/#do-not-inspect)도메인 또는 IP에 대한 응용 프로그램이 의존합니다.
주요 특징

:::카트로션
WARP를 배포하더라도[WARP를 사용하여 인증서 설치](/cloudflare-one/team-and-resources/devices/user-side-certificates/automated-deployment/)방법, 당신은 여전히 특정 응용 프로그램에 Cloudflare 인증서를 추가해야합니다. WARP 방법을 사용하여 설치 인증서는 Cloudflare 인증서를 운영 체제 인증서 저장소에 설치합니다.

### 프로그래밍 언어 및 실행 시간

프로그래밍 언어 런타임은 종종 자신의 인증서 상점을 유지하거나 언어 별 인증서 관리 도구를 사용합니다.

#### 사이트맵

Python 버전에 따라 설치 및 구성이 필요한 경우 사용해야 할 수도 있습니다.`python`또는`python3`명령. 이용안내[가상 환경](https://docs.python.org/3/library/venv.html), 당신은 각 가상 환경 안에 뒤에 오는 단계를 반복할 필요가 있을 것입니다.

<Tabs>
  <TabItem label="윈도우" icon="seti:windows">
    Windows에서 Python 인증서를 자동으로 설치하려면`pip`·`certifi`(인증 유효성에 대한 기본 인증서 번들).

    1. [Cloudflare 인증서 다운로드](#download-a-cloudflare-root-certificate)내 계정`.crt`파일 형식.
    2. PowerShell 터미널에서 설치`certifi`포장:
       ```powershell
       python -m pip install certifi
       ```
    3. Python CA 저장소 식별:
       ```powershell
       $CERT_PATH = python -c "import certifi; print(certifi.where())"
       ```
    4. Cloudflare 인증서를 포함하는 번들을 업데이트하십시오:
       ```powershell
       gc "$env:USERPROFILE\Downloads\certificate.crt" | ac $CERT_PATH
       ```
    5. (선택 사항) PowerShell의 구성 파일에 추가하여 CA 저장소로 시스템 변수를 구성:
       ```powershell
       [System.Environment]::SetEnvironmentVariable('CERT_PATH', $CERT_PATH, 'Machine')
       [System.Environment]::SetEnvironmentVariable('SSL_CERT_FILE', $CERT_PATH, 'Machine')
       [System.Environment]::SetEnvironmentVariable('REQUESTS_CA_BUNDLE', $CERT_PATH, 'Machine')
       ```
    6. 당신의 맨끝을 재시작하십시오.
  </TabItem>

  <TabItem label="macOS 및 Linux" icon="seti:shell">
    1. [Cloudflare 인증서 다운로드](#download-a-cloudflare-root-certificate)내 계정`.pem`파일 형식.
    2. 터미널에서 설치`certifi`포장:
       ```sh
       python -m pip install certifi
       ```
    3. Cloudflare 인증서를 실행하여이 CA 저장소에 승인:
       ```sh
       echo | cat - certificate.pem >> $(python -m certifi)
       ```
    4. (선택 사항) 쉘의 구성 파일에 추가하여 CA 저장소로 시스템 변수를 구성 (예 :`~/.zshrc`또는`~/.bash_profile`). 예를 들면:
       ```sh
       echo 'export CERT_PATH=$(python -c "import certifi; print(certifi.where())")
       export SSL_CERT_FILE=${CERT_PATH}
       export REQUESTS_CA_BUNDLE=${CERT_PATH}' >> ~/.zshrc
       ```
    5. 당신의 맨끝을 재시작하십시오.
  </TabItem>
</Tabs>

#### 다운로드

Java는 Java를 포함하는 다른 설치 또는 응용 프로그램에 따라 여러 인증서 키 저장소 위치를 가질 수 있습니다. Java Virtual Machine (JVM) 설치에 따라 각 인스턴스의 인증서를 설치할 필요가 있습니다. 각 Java 응용 프로그램을 수동으로 구성하고 인증서를 신뢰 할 수도 있습니다.

시스템 JVM에서 Cloudflare 루트 인증서를 설치하려면 운영 체제의 절차를 따르십시오. 이 단계는 당신을 요구합니다[다운로드`.pem`인증번호](#download-a-cloudflare-root-certificate).

<Tabs>
  <TabItem label="macOS 및 Linux" icon="seti:shell">
    1. 설치하기[열린SSL](https://www.openssl.org/).

    2. 터미널에서 Cloudflare 인증서를 Java로 포맷합니다.

       ```sh
       openssl x509 -in Cloudflare_CA.pem -inform pem -out Cloudflare_CA.der -outform der
       ```

    3. 변환 된 인증서를 Java 키 저장소에 가져 오기.

       ```sh
       sudo $JAVA_HOME/bin/keytool -import -trustcacerts -alias 'Cloudflare Root CA' -file Cloudflare_CA.der -keystore $JAVA_HOME/jre/lib/security/cacerts -storepass changeit -noprompt 2>&1
       ```

    4. Java의 모든 인스턴스를 복원합니다.
  </TabItem>

  <TabItem label="윈도우" icon="seti:windows">
    1. 설치하기[Windows용 OpenSSL](https://slproweb.com/products/Win32OpenSSL.html).

    2. 관리자 PowerShell 터미널에서, Java 용 Cloudflare 인증서를 포맷합니다.

       ```powershell
       openssl x509 -in Cloudflare_CA.pem -inform pem -out Cloudflare_CA.der -outform der
       ```

    3. 변환 된 인증서를 Java 키 저장소에 가져 오기.

       ```powershell
       "%JAVA_HOME%\bin\keytool" -import -trustcacerts -alias "Cloudflare Root CA" -file Cloudflare_CA.der -keystore "%JAVA_HOME%\jre\lib\security\cacerts" -storepass changeit -noprompt
       ```

    4. Java의 모든 인스턴스를 복원합니다.
  </TabItem>
</Tabs>

#### 뚱 베어

RubyGems의 Cloudflare 루트 인증서를 신뢰하려면 운영 체제의 절차를 따르십시오. 이 단계는 당신을 요구합니다[다운로드`.pem`인증번호](#download-a-cloudflare-root-certificate).

<Tabs>
  <TabItem label="macOS 및 Linux" icon="seti:shell">
    1. 설치하기[열린SSL](https://www.openssl.org/).

    2. 터미널에서, Ruby의 Cloudflare 인증서를 포맷합니다.

       ```sh
       openssl x509 -in ~/Downloads/certificate.pem -out ~/Downloads/ruby-root-ca.crt
       ```

    3. RubyGems 인증서 디렉토리를 홈 폴더에 만듭니다.

       ```sh
       mkdir -p ~/.gem/ssl
       ```

    4. Cloudflare 인증서를 RubyGems 인증서 저장소에 복사합니다.

       ```sh
       cp ~/Downloads/ruby-root-ca.crt ~/.gem/ssl/rubygems.org.pem
       ```

    5. RubyGems를 구성하여 인증서를 사용합니다.

       ```sh
       gem sources --add-trusted-cert ~/.gem/ssl/rubygems.org.pem
       ```

       또는 RubyGems 구성 파일에 다음 줄을 추가합니다.`~/.gemrc`인증서를 세계적으로 신뢰하는 파일:

       ```yaml
       :ssl_cert: ~/.gem/ssl/rubygems.org.pem
       ```

    6. 모든 터미널 세션을 복원합니다.
  </TabItem>

  <TabItem label="윈도우" icon="seti:windows">
    1. 설치하기[Windows용 OpenSSL](https://slproweb.com/products/Win32OpenSSL.html).

    2. PowerShell 터미널에서 Ruby의 Cloudflare 인증서를 형식합니다.

       ```powershell
       openssl x509 -in %UserProfile%\Downloads\certificate.pem -out %UserProfile%\Downloads\ruby-root-ca.crt
       ```

    3. RubyGems 인증서 디렉토리를 홈 폴더에 만듭니다.

       ```powershell
       mkdir -Force "$env:USERPROFILE\.gem\ssl"
       ```

    4. Cloudflare 인증서를 RubyGems 인증서 저장소에 복사합니다.

       ```powershell
       Copy-Item "$env:USERPROFILE\Downloads\ruby-root-ca.crt" "$env:USERPROFILE\.gem\ssl\rubygems.org.pem"
       ```

    5. RubyGems를 구성하여 인증서를 사용합니다.

       ```powershell
       gem sources --add-trusted-cert "$env:USERPROFILE\.gem\ssl\rubygems.org.pem"
       ```

       또는 RubyGems 구성 파일에 다음 줄을 추가합니다.`$HOME\.gemrc`글로벌 신뢰 인증서:

       ```yaml
       :ssl_cert: C:/Users/<username>/.gem/ssl/rubygems.org.pem
       ```

    6. 모든 터미널 세션을 복원합니다.
  </TabItem>
</Tabs>

  <TabItem label="macOS 및 Linux" icon="seti:shell">

Docker 컨테이너에서 사용할 인증서를 설치하려면:

2. Docker 프로젝트에서 인증서의 디렉토리 만들기:

   ```sh
   cd docker-project
   ```

3. 인증서가 올바르게 디렉토리로 이동합니다. 프로젝트는 다음과 같은 구조가 있어야 합니다.

   ```sh
   docker-project/
   ```

   <Tabs>

          ```docker title="Red Hat-based images"
          FROM registry.access.redhat.com/ubi9/ubi:latest
          ```

          ```docker title="Debian-based images"
          FROM debian:12
          # Or FROM ubuntu:22.04

          # Install necessary certificates package
          RUN apt-get update && apt-get install -y ca-certificates
          ```

          ```sh
          docker build -t <your-container-name> .
          ```

          ```sh title="Red Hat-based images"
          docker run --rm your-image-name sh -c "cat /etc/pki/ca-trust/extracted/pem/tls-ca-bundle.pem | grep Cloudflare"
          ```


Command-line 도구는 일반적으로 시스템 인증서 저장소를 사용하지만 특정 구성이 필요할 수 있습니다.

Android Studio는 자체 JVM 및 인증서 저장소를 사용합니다. Cloudflare 루트 인증서를 설치하려면:

3. Cloudflare 인증서를 Android Studio의 JVM에 추가하십시오.

<Tabs>
  <TabItem label="macOS 및 Linux" icon="seti:shell">

### 클라우드 및 인프라 도구

Cloud 서비스 제공 업체 및 인프라 도구는 종종 API 액세스 및 리소스 관리를위한 인증서 구성을 요구합니다.

#### Google 클라우드

##### 구글 클라우드 SDK

아래 명령은 Cloudflare 인증서를 사용하여 Google Cloud SDK를 설정합니다. Google Cloud SDK 구성에 대한 자세한 내용은 참조[Google Cloud 문서](https://cloud.google.com/sdk/docs/proxy-settings).

1. 컬의 받기`cacert`뭉치.

   ```sh
   curl --remote-name https://curl.se/ca/cacert.pem
   ```

2. [Cloudflare 인증서 다운로드](#download-a-cloudflare-root-certificate)내 계정`.pem`파일 형식.

3. 단 하나에 certs를 결합`.pem`파일.

   ```sh
   cat cacert.pem certificate.pem > ~/ca.pem
   ```

4. Google Cloud를 구성하여 결합`.pem`.

   ```sh
   gcloud config set core/custom_ca_certs_file ~/ca.pem
   ```

:::참조

파일에`~/ca.pem`주문에 남아 있어야`gcloud`활용할 수 있는 유틸리티. 파일이 이동되면, 다시 실행해야 3 점`gcloud`파일의 새로운 위치로.

2. 찾아보기[AWS 구성 파일](https://docs.aws.amazon.com/cli/v1/userguide/cli-configure-files.html#cli-configure-files-where).

   ```diff lang="ini" title=".aws/config"
   [default]
   region = us-west-1

   +ca_bundle = /path/to/certificate.pem
   ```

4. 당신의 맨끝을 재시작하십시오.

2. 터미널에서 설정[`AWS_CA_BUNDLE`환경 변수](https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-envvars.html)운영 체제에 따라 인증서의 위치에.
3. 당신의 맨끝을 재시작하십시오.

### Enterprise 응용

Enterprise 데스크톱 응용 및 전문 도구는 사용자 정의 인증서 구성을 필요로 할 수 있습니다.

#### Google 드라이브

Google Drive 데스크톱 애플리케이션에서 Cloudflare 루트 인증서를 신뢰하려면 운영 체제의 절차를 따르십시오. 이 단계는 당신을 요구합니다[다운로드`.pem`인증번호](#download-a-cloudflare-root-certificate).

<Tabs>
  <TabItem label="맥 OS" icon="apple">
    1. 터미널에서 문서 폴더와 같은 영구 위치에 새로운 인증서 파일에 Google Drive 인증서 파일의 내용을 복사합니다. 예를 들면:

       ```sh
       cat /Applications/"Google Drive.app"/Contents/Resources/roots.pem > ~/Documents/gdrivecerts.pem
       ```

    2. 다운로드 된 인증서의 내용을 새 파일의 끝으로 승인하십시오. 예를 들면:

       ```sh
       cat ~/Downloads/certificate.pem >> ~/Documents/gdrivecerts.pem
       ```

    3. 새로 생성 된 루트 인증서를 Google 드라이브 응용 프로그램에 적용하십시오. 예를 들면:

       ```sh
       sudo defaults write /Library/Preferences/com.google.drivefs.settings TrustedRootCertsFile "/Users/$(whoami)/Documents/gdrivecerts.pem"
       ```

    다음 명령으로 업데이트를 확인할 수 있습니다.

    ```sh
    defaults read /Library/Preferences/com.google.drivefs.settings
    ```
  </TabItem>

  <TabItem label="윈도우" icon="seti:windows">
    1. 관리자 PowerShell 터미널에서 문서 폴더와 같은 영구 위치에 새로운 인증서 파일에 Google Drive 인증서 파일의 내용을 복사합니다. 예를 들면:

       ```powershell
       Get-Content "C:\Program Files\Google\Drive File Stream\roots.pem" | Set-Content "$HOME\Documents\gdrivecerts.pem"
       ```

    2. 다운로드 된 인증서의 내용을 새 파일의 끝으로 승인하십시오. 예를 들면:

       ```powershell
       Get-Content "$HOME\Downloads\certificate.pem" | Add-Content "$HOME\Documents\gdrivecerts.pem"
       ```

    3. 새로 생성 된 루트 인증서를 Google 드라이브 응용 프로그램에 적용하십시오. 예를 들면:

       ```powershell
       Set-ItemProperty -Path "HKLM:\SOFTWARE\Google\DriveFS" -Name "TrustedRootCertsFile" -Value "$HOME\Documents\gdrivecerts.pem"
       ```

    다음 명령으로 업데이트를 확인할 수 있습니다.

    ```powershell
    Get-ItemProperty -Path "HKLM:\SOFTWARE\Google\DriveFS" | Select-Object TrustedRootCertsFile
    ```
  </TabItem>
</Tabs>

더 많은 정보를 원하시면, 참조[Google 문서](https://support.google.com/a/answer/7644837)제품정보`TrustedRootCertsFile`설정.

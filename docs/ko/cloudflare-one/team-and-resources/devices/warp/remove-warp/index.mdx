다음 절차는 장치에서 WARP 클라이언트를 제거하지 않을 것입니다. WARP 클라이언트를 사용하여 루트 인증서를 배포하는 경우 인증서도 제거됩니다.

## 윈도우

1. Windows 설정으로 이동 (Windows 키 + I).
2. 제품정보**앱 다운로드**.
3. 제품정보**앱 & 기능**.
4. 목록에서 Cloudflare WARP 앱을 찾아 선택합니다.

## 맥 OS

원래 사용되는 macOS 패키지의 일부로 스크립트를 제거 할 수 있습니다.

1. uninstall 스크립트를 찾아 실행하려면 다음 명령을 실행하십시오.

```sh
cd /Applications/Cloudflare\ WARP.app/Contents/Resources
./uninstall.sh
```

2. 신속한 경우 관리자 자격 증명을 입력하여 제거하십시오.

:::참조

당신은 우회할 수 있습니다**견적 요청**패스워드`-f`macOS uninstall 명령에 매개 변수로.

:::

## 리눅스

CentOS 8에서, RHEL 8:

```sh
sudo yum remove cloudflare-warp
```

우분투 18.04, 우분투 20.04, 우분투 22.04, 데비안 9, 데비안 10, 데비안 11:

```sh
sudo apt remove cloudflare-warp
```

## iOS 및 Android

1. 홈 화면에 Cloudflare 원 에이전트 응용 프로그램 (또는 유산 1.1.1.1 응용 프로그램)을 찾으십시오.
2. 응용 타일을 선택하고, 그 후 선택**앱 제거**.
3. 제품정보**앱 삭제**.

:::참조

당신은[수동으로 Cloudflare 인증서를 배치](/cloudflare-one/team-and-resources/devices/user-side-certificates/manual-deployment/), 수동으로 장치를 삭제하는 것을 기억하십시오.

## CF CAPTIVE PORTAL TIMED OUT의 특징

### 증상

- 캡티브 포털 네트워크에 로그인할 수 없습니다.
- 인터넷 연결 없음

### 이름 \*

[Captive 포털 탐지](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#captive-portal-detection)다음 문제 중 하나가 발생했습니다.

- 사용자는 WARP에 의해 설정된 시간 제한 내에서 캡티브 포털 로그인 프로세스를 완료하지 않았다.
- 캡티브 포털은 캡티브 포털 감지 기능에 의해 아직 지원되지 않는 흐름에 사용자를 리디렉션.

### 제품 설명

1. 더 보기[캡티브 포털 timeout](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#captive-portal-detection)로그인할 때 더 많은 시간을 허용한다.
2. 이 문제를 해결하지 않으면 사용자가 수동으로 허용[WARP를 끄십시오](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#lock-warp-switch). 우리는 조정을 추천합니다[자동차 연결](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#auto-connect)클라이언트가 몇 분 후에 스스로 돌아갑니다.

## CF CONNECTIVITY FAILURE UNKNOWN의 특징

### 증상

- WARP를 연결할 수 없습니다
- 인터넷 연결 없음
- 사용자는 캡티브 포털 뒤에 있을 수 있습니다.

### 이름 \*

처음 화면[연결 체크](/cloudflare-one/team-and-resources/devices/warp/deployment/firewall/#connectivity-checks)알 수없는 이유에 실패. 더 알아보기[WARP를 연결할 수 없습니다](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/common-issues/#unable-to-connect-warp)왜이 오류가 발생합니다.

### 제품 설명

1. 지원하다[WARP 디버그 로그](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/warp-logs/)장치 용.
2. 문제 해결 단계에 따라[WARP를 연결할 수 없습니다](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/common-issues/#unable-to-connect-warp).

## CF DNS LOOKUP 프랑스

### 증상

- WARP를 연결할 수 없습니다
- 인터넷을 검색할 수 없습니다
- `nslookup`·`dig`명령은 장치에 실패

### 이름 \*

WARP는 hostnames를 통해 해결할 수 없었다[로컬 DNS 프록시](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/warp-architecture/#dns-traffic).

### 제품 설명

1. 사용자가 DNS 연결을 가지고 있는지 확인합니다.
2. WARP가 비활성화 될 때 DNS 해상도가 작동합니다.
3. 제3자 도구가 DNS 제어를 위해 WARP와 인터퍼링을 보장한다.
4. 제3자 도구가없는 것을 보장합니다.[TLS 해독](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/common-issues/#a-third-party-security-product-is-interfering-with-gateway)교통에[WARP IP 주소](/cloudflare-one/team-and-resources/devices/warp/deployment/firewall/).

## 사이트맵

### 증상

- WARP를 연결할 수 없습니다[DNS 필터링을 가능하게 하는 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/).

### 이름 \*

제3자 프로세스(보통 제3자 DNS 소프트웨어)는 포트에 바인딩`53`WARP's에 의해 사용되는 ,[로컬 DNS 프록시](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/warp-architecture/#dns-traffic)DNS 해상도를 실행합니다. 제3자 프로세스의 이름은 GUI 오류 메시지에 나타납니다.

macOS에서 볼 수 있습니다.`mDNSResponder`특정 애플리케이션 이름 대신 --`mDNSResponder`다른 프로세스를 대신하여 DNS 요청을 처리하는 macOS 시스템 프로세스입니다. 어떤 프로세스를 결정하는 알려진 방법이 없습니다.`mDNSResponder`포트에 바인딩`53`, 하지만 가장 일반적인 culprits는 가상 머신 소프트웨어 (예를 들어, Docker 및 VMware Workstation) 및 macOS 인터넷 공유 기능입니다.

### 제품 설명

1. 제3자 공정에서 DNS 차단을 제거하거나 비활성화하십시오.

<Details header="mDNSResponder에">
  아래는 원인으로 알려진 제3자 소프트웨어의 비 유숙 목록입니다.`mDNSResponder`포트에 바인딩`53`. 중지 시도보다 오히려`mDNSResponder`, 당신은 더 이상 포트를 사용하지 않도록 타사 소프트웨어를 구성해야`53`WARP에 연결하기 전에 또는 일시적으로 비활성화하십시오.

  - **기타 제품**: [UDP를 위한 커널 네트워킹을 해제](https://github.com/docker/for-mac/issues/7008#issuecomment-1746653802)Docker에서. 대체로, uncheck**컴퓨터에 로그인할 때 Docker Desktop 시작**이름 \*[**계정 설정** > **주요사업**](https://docs.docker.com/desktop/settings-and-maintenance/settings/#general). 자동적인 시작 과정을 해제하는 것은 항구에 바인딩에서 도커를 방지할 것입니다`53`WARP의 앞에.
  - **인터넷 공유 기능**: 인터넷 공유를 비활성화하려면 :
    1. macOS에서 이동**시스템 설정** > **주요사업** > **공유하기**.
    2. 공지사항**인터넷 공유**.
  - **VMware Workstation 또는 Parallels와 같은 특정 VM 소프트웨어**: VM 소프트웨어의 존재는 WARP와 호환성이 VM의 구성에 매우 의존하기 때문에 오프딩 프로그램입니다. 문제점의 주위에 일하기 위하여, 어떤 VMs를 달리기 전에 WARP에 연결하십시오:
    1. 모든 VM을 중지 / 필요.
    2. WARP에 연결하십시오.
    3. 다시 VM을 시작합니다.
</Details>

2. 대안으로, 스위치 WARP에[교통 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/#traffic-only-mode)모드.

## CF FAILED READ SYSTEM DNS CONFIG

### 증상

- WARP를 연결할 수 없습니다
- 인터넷을 검색할 수 없습니다

### 이름 \*

WARP는 시스템 DNS 구성을 읽을 수 없습니다, 가장 가능성이 잘못된 네임 서버 또는 검색 도메인이 포함되어 있기 때문에.

### 제품 설명

macOS 및 Linux에서 그 검증`/etc/resolv.conf`이름 \*[제대로 된](https://man7.org/linux/man-pages/man5/resolv.conf.5.html)자주 묻는 질문[잘못된 문자](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/common-issues/#maclinux-the-devices-etcresolvconf-file-has-an-invalid-character).

Windows에서 레지스트리 항목에 대한 검증`HKLM\System\CurrentControlSet\Services\TCPIP\Parameters\SearchList`유효한 검색 영역만 포함합니다. 잘못된 항목의 예에는 IP 주소와 도메인이 포함되어 있습니다.`.local`).

## CF FAILED TO SET MTLS의 특징

### 증상

- WARP를 연결할 수 없습니다

### 이름 \*

장치는 현재 실패[유효한 mTLS 증명서](/cloudflare-one/team-and-resources/devices/warp/deployment/device-enrollment/#check-for-mtls-certificate)장치 등록 중.

### 제품 설명

1. 인증서 설치에 대한 관리자 제한이 없습니다.
2. 장치에서 클라이언트 인증서를 다시 설치합니다.

## CF HAPPY EYEBALLS MITM FAILURE

### 증상

- WARP를 연결할 수 없습니다

### 이름 \*

라우터, 방화벽, 바이러스 백신 소프트웨어 또는 기타 타사 보안 제품은 WARP 포트에서 UDP 차단됩니다.

### 제품 설명

1. 제3자 보안 제품 구성[WARP 진입 IP 및 포트](/cloudflare-one/team-and-resources/devices/warp/deployment/firewall/#warp-ingress-ip).
2. 인터넷 라우터가 제대로 작동하고 라우터를 재부팅하려고합니다.
3. 기기가 수정되지 않음을 확인합니다.**팀 & 자원** > **제품정보**.

## CF HOST UNREACHABLE 체크

### 증상

- WARP를 연결할 수 없습니다
- 인터넷 연결 없음
- 사용자는 캡티브 포털 뒤에 있을 수 있습니다.

### 이름 \*

더 보기[연결 체크](/cloudflare-one/team-and-resources/devices/warp/deployment/firewall/#connectivity-checks)WARP 갱도의 안쪽에는 실패했습니다.

### 제품 설명

1. 타사 HTTP 필터링 소프트웨어 (AV, DLP, 또는 방화벽)의 존재를 확인하여 트래픽을 방해 할 수 있습니다[WARP의 IP](/cloudflare-one/team-and-resources/devices/warp/deployment/firewall).
2. 제3자 소프트웨어에서, WARP를 통해 가는 모든 IP 트래픽을 위한 우회 검사. WARP 터널을 통해 트래픽 경로가 무엇인지 알아 보려면, 참조[분할 터널](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/split-tunnels/).

## CF INSUFFICIENT 디스크

### 증상

- WARP를 연결할 수 없습니다
- OS는 디스크가 가득 찬 경고

### 이름 \*

하드 드라이브는 전체 또는 WARP에 대한 잘못된 권한을 가지고 데이터를 작성합니다.

### 제품 설명

1. 당신의 장치가 만나는 것을 보증하십시오[HD 공간 요구 사항](/cloudflare-one/team-and-resources/devices/warp/download-warp/)WARP를 위해.
2. 디스크 공간을 사용하여 WARP를 방지 할 수있는 디스크 권한 검사.
3. 빈 쓰레기 또는 큰 파일을 제거.

## CF INSUFFICIENT FILE 디스크립터

- WARP를 연결할 수 없습니다

### 제품 설명

시스템 설정에서 파일 descriptor 한계를 증가시킵니다.

## CF INSUFFICIENT MEMORY

### 증상

- WARP를 연결할 수 없습니다
- 장치가 매우 느립니다.

### 이름 \*

장치는 WARP를 실행하는 충분한 기억이 없습니다.

### 제품 설명

1. 당신의 장치가 만나는 것을 보증하십시오[최소 메모리 요구 사항](/cloudflare-one/team-and-resources/devices/warp/download-warp/)WARP를 위해.
2. 메모리 사용을 확인하기 위해 모든 실행 프로세스를 나열합니다.

## CF LOCAL POLICY FILE FAILED TO 판

### 증상

- WARP를 연결할 수 없습니다

### 이름 \*

WARP 클라이언트는 잘못된 MDM 구성 파일을 사용하여 장치에 배치되었습니다.

### 제품 설명

1. 자주 묻는 질문[회사연혁](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/)당신의 운영 체계를 위해.
2. 장치에서 MDM 구성 파일을 찾습니다.
3. 파일을 올바르게 포맷하고만 포함합니다.[허용된 인수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/).

## CF NO 네트워크

### 증상

- WARP를 연결할 수 없습니다
- 인터넷 연결 없음

### 이름 \*

장치는 인터넷에 연결되는 Wi-Fi 네트워크 또는 LAN에 연결되지 않습니다.

### 제품 설명

1. 장치에서 네트워크 설정 패널을 시작합니다.
2. 유효한 네트워크에 연결되는 것을 보장합니다.
3. 기기가 유효한 IP 주소를 검색하는 것을 확인합니다.
4. 오류를 해결하지 않으면 장치 재부팅하거나 시스템의 네트워크 진단 도구를 실행하십시오.

## CF TLS INTERCEPTION 블록 DOH

### 증상

- DNS 요청은 WARP가 켜지면 해결되지 않습니다.

### 이름 \*

제3자 응용 프로그램 또는 서비스는 WARP에서 HTTPS 트래픽을 통해 DNS를 차단합니다.

### 제품 설명

제3자 신청서를 작성하여[WARP 도 IPs](/cloudflare-one/team-and-resources/devices/warp/deployment/firewall/#doh-ip).

## CF TLS INTERCEPTION 체크

### 증상

- WARP를 연결할 수 없습니다

### 이름 \*

장치 또는 네트워크의 타사 보안 제품은 HTTPS 트래픽에서 TLS 해독을 수행하고 있습니다. 더 많은 정보를 원하시면, 참조[문제 해결 가이드](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/common-issues/#a-third-party-security-product-is-interfering-with-gateway).

### 제품 설명

WARP 클라이언트 GUI는 다음 상태 메시지를 표시합니다.**연결하기**으로**연결하기**국가. 이 메시지는 WARP daemon의 연결 단계가 장치에서 Cloudflare에 연결되도록 나타냅니다. 더 보기[WARP 형태](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/)연결 과정에서 메시지가 표시된 것을 결정합니다. WARP가 연결 중에 오류가 발생하면 상태 메시지가 변경됩니다.[오류 코드](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/client-errors/).

콘솔에 상태 메시지를 인쇄하려면, 실행`warp-cli -l status`WARP 스위치를 켜기 전에 명령.

| 상태 메시지          | 이름 \*                                                                                                                                                                                                                                        |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 연결 설정 검증        | 연결 구성 요소를 초기화[WARP 설정](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/).                                                                                                                                       |
| 검증된 네트워크        | Ethernet 및/또는 Wi-Fi 네트워크 연결을 검증합니다.                                                                                                                                                                                                          |
| IP 연결 초기화       | Cloudflare에 IPv4 및 IPv6 연결을 확인[Happy Eyeballs 알고리즘](https://datatracker.ietf.org/doc/html/rfc6555).                                                                                                                                          |
| 연결 설정           | Happy Eyeballs에 의해 발견 된 엔드 포인트에 연결.                                                                                                                                                                                                          |
| 터널 구축           | 계정 만들기[가상 네트워크 인터페이스](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/warp-architecture/#virtual-interface)WARP 갱도를 위한 운영 체계에.                                                                                  |
| 방화벽 구성          | WARP 터널 트래픽을 허용하는 시스템 방화벽 구성.                                                                                                                                                                                                                |
| routing 테이블 설정  | 업데이트[시스템 라우팅 테이블](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/warp-architecture/#routing-table)제품정보[분할 터널 규칙](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/split-tunnels/). |
| 방화벽 규칙 구성       | 설정하기[시스템 방화벽](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/warp-architecture/#system-firewall)Split Tunnel 규칙을 기반으로 합니다.                                                                                     |
| DNS에 연결하기       | DNS 엔드포인트에 대한 연결을 확인합니다 (`<account-id>.cloudflare-gateway.com`).                                                                                                                                                                             |
| 로컬 엔드포인트 통신 설정  | 로컬 DNS 프록시 소켓 구성.                                                                                                                                                                                                                            |
| 로컬 DNS 프록시 구성   | 계정 만들기[로컬 DNS 프록시](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/warp-architecture/#dns-traffic)DNS 해상도.                                                                                                      |
| DNS 설정 적용       | 장치에서 기본 DNS 서버로 로컬 DNS 프록시를 설정합니다.                                                                                                                                                                                                           |
| 프록시 구성          | (만에)[로컬 프록시 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/#local-proxy-mode)) SOCKS 프록시 구성.                                                                                                                  |
| 터널 연결           | 연결하기[여행 정보](/cloudflare-one/team-and-resources/devices/warp/deployment/firewall/#connectivity-checks)안쪽과 외부 WARP 갱도.                                                                                                                         |
| DNS 설정 검증       | DNS 요청이 WARP의 로컬 DNS 프록시에 의해 응답되도록 합니다.                                                                                                                                                                                                      |
| SOCKS 프록시 구성 검증 | (만에)[로컬 프록시 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/#local-proxy-mode)) SOCKS 프록시 구성을 검증합니다.                                                                                                           |
| MTLS ID 관리      | (만에)[Posture 전용 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/device-information-only/)) mTLS 인증을 위한 클라이언트 인증서를 설치합니다.                                                                                       |

이 가이드는 당신이 Cloudflare WARP 클라이언트와 일반적인 문제점을 진단하고 해결하는 것을 돕습니다. Windows, macOS 및 Linux를 포함한 데스크톱 운영 체제에서 WARP 클라이언트를 해결하는 방법을 다룹니다.

1. **시작하기 전에**: [자주 묻는 질문](#prerequisites), 권한,[버전 제어](#check-your-warp-version), 그리고 WARP 기초.
2. **로그 수집**: 를 통해[모델 번호: Cloudflare 한국어](#option-a-collect-logs-via-the-cloudflare-dashboard)(DEX 원격 캡처 포함) 또는[명령행 인터페이스](#option-b-collect-logs-via-the-cli)(클립) (`warp-diag`).
3. **비밀번호**: [주요연혁](#check-warp-status), [제품정보](#check-warp-settings), [프로필 ID](#profile-id), [연락처](#exclude-mode-with-hostsips)구성 및 기타 설정.
4. **일반적인 misconfigurations 수정**: [회사 소개](#wrong-profile-id), [분할 터널 문제](#wrong-split-tunnel-configuration), [관리 네트워크 문제](#review-your-managed-network-settings), [사용자 그룹 mismatch](#check-a-users-group-membership).
5. **지원 표 파일**: [티켓 제출 방법](#5-file-a-support-ticket)당신은 당신의 문제 해결 옵션을 소진 한 후.

:::참고\[AI-assisted troubleshooting]

모델 번호: Cloudflare 하나는 WARP 조사를 가속화하는 두 개의 무료 AI 도우미를 포함합니다 :

[**WARP 진단 해석기**](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/warp-logs/#warp-diagnostics-analyzer-beta)- 기기의 WARP 진단 로그를 파싱하는 AI를 사용하여 중요한 사건을 요약하고, 가능성 원인을 요약한 다음 단계를 추천합니다. 이 분석기는 대시보드를 통해 수집된 로그를 위해 유효합니다.

[**DEX MCP 서버**](/cloudflare-one/insights/dex/dex-mcp-server/)— 고객이 같은 질문을 할 수있는 AI 도구, "내가 사용하는 장치에 대한 연결성 및 성능 지표보기[모델 번호: carly@acme.com](mailto:carly@acme.com)", DEX API에서 데이터를 포함하는 답변을받습니다.

## 1. 시작하기 전에

### 자주 묻는 질문

- 당신은 완료해야합니다[Zero Trust 온보딩 교류](/cloudflare-one/setup/)만든 Zero Trust 조직으로.
- 최종 사용자 장치에 설치된 WARP 클라이언트가 있어야 합니다.
- 당신은해야합니다[이름 \*](/cloudflare-one/roles-permissions/)Cloudflare 대시보드에 접속 로그에 대한 관리자 권한을 제공합니다.

### WARP 버전을 확인

많은 문제 해결 문제는 outdated 클라이언트 버전에 의해 발생합니다. 최고의 성능과 호환성을 위해 관리자는 새로운 릴리스를 확인해야하며[WARP 클라이언트 업데이트](/cloudflare-one/team-and-resources/devices/warp/download-warp/)다른 문제를 해결하려고하기 전에.

WARP 클라이언트를 업데이트 한 후, 반복하면 문제를 모니터링합니다. 문제가 발생하면 문제 해결 가이드가 계속됩니다.

### WARP 설정 확인

WARP 상태를 확인한 후, WARP의 설정을 검토하여 예상 구성이 적용된 경우 확인하십시오. 자주 묻는 질문`warp-settings.txt`WARP 클라이언트 설정을 검토하는 파일. 장치의 적용된 장치 단면도 및 쪼개지는 갱도 윤곽을 검사할 것입니다.

바탕 화면에 WARP 진단 로그를 찾아서 열고,`warp-settings.txt`파일. 다음 예제를 검토`warp-settings.txt`파일 및 아래의 내용의 설명.

(user set)  qlog logging: Enabled

  cname.user.net

#### 관련 기사`warp-settings.txt`이름 \*

필드의 의미를 검토`warp-settings.txt`문제 해결에 관련이 있습니다.

##### 항상 에

GUI의 WARP toggle의 현재 상태를 참조하십시오. 예를 들어, WARP toggle는 켜집니다.

```txt
Always On: true
```

##### 스위치 Locked

관련 기사[자물쇠 WARP 스위치](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#lock-warp-switch)사용자가 WARP 스위치를 해제하고 클라이언트를 분리 할 수 있습니다. 예제 파일에서 값은`false`사용자가 재량에 WARP 스위치를 켜거나 꺼낼 수 있습니다.

```txt
Switch Locked: false
```

잠금 WARP 스위치가 활성화되면 (`true`), 사용자는 필요로 할 것입니다[관리자 override 코드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#allow-admin-override-codes)일시적으로 자신의 장치에 WARP를 끄십시오.

##### 주요 특징

관련 기사[WARP 형태](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/)장치가 사용됩니다. 예 파일에서 WARP 모드는`WarpWithDnsOverHttps`교통 및 DNS 모드입니다. 더 알아보기[WARP 형태 비교 모체](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/)당신의 이름`warp-settings.txt`file's value with the mode 이름.

```txt
Mode: WarpWithDnsOverHttps
```

##### 호스트 / ips와 함께 모드 제외

당신의 의견[연락처](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/split-tunnels/)설정. 예를 들어 파일에서 WARP는 예외 모드에서 실행되며, 이러한 호스트에 대한 트래픽을 제외하고 모든 트래픽을 의미하며 IP는 WARP 터널을 통해 전송됩니다. 이름 \*`cname.user.net`IP 정보`1xx.1xx.1xx.1xx/25 `WARP 터널에서 제외됩니다.

```txt
Exclude mode, with hosts/ips:
  1xx.1xx.1xx.1xx/25 (zoom)
...
  cname.user.net
```

:::note\[Exclude 모드 versus 포함 모드]
`Exclude mode`모든 트래픽은 IP 및 도메인을 제외하고 WARP 터널을 통해 전송됩니다.

`Include mode`WARP 터널을 통해 지정한 IP 또는 도메인에만 트래픽이 전송됩니다.
주요 특징

##### Fallback 도메인

당신의 의견[지역 도메인 Fallback](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/local-domains/)설정. 예 파일에서 WARP 목록`intranet`처리할 게이트웨이로 전송되지 않는 도메인으로 설정된 fallback 서버에 직접 전송됩니다.

```txt
(network policy)    Fallback domains:
  intranet
...
```

##### 허용 모드 스위치

관련 기사[모드 스위치](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#mode-switch)설정. 예를 들어, 모드 스위치가 활성화됩니다 (`true`) 사용자가 사이에서 전환 할 수있는 옵션이 있음[교통 및 DNS 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/#traffic-and-dns-mode-default)모드 및[DNS-over-HTTPS(DoH) 게이트웨이](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/#dns-only-mode)모드.

```txt
Allow Mode Switch: true
```

##### 자주 묻는 질문

관련 기사[업데이트](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#allow-updates)설정. 예를 들어 파일에서 업데이트 설정을 설정할 수 있습니다.`false`사용자가 WARP 클라이언트의 새로운 버전이 유효하고 승인 관리자없이 WARP를 업데이트 할 수없는 경우 업데이트 알림을받지 않습니다.

```txt
Allow Updates: false
```

##### Org를 남기기 위해 허용

관련 기사[조직을 떠나는 장치](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#allow-device-to-leave-organization)설정. 예제 파일에서 값은 설정된다.`true`사용자는 Zero Trust 조직에서 로그아웃 할 수 있습니다.

```txt
Allowed to Leave Org: true
```

##### LAN 액세스 설정

관련 기사[사용자를 허용 로컬 네트워크 exclusion](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#allow-users-to-enable-local-network-exclusion)설정. 활성화되면 WARP 터널에서 감지 된 로컬 서브넷을 제외하고 사용자가 일시적으로 로컬 장치 ( 프린터와 같은)에 액세스 할 수 있습니다. 이 예제는 다음 WARP 재연결까지 액세스가 허용되며 하위넷에만 해당됩니다.`/24`.

```txt
LAN Access Settings: Allowed until reconnect on a /24 subnet
```

관련 기사[회사소개](/cloudflare-one/team-and-resources/devices/warp/configure-warp/device-profiles/)장치가 사용됩니다. 이 예에서 ID는`000000x1-00x1-1xx0-1xx1-11101x1axx11`.

#### 관리된 네트워크 설정 검토

·[관리 네트워크](/cloudflare-one/team-and-resources/devices/warp/configure-warp/managed-networks/)TLS 엔드포인트를 정의하는 네트워크 위치는 물리적 사무실과 같습니다. WARP 클라이언트는 그것의 위치를 결정하기 위하여 이 TLS 엔드포인트를 검사하고 대응 장치 단면도를 적용합니다.

관리 네트워크가 misconfigured 또는 TLS 엔드포인트가 제한되지 않은 경우, 장치가 무인화 된 프로파일로 돌아올 수 있습니다.

관리 네트워크 문제에 대한 WARP 문제 해결 :

1. endpoint를 정의할 수 있습니다.

   WARP 클라이언트는 네트워크를 식별하기 위해 TLS 엔드포인트에 연결됩니다. 엔드포인트가 다운되거나 제한되지 않는 경우, WARP 클라이언트는 네트워크를 감지하고 잘못된 프로필을 적용하지 못합니다.

   <Render file="warp/managed-networks-sha-256" product="cloudflare-one" />

   endpoint가 다운되면 수신됩니다.`Could not find certificate from <stdin>`응답.

   반환된 SHA-256 지문을 받은 경우:

   1. 로그인[모델 번호: Cloudflare 한국어](https://one.dash.cloudflare.com/)·**팀 & 자원** > **제품정보** > **회사소개**.
   2. 오시는 길**관리 네트워크** > **제품정보**.
   3. 대시보드에서 TLS Cert SHA-256을 비교하여 터미널에서 반품 된 지문을 사용하여 일치합니다.

2. 단일 위치에 대한 단일 프로파일을 사용합니다.

   관리를 단순화하고 오류를 방지하기 위해 여러 관리 된 네트워크 프로필을 동일한 위치에 생성합니다. 예를 들어, 하나의 사무실에서 여러 TLS 엔드 포인트가 있다면, 단일 장치 프로파일에 모두 연결하십시오. 구성 오류로 인해 무인화 된 프로파일과 일치하는 장치의 위험을 줄일 수 있습니다.

### 잘못된 분할 터널 구성

<Render file="warp/split-tunnel-intro" product="cloudflare-one" />

잘못된 구성[연락처](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/split-tunnels/)연결 문제를 일으킬 수 있습니다.

예를 들어 IP 및 도메인 제외 모드를 설정하고 애플리케이션에 필요한 IP 주소를 실수로 제외하면 해당 애플리케이션이 제대로 동작하지 않을 수 있습니다. 반대로 IP 및 도메인 포함 모드에서 필요한 IP 또는 도메인을 포함하지 않으면 트래픽이 WARP를 우회하게 되고, Zero Trust 보안 기능에 대한 액세스를 잃게 됩니다.

#### 1. 적용된 분할 갱도 윤곽을 검사하십시오

WARP 진단 로그를 다운로드한 후에, 당신의 윤곽이 예정대로 작동한다는 검토:

1. 자주 묻는 질문`warp-settings.txt`파일 및 찾기`Exclude mode, with hosts/ips:`또는`Include mode, with hosts/ips:`.

   :::note\[Exclude 모드 versus 포함 모드]
   `Exclude mode`모든 트래픽은 IP 및 도메인을 제외하고 WARP 터널을 통해 전송됩니다.

   `Include mode`WARP 터널을 통해 지정한 IP 또는 도메인에만 트래픽이 전송됩니다.
   주요 특징

2. 로그인[모델 번호: Cloudflare 한국어](https://one.dash.cloudflare.com/), 이동**팀 & 자원** > **제품정보** > **회사소개** > **일반 프로필**.

3. 장치를 위한 기기 프로파일을 찾아 선택하고 선택합니다.

4. 제품정보**제품정보**.

5. 제품정보**분할 터널**선택한 모드를 참고 > 선택**계정 관리**.

6. 크로스 - 참고 자료 당신은 Cloudflare 하나 대시보드에서 IPs/hosts에 목록으로 만들어진 IPs/hosts로 구성했습니다`warp-settings.txt`.

대시보드 분할 갱도 윤곽이 당신의 일치하지 않는 경우에`warp-settings.txt`파일 구성, 당신은 WARP 클라이언트를 강제할 필요가 있을지도 모릅니다[설정 업데이트](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/troubleshooting-guide/#update-the-warp-clients-settings).

#### 2. WARP 클라이언트의 조정을 업데이트하십시오

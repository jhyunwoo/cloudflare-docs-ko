사용자는 Cloudflare Zero Trust 서비스에 연결할 수 있습니다. Cloudflare 이전에 기능으로 번들[WARP 클라이언트](/warp-client/), 또한 소비자를 위한 개인 중심의 DNS 및 VPN 서비스를 제공 하는 응용 프로그램 (1.1.1.1 w/ WARP로 알려진). 동일한 애플리케이션에서 엔터프라이즈 및 소비자 기능을 모두 지원하면 전 세계 수백만 명의 소비자가 사용 한 동일한 기반에 Zero Trust를 구축 할 수 있지만 변경 사항이 릴리스 될 수 있습니다. 결과적으로 Cloudflare One Agent를 시작으로 WARP 클라이언트를 Zero Trust 배포합니다.

Cloudflare One Agent는 기존의 Zero Trust 기능을 지원합니다. underlying 연결 기술은 1.1.1.1 w/ WARP 사용자가 Cloudflare One Agent에서 피드백을 기반으로 성능 및 신뢰성에 따라 동일한, 개선을 유지한다.

## macOS, Windows 및 Linux

이 시간에 데스크탑 클라이언트에 대한 작업이 필요하지 않습니다. 기존 Cloudflare WARP 클라이언트는 Zero Trust와 1.1.1.1 기능 둘 다 지원 계속할 것입니다.

## iOS 및 Android

Zero Trust 사용자는 Cloudflare 1 대리인 app에 1.1.1.1 앱에서 migrate 해야 합니다. Cloudflare는 Zero Trust 특징을 위한 1.1.1.1 app를 사용하는 더 이상 지원 고객입니다.

조직은 두 가지 모드 중 하나에서 최소 붕괴로 팀을 마이그레이션 할 수 있습니다.[수동으로](#migrate-manual-deployments)또는 를 통해[관리 endpoint 솔루션](#migrate-managed-deployments).

### Migrate 매뉴얼 배포

다운로드하고 수동으로 1.1.1.1 앱을 설치하면 권장 마이그레이션 단계가 있습니다.

<Tabs>
  <TabItem label="이름 *">
    1. 업데이트**1.1.1.1**버전 6.29 이상으로 앱. 업데이트는 1.1.1.1이 될 수 있음을 보장합니다.[채용공고](#what-to-do-with-the-old-app)새로운 Cloudflare 하나 대리인 앱으로.

    2. 지원되는 경우[TLS 해독](/cloudflare-one/traffic-policies/http-policies/tls-decryption/), 당신이 가지고 있다는 것을 지킵니다[Inspect 정책 없음](/cloudflare-one/traffic-policies/get-started/http/)뒤에 오는 신청을 위한 장소:

       - *Google 서비스 (검사하지 않음)*
       - *Google Play 스토어 (검사하지 않음)*
       - *Google (검사하지 않음)*
       - *Google 드라이브 (검사하지 않음)*
       - *Google 채팅 (검사하지 않음)*
       - *Google Meet (검사하지 않음)*

       Android 마이그레이션을 수행 할 때 인증서 핀화 문제를 방지합니다.

    3. 이름 \*[이 지침](/cloudflare-one/team-and-resources/devices/warp/deployment/manual-deployment/#ios-android-and-chromeos)Cloudflare One Agent를 설치하고 등록하십시오.
  </TabItem>

  <TabItem label="네트워크">
    1. 업데이트**1.1.1.1**버전 6.22 이상으로 앱. 업데이트는 1.1.1.1이 될 수 있음을 보장합니다.[채용공고](#what-to-do-with-the-old-app)새로운 Cloudflare 하나 대리인 앱으로.
    2. [다운로드](/cloudflare-one/team-and-resources/devices/warp/download-warp/#ios)이름 \***모델 번호: Cloudflare 1개의 대리인**앱.
    3. Cloudflare One Agent 앱 출시 1.1.1.1의 모든 설정은 Cloudflare One Agent에 자동으로 마이그레이션됩니다. 사용자는 reauthenticate가 필요하지 않습니다.
  </TabItem>
</Tabs>

같은 Zero Trust 조직에 Cloudflare 하나 에이전트를 1.1.1.1로 등록하면 자동으로 Cloudflare 하나 1.1.1.1에 기록됩니다. 1.1.1.1 앱은 소비자 모드로 돌아가며,**Cloudflare Zero Trust로 로그인**이전 앱의 버튼은 새로운 앱으로 리디렉션됩니다.

다른 Zero Trust 조직에 Cloudflare One Agent를 등록하면 다른 Zero Trust 조직에 1.1.1.1로 로그인됩니다.

#### 오래된 앱으로 무엇을 할 수 있습니까?

1.1.1.1과 Cloudflare 둘 다 동안 한 에이전트는 장치, iOS 및 Android에 존재할 수 있습니다. 이 응용 프로그램은 한 번에 연결할 수 있습니다.

회사의 리소스에 액세스하려면 Cloudflare One Agent 앱을 사용해야합니다.

개인 브라우징을 위해 1.1.1.1 앱을 사용할 수 있습니다. 1.1.1.1 w/ WARP에 연결될 때, 당신의 소통량은 Cloudflare의 네트워크를 통해 암호화되고 개인적으로 노선되고, 당신의 고용주는 당신의 브라우징 활동의 무엇이든을 볼 수 없을 것입니다. 소비자 WARP 서비스에 대한 자세한 내용을 보려면, 참조[WARP 클라이언트](/warp-client/).

개인 브라우징을 위해 이전 1.1.1.1 앱을 사용하지 않으려면, 당신은 할 수 있습니다[설치하기](/cloudflare-one/team-and-resources/devices/warp/remove-warp/#ios-and-android)그것은.

### Migrate 관리

1.1.1.1 앱을 배포하면[MDM 공급자](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/), 다음과 같이 이동을 수행합니다:

<Tabs>
  <TabItem label="이름 *">
    1. MDM 도구를 사용하여 업데이트**1.1.1.1**버전 6.29 이상으로 앱. 업데이트는 1.1.1.1이 마이그레이션 중에 새로운 Cloudflare One Agent 앱과 공동 작업 할 수 있음을 보장합니다.

    2. 추가하기**모델 번호: Cloudflare 1개의 대리인**Google Play 스토어에서 앱. 그것의 신청 ID는 입니다`com.cloudflare.cloudflareoneagent`.

    3. 제출하기[MDM 배치 모수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/#android--chromeos)제품정보**1.1.1.1**앱.

    4. MDM 배포 매개 변수를 붙여넣기**모델 번호: Cloudflare 1개의 대리인**앱 구성. 실수로 애플리케이션 ID를 덮지 않도록하십시오 (`com.cloudflare.cloudflareoneagent`).

    5. MDM 도구를 사용하여 설치**모델 번호: Cloudflare 1개의 대리인**당신의 장치에.

    6. Android에서 사용자는 필요합니다.[관련 제품](/cloudflare-one/team-and-resources/devices/warp/deployment/manual-deployment/#ios-android-and-chromeos)새로운 응용 프로그램에는 초기 단계를 통해 갔다.
  </TabItem>

  <TabItem label="네트워크">
    1. MDM 도구를 사용하여 업데이트**1.1.1.1**버전 6.22 이상으로 앱. 업데이트는 1.1.1.1이 마이그레이션 중에 새로운 Cloudflare One Agent 앱과 공동 작업 할 수 있음을 보장합니다.

    2. 추가하기**모델 번호: Cloudflare 1개의 대리인**앱 스토어에서 앱. 그것의 신청 ID는 입니다`com.cloudflare.cloudflareoneagent`.

    3. 제출하기[MDM 배치 모수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/#ios)제품정보**1.1.1.1**앱.

    4. MDM 배포 매개 변수를 붙여넣기**모델 번호: Cloudflare 1개의 대리인**앱 구성. 실수로 애플리케이션 ID를 덮지 않도록하십시오 (`com.cloudflare.cloudflareoneagent`).

    5. MDM 도구를 사용하여 설치**모델 번호: Cloudflare 1개의 대리인**당신의 장치에.

    iOS에서 사용자는 1.1.1.1 앱의 등록 데이터가 새로운 Cloudflare One Agent 앱으로 자동 마이그레이션 할 필요가 없습니다.
  </TabItem>
</Tabs>

사용자가 등록되면 마이그레이션 프로세스가 완료됩니다. 1.1.1.1 앱이 되겠습니다.[소비자 모드](#what-to-do-with-the-old-app)기존 MDM 구성 프로파일을 무시합니다. 1.1.1.1 앱을 유지하려는 경우 MDM 구성을 제거하고 삭제할 수 있습니다.

### 관련 기사

사용자가 마이그레이션했는지 확인하려면**팀 & 자원** > **제품정보**. Cloudflare One Agent를 통해 등록된 장치는 새로운 장치 ID를 가진 새로운 장치로 나타날 것입니다. 그들의 오래된 1.1.1.1 등록은 비활성 장치로 유지됩니다.

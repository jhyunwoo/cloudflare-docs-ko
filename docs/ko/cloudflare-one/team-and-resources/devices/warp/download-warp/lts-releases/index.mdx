Long-Term Support (LTS) 릴리스는 다음 LTS 릴리스 후 최소 12 개월 또는 90 일 동안 보안 버그 수정을 계속하는 보장 된 안정적인 릴리스입니다.

<Render file="warp/support-lifecycle" product="cloudflare-one" />

:::참조
LTS 릴리스는 현재 사용할 수 없습니다, Cloudflare 여전히 새로운 LTS 릴리스 프로세스를 압연. 안정적인 릴리스가 LTS 릴리스를 선언하면이 페이지에 나열되어 발표됩니다.[WARP 변경 로그](/cloudflare-one/changelog/warp/).
:::

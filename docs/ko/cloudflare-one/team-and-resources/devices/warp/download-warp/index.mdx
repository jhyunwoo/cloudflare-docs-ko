## iOS 앱

|           |           |
| --------- | --------- |
| **OS 버전** | iOS 11 이상 |

[iOS App Store에서 다운로드](https://apps.apple.com/us/app/cloudflare-one-agent/id6443476492)또는 "Cloudflare One Agent"를 검색하십시오.

:::주\[1.1.1.1]

레거시 iOS 클라이언트,[1.1.1.1: 더 빠른 인터넷](https://apps.apple.com/us/app/1-1-1-1-faster-internet/id1423538627), Cloudflare 1 대리인에 의해 대체되었습니다. 더 알아보기[본문 바로가기](/cloudflare-one/team-and-resources/devices/warp/download-warp/cloudflare-one-agent-migration/).

:::

## 다운로드

|           |      |
| --------- | ---- |
| **OS 버전** | 5.0+ |

[Google Play 스토어에서 다운로드](https://play.google.com/store/apps/details?id=com.cloudflare.cloudflareoneagent)또는 "Cloudflare One Agent"를 검색하십시오.

:::주\[1.1.1.1]

레거시 Android 클라이언트,[1.1.1.1 + WARP: 더 안전한 인터넷](https://play.google.com/store/apps/details?id=com.cloudflare.onedotonedotonedotone), Cloudflare 1 대리인에 의해 대체되었습니다. 더 알아보기[본문 바로가기](/cloudflare-one/team-and-resources/devices/warp/download-warp/cloudflare-one-agent-migration/).

:::

## 크롬 OS

|           |                            |
| --------- | -------------------------- |
| **OS 버전** | 2019 년 이후 제조 된 Chromebooks |

Chromebooks는 지원됩니다[Android 앱](#android). 2019년 이후에 만들어진 모든 Chromebooks는 우리의 안드로이드 앱을 완전히 지원해야 합니다. 2019년 이전의 크롬북이 있다면,[이 목록을 참조](https://www.chromium.org/chromium-os/chrome-os-systems-supporting-android-apps/)기기가 지원되는지 확인합니다.

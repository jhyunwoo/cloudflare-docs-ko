## WARP 클라이언트 수명주기

### 데스크탑 플랫폼

Windows, macOS 및 Linux용 WARP 클라이언트 릴리스는 두 가지 형태로 제공됩니다. 베타 및 안정. Occasionally, 안정적인 릴리스는 Long-Term 지원 릴리스 (LTS)를 선언합니다.

- [베타 출시](/cloudflare-one/team-and-resources/devices/warp/download-warp/beta-releases/)새로운 기능의 초기 테스트는 다음의 안정적인 릴리스에서 배 앞에 허용합니다. 베타 릴리스는 보안 수정을 얻기 위해 보장되지 않으며 생산 환경에 권장되지 않습니다.
- [안정된 출시](/cloudflare-one/team-and-resources/devices/warp/download-warp/)LTS 릴리스로 라벨을 붙인 , 생산 보행 이며 최신 기능 및 보안 버그 수정을 포함 합니다. 비-LTS 안정 출시에서 발견 된 기능 및 보안 버그는 나중에 안정적인 릴리스로 고정 될 것입니다. 그들은 이전 버전으로 백업되지 않습니다. 따라서, Cloudflare는 정기적으로 최신 안정되어 있는 방출을 배치하는 것을 추천합니다.
- [LTS 출시](/cloudflare-one/team-and-resources/devices/warp/download-warp/lts-releases/)다음 LTS 릴리스 후 최소 12 개월 또는 90 일 동안 보안 버그 수정을 계속 수신 보장됩니다. 예를 들어, 두 개의 연속 LTS 릴리스 사이에 15 개월이 있다면, 이전 LTS 릴리스는 18 개월 동안 보안 수정을 받게됩니다 (그런 릴리스에서 90 나중에 LTS 릴리스 후). 다가오는 안정적인 출시는 향후 90일 이전 기간의 고객에게 알리기 위해 LTS 출시를 선언합니다.

  적시에 보안 수정을 덜 자주[버전 테스트](/cloudflare-one/team-and-resources/devices/warp/download-warp/update-warp/#test-before-updates), 고객은 LTS 릴리스 만 배포하고 안정적인 릴리스를 건너 뛸 수 있습니다. 이 접근법은 안정성이 최신 기능의 급속한 채택보다 더 중요하다는 큰 위험 역 조직에 권장됩니다.

### 모바일 플랫폼

WARP 클라이언트는 iOS, iPadOS, Android, ChromeOS 및 ChromeOS Flex에 대한 릴리스가 iOS 앱 스토어 또는 Google Play 스토어를 통해 출시 된 안정적인 릴리스로 제한됩니다. 따라서 보안 수정은 최신 릴리스를 통해 배송됩니다.

### 특징 deprecation 정책

특정 WARP 클라이언트 버전에 포함 된 주요 기능은 그 버전의 전체 수명주기에 대해 지원됩니다. 즉, Cloudflare는 보안 지원 창 내에서 여전히 클라이언트 버전에서 기능을 제거하지 않습니다.

Cloudflare는 미래 릴리스의 주요 기능을 제거하기 전에 최소 90 일 통지를 제공합니다. 이것은 안정되어 있는 방출 궤도에 고객에게 최신 방출의 채택을 연기 없이 특징 제거를 준비할 수 있습니다. LTS 릴리스 트랙의 고객은 이미 LTS 릴리스 사이의 90 일 오버랩 기간이 있습니다.

### 공지사항

Cloudflare는 조정 방출 계획에서 작동하지 않습니다; WARP 클라이언트를 위한 모든 방출은 증가합니다. 새로운 WARP 클라이언트 버전이 출시되면 Cloudflare는 릴리스 노트를 게시합니다.[다운로드](/cloudflare-one/team-and-resources/devices/warp/download-warp/)그리고 에서[공지사항](/cloudflare-one/changelog/warp/).

## 지원된 운영 체계

WARP는 납품업자 또는 유지업자에 의해 제공되는 1 차적인 정비 timespan를 위한 운영 체계를 지원하기 위하여 보장됩니다. 이것은 WARP 클라이언트에 있는 안전 고침이 밑에 운영 체계에 있는 안전 고침에 의해 항상 지원된다는 것을 보증하는 것입니다.

### 윈도우

Windows 용 WARP 클라이언트 지원 정책은 다음과 같습니다.[Microsoft의 Lifecycle 정책](https://learn.microsoft.com/en-us/lifecycle/).

- **윈도우 10 및 11**: WARP 지원[Windows 클라이언트 버전](https://learn.microsoft.com/en-us/windows/release-health/supported-versions-windows-client)Microsoft의 현대 라이프사이클 정책의 Active servicing에 남아 있기 때문에. Enterprise LTSC 에디션은 Mainstream Support에서 유지해야 합니다.
- **Windows 서버**: Windows Server 용 WARP 지원이 종료됩니다. 일단 시험이 완료되면, 우리의 정책은 지원될 것입니다[Windows 서버 LTSC 출시](https://learn.microsoft.com/en-us/windows/release-health/windows-server-release-info)Mainstream 지원 창 안에. Windows Server의 연간 채널 출시가 지원되지 않습니다.

:::참조
WARP 클라이언트가 지원하는 Windows 10의 단지 1개의 버전이 있습니다: 최신 LTSC 방출. 표준 Windows 10 릴리스는 더 이상 지원되지 않습니다. Windows 11을 데스크톱 장치에 배포하는 것을 강력하게 권장합니다.

#### Windows Server의 이전 버전

WARP 클라이언트는 마이크로소프트의 주류 지원 창을 떠난 가장 최근 Windows 서버 버전을 지원할 것입니다, Windows 서버의 이동으로 대부분의 운영 체계 보다는 현저하게 더 길게 하기 위하여 관찰되었습니다. Windows Server 릴리스가 Mainstream Support를 떠난 후에는 WARP 클라이언트가 지원되는 시간을 보장하지 않습니다. 지원 종료가 90 일 전에 발표됩니다. Windows Server의 지원된 버전으로 신속하게 마이그레이션할 수 있으므로 운영 체제의 버그가 발생하지 않도록 주의하십시오. 모든 경우에, WARP 클라이언트는 underlying 운영 체계에 있는 안전 문제점을 해결하지 않을 것입니다.

#### Linux 용 Windows 서브 시스템 (WSL)

Linux v2 용 Windows 서브 시스템 (WSLv2)는 Windows 호스트에 설치되는 WARP 클라이언트 (WARP 클라이언트가 WSLv2) 내부를 실행하지 않기 때문에 Windows의 호스트 버전이 지원됩니다.

### 맥 OS

WARP 클라이언트는 macOS의 현재 중요한 버전을 지원하고 이전의 중요한 버전. 이전 버전의 장치에는 최신 미성년자 및 패치 업데이트가 설치되어 있어야 합니다 (예를 들어,`14.8.3`) 지원 받기. 이 정책은 Apple의 표준 보안 업데이트 사이클뿐만 아니라 다른 데스크탑 운영 체제와 비교하여 새로운 macOS 버전의 비교 빠른 릴리스와 일치합니다.

### 빨간 모자 기업 리눅스 (RHEL)

### 크롬 OS

WARP 클라이언트는 안정되어 있는, LTS 및 LTSC 수로에 현재 ChromeOS 방출만 지원합니다.

이 문서에 나열된 다른 운영 체제와 달리 특정 ChromeOS 버전 번호는 플랫폼의 급속한 방출 cadence로 인해 여기에 추적되지 않습니다 (약 4 주 6 개월마다). 본문 바로가기[ChromeOS 릴리스 일정](https://chromiumdash.appspot.com/schedule)채널의 현재 버전을 확인하려면.

장치 등록 권한은 사용자가 조직의 Cloudflare Zero Trust 인스턴스에 새로운 장치를 연결할 수 있는지 결정합니다.

## 장치 등록 권한 설정

<Render file="warp/device-enrollment" product="cloudflare-one" />

사용자는 지금 할 수 있습니다[휴대폰 번호](/cloudflare-one/team-and-resources/devices/warp/deployment/manual-deployment/)당신의 ID 공급자에 로그인하십시오. 로그인 후 조직에서 사용자를 방지하기 위해, 비활성화[조직을 떠나는 장치](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#allow-device-to-leave-organization)WARP 클라이언트 설정에서.

## 예시정책

### 서비스 토큰

사용자가 자격 증명을 인증하는 대신, 당신은 사용할 수 있습니다[서비스 토큰](/cloudflare-one/access-controls/service-credentials/service-tokens/)모든 사용자 상호 작용 없이 장치를 등록하십시오. 이용자는 정체성 공급자에 로그인할 필요가 없기 때문에, 정체성 정책은 이러한 장치에서 시행할 수 없습니다.

서비스 토큰을 사용하여 장치를 등록하려면:

<Render file="warp/service-token-enrollment" product="cloudflare-one" />

어떤 기기가 등록되어 있는지 확인할 수 있습니다.**팀 & 자원** > **제품정보**. 서비스 토큰 (또는 다른 서비스 Auth 정책)을 사용하여 등록한 장치에는**이름 \***&#xD604;장 쇼`non_identity@<team-name>.cloudflareaccess.com`.

### mTLS 인증서 확인

기업 고객은 강제할 수 있습니다[상호 TLS 인증](/cloudflare-one/access-controls/service-credentials/mutual-tls-authentication/)장치 등록 중.

<Render file="warp/device-enrollment-mtls" product="cloudflare-one" />

사용자 정의[Zero Trust 조직에 로그인](/cloudflare-one/team-and-resources/devices/warp/deployment/manual-deployment/)WARP 클라이언트에서, 그들의 장치는 연결하기 위하여 유효한 클라이언트 증명서를 제시해야 합니다.

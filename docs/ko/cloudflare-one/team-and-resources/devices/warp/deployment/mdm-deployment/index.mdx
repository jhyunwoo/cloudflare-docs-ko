## 윈도우

Windows용 WARP 클라이언트는 Intune, AD, 또는 실행할 수 있는 모든 스크립트 또는 관리 도구를 통해 자동화된 설치를 허용합니다`.msi`파일.

### WARP 설치

WARP 클라이언트를 설치하려면 다음 명령을 실행하십시오.

```bash
msiexec /i "Cloudflare_WARP_<VERSION>.msi" /qn ORGANIZATION="your-team-name" SUPPORT_URL="http://support.example.com"
```

#### 지원된 재산

WARP MSI 설치 프로그램은 다음을 지원합니다[관련 상품](https://learn.microsoft.com/en-us/windows/win32/msi/public-properties):

- `ORGANIZATION`
- `GATEWAY_UNIQUE_ID`
- `AUTH_CLIENT_ID`
- `AUTH_CLIENT_SECRET`
- `ONBOARDING`
- `OVERRIDE_API_ENDPOINT`
- `OVERRIDE_DOH_ENDPOINT`
- `OVERRIDE_WARP_ENDPOINT`
- `SERVICE_MODE`
- `SUPPORT_URL`
- `SWITCH_LOCKED`

더 알아보기[배포 매개 변수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/)각 재산에 대한 설명.

### 제거 WARP

WARP 클라이언트를 제거하려면:

1. 첫째, 찾아`.msi`다음 PowerShell 명령 패키지:

```powershell
Get-WmiObject Win32_Product | Where-Object { $_.Name -match "WARP" } | Sort-Object -Property Name | Format-Table IdentifyingNumber, Name, LocalPackage -AutoSize
```

```txt output
IdentifyingNumber                      Name            LocalPackage
-----------------                      ----            ------------
{5RA4DJWK-13D8-2NSX-QRF8-UANLODWD6D90} Cloudflare WARP C:\WINDOWS\Installer\3f476db.msi
```

2. uninstall 명령에서 LocalPackage 출력을 사용할 수 있습니다. 예를 들어,

```powershell
msiexec /x C:\WINDOWS\Installer\<WARP_RELEASE>.msi /quiet
```

### MDM 매개 변수 업데이트

Windows 클라이언트의 on-disk 구성은 수정하거나 교체하여 언제든지 변경할 수 있습니다.`C:\ProgramData\Cloudflare\mdm.xml`. 이 파일의 형식은 다음과 같습니다.

```xml
<dict>
  <key>organization</key>
  <string>your-team-name</string>
	<key>onboarding</key>
	<false/>
</dict>
```

이 파일 변경은 WARP 클라이언트가 즉시 처리됩니다.

### 임베디드 브라우저에서 인증

기본적으로 WARP는 사용자의 기본 브라우저를 사용하여 등록을 수행합니다. 기본 설정은 임베디드 브라우저에서 사용자를 정정할 수 있습니다. 임베디드 브라우저는 실행에서 기본 브라우저를 방지 할 수있는 모든 프로토콜 핸들러 문제 주위에 작동합니다.

임베디드 브라우저를 사용하려면:

1. WebView2 다운로드 및 설치[Microsoft 지침](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section).
2. 다음 명령으로 레지스트리 키를 추가:
   ```txt
   REG ADD HKLM\SOFTWARE\Cloudflare\CloudflareWARP /f /v UseWebView2 /t REG_SZ /d y
   ```

WARP 클라이언트는 이제 사용자가 Zero Trust로 장치를 등록 할 때 WebView2를 시작합니다.

macOS용 WARP 클라이언트는 Jamf, Intune, Kandji, 또는 JumpCloud 또는 모든 스크립트 또는 관리 도구와 같은 도구를 통해 자동화 된 설치를 허용합니다.`com.cloudflare.warp.plist`파일 형식`/Library/Managed Preferences`. plist는 또한 감싸일 수 있습니다`.mobileconfig`.

### MDM 배포를위한 준비 파일

#### `plist`이름 \*

1. [다운로드](/cloudflare-one/static/mdm/com.cloudflare.warp.plist)이름 \*`com.cloudflare.warp.plist`파일.

2. 기타 제품`your-team-name`당신의 Cloudflare로 한국어<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>.

3. 원하는 파일 수정[배포 매개 변수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/).

#### `mobileconfig`이름 \*

1. [다운로드](/cloudflare-one/static/mdm/CloudflareWARP.mobileconfig)이름 \*`.mobileconfig`파일.

2. 기타 제품`your-team-name`당신의 Cloudflare로 한국어<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>.

3. 지원하다`uuidgen`macOS 터미널에서. 이 값을 생성한다.`PayloadUUID`, 기본 값을 대신 사용할 수 있는 경우`PayloadUUID`.

4. 원하는 파일 수정[배포 매개 변수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/).

### 관리되지 않음`mdm.xml`이름 \*

구성할 수 있습니다.[WARP 배치 모수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/)macOS에서 수동으로 배치`mdm.xml`파일 형식`/Library/Application Support/Cloudflare`. 이 배포 방법은 푸시하는 대안입니다`plist`또는`mobileconfig`MDM 도구를 사용하여.

형식의`/Library/Application Support/Cloudflare/mdm.xml`다음과 같이:

```xml
<dict>
  <key>organization</key>
  <string>your-team-name</string>
</dict>
```

```xml
<dict>
  <key>organization</key>
  <string>your-team-name</string>
</dict>
```

설치로 진행하려면 XML 코드의 예입니다.

```xml
<key>organization</key>
<string>your-team-name</string>
<key>switch_locked</key>
<true />
<key>auto_connect</key>
<integer>0</integer>
<key>gateway_unique_id</key>
<string>your_gateway_doh_subdomain</string>
<key>service_mode</key>
<string>warp</string>
<key>support_url</key>
<string>https://support.example.com</string>
```

MDM 도구가 XML을 지원하지 않으면 XML을 JSON으로 변환해야 할 수 있습니다. 아래 예입니다:

```json
{
	"organization": "your-team-name",
	"gateway_unique_id": "your_gateway_doh_subdomain",
	"onboarding": true,
	"switch_locked": true,
	"auto_connect": 0,
	"service_mode": "warp",
	"support_url": "https://support.example.com"
}
```

더 알아보기[배포 매개 변수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/)각 값에 대한 설명.

Cloudflare Zero Trust로 원격 사용자의 Windows 로그인 자격 증명을 검증하기 위해 온프레미스 Active Directory (또는 이와 유사한) 서버를 사용할 수 있습니다. 사용자가 처음 Windows 로그인 정보를 입력하기 전에 WARP 클라이언트는 서비스 토큰을 사용하여 연결을 설정합니다. 이 초기 연결은 사용자 ID와 관련이 없습니다. 사용자가 Windows 로그인을 완료하면, WARP 스위치는 ID 기반 세션으로 전환하고 모든 미래 로그인에 사용자 등록을 적용합니다.

## 자주 묻는 질문

- Active Directory 리소스는[Cloudflare에 연결해](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/).

## 3. MDM 파일을 구성

Windows 사전 로그인 기능을 활성화하려면 다음 형식의 MDM 파일이 있어야 합니다.[설치하기](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/#windows)장치에서. 다음 예제에서,`pre_login`key는 서비스 토큰을 사용하여 연결 할 수있는 장치를 허용합니다.`configs`기본 Zero Trust 구성을 포함합니다.

```xml
<dict>
  <key>pre_login</key>
  <dict>
    <key>organization</key>
    <string>mycompany</string>
    <key>auth_client_id</key>
    <string>TOKEN-ID</string>
    <key>auth_client_secret</key>
    <string>TOKEN-SECRET</string>
  </dict>
  <key>configs</key>
  <array>
    <dict>
      <key>organization</key>
      <string>mycompany</string>
      <key>display_name</key>
      <string>Default</string>
    </dict>
  </array>
</dict>
```

WARP는 다른 WARP 등록이 존재하지 않을 때 사전 로그인 구성을 적용하고 사용자는 Windows로 로그인하지 않았습니다. 사전 로그인 구성이 효과에있을 때, 장치가 나타납니다**팀 & 자원** > **제품정보**자주 묻는 질문`non_identity@<team-name>.cloudflareaccess.com`.

사용자가 Windows로 로그인 한 후 WARP는 기본 MDM 구성으로 자동으로 전환하고 IdP로 인증하는 사용자를 프롬프트합니다. 인증되면 WARP 등록 및 사용자 정체와 연결됩니다. 더 보기**팀 & 자원** > **제품정보**페이지는 이제 사용자의 이메일과 관련된 새로운 장치를 보여줍니다.

이름 \*[다중 사용자 모드](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/windows-multiuser/)이 사용자 등록은 다음 Windows 사용자 로그인 전에 다음 연결에 사용됩니다. 사용자 등록을 삭제하면 WARP가 Windows에서 사용자가 로그 아웃 한 후 사전 로그인 구성으로 전환합니다.

pre-login 구성이 어떻게 작동했는지 알아보기[다중 사용자 모드](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/windows-multiuser/), 참조[WARP 등록 순서도](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/windows-multiuser/#warp-registration-logic).

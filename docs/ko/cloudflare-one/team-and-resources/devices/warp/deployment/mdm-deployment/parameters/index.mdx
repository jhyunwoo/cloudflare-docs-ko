## 가득 차있는 Cloudflare Zero Trust 특징을 위해 요구되는

Cloudflare Zero Trust의 대다수를 위해, 당신은 팀 이름을 지정할 필요가 있습니다. 팀 이름에 달려있는 Cloudflare Zero Trust 특징의 보기는 입니다[HTTP 정책](/cloudflare-one/traffic-policies/http-policies/), [브라우저 고립](/cloudflare-one/remote-browser-isolation/)·[장치 자세](/cloudflare-one/reusable-components/posture-checks/).

### `organization`

클라이언트가 귀하의 조직으로 장치를 등록하도록 지시합니다. 등록은 인증이 필요합니다.[사이트맵](/cloudflare-one/integrations/identity-providers/)또는[서비스 Auth](/cloudflare-one/access-controls/service-credentials/service-tokens/).

**가치 유형:** `string`

**가치:**&#xB0B4; 계정<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>.

## DNS 전용 정책 시행에 필요한

이 필드는 DoH 전용 모드에서 클라이언트를 배치 할 때 DNS 정책을 시행하는 데 사용됩니다.

### `gateway_unique_id`

클라이언트가 특정 DNS 쿼리를 직접 지시[Gateway DNS 위치](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/). 이 값은 배포하지 않고만 필요하다.[팀 이름](#organization)또는 여러 DNS 위치에서 조직. DoH 하위 도메인을 제공하지 않는 경우 조직의 기본 게이트웨이 DNS 위치를 자동으로 사용합니다.

**가치 유형:** `string`

**가치:**&#xB0B4; 계정<GlossaryTooltip term="DoH subdomain">DoH 하위 도메인</GlossaryTooltip>.

Zero Trust 조직에서 장치를 Enrolls[서비스 토큰](/cloudflare-one/access-controls/service-credentials/service-tokens/#create-a-service-token)·

**가치 유형:** `string`

**가치:**&#xC11C;비스 토큰의 클라이언트 ID.

### `auto_connect`

스위치가 사용자에 의해 꺼진 경우에, 클라이언트는 분의 지정된 수 후에 자동적으로 돌려보낼 것입니다. 우리는이 세트를 매우 낮은 값으로 유지하는 것이 좋습니다 - 일반적으로 호텔 또는 공항 Wi-Fi에 로그인 할 수있는 사용자를위한 충분한 시간. 어떤 값이 지정되는 경우`auto_connect`WARP 클라이언트의 기본 상태는 항상 연결될 것입니다 (예를 들면, 처음 설치 또는 재부팅 후에).

**가치 유형:** `integer`

**가치:**

- `0`- 사용자가 다시 돌아갈 때까지 무한하게 위치를 유지 할 수있는 스위치를 허용한다.
- `1`으로`1440`— 지정된 수 분 후에 자동으로 스위치를 켜십시오.

:::참조

이 매개 변수는 이전을 대체`enabled`더 이상 새로운 기능과 함께 사용할 수없는 재산`switch_locked`·`auto_connect`. 이 매개 변수를 사용하려면 제거해야합니다.`enabled`.
:::

### `enable_netbt`

NetBIOS over TCP/IP (NetBT)는 Windows의 유산 기능으로 주로 몇몇에 있는 이름 해결책을 위해 사용됩니다[드문 시나리오](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#when-to-enable-netbt). Cloudflare WARP는 보안상의 이유로 기본적으로 터널 인터페이스에 NetBT를 비활성화합니다. 조직이 NetBT를 요구하는 레거시 애플리케이션에 여전히 의존한다면, 기본 동작을 무시하고 NetBT를 활성화할 수 있습니다.

**가치 유형:** `boolean`

**가치:**

- `false`- (과태) WARP 터널 인터페이스에서 NetBT를 비활성화합니다.
- `true`— WARP 갱도 공용영역에 NetBT를 가능하게 합니다.

### `enable_pmtud`

[경로 MTU Discovery (PMTUD)](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/path-mtu-discovery/)WARP는 현재 네트워크에 전송 될 수있는 가장 큰 패킷 크기를 발견하고 연결 성능을 최적화 할 수 있습니다.

**가치 유형:** `boolean`

**가치:**

- `false`— (과태) PMTUD를 비활성화합니다.
- `true`— WARP 갱도 공용영역에 PMTUD를 가능하게 합니다.

이 기능은 Cloudflare 중국 지역 네트워크 파트너 또는 네트워크 트래픽의 무결성을 유지할 수있는 다른 타사 네트워크 파트너와 함께 사용됩니다. 대부분의 IT 관리자는 새로운 IP에 모든 API 트래픽을 리디렉션 할 때이 설정을 설정하지 않아야합니다.

**가치 유형:** `string`

**가치:** `1.2.3.4`— Redirect 모든 클라이언트 Orchestration API 호출`1.2.3.4`.

문자열은 유효한 IPv4 또는 IPv6 주소이어야 합니다. 그렇지 않으면 WARP 클라이언트는 전체 MDM 파일을 파싱하지 않습니다.

이 기능은 Cloudflare 중국 지역 네트워크 파트너 또는 네트워크 트래픽의 무결성을 유지할 수있는 다른 타사 네트워크 파트너와 함께 사용됩니다. 대부분의 IT 관리자는 새로운 IP로 모든 DoH 트래픽을 리디렉션 할 때이 설정을 설정하지 않아야합니다.

**가치 유형:** `string`

**가치:** `1.2.3.4`— HTTPS를 통해 모든 DNS를 다시 시작합니다.`1.2.3.4`.

문자열은 유효한 IPv4 또는 IPv6 주소이어야 합니다. 그렇지 않으면 WARP 클라이언트는 전체 MDM 파일을 파싱하지 않습니다.

이 기능은 Cloudflare 중국 지역 네트워크 파트너 또는 네트워크 트래픽의 무결성을 유지할 수있는 다른 타사 네트워크 파트너와 함께 사용됩니다. 대부분의 IT 관리자는 새로운 IP로 모든 WARP 트래픽을 리디렉션 할 때이 설정을 설정하지 않아야합니다.

**가치 유형:** `string`

**가치:** `203.0.113.0:500`- 모든 WARP 트래픽을 다시`203.0.113.0`항구에`500`.

문자열은 유효한 IPv4 또는 IPv6 소켓 주소 (IP 주소 및 포트 번호 포함)이어야 합니다. 그렇지 않으면 WARP 클라이언트는 전체 MDM 파일을 파싱하지 않을 것입니다.

### `service_mode`

클라이언트의 조작 모드를 선택할 수 있습니다.

**가치 유형:** `string`

**가치:**

- `warp`- (기본)[교통 및 DNS 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/#traffic-and-dns-mode-default).
- `1dot1` — [DNS만 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/#dns-only-mode).
- `proxy` — [로컬 프록시 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/#local-proxy-mode). 사용`proxy_port`localhost SOCKS 프록시 포트를 지정하는 매개 변수 (between`0`-`66535`). 예를 들어,
  ```xml
  <key>service_mode</key>
  <string>proxy</string>
  <key>proxy_port</key>
  <integer>44444</integer>
  ```
- `postureonly` — [Posture 전용 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/#posture-only-mode).
- `tunnelonly` - [교통 모드](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/#traffic-only-mode).

### `support_url`

WARP 클라이언트가 MDM를 통해 배치될 때, in-app**연락처**버튼은 기본적으로 비활성화됩니다. 이 매개 변수는 버튼과 직접 피드백을 조직으로 재 활성화 할 수 있습니다.

**가치 유형:** `string`

**가치:**

- `https://<support.example.com>`- 사용`https://`회사의 내부 도움말 사이트를 엽니 다.
- `mailto:<yoursupport@example.com>`- 사용`mailto:`기본 메일 클라이언트를 엽니 다.

### `switch_locked`

사용자가 WARP 스위치를 차단하고 클라이언트를 분리 할 수 있습니다.

**가치 유형:** `boolean`

**가치:**

- `false`- (기본) 사용자는 재량에 스위치 온/오프를 돌릴 수 있습니다. 스위치가 꺼질 때, 사용자는 특정 장치 자세 검사를 레버리지에 의해 보호되는 위치에 도달 할 수 없습니다.
- `true`— 사용자는 스위치를 돌리기에서 방지됩니다. WARP 클라이언트는 연결된 국가에서 자동적으로 시작할 것입니다.

새로운 배포에, 당신은 또한 포함해야`auto_connect`적어도 값의 매개 변수`0`. 이것은 사용자가 수동으로 가능하게 할 수있는 방법없이 오프 상태로 배포되는 클라이언트를 방지 할 것입니다.

:::참조
이 매개 변수는 이전을 대체`enabled`더 이상 새로운 기능과 함께 사용할 수없는 재산`switch_locked`·`auto_connect`. 이 매개 변수를 사용하려면 제거해야합니다.`enabled`.
:::

## 최고 수준의 매개 변수

최고 수준의 매개 변수는 WARP가 장치 등록을 관리하는 방법을 결정합니다.

### `configs`

사용자를 허용[Zero Trust 조직 사이 스위치](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/switch-organizations/)WARP 클라이언트 GUI에서. 더 보기`configs`배열은 또한 다른 것을 사용할 때 요구됩니다[최고 수준 모수](#top-level-parameters)등`multi_user`또는`pre_login`, 1개의 조직만 지정되는 경우에 조차.

**가치 유형:** `array`

**가치:**&#xD558;나 이상의 Zero Trust 조직을 포함하는 배열.

### `multi_user`

Windows 장치에 여러 사용자 등록을 가능하게 합니다.

**가치 유형:** `boolean`

**가치:**

- `false`- (기본) 1개의 WARP 등록은 장치 당 저장됩니다. 사용자가 WARP에 로그인 한 후 설정 및 정체성은 장치에서 모든 트래픽에 적용됩니다.
- `true`— 각 Windows 사용자는 자신의 WARP 등록이 있습니다. 더 많은 정보를 원하시면, 참조[Windows 장치에서 여러 사용자](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/windows-multiuser/).

### `pre_login`

WARP를 허용하여 서비스 토큰과 연결하여 초기 Windows 로그인을 완료합니다. 더 많은 정보를 원하시면, 참조[Windows 로그인 전에 WARP 연결](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/windows-prelogin/).

## Per-app VPN 매개 변수 (Android)

[퍼앱 VPN](https://support.google.com/work/android/answer/9213914?hl=en)매개 변수는 WARP 터널을 통해 트래픽을 보낼 수있는 안드로이드 응용 프로그램을 선택할 수 있습니다. 관리자는 Android 앱을 관리하거나 작업 프로필에 배포하는 모든 MDM 도구를 통해 이러한 매개 변수를 구성할 수 있습니다.

### `app_identifier`

Google Play 스토어에서 앱을 고유하게 식별하는 응용 패키지 이름 / 번들 식별자. 이 응용 프로그램은 WARP 서비스를 통해 터널링됩니다.

**가치 유형**: `string`

**제품정보**: 앱 식별자는 특정 앱의 Play Store URL의 ID 쿼리 매개 변수에서 찾을 수 있습니다. 예시: 예시`https://play.google.com/store/apps/details?id=com.cloudflare.cloudflareoneagent`Cloudflare One Agent 앱의 앱 식별자는`com.cloudflare.cloudflareoneagent`.

### `is_browser`

옵션 속성.`is_browser`Cloudflare One Agent Application은 Re-authentication 및 Gateway 블록 알림과 같은 특정 기능에 대한 기본 브라우저 대신 브라우저를 열지 결정합니다. 필요한 경우, 관리자는 명시적으로 주어진 것을 나타냅니다`tunneled_app`자동 브라우저 감지에 의존하지 않는 브라우저입니다.

**가치 유형**: `boolean`

**제품정보**: 값이 있는 경우`true`, 정의 된 응용 프로그램을 식별`app_identifier`브라우저로. 기본값은`false`·`is_browser`옵션 속성입니다.

Cloudflare Zero Trust는 통합합니다[모델 번호: Cloudflare 기술 파트너](https://www.cloudflare.com/partners/technology-partners/)WARP 클라이언트를 더 큰 장치로 배포하는 데 도움이되는 도구. 이러한 협업 덕분에 WARP 클라이언트 애플리케이션을 최종 사용자 장치로 배포하고 실시간으로 고급 구성을 원격으로 설정할 수 있습니다.

## 윈도우

1. 스크립트 파일 만들기`.bat`, `.cmd`·`.ps1`파일 형식을 다운로드, 설치 및 구성 Cloudflare WARP 클라이언트 Windows 응용 프로그램 장치. 아래 목록은 구성 매개 변수의 모든 샘플 스크립트입니다:

   ```python
   <# Choose file name for downloading application #>
   $filename = filename.msi'

   <# Download URL of the installer. #>
   $url = 'https://downloads.cloudflareclient.com/v1/download/windows/ga'
   Write-Host 'Downloading App from' $url
   Invoke-WebRequest -Uri $url -OutFile $filename

   <# Run the installer and wait for the installation to finish #>
   $arguments = "ORGANIZATION="exampleorg" SERVICE_MODE="warp" GATEWAY_UNIQUE_ID="fmxk762nrj" SUPPORT_URL="http://support.example.com""

   $installProcess = (Start-Process $filename -ArgumentList $arguments -PassThru -Wait)

   <# Check if installation was successful #>
   if ($installProcess.ExitCode -ne 0) {
       Write-Host "Installation failed!"
       exit $installProcess.ExitCode
   }
   else {
       Write-Host "Installation completed successfully!"
   }
   ```

2. Hexnode를 사용하여 장치에 스크립트 파일을 밀어.

3. Hexnode 콘솔에서 이동**계정 관리** > **제품정보**.

4. 장치 이름을 선택하십시오. 이것은 당신에게 데려 갈 것이다**회사소개**.

5. 제품정보**관련 기사** > **Custom Script 실행**.

6. 스크립트 파일 소스를 선택*파일 업로드*, 다음 스크립트 파일을 업로드합니다.

7. 제품정보**계정 관리**.

## 맥 OS

1. [다운로드](/cloudflare-one/team-and-resources/devices/warp/download-warp/#macos)macOS용 Cloudflare WARP 클라이언트.

2. Hexnode 콘솔에서 이동**앱 다운로드** > **앱 추가** > **기업 앱**.

3. 제품정보*맥 OS*앱 플랫폼으로.

4. 앱 이름, 범주 및 설명 추가.

5. 다운로드`Cloudflare_WARP_<VERSION>.pkg`파일 및 선택**더 보기**.

6. 지원된 앱 구성으로 XML 파일을 설정합니다.
   받아들여진 매개변수를 가진 표본 XML 파일입니다.

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
   <plist version="1.0">
   <dict>
   <key>organization</key>
   <string>organizationname</string>
   <key>auto_connect</key>
   <integer>1</integer>
   <key>switch_locked</key>
   <false />
   <key>service_mode</key>
   <string>warp</string>
   <key>support_url</key>
   <string>https://support.example.com</string>
   </dict>
   </plist>
   ```

7. Hexnode 콘솔에서 이동**회사연혁**.

8. 새로운 정책을 만들고 정책 이름을 제공합니다.

9. 오시는 길**맥 OS** > **앱 관리** > **Mandatory 앱**그리고 정책 설정 시작.

10. 제품정보**더 보기**이전에 업로드된 WARP 클라이언트 앱을 선택하십시오.

11. 오시는 길**앱 구성** > **새 구성 추가**.

12. 선택하기*WARP 클라이언트*앱 및 단계 6.에서 XML 파일을 업로드

13. 지금 이동**정책 대상**그리고 대상 entities와 정책을 준수합니다.

선택한 장치에 구성과 함께 앱을 푸시합니다.

## iOS 앱

1. Hexnode 콘솔에서 이동**앱 다운로드** > **앱 추가** > **스토어 앱**.

2. 제품정보*iOS 앱*앱 플랫폼으로.

3. 관련 기사[**모델 번호: Cloudflare 1개의 대리인**](https://apps.apple.com/us/app/cloudflare-one-agent/id6443476492)·**더 보기**앱.

4. 지원된 앱 구성으로 XML 파일을 설정합니다. 이 샘플 XML 코드를 사용하여 지원되는 인수를 식별합니다.

   ```xml
   <dict>
   <key>organization</key>
   <string>yourorganization</string>
   <key>auto_connect</key>
   <integer>1</integer>
   <key>switch_locked</key>
   <false />
   <key>service_mode</key>
   <string>warp</string>
   <key>support_url</key
   <string>https://support.example.com</string>
   </dict>
   ```

5. Hexnode 앱 구성 업로드:
   1. Hexnode 콘솔에서, 이동**앱 다운로드**탭.
   2. Cloudflare One Agent 앱을 찾아 이름을 선택하십시오.
   3. 설정 아이콘을 선택하고 선택**앱 구성**.
   4. 해당 필드에 XML 파일을 업로드합니다.
   5. 제품정보**제품 정보**.

6. Hexnode를 사용하여 대상 장치에 앱을 푸시합니다.
   1. Hexnode 콘솔에서 이동**회사연혁**새로운 정책 만들기.
   2. 정책에 대한 이름을 제공하고 가기**iOS 앱**.
   3. 오시는 길**Mandatory 앱** > **설정하기**.
   4. 제품정보**더 보기** > **앱 추가**, 필수 앱을 확인하고, 선택**이름 \***.
   5. 오시는 길**정책 대상**그리고 필요한 대상 기기와 정책을 준수합니다.

선택한 장치에 구성과 함께 앱을 푸시합니다.

## 다운로드

1. Hexnode 콘솔에서 이동**앱 다운로드** > **앱 추가** > **Google 앱 관리**.
2. 앱 검색[**모델 번호: Cloudflare 1개의 대리인**](https://play.google.com/store/apps/details?id=com.cloudflare.cloudflareoneagent).
3. 관리 된 Google Play 앱으로 앱을 Approve.
4. 오시는 길**회사연혁**새로운 정책 만들기.
5. 오시는 길**다운로드** > **앱 구성** > **새 구성 추가**.
6. 자주 묻는 질문**모델 번호: Cloudflare 1개의 대리인**앱 및 사용자 정의 구성 설정.
7. 오시는 길**정책 대상**그리고 필요한 대상 기기와 정책을 준수합니다.
8. 자주 묻는 질문

선택한 장치에 구성과 함께 앱을 푸시합니다.

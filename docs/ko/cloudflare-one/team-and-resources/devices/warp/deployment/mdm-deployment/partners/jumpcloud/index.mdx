## 윈도우

1. 로그인하기[JumpCloud 관리자 포털](https://console.jumpcloud.com).

2. 오시는 길**장치 관리** > **소프트웨어 관리**.

3. 선택하기**윈도우**탭, 다음 선&#xD0DD;**(+)**.

   ![JumpCloud Windows 탭에서 WARP 구성](~/assets/images/cloudflare-one/connections/jumpcloud.png)

4. 내 계정**소프트웨어 이름**필드는 독특한 표시 이름을 입력합니다.

5. 내 계정**패키지 ID**필드, 입력`warp`.

6. 제품정보**이 소프트웨어를 설치**.

7. (선택 사항) 선택**날짜까지 소프트웨어 패키지 유지**이 앱을 업데이트하려면 업데이트가 가능합니다.

8. (선택 사항) 선택**최종 사용자는 최대 1 주 동안 업데이트 지연**바쁜 시간 동안 업데이트를 피하기 위해.

9. 제품정보**제품 정보**.

10. 앱을 배포하려는 장치(s)를 선택하십시오.
    - **단일 장치**: 바로가기**제품정보**탭을 선택하고 대상 장치를 선택합니다.
    - **장치 그룹**: 바로가기**장치 그룹**탭을 선택하고 대상 장치 그룹을 선택합니다.

11. 제품정보**제품 정보**.

12. 제품정보**제품 정보**다시.

Cloudflare WARP가 앱을 선택하여 설치되었음을 검증하고보기**주요연혁**탭.

## 맥 OS

1. 로그인하기[JumpCloud 관리자 포털](https://console.jumpcloud.com).

2. 오시는 길**장치 관리** > **소프트웨어 관리**.

3. 선택하기**애플 아이폰**탭, 다음 선&#xD0DD;**(+)**.

   ![JumpCloud Apple 탭에서 WARP 구성](~/assets/images/cloudflare-one/connections/jumpcloud-mac.png)

4. 내 계정**소프트웨어 Description**필드는 독특한 표시 이름을 입력합니다.

5. 내 계정**소프트웨어 패키지 URL**, URL 위치에 입력`Cloudflare_WARP_<VERSION>.pkg`파일. 이미 설치 패키지가 없다면,[다운로드](/cloudflare-one/team-and-resources/devices/warp/download-warp/#macos).

6. 앱을 배포하려는 장치(s)를 선택하십시오.
   - **단일 장치**: 바로가기**제품정보**탭을 선택하고 대상 장치를 선택합니다. 모든 장치를 선택하려면 다음의 체크 박스를 선택하십시오.**제품정보**.
   - **장치 그룹**: 바로가기**장치 그룹**탭을 선택하고 대상 장치 그룹을 선택합니다. 모든 장치 그룹을 선택하려면 다음의 체크 박스를 선택하십시오.**제품정보**.

7. 제품정보**제품 정보**클라이언트를 설치하기.

Cloudflare WARP가 앱을 선택하여 설치되었음을 검증하고보기**주요연혁**탭.

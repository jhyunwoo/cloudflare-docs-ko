이 가이드는 Microsoft Intune를 사용하여 Cloudflare WARP 클라이언트를 배치하는 방법을 포함합니다.

## 윈도우

### WARP 클라이언트 배포

Intune을 사용하여 Windows에서 WARP를 배포하려면:

1. [다운로드`Cloudflare_WARP_<VERSION>.msi`설치](/cloudflare-one/team-and-resources/devices/warp/download-warp/#windows).

2. Microsoft Intune 계정에 로그인하십시오.

3. 오시는 길**앱 다운로드** > **모든 앱** > **더 보기**.

4. 내 계정**앱 유형**, 선택*Line-of-business 앱*드롭다운 메뉴에서. 제품정보**제품정보**.

5. 제품정보**앱 패키지 파일 선택**다운로드`Cloudflare_WARP_<VERSION>.msi`이전에 다운로드 한 설치자.

6. 제품정보**이름 \***.

7. 제품 정보**credentials에 로그를 사용하여이 스크립트를 실행**, 선택*이름 \**.

8. 제품 정보**Enforce 스크립트 서명 확인**, 선택*이름 \**.

9. 내 계정**이름 \***&#xD544;드, 패키지의 버전 번호를 입력하는 것이 좋습니다.

10. 내 계정**관련 기사**필드, 우리는 입력을 권장합니다`Cloudflare, Inc`.

11. 내 계정**명령줄 인수**필드는 유효한 설치 명령을 입력합니다. 예를 들면:

    ```txt
    /qn ORGANIZATION="your-team-name" SUPPORT_URL="http://support.example.com"
    ```

    더 알아보기[배포 매개 변수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/)각 인수에 대한 설명. 새를 밀어서 이 매개 변수를 변경할 수 있습니다.[MDM 파일](#update-mdm-parameters).

12. 제품정보**이름 \***.

13. Cloudflare WARP를 요구하는 사용자 또는 그룹을 추가하고 선택하십시오**이름 \***.

14. 구성을 검토하고 선택**이름 \***.

Intune는 이제 WARP 클라이언트를 배치하도록 구성되었습니다.

### MDM 매개 변수 업데이트

업데이트에 Intune을 사용할 수 있습니다.[MDM 모수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/)WARP 클라이언트를 위해. Windows에서이 매개 변수는 로컬 장치에 저장됩니다.`C:\ProgramData\Cloudflare\mdm.xml`.

새를 밀어`mdm.xml`Intune를 사용하여 파일:

1. Microsoft Intune 계정에 로그인하십시오.

2. 오시는 길**제품정보** > **스크립트 및 구제**.

3. 선택하기**플랫폼 스크립트**탭 및 선택**더 보기**.

4. 제품정보**Windows 10 이상**.

5. 스크립트의 이름을 입력 (예를 들어,`Deploy Cloudflare mdm.xml`).

6. 내 계정**PowerShell 스크립트**, 다음 업로드`.ps1`파일. 원하는 XML 콘텐츠를 수정해야 합니다.[이름 \*](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/).

   ```powershell title="mdm-template.ps1"
   # Define the path to the file
   $filePath = "C:\ProgramData\Cloudflare\mdm.xml"

   # Create the XML content as a string
   $xmlContent = @"
   <dict>
   	<key>multi_user</key>
   	<true/>
   	<key>pre_login</key>
   	<dict>
   		<key>organization</key>
   		<string>mycompany</string>
   		<key>auth_client_id</key>
   		<string>88bf3b6d86161464f6509f7219099e57.access</string>
   		<key>auth_client_secret</key>
   		<string>bdd31cbc4dec990953e39163fbbb194c93313ca9f0a6e420346af9d326b1d2a5</string>
   	</dict>
   	<key>configs</key>
   	<array>
   		<dict>
   			<key>organization</key>
   			<string>mycompany</string>
   			<key>display_name</key>
   			<string>Production environment</string>
   		</dict>
   		<dict>
   			<key>organization</key>
   			<string>test-org</string>
   			<key>display_name</key>
   			<string>Test environment</string>
   		</dict>
   	</array>
   </dict>
   "@

   # Ensure the directory exists
   $directory = Split-Path $filePath -parent
   if (-not (Test-Path $directory)) {
   	New-Item -ItemType Directory -Path $directory | Out-Null
   }

   # Write the XML content to the file
   try {
   	$xmlContent | Out-File -Encoding UTF8 -FilePath $filePath
   	Write-Host "mdm.xml file created successfully at: $filePath"
   }
   catch {
   	Write-Error "Failed to create mdm.xml file: $_"
   }
   ```

7. 내 계정**회사연혁**, 새로운 것을 받는 Windows 장치를 선정하십시오`mdm.xml`파일.

8. 스크립트를 배포하려면, select**더 보기**.

Intune는 이제 대상 장치에 Powershell 스크립트를 실행하고 이전을 덮어`mdm.xml`파일. 새 소식`mdm.xml`파일은 생성됩니다. WARP는 새로운 구성을 사용하여 즉시 시작합니다.<Render file="warp/connectivity-status-check" product="cloudflare-one" />

Intune의 Win32 앱 도구를 사용하여 Powershell 스크립트를 실행하려면, 참조[Intune 문서](https://learn.microsoft.com/en-us/mem/intune/apps/apps-win32-app-management).

### 3. 업로드`MobileConfig`제품 설명

1. 텍스트 편집기를 열고 다음에서 붙여 넣기`.mobileconfig`템플릿:

   ```xml
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
   <plist version="1.0">
   		<dict>
   				<key>PayloadDisplayName</key>
   				<string>Cloudflare WARP</string>
   				<key>PayloadIdentifier</key>
   				<string>cloudflare_warp</string>
   				<key>PayloadOrganization</key>
   				<string>Cloudflare, Ltd.</string>
   				<key>PayloadRemovalDisallowed</key>
   				<false/>
   				<key>PayloadType</key>
   				<string>Configuration</string>
   				<key>PayloadScope</key>
   				<string>System</string>
   				<key>PayloadUUID</key>
   				<string>YOUR_PAYLOAD_UUID_HERE</string>
   				<key>PayloadVersion</key>
   				<integer>1</integer>
   				<key>PayloadContent</key>
   				<array>
   						<dict>
   								<key>organization</key>
   								<string>YOUR_TEAM_NAME_HERE</string>
   								<key>auto_connect</key>
   								<integer>120</integer>
   								<key>onboarding</key>
   								<false/>
   								<key>PayloadDisplayName</key>
   								<string>Warp Configuration</string>
   								<key>PayloadIdentifier</key>
   								<string>com.cloudflare.warp.YOUR_PAYLOAD_UUID_HERE</string>
   								<key>PayloadOrganization</key>
   								<string>Cloudflare Ltd.</string>
   								<key>PayloadType</key>
   								<string>com.cloudflare.warp</string>
   								<key>PayloadUUID</key>
   								<string>YOUR_PAYLOAD_UUID_HERE</string>

3. 조직의 문자열을 업데이트 (`YOUR_TEAM_NAME_HERE`) 당신의[팀 이름](/cloudflare-one/faq/getting-started-faq/#what-is-a-team-domainteam-name).

   	<dict>
   			<key>organization</key>
   			<string>YOUR_TEAM_NAME_HERE</string>
   			// add desired deployment parameters here
   ```

   :::tip\[최고의 연습]
   기본적으로 템플릿을 배포함으로써 최소 양식. 이것은 사용자 정의 매개 변수를 추가하기 전에 성공적인 배포를 확인합니다.
   주요 특징

5. 내 계정[Microsoft Intune 관리자 센터](https://intune.microsoft.com), 이동**제품정보** > **맥 OS**.

6. 이름 \***장치 관리**, 선택**제품 설명**.

7. 제품정보**이름 \*** > **새로운 정책**.

8. 제품 정보**회사 소개**, 선택*한국어*> 선택**제품 정보**으로**템플릿 이름**> 선택**이름 \***.

9. 내 계정**기본 정보**, 필요한 필드를 입력 > 선택**이름 \***.

10. 내 계정**사용자 정의 구성 프로필 이름**, 이름을 입력합니다.

11. 제품 정보**Deployment 채널**, 선택**장치 채널**.

12. 이름 \***Configuration Profile 파일**, 업로드`.mobileconfig`텍스트 편집기에서 만든 파일 1 단계 > 선택**이름 \***.

13. 내 계정**회사연혁**, 옵션을 선택 (예를 들면,**모든 장치 추가**또는**모든 사용자**) 귀하의 범위에 유효합니다. 모든 단계에 대한 동일한 범위가 될 것입니다.

14. 구성을 검토하고 정책을 작성합니다.

이 단계를 완료하면 팀 설정으로 WARP를 사전 설정하여 설치시 자동으로 연결됩니다.

### 4. WARP 클라이언트 업로드`.pkg`

:::tip\[최고의 연습]
1단계, 2단계, 3단계 이후 최소 1시간 이상 완료된 후 고객은 기기 구성을 확인하고 업데이트할 수 있는 충분한 시간을 가지고 있습니다.
주요 특징

1. 내 계정[모델 번호: Cloudflare 한국어](https://one.dash.cloudflare.com/), [WARP 클라이언트 다운로드](/cloudflare-one/team-and-resources/devices/warp/download-warp/#macos)내 계정`.pkg`파일 형식.

   :::note\[새로운 릴리스를 사용할 때 WARP를 업데이트하기 위해이 단계를 다시 입력]
   때마다 WARP는 새로운 버전을 풀어 놓고, 당신은 이 과정을 반복하고 새로운 것을 얻어야 합니다`.pkg`새로운 WARP 버전을 위한 파일.
   주요 특징

2. 로그인하기[Microsoft Intune 관리자 센터](https://intune.microsoft.com)·**앱 다운로드** > **맥 OS**.

3. 제품정보**이름 \***.

4. 제품 정보**앱 유형**, 선택*macOS 앱(PKG)*.

5. 내 계정**앱 정보**, 선택`.pkg`파일 다운로드 및 입력 필수 세부 사항. 이름 \*`Cloudflare`게시자로서.

#### Cloudflare 구성 One Agent 앱 정책

Cloudflare를 구성하려면 One Agent 앱 정책:

1. Microsoft Intune 관리자 센터에서는**앱 다운로드** > **App 구성 정책**> 선택**더 보기** > **관리 장치**.

2. 구성 정책의 기본 세부 사항을 작성:
   1. 이름 \***이름 \***&#xC758; 프로파일. (예를 들면: Cloudflare One Agent - 구성 정책)
   2. 플랫폼 선택**Android 기업**.
   3. 자주 묻는 질문**회사 소개**. (예를 들면: 개인화한 일 단면도 전용)

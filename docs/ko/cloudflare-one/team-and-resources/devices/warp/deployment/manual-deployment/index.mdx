사용자를 수동으로 다운로드하고 WARP 클라이언트를 구성하려면 조직의 Cloudflare Zero Trust 인스턴스에 클라이언트를 연결할 필요가 있습니다.

## 자주 묻는 질문

- [장치 등록 권한 설정](/cloudflare-one/team-and-resources/devices/warp/deployment/device-enrollment/)사용자가 연결할 수 있는 지정

## Windows, macOS 및 Linux

### GUI 사용

장치는 이제 조직의 Zero Trust 정책에 의해 보호됩니다.

### CLI를 사용하여

터미널을 사용하여 장치를 등록하려면:

1. [다운로드](https://pkg.cloudflareclient.com/)그리고 WARP 포장을 설치하십시오.

2. 터미널 창을 엽니다. 현재 사용자로 터미널에 로그인하고 루트가 아닌지 확인합니다.

3. 조직의 Cloudflare Zero Trust로 변환<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>:

   ```sh
   warp-cli registration new <your-team-name>
   ```

4. 브라우저 창에서, 귀하의 조직에 필요한 인증 단계를 완료합니다.

   일단 인증되면 성공 페이지와 대화 상자를 볼 수 있습니다.

5. 제품정보**링크 열기**.

6. 터미널에 등록을 확인:

   ```sh
   warp-cli registration show
   ```

<Details header="문제 해결 누락된 등록">
  등록 절차는 완료하는 데 몇 분 걸릴 수 있습니다. 등록이 계속 누락되면 브라우저에서 WARP 클라이언트에 인증 토큰을 복사합니다.

  1. 성공 페이지, 오른쪽 클릭 및 선택**사이트 맵**.
  2. 토큰을 포함하는 HTML 메타데이터 태그를 찾습니다. 예를 들어,`<meta http-equiv="refresh" content"=0;url=com.cloudflare.warp://<your-team-name>.cloudflareaccess.com/auth?token=yeooilknmasdlfnlnsadfojDSFJndf_kjnasdf..." />`
  3. URL 필드를 복사:`com.cloudflare.warp://<your-team-name>.cloudflareaccess.com/auth?token=<your-token>`
  4. 터미널에서 이전 단계에서 URL을 사용하여 다음 명령을 실행합니다.

     ```sh
     warp-cli registration token "com.cloudflare.warp://<your-team-name>.cloudflareaccess.com/auth?token=<your-token>"
     ```

  당신이 얻을 경우`401`오류, 토큰이 만료되었습니다. 웹 페이지를 새로 고침하여 새로운 토큰을 페이지 소스에서 빠르게 잡아라.
</Details>

7. WARP를 구성하지 않았다면[자동 연결](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#auto-connect), 수동으로 WARP에 회전:

   ```sh
   warp-cli connect
   ```

장치는 이제 조직의 Zero Trust 정책에 의해 보호됩니다. 모든 사용 가능한 명령에 대한 자세한 내용은 실행`warp-cli --help`.

Administrators는 사용자 정의 로그인 URL을 제공하여 조직에서 자동으로 작성할 수 있습니다.<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>장치 등록 중. URL을 사용하여 팀 이름의 수동 입력으로 제공되는 오류의 잠재력을 감소시킵니다.

WARP 클라이언트는 직접 링크 또는 QR 코드와 같은 URL 핸들러를 통해 액세스 URL을 지원합니다. 직접 링크는 현재 Safari 및 Firefox에서만 지원됩니다. 기본 브라우저가 Chrome(또는 다른 지원 브라우저)인 경우, QR 코드에서 링크를 삽입하는 것이 좋습니다.

#### 로그인 URL 생성

장치 등록의 URL을 생성하려면:

1. 다음 링크 복사, 교체`<your-team-name>`당신의 Zero Trust로<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>:

   ```txt
   cf1app://oneapp.cloudflare.com/team?name=<your-team-name>
   ```

2. (선택 사항) QR 코드에 링크를 삽입하는 QR 코드 생성기를 사용합니다.

3. 링크 또는 QR 코드를 사용자에 분산.

#### 로그인 URL 사용

로그인 URL을 사용하여 장치를 등록하려면:

1. [다운로드](/cloudflare-one/team-and-resources/devices/warp/download-warp/)Cloudflare One Agent 앱을 설치합니다.

2. 오시는 길[로그인 URL](#generate-a-login-url)계정 관리자에 의해 제공. QR 코드를 사용하려면 기기에서 QR 스캐너 앱을 열고 QR 코드를 스캔합니다.

   Cloudflare One Agent 앱을 열고 온보드 흐름을 시작합니다.

   :::참조
   이 URL과 관련된 계정에 이미 등록 된 경우 Cloudflare 1개의 대리인은 onboarding를 우회하고 보여줄 것입니다**연결하기**스위치.
   주요 특징

3. 내장 흐름을 완료하려면:

   a. 개인 정보 보호 정책 및 선택**이름 \***.

   b. 에**팀 이름 입력**스크린은, pre-populated 것을 확인합니다<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>당신의 조직에 일치.

   :::주최\[`Already Authenticated`오류]
   만약에 Cloudflare 하나의 에이전트는 다른 팀 이름을 사용하여 로그인, 당신은 먼저 그 계정에서 로그 아웃해야합니다. 오시는 길**계정 설정** > **계좌정보**로그인하고 QR 코드 또는 로그인 링크를 다시 시도하십시오.
   주요 특징

   c. 귀하의 조직에 따라 인증 단계 완료.

   ₢ 킹 인증 후, 선택**VPN 프로파일 설치**.

   이름 \* 내 계정**연결 요청**팝업 창, 선택**이름 \***.

4. 사용 안함[자동 연결](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#auto-connect), 수동으로 스위치에 켜기**연결하기**.

장치는 이제 조직의 Zero Trust 정책에 의해 보호됩니다.

## 가상 머신

기본적으로 가상 머신 (VMs)는 호스트의 WARP 클라이언트 설정에 따라 다릅니다. VM에서 WARP의 별도 인스턴스를 배포하려면 VM을 구성해야 합니다.

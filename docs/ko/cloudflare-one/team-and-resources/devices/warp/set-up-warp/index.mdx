이 문서는 조직에서 WARP를 처음 설정할 때 따라가는 단계별 안내입니다. 클라이언트를 다운로드하고 Cloudflare 엣지로 첫 번째 쿼리를 보내기까지의 전체 흐름을 설명합니다.

## 트래픽 및 DNS 모드 (과태)

이 모드는 완벽한 제품군을 가능하게 합니다.[장치 보안 기능](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes).

### 1. Cloudflare Zero Trust 계정을 만드십시오.

더 보기[Cloudflare Zero Trust 가정](https://one.dash.cloudflare.com/)장치 연결 데이터를 확인하고 보안 웹 게이트웨이 및 Zero Trust 정책을 만들 수 있습니다.

당신이 완료 한대로[Cloudflare Zero Trust 온보딩](/cloudflare-one/setup/), 당신은 만들 것을 물어<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>당신의 조직에. 당신은 당신의 장치에 WARP 클라이언트를 배치할 때 팀 이름을 필요로 할 것입니다; 그것은 당신의 조직 Cloudflare Zero Trust 인스턴스에 연결하는 당신의 사용자를 허용할 것입니다.

### 2. 로그인 방법을 설정합니다.

설정하기[1회 PIN](/cloudflare-one/integrations/identity-providers/one-time-pin/)또는 연결[제3자 ID 공급자](/cloudflare-one/integrations/identity-providers/)Zero Trust에서. 이 로그인 방법은 사용자가 Cloudflare Zero Trust 설정에 새 장치를 추가 할 때 사용할 것입니다.

### 3. 다음, 장치 등록 권한을 정의합니다.

이름 \*[장치 등록 규칙](/cloudflare-one/team-and-resources/devices/warp/deployment/device-enrollment/)조직의 Cloudflare Zero Trust 설정에 장치를 연결할 수 있어야합니다. 여러분의 규칙을 작성하면 로그인 방법을 선택해야 합니다.

### 4. 당신의 장치에 Cloudflare 뿌리 증명서 설치하십시오.

HTTP 트래픽 검사를 포함한 고급 보안 기능은 사용자가 설치 및 신뢰를 요구합니다.[Cloudflare 뿌리 증명서](/cloudflare-one/team-and-resources/devices/user-side-certificates/)기계 또는 장치에. 모든 장치에서 인증서를 수동으로 설치하면이 단계는 HTTP 필터링에 따라야합니다.

### 5. WARP 클라이언트를 장치에 다운로드하고 배치하십시오.

중 하나를 선택하십시오.[다른 방법](/cloudflare-one/team-and-resources/devices/warp/deployment/)WARP 클라이언트를 배포하려면 조직에 가장 적합한 작업에 따라.

### 6. 귀하의 장치에서 조직의 Cloudflare Zero Trust 인스턴스에 로그인하십시오.

WARP 클라이언트가 장치에 설치되면,[Zero Trust 조직에 로그인](/cloudflare-one/team-and-resources/devices/warp/deployment/manual-deployment/). 이미 Cloudflare에 있는 ID 공급자를 설치한 경우에 액세스, 사용자는이 방법을 사용하여 인증 할 것이다. 정체성 공급자를 설정하지 않은 경우 사용자는 정체성 공급자로 인증 할 수 있습니다.[1 시간 핀](/cloudflare-one/integrations/identity-providers/one-time-pin/)기본적으로 활성화됩니다.

다음, 빌드[보안 웹 게이트웨이 정책](/cloudflare-one/traffic-policies/)장치에서 DNS, HTTP 및 네트워크 트래픽을 필터링합니다.

## DNS만 모드

이 모드는 회사 장치에서 아웃바운드 트래픽에 DNS 필터링을 적용하려는 조직에 가장 적합합니다. HTTP 정책, 정체성 정책, 장치 자세 검사, 또는 브라우저 고립과 같은 고급 HTTP 필터링 기능을 사용할 수 없습니다.

### 1. Cloudflare Zero Trust 계정을 만드십시오.

Zero Trust는 장치 연결 자료를 확인하고, 또한 당신의 조직을 위한 안전한 웹 출입구 및 Zero Trust 정책을 창조하기 위하여 당신의 go-to 장소일 것입니다.

당신이 완료 한대로[Cloudflare Zero Trust 온보딩](/cloudflare-one/setup/), 당신은 만들 것을 물어<GlossaryTooltip term="team name">팀 이름</GlossaryTooltip>당신의 조직에. 당신은 당신의 장치에 WARP 클라이언트를 배치할 때 팀 이름을 필요로 할 것입니다; 그것은 당신의 조직 Cloudflare Zero Trust 인스턴스에 연결하는 당신의 사용자를 허용할 것입니다.

### 2. 로그인 방법을 설정합니다.

설정하기[1회 PIN](/cloudflare-one/integrations/identity-providers/one-time-pin/)또는 연결[제3자 ID 공급자](/cloudflare-one/integrations/identity-providers/)Zero Trust에서. 이 로그인 방법은 사용자가 Cloudflare Zero Trust 설정에 새 장치를 추가 할 때 사용할 것입니다.

### 3. 다음, 장치 등록 권한을 정의합니다.

이름 \*[장치 등록 규칙](/cloudflare-one/team-and-resources/devices/warp/deployment/device-enrollment/)조직의 Cloudflare Zero Trust 설정에 장치를 연결할 수 있어야합니다. 여러분의 규칙을 작성하면 로그인 방법을 선택해야 합니다.

### 4. (선택 사항) 게이트웨이에 DNS 위치를 추가합니다.

WARP 클라이언트는 Zero Trust 조직에 등록될 때 기본 DNS 엔드포인트에 DoH 쿼리를 지시할 것입니다. 이 쿼리를 별도의 DNS 엔드포인트로 직접 입력해야 하는 경우,[DNS 위치 추가](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/)게이트웨이 Gateway가 할당됩니다.<GlossaryTooltip term="DoH subdomain">DoH 하위 도메인</GlossaryTooltip>해당 위치로 WARP 클라이언트를 기기에 배포할 때 추가할 수 있습니다.

### 5. WARP 클라이언트를 장치에 다운로드하고 배치하십시오.

중 하나를 선택하십시오.[다른 방법](/cloudflare-one/team-and-resources/devices/warp/deployment/)WARP 클라이언트를 배포하려면 조직에 가장 적합한 작업에 따라.

다음, 생성[DNS 정책](/cloudflare-one/traffic-policies/dns-policies/)장치에서 DNS 쿼리를 제어하는 것은 해결됩니다.

- 사용자가 WARP를 끄는 동시에 호환 가능한 공용 Wi-Fi 또는 연결된 고객 사이트에서 방화벽과 같은 임시 네트워크 문제의 주위에 작업 할 수 있습니다.

#### override 코드를 검색

사용자를 위한 일회성 코드를 검색하려면:

1. 이름 \***admin override 코드 허용**.
2. 오시는 길**팀 & 자원** > **제품정보**.
3. 제품정보**자주 묻는 질문**연결된 장치.
4. 기타 제품**사용자 정보**사용자의 이름을 선택합니다.
5. 7 자리 복사**Override 코드**측 패널에서 보이는.
6. 이 코드를 사용하여 사용자가 장치에 입력합니다.

사용자는 코드를 활성화 할 수있는 무제한의 시간이 있습니다.

#### 오버라이드 코드를 입력

WARP의 기본 IP 주소를 삭제[가상 네트워크 인터페이스](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/warp-architecture/#ip-traffic)각각의 장치에는 고유한 로컬 인터페이스 IP가 있습니다.

이 설정은 주로 prerequisite로 사용됩니다.[WARP 연결관](/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/warp-connector/)·[이름 \*](#device-tunnel-protocol). 당신은 또한 당신의 네트워크에 다른 국부적으로 서비스로 기본 IP 충돌 때 그것을 사용할 수 있습니다.

**가치:**

- `Disabled`: (기본) 로컬 인터페이스 IP 설정`172.16.0.2`모든 장치에서. 이 구성은 기기에 의해만 존중됩니다.[와이어 가드](#device-tunnel-protocol)기기에 영향을 미치지 않습니다.[이름 \*](#device-tunnel-protocol).

- `Enabled`: 각 장치에 로컬 인터페이스 IP 설정<GlossaryTooltip term="WARP CGNAT IP">사이트맵</GlossaryTooltip>또는 에[주문 장치 IP](/cloudflare-one/team-and-resources/devices/warp/configure-warp/device-ips/).

WARP 장치에 할당된 IP는 당신의 Zero Trust 조직 또는 다른 등록에 스위치에서 장치 unregisters까지 영구적입니다. 연결 및 재연결은 IP 주소 할당을 변경하지 않습니다.

**제품정보**:

- **와이어 가드**: 설치[와이어 가드](https://www.wireguard.com/)Cloudflare에 연결. WARP 클라이언트는 비 FIPs 고분고분한 cipher 스위트를 사용하여 트래픽을 암호화합니다,`TLS_CHACHA20_POLY1305_SHA256`. #### 제한 사항

- WARP는 현지 네트워크를 제외한다[RFC 1918년](https://datatracker.ietf.org/doc/html/rfc1918)주소 공간. CGNAT와 같은 다른 IP 주소는 지원되지 않습니다.
- 최대 제외된 subnet 크기는`/24`.
- 장치에는 특정한 지역 IP 범위를 가진 다수 네트워크 공용영역이 있는 경우에, WARP는 그 네트워크의 하나만 제외할 것입니다. 특정 로컬 네트워크에 액세스하려면 다른 인터페이스와 분리 / 연결 WARP를 비활성화하십시오.

NetBIOS over TCP/IP (NetBT)는 Windows의 이름 해결책 그리고 다른 특징을 위해 사용되는 유산 의정서입니다. NetBT는 몇 년 동안 deprecated되었지만 Windows는 제거하지 않았습니다. Cloudflare WARP는 보안상의 이유로 기본적으로 터널 인터페이스에서 NetBT를 비활성화하고 현대 모범 사례와 일치합니다. 이 설정은 기본 동작을 무시하고 WARP 터널을 통해 NetBT를 활성화 할 수 있습니다.

#### NetBT를 사용할 때

당신은 켜야한다**TCPIP에 NetBIOS**장치가 NetBT 이상 내부 리소스에 액세스 할 필요가 있다면. 예제 시나리오는 다음과 같습니다 :

- **Legacy 이름 해결책**: Single-label 이름을 해결하기 위해 NetBIOS에서 의존합니다.`\\SERVER01`), 대신 완전히 자격이 된 도메인 이름을 위한 단 하나 상표 이름 또는 표준 DNS를 위한 mDNS 같이 현대 대안의 (와 같은`\\server01.corp.internal`).
- **사이트맵**: 현대 SMB (v2/v3)을 지원하지 않는 매우 오래된 파일 공유 또는 프린터에 액세스하고 발견을위한 NetBT가 필요합니다.
- **Legacy 신청**: Node-to-node 통신을 위해 NetBIOS를 하드코드로 하는 전문 내부 소프트웨어를 사용합니다.

그렇지 않으면, 권고는 항상 비활성화됩니다.**TCPIP에 NetBIOS**. 당신은 다른 조정을 위해 선택할 수 있습니다[원격 장치](/cloudflare-one/team-and-resources/devices/warp/configure-warp/device-profiles/)뚱 베어[on-prem 장치](/cloudflare-one/team-and-resources/devices/warp/configure-warp/managed-networks/#4-configure-device-profile).

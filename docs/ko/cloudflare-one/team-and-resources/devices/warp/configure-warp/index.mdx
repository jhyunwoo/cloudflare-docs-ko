WARP 클라이언트 설정을 구성하여 기존 인프라와 함께 작동하며 리소스에 대한 차별화된 액세스를 제공합니다.

:::노트\[Managed 배포]

배포하는 경우[WARP 장치 관리 소프트웨어](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/), 우리는 단지 공급을 추천합니다`organization`내 계정[배포 매개 변수](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/)대시보드를 통해 다른 모든 설정을 관리합니다. 대시보드에 구성하는 모든 설정은 관리 소프트웨어에 의해 배포 된 로컬 정책에 의해 overridden 될 것입니다. 대시보드 설정은 의도대로 적용되며 관리 된 배포 설정에서 해당 매개 변수를 제거합니다.

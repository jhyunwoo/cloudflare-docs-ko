Cloudflare Gateway로 전송되는 트래픽의 유형을 제어하기 위해 다른 모드에서 WARP 클라이언트를 배포 할 수 있습니다. WARP 모드는 Zero Trust 기능이 장치에서 사용할 수 있는지 결정합니다.

## 트래픽 및 DNS 모드 (과태)

WARP 클라이언트는 모든 항구와 의정서를 위한 장치 소통량을, 전달합니다 DNS 해결책을 전달합니다[클라이언트 DNS 해결자](/cloudflare-one/networks/resolvers-and-proxies/dns/locations/dns-resolver-ips/).

고급 방화벽 / 프록시 기능 및 장치 자세 규칙을 시행 할 때 사용.

| DNS 필터링 | 네트워크 필터링 | HTTP 필터링 | 기능 활성화                                                                 |
| ------- | -------- | -------- | ---------------------------------------------------------------------- |
| 이름 \*   | 이름 \*    | 이름 \*    | DNS 정책, 네트워크 정책, HTTP 정책, 브라우저 고립, 정체성 정책, 장치 자세 검사, AV 검사 및 데이터 손실 방지 |

## DNS만 모드

WARP 클라이언트는 Cloudflare 계정 결산기에 DNS 해결책을 전달합니다, 그러나 장치 소통량을 노선하지 않습니다. 네트워크 및 HTTP 트래픽은 장치의 기본 메커니즘에 의해 처리됩니다.

회사 장치에서 아웃바운드 트래픽에 DNS 필터링을 적용 할 때만 사용하십시오.

| DNS 필터링 | 네트워크 필터링 | HTTP 필터링 | 기능 활성화 |
| ------- | -------- | -------- | ------ |
| 이름 \*   | 이름 \*    | 이름 \*    | DNS 정책 |

## 교통 모드

WARP 클라이언트는 모든 항구와 의정서를 위한 장치 소통량을 노선합니다. DNS 해결책은 장치 운영 체계에 의해 관리됩니다.

프록시 네트워크 및 HTTP 트래픽을 원할 때 사용하지만 기존 DNS 필터링 소프트웨어를 유지하십시오.

| DNS 필터링 | 네트워크 필터링 | HTTP 필터링 | 기능 활성화                                                          |
| ------- | -------- | -------- | --------------------------------------------------------------- |
| 이름 \*   | 이름 \*    | 이름 \*    | 네트워크 정책, HTTP 정책, 브라우저 고립, 정체성 정책, 장치 자세 검사, AV 스캐닝 및 데이터 손실 방지 |

:::참조

- 트래픽 유일한 형태는 DNS 해결책을 위한 WARP에 의존하는 모든 특징을, 포함합니다[도메인 기반 분할 터널링](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/split-tunnels/#domain-based-split-tunnels)·[지역 도메인 Fallback](/cloudflare-one/team-and-resources/devices/warp/configure-warp/route-traffic/local-domains/).
- Windows, Linux 및 macOS에서만 사용할 수 있습니다.
- 트래픽 만 모드에는 알려진 제한이 있습니다.[IPv6 주소로 DNS 서버](/cloudflare-one/team-and-resources/devices/warp/troubleshooting/known-limitations/#ipv6-dns-resolution-in-traffic-only-mode).

:::

## 로컬 프록시 모드

WARP 클라이언트는 명시적으로 간접 로컬 HTTP 트래픽을 전달합니다.

특정 응용 프로그램에 지시된 트래픽을 필터링 할 때 사용.

| DNS 필터링 | 네트워크 필터링 | HTTP 필터링 | 기능 활성화                                                                 |
| ------- | -------- | -------- | ---------------------------------------------------------------------- |
| 이름 \*   | 이름 \*    | 이름 \*    | HTTP 정책, 브라우저 고립, ID 기반 정책, AV 스캐닝 및 로컬 호스트 프록시를 통해 전송되는 트래픽 데이터 손실 방지 |

### 로컬 프록시 모드 설정

Cloudflare를 만들 때 하나의 계정, 기본값[회사소개](/cloudflare-one/team-and-resources/devices/warp/configure-warp/device-profiles/)트래픽 및 DNS 모드에서 생성됩니다. 로컬 프록시 모드를 설정하려면 기본 장치 프로파일을 편집하거나 새로운 장치 프로파일을 만들고 로컬 프록시 모드로 WARP 서비스 모드를 설정해야합니다.

기본 프로파일은 특정 프로파일에 할당되지 않은 모든 장치에 사용됩니다. 특정 장치에 로컬 프록시 모드를 적용하려면 새로운 장치 프로파일을 만들고 그 장치에 할당해야합니다.

로컬 프록시 모드를 설정하려면:

1. 내 계정[모델 번호: Cloudflare 한국어](https://one.dash.cloudflare.com/), 이동**팀 & 자원** > **회사소개**.
2. 디폴트 프로파일을 편집하거나 새로운 장치 프로파일을 만들 것인지 결정합니다.
3. 구성하려는 장치 프로파일 선택 >**제품정보**(만 볼 경&#xC6B0;**- 연혁**, 당신은 프로필을 수정해야 권한이 부족).
4. 감사합니다.**장치 터널 프로토콜**설정`MASQUE`.
5. 이름 \***서비스 모드**, 선택**로컬 프록시 모드**.
6. 제품정보**회사 소개**.

:::노트\[MDM 배포]

MDM을 통해 WARP를 배치하는 경우 구성 파일은 WARP 서비스 모드를 포함하여 모든 장치 프로파일 설정을 삭제합니다. 더 알아보기[`service_mode`이름 \*](/cloudflare-one/team-and-resources/devices/warp/deployment/mdm-deployment/parameters/#service_mode)더 많은 정보.

:::

로컬 프록시 모드를 사용하는 기기의 경우 WARP 클라이언트는 주소로 구성된 포트를 듣습니다.`127.0.0.1` (`localhost`). Cloudflare 용도`40000`로컬 프록시 모드에서 WARP의 기본 포트로, 사용 가능한 포트에 이것을 수정할 수 있습니다. 이 프록시를 사용하려면 개별 애플리케이션 또는 시스템 프록시 설정을 지정해야 합니다.

일단 구성, 트래픽이 이러한 응용 프로그램에서 안전하게 터널을 통해 WARP.

더 복잡한 라우팅 결정 (예 : 인터넷 또는 기타 프록시에 직접 트래픽 라우팅)을 만들려면 사용할 수 있습니다.[PAC 파일](/learning-paths/secure-internet-traffic/configure-device-agent/pac-files/).

### 제한 사항

- Local proxy 모드는 SOCKS5/HTTP 프록시 통신을 지원하는 애플리케이션/운영 시스템에서만 사용할 수 있습니다.
- MASQUE를 요구합니다[장치 갱도 의정서](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#device-tunnel-protocol). Wireguard는 지원되지 않습니다.
- Windows, Linux 및 macOS에서만 사용할 수 있습니다.
- 로컬 프록시 모드는 요청에 대한 10 초의 시간 제한이 있습니다. 요청이 10 초 제한 이상되면 Cloudflare는 연결이 떨어지게됩니다.

## Posture 전용 모드

WARP 클라이언트는 안전 정책에서 참고 자료d일 수 있는 장치 건강과 자세 자료를 제공하기 위하여 비동기 정보를 제공합니다. 클라이언트는 장치 여정 또는 앞으로 DNS 해결책을 통제하지 않습니다.

실행할 때만 사용[WARP 클라이언트 장치 자세 검사](/cloudflare-one/reusable-components/posture-checks/warp-client-checks/)계정의 영역. Posture 만 모드를 설정하려면, 참조[회사 소개](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-modes/device-information-only/).

| DNS 필터링 | 네트워크 필터링 | HTTP 필터링 | 기능 활성화                                                     |
| ------- | -------- | -------- | ---------------------------------------------------------- |
| 이름 \*   | 이름 \*    | 이름 \*    | 장치 자세 규칙[오시는 길](/cloudflare-one/access-controls/policies/) |

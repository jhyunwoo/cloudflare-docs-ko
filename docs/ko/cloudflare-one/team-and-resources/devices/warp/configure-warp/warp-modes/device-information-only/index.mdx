Posture 만 모드를 사용하면 사용자가 연결 할 때 장치 자세 규칙을 시행 할 수 있습니다.[셀프 호스팅 액세스 응용](/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/). 이 모드는 귀하의 계정에서 생성 된 클라이언트 인증서에 의존하여 액세스 응용 프로그램과 장치 간의 신뢰를 구축합니다.

## 1. 계정 설정 켜기

API를 사용하여 클라이언트 인증서 제공[당신의 지역](/fundamentals/account/find-account-and-zone-ids/):

<APIRequest
  path="/zones/{zone_id}/devices/policy/certificates"
  method="PATCH"
  json={{
  	enabled: true,
  }}
/>

## 2. WARP 클라이언트 형성

1. 내 계정[모델 번호: Cloudflare 한국어](https://one.dash.cloudflare.com), 이동**팀 & 자원** > **제품정보** > **회사소개** > **일반 프로필**.

2. 선택하기[회사소개](/cloudflare-one/team-and-resources/devices/warp/configure-warp/device-profiles/)선택하기**제품정보**.

3. 제품 정보**서비스 모드**, 선택**Posture 전용 모드**.

4. 제품정보**회사 소개**.

5. [당신의 장치](/cloudflare-one/team-and-resources/devices/warp/deployment/manual-deployment/)Zero Trust 조직으로.

   Posture 만 모드에서 등록하면 WARP 클라이언트가 자동으로 클라이언트 인증서를 생성하고 장치에 인증서를 설치합니다. 이 증명서는 나가는 교통의 근원을 확인하는 것이 필요합니다.

## 3. (선택) 클라이언트 인증서를 검증

1. 기기에 설치된 클라이언트 인증서를 보려면:

       3. 오시는 길**이름 \*** > **인증서**.
     </TabItem>

     <TabItem label="맥 OS">
       1. 기타**키 체인 액세스**.

     </TabItem>

     <TabItem label="iOS 앱">

     <TabItem label="다운로드">

2. Cloudflare 계정에 클라이언트 인증서를 확인하려면:

   1. 내 계정[Cloudflare 대시보드](https://dash.cloudflare.com/), 당신은 클라이언트 인증서를 활성화하는 지역을 선택하십시오.
   2. 오시는 길**사이트맵** > **고객 인증서**.

   인증서 이름은 WARP 등록입니다.**장치 ID**.

## 4. 클라이언트 증명서를 강화하십시오

유효한 클라이언트 인증서가 없는 장치에서 트래픽을 차단하려면:

1. 내 계정[Cloudflare 대시보드](https://dash.cloudflare.com/), 이동**사이트맵** > **고객 인증서**.
2. 이름 \***이름 \***, 선택**제품정보**액세스 응용 프로그램의 호스트 이름 (예를 들어,`app.mycompany.com`). mTLS 인증이 가능합니다.
3. 제품정보**mTLS 규칙 만들기**.
4. WAF 사용자 정의 규칙을 작성하여 유효한 클라이언트 인증서에 대한 모든 요청을 확인합니다.
   | 제품정보   | 회사연혁  | 제품정보                | 로그인   | - 연혁 |
   | ------ | ----- | ------------------- | ----- | ---- |
   | 고객 인증서 | 이름 \* | 이름 \*               | 이름 \* | 제품정보 |
   | 이름 \*  | 이름 \* | `app.mycompany.com` |       |      |
5. 제품정보**계정 만들기**.

Posture 만 모드는 이제 장치에서 활성화됩니다. 장치 자세를 enforcing 시작하려면, 설정[WARP 클라이언트 체크](/cloudflare-one/reusable-components/posture-checks/warp-client-checks/)그리고 추가*이름 \**&#xC7A5;치 자세 규칙 당신의[오시는 길](/cloudflare-one/access-controls/policies/). 장치가 처음으로 액세스 응용 프로그램에 연결하면 브라우저는 WARP에 의해 설치된 클라이언트 인증서를 사용하도록 요청됩니다.

## WARP 세션 구성<Badge text="Beta" variant="caution" size="small" />

WARP 세션을 사용하여 액세스 응용 프로그램에 로그인 할 수 있습니다. WARP 인증은 허용 또는 블록 정책에 의해 보호되는 액세스 응용 프로그램에만 지원됩니다.

접근 신청을 위한 WARP 회의를 구성하기 위하여:

1. 내 계정[모델 번호: Cloudflare 한국어](https://one.dash.cloudflare.com/), 이동**팀 & 자원** > **제품정보** > **회사연혁**.
2. 내 계정**장치 등록 권한**, 선택**계정 관리**.
3. 오시는 길**로그인 방법**탭 및 활성화**WARP 인증 ID**.
4. 이름 \***세션 기간**, 세션 타임아웃 값을 선택합니다. 이 타임아웃은 WARP 인증이 가능한 모든 액세스 애플리케이션에 적용됩니다.

:::참조

이 타임아웃 값은 적용되지 않습니다.[WARP 세션은 게이트웨이 정책에서 확인](#configure-warp-sessions-in-gateway).
:::

5. (선택) WARP 인증은 모든 기존 및 새로운 응용 프로그램에 대한 기본으로 설정 가능**모든 액세스 응용 프로그램에 적용**. 당신은 당신이 할 때 per-application 기초에 이 과잉을 과잉할 수 있습니다[지원하다](/cloudflare-one/access-controls/applications/http-apps/)또는 액세스 응용 프로그램을 수정합니다.
6. 제품정보**제품 정보**.

사용자는 이제 WARP로 한 번 인증하여 설정된 기간 동안 액세스 애플리케이션에 액세스할 수 있습니다. 세션 타이머는 WARP에 등록하는 데 사용되는 IdP와 함께 사용자가 다시 결과를 다시 시작합니다.

## IdP와 힘 사용자 상호 작용

사용자가 IdP와 함께 활성 브라우저 세션을 가지고 있다면, WARP는 기존 브라우저 쿠키를 사용하여 재조립 및 사용자는 자격 증명을 다시 입력 할 수 없습니다. IdP에서 명시된 사용자 상호작용을 요구하려면 이 행동을 무시할 수 있습니다.

## 제한 사항

- **장치 당 1명의 사용자**— 디바이스가 이미 사용자 A에 등록되면, User B는 re-authentication flow를 통해 해당 장치에 로그인할 수 없습니다. 다른 사용자에 장치 등록을 전환하려면, 사용자 A 먼저 Zero Trust에서 로그 아웃해야합니다 (if[조직을 떠나는 장치](/cloudflare-one/team-and-resources/devices/warp/configure-warp/warp-settings/#allow-device-to-leave-organization)활성화), 또는 관리자는 등록을 취소 할 수 있습니다**팀 & 자원** > **제품정보**. 사용자 B는 그 후에 제대로 할 수 있습니다[이름 \*](/cloudflare-one/team-and-resources/devices/warp/deployment/manual-deployment/).
- **Active 연결이 종료되지 않습니다.**- SSH 및 RDP와 같은 Active Sessions는 타임아웃 제한을 넘어 연결됩니다.
- **Binding Cookie는 지원되지 않습니다.**- WARP 인증은 액세스 응용 프로그램에 작동하지 않습니다[쿠키 정책](/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/#binding-cookie)지원하다

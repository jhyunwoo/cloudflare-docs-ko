## Verify 장치 프로파일

### 대시보드를 통해

특정 장치에 대한 마지막 활성 장치 프로파일을 확인하려면:

1. 내 계정[모델 번호: Cloudflare 한국어](https://one.dash.cloudflare.com/), 이동**팀 & 자원** > **제품정보**.
2. 장치의 밑에, 당신의 장치를 찾아내십시오.
3. 아래 장치 프로필을 검토**Last active 장치 프로파일**.

사용자의 장치에 대한 마지막 활성 장치 프로파일을 확인하려면:

1. 내 계정[모델 번호: Cloudflare 한국어](https://one.dash.cloudflare.com/), 이동**팀 & 자원** > **이름 \***.
2. 이름 \***사용자 이름**, 사용자가 조사하고 싶습니다.
3. 제품정보**제품정보**사용자가 사용하는 모든 장치를 볼 수 있습니다.
4. 해당 기기에 대한 마지막 활성 장치 프로파일을 조사하고 확인하려는 장치를 찾습니다.**회사소개**열.

대안으로, 당신은 사용할 수 있습니다[DEX 원격 캡처](/cloudflare-one/insights/dex/remote-captures/)WARP 진단 로그 수집. 장치 프로필 UUID가 표시됩니다.[검색 결과](/cloudflare-one/insights/dex/remote-captures/#warp-diagnostics-analyzer-beta)이름 \*`Profile ID`.

### CLI를 통해

장치 프로파일 및 프로파일 설정이 현재 장치에서 확인하려면 터미널을 열고 실행하십시오.

```sh
warp-cli settings
```

장치 프로파일 UUID는`Profile ID`이름 \*

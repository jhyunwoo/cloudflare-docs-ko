Cross-domain Identity Management (SCIM)의 시스템은 정체성 공급자가 클라우드 애플리케이션 및 서비스로 사용자 정체 정보를 동기화 할 수있는 개방형 표준 프로토콜입니다. SCIM을 구성한 후, 사용자 ID 공급자의 생성, 편집 또는 삭제가 모든 지원되는 응용 프로그램을 통해 자동으로 업데이트됩니다. IT 관리자는 새로운 사용자를 내장하고 그룹과 권한을 업데이트하고 직원 종료 또는 보안 침해의 이벤트에 액세스 할 수 있습니다.

:::참조
이 단면도는 Cloudflare Zero Trust 전용을 위한 SCIM 준비를 포함합니다. Cloudflare 계정에 대한 액세스를 제공하려면, 당신은 명백하게 설정해야합니다[대시보드 SSO SCIM 통합](/fundamentals/account/account-security/scim-setup/)IdP에서. Cloudflare 대시보드에 접속할 수 있는 새로운 SCIM 애플리케이션에 사용자와 그룹을 할당할 수 있습니다.

사용자를 통해 제공[Zero Trust SCIM 통합](#sync-users-and-groups-in-zero-trust-policies)Cloudflare 대시보드에 액세스할 수 없습니다.[Cloudflare 대시보드 SSO 신청](/fundamentals/manage-members/dashboard-sso/).
:::

## 지원된 ID 공급자

사이트맵 SCIM 버전을 사용하는 모든 SAML 및 OIDC ID 공급자에 대한 SCIM 제공 지원`2.0`.

## Zero Trust 정책에서 사용자 및 그룹 동기화

사이트맵 액세스는 Zero Trust에서 자동으로 디프로비젼 사용자가 ID 공급자에서 비활성화하고 액세스 및 게이트웨이 정책 빌더에 동기화 된 그룹 이름을 표시합니다. Cloudflare는 신원 공급자에 추가될 때 Zero Trust에 있는 새로운 사용자를 제공하지 않습니다 - 사용자는 먼저 WARP 클라이언트를 가진 장치를 등록해야 하고 접근 신청에 정정하십시오.

Zero Trust에 대한 SCIM을 설정하려면[SSO 통합](/cloudflare-one/integrations/identity-providers/)관련 기사

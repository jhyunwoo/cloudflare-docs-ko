사용자 로그는 Cloudflare One에 인증된 모든 사용자의 목록을 보여줍니다. 로그인 한 각 사용자의 경우, 등록 된 장치, 로그인 기록, 좌석 사용 및 정책 시행에 사용되는 ID를 볼 수 있습니다.

## 사용자 로그 보기

내 계정[사이트맵 한국어](https://one.dash.cloudflare.com/), 이동**팀 & 자원** > **이름 \***.

이 페이지는 WARP 클라이언트를 등록하거나 Cloudflare 액세스 응용 프로그램에 인증 한 모든 사용자를 나열합니다. 사용자의 이름을 선택하여 자세한 로그를 볼 수 있습니다.[자신의 세션을 취소](/cloudflare-one/access-controls/access-settings/session-management/#revoke-user-sessions), 또는[그들의 좌석을 제거](/cloudflare-one/team-and-resources/users/seat-management/).

### 자주 묻는 질문

- **사용자 등록 ID**: 마지막으로 본 정체성을 볼 수 있는 사용자의 이름을 선택합니다. 이 정체성은 Gateway 정책과 WARP를 평가하는 데 사용됩니다.[회사소개](/cloudflare-one/team-and-resources/devices/warp/configure-warp/device-profiles/). 사용자가 WARP를 재조정할 때 새로 고침이 발생하거나, 액세스 응용 프로그램에 로그인하거나, IdP 그룹 회원이 업데이트된 경우<GlossaryTooltip term="SCIM" link="/cloudflare-one/team-and-resources/users/scim/">SCIM 제공</GlossaryTooltip>. 사용자의 정체성이 시간이 지남에 따라 바뀌는 방법을 추적하려면**감사 로그**탭.
- **세션 ID**: 사용자의 활성 세션, 각 세션을 인증하는 데 사용되는 정체성, 각 세션이 있을 때[구매하기](/cloudflare-one/access-controls/access-settings/session-management/).
- **제품정보**: WARP를 통해 사용자에 등록된 장치.
- **최근 활동**: 사용자의 가장 최근의 액세스 로그인 시도. 자세한 내용은, 참조[인증 감사 로그](/cloudflare-one/insights/logs/audit-logs/#authentication-audit-logs).

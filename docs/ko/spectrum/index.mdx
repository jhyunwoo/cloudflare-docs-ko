<Description>

Spectrum은 모든 [TCP](https://www.cloudflare.com/learning/ddos/glossary/tcp-ip/) 또는 [UDP](https://www.cloudflare.com/learning/ddos/glossary/user-datagram-protocol-udp/) 기반 애플리케이션에 보안과 가속을 제공합니다.

</Description>

<Plan type="paid" />

Spectrum을 사용하면 MQTT, 이메일, 파일 전송, 버전 관리, 게임 등 다양한 TCP 또는 UDP 트래픽을 Cloudflare를 통해 라우팅하여 원본을 숨기고 [DDoS 공격](https://www.cloudflare.com/learning/ddos/what-is-a-ddos-attack/)으로부터 보호할 수 있습니다.

</Feature>

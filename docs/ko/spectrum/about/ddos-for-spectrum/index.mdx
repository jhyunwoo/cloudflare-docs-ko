title: Spectrum용 DDoS 보호
weight: 0

---

Spectrum은 [OSI 모델](https://www.cloudflare.com/learning/ddos/glossary/open-systems-interconnection-model-osi/)의 3-4계층, 즉 TCP 및 UDP 기반 DDoS 공격에 대한 보호를 제공합니다.

Spectrum은 4계층 리버스 프록시로 작동하므로, 트래픽이 오리진으로 프록시되기 전에 먼저 올바른 TCP 연결이 설정되어야 합니다. 이로 인해 SYN 또는 SYN-ACK 반사 공격의 영향은 Cloudflare 전역 네트워크로 이동합니다. 또한 애플리케이션 앞단에 Spectrum을 사용하면 오리진 IP가 숨겨져 공격자가 오리진 서버를 직접 노리지 못하게 됩니다. Cloudflare로 이전한 뒤에는 오리진 IP 주소를 교체하고, [Cloudflare IP 주소 범위](https://www.cloudflare.com/ips/)에서 오는 트래픽만 허용하도록 제한하는 것도 권장됩니다.

합법적인 TCP 연결이 아직 클라이언트와 Cloudflare 사이에 설정되지 않았다면, 임의이거나 상태 정보가 맞지 않는 TCP 패킷은 오리진으로 전달되어서는 안 됩니다. Spectrum은 또한 [Linux 네트워킹 스택의 일부인 SYN cookie challenge를 활용](https://blog.cloudflare.com/syn-packet-handling-in-the-wild/)하여 플러드 공격을 방어합니다.

또한 특정되지 않은 프로토콜의 패킷 플러드가 애플리케이션을 겨냥하는 경우(예를 들어 Spectrum 애플리케이션은 TCP 트래픽용인데 UDP 플러드가 해당 애플리케이션을 겨냥하는 경우), 해당 패킷은 폐기됩니다. 마찬가지로 지정하지 않은 포트 또는 포트 범위를 겨냥하는 패킷도 폐기됩니다.

L3/4 DDoS 공격은 기본적으로 활성화된 [Network-layer DDoS Attack Protection managed ruleset](/ddos-protection/managed-rulesets/network/)에 의해 탐지되고 완화됩니다. 이 ruleset은 패킷 헤더 필드를 기반으로 공격을 동적으로 지문화하여 DDoS 공격을 탐지하고 완화합니다.

HTTP/S 애플리케이션을 L7 DDoS 공격으로부터 보호하고 캐싱 및 추가 기능의 이점을 얻으려면, Cloudflare Spectrum과 함께 동작하는 Cloudflare의 웹 애플리케이션 방화벽/콘텐츠 전송 네트워크 서비스로 애플리케이션을 온보드하세요.

자세한 내용은 [Cloudflare DDoS Protection](/ddos-protection/)을 참고하세요.

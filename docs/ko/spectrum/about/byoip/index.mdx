Spectrum 애플리케이션을 만들면 일반적으로 Cloudflare는 Cloudflare의 IP 풀에서 임의의 IP를 애플리케이션에 할당합니다. 네트워크 설정을 명시적으로 구성하고 싶거나 자체 IP 주소를 사용하고 싶다면, Spectrum과 함께 BYOIP를 사용해 그렇게 할 수 있습니다.

BYOIP는 [Bring Your Own IP](/byoip/)의 약자입니다. IP 프리픽스를 보유하고 있다면 이를 Cloudflare로 이전할 수 있습니다. 이전이 완료되면 Cloudflare가 해당 IP 프리픽스를 광고하고 트래픽이 전 세계 Cloudflare 네트워크로 라우팅됩니다. 하지만 구성이 없다면 Cloudflare는 이 트래픽을 어떻게 처리해야 하는지 알 수 없습니다. 마지막 단계는 보호하려는 모든 애플리케이션에 대해, 연결하려는 IP 주소와 함께 Spectrum 애플리케이션을 추가하는 것입니다.


:::caution


BYOIP가 아닌 구성에서 BYOIP로 전환할 때 이미 Spectrum 애플리케이션을 사용 중이라면, 기존 구성을 삭제하고 새로 다시 만들어야 합니다.


:::

현재 Cloudflare가 지원하는 가장 작은 프리픽스는 IPv4의 경우 `/24`, IPv6의 경우 `/48`입니다.

BYOIP는 Spectrum에 기본 포함되지 않습니다. 이를 활성화하려면 계정 팀에 문의하세요.

## IP 주소 할당

IP를 사용하려면 적절한 A(IPv4) 또는 AAAA(IPv6) 레코드를 만들 수 있도록 해당 IP를 Spectrum 앱에 할당해야 합니다. 이는 API를 통해 애플리케이션을 생성할 때 하나 이상의 IP 주소를 지정하여 수행합니다. 또한 애플리케이션 속성을 변경할 때도 API를 통해서만 수행해야 합니다. 추가로, BYOIP를 사용해 Spectrum 앱을 만들려면 DNS `"type"` 필드를 `"ADDRESS"`로 업데이트해야 합니다.

```json
{
  "id": "4590376cf2994d72cee36828ec4eff19",
  "protocol": "tcp/22",
  "dns": {
    "type": "ADDRESS",
    "name": "ssh.example.com"
  },
  "origin_direct": ["tcp://192.0.2.1:22"],
  "ip_firewall": true,
  "proxy_protocol": false,
  "spp": false,
  "tls": "off",
  "traffic_type": "direct",
  "edge_ips": {
    "type": "static",
    "ips": ["198.51.100.10", "2001:DB8::1"]
  }
}
```

Spectrum은 이를 통해 연결되는 모든 클라이언트의 전체 수명 주기를 기록합니다. 이러한 이벤트 로그는 Logpush를 통해 별도의 카테고리(dataset type `spectrum_events`)로 제공되며, HTTP 로그 이벤트의 일부는 아닙니다.

각 연결에 대해 Spectrum은 connect 이벤트와 함께 disconnect 또는 error 이벤트를 기록합니다. 상태 코드에 대한 자세한 내용은 아래에서 확인할 수 있습니다.

## Logpush 구성

Spectrum [로그 이벤트](/logs/logpush/logpush-job/datasets/)는 선호하는 [대상](/logs/logpush/logpush-job/enable-destinations/)에 따라 대시보드 또는 API를 통해 구성할 수 있습니다.

## 상태 코드

| Code | Description |
| ---- | ----------- |
| 0 | 연결이 성공적으로 열렸습니다. |
| 200 | 정상적인 연결 종료입니다. |
| 400 | 클라이언트/엣지 TLS 핸드셰이크 중 전송된 TLS client hello에 잘못된 SNI가 포함되어 있었습니다. |
| 403 | 클라이언트 IP가 deny 동작을 가진 방화벽 규칙과 일치하여 연결이 종료되었습니다. |
| 443 | 클라이언트 TLS 핸드셰이크가 실패했습니다. |
| 444 | origin이 reset(RST) 패킷을 전송하여 연결을 종료했습니다. 일부 데이터는 전송되지 않았을 수 있습니다. |
| 445 | origin과의 확립된 연결에서 타임아웃 이벤트(ETIMEDOUT)가 발생했습니다. |
| 446 | origin keepalive가 만료되었습니다(EHOSTUNREACH). |
| 447 | 확립된 origin 연결에서 읽기 또는 쓰기 중 오류가 발생했습니다(ECONNREFUSED). |
| 448 | origin 연결이 broken pipe(EPIPE)로 인해 종료되었습니다. |
| 490 | 확립된 연결에서 클라이언트 TLS 오류가 발생했습니다. |
| 495 | 클라이언트 연결에서 오류가 수신되었습니다(ECONNREFUSED). |
| 496 | 클라이언트 호스트에 도달할 수 없습니다(EHOSTUNREACH). |
| 497 | 클라이언트와의 확립된 연결에서 타임아웃 이벤트(ETIMEDOUT)가 발생했습니다. |
| 498 | 확립된 클라이언트 연결이 broken pipe(EPIPE)로 인해 종료되었습니다. |
| 499 | 클라이언트가 reset(RST) 패킷을 전송하여 연결을 종료했습니다. 일부 데이터는 전송되지 않았을 수 있습니다. |
| 500 | Cloudflare 내부 오류입니다. |
| 503 | keyless SSL로 TLS 핸드셰이크를 수행하는 과정에서 관련 오류가 발생했습니다. |
| 520 | 알 수 없는 origin 연결 오류입니다. |
| 521 | origin이 연결 열기를 거부했습니다(ECONNREFUSED). |
| 522 | origin으로 연결을 여는 데 실패했습니다: ETIMEDOUT |
| 523 | origin으로 연결을 여는 데 실패했습니다: ENETUNREACH |
| 524 | 내부 시스템 오류로 인해 origin으로 연결을 여는 데 실패했습니다. |
| 530 | origin을 IP로 확인하는 중 내부 오류가 발생했습니다. |
| 531 | origin을 IP로 확인할 수 없었습니다. |
| 532 | origin IP가 차단되어 origin 연결이 열리지 않았습니다. |
| 533 | origin을 IP로 확인하는 중 내부 오류가 발생했습니다. |
| 540 | 잘못된 구성으로 인해 클라이언트/엣지 TLS 핸드셰이크가 실패했습니다. |
| 999 | 알 수 없는 연결 오류입니다. |

Spectrum 요청 및 응답 본문의 특정 필드는 Enterprise 플랜이 필요합니다. 플랜을 업그레이드하려면 계정 담당 팀에 문의하세요.

Enterprise 플랜이 필요한 Spectrum 속성은 다음과 같습니다.

| Name | Type | Description | Example |
| ---- | ---- | ----------- | ------- |
| `origin_dns` | object | DNS를 통해 origin 서버 주소를 찾는 데 사용되는 방법과 매개변수입니다. 유효한 레코드 유형은 `A`, `AAAA`, `SRV`, 그리고 빈 값(`A`와 `AAA` 모두)입니다.<br />요청에는 `origin_dns` 매개변수 또는 `origin_direct` 매개변수 중 하나가 반드시 포함되어야 합니다. 둘 다 지정되면 서비스는 `HTTP 400 Bad Request`를 반환합니다. | `origin_dns: {type: A, name: mqtt.example.com, ttl: 1200}` |
| `origin_port` | integer | origin의 대상 포트입니다. | `22` |
| `proxy_protocol` | string | origin에 대해 Proxy Protocol을 활성화합니다. Spectrum은 `v1`, `v2`, `simple` 프록시 프로토콜을 지원합니다. 자세한 내용은 [Proxy Protocol](/spectrum/how-to/enable-proxy-protocol/)을 참조하세요. | `off` |
| `ip_firewall` | boolean | 이 애플리케이션에 대해 IP Access 규칙을 활성화합니다. | `true` |
| `tls` | string | 애플리케이션에 대한 TLS 종료 유형입니다. 옵션은 `off`(기본값, Passthrough라고도 함), `flexible`, `full`, `strict`입니다. 각 옵션의 설명은 [Configuration Options](/spectrum/reference/configuration-options/)를 참조하세요. | `full` |
| `argo_smart_routing` | boolean | 애플리케이션에 대해 Argo Smart Routing을 활성화합니다. 이 기능은 `traffic_type`이 `direct`로 설정된 TCP 애플리케이션에서만 사용할 수 있습니다. | `true` |

[Spectrum API 문서](/api/resources/spectrum/subresources/apps/methods/list/)에서 API 요청 예시를 확인하세요.

주어진 키의 값을 얻으려면, 호출`get()`방법의[KV 바인딩](/kv/concepts/kv-bindings/)모든 것[KV 네임스페이스](/kv/concepts/kv-namespaces/)당신은 당신의 노동자 부호에 경계가 있습니다:

```js
//개별 키 읽기
env.NAMESPACE.get(key);

//여러 키 읽기
env.NAMESPACE.get(keys);
```

더 보기`get()`방법 당신이 할 수있는 약속을 반환`await`값을 얻는다.

문자열로 단일 키를 요청하면 약속의 단일 응답을 받게됩니다. 키가 발견되지 않은 경우, 약속은 리터 값으로 해결됩니다.`null`.

또한 키의 배열을 요청할 수 있습니다. 반환 값은`Map`key-value 쌍의 발견,
발견하지 않는 열쇠로`null`가치.

```js
export default {
	async fetch(request, env, ctx) {
		try {
			//단일 키 읽기, 값 반환 또는 null
			const value = await env.NAMESPACE.get("first-key");

			//여러 키 읽기, 값의지도를 반환
			const values = await env.NAMESPACE.get(["first-key", "second-key"]);

			//metadata로 단일 키 읽기, 값 또는 null을 반환
			const valueWithMetadata = await env.NAMESPACE.getWithMetadata("first-key");

			//metadata로 여러 키 읽기, 값의지도를 반환
			const valuesWithMetadata = await env.NAMESPACE.getWithMetadata(["first-key", "second-key"]);

			return new Response({
				value: value,
				values: Object.fromEntries(values),
				valueWithMetadata: valueWithMetadata,
				valuesWithMetadata: Object.fromEntries(valuesWithMetadata)
			});
		} catch (e) {
			return new Response(e.message, { status: 500 });
		}
	},
};
```

:::참조

`get()`·`getWithMetadata()`메서드는 stale 값을 반환할 수 있습니다. 주어진 키가 최근 주어진 위치에 읽고 있다면, 다른 위치에 만든 키에 쓰기 또는 업데이트는 60 초까지 걸릴 수 있습니다 (또는 기간의`cacheTtl`전시에 ).

:::

### `get()`제품 설명

사용 방법`get()`단일 값을 얻는 방법, 또는 다중 키 주어진 경우 여러 값:

- 단일 키 읽기[get(키: 문자열)](#request-a-single-key-with-getkey-string)
- 여러 키 읽기[get(키: string\[\])](#request-multiple-keys-with-getkeys-string)

#### 단일 키 요청`get(key: string)`

단일 키의 값을 얻으려면, 호출`get()`어떤 KV 네임스페이스의 메소드를 사용하여 작업자 코드에 바인딩해야 합니다:

```js
env.NAMESPACE.get(key, type?);
//이름 *
env.NAMESPACE.get(key, options?);
```

##### 매개 변수

- `key`: `string`
  - KV 쌍의 열쇠.
- `type`: `"text" | "json" | "arrayBuffer" | "stream"`
  - 옵션. 반환 값의 유형.`text`기본값입니다.
- `options`: `{
    cacheTtl?: number,
    type?: "text" | "json" | "arrayBuffer" | "stream"
  }`
  - 옵션. 옵션 포함`cacheTtl`·`type`이름 \* 더 보기`cacheTtl`속성은 KV 결과가 글로벌 네트워크 위치에 캐시되어 있기 때문에 초의 길이를 정의합니다 (최소 : 30). 더 보기`type`속성은 값의 유형을 반환합니다.

##### 관련 기사

- `response`: `Promise<string | Object | ArrayBuffer | ReadableStream | null>`
  - 요청된 KV 쌍을 위한 가치. 응답 유형은에 달려 있을 것입니다`type`매개변수 제공`get()`다음과 같이 명령:
  - `text`: 아`string`(과태).
  - `json`: JSON 문자열에서 분리된 객체.
  - `arrayBuffer`: 한국어[`ArrayBuffer`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/ArrayBuffer)예.
  - `stream`: 아[`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream).

#### 여러 키 요청`get(keys: string[])`

여러 키의 값을 얻으려면, 호출`get()`어떤 KV 네임스페이스의 메소드를 사용하여 작업자 코드에 바인딩해야 합니다:

```js
env.NAMESPACE.get(keys, type?);
//이름 *
env.NAMESPACE.get(keys, options?);
```

##### 매개 변수

- `keys`: `string[]`
  - KV 쌍의 열쇠. 최대: 100개의 열쇠
- `type`: `"text" | "json"`
  - 옵션. 반환 값의 유형.`text`기본값입니다.
- `options`: `{
    cacheTtl?: number,
    type?: "text" | "json"
  }`
  - 옵션. 옵션 포함`cacheTtl`·`type`이름 \* 더 보기`cacheTtl`속성은 KV 결과가 글로벌 네트워크 위치에 캐시되어 있기 때문에 초의 길이를 정의합니다 (최소 : 30). 더 보기`type`속성은 값의 유형을 반환합니다.

:::참조

더 보기`.get()`다중 키를 읽는 기능은 지원하지 않습니다`arrayBuffer`또는`stream`반환 유형. 여러 키를 읽을 필요가 있다면`arrayBuffer`또는`stream`유형, 사용 고려`.get()`평행한에 있는 개인적인 열쇠를 읽는 기능`Promise.all()`.

:::

##### 관련 기사

- `response`: `Promise<Map<string, string | Object | null>>`
  - 요청된 KV 쌍을 위한 가치. 열쇠가 없는 경우에,`null`열쇠를 위해 반환됩니다. 응답 유형은에 달려 있을 것입니다`type`매개변수 제공`get()`다음과 같이 명령:
    - `text`: 아`string`(과태).
    - `json`: JSON 문자열에서 분리된 객체.

응답 크기의 한계는 25 MB입니다. 이 크기의 응답은 실패합니다.`413 Error`오류 메시지.

### `getWithMetadata()`제품 설명

사용 방법`getWithMetadata()`메타데이터와 함께 하나의 값을 얻는 방법, 또는 메타데이터와 여러 값:

- 단일 키 읽기[getWithMetadata(키: 문자열)](#request-a-single-key-with-getwithmetadatakey-string)
- 여러 키 읽기[getWithMetadata(키: 문자열\[\])](#request-multiple-keys-with-getwithmetadatakeys-string)

#### 단일 키 요청`getWithMetadata(key: string)`

메타 데이터와 함께 주어진 키에 대한 값을 얻으려면, 호출`getWithMetadata()`어떤 KV 네임스페이스에서 작업자 코드에 바인딩:

```js
env.NAMESPACE.getWithMetadata(key, type?);
//이름 *
env.NAMESPACE.getWithMetadata(key, options?);
```

메타데이터는 각 KVXQ 항목에 추가되는 serializable 값입니다.

##### 매개 변수

- `key`: `string`
  - KV 쌍의 열쇠.
- `type`: `"text" | "json" | "arrayBuffer" | "stream"`
  - 옵션. 반환 값의 유형.`text`기본값입니다.
- `options`: `{
    cacheTtl?: number,
    type?: "text" | "json" | "arrayBuffer" | "stream"
  }`
  - 옵션. 옵션 포함`cacheTtl`·`type`이름 \* 더 보기`cacheTtl`속성은 KV 결과가 글로벌 네트워크 위치에 캐시되어 있기 때문에 초의 길이를 정의합니다 (최소 : 30). 더 보기`type`속성은 값의 유형을 반환합니다.

##### 관련 기사

- `response`: `Promise<{
  value: string | Object | ArrayBuffer | ReadableStream | null,
  metadata: string | null
  }>`

  - 요청된 KV 쌍에 대한 값과 메타 데이터를 포함하는 객체. 값 속성의 유형은에 따라 달라집니다.`type`매개변수 제공`getWithMetadata()`다음과 같이 명령:
    - `text`: 아`string`(과태).
    - `json`: JSON 문자열에서 분리된 객체.
    - `arrayBuffer`: 한국어[`ArrayBuffer`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/ArrayBuffer)예.
    - `stream`: 아[`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream).

요청된 키 값 쌍과 관련된 메타 데이터가 없다면,`null`metadata에 반환됩니다.

#### 여러 키 요청`getWithMetadata(keys: string[])`

메타 데이터와 함께 키의 주어진 세트에 대한 값을 얻으려면, 호출`getWithMetadata()`어떤 KV 네임스페이스에 메소드를 사용하여 작업자 코드에 바인딩해야 합니다:

```js
env.NAMESPACE.getWithMetadata(keys, type?);
//이름 *
env.NAMESPACE.getWithMetadata(keys, options?);
```

##### 매개 변수

- `keys`: `string[]`
  - KV 쌍의 열쇠. 최대: 100개의 열쇠
- `type`: `"text" | "json"`
  - 옵션. 반환 값의 유형.`text`기본값입니다.
- `options`: `{
    cacheTtl?: number,
    type?: "text" | "json"
  }`
  - 옵션. 옵션 포함`cacheTtl`·`type`이름 \* 더 보기`cacheTtl`속성은 KV 결과가 글로벌 네트워크 위치에 캐시되어 있기 때문에 초의 길이를 정의합니다 (최소 : 30). 더 보기`type`속성은 값의 유형을 반환합니다.

:::참조
더 보기`.get()`다중 키를 읽는 기능은 지원하지 않습니다`arrayBuffer`또는`stream`반환 유형. 여러 키를 읽을 필요가 있다면`arrayBuffer`또는`stream`유형, 사용 고려`.get()`평행한에 있는 개인적인 열쇠를 읽는 기능`Promise.all()`.
:::

##### 관련 기사

- `response`: `Promise<Map<string, {
  value: string | Object | null,
  metadata: string | Object | null
  }>`

  - 요청된 KV 쌍에 대한 값과 메타 데이터를 포함하는 객체. 값 속성의 유형은에 따라 달라집니다.`type`매개변수 제공`getWithMetadata()`다음과 같이 명령:
    - `text`: 아`string`(과태).
    - `json`: JSON 문자열에서 분리된 객체.
  - 메타데이터의 유형은 문자열이나 객체 중 하나일 수 있는 무엇에 따라 달라집니다.

요청된 키 값 쌍과 관련된 메타 데이터가 없다면,`null`metadata에 반환됩니다.

응답 크기의 한계는 25 MB입니다. 이 크기의 응답은 실패합니다.`413 Error`오류 메시지.

## 구시가지

### 유형 모수

간단한 값을 위해, 기본값을 사용하십시오`text`당신의 가치를 제공하는 유형`string`. 편의를 위해,`json`타입은 객체를 반환하기 전에 JSON 값을 객체로 변환하는 것을 지정합니다. 큰 가치를 위해, 사용`stream`요청하기`ReadableStream`. 바이너리 값의 경우, 사용`arrayBuffer`요청하기`ArrayBuffer`.

큰 가치를 위해, 선택의`type`대기 시간 및 CPU 사용에 눈에 띄는 효과가있을 수 있습니다. 참고 자료를 위해,`type`가장 빠른 속도로 주문할 수 있습니다.`stream`, `arrayBuffer`, `text`·`json`.

### CacheTtl 매개 변수

`cacheTtl`KV 결과가 글로벌 네트워크 위치에 캐시되어 초의 길이를 정의하는 매개 변수입니다.

초에 있는 시간의 길이를 정의하는 것은 비교적 infrequently 읽는 열쇠에 찬 독서 대기권을 감소시키기를 위해 유용합니다.`cacheTtl`데이터가 write-once 또는 write-rarely인 경우 유용합니다.

:::노트\[뜨거운 찬]

뜨거운 읽음은 자료가 Cloudflare의 가장자리 네트워크에 캐시된다는 것을 의미합니다[사이트맵](https://developers.cloudflare.com/cache/)로컬 캐시 또는 지역 캐시에 있는지 여부. 콜드 읽음은 데이터가 캐시되지 않다는 것을 의미합니다. 따라서 데이터는 중앙 상점에서 fetched해야합니다. 기존 키 값 쌍과 비 유능한 키 값 쌍 모두 (일컬어 부정적인 모습) 가장자리에 캐시됩니다.
주요 특징

`cacheTtl`귀하의 데이터가 종종 업데이트되고 그들이 작성한 후 업데이트가 곧 볼 필요가 없습니다, 다른 글로벌 네트워크 위치에서 발생하는 쓰기 때문에 캐시 된 값이 만료 될 때까지 볼 수 없습니다.

더 보기`cacheTtl`매개변수는 더 중대한 integer이어야 합니다 또는 동등한 것`30`. `60`기본값입니다. 최대 값`cacheTtl`이름 \*[`Number.MAX_SAFE_INTEGER`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/MAX_SAFE_INTEGER).

키가 주어진대로 읽혔습니다.`cacheTtl`지역에서, 그것은 그 지역에 캐시 남아있을 것입니다 그 지역 끝까지`cacheTtl`또는 eviction. 이것은 KV의 건축 캐싱 층의 지역 그리고 중앙 층에 영향을 줍니다. Workers QXKV, KV에 내부 지역과 중앙 캐싱 층의 지구가 새로 쓴 결과와 다시 유효하게 될 때.

### 대량 요청으로 Worker invocation 당 더 많은 키를 요청

Workers는 invocation 당 외부 서비스에 1,000개의 가동으로 제한됩니다. 이것은 Workers KV에, 문서로 적용합니다[Workers KV 제한](/kv/platform/limits/).

가동 당 1,000 이상 열쇠를 읽기 위하여는, 당신은 단 하나 가동에 있는 다수 열쇠를 읽는 대량 읽는 가동을 사용할 수 있습니다. 1,000개의 작업 한계에 대한 단일 작업으로 계산합니다.

### 탄화 열쇠에 의해 cardinality 감소

혼합 사용 패턴 (일부 핫 키와 일부 찬 키)가 있는 관련 키 가치 쌍의 세트를 가지고 있다면, 그들을 탄화시킨다. 뜨거운 열쇠를 가진 찬 열쇠에 의하여, 찬 열쇠는 개인적인 열쇠로 uncached 경우에 보다 빨리 읽을 수 있는 뜨거운 열쇠를 함께 캐시될 것입니다.

#### "최고"KVXQ 항목으로 합병

하나의 석탄 기술은 슈퍼 키 가치 객체의 모든 키와 값 부분을 만들 것입니다. 예는 아래와 같습니다.

```
key1: value1
key2: value2
key3: value3
```

계정이 없습니다.

```
coalesced: {
  key1: value1,
  key2: value2,
  key3: value3,
}
```

값의 탄화수소에 의해, 찬 열쇠는 더 온난한 열쇠의 접근 본 때문에 캐시에서 온난한 것을 지킵니다.

이 작품은 각 다른 값을 독립적으로 업데이트 할 필요가 없을 때 가장 잘 작동합니다.

- **제품 정보**: 즉시 액세스 키는 캐시에 보관됩니다.
- **관련 제품**: 결과 값의 크기는 메모리 제한에서 작업자를 밀어 줄 수 있습니다. 안전한 상승 값은[locking 기계장치](/kv/api/write-key-value-pairs/#concurrent-writes-to-the-same-key)어떤 종류의.

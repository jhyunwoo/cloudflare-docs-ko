KV 네임스페이스의 모든 키를 나열하려면`list()`방법의[KV 바인딩](/kv/concepts/kv-bindings/)모든 것[KV 네임스페이스](/kv/concepts/kv-namespaces/)당신은 당신의 노동자 부호에 경계가 있습니다:

```js
env.NAMESPACE.list();
```

더 보기`list()`방법 당신이 할 수있는 약속을 반환`await`값을 얻는다.

#### 이름 \*

작업자 내에서 목록 키의 예:

```js
export default {
  async fetch(request, env, ctx) {
    try {
      const value = await env.NAMESPACE.list();

      return new Response(JSON.stringify(value.keys), {
        status: 200
      });
    }
    catch (e)
    {
      return new Response(e.message, {status: 500});
    }
  },
};
```

## 이름 \*

뒤에 오는 방법은 KV의 열쇠를 목록으로 만들 것입니다:

- [목록()](#list-method)

### `list()`제품 설명

KV 네임스페이스의 모든 키를 나열하려면`list()`방법의[KV 바인딩](/kv/concepts/kv-bindings/)어떤 KV 네임스페이스에서 작업자 코드에 바인딩:

```ts
env.NAMESPACE.list(options?)
```

#### 매개 변수

- `options`: `{
  prefix?: string,
  limit?: string,
  cursor?: string
  }`
  - 속성을 가진 객체`prefix`(선택),`limit`(선택), 또는`cursor`(선택).
    - `prefix`한국어`string`모든 키를 필터링 할 수 있는 접두사를 나타냅니다.
    - `limit`반환된 키의 최대 번호입니다. 기본값은 1,000이며 최대입니다. 이 기본값을 변경하고 싶지는 않지만 완성에 포함되어 있습니다.
    - `cursor`한국어`string`paginating 응답을 위해 사용해.

#### 관련 기사

- `response`: `Promise<{
  keys: {
    name: string,
    expiration?: number,
    metadata?: object
  }[],
  list_complete: boolean,
  cursor: string
  }>`
  - ·`Promise`그것은 포함 된 개체에 해결`keys`, `list_complete`·`cursor`이름 \*
    - `keys`각 키가 나열된 객체를 포함하는 배열입니다. 각 개체에는 속성이 있습니다.`name`, `expiration`(선택), 및`metadata`(선택). 키 값 쌍이 만료 세트를 가지고 있다면, 만료는 TTL 형태로 설정된 경우에도 절대 값 양식에서 존재합니다. key-value 쌍이 non-null 메타데이터 세트를 가지고 있다면, metadata가 존재합니다.
    - `list_complete`boolean입니다.`false`fetch에 더 많은 키가 있다면, 심지어`keys`배열은 비어 있습니다.
    - `cursor`한국어`string`paginating 응답을 위해 사용해.

더 보기`list()`메소드는 다음과 같이 보이는 객체로 해결하는 약속을 반환합니다.

```json
{
  "keys": [
    {
      "name": "foo",
      "expiration": 1234,
      "metadata": { "someMetadataKey": "someMetadataValue" }
    }
  ],
  "list_complete": false,
  "cursor": "6Ck1la0VxJ0djhidm1MdX2FyD"
}
```

더 보기`keys`속성은 각 키를 설명하는 개체의 배열을 포함합니다. 그 객체는 자체의 세 키에 하나가 될 것입니다 :`name`열쇠의, 그리고 선택적으로 열쇠의`expiration`·`metadata`가치.

더 보기`name`한국어`string`·`expiration`값은 숫자이며,`metadata`어떤 유형이 초기 설정되었습니다. 더 보기`expiration`키가 만료되면 값이 반환되고 TTL 형태로 설정된 경우에도 절대 값 양식에있을 것입니다. 이름 \*`metadata`주어진 키가 비 null 관련 메타데이터가 있다면 반환됩니다.

이름 \*`list_complete`이름 \*`false`, 더 많은 키가 fetch, 경우에도`keys`배열은 비어 있습니다. 당신은 사용할 것이다`cursor`더 많은 키를 얻는 재산. 더 알아보기[제품정보](#pagination)더 많은 정보.

메타데이터의 가치를 저장하는 것을 고려하면 값이 일치하면[메타데이터 크기 제한](/kv/platform/limits/). metadata에 있는 Storing 가치는 더 능률적입니다`list()`다음으로`get()`키 당. 사용 방법`put()`, 떠나`value`매개 변수 빈 및 대신 메타 데이터 객체의 속성을 포함:

```js
await NAMESPACE.put(key, "", {
  metadata: { value: value },
});
```

변화는 60 초까지 걸릴지도 모릅니다 (또는 가치 세트로`cacheTtl`이름 \*`get()`또는`getWithMetadata()`메소드) KV 네임스페이스에서 메소드를 호출하는 응용 프로그램에 반영됩니다.

## 구시가지

### 연락처

특정 접두사로 시작하는 모든 키를 나열합니다.

예를 들어, 사용자, 사용자 ID, 키 이름과 함께 키를 구성할 수 있습니다.`user:1:<key>`). 다음 코드를 사용하여 사용자 번호에 대한 키를 얻을 수 있습니다:

```js
export default {
  async fetch(request, env, ctx) {
    const value = await env.NAMESPACE.list({ prefix: "user:1:" });
    return new Response(value.keys);
  },
};
```

이 모든 키가 시작됩니다.`"user:1:"`연락처

### 주문하기

열쇠는 항상 그들의 UTF-8 바이트에 따라 lexicographically 분류한 순서에서 반환됩니다.

### 제품정보

더 많은 키가 fetch에 있다면,`list_complete`열쇠는 놓일 것입니다`false`·`cursor`반환됩니다. 이 경우 전화 할 수 있습니다.`list()`다시 한번`cursor`열쇠의 다음 배치를 얻는 가치:

```js
const value = await NAMESPACE.list();

const cursor = value.cursor;

const next_value = await NAMESPACE.list({ cursor: cursor });
```

빈 배열을 확인`keys`더 많은 키가 fetch인지 결정하는 것은 충분하지 않습니다. 대신, 사용`list_complete`.

빈 배열을 할 수 있습니다`keys`, 그러나 아직도 fetch에 더 많은 열쇠가, 때문에[최근 만료되거나 삭제된 키](https://en.wikipedia.org/wiki/Tombstone_%28data_store%29)반환에 포함되지 않습니다`keys`.

큰 결과를 설정할 때도 제공`prefix`인수,`prefix`인수는 초기 인수와 함께 모든 후속 호출에서 제공해야합니다.

### metadata에 최적화된 스토리지`list()`회사연혁

메타데이터의 가치를 저장하는 것을 고려하면 값이 일치하면[메타데이터 크기 제한](/kv/platform/limits/). metadata에 있는 Storing 가치는 더 능률적입니다`list()`다음으로`get()`키 당. 사용 방법`put()`, 떠나`value`매개 변수 빈 및 대신 메타 데이터 객체의 속성을 포함:

```js
await NAMESPACE.put(key, "", {
  metadata: { value: value },
});
```

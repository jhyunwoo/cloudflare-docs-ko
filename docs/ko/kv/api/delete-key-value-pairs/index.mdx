key-value 쌍을 삭제하려면`delete()`방법의[KV 바인딩](/kv/concepts/kv-bindings/)모든 것[KV 네임스페이스](/kv/concepts/kv-namespaces/)당신은 당신의 노동자 부호에 경계가 있습니다:

```js
env.NAMESPACE.delete(key);
```

#### 이름 \*

노동자 내에서 키 가치 쌍을 삭제하는 예 :

```js
export default {
  async fetch(request, env, ctx) {
    try {
      await env.NAMESPACE.delete("first-key");

      return new Response("Successful delete", {
        status: 200
      });
    }
    catch (e)
    {
      return new Response(e.message, {status: 500});
    }
  },
};
```

## 이름 \*

다음 방법은 KV에서 삭제됩니다.

- [삭제()](#delete-method)

### `delete()`제품 설명

key-value 쌍을 삭제하려면`delete()`방법의[KV 바인딩](/kv/concepts/kv-bindings/)어떤 KV 네임스페이스에서 작업자 코드에 바인딩:

```js
env.NAMESPACE.delete(key);
```

#### 매개 변수

- `key`: `string`
  - 가치와 연관시키는 열쇠.

#### 관련 기사

- `response`: `Promise<void>`
  - ·`Promise`삭제가 성공하면 해결됩니다.

이 방법은 당신이해야 할 약속을 반환`await`성공적인 토론을 확인하려면 전화 번호`delete()`non-existing key는 성공적인 삭제로 반환됩니다.

자주 묻는 질문`delete()`방법은 KV 네임스페이스에서 키와 값을 제거합니다. 어떤 작업으로, 그것은 Cloudflare 글로벌 네트워크의 다양한 지점에서 삭제 된 키에 대한 몇 시간을 걸릴 수 있습니다.

## 구시가지

### 대량의 데이터 삭제

Wrangler 또는 한 번에 하나의 키 가치 쌍을 삭제[REST API를 통해](/api/resources/kv/subresources/namespaces/subresources/keys/methods/bulk_delete/).

대량 REST API는 한 번에 10,000 KV 쌍까지 받아들일 수 있습니다. 대량 글은 지원되지 않습니다.[KV 바인딩](/kv/concepts/kv-bindings/).

## KV에 접근하는 다른 방법

당신은 또한 할 수 있습니다[Wrangler를 가진 명령 선에서 열쇠 가치 쌍을 삭제하십시오](/kv/reference/kv-commands/#kv-namespace-delete)또는[REST API로](/api/resources/kv/subresources/namespaces/subresources/values/methods/delete/).

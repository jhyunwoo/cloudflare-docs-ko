Workers KVXQ의 정적 자산을 저장함으로써, 이 자산을 전 세계적으로 저하중과 높은 처리량으로 검색할 수 있습니다. 이러한 자산을 직접 제공하거나 동적으로 응답을 생성합니다. 사용자 정의 스크립트와 같은 파일을 제공 할 때 유용 할 수 있습니다, 내부에 맞는 작은 이미지[KV 제한](/kv/platform/limits/), 또는 번역과 같은 정적 자산에서 동적 HTML 응답을 생성 할 때.

:::주\[주]
당신이 필요로 하는 경우에**front-end 또는 full-stack 웹 응용 프로그램 호스트**, **제품 정보[Cloudflare Workers 정적 자산](/workers/static-assets/)또는[Cloudflare Pages](/pages/)**, 이는 웹 애플리케이션 및 자산에 대한 목적으로 구축 된 배포 경험을 제공합니다.

[QXQX0366XQQKV](/kv/)더 유연한 API를 제공합니다. 액세스, 편집 및 저장 자산을 바로 사용할 수 있습니다.[작업자](/workers/)설치가 필요없습니다. 배포 번들에 포함되지 않은 사용자 정의 자산을 제공 할 수 있습니다, 업로드 된 미디어 자산 또는 사용자 정의 스크립트 및 파일 실행 시간에 생성.
주요 특징

## Wrangler를 사용하는 QXKVXQ에 정적 자산을 쓰기

Workers KVXQ에 있는 정체되는 자산을 저장하기 위하여, 당신은 사용할 수 있습니다[Wrangler 클립](/workers/wrangler/)(개발 중 사용),[Workers KV 바인딩](/kv/concepts/kv-bindings/)Workers 신청에서, 또는[Workers QXQX0378XQREST API](/api/resources/kv/subresources/namespaces/methods/list/)(외부 응용 프로그램에서 Workers KV에 액세스하는 데 사용). Wrangler CLI를 사용하는 방법을 설명합니다.

이 시나리오의 경우 Workers KVQ 저장소 내에서 샘플 HTML 파일을 저장할 수 있습니다.

새 파일 만들기`index.html`다음 내용으로:

```html title="index.html"
Hello World!
```

우리는 다음 Wrangler 명령을 사용하여 KV 쌍을 만들 수 있습니다 우리의 생산 및 미리보기 네임스페이스 내의이 파일에 대한:

```sh
npx wrangler kv key put index.html --path index.html --namespace-id=<ENTER_NAMESPACE_ID_HERE>
```

이것은 Wrangler 파일에 바인딩에 의해 지정된 우리의 생산 및 미리보기 이름 공간 안에 열쇠와 파일 내용으로 파일 이름을 가진 KVXQ 쌍을 창조할 것입니다.

## 노동자 응용 프로그램에서 KV에서 정적 자산

이 예제에서, 우리의 Workers 응용 프로그램은 HTTP 요청의 경로로 어떤 키 이름을 받아들이고 그 키에 대한 KV 저장소에 저장된 값을 반환합니다.

<Tabs>
  <TabItem label="사이트맵">
    ```js

    import mime from "mime";

    interface Env {
    assets: KVNamespace;
    }

    export default {
    	async fetch(request, env, ctx): Promise<Response> {
    		//반환 오류 if not a get request
    		if(request.method !== 'GET'){
    			return new Response('Method Not Allowed', {
    				status: 405,
    			})
    		}

        	//키가 누락된 경우 url & return 오류에서 키 가져오기
        	const parsedUrl = new URL(request.url)
        	const key = parsedUrl.pathname.replace(/^\/+/, '') //어떤 preceding/'s를 벗기십시오
        	if(!key){
        		return new Response('Missing path in URL', {
        			status: 400
        		})
        	}

        	//키 경로에서 mimetype을 가져옵니다
        	const extension = key.split('.').pop();
        	let mimeType = mime.getType(extension) || "text/plain";
        	if (mimeType.startsWith("text") || mimeType === "application/javascript") {
        		mimeType += "; charset=utf-8";
        	}

        	//Workers QXQX0397XQQQQQXQ 스토어에서 값을 가져 와서 찾을 경우 반환
        	const value = await env.assets.get(key, 'arrayBuffer')
        	if(!value){
        		return new Response("Not found", {
        			status: 404
        		})
        	}

        	//Workers 신청에서 KV 상점에서 가치를 가진 응답을 반환하십시오
        	return new Response(value, {
        		status: 200,
        		headers: new Headers({
        			"Content-Type": mimeType
        		})
        	});
        },

    } satisfies ExportedHandler<Env>;

    ```
  </TabItem>

    ```json

    	"$schema": "node_modules/wrangler/config-schema.json",
    	"name": "<ENTER_WORKER_NAME>",
    	"main": "src/index.ts",
    	"compatibility_date": "2025-03-03",
    	"observability": {
    		"enabled": true
    	},
    	"kv_namespaces": [
    		{
    			"binding": "assets",
    ```

</Tabs>

이 코드는 HTTP 요청에서 키 값 쌍에 대한 키 이름을 파. 그런 다음 응답에 대한 적절한 MIME 유형이 응답을 처리하는 방법을 알려줍니다.
KV 저장소에서 값을 검색하려면, 이 코드 사용`arrayBuffer`제대로 이미지, 문서 및 비디오/오디오 파일과 같은 바이너리 데이터를 처리한다.

열쇠를 가진 표본 열쇠 가치 쌍을 주기하십시오`index.html`우리의 Workers QXKV 이름공간 상점에 있는 몇몇 HTML 내용을 포함하는 가치, 우리는 우리의 Workers 신청에 접근해서 좋습니다
에 의해`https://<YOUR-WORKER-HOSTNAME>/index.html`본문내용 바로가기`index.html`파일.

이미지 또는 문서와 함께 시도하면이 노동자가 KV에서 이러한 자산을 제대로 서빙한다는 것을 볼 수 있습니다.

## 키 값 쌍의 동적 응답 생성

정적 자산을 제공 할뿐만 아니라 KV 저장소에 저장된 값에 따라 동적 HTML 또는 API 응답을 생성합니다.

1. 프로젝트의 루트에 이 파일을 만들기 시작:

```json title="hello-world.json"
[
	{
		"language_code": "en",
		"message": "Hello World!"
	},
	{
		"language_code": "es",
		"message": "¡Hola Mundo!"
	},
	{
		"language_code": "fr",
		"message": "Bonjour le monde!"
	},
	{
		"language_code": "de",
		"message": "Hallo Welt!"
	},
	{
		"language_code": "zh",
		"message": "你好，世界！"
	},
	{
		"language_code": "ja",
		"message": "こんにちは、世界！"
	},
	{
		"language_code": "hi",
		"message": "नमस्ते दुनिया!"
	},
	{
		"language_code": "ar",
		"message": "مرحبا بالعالم!"
	}

```

2. 터미널을 열고 다음 KV 명령을 입력하여 번역 파일 KV 입력을 생성합니다.

```sh
npx wrangler kv key put hello-world.json --path hello-world.json --namespace-id=<ENTER_NAMESPACE_ID_HERE>
```

3. Workers 코드를 업데이트하여 허용 언어 헤더의 언어를 기반으로 번역 된 HTML 파일을 제공하기 위해 논리를 추가하십시오.

    ```js {2, 26-63}
    import mime from 'mime';
    import parser from 'accept-language-parser'

    interface Env {
    assets: KVNamespace;
    }

    export default {
      async fetch(request, env, ctx): Promise<Response> {
        //반환 오류 if not a get request
        if(request.method !== 'GET'){
          return new Response('Method Not Allowed', {
            status: 405,
          })
        }

        //키가 누락된 경우 url & return 오류에서 키 가져오기
        const parsedUrl = new URL(request.url)
        const key = parsedUrl.pathname.replace(/^\/+/, '') //어떤 preceding/'s를 벗기십시오
        if(!key){
          return new Response('Missing path in URL', {
            status: 400
          })
        }

        	//번역 경로에 대한 핸들러 추가 (초회 반환)
        	if(key === 'hello-world'){
        		//QXQX0405XQ QXKV의 요청과 번역에서 언어 헤더를 검색
        		const languageHeader = request.headers.get('Accept-Language') || 'en' //기본 영어
        		const translations : {
        			"language_code": string,
        			"message": string
        		}[] = await env.assets.get('hello-world.json', 'json') || [];

        		//요청된 언어 추출
        		const supportedLanguageCodes = translations.map(item => item.language_code)
        		const languageCode = parser.pick(supportedLanguageCodes, languageHeader, {
        			loose: true
        		})

        		//선택한 언어에 대한 메시지를 가져옵니다
        		let selectedTranslation = translations.find(item => item.language_code === languageCode)
        		if(!selectedTranslation) selectedTranslation = translations.find(item => item.language_code === "en")
        		const helloWorldTranslated = selectedTranslation!['message'];

        		//번역된 HTML을 생성하고 반환
        		const html = `<!DOCTYPE html>
        		<html>
        			<head>
        				<title>Hello World translation</title>
        			</head>
        			<body>
        				<h1>${helloWorldTranslated}</h1>
        			</body>
        		</html>
        		`
        		return new Response(html, {
        			status: 200,
        			headers: {
        				'Content-Type': 'text/html; charset=utf-8'
        			}
        		})
        	}

        //키 경로에서 mimetype을 가져옵니다
        const extension = key.split('.').pop();
        let mimeType = mime.getType(extension) || "text/plain";
        if (mimeType.startsWith("text") || mimeType === "application/javascript") {
          mimeType += "; charset=utf-8";
        }

        //Workers KVQQXQ 스토어에서 값을 가져 와서 찾을 경우 반환
        const value = await env.assets.get(key, 'arrayBuffer')
        if(!value){
          return new Response("Not found", {
            status: 404
          })
        }

        //WorkersXQ 신청에서 KV 상점에서 가치를 가진 응답을 반환하십시오
        return new Response(value, {
          status: 200,
          headers: new Headers({
            "Content-Type": mimeType
          })
        });

    },
    } satisfies ExportedHandler<Env>;

    ```

이 새로운 코드는 특정 엔드포인트를 제공합니다,`/hello-world`번역된 응답을 제공할 것입니다. 이 URL이 접근될 때, 우리의 노동자 부호는 클라이언트에 의해 요구된 언어에 첫째로 retrieve`Accept-Language`요청 헤더와 우리의 KV 상점에서 번역`hello-world.json`주요. 그것은 그런 다음 번역된 메시지를 얻고 생성 된 HTML을 반환합니다.

Worker 응용 프로그램에 액세스 할 때`https://<YOUR-WORKER-HOSTNAME>/hello-world`, 우리는 우리의 응용 프로그램이 제대로 번역 된 "Hello World"메시지를 반환한다는 것을 알 수 있습니다.

브라우저의 개발자 콘솔에서 Locale 언어를 변경하십시오 (크롬 브라우저에서, 실행`Show Sensors`현지에 대한 드롭다운 선택 얻기 위해). Worker가 이제 현지 언어로 번역된 메시지를 반환한다는 것을 알 수 있습니다.

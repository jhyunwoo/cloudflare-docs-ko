## Workers KV를 가진 노선 요구

이 예에서 멀티텐트 전자 상거래 응용 프로그램은 Cloudflare Workers에 내장되어 있습니다. 각 상점 정면은 다른 tenant이고 그것의 자신의 외부 웹 서버가 있습니다.
우리의 Cloudflare Worker는 storefront ID에 따라 모든 storefronts 및 routing 요청에 대한 모든 요청을 수신하는 책임입니다.

시연의 단순성을 위해, storefront는 storefront ID를 포함하는 경로 요소로 식별됩니다.
`https://<WORKER_HOSTNAME>/<STOREFRONT_ID>/...`storefront의 URL 패턴입니다. subdomains를 사용하여 실제 시나리오에서 매장을 식별 할 수 있습니다.

    ```js title="index.ts" collapse={17-22, 34-39, 69-73}

    //Workers KVXQ에 저장된 자료를 여정:
    //키: "storefrontA" | 가치: {"origin": "https://storefrontA-server.example.com"}
    //키: "storefrontB" | 가치: {"origin": "https://storefrontB-server.example.com"}

    interface Env {
    ROUTING_CONFIG: KVNamespace;
    }

    export default {
      async fetch(request, env, ctx) {

        //경로에서 storefront ID를 추출하는 URL을 파
        const url = new URL(request.url);
        const pathParts = url.pathname.split('/').filter(part => part !== '');

        //storefront ID가 경로에 제공되면, 그렇지 않으면 400을 반환
        if (pathParts.length === 0) {
          return new Response('Welcome to our multi-tenant platform. Please specify a storefront ID in the URL path.', {
            status: 400,
            headers: { 'Content-Type': 'text/plain' }
          });
        }

        //첫번째 경로 세그먼트에서 storefront ID를 추출
        const storefrontId = pathParts[0];

        try {
          //env.ROUTING CONFIG를 사용하여 KV의 저장소 구성을 찾습니다.
          const storefrontConfig = await env.ROUTING_CONFIG.get<{
        			origin: string;
        		}>(storefrontId, {type: "json"});

          //구성이 없는 경우, 404을 반환
          if (!storefrontConfig) {
            return new Response(`Storefront "${storefrontId}" not found.`, {
              status: 404,
              headers: { 'Content-Type': 'text/plain' }
            });
          }

          //Origin 서버에 대한 새로운 URL 구축
          //전달할 때 경로에서 storefront ID 제거
          const newPathname = '/' + pathParts.slice(1).join('/');
          const originUrl = new URL(newPathname, storefrontConfig.origin);
          originUrl.search = url.search;

          //Origin 서버에 새 요청 만들기
          const originRequest = new Request(originUrl, {
            method: request.method,
            headers: request.headers,
            body: request.body,
            redirect: 'follow'
          });

          //Origin 서버에 요청 보내기
          const response = await fetch(originRequest);

        		console.log(response.status)

          //응답을 복제하고 사용자 정의 헤더를 추가
          const modifiedResponse = new Response(response.body, response);
          modifiedResponse.headers.set('X-Served-By', 'Cloudflare Worker');
          modifiedResponse.headers.set('X-Storefront-ID', storefrontId);

          return modifiedResponse;

        } catch (error) {
          //모든 오류 처리
          console.error(`Error processing request for storefront ${storefrontId}:`, error);
          return new Response('An error occurred while processing your request.', {
            status: 500,
            headers: { 'Content-Type': 'text/plain' }
          });
        }

    }
    } satisfies ExportedHandler<Env>;

    ```

이 예에서 Cloudflare Worker는 요청을 받고 URL 경로에서 storefront ID를 추출합니다.
storefront ID는 Workers KV에서 원래 서버 URL을 찾는 데 사용됩니다.`get()`방법.
요청은 원래 서버로 전달되고 응답은 클라이언트로 반환되기 전에 사용자 정의 헤더를 포함하도록 수정됩니다.

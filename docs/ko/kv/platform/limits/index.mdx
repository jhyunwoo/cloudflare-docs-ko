| 제품 정보                                                                    | 무료 다운로드         | 계정 만들기   |
| ------------------------------------------------------------------------ | --------------- | -------- |
| 자세히보기                                                                    | 일 당 100,000의 읽음 | 제한 없음    |
| 다른 키로 쓰기                                                                 | 일 당 1,000의 쓰기   | 제한 없음    |
| 동일한 키에 쓰기                                                                | 초당 1            | 초당 1     |
| 작업/작업[^1]                                                                | 1000            | 1000     |
| 계정 당 네임스페이스                                                              | 1,000           | 1,000    |
| 저장/account                                                               | 1개 GB           | 제한 없음    |
| 저장/namespace                                                             | 1개 GB           | 제한 없음    |
| 핵심/이름공간                                                                  | 제한 없음           | 제한 없음    |
| 키 크기                                                                     | 512 바이트         | 512 바이트  |
| 핵심 메타데이터                                                                 | 1024 바이트        | 1024 바이트 |
| 가치 크기                                                                    | 25 미브           | 25 미브    |
| 이름 \*[`cacheTtl`](/kv/api/read-key-value-pairs/#cachettl-parameter) [^2] | 30 초            | 30 초     |

[^1]: 단 하나 주장 안에, 노동자는 외부 서비스에 1,000 까지 가동을 만들 수 있습니다 (예를 들면, 500 Workers KVXQ는 읽습니다 500 R2XQ는 읽습니다). Workers KV는 외부 서비스에 1개의 요구에 대 한 대량 요구.

[^2]: 최대 값은[`Number.MAX_SAFE_INTEGER`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/MAX_SAFE_INTEGER).

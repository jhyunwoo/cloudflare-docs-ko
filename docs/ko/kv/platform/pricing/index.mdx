## 가격 FAQ

#### KV를 통해 쓰기 때[REST API를](/api/resources/kv/subresources/namespaces/subresources/keys/methods/bulk_update/), 어떻게 청구됩니까?

각 키 값 쌍에서`PUT`요청은 단일 쓰기로 계산되며, 각 통화와 동일한 방법`PUT`Workers API에서 쓰기로 계산합니다. REST API를 통해 5,000개의 키를 작성하여 5,000개의 키를 작성합니다.`PUT`직장에서 호출.

#### 대시보드 또는 Wrangler (클릭) 계산에서 쿼리 할 수 있습니까?

예, Cloudflare 대시보드XQ 또는 Wrangler를 통해 어떤 작업, 업데이 트 (writing) 키, 삭제 키, 청구 가능한 KV 사용으로 네임스페이스에서 키를 나열.

#### 어떤 작업 처리 수수료?

모든 작업 incur 요금이 부과되지 않은 키에 대한 fetches 포함`null`(Workers API) 또는`HTTP 404`(REST API). 이 작업은 여전히 KV의 인프라를 가로 질러줍니다.

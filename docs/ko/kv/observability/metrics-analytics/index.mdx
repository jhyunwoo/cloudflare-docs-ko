KV는 계정의 모든 네임스페이스에서 요청 및 저장을 검사할 수 있도록 분석합니다.

표시된 미터[Cloudflare 대시보드](https://dash.cloudflare.com/)차트는 Cloudflare[GraphQL 분석 API](/analytics/graphql-api/). 미터에 접근할 수 있습니다[프로그램](#query-via-the-graphql-api)GraphQL 또는 HTTP 클라이언트를 통해.

## 미터

KV는 현재 아래 미터를 드러냅니다:

| 데이터셋  | GraphQL Dataset 이름           | 이름 \*                                      |
| ----- | ---------------------------- | ------------------------------------------ |
| 영업 시간 | `kvOperationsAdaptiveGroups` | 이 데이터 세트는 KV 네임스페이스로 제작된 작업입니다.            |
| 제품 정보 | `kvStorageAdaptiveGroups`    | 이 dataset는 KV 네임스페이스의 저장 세부사항으로 이루어져 있습니다. |

미터는 지난 31 일 동안 (그리고 유지됩니다) 수 있습니다.

## 대시보드에서 미터보기

KV에 대한 Per-namespace 분석은 Cloudflare 대시보드에서 사용할 수 있습니다. 데이터베이스의 현재와 역사적인 메트릭스를 볼 수 있습니다.

1. Cloudflare 대시보드에서, 가십시오**Workers KV**사이트 맵

   <DashButton url="/?to=/:account/workers/kv/namespaces" />
2. 기존 네임스페이스를 선택합니다.
3. 선택하기**미터**탭.

쿼리에 시간 창을 선택 할 수 있습니다. 이 기본값은 마지막 24시간입니다.

## GraphQL API를 통해 쿼리

KV 네임스페이스에 대한 프로그래밍 가능한 쿼리 분석[GraphQL 분석 API](/analytics/graphql-api/). 이 API는 Cloudflare 대시보드와 동일한 datasets를 쿼리하고 GraphQL를 지원합니다[관련 상품](/analytics/graphql-api/features/discovery/introspection/).

시작하기에[GraphQL 분석 API](/analytics/graphql-api/), 설정에 문서를 따르십시오[GraphQL Analytics API 인증](/analytics/graphql-api/getting-started/authentication/).

GraphQL API를 사용하여 KV의 데이터 세트를 검색하려면 제공해야합니다.`accountTag`Cloudflare를 가진 여과기 계정 ID. KV를 위한 GraphQL 데이터 세트는 다음을 포함합니다:

- `kvOperationsAdaptiveGroups`
- `kvStorageAdaptiveGroups`

### 이름 \*

다음은 KV 분석에 대한 정보를 검색하는 데 사용할 수있는 일반적인 GraphQL 쿼리입니다. 이 쿼리는 변수의 사용`$accountTag`, `$date_geq`, `$date_leq`·`$namespaceId`GraphQL 변수로 설정하거나 라인에 교체해야 합니다. 이 변수는 다음과 같습니다:

```json
{
	"accountTag": "<YOUR_ACCOUNT_ID>",
	"namespaceId": "<YOUR_KV_NAMESPACE_ID>",
	"date_geq": "2024-07-15",
	"date_leq": "2024-07-30"
}
```

#### 영업 시간

읽음, 쓰기, 삭제 및 목록 작업을 쿼리하기 위해`namespaceId`주어진 날짜 범위를 위해 (`start`·`end`), 그룹`date`·`actionType`:

```graphql graphql-api-explorer
query KvOperationsSample(
	$accountTag: string!
	$namespaceId: string
	$start: Date
	$end: Date
) {
	viewer {
		accounts(filter: { accountTag: $accountTag }) {
			kvOperationsAdaptiveGroups(
				filter: { namespaceId: $namespaceId, date_geq: $start, date_leq: $end }
				limit: 10000
				orderBy: [date_DESC]
			) {
				sum {
					requests
				}
				dimensions {
					date
					actionType
				}
			}
		}
	}
}
```

읽힌 작업에 대한 대기 시간의 배포를 쿼리하기 위해`namespaceId`주어진 날짜 범위 안에 (`start`, `end`):

```graphql graphql-api-explorer
query KvOperationsSample2(
	$accountTag: string!
	$namespaceId: string
	$start: Date
	$end: Date
) {
	viewer {
		accounts(filter: { accountTag: $accountTag }) {
			kvOperationsAdaptiveGroups(
				filter: {
					namespaceId: $namespaceId
					date_geq: $start
					date_leq: $end
					actionType: "read"
				}
				limit: 10000
			) {
				sum {
					requests
				}
				dimensions {
					actionType
				}
				quantiles {
					latencyMsP25
					latencyMsP50
					latencyMsP75
					latencyMsP90
					latencyMsP99
					latencyMsP999
				}
			}
		}
	}
}
```

모든 KV 네임스페이스에서 계정 전체 읽기, 쓰기, 삭제 및 목록 작업을 쿼리하려면:

```graphql graphql-api-explorer
query KvOperationsAllSample($accountTag: string!, $start: Date, $end: Date) {
	viewer {
		accounts(filter: { accountTag: $accountTag }) {
			kvOperationsAdaptiveGroups(
				filter: { date_geq: $start, date_leq: $end }
				limit: 10000
			) {
				sum {
					requests
				}
				dimensions {
					actionType
				}
			}
		}
	}
}
```

#### 제품 정보

저장 세부사항을 쿼리하기 위하여 (`keyCount`·`byteCount`) 주어진 날짜 범위의 각 일 동안 KV namespace의:

```graphql graphql-api-explorer
query Viewer(
	$accountTag: string!
	$namespaceId: string
	$start: Date
	$end: Date
) {
	viewer {
		accounts(filter: { accountTag: $accountTag }) {
			kvStorageAdaptiveGroups(
				filter: { date_geq: $start, date_leq: $end, namespaceId: $namespaceId }
				limit: 10000
				orderBy: [date_DESC]
			) {
				max {
					keyCount
					byteCount
				}
				dimensions {
					date
				}
			}
		}
	}
}
```

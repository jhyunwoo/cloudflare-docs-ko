KV 네임스페이스는 함께 사용할 수 있습니다.[제품정보](/workers/wrangler/environments/). 이것은 당신이 KV 바인딩을 나타내는 당신의 노동자에 있는 부호가 있을 때 유용합니다`MY_KV`, 그리고 당신은 다른 KV namespaces에 이 바인딩 점을 가지고 가고 (예를 들면, staging와 생산을 위해 하나).

Wrangler 파일에 있는 뒤에 오는 부호는 2개의 다른 KV 네임스페이스가 있는 2개의 환경이 있는 방법을 보여줍니다 그러나 동일한 바인딩 이름:

<WranglerConfig>
  ```jsonc
  {
  	"env": {
  		"staging": {
  			"kv_namespaces": [
  				{
  					"binding": "MY_KV",
  					"id": "e29b263ab50e42ce9b637fa8370175e8"
  				}
  			]
  		},
  		"production": {
  			"kv_namespaces": [
  				{
  					"binding": "MY_KV",
  					"id": "a825455ce00f4f7282403da85269f8ea"
  				}
  			]
  		}
  	}
  }
  ```
</WranglerConfig>

두 가지 다른 KV 네임스페이스에 대한 동일한 바인딩 이름을 사용하여 더 읽을 수 있습니다.

내 계정`staging`환경,`MY_KV.get("KEY")`namespace ID에서 읽을 것`e29b263ab50e42ce9b637fa8370175e8`. 에서`production`환경,`MY_KV.get("KEY")`namespace ID에서 읽을 것`a825455ce00f4f7282403da85269f8ea`.

값을 삽입하려면`staging`KV 네임스페이스, 실행:

```sh
wrangler kv key put --env=staging --binding=<YOUR_BINDING> "<KEY>" "<VALUE>"
```

이름 \*`--namespace-id`항상 독특합니다 (묶는 이름과는 달리), 당신은 지정할 필요가 없습니다`--env`인자:

```sh
wrangler kv key put --namespace-id=<YOUR_ID> "<KEY>" "<VALUE>"
```

:::카트로션

버전 3.60.0부터, Wrangler KV 명령 지원`kv ...`구문. 당신은 3.60.0의 밑에 Wrangler의 버전을 사용하는 경우에, 명령은 따릅니다`kv:...`구문. 더 알아보기`kv:...`구문에서[Wrangler 명령](/kv/reference/kv-commands/)KV 페이지.
주요 특징

이름 \*`kv`subcommands는 또한 당신이 선택을 가진 환경을 지정할 수 있습니다`--env`플래그.

옵션으로 환경 지정`--env`플래그는 같은 코드를 실행하지만 다른 KV 네임스페이스와 함께 WorkersXQXQXQXQXQXQXQ를 게시 할 수 있습니다.

예를 들어 KV 데이터에 KV 네임스페이스를 KV 데이터에 별도의 시효 및 생산 KVXQ를 사용할 수 있습니다.

<WranglerConfig>
  ```jsonc
  {
  	"$schema": "./node_modules/wrangler/config-schema.json",
  	"type": "webpack",
  	"name": "my-worker",
  	"account_id": "<account id here>",
  	"route": "staging.example.com/*",
  	"workers_dev": false,
  	"kv_namespaces": [
  		{
  			"binding": "MY_KV",
  			"id": "06779da6940b431db6e566b4846d64db"
  		}
  	],
  	"env": {
  		"production": {
  			"route": "example.com/*",
  			"kv_namespaces": [
  				{
  					"binding": "MY_KV",
  					"id": "07bc1f3d1f2a4fd8a45a7e026e2681c6"
  				}
  			]
  		}
  	}
  }
  ```
</WranglerConfig>

위 Wrangler 파일로 지정할 수 있습니다.`--env production`KV 액션을 수행 할 때 KV 네임스페이스`MY_KV`이름 \*`env.production`.

예를 들어 위의 Wrangler 파일과 함께 KVXQ 인스턴스에서 값을 얻을 수 있습니다.

```sh
wrangler kv key get --binding "MY_KV" --env=production "<KEY>"
```

## 회사연혁

아래는 WranglerXQ 명령을 Workers KV.

### `kv:...`구문 결정

버전 3.60.0부터, Wrangler는 지원합니다`kv ...`구문. 3.60.0 이하의 버전을 사용하는 경우, 명령은 다음과 같습니다.`kv:...`구문.

더 보기`kv:...`구문은 버전 3.60.0 이상의 버전에서 deprecated이며 미래의 주요 버전에서 제거됩니다.

예를 들어, 명령어를 사용하여`kv ...`같은 구문 :

```sh
wrangler kv namespace list
wrangler kv key get <KEY>
wrangler kv bulk put <FILENAME>
```

동일한 명령을 사용하여`kv:...`같은 구문 :

```sh
wrangler kv:namespace list
wrangler kv:key get <KEY>
wrangler kv:bulk put <FILENAME>
```

### 왜 즉시 키 값 쌍의 업데이트 값을 볼 수 없습니까?

Workers KV는 Cloudflare 네트워크의 맞은편에 자료를 몹니다. 따라서, 당신은 최대에 대한 캐시 된 값을 읽을 수 있습니다[캐시 TTL](/kv/api/read-key-value-pairs/#cachettl-parameter)시간.

### Workers KV는 결국 일관된 또는 강하게 일관되게 합니까?

QXQX0666XQQ KV는 결국 일관되게 입니다.

Workers KV는 중앙 상점에 자료 저장하고 잡종 푸시/풀 복제 접근을 통해 모든 CloudflareXQ 위치에 자료를 복제합니다. 이것은 키 값 쌍의 이전 값이 긴 위치에 볼 수 있음을 의미합니다.[캐시 TTL](/kv/api/read-key-value-pairs/#cachettl-parameter). 이것은 Workers KV가 결국 일관된 것을 의미합니다.

Workers KV에 가동[REST API를](/api/resources/kv/)같은 것[REST API의 한계](/fundamentals/api/reference/limits/). 이 제한은 모든 Cloudflare REST API 요청에 따라 공유됩니다.

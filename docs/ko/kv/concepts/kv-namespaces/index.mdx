## WranglerX0210XQXQ를 통한 KV 네임스페이스

KV 네임스페이스를 작업자에게 바인딩하려면 아래 객체의 배열을 아래 객체로 지정합니다.`kv_namespaces`주요.

- `binding` <Type text="string" /> <MetaInfo text="required" />

  - KV 네임스페이스를 참조하는 데 사용되는 바인딩 이름.

- `id` <Type text="string" /> <MetaInfo text="required" />

  - KV 네임스페이스의 ID.

- `preview_id` <Type text="string" /> <MetaInfo text="optional" />

  - KV 네임스페이스의 ID`wrangler dev`.

예:

<WranglerConfig>
  ```jsonc
  {
  	"kv_namespaces": [
  		{
  			"binding": "<TEST_NAMESPACE>",
  			"id": "<TEST_ID>"
  		}
  	]
  }
  ```
</WranglerConfig>

## 대시보드

Cloudflare 대시보드에 있는 당신의 노동자에 namespace를 묶기 위하여:

1. Cloudflare 대시보드에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />
2. 자주 묻는 질문**작업자**.
3. 제품정보**계정 설정** > **회사 소개**.
4. 제품정보**더 보기**.
5. 제품정보**KV 이름공간**.
6. 원하는 변수 이름을 입력 (묶음의 이름).
7. KV 네임스페이스를 선택하세요.
8. 제품정보**계정 만들기**.

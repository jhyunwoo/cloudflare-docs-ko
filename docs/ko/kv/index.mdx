<Description>
  Global, low-latency, key-value 데이터 저장을 만듭니다.
</Description>

<Plan type="workers-all" />

Workers KV는 전 세계적으로 데이터를 저장하고 검색 할 수있는 데이터 저장소입니다. Workers KV로, 당신은 낮은 대기권과 높은 읽힌 양을 지원하는 동적 및 performant APIs 및 웹 사이트를 구축 할 수 있습니다.

예를 들어, Workers KV를 사용할 수 있습니다.

- 캐싱 API 응답.
- 사용자 설정 저장 / p참고 자료.
- Storing 사용자 인증 세부 사항.

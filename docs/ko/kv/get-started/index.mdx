Workers KV는 당신의 높은 처리량 세계적인 저장을 제공합니다[Cloudflare Workers](/workers/)신청. Workers KV는 사용자 구성 자료, 라우팅 데이터, A/B 테스트 구성 및 인증 토큰을 저장하는 데 이상적입니다. read-heavy 워크로드에 적합합니다.

이 가이드는 당신을 통해 지시합니다:

- KV 네임스페이스 만들기.
- KV 네임스페이스를 Cloudflare 작업자.
- KV 네임스페이스에서 키값 쌍을 읽으십시오.

Wrangler CLI를 통해 이러한 작업을 수행하거나 Cloudflare 대시보드Q를 통해 수행 할 수 있습니다.

## 빠른 시작

설정 단계와 시작하기XQ를 신속하게 건너려면 아래 버튼을 클릭하십시오.

[![Cloudflare에 배포](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/cloudflare/docs-examples/tree/update/kv/kv/kv-get-started)

GitHub 계정에서 저장소를 생성하고 Cloudflare WorkersXQ에 응용 프로그램을 배포합니다. Cloudflare WorkersXQ에 익숙한 경우 이 옵션을 사용하고 단계별 지도를 건너 뛰기를 바랍니다.

당신은 수동으로 Cloudflare Workers에 새로운 경우에 단계를 따르고 싶을지도 모릅니다.

## 3. KV namespace에 당신의 노동자를 바짝 죄십시오

KV 네임스페이스로 작업자를 연결하기 위해 바인딩을 작성해야 합니다.[회사 소개](/workers/runtime-apis/bindings/)Workers는 KV, Cloudflare 개발자 플랫폼과 같은 리소스에 액세스 할 수 있습니다.

:::주최\[배경]

묶음은 당신의 노동자가 외부 자원과 어떻게 상호 작용하는지[KV 네임스페이스](/kv/concepts/kv-namespaces/). 바인딩은 Workers 런타임이 코드를 제공합니다. Wrangler 파일에서 변수 이름을 선언할 수 있으며, 이 변수를 통해 해당 리소스에 바인딩할 수 있습니다. 모든 바인딩의 변수 이름과 행동은 노동자를 배치 할 때 결정됩니다.

더 알아보기[환경 정책](/kv/reference/environments/)더 많은 정보.

:::

    </Steps>

         ```sh
         npm run deploy
         ```

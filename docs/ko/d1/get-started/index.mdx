이 가이드는 당신을 통해 지시합니다:

- D1, Cloudflare의 기본 Serverless SQL 데이터베이스를 사용하여 첫 번째 데이터베이스를 만듭니다.
- schema를 만들고 명령 줄을 통해 데이터베이스를 쿼리합니다.
- 연결하기[Cloudflare 작업자](/workers/)D1 데이터베이스에 바인딩을 사용하여 D1 데이터베이스 프로그래밍.

CLI를 통해 이러한 작업을 수행하거나 Cloudflare 대시보드XQ를 통해 수행 할 수 있습니다.

## 2. 데이터베이스 만들기

D1 데이터베이스는 다른 많은 SQL 데이터베이스와 마찬가지로 개념적입니다. 데이터베이스는 하나 이상의 테이블을 포함 할 수 있으며, 그 테이블을 쿼리 할 수있는 능력, 옵션 인덱스. D1는 익숙한 사용[SQL 쿼리 언어](https://www.sqlite.org/lang.html)(SQLite에 의해 사용).

먼저 D1 데이터베이스를 만들려면:

         :::참조

## 3. 당신의 D1 데이타베이스에 당신의 노동자를 바짝 죄십시오

D1 데이터베이스에 연결하기 위해 작업자에게 바인딩을 작성해야 합니다.[회사 소개](/workers/runtime-apis/bindings/)Workers는 D1, Cloudflare 개발자 플랫폼과 같은 리소스에 액세스 할 수 있습니다.

D1 데이터베이스를 작업자에게 바인딩하려면:

<Tabs syncKey="CLIvDash">
  <TabItem label="제품정보">
    Wrangler 설정 파일에 바인딩을 자동으로 추가할 수 있습니다.`wrangler d1 create`명령 (단계 3의[2. 데이터베이스 만들기](/d1/get-started/#2-create-a-database)).

    그러나 수동으로 바인딩을 추가하려면 아래 단계를 따르십시오.

    <Steps>
      1. 2단계에서 획득한 라인 복사[2. 데이터베이스 만들기](/d1/get-started/#2-create-a-database)당신의 맨끝에서.
      2. Wrangler 파일의 끝에 추가하십시오.

         <WranglerConfig>
           ```jsonc
           {
             "d1_databases": [
               {
                 "binding": "prod_d1_tutorial", //env.DB에 있는 당신의 노동자에서 유효한
                 "database_name": "prod-d1-tutorial",
                 "database_id": "<unique-ID-for-your-database>"
               }
             ]
           }
           ```
         </WranglerConfig>

         특정한:

         - value (string) 설정`binding`이름 \***바인딩 이름**, 그리고 당신의 노동자에 있는 참고 자료 이 데이타베이스에 사용됩니다. 이 튜토리얼에서 바인딩 이름을`prod_d1_tutorial`.
         - 바인딩 이름은이어야 합니다[유효한 JavaScript 가변 이름](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Grammar_and_types#variables). 예를 들면,`binding = "MY_DB"`또는`binding = "productionDB"`둘 다 바인딩을 위한 유효한 이름일 것입니다.
         - 당신의 의무는 당신의 노동자에서 유효합니다`env.<BINDING_NAME>`D1[모델 번호: Workers 바인딩 API](/d1/worker-api/)이 바인딩에 노출됩니다.
    </Steps>

    :::참조
    실행할 때`wrangler d1 create`명령, 클라이언트 API 패키지 (D1 API 및 데이터베이스 클래스 구현)는 자동으로 설치됩니다. D1 Workers Binding API, 참조[Workers 바인딩 API](/d1/worker-api/).
    :::

    D1 데이터베이스도 결합할 수 있습니다.[Pages 기능](/pages/functions/). 자세한 내용은 참조[D1를 위한 의무 기능](/pages/functions/bindings/#d1-databases).
  </TabItem>

  <TabItem label="대시보드">

    <Steps>

         <DashButton url="/?to=/:account/workers-and-pages" />

      3. 오시는 길**회사 소개**탭.

      5. 제품정보**D1 데이터베이스** > **바인딩**.
      6. 이름 당신의 바인딩에서**변수 이름**, 다음을 선택합니다`prod-d1-tutorial`D1 데이터베이스에서 생성[단계 2](/d1/get-started/#2-create-a-database)드롭다운 메뉴에서. 이 튜토리얼을 위해, 당신의 바인딩을 명명`prod_d1_tutorial`.

### 직장 내의 쿼리 작성

데이터베이스를 설정 한 후 작업자 내에서 SQL 쿼리를 실행하십시오.

<Tabs syncKey="CLIvDash">
  <TabItem label="제품정보">
    <Steps>
      1. 내 계정`d1-tutorial`노동자와 열려있는`index.ts`파일. 더 보기`index.ts`파일은 D1와 작업자의 상호 작용을 구성하는 곳입니다.
      2. 자주 묻는 질문`index.ts`.
      3. 다음 코드를 붙여넣기 snippet 당신의`index.ts`파일 :

         <Tabs syncKey="workersExamples">
           <TypeScriptExample filename="index.ts" omitTabs={true}>
             ```typescript
             export interface Env {
             	//Wrangler config 파일의 이름을 'binding'의 값으로 설정하면
             	//정의된 변수 이름과 "DB"를 대체합니다.
             	prod_d1_tutorial: D1Database;
             }

             export default {
             	async fetch(request, env): Promise<Response> {
             		const { pathname } = new URL(request.url);

             		if (pathname === "/api/beverages") {
             			//바인딩 이름으로 `DB`를 사용하지 않았다면 여기에서 변경하십시오.
             			const { results } = await env.prod_d1_tutorial.prepare(
             				"SELECT * FROM Customers WHERE CompanyName = ?",
             			)
             				.bind("Bs Beverages")
             				.run();
             			return Response.json(results);
             		}

             		return new Response(
             			"Call /api/beverages to see everyone who works at Bs Beverages",
             		);
             	},
             } satisfies ExportedHandler<Env>;
             ```
           </TypeScriptExample>

           <TabItem label="Python" icon="seti:python">

         1. D1 데이터베이스에 바인딩을 정의합니다. 이 바인딩은 일치합니다`binding`설정 값[Wrangler 구성 파일](/workers/wrangler/configuration/)이름 \*`d1_databases`.
         2. Query를 사용하여 데이터베이스`env.prod_d1_tutorial.prepare`관련 기사[자주 묻는 질문](/d1/worker-api/d1-database/#prepare)위시리스트`?`자주 묻는 질문
         3. 이름 \*`bind()`안전하게 그 위너에게 가치를 부여합니다. 실제 응용 프로그램에서 사용자가 통과 할 수 있습니다.`CompanyName`그들은 결과 목록을 원한다. 사용 방법`bind()`arbitrary SQL ( "SQL injection"으로 알려진) 실행에서 사용자를 방지하고 데이터베이스를 삭제하거나 수정합니다.

         5. 쿼리 결과를 반환, 어쨌든, JSON 형식으로`Response.json(results)`.

         			});

         		return new Response(
         			"Call /api/beverages to see everyone who works at Bs Beverages"
         		);

         };

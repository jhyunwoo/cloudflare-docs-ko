D1는 계정의 모든 데이터베이스에서 빌링 메트릭을 추적하는 분석 결과를 노출시킵니다.

표시된 미터[Cloudflare 대시보드](https://dash.cloudflare.com/)Cloudflare[GraphQL 분석 API](/analytics/graphql-api/). 미터에 접근할 수 있습니다[프로그램](/d1/observability/metrics-analytics/#query-via-the-graphql-api)GraphQL 또는 HTTP 클라이언트를 통해.

## 대시보드의 메트릭 보기

D1를 위한 총 계정 청구가능한 사용법 분석은 Cloudflare 대시보드에서 유효합니다. 계정의 현재와 과거 미터를 볼 수:

1. Cloudflare 대시보드에서, 가십시오**계정 관리**사이트 맵

   <DashButton url="/?to=/:account/billing" />
2. 오시는 길**Billable 사용법**.

여기에서 귀하 자신의 계정의 D1 사용의 차트를 볼 수 있습니다.

최대 30 일 동안 청구 가능한 사용 내역이 저장됩니다.

## 청구 알림

사용법 근거한 청구 통보는 안에 유효합니다[Cloudflare 대시보드](https://dash.cloudflare.com)사용자를 위해 총 계정 사용을 모니터링.

뒤에 오는 미터에 통보는 유효합니다:

- 행 읽기
- 연락처

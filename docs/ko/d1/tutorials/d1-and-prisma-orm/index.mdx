## Prisma ORM은 무엇입니까?

[프리즈마 ORM](https://www.prisma.io/orm)차세대 JavaScript 및 TypeScript ORM은 직관적 인 데이터 모델, 자동화 된 마이그레이션, 유형 안전 및 자동 컴파일 덕분에 데이터베이스와 함께 작업 할 때 개발자 경험의 새로운 수준을 잠금 해제합니다.

Prisma ORM에 대한 자세한 내용을 보려면, 참조[Prisma 문서](https://www.prisma.io/docs).

## D1를 CloudflareXQ로 쿼리 Prisma ORM을 사용하는 노동자

이 튜토리얼은 Cloudflare를 설정하고 배포하는 방법을 보여줍니다 D1 데이터베이스에 액세스하는 작업자.

## 빠른 시작

단계와 시작하기XQ를 신속하게 건너뛰고 싶다면,**Cloudflare에 배포**아래.

[![Cloudflare에 배포](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/cloudflare/docs-examples/tree/d1-prisma/d1/query-d1-using-prisma)

GitHub 계정에서 저장소를 생성하고 Cloudflare WorkersXQ에 응용 프로그램을 배포합니다. Cloudflare WorkersXQ에 익숙한 경우에 이 선택권을 이용하고, 단계별 지도를 건너뛰기를 바랍니다.

당신은 수동으로 Cloudflare Workers에 새로운 경우에 단계를 따르고 싶을지도 모릅니다.

## 자주 묻는 질문

- [`Node.js`](https://nodejs.org/en/)·[`npm`](https://docs.npmjs.com/getting-started)기계에 설치.
- ·[Cloudflare 계정](https://dash.cloudflare.com).

## 1. Cloudflare 작업자

터미널을 열고 다음 명령을 실행하여 Cloudflare Cloudflare의 작업자[`hello-world`](https://github.com/cloudflare/workers-sdk/tree/4fdd8987772d914cf50725e9fa8cb91a82a6870d/packages/create-cloudflare/templates/hello-world)템플릿:

```sh
npm create cloudflare@latest prisma-d1-example -- --type hello-world
```

터미널에서 프로젝트에 관련된 일련의 질문을 받게됩니다.

1. 이름 \*`yes`TypeScript를 사용하기 위하여.
2. 이름 \*`no`작업자를 배치합니다.

## 2. Prisma ORM 초기화

:::참조

D1는 Prisma ORM에서 지원됩니다[v5.12.0의](https://github.com/prisma/prisma/releases/tag/5.12.0).

:::

Prisma ORM을 설정하려면 프로젝트 디렉토리로 이동하고 Prisma CLI를 설치하십시오.

```sh
cd prisma-d1-example
```

<PackageManagers pkg="prisma" dev />

다음, Prisma 클라이언트 패키지와 D1에 대한 드라이버 어댑터를 설치:

<PackageManagers pkg="@prisma/client @prisma/adapter-d1" />

마지막으로 Prisma ORM에 의해 필요한 파일을 부팅 :

<PackageManagers type="exec" pkg="prisma" args="init --datasource-provider sqlite" />

위의 명령:

1. 새 디렉토리 만들기`prisma`그것은 당신의[Prisma 스키마](https://www.prisma.io/docs/orm/prisma-schema/overview)파일.
2. 계정 만들기`.env`Prisma CLI에 의해 읽을 환경 변수를 구성하는 데 사용되는 파일.

이 튜토리얼에서, 당신은 필요하지 않습니다`.env`Prisma ORM과 D1 사이의 연결 이후 파일이 발생할 것입니다.[관련 제품](/workers/runtime-apis/bindings/). 다음 단계는이 바인딩을 설정하여 당신을 지시합니다.

이용하기[운전사 접합기](https://www.prisma.io/docs/orm/overview/databases/database-drivers#driver-adapters)현재 Preview에서 기능, 당신은 명시적으로 그것을 통해 활성화해야합니다`previewFeatures`현장에`generator`블록.

자주 묻는 질문`schema.prisma`파일 및 조정`generator`다음과 같이 반영하는 구획:

```prisma title="schema.prisma"
generator client {
  provider        = "prisma-client-js"
  output          = "../src/generated/prisma"
  previewFeatures = ["driverAdapters"]
}
```

## 3. D1 데이터베이스 생성

이 단계에서 D1 데이터베이스를 설정합니다. D1 데이터베이스를 만들 수 있습니다.[Cloudflare대시보드](https://dash.cloudflare.com), 또는 통해`wrangler`. 이 튜토리얼은`wrangler`로그인

터미널을 열고 다음 명령을 실행:

```sh
npx wrangler d1 create prisma-demo-db
```

당신은 당신의 맨끝에 뒤에 오는 산출을 받습니다:

```
✅ Successfully created DB 'prisma-demo-db' in region WEUR
Created your new D1 database.

{
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "prisma-demo-db",
      "database_id": "<D1_DATABASE_ID>"
    }
  ]
}
```

이제 D1 데이터베이스가 Cloudflare 계정에 Cloudflare Worker에 바인딩되어 있습니다.

명령 출력의 마지막 부분을 복사하고 Wrangler 파일로 붙여 넣습니다. 그것은 이것과 유사해야합니다 :

## 4. 데이터베이스에서 테이블 만들기

[Prisma 마이그레이션](https://www.prisma.io/docs/orm/prisma-migrate/understanding-prisma-migrate/overview)아직 D1XQ를 지원하지 않으므로 기본 마이그레이션 워크플로우를 사용하여 수행 할 수 없습니다.`prisma migrate dev`또는`prisma db push`.

:::참조

D1에 대한 Prisma Migrate는 현재 초기 액세스입니다. 그것을 시도하려는 경우, 당신은 지침을 따를 수 있습니다[Prisma 문서](https://www.prisma.io/docs/orm/overview/databases/cloudflare-d1#using-prisma-migrate-via-a-driver-adapter-in-prismaconfigts-early-access).

:::

D1 사용[회사연혁](/d1/reference/migrations)schema 변경을 관리하고 Prisma CLI는 해당 업데이트에 필요한 SQL을 생성 할 수 있습니다. 아래 단계에서는 데이터베이스에 마이그레이션을 생성하고 적용 할 수있는 두 도구를 사용합니다.

첫째, 새로운 마이그레이션을 사용하여`wrangler`:

```sh
npx wrangler d1 migrations create prisma-demo-db create_user_table
```

이름 \*`yes`새 폴더 만들기`migrations`.

명령은 이제 새 디렉토리를 만들었습니다.`migrations`그리고 빈 파일 호출`0001_create_user_table.sql`그것의 안쪽에:

</FileTree>

`UNIQUE INDEX`에 의해`email`만든 때문에`User`당신의 Prisma schema에 있는 모형은 사용입니다[`@unique`](https://www.prisma.io/docs/orm/reference/prisma-schema-reference#unique)그것의 특성`email`이름 \*

지금 사용할 필요가`wrangler d1 migrations apply`D1에 이 SQL 문 보내기 명령. 이 명령은 두 가지 옵션을 허용합니다.

- `--local`: 성명서 실행*한국어*D1의 버전. D1의이 로컬 버전은 SQLite 데이터베이스 파일입니다.`.wrangler/state`프로젝트의 디렉토리. 이 접근법을 사용하면 현지 기계에서 작업자를 개발하고 테스트 할 수 있습니다. 더 알아보기[지역 개발](/d1/best-practices/local-development/)더 알아보기.
- `--remote`: 귀하의 성명*원격 제어*D1의 버전. 이 버전은 당신에 의해 사용됩니다*설치하기*Cloudflare Workers. 더 알아보기[원격 개발](/d1/best-practices/remote-development/)더 알아보기.

이 튜토리얼에서 로컬 및 원격 개발을 수행 할 것입니다. Worker를 로컬로 테스트하고 나서 Worker를 배포합니다.

터미널을 열고 명령을 모두 실행하십시오.

```sh
#로컬 데이터베이스
npx wrangler d1 migrations apply prisma-demo-db --local
```

```sh
#원격 데이터베이스
npx wrangler d1 migrations apply prisma-demo-db --remote
```

제품 정보`Yes`마이그레이션이 적용되어야한다는 것을 확인하기 위해 신속한 두 번.

다음, 작업자가 실행되면 쿼리 할 수있는 일부 데이터를 만듭니다. 이 시간, 당신은 파일에 저장하지 않고 SQL 문장을 실행합니다:

```sh
#로컬 데이터베이스
npx wrangler d1 execute prisma-demo-db --command "INSERT INTO  \"User\" (\"email\", \"name\") VALUES
('jane@prisma.io', 'Jane Doe (Local)');" --local
```

```sh
#원격 데이터베이스
npx wrangler d1 execute prisma-demo-db --command "INSERT INTO  \"User\" (\"email\", \"name\") VALUES
('jane@prisma.io', 'Jane Doe (Remote)');" --remote
```

:::참조
오류가 발생하면`Unknown arguments: (\email\,, \name\)...`, 당신은 backslashes 대신 backticks (\`)와 더블 인용을 탈출해야합니다 (\\).

Wrangler 명령은 다음과 같습니다.

```sh
#\ 대신 `으로 탈출
npx wrangler d1 execute prisma-demo-db --command "INSERT INTO  `"User`" (`"email`", `"name`") VALUES
('jane@prisma.io', 'Jane Doe (Local)');" --<FLAG>
```

:::

## 6. 작업자를 로컬로 실행

이제 데이터베이스 쿼리가 발생하고 Prisma Client가 생성되어 Worker를 로컬로 실행합니다.

```sh
npm run dev
```

본문 바로가기[`http://localhost:8787`](http://localhost:8787/)데이터베이스 쿼리의 결과를 확인하려면:

```json
[{ "id": 1, "email": "jane@prisma.io", "name": "Jane Doe (Local)" }]
```

## 7. 노동자를 배포

Worker를 배포하려면 다음 명령을 실행하십시오.

```sh
npm run deploy
```

직장인에게`https://prisma-d1-example.USERNAME.workers.dev`. 당신의 브라우저는 당신의 먼 D1 데이타베이스에게서 뒤에 오는 자료를 표시해야 합니다:

```json
[{ "id": 1, "email": "jane@prisma.io", "name": "Jane Doe (Remote)" }]
```

이 튜토리얼을 끝내면 Cloudflare를 배포했습니다. D1를 데이터베이스로 사용하고 Prisma ORM을 통해 쿼리합니다.

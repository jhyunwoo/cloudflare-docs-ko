D1XQ에 저장된 데이터의 위치는 데이터베이스가 실행되는지 여부를 최적화하는 방법을 포함하여 결정됩니다.

## 자동 (추천)

기본적으로 D1는 데이터베이스를 생성하기 위해 요청을 발급한 위치에 있는 기본 데이터베이스 인스턴스를 자동으로 생성합니다. 대부분의 경우 D1를 사용하여 데이터베이스에 최적의 위치를 선택할 수 있습니다.

## 데이터베이스 제한

D1 데이터베이스를 만들고 저장하는 데 사용됩니다.[GDPR](https://gdpr-info.eu/)또는[파일 형식](https://blog.cloudflare.com/cloudflare-achieves-fedramp-authorization/).

Workers는 여전히 세계 어디서나 관할권에 데이터베이스에 액세스 할 수 있습니다. 관할권 제약은 데이터베이스 자체가 실행되고 persists 데이터 만 제어합니다. 자주 묻는 질문[지역 서비스](/data-localization/regional-services/)Cloudflare가 요청에 응답하는 지역에서 제어 할 수 있습니다.

:::참조

Jurisdictions는 데이터베이스 생성에 설정할 수 있으며 데이터베이스가 존재하는 후 추가 또는 업데이트 할 수 없습니다. 관할 구역과 위치 힌트 모두 제공된 경우, 관할권은 우선권과 위치 힌트가 무시됩니다.
주요 특징

### 지원된 관할권

| 제품 설명 | 제품정보                     |
| ----- | ------------------------ |
| ·     | 유럽 연합 (EU)               |
| 뚱 베어  | FedRAMP-compliant 데이터 센터 |

### 대시보드를 사용하십시오

1. Cloudflare 대시보드에서, 가십시오**D1 SQL 데이터베이스**사이트 맵

   <DashButton url="/?to=/:account/workers/d1" />

2. 제품정보**데이터베이스**.

3. 이름 \***데이터 위치**, 선택**관할 구역**목록에서 관할권을 선택하십시오.

4. 제품정보**이름 \***&#xB370;이터베이스를 만들려면.

### wrangler 사용

```sh
npx wrangler@latest d1 create db-with-jurisdiction --jurisdiction=eu
```

### REST API 사용

```curl

     -H "Authorization: Bearer $TOKENn" \
     -H "Content-Type: application/json" \
     --data '{"name": "db-wth-jurisdiction", "jurisdiction": "eu" }'
```

## 위치 hint 제공

위치 hint는 선택적 매개 변수입니다. 원하는 지리적 위치를 기본 데이터베이스 인스턴스에 표시할 수 있습니다.

당신은 명시적으로 특정 데이터베이스에 쓰기의 대다수가 데이터베이스를 생성하는 것보다 다른 위치에서 오는 경우에 위치 힌트를 제공 할 수 있습니다. 위치 hints는 때 유용할 수 있습니다:

- 분산된 팀에서 일.
- 특정 위치에 있는 사용자에 특정한 데이터베이스를 창조하십시오.
- 연속 배포 (CD) 또는 Infrastructure as Code (IaC) 시스템을 사용하여 프로그래밍 데이터베이스를 만듭니다.

D1 데이터베이스를 만들 때 위치 hint를 제공합니다.

- 사용 방법[`wrangler d1`](/workers/wrangler/commands/#d1)데이터베이스를 만듭니다.
- 데이터베이스 만들기[Cloudflare 대시보드를 통해](https://dash.cloudflare.com/?to=/:account/workers/d1).

:::카트로션
위치 힌트 제공은 D1가 선호하는 위치에 달려 있음을 보장하지 않습니다. 대신 p참고 자료XQ에 가장 가까운 위치에 실행됩니다.
주요 특징

### wrangler 사용

:::참조
wrangler를 설치하려면 D1 및 WorkersXQ의 명령행 인터페이스를 참조하십시오.[설치 및 업데이트 Wrangler](/workers/wrangler/install-and-update/).
:::

새로운 데이터베이스를 만들 때 위치 힌트를 제공하려면, 패스`--location`유효한 위치 hint를 가진 깃발:

```sh
wrangler d1 create new-database --location=weur
```

### 대시보드를 사용하십시오

대시보드를 통해 데이터베이스를 만들 때 위치 힌트를 제공하려면:

1. Cloudflare 대시보드에서, 가십시오**D1 SQL 데이터베이스**사이트 맵

   <DashButton url="/?to=/:account/workers/d1" />

2. 제품정보**데이터베이스**.

3. 데이터베이스 이름 및 옵션 제공**제품정보**.

4. 제품정보**이름 \***&#xB370;이터베이스를 만들려면.

### 사용 가능한 위치 hints

D1는 뒤에 오는 위치 hints를 지원합니다:

| 사이트맵  | Hint 묘사 |
| ----- | ------- |
| 이름 \* | 미국 서부   |
| 뚱 베어  | 북아메리카   |
| 뚱 베어  | 서유럽     |
| 뚱 베어  | 동유럽     |
| 아파르   | 아시아 태평양 |
| ₢ 킹   | 운영 정보   |

:::카트로션
D1 위치 힌트는 현재 남아메리카를 위해 지원되지 않습니다 (`sam`), 아프리카 (`afr`), 중동 (`me`). D1 데이터베이스는 이 위치에서 실행되지 않습니다.

## 관련 기사

D1가 활성화되어 전 세계 기본 데이터베이스 인스턴스의 읽기 전용 사본을 생성합니다. 1차 데이터베이스 인스턴스에서 멀리 떨어진 사용자에 대한 쿼리 대기 시간을 줄입니다.

D1는 복제를 읽을 때, D1는 자동적으로 읽힌 복제를 만듭니다[모든 지역](/d1/configuration/data-location#available-location-hints)기본 데이터베이스 인스턴스가 있는 지역을 포함하여 .

관할권이 형성된 경우, 복사본은 데이터베이스 생성에 있는 관할 구역 내에서만 생성됩니다.

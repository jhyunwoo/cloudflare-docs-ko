어떤 D1 Worker Binding APIs는 유형 객체를 반환합니다.

| 모델 번호: D1 Worker 바인딩 API                                                                                                        | 반환 객체          |
| ------------------------------------------------------------------------------------------------------------------------------- | -------------- |
| [`D1PreparedStatement::run`](/d1/worker-api/prepared-statements/#run), [`D1Database::batch`](/d1/worker-api/d1-database/#batch) | `D1Result`     |
| [`D1Database::exec`](/d1/worker-api/d1-database/#exec)                                                                          | `D1ExecResult` |

## `D1Result`

방법[`D1PreparedStatement::run`](/d1/worker-api/prepared-statements/#run)·[`D1Database::batch`](/d1/worker-api/d1-database/#batch)반환 유형[`D1Result`](#d1result)각 쿼리에 대한 객체. 이 객체는 다음과 같습니다:

- 성공 상태
- milliseconds에서 작업의 내부 기간을 가진 메타 객체
- 결과 (해당되는 경우)

```js
{
  success: boolean, //진정한 작업이 성공했다면 false 그렇지 않으면
  meta: {
    served_by: string //결과 반환 Cloudflare의 백엔드 노동자의 버전
    served_by_region: string //쿼리를 실행하는 데이터베이스 인스턴스의 영역
    served_by_primary: boolean //true if (and only if) 쿼리를 실행하는 데이터베이스 인스턴스는
    timings: {
      sql_duration_ms: number //데이터베이스 인스턴스에 의해 SQL 쿼리 실행의 지속 (네트워크 시간을 포함하지 않음)
    }
    duration: number, //SQL 쿼리 실행의 기간, milliseconds에서
		changes: number, //데이터베이스로 만든 변경 수
		last_row_id: number, //마지막 삽입 행 ID는, 테이블이 `WITHOUT ROWID` 옵션 없이 정의될 때만 적용합니다
		changed_db: boolean, //데이터베이스에 뭔가가 변경되면 true
    size_after: number, //쿼리가 성공적으로 적용된 후 데이터베이스의 크기
    rows_read: number, //이 쿼리에 의해 줄 (scanned)의 수
    rows_written: number //이 쿼리에 의해 작성된 행 수
    total_attempts: number //retries를 포함한 쿼리를 성공적으로 수행 할 수있는 총 시도 수
  }
  results: array | null, //[] 비어 있는 경우, 또는 null이 적용되지 않는 경우
}
```

## `D1ExecResult`

이 방법[`D1Database::exec`](/d1/worker-api/d1-database/#exec)typed를 반환[`D1ExecResult`](#d1execresult)각 쿼리에 대한 객체. 이 객체는 다음과 같습니다:

- 실행 쿼리의 수
- milliseconds의 가동의 내구

```js
{
	"count": number, //실행 쿼리의 수
	"duration": number //가동의 내구, milliseconds에서
}
```

### 이름 \*

:::노트\[ 대용량 저장]
열에 있는 어떤 숫자 가치든지 JavaScript의 수를 위한 52 비트 정밀도에 의해 영향을 받습니다. 매우 큰 번호를 저장하는 경우 (in`int64`), 그 후에 동일한 가치를 검색합니다, 반환 값은 당신의 고유 번호 보다는 더 적은 정확할지도 모릅니다.

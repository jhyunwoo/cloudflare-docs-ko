Worker Binding API를 사용하여 Worker에서 D1 데이터베이스에서 SQL 쿼리를 실행할 수 있습니다. 이렇게하려면 다음 단계를 수행 할 수 있습니다.

1. [D1 데이터베이스](/d1/get-started/#3-bind-your-worker-to-your-d1-database).
2. [자주 묻는 질문](/d1/worker-api/d1-database/#prepare).
3. [자주 묻는 질문](/d1/worker-api/prepared-statements).
4. 항문핥기[반환 객체](/d1/worker-api/return-object)(필수).

API 문서에 대한 관련 섹션을 참조하십시오.

## TypeScript 지원

모델 번호: D1 Worker Bindings API는 실행에 의해 생성 된 실행 시간 유형을 통해 완전히 입력됩니다.[`wrangler types`](/workers/languages/typescript/#typescript)패키지, 또한 지원[일반적인 유형](https://www.typescriptlang.org/docs/handbook/2/generics.html#generic-types)TypeScript API의 일부로. 일반적인 유형으로 선택 가능`type parameter`그래서 함수는 데이터의 유형이 취급되는 것을 이해합니다.

자주 묻는 질문[`D1PreparedStatement::run`](/d1/worker-api/prepared-statements/#run), [`D1PreparedStatement::raw`](/d1/worker-api/prepared-statements/#raw)·[`D1PreparedStatement::first`](/d1/worker-api/prepared-statements/#first), 각 데이터베이스 행을 나타내는 유형을 제공 할 수 있습니다. D1의 API는[결과물 반환](/d1/worker-api/return-object/#d1result)정확한 유형으로.

예를 들어, 제공`OrderRow`타입 파라미터로[`D1PreparedStatement::run`](/d1/worker-api/prepared-statements/#run)typed를 반환합니다.`Array<OrderRow>`대신 기본 객체`Record<string, unknown>`유형:

```ts
//줄 정의
type OrderRow = {
	Id: string;
	CustomerName: string;
	OrderDate: number;
};

//응용 분야의 Elsewhere
//env.MY DB는 D1 데이터베이스가 Wrangler 설정 파일에서 바인딩됩니다
const result = await env.MY_DB.prepare(
	"SELECT Id, CustomerName, OrderDate FROM [Order] ORDER BY ShippedDate DESC LIMIT 100",
).run<OrderRow>();
```

## API 놀이터

D1 노동자 바인딩 API 운동장은 입니다`index.js`D1를 위한 문서화 노동자 바인딩 API의 각각을 시험할 수 있는 파일. 파일의 끝에서 빌드[시작하기](/d1/get-started/#write-queries-within-your-worker)이름 \*

API 문서와 함께 사용해서 각 API가 어떻게 작동하는지 잘 이해할 수 있습니다.

API 놀이터를 설정하는 단계를 따르십시오.

### 1. Get 시작 튜토리얼 완료

더 보기[시작하기](/d1/get-started/#write-queries-within-your-worker)자습서. TypeScriptQ 대신 QXJavaScriptXQ를 사용하십시오.

### 2. 내용 수정`index.js`

본문 바로가기`index.js`아래 코드를 사용하여 각 API의 효과를 볼 수 있습니다.

<Details header="프로젝트" open={false}>
  ```js
  //사이트맵 놀이터 - 각 D1를 시험하십시오 Worker 바인딩 API 방법
  //다른 방법을 테스트하는 URL 경로 변경 (예: /RUN, /RAW, /FIRST)
  export default {
  	async fetch(request, env) {
  	  const { pathname } = new URL(request.url);

  		//테스트용 샘플 데이터
  		const companyName1 = `Bs Beverages`;
  		const companyName2 = `Around the Horn`;

  		//reusable 문 준비
  		const stmt = env.DB.prepare(`SELECT * FROM Customers WHERE CompanyName = ?`);
  		const stmtMulti = env.DB.prepare(`SELECT * FROM Customers; SELECT * FROM Customers WHERE CompanyName = ?`);
  		const session = env.DB.withSession("first-primary")
  		const sessionStmt = session.prepare(`SELECT * FROM Customers WHERE CompanyName = ?`);

        //테스트 D1PreparedStatement::run - 전체 D1Result 개체를 반환
        if (pathname === `/RUN`){
      	const returnValue = await stmt.bind(companyName1).run();
      	return Response.json(returnValue);

        //테스트 D1PreparedStatement::raw - 배열의 반환 배열
      } else if (pathname === `/RAW`){
      	const returnValue = await stmt.bind(companyName1).raw();
      	return Response.json(returnValue);

        //D1PreparedStatement를 시험하십시오: 첫번째 - 첫번째 줄을 단지 반환하십시오
      } else if (pathname === `/FIRST`){
      	const returnValue = await stmt.bind(companyName1).first();
      	return Response.json(returnValue);

        //D1Database::batch - 다수 문을 실행하십시오
      } else if (pathname === `/BATCH`) {
      	const batchResult = await env.DB.batch([
      		stmt.bind(companyName1),
      		stmt.bind(companyName2)
      	]);
      	return Response.json(batchResult);

        //D1Database::exec - 매개변수 없이 익지않는 SQL을 실행하십시오
      } else if (pathname === `/EXEC`){
      	const returnValue = await env.DB.exec(`SELECT * FROM Customers WHERE CompanyName = "Bs Beverages"`);
      	return Response.json(returnValue);

        //시험 D1 세션 API 읽기 복제
      } else if (pathname === `/WITHSESSION`){
      	const returnValue = await sessionStmt.bind(companyName1).run();
      	console.log("You're now using D1 Sessions!")
      	return Response.json(returnValue);
      }

        //지시와 기본 응답
        return new Response(
      	`Welcome to the D1 API Playground!
      	\nChange the URL to test the various methods inside your index.js file.`,
        );
      },

  };

  ```
</Details>

D1는 데이터베이스 내에서 저장된 JSON 데이터를 쿼리하고 파싱하기위한 내장 지원이 있습니다. 이렇게 하면:

- [Query 경로](#extract-values)저장된 JSON 객체 내에서 - 예를 들어, 키 또는 배열 인덱스의 값을 추출하는 것은 특히 더 큰 JSON 객체와 유용합니다.
- 삽입 및/또는 객체 또는 배열 내에서 값을 대체합니다.
- [JSON 객체의 내용을 확장](#expand-arrays-for-in-queries)또는 여러 행에 배열 - 예를 들어, 사용의 일부로`WHERE ... IN`사전.
- 이름 \*[생성된 열](/d1/reference/generated-columns/)JSON 객체의 값으로 자동으로 변환됩니다.

D1XQ 내에서 JSON을 파싱하는 가장 큰 장점 중 하나는 데이터베이스에 라운드 스트립 ( 쿼리)의 번호를 직접 줄일 수 있다는 것입니다. 그것은 당신이 응용 프로그램에 JSON 개체를 읽을 필요가있는 경우를 감소 (1), 그것을 파, 다음 다시 작성 (2).

이 데이터에 대해 더 정확하게 쿼리 할 수 있으며 결과가 추가 파스 및 필터에 적용해야 합니다.

## 제품정보

JSON 데이터는 저장됩니다.`TEXT`D1에 있는 란. JSON 유형은 동일합니다.[유형 변환 규칙](/d1/worker-api/#type-conversion)일반 D1로 다음과 같은:

- JSON null은 D1로 처리됩니다.`NULL`.
- JSON 번호는 처리됩니다.`INTEGER`또는`REAL`.
- Booleans는 대우됩니다`INTEGER`값:`true`이름 \*`1`·`false`이름 \*`0`.
- 객체와 배열 값으로`TEXT`.

## 지원된 기능

뒤에 오는 테이블은 D1 및 예 사용법으로 건축된 JSON 기능을 개요합니다.

- 더 보기`json`인자 placeholder는 JSON 객체, 배열, 문자열, 숫자 또는 null 값일 수 있습니다.
- 더 보기`value`인수는 문자열 리터 (만)을 허용하고 문자열로 입력을 치료합니다. 또한 JSON을 잘 형성합니다. 이 규칙에 대한 예외는 배열 할 때`json_*`함수: 외부(wrapping) 함수는 JSON으로 내부(wrapped) 함수 반환값을 해석합니다.
- 더 보기`path`인수는 path-style traversal 구문을 받아들입니다 - 예를 들어,`$`top-level object/array를 참조하려면`$.key1.key2`배열된 객체를 참조하고,`$.key[2]`배열에 색인.

| 제품정보                                                        | 이름 \*                                                                                                           | 이름 \*                                                                                 |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `json(json)`                                                | 제공된 문자열은 JSON이고 JSON 객체의 분화 된 버전을 반환합니다.                                                                        | `json('{"hello":["world" ,"there"] }')`이름 \*`{"hello":["world","there"]}`             |
| `json_array(value1, value2, value3, ...)`                   | 값에서 JSON 배열을 반환합니다.                                                                                             | `json_array(1, 2, 3)`이름 \*`[1, 2, 3]`                                                 |
| `json_array_length(json)` - `json_array_length(json, path)` | JSON 배열의 길이를 반환                                                                                                 | `json_array_length('{"data":["x", "y", "z"]}', '$.data')`이름 \*`3`                     |
| `json_extract(json, path)`                                  | 주어진 경로에서 값을 추출합니다.`$.path.to.value`구문.                                                                          | `json_extract('{"temp":"78.3", "sunset":"20:44"}', '$.temp')`이름 \*`"78.3"`            |
| `json -> path`                                              | 경로 구문을 사용하여 주어진 경로에서 값을 추출하고 JSON으로 반환합니다.                                                                      |                                                                                       |
| `json ->> path`                                             | 경로 구문을 사용하여 주어진 경로에서 값을 추출하고 SQL 유형으로 반환합니다.                                                                    |                                                                                       |
| `json_insert(json, path, value)`                            | 주어진 경로에 값을 삽입합니다. 기존의 값을 덮지 않는다.                                                                                |                                                                                       |
| `json_object(label1, value1, ...)`                          | (keys, value) 쌍을 받아들이고 JSON 객체를 반환합니다.                                                                          | `json_object('temp', 45, 'wind_speed_mph', 13)`이름 \*`{"temp":45,"wind_speed_mph":13}` |
| `json_patch(target, patch)`                                 | JSON 사용[채용정보](https://tools.ietf.org/html/rfc7396)주어진 패치를 대상 JSON 객체로 병합하는 접근법.                                 |                                                                                       |
| `json_remove(json, path, ...)`                              | 지정된 경로에서 키와 값을 제거합니다.                                                                                           | `json_remove('[60,70,80,90]', '$[0]')`이름 \*`70,80,90]`                                |
| `json_replace(json, path, value)`                           | 주어진 경로에 값을 삽입합니다. 기존의 값을 덮고 있지만 존재하지 않는 경우 새로운 키를 만들지 않습니다.                                                     |                                                                                       |
| `json_set(json, path, value)`                               | 주어진 경로에 값을 삽입합니다. 기존의 값을 덮습니다.                                                                                  |                                                                                       |
| `json_type(json)` - `json_type(json, path)`                 | 지정된 경로에서 제공된 값 또는 값의 유형을 반환합니다. 반환 중 하나`null`, `true`, `false`, `integer`, `real`, `text`, `array`, 또는`object`. | `json_type('{"temperatures":[73.6, 77.8, 80.2]}', '$.temperatures')`이름 \*`array`      |
| `json_valid(json)`                                          | 유효 JSON에 대한 잘못된 JSON 및 1 (true)의 0 (false)를 반환합니다.                                                              | `json_valid({invalid:json})`이름 \*`0\`                                                 |
| `json_quote(value)`                                         | 제공된 SQL 값을 JSON 표현으로 변환합니다.                                                                                     | `json_quote('[1, 2, 3]')`이름 \*`[1,2,3]`                                               |
| `json_group_array(value)`                                   | JSON 배열으로 제공된 값(s)을 반환합니다.                                                                                      |                                                                                       |
| `json_each(value)` - `json_each(value, path)`               | 객체의 각 요소를 개별 행으로 반환합니다. 그것은 단지 최상위 객체를 구합니다.                                                                    |                                                                                       |
| `json_tree(value)` - `json_tree(value, path)`               | 객체의 각 요소를 개별 행으로 반환합니다. 그것은 전체 개체를 가로 질러.                                                                       |                                                                                       |

SQLite는[JSON 확장](https://www.sqlite.org/json1.html)D1는에, 추가 사용법 예가 있습니다.

## 오류 처리

JSON 함수가 반환됩니다.`malformed JSON`JSON 및/또는 JSON을 유효하지 않은 데이터에서 동작할 때 오류가 발생합니다. D1는 유효 JSON을 고려하여[RFC 7159의](https://www.rfc-editor.org/rfc/rfc7159.txt)관련 기사

다음 예제에서, 호출`json_extract`string 이상( 유효 JSON)은 쿼리를 반환합니다.`malformed JSON`오류:

```sql
SELECT json_extract('not valid JSON: just a string', '$')
```

이 오류를 반환합니다:

```txt
ERROR 9015: SQL engine error: query error: Error code 1: SQL error or missing database (malformed
  JSON)`
```

## 공급 업체

D1의 지원[생성된 열](/d1/reference/generated-columns/)JSON 데이터의 추출 또는 계산 값을 포함하여 다른 열의 값에 따라 생성되는 동적 열을 만들 수 있습니다.

이 란은 다른 어떤 란든지 같이 정복될 수 있고, 가지고 있을 수 있습니다[이름 \*](/d1/best-practices/use-indexes/)그들에 정의. JSON 데이터가 자주 쿼리 및 필터를 가지고 있다면 생성 된 열을 생성하고 인덱스는 극적으로 쿼리 성능을 향상시킬 수 있습니다.

예를 들어, 더 큰 JSON 객체 내에서 값을 기준으로 열을 정의하기 위해, 사용`AS`키워드와 결합[JSON 기능](#supported-functions)typed 열을 생성하려면:

```sql
CREATE TABLE some_table (
    -- other columns omitted
    raw_data TEXT -- JSON: {"measurement":{"aqi":[21,42,58],"wind_mph":"13","location":"US-NY"}}
    location AS (json_extract(raw_data, '$.measurement.location')) STORED
)
```

더 알아보기[공급 업체](/d1/reference/generated-columns/)열을 생성하는 방법에 대해 자세히 알아보세요.

## 예제 사용

### 추출 값

D1의 JSON 객체에서 값을 추출하는 세 가지 방법이 있습니다.

- 더 보기`json_extract()`함수 - 예를 들면,`json_extract(text_column_containing_json, '$.path.to.value)`.
- 더 보기`->`연산자, 값의 JSON 표현을 반환합니다.
- 더 보기`->>`연산자, 이는 값의 SQL 표현을 반환합니다.

더 보기`->`·`->>`운영자는 모두 PostgreSQL과 MySQL/MariaDB에서 동일한 연산자와 유사하게 작동한다.

열에 다음과 같은 JSON 객체를 부여합니다.`sensor_reading`, 당신은 그것에서 가치를 직접 추출할 수 있습니다.

```json
{
    "measurement": {
        "temp_f": "77.4",
        "aqi": [21, 42, 58],
        "o3": [18, 500],
        "wind_mph": "13",
        "location": "US-NY"
    }
}
```

```sql
-- Extract the temperature value
json_extract(sensor_reading, '$.measurement.temp_f')-- returns "77.4" as TEXT
```

```sql
-- Extract the maximum PM2.5 air quality reading
sensor_reading -> '$.measurement.aqi[3]' -- returns 58 as a JSON number
```

```sql
-- Extract the o3 (ozone) array in full
sensor_reading -\-> '$.measurement.o3' -- returns '[18, 500]' as TEXT
```

### 배열의 길이를 가져옵니다

두 가지 방법으로 JSON 배열의 길이를 얻을 수 있습니다.

1. 자주 묻는 질문`json_array_length(value)`기타 제품
2. 자주 묻는 질문`json_array_length(value, path)`객체 또는 외부 배열 내에서 배열에 경로를 지정합니다.

예를 들어, 다음과 같은 JSON 객체를 열 호출에 저장`login_history`, 당신은 마지막 로그인의 수를 직접 얻을 수 있었다:

```json
{
    "user_id": "abc12345",
    "previous_logins": ["2023-03-31T21:07:14-05:00", "2023-03-28T08:21:02-05:00", "2023-03-28T05:52:11-05:00"]
}
```

```sql
json_array_length(login_history, '$.previous_logins') --> returns 3 as an INTEGER
```

당신은 또한 사용할 수 있습니다`json_array_length`더 복잡한 쿼리에 사전 작성 - 예를 들어,`WHERE json_array_length(some_column, '$.path.to.value') >= 5`.

### 기존 객체에 값을 삽입

기존 JSON 객체 또는 배열에 값을 삽입할 수 있습니다.`json_insert()`. 예를 들면, 당신이 있는 경우에`TEXT`열 호출`login_history`로그인`users`다음 객체를 포함하는 테이블:

```json
{"history": ["2023-05-13T15:13:02+00:00", "2023-05-14T07:11:22+00:00", "2023-05-15T15:03:51+00:00"]}
```

새로운 타임스탬프를 추가하려면`history`우리의 제품`login_history`열, 다음과 같은 쿼리를 작성:

```sql
UPDATE users
SET login_history = json_insert(login_history, '$.history[#]', '2023-05-15T20:33:06+00:00')
WHERE user_id = 'aba0e360-1e04-41b3-91a0-1f2263e1e0fb'
```

세 가지 인수 제공`json_insert`:

1. JSON을 포함하는 우리의 열의 이름은 수정합니다.
2. 객체 내의 키 경로는 수정합니다.
3. JSON 값을 삽입합니다. 사용 방법`[#]`이름 \*`json_insert`당신의 배열의 끝에 부를 것이다.

기존의 값을 대체하려면 사용`json_replace()`, 이미 존재하는 경우 기존 키 값 쌍을 덮을 것이다. 이미 존재 여부에 관계없이 값을 설정하려면, 사용`json_set()`.

### IN 쿼리에 대한 확장 배열

제품 정보`json_each`여러 행으로 배열을 확장합니다. 구성 할 때 유용 할 수 있습니다.`WHERE column IN (?)`여러 값에 쿼리. 예를 들어, 사용자가 integer의 목록을 업데이트하려는 경우`id`, 사용`json_each`각 값으로 테이블을 반값으로 돌려줍니다.`value`:

```sql
UPDATE users
SET last_audited = '2023-05-16T11:24:08+00:00'
WHERE id IN (SELECT value FROM json_each('[183183, 13913, 94944]'))
```

이것은 단지 추출 할 것`value`테이블에서 열이 반환`json_each`, 각 행은 배열로 전달되는 사용자 ID를 대표합니다.

`json_each`효과적으로 여러 열을 가진 테이블을 반환, 가장 관련있는 것:

- `key`- 키 (또는 인덱스).
- `value`- 각 요소의 리터 값은 다음과 같습니다.`json_each`.
- `type`- 값의 유형 : 중 하나`null`, `true`, `false`, `integer`, `real`, `text`, `array`, 또는`object`.
- `fullkey`- 요소의 전체 경로 : 예.`$[1]`배열에 있는 두번째 성분을 위해, 또는`$.path.to.key`배열된 객체를 위해.
- `path`- 최고 수준의 경로 -`$`원소의 경로로`fullkey`이름 \*`$[0]`.

이 예제에서,`SELECT * FROM json_each('[183183, 13913, 94944]')`아래를 닮은 테이블을 반환합니다:

```sql
key|value|type|id|fullkey|path
0|183183|integer|1|$[0]|$
1|13913|integer|2|$[1]|$
2|94944|integer|3|$[2]|$
```

사용 가능`json_each`이름 \*[D1Workers 바인딩 API](/d1/worker-api/)자주 묻는 질문`JSON.stringify`배열을 전달하기[경계 모수](/d1/worker-api/d1-database/#guidance):

```ts
const stmt = context.env.DB
    .prepare("UPDATE users SET last_audited = ? WHERE id IN (SELECT value FROM json_each(?1))")
const resp = await stmt.bind(
    "2023-05-16T11:24:08+00:00",
    JSON.stringify([183183, 13913, 94944])
    ).run()
```

이것은 단지 당신의 행을 업데이트합니다`users`테이블 어디에`id`3가지 중 하나를 일치합니다.

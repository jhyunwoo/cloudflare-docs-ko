## 호환 PRAGMA 문

D1는 몇몇을 지원합니다[SQLite 광고](https://www.sqlite.org/pragma.html)이름 \* PRAGMA 문은 SQLite에 대한 SQL 확장입니다. PRAGMA 명령은 다음과 같이 사용될 수 있습니다.

- 특정 SQLite 작업의 동작을 수정합니다.
- Query 내부 데이터에 대한 SQLite 라이브러리 schemas 또는 테이블 (하지만 PRAGMA 진술은 테이블의 내용을 쿼리 할 수 있음).
- 제품정보[환경 변수](/workers/configuration/environment-variables/).

```sql
SELECT name, sql FROM sqlite_master
```

## LIKE 정보

SQL의 검색을 수행 할 수 있습니다.`LIKE`통신수:

```js
const { results } = await env.DB.prepare(
	"SELECT * FROM Customers WHERE CompanyName LIKE ?",
)
	.bind("%eve%")
	.run();
console.log("results: ", results);
```

이 페이지는 다음을 포함하는 D1XQ의 데이터 보안 속성에 대한 세부 정보:

- 암호화 패턴 (EAR).
- 암호화 (EIT).
- Cloudflare의 준수 인증.

## 복원

모든 개체에 저장 D1, 포함 메타 데이터, 라이브 데이터베이스, 그리고 비활성 데이터베이스는 복원에 암호화됩니다. 암호화 및 해독은 자동이며 사용자 구성이 필요하지 않으며 D1의 효과적인 성능에 영향을 미치지 않습니다.

암호화 키는 Cloudflare에 의해 관리되며 CloudflareXQ 내부에서 암호화 된 데이터를 관리하는 데 사용됩니다.

Objects는 암호화되어 있습니다.[사이트맵](https://www.cloudflare.com/learning/ssl/what-is-encryption/), 넓게 시험해, 높게 performant와 기업 표준 암호화 알고리즘. D1는 그것의 선호한 형태로 GCM (Galois/Counter 형태)를 이용합니다.

## Transit의 암호화

Cloudflare의 데이터 전송 Cloudflare 네트워크와 D1XQXQXQXQ의 노드간의 작업자 및/또는 동일하게 보호됩니다.[수송 층 안전](https://www.cloudflare.com/learning/ssl/transport-layer-security-tls/)(TLS/SSL).

HTTP API를 통해 API 액세스 또는 사용[채용정보](/workers/wrangler/install-and-update/)명령행 공용영역은 또한 TLS/SSL (HTTPS)에 있습니다.

## 견적 요청

Cloudflare의 업계 표준 보안 준수 인증에 대한 준수에 대한 자세한 내용은 CloudflareXQ[신뢰 허브](https://www.cloudflare.com/trust-hub/compliance-resources/).

## 자주 묻는 질문

시작하기 전에:

1. 자주 묻는 질문[D1 튜토리얼](/d1/get-started/)TypeScript 및 JavaScript에 대한 자세한 내용은**D1 데이터베이스를 만들고 Workers 프로젝트 구성**.
2. 더 알아보기[Python 언어 가이드](/workers/languages/python/)Python 지원이 Workers 플랫폼에서 작동하는지 이해하기 위해.
3. Python 언어와 기본 친숙함이 있습니다.

Cloudflare Workers에 새로운 경우, 참조[자주 묻는 질문](/workers/get-started/guide/)이 예제를 계속하기 전에 먼저.

## Python에서 조회

이 예제는 기존 D1 데이터베이스가 있습니다. Python 데이터베이스를 쿼리하는 노동자, 당신은 먼저 만들 필요가[관련 제품](/workers/runtime-apis/bindings/)당신의 노동자와 당신의 D1 데이터베이스 사이 그리고 당신의에서 이것을 정의하십시오[Wrangler 구성 파일](/workers/wrangler/configuration/).

당신은 필요`database_name`·`database_id`D1 데이터베이스 당신은 사용할 수 있습니다`wrangler`새로운 데이터베이스를 만들거나 기존 데이터베이스에 ID를 가져오려면 다음과 같습니다.

```sh title="Create a database"
npx wrangler d1 create my-first-db
```

```sh title="Retrieve a database ID"
npx wrangler d1 info some-existing-db
```

### 1. 바인딩 구성

Wrangler 파일에서 새로운 생성`[[d1_databases]]`구성 블록 및 설정`database_name`·`database_id`쿼리하려는 D1 데이터베이스의 이름과 ID (respectively)에:

<WranglerConfig>
  ```jsonc
  {
  	"$schema": "./node_modules/wrangler/config-schema.json",
  	"name": "python-and-d1",
  	"main": "src/entry.py",
  	"compatibility_flags": [ //Python Workers
  		"python_workers"
  	],
  	"compatibility_date": "$today",
  	"d1_databases": [
  		{
  			"binding": "DB", //이 작업자의 데이터베이스를 참조하는 방법
  			"database_name": "YOUR_DATABASE_NAME",
  			"database_id": "YOUR_DATABASE_ID"
  		}
  	]
  }
  ```
</WranglerConfig>

가치의`binding`작업자 내에서 데이터베이스를 참조하는 방법. 이것을 변경하면 Worker 스크립트에서 이것을 변경해야 합니다.

### 2. Python 작업자

Python Worker, 빈 파일 만들기`src/entry.py`, 값 일치`main`아래 내용을 가진 Wrangler 파일에:

```python
from workers import Response, WorkerEntrypoint

class Default(WorkerEntrypoint):
    async def fetch(self, request):
        #여기에 요청하고 싶습니다!

        try:
            #질문 D1 - 우리는이 예제에서 우리의 데이터베이스에서 모든 테이블을 나열합니다.
            results = await self.env.DB.prepare("PRAGMA table_list").run()
            #JSON 응답을 반환
            return Response.json(results)
        except Exception as e:
            return Response.json({"error": "Database query failed"}, status=500)

```

가치의`binding`Wrangler 파일에서 Python 코드에서 변수의 이름을 정확히 일치해야합니다. 이 예제는 데이터베이스를 통해 나타냅니다.`DB`바인딩 및 이 바인딩을 통해 쿼리`await env.DB.prepare(...)`.

Python를 배포할 수 있습니다. 직접 노동자:

```sh
npx wrangler deploy
```

<Description>
  Workers 및 Pages 프로젝트에서 쿼리하는 새로운 serverless SQL 데이터베이스를 만듭니다.
</Description>

<Plan type="workers-all" />

D1는 SQLite의 SQL semantics, 붙박이 재난 회복 및 노동자 및 HTTP API 접근을 가진 QXQX0005XQ's 관리되고, 서버가 없는 데이타베이스입니다.

D1는 다수, 더 작은 (10 GB) 데이타베이스의 맞은편에 수평 가늠자를 위해, per-user, per-tenant 또는 per-entity 데이타베이스와 같은 디자인됩니다. D1를 사용하면 여러 데이터베이스와 분리 할 수있는 수천 개의 데이터베이스와 응용 프로그램을 구축 할 수 있습니다. D1 가격은 쿼리 및 저장 비용에만 근거합니다.

당신의 첫번째 D1 데이타베이스를 창조하십시오[시작하기](/d1/get-started/), 학습 방법[data를 데이터베이스로 가져 오기](/d1/best-practices/import-export-data/), 그리고 방법[데이터베이스](/d1/worker-api/)직접에서[Workers](/workers/)또는[Pages](/pages/functions/bindings/#d1-databases).

## 주요 특징

<Feature header="첫 번째 D1 데이터베이스 만들기" href="/d1/get-started/" cta="Create your D1 database">
  첫 번째 D1 데이터베이스를 작성하여 스키마, 가져오기 데이터 및 쿼리 D1를 직접 응용 프로그램에서 설정[Workers로 건축하는](/workers/).
</Feature>

<Feature header="사이트맵" href="/d1/sql-api/sql-statements/" cta="Execute SQL queries">
  SQLite의 SQL 호환성 및 D1 클라이언트 API와 SQL을 실행합니다.
</Feature>

<Feature header="시간 여행" href="/d1/reference/time-travel/" cta="Learn about Time Travel">
  시간 여행은 D1의 백업 및 포인트 인 시간 회복에 대한 접근이며 지난 30 일 이내에 데이터베이스를 복원 할 수 있습니다.
</Feature>

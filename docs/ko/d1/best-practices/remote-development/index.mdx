D1는 원격 개발을 지원합니다[대시보드 운동장](/workers/playground/#use-the-playground). 대시보드 놀이터는 비주얼 스튜디오 코드의 브라우저 버전을 사용하며 브라우저에서 전적으로 작업자에게 신속하게 이식 할 수 있습니다.

## 1. 노동자에 D1 데이터베이스를 Bind

:::참조

이 가이드는 이전에 Worker를 만들고 D1 데이터베이스를 만들었습니다.

D1 및/또는 Cloudflare Workers에 새로운 사용자는 읽혀야 합니다[D1 튜토리얼](/d1/get-started/)설치하기`wrangler`첫 번째 데이터베이스를 배포합니다.

:::

1. Cloudflare 대시보드에서, 가십시오**Workers & Pages**사이트 맵

   <DashButton url="/?to=/:account/workers-and-pages" />
2. 기존 노동자를 선택하십시오.
3. 오시는 길**회사 소개**탭.
4. 제품정보**바인딩**.
5. 제품정보**D1 데이터베이스** > **바인딩**.
6. 변수 이름을 입력합니다.`DB`, 그리고 D1 데이터베이스를 선택하여 이 작업자에서 액세스 할 수 있습니다.
7. 제품정보**바인딩**.

## 2. 원격 개발 세션 시작

1. Cloudflare 대시보드XQ의 작업자의 페이지에서 선택**비밀번호**페이지 상단에.
2. 지금 노동자는 D1에 접근합니다.

다음 Worker 스크립트를 사용하여 Worker가 경계 D1 데이터베이스에 액세스 할 수 있는지 확인하십시오.

```js
export default {
  async fetch(request, env, ctx) {
    const res = await env.DB.prepare("SELECT 1;").run();
    return new Response(JSON.stringify(res, null, 2));
  },
};
```

주요 특징

## 관련 쿼리의 예

다음 예제를 고려하십시오.`shouldRetry(...)`기능, 에서 촬영[D1는 복제 시동기 템플렛을 읽었습니다](https://github.com/cloudflare/templates/blob/main/d1-starter-sessions-api-template/src/index.ts#L108).

당신은 당신의 retries가 더 성공적인 retries를 위한 지터 전략을 가진 exponential backoff를 적용해야 합니다.
이미 같은 라이브러리 요약을 사용할 수 있습니다.[`@cloudflare/actors`](https://github.com/cloudflare/actors), 또는[retry 논리를 복사](https://github.com/cloudflare/actors/blob/9ba112503132ddf6b5cef37ff145e7a2dd5ffbfc/packages/core/src/retries.ts#L18)자신의 코드를 직접.

```ts
import { tryWhile } from "@cloudflare/actors";

function queryD1Example(d1: D1Database, sql: string) {
  return await tryWhile(async () => {
    return await d1.prepare(sql).run();
  }, shouldRetry);
}

function shouldRetry(err: unknown, nextAttempt: number) {
  const errMsg = String(err);
  const isRetryableError =
    errMsg.includes("Network connection lost") ||
    errMsg.includes("storage caused object to be reset") ||
    errMsg.includes("reset because its code was updated");
  if (nextAttempt <= 5 && isRetryableError) {
    return true;
  }
  return false;
}
```

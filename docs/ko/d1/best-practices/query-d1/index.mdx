D1는 SQLite의 쿼리 엔진을 활용하기 때문에 대부분의 SQLite의 SQL 컨벤션과 호환됩니다. D1를 쿼리하는 SQL 명령을 사용할 수 있습니다.

D1 데이터베이스와 상호 작용할 수있는 여러 가지 방법이 있습니다.

1. 사용 방법[D1 Workers 바인딩 API](/d1/worker-api/)당신의 코드에.
2. 사용 방법[D1 등급 API](/api/resources/d1/subresources/database/methods/create/).
3. 사용 방법[D1 Wrangler 명령](/d1/wrangler-commands/).

## D1

D1는 Workers BindingAPI 또는 REST API (Wrangler 명령을 포함하여 SQL 문헌을 사용하여 데이터베이스를 쿼리 할 수 있는 SQLite semantics를 이해합니다). 더 알아보기[D1 SQL API](/d1/sql-api/sql-statements/)지원된 SQL 문에 대해 자세히 알아볼 수 있습니다.

### 외국 핵심 관계 사용

D1를 사용하여 SQL을 사용할 때 데이터베이스의 테이블에서 외국 키 제약을 정의하고 시행 할 수 있습니다. 외국 키 제약은 테이블에 걸쳐 관계를 시행 할 수 있습니다, 또는 다른 테이블에 참고 자료 행을 삭제에서 당신을 방지. 외국 핵심 관계의 예는 아래에 표시됩니다.

```sql
CREATE TABLE users (
    user_id INTEGER PRIMARY KEY,
    email_address TEXT,
    name TEXT,
    metadata TEXT
)

CREATE TABLE orders (
    order_id INTEGER PRIMARY KEY,
    status INTEGER,
    item_desc TEXT,
    shipped_date INTEGER,
    user_who_ordered INTEGER,
    FOREIGN KEY(user_who_ordered) REFERENCES users(user_id)
)
```

더 알아보기[외국 키 정의](/d1/sql-api/foreign-keys/)더 많은 정보.

### 쿼리 JSON

D1는 데이터베이스 내에서 저장된 JSON 데이터를 쿼리하고 파싱할 수 있습니다. 예를 들어, JSON 객체 안에 값을 추출할 수 있습니다.

다음 JSON 객체를 부여합니다 (`type:blob`) 열에서 명명`sensor_reading`, 당신은 그것에서 가치를 직접 추출할 수 있습니다.

```json
{
    "measurement": {
        "temp_f": "77.4",
        "aqi": [21, 42, 58],
        "o3": [18, 500],
        "wind_mph": "13",
        "location": "US-NY"
    }
}
```

```sql
-- Extract the temperature value
SELECT json_extract(sensor_reading, '$.measurement.temp_f')-- returns "77.4" as TEXT
```

더 알아보기[쿼리 JSON](/d1/sql-api/query-json/)JSON 객체를 쿼리하는 것에 대해 자세히 알아보세요.

## 질문 D1QXQXQXQXQ 바인딩 API

Workers 바인딩 API는 주로 데이터 비행기와 상호 작용하고, 당신의 노동자에서 D1 데이타베이스를 쿼리 할 수 있습니다.

이렇게 하면:

1. 당신의 노동자에 D1 데이터베이스를 Bind.
2. 자주 묻는 질문
3. 자주 묻는 질문

```js title="index.js"
export default {
    async fetch(request, env) {
        const {pathname} = new URL(request.url);
        const companyName1 = `Bs Beverages`;
        const companyName2 = `Around the Horn`;
        const stmt = env.DB.prepare(`SELECT * FROM Customers WHERE CompanyName = ?`);

        if (pathname === `/RUN`) {
            const returnValue = await stmt.bind(companyName1).run();
            return Response.json(returnValue);
        }

        return new Response(
            `Welcome to the D1 API Playground!
						\nChange the URL to test the various methods inside your index.js file.`,
        );
    },
};
```

더 알아보기[Workers 바인딩 API](/d1/worker-api/)더 많은 정보.

## 질문 D1XQ와 QXQXQXQ 명령

D1 데이터베이스를 쿼리하는 Wrangler 명령을 사용할 수 있습니다. Wrangler 명령은 REST API를 사용하여 작업을 수행합니다.

```sh
npx wrangler d1 execute prod-d1-tutorial --command="SELECT * FROM Customers"
```

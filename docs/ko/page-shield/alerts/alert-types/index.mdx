도메인에서 감지된 리소스에 대한 경고를 구성할 수 있습니다. 더 알아보기[제품정보](/page-shield/alerts/)더 많은 정보.

## 새로운 리소스 경고

:::참조
사업 계획 또는 더 높은 필요.
주요 특징

새로운 리소스는 도메인에 감지 된 새로운 리소스에 대해 알려줍니다, 새로운 호스트 도메인에서 감지 된 리소스, 또는 새로 감지 된 리소스의 URL 길이와 문제.

<AvailableNotifications product="Page Shield" notificationFilter="Page Shield New Domain Alert" />

<AvailableNotifications product="Page Shield" notificationFilter="Page Shield New Resource Exceeds Max URL Length Alert" />

## Code 변경 경고

:::참조
유료 애드온과 엔터프라이즈 플랜을 요구합니다.
주요 특징

이 경고는 당신에게 대해 알려줍니다.[코드 변경](/page-shield/detection/review-changed-scripts/)이전에는 스크립트를 감지했습니다.

<AvailableNotifications product="Page Shield" notificationFilter="Page Shield New Code Change Detection Alert" />

## 맛있는 자원 경고

:::참조
유료 애드온과 엔터프라이즈 플랜을 요구합니다.
주요 특징

맛있는 자원 경고는 당신을 통지[악성행위](/page-shield/how-it-works/malicious-script-detection/), 그들에 따라[이름 \*](/page-shield/how-it-works/malicious-script-detection/#malicious-domain-checks), [사이트 맵](/page-shield/how-it-works/malicious-script-detection/#malicious-url-checks), 또는[스크립트 내용](/page-shield/how-it-works/malicious-script-detection/#malicious-script-detection).

<AvailableNotifications product="Page Shield" notificationFilter="Page Shield New Malicious URL Alert" />

주요 특징

## 이름 \*

완료된 엔드포인트를 얻을 수 있습니다.[페이지 방패 API](/api/resources/page_shield/methods/get/)Cloudflare API 기본 URL에 엔드포인트:

```txt
https://api.cloudflare.com/client/v4
```

더 보기`{zone_id}`인수는 영역 ID입니다 (thocdecimal 문자열). Cloudflare\`\`대시보드 또는 Cloudflare API'를 사용하여 이 값을 찾을 수 있습니다.[`/zones`끝점](/fundamentals/account/find-account-and-zone-ids/).

더 보기`{script_id}`인수는 스크립트 ID입니다 (thocdecimal string). 이 값은 응답에 포함되어 있습니다.[Page Shield 스크립트 목록](/api/resources/page_shield/subresources/scripts/methods/list/)모든 감지된 스크립트에 대한 작동.

더 보기`{connection_id}`인수는 연결 ID입니다 (thocdecimal string). 이 값은 각 검출된 연결을 위한 List Page Shield 연결 API 가동의 응답에 포함됩니다.

뒤에 오는 테이블은 유효한 가동을 요약합니다:

## API 노트

악성 스크립트 분류 (`Malicious`또는`Not malicious`)는 API에서 직접 유효하지 않습니다. 이 분류를 결정하려면 스크립트의 비교`js_integrity_score`현재 10로 설정된 분류 임계값을 가진 값. 임계 값보다 낮은 점수 값과 스크립트는 악의적으로 간주됩니다.

## Common API 호출

### 페이지 방패 설정

이 예제는 상태 (enabled/disabled)를 포함하여 Page Shield의 현재 설정을 얻습니다.

<APIRequest path="/zones/{zone_id}/page_shield" method="GET" />

```json output
{
	"result": {
		"enabled": true,
		"updated_at": "2023-05-14T11:47:55.677555Z",
		"use_cloudflare_reporting_endpoint": true,
		"use_connection_url_path": false
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

### Enable 페이지 방패

이 예제는 지정된 영역에서 Page Shield를 활성화합니다.

<APIRequest path="/zones/{zone_id}/page_shield" method="PUT" json={{ enabled: true }} />

```json output
{
	"result": {
		"enabled": true,
		"updated_at": "2023-05-14T11:50:41.756996Z"
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

### 정책 만들기

이름 \*`POST`요청은 페이지 방패 정책 (또는 콘텐츠 보안 규칙)을 작성합니다.*로그인*동작, 다음과 같은 스크립트를 정의하여 호스팅되는 곳을 기준으로 허용:

- 호스팅되는 스크립트`myapp.example.com`(스크립트가 포함되지 않음)`example.com`).
- 호스팅되는 스크립트`cdnjs.cloudflare.com`.
- 전체 URL을 사용하여 Google Analytics 스크립트.
- 같은 기원의 모든 스크립트 (same HTTP 또는 HTTPS 방식과 hostname).

다른 모든 스크립트는 정책 위반을 트리거하지만, 그 스크립트는 차단되지 않습니다.

더 많은 정보<GlossaryTooltip term="content security policy (CSP)">콘텐츠 보안 정책 (CSP)</GlossaryTooltip>지시어와 값, 참조[MDN 문서](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy).

:::참조
CSP 지침 및 정책에 의해 지원되는 키워드 목록은 참조[CSP 지침 지원](/page-shield/policies/csp-directives/).
:::

<APIRequest
  path="/zones/{zone_id}/page_shield/policies"
  method="POST"
  json={{
  	description: "My first policy in log mode",
  	action: "log",
  	expression: 'http.host eq "myapp.example.com"',
  	enabled: "true",
  	value:
  		"script-src myapp.example.com cdnjs.cloudflare.com https://www.google-analytics.com/analytics.js 'self'",
  }}
/>

정책 만들기*지원하다*대신 작업*로그인*, 사용`"action": "allow"`요청 몸에서. 이러한 정책의 경우 정책에 의해 허용되는 모든 스크립트가 차단됩니다.

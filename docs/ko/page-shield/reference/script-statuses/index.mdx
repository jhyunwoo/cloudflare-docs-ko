Cloudflare는 다음과 같이 스크립트와 연결(일컬어 리소스)를 분류합니다:

- 스크립트/연결의 수가 보고되었습니다.
- 스크립트/연결이 악화되었는지 여부.

Page Shield's 대시보드를 사용하여 도메인에 로드된 스크립트를 검토하고 이를 연결합니다. 더 많은 정보를 원하시면, 참조[모니터링 리소스 및 쿠키](/page-shield/detection/monitor-connections-scripts/).

## 유효한 상태

- **자주 묻는 질문**: 스크립트/연결에 대한 3개 이상의 보고서가 있습니다. 스크립트/연결에 대한 보고서가 없는 경우*자주 묻는 질문*5 일 동안 상태, 다음 Page Shield는 스크립트 / 연결에 대한 모든 정보를 삭제합니다. 스크립트*자주 묻는 질문*상태는 All Reported Scripts 대시보드에서만 표시되며,*자주 묻는 질문*상태는 All Reported Connections 대시보드에만 표시됩니다.
- **지원하다**: 스크립트/연결에 대한 3개 이상의 보고서가 있습니다.
- **관련 기사**: 이전 활성 스크립트 / 연결은 지난 7 일 동안보고되지 않았습니다. 스크립트/연결이 다시 보고되면 상태가 다시 변경됩니다.*지원하다*. 스크립트/연결이 30 일 동안 보고되지 않는 경우, 페이지 방패는 그것에 관하여 모든 정보를 삭제할 것입니다. 스크립트*관련 기사*상태는 All Reported Scripts 대시보드에서만 표시되며,*관련 기사*상태는 All Reported Connections 대시보드에만 표시됩니다.

:::참조

모든 스크립트와 연결이 악의적 인 것으로 나타납니다 모니터 대시보드, 자신의 상태에 관계없이.

Malicious script/connection detection는 유료 애드온으로 엔터프라이즈 고객에게만 사용할 수 있습니다.

:::

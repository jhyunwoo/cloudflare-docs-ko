Cloudflare 사용자와 다음[이름 \*](/fundamentals/manage-members/roles/)Cloudflare\`\`대시보드에서 Page Shield에 액세스해야 합니다.

- 관리자
- 슈퍼 관리자 - 모든 특전
- 페이지 방패
- 페이지 방패 읽&#xAE30;*(읽기 전용 액세스)*
- 도메인 페이지 방패
- 도메인 페이지 Shield 읽&#xAE30;*(읽기 전용 액세스)*

특정 페이지 방패 기능의 가용성은 당신의 Cloudflare 계획에 달려 있습니다. 더 알아보기[적용분야](/page-shield/#availability)더 많은 정보.

형식의<GlossaryTooltip term="content security policy (CSP)">콘텐츠 보안 정책 (CSP)</GlossaryTooltip>Page Shield에 의해 추가된 HTTP 헤더는 다음과 같습니다.

```txt
content-security-policy-report-only: script-src 'none'; connect-src 'none'; report-uri https://csp-reporting.cloudflare.com/cdn-cgi/script_monitor/report?<QUERY_STRING>
```

당신은[endpoint를 구성](/page-shield/reference/settings/#reporting-endpoint)같은 hostname을 사용하려면 HTTP 헤더는 다음과 같은 형식을 가질 것입니다.

```txt
content-security-policy-report-only: script-src 'none'; connect-src 'none'; report-uri <YOUR_HOSTNAME>/cdn-cgi/script_monitor/report?<QUERY_STRING>
```

:::주\[주]

Cloudflare는 전송된 응답의 샘플에 웹 페이지 리소스를 모니터링하는 데 사용되는 CSP 보고서 전용 HTTP 헤더를 추가합니다.

설정하기[로그 정책](/page-shield/policies/)다른 CSP 보고서 전용 헤더를 추가합니다. Cloudflare는 고객 정의 정책과 관련된 보고서 전용 헤더에 대해 샘플링을 수행하지 않습니다.

:::

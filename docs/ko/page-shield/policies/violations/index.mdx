## GraphQL API를 통해 정책 위반 받기

사용 방법[Cloudflare 그래프QL API](/analytics/graphql-api/)다음 데이터셋을 통해 정책 위반 정보를 얻기 위해:

- `pageShieldReportsAdaptiveGroups`

지난 30 일 동안 정책 위반에 대한 데이터 세트를 쿼리 할 수 있습니다.

제품 정보[관련 상품](/analytics/graphql-api/features/discovery/introspection/)GraphQL 스키마를 사용할 수 있는 필드를 탐험하세요. 더 많은 정보를 원하시면, 참조[GraphQL 스키마를 탐험](/analytics/graphql-api/getting-started/explore-graphql-schema/).

GraphQL 쿼리에 대한 소개, 참조[Querying 기본](/analytics/graphql-api/getting-started/querying-basics/).

### 이름 \*

```graphql graphql-api-explorer title="Example GraphQL query"
query PageShieldReports(
	$zoneTag: string
	$datetimeStart: Time
	$datetimeEnd: Time
) {
	viewer {
		zones(filter: { zoneTag: $zoneTag }) {
			pageShieldReportsAdaptiveGroups(
				limit: 100
				orderBy: [datetime_ASC]
				filter: { datetime_geq: $datetimeStart, datetime_leq: $datetimeEnd }
			) {
				avg {
					sampleInterval
				}
				count
				dimensions {
					policyID
					datetime
					datetimeMinute
					datetimeFiveMinutes
					datetimeFifteenMinutes
					datetimeHalfOfHour
					datetimeHour
					url
					urlHost
					host
					resourceType
					pageURL
					action
				}
			}
		}
	}
}
```

## Logpush를 통해 정책 위반

[Cloudflare로 푸쉬](/logs/logpush/)저장 서비스에 푸시 로그를 지원,<GlossaryTooltip term="SIEM">SIEM 시스템</GlossaryTooltip>, 그리고 로그 관리 공급자.

정책 위반에 대한 정보[`page_shield_events`데이터셋](/logs/logpush/logpush-job/datasets/zone/page_shield_events/).

Logpush 작업 구성에 대한 자세한 내용은 참조[다운로드](/logs/logpush/)문서.

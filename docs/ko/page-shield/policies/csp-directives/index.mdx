페이지 방패[회사연혁](/page-shield/policies/)가장 많이<GlossaryTooltip term="content security policy (CSP)">콘텐츠 보안 정책 (CSP)</GlossaryTooltip>두 개의 모니터 및 unmonitored 리소스를 다루는 지침. 스크립트와 그 연결 외에 다른 유형의 리소스를 제어하는 정책을 사용할 수 있습니다, 심지어 'Cloudflare'는 이러한 리소스를 모니터링하지 않습니다.

각 CSP 지시어는 다음과 같은 여러 값을 포함할 수 있다:

- 계정 만들기
- 이름 \*
- 한국어
- 단일 인용 사이의 특수 키워드 (예를 들어,`'none'`)
- 단일 인용 (예를 들어,`'sha384-oqVuAfXRKap7fdgcCY5uykM6+R9GqQ8K/uxy9rx7HNQlGYl1kPzQho1wx4JwY8wC'`)

Hostname 및 URI 값 지원`*`왼손잡이를 위한 wildcard.

다음 표는 CSP 지침 및 정책에서 사용할 수있는 특수 값을 나열합니다.

| 제품 정보                       | 대시보드의 이름          | 특수 값 지원                                                                            | 계정 관리                                                        |
| --------------------------- | ----------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------ |

| `frame-src`                 | 회사 소개             | `'none'`<br />`'self'`<br />`'unsafe-inline'`<br />`'unsafe-eval'`<br />`'<HASH>'` | 이름 \*                                                        |

기업 계획에서 고객에게 유료 추가 기능으로 제공됩니다.
주요 특징

Cloudflare는 도메인의 페이지에 JavaScript 의존성을 분석합니다.

알림을 구성할 수 있습니다[코드 변경 경고](/page-shield/alerts/alert-types/#code-change-alert)도메인에서 변경된 스크립트에 대한 일일 알림을 수신합니다.

그런 알림을 받으면:

<Steps>
  {/* prettier-ignore-start */}

  1. 클라이언트 측 리소스 페이지로 이동:

     <Tabs syncKey="dashNewNav">
       <TabItem label="새로운 ‘대시보드’" icon="rocket">
         1. 'Cloudflare'에서 '대시보드'로 이동**웹 자산**사이트 맵

            <DashButton url="/?to=/:account/:zone/security/web-assets" />

         2. 선택하기**고객 서비스**탭.
       </TabItem>

       <TabItem label="'대시보드'">
         1. 로그인하기[‘Cloudflare’ ‘대시보드’](https://dash.cloudflare.com/), 귀하의 계정과 도메인을 선택합니다.
         2. 오시는 길**보안 보안** > **페이지 방패**.
       </TabItem>
     </Tabs>

  2. 각 변경된 스크립트의 세부 사항을 확인하고 예상되는 변경 사항이 있는 경우 유효하다.

  {/* prettier-ignore-end */}
</Steps>

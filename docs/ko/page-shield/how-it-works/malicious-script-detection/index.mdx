이 기능은 엔터프라이즈 플랜에서 고객을 위한 유료 애드온으로 제공됩니다.
주요 특징

Cloudflare는 스크립트, 또는 스크립트에 의해 만들어진 연결을 결정하는 다른 메커니즘을 사용한다. 이 기계장치는:

- Malicious 스크립트 탐지
- 맛있는 URL 체크
- Malicious 도메인 확인

위협 피드에 대한 모든 업데이트는 이전에 감지 된 스크립트 또는 연결에 대한 새로운 체크를 트리거합니다. 클라이언트 측 리소스 모니터링 '대시 보드'는 항상 최신 categorization을 반영합니다.

## Malicious 스크립트 탐지

이 유형의 감지에서 Cloudflare는 스크립트 파일을 다운로드하고 classifier를 통해 실행합니다. classifier는 기계 학습 (ML) 모델로 악성 작업의 패턴을 감지하는 것을 배웠습니다.[Magecart 유형 공격](https://sansec.io/what-is-magecart).

스크립트 클래스터는 스크립트에 대한 확률 점수를 출력합니다 (또한 JS 무결성 점수라고도 함) 1과 99 사이, 어느 의미는 확실히 악의적이고 99는 확실히 악의적. 이 점수는 임계값과 함께, 악의적인 스크립트 감지 시스템이 악성 스크립트를 악의적으로 분류할 것인지 결정합니다.

스크립트를 악성로 고려하는 점수 임계 값은 현재 10로 설정됩니다. 스크립트 분류 점수가 이 값의 밑에 있는 경우, 모니터링 대시보드는 악성코드를 표시한다.

무결성 점수 외에도, Cloudflare는 다른 악성 코드 탐지에 대한 개별 점수를 제공합니다 (scores from 1 to 99):

- **언어 선택**
- **Crypto 광산**
- **말웨어**

당신은 할 수[Malicious Script Alerts 구성](/page-shield/alerts/configure/)Cloudflare가 도메인에서 악성코드로 분류된 JavaScript코드를 감지하면 알림을 받게 됩니다.

:::참조
현재 스크립트 classifier는 최대 300 KB의 스크립트에서만 실행됩니다. 위협 인텔리전스 피드를 기반으로 한 신호와 같은 모니터링 전략의 다른 신호를 고려하는 것이 좋습니다. (말릴 URL / 도메인 확인).
주요 특징

## 맛있는 URL 체크

Cloudflare는 위협 인텔리전스에서 JavaScript 의존성의 URL을 검색하여 그 스크립트가 악화되어 있는지 결정합니다.

클라이언트 사이드 리소스 모니터링 대시보드는 스크립트 목록의 상단에 악의적으로 간주 된 스크립트를 표시합니다.

당신은 할 수[Malicious URL 경고 설정](/page-shield/alerts/configure/)'Cloudflare\`가 도메인의 악성 URL에서 스크립트를 감지하면 알림을 받게 됩니다.

현재 구성에 따라, Cloudflare는 도메인의 스크립트에 의해 만들어진 URL의 악성 URL을 검색할 수 있습니다. 이 체크를 활성화하려면[리소스 모니터링을 사용하여 전체 URL을 outgoing 연결](/page-shield/reference/settings/#connection-target-details)대신 설정 페이지의 호스트 이름.

## Malicious 도메인 확인

Cloudflare는 클라이언트 측의 도메인을 검색합니다. JavaScript는 위협 피드에 의존합니다. 그 스크립트가 알려진 악의적인 도메인에서 제공됩니다.

먼저 악의적 인 것으로보고 된 도메인은 나중에 더 많은 분석 후 비 맛있는 것으로보고되어 도메인은 안전합니다.

Cloudflare는 스크립트에 설명된 동일한 접근법을 따르는 도메인의 페이지에 스크립트에 의해 만들어진 연결의 대상 도메인을 확인합니다.

당신은 할 수[Malicious Domain Alerts 구성](/page-shield/alerts/configure/)'Cloudflare'가 도메인에서 알려진 악성 도메인에서로드 된 악성 스크립트를 감지 한 즉시 알림을받을 수 있습니다.

***

## 악성 스크립트 및 연결 카테고리

위협 인텔리전스 피드에서 데이터에 근거한 Scripts 및 연결. 현재 범주는 다음과 같습니다 :

- 보안 위협
- 명령 및 제어 (C2) 및 Botnet
- Crypto 광산
- 스파이웨어
- 한국어
- 말웨어
- Domain Generation Algorithm (DGA) 도메인
- 타이포쿼팅 & 임인

각 스크립트 또는 연결은 악의적으로 인해 여러 범주에 속할 수 있습니다.

Page Shield는 관리<GlossaryTooltip term="client-side resource" prepend="A client-side resource is ">클라이언트 측 자원</GlossaryTooltip>(스크립트 및 연결 포함) 귀하의 웹 사이트 방문자에 의해로드, 그리고에 대한 가시성을 제공합니다[제품 정보](https://www.cloudflare.com/learning/privacy/what-are-cookies/)최근 HTTP 트래픽에서 감지. Page Shield는 리소스 변경 시 알림을 트리거하거나 악의적으로 간주할 수 있습니다.

Enabling 리소스 모니터링 추가<GlossaryTooltip term="content security policy (CSP)" link="https://developer.mozilla.org/en-US/docs/Web/HTTP/CSP">콘텐츠 보안 정책 (CSP)</GlossaryTooltip>에 게시 됨[보고서-only 지시어](/page-shield/reference/csp-header/)브라우저에서 정보를 수집합니다. 이것은 'Cloudflare를 허용하여 응용 프로그램에서 실행되는 모든 스크립트의 목록을 제공하고 연결은 타사 엔드 포인트로 만듭니다. Cloudflare\`는 또한 쿠키에 대한 진입 및 egress 트래픽을 모니터링하고, 원래 서버 또는 방문자의 브라우저에 의해 설정.

클라이언트 사이드 리소스 모니터링 대시보드는 활성 스크립트, 연결, 쿠키의 목록을 보여줍니다. 더 보기**모든 보고된 스크립트**·**모든 보고된 연결**대시보드는 각 도메인에서 검출된 스크립트와 연결의 전체 목록을 보여준다.

Cloudflare는 웹 페이지 리소스를 전송하는 데 사용되는 CSP 보고서 전용 HTTP 헤더를 추가합니다. 이것은 그것이 될 수 있음을 의미합니다.[작은 지연](/page-shield/troubleshooting/#cloudflare-does-not-show-any-client-side-resources-after-activation)스크립트나 쿠키를 배포하고 자원 모니터링에 표시된 데이터가 ‘대시보드’입니다.

유료 애드온을 가진 기업 고객은 추가 분류 메커니즘에 액세스 할 수 있습니다 위협 피드를 기반으로 스크립트, 또는 스크립트에 의해 만들어진 연결, 악의. 더 많은 정보를 원하시면, 참조[악성 스크립트 및 연결 탐지](/page-shield/how-it-works/malicious-script-detection/).

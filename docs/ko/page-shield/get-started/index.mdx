## 1. 클라이언트 측 자원 감시를 활성화하십시오

클라이언트 측 자원 감시를 가능하게 하기 위하여:

<Tabs syncKey="dashNewNav">
  <TabItem label="새로운 ‘대시보드’" icon="rocket">
    <Steps>
      1. ‘Cloudflare’ ‘대시보드’에서 보안으로 이동**계정 설정**사이트 맵

         <DashButton url="/?to=/:account/:zone/security/settings" />

      2. (선택) 필터 로**고객 측 남용**.

      3. 기타 제품**연속 스크립트 모니터링**.
    </Steps>
  </TabItem>

  <TabItem label="'대시보드'">
    <Steps>
      1. 로그인하기[‘Cloudflare’ ‘대시보드’](https://dash.cloudflare.com/), 귀하의 계정과 도메인을 선택합니다.
      2. 오시는 길**보안 보안** > **페이지 방패**.
      3. 제품정보**Enable 페이지 방패**.
    </Steps>
  </TabItem>
</Tabs>

'Cloudflare' 대시보드에서 Page Shield에 액세스하지 않은 경우, 사용자 중 하나가 있는지 확인[필요한 역할](/page-shield/reference/roles-and-permissions/).

## 2. 검토 감지 된 리소스

클라이언트 측 리소스 모니터링을 활성화하면 도메인에서 감지된 스크립트 목록을 얻을 수 있습니다.

Cloudflare에 의해 검출된 스크립트를 검토하려면:

<Steps>
  {/* prettier-ignore-start */}

  1. 클라이언트 측 리소스 페이지로 이동:

     <Tabs syncKey="dashNewNav">
       <TabItem label="새로운 ‘대시보드’" icon="rocket">
         1. 'Cloudflare'에서 '대시보드'로 이동**웹 자산**사이트 맵

            <DashButton url="/?to=/:account/:zone/security/web-assets" />

         2. 선택하기**고객 서비스**탭.
       </TabItem>

       <TabItem label="'대시보드'">
         1. 로그인하기[‘Cloudflare’ ‘대시보드’](https://dash.cloudflare.com/), 귀하의 계정과 도메인을 선택합니다.
         2. 오시는 길**보안 보안** > **페이지 방패**.
       </TabItem>
     </Tabs>

  2. 검색된 스크립트 목록을 검토, 알 수없는 또는 예기치 않은 스크립트를 검사.<br />
     [당신의 계획에 따라](/page-shield/#availability), Cloudflare도:
     - 스크립트가 있다면[법적 고지](/page-shield/how-it-works/malicious-script-detection/).
     - [자주 묻는 질문](/page-shield/detection/monitor-connections-scripts/#view-details)각 검출된 스크립트에 대해

  {/* prettier-ignore-end */}
</Steps>

계획에 따라 도메인 페이지의 스크립트에 의해 만들어진 연결을 검토하고 악의적 인 활동을 확인 할 수 있습니다.

## 4. (선택) 정의 정책

:::참조
지불한 add-on를 가진 기업 고객에게만 유효한.
주요 특징

[회사연혁](/page-shield/policies/)— 콘텐츠 보안 규칙 호출[새로운 보안 대시보드](/security/)— 웹 사이트에 허용된 리소스를 정의합니다. 긍정적 인 보안 모델을 구현하는 정책 만들기[^1].

[^1]: 긍정적 인 보안 모델은 허용되고 다른 모든 것을 거부하는 것을 정의하는 것입니다. 대조적으로 부정적인 보안 모델은 거부되고 나머지를 수락하는 것을 정의합니다.

### 4.1. 로그 작업에 대한 정책을 작성

당신은 정책을 만들 때[*로그인*이름 \*](/page-shield/policies/#policy-actions), Cloudflare는 모든 리소스를 차단하지 않고 정책에 의해 덮지 않는 리소스를 기록합니다. 이 작업을 사용하여 배포하기 전에 새로운 정책을 검증합니다.

<Render file="policy-create" params={{ policyAction: "Log" }} product="page-shield" />

### 4.2. 정책 위반

당신이 만든 정책에 의해 덮지 않은 자원은보고됩니다[정책 위반](/page-shield/policies/violations/). 몇 번 후, 정책 위반 목록을 검토하여 정책이 정확하다.

<Render file="policy-review-violations" product="page-shield" />

필요한 경우 정책 업데이트.

### 4.3. 허용하는 정책 활동 변경

정책이 정확하다는 것을 확인하면 정책 조치를 변경하십시오.*로그인*으로*지원하다*.

당신이 사용할 때[*지원하다*이름 \*](/page-shield/policies/#policy-actions), Cloudflare는 정책에 따라 명시적으로 허용되지 않은 리소스를 차단 시작합니다.

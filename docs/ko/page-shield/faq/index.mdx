## CSP HTTP 헤더가 정책을 만들 때 원래 서버로 설정됩니까?

<Render file="policy-headers" product="page-shield" />

Page Shield는 새로운 CSP HTTP 헤더를 응답에 추가합니다. 이것은 Cloudflare가 어떤 것을 지킬 것임을 의미합니다.`Content-Security-Policy-Report-Only`·`Content-Security-Policy`HTTP 헤더는 소스 서버에서 설정하고 Cloudflare 영역에 구성 된 정책에 대한 별도의 HTTP 헤더를 추가합니다.

당신은 단지 하나의 정책이 있음을 권장합니다[모드를 허용](/page-shield/policies/#policy-actions)(그는 정책이 시행됨). 하나 이상의 경우`Content-Security-Policy`HTTP 헤더 응답, 가장 제한적 정책 승리. 더 많은 정보를 원하시면, 참조[MDN 문서](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy#multiple_content_security_policies).

## 추가할 수 있습니다.`nonce`정책에 CSP 지침?

Page Shield는 현재 지원하지 않습니다.[`nonce`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP#nonces)정책의 지시. 대신 사용할 수 있습니다.[`hash`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP#hashes)CSP 지침. 지원된 지침과 값에 대한 자세한 내용은 참조[CSP 지침 지원](/page-shield/policies/csp-directives/).

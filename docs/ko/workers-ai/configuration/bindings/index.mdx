## Workers

[Workers](/workers/)Serverless 실행 환경을 제공하여 새로운 응용 프로그램 또는 augment 기존의 것을 만들 수 있습니다.

Workers AIXQXQXQXQXQXQXQ를 사용하려면 Workers AIXQXQ[관련 제품](/workers/runtime-apis/bindings/). 바인딩은 Workers와 Workers AI, Cloudflare 개발자 플랫폼과 같은 리소스와 상호 작용하는 WorkersXQXQ를 허용합니다. QXQX0008XQQdashboardXQXQ에 바인딩을 만들거나 당신의 새롭게 하기에 의하여[Wrangler 파일](/workers/wrangler/configuration/).

Workers AI를 작업자에게 바인딩하려면 Wrangler 파일의 끝에 다음을 추가하십시오.

<WranglerConfig>
  ```jsonc
  {
  	"ai": {
  		"binding": "AI" //i.e. env에 당신의 노동자에서 유효한. 사이트맵
  	}
  }
  ```
</WranglerConfig>

## Pages 기능

[Pages 기능](/pages/functions/)CloudflareQXQXPagesXQ를 사용하여 QXCloudflare 네트워크에서 코드를 실행하여 전체 스택 응용 프로그램을 구축 할 수 있습니다. 기능은 두건의 밑에 Workers입니다.

Pages 기능에서 Workers AI 바인딩을 구성하려면 Cloudflare QXQXdashboardXQ를 사용해야합니다. 더 알아보기[Workers AI 바인딩](/pages/functions/bindings/#workers-ai)자주 묻는 질문

## 제품 설명

### 동기화 env.AI.run()

`async env.AI.run()`모델을 실행합니다. 첫 번째 매개 변수로 모델을 가져, 두 번째 매개 변수로 객체.

```javascript
const answer = await env.AI.run('@cf/meta/llama-3.1-8b-instruct', {
    prompt: "What is the origin of the phrase 'Hello, World'"
});
```

**매개 변수**

- `model` <Type text="string" /> <MetaInfo text="required" />

  - 실행하는 모델.

  **지원 옵션**

  - `stream` <Type text="boolean" /> <MetaInfo text="optional" />
    - 해당 이용 후기에 달린 코멘트가 없습니다.

```javascript
const answer = await env.AI.run('@cf/meta/llama-3.1-8b-instruct', {
    prompt: "What is the origin of the phrase 'Hello, World'",
    stream: true
});

return new Response(answer, {
    headers: { "content-type": "text/event-stream" }
});
```

Workers AI를 사용하여[채팅 UI](https://github.com/huggingface/chat-ui?tab=readme-ov-file#text-embedding-models), Hugging Face가 제공하는 오픈 소스 채팅 인터페이스.

## 자주 묻는 질문

다음이 필요합니다.

- ·[Cloudflare 계정](https://dash.cloudflare.com)
- 내 계정[계정 ID](/fundamentals/account/find-account-and-zone-ids/)
- 이름 \*[API 토큰](/workers-ai/get-started/rest-api/#1-get-api-token-and-account-id)Workers AI를 위해

## 설치하기

먼저, reference 당신의 계정 ID 및 API 토큰에 대한 방법을 결정하십시오 (당신의 계정에 직접`.env.local`사용 방법`CLOUDFLARE_ACCOUNT_ID`·`CLOUDFLARE_API_TOKEN`변수 또는 endpoint 설정에서).

그런 다음 설정 지침의 나머지를 따르십시오.[채팅 UI GitHub 저장소](https://github.com/huggingface/chat-ui?tab=readme-ov-file#text-embedding-models).

모델을 설정할 때, 지정`cloudflare`끝점.

```json
{
  "name" : "nousresearch/hermes-2-pro-mistral-7b",
  "tokenizer": "nousresearch/hermes-2-pro-mistral-7b",
  "parameters": {
    "stop": ["<|im_end|>"]
  },
  "endpoints" : [
    {
      "type": "cloudflare",
      // optionally specify these if not included in .env.local
      "accountId": "your-account-id",
      "apiToken": "your-api-token"
      //
    }
  ]
}
```

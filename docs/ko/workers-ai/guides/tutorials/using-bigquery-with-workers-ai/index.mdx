get started에 가장 쉬운 방법[Workers AI](/workers-ai/)그것을 시도하는[Multi-modal 놀이터](https://multi-modal.ai.cloudflare.com/)그리고[LLM 놀이터](https://playground.ai.cloudflare.com/). 당신이 Workers AIXQ와 코드를 통합하려는 경우, 그 다음 그것을 사용하기로 결정할 수 있습니다[REST API 엔드포인트](/workers-ai/get-started/rest-api/)또는[Worker 바인딩](/workers-ai/configuration/bindings/).

그러나 데이터에 대해? CloudflareXQ 밖에 저장되는 소화 자료에 이 모형을 원하는 경우에?

이 튜토리얼에서는 Google BigQuery에서 Cloudflare에 데이터를 가져올 방법을 배울 수 있습니다. 노동자는 Workers AI 모형을 위해 입력으로 사용될 수 있다 그래야.

## 자주 묻는 질문

당신은 필요로 할 것이다:

- ·[Cloudflare 작업자](/workers/)프로젝트 실행[이름 \* 세계 스크립트](/workers/get-started/guide/).
- Google Cloud 플랫폼[서비스 계정](https://cloud.google.com/iam/docs/service-accounts-create#iam-service-accounts-create-console)이름 \*[관련 키](https://cloud.google.com/iam/docs/keys-create-delete#iam-service-account-keys-create-console)BigQuery에 대한 액세스를 읽은 파일 다운로드.
- BigQuery 테이블에 액세스 할 수있는 몇 가지 테스트 데이터와 함께[BigQuery 작업 쿼리](https://cloud.google.com/bigquery/docs/reference/rest/v2/jobs/query). 이 튜토리얼을 위해 당신은 당신의 자신의 테이블을 만드는 것이 좋습니다[샘플 테이블](https://cloud.google.com/bigquery/public-data#sample_tables), 자신의 GCP 네임스페이스에 복제하지 않는 한, 그에 대해 작업 쿼리를 실행할 수 없습니다. 이 예제의 경우,[해커 뉴스 Corpus](https://www.kaggle.com/datasets/hacker-news/hacker-news-corpus)그것의 MIT 면허의 밑에 사용되었습니다.

## 1. 당신의 Cloudflare를 설치하십시오 작업자

Cloudflare로 데이터를 섭취하고 Workers AIXQ로 피드하면[Cloudflare 작업자](/workers/). 아직 만들지 않은 경우, 우리의 리뷰를 검토하십시오[get started에 대한 자습서](/workers/get-started/).

노동자를 만들 수있는 단계 뒤에, 당신은 당신의 새로운 노동자 프로젝트에 다음 코드를해야:

```javascript
export default {
	async fetch(request, env, ctx) {
		return new Response("Hello World!");
	},
};
```

Worker 프로젝트가 성공적으로 만든 경우, 실행할 수도 있어야 합니다.`npx wrangler dev`로컬 작업자를 실행하는 콘솔에서:

```sh
[wrangler:inf] Ready on http://localhost:8787
```

브라우저 탭 열기`http://localhost:8787/`배포 된 노동자를 볼 수 있습니다. 포트가 있음`8787`당신의 경우에 다른 것일지도 모릅니다.

당신은보고해야합니다`Hello World!`브라우저에서:

```sh
Hello World!
```

이 단계에서 어떤 문제로 실행하면 검토하십시오.[Worker's 시작 가이드](/workers/get-started/guide/).

## 2. 비밀로 노동자로 GCP 서비스 열쇠를 수입하십시오

이제 Worker가 성공적으로 생성 된 것을 확인했습니다. reference의 Google Cloud Platform 서비스 키가 생성되었습니다.[자주 묻는 질문](#prerequisites)이 튜토리얼의 섹션.

Google Cloud Platform의 다운로드된 키 JSON 파일에는 다음과 같은 형식이 있어야 합니다.

```json
{
	"type": "service_account",
	"project_id": "<your_project_id>",
	"private_key_id": "<your_private_key_id>",
	"private_key": "<your_private_key>",
	"client_email": "<your_service_account_id>@<your_project_id>.iam.gserviceaccount.com",
	"client_id": "<your_oauth2_client_id>",
	"auth_uri": "https://accounts.google.com/o/oauth2/auth",
	"token_uri": "https://oauth2.googleapis.com/token",
	"auth_provider_x509_cert_url": "https://www.googleapis.com/oauth2/v1/certs",
	"client_x509_cert_url": "https://www.googleapis.com/robot/v1/metadata/x509/<your_service_account_id>%40<your_project_id>.iam.gserviceaccount.com",
	"universe_domain": "googleapis.com"
}
```

이 튜토리얼의 경우 다음 필드의 값을 필요로합니다.`client_email`, `private_key`, `private_key_id`·`project_id`.

이 정보를 저장하는 대신 일반 텍스트에서 노동자, 당신은 사용할 것입니다[계정 관리](/workers/configuration/secrets/)암호화되지 않은 콘텐츠를 확인하려면 Worker 자체를 통해 접근 할 수 있습니다.

JSON 파일에서 JSON 키 파일로 시작된 Secrets로 3개의 값을 가져옵니다.`client_email`우리가 지금 호출 할 것`BQ_CLIENT_EMAIL`(다른 변수 이름을 사용할 수 있습니다):

```sh
npx wrangler secret put BQ_CLIENT_EMAIL
```

필드의 값이 될 비밀 값을 입력하도록 요청됩니다.`client_email`JSON 키 파일에서.

:::참조

저장하는 비밀에 두 배 따옴표를 포함하지 마십시오. 문자열로 이미 해석됩니다.

:::

비밀이 성공적으로 업로드되면 다음 메시지가 표시됩니다.

```sh
✨ Success! Uploaded secret BQ_CLIENT_EMAIL
```

이제 나머지 세 가지 필드에 대한 비밀을 가져;`private_key`, `private_key_id`·`project_id`이름 \*`BQ_PRIVATE_KEY`, `BQ_PRIVATE_KEY_ID`·`BQ_PROJECT_ID`각각:

```sh

```

```sh
npx wrangler secret put BQ_PRIVATE_KEY_ID
```

```sh

```

이 시점에서 Google Cloud Platform에서 Cloudflare Secrets로 다운로드 한 JSON 키 파일에서 3 필드를 성공적으로 수입했습니다.

[계정 관리](/workers/configuration/secrets/)한 번에 WorkersXQ에서만 사용할 수 있습니다. 개발 중에 사용할 수 있도록[더 보기`.dev.vars`](/workers/configuration/secrets/#local-development-with-secrets)로컬로 이러한 자격 증명과 referenceXQ를 저장할 수 있는 파일.

내 계정`dev.vars`파일은 다음과 같습니다 :

```
BQ_CLIENT_EMAIL="<your_service_account_id>@<your_project_id>.iam.gserviceaccount.com"
BQ_CLIENT_KEY="-----BEGIN PRIVATE KEY-----<content_of_your_private_key>-----END PRIVATE KEY-----\n"
BQ_PRIVATE_KEY_ID="<your_private_key_id>"

```

자주 묻는 질문`.dev.vars`당신의 프로젝트`.gitignore`버전 컨트롤을 사용할 때 저장소에 업로드되는 자격 증명을 방지하기 위해 파일.

비밀을 확인하는 것은 제대로로드됩니다.`src/index.js`다음과 같이 콘솔 출력으로 값을 기록함으로써:

## 3. JWT 작업을 처리하는 라이브러리 설치

BigQuery의 REST API와 상호 작용하려면, 생성해야 할 것입니다[JSON 웹 토큰](https://jwt.io/introduction)이전 단계에서 Worker secrets로 로드한 credentials를 사용하여 요청을 인증합니다.

이 튜토리얼의 경우, 당신은 사용할 것입니다[뚱 베어](https://www.npmjs.com/package/jose?activeTab=readme)JWT 관련 업무용 라이브러리. 콘솔에서 다음 명령을 실행하여 설치:

```sh
npm i jose
```

설치가 성공했는지 확인하려면 실행할 수 있습니다.`npm list`모든 설치 패키지를 나열하는 경우 확인하려면`jose`의존도가 추가되었습니다 :

```sh
<project_name>@0.0.0
/<path_to_your_project>/<project_name>
├── @cloudflare/vitest-pool-workers@0.4.29
├── jose@5.9.2
├── vitest@1.5.0
└── wrangler@3.75.0
```

## 4. JSON 웹 토큰 생성

이제 설치했습니다.`jose`라이브러리, 그것을 가져올 시간이며 서명 된 JSON Web Token (JWT)을 생성하는 코드를 사용하여 기능을 추가합니다.

```javascript
import * as jose from 'jose';
...
const generateBQJWT = async (aCryptoKey, env) => {
const algorithm = "RS256";
const audience = "https://bigquery.googleapis.com/";
const expiryAt = (new Date().valueOf() / 1000);
	const privateKey = await jose.importPKCS8(env.BQ_PRIVATE_KEY, algorithm);

	//서명된 JSON 웹 토큰 생성 (JWT)
	return new jose.SignJWT()
    	.setProtectedHeader({
        	typ: 'JWT',
        	alg: algorithm,
        	kid: env.BQ_PRIVATE_KEY_ID
    	})
    	.setIssuer(env.BQ_CLIENT_EMAIL)
    	.setSubject(env.BQ_CLIENT_EMAIL)
    	.setAudience(audience)
    	.setExpirationTime(expiryAt)
    	.setIssuedAt()
    	.sign(privateKey)
}

export default {
	async fetch(request, env, ctx) {
       ...
//BigQuery API 호출을 인증하는 JWT 생성
    	let bqJWT;
    	try {
        	bqJWT = await generateBQJWT(env);
    	} catch (e) {
        	return new Response('An error has occurred while generating the JWT', { status: 500 })
    	}
	},
       ...
};

```

이제 JWT를 만들었을 때 BigQuery에 API 호출을 할 때 일부 데이터를 fetch합니다.

## 5. Google BigQuery에 대한 인증 요청 확인

이전 단계에서 생성 된 JWT 토큰을 사용하면 BigQuery의 API에 API 요청을 배치하여 테이블에서 데이터를 검색합니다.

이제 BigQuery에서 만든 테이블을 쿼리합니다. 이 예제는 샘플 버전의 사용[해커 뉴스 Corpus](https://www.kaggle.com/datasets/hacker-news/hacker-news-corpus)MIT 라이센스에 따라 사용되었고 BigQuery에 업로드되었습니다.

```javascript
const queryBQ = async (bqJWT, path) => {
	const bqEndpoint = `https://bigquery.googleapis.com${path}`
	//이 예에서 텍스트는 queried (hn.news sampled) 인 BigQuery 테이블의 필드입니다.
	const query = 'SELECT text FROM hn.news_sampled LIMIT 3';
	const response = await fetch(bqEndpoint, {
    	method: "POST",
    	body: JSON.stringify({
        	"query": query
    	}),
    	headers: {
        	Authorization: `Bearer ${bqJWT}`
    	}
	})
	return response.json()
}
...
export default {
	async fetch(request, env, ctx) {
		...
    		let ticketInfo;
    		try {
    		ticketInfo = await queryBQ(bqJWT);
    	} catch (e) {
        	return new Response('An error has occurred while querying BQ', { status: 500 });
    	}
	...
	},
};
```

BigQuery에서 원시 행 데이터를 가지고 이제 JSON-like 스타일에 형식 할 수 있음을 의미합니다.

## 6. 쿼리의 형식 결과

BigQuery에서 데이터를 검색 한 적이 있습니까? BigQuery API 응답은 다음과 같습니다.

```json
{
	...
	"schema": {
    	"fields": [
        	{
            	"name": "title",
            	"type": "STRING",
            	"mode": "NULLABLE"
        	},
        	{
            	"name": "text",
            	"type": "STRING",
            	"mode": "NULLABLE"
        	}
    	]
	},
	...
	"rows": [
    	{
        	"f": [
            	{
                	"v": "<some_value>"
            	},
            	{
                	"v": "<some_value>"
            	}
        	]
    	},
    	{
        	"f": [
            	{
                	"v": "<some_value>"
            	},
            	{
                	"v": "<some_value>"
            	}
        	]
    	},
    	{
        	"f": [
            	{
                	"v": "<some_value>"
            	},
            	{
                	"v": "<some_value>"
            	}
        	]
    	}
	],
	...
}
```

이 형식은 결과를 통해 시도 할 때 읽고 작업 할 수 있습니다. 그래서 당신은 이제 각 개별 값으로 스키마를지도 할 수있는 기능을 구현하고, 결과 출력은 아래에 표시된 것처럼 읽기 쉽게 될 것입니다. 각 행은 배열 내에서 객체에 대응합니다.

```javascript
[
	{
		title: "<some_value>",
		text: "<some_value>",
	},
	{
		title: "<some_value>",
		text: "<some_value>",
	},
	{
		title: "<some_value>",
		text: "<some_value>",
	},
];
```

이름 \*`formatRows`BigQuery 응답 몸에서 반환된 행과 필드의 수를 가지고 있으며, 지정된 필드와 객체의 배열을 반환합니다.

```javascript
const formatRows = (rowsWithoutFieldNames, fields) => {
	//필드 이름에 색인
	const fieldsByIndex = new Map();

	//이름에 의해 모든 필드를로드하고 자신의 키로 배열 결과에 색인을 가지고
	fields.forEach((field, index) => {
    	fieldsByIndex.set(index, field.name)
	})

	//행을 통해서 Iterate
	const rowsWithFieldNames = rowsWithoutFieldNames.map(row => {
    	//각 행마다 배열 f에 의해 대표되고, 이름이 지정된 값을 통해 입력되고 필드ByIndex에서 검색하여 필드 이름을 찾습니다.
    	let newRow = {}
    	row.f.forEach((field, index) => {
        	const fieldName = fieldsByIndex.get(index);
        	if (fieldName) {
		//행에 각 필드를 들어, newRow에 추가
            	newRow = ({ ...newRow, [fieldName]: field.v });
        	}
    	})
    	return newRow
	})

	return rowsWithFieldNames
}

export default {
	async fetch(request, env, ctx) {
		...
    	//지정된 필드를 가진 물체의 배열으로 출력 형식
    	let formattedResults;

    	if ('rows' in ticketInfo) {
        	formattedResults = formatRows(ticketInfo.rows, ticketInfo.schema.fields);
        	console.log(formattedResults)
    	} else if ('error' in ticketInfo) {
        	return new Response(ticketInfo.error.message, { status: 500 })
    	}
	...
	},
};
```

## 7. Workers AI로 급식 자료

이제 BigQuery API에서 응답을 결과의 배열으로 변환하고 일부 태그를 생성하고 LLM을 사용하여 관련 침입 점수를 첨부[Workers AI](/workers-ai/):

```javascript
const generateTags = (data, env) => {
	return env.AI.run("@cf/meta/llama-3.1-8b-instruct", {
    	prompt: `Create three one-word tags for the following text. return only these three tags separated by a comma. don't return text that is not a category.Lowercase only. ${JSON.stringify(data)}`,
	});
}

const generateSentimentScore = (data, env) => {
	return env.AI.run("@cf/meta/llama-3.1-8b-instruct", {
    	prompt: `return a float number between 0 and 1 measuring the sentiment of the following text. 0 being negative and 1 positive. return only the number, no text. ${JSON.stringify(data)}`,
	});
}

//가치를 통해 AI 핸들러에 보내고 단일 약속으로 모든 응답을 캡슐화
const getAIGeneratedContent = (data, env, aiHandler) => {
	let results = data?.map(dataPoint => {
    	return aiHandler(dataPoint, env)
	})
	return Promise.all(results)
}
...
export default {
	async fetch(request, env, ctx) {
		...
let summaries, sentimentScores;
    	try {
        	summaries = await getAIGeneratedContent(formattedResults, env, generateTags);
        	sentimentScores = await getAIGeneratedContent(formattedResults, env, generateSentimentScore)
    	} catch {
        	return new Response('There was an error while generating the text summaries or sentiment scores')
    	}
},

formattedResults = formattedResults?.map((formattedResult, i) => {
        	if (sentimentScores[i].response && summaries[i].response) {
            	return {
                	...formattedResult,
                	'sentiment': parseFloat(sentimentScores[i].response).toFixed(2),
                	'tags': summaries[i].response.split(',').map((result) => result.trim())
            	}
        	}
    	}
};

```

## 최종 결과

다른 단계에 표시된 모든 코드는 다음 코드에 결합됩니다`src/index.js`:

```javascript
import * as jose from "jose";

const generateBQJWT = async (env) => {
	const algorithm = "RS256";
	const audience = "https://bigquery.googleapis.com/";
	const expiryAt = new Date().valueOf() / 1000;
	const privateKey = await jose.importPKCS8(env.BQ_PRIVATE_KEY, algorithm);

	//서명된 JSON 웹 토큰 생성 (JWT)
	return new jose.SignJWT()
		.setProtectedHeader({
			typ: "JWT",
			alg: algorithm,
			kid: env.BQ_PRIVATE_KEY_ID,
		})
		.setIssuer(env.BQ_CLIENT_EMAIL)
		.setSubject(env.BQ_CLIENT_EMAIL)
		.setAudience(audience)
		.setExpirationTime(expiryAt)
		.setIssuedAt()
		.sign(privateKey);
};

const queryBQ = async (bgJWT, path) => {
	const bqEndpoint = `https://bigquery.googleapis.com${path}`;
	const query = "SELECT text FROM hn.news_sampled LIMIT 3";
	const response = await fetch(bqEndpoint, {
		method: "POST",
		body: JSON.stringify({
			query: query,
		}),
		headers: {
			Authorization: `Bearer ${bgJWT}`,
		},
	});
	return response.json();
};

const formatRows = (rowsWithoutFieldNames, fields) => {
	//필드 이름에 색인
	const fieldsByIndex = new Map();

	fields.forEach((field, index) => {
		fieldsByIndex.set(index, field.name);
	});

	const rowsWithFieldNames = rowsWithoutFieldNames.map((row) => {
		//Map rows into a array of object 와 필드 이름
		let newRow = {};
		row.f.forEach((field, index) => {
			const fieldName = fieldsByIndex.get(index);
			if (fieldName) {
				newRow = { ...newRow, [fieldName]: field.v };
			}
		});
		return newRow;
	});

	return rowsWithFieldNames;
};

const generateTags = (data, env) => {
	return env.AI.run("@cf/meta/llama-3.1-8b-instruct", {
		prompt: `Create three one-word tags for the following text. return only these three tags separated by a comma. don't return text that is not a category.Lowercase only. ${JSON.stringify(data)}`,
	});
};

const generateSentimentScore = (data, env) => {
	return env.AI.run("@cf/meta/llama-3.1-8b-instruct", {
		prompt: `return a float number between 0 and 1 measuring the sentiment of the following text. 0 being negative and 1 positive. return only the number, no text. ${JSON.stringify(data)}`,
	});
};

const getAIGeneratedContent = (data, env, aiHandler) => {
	let results = data?.map((dataPoint) => {
		return aiHandler(dataPoint, env);
	});
	return Promise.all(results);
};

export default {
	async fetch(request, env, ctx) {
		//BigQuery API 호출을 인증하는 JWT 생성
		let bqJWT;
		try {
			bqJWT = await generateBQJWT(env);
		} catch (error) {
			console.log(error);
			return new Response("An error has occurred while generating the JWT", {
				status: 500,
			});
		}

		//BigQuery에서 Fetch 결과
		let ticketInfo;
		try {
			ticketInfo = await queryBQ(
				bqJWT,
				`/bigquery/v2/projects/${env.BQ_PROJECT_ID}/queries`,
			);
		} catch (error) {
			console.log(error);
			return new Response("An error has occurred while querying BQ", {
				status: 500,
			});
		}

		//지정된 필드를 가진 물체의 배열으로 출력 형식
		let formattedResults;
		if ("rows" in ticketInfo) {
			formattedResults = formatRows(ticketInfo.rows, ticketInfo.schema.fields);
		} else if ("error" in ticketInfo) {
			return new Response(ticketInfo.error.message, { status: 500 });
		}

		//AI 요약 및 감정 점수 생성
		let summaries, sentimentScores;
		try {
			summaries = await getAIGeneratedContent(
				formattedResults,
				env,
				generateTags,
			);
			sentimentScores = await getAIGeneratedContent(
				formattedResults,
				env,
				generateSentimentScore,
			);
		} catch {
			return new Response(
				"There was an error while generating the text summaries or sentiment scores",
			);
		}

		//이전 결과에 AI summaries 및 sentiment 점수 추가
		formattedResults = formattedResults?.map((formattedResult, i) => {
			if (sentimentScores[i].response && summaries[i].response) {
				return {
					...formattedResult,
					sentiment: parseFloat(sentimentScores[i].response).toFixed(2),
					tags: summaries[i].response.split(",").map((result) => result.trim()),
				};
			}
		});

		const response = { data: formattedResults };

		return new Response(JSON.stringify(response), {
			headers: { "Content-Type": "application/json" },
		});
	},
};
```

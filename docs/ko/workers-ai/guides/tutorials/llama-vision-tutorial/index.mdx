## 자주 묻는 질문

시작하기 전에 다음을해야합니다.

1. ·[Cloudflare 계정](https://dash.cloudflare.com/sign-up)Workers 및 Workers AIXQ 활성화.
2. 내 계정`CLOUDFLARE_ACCOUNT_ID`·`CLOUDFLARE_AUTH_TOKEN`.
   - API 토큰 아래 Cloudflare dashboardXQ에서 API 토큰을 생성할 수 있습니다.
3. Node.jsXQ는 Cloudflare Workers (선택적인 그러나 추천되는)와 일하기 위하여 설치했습니다.

## 1. Meta의 라이선스에 동의

당신이 사용하는 첫 번째 시간[Llama 3.2 11B 시각 지시](/workers-ai/models/llama-3.2-11b-vision-instruct)모델, Meta의 라이센스 및 허용 사용 정책에 동의해야합니다.

```bash title="curl"
curl https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/ai/run/@cf/meta/llama-3.2-11b-vision-instruct \
  -X POST \
  -H "Authorization: Bearer $CLOUDFLARE_AUTH_TOKEN" \
  -d '{ "prompt": "agree" }'
```

기타 제품`$CLOUDFLARE_ACCOUNT_ID`·`$CLOUDFLARE_AUTH_TOKEN`실제 계정 ID 및 토큰으로.

## 2. Cloudflare 작업자

1. Worker 프로젝트 만들기
   새로운 Worker 프로젝트를 만들 것입니다.`create-cloudflare`클립 (`C3`). 이 도구는 설정과 Cloudflare에 새로운 응용 프로그램을 배포하는 단순화.

   터미널에서 다음 명령을 실행:

<PackageManagers type="create" pkg="cloudflare@latest" args={"llama-vision-tutorial"} />

<Render
  file="c3-post-run-steps"
  product="workers"
  params={{
  	category: "hello-world",
  	type: "Worker only",
  	lang: "JavaScript",
  }}
/>

설정 완료 후, 새로운 디렉토리 호출`llama-vision-tutorial`생성됩니다.

2. 애플리케이션 디렉토리에 Navigate
   프로젝트 디렉토리로 변경:

   ```bash
   cd llama-vision-tutorial
   ```

3. 프로젝트 구조
   내 계정`llama-vision-tutorial`디렉토리는 다음과 같습니다:
   - "Hello World"에서 노동자`src/index.ts`.
   - ·`wrangler.json`설정 관리 설정을위한 구성 파일.

## 3. Worker 코드를 작성

수정하기`src/index.ts`(주)`index.js`TypeScript) 파일을 사용하지 않고 다음 코드로 콘텐츠를 교체하십시오.

```javascript
export interface Env {
  AI: Ai;
}

export default {
  async fetch(request, env): Promise<Response> {
    const messages = [
      { role: "system", content: "You are a helpful assistant." },
      { role: "user", content: "Describe the image I'm providing." },
    ];

    //base64 또는 URL로 인코딩된 이미지 데이터로 이것을 대체하십시오.
    const imageBase64 = "data:image/png;base64,IMAGE_DATA_HERE";

    const response = await env.AI.run("@cf/meta/llama-3.2-11b-vision-instruct", {
      messages,
      image: imageBase64,
    });

    return Response.json(response);
  },
} satisfies ExportedHandler<Env>;
```

## 4. 당신의 노동자에 Bind Workers AI

1. 자주 묻는 질문[Wrangler 구성 파일](/workers/wrangler/configuration/)그리고 뒤에 오는 윤곽을 추가하십시오:

<WranglerConfig>
  ```jsonc
  {
  	"env": {},
  	"ai": {
  		"binding": "AI"
  	}
  }
  ```
</WranglerConfig>

2. 파일 저장.

## 5. 노동자를 배포

다음 명령을 실행하여 노동자를 배치하십시오.

```bash
wrangler deploy
```

## 6. 당신의 노동자를 시험하십시오

1. 배포 후, 당신은 당신의 노동자를위한 독특한 URL을 받게됩니다 (예를 들어,`https://llama-vision-tutorial.<your-subdomain>.workers.dev`).
2. 같은 도구 사용`curl`또는 Postman은 당신의 노동자에 요구에 보내기 위하여:

```bash
curl -X POST https://llama-vision-tutorial.<your-subdomain>.workers.dev \
  -d '{ "image": "BASE64_ENCODED_IMAGE" }'
```

기타 제품`BASE64_ENCODED_IMAGE`실제 base64 인코딩된 이미지 문자열로.

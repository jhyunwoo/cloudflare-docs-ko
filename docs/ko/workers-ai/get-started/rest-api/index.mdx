이 가이드는 첫 번째 Workers AI 프로젝트를 설정하고 배포 할 수 있습니다. QXQX0040XQREST API를 사용하여 큰 언어 모델 (LLM)을 실험합니다.

## 자주 묻는 질문

로그인[Cloudflare 계정](https://dash.cloudflare.com/sign-up/workers-and-pages)이미 없다면.

## 1. API 토큰 및 계정 ID 받기

REST API를 사용하려면 API 토큰 및 계정 ID가 필요합니다.

이 값을 얻기:

1. Cloudflare dashboard에서, 갑니다**Workers AI**사이트 맵

   <DashButton url="/?to=/:account/ai/workers-ai" />
2. 제품정보**REST API 사용**.
3. API 토큰 받기:
   1. 제품정보**Workers AI API 토큰 생성**.
   2. 사전 작성된 정보를 검토합니다.
   3. 제품정보**API 만들기 토큰 토큰**.
   4. 제품정보**복사 API 토큰 토큰**.
   5. 미래에 대한 가치 저장.
4. 제품 정보**계정 ID**, 값을 위한 복사**계정 ID**. 미래 사용에 대한 그 가치를 저장합니다.

:::참조

당신이 선택하는 경우에[API 토큰 생성](/fundamentals/api/get-started/create-token/)템플릿을 사용하는 대신, 토큰은 모두에 대한 권한이 필요합니다.`Workers AI - Read`·`Workers AI - Edit`.

:::

## 2. API를 통해 모델을 실행

API 토큰을 생성한 후 API 토큰을 사용하여 API에 요청을 전달합니다.

당신은 사용할 것이다[AI 모델 실행](/api/resources/ai/methods/run/)끝점 실행[`@cf/meta/llama-3.1-8b-instruct`](/workers-ai/models/llama-3.1-8b-instruct/)모델:

```bash
curl https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/run/@cf/meta/llama-3.1-8b-instruct \
  -H 'Authorization: Bearer {API_TOKEN}' \
  -d '{ "prompt": "Where did the phrase Hello World come from" }'
```

값 바꾸기`{ACCOUNT_ID}`·`{API_TOKEN}`.

API 응답은 다음과 같습니다 :

```json
{
	"result": {
		"response": "Hello, World first appeared in 1974 at Bell Labs when Brian Kernighan included it in the C programming language example. It became widely used as a basic test program due to simplicity and clarity. It represents an inviting greeting from a program to the world."
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

이 예제 실행은`@cf/meta/llama-3.1-8b-instruct`모형, 그러나 당신은 모형의 어떤을 안으로 사용할 수 있습니다[Workers AI 모델 카탈로그](/workers-ai/models/). 다른 모형을 사용하는 경우에, 당신은 대체할 필요가 있을 것입니다`{model}`원하는 모델 이름과 함께.

이 가이드를 완료하면 Cloudflare 계정 (당신은 이미 하나이없는 경우) 및 Workers AIXQ를 부여하는 API 토큰이 계정에 권한을 읽습니다. 당신은 실행[`@cf/meta/llama-3.1-8b-instruct`](/workers-ai/models/llama-3.1-8b-instruct/)터미널에서 cURL 명령을 사용하여 JSON 응답에서 신속한 답변을 받았습니다.

## 1. Worker 프로젝트 만들기

새로운 Worker 프로젝트를 만들 것입니다.`create-cloudflare`CLI (C3).[사이트맵](https://github.com/cloudflare/workers-sdk/tree/main/packages/create-cloudflare)Cloudflare에 새 응용 프로그램을 설정하고 배치하는 데 도움이되는 명령줄 도구입니다.

새 프로젝트 만들기`hello-ai`으로 실행:

<PackageManagers type="create" pkg="cloudflare@latest" args={"hello-ai"} />

(주)`npm create cloudflare@latest`설치하기[`create-cloudflare`제품 설명](https://www.npmjs.com/package/create-cloudflare), 그리고 설치를 통해 당신을 지도하십시오. C3도 설치[모델 번호: Wrangler](/workers/wrangler/)Cloudflare 개발자 플랫폼 CLI.

이것은 새로운 것`hello-ai`디렉토리. 당신의 새로운`hello-ai`디렉토리는 다음과 같습니다:

- ·`"Hello World"` [작업자](/workers/get-started/guide/#3-write-code)에 의해`src/index.ts`.
- ·[`wrangler.jsonc`](/workers/wrangler/configuration/)구성 파일.

앱 디렉토리로 이동:

```sh
cd hello-ai
```

## 2. Workers AI에 당신의 노동자를 연결하십시오

당신은 Workers AI에 연결하기 위하여 노동자를 위한 AI 바인딩을 창조해야 합니다.[회사 소개](/workers/runtime-apis/bindings/)Workers는 Workers AI, Cloudflare 개발자 플랫폼과 같은 리소스와 상호 작용할 수 있습니다.

노동자에 Workers AI를 바인딩하려면 Wrangler 파일의 끝에 다음을 추가하십시오:

<WranglerConfig>
  ```jsonc
  {
  	"ai": {
  		"binding": "AI"
  	}
  }
  ```
</WranglerConfig>

당신의 바인딩은 입니다[당신의 노동자 부호에서 유효한](/workers/reference/migrate-to-module-workers/#bindings-in-es-modules-format)에 의해[`env.AI`](/workers/runtime-apis/handlers/fetch/).

## 3. 당신의 노동자에 있는 inference 업무를 실행하십시오

당신은 지금 당신의 노동자에 inference 업무를 실행할 준비가되어 있습니다. 이 경우 LLM을 사용할 것입니다.[`llama-3.1-8b-instruct`](/workers-ai/models/llama-3.1-8b-instruct/), 질문에 대답하기.

업데이트`index.ts`파일 형식`hello-ai`다음 코드와 응용 프로그램 디렉토리:

<TypeScriptExample filename="index.ts">
  ```ts
  export interface Env {
  	//Wrangler config 파일의 이름을 'binding'의 값으로 설정하면
  	//정의 된 변수 이름과 "AI"를 대체합니다.
  	AI: Ai;
  }

  export default {
  	async fetch(request, env): Promise<Response> {
  		const response = await env.AI.run("@cf/meta/llama-3.1-8b-instruct", {
  			prompt: "What is the origin of the phrase Hello, World",
  		});

  		return new Response(JSON.stringify(response));
  	},
  } satisfies ExportedHandler<Env>;
  ```
</TypeScriptExample>

이 점까지, 당신은 당신의 노동자를 위한 AI 바인딩을 창조하고 Llama 3.1 모형을 실행할 수 있는 노동자를 형성했습니다. 로컬로 프로젝트를 테스트할 수 있습니다.


## 5. AI Worker 배포

AI Worker를 전세계에 배포하기 전에 Cloudflare 계정으로 로그인하십시오.

```sh
npx wrangler login
```

QXQX0073XQQ dashboard에 로그인하려면 웹 페이지로 이동합니다. 로그인한 후 Wrangler가 Cloudflare 계정에 변경할 수 있는 경우 요청됩니다. 스크롤 다운 및 선택**지원하다**계속.

마지막으로 Worker를 배포하여 인터넷에 접근할 수 있는 프로젝트를 만들 수 있습니다. 노동자를 배포하려면, 실행:

```sh
npx wrangler deploy
```

```sh output
https://hello-ai.<YOUR_SUBDOMAIN>.workers.dev
```

당신의 노동자는 당신의 관례에 배치될 것입니다[`workers.dev`](/workers/configuration/routing/workers-dev/)하위 도메인. 이제 AI Worker를 실행하는 URL을 방문할 수 있습니다.

이 튜토리얼을 끝내면 Worker를 만들었습니다. AI 바인딩을 통해 Workers AIXQ에 연결하고 Llama 3 모델의 인스퍼 작업을 ran.

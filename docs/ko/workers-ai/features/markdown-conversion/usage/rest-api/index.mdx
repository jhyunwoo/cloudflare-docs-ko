Markdown 변환 REST API를 사용하여 문서를 Markdown으로 변환 할 수 있습니다.

## 필수품: Workers AI를 얻으십시오 API 토큰

REST API를 통해 Markdown 변환 서비스를 사용하려면 API 토큰을 사용해야 합니다.[Workers AI](/workers-ai/)REST API. 더 알아보기[Workers AI REST API로 시작](/workers-ai/get-started/rest-api/)올바른 권한을 가진 API 토큰을 얻는 방법에 대한 지침.

## 관련 기사

이 엔드포인트는 Markdown으로 우리에게 주어진 모든 파일을 변환 할 수 있습니다.

```bash
curl https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/tomarkdown \
  -X POST \
  -H 'Authorization: Bearer {API_TOKEN}' \
  -F "files=@cat.jpeg" \
  -F "files=@somatosensory.pdf" \
  -F 'conversionOptions={ ... }'
```

:::참조

당신을 얻을 수 있습니다`ACCOUNT_ID`에 의해[Workers & PagesXQ에 dashboard](/fundamentals/account/find-account-and-zone-ids/#find-account-id-workers-and-pages).

:::

### 매개 변수

`files` <Type text="File[]" /> <MetaInfo text="required" />

변환하려는 파일.

`conversionOptions` <Type text="ConversionOptions" /> <MetaInfo text="optional" />

파일을 변환하는 방법을 제어 할 수있는 옵션. 더 알아보기[변환 옵션](/workers-ai/features/markdown-conversion/conversion-options/)더 자세한 내용은.

## 지원되는

이 엔드포인트는 변환을 위해 지원하는 풍부한 형식의 전체 세트를 검색할 수 있습니다.

```bash
curl https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/tomarkdown/supported \
  -H 'Authorization: Bearer {API_TOKEN}'
```

:::참조

당신을 얻을 수 있습니다`ACCOUNT_ID`에 의해[Workers & PagesXQXQXQXQXQ](/fundamentals/account/find-account-and-zone-ids/#find-account-id-workers-and-pages).

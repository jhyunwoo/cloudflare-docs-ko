기본적으로,`toMarkdown`서비스 파일에서 텍스트 콘텐츠를 추출합니다. 변환 프로세스의 기능을 확장하려면 특정 파일 유형이 변환되는 방법을 제어하는 서비스에 옵션을 통과 할 수 있습니다.

옵션은 파일 유형에 의해 구성되며 모든 옵션입니다.

## 사용 가능한 옵션

### 제품정보

```typescript
{
  image?: {
    descriptionLanguage?: 'en' | 'it' | 'de' | 'es' | 'fr' | 'pt';
  }
}
```

- `descriptionLanguage`: AI-generated 이미지 설명의 언어를 제어합니다.

:::카트로션

이 옵션은*가장 좋은*기초 : 결과 텍스트가 원하는 언어로 될 것이라는 보장되지 않습니다.

:::

### 사이트맵

```typescript
{
  html?: {
    hostname?: string;
    cssSelector?: string;
  }
}
```

- `hostname`: HTML 내부의 상대적인 링크를 다시 해결 할 때 호스트로 사용하는 문자열.

- `cssSelector`: CSS selector 패턴을 포함하는 문자열은 HTML에서 특정 요소를 선택합니다. 더 알아보기[HTML이 처리되는 방법](/workers-ai/features/markdown-conversion/how-it-works/#html)더 많은 정보.

### PDF 파일

```typescript
{
  pdf?: {
    metadata?: boolean;
  }
}
```

- `metadata`: 이전, 모든 변환 PDF 파일은 항상 변환 할 때 메타 데이터 정보를 포함. 이 옵션은이 행동을 선택 할 수 있습니다.

## 이름 \*

### 회사 소개

사용자 정의 옵션을 구성하려면 패스`conversionOptions`바인딩 호출의 두 번째 인수 내부 객체, 다음과 같이:

```typescript
await env.AI.toMarkdown(..., {
  conversionOptions: {
    html: { ... },
    pdf: { ... },
    ...
   }
})
```

### REST API를

REST API가 파일 업로드를 사용하고 있기 때문에 요청의`Content-Type`일 수 있습니다`multipart/form-data`. 그런 것과 같이, 당신의 끈으로 묶인 목표를 가진 새로운 모양 분야를 값을 포함합니다:

```bash
curl https://api.cloudflare.com/client/v4/accounts/{ACCOUNT_ID}/ai/tomarkdown \
  -X POST \
  -H 'Authorization: Bearer {API_TOKEN}' \
  ...
  -F 'conversionOptions={ "html": { ... }, ... }'
```

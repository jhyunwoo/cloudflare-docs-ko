[옵션 정보](https://en.wikipedia.org/wiki/Markdown)텍스트 생성 및 대형 언어 모델 (LLMs) 교육 및 inference에 필수적이므로 구조, semantic, 인간 및 기계 학습 입력을 제공 할 수 있습니다. 마찬가지로 Markdown은 RAGs의 컨텍스트에서 더 나은 검색 및 합성을 위해 chunking 및 structuring 입력 데이터를 용이하게하며 패싱 및 렌더링이 용이하며 AI 에이전트에 이상적입니다.

이러한 이유로 문서 변환은 AI 애플리케이션을 설계하고 개발할 때 중요한 역할을 합니다. Workers AI는 제공합니다`toMarkdown`개발자가 사용할 수있는 유틸리티 방법[`env.AI`](/workers-ai/features/markdown-conversion/usage/binding/)바인딩 또는[REST API](/workers-ai/features/markdown-conversion/usage/rest-api/)빠르고 쉽고 편리한 변환 및 Markdown 언어에 여러 형식의 문서 요약.

## 가격 책정

`toMarkdown`대부분의 형식 변환을 위해 무료입니다. 일부 경우에, 이미지 변환과 같은, 그것은 Workers AIXQ 모델을 사용할 수 있으며, 이는 Workers AIXQ 무료 할당 제한을 초과하는 경우 추가 비용이 발생할 수 있습니다. 더 알아보기[우리가 사용하는 어떤 모델](/workers-ai/features/markdown-conversion/how-it-works/)그리고[Workers AI 가격 페이지](/workers-ai/platform/pricing/)더 많은 정보.

## 다른 Markdown 변환 기능

- 브라우저 렌더링[/마크 다운](/browser-rendering/rest-api/markdown-endpoint/)REST API는 변환하기 전에 실제 브라우저에서 동적 페이지 또는 응용 프로그램을 렌더링해야하는 경우 Markdown 변환을 지원합니다.
- [에이전트에 대한 Markdown](/fundamentals/reference/markdown-for-agents/)콘텐츠 협상 헤더를 사용하여 Cloudflare 영역에 대한 실시간 문서 변환을 허용합니다.

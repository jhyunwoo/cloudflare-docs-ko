## 잘 다루는 것은?

Fine-tuning은 AI 모델을 수정하는 일반 용어로 추가 데이터로 계속 훈련합니다. 미세 조정의 목표는 세대가 데이터셋과 유사하다는 확률을 높이는 것입니다. 스크래치에서 모델은 비싸고 시간이 걸리는 많은 사용 사례에 대해 실용적이지 않습니다. 기존의 사전 훈련 된 모델을 미세 조정함으로써 원하는 작업을 수행하면서 능력에서 혜택을 누릴 수 있습니다.

[낮은 순위 적응](https://arxiv.org/abs/2106.09685)(LoRA)는 LLMs뿐만 아니라 다양한 모델 아키텍처에 적용 할 수있는 특정 미세 조정 방법입니다. 사전 훈련 된 모델 무게가 직접 수정되거나 기존의 미세 조정 방법의 추가 미세 조정 무게와 융합 된 것이 일반적입니다. LoRA, 다른 한편으로는 미세 톤 중량과 사전 훈련 된 모델이 분리되고 사전 훈련 된 모델이 변경되지 않도록 허용합니다. 마지막 결과는 특정한 작풍에 있는 특정한 성격을 갖는 부호와 같은 특정한 일에 더 정확한 모형을 훈련할 수 있다는 것입니다.

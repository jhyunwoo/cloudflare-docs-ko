비동기 일괄 처리는 단일 통화의 inference 요청의 수집 (배치)를 보낼 수 있습니다. 모든 요청에 대한 즉각적인 응답을 기대하는 대신, 시스템은 처리하고 결과를 나중에 반환합니다.

일괄 처리는 큰 작업 부하에 대 한 유용 하 고 요약 또는 인간의 상호 작용이 없을 때 embedding. 일괄 처리 API를 사용하면 요청이 결국 수행되므로 Cloudflare가 주어진 시간에 충분한 용량이 없습니다.

일괄 요청을 보낼 때 API는 즉시 같은 상태를 가진 영수증을 인정합니다.`queued`특별한 혜택`request_id`. 이 ID는 나중에 처리가 완료되면 최종 응답에 대한 설문 조사에 사용됩니다.

Cloudflare를 생성하고 배치하여 Batch API를 사용할 수 있습니다. 작업자가 레버리지[AI 바인딩을 가진 Batch API](/workers-ai/features/batch-api/workers-binding/), 사용[REST API를](/workers-ai/features/batch-api/rest-api/)직접 또는 처음부터[관련 기사](https://github.com/craigsdennis/batch-please-workers-ai).

:::주\[주]

총 페이로드가 10MB 미만임을 보장합니다.

:::

## 데모 신청

get startedXQ를 빠르게 원한다면 아래 버튼을 클릭하십시오.

[![Workers에 배포](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/craigsdennis/batch-please-workers-ai)

GitHub 계정의 저장소를 만들고 Cloudflare의 비동기 배치 API를 사용하는 방법을 설명하는 데 필요한 작업자를 배치합니다. 템플릿에는 preconfigured AI 바인딩이 포함되어 있으며 외부 references없이 일괄 처리 요청을 전송하고 검색하기위한 예입니다. 배포되면 라이브 노동자를 방문하고 즉시 Batch API로 실험을 시작할 수 있습니다.

## runWithTools의 특징

이 래퍼 방법은 임베디드 기능을 호출 할 수 있습니다. AI 바인딩, 모델, 입력을 전달합니다 (`messages`배열과`tools`배열) 및 선택적인 윤곽.

- `AI Binding`담당자: Mr.
  - AI 바인딩 등`env.AI`.
- `model`BaseAiTextGeneration모델
  - 함수 호출을 지원하는 모델의 ID. 예를 들어,`@hf/nousresearch/hermes-2-pro-mistral-7b`.
- `input`계정 만들기
  - `messages`역할ScopedChatInput\[]
  - `tools`AiTextGenerationToolInputWithFunction\[]는 다음과 같습니다.
- `config`계정 만들기
  - `streamFinalResponse`선택 불린
  - `maxRecursiveToolRuns`선택 번호
  - `strictValidation`선택 불린
  - `verbose`선택 불린
  - `trimFunction`선택 불린 -`trimFunction`, 당신은 그것을 통과할 수 있습니다`autoTrimTools`, 또 다른 돕는 방법은 우리가 자동적으로 의도를 위해 그것을 보내기 전에 올바른 도구 (LLM 사용)를 선택할 것을 결정했습니다. 이것은 당신의 마지막 inference 호출이 몇몇 입력 토큰이 있다는 것을 의미합니다.

## createToolsOpenAPISpec에서

이 방법은 OpenAPI specs를 기반으로 도구 스키마를 자동으로 만들 수 있도록, 그래서 당신은 수동으로 쓰기 또는 도구 스키마를 하드 코딩 할 필요가 없습니다. JSON 또는 YAML 형식으로 API에 OpenAPI spec을 전달할 수 있습니다.

`createToolsFromOpenAPISpec`Authentication 또는 User-Agent와 같은 헤더를 제공해야하는 경우 overrides를 수행 할 수 있는 설정 입력이 있습니다.

- `spec`이름 \*
  - JSON 또는 YAML 형식의 OpenAPI 사양 또는 원격 OpenAPI 사양에 URL.
- `config`Config 옵션 - createToolsFromOpenAPISpec 기능에 대한 구성 옵션
  - `overrides`ConfigRule\[] 선택
  - `matchPatterns`RegExp\[] 옵션
  - `options`선택 객체 \{
    `verbose`선택 불린
    이름 \*

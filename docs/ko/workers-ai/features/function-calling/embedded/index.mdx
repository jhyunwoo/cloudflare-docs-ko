Cloudflare는 독특합니다[Embedded 함수 호출](https://blog.cloudflare.com/embedded-function-calling)도구 호출 inference와 함께 함수 코드를 실행할 수 있는 기능. npm 패키지[`@cloudflare/ai-utils`](https://www.npmjs.com/package/@cloudflare/ai-utils)개발자 도구 키트는 get started.

임베디드 함수 호출은 웹 사이트 및 API와 상호 작용하는 복잡한 에이전트를 쉽게 만들 수 있습니다. 자연 언어를 사용하여 Google 캘린더에서 회의를 만들고, 데이터를 Notion에 저장하고, 다른 API에 routing 요청을 자동적으로 routing하고, R2 물통에 데이터를 저장 - 또는 동시에 모두. 필요한 모든 것은 get started에 프롬프트와 OpenAPI spec입니다.

:::caution\[REST API 지원]

임베디드 함수 호출은 Workers 플랫폼에 기본 기능에 따라 달라집니다. 이것은 임베디드 함수 호출이 통해만 지원된다는 것을 의미합니다[Cloudflare Workers](/workers-ai/get-started/workers-wrangler/), 를 통해[REST API를](/workers-ai/get-started/rest-api/).

:::

### 스카프

이것은<strong>뚱 베어</strong>방법. Workers AI는 다양한 모델에 대해 서로 다른 채팅 템플릿을 사용하여 알 수 있고 텍스트 생성 작업을 만들 때 개발자에게 통합 된 인터페이스를 제공합니다.

Scoped prompts는 메시지 목록입니다. 각 메시지는 두 개의 키 정의: 역할과 내용.

일반적으로 역할은 세 가지 옵션 중 하나 일 수 있습니다.

- <strong>시스템</strong>- 시스템 메시지는 AI의 개성을 정의합니다. 당신은 할 수
  그들을 사용하여 규칙을 설정하고 AI가 행동하는 것을 기대합니다.
- <strong>사용자 이름</strong>- 사용자 메시지가 실제로 AI를 쿼리하는 곳
  질문이나 대화를 제공합니다.
- <strong>지원하다</strong>- AI에 대한 Assistant 메시지
  원하는 출력 형식. 모든 모델은이 역할을 지원합니다.

OpenAI는[좋은 설명](https://platform.openai.com/docs/guides/text-generation#messages-and-roles)그들은 GPT 모델과 이러한 역할을 사용하는 방법. 채팅 템플릿이 유연하지만 다른 텍스트 생성 모델은 동일한 규칙을 따르는 경향이있다.

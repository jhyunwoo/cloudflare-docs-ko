우리는이 목록을 계속 확장하고 새로운, 요청한 모델로 유지됩니다.

Workers AI는 요청한 JSON Schema에 따라 모델이 반응한다는 것을 보증할 수 없습니다. JSON Schema의 작업과 적절성의 복잡성에 따라 모델은 극단적 인 상황에서 요청을 만족시킬 수 없습니다. 그 경우, 그 다음 오류`JSON Mode couldn't be met`반환하고 처리해야합니다.

JSON 파일 모드는 현재 스트리밍을 지원하지 않습니다.
